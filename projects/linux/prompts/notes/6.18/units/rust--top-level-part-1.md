# RUST — (top level) (part 1)

Core Rust-for-Linux crate (`rust/kernel/*`), C FFI bindings (`rust/bindings/*`), and C helper wrappers (`rust/helpers/*.c`) providing memory safety, refcounting (`Arc`, `ARef`), intrusive collections (`List`, `RBTree`), synchronization (`CondVar`, `Completion`, `Revocable`), workqueues, `UserSlice`, `IovIterSource`/`IovIterDest`, strings, tasks, errors, and USB abstractions.

## Architecture & Data Flow

- `ListLinks<ID>` `prev`/`next` are null iff not in a `List`, and `ListItem::view_links` must return null pointers outside `prepare_to_insert`..`post_remove`. In `List::remove_internal_inner`, after relinking `(*next).prev` and `(*prev).next`, clear `(*item).prev` and `(*item).next` to `null_mut()` before setting `self.first = (*prev).next` and calling `T::post_remove` and `ListArc::from_raw`. `List::push_all_back` must reset `other.first = null_mut()` after splicing so dropping `other` does not double-remove nodes. [F7, F41, F46]
- In `list::Iter::next` and `list::Cursor::move_next`, reset the pointer to `null_mut()` when `(*current).next` equals `first` (`stop`). In `list::Cursor::prev_ptr`, check `next == first` before the `next.is_null()` check that substitutes `next = first` prior to dereferencing `(*next).prev`. [F74, F75]
- `ListLinksSelfPtr<T, ID>` must stay `#[repr(C)]` with `inner: ListLinks<ID>` first, and `ListItem::prepare_to_insert` must write `me` into `self_ptr` before returning `links_field` so `view_value`/`post_remove` can recover unsized `*const Self`. `ListArc` transitions must keep `ListArcSafe<ID>` synchronized: `From<Pin<UniqueArc<T>>>` and `pair_from_pin_unique` call `on_create_list_arc_from_unique`, `into_arc` and `Drop::drop` call `on_drop_list_arc`, and `into_raw` uses `transmute_to_arc`. [F48, F100]
- `ArcInner<T>` must stay `#[repr(C)]` with `data: T` last so fat-pointer metadata matches between `*const T` and `*const ArcInner<T>`, and `ArcInner::container_of` can subtract `Layout::new::<Refcount>().extend(Layout::for_value(&*ptr)).unwrap_unchecked().1`. [F67]
- `ForeignOwnable::into_foreign` must return a non-null pointer aligned to `>= Self::FOREIGN_ALIGN`, and `borrow_mut` must never allow changing the address of the foreign allocation (e.g. yielding `&mut Self` on a pointer wrapper). `unsafe impl AlwaysRefCounted` is only valid when every instance is refcounted and `inc_ref` keeps the allocation alive until `dec_ref`, since `From<&T> for ARef<T>` upgrades any `&T`. [F107, F109]
- `HasWork<T, ID>` and `HasDelayedWork<T, ID>` require `raw_get_work` and `work_container_of` to be exact inverses for `ID`, and for `HasDelayedWork` the returned `Work<T, ID>` pointer must be `bindings::delayed_work.work`. [F99]
- `LockClassKey` must only be created uninitialized in static storage via `static_lock_class!` or registered in-place via `LockClassKey::new_dynamic()`, never via a safe `new`/`Default` that leaves a dynamic key unregistered with lockdep. `kernel::Module` and `kernel::InPlaceModule` must require `Send + Sync` supertraits because `init` and `Drop` can run on different tasks. [F106, F115]
- `UserSliceReader` (`skip`, `read_raw`, `read`) and `UserSliceWriter` (`write_slice`, `write`) must check `len <= self.length` and verify `copy_from_user`/`copy_to_user` returned `0` before advancing `self.ptr` and decrementing `self.length`. `UserSliceReader::read_raw` and `IovIterSource::copy_from_iter_raw` must never write uninitialized bytes into `out: &mut [MaybeUninit<u8>]` even on error/partial copy, since `read_slice` and `copy_from_iter` cast `&mut [u8]` to `&mut [MaybeUninit<u8>]`. [F33, F51]
- `unsafe trait AsBytes` forbids uninitialized padding bytes, interior mutability, and kernel pointers; `unsafe trait FromBytes` allows padding only if every bit pattern is valid (no `bool`/`enum` with invalid bit patterns) and there is no interior mutability. [F60]
- `CStr` requires a non-empty slice ending in `0` with no interior `0`s; `len_with_nul` calls `unreachable_unchecked()` if empty, and `index(RangeFrom<usize>)` bounds-checks `index.start` against `self.as_bytes()` to preserve the trailing NUL. `NullTerminatedFormatter` keeps `self.buffer.len() >= 1` and `self.buffer[0] == 0`; `write_str` must check `len > self.buffer.len() - 1`, slice `self.buffer = &mut buffer[len..]`, and write `0` to `self.buffer[0]`. [F64, F66]
- `RawFormatter::write_str` must advance `self.pos` via `saturating_add(s.len())` while clamping copied bytes to `min(pos_new, self.end).saturating_sub(self.pos)` so `self.pos` tracks total formatted length for `rust_fmt_argument` (`%pA`) and `CString::try_from_fmt`. `CString::try_from_fmt` must write both `args` and `"\0"` in both the sizing `RawFormatter` and buffer `Formatter` passes, then scan `f.bytes_written() - 1` bytes with `bindings::memchr` to reject interior NULs. [F65, F80]
- `genmask_*` and `genmask_checked_*` (`impl_genmask_fn!`) must compute the upper mask as `high | (high - 1)` from `high = 1 << end` after checking `start <= end` and `end < <$ty>::BITS`, avoiding `1 << (end + 1)` overflow when `end == <$ty>::BITS - 1`. `Alignable::align_down`/`align_up` must convert `Alignment` into `Self` via `try_from` rather than truncating with `as Self`, returning `0` in `align_down` and `None` (for non-zero `self`) in `align_up` on overflow. [F85, F87]

## Synchronization

- `Revocable::try_access` must call `rcu::read_lock` before loading `self.is_available`, and callers holding `RevocableGuard` (or a reference from `try_access_with_guard`) must not sleep. `Revocable::revoke_internal` atomically swaps `is_available` to `false` and, only on `true -> false`, calls `bindings::synchronize_rcu()` (when `SYNC` is true in `revoke`; skipped in `revoke_nosync` when no concurrent readers exist) before `drop_in_place(self.data.get())`; `PinnedDrop::drop` only calls `drop_in_place` if `*p.is_available.get_mut()` is `true`. [F10, F15, F120, F125]
- `CondVar::wait_internal` must call `prepare_to_wait_exclusive` before `guard.do_unlocked` releases the lock, and `finish_wait` after `do_unlocked` reacquires it and before stack `wait` drops. In `CondVar::wait_interruptible_freezable`, no lock other than `guard` may be held or freezing can deadlock. [F11, F129]
- `AtomicTracker::on_drop_list_arc` must store `false` with `Ordering::Release` and `try_new_list_arc` must transition `false -> true` with `Ordering::Acquire`. `Arc::into_unique_or_drop` must wrap in `ManuallyDrop` and use `refcount.dec_and_test()` followed by `refcount.set(1)`, never dereferencing `this` if `dec_and_test()` returns `false`. [F19, F21]
- In `usb::Adapter::register`, `name`, `probe`, `disconnect`, and `id_table` on `struct usb_driver` must be initialized before `bindings::usb_register_driver`. [F26]
- `IovIterSource` and `IovIterDest` must remain `!Send` because `struct iov_iter` may use thread-local `kmap_local_page()` mappings. Calling `bindings::task_active_pid_ns` without RCU/refcount protection (as in `CurrentTask::active_pid_ns`) is only sound on `current`; arbitrary `Task` pointers must use `Task::get_pid_ns` (`rust_helper_task_get_pid_ns`). [F133, F146]

## Object Lifetimes

- `ForeignOwnable::from_foreign` must be called at most once per `into_foreign` and only after all `borrow`/`borrow_mut` lifetimes on that pointer have ended. A dynamic `LockClassKey` (`new_dynamic()`) calls `bindings::lockdep_unregister_key` in `PinnedDrop::drop`, so all locks using a borrowed reference to it must drop before the key is reclaimed via `from_foreign` and dropped. [F2, F14]
- In `RBTree::drop`, fetch `bindings::rb_next_postorder(next)` before freeing the current node with `drop(KBox::from_raw(this))`; in `rbtree::Cursor::remove_current`, read neighbors via `get_neighbor_raw` before `bindings::rb_erase`. [F9]
- `usb::Adapter::probe_callback` stores `Pin<KBox<T>>` via `dev.set_drvdata(data)`, and `disconnect_callback` must reclaim and drop that exact `Pin<KBox<T>>` via `dev.drvdata_obtain::<Pin<KBox<T>>>()` after `T::disconnect`. When deriving a parent/related `&Device` from a child wrapper (e.g. `AsRef<Device> for usb::Interface<Ctx>`), do not propagate the child's `device::DeviceContext` `Ctx` unless the target shares that bound/lock state. [F13, F110]
- `CurrentTask` references from `current!()`/`Task::current()` must never escape the active task context (including across `kthread_use_mm()`/`kthread_unuse_mm()`, `begin_new_exec()`, `release_task()`, or return to userspace), so closures entering a new mm/task sub-context must require `Send` (blocked by `NotThreadSafe`). [F113]
- `print_macro!` must bind `fmt!($($arg)+)` as the `match` scrutinee around `call_printk` rather than a `let` binding, and `call_printk`'s `module_name` (`__LOG_PREFIX`) must be NUL-terminated. [F92]

## API Contracts

- `ARef::from_raw` adopts an existing refcount without calling `AlwaysRefCounted::inc_ref`, whereas `ARef::from(&T)` and `ARef::clone` call `inc_ref` first. `ListArc::pair_from_unique` and `pair_from_pin_unique` require `build_assert!(ID != ID2)`. [F4, F40]
- `DelayedWork::new` must initialize `(*slot).work` via `bindings::init_work_with_key` and `(*slot).timer` via `bindings::timer_init_key` with `Some(bindings::delayed_work_timer_fn)` and `bindings::TIMER_IRQSAFE`. Work items queued to `workqueue::system_bh()` or `system_bh_highpri()` run in softirq context and must not sleep; `task::might_sleep` must only be called in sleepable context. [F23, F128, F132]
- Construct a single `UserSlice` per userspace region and validate the kernel copy rather than calling `UserSlice::new` or `clone_reader` twice on the same address (TOCTOU). Dynamically-sized copies in `read_raw`/`write_slice` must call `bindings::copy_from_user`/`copy_to_user`, reserving `_copy_from_user`/`_copy_to_user` for compile-time `size_of::<T>()` copies in `read`/`write`. [F56, F94]
- `FromBytes::from_bytes` and `from_bytes_mut` require `bytes.len() == size_of::<Self>()` and `slice_ptr.is_aligned()`; use `from_bytes_copy` for potentially unaligned slices. Compile-time `bit_u*` and `genmask_u*` enforce `n < <$ty>::BITS` and `start <= end` via `build_assert!`; use `checked_bit_*`/`genmask_checked_*` for runtime values not provably in-bounds. `_IOC` (`_IO`, `_IOR`, `_IOW`, `_IOWR`) enforces `dir <= _IOC_DIRMASK`, `ty <= _IOC_TYPEMASK`, `nr <= _IOC_NRMASK`, and `size_of::<T>() <= _IOC_SIZEMASK as usize` via `build_assert!`. [F61, F70, F86]
- `pr_*!` logging macros do not append `\n`; callers must end format strings with `\n` unless followed by `pr_cont!`. `Opaque::ffi_init`/`try_ffi_init` closures must not read from the uninitialized `*mut T` slot before writing, and `Opaque::get` callers must ensure `T` is initialized. [F91, F105]
- `IovIterSource::from_raw` and `IovIterDest::from_raw` assert `data_source` equals `ITER_SOURCE` or `ITER_DEST` and require buffers to stay valid for `'data` and exclusively accessed for `'iov`. Before calling `unsafe { buf.inc_len(len) }` after reading into `Vec::spare_capacity_mut()`, `len` must be bounded to the bytes actually initialized (e.g. `_copy_from_iter` return in `copy_from_iter_vec` or `Ok(())` from `read_raw`). [F112, F116]
- In `rust/kernel/lib.rs`, gate subsystem modules on their base Kconfig symbol (`CONFIG_PCI`, `CONFIG_BLOCK`, `CONFIG_NET`), not optional sub-features like `CONFIG_PCI_MSI`. [F138]

## Error Handling

- In `<Arc<T> as RawWorkItem<ID>>::__enqueue`, `Arc::into_raw(self)` transfers one refcount before `queue_work_on(work_ptr)` and must reclaim it via `Err(unsafe { Arc::from_raw(ptr) })` if `queue_work_on` returns `false`. [F12]
- `Error` wraps `NonZeroI32` in `-(bindings::MAX_ERRNO as i32)..0`; `Error::from_errno` and `to_result` warn and return `EINVAL` for `< -MAX_ERRNO` (and `from_errno` for `>= 0`), while `from_result` casts `e.to_errno() as i16`. `to_result` maps any `err >= 0` to `Ok(())`, so do not use it when positive returns indicate errors or carry data. `from_err_ptr` only checks `bindings::IS_ERR` and returns `Ok(null)` on `NULL`, requiring a separate null check when C can return `NULL`. [F28, F29, F69]
- `copy_from_user`/`_copy_from_user`/`copy_to_user`/`_copy_to_user` return uncopied byte counts (`res != 0` -> `Err(EFAULT)` without advancing `ptr`/`length`), whereas `strncpy_from_user` returns negative errno or copied count. `UserSliceReader::strcpy_into_buf` must reject empty `buf` with `Err(EINVAL)`, cap `raw_strncpy_from_user` to `self.length`, return `Err(EFAULT)` if `len == dst.len() < buf.len()`, and write `0` to the last byte of `buf` when `len == buf.len()`. [F34, F59]
- `CondVar::wait_interruptible_timeout` must check `crate::current!().signal_pending()` before checking if remaining jiffies is `0`, returning `CondVarTimeoutResult::Signal { jiffies }` if both occur. `IovIterDest::simple_read_from_buffer` must reject `*ppos < 0` with `Err(EINVAL)`, return `Ok(0)` without changing `*ppos` when `*ppos` exceeds `usize::MAX` or `contents.len()`, and otherwise advance `*ppos` by copied bytes. [F42, F63]

## External Contracts

- `usb::DeviceId` constructors must zero unused `bindings::usb_device_id` fields and set `match_flags` to the populated-field bitmask; `RawDeviceIdIndex` must use `offset_of!(bindings::usb_device_id, driver_info)`. [F68]
- C macro constants using expressions/`BIT()` (`VM_MERGEABLE`, `BLK_FEAT_ROTATIONAL`, `FOP_UNSIGNED_OFFSET`, `GFP_*`) must be bound via `const <type> RUST_CONST_HELPER_<NAME> = <NAME>;` in `rust/bindings/bindings_helper.h` with their exact C typedef. Rust functions called from C (`rust_fmt_argument`, `WorkItemPointer::run`, `usb::Adapter` callbacks) must be `extern "C"` and use `crate::ffi::{c_char, c_long, c_ulong}` rather than `core::ffi`. [F82, F90, F134]
- Guard 64-bit MMIO helpers (`rust_helper_readq*`, `rust_helper_writeq*`) in `rust/helpers/io.c` with `#ifdef CONFIG_64BIT`, and guard regulator consumer helpers that are only `static inline` when `!CONFIG_REGULATOR` in `rust/helpers/regulator.c` with `#ifndef CONFIG_REGULATOR`. [F122, F123]
- Invoke C-header inline asm templates (`generated_arch_static_branch_asm.rs`, `generated_arch_warn_asm.rs`) via `$crate::asm!` (not `core::arch::asm!`) so `options(att_syntax)` applies on x86. Panicking intrinsics in `rust/compiler_builtins.rs` must use a `__rust` prefix and be listed in `redirect-intrinsics` in `rust/Makefile`. All symbols in `rust/exports.c` must use `EXPORT_SYMBOL_RUST_GPL`. [F135, F137, F139]

## Known Pitfalls

- Use `::pin_init::assert_pinned!($t, $field, $fty, inline)` (not `$crate::assert_pinned!`) in `impl_list_arc_safe!`, and pass `_key.cast_mut()` to `static_key_count` in the `#[cfg(not(CONFIG_JUMP_LABEL))]` arm of `static_branch_unlikely!`. Do not hand-edit `rust/helpers/atomic.c` without updating `scripts/atomic/gen-rust-atomic-helpers.sh`. [F49, F54, F55]
- In `list::CursorPeek::remove`, call `self.cursor.move_next()` before `remove_internal(self.ptr)` when `ISNEXT` is true, and callers in `while let Some(next) = cursor.peek_next()` must not call `cursor.move_next()` after `next.remove()`. [F76]
- In `rust/bindings/bindings_helper.h`, include headers defining C `enum` types (e.g. `<linux/hrtimer_types.h>`) before headers that forward-declare them so `bindgen` emits `c_uint` instead of `i32`. [F81]
- Advance `UserPtr` in `UserSliceReader`/`UserSliceWriter` with `UserPtr::wrapping_byte_add` (after checking `self.length`) so addresses near `usize::MAX` do not panic under `CONFIG_RUST_OVERFLOW_CHECKS`. Call `Kuid::into_uid_in_current_ns` and `Kuid::current_euid` only in the target task's syscall/process context, never from a workqueue or kthread. [F88, F148]
