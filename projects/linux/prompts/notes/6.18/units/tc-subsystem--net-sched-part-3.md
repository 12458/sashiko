# TC subsystem — net/sched (part 3)

This unit contains the generic packet scheduler core (`net/sched/sch_generic.c`) and 17 Qdisc implementations (`sch_htb`, `sch_hfsc`, `sch_qfq`, `sch_prio`, `sch_multiq`, `sch_mq`, `sch_mqprio`, `sch_ingress`, `sch_gred`, `sch_red`, `sch_pie`, `sch_hhf`, `sch_sfb`, `sch_sfq`, `sch_skbprio`, `sch_plug`), managing Qdisc lifecycles, queue grafting, locked/lockless packet enqueue/dequeue, watchdogs, and QoS offloads.

## Architecture & Data Flow

- Every `struct Qdisc` (`qdisc_alloc()`, `noop_qdisc`) must set `.owner = -1`; mutations to `state`, `refcnt`, or `dev_queue` must check `!(qdisc->flags & TCQ_F_BUILTIN)`. `noqueue_init()` sets `qdisc->enqueue = NULL`. `dev_activate()` returns early if `!netif_carrier_ok(dev)` without transitioning `dev_queue->qdisc` or calling `netdev_watchdog_up()`. `mq_change_real_num_tx()` only hashes/unhashes `qdisc_sleeping` where `qdisc != &noop_qdisc && !qdisc->handle`. [F238, F239, F250, F327, F336]
- In `dequeue_skb()`, SKBs from `q->gso_skb` set `*validate = false` unless `xfrm_offload(skb)`. Without `qdisc_may_bulk(q)`, `try_bulk_dequeue_skb_slow()` stops chaining and stashes SKBs with mismatched `skb_get_queue_mapping()` into `q->skb_bad_txq`. `->change()` handlers lowering `sch->limit` must drain via `qdisc_dequeue_internal()` and `qdisc_tree_reduce_backlog()`. `TCQ_F_CPUSTATS` `->reset()` callbacks (`pfifo_fast_reset()`) must zero per-CPU `cpu_qstats` `backlog` and `qlen`. [F247, F248, F356, F358]
- In `struct htb_class`, `leaf` (`cl->level == 0`) and `inner` (`cl->level > 0`) share a union: check `!cl->level` before accessing `cl->leaf`, and erase `cl->pq_node` from `q->hlevel[old_level].wait_pq` before changing `cl->level` and zeroing `inner`. When HTB offload (`q->offload`) detaches a leaf Qdisc, add `old_q->bstats` into `parent->bstats_bias`; in `htb_destroy()`, the `do { ... } while (changed)` loop must skip inner classes (`if (cl->level) continue;`) and call `htb_parent_to_leaf()` when `last_child` is true. [F240, F255, F256, F288]
- Child `dequeue()` can synchronously invoke `qdisc_tree_reduce_backlog()` -> `htb_qlen_notify()` -> `htb_deactivate()`, so `htb_deactivate()` must return if `!cl->prio_activity`, `htb_next_rb_node()` must guard against NULL `*n`, and `htb_lookup_leaf()` / `htb_dequeue_tree()` must handle `hprio->row.rb_node` becoming `NULL`. `htb_change_class_mode()` calls `htb_deactivate_prios()` before `cl->cmode = new_mode` and `htb_activate_prios()` after. Erasing `cl->node + prio` requires advancing `hprio->ptr` in `htb_remove_class_from_row()`, and saving `last_ptr_id` / clearing `ptr = NULL` before `htb_safe_rb_erase()` in `htb_deactivate_prios()`. `htb_add_to_wait_tree()` increments `cl->pq_key++` if `cl->pq_key == q->now`. `htb_init()` clamps `q->rate2quantum >= 1`, and `htb_change_class()` uses `do_div()` and clamps `cl->quantum` to `INT_MAX`. [F207, F252, F253, F254, F286, F308]
- In `hfsc_enqueue()`, increment `sch->qstats.backlog` and `sch->q.qlen` right after `qdisc_enqueue()` and before `init_ed()`, `init_vf()`, or `peek()`. In `hfsc_change_class()` and `hfsc_dequeue()`, re-check `cl->qdisc->q.qlen != 0` after `qdisc_peek_len()` before `init_ed()`, `update_ed()`, `update_d()`, `init_vf()`, or `update_vf()`. Non-root parents in `hfsc_change_class()` lacking `HFSC_FSC` must call `hfsc_upgrade_rt(parent)` under `sch_tree_lock(sch)`. Every `cftree_insert/update/remove()` on `cl` must call `update_cfmin(cl->cl_parent)`. `hfsc_classify()` and `hfsc_bind_tcf()` only resolve to `cl->level < head->level`. `m2sm()`, `m2ism()`, and `d2dx()` widen `m`/`d` to `u64`, add `divisor - 1` before `do_div()`, and return `HT_INFINITY` in `m2ism()` when `m == 0`; `rtsc_min()` returns early when `isc->sm1 <= isc->sm2`. [F257, F258, F259, F260, F289, F302, F303]
- In `sch_qfq.c`, `qfq_update_agg()` and `qfq_destroy_agg()` must update `q->nonfull_aggs`, `agg->budgetmax`, `agg->inv_w`, `q->wsum`, and `q->iwsum` in lockstep, and advance `q->in_serv_agg` via `qfq_choose_next_agg(q)` if equal. `qfq_change_class()` and `qfq_change_agg()` must check `lmax <= QFQ_MAX_LMAX` (and `>= QFQ_MIN_LMAX` on config) before `qfq_update_agg()`. `qfq_slot_scan/rotate()` shift `grp->full_slots` and advance `grp->front` modulo `QFQ_MAX_SLOTS` in lockstep; `qfq_slot_insert()` caps `slot` at `QFQ_MAX_SLOTS - 2`. Compare virtual timestamps with `qfq_gt(a, b)` (`(s64)(a - b) > 0`). [F261, F262, F276, F304]
- In `sch_mqprio.c`, `dev->num_tx_queues < TC_H_MIN_PRIORITY` separates 1-based TXQ handles (`cl - 1`) from TC handles (`>= TC_H_MIN_PRIORITY`). In `mqprio_walk()`, if `ntx < TC_MAX_QUEUE` after the TC loop, pad `arg->count` and `ntx` to `TC_MAX_QUEUE` before subtracting `TC_MAX_QUEUE`. `TCA_MQPRIO_TC_ENTRY_INDEX` uses `NLA_POLICY_MAX(NLA_U32, TC_QOPT_MAX_QUEUE - 1)`, and `mqprio_parse_nlattr()` rate loops must check `nla_len(attr) == sizeof(u64)` and `i < qopt->num_tc`. [F268, F269, F271, F297]
- In `sch_sfq.c`, `skblist_next` and `skblist_prev` must be the first two members of `struct sfq_slot`. `sfq_index` `< SFQ_MAX_FLOWS` indexes `q->slots[]`, `[SFQ_MAX_FLOWS, SFQ_MAX_FLOWS + SFQ_MAX_DEPTH]` uses `sfq_dep_head()`, and `SFQ_EMPTY_SLOT` (`0xffff`) marks empty `q->ht[]` buckets. `sfq_classify/walk()` return 1-based handles (`cl - 1` indexes `q->ht[]`). Every `slot->qlen` change must use `sfq_inc/dec()`, and 0/1 transitions (including `sfq_drop()` and `sfq_dequeue()`) must update `q->ht[slot->hash]` and `q->tail` (`NULL` if `slot->next == x`). `sfq_change()` rejects `(int)ctl->quantum < 0`, `ctl->perturb_period < 0 || > INT_MAX / HZ`, and post-clamp `limit == 1`. [F208, F264, F273, F274, F275, F313, F318]
- In `sch_hhf.c`, `HHF_ARRAYS_LEN` must be a multiple of `BITS_PER_LONG`; `hhf_classify()` checks `test_bit(pos, q->hhf_valid_bits[i])` before reading `q->hhf_arrays[i][pos]`. Use `hhf_time_before(a, b)` for `u32` timestamps. `hhf_change()` widens `new_quantum` to `u64` before multiplying by `new_hhf_non_hh_weight` and rejects `0` or `> INT_MAX`. `seek_list()` returns `NULL` without freeing an expired entry if `list_is_last(&flow->flowchain, head)`. In `hhf_dequeue()`, an empty `bucket` on `q->new_buckets` when `!list_empty(&q->old_buckets)` moves to `q->old_buckets` rather than `list_del_init()`. [F263, F294, F295, F309, F310, F324]
- In `sch_gred.c`, `gred_vqs_validate()` validates all `TCA_GRED_VQ_ENTRY` items (`dp < table->DPs`, `dp == cdp || table->tab[dp]`) before `gred_vqs_apply()`. Changing `grio` or VQ `prio` calls `gred_wred_mode_check(sch)`, and in WRED mode `gred_enqueue()` syncs `q->vars` with `table->wred_set` via `gred_load/store_wred_set()`. In `sch_pie.c`, `pie_qdisc_enqueue()` calls `pie_set_enqueue_time(skb)` when `!q->params.dq_rate_estimator`; `pie_process_dequeue()` and `pie_calculate_probability()` guard against `dtime == 0` and `vars->avg_dq_rate == 0`. [F246, F266, F278, F311]
- In `sfb_enqueue()`, copy `sfb_skb_cb(skb)` before `qdisc_enqueue()` and call `increment_qlen()` only on `NET_XMIT_SUCCESS`; `sfb_bucket` `p_mark` and `qlen` saturate in `[0, 0xFFFF]`. In `sch_skbprio.c`, clamp `skb->priority` to `SKBPRIO_MAX_PRIORITY - 1`, maintain `lowest_prio`/`highest_prio` on non-empty queues, and reset `highest_prio = 0, lowest_prio = SKBPRIO_MAX_PRIORITY - 1` when all `q->qdiscs[]` are empty. [F265, F267, F281, F314]

## Synchronization

- In `sch_direct_xmit()`, release `qdisc_lock(q)` before `validate_xmit_skb_list()` and `HARD_TX_LOCK()`, re-acquiring it only after `HARD_TX_UNLOCK()` before `dev_requeue_skb()`. Hold `dev->tx_global_lock` around `netif_freeze/unfreeze_queues()` (`netif_freeze_queues()` takes `__netif_tx_lock(txq, cpu)`). In `dev_watchdog()`, check `netif_xmit_stopped(txq)`, issue `smp_mb()`, then read `READ_ONCE(txq->trans_start)`. [F210, F215, F343]
- On `TCQ_F_NOLOCK` Qdiscs: `qdisc_run_begin()` sets `__QDISC_STATE_MISSED` and retries `spin_trylock(&qdisc->seqlock)`, pairing with `smp_mb()` after `spin_unlock(&qdisc->seqlock)` in `qdisc_run_end()`; `qdisc_maybe_clear_missed()` issues `smp_mb__after_atomic()` after `clear_bit(__QDISC_STATE_MISSED)` before re-checking `netif_xmit_frozen_or_stopped(txq)`; `q->gso_skb` and `q->skb_bad_txq` require `qdisc_lock(q)` (re-peeking `gso_skb` after locking); `dev_reset_queue()` locks `qdisc->seqlock` then `qdisc_lock(qdisc)` with BH disabled; and `pfifo_fast_dequeue()` clears `MISSED`/`DRAINING`, issues `smp_mb__after_atomic()`, and retries once (`need_retry = false`) if `QDISC_STATE_NON_EMPTY` is set. `pfifo_fast_change_tx_queue_len()` must use `skb_array_resize_multiple_bh()`. [F211, F212, F213, F214, F293, F341, F350]
- `dev_deactivate_many()` marks queues `DEACTIVATED`, sets `&noop_qdisc`, stops the watchdog, and calls `synchronize_net()` before `dev_reset_queue()` and waiting for `!some_qdisc_is_busy(dev)`. Callers without `rtnl_lock` must use `qdisc_put_unlocked()`. `GFP_KERNEL` allocations, `ndo_setup_tc`, and `qdisc_put()` / class destroy helpers must run outside `sch_tree_lock(sch)` (which disables BH, while `lockdep_unregister_key()` sleeps), and child Qdisc detachment/replacement must call `qdisc_purge_queue()` (or `qdisc_replace()`) under `sch_tree_lock(sch)` first. [F220, F221, F223, F326, F338]
- Because child Qdiscs can re-enter `enqueue()`, `hfsc_enqueue()` checks `!cl_in_el_or_vttree(cl)` and `qfq_enqueue()` checks `cl_is_active(cl)` after `qdisc_enqueue()`. In `sch_qfq.c`, `qfq_change_agg()` runs in softirq (`GFP_ATOMIC`), so all control/dump accesses to `cl->agg` must hold `sch_tree_lock(sch)`. In `mqprio_dump_class_stats()`, drop `d->lock` (`spin_unlock_bh`) before locking per-queue Qdiscs for `cl >= TC_H_MIN_PRIORITY` and re-acquire it before `gnet_stats_copy_basic()`. [F204, F206, F222, F340]
- `mini_qdisc_pair_swap()` waits for the RCU grace period on `miniq->rcu_state` before updating `miniq->filter_list` and `*miniqp->p_miniq`, then sets `miniq_old->rcu_state = start_poll_synchronize_rcu()`. Datapath `filter_list` and `sch->stab` reads use `rcu_dereference_bh()`. Timer callbacks (`pie_timer`, `red_adaptative_timer`, `sfq_perturbation`) hold `rcu_read_lock()` around `qdisc_lock(qdisc_root_sleeping(sch))`, and callers under `sch_tree_lock(sch)` use `timer_delete()`, not `timer_delete_sync()`. `sch->limit` (`sch_skbprio`) and `q->defcls` (`sch_hfsc`) require `WRITE_ONCE()`/`READ_ONCE()`. [F219, F228, F345, F353]

## Object Lifetimes

- `qdisc_alloc()` and `__qdisc_destroy()` call `lockdep_unregister_key(&sch->root_lock_key)` before freeing `sch`; `qdisc_alloc()` calls `netdev_hold()` after fallible allocations, and `__qdisc_destroy()` runs `qdisc_reset()` and `ops->destroy()` before `bpf_module_put()` and `netdev_put()`. `netdev_watchdog_up/down()` and `dev_watchdog()` maintain one `dev->watchdog_dev_tracker` ref under `dev->tx_global_lock` while `watchdog_timer` is pending. [F190, F217, F330]
- `htb_init()` and `hfsc_init_qdisc()` initialize watchdogs (and `q->work` in HTB) before any error return. `->destroy()` callbacks synchronously cancel work/timers (`cancel_work_sync`, `qdisc_watchdog_cancel`, `timer_delete_sync` after zeroing period) and complete all `tcf_block_put()` calls before freeing classes or private data. In `mq`, `mqprio`, and offloaded `htb`, `.attach` frees/NULLs pre-allocated `qdiscs`/`direct_qdiscs`, and `.destroy` calls `qdisc_put()` on non-NULL entries if `.attach` never ran; HTB offload grafting onto `dev_queue` requires `qdisc_refcount_inc()` for the second reference in `qdisc_sleeping`. [F196, F225, F332, F346, F372]
- In `sch_ingress.c`, `ingress/clsact_destroy()` guard `sch->parent`, call `tcf_block_put_ext()` before `tcx_miniq_dec()` and `tcx_entry_free()`, and balance `tcx_miniq_inc/dec()`, detaching (`tcx_entry_update` with `true` for ingress, `false` for egress) and freeing `entry` only when `!tcx_entry_is_active(entry)`. `gred_change_vq()` sets `*prealloc = NULL` when consuming `prealloc`. `hfsc_destroy_class()` guards `kfree(cl)` with `cl != &q->root` and `hfsc_delete_class()` rejects `&q->root`. [F200, F201, F205, F236, F237, F321]

## API Contracts

- Every `Qdisc_ops` using `qdisc_priv(sch)` sets `ops->priv_size >= sizeof(...)` and uses `bpf_try_module_get/put()`. `qdisc_skb_cb(skb)->data` structs call `qdisc_cb_private_validate()`. `qdisc_alloc()` and `fifo_create_dflt()` return `ERR_PTR`, whereas `qdisc_create_dflt()` returns `NULL` (falling back to `&noop_qdisc` without `qdisc_hash_add()` in `htb`, `hfsc`, `qfq`, `prio`). [F191, F229, F242, F316, F360]
- `dequeue_skb()` checks `skb == SKB_XOFF_MAGIC` from `qdisc_dequeue_skb_bad_txq()`. `htb_enqueue()` checks both `cl == HTB_DIRECT` and `!cl` from `htb_classify()`. Dequeue helpers building `skb->next` chains call `skb_mark_not_on_list()` on the tail SKB, and parents peeking children dequeue via `qdisc_dequeue_peeked()`. On quota exhaustion or requeue, `TCQ_F_NOLOCK` Qdiscs set `__QDISC_STATE_MISSED` while locked Qdiscs call `__netif_schedule(q)`. When `hhf_enqueue()` or `sfq_enqueue()` drops a packet over limit, return `NET_XMIT_CN` only if dropped from the same flow/bucket, else call `qdisc_tree_reduce_backlog()` and return `NET_XMIT_SUCCESS`. [F230, F231, F355, F359, F362, F366]
- Array-indexed classful Qdiscs (`prio`, `multiq`, `mq`, `mqprio`, `sfq`, `skbprio`) use 1-based class cookies (`cl - 1` for 0-based indexing). `dev_graft_qdisc()` callers on a running device (`dev->flags & IFF_UP`) bracket with `dev_deactivate/activate()`. Offload helpers check `tc_can_offload(dev)` and `ndo_setup_tc`. `mqprio_init()` validates `qopt` (`mqprio_validate_qopt()`, querying `qdisc_offload_query_caps()` and `ethtool_dev_mm_supported()`) before parsing nlattrs or configuring queues, and delegates TC mapping to `ndo_setup_tc` when `qopt->hw` is set. `__red_change()`, `gred_change_vq()`, and `sfq_change()` call `red_check_params()` before `red_set_parms()`. [F245, F270, F312, F328, F333, F334, F335]

## Error Handling & External Contracts

- `->reset()` and `->destroy()` callbacks (`gred_destroy`, `pfifo_fast_reset/destroy`, `hhf_destroy`) NULL-check pointers allocated after fallible `->init()` steps; `htb_init()` sets `q->offload = true` only after `htb_offload()` and all fallible steps succeed. If `htb_offload()` fails in `htb_destroy_class_offload()` or `htb_change_class()` while `!destroying`, restore `old` via `htb_graft_helper(dev_queue, old)`. Treat empty child Qdiscs on activate/dequeue/peek as recoverable (`qdisc_warn_nonwc()`, never `WARN_ON`), and keep hot-path warnings rate-limited or once-only. [F234, F241, F331, F364, F365]
- Zero-initialize stack UAPI structs in `.dump`/`.dump_stats`; `gred_dump()` appends all `MAX_DPs` entries with `opt.DP = MAX_DPs + i` for NULL VQs. `mqprio_parse_nlattr()` offsets by `NLA_ALIGN(sizeof(*qopt))` and rejects trailing attrs when `!qopt->hw`. Convert netlink time/tick units in `sch_pie`, `sch_hhf`, and `sch_htb` (`PSCHED_TICKS2NS`/`NS2TICKS`, `usecs_to_jiffies`/`jiffies_to_usecs`) and check `HTB_VER >> 16`. [F279, F367, F368, F369, F370]

## Known Pitfalls

- In `htb_dequeue_tree()`, if an empty class is deactivated and `cl == start`, update `start = next = htb_lookup_leaf(hprio, prio)` so `while (cl != start)` terminates. In `sch_hfsc.c`, `seg_x2y()` and `seg_y2x()` split `x`/`y` into upper/lower parts before multiplying by `sm`/`ism`, and `seg_y2x()` checks `ism == HT_INFINITY`. In `sch_qfq.c`, `qfq_make_eligible()` checks `last_flip_pos > 31` before `1UL << last_flip_pos`, and 32-bit lengths/budgets cast to `u64` before multiplying by `inv_w` or `iwsum`. In `multiq_tune()`, size `removed` for `q->max_bands - qopt->bands`, not `q->max_bands - q->bands`. [F285, F301, F305, F307, F315]
