# ARM/QUALCOMM MAILING LIST — (top level) (part 2)

Qualcomm drivers: UART (`msm_serial`, `qcom_geni_serial`), UFS (`ufs-qcom`), DWC3 (`dwc3-qcom`), WLED (`qcom-wled`), watchdog (`qcom-wdt`), and DT clock headers (`include/dt-bindings/clock/qcom,*`).

## Architecture & Data Flow

- In `ufs-qcom.c`, `ufs_qcom_bw_table` uses 1-based gear/lane clamped to `QCOM_UFS_MAX_GEAR` (5) and `QCOM_UFS_MAX_LANE` (2) in `ufs_qcom_get_bw_table()`, while `MODE_MIN`/`MODE_MAX` use `[MODE_MIN/MAX][0][0]` (update in lockstep with new max-BW entries for `ufs_qcom_icc_init()`). In `ufs_qcom_pwr_change_notify()` (`POST_CHANGE`), copy `dev_req_params` to `host->dev_req_params` before `ufs_qcom_icc_update_bw(host)`. [F370, F374, F387]
- In `ufs-qcom.c`, sync `host->phy_gear` with `host->host_params.hs_tx_gear` in `ufs_qcom_parse_gear_limits()`, and in `ufs_qcom_pwr_change_notify()` (`PRE_CHANGE`, `UFSHCD_STATE_RESET`) match `dev_req_params->gear_tx` (clearing `UFSHCD_QUIRK_REINIT_AFTER_MAX_GEAR_SWITCH`) or update `phy_gear`. In `ufs_qcom_power_up_sequence()`, if `hw_ver.major == 0x5` and `phy_gear == UFS_HS_G5`, set `host_params.hs_rate = PA_HS_MODE_A` before computing PHY `mode`. [F372, F373]
- In `ufs-qcom.c`, set `hba->spm_lvl = UFS_PM_LVL_5` when `drvdata && drvdata->no_phy_retention` in `ufs_qcom_init()`; set `opr->base = hba->mcq_base + (opr->offset - UFS_QCOM_MCQ_CONFIG_OFFSET)` in `ufs_qcom_op_runtime_config()`; and re-read `ufshcd_dme_get()` on timeout in `ufs_qcom_check_hibern8()` before checking `tx_fsm_val != TX_FSM_HIBERN8`. [F406, F426, F440]
- In `ufs_qcom_set_core_clk_ctrl()`, check `FIELD_FIT` (`CLK_1US_CYCLES_MASK_V4` for `hw_ver.major >= 4`, else `CLK_1US_CYCLES_MASK`) and return `-ERANGE` before `FIELD_PREP` into `DME_VS_CORE_CLK_CTRL`. In `ufs_qcom_cfg_timers()`, clamp `clk_freq >= DEFAULT_CLK_RATE_HZ` (`1000000`) before `/ USEC_PER_SEC`. Any new `TSTBUS_*` before `TSTBUS_MAX` needs a `testbus_info` entry (`nminor <= 256`; `ufs_qcom_dump_testbus()` passes `nminor * sizeof(u32)` to `print_hex_dump()`) and a `case` in `ufs_qcom_testbus_config()`. [F375, F389, F415, F429]
- In `dwc3-qcom.c`, `qcom->ports[]` and `pwr_evnt_irq_stat_reg[]` use 0-based `port_index`, whereas `usb_hub_find_child()` and multiport DT IRQ names in `dwc3_qcom_setup_port_irq()` / `dwc3_qcom_find_num_ports()` use `port_index + 1`. `dwc3_qcom_suspend()` samples `port->usb2_speed` before enabling IRQs, and `dwc3_qcom_disable_port_interrupts()` on resume must branch on saved `port->usb2_speed` identically. [F376, F392]
- In `qcom_geni_serial.c`, earlycon-reachable helpers (`poll_bitfield()`, `get_char()`, `wr_char()`, `__qcom_geni_serial_console_write()`) must only call `to_dev_port(uport)` when `((struct qcom_geni_private_data *)uport->private_data)->drv` is non-`NULL`. `get_port_from_line()` must pass `nr_ports - 1` as max to `ida_alloc_range()`, and `qcom_geni_serial_probe()` must return `-ENODEV` if `uport->private_data` is set. In `qcom_geni_serial_port_setup()`, call `geni_load_se_firmware(&port->se, GENI_SE_UART)` on `GENI_SE_INVALID_PROTO`, or return `-ENXIO` if not `GENI_SE_UART`. [F382, F421, F442, F444]
- In `qcom_geni_serial.c`, FIFO counts (`tx_fifo_depth`, `TX_FIFO_WC`, `RX_FIFO_WC_MSK`) are in 4-byte words (`BYTES_PER_FIFO_WORD`) and must be scaled against byte counts (`SE_UART_TX_TRANS_LEN`, `tx_remaining`, `tx_queued`, `kfifo_len`). In `qcom_geni_serial_handle_tx_fifo()`, clear `M_TX_FIFO_WATERMARK_EN` in `SE_GENI_M_IRQ_CLEAR` after writing a chunk and disable it in `SE_GENI_M_IRQ_EN` when `tx_remaining == 0`. [F369, F424]
- In `qcom_geni_serial.c`, `geni_serial_set_rate()` must compute `clk_div = DIV_ROUND_UP(clk_rate, baud * sampling_rate)` and verify `clk_div <= (CLK_DIV_MSK >> CLK_DIV_SHFT)`. When `drop` is true in `handle_rx_console()` and `qcom_geni_serial_handle_rx_dma()`, still drain RX FIFO (`ioread32_rep`, `i += chunk`) or unprep/re-prep RX DMA, skipping only flip-buffer insertion. Before console TX in `__qcom_geni_serial_console_write()` or `__msm_console_write()`, add the `'\n'` count in `s[0..count-1]` to the hardware transfer length (`SE_UART_TX_TRANS_LEN` or `msm_reset_dm_count()`). [F385, F404, F417]
- In `msm_serial.c`, `struct uart_port uart` must be first in `struct msm_port` (`msm_serial_suspend()`/`resume()` cast `drvdata` to `struct msm_port *`). Do not access `MSM_UART_MREG`/`NREG`/`DREG`/`MNDREG` in `msm_serial_set_mnd_regs()` when `msm_port->is_uartdm` is set. In `msm_find_best_baud()`, `break` if `clk_round_rate(msm_port->clk, old + 1)` returns `target == old`. [F400, F422, F441]
- In `msm_handle_tx()`, TX DMA `dma_count` must be `UARTDM_TX_AIGN` aligned and `>= UARTDM_BURST_SIZE` (16) on `is_uartdm > UARTDM_1P3`, and `<= UARTDM_TX_MAX` (256) on `<= UARTDM_1P3`, else use PIO. In `msm_handle_rx_dm()`, `old_snap_state` accumulates bytes on non-stale `MSM_UART_IMR_RXLEV` (minus unread remainder if `RX_READY` clears) and is subtracted from `UARTDM_RX_TOTAL_SNAP` and zeroed on `MSM_UART_IMR_RXSTALE` before re-arming `UARTDM_DMRX`. [F364, F386]
- In `qcom-wled.c`, `wled_cabc_config`, `wled_ovp_delay`, and `wled_auto_detection_required` are `NULL` on WLED3. In `wled_configure()`, bound `string_len` and `enabled_strings[i]` by `wled->max_string_count` (3 on WLED3, 4 on WLED4/5) and require `qcom,num-strings <= string_len`. On WLED5, clamp `wled->max_brightness` to `WLED5_SINK_REG_BRIGHT_MAX_12B` when `cabc_sel` is set before `wled5_setup()`. [F354, F380, F395]
- In `qcom-wled.c`, call `wled_module_enable()` only when `!!brightness != !!wled->brightness` (or in `wled_short_irq_handler()`). In `wled_update_status()`, latch brightness with `wled5_mod_sync_toggle()` on WLED5 and `wled->wled_sync_toggle()` on `< 5`. In `wled_auto_string_detection()`, read `WLED4_SINK_REG_CURR_SINK` before disabling sinks, and restore CABC, `WLED3_CTRL_REG_FEEDBACK_CONTROL`, `wled->brightness`, and `WLED3_CTRL_REG_MOD_EN` (or set `disabled_by_short = true`). In `qcom-wdt.c`, `qcom_wdt_set_timeout()` and `qcom_wdt_set_pretimeout()` must call `qcom_wdt_start()` to update `WDT_BARK_TIME`, `WDT_BITE_TIME`, and `WDT_RST`. [F377, F378, F379, F381]

## Synchronization

- In `qcom_geni_serial.c`, set `IRQ_NOAUTOEN` on `uport->irq` before `devm_request_irq()`, and in `qcom_geni_serial_startup()` call `qcom_geni_serial_start_rx()` under `uart_port_lock_irq(uport)` after `port_setup()` and before `enable_irq()`. In `qcom_geni_serial_shutdown()`, call `disable_irq(uport->irq)` before `uart_port_lock_irq(uport)`, and hold `uport->lock` across `stop_tx()`, `stop_rx()`, and `cancel_tx_cmd()`. [F328, F329, F330]
- In `__msm_console_write()` and `qcom_geni_serial_console_write()`, use `uart_port_trylock_irqsave()` when `oops_in_progress` and only unlock if `locked`. In `qcom_geni_serial_console_write()`, when `qcom_geni_serial_main_active(uport)` and (`!locked` or `tx_remaining == 0`), call `qcom_geni_serial_poll_tx_done()` instead of `drain_fifo()`. Update `port->poll_timeout_us` via `WRITE_ONCE()` in `qcom_geni_serial_set_termios()`. [F331, F332, F456]
- In `msm_serial.c`, serialize runtime `msm_port->imr` and `MSM_UART_IMR` updates under `port->lock`. `msm_set_baud_rate()` (`__must_hold(&port->lock)`) must unlock `port->lock` before `msm_find_best_baud()` and `dev_pm_opp_set_rate()`, then relock and update `*saved_flags` before touching `uartclk`, `imr`, or registers. `msm_stop_dma()` must clear `dma->rx.count` and `sg_init_table(&dma->tx_sg, 1)`, and `msm_complete_rx/tx_dma()` must recheck `!dma->rx.count` / `!sg_dma_len(&dma->tx_sg)` after locking `port->lock`. In `qcom_geni_serial_isr()`, `msm_uart_irq()`, and `msm_complete_rx_dma()`, call `uart_prepare_sysrq_char()` under `uport->lock` and unlock with `uart_unlock_and_check_sysrq()`. [F333, F334, F335, F473]
- Hold `wled->lock` across `wled_update_status()`, `wled_short_irq_handler()`, `wled_ovp_irq_handler()`, and `wled_auto_detection_at_init()`. In `ufs_qcom_host_reset()`, call `ufshcd_disable_irq(hba)` before `reset_control_assert(host->core_reset)`, and `ufshcd_enable_irq(hba)` after deassert only if `hba->is_irq_enabled` was true. In `dwc3-qcom.c`, request wakeup IRQs with `IRQF_NO_AUTOEN`, enable only after core suspend, disable before core resume, and only call `dwc3_qcom_is_host()` or read `qcom->dwc.xhci` where role switching cannot race. [F336, F339, F342, F462]

## Object Lifetimes

- In `ufs-qcom.c`, run `ufs_qcom_power_up_sequence(hba)` before `ufs_qcom_enable_lane_clks(host)` in `ufs_qcom_hce_enable_notify()` (`PRE_CHANGE`), roll back `phy_init(phy)` with `phy_exit(phy)` on later PHY errors, and in `ufs_qcom_exit()` disable lane clocks and call `phy_power_off()` before `phy_exit()`. In `ufs_qcom_opp_freq_to_clk_freq()`, check `found` before `dev_pm_opp_get_freq_indexed()` and call `dev_pm_opp_put(opp)` on all paths. [F312, F314, F407, F432]
- In `ufs_qcom_config_esi()`, call `platform_device_msi_free_irqs_all(hba->dev)` only after `platform_device_msi_init_and_alloc_irqs()` succeeds, after freeing `[0, idx - 1]` via `devm_free_irq()` on error, and in `ufs_qcom_remove()` when `host->esi_enabled`. Use `devm_of_qcom_ice_get()` and `devm_blk_crypto_profile_init()` in `ufs_qcom_ice_init()`. [F310, F434, F435]
- In `dwc3-qcom.c`, `icc_put()` `icc_path_ddr` and `icc_path_apps` on init/probe failure and in `dwc3_qcom_remove()`. In `dwc3_qcom_probe()`, undo `clk_bulk_prepare_enable()` on error, call `dwc3_core_remove(&qcom->dwc)` before `clk_bulk_disable_unprepare()` if `dwc3_core_probe()` succeeded, and never call `reset_control_assert(qcom->resets)` after deassert. [F317, F319, F449]
- In `msm_serial.c`, zero `struct msm_dma` on failure/release in `msm_request_tx/rx_dma()` and `msm_release_dma()`. `msm_request_port()` must `release_mem_region()` if `ioremap()` fails, and `msm_release_port()` must release the region, `iounmap()`, and set `port->membase = NULL`. In `msm_serial_early_console_setup_dm()`, clear `UARTDM_DMEN` and reset/enable RX/TX via `MSM_UART_CR` before setting `device->con->write`. [F320, F322, F431]
- In `qcom_geni_serial.c`, zero `tx_dma_addr` (and `tx_remaining`) or `rx_dma_addr` on `geni_se_tx/rx_dma_unprep()`; in `qcom_geni_serial_handle_rx_dma()`, unprep and zero `rx_dma_addr` before `handle_rx_uart()` or `geni_se_rx_dma_prep()`. `geni_serial_resources_on()` enables ICC before `geni_se_resources_on()` (disabling ICC on error), and `geni_serial_resources_off()` zeroes OPP rate and calls `geni_se_resources_off()` before `geni_icc_disable()`. For console ports, set `QCOM_ICC_TAG_ACTIVE_ONLY` before `uart_suspend_port()` and restore `QCOM_ICC_TAG_ALWAYS` after `uart_resume_port()`. [F324, F325, F452, F459]
- In `qcom_geni_serial_probe()`, roll back `uart_add_one_port()` on `dev_pm_set_dedicated_wake_irq()` error via `device_init_wakeup(..., false)`, `ida_free()`, and `uart_remove_one_port()`. In `qcom-wled.c`, when `wled_module_enable(wled, 0)` runs with `ovp_irq > 0`, call `disable_irq(wled->ovp_irq)` only if `cancel_delayed_work_sync(&wled->ovp_work)` is `false`; reset `ovp_irq = 0` if `devm_request_threaded_irq()` fails. [F326, F327]

## API Contracts

- In `ufs-qcom.c`, when `hba->use_pm_opp` and `freq != ULONG_MAX`, map `freq` via `ufs_qcom_opp_freq_to_clk_freq()` in `ufs_qcom_cfg_timers()`, `ufs_qcom_set_core_clk_ctrl()`, and `ufs_qcom_freq_to_gear_speed()` (which clamps to `max_pwr_info.info.gear_rx` and defaults to `UFS_HS_DONT_CHANGE`). Pass `ceil(clk_freq, HZ_PER_MHZ)` to `ufs_qcom_set_clk_40ns_cycles()`. [F346, F347, F371]
- In `ufs-qcom.c`, `ufs_qcom_dump_regs()` requires 4-byte aligned `offset`/`len` and `GFP_ATOMIC`; in `ufs_qcom_dump_dbg_regs()`, guard `ufs_qcom_dump_mcq_hci_regs()`, `cond_resched()`, and `ufs_qcom_dump_testbus()` with `if (in_task())`. In `ufs_qcom_ice_init()`, scale `REG_UFS_CRYPTOCAP` index `i` by `sizeof(__le32)`, pass `caps.config_count + 1` to `devm_blk_crypto_profile_init()`, and multiply `cap.sdus_mask` by `512`. Bracket `qcom_ice_program/evict_key()` with `ufshcd_hold/release(hba)`. Allocate `hba->nr_hw_queues - hba->nr_queues[HCTX_TYPE_POLL]` MSIs in `ufs_qcom_config_esi()`. [F391, F427, F460, F468, F470]
- In `dwc3-qcom.c`, `dwc3_qcom_probe()` must pass `ignore_clocks_and_resets = true` and `res->end = res.start + SDM845_QSCRATCH_BASE_OFFSET` to `dwc3_core_probe()`, not call `platform_set_drvdata()`, and downcast `drvdata` (`struct dwc3 *`) via `to_dwc3_qcom()`. [F423, F475]
- In `qcom_geni_serial.c`, guard `qcom_geni_serial_port_setup()` with `if (!port->setup)`, only issue `UART_START_READ` in `poll_init()` when `!qcom_geni_serial_secondary_active(uport)`, and map `UART_PM_STATE_UNDEFINED` to `UART_PM_STATE_OFF` in `qcom_geni_serial_pm()`. In `wled3/4/5_set_brightness()`, pass `__le16` (`cpu_to_le16()`) with `val_count = 2` to `regmap_bulk_write()`. In `qcom_wdt_probe()`, reject `rate == 0 || rate > data->max_tick_count`, and if `qcom_wdt_is_running()`, call `qcom_wdt_start()` and set `WDOG_HW_RUNNING`. `qcom_wdt_restart()` must use `wmb()` and `mdelay()`. [F368, F428, F466, F472, F476]

## Error Handling

- In `ufs-qcom.c`, check `ufshcd_get_variant(hba)` for `NULL` in `ufs_qcom_setup_clocks()`; jump to `out_variant_clear` on error after `ufshcd_set_variant(hba, host)` in `ufs_qcom_init()`; call `ufshcd_uic_hibern8_exit(hba)` on error after `ufshcd_uic_hibern8_enter(hba)` in `ufs_qcom_clk_scale_notify()`; and in `ufs_qcom_ice_init()` treat `ERR_PTR(-EOPNOTSUPP)` or `NULL` from `devm_of_qcom_ice_get()` as `0` (no `UFSHCD_CAP_CRYPTO`). [F316, F343, F344, F345]
- In `dwc3-qcom.c`, roll back `icc_path_ddr` if `icc_path_apps` fails in `dwc3_qcom_interconnect_enable/disable()`; check `platform_get_resource()` and `devm_ioremap()` for `NULL` and set negative `ret` before `goto clk_disable`; and keep `*_phy_irq` as `0` unless `irq > 0` and `dwc3_qcom_request_irq()` succeeds. Check `devm_kasprintf()` for `NULL` (`-ENOMEM`), ignore `-ENODEV` from `devm_pm_opp_of_add_table()` in `msm_serial` / `qcom_geni_serial`, and use `dev_err_ratelimited()` in `handle_rx_uart()` and `qcom_geni_serial_stop_tx_dma()`. [F318, F350, F351, F352, F360, F477]

## External Contracts

- `qcom,dispcc-sm8150.h` and `qcom,dispcc-sm8350.h` symlink to `include/dt-bindings/clock/qcom,dispcc-sm8250.h`; do not renumber or remove existing IDs. In `ufs-qcom.c`, skip `devm_phy_get()` and `devm_clk_bulk_get_all()` when `has_acpi_companion(dev)` is true. [F398, F443]

## Known Pitfalls

- For 32-bit UART FIFO registers (`UARTDM_RF/TF`, `MSM_UART_TF`, `SE_GENI_RX/TX_FIFOn`), pass a `>= 4`-byte buffer (zero-initialized on partial TX writes) and `count = 1` word to `ioread32_rep()` / `iowrite32_rep()`. In `__qcom_geni_serial_console_write()`, right-shift partial `write_cached_bytes` by `BITS_PER_BYTE * (BYTES_PER_FIFO_WORD - write_cached_bytes_cnt)` before writing `SE_GENI_TX_FIFOn`. [F358, F384, F425]
- In `qcom_geni_serial.c`, when reading `SE_GENI_RX_FIFO_STATUS`, check `word_cnt` non-zero before `word_cnt - 1` and treat `RX_LAST_BYTE_VALID == 0` on `RX_LAST` as `BYTES_PER_FIFO_WORD` (4). Round `timeout_us` via `DIV_ROUND_UP(timeout_us, 10) * 10` and use `udelay()` in `qcom_geni_serial_poll_bitfield()`. In `qcom_geni_serial_set_termios()`, clear `UART_CTS_MASK` when `CRTSCTS` is set and set it when clear. [F402, F405, F419]
- In `__msm_console_write()`, declare `bool replaced = false` outside `while (i < count)` and advance `s` only when `j < num_chars` after `'\r'` insertion. In `msm_start_rx_dma()` (on fallback) and `msm_complete_tx_dma()` (on `UARTDM > 1p3`), reset and re-enable RX/TX via `MSM_UART_CR` after clearing `UARTDM_DMEN`. [F399, F447]
- In `ufs-qcom.c`, keep the `switch (cycles_in_1us)` table in `ufs_qcom_set_clk_40ns_cycles()` (`403 MHz` -> `16`), and flush writes to `REG_UFS_CFG1`, `REG_UFS_CFG2`, `REG_UFS_SYS1CLK_1US`, and `dev_ref_clk_ctrl_mmio` with a readback. Use `disable_irq_nosync(irq)` in `dwc3_qcom_disable_wakeup_irq()`. [F414, F445, F463]
- In `qcom-wled.c`, index per-string registers/bits by `j = wled->cfg.enabled_strings[i]`, not `i`; in `wled_auto_string_detection()`, shift 0-based `j` for `WLED4_SINK_REG_CURR_SINK` but write `j + 1` to `WLED3_CTRL_REG_FEEDBACK_CONTROL`. Keep `if (c == val) break;` inside `for (j = 0; c != val; j++)` in `wled_configure()`, and unlock `WLED4_CTRL_REG_SEC_ACCESS` (`0xa5`) before writing `WLED4_CTRL_REG_TEST1` in `wled4_setup()`. [F396, F410, F411, F448]
