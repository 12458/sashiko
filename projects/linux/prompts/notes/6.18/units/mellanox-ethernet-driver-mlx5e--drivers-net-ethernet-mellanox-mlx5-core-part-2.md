# MELLANOX ETHERNET DRIVER (mlx5e) — drivers/net/ethernet/mellanox/mlx5/core (part 2)

This component implements E-Switch representors (`en_rep.c`, `en_rep.h`), RX datapath (`en_rx.c`: CQE decompression, `page_pool`, MPWRQ, SHAMPO, LRO, XDP, AF_XDP), TC offloading (`en_tc.c`, `en_tc.h`), stats (`en_stats.c`, `en_stats.h`), and self-tests (`en_selftest.c`).

## Architecture & Data Flow

- `struct mlx5_flow_attr` ends with a flexible union (`esw_attr` for FDB, `nic_attr` otherwise): allocate via `mlx5_alloc_flow_attr(ns)`, copy `ns_to_attr_sz(ns)` (`ESW_FLOW_ATTR_SZ`/`NIC_FLOW_ATTR_SZ`) bytes rather than `sizeof(*attr)`, and guard union access with `mlx5e_is_eswitch_flow(flow)` or `ns_type == MLX5_FLOW_NAMESPACE_FDB` [F47, F128].
- Shared NIC/switchdev helpers must check mode first: `priv->ppriv` (`mlx5e_rep_priv`) is `NULL` on NIC netdevs (`mlx5e_is_uplink_rep`, `get_tc_ht`, `is_flow_rule_duplicate_allowed` must check `rpriv` or ESW flags), TC helpers (`mlx5e_tc_action_miss_mapping_get/put`, `mlx5e_get_priv_obj_mapping`, `get_ct_priv`, `get_post_action`, `get_act_stats_handle`) must check `is_mdev_switchdev_mode(priv->mdev)` before accessing `esw->offloads` or uplink priv, and callers of `netdev_priv(ndev)` on arbitrary netdevs (`mlx5e_eswitch_{uplink_,vf_,}rep`, `mlx5e_tc_netdev_event`) must verify `ndev->netdev_ops` is `&mlx5e_netdev_ops` (uplink rep) or `&mlx5e_netdev_ops_rep` (VF rep) [F48, F139, F140, F185].
- When `parse_tc_actions` splits a post-action `mlx5_flow_attr` at index `i`, run `mlx5e_tc_act_post_parse` for `[i_split, i]`, clone `flow->attr` via `mlx5e_clone_flow_attr_for_post_act` (allocating fresh `parse_attr` and resetting per-stage action, `dest_chain`, `dest_ft`, `out_count`, `split_count`, counter, cookie, CT, and branch fields), set `i_split = i + 1` and `parse_state->if_count = 0`, and prepend via `list_add` to `flow->attrs`; post_act offload/unoffload/free loops must stop at `list_is_last(&attr->list, &flow->attrs)` [F86, F87, F109].
- In `post_process_attr`, call `mlx5e_tc_tun_encap_dests_set` only if `mlx5e_is_eswitch_flow(flow) && has_encap_dests(attr)`; `extra_split_attr_dests_needed` and `post_process_attr` must check static `MLX5_ESW_DEST_ENCAP` and finish initializing `extra_split_attr`, mod-hdr handles, and counters even if `mlx5e_tc_tun_encap_dests_set` sets `SLOW` [F35, F105].
- In `offload_pedit_fields`, `mask_field_get`, and `mask_field_clear`, access network-byte-order `pedit_headers` with width-matched conversions (`f->field_bsize`), clearing every matched SET/ADD mask via `mask_field_clear` (even no-ops) for `verify_offload_pedit_fields`; in `actions_prepare_mod_hdr_actions`, if `mod_hdr_acts.num_actions == 0`, clear `MLX5_FLOW_CONTEXT_ACTION_MOD_HDR`, deallocate `mod_hdr_acts`, and (on FDB without VLAN pop/push) reset `esw_attr->split_count = 0` [F84, F85, F90].
- Each `mlx5e_tc_attr_to_reg_mappings` entry requires `1 <= mlen <= 32` and `moffset + mlen <= 32`; never call `mlx5e_tc_match_to_reg_{,get_}match` on types without `.soffset` (`MAPPED_OBJ_TO_REG`, `VPORT_TO_REG`), and pass unshifted `val`/`mask` bounded by `GENMASK(mlen - 1, 0)` so `mlx5e_tc_match_to_reg_match` masks `max_mask << moffset`, ORs shifted `mask`/`val`, and sets `MLX5_MATCH_MISC_PARAMETERS_2` [F82, F122, F136].
- In `__parse_cls_flower`, if `parse_tunnel_attr` sets `match_inner = true`, switch `match_level`, `headers_c`, and `headers_v` to inner headers before L2/L3/L4 parsing; in `enc_opts_is_dont_care_or_full_match`, once `*dont_care` is `false`, keep `if (!(*dont_care) || ...)` sticky across the loop; in `mlx5e_get_flow_tunnel_id`, `memset` stack `tunnel_match_key` and `tunnel_match_enc_opts` to 0 before `mapping_add` [F59, F83, F113].
- In `mlx5e_add_offloaded_nic_rule`, check `attr->dest_ft`, `nic_attr->hairpin_ft`, and `nic_attr->hairpin_tirn` before `MLX5_FLOW_CONTEXT_ACTION_FWD_DEST`; in `mlx5e_set_fwd_to_int_port_actions`, set `esw_attr->split_count = out_index` and `attr->dest_chain = 0`; in `dec_jump_count`, only decrement `jump_count` when `(act->id, act->hw_index)` changes [F88, F110, F111].
- MPWQE/UMR setup: `mlx5e_alloc_rx_mpwqe` must zero `wi->skip_release_bitmap`, set `wi->consumed_strides = 0`, and zero alignment-padded `umr_wqe->inline_mtts` (`MLX5_UMR_MTT_NUM_ENTRIES_ALIGNMENT`), while `build_ksm_umr` zeros the UMR header up to `inline_ksms`; `mlx5e_dealloc_rx_mpwqe` and `err_unmap` must call `bitmap_fill(wi->skip_release_bitmap, rq->mpwqe.pages_per_wqe)` after releasing pages [F57, F69].
- In `mlx5e_alloc_rx_mpwqe` and `mlx5e_build_shampo_hd_umr`, set `sq->doorbell_cseg = &umr_wqe->hdr.ctrl`, and in `mlx5e_post_rx_mpwqes`, drain `umr_completed` via `mlx5e_post_rx_mpwqe`, subtract it from `umr_in_progress`, and reset it to 0 before computing `missing`, then ring `icosq` (`mlx5e_notify_hw`) and clear `sq->doorbell_cseg = NULL`; in `mlx5e_post_rx_wqes`, subtract `(head + wqe_bulk) & rq->wqe.info.wqe_index_mask` from `wqe_bulk` [F66, F92, F158].
- In `mlx5e_handle_rx_cqe_mpwrq{_shampo}`, add `cstrides` to `wi->consumed_strides` up front and route all early exits to `mpwrq_cqe_out` (and `free_hd_entry` if `head_size != 0`) for `mlx5_wq_ll_pop`; set `rq->hw_gro_data->skb = NULL` whenever passed to `napi_gro_receive` or dropped, and in `mlx5e_poll_rx_cq` when `work_done > 0`, call `mlx5e_shampo_flush_skb(rq, NULL, false)` and (if `rq->xdp_prog`) `mlx5e_xdp_rx_poll_complete(rq)` [F67, F118, F177].
- Clear `rss_hash_type`/`rss_hash_result` in `mlx5e_decompress_cqe_no_hash`; return `budget_rem` without popping if `left > budget_rem` in `mlx5e_decompress_enhanced_cqe`; invert `op_own` on CQ wrap in `mlx5e_cqes_update_owner`; recompute `rx_headroom`, `metasize`, and `cqe_bcnt` from `mxbuf->xdp` on `XDP_PASS` in `mlx5e_skb_from_cqe_{,mpwrq_}linear`; increment `&priv->channel_stats[rq->ix]->rq` (not parent `rq->stats`) in `mlx5i_complete_rx_cqe` [F71, F72, F73, F93, F117].
- NULL-check `priv->channels.ptp` in `mlx5e_stats_ts_get` and `mlx5e_add_sqs_fwd_rules` even when `tx_ptp_opened` or `MLX5E_PFLAG_TX_PORT_TS` is set; in `mlx5e_add_sqs_fwd_rules`, size `sqs` with `sqs_per_channel = mlx5e_get_dcb_num_tc(&priv->channels.params) + (is_uplink_rep ? 2 : 0)` across `priv->channels.num + ptp_sq` channels, passing `num_sqs` to `mlx5e_sqs2vport_start`; in `mlx5e_build_rep_params`, call `mlx5e_set_xdp_feature` after `mlx5e_build_rq_params` (under `rtnl_lock` if `NETREG_REGISTERED`) [F51, F80, F133].
- `mlx5e_stats_update{_ndo_stats}` iterate `stats_grps` in reverse while `mlx5e_stats_fill{_strings}` iterate forward; new `mlx5e_sw_stats` fields require aggregation in `mlx5e_stats_grp_sw_update_stats` and entries in `sw_stats_desc[]`; VF representor stats use `mlx5e_stats_copy_rep_stats` from `priv->stats.rep_stats`; `fec_rs_histogram_fill_ranges` must bound `num_of_bins` to `MLX5_RS_HISTOGRAM_ENTRIES`; skipped tests in `mlx5e_self_test{_fill_strings}` must not advance `count`; `mlx5e_test_loopback_setup`/`cleanup` must only toggle hardware loopback when `!lbtp->local_lb` and refresh TIRs (`enable_uc_lb` `true`/`false`) [F74, F79, F81, F99, F115, F116].

## Synchronization

- `tc_ht` lookups require `rcu_read_lock()` and `mlx5e_flow_get` inside RCU to use `flow` after unlock; `mlx5e_delete_flower` must lookup `flow`, set `flow_flag_test_and_set(flow, DELETED)`, and call `rhashtable_remove_fast` in one `rcu_read_lock()` section before `mlx5e_flow_put` [F29, F165].
- Hairpin table (`tc->hairpin_tbl_lock`): in `mlx5e_hairpin_flow_add`, init `flows_lock`, `flows`, `dead_peer_wait_list`, `refcnt` (1), and `res_ready` before inserting `hpe` and unlocking, and call `complete_all(&hpe->res_ready)` after setting `hpe->hp`; lookups, `mlx5e_tc_hairpin_update_dead_peer` (pinning under lock and dropping before waiting/putting), and `mlx5e_hairpin_put` (`refcount_dec_and_mutex_lock` and unlinking `hairpin_hlist` before unlock) must wait on `res_ready` and check `!IS_ERR_OR_NULL(hpe->hp)` [F16, F23, F33, F53, F148].
- Signal `complete_all(&flow->init_done)` after `mlx5e_tc_add_fdb_flow` in `__mlx5e_add_fdb_flow` (even on error) and `complete_all(&flow->del_hw_done)` in `mlx5e_tc_del_fdb_flow`; hold `unready_flows_lock` in `unready_flow_add`/`del`; hold `tc->t_lock` for `tc->t` in `mlx5e_add_offloaded_nic_rule`/`mlx5e_tc_del_nic_flow`; set `tc_ht_lock_key` and `tc_ht_wq_key` on TC `rhashtable` init; use `mlx5_devcom_for_each_peer_entry_rcu` under `rcu_read_lock()` in `mlx5e_tc_query_route_vport` [F24, F31, F34, F89, F162].
- Lock `rtnl_lock()` before `netdev_lock(netdev)` in `mlx5e_uplink_rep_enable`/`disable`; use `dma_wmb()` before `mlx5_wq_{ll,cyc}_update_db_record` and `wmb()` after `mlx5_cqwq_update_db_record`; read `htb_max_qos_sqs` with `smp_load_acquire` and `htb_qos_sq_stats[i]` with `READ_ONCE`; init `lbtp` before `dev_add_pack` and `dev_remove_pack` before freeing `lbtp` [F25, F39, F156, F160].

## Object Lifetimes

- `page_pool` fragments (`mlx5e_page_alloc/release_fragmented`) bias by `MLX5E_PAGECNT_BIAS_MAX` and unref by `MLX5E_PAGECNT_BIAS_MAX - frag_page->frags`: increment `frag_page->frags` on every SKB frag attach and XDP xmit (clearing `MLX5E_RQ_FLAG_XDP_XMIT` via `__test_and_clear_bit`); release `wi->linear_page` on all `if (prog)` exits in `mlx5e_skb_from_cqe_mpwrq_nonlinear`; free XSK RX WQEs via `xsk_buff_free()`; keep SHAMPO `ksm_entries` aligned to `MLX5E_SHAMPO_WQ_HEADER_PER_PAGE` and call `mlx5e_shampo_fill_umr` for `[shampo->ci, shampo->pi)` before `mlx5e_shampo_dealloc_hd` [F1, F4, F5, F6, F176, F180].
- Representor ordering: `mlx5e_rep_neigh_init` runs before `mlx5e_init_uplink_rep_tx`/`mlx5e_tc_ht_init` and `mlx5e_rep_neigh_cleanup` after their cleanups; `cancel_work_sync(&rpriv->uplink_priv.mpesw_work)` precedes `mlx5e_cleanup_rep_rx`; `mlx5_esw_offloads_devcom_init` runs last in `mlx5e_tc_esw_init` and `devcom_cleanup` first in cleanup; in `mlx5e_vport_uplink_rep_unload` (non-legacy), `unregister_netdev` precedes `mlx5e_netdev_attach_nic_profile`; VF unload order is `unregister_netdev`, `vnic_reporter_destroy`, `detach_netdev`, `profile->cleanup`, `destroy_netdev`, `kvfree(ppriv)`; only destroy `rpriv->root_ft` if `rep->vport == MLX5_VPORT_UPLINK`; `rep_vport_rx_rule_destroy` must zero `rpriv->vport_rx_rule` [F9, F10, F11, F12, F27, F145, F146].
- TC lifetimes: in `mlx5e_configure_flower`, always release `mlx5_esw_hold` (`mlx5_esw_release`), and undo `mlx5e_tc_block_ipsec_offload` and `mlx5_esw_get` on error/duplicate and in `mlx5e_delete_flower`; pair `mlx5_chains_get_table` with `mlx5_chains_put_table`; call `mlx5_geneve_tlv_option_del` before freeing `spec` if `mlx5_flow_has_geneve_opt(spec)`; unlink `peer_flow->peer_flows` unconditionally before `refcount_dec_and_test` in `mlx5e_tc_del_fdb_peer_flow`; never cache pointers across `mlx5e_mod_hdr_alloc` and increment `mod_hdr_acts->num_actions` after each call [F17, F20, F21, F106, F137].

## API Contracts

- Return conventions: `mlx5e_tc_table_alloc()` (`CONFIG_MLX5_CLS_ACT`), `mlx5e_flow_get()`, and `mlx5_esw_offloads_devlink_port()` return `ERR_PTR` (check `IS_ERR()`); `mlx5e_tc_match_to_reg_set_and_get_id()` returns `>= 0` on success (check `< 0`); `mlx5e_build_rx_skb()`, `mlx5e_complete_rx_cqe()`, and `mlx5e_shampo_complete_rx_cqe()` return `true` when dropped/consumed; `mlx5i_complete_rx_cqe()` sets `skb->dev = NULL` on drop (free in `mlx5i_handle_rx_cqe()`); `mlx5e_tc_update_skb` returns a ref in `tc_priv->fwd_dev` (even if `skb_done`) requiring `dev_put` [F22, F41, F42, F43, F44, F45, F46].
- Hardware/driver contracts: `set_action_in.length == 0` encodes 32 bits; `mlx5_core_query_vport_counter(dev, 1, vf, ...)` takes `rep->vport - 1` while `mlx5e_rep_query_aggr_q_counter` takes `rep->vport` and requires `q_counter_other_vport` and `q_counter_aggregation` caps; check `MLX5_CAP_GEN(..., hairpin)` on both `priv->mdev` and `peer_mdev`, and size hairpin indirect RQT with `hp->num_channels`; `mlx5e_cond_loopback` rejects switchdev and `mlx5_get_sd(priv->mdev)`; `mlx5e_copy_skb_header` requires `ALIGN(headlen, sizeof(long))` allocation; RX `dma_sync_single*_for_cpu` must use `rq->buff.map_dir`; `stats_grp` `fill_strings`/`fill_stats` must match `get_num_stats` [F60, F62, F63, F131, F135, F149, F151, F154, F167].

## Error Handling

- `tc->post_act` / `uplink_priv->post_act` (`get_post_action()`), `tc->t`, and `flow->rule[0]` store `ERR_PTR`s on failure (check `IS_ERR()` / `!IS_ERR_OR_NULL()`); `mlx5_uplink_netdev_get()` and `rpriv->netdev` can be `NULL` when unbound (NULL-check before `netdev_priv`); in `mlx5e_sqs2vport_start`, clean up `rep_sq` if `mlx5e_sqs2vport_add_peers_rules` fails before `goto out_err`; in `mlx5e_refill_rx_wqes` (`err_free`), free `total_alloc + refill_alloc` WQEs and set `BIT(MLX5E_WQE_FRAG_SKIP_RELEASE)` on `total_alloc + refill` WQEs; set `err` before `goto` when `err` was 0 or reused; report unsupported user TC rules via `NL_SET_ERR_MSG_MOD` without `WARN_ON` [F13, F49, F50, F54, F55, F119, F193].

## External Contracts

- RX LRO/csum/devmem: verify `network_depth + sizeof(ip/ipv6 hdr)` via `is_last_ethertype_ip` (`pskb_may_pull`) before dereferencing in `mlx5e_handle_csum`/`mlx5e_enable_ecn`, and call `mlx5e_skb_csum_fixup` for `CHECKSUM_COMPLETE` without `MLX5E_RQ_STATE_CSUM_FULL`; for `lro_num_seg > 1`, set `gso_size = DIV_ROUND_UP(cqe_bcnt - hdrlen, lro_num_seg)` and `gso_segs = lro_num_seg`, and recompute `tcp->check` (`csum_partial` + `tcp_v4/v6_check`) in `mlx5e_lro_update_hdr`; in `mlx5e_handle_rx_cqe_mpwrq_shampo`, drop when `head_size == 0` and `netmem_is_net_iov(frag_page->netmem)`; `dev_queue_xmit` consumes `skb` in `mlx5e_test_loopback`, and `mlx5e_test_loopback_validate` must `skb_linearize`, check `skb_headlen`, compute UDP offset from `(u8 *)iph + 4 * iph->ihl`, and `kfree_skb`; flip vport counters (`vport_rx_*` from `transmitted_*`) in `mlx5e_stats_grp_vport_rep_update_stats`; scope NIC TC netdev lookups and notifier to `dev_net` [F14, F97, F171, F172, F173, F179, F181, F184, F191].

## Known Pitfalls

- `mlx5e_build_linear_skb` resets `sinfo->nr_frags = 0`, so pass `wi - head_wi - 1` or `frag_page - head_page` to `xdp_update_skb_frags_info`, and iterate fragments in `[head_wi, wi)`; add `ETH_HLEN` to `fk.control.thoff` when indexing `mlx5e_shampo_get_packet_hd()` but not `skb->data`; split `num_wqe` across `entries_before` wrap in `mlx5e_alloc_rx_hd_mpwqe`; keep `sqcc` as `u16` compared with `!=`/`==` in `mlx5e_free_icosq_descs`/`mlx5e_poll_ico_cq`; use `BIT_ULL()` for `dissector->used_keys`; use `do_div(rate, 1000000)` and `max_t(u32, rate, 1)` in `apply_police_params`; copy narrow bitmasks to `unsigned long` before `find_first_bit`/`for_each_set_bit`; match `counter_desc.offset` with `MLX5E_READ_CTR{64,32}_{CPU,BE}`; check `snprintf` truncation with `count >= sizeof(drvinfo->fw_version)` in `mlx5e_rep_get_drvinfo` [F70, F91, F121, F124, F126, F127, F134, F138, F141, F142].
