# NETFILTER — net/netfilter (part 7)

Implements `nf_tables` expressions and stateful objects (`nft_last` through `nft_xfrm`), the four set backends (`nft_set_bitmap.c`, `nft_set_hash.c`, `nft_set_pipapo.c` with AVX2 in `nft_set_pipapo_avx2.c`, `nft_set_rbtree.c`), and Netfilter checksum/routing utilities (`utils.c`).

## Architecture & Data Flow
- Every set element struct (`nft_bitmap_elem`, `nft_rhash_elem`, `nft_hash_elem`, `nft_rbtree_elem`, `nft_pipapo_elem`) must put `struct nft_elem_priv priv` at offset 0 and `struct nft_set_ext ext` last, with `ops.elemsize = offsetof(..., ext)`. Under `CONFIG_MITIGATION_RETPOLINE`, `__nft_set_do_lookup()` dispatches every registered `nft_set_type.ops` before `WARN_ON_ONCE(1)`, so new set backends must be added there. [F205, F264]
- Dataplane `nft_pipapo_lookup()` and `nft_pipapo_avx2_lookup()` on `priv->match` must pass `0` as `genmask` to `pipapo_get_slow()` / `pipapo_get_avx2()`, since new-generation entries live only in `priv->clone` until `nft_pipapo_commit()`. [F182]
- Before multi-field PIPAPO lookups, `pipapo_resmap_init()` must set `res_map[0 .. m->f->bsize - 1]` to `ULONG_MAX` and zero `res_map[m->f->bsize .. m->bsize_max - 1]` (which `pipapo_resmap_init_avx2()` must also zero). In `pipapo_refill()`, when `!match_only`, clear every scanned `map[k]` to `0` (even before returning `-1` on `i >= rules`) so swapped `res_map`/`fill_map` bitmaps stay zeroed. [F164, F234]
- `union nft_pipapo_map_bucket` in `f->mt` stores `{ .to, .n }` rule ranges on intermediate fields (`i < m->field_count - 1`) and `struct nft_pipapo_elem *e` only on the last field. In `pipapo_drop()`, deleting rules requires `bitmap_cut()` on `f->lt`, `pipapo_unmap()` on `f->mt` (subtracting `rulemap[i + 1].n` from `mt[].to` only when `!is_last`), and decrementing `f->rules`. In `nft_pipapo_remove()`, after `pipapo_match_field()`, the last field must also verify `f->mt[rulemap[i].to].e == e` before `pipapo_drop()`. [F166, F187, F227]
- In `nft_pipapo_insert()`, if any `f->bsize > m->bsize_max` or `!m->scratch`, `pipapo_realloc_scratch(m, bsize_max)` must succeed before updating `m->bsize_max`; it allocates `struct_size(scratch, __map, bsize_max * 2) + NFT_PIPAPO_ALIGN_HEADROOM` and stores the unaligned pointer for `pipapo_free_scratch()`, so lookups must align `&scratch->__map[0]` via `NFT_PIPAPO_LT_ALIGN()`. `pipapo_resize()` must round `DIV_ROUND_UP(rules, BITS_PER_LONG)` up to `NFT_PIPAPO_ALIGN / sizeof(*new_lt)`. Key pointers stepping across concatenated fields must advance by `NFT_PIPAPO_GROUPS_PADDED_SIZE(f)`. [F188, F245, F256, F260]
- In `nft_set_rbtree.c`, expiring a start element in `nft_rbtree_gc_elem()` or `nft_rbtree_gc()` must also deactivate and erase its preceding `NFT_SET_ELEM_INTERVAL_END` node (using `NFT_GENMASK_ANY` in `nft_rbtree_gc_elem()`). In `__nft_rbtree_lookup()`, on `d < 0`, update `interval = rbe` only if `nft_set_elem_active(&rbe->ext, genmask)`, `!nft_rbtree_elem_expired(rbe)`, and `rbe` is not an interval-end sharing the key of an already recorded start `interval`. In `__nft_rbtree_insert()`, on `d == 0 && !nft_rbtree_interval_end(rbe)` with a key-equal `rbe_ge`, update `rbe_ge = rbe` only if `rbe_ge` and `new` share start/end polarity. [F189, F224, F230]
- In `nft_rhash_expr_needs_gc_run()`, `expr->ops->gc()` triggers GC only when `set->flags & NFT_SET_EVAL` is set. In `nft_rhash_walk_update()`, set `set->in_update_walk = true` during `walk_list` iteration (rejecting recursion with `-EMLINK`) and call `init_llist_node(&he->walk_node)` on every dequeued element even after `iter->err` is set. [F192, F225]
- `nft_bitmap_estimate()` must reject `desc->klen > 2`, and `nft_bitmap_location()` shifts `k <<= 1` for 2 generation bits per key. All control-plane mutations (`nft_bitmap_insert`, `remove`, `activate`, `deactivate`, `flush`) must update `(genmask << off)` in `priv->bitmap[idx]` in lockstep with `priv->list` and `be->ext`. [F193, F216]
- In `nft_payload_eval()` and `nft_payload_inner_eval()`, zero `dest[priv->len / NFT_REG32_SIZE]` when `priv->len % NFT_REG32_SIZE != 0` before copying. String writes in `nft_meta_get_eval_kind()`, `nft_meta_store_ifname()`, and `nft_osf_eval()` must use `strscpy_pad()` with `IFNAMSIZ` or `NFT_OSF_MAXGENRELEN`. When `skb_vlan_tag_present(skb)` and `NFT_PAYLOAD_LL_HEADER` reads/writes past `offsetof(struct ethhdr, h_proto)`, use `nft_payload_copy_vlan()` / `nft_payload_set_vlan()` (clamping `ethlen` to `VLAN_ETH_HLEN - offset` and adjusting offsets by `VLAN_HLEN`). [F175, F210, F211, F296]
- In `nft_payload_set_eval()`, check `offset + priv->len <= skb->len` before `skb_checksum()`; compute `fsum` before `skb_store_bits()` for inet/L4 checksums, but call `nft_payload_csum_sctp()` after `skb_store_bits()`. `nft_payload_l4csum_offset()` on `IPPROTO_UDP` must return `-1` if `!nft_payload_udp_checksum()` before falling through to `IPPROTO_UDPLITE`. In `nft_payload_l4csum_update()`, when `skb->ip_summed == CHECKSUM_COMPLETE`, update `skb->csum = ~csum_add(csum_sub(~(skb->csum), fsum), tsum)` alongside `nft_csum_replace()`. [F198, F208, F240, F297]
- `nft_payload_set_reduce()` and `nft_meta_set_reduce()` must call `__nft_reg_track_cancel(track, i)` for tracked `nft_payload_ops`/`nft_payload_fast_ops` or `nft_meta_get_ops` registers. In `nft_nat_init()`, `nft_masq_init()`, and `nft_redir_init()`, default `sreg_*_max = sreg_*_min` when `sreg_*_min != 0` and `*_MAX` is omitted. In `nft_socket_eval()`, `nft_meta_get_eval_skugid()`, and `nft_meta_get_eval_cgroup()`, reject `skb->sk` if `!net_eq(nft_net(pkt), sock_net(sk))`. [F178, F200, F299]
- In `nft_tunnel_obj_opts_init()`, `type` prevents mixing option types in `opts->u` (`0` for VXLAN/ERSPAN, `0` or `IP_TUNNEL_GENEVE_OPT_BIT` for GENEVE); `nft_tunnel_opts_geneve_policy[NFTA_TUNNEL_KEY_GENEVE_DATA].len` must be at most 127, and `nft_tunnel_obj_geneve_init()` must check `data_len % 4 == 0` and `opts->len <= IP_TUNNEL_OPTS_MAX`. [F212, F237]
- `nft_quota_do_init()` must reject `quota > S64_MAX` (`-EOVERFLOW`) and `consumed > quota` (`-EINVAL`); in `nft_quota_do_dump()` with `reset`, pair `atomic64_sub()` with `clear_bit(NFT_QUOTA_DEPLETED_BIT, &priv->flags)` after `nla_put_*`. `nft_limit_init()` must reject `priv->rate == 0` (`-EINVAL`). `nft_ng_inc_init()` and `nft_ng_random_init()` must reject `modulus == 0` (`-ERANGE`) and `offset + modulus - 1 < offset` (`-EOVERFLOW`), with `counter = modulus - 1` in `nft_ng_inc_init()`. `nft_xfrm_get_init()` must reject `spnum >= XFRM_MAX_DEPTH` (`-ERANGE`) and `nft_xfrm_get_eval_in()` must check `sp && sp->len > priv->spnum`. `nft_reject_init()` must reject `icmp_code > NFT_REJECT_ICMPX_MAX` when `type == NFT_REJECT_ICMPX_UNREACH`. [F203, F215, F219, F221, F222, F242]

## Synchronization
- In `nft_set_do_lookup()`, sample `base_seq = nft_base_seq(net)` inside the `do { ... } while` loop before `__nft_set_do_lookup()` and retry on `NULL` while `nft_lookup_should_retry(net, base_seq)`. [F238]
- Callers of `pipapo_get_avx2()` must call `local_bh_disable()` and verify `irq_fpu_usable()`. Every exit from `pipapo_get_slow()` and `pipapo_get_avx2()` after `__local_lock_nested_bh(&scratch->bh_lock)` must save `scratch->map_index = map_index` (if in the field loop), call `kernel_fpu_end()` (in AVX2), and unlock `scratch->bh_lock` (plus `local_bh_enable()` in `pipapo_get_slow()`). [F145, F153]
- PIPAPO control-plane mutations must use `priv->clone` (`pipapo_maybe_clone()`). `nft_pipapo_commit()` publishes it via `rcu_replace_pointer()`, frees `old` via `call_rcu(&old->rcu, pipapo_reclaim_match)`, and sets `priv->clone = NULL` (as must `nft_pipapo_abort()` after `pipapo_free_match(priv->clone)`). [F142, F281]
- In `nft_rhash_gc()`, sample `READ_ONCE(nft_net->gc_seq)` before walking and abort via `nft_trans_gc_destroy(gc)` if it changes; increment `priv->wq_gc_seq` (skipping `0`) and stamp `he->wq_gc_seq = priv->wq_gc_seq` to avoid duplicate queueing on resize; call `nft_trans_gc_catchall_async()` before `rhashtable_walk_stop(&hti)`. `nft_rhash_walk_update()` must collect elements onto `walk_list` under RCU and call `iter->fn` only after `rhashtable_walk_stop()`/`exit()`. `nft_rhash_destroy()` must call `cancel_delayed_work_sync(&priv->gc_work)` before `rhashtable_free_and_destroy()`. [F157, F226, F276, F278]
- In `nft_set_rbtree.c`, mutations to `priv->root` must hold `write_lock_bh(&priv->lock)` and `write_seqcount_begin/end(&priv->count)` (so `nft_rbtree_gc_elem()` must use `GFP_ATOMIC`); lockless readers retry under `read_lock_bh(&priv->lock)` on seqcount conflict. [F160, F279]
- Pass `lockdep_is_held(&nft_pernet(net)->commit_mutex)` to `list_for_each_entry_rcu()` / `hlist_for_each_entry_rcu()` in `nft_bitmap_elem_find()`, `nft_bitmap_walk()`, and `nft_hash_walk()`. Hold `read_lock_bh(&sk->sk_callback_lock)` in `nft_meta_get_eval_skugid()` and `spin_lock_bh(&priv->limit->lock)` in `nft_limit_eval()`. [F275, F285, F286]

## Object Lifetimes
- In `nft_socket_eval()`, every exit after `nft_socket_do_lookup(pkt)` must reach `out_put_sk` and call `sock_gen_put(sk)` when `sk != skb->sk`. [F133]
- In `nft_tunnel_obj_init()`, call `metadata_dst_free(md)` if `dst_cache_init()` fails; in `nft_tunnel_obj_eval()`, call `skb_dst_drop(skb)` and `dst_hold((struct dst_entry *)priv->md)` before `skb_dst_set()`. In `nft_synproxy_do_init()`, if `nf_synproxy_ipv6_init()` fails in `NFPROTO_INET`, call `nf_synproxy_ipv4_fini()` before `nf_ct_netns_put()`. In `nft_secmark_obj_init()`, call `security_secmark_refcount_inc()` only after `nft_secmark_compute_secid()` succeeds, and pair `security_secmark_refcount_dec()` with `kfree(priv->ctx)` in `nft_secmark_obj_destroy()`. [F135, F136, F149]
- In `nft_rhash_update()`, if `rhashtable_lookup_get_insert_key()` returns `IS_ERR(prev)` or `prev != NULL`, call `nft_set_elem_destroy(set, &he->priv, true)` and `atomic_dec(&set->nelems)`. [F137]
- In `pipapo_resize()`, if `pipapo_realloc_mt()` fails, `kvfree(new_lt)` without updating `f->lt` or `f->bsize`, freeing `old_lt` only on success. In `pipapo_clone()`, on failure at field `i`, `out_mt` frees `dst->lt`, `out_lt` frees `dst->mt` and `dst->lt` for `< i`, and `out_scratch_realloc`/`out_scratch` free per-CPU scratch maps, `new->scratch`, and `new`. [F143, F144]
- In `nft_pipapo_destroy()`, when `priv->clone` is non-NULL, call `nft_set_pipapo_match_destroy()` only on `priv->clone` (not `priv->match`), and `pipapo_free_match()` on both. In `nft_pipapo_do_walk()` and `nft_set_pipapo_match_destroy()`, skip `r < f->rules - 1 && f->mt[r + 1].e == f->mt[r].e`. In `pipapo_gc()` and `nft_rbtree_gc()`, check `gc = nft_trans_gc_queue_sync(gc, GFP_KERNEL)` for `NULL` before deactivating/unlinking expired elements and calling `nft_trans_gc_elem_add()`. [F146, F183, F233]
- In `nft_objref_deactivate()`, skip `nft_use_dec(&obj->use)` when `phase == NFT_TRANS_COMMIT`. In `nft_limit_clone()`, `nft_quota_clone()`, and `nft_last_clone()`, allocate new state structs using the passed `gfp` flag (and reset `tokens = priv_src->tokens_max` and `last = ktime_get_ns()` in `nft_limit_clone()`). [F148, F202, F287]

## API Contracts
- Across `nft_set_ops`: `.get()` returns `ERR_PTR(-ENOENT)` on miss while `.lookup()`/`.deactivate()` return `NULL`; `.insert()` returning `-EEXIST` must set `*elem_priv`; `.walk()` must not pre-filter by `nft_set_elem_active()`, `.activate()` must call `nft_clear(net, &ext)`, and `.walk()` callers (`nft_lookup_validate()`) must initialize `iter.type` (`NFT_ITER_READ`/`UPDATE`), `genmask`, `skip`, `count`, `err`, and `fn`; control-plane `.insert`/`.deactivate`/`pipapo_gc`/`nft_rbtree_gc` must expire against `nft_net_tstamp(net)` (`__nft_set_elem_expired()`), while dataplane ops use live jiffies. `nft_set_rbtree_type.ops` must provide `nft_rbtree_ksize`, `usize`, and `adjust_maxsize`. [F169, F171, F172, F191, F194, F195]
- Zero-initialize `left`/`right` before `pipapo_get_boundaries()`; use `memmove()` in `pipapo_unmap()`; pass bit counts (`f->bsize * BITS_PER_LONG`) to `__bitmap_and()`/`bitmap_cut()` and word counts (`f->bsize`) to `pipapo_refill()`. Initialize `*plen` before `nf_ip6_check_hbh_len(skb, plen)`. [F168, F179, F259, F269]
- Leave `.eval = NULL` on `nft_meta_inner_ops` and `nft_payload_inner_ops`. Select `nft_payload_fast_ops` only when `len <= 4`, `is_power_of_2(len)`, `IS_ALIGNED(offset, len)`, and `base` is network/transport header. In `.reduce` callbacks, cast `nft_expr_priv(track->regs[priv->dreg].selector)` only after `nft_reg_track_cmp(track, expr, priv->dreg)`. [F263, F265, F294]
- Call `nft_socket_cgroup_subtree_level()` only in process context (`nft_socket_init()`). `nft_objref_validate_obj_type()` must restrict `NFT_OBJECT_SYNPROXY` to IPv4/IPv6/inet and `LOCAL_IN | FORWARD`. Family-agnostic `.validate` callbacks checking `NF_INET_*` hooks must reject non-IP/inet `ctx->family` with `-EOPNOTSUPP`. Control-plane ruleset allocations must use `GFP_KERNEL_ACCOUNT`. [F284, F289, F290, F304]

## Error Handling
- In PIPAPO, dereference and null-check `*raw_cpu_ptr(m->scratch)` / `*get_cpu_ptr(m->scratch)`. On the last field in `pipapo_get_slow()` and `pipapo_get_avx2()`, if `e` is expired or inactive, `goto next_match` (`pipapo_refill()`). `pipapo_estimate_size()` must check `div_u64(size, desc->size) != entry_size` (and callers reject `est->size == 0`); LT sizes must use `lt_calculate_size()`, and `pipapo_realloc_mt()` / `pipapo_clone()` must bound `rules_alloc <= INT_MAX / sizeof(*new_mt)` with `check_add_overflow()`. [F163, F165, F243, F244, F254]
- Check `IS_ERR(removed_end)` after `nft_rbtree_gc_elem()`, and if `removed_end` equals `rbe_le` or `rbe_ge` in `__nft_rbtree_insert()`, return `-EAGAIN`. [F173, F190]
- `nft_payload_inner_init()` and `nft_meta_inner_init()` must null-check required `tb[]` attributes. `nft_payload_l4csum_update()` must return `0` when `nft_payload_l4csum_offset() < 0` and `-1` on skb helper failure. Check `IS_ERR()` on `cgroup_get_from_path("/")` and store `nft_socket_cgroup_subtree_level()` in a signed `int`. In `nft_log`, guard `kfree(priv->prefix)` with `priv->prefix != nft_log_null_prefix` and skip `nf_logger_put()` for `NFT_LOGLEVEL_AUDIT`. Use `check_mul/add_overflow()` in `nft_limit_init()`. In `nft_queue_init()`, reject `queues_total == 0` (`-EINVAL`) and `(u32)queues_total - 1 + queuenum > U16_MAX` (`-ERANGE`). [F174, F176, F177, F180, F241, F250]

## External Contracts
- Wrap each `struct geneve_opt` in its own `NFTA_TUNNEL_KEY_OPTS_GENEVE` nest in `nft_tunnel_opts_dump()`. `nft_overquota()` checks `consumed > quota`, while depletion reporting and dump clamping (`NFT_QUOTA_F_DEPLETED`) trigger at `consumed >= quota`. In `nft_socket_init()`, save unadjusted `NFTA_SOCKET_LEVEL` in `priv->level_user` for `nft_socket_dump()`. [F213, F214, F302]

## Known Pitfalls
- In `nf_ip6_check_hbh_len()`, refresh `nh` and `ipv6_hdr(skb)` after `pskb_may_pull(skb, off + len)`; advance `off++`/`len--` on `IPV6_TLV_PAD1`, check `len >= 2` and `optlen = nh[off + 1] + 2 <= len` on other TLVs, and for `IPV6_TLV_JUMBO` verify `nh[off + 1] == 4`, `(off & 3) == 2`, `pkt_len > IPV6_MAXPLEN`, `!ipv6_hdr(skb)->payload_len`, and `pkt_len <= skb->len - sizeof(struct ipv6hdr)`. [F196, F207, F236]
- In `pipapo_gc()`, advance `first_rule += rules_f0` only when `e` is not expired (since `pipapo_drop()` shifts rules down). In `nft_pipapo_insert()`, advance temporary `start_p`/`end_p` in the validation loop. Keep scalar fields before `lt` in `struct nft_pipapo_field` for `pipapo_clone()`'s `offsetof(..., lt)` `memcpy`. In `nft_pipapo_avx2_fill()`, evaluate `~0UL >> (BITS_PER_LONG - len)` only when `1 <= len && len <= BITS_PER_LONG`. [F232, F235, F246, F258]
- Widen to `u64` and cap at `NFT_MAX_BUCKETS` in `nft_hash_buckets()` / `nft_hash_privsize()` / `nft_hash_estimate()`. Check `time_before(jiffies, last_jiffies)` in `nft_last_dump()`. Add byte offsets to `opts->u.data` before casting to `struct geneve_opt *` in `nft_tunnel.c`. [F247, F252, F255]
