# DRM DRIVER for Qualcomm display hardware — drivers/gpu/drm/msm/disp/dpu1 (part 1)

This component contains the static SoC hardware catalog definitions (DPU 1.x–12.0), core performance/bandwidth/clock management (`dpu_core_perf`), and the DRM CRTC (`dpu_crtc`) and virtual encoder (`dpu_encoder`) implementations.

## Architecture & Data Flow
- Any non-mode state change altering resource reservation in `dpu_crtc_get_topology()` or `dpu_encoder_update_topology()` (e.g., writeback YUV toggling `num_cdm` or clone mode toggling `cwb_enabled`) must be mirrored in `dpu_encoder_needs_modeset()` and `dpu_crtc_check_mode_changed()` to set `new_crtc_state->mode_changed = true`. In `dpu_crtc_get_topology()`, the `topology.num_intf == 2` branch setting `num_lm = 2` must be guarded with `!topology.cwb_enabled`. [F58, F83]
- In `dpu_crtc_atomic_check()`, when `mode_changed || connectors_changed`, `dpu_crtc_assign_resources()` must populate `cstate->mixers` and `num_mixers` before `_dpu_crtc_check_and_setup_lm_bounds()` computes `cstate->lm_bounds`. Also, because `dpu_crtc_duplicate_state()` uses `kmemdup()`, `dpu_crtc_atomic_check()` must zero `cstate->new_perf` when returning early for `!crtc_state->enable || !drm_atomic_crtc_effectively_active(crtc_state)`. [F48, F57]
- In `dpu_crtc_assign_resources()` and `dpu_encoder_virt_atomic_mode_set()`, `num_ctl` (`DPU_HW_BLK_CTL`) can be smaller than `num_lm` or `dpu_enc->num_phys_encs` (e.g., one CTL driving two mixers/encoders), so `hw_ctl` indexing must clamp to `num_ctl - 1` or `hw_ctl[0]` rather than `hw_ctl[i]`. [F71]
- Optional hardware blocks require `NULL` checks before dereference: `struct dpu_encoder_phys` populates either `hw_intf` or `hw_wb` (never both); `struct dpu_crtc_mixer.hw_dspp` is `NULL` unless `crtc_state->ctm` was set (`_dpu_crtc_setup_cp_blocks()`, `dpu_crtc_atomic_print_state()`); and `struct dpu_plane_state.r_pipe.sspp` is `NULL` for single-SSPP planes (`_dpu_crtc_blend_setup_mixer()`, `_dpu_debugfs_status_show()`). [F40, F41, F42]
- In `dpu_crtc_atomic_begin()`, `dpu_encoder_trigger_kickoff_pending()` must run before `_dpu_crtc_blend_setup()` and `_dpu_crtc_setup_cp_blocks()` stage pending flush bits on CTLs. When clearing blend stages in `_dpu_crtc_blend_setup()` or `dpu_encoder_helper_reset_mixers()`, `set_active_fetch_pipes(ctl, NULL)` and `set_active_pipes(ctl, NULL)` (plus `set_active_lms(ctl, NULL)` on mixer reset) must be called with `clear_all_blendstages`. [F54, F118]
- In `dpu_encoder_prepare_for_kickoff()`, if any physical encoder has `enable_state == DPU_ENC_ERR_NEEDS_HW_RESET`, `dpu_encoder_helper_hw_reset()` must run on all `dpu_enc->phys_encs[i]` in a second pass after `dpu_encoder_resource_control(drm_enc, DPU_ENC_RC_EVENT_KICKOFF)`. [F87]
- `dpu_encoder_helper_phys_cleanup()` must unbind/disable all optional features on shared blocks (`hw_wb`, `hw_intf`, `hw_pp` dither, `hw_cwb`, `merge_3d`, `hw_cdm`, `hw_dsc`) and set `dpu_enc->dsc = NULL` before flushing/starting `ctl`. State cleared in `dpu_encoder_virt_atomic_disable()` or `dpu_encoder_helper_phys_cleanup()` (`connector`, `dsc`, `enabled`) must be re-initialized in `dpu_encoder_virt_atomic_enable()`, not `dpu_encoder_virt_atomic_mode_set()`. [F55, F56]
- In `_dpu_crtc_setup_blend_cfg()`, 16-bit `pstate->base.alpha` is right-shifted by 8 (`max_alpha = 0xff`) for `core_major_ver < 12`, and by 6 (`max_alpha = 0x3ff`) for `core_major_ver >= 12`. In `dpu_encoder_dsc_initial_line_calc()`, use `DIV_ROUND_UP(total_pixels, dsc->slice_width)`. In `_dpu_encoder_calculate_linetime()`, check `pclk_rate != 0` before `DIV_ROUND_UP_ULL(1000000000ull, pclk_rate)`, and check `line_time != 0` in `dpu_encoder_vsync_time()`. [F92, F93, F95]
- In `catalog/dpu_*.h`: block `.name` initializers (`DPU_HW_BLK_INFO`) must be `<= 15` chars (`DPU_HW_BLK_NAME_LEN - 1`); unpopulated 1-based `DPU_IRQ_IDX` `intr_*` fields must be `0` (not `-1`); `struct dpu_perf_cfg` must set non-zero `.max_bw_high` and `.min_prefill_lines`; `struct dpu_pingpong_cfg` must set `.sblk` (and `.intr_rdptr` on DPU < 5.0); DPU >= 5.0 `struct dpu_ctl_cfg` must not set `BIT(DPU_CTL_SPLIT_DISPLAY)`; DPU >= 7.0 `struct dpu_dsc_cfg` must set `.sblk`; and SmartDMA v2 SoCs must use `*_SDMA` SSPP masks. [F66, F104, F107, F108, F109, F110, F111]

## Synchronization
- `dpu_enc->enc_spinlock` is taken in hardirq context (`dpu_encoder_vblank_callback()`) and nests outside `crtc->dev->event_lock` (via `dpu_crtc_vblank_callback()`). Always use `spin_lock_irqsave()`, never acquire it under `event_lock`, hold it when updating/reading `dpu_enc->crtc` (`dpu_encoder_assign_crtc()`, `dpu_encoder_vblank_callback()`), and release it in `dpu_encoder_toggle_vblank_for_crtc()` before calling `phys->ops.control_vblank_irq()` (which takes sleeping `vblank_ctl_lock`). [F25, F130, F131]
- In `_dpu_encoder_kickoff_phys()`, hold `dpu_enc->enc_spinlock` via `spin_lock_irqsave()` across setting `set_bit(i, dpu_enc->frame_busy_mask)` (only for `phys->split_role != ENC_ROLE_SLAVE`), calling `_dpu_encoder_trigger_flush()` (or accumulating `pending_flush` to flush once on `cur_master` when `needs_single_flush(phys)` is true), and calling `_dpu_encoder_trigger_start(dpu_enc->cur_master)`. [F86, F124]
- In `dpu_crtc_commit_kickoff()` and `dpu_crtc_kickoff_clone_mode()`, call `dpu_encoder_start_frame_done_timer()` only after `dpu_encoder_kickoff()` sets `frame_busy_mask`. In `dpu_crtc_kickoff_clone_mode()`, kick off `wb_encoder` before `rt_encoder`, and start `frame_done_timer` on both only after both kickoffs complete. [F18, F81]
- `dpu_enc->enc_lock` protects `dpu_enc->enabled`, `dpu_enc->phys_encs[]`, and physical encoder enable/disable/restore sequences across `dpu_encoder_setup_display()`, `dpu_encoder_virt_atomic_enable()`, `dpu_encoder_virt_atomic_disable()`, `dpu_encoder_virt_runtime_resume()`, and `_dpu_encoder_status_show()`, nesting outside `dpu_enc->rc_lock`. [F28]
- In `dpu_encoder_resource_control()`, call `cancel_delayed_work_sync(&dpu_enc->delayed_off_work)` before acquiring `dpu_enc->rc_lock` (`dpu_encoder_off_work()` takes `rc_lock`). Process-context events (`KICKOFF`, `PRE_STOP`, `STOP`, `ENTER_IDLE`) must hold `rc_lock` across all `rc_state` transitions and resource/IRQ calls (`ENTER_IDLE` must recheck `rc_state == DPU_ENC_RC_STATE_ON` and `frame_busy_mask[0] == 0` under `rc_lock`), while IRQ-context `FRAME_DONE` must not acquire `rc_lock`. [F29, F30, F127]
- Hardirq `dpu_encoder_frame_done_callback()` must zero `frame_done_timeout_ms` before non-blocking `timer_delete(&dpu_enc->frame_done_timer)` (process-context `dpu_encoder_virt_atomic_disable()` uses `timer_delete_sync()` under `enc_lock`). `dpu_encoder_frame_done_timeout()` must verify `frame_busy_mask[0]`, `dpu_enc->crtc`, and `atomic_xchg(&dpu_enc->frame_done_timeout_ms, 0) != 0` before reporting `DPU_ENCODER_FRAME_EVENT_ERROR`. [F32, F134]
- Hardirq/softirq `dpu_crtc_frame_event_cb()` must ignore `DPU_ENCODER_FRAME_EVENT_IDLE` before dequeuing from `dpu_crtc->frame_event_list` under `spin_lock_irqsave(&dpu_crtc->spin_lock, ...)`, and defer `dpu_core_perf_crtc_release_bw()` to `dpu_crtc_frame_event_work()`. Every path in `dpu_crtc_frame_event_work()` must return `fevent` to `frame_event_list` under `dpu_crtc->spin_lock`. [F80, F129]
- `dpu_crtc_atomic_check()` increments `dpu_kms->bandwidth_ref` per active commit (released via `dpu_core_perf_crtc_release_bw()` when `frame_pending` hits 0 or on abort in `dpu_crtc_disable()`), while `dpu_crtc_enable()` / `dpu_crtc_disable()` hold an extra `bandwidth_ref` for `INTF_MODE_VIDEO`. [F33]
- When `dpu_encoder_helper_wait_for_irq()` times out on `wait_info->wq` but sees a pending IRQ via `dpu_core_irq_read()`, wrap `func(phys_enc)` in `local_irq_save()` / `local_irq_restore()`. Callers of `dpu_crtc_get_intf_mode()` must hold `crtc->mutex` and never call it from `atomic_check`. [F133, F137]

## Object Lifetimes
- When moving `crtc->state->event` to `dpu_crtc->event` in `dpu_crtc_atomic_flush()` or sending vblank events in `_dpu_crtc_complete_flip()` and `dpu_crtc_disable()`, clear the source pointer to `NULL` under `dev->event_lock`. [F2]
- Because `dpu_encoder_assign_crtc()` requires `dpu_enc->crtc == NULL` on reassignment and `dpu_encoder_toggle_vblank_for_crtc()` requires `dpu_enc->crtc == crtc`: `dpu_crtc_enable()` skips assignment if `old_crtc_state->self_refresh_active` and otherwise calls `dpu_encoder_assign_crtc(encoder, crtc)` before `drm_crtc_vblank_on(crtc)`; `dpu_crtc_disable()` calls `drm_crtc_vblank_off(crtc)` before `dpu_encoder_assign_crtc(encoder, NULL)`, keeping `dpu_enc->crtc` when entering `self_refresh_active` and clearing it when disabling from `old_crtc_state->self_refresh_active`. [F4, F17]
- `dpu_crtc_assign_resources()` and `dpu_crtc_reassign_planes()` must call `dpu_rm_release(global_state, crtc)` and `dpu_rm_release_all_sspp(global_state, crtc)` before `if (!crtc_state->enable) return 0;`. [F6]
- `_dpu_encoder_resource_enable()` calls `pm_runtime_get_sync()` before `_dpu_encoder_irq_enable()`, and `_dpu_encoder_resource_disable()` calls `_dpu_encoder_irq_disable()` before `pm_runtime_put_sync()`. In `dpu_encoder_resource_control()`, video mode keeps runtime PM active in `IDLE` (`ENTER_IDLE` only disables IRQs), so `KICKOFF` and `PRE_STOP` from `IDLE` in video mode only call `_dpu_encoder_irq_enable()`, and `PRE_STOP` transitions to `PRE_OFF` so `STOP` calls `_dpu_encoder_resource_disable()`. [F8, F9]
- In `dpu_encoder_virt_atomic_mode_set()`, clear unused `dpu_enc->hw_pp[i >= num_pp]` and `dpu_enc->cur_master->hw_cdm` (when unassigned) to `NULL`, and invoke `phys->ops.atomic_mode_set` after assigning `phys->hw_pp` and `phys->hw_ctl` so `phys_enc->irq[]` is populated before async `control_vblank_irq`. [F13, F16]
- In `dpu_crtc_disable()`, `_dpu_crtc_wait_for_frame_done(crtc)` must finish before setting `dpu_crtc->enabled = false`, releasing `frame_pending` references, calling `dpu_core_perf_crtc_update(crtc, 0)`, and calling `pm_runtime_put_sync()`. Under `dpu_enc->enc_lock`, `dpu_encoder_virt_atomic_disable()` must call `dpu_encoder_wait_for_tx_complete()`, send `PRE_STOP`, run `phys->ops.disable()`, drain `frame_done_timer` via `timer_delete_sync()`, and send `STOP`. [F19, F20]
- `dpu_crtc` and `dpu_encoder_virt` are managed via `drmm_crtc_alloc_with_planes()` and `drmm_encoder_alloc()` (no `kfree()` in `.destroy`), whereas `dpu_crtc_state` is freed via `kfree()` in `dpu_crtc_destroy_state()`. `dpu_crtc_set_crc_source()` must balance `drm_crtc_vblank_get()`/`put()` when toggling `DPU_CRTC_CRC_SOURCE_NONE` and synchronize `crc_source` under `crtc->mutex` and `drm_dev->event_lock`. [F125, F139]

## API Contracts
- In `dpu_core_perf_crtc_update()`, update bus BW (`_dpu_core_perf_crtc_update_bus()`) before core clock (`dev_pm_opp_set_rate()`); for enabled CRTCs, only raise votes when `params_changed != 0` (pre-kickoff) and only lower when `params_changed == 0` (post-commit). `bw_ctl` is in bytes/sec while `max_bw_high` and `icc_set_bw()` use kBps (`/ 1000`), and `_dpu_core_perf_crtc_update_bus()` must return early if `!kms->num_paths` before dividing `avg_bw` by `kms->num_paths`. In `dpu_crtc_mode_valid()`, store `dpu_core_perf_adjusted_mode_clk()` in `u64` and multiply by `1000` (kHz to Hz) before comparing to `max_core_clk_rate`. [F34, F90, F91, F140]
- Zero-initialize `struct dpu_core_perf_params perf = { 0 }` before `dpu_core_perf_aggregate()` and `struct msm_display_topology topology = {0}` before `dpu_encoder_update_topology()`, as both accumulate in place. [F44, F47]
- `dpu_rm_get_assigned_resources()` takes `blks_size` as an element count (`ARRAY_SIZE(...)` or `1`, never `sizeof()`), writes only `0 .. num_blks - 1`, and returns `struct dpu_hw_blk *`. Callers must bound reads by the returned count (or init `hw_cdm = NULL`), update `phys->hw_pp`/`hw_ctl` before error returns, and downcast with the matching `to_dpu_hw_*` macro. [F45, F96, F100]
- In `dpu_crtc_atomic_check()` and `dpu_crtc_assign_resources()`, trigger resource reallocation only on `mode_changed || connectors_changed` (ignore `active_changed`) and reserve whenever `crtc_state->enable` is true (ignore `active`). [F136]
- In `dpu_encoder_setup_display()`, `disp_info->h_tile_instance[i]` is a 0-based controller index for `intf_type != INTF_WB`, but a 1-based `enum dpu_wb` ID for `INTF_WB`. Callers of `ctl->ops.set_active_{fetch_pipes,pipes,lms}` must pass `NULL` or a zeroed `DECLARE_BITMAP(..., SSPP_MAX / LM_MAX)`. Debugfs handlers must cast `s->private` / `file->private_data` to the exact type passed to `debugfs_create_file()`. [F53, F101, F105]

## Error Handling
- `dpu_encoder_helper_wait_for_irq()` and `dpu_encoder_wait_for_commit_done()` return `-EWOULDBLOCK` when `DPU_ENC_DISABLED` and `-ETIMEDOUT` on hardware timeout; only invoke timeout recovery or `msm_disp_snapshot_state()` on `ret == -ETIMEDOUT`. Gate `msm_disp_snapshot_state()` to first occurrence (`underrun_cnt == 1`, `frame_done_timeout_cnt == 1`, `!commit_done_timedout`), and use ratelimited logging (`DRM_ERROR_RATELIMITED` / `DPU_ERROR_ENC_RATELIMITED`) in `dpu_crtc_frame_event_cb()` and `dpu_encoder_frame_done_timeout()`. [F36, F143, F144]
- `dpu_encoder_virt_add_phys_encs()` must check `num_phys_encs + NUM_PHYS_ENCODER_TYPES >= ARRAY_SIZE(dpu_enc->phys_encs)` before creating encoders, and check `IS_ERR(enc)` on `dpu_encoder_phys_{wb,cmd,vid}_init()` before storing `enc`, incrementing `num_phys_encs`, or assigning `cur_master`/`cur_slave`. [F43, F75]
- `dpu_crtc_parse_crc_source()` returns `DPU_CRTC_CRC_SOURCE_INVALID` (`-1`), so `enum dpu_crtc_crc_source` must stay signed (`source < 0`). In `dpu_encoder_update_topology()` and `dpu_encoder_needs_modeset()`, check both `drm_atomic_get_new_connector_for_encoder()` and `drm_atomic_get_new_connector_state()` for `NULL`. In `_dpu_crtc_check_and_setup_lm_bounds()`, reject unsplit `adj_mode->hdisplay` (when `!has_3d_merge`) and per-mixer `drm_rect_width(&cstate->lm_bounds[i])` exceeding `max_mixer_width` with `-E2BIG`. In `_dpu_core_perf_mode_write()`, reject `perf_mode >= DPU_PERF_MODE_MAX` with `-EINVAL`. [F37, F38, F68, F73]

## Known Pitfalls
- In `dpu_crtc_disable()`, iterate `old_crtc_state->encoder_mask`, and in `dpu_crtc_vblank()`, iterate `mode_config.encoder_list` (`crtc->state->encoder_mask` is already cleared on disable). In `dpu_crtc_kickoff_clone_mode()`, initialize `rt_encoder = NULL` and `wb_encoder = NULL` before the loop. [F46, F82]
- Test `irq_idx == 0` (not `< 0`) on `unsigned int irq_idx` in `dpu_encoder_helper_wait_for_irq()`. In `dpu_encoder_get_crc()`, index `crcs[pos + entries_added]` (not `pos + i`), and check `rc < 0` in `dpu_crtc_get_encoder_crc()`. [F67, F79]
- Cast the leading operand of `mode->vtotal * mode->hdisplay * drm_mode_vrefresh(mode)` to `u64` in `_dpu_core_perf_calc_clk()`. In `dpu_encoder_vsync_time()`, check `cur_line >= vtotal` before `vtotal - cur_line` on `u32`. [F89, F94]
- Keep `enable_bw_release` and `perf_cfg->{max_bw_low,max_bw_high,min_core_ib,min_llcc_ib,min_dram_ib}` as `u32` (with `0400` debugfs mode on `const` `perf_cfg` fields) for `debugfs_create_u32()`. Format DRM fourcc codes with `%p4cc` or `%4.4s` (never `%s`). Keep `MAX_PHYS_ENCODERS_PER_VIRTUAL <= BITS_PER_LONG` because `frame_busy_mask[0]` is tested directly. [F102, F103, F106]
