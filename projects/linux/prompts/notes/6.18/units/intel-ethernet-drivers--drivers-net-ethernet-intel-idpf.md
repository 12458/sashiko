# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/idpf

This component implements the Intel Infrastructure Data Path Function (idpf) driver, supporting split-queue and single-queue Tx/Rx datapaths, vport lifecycle management, PCI probe/remove, VF register initialization, and IEEE 1588 PTP via BAR registers or Virtchnl2.

## Architecture & Data Flow
- `struct idpf_tx_queue` unions `txq_grp` with `complq` and `{last_re, tx_max_bufs, cleaned_bytes, clean_budget, cleaned_pkts, refillq}` with `{pending, xdp_tx, timer, xdp_lock}`; check `idpf_queue_has(XDP, txq)` first. XDP TX queues `[num_txq - num_xdp_txq, num_txq)` are not registered in `idpf_set_real_num_queues()`; `idpf_tx_start()` must reject them and `idpf_tx_desc_rel()` must skip `netdev_tx_reset_subqueue()` when `XDP` is set [F381, F496].
- `idpf_rx_queue` and `idpf_rxq_group` union splitq fields (`splitq`, `bufq_sets`, `napi`, `xdp_prog`) with singleq fields (`singleq`, `rx_buf`, `pp`, `tail`), and `idpf_rxq_group_alloc()` embeds `idpf_rx_queue` in `idpf_rxq_set` only in splitq mode; check `idpf_is_queue_model_split(vport->rxq_model)` before accessing union fields or `container_of(rxq, struct idpf_rxq_set, rxq)` [F382, F453].
- When `FLOW_SCH_EN` is set, size/clean `tx_q->tx_buf` and `refillq->ring` with `tx_q->buf_pool_size` (`U16_MAX`) instead of `desc_count` (`idpf_tx_buf_alloc_all()`, `idpf_tx_desc_alloc()`, `idpf_tx_buf_clean()`), and use 8B `complq->comp` instead of 4B `complq->comp_4b` (`idpf_compl_desc_alloc()`, `idpf_wait_for_sw_marker_completion()`). In `idpf_tx_splitq_map()`, terminate `idpf_tx_buf_next(tx_buf)` chains with `IDPF_TXBUF_NULL` (`U32_MAX`) at EOP and before `idpf_tx_splitq_pkt_err_unmap()` [F404, F405, F410].
- Keep `txq_grp->num_completions_pending` and `complq->num_completions` synced across `idpf_tx_splitq_frame()`, `idpf_tx_clean_complq()`, and `idpf_clean_queue_set()` (zeroing both on disabled queue sets). In `idpf_tx_clean_complq()`, verify `rel_tx_qid < complq->txq_grp->num_txq` and `txqs[rel_tx_qid]` is non-NULL, and zero `tx_q->cleaned_bytes` and `cleaned_pkts` after `__netif_txq_completed_wake()` [F399, F411, F428].
- When allocating/resetting splitq rings (`idpf_tx/compl/rx/bufq_desc_alloc()`), zero `next_to_use`, `next_to_clean`, `next_to_alloc` and set `GEN_CHK`. Ring distance/pending helpers (`IDPF_DESC_UNUSED`, `IDPF_TX_COMPLQ_PENDING`, `idpf_tx_splitq_get_free_bufs`, `idpf_tx_splitq_need_re`, `idpf_rx_clean_refillq`) must add modulus (`desc_count` or `U32_MAX`) on wrap [F402, F446].
- Splitq Rx `bufq->desc_count` must not exceed `IDPF_RX_BUFQ_DESC_COUNT(rxq_desc_count, num_bufqs)`, and `idpf_rx_buf_alloc_all()` posts at most `IDPF_RX_BUFQ_WORKING_SET(rxbufq)` (`desc_count - 1`). In `idpf_rx_clean_refillq()`, advance refillq `ntc`/`RFL_GEN_CHK` and `bufq_nta`/`buf_desc` only after `idpf_rx_update_bufq_desc()` succeeds [F407, F432].
- Size per-vector queue arrays in `idpf_vport_intr_alloc()` and `idpf_qp_enable()` with `DIV_ROUND_UP(num_txq/rxq_grp, num_q_vectors)`, and size/fill `vport->q_vector_idxs` with `num_q_vectors + IDPF_RESERVED_VECS` entries for the NOIRQ vector at `[num_q_vectors]` [F442, F452].
- Both `idpf_intr_reg_init()` and `idpf_vf_intr_reg_init()` must initialize all `idpf_intr_reg` fields (`dyn_ctl_itridx_s`, `dyn_ctl_intrvl_s`, etc.). `idpf_vf_intr_reg_init()` must check `num_regs >= num_vecs` and index `reg_vals[]` with `q_vector_idxs[i] - IDPF_MBX_Q_VEC`. `idpf_vport_intr_update_itr_ena_irq()` must call `idpf_vport_intr_buildreg_itr()` before clearing `wb_on_itr` [F396, F413, F458].
- Store config that survives hard reset (`rss_data`, `q_coalesce`, queue/desc counts, `xdp_prog`, `user_flags`, `mac_filter_list`) in `vport_config[idx]->user_config`. In `idpf_rss_data`, multiply `rss_lut_size` by `sizeof(u32)` for `rss_lut`/`cached_lut` alloc/copy/zero, and sync `cached_lut` when toggling `NETIF_F_RXHASH` in `idpf_vport_manage_rss_lut()` [F393, F398, F447].
- In `idpf_set_mac()`, set `vport->default_mac_addr` before `idpf_add_mac_filter()`, and on error restore it from `netdev->dev_addr` after `__idpf_del_mac_filter()`. In `idpf_addr_unsync()`, return 0 if `ether_addr_equal(addr, netdev->dev_addr)`. In `idpf_set_rx_mode()`, clear `__IDPF_PROMISC_MC` only when neither `IFF_ALLMULTI` nor `IFF_PROMISC` is set [F389, F421, F500].
- In `idpf_tx_singleq_csum()`, when `skb->encapsulation` is true, outer IP flags in `off->tx_flags` and `ip.hdr`/`l4.hdr` are overwritten with inner header values after setting `off->cd_tunneling`. In `idpf_tso()`, `skb_cow_head(skb, 0)` must succeed before mutating headers [F400, F401].
- `reg_ops.ptp_reg_init` is NULL on VFs, and `ptp->dev_clk_regs` require `IDPF_PTP_DIRECT` access (tested before `@mailbox` in `idpf_ptp_get_access()`). All `CONFIG_PTP_1588_CLOCK` declarations in `idpf_ptp.h` need `#else` stubs. `idpf_check_reset_complete()` must reject `readl(rstat) == 0xFFFFFFFF` [F388, F403, F423, F465].

## Synchronization
- Non-datapath NDOs must lock `adapter->vport_ctrl_lock` (`idpf_vport_ctrl_lock()`) before `idpf_netdev_to_vport()`; `idpf_init_hard_reset()` holds it until `idpf_init_task()` clears `IDPF_HR_RESET_IN_PROG`. Unlocked NDOs (`idpf_features_check()`, `idpf_set_rx_mode()`, `idpf_get_stats64()`, `idpf_tx_timeout()`) must use `idpf_netdev_priv`/`np->adapter` because `np->vport` is NULL during reset. In `idpf_vc_event_task()` (`IDPF_HR_FUNC_RESET`), call `idpf_vc_xn_shutdown()` before `idpf_init_hard_reset()` takes `vport_ctrl_lock` [F357, F362, F374].
- Pass `rtnl = false` to `idpf_vport_open()`/`stop()` when holding `rtnl_lock` (`idpf_open()`, `idpf_stop()`, `idpf_initiate_soft_reset()`), and `true` from unlocked tasks (`idpf_init_task()`, `idpf_vport_dealloc()`) [F363].
- Issue `dma_rmb()` in `idpf_rx_splitq/singleq_clean()` after checking descriptor DD/GEN and before reading `rx_desc`; `wmb()` in `idpf_tx_buf_hw_update()` after setting `next_to_use` and before writing `tx_q->tail`; and `smp_rmb()` in `idpf_tx_singleq_clean()` after `tx_buf->type == LIBETH_SQE_SKB` and before reading `rs_idx`/`eop_desc->qw1` [F352, F355].
- Check all splitq TX stop conditions inside `idpf_txq_has_room()` via `netif_subqueue_maybe_stop()`. Any TX stop, drop, or rollback path (`idpf_tx_start()`, `idpf_tx_splitq/singleq_frame()`, `idpf_tx_drop_skb()`) must call `idpf_tx_buf_hw_update(..., false)` to flush `netdev_xmit_more()` [F353, F354].
- Protect `mac_filter_list` with `spin_lock_bh(&vport_config->mac_filter_list_lock)`, allocate with `GFP_ATOMIC` under it, and unlock before sleeping virtchnl calls in `idpf_add_del_mac_filters()`. `idpf_set_rx_mode()`, `idpf_addr_sync()`, and `idpf_addr_unsync()` run in atomic BH-disabled context and must pass `async = true` to virtchnl helpers [F365, F471].
- Hold `adapter->vector_lock` for all `vector_stack` and `num_avail_msix` operations; never push/pop/count reserved default-pool indices `[0, stack->base)` in `idpf_vector_stash()` or `idpf_req_rel_vector_indexes()` [F366, F397].
- Hold `ptp->read_dev_clk_lock` across `idpf_ptp_enable_shtime()` and the low/high `readl()`s in `idpf_ptp_read_src_clk_reg_direct()` and `idpf_ptp_get_sync_device_time_direct()`. Update `cached_phc_time`/`jiffies` with `WRITE_ONCE()` within `< 2 * HZ` (paired with `READ_ONCE()` in `idpf_rx_hwtstamp()`) [F370, F373].
- Allocate workqueues in `idpf_probe()` with `WQ_UNBOUND` (plus `WQ_MEM_RECLAIM` on `init/serv/stats/vc_event_wq` and `WQ_HIGHPRI` on `mbx_wq`). Guard 64-bit `q_stats` and `tstamp_stats` with `u64_stats_update_begin/end()` and `u64_stats_fetch_begin/retry()` [F470, F481].

## Object Lifetimes
- During hard reset (`IDPF_HR_RESET_IN_PROG`), `idpf_vport_dealloc()` must not call `idpf_decfg_netdev()` and must set `np->vport = NULL`, while `idpf_cfg_netdev()` reuses `adapter->netdevs[idx]` when `IDPF_VPORT_REG_NETDEV` is set [F342].
- `idpf_remove()` must set `IDPF_REMOVE_IN_PROG` and `cancel_delayed_work_sync(&adapter->vc_event_task)` before tearing down SR-IOV, virtchnl, mailbox, netdevs, or workqueues. `idpf_shutdown()` must cancel `serv_task` before `vc_event_task` and `idpf_vc_core_deinit()`, without calling `idpf_remove()` or `idpf_sriov_configure(pdev, 0)`. `idpf_deinit_task()` must cancel `init_task` and `stats_task` before `idpf_vport_dealloc()` [F343, F358, F361, F456].
- In `idpf_vport_open()`, init Rx buffers/tail, XDP RxQ info, and NAPI/IRQs (`idpf_vport_intr_ena`) before enabling queues/vport via virtchnl. In `idpf_vport_stop()` and open unwind, disable vport/queues first, then call `idpf_vport_intr_deinit()` and `idpf_xdp_rxq_info_deinit_all()` before `idpf_vport_queues_rel()` and `idpf_vport_intr_rel()` [F351, F467].
- Recycle all `libeth_fqe` entries via `idpf_rx_page_rel()` before `libeth_rx_fq_destroy()` in `idpf_rx_buf_rel_bufq()`, `idpf_rx_hdr_buf_rel_all()`, and `idpf_rx_buf_rel_all()`. In `idpf_rx_desc_rel()`, call `libeth_xdp_return_stash(&rxq->xdp)` when `!idpf_queue_has(XSK, rxq)` [F348, F502].
- `idpf_ptp_release_vport_tstamp()` must `cancel_work_sync(&vport->tstamp_task)` before locking `latches_lock` to drain latch lists (`list_for_each_entry_safe()`, as in `idpf_del_all_mac_filters()`) and freeing `tx_tstamp_caps`. When `get_dev_clk_time_access != IDPF_PTP_NONE`, call `ptp_cancel_worker_sync()` before `ptp_clock_unregister()` in `idpf_ptp_init()`/`release()` [F350, F426, F468].
- `idpf_ptp_request_ts()` calls `skb_get(skb)` and sets `SKBTX_IN_PROGRESS`; `idpf_tx_clean_bufs()` must check `SKBTX_IN_PROGRESS` and call `idpf_tx_read_tstamp()` before `libeth_tx_complete()`. Allocate `request_irq()` names with `kasprintf()` since teardown passes `free_irq()`'s return to `kfree()` [F455, F505].

## API Contracts
- Use `DMA_ATTR_FORCE_CONTIGUOUS` in `idpf_alloc/free_dma_mem()` and zero `va`, `pa`, `size` on free. Callers of `idpf_vector_to_queue_set()` must `kfree()` the returned pointer [F344, F345].
- `idpf_rx_singleq_buf_hw_alloc_all()` returns `false` on success and `true` on partial failure (opposite of `idpf_rx_post_init_bufs()`/`idpf_rx_post_buf_desc()`). `idpf_req_rel_vector_indexes()` returns `0` on allocation failure, so callers must check `<= 0` [F376, F387].
- `idpf_tso()` and `idpf_tx_singleq_csum()` return `< 0` on error, `0` if software/unneeded, and `1` for HW offload. Initialize `buf_count = 1` before `idpf_tx_res_count_required()` and drop the SKB if it returns `0`. Store `idpf_tx_tstamp()`'s return in signed `int` and check `idx != -1`. If `skb_put_padto()` fails in `idpf_tx_start()`, only call `idpf_tx_buf_hw_update(..., false)` and return `NETDEV_TX_OK` (SKB is already freed) [F377, F378, F379, F495].
- `idpf_get_mbx_reg_addr()` takes an offset relative to `static_reg_info[0].start`; `idpf_get_rstat_reg_addr()` and `idpf_get_reg_addr()` take full BAR0 offsets (`idpf_get_reg_addr()` `BUG()`s if unmapped) [F386].
- Use `idpf_is_cap_ena_all()` for multi-bit capability masks (`IDPF_CAP_HSPLIT`, `IDPF_CAP_RSC`, checksums). In `idpf_vport_set_hsplit()`, `ETHTOOL_TCP_DATA_SPLIT_UNKNOWN` returns `true` if unsupported and falls through to `ENABLED` if supported [F422, F424].
- In `idpf_rx_splitq_clean()`, if `rx_bufq->hdr_pp && !hdr_len && !xdp->data`, call `idpf_rx_hsplit_wa()` (or zero `pkt_len` on 0 return). In `idpf_rx_rsc()`, set network and transport headers before `skb_transport_offset()` [F491, F501].

## Error Handling
- In `idpf_tx_splitq_frame()`/`map()`, save `tx_params.prev_ntu` before getting descriptors and (when `FLOW_SCH_EN` is set) `refillq->next_to_clean` and `RFL_GEN_CHK` before `idpf_tx_get_free_buf_id()`, restoring them on error in `idpf_tx_splitq_frame()` and `idpf_tx_splitq_pkt_err_unmap()` [F336, F337].
- In `idpf_tx_singleq_dma_map_error()`, wrap `idx` from `0` to `desc_count` before `idx--`, and if `skb_is_gso(skb)`, zero and step back over the context descriptor too. In `idpf_tx_singleq_csum()`, on unsupported L4/tunnel protocols, return `-1` if `is_tso`, else `skb_checksum_help(skb)` and return `0` [F415, F425].
- In `idpf_vport_alloc()`, jump to `free_vector_idxs` on errors after `q_vector_idxs` allocation. In `idpf_init_hard_reset()`, `cancel_delayed_work_sync(&adapter->mbx_task)` before `idpf_deinit_dflt_mbx()` if `idpf_vc_core_init()` fails. Set `IDPF_VPORT_REG_NETDEV` only after `register_netdev() == 0`, and check `test_and_clear_bit(IDPF_VPORT_REG_NETDEV, ...)` in `idpf_decfg_netdev()` [F340, F360, F375].
- Check `rsc_seg_len != 0` before `DIV_ROUND_UP()` in `idpf_rx_rsc()`, and check `q_vec->num_txq/rxq/complq != 0` before dividing `budget` in `idpf_tx/rx_singleq/splitq_clean_all()` [F440, F441].

## External Contracts
- Split `> IDPF_TX_MAX_DESC_DATA` (`SZ_16K - 1`) Tx fragments with first chunk `IDPF_TX_MAX_DESC_DATA_ALIGNED + (-dma & (IDPF_TX_MAX_READ_REQ_SIZE - 1))` and subsequent chunks `IDPF_TX_MAX_DESC_DATA_ALIGNED` (12K). Align splitq Rx `bufq->tail` writes down to a multiple of 8 (`IDPF_RX_BUF_STRIDE` / `POST_STRIDE`) [F408, F409].
- `idpf_features_check()` must clear `CSUM | GSO` when `skb_network_offset(skb) & ~126`, hdr len `> max_tx_hdr_size`, or encap L4 len `& ~(127 * 2)`, and clear `GSO` when `gso_size < IDPF_TX_TSO_MIN_MSS` (88) or `idpf_chk_tso_segment()` fails. In `idpf_cfg_netdev()`, gate Tx checksums on `IDPF_CAP_TX_CSUM_*` via `idpf_is_cap_ena_all()` and set `hw_enc_features = dflt_features | other_offloads` [F416, F459, F497].
- In `idpf_vport_splitq/singleq_napi_poll()`, if `budget <= 0`, only clean Tx and return. Combine `clean_complete` with `&=` (not `&&`); if `!clean_complete`, call `idpf_vport_intr_set_wb_on_itr()` and return `budget`; if complete, clamp `work_done` to `budget - 1` and call `idpf_vport_intr_update_itr_ena_irq()` only if `napi_complete_done()` returns `true` [F434, F487, F489].
- Singleq Rx must check `rx_q->rxdids == VIRTCHNL2_RXDID_1_32B_BASE_M` (`base_wb` vs `flex_nic_wb`); splitq Rx must check `rxdid == VIRTCHNL2_RXDID_2_FLEX_SPLITQ`. `idpf_rx_rsc()` must set `gso_size`, `gso_type`, TCP pseudo-hdr csum, and call `tcp_gro_complete(skb)` even when `rsc_segments == 1` [F420, F492].
- Route `idpf_ptp_adjtime()` deltas outside `[S32_MIN, S32_MAX]` to `idpf_ptp_adjtime_nonatomic()`. On `CONFIG_X86`, set `getcrosststamp` only if `pcie_ptm_enabled()`, `X86_FEATURE_ART`, and `X86_FEATURE_TSC_KNOWN_FREQ` are all true, and set `system->cs_id` to `CSID_X86_ART` (x86) or `CSID_ARM_ARCH_COUNTER` (ARM) [F419, F488].

## Known Pitfalls
- `idpf_initiate_soft_reset()` copies `idpf_vport` only up to `offsetof(struct idpf_vport, link_up)`; use `vport` (not `new_vport`) for fields at/after `link_up` and do not mutate pre-`link_up` fields on `vport` before `memcpy` [F341].
- Free `txq/rxq->desc_ring` with `dmam_free_coherent()` and `complq->desc_ring` / `bufq->split_buf` with `dma_free_coherent()` [F346].
- `idpf_tx_clean_complq()` and `idpf_tx_singleq_clean()` subtract `desc_count` from `s16 ntc` before looping and must add `desc_count` back before storing `next_to_clean`. `idpf_rx_hsplit_wa()` copies `LARGEST_ALIGN(copy)` bytes into `hdr`, requiring that much writable space [F414, F450].
- Cast 32-bit values to `u64` before shifting `>= 32` in `idpf_ptp_read_src_clk_reg_direct()`, `idpf_ptp_get_sync_device_time_direct()`, and `idpf_tx_singleq_build_ctob()` [F437, F438].
