# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 6)

PCI/SR-IOV, PM, GPU migration, MMIO/iosys_map, memirq, MOCS/PAT, OA, PMU, PCODE, NVM, PSMI, and preempt fences.

## Architecture & Data Flow
- `xe_migrate.c` jobs writing migration VM PTEs (`xe_migrate_copy()`, non-identity `xe_migrate_clear()`, `__xe_migrate_update_pgtables()`, `xe_migrate_vram()`) must end the preamble with `MI_BATCH_BUFFER_END` at `update_idx` and pass `MI_INVALIDATE_TLB` to `xe_sched_job_add_migrate_flush()`. `MI_STORE_DATA_IMM` PTE writes cap at `MAX_PTE_PER_SDI` (`0x1FE` qwords), and `write_pgtable()` pads `bb->cs` with `MI_NOOP` when `!(bb->len & 1)`. [F679, F753]
- Level-2 PDE indices (`IDENTITY_OFFSET` `256ULL`, `255ULL`, `slot + 1ULL` in `xe_migrate_vm_addr()`) must be `u64` before shifting by `xe_pt_shift()` (30). `xe_migrate_prepare_vm()` and `xe_migrate_vram_ofs()` use `DIV_ROUND_UP_ULL(actual_phy_size, SZ_1G)` to offset the Xe2+ compressed VRAM map, and `xe_migrate_program_identity()`'s 1GiB loop switches to 2MiB pages when `pos + SZ_1G >= vram_limit` and `break`s after the 2MiB loop. [F682, F700, F701]
- In `xe_migrate_ccs_rw_copy()`, size precalculation and emission loops must count equal dwords (`batch_size_allocated == bb->len`). On integrated flat-CCS, `max_mem_transfer_per_pass()` caps at `MAX_CCS_LIMITED_TRANSFER` (`SZ_4M`). Before `build_pt_update_batch_sram()`, `xe_migrate_vram()` expands compound `drm_pagemap_addr` entries across `1..NR_PAGES(order) - 1` (bounded by `npages`), advancing `i` by `NR_PAGES(order)`. `xe_migrate_dma_map()` uses `vmalloc_to_page()` if `is_vmalloc_addr(buf)` else `virt_to_page()`. [F653, F686, F703, F758]
- `xe->oa.xe` is set only when OA is supported (`xe_oa_init()`) and cleared on failure/`xe_oa_fini()`, so OA entry points must check `if (!oa->xe)`. When `stream->no_preempt` is set, `xe_oa_enable_locked()` zeroes `timeslice_us`/`preempt_timeout_us` via `xe_oa_disable_preempt_timeslice()`, and `xe_oa_disable_locked()` and `xe_oa_disable_preempt_timeslice()`'s error path must restore them from `sched_props`. [F637, F651]
- `xe_oa_init_oa_buffer()` writes `oa_buffer` after `oa_head_ptr` and before `oa_tail_ptr` under `ptr_lock`, resets `head`/`tail` to 0, and zeroes `vaddr`; `OABUFFER_SIZE_MASK` subtracts 20 from `size_exponent` when `> 24` (`> SZ_16M`) else 17 (`oag_buf_size_select()`). `xe_oa_append_reports()` clears copied reports' ID/timestamp (`oa_report_header_64bit(stream)` for 64-bit offsets 0/8 vs 32-bit 0/4, or zeroes the whole report if `circ_size % report_size != 0`) and updates `oa_head_ptr` and `head` under `ptr_lock`. OA circular math wraps at `circ_size`, splitting copies/zeroing across `oa_buf_end` when `circ_size % report_size != 0`. [F646, F647, F663, F664, F706, F715]
- `xe_oa_set_property_funcs_open` and `_config` must match sizes (`xe_oa_set_prop_ret_inval` for unsupported config props). `oa_exponent_to_ns()` requires exponent in `[0, 31]` and `2ULL << exponent`. `write_cs_mi_lri()` batchbuffers (`__xe_oa_alloc_config_buffer()`) size dwords via `num_lri_dwords()`. `xe_mmio_range` tables for `xe_oa_reg_in_range_table()` need non-zero `.start`/`.end` and a `{}` sentinel. [F662, F694, F705, F714]
- `xe_memirq_init()` allocates `memirq->bo` with `XE_BO_FLAG_SYSTEM | XE_BO_FLAG_GGTT | XE_BO_FLAG_GGTT_INVALIDATE | XE_BO_FLAG_NEEDS_UC | XE_BO_FLAG_NEEDS_CPU_ACCESS`, sized `XE_HW_ENGINE_MAX_INSTANCE * SZ_4K` if `xe_device_has_msix(xe)` else `SZ_4K`. Per 4KiB page, source is at `XE_MEMIRQ_SOURCE_OFFSET(instance) + offset` (`0x400 + offset`) and status is at `XE_MEMIRQ_STATUS_OFFSET(instance) + offset * SZ_16`. [F675, F740]
- In `xe_pat_init_early()`, `pat.ops` is `NULL` on VFs, `program_media` is `NULL` when `MEDIA_VER(xe) < 13`, and the platform chain must match explicit versions without an open-ended `>=` fallback; callers must NULL-check `ops` and `program_media`. `XE2_PAT` must never enable both `comp_en` and `__coh_mode != 0`. In `get_mocs_settings()`, `table_size <= num_mocs_regs` and `0 < unused_entries_index < table_size`. In `xe_info_init()`, `!graphics_ip` is fatal (`-ENODEV`), whereas `media_ip`, `media_desc`, and `tile->media_gt` are `NULL` when media is absent or `MEDIA_VER(xe) < 13`. In `xe_pci.c`, `pciidlist` (most-specific first), `subplatforms`, and subplatform ID arrays end with `{}`/`0`. [F638, F640, F660, F676, F691, F737]

## Synchronization
- Runtime `pcode_mailbox_rw()` requires `tile->pcode.lock`; `xe_pcode_ready()` takes `locked = true` on resume and `false` only in `xe_pcode_probe_early()`. Retrying `pcode_try_request()` under `preempt_disable()` in `xe_pcode_request()` requires `atomic = true`. [F602, F751]
- `xe_pm_runtime_suspend/resume()` set `xe->pm_callback_task` to `current` via `xe_pm_write_callback_task()` (`WRITE_ONCE()` + `smp_mb()`) and clear it on exit, pairing with `smp_mb()` + `READ_ONCE()` in `xe_pm_read_callback_task()`. Callers holding locks taken in runtime PM callbacks (BO `dma_resv` when `d3cold.capable`, `vram_userfault.lock`) or in `fs_reclaim` when `!xe_rpm_reclaim_safe(xe)` must never call synchronous resume (`xe_pm_runtime_get()`, `xe_pm_runtime_get_ioctl()`, `xe_pm_runtime_resume_and_get()`). [F603, F604]
- `xe_pm_set_vram_threshold()` and `xe_pm_d3cold_allowed_toggle()` require `xe->d3cold.lock` and `DIV_ROUND_UP_ULL(val, 1024 * 1024)`. Iterating `vram_userfault.list` and `rebind_resume_list` requires `list_for_each_entry_safe()`. In `xe_pm_notifier_callback()`, `PM_SUSPEND/HIBERNATION_PREPARE` call `reinit_completion(&xe->pm_block)` before evicting user BOs, and `PM_POST_*` call `complete_all(&xe->pm_block)` before `xe_pm_wake_rebind_workers()`. [F607, F697, F709, F723]
- `xe_pmu_register()` sets `pmu->registered = true` after `set_supported_events()` and `perf_pmu_register()`; `xe_pmu_unregister()` clears it before `perf_pmu_unregister()` and `kfree(pmu->name)`. Monotonic events (`!is_gt_frequency_event(event)`) init `hw.prev_count` in `xe_pmu_enable()` and add `new - prev` via `local64_try_cmpxchg()` in `xe_pmu_event_update()`; frequency events add `new` directly. [F608, F610, F659]
- Dynamic OA configs in `oa->metrics_idr` and sysfs under `oa->metrics_kobj` are updated together under `oa->metrics_lock` (`xe_oa_remove_config_ioctl()` removes both before `xe_oa_config_put()`); `xe_oa_config_release()` uses `kfree_rcu()`, and `xe_oa_get_oa_config()` holds `rcu_read_lock()` across `idr_find()` and `kref_get_unless_zero()`. [F611, F650]
- Opening/destroying OA streams and `oa_unit->exclusive_stream` require `gt->oa.gt_lock`. Stream fops (`xe_oa_ioctl()`, `xe_oa_poll()`, `__xe_oa_read()`) require `stream->stream_lock`, except `xe_oa_wait_unlocked()` runs unlocked. `oa_buffer.head/tail` and OA buffer MMIO regs require `spin_lock_irqsave(&stream->oa_buffer.ptr_lock)`, dropping `ptr_lock` around `xe_oa_append_report()`. In `xe_oa_emit_oa_config()`, `xe_oa_update_last_fence(stream, fence)` must precede `dma_fence_add_callback(..., xe_oa_config_cb)` because `xe_oa_config_cb()` drops `fence`. [F612, F613, F614, F616]
- In `xe_migrate_job_lock()`, pushing to `m->q` and updating `m->fence` require `m->job_mutex` (`fs_reclaim`-primed, no `GFP_KERNEL`), whereas `q != m->q` requires `xe_vm_assert_held(q->vm)`. `xe_migrate_update_pgtables_cpu()` calls `xe_device_wmb(vm->xe)` after CPU PTE writes. In `preempt_fence_work_func()`, the entire body (`suspend_wait()`, `dma_fence_signal()`, `xe_vm_queue_rebind_worker()`, `xe_exec_queue_put()`) must stay inside `dma_fence_begin/end_signalling()`. [F618, F619, F745]

## Object Lifetimes
- In multi-pass migration (`xe_migrate_copy/clear/access_memory()`), the previous pass's `fence` must not be dropped via `dma_fence_put()` until the next job submission succeeds (`dma_fence_wait(fence, false)` on error). In batch teardown, `xe_bb_free()` and `drm_suballoc_free()` take `NULL` before `xe_sched_job_push()` and `fence` after. [F583, F586]
- Once `auxiliary_device_init(&nvm->aux_dev)` succeeds, `xe_nvm_release_dev()` frees `nvm` on `auxiliary_device_uninit()`; never `kfree(nvm)` directly. In `xe_psmi.c`, region bit `id` (`>= 1`) indexes `capture_obj[id]` and `xe->tiles[id - 1]`; `psmi_cleanup()` unpins BOs under `xe_bo_lock()` and zeroes `capture_obj[id]`, `psmi_resize_object()` calls `psmi_cleanup(xe)` before allocating and on failure (checking `IS_ERR(bo)` before storing), and `psmi_debugfs_capture_region_mask_set()` rejects changing `region_mask` while `size != 0`. [F589, F590, F645, F658]
- In `xe_pmu_event_init()`, `!event->parent` takes `drm_dev_get()`, `xe_pm_runtime_get()`, and optional `event_gt_forcewake()` (`event->pmu_private`), rolling back on failure or releasing all in `xe_pmu_event_destroy()`. [F591]
- `xe_oa_emit_oa_config()` frees `stream->syncs` only on success; on earlier failure, callers must run `xe_sync_entry_cleanup()` and `kfree(syncs)`. Once `oa_config->regs = regs` is set in `xe_oa_add_config_ioctl()`, `xe_oa_config_put()` frees `regs`. Open OA streams hold `xe_pm_runtime_get()` and `XE_FORCEWAKE_ALL` until `xe_oa_stream_destroy()`, and `drm_dev_get()` until `xe_oa_release()` after `xe_oa_destroy_locked()`. `xe_oa_disable_locked()` (`hrtimer_cancel(&stream->poll_check_timer)`) must finish before `xe_oa_stream_destroy()` unpins `oa_buffer.bo`. [F593, F595, F615, F732]
- On SR-IOV PF, `pf_enable_vfs()` holds `xe_pm_runtime_get_noresume()` until `pf_disable_vfs()` and calls `pf_link_vfs()` to link each VF (consumer) to PF (supplier) with `DL_FLAG_AUTOREMOVE_CONSUMER` (dropping `xe_pci_pf_get_vf_dev()`'s ref via `pci_dev_put()`). `xe_pci_remove()` must call `xe_pci_sriov_configure(pdev, 0)` before `xe_device_remove()`. [F620, F726]

## API Contracts
- `xe_migrate_get_vm()` returns a refcounted `xe_vm *` (`xe_vm_put()`), whereas `xe_migrate_lrc/exec_queue()` return borrowed pointers. In `xe_migrate_pt_update_ops`, `.populate/.clear()` get non-NULL `map` (`pos == NULL`, `ofs` in qwords) for CPU updates and `map == NULL` with 64-bit-aligned `pos` (`ofs` unused) for GPU updates. [F585, F625]
- `xe_mmio_read8/16/32()` call `mmio_flush_pending_writes()` first, and on VFs, `xe_mmio_read/write32()` route non-`reg.vf` to `xe_gt_sriov_vf_read/write32()`. 64-bit GTTMMADR reads use `xe_mmio_read64_2x32()` (never on side-effecting regs). `xe_mmio_rmw32(mmio, reg, clr, set)` takes positive clear mask `clr` and returns the old unmasked value. `__xe_mmio_wait32()` does one final read/check on timeout and writes unmasked `read` to `*out_val`. `xe_map_rd/wr()` use byte offsets, `xe_map_rd/wr_array()` scale `index__` by `sizeof(type__)`, and `xe_map_rd/wr_ring_u32()` use `u32` units. [F629, F630, F689, F712, F728, F729]
- `xe_oa_config_locked()` swaps `stream->oa_config` via `xchg()`, drops the old ref, and returns the old ID (`err ?: ret`). `oa->metrics_idr` uses base 1 (IDs `>= 1`). `xe_oa_mmap()` requires full-BO size, rejects `VM_WRITE | VM_EXEC | VM_SHARED | VM_MAYSHARE`, and clears `VM_MAYWRITE | VM_MAYEXEC`. PF helpers take 1-based VF IDs (`1..num_vfs`), whereas `xe_pci_pf_get_vf_dev()` takes 0-based `vf_id` and returns a refcounted `pci_dev *`. `xe_pcode_read(tile, mbox, val, val1)` requires non-NULL `val` pre-initialized with input `PCODE_DATA0`. [F635, F641, F642, F668, F765]
- `xe_pm_runtime_get_ioctl()` returns `>= 0` on success and `< 0` on error while still incrementing usage count (except `-ELOOP`), whereas `xe_pm_runtime_get_if_active/in_use()` and `xe_pm_runtime_resume_and_get()` return `true` only if a ref was acquired. `xe_pm_runtime_init()` sets `DPM_FLAG_NO_DIRECT_COMPLETE` on `IS_DGFX(xe)`. `xe_preempt_fence_alloc()` returns `ERR_PTR(-ENOMEM)` via `kmalloc()`, freed via `xe_preempt_fence_free()` before `xe_preempt_fence_arm()` and `dma_fence_put()` after. [F643, F644, F770]

## Error Handling
- In `xe_migrate_update_pgtables()`, only `ERR_PTR(-ETIME)` from `xe_migrate_update_pgtables_cpu()` (`pre_commit` when `!pt_update->job`) falls back to GPU. `xe_migrate_dma_map()` must `kcalloc()` `pagemap_addr` so `xe_migrate_dma_unmap()` stops at `!pagemap_addr[i].addr`. [F624, F627]
- In `xe_oa_read()`, `xe_oa_append_reports()` returns `-ENOSPC` when full, so `xe_oa_read()` returns `offset ?: (ret ?: -EAGAIN)` and keeps `stream->pollin` true on `-ENOSPC`/`-EIO`. In `xe_oa_emit_oa_config()`, `-ENOENT` from `dma_fence_add_callback()` calls `xe_oa_config_cb()` directly and returns `0`. `xe_oa_stream_open_ioctl()` inits `param.period_exponent = -1`. [F633, F634, F636]
- `xe_pci_probe()` checks `xe_survivability_mode_is_boot_enabled(xe)` to return `0` before checking `xe_device_probe_early()`'s `err`, and `xe_pci_remove/suspend()` also guard against it. In `xe_pm_notifier_callback()`, BO eviction/prepare failures during `PM_SUSPEND/HIBERNATION_PREPARE` must not drop `xe_pm_runtime_get()` or return `NOTIFY_BAD`. [F639, F724]

## External Contracts
- `xe_pmu_register()` replaces `':'` with `'_'` in `pmu->name`. `event_supported()` checks `id < sizeof(pmu->supported_events) * BITS_PER_BYTE`. `event_param_valid()` requires `engine_class`, `engine_instance`, and `function_id` to be 0 for GT events, and `function_id <= xe_sriov_pf_get_totalvfs(xe)` on PF (`0` on non-PF) for engine events. [F678, F720, F761]
- `xe_oa_user_extensions()` and `xe_oa_user_ext_set_property()` reject `ext.pad != 0`, cap at `MAX_USER_EXTENSIONS` (`16`, `-E2BIG`), bounds-check IDs, and use `array_index_nospec()`. When `xe_observation_paranoid` is true, config ioctls and `xe_oa_mmap()` require `perfmon_capable()`, and `xe_oa_stream_open_ioctl()` requires it unless `param.exec_q && !param.sample && !param.no_preempt`. `xe_oa_alloc_regs()` reads `n_regs` `(addr, val)` `u32` pairs (advancing `regs` by 2) and validates addresses with `xe_oa_is_valid_config_reg_addr()`. [F713, F766, F767, F768]
- `xe_mmio_gem_create/mmap()` require `PAGE_SIZE`-aligned `phys_addr`/`size` and `VM_SHARED` full-BO mappings; `xe_mmio_gem_vm_fault()` guards `vmf_insert_pfn()` with `drm_dev_enter/exit()` or maps `xe_mmio_gem_vm_fault_dummy_page()`. [F621, F739]

## Known Pitfalls
- Because `xe_migrate_vram()` requires 64-byte (`XE_CACHELINE_BYTES`) alignment, `xe_migrate_access_memory()` bounces unaligned accesses via `kmalloc(XE_CACHELINE_BYTES, GFP_KERNEL)` (never stack) and clamps sub-page chunks to `S16_MAX * 4`. In `xe_migrate_copy()`, both `pte_update_size()` calls must pass `&src_L0` after `src_L0 = min(src_L0, dst_L0)`. [F680, F683, F741]
- In `xe_oa_buffer_check_unlocked()`, `hw_tail` from `xe_oa_hw_tail_read()` subtracts `gtt_offset`, rounds down by `xe_oa_circ_diff(stream, hw_tail, tail) % report_size`, and walks backward via `xe_oa_circ_diff()`. `xe_oa_add_config_ioctl()` must `kzalloc()` `struct xe_oa_config` to NUL-terminate `uuid[UUID_STRING_LEN]`. [F665, F718]
- With MSI-X (`hw_reports_to_instance_zero(memirq)`), `__memirq_source/status_page()` and `xe_memirq_hwe_handler()` index page `hwe->instance` (else page 0), and `memirq_received()` clears non-zero bytes to `0x00` and logs non-`0xff` via `memirq_err_ratelimited()`. `xe_memirq_handler()` skips `gt->tile != tile`, and `memirq_dispatch_guc()` checks `GUC_INTR_GUC2HOST` and `GUC_INTR_SW_INT_0` with separate `if`s. `LNCFCMOCS` loops pack two 16-bit entries per reg (`l3cc_combine()`) and bound `i` by `(info->num_mocs_regs + 1) / 2`. [F655, F677, F688, F771]
- In `XE_EVENT_ATTR_GROUP` (`xe_pmu.c`), `dev_get_drvdata(kobj_to_dev(kobj))` is `struct pmu *` (`container_of(..., struct xe_pmu, base)`). In `xe_pm_resume()`, `xe_i2c_pm_resume(xe, true)`, `xe_pcode_ready()`, `xe_bo_restore_early/late()`, and `xe_late_bind_fw_load()` run unconditionally (not gated on `d3cold.allowed`). On VFs, `read_gmdid()` temporarily sets `gt->info.id/type` on `xe_root_mmio_gt(xe)` for `xe_gt_sriov_vf_gmdid(gt)` and resets `gt->info.type = XE_GT_TYPE_UNINITIALIZED`. [F717, F722, F736]
