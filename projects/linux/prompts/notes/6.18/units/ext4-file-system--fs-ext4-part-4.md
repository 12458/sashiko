# EXT4 FILE SYSTEM — fs/ext4 (part 4)

This component implements ext4's multi-block allocator (`mballoc`), directory and namespace operations (HTree, casefolding, fscrypt), online extent migration/defragmentation (`EXT4_IOC_MIGRATE`, `EXT4_IOC_MOVE_EXT`), Multi-Mount Protection (MMP), orphan inode tracking, and page writeback bio submission/completion.

## Architecture & Data Flow
- In `mb_update_avg_fragment_size()`, when `grp->bb_fragments == 0`, set `new = -1`, erase from `s_mb_avg_fragment_size[old]` (`old >= 0`), and set `bb_avg_fragment_size_order = -1`; in `mb_set_largest_free_order()`, always erase from `s_mb_largest_free_orders[old]` (`old >= 0`), gating only `[new]` insertion on `test_opt2(sb, MB_OPTIMIZE_SCAN)`. Check `bb_fragments != 0` before `bb_free / bb_fragments` (also in `ext4_mb_good_group()`). [F72, F73, F152]
- Per-order arrays (`s_mb_largest_free_orders`, `s_mb_avg_fragment_size`, `s_mb_offsets`, `s_mb_maxs`, `bb_counters`) and `ext4_group_info` slabs have `MB_NUM_ORDERS(sb)` (`s_blocksize_bits + 2`) elements; clamp any `fls()` order below `MB_NUM_ORDERS(sb)` and bound `bb_counters` copies/zeroing by `s_blocksize_bits + 2`. In `ext4_mb_mark_free_simple()`, OR `first` with `border = 2 << sb->s_blocksize_bits` before `ffs(first | border) - 1`. [F100, F151, F160]
- In `mb_free_blocks()`, update `bb_free`/`bb_first_free`/`bb_fragments` only after `mb_test_and_clear_bits() == -1`. Always call `EXT4_MB_GRP_CLEAR_TRIMMED(grp)` in `ext4_free_data_in_buddy()` and `ext4_mb_clear_bb()`. Clear `EXT4_FREE_BLOCKS_VALIDATED` whenever `ext4_free_blocks()` adjusts `(block, count)` or `ext4_mb_clear_bb()` loops to `do_more:`. In `ext4_mb_mark_context()`, update `ext4_free_group_clusters`, `ext4_block_bitmap_csum_set()`, `ext4_group_desc_csum_set()` under group lock, and `fg->free_clusters` (`s_log_groups_per_flex`). [F74, F75, F76, F127]
- Group scan & goal selection: in `ext4_mb_scan_groups_goal_fast()`, use `CR_BEST_AVAIL_LEN` only if `EXT4_MB_HINT_DATA` (else `CR_GOAL_LEN_SLOW`); restore `ac_g_ex.fe_len = ac_orig_goal_len` when `ext4_mb_scan_groups_best_avail()` falls back to `CR_GOAL_LEN_SLOW`; in `ext4_mb_scan_groups_linear()`, increment `ac_criteria` only when `count == ngroups` and update `*start = group`. If `ext4_mb_try_best_found()` loses `ac_b_ex`, zero `ac_b_ex` and set `AC_STATUS_CONTINUE`, `EXT4_MB_HINT_FIRST`, and `CR_ANY_FREE`. Check stripe alignment before `max >= fe_len` in `ext4_mb_find_by_goal()`, and always advance `i` and decrement `free` in `ext4_mb_complex_scan_group()`. [F78, F79, F117, F119, F121, F122]
- Normalization & group init: in `ext4_mb_normalize_request()`, clamp `start + size <= EXT_MAX_BLOCKS` and adjust via `ext4_mb_pa_adjust_overlap()` within `EXT4_BLOCKS_PER_GROUP(sb)`. In `ext4_mb_new_inode_pa()`, align `ac_b_ex.fe_logical` to `ac_g_ex.fe_logical` (when `fe_len < ac_orig_goal_len`) only if `o_ex_end <= extent_logical_end(sbi, &ex)`. In `ext4_mb_init_cache()`, if `folio_test_uptodate(folio)`, skip groups with `!EXT4_MB_GRP_NEED_INIT(grinfo)`. Size `s_mb_nr_global_goals` with `DIV_ROUND_UP(s_groups_count, 4)`, size `meta_group_info` with `(ngroups + EXT4_DESC_PER_BLOCK(sb) - 1) >> EXT4_DESC_PER_BLOCK_BITS(sb)`, treat `s_group_info_size` as element count, and compare `grp < ext4_get_groups_count(sb) - 1` in `ext4_last_grp_cluster()`. [F80, F101, F102, F103, F155, F156, F161]
- Orphan & directory rules: use `ext4_inode_orphan_tracked(inode)` rather than `list_empty(&ei->i_orphan)` alone, and call `ext4_mark_inode_dirty()` when dropping `i_nlink` before `ext4_orphan_add()`. `dx_probe()` must bound `indirect_levels < ext4_dir_htree_level(sb)`, verify `dx_get_limit()`, check `1 <= count <= limit`, and reject cycle blocks; `ext4_dx_csum_verify/set()` must check `count_offset + limit * sizeof(struct dx_entry) <= blocksize - sizeof(struct dx_tail)` and cast `c` to `struct dx_entry *`; `make_indexed_dir()` calls `ext4_check_dx_root()`; `ext4_search_dir()` checks `de->name + de->name_len <= dlimit` and `de_len > 0`. Use `ext4_rec_len_from/to_disk()`, mask `dx_get_block()` with `0x0fffffff`, shift `dx_map_entry::offs` by 2, and use `ext4_inc/dec_count()`. [F83, F85, F105, F106, F107, F108, F109, F111, F147, F148, F166]
- Casefold, rename & symlink: when `!sb_no_casefold_compat_fallback(sb)` on a casefolded dir, `__ext4_find_entry()` falls back to linear scan on `ext4_dx_find_entry()` miss and `ext4_match()` ignores hash mismatch. Pass `ent->inode` (not `ent->dir`) when checksumming/dirtying `ent->dir_bh` in `ext4_rename_dir_finish()`, and copy `disk_link.len` (with NUL) into `i_data` while setting `i_size = disk_link.len - 1` in `ext4_symlink()`. [F132, F137, F169]
- Migrate, move_extent & writeback: in `ext4_ind_migrate()`, flush `ext4_alloc_da_blocks(inode)` first and require blocks `<= EXT4_MAX_BLOCK_FILE_PHYS` (also in `ext4_mb_use_preallocated()`), `eh_depth == 0`, `eh_entries <= 1`, and `end < EXT4_NDIR_BLOCKS`. In `ext4_move_extents()`, add `move_extent_per_page()` to `*moved_len` before breaking on error; in `move_extent_per_page()`, `mext_page_mkuptodate()` breaks at `bh_offset(bh) >= to` and `filemap_release_folio()` must succeed on both folios before `ext4_swap_extents()`/`ext4_get_block()`. In `ext4_bio_write_folio()`, set `buffer_async_write` and `__folio_start_writeback()` before `io_submit_add_bh()` (reverting on fscrypt error), and use `ext4_io_end_defer_completion()` across `ext4_end_bio()`/`ext4_put_io_end[_defer]()`. [F93, F94, F95, F97, F113, F128, F146, F210]

## Synchronization
- `mballoc` locks: never hold `ext4_lock_group()` when calling `ext4_mb_init_cache/group()` or `ext4_mb_load_buddy[_gfp]()`; `i_prealloc_lock` and `lg_prealloc_lock` nest inside `ext4_lock_group()`. Use `GFP_ATOMIC` (no `__GFP_NOFAIL`) for `xa_insert()` under group lock. Recheck `ext4_mb_good_group()` after locking in `ext4_mb_scan_group()`. Store `raw_cpu_ptr(sbi->s_locality_groups)` in `ac->ac_lg` and unlock `ac->ac_lg->lg_mutex` in `ext4_mb_release_context()`. Unlink/read `bb_prealloc_list` under `ext4_lock_group()`; update `MB_GROUP_PA` fields only in `ext4_mb_release_context()` under `pa_lock` after `ext4_mb_mark_diskspace_used()`; and copy `s_group_info` before `rcu_assign_pointer()` + `ext4_kvfree_array_rcu()`. [F37, F40, F42, F46, F47, F179, F181, F183]
- Inode PA rbtree (`ei->i_prealloc_node`): in `ext4_mb_use_preallocated()` and `ext4_mb_pa_adjust_overlap()`, descend by immutable `pa_lstart`, then walk `rb_prev()`/`rb_next()` skipping `pa_deleted != 0` under `pa_lock`; hold `tmp_pa->pa_lock` across `pa_deleted == 0`, range checks, `atomic_inc(&pa_count)`, and `ext4_mb_use_inode_pa()`. In `ext4_discard_preallocations()`, if `pa_count != 0` or `pa_deleted != 0`, drop locks, sleep (`schedule_timeout_uninterruptible(HZ)`), and `goto repeat`. [F41, F123, F124, F125]
- Writeback & `io_end`: hold `spin_lock_irqsave(&head->b_uptodate_lock, flags)` in `ext4_finish_bio()` when clearing `buffer_async_write` and counting `under_io`. In `ext4_end_bio()`, if `ext4_io_end_defer_completion(io_end)` is true, link `bio` via `xchg(&io_end->bio, bio)` before `ext4_put_io_end_defer()`; else call `ext4_put_io_end_defer()` before `ext4_finish_bio()`. Protect `i_rsv_conversion_list` and work queueing with `spin_lock_irqsave(&ei->i_completed_io_lock, flags)`. [F29, F30, F31]
- Migrate & move_extent locking: lock two inodes/folios in ascending `struct inode *` order in `ext4_double_down_write_data_sem()` and `mext_folio_double_lock()` (under `memalloc_nofs_save()`, waiting on writeback, then swapping `folio[0..1]` back if `inode1 > inode2`). Drop `i_data_sem` before `move_extent_per_page()`, which relocks `i_data_sem` under folio locks and rechecks `mext_check_coverage()` if `unwritten`. Hold `ext4_writepages_down_write(sb)` across `ext4_ext/ind_migrate()`, and recheck `EXT4_STATE_EXT_MIGRATE` under `i_data_sem` in `ext4_ext_swap_inode_data()`. [F16, F32, F33, F34, F187]
- Orphan, unlink & MMP locking: call `ext4_find_entry()` before `ext4_journal_start()` in `__ext4_unlink()`. Require `inode_is_locked()` and call `ext4_reserve_inode_write()` before `s_orphan_lock` in `ext4_orphan_add/del()`; use `atomic_dec_if_positive(&ob_free_entries)` + `cmpxchg()` (restoring with `atomic_inc()` on error) in `ext4_orphan_file_add()`. Set `s_mmp_bh` before `kthread_run(kmmpd)` using `write_mmp_block_thawed()` under `s_umount` vs `write_mmp_block()` in `kmmpd()`. [F26, F35, F188, F191, F205]

## Object Lifetimes
- Clear `bh = NULL` after calling `make_indexed_dir()`, and cache `info->indirect_levels` before the `brelse(frames[i].bh)` loop in `dx_release()`. In `ext4_end_io_end()`, clear `io_end->handle = NULL`, free/convert the reserved handle, and clear `EXT4_IO_END_UNWRITTEN` before `ext4_release_io_end()`; in `ext4_finish_bio()`, use `fscrypt_pagecache_folio()` and call `fscrypt_free_bounce_page()` only when `!under_io`. [F2, F7, F133, F202]
- Restore quotas (`dquot_quota_off()`) and `sb->s_flags` in `ext4_orphan_cleanup()`. In `kmmpd()`, `put_bh(bh_check)` and wait for `kthread_should_stop()` at `wait_to_exit`; in `ext4_stop_mmpd()`, call `kthread_stop(s_mmp_tsk)` before `brelse(s_mmp_bh)`. On `ext4_ext_migrate()` failure, call `free_ext_block()`, zero `tmp_inode` `i_size`/`i_blocks`, restore `i_csum_seed`, and call `ext4_ext_tree_init()` before `iput()`. [F12, F14, F15, F27]
- `mballoc` lifetimes: balance `folio_get/put()` on `bd_buddy/bitmap_folio` across first insert into `bb_free_root` (`ext4_mb_free_metadata()`) and last erase (`ext4_free_data_in_buddy()`), and pin `ac_bitmap/buddy_folio` in `ext4_mb_use_best_found()` until `ext4_mb_release_context()`. Guard `kfree(bh)` with `bh != &bhs` in `ext4_mb_init_cache()`. Unlink `u.pa_tmp_list` before `call_rcu(&pa->u.pa_rcu, ...)` on `MB_GROUP_PA`, `flush_work(&sbi->s_discard_work)` before freeing `s_group_info`/`s_buddy_cache` in `ext4_mb_release()`, and call `rcu_barrier()` before destroying `ext4_pspace_cachep`. [F20, F24, F38, F45, F170, F171]

## API Contracts
- `ext4_add_nondir()` consumes `*inodep` (`*inodep = NULL`) on success and leaves `*inodep` non-NULL (after dropping `i_nlink`, orphan-adding, unlocking) for caller `iput()` on failure. Pass `EXT4_MAXQUOTAS_TRANS_BLOCKS()` to `ext4_new_inode_start_handle()` in `ext4_tmpfile()` and `ext4_whiteout_for_rename()`. `do_split()` releases `*bh`/`bh2` and sets `*bh = NULL` on error; `__ext4_read_dirblock()` returns `NULL` for holes at `block > 0` with `EITHER`/`DIRENT`; `ext4_find/lookup_entry()` returns `NULL` on miss, `ERR_PTR` on error, or `bh`. Never use `sizeof(struct ext4_dir_entry_2)`/`de++`, and pass `dir = NULL` to `ext4_dir_rec_len()` for `.`/`..` and `dx_root_limit()`. [F1, F3, F57, F59, F162, F163, F194]
- `read_mmp_block()` releases and zeroes `*bh` on error. `get_ext_path()` calls `ext4_free_ext_path(path)` before returning `ERR_PTR(-ENODATA)`. `mext_check_arguments()` checks starts/lengths/sums `< EXT_MAX_BLOCKS` and sub-page alignment; `move_extent_per_page()` returns `replaced_count` (`*err` via pointer) and commits `replaced_count > 0` blocks on `data_copy` even if `*err != 0`. `ext4_orphan_[file_]del()` supports `handle == NULL`. Use `ext4_put_io_end_defer()` in `ext4_end_bio()` or under an active `handle_t`. [F13, F17, F66, F69, F98, F176]
- `ext4_mb_new_blocks[_simple]()` must write `*errp` on all paths. `ext4_mb_get_buddy_page_lock()` zeroes folio pointers and leaves `bd_buddy_folio == NULL` when `PAGE_SIZE / s_blocksize >= 2`. `ext4_mb_mark_context()` callers skip in-core updates only when `err && changed == 0`. Convert cluster fields (`fe_start/len`, `pa_len/free`) via `EXT4_C2B()`/`EXT4_NUM_B2C()` when combining with block offsets. Use `mb_*_bit()` on `mb_find_buddy()` pointers, and decrement `v` in `ext4_mb_seq_groups/structs_summary_show()`. [F50, F54, F55, F56, F159, F214]

## Error Handling
- Call `brelse(bh2)` before `goto journal_error` in `ext4_dx_add_entry()`; `brelse()` `bh_use[ra_ptr..ra_max-1]` and reset `ra_max = 0` on batch error in `__ext4_find_entry()`; intercept `ERR_BAD_DX_DIR` in callers of `dx_probe()`/`ext4_dx_find/add_entry()`; stop non-NULL `ext4_journal_current_handle()` on `ext4_new_inode_start_handle()` error; and on `ext4_rename()` failure with `whiteout`, call `ext4_resetent()`, drop link/dirty/orphan-add/unlock `whiteout`, stop `handle`, and `iput(whiteout)`. [F4, F5, F6, F58, F61]
- In `ext4_orphan_add/del()`, `brelse(iloc.bh)` if skipping `ext4_mark_iloc_dirty()`, and `list_del_init(&ei->i_orphan)` on `ext4_orphan_add()` error. In `ext4_init_orphan_info()`, check `IS_ERR(ob_bh)` and `!ob_bh`, and decrement `i` at `out_free:`. Clear `s_mmp_tsk = NULL` on `kthread_run()` error in `ext4_multi_mount_protect()`. Pass `(donor_inode, orig_inode)` and `&err2` to `ext4_swap_extents()` and set `replaced_count = 0` at `repair_branches:` in `move_extent_per_page()`. [F11, F64, F70, F130]
- In `ext4_mb_new_blocks()`, call `ext4_mb_pa_put_free(ac)` if `ac_pa` is unlinked; call `ext4_discard_allocated_blocks(ac)` before `ac_b_ex.fe_len = 0` at `errout:`; and refund `inquota - ar->len` and `reserv_clstrs` (if `ar->len == 0`) when `!EXT4_MB_DELALLOC_RESERVED` at `out:`. Check `!IS_ERR_OR_NULL(folio)` at `err:` in `ext4_mb_load_buddy_gfp()`, NULL-check xarrays in `ext4_mb_avg_fragment_size/largest_free_orders_destroy()`, NULL-check `ext4_get_group_info()`, and save the first negative error from `ext4_mb_good_group_nolock()` in `ac_first_err`. [F21, F22, F23, F48, F49, F51, F52]

## External Contracts
- Keep `"Buffer I/O error on device %pg, logical block %llu\n"` in `buffer_io_error()`. Redirty and pass `keep_towrite = true` in `ext4_bio_write_folio()` when skipped dirty/`jbddirty` buffers remain. On `IS_CASEFOLDED(dir)`, return `NULL` without `d_splice_alias()` on lookup miss and `d_invalidate()` on unlink/rmdir; validate `ext4_valid_inum()` and `ino != dir->i_ino` and map `-ESTALE` to `-EFSCORRUPTED` in `ext4_lookup()`. Clear `buffer_uptodate(*bh)` and verify magic/csum in `read_mmp_block()`; reject `i_size > 8 << 20` and verify magic/csum in `ext4_init_orphan_info()`; and convert `fstrim_range` byte fields to blocks/clusters and write `range->len` back in bytes in `ext4_trim_fs()`. [F115, F196, F198, F201, F206, F213, F216]

## Known Pitfalls
- In `ext4_dx_add_entry()`, restart `dx_probe()` after upper index split or root level add, and rebase `frame->at`/`entries`/`bh` to `bh2` when `at - entries >= icount1`. Test `if (i >= 0)` and reject `split == 0` in `do_split()`. Restore `fname_crypto_str.len` per entry in `htree_dirblock_to_tree()`; zero deleted dirents from `&de->name_len` in `dx_move_dirents()`/`ext4_generic_delete_entry()`; compute `ext4_next_entry()` before mutating `to->rec_len` or `memmove()` in `dx_pack_dirents()`; and re-lookup `old.de` in `ext4_rename_delete/resetent()`. [F87, F88, F89, F99, F164, F165, F167]
- Use `extent_logical_end()`/`pa_logical_end()` (`loff_t`) to avoid 32-bit wrap; cast `fe_logical`, `EXT4_C2B(sbi, fe_len)`, `orig_page_offset`, and `uint64_t` `trimmed` to 64-bit before `<<`; and use `do_div()` on `ext4_fsblk_t / s_stripe`. Use unsigned `ext4_group_t` and wrap with `*group + 1 >= ngroups` in `next_linear_group()`. In `ext4_mb_discard_preallocations_should_retry()`, allow first retry via `!(ac_flags & EXT4_MB_STRICT_CHECK)` and overwrite `*seq` with `ext4_get_discard_pa_seq_sum()`. `ext4_end_bio()` overwrites `bio->bi_private` via `xchg(&io_end->bio, bio)` on deferred completion; and `ext4_bio_write_folio()` must use `GFP_NOWAIT` (or `ext4_io_submit()` first) for fscrypt bounce allocation when `io->io_bio` is non-NULL. [F141, F142, F143, F144, F153, F158, F173, F178]
