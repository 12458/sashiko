# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 1)

Implements the foundational hardware interface and management services of the mlx5 core driver: firmware commands (`cmd.c`), DMA/doorbell allocation (`alloc.c`), CQs (`cq.c`), auxiliary devices and devlink (`dev.c`, `devlink.c`), DPLL (`dpll.c`), diagnostics (`diag/`), and Ethernet (`en/`) queue parameters, HTB QoS, header modification, ID mapping, port config, and health recovery.

## Architecture & Data Flow

- In `cmd.c`, `1 << cmd->vars.log_sz` in `mlx5_cmd_enable` must not exceed `MLX5_MAX_COMMANDS` (32) (`cmd->vars.bitmask` is one `unsigned long`). Slot `cmd->vars.max_reg_cmds` is reserved for `page_queue` (`MLX5_CMD_OP_MANAGE_PAGES`), while `cmd_alloc_index()` searches `[0, cmd->vars.max_reg_cmds)`. `alloc_token()` must skip 0 on `u8` wraparound. `free_cmd_page` must pass unaligned `cmd->cmd_alloc_buf`, `cmd->alloc_dma`, and `cmd->alloc_size` (not aligned `cmd_buf`/`dma`) to `dma_free_coherent`. [F943, F984, F990, F991]
- When `alloc_msg` reuses a cached `mlx5_cmd_msg`, it must set `msg->len = in_size`, and `free_msg` must return messages with `msg->parent` to `msg->parent->head` under `msg->parent->lock` instead of `mlx5_free_cmd_msg`. Per-command traversals (`calc_chain_sig`, `verify_signature`, `dump_command`) must bound iteration to `mlx5_calc_cmd_blocks(msg)`, whereas `mlx5_free_cmd_msg` iterates `msg->next` until `NULL`. [F875, F962]
- In `alloc.c`, `mlx5_frag_buf_alloc_node` fragments must align to `1 << buf->page_shift`; on alignment failure, fragment `i` must be freed with `frag_sz` before `err_free_buf` (which frees `0 .. i - 1` using `PAGE_SIZE`). `buf->size` and `buf->npages` must not change before `mlx5_frag_buf_free`. `mlx5_fill_page_frag_array_perm` requires `!(perm & 0xfc)`. `mlx5_db_pgdir.bitmap` uses inverted polarity (`1` = free, `0` = used); in `mlx5_alloc_db_from_pgdir`, `pgdir->db_page` (`__be32 *`) adds `offset / sizeof(*pgdir->db_page)` while `pgdir->db_dma` adds byte `offset`. [F869, F948, F949, F985, F987]
- In `dev.c`, `is_mp_supported` must exclude `is_ib_rep_supported(dev)` and `mlx5_rdma_supported` must exclude both `is_ib_rep_supported` and `is_mp_supported`. In `mlx5_detach_device` with `suspend == true`, an adev is suspended in place only if `is_enabled()` (if present) is true, `adev->dev.driver` is bound, and `adrv->suspend` exists; otherwise `del_adev` must delete it and set `priv->adev[i] = NULL`. In `devlink.c`, conditional `mlx5_devlink_*_params_register` and `*_unregister` pairs must use identical capability checks. [F965, F1010, F1011]
- In `mlx5_fw_tracer_start`, `mlx5_fw_tracer_set_mtrc_conf` must reset `tracer->buff.consumer_index = 0` and `mlx5_fw_tracer_set_mtrc_ctrl` (when `status` != 0) must reset `tracer->last_timestamp = 0`. In `mlx5_tracer_handle_timestamp_trace`, when `str_frmt->timestamp >= (timestamp_event.timestamp & MASK_6_0)`, decrement `timestamp_event.timestamp` before masking with `MASK_52_7`. [F939, F983]
- In `mlx5_rsc_dump_trigger`, `cmd->cmd` is both input and output to `mlx5_core_access_reg`, so `in_seq_num` must be read before the call and checked against `out_seq_num`. In `mlx5_rsc_dump_read_menu_sgmt`, advance by `MLX5_RSC_DUMP_MENU_HEADER_SIZE` only when `start_idx == 0`, and stop when `size += MLX5_ST_SZ_BYTES(resource_dump_menu_record)` reaches `>= read_size`. [F941, F953]
- In `en/htb.c`, `mlx5e_htb_node_modify` must call `mlx5e_htb_update_children` whenever `node->max_average_bw` changes. `mlx5e_htb_convert_rate` must check `parent->classid != MLX5E_HTB_CLASSID_ROOT` before dereferencing `parent->parent`. `mlx5e_htb_leaf_del` must keep `qos_used_qids` contiguous (for `mlx5e_htb_cur_leaf_nodes`) by moving the highest `moved_qid` into a deleted lower slot. Before deleting or reassigning a node's `qid` (`mlx5e_htb_leaf_to_inner` rollback, `mlx5e_htb_leaf_del`, `mlx5e_htb_leaf_del_last`), set the old node's `qid` to `MLX5E_QOS_QID_INNER`, and on reassignment close its SQ and call `mlx5e_reset_qdisc`. [F882, F926, F927, F929, F971]
- In `en/params.c`, when `params->xdp_prog` is set on striding RQ, `mlx5e_build_icosq_log_wq_sz` must reserve `wqebbs` for the RQ plus max `mlx5e_mpwrq_total_umr_wqebbs` across all XSK frame shifts and UMR modes, using `DIV_ROUND_UP(wqebbs * MLX5_SEND_WQE_BB, useful_space)` (accounting for page-boundary NOPs). `mlx5e_mpwrq_umr_mode` must check `oversized` before `unaligned`; `mlx5e_mpwrq_pages_per_wqe` returns >= 2 for `ALIGNED`, and `mlx5e_mpwrq_mtts_per_wqe` adds 1 guard page before aligning. [F930, F955, F973, F982]
- With `params->xdp_prog`, `mlx5e_rx_get_linear_stride_sz` and `mlx5e_mpwqe_get_log_stride_size` require stride >= `PAGE_SIZE`. `mlx5e_rx_get_linear_sz_skb` requires `no_head_tail_room == true` when XSK is enabled or on non-linear striding RQ with XDP. In `mlx5e_build_rq_frags_info` for non-linear cyclic RQs, `frag_stride` is `PAGE_SIZE` with XDP (without XDP, frag 0 includes headroom and `skb_shared_info` before `roundup_pow_of_two`), `wqe_index_mask` is `(WQEs per page) - 1`, and `wqe_bulk >= wqe_index_mask + 1`. [F956, F1048, F1049, F1050]
- In `mlx5e_fs_tt_redirect_udp_destroy` and `mlx5e_fs_tt_redirect_any_destroy`, restore default TTC destinations via `mlx5_ttc_fwd_default_dest` (`fs_udp_disable` / `fs_any_disable`) before destroying redirect tables. [F932]
- In `en/port.c`, `mlx5e_port_set_sbcm` and `mlx5e_port_set_priority2buffer` must query the register first to preserve unmodified fields. Accessing `MLX5_REG_PPLM` requires both `MLX5_CAP_GEN(dev, pcam_reg)` and `MLX5_CAP_PCAM_REG(dev, pplm)` and stopping when `mlx5e_is_fec_supported_link_mode` is false. `enum mlx5e_fec_supported_link_mode` must stay ordered by per-lane speed and matched in `mlx5e_fec_admin_field` and `mlx5e_get_fec_cap_field`; `mlx5e_remap_fec_conf_mode` must check `200G` before `50G`, and `mlx5e_set_fec_mode` must reset `conf_fec = fec_policy` each iteration. [F936, F942, F975, F1017]

## Synchronization

- `mlx5_dma_zalloc_coherent_node` must hold `dev->priv.alloc_mutex` around `set_dev_node(device, node)`, `dma_alloc_coherent`, and restoring `original_node`. [F870]
- In `cmd.c`, when `callback` is non-NULL, `cmd_alloc_ent` and `cmd_exec` must use `GFP_ATOMIC`, and `mlx5_cmd_exec_cb` must use `down_trylock` on `unprivileged_sem` and `throttle_sem`. Non-zero UIDs not in `privileged_uids` (when `mlx5_has_privileged_uid(dev)`) must acquire `unprivileged_sem` and release it on completion. After `iowrite32be` rings `&dev->iseg->cmd_dbell` in `cmd_work_handler`, do not dereference `ent` unless polling (using local copies); `poll_timeout` must `READ_ONCE(ent->lay->status_own)` followed by `rmb()` before `mlx5_cmd_comp_handler`. [F872, F889, F1021, F1056]
- `mlx5_cmd_change_mod` and `mlx5_cmd_allowed_opcode` must acquire all `max_reg_cmds` counts of `sem` and `pages_sem`, and `mlx5_cmd_use_polling` must switch to `CMD_MODE_POLLING` before unregistering `dev->cmd.nb`. `mlx5_cmd_flush` must use `while (down_trylock(...))` calling `mlx5_cmd_trigger_completions` and `cond_resched()`. `mlx5_cmd_trigger_completions` must call `cmd_ent_get` on active entries under `alloc_lock` before unlocking and calling `mlx5_cmd_comp_handler`, then `cmd_ent_put`. `stats->lock` must use `spin_lock_irq`/`spin_lock_irqsave`, and `average_read` must guard `div64_u64(stats->sum, stats->n)` with `if (stats->n)` under `stats->lock`. [F874, F894, F963, F981, F1024]
- `mlx5_attach_device`, `mlx5_detach_device`, `mlx5_register_device`, and `mlx5_unregister_device` require the devlink lock (`devl_assert_locked`) and `mlx5_devcom_comp_lock(dev->priv.hca_devcom_comp)` before mutating `priv.flags` or `priv.adev`. `mlx5_crdump_collect` must lock `mlx5_vsc_gw_lock` before `MLX5_SEMAPHORE_SW_RESET` and unlock in reverse order on all paths. [F880, F898]
- In `en/htb.c`, mutating `qos_used_qids` or `qos_tc2node` requires holding `priv->state_lock`. Live `node->qid` updates must set `WRITE_ONCE(node->qid, MLX5E_QOS_QID_INNER)` before closing the old SQ and use `WRITE_ONCE` for the new `qid`, pairing with `READ_ONCE` under RCU in `mlx5e_htb_get_txq_by_classid`. [F903, F1036]

## Object Lifetimes

- In `cmd_exec`, when `callback` is non-NULL, `cmd_exec` frees `inb` and `outb` only if `mlx5_cmd_invoke` fails. In `mlx5_cmd_comp_handler`, call `cmd_ent_put(ent)` only when `!forced`, `mlx5_cmd_is_down(dev)`, or `!opcode_allowed(cmd, ent->op)` so timed-out slots stay reserved. `mlx5_cmd_exec_cb_handler` must copy `work->ctx`, `throttle_locked`, and `unpriv_locked` to locals before `work->user_callback(status, work)` and never dereference `work` after. [F871, F873, F876]
- `mlx5_create_cq` must init `refcount`, `free`, `comp`, and `tasklet_ctx` before `mlx5_eq_add_cq`; `mlx5_core_destroy_cq` must call `mlx5_eq_del_cq`, `DESTROY_CQ`, and `synchronize_irq(cq->irqn)` before `mlx5_cq_put` and `wait_for_completion(&cq->free)`. `mlx5_cq_tasklet_cb` must use `list_del_init(&mcq->tasklet_ctx.list)` and reschedule if `process_list` is non-empty. [F895, F964]
- In `add_adev`, free `madev` with `kfree` if `auxiliary_device_init` fails, but use `auxiliary_device_uninit` (without `kfree`) if `auxiliary_device_add` fails; callers (`mlx5_attach_device`, `add_drivers`) must reset `priv->adev[i] = NULL` on `IS_ERR`. In `mlx5_ec_cleanup`, non-eswitch-manager ECPFs must call `mlx5_host_pf_cleanup` before `mlx5_wait_for_pages` for `MLX5_HOST_PF`/`MLX5_VF`. `mlx5_dpll_remove` must call `cancel_delayed_work_sync`, `mlx5_dpll_mdev_netdev_untrack`, and `destroy_workqueue` before unregistering DPLL pin/device. `mlx5e_pcie_cong_event_init` must init fields before `mlx5_eq_notifier_register`, and cleanup must unregister and `cancel_work_sync` before destroying `obj_id`. [F878, F887, F907, F914, F1019]
- In `fw_tracer.c`, `mlx5_tracer_handle_timestamp_trace` and `mlx5_fw_tracer_clean_ready_list` must `list_del(&str_frmt->list)` without freeing `str_frmt` (freed via `tracer->hash`), and `mlx5_fw_tracer_destroy` / `mlx5_fw_tracer_recreate_strings_db` must cancel `read_fw_strings_work` and clean both `ready_strings_list` and `hash` before `mlx5_fw_tracer_free_strings_db`. [F934, F969]
- In `mlx5e_mod_hdr_attach`, always set `mh->compl_result` and call `complete_all(&mh->res_ready)` after `mlx5_modify_header_alloc`, and only call `mlx5_modify_header_dealloc` in `mlx5e_mod_hdr_detach` when `compl_result > 0`. `mlx5e_mod_hdr_alloc` and `mlx5e_mod_hdr_dealloc` must respect `is_static` (zeroing grown tail on `krealloc`, skipping `kfree` when `is_static`), and callers must increment `num_actions` after each alloc and re-fetch pointers via `mlx5e_mod_hdr_get_item`. In `mapping_remove`, when `--mi->cnt == 0` with `delayed_removal`, remove from `ctx->ht` immediately but defer `xa_erase` and `kfree_rcu` to `dwork` (flushed before `xa_destroy`). [F883, F884, F885, F920, F933, F999]

## API Contracts

- In synchronous `mlx5_cmd_invoke`, negative returns are driver errors, positive returns are `ent->status` (converted via `deliv_status_to_err`), and 0 is success; `page_queue` commands with `callback != NULL` return `-EINVAL`. Callers of `mlx5_cmd_cleanup_async_ctx` must stop `mlx5_cmd_exec_cb` submissions first, and async callbacks must not sleep. Every `MLX5_CMD_OP_*` must be handled in `mlx5_internal_err_ret_value` and `mlx5_command_str`. [F893, F909, F924, F960, F961, F1022]
- Buffer/input contracts: `mlx5_core_query_cq` requires `out` >= `MLX5_ST_SZ_BYTES(query_cq_out)`; `mlx5_crdump_collect` requires `cr_data` >= `crdump_size`; `mlx5e_port_query_pbmc`/`set_pbmc` require `MLX5_ST_SZ_BYTES(pbmc_reg)` and `priority2buffer` requires 8 `u8`s; `mlx5_rsc_dump_next` returns `< 0` on error, `1` for more, `0` when done (use signed `int`); `mlx5_cmd_pcie_cong_event_query` ORs into `*state` (caller must zero-init); `mlx5e_channels_get_ptp_rqn` returns `false` without setting `*rqn` if inactive, while `mlx5e_channels_get_xsk_rqn` requires `mlx5e_channels_is_xsk`; `mapping_add` uses 1-based `XA_LIMIT(1, ctx->max_id)` and `mapping_add`/`find`/`create_for_id` require consistent `ctx->data_size`; `mlx5e_create_devlink` must use `devlink_alloc_ns` with parent netns and `devl_nested_devlink_set`. [F910, F918, F925, F959, F988, F994, F997, F1001, F1047]

## Error Handling

- `mlx5_cmd_do` returns `-EREMOTEIO` when firmware sets `outbox.status != MLX5_CMD_STAT_OK` (translated by `mlx5_cmd_check`/`mlx5_cmd_exec`). `cmd_status_print` must skip `mlx5_cmd_out_err` when `in_to_uid(in) != 0`, or for `DESTROY_MKEY`, `CREATE_UCTX`, or `MLX5_CMD_STAT_NOT_READY`. Guard `dev->rsc_dump` and `health->vnic_reporter` with `IS_ERR_OR_NULL`. `mlx5_devlink_trap_action_set` must restore `action_orig` on `NOTIFY_BAD`. In `mlx5e_htb_leaf_del_last` (`force == true`), preserve `mlx5_qos_create_leaf_node` failure in `saved_err` across `mlx5_qos_destroy_node`. [F908, F911, F913, F917, F931, F1057]

## External Contracts

- In `mlx5_alloc_cmd_msg`, chain `mlx5_cmd_prot_block` in ascending big-endian `block_num` `0 .. n - 1` from `msg->next` with `cpu_to_be64(next->dma)`; `calc_block_sig` must compute `ctrl_sig` before `sig`. `mlx5_devlink_reload_up` on `FW_ACTIVATE` without `NO_RESET` must set `BIT(DEVLINK_RELOAD_ACTION_DRIVER_REINIT)` in `*actions_performed`. `mlx5_dpll_clock_quality_level_get` must populate `qls` via `__set_bit`. `mlx5e_build_rq_param` must subtract `MLX5_MPWQE_LOG_NUM_STRIDES_BASE` and `MLX5_MPWQE_LOG_STRIDE_SZ_BASE`. `mlx5e_htb_convert_rate`/`ceil` must use `div_u64`/`div64_u64` (checking `parent->max_average_bw != 0`) and clamp `*max_average_bw` to >= 1. `mlx5e_health_rsc_fmsg_dump` must chunk binary puts to `MLX5_HEALTH_DEVLINK_MAX_SIZE` (1024) via `mlx5e_health_rsc_fmsg_binary`. [F922, F923, F945, F946, F980, F1044, F1046, F1055]

## Known Pitfalls

- Pass `1ULL << ent->idx` (not `1 << ent->idx`) to `mlx5_cmd_comp_handler` to avoid sign-extension into bit 32 (`MLX5_TRIGGERED_CMD_COMP`). Use `mlx5_nb_cof` for `mlx5_eq_notifier_register` callbacks and `container_of` for `mlx5_blocking_notifier_register`. In `debugfs.c`, `d->fields[i].i` must equal `i` in trailing flexible array `fields[]`. In `mlx5_devlink_serial_numbers_put`, `kstrndup` VPD slices by `kw_len`. Tracepoint helpers (`parse_fs_hdrs`, `parse_fs_dst`, `parse_action`) must call `trace_seq_putc(p, 0)`. [F950, F976, F993, F995, F1002]
- `mlx5_fw_tracer_cleanup` must use non-blocking `cancel_work(&tracer->update_db_work)` (called from `update_db_work`). `mlx5_tracer_get_num_of_params` must scan `"%llx"` with cursor `pstr`, advance `str = substr + 1` when counting `"%"`, and `mlx5_tracer_handle_string_trace` must reject `last_param_num > TRACER_MAX_PARAMS` (7) before writing `params`. `mlx5_fw_tracer_handle_traces` must copy blocks to `tmp_trace_block` and verify `last_timestamp` before parsing; `poll_trace` must cast `timestamp_high`/`mid` to `u64` before shifting. In `mlx5e_mpwqe_get_log_rq_size` and `mlx5e_rx_mpwqe_is_linear_skb`, check `u8` operands before subtracting to avoid underflow. [F879, F940, F952, F954, F968, F977]
