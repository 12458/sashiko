# IO_URING — (top level)

Implements the core `io_uring` engine (`io_uring.c`), worker pool (`io-wq.c`), shared types, memory mapping (`memmap.c`), provided buffers (`kbuf.c`), and auxiliary ops (`cancel.c`, `futex.c`, `fs.c`, `msg_ring.c`, `eventfd.c`, `napi.c`, `cmd_net.c`, `mock_file.c`).

## Architecture & Data Flow
- In `struct io_kiocb`, `req->kbuf` and `req->buf_node` share a union valid only under `REQ_F_BUFFER_SELECTED` and `REQ_F_BUF_NODE`. `req->creds` and `req->apoll` are not cleared on recycle (KASAN-poisoned), requiring `REQ_F_CREDS` and `REQ_F_POLLED`. In `struct io_buffer_list`, `buf_list` and `buf_ring` (with `region`) share a union discriminated by `bl->flags & IOBL_BUF_RING`. `req_cachep` whitelists only `req->cmd.data` (56B) for usercopy, so direct `copy_from/to_user()` into `io_kiocb` must stay within `req->cmd.data`. [F47, F48, F50, F137]
- `req->flags` (`io_req_flags_t`, `u64 __bitwise`) reserves bits 0..7 for UAPI `IOSQE_*`; internal `REQ_F_*_BIT` start at bit 8 (`REQ_F_FAIL_BIT`), use `IO_REQ_FLAG(bitno)` (`BIT_ULL`), and `__REQ_F_LAST_BIT <= 64`. `io_fixed_file_set()` shifts `io_file_get_flags(file)` (`FFS_NOWAIT | FFS_ISREG`) by `REQ_F_SUPPORT_NOWAIT_BIT` into the low two bits of `node->file_ptr`, so `REQ_F_ISREG_BIT == REQ_F_SUPPORT_NOWAIT_BIT + 1` and `node->file_ptr` must be masked via `io_slot_file()`. [F60, F121, F141]
- Even with `ctx->task_complete` or `IORING_SETUP_SINGLE_ISSUER`, `ctx->submitter_task` can be `NULL` (`IORING_SETUP_R_DISABLED`); check non-NULL before dereferencing or queuing `task_work`. [F52]
- Before `__io_cqring_overflow_flush()` drops `completion_lock` and `uring_lock` with `cq_overflow_list` non-empty, set `ctx->cqe_sentinel = ctx->cqe_cached` to force CQE emitters into `io_cqe_cache_refill()`. Empty/non-empty transitions of `cq_overflow_list` under `completion_lock` must update `IO_CHECK_CQ_OVERFLOW_BIT` and `IORING_SQ_CQ_OVERFLOW` in lockstep. Before `io_req_post_cqe()` posts an aux CQE, flush `submit_state.compl_reqs` via `__io_submit_flush_completions(ctx)` and set `submit_state.cq_flush = true`. [F64, F65, F68]
- On `IORING_SETUP_CQE_MIXED` rings, 32B CQEs set `IORING_CQE_F_32` (`ctx_cqe32_flags()`) and advance `cqe_cached` and `cached_cq_tail` by 2 slots (emitting an `IORING_CQE_F_SKIP` pad via `io_fill_nop_cqe()` if wrapping), whereas `IORING_SETUP_CQE32` advances `cached_cq_tail` by 1. For 32B overflow CQEs, `io_alloc_ocqe()` adds `sizeof(struct io_uring_cqe)` to `sizeof(struct io_overflow_cqe)` and `__io_cqring_overflow_flush()` copies `2 * sizeof(struct io_uring_cqe)`. Under `IORING_SETUP_SQE128`, shift `ctx->sq_sqes` indices left by 1 and use `uring_sqe_size(ctx)`. [F66, F132, F135]
- In `io_submit_sqes()`, if `io_submit_sqe()` fails and `!(ctx->flags & IORING_SETUP_SUBMIT_ALL)`, decrement `left--` before breaking out of `do { ... } while (--left)`. In `io_submit_fail_init()`, failed requests with `IO_REQ_LINK_FLAGS` must be appended to `submit_state.link` and return `0`. Use `req_set_fail()` so `REQ_F_CQE_SKIP` becomes `REQ_F_SKIP_LINK_CQES`. [F78, F114, F115]
- In `struct io_uring_buf_ring`, the 16B header (`tail` at offset 14) unions with `bufs[0]`, so `io_register_pbuf_ring()` must size it via `flex_array_size(br, bufs, reg.ring_entries)` (not `struct_size()`) and enforce `reg.ring_entries` is a power of 2 `< 65536`. In `io_install_fixed_file()`, call `io_file_bitmap_set()` only when `io_reset_rsrc_node()` returns `false`, and pair `io_reset_rsrc_node()` with `io_file_bitmap_clear()` in `io_fixed_fd_remove()`. [F75, F92, F139]
- In `io-wq.c`, `wq->hash_tail[hash]` keeps same-hash items contiguous in `acct->work_list`: `io_get_next_work()` clears `wq->hash_tail[hash] = NULL` when cutting `[work, tail]`, and when a hash bit is set in `wq->hash->map`, fast-forwards `node` to `&tail->list`; `io_wq_remove_pending()` updates `wq->hash_tail[hash]` to `prev_work` (if same hash) or `NULL`. [F76, F103]
- `ctx->personalities` uses `XA_FLAGS_ALLOC1` (1-based). `io_init_req()` must verify `req->opcode < IORING_OP_LAST` before `io_check_restriction()`. `io_uring_fill_params()` must reject zero `entries` / `p->cq_entries` and cap to `IORING_MAX_ENTRIES` / `IORING_MAX_CQ_ENTRIES` before `roundup_pow_of_two()`. Compare `rings->cq.tail` and `iowq->cq_tail` via signed `int` subtraction in `io_should_wake()` / `io_cqring_wait()`. In `io_cancel_req_match()`, `match_user_data` defaults to `true` when neither `FD` nor `OP` is set (unless `ANY`), and otherwise requires `IORING_ASYNC_CANCEL_USERDATA`. [F97, F107, F127, F129, F142]

## Synchronization
- `io_ring_submit_lock()` locks `ctx->uring_lock` only if `IO_URING_F_UNLOCKED` is set in `issue_flags`; pair with `io_ring_submit_unlock()` using the same bit, and pass core `issue_flags` through to `io_uring_cmd_done*()` and `io_uring_cmd_mark_cancelable()`. `io_alloc_req()`, `__io_alloc_req_refill()`, `io_cache_alloc/free()`, and `io_uring_alloc_async_data()` require `ctx->uring_lock`. [F5, F61, F152]
- `io_uring_poll()` must never take `ctx->uring_lock`, and `io_uring_show_fdinfo()` must only use `mutex_trylock(&ctx->uring_lock)`. When `io_msg_ring` targets `target_ctx`, bounce via `task_work` to `target_ctx->submitter_task` if `target_ctx->task_complete` is set, and otherwise use `io_lock_external_ctx()` before locking `target_ctx->uring_lock`. [F80, F169]
- CQE helpers (`io_get_cqe_overflow`, `io_cqe_cache_refill`, `io_fill_cqe_req`, `io_fill_cqe_aux`) require `ctx->completion_lock` unless `ctx->lockless_cq` is set (`ctx->uring_lock` held, and on `submitter_task` if `task_complete`). On `IOPOLL` rings, add to `ctx->iopoll_list` via `io_iopoll_req_issued()` only after `def->issue` returns `IOU_ISSUE_SKIP_COMPLETE`, locking `ctx->uring_lock` if `IO_URING_F_UNLOCKED`. Walking `req->link` when `REQ_F_LINK_TIMEOUT` is set (`io_match_task_safe`, `io_prep_async_link`) requires `raw_spin_lock_irq(&ctx->timeout_lock)`. [F23, F28, F29]
- `io_req_local_work_add()` must hold `guard(rcu)()` while reading `first_req->nr_tw` (`SLAB_TYPESAFE_BY_RCU`) and updating `ctx->work_llist.first` via `try_cmpxchg()`, pairing with `atomic_set(&ctx->cq_wait_nr, nr_wait)` before `set_current_state(TASK_INTERRUPTIBLE)` in `io_cqring_wait()`. `ctx->napi_list` / `napi_ht` mutations require `ctx->napi_lock` and RCU primitives (`kfree_rcu()`), while lockless lookups require `scoped_guard(rcu)`. `io_eventfd_signal()` dereferences `ctx->io_ev_fd` under `guard(rcu)()`, pins `ev_fd->refs`, and holds `ctx->completion_lock` for `ev_fd->last_cq_tail`; `io_eventfd_put()` uses `call_rcu()`. [F38, F39, F40]
- In `io_worker_handle_work()`, set `worker->cur_work` under `worker->lock` before dropping `acct->lock`, and hold `worker->lock` (inside `acct->workers_lock`) in `io_wq_worker_cancel()`. `io_acct_run_queue()` returns `true` with `acct->lock` held and `false` unlocked. In `io_acct_cancel_pending_work()`, return immediately after dropping `acct->lock` for `io_run_cancel()`. RCU readers of `acct->free_list` / `all_list` must pin workers via `io_worker_get()`, list mutations require `acct->workers_lock`, and `io_worker_exit()` uses `kfree_rcu(worker, rcu)`. [F24, F45, F102, F158]
- Read user-mapped `struct io_uring_sqe` fields with `READ_ONCE()`. Use `smp_load_acquire()` for `rings->sq.tail` and `br->tail`, and `smp_store_release()` for `rings->cq.tail` and `rings->sq.head`. Initialize regions and buffer lists before publishing under `ctx->mmap_lock` (`io_create_region_mmap_safe()`, `io_buffer_add_list()`). In `io_ring_buffer_select()`, if `IO_URING_F_UNLOCKED` or `!io_file_can_poll(req)`, commit `IOBL_BUF_RING` buffers immediately via `io_kbuf_commit()` under `ctx->uring_lock` and set `sel.buf_list = NULL`. [F74, F84, F161, F162]

## Object Lifetimes
- Setting `req->async_data` requires `REQ_F_ASYNC_DATA`, and freeing it before `io_clean_op()` must clear both via `io_req_async_data_free/clear()`. In `fs.c`, `.prep` sets `REQ_F_NEED_CLEANUP` after `getname()` and issue handlers must clear it once `do_renameat2()` / `do_unlinkat()` / `do_mkdirat()` / `do_symlinkat()` / `do_linkat()` consumes the filename. [F1, F7]
- Requests targeting `io_is_uring_fops(file)` or relying on `current->mm` (`io_futex_prep()`, `io_futexv_prep()`) must call `io_req_track_inflight(req)`; `io_install_fixed_file()` must reject `io_is_uring_fops(file)` (`-EBADF`). `io_file_get_normal()` takes an `fget()` ref dropped by `io_put_file()` only when `!REQ_F_FIXED_FILE`, whereas `io_file_get_fixed()` uses `req->file_node` refs, so assigning a fixed file to `req->file` must set `REQ_F_FIXED_FILE`. [F2, F8, F164]
- `__io_alloc_req_refill()` takes `ctx->refs` and increments `nr_req_allocated`: return aborted `io_alloc_req()` requests via `io_req_add_to_cache()` (never `kmem_cache_free()`), call `__io_req_caches_free(ctx)` in `io_queue_deferred()` before comparing `nr_req_allocated != nr_drained`, and adjust `nr_drained` by `io_linked_nr(req)` on `defer_list` changes. Free remote `msg_ring` requests with `kfree_rcu(req, rcu_head)`. Return unused `io_get_task_refs(left)` refs via `current->io_uring->cached_refs += left` in `io_submit_sqes()`. `io_wq_submit_work()` holds an extra ref dropped by `io_wq_free_work()`, required by `io_req_complete_post()` (`IO_URING_F_IOWQ` only). In `__io_fallback_tw()`, pair `percpu_ref_get/put(&last_ctx->refs)` regardless of `sync`, gating only `flush_delayed_work()` on `sync`. [F4, F10, F11, F17, F69, F144]
- `io_uring_create()` must finish `ctx` setup before installing `file`; errors before `io_uring_get_file(ctx)` call `io_ring_ctx_wait_and_kill(ctx)`, and errors after jump to `err_fput` (`fput(file)`). `io_ring_ctx_wait_and_kill()` kills `ctx->refs` and flushes `fallback_work` before `io_ring_exit_work()`, which waits for `ctx->ref_comp`, drains `ctx->tctx_list` (calling `list_rotate_left()` before `task_work_add()`), and calls `synchronize_rcu()` (`DEFER_TASKRUN`) before `io_ring_ctx_free()`. [F14, F22, F25, F105]
- In `io_wq_create()`, failures after `get_task_struct(data->task)` must call `put_task_struct(wq->task)`. `io_wq_put_and_exit()` requires `IO_WQ_BIT_EXIT` and runs `io_wq_exit_workers()` before `io_wq_destroy()`. In `io_wq_cancel_tw_create()`, call `kfree(worker)` only when `cb->func == create_worker_cont`. `io_create_region()` sets `mr->nr_pages` only after `__io_account_mem()` succeeds, and `mr->pages` is assigned only after all pages are acquired (never `ERR_PTR`); `io_free_region()` unpins/releases `mr->pages`, `vunmap`s, unaccount mem, and zeroes `*mr`. [F3, F12, F18, F26, F53]

## API Contracts
- `io_fixed_fd_install()` calls `fput(file)` on error, whereas `__io_fixed_fd_install()` takes ownership only on success (`ret >= 0`). In `io_eventfd_signal()`, call `io_eventfd_put(ev_fd)` only if `skip` or `__io_eventfd_signal()` returns `true`. `io_alloc_cache_init()` / `io_futex_cache_init()` return `false` on success and `true` on error. `io_cache_alloc()` only zeroes `cache->init_clear` bytes on fresh/KASAN allocs (`apoll_cache` / `futex_cache` have `0`), so initialize fields above `init_clear` and any dirtied fields. [F6, F9, F42, F57]
- In `io_futexv_wait()`, when `futex_wait_multiple_setup()` returns `0`, call `__set_current_state(TASK_RUNNING)` before unlocking `ctx->uring_lock`. Use `io_cqe_overflow_locked()` (`GFP_ATOMIC`) under `ctx->completion_lock`, and `io_cqe_overflow()` (`GFP_KERNEL`) unlocked. Call `io_add_aux_cqe()` / `io_req_post_cqe*()` only from inline `task_work` under `ctx->uring_lock`. Mirror `#if defined(CONFIG_IO_URING)` signature changes in `cmd.h` and `io_uring.h` in `#else` stubs. [F16, F82, F153, F154]
- Verify `io_is_uring_fops(file)` before casting `file->private_data` in `io_uring_enter()`, `io_msg_ring()`, and `io_uring_sync_msg_ring()`. With `IORING_ENTER_EXT_ARG_REG`, `io_get_ext_arg_reg()` must check `offset % sizeof(long) == 0` and `offset + sizeof(struct io_uring_reg_wait) <= ctx->cq_wait_size`. Convert UAPI `min_wait_usec` and `busy_poll_to` via `* NSEC_PER_USEC` and `ktime_to_us()`. Check `napi_id_valid()`, reject `IOPOLL` in `io_register_napi()`, and restrict static NAPI ops to `IO_URING_NAPI_TRACKING_STATIC`. `io_uring_cmd_timestamp()` requires `IO_URING_F_CQE32`, dequeues only `skb_has_tx_timestamp()` && `skb->len == 0` SKBs, and splices unconsumed SKBs back under `q->lock`. Check `prot && prot->ioctl` in `io_uring_cmd_sock()` and pass `!!(issue_flags & IO_URING_F_COMPAT)` in sockopt handlers. [F62, F94, F143, F170, F171, F172]
- Call `io_submit_state_end()` on all exits from `io_submit_sqes()` after `io_submit_state_start()`. In `io_prep_async_work()`, hash `REQ_F_ISREG` files with `def->hash_reg_file` unless `O_DIRECT && FOP_DIO_PARALLEL_WRITE && !IOPOLL`, set `IO_WQ_WORK_UNBOUND` for `def->unbound_nonreg_file` when `!REQ_F_ISREG && !S_ISBLK`, and capture `get_current_cred()` when `!REQ_F_CREDS` (with `security_uring_override_creds()` in `io_init_req()` and `override_creds()` in `__io_issue_sqe()`). Spawn workers via `task_work_add` on `wq->task` and clamp to `cpuset_cpus_allowed()` / `RLIMIT_NPROC`. Enforce `io_uring_allowed()` / `security_uring_allowed()`, and require `CAP_SYS_ADMIN` + `add_taint(TAINT_TEST, ...)` in `mock_file.c`. [F166, F174, F180, F182, F183, F185]

## Error Handling
- On partial returns (`< nr_pages`) from `pin_user_pages_fast()` or `alloc_pages_bulk_node()`, unpin or release partial pages before `kvfree(pages)`. Validate page alignment, `check_add_overflow()`, `<= INT_MAX` page counts, and reject `IO_REGION_F_USER_PROVIDED` in `io_region_validate_mmap()`. Use overflow helpers in `rings_size()` (returning `SIZE_MAX`) and `io_provide_buffers_prep()` (checking `MAX_BIDS_PER_BGID` in `u64`). In `io_ring_buffers_peek()`, reject `len == 0` before dividing `(arg->max_len + len - 1) / len`. [F13, F93, F123, F124, F125, F126]
- Use `io_init_fail_req(req, err)` for errors before `def->prep()` in `io_init_req()` to zero `req->cmd.data`. In `io_cqring_wait()`, run local/task work after `io_cqring_wait_schedule()` errors and return `0` if `cq.head != cq.tail`. On `io_alloc_ocqe()` failure, increment `cq_overflow` and set `IO_CHECK_CQ_DROPPED_BIT` (`-EBADR`). [F55, F56, F184]

## External Contracts
- In `io_uring_enter()`, if `to_submit` succeeds (`ret > 0`), propagate `GETEVENTS` errors (`ret2`) only if `ret == 0`. Keep `struct io_uring_sqe` 64B with fixed-width `__u8`..`__u64` types (`BUILD_BUG_SQE_ELEM`). Reserve bits 24..31 (`0xff000000`) of `sqe->uring_cmd_flags` for kernel flags outside `IORING_URING_CMD_MASK`. Reject non-zero unused/resv/pad fields and unknown flags with `-EINVAL`. Clamp untrusted indices with `array_index_nospec()`. Reject non-zero `addr` in `io_uring_get_unmapped_area()` (`CONFIG_MMU`) and enforce `SHM_COLOUR` alignment. [F54, F83, F85, F95, F175, F179]

## Known Pitfalls
- Zero `req->big_cqe` after copying in `io_fill_cqe_req()` / `io_alloc_ocqe()`. Save `node = req->comp_list.next` before queuing/putting/caching `req` in `io_free_batch_list()`, and read `next_hashed = wq_next_work(work)` before `io_wq_submit_work()` / `io_wq_free_work()`. Cast `mr->nr_pages` to `size_t` before `<< PAGE_SHIFT`; cast `reg.bgid` to `unsigned long` before `<< IORING_OFF_PBUF_SHIFT`; use `min_t(u32, len, buf_len)` in `io_kbuf_inc_commit()`; and use `min_t(__u16, tail - head, UIO_MAXIOV)` in `io_ring_buffers_peek()`. In `io_ring_buffers_peek()`, on `!(bl->flags & IOBL_INC)`, set `arg->partial_map = 1` and truncate `buf->len` only on the first iov. Check `!PageHighMem(mr->pages[0])` before `page_address()` in `io_region_init_ptr()`. [F67, F71, F101, F104, F119, F120, F122, F130, F147]
- Store `io_acct_activate_free_worker()` in `activated_free_worker` (not `do_create`) in `create_worker_cb()`. Clear `needs_poll` and `IO_URING_F_NONBLOCK` before retrying after `io_arm_poll_handler() != IO_APOLL_OK` in `io_wq_submit_work()`. Fall through on `-EALREADY` from `io_async_cancel_one()` in `io_try_cancel()`; refresh `cd.seq` and fixed file lookup on each retry in `io_sync_cancel()`. Decrement `min_events -= ret` before `again:` and drain `retry_llist` first in `__io_run_local_work()`; set `ctx = NULL` after `ctx_flush_and_put()` before `cond_resched()` in `io_handle_tw_list()`; run `task_work` (dropping `uring_lock` if needed) when `iopoll_list` is empty or `io_task_work_pending(ctx)` in `io_iopoll_check()`. [F98, F106, F108, F109, F110, F112, F113]
