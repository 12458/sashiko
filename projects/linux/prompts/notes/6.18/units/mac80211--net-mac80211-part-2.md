# MAC80211 — net/mac80211 (part 2)

Core device, virtual interface, MLO link, key, and protocol management layer of the Linux mac80211 stack (`main.c`, `iface.c`, `link.c`, `key.c`, `fils_aead.c`, `ht.c`, `he.c`, `ibss.c`, `mesh.c`, `led.c`, `ieee80211_i.h`).

## Architecture & Data Flow
- `ieee80211_setup_sdata` normalizes `P2P_GO` to `NL80211_IFTYPE_AP` and `P2P_CLIENT` to `STATION` (`sdata->vif.p2p = true`); switches on `sdata->vif.type` handle AP/STATION, while P2P-aware callers use `ieee80211_vif_type_p2p(&sdata->vif)`. Changing type (`ieee80211_if_change_type`, `ieee80211_runtime_change_iftype`) must call `ieee80211_teardown_sdata` then `ieee80211_setup_sdata` (zeroing `sdata->u` and `sdata->deflink.u`) and set `sdata->u.mgd.use_4addr = false` for `STATION`. [F550, F582]
- `sdata->bss` is non-NULL only while an `AP` is open or an `AP_VLAN` is attached to a running AP; check `sdata->bss != NULL` before `container_of(sdata->bss, struct ieee80211_sub_if_data, u.ap)` if an `AP_VLAN` may be closed. An AP's `crypto_tx_tailroom_needed_cnt` must stay synced across child `sdata->u.ap.vlans` via `update_vlan_tailroom_need_count`, be inherited in `ieee80211_do_open`, and reset together in `ieee80211_reenable_keys`. [F551, F568]
- In `ieee80211_set_sdata_offload_flags` and `ieee80211_set_vif_encap_ops`, disable 802.3 TX encap offload (`ieee80211_dataif_8023_ops`, `IEEE80211_OFFLOAD_ENCAP_ENABLED`) if `local->virt_monitors != 0`, SW fragmentation is active, or 4-addr lacks `IEEE80211_OFFLOAD_ENCAP_4ADDR`. Changing `offload_flags` requires `ieee80211_check_fast_rx_iface`, and `ieee80211_recalc_sdata_offload` must update driver offload and `ieee80211_set_vif_encap_ops` on `sdata` and child `AP_VLAN`s. [F569, F695]
- Opening/stopping a non-active `MONITOR` (without `NO_VIRTUAL_MONITOR`) must update `local->virt_monitors`, toggle `IEEE80211_CONF_MONITOR` before `ieee80211_configure_filter`, and call `ieee80211_adjust_monitor_flags`, `ieee80211_recalc_offload`, and `ieee80211_recalc_idle`. In `ieee80211_do_stop`, return early if `local->suspended` is true (before `drv_remove_interface` or hw/filter config) or right after `ieee80211_stop_device()` when `local->open_count == 0`. [F570, F653, F663]
- Key slots: `sdata->keys` and `sta->ptk` have 4 slots (`0..3` WEP/pairwise); `link->gtk` and `link_sta->gtk` have 8 (`0..3` GTK, `4..5` IGTK, `6..7` BIGTK). `ieee80211_set_default_{key,mgmt_key,beacon_key}` expect `idx` in `0..3`, `4..5`, and `6..7` (out-of-range clears to NULL). In `ieee80211_key_replace`, if `old` matches `default_{unicast,multicast,mgmt,beacon}_key`, clear or rebind it to `new`. After `ieee80211_pairwise_rekey` sets `WLAN_STA_BLOCK_BA`, `_ieee80211_set_tx_key` must clear it (if `force` or no `AMPDU_KEYBORDER_SUPPORT`) and call `ieee80211_check_fast_xmit(sta)`. [F565, F574, F575, F595]
- In `struct ieee80211_key`, `u.{ccmp,gcmp}.rx_pn` have `IEEE80211_NUM_TIDS + 1` entries (`IEEE80211_NUM_TIDS` for `tid < 0` mgmt), whereas `u.tkip.rx` has `IEEE80211_NUM_TIDS` (`0 <= tid < 16`). `ieee80211_key_alloc` decodes little-endian `seq` via `get_unaligned_le16/32` for TKIP, but reverses bytes into big-endian `rx_pn` (`seq[PN_LEN - j - 1]`) for CCMP/GCMP/CMAC/GMAC. [F596, F597]
- Trailing flexible/priv members (`conf` in `ieee80211_key`/`ieee80211_chanctx`, `txq` in `txq_info`, `vif` in `ieee80211_sub_if_data`) must stay last. `ieee80211_if_add` aligns `txqi` offset via `ALIGN(sizeof(*sdata) + local->hw.vif_data_size, sizeof(void *))`; `ieee80211_alloc_hw_nm` aligns `local->hw.priv` to `ALIGN(sizeof(*local), NETDEV_ALIGN)`. `ps_data.tim` is `BITS_TO_LONGS(IEEE80211_MAX_AID + 1)` longs aligned to `__alignof__(unsigned long)` (mutated via `sta_info_{set,clear}_tim_bit`). `tid_rx_manage_offl` uses `0..15` for start and `16..31` for stop. [F591, F598, F599, F605, F650]
- In `ieee80211_link_init` / `ieee80211_vif_update_links`, `link_id < 0` targets `sdata->deflink` at slot `0`; transitioning `valid_links` from `0` forces bit 0 into `rem` while skipping `&sdata->deflink` in `to_free`. In `ieee80211_set_vif_links_bitmaps`, when `valid_links != 0`, `dormant_links` must be a strict subset of `valid_links`, and on `STATION` with `active_links == 0`, `valid_links & ~dormant_links` may have at most 1 bit set. [F602, F611]
- Unset TX power (`txpower`, `{user,ap}_power_level`) must be `INT_MIN` (`IEEE80211_UNSET_POWER_LEVEL`), not `0`. Modifying `sband->vht_cap` in `ieee80211_register_hw` requires `kmemdup`ing `bands[band]` and setting `BIT(band)` in `local->sband_allocated` for `ieee80211_free_hw`. `cipher_suites` in `ieee80211_init_cipher_suites` must keep 3 non-FIPS suites first and 4 MFP suites last. Overridable HT caps in `ieee80211_apply_htcap_overrides` must be in `mac80211_ht_capa_mod_mask`. Update `link_sta->pub->bandwidth` before `rate_control_rate_update(..., IEEE80211_RC_BW_CHANGED)`. [F559, F577, F578, F585, F586]
- Bounds checks: `fils_decrypt_assoc_resp` must verify `*frame_len >= 30`, find `WLAN_EID_EXT_FILS_SESSION` (`datalen == 9`), and check `crypt_len >= AES_BLOCK_SIZE` before `aes_siv_decrypt`. IBSS/mesh mgmt RX (`ieee80211_rx_mgmt_probe_beacon`, `ieee80211_mesh_rx_{probe_req,bcn_presp}`) must check `baselen <= len` before `len - baselen`. `ieee80211_mesh_update_bss_params` must verify `cap->datalen >= 1 + sizeof(*he_oper)` before `ieee80211_he_oper_size(cap->data + 1)`. [F588, F594, F607]
- Protocol state & loops: `ieee80211_mesh_build_beacon` must `skb_trim(skb, 0)` before building tail so `ifmsh->meshconf_offset` is relative to `bcn->tail`. `mesh_rmc_check` (`hlist_for_each_entry_safe`) increments `entries` before expiry/max checks and decrements it on deletion. `ieee80211_ibss_build_presp` must increment `ri++` when breaking at `++rates_added == 8`. `ieee80211_get_mbssid_beacon_len` treats `i == elems->cnt` as a total-length sentinel (`i > elems->cnt` bounds check). `ieee80211_ifa_changed` writes `arp_addr_list[c]` only if `c < IEEE80211_BSS_ARP_ADDR_LIST_LEN` but always increments `arp_addr_cnt`. `tpt_trig_timer` needs signed `i` (`throughput < 0` sentinel). `ieee80211_assign_perm_addr` requires contiguous `mask`. [F579, F593, F601, F603, F606, F623, F627]

## Synchronization
- Mutating `local->interfaces` or `local->monitor_sdata` requires RTNL, wiphy mutex, `local->iflist_mtx`, and RCU primitives. In `ieee80211_if_add`, `ieee80211_setup_sdata` and `cfg80211_register_netdevice` must precede `list_add_tail_rcu`. `ieee80211_remove_interfaces` must call `cfg80211_shutdown_all_interfaces` before taking `wiphy_lock` and using non-RCU list ops. [F526, F668, F669]
- In `ieee80211_stop` on `AP`, `dev_close` child `vlans` before taking `wiphy` lock, and call `ieee80211_stop_mbssid` inside it. In `ieee80211_do_stop`, `clear_bit(SDATA_STATE_RUNNING)` must be followed by `synchronize_rcu()`; call `ieee80211_free_keys(sdata, true)` (`force_synchronize`); run `sta_info_flush` before `drv_remove_interface`; and unlink `local->pending[i]` under `queue_stop_reason_lock` before calling `ieee80211_free_txskb` unlocked. [F528, F670, F671, F672]
- `ieee80211_link_init` must initialize all link/conf fields and works before `rcu_assign_pointer` on `sdata->vif.link_conf[link_id]` and `sdata->link[link_id]`. Removing links in `ieee80211_vif_update_links` requires `RCU_INIT_POINTER` and `synchronize_rcu()` (in `ieee80211_tear_down_links`) before freeing keys or `to_free` links. [F535, F536]
- `local->mc_list` accesses require `spin_lock_bh(&local->filter_lock)` (inside `netif_addr_lock_bh(dev)`), unlocked before `drv_configure_filter`. In `ieee80211_ba_session_work`, `fq->lock` nests inside `sta->lock`; release both before `synchronize_net()` if `!skb_queue_empty(&txqi->frags)`. [F531, F538]
- `ieee80211_restart_hw` sets `local->in_reconfig = true` and stops queues; `ieee80211_restart_work` flushes workqueues/wiphy works/ROC, cancels scans, and calls `synchronize_net()` before `ieee80211_reconfig()`. Workers using `ieee80211_can_run_worker()` and `ieee80211_activate_links_work` abort if `in_reconfig` (or `quiescing`/`suspended`). `ieee80211_unregister_hw` kills tasklets before `ieee80211_remove_interfaces`, and drops `wiphy_lock`/`rtnl_lock` before `cancel_work_sync(&local->restart_work)` and `destroy_workqueue`. [F664, F665, F676]
- `ieee80211_ifa_changed` must check `wdev->registered` before `mutex_lock_nested(&wiphy->mtx, 1)`. Drain `ifibss->incomplete_stations` via `while (!list_empty(...))` under `incomplete_lock`, dropping the lock before `sta_info_free` / `ieee80211_ibss_finish_sta`. `ieee80211_ibss_{add,finish}_sta` (`__acquires(RCU)`) are called without `rcu_read_lock()` and always return holding it. `ieee80211_stop_tpt_led_trig` sets `running = false` before `timer_delete_sync`. [F622, F674, F685, F687]

## Object Lifetimes
- Unlinked keys from `ieee80211_key_alloc()` must be freed via `ieee80211_key_free_unused()` (frees cipher `tfm` before `kfree_sensitive`). `ieee80211_free_keys_iface` and `ieee80211_remove_link_keys` must use `list_for_each_entry_safe`, unlink via `ieee80211_key_replace(..., NULL)`, and `synchronize_net()`/`_rcu()` before `__ieee80211_key_destroy`. In `ieee80211_key_enable_hw_accel`, never upload `KEY_FLAG_TAINTED` keys; if `KEY_FLAG_UPLOADED_TO_HARDWARE` is set, restore tailroom count and clear the flag. [F511, F576, F621]
- On error with `new_links != 0`, `ieee80211_vif_update_links()` must restore `sdata->link` / `vif.link_conf`, zero `to_free`, free new links, and re-run `ieee80211_link_init(&sdata->deflink)` if `old_links == 0`. `_ieee80211_set_active_links()` adds new links via `drv_change_vif_links()` before chanctx/sta/key updates, and removes deactivated links via `drv_change_vif_links()` after them. [F516, F657]
- `sdata` is `kzalloc`ed only when `sdata->dev == NULL` (`P2P_DEVICE`, `NAN`, `monitor_sdata`); otherwise `sdata` and `txqi` live in `netdev_priv(sdata->dev)` and must not be `kfree`d. `ieee80211_do_{open,stop}` must gate `local->open_count` and `drv_{add,remove}_interface` on `coming_up`/`going_down`. [F522, F642]
- On `led_trigger_register()` failure in `ieee80211_led_init()`, free and NULL `.name` (or `tpt_led_trigger`). On `drv_join_ibss()` failure in `__ieee80211_sta_join_ibss()`, reset IBSS state, NULL and `kfree_rcu` `ifibss->presp`, and call `ieee80211_link_release_channel(&sdata->deflink)`. `ieee80211_mesh_rebuild_beacon()` only `kfree_rcu`s `old_bcn` if `ieee80211_mesh_build_beacon()` succeeds; on failure `ieee80211_mesh_csa_beacon()` NULLs `ifmsh->csa` and `kfree_rcu`s `tmp_csa_settings`. [F519, F523, F524]

## API Contracts
- Driver ops (`ieee80211_alloc_hw_nm`, `ieee80211_register_hw`): `link_info_changed` and `vif_cfg_changed` must be paired and exclude `bss_info_changed`; `sta_state` excludes `sta_{add,remove}`; chanctx ops cannot mix emulated and custom callbacks. `WIPHY_FLAG_SUPPORTS_MLO` requires `link_info_changed`, `HAS_RATE_CONTROL`, `AMPDU_AGGREGATION`, `MFP_CAPABLE`, and `AP_LINK_PS`, and forbids `emulate_chanctx` and legacy PS/beacon flags. `hw->netdev_features` must be a subset of `MAC80211_SUPPORTED_FEATURES`. HT/VHT/HE require `hw->queues >= 4`; EHT requires HE. `SW_CRYPTO_CONTROL` requires `wiphy->cipher_suites`, forbids FIPS, and falls back to SW crypto only when `drv_set_key()` returns `1`. [F660, F661, F662, F689, F690, F691]
- Notifications & config: `ieee80211_vif_cfg_change_notify` only accepts `BSS_CHANGED_VIF_CFG_FLAGS`, `ieee80211_link_info_change_notify` rejects them, and `ieee80211_bss_info_change_notify` forbids MLD vifs. Never pass `IEEE80211_CONF_CHANGE_{CHANNEL,POWER,SMPS}` to `ieee80211_hw_config`. [F562, F563]
- Links, SMPS & OMI: `ieee80211_set_active_links` requires wiphy lock (else `_async`) and must call `_ieee80211_set_active_links(sdata, old_active & active_links)` before `active_links` when `old_active & active_links` is non-zero. `ieee80211_request_smps` uses `rcu_read_lock()` and `wiphy_work_queue`. `ieee80211_{prepare,finalize}_rx_omi_bw` must be paired. [F537, F573, F618, F682]
- Keys & WoWLAN: `ieee80211_iter_keys` (wiphy lock) and `_rcu` (RCU lock, no sleep/remove) accept `vif == NULL` and pass `sta = NULL` for vif/link keys. With `local->wowlan` set, `ieee80211_gtk_rekey_add` requires `STATION`, and `ieee80211_key_replace` (`old == NULL`) skips `ieee80211_key_enable_hw_accel()` and sets `KEY_FLAG_UPLOADED_TO_HARDWARE` on active links. [F554, F666, F679]
- HE, mesh, FILS & notifiers: `ieee80211_he_{cap_ie_to_sta_he_cap,op_ie_to_bss_conf,spr_ie_to_bss_conf}` must `memset` output structs to 0 before input checks; callers must pre-validate sizes via `ieee80211_he_capa_size_ok` and `ieee80211_he_spr_size`. `ieee80211_mesh_xmit_fast` returns `false` only if `skb` is unconsumed. `ieee80211_new_mesh_header` requires `addr4or5 != NULL` if `addr6 != NULL`. `aes_siv_{encrypt,decrypt}` require `addr[]`/`len[]` sized to `num_elem + 1` (`num_elem >= 1`). Notifiers must check `dev->ieee80211_ptr` and `wiphy->privid == mac80211_wiphy_privid` before `IEEE80211_DEV_TO_SUB_IF`. [F547, F558, F566, F589, F590, F625, F647]

## Error Handling
- `ieee80211_key_alloc` returns `ERR_PTR` (check `IS_ERR`), and `ieee80211_key_link` frees `key` on all errors (never free `key` after `ieee80211_key_link` fails). In `ieee80211_runtime_change_iftype`, preserve `ret` from `drv_change_interface` by using `err` for recovery `ieee80211_do_open`. Use ratelimited logging for IBSS max STA and peer DELBA. [F544, F556, F705]

## External Contracts
- `ieee80211_if_add` must set `dev_net_set(ndev, wiphy_net(local->hw.wiphy))` and `ndev->needed_{headroom,tailroom}` before `cfg80211_register_netdevice`. `ieee80211_mesh_xmit_fast` must run `skb_checksum_help`, check headroom, and `skb_share_check` before pushing headers. `ieee80211_handle_queued_frames` must reset `skb->pkt_type = 0`. `ieee80211_monitor_select_queue` must zero `IEEE80211_SKB_CB(skb)` and verify `skb->len` against radiotap + 802.11 hdrlen. [F693, F696, F701, F703]

## Known Pitfalls
- Call `__ieee80211_sta_recalc_aggregates` again after `drv_change_sta_links` in `_ieee80211_set_active_links`. Check `link_id >= 0` before `BIT(link_id)` in key helpers (`key->conf.link_id` can be `-1`), and normalize `link_id < 0 ? 0 : link_id` with 2-bit `smps` in `ieee80211_send_smps_action`. [F572, F592, F635]
- Buffer aliasing: `ieee80211_mesh_xmit_fast` (`MESH_FLAGS_AE_A5_A6`) must save `skb->data + ETH_ALEN` before `skb_push`/`memcpy`. `aes_siv_encrypt` must `kmemdup` `plain` and `aes_siv_decrypt` must copy `iv_crypt` to `frame_iv` before writing `out`. [F580, F581]
- `AP_VLAN` & MBSSID: `ieee80211_set_vif_encap_ops` reads `type`/`offload_flags` from parent `bss` on `AP_VLAN` but sets `sdata->dev->netdev_ops`. `ieee80211_link_init` on `AP_VLAN` must `memcpy(link_conf, ap_bss_conf)` before initializing `link_id`, `vif`, `txpower`, and `addr`. In `ieee80211_stop_mbssid` (`sdata != tx_sdata`), get `tx_link` from `tx_sdata`, clear `tx_bss_conf`, and stop `tx_sdata` last. [F629, F630, F631]
- In `ieee80211_do_stop`'s 2nd switch, `MONITOR` breaks early for pure virtual monitors (`!MONITOR_FLAG_ACTIVE && !NO_VIRTUAL_MONITOR`), else falls through to `drv_remove_interface`. Compare `beacon_timestamp > rx_timestamp` as `u64` in `ieee80211_rx_bss_info` (`-1ULL` when TSF unsupported). Never cast `u16 *` or `u64 *` to `unsigned long *` for `for_each_set_bit` (use `unsigned long` or `BITMAP_FROM_U64`). [F616, F638, F639, F651]
