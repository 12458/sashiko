# BLOCK LAYER — drivers/block

`drivers/block` contains virtual, test, and platform-specific block drivers: `null_blk` (memory-backed storage, writeback cache, zoned emulation, badblocks, bandwidth throttling, fault injection), Xen PV frontend (`xen-blkfront.c`), Sun LDOM Virtual Disk Client (`sunvdc.c`), Sony PS3 disk (`ps3disk.c`), Apple SWIM/SWIM3 floppy (`swim.c`, `swim3.c`), Nintendo 64 cartridge (`n64cart.c`), and Amiga Zorro II RAM disk (`z2ram.c`).

## Architecture & Data Flow

- In `null_blk`, `nullb_page.bitmap` has `MAP_SZ` bits (`0 .. MAP_SZ - 3` for `sector & SECTOR_MASK`, `NULLB_PAGE_FREE` at `MAP_SZ - 2`, `NULLB_PAGE_LOCK` at `MAP_SZ - 1`), so `null_page_empty()` must only scan `MAP_SZ - 2` bits. Direct writes (`is_fua` in `copy_to_nullb()`) and discards (`null_handle_discard()`) when `null_cache_active(nullb)` is true must call `null_free_sector(nullb, sector, true)`. `null_validate_conf()` caps `dev->cache_size` to `ULONG_MAX / 1024 / 1024`, forces `dev->blocking = true` when `dev->memory_backed` (`BLK_MQ_F_BLOCKING`), and enforces `submit_queues <= nr_cpu_ids` and `poll_queues <= g_poll_queues`. [F677, F691, F692, F727, F772]
- In `null_blk/zoned.c`, `dev->zone_size` must be a power of 2 (`is_power_of_2()`). Sequential zones start at `dev->zone_nr_conv`, so `null_close_imp_open_zone()` and `null_zone_mgmt()` must start/wrap at `dev->zone_nr_conv`. Setting a zone to `BLK_ZONE_COND_EMPTY` (`null_reset_zone()`, `null_set_zone_cond()`) must set `zone->wp = zone->start` and (if `dev->memory_backed`) call `null_handle_discard()`; closing an open zone at `zone->wp == zone->start` transitions to `BLK_ZONE_COND_EMPTY` without incrementing `dev->nr_zones_closed`. [F674, F694, F712, F730]
- In `xen-blkfront.c`, `rinfo->persistent_gnts_c` counts only `rinfo->grants` entries with `gref != INVALID_GRANT_REF`: `get_free_grant()`, `purge_persistent_grants()`, and `blkif_free_ring()` decrement it, while `blkif_completion()` increments it only when `!gnttab_try_end_foreign_access()`. `INDIRECT_GREFS()` and `psegs` in `blkfront_setup_indirect()` must use `DIV_ROUND_UP()`, and `talk_to_blkback()` must bound `ring_page_order` via `min(xen_blkif_max_ring_order, max_page_order)`. [F622, F739, F740]
- In `xen-blkfront.c`, `blkif_ring_get_request()` must set `shadow[id].request = req` and `shadow[id].req.u.rw.id = id` after `get_id_from_freelist()` (checked by `add_id_to_freelist()`). In `blkif_setup_rw_req_grant()`, when `setup->require_extra_req && grant_idx >= BLKIF_MAX_SEGMENTS_PER_REQUEST`, local `grant_idx` is reduced by `BLKIF_MAX_SEGMENTS_PER_REQUEST` to index `extra_ring_req->u.rw.seg[grant_idx]`, but `shadow->grants_used[setup->grant_idx]` must use the unadjusted `setup->grant_idx`. [F684, F720]
- In `sunvdc.c`, TX descriptors have stride `dr->entry_size = sizeof(struct vio_disk_desc) + sizeof(struct ldc_trans_cookie) * port->ring_cookies`, so `vdc_alloc_tx_ring()`, `vdc_free_tx_ring()`, and `vio_dring_entry()` must scale by `dr->entry_size`. Both `vdc_end_one()` and `vdc_requeue_inflight()` must unmap `desc->cookies` (`ldc_unmap()`), set `desc->hdr.state = VIO_DESC_FREE`, advance `dr->cons`, and clear `rqe->req = NULL` (or call `vdc_end_special()`). [F687, F748]
- In `swim.c` and `swim3.c`, cylinder/head are 0-based whereas `fs->req_sector` is 1-based (`1 .. fs->secpertrack`), so remaining-sector and wrap math must use `fs->secpertrack - fs->req_sector + 1` and `fs->req_sector > fs->secpertrack`. `swim.c` must call `swim_drive(base, fs->location)` before drive ops and reset `fs->track = 0` after `swim_track00()` on seek failure. `z2_open()` (`z2ram.c`) must check `current_device` under `z2ram_mutex` and shift `z2ram_size` by `Z2RAM_CHUNKSHIFT` before setting capacity. [F688, F690, F704]
- In `swim3.c`, `dbdma_cmd_space` is `5 * sizeof(struct dbdma_cmd)` to fit four aligned `dbdma_cmd` entries; on `WRITE`, `setup_transfer()` puts `write_preamble` at `dma_cmd[0]` and data at `dma_cmd[1]`, so `swim3_interrupt()` must advance `cp` by 1 on `WRITE` before reading `le16_to_cpu()` status/counts. Exiting any timed state in `swim3_interrupt()` must call `timer_delete(&fs->timeout)` and clear `fs->timeout_pending = 0`, and `floppy_open()` (`ref_count == 0`) / `floppy_revalidate()` must reset `fs->cur_cyl = -1` and `fs->write_prot = -1`. [F689, F705, F749]

## Synchronization

- In `null_blk`, `null_insert_page()` enters with `nullb->lock` held, drops it for `null_alloc_page()` and `radix_tree_preload(GFP_NOIO)`, and must reacquire `spin_lock_irq(&nullb->lock)` and call `radix_tree_preload_end()` on all exit paths. Zone locks must use `null_init/lock/unlock_zone()` (mutex when `dev->memory_backed`, spinlock otherwise), always nest outside `dev->zone_res_lock` and `nullb->lock`, and `dev->zone_res_lock` must be dropped before `null_handle_memory_backed()` or `null_handle_discard()`. [F617, F634, F775]
- In `null_blk`, on poll queues, `null_poll()` must call `blk_mq_set_request_complete()` before unlocking `nq->poll_lock`, and `null_timeout_rq()` must check `blk_mq_request_completed()` under `nq->poll_lock`. On non-poll queues, `null_timeout_rq()` only completes `rq` when `cmd->fake_timeout` is true, and `null_handle_cmd()` only sets `cmd->error = sts` when `cmd->error == BLK_STS_OK`. `null_handle_throttled()` must recheck `atomic_long_read(&nullb->cur_bytes) > 0` after `blk_mq_stop_hw_queues()`, and `null_del_dev()` must cancel `nullb->bw_timer`. [F641, F642, F643]
- In `xen-blkfront.c`, lock order is `blkfront_mutex` -> `info->mutex` -> `rinfo->ring_lock`; `ring_lock` uses `spin_lock_irqsave()` and requires `kmap_atomic()` / `kunmap_atomic()` for SG/grant pages. `blkif_queue_discard_req()` and `blkif_queue_rw_req()` must populate grants and `shadow[id]` under `ring_lock` before copying to `*final_ring_req`, setting `status = REQ_WAITING`, and calling `flush_requests()`. `xlbd_reserve_minors()` must recheck `end > nr_minors` after acquiring `minor_lock`. [F645, F647, F648, F776]
- In `sunvdc.c` (`__send_request()`, `generic_request()`), descriptor fields, cookies, and `port->rq_arr[dr->prod].req` (or `port->vio.cmp`) must be written under `port->vio.lock` followed by `wmb()` before setting `desc->hdr.state = VIO_DESC_READY` and calling `__vdc_tx_trigger()`. `vdc_queue_drain()` sets `port->drain = 1` under `port->vio.lock`, drops it for `blk_mq_freeze/quiesce_queue()`, and reacquires it to clear `port->drain = 0`. In `ps3disk.c`, `priv->lock` protects `priv->req`, and `ps3stor_send_command()` requires `priv->req == NULL`. [F649, F651, F654]

## Object Lifetimes

- In `null_blk`, `null_free_page()` sets `NULLB_PAGE_FREE`, but if `NULLB_PAGE_LOCK` is set, returns without freeing so `null_flush_cache_page()` frees it after unlocking. `null_free_zoned_dev()` must set `dev->zones = NULL` and `null_del_dev()` / `null_add_dev()` error paths must set `dev->nullb = NULL`; `null_del_dev()` only frees cache pages (`null_free_device_storage(dev, true)`), while `dev->data` and `dev` are freed in `nullb_device_release()` / `null_destroy_dev()`. `null_map_queues()` must null-check `set->driver_data`, teardown only frees `nullb->tag_set` when `== &nullb->__tag_set`, and `null_register_zoned_dev()` runs between `set_capacity()` and `add_disk()`. [F616, F619, F659, F751, F754]
- In `xen-blkfront.c`, when `new_persistent_gnts` is true in `blkif_queue_rw_req()`, call `gnttab_free_grant_references(setup.gref_head)` before returning; when `!info->bounce`, `blkif_completion()` must return `s->indirect_grants[i]->page` to `rinfo->indirect_pages` when foreign access ends. `blkif_free_ring()` and `blkfront_closing()` must call `gnttab_cancel_free_callback(&rinfo->callback)` before `flush_work(&rinfo->work)` (unlocked). `blkfront_remove()` deletes `info->info_list` under `blkfront_mutex` before `blkif_free(info, 0)` and frees minors/disk/tag_set after. [F621, F624, F626, F767]
- In `sunvdc.c`, `vdc_port_mpgroup_check()` must call `put_device(dev)` on `device_find_child()` results; `vdc_port_probe()` must pair `mdesc_grab()` with `mdesc_release(hp)` and only set drvdata after `probe_disk()` succeeds; and `generic_request()` must clear `port->vio.cmp = NULL` under `port->vio.lock` if `__vdc_tx_trigger()` fails. `ps3disk_probe()` error paths and `ps3disk_remove()` must unwind in reverse order and clear `devidx` in `ps3disk_mask` under `ps3disk_mask_mutex`. [F627, F628, F631, F757]
- In `swim.c` and `swim3.c`, `floppy_open()` errors must restore `fs->ref_count` and turn the motor `OFF` when `ref_count == 0`. In `swim3.c`, `grab_drive()` must decrement `fs->wanted` on wakeup and `-EINTR`, callers (`fd_eject()`, `floppy_revalidate()`) must call `release_drive(fs)`, and `swim3_add_device()` must call `swim3_mb_event(mdev, MB_FD)` before `request_irq()` and disable `PMAC_FTR_SWIM3_ENABLE` on failure. [F632, F633, F765]

## API Contracts

- In `null_blk`, `null_radix_tree_insert()` frees `t_page` via `null_free_page()` on duplicate insert without incrementing `curr_cache`. `null_zone_valid_read_len()` requires the zone lock held and converts `sector` (sectors) and `len` (bytes) to return bytes; `null_zone_write()` on `REQ_OP_ZONE_APPEND` writes at `zone->wp` and sets `blk_mq_rq_from_pdu(cmd)->__sector`. `null_check_zone_resources()` has `BLK_ZONE_COND_EMPTY` check `null_check_active()` and fall through to `BLK_ZONE_COND_CLOSED` (`null_check_open()`). `null_set_zone_cond()` toggles matching `READONLY`/`OFFLINE` to `EMPTY`, or calls `null_finish_zone()` first. `null_report_zones()` must pass a zeroed stack `struct blk_zone` to `cb()`. [F615, F638, F663, F710, F713, F784, F785]
- In `null_blk`, `null_poll()` passes `cmd->error != BLK_STS_OK` to `blk_mq_add_to_batch()` and falls back to `blk_mq_end_request(req, cmd->error)`. Under `CONFIG_KMSAN` and `!dev->memory_backed`, `nullb_complete_cmd()` must call `nullb_zero_read_cmd_buffer()`. `badblocks_check/set/clear()` callers must use 64-bit `sector_t`/`u64`. `NULLB_DEVICE_ATTR` only allows `{uint, ulong, bool}` and rejects `APPLY == NULL` writes with `-EBUSY` once `NULLB_DEV_FL_CONFIGURED` is set. In `trace.h`, `enum req_op` uses `__field_struct()` and `#include <trace/define_trace.h>` stays outside `_TRACE_NULLB_H`. [F655, F728, F786, F788, F789]
- In `xen-blkfront.c`, `blkfront_probe()` under `xen_hvm_domain()` rejects `"cdrom"` and non-extended non-`XENVBD_MAJOR` devices (`-ENODEV`). `blkfront_gather_backend_features()` sets `info->bounce = true` when `feature_persistent` and `feature_fua = 0` when `feature-flush-cache`. `encode_disk_name()` callers must bounds-check `ptr` and NUL-terminate. `blkif_set_queue_limits()` scales `max_hw_sectors` by `XEN_PAGE_SIZE / 512` and divides `max_segments` by `GRANTS_PER_PSEG`; `xlvbd_alloc_gendisk()` halves `queue_depth` when `HAS_EXTRA_REQ && !max_indirect_segments`; `blkfront_setup_indirect()` uses `memalloc_noio_save/restore()`; and `blkfront_resume()` / `blkif_recover()` requeue flush/discard/secure-erase/FUA via `info->requests` while moving other bios to `info->bio_list` (`request->bio = NULL`) before `blk_mq_end_request()`. [F746, F768, F770, F778, F791, F792, F795]
- In `sunvdc.c`, `generic_request()` 8-byte aligns `op_len` (`(op_len + 7) & ~7`) for LDC mapping while clamping `len <= op_len` for `memcpy()`; `vdc_version_supported(port, 1, 1)` guards `vdisk_size`, `vdisk_mtype`, `CDROM_GET_CAPABILITY`, and skipping `VD_OP_GET_DISKGEOM`, while `(port, 1, 2)` guards `phys_block_size`. In `n64cart.c`, `reg_base` is word-indexed (`u32 __iomem *`), and `n64cart_do_bvec()` must call `n64cart_wait_dma()` before and after writing `PI_WRITE_REG` (`bv->bv_len - 1`) prior to `dma_unmap_page()`. [F670, F703, F755, F759]

## Error Handling

- In `null_blk`, `null_handle_badblocks()` returns `BLK_STS_IOERR` with `*nr_sectors` set to partial sectors, which `null_process_cmd()` and `null_zone_write()` must transfer before returning `badblocks_ret`. `nullb_update_nr_hw_queues()` must check `set->nr_hw_queues == nr_hw_queues` after `blk_mq_update_nr_hw_queues()` and revert queue counts (`-ENOMEM`) on mismatch. `xlvbd_alloc_gendisk()` and `probe_disk()` must check `IS_ERR()` on `blk_mq_alloc_disk()` before assigning `info->gd` or `port->disk`. [F656, F660, F671]
- In `xen-blkfront.c`, `blkif_interrupt()` must check `!RING_RESPONSE_PROD_OVERFLOW()`, `RING_COPY_RESPONSE()`, `bret.id < BLK_RING_SIZE(info)`, `status == REQ_WAITING`, and `bret.operation == op` before indexing `shadow[id]`. `blkif_completion()` returns `0` when awaiting a split sibling (`continue`), `1` when complete (updating `*id`), and `< 0` on error (`goto err`). Unsupported flush/barrier responses clear `feature_flush`/`feature_fua` and complete with `BLK_STS_OK` (`blkif_queue_rq()` also completes `REQ_OP_FLUSH` with `BLK_STS_OK` when `!feature_flush`). In `sunvdc.c`, `vdc_ack()` must check `dring_ident`, `start_idx == end_idx`, and `start_idx < VDC_TX_RING_SIZE`; `vdc_handle_attr()` rejects `pkt->vdisk_block_size > port->vdisk_block_size` (`-ECONNRESET`) and only shrinks `port->max_xfer_size`. [F664, F697, F701, F702, F793]

## External Contracts

- In `xen-blkfront.c`, `write_per_ring_nodes()` writes `"ring-ref"` when `nr_ring_pages == 1`, and `talk_to_blkback()` omits `"queue-%u"` when `nr_rings == 1`. In `swim.c` and `swim3.c`, ioctls with `cmd & 0x80` require `capable(CAP_SYS_ADMIN)`, and `swim_probe()` must call `set_swim_mode(swim_base, 1)` and check `get_swim_mode(swim_base)`. In `swim3.c`, DBDMA addresses require `swim3_phys_to_bus()` and little-endian access; `xfer_timeout()` must poll `in_le32(&dr->status) & ACTIVE` after clearing `RUN`; and `swim3_interrupt()` (`do_transfer`) must poll `cp->xfer_status` (when `0` and no `ERROR_INTR`) up to 100 `udelay(1)` loops before stopping DBDMA. [F700, F761, F762, F763, F764, F796]

## Known Pitfalls

- In `null_blk`, `memb_group_features_show()` must check `ret >= left` (`-ENOBUFS`) before `left -= ret`; `null_handle_badblocks()` must check `sector < first_bad` after `ALIGN_DOWN(first_bad, block_sectors)`; and `null_init_zoned_dev()` must clamp `dev->zone_nr_conv` to `dev->nr_zones - 1` before bounding `zone_max_active`/`zone_max_open`. Avoid 32/64-bit bugs: cast `unsigned long` MiB counts to `sector_t` before `* SZ_1M` (`mb_to_sects()`, `null_add_dev()`); use `sector_div()` and `(sector_t)(geo->cylinders + 1)` in `vdc_getgeo()` / `blkif_getgeo()`; cast `blk_rq_pos(req)` to `long` in `swim3_queue_rq()`; and cast to `u64` in `((u64)1 << (u64)op) & port->operations` and `~(u64)MINORMASK` in `sunvdc.c`. [F696, F726, F729, F732, F735, F736, F737, F738]
- In `xen-blkfront.c`, `blkfront_ring_info` ends with flexible array `shadow[]`, so `info->rinfo` must be accessed via `get_rinfo()` or `for_each_rinfo()`, never `info->rinfo[i]`. In `swim3.c`, `act()` uses `break` for synchronous state transitions and `return` for async operations/timers (`scan_track()`, `seek_track()`, `settling`, `setup_transfer()`). In `ps3disk_identify()`, `dev->bounce_buf` requires `swap_buf_le16(id, ATA_ID_WORDS)` first, and `ata_id_c_string()` requires an odd `len`. [F698, F706, F724]
