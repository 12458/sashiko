# Hyper-V/Azure CORE AND DRIVERS — (top level) (part 2)

This unit covers the Hyper-V SCSI/FC storage driver (`storvsc_drv.c`), UIO VMBus driver (`uio_hv_generic.c`), AF_VSOCK transport (`hyperv_transport.c`), Hyper-V headers (`include/linux/hyperv.h`, `include/hyperv/*`, `include/uapi/linux/hyperv.h`), and userspace daemons (`tools/hv/*`).

## Architecture & Data Flow
- On `struct vmbus_channel`, `primary_channel` is NULL on primary channels and non-NULL on subchannels (`device_obj` is NULL); callbacks on both (`hv_uio_channel_cb`, `storvsc_on_channel_callback`) must resolve `hv_device` via `chan->primary_channel ? chan->primary_channel->device_obj : chan->device_obj`, while primary-only callbacks (`hv_uio_rescind`) use `chan->device_obj`. [F429]
- `stor_device->stor_chns` has `nr_cpu_ids` slots: only index `stor_chns[]` or `alloced_cpus` with valid Linux CPU numbers (`< nr_cpu_ids`), never `target_vp` or raw hwqueue numbers. In `storvsc_change_target_cpu()`, after clearing `old` in `alloced_cpus`, clear `stor_chns[cpu]` for every CPU not in `alloced_cpus` via `for_each_possible_cpu(cpu)` before setting `new`. [F487, F526]
- In `storvsc_on_io_completion()` and `storvsc_command_completion()`, clamp `sense_info_length` to `STORVSC_SENSE_BUFFER_SIZE` before copying `sense_data`, zero `data_transfer_length` on non-overrun errors, and clamp it to `cmd_request->payload->range.len` before `scsi_set_resid()`. [F466]
- In `storvsc_probe()`, clamp `max_xfer_bytes` to `STORVSC_FC_MAX_XFER_SIZE` when `is_fc` is true before deriving `host->max_sectors` and `host->sg_tablesize`. On `VSTOR_OPERATION_FCHBA_DATA` in `storvsc_on_receive()`, `cache_wwn()` must update `stor_device->node_name`/`port_name` and `fc_host_node_name`/`fc_host_port_name` together. [F448, F532]
- In `hyperv_transport.c`, call `hv_pkt_iter_first(hvs->chan)` only when `hvs->recv_desc == NULL`, and advance via `hv_pkt_iter_next()` in `hvs_stream_dequeue()` only when `hvs->recv_data_len == 0` (else `hvs->recv_data_off += to_read`). Whenever `hvs->recv_desc` becomes non-NULL, immediately call `hvs_update_recv_data(hvs)`, which must verify `hv_pkt_len(hvs->recv_desc) >= HVS_HEADER_LEN` before reading `recv_buf->hdr.data_size`, and verify `payload_len <= pkt_len - HVS_HEADER_LEN` and `payload_len <= HVS_MTU_SIZE`. [F451, F470, F490]
- `hvs_channel_writable_bytes()` must return 0 when `hv_get_bytes_to_write(&chan->outbound) <= HVS_PKT_LEN(1) + HVS_PKT_LEN(0)` and subtract both lengths so space is always reserved for `hvs_shutdown_lock_held()`'s 0-byte FIN packet. [F471]
- Never write `c->outbound.ring_buffer->pending_send_sz` directly: `set_channel_pending_send_size()` under `c->outbound.ring_lock` must increment `out_full_total` (and if `!out_full_flag`, increment `out_full_first` and set `out_full_flag = true`) on non-zero `size`, and clear `out_full_flag = false` on zero `size`. [F454]
- `__cpumask_to_vpset()` must map each CPU via `hv_cpu_number_to_vp_number()` (returning -1 on `VP_INVAL`), check `hv_max_vp_index / HV_VCPUS_PER_SPARSE_BANK < HV_MAX_SPARSE_VCPU_BANKS`, and zero `vpset->bank_contents[0 .. max_vcpu_bank]` inclusive since callers reuse `hv_tlb_flush_ex` buffers. [F478]
- In `tools/hv/vmbus_bufring.c`, each packet has an 8-byte trailer (`sizeof(uint64_t)`): `vmbus_txbr_write()` must require `avail > total` (`total` includes `sizeof(save_windex)`), and `vmbus_rxbr_peek()`/`vmbus_rxbr_read()` must require `dlen + skip + sizeof(uint64_t)` bytes. `rte_vmbus_chan_recv_raw()` must verify `pkt.hlen >= VMBUS_CHANPKT_HLEN_MIN`, `pkt.hlen <= pkt.tlen`, and `(pkt.tlen << VMBUS_CHANPKT_SIZE_SHIFT) <= *len` before copying. [F473, F474]
- In `hv_fcopy_start()`, convert `__u16` `smsg_in->file_name` and `path_name` via `wcstoutf8(..., W_MAX_PATH - 1)` (never `wchar_t` functions like `wcstombs()`), and reject `snprintf()` into `target_fname` returning `>= sizeof(target_fname)` in `hv_fcopy_create_file()`. [F475]
- In `vss_operate()`, skip `/` (`root_seen = 1`) during the `getmntent(mounts)` loop and freeze/thaw `/` only after all other mounts and `endmntent(mounts)`; on `err:`, thaw via `vss_operate(VSS_OP_THAW)` before calling `syslog()`. [F498]

## Synchronization
- Before `vmbus_open` in `storvsc_connect_to_vsp` or `handle_sc_creation`, set `channel->max_pkt_size` and `channel->next_request_id_callback`; in `handle_sc_creation`, publish `new_sc` to `stor_chns` and `alloced_cpus` only after `vmbus_open` succeeds. [F408]
- Call `init_completion(&request->wait_event)` before `vmbus_sendpacket` for synchronous `VMBUS_RQST_INIT`/`VMBUS_RQST_RESET` requests in `handle_multichannel_storage`, `storvsc_execute_vstor_op`, and `storvsc_host_reset_handler`. In `storvsc_host_reset_handler`, call `storvsc_wait_to_drain(stor_device)` after `wait_for_completion_timeout` before returning `SUCCESS`. [F409, F412]
- In `storvsc_dev_remove`, order `stor_device->destroy = true` with `wmb()` before `storvsc_wait_to_drain(stor_device)`, and call `hv_set_drvdata(device, NULL)` and `vmbus_close(device->channel)` only after `storvsc_wait_to_drain` returns. [F410]
- Serialize writes to `stor_device->stor_chns[]` and `alloced_cpus` in `storvsc_change_target_cpu` and `get_og_chn` under `spin_lock_irqsave(&stor_device->lock, flags)`, using `READ_ONCE`/`WRITE_ONCE` for lockless reads in `storvsc_do_io`; if `READ_ONCE(stor_device->stor_chns[q_num])` is NULL, take `stor_device->lock` and recheck `stor_chns[q_num]` before calling `get_og_chn()`. [F413, F414]
- In `storvsc_host_scan`, hold `host->scan_mutex` across `shost_for_each_device(sdev, host)` and release it before `scsi_scan_host(host)`. [F415]
- `storvsc_on_channel_callback()` and `storvsc_handle_error()` run in softirq context: allocate `struct storvsc_scan_work` with `GFP_ATOMIC` and defer `storvsc_device_scan()`/`storvsc_remove_lun()` to `host_dev->handle_error_wq`. In `storvsc_queuecommand()`, allocate variable-length `struct vmbus_packet_mpb_array` with `GFP_ATOMIC`, and never sleep in `storvsc_do_io()` (runs between `get_cpu()` and `put_cpu()`). [F544, F545]
- In `uio_hv_generic.c`, `HV_CALL_ISR` runs `hv_uio_channel_cb()` in hardirq context under `rcu_read_lock()` and `channel->sched_lock` (must not sleep). In `hv_uio_remove`, call `hv_remove_ring_sysfs(dev->channel)` and `uio_unregister_device(&pdata->info)` before `hv_uio_cleanup` and `vmbus_free_ring`. [F419, F543]
- In `hvs_open_connection`, acquire `lock_sock(sk)` after `vsock_find_bound_socket(&addr)` before checking `sk->sk_state`, opening `chan`, or modifying socket queues, and call `sock_put(sk)` before `release_sock(sk)` on exit. [F420]
- In `hvs_close_lock_held`, set `sock_hold(sk)` and `vsk->close_work_scheduled = true` under `lock_sock(sk)` before `schedule_delayed_work(&vsk->close_work, ...)`. `hvs_close_timeout` must `sock_hold(sk)`, take `lock_sock(sk)`, and recheck `!sock_flag(sk, SOCK_DONE)` before `hvs_do_close_lock_held(vsk, false)`. Under `lock_sock(sk)`, `hvs_do_close_lock_held()` must use `cancel_delayed_work(&vsk->close_work)`, never `cancel_delayed_work_sync()`. [F422, F549]
- Read `rbi->ring_buffer->write_index` and `read_index` with `READ_ONCE` in `hv_get_bytes_to_read`/`hv_get_bytes_to_write`. Issue `virt_mb()` right after writing `rbi->ring_buffer->interrupt_mask` in `hv_begin_read`/`hv_end_read`, and recheck `hv_get_bytes_to_read(rbi)` after the barrier in `hv_end_read`. [F423, F424]
- In `hv_read_tsc_page_tsc`, read `tsc_pg->tsc_sequence` with `READ_ONCE` (return `false` if 0), order with `smp_rmb()` before reading `tsc_scale`, `tsc_offset`, and `hv_get_raw_timer()`, and order with a second `smp_rmb()` before verifying `READ_ONCE(tsc_pg->tsc_sequence) == sequence`. [F426]
- `vmbus_signal_eom()` must clear `msg->header.message_type` using `cmpxchg(&msg->header.message_type, old_msg_type, HVMSG_NONE)` before checking `msg_pending` and writing `HV_MSR_EOM`. [F554]
- In `vmbus_txbr_write()` (`tools/hv/vmbus_bufring.c`), atomically advance shadow `tbr->windex` via `rte_atomic32_cmpset()` first, copy packet and `save_windex` trailer, and only then spin-update shared `vbr->windex` (`vmbus_br_setup()` must set `br->windex = br->vbr->windex`). [F459]

## Object Lifetimes
- In `storvsc_queuecommand()`, if `storvsc_do_io()` fails after `scsi_dma_map(scmnd)`, call `scsi_dma_unmap(scmnd)`. In `storvsc_command_completion()`, copy `cmd_request->payload` and `payload_sz` to locals before `scsi_done(scmnd)`, and call `kfree(payload)` only when `payload_sz > sizeof(struct vmbus_channel_packet_multipage_buffer)`. [F392, F393]
- In `storvsc_probe()`, error paths after `storvsc_connect_to_vsp()` (`err_out2`..`err_out4`) must call `storvsc_dev_remove(device)` and jump to `err_out0` (`scsi_host_put(host)`), bypassing `err_out1`. `storvsc_suspend()` must call `storvsc_wait_to_drain()`, drain `host_dev->handle_error_wq`, close `hv_dev->channel`, free/NULL `stor_chns`, and clear `alloced_cpus` before `storvsc_resume()`. [F395, F533]
- `storvsc_device_scan()` and `storvsc_remove_lun()` own `struct storvsc_scan_work *wrk` and must call `scsi_device_put()`, `scsi_host_put()`, and `kfree(wrk)` on all paths. [F397]
- In `hv_uio_open`/`hv_uio_release`, call `vmbus_connect_ring` only when `atomic_inc_return(&pdata->refcnt) == 1` (decrementing on failure) and `vmbus_disconnect_ring` only when `atomic_dec_and_test(&pdata->refcnt)`. In `hv_uio_probe()` error paths and `hv_uio_cleanup()`, `vfree()` `pdata->recv_buf`/`send_buf` only when `!pdata->recv_gpadl.decrypted` / `!pdata->send_gpadl.decrypted`. [F418, F557]
- In `hvs_open_connection()`, complete `set_per_channel_state(chan, conn_from_host ? new : sk)` and `sock_hold(conn_from_host ? new : sk)` before `vmbus_set_chn_rescind_callback(chan, hvs_close_connection)`. If `vmbus_open()` fails, reset `hvs_new->chan` or `hvs->chan` to NULL (and `sock_put(new)` if `conn_from_host`) before `out:` (which calls `sock_put(sk)` and `release_sock(sk)` on `sk`). [F401, F421, F489]

## API Contracts
- Always use `driver_set_override()` to set or clear `struct hv_device::driver_override`. [F405]
- `virt_to_hvpfn()` must check `is_vmalloc_addr(addr)` and use `page_to_phys(vmalloc_to_page(addr)) + offset_in_page(addr)` before `>> HV_HYP_PAGE_SHIFT` rather than `__pa()`. [F559]
- `struct vmbus_channel_packet_page_buffer`, `vmbus_channel_packet_multipage_buffer`, and `vmbus_packet_mpb_array` must keep the exact `__packed` layout and header offsets of `struct vmdata_gpa_direct`. [F515]
- In `storvsc_drv.c`, request ID 0 is reserved for unsolicited messages: `storvsc_next_request_id()` returns `blk_mq_unique_tag() + 1`, and `storvsc_on_channel_callback()` must pass `rqst_id - 1` to `scsi_host_find_tag()` and reject `COMPLETE_IO`/`FCHBA_DATA` when `rqst_id == 0`. [F436]
- In `handle_multichannel_storage()`, call `vmbus_set_sc_create_callback(device->channel, handle_sc_creation)` before sending `VSTOR_OPERATION_CREATE_SUB_CHANNELS`. [F531]
- `storvsc` must use `HV_HYP_PAGE_SIZE - 1` for `virt_boundary_mask` and `dma_set_min_align_mask`, and `(max_xfer_bytes >> HV_HYP_PAGE_SHIFT) + 1` for `host->sg_tablesize`. `storvsc_eh_timed_out()` must always return `SCSI_EH_RESET_TIMER` and never call `fc_eh_timed_out()`. [F577, F579]
- In `uio_hv_generic.c`, modify `inbound.ring_buffer->interrupt_mask` only in `set_event()` via `hv_uio_irqcontrol()`, writing `interrupt_mask = !irq_state` followed by `virt_mb()` before `vmbus_set_event(channel)`, and applying `set_event()` to both `dev->channel` and `&primary->sc_list` under `vmbus_connection.channel_mutex`. [F449, F493, F538]
- In `uio_hv_generic.c`, size `INT_PAGE_MAP`/`MON_PAGE_MAP` to `HV_HYP_PAGE_SIZE` and `TXRX_RING_MAP`/`hv_uio_ring_mmap()` to `channel->ringbuffer_pagecount << PAGE_SHIFT`. Ignore non-zero returns from `hv_create_ring_sysfs()` in `hv_uio_probe()`. `hv_uio_rescind()` must set `pdata->info.irq = 0`, call `uio_event_notify(&pdata->info)`, and call `vmbus_device_unregister(channel->device_obj)`. [F534, F578, F584]
- In `hyperv_transport.c`, verify `hvs_check_transport(vnew)` after `vsock_assign_transport(vnew, vsock_sk(sk))` in `hvs_open_connection()`. Keep `hvs_suspend`/`hvs_resume` on `hvs_drv`, and always return 0 from `hvs_probe()`. [F587, F589]
- In `hv_vss_daemon.c` and `hv_kvp_daemon.c`, read `vss_hdr.operation` / `kvp_hdr.operation` and `pool` into locals before writing `error` (which shares the union at offset 0). [F442]

## Error Handling
- In `storvsc_handle_error()`, switch on `SRB_STATUS(vm_srb->srb_status)` (low 6 bits) and test `SRB_STATUS_AUTOSENSE_VALID`/`SRB_STATUS_QUEUE_FROZEN` as bit flags. In `storvsc_on_io_completion()`, use `storvsc_log_ratelimited()` with `STORVSC_LOGGING_WARN` for `TEST_UNIT_READY`. [F483, F583]
- In `storvsc_channel_init()`, pass `status_check = false` to `storvsc_execute_vstor_op()` when probing `protocol_version[]`. [F486]
- In `hvs_stream_enqueue()`, if a later chunk fails after `bytes_written > 0`, jump to `out` so `ret = bytes_written` is returned. [F441]
- In `vss_do_freeze()`, treat `EBUSY` on `FIFREEZE` and `EINVAL` on `FITHAW` as success (`return 0`). [F592]

## External Contracts
- `struct hv_ring_buffer` and `struct vmbus_bufring` headers before `buffer[]`/`data[]` must be padded to 4096/`PAGE_SIZE` bytes with no trailing fields. UIO users (`hv_fcopy_uio_daemon`) must divide sysfs `ring` `st_size` by 2 for `ring_size`, mmap `2 * size` in `vmbus_uio_map()`, and place `rxbr` at `(char *)ring + ring_size`. [F477, F516]
- In `hvs_open_connection()`, check `is_valid_srv_id()` (`srv_id_template` in `b[4..15]`, port in `b[0..3]`), and use `RINGBUFFER_HVS_SND_SIZE`/`RINGBUFFER_HVS_RCV_SIZE` when `vmbus_proto_version < VERSION_WIN10_V5` (using `sk_sndbuf`/`sk_rcvbuf` clamped to `RINGBUFFER_HVS_MAX_SIZE` only on `VERSION_WIN10_V5`+). [F472, F540]
- In `hv_do_rep_hypercall()`, abort if `!hv_result_success(status)` and mask out `HV_HYPERCALL_REP_START_MASK` before setting `rep_comp << HV_HYPERCALL_REP_START_OFFSET`. [F494]
- Never change `HV_KVP_EXCHANGE_MAX_VALUE_SIZE` (2048) or `HV_KVP_EXCHANGE_MAX_KEY_SIZE` (512), and validate `key_size`/`value_size` against them in `kvp_key_add_or_modify()` and `kvp_get_value()`. [F480]

## Known Pitfalls
- In `storvsc_queuecommand()`, zero `vstor_packet`, `payload->range.len`, and `payload_sz` before checking `scsi_sg_count(scmnd)`; initialize PFN index `i = 0` once before `for_each_sg()` and round end addresses with `HVPFN_UP()` and start addresses with `HVPFN_DOWN()`. [F445, F488, F508]
- Check `if (num_channels == 0)` in `get_og_chn()` before `hash_qnum -= num_channels`; use `sector_div()` in `storvsc_get_chs()`; and use `time_after(jiffies, time_limit)` in `storvsc_on_channel_callback()`. [F504, F507, F513]
- Cast `u16`/`uint32_t` values to 64-bit before shifting (`varhead_size`/`rep_count`/`rep_comp` in `hv_do_rep_hypercall()`, `HV_LINUX_VENDOR_ID` in `hv_generate_guest_id()`, `old_windex` in `vmbus_txbr_write()`), and use `mul_u64_u64_shr(*cur_tsc, scale, 64)` in `hv_read_tsc_page_tsc()`. [F500, F501, F502, F506]
- Shift VMBus 8-byte descriptor lengths (`offset8`/`hlen`, `len8`/`tlen`) left by 3 before byte arithmetic (`hv_pkt_data`, `hv_pkt_datalen`, `hv_pkt_len`, `fcopy_pkt_process`, `rte_vmbus_chan_recv_raw`). Keep `hvs->recv_desc` typed as `struct vmpacket_descriptor *` for `hvs->recv_desc + 1`. [F518, F519]
- In `hv_kvp_daemon.c`, recompute interior pointers (`readp`) and update `kvp_file_info[pool].records`/`num_blocks`/`num_records` after `realloc()`; size `char *` buffers for `__u16` `hv_kvp_ipaddr_value` fields by byte size (`MAX_IP_ADDR_SIZE * 2`); and keep `process_ip_string_nm()` returning `> 0` when addresses match `ip_ver` and `process_dns_gateway_nm()` filtering by `ip_ver`. [F461, F497, F524]
- In `hv_fcopy_create_file()`, when `q = strchr(p, '/')` has `q == p`, advance `p++` and `continue`; otherwise restore `*q = '/'` and set `p = q + 1`. [F499]
