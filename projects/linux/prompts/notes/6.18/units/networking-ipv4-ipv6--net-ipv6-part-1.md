# NETWORKING [IPv4/IPv6] — net/ipv6 (part 1)

Implements the core IPv6 protocol family (`af_inet6.c`), interface address autoconfiguration, SLAAC, and Duplicate Address Detection (`addrconf.c`, `addrconf_core.c`), RFC 6724 source address selection labels (`addrlabel.c`), anycast group management (`anycast.c`), UDP/RAW datagram socket helpers (`datagram.c`), IPv6 extension headers (`exthdrs.c`, `exthdrs_core.c`, `exthdrs_offload.c`), policy routing rules (`fib6_rules.c`, `fib6_notifier.c`), and FOU/GUE encapsulation (`fou6.c`).

## Architecture & Data Flow
- `idev->addr_list` insertions must use `ipv6_link_dev_addr()` to keep entries sorted by descending scope. In `__ip6addrlbl_add()`, `ip6addrlbl_table.head` must stay sorted by descending `prefixlen`, with `ifindex != 0` before `!p->ifindex` for equal `prefixlen`. [F441, F495]
- Source address selection: in `ipv6_get_saddr_eval()`, multi-valued rules (`IPV6_SADDR_RULE_SCOPE`, `IPV6_SADDR_RULE_PREFIX`) must cache their score in `ipv6_saddr_score` and return it in `if (i <= score->rule)`; when `__ipv6_dev_get_saddr()` swaps `hiscore` and `score`, it must restore `score->ifa = hiscore->ifa` so the `list_for_each_entry_rcu()` cursor stays valid; and `__ipv6_chk_addr_and_flags()` masks `IFA_F_TENTATIVE` off `ifp_flags` when `IFA_F_OPTIMISTIC` is set, so callers excluding optimistic addresses must pass `IFA_F_OPTIMISTIC` in `banned_flags`. [F442, F485, F486]
- L3/VRF and netns scoping: `ipv6_dev_get_saddr()` and `__ipv6_chk_addr_and_flags()` must restrict candidates to the target's L3 master domain (`l3mdev_master_ifindex_rcu` / `l3mdev_master_dev_rcu`); user-supplied outgoing interfaces in `__ip6_datagram_connect()` (`sin6_scope_id`) and `ip6_datagram_send_ctl()` (`IPV6_PKTINFO`) require `sk_dev_equal_l3scope()`; `fib6_lookup()` / `fib6_rule_lookup()` must call `l3mdev_update_flow()` before `fib_rules_lookup()` when `fib6_has_custom_rules` is set; and `ipv6_chk_acast_addr()` (when `dev == NULL`) must check `net_eq(dev_net(fib6_info_nh_dev(aca->aca_rt)), net)`. [F461, F539, F548, F552]
- Policy routing and prefix GC: when `r->src.plen != 0` and `!(flags & RT6_LOOKUP_F_HAS_SADDR)`, `fib6_rule_match()` must allow a match if `FIB_RULE_FIND_SADDR` is set and defer the `ipv6_prefix_equal` check to `fib6_rule_saddr()`. Under `table->tb6_lock`, `fib6_set_expires()` must be paired with `fib6_add_gc_list()` and `fib6_clean_expires()` with `fib6_remove_gc_list()`. [F443, F497]
- Temporary, retained, and nopolicy addresses: deleting an `IFA_F_MANAGETEMPADDR` address (`inet6_addr_del`) or clearing that flag (`inet6_addr_modify`) must call `delete_tempaddrs(idev, ifp)`; regenerating an expiring `IFA_F_TEMPORARY` address in `addrconf_verify_rtnl()` must increment `ifp->regen_count` and reset `ifpub->regen_count = 0` before `ipv6_create_tempaddr(ifpub, true)`; retaining an address in `addrconf_ifdown()` (`keep_addr_on_down`) must set `INET6_IFADDR_STATE_PREDAD`, set `IFA_F_TENTATIVE` (unless `IFA_F_NODAD`), and detach/delete `ifa->rt` for `fixup_permanent_addr()`; and `addrconf_disable_policy_idev()` must update `ifa->rt->dst_nopolicy` and `DST_NOPOLICY` across all per-CPU `rt6i_pcpu` entries. [F444, F445, F446, F448]
- Netlink dumps: adding attributes in `inet6_fill_ifla6_attrs`, `inet6_fill_ifaddr`, `inet6_fill_prefix`, `inet6_netconf_fill_devconf`, or `ip6addrlbl_fill` requires updating their paired `*size()` helpers; `in6_dump_addrs()` must set `*s_ip_idx = err ? ip_idx : 0` on return; and `inet6_base_seq()` must never return `0` (substituting `0x80000000` on wrap). [F462, F478, F489]
- Inbound extension headers and TLVs: `ipv6_destopt_rcv`, `ipv6_rthdr_rcv`, and `ipv6_parse_hopopts` require a two-stage `pskb_may_pull` (8 bytes first, then `((skb_transport_header(skb)[1] + 1) << 3)` bytes); `ip6_parse_tlv` must check `len >= 2` and `optlen <= len`, cap consecutive `PAD1`/`PADN` bytes at 7 (with `PadN` bytes zero), and cap non-padding TLVs at `abs(max_count)`. [F463, F464]
- Option-specific invariants: in `ipv6_hop_ioam`, require `(optoff & 3) == 0` and check `hdr->opt_len` against `2 + sizeof(*trace)` and `2 + sizeof(*trace) + trace->remlen * 4` before `skb_ensure_writable()`; in `ipv6_hop_jumbo`, require `nh[optoff + 1] == 4`, `(optoff & 3) == 2`, `pkt_len > IPV6_MAXPLEN`, `payload_len == 0`, and `pkt_len <= skb->len - sizeof(struct ipv6hdr)`; in `ipv6_rpl_srh_rcv`, verify `n = (hdr->hdrlen << 3) - hdr->pad - (16 - hdr->cmpre)` is divisible by `16 - hdr->cmpri` (`r == 0`) with `n + 1 <= 255` and `segments_left <= n + 1`; and in `ipv6_rthdr_rcv()`, init `addr = NULL` before `looped_back:` and drop `IPV6_SRCRT_TYPE_2` if `segments_left == 0 && !addr`. [F466, F467, F468, F493]
- Options and socket layout: `ipv6_renew_options` and `ipv6_dup_options` pad each option after `opt2 + 1` to `CMSG_ALIGN(ipv6_optlen(hdr))` in `tot_len` while `opt_nflen`/`opt_flen` sum unpadded lengths, and `ipv6_dup_options` rebases pointers by `(char *)opt2 - (char *)opt`. Every `PF_INET6` `struct proto` must embed `struct ipv6_pinfo` at `prot->ipv6_pinfo_offset`; `inet6_net_init` must set `icmpv6_ratemask_ptr` to `&icmpv6_ratemask`; and `ETH_P_IPV6` error SKBs with `ipv6_datagram_support_addr(serr)` must have `skb_network_header(skb) + serr->addr_offset` pointing to `daddr` inside a `struct ipv6hdr`. [F470, F513, F515, F516]

## Synchronization
- Lock ordering, BH, and publication: in `addrconf.c`, `idev->lock` nests outside `ifp->lock`, and both plus `addrconf_hash_lock` are used in softirq/timers, requiring `_bh` locking in process context; `idev->token` accesses require `idev->lock`. `ipv6_add_dev()` must finish all `ndev` init before `rcu_assign_pointer(dev->ip6_ptr, ndev)`; `ipv6_add_addr()` must init `ifa->lock`, `dad_work`, `rt`, `idev`, and `refcnt` before hashing/linking; and `inet6_init()` must assign `ipv6_stub` and `ipv6_bpf_stub` last after `wmb()`, with `rawv6_init()` and `sock_register(&inet6_family_ops)` before `icmpv6_init()`, `ndisc_init()`, and `igmp6_init()`. [F401, F403, F414, F417, F520, F521]
- List walks and RCU refs: to run calls that cannot hold `idev->lock` (`addrconf_join_anycast`, `addrconf_leave_anycast`, `ip6_del_rt`) while walking `idev->addr_list` under RTNL, stage entries onto `ifa->if_list_aux` under `idev->lock`; in `addrconf_verify_rtnl()`, pin `ifp`/`ifpub` with `in6_ifa_hold()` before dropping `ifp->lock` and `rcu_read_unlock_bh()`, and `goto restart` after re-locking; RCU lookups in `ipv6_get_ifaddr()` and `addrconf_get_prefix_route()` must use `in6_ifa_hold_safe()` and `fib6_info_hold_safe()`; and `ipv6_sock_ac_join()` must call `rt6_lookup()`, `dst_dev_rcu(&rt->dst)`, and `netdev_hold()` inside `rcu_read_lock()`. [F406, F407, F526, F528]
- Workqueues and notifiers: `addrconf_cleanup()` and `addrconf_exit_net()` must not hold `rtnl_net_lock` across `destroy_workqueue(addrconf_wq)` or `cancel_delayed_work_sync(&net->ipv6.addr_chk_work)` (before freeing `inet6_addr_lst`). `inet6addr_validator_notifier_call_chain()` is blocking (`can_block` only), whereas `inet6addr_notifier_call_chain()` is atomic. [F412, F519]
- Socket and protosw concurrency: read `np->opt` under `rcu_read_lock()` and detach via `xchg(&np->opt, NULL)` before `txopt_put()`; update/clear `np->rxpmtu` and `np->pktoptions` via atomic `xchg()` and `kfree_skb()` displaced SKBs; read `READ_ONCE(sk->sk_prot)` once in unlocked socket ops (`inet6_bind_sk`, `inet6_ioctl`, `inet6_sendmsg`, `inet6_recvmsg`); read `sk->sk_uid` via `sk_uid(sk)`; and serialize `inetsw6` changes with `spin_lock_bh(&inetsw6_lock)`, RCU list ops, and `synchronize_net()` on unregister. [F421, F530, F531, F532, F533]

## Object Lifetimes
- `inet6_dev`, `inet6_ifaddr`, and timers: before `in6_dev_finish_destroy` (or the final `in6_dev_put`), set `idev->dead = 1` or `idev` leaks; in `addrconf_ifdown(dev, true)`, clear `dev->ip6_ptr = NULL` without `netdev_put(dev)`. `ipv6_add_addr` returns `ifp` with a caller ref that must be dropped via `in6_ifa_put`; `ipv6_del_addr()` must atomically check and set `ifp->state = INET6_IFADDR_STATE_DEAD` under `spin_lock_bh(&ifp->lock)` (skipping unhash/removal if already dead) because `inet6_ifa_finish_destroy` only frees `ifp` when `DEAD`. Always use `addrconf_mod_dad_work` / `addrconf_del_dad_work` and `addrconf_mod_rs_timer` / `addrconf_del_rs_timer` to keep refs balanced; in `ipv6_create_tempaddr`, `in6_ifa_hold(ifp)` transfers to `ift->ifpub`, so any error/retry before `ift->ifpub = ifp` must call `in6_ifa_put(ifp)` and `in6_dev_put(idev)`. [F377, F379, F381, F382, F383, F405, F411]
- `fib6_info` refs: `addrconf_get_prefix_route` returns a held `fib6_info *` and `ip6_del_rt` consumes one ref, so callers must either pass `rt` to `ip6_del_rt` (and set `rt = NULL` if `fib6_info_release(rt)` follows) or call `fib6_info_release(rt)`. Always set `ifp->rt = NULL` after `ip6_del_rt(ifp->rt)` (and release any prior `ifp->rt` in `fixup_permanent_addr`). In `aca_alloc`, keep `fib6_info_hold(f6i)` so `ip6_del_rt` on unlink and `fib6_info_release` in `aca_free_rcu` each have a ref. [F384, F385, F386]
- Socket and option cleanup: in `inet6_create`, failures after `sock_init_data` must jump to `out_sk_release` (`sk_common_release`, `sock->sk = NULL`); detaching sticky `np->opt` must subtract `opt->tot_len` from `sk->sk_omem_alloc` before `txopt_put(opt)`; in `ipv6_sock_ac_join`, clear `pac = NULL` once linked into `np->ipv6_ac_list` before `error_idev:`; and in `ip6_datagram_dst_update()`, release non-NULL `flowlabel` via `fl6_sock_release()` on all exits, but return/clear `IS_ERR(flowlabel)` before `out:`. [F387, F388, F389, F422, F426]
- Rollback and teardown: in `__inet6_bind`, restore `sk_ipv6only`, call `inet_reset_saddr(sk)`, and on post-bind failure call `put_port(sk)`; in `__ip6_datagram_connect`, restore `sk_v6_daddr`, `flow_label`, and `inet_dport` if `ip6_datagram_dst_update` fails; in `inet6_addr_add`, roll back `ipv6_mc_config(..., true, ...)` with `false` on error; in `fib6_rules.c`, release rejected `rt6_info *` with `ip6_rt_put_flags(rt, flags)`, call `dst_hold(&rt->dst)` on fallback/discard routes iff `!(flags & RT6_LOOKUP_F_DST_NOREF)`, and keep `fib6_rules_require_fldissect` symmetric between `fib6_rule_configure` and `fib6_rule_delete`; in `__addrconf_sysctl_unregister`, save and `kfree(p->sysctl_header->ctl_table_arg)` around `unregister_net_sysctl_table`; and in `inet6_dump_addr`/`inet6_rtm_getaddr`, call `put_net(tgt_net)` iff `fillargs.netnsid >= 0`. [F390, F391, F394, F395, F396, F398, F399]

## API Contracts
- Ref and RCU contracts: `ipv6_del_addr` and `addrconf_dad_stop` always consume one `ifp` ref (`in6_ifa_put(ifp)`); callers not transferring a ref must call `in6_ifa_hold(ifp)` first. `ipv6_dev_find()` and `fib6_lookup()` (`FIB_LOOKUP_NOREF`) return unreferenced pointers requiring `rcu_read_lock()` (or RTNL for `ipv6_dev_find`). Autoconf entry points (`addrconf_dev_config`, `addrconf_gre_config`, `inet6_addr_add`) must use `addrconf_add_dev()` (not `ipv6_find_idev()`) so `addrconf_add_mroute()` installs `ff00::/8`. `ipv6_add_addr`, `ipv6_add_dev`, `ipv6_find_idev`, and `addrconf_add_dev` return `ERR_PTR(-errno)` on failure, not `NULL`. `addrconf_prefix_route()` takes `expires` in `clock_t` (`jiffies_to_clock_t()`), whereas `cleanup_prefix_route()` and `fib6_set_expires()` take `jiffies`. [F380, F424, F437, F439, F525, F535]
- Extension header helpers: `ip6_parse_tlv` and all its TLV callbacks consume and free `skb` when returning `false`; callers (`ipv6_destopt_rcv`, `ipv6_parse_hopopts`) must not free `skb` on `false`. `ipv6_find_hdr()` requires `*offset` initialized to `0` (or a valid header offset) and returns `-EBADMSG`/`-ENOENT` on error, whereas `ipv6_skip_exthdr()` and `ipv6_find_tlv()` return `-1` on error in a signed `int` (`ipv6_find_tlv` also requires `offset >= 0` in linear SKB data). [F393, F429, F430, F469]
- Txoptions: `ipv6_renew_options()` returns `NULL` as valid success when `tot_len == 0` and `ERR_PTR(-ENOBUFS)` on error (unlike `ipv6_dup_options()`, which returns `NULL` on error); `ip6_datagram_send_ctl()` requires `ipc6->opt` to point to a zero-initialized `struct ipv6_txoptions`; and when `opt->dst0opt && !opt->srcrt`, `ipv6_push_nfrag_opts()` ignores `dst0opt` and `__ipv6_fixup_options()` shallow-copies `sizeof(*opt_space)` into `opt_space` (leaving `hopopt`/`dst1opt` aliasing `opt`), so `opt_space` must not outlive `opt` or be passed to `ipv6_dup_options` or `txopt_put`. [F427, F428, F498, F507]
- `fib6_rule_lookup()` must never return `NULL` (falling back to `ip6_null_entry`). In `fib6_rule_action`, `lookup_ptr == fib6_table_lookup` requires `lookup_data` to be `int *` (`oif`), whereas other `lookup_ptr` values must be `pol_lookup_t` with `const struct sk_buff *`. In `inet6_bind_sk`, `BPF_CGROUP_RUN_PROG_INET_BIND_LOCK` must run after `addr_len >= SIN6_LEN_RFC2133` but before `__inet6_bind`. `inet6_register_protosw` must reject duplicates of `INET_PROTOSW_PERMANENT` (`-EPERM`) and insert after `last_perm`; `inet6_unregister_protosw` must refuse `INET_PROTOSW_PERMANENT`. [F435, F510, F544, F546]

## Error Handling
- Check `__dev_get_by_index()` / `__dev_get_by_name()` for `NULL` before `netdev_lock_ops()`, `ipv6_find_idev()`, or `__in6_dev_get_rtnl_net()`. In `ipv6_add_addr()`, reset `f6i = NULL` if `addrconf_f6i_alloc()` returns `IS_ERR(f6i)` before jumping to `out`. Zero trailing netlink stats padding in `__snmp6_fill_statsdev`/`__snmp6_fill_stats64`, unused cmsg fields (`ee_pad`, `ee_data`, `sin6_flowinfo`, `sin6_port`, `sin6_scope_id`, `errhdr.offender`) in `datagram.c`, and stack `struct flowi6` instances in `inet6_sk_rebuild_header` and `ip6_datagram_flow_key_init`. [F423, F425, F432, F433, F438]

## External Contracts
- Reject `plen > 128` in `inet6_addr_add`, `inet6_addr_del`, and `ip6addrlbl_newdel`; reject `IFA_F_MANAGETEMPADDR` when `plen != 64` or on `IFA_F_TEMPORARY` addresses; and reject `label == IPV6_ADDR_LABEL_DEFAULT` in `ip6addrlbl_newdel`. Only read `sin6_scope_id` in bind/connect when `addr_len >= sizeof(struct sockaddr_in6)` (28 bytes, not `SIN6_LEN_RFC2133`). Require `ns_capable(net->user_ns, CAP_NET_RAW)` and two-stage `cmsg_len` checks for Hop-by-Hop/Destination option cmsgs in `ip6_datagram_send_ctl`. Copy `compat_in6_rtmsg` field-by-field in `inet6_compat_routing_ioctl`. Shift `FRA_DSCP`/`FRA_DSCP_MASK` by 2 (`<< 2` / `>> 2`) in `fib6_rules.c`, and when `RTEXT_FILTER_SKIP_STATS` is set in `inet6_fill_ifla6_attrs`, skip only `inet6_fill_ifla6_stats_attrs`. [F472, F473, F475, F480, F481, F503, F536, F547]

## Known Pitfalls
- SKB mutation and pointers in `exthdrs.c` and `fou6.c`: inbound handlers mutating headers (`ipv6_dest_hao`, `ipv6_srh_rcv`, `ipv6_rpl_srh_rcv`, `ipv6_rthdr_rcv`, `ipv6_hop_ioam`) must unshare the SKB, refresh cached pointers (including `nh` in `ip6_parse_tlv`, and in `ipv6_rpl_srh_rcv` refreshing `oldhdr` and using `memmove`), and update `skb->csum` or set `CHECKSUM_NONE`. Jumping to `looped_back` in `ipv6_srh_rcv`/`ipv6_rpl_srh_rcv` requires `skb_pull(skb, sizeof(struct ipv6hdr))` first. In `gue6_err()`, re-fetch `guehdr` after the second `pskb_may_pull` and restore `skb_set_transport_header(skb, transport_offset)` at `out:`. [F455, F457, F458, F509, F541]
- Alignment, math, and config pitfalls: `__snmp6_fill_statsdev`/`__snmp6_fill_stats64` must use `put_unaligned()`/`memcpy()` and `snmp_get_cpu_field64()`; `rfc3315_s14_backoff_init`/`update` must cast `irt`/`rt`/`mrt` to `u64` before multiplying and use `do_div(tmp, 1000000)`; `ipv6_create_tempaddr` must guard `idev->desync_factor %= max_desync_factor` with `if (max_desync_factor > 0)`; `check_cleanup_prefix_route` and `addrconf_verify_rtnl` must use `time_before` on `jiffies`; `addrconf_gre_config()` must skip `addrconf_addr_gen()` when `*(__be32 *)dev->dev_addr == 0` and `IN6_ADDR_GEN_MODE_EUI64`; and `__addrconf_sysctl_register()` must rebase `table[i].data` and only set `extra1`/`extra2` when both are NULL. [F440, F449, F499, F501, F505, F527]
