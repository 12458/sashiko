# BLUETOOTH DRIVERS — drivers/bluetooth (part 2)

Implements Bluetooth host controller transport drivers for USB (`btusb`), SDIO (`btsdio`, `btmtksdio`), PCMCIA (`dtl1_cs`), RSI (`btrsi`), and UART/Serdev (`hci_bcm`, `hci_ag6xx`, `hci_ath`), plus vendor helpers for MediaTek (`btmtk`), Qualcomm (`btqca`), and Realtek (`btrtl`).

## Architecture & Data Flow

- USB RX/SCO & probe: in `btusb_recv_intr()`, `btusb_recv_bulk()`, `btusb_recv_isoc()`, and `btmtk_recv_isopkt()`, check `skb_tailroom(skb) < hci_skb_expect(skb)` once the HCI header completes and drop with `-EILSEQ`. In `btusb_recv_isoc()`, validate new SCO headers (`skb->len == HCI_SCO_HDR_SIZE`) via `btusb_validate_sco_handle()`. Bypass `SCO_LINK`/`ESCO_LINK` checks when `HCI_USER_CHANNEL` is set. In `btusb_probe()`, `BTUSB_IFNUM_2` rejects `intf` only when `bInterfaceNumber` is neither `0` nor `2`. Keep `btusb_hci_drv_supported_commands[]` in lockstep with `btusb_hci_drv_*_handlers[]`. [F62, F94, F103, F104, F180]
- Optional USB interfaces & ISOC state: `data->isoc` and `data->diag` can be `NULL`; always check before dereferencing. When `btusb_switch_alt_setting()` changes `isoc_altsetting`, kill `isoc_anchor`, free/NULL `sco_skb` under `rxlock`, and call `__set_isoc_interface()` to re-resolve `isoc_tx_ep`/`isoc_rx_ep`. When `sco_num == 0` in `btusb_work()`, kill `isoc_anchor`, clear `BTUSB_ISOC_RUNNING`, reset altsetting to 0 via `__set_isoc_interface(hdev, 0)`, and clear `BTUSB_DID_ISO_RESUME` with `usb_autopm_put_interface()`. [F50, F55, F56]
- QCA/MTK coredumps: `acl_pkt_is_dump_qca()`/`evt_pkt_is_dump_qca()` must validate headers on a cloned `skb` via `skb_pull_data()` before `handle_dump_pkt_qca()` pulls `offsetof(struct qca_dump_hdr, data0)` (`seqno == 0`) or `data` (`seqno > 0`). Disable autosuspend on QCA `seqno == 0` and MTK `0xfc6f` (`btmtk_usb_recv_acl()`, `btmtksdio_recv_acl()`). `handle_dump_pkt_qca()` must jump to `out:` on completion/error to re-enable autosuspend, zero dump state, and clear `BTUSB_HW_SSR_ACTIVE`. In `btmtk_process_coredump()`, check `skb->len > MTK_COREDUMP_END_LEN` before tail comparison and keep `fallthrough;` from `HCI_DEVCOREDUMP_IDLE` to `HCI_DEVCOREDUMP_ACTIVE`. [F61, F85, F95, F107, F156, F177]
- SDIO state, RX & MTK FW: `btmtksdio_open()` sets `BTMTKSDIO_FUNC_ENABLED` and `btmtksdio_close()` clears it; close, remove, and PM callbacks must test it before touching hardware. `btmtksdio_reset()` sets `BTMTKSDIO_HW_RESET_ACTIVE`; `btmtksdio_shutdown()` must skip WMT commands while set, and `btmtksdio_setup()` must clear `BT_DL_STATE` in `MT7921_DLSTATUS` and `BTMTKSDIO_HW_RESET_ACTIVE`. In `btmtksdio_rx_packet()`, validate `rx_size` against `sdio_hdr->len`, check `pad_size = skb->len - pkts[i].hlen - dlen >= 0`, and `skb_trim()`. In `btsdio_rx_packet()`, verify `4 <= len <= 65543` before `len - 4`. In `btmtk_setup_firmware_79xx()`, reset `first_block = 1`, `fw_ptr = fw_bin_ptr`, and `retry = 20` each section loop. [F64, F65, F89, F97, F110]
- Realtek parsing: `btrtl_initialize()` retries `check_version:` at most once (`drop_fw = true` only when `!ic_info && !drop_fw`, else `false`). Because `btrtl_dev->ic_info` can be `NULL`, NULL-check it in `btrtl_download_firmware()`, `btrtl_set_quirks()`, and `btrtl_setup_realtek()`. Match 1-based firmware chip ID against `rom_version + 1`. `btrtl_parse_section()` must pull `sizeof(*common_subsec)` and `subsec_len` via `rtl_iov_pull_data()` before any `continue`, and `rtlbt_parse_firmware()` must reject `length == 0` before `fwptr -= length`. In `btrtl_get_uart_settings()`, validate `cfg_len` and `entry->len` (`>= 4` and `>= 13`). [F42, F90, F93, F112, F113]
- QCA TLV & NVM: `qca_download_firmware()` must copy `fw->data` into a writable `vmalloc()` buffer before `qca_tlv_check_data()` mutates `TLV_TYPE_NVM` bytes in place. `qca_tlv_check_data()` must validate `idx + sizeof(struct tlv_type_nvm) + tag_len <= length` and per-tag payload sizes, and set both `config->dnld_mode` and `config->dnld_type` (checked for `qca_inject_cmd_complete_event()`). In `qca_read_fw_board_id()`, check `skb->len >= 3` after pulling `edl`. Select `"_gf"` in `btusb_generate_qca_nvm_name()` from `ver->ram_version` independently of `qca_extract_board_id()` (`0xffff -> 0`); in `qca_uart_setup()`, `WCN6855`/`QCA2066`/`WCN7850` use `qca_read_fw_board_id()` + `qca_get_nvm_name_by_board()`, and `WCN3950` maps `SOC_ID_T`/`S` to `"t"`/`"s"`. [F69, F70, F80, F82, F142, F143]
- RSI, UART & PCMCIA: `rsi_hci_send_pkt()` must copy `hci_skb_pkt_type(skb)` to `bt_cb(new_skb)->pkt_type` on headroom realloc, and when aligning to `RSI_DMA_ALIGN`, sample `skb->data`/`skb->len` before `skb_push()`/`skb_pull()` and use `memmove()` + `skb_trim()`. `bcm_suspend_device()` sets `is_suspended = true` and disables flow control, reverting both if `set_device_wakeup()` fails or on resume. `ath_enqueue()` must read `ath->cur_sleep` for `HCI_OP_ATH_SLEEP` before `skb_push(skb, 1)` and set `HCI_UART_SENDING` before scheduling `ctxtsw`. `ag6xx_setup()` stops on `pbn->addr == 0xffffffff` and checks `fw->data + fw->size > pbn->data + plen`. In `dtl1_cs.c`, bound `UART_LSR`/`UART_IIR` loops with `boguscount` and reset `rx_state = RECV_WAIT_NSH`, `rx_count = NSHL`, and `rx_skb = NULL` together. [F72, F75, F76, F77, F96, F123, F151]

## Synchronization

- `btusb` RX locking: hold `data->rxlock` via `spin_lock_irqsave()` (or `isorxlock` in `btmtk_recv_isopkt()`) whenever accessing or freeing `evt_skb`, `acl_skb`, `sco_skb`, or `isopkt_skb`, setting the pointer to `NULL` on free or handoff. Inside `spin_lock_irqsave(&data->rxlock, flags)` in `btusb_free_frags()` and `btusb_switch_alt_setting()`, use `dev_kfree_skb_irq()`, not `kfree_skb()`. `data->recv_event` and `data->recv_acl` run under `rxlock` in URB completion context and must not sleep (`GFP_ATOMIC` only). [F8, F31, F157, F158]
- `btusb` TX, PM & close: acquire `data->txlock` with `spin_lock_irqsave`/`spin_lock_irq` to update `BTUSB_SUSPENDING` and `tx_in_flight` together across `submit_or_queue_tx_urb()`, `play_deferred()`, `btusb_tx_complete()`, and `btusb_suspend()`/`btusb_resume()`. Gate suspend/resume on `data->suspend_count` (`0 -> 1`, `1 -> 0`), decrementing `suspend_count` if `btusb_suspend()` aborts on `tx_in_flight`. Clear `BTUSB_*_RUNNING` flags in `btusb_close()` before `btusb_stop_traffic()` and `btusb_free_frags()`. Guard disabling `oob_wake_irq` with `test_and_clear_bit(BTUSB_OOB_WAKE_ENABLED, &data->flags)` and use `disable_irq_nosync()` in `btusb_oob_wake_handler()`. [F34, F57, F58, F159, F162]
- MediaTek USB/SDIO: in `btusb_mtk_claim_iso_intf()`, hold `device_lock(&btmtk_data->isopkt_intf->dev)` around `usb_driver_claim_interface()` and call `init_usb_anchor(&btmtk_data->isopkt_anchor)` when setting `BTMTK_ISOPKT_OVER_INTR`. In `btmtk_usb_hci_wmt_sync()`, `wait_on_bit_timeout()` on `BTMTK_TX_WAIT_VND_EVT` must use `TASK_UNINTERRUPTIBLE`. In `btmtk_usb_wmt_recv()` and `btmtksdio_recv_event()`, store `evt_skb` before `test_and_clear_bit()` and call `smp_mb__after_atomic()` before `wake_up_bit()`. [F22, F135, F166]
- `btmtksdio` IRQs & PM ownership: `btmtksdio_open()` must clear `C_INT_EN_CLR` in `MTK_REG_CHLPCR` and mask `MTK_REG_CHIER` before `sdio_claim_irq()`, setting `C_INT_EN_SET` only after configuring `MTK_REG_CHCR`/`MTK_REG_CHIER`. `btmtksdio_close()` must clear `C_INT_EN_CLR`, `sdio_release_irq()`, and `cancel_work_sync(&bdev->txrx_work)` before `btmtksdio_fw_pmctrl()` and `sdio_disable_func()`. In `btmtksdio_txrx_work()`, write `int_status` back to `MTK_REG_CHISR` before TX/RX. In `btmtksdio_fw_pmctrl()` and `btmtksdio_drv_pmctrl()`, claim the SDIO host and poll `MTK_REG_CHLPCR` (and `MTK_REG_PD2HRM0R` when `lp_mbox_supported` and `BTMTKSDIO_PATCH_ENABLED`) via `readx_poll_timeout()`. [F28, F29, F133, F150]
- In `hci_bcm.c`, hold `bcm_device_lock` whenever accessing `bcm_device_list`, calling `bcm_device_exists()`, or dereferencing a non-serdev `bcm->dev` or `bdev->hu`. In `dtl1_cs.c`, serialize UART TX via `dtl1_write_wakeup()` using `XMIT_SENDING`, `XMIT_WAKEUP`, and `XMIT_WAITING`. [F38, F39]

## Object Lifetimes

- Coredump `skb` ownership: `hci_devcd_append()` consumes `skb` even on error; callers (`btmtk_process_coredump()`, `handle_dump_pkt_qca()`) must read `skb->data`/`skb->len` before calling it and never `kfree_skb(skb)` after. `btmtk_process_coredump()` unconditionally consumes `skb`; in `btmtk_usb_recv_acl()` (`case 0xfc6f:`), pass `skb_clone(skb, GFP_ATOMIC)` to `btmtk_process_coredump()` so the original `skb` falls through to `hci_recv_diag()`. [F1, F2, F108]
- TX `skb` & URB ownership: `hdev->send` callbacks must not free `skb` when returning a negative errno. In `btsdio_tx_packet()` and `btmtksdio_tx_packet()`, on `sdio_writesb()` failure after `skb_push()`, strip the header with `skb_pull()` and do not free `skb` (requeued by worker). TX URBs using `btusb_tx_complete()`/`btusb_isoc_tx_complete()` must set `urb->context = skb` and `skb->dev = (void *)hdev`; `submit_tx_urb()`, `submit_or_queue_tx_urb()`, and `play_deferred()` consume the URB reference, and `kfree(urb->setup_packet)` must run on every control URB failure or completion. [F10, F11, F128, F174]
- `btusb` & `btmtk` teardown: in `btusb_probe()` error paths and `btusb_disconnect()`, call `gpiod_put(data->reset_gpio)` and `device_init_wakeup(&data->udev->dev, false)`. In `btusb_disconnect()`, clear `usb_set_intfdata(..., NULL)` on `intf`, `isoc`, and `diag` before `hci_unregister_dev()`, and call `usb_driver_release_interface()` only on claimed interfaces other than `intf`. In `btusb_mtk_release_iso_intf()`, kill `isopkt_anchor`, clear `BTMTK_ISOPKT_RUNNING`, free/NULL `isopkt_skb`, and clear `intfdata` before releasing `isopkt_intf`. Always set `evt_skb = NULL` after `kfree_skb()` in MTK WMT paths, and balance `usb_autopm_get_interface()`/`put_interface()` in `btmtk_usb_hci_wmt_sync()` and `btmtk_usb_shutdown()`. [F7, F12, F137, F138, F152]
- `btmtksdio`, `btrtl` & `btqca`: pair `pm_runtime_put_noidle()` in `btmtksdio_probe()` with `pm_runtime_get_noresume()` in `btmtksdio_remove()`, and call `btmtksdio_close()` in `btmtksdio_remove()` if `BTMTKSDIO_FUNC_ENABLED` is set. Restore `old_node` and `of_node_put()` after `of_find_compatible_node()` in `btmtksdio_probe()`, and set `bdev->reset = NULL` after `devm_gpiod_put()` in `btmtksdio_setup()`. `btrtl_insert_ordered_subsec()` inserts via raw `struct list_head *pos` (`__list_add(&node->list, pos->prev, pos)`), and callers must release `btrtl_initialize()` results via `btrtl_free()` (`list_for_each_entry_safe`, never freeing borrowed `subsec->data` into `fw_data`). Free `data` via `goto out` (`vfree(data)`) in `qca_download_firmware()`. [F4, F5, F6, F16, F17, F18, F109, F134]
- `hci_bcm` & `dtl1`: in `hci_bcm.c`, set `txco_clk = NULL` after `devm_clk_put()`, gate power/clocks on `res_enabled` (skipping NULL `supplies[0].supply`), only clear `bdev->hu = NULL` when `!hu->serdev`, and free IRQ/wakeup/PM in `bcm_close()` under `bcm_device_lock`. Initialize UART registers and `msleep(2000)` before `hci_register_dev()` in `dtl1_open()`. [F21, F74, F136, F139, F155]

## API Contracts

- Private `hdev` data & bitmaps: `btrtl_*`/`btrealtek_*` cast `hci_get_priv(hdev)` to `struct btrealtek_data *`, and `btmtk_reset_sync()`, `btmtk_register_coredump()`, `btmtk_process_coredump()`, `alloc_mtk_intr_urb()`, and `btmtk_usb_*()` cast `hci_get_priv(hdev)` to `struct btmtk_data *`; callers (e.g. `btmtksdio`) must allocate `hdev` via `hci_alloc_dev_priv()` with sufficient size. Access `hdev->quirk_flags` and `realtek->flags` (`DECLARE_BITMAP`) only via `hci_*_quirk()` and `btrealtek_*_flag()`. [F126, F127, F132]
- USB URBs, transfers & PM: `alloc_*_urb()` helpers return `ERR_PTR(-errno)` (check `IS_ERR(urb)`). In `alloc_mtk_intr_urb()`, verify `skb->len <= MTK_ISO_THRESHOLD` (264) and pad via `btmtk_isopkt_pad()` (`skb_pad()` + `__skb_put()`) *before* `usb_fill_int_urb()` captures `skb->data`/`skb->len`. Use `kmalloc`/`kzalloc` buffers for `usb_control_msg()`/`usb_bulk_msg()`, and pass `GFP_NOIO` when submitting RX URBs in `btusb_resume()` and `btmtk_usb_resume()`. `btusb_suspend()` may return `-EBUSY` only when `PMSG_IS_AUTO(message)` is true. In `btusb_hci_drv_read_info()`, scale `num_supported_commands` by `sizeof(__le16)`, set `rp->num_supported_commands` before indexing `rp->supported_commands[]` (`__counted_by_le`), and use `strscpy_pad()` for `rp->driver_name`. [F49, F54, F124, F125, F129, F160, F163, F181]
- HCI events, SDIO & headers: pass `0` (not `HCI_EV_VENDOR`) as `event` to `__hci_cmd_sync_ev()` for QCA EDL commands returning `HCI_EV_CMD_COMPLETE` (`qca_read_fw_build_info()`, `qca_send_patch_config_cmd()`, `qca_read_fw_board_id()`, `soc_type >= QCA_WCN3991`). Inject synthetic `HCI_EV_CMD_COMPLETE` via `hci_recv_frame()` when suppressed (`QCA_SKIP_EVT_VSE`/`VSE_CC`, `BTINTEL_HCI_OP_RESET`), and use `__hci_cmd_send()` (not sync) in coredump triggers (`btusb_coredump_qca`, `btmtk_coredump`, `btrtl_coredump`). In `btmtksdio_tx_packet()`, clear `BTMTKSDIO_HW_TX_READY` before `sdio_writesb()`, pass `round_up(skb->len, MTK_SDIO_BLOCK_SIZE)`, and keep unpadded `skb->len` in `sdio_hdr->len`. In `btmtksdio_get_codec_config_data()`, NULL-check/init `*ven_data`/`*ven_len` and free/NULL `*ven_data` on error. Keep `serdev_hu` first in `struct bcm_device`, and keep `#else` stubs in `btmtk.h`/`btqca.h`/`btrtl.h` matching `#if IS_ENABLED(...)` prototypes. [F44, F53, F73, F78, F149, F172, F173]

## Error Handling

- Explicit error codes: in `btrtl_initialize()`, every jump to `err_free`/`err_alloc` must set negative `ret` (including `ret = -EINVAL` when `cfg_len == 0` with `config_needed`) so `ERR_PTR(ret)` is never `NULL`. In `btqca.c` helpers initializing `err = 0` (`qca_read_soc_version()`, `qca_read_fw_build_info()`, `qca_read_fw_board_id()`, `qca_tlv_send_segment()`), every error path before `goto out` must set negative `err`. [F41, F43]
- Timeouts, polling & coredump reg: in `btmtk_usb_hci_wmt_sync()` and `mtk_hci_wmt_sync()`, positive returns from `wait_on_bit_timeout()` must clear the wait bit and set `err = -ETIMEDOUT`. When polling `btmtk_usb_func_query()`/`btmtksdio_func_query()` via `readx_poll_timeout()`, check both `err < 0` and signed `status < 0`. Ignore `-EOPNOTSUPP` from `hci_devcd_register()`/`btmtk_register_coredump()`, and call `hci_cmd_sync_cancel()` in `btusb` when interrupt URB submission fails (`err != -EPERM`) or a command URB fails. [F45, F47, F48, F183]

## External Contracts

- Wire protocols & hardware: on `soc_type >= QCA_WCN3991`, `qca_read_soc_version()` and `qca_tlv_send_segment()` receive `HCI_EV_CMD_COMPLETE` with a 1-byte status prefix at `edl->data[0]` (`qca_btsoc_version` at `edl->data + 1`) and no `tlv_seg_resp`. `qca_set_bdaddr()` (`0xFC14`) must `baswap()` the address (unlike `qca_set_bdaddr_rome()`/`btusb_set_bdaddr_wcn6855()`). In MTK WMT commands, check `hlen <= 255`, set `hdr->dlen = cpu_to_le16(wmt_params->dlen + 1)`, and read `wmt_evt_funcc->status` (`__be16`) with `be16_to_cpu()`. In `rtl_download_firmware()`, wrap `dl_cmd->index` from `0x7f` to `1` and OR `0x80` on the last fragment. In `dtl1_cs.c`, odd `nsh.len` frames have 1 wire pad byte not counted in `nsh.len`. In `hci_bcm.c`, drive `dev->reset` with `!powered` and `dev->shutdown` with `powered`, and use `acpi_bcm_int_last_gpios` when `dev->irq != 0` with 2 ACPI GPIOs. [F83, F84, F86, F87, F98, F118, F145, F146]

## Known Pitfalls

- `btusb_reset()` and vendor `hdev->reset` callbacks must never call `hdev->reset(hdev)`. For CSR `0x0a12:0x0001`, size the intr URB with `wMaxPacketSize` (not `HCI_MAX_EVENT_SIZE`) and apply fake-CSR quirks in `btusb_setup_csr()`. In `btusb_setup_qca_load_rampatch()`, only OR `rver_rom_high << 16` when `ver_rom & ~0xffffU` is non-zero; in `handle_dump_pkt_qca()`, skip gap calculation on `seqno == QCA_LAST_SEQUENCE_NUM` (`0xffff`); in `qca_read_fw_build_info()`, `kstrndup()` the build label before `hci_set_fw_info()`; in `qca_tlv_check_data()` (`TLV_TYPE_NVM`), use `length + (tlv->data - fw_data)`. In `bcm_open()` (`!hu->serdev`), match `bcm_device_list` by `hu->tty->dev->parent == dev->dev->parent`. [F105, F115, F119, F120, F130, F131, F141]
