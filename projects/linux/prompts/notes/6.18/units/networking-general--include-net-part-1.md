# NETWORKING [GENERAL] — include/net (part 1)

Core networking headers for IPv4/IPv6, FIB routing/rules, flow dissection/offload, GRO/GSO, Generic Netlink, FQ, and tunnels.

## Architecture & Data Flow
- `inet_timewait_sock` must keep `__tw_common` first, `inet_sock` must keep `sk` and `pinet6` first, and `inet_connection_sock` must keep `icsk_inet` first for casts and `__inet_sk_copy_descendant()`. [F87]
- `inet_hashinfo` `lhash2` buckets must use nulls markers offset by `LISTENING_NULLS_BASE` (`1U << 29`), distinct from `ehash` nulls since sockets move `TCP_ESTABLISHED` to `TCP_LISTEN` without an RCU grace period. [F21]
- Updating IPv4 socket addresses (`sk_daddr_set()`, `sk_rcv_saddr_set()`, `inet_reset_saddr()`) must update paired IPv6 addresses (`sk_v6_daddr`, `sk_v6_rcv_saddr`, `inet6_sk(sk)->saddr`) when `CONFIG_IPV6` is enabled, and changing `sk_rcv_saddr`/`sk_v6_rcv_saddr` on a bound socket requires `inet_bhash2_update_saddr()`. [F78]
- `INET_ECN_xmit()` and `INET_ECN_dontxmit()` must update `inet_sk(sk)->tos` and, if `inet6_sk(sk)`, `inet6_sk(sk)->tclass` in lockstep. [F68]
- `inet_csk_reset_xmit_timer()` and `inet_csk_clear_xmit_timer()` must update `icsk_pending` or `icsk_ack.pending` (and `icsk_ack.retry` on clear) via `smp_store_release()` in lockstep with `icsk_retransmit_timer` / `icsk_delack_timer`. [F79]
- `inet_csk_reqsk_queue_is_full()` must test `inet_csk_reqsk_queue_len(sk) > sk->sk_max_ack_backlog` (not `>=`) so backlog 0 allows one connection. [F82]
- Downcasting `fib_nh_common *` (`res->nhc`) to `fib_nh *` via `container_of` requires `nhc->nhc_family == AF_INET` (IPv6 embeds `nh_common` in `fib6_nh`). When `flowi_l3mdev` is derived from `flowi_oif` instead of `flowi_iif`, `FLOWI_FLAG_L3MDEV_OIF` must be set in `flowic_flags`. [F45, F160]
- In `ip_tunnel_info`, `key.u.ipv4` vs `u.ipv6` is selected by `IP_TUNNEL_INFO_IPV6` (`ip_tunnel_info_af()`); IPv4 `ip_tunnel_key_init()` must zero `IP_TUNNEL_KEY_IPV4_PAD` and trailing padding after `IP_TUNNEL_KEY_SIZE`. [F48]
- `ip_tunnel_info_opts_set()` must set `info->options_len = len` before copying into `__counted_by(options_len)` `info->options` and OR `flags` into `info->key.tun_flags`; option bits in `ip_tunnel_{set,clear,is}_options_present()` must be updated in lockstep. [F74]
- `lwtunnel_headroom(lwtstate, mtu)` returns 0 if `headroom >= mtu`; `ip_dst_mtu_maybe_forward()`, `ip_skb_dst_mtu()`, `ip6_skb_dst_mtu()`, and `ip6_dst_mtu_maybe_forward()` must pass the clamped `mtu` before subtracting it. [F99]
- In `fq_impl.h`: every `skb` removal from `fq_flow::queue` must call `fq_adjust_removal()`/`__fq_adjust_removal()` under `fq->lock`; `fq->flows_bitmap` updates must exclude `&tin->default_flow`; when unlinking `flow->flowchain` in `fq_tin_dequeue()` or `fq_flow_reset()`, set `flow->tin = NULL`, except in `fq_tin_dequeue()` when `dequeue_func` returns `NULL` on a `new_flows` head with non-empty `old_flows`, which must `list_move_tail()` to `old_flows`; `fq_flow_drop()` must use `do ... while (packets < pending)` so queue length 1 still drops a packet. [F61, F102, F103, F141, F183]
- Transient per-pass GRO fields in `napi_gro_cb` must be inside `struct_group(zeroed, ...)`. `call_gro_receive()`, `call_gro_receive_sk()`, and `indirect_call_gro_receive_inet()` must check `gro_recursion_inc_test(skb)` (`GRO_RECURSION_LIMIT` = 15) and set `flush |= 1` on limit. `gro_normal_one()` and `gro_normal_list()` must update `gro->rx_list` and `gro->rx_count` in lockstep. [F62, F65, F105]
- In `flow_keys`, `addrs` must be last and `basic` (`FLOW_KEYS_HASH_START_FIELD`) `__aligned(SIPHASH_ALIGNMENT)`. `flow_dissector_key_ipv4_addrs`, `flow_dissector_key_ipv6_addrs`, and `flowi4` must keep `src`/`saddr` immediately before `dst`/`daddr`; `flow_dissector_key_eth_addrs` must keep `dst` immediately before `src`. [F83, F85, F126]
- `INET_COMBINED_PORTS(__sport, __dport)` requires `__sport` in `__be16` and `__dport` in host `__u16`. `IP6_ECN_set_ce()` / `IP6_ECN_set_ect1()` must sample `*(__be32 *)iph` before writing and update `skb->csum` when `ip_summed == CHECKSUM_COMPLETE`, whereas IPv4 updates `iph->check`. `__ipv6_prefix_equal64_half()` and 32-bit `ipv6_prefix_equal()` must guard shifts with `len != 0` / `pbi != 0` and `len <= 64` (`prefixlen <= 128`). [F69, F86, F116]

## Synchronization
- All queue, flow, and tin mutations in `fq_impl.h` (`fq_flow_dequeue()`, `fq_flow_drop()`, `fq_tin_dequeue()`, `fq_flow_classify()`, `fq_tin_enqueue()`, `fq_flow_filter()`, `fq_tin_filter()`, `fq_flow_reset()`, `fq_tin_reset()`, `fq_reset()`) require `fq->lock`. [F16]
- Lockless socket readers must use `inet_sk_state_load()` paired with `inet_sk_state_store()`, and `READ_ONCE(sk->sk_bound_dev_if)` in `inet_match()`/`inet6_match()`. `__inet_inherit_port()` requires local BH disabled. Calling `ip_select_ident()` or `ip_select_ident_segs()` on a connected TCP socket requires owning the socket lock. [F20, F24, F29, F148]
- On `fib6_info`: `fib6_add_gc_list()`, `fib6_remove_gc_list()`, `fib6_set_expires()`, and `fib6_clean_expires()` (`RTF_EXPIRES` and `expires` updated in lockstep) require `tb6_lock`, and `fib6_add_gc_list()` must re-verify `fib6_node != NULL` under `tb6_lock`; `fib6_lookup()` and `fib6_table_lookup()` require `rcu_read_lock()` across lookup and `fib6_select_path()`; `fib6_get_cookie_safe()` requires `rcu_read_lock()`, `rcu_dereference(f6i->fib6_node)`, `READ_ONCE(fn->fn_sernum)`, and `smp_rmb()`. [F31, F32, F76, F150]
- `ip_dst_mtu_maybe_forward()` and `ip6_dst_mtu_maybe_forward()` require `rcu_read_lock()` and `dst_dev_rcu()`/`dev_net_rcu()`. `lwtunnel_set_redirect()` must use `READ_ONCE()`/`WRITE_ONCE()` on `dst->output` and `dst->input`. `txopt_get()` requires `rcu_read_lock()` and `refcount_inc_not_zero(&opt->refcnt)`, paired with `kfree_rcu()` in `txopt_put()`. [F36, F146, F158]
- `genlmsg_multicast_allns()` requires `rtnl_lock` or `rcu_read_lock()`. `iptunnel_xmit_stats()` must update `dev->tstats` under `get_cpu_ptr()`/`put_cpu_ptr()` and `u64_stats_update_begin()`/`end()`. In `kcm_sock`, `tx_wait` and `tx_wait_more` use different locks and must remain separate `bool` fields, not bitfields. [F18, F34, F154]

## Object Lifetimes
- Before `fib6_info_release()` drops the last `fib6_ref`, `f6i->gc_link` must be unhashed via `fib6_remove_gc_list()` under `tb6_lock`. `ip_dst_init_metrics()`, `ip_fib_metrics_put()`, and `ip_dst_metrics_put()` must check `!= &dst_default_metrics` before refcounting or freeing. [F5, F77]
- `fqdir_pre_exit()` sets `WRITE_ONCE(fqdir->high_thresh, 0)` and `WRITE_ONCE(fqdir->dead, true)`. In `ip6frag_expire_frag_queue()`, under `rcu_read_lock()`, check `READ_ONCE(fq->q.fqdir->dead)` before `fq->q.lock`; unlink `head` via `inet_frag_pull_head(&fq->q)` before setting `head->dev`; unlock `fq->q.lock` before `icmpv6_send()`, keeping `rcu_read_lock()` until `icmpv6_send()` finishes and `head` is freed with `kfree_skb_reason()`; on all exit paths, drop `fq->q.lock` and `rcu_read_unlock()` before `inet_frag_putn(&fq->q, refs)`. [F6, F7, F26, F156]
- `__inet_lookup()` and `__inet6_lookup()` return listener sockets with `*refcounted = false`; callers must check `refcounted` before `sock_put()` or pin with `refcount_inc_not_zero(&sk->sk_refcnt)` before leaving RCU. In `inet_peer`, `rid` shares a union with `rcu` and must not be accessed once `refcnt == 0`. [F23, F28]
- On `FLOW_BLOCK_UNBIND`, drivers must call `flow_block_cb_remove()` or `flow_indr_block_cb_remove()` rather than `list_del()` + `flow_block_cb_free()`. [F142]

## API Contracts
- `fib_lookup()` sets `FIB_LOOKUP_NOREF`, so `res->fi` is valid only under `rcu_read_lock()` unless held via `fib_info_hold()`. Routes from lookups with `RT6_LOOKUP_F_DST_NOREF` must be released via `ip6_rt_put_flags(rt, flags)` (uncached routes still hold a ref). Check `!f6i->nh` before accessing flexible array `f6i->fib6_nh`. [F13, F128, F181]
- Downcasting `fib_notifier_info *` requires checking both `info->family` and `fib_event_type`. Mutating FIB rules via `fib_rules_ops` must call `ops->flush_cache`. [F80, F139]
- Check `flow_rule_match_key()` before calling any `flow_rule_match_*()`, and check `flow_action_has_entries()` (or `flow_offload_has_one_action()`) before `flow_action_first_entry_get()`. [F43, F44]
- `flow_action_hw_stats_check()` takes an unshifted `flow_action_hw_stats_bit` (requiring `BIT(allow_bit)`, while `flow_action_basic_hw_stats_check()` requires both bits of `FLOW_ACTION_HW_STATS_ANY` via `~hw_stats & FLOW_ACTION_HW_STATS_ANY`), whereas `flow_stats_update()` takes a shifted `flow_action_hw_stats` mask with at most one bit set. [F54, F108]
- `sk_to_full_sk()`, `sk_const_to_full_sk()`, and `skb_to_full_sk()` return `NULL` for `TCP_TIME_WAIT`; check `inet_test_bit(IS_ICSK, sk)` before `inet_csk(sk)` on generic sockets. `__inet_sk_copy_descendant()` requires `ancestor_size >= sizeof(struct inet_sock)`. `inet_csk_clear_xmit_timer()` only accepts `ICSK_TIME_RETRANS`, `ICSK_TIME_PROBE0`, and `ICSK_TIME_DACK`. `inet_get_iif_sdif()` and `inet6_get_iif_sdif()` require `rcu_read_lock()`, `skb->dev`, and `!skb_valid_dst(skb)`. [F46, F112, F129, F169]
- `ipcm_cookie` and `ipcm6_cookie` use `-1` sentinels (`tos = -1`, `hlimit = -1`); initialize via `ipcm_init()`, `ipcm_init_sk()`, or `ipcm6_init_sk()`. `fl6_merge_options(&opt_space, ...)` and `ipv6_fixup_options(&opt_space, ...)` may return stack `&opt_space`; never pass the result to `txopt_put()` or `ipv6_dup_options()`. [F52, F137]
- `ip6_flow_hdr()` and `ip6_make_flowinfo()` require `tclass` in `0..255` and `flowlabel` pre-masked with `IPV6_FLOWLABEL_MASK`. `ipv6_addr_prefix()` and `ipv6_addr_prefix_copy()` require `0 <= plen <= 128`. `__ipv6_addr_diff()`/`__ipv6_addr_diff32()` require `addrlen` divisible by 4 (`!(addrlen & 7)` for `__ipv6_addr_diff64()`). [F59, F94, F118]
- `*ECN_decapsulate()` helpers return `0` (ok), `1` (log anomaly), or `2` (drop); initialize `bool set_ce = false` before `__INET_ECN_decapsulate()`. In `iptunnel_xmit_stats()`, `pkt_len > 0` is tx ok, `0` is dropped, `< 0` is error. `iptunnel_pull_offloads()` must `skb_unclone()` if `skb_is_gso(skb)` before clearing encap GSO flags. Tunnel flag bitmaps must use `IP_TUNNEL_DECLARE_FLAGS()`. `gre_build_header()` requires `hdr_len == gre_calc_hlen(flags)`. `validate_gue_flags()` must check `guehdr_flags_len(flags) <= optlen` before reading private flags and re-check with `guehdr_priv_flags_len(pflags)`. [F39, F41, F72, F90, F91, F110, F140]
- `skb_gro_header()`, `skb_gro_header_slow()`, and `skb_gro_remcsum_process()` may `pskb_may_pull()`, invalidating cached header pointers; only call `skb_gro_header_fast()` when `skb_gro_may_pull()`. If GRO flushes without consuming after `skb_gro_remcsum_process()`, use `skb_gro_flush_final_remcsum()`. Use `gso_pskb_expand_head()` when expanding GSO `skb->head`. `gso_reset_checksum()` must skip `csum`/`csum_start` when `remcsum_offload` is set, and `gso_make_checksum()` must read them before updating. `fq_tin_enqueue()`, `ip_fraglist_next()`, and `ip6_fraglist_next()` must advance past `skb->next` and call `skb_mark_not_on_list(skb)`. [F64, F66, F67, F104, F131]
- Generic Netlink: `genlmsg_multicast*()`, `genl_set_err()` (negative errno), and `genl_has_listeners()` take a 0-based `group` index (`< n_mcgrps`); `genl_split_ops` must set either `GENL_CMD_CAP_DO` or `GENL_CMD_CAP_DUMP`, sorted by `cmd` with `DO` before `DUMP`; ops with `cmd >= resv_start_op` must have `validate == 0` and a `policy`; `GENL_ADMIN_PERM` checks `init_user_ns`, while `GENL_UNS_ADMIN_PERM` checks `net->user_ns`. Initialize `gnet_stats_basic_sync` with `gnet_stats_basic_sync_init()` and use `_bstats_set()`/`_bstats_update()` and `gnet_stats_add_basic()`. [F17, F56, F161, F162, F165]

## Error Handling
- On `bitmap_zalloc()` failure in `fq_init()`, `kvfree(fq->flows)` and set it to `NULL`; `fq_reset()` must reset all flows before freeing and NULLing `fq->flows` and `fq->flows_bitmap`. [F3]
- `ip6_route_output*()`, `ip6_route_lookup()`, and `fib6_rule_lookup()` return a `dst_entry *` with negative `dst->error` (never `NULL`/`ERR_PTR`), whereas `ip6_dst_lookup_flow()` and `ip6_sk_dst_lookup_flow()` return `ERR_PTR`. `fl6_sock_lookup()` returns `ERR_PTR(-ENOENT)` when exclusive flowlabels are active and `NULL` otherwise. `inet_steal_sock()` and `inet6_steal_sock()` can return `ERR_PTR` from reuseport lookup; check `IS_ERR(sk)`. Store `skb_get_dsfield()` return in `int` (returns `-1` on error). [F37, F40, F42, F111]

## External Contracts
- `flow_dissector_ctrl_flags` must keep `FLOW_DIS_*` synced with `TCA_FLOWER_KEY_FLAGS_*` and start internal flags at `TCA_FLOWER_KEY_FLAGS_MAX << 1`. Only append new `FIB_MULTIPATH_HASH_FIELD_*` bits, and mask `fl4->flowi4_dscp` with `INET_DSCP_LEGACY_TOS_MASK` (`0x1c`) in `fib_dscp_masked_match()`. [F100, F101]

## Known Pitfalls
- Pass the user-header pointer from `genlmsg_put*()` (not `nlmsghdr *` or `genlmsghdr *`) to `genlmsg_end()`, `genlmsg_cancel()`, `genlmsg_nlhdr()`, and `genl_dump_check_consistent()`. After `genl_info_init_ntf()` (`genl_info_is_ntf(info)`), `info->genlhdr` aliases `info->user_ptr[0]`/`info->ctx` and `info->nlhdr` is `NULL`; do not touch `ctx`/`user_ptr[0]` or call `genlmsg_len()`/`genlmsg_data()`. [F55, F138]
- `__inet6_lookup()` takes `hnum` in host `u16`, whereas `__inet_lookup()` takes `dport` in `__be16`. Use `key32_to_tunnel_id()` / `tunnel_id_to_key32()` between `__be32` keys and `__be64` IDs. Cast 32-bit operands to `u64` before `<< 32` in `fib_multipath_hash_construct_key()`, `key32_to_tunnel_id()`, and `INET_ADDR_COOKIE()`, and before backoff shifts in `inet_csk_rto_backoff()` and `reqsk_timeout()`. [F57, F89, F115, F124]
- Use `BIT_ULL(key_id)` / `1ULL << key_id` on `flow_dissector->used_keys` (`FLOW_DISSECTOR_KEY_IPSEC` is 32). Never dereference `__act` after `flow_action_for_each()` finishes without breaking. `flow_rule_{has,has_enc,match_has}_control_flags()` return `true` on error (when flags are set), opposite to `flow_rule_is_supp_control_flags()`. [F107, F109, F114]
- In `inet_gro_flush()`, `ip_fixedid` tracks outer/inner via `1 << inner`, and `(id >> 16) - (id2 >> 16)` must be truncated to `u16` (`ipid_offset`). `ipv6_hopopt_jumbo_remove()` must `skb_cow_head(skb, 0)`, advance both `network_header` and `mac_header` after `memmove`/`__skb_pull`, and re-fetch `ipv6_hdr(skb)` afterward. [F70, F106, F119]
- `ip_decrease_ttl()` must widen `iph->check` to `u32` and fold carry via `check + (check >= 0xFFFF)`. `fib6_check_expired()` and `ip_dst_mtu_maybe_forward()` must check `RTF_EXPIRES` / `rt_pmtu != 0` and use `time_after()`/`time_before()`. In `snmp_get_cpu_field*()`, `offt` is an element index while `syncp_offset` is a byte offset. [F120, F122, F130]
