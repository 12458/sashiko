# ARM64 PORT (AARCH64 ARCHITECTURE) — (top level)

Implements the core AArch64 memory management subsystem (`arch/arm64/mm/`), architecture library routines (`arch/arm64/lib/`), and confidential computing guest drivers (`drivers/virt/coco/`), covering page tables, fault handling, ASID rollover, contpte, HugeTLB, GCS, MTE swap tags, fixmap, instruction encoding, Arm CCA TSM attestation, and pKVM guest hypercalls.

## Architecture & Data Flow
- In `context.c`, `mm->context.id`, `active_asids`, and `reserved_asids` store 64-bit context IDs (generation in `ASID_MASK`), so `asid_map`/`pinned_asid_map` bit ops must strip the generation via `ctxid2asid(asid)`. `new_context()` must start `find_next_zero_bit()` at `>= 1`; `asids_update_limit()` caps `max_pinned_asids` at `num_available_asids - num_possible_cpus() - 2`; and under KPTI (`arm64_kernel_unmapped_at_el0()`), `set_kpti_asid_bits()` fills `asid_map`/`pinned_asid_map` with `0xaa` (using `BITS_TO_LONGS(NUM_USER_ASIDS) * sizeof(unsigned long)` for `memset`) and `arm64_mm_context_get()` sets `asid |= 1` on non-zero ASIDs. [F239, F240, F285, F286]
- In `new_context()`, `check_update_reserved_asid(asid, newasid)` must run before checking `mm->context.pinned` and scan all CPUs in `for_each_possible_cpu()` without early exit. In `flush_context()`, if `atomic64_xchg_relaxed(&per_cpu(active_asids, i), 0)` returns `0`, `per_cpu(reserved_asids, i)` must be preserved and its bit set in `asid_map`. [F174, F209]
- In `contpte_convert()`, `contpte_ptep_get()`, and `contpte_ptep_get_lockless()`, OR dirty and young (`PTE_AF`) bits across all `CONT_PTES` entries in `contpte_align_down(ptep)`; in `contpte_ptep_get*()`, the `pte_dirty(pte)` branch starts its inner `pte_young` scan at `i` without advancing `i`/`ptep`, while `pte_young(pte)` advances `i`, `ptep`, and `pfn` first. [F212, F255]
- Before clearing or write-protecting a PTE range in `contpte_clear_full_ptes()`, `contpte_get_and_clear_full_ptes()`, or `contpte_wrprotect_ptes()`, unfold partially covered `CONT_PTES` blocks via `contpte_try_unfold_partial()` or `__contpte_try_unfold()`. `contpte_ptep_set_access_flags()` must compare `pte_val(pte_mknoncont(ptep_get(ptep))) == pte_val(entry)`; if `pte_write()` is unchanged, update all `CONT_PTES` entries via `__ptep_set_access_flags()`, else unfold via `__contpte_try_unfold()`. [F199, F214, F322]
- `__contpte_try_fold()`, `__contpte_try_unfold()`, and `contpte_set_ptes()` require `mm_is_user(mm)`, and `__contpte_try_fold()` must verify a single non-special `struct folio` spans `CONT_PTE_SIZE`. Aligning `pte_t *` or `pmd_t *` via `PTR_ALIGN_DOWN()` in `contpte.c`/`mmu.c` must multiply `CONT_PTES`/`CONT_PMDS` by `sizeof(*ptep)`/`sizeof(*pmdp)` (VAs use `CONT_PTE_SIZE`, PFNs use `CONT_PTES`). [F277, F320]
- In `hugetlbpage.c`, `clear_flush()` and `get_clear_contig()` must break present contiguous entries with `__ptep_get_and_clear_anysz()` (not `__pte_clear()`) for `page_table_check`. `get_clear_contig()` must guard `pte_dirty()`/`pte_young()` with `pte_present(pte)`, and `huge_ptep_set_access_flags()` on `pte_cont(pte)` must merge dirty/young bits from `get_clear_contig_flush()` into `pte` before `__set_ptes_anysz()`. `huge_pte_alloc()` must use `p4d_alloc(mm, pgdp, addr)` (not `p4d_offset()`), and `huge_pte_offset()` must check `sz != PUD_SIZE && pud_none(pud)` before `pud_leaf(pud) || !pud_present(pud)` and `!(sz == PMD_SIZE || sz == CONT_PMD_SIZE) && pmd_none(pmd)` before `pmd_leaf(pmd) || !pmd_present(pmd)`. [F194, F215, F216, F257, F315]
- In `pgattr_change_is_safe()`, live valid kernel mappings may only modify `PTE_PXN | PTE_RDONLY | PTE_WRITE | PTE_NG | PTE_SWBITS_MASK` (and `MT_NORMAL`/`MT_NORMAL_TAGGED`) without break-before-make, must never change PFN or touch `PTE_CONT` entries, and must reject Non-Global-to-Global transitions via `if (old & ~new & PTE_NG) return false;`. [F259, F309]
- In `mmu.c`, `__pgd_pgtable_alloc()` strips `__GFP_ZERO`, so `alloc_init_*` callers of `pgtable_alloc()` must call `init_clear_pgtable()` before `__p*d_populate()`. `mark_rodata_ro()` must set `WRITE_ONCE(rodata_is_rw, false)` before `update_mapping_prot()` on `__start_rodata..__init_begin`. In `change_memory_common()`, when `rodata_full` is true and `PTE_RDONLY` changes on a `VM_ALLOC` area, apply the change via `__change_memory_common()` to the linear-map alias of each page in `area->pages[]` followed by `vm_unmap_aliases()`. `kernel_page_present()` must always walk `pgd_offset_k(addr)` to the leaf entry even when `!can_set_direct_map()`. [F204, F219, F225, F310]
- In `bootmem_init()`, `arm64_hugetlb_cma_reserve()` follows `arch_numa_init()`, `sparse_init()` follows fixed reservations, and `dma_contiguous_reserve()` follows `zone_sizes_init()` (which sets `zone_dma_limit = U32_MAX` when `memblock_start_of_DRAM() < U32_MAX`). `arch_add_memory()` sets `max_pfn = max(max_pfn, PFN_UP(start + size))` and `max_low_pfn = max_pfn`. `vmemmap_populate()` sub-section ranges must use `vmemmap_populate_basepages()` even on 4K pages. When `!pgdir_is_page_size()`, `pgtable_cache_init()` creates `pgd_cache` with size/alignment `PGD_SIZE`. [F217, F218, F243, F249, F292]
- In `do_page_fault()`, if `faulthandler_disabled() || !mm`, jump to `no_context` before taking locks; check `is_gcs_fault(esr)` before `is_write_abort(esr)` and read-fault branches so all GCS faults set `VM_WRITE` and `FAULT_FLAG_WRITE`; and if `handle_mm_fault()` under `FAULT_FLAG_VMA_LOCK` returns `VM_FAULT_RETRY | VM_FAULT_MAJOR`, set `FAULT_FLAG_TRIED` in `mm_flags`. `esr_to_fault_info()` requires all 64 `fault_info[]` slots populated (`do_bad` for unallocated); `fault_from_pkey()` must use `arch_vma_access_permitted()` (not `ESR_ELx_Overlay`); and `EX_TYPE_UACCESS_CPY` handlers must check `cpy_faulted_on_uaccess(ex, esr)`. [F221, F241, F252, F263, F299, F303]
- Gate `SYS_POR_EL0` and `SYS_GCSPR_EL0`/`SYS_GCSCRE0_EL1` accesses on `system_supports_poe()` and `system_supports_gcs()`. `arch_set_user_pkey_access()` must mask `~(POE_MASK << POR_ELx_PERM_SHIFT(pkey))` and OR in `POR_ELx_PERM_PREP(pkey, new_por)`. In `gcs.c`, `gcs_free()` zeros `gcspr_el0`, `gcs_base`, and `gcs_size`; `arch_set_shadow_stack_status()` rejects `PR_SHADOW_STACK_ENABLE` if `gcs_base` or `gcspr_el0` is non-zero; `gcs_alloc_thread_stack()` calls `alloc_gcs()` only when `(args->flags & (CLONE_VFORK | CLONE_VM)) == CLONE_VM`; and `map_shadow_stack` issues `gcsb_dsync()` after `put_user_gcs()`. [F224, F226, F262, F293, F313]

## Synchronization
- In `do_page_fault()`, pre-fault rejections under `lock_vma_under_rcu()` or `lock_mm_and_find_vma()` must release `vma_end_read(vma)` or `mmap_read_unlock(mm)` before `goto bad_area`, sampling `vma_pkey(vma)` into `pkey` first when `fault_from_pkey(vma, mm_flags)` is true. Post-`handle_mm_fault()`, call `vma_end_read(vma)` only when `!(fault & (VM_FAULT_RETRY | VM_FAULT_COMPLETED))`, and `mmap_read_unlock(mm)` only when `!fault_signal_pending(fault, regs)` and `!(fault & (VM_FAULT_COMPLETED | VM_FAULT_RETRY))`. [F164, F165, F222]
- In `check_and_switch_context()`, the lockless `atomic64_cmpxchg_relaxed()` fastpath on `this_cpu_ptr(&active_asids)` requires non-zero `old_active_asid` and `asid_gen_match(asid)`; if it fails, acquire `cpu_asid_lock`, reload `mm->context.id`, and recheck `asid_gen_match()` before `new_context(mm)`. [F172, F296]
- `set_swapper_pgd()` must remain `noinstr` and, when `!rodata_is_rw`, hold `swapper_pgdir_lock` across `pgd_set_fixmap()`, `WRITE_ONCE(*fixmap_pgdp, pgd)`, and `pgd_clear_fixmap()`, whereas `__create_pgd_mapping()` holds `fixmap_lock`. `split_pmd()`, `split_pud()`, and `init_clear_pgtable()` must issue `dsb(ishst)` before `__pmd_populate()`/`__pud_populate()`. `split_kernel_leaf_mapping()` must hold `pgtable_split_lock` and run before `walk_kernel_page_table_range_lockless()` in `update_range_prot()`. [F179, F180, F186, F306]
- `init_idmap_kpti_bbml2_flag()` must set `idmap_kpti_bbml2_flag = 1` with `smp_mb()` before `stop_machine()`, and CPU 0 in `linear_map_split_to_ptes()` must wait via `smp_cond_load_acquire()` for `num_online_cpus()` before splitting and clear the flag only after `flush_tlb_kernel_range()`. In `__pmd_free_pte_page()` (`acquire_mmap_lock` true) and `pud_free_pmd_page()`, if `arm64_ptdump_lock_key` is enabled, cycle `mmap_read_lock(&init_mm)`/`mmap_read_unlock(&init_mm)` after `__flush_tlb_kernel_pgtable(addr)` before freeing the table. [F181, F227]
- `__ptep_set_access_flags()` must use `cmpxchg_relaxed` with `entry` masked to `PTE_RDONLY | PTE_AF | PTE_WRITE | PTE_DIRTY` and `PTE_RDONLY` inverted before ORing and inverted back. In `contpte_ptep_get_lockless()`, any `contpte_is_consistent()` failure must `goto retry` and discard accumulated dirty/young bits in `orig_pte`. `is_spurious_el1_translation_fault()` must disable IRQs (`local_irq_save()`) and place an `isb()` between `at s1e1r` and `read_sysreg_par()`. [F223, F256, F302]
- `mte_restore_tags()`, `copy_highpage()`, and `tag_clear_highpage()` must acquire `try_page_mte_tagging()`/`folio_try_hugetlb_mte_tagging()` before writing tags and call `set_page_mte_tagged()`/`folio_set_hugetlb_mte_tagged()` afterwards. `__set_memory_enc_dec()` must clear `PTE_VALID` and flush TLBs via `__change_memory_common()` before `rsi_set_memory_range_protected()`/`_shared()`, restoring `PTE_VALID` only on success. [F182, F185]

## Object Lifetimes
- In `mte_save_tags()`, after `xa_store(&mte_pages, ..., tag_storage, GFP_KERNEL)`, free `tag_storage` if `xa_is_err(ret)` or free non-NULL prior `ret` via `mte_free_tag_storage()`. `mte_restore_tags()` must only `xa_load(&mte_pages, entry.val)` without erasing/freeing; tags are freed only by `mte_invalidate_tags*()`. [F158, F160]
- Under `cpu_asid_lock`, `arm64_mm_context_get()` increments `nr_pinned_asids` and sets `pinned_asid_map` only when `mm->context.pinned` transitions `0 -> 1`, and `arm64_mm_context_put()` clears `pinned_asid_map` and decrements `nr_pinned_asids` only when `refcount_dec_and_test(&mm->context.pinned)` is true. [F161]
- `pgd_alloc()`/`pgd_free()` must pair `__pgd_alloc()`/`__pgd_free()` when `pgdir_is_page_size()` and `kmem_cache_alloc()`/`kmem_cache_free()` on `pgd_cache` otherwise. `free_initmem()` must unmap `[__init_begin, __init_end)` via `vunmap_range()` without removing the VM area. `dma-mapping.c` must not define `arch_teardown_dma_ops()` to clear `dev->dma_ops`. In `arm_cca_report_new()`, `arm_cca_attestation_init()` and `arm_cca_attestation_continue()` must run on the same `cpu` via `smp_call_function_single(cpu, ..., &info, true)` (`wait = true`), while `GFP_KERNEL` allocations happen in preemptible context. [F169, F170, F171, F284, F314]

## API Contracts
- In `hugetlbpage.c`, `set_huge_pte_at()`, `huge_pte_clear()`, and `huge_ptep_get_and_clear()` must derive `ncontig` and `pgsize` from `sz` via `num_contig_ptes(sz, &pgsize)`, and HugeTLB helpers must use `__set_ptes_anysz()`/`__ptep_get_and_clear_anysz()` with `pgsize`. In `contpte.c`, `contpte_clear_young_dirty_ptes()` must scale `nr * PAGE_SIZE` for `end` and pass `(end - start) / PAGE_SIZE` to `__clear_young_dirty_ptes()`; `__contpte_try_fold()` callers must check `pte_valid(pte) && !pte_special(pte)`; and `contpte_set_ptes()` requires `nr > 1`. In `copy_highpage()`, `folio_test_hugetlb(src)` must stay in the hugetlb branch (copying tags only if `folio_test_hugetlb_mte_tagged(src)` and `from == folio_page(src, 0)`). [F195, F196, F197, F198, F278, F317]
- `early_fixmap_init*()` must populate `bm_pud`/`bm_pmd`/`bm_pte` via `__p*d_populate()` with `__pa_symbol()`. `__set_fixmap()` requires `idx` in `(FIX_HOLE, __end_of_fixed_addresses)` and must not sleep or use IPIs. `__pa_symbol()` requires `[KERNEL_START, KERNEL_END]` addresses; `virt_to_phys()` requires `__is_lm_address(__tag_reset(x))`. `__create_pgd_mapping_locked()` requires `(phys ^ virt) & ~PAGE_MASK == 0`, and `map_mem()` regions later updated via `update_mapping_prot()` must use `NO_CONT_MAPPINGS`. `change_memory_common()` requires a single `VM_ALLOC` area without `VM_ALLOW_HUGE_VMAP`, using `kasan_reset_tag(area->addr)` for bounds checks. [F202, F203, F205, F206, F236, F248, F307]
- `arm_cca_guest_init()` must check `is_realm_world()`, and `arm_cca_report_new()` must validate `desc->inblob_len` in `[32, 64]`, check signed `long max_size = info.result` (`> 0`) before `kvzalloc()`, and verify `token_size + info.offset <= max_size`. `do_csum()` must check `len <= 0` before `kasan_check_read(buff, len)` and `len + offset - 8`. [F231, F237, F268, F288, F330]

## Error Handling
- `arch_prepare_to_swap()` must unwind failed `mte_save_tags()` loops via `while (i--) __mte_invalidate_tags(folio_page(folio, i));`, and `mte_invalidate_tags_area()` must pass `last_entry.val - 1` to `xas_for_each()`. In `map_shadow_stack`, `put_user_gcs()` callers must initialize `int ret = 0` beforehand and call `vm_munmap(addr, size)` if `ret != 0`. [F159, F162, F200, F245]
- `arch_add_memory()` must roll back `__create_pgd_mapping()` with `__remove_pgd_mapping()` if `__add_pages()` fails (`arch_remove_memory()` calls `__remove_pages()` before `__remove_pgd_mapping()`). `__pgd_pgtable_alloc()` and `try_pgd_pgtable_alloc_init_mm()` return `INVALID_PHYS_ADDR` (`-1ULL`) on failure (never check `!pa`), and `pud_free_pmd_page()` must check `pmd_present(pmdp_get(pmdp))` before `__pmd_free_pte_page()`. [F167, F187, F193]
- In `arm_cca_report_new()`, errors after allocating `token` and `buf` must zero `token_size` and jump to `exit_free_granule_page` before `no_free_ptr(token)`. `mmio_guard_ioremap_hook()` must only issue `MMIO_GUARD` for `PROT_DEVICE_nGnRE`/`nGnRnE` and always return `0`. `aarch64_insn_encode_immediate()` and `aarch64_insn_encode_register()` must return `AARCH64_BREAK_FAULT` immediately if `insn == AARCH64_BREAK_FAULT`. [F189, F192, F323]

## External Contracts
- `map_shadow_stack` requires page-aligned `addr`, 8-byte aligned `size != 8`, and `PAGE_ALIGN(size) >= size`. `arch_set_shadow_stack_status()` rejects `arg & ~PR_SHADOW_STACK_SUPPORTED_STATUS_MASK`, whereas `arch_lock_shadow_stack_status()` ORs all `arg` bits into `gcs_el0_locked`. `set_thread_esr()` must sanitize `!is_ttbr0_addr()` faults to `ESR_ELx_FSC_FAULT`, and `do_mem_abort()`/`do_sea()` must pass `untagged_addr(far)` to `arm64_notify_die()` (or `0` in `do_sea()` when `esr & ESR_ELx_FnV`). [F207, F233, F234, F242]

## Known Pitfalls
- `is_write_abort()` must check `(esr & ESR_ELx_WNR) && !(esr & ESR_ELx_CM)`. In `copy_pmd()`, `copy_pud()`, `copy_p4d()`, and `copy_page_tables()`, `next = p*d_addr_end(addr, end)` must precede `if (p*d_none(...)) continue;`, with pointer/addr increments in `while (...)`. Before `system_capabilities_finalized()`, `force_pte_mapping()` must fall back to `cpu_supports_bbml2_noabort()`, and `linear_map_maybe_split_to_ptes()` must split if `!system_supports_bbml2_noabort()`. `pfn_is_map_memory()` must verify `PHYS_PFN(PFN_PHYS(pfn)) == pfn`. [F253, F258, F271, F291]
