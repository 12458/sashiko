# QCOM AUDIO (ASoC) DRIVERS — sound/soc/codecs (part 1)

Qualcomm ASoC codec drivers and shared helper modules covering the MSM8916/PM8916 analog and digital codecs, the PM4125 SoundWire/SPMI codec, the WCD9335 SLIMbus codec, and common Class-H (`wcd-clsh-v2`) and Multi-Button Headset Control (`wcd-mbhc-v2`) libraries.

## Architecture & Data Flow
- In `pm4125-sdw.c`, `priv->regmap` is allocated only on the TX slave (`priv->is_tx`) and is `NULL` on RX; it must start in `regcache_cache_only(priv->regmap, true)` in `pm4125_probe` and only exit cache-only mode and `regcache_sync` on `SDW_SLAVE_ATTACHED` in `pm4125_update_status` or in `pm4125_sdw_runtime_resume`. Shared callbacks (`pm4125_update_status`, `pm4125_sdw_runtime_suspend`/`resume`) must check `if (priv->regmap)`. [F32, F96]
- On PM4125, `dev_get_drvdata(&slave->dev)` on SoundWire slaves must remain `struct pm4125_sdw_priv *`, whereas `dev_get_drvdata(dev)` on the master platform device, component, and DAIs is `struct pm4125_priv *`. On WCD9335, `wcd9335_slim_probe` sets `dev_set_drvdata(&slim->dev, wcd)` and `wcd9335_codec_probe` never calls `snd_soc_component_set_drvdata`, so both `dev_get_drvdata(comp->dev)` and `snd_soc_component_get_drvdata(comp)` must return `struct wcd9335_codec *`. [F86, F87]
- In `pm4125_connect_port()`, `port_idx` is 1-based (`sdw_priv->port_config[port_idx - 1]` and `sdev->m_port_map[port_num]`, populated from index 1), `ch_id` is 0-based (`sdw_priv->ch_info[ch_id]`), and `PM4125_SWRM_CH_MASK(ch_idx)` takes 1..8 (`BIT(ch_idx - 1)` stored in `u8 mstr_ch_mask`). Channel updates must modify `port_config[port_idx - 1].ch_mask` and `master_channel_map[sdev->m_port_map[port_num]]` in lockstep. [F36, F48, F81]
- In `pm4125_sdw_hw_params`, the loop over `priv->port_config[0..PM4125_MAX_SWR_PORTS-1]` must skip zero `ch_mask` entries, compact active ports into `port_config[priv->active_ports++]` before `sdw_stream_add_slave`, and note `for_each_set_bit(j, &ch_mask, 4)` only counts bits 0..3 toward `priv->sconfig.ch_count`. [F72, F91]
- `MIC_BIAS_1`..`4` are 1-based: `pm4125_micbias_control` and `wcd9335_micbias_control` must use `micb_index = micb_num - 1` and check `0 <= micb_index < MAX_MICBIAS`. `MICB_PULLUP_ENABLE` writes pullup bits only when `pullup_ref == 1 && micb_ref == 0`, and `MICB_DISABLE` reaching `micb_ref == 0` must switch to pullup mode if `pullup_ref > 0`. In `pm4125_codec_enable_micbias`, `MIC_BIAS_3` must use `MICB_PULLUP_ENABLE`/`DISABLE` (`enable_mask` is 0). [F57, F74, F109]
- In WCD9335, `wcd->tx_chs[port_id].list` and `rx_chs[port_id].list` are shared across DAIs: `slim_tx_mixer_put` must guard `list_add_tail` with `wcd->tx_port_value[port_id] != dai_id` and `list_del_init` with `tx_port_value[port_id] == dai_id` (setting `tx_port_value = -1`), and `slim_rx_mux_put` must call `list_del_init` before re-adding. [F7]
- In `wcd9335.c`, `wcd9335_put_dec_enum` must update `WCD9335_CDC_TX_ADC_AMIC_DMIC_SEL_MASK` in `WCD9335_CDC_TX0..8_TX_PATH_CFG0` when ADC MUX0..8 changes between DMIC (`0`) and AMIC, and `wcd9335_int_dem_inp_mux_put` must update `WCD9335_CDC_RX_PATH_CFG0_DLY_ZN_EN_MASK` in `WCD9335_CDC_RX{0,1,2}_RX_PATH_CFG0` in lockstep with `RX_PATH_SEC0`. [F51, F52]
- In `wcd9335.c`, `INTERP_EAR` (`0`) has no compander, so `wcd9335_config_compander` must return early when `!interp_n` and use `comp = interp_n - 1` to index `wcd->comp_enabled`, `WCD9335_CDC_COMPANDER1_CTL`, and `WCD9335_CDC_RX1_RX_PATH_CFG`. `wcd9335_codec_find_amic_input` must reject `adc_mux_n == WCD9335_INVALID_ADC_MUX` (`9`), `< 0`, or `> WCD9335_MAX_VALID_ADC_MUX` (`13`), using a 2-register stride from `ADC_MUX0_CFG0` for `adc_mux_n < 4` and a 1-register stride from `ADC_MUX4_CFG0` for `>= 4`. [F61, F62]
- `wcd9335_codec_hph_mode_gain_opt` must only overwrite `WCD9335_HPH_L_EN`/`R_EN` and cache the 5-bit gain into `wcd->hph_l_gain`/`hph_r_gain` when the corresponding PA bit in `WCD9335_ANA_HPH` is off and the register value differs from `l_val`/`r_val`. In `wcd9335_power_on_reset`, sleep at least 600us (`usleep_range(600, 650)`) after enabling regulators in `wcd9335_parse_dt` before pulling `wcd->reset_gpio` high. [F42, F106]
- In `wcd-mbhc-v2.c`, `wcd_mbhc_report_plug_insertion` must skip `wcd_mbhc_compute_impedance` when `WCD_MBHC_HPH_PA_EN` is set and preserve `SND_JACK_LINEOUT` / `MBHC_PLUG_TYPE_HIGH_HPH` via `mbhc->force_linein` until `wcd_mbhc_report_plug_removal` clears it. [F43]
- In `wcd_mbhc_adc_hs_rem_irq`, check `mbhc->current_plug == MBHC_PLUG_TYPE_HEADPHONE` (setting `mbhc->extn_cable_hph_rem = true`) before `wcd_mbhc_elec_hs_report_unplug` overwrites `current_plug`. In `wcd_correct_swch_plug`, set `WCD_MBHC_DETECTION_DONE` to `1` only for `MBHC_PLUG_TYPE_HEADSET` (`0` otherwise), and re-enable `mbhc->intr_ids->mbhc_hs_ins_intr` on exit for `MBHC_PLUG_TYPE_HEADPHONE`. [F71, F103]
- In `wcd-mbhc-v2.c`, jiffies timeouts in `wcd_correct_swch_plug()` and `wcd_mbhc_adc_hs_rem_irq()` must use `time_after(jiffies, timeout)`, and button debounce elapsed time in `wcd_mbhc_btn_press_handler()` must use `jiffies_to_msecs(jiffies - mbhc->jiffies_atreport)`. [F82]
- In `msm8916-wcd-analog.c`, while `priv->detect_accessory_type` is true, `mbhc_btn_press_irq_handler` must suppress `SND_JACK_BTN_0` and `mbhc_btn_release_irq_handler` must set `priv->mbhc_btn0_released`, which `pm8916_mbhc_switch_irq_handler` consumes on insertion and resets (`detect_accessory_type = true`, `mbhc_btn0_released = false`) on removal. [F47]
- In `pm8916_wcd_analog_enable_adc`, `PRE_PMU` must sleep 10ms before setting the TXFE init bit in `CDC_A_TX_1_2_TEST_CTL_2`, `POST_PMU` must sleep 12ms before clearing it, and in `POST_PMD` `CDC_A_TX_2_EN` must clear `MICB_1_CTL_CFILT_REF_SEL_MASK` in `CDC_A_MICB_1_CTL` and fall through to `CDC_A_TX_3_EN` to reset `CDC_D_CDC_CONN_TX2_CTL`. [F65, F105]
- In `msm8916-wcd-digital.c`, `msm8x16_wcd_get/put_iir_band_audio_mixer` `memcpy` `ctl->bytes_ext.max` bytes into a stack `u32 coeff[BAND_MAX]` buffer, so `bytes_ext.max` must not exceed `WCD_IIR_FILTER_SIZE` (`sizeof(u32) * BAND_MAX`). [F83]

## Synchronization
- `wcd_mbhc_report_plug()`, `wcd_mbhc_adc_detect_plug_type()`, `wcd_schedule_hs_detect_plug()`, and `wcd_cancel_hs_detect_plug()` (`wcd_mbhc_cancel_pending_work()`) require `mbhc->lock` held; `wcd_cancel_hs_detect_plug()` sets `mbhc->hs_detect_work_stop = true`, drops `mbhc->lock` across `cancel_work_sync(work)`, and re-acquires `mbhc->lock`. Never call `cancel_work_sync(&mbhc->correct_plug_swch)` directly under `mbhc->lock`. [F2, F13]
- In `mbhc_plug_detect_fn()`, set `mbhc->in_swch_irq_handler = true` before `wcd_mbhc_cancel_pending_work()` drops `mbhc->lock`, and read `mbhc->current_plug` only after `mbhc->lock` is re-acquired. [F16]
- `wcd_btn_long_press_fn` (`mbhc->mbhc_btn_dwork`) must never acquire `mbhc->lock` because `wcd_cancel_btn_work` calls `cancel_delayed_work_sync(&mbhc->mbhc_btn_dwork)` under `mbhc->lock`. Disabling `mbhc_hs_ins_intr` or `mbhc_hs_rem_intr` inside `wcd_mbhc_adc_hs_ins_irq`, `wcd_mbhc_elec_hs_report_unplug`, or `mbhc_plug_detect_fn` must use `disable_irq_nosync`, not `disable_irq`. [F113, F114]
- `pm4125_bind()` must create `DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME` device links from `rxdev` to `txdev` and `dev` to `txdev`/`rxdev` before registering the component (removing all three via `device_link_remove` on error or in `pm4125_unbind()`), and `pm4125_soc_codec_probe()` must wait on `tx_sdw_dev->initialization_complete` before `pm_runtime_resume_and_get()` and `pm4125_io_init()`. [F22, F97]
- `pm4125_global_mbias_enable()`/`disable()` must gate `PM4125_ANA_MBIAS_EN` updates with `atomic_inc_return(&pm4125->gloal_mbias_cnt) == 1` and `atomic_dec_and_test(&pm4125->gloal_mbias_cnt)`. [F23]
- `wcd_clsh_ctrl_set_state` and `wcd_clsh_set_hph_mode` call `usleep_range` and mutate `struct wcd_clsh_ctrl` without internal locks, so callers must invoke them only from sleepable process context under the ASoC DAPM or card lock. [F116]

## Object Lifetimes
- `wcd_mbhc_init()` must use non-devm `kzalloc` and initialize `mbhc->lock`, `mbhc_btn_dwork`, `correct_plug_swch`, and `mbhc_plug_detect_work` before requesting the seven MBHC IRQs via non-devm `request_threaded_irq`, and `wcd_mbhc_deinit()` must `free_irq()` all seven before cancelling work and `kfree(mbhc)`. [F17, F92]
- `wcd_clsh_ctrl_alloc` uses `kzalloc` and returns `ERR_PTR(-ENOMEM)` on failure; callers must check `IS_ERR()` and call `wcd_clsh_ctrl_free` on probe error and in `.remove` (`wcd9335_codec_remove`). [F5]
- In `wcd9335_trigger`, stop/suspend/pause must call `slim_stream_disable` before `slim_stream_unprepare`. In `wcd9335_cdc_req_mclk_enable`, enable `wcd9335_enable_master_bias` before `wcd9335_enable_mclk`, and disable `wcd9335_disable_mclk` before `wcd9335_disable_master_bias`, `clk_disable_unprepare(wcd->mclk)`, and `wcd9335_cdc_sido_ccl_enable(wcd, false)`. [F1, F6]
- `wcd9335_slim_set_hw_params` allocates `cfg->chs` (`dai_data->sconfig.chs`) via `kcalloc`, which must be freed and cleared (`cfg->chs = NULL`) on error and freed on `SND_SOC_DAPM_POST_PMD` in `wcd9335_codec_enable_slim`. [F8]
- In `pm4125_add_slave_components`, `component_match_add_release` (`component_release_of`) takes ownership of `pm4125->rxnode` and `txnode`, so callers must not call `of_node_put` on them. In `wcd9335_parse_dt` and `pm4125_probe`, bulk regulators without manual teardown in `.remove` must use `devm_regulator_bulk_get_enable`. [F11, F95]

## API Contracts
- `wcd_mbhc_init` and `wcd_mbhc_start` store borrowed pointers to `mbhc_cb`, `intr_ids`, `fields` (at least `WCD_MBHC_REG_FUNC_MAX` elements), `cfg`, and `jack` without copying, which must outlive `wcd_mbhc_deinit`. `wcd_mbhc_start()` must set `mbhc->cfg` and `mbhc->jack` before `wcd_mbhc_initialise()`. [F4, F18, F84]
- `wcd_mbhc_init` requires non-NULL `intr_ids`, `fields`, `mbhc_cb`, `mbhc_cb->mbhc_bias`, and `mbhc_cb->set_btn_thr` (setting `mbhc->impedance_detect` only if `compute_impedance` is set). Other `mbhc_cb` callbacks may be NULL and unsupported `mbhc->fields[]` entries may have `.reg == 0`, so field accesses must use `wcd_mbhc_read_field()`/`write_field()` and optional callbacks must be null-checked. [F31, F117]
- Callers of `wcd_mbhc_start()` with non-zero `cfg->hs_thr` or `hph_thr` must set a non-zero `cfg->micb_mv`, and `get_micbias_val` callbacks must write a positive mV value into `*mb`, as threshold helpers and `wcd_correct_swch_plug()` divide by them without zero checks. `set_btn_thr` callbacks (`pm4125_mbhc_program_btn_thr`) must check `num_btn <= WCD_MBHC_DEF_BUTTONS` (8). [F59, F78, F79]
- `wcd_measure_adc_once()` returns `>= 0` mV or `-EINVAL`, and `wcd_check_cross_conn()` returns `< 0` (error/active PA), `0` (none), or `1` (cross-connected); store both in signed `int`s and test `< 0` vs `> 0`. `wcd_mbhc_get_impedance()` writes `*zl`/`*zr` and returns `0` only if both `mbhc->zl` and `zr` are non-zero (`-EINVAL` otherwise). [F29, F30]
- `wcd_clsh_ctrl_set_state()` and `_wcd_clsh_ctrl_set_state()` accept only a single state constant (rejecting bitwise ORs with `-EINVAL`) and branch on `ctrl->codec_version >= WCD937X`: v2 (`< WCD937X`) supports `WCD_CLSH_STATE_LO` (`CLS_AB`), rejects `CLS_H_NORMAL` on HPHL/R, and requires `CLS_H_LOHIFI` mapped to `CLS_H_HIFI`; v3 (`>= WCD937X`) supports `WCD_CLSH_STATE_AUX` and v3 sequences in `wcd_clsh_set_hph_mode`. [F37, F110]
- `pm4125_sdw_device_get()` returns `NULL` (not `ERR_PTR`) on failure; callers must check for `NULL`. In `pm4125_get_channel_map()` and `wcd9335_get_channel_map()`, callers may pass `NULL` for the unused direction's pointers, so playback DAIs must only touch `rx_num`/`rx_slot` and capture DAIs only `tx_num`/`tx_slot`. [F28, F39]
- In `pm4125_codec_irq_chip_map`, the parent virq uses `irq_set_nested_thread(virq, 1)` and `pm4125_interrupt_callback` loops `handle_nested_irq(irq_find_mapping(slave_irq, 0))` while `PM4125_DIG_SWR_INTR_STATUS_0..2` is non-zero (with `pm4125_handle_post_irq` clearing `INTR_CLEAR_0..2` to 0); child IRQs on `pm4125->irq_chip` must use threaded handlers (`NULL` hardirq handler). [F100, F115]
- In `wcd9335.c`, SLIMbus interface lookup, `slim_get_logical_addr`, `regmap_init_slimbus`, `wcd9335_bring_up`, and component registration must be deferred from `wcd9335_slim_probe` to `wcd9335_slim_status`, and custom DAPM `.put` callbacks must call `snd_soc_dapm_mux_update_power`, `snd_soc_dapm_mixer_update_power`, or `snd_soc_dapm_put_enum_double`. [F121, F126]
- When changing exported declarations in `wcd-mbhc-v2.h` or `pm4125.h`, update both the `#if IS_ENABLED(...)` prototypes and the `#else` static inline stubs. [F54]

## Error Handling
- In `wcd9335_slimbus_irq`, on `WCD9335_SLIM_IRQ_OVERFLOW` or `UNDERFLOW`, log with `dev_err_ratelimited` and clear that port's enable bit in `WCD9335_SLIM_PGD_PORT_INT_EN0` / `TX_EN0` until `wcd9335_codec_enable_int_port` re-enables it on `SND_SOC_DAPM_POST_PMU`. [F128]

## External Contracts
- In `get_iir_band_coeff` and `set_iir_band_coeff`, each 32-bit coefficient is transferred as 4 little-endian bytes via `LPASS_CDC_IIR1_COEF_B2_CTL + 64 * iir_idx` (address `& 0x7F`, byte 3 `& 0x3F`), and reads must rewrite the byte offset to `LPASS_CDC_IIR1_COEF_B1_CTL + 64 * iir_idx` before every byte read. [F63]
- `wcd_dt_parse_mbhc_data` and `pm4125_dt_parse_micbias_info` divide `"qcom,*-microvolt"` DT properties by 1000, storing `hs_thr`, `hph_thr`, `btn_high`, `micb_mv`, and `micb1_mv`..`micb3_mv` in millivolts. [F118]
- In `wcd_mbhc_report_plug_removal`, cancel `mbhc_btn_dwork` via `wcd_cancel_btn_work`, and if it returns `0` while `mbhc->buttons_pressed` is non-zero, report a button release (`0`) via `snd_soc_jack_report` before reporting jack removal. [F127]

## Known Pitfalls
- Pass unshifted values to `wcd_mbhc_write_field()` and `snd_soc_component_write_field()`, which shift `val` by `__ffs(mask)` (unlike `snd_soc_component_update_bits()` / `regmap_update_bits()`). [F80]
- In `wcd_mbhc_initialise` and `wcd_correct_swch_plug`, which proceed on `-EACCES` and unconditionally call `pm_runtime_put_autosuspend` on exit, use `pm_runtime_get_sync` (with `pm_runtime_put_noidle` on `ret < 0 && ret != -EACCES`), never `pm_runtime_resume_and_get`. [F94]
- In `wcd9335_codec`, `rx_chs` stores `ch->port` offset by `WCD9335_RX_START` (16..28), so `wcd9335_codec_enable_int_port` must subtract `WCD9335_RX_START` when `ch->port >= WCD9335_RX_START`. In `wcd9335_slimbus_irq`, `for_each_set_bit(j, &status, 32)` must use `port_id = (j >= 16 ? j - 16 : j)` for `PORT_INT_EN0` / `TX_EN0` bit checks, but raw index `j` for `PORT_INT_RX_SOURCE0` and `PORT_INT_CLR_RX_0`. [F60, F77]
- DAPM widget name parsing in WCD9335 and MSM8916 digital codecs is strict: `wcd9335_codec_enable_dec` copies 15 bytes of `w->name`, splits on `" "` with `strsep`, and passes `strpbrk(..., "012345678")` to `kstrtouint` (`<= 15` chars, space before digit, no suffix); `wcd9335_codec_enable_dmic` and `msm8916_wcd_digital_enable_dmic` pass `strpbrk(w->name, ...)` to `kstrtouint` (no digits in prefix, no suffix); and `__wcd9335_codec_enable_micbias` uses `strnstr(w->name, "MIC BIAS1", sizeof("MIC BIAS1"))` (must start with `"MIC BIAS1"`..`"4"` with no prefix). [F88, F89, F90]
