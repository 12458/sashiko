# BLOCK LAYER — block (part 1)

Core block layer foundation for `bdev` lifecycle/claiming, `bio` management, request submission/plugging/merging, user/kernel buffer mapping, `blk-crypto`, `bio-integrity`, `blk-flush`, badblocks, `io_context`/`io_cq`, and blkcg.

## Architecture & Data Flow
- `bdev_freeze()` and `bdev_thaw()` keep `bd_fsfreeze_count` balanced under `bd_fsfreeze_mutex`, decrementing if initial freeze fails and re-incrementing if final thaw fails. [F2]
- `__bio_advance()` advances `bio_integrity_advance()` and `bio_crypt_advance()` with `bio_advance_iter()`. When `bio_split()` or `bio_trim()` shrinks `bi_iter.bi_size` on an integrity bio, call `bio_integrity_trim()` after updating `bi_iter.bi_size`. `bio_truncate()` only reduces `bi_iter.bi_size` (and zeroes read tails) without changing `bi_io_vec` or `bi_vcnt`. `bio_reset()` calls `bio_uninit(bio)`, zeroes only `BIO_RESET_BYTES` (`offsetof(struct bio, bi_max_vecs)`), and sets `__bi_remaining = 1` while preserving `bi_max_vecs`, `__bi_cnt`, `bi_io_vec`, and `bi_pool`. [F69, F70, F80, F98]
- `__submit_bio_noacct()` moves `bio_list_on_stack[0]` to `[1]` before `__submit_bio(bio)`, splits new `[0]` bios into `lower` and `same` queue lists, and merges `lower`, `same`, then `[1]`. In `submit_bio_noacct_nocheck()` with active `current->bio_list` and `split == true` (`bio_submit_split_bioset()`), queue the remainder at the head of `current->bio_list[0]` via `bio_list_add_head()`, and call `trace_block_split()` after `bio_split()` advances `bi_sector` and before resubmitting. [F72, F119, F197]
- `blk_attempt_plug_merge()` checks `plug->mq_list.tail` first. `flush_plug_callbacks()` drains `plug->cb_list` in a `while (!list_empty(&plug->cb_list))` loop using `list_splice_init()`. Before merging requests/bios with `RQF_MIXED_MERGE` or differing `REQ_FAILFAST_MASK` / `REQ_RAHEAD` flags, `blk_rq_set_mixed_merge()` propagates `rq->cmd_flags & REQ_FAILFAST_MASK` to each bio on `rq` and sets `RQF_MIXED_MERGE`, and `blk_update_mixed_merge()` updates `req->cmd_flags` on front-merge. `blk_cgroup_mergeable()` requires matching `bi_blkg` and `bio_issue_as_root_blkg()`. [F73, F76, F126, F213]
- `bio_crypt_ctx_mergeable(bc1, bc1_bytes, bc2)` checks DUN continuity in `@bc1` then `@bc2` order; `bio_attempt_front_merge()` passes `(bio->bi_crypt_context, bio->bi_iter.bi_size, req->crypt_ctx)` and updates `req->crypt_ctx->bc_dun` via `bio_crypt_do_front_merge()`, whereas back-merge and `blk_rq_append_bio()` call `bio_crypt_free_ctx(bio)`. `bc_dun` is a little-endian `u64[BLK_CRYPTO_DUN_ARRAY_SIZE]` array: `bio_crypt_dun_increment()` and `bio_crypt_dun_is_contiguous()` propagate 64-bit carry across all limbs (rejecting merges if final `carry != 0`), and `blk_crypto_dun_to_iv()` converts limbs with `cpu_to_le64()`. [F60, F74, F107, F142]
- `blk-integrity` and `blk-crypto` are mutually exclusive (`blk_crypto_register()` rejects integrity queues; `bio_integrity_alloc()` returns `ERR_PTR(-EOPNOTSUPP)` if `bio_has_crypt_ctx(bio)`). `bio_integrity_init/free/finish()` set/clear `REQ_INTEGRITY` in `bio->bi_opf` with `bio->bi_integrity`. In `bio_integrity_prep()`, `REQ_OP_WRITE` buffer allocation adds `__GFP_ZERO` when `BLK_INTEGRITY_NOGENERATE` or `BLK_INTEGRITY_CSUM_NONE` is set; `REQ_OP_READ` saves `bid->saved_bio_iter = bio->bi_iter` before submission for `bio_integrity_verify_fn()`. `bio_integrity_copy_user()` on `READ` allocates `nr_vecs + 1` bvecs (`bip_vec[0]` bounce buffer, `&bip_vec[1]` pinned user bvecs). [F64, F71, F86, F87, F210]
- `blk_insert_flush()` requires a single-bio request (`rq->bio == rq->biotail`, no merging on `REQ_PREFLUSH`/`REQ_FUA`) so `blk_flush_restore_request()` restores `rq->bio = rq->biotail`, `rq->__sector`, `rq->end_io`, and clears `RQF_FLUSH_SEQ`. `rq->flush.seq` only sets bits in `REQ_FSEQ_ACTIONS` (bits 0..2, leaving bit 3 `REQ_FSEQ_DONE` clear for `1 << ffz(rq->flush.seq)`); for `REQ_FSEQ_DATA | REQ_FSEQ_POSTFLUSH`, `blk_insert_flush()` pre-sets `REQ_FSEQ_PREFLUSH`. `blk_alloc_flush_queue()` sizes `fq->flush_rq` to `round_up(sizeof(struct request) + cmd_size, cache_line_size())`. `flush_pending_idx == flush_running_idx` when idle and toggles via `^= 1` under `fq->mq_flush_lock`; `flush_end_io()` toggles `flush_running_idx ^= 1` before `list_for_each_entry_safe()` and `list_del_init(&rq->queuelist)` before `blk_flush_complete_seq()`. [F77, F79, F121, F122, F137, F160]
- Badblocks functions shifting by `bb->shift` must first verify `bb->shift >= 0`. `BB_MAKE(a, l, ack)` stores `(l) - 1` (`1 <= l <= BB_MAX_LEN`, `bb->count <= MAX_BADBLOCKS`). `front_overwrite()` and `front_splitting_clear()` save `BB_END(p[prev])` and `BB_ACK(p[prev])` before mutating `p[prev]`. In `_badblocks_set()`, after `insert_at(bb, 0, &bad)` or `insert_at(bb, prev + 1, &bad)`, set `hint = ++prev` before `try_adjacent_combine(bb, prev)`. [F90, F108, F116, F136]

## Synchronization
- `bdev_freeze()`, `bdev_thaw()`, and `bdev_mark_dead()` lock `bd_holder_lock` before `bd_holder_ops->freeze`/`thaw`/`mark_dead`, and the callback must unlock `bd_holder_lock` before returning. `set_blocksize()` holds `inode_lock(inode)` and `filemap_invalidate_lock(inode->i_mapping)` across `sync_blockdev()`, `kill_bdev()`, `i_blkbits` update, and `mapping_set_folio_min_order()`. In `sync_bdevs()`, pin `inode` via `__iget(inode)` under `i_lock` before dropping `s_inode_list_lock`, and call `iput(old_inode)` or lock `open_mutex` only after releasing `s_inode_list_lock`. [F35, F37, F190]
- When `current->bio_list` is non-empty and `bs->rescue_workqueue` is set, `bio_alloc_bioset()` clears `__GFP_DIRECT_RECLAIM` initially and on failure calls `punt_bios_to_rescuer(bs)` (punting only bios with `bio->bi_pool == bs`) before retrying. Because `bio` slabs use `SLAB_TYPESAFE_BY_RCU`, `iocb_bio_iopoll()` holds `rcu_read_lock()` around `READ_ONCE(kiocb->private)` and `bio_poll()`, which `READ_ONCE()`s `bi_cookie`/`bi_bdev` and pins `percpu_ref_tryget(&q->q_usage_counter)`. [F42, F83, F177]
- Direct-I/O reads dirty user folios in process context before submission via `bio_set_pages_dirty()`; IRQ-capable completions use `bio_check_pages_dirty()` (which consumes `@bio`, overwrites `bi_private`, and calls `bio_release_pages()` + `bio_put()`). `bio_integrity_unpin_bvec()` only calls `unpin_user_page()` (never `set_page_dirty_lock()`), `__bio_integrity_endio()` on `REQ_OP_READ` defers verification to `kintegrityd_wq`, and `blk_crypto_fallback_decrypt_endio()` queues decryption to `blk_crypto_wq`. [F10, F170, F171, F172, F173]
- In `blk_queue_enter()` and `__bio_queue_enter()`, after `blk_try_enter_queue()` fails, `smp_rmb()` must precede `wait_event(q->mq_freeze_wq, ...)`. While a queue is frozen (`q->io_lockdep_map` / `q->q_lockdep_map` held, ordered inside `fs_reclaim`), code must not acquire `fs_reclaim` or `cpu_hotplug_lock` (`static_branch_inc/dec()`). [F41, F192]
- `io_cq` teardown requires `q->queue_lock` -> `ioc->lock` order: `put_io_context()` defers non-empty `icq_list` teardown to `ioc_release_fn()`, which drops `ioc->lock` under `rcu_read_lock()` if `spin_trylock(&q->queue_lock)` fails. `set_task_ioprio()` checks permissions under `rcu_read_lock()` (`__task_cred(task)` / `CAP_SYS_NICE` and `security_task_setioprio()`); if `task_lock(task)` is dropped to allocate `ioc`, recheck `PF_EXITING` and `task->io_context` after re-locking and free `ioc` if set. `blkg_lookup()` and `blkg_for_each_descendant_*()` require `rcu_read_lock()`, and `blkg_rwstat_recursive_sum()` also requires `q->queue_lock`. Blkcg config handlers taking `q->elevator_lock` alongside `q->rq_qos_mutex` must use `blkg_conf_open_bdev_frozen()` / `blkg_conf_exit_frozen()`. [F15, F28, F29, F31, F214]
- `blk_crypto_hw_enter()` calls `pm_runtime_get_sync(profile->dev)` before `down_write(&profile->lock)`, whereas `blk_crypto_reprogram_all_keys()` takes `profile->lock` without `pm_runtime_get_sync()`. `profile->idle_slots_lock` nests inside `profile->lock` with IRQs disabled, removing/re-adding `slot->idle_slot_node` on `0 <-> 1` `slot_refs` transitions. In `blk_crypto_get_keyslot()`, after a read-lock miss, re-call `blk_crypto_find_and_grab_keyslot()` and recheck `!list_empty(&profile->idle_slots)` after each `blk_crypto_hw_enter()`, and call `blk_crypto_hw_exit()` before `wait_event()`. `blk_crypto_fallback_start_using_mode()` initializes all `blk_crypto_keyslots[i].tfms[mode_num]` under `tfms_init_lock` before `smp_store_release(&tfms_inited[mode_num], true)`. [F26, F33, F92, F162, F181]
- `fq->mq_flush_lock` requires IRQs disabled, and `q->requeue_lock` nests inside it. In `blk_kick_flush()`, set `flush_rq->end_io = flush_end_io` before `smp_wmb()` and `req_ref_set(flush_rq, 1)`. `_badblocks_set/clear()` and `ack_all_badblocks()` require `write_seqlock_irq/irqsave(&bb->lock)`. [F25, F34, F188]

## Object Lifetimes
- `bdev_file->private_data` stores `ERR_PTR(ret)` if `bdev_open()` fails in `bdev_file_open_by_dev()` (after `ihold(BD_INODE(bdev))`, before `fput(bdev_file)` so `bdev_release()` only calls `blkdev_put_no_open(bdev)`) and stores `BDEV_I(bdev_file->f_mapping->host)` when `bdev_fput()` yields write access/claim under `disk->open_mutex`; readers must check `IS_ERR()` and `bdev_unclaimed()`. `bd_prepare_to_claim()` must pair on all paths with `bd_finish_claiming()` or `bd_abort_claiming()`. [F3, F4, F5, F149]
- Bios initialized via `bio_init()` / `bio_init_inline()` (stack or `bio_kmalloc()`) require `bio_uninit()` before freeing (`bio_put()` requires `bio->bi_pool`). Bios from `blk_rq_map_bio_alloc()` must be freed via `blk_mq_map_bio_put()`. Cloned/split bios borrow `@bio_src->bi_io_vec` and `bip_vec` without page refs, so `@bio_src` must outlive them; if `__bio_clone()` fails in `bio_integrity_clone()`, callers must still call `bio_uninit()` or `bio_put()`. [F6, F8, F16, F51]
- `bioset_exit()` calls `bio_alloc_cache_destroy(bs)` and `destroy_workqueue(bs->rescue_workqueue)` before exiting `bio_pool`, `bvec_pool`, and `bio_put_slab(bs)`. `blk_free_queue()` defers `percpu_ref_exit(&q->q_usage_counter)` and `kmem_cache_free()` to `blk_free_queue_rcu()`. `__submit_bio_noacct*()` resets `current->bio_list = NULL` before returning. `blk_start_plug_nr_ios()` does not overwrite a non-NULL `current->plug`, and `blk_finish_plug(plug)` flushes/clears `current->plug` only if `plug == current->plug`. `attempt_merge()` transfers `next->bio`, calls `blk_crypto_rq_put_keyslot(next)`, sets `next->bio = NULL`, and returns `next` for the caller to free. [F13, F14, F18, F40, F161]
- `bio_alloc_map_data()` rejects `data->nr_segs > UIO_MAXIOV` and, when `iter_is_iovec(data)`, deep-copies `iter_iov(data)` into `bmd->iov` and repoints `bmd->iter.__iov = bmd->iov`. In `__bio_release_pages()`, `nr_pages` for a folio segment is `(fi.offset + fi.length - 1) / PAGE_SIZE - fi.offset / PAGE_SIZE + 1`. In `bio-integrity.c`, `bip` must be first in `struct bio_integrity_alloc`, and `BIP_BLOCK_INTEGRITY` is only for `struct bio_integrity_data` (`bid_pool`). `__blk_crypto_evict_key()` unconditionally runs `hlist_del(&slot->hash_node)` and `slot->key = NULL`. `devm_blk_crypto_profile_init()` profiles must not call `blk_crypto_profile_destroy()`. `__badblocks_init()` binds `bb->page` to `bb->dev`, which must not change before `badblocks_exit()`. [F22, F99, F141, F150, F152, F164, F165]

## API Contracts
- `set_blocksize()` returns `0` or `< 0`; `sb_set_blocksize()` and `sb_min_blocksize()` return block size or `0` on failure. `submit_bio_wait()` does not consume the caller's `@bio` ref, whereas `bio_chain(bio, parent)` requires `!bio->bi_private && !bio->bi_end_io` and consumes `bio`. `bio_split()` returns `ERR_PTR` on failure without ending `@bio`, whereas `bio_submit_split_bioset()`, `bio_integrity_prep()`, and `__blk_crypto_bio_prep()` set `bi_status`, call `bio_endio(bio)`, and return `NULL`/`false`. `bio_split_io_at()` returns `< 0` (error), `0` (no split), or `> 0` split sectors (`blk_rq_append_bio()` returns `-EREMOTEIO` when `> 0`). [F7, F9, F19, F48, F49, F50]
- `bio_split()` and `bio_trim()` take 512-byte sectors (`bio_trim()` checks `offset, size <= BIO_MAX_SECTORS` and `offset + size <= bio_sectors(bio)` before `<< 9`), while `bio_advance*()` and `bio_integrity_advance()` take bytes. Helpers sizing `bi_iter.bi_size` from sectors (`bio_discard_limit()`, `bio_write_zeroes_limit()`, `blkdev_issue_secure_erase()`, `bio_allowed_max_sectors()`) cap sectors to `UINT_MAX >> SECTOR_SHIFT` before `<< SECTOR_SHIFT`. Adding data to a bio (`bio_add_page()`, `bio_add_folio*()`, `bio_full()`, `__bio_iov_iter_get_pages()`) caps `len` against `UINT_MAX - bio->bi_iter.bi_size`, and `bio_add_folio*()` converts `off` to `folio_page(folio, off / PAGE_SIZE)` and `off % PAGE_SIZE`. [F56, F97, F129, F132, F133]
- `bio_kmalloc()` rejects `nr_vecs > BIO_MAX_INLINE_VECS`. `bvec_alloc()` updates `*nr_vecs` in place, which must be saved in `bio->bi_max_vecs`. With `bioset_init()` `front_pad > 0`, `struct bio` must be the last member of the outer struct. `blk_rq_map_user()` and `blk_rq_integrity_map_user()` use `iov_iter` direction `rq_data_dir(rq)`. `blk_rq_map_kern()` uses `bio_copy_kern()` when `object_is_on_stack(kbuf)` or unaligned. `bio_add_vmalloc*()` flushes vmap only on writes; read completions must call `invalidate_kernel_vmap_range()`. `bio_integrity_map_iter()` checks `meta->iter.count >= integrity_bytes` and `!(meta->flags & ~IO_INTEGRITY_VALID_FLAGS)`, truncating the `iov_iter` to `integrity_bytes`. [F54, F62, F93, F102, F144, F151, F175]
- `bio_crypt_set_ctx()` requires `__GFP_DIRECT_RECLAIM`. `blk_crypto_profile_init()` zeroes `*profile` and must precede field setup. `blk_crypto_get_keyslot()` returns `BLK_STS_OK` with `*slot_ptr = NULL` when `num_slots == 0` (check `blk_crypto_rq_has_keyslot(rq)`). `blk_queue_flag_set/clear(flag, q)` take a `QUEUE_FLAG_*` bit index, not `BIT(...)`. `blk_set_pm_only(q)` balances with `blk_clear_pm_only(q)`. `badblocks_check()` returns `0` (none), `1` (acked), or `-1` (unacked); badblock APIs take `sector_t` and `badblocks_show()` casts `BB_OFFSET()` to `unsigned long long` before `<< bb->shift`. [F59, F66, F67, F135, F163, F168, F178]

## Error Handling & Known Pitfalls
- `blk_rq_unmap_user()` runs in process context on the original saved `rq->bio`, unmapping/putting every bio in `bi_next` while keeping the first error from `bio_uncopy_user()` (which checks `current->mm` before `bio_copy_to_iter()`). In `__bio_iov_iter_get_pages()`, on early exit/error, `while (i < nr_pages) bio_release_page(bio, pages[i++]);` releases remaining pages. In `blk_crypto_fallback_encrypt_bio()`, if `crypto_wait_req()` fails after setting `enc_bvec->bv_page = ciphertext_page`, increment `i++` before `goto out_free_bounce_pages`. `bio_check_eod()` with `nr_sectors != 0` and `maxsector == 0` still returns `-EIO`. [F63, F125, F127, F174, F198]
- `I_BDEV()` and `BDEV_I()` are only valid on `blockdev_superblock` pseudo-inodes (`bdev_file->f_mapping->host`), never on `/dev` VFS inodes. `bio_endio()` iterates `bio_chain_endio` via `bio = __bio_chain_endio(bio); goto again;`. `__bio_iov_iter_get_pages()` aliases the tail of `bio->bi_io_vec` as `pages` offset by `entries_left * (PAGE_PTRS_PER_BVEC - 1)`. In `blk_crypto_fallback_decrypt_endio()`, restore `bi_private`/`bi_end_io` from `f_ctx->bi_private_orig`/`bi_end_io_orig` before writing `f_ctx->work`/`bio` (anonymous union). `blk_crypto_profile_init()` clamps `slot_hashtable_size` to `>= 2` when `num_slots > 0`. [F23, F96, F106, F120, F148]
- `get_max_segment_size()` compares `lim->seg_boundary_mask - (lim->seg_boundary_mask & paddr)` against `(unsigned long)lim->max_segment_size - 1` before adding 1. `bio_split_discard()` clamps `granularity` to `max(lim->discard_granularity >> 9, 1U)` and uses `sector_div()`. `blk_kick_flush()` and `update_io_ticks()` use `time_before()`/`time_after()` on `jiffies`. In `badblocks.c`, `read_seqbegin(&bb->lock)` retry loops reset all cursor/accumulator locals on retry; in `_badblocks_set()`, when `can_front_overwrite(bb, prev, &bad, &extra)` (with `extra = 0`) returns `false`, `extra > 0` jumps to `out` and `extra == 0` skips `p[prev]`; `bb->page` shifts use `memmove()` with count `* 8` before updating `bb->count`. [F115, F117, F134, F138, F143, F154]
