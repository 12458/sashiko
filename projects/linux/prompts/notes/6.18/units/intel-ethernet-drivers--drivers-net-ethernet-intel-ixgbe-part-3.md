# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 3)

This unit implements the PCI driver lifecycle, `net_device_ops`, NAPI Tx/Rx/XDP data paths, interrupts, service task, AER recovery, PF/VF mailbox operations, and `tc-flower`/`cls_u32` Flow Director parsing tables (`ixgbe_model.h`) for `ixgbe`.

## Architecture & Data Flow

- In `struct ixgbe_tx_buffer`, `skb` and `xdpf` share a union: non-XSK Tx cleanup must check `ring_is_xdp(tx_ring)` to free `xdpf` via `xdp_return_frame()` or `skb` via `dev_kfree_skb_any()` / `napi_consume_skb()`. `ixgbe_xmit_frame_ring()` must reserve `count + 3` descriptors via `ixgbe_maybe_stop_tx()` where `count` sums `TXD_USE_COUNT()` over `skb_headlen(skb)` and `nr_frags`, because `ixgbe_tx_map()` splits segments `> IXGBE_MAX_DATA_PER_TXD` (16 KB) without rechecking space. [F1520, F1561]
- In `ixgbe_alloc_rx_buffers()` and `ixgbe_clean_tx_irq()`, index `i` is biased by `i -= ring->count` so wrap-around occurs at `!i`; restore `i += ring->count` before storing `next_to_use` or `next_to_clean`. When `ixgbe_alloc_rx_buffers()` advances `next_to_use` to `i`, it must also set `next_to_alloc = i`, zero `rx_desc->wb.upper.length` on the new `next_to_use` descriptor, run `wmb()`, and write `i` to `rx_ring->tail`. [F1535, F1559]
- In `ixgbe_can_reuse_rx_page()`, when `pagecnt_bias == 1`, update `page_ref_add(page, USHRT_MAX - 1)` and `pagecnt_bias = USHRT_MAX` in lockstep. On `PAGE_SIZE < 8192`, `ixgbe_add_rx_frag()`, `ixgbe_construct_skb()`, `ixgbe_build_skb()`, and `ixgbe_rx_buffer_flip()` toggle `page_offset ^= truesize` (`ixgbe_rx_pg_size(rx_ring) / 2`), whereas on `PAGE_SIZE >= 8192` they add `truesize` bounded by `IXGBE_LAST_OFFSET`. [F1537, F1572]
- `ixgbe_configure_rx()` must call `ixgbe_set_rx_buffer_len()` before `ixgbe_configure_rx_ring()`, which on `PAGE_SIZE < 8192` (non-82598/82599) sets `IXGBE_MAX_2K_FRAME_BUILD_SKB | IXGBE_RXDCTL_RLPML_EN` when `ring_uses_build_skb(ring)` and `!test_bit(__IXGBE_RX_3K_BUFFER, &ring->state)`. In `ixgbe_configure_rscctl()`, program `IXGBE_RSCCTL(reg_idx)` with `IXGBE_RSCCTL_MAXDESC_16` so coalesced packets stay `<= 65535` bytes. `ixgbe_update_rsc_stats()` must check `IXGBE_CB(skb)->append_cnt != 0` before `ixgbe_set_rsc_gso_size()` and clear `append_cnt` only after `DIV_ROUND_UP()` division. In `ixgbe_cleanup_headers()`, skip `eth_skb_pad(skb)` when `ixgbe_rx_is_fcoe(rx_ring, rx_desc)` is true. [F1565, F1566, F1593, F1650]
- `ixgbe_setup_tx_resources()` / `ixgbe_setup_rx_resources()` align `ring->size` to 4096 for `dma_alloc_coherent()` / `dma_free_coherent()`, while `ixgbe_configure_tx_ring()` / `ixgbe_configure_rx_ring()` program `IXGBE_TDLEN` / `IXGBE_RDLEN` with `ring->count * sizeof(desc)`. `ixgbe_clean_rx_ring()` / `ixgbe_clean_tx_ring()` must reset `next_to_alloc`, `next_to_clean`, and `next_to_use` to 0 (and call `netdev_tx_reset_queue()` on non-XDP Tx rings). [F1541, F1602]
- On non-82598EB, `ixgbe_configure_tx()` sets `IXGBE_DMATXCTL_TE` before enabling Tx/XDP rings, and `ixgbe_disable_tx()` clears it only after polling all active `IXGBE_TXDCTL` registers for `ENABLE` to clear. On `ixgbe_mac_82598EB`, `TXDCTL.ENABLE` and `RXDCTL.ENABLE` do not update when link is down (`!(IXGBE_READ_REG(hw, IXGBE_LINKS) & IXGBE_LINKS_UP)`), so skip polling when 82598 link is down. [F1579, F1606]
- In `ixgbe_configure()`, call `ixgbe_configure_virtualization()` before `ixgbe_restore_vlan()` and `ixgbe_set_rx_mode()`; on 82599EB and X540, bracket Flow Director init and `ixgbe_fdir_filter_restore()` with `disable_rx_buff(hw)` and `enable_rx_buff(hw)`. `IXGBE_VLVF` slot 0 is reserved: `ixgbe_vlan_promisc_enable()`, `ixgbe_scrub_vfta()`, and `ixgbe_find_vlvf_entry()` iterate `for (i = IXGBE_VLVF_ENTRIES; --i;)` and index `IXGBE_VLVFB(i * 2 + p / 32)` bit `BIT(p % 32)`. [F1533, F1570, F1609]
- In `ixgbe_up_complete()`, clear `__IXGBE_DOWN`, call `ixgbe_napi_enable_all()`, and read `IXGBE_EICR` before `ixgbe_irq_enable()`. In `ixgbe_down()`, stop netif Tx, call `ixgbe_disable_rx()` (plus `synchronize_rcu()` if `xdp_ring[0]` is set), `ixgbe_irq_disable()`, `ixgbe_napi_disable_all()`, `del_timer_sync(&service_timer)`, `ixgbe_disable_tx()`, and `ixgbe_reset()` before cleaning rings. In `ixgbe_reset()`, after `init_hw()`, call `ixgbe_flush_sw_mac_table()`, `__dev_uc_unsync()`, and `ixgbe_mac_set_default_filter()`. In `ixgbe_change_mtu()`, `WRITE_ONCE(netdev->mtu, new_mtu)` must precede `ixgbe_reinit_locked()`. [F1542, F1544, F1610, F1611]
- In `ixgbe_request_msix_irqs()`, `ixgbe_free_irq()`, `ixgbe_irq_disable()`, and `ixgbe_configure_msix()`, loop counter `vector`/`v_idx` after `0 .. num_q_vectors - 1` indexes `ixgbe_msix_other` at `msix_entries[num_q_vectors]`. In `ixgbe_configure_msix()`, evaluate `BIT(adapter->num_vfs - 32) - 1` only when `num_vfs > 32` before writing `IXGBE_EITRSEL`. [F1576, F1594]
- In `ixgbe_model.h`, terminate `ixgbe_mat_field` arrays with `{.val = NULL}` and `ixgbe_nexthdr` arrays with `{.jump = NULL}`. In `cls_u32` handlers, non-root `uhtid` (`!= 0x800`) must be `< IXGBE_MAX_LINK_HANDLE`, indexing `jump_tables[uhtid]` directly and `adapter->tables` at bit `uhtid - 1`. `filter->action` encodes 0-based VF `vf` as `(vf + 1) << ETHTOOL_RX_FLOW_SPEC_RING_VF_OFF` (`0` = PF), so `ixgbe_fdir_filter_restore()` must check `vf <= num_vfs` and index VF queues with `vf - 1`. [F1522, F1567, F1569]
- `adapter->xdp_prog` cannot coexist with SR-IOV/VMDq, DCB, LRO/RSC, macvlan L2FW offload, or frame size `> ixgbe_max_xdp_frame_size(adapter)`. In `ixgbe_mbx.c`, `IXGBE_MBVFICR` packs 16 VFs per register (`vf >> 4`, bit `vf % 16`, reqs 0..15, ACKs 16..31), while `IXGBE_VFLRE` / `IXGBE_VFLREC` pack 32 VFs per register (`vf < 32 ? 0 : 1`, shift `vf % 32`). [F1557, F1653]
- In `ixgbe_probe()`, reject VFs (`pdev->is_virtfn`), copy `const` `*ii->*_ops` by value into `adapter->hw`, set `hw->eeprom.ops.read = &ixgbe_read_eeprom_bit_bang_generic` if `!(IXGBE_EEC(hw) & BIT(8))` before `ixgbe_sw_init()`, and copy PCI IDs into `hw` before `ii->get_invariants(hw)`. If `ixgbe_check_fw_error()` is true after `ixgbe_sw_init()`, divert to `ixgbe_recovery_probe()`, which on `ixgbe_mac_e610` skips `register_netdev()` (so `ixgbe_remove()` must check `netdev->reg_state == NETREG_REGISTERED`). When `ixgbe_pcie_from_parent()` is true, read PCIe link from `pdev->bus->parent->self`, and skip `ixgbe_check_minimum_link()` when `hw->bus.type == ixgbe_bus_type_internal`. [F1549, F1616, F1617, F1618, F1619]
- Gate `pci_disable_device()` with `!test_and_set_bit(__IXGBE_DISABLED, &adapter->state)`, and on `pci_enable_device_mem()` clear `__IXGBE_DISABLED` and restore `hw.hw_addr = adapter->io_addr`. Under `rtnl_lock()`, `__ixgbe_shutdown()` detaches `netdev`, calls `ixgbe_close_suspend()` if running, and calls `ixgbe_clear_interrupt_scheme()`, while `ixgbe_resume()` calls `ixgbe_init_interrupt_scheme()` before `ixgbe_open()`. Pair `ixgbe_get_hw_control()` (`IXGBE_CTRL_EXT_DRV_LOAD`) with `ixgbe_release_hw_control()` on close, shutdown, remove, and probe error. [F1627, F1628, F1629]

## Synchronization

- `devl_lock(adapter->devlink)` wraps `register_netdev()` / `unregister_netdev()`, setting lock order `devl_lock` -> `rtnl_lock`. Initialize `service_timer` and `service_task` before setting `__IXGBE_SERVICE_INITED`. Every exit of `ixgbe_service_task()` and `ixgbe_recovery_service_task()` must call `ixgbe_service_event_complete()`. Never call `cancel_work_sync(&adapter->service_task)` in `ixgbe_down()`. [F1495, F1511, F1634, F1638]
- In `ixgbe_reset_subtask()`, after taking `rtnl_lock()`, reverify `!(__IXGBE_DOWN | __IXGBE_REMOVING | __IXGBE_RESETTING)` before `ixgbe_reinit_locked()`. Serialize SFP init and flag changes in `ixgbe_reset()`, `ixgbe_sfp_detection_subtask()`, and `ixgbe_sfp_link_config_subtask()` with `test_and_set_bit(__IXGBE_IN_SFP_INIT, &adapter->state)`. [F1504, F1506]
- In `ixgbe_tx_map()` and `ixgbe_xmit_xdp_ring()`, run `wmb()` / `smp_wmb()` before storing `next_to_watch = tx_desc`, paired with `smp_rmb()` in `ixgbe_clean_tx_irq()` before reading `eop_desc->wb.status`. All XDP Tx ring transmits and tail updates must take `ring->tx_lock` when `static_branch_unlikely(&ixgbe_xdp_locking_key)` is enabled. When detaching XDP in `ixgbe_xdp_setup()`, call `synchronize_rcu()` before `ixgbe_setup_tc()` and `xdp_features_clear_redirect_target(dev)` after. [F1500, F1507, F1654]
- Bracket `ring->stats` updates with `u64_stats_update_begin/end(&ring->syncp)` and reads in `ixgbe_get_stats64()` / `ixgbe_get_ring_stats64()` with `u64_stats_fetch_begin/retry()` under `rcu_read_lock()` and `READ_ONCE(adapter->*_ring[i])`. In `ixgbe_fwd_ring_up()`, order `rx_ring->netdev = vdev` before `ixgbe_add_mac_filter()` with `wmb()`. In `ixgbe_write_mbx_pf()` / `ixgbe_read_mbx_pf()`, after `ixgbe_obtain_mbx_lock_pf()`, write `IXGBE_PFMAILBOX_STS` or `ACK` to release ownership. [F1494, F1496, F1510]

## Object Lifetimes

- `ixgbe_get_rx_buffer()` decrements `pagecnt_bias`; any path in `ixgbe_clean_rx_irq()` or `ixgbe_construct_skb()` not attaching/flipping the page must increment `pagecnt_bias` back. In `ixgbe_put_rx_buffer()`, defer unmapping non-EOP first buffers (`IXGBE_CB(skb)->dma == rx_buffer->dma`) via `IXGBE_CB(skb)->page_released = true`, and always clear `rx_buffer->page = NULL` and `rx_buffer->skb = NULL`. [F1478, F1479, F1480]
- In `ixgbe_setup_tx_resources()` / `ixgbe_setup_rx_resources()`, restore `set_dev_node(dev, orig_node)` right after the first `dma_alloc_coherent()`. `ixgbe_free_tx_resources()` / `ixgbe_free_rx_resources()` must guard `dma_free_coherent()` with `if (!ring->desc)` and NULL `ring->*_buffer_info` and `ring->desc`. [F1485, F1486]
- In `ixgbe_free_irq()`, under `IXGBE_FLAG_MSIX_ENABLED`, skip `q_vector` entries with `!rx.ring && !tx.ring`. In `ixgbe_remove()`, set `__IXGBE_REMOVING` before `cancel_work_sync(&adapter->service_task)`, and call both `free_netdev(netdev)` and `devlink_free(adapter->devlink)`. [F1487, F1497, F1613]
- In `ixgbe_fwd_del()`, call `ixgbe_del_mac_filter()` and `napi_synchronize(&qv->napi)` before clearing `ring->netdev = NULL` and freeing `accel`. In `ixgbe_configure_clsu32()`, when `!link_uhtid`, `ixgbe_update_ethtool_fdir_entry()` owns `input` and copies `mask`, so success frees only `mask` and error frees both. [F1490, F1499]
- In `ixgbe_xdp_setup()`, call `bpf_prog_put(old_prog)` only after `ixgbe_setup_tc()` or `WRITE_ONCE(rx_ring[i]->xdp_prog, prog)`. In `ixgbe_io_error_detected()`, when breaking out of `pci_get_device()` on a matching `vfdev`, call `pci_dev_put(vfdev)` after `pcie_flr(vfdev)` and increment `adapter->vferr_refcount`. [F1491, F1492]

## API Contracts

- Use `ixgbe_from_netdev(netdev)` instead of `netdev_priv(netdev)`. Check `netif_is_ixgbe(ring->netdev)` in `ixgbe_process_skb_fields()` and `ixgbe_vlan_strip_enable/disable()`, and check `netif_is_macvlan(vdev)` plus non-NULL `macvlan_accel_priv(vdev)` in `netdev_walk_all_upper_dev_rcu()` callbacks. `ixgbe_fwd_ring_up()` frees `accel` on error, so callers must not. [F1489, F1599, F1601, F1651]
- Pass `VMDQ_P(pool)` to `ixgbe_add_mac_filter()`, `ixgbe_del_mac_filter()`, and `ixgbe_available_rars()`. Store `ixgbe_add_mac_filter()` and `ixgbe_write_mc_addr_list()` returns in signed `int` and check `< 0` for error. `ixgbe_cleanup_headers()` frees `skb` when returning `true`. In `ixgbe_clean_rx_ring()`, call `dma_sync_single_range_for_cpu()` before unmapping Rx pages (`DMA_ATTR_SKIP_CPU_SYNC`). [F1481, F1512, F1513, F1529, F1641]
- Call `skb_cow_head(skb, 0)` before mutating headers in `ixgbe_tso()` or VLAN priority insertion. `ixgbe_tso()` returns `< 0` (drop), `1` (emitted), or `0` (call `ixgbe_tx_csum()`). `__ixgbe_xmit_frame()` pads via `skb_put_padto(skb, 17)` and returns `NETDEV_TX_OK` on error (already freed). `ixgbe_features_check()` clears csum/TSO if MAC hdr `> 127` or network hdr `> 511`, and clears `NETIF_F_TSO` on non-IPsec encapsulated packets without `NETIF_F_TSO_MANGLEID`. [F1515, F1648, F1649, F1652]
- `ixgbe_xmit_xdp_ring()` returns `IXGBE_XDP_TX` or `IXGBE_XDP_CONSUMED` without freeing `xdpf`. `ixgbe_xdp_xmit()` rejects `flags & ~XDP_XMIT_FLAGS_MASK` with `-EINVAL`, updates tail only on `XDP_XMIT_FLUSH`, and never frees untransmitted frames. `ixgbe_clean_rx_irq()` calls `xdp_do_flush()` / `ixgbe_xdp_ring_update_tail_locked()` on `IXGBE_XDP_REDIR` / `IXGBE_XDP_TX`; Rx rings pair `xdp_rxq_info_reg()` with `xdp_rxq_info_unreg()`. `ixgbe_set_ivar()` takes `ring->reg_idx` (not `queue_index`). `ixgbe_read_mbx()` / `ixgbe_write_mbx()` take `size` in `u32` words (`<= 16`), not bytes. [F1514, F1531, F1532, F1655, F1656, F1661]

## Error Handling

- On DMA error, `ixgbe_tx_map()` unmaps fragments, frees and NULLs `first->skb`, and rewinds `next_to_use`, so `ixgbe_xmit_frame_ring()` must jump to `cleanup_tx_timestamp` (not `out_drop`). Any drop after `IXGBE_TX_FLAGS_TSTAMP` must free and NULL `adapter->ptp_tx_skb`, cancel `ptp_tx_work`, and clear `__IXGBE_PTP_TX_IN_PROGRESS`. In `ixgbe_setup_all_tx_resources()`, initialize `j = 0` before the `i` loop for `err_setup_tx` unwind. [F1482, F1483, F1577]

## External Contracts

- Never reorder `enum ixgbe_pfvf_api_rev`; append before `ixgbe_mbox_api_unknown`. In `ixgbe_poll()`, clamp `per_ring_budget = max(budget/q_vector->rx.count, 1)` and return `min(work_done, budget - 1)` when `napi_complete_done()` is called. [F1553, F1587]

## Known Pitfalls

- In `ixgbe_clean_rx_irq()`, `xdp_res` is declared outside the loop and only set when `!skb`; any `!skb` branch must set `xdp_res`. In `ixgbe_tx_csum()`, when `skb->ip_summed != CHECKSUM_PARTIAL` or `skb_checksum_help()` runs, still jump to `csum_failed` / `no_csum` so `ixgbe_tx_ctxtdesc()` runs if `IXGBE_TX_FLAGS_HW_VLAN | IXGBE_TX_FLAGS_CC` is set. In `ixgbe_atr()`, verify `skb_tail_pointer(skb)` bounds before reading headers and read IPv4 `ihl` as `(hdr.network[0] & 0x0F) << 2`. [F1564, F1575, F1583]
- In `ixgbe_msix_other()`, read `IXGBE_EICS` masked with `0xFFFF0000` before writing `IXGBE_EICR`. In legacy/MSI mode, `ixgbe_check_hang_subtask()` must not write `IXGBE_EIAM`-enabled bits (`IXGBE_EICS_RTX_QUEUE`) to `IXGBE_EICS`. In `ixgbe_write_eitr()`, OR `itr_reg << 16` on 82598EB and `IXGBE_EITR_CNT_WDIS` on 82599EB+. [F1538, F1622, F1623]
- In `ixgbe_update_stats()`, read `_H` after `_L` on 82599EB+ 64-bit counters (82598EB has only `_H`); accumulate VF stats only when `!__IXGBE_RESETTING` using `UPDATE_VF_COUNTER_36bit()` for byte counters; and use `time_after()` for jiffies deadlines (`next_update`, `link_check_timeout`, `sfp_poll_time`). In `ixgbe_sw_init()`, `ixgbe_mac_x550em_a` and `ixgbe_mac_X550EM_x` fall through to `ixgbe_mac_X550`, so guard X550-only flags with `if (hw->mac.type == ixgbe_mac_X550)`. [F1585, F1597, F1598, F1625]
