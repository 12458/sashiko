# INTEL ASoC DRIVERS — sound/soc/intel (part 3)

This unit covers SOF machine drivers (`sof_sdw.c`, `sof_ssp_amp.c`, `sof_wm8804.c`), the Wildcat Point / Lynx Point AudioDSP platform driver (`catpt`) for DSP lifecycle, DesignWare DMA, firmware loading/restoration, IPC, and PCM streams, and Intel ACPI machine match tables and topology/SDCA quirk helpers.

## Architecture & Data Flow

- In `snd_soc_acpi_intel_*_sdw_machines` (`adl`, `arl`, `mtl`, `ptl`), entries with more links in `.link_mask`, more devices in `.links`, or `.machine_check` must precede subset entries, and every `snd_soc_acpi_link_adr` array in `.links` must end with `{}` for `hda_sdw_machine_select()` and `asoc_sdw_parse_sdw_endpoints()`. In I2S `snd_soc_acpi_intel_*_machines` (`adl`, `arl`, `mtl`, `ptl`, `rpl`), `.machine_quirk = snd_soc_acpi_codec_list` entries must precede generic entries for the same codec, with amp-only boards (`CSC3541`, `INTC10B0`, `10EC1308`) last. [F181, F198, F199]
- In `soc-acpi-intel-ssp-common.c`, dual-role codec/amp chips (e.g. `RT5650`) must be listed in both `codecs[]` and `amps[]`, placed at the end of `amps[]` after all dedicated amplifiers. [F178]
- In `sof_card_dai_links_create()`, assign `card->codec_conf` and `card->dai_link` before `create_*_dailinks()` (`sdw`, `ssp`, `dmic`, `hdmi`, `bt`) advance the local pointers in place, and allocate a separate `snd_soc_dai_link_component *platform` per DAI link rather than sharing a static array. Do not overwrite `mach_params->dmic_num` (mic channel count for `cfg-mics:%d`, `0` when `ctx->ignore_internal_dmic` else `DMIC_DEFAULT_CHANNELS`) with the DMIC link count `dmic_num`. [F174, F175, F227]
- In `create_dmic_dailinks()` and `create_hdmi_dailinks()`, pass `asoc_sdw_dmic_init` and `sof_sdw_hdmi_init` only on the first link (`"dmic01"` and `i == 0`), and `NULL` for `"dmic16k"` and `i > 0`. In `sof_sdw.c` and `sof_sdw_hdmi.c`, `snd_soc_card_get_drvdata(card)` is `struct asoc_sdw_mc_private *`, while `struct intel_mc_ctx *` lives in `ctx->private`. When `ctx->append_dai_type` is true in `create_sdw_dailink()`, `sof_end->dai_info->dai_type` indexes 3-element `type_strings[]` and `stream + 2` indexes suffixed `sdw_stream_name[]`. [F193, F215, F229]
- In `sof_sdw_get_tplg_files()`, `tplg_mask` must test and set `BIT(tplg_dev)` to deduplicate function types across `for_each_card_prelinks(card, i, dai_link)`, and `(*tplg_files)` must be indexed by `tplg_num++` rather than `i`. [F212]
- In `sof_wm8804_hw_params()`, clear `ctx->sample_rate = 0` before changing clock dividers, PLL, or SYSCLK and set it to `samplerate` only after all updates succeed; when switching `ctx->gpio_44` and `ctx->gpio_48`, drive the LOW GPIO before driving the HIGH GPIO. [F177]
- `catpt_sram_init()` uses inclusive bounds `[start, start + size - 1]`. Whenever `cdev->dram` or `cdev->iram` regions change after boot, `catpt_dsp_update_srampge()` must update active-low PCI `VDRTCTL0` bits (`0` = on, `1` = gated) using inclusive block indices `l = (res->start - sram->start) / CATPT_MEMBLOCK_SIZE` and `h = (res->end - sram->start) / CATPT_MEMBLOCK_SIZE` for `GENMASK(h, l)`, inverting busy masks (`~(new << __ffs(mask)) & mask`) and iterating enabled blocks with `for_each_clear_bit_from()`. [F166, F194, F214]
- Across D3, `catpt_suspend()` saves memdumps, module states, and stream contexts to `cdev->dxbuf_paddr`, and `catpt_resume()` restores them via `catpt_boot_firmware(cdev, true)` and replays `catpt_ipc_set_device_format()` for each `cdev->devfmt[i]` with `iface != UINT_MAX` (`catpt_dev_init()` sets `iface = UINT_MAX` since `0` is `CATPT_SSP_IFACE_0`, and `catpt_dai_pcm_new()` updates `cdev->devfmt[devfmt.iface]` only after `catpt_ipc_set_device_format()` succeeds). [F155, F169]
- In `catpt_dsp_select_lpclock()`, changing `CATPT_CS_LPCS` in `CS1` requires calling `cdev->spec->pll_shutdown(cdev, lp)` under `cdev->clk_mutex`, and if `waiti` is true and polling `ISD` for `CATPT_ISD_DCPWM` times out, abort `lp == true`. In `catpt_dai_trigger()`, `SNDRV_PCM_TRIGGER_STOP` must clear `stream->prepared = false` before `catpt_dsp_update_lpclock(cdev)`, while `SNDRV_PCM_TRIGGER_START` must call `catpt_dsp_update_lpclock(cdev)` before `catpt_ipc_resume_stream()`. [F168, F204]
- `catpt_load_images()` indexes 2-element `names[]` with `cdev->spec->core_id - 1` (`core_id` in `1..2`). Before `catpt_load_module()` or `catpt_restore_module()`, `catpt_load_firmware()` and `catpt_restore_firmware()` must verify `mod->signature` (`FW_SIGNATURE_SIZE`) and `mod->module_id <= CATPT_MODID_LAST` before indexing `cdev->modules[mod->module_id]`. [F185, F191]
- In `catpt_dsp_do_send_msg()`, validate `request.size` and non-NULL `reply->size` against `ipc->config.outbox_size`. In `catpt_ipc_alloc_stream()`, serialize `catpt_alloc_stream_input` into `payload` by shifting fields at `offsetof(struct catpt_alloc_stream_input, persistent_mem)` forward by `sizeof(*modules) * num_modules` with `memmove()` (not `memcpy()`) before inserting `modules`. [F187, F224]
- In `catpt/pcm.c`, per-stream kcontrols cache inactive changes in `kcontrol->private_value` and apply them in `catpt_dai_hw_params()` via `catpt_dai_apply_usettings()` after `catpt_ipc_alloc_stream()`; `catpt_dai_apply_usettings()` matches `component_kcontrols[]` names in `component->card->snd_card->controls`, checks `!list_entry_is_head(pos, ..., list)`, and casts `pos->private_value` to `bool *` (loopback) or `long *` (`long[CATPT_CHANNELS_MAX]`). [F171, F206, F269]
- In `catpt/pcm.c`, `catpt_stream_volume()` and `catpt_mixer_volume()` clamp `channel >= CATPT_CHANNELS_MAX` to `0` before indexing `volume_regaddr[]`; `ctlvol_to_dspvol()` clamps `value > DSP_VOLUME_STEP_MAX` (`30`) to `0`; and `dspvol_to_ctlvol()` checks `volume > DSP_VOLUME_MAX` and `volume != 0` before `__fls(volume)`. In `catpt_coredump()`, bound `cdev->ipc.config.fw_info` (`FW_INFO_SIZE_MAX = 100`) scanning with `strnchr(info, eof - info, ' ')` and `min_t(u32, eof - info, CATPT_DUMP_HASH_SIZE)`. [F188, F195, F219]

## Synchronization

- In `catpt_dsp_do_send_msg()`, `catpt_ipc_msg_init()` and `catpt_dsp_send_tx()` must run together under `spin_lock_irqsave(&ipc->lock, flags)` before writing `CATPT_SHIM_IPCC`. In `catpt_dsp_irq_handler()` and `catpt_dsp_irq_thread()`, `catpt_dsp_copy_rx()` and `catpt_dsp_process_response()` must finish reading the mailbox and completing `done_completion`/`busy_completion` before clearing `CATPT_IPCC_DONE` or setting `CATPT_IPCD_DONE` and unmasking `CATPT_IMC_IPCCD`/`CATPT_IMC_IPCDB`. [F141, F144]
- In `catpt_boot_firmware()`, `reinit_completion(&cdev->fw_ready)` must precede `catpt_dsp_stall(cdev, false)`, and in `catpt_dsp_process_response()`, `catpt_ipc_arm()` must complete before `complete(&cdev->fw_ready)`. [F143]
- `catpt_dsp_send_msg_timeout()`, `catpt_dsp_send_msg()`, and `catpt_ipc_*` lock `cdev->ipc.mutex` and sleep on `wait_for_completion_timeout()`, requiring sleepable context. `CATPT_ISC_IPCDB` replies/notifications must be masked in `catpt_dsp_irq_handler()` and processed in `catpt_dsp_irq_thread()` (`IRQ_WAKE_THREAD`) because `catpt_dsp_process_response()` performs `GFP_KERNEL` allocations, `vzalloc()`/`dev_coredumpv()`, and sleeping IPC. `cdev->list_lock` uses non-IRQ-saving `spin_lock()`, so `catpt_stream_find()` and `cdev->stream_list` must never be used in hardirq context. [F254, F255, F256]

## Object Lifetimes

- `catpt_dsp_power_up()` must put the device in D0 before `catpt_dmac_probe()` (`dw_dma_probe()`), and `catpt_dmac_remove()` must precede `catpt_dsp_power_down()` on probe failure and removal. In `catpt_acpi_remove()`, `pm_runtime_disable(cdev->dev)` must precede `catpt_dmac_remove(cdev)` so `dw_dma_remove()` does not trigger runtime PM callbacks. [F126, F127]
- In `catpt_suspend()`, stall the DSP, finish DMA context saves (`catpt_store_memdumps`, `catpt_store_module_states`, `catpt_store_streams_context`), and call `dma_release_channel(chan)` before `catpt_dsp_power_down(cdev)`. In `catpt_resume()` and `catpt_runtime_suspend()`, immediately balance `try_module_get(dev->driver->owner)` with `module_put(dev->driver->owner)`. [F129, F136]
- Every SRAM child `struct resource` from `catpt_request_region()` or `__request_region()` must be unlinked with `release_resource(res)` and freed with `kfree(res)` in `catpt_dai_shutdown()` and `catpt_sram_free()`, saving `res->sibling` before freeing. In `catpt_load_block()`, only call `__request_region()` when `alloc` is true (`catpt_load_module()`, not restore paths), and call `__release_region(sram, dst_addr, blk->size)` if `catpt_dma_memcpy_todsp()` fails. [F131, F134, F207]
- In `catpt_dai_shutdown()`, unlink `stream->node` from `cdev->stream_list` under `cdev->list_lock` before releasing `stream->persistent`, updating SRAM power gating, freeing `stream->pgtbl` and `stream`, and clearing DAI `dma_data` to `NULL`. Guard `catpt_ipc_alloc_stream()` in `catpt_dai_hw_params()` with `!stream->allocated` (setting `true` on success), and in `catpt_dai_hw_free()` only call `catpt_ipc_reset_stream()`/`catpt_ipc_free_stream()` when `stream->allocated` is true (then set `false`). [F132, F133]
- In `sof_sdw.c`, `mc_probe()` must reset `codec_info_list[i].amp_num = 0` before `sof_card_dai_links_create()`, and call `asoc_sdw_mc_dailink_exit_loop(card)` on `devm_snd_soc_register_card()` failure and in `mc_remove()`. `sof_card_dai_links_create()` must `kfree()` `sof_ends` and `sof_dais` on completion and all error paths (`err_end`, `err_dai`). [F137, F138, F162]
- In `sof_wm8804_probe()`, release `acpi_dev_get_first_match_dev()` with `acpi_dev_put(adev)`, and when `SOF_WM8804_UP2_QUIRK` is set, call `gpiod_remove_lookup_table(&up2_gpios_table)` in `sof_wm8804_remove()`. In `sof_sdw_get_tplg_files()`, call `release_firmware(fw)` whenever `firmware_request_nowarn()` returns `0`. [F139, F140]

## API Contracts

- `catpt_dma_request_config_chan()` returns `ERR_PTR` on failure (check `IS_ERR()`, not `NULL`) and requires `dma_release_channel()` on success. In `catpt_coredump()`, `dev_coredumpv()` takes ownership of `vzalloc()`-allocated `dump` (do not `vfree(dump)`). [F128, F135]
- Both SoundWire DAI links in `create_sdw_dailink()` (`sdw_ops`) and Catpt FE DAI links (`catpt_fe_dai_ops` / `catpt_dai_trigger()`) sleep and must set `.nonatomic = true`. [F149, F257]
- Header-only `catpt_ipc_*` helpers must zero-initialize `struct catpt_ipc_msg request = { {0}}`. Host DRAM offsets sent in `catpt_ipc_alloc_stream()` must use `catpt_to_dsp_offset()`, while `cdev->dx_ctx.meminfo[i].offset` must use `catpt_to_host_offset()` before `cdev->dram` checks or adding to `cdev->lpe_base`/`cdev->dxbuf_paddr`. In `catpt_dsp_update_srampge()`, `catpt_dsp_power_down()`, and `catpt_dsp_power_up()`, disable `CATPT_VDRTCTL2_DCLCGE` in `VDRTCTL2` before modifying `VDRTCTL0`, `PMCS`, or SHIM/SSP power-cycle registers, and re-enable it after. [F151, F156, F238]
- In `catpt/pcm.c`, compute `rinfo.num_pages` with `DIV_ROUND_UP(rtm->dma_bytes, PAGE_SIZE)` to match `catpt_arrange_page_table()`; call `catpt_ipc_set_write_pos()` only for `CATPT_STRM_TYPE_RENDER` streams using `frames_to_bytes()` (and convert `catpt_component_pointer()` with `bytes_to_frames()`); and advertise 24-bit audio via `SNDRV_PCM_FMTBIT_S32_LE` with `.subformats = SNDRV_PCM_SUBFMTBIT_MSBITS_24 | SNDRV_PCM_SUBFMTBIT_MSBITS_MAX` rather than `SNDRV_PCM_FMTBIT_S24_LE`. [F217, F265, F268]
- In `sof_card_dai_links_create()`, zero `num_devs` and `num_ends` before `asoc_sdw_count_sdw_endpoints()` and allocate `sof_dais` with `kcalloc(num_ends + 1, ...)` for the zeroed loop sentinel. In `create_sdw_dailinks()` and `create_sdw_dailink()`, initialize `intel_ctx->sdw_pin_index[i] = SOC_SDW_INTEL_BIDIR_PDI_BASE` and convert `sof_end->link_mask` with `ffs(sof_end->link_mask) - 1`. [F160, F161]
- `.machine_check` callback `snd_soc_acpi_intel_sdca_is_device_rt712_vb(void *arg)` takes a nullable `struct sdw_intel_ctx *` and returns `bool` (unlike `.machine_quirk` which takes/returns `struct snd_soc_acpi_mach *`). In `soc-intel-quirks.h`, guard non-stub `soc_intel_is_byt_cr()` with `#if IS_REACHABLE(CONFIG_IOSF_MBI)`. [F164, F266]

## Error Handling

- `catpt_dsp_send_msg()` and `catpt_ipc_*` return negative errno or positive `enum catpt_reply_status`; callers must test `if (ret)` and wrap with `CATPT_IPC_ERROR(ret)`. In `catpt_dma_memcpy()`, check `dma_submit_error()` before `dma_wait_for_async_tx(desc)` and still clear `CATPT_HMDC_HDDA` in `HMDC` on submit failure. [F150, F153]
- `catpt_request_region()` returns `NULL` (not `ERR_PTR`), and `cdev->scratch` is `NULL` when `scratch_size == 0`, so `catpt_ipc_alloc_stream()` must NULL-check `cdev->scratch`. Catpt callbacks calling `pm_runtime_resume_and_get(cdev->dev)` (`catpt_dai_pcm_new()`, kcontrols, `fw_version_show()`) must ignore `-EACCES` and always call `pm_runtime_put_autosuspend(cdev->dev)`. [F154, F244]
- In `create_sdw_dailinks()`, initialize `current_be_id = 0` before `create_sdw_dailink()`, and NULL-check optional `sof_end->codec_info->add_sidecar` and `sof_end->dai_info->init` before calling. In `sof_sdw.c` and `sof-function-topology-lib.c`, NULL-check all `devm_kasprintf()` calls (`-ENOMEM`), and in `sof_sdw_get_tplg_files()` return `0` (not negative errno) when a DAI link is unsupported or a sub-topology file is missing. In `sof_wm8804_hw_params()`, check `IS_ERR_OR_NULL()` on `ctx->gpio_44` and `ctx->gpio_48`. [F157, F158, F159, F163, F165]

## External Contracts

- In `mc_probe()` (`sof_sdw.c`), `card->components` tokens (`" cfg-amp:%d"`, `"%s mic:dmic cfg-mics:%d"`) must be space-delimited. In Intel ACPI match tables, CS35L56 `snd_soc_acpi_adr_device` entries must use `"AMPn"` `.name_prefix`, and every `snd_soc_acpi_mach.drv_name` and `platform_device_id.name` must be `<= 23` chars (`PLATFORM_NAME_SIZE - 1`). [F183, F184, F233]
- `catpt_dmac_probe()` must set `DMA_BIT_MASK(31)` because DSP SRAM DMA uses bits 31:20 (`CATPT_DMA_DSP_ADDR_MASK`) and `catpt_arrange_page_table()` packs 19-bit PFNs into 20-bit slots at `((i << 2) + i) >> 1` (`pfn << 4` on odd `i`). In `catpt_dsp_process_response()`, shift `msg.mailbox_address << 3` for the `catpt_fw_ready` offset in `cdev->lpe_ba`; in `catpt_load_module()`, set `type->entry_point = mod->entry_point - 4`. [F216, F221, F223, F259]

## Known Pitfalls

- `catpt_request_region()` dereferences `root->child` unconditionally, requiring `catpt_first_boot_firmware()` to have populated `cdev->dram.child` and reserved the tail `[res->end + 1, cdev->dram.end]`. When `catpt_dsp_set_srampge()` ungates `VDRTCTL0` SRAM blocks, it must wait `udelay(60)` and do a 4-byte dummy `memcpy_fromio()` per enabled block; both `catpt_dsp_power_down()` and `catpt_dsp_power_up()` must call `catpt_dsp_set_regs_defaults()`. [F205, F237, F239]
- In `catpt_load_image()`, copy `request_firmware()` data (`img->data`) into a `dma_alloc_coherent()` buffer before DMA, and cast `fw`, `mod`, and `basefw` to `(u8 *)` before adding byte offsets when walking firmware headers. In `create_ssp_dailinks()`, use set-bit `i` for `"SSP%d-Codec"`/`"SSP%d Pin"` and sequential `j++` for `"i2c-%s:0%d"`. [F211, F226, F262]
