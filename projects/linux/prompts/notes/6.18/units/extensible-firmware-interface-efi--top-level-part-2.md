# EXTENSIBLE FIRMWARE INTERFACE (EFI) — (top level) (part 2)

This component contains the pre-boot UEFI Boot Stub (`drivers/firmware/efi/libstub/*`) for kernel decompression/relocation, initrd/DTB loading, GOP setup, KASLR/RNG seeding, TPM/CC measurement, and FDT/`boot_params` preparation before `ExitBootServices()`, alongside core EFI runtime wrappers (`runtime-wrappers.c`), variable operations (`vars.c`, `stmm/tee_stmm_efi.c`), memory map/attribute and unaccepted memory management (`memmap.c`, `memattr.c`, `unaccepted_memory.c`), MOK/RCI2/OVMF tables, TPM event logs, EFI reboot, and `sysfb_efi.c` DMI quirks.

## Architecture & Data Flow
- In x86/shared libstub code, access UEFI union fields and methods only via `efi_table_attr()`, `efi_call_proto()`, `efi_bs_call()`, `efi_rt_call()`, `efi_dxe_call()`, or `efi_fn_call()`, and handle/event arrays via `for_each_efi_handle()`, `efi_get_handle_at()`, or `efi_set_event_at()`. [F209]
- On x86 entry: `efi_handover_entry()` must zero `[_bss, _ebss)` before `efi_stub_entry()`. In `efi_pe_entry()`, `efi_allocate_bootparams()` must set `hdr->initrd_addr_max = INT_MAX`, and after `handle_kernel_image()` relocates the kernel, `screen_info_offset` must be set to `image_addr - (unsigned long)image->image_base` before `efi_stub_common()` calls `alloc_screen_info()`. In `efi_stub_entry()`, `sev_enable(boot_params)` must run before `efi_5level_switch()` replaces the GDT, and both `la57_toggle` and `new_cr3` (copying into `pgt` if needed) must reside `<= U32_MAX`. [F216, F229, F239, F329, F330]
- In x86 `efi_decompress_kernel()`, pass `LOAD_PHYSICAL_ADDR` as `alloc_min` to `efi_random_alloc()`. When `CONFIG_RANDOMIZE_BASE` and `!efi_nokaslr`, set `KASLR_FLAG` in `boot_params->hdr.loadflags`, and zero `seed[0]` if `cmdline_memmap_override` or AMI UEFI `<= v2.0` is detected. `efi_random_alloc()` stores slot counts in `MD_NUM_SLOTS(md)` in its local map copy; when `total_mirrored_slots > 0`, both passes must filter on `EFI_MEMORY_MORE_RELIABLE`, clamp `md->phys_addr` to `max(md->phys_addr, alloc_min)` before rounding to `align`, and compute `(total_slots * (u64)(random_seed & U32_MAX)) >> 32`. [F219, F230, F236, F240, F278]
- In `exit_boot()`, `allocate_e820()` must pre-allocate `e820ext` (with `EFI_MMAP_NR_SLACK_SLOTS`) and `unaccepted_table` before `efi_exit_boot_services()`. In `setup_e820()`, `process_unaccepted_memory()` populates `unaccepted_table->bitmap` post-EBS while converting `EFI_UNACCEPTED_MEMORY` to `E820_TYPE_RAM`; when `nr_entries == ARRAY_SIZE(params->e820_table)`, switch `entry` to `e820ext->data` without resetting `nr_entries`, then pass `nr_entries - ARRAY_SIZE(params->e820_table)` to `add_e820ext()` and subtract it before setting `params->e820_entries`. [F234, F269]
- In `efi_get_memory_map()`, when `install_cfg_tbl` is true, install `LINUX_EFI_BOOT_MEMMAP_GUID` before the final `get_memory_map` call (and uninstall with `NULL` on failure). In `update_fdt()`, delete existing memory reservations in reverse index order (`while (num_rsv-- > 0) fdt_del_mem_rsv(fdt, num_rsv);`) and pre-populate `/chosen` `linux,uefi-mmap-*` placeholders before `fdt_pack()` so `update_fdt_memmap()` can overwrite them via `fdt_setprop_inplace_var()`. [F226, F235, F273]
- In `efi_convert_cmdline()`, call `efi_measure_tagged_event()` on raw `image->load_options` before `efi_apply_loadoptions_quirk()` mutates `options` in place. Bound UTF-16 parsing by `options_chars = options_size / sizeof(efi_char16_t)` as well as `L'\0'`/`L'\n'`, and if the final word (`!options_chars`) is a high surrogate (`(c & 0xfc00) == 0xd800`), ignore it (`options_bytes -= 3`) without dereferencing `*s2`. In `efi_load_option_unpack()`, validate `size >= offsetof(efi_load_option_t, variable_data)`, NUL-terminated `description`, device path `header.length`, and `pos == (const void *)file_path_list + src->file_path_list_length`. [F237, F254, F255]
- In `efi_pci_disable_bridge_busmaster()`, disconnect all non-VGA PCI handles on non-zero buses (`bus_nr != 0`, `class != PCI_CLASS_DISPLAY_VGA`) in a first pass before clearing `PCI_COMMAND_MASTER` on `PCI_CLASS_BRIDGE_PCI` bridges in the second pass. In `preserve_pci_rom_image()`, reject `!romimage || !romsize || romsize > SZ_16M` with `EFI_INVALID_PARAMETER` before allocating. In `find_gop()`, return early only when a usable GOP handle supports `EFI_CONSOLE_OUT_DEVICE_GUID`, saving the first usable non-ConOut GOP in `first_gop` as fallback. [F275, F304, F311]
- Call `sysfb_apply_efi_quirks()` before `sysfb_parse_mode()`, and `sysfb_set_efifb_fwnode()` after `platform_device` allocation. `VIDEO_CAPABILITY_SKIP_QUIRKS` skips `efifb_dmi_system_table` for `VIDEO_TYPE_EFI`, but `efifb_dmi_swap_width_height` must still run and update `lfb_linelength = 4 * screen_info.lfb_width`. In `efifb_set_system()`, verify DMI `info->base` lies within an active `PCI_CLASS_DISPLAY_VGA` `IORESOURCE_MEM` BAR, and if `lfb_base` is 0, reset `lfb_linelength`, `lfb_width`, `lfb_height`, and `orig_video_isVGA` to 0. [F238, F305, F306, F307]
- In `struct efi_unaccepted_memory`, `size` is in bytes and `unit_size` (`u32`) must be widened to `u64` before multiplying by bit indices or `BITS_PER_BYTE`. `process_unaccepted_memory()` must accept ranges `< 2 * unit_size` via `arch_accept_memory(start, end)` before rounding to `unit_size`. `accept_memory()` and `range_contains_unaccepted_memory()` must extend `end` by `unit_size` when `(start + size - unaccepted->phys_base) % unit_size == 0`, clamp `end` to `unaccepted->size * (u64)unit_size * BITS_PER_BYTE`, use `[start / unit_size, DIV_ROUND_UP(end, unit_size))` indices, and treat `entry->end <= range.start || entry->start >= range.end` on `accepting_list` as non-overlapping. [F241, F242, F243, F281, F284, F301]
- `efi_memattr_init()` must reject `tbl->version > 2` or `tbl->num_entries * tbl->desc_size > 3 * efi.memmap.nr_map * efi.memmap.desc_size`, and `entry_is_valid()` must require `PAGE_SIZE` alignment and containment within one `EFI_MEMORY_RUNTIME` region. In `efi_mokvar_table_init()`, remap across page boundaries and force NUL termination on `mokvar_entry->name`. In `ovmf_log_read()`, wrap `start` by `hdr->log_size` and clamp against `hdr->tail_off` and `logbufsize`. In `reboot.c`, check `EFI_RT_SUPPORTED_RESET_SYSTEM` before `efi.reset_system`, and let `efi_capsule_pending(&cap_reset_mode)` override `efi_reboot_quirk_mode`. [F251, F258, F300, F314]

## Synchronization
- `efivar_lock()` and `efivar_trylock()` must release `efivars_lock` and return `-ENODEV` if `!__efivars->ops`. Callers of `efivar_get_variable()`, `efivar_get_next_variable()`, and `efivar_set_variable_locked()` must hold `efivars_lock`. Because `efivars_register()` calls `efivar_ops_nh` notifiers under `efivars_lock`, notifier callbacks must never call `efivar_lock()`, `efivar_set_variable()`, or `efivars_register()`/`efivars_unregister()`. [F180, F196]
- Callers using the shared `efi_rts_work` and stack `union efi_rts_args` must hold `efi_runtime_lock` across `__efi_queue_work()` until completion and reset `efi_rts_id = EFI_NONE`. Non-blocking wrappers (`virt_efi_set_variable_nb`, `virt_efi_query_variable_info_nb`, `virt_efi_reset_system`) must use `down_trylock(&efi_runtime_lock)` and invoke firmware directly in caller context. [F187, F318]
- In `riscv_enable_runtime_services()`, `efi_virtmap_init()` and `efi_native_runtime_setup()` must complete before setting `EFI_RUNTIME_SERVICES` in `efi.flags`. On RISC-V, `efi_virtmap_load()` disables preemption around switching `current->active_mm` to `efi_mm` until `efi_virtmap_unload()`, so code in between must not sleep. [F200, F321]

## Object Lifetimes
- Call `efi_memmap_unmap()` (which unmaps `efi.memmap.map`, sets it to `NULL`, and clears `EFI_MEMMAP`) before `efi_memmap_init_late()`. In `efi_exit_boot_services()`, run map-mutating calls like `efi_pci_disable_bridge_busmaster()` before `efi_get_memory_map()`, and on `exit_boot_services()` retry reuse the existing `map` buffer without `allocate_pool` or `free_pool`. [F171, F173]
- In `efi_random_get_seed()`, zero and `free_pool(prev_seed)` only after `install_configuration_table` succeeds with the new seed. In `alloc_e820ext()`, reset `*e820ext = NULL` and `*e820ext_size = 0` after freeing the old buffer and before calling `allocate_pool`. [F176, F179]
- In `tee_stmm_efi.c`, `setup_mm_hdr(&comm_buf, payload_size, func)` allocates `comm_buf` via `alloc_pages_exact(COMM_BUF_SIZE(payload_size), ...)` (required for `tee_shm_register_kernel_buf()`) and returns `var_hdr->data`; callers must pass `comm_buf` and the unmutated `payload_size` to `mm_communicate()` and `free_pages_exact()`, and `tee_mm_communicate()` must call `tee_shm_free(shm)`. In `tee_stmm_efi_probe()`, register `devm` cleanups for `ctx` then `session` in order and call `efivars_generic_ops_unregister()` before registering `tee_efivars`; `tee_stmm_efi_remove()` must unregister `tee_efivars` before `tee_stmm_restore_efivars_generic_ops()`. [F181, F182, F232, F271, F331]
- In `accept_memory()`, stack `range` on `accepting_list` must stay linked while `unaccepted_memory_lock` is dropped (with IRQs disabled) across `arch_accept_memory()`, and must be unlinked via `list_del(&range.list)` with `touch_softlockup_watchdog()` called before unlocking. [F183, F316]
- `efifb_add_links()` must call `of_node_put(sup_np)` on the node returned by `find_pci_overlap_node()`. In `efi_rci2_sysfs_init()` and `ovmf_log_probe()`, `memunmap()` the initial header mapping before remapping the full table and unwind mappings/kobjects on error. Every virtual runtime call in `efi_call_rts()` and `efi_call_virt_pointer()` must bracket firmware invocation with `arch_efi_call_virt_setup()` + `efi_call_virt_save_flags()` and `efi_call_virt_check_flags()` + `arch_efi_call_virt_teardown()`. [F184, F185, F188]

## API Contracts
- `efi_convert_cmdline()` returns `NULL` only on allocation failure; check `cmdline[0] == 0` for an empty command line. `handle_cmdline_files()` and `find_file_option()` take `optstr_size` in bytes excluding `L'\0'` (`sizeof(L"...") - 2`) and `cmdline_len`/`result_len` in `efi_char16_t` elements; `handle_cmdline_files()` returns `EFI_NOT_READY` when no option matches (a non-error). Multiply microsecond timeouts by `EFI_100NSEC_PER_USEC` (10) for `boottime->set_timer`. [F202, F207, F221, F299]
- In `efivar_set_variable_locked()`, pass `data_size + ucs2_strsize(name, EFI_VAR_NAME_LEN)` to `check_var_size()` when `data_size > 0`. Because `efivar_set_variable_locked()` falls back to `ops->set_variable` when `ops->set_variable_nonblocking` is `NULL`, backends with sleeping `set_variable` (like `tee_stmm_efi.c`) must populate `set_variable_nonblocking`. [F223, F320]
- `process_unaccepted_memory(start, end)` and `arch_accept_memory(start, end)` take `[start, end)` addresses, whereas `accept_memory(start, size)` and `range_contains_unaccepted_memory(start, size)` take start and byte length. `efi_mokvar_entry_next()` must clear `*mokvar_entry = NULL` before returning `NULL` on sentinel/error, and MOK sysfs attributes require mode `0400` and `capable(CAP_SYS_ADMIN)`. Annotate all indirect UEFI runtime callers in `runtime-wrappers.c` with `__nocfi`, and register `efi_power_off` with `SYS_OFF_PRIO_FIRMWARE + 1`. [F224, F272, F289, F333, F341]

## Error Handling
- In `allocate_new_fdt_and_exit_boot()`, guard `free_pool(priv.runtime_map)` with `if (!efi_novamap)`, and if `set_virtual_address_map()` fails post-EBS, mark `EFI_MEMORY_RUNTIME` descriptors with `virt_addr = U64_MAX` and return `EFI_SUCCESS`. In `handle_cmdline_files()`, `do_builtin` must reset `twopass = false` without zeroing `alloc_addr`/`alloc_size`, and errors must close `file`, `volume`, and `efi_free(alloc_size, alloc_addr)`. Functions returning pool buffers via double-pointer out-parameters (`efi_handle_cmdline()`, `preserve_pci_rom_image()`, `efi_get_memory_map()`) must free the local pointer on error and transfer via `no_free_ptr()` only on success. [F172, F178, F218, F266, F270]
- In `efi_tpm_eventlog_init()`, do not store unsigned `tbl_size` in the signed `int` variable used for `tpm2_calc_event_log_size()`. In `check_var_size()`, if `query_variable_store` is `NULL` or returns `EFI_UNSUPPORTED`, return `EFI_SUCCESS` for `size <= SZ_64K` and `EFI_OUT_OF_RESOURCES` otherwise. In `__efi_queue_work()`, set `efi_rts_work.status = EFI_DEVICE_ERROR` when `!efi_enabled(EFI_RUNTIME_SERVICES)`, and return `EFI_UNSUPPORTED` in UEFI 2.0 runtime wrappers when `efi.runtime_version < EFI_2_00_SYSTEM_TABLE_REVISION`. [F201, F203, F204, F313]
- In `efi_adjust_memory_range_protection()`, propagate errors from `memattr` callbacks to `efi_decompress_kernel()`; on the `efi_dxe_table` path (after validating `EFI_DXE_SERVICES_TABLE_SIGNATURE`), compute `next = desc.base_address + desc.length` before `continue` and only modify `EfiGcdMemoryTypeSystemMemory`/`EfiGcdMemoryTypeMoreReliable` regions with `EFI_MEMORY_RO | EFI_MEMORY_XP`. In `tee_stmm_efi.c`, check both `rc < 0` and `arg.ret != 0` / `sess_arg.ret != 0`, and in `get_property_int()` convert `EFI_NOT_FOUND` to `EFI_SUCCESS` with zeroed `*var_property`. [F205, F206, F208, F265, F312]

## External Contracts
- Declare all UEFI callbacks/function pointers with `__efiapi` and keep `efi_guid_t` 32-bit aligned. Allocate kexec-persistent tables (`unaccepted_table`, RNG `seed`) from `EFI_ACPI_RECLAIM_MEMORY`. Use `efi_set_u64_split()` for split 64-bit `boot_params`/`screen_info` fields and set `VIDEO_CAPABILITY_64BIT_BASE` when `ext_lfb_base` is non-zero. Check `IS_ALIGNED((u64)_text, SEGMENT_ALIGN)` in arm64 `handle_kernel_image()`. [F247, F259, F324, F332]
- In `__efi_get_smbios_string()`, start at `(u8 *)record + record->length` with 1-based indexing. In `efi_rci2_sysfs_init()`, verify `RCI_SIGNATURE`, `rci2_len != 0`, and 16-bit `checksum() == 0` (including odd trailing byte). In `tee_stmm_efi.c`, place variable data at `(u8 *)var_acc->name + name_size` (`name_size` including NUL `u16`) and verify `out_name_size >= in_name_size` in `tee_get_next_variable()`. Compute TPM2 log size as `log_last_entry - log_location + last_entry_size` via `__calc_tpm2_event_size()`. In `zboot-decompress-*`, declare `payload_size` as `u32 __aligned(1)`, subtract 4 from ZSTD input length, and skip 10-byte GZIP header. [F246, F250, F253, F257, F261]

## Known Pitfalls
- Zero partially populated `allocate_pool` buffers with `memset()`. Pass physical table addresses (never `early_memremap()` virtual pointers) to `memblock_reserve()`. Synchronize I/D caches (`efi_icache_sync()` / `efi_cache_sync_image()`) before `efi_remap_image()` or jumping to relocated/decompressed kernel images. [F215, F325, F328]
- In `libstub/vsprintf.c`, never use `%z` or `%t` format qualifiers; `%.*ls` precision is in output UTF-8 bytes (and `utf16s_utf8nlen()` must not read a second surrogate `u16` at `len + clen == maxlen`); `put_dec()` must use `0x346DC5D7ULL >> 43` instead of 64-bit `/`/`%`; and `efi_puts()` must flush `buf` when `pos >= lim - 2`. [F256, F279, F295, F296]
- In arm64 `system_needs_vamap()`, match Ampere eMAG/Altra via SMBIOS type 4 (`0x0a160001`/`0x0a160002` and processor version strings) keeping `default:` before the `case` labels so matching strings fall through to `return true`. In `memrange_efi_to_native()`, compute `*npages = PFN_UP(*addr + (*npages << EFI_PAGE_SHIFT)) - PFN_DOWN(*addr)` before `*addr &= PAGE_MASK`. In `pixel_bpp()` and `find_bits()`, check `if (!mask)` before `__ffs()`/`__fls()`. [F274, F285, F287, F309]
