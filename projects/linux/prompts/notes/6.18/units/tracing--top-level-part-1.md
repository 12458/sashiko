# TRACING — (top level) (part 1)

This component implements the `tracefs` pseudo-filesystem and its just-in-time (JIT) `eventfs` inode/dentry management layer (`fs/tracefs/`), alongside the core kernel tracepoint, trace event, recursion-protection, sequence-buffer, and BPF raw-tracepoint header infrastructure (`include/linux/trace*.h`, `include/trace/`), plus subsystem trace event definitions (`include/trace/events/alarmtimer.h` through `kyber.h`).

## Architecture & Data Flow

- In `struct tracefs_inode`, `ti->private` points to a root `struct inode` when `TRACEFS_EVENT_INODE` is clear, to `struct eventfs_inode` on eventfs directories, and is `NULL` on eventfs regular files (which store their parent `eventfs_inode` in `dentry->d_fsdata`). Broken by: dereferencing `ti->private` when `TRACEFS_EVENT_INODE` is set without a `NULL` check, or passing an eventfs inode to `set_tracefs_inode_owner()`. [F213]
- On non-eventfs `tracefs` inodes, `tracefs_setattr()` must set `TRACEFS_UID_PERM_SET`/`TRACEFS_GID_PERM_SET` in `ti->flags` so `set_tracefs_inode_owner()` preserves explicit ownership. In `tracefs_apply_options()`, `Opt_uid`/`Opt_gid` remounts must update `ti->flags` and `ti->vfs_inode.i_uid`/`i_gid` on each `tracefs_inode` before `eventfs_remount()` propagates them into `eventfs_set_attrs()`. [F227, F228]
- In `eventfs_set_attr()`, JIT dentry attribute changes must be saved under `eventfs_mutex` in `ei->attr` (when `!ei->is_events`) or `ei->entry_attrs[i]` (files) with `EVENTFS_SAVE_MODE`/`UID`/`GID` for `update_inode_attr()`. `eventfs_attr.mode` packs both the 16-bit mode (`EVENTFS_MODE_MASK`) and upper `EVENTFS_SAVE_*` flags, so `update_attr()` must preserve `~EVENTFS_MODE_MASK` and `update_inode_attr()` must mask `attr->mode` with `EVENTFS_MODE_MASK`. [F229, F246]
- `eventfs_dir_ino()` must skip `EVENTFS_FILE_INODE_INO` (`0x12c4e37`) when assigning directory `ei->ino` (all eventfs regular files share it). The `eventfs_inode` hierarchy under `events/` must not exceed depth 3 (`level > 3`), where `eventfs_set_attrs()` and `eventfs_remove_rec()` warn and abort. [F239, F297]
- In `struct tracepoint`, `tp->ext` is `NULL` for `DEFINE_TRACE` and non-NULL only for `DEFINE_TRACE_FN`/`DEFINE_TRACE_SYSCALL`, so check `if (tp->ext)` before accessing `faultable`, `regfunc`, or `unregfunc`. In `__DEFINE_TRACE_EXT()`, `__traceiter_##_name()` unconditionally dereferences `it_func_ptr[0].func` in a `do-while` loop until `(++it_func_ptr)->func` is `NULL`, requiring non-NULL `funcs` arrays to have at least one valid entry and a `NULL` terminator. [F218, F251]
- In `struct trace_event_fields` arrays, when `type == TRACE_FUNCTION_TYPE` (`(const char *)~0UL`), the anonymous union's `define_fields` function pointer is active rather than the field metadata struct (`name`, `size`, `align`, etc.); always check `field->type == TRACE_FUNCTION_TYPE` before dereferencing `type` or `name` as strings. [F217]
- In `struct trace_iterator`, transient per-entry state reset on each `pipe_read` cycle must sit at or after `struct trace_seq seq`, while persistent session state (`tr`, `trace`, `array_buffer`, `buffer_iter`, `iter_flags`, `temp`, `fmt`, `tmp_seq`, `started`, `closed`, `snapshot`) must precede `seq`. [F233]
- `struct trace_dynamic_info` must place `len` before `offset` on `CONFIG_CPU_BIG_ENDIAN` and `offset` before `len` on little-endian CPUs to match the `offset | (len << 16)` layout of 32-bit `__data_loc_<item>` locators. In `include/trace/bpf_probe.h`, `__CAST_TO_U64(x)` must copy arguments into `UINTTYPE(sizeof(x))` before casting to `u64` so narrow signed integers and small structs zero-extend for `bpf_trace_run1`..`12`. [F236, F260]
- Recursion context bit enums at `TRACE_FTRACE_BIT` and `TRACE_INTERNAL_BIT` must stay ordered as `[BASE, NMI, IRQ, SIRQ, TRANSITION]` because `trace_test_and_set_recursion()` indexes them via `TRACE_CTX_NORMAL - interrupt_context_level()` (or `TRACE_CTX_TRANSITION`). [F242]

## Synchronization

- `eventfs_create_dir()` must initialize `ei->name`, `ei->kref`, `ei->entries`, `ei->nr_entries`, `ei->data`, `ei->children`, and `ei->list` before taking `eventfs_mutex` and linking `ei->list` into `parent->children` (only if `!parent->is_freed`). Allocations in `eventfs_set_attr()` under the VFS inode lock and `eventfs_mutex` (e.g., `ei->entry_attrs`) must use `GFP_NOFS`. [F194, F277]
- In `eventfs_iterate()`, hold `srcu_read_lock(&eventfs_srcu)` across the walk, take `eventfs_mutex` to check `!ei->is_freed` and run `entry->callback`, and release `eventfs_mutex` before `dir_emit()`. `eventfs_callback` runs under `eventfs_mutex` and must never re-enter `tracefs`/`eventfs` APIs. `tracefs_d_revalidate()` may run in `LOOKUP_RCU`, so it must check `ei->is_freed` locklessly without taking `eventfs_mutex` or sleeping. [F196, F197, F278]
- Mutate `tracefs_inodes` only under `spin_lock_irqsave(&tracefs_inode_lock, flags)` with `list_add_rcu()`/`list_del_rcu()` (`tracefs_alloc_inode()`, `tracefs_destroy_inode()`) and traverse under `rcu_read_lock()` with `list_for_each_entry_rcu()`. [F199]
- `tracefs_syscall_mkdir()` and `tracefs_syscall_rmdir()` must copy `dentry->d_name` via `get_dname(dentry)` before unlocking `inode` (and `d_inode(dentry)` in `rmdir`), call `tracefs_ops.mkdir`/`rmdir`, and re-lock (`I_MUTEX_PARENT` on `inode` first in `rmdir`) before returning. [F186]
- `__DECLARE_TRACE` must call `__DO_TRACE_CALL` under `guard(preempt_notrace)()`, whereas faultable `__DECLARE_TRACE_SYSCALL` must use `guard(rcu_tasks_trace)()` and disable preemption in `__BPF_DECLARE_TRACE_SYSCALL` around `bpf_trace_run*`. [F203]
- `current->trace_recursion` may only be modified by `current`: `trace_test_and_set_recursion()` must set the bit and issue `barrier()` before `preempt_disable_notrace()`, and `trace_clear_recursion()` must call `preempt_enable_notrace()` and `barrier()` before `trace_recursion_clear(bit)`. [F286]
- Writers updating `struct trace_event_file::flags` (`EVENT_FILE_FL_*`) must use atomic `set_bit()`/`clear_bit()`, whereas tracing critical-section readers may read `file->flags` non-atomically. `bpf_prog_array_valid(call)` does a lockless `READ_ONCE(call->prog_array)` outside RCU, so callers must re-check `call->prog_array` after entering `rcu_read_lock()`. [F205, F206]
- `hist_poll_wakeup()` may run in hardirq/NMI trigger contexts and must defer waking `hist_poll_wq` via `irq_work_queue(&hist_poll_work)` after `wq_has_sleeper(&hist_poll_wq)` rather than calling `wake_up()` directly. [F287]

## Object Lifetimes

- Only `dentry->d_fsdata` holds a `kref` on `struct eventfs_inode` (`get_ei()` in `lookup_file()`, `lookup_dir_entry()`, `eventfs_create_events_dir()`; `put_ei()` in `eventfs_d_release()`); `tracefs_inode.private` is uncounted and must not touch `ei->kref`. [F180]
- In `struct eventfs_inode`, `list` and `rcu` share a union, so `eventfs_remove_rec()` must call `list_del_rcu(&ei->list)` under `eventfs_mutex` before `free_ei(ei)` schedules `call_srcu(&eventfs_srcu, &ei->rcu, free_ei_rcu)`. `free_ei_rcu()` must free `ei->name` with `kfree_const()` and check `ei->is_events` to free `get_root_inode(ei)` (`struct eventfs_root_inode`) rather than `kfree(ei)`. [F182, F183]
- `eventfs_remove_events_dir()` must read `dentry = rei->events_dir`, clear `rei->events_dir = NULL`, and call `eventfs_remove_dir(ei)` before `d_invalidate(dentry)` and `dput(dentry)`. [F184]
- A successful `tracefs_start_creating()` pins `tracefs_mount`, gets `dentry`, and locks `d_inode(dentry->d_parent)`, so callers must finish with `tracefs_end_creating(dentry)` or `tracefs_failed_creating(dentry)`. [F185]
- After `tracepoint_probe_unregister()`, callers must call `tracepoint_synchronize_unregister()` before freeing probe code/data, or defer via `call_rcu_tasks_trace()` when `tracepoint_is_faultable(tp)` is true and `call_rcu()` when false. [F190]
- `tracepoint_string(str)` stores the raw pointer in `__tracepoint_str`, so `str` must be a persistent string literal valid for the kernel/module lifetime. `dma_fence_unsignaled` tracepoints call `fence->ops->get_driver_name()`/`get_timeline_name()` without RCU and must only be used when `fence` cannot race with signaling. [F191, F192]

## API Contracts

- `eventfs_create_events_dir()` returns `NULL` under `LOCKDOWN_TRACEFS` or an `ERR_PTR` on error, whereas `eventfs_create_dir()` always returns an `ERR_PTR` on failure (never `NULL`). With `CONFIG_TRACING`, `tracefs_create_file()`, `tracefs_create_dir()`, and `tracefs_create_instance_dir()` always translate `IS_ERR` to `NULL`. `tracefs_create_file()` (`BUG_ON`) and `lookup_file()` (`-EIO`) require `mode` to omit `S_IFMT` or satisfy `S_ISREG(mode)`. [F208, F209, F299]
- In `eventfs_root_lookup()` and `eventfs_iterate()`, reset local `data = ei->data` before each `entry->callback(name, &mode, &data, &fops)` call; callbacks return `<= 0` to omit the entry and `> 0` to create/emit it. [F210, F221]
- `trace_test_and_set_recursion()` / `ftrace_test_recursion_trylock()` disable preemption only when returning `bit >= 0`; call `trace_clear_recursion(bit)` / `ftrace_test_recursion_unlock(bit)` iff `bit >= 0` with that exact `bit`. `trace_recursion_set()`, `trace_recursion_clear()`, `trace_recursion_test()`, and `trace_clear_recursion()` take an unshifted bit index, never `BIT(bit)`. `tracing_gen_ctx_dec()` requires preemption disabled so `trace_ctx--` does not underflow the low preempt-count bits under `CONFIG_PREEMPTION`. [F188, F224, F259]
- `trace_event_class::reg` returns boolean `1` (`true`) for `TRACE_REG_PERF_ADD`/`DEL` when a custom action was taken (skipping default per-CPU list ops) and `0` (`false`) for the default action. In `trace_trigger_soft_disabled()`, test `EVENT_FILE_FL_TRIGGER_COND` (returning `false`) before `__trace_trigger_soft_disabled()` so conditional triggers still format records. [F212, F247]
- Use `trace_seq_used(s)` rather than `s->seq.len` (which can exceed `TRACE_SEQ_BUFFER_SIZE` on overflow) for valid byte counts in `struct trace_seq`. Terminate `struct trace_print_flags` / `trace_print_flags_u64` arrays passed to `trace_print_flags_seq*()` / `trace_print_symbols_seq*()` with `{ ..., NULL }`. [F223, F241]
- `__DEFINE_RUST_DO_TRACE` (`rust_do_trace_##name`) calls `__do_trace_##name(args)` without checking `__tracepoint_##name.key` (Rust callers must gate on the static branch), and `DEFINE_RUST_DO_TRACE` in `include/trace/define_trace.h` is only active during `TRACE_INCLUDE` when both `CREATE_RUST_TRACE_POINTS` and `CREATE_TRACE_POINTS` are defined. [F274, F275]
- Guard `include/trace/events/*.h` headers with `#if !defined(_TRACE_<SYSTEM>_H) || defined(TRACE_HEADER_MULTI_READ)` and place `#include <trace/define_trace.h>` outside `#endif`. Pass `unsigned long *` bitmaps (e.g., `cpumask_bits(mask)`) as `src` to `__assign_bitmask()`/`__assign_cpumask()`. [F272, F303]

## Error Handling

- When `eventfs_create_dir()` or `eventfs_create_events_dir()` fails after setting `ei->entries` and `ei->nr_entries`, free `ei` via `cleanup_ei(ei)` (not `free_ei(ei)` or `put_ei(ei)`) so `ei->nr_entries` is zeroed and `release_ei()` does not run `entry->release` callbacks. [F181]

## External Contracts

- `tracefs_create_file()`, `tracefs_create_dir()`, and `eventfs_create_events_dir()` must check `security_locked_down(LOCKDOWN_TRACEFS)` and return `NULL` when locked down. All `eventfs` directory inodes must keep `i_nlink == 1` (never `inc_nlink()`). In `include/trace/events/kmem.h`, `rss_stat` must store `mm_ptr_to_hash(mm)` rather than a raw `mm` pointer. [F243, F298, F306]

## Known Pitfalls

- In `eventfs_iterate()`, call `dir_emit_dots(file, ctx)` before `c = ctx->pos - 2` so `c >= 0`. On `dir_emit()` failure, the `ei->entries` loop (which increments `ctx->pos` in the `for` header) must jump to `out`, whereas the `ei->children` loop (which increments `ctx->pos` before `dir_emit()`) must jump to `out_dec`. [F250, F262]
- In `set_tracefs_inode_owner()`, when `root_inode` is an instance root (`rti`), test `rti->flags` for mount-root UID/GID fallback, but test `ti->flags` before updating `inode->i_uid`/`i_gid`. In `eventfs_get_inode()`, advance `dentry = dentry->d_parent` before reading `pei = dentry->d_fsdata` in a `do-while` loop until `pei->is_events` is set, because the child dentry's `d_fsdata` is not set yet. [F253, F255]
- `__dynamic_array(type, item, len)` takes an element count (divide byte lengths by `QUADLET_SIZE` for `u32` arrays in `firewire.h`), whereas `__get_dynamic_array_len(item)` returns byte size (divide by `sizeof(type)` in `__print_array()`). When skipping elements in `firewire_ohci.h`, cast `__get_dynamic_array()` (`void *`) to `const u32 *` before pointer arithmetic and decrement the count. In `firewire.h`, `ASYNC_HEADER_GET_OFFSET(header)` must cast the masked quadlet to `unsigned long long` before `<< 32`. [F237, F263, F266, F273]
- In `include/trace/events/filemap.h`, check `if (mapping->host->i_sb)` before reading `s_dev` (falling back to `i_rdev`), and cast `unsigned long` `index`/`last_index` to `loff_t` before `+ 1` and `<< PAGE_SHIFT` in `mm_filemap_op_page_cache_range` and `mm_filemap_fault`. In `include/trace/events/icmp.h`, `trace_icmp_send` must verify `proto_4 == IPPROTO_UDP`, `(u8 *)uh >= skb->head`, and `(u8 *)uh + sizeof(struct udphdr) <= skb_tail_pointer(skb)` before reading `uh`. [F264, F304, F307]
