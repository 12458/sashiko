# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd (part 2)

This component implements the NFSD sunrpc service lifecycle (`nfssvc.c`), `/proc/fs/nfsd` and generic netlink interfaces (`nfsctl.c`), filehandle verification and composition (`nfsfh.c`, `nfsfh.h`), the duplicate reply cache (`nfscache.c`), NFSv2 procedure and XDR handlers (`nfsproc.c`, `nfsxdr.c`), the NFSv4 compound XDR decoder and encoder (`nfs4xdr.c`, `nfs4xdr_gen.c`), and statistics (`stats.c`, `stats.h`).

## Architecture & Data Flow

- Every `enum nfsd_fsid` variant must be handled in lockstep in `key_len()`, `mk_fsid()` (which `BUG()`s on unknown variants), `fsid_type_ok_for_exp()`, and `fsid_source()`. `fh_compose()` must zero `fh_auth_type` (`fh_raw[1]`) and `nfsd_set_fh_dentry()` rejects non-zero `fh_auth_type` with `nfserr_badhandle`; `fh_fsid_type` must map to a non-zero `key_len()` with `fh->fh_size / 4 >= 1 + key_len(fh->fh_fsid_type) / 4`. [F416, F426]
- In `set_version_and_fsid_type()`, `FSID_UUID16` and `FSID_UUID16_INUM` require `fhp->fh_maxsize >= 64`, `FSID_DEV` requires `old_valid_dev(exp_sb(exp)->s_dev)`, and `ref_fh = NULL` must be set before the `version` switch and `fsid_type_ok_for_exp()` check so `goto retry` falls back to `exp` instead of looping forever. [F427, F445]
- In `__fh_verify()`, even when `fhp->fh_dentry` is already populated, `check_pseudo_root()`, `nfsd_setuser_and_check_port()`, `nfsd_mode_check()`, security flavor checks, and `nfsd_permission()` must still run because access flags or export credentials may differ across operations. [F408]
- In `nfsd_dispatch()`, `xdr_stream_pos(&rqstp->rq_arg_stream)` and `xdr_stream_remaining(&rqstp->rq_arg_stream)` must be saved before `proc->pc_decode()` advances past the header checksummed by `nfsd_cache_lookup()`. `nfsd_cacherep_alloc()` must zero `rp->c_key` with `memset()` before field assignment because `nfsd_cache_key_cmp()` `memcmp()`s the whole struct including padding. [F381, F404]
- In `nfsd_reply_cache_init()`, `hashsize` is a power of two (`<= 32768`) with `nn->maskbits = ilog2(hashsize)` (`hashsize == 1U << nn->maskbits`, `maskbits < 32`). In `nfsd_prune_bucket_locked()`, `rp->c_timestamp` expiration must use `time_before(jiffies - RC_EXPIRE, rp->c_timestamp)`, never `<` or `>`. [F455, F458]
- In `nfsd4_decode_compound()`, `argp->opcnt` must be forced to `0` when `argp->minorversion > NFSD_SUPPORTED_MINOR_VERSION` before decoding ops because `nfsd_suppattrs[minorversion]` has `NFSD_SUPPORTED_MINOR_VERSION + 1` rows. Every opcode in `nfsd4_opnum_in_range()` needs non-NULL entries in `nfsd4_dec_ops[]` and `nfsd4_enc_ops[]`. [F415, F424]
- Every bit in `NFSD_WRITEABLE_ATTRS_WORD0..2` must be decoded in ascending bit order in `nfsd4_decode_fattr4()` (which checks `attrlist4_count == xdr_stream_pos(argp->xdr) - starting_pos`), and every bit in `nfsd_suppattrs` must have a non-NULL callback at `nfsd4_enc_fattr4_encode_ops[FATTR4_*]`. [F389, F414]
- `nfsd4_encode_fattr4()` must copy `const u32 *bmval` into a local `attrmask[3]` before masking out unsupported/absent-fs bits so `READDIR` can reuse `cd->rd_bmval`. When `nfsd4_deleg_getattr_conflict()` returns a delegation `dp`, `args.change_attr` must come from `dp->dl_cb_fattr.ncf_initial_cinfo` (after incrementing it and updating `args.stat.size` from `ncf_cur_fsize` if `ncf_file_modified`) rather than `nfsd4_change_attribute()`. [F398, F412]
- Raw XDR space reservations for opaque payloads (`nfsd4_encode_opaque_fixed`, `nfsd4_encode_opaque`, `nfsd4_encode_readv`, `nfsd4_encode_readlink`, `nfsd4_vbuf_to_stream`) must zero trailing `xdr_pad_size(len)` bytes. `nfsd4_decode_stateid4()`/`nfsd4_encode_stateid4()` byte-swap `si_generation`, while `si_opaque` and `clientid_t` are `memcpy()`d verbatim. [F395, F428]
- In `nfsd()`, worker kthreads must call `unshare_fs_struct()` before setting `current->fs->umask = 0`. In `nfsd_set_nrthreads()`, each `nthreads[i]` must be clamped to `NFSD_MAXSERVS` before summing `tot`, and `tot > 0` checked before dividing `nthreads[i] * NFSD_MAXSERVS / tot`. [F406, F457]
- Toggling NFSv4 minor versions must go through `nfsd_minorversion()`, which sets `nn->nfsd_versions[4]` on `NFSD_SET` and calls `nfsd_adjust_nfsd_versions4()` on `NFSD_CLEAR`. In `nfsd_nl_listener_set_doit()`, removing any listener (`!list_empty(&permsocks)` after moving kept `svc_xprt`s via `list_for_each_entry_safe`) requires splicing `permsocks` back onto `serv->sv_permsocks` before unlocking `serv->sv_lock`, verifying `serv->sv_nrthreads == 0`, and calling `svc_xprt_destroy_all()` before recreating kept listeners. [F399, F401, F444]

## Synchronization

- `nfsd_mutex` must be held for `nfsd_svc()`, `nfsd_create_serv()`, `nfsd_destroy_serv()`, and `nfsd_set_nrthreads()`, and when mutating `nn->nfsd_versions`, `nn->nfsd4_minorversions`, `nn->nfsd4_lease`, `nn->nfsd4_grace`, or `nfsd_max_blksize` after `nfsd_net_init()`. [F362]
- In `nfsd_reply_cache_init()`, `nn->drc_hashsize` must stay `0` until every bucket's `lru_head` and `cache_lock` in `nn->drc_hashtbl` are initialized, because `shrinker_register()` runs first and `nfsd_reply_cache_scan()` iterates up to `nn->drc_hashsize`. [F356]
- All accesses to `b->rb_head`, `b->lru_head`, and `rp->c_state` transitions (`RC_INPROG` to `RC_DONE`) require `b->cache_lock`. `nfsd_cache_update()` must populate `rp->c_replvec` or `rp->c_replstat` while `c_state == RC_INPROG` before `lru_put_end()` and `c_state = RC_DONE` under `b->cache_lock`. `GFP_KERNEL` allocations and `nfsd_cacherep_dispose()` of entries unlinked by `nfsd_prune_bucket_locked()` must run outside `b->cache_lock`. [F364, F365, F473]
- In `clear_ncl()` and `get_nfsdfs_client()`, `inode->i_private` access requires `inode->i_lock`: `get_nfsdfs_client()` takes `nc->cl_ref` under `i_lock`, while `clear_ncl()` drops `i_lock` before `kref_put(&ncl->cl_ref, ncl->cl_release)`. `nn->writeverf` updates require `write_seqlock(&nn->writeverf_lock)` (`nfsd_reset_write_verifier()`), paired with `nfsd_copy_write_verifier()`. [F367, F368]
- In `nfsd_dispatch()`, `rqstp->rq_status_counter` is set odd via `smp_store_release()` after `pc_decode()` and incremented back to even via `smp_store_release()` after `pc_encode()`, pairing with the two `smp_load_acquire()` checks in `nfsd_nl_rpc_status_get_dumpit()`, which also requires both `nfsd_mutex` and `rcu_read_lock()` while iterating `sp_all_threads`. [F369, F370]
- `nfsd_net_try_get()` (using `percpu_ref_tryget_live(&nn->nfsd_net_ref)`) and `nfsd_net_put()` require `rcu_read_lock()`. `try_to_expire_client()` must use `cmpxchg(&clp->cl_state, NFSD4_COURTESY, NFSD4_EXPIRABLE)`. [F371, F374]

## Object Lifetimes

- Callers of `fh_verify()` or `fh_verify_local()` must call `fh_put(fhp)` even on error because `nfsd_set_fh_dentry()` populates `fh_dentry` and `fh_export` before later checks can fail. In `nfsd_procedures2`, `.pc_release` only releases `resp->fh`, so NFSv2 handlers verifying `argp->fh`, `argp->ffh`, `argp->tfh`, or a local `svc_fh` without `fh_copy()` into `resp->fh` must call `fh_put()`. [F337, F341]
- `fh_want_write()` acquires `mnt_want_write()` at most once (`fhp->fh_want_write`). `fh_put()` must call `fh_drop_write(fhp)` before `exp_put(fhp->fh_export)` and zero `fh_dentry`, `fh_export`, `fh_want_write`, `fh_pre_saved`, `fh_post_saved`, and `fh_no_wcc`. In `fh_compose(fhp, exp, dentry, ref_fh)`, when `ref_fh == fhp`, `set_version_and_fsid_type()` and `ref_fh->fh_no_wcc` must run and `fh_put(ref_fh)` be called before assigning new `fh_dentry`/`fh_export`, and `FILEID_INVALID` failure calls `fh_put(fhp)`. [F338, F340, F490]
- In `nfsd_dispatch()`, once `nfsd_cache_lookup()` returns `RC_DOIT`, every exit path (including `RQ_DROPME` and `pc_encode` error) must call `nfsd_cache_update()` (with `RC_NOCACHE, NULL` on error) to free `rp`. `rp->c_type = RC_REPLBUFF` is set iff `c_replvec.iov_base` is allocated and accounted in `NFSD_STATS_DRC_MEM_USAGE`, and `c_state != RC_UNUSED` iff linked in `b->rb_head` and counted in `nn->num_drc_entries`. `nfsd_reply_cache_shutdown()` must call `shrinker_free()` before freeing `nn->drc_hashtbl` and clearing `drc_hashtbl = NULL` and `drc_hashsize = 0`. [F342, F343, F344]
- Any `nfsd_create_serv(net)` caller must call `nfsd_destroy_serv(net)` if `sv_nrthreads == 0` on `nfsd_svc()` exit or `!sv_nrthreads && list_empty(&sv_permsocks)` after listener setup. `nfsd_destroy_serv()` requires `nfsd_mutex`, clears `nn->nfsd_serv = NULL` under `nfsd_notifier_lock`, and unconditionally calls `svc_xprt_destroy_all()` and `svc_destroy()` even if `!nn->nfsd_net_up`. [F345, F346]
- `nfsd_startup_net()`/`nfsd_shutdown_net()` and `nfsd_net_init()`/`nfsd_net_exit()` must unwind in reverse LIFO order; `nfsd_shutdown_net()` must confirm `percpu_ref_kill_and_confirm(&nn->nfsd_net_ref, nfsd_net_done)` before teardown and wait for `nn->nfsd_net_free_done` before `percpu_ref_exit()`, and `nfsd_net_pre_exit()` must call `nfs_localio_invalidate_clients()` before `nfsd_net_exit()` destroys `nn->counter`. [F347, F349]
- In `nfsd_mkdir()`, `_nfsd_symlink()`, and `nfsdfs_create_files()`, `iput(inode)` is required if `simple_start_creating()` fails; in `nfsd_client_mkdir()`, `nfsdfs_create_files()` failure requires `nfsd_client_rmdir(dentry)`. `_nfsd_symlink()` stores `content` directly in `inode->i_link` without copying. `nfsd` file ops must get `struct net *` via `netns(file)` (`inode->i_sb->s_fs_info`), and `nfsd_umount()` must call `nfsd_shutdown_threads(net)` before `put_net(net)`. [F350, F468, F496]
- In `nfs4svc_decode_compoundargs()`, per-op buffers must use `svcxdr_tmpalloc()` (`argp->to_free`) and `argp->ops` (when `opcnt > ARRAY_SIZE(argp->iops)`) must use `vcalloc()` (resetting `argp->ops = argp->iops` on failure) for `nfsd4_release_compoundargs()`. `xdr_inline_decode()` buffers kept across decode calls require `svcxdr_savemem()` (or `svcxdr_dupstr()` for NUL-terminated strings). [F351, F503]
- `nfsd4_encode_operation()` must exit via `release:` to call `opdesc->op_release(&op->u)` and advance `rqstp->rq_next_page = xdr->page_ptr + 1`. `nfsd4_encode_fattr4()` must exit via `out:` to free `args.context`, `args.acl`, and `tempfh` (`fh_put` + `kfree`) and call `xdr_truncate_encode(xdr, starting_len)` on error. `nfsd4_encode_getxattr()` and `nfsd4_encode_listxattrs()` must `kvfree()` `getxa_buf`/`lsxa_buf` when length `> 0`. [F352, F353, F354]

## API Contracts

- `fh_copy(dst, src)` requires `src->fh_dentry == NULL` (shallow copy without refcounts). In `nfsfh.c`, `fh_size`, `fh_maxsize`, and `key_len()` are in bytes, whereas `exportfs_decode_fh_raw()` (`data_left`), `exportfs_encode_fh()` (`maxsize`), and `fh_fsid()` pointer arithmetic use 4-byte words. [F339, F378]
- In `__fh_verify()`, `check_xprtsec_policy(exp, rqstp)` must run independently of `NFSD_MAY_BYPASS_GSS*`, skipped only when `!rqstp` or `access & NFSD_MAY_NLM`. In `nfsd_set_fh_dentry()`, `NFSEXP_NOSUBTREECHECK` calls `cap_raise_nfsd_set()` before `exportfs_decode_fh_raw()`, whereas without it `nfsd_setuser_and_check_port()` must run first for `nfsd_acceptable()`. [F436, F488]
- `nfsd4_change_attribute()` requires `stat` from `vfs_getattr()` with `STATX_CHANGE_COOKIE | STATX_MODE | STATX_CTIME` or `fh_getattr()` on an `NFS4_FHSIZE` handle (`fh_getattr()` omits `STATX_CHANGE_COOKIE` otherwise). [F379]
- `nfsd_svc()` returns thread count (`>= 0`) or `-errno` (clamp `> 0` to `0` in `.doit` callbacks). `nfsd_set_nrthreads()` with `n == 1` distributes `nthreads[0]` across all pools; `n > 1` sets pools `0..n-1` and zeros remaining pools. `write_threads()` and `__write_ports()` must pass `file->f_cred` (not `current_cred()`). `nfsd_current_rqst()` must be used (and NULL-checked) when outside an `nfsd()` kthread. [F385, F386, F484, F494]
- `nfsd4_decode_bitmap4()` takes `bmlen` as `ARRAY_SIZE(bmval)`, never `sizeof(bmval)`. `nfsd4_decode_sequence()` and `nfsd4_encode_sequence()` convert between 0-based wire highest-slot indices and 1-based `seq->maxslots` / `target_maxslots`. `nfssvc_encode_entry()` and `nfsd4_encode_entry4()` return `0` or `-EINVAL`, storing the `__be32` `nfserr_*` in `common.err`. [F393, F394, F462]

## Error Handling

- `__fh_verify()`, `nfsd_set_fh_dentry()`, and `nfsd_setuser_and_check_port()` must NULL-check `rqstp` (`fh_verify_local()` passes `NULL`). `nfsd_set_fh_dentry()` must check `exportfs_decode_fh_raw()` with `IS_ERR_OR_NULL()` and only assign `fh_dentry`/`fh_export` after both `exp` and `dentry` are valid. [F376, F377]
- `nfsd4_decode_bitmap4()` only returns `nfserr_bad_xdr` on `-EBADMSG`, treating `-EMSGSIZE` as `nfs_ok`. `nfsd4_decode_fattr4()` must NULL-check `umask` and `nfsd4_decode_share_access()` must NULL-check `deleg_when`. Encoders for `OP_NONTRIVIAL_ERROR_ENCODE` ops (`lock`, `lockt`, `setattr`, `setclientid`) must return `nfserr` (not `nfs_ok`) after encoding error payloads. [F387, F390, F392]

## External Contracts

- `nfsd_print_version_support()` must suppress `+4.0` when v4.0 is enabled while printing `-4.0` when disabled. `write_pool_threads()` must ignore `npools == 0` (reporting `"0\n"`) and clamp `nthreads[0] == 0` to `1` on a running server. `nfsd_show()` must keep zero placeholders on `fh`, `th`, `ra`, and `proc4ops[0..2]`. `svcxdr_decode_sattr()` treats mode `0xffff` as unset and `mtime.usec == 1000000` as set-to-server-time; `nfsd4_dec_ops[OP_PUTPUBFH]` must use `nfsd4_decode_noop` on all minor versions. `nfsd_files` and `tree_descr` arrays must end with `{""}` / `{NULL}`, with static inodes `< NFSD_MaxReserved`. [F431, F432, F433, F434, F435, F440]

## Known Pitfalls

- `nfsd_mode_check()` must check `requested == S_IFDIR` before returning `nfserr_symlink` on `S_IFLNK` (returning internal `nfserr_symlink_not_dir`), and NFSv2/NFSv4 callers must map status via `nfsd_map_status()` / `nfsd4_map_status()`. `nfsd_minorversion()` returns `-1` when `minorversion > NFSD_SUPPORTED_MINOR_VERSION` and `change != NFSD_AVAIL` (check `> 0` or `NFSD_AVAIL`, never truthiness of `NFSD_TEST`). [F380, F384, F437]
- In `nfsd4_encode_fattr4()`, `args->fhp` is `NULL` during `READDIR` unless `FATTR4_WORD0_FILEHANDLE | FATTR4_WORD0_FSID` is set, and `u32 attrmask[3]` must be converted via `bitmap_from_arr32()` before `for_each_set_bit()`. In `nfs4xdr.c` encoders, never dereference `xdr_reserve_space()` pointers after subsequent encoding or `xdr_commit_encode()`—save `xdr->buf->len` and use `write_bytes_to_xdr_buf()`. `nfs4svc_encode_compoundres()` must advance `p` past `resp->tag` by `XDR_QUADLEN(resp->taglen)`. [F391, F396, F456, F463]
- `nfsd4_encode_splice_read()` requires a single read op, `xdr->buf->page_len == 0`, and free space in `xdr->buf->head`, and must reset `buf->page_len = 0` on error before `xdr_truncate_encode()`. Decoded XDR strings (`nfsd4_decode_component4`, `nfsd4_decode_opaque`, `nfsd4_decode_nl4_server`, `svcxdr_decode_filename`) are not NUL-terminated. In `nfsd4_decode_fattr4()`, `FATTR4_WORD2_TIME_DELEG_*` must assign `tv_sec = .seconds` and `tv_nsec = .nseconds`. [F429, F450, F470]
- In `nfsd4_encode_entry4_fattr()`, `exp_get(exp)` must precede `nfsd_mountpoint()`, and `nfsd_cross_mnt()` updates `dentry` and `exp` in place for both `nfsd4_encode_fattr4()` and `out_put:`. In `nfsd4_encode_listxattrs()`, `left -= XATTR_USER_PREFIX_LEN` and `sp += XATTR_USER_PREFIX_LEN` must run before `if (nuser++ < offset) goto contloop;`. [F447, F452]
- `nfsd_prune_bucket_locked()` must use `list_for_each_entry_safe()` on `&b->lru_head` because `rp->c_lru` is relinked onto `dispose`. `nfsd_acceptable()` must check `!IS_ROOT(tdentry)` in its parent walk loop. `nfsd_proc_setattr()` must test `(iap->ia_valid & BOTH_TIME_SET) == BOTH_TIME_SET`, and `nfsd4_change_attribute()` must cast `stat->ctime.tv_sec` to `u64` before `<< 30`. [F438, F443, F448, F453]
- `nfsd_nl_rpc_status_get_dumpit()` must reset `rqstp_index = 0` per pool iteration. `nfsd_nl_listener_set_doit()` must check `nla_len(tb[NFSD_A_SOCK_ADDR]) >= sizeof(struct sockaddr)` before reading `nla_data()`. `SVCFH_fmt()` uses a static buffer, rejects `fh_size > 64`, and cannot be called twice in one `dprintk()`. [F446, F467, F498]
