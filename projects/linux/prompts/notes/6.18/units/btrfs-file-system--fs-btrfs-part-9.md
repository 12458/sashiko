# BTRFS FILE SYSTEM — fs/btrfs (part 9)

Implements the Btrfs send stream generator (`send.c`), space reservation and async reclaim ticketing (`space-info.c`), subpage sector-granularity status bitmaps (`subpage.c`), and VFS superblock/mount handling, `/dev/btrfs-control`, and module init/exit (`super.c`).

## Architecture & Data Flow

- `btrfs_folio_state::bitmaps` packs `btrfs_bitmap_nr_max` (6) sub-bitmaps of `blocks_per_folio = fsize >> fs_info->sectorsize_bits` bits each, indexed at `(offset_in_folio(folio, start) >> fs_info->sectorsize_bits) + blocks_per_folio * btrfs_bitmap_nr_<name>`. `eb_refs` and `nr_locked` share a union by `btrfs_folio_type`: use `btrfs_folio_inc/dec_eb_refs()` only on metadata folios and `btrfs_folio_set/end_lock()` only on data folios, where `nr_locked` must equal the set bits in `btrfs_bitmap_nr_locked` under `bfs->lock` and `folio_unlock()` runs only when `nr_locked` was or hits 0. [F1034, F1048, F1077]
- `btrfs_subpage_set_uptodate()`/`_checked()` set the VFS folio flag only when `subpage_test_bitmap_all_set()` holds, while `_clear_uptodate()`/`_checked()` clear it when any bit clears. Setting any dirty, writeback, or ordered bit sets the VFS flag, and `btrfs_subpage_clear_dirty()`/`_writeback()`/`_ordered()` clear it only when `subpage_test_bitmap_all_zero()` holds. `btrfs_subpage_set_writeback()` must call `__folio_start_writeback(folio, true)` and only clear `PAGECACHE_TAG_TOWRITE` when `!folio_test_dirty(folio)`. [F1045, F1046, F1047]
- Queuing a `reserve_ticket` adds `ticket.bytes` to `space_info->reclaim_size` under `space_info->lock`; `remove_ticket()` must run before zeroing `ticket->bytes`. On fatal signal, `wait_reserve_ticket()` must call `remove_ticket()` and set `ticket->error = -EINTR` under `space_info->lock` so a ticket never has both `bytes == 0` and `error != 0`. [F1049, F1050]
- Granting a ticket in `btrfs_try_granting_tickets()` or `steal_from_global_rsv()` must increment `space_info->tickets_id` under `space_info->lock`. In `do_async_reclaim_metadata/data_space()`, if `tickets_id != last_tickets_id` after `flush_space()`, update `last_tickets_id` and reset `flush_state` (and decrement non-zero `commit_cycles` in metadata reclaim). `maybe_fail_all_tickets()` must call `btrfs_try_granting_tickets()` after each removal, stop if `tickets_id` changes, and return `true` so callers reset `flush_state`. [F1051, F1093, F1094]
- `do_async_reclaim_metadata_space()` advances `flush_state++` through `enum btrfs_flush_state` from `FLUSH_DELAYED_ITEMS_NR` to `final_state` (`RESET_ZONES` on zoned, `COMMIT_TRANS` otherwise), so `RESET_ZONES` must stay after `COMMIT_TRANS`. `btrfs_set_periodic_reclaim_ready(space_info, false)` must zero `reclaimable_bytes` under `space_info->lock`. In `do_reclaim_sweep()`, initialize `try_again = true` before `again:`, clear it when marking any block group on pass 1, and clear it before `goto again` when `urgent` is true. [F1052, F1092, F1096]
- Keep `btrfs_space_info::clamp` in `[1, 8]` (`max(1, clamp - 1)`, `min(clamp + 1, 8)`) for `thresh >>= space_info->clamp`. Always use `btrfs_space_info_update_*()` under `space_info->lock` so negative deltas in `DECLARE_SPACE_INFO_UPDATE()` (`bytes_may_use`, `bytes_pinned`, `bytes_zone_unusable`) `WARN_ON(1)` and clamp to 0 on underflow. [F1080, F1107]
- Before `send_subvol()`, `btrfs_ioctl_send()` must call `flush_delalloc_roots(sctx)` then `ensure_commit_roots_uptodate(sctx)`. Before `send_root` is appended to `sctx->clone_roots` and `sort_clone_roots = 1` is set, `out:` must call `btrfs_root_dec_send_in_progress()` on `send_root` and the first `clone_sources_to_rollback` entries separately; once `sort_clone_roots == 1`, iterate all `sctx->clone_roots_cnt` entries. [F1060, F1164]
- When `process_recorded_refs()` orphanizes `ow_inode`, set `wdm->orphanized = true` on its `waiting_dir_move`, remove `(ow_inode, ow_gen)` from `sctx->name_cache`, call `refresh_ref_path()` if it is a directory, and recompute `sctx->cur_inode_path` and `valid_path` if it is an ancestor. In `wait_for_parent_move()`, if an ancestor `ino` satisfies `is_waiting_for_move(sctx, ino)`, delay renaming `sctx->cur_ino` only if `is_ancestor(sctx->parent_root, sctx->cur_ino, sctx->cur_inode_gen, ino, ...)` returns 1. [F1055, F1101]
- `lookup_backref_cache()` must clear `sctx->backref_cache` when `fs_info->last_reloc_trans > sctx->backref_cache_last_reloc_trans`, and `store_backref_cache()` must record `last_reloc_trans` when `sctx->backref_cache.size == 1`. Initialize `sctx->dir_utimes_cache` with `max_size = 0` so `cache_dir_utimes()` never evicts; prune via `trim_dir_utimes_cache()` in `finish_inode_if_needed()` and on teardown in `btrfs_ioctl_send()`. [F1056, F1097]
- `name_cache_entry::name` is `__counted_by(name_len) __nonstring`; `__get_cur_name_and_parent()` must allocate `sizeof(*nce) + fs_path_len(dest)`, set `nce->name_len` before writing `nce->name`, and bound reads by `name_len`. `iterate_dir_item()` must validate `name_len` and `data_len` against `XATTR_NAME_MAX` and `BTRFS_MAX_XATTR_SIZE(root->fs_info)` (or `PATH_MAX`) before resizing `buf` and calling `read_extent_buffer()`. [F1075, F1123]
- `send_extent_data()` may call `send_encoded_inline_extent()` or `send_encoded_extent()` only when `sectorsize <= PAGE_SIZE`, `BTRFS_SEND_FLAG_COMPRESSED` is set, the extent is compressed, and its compressed size `<= len`. In `send_encoded_extent()`, data starts at `data_offset = PAGE_ALIGN(sctx->send_size)`, so `crc32c()` and `write_buf()` must skip `[sctx->send_size, data_offset)` while `hdr->len = sctx->send_size + disk_num_bytes - sizeof(*hdr)`. [F1070, F1102]
- In `clone_range()`, when cloning from the active inode in `send_root` (`clone_root->root == sctx->send_root && clone_root->ino == sctx->cur_ino`), break once `clone_root->offset >= sctx->cur_inode_next_write_offset` so the rest falls back to `send_extent_data()`. `tree_advance()` must update `*key` from `path->nodes[*level]` even when `tree_move_next_or_upnext()` returns `-1` at end-of-root (`slots[root_level] = nritems - 1`) for `restart_after_relocation()`. [F1103, F1105]
- Use `btrfs_set/clear_sb_rdonly()` to keep `SB_RDONLY` and `BTRFS_FS_STATE_RO` in sync. `btrfs_unfreeze()` must run `check_dev_super()` on all `fs_devices->devices` before clearing `BTRFS_FS_FROZEN`, and still return `0` after `btrfs_handle_fs_error()`. Copy new mount options in both `btrfs_ctx_to_info()` and `btrfs_info_to_ctx()`, and call `btrfs_emit_options()` and `btrfs_clear_oneshot_options()` on both initial mount and `btrfs_reconfigure()`. [F1061, F1062, F1063, F1133]
- In `btrfs_parse_param()` and `btrfs_parse_compress()`, `nodatacow` must clear `COMPRESS`/`FORCE_COMPRESS` and set `NODATACOW`/`NODATASUM`, while `datasum` or compression must clear `NODATACOW`/`NODATASUM`. Because `Opt_ssd_spread` sets both `SSD` and `SSD_SPREAD`, `btrfs_show_options()` must check `SSD_SPREAD` before `else if (btrfs_test_opt(info, SSD))`. [F1066, F1088]

## Synchronization

- `btrfs_folio_inc/dec_eb_refs()` must hold `folio->mapping->i_private_lock`, incrementing `eb_refs` before radix-tree insertion. All `btrfs_folio_state::bitmaps` accesses (and `nr_locked` updates in `btrfs_subpage_end_and_test_lock()` / `btrfs_folio_end_lock_bitmap()`) must use `spin_lock_irqsave(&bfs->lock)`. [F1010, F1136]
- Hold `space_info->lock` for `btrfs_space_info_update_*()`, `tickets`/`priority_tickets`/`reclaim_size` updates, and `btrfs_try_granting_tickets()`; acquire `space_info->lock` outside `btrfs_block_rsv::lock` and `btrfs_block_group::lock`. In `priority_reclaim_metadata/data_space()`, recheck `ticket->bytes == 0` under `space_info->lock` after `flush_space()`. [F1013, F1015, F1141]
- In `do_reclaim_sweep()`, hold `space_info->groups_sem` (read) and pin `bg` via `btrfs_get_block_group(bg)` before locking `bg->lock` and calling `btrfs_mark_bg_to_reclaim(bg)`. In `shrink_delalloc()`, call `btrfs_wait_ordered_roots()` only when `current->journal_info == NULL`. [F1018, F1139]
- In `btrfs_ioctl_send()`, hold `root->root_item_lock` on `send_root`, `parent_root`, and `clone_roots[i].root` to check `btrfs_root_readonly(root)`, `!btrfs_root_dead(root)`, and `!root->dedupe_in_progress`, and increment `send_in_progress`. `store_backref_cache()` must allocate with `GFP_NOFS`. `btrfs_compare_trees()` must clone level-0 leaves and root nodes via `btrfs_clone_extent_buffer()` / `replace_node_with_clone()` and drop `commit_root_sem` before calling `changed_cb()`. [F1008, F1024, F1028]
- In `btrfs_get_tree_super()`, drop `uuid_mutex` before `sget_fc()` while pinning `fs_devices` via `btrfs_fs_devices_inc/dec_holding()`. Enclose `fs_devices->latest_dev` / `btrfs_dev_name()` in `btrfs_show_devname()` and lockless `fs_devices->devices` iteration in `btrfs_calc_avail_data_space()` in `rcu_read_lock()` / `list_for_each_entry_rcu()`. [F1146, F1149]
- In `btrfs_remount_ro()`, before `btrfs_commit_super()`, cancel async reclaim works, cycle `uuid_tree_rescan_sem`, set `BTRFS_FS_STATE_RO`/`SB_RDONLY`, wait on `BTRFS_FS_CLEANER_RUNNING`, run delayed iputs, and pause/wait on dev-replace, scrub, balance, and qgroup rescan. In `btrfs_sync_fs()`, if `btrfs_attach_transaction_barrier()` returns `-ENOENT` with `BTRFS_FS_NEED_TRANS_COMMIT` set, probe `sb_start_write_trylock(sb)` (then `sb_end_write(sb)`) and return 0 if frozen. [F1021, F1147]

## Object Lifetimes

- In `btrfs_get_tree_super()`, reset `fs_info->fs_devices = NULL` under `uuid_mutex` whenever `btrfs_open_devices()` does not open `fs_devices` (`sget_fc()` failure, reused `sb->s_root`, or `btrfs_open_devices()` failure) before `btrfs_free_fs_info()`. `btrfs_dup_fs_context()` increments `ctx->refs` and moves `src_fc->source` to `fc->source` (`src_fc->source = NULL`); `btrfs_get_tree_subvol()` sets `ctx->subvol_name = NULL` after `mount_subvol()`. In `create_space_info_sub_group()`, reset `parent->sub_group[index] = NULL` if `btrfs_sysfs_add_space_info_type()` fails. [F995, F1002, F1065]
- `fs_path` starts with `p->buf == p->inline_buf`; `fs_path_ensure_buf()` must `kmalloc()` + `memcpy()` (not `krealloc()`) when `p->buf == p->inline_buf`, and `fs_path_free()` / `btrfs_ioctl_send()` must `kfree(p->buf)` only when `p->buf != p->inline_buf`. In `recorded_ref`, `ref->name` aliases `ref->full_path->start` via `set_ref_path()`, so `refresh_ref_path()` must `kmemdup()` `ref->name` before `fs_path_reset()`, and `update_ref_path()` must build a new `fs_path` before freeing `ref->full_path` and calling `set_ref_path()`. [F1006, F1120]
- Close `sctx->cur_inode` via `close_current_inode(sctx)` in `changed_inode()` and `btrfs_ioctl_send()` teardown (evicting pages if `clean_page_cache`, calling `iput()`, setting `cur_inode = NULL`). In `tail_append_pending_moves()` and `btrfs_ioctl_send()` cleanup, drain/free all entries on `pm->list` before erasing and freeing the rbtree node `pm` in `sctx->pending_dir_moves`. [F1007, F1099]

## API Contracts

- `btrfs_alloc_folio_state()` uses `GFP_NOFS` and returns `ERR_PTR(-ENOMEM)`, so callers must check `IS_ERR()`. Non-clamping `btrfs_subpage_*()` / `btrfs_folio_*()` require `sectorsize`-aligned `[start, start + len)` within the folio; otherwise use `btrfs_folio_clamp_*()`. When `btrfs_subpage_clear_and_test_dirty()` returns `true`, callers must call `folio_clear_dirty_for_io(folio)`. `GET_SUBPAGE_BITMAP()` requires `blocks_per_folio <= BITS_PER_LONG`, and `SUBPAGE_DUMP_BITMAP()` / `btrfs_subpage_dump_bitmap()` must pass `blocks_per_folio` as the `%*pbl` precision with an `unsigned long *`. [F1033, F1035, F1036, F1119, F1137]
- Guard ticket creation and `handle_reserve_ticket()` with `can_ticket(flush)` (asserts on `NO_FLUSH`/`FLUSH_EMERGENCY`). When `current->journal_info != NULL`, `__reserve_bytes()` and `btrfs_reserve_data_bytes()` must not use `FLUSH_ALL*`, `FLUSH_EVICT`, or `FLUSH_DATA`, and `flush_space()` must not run `COMMIT_TRANS`. [F1095, F1138]
- `get_path_for_command()` returns an `ERR_PTR` (never `NULL`), `&sctx->cur_inode_path`, or a heap `fs_path *`; check `IS_ERR()` and free via `free_path_for_command()`. `put_data_header()` sets `sctx->put_data = true`, causing subsequent `tlv_put()` / `put_data_header()` calls to fail with `-EINVAL` until `send_cmd()` or `send_encoded_extent()` resets `send_size = 0` and `put_data = false`. [F1039, F1040]

## Error Handling

- In `btrfs_reconfigure()`, failures after `btrfs_ctx_to_info()` / `btrfs_remount_begin()` must jump to `restore:` to revert `old_ctx`, call `btrfs_remount_cleanup()`, and clear `BTRFS_FS_STATE_REMOUNTING`. `btrfs_get_subvol_name_from_objectid()` returns an `ERR_PTR` (never `NULL`) and must set `fs_root = NULL` if `btrfs_get_fs_root()` fails before `goto err`. [F999, F1030]
- After `btrfs_for_each_slot(..., iter_ret)` in `send.c`, check `if (iter_ret < 0)` and propagate it. In `record_ref_in_tree()`, `out:` must call `fs_path_free(path)` only if `(!ref || !ref->full_path)`. In `btrfs_ioctl_send()`, guard `sctx->parent_root` cleanup at `out:` with `!IS_ERR_OR_NULL(sctx->parent_root)`. [F1041, F1042, F1043]

## External Contracts

- `btrfs_ioctl_send()` must reject `arg->flags & ~BTRFS_SEND_FLAG_MASK` with `-EOPNOTSUPP`, `proto > BTRFS_SEND_STREAM_VERSION` with `-EPROTO`, and `BTRFS_SEND_FLAG_COMPRESSED` when `proto < 2` with `-EINVAL`. `send_cmd()` and `send_encoded_extent()` must zero `hdr->crc` before `crc32c(0, ...)` and exclude `sizeof(*hdr)` from `hdr->len`. In `clone_range()`, if a clone ends at unaligned `clone_src_i_size` before `sctx->cur_inode_size`, clone only the `SZ_64K`-aligned prefix and `send_extent_data()` the tail. [F1068, F1072, F1076]
- `btrfs_parse_compress()` accepts `lzo:<level>` (`may_have_level = true`), but `btrfs_show_options()` omits `:%d` for `BTRFS_COMPRESS_LZO`, and `subvol` / devname output must use `seq_show_option()` / `seq_escape()`. In `btrfs_parse_param()`, warn if `commit_interval > BTRFS_WARNING_COMMIT_INTERVAL` and map `0` to `BTRFS_DEFAULT_COMMIT_INTERVAL`, reject `thread_pool=0` with `-EINVAL`, and map `subvolid=0` to `BTRFS_FS_TREE_OBJECTID`. `btrfs_control_ioctl()` must check `capable(CAP_SYS_ADMIN)` and `btrfs_check_ioctl_vol_args_path(vol)` first, and wrap `btrfs_scan_one_device(..., false)` with `PTR_ERR_OR_ZERO()`. [F1081, F1082, F1083, F1162]

## Known Pitfalls

- `btrfs_subpage_clamp_range()` must set `*len = 0` if `folio_pos(folio) >= orig_start + orig_len` before subtracting `*start`. `calc_pct_ratio()` must use `check_mul_overflow(100, x, &x)` and clamp `y = 1` if `y >>= 10` hits 0. `calc_reclaim_items_nr()` and `btrfs_preempt_reclaim_metadata_space()` must clamp 0 division/shift results to 1 item. Clamp `u64 temp` in `shrink_delalloc()` and `sc->nr_to_scan` in `btrfs_free_cached_objects()` to `LONG_MAX`. [F1108, F1109, F1110, F1112]
- `fs_path_ensure_buf()` invalidates `p->start`/`p->end` and must `memmove()` reversed paths to the new buffer tail. After dropping `commit_root_sem` in `btrfs_compare_trees()` or `full_send_tree()`, if `fs_info->last_reloc_trans > sctx->last_reloc_trans`, re-search paths from commit roots (`restart_after_relocation()`). [F1053, F1057]
- Bound `arg->clone_sources_count <= SZ_8M / sizeof(struct clone_root)` before setting `sctx->clone_roots_cnt` and allocating `clone_sources_count + 1`. In `send_encoded_extent()`, check `data_offset > sctx->send_max_size` before subtracting `data_offset`, and index `sctx->send_buf_pages` by `data_offset >> PAGE_SHIFT`. In `iterate_dir_item()`, check `is_vmalloc_addr(buf)` and `vfree()` before `kvmalloc()` instead of `krealloc()`. In `send_extent_data()` and `close_current_inode()`, pass `PAGE_SIZE`-aligned ranges starting at `sctx->page_cache_clear_start` to `truncate_inode_pages_range()`. [F1114, F1115, F1125, F1126, F1154]
- `btrfs_parse_compress()` must only clear `FORCE_COMPRESS` when `opt` is neither `Opt_compress_force` nor `Opt_compress_force_type` (or for `no`/`none`). Set `fc->sb_flags_mask |= SB_POSIXACL` for `Opt_acl` in `btrfs_parse_param()` only when `fc->purpose != FS_CONTEXT_FOR_RECONFIGURE`. `set_device_specific_options()` must not set `DISCARD_ASYNC` when `btrfs_is_zoned(fs_info)` or when any discard flag is already set. `btrfs_get_subvol_name_from_objectid()` must check `ptr < name` after `ptr -= len + 1` and use `memmove(name, ptr, name + PATH_MAX - ptr)`. [F1089, F1128, F1132, F1157]
