# COMMON INTERNET FILE SYSTEM CLIENT (CIFS and SMB3) — fs/smb/client (part 2)

This component implements network connection, session, and tree-connection lifecycle management, `cifsd` socket demultiplexing, SMB1 PDU construction and transport, SMB3 LZ77 compression, and DFS referral walking and caching.

## Architecture & Data Flow
- `ses->chans[0]` is primary and `1..ses->chan_count - 1` are secondary; secondary loops in `cifs_signal_cifsd_for_reconnect()` and `__cifs_put_smb_ses()` must start at `1`. In `cifs_mark_tcp_ses_conns_for_reconnect()`, iterate `&pserver->smb_ses_list` (`pserver = server->primary_server`), but pass `server` to `cifs_ses_get_chan_index()` and `cifs_chan_set_need_reconnect()`. [F104, F130]
- When `__cifs_reconnect()` has `mark_smb_session` true, call `cifs_signal_cifsd_for_reconnect(server, mark_smb_session)` before `cifs_mark_tcp_ses_conns_for_reconnect()` so all channels get `CifsNeedReconnect`. `cifs_mark_tcp_ses_conns_for_reconnect()` sets `ses->ses_status = SES_NEED_RECON` and marks `tcon_list`/`tcon_ipc` (`need_reconnect = true`, `status = TID_NEED_RECON`, canceling `query_interfaces`) only when `mark_smb_session` or `CIFS_ALL_CHANS_NEED_RECONNECT(ses)` is true. [F69, F70]
- In `cifs_setup_session()`, when binding (`!CIFS_ALL_CHANS_NEED_RECONNECT(ses)`), do not modify/free `ses_status`, `iface_last_update`, `capabilities`, or `auth_key`, and update `ses->ip_addr` only if `server == pserver`. [F75]
- In `cifs_negotiate_protocol()`, setting `tcpStatus = CifsInNegotiate` under `srv_lock` records `server->neg_start = jiffies` without touching `lstrp`, and `server_unresponsive()` checks the 20s timeout against `neg_start`. On `-EAGAIN` from `negotiate()`, `in_retry` bounds retry to once, mapping a second `-EAGAIN` to `-EHOSTDOWN`. [F68, F123]
- In `cifs_get_smb_ses()`, guard `retry_old_session:`/`retry_new_session:` on `-EACCES`/`-EKEYEXPIRED`/`-EKEYREVOKED` with `(!retries && ses->password2)`, incrementing `retries` and swapping `password`/`password2`. `match_session()` requires `uid_eq(ctx->cred_uid, ses->cred_uid)` for `Kerberos`/`IAKerb`; `match_server()` requires `net_eq(cifs_net_ns(server), current->nsproxy->net_ns)`. [F124, F178, F182]
- `cifs_abort_connection()` must reset `maxBuf = 0`, `max_read = 0`, `sequence_number = 0`, `session_estab = false`, free/zero `session_key`, set `lstrp = jiffies`, and drain `pending_mid_q` with `mid->deleted_from_q = true`. [F71]
- In `cifs_demultiplex_thread()` and `standard_receive3()`, `server->pdu_size` must be in `[MID_HEADER_SIZE(server), CIFSMaxBufSize + MAX_HEADER_SIZE(server) - HEADER_PREAMBLE_SIZE(server)]`. If `pdu_length > MAX_CIFS_SMALL_BUFFER_SIZE - 4`, `standard_receive3()` sets `large_buf = true`, copies `total_read` bytes to `bigbuf`, and sets `buf = server->bigbuf`. On `next_pdu:`, `cifs_demultiplex_thread()` calls `allocate_buffers()`, subtracts `pdu_size` from `pdu_length`, resets `total_read = 0`, `large_buf = false`, `buf = smallbuf`, and defers `pending_reconnect` until frame end. [F73, F94, F122]
- In `SendReceive()` and `SendReceiveBlockingLock()`, `be32_to_cpu(in_buf->smb_buf_length)` must not exceed `CIFSMaxBufSize + MAX_CIFS_HDR_SIZE - 4`, `out_buf` copy is `get_rfc1002_length(midQ->resp_buf) + 4` bytes, and failed `smb_send()` after `cifs_sign_smb()` must do `server->sequence_number -= 2` under `cifs_server_lock(server)`. [F76, F95]
- In `dfs_mount_share()`, once `dfs_get_referral()` confirms DFS and `!ctx->dfs_conn`, set `ctx->dfs_conn = true`, call `cifs_mount_put_conns(mnt_ctx)`, and re-run `get_session(mnt_ctx, NULL)`. On DFS mount/remount, call `cifs_autodisable_serverino(cifs_sb)` and set `CIFS_MOUNT_USE_PREFIX_PATH`. Both `CONFIG_CIFS_DFS_UPCALL` branches of `cifs_tree_connect()` and `cifs_mount()` must update `tcon->status`, `need_reconnect`, `mount_setup_tlink()`, and `cifs_mount_put_conns()` in lockstep. [F83, F84, F90]
- `struct dfs_ref_walk` uses inclusive `ref_walk_end(rw)`; `ref_walk_advance()` returns `-ELOOP` if `ref_walk_cur(rw) + 1 > ref_walk_end(rw)` and calls `__ref_walk_free(ref)` on the next slot before advancing, while `ref_walk_descend()` stops when `--ref_walk_cur(rw) < ref_walk_start(rw)`. When `__dfs_referral_walk()` advances into an interlink (`server_type == DFS_TYPE_LINK && DFS_INTERLINK(flags)`, requiring `DFSREF_REFERRAL_SERVER && !DFSREF_STORAGE_SERVER`), call `ref_walk_mark_end(rw)` before `goto again`. [F86, F103, F110, F125]
- In `lookup_cache_entry()`, prefix lookups on >2 components must strip trailing separators and back `e` up to the preceding separator each iteration. In `cifs_are_all_path_components_accessible()`, restore `*s = tmp` immediately after `is_path_accessible()`, and advance `s` past the component before `if (skip) { skip = 0; continue; }`. [F88, F127, F129]
- In `reset_cifs_unix_caps()` on reconnect (`ctx == NULL`), save `tcon->fsUnixInfo.Capability` before `CIFSSMBQFSUnixInfo()` and mask off `CIFS_UNIX_POSIX_ACL_CAP` and `CIFS_UNIX_POSIX_PATHNAMES_CAP` if previously unset. In `CIFSTCon()`, clear `tcon->need_reconnect = false` before `reset_cifs_unix_caps()`. [F77, F78]
- `cifs_query_reparse_point()` requires `io_rsp->SetupCount == 1` and `data_count == le16_to_cpu(io_rsp->ReturnedDataLen)`. `CIFSSMBQAllEAs()` requires `ea_response_data + list_len <= end_of_smb` and signed `int list_len` aborting with `-EIO` if `< 0`. `cifs_to_posix_acl()` must verify `size_of_data_area` covers `access_entry_count` (plus `default_entry_count` at `&ace_array[access_entry_count]` for `ACL_TYPE_DEFAULT`). `access_flags_to_smbopen_mode()` must check `(with_write_flags && with_read_flags)` first. [F91, F98, F99, F111]
- In `lz77_compress()`, stop the main loop at `srcp + LZ77_STEP_SIZE >= end` and abort with `-EMSGSIZE` at `dstp - dst >= slen - (slen >> 3)`. Clamp trailing literals to `c = umin(end - srcp, 32 - flag_count)` and flush/reset `flag_count = 0` at 32. `has_low_entropy()` requires `slen > 0` and descending-sorted `bkt` guarded by `bkt[i].count > 0`. [F106, F135, F137]

## Synchronization
- Lock order: `ses->session_mutex` before `srv_lock`, `ses_lock`, or `chan_lock`; spinlocks nest `cifs_tcp_ses_lock` -> `srv_lock` (`match_server`) -> `ses_lock` -> `chan_lock` (`match_session` needs both) -> `tc_lock` (`match_tcon`). Hold `cifs_tcp_ses_lock` for all mutations of `srv_count`, `ses_count`, `tc_count`, `cifs_tcp_ses_list`, `smb_ses_list`, and `tcon_list`. [F32, F33, F163]
- `cifs_signal_cifsd_for_reconnect()` must never take `srv_lock` under `ses_lock`/`chan_lock`; pin secondary channels (`nserver->srv_count++`) onto a local list under `cifs_tcp_ses_lock` and `chan_lock`, then update `tcpStatus` under `srv_lock` outside session locks. [F22]
- Serialize all `mid_q_entry::callback` accesses under `mid->mid_lock` (`mid_execute_callback()`). When draining `pending_mid_q`, move entries to a local list under `mid_queue_lock` with `kref_get(&mid->refcount)` and `mid->deleted_from_q = true`, then run `mid_execute_callback()` and `release_mid()` unlocked. [F21, F119]
- Hold `cifs_server_lock(server)` across `allocate_mid()`, `cifs_sign_smb()`, `smb_send()`, and `sequence_number` rollback in `SendReceive()`/`SendReceiveBlockingLock()`, and in `reconn_set_ipaddr_from_hostname()` (which must drop `srv_lock` across `dns_resolve_name()`). [F30, F166]
- In `cifs_get_tcp_session()`, initialize locks, works, `srv_count`, `tsk`, and `tcpStatus = CifsNeedNegotiate` before linking into `cifs_tcp_ses_list` and queuing `echo`. Coordinate `cifsd` exit via `xchg(&server->tsk, NULL)` (`cifsd` sleeps until `signal_pending(current)` if `NULL`). `cifs_put_tcp_session()` drops `cifs_tcp_ses_lock` before cancelling work and passes `from_reconnect != 0` in `smb2_reconnect_server` to avoid `cancel_delayed_work_sync(&server->reconnect)`. [F26, F28, F170]
- In `cifs_reconnect_tcon()`, after locking `session_mutex`, recheck `tcpStatus` under `srv_lock` and `cifs_chan_needs_reconnect()`/`ses_status` under `ses_lock` + `chan_lock`. Post-RPC updates in `cifs_negotiate_protocol()`, `cifs_setup_session()`, and `cifs_tree_connect()` must re-lock and verify status is still `CifsInNegotiate`, `SES_IN_SETUP`, or `TID_IN_TCON`. [F36, F37]
- Populate `tcon->origin_fullpath` and `tcon->dfs_ses_list` under `tc_lock` before queuing `tcon->dfs_cache_work`. In `dfs_cache.c`, drop `htable_rw_lock` across `get_dfs_referral()` and recheck `lookup_cache_entry()`/`cache_entry_expired()` under `down_write(&htable_rw_lock)`. `cache_refresh_path()` returns valid `ce` with `htable_rw_lock` read-held and drops it on `IS_ERR(ce)`. Access `ce->tgthint` with `READ_ONCE()`/`WRITE_ONCE()`. [F15, F25, F34, F35]
- In `cifs_sb_tlink()`, re-run `tlink_rb_search()` under `tlink_tree_lock` before `tlink_rb_insert()`, and clear/wake `TCON_LINK_PENDING` after `cifs_construct_tcon()`. In `cifs_umount()`, call `cancel_delayed_work_sync(&cifs_sb->prune_tlinks)` before unlinking `tcon_sb_link`, draining `tlink_tree`, or `call_rcu()`. [F39, F40]
- Do not touch `wdata` in `cifs_async_writev()` after `cifs_call_async()` returns `0`. In `cifs_set_cifscreds()`, hold `down_read(&key->sem)` across `user_key_payload_locked(key)` and payload reads before `key_put(key)`. Keep `memalloc_noreclaim_save()` active in `cifs_demultiplex_thread()`. [F42, F161, F183]

## Object Lifetimes
- `cifs_get_smb_ses()` and `cifs_get_tcon()` require caller-held `srv_count`/`ses_count` refs: each puts the ref on match, transfers it into the new struct, or leaves it with the caller on `ERR_PTR`. `cifs_mount_put_conns()` releases only the highest non-NULL pointer (`tcon`, else `ses`, else `server`) and nulls all three before `free_xid()`. [F1, F2, F3]
- In `cifs_get_tcp_session()`, release `get_net()` and `primary_server` refs on error before `cifsd` starts, and otherwise in `clean_demultiplex_info()` and `cifs_put_tcp_session()`. Free `hostname`, `leaf_fullpath`, and `server` only in `clean_demultiplex_info()`. Every `sock_release(server->ssocket)` must set `server->ssocket = NULL`, and `generic_ip_connect()` must call `sk_net_refcnt_upgrade()` after `sock_create_kern()`. [F4, F5, F23, F175]
- `cifs_put_tcon()` returns early if `tcon->ipc` (freed in `__cifs_put_smb_ses()`), and must `cancel_delayed_work_sync()` `query_interfaces` and `dfs_cache_work` before draining `dfs_ses_list` or freeing `tcon`. `ref_walk_set_tcon()` moves `ref->ses` to `tcon->dfs_ses_list` and nulls `ref->ses`. `dfs.c:get_session()` must null borrowed `ctx->leaf_fullpath` and `ctx->dns_dom`. [F7, F13, F24, F152]
- To remove a `tcon_link` in `cifs_prune_tlinks()`/`cifs_umount()`, advance the cursor, call `cifs_get_tlink()`, clear `TCON_LINK_IN_TREE`, and `rb_erase()` under `tlink_tree_lock`, then drop the lock before `cifs_put_tlink()`. Check `!IS_ERR(tlink_tcon(tlink))` before using/putting `tl_tcon`. [F53, F120]
- Clean up `alloc_mid()` (`cifs_setup_async_request`) with `release_mid()` and `allocate_mid()` (`cifs_setup_request`) with `delete_mid()`. In `SendReceive()`/`SendReceiveBlockingLock()`, if `wait_for_response()` fails and `midQ->callback` is non-NULL under `mid_lock`, set `midQ->callback = release_mid` and skip `delete_mid(midQ)`. In `handle_mid()`, `!mid->multiRsp` transfers buffer ownership to `mid->resp_buf` by nulling `server->bigbuf`/`smallbuf`; never touch `bufs[i]` after `mid_execute_callback()`. [F9, F11, F12, F149]
- `alloc_cache_entry()` steals `refs[0].path_name` (`= NULL`), so run `cache_entry_hash()` first. In `purge_cache()`, set `oldest = ce` only in the `else if` branch after `if (ce->numtgts == 1) flush_cache_ent(ce)`. [F14, F121]
- After `CIFS_open()`, `cifs_query_reparse_point()` must call `CIFSSMBClose()` on all paths and free `io_req` only on error; `cifs_create_reparse_inode()` must call `CIFSSMBClose()` and `CIFSSMBDelFile()` on error while preserving `rc`. `smb_compress()` and `collect_sample()` must copy `rq->rq_iter` by value. [F18, F19, F20, F58]

## API Contracts
- Only `cifsd` may call `cifs_reconnect()` or `cifs_mark_tcp_ses_conns_for_reconnect()`; others call `cifs_signal_cifsd_for_reconnect()`. When `mid != NULL`, `cifs_handle_standard()` must return `0` and pass `check_message()` errors to `handle_mid()`. [F29, F47]
- `generic_ip_connect()` sets `sk_allocation = GFP_NOFS`, `sk_use_task_frag = false`, and reclassifies socket lockdep classes. Multiply `ctx->echo_interval` by `HZ` for `server->echo_interval`. [F67, F177]
- `SendReceive2()` splits caller `iov[0]`'s 4-byte RFC1001 length into `new_iov[0]` and `new_iov[1]` (`+ 4`), as required by `cifs_setup_request()`/`cifs_setup_async_request()`. SMB1 `ParameterOffset`/`DataOffset` are relative to `&pSMB->hdr.Protocol` (`offsetof() - 4`, `(char *)pSMB + offset + 4`). [F63, F96, F147]
- `CIFSSMBQFSUnixInfo()`/`CIFSSMBSetFSUnixInfo()` must use `smb_init_no_reconnect()`. `CIFSSMBRead()` copies and frees `rsp_iov` if `*buf != NULL`, or transfers ownership if `*buf == NULL`. `CIFSSMBGetCIFSACL()` requires full `OWNER_SECINFO | GROUP_SECINFO | DACL_SECINFO` (`SACL_SECINFO`) flags. [F43, F55, F65]
- SMB1 `cifs_readv_callback()` and `cifs_writev_callback()` must zero `credits.value`, call `add_credits()`, set `NETFS_SREQ_NEED_RETRY` with `-EAGAIN`, set `NETFS_SREQ_MADE_PROGRESS` on positive transfers, and (for reads) set `NETFS_SREQ_HIT_EOF` (`result = 0`) at EOF/`-ENODATA` before terminating the subreq. [F89, F179, F180, F181]
- `decode_negTokenInit()` returns `1` on success (`0` on error). `target_share_matches_server()` and `match_target_ip()` return `0` and write boolean results to out-params; `extract_unc_hostname()`'s `dfs_host` is non-NUL-terminated (`dfs_host_len`). `cifs_get_dfs_tcon_super()` returns `ERR_PTR`. Pass `path + 1` to `dfs_cache_*` and `dfs_parse_target_referral()`. [F44, F48, F51, F64, F154]
- `should_compress()`/`smb_compress()` require `rq_iov[0]` to be `smb2_hdr` (`smb2_write_req` for writes), `send_fn` must consume `comp_rq` synchronously, and `compress.c` must use `iov_iter` helpers (never `iter->xarray`). Initialize `dlen = slen` (`>= 8`) before `lz77_compress()` and fall back to `send_fn(server, 1, rq)` on `-EMSGSIZE || dlen >= slen`. `lz77_write_match()` requires `1 <= dist < SZ_1K` and `len >= 4`. [F49, F52, F136, F150, F151]

## Error Handling
- `cifs_reconnect_tcon()` returns `-EAGAIN` for handle-based SMB1 ops; callers must not loop on `-EAGAIN`, and `CIFSSMBClose()`, `CIFSFindClose()`, `CIFSSMBTDis()`, and `CIFSSMBLogoff()` map `-EAGAIN` to `0`. In `is_smb_response()`, map `cifs_reconnect_once()`'s `0` to `-EAGAIN` and `-EAGAIN` to `-EHOSTDOWN`. [F45, F46]
- Reset `IS_ERR` pointers to `NULL` before storing into `mnt_ctx` or `*rw` (`dfs_referral_walk`). `SendReceive2()` must set `*resp_buf_type = CIFS_NO_BUFFER` on early error. `cifs_fill_unix_set_info()` must set unchanged `EndOfFile`, `NumOfBytes`, `Uid`, and `Gid` to `NO_CHANGE_64` (never `0`). [F56, F57, F59, F61]

## External Contracts
- Without `CAP_LARGE_FILES`, SMB1 read/write must reject `(offset >> 32) > 0` with `-EIO`. In SMB1 write responses, if `(CountHigh << 16) + Count` exceeds requested bytes, mask with `&= 0xFFFF`. `posix_acl_to_cifs()` sets unused entry count to `0xFFFF`. `CIFSSMBSetEA()` places `ea_value` at `name + name_len + 1`. `dfscache_proc_write()` uses `get_user(c, buffer)` and requires `c == '0'`. [F100, F107, F132, F133, F144]

## Known Pitfalls
- Initialize `int rc = 0` on all paths reaching `free_xid()`, or use `_free_xid()`. Copy `psrch_inf->presume_name` and validate the new response before freeing `ntwrk_buf_start` in `CIFSFindNext()`. In `update_cache_entry_locked()`, `kstrdup(ce->tgthint->name)` before `free_tgts(ce)` and reset `ce->numtgts = 0`. Call `dfs_ses_refpath(ses)` before `ses = CIFS_DFS_ROOT_SES(ses)`. [F62, F80, F81, F131]
- Check `((global_secflags & CIFSSEC_MUST_SIGN) == CIFSSEC_MUST_SIGN)` in `cifs_enable_signing()`. Cast `le16_to_cpu(pSMBr->ServerTimeZone)` to `(__s16)` in `CIFSSMBNegotiate()`. Use `time_before()`/`time_after()` for `jiffies` in `connect.c`. Reset `length = 0` before `continue` on negative recv in `cifs_readv_from_socket()`. Set `l1 = 1` before `continue` when `l1 < 0 && l2 < 0` in `dfs_path_equal()`. Use `kzalloc()` for `ppath` in `dfs_cache_get_tgt_share()`. Pass `s - line + 1` to `strscpy(root_dev, line, ...)` in `cifs_root_setup()`. [F109, F126, F128, F134, F138, F157, F158]
