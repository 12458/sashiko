# NETWORKING [IPv4/IPv6] — net/ipv6 (part 6)

This unit implements TCP over IPv6 (including IPv4-mapped IPv6 socket transitions, TCP-MD5/TCP-AO authentication, SYN cookies, ICMPv6 error handling, and `/proc/net/tcp6` reporting), TCPv6 and UDPv6 GSO/GRO offload callbacks, IP-in-IPv6/MPLS-in-IPv6 tunnel protocol demultiplexing, and UDP-Lite over IPv6.

## Architecture & Data Flow

- In `net/ipv6/tcp_ipv6.c`, `tcp_inet6_sk(sk)`, `tcp_sk(sk)`, and `inet_sk(sk)` (including `inet6_test_bit()`) must only be called after ruling out `TCP_TIME_WAIT` and `TCP_NEW_SYN_RECV` minisocks (or verifying `sk_fullsock(sk)`), because `tcp6_timewait_sock` and `tcp6_request_sock` do not embed `struct tcp_sock` or `struct ipv6_pinfo`. [F1133]
- In `tcp_v6_syn_recv_sock()`, after cloning `newsk` and copying the listener's `struct ipv6_pinfo` via `memcpy(newnp, np, sizeof(struct ipv6_pinfo))`, `inet_sk(newsk)->pinet6` must be repointed to `tcp_inet6_sk(newsk)` and `newnp`'s pointer fields (`ipv6_mc_list`, `ipv6_ac_list`, `ipv6_fl_list`, `pktoptions`, `opt`) must be nulled before attaching child options in both v4-mapped and native IPv6 branches. [F1094]
- In `tcp_v6_init_req()`, `ireq->ir_rmt_addr` and `ireq->ir_loc_addr` must be set to `LOOPBACK4_IPV6` alongside `ireq->ir_v6_rmt_addr` and `ireq->ir_v6_loc_addr` because `inet_csk_clone_lock()` copies them into the child socket's IPv4 address fields. [F1100]
- In `tcp_v6_connect()`, if `tp->rx_opt.ts_recent_stamp` is set and the new destination `usin->sin6_addr` differs from `sk->sk_v6_daddr`, `tp->rx_opt.ts_recent`, `tp->rx_opt.ts_recent_stamp`, and `tp->write_seq` must all be reset to 0 before updating `sk->sk_v6_daddr`. [F1099]
- When `tcp_v6_connect()` transitions an `AF_INET6` socket to `IPV6_ADDR_MAPPED`, it must update `icsk->icsk_af_ops` (via `WRITE_ONCE` between `&ipv6_specific` and `&ipv6_mapped` because `tcp_setsockopt`/`tcp_getsockopt` read it locklessly via `READ_ONCE`), `sk->sk_backlog_rcv`, `tp->af_specific`, and `mptcpv6_handle_mapped(sk, true)` before calling `tcp_v4_connect()`, and roll back all of them plus `icsk->icsk_ext_hdr_len` on failure. [F1076, F1157]
- When `inet6_sk_rx_dst_set()` caches `sk->sk_rx_dst`, it must acquire a reference on `skb_dst(skb)` via `dst_hold_safe(dst)` before `rcu_assign_pointer` and record `sk->sk_rx_dst_ifindex` and `sk->sk_rx_dst_cookie`; readers (`tcp_v6_do_rcv()` and `tcp_v6_early_demux()`) must verify both `sk->sk_rx_dst_ifindex == skb->skb_iif` and the route cookie before using the cached `dst_entry`. [F1098, F1148]
- In `tcp_v6_err()`, the `TCP_SYN_SENT` and `TCP_SYN_RECV` switch cases must `break` out of the switch instead of calling `ipv6_icmp_error()` and `tcp_done_with_error()` when `fastopen && !fastopen->sk`, because an unaccepted Fast Open child socket is only treated as connected once `fastopen->sk` is non-NULL. [F1118]
- In `tcp_v6_send_response()`, every TCP option length added to `tot_len` before computing `t1->doff = tot_len / 4` must be a multiple of 4 bytes (using aligned lengths such as `TCPOLEN_TSTAMP_ALIGNED`, `TCPOLEN_MD5SIG_ALIGNED`, and `tcp_ao_len_aligned()`). [F1127]
- In `tcp_v6_md5_hash_headers()`, `hp->scratch` is formatted as a contiguous `struct tcp6_pseudohdr` followed at `bp + 1` by the 20-byte base `struct tcphdr` (with `check` zeroed and excluding TCP options), while `tcp_v6_md5_hash_skb()` hashes the remaining bytes via `tcp_sigpool_hash_skb_data()` starting at offset `th->doff << 2`. [F1109]
- In `tcp6_gso_segment()`, an `SKB_GSO_FRAGLIST` packet must only take `__tcp6_gso_segment_list()` when `skb_pagelen(skb) - th->doff * 4 == skb_shinfo(skb)->gso_size`, and otherwise must set `skb->ip_summed = CHECKSUM_NONE` and fall through to recompute the `CHECKSUM_PARTIAL` pseudo-header before calling `tcp_gso_segment()`. [F1123]
- In `__tcpv6_gso_segment_list_csum()`, the first segment `segs` holds the reference `ipv6hdr` (`iph`) and `tcphdr` (`th`); if `segs->next` differs in `saddr`, `daddr`, or ports, the `while ((seg = seg->next))` loop must iterate from `segs->next` and update each segment's `iph2` and `th2` against `iph` and `th` from `segs`. In `__tcpv6_gso_segment_csum()`, `inet_proto_csum_replace16()` and `inet_proto_csum_replace2()` must update `th->check` using old values before `*oldip` and `*oldport` are overwritten. [F1103, F1122]
- In `udp6_ufo_fragment()`, `skb->encapsulation && skb_shinfo(skb)->gso_type & (SKB_GSO_UDP_TUNNEL|SKB_GSO_UDP_TUNNEL_CSUM)` must be checked (calling `skb_udp_tunnel_segment()`) before `SKB_GSO_UDP | SKB_GSO_UDP_L4` (`__udp_gso_segment()`). Before shifting unfragmentable headers left by `frag_hdr_sz` with `memmove`, headroom must be ensured via `gso_pskb_expand_head()`, `*prevhdr` sampled into `nexthdr` before writing `NEXTHDR_FRAGMENT`, and `SKB_GSO_CB(skb)->mac_offset`, `skb->mac_header`, and `skb->network_header` decremented by `frag_hdr_sz`. [F1101, F1124]
- In `udp6_gro_complete()`, the fraglist early return must be guarded by `NAPI_GRO_CB(skb)->is_flist && !NAPI_GRO_CB(skb)->encap_mark` so packets with an unprocessed outer UDP tunnel (`encap_mark != 0`) fall through to `udp_gro_complete()`. [F1125]
- `xfrm6_tunnel_register()` maintains `tunnel6_handlers`, `tunnel46_handlers`, and `tunnelmpls6_handlers` in strictly ascending `priority` order under `tunnel6_mutex` by advancing `pprev = &t->next` until `t->priority > priority` and rejecting `t->priority == priority` with `-EEXIST`. [F1120]

## Synchronization

- In `tcp_v6_err()`, while holding `bh_lock_sock(sk)`, `dst->ops->redirect`, `tcp_v6_mtu_reduced()`, `tcp_done_with_error()`, and `sk_error_report()` may only be called when `!sock_owned_by_user(sk)`. When `ICMPV6_PKT_TOOBIG` defers PMTU reduction because `sock_owned_by_user(sk)` is true, `sock_hold(sk)` must be called only when `!test_and_set_bit(TCP_MTU_REDUCED_DEFERRED, &sk->sk_tsq_flags)` succeeds. [F1055, F1073]
- In `tcp_v6_send_reset()`, `rcu_read_lock()` must be held across TCP-MD5 and TCP-AO key lookups (`tcp_v6_md5_do_lookup()`, `tcp_ao_prepare_reset()`) and until `tcp_v6_send_response()` completes. [F1078]
- In `tcp_v6_send_synack()`, `rcu_read_lock()` must be held across `rcu_dereference(np->opt)` and the `ip6_xmit()` call when `ireq->ipv6_opt` is NULL. [F1150]
- Because `get_tcp6_sock()` reads socket state under RCU without locking `sp`, it must load `icsk->icsk_pending` with `smp_load_acquire(&icsk->icsk_pending)` before reading `icsk_timeout(icsk)` and must clamp `READ_ONCE(tp->rcv_nxt) - READ_ONCE(tp->copied_seq)` with `max_t(int, ..., 0)`. [F1079]

## Object Lifetimes

- In `tcp_v6_err()`, the reference returned by `__inet6_lookup_established()` must be released according to `sk->sk_state`: `inet_twsk_put(inet_twsk(sk))` for `TCP_TIME_WAIT`, delegating `reqsk_put()` to `tcp_req_err()` for `TCP_NEW_SYN_RECV`, and `sock_put(sk)` on all other paths. [F1054]
- In `tcp_v6_rcv()`, the `TCP_NEW_SYN_RECV` path holds `req` from `__inet6_lookup_skb()` until it acquires a reference on the listener `sk` (via `reuseport_migrate_sock()` or `sock_hold(sk)`) and sets `refcounted = true`; every exit or retry to `lookup` must release `req` and/or `sk` matching that stage. In `do_time_wait`'s `TCP_TW_SYN` branch, replacing `sk` with a listener `sk2` from `inet6_lookup_listener()` and jumping to `process` must release the timewait socket via `inet_twsk_deschedule_put()` and set `refcounted = false` because `inet6_lookup_listener()` does not increment `sk_refcnt`. [F1064, F1117]
- In `tcp_v6_rcv()`, after `tcp_v6_fill_cb(skb, hdr, th)` copies the ingress interface state into `TCP_SKB_CB(skb)->header.h6` and before passing `skb` to `tcp_v6_do_rcv()` or `tcp_add_backlog()`, `skb->dev` must be cleared to NULL. [F1167]
- When `tcp_v6_init_req()` attaches `skb` to `ireq->pktopts` with `refcount_inc(&skb->users)`, `tcp_v6_syn_recv_sock()` (when `*own_req` is true) must call `consume_skb(ireq->pktopts)` and set `ireq->pktopts = NULL` after cloning it so `tcp_v6_reqsk_destructor()` does not double-free it. [F1057]
- In `tcp_v6_syn_recv_sock()`, `dst` must be freed via `dst_release(dst)` on failure paths before `ip6_dst_store(newsk, dst, false, false)` (`exit_overflow` and `exit_nonewsk`), whereas failures after `ip6_dst_store()` must jump to `put_and_exit` (`tcp_done(newsk)`) without calling `dst_release(dst)`. [F1060]
- In `tcp_v6_syn_recv_sock()`, when `inet_ehash_nolisten()` sets `*own_req = false`, `newsk` must be unlocked and put (`bh_unlock_sock(newsk); sock_put(newsk); newsk = NULL;`) only when `!req_unhash && found_dup_sk` (the syncookie case), leaving `newsk` locked and referenced for `inet_csk_complete_hashdance()` otherwise. [F1061]
- In `tcp_v6_send_reset()`, `key.traffic_key` must be freed with `kfree()` at `out:` if and only if `allocated_traffic_key` is true, because `tcp_ao_prepare_reset()` kmallocs `traffic_key` for listener/request sockets (even on hash failure) but returns a borrowed pointer for established/timewait sockets. [F1058]
- In `tcp_v6_md5_hash_hdr()` and `tcp_v6_md5_hash_skb()`, every failure path must zero the 16-byte `md5_hash` output buffer via `memset(md5_hash, 0, 16)` before returning 1; a successful `tcp_sigpool_start()` must be paired with `tcp_sigpool_end(&hp)` on both normal completion and `clear_hash` error paths, whereas a failed `tcp_sigpool_start()` must jump to `clear_hash_nostart` without calling `tcp_sigpool_end()`. [F1056, F1080]
- In `tcp6_check_fraglist_gro()`, the socket returned by `__inet6_lookup_established()` is only tested for existence and must be immediately released with `sock_gen_put(sk)`, whereas `udp6_gro_lookup_skb()` returns an RCU-borrowed socket from `udp_tunnel_sk()` or `__udp6_lib_lookup()` that must not be put. [F1065]
- In `net/ipv6/tunnel6.c`, `xfrm6_tunnel_deregister()` must call `synchronize_net()` after unlinking `handler` under `tunnel6_mutex`. In `tunnel6_rcv()`, `tunnel46_rcv()`, and `tunnelmpls6_rcv()`, a handler returning 0 takes ownership of `skb` (consumed), whereas returning non-zero leaves `skb` ownership with the caller to try subsequent handlers or send ICMPv6 and call `kfree_skb(skb)`. [F1066, F1165]

## API Contracts

- In `net/ipv6/tcp_ipv6.c`, `ip6_dst_lookup_flow()` returns an `ERR_PTR`-encoded `struct dst_entry *` that must be checked with `IS_ERR(dst)`, whereas `inet6_csk_route_req()` and `tcp_v6_route_req()` return NULL on failure and must be checked for `!dst`. [F1081]
- Callers of `__inet6_lookup_established()` and `inet6_lookup_listener()` must pass the remote port in network byte order (`__be16`) and the local port in host byte order via `ntohs()`; in `tcp_v6_err()`, the embedded header's destination (`hdr->daddr`, `th->dest`) is remote while its source (`hdr->saddr`, `ntohs(th->source)`) is local. [F1087]
- In `tcp_v6_rcv()`, `tcp_v6_fill_cb()` must only be called after `xfrm6_policy_check()` because `xfrm6_policy_check()` (`_decode_session6()`) reads `IP6CB(skb)`, which `tcp_v6_fill_cb()` overwrites when moving `struct inet6_skb_parm` into `TCP_SKB_CB(skb)->header.h6` (and any loop/fallthrough back to `xfrm6_policy_check()` must first call `tcp_v6_restore_cb()`). Before `tcp_v6_fill_cb()` (in `tcp_v6_early_demux()`, `tcp_v6_err()`, and `tcp_v6_rcv()` entry), ingress interface indices must be read via `inet6_iif(skb)` and `inet6_sdif(skb)` rather than `tcp_v6_iif()`, `tcp_v6_iif_l3_slave()`, or `tcp_v6_sdif()`. [F1153, F1155]
- In `tcp_v6_syn_recv_sock()`, `tcp_v6_do_rcv()`, and `tcp_v6_conn_request()`, packets with `skb->protocol == htons(ETH_P_IP)` must be delegated to their IPv4 counterparts, and `tcp_v6_syn_recv_sock()` must call `tcp_sync_mss(newsk, inet_csk(newsk)->icsk_pmtu_cookie)` after setting `icsk_af_ops = &ipv6_mapped`. [F1158]
- Callers of `tcp_v6_send_ack()` (such as `tcp_v6_timewait_ack()` and `tcp_v6_reqsk_send_ack()`) must right-shift the receive window by the socket's receive window scale (`tw->tw_rcv_wscale` or `inet_rsk(req)->rcv_wscale`) before passing `win`, because `tcp_v6_send_response()` truncates `win` to 16 bits via `htons(win)`. [F1128]
- In `tcp_v6_send_reset()`, `tcp_v6_timewait_ack()`, and `tcp_v6_reqsk_send_ack()`, `tcp_parse_auth_options()` must succeed on `tcp_hdr(skb)` before inspecting TCP-MD5 or TCP-AO options, `struct tcp_key key` must be zero-initialized (`struct tcp_key key = {}`), and `key.type` must only be set to `TCP_KEY_MD5` or `TCP_KEY_AO` after key lookup and `traffic_key` allocation succeed. [F1091, F1110]
- In `tcp_v6_md5_lookup(sk, addr_sk)`, the network namespace and MD5 key table must be queried on `sk` (`sock_net(sk)` and `tcp_v6_md5_do_lookup(sk, ...)`), whereas the bound interface and peer address must be read from `addr_sk` (`addr_sk->sk_bound_dev_if` and `&addr_sk->sk_v6_daddr`). [F1119]
- In `tcp_v6_parse_md5_keys()`, `cmd.tcpm_keylen` must be checked against `TCP_MD5SIG_MAXKEYLEN` before calling `tcp_md5_do_add()`. When `ipv6_addr_v4mapped(&sin6->sin6_addr)` is true, the peer address passed to `tcp_md5_do_del()`, `tcp_ao_required()`, and `tcp_md5_do_add()` must be `&sin6->sin6_addr.s6_addr32[3]` with `AF_INET` and `prefixlen <= 32`, and `tcp_ao_required()` must receive `l3flag ? l3index : -1`. [F1086, F1108]
- In `net/ipv6/tunnel6.c`, `xfrm6_tunnel` receive and error callbacks (`handler->handler` and `handler->err_handler` in `tunnel6_rcv()`, `tunnel46_rcv()`, `tunnelmpls6_rcv()`, `tunnel6_err()`) return 0 when consumed and non-zero to try the next handler, whereas `handler->cb_handler` in `tunnel6_rcv_cb()` returns `<= 0` to stop and return `ret` and `> 0` to continue traversal. [F1090]

## Error Handling

- In `tcp6_gro_receive()` and `udp6_gro_receive()`, when checksum validation or transport header pull (`tcp_gro_pull_header()` or `udp_gro_udphdr()`) fails, the function must set `NAPI_GRO_CB(skb)->flush = 1` and return NULL. [F1088]
- In `udp6_ufo_fragment()`, the return value of `ip6_find_1stfragopt(skb, &prevhdr)` must be stored in a signed `int err` and checked for `err < 0` (returning `ERR_PTR(err)`) before assigning it to `unsigned int unfrag_ip6hlen` and shifting headers with `memmove`. [F1089]
- On softirq packet-processing paths in `net/ipv6/tcp_ipv6.c`, logging triggered by peer packets or missing runtime keys (such as a missing TCP-AO key in `tcp_v6_reqsk_send_ack()`) must use `net_info_ratelimited()` rather than unratelimited `printk` or `WARN`. [F1166]

## External Contracts

- `tcp_v6_pre_connect()` must validate `addr_len >= SIN6_LEN_RFC2133` before invoking `BPF_CGROUP_RUN_PROG_INET6_CONNECT(sk, uaddr, &addr_len)`, and `tcp_v6_connect()` must check `addr_len >= sizeof(struct sockaddr_in6)` before reading `usin->sin6_scope_id`. [F1156]
- In `tcp_v6_parse_md5_keys()`, `cmd.tcpm_prefixlen` and `cmd.tcpm_ifindex` must only be read when `optname == TCP_MD5SIG_EXT` and the respective `TCP_MD5SIG_FLAG_PREFIX` or `TCP_MD5SIG_FLAG_IFINDEX` bit is set in `cmd.tcpm_flags`. When `TCP_MD5SIG_FLAG_IFINDEX` is set with a non-zero `tcpm_ifindex`, the device in `sock_net(sk)` must satisfy `netif_is_l3_master(dev)` or `-EINVAL` is returned, and adding a key must be rejected with `-EKEYREJECTED` if `tcp_ao_required()` matches the peer. [F1106, F1160]
- In `get_openreq6()`, `get_tcp6_sock()`, and `get_timewait6_sock()`, `/proc/net/tcp6` must format IPv6 addresses as four raw network-byte-order `s6_addr32` words (`%08X%08X%08X%08X` without `ntohl()`), format kernel socket pointers (`req`, `sp`, `tw`) with `%pK`, format the final `snd_ssthresh` column in `get_tcp6_sock()` with signed `%d` (so initial slowstart is `-1`), and clamp locklessly computed `rx_queue` (`tp->rcv_nxt - tp->copied_seq`) and signed `long` timer expiration deltas relative to `jiffies` to non-negative values (via `jiffies_delta_to_clock_t()` or `ttd < 0` clamping) before `jiffies_to_clock_t()`. [F1113, F1131, F1141]

## Known Pitfalls

- In `tcp_v6_rcv()`, `pskb_may_pull(skb, sizeof(struct tcphdr))` and the check `th->doff >= sizeof(struct tcphdr) / 4` must precede `pskb_may_pull(skb, th->doff * 4)`, and `th` and `hdr` must be reloaded after `pskb_may_pull()` and `tcp_filter()`. [F1112]
- In `tcp_v6_err()`, validating that an ICMPv6 error's embedded TCP sequence number falls within the unacknowledged send window must use modular sequence comparison `between(seq, snd_una, tp->snd_nxt)` rather than direct relational operators. [F1129]
