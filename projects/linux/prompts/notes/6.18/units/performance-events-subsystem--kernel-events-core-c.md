# PERFORMANCE EVENTS SUBSYSTEM — kernel/events/core.c

Implements the core Linux kernel Performance Events subsystem (`kernel/events/core.c`), including the `perf_event_open` syscall, anonymous inode file operations (`perf_fops`), event grouping, and hierarchical per-CPU and per-task scheduling contexts. It manages PMU registration and lifecycle, hardware/software/tracepoint/BPF event dispatching, mmap ring-buffer and AUX buffer management, cgroup and task inheritance, and cross-CPU IPI synchronization.

## Architecture & Data Flow

- When `__pmu_detach_event()` revokes an event (`event->state <= PERF_EVENT_STATE_REVOKED`), it sets `event->pmu = NULL`, `event->pmu_ctx = NULL`, and `event->destroy = NULL`; operations on existing events must check `event->state <= PERF_EVENT_STATE_REVOKED` before accessing `event->pmu` or `event->pmu_ctx`. [F194]
- `event->prog` can hold either a `BPF_PROG_TYPE_PERF_EVENT` overflow handler or a tracing BPF program (`KPROBE`/`TRACEPOINT`); `__perf_event_overflow()` must check `event->prog->type == BPF_PROG_TYPE_PERF_EVENT` before calling `bpf_overflow_handler()`, and `perf_event_free_bpf_prog()` must branch on `perf_event_is_tracing(event)`. [F195]
- In `__perf_remove_from_context()`, `perf_cgroup_event_disable()` must be called when `event->state > PERF_EVENT_STATE_OFF` before `perf_event_set_state()` lowers `event->state` to `<= PERF_EVENT_STATE_OFF`, so that `ctx->nr_cgroups` is decremented and `cpuctx->cgrp` is cleared when the last cgroup event is removed. [F206]
- In `__perf_remove_from_context()`, `perf_event_set_state(event, min(event->state, state))` must be called after `event_sched_out()` and before `perf_child_detach()`, so `perf_event_update_time()` updates `event->total_time_enabled` and `event->total_time_running` before `sync_child_event()` adds them to the parent event. [F207]
- Because `__perf_effective_state()` treats all siblings in a group as `OFF` whenever `leader->state <= PERF_EVENT_STATE_OFF`, `perf_event_set_state()` must call `perf_event_update_time(event)` and, when `(event->state < 0) ^ (state < 0)`, `perf_event_update_sibling_time(event)` before writing `event->state`. [F208]
- Whenever a sibling is added to or removed from a group in `perf_group_attach()` or `perf_group_detach()`, `group_leader->nr_siblings` and `group_leader->group_generation` must be updated and `perf_event__header_size()` must be called for `group_leader` and every sibling on `group_leader->sibling_list`. [F209]
- When `perf_group_detach()` detaches a group leader, each sibling must be promoted to a singleton leader (`sibling->group_leader = sibling`, `sibling->group_caps = event->group_caps`), added via `add_event_to_groups()` and `get_event_list()` if attached/active, or disabled into `PERF_EVENT_STATE_ERROR` if `PERF_EV_CAP_SIBLING` is set. [F210]
- In `list_add_event()` and `list_del_event()`, adding or removing an event on `ctx->event_list` must update `event->attach_state` (`PERF_ATTACH_CONTEXT`), `ctx->nr_events`, `event->pmu_ctx->nr_events`, `ctx->nr_user`, `ctx->nr_stat`, `ctx->nr_no_switch_fast`, the group rb-tree (for group leaders), and `ctx->generation` in lockstep. [F211]

## Synchronization

- In `perf_cgroup_switch()`, after the optimistic lockless check on `READ_ONCE(cpuctx->cgrp)` and acquiring `perf_ctx_lock(cpuctx, cpuctx->task_ctx)`, `READ_ONCE(cpuctx->cgrp) == NULL` must be rechecked under the lock before asserting `cpuctx->ctx.nr_cgroups == 0` or scheduling events. [F171]
- In `put_ctx()`, when `refcount_dec_and_test(&ctx->refcount)` returns false, `smp_mb__after_atomic()` must be executed before testing `ctx->task == TASK_TOMBSTONE` and calling `wake_up_var(&ctx->refcount)` so the decrement is ordered before the tombstone check. [F172]
- Any path that migrates `event->ctx` (such as `perf_pmu_migrate_context()`) must hold `ctx->mutex` of both the old and new `perf_event_context` ordered by mutex address (`mutex_lock_double()`) and call `synchronize_rcu()` between `perf_remove_from_context()` and re-installation. [F174]
- In `perf_lock_task_context()`, interrupts must be disabled via `local_irq_save()` before entering `rcu_read_lock()`, and after acquiring `raw_spin_lock(&ctx->lock)` the caller must reverify `ctx == rcu_dereference(task->perf_event_ctxp)`, `ctx->task != TASK_TOMBSTONE`, and `refcount_inc_not_zero(&ctx->refcount)`. [F176]
- `event_sched_in()` must write `event->oncpu` and execute `smp_wmb()` before setting `event->state` to `PERF_EVENT_STATE_ACTIVE`, and lockless readers (`perf_event_read()`, `perf_event_stop()`, `__perf_event_stop()`) must issue `smp_rmb()` after observing `PERF_EVENT_STATE_ACTIVE` before reading `event->oncpu`. [F177]
- `perf_install_in_context()` must publish `event->ctx` using `smp_store_release(&event->ctx, ctx)` after the event and context are initialized, pairing with `smp_load_acquire(&event->ctx)` in `perf_iterate_sb_cpu()` which skips per-CPU side-band events whose `event->ctx` is still NULL. [F178]
- Before calling `task_function_call(task, __perf_install_in_context, event)`, `perf_install_in_context()` must execute `smp_mb()` to order the prior `task->perf_event_ctxp` store before the `task_cpu(task)` load, and if the IPI misses, recheck `task_curr(task)` under `ctx->lock`. [F179]
- When detaching an event from `task->perf_event_list` in `perf_event_exit_task()` or `perf_remove_from_owner()`, `list_del_init(&event->owner_entry)` must be followed by `smp_store_release(&event->owner, NULL)` under `perf_event_mutex`, and `perf_remove_from_owner()` must recheck `event->owner` after locking `owner->perf_event_mutex`. [F181]

## Object Lifetimes

- In inherit_event(), any error or orphan exit path taken after perf_event_alloc() sets child_event->parent but before atomic_long_inc_not_zero(&parent_event->refcount) succeeds must free child_event with free_event() rather than put_event(), because put_event() unconditionally calls put_event(event->parent). [F155]
- perf_child_detach() must only clear PERF_ATTACH_CHILD and remove event->child_list without clearing or poisoning event->parent or dropping parent_event->refcount; event->parent must remain valid until put_event() finishes _free_event(event) (including irq_work_sync()) and calls put_event(parent). [F156]
- In __perf_event_overflow(), event->pending_work, local_inc(&event->ctx->nr_no_switch_fast), and atomic_long_inc_not_zero(&event->refcount) must only be set or incremented after task_work_add(current, &event->pending_task, notify_mode) returns 0. [F163]
- In perf_event_exit_event(), when detaching a child event (parent_event != NULL), put_event(event) must only be called if event->attach_state had PERF_ATTACH_CHILD set before perf_remove_from_context() cleared it. [F166]
- In __perf_pmu_install_event(), get_ctx(ctx) and perf_install_in_context(ctx, event, cpu) (which updates event->ctx via smp_store_release()) must complete before put_ctx(old_ctx) is called. [F168]
- When perf_event_exit_task_context() detaches a context from a task and drops the task reference via put_task_struct(task), it must set WRITE_ONCE(ctx->task, TASK_TOMBSTONE) under ctx->lock, and put_ctx() must check ctx->task != TASK_TOMBSTONE before calling put_task_struct(ctx->task). [F169]
- In perf_mmap_close(), when the last mapping of a ring buffer or AUX buffer closes, locked memory accounting must subtract rb->mmap_locked (or rb->aux_mmap_locked) from vma->vm_mm->pinned_vm and the remaining pages from rb->mmap_user->locked_vm, matching the split computed by perf_mmap_calc_limits(). [F170]
- During event teardown, `_free_event()` must synchronously drain `event->pending_irq` and `event->pending_disable_irq` via `irq_work_sync()`, and in `__free_event()`, `event->destroy(event)` must run before `put_task_struct(event->hw.target)` and `put_pmu_ctx(event->pmu_ctx)` must run before `put_ctx(event->ctx)`. [F180]

## API Contracts

- unclone_ctx() must be called under ctx->lock and returns the detached ctx->parent_ctx with its reference still held; the caller must release ctx->lock before calling put_ctx() on the returned pointer. [F164]
- `inherit_event()` returns an `ERR_PTR()` on failure, `NULL` when `parent_event` is revoked or orphaned (`is_orphaned_event()`), and a valid `struct perf_event *` on success; callers such as `inherit_group()` must test `IS_ERR()` first and treat `NULL` as a non-error. [F191]
- `perf_callchain()` must never return `NULL` and instead returns `&__empty_callchain` (`.nr = 0`) when callchain collection is disabled or `get_perf_callchain()` returns `NULL`, because callers unconditionally dereference `data->callchain->nr`. [F192]
- `perf_swevent_get_recursion_context()` returns a negative value when recursion is disallowed or a non-negative `rctx` index that `perf_trace_run_bpf_submit()` and `perf_tp_event()` must release via `perf_swevent_put_recursion_context(rctx)` on every exit path. [F193]
- In `_perf_event_period()`, `value` is a frequency in Hz when `event->attr.freq` is set and a period in event counts when `!event->attr.freq`; `_perf_event_period()` must check `value > sysctl_perf_event_sample_rate` in frequency mode and must only call `perf_event_check_period(event, value)` in period mode. [F204]
- In perf_mmap(), the VMA page count nr_pages must be checked against INT_MAX and vma_size must equal PAGE_SIZE * nr_pages before calling perf_mmap_rb() or perf_mmap_aux(), because rb_alloc() and rb_alloc_aux() take nr_pages as a signed int. [F230]
- Both perf_event_open() and _perf_event_period() must reject sample_freq > sysctl_perf_event_sample_rate when event->attr.freq is set, and must reject sample_period values with bit 63 set (value & (1ULL << 63)) when event->attr.freq is not set. [F238]
- In perf_event_set_filter(), the user filter string must be copied with strndup_user(arg, PAGE_SIZE), and perf_event_parse_addr_filter() must reject any PERF_ADDR_FILTER_ACTION_FILTER specification with filter->size == 0 or any trailing incomplete filter state (state != IF_STATE_ACTION) with -EINVAL. [F249]

## Error Handling

- When sys_perf_event_open() or perf_event_create_kernel_counter() fails after assigning event->pmu_ctx = find_get_pmu_context(...) but before perf_install_in_context() sets event->ctx, the error path must call put_pmu_ctx(event->pmu_ctx) and clear event->pmu_ctx = NULL before calling put_event(event). [F158]
- In perf_event_alloc(), attach_perf_ctx_data(event) must be called immediately after perf_init_event(event) when PERF_ATTACH_TASK_DATA is set in event->attach_state, with no fallible checks placed between them. [F160]
- In perf_mmap(), ring-buffer and AUX setup (perf_mmap_rb() or perf_mmap_aux()) must succeed before setting vma->vm_ops or invoking pmu->event_mapped(), and if map_range() fails afterward, perf_mmap() must explicitly call perf_mmap_close(vma). [F161]
- In perf_mmap_aux(), after refcount_inc_not_zero(&rb->mmap_count) succeeds on a buffer where !rb_has_aux(rb), any failure in perf_mmap_calc_limits() or rb_alloc_aux() must roll back rb->mmap_count via refcount_dec(&rb->mmap_count) and must not set rb->aux_mmap_count. [F162]
- When iterating multiple tracepoint events in `perf_tp_event()` and `__perf_tp_event_target_task()` with a shared `struct perf_sample_data`, `perf_sample_data_init()` must be called before each event's `perf_sample_save_raw_data()` and `perf_swevent_event()`. [F201]
- In `__perf_event_header__init_id()`, when `sample_type & PERF_SAMPLE_CPU` is set, `data->cpu_entry.reserved` must be explicitly zero-initialized because `data->cpu_entry` is allocated on the stack without zeroing and copied in full to the user ring buffer via `perf_output_put(handle, data->cpu_entry)`. [F203]
- In perf_try_init_event(), any validation failure after pmu->event_init(event) returns 0 (such as PERF_PMU_CAP_EXTENDED_REGS, PERF_PMU_CAP_NO_EXCLUDE, or pmu->scope cpumask checks) must jump to err_destroy so event->destroy(event) is called before clearing event->pmu and dropping pmu->module. [F293]
- In perf_sample_event_took(), which runs in NMI/sample context, logging that the sample rate was lowered must be deferred via irq_work_queue(&perf_duration_work) to perf_duration_warn() using printk_ratelimited() rather than calling printk() directly. [F329]

## External Contracts

- perf_copy_attr() must treat uattr->size == 0 as PERF_ATTR_SIZE_VER0, reject sizes outside [PERF_ATTR_SIZE_VER0, PAGE_SIZE] or with non-zero trailing bytes via copy_struct_from_user(), and on size error write sizeof(*attr) back to uattr->size before returning -E2BIG. [F233]
- perf_copy_attr() must reject any non-zero reserved field (__reserved_1, __reserved_2, __reserved_3) and any unknown flag bits in sample_type (~(PERF_SAMPLE_MAX-1)), read_format (~(PERF_FORMAT_MAX-1)), or branch_sample_type (~(PERF_SAMPLE_BRANCH_MAX-1)) with -EINVAL. [F234]
- Under CONFIG_COMPAT, perf_compat_ioctl() must rewrite _IOC_SIZE(cmd) from sizeof(compat_uptr_t) to sizeof(void *) for pointer-sized ioctl commands (PERF_EVENT_IOC_SET_FILTER, PERF_EVENT_IOC_ID, PERF_EVENT_IOC_QUERY_BPF, PERF_EVENT_IOC_MODIFY_ATTRIBUTES) before calling perf_ioctl(). [F239]
- struct perf_event_mmap_page must preserve offsetof(struct perf_event_mmap_page, data_head) == 1024, and perf_event_init_userpage() must initialize userpg->size to offsetof(struct perf_event_mmap_page, __reserved) and userpg->data_offset to PAGE_SIZE. [F246]
- In __perf_read(), reading an event in PERF_EVENT_STATE_ERROR must return 0 (EOF), and a user buffer with count < event->read_size must be rejected with -ENOSPC before calling perf_read_group() or perf_read_one(). [F247]
- perf_uprobe_event_init() must require capable(CAP_SYS_ADMIN) rather than perfmon_capable(), whereas perf_kprobe_event_init() checks perfmon_capable(). [F319]
- In perf_event_switch(), determining whether a task being scheduled out was preempted (to set PERF_RECORD_MISC_SWITCH_OUT_PREEMPT in the switch record header) must check task_is_runnable(task) rather than task->on_rq. [F327]

## Known Pitfalls

- Because CPU-wide events can interrupt a task in `do_exit()` after `exit_mm()` has cleared `current->mm`, sampling paths `perf_sample_ustack_size()` and `perf_callchain()` must check `current->mm != NULL` before reading user stacks or callchains, and `perf_get_page_size()` must fall back to `&init_mm` when `!current->mm`. [F196]
- `perf_event_setup_cpumask()` must detect early boot via `cpumask_empty(perf_online_mask)` and check `!cpumask_empty(cpumask)` in addition to `!cpumask` on the topology mask returned by `perf_scope_cpu_topology_cpumask()`, because architecture topology helpers may return a non-NULL static empty cpumask. [F197]
- `perf_event_bpf_emit_ksymbols()` must unconditionally emit the main BPF program's ksymbol from `prog->aux->ksym.name` and start the `prog->aux->func[i]` subprogram loop at index `i = 1`, because `prog->aux->func[0]->aux->ksym` is not initialized. [F202]
- When formatting paths into a PATH_MAX buffer in perf_event_cgroup() and perf_event_mmap_event(), the length passed to cgroup_path() or file_path() must be PATH_MAX - sizeof(u64) so that appending up to 7 NUL bytes to 8-byte align strlen(name) + 1 cannot write past the end of the buffer. [F241]
- In `perf_prepare_sample()`, because `filtered_sample_type` synthetic-enables `PERF_SAMPLE_REGS_USER` when `PERF_SAMPLE_STACK_USER` is set, accounting `data->dyn_size` and setting `data->sample_flags |= PERF_SAMPLE_REGS_USER` must check `(sample_type & ~data->sample_flags) & PERF_SAMPLE_REGS_USER` rather than `filtered_sample_type`. [F252]
- `for_each_sibling_event(sibling, event)` must not be invoked on an event whose `event->ctx` is still `NULL` (such as a newly created group leader in `perf_event_validate_size()`), because `lockdep_assert_event_ctx(event)` dereferences `event->ctx->mutex` when hardirqs are enabled. [F256]
- In perf_adjust_period(), the low-pass filter on s64 delta = (s64)(period - hwc->sample_period) must bias non-negative values by +7 and negative values by -7 before dividing by 8 so that small negative deltas (-7 <= delta < 0) are not truncated to zero. [F269]
- In perf_event_mmap(), vma->vm_pgoff must be cast to u64 before shifting left by PAGE_SHIFT ((u64)vma->vm_pgoff << PAGE_SHIFT) when initializing mmap_event.event_id.pgoff so that file offsets >= 4 GiB do not overflow a 32-bit unsigned long on 32-bit architectures. [F274]
