# GPIO SUBSYSTEM — (top level)

This component contains the core Linux GPIO framework (`gpiolib.c`, `gpiolib.h`), its DT (`gpiolib-of.c`), swnode (`gpiolib-swnode.c`), devres (`gpiolib-devres.c`), legacy (`gpiolib-legacy.c`), and sysfs (`gpiolib-sysfs.c`) frontends, public GPIO/DT headers, and controller drivers (`gpio-xlp.c` through `gpio-zynqmp-modepin.c`).

## Architecture & Data Flow
- `gpio_chip_hwgpio()` and `desc_to_gpio()` compute hardware offsets via `desc - &desc->gdev->descs[0]`; every `struct gpio_desc *` must reside inside its `desc->gdev->descs` array. `gpiod_free_commit()` must clear per-consumer flags (`ACTIVE_LOW`, `OPEN_DRAIN`, `OPEN_SOURCE`, bias, edge, `IS_HOGGED`, `REQUESTED`), `desc->hog`, `desc->label`, and `desc->debounce_period_us`, while preserving `GPIOD_FLAG_IS_OUT` and `GPIOD_FLAG_USED_AS_IRQ`. [F397, F441]
- In `gpiod_direction_output_nonotify()`, when open-drain/open-source emulation calls `gpiod_direction_input_nonotify(desc)` (`set_output_flag`), set `GPIOD_FLAG_IS_OUT` afterward so `gpiod_set_raw_value_commit()` does not fail with `-EPERM`. In `gpiod_get_direction()`, if `GPIOD_FLAG_OPEN_DRAIN` and `GPIOD_FLAG_IS_OUT` are both set, return `0` before calling `guard.gc->get_direction`. [F392, F423]
- In `gpiod_configure_flags()`, reject multiple `GPIO_PULL_UP`/`PULL_DOWN`/`PULL_DISABLE` bits in `lflags` before the bias `if`/`else if` chain, and check `!(dflags & GPIOD_FLAGS_BIT_DIR_SET)` before `dflags & GPIOD_FLAGS_BIT_DIR_OUT` so `GPIOD_ASIS` (`0`) returns early. [F421, F422]
- `gpiod_get_array()` must place `struct gpio_array` (`array_info`) in the same `krealloc()` block right after `descs->desc[count]`, set `array_info->desc = descs->desc` after reallocation (as `gpiod_get/set_array_value_complex()` require `(void *)array_info == desc_array + array_info->size` and `gpiod_put_array()` frees only `descs`), and size `invert_mask`/`get_mask`/`set_mask` to `BITS_TO_LONGS(max(gdev->ngpio, count))`. [F435, F438]
- In `gpio_chip_get_multiple()` and `gpiochip_set_multiple()`, when `gc->get_multiple`/`set_multiple` is non-NULL, return its status directly (mapping `> 0` to `-EBADE`) without falling through to `for_each_set_bit()`; when `NULL`, fall back silently without `WARN_ON()`. [F417, F484]
- `gpiochip_allocate_mask()` fills valid masks with `bitmap_fill(p, gc->ngpio)` so lines start valid before `gpiochip_apply_reserved_ranges()` or `init_valid_mask` clears bits. In `gpiochip_apply_reserved_ranges()`, `size` is even (`gpiochip_count_reserved_ranges()`) and both `ranges[--size]` decrements must precede the bounds-check `continue`. [F386, F430]
- `gpiochip_set_names()` must return early if `"gpio-line-names"` `count <= chip->offset`, and clamp `count - chip->offset` to `chip->ngpio`. `gpiodev_add_to_list_unlocked()` keeps `gpio_devices` sorted by non-overlapping `[base, base + ngpio)` ranges, and `gpiochip_find_base_unlocked()` allocates dynamic bases only in `[GPIO_DYNAMIC_BASE, GPIO_DYNAMIC_MAX - ngpio]`. [F407, F409]
- In `struct gpio_irq_chip`, `per_parent_data` selects between `parent_handler_data_array` (`num_parents` elements) and `parent_handler_data` (or `gc` if `NULL`). With `IRQCHIP_IMMUTABLE`, `gpiolib` must not mutate `gc->irq.chip`, and the chip must use `GPIOCHIP_IRQ_RESOURCE_HELPERS` and `gpiochip_enable_irq()`/`gpiochip_disable_irq()`. [F384, F455]
- `of_gpiochip_add()` rejects `chip->of_gpio_n_cells > MAX_PHANDLE_ARGS`, `of_xlate_and_get_gpiod_flags()` requires `gpiospec->args_count == chip->of_gpio_n_cells`, and `of_gpiochip_add_pin_range()` parses `chip->of_gpio_n_cells + 1` cells per `"gpio-ranges"` entry and trims linear ranges to `[chip->offset, chip->offset + chip->ngpio)`. [F412]
- In `gpiolib-of.c`, clear `OF_POPULATED` on `rd->dn` if `of_gpiochip_add_hog()` fails in `of_gpio_notify()` or when `of_gpiochip_remove_hog()` runs on `OF_RECONFIG_CHANGE_REMOVE`, and update SPI CS quirks (`"cs"` -> `"gpios"`) in `of_gpio_spi_cs_get_count()` and `of_find_gpio_rename()` in lockstep. [F398, F402]
- In `gpio_sysfs_set_active_low()`, changing `GPIOD_FLAG_ACTIVE_LOW` when `data->irq_flags` is `TRIGGER_FALLING`/`RISING` must free and re-request the IRQ using a saved copy of `data->irq_flags` (since `gpio_sysfs_free_irq()` clears it). In `gpio-xlp.c`, registers are at `(gpio / XLP_GPIO_REGSZ) * 4` bit `BIT(gpio % XLP_GPIO_REGSZ)` with `gc->ngpio <= XLP_MAX_NR_GPIO` (96), and `xlp_gpio_generic_handler()` must initialize `regoff = -1` before `for_each_set_bit()`. [F396, F415, F432]

## Synchronization
- Runtime accesses to `gdev->chip` and internal `gpiochip_*` wrappers must hold `gdev->srcu` (`gpio_chip_guard`) and verify `gc != NULL`; before registration in `gpiochip_add_data_with_key()`, call `gc->get_direction()` directly. Compare another descriptor's chip via `gpio_device_chip_cmp(gdev, gc)` so its `gdev->srcu` is held. [F359, F362, F369]
- Mutate `gpio_devices` under `gpio_devices_lock` with RCU list primitives (`list_add_rcu`, `list_del_rcu`), and call `synchronize_srcu(&gpio_devices_srcu)` after unlocking on removal before freeing/numbing `gdev`. `gpiod_find_and_request()` must hold `gpio_devices_srcu` continuously across lookup and `gpiod_request()`. [F367, F476]
- `desc_set_label()` updates `desc->label` via `rcu_replace_pointer()` and frees the old label via `call_srcu(&desc->gdev->desc_srcu, &old->rh, desc_free_label)`; `gpiodev_release()` must call `synchronize_srcu(&gdev->desc_srcu)` before `cleanup_srcu_struct()`. Callers of `gpiod_get_label(desc)` must hold `desc->gdev->desc_srcu` while accessing the string (or copy it under the lock, as in `gpiochip_dup_line_label()`), and check for `NULL`. [F382, F469, F470]
- `gpiod_line_state_notify()` must hold `read_lock_irqsave(&desc->gdev->line_state_lock)` around `raw_notifier_call_chain()`, matching `write_lock_irqsave()`. `gpiochip_irqchip_add_allocated_domain()` must set `gc->to_irq`, `gc->irq.domain`, and `gc->irq.domain_is_allocated_externally` and run `barrier()` before `gc->irq.initialized = true`. [F360, F366]
- Hold `gpio_lookup_lock` for `gpio_lookup_list` (`gpiod_add_lookup_tables`, `gpiod_remove_lookup_table`, `gpiod_find`, `platform_gpio_count`), and `gpio_machine_hogs_mutex` for `gpio_machine_hogs` (`machine_gpiochip_add`, `gpiod_add_hogs`, `gpiod_remove_hogs`). `gpiochip_lock_as_irq()` must only call `gpiod_get_direction(desc)` when `!gc->can_sleep && gc->get_direction`. In `gpiod_free_irqs()`, release `irqd->request_mutex` before calling `free_irq(irq, cookie)`. [F370, F475, F478]
- In `gpiolib-sysfs.c`, `gpio_sysfs_request_irq()`, `gpio_sysfs_free_irq()`, and `gpio_sysfs_set_active_low()` require `data->mutex`, except in `gpiod_unexport()` where `device_unregister(desc_data->dev)` must precede `gpio_sysfs_free_irq(desc_data)` under `sysfs_lock`. `gpiochip_sysfs_unregister()` must drop `sysfs_lock` after unregistering `cdev_base`/`cdev_id` before calling `gpiod_unexport()`. [F372, F479]
- Driver locking: in `gpio-xtensa.c`, wrap `read_impwire`/`rur.expstate`/`wrmsk_expstate` in `enable_cp()` and `disable_cp()`; in `gpio-xlp.c`, guard `gpio_intr_en`, `gpio_intr_stat` (W1C), and `gpio_enabled_mask` with `spin_lock_irqsave(&priv->lock, flags)`; in `gpio-zevio.c`, hold `controller->lock` for MMIO and write `ZEVIO_GPIO_OUTPUT` before `ZEVIO_GPIO_DIRECTION` in `zevio_gpio_direction_output()`. [F373, F463, F465]

## Object Lifetimes
- `gpiod_request()` takes `try_module_get(desc->gdev->owner)` and `gpio_device_get(desc->gdev)` (released by `gpiod_free()`), whereas `gpiochip_request_own_desc()` takes neither and pairs with `gpiochip_free_own_desc()`. `gpiochip_reqres_irq()` must take `try_module_get(gc->gpiodev->owner)` before `gpiochip_lock_as_irq()` and call `module_put()` on failure or in `gpiochip_relres_irq()`. [F344, F358]
- `gpiochip_remove()` must unregister sysfs, free hogs/IRQs, unlink `gdev->list` under `gpio_devices_lock`, `synchronize_srcu(&gpio_devices_srcu)`, set `gdev->chip = NULL`, and `synchronize_srcu(&gdev->srcu)` before tearing down `gc` state and calling `gcdev_unregister(gdev)`. `gpiochip_free_mask()` must set `*p = NULL` after `bitmap_free(*p)` so `err_remove_irqchip` does not double-free `gc->irq.valid_mask`. [F348, F363]
- `devm_gpiod_put*()` must call `devm_release_action()` (not `devm_remove_action()`), whereas `devm_gpiod_unhinge()` calls `devm_remove_action_nowarn()` and ignores `-ENOENT`. With `GPIOD_FLAGS_BIT_NONEXCLUSIVE`, `devm_gpiod_get_index()` must check `devm_is_action_added(dev, devm_gpiod_release, desc)` before adding the action. [F349, F451]
- `gpio_device_find*()` return a refcounted `struct gpio_device *` requiring `gpio_device_put()`, whereas `gpio_device_get_desc()` and `gpiod_to_gpio_device()` do not increment the refcount. Visitor callbacks for `gpio_device_find()` (like `gpiofind_sysfs_register()`) must return `0` to avoid stopping early and leaking a reference. [F431, F453]
- Free `gdev->label` (`kstrdup_const()`) with `kfree_const()`. In `gpiochip_set_names()` and `gpiodev_release()`, free only the temporary `names` array (`kfree(names)`) and never `names[i]` or `desc->name`. [F356, F445]
- Node references: in `of_get_named_gpiod_flags()`, after `of_parse_phandle_with_args_map()`, every path must put `gpiospec.np` and `gdev`; in `of_gpiochip_add_pin_range()`, call `of_node_put(pinspec.np)` before any `return`/`continue` after `of_parse_phandle_with_fixed_args()`; `of_gpiochip_add()` calls `of_node_get(np)` after `of_gpiochip_add_pin_range()` and puts it if `of_gpiochip_scan_gpios()` fails or in `of_gpiochip_remove()`; in `swnode_find_gpio()`/`swnode_gpio_count()`, pair `swnode_gpio_get_reference()` with `fwnode_handle_put(args.fwnode)`. [F353, F355, F428, F460]

## API Contracts
- Non-optional getters (`[devm_]gpiod_get_index/array`) return `ERR_PTR(-ENOENT)` when unassigned; `_optional` variants convert only `-ENOENT` (`gpiod_not_found()`) to `NULL`. When `!CONFIG_GPIOLIB`, stubs return `NULL` (`_optional`) or `ERR_PTR(-ENOSYS)` and `WARN_ON(desc)` if any non-NULL pointer is passed to consumer calls. [F374, F498]
- `gpio_to_desc()` takes a global GPIO number and returns `NULL` on failure; `gpio_device_get_desc()` and `gpiochip_get_desc()` take a hardware offset (`0 .. gdev->ngpio - 1`), return `ERR_PTR(-EINVAL)` if out of bounds, and `gpio_device_get_desc()` clamps `hwnum` with `array_index_nospec()`. [F375, F486]
- Public `gpiod_*` entry points must validate `desc` with `VALIDATE_DESC[_VOID]()` before `gpio_chip_guard`, `gpiod_line_state_notify()`, or `*_nonotify()`/`*_commit()` helpers, except `gpiod_get_direction()` and `gpiod_to_irq()` which must check `validate_desc(desc, __func__) <= 0` and return `-EINVAL` (`0` is valid output / `NO_IRQ`). [F376, F377]
- `gpio_chip` callbacks `.request`, `.direction_input`, `.direction_output`, `.set`, `.set_multiple`, `.get_multiple`, and `.set_config` return `0` or `< 0`; `.get` and `.get_direction` return `0`, `1`, or `< 0` (`> 1` becomes `-EBADE`). Setting `.direction_input` without `.get`, or supporting output without `.direction_output` or `.set`, fails with `-EIO`. [F379, F490]
- Logical accessors (`gpiod_direction_output`, `gpiod_get/set_value*`) apply `GPIOD_FLAG_ACTIVE_LOW` and open-drain/open-source; `*_raw*()` use physical levels. Non-sleeping accessors (`can_sleep == false`) must not be used when `gdev->can_sleep` or `gc->can_sleep` is true; use `*_cansleep()`. `GPIOD_FLAG_*` are bit numbers (`0`..`19`) for bitops on `desc->flags`; `enum gpiod_flags`, `gpio_lookup_flags`, and `of_gpio_flags` are bitmasks for `|`/`&`. [F388, F472, F493]
- `gpiod_set_config()` / `gpio_do_set_config()` take `pinconf_to_config_packed()`; `gpiod_set_debounce()` / `gpio_set_debounce_timeout()` take unpacked microseconds. `gpiod_set_transitory()` updates `GPIOD_FLAG_TRANSITORY` before `gpio_set_config_with_argument_optional(..., PIN_CONFIG_PERSIST_STATE, !transitory)` (which ignores `-ENOTSUPP`). `gpiochip_dup_line_label()` returns `NULL` (out of range/unrequested), `ERR_PTR(-ENOMEM)`, or a `kfree()`-able string. [F383, F389, F467]
- For gpiolib IRQ domains, `domain->host_data` and `irq_data_get_irq_chip_data()` are `struct gpio_chip *gc`, and `parent_handler` `handler_data` defaults to `gc`. `gpiochip_add_irqchip()` rejects `gc->can_sleep && gc->irq.parent_handler` (`-EINVAL`), and warns/resets `default_type != IRQ_TYPE_NONE` when a fwnode is present. With `gc->irq.parent_domain`, `child_to_parent_hwirq` and `fwnode` are required, and `gpiochip_hierarchy_setup_domain_ops()` overwrites `activate`, `deactivate`, and `alloc` in `child_irq_domain_ops`. [F444, F474, F491, F492]
- `gpiod_lookup_table.table` arrays end with `.key == NULL` (`chip_hwnum == U16_MAX` for line names); `gpiod_hog` arrays end with `.chip_label == NULL`. `gpiod_fwnode_lookup()` falls back to `fwnode->secondary` on `-ENOENT`. `gpiochip_add_pin_ranges()` only calls `gc->add_pin_ranges(gc)` if `"gpio-ranges"` is absent on `&gc->gpiodev->dev`. [F411, F457, F458]

## Error Handling
- In `gpiochip_sysfs_register()`, extract `PTR_ERR(data->cdev_base)` / `PTR_ERR(data->cdev_id)` before `kfree(data)`. In `gpiod_direction_input_nonotify()` and `gpiod_direction_output_raw_commit()`, do not leave `GPIO_LINE_DIRECTION_IN` (`1`) from `gpiochip_get_direction()` in `ret`. [F350, F378]
- Helpers callable before `gc->gpiodev` is initialized (`gpiochip_line_is_valid`, `gpiochip_get_ngpios`) must not dereference `gc->gpiodev` unconditionally or use `chip_err()`/`chip_warn()`. `gpiochip_add_data_with_key()` must suppress `pr_err()` on `-EPROBE_DEFER`. [F381, F497]
- In `gpiod_get_array()`, increment `descs->ndescs` only after `gpiod_get_index()` succeeds so `gpiod_put_array()` never sees an `ERR_PTR`. `gpiod_request_user()` translates `-EPROBE_DEFER` to `-ENODEV`, and sysfs export/unexport paths log invalid/masked GPIOs with `pr_debug_ratelimited()`. [F385, F488]

## External Contracts
- `/sys/class/gpio/{export,unexport}` use `gpio_to_desc()` (global numbers); `/sys/class/gpio/chipN/{export,unexport}` (`do_chip_export_store`) use `gpio_device_get_desc()` (0-based offsets). `unexport_gpio_desc()` and `gpiochip_sysfs_unregister()` must check `GPIOD_FLAG_SYSFS` (not just `GPIOD_FLAG_EXPORT`) before unexporting and freeing. [F413, F487]
- In `/sys/kernel/debug/gpio`, `gpiolib_seq_start()` must set `priv->newline = true` when `*pos > 0`, and every path in `gpiolib_seq_show()` (including `!gc`) must emit a trailing `'\n'`. [F395, F414]

## Known Pitfalls
- In `gpiod_get/set_array_value_complex()`: use stack `fastpath_mask`/`fastpath_bits` only when `guard.gc->ngpio <= FASTPATH_NGPIO`, else `bitmap_alloc(guard.gc->ngpio, can_sleep ? GFP_KERNEL : GFP_ATOMIC)`; always call `bitmap_zero(mask, guard.gc->ngpio)`; if `array_info` fails fastpath validation, reset `array_info = NULL` before the `while (i < array_size)` loop; because fastpath `bitmap_xor()` inverts `value_bitmap` in-place for `invert_mask` pins, the `gpiod_set_array_value_complex()` slowpath must skip active-low inversion when `array_info && test_bit(i, array_info->invert_mask)`. [F387, F406, F418, F419, F440, F473]
- In `gpiodev_add_to_list_unlocked()`, check `if (&next->list == &gpio_devices) break;` before reading `next->base`. In `gpiod_unexport()`, save the match in `desc_data = tmp` before breaking from `list_for_each_entry()` and test `desc_data`, not `tmp`. In `gpiochip_get_ngpios()`, check `gc->ngpio == 0` on the `u16` field after assigning the `u32` property to catch 65536-multiple truncation. [F416, F424, F434]
- Pass only a fixed-size `char` array (not `char *`) to `for_each_gpio_property_name(propname, con_id)` (`sizeof(propname)`). In `for_each_hwgpio_in_range()` and wrappers, declare `_i` as `int`/`unsigned int` and never reassign `_label` to a non-kmalloc pointer or free it without setting `_label = NULL`. [F437, F446]
- In `gpio_is_visible()`, downcast `dev_attr` to `struct gpiod_data` via `container_of()` only after matching `attr->name` to its specific member (`dir_attr`, `val_attr`, `edge_attr`, `active_low_attr`). In `of_gpio_set_polarity_by_property()`, match compatibility on `np_compat` (`np->parent` for `atmel,hsmci`) but read `polarity_propname` from `np_propname` (`np`). In `of_gpio_flags_quirks()`, for SPI `"cs-gpios"`, read `reg` and `"spi-cs-high"` from `child`, not `np`. [F426, F427, F442]
