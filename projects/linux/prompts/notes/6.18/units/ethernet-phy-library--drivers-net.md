# ETHERNET PHY LIBRARY — drivers/net

`drivers/net` provides MDIO controllers, muxes, OF/ACPI/fwnode MDIO helpers, XPCS platform glue, and vendor Ethernet PHY drivers/libraries (Aquantia, Broadcom, Airoha EN8811H, ADIN1100, AX88796B).

## Architecture & Data Flow
- In `bcm-phy-ptp.c`, CPU framesync on `NSE_CTRL` under `priv->mutex` must call `bcm_ptp_framesync_disable()`, `bcm_ptp_framesync()`, and `bcm_ptp_framesync_restore()`. `bcm_ptp_settime_locked()` passes `NSE_INIT` so `SHADOW_LOAD` auto-clears; `bcm_ptp_adjfine()` omits `NSE_INIT` and must write `0` to `SHADOW_LOAD`. `bcm_ptp_get_framesync_ts()`/`bcm_ptp_get_tstamp()` must bracket `HB_REG_0..3`/`TS_REG_0..3` reads with `HB_READ_START`/`TS_READ_START` and `HB_READ_END`/`TS_READ_END` then `0`. [F63, F64, F65]
- `bcm_ptp_probe()` must copy `bcm_ptp_clock_info` into `priv->ptp_info` and register `&priv->ptp_info` (for `ptp2priv`). In `bcm_ptp_txtstamp()`, `HWTSTAMP_TX_ONESTEP_P2P` and `HWTSTAMP_TX_ONESTEP_SYNC` must fall through into `HWTSTAMP_TX_ON` to queue one-step packets with `BCM_SKB_CB(skb)->discard = true`. [F104, F130]
- `aqr_gen1_config_init()` must call `aqr_wait_reset_complete()` before `aqr_build_fingerprint()`, `aqr107_set_downshift()`, `aqr107_config_mdi()`, or `aqr_phy_led_active_low_set()`. `aqr_phy_led_polarity_set()` must record indices in `priv->leds_active_low`/`leds_active_high` for `aqr_gen1_config_init()` to restore. `aquantia_leds.c` callbacks must reject `index >= AQR_MAX_LEDS` (`-EINVAL`) and `rules & ~supported_triggers` (`-EOPNOTSUPP`). [F67, F79, F137]
- In `aqr_fw_boot()`, add `primary_offset` to `iram_offset`/`dram_offset`, validate with `aqr_fw_validate_get()`, and require `sizeof(u32)` alignment. `aqr_translate_interface()` translates `USXGMII` to `10G_QXGMII` only when both `PHY_ID_AQR412C` and `priv->fingerprint == AQR_G3_V4_3_C_AQR_NXP_SPF_30841_MUSX_ID40019_VER1198` match. `aqr_hwmon_probe()` must advance `j` only when `isalnum(hwmon_name[i])` and set `hwmon_name[j] = '\0'`. [F75, F112, F148]
- In `air_en8811h.c`, LED callbacks must reject `index >= EN8811H_LED_COUNT` (`-EINVAL`) and `rules & ~en8811h_led_trig` (`-EOPNOTSUPP`). Manual LED updates must clear `priv->led[index].rules = 0`; `air_led_hw_control_set()` must clear `AIR_PHY_LED_STATE_FORCE_ON | AIR_PHY_LED_STATE_FORCE_BLINK`. `en8811h_config_init()` sets `priv->mcu_needs_restart = true` on first run and calls `en8811h_restart_mcu()` on later runs before `AIR_PHY_MCU_CMD_1..4`. In `en8811h_read_status()`, if `priv->firmware_version < 0x24011202`, set `2500baseT_Full` in `lp_advertising` from `phydev->speed == SPEED_2500`. [F57, F68, F78, F147]
- In `bcm_omega_config_init()`/`bcm_omega_set_tunable()`, couple EEE with downshift via `bcm_phy_set_eee(phydev, count == DOWNSHIFT_DEV_DISABLE)`, then `genphy_restart_aneg()`. `bcm_phy_led_brightness_set()` requires `index < 4`. `bcm_phy_get_wol()` must check `is_broadcast_ether_addr(da)` before `is_multicast_ether_addr(da)`. `bcm_phy_handle_interrupt()` must invert active-low `MII_BCM54XX_IMR` (`irq_mask = ~irq_mask`) before testing `!(irq_status & irq_mask)`. [F69, F88, F108, F109]
- Signature changes to `bcm_ptp_probe/config_init/stop()` or `aqr_hwmon_probe()` must update both declarations and `#else` stubs in `bcm-phy-lib.h` / `aquantia.h`. Keep trailing `{}`/`NULL` sentinels in `whitelist_phys[]` and `aqr_hwmon_info[]`. `of_phy_register_fixed_link()` must zero-init `struct fixed_phy_status status = {}` for `"in-band-status"`. `of_mdiobus_child_is_phy()` must return `false` for non-matching `compatible` strings so `__of_mdiobus_parse_phys()` calls `of_mdiobus_register_device()`. [F47, F73, F74, F96, F111]
- In `mdio-realtek-rtl9300.c`, `pdev` drvdata is `rtl9300_mdio_priv` while `bus->priv` is `rtl9300_mdio_chan` (`chan->priv`). `rtl9300_mdiobus_map_ports()` must filter `mdio_dn->parent != dev->of_node` (`mdio_dn = phy_dn->parent`) and require `pn < MAX_PORTS` (28) and `bus < MAX_SMI_BUSSES` (4). `mdio-mux-multiplexer.c` must call `mux_control_deselect()` only when `s->do_deselect` is true. `mdio_mux_mmioreg_probe()` must require `s->iosize` in `{1,2,4}`, `mux-mask` within `s->iosize * 8` bits, and child `reg & ~s->mask == 0`. [F59, F91, F93, F102, F131]
- In `pcs-xpcs-plat.c`, `xpcs_plat_init_res()` requires `pxpcs->reg_width` in `{2,4}` and `resource_size(res) >= pxpcs->reg_width * (SZ_256 or SZ_2M)`, `xpcs_mmio_read/write` must reject `addr != 0` (`-ENODEV`), and all `pxpcs->reg_base` offsets must be scaled by `pxpcs->reg_width` (`<< 2` or `<< 1`). `ipq4019_mdio_select_mdc_rate()` and `ipq4019_mdio_set_div()` must use `DIV_ROUND_UP(ahb_rate, div)`. `mscc_miim_clk_set()` must return if `!miim->bus_freq`, compute `div = DIV_ROUND_UP(rate, 2 * miim->bus_freq) - 1`, and reject `div == 0` or `div & ~MSCC_MIIM_CFG_PRESCALE_MASK`. [F95, F120, F121, F129]
- `g12a_ephy_pll_init()` must set non-zero `PLL_CTL0_N` in `ETH_PLL_CTL0`. `gxl_enable_internal_mdio()` must set `REG2_REVERSED | FIELD_PREP(REG2_PHYID, EPHY_GXL_ID)`. `mdio-cavium.c` ops must call `cavium_mdiobus_set_mode(p, C22/C45)` before `SMI_CMD`, and `cvmx_smix_*` unions must use `OCT_MDIO_BITFIELD_FIELD` MSB-to-LSB. `mdio_i2c_alloc()` selects SMBus byte ops only when `I2C_FUNC_SMBUS_BYTE_DATA` and `!I2C_FUNC_I2C`. [F71, F110, F122, F149, F173]

## Synchronization
- In `air_en8811h.c`, BUCKPBUS helpers must init `ret = 0`, bracket page-4 accesses with `phy_select_page(phydev, AIR_PHY_PAGE_EXTENDED_4)` and `phy_restore_page(phydev, saved_page, ret)`, use `__phy_read/write()`, and `__air_buckpbus_reg_write/read/modify()` must set `AIR_BPBUS_MODE_ADDR_FIXED`. [F15, F49, F61]
- `__bcm_phy_*_exp()` and `__bcm_phy_*_rdb()` require `phy_lock_mdio_bus(phydev)`. `_bcm_phy_cable_test_start()` must set `BMCR_ANENABLE`, `ADVERTISE_CSMA`, and `MII_CTRL1000 = 0` before `BCM54XX_ECD_CTRL_RUN`, and when `is_rdb`, both `_bcm_phy_cable_test_start/get_status()` must hold `phy_lock_mdio_bus(phydev)` across `__bcm_phy_enable_legacy_access()`, expansion accesses, and `out: ret = __bcm_phy_enable_rdb_access(phydev) ? : ret;`. [F24, F40, F161, F183]
- In `bcm-phy-ptp.c`, hold `priv->mutex` across `priv->nse_ctrl` updates, framesync helpers, `bcm_ptp_settime_locked()`, and `bcm_ptp_get_tstamp()`. `bcm_ptp_perout/extts_locked()` must call `cancel_delayed_work_sync(&priv->pin_work)` if `priv->pin_active` before `INIT_DELAYED_WORK()`, and workers must abort if `!priv->pin_active` under `priv->mutex`. `bcm_ptp_cancel_func()` sets `priv->pin_active = false` and clears `NSE_CTRL` sync/capture bits before `cancel_delayed_work_sync()`. `bcm_ptp_stop()` calls `ptp_cancel_worker_sync()` and `bcm_ptp_cancel_func()`; `bcm_ptp_hwtstamp()` calls `ptp_cancel_worker_sync()` before purging `priv->tx_queue`. [F25, F26, F27, F140]
- In `bcm_ptp_match_tstamp()`, hold `spin_lock_irqsave(&priv->tx_queue.lock, flags)` across `skb_queue_walk()` and `__skb_unlink()` (immediately breaking and saving `ts_skb`), calling `skb_complete_tx_timestamp()`/`kfree_skb()` after unlock. [F28, F103]
- `smbus_byte_mii_read/write_default_c22()` and `i2c_transfer_rollball()` must hold `i2c_lock_bus(i2c, I2C_LOCK_SEGMENT)` across all transfers; `i2c_transfer_rollball()` must save `__i2c_transfer_err()` in `main_err`, restore `saved_page` before unlock, and return `main_err ? : ret`. [F20, F42, F169]
- `mdio_mux_read/write[_c45]()` hold `pb->mii_bus->mdio_lock` (`MDIO_MUTEX_MUX`) across `pb->switch_fn()` and parent transfer, updating `pb->current_child` only on `0` return. `rtl9300_mdio_read/write_c22/c45()` hold `priv->lock` across `SMI_ACCESS_PHY_CTRL_0..3` and `rtl9300_mdio_wait_ready()`. `ipq8064_mdio` `priv->base` requires `bus->mdio_lock`. `g12a_ephy_pll_enable()` runs in atomic CCF context and must pass `delay_us = 0` to `readl_poll_timeout()`. [F58, F168, F170, F171]
- In `en8811h_probe()`, set `priv->phydev = phydev` before `en8811h_clk_provider_setup()`. Set `fwnode`, IRQ, reset delays, and `platform_data` before `phy_device_register()` or `mdio_device_register()` in `fwnode_mdiobus_*`, `of_mdiobus_register_device()`, and `xpcs_plat_init_dev()`. [F30, F32]

## Object Lifetimes
- If `phy_device_register()` or `mdio_device_register()` fails after `fwnode_handle_get()` and `device_set_node()`/`dev.fwnode`, clear `dev.fwnode` before `phy/mdio_device_free()` to prevent double `fwnode_handle_put()`. [F1]
- In `fwnode_mdiobus_register_phy()`, assign `phy->psec` and non-NULL `phy->mii_ts` (after `phy_device_register()`) only after all steps that jump to `unregister_phy`, unwinding in reverse: `phy_device_remove(phy)`, `phy_device_free(phy)`, `unregister_mii_timestamper(mii_ts)`. `fwnode_find_mii_timestamper()` must call `of_node_put(arg.np)` on `arg.args_count != 1` and after `register_mii_timestamper()`. [F2, F44, F138, F150, F185]
- `of_phy_get_and_connect()` must call `of_node_get(np)` when `of_phy_is_fixed_link(np)` to balance `of_node_put(phy_np)`. Early exits from `for_each_available_child_of_node(np, child)` in `of_mdio.c` or `mdio-mux.c` must call `of_node_put(child)`. [F4, F101]
- In `mdio_mux_init()`, call `get_device(&parent_bus->dev)` for caller-supplied `mux_bus`. Link `cb` onto `pb->children` only after `of_mdiobus_register()` succeeds; free `cb->mii_bus` and continue on non-deferral errors, or jump to `err_loop:` on `-EPROBE_DEFER`/`-ENOMEM`. Set drvdata before `mdio_mux_init()` if `switch_fn` uses drvdata, and call `mdio_mux_uninit()` in `.remove` before parent teardown. [F6, F7, F22, F54, F132, F142]
- Non-devres MDIO drivers (`mdio-bcm-iproc.c`, `mdio-hisi-femac.c`, `mdio-moxart.c`, `mdio-sun4i.c`) must call `mdiobus_unregister(bus)` before disabling clocks/regulators and `mdiobus_free(bus)`. `pcs-xpcs-plat.c` MMIO accessors must wrap `pxpcs->reg_base` in `pm_runtime_resume_and_get()` and `pm_runtime_put()`. [F18, F159]
- Unwind in reverse order: `release_firmware(fw2)` then `fw1` in `en8811h_load_firmware()`, and `kfree(buf)` then `nvmem_cell_put(cell)` in `aqr_firmware_load_nvmem()` (skip `kfree` on read error). `bcm_ptp_txtstamp()` must queue or `kfree_skb(skb)`; `bcm_ptp_match_tstamp()` must `kfree_skb()` matched SKBs with `BCM_SKB_CB(ts_skb)->discard`. [F16, F17, F176]

## API Contracts
- Callers of `of_mdio/phy_find_device()` (`of_phy_connect()`, `of_phy_deregister_fixed_link()`) must call `put_device(&phy->mdio.dev)`. Callers of `fwnode_mdiobus_[phy_device_]register_phy()` must validate `addr < PHY_MAX_ADDR` (32). [F3, F123]
- Free `alloc_mdio_bitbang()` buses with `free_mdio_bitbang(bus)`. `mdiobb_send_bit/num()` require `set_mdio_dir(ctrl, 1)`; `mdiobb_get_bit/num()` require `set_mdio_dir(ctrl, 0)`. `mdio_mux` `switch_fn` must handle `current_child == -1`. 32-bit MDIO reads (`xpcs_mmio_read_reg_indirect/direct()`, `mscc_miim_read()`) must mask results with `0xffff`. [F10, F53, F72, F125]
- In `aqr_phy_led_active_low_set()`, `__bcm_phy_modify_exp/rdb()`, and `air_buckpbus_reg_modify()`, `set` must be a pre-shifted bitmask, not a boolean. `bcm54xx_auxctl_write()` requires `MII_BCM54XX_AUXCTL_MISC_WREN` in `val` for `SHDWSEL_MISC`; `bcm54xx_auxctl_read()` shifts `regnum` and sets `SHDWSEL_MASK`. `bcm_phy_read/write_exp()` require the bank selector in `reg` (`_exp_sel()` ORs `MII_BCM54XX_EXP_SEL_ER`). [F36, F50, F51]
- `bcm_phy_get_stats()` requires a non-NULL `shadow` array of `bcm_phy_get_sset_count(phydev)` `u64`s. `bcm_phy_set_wol()` returns `-EOPNOTSUPP` for unsupported `wolopts`. `bcm_ptp_probe()` returns `NULL` or `ERR_PTR`; check `IS_ERR()` on probe and non-NULL before `bcm_ptp_stop()`. `bcm_ptp_do_aux_work()` returns `1` while `tx_queue` is non-empty and `-1` when empty. [F39, F48, F178, F182]
- `aqr_config_intr()` and `bcm_phy_config_intr()` must clear interrupts before unmasking on enable and after masking on disable. `aqr_hwmon_get/set()` convert millidegrees to/from `s16` 1/256th-degree C (`* 1000 / 256`, `[-128000, 128000)` -> `-ERANGE`). `aqr_phy_led_polarity_set()` returns `-EINVAL` if no mode matches. Aquantia PHYs with restricted speeds (`AQCS109`, `AQR111/B0`, `AQR114C`, `AQR115/C`) must set features in `.get_features`, not `.config_init`. [F52, F97, F135, F136, F179]

## Error Handling
- `ipq4019_mdio_probe()` must check `IS_ERR(priv->eth_ldo_rdy)`. `sun4i_mdio_probe()` must set `data->regulator = NULL` on non-`-EPROBE_DEFER` errors. `aqr107_config_mdi()` must treat `-EINVAL` and `-ENOSYS` from `of_property_read_u32()` as `0`. [F33, F34, F35]
- `aqr_wait_reset_complete()` must check signed `val < 0` after `read_poll_timeout()`. `aqr_gen1_read_status()` must ignore `-ETIMEDOUT` from `phy_read_mmd_poll_timeout()`. `_bcm_phy_cable_test_get_status()` must init `*finished = false` before reads. Callers of `phy_modify[_mmd]_changed()` wrappers (`aqr_set_mdix()`, `bcm_setup_lre_master_slave()`, `bcm_config_lre_advert()`) must check `< 0` for error and `> 0` for changed. [F37, F41, F55, F100]
- In `fwnode_mdiobus_phy_device_register()`, propagate `-EPROBE_DEFER` from `fwnode_irq_get()` via `driver_deferred_probe_check_state()`, falling back to `mdio->irq[addr]` on other `rc <= 0`. In `__of_mdiobus_parse_phys()`, `__of_mdiobus_register()`, and `__acpi_mdiobus_register()`, ignore `-ENODEV` from child registration. [F45, F46]

## External Contracts
- In `aqr_fw_boot/load_memory()`, CRCs are BE16 while headers/payloads are unaligned LE. `__air_write_buf()` writes unaligned LE16 `AIR_BPBUS_WR_DATA_HIGH` (`offset + 2`) before `LOW` (`offset`). `aqr107_get_stat()` reads `stat->reg + 1` only if `stat->size > 16` and returns `U64_MAX` on error (`aqr107_get_stats()` must skip `U64_MAX`). [F38, F76, F77, F81]
- `bcm_ptp_perout_locked()` requires 1s period and 8ns-scaled `pulse` (`>> 3`) in `[1, min(period, BCM_MAX_PULSE_8NS)]`. `bcm_ptp_rxtstamp()` reads the 8-byte BE32 timestamp after `struct ptp_header` and strips it only if `off < skb->len`. `bcm_phy_set/get_wol()` pack MAC/mask as BE16 into `BCM54XX_WOL_MPD_DATA1/2(2 - i)` and `MASK(2 - i)`. [F56, F82, F83, F86]
- Support both `'fixed-link'` child nodes and 5-cell arrays in `of_phy_is/register_fixed_link()`. `mdio_mux_iproc_switch_fn()` subtracts `EXT_BUS_START_ADDR` (16) for external buses, and `probe()` aligns `res->start` down to `SZ_4K`. `mdio-i2c.c` default ops check `i2c_mii_valid_phy_id()` (blocking `0x10`/`0x11`), RollBall ops require `ROLLBALL_PHY_I2C_ADDR` (`0x51`), and filtered/timed-out reads return `0xffff`. [F43, F90, F92, F94]

## Known Pitfalls
- Pass `led_idx` from `for_each_set_bit()` as `index` to `aqr_phy_led_active_low_set()`. Validate firmware strings with `aqr_fw_validate_get()` and `strscpy()` before `%s`. In `aqr_gen2_fill_interface_modes()`, gate polling on `priv->wait_on_global_cfg` and poll `VEND1_GLOBAL_CFG_100M`. `aqr_gen1_wait_processor_intensive_op()` must call `usleep_range(1000, 5000)` before `phy_read_mmd_poll_timeout()`. [F98, F133, F145, F156]
- In `bcm_ptp_txtstamp()`, use `be16_to_cpu(hdr->sequence_id)`. In `bcm_ptp_adjfine()`, negate negative `scaled_ppm` before `adj = scaled_ppm << 9` and `div_u64(adj, 15625)`. In `bcm_ptp_settime_locked()`, mask `ns >> 36` with `0xfff` for `NCO_TIME_2_CTRL`. [F84, F115, F117]
- Keep `BCM54XX_SHD_SCR2_WSPD_RTRY_LMT_OFFSET` and `MASK` signed `int` in `bcm_phy_downshift_set()`. Compare jiffies with `time_after()`/`time_is_before_jiffies()`. Copy `desired_child` into a `DECLARE_BITMAP` in `mdio_mux_gpio_switch_fn()`. Call `airoha_mdio_reset()` before `airoha_mdio_read/cl45_read()`, and `__delay(1000)` before each `oct_mdio_readq()` poll in `mdio-cavium.c`. [F119, F126, F134, F158, F172]
