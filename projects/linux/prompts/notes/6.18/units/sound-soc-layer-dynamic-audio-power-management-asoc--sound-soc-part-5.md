# SOUND - SOC LAYER / DYNAMIC AUDIO POWER MANAGEMENT (ASoC) — sound/soc (part 5)

Contains ASoC platform, DAI, and machine drivers for MediaTek MT8365, Freescale MXS (SAIF/SGTL5000), and Renesas SuperH (SH7760, SIU, HAC, SSI, Migo-R), along with shared SoundWire machine driver utilities (`sdw_utils`) and core ASoC card, AC'97, and ACPI helpers.

## Architecture & Data Flow

- In `mt8365_afe_private`, `be_data` (`MT8365_AFE_BACKEND_NUM` elements) is indexed by `dai_id - MT8365_AFE_BACKEND_BASE`, whereas `dai_priv` and `dai_on` (`MT8365_AFE_BACKEND_END` elements) use the unshifted DAI ID. Every DAI using `mt8365_afe_i2s_ops` or `mt8365_afe_2nd_i2s_ops` must populate `afe_priv->dai_priv[dai->id]` with a `struct mtk_afe_i2s_priv` instance, as `mt8365_dai_i2s_startup/shutdown/prepare()` unconditionally dereference it as `struct mtk_afe_i2s_priv *`. [F61, F97]
- In MT8365 backend DAIs (`mt8365_dai_int_adda_prepare()`, `mt8365_dai_i2s_prepare()`, `mt8365_afe_hw_gain1_prepare()`), `be->prepared[substream->stream]` must guard enabling refcounted clocks/blocks (`mt8365_dai_enable_adda_on()`, `mt8365_afe_set_i2s_out_enable()`, `mt8365_afe_enable_apll_associated_cfg()`) and be cleared in `.shutdown`. `mt8365_dai_configure_dmic()` must set `dmic_data->dmic_channel = dai->symmetric_channels` before `mt8365_dai_enable/disable_dmic()` pass it to `get_chan_reg()`. [F10, F54]
- In `mt8365-afe-pcm.c`, optional register offsets/shifts in `struct mtk_base_memif_data` (`mono_reg`, `mono_shift`, `fs_reg`, `fs_shift`, `hd_reg`) and `memif->irq_usage` use `-1` as the unpopulated sentinel (`0` is valid; test `< 0` or `>= 0`). In `mt8365_afe_fe_hw_params()`, program the end register with `memif->phys_buf_addr + memif->buffer_size - 1` at `reg_ofs_base + 4` for `MT8365_AFE_MEMIF_TDM_IN` (`AFE_HDMI_IN_2CH_END`) and `+ 8` for all other FE memifs. [F42, F62]
- Every `MT8365_CLK_*` enum (`0 .. MT8365_CLK_NUM - 1`) must have a non-NULL entry in `aud_clks[MT8365_CLK_NUM]`, and every `MT8365_TOP_CG_*` enum must be handled in both `get_top_cg_reg()` and `get_top_cg_mask()`. In `mt8365_afe_irq_handler()`, mask `AFE_IRQ_MCU_STATUS` with `AFE_IRQ_MCU_EN` before dispatching periods and writing `AFE_IRQ_MCU_CLR` so DSP interrupts are not cleared by the CPU ISR. [F55, F108]
- In `mxs-saif.c`, `master_saif->ongoing` and `master_saif->cur_rate` are updated in lockstep by `mxs_saif_set_clk()` and `mxs_saif_trigger()`, and `mxs_saif_set_clk()` must reject `rate != master_saif->cur_rate` with `-EINVAL` while `master_saif->ongoing` is non-zero. `mxs_saif_trigger()` must guard start/resume/pause-release with `saif->state == MXS_SAIF_STATE_RUNNING` and stop/suspend/pause-push with `MXS_SAIF_STATE_STOPPED`. When `master_saif->mclk_in_use` is set (`mxs_saif_get_mclk()`), `mxs_saif_trigger()` must not toggle `BM_SAIF_CTRL_RUN` on `master_saif` and `mxs_saif_hw_params()` must skip the `BM_SAIF_STAT_BUSY` check until `mxs_saif_put_mclk()`. [F12, F56, F57]
- In Renesas SIU, `siu_dai_prepare()` calls `siu_dai_spbstart()` only when `port_info->play_cap == 0` (before setting `PLAYBACK_ENABLED`/`CAPTURE_ENABLED`), and `siu_dai_shutdown()` calls `siu_dai_spbstop()` and `siu_dai_stop()` only when clearing the stream bit leaves `port_info->play_cap == 0` and both `playback.rw_flg` and `capture.rw_flg` are 0. [F15, F21]
- In `struct siu_firmware`, the layout must match `"siu_spb.bin"` copied by `siu_probe()`, keeping `yram0..yram4` contiguous because `siu_dai_spbstart()` indexes `ydef = fw->yram0` across `0 .. YRAM_DEF_SIZE - 1`. `siu_pcm_prepare()` must reject `buf_bytes % period_bytes != 0` or `xfer_cnt` outside `1..0x1000000` (paired with `SNDRV_PCM_HW_PARAM_PERIODS` integer constraint in `siu_dai_startup()`). `siu_dai_put_volume()` must validate both `value[0]` and `value[1]` are in `[0, SIU_MAX_VOLUME]` before packing `value[0] | (value[1] << 16)`. [F64, F65, F92]
- In `ssi_hw_params()`, sample widths in `(16, 24]` must be rounded up to `bits = 24` and `channels` validated as an even integer in `[2, 8]` before computing `((channels >> 1) - 1) << CR_CHNL_SHIFT` and `swl = (bits * channels) / 2`. [F94]
- In `asoc_sdw_parse_sdw_endpoints()`, set `soc_end->name_prefix` and `soc_end->include_sidecar` once per `adr_dev` in the outer loop and increment `soc_end++` only at the end of the inner endpoint loop after all `continue` filters. When `check_sdca` is true, apply `dai_info->quirk` filtering only if `(dai_info->quirk & ctx->mc_quirk)` is non-zero; otherwise call `is_sdca_endpoint_present()`. [F76, F120]
- `asoc_sdw_bridge_cs35l56_count_sidecar()`, `asoc_sdw_bridge_cs35l56_add_sidecar()`, and `asoc_sdw_bridge_cs35l56_spk_init()` must gate sidecar counts on `ctx->mc_quirk & SOC_SDW_SIDECAR_AMPS` and `ARRAY_SIZE(bridge_cs35l56_name_prefixes)` in lockstep. In `asoc_sdw_cs_spk_feedback_rtd_init()`, index `ch_slot` by `ch_map->cpu` while looking up codec DAIs by loop index `i`. In `asoc_sdw_hw_params()`, capture streams must verify `ch >= num_codecs` and `ch % num_codecs == 0` before `GENMASK(ch / num_codecs - 1, 0)`. [F60, F79, F88]
- In `rt_amp_add_device_props()`, `rt711_add_codec_device_props()`, and `rt_sdca_jack_add_codec_device_props()`, `props[]` passed to `fwnode_create_software_node()` must retain a trailing zeroed sentinel within `SOC_SDW_MAX_NO_PROPS`, and `pdata->bq_params_cnt <= RT_AMP_MAX_BQ_REG`. [F71]
- When `snd_soc_acpi_id_present()` matches via `machine->comp_ids`, it must copy the matched `comp_ids->codecs[i]` into `machine->id`. In `snd_soc_acpi_sdw_link_slaves_found()`, check `peripheral->id.unique_id == SDW_UNIQUE_ID(adr)` only when `reported_part_count > 1` (after verifying `reported_part_count == expected_part_count`). [F45, F81]
- In `soc-card.c`, `snd_soc_card_probe()` and `snd_soc_card_late_probe()` must set `card->probed = 1` only after `card->probe`/`late_probe` succeed, and `snd_soc_card_remove()` must check `card->probed` before calling `card->remove(card)` and resetting `card->probed = 0`. [F124]

## Synchronization

- In `mt8365_afe_pcm_dev_probe()`, initialize `afe->regmap`, `afe->memif`, and `afe->irqs` (including `irq_data` pointers) before `devm_request_irq()` registers `mt8365_afe_irq_handler()`. In `camelot_pcm_open()`, set `cam->rx_ss` or `cam->tx_ss` before `dmabrg_request_irq()`, and call `dmabrg_free_irq()` in `camelot_pcm_close()`. [F19, F22]
- In `sound/soc/mediatek/mt8365/`, updates to `top_cg_ref_cnt`, `afe_on_ref_cnt`, `adda_afe_on_ref_cnt`, and `i2s_out_on_ref_cnt` and their `regmap_update_bits()` calls must hold `spin_lock_irqsave(&afe_priv->afe_ctrl_lock, flags)`. Toggling `AFE_I2S_CON1` bit 0 (`MT8365_AFE_IO_I2S` with `adda_link` or `MT8365_AFE_IO_INT_ADDA` playback) must use `mt8365_afe_set_i2s_out_enable()`, and toggling `AFE_ADDA_UL_DL_ADDA_AFE_ON` across ADDA and DMIC must use `mt8365_dai_enable/disable_adda_on()`. `mt8365_afe_enable/disable_apll_tuner_cfg()` acquire `afe_priv->afe_clk_mutex` (`apll_tuner_ref_cnt`), so they and `mt8365_afe_enable/disable_apll_associated_cfg()` must only run in sleepable context outside `afe_ctrl_lock`. [F50, F51, F125, F126]
- `mxs_saif_trigger()` runs in atomic trigger context and must only use non-sleeping `clk_enable()`, `clk_disable()`, and `udelay()`, relying on `mxs_saif_startup()` / `mxs_saif_hw_params()` for `clk_prepare()`. In `hac.c`, `hac_read_codec_aux()` and `hac_ac97_write()` must wrap `HACTSR` clear and `HACCSDR`/`HACCSAR` writes in `local_irq_disable()` / `local_irq_enable()`, re-enabling IRQs before `udelay(1)` polling. [F127, F131]
- In `sdw_utils`, DAI lookups before `snd_soc_register_card()` (`is_sdca_endpoint_present()`) must call `snd_soc_find_dai_with_mutex()`, whereas lookups inside `.rtd_init` callbacks (`asoc_sdw_cs_spk_feedback_rtd_init()`) must call `snd_soc_find_dai()` (`client_mutex` is already held). [F133]
- In `soc-card.c`, `jack_new()` must initialize `jack->mutex`, `jack->card`, `jack->pins`, `jack->jack_zones`, and `jack->notifier` before `snd_jack_new()` or `snd_soc_jack_add_pins()`. `snd_soc_card_get_kcontrol()` must return `NULL` when `!name` and use `snd_ctl_find_id_mixer(soc_card->snd_card, name)` rather than walking `controls` unlocked. [F27, F28, F135]

## Object Lifetimes

- `snd_soc_alloc_ac97_component()` and `snd_soc_new_ac97_component()` return `ERR_PTR` (never `NULL`); after `device_initialize(&ac97->dev)`, release `ac97` via `put_device(&ac97->dev)`, never `kfree()`. `snd_soc_free_ac97_component()` must tear down in reverse order: `snd_soc_ac97_free_gpio(ac97)`, `device_del(&ac97->dev)`, `ac97->bus = NULL`, then `put_device(&ac97->dev)`. [F2, F36]
- `rt711_add_codec_device_props()`, `rt_sdca_jack_add_codec_device_props()`, and `rt_amp_add_device_props()` must call `fwnode_handle_put(fwnode)` after `device_add_software_node()`. Their `.init` callers must run before `snd_soc_register_card()` and pair with `.exit` callbacks (`device_remove_software_node()` and `put_device()`) via `asoc_sdw_mc_dailink_exit_loop()`. [F6, F118]
- `mt8365_afe_disable_main_clk()` must reverse `mt8365_afe_enable_main_clk()` in exact LIFO order (`mt8365_afe_disable_afe_on()`, `mt8365_afe_disable_top_cg(MT8365_TOP_CG_AFE)`, then `MT8365_CLK_TOP_AUD_SEL`). `mt8365_afe_disable_apll_associated_cfg()` must reverse `mt8365_afe_enable_apll_associated_cfg()` (APLL tuner cfg, tuner top CG, HD engen, 22M/24M top CG, then `MT8365_CLK_ENGEN1`/`2`). [F8, F9]
- In `mt8365_dai_i2s_startup/shutdown()`, consumer-mode capture (`SND_SOC_DAIFMT_CBP_CFP`) gates `MT8365_TOP_CG_I2S_IN` instead of `clocks[i2s_data->clk_id_in]`, and shutdown calls `mt8365_afe_disable_apll_associated_cfg()` only if `be->prepared[substream->stream]` is true. In `mt8365_afe_fe_hw_free()`, only call `snd_pcm_lib_free_pages()` and `mt8365_afe_emi_clk_off()` when `!fe_data->use_sram`. [F111, F144]
- Release every `of_parse_phandle()` node in `mxs_saif_probe()` and `mxs_sgtl5000_probe()` with `of_node_put()` on all paths. In `siu_pcm_free()`, call `cancel_work_sync()` on `capture.work` and `playback.work` before `siu_free_port(port_info)`. In `snd_soc_acpi_find_package()`, `kfree(buffer.pointer)` on every path after `acpi_evaluate_object_typed()` returns `AE_OK`. [F14, F16, F113]

## API Contracts

- `is_sdca_endpoint_present()` returns `1` (present), `0` (absent), or `< 0` (errno); `asoc_sdw_parse_sdw_endpoints()` must check `ret < 0` to abort and `!ret` to skip. `hac_get_codec_data()` returns remaining retries `i` (non-zero on success, `0` on failure), which `hac_read_codec_aux()` checks to break and return `val` instead of `~0`. [F31, F85]
- `mt8365_afe_fs_timing()` returns `0..14` or `-EINVAL`; store in signed `int` and check `fs >= 0` before `get_iir_coef()` or bitshifts. `mt8365_dai_set_priv()` `memcpy`s `priv_size` bytes from `priv_data`, so `priv_size` must match the source object size (e.g., `sizeof(mt8365_i2s_priv[i])`). [F43, F96]
- `snd_soc_acpi_find_package()` resets `pkg_ctx->data_valid = false`, requires `myobj->package.count == pkg_ctx->length` before `acpi_extract_package()`, and returns `AE_OK` on failure so scanning continues; `snd_soc_acpi_find_package_from_hid()` must check both `!ACPI_FAILURE(status)` and `ctx->data_valid`. `snd_soc_acpi_mach` tables must end with a zeroed sentinel (`id[0] == 0 && !comp_ids`) and be non-`const` if `comp_ids` is used. `asoc_sdw_find_codec_info_acpi()` uses `memcmp(..., ACPI_ID_LEN)`, requiring a zero-padded 16-byte buffer. [F44, F67, F68, F107]
- `sdw_utils` machine drivers must set `card->drvdata` to `struct asoc_sdw_mc_private *`, initialize `ctx->codec_info_list_count = asoc_sdw_get_codec_info_list_count()`, and call `asoc_sdw_mc_dailink_exit_loop(card)` on teardown/error to reset `rtd_init_done` in `codec_info_list[]`. Export all `sdw_utils` symbols with `EXPORT_SYMBOL_NS(..., "SND_SOC_SDW_UTILS")`. [F47, F102, F140]
- `asoc_sdw_count_sdw_endpoints()` and `asoc_sdw_parse_sdw_endpoints()` require a trailing `num_adr == 0` sentinel in `links` and zero-initialized `*num_devs`/`*num_ends` counters. `asoc_sdw_find_dailink()` requires a zero-initialized `asoc_sdw_dailink` array sized for all endpoints (plus sentinel). Multi-amp `.rtd_init` callbacks (`asoc_sdw_cs_spk_rtd_init`, `asoc_sdw_ti_spk_rtd_init`, `asoc_sdw_rt_amp_spk_rtd_init`) must loop via `for_each_rtd_codec_dais(rtd, i, codec_dai)` because `asoc_sdw_rtd_init()` sets `rtd_init_done` on the first DAI. `asoc_sdw_cs_spk_feedback_rtd_init()` requires `num_cpus <= 8` and `num_codecs / num_cpus` in `1..4`. [F69, F70, F78, F142]
- Cards binding `siu_component` must have `card->dev` on a `platform_device` with `pdev->id` in `[0, SIU_PORT_NUM)`. `snd_soc_ac97_gpio_chip` must set `.can_sleep = 1`, and `snd_soc_set_ac97_ops_of_reset()` requires a mutable `ops` struct paired with `snd_soc_set_ac97_ops(NULL)` on teardown. Jacks using `snd_soc_jack_add_pins()` must be created via `snd_soc_card_jack_new_pins()`, not `snd_soc_card_jack_new()`. [F100, F132, F134, F138]

## Error Handling

- Check `kzalloc()` (`dlc`) and `_asoc_sdw_get_codec_name()` (`sdw_codec_name`) for `NULL` in `is_sdca_endpoint_present()`. In `mt8365_afe_set_i2s_out_enable()`, initialize `i2s_data = NULL` and check non-NULL after the lookup loop. [F30, F33]
- Capture `platform_get_irq()` in a signed `int` and check `< 0` in `mt8365_afe_pcm_dev_probe()` and `mxs_saif_probe()`. Check every `clk_enable()` return in `mxs_saif_hw_params()` and `mxs_saif_trigger()`, unwinding `clk_disable(master_saif->clk)` if `clk_enable(saif->clk)` fails. [F34, F35]
- Check `!IS_ERR(priv->pin_states[i])` before `pinctrl_select_state()` in `mt8365_mt6357_int_adda_startup/shutdown()`. In `snd_soc_ac97_parse_pinctl()`, pass `PTR_ERR()` of the specific failed GPIO field (`sync_gpio`, `sdata_gpio`, `reset_gpio`) to `dev_err_probe()`. [F41, F75]

## External Contracts

- `SOC_SDW_DAI_TYPE_AMP` entries in `codec_info_list[]` relying on `asoc_sdw_rtd_init()` for `spk:<name>` must set `.component_name`. For UCM compatibility, append `"-sdca"` when `name_prefix` matches `need_sdca_suffix` (`"rt711"`, `"rt713"`) in `asoc_sdw_rt_sdca_jack_rtd_init()`, and format `"rt714"` as `"mic:rt715-sdca"` in `asoc_sdw_rt_dmic_rtd_init()`. [F46, F73]

## Known Pitfalls

- In `mt8365_afe_get_cm_update_cnt()`, compute `ch_pair` with ceiling division (`(channel / 2) + 1` when odd) and keep the descending `switch (channel)` fallthroughs from `16` to `1`. In `mt8365_afe_set_2nd_i2s_asrc()`, compute `FIELD_PREP(IIR_STAGE_MASK, ((u32)coef_count / 6) - 1)` only when `coef != NULL`. In `mt8365_dai_set_adda_in_enable()` and `mt8365_dai_dmic_shutdown()`, wait `usleep_range(125..150, 300)` after clearing UL source enable before disabling `adda_on` or `MT8365_TOP_CG_DMIC*_ADC`. [F82, F90, F95, F110]
- In `mxs-saif.c`, clear `BM_SAIF_CTRL_SFTRST` and `BM_SAIF_CTRL_CLKGATE` before writing `SAIF_CTRL`, and return `-EBUSY` if `BM_SAIF_STAT_BUSY` is set. In `mxs_saif_trigger()`, access `SAIF_DATA` twice on start, and `udelay(USEC_PER_SEC / master_saif->cur_rate)` after clearing `BM_SAIF_CTRL_RUN` before `clk_disable()`. [F114, F115]
- Preserve descending `switch` fallthroughs (`++i`) in `ssi_hw_params()` and `ssi_set_clkdiv()`. Scale offsets added to `u32 __iomem *` fields (`pram`, `xram`, `yram`, `reg`) in `struct siu_info` by `/ sizeof(u32)`. Use `SNDRV_DMA_TYPE_CONTINUOUS` (never `SNDRV_DMA_TYPE_DEV`) in `camelot_pcm_new()`. [F84, F98, F130]
- Use `asoc_sdw_startup()` / `asoc_sdw_shutdown()` wrappers in `snd_soc_ops` rather than casting `sdw_startup/shutdown_stream()`. Keep `CODEC_NAME_SIZE` at 7 (`soc_sdw_rt_amp.c`) and 6 (`soc_sdw_rt_mf_sdca.c`) so `snprintf()` truncates `dai->name` to the 5/6-char codec prefix. [F101, F105]
