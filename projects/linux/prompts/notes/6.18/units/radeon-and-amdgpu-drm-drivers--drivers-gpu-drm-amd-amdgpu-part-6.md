# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 6)

Core AMDGPU infrastructure for TTM memory management, GPU rings and software ring muxing, synchronization (`amdgpu_sync`, `amdgpu_seq64`), reset domains, microcode (`amdgpu_ucode`), RAS EEPROM/UMC page retirement, RLC/SDMA helpers, scheduler priority ioctls, and Secure Display debugfs.

## Architecture & Data Flow
- In `amdgpu_ring`, `ring_size` is in bytes (`extra_bytes` is added only to `ring_obj` BO size, never `ring_size`/`buf_mask`), whereas `wptr`, `rptr`, `max_dw`, `count_dw`, and `buf_mask` (`(ring_size / 4) - 1`) are in DWords. Emission helpers (`amdgpu_ring_write/write_multiple/insert_nop`) index `ring[]` with `wptr & buf_mask`, mask `wptr` with `ptr_mask`, and decrement `count_dw`; wrap-around math (`amdgpu_ring_patch_cond_exec`, `amdgpu_ring_mux_copy_pkt_from_sw_ring`, `amdgpu_ring_mux_get_rptr`) adds `ring_size >> 2`. Writeback offsets from `amdgpu_device_wb_get` (`rptr/wptr/fence/trail_fence/cond_exe_offs`) are DWord indices: `amdgpu_ring_get_gpu_addr` multiplies `offset` by 4, while `amdgpu_ring_get_cpu_addr` indexes `adev->wb.wb[offset]` directly. In `amdgpu_ring_to_mqd_prop`, set `prop->hqd_active = true` only for `AMDGPU_RING_TYPE_KIQ`. [F1103, F1119, F1120, F1155, F1162, F1183]
- `amdgpu_ring_mux_start_ib` sets `chunk->cntl/de/ce_offset` to `ring->buf_mask + 1`; `amdgpu_mux_resubmit_chunks` must check `<= e->ring->buf_mask` before `amdgpu_ring_patch_cntl/ce/de`. When `mux->s_resubmit` is true under `mux->lock`, `amdgpu_mux_resubmit_chunks` sets `mux->wptr_resubmit = chunk->end` per chunk, deletes `resubmit_timer`, and clears `s_resubmit = false`; in `amdgpu_ring_mux_set_wptr` for `hw_prio <= AMDGPU_RING_PRIO_DEFAULT`, clamp `e->sw_cptr` to `wptr_resubmit` and skip copying if `wptr_resubmit >= wptr`. [F1086, F1105, F1106]
- `struct ttm_tt ttm` must be at offset 0 of `struct amdgpu_ttm_tt` for `(void *)` casts (`amdgpu_ttm_tt_discard_user_pages`, `amdgpu_ttm_gart_bind_gfx9_mqd`, `amdgpu_ttm_tt_get_userptr`). In `amdgpu_ttm_backend_unbind`, `amdgpu_ttm_tt_unpin_userptr` and imported `dma_buf_unmap_attachment` (`ttm->sg = NULL`) must run before returning on `!gtt->bound` or `gtt->offset == AMDGPU_BO_INVALID_OFFSET`. [F1110, F1168]
- `amdgpu_res_cursor` stores a byte-addressed `drm_buddy_block *` for `TTM_PL_VRAM` and a page-addressed `drm_mm_node *` (`<< PAGE_SHIFT` in `amdgpu_res_first/next`) for `TTM_PL_TT`, `AMDGPU_PL_DOORBELL`, and `AMDGPU_PL_MMIO_REMAP`; never downcast `AMDGPU_PL_PREEMPT` via `to_ttm_range_mgr_node` or `amdgpu_gtt_mgr_has_gart_addr`. Steps in `amdgpu_res_next(cur, size)` must not exceed `cur->size`, and skipping a cleared block via `amdgpu_res_cleared(&cursor)` in `amdgpu_ttm_clear_buffer` must call `amdgpu_res_next(&cursor, cursor.size)` before `continue`. [F1109, F1131, F1166]
- In `amdgpu_ttm_init`, fixed-offset VRAM reservations (`amdgpu_bo_create_kernel_at`) must immediately follow `amdgpu_vram_mgr_init`. `amdgpu_ttm_set_buffer_funcs_status` updates `buffer_funcs_enabled`, `high_pr`/`low_pr` entities (destroying `high_pr` if `low_pr` init fails), `man->move` (putting/NULLing on disable), and `man->size` (`real_vram_size` vs `visible_vram_size`) in lockstep. [F1055, F1107, F1172]
- In `amdgpu_bo_move`, direct `TTM_PL_SYSTEM` <-> `TTM_PL_VRAM` moves when `buffer_funcs_enabled` is true must set `hop` to `TTM_PL_TT` and return `-EMULTIHOP` before `amdgpu_bo_move_notify` or `amdgpu_move_blit`. `amdgpu_copy_buffer` and `amdgpu_ttm_fill_mem` must compute `num_loops` via `DIV_ROUND_UP`/`DIV_ROUND_UP_ULL`. `amdgpu_ttm_map_buffer` sizes the IB to `num_dw * 4 + num_bytes` (`num_dw = ALIGN(copy_num_dw, 8)`), placing inline GART PTEs at `job->ibs[0].gpu_addr + num_dw * 4` and `&job->ibs[0].ptr[num_dw]` after `amdgpu_ring_pad_ib`. [F1142, F1153, F1169]
- In `amdgpu_ras_eeprom.c`, size/step I2C buffers and offsets by `RAS_TABLE_RECORD_SIZE` (24B) via `__encode_table_record_to_buf`/`__decode_table_record_from_buf`, never `sizeof(struct eeprom_table_record)`. Map indices off `ras_fri` modulo `ras_max_record_count` (`RAS_RI_TO_AI`), splitting multi-record I2C transfers across wrap at index 0; in `amdgpu_ras_eeprom_append_table`, compute `ras_num_recs = (b + ras_max_record_count - ras_fri) % ras_max_record_count`. [F1114, F1116, F1154]
- Modifying `control->ras_num_recs` (`amdgpu_ras_eeprom_append/reset_table`) requires updating `tbl_hdr` (`tbl_size`, `checksum`), `tbl_rai`, and `amdgpu_ras_debugfs_set_ret_size` under `ras_tbl_mutex`. `amdgpu_ras_eeprom_reset_table` also zeroes `ras_num_bad_pages`, `ras_num_mca_recs`, `ras_num_pa_recs`, `ras_fri`, `bad_channel_bitmap`, and `con->update_channel_flag`, and notifies SMU (`amdgpu_dpm_send_hbm_bad_pages_num/bad_channel_flag`). Setting `1 << record[i].mem_channel` in `bad_channel_bitmap` requires `mem_channel < BITS_PER_TYPE(bad_channel_bitmap)` and `con->update_channel_flag = true` (cleared by `amdgpu_umc_handle_bad_pages` after notifying SMU). [F1099, F1100, F1101, F1150]
- In `gfx_firmware_header_v1_0`, `jt_offset` and `jt_size` are DWords: multiply by 4 in byte calculations (`amdgpu_ucode_init_single_fw/patch_jt/init_bo`), but not when indexing `__le32 *` in `amdgpu_gfx_rlc_setup_cp_table`. Each `adev->firmware.ucode[]` entry must add `ALIGN(ucode_size, PAGE_SIZE)` to `fw_size` before `amdgpu_ucode_create_bo`. `amdgpu_ucode_init_bo` may skip repopulating `fw_buf` on reset/suspend only when `!amdgpu_sriov_vf(adev)`, and must refresh `fw_buf_mc` via `amdgpu_bo_fb_aper_addr` when `amdgpu_virt_xgmi_migrate_enabled(adev)`. [F1113, F1126, F1127]
- `adev->umc.active_mask` must be `unsigned long` (`node_inst_num * umc_inst_num <= BITS_PER_LONG`), decoded by `/ umc_inst_num` and `% umc_inst_num` (`amdgpu_umc_loop_all_aid`) when `aid_mask != 0`, or as `node_inst_num` bits (`LOOP_UMC_NODE_INST`) when `aid_mask == 0`. In `amdgpu_sync_test_fence`, `fence_owner` checks for `UNDEFINED`, `KFD`, and `VM` precede `switch (mode)`. In `amdgpu_seq64_alloc`, scale `bit_pos` by `sizeof(u64)` for byte `va`/`gpu_addr`, but add unscaled to `u64 *` `cpu_base_addr`. `amdgpu_reset_xgmi_reset_on_init_suspend` suspends valid/hw IP blocks (except `DCE`) in reverse order (`num_ip_blocks - 1`..`0`) then calls `amdgpu_vcn_save_vcpu_bo`. `amdgpu_gfx_rlc_enter/exit_safe_mode` must verify `is_rlc_enabled` and `AMD_CG_SUPPORT_GFX_CGCG/MGCG/3D_CGCG` in `cg_flags`. [F1128, F1132, F1165, F1170, F1176, F1190]

## Synchronization
- `amdgpu_device_lock_reset_domain` sets `in_gpu_reset = 1` before `down_write(&reset_domain->sem)`, and `unlock_reset_domain` clears `in_gpu_reset = 0` before `up_write`; `amdgpu_reset_pending(domain)` requires holding `domain->sem`. In `amdgpu_reset_xgmi_reset_on_init_perform_reset`, lock `reset_cntl->reset_lock` and set `active_reset` on all hive devices before queueing `xgmi_reset_work`, holding `reset_lock` until `flush_work` completes. [F1061, F1062, F1063]
- `amdgpu_ring_reset_helper_begin/end` keep `ring->sched` stopped (`drm_sched_wqueue_stop`) across backup, ring test, `guilty_fence` completion, and `amdgpu_ring_commit`. `amdgpu_sdma_reset_engine` holds `engine_reset_mutex` and, when `!caller_handles_kernel_queues`, stops `gfx_ring->sched` (and `page_ring->sched`) before stopping kernel queues and soft-resetting. In `amdgpu_ring_soft_recovery`, check `!dma_fence_is_signaled_locked(fence)` and call `dma_fence_set_error(fence, -ENODATA)` under `spin_lock_irqsave(fence->lock, flags)`. [F1065, F1066, F1075]
- `amdgpu_ring_mux_copy_pkt_from_sw_ring`, `amdgpu_mux_resubmit_chunks`, `amdgpu_ring_mux_set_wptr`, and `amdgpu_mcbp_trigger_preempt` require `mux->lock`. Because process context uses `spin_lock(&mux->lock)`, timer `amdgpu_mux_resubmit_fallback` must use `spin_trylock(&mux->lock)` and reschedule `resubmit_timer` via `amdgpu_ring_mux_schedule_resubmit` on contention. [F1068, F1069]
- In `amdgpu_bo_move` to `TTM_PL_SYSTEM` from `TTM_PL_TT` or `AMDGPU_PL_PREEMPT`, `ttm_bo_wait_ctx(bo, ctx)` must succeed before `amdgpu_ttm_backend_unbind` and `ttm_resource_free`. `amdgpu_ttm_bo_eviction_valuable` must return `false` for `AMDGPU_PL_PREEMPT`. Callers of `amdgpu_ttm_map_buffer` must hold `gtt_window_lock` across the chunk loop (window 0 for src, 1 for dst) and advance `amdgpu_res_cursor` by the clamped `*size`. [F1072, F1108, F1202]
- `__amdgpu_ras_eeprom_write/read`, `amdgpu_ras_eeprom_append_table`, and `amdgpu_ras_eeprom_update_header` require `control->ras_tbl_mutex` and take `down_read(&adev->reset_domain->sem)` inside it (`ras_tbl_mutex -> reset_domain->sem`). In `amdgpu_ras_eeprom_append`, EEPROM-only flags in bits 0..47 of `record[i].retired_page` (`(uint64_t)nps << UMC_NPS_SHIFT`) must be cleared before returning on all paths; widen `nps` to `uint64_t` before shifting by `UMC_NPS_SHIFT` (40) or `58` (also in `amdgpu_umc_pa2mca`). [F1054, F1115, F1147, F1194]
- In `amdgpu_umc_handle_bad_pages`, querying `con->umc_ecc`, retiring pages, and updating `update_channel_flag` require `con->page_retirement_lock`, while radix tree updates in `amdgpu_umc_logs_ecc_err` require `con->umc_ecc_log.lock`. In `amdgpu_umc_pasid_poison_handler` on bare-metal UMC v12+, after `amdgpu_ras_put_poison_req` succeeds, `atomic_inc` `page_retirement_req_cnt` and `poison_consumption_count` before `wake_up(&con->page_retirement_wq)`. [F1076, F1077]
- `amdgpu_securedisplay_debugfs_write` holds `psp->securedisplay_context.mutex` across `psp_prep_securedisplay_cmd_buf`, `psp_securedisplay_invoke`, and reading `securedisplay_cmd` outputs. `amdgpu_sched_process_priority_override` requires `fpriv->ctx_mgr.lock` while iterating `ctx_handles`, whereas `amdgpu_sched_context_priority_override` uses `amdgpu_ctx_get/put`. `amdgpu_sync_resv` requires the `dma_resv` lock (`dma_resv_for_each_fence`), whereas unlocked `amdgpu_sync_kfd` uses `dma_resv_for_each_fence_unlocked`. [F1078, F1079, F1197]

## Object Lifetimes
- `amdgpu_ttm_tt_unpopulate` clears `ttm->pages[i]->mapping = NULL` before returning pages to `adev->mman.ttm_pools[gtt->pool_id]` or `&adev->mman.bdev.pool`. `amdgpu_ttm_tt_set_userptr` pins `current->group_leader` in `gtt->usertask` (`put_task_struct` in `amdgpu_ttm_backend_destroy`), and `amdgpu_ttm_tt_get_usermm` returns `gtt->usertask->mm`. In `amdgpu_ttm_fini`, guard `iounmap(adev->mman.aper_base_kaddr)` with `drm_dev_enter/exit`. [F1048, F1179, F1209]
- When `amdgpu_sdma_init_microcode` uses `duplicate == true`, `amdgpu_sdma_destroy_inst_ctx` must also pass `duplicate == true` so `instance[0].fw` is freed once. In `amdgpu_gfx_rlc_init_microcode_v2_0`, `register_restore` points inside `register_list_format` (`reg_list_format_size_bytes + reg_list_size_bytes`) and must never be `kfree`d. [F1051, F1163]
- In `amdgpu_seq64_map`, if `amdgpu_vm_bo_map/update` fails after `amdgpu_vm_bo_add`, call `amdgpu_vm_bo_del(adev, *bo_va)` before `drm_exec_fini`. Helpers calling `amdgpu_bo_create_reserved` (`amdgpu_gfx_rlc_init_sr/cpt`) must call `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` on success. If `amdgpu_sdma/umc_ras_late_init` fails `amdgpu_irq_get` after `amdgpu_ras_block_late_init`, call `amdgpu_ras_block_late_fini`. In `amdgpu_sync_resv`, breaking from `dma_fence_chain_for_each(f, f)` must sync to `f` and call `dma_fence_put(f)`. [F1053, F1056, F1058, F1133]

## API Contracts
- `amdgpu_sync_peek_fence` returns a borrowed fence pointer, whereas `amdgpu_sync_get_fence` returns a reference requiring `dma_fence_put`. Check `to_drm_sched_fence(f)` and `to_amdgpu_amdkfd_fence(f)` before downcasting fences in `amdgpu_sync.c`, and check `e->fence->context == f->context` before `amdgpu_sync_keep_later` in `amdgpu_sync_add_later`. [F1043, F1156, F1171]
- Pair every successful `amdgpu_ttm_tt_get_user_pages` with one `amdgpu_ttm_tt_get_user_pages_done` or `amdgpu_ttm_tt_discard_user_pages` (nulling `range` if cleanup also runs). In `amdgpu_ttm_tt_set_userptr`, call `amdgpu_ttm_tt_create(bo, 0)` before setting `TTM_TT_FLAG_EXTERNAL`. `amdgpu_ttm_tt_unpin_userptr` must check `ttm->sg && ttm->sg->sgl` and match `amdgpu_ttm_tt_pin_userptr`'s `AMDGPU_GEM_USERPTR_READONLY` DMA direction. [F1045, F1206, F1207]
- `amdgpu_ttm_clear_buffer` requires non-NULL `fence` (`*fence = dma_fence_get_stub()`), while `amdgpu_ttm_copy_mem_to_mem` and `amdgpu_fill_buffer` allow `f == NULL`. `amdgpu_ttm_access_memory` returns positive bytes transferred or `-errno`, whereas `amdgpu_ttm_access_memory_sdma` returns `0` or `-errno`. Check `amdgpu_bo_is_amdgpu_bo(bo)` in `amdgpu_evict_flags` and `amdgpu_ttm_bo_eviction_valuable`, call `amdgpu_gart_invalidate_tlb` after `amdgpu_ttm_gart_bind` in `amdgpu_ttm_alloc_gart`, and verify `amdgpu_res_copyable` (`TTM_PL_FLAG_CONTIGUOUS` on VRAM) before `ttm_bo_move_memcpy` in `amdgpu_bo_move`. [F1092, F1095, F1167, F1205, F1211]
- Pair `amdgpu_ring_alloc` with `amdgpu_ring_undo` or `amdgpu_ring_commit` (which pads to `align_mask` with `insert_nop`, runs `mb()`, and calls `amdgpu_ring_set_wptr` before `end_use`). `amdgpu_ring_patch_cond_exec` requires `offset <= buf_mask` and `ring[offset] == 0`. In `amdgpu_seq64_alloc`, `va` and `cpu_addr` are non-NULL while `gpu_addr` is optional; `amdgpu_seq64_free` takes the process `*va` from `amdgpu_seq64_alloc`, not `*gpu_addr`. [F1089, F1090, F1102, F1104, F1184]
- `__verify_ras_table_checksum` returns `0` when valid, `1..255` on mismatch, and `-errno` on failure. `amdgpu_umc_fill_error_record` shifts byte `retired_page >> AMDGPU_GPU_PAGE_SHIFT` while storing `err_addr` unshifted. `amdgpu_umc_lookup_bad_pages_in_a_row` returns positive PFN count, `0` on `-ENOMEM`, and `-errno` on `amdgpu_umc_pages_in_a_row` failure. `fw_attrs` `.show` callbacks in `amdgpu_ucode.c` are called with `buf == NULL` by `amdgpu_ucode_sys_visible` and must check `if (!buf)` first. [F1081, F1084, F1085, F1096]

## Error Handling
- In `amdgpu_umc_handle_bad_pages`, still invoke `query_ras_error_address` / `ecc_info_query_ras_error_address` when `kcalloc` for `err_data->err_addr` fails (`err_addr_len == 0`) to clear HW status. `amdgpu_sa_bo_new` must set `*sa_bo = NULL` and return `PTR_ERR(sa)` when `drm_suballoc_new` fails. `amdgpu_ucode_request` returns `-ENODEV` on firmware request failure and `-EINVAL` on `amdgpu_ucode_validate` failure without freeing `*fw` (callers use `amdgpu_ucode_release`). [F1083, F1088, F1097]

## External Contracts
- In `amdgpu_ras_eeprom.c`, `tbl_hdr_fmt_size` and `rec_hdr_fmt_size` must match `tbl_hdr_fmt`/`rec_hdr_fmt` lengths, `record.err_type` must be `< AMDGPU_RAS_EEPROM_ERR_COUNT` when indexing `record_err_type_str` in `amdgpu_ras_debugfs_table_read`, and intra-record offset `r` must be reset to `0` after the first loop iteration. `amdgpu_debugfs_ring_read`, `amdgpu_debugfs_virt_ring_read`, and `amdgpu_ttm_vram_read/write` require 4-byte aligned `*pos` and `size` (first 12B of `ring_read` hold `rptr`, `wptr`, driver `wptr`). In `amdgpu_sched_ioctl`, validate `args->in.op` before `amdgpu_ctx_priority_is_valid(args->in.priority)` and convert the user fd via `amdgpu_file_to_fpriv(fd_file(f), &fpriv)`. [F1117, F1122, F1125, F1137, F1214]

## Known Pitfalls
- Use `hash_for_each_safe` whenever pruning `sync->fences` via `amdgpu_sync_entry_free` (`amdgpu_sync_peek_fence/clone/push_to_job`). Cast `page_offset`, `ttm->num_pages`, and `ttm_resource.start` to `u64` before `<< PAGE_SHIFT` in `amdgpu_ttm_io_mem_pfn`, `amdgpu_ttm_tt_pin_userptr`, `amdgpu_ttm_backend_bind`, and `amdgpu_ttm_alloc_gart`; in `amdgpu_ttm_gart_bind_gfx9_mqd`, use `num_xcc = max(1U, adev->gfx.num_xcc_per_xcp)` and `do_div(pages_per_xcc, num_xcc)`. [F1134, F1144, F1152]
- Truncate `-csum` through `u8 csum` before assigning to `uint32_t tbl_hdr.checksum` in `amdgpu_ras_eeprom_correct_header_tag/reset_table/update_header`. In `amdgpu_iomem_read/write`, check `pfn_valid(pfn)` and `p->mapping == adev->mman.bdev.dev_mapping` before `kmap_local_page`, and call `kunmap_local(ptr)` before returning `-EFAULT`. [F1149, F1201]

## Other
- `amdgpu_ttm_vram_mm_access` must call `amdgpu_device_mm_access` with `ALIGN_DOWN(pos, 4)` and 4-byte widths, using read-modify-write for unaligned bytes; `0xffffffff >> (bytes - size) * 8` relies on `while (size)` and `if (size < bytes)` keeping `1 <= bytes - size <= 3`. [F1157, F1185]
