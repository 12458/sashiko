# NETFILTER — net/netfilter (part 3)

Implements Netfilter L4 protocol trackers (TCP, UDP, SCTP, ICMP, ICMPv6, GRE, generic), helpers (SIP, PPTP, SANE, SNMP, TFTP), TCP sequence adjustment (`nf_conntrack_seqadj.c`), procfs/sysctl (`nf_conntrack_standalone.c`), flowtable fastpath/offload (`nf_flow_table_*.c`), and logging (`nf_log*.c`).

## Architecture & Data Flow

- `flow_offload_hash/obj/cmp` hash and `memcmp` `flow_offload_tuple` up to `offsetof(..., __hash)`: key fields must precede `__hash`, metadata follow it, and tuples passed to `flow_offload_lookup` or `rhashtable` must be zero-initialized. `nf_flow_table_iterate()` must check `IS_ERR(tuplehash)` (continue on `-EAGAIN`, break on others) and skip `tuple.dir != 0` before `container_of(..., tuplehash[0])`. [F436, F462, F489]
- `flow_offload_fill_route()` copies `route->tuple[dir].in.encap[i]` in reverse (`num_encaps - 1` down to `0`) into `flow_tuple->encap[j]` and remaps `BIT(i)` of `ingress_vlans` to `BIT(j)` of `in_vlan_ingress`. `nf_flow_offload_rule_alloc()` preallocates `NF_FLOW_RULE_ACTION_MAX` (16) entries without bounds checks in `flow_action_entry_next()`, so `nf_flow_rule_route_ipv4/ipv6()` must not exceed 16 actions. [F463, F475]
- In `nf_flow_offload_*_forward()`, `skb_try_make_writable(skb, thoff + ctx->hdrsize)` must precede `nf_flow_encap_pop()` and NAT/TTL mangling; after `nf_flow_encap_pop()`, reload `iph`/`ip6h` and reduce IPv4 `thoff` by `ctx->offset`. In `nf_ct_seq/sack_adjust()`, `skb_ensure_writable()` must cover `optend` before modifying bytes, re-deriving `tcph` (`skb->data + protoff`) afterwards. [F540, F542]
- In `nf_flow_snat/dnat_port/ip/ipv6` and `nf_ct_seq_adjust` / `nf_ct_sack_block_adjust`, sample old port, IP, `seq`, `ack_seq`, or SACK edges for `inet_proto_csum_replace*()` before overwriting headers; `nf_flow_nat_*_udp` must rewrite a `0` checksum to `CSUM_MANGLED_0`. [F460, F461]
- `nf_flow_exceeds_mtu()` must validate GSO packets (`skb->len > mtu`) via `skb_gso_validate_network_len(skb, mtu)` against `tuple.mtu + ctx->offset`, returning `0` (`NF_ACCEPT`) in `nf_flow_offload_*_forward()` without refreshing/tearing down on oversize. Before `nf_flow_xmit_xfrm()`, `nf_flow_offload_ip/ipv6_hook()` must zero `skb->cb`, set `IPCB/IP6CB(skb)->iif = skb->dev->ifindex`, and set `IPSKB/IP6SKB_FORWARDED`. [F545, F549]
- In `nf_do_netdev_egress()`, if `hook == NF_NETDEV_INGRESS && skb_mac_header_was_set(skb)`, `skb_cow_head(skb, skb->mac_len)` must succeed before `skb_push()`, and `skb_clear_tstamp(skb)` must precede `dev_queue_xmit()`. In `nf_confirm()`, packets at `NF_INET_POST_ROUTING` on an L3 master/VRF (`in_vrf_postrouting(state)`) must return `NF_ACCEPT` immediately without helpers, seqadj, or `nf_conntrack_confirm()`. [F546, F547]
- When `nf_ct_netns_do_get()` first registers hooks for `nfproto`, it must run `nf_ct_tcp_fixup()` to zero `seen[0/1].td_maxwin` on `ESTABLISHED` connections. Keep `ct->proto.tcp.state < TCP_CONNTRACK_MAX` (10) by rejecting `>= MAX` in `nlattr_to_tcp()` and returning early on `IGNORE`/`MAX` in `nf_conntrack_tcp_packet()`. When `new_state == SYN_SENT` and `old_state >= TIME_WAIT` without `IP_CT_TCP_FLAG_CLOSE_INIT` or same-dir `TCP_RST_SET`, `nf_conntrack_tcp_packet()` must fall through to `TCP_CONNTRACK_IGNORE`. [F442, F469, F486]
- In `get_conntrack_index()`, check `rst`, `syn` (with `ack` for `SYNACK_SET`), and `fin` before `ack`. `tcp_options()` must clamp `td_scale <= TCP_MAX_WSCALE` (14); `tcp_init_sender()` and `nlattr_to_tcp()` must zero both `td_scale`s unless both `seen[0/1].flags` have `IP_CT_TCP_FLAG_WINDOW_SCALE`; `nf_ct_tcp_state_reset()` and `tcp_options()` must zero `td_scale` and mask `state->flags &= IP_CT_TCP_FLAG_BE_LIBERAL`. [F446, F456, F483, F499]
- In `tcp_options()`, `tcp_sack()`, and `nf_ct_sack_adjust()`, option loops must verify `>= 2` bytes remain and `opsize >= 2 && opsize <= length` before reading/advancing, using `get_unaligned_be32()` for SACK edges. TCP seq/ACK/SACK comparisons must use `before()`/`after()`, subtracting `offset_before` before comparing peer ACK/SACKs against `correction_pos`. [F468, F503]
- `nf_conntrack_l4proto_tcp.ctnl_timeout.obj_size` must use `TCP_CONNTRACK_TIMEOUT_MAX`. TCP/SCTP init and `*_timeout_nlattr_to_obj` must set `timeouts[0]` to `SYN_SENT` / `CLOSED`. `sctp_new_state()` `default` must return `cur_state` unchanged. In `nf_conntrack_proto_icmp/icmpv6.c`, `invmap` stores target types + 1 (`0` = unmapped), and ICMPv6 `invmap`/`valid_new` and `noct_valid_new` are indexed by `type - 128` and `icmp6_type - 130`. [F455, F470, F488, F507]
- L4 `*_error` validators must only check checksums when `state->hook == NF_INET_PRE_ROUTING && state->net->ct.sysctl_checksum`. `conntrack_pptp_help()` must check `reqlen` against `pptp_msg_size[msg]` (`1 <= msg <= PPTP_MSG_MAX`) and clamp to `sizeof(*pptpReq)`. `nf_conntrack_sane.c:help()` must verify `dataoff < skb->len` and clamp `datalen` to `sizeof(struct sane_reply_net_start)`. `process_register_response()` must reset `c_expires = expires` each loop iteration. [F465, F467, F493, F550]
- `nf_conntrack_standalone_init_sysctl()` must `kmemdup()` `nf_ct_sysctl_table`, rebind per-netns `.data`, and set `.mode = 0444` on global sysctls (`CT_MAX`, `CT_EXPECT_MAX`, `CT_BUCKETS`) when `!net_eq(&init_net, net)`. `nf_conntrack_hash_sysctl()` must sync `nf_conntrack_htable_size_user` from `nf_conntrack_htable_size` before `proc_dointvec()` and after `nf_conntrack_hash_resize()`. [F443, F453]
- `nf_conntrack_standalone_init_proc()` must create `/proc/net/nf_conntrack` (`0440`) owned by `net->user_ns` root. In `ct_seq_show()`, killing an entry via `nf_ct_should_gc()`/`nf_ct_kill()` must decrement `st->skip_elems`. `ct_cpu_seq_show()` and `nf_flow_table_cpu_seq_show()` must check `v == SEQ_START_TOKEN` before dereferencing `st`. [F444, F514, F556]
- `nf_log_buf` sizes `buf` as `S_SIZE + 1` and `nf_log_buf_add()` caps `m->count` at `S_SIZE`. `nf_log_syslog.c` callbacks must check `nf_log_allowed(net)` (`nf_log_all_netns` is `init_net`-only), and `nf_log_dump_sk_uid_gid()` must verify `sk && sk_fullsock(sk) && net_eq(net, sock_net(sk))`, hold `read_lock_bh(&sk->sk_callback_lock)`, and format `fsuid`/`fsgid` in `&init_user_ns`. [F479, F557, F558]

## Synchronization

- `flow_offload_add()` must set `flow->timeout` before `rhashtable_insert_fast()`. Because `flow_offload_lookup()` is RCU-only without a refcount, `flow_offload_del()` must remove both nodes from `rhashtable` before `flow_offload_free()` (`kfree_rcu()`). `flow_offload_teardown()` must gate `flow_offload_fixup_ct()` behind `!test_and_set_bit(NF_FLOW_TEARDOWN, &flow->flags)`. [F406, F412, F529]
- In `nf_flow_table_extend_ct_timeout()` and `ct_seq_show()`, follow `refcount_inc_not_zero(&ct->ct_general.use)` with `smp_acquire__after_ctrl_dep()` before reading `ct->status`, and use `cmpxchg(&ct->timeout, expires, new_timeout)` in `nf_flow_table_extend_ct_timeout()`. Confirmed `ct` accesses to `ct->proto.tcp`, `ct->proto.sctp`, and `nf_conn_seqadj` require `spin_lock_bh(&ct->lock)`. [F413, F414, F524]
- `ct_get_next()` under `rcu_read_lock()` must walk `hlist_nulls_next_rcu()` to the end marker and verify `get_nulls_value(tmp) == i` before returning `h` (and `get_nulls_value(n) == i` at bucket end), restarting on mismatch. In `getorigdst()` / `ipv6_getorigdst()`, copy socket fields under `lock_sock(sk)` before `nf_conntrack_find_get()`, and call `nf_ct_put(ct)` before `copy_to_user()`. [F417, F422]
- `nf_ct_proto_mutex` serializes `cnet->users4/6/bridge` and `nf_ct_bridge_info`; `nf_ct_netns_do_get()` must drop it before `request_module()`, reacquire to recheck `nf_ct_bridge_info`, and drop it before `nf_ct_iterate_cleanup_net()`. In `flow_offload_eth_dst()`, reading `n->nud_state` and `n->ha` requires `read_lock_bh(&n->lock)` before `neigh_release(n)`. [F418, F424]
- `nf_get_nf_dup_skb_recursion()` must use `&current->net_xmit.nf_dup_skb_recursion` on `CONFIG_PREEMPT_RT` and `this_cpu_ptr(&softnet_data.xmit.nf_dup_skb_recursion)` otherwise. `nf_fwd/do_netdev_egress()` always consume `skb` (bracketing `dev_queue_xmit(skb)` with `(*nf_dup_skb_recursion)++`/`--` or calling `kfree_skb(skb)` on error), whereas `nf_dup_netdev_egress()` clones `pkt->skb`. [F395, F538]
- `loggers` and `net->nf.nf_loggers` updates require `nf_log_mutex` and RCU primitives, with `synchronize_rcu()` after unlocking in `nf_log_unregister()`. On `kmalloc()` failure, `nf_log_buf_open()` disables BH and spins on `xchg(&emergency_ptr, NULL)`, which `nf_log_buf_close()` releases before `local_bh_enable()`; never sleep or skip close while open. [F419, F420]

## Object Lifetimes

- `flow_offload_route_init()` consumes `route->tuple[dir].dst` (releasing for `XMIT_DIRECT` or storing in `dst_cache`) and sets `route->tuple[dir].dst = NULL` to avoid double-free. `nf_flow_offload_work_alloc()` sets `NF_FLOW_HW_PENDING` and must clear it on `kmalloc()` failure and before `kfree(offload)` in `flow_offload_work_handler()`, balancing `count_wq_add/del/stats`. For `NF_FLOW_HW`, `nf_flow_offload_gc_step()` must wait for `NF_FLOW_HW_DYING` and `NF_FLOW_HW_DEAD` before `flow_offload_del()`. [F389, F392, F408]
- `cls_flow->cookie` in `nf_flow_offload_init/tuple()` must point to persistent `&flow->tuplehash[dir].tuple`. `nf_flow_table_free()` must unlink `list`, `cancel_delayed_work_sync(&gc_work)`, and run `nf_flow_table_offload_flush()`, teardown, `nf_flow_table_gc_run()`, `nf_flow_table_offload_flush_cleanup()`, and `rhashtable_destroy()`. [F391, F515]
- Because `nf_flow_offload_rule_alloc()`'s `err_flow_match` skips `__nf_flow_offload_destroy()`, `nf_flow_rule_route_ipv4/ipv6()` must not fail after `flow_offload_redirect()` takes `dev_get_by_index()`. `nft_fwd_dup_netdev_offload()` transfers `dev_get_by_index()` to `entry->dev` for `nft_flow_rule_destroy()` to release. [F393, F394]
- `nf_flow_table_block_setup()` splices/frees `block_cb`s under `down_write(&flowtable->flow_block_lock)`, and `nf_flow_table_indr_cleanup()` must run `nf_flow_table_gc_cleanup()` before taking `flow_block_lock`. `nf_flowtable_by_dev_remove()` frees `flow_offload_xdp_ft` via `kfree_rcu()`, and when `list_empty(&elem->head)`, unlinks `elem->hnode` under `nf_xdp_hashtable_lock` and frees `elem` after `synchronize_rcu()`. [F396, F397]
- In `ipv4_conntrack_local()`, bypassing fragments with `nf_ct_is_template(tmpl)` must clear `skb->_nfct = 0` and `nf_ct_put(tmpl)`. In `ct_seq_show()`, exits after `refcount_inc_not_zero()` must jump to `release:` (`nf_ct_put(ct)`). `nf_ct_netns_get/put(NFPROTO_BRIDGE)` and `nf_logger_find_get/put(NFPROTO_INET)` must acquire/release both `IPV4` and `IPV6` with rollback on failure. [F398, F399, F402, F405]
- `nf_ct_set_timeout()` must drop `h->timeout_find_get()` via `__nf_ct_timeout_put()` on error, and `nf_ct_destroy_timeout()` must null `timeout_ext->timeout`. `nf_ct_gre_keymap_destroy()` must unlink, `kfree_rcu()`, and null `keymap[dir]` under `spin_lock_bh(&keymap_lock)`. `netfilter_log_sysctl_exit()` and `nf_lwtunnel_net_exit()` must `kfree(table)` only when `!net_eq(net, &init_net)`. [F400, F401, F404]

## API Contracts

- `flow_offload_alloc()` increments `ct->ct_general.use`, and `flow_offload_add()` does not free `flow` on failure, so callers must call `flow_offload_free(flow)` on negative return. [F390]
- `ct_sip_get_header`, `ct_sip_get_sdp_header`, `ct_sip_parse_request`, `ct_sip_parse_header_uri`, and `ct_sip_parse_numerical_param` return `1` (match), `0` (absent), or `-1` (malformed), while `ct_sip_parse_address_param` returns `1`/`0`. `ct_sip_get/next_header` must set `*matchoff` before returning `-1`. Non-void `nf_nat_sip_hooks` callbacks must return `NF_ACCEPT` or `NF_DROP`. [F426, F427, F428]
- `nf_ct_seq_offset()` takes host `u32 seq`, while `nf_ct_seqadj_set()` takes `__be32 seq`; in `tcp_in_window()`, call `nf_ct_seq_offset()` with `!dir` and `ack - 1`. `inet_proto_csum_replace2/4/16()` takes `pseudohdr = true` for L3 addresses and `false` for L4 ports or TCP seq/SACKs. [F439, F544]
- `for_each_sctp_chunk` requires prior `do_basic_checks()` verification that `sch->length != 0`, and any `map` passed to `do_basic_checks()` must be zeroed and `>= 256` bits. L4 `ctnl_timeout` callbacks must scale `NLA_U32` attributes by `* HZ` (`ntohl`) on input and `/ HZ` (`htonl`) on output. `bpf_xdp_flow_lookup()` must verify `opts_len == NF_BPF_FLOWTABLE_OPTS_SZ` (4) and set `opts->error` on `NULL` returns. [F464, F521, F553, F554]

## Error Handling

- L4 packet/error handlers (`nf_conntrack_*_packet`, `nf_conntrack_inet_error`) must return `-NF_ACCEPT`, `-NF_REPEAT`, or `NF_DROP` (0), never negative errnos, and log invalid packets via `nf_l4proto_log_invalid()` / `nf_ct_l4proto_log_invalid()`. [F425, F559]
- `nf_ct_seq/sack_adjust()` return `1` (success) or `0` (failure); `nf_ct_seqadj_set()` must verify `nfct_seqadj(ct) != NULL` before setting `IPS_SEQ_ADJUST_BIT`. `nf_flow_offload_*_forward()` return `1` (offloaded), `0` (`NF_ACCEPT`), or `-1` (`NF_DROP`). `flow_offload_tuple.dst_cache` is only valid when `xmit_type` is `XMIT_NEIGH` or `XMIT_XFRM`. L4 `ctnl_timeout.nlattr_to_obj` must fall back to per-netns timeouts when `data == NULL`. [F429, F430, F432, F433, F434]

## External Contracts

- `getorigdst()` / `ipv6_getorigdst()` must zero-initialize stack `nf_conntrack_tuple` (and `sin.sin_zero`), and `tcp_to_nlattr()` must zero-initialize `struct nf_ct_tcp_flags tmp = {}`. `nf_hooks_lwtunnel_set()` must reject `!enable` with `-EBUSY` once `nf_hooks_lwtunnel_enabled` is active. [F437, F552, F561]

## Known Pitfalls

- Recompute `iph`/`ip6h` after `pskb_may_pull(skb, thoff + ctx->hdrsize)` in `nf_flow_tuple_ip/ipv6()`. In `sip_help_tcp()`, pass `&dptr`/`&msglen` to `process_sip_msg()` and update `diff = msglen - origlen`, `tdiff += diff`, and `datalen = datalen + diff - msglen`. Bound `nf_conntrack_sip.c` payload scans by `limit - cp/dptr`, and in `ct_sip_get_sdp_header()`, only dereference `thdr` when `term != SDP_HDR_UNSPEC`. [F448, F452, F471, F519]
- `gre_pkt_to_tuple()` must request only 8 bytes in `skb_header_pointer()` for `_pgrehdr`. In `nf_conntrack_icmpv6_redirect()`, do not dereference `rd_msg` after the second `skb_header_pointer(..., &tmp.nd_opt)` call sharing union `tmp`. [F466, F512]
- In `nf_flow_table_offload.c`, `tuplehash[dir].tuple` supplies `xmit_type`, encap `dst_cache`, and popped VLANs, while `tuplehash[!dir].tuple` supplies `XMIT_NEIGH` `iifidx`, `src_v4`, decap `dst_cache`, and pushed headers; `flow_offload_mangle()` requires 4-byte aligned offsets/masks; `used_keys`/`enc_keys` require `BIT_ULL()`. [F476, F496, F498]
- Use signed `nf_flow_timeout_delta()` for flowtable timeouts, keeping `timeout` as `s32` clamped to `>= 0` in `flow_offload_fixup_ct()`. Use `IPS_*_BIT`/`NF_FLOW_*` indices with bitops and `IPS_*`/`NF_FLOWTABLE_*` masks with `&`/`|`. In `tcp_in_window()`, test `(tcp_flag_word(tcph) & (TCP_FLAG_ACK|TCP_FLAG_RST)) == (TCP_FLAG_ACK|TCP_FLAG_RST)` for equality. [F484, F501, F502, F520]
- Use `div_s64(delta_time, NSEC_PER_SEC)` in `ct_show_delta_time()`. In `dump_mac_header()`, check `p >= skb->head` when subtracting `ETH_HLEN` for `ARPHRD_SIT`. In `nf_log_proc_dostring()`, set `buf[0] = '\0'` before `proc_dostring()` on write. [F481, F500, F518]
