# BPF [GENERAL] (Safe Dynamic Programs and Tools) — (top level) (part 2)

This component provides core BPF infrastructure, specialized map types, iterators, tracing attachment backends, and low-level synchronization and memory management primitives. It includes the NMI-safe per-CPU BPF memory allocator (`memalloc.c`), resilient queued spinlocks with deadlock detection (`rqspinlock.c`), per-CPU freelists, arena range trees, BPF program/map/task iterators, hardware offload management (`offload.c`), netns links (`net_namespace.c`), BPF tokens (`token.c`), program streams (`stream.c`), ELF build-ID parsing (`lib/buildid.c`), and the tracing/probe BPF subsystem (`kernel/trace/bpf_trace.c`).

## Architecture & Data Flow

- In `kernel/bpf/offload.c`, a `struct bpf_offload_netdev` entry in `offdevs` has `ondev->offdev == NULL` when registered for a device-bound-only program, so any code that accesses `offload->offdev->ops` must only run on true offloaded programs where `bpf_prog_is_offloaded(prog->aux)` (and thus `ondev->offdev != NULL`) holds. [F48]
- In `struct freader` (`lib/buildid.c`), `r->buf != NULL` discriminates between file-backed mode (union arm with `file`, `folio`, `addr`, `folio_off`, `may_fault`) and memory-buffer mode (`r->buf == NULL`, union arm with `data`, `data_sz`), so `freader_cleanup` and `freader_fetch` must check `r->buf` before accessing file/folio fields. [F52]
- In kernel/bpf/range_tree.c, any update to rn_start or rn_last of an inserted struct range_node must remove the node from both rt->it_root and rt->range_size_root via range_it_remove() before mutating the bounds and reinsert it into both trees via range_it_insert(). [F64]
- In kernel/bpf/offload.c, when __bpf_offload_dev_netdev_unregister() migrates progs and maps from an unregistering ondev to an alternate netdev (altdev) on the same bpf_offload_dev, it must update every offload->netdev and offmap->netdev pointer to altdev->netdev before splicing the lists. [F67]
- In kernel/trace/bpf_trace.c, bpf_kprobe_multi_link_attach() must keep cookies[] ordered in lockstep with us.syms[] (via symbols_swap_r before ftrace_lookup_symbols()) and then with link->addrs[] (via bpf_kprobe_multi_cookie_swap) so bpf_kprobe_multi_cookie() can index link->cookies by (addr - link->addrs). [F72]
- In kernel/bpf/rqspinlock.c, both conditional compilation definitions of RES_CHECK_TIMEOUT (#ifndef res_smp_cond_load_acquire and #else) must pass the full argument list (lock, mask, &(ts)) to check_timeout(). [F75]
- In kernel/bpf/memalloc.c, whenever an object is added to an empty c->free_by_rcu list (when __llist_add() returns true in unit_free_rcu() or check_free_by_rcu()), c->free_by_rcu_tail must be updated to that node and copied to c->waiting_for_gp_tail when moving the list to c->waiting_for_gp. [F80]
- In kernel/bpf/queue_stack_maps.c, when queue_stack_map_push_elem() overwrites an entry in a full map (queue_stack_map_is_full(qs) with BPF_EXIST), it must advance qs->tail (wrapping at qs->size) before advancing qs->head so qs->head does not catch up to qs->tail. [F81]

## Synchronization

- `bpf_res_spin_lock()` and `bpf_res_spin_lock_irqsave()` must call `bpf_prog_report_rqspinlock_violation()` before re-enabling interrupts and preemption on lock acquisition failure, and must restore IRQ state and preemption before returning the non-zero error code. [F20]
- Whenever task_vma_seq_get_next or task_vma_seq_stop drops mmap_lock, it must save prev_vm_start and prev_vm_end beforehand (setting prev_vm_start = ~0UL in task_vma_seq_stop when v is non-NULL) and re-lookup the VMA via find_vma(curr_mm, info->prev_vm_end - 1) after relocking rather than dereferencing info->vma. [F28]
- Callers of __pcpu_freelist_push and __pcpu_freelist_pop must disable local interrupts beforehand (or call pcpu_freelist_push / pcpu_freelist_pop), and ___pcpu_freelist_pop must re-verify that head->first is non-NULL after acquiring raw_res_spin_lock(&head->lock). [F29]
- In kernel/bpf/net_namespace.c, struct bpf_netns_link::net is an unreferenced pointer protected by netns_bpf_mutex, and link callbacks (bpf_netns_link_release, bpf_netns_link_update_prog, bpf_netns_link_fill_info) must check that net_link->net is non-NULL (and check_net(net) when accessing live netns state) under netns_bpf_mutex. [F30]
- In bpf_fd_reuseport_array_update_elem, after the lockless check, spin_lock_bh(&reuseport_lock) and write_lock_bh(&nsk->sk_callback_lock) must be acquired and reuseport_array_update_check re-run on re-read osk and reuse; nsk->sk_callback_lock must be unlocked before locking free_osk->sk_callback_lock. [F32]
- In resilient_queued_spin_lock_slowpath (kernel/bpf/rqspinlock.c), after incrementing rqnodes[0].mcs.count, a compiler barrier() must precede initializing node->locked = 0 and node->next = NULL, and smp_wmb() must precede publishing the node via xchg_tail(lock, tail). [F35]
- On timeout or deadlock in resilient_queued_spin_lock_slowpath, a pending waiter must call clear_pending(lock), and an MCS waiter at waitq_timeout must either clear tail via try_cmpxchg_tail(lock, tail, 0) or wait for node->next and set WRITE_ONCE(next->locked, RES_TIMEOUT_VAL) before decrementing rqnodes[0].mcs.count. [F36]
- In kernel/bpf/stream.c, bump allocation from stream_pcpu_page in bpf_stream_page_reserve_elem must be guarded by bpf_stream_page_local_lock(&flags) and call bpf_stream_page_get(page) for each reserved element, while draining stream->log into backlog_head/backlog_tail and reading in bpf_stream_read require stream->lock. [F37]

## Object Lifetimes

- In `kernel/bpf/stream.c`, each `bpf_stream_page` is initialized with `refcount_set(&stream_page->ref, 1)` for `stream_pcpu_page` ownership, incremented via `bpf_stream_page_get(page)` for each reserved `bpf_stream_elem`, and decremented via `bpf_stream_page_put()` both when replaced in `stream_pcpu_page` and when each element is freed. [F12]
- `task_vma_seq_get_next()` must hold a reference on `info->task`, a reference on `info->mm` (`mm_users`), and `mmap_read_lock` on `info->mm` whenever it returns a non-NULL VMA, and must release all three and clear `info->task`, `info->mm`, and `info->vma` to `NULL` whenever it returns `NULL`. [F17]
- In `load_skel()` (`kernel/bpf/preload/bpf_preload_kern.c`), after obtaining `maps_link` and `progs_link` via `bpf_link_get_from_fd()`, `skel->links.dump_bpf_map_fd` and `skel->links.dump_bpf_prog_fd` must be closed with `close_fd()` and zeroed so `iterators_bpf__destroy()` does not close fd 0 or unrelated descriptors of the init process. [F21]
- During bpf_mem_alloc_destroy, each per-CPU bpf_mem_cache must set WRITE_ONCE(c->draining, true), call irq_work_sync(&c->refill_work), and call drain_mem_cache(c) before checking call_rcu_in_progress/call_rcu_ttrace_in_progress and waiting on rcu_barrier() and rcu_barrier_tasks_trace() in free_mem_alloc. [F25]
- In bpf_uprobe_multi_link_attach, link->task, link->link, and each uprobes[i].link and uprobes[i].consumer must be initialized before uprobe_register(), and bpf_uprobe_unregister must call uprobe_unregister_nosync() for all entries followed by uprobe_unregister_sync() before releasing link->task, link->path, or freeing link memory. [F41]
- In bpf_kprobe_multi_link_attach, link->addrs and link->cookies must be sorted together via sort_r and module references acquired via get_modules_for_addrs before register_fprobe_ips is called; in bpf_kprobe_multi_link_release, unregister_fprobe(&kmulti_link->fp) must complete before kprobe_multi_put_modules runs. [F42]
- All `net_device` instances registered with a `struct bpf_offload_dev` via `bpf_offload_dev_netdev_register()` must be unregistered via `bpf_offload_dev_netdev_unregister()` before `bpf_offload_dev_destroy()` is called. [F146]

## API Contracts

- `netns_bpf_prog_attach()` takes ownership of the caller's `prog` reference only when it returns `0` (dropping the previously attached `net->bpf.progs[type]` reference via `bpf_prog_put(attached)`), and must not call `bpf_prog_put(prog)` on any error path. [F4]
- Callers of `bpf_mem_cache_raw_free(ptr)` must ensure `ptr` has already passed through an `rcu_tasks_trace` grace period before calling it, because `bpf_mem_cache_raw_free()` directly invokes `kfree(ptr - LLIST_NODE_SZ)` without RCU deferral. [F11]
- Callers of `bpf_mmap_unlock_get_irq_work` must test its boolean return value (`irq_work_busy`) rather than checking whether `*work_ptr` is `NULL`, because `*work_ptr` is legitimately set to `NULL` when interrupts are enabled and `bpf_mmap_unlock_mm` uses `NULL` to select direct `mmap_read_unlock`. [F45]
- In `kernel/bpf/task_iter.c`, `get_pid_task` must be called with `PIDTYPE_PID` when resolving a thread (`BPF_TASK_ITER_TID` or resuming `common->pid_visiting` in `task_group_seq_get_next`), and with `PIDTYPE_TGID` only when resolving a thread group leader on the initial `!*tid` lookup of `task_group_seq_get_next`. [F51]
- `parse_build_id` must zero-pad the caller's `build_id` buffer from `desc_sz` up to `BUILD_ID_SIZE_MAX` (`memset(build_id + desc_sz, 0, BUILD_ID_SIZE_MAX - desc_sz)`) and only write `*size = desc_sz` when the optional `size` pointer is non-NULL (such as in `build_id_parse_buf`, which passes `NULL`). [F54]
- `range_tree_find` returns `s64` so that it can represent both the full unsigned 32-bit `u32` slot start offset (`rn->rn_start`) on success and `-ENOENT` (`< 0`) when no free range of length `len` exists; callers must store or test its return value as signed before truncating to `u32`. [F57]
- In `kernel/bpf/token.c`, `token->allowed_cmds`, `allowed_maps`, `allowed_progs`, and `allowed_attachs` are 64-bit bitmasks indexed by enum values (`BIT_ULL(...)`), so `bpf_token_allow_map_type` and `bpf_token_allow_prog_type` must bounds-check enum arguments against `__MAX_BPF_*` (`< 64`) before shifting with `BIT_ULL`. [F62]

## Error Handling

- In `bpf_token_create()`, error paths taken after `alloc_file_pseudo()` succeeds must release the inode and file via `fput(file)` rather than `iput(inode)`, because `alloc_file_pseudo()` transfers ownership of `inode` to `file`. [F1]
- In `perf_event_detach_bpf_prog()`, when `event->prog` is non-NULL, failure of `bpf_prog_array_copy()` must fall back to `bpf_prog_array_delete_safe()` and still clear `event->prog = NULL` and call `bpf_prog_put(prog)` after `synchronize_rcu_tasks_trace()`. [F7]
- Callbacks passed to `__bpf_dynptr_copy` (such as `copy_user_data_sleepable`) must return `0` on success and a negative errno on failure, converting positive residual byte counts from `copy_from_user` or short byte counts from `access_process_vm` into `-EFAULT`. [F43]
- Open-coded BPF iterator constructors (`bpf_iter_task_vma_new`, `bpf_iter_css_task_new`, `bpf_iter_task_new`) must set their internal state pointer (`kit->data`, `kit->css_it`, or `kit->pos`) to `NULL` on every error path before returning, because the verifier still invokes the corresponding `_next` and `_destroy` kfuncs. [F46]
- Before calling `netdev_lock_ops` or invoking `netdev->netdev_ops->ndo_bpf` on a `net_device` looked up by ifindex (such as in `bpf_map_offload_map_alloc` or `bpf_prog_dev_bound_init`), the pointer must be validated with `bpf_dev_offload_check(netdev)` to ensure both `netdev` and `netdev->netdev_ops->ndo_bpf` are non-NULL. [F47]
- In `bpf_prog_offload_replace_insn` and `bpf_prog_offload_remove_insns`, `offload->opt_failed` is a sticky flag updated via `offload->opt_failed |= ret`, so once any optimization hook fails (or is absent, defaulting `ret` to `-EOPNOTSUPP`), subsequent `replace_insn` or `remove_insns` callbacks must not be invoked. [F49]
- In `perf_event_detach_bpf_prog`, `event->tp_event->prog_array` can be `NULL` even when `event->prog` is non-NULL; when `old_array` is `NULL`, the function must skip `bpf_prog_array_copy` and still clear `event->prog` and release `prog` after `synchronize_rcu_tasks_trace()`. [F50]

## External Contracts

- Link attachment entry points `bpf_kprobe_multi_link_attach()`, `bpf_uprobe_multi_link_attach()`, and `netns_bpf_link_create()` must reject non-zero `attr->link_create.flags` with `-EINVAL` in addition to checking any link-specific flags (`kprobe_multi.flags` or `uprobe_multi.flags`). [F95]
- In `bpf_kprobe_multi_link_fill_link_info()` and `bpf_uprobe_multi_link_fill_link_info()`, when array buffer pointers are provided with `ucount < link->cnt`, the handler must still set `info->...count = link->cnt`, copy `ucount` entries to user space, and return `-ENOSPC` (while returning `-EINVAL` if buffer pointers and `ucount` are mismatched). [F96]
- In `btf_sysfs_vmlinux_mmap()`, mapping `/sys/kernel/btf/vmlinux` must reject non-zero `vma->vm_pgoff`, `pfn + pages < pfn`, or `(vm_size >> PAGE_SHIFT) > pages` (where `pages = PAGE_ALIGN(attr->size) >> PAGE_SHIFT`) with `-EINVAL`, and reject `VM_WRITE | VM_EXEC | VM_MAYSHARE` with `-EACCES` before calling `remap_pfn_range()`. [F97]
- In kernel/bpf/sysfs_btf.c, btf_sysfs_vmlinux_mmap() must reject non-zero vma->vm_pgoff, reject vma->vm_flags containing VM_WRITE, VM_EXEC, or VM_MAYSHARE with -EACCES, and clear VM_MAYEXEC | VM_MAYWRITE via vm_flags_mod() before calling remap_pfn_range() on __start_BTF. [F179]
- In kernel/bpf/token.c, bpf_token_create() must verify that the target fd is the root dentry of a bpffs super_block (path.dentry == sb->s_root && sb->s_op == &bpf_super_ops) owned by a non-init user_namespace matching current_user_ns(), and store get_user_ns(sb->s_user_ns) in token->userns for bpf_token_capable(). [F180]
- In kernel/trace/bpf_trace.c, bpf_uprobe_multi_link_attach() must reject negative pid values (pid < 0) with -EINVAL, resolve non-zero pid via get_pid_task(find_vpid(pid), PIDTYPE_TGID), and filter target processes using uprobe->link->task->mm == mm in uprobe_multi_link_filter() and same_thread_group(current, link->task) in uprobe_prog_run(). [F182]
- In kernel/trace/bpf_trace.c, bpf_uprobe_multi_link_fill_link_info() must reject mismatched upath and upath_size (!upath ^ !upath_size) with -EINVAL, and when both are zero it must still compute the d_path() length and populate info->uprobe_multi.path_size without copying to userspace. [F184]

## Known Pitfalls

- In `parse_build_id()`, `get_build_id_32()`, and `get_build_id_64()`, ELF header and note fields (`e_phnum`, `e_phoff`, `p_offset`, `p_filesz`, `n_namesz`, `n_descsz`) must be copied into local variables with `READ_ONCE()` before any subsequent `freader_fetch()` call, because `freader_fetch()` invalidates previously returned pointers. [F83]
- In `__bpf_dynptr_copy_str()`, when copying a string into a non-contiguous dynptr in chunks of `chunk_sz = min_t(u32, sizeof(buf), size - off)`, the loop must advance `off` by `chunk_sz - 1` (and stop when `cnt < chunk_sz || chunk_sz == 1`) so the trailing NUL byte written by `str_copy_fn` at the end of a full chunk is overwritten by the next chunk. [F99]
- When `queued_fetch_set_pending_acquire()` in `resilient_queued_spin_lock_slowpath()` observes contention (`val & ~_Q_LOCKED_MASK`), it must call `clear_pending(lock)` only when `!(val & _Q_PENDING_MASK)` holds on the old value `val` before jumping to `queue`. [F101]
- In `task_seq_get_next()`, every `goto retry` branch after `find_ge_pid(*tid, common->ns)` must increment `*tid` (`++*tid`), and any branch that drops a non-NULL `task` via `put_task_struct(task)` must reset `task = NULL` before jumping to `retry`. [F103]
- When advancing to the next task after exhausting files in `task_file_seq_get_next()` or VMAs/`mm` in `task_vma_seq_get_next()`, the function must stop immediately if `info->common.type == BPF_TASK_ITER_TID`, and otherwise increment `info->tid` and clear `info->task = NULL` before jumping to `again`. [F105]
- In `alloc_bulk()`, the loop counter `i` must be initialized to `0` only in the first loop (`free_by_rcu_ttrace`) and carried across the subsequent `waiting_for_gp_ttrace` and `__alloc()` loops (`for (; i < cnt; i++)`) without reinitialization. [F107]
- In `memalloc.c` (`free_all()`, `do_call_rcu_ttrace()`, `free_bulk()`, `check_free_by_rcu()`), traversing a detached `llist_node` chain whose body frees the node or re-adds it to another `llist_head` must use `llist_for_each_safe()`. [F108]
