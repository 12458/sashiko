# NETWORKING [IPv4/IPv6] — net/ipv6 (part 2)

Implements IPv6 input/output (`ip6_input.c`, `ip6_output.c`, `ip6_offload.c`, `ip6_checksum.c`), FIB radix tree (`ip6_fib.c`), ICMPv6 (`icmp.c`, `ip6_icmp.c`), Flow Labels (`ip6_flowlabel.c`), GRE/ERSPAN tunnels (`ip6_gre.c`), IOAM (`ioam6.c`, `ioam6_iptunnel.c`), and ILA (`ila/*`).

## Architecture & Data Flow

- In `struct fib6_info`, flexible array `fib6_nh[]` is allocated only when `f6i->nh == NULL` (`fib6_info_alloc()`), and `fib6_siblings` unions with `nh_list`; check `f6i->nh` before touching either. In `fib6_add_1()`, `fib6_node_lookup_1()`, and `fib6_locate_1()`, cast `leaf` to `(u8 *)` before adding byte offset (`fib6_dst`/`fib6_src`), terminate `lookup_args[]` with `{ .offset = 0 }`, and check `plen < fn->fn_bit` and `plen == fn->fn_bit` before `addr_bit_set()` so bit index stays in `0..127`. [F594, F631, F662, F677]
- Adding/deleting routes with `fib6_requires_src(rt)` (`fib6_src.plen > 0`) in `fib6_add()`/`fib6_del()` must call `fib6_routes_require_src_inc()`/`_dec()` in lockstep for `ip6_extract_route_hint()`. `fib6_new_sernum()` must wrap `net->ipv6.fib6_sernum` from `INT_MAX` to `1` via `atomic_try_cmpxchg`, never returning `0` (`FIB6_NO_SERNUM_CHANGE`). [F611, F667]
- Removing a route/node in `fib6_del_route()` or `fib6_repair_tree()` must adjust `net->ipv6.fib6_walkers` under `fib6_walker_lock` and reset `fn->rr_ptr`. In `fib6_clean_node()`, when `c->func()` returns `-1`, set `w->leaf = rt` before `fib6_del()` and return `0` immediately on success without continuing `for_each_fib6_walker_rt(w)` or overwriting `w->leaf`. [F607, F646]
- In `__ip6_append_data()`, verify `mtu > fragheaderlen`, `((mtu - fragheaderlen) & ~7) + fragheaderlen > sizeof(struct frag_hdr)`, and `headersize + transhdrlen <= mtu` before computing `maxfraglen` or subtracting `transhdrlen`; enable `CHECKSUM_PARTIAL` only for unfragmented `IPPROTO_UDP` without exthdrs (`zc = true` requires `NETIF_F_SG` and `CHECKSUM_PARTIAL`); and zero `transhdrlen`, `exthdrlen`, `dst_exthdrlen`, `cork->tx_flags`, and `tskey` after fragment 1. [F618, F641, F709]
- Non-final fragments in `ip6_fragment()`, `ip6_frag_next()`, `ip6_fraglist_prepare()`, and `ipv6_gso_segment()` must have payload length a non-zero multiple of 8 (`& ~7`). `ip6_finish_output_gso_slowpath_drop()` must call `ip6_fragment()` only when `segs->len > mtu` (else `ip6_finish_output2()`). `ip6_sk_dst_check()` must verify `dst->ops->family == AF_INET6` before `dst_rt6_info(dst)`. [F640, F679, F711]
- In `ip6_rcv_core()`, set `IP6CB(skb)->iif` from `ip6_dst_idev(skb_dst(skb))->dev->ifindex` when `skb_valid_dst(skb)` (else `dev->ifindex`), and validate/trim `pkt_len + sizeof(struct ipv6hdr) <= skb->len` via `pskb_trim_rcsum()` whenever `pkt_len != 0 || hdr->nexthdr != NEXTHDR_HOP`. When `inet6_sdif(skb)` is non-zero (VRF), `ip6_protocol_deliver_rcu()` and `ip6_mc_input()` must pass `dev_get_by_index_rcu(net, sdif)` to `ipv6_chk_mcast_addr()`. [F632, F703, F705]
- In `ipv6_gso_segment()`, abort if `skb_reset_transport_header_careful(skb)` returns false after `ipv6_gso_pull_exthdrs()`. In `sit_ip6ip6_gro_receive()` and `ip4ip6_gro_receive()`, if `NAPI_GRO_CB(skb)->encap_mark` is set, set `flush = 1` and return `NULL`. [F624, F708]
- `tuninfo` must be last in `struct ioam6_lwt` and `traceh` last in `struct ioam6_lwt_encap`. Gate `ilwt->tundst` on `mode != IOAM6_IPTUNNEL_MODE_INLINE` (plus `has_tunsrc` for `tunsrc`). Ensure `1 <= freq.k <= freq.n <= IOAM6_IPTUNNEL_FREQ_MAX` in `ioam6_build_state()` and read `ilwt->pkt_cnt` as `u32` in `ioam6_output()`. [F592, F626, F663]
- `ioam6_trace_hdr` `remlen`/`nodelen` and `sclen` are in 4-byte words (multiply by 4 for byte lengths/offsets); `ioam6_fill_trace_data()` must check `remlen != 0 && remlen >= nodelen + sclen`. `ioam6_genl_addsc()` must set `sc->len = ALIGN(len, 4)` (`<= IOAM6_MAX_SCHEMA_DATA_LEN`, `255 * 4`) and zero-allocate `sizeof(*sc) + len_aligned`. [F627, F628, F671]
- Reconfiguring a tunnel in `ip6_gre.c` must unlink `t` from `ign->tunnels`, update `t->parms`, reset `t->dst_cache` (`ip6gre_tnl_copy_tnl_parm()`), and relink. `ign->fb_tunnel_dev` (`ip6gre0`) has `netns_immutable = true`, rejects `changelink` (`-EINVAL`) and `SIOCDELTUNNEL` (`-EPERM`), and is ignored in `ip6gre_dellink()`. In `ip6gre_exit_rtnl_net()`, guard `unregister_netdevice_queue()` on `ign->tunnels` with `if (!net_eq(dev_net(t->dev), net))`. [F613, F658, F713]
- In `ip6erspan_tunnel_xmit()` with `collect_md`, verify `IP_TUNNEL_ERSPAN_OPT_BIT` and `options_len >= sizeof(*md)` before reading `ip_tunnel_info_opts()`. In `ip6_err_gen_icmpv6_unreach()`, reset RFC 4884 `data_len = 0` unless `data_len >= 128 && !(data_len & 7) && skb->len >= data_len` after `pskb_may_pull()`. In `icmpv6_mask_allow()`, check `type <= ICMPV6_MSG_MAX` before `test_bit()`. [F634, F636, F681]
- In `ila_update_ipv6_locator()`, adjust checksums before overwriting `iaddr->loc = p->locator`, and call `pskb_may_pull()` for the L4 header in `ila_csum_adjust_transport()`. In `ila_xlat.c`, `rhash_table` indexes only sublist heads: replacing/deleting a head with `ila->next` must use `rhashtable_replace_fast()`, and `ila_xlat_nl_dump()` must resume with `rhashtable_walk_peek()` and reset `skip = 0` before `rhashtable_walk_next()`. [F621, F623, F639, F656]
- In `struct ip6_flowlabel`, `fl->owner.pid` is valid only for `IPV6_FL_S_PROCESS` and `owner.uid` for `IPV6_FL_S_USER`. `fl_release()` may early-free and zero `fl->opt = NULL` on last user drop only when `fl->share == IPV6_FL_S_EXCL` so `fl_free()` still decrements `ipv6_flowlabel_exclusive`. [F600, F612]

## Synchronization

- FIB mutations (`fib6_add()`, `fib6_del()`) and walks (`fib6_walk()`, `fib6_walk_continue()`) require `spin_lock_bh(&table->tb6_lock)` and `GFP_ATOMIC`. Lock order: `fib6_gc_lock` -> `table->tb6_lock` -> `fib6_walker_lock` or `rt->nh->lock` (used in `fib6_add_rt2node_nh()` and `fib6_purge_rt()` for `nh->dead` and `rt->nh_list`). `fib6_net_exit()` must call `timer_delete_sync(&net->ipv6.ip6_fib_timer)` before freeing tables. [F574, F575, F689, F690]
- `fib6_new_table()` must take `spin_lock_bh(&net->ipv6.fib_table_hash_lock)` and recheck `fib6_get_table()` before `fib6_link_table()`. Published `fib6_node`s must be freed via `node_free()` (`kfree_rcu()`), using `node_free_immediate()` only for unpublished nodes. [F573, F691]
- `__fib6_update_sernum_upto_root()` must run `smp_wmb()` before `WRITE_ONCE(fn->fn_sernum, sernum)`, pairing with `smp_rmb()` in `fib6_get_cookie_safe()`. Resuming a suspended `fib6_walk_continue()` after dropping `tb6_lock` must check `READ_ONCE(w->root->fn_sernum)` and reset `w->state = FWS_INIT`, `w->node = w->root`, `w->skip = w->count` if changed. Detaching multipath siblings in `fib6_del_route()` or `fib6_add_rt2node()` must set `WRITE_ONCE(rt->fib6_nsiblings, 0)` and use `list_del_rcu(&rt->fib6_siblings)`. [F570, F572, F643]
- `ip6_output()`, `ip6_xmit()`, and the `skb_has_frag_list()` fastpath of `ip6_fragment()` must hold `rcu_read_lock()` across output/fragment loops and stats updates, using `dst_dev_rcu(dst)`. `ip6_xmit()` and `NF_INET_LOCAL_OUT` hooks must not assume `lock_sock(sk)` is held. [F682, F684, F685]
- In `ip6_flowlabel.c`, use `spin_lock_bh(&ip6_fl_lock)` outside the timer and drop `ip6_sk_fl_lock` before `fl_release()`. RCU lookups (`fl_lookup()`, `__fl6_sock_lookup()`, `ipv6_flowlabel_get()`) must use `atomic_inc_not_zero(&fl->users)`. `fl_intern()` must recheck `__fl_lookup()` under `ip6_fl_lock`, and `ipv6_flowlabel_get()` must revalidate `fl1->share` and `fl1->owner` on hit. [F577, F578, F693]
- `icmpv6_xmit_lock()` callers must disable BH, use `spin_trylock(&sk->sk_lock.slock)` on per-CPU `ipv6_icmp_sk`, and unlock via `icmpv6_xmit_unlock()` (which resets `sock_net_set(sk, &init_net)`). When `!IS_BUILTIN(CONFIG_IPV6)`, `inet6_register_icmp_sender()`/`inet6_unregister_icmp_sender()` must use `cmpxchg()` on `ip6_icmp_send` and `synchronize_net()` on unregister. [F579, F580]
- In `ioam6.c`, hold `nsdata->lock` when mutating `namespaces`, `schemas`, `ns->schema`, or `sc->ns`, and clear the peer pointer before `kfree_rcu()`. In `ila_xlat.c`, `ila_lookup_wildcards()`/`ila_lookup_by_params()` require `rcu_read_lock()`, while bucket changes require `ila_get_lock()` and `kfree_rcu()`. [F583, F698]

## Object Lifetimes

- In `ioam6_output()` and `ila_output()`, bracket `dst_cache_get()`/`dst_cache_set_ip6()` with `local_bh_disable()`/`local_bh_enable()`, and call `skb_dst_drop(skb)` before `skb_dst_set(skb, dst)`. Never cache `dst` directly when `orig_dst->lwtstate == dst->lwtstate`: skip caching in `ila_output()`, or in `ioam6_output()` cache `&ilwt->null_dst` (initialized with `DST_NOCOUNT`) and replace it on lookup with `orig_dst` after `dst_release()` and `dst_hold(orig_dst)`. [F553, F554, F584, F591]
- In `fib6_purge_rt()`, if `refcount_read(&rt->fib6_ref) != 1`, replace `fn->leaf == rt` on ancestor intermediate nodes (`!(fn->fn_flags & RTN_RTINFO)`) via `fib6_find_prefix()`. Before `fib6_info_release()` schedules `fib6_info_destroy_rcu()`, `rt->fib6_node` must be `NULL`, and `fib6_drop_pcpu_from()` must set `f6i->fib6_destroying = 1` with a barrier before `xchg(&pcpu_rt->from, NULL)`. [F559, F560]
- `fib6_walk()` links `w` via `fib6_walker_link()` and only unlinks it when `fib6_walk_continue(w) <= 0`; callers suspending a walk (`res > 0`) must call `fib6_walker_unlink()` before freeing `w`. [F566]
- Coalescing `frag_list` buffers in `__ip6_make_skb()` or preparing fraglist fragments in `ip6_fragment()` must add each fragment's `truesize` to `skb->truesize` and clear its `destructor` and `sk` to `NULL`. [F557]
- Cleanup of `fl` after `fl_create()` succeeds must call `fl_free(fl)` (not `kfree()`). In `ip6_gre.c`, `ndo_uninit` must call `netdev_put(dev, &t->dev_tracker)` and unlink `t`, while `ip6gre_dev_free()` (`priv_destructor`) destroys `gro_cells` and `dst_cache`. In `ila_add_mapping()`, serialize `ila_nf_hook_ops` registration under `ila_mutex`, and unregister hooks in `ila_xlat_pre_exit_net()` before `ila_xlat_exit_net()` destroys `rhash_table`. [F563, F565, F582]

## API Contracts

- `ip6_dst_lookup()` and `ip6_dst_lookup_tail()` free `*dst` and set `*dst = NULL` on error; callers must only `dst_release(dst)` when it returns 0 (and before `xfrm_lookup()`, which consumes `dst`). Set FIB metrics via `fib6_metric_set(f6i, metric, val)` (1-based `RTAX_*`), never by writing `fib6_metrics` or `fib6_pmtu` directly. [F567, F597]
- `fib6_clean_all()` callbacks must return `0` (continue), `-1` (delete), or `-2` (skip siblings). Any `fib6_walker` callback returning `0` after finishing `w->node` must set `w->leaf = NULL`. [F596, F645]
- In `ip6_protocol_deliver_rcu()`, `ret > 0` from `ipprot->handler(skb)` resubmits (`ret` is `nexthdr` if `INET6_PROTO_FINAL`, else read from `IP6CB(skb)->nhoff`). `ip6_rcv_core()` must call `skb_orphan(skb)` if `!skb_sk_is_prefetched(skb)` before `NF_INET_PRE_ROUTING`. [F601, F704]
- `ipv6_gro_pull_exthdrs()` must call `skb_gro_header()` for `sizeof(*opth)` and again for `off + ipv6_optlen(opth)` before advancing `off`. `ipv6_gso_segment()` must strip synthetic jumbo headers via `ipv6_hopopt_jumbo_remove(skb)` before reading `nhoff`. In `ip6_fragment()`'s `frag_list` loop, call `ip6_fraglist_prepare()` before `output()` and `ip6_fraglist_next()` only after `output()` succeeds. [F625, F653, F707]
- `icmpv6_err_convert()` returns boolean fatality (`1`/`0`) and writes positive `E*` to `*err`. `inet6_protocol.err_handler` callbacks reading past `inner_offset + 8` must call `pskb_may_pull()`. In `icmpv6_ndo_send()`, if `nf_ct_get()` has `IPS_NAT_MASK`, clone/make writable and restore `ct->tuplehash[CTINFO2DIR(ctinfo)].tuple.src.u3.in6` into `saddr` across `__icmpv6_send()`. `ila_csum_adjust_transport()` must pass `pseudohdr = true, ipv6 = true` to `inet_proto_csum_replace_by_diff()`. [F586, F589, F633, F700]
- `ipv6_flowlabel_renew()` uses `ns_capable(net->user_ns, CAP_NET_ADMIN)`, while `check_linger()` and `mem_check()` require `capable(CAP_NET_ADMIN)`. `ip6fl_seq_show()` must format `owner.pid` via `pid_nr_ns(fl->owner.pid, state->pid_ns)` and `owner.uid` via `from_kuid_munged(seq_user_ns(seq), fl->owner.uid)`. [F717, F718]

## Error Handling

- In `fib6_add()`, if `fib6_add_1()` returns `ERR_PTR(fn)`, set `fn = NULL` before `out:`/`failure:`; if a later step fails after setting `pn->leaf = rt` (`pn != fn`), restore `pn->leaf` before `fib6_repair_tree()`. In `fib6_add_rt2node()`, reset `rt->fib6_nsiblings = 0` on `-EEXIST` (`rt6_duplicate_nexthop()`), and if `call_fib6_entry_notifiers()` fails after linking siblings, unlink `rt->fib6_siblings`, decrement siblings' `fib6_nsiblings`, zero `rt->fib6_nsiblings`, and call `rt6_multipath_rebalance()`. [F561, F598, F648]
- `ip6_setup_cork()` must set `cork->base.dst = &rt->dst` before any fallible check so `ip6_cork_release()` frees `rt`. Check `__neigh_create()` with `IS_ERR(neigh)` in `ip6_finish_output2()`. In `ip6_fragment()`, fast-path validation failures inside `skb_walk_frags(skb, frag)` must `goto slow_path_clean` with `frag` unchanged. In `icmpv6_route_lookup()`, reset `dst = NULL` when initial `xfrm_lookup()` returns `ERR_PTR(-EPERM)`. [F588, F602, F603, F652]

## External Contracts

- In `ipv6_flowlabel_opt()`/`fl_create()`, read trailing options at `CMSG_ALIGN(sizeof(*freq))` with `olen <= 64 * 1024`, and reject `fl->opt->opt_flen != 0` with `-EINVAL`. In `ip6erspan_tap_validate()`, check `IFLA_GRE_IKEY`/`OKEY` with `ntohl(...) & ~ID_MASK` and mask ERSPAN v1/v2 fields. In `ila_build_state()`, require `fc_dst_len >= 67` for `ILA_ATYPE_USE_FORMAT`, reject `ILA_ATYPE_IID`, and reject `ILA_CSUM_NEUTRAL_MAP` if `ila_csum_neutral_set()` is true. In `is_ineligible()`, check `!tp && frag_off != 0` (false) before `!tp || !(*tp & ICMPV6_INFOMSG_MASK)` (true). [F637, F642, F659, F715, F716]

## Known Pitfalls

- Recompute pointers into `skb->head` after helpers that reallocate/unclone: `pkt_md` (and copy `ver == 1 ? ERSPAN_V1_MDSIZE : ERSPAN_V2_MDSIZE`) after `__iptunnel_pull_header()` in `ip6erspan_rcv()`; `ipv6h` after `ip6_tnl_parse_tlv_enc_lim()` in `prepare_ip6gre_xmit_ipv6()`; `prevhdr` after `skb_checksum_help()` in `ip6_fragment()`; and `hdr = ipv6_hdr(skb)` after `skb_cow()` in `ip6_forward()` (which must not decrement `hop_limit` before `ip6_forward_proxy_check()` or `skb_cow()`). Use `memmove()` (not `memcpy()`) for overlapping shifts in `ioam6_do_inline()`, `ipv6_gro_complete()`, and `ip6_err_gen_icmpv6_unreach()`. [F614, F620, F635, F673, F676, F710]
- In `fib6_del_route()` and `fib6_add_rt2node()`, pass `next_sibling`/`temp_sibling` from `list_for_each_entry_safe()` (not `sibling` or `rt`) to `rt6_multipath_rebalance()`. Skip multipath siblings in `for_each_fib6_walker_rt(w)` via `rt = list_last_entry(&rt->fib6_siblings, struct fib6_info, fib6_siblings)`. Advance pointer-to-pointer cursors (`ins` in `fib6_add_rt2node()`, `flp` in `ip6_fl_gc()`/`ip6_fl_purge()`) only when retaining the entry. [F644, F647, F649]
- In `csum_ipv6_magic()`, fold carry (`carry = (sum < operand); sum += carry;`) after every 32-bit addition. Compare flowlabel `jiffies` timestamps via `time_after()`/`time_before()` or signed `(long)(a - b) > 0`. Pass `idev = NULL` to `__ICMP6_INC_STATS(net, NULL, ICMP6_MIB_RATELIMITHOST)` in `icmpv6_xrlim_allow()`. [F660, F668, F702]
