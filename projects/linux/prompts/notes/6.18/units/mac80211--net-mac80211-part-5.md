# MAC80211 — net/mac80211 (part 5)

Implements the mac80211 RX path (`rx.c`), station lifecycle and hash management (`sta_info.c`/`sta_info.h`), scanning (`scan.c`), spectrum management (`spectmgmt.c`), S1G/TWT (`s1g.c`), and Minstrel HT/VHT rate control (`rc80211_minstrel_ht.c`, `rc80211_minstrel_ht_debugfs.c`).

## Architecture & Data Flow

- Never modify `WLAN_STA_AUTH`, `WLAN_STA_ASSOC`, or `WLAN_STA_AUTHORIZED` via `set_sta_flag()`/`clear_sta_flag()` or mutate `sta->sta_state` directly; only `_sta_info_move_state()` updates them in lockstep with mcast counts and fast-TX/RX caches. [F383]
- `struct ieee80211_sta sta` must be the last member of `struct sta_info` (`sta.drv_priv[]` trails into `+ hw->sta_data_size`). `__sta_info_alloc()` allocates all `IEEE80211_NUM_TIDS + 1` `txq_info` entries (strided by `sizeof(struct txq_info) + ALIGN(hw->txq_data_size, sizeof(void *))`) in one block at `sta->sta.txq[0]`, freed via `kfree(to_txq_info(sta->sta.txq[0]))`. [F415, F416]
- For MLO stations, `__ieee80211_sta_recalc_aggregates()` writes min `max_amsdu_len`/`max_rc_amsdu_len`/`max_tid_amsdu_len` into `sta->cur` (`sta->sta.cur = &sta->cur`), never mutating `sta->sta.deflink.agg`. Track `link_sta->capa_nss` and `op_mode_nss` separately from `link_sta->pub->rx_nss`. [F385, F392]
- Every exit in `ieee80211_check_fast_rx()` must hit `clear:`/`clear_rcu:` so `WLAN_STA_DECAP_OFFLOAD`, `drv_sta_set_decap_offload()`, and `sta->fast_rx` stay synced; disable `fast_rx` if `AMPDU_AGGREGATION` lacks `SUPPORTS_REORDERING_BUFFER`, PS uses `PS_NULLFUNC_STACK` or lacks `SUPPORTS_DYNAMIC_PS`, or on AP/AP_VLAN vifs without `AP_LINK_PS`. [F389, F477]
- In `__ieee80211_rx_handle_packet()`, linearize management frames with `skb_linearize(skb)` after `skb->len >= ieee80211_hdrlen(fc)` (data frames use `pskb_may_pull()`). For MLO data frames with `!status->link_valid && sta->sta.mlo`, resolve `link_sta` and `link_id` via `link_sta_info_get_bss(rx.sdata, hdr->addr2)`. In `ieee80211_rx_for_interface()`, query `link_sta_info_get_bss()` before `sta_info_get_bss()`. [F373, F430, F504]
- In `ieee80211_rx_data`, `rx->sta` and `rx->link_sta` can be NULL in RX handlers (including `ieee80211_rx_h_action()` for `PUBLIC`, `SELF_PROTECTED`, and `SPECTRUM_MGMT`), and `rx->link_sta` is non-NULL iff `rx->sta` is non-NULL. Because `ieee80211_rx_handlers()` reuses one `rx_data` across dequeued `frames`, `ieee80211_rx_h_decrypt()` must reset `rx->key = NULL` on entry. [F375, F432]
- In `ieee80211_rx_h_decrypt()`, check `mmie_keyidx >= 0 && ieee80211_is_beacon(fc)` before general `mmie_keyidx >= 0`, and range-check `mmie_keyidx` against IGTK (`[NUM_DEFAULT_KEYS, +NUM_DEFAULT_MGMT_KEYS)`) and BIGTK (`[+NUM_DEFAULT_MGMT_KEYS, +NUM_DEFAULT_BEACON_KEYS)`) bounds before indexing `gtk[]`. In `ieee80211_get_mmie_keyidx()`, check `skb->len >= 24 + sizeof(*mmie)` (or `sizeof(*mmie16)`). In `ieee80211_rx_h_defragment()`, when `entry->check_sequential_pn` is set, each fragment's 6-byte big-endian `rx->ccm_gcm.pn` must equal `entry->last_pn + 1` (carry from byte 5 to 0) or drop with `RX_DROP_U_REPLAY`. [F410, F411, F431, F449]
- In `rx.c`, compare 12-bit SNs with `ieee80211_sn_less()`/`_less_eq()` and update modulo 4096 (`& IEEE80211_SN_MASK`). Index `tid_agg_rx->reorder_buf`/`reorder_time` by `sn % buf_size` only after `ieee80211_sta_manage_reorder_buf()` bounds `mpdu_seq_num` in `[head_seq_num, head_seq_num + buf_size)`. `ieee80211_release_reorder_frame()` must clear `BIT_ULL(index)` in `reorder_buf_filtered` and increment `head_seq_num` on all paths (including `no_frame:`). In `ieee80211_sta_reorder_release()`, releasing timed-out slot `j` must purge incomplete A-MSDUs in `(index + 1) % buf_size .. j`, add `skipped` to `head_seq_num`, and reset `skipped = 0`. [F409, F424, F425, F448]
- Check variable header/IE bounds before reading: `ieee80211_rx_h_action()`/`_post_userspace()` must check `rx->skb->len` against `offsetofend` of the category's action code/payload; `ieee80211_process_rx_twt_action()` must verify both `sizeof(struct ieee80211_twt_setup) + 2` and `IEEE80211_MIN_ACTION_SIZE + 4 + twt->length`; S1G beacons in `ieee80211_scan_rx()` must add `ieee80211_s1g_optional_len(ext->frame_control)` to `min_hdr_len`; `ieee80211_rx_check_bss_color_collision()` must check `baselen > rx->skb->len` and `ie->datalen` against `sizeof(struct ieee80211_he_operation)` and `ieee80211_he_oper_size()`; `ieee80211_sta_set_max_amsdu_subframes()` must guard `ext_capab[7]` (`< 8`) and `ext_capab[8]` (`>= 9`) separately; `ieee80211_parse_ch_switch_ie()` must check `IEEE80211_BW_IND_DIS_SUBCH_PRESENT` and use `get_unaligned_le16(bwi->info.optional)`. [F403, F404, F405, F413, F418, F420]
- `ieee80211_clean_skb()` must clear `RX_FLAG_RADIOTAP_TLV_AT_END`, `LSIG`, `HE_MU`, and `HE` from `status->flag` and `IEEE80211_FCTL_ORDER` from `hdr->frame_control` when stripping radiotap and HT-Control fields. [F395]
- In `ieee80211_deliver_skb()` and `ieee80211_rx_8023()`, intra-BSS forwarding must `skb_copy()` multicast frames into `xmit_skb` (keeping `skb` for local delivery) but set `xmit_skb = skb; skb = NULL` on unicast, and add 256 to `xmit_skb->priority` before `dev_queue_xmit()`. In `ieee80211_rx_mesh_data()`, call `ieee80211_set_qos_hdr(sdata, fwd_skb)` before `ieee80211_add_pending_skb()`. [F439, F498, F499]
- Manipulate `tim` in `__bss_tim_set()`/`_clear()`/`_get()` byte-wise (`tim[id / 8]`, `1 << (id % 8)`), never with `unsigned long` bitops. In `ieee80211_sta_update_pending_airtime()`, clamp negative `atomic_sub_return()` underflow on `aql_tx_pending` and `aql_ac_pending_airtime[ac]` to 0 via `atomic_cmpxchg()`. In `sta_set_link_sinfo()`/`sta_set_sinfo()`, only fill fallback `tx_bytes`/`rx_bytes` if neither `BIT_ULL(NL80211_STA_INFO_{TX,RX}_BYTES64)` nor `..._BYTES` is set in `filled`. Keep `sta_stats_encode_rate()` and `sta_stats_decode_rate()` bitfields in lockstep. [F401, F417, F438, F450]
- In `__ieee80211_start_scan()`, allocate `struct_size(local->hw_scan_req, req.channels, req->n_channels) + hw_scan_ies_bufsize` (scaled by `n_bands` if `SINGLE_SCAN_ON_ALL_BANDS`), set `req.n_channels` before accessing `req.channels[]`, and pass negative `req->tsf_report_link_id` through unchanged on MLD vifs. Set `IEEE80211_TX_CTRL_DONT_USE_RATE_MASK` in `ieee80211_send_scan_probe_req()`. In `ieee80211_scan_state_set_channel()`, increment `local->scan_channel_idx++` before `if (skip)`. [F394, F397, F419, F434]
- In `rc80211_minstrel_ht.c`, keep `rate_info` (`minstrel_ht_ri_*`) and `ieee80211_tx_rate` (`minstrel_ht_txstat_valid`, `minstrel_ht_get_stats`) paths in sync; sync `cur_sample_rates` in `minstrel_ht_refill_sample_rates()`; widen `mcs_group::duration[]` to 32-bit and left-shift by `group->shift` (`minstrel_get_duration()`); guard `MINSTREL_FRAC()` with `attempts > 0` / `ampdu_packets > 0`; and in `minstrel_ht_tx_status()` reset `total_packets` and `sample_packets` to 0 when `mi->total_packets >= ~0 - info->status.ampdu_len`. [F390, F402, F444, F445, F446]

## Synchronization

- Callers of `sta_info_get*()` and `link_sta_info_get_bss()` must hold `rcu_read_lock()` or `wiphy->mtx`; callers of `ieee80211_find_sta*()` must hold `rcu_read_lock()` across the call and all uses of the returned pointer. [F359, F488]
- In `sta_info_insert_finish()`, set `WLAN_STA_BLOCK_BA` before hashing/linking `sta` and clear it only after `sta_info_insert_drv_state()` succeeds and `WLAN_STA_INSERTED` is set. When `_sta_info_move_state()` demotes `IEEE80211_STA_AUTHORIZED` to `ASSOC` with `ops->set_key`, clear `WLAN_STA_AUTHORIZED`, call `synchronize_net()`, and flush queues before removing keys. [F353, F356]
- In `sta_ps_end()` and `ieee80211_sta_block_awake()`, set `WLAN_STA_PS_DELIVER` before clearing `WLAN_STA_PS_STA`/`PS_DRIVER`, and clear `PS_DELIVER` in `ieee80211_sta_ps_deliver_wakeup()` under `spin_lock_bh(&sta->ps_lock)` (nesting `spin_lock_irqsave()` on `tx_filtered`/`ps_tx_buf`) after splicing queues. While `WLAN_STA_PS_DRIVER` is set, defer PS/PS-Poll/uAPSD delivery until `ieee80211_sta_block_awake(..., false)` schedules `drv_deliver_wk`. Wrap PS delivery in `sta_deliver_ps_frames()` with `local_bh_disable()`/`enable()`, never call `ieee80211_sta_ps_transition()` with softirqs enabled, and hold `spin_lock_bh(&local->tim_lock)` in `__sta_info_recalc_tim()` around `ps->tim` and `drv_set_tim()`. [F361, F475, F491, F492, F493]
- Hold `tid_agg_rx->reorder_lock` for all `tid_agg_rx` reorder fields and release it before `ieee80211_rx_handlers()`. `ieee80211_rx_handlers()` must hold `spin_lock_bh(&rx->local->rx_path_lock)`. Call `ieee80211_release_reorder_timeout()` under `rcu_read_lock()`. [F362, F481, F483]
- `ieee80211_invoke_fast_rx()` runs locklessly and must reject frames without `RX_FLAG_DUP_VALIDATED` (or without `RX_FLAG_PN_VALIDATED | RX_FLAG_DECRYPTED` when `fast_rx->key` is set). Mutate `sta->fast_rx` under `spin_lock_bh(&sta->lock)` and free old pointers via `kfree_rcu(old, rcu_head)`. [F363, F485]
- `link_sta->pcpu_rx_stats` is allocated only when `USES_RSS` (`fast_rx->uses_rss`) is set: check it before `per_cpu_ptr()`/`this_cpu_ptr()`, sum `rx_stats` + all CPUs of `pcpu_rx_stats` in `sta_info.c`, keep `ieee80211_rx_8023()` stats synced with slowpath RX while skipping `rx_stats_avg` when `uses_rss` is set, and bracket 64-bit `bytes`/`msdu[]` accesses with `u64_stats_update_begin`/`end` and `sta_get_stats_bytes()`/`sta_get_tidstats_msdu()`. [F364, F365, F374, F400]
- Drop frames in `ieee80211_rx_list()` when `quiescing`, `suspended`, `in_reconfig`, or `!started`, and ignore `ieee80211_sched_scan_stopped()` during `in_reconfig`. All `mac80211_minstrel_ht` callbacks under `sta->rate_ctrl_lock` and `minstrel_ht_update_rates()` must use `GFP_ATOMIC`. [F476, F497]

## Object Lifetimes

- `sta_info_insert()` and `sta_info_insert_rcu()` consume `sta` and free it on error; `sta_info_insert_rcu()` requires process context with `wiphy->mtx` held and `!rcu_read_lock()`, and always returns with `rcu_read_lock()` held. Between `__sta_info_destroy_part1()` and `__sta_info_destroy_part2()`, `synchronize_net()` must elapse. `sta_remove_link()` requires `wiphy->mtx`, clears `BIT(link_id)` in `valid_links`, calls `sta_accumulate_removed_link_stats()` before clearing `link[link_id]` with `RCU_INIT_POINTER()`, frees `sta_link_alloc` via `kfree_rcu()`, and calls `ieee80211_sta_recalc_aggregates()`. [F384, F468, F470, F489, F494]
- When `SCAN_HW_SCANNING` is set, `ieee80211_scan_cancel()` must not cancel `scan_work`, free `hw_scan_req`, or call `__ieee80211_scan_completed()`. In `__ieee80211_scan_completed()`, free/NULL `hw_scan_req`, NULL `scan_req` and `scan_sdata`, and call `synchronize_rcu()` before `cfg80211_scan_done()`. Release non-NULL `ieee80211_bss_info_update()` returns via `ieee80211_rx_bss_put()`. In `ieee80211_make_monitor_skb()` with `use_origskb == true`, clear `*origskb = NULL` and free `skb` if `pskb_expand_head()` fails. [F344, F346, F347, F350]

## API Contracts

- Run `ieee80211_recalc_min_chandef()` and `ieee80211_recalc_p2p_go_ps_allowed()` before `sta_info_insert_drv_state()` when `sta_state >= IEEE80211_STA_ASSOC`. In `_sta_info_move_state()` (`WLAN_STA_INSERTED`), call `drv_sta_state()` before updating `_flags` when increasing state, and after state/queue teardown when decreasing. In `ieee80211_sta_activate_link()`, call `recalc_min_chandef()` and `sta_recalc_aggregates()` before `drv_change_sta_links()`, and unwind via `valid_links = old_links` and `sta_remove_link(sta, link_id, false)` on error before `link_sta_info_hash_add()`. [F464, F466, F473]
- In `sta_info.c`, `link_id < 0` (`-1`) selects `deflink`, while `link_id >= 0` indexes `sta->link[link_id]`. Pre-populate `rx_beacon` from `count_beacon_signal` before `drv_sta_statistics()`/`drv_link_sta_statistics()` on `NL80211_IFTYPE_STATION`. Pass `ignored_acs` to `ieee80211_sta_ps_deliver_response()`/`_more_data()` as `ieee80211_ac_to_qos_mask` bits (`~uapsd_queues` for U-APSD; `uapsd_queues` for PS-Poll, reset to `0` when `uapsd_queues == BIT(IEEE80211_NUM_ACS) - 1`). When `AP_LINK_PS` is set, skip RX PM/PS-Poll/uAPSD handling and do not call `drv_sta_notify()` in `sta_ps_start()`/`deliver_wakeup()`. [F378, F379, F437, F474, F479]
- RX handlers must return `RX_QUEUED` if they consume/free `rx->skb`, and `RX_DROP*` only when `rx->skb` remains for `ieee80211_rx_handlers_result()` to free. On malformed action frames in `ieee80211_rx_h_action()`, set `IEEE80211_RX_MALFORMED_ACTION_FRM` and return `RX_CONTINUE` (`goto invalid`). In `ieee80211_rx_napi()`, call `ieee80211_rx_list()` under `rcu_read_lock()` and `skb_list_del_init(skb)` before `napi_gro_receive()`. Call `skb_postpull_rcsum()` before pulling SNAP in `ieee80211_invoke_fast_rx()`. Use `MESH_FAST_TX_TYPE_FORWARDED` in `ieee80211_rx_mesh_fast_forward()`. [F371, F393, F433, F502, F505]
- `ieee80211_parse_ch_switch_ie()` returns `0` (parsed), `< 0` (error), or `1` (absent). Pass a `>= IEEE80211_MAX_SSID_LEN`-byte buffer to `ieee80211_request_ibss_scan()`. In `rc80211_minstrel_ht.c`, unused `cck_rates`/`ofdm_rates` are `0xff`, `ieee80211_sta_rates` ends with `idx = -1`, `GROUP_IDX`/`VHT_GROUP_IDX` take 1-based `_streams`, and `minstrel_ht_get_expected_throughput()` returns kbps (`tp_avg * 10 * AVG_PKT_SIZE * 8 / 1024`). [F366, F381, F421, F455, F506]

## Error Handling

- If `sta_info_insert_drv_state()` fails in `sta_info_insert_finish()`, unhash `deflink` and `sta`, unlink `sta->list`, decrement `num_sta`, and call `synchronize_net()` before `cleanup_single_sta()`; inside `sta_info_insert_drv_state()`, unwind `drv_sta_state()` back to `IEEE80211_STA_NOTEXIST` on non-IBSS failure. [F339, F340]
- In `ieee80211_rx_h_defragment()`, if final-fragment `pskb_expand_head()` fails, call `__skb_queue_purge(&entry->skb_list)` and return `RX_DROP_U_OOM`. In `ieee80211_parse_ch_switch_ie()`, initialize `csa_ie->chanreq.ap = csa_ie->chanreq.oper` and only copy `new_chandef` if `new_chandef.chan != NULL`. In `__ieee80211_start_scan()`, do not return early after allocating `hw_scan_req`; if `drv_hw_scan()` returns `1` (fallback to sw scan, or `-EOPNOTSUPP` on P2P_GO), reset `hw_scan_req`, `scanning`, `scan_req`, and `scan_sdata` before `goto again`. Guard rate/encoding `WARN*` in `ieee80211_rx_list()` with `!(status->flag & RX_FLAG_FAILED_PLCP_CRC)`. [F351, F367, F370, F414, F435, F508]

## External Contracts

- `ieee80211_find_sta()` and `ieee80211_find_sta_by_ifaddr()` return `NULL` if `!sta->uploaded` (`ieee80211_find_sta_by_link_addrs()` does not). RX `skb->data` must be 2-byte aligned (`ieee80211_verify_alignment()`), `ieee80211_rx_list()` must zero `status->rx_flags`, and `ieee80211_deliver_skb_to_local_stack()` must zero `skb->cb` and rewrite control-port `ehdr->h_dest` to `sdata->vif.addr`. [F382, F396, F486, F500]

## Known Pitfalls

- Re-fetch `hdr` from `rx->skb->data` after decrypt in `ieee80211_rx_h_decrypt()`, `skb_linearize()` in `ieee80211_rx_h_defragment()`, and `skb_copy()` in `ieee80211_prepare_and_rx_handle()` (which must also copy `skb_hwtstamps(skb)->hwtstamp`). In `ieee80211_invoke_fast_rx()`, after `/* after this point, don't punt to the slowpath! */`, always `goto drop` instead of returning `false`. In `__ieee80211_rx_handle_packet()` multi-target loops, pass `consume = false` on `prev_sta`/`prev` inside the loop and `consume = true` after, never dereferencing the loop cursor after the loop. [F391, F398, F429, F501]
- In `ieee80211_add_rx_radiotap_header()`, copy/pull `he`/`he_mu`/`lsig` structs before `skb_push()`/`memset()`, and compute `pos` via `&rthdr->it_optional[it_present + 1 - rthdr->it_optional]`. Use `pskb_may_pull()` + `memmove()` when stripping HT-Control in `ieee80211_clean_skb()`, and `DIV_ROUND_UP()` when scaling 5/10 MHz legacy bitrates. [F399, F447, F456, F457]
- Use `BIT_ULL()` for `reorder_buf_filtered`/`filtered` (requiring `max_rx_aggregation_subframes <= 64` and `diff < buf_size`), BSS `color` in `ieee80211_rx_check_bss_color_collision()`, and `NL80211_STA_INFO_*` in `filled`. Negate `status->signal` into `ewma_*_signal_add()` and negate `ewma_*_signal_read()` when reading back. Initialize `sinfo->valid_links = sta->sta.valid_links` before `for_each_valid_link()` in `sta_set_sinfo()`. Keep `minstrel_debugfs_info` output within 32768 bytes. [F380, F423, F440, F441, F442, F443, F460]
