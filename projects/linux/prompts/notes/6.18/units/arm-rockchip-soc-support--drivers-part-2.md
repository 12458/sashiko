# ARM/Rockchip SoC support — drivers (part 2)

Rockchip peripheral, bus, memory management, and PHY drivers comprising the RK3x I2C controller, SARADC (IIO), IOMMU (v1/v2 page tables), CPU-to-MCU mailbox, DesignWare MMC host platform glue, eFuse/OTP NVMEM providers, AXI PCIe Root Complex/Endpoint controllers, and MIPI D-PHY/eMMC/HDMI/USB2 PHYs.

## Architecture & Data Flow

- In `rockchip-iommu.c`, `iommu->domain` is initialized to `&rk_identity_domain` only once in `rk_iommu_probe()` (never in per-master `rk_iommu_of_xlate()`), and callers of `to_rk_domain(iommu->domain)` (`rk_iommu_enable()`, `rk_iommu_identity_attach()`, `rk_iommu_suspend()`, `rk_iommu_resume()`) must verify `iommu->domain != &rk_identity_domain`. [F183, F194]
- In `rockchip-iommu.c`, `RK_IOMMU_PGSIZE_BITMAP` (`0x007ff000`) must not exceed 4 MiB (`NUM_PT_ENTRIES * SPAGE_SIZE`) because `rk_iommu_map()`/`unmap()` index a single second-level page table; v2 DTEs/PTEs pack PA bits 39:32 into bits 11:4 (`DTE_HI_MASK1`/`2`), so `rk_mk_pte_v2()` must not set v1 cache flags (`RK_PTE_PAGE_FLAGS_MASK`) and PA extraction must use `rk_ops->pt_address`. [F220, F221]
- Before `rockchip_pcie_parse_dt()`, set `rockchip->dev` and `rockchip->is_rc`; `struct rockchip_pcie` is inside `pci_host_bridge` only when `is_rc` is true (else inside `rockchip_pcie_ep`), so `pci_host_bridge_from_priv(rockchip)` and `rockchip->reg_base` are RC-only while `rockchip->mem_res` is EP-only. [F180, F264]
- `rockchip_pci_core_rsts` must stay ordered `"pipe"`, `"mgmt"`, `"core"`, `"mgmt-sticky"` (`reset_control_bulk_deassert()` runs in reverse); in `rockchip_pcie_cfg_atu()`, ATU region 0 is for config accesses, `1 .. offset + reg_no` for MEM/IO, and `reg_no + 1 + offset` for `AXI_WRAPPER_NOR_MSG` with `msg_bus_addr` advanced by `(reg_no + offset) << 20`. [F205, F272]
- In `pcie-rockchip-ep.c`, `rockchip_pcie_ep_map_addr()` sets `ep->ob_addr[r]` and bit `r` in `ep->ob_region_map`, and `rockchip_pcie_ep_unmap_addr()` must verify both before clearing ATU, `ob_addr[r]`, and bit `r`; `rockchip_pcie_ep_send_msi_irq()` caches the MSI ATU mapping by both `ep->irq_pci_addr` (init `ROCKCHIP_PCIE_EP_DUMMY_IRQ_ADDR`) and `ep->irq_pci_fn`, reprogramming when either changes; BARs 0..3 use `BAR_CFG0(fn)` (`b = bar`), BARs 4..5 use `BAR_CFG1(fn)` (`b = bar - BAR_4`), and 64-bit BARs require even `bar`. [F146, F202, F227]
- In `i2c-rk3x.c`, all `REG_CON` writes (`rk3x_i2c_start()`, `rk3x_i2c_stop()`, timeout in `rk3x_i2c_xfer_common()`) must preserve `i2c_readl(i2c, REG_CON) & REG_CON_TUNING_MASK`; `rk3x_i2c_clk_notifier_cb()` must validate `new_rate` via `calc_timings()` in `PRE_RATE_CHANGE`, calling `rk3x_i2c_adapt_div()` in `PRE_RATE_CHANGE` (rolling back on `ABORT_RATE_CHANGE`) when `new_rate > old_rate` and in `POST_RATE_CHANGE` when `new_rate < old_rate`. [F198, F200]
- In `rk3x_i2c_v0/v1_calc_timings()`, clamp `t->bus_freq_hz >= 1000` before `scl_rate_khz = t->bus_freq_hz / 1000`, round up `min_total_div`/`min_low_div`/`min_high_div` with `DIV_ROUND_UP()`, and truncate v0 `max_low_div`. [F251, F252]
- In `i2c-rk3x.c`, `REG_CON_MOD_REGISTER_TX` in `rk3x_i2c_setup()` requires `msgs[0].len < 4` (`REG_MRXRADDR` holds 3 bytes); `rk3x_i2c_fill_transmit_buf()` puts `(i2c->addr & 0x7f) << 1` at byte 0 when `processed == 0 && cnt == 0` without incrementing `processed` (max 31 payload bytes in first 32-byte chunk); `rk3x_i2c_prepare_read()`/`handle_read()` cap chunks at 32 bytes, clearing `REG_CON_LASTACK` when `len > 32` and setting `REG_CON_MOD_RX` when `processed != 0`. [F216, F217, F218]
- In `dw_mmc-rockchip.c`, `priv->drv_clk` and `priv->sample_clk` hold `ERR_PTR` when absent (guard with `!IS_ERR()`), and `rockchip_mmc_get/set_phase()` must check `priv->internal_phase`; in `dw_mci_rk3288_execute_tuning()`, increment `i++` when `i == priv->num_phases - 1` before the 20-degree skip, and compute wrapped range `len = ranges[i].end - ranges[i].start + 1` as signed `int` (`if (len < 0) len += priv->num_phases`) with `middle_phase %= priv->num_phases`. [F190, F236, F255]
- In `rockchip_rk3328/rk3399_efuse_read()` and `rk3588_otp_read()`, round start down and `offset + bytes` up to 4-byte words (`RK3399_NBYTES`/`RK3588_NBYTES`), read `addr_end - addr_start` words into a bounce buffer, and copy from `buf + (offset % 4)`. [F223]
- In `phy-rockchip-inno-usb2.c`, writable `usb2phy_reg` entries for `property_enable()` require `bitend <= 15` (`BIT_WRITEABLE_SHIFT` is 16); port init must set `rport->suspended = true` and (when no `"extcon"` property exists) sync `utmi_id` to `rphy->edev` via `extcon_set_state_sync(..., EXTCON_USB_HOST, !id)`; when `USB2PHY_PORT_OTG` has `rport->mode` as `USB_DR_MODE_HOST` or `USB_DR_MODE_UNKNOWN`, `otg_sm_work` and `chg_work` are uninitialized so `init`/`exit`/`irq` must skip OTG works/IRQs; `rockchip_usb2phy_irq()` and `rockchip_usb2phy_otg_mux_irq()` must OR sub-handler returns (`ret |= ...`). [F175, F208, F209, F233, F239]
- In `phy-rockchip-inno-usb2.c`, `rockchip_chg_detect_work()` disables `chg_det.opmode` at `USB_CHG_STATE_UNDEFINED` and re-enables it at `USB_CHG_STATE_DETECTED`, while `rockchip_usb2phy_otg_sm_work()` resets `chg_state`/`chg_type` on VBUS detach; on `PHY_STATE_DISCONNECT`, `rockchip_usb2phy_sm_work()` powers off the port, enables `ls_det_clr`/`ls_det_en`, and returns without rearming `sm_work`, while `rockchip_usb2phy_linestate_irq()` disables `ls_det_en`, clears `ls_det_clr`, and re-invokes `rockchip_usb2phy_sm_work()`. [F210, F211]
- In `phy-rockchip-inno-hdmi.c`, `inno_hdmi_phy_rk3328_clk_recalc_rate()` must round `vco` to kHz (`DIV_ROUND_CLOSEST((unsigned long)vco, 1000) * 1000`); `inno_hdmi_phy_power_off()` must clear `inno->tmdsclock = 0` so `set_rate()` does not short-circuit on power-on; `pre_pll_cfg_table`, `post_pll_cfg_table`, `rk3228_phy_cfg`, and `rk3328_phy_cfg` require a zeroed sentinel, with `post_pll_cfg_table` and `phy_cfg_table` sorted by `.tmdsclock` ascending. [F206, F207, F231]
- In `phy-rockchip-inno-dsidphy.c`, `inno_mipi_dphy_timing` tables must be sorted by `.rate` ascending, and `inno_dsidphy_mipi_mode_enable()` must clamp `i` to `num_timings - 1`, guard `lpx >= 2` before `lpx -= 2` in `MAX_1GHZ` mode, and loop all 5 `FIRST_ADDRESS` banks (`REGISTER_PART_CLOCK_LANE`..`DATA3_LANE`) for registers `0x05`..`0x12`; in `phy-rockchip-inno-csidphy.c` and `phy-rockchip-dphy-rx0.c`, `hsfreq_ranges` must be sorted by `.range_h` ascending and `pwrctl_offset`/`calib_offset >= 0` and `reg->valid` checked before use; `rockchip_emmc_phy_power()` must return `0` when `rate == 0` without polling `PHYCTRL_IS_DLLRDY`. [F191, F212, F229, F230, F243]

## Synchronization

- In `rockchip-iommu.c`, `rk_domain->dt_lock` nests outside `rk_domain->iommus_lock` (never acquire `dt_lock` under `iommus_lock`); `rk_dte_get_page_table()` (using `GFP_ATOMIC | rk_ops->gfp_flags`), `rk_iommu_map_iova()`, and `rk_iommu_unmap_iova()` require `dt_lock`, while `rk_domain->iommus` walks/mutations and `rk_iommu_zap_iova()` require `iommus_lock`. [F158, F159, F288]
- In `rk3x_i2c_xfer_common()`, hold `i2c->lock` across `clk_enable()`, `rk3x_i2c_setup()`, timeout recovery, and `clk_disable()`, unlocking only during transfer wait (in polling mode, call `disable_irq(i2c->irq)` after unlock before `rk3x_i2c_start()`/`rk3x_i2c_wait_xfer_poll()` and `enable_irq()` before relocking). [F149, F162]
- In `pcie-rockchip-ep.c`, `rockchip_pcie_ep_setup_irq()` must set `ep->perst_asserted = true` and `IRQ_NOAUTOEN` on `ep->perst_irq`, and `rockchip_pcie_ep_stop()` must set `perst_asserted = true` and `disable_irq(ep->perst_irq)` before `cancel_delayed_work_sync(&ep->link_training)`, guarding `enable_irq`/`disable_irq(ep->perst_irq)` on `rockchip->perst_gpio != NULL`. [F181, F278]
- In `rockchip_saradc_conversion()`, set `info->last_chan = chan` under `info->lock` before `rockchip_saradc_start()`; in `rockchip_usb2phy_linestate_irq()`, unlock `rport->mutex` before calling `rockchip_usb2phy_sm_work()`. [F167, F214]

## Object Lifetimes

- In `rockchip-iommu.c`, second-level page tables in `rk_domain->dt` persist across `rk_iommu_unmap()` and are unmapped/freed only in `rk_iommu_domain_free()`; `rk_iommu_attach_device()` must detach via `rk_iommu_identity_attach(&rk_identity_domain, dev)` before adding `iommu->node` to `rk_domain->iommus`, and call it again on `rk_iommu_enable()` failure. [F139, F141]
- In `rockchip-iommu.c`, `rk_iommu_of_xlate()` must `devm_kzalloc()` `rk_iommudata` on `&iommu_dev->dev` and call `platform_device_put(iommu_dev)`; `rk_iommu_release_device()` must call `device_link_del(data->link)` (created with `DL_FLAG_STATELESS`); `rk_iommu_probe()` must init clocks, runtime PM, IRQs, and DMA mask before `iommu_device_sysfs_add()`/`iommu_device_register()`; `rk_iommu_shutdown()` must `devm_free_irq()` before `pm_runtime_force_suspend()`; and `rk_iommu_zap_iova()`/`rk_iommu_irq()` may touch MMU regs/clocks only when `pm_runtime_get_if_in_use(iommu->dev) > 0` (balancing with `clk_bulk_disable()` and `pm_runtime_put()`). [F142, F143, F170, F268, F269]
- `rockchip_pcie_deinit_phys()` must call `phy_power_off()` only on lanes in `rockchip->lanes_map` while calling `phy_exit()` on all `MAX_LANE_NUM` PHYs; `rockchip_pcie_suspend_noirq()` must mask `PCIE_CLIENT_INT_MASK` and `PCIE_CORE_INT_MASK` before `rockchip_pcie_wait_l2()` and re-enable via `rockchip_pcie_enable_interrupts()` on failure. [F144, F171]
- `rk3x_i2c_probe()` error paths and `rk3x_i2c_remove()` must call `clk_unprepare(i2c->pclk)` and `clk_unprepare(i2c->clk)` after `clk_notifier_unregister()` even when `pclk == clk`; `rockchip_mbox_isr()` and `rockchip_mbox_shutdown()` must clear `mb->chans[idx].msg = NULL`; `dw_mci_rockchip_probe()` must unwind runtime PM on `dw_mci_pltfm_register()` failure and `dw_mci_rockchip_remove()` must call `pm_runtime_get_sync()` before `dw_mci_pltfm_remove()`; `rockchip_emmc_phy_init()`/`exit()` must manage `rk_phy->emmcclk` via non-devm `clk_get_optional()` (setting `NULL` on `IS_ERR`) and `clk_put()`; `inno_hdmi_phy_rk3328_init()` must call `nvmem_cell_put(cell)` and `kfree(efuse_buf)`. [F148, F151, F152, F153, F154]

## API Contracts

- In `rockchip-iommu.c`, `rk_table_flush()` takes `count` in `u32` entries while `rk_iommu_unmap_iova()`/`zap_iova()` take byte `size`; `rk_iommu_enable_stall()` must check `rk_iommu_is_paging_enabled(iommu)` before issuing `RK_MMU_CMD_ENABLE_STALL`; `rk_iommu_attach_device()` must return `0` when `rk_iommu_from_dev(dev)` is `NULL`. [F185, F270, F303]
- In `pcie-rockchip-host.c`, config accessors return `PCIBIOS_*` codes, zero `*val = 0` on read errors, and reject `PCI_SLOT(devfn) != 0` on root/child buses via `rockchip_pcie_valid_device()`; `rockchip_pcie_wr_own_conf()` must use 32-bit `readl`/`writel` RMW for `size < 4`; RC `perst_gpio` must be requested `GPIOD_OUT_LOW` and held low until `PCIE_CLIENT_LINK_TRAIN_ENABLE` + `PCIE_T_PVPERL_MS`, and Gen2 retraining (`PCI_EXP_LNKCTL_RL`) requires Gen1 `PCIE_LINK_UP` and `PCI_EXP_LNKCTL2_TLS_5_0GT`. [F178, F228, F273, F274, F304]
- `rockchip_pcie_prog_ob_atu()`/`ib_atu()` take `num_pass_bits` as `bits - 1` (and `ib_atu` shifts `lower_addr` left by 8) whereas `rockchip_pcie_prog_ep_ob_atu()` takes full bits and subtracts 1 internally; EP outbound ATU alignment (`rockchip_pcie_epc_features.align` and `rockchip_pcie_ep_align_addr()`) is `ROCKCHIP_PCIE_AT_SIZE_ALIGN` (256); `rockchip_pcie_ep_set_bar()` must clamp size to `>= MIN_EP_APERTURE` and round via `1ULL << fls64(sz - 1)`; `rockchip_pcie_ep_send_msi_irq()` treats `interrupt_num` as 1-based (`(interrupt_num - 1) & data_mask`). [F179, F300, F305, F306]
- `rk3x_i2c_setup()` returns consumed messages (1 or 2) or negative errno, and `rk3x_i2c_xfer_common()` returns `ret < 0 ? ret : num`; `dw_mci_rk3288_set_ios()` doubles `ciu_clk` (`2 * ios->clock * RK3288_CLKGEN_DIV`, 180-deg phase) for 8-bit `MMC_TIMING_MMC_DDR52` and resets `host->current_speed = 0` when `host->bus_hz` changes; `econfig` and `otp_config` must set `.add_legacy_fixed_of_cells = true` and `rockchip_efuse_match` `.data` must be `nvmem_reg_read_t` pointers. [F193, F263, F299, F311]
- In `phy-rockchip-inno-usb2.c`, pass `phy->dev.parent` (not `&phy->dev`) to `dev_get_drvdata()` for `struct rockchip_usb2phy *`; in `phy-rockchip-inno-hdmi.c`, `inno_write/read/update_bits/poll()` take 1-based register indices (multiplied by 4 internally), `inno_hdmi_phy_get_pre_pll_cfg()` returns `ERR_PTR(-EINVAL)`, and `inno_hdmi_phy_rk3228_clk_round_rate()` must reject `cfg->fracdiv != 0`; in `phy-rockchip-inno-dsidphy.c`, `inno_dsidphy_configure()` requires `PHY_MODE_MIPI_DPHY` and `phy_mipi_dphy_config_validate()`, `power_on()` requires `MIPI_DPHY` or `LVDS`, and `cfg->clk_pre` (in UI) divides by `BITS_PER_BYTE` while picosecond fields divide by `t_txbyteclkhs`. [F176, F192, F266, F309, F310]

## Error Handling

- On encountering a valid PTE at `pte_count`, `rk_iommu_map_iova()` must roll back via `rk_iommu_unmap_iova(rk_domain, pte_addr, pte_dma, pte_count * SPAGE_SIZE)` under `dt_lock`. [F140]
- Guard optional `rockchip->vpcie12v`/`vpcie3v3` with `!IS_ERR()`; in `rockchip_pcie_init_port()`/`host_init_port()`, `i` must hold the count of active PHYs at `goto err_power_off_phy`/`err_exit_phy` (resetting `i = MAX_LANE_NUM` before `err_exit_phy`); in `rockchip_pcie_ep_init_ob_mem()`, set `err` to a negative errno if `pci_epc_mem_alloc_addr()` fails after `pci_epc_multi_mem_init()`; in `rockchip_usb2phy_otg_port_init()`, do not clobber `ret` with `property_enabled()` and jump to `out` on `devm_extcon_register_notifier()` error. [F172, F174, F177, F238]
- On `rockchip_saradc_conversion()` error, callers must call `rockchip_saradc_power_down(info)` before unlocking `info->lock`, and `rockchip_saradc_trigger_handler()` must always call `iio_trigger_notify_done(i_dev->trig)`. [F150, F298]

## External Contracts

- In `rockchip_saradc_trigger_handler()`, zero-initialize the stack scan buffer `data` (`u16 values[SARADC_MAX_CHANNELS]`, where variant `num_channels <= SARADC_MAX_CHANNELS`) before `iio_for_each_active_channel(i_dev, i)`, indexing `i_dev->channels[i]` with `i` and `data.values[j]` with a separate counter `j`. [F245, F267, F297]

## Known Pitfalls

- In `rockchip-iommu.c`, `rk_dte_pt_address_v2()` must widen `dte` to `u64` before shifting by `DTE_HI_SHIFT2` (32) / `DTE_HI_SHIFT1` (24), and `phys_to_virt(pt_phys)` (`void *`) must be cast to `u32 *` before adding `rk_iova_pte_index(iova)` (while `pt_phys`/`dt_dma` add `index * sizeof(u32)`). [F249, F261]
- `PCIE_ADDR_MASK` must be 64-bit (`GENMASK_ULL(63, MIN_AXI_ADDR_BITS_PASSED)`); `rockchip_pcie_ep_write_header()` must not apply shifted masks like `GENMASK(31, 16)` to unshifted `pci_epf_header` fields before shifting; and `ROCKCHIP_PCIE_EP_MSI_CTRL_REG` accesses must use `u32` variables with `PCI_MSI_FLAGS_*` shifted by `ROCKCHIP_PCIE_EP_MSI_FLAGS_OFFSET` (16). [F173, F246, F247]
- In `rockchip_mmc_set_internal_phase()`, guard `!rate` before dividing, pre-scale `delay` to `10000000` before multiplying by `remainder`, and clamp with `min_t(u32, delay, 255)`; in `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_cfg` arrays must end with `{ .reg = 0 }` and any valid entry with `.reg == 0` (`rk3576`/`rk3588`) must be at index 0; in `phy-rockchip-inno-hdmi.c` and `phy-rockchip-inno-dsidphy.c`, never mix `RK3228_*`/`RK3328_*` macros, and use `u64` + `do_div()`/`div_u64()` for `(u64)rate * bus_width / 8`, `vco`, `(u64)fout * _prediv`, `(u64)_fbdiv * fref`, and `PSEC_PER_SEC` math. [F232, F241, F254, F256, F257]
