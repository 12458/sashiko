# SCHEDULER — kernel/sched (part 4)

Internal scheduler header (`sched.h`), RT and Stop classes (`rt.c`, `stop_task.c`), PELT (`pelt.c`, `pelt.h`), global loadavg (`loadavg.c`), scheduler syscalls (`syscalls.c`), domain topology (`topology.c`), `/proc/schedstat` (`stats.c`, `stats.h`), and waitqueues (`wait.c`, `wait_bit.c`, `swait.c`).

## Architecture & Data Flow

- `struct sched_class` instances must use `DEFINE_SCHED_CLASS(name)` between `__sched_class_highest` and `__sched_class_lowest` (`sched_class_above(a, b)` is `a < b`). In `next_active_class()`, skipping `fair_sched_class` (`scx_switched_all()`) must precede skipping `ext_sched_class` (`!scx_enabled()`) without `else if`. [F467, F484]
- `DEQUEUE_SLEEP`, `DEQUEUE_SAVE`, `DEQUEUE_MOVE`, `DEQUEUE_NOCLOCK`, `DEQUEUE_MIGRATING`, and `DEQUEUE_DELAYED` must match `ENQUEUE_WAKEUP`, `ENQUEUE_RESTORE`, `ENQUEUE_MOVE`, `ENQUEUE_NOCLOCK`, `ENQUEUE_MIGRATING`, and `ENQUEUE_DELAYED` bit values. In `put_prev_set_next_task()`, `__put_prev_set_next_dl_server(rq, prev, next)` must always run, even when `next == prev`. [F444, F445]
- `struct rq::nr_pinned` (`RQ_nr_pinned`) must be `unsigned int` for `this_rq_pinned()`. `rq->nr_uninterruptible` is updated under `rq->__lock` and can be negative per-CPU (only the cross-CPU sum is valid). On 64-bit, `scale_load_down(w)` clamps non-zero shifted weights to `>= 2UL` (`MIN_SHARES`). `uclamp_bucket_id()` must clamp `clamp_value / UCLAMP_BUCKET_DELTA` to `UCLAMP_BUCKETS - 1`. [F379, F494, F495, F529]
- `__mm_cid_try_get()` must clamp `mm->max_nr_cid` to `min(READ_ONCE(mm->nr_cpus_allowed), atomic_read(&mm->mm_users))` before reading `pcpu_cid->recent_cid`, reusing it only if `!mm_cid_is_unset(cid) && cid < max_nr_cid`. [F447]
- In `rt.c`, check `rt_entity_is_task(rt_se)` or `!group_rt_rq(rt_se)` before `rt_task_of(rt_se)`. `dequeue_rt_stack()` must dequeue top-down from root to `rt_se` before `dequeue_top_rt_rq()`. `rt_prio_array::bitmap` is sized `MAX_RT_PRIO + 1` with sentinel bit `MAX_RT_PRIO` set, while `array->queue` has `MAX_RT_PRIO` entries. `inc_rt_prio_smp()`/`dec_rt_prio_smp()` must call `cpupri_set()` only when `rt_rq == &rq->rt && rq->online`. [F409, F423, F424, F454]
- `enqueue_pushable_task()` and `dequeue_pushable_task()` must update `highest_prio.next`, `overloaded`, `rto_mask`, and `rto_count` together, and `set_next_task_rt()` must call `dequeue_pushable_task()`. `move_entity()` skips relisting only when `(flags & (DEQUEUE_SAVE | DEQUEUE_MOVE)) == DEQUEUE_SAVE`; in `__sched_setscheduler()`, if `pi && rt_effective_prio(p, newprio) == oldprio`, clear `DEQUEUE_MOVE`. Unthrottling a runnable `rt_rq` in `do_sched_rt_period_timer()` when `rq->curr == rq->idle` requires `rq_clock_cancel_skipupdate(rq)`. [F425, F427, F432, F474]
- `__sched_setscheduler()` enforces `attr->sched_priority <= MAX_RT_PRIO - 1` and `rt_policy(policy) == (attr->sched_priority != 0)` before `__setscheduler_params()`, which sets `p->timer_slack_ns = 0` for RT/DL and restores `p->default_timer_slack_ns` when leaving RT/DL. `__setscheduler_uclamp()`/`uclamp_reset()` must preserve `uc_se->user_defined` clamps unless `SCHED_FLAG_UTIL_CLAMP_{MIN,MAX}` is set. [F433, F434, F451]
- `decay_load(val, n)` returns `0` if `n > LOAD_AVG_PERIOD * 63`, shifts `val >>= local_n / LOAD_AVG_PERIOD`, and reduces `local_n %= LOAD_AVG_PERIOD` before indexing `runnable_avg_yN_inv`. `___update_load_avg()` divides `*_sum` by `get_pelt_divider(sa)`, and `__update_load_avg_se()` calls `cfs_se_util_change(&se->avg)`. On migration in `__update_stats_wait_end()`, `stats->wait_start` stores pre-migration `delta` so `__update_stats_wait_start()` subtracts it on the destination CPU. [F440, F441, F458]
- Allocations of `sched_domain`, `sched_group`, `sched_group_capacity`, and `asym_cap_data` must add `cpumask_size()` to `sizeof(...)`. `sched_domain_topology_level` arrays must end with `{ .mask = NULL }`. `sd->groups` is circular (built via `for_each_cpu_wrap(i, span, cpu)`), terminating on `sg == sd->groups`. `build_sched_domains()` must run `claim_allocations()` and `init_sched_groups_capacity()` in descending CPU order (`i = nr_cpumask_bits - 1` down to `0`). [F462, F465, F486, F498]
- In `cpu_attach_domain()`, advance `tmp = tmp->parent` only in the `else` branch of `sd_parent_degenerate(tmp, parent)`, and call `update_top_cache_domain(cpu)` (`sd_llc_id` before `sd_share_id`) after attaching `rq->sd`. `highest_flag_domain()` may break early on `!(sd->flags & flag)` only when `flag & SD_SHARED_CHILD_MASK`. `partition_sched_domains_locked()` must call `dl_rebuild_rd_accounting()`, and `rq_attach_root()` must call `__dl_server_attach_root(&rq->fair_server, rq)` if `rq->fair_server.dl_server` is set. [F435, F436, F437, F481, F483]

## Synchronization

- `rq_clock*()` requires `rq->__lock` and `update_rq_clock(rq)`. Lock drops must pair `rq_unpin_lock(rq, rf)` (saving `RQCF_UPDATED` and calling `scx_rq_clock_invalidate(rq)`) with `rq_repin_lock(rq, rf)`. `double_lock_balance()`/`double_rq_lock()` must call `double_rq_clock_clear_update()`. `double_lock_balance(this_rq, busiest)` requires IRQs disabled and pairs with `double_unlock_balance(this_rq, busiest)`; non-trylock dual-rq locking must order by `rq_order_less()`. [F375, F376, F388, F446, F518]
- On `!CONFIG_64BIT`, lockless accesses to `clock_idle`, `clock_pelt_idle`, and `throttled_pelt_idle` must use `u64_u32_load()`/`u64_u32_store()`, and `_update_idle_rq_clock_pelt()` orders `clock_idle` before `clock_pelt_idle` with `smp_wmb()`. `sched_clock_irqtime` must remain a plain `int` (not a `static_key`). `__set_task_cpu(p, cpu)` must call `set_task_rq(p, cpu)` and `smp_wmb()` before `WRITE_ONCE(task_thread_info(p)->cpu, cpu)`. `switched_from()` may drop `rq->__lock`. [F387, F390, F513, F521]
- `mm_cid_put*()` and `mm_cid_pcpu_unset()` require IRQs disabled and cross-CPU `cmpxchg()`/`try_cmpxchg()` on `this_cpu_ptr(pcpu_cid)->cid`. `walk_tg_tree()`, `for_each_rt_rq()`, and `idle_get_state(rq)` require RCU read lock. In `sched_getparam()`, `sched_getattr()`, and `sched_rr_get_interval()`, exit `rcu` and `task_rq_lock` guards before `copy_to_user()`/`put_timespec64()`. [F525, F527, F528, F531]
- In `rt.c`, `rt_b->rt_runtime_lock` nests inside `rq->__lock` and outside `rt_rq->rt_runtime_lock`. `rt_set_overload()` sets `rto_mask` and `smp_wmb()` before `atomic_inc(&rd->rto_count)`, pairing with `smp_rmb()` in `pull_rt_task()` and `atomic_read_acquire(&rd->rto_loop_next)` in `rto_next_cpu()` (which resets `rto_cpu = -1` at `>= nr_cpu_ids` and updates `rto_loop = next` under `rto_lock`). Before `stop_one_cpu_nowait(..., push_cpu_stop, ...)`, call `get_push_task()` under `rq->__lock`, then bracket `raw_spin_rq_unlock()`, `stop_one_cpu_nowait()`, and `raw_spin_rq_lock()` with `preempt_disable()`/`preempt_enable()`. [F394, F396, F478, F517, F520]
- In `__sched_setscheduler()`, `uclamp_validate()` and `cpuset_lock()` (when `dl_policy`) must precede `task_rq_lock(p, &rf)`, with `cpuset_unlock()` on all exit/retry paths; recheck `oldpolicy != p->policy` after locking, and disable preemption before `splice_balance_callbacks(rq)` and `task_rq_unlock()`, running `rt_mutex_adjust_pi(p)` and `balance_callbacks()` before `preempt_enable()`. In `yield_to()`, recheck `task_rq(p) != p_rq` after `double_rq_lock(rq, p_rq)`. [F368, F399, F400, F401]
- `sched_init_numa()` validates `node_distance(i, j)` in `[LOCAL_DISTANCE, NR_DISTANCE_VALUES)`, zeroes `sched_domains_numa_levels` before allocating `sched_domains_numa_masks`, and sets `nr_levels` after publishing; `sched_reset_numa()` zeroes levels/pointers before `synchronize_rcu()` and `kfree()`. `calc_global_nohz()` orders `WRITE_ONCE(calc_load_update, ...)` before `calc_load_idx` increment with `smp_wmb()`, pairing with `smp_rmb()` in `calc_load_write_idx()`. [F378, F402, F463]
- `prepare_to_wait*()` calls `set_current_state(state)` after waitqueue insertion; on `signal_pending_state()` in `prepare_to_wait_event()`/`prepare_to_swait_event()`, unlink via `list_del_init()` under queue lock before returning `-ERESTARTSYS`. `do_wait_intr*()` is entered/exited with `wq->lock` held and returns `-ERESTARTSYS` with `wait` still queued. `wait_woken()` clears `WQ_FLAG_WOKEN` with `smp_store_mb()`, pairing with `smp_mb()` in `woken_wake_function()`. `swake_up_all()` must `list_splice_init()` onto a local list and `list_del_init()` each entry before dropping `q->lock`. [F373, F381, F382, F384, F471]

## Object Lifetimes

- Never dereference `p` after `smp_store_release(&p->on_rq, 0)` in `__block_task(rq, p)` without `p->pi_lock` or a refcount. `push_rt_task()` must pin `next_task` via `get_task_struct()` before `find_lock_lowest_rq()` (which revalidates `!is_migration_disabled(task)`, `cpus_mask`, and `task == pick_next_pushable_task(rq)` if `double_lock_balance()` drops `rq->__lock`), and call `put_task_struct(next_task)` before `goto retry`. [F366, F391, F395]
- `tell_cpu_to_push()` calls `sched_get_rd(rq->rd)` before queueing `rto_push_work`, paired with `sched_put_rd(rd)` in `rto_push_irq_work_func()` when `rto_next_cpu(rd) < 0`. `rq_attach_root()` decrements `old_rd->refcount` before incrementing `rd->refcount` (freeing via `call_rcu(&old_rd->rcu, free_rootdomain)`), so never pass `rd == rq->rd` when `rd->refcount == 1`. [F364, F397]
- `partition_sched_domains_locked()` takes ownership of `doms_new` and `dattr_new`. `sched_setaffinity()` must call `kfree(ac.user_mask)` after `__sched_setaffinity(p, &ac)`. In `build_sched_domains()`, all exit paths must call `__free_domain_allocs(&d, alloc_state, cpu_map)` after `claim_allocations()` NULLs attached per-CPU `sdd` pointers, and `free_sched_groups()` on NUMA overlap groups before `claim_allocations()` must pass `free_sgc = 0`. [F360, F362, F363, F370, F419]
- `finish_wait()`/`finish_swait()` use `!list_empty_careful()` paired with `list_del_init_careful()` in `autoremove_wake_function()`. In `__wait_on_bit_lock()`, when `action` returns non-zero, call `finish_wait()` before `test_and_set_bit()`. [F374, F383]

## API Contracts

- `sched_class::pick_next_task(rq, prev)` must call `put_prev_task(prev)` and `set_next_task_first(next)` when returning a task. `task_tick_rt()`/`task_tick_stop()` must use `@rq` and `@p`, never `this_rq()` or `current`. `cpufreq_update_util(rq, flags)` requires `cpu_of(rq)`, RCU-sched read lock, `rq->__lock`, and updated `rq` clock. [F522, F526, F533]
- `find_lowest_rq()` returns `-1` on failure. `alloc_rt_sched_group()` and `sched_rt_can_attach()` return `1` on success and `0` on failure; `tg_set_rt_bandwidth()` and `sched_group_set_rt_{runtime,period}()` return `0` or `-errno` (checking `> U64_MAX / NSEC_PER_USEC` and mapping `< 0` to `RUNTIME_INF`). [F405, F410, F411]
- `__sched_setscheduler()` must not be called in interrupt context when `pi` is true; `sys_sched_setscheduler()`/`sys_sched_setattr()` must reject `(int)attr.sched_policy < 0` before `SETPARAM_POLICY`; when `rt_group_sched_enabled() && rt_bandwidth_enabled()`, user RT transitions and `sched_rt_can_attach()` must reject zero-runtime non-autogroup task groups. `__normal_prio()` inverts `rt_prio` via `MAX_RT_PRIO - 1 - rt_prio`, while `task_prio(p)` subtracts `MAX_RT_PRIO`. `yield_to()` returns `> 0`, `0`, or `-ESRCH`. `sched_move_task(tsk, for_autogroup)` requires explicit `for_autogroup`. `sched_setaffinity()` checks `ns_capable(..., CAP_SYS_NICE)`, while `user_check_sched_setscheduler()` checks global `capable(CAP_SYS_NICE)` after `task_rlimit(p, ...)` checks. [F415, F416, F417, F418, F515, F540, F541]
- `sched_numa_hop_mask()` requires `rcu_read_lock()` and `IS_ERR_OR_NULL()` checks. `tl->sd_flags` may be `NULL` and may only return `TOPOLOGY_SD_FLAGS`; call `set_sched_topology()` before `sched_smp_initialized`. `swake_up_all()` must not be called with IRQs disabled (use `swake_up_all_locked()`). `__wake_up_common()` returns residual `nr_exclusive`, whereas `__wake_up_common_lock()` returns woken count. Callers of `wake_up_bit()`/`wake_up_var()` require `smp_mb__after_atomic()` or `smp_mb()` before waking; `wait_bit_action_f` returns `0` to continue or non-zero to abort. [F380, F385, F404, F406, F407, F421, F524, F535]

## Error Handling

- `sched_rt_handler()` must save and restore `sysctl_sched_rt_period` and `sysctl_sched_rt_runtime` on validation failure and call `rebuild_sched_domains()` after unlocking. `sched_numa_find_nth_cpu()` must check `rcu_dereference(sched_domains_numa_masks)` and `bsearch()` result `hop_masks` for `NULL`, returning `nr_cpu_ids`. [F403, F429]

## External Contracts

- Zero-initialize `kattr` and `lp` in `sys_sched_getattr()`/`sys_sched_getparam()`, mask `kattr.sched_flags &= SCHED_FLAG_ALL`, and reject `SCHED_FLAG_SUGOV` when `user` is true. `sched_copy_attr()` zeroes `*attr`, maps `size == 0` to `SCHED_ATTR_SIZE_VER0`, writes `sizeof(*attr)` to `uattr->size` on `-E2BIG`, and requires `size >= SCHED_ATTR_SIZE_VER1` for `SCHED_FLAG_UTIL_CLAMP`. `sys_sched_getaffinity()` checks `len * BITS_PER_BYTE >= nr_cpu_ids` and `sizeof(unsigned long)` alignment, uses `zalloc_cpumask_var()`, and returns `min(len, cpumask_size())`; `get_user_cpu_mask()` clears `new_mask` when `len < cpumask_size()`. Bump `SCHEDSTAT_VERSION` when changing `show_schedstat()`, and filter `schedstat_start()` through `cpu_online_mask`. [F413, F414, F449, F450, F452, F539, F543]

## Known Pitfalls

- In `__sched_setscheduler()`, if `prev_class != next_class` and `p->se.sched_delayed` is set, call `dequeue_task(rq, p, DEQUEUE_SLEEP | DEQUEUE_DELAYED | DEQUEUE_NOCLOCK)` before switching `p->sched_class`. `___update_load_sum()` must check `(s64)delta < 0` before `delta >>= 10` and advance `last_update_time` by `delta << 10`. Use `div_u64()`/`do_div()` for 64-bit divisions in `rt.c` and `DIV_ROUND_UP()` in `watchdog()`. [F431, F489, F493]
- Map `node = numa_nearest_node(node, N_CPU)` in `sched_numa_find_nth_cpu()`, check `!masks[i][j]` in `sched_numa_find_closest()`, and check `b == k->masks` before `*((struct cpumask ***)b - 1)` in `hop_cmp()`. Snapshot `curr->flags` before `curr->func` and use `list_for_each_entry_safe_from()` in `__wake_up_common()`. Snapshot `now = READ_ONCE(jiffies)` once in `bit_wait_timeout()` with `time_after_eq()`. Match both `key.flags` and `key.bit_nr` (`-1` for var waiters, never calling `test_bit()` in `var_wake_function()`) on `bit_wait_table`. [F443, F464, F469, F496, F502, F509]
