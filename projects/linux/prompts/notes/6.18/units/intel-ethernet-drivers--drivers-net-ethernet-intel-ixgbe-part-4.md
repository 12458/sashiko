# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 4)

This component of `ixgbe` implements PHY and SFP+/QSFP+ transceiver management (`ixgbe_phy.c`), IEEE 1588 PTP clock and timestamping across 82599/X540/X550/E610 (`ixgbe_ptp.c`), SR-IOV VF provisioning and PF-VF mailbox handling (`ixgbe_sriov.c`), hwmon thermal sysfs attributes (`ixgbe_sysfs.c`), X540 MAC/EEPROM/PHY ops (`ixgbe_x540.c`), and register/descriptor types (`ixgbe_type.h`, `ixgbe_type_e610.h`).

## Architecture & Data Flow

- `struct ixgbe_hw::back` and `struct mii_bus::priv` must point to the owning `struct ixgbe_adapter`. On C3000 SoCs (`x550em_a`), `ixgbe_mii_bus_init()` must only register an `mii_bus` on the lowest-numbered PCI function (`ixgbe_x550em_a_has_mii(hw)`), and its MDIO callbacks must acquire `IXGBE_GSSR_TOKEN_SM | IXGBE_GSSR_PHY0_SM` in addition to `hw->phy.phy_semaphore_mask`. [F909, F950]
- In `ixgbe_identify_sfp_module_generic()` and `ixgbe_identify_qsfp_module_generic()`, call `hw->mac.ops.set_lan_id(hw)` before assigning core-specific `sfp_type` values, set `sfp_setup_needed` if `sfp_type` changes, and reset `sfp_type = ixgbe_sfp_type_not_present` on I2C read errors. In `ixgbe_get_sfp_init_sequence_offsets()` and `ixgbe_reset_phy_nl()`, traverse EEPROM SFP init tables until `IXGBE_PHY_INIT_END_NL` (`0xFFFF`) and `IXGBE_CONTROL_NL` with `edata == IXGBE_CONTROL_EOL_NL` (`0x0FFF`), rejecting `0` or `0xFFFF` offsets. [F908, F917]
- In `ixgbe_reset_hw_X540()`, reset `hw->mac.num_rar_entries` to `IXGBE_X540_MAX_TX_QUEUES` (128) before `init_rx_addrs(hw)`, and decrement `num_rar_entries` when programming a valid `san_addr` into `num_rar_entries - 1`. In `ixgbe_calc_eeprom_checksum_X540()`, skip EEPROM section pointers (`IXGBE_PCIE_ANALOG_PTR` .. `IXGBE_FW_PTR - 1`, excluding `PHY_PTR` and `OPTION_ROM_PTR`) if pointer or length is `0`, `0xFFFF`, `pointer >= word_size`, or `pointer + length >= word_size`. [F906, F918]
- On X550, X550EM_x, x550em_a, and E610, time registers store 32-bit billions of cycles and 32-bit cycles; `ixgbe_ptp_read_X550()`, `ixgbe_ptp_convert_to_hwtstamp()`, and `ixgbe_ptp_gettimex()` must linearize them via `timespec64_to_ns()`, and `ixgbe_ptp_setup_sdp_X550()` must split `clock_edge` via `ns_to_timespec64()`. Compare jiffies timestamps (`last_overflow_check`, `last_rx_ptp_check`, `last_rx_timestamp`, `ptp_tx_start`) with `time_is_before_jiffies()` / `time_after()`, never `<` or `>`. [F937, F939]
- In `ixgbe_pci_sriov_enable()`, `num_vfs` must not exceed `limit - num_rx_pools` (`limit`: `IXGBE_MAX_VFS_8TC` 16 for >4 TCs, `4TC` 32 for 2..4 TCs, `1TC` 64 for <=1 TC; `num_rx_pools` = weight of `fwd_bitmask`). `__ixgbe_enable_sriov()` must reject enabling with `-EINVAL` if `adapter->xdp_prog` is loaded, set `SRIOV_ENABLED` and `VMDQ_ENABLED`, set `ring_feature[RING_F_VMDQ].offset = num_vfs`, cap `dcb_cfg.num_tcs`, and clear `IXGBE_FLAG2_RSC_CAPABLE` and `RSC_ENABLED`. [F891, F912, F984]
- In `ixgbe_set_vf_multicasts()`, clamp `FIELD_GET(IXGBE_VT_MSGINFO_MASK, msgbuf[0])` to `IXGBE_MAX_VF_MC_ENTRIES` (30) before indexing `hash_list` or `vfinfo->vf_mc_hashes`, and save hashes/count in `vfinfo` so `ixgbe_restore_vf_multicasts()` can reprogram `IXGBE_MTA`, `mta_in_use`, and `IXGBE_VMOLR_ROMPE`. In `ixgbe_set_vf_macvlan()`, keep `adapter->vf_mvs.l` and `mac_table` in sync via `ixgbe_del_mac_filter()` (`index <= 1`) and only mark an entry `free = false` after `ixgbe_add_mac_filter()` succeeds. [F893, F896, F910]
- In `ixgbe_clear_vf_vlans()`, clearing a VF bit from `IXGBE_VLVFB(word)` must preserve `IXGBE_VLVF(i)` and `IXGBE_VFTA` if any other VF pool bit remains set across the 64-bit `VLVFB` pair, and preserve `IXGBE_VFTA` if `VMDQ_P(0)` remains set. In `ixgbe_set_vf_vlan()`, adding a VF VLAN present in `active_vlans` must first add `VMDQ_P(0)` via `set_vfta()`, and removing/failing a VF VLAN when `active_vlans` or `VLAN_PROMISC` is set must call `ixgbe_update_pf_promisc_vlvf()`. [F894, F895]
- Across VF resets (`ixgbe_vf_reset_event()`, `ixgbe_vf_reset_msg()`), clear transient VF state (VF VLANs, `num_vf_mc_hashes`, IPsec SAs, MACVLANs, `vf_api`, `PFMBMEM`, `PVFTDWBAHn/L`) while preserving and re-applying PF-configured `vfinfo` fields (`pf_vlan`, `pf_qos`, `spoofchk_enabled`, `vf_mac_addresses`, `pf_set_mac`, `link_enable`). In `ixgbe_ndo_set_vf_vlan()`, if `vfinfo[vf].pf_vlan` is already non-zero, call `ixgbe_disable_port_vlan()` before `ixgbe_enable_port_vlan()`. [F897, F899]
- VF Tx rate limiting (`ixgbe_ndo_set_vf_bw()`) requires a 10Gbps link stored in `adapter->vf_rate_link_speed`; if `ixgbe_check_vf_rate_limit()` sees `ixgbe_link_mbps(adapter) != vf_rate_link_speed`, it must zero `vf_rate_link_speed` and all `vfinfo[i].tx_rate` and reprogram `IXGBE_RTTBCNRC`. [F900]
- Unaligned binary firmware, OROM, and ACI/HIC structs in `ixgbe_type_e610.h` and `ixgbe_type.h` (`ixgbe_orom_civd_info`, `ixgbe_aci_cmd_get_link_status_data`, `ixgbe_aci_cmd_nvm_comp_tbl`, `ixgbe_hic_internal_phy_req`) must be marked `__packed`. [F919]

## Synchronization

- `ixgbe_get_swfw_sync_semaphore()` acquires `IXGBE_SWSM_SMBI` before `IXGBE_SWFW_REGSMP` and must call `ixgbe_release_swfw_sync_semaphore()` on `REGSMP` timeout (releasing `REGSMP` before `SMBI`). `ixgbe_acquire_swfw_sync_X540()` must release the register semaphore before sleeping or returning. Both sleep via `usleep_range()`, so X540 SWFW semaphore callers (`eeprom_ops_X540`, locked `phy_ops_X540`) must run in process context. [F859, F860, F980]
- Code holding `IXGBE_GSSR_EEP_SM` (`ixgbe_calc_eeprom_checksum_X540()` and locked sections of `ixgbe_validate_eeprom_checksum_X540()` / `ixgbe_update_eeprom_checksum_X540()`) must call `ixgbe_read_eerd_generic()` and `ixgbe_write_eewr_generic()`, never `hw->eeprom.ops.read`/`write`. [F861]
- In `ixgbe_read/write_i2c_combined_generic_int()` and `ixgbe_read/write_i2c_byte_generic_int()`, when `lock` is true, error recovery `ixgbe_i2c_bus_clear(hw)` must run before releasing `hw->phy.phy_semaphore_mask`. `ixgbe_write_i2c_byte_generic_int()` acquires `swfw_mask` once before its retry loop and must not release it at `fail:` inside the loop. [F862, F933]
- In `ixgbe_ptp_init()`, `spin_lock_init(&adapter->tmreg_lock)` must precede `ixgbe_ptp_create_clock()`, and `INIT_WORK(&adapter->ptp_tx_work, ...)` plus `ixgbe_ptp_reset()` must complete before `set_bit(__IXGBE_PTP_RUNNING, &adapter->state)`. `adapter->tmreg_lock` (`spin_lock_irqsave`) protects `hw_tc`, `hw_cc`, and `IXGBE_SYSTIMR/L/H` across all PTP time/cyclecounter functions. [F863, F864, F869]
- `ixgbe_ptp_start_cyclecounter()` publishes `adapter->base_incval` via `WRITE_ONCE()` + `smp_mb()`, pairing with `smp_mb()` + `READ_ONCE()` in `ixgbe_ptp_adjfine_82599()`. In `ixgbe_ptp_suspend()` and `ixgbe_ptp_tx_hang()`, `cancel_work_sync(&adapter->ptp_tx_work)` must precede `ixgbe_ptp_clear_tx_timestamp()`. [F865, F871]
- In `ixgbe_pci_sriov_enable()`, `__ixgbe_enable_sriov()`, `ixgbe_vf_configuration()`, and `ixgbe_sriov_reinit()` must complete before `pci_enable_sriov()`. In `ixgbe_disable_sriov()`, set `adapter->num_vfs = 0` under `spin_lock_irqsave(&adapter->vfs_lock, ...)` before dropping `vfdev` refs and freeing `vfinfo` and `mv_list`. [F872, F873]
- `ixgbe_msg_task()` runs in hardirq context (`ixgbe_msix_other`) holding `adapter->vfs_lock`, so VF mailbox/reset handlers must never sleep or use `GFP_KERNEL`. `ixgbe_rcv_msg_from_vf()` and `ixgbe_rcv_ack_from_vf()` must NACK any non-`IXGBE_VF_RESET` message/ACK unless `vfinfo[vf].clear_to_send` is set. [F874, F973]

## Object Lifetimes

- `adapter->vf_mvs.l` entries in `ixgbe_alloc_vf_macvlans()` are elements of the single `kcalloc` array `adapter->mv_list` and must only be freed together via `kfree(adapter->mv_list)`. [F851]
- In `ixgbe_ptp_create_clock()`, reuse `adapter->ptp_clock` if `!IS_ERR_OR_NULL()` without resetting `tstamp_config`; if `ptp_clock_register()` fails, set `adapter->ptp_clock = NULL` before returning `PTR_ERR`. Only `ixgbe_ptp_stop()` may call `ptp_clock_unregister()`, and only after `ixgbe_ptp_suspend()` clears `__IXGBE_PTP_RUNNING`, disables SDP PPS, and drains `ptp_tx_work`. [F853, F866, F998]
- In `ixgbe_ptp_tx_hwtstamp()`, set `adapter->ptp_tx_skb = NULL` and `clear_bit_unlock(__IXGBE_PTP_TX_IN_PROGRESS, &adapter->state)` before calling `skb_tstamp_tx()` and `dev_kfree_skb_any()` on the local `skb` pointer. [F854]
- `ixgbe_get_first_secondary_devfn()` drops `rp_pdev` on all paths and returns a refcounted `pci_dev *` that callers (`ixgbe_x550em_a_has_mii()`) must pass to `pci_dev_put()`. [F856]
- `ixgbe_mii_bus_init()` uses `devm_mdiobus_alloc()` with non-devm `mdiobus_register()`, so teardown must call `mdiobus_unregister()` without `mdiobus_free()`. `ixgbe_sysfs_init()` uses `devm_kzalloc()` and `devm_hwmon_device_register_with_groups()`, so `ixgbe_sysfs_exit()` must not manually free or unregister them. [F857, F858]

## API Contracts

- `ixgbe_read/write_i2c_byte_generic()` take `(hw, byte_offset, dev_addr, data)` (offset before address), whereas `ixgbe_read/write_i2c_combined_generic_int()` take `(hw, addr, reg, val, lock)`. `ixgbe_read/write_phy_reg_generic()` and `_mdi()` take `(hw, reg_addr, device_type, phy_data)` (register before MMD), unlike `ixgbe_mii_bus_read_generic_c45(bus, addr, devad, regnum)`. [F887, F888]
- `ixgbe_reset_phy_generic()`, `ixgbe_setup_phy_link_generic()`, `ixgbe_setup_phy_link_tnx()`, `ixgbe_reset_phy_nl()`, and `ixgbe_set_copper_phy_power()` must abort if `ixgbe_check_reset_blocked(hw)` is true (`MNG_VETO`). [F965]
- Null-check optional `mac.ops` (`init_thermal_sensor_thresh`, `disable_mdd`, `handle_mdd`, `restore_mdd_vf`, `set_ethertype_anti_spoofing`, all `NULL` in `mac_ops_X540`) and `adapter->ptp_setup_sdp` (`NULL` on 82599EB) before calling. Pass `DECLARE_BITMAP(vf_bitmap, 64)` (zero-initialized) to `handle_mdd`. [F881, F883, F951]
- In `ixgbe_sysfs_init()`, return `0` without registering hwmon if `init_thermal_sensor_thresh` is `NULL` or fails; only add attributes for `sensor[i].location != 0`, and call `sysfs_attr_init()` in `ixgbe_add_hwmon_attr()`. [F885, F999]
- On X550 and E610, `ixgbe_ptp_read_X550()` and `ixgbe_ptp_gettimex()` must read `IXGBE_SYSTIMR` before `SYSTIML`/`SYSTIMH` to latch system time. For packet timestamps, read `IXGBE_RXSTMPL`/`TXSTMPL` before `RXSTMPH`/`TXSTMPH` (which unlatches the registers), and read the high register in hang/clear paths (`ixgbe_ptp_clear_tx_timestamp()`). [F955, F956]
- `ixgbe_blink_led_start/stop_X540()` must reject `index > 3` before `IXGBE_LED_*` macros. `eeprom_ops.read_buffer`/`write_buffer` (`ixgbe_read_eerd/write_eewr_buffer_X540()`) take `offset` and `words` as 16-bit word counts. On X540 `revision_id == 0`, `ixgbe_update_flash_X540()` must re-read `IXGBE_EEC` after initial `FLUP` and repeat `FLUP` + poll if `IXGBE_EEC_SEC1VAL` is set. [F942, F946, F964]
- Call `IXGBE_WRITE_FLUSH(hw)` before each `IXGBE_QDE` write in `ixgbe_write_qde()`, and between `ixgbe_read_mbx()` and `ixgbe_write_mbx()` in `ixgbe_rcv_msg_from_vf()`. [F972]

## Error Handling

- `ixgbe_calc_eeprom_checksum_X540()` returns a 16-bit checksum or `-EIO`, and `ixgbe_set_vf_mac()` returns a non-negative RAR index or negative errno; callers must store results in a signed `int` and test `< 0`. Conversely, `ixgbe_check_for_rst/msg/ack()` return `0` when an event bit is found and `-EIO` otherwise, so test `!ixgbe_check_for_*(hw, vf)`. [F877, F878, F879]
- `ixgbe_ptp_set_timestamp_mode()` must stage flag changes in local `aflags` and only commit `adapter->flags` (and `adapter->tstamp_config` in `ixgbe_ptp_hwtstamp_set()`) after validation and register writes succeed. `ixgbe_negotiate_vf_api()` must log unsupported API versions with `e_dbg` before returning `-1`. [F886, F993]

## External Contracts

- `ixgbe_pci_sriov_enable()` must return positive `num_vfs` on success or negative errno. SFF-8472 masks in `ixgbe_phy.h` (`IXGBE_SFF_BASEBX10_CAPABLE = 0x40`) must be powers of two, and `IXGBE_SFF_BITRATE_NOMINAL` is in 100 MBd units (`0xD` = 1.25 Gb/s). [F880, F889]
- `ixgbe_sysfs.c` show callbacks (`temp`, `cautionthresh`, `maxopthresh`) must multiply Celsius fields by `1000` (millidegrees), and `ixgbe_add_hwmon_attr()` must use 1-based `offset + 1`. In `ixgbe_ptp_rx_pktstamp()`, extract the `__le64` timestamp at `skb->len - IXGBE_TS_HDR_LEN` and trim `IXGBE_TS_HDR_LEN` (8) bytes via `__pskb_trim()`. [F890, F920]
- `ixgbe_set_vf_lpe()` must reject `max_frame` outside `[ETH_MIN_MTU, IXGBE_MAX_JUMBO_FRAME_SIZE]`, and on 82599EB with legacy VF APIs reject `> ETH_FRAME_LEN + ETH_FCS_LEN` and clear the VF bit in `IXGBE_VFRE`. `ixgbe_get_vf_reta()` and `ixgbe_ndo_set_vf_rss_query_en()` are restricted to 82599 and X540 (packing 16 2-bit RETA entries per `u32` into 8 dwords at `&msgbuf[1]`). [F911, F921]
- For untrusted VFs (`!vfinfo[vf].trusted`): if `pf_set_mac` is set, reject `new_mac != vf_mac_addresses` in `ixgbe_set_vf_mac_addr()` and `index > 0` in `ixgbe_set_vf_macvlan_msg()`; in `ixgbe_update_vf_xcast_mode()`, clamp `xcast_mode` to `IXGBEVF_XCAST_MODE_MULTI`. Reject `PROMISC` with `-EOPNOTSUPP` on `<= ixgbe_mac_82599EB` or `-EPERM` if PF `IXGBE_FCTRL_UPE` is clear. In `ixgbe_set_vf_vlan_msg()`, reject requests when `pf_vlan` or `hw_tcs` is non-zero, and return `0` without calling `ixgbe_set_vf_vlan()` when `!vid && !add`. [F988, F989, F990]

## Known Pitfalls

- In `ixgbe_get_vfs()`, the `pci_get_device()` loop must `continue` (not `break`) when `vf >= adapter->num_vfs` and call `pci_dev_get(vfdev)` for every stored `vfinfo[vf].vfdev`. In `ixgbe_reset_phy_generic()`, reset polling breaks when `IXGBE_MDIO_TX_VENDOR_ALARMS_3_RST_MASK` sets for `ixgbe_phy_x550em_ext_t`, but when `MDIO_CTRL1_RESET` clears for other PHYs. [F923, F931]
- In `ixgbe_ptp_setup_sdp_X540/X550()`, widen `NS_PER_HALF_SEC` and `rem` to `u64` before `<< cc->shift` (28 on X540) and `div_u64()`. Cast `IXGBE_READ_REG()` on `IXGBE_SYSTIMH`/`TXSTMPH`/`RXSTMPH` to `u64` before `<< 32`. [F935, F936]
- Index 64-pool bitmap registers (`IXGBE_VFRE`, `VFTE`, `VMECM`, `VLVFB`) by `vf / 32` with bit `vf % 32`. In `ixgbe_sysfs.c`, `hwmon_attr::name` is 12 bytes (exact fit for `"temp%u_input"` with `IXGBE_MAX_SENSORS == 3`), and `hwmon_buff` arrays hold at most 4 attrs per sensor (`IXGBE_MAX_SENSORS * 4` plus trailing `NULL` in `attrs`). [F940, F947, F948]
