# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 7)

This unit implements GPU page tables (`xe_pt`, `xe_pt_walk`), SVM (`xe_svm`/`drm_gpusvm`), PXP (`xe_pxp`), RTP (`xe_rtp`, `xe_reg_sr`, `xe_reg_whitelist`), ring ops (`xe_ring_ops`), scheduler jobs (`xe_sched_job`), shrinker (`xe_shrinker`), query ioctls (`xe_query`), sync objects (`xe_sync`), range fences (`xe_range_fence`), suballocation (`xe_sa`), SR-IOV, and survivability mode.

## Architecture & Data Flow

- Only `pt->level > 0` are `struct xe_pt_dir` (`as_xe_pt_dir(pt)` requires `pt->level > 0`). `xe_pt_destroy` recurses only when `pt->num_live > 0` via `pt_dir->staging`, so `xe_pt_insert_entry` must set `parent->base.staging[offset]` and bump `parent->num_live` for non-preexisting parents. `entry->pt_entries` is indexed by `0..qwords - 1` (relative to `entry->ofs`), while `pt_dir->children`/`staging` use `entry->ofs + j`. [F775, F867, F895]
- `unbind_range_prepare()` sets `pt_op->vma = XE_INVALID_VMA` (`0xdeaddeadull`); `xe_pt_commit()` and `xe_pt_commit_prepare_locks_assert()` must guard against `XE_INVALID_VMA` before dereferencing. `xe_pt_abort_bind()`, `xe_pt_abort_unbind()`, and `xe_pt_update_ops_abort()` unwind in reverse with signed `int` (`for (i = count - 1; i >= 0; --i)`), skipping `!pt_op->vma || i >= pt_update_ops->current_op`. [F816, F868]
- `bind_op_prepare` sets `BIT(tile->id)` in `vma->tile_staged`, `unbind_op_prepare` checks `(tile_present | tile_staged) & BIT(tile->id)`, and `bind_op_commit` moves it to `tile_present`. On non-LR VMs, rebinding bumps `vm->tlb_flush_seqno`, and `xe_sched_job_arm` compares it to `q->tlb_flush_seqno` (or `vm->batch_invalidate_tlb`) to sync `q->tlb_flush_seqno` and set `job->ring_ops_flush_tlb = true`. [F837, F851]
- In `xe_pt_stage_bind_entry`, compact 64K L0 (`XE_PDE_64K`) requires full 2MB L1 coverage (`covers`) and `xe_pt_scan_64K`; non-compact L0 VRAM PTEs with `needs_64K` require `xe_pt_is_pte_ps64K` or return `-EINVAL`. `vm->xef` must be set before `xe_pt_create()` for `XE_BO_FLAG_PINNED_LATE_RESTORE` and `vm->xef->client` registration. [F825, F936]
- `xe_res_next()` returns immediately when `cur->remaining == 0`, and `__xe_res_dma_next()` guards coalescing with `cur->dma_seg_size - start < cur->remaining`. [F869]
- In `xe_pxp_pm_suspend`, if `pxp->status == XE_PXP_ACTIVE` or (`XE_PXP_NEEDS_TERMINATION` and `key_instance != last_suspend_key_instance`), bump `key_instance`, call `pxp_invalidate_queues`, and sync `last_suspend_key_instance`. `__exec_queue_add` requires `pxp->status == XE_PXP_ACTIVE` under `pxp->mutex` with a runtime PM ref; `__pxp_exec_queue_remove` drops that ref and sets `q->pxp.type = DRM_XE_PXP_TYPE_NONE`. [F843, F844]
- `gsccs_send_message()` checks `msg_in_size` and `msg_out_size_max` against `gsc_res->inout_size - sizeof(struct intel_gsc_mtl_header)`, calls `xe_device_wmb(xe)` before `pxp_pkt_submit`, and clamps `reply_size` to `msg_out_size_max` before copying from `msg_out`. [F861, F923]
- `xe_reg_sr_add` requires overlapping `sr->xa` entries to have disjoint `clr_bits`/`set_bits` and identical `reg.raw` (`compatible_entries`). `whitelist_apply_to_hwe()` stops at `slot == RING_MAX_NONPRIV_SLOTS`. In `rule_matches()`, a failed rule advances `i` to `XE_RTP_MATCH_OR` and resets `rcount = 0` so outer `++i` hits the next clause. [F872, F877, F909]
- `xe_reg_sr_apply_mmio` skips VFs (`IS_SRIOV_VF`), verifies `xe_force_wake_get(..., XE_FORCEWAKE_ALL)` via `xe_force_wake_ref_has_domain`, and always calls `xe_force_wake_put`. In `apply_one_mmio`, `reg.masked` sets `entry->clr_bits << 16` without reading HW (`clr_bits` must cover `set_bits` in lower 16 bits); non-masked uses `xe_gt_mcr_unicast_read_any`/`multicast_write` if `reg.mcr`, else `xe_mmio_read32`/`write32`. [F891, F910, F911]
- `xe_ring_ops.c` emission fills `u32 dw[MAX_JOB_SIZE_DW]` (`i <= MAX_JOB_SIZE_DW`) and passes `i * sizeof(*dw)` to `xe_lrc_write_ring()`. Ring TLB/AuxCCS invalidations (`MI_INVALIDATE_TLB`, `emit_pipe_invalidate`, `emit_flush_invalidate`, `emit_aux_table_inv`) must be bracketed by `preparser_disable(true)` and `preparser_disable(false)` before `emit_bb_start`. [F898, F937]
- `xe_shrinker_walk()` runs up to three `__xe_shrinker_walk()` passes (1: `no_wait_gpu = true, writeback = false`; 2: GPU wait; 3: `writeback = true`), stopping once `*scanned >= to_scan` or on error. [F873]
- `XE_SRIOV_MODE_NONE = 1` catches calls before `xe_sriov_probe_early()`. PF VFIDs are `1..totalvfs` (0 is `PFID`), so `xe->sriov.pf.vfs` has `1 + totalvfs` elements (`vfid <= totalvfs`). If PF is disabled (`pf_continue_as_native`), call `pci_sriov_set_totalvfs(pdev, 0)`. [F819, F863, F908]
- VF migration (`vf_migration_init_early`) requires `GRAPHICS_VER(xe) >= 20` and, on igfx (`!IS_DGFX`), GuC ABI `>= 1.23.0` before `xe_sriov_vf_ccs_init`. In `vf_post_migration_recovery`, `vf_post_migration_shutdown` pauses GuC submission/resets before `gt_vf_post_migration_fixups` (rebasing GGTT nodes, HWSPs, rings, and CT messages by `xe_gt_sriov_vf_ggtt_shift(gt)`), and `vf_post_migration_kickstart` resumes IRQs/submission before `vf_post_migration_notify_resfix_done`. [F849, F906, F907]
- `xe_sched_job_snapshot_capture()` sets `snapshot->batch_addr_len = q->width` before indexing `batch_addr[i]`. `__xe_sa_bo_manager_init()` sizes BO to `size`, passing `size - guard` to `drm_suballoc_manager_init()` and `cpu_ptr`. Survivability mode requires `IS_DGFX(xe) && !IS_SRIOV_VF(xe) && platform >= XE_BATTLEMAGE`, and `enable_boot_survivability_mode` sets `survivability->mode = true` before `xe_heci_gsc_init(xe)`. [F897, F900, F913]

## Synchronization

- When `needs_svm_lock` is true, `xe_pt_svm_userptr_pre_commit` takes `xe_svm_notifier_lock(vm)` and transfers it on success to `xe_pt_update_ops_run`, which unlocks after `xe_pt_commit` and `op_commit`. `xe_pt_stage_bind()` holds `xe_svm_notifier_lock(vm)` while checking `xe_svm_range_pages_valid`, `xe_svm_range_has_dma_mapping`, and reading `dma_addr`. [F776, F807]
- `xe_pt_zap_ptes_range` requires `notifier_lock` (write) or `notifier_lock` (read) + `vm->lock` (write); setting `range->tile_invalidated` must not fail before TLB invalidation. In `xe_svm_invalidate()`, `xe_device_wmb(xe)` and `xe_vm_range_tilemask_tlb_inval()` must finish before `xe_svm_range_notifier_event_end()` unmaps DMA pages. `xe_svm_garbage_collector()` drops `garbage_collector.lock` before `__xe_svm_garbage_collector()`. [F804, F805, F933]
- When `needs_invalidation` is set in `xe_pt_update_ops_run`, `xe_tlb_inval_job_push` chains `ijob` (and `mjob` if `tile->media_gt`) onto the migration `fence`, adding `ifence`/`mfence` to `xe_vm_resv(vm)` and `op_commit`. [F935]
- `xe_range_fence_insert()` initializes `rfence->tree` and `rfence->fence` before `dma_fence_add_callback`. `xe_range_fence_signal_notify` and `xe_range_fence_tree_remove_all()` never mutate `tree->root` directly; they queue nodes onto `tree->list` via `llist_add`, drained by `__xe_range_fence_tree_cleanup()`. [F794, F881, F924]
- `xe_sync_in_fence_get()` requires `vm->lock`. `xe_fence_set_error()` checks `DMA_FENCE_FLAG_SIGNALED_BIT` and calls `dma_fence_set_error()` under `spin_lock_irqsave(&fence->lock, ...)`. [F793, F809]
- `xe_pxp_init()` calls `complete_all()` on `pxp->activation` and `pxp->termination` before setting `xe->pxp = pxp`. Waiters (`pxp_start`, `pxp_terminate`, `xe_pxp_pm_suspend`) must never hold `pxp->mutex` during `wait_for_completion_timeout()`. `pxp_invalidate_queues()` pins queues via `xe_exec_queue_get_unless_zero()` and moves them to a local list under `pxp->queues.lock` before dropping the lock to call `xe_exec_queue_kill()` and `__pxp_exec_queue_remove()`. [F795, F797, F800]
- `xe_pxp_irq_handler` (under `xe->irq.lock`) sets `pxp->irq.events` and queues `pxp->irq.work`; `pxp_irq_work` uses `spin_lock_irq(&xe->irq.lock)` to read/clear `events` and guards `pxp_terminate(pxp)` with `xe_pm_runtime_get_if_active` / `put`. In `xe_shrinker_runtime_pm_get()`, if `xe_pm_runtime_get_if_active(xe)` is false, synchronous `xe_pm_runtime_get(xe)` is allowed only when `xe_rpm_reclaim_safe(xe) && !ttm_bo_shrink_avoid_wait()`; otherwise queue `shrinker->pm_worker`. [F802, F917, F929]
- `xe_sriov_vf_ccs_fini()` sets LRC ring tail to head and `xe_sriov_vf_ccs_detach_bo()` overwrites `bb->cs` with `MI_NOOP` before freeing. `vf_post_migration_recovery()` clears each GT's bit in `gt_flags` via `vf_get_next_migrated_gt_id()` before fixups, and `vf_post_migration_notify_resfix_done()` skips GTs where `gt_vf_post_migration_needed(gt)` became true again. [F810, F882]

## Object Lifetimes

- Before `xe_pt_commit_prepare_bind`, `entries[i].pt_entries[j].pt` owns new subtrees (`xe_pt_cancel_bind`); `xe_pt_commit_prepare_bind` swaps new subtrees into `pt_dir->staging` and displaced subtrees into `pt_entries[j].pt` (`xe_pt_commit` or `xe_pt_abort_bind`). [F772]
- `xe_sync_entry_signal()` sets `sync->chain_fence = NULL` after `drm_syncobj_add_point`, and takes `dma_fence_get(fence)` and `user_fence_get(sync->ufence)` before `dma_fence_add_callback`. `user_fence_create()`/`destroy()` pair `mmgrab()`/`mmdrop()`, and `user_fence_worker()` sets `ufence->signalled = 1` and copies to `ufence->addr` inside `mmget_not_zero()` + `kthread_use_mm()`/`unuse_mm()` + `mmput()` before calling `wake_up_all(&ufence->xe->ufence_wq)`. [F778, F792, F857, F947]
- `pxp_fini` calls `destroy_workqueue(pxp->irq.wq)` before `xe_pxp_destroy_execution_resources(pxp)`, and `destroy_gsc_client_resources` tears down `q`, `bo`, `vm` in reverse order. `xe_shrinker_fini` calls `shrinker_free(shrinker->shrink)` before `flush_work(&shrinker->pm_worker)` and `kfree(shrinker)`. `xe_shrinker_walk` restores `ctx->no_wait_gpu` before returning after pass 1, and `xe_shrinker_scan` balances `xe_shrinker_runtime_pm_get`/`put`. [F783, F789, F790]
- `xe_drm_pagemap_populate_mm` takes `xe_bo_get(bo)` and `xe_pm_runtime_get_noresume(xe)` before `drm_pagemap_migrate_to_devmem`, releasing both via `xe_svm_devmem_release(&bo->devmem_allocation)` on failure. `xe_devm_add` calls `devm_release_mem_region` if `devm_memremap_pages` fails. `xe_svm_unmap_address_range` holds `drm_gpusvm_range_get(range)` across `__xe_svm_garbage_collector()`. `__xe_svm_handle_pagefault` clears `xe_vm_set_validation_exec(vm, NULL)` immediately after `xe_vm_range_rebind`. [F784, F785, F786, F920]
- `job_alloc` and `job_free` both select `xe_sched_job_parallel_slab` when `xe_exec_queue_is_parallel(q) || xe_sched_job_is_migration(q)` (migration jobs use 2 `job->ptrs[]` and a 2-element `batch_addr` array), and `xe_sched_job_arm` nulls `lrc_fence` and `chain_fence` when arming. [F852, F896]

## API Contracts

- `xe_range_fence_insert` always consumes `@rfence` ownership. `xe_pt_walk_range()`/`shared()` take exclusive `end` (`last + 1`), whereas `xe_range_fence_*` and `xe_vm_pgtable_update_ops` use inclusive `last`. Partially covered new page tables (`!covers`) from `xe_pt_create()` must be initialized with `xe_pt_populate_empty()` or `xe_pt_clear()`. `xe_pt_walk_shared()` callbacks receive parent `level` and operate on `*child` at `level - 1`, checking `parent != *child` before killing `*child`. [F777, F827, F864, F875]
- `drm_gpusvm_ctx.device_private_page_owner` is `xe_svm_devm_owner(vm->xe)` for SVM faults and `NULL` for `userptr`. `xe_svm_invalidate()` must call `xe_svm_range_notifier_event_end()` even when `xe_vm_is_closed(vm)`. Notifier lock helpers in `xe_svm.h` are guarded by `CONFIG_DRM_GPUSVM`, not `CONFIG_DRM_XE_GPUSVM`. [F824, F953, F955]
- RTP `*_STEP` rules are half-open `[start, end)`, while `*_VERSION_RANGE` rules are closed `[start, end]`. `xe_rtp_process()` requires a `{}` sentinel (`rules == NULL`). `xe_rtp_process_ctx_enable_active_tracking()` requires a pre-cleared `unsigned long` bitmap of `BITS_TO_LONGS(n_entries)` words. [F831, F870, F902]
- `xe_pxp_get_readiness_status()` returns `< 0` (error/disabled), `0` (in-progress), or `1` (ready); callers requiring active PXP (`pxp_start`, `query_pxp_status`) treat `0` as `-EBUSY`. When `sa_manager->is_iomem` is true, CPU writes via `xe_sa_bo_cpu_addr(sa_bo)` require `xe_sa_bo_flush_write(sa_bo)`. [F811, F850]
- `xe_shrinker_count()`/`scan()` only count/scan non-purgeable BOs for swap when `sc->gfp_mask & __GFP_FS`, and set `writeback` only when `!ctx.no_wait_gpu && (sc->gfp_mask & __GFP_IO)`. Return `SHRINK_EMPTY` from `count` when 0 pages are reclaimable, and `SHRINK_STOP` from `scan` when `nr_scanned == 0`. In `query_mem_regions()`, `XE_PL_TT` `man->size` is in pages (`<< PAGE_SHIFT` for bytes), while VRAM `man->size` is in bytes. [F944, F950, F951]

## Error Handling

- On `dma_fence_array_create` failure in `xe_sync_in_fence_get`, decrement `vm->composite_fence_seqno`, `dma_fence_put` all `current_fence` entries, and `kfree(fences)`. When `xe_sync_entry_parse()` fails, do not call `xe_sync_entry_cleanup()` on the failed entry (`sync->ufence` may be an `ERR_PTR`). [F779, F823]
- `__xe_shrinker_walk()` and `xe_shrinker_walk()` return signed `s64`; check `lret >= 0` before adding to unsigned counters. `__xe_sa_bo_new()` rejects `size > sa_manager->base.size` with `ERR_PTR(-ENOBUFS)` before `drm_suballoc_new()`. On `-EAGAIN` from `xe_svm_range_set_default_attr()`, `xe_svm_garbage_collector()` records `ret = -EAGAIN` and keeps draining `range_list`, and `xe_svm_handle_pagefault()` re-lookups `vma` via `xe_vm_find_vma_by_addr()` before retrying. [F812, F880, F956]

## External Contracts

- `xe_query_ioctl()` requires zero `extensions`/`reserved` and bounds-checks `query->query` with `array_index_nospec()`. Every `xe_query_funcs` handler writes `size` and returns 0 when `query->size == 0`, or returns `-EINVAL` if `query->size != size`. `query_engine_cycles()` rejects VFs (`-EOPNOTSUPP`), holds `XE_FORCEWAKE_ALL` around `hwe_read_timestamp` (retrying up to 3 times on UDW rollover), and only writes output fields via `put_user()`. [F826, F858, F922, F940]
- `mem_region_mask` and `near_mem_regions`/`far_mem_regions` use bit 0 for SYSMEM and `BIT(vram->id) << 1` for VRAM to match `query_mem_regions()` instance indices, where `used` and `cpu_visible_used` are populated unconditionally without `perfmon_capable()`. `xe_sync_entry_parse()` rejects non-zero `upper_32_bits(sync_in.addr)` for syncobjs and unaligned `sync_in.addr & 0x7` for `USER_FENCE` with `-EINVAL`. `xe_survivability_mode_fini` must never clear user configfs attributes. [F853, F855, F860, F943]

## Known Pitfalls

- Page-table shifts in `xe_pt_walk`/`xe_pt` must use 64-bit `1ull << shift` (shifts reach 48), and `xe_pt_offset` guards `walk->shifts[level + 1]` with `level < walk->max_level`. At level 1 in `xe_pt_stage_bind_entry`, reset `walk->shifts = xe_normal_pt_shifts` before checking if L0 can use `xe_compact_pt_shifts`. [F835, F884, F885]
- `gsccs_send_message` poisons `gsc_res->msg_out` before submission and `gsc_res->msg_in` after reading via `xe_gsc_poison_header`. In `xe_rtp.c`, `GRAPHICS_*` rules only match non-media GTs and `MEDIA_*` only match media GTs unless `*_ANY_GT` is used. [F845, F847]
- In `xe_svm_copy()`, advancing `i` by `NR_PAGES(order) - 1` requires recomputing `chunk` and `last` from `i`. `xe_vram_region_page_to_dpa` widens `page_to_pfn(page)` to `u64` before `<< PAGE_SHIFT` and asserts `>= vr->hpa_base`. `populate_survivability_info()` reads `reg_value = info[id].value` before `id = aux_history_offset(reg_value)`. `get_ccs_bb_pool_size` uses `div64_u64` and `DIV_ROUND_UP_ULL` on 64-bit `sys_mem_size`. `xe_sched_job_started`/`completed` use `!__dma_fence_is_later(...)` for LRC seqnos. `query_oa_units()` advances a byte pointer by `sizeof(*du) + j * sizeof(du->eci[0])` per unit. [F879, F883, F888, F889, F892, F899]
