# USB NETWORKING DRIVERS — drivers/net/usb (part 3)

This unit comprises four `usbnet`-based USB Ethernet minidrivers: `smsc95xx` (Microchip/SMSC LAN95xx), `sr9700` (CoreChip SR9700), `sr9800` (CoreChip SR9800), and `zaurus` (Sharp Zaurus PDAs and pseudo-MDLM/BLAN devices), providing USB vendor register access, MDIO/phylib and IRQ domain integration, Wake-on-LAN/runtime PM, and device-specific RX/TX SKB framing and checksum offloading.

## Architecture & Data Flow

- In `smsc95xx_rx_fixup`, after pulling `4 + NET_IP_ALIGN` header bytes (relying on `EVENT_NO_IP_ALIGN` in `smsc95xx_bind` and `HW_CFG_RXDOFF_` = `NET_IP_ALIGN << 9` in `smsc95xx_reset`), check `size` (`RX_STS_FL_`) against `skb->len` and `ETH_FRAME_LEN + 12` before cloning/copying/pulling. On `RX_STS_ES_`, record stats and still pull `size` and `align_count = (4 - ((size + NET_IP_ALIGN) % 4)) % 4` so later sub-frames are processed. When `NETIF_F_RXCSUM` is set, call `smsc95xx_rx_csum_offload` before `skb_trim(..., len - 4)` strips the FCS, reading `skb_tail_pointer(skb) - 2` via `get_unaligned()` before trimming 2 bytes. [F234, F255, F305, F309]
- In `sr9700_rx_fixup`, signed `int len = (skb->data[1] | (skb->data[2] << 8)) - 4` must be validated for `len < 0`, `len > ETH_FRAME_LEN`, and `len > skb->len` before allocating `sr_skb`, copying from `skb->data + 3`, or advancing `skb`. In `sr_rx_fixup` (`sr9800.c`), each sub-frame's 11-bit `size` (`header & 0x7ff`) must match `(~header >> 16) & 0x07ff` and satisfy `size <= dev->net->mtu + ETH_HLEN + VLAN_HLEN` and `size + offset <= skb->len`, advancing `offset` by `(size + 1) & 0xfffe` to reach exact `skb->len`. [F240, F243]
- When `sr_tx_fixup` shifts `skb->data` in place via `memmove(skb->head + 4, skb->data, skb->len)` (only when `!skb_cloned(skb)` and `headroom + tailroom >= 4 + padlen`), it must immediately call `skb_set_tail_pointer(skb, skb->len)` before pushing the header or appending `padbytes`. [F229]
- `struct sr_data` (`sr9800.h`) must not exceed `sizeof(unsigned long[5])` (20 bytes on 32-bit); async USB writes in `sr_set_multicast` and `sr_set_mac_address` must use `data->multi_filter` and `data->mac_addr` in `dev->data`, never stack buffers. [F230]
- USB interrupt URB callbacks must validate `urb->actual_length` (`== 4` in `smsc95xx_status`; `>= 8` in `sr9700_status` and `sr_status`) before reading `urb->transfer_buffer`. [F246]
- In `smsc95xx`, `pdata->mac_cr` persists across calls: in `smsc95xx_set_multicast`, each branch (`IFF_PROMISC` / `IFF_ALLMULTI` / `!netdev_mc_empty` / `else`) must clear the other two bits among `MAC_CR_PRMS_`, `MAC_CR_MCPAS_`, and `MAC_CR_HPFILT_`, and mask the 6-bit `smsc95xx_hash` shift with `0x1F` (`0x01 << (bitnum & 0x1F)`) while `bitnum & 0x20` selects `hash_hi` vs `hash_lo`. In `smsc95xx_mac_update_fullduplex`, toggle `MAC_CR_FDPX_` and `MAC_CR_RCVOWN_` with opposite polarities. [F247, F248, F261]
- In `sr9700_set_multicast` and `sr_set_multicast`, `IFF_PROMISC` must precede `IFF_ALLMULTI || netdev_mc_count(...) > MAX`, which must precede `netdev_for_each_mc_addr`. Shifting unsigned 32-bit `ether_crc(ETH_ALEN, ha->addr)` right by 26 bounds the hash to `0..63` so `>> 3` indexes the 8-byte filter array and `& 0x7` shifts by `< 8`. [F249, F262]
- Both `smsc95xx_reset` (via `smsc95xx_set_mac_address`) and `sr9800_reset` (via `SR_CMD_WRITE_NODE_ID`) must reprogram the MAC address registers from `dev->net->dev_addr` after chip reset. In `smsc95xx_set_pauseparam`, store `pause` fields in `pdata->pause_rx`/`pause_tx`/`pause_autoneg` unconditionally, but force `pause_autoneg_rx`/`tx` passed to `phy_set_asym_pause` to `false` when `!pause->autoneg`. [F252, F286]
- In `smsc95xx`, `pdata->features` (`FEATURE_8_WAKEUP_FILTERS`, `FEATURE_PHY_NLP_CROSSOVER`, `FEATURE_REMOTE_WAKEUP`) is probed from `ID_REV >> 16` in `smsc95xx_bind`. Use `PHY_EDPD_CONFIG` and `SUSPEND1` autosuspend only when `FEATURE_PHY_NLP_CROSSOVER` is set. In `smsc95xx_suspend`, `WUFF` write loops iterate over all `wuff_filter_count` slots (4 or 8), so zero-allocate `filter_mask` for 32 `u32` words (`LAN9500A_WUFF_NUM * 4`) and zero-initialize `command[2]`, `offset[2]`, and `crc[4]` for 8 filters; when `pdata->wolopts & WAKE_PHY` is set, enter `SUSPEND1` and `goto done` only when `!link_up` (otherwise configure `PM_CTL_ED_EN_` and enter `SUSPEND0`). In `smsc95xx_resume`, snapshot `pdata->suspend_flags` and clear it to `0` before any failable register access. [F224, F253, F271, F280]
- Busy-wait loops in `smsc95xx_phy_wait_not_busy`, `smsc95xx_wait_eeprom`, and `smsc95xx_eeprom_confirm_not_busy` must snapshot `unsigned long start_time = jiffies` and check `time_after(jiffies, start_time + HZ)`. `smsc95xx_ethtool_getregs` must step byte offset `i` by `sizeof(u32)` from `ID_REV` through `COE_CR` while indexing `u32 *data` by `j++`, matching `COE_CR - ID_REV + sizeof(u32)` from `smsc95xx_ethtool_getregslen`. [F267, F272]

## Synchronization

- In `smsc95xx_bind`, set `dev->driver_priv = pdata` and `spin_lock_init(&pdata->mac_cr_lock)` before `smsc95xx_reset(dev)`. All `pdata->mac_cr` updates outside `smsc95xx_reset` must use `spin_lock_irqsave(&pdata->mac_cr_lock, flags)` and unlock before `smsc95xx_write_reg` or `smsc95xx_write_reg_async`. [F202, F295]
- In `smsc95xx_bind`, initialize `pdata->is_internal_phy`, `pdata->mdiobus->phy_mask`, `pdata->mdiobus->priv = dev`, and bus callbacks before `mdiobus_register(pdata->mdiobus)`, and configure `pdata->phydev->irq` (`irq_domain` mapping and `irq_chip` handler) before `phy_connect_direct()`. In `smsc95xx_status`, call `generic_handle_domain_irq(pdata->irqdomain, PHY_HWIRQ)` under `local_irq_save(flags)`, and never perform sleeping USB accesses in `pdata->irqchip` callbacks. [F206, F297]
- In `smsc95xx_suspend`, `smsc95xx_resume`, and `smsc95xx_reset_resume`, set `pdata->pm_task = current` before any register/PHY access and clear `pdata->pm_task = NULL` on every exit path so `smsc95xx_read_reg`/`smsc95xx_write_reg` use `_nopm` USB helpers only for the active PM task. [F209]
- Indirect PHY/EEPROM sequences must hold `dev->phy_mutex`: `smsc95xx_mdio_read`, `smsc95xx_mdio_write`, `smsc95xx_mdiobus_reset`, and `smsc95xx_phy_wait_not_busy` (`smsc95xx.c`); `sr_share_read_word` and `sr_share_write_word` (`sr9700.c`, programming `SR_EPAR`/`SR_EPCR`, calling `wait_phy_eeprom_ready`, and clearing `SR_EPCR` to `0x0` before unlock); and `sr_mdio_read`/`sr_mdio_write` (`sr9800.c`, calling `sr_set_sw_mii(dev)` before `SR_CMD_READ_MII_REG`/`SR_CMD_WRITE_MII_REG` and `sr_set_hw_mii(dev)` before unlock). [F231, F287, F298]

## Object Lifetimes

- `smsc95xx_bind` error unwind and `smsc95xx_unbind` must release resources in reverse order: `phy_disconnect`, `mdiobus_unregister`, `mdiobus_free`, `irq_dispose_mapping`, `irq_domain_remove`, `irq_domain_free_fwnode`, `kfree(pdata)`. `smsc95xx_info` must pair `.reset = smsc95xx_reset` and `.check_connect = smsc95xx_start_phy` (`phy_start` after MAC reset on open) with `.stop = smsc95xx_stop` (`phy_stop` on close before URBs stop or `phy_disconnect`). [F192, F198, F274]
- When `FEATURE_REMOTE_WAKEUP` is absent in `pdata->features`, `smsc95xx_manage_power` must pair `usb_autopm_get_interface_no_resume(dev->intf)` (`on` true) with `usb_autopm_put_interface(dev->intf)` (`on` false), and never adjust autopm when `FEATURE_REMOTE_WAKEUP` is set. In `smsc95xx_suspend`, `filter_mask` must be freed via `kfree(filter_mask)` both on `smsc95xx_write_reg(dev, WUFF, ...)` failure before `goto done` and right after the loop. [F195, F197]
- In `sr9800_bind`, call `sr_get_phyid` only after `SR_CMD_SW_PHY_SELECT` and `sr9800_phy_powerup`, polling `MII_PHYSID1` until neither `0` nor `0xFFFF` (up to 100 ms). In `zaurus.c`, any `driver_info` with `.bind = zaurus_bind` must set `.unbind = usbnet_cdc_unbind`. [F193, F290]
- `smsc95xx_tx_fixup`, `sr9700_tx_fixup`, `sr_tx_fixup`, and `zaurus_tx_fixup` must unshare/expand `skb` (`skb_cow_head` or `!skb_cloned` + `skb_copy_expand`) before mutating `skb->data` or pushing/putting framing bytes, and call `dev_kfree_skb_any(skb)` whenever returning `NULL`. [F308]

## API Contracts

- In `smsc95xx_rx_fixup`, `sr9700_rx_fixup`, and `sr_rx_fixup`, copy sub-frames into new SKBs via `netdev_alloc_skb_ip_align()` without using `skb_clone()` or modifying `skb->truesize`. In `smsc95xx_rx_fixup` and `sr9700_rx_fixup` (no `FLAG_MULTI_PACKET`), pass non-final frames to `usbnet_skb_return()` (plus `skb_pull(skb, len + SR_RX_OVERHEAD)` in `sr9700_rx_fixup`), and trim the final frame in-place in `skb`, returning non-zero (`2` in `sr9700_rx_fixup`) without freeing `skb`. In `sr_rx_fixup` (`FLAG_MULTI_PACKET` set), pass every sub-frame including the last to `usbnet_skb_return()` and let `usbnet` free the outer `skb`; in `sr_tx_fixup`, call `usbnet_set_skb_tx_stats(skb, 1, 0)` on every returned `skb`. All `.tx_fixup`/`.rx_fixup` allocations must use the caller's `gfp_t flags` or `GFP_ATOMIC`-safe helpers, never `GFP_KERNEL`. [F190, F191, F256, F300, F302, F304]
- `smsc95xx_read_reg`, `smsc95xx_write_reg`, `sr_read`, `sr_write`, `sr_read_cmd`, and `sr_write_cmd` return positive byte counts on success, not `0`; callers must test `ret < 0` for error and never `return ret` from functions returning `0`/-errno on completion or timeout. [F212]
- `sr9700_get_eeprom` and `sr_get_eeprom` cast `data` to `__le16 *` and read 2-byte words, so reject odd `eeprom->len` (and odd `eeprom->offset` in `sr9700_get_eeprom`) with `-EINVAL`, and pass word offsets (`eeprom->offset / 2 + i`) to `sr_read_eeprom_word`. [F220]
- `smsc95xx_init_mac_address` must pass `&dev->udev->dev` (not `&dev->intf->dev`) to `platform_get_ethdev_address`, validate with `is_valid_ether_addr`, and fall back to EEPROM (`EEPROM_MAC_OFFSET`) then `eth_hw_addr_random`. [F285]
- `blan_mdlm_bind` (`zaurus.c`) must verify that `intf->cur_altsetting->extra` has one `USB_CDC_MDLM_TYPE` descriptor (`blan_guid` or `safe_guid`) and one `USB_CDC_MDLM_DETAIL_TYPE` descriptor with `bLength == sizeof(*detail) + 2` (SAFE, type 0) or `sizeof(*detail) + 3` (BLAN, type 1) and `(detail->bDetailData[1] & ~0x02) == 0x01`, returning `-ENODEV` otherwise. [F245, F293]

## Error Handling

- Synchronous USB control wrappers (`smsc95xx_read_reg`, `sr_read`, `sr_write`, `sr_read_cmd`, `sr_write_cmd`) must treat non-negative returns from `usbnet_read_cmd`/`usbnet_write_cmd` shorter than the requested length as errors (`-ENODATA` or `-EINVAL`) before reading the buffer. [F210]
- Every `.bind` callback must check `usbnet_get_endpoints(dev, intf)` and propagate errors. In `smsc95xx_bind`, `ret` can be `4` after register/MDIO calls, so NULL/zero failure checks (`irq_create_mapping`, `phy_find_first`) must set `ret` to a negative errno before `goto`. [F213, F214]
- Guard `ndev->phydev` in `smsc95xx_set_pauseparam` (`!phydev`) and `smsc95xx_ioctl` (`!netif_running(netdev)`) before accessing `phydev`. In `smsc95xx_suspend`, any error after `usbnet_suspend` during `PMSG_IS_AUTO(message)` must jump to `done:` to run `usbnet_resume(intf)`. Suppress `netdev_warn()` on `-ENODEV` in `smsc95xx` register/MDIO/duplex helpers, and convert `-ENODEV` to `0` in `smsc95xx_phy_wait_not_busy` and `smsc95xx_mdio_read`. [F217, F278, F313]

## External Contracts

- `smsc95xx_handle_link_change` must call both `smsc95xx_mac_update_fullduplex(dev)` and `usbnet_defer_kevent(dev, EVENT_LINK_CHANGE)`. `smsc95xx_bind` must only advertise `NETIF_F_IP_CSUM`, never `NETIF_F_IPV6_CSUM` or `NETIF_F_HW_CSUM` (hardware lacks IPv6 UDP `0` to `0xffff` conversion). Any `ZAURUS_MASTER_INTERFACE` or `ZAURUS_FAKE_INTERFACE` ID added to `zaurus.c` must also be blacklisted (`.driver_info = 0`) in `cdc_ether.c`. [F222, F292, F306]

## Known Pitfalls

- In `smsc95xx_tx_fixup`, call `skb_cow_head(skb, overhead)` before software checksum writes or `skb_push()`, and evaluate `tx_cmd_b`, `smsc95xx_can_tx_checksum(skb)` (rejecting `skb->len <= 45` or `skb->csum_offset >= (skb->len - skb_checksum_start_offset(skb)) - 5`), and `smsc95xx_calc_csum_preamble(skb)` (truncating offsets to `u16 low_16`/`high_16` before `(high_16 << 16) | low_16`) before `skb_push()`. When `smsc95xx_can_tx_checksum` is false on `CHECKSUM_PARTIAL`, fold `csum_partial()` in software and omit `csum_preamble` and `TX_CMD_B_CSUM_ENABLE`; when true, push the 4-byte `csum_preamble` before the 8-byte `tx_cmd_a`/`tx_cmd_b` header and add `4` to both lengths. [F226, F236, F237, F265, F307]
- In `sr9700_tx_fixup`, sample `len = skb->len` before `__skb_push(skb, SR_TX_OVERHEAD)`, but evaluate `(skb->len % dev->maxpacket) == 0` after `__skb_push` to increment `len`. Access multi-byte wire headers/trailers/padding in SKB and URB buffers via `get_unaligned*`/`put_unaligned*`. [F228, F301]
- In `smsc95xx_wait_eeprom`, check `val & (E2P_CMD_TIMEOUT_ | E2P_CMD_BUSY_)` after the loop because it breaks on either bit. In `smsc95xx_reset`, read-modify-write `LED_GPIO_CFG` (`LED_GPIO_CFG_SPD_LED | LED_GPIO_CFG_LNK_LED | LED_GPIO_CFG_FDX_LED`) rather than overwriting it. In `smsc95xx_enter_suspend0`/`1`/`2`/`3`, mask out `PM_CTL_SUS_MODE_ | PM_CTL_WUPS_ | PM_CTL_PHY_RST_` before setting `PM_CTL_SUS_MODE_*`. [F250, F282, F283]
- In `sr9700.c`, `sr_mdio_read` must override `BMSR_LSTATUS` from `SR_NSR` (`NSR_LINKST`) when `loc == MII_BMSR`. In `sr_get_phyid` (`sr9800.c`), check `sr_mdio_read` for errors (`<= 0` for `MII_PHYSID1`, `< 0` for `MII_PHYSID2`) and mask with `0xffff` before shifting into `u32 phy_id`. [F266, F288]
