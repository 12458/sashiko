# BTRFS FILE SYSTEM — fs/btrfs (part 6)

Implements Btrfs ioctls (subvolume/snapshot, tree search, ino/logical lookup, resize, balance, scrub, quota, encoded I/O, compat ioctls), B-tree extent buffer and DREW locking, maple-tree LRU cache, LZO compression, error/message logging, ordered extents, orphan items, tree printing, and inode properties.

## Architecture & Data Flow
- `btrfs_split_ordered_extent()` requires `len < ordered->num_bytes`, an uncompressed extent (`!(flags & (1U << BTRFS_ORDERED_COMPRESSED))`, `disk_num_bytes == num_bytes`), and `bytes_left == 0 || bytes_left == disk_num_bytes`. Under `root->ordered_extent_lock` and `inode->ordered_tree_lock` it updates `ordered` in place, syncs `bytes_left` (zeroing `new->bytes_left` if `BTRFS_ORDERED_IO_DONE`) and `truncated_len`, and moves `len` data bytes of `btrfs_ordered_sum` (`sum->len` is data bytes, not `sums[]` byte size) to `new->list`. [F716, F726, F796]
- `btrfs_lru_cache_store()` and `btrfs_lru_cache_lookup()` chain a `list_head` per `maple_tree` slot and call `match_entry()` on 64-bit `key` and `gen`. In `btrfs_lru_cache_remove()`, sample `entry->list.prev` before `list_del(&entry->list)`; if `list_empty(prev)`, erase the slot head via `mtree_erase()` and free it with `entry` while decrementing `cache->size`. [F730, F782]
- If `handler->apply()` fails in `btrfs_set_prop()` or `btrfs_inode_inherit_props()` after `btrfs_setxattr()` sets a non-empty xattr, roll it back via `btrfs_setxattr(..., NULL, 0, 0)` without setting `BTRFS_INODE_HAS_PROPS`. In `btrfs_inode_inherit_props()`, `need_reserve` starts `false` and becomes `true` only after an iteration sets a property past all `continue` checks. [F731, F770]
- In `btrfs_fileattr_set()`, call `btrfs_mask_fsflags_for_type()` before `check_fsflags()` (which rejects mutually exclusive `FS_NOCOW_FL`/`FS_COMPR_FL`/`FS_NOCOMP_FL`). When `!fa->flags_valid` (`FS_IOC_FSSETXATTR`), update only `FS_SYNC_FL`, `FS_IMMUTABLE_FL`, `FS_APPEND_FL`, `FS_NODUMP_FL`, and `FS_NOATIME_FL`; on `S_ISREG`, `FS_NOCOW_FL` toggles `BTRFS_INODE_NODATACOW | BTRFS_INODE_NODATASUM` only when `i_size == 0`; update `"btrfs.compression"` before assigning `inode->flags` and calling `btrfs_update_inode_mapping_flags()` and `btrfs_sync_inode_flags_to_i_flags()`. [F732, F781, F819, F820]
- `_btrfs_ioctl_set_received_subvol()` removes any prior non-empty `received_uuid` via `btrfs_uuid_tree_remove()` before overwriting it, and adds the new UUID via `btrfs_uuid_tree_add()` after `btrfs_update_root()`. When `btrfs_ioctl_add_dev()` preempts a paused balance via `btrfs_exclop_start_try_lock()`, restore `BTRFS_EXCLOP_BALANCE_PAUSED` via `btrfs_exclop_balance()` instead of `btrfs_exclop_finish()`. [F734, F735]
- In `btrfs_uring_encoded_read()` and `btrfs_uring_encoded_write()`, reuse `bc->data` without re-importing the user iovec when `IORING_URING_CMD_REISSUE` is set, and never free `bc->data` or `data->iov` on `-EAGAIN` or `-EIOCBQUEUED`. In `copy_compressed_data_to_page()` and `lzo_decompress_bio()`, when `1` to `LZO_LEN - 1` bytes remain in a sector, advance `*cur_out` (zero-padded) and `cur_in` by `sector_bytes_left` so 4-byte (`LZO_LEN`) headers never cross a sector boundary. [F738, F767]

## Synchronization
- Process-context `btrfs_inode::ordered_tree_lock` acquisitions must disable IRQs (`spin_lock_irq` / `spin_lock_irqsave`). `btrfs_split_ordered_extent()` takes `spin_lock_irq(&root->ordered_extent_lock)` before `inode->ordered_tree_lock`. `fs_info->ordered_root_lock` nests inside `root->ordered_extent_lock`, whereas `btrfs_wait_ordered_roots()` must drop `ordered_root_lock` before `btrfs_wait_ordered_extents()`. [F693, F804, F806]
- `alloc_ordered_extent()` initializes all fields, lists, waitqueues, completion, `igrab()`, and `refs = 1` before `insert_ordered_extent()` increments `entry->refs` and publishes it. In `btrfs_remove_ordered_extent()`, erasing `entry->rb_node`, clearing a matching `ordered_tree_last`, and setting `BTRFS_ORDERED_COMPLETE` happen under `ordered_tree_lock` before waking `entry->wait`; when `BTRFS_ORDERED_PENDING` is set, hold `fs_info->trans_lock` only to read `running_transaction` and `refcount_inc(&trans->use_count)`, dropping it before asserting, decrementing `trans->pending_ordered`, waking `trans->pending_wait`, and calling `btrfs_put_transaction()`. [F691, F695, F696]
- In `btrfs_mark_ordered_io_finished()`, when `can_finish_ordered_extent()` returns `true`, drop `inode->ordered_tree_lock` around `btrfs_queue_ordered_fn(entry)` and re-acquire before continuing via `cur += len` and `ordered_tree_search(inode, cur)` (never `rb_next(node)`). In `btrfs_finish_ordered_extent()`, a `!uptodate` non-NOCOW extent sets `BTRFS_INODE_COW_WRITE_ERROR` on `inode->runtime_flags` before queuing work. [F729, F776, F807]
- For `btrfs_is_free_space_inode(inode)`, queue ordered completion onto `fs_info->endio_freespace_worker` (not `endio_write_workers`) and skip `btrfs_ordered_extent` lockdep acquire/release in `btrfs_start_ordered_extent_nowriteback()` and `btrfs_remove_ordered_extent()`. Use `cond_wake_up_nomb()` only after a full barrier (`test_and_set_bit` in `btrfs_dec_test_ordered_pending()`); plain `set_bit(BTRFS_ORDERED_IO_DONE, ...)` in `can_finish_ordered_extent()` requires `cond_wake_up()`. [F808, F809]
- In `btrfs_wait_ordered_extents()` and `btrfs_wait_ordered_roots()`, move each selected entry from `splice` back to the root/global list before dropping the spinlock, splice `skipped` and remaining `splice` entries back on exit, and never decrement `nr` when `nr == U64_MAX`. In `btrfs_lock_and_flush_ordered_range()`, unlock `[start, end]` via `btrfs_unlock_extent()` before `btrfs_start_ordered_extent(ordered)` and loop to relock/recheck; if `cached_state == NULL`, drop the extra ref via `refcount_dec(&cache->refs)`. [F666, F699, F771, F791]
- In `create_subvol()`, call `btrfs_record_new_subvolume(trans, BTRFS_I(dir))` before `btrfs_create_new_inode()`. In `btrfs_mksnapshot()`, hold `btrfs_drew_read_lock(&root->snapshot_lock)` across `btrfs_start_delalloc_snapshot()`, incrementing `root->snapshot_force_cow`, `btrfs_wait_ordered_extents()`, and `btrfs_mksubvol()`. `BTRFS_QUOTA_CTL_DISABLE` takes `fs_info->cleaner_mutex` before `down_write(&fs_info->subvol_sem)`. Clearing `BTRFS_ROOT_SUBVOL_RDONLY` and checking `root->send_in_progress == 0` in `btrfs_ioctl_subvol_setflags()` requires `down_write(&fs_info->subvol_sem)` and `root->root_item_lock`. [F679, F680, F682, F683]
- `btrfs_drew_try_write_lock()` and `btrfs_drew_read_lock()` require `smp_mb__after_atomic()` between incrementing `writers`/`readers` and reading the opposite counter. `btrfs_lock_root_node()`, `btrfs_read_lock_root_node()`, and `btrfs_try_read_lock_root_node()` must verify `eb == root->node` under `eb->lock`, unlocking and freeing `eb` to retry if changed. [F688, F689]
- `copy_to_sk()` under a leaf lock must use `copy_to_user_nofault()` and `read_extent_buffer_to_user_nofault()` (rewinding `*sk_offset` by `sizeof(sh)` on payload fault) and `fault_in_subpage_writeable()` in `search_ioctl()` with the path released. `btrfs_search_path_in_tree_user()` must call `btrfs_release_path(path)` before `btrfs_iget()` and `inode_permission(..., MAY_READ | MAY_EXEC)`, returning `-EACCES` if `BTRFS_FIRST_FREE_OBJECTID` is reached before `upper_limit`. [F825, F826]
- When `btrfs_encoded_read()` returns `-EIOCBQUEUED` in `btrfs_uring_encoded_read()`, keep the shared inode lock and extent lock held (unlocking both if an error prevents queuing) and pair `btrfs_lockdep_inode_release()` in `btrfs_uring_read_extent()` with `btrfs_lockdep_inode_acquire()` in `btrfs_uring_read_finished()`. `struct btrfs_lru_cache` requires external locking if shared. Iterating `fs_devices->devices` or calling `btrfs_dev_name(dev)` in `btrfs_ioctl_fitrim()`, `btrfs_ioctl_fs_info()`, and `btrfs_ioctl_dev_info()` (without device mutexes) and `_btrfs_printk()` require `rcu_read_lock()`, with `copy_to_user()` outside RCU. [F700, F817, F829, F833]

## Object Lifetimes
- In `alloc_ordered_extent()`, if an error occurs after `btrfs_qgroup_release_data()`, free `qgroup_rsv` via `btrfs_qgroup_free_refroot(..., BTRFS_QGROUP_RSV_DATA)`. `btrfs_remove_ordered_extent()` does not drop a ref on `entry->refs`, and `btrfs_put_ordered_extent()` asserts `RB_EMPTY_NODE(&entry->rb_node)`, `root_extent_list`, and `log_list` are empty on final put. [F664, F665]
- In `create_subvol()` and `create_snapshot()`, if `btrfs_insert_root()` fails in `create_subvol()` after `btrfs_alloc_tree_block()`, clear dirty on `leaf` and call `btrfs_free_tree_block(trans, objectid, leaf, 0, 1)` before `free_extent_buffer(leaf)`. Zero `qgroup_reserved` once `btrfs_qgroup_convert_reserved_meta()` transfers it to `trans`, and clear `anon_dev` (including `pending_snapshot->snap->anon_dev = 0` on error) once assigned to a root. [F670, F717]
- In `btrfs_ioctl_balance()`, `btrfs_try_lock_balance()` sets `need_unlock` only when newly claiming `BTRFS_EXCLOP_BALANCE`, and `btrfs_balance()` consumes `bctl` and the exclop (`need_unlock = false; bctl = NULL;`). `btrfs_add_qgroup_relation()` always consumes `prealloc` (`prealloc = NULL`). In `lzo_compress_folios()`, put and zero cached `folio_in` in the loop only when `IS_ALIGNED(cur_in, min_folio_size)`, and at `out:` if non-NULL. [F675, F676, F768]

## API Contracts
- `struct btrfs_lru_cache_entry` must be at offset 0 of a `kmalloc()` struct, and `btrfs_lru_cache_store()` takes ownership of `new_entry` only when returning `0`. `exclop_start_or_cancel_reloc()` returns `0` when claimed, positive `BTRFS_ERROR_DEV_EXCL_RUN_IN_PROGRESS` when busy, or negative errors in cancel mode, so check `if (ret)` (not `ret < 0`). `btrfs_update_ioctl_balance_args()` ORs into `bargs->state` (`|=`), requiring a zeroed `*bargs`. [F668, F718, F722]
- `btrfs_try_read_lock_root_node()`, `btrfs_alloc_ordered_extent()`, and `btrfs_split_ordered_extent()` return `ERR_PTR()` on failure, whereas `btrfs_lookup_ordered_extent()`, `btrfs_lookup_ordered_range()`, `btrfs_lookup_first_ordered_extent()`, and `btrfs_lookup_first_ordered_range()` return `NULL`. `btrfs_tree_unlock_rw()` calls `BUG()` if `@rw` is not `BTRFS_WRITE_LOCK` or `BTRFS_READ_LOCK`. Call `btrfs_unlock_up_safe(path, level)` only when no further updates will propagate to `@level` or above. [F690, F701, F702, F709]
- `btrfs_alloc_ordered_extent()` requires shifted `BTRFS_ORDERED_TYPE_FLAGS` bits and normalizes NOCOW/PREALLOC `@offset` to 0 while adding `file_extent->offset` to `disk_bytenr`. `btrfs_finish_ordered_extent()`, `btrfs_mark_ordered_io_finished()`, and `can_finish_ordered_extent()` accept `folio == NULL`. `btrfs_dec_test_ordered_pending()` requires `[file_offset, file_offset + io_size)` within one ordered extent and stores an extra-ref pointer in `*cached` only when returning `true` with `cached != NULL`. `btrfs_lock_and_flush_ordered_range()` and `btrfs_try_lock_ordered_range()` take inclusive `[start, end]`, whereas `btrfs_wait_ordered_range()`, `btrfs_lookup_ordered_range()`, and `btrfs_lookup_first_ordered_range()` take `(start, len)`. [F710, F712, F713, F715]
- In `lzo_compress_folios()`, `*out_folios` and `*total_out` are in/out, and on exit `*out_folios` is set to `DIV_ROUND_UP(cur_out, min_folio_size)`. `btrfs_ignore_prop()` requires prior validation (`handler != NULL`), and `prop_handler::validate`/`apply` must bound un-terminated `value` by `len`. [F704, F707, F792, F800]

## Error Handling
- When `lzo_decompress()` produces `out_len < destlen`, zero `[dest_pgoff + out_len, dest_pgoff + destlen)` in `dest_folio` before returning `-EIO`; for inline extents require `srclen` in `[LZO_LEN, workspace_buf_length(fs_info) + LZO_LEN * 2]`, outer header `== srclen`, and segment header `== srclen - LZO_LEN * 2`. `lzo_decompress_bio()` returns `-EUCLEAN` if `len_in > min(BTRFS_MAX_COMPRESSED, cb->compressed_len)` or `round_up(len_in, sectorsize) < cb->compressed_len`, and `-EIO` if `seg_len > workspace_cbuf_length(fs_info)`. [F705, F743, F830]
- In `fs/btrfs/ioctl.c`, reset any `ERR_PTR()` in `root`, `ipa`/`ipath`, or `bargs` to `NULL` before jumping to cleanup (`btrfs_put_root()`, `free_ipath()`, `kfree()`). In `btrfs_ioctl_subvol_setflags()`, restore `root_flags` on `root->root_item` before unlocking `subvol_sem` if transaction start, `btrfs_update_root()`, or commit fails. `btrfs_split_ordered_extent()` must check `BTRFS_ORDERED_IOERR` before asserting `!(flags & ~BTRFS_ORDERED_TYPE_FLAGS)`. `btrfs_wait_ordered_range()` must wait for all overlapping ordered extents before returning `ret_wb ? ret_wb : ret` even on `filemap_fdatawait_range()` error or `BTRFS_ORDERED_IOERR`. [F719, F725, F733, F772]
- Ioctl checks: `btrfs_ioctl_snap_create_v2()` (`BTRFS_SUBVOL_QGROUP_INHERIT`) bounds `vol_args->size` to `[sizeof(*inherit), PAGE_SIZE]` and calls `btrfs_qgroup_check_inherit()`; `btrfs_ioctl_logical_to_ino()` v2 rejects non-zero `loi->reserved[]` and unknown `loi->flags`, clamping `loi->size` to `SZ_64K` (v1) / `SZ_16M` (v2); encoded writes check `flags == 0`, zero `reserved[]`, valid `compression`/`encryption` (not both `NONE`), `unencoded_offset <= unencoded_len`, and `len <= unencoded_len - unencoded_offset`; `btrfs_ioctl_subvol_sync()` rejects `args.subvolid > U32_MAX` (`-EOVERFLOW`) on 32-bit; `btrfs_ioctl_resize()` checks `new_size > old_size` (`-EINVAL`, `mod < 0`) and `new_size > ULLONG_MAX - old_size` (`-ERANGE`, `mod > 0`). [F754, F758, F761, F762, F785]

## External Contracts
- `btrfs_ioctl_scrub()` copies `sa` to user even on `btrfs_scrub_dev()` error. In `copy_to_sk()`, when the first item exceeds `*buf_size`, set `*buf_size = sizeof(sh) + item_len`, write `sh.len = 0`, and return `-EOVERFLOW` (cleared to `0` in v1 `btrfs_ioctl_tree_search()`, returned after copying `*buf_size` in v2). `btrfs_ioctl_fs_info()` zeroes `fi_args` and populates/flags only requested optional fields. `btrfs_ioctl_ino_to_path()` subtracts `(u64)(unsigned long)ipath->fspath->val` from each `ipath->fspath->val[i]` before copying to user. [F721, F755, F757, F798]
- Validate NUL-termination in `btrfs_ioctl_vol_args` / `v2` via `btrfs_check_ioctl_vol_args_path()` or `btrfs_check_ioctl_vol_args2_subvol_name()` (`-ENAMETOOLONG`). In `__btrfs_ioctl_snap_create()` (`!subvol`), require same sb (`-EXDEV`), `inode_owner_or_capable()` (`-EPERM`), and `btrfs_ino(BTRFS_I(src_inode)) == BTRFS_FIRST_FREE_OBJECTID` (`-EINVAL`). In `btrfs_ioctl_snap_destroy()`, return `-EOPNOTSUPP` for `BTRFS_SUBVOL_SPEC_BY_ID` on an idmapped mount if `old_dir != dir`, and when `!capable(CAP_SYS_ADMIN)` require `USER_SUBVOL_RM_ALLOWED` (`-EPERM`), `root != dest` (`-EINVAL`), and `inode_permission(idmap, inode, MAY_WRITE | MAY_EXEC)` on the target root inode. [F821, F822, F823, F824]

## Known Pitfalls
- `btrfs_ioctl_fitrim()` requires `range.len >= fs_info->sectorsize` and must not clamp or reject `range.start` or `range.len` against `super->total_bytes`. In `btrfs_search_path_in_tree()` and `btrfs_search_path_in_tree_user()`, check `ptr < name` / `ptr < args->path` (`-ENAMETOOLONG`) after `ptr -= len + 1` before writing `'/'` or `read_extent_buffer()`, and use `memmove()` to shift the path to the buffer start. [F753, F756, F797]
- In `iterate_object_props()`, `btrfs_next_leaf()` must `continue` immediately to reload `slot` and `leaf`. In `btrfs_lookup_ordered_range()` and `btrfs_lookup_first_ordered_range()`, reset `entry = NULL` before `out:` if no extent overlaps. In `copy_compressed_data_to_page()`, `kunmap_local(kaddr)` before `btrfs_alloc_compr_folio()` or returning an error. Carry across `key->offset`, `key->type`, and `key->objectid` in `copy_to_sk()` (returning 1 at max key). In `btrfs_wait_ordered_range()`, check `start + len < start` (clamping `orig_end` to `OFFSET_MAX`) and stop before `end--` when `end == 0 || end == start`. [F769, F774, F789, F790, F818]
