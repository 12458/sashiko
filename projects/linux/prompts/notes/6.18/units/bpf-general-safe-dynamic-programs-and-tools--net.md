# BPF [GENERAL] (Safe Dynamic Programs and Tools) — net

This component implements the networking BPF subsystem (`net/core/filter.c`), cBPF-to-eBPF conversion, networking helpers/kfuncs, XDP redirect/flush, `BPF_PROG_TEST_RUN` (`net/bpf/test_run.c`), and `bpf_dummy_struct_ops` (`net/bpf/bpf_dummy_struct_ops.c`).

## Architecture & Data Flow

- Every `sk_buff` helper for TC, LWT, or `CGROUP_SKB` that reallocates, linearizes, or shifts `skb->data` or `skb->len` (`bpf_try_make_writable()`, `bpf_skb_adjust_room()`, `bpf_skb_change_tail()`, `bpf_skb_change_head()`) must call `bpf_compute_data_pointers(skb)`. When `sk_skb_adjust_room()` adjusts `skb->data` and `tls_sw_has_ctx_rx(skb->sk)` holds, it must update `strp_msg(skb)->full_len += len_diff`. [F257, F271]
- In `bpf_skb_net_grow()`, when `encap` is true, `skb->network_header`, `mac_header`, and `transport_header` must be sampled before `bpf_skb_net_hdr_push()`. On GSO packets, `bpf_skb_net_grow()` and `bpf_skb_net_shrink()` must set `SKB_GSO_DODGY`, reset `gso_segs = 0`, and adjust `gso_size` unless `BPF_F_ADJ_ROOM_FIXED_GSO` is set (linearizing `frag_list` on grow). L3 IPv4/IPv6 protocol changes (`bpf_skb_proto_4_to_6()`, `bpf_skb_proto_6_to_4()`, `bpf_skb_net_grow()`, `bpf_skb_net_shrink()`) must call `bpf_skb_change_protocol()` to drop cached `skb_dst(skb)`. [F264, F265, F266]
- `bpf_lwt_seg6_store_bytes()` and `bpf_lwt_seg6_adjust_srh()` must set `srh_state->valid = false` when modifying SRH TLVs (and `adjust_srh` updates `srh_state->hdrlen += len` and `ipv6hdr->payload_len`). In `bpf_l4_csum_replace()`, diff updates (`!(flags & BPF_F_HDR_FIELD_MASK)`) must pass `BPF_F_IPV6` as `is_ipv6` to `inet_proto_csum_replace_by_diff()`. `bpf_dynptr_from_skb_meta()` must call `bpf_dynptr_set_rdonly(ptr)` when `skb_cloned(skb)`. [F263, F364, F370]
- `sk_msg_sg` indices wrap modulo `NR_MSG_FRAG_IDS` (`MAX_MSG_FRAGS + 1`) via `sk_msg_iter_var_next()`/`prev()`, and `bpf_msg_pull_data()` must wrap `i + shift` and `msg->sg.end - shift` by `NR_MSG_FRAG_IDS`. `bpf_msg_pull_data()`, `bpf_msg_push_data()`, and `bpf_msg_pop_data()` must call `sk_msg_reset_curr(msg)` (setting `curr` to the element before `end` and `copybreak` to its `length` when `msg->sg.size > 0`) and recompute `msg->data`/`data_end`. In `bpf_msg_push_data()`, `start == offset + l` is valid; if the loop ends at `i == msg->sg.end`, step `i` back via `sk_msg_iter_var_prev(i)`. [F258, F259, F280, F282]
- `bpf_xdp_adjust_head()` and `bpf_xdp_adjust_meta()` must keep `xdp->data_meta >= xdp->data_hard_start + sizeof(struct xdp_frame)`, `xdp->data` in `[xdp_frame_end + metalen, xdp->data_end - ETH_HLEN]`, and `!xdp_metalen_invalid(metalen)`. `bpf_xdp_frags_shrink_tail()` must bound `offset` by `(int)xdp_get_buff_len(xdp) - ETH_HLEN`, iterate from `sinfo->nr_frags - 1` down to `0` with signed `int i`, and subtract residual `offset` from `xdp->data_end` if `!sinfo->nr_frags`. With `MEM_TYPE_XSK_BUFF_POOL`, `bpf_xdp_frags_increase_tail()` and `bpf_xdp_shrink_data()` must update the AF_XDP node (`xsk_buff_get_tail()`/`get_head()`). [F268, F289, F291]
- Downcasting `struct sock *` to full-socket types (`tcp_sock`, `tcp6_sock`, `udp6_sock`, `unix_sock`) or calling `__bpf_setsockopt`/`__bpf_getsockopt` requires `sk_fullsock(sk)`. `bpf_skc_to_tcp_timewait_sock()` and `bpf_skc_to_tcp_request_sock()` require `sk->sk_prot` to be `&tcp_prot`/`&tcpv6_prot` and `sk_state` to be `TCP_TIME_WAIT`/`TCP_NEW_SYN_RECV`. In `bpf_sock_ops_get_syn()`, when `!bpf_sock->syn_skb`, `sk->sk_state == TCP_NEW_SYN_RECV` selects `inet_reqsk(sk)->saved_syn` vs `tcp_sk(sk)->saved_syn`. [F241, F242, F332]
- `bpf_search_tcp_opt()` stops on `TCPOPT_EOL`, advances 1 on `TCPOPT_NOP`, and rejects `opend - op < 2 || opend - op < op[1] || op[1] < 2`. `bpf_sock_addr_set_sun_path()` rejects `sun_path__sz == 0 || sun_path__sz > UNIX_PATH_MAX` with `-EINVAL`. [F299, F311]
- In `bpf_skb_is_valid_access()` and `sock_ops_is_valid_access()`, 64-bit fields must use `bpf_ctx_range*()` macros rather than `offsetof()`, and implicit padding in `__sk_buff` and `bpf_sock` must return `false`; in `sock_addr`, `sk_msg`, `flow_dissector`, `sk_reuseport`, and `sk_lookup` validators, `default` in `switch (off)` must return `false`. 32-bit packet pointers (`data`, `data_end`, `data_meta`) in `skb`, `xdp`, and `flow_dissector` must reject `info->is_ldsx`. Temp registers in `sock_addr_convert_ctx_access()`, `sock_ops_convert_ctx_access()`, and `bpf_convert_data_end_access()` must differ from `src_reg`/`dst_reg` and be spilled/restored on all branches. [F272, F301, F302, F303, F315]
- `bpf_check_classic()` validates opcodes, `k != 0` for `BPF_DIV`/`BPF_MOD`, `k < 32` for shifts, `k < BPF_MEMWORDS` (`<= 16`) for `BPF_MEM`, jump targets `< flen`, and trailing `BPF_RET` before `check_load_and_stores()`, which resets `memvalid = ~0` after propagating jump masks (`stack_depth` is updated only on `BPF_ST`/`STX`). `bpf_convert_filter()` saves `R1` to `R6` (and `skb->data`/headlen to `R8`/`R9` if `*seen_ld_abs`), zero-extends `BPF_REG_X` and guards `X == 0` on `BPF_DIV`/`MOD | BPF_X`, checks `S16_MIN..S16_MAX` offsets, and scales `insn - tmp_insns` by `sizeof(*insn)` in `memcpy()` (`*new_len == new_flen` in `<= 2` passes). `bpf_skb_load_helper_16()`/`_32()` convert negative offsets, use `get_unaligned_be*()`, and `be*_to_cpu()`. [F285, F286, F288, F307, F308, F317, F318, F319, F320, F324, F357]
- For `BPF_F_TEST_XDP_LIVE_FRAMES` (`test_run.c`), `struct xdp_page_head` sits at page start, so headroom adds `sizeof(struct xdp_page_head)` and `xdp_test_run_init_page()` bounds frame size to `PAGE_SIZE - sizeof(struct xdp_page_head)`. `bpf_test_run_xdp_live()` resets `xdp.frame_cnt = 0` per batch for `bpf_test_timer_continue()`. In `xdp_test_run_batch()`, `ctx_was_changed(head)` requires `xdp_update_frame_from_buff(ctx, frm)` before redirect/`XDP_PASS`, and `reset_ctx()` restores `head->frame->mem_type = head->orig_ctx.rxq->mem.type`. `bpf_test_finish()` checks `int len = copy_size - sinfo->xdp_frags_size < 0` (`-ENOSPC`) when `sinfo` is non-NULL. [F260, F261, F292, F309, F325]

## Synchronization

- `__sk_attach_prog()`, `sk_detach_filter()`, and `sk_get_filter()` require `lockdep_sock_is_held(sk)`, while `sk_filter_trim_cap()` uses `rcu_read_lock()`. `__sk_attach_prog()` must set `fp->prog`, call `__sk_filter_charge()`, and `refcount_set(&fp->refcnt, 1)` before `rcu_assign_pointer(sk->sk_filter, fp)`, and `sk_filter_release()` must defer `__sk_filter_release()` via `call_rcu()`. [F219, F221, F347]
- `tc_cls_act_btf_struct_access()` and `xdp_btf_struct_access()` must hold `nf_conn_btf_access_lock` around `nfct_btf_struct_access`. `bpf_lwt_seg6_store_bytes()`, `bpf_lwt_seg6_action()`, and `bpf_lwt_seg6_adjust_srh()` require per-CPU `srh_state->bh_lock`. [F225, F351]
- `bpf_sock_ops_setsockopt`, `getsockopt`, `cb_flags_set`, and `load_hdr_opt` must return `-EOPNOTSUPP` when `!is_locked_tcp_sock_ops(bpf_sock)`. `sol_tcp_sockopt_congestion()` must return `-EBUSY` if `tp->bpf_chg_cc_inprogress` is set, setting/resetting it around `do_tcp_setsockopt()`. [F214, F227]
- `bpf_out_neigh_v6()` and `bpf_out_neigh_v4()` must pair `rcu_read_lock()` with `rcu_read_unlock()` on all exits and wrap `neigh_output()` in `local_bh_disable()`/`enable()` with `dev_xmit_recursion_inc()`/`dec()`. [F342]
- `bpf_test_run()` and `xdp_test_run_batch()` must wrap execution in `local_bh_disable()` and `bpf_net_ctx_set()`/`clear()` before `bpf_test_timer_continue()`, which calls `bpf_test_timer_leave()`/`enter()` around `cond_resched()`. `bpf_prog_test_run_raw_tp()` holds `get_cpu()` across `cpu_online()` and `smp_call_function_single()`/`__bpf_prog_test_run_raw_tp()`, while `bpf_prog_test_run_syscall()` uses `rcu_read_lock_trace()`/`unlock_trace()`. [F343, F344, F354]

## Object Lifetimes

- `bpf_prepare_filter()` and `bpf_migrate_filter()` call `__bpf_prog_release(fp)` on error (callers must not free `IS_ERR(fp)`), and `bpf_migrate_filter()` must reset `fp = old_fp` before `out_err_free` if `bpf_prog_realloc()` returns NULL. `__bpf_prog_release()` and `sk_reuseport_prog_free()` free eBPF (`SOCKET_FILTER`, `SK_REUSEPORT`) via `bpf_prog_put()` and cBPF (`UNSPEC`) via `bpf_release_orig_filter()` and `bpf_prog_free()`/`destroy()`. [F205, F206, F208]
- `__sk_attach_prog(prog, sk)` takes ownership of `prog` only on success (charging optmem via `__sk_filter_charge()` and uncharging `old_fp`, whereas `sk_reuseport_attach_bpf()` skips `sysctl_optmem_max`); callers release `prog` on error. `sk_filter_charge()` uses `refcount_inc_not_zero(&fp->refcnt)` and calls `sk_filter_release(fp)` if `__sk_filter_charge()` fails. `sk_filter_trim_cap()` must restore `skb->sk = save_sk` after `bpf_prog_run_save_cb()`. [F203, F207, F222, F376]
- Call `skb_dst_drop(skb)` before `skb_dst_set()` (`__bpf_redirect_neigh_v4`/`v6`, `bpf_skb_set_tunnel_key`). In `bpf_clone_redirect()`, call `bpf_try_make_head_writable(skb)` after `skb_clone()` and `kfree_skb(clone)` if it fails. [F209, F210]
- In `sk_lookup()`, `__bpf_sk_lookup()`, and `bpf_sk_lookup()`, if `sk_to_full_sk(sk)` returns `sk2 != sk`, call `sock_gen_put(sk)`, and verify `SOCK_RCU_FREE` on any unreferenced socket (`!refcounted` or `sk2 != sk`). `bpf_sk_assign()` pins refcounted sockets via `refcount_inc_not_zero(&sk->sk_refcnt)` (`-ENOENT` on failure) after `!sk_unhashed(sk)` before `skb_orphan(skb)`. `bpf_sk_lookup_assign()` rejects `sk_is_refcounted(sk)` (`-ESOCKTNOSUPPORT`), and `sk_select_reuseport()` error paths after `map_lookup_elem()` must `sock_put(selected_sk)` if `sk_is_refcounted(selected_sk)`. [F215, F217, F218, F230, F231]
- In `bpf_msg_push_data()`/`pop_data()`, splitting an `sg` entry requires `get_page()`, removing/replacing requires `put_page()`, and `msg->sg.size` and `sk_mem_charge()`/`uncharge()` must match the byte delta. Shrinking XDP frags (`bpf_xdp_frags_shrink_tail()`, `bpf_xdp_pull_data()`) must free consumed frags via `bpf_xdp_shrink_data()`, decrement `nr_frags`, and clear frags/pfmemalloc flags when `nr_frags == 0`. [F211, F212]
- `bpf_struct_ops_test_run()` must `bpf_prog_inc(prog)` before `bpf_link_init()`, and `bpf_set_run_ctx()` callers must `bpf_reset_run_ctx()`. In `test_run.c`, `bpf_prog_test_run_skb()` guards `dev_put(dev)` with `dev && dev != net->loopback_dev`; `bpf_prog_test_run_nf()` sets `data = NULL` after `slab_build_skb(data)`; `bpf_prog_test_run_xdp()` calls `xdp_convert_buff_to_md()` on all exits after `xdp_convert_md_to_buff()` to `dev_put(xdp->rxq->dev)`. `xdp_test_run_batch()` calls `xdp_return_buff(ctx)` on failed update/redirect or `XDP_DROP`/invalid action and `xdp_do_flush()` before `bpf_net_ctx_clear()`; `xdp_recv_frames()` calls `xdp_return_frame()` on unbuilt frames. [F196, F197, F198, F199, F201, F202, F340]

## API Contracts

- Networking `is_valid_access` callbacks must reject `off % size != 0`, and `cg_skb_is_valid_access()`/`bpf_sk_base_func_proto()` must use `bpf_token_capable(prog->aux->token, ...)`. Read-modify-write helper args (`mtu_len` in `bpf_skb`/`xdp_check_mtu_proto`, `search_res` in `bpf_sock_ops_load_hdr_opt_proto`) must use `MEM_WRITE` without `MEM_UNINIT`. [F250, F278, F375]
- `bpf_xdp_pointer()` returns `ERR_PTR(-EFAULT)` if `offset > 0xffff || len > 0xffff`, `ERR_PTR(-EINVAL)` if `offset + len > xdp_get_buff_len(xdp)`, and `NULL` across frag boundaries (for `bpf_xdp_copy_buf()`). Syncookie helpers require `th_len >= sizeof(*th)` and `th_len == th->doff * 4`, returning `cookie | ((u64)mss << 32)`. `__bpf_skc_lookup()` checks `len` against `sizeof(tuple->ipv4)`/`ipv6` and uses `(s32)netns_id < 0` for `caller_net` while requiring `netns_id <= S32_MAX`. [F255, F256, F290]
- `ri->map_id = INT_MAX` with `BPF_MAP_TYPE_UNSPEC` marks `ifindex` XDP redirects (`bpf_xdp_redirect`, `xdp_master_redirect` when `slave != xdp->rxq->dev`, `xdp_test_run_batch`). `__xdp_do_redirect_frame()` and `xdp_do_generic_redirect()` reset `ri->map_id`, `flags`, and `map_type` on entry and `WRITE_ONCE(ri->map, NULL)` on broadcast `DEVMAP`/`DEVMAP_HASH`. Drivers must call `xdp_do_flush()` before `napi_complete_done()` and before exiting BH-disabled NAPI poll. `bpf_redirect()`/`clone_redirect()` reject `flags & (~(BPF_F_INGRESS) | BPF_F_REDIRECT_INTERNAL)`, and `BPF_F_PEER` in `skb_do_redirect()` requires `skb_at_tc_ingress(skb)`, `ndo_get_peer_dev`, `IFF_UP`, and `!net_eq(net, dev_net(dev))`. [F213, F300, F305, F336, F337, F338]
- `bpf_sock_destroy()` requires `sk->sk_prot->diag_destroy`, `IPPROTO_TCP`/`UDP`, and `BPF_TRACE_ITER` (`tracing_iter_filter`). `lwt_seg6local_prog_ops` must not set `.test_run = bpf_prog_test_run_skb`. [F367, F381]
- `bpf_ctx_init()` callers must check both `IS_ERR(ctx)` and `ctx != NULL`. `bpf_test_timer_continue()` uses `do_div(t->time_spent, t->i)`, clamps to `U32_MAX`, and requires `repeat >= 1`. BTF destructor kfuncs in `test_run.c` take `void *` with `CFI_NOSEAL()`. In `bpf_dummy_struct_ops.c`, `bpf_dummy_ops_check_member()` rejects `prog->sleepable` except on `test_sleepable`; `args->args[0] == 0` passes `NULL` state (`check_test_run_args()` rejects `0` for non-nullable BTF pointers); and `bpf_struct_ops_test_run()` calls `arch_protect_bpf_trampoline()` and adds `cfi_get_offset()`. [F243, F244, F321, F330, F355, F356]

## Error Handling

- In `bpf_test_run()`, clear `ERR_PTR` slots to `NULL` before `bpf_cgroup_storage_free()`. `bpf_test_finish()` and `bpf_ctx_finish()` still copy clamped data and unclamped `size` on `-ENOSPC`. In `xdp_test_run_batch()`, `out:` must run `xdp_do_flush()` and `xdp_recv_frames()` even after `-ENOMEM`, only overwriting `err` if `xdp_recv_frames()` fails. [F200, F239, F247]
- `bpf_dynptr_from_skb()`, `skb_meta()`, and `xdp()` must call `bpf_dynptr_set_null()` on `-EINVAL`. `__bpf_skb_min_len()` must check signed `int` offsets `> 0` before assigning to `u32 min_len`. `bpf_sock_ops_store_hdr_opt()` maps `bpf_search_tcp_opt()` valid pointer to `-EEXIST`, `-ENOMSG` with `eol` to `-ENOSPC`, and propagates `-EFAULT`. `bpf_skb_get_tunnel_key()` and `bpf_skb_get_xfrm_state()` must zero `&remote_ipv6[1]` and `&local_ipv6[1]` (`sizeof(__u32) * 3`) for IPv4. `__bpf_tx_skb()` and `bpf_out_neigh_v4()`/`_v6()` check `dev_xmit_recursion()`, log with `net_crit_ratelimited`, and return `-ENETDOWN`; invalid XDP actions use `bpf_warn_invalid_xdp_action()`. [F236, F240, F249, F251, F377]

## External Contracts

- `copy_bpf_fprog_from_user()` handles `in_compat_syscall()` (`compat_sock_fprog`, `memset` zeroing `dst`, `compat_ptr`). `sk_get_filter()` returns `0` if unattached, `-EACCES` if `!orig_prog`, `-EINVAL` if `len && len < fprog->len`, and `fprog->len` (block count). `bpf_skb_get`/`set_tunnel_key()` support legacy prefix sizes via a stack `compat` buffer. [F238, F294, F371]
- `__sk_buff`, `bpf_sock_ops`, and `sk_msg_md` shift `remote_port` left 16 bits on little-endian, while `sk_lookup` allows 1/2/4-byte reads at `remote_port` and 2-byte zero-padding reads after it. `bpf_ctx_init()` checks `bpf_check_uarg_tail_zero()`, and `convert___skb_to_skb()`, `verify_user_bpf_flow_keys()`, and `bpf_prog_test_run_sk_lookup()` check `range_is_zero()`. [F293, F295, F296]

## Known Pitfalls

- `tc_cls_act_is_valid_access()` must intercept `tstamp_type`, set `prog->tstamp_type_access = 1`, and return `size == sizeof(__u8)` before `bpf_skb_is_valid_access()`. `bpf_msg_pop_data()` must not advance `i` after `sk_msg_shift_left(msg, i)` when `pop >= sge->length`. `bpf_xdp_copy_buf()` must check `if (!len || next_frag == end_frag) break;` before dereferencing `next_frag`. [F304, F306, F310]
- In `bpf_convert_filter()`, `BPF_JMP | BPF_K` with `(int)fp->k < 0` must zero-extend `fp->k` into `BPF_REG_TMP` (`BPF_MOV32_IMM`) and compare with `BPF_X`. `__bpf_skb_change_head()` must check `new_len < skb->len` unconditionally (even for GSO). Packet-writing helpers must refresh `skb->data` pointers (and `srh_state->srh`) after `bpf_try_make_writable()`, `skb_cow_head()`, or header push/pop, and `bpf_skb_generic_push()`/`pop()` must use `memmove()`. `sol_tcp_sockopt_congestion()` requires `*optlen >= 2`, NUL-terminates `getsockopt`, and uses `strncmp(..., optval, *optlen)` on `setsockopt`. [F316, F322, F326, F328, F334]
