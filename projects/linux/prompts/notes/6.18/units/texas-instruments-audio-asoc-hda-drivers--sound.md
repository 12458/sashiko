# TEXAS INSTRUMENTS AUDIO (ASoC/HDA) DRIVERS — sound

This unit contains Texas Instruments audio codec and smart amplifier drivers across the HDA side-codec and ASoC frameworks (`pcm1681`, `pcm1789`, `pcm179x`, `pcm186x`, `pcm3008`, `pcm3060`, `pcm3168a`, `pcm5102a`, `pcm512x`, `tas2552`, `tas2562`, `tas2764`, `tas2770`, `tas2780`, `tas2781_hda_i2c`, and `tas2781-comlib`).

## Architecture & Data Flow
- `tasdevice_regmap` (`tas2781-comlib-i2c.c`) must keep `.cache_type = REGCACHE_NONE` because one `regmap` is shared across multiple `tasdev->dev_addr` I2C addresses with two-level `BOOK`/`PAGE` addressing where `TASDEVICE_BOOKCTL_REG` is outside `tasdevice_ranges`. In `tasdevice_change_chn_book()` and `tasdev_chn_switch()`, changing `client->addr` to `tasdev->dev_addr` must immediately write `0` to `TASDEVICE_PAGE_SELECT`, and `tasdev->cur_book` must only update after `regmap_write(map, TASDEVICE_BOOKCTL_REG, book)` succeeds. [F51, F52]
- `tasdevice_init()` and `tas2781_system_resume()` must reset each channel's `cur_book`, `cur_prog`, and `cur_conf` in `tas_priv->tasdevice[i]` to `-1` before hardware reset or DSP loading so cached state does not skip writes. Both `tasdevice_dspfw_init()` and `tas2781_system_resume()` must check `tas_priv->rcabin.init_profile_id >= 0` after `tasdevice_prmg_load()` and apply `TASDEVICE_BIN_BLK_PRE_POWER_UP` via `tasdevice_select_cfg_blk()`. [F39, F53, F55]
- In `tas2781_hda_i2c.c`, `dev_set_drvdata(&clt->dev, tas_hda)` stores `struct tas2781_hda *` on `clt->dev` (`tas_priv->dev`), whereas `tasdev_add_kcontrols()` (`snd_kcontrol_chip()`) and `tascodec_init()` pass `struct tasdevice_priv *` (`tas_hda->priv`), and `tas_hda->hda_priv` is `struct tas2781_hda_i2c_priv *`. `tasdevice_kzalloc()` stores `struct i2c_client *` in `tas_priv->client`; `tascodec_init()` stores `struct hda_codec *` in `tas_priv->codec`. [F109, F111, F112]
- In `tas2764`, `tas2770`, and `tas2562`, `PWR_CTRL` mode bits encode both `dac_powered` and `unmuted` via `tas2764_update_pwr_ctrl()`, `tas2770_update_pwr_ctrl()`, or `tas2562_update_pwr_ctrl()`. `tas2764_mute()` must step through `TAS2764_PWR_CTRL_MUTE` on both transitions (sleeping 6-7 ms on mute before `dac_powered = false`). In `tas2770`, `sense_event()` must set `TAS2770_PWR_CTRL_SHUTDOWN` on `SND_SOC_DAPM_PRE_REG` and call `tas2770_update_pwr_ctrl()` on `SND_SOC_DAPM_POST_REG`. `tas2764_codec_suspend()`/`tas2770_codec_suspend()` must not clear `dac_powered`/`unmuted` so `*_codec_resume()` restores `PWR_CTRL` before `regcache_sync()`. [F60, F61, F62, F100]
- In `tas2764` and `tas2770`, deasserting `sdz_gpio`/`reset_gpio` or writing `TAS2764_RST`/`TAS2770_RST` in `tas2764_reset()`/`tas2770_reset()` requires a >=1 ms delay (`usleep_range(1000, 2000)`) before register access, and software reset in `tas2764_codec_probe()`/`tas2770_codec_probe()` must be immediately followed by `regmap_reinit_cache()`. [F59, F122]
- In `tas2764_set_bitwidth()`, `tas2780_set_bitwidth()`, and `tas2562_set_bitwidth()`, TDM sense bits in `TDM_CFG5`/`TDM_CFG6` must be set only when active-low `VSENSE_POWER_EN`/`ISENSE_POWER_EN` in `PWR_CTRL` is `0`. In `tas2770_parse_dt()`, missing `ti,imon-slot-no`, `ti,vmon-slot-no`, or `ti,pdm-slot-no` must default to `-1` (not `0`). In `tas2562`, when `model_id == TAS2110`, `tas2562_parse_dt()` skips sense slots and `tas2562_probe()` registers `soc_component_dev_tas2110`. [F40, F63, F128]
- In `tas2764_codec_probe()`, `sn012776_bop_presets` and `tas2764_apply_init_quirks()` must only run for `DEVID_SN012776`, pages `0xf0..0xff` must stay volatile in `tas2764_volatile_register()`, and hidden page `0xfd` sequences (`tas2764_unk_seq2`, `tas2764_pre_shutdown_seq`, `tas2764_post_shutdown_seq`) must bracket accesses with `TAS2764_REG(0xfd, 0x0d) = 0xd` and `0x0`. [F64, F125]
- In `tas2562_volume_control_put()`, the control value (`0..110`) is divided by `2` to index 55-entry `float_vol_db_lookup[]` and written big-endian across `TAS2562_DVC_CFG1` (MSB) to `TAS2562_DVC_CFG4` (LSB). [F84]
- In `tas2552`, `tas2552_sw_shutdown()` must guard `if (!tas2552->component)` before `snd_soc_component_update_bits()`. `tas2552_setup_pll()` must sample and clear `TAS2552_PLL_ENABLE` in `TAS2552_CFG_2` before writing `TAS2552_CFG_1`/`TAS2552_PLL_CTRL_1..3` and restore it after. `tas2552_set_dai_sysclk()` must rewrite out-of-range (`< 512000` or `> 24576000`) MCLK/IVCLKIN to `TAS2552_PLL_CLKIN_BCLK` and `freq = 0`. `tas2552_prepare()` must only write `tdm_delay` to `TAS2552_SER_CTRL_2` for `DSP_A` (`tdm_delay + 1`) or `DSP_B` (`tdm_delay`), and `0` otherwise. [F34, F72, F93, F99]
- In `pcm512x`, `pcm512x->sclk` can be an `ERR_PTR` at runtime; all `clk_*` calls must check `!IS_ERR(pcm512x->sclk)` and `pcm512x_dai_startup_master()` must reject `IS_ERR(pcm512x->sclk)`. Each `supplies[i]` needs its own `supply_nb[i]` (`pcm512x_regulator_event_##i`) marking `regmap` dirty and cache-only on `REGULATOR_EVENT_DISABLE`. `pcm512x_i2c_probe()` must copy `pcm512x_regmap` locally before setting `read_flag_mask`/`write_flag_mask = 0x80`. `pcm512x_overclock_pll/dsp/dac_put()` must return `-EBUSY` unless bias is `OFF` or `STANDBY`. DT `pll-in`/`pll-out` in `[1, 6]` subtract `1` for 0-based GPIO registers/shifts, and `pcm512x_hw_rule_rate()` must use `DIV_ROUND_UP(16000000, frame_size)`. [F32, F68, F69, F70, F82, F103]
- In `pcm3168a`, `pcm3168a_probe()` must copy `pcm3168a_dais` into `pcm3168a->dai_drv`, and `pcm3168a_set_dai_fmt()`/`pcm3168a_set_tdm_slot()` must call `pcm3168a_update_fixup_pcm_stream(dai)`. `pcm3168a->sysclk` must stay non-zero, `gpio_rst` is requested with `GPIOD_OUT_LOW | GPIOD_FLAGS_BIT_NONEXCLUSIVE` (and set to `1` in `pcm3168a_remove()`), and reset delays use `DIV_ROUND_UP(3846 * 1000, pcm3168a->sysclk)`. `pcm3168a_hw_params()` bounds `pcm3168a_scki_ratios[]` to 6 entries for DAC and 4 for ADC, encoding provider mode as `ms = i + 1`. [F66, F81, F105, F116, F134]
- In `pcm1681`, `pcm1681_put_deemph()` and `pcm1681_hw_params()` must both call `pcm1681_set_deemph()`, and DAC channels `1..8` map to registers via `PCM1681_ATT_CONTROL(X)` (`0x01..0x06`, `0x10..0x11`). In `pcm186x_hw_params()`, `if (priv->is_tdm_mode)` (`div_lrck = 256`) must precede `if (priv->is_provider_mode)`. [F71, F80, F94]

## Synchronization
- In `tas2781_hda_i2c.c`, all post-probe paths calling `tasdevice_*` register helpers must hold `tas_priv->codec_lock`, and callers (`tas2781_hda_playback_hook()`, `tasdev_fw_ready()`, `tas2781_hda_bind()`) must call `pm_runtime_get_sync()` before locking `codec_lock` and unlock `codec_lock` before `pm_runtime_put_autosuspend()`. [F18, F19]
- In `tascodec_init()`, `tas_priv->codec`, `rca_binaryname`, and `crc8_lkp_tbl` must be initialized under `codec_lock` before `request_firmware_nowait()` because `tasdev_fw_ready()` reads `tas_priv->codec` before acquiring `codec_lock`. In `tasdevice_dspfw_init()`, `tasdevice_dsp_prog_ctrl` and `tasdevice_dsp_conf_ctrl` must only be registered after `tasdevice_dsp_parser()` populates `tas_priv->fmw`. [F16, F17, F21]
- In `pcm512x`, `pcm512x_digital_playback_switch_get/put()` and `pcm512x_mute()` must hold `pcm512x->mutex` while accessing `pcm512x->mute` (`0x1` stream, `0x2` right, `0x4` left) and calling `pcm512x_update_mute()` (`0x5` RQML, `0x3` RQMR), and `pcm512x_mute()` must poll volatile `PCM512x_ANALOG_MUTE_DET` via `regmap_read_poll_timeout()` for `(~pcm512x->mute >> 1) & 0x3` before unlocking `mutex` on all paths. [F9, F89, F132]
- `pcm1789_trigger()` runs in atomic context and must defer `regmap_update_bits()` to `pcm1789_work_queue()` via `schedule_work(&priv->work)`; `pcm1789_common_init()` must run `INIT_WORK()` before component registration, and `pcm1789_common_exit()` must call `flush_work(&priv->work)`. [F25, F142]
- In `tas2764_codec_probe()`, `tas2764->component` assignment, `tas2764_reset()`, `regmap_reinit_cache()`, and `TAS2764_INT_MASK0..4` setup (`0` unmasks, `1` masks) must complete before registering `tas2764_irq()` via `devm_request_threaded_irq()` as a `thread_fn` with `IRQF_ONESHOT | IRQF_SHARED`. [F26, F123, F143]

## Object Lifetimes
- Callers of `tascodec_init()` must pass their own `THIS_MODULE` so `request_firmware_nowait()` pins the callback's module. On all exit paths of `tasdev_fw_ready()`, it must unlock `codec_lock`, call `release_firmware(fmw)`, and call `pm_runtime_put_autosuspend(tas_hda->dev)`. [F1, F3]
- `tas2781_read_acpi()` must release both `put_device(physdev)` and `acpi_dev_put(adev)` on all exit paths. In `tas2781_hda_i2c_probe()`, `tasdevice_init()` must run after `tas2781_read_acpi()` and before `pm_runtime_enable()`/`component_add()`, and any subsequent error must jump to `err:` so `tas2781_hda_remove()` calls `tasdevice_remove()` after `component_del()` and `pm_runtime_disable()`. [F6, F7, F22]
- In `tas2781_hda_unbind()`, clear `comp->dev`, `comp->name`, and `comp->playback_hook`, set `fw_state = TASDEVICE_DSP_FW_PENDING`, and call `tas2781_hda_remove_controls()` (removing all card kcontrols added via `tasdev_add_kcontrols()`) before `tasdevice_config_info_remove()` and `tasdevice_dsp_remove(tas_hda->priv)` (which must set `tas_dev->fmw = NULL` and also be called before reloading firmware in `tasdevice_dspfw_init()`). [F20, F58, F120, F151]
- `pcm3168a_probe()` and `pcm3168a_rt_resume()` enable `scki` before `supplies`, and rollback/`pcm3168a_disable()` must disable `supplies` before `scki`. `pcm512x_probe()` and `pcm512x_remove()` must unwind `regulator_bulk_enable()`, `clk_prepare_enable(sclk)`, and `pm_runtime_enable()` in reverse order. [F10, F130]
- In `tas2552_component_probe()`, failure at `pm_runtime_resume_and_get()` must jump to `probe_fail:` (`pm_runtime_put_noidle()`, deassert `enable_gpio`, `regulator_bulk_disable()`). In `tas2552_probe()`, failure after `pm_runtime_put_sync_autosuspend()` must call `pm_runtime_get_noresume()`. [F13, F14]

## API Contracts
- `tasdevice_dev_read/bulk_read/write/bulk_write/update_bits()` must check `chn < tas_priv->ndev`, select `TASDEVICE_BOOK_ID(reg)` via `change_chn_book()`, and pass `TASDEVICE_PGRG(reg)` to `regmap`. `tasdev_chn_switch()` does not bounds-check `chn` (callers must clamp `chn < tas_priv->ndev`) and must return `1` on address change, `0` if unchanged, or negative errno. [F27, F77, F78]
- `tasdevice_kzalloc()` and `tasdevice_init()` must never call `dev_set_drvdata(tas_priv->dev, ...)`. `tasdevice_dsp_remove()` and `tasdevice_*` firmware helpers expect `struct tasdevice_priv *` (`tas_hda->priv`) as `void *context`. `tas2781_get_i2c_res()` must skip `tas_priv->global_addr`, cap `tas_priv->ndev` at `TASDEVICE_MAX_CHANNELS`, and always return `1`. [F29, F54, F76, F110]
- `ACARD_SINGLE_RANGE_EXT_TLV` controls using `tas2781_amp_getvol/putvol` require `((1 << fls(xmax)) - 1) << xshift <= 0xff`. `tasdevice_amp_putvol()` and `tasdevice_digital_putvol()` must clamp via `tasdevice_clamp()`, iterate all `tas_priv->ndev` channels counting errors in `err_cnt`, and return `(err_cnt == tas_priv->ndev) ? 0 : 1`. [F28, F45, F150]
- In `tas2764`, `tas2770`, `tas2780`, `tas2562`, `tas2552`, and `pcm186x` `set_tdm_slot` callbacks, verify `tx_mask != 0` before `__ffs()`/`__fls()` (including before extracting a second slot). `tas2764`/`tas2770`/`tas2780` (`channels_min = 1`, `channels_max = 2`) map 1 bit to both slots, must clear consumed bits from `tx_mask` before checking `tx_mask != 0 || left_slot >= slots || right_slot >= slots`, and reject `rx_mask != 0` or >2 bits. `tas2552` requires `(__ffs(tx_mask) + 1) == __fls(tx_mask)`. `pcm186x` requires contiguous bits and `__ffs(tx_mask) * slot_width <= 255`. `tas2562`, `tas2770`, and `pcm3168a` must accept `slot_width == 0`. [F83, F86, F87, F91, F107, F146]
- Every `snd_soc_dai_ops` whose `.mute_stream` (`tas2764`, `tas2770`, `tas2780`, `tas2552`, `tas2562`, `pcm3168a`) ignores `direction` must set `.no_capture_mute = 1`. SmartAmp DAIs (`tas2552`, `tas2562`, `tas2764`, `tas2770`, `tas2780`) must keep `.capture` streams and sense/feedback DAPM widgets/routes. `pcm512x_find_sck()` and `pcm512x_pllin_dac_rate()` return `0` on error, so `pcm512x_set_dividers()` must check for `0` before dividing. [F30, F145, F147]

## Error Handling
- In `tas2563_save_calibration()`, check `efi_rt_services_supported(EFI_RT_SUPPORTED_GET_VARIABLE)` before `efi.get_variable`, and on each inner iteration zero `memset(efi_name, 0, sizeof(efi_name))` and bound the `var8`-to-`efi_name` copy by `sizeof(var8)` (`TAS2563_CAL_VAR_NAME_MAX`). [F31, F41, F114]
- In `tasdevice_dspfw_init()`, check `tas_priv->speaker_id != NULL` before `gpiod_get_value()` and clamp `< 0` to `0`. In `tas2764_parse_dt()` and `tas2770_parse_dt()`, non-`-EPROBE_DEFER` errors from `devm_gpiod_get_optional(dev, "shutdown", ...)` must set `sdz_gpio = NULL`. [F33, F35]
- In `tas2770_codec_suspend()`, if `snd_soc_component_update_bits()` fails when `!sdz_gpio`, restore `regcache_cache_only(..., false)` and `regcache_sync()`, and set `ret = 0` on success. In `pcm186x_power_on()`, if `regcache_sync()` fails, restore `regcache_cache_only(..., true)` and call `regulator_bulk_disable()` without overwriting `ret`. [F36, F37]
- `tas2562_dac_event()`, `tas2770_dac_event()`, and `sense_event()` must propagate status from `*_update_pwr_ctrl()`/`snd_soc_component_update_bits()`. `tas2764_irq()` must use `dev_crit/err_ratelimited()`, return `IRQ_NONE` when `latched[0] == 0`, and set `TAS2764_INT_CLK_CFG_IRQZ_CLR` only when `latched[0] != 0` (keeping `TAS2764_INT_LTCH0..4` and `TAS2764_INT_CLK_CFG` volatile). [F38, F124, F155]

## External Contracts
- In `tas2563_save_calibration()`, UEFI variable names use 1-based `i + 1` (`R0_%d`), whereas `cd->data` stores `p->ndev` records of `cd->cali_dat_sz_per_dev + 1` bytes: 1-byte 0-based `i` followed by `TASDEV_CALIB_N` big-endian `__be32` values. [F44]
- In `pcm512x_set_dividers()` and `pcm186x_hw_params()`, divider registers (`PCM512x_PLL_COEFF_0`/`4`, `PCM512x_*_CLKDIV*`, `PCM186X_BCK_DIV`, `PCM186X_LRK_DIV`) take `divider - 1`, whereas `PCM512x_PLL_COEFF_1..3` and `PCM512x_IDAC_1`/`2` take raw values. [F47]
- `tas2764_read_die_temp()` and `tas2770_read_die_temp()` must output millidegrees Celsius (`(reg - 93) * 1000` and `(reading - (93 * 16)) * (1000 / 16)`). `DECLARE_TLV_DB_SCALE` controls with hardware mute at step 0 (`tas2764_playback_volume`, `pcm3168a_dac/adc_tlv`, `pcm1789_dac_tlv`, `pcm179x_dac_tlv`, `pcm512x` `digital_tlv`) must set `mute = 1` and shift `min` down by one `step`. SPI codec drivers (`pcm179x`, `pcm186x`, `pcm3060`, `pcm3168a`, `pcm512x`) must keep `of_device_id` and `spi_device_id` tables matched. [F48, F136, F148]

## Known Pitfalls
- In `pcm512x_find_pll_coeff()`, after the `D = 0` loop (`for (R = 16; R; R--)`) ends with `R == 0`, reset `R = 1` before `if (num > 0xffffffffUL / 10000) goto fallback;` (which guards `10000 * num`), and in `fallback:` use 64-bit `10000ULL * pll_rate * P` and `(u64)K * pllin_rate` with `DIV_ROUND_CLOSEST_ULL()` and `DIV_ROUND_DOWN_ULL()`. [F95, F101, F102]
- In `pcm3060_set_sysclk()`, `PCM3060_REG_CSEL` has opposite polarity for DAC (`PCM3060_REG67`, 0 = CLK2) and ADC (`PCM3060_REG72`, 0 = CLK1), so `PCM3060_CLK1` sets `CSEL` only when `dai->id == PCM3060_DAI_ID_DAC` and `PCM3060_CLK2` only when `!=`. In `tas2764_set_fmt()` and `tas2770_set_fmt()`, `FRAME_START`/`FPOL_MASK` must XOR the format's base polarity with `SND_SOC_DAIFMT_INV_MASK`. [F98, F127]
