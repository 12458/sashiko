# MEMORY MANAGEMENT - CORE — include/linux

Core memory management headers defining page/folio descriptors, VMAs, address spaces, NUMA zones, GFP flags, and helpers for refcounting, page flags, highmem, MMU notifiers, page table walks, and hotplug.

## Architecture & Data Flow

- `PG_waiters` must stay at bit 7 of `folio->flags` alongside `PG_locked`; `folio_xor_flags_has_waiters()` requires the folio lock and `mask` in bits 0..6. `FOLIO_SECOND_PAGE` flags (`PG_has_hwpoisoned`, `PG_large_rmappable`, `PG_partially_mapped`) must be in `PAGE_FLAGS_SECOND`, avoid bits 0..7 (`folio_large_order()` in `folio->_flags_1 & 0xff`), and use atomic `FOLIO_FLAG(..., FOLIO_SECOND_PAGE)` rather than `__FOLIO_SET_FLAG`/`__FOLIO_CLEAR_FLAG`. [F23, F98, F99]
- Page-flag masks (`ZONES_MASK`, `NODES_MASK`, `SECTIONS_MASK`, `LAST_CPUPID_MASK`, `KASAN_TAG_MASK`, `ZONEID_MASK`) must use `1UL` so narrow types promote before `<< *_PGSHIFT`, and `*_PGSHIFT` must multiply `*_PGOFF` by `(*_WIDTH != 0)` (or `(ZONEID_SHIFT != 0)`). [F131, F132]
- Because HVO fake head pages set `PG_head`, `PageHead(page)` must check `test_bit(PG_head, &page->flags.f) && !page_is_fake_head(page)` and `PageTail(page)` must check `(READ_ONCE(page->compound_head) & 1) || page_is_fake_head(page)`. `page_fixed_fake_head()` must check `IS_ALIGNED((unsigned long)page, PAGE_SIZE)` and `test_bit(PG_head, &page->flags.f)` before reading `page[1].compound_head`. [F107, F117]
- `folio->pgmap` unions with `lru`/`mlock_count`; only call `page_pgmap(page)` when `is_zone_device_page(page)` is true. On 64-bit, `__mm_zero_struct_page()` must cover all 8-byte-aligned `sizeof(struct page)` in `[56, 96]` via fallthrough switch cases. [F42, F124]
- `page->pp_magic` (aliasing `lru.next`/`compound_head`) preserves bit 0 (`PageTail`), bit 1 (`page_is_pfmemalloc`), and `PP_DMA_INDEX_MASK`; `page_pool_page_is_pp()` must mask with `PP_MAGIC_MASK`. `PP_DMA_INDEX_BITS` must stay below `__ffs(POISON_POINTER_DELTA)` (when `> 0`) or `__ffs(PAGE_OFFSET)` (when constant and aligned to `PP_DMA_INDEX_MIN_OFFSET`, else `0`). [F84, F90]
- `mm_id_t` in `folio->_mm_id[0..1]` must fit in `MM_ID_BITS` (`<= MM_ID_MAX`), reserving `FOLIO_MM_IDS_LOCK_BITNUM` and `FOLIO_MM_IDS_SHARED_BITNUM` in `_mm_ids`. `folio_maybe_mapped_shared()` must return `mapcount > 1` for small/hugetlb folios and check `mapcount <= 1` before testing `FOLIO_MM_IDS_SHARED_BITNUM` on large folios. [F93, F126]
- Adding a `struct vm_area_struct` field requires updating `vm_area_init_from()`. In `include/linux/mm.h`, `VM_*` bits (`VM_HIGH_ARCH_BIT_0`..`6`, `VM_UFFD_MINOR_BIT`) must never collide under any Kconfig combination, and `VM_MAYREAD`..`VM_MAYSHARE` must stay at `VM_READ << 4`..`VM_SHARED << 4`. [F67, F68]
- `vm_start_gap(vma)` and `vm_end_gap(vma)` must clamp to `0` on underflow and `-PAGE_SIZE` on overflow. In `enum fault_flag`, `!(flags & FAULT_FLAG_ALLOW_RETRY) && (flags & FAULT_FLAG_TRIED)` and `(flags & FAULT_FLAG_WRITE) && (flags & FAULT_FLAG_UNSHARE)` are illegal. [F83, F110]
- `struct mm_struct` ends with `cpu_bitmap[]` (`mm_cpumask`, `mm_cpus_allowed`, and `mm_cidmask` at `0`, `+cpumask_size()`, `+2*cpumask_size()`), matching `cpumask_size() + mm_cid_size()`; no field may follow it, and `mm_cpus_allowed(mm)` + `mm->nr_cpus_allowed` must be updated together under `mm->cpus_allowed_lock`. On fork, `mmf_init_legacy_flags()` masks with `MMF_INIT_LEGACY_MASK` and clears both `MMF_HAS_MDWE` and `MMF_HAS_MDWE_NO_INHERIT` if `MMF_HAS_MDWE_NO_INHERIT` is set. [F72, F87, F94]
- `__pagetable_ctor()` and `pagetable_dtor()` must keep `PGTY_table` and `NR_PAGETABLE` (`+/-ptdesc_nr_pages(ptdesc)`) in sync, and `pagetable_pte_ctor()`/`pagetable_pmd_ctor()` must skip split-ptlock init when `mm == &init_mm`. [F73]
- `gfp_zone()` allows at most one of `__GFP_DMA`, `__GFP_DMA32`, `__GFP_HIGHMEM`, and `__GFP_MOVABLE` selects `ZONE_MOVABLE` only with `__GFP_HIGHMEM`. In `struct mem_section`, `SECTION_MAP_LAST_BIT` cannot exceed 6 bits unconditionally (`PFN_SECTION_SHIFT` on 256K-page powerpc), `sizeof(struct mem_section)` must be a power of two `<= PAGE_SIZE`, and `NR_SECTION_ROOTS` must use `DIV_ROUND_UP(NR_MEM_SECTIONS, SECTIONS_PER_ROOT)`. [F101, F113, F137]
- In `struct zone`, unusable-free watermark checks must subtract `nr_free_highatomic` (not `nr_reserved_highatomic`), and reads below `zone->percpu_drift_mark` must use `zone_page_state_snapshot()`. `MEMCG_NR_GENS` must be `>= 3`. [F78, F139]
- Update in lockstep: `___GFP_*_BIT` and `VM_*` with `include/trace/events/mmflags.h` (and `tools/perf/builtin-kmem.c`); `enum migratetype` with `migratetype_names[]`; `MM_*PAGES` with `resident_page_types[]`; and `enum lru_list` order (`LRU_ACTIVE` +1, `LRU_FILE` +2) with `NR_ZONE_LRU_BASE`, `NR_LRU_BASE`, and `vmstat_text`. Non-rate-limited NUMA promotions must increment `PGPROMOTE_CANDIDATE_NRL`, not `PGPROMOTE_CANDIDATE`. [F79, F81, F106]

## Synchronization

- Lockless `page_folio(page)` can race with folio split; callers must recheck `page_folio(page) == folio` after `folio_try_get(folio)`. `page_ref_add_unless()` must run `page_count_writable(page, u)` and `atomic_add_unless()` under `rcu_read_lock()`, checking `atomic_read_acquire(&page->_refcount) == u` before `page_fixed_fake_head(page) == page`. `page_kasan_tag_set()` must XOR the tag with `0xff` and update `page->flags.f` via `READ_ONCE()` + `try_cmpxchg()`. [F36, F88, F168]
- Because `vm_area_struct` uses `SLAB_TYPESAFE_BY_RCU` (`vm_freeptr` unions with `vm_start`/`vm_end`), unstable RCU readers may only access `vm_mm`, `vm_refcnt`, and (`READ_ONCE()`) `vm_lock_seq`. Modifying `vma->vm_flags` on a linked VMA requires VMA write-locking (`vm_flags_set`/`clear`/`mod`, or `vma_start_write` before `vm_flags_reset`). Writing `vma->vm_lock_seq` (`WRITE_ONCE()`) requires both write `mmap_lock` and `VMA_LOCK_OFFSET` in `vm_refcnt`; `mm->mm_lock_seq` uses RELEASE under write `mmap_lock` and ACQUIRE outside it. [F32, F38, F170]
- `pte_offset_map()`/`pte_offset_map_lock()` enter RCU; callers must not sleep while mapped and must unlock `ptl` before `pte_unmap()`. `folio_needs_cow_for_dma()` requires `ptl` and an active `vma->vm_mm->write_protect_seq` write section. [F35, F167]
- In MMU notifiers, `arch_invalidate_secondary_tlbs()` and `free_notifier()` must never sleep, and `invalidate_range_start()`/`invalidate()` must not sleep when `!mmu_notifier_range_blockable(range)`. `mmu_interval_set_seq()` (called unconditionally in `ops->invalidate` when `mmu_interval_read_begin()` is used) and `mmu_interval_read_retry()` must share the same driver lock. [F26, F162]
- `pgdat->node_size_lock` (`pgdat_resize_lock()`) nests above `zone->lock` and `zone->span_seqlock`. Updating `mm->owner` requires `current == mm->owner`, `current->mm != mm`, `new_owner->mm == mm`, and `task_lock(new_owner)`. [F34, F39]
- `GFP_ATOMIC` and `GFP_NOWAIT` set `__GFP_KSWAPD_RECLAIM` (`gfpflags_allow_spinning()`) and may spin on locks; NMI or `raw_spinlock_t` contexts must use `alloc_pages_nolock()`. `folio_put()`, `folio_put_refs()`, `folios_put()`, and `put_page()` must never be called in NMI context. [F156, F169]
- `page_ext_lookup()` and `for_each_page_ext()` (`page_ext_iter_begin`/`next`) require `rcu_read_lock()`, and `page_ext_get()` callers must not sleep before `page_ext_put()`. Multi-page PFN scans must use `for_each_page_ext()` rather than `page_ext_next()` across `PAGES_PER_SECTION` boundaries, and `enum page_ext_flags` users must set `.need_shared_flags = true`. [F91, F165, F193]

## Object Lifetimes

- `get_page()` and `put_page()` must return early on `folio_test_slab(folio)` or `folio_test_large_kmalloc(folio)` (frozen zero refcount). `folio_alloc_gigantic()` requires `order > 0` and `__GFP_COMP` and must be freed via `folio_put()`, not `free_contig_range()`. [F1, F14, F56]
- Never pass `FOLL_PIN` to `get_user_pages*()` or combine `FOLL_PIN` with `FOLL_GET`; release `pin_user_pages*()` pages with `unpin_user_page*()`/`unpin_folio*()`, never `put_page()`/`folio_put()`. `folio_release_kmap()` must call `kunmap_local(addr)` before `folio_put(folio)`. [F5, F190]
- Non-NULL `folio_walk_start()` returns a borrowed folio with `fw->ptl` locked (`fw->ptep` mapped on `FW_LEVEL_PTE`) that must be ended by `folio_walk_end(fw, vma)`. In `mm_walk_ops.hugetlb_entry`, dropping and retaking the VMA lock invalidates `pte` and `ptl`. [F7, F21]
- `anon_vma_name(vma)` requires `mmap_lock` and a `kref` increment if used after unlock. Fault handlers must drop locks via `release_fault_lock(vmf)` (`vma_end_read` under `FAULT_FLAG_VMA_LOCK`, else `mmap_read_unlock`), not raw `mmap_read_unlock()`. Private `alloc_pages()` users must keep bit 0 of the first union word clear, reset `page->mapping = NULL` before free, and reset `page->page_type` low 16 bits to `0xffff` before clearing page type. [F13, F15, F16]

## API Contracts

- If `pagetable_pte_ctor()` or `pagetable_pmd_ctor()` returns `false`, free with `pagetable_free()`, not `pagetable_dtor()`. With `CONFIG_HUGETLB_PMD_PAGE_TABLE_SHARING`, track/query hugetlb PMD sharing via `ptdesc_pmd_pts_*()` / `ptdesc_pmd_is_shared()`, not `page_count()`. [F9, F66]
- `folio_batch_add()` does not bounds-check (`PAGEVEC_SIZE == 31`); stop when it or `folio_batch_space()` returns `0`. Call `folio_batch_remove_exceptionals()` before `folios_put()`/`folio_batch_release()` when shadow/swap/DAX entries may exist, and use `folio_batch_reinit()` (not `folio_batch_init()`) to preserve `percpu_pvec_drained`. [F19, F85, F109]
- In `vm_operations_struct`, `set_policy` must ref non-NULL retained `@new`, `get_policy` must call `mpol_get()` only on `MPOL_SHARED` policies (else `NULL`), and `mprotect` must not mutate `vma`. If `vm_special_mapping.fault == NULL`, `.pages` must be a non-NULL, `NULL`-terminated array. VMA maple tree helpers (`vma_find`, `vma_iter_clear_gfp`, `vma_iter_bulk_store`, `mas_find`, `__mas_set_range`) must pass inclusive `vm_end - 1`. [F12, F95, F102, F180]
- `mm_flags_test`/`set`/`clear` take bit indices (`MMF_*`), while `__mm_flags_set_word`/`__mm_flags_set_mask_bits_word` take shifted masks and only touch the first `BITS_PER_LONG` word of 64-bit `mm_flags_t`. `page_mapcount_is_type()` expects `page->_mapcount + 1` (use `page_type_has_type()` for unbiased values). `Set`/`Clear`/`__ClearPageAnonExclusive()` require the head page on HugeTLB and `PageAnonNotKsm(page)`. `PG_writeback` must be set via `folio_start_writeback()`/`set_page_writeback()`. [F40, F63, F64, F155, F187]
- Unreferenced `compound_order(page)`/`page_size(page)` callers must validate the order before shifting. `folio_mk_pte`/`pmd`/`pud()` map refcounted folios without setting the special bit. [F135, F177]
- `kmap()` can sleep; `kmap_local_page()`/`kmap_local_folio(folio, byte_offset)` work in any context, map one page when `folio_test_partial_kmap(folio)` is true, and must be unmapped in LIFO order via `kunmap_local()`. Pass the return value of `folio_zero_tail(folio, offset, kaddr)` to `kunmap_local()`. `folio_zero_segment(s)`/`zero_user_segment` take an exclusive end offset; `folio_zero_range`/`memzero_page` take a byte length. `copy_mc_[user_]highpage()` returns positive uncopied bytes on MCE. [F50, F51, F52, F147, F159]
- `__alloc_pages_node()`/`__folio_alloc_node()` forbid `NUMA_NO_NODE` (unlike `alloc_pages_node()`). `gfp_has_io_fs()` checks `(gfp & (__GFP_IO | __GFP_FS)) == (__GFP_IO | __GFP_FS)`. `__GFP_NORETRY`/`__GFP_RETRY_MAYFAIL`/`__GFP_NOFAIL` require `__GFP_DIRECT_RECLAIM` (`__GFP_NOFAIL` also requires `order <= 1`). Nested allocator hooks must use `gfp_nested_mask()`. `page_frag_alloc_align()` takes `align`; `__page_frag_alloc_align()` takes `-align`. [F53, F54, F112, F157, F158]
- `mm_walk_ops.test_walk` returns `0` (walk), `1` (skip), or `< 0` (abort) and is skipped by `walk_page_vma()`. An `mmu_notifier_ops` with failable non-blocking `invalidate_range_start` must not define `invalidate_range_end`, and callers must not touch PTEs if `mmu_notifier_invalidate_range_start_nonblock()` fails. `get_user_page_vma_remote()` returns `ERR_PTR` (never `NULL`) and rejects `FOLL_NOWAIT`. [F27, F46, F59]
- `pfn_valid(pfn)` must check `PHYS_PFN(PFN_PHYS(pfn)) == pfn` and `pfn_to_section_nr(pfn) < NR_MEM_SECTIONS`. `first_valid_pfn`/`next_valid_pfn` return `>= end_pfn` on exhaustion (`next_valid_pfn` only rechecks at (sub)section boundaries). `next_present_section_nr()` pre-increments (pass `start - 1`) and returns `-1UL` on exhaustion. `first`/`next_zones_zonelist()` return a sentinel with `zonelist_zone(z) == NULL` and require `++z` before `next_zones_zonelist()`. [F48, F108, F121, F122, F123]
- `vmstat_item_in_bytes()` is true only for `NR_SLAB_[UN]RECLAIMABLE_B`. `memory_notify.altmap_*` are valid only on `MEM_PREPARE_ONLINE`/`MEM_FINISH_OFFLINE`. `VM_WARN_ON_ONCE_*()` static `__warned` flags must use `__section(".data..once")`. [F179, F191, F192]

## External Contracts

- User-facing RSS/swap reporting must use `get_mm_counter_sum()`, not `get_mm_counter()`. [F178]

## Known Pitfalls

- Verify `!folio_test_slab(folio)` before calling `folio_test_anon()`, `PageAnon()`, `PageAnonNotKsm()`, or `folio_test_ksm()` on arbitrary pages, and mask `folio->mapping` with `FOLIO_MAPPING_FLAGS` to distinguish `FOLIO_MAPPING_ANON` from `FOLIO_MAPPING_KSM`. Gate `PG_swapcache` on `folio_test_swapbacked()` and `PageMovableOps()` on `PageOffline() || PageZsmalloc()` (`page_has_movable_ops()`). `folio_has_private()` only checks the head page. [F41, F115, F116, F188]
- Never use `struct folio *` pointer arithmetic (`sizeof(struct folio) == 4 * sizeof(struct page)`); use `folio_page()` or `folio_next()`. On 32-bit, `_entire_mapcount` and `_pincount` are in `__page_2` (absent on order-1 folios); use `folio_entire_mapcount()` and `folio_has_pincount()`. On stack snapshots (`dump_page()`), test `page->compound_head & 1` instead of `PageTail()` (`folio_flags()`) and pass PFN to `is_migrate_cma_folio()`/`get_pfnblock_migratetype()`. [F141, F142, F145, F146]
- `FOLIO_TYPE_OPS`/`PAGE_TYPE_OPS` must cast `PGTY_*` to `unsigned int` before `<< 24`, while `page_type_has_type()` takes signed `int`. Cast `folio_ref_count()` to `unsigned int` in `folio_maybe_dma_pinned()` and `folio_ref_zero_or_close_to_overflow()`. Define `VM_*` flags at bit `>= 31` with `BIT()` (`unsigned long`). Pass pointers (`&folio->flags`, `&gfp_mask`, `&vma->vm_flags`) to `%pGp`, `%pGg`, `%pGv`. [F130, F133, F134, F153]
- Use `mmu_notifier_range_init_owner()` for `MMU_NOTIFY_MIGRATE`/`MMU_NOTIFY_EXCLUSIVE` and only read `range->owner` on those events. `mm_cid_is_lazy_put(cid)` must check `!mm_cid_is_unset(cid) && (cid & MM_CID_LAZY_PUT)`. Use `lruvec_pgdat(lruvec)` instead of `container_of`. Zeroed user folios must use `user_alloc_needs_zeroing()` + `clear_user_highpage()`/`folio_zero_user()`, not `__GFP_ZERO`. [F58, F128, F149, F161]
