# TRACING — kernel/trace (part 4)

Advanced ftrace trace-event mechanisms: event triggers (`trace_events_trigger.c`), histograms and actions (`trace_events_hist.c`), synthetic events (`trace_events_synth.c`), user-space trace events (`trace_events_user.c`), event injection (`trace_events_inject.c`), and event format exports (`trace_export.c`).

## Architecture & Data Flow

- `file->triggers` is heterogeneous: loops must check `cmd_ops->trigger_type` before casting `private_data`, and `find_named_trigger()` must skip entries with `data->named_data != NULL`. Trigger callbacks (`traceon`/`traceoff`/`snapshot`/`stacktrace`) must check `file = data->private_data` and act on `file->tr` when non-NULL. [F71, F120, F141]
- In `struct action_data`, `data->handler` discriminates `match_data` (`HANDLER_ONMATCH`) vs `track_data` (`HANDLER_ONMAX`/`HANDLER_ONCHANGE`); for `ACTION_TRACE`, `synth_event_name` is set only when `use_trace_keyword` is true (else `action_name`). `create_var_ref()` and `parse_action_params()`/`trace_action_create()` must bound `n_var_refs < TRACING_MAP_VARS_MAX` and `n_params <= SYNTH_FIELDS_MAX`. [F58, F59, F100]
- In `event_hist_trigger_parse()`, `create_actions()` must precede `save_hist_vars()` (when `has_hist_vars(hist_data) || hist_data->n_var_refs`) and `tracing_map_init()`, because `hist_trigger_elt_data_alloc()` sizes `field_var_str` to `n_field_var_str + n_save_var_str + n_var_str` and allocates `elt_data->comm` only when `HIST_FIELD_FL_EXECNAME` is set (all `elt_data->comm` users must NULL-check it). [F62, F69, F74]
- In `event_hist_trigger()`, `hist_pad->compound_key` (`key_size`) and `hist_pad->entries` (`HIST_STACKTRACE_SIZE`) must be zeroed via `memset()`. `create_key_field()` aligns keys to `sizeof(u64)` up to `HIST_KEY_SIZE_MAX`, and `add_to_key()` clamps string copies to `key_field->size - 1`. `resolve_var_refs()` runs with `self = false` before `hist_trigger_elt_update()` and `self = true` after. [F64, F103, F117]
- `create_tracing_map_fields()` registers `HIST_FIELD_FL_VAR` as map variables, so `create_sort_keys()` must skip `HIST_FIELD_FL_VAR` when incrementing `k` for `sort_key->field_idx`, and `event_hist_trigger_print()` must add `hist_data->n_vars` when `idx >= hist_data->n_vals - hist_data->n_vars`. `hist_show()` sets both `hist_file->last_read` and `last_act` to `get_hist_hit_count(event_file)`. [F78, F110]
- In `parse_unary()`/`parse_expr()`, non-constant expressions copy `size`, `is_signed`, `type`, and `HIST_FIELD_FL_TIMESTAMP[_USECS]` from `operand1`. `contains_operator()` uses `strrchr()` for `+`/`-` before `/`/`*` (`plus_op > minus_op`, `mult_op > div_op`). For `FIELD_OP_DIV` with a `HIST_FIELD_FL_CONST` divisor, `parse_expr()` rejects `0` and copies the constant to `operand2->constant` before `hist_field_get_div_fn()`; `HIST_FIELD_FN_DIV_MULT_SHIFT` requires `div <= (1 << HIST_DIV_SHIFT)` and `val1 < (1 << HIST_DIV_SHIFT)`. [F72, F108, F122, F123]
- Histogram stacktrace variables store frame count at `((unsigned long *)str)[0]` and frames at `1..`; `trace_event_raw_event_synth()`, `print_synth_event()`, and `event_hist_trigger()` must reserve/skip index 0. Any `dyn_event_list` iteration must check `is_synth_event(pos)` before `to_synth_event(pos)`. [F60, F95]
- `synth_field.offset` and `synth_event.n_u64` count 8-byte `union trace_synth_field` slots (`STR_VAR_LEN_MAX / sizeof(u64)` for static strings, 1 otherwise), while `trace_define_field()` and `trace_dynamic_info.offset` use byte offsets. In `check_synth_field()`, when `strcmp(field->type, hist_field->type) != 0`, `is_signed` equality is required only when `!field->is_string`. `ERRORS` X-macro tables in `trace_events_{hist,synth}.c` must match `err_text[]` 1-to-1. [F107, F128, F176]
- `trace_alloc_entry()` (`trace_events_inject.c`) allocates `entry_size + 1` zeroed bytes and initializes `FILTER_{DYN,RDYN,PTR}_STRING` fields to point to the trailing NUL or `""`, encoding dynamic locators as `(str_len << 16) | str_loc` (`str_loc` reduced by `field->offset + field->size` for `FILTER_RDYN_STRING`). [F65, F99]
- In `trace_events_user.c`, `ftrace_event_field.offset` and `user_event_validator.offset` include `sizeof(struct trace_entry)`, whereas `user->min_size` excludes it; `user_event_{ftrace,perf}()` copy into `entry + 1` but pass `entry` to `user_event_validate()`. `user_events_write_core()` must verify `idx >= 0 && idx < refs->count` and `i->count >= user->min_size`. [F88, F137]
- `user_event_enabler.values` must be `unsigned long`. `user_event_enabler_dup()` skips `ENABLE_VAL_FREEING_BIT` enablers and masks `values` with `ENABLE_VAL_DUP_MASK`. `attempt` in `user_event_enabler_create()`, `user_event_mm_clear_bit()`, and `user_event_enabler_fault_fixup()` is initialized before `retry:` and bounded by `attempt > 10` in `user_event_mm_fault_in()`. `find_user_event()` matches `EVENT_MULTI_FORMAT(reg_flags)`, and teardown frees `EVENT_TP_NAME(user)` when `!= EVENT_NAME(user)`. [F82, F85, F116, F138]

## Synchronization

- `event_mutex` nests outside `trigger_cmd_mutex`. `file->triggers` changes and `update_cond_flag()` require `event_mutex` and `list_{add,add_tail,del}_rcu`. `trigger_data_free()`, `set_trigger_filter()`, and `hist_clear()` must call `tracepoint_synchronize_unregister()` before freeing a trigger/filter or clearing a map; in `event_hist_trigger_free()`, `trigger_data_free()` precedes `remove_hist_vars()`, `unregister_field_var_hists()`, `destroy_hist_data()`, and `free_hist_pad()`. [F35, F38, F155, F156]
- `[un]pause_named_trigger()` updates `paused` on all `named_triggers` sharing `name`, and `hist_clear()` pauses them and calls `tracepoint_synchronize_unregister()` before `tracing_map_clear()`. `event_hist_trigger()` acquires/releases its per-CPU scratch buffer via `{get,put}_hist_pad()`. [F77, F145]
- In `trace_events_synth.c`, `last_cmd` requires `lastcmd_mutex`, and string fields in `trace_event_raw_event_synth()`/`trace_string()` must use `fetch_store_{strlen,string}()` or `strncpy_from_{user,kernel}_nofault()`. `event_inject_write()` holds `event_mutex` across `event_file_file()`, `parse_entry()`, and `trace_inject_entry()`, which holds `rcu_read_lock_sched()` across buffer reserve/commit. [F24, F43, F147]
- In `trace_events_user.c`, lock order is `group->reg_mutex` -> `event_mutex` -> `mm->mmap_lock`. `user_event_parse()` holds `group->reg_mutex` for `user_event_set_tp_name()` and `event_mutex` for `current_user_events`, registration, and `group->register_table`. `user_event_{put,enabler_destroy}(..., locked)` require `locked == true` iff `event_mutex` is held. [F32, F154]
- `user_event_mm_remove()` cycles `mmap_write_lock(mm->mm)` after `mm->tasks` hits 0 and defers `user_event_mm_put()` via `queue_rcu_work()`. `user_event_enabler_write()` (under `event_mutex` and `mmap_read_lock`) and `user_event_mm_fault_in()` check `refcount_read(&mm->tasks) == 0`; `user_event_enabler_write()` passes `FOLL_WRITE | FOLL_NOFAULT` to `pin_user_pages_remote()`, releases via `kunmap_local()` and `unpin_user_pages_dirty_lock(&page, 1, true)`, and on fault queues work with `GFP_NOWAIT` (or callers drop `mmap_read_lock` and `event_mutex` before `user_event_mm_fault_in()`). [F27, F30, F151, F169]
- `user_event_enabler_update()` (under `event_mutex`) collects `mm->next` via `user_event_mm_get_all()` under `rcu_read_lock()`, drops RCU, then locks each `mm->mm` and calls `user_event_mm_put()`. `user_events_ref_add()` updates `info->refs` under `group->reg_mutex` via `rcu_assign_pointer()` and `kfree_rcu()`; `user_events_write_core()` calls `fault_in_iov_iter_readable()` before `rcu_read_lock_sched()` and copies via `copy_nofault()`. [F149, F150, F158]

## Object Lifetimes

- `parse_entry()` leaves `*pentry` allocated on non-`-ENOMEM` errors, so `event_inject_write()` must unconditionally call `kfree(entry)`. In `event_trigger_parse()`, `trigger_data_alloc()`'s object is bracketed by `event_trigger_{init,free}()` and freed via `trigger_data_free()`, never `kfree()`. [F1, F3]
- `register_snapshot_trigger()` arms via `tracing_arm_snapshot(file->tr)` and disarms on `register_trigger()` failure; `unregister_snapshot_trigger()` disarms only if `try_unregister_trigger()` returns `true`. `event_enable_trigger_parse()` calls `trace_event_try_get_ref()` and `trace_event_enable_disable(event_enable_file, 1, 1)` before `event_trigger_register()`, unwinding both on failure and in `event_enable_trigger_free()`. [F5, F6]
- `synth_event_reg()` pins `event->mod` via `try_module_get()` before `trace_event_reg()` on register and calls `module_put()` after unregister; `synth_event_delete()` calls `tracing_reset_all_online_cpus()` after dropping `event_mutex` if `se->mod != NULL`. `alloc_synth_event()` takes ownership of `fields[]` only on success (`event->n_fields = n_fields`). `destroy_synth_event()` and `synth_event_release()` require `se->ref == 0` (under `event_mutex`). [F7, F8, F10, F174]
- In `event_hist_trigger_parse()`, fallible setup (`create_actions()`, `save_hist_vars()`, `tracing_map_init()`) must precede `event_trigger_register()`. `save_hist_vars()` takes a `tr` ref via `tracing_check_open_get_tr(tr)` (releasing on `kzalloc()` failure), and `remove_hist_vars()` runs before `destroy_hist_data()` to unlink/free `var_data` and call `trace_array_put(tr)`. [F11, F12]
- `event_hist_trigger_init()` calls `alloc_hist_pad()` before incrementing `data->ref`, and `event_hist_trigger_free()` calls `free_hist_pad()` on every call regardless of `--data->ref`. `create_hist_data()` clears `hist_data->attrs = NULL` on error so its caller frees `attrs`. `destroy_hist_field()` ignores `HIST_FIELD_FL_VAR_REF` fields (freed once via `__destroy_hist_field()` on `hist_data->var_refs[]` in `destroy_hist_fields()`). [F13, F15, F16]
- `user_event_parse()` takes ownership of `name` only on success; on error the caller frees `name`. When `user_event_put()` drops the last ref to a non-persistent `user_event`, it holds `event_mutex`, resets `user->refcnt` to 1, and queues `delayed_destroy_user_event()`. Under `event_mutex`, `destroy_user_event()` calls `user_event_destroy_fields()` before `user_event_set_call_visible(user, false)`, and only on success unlinks `user` and decrements `current_user_events`. [F17, F18, F19]
- `user_events_ioctl_unreg()` skips `user_event_enabler_destroy()` when `ENABLE_VAL_FAULTING_BIT` is set (deferring to `user_event_enabler_fault_fixup()`). On payload copy/validation failure after reservation, `user_event_ftrace()` calls `__trace_event_discard_commit()` and `user_event_perf()` calls `perf_swevent_put_recursion_context()`. [F22, F23]

## API Contracts

- `trace_event_raw_event_synth()` and `[__]synth_event_trace_{start,end}()` bracket buffer reserve/commit with `ring_buffer_nest_{start,end}()`, and callers must call `_end()` once `_start()` succeeds. `__synth_event_add_val()` checks `trace_state->disabled` before dereferencing `event`/`entry` and returns `-EINVAL` if `add_name` and `add_next` are mixed. `{create_synth,user_event}_create()` return `-ECANCELED` on prefix mismatch. [F9, F45, F121, F148]
- `parse_field()` returns `ERR_PTR` on error, or `NULL` on success for common/synthetic fields while setting `HIST_FIELD_FL_*`. `find_match_var()`, `find_synthetic_field_var()`, and `create_target_field_var()` return `NULL`, a valid pointer, or `ERR_PTR` (check both and clear `ERR_PTR` before cleanup). `synth_field_size()` returns `0` for both valid dynamic (`char[]`, `long[]`) and unknown types. `trace_string()` returns dynamic byte length (`0` if static) and advances `*n_u64` by `1` or `STR_VAR_LEN_MAX / sizeof(u64)`. [F51, F52, F54, F55]
- `__data_loc` (`FILTER_DYN_STRING`) offsets are relative to the event entry start; `__rel_loc` (`FILTER_RDYN_STRING`/`VALIDATOR_REL`) offsets are relative to `field->offset + sizeof(u32)`. `__set_synth_event_print_fmt()` excludes NUL (allocate `len + 1`), whereas `user_*_set_*()` include NUL; `user_dyn_field_set_string()` updates `*iout = i` only when `len != 0`. `__fill_bar_str(buf, size, ...)` requires `size + 1` bytes. [F67, F112, F133, F142]
- `user_event_capable()` requires `perfmon_capable()` for `USER_EVENT_REG_PERSIST` on create/delete. `user_event_set_call_visible()` overrides `fsuid = GLOBAL_ROOT_UID` around `trace_{add,remove}_event_call()`. User-triggered allocations in `trace_events_user.c` use `GFP_KERNEL_ACCOUNT`/`__GFP_ACCOUNT`. `{synth_events,event_trigger_regex}_open()` check `security_locked_down(LOCKDOWN_TRACEFS)` first; `event_hist{_debug}_open()` clear `file->private_data = NULL` after `tracing_open_file_tr()` before `single_open()` and call `tracing_release_file_tr()` on error. [F166, F167, F168, F171, F172]

## Error Handling

- `set_trigger_filter()` sets `data->filter` even on error, so callers of `event_trigger_set_filter()` must call `event_trigger_reset_filter()` on failure. Tracefs file ops on `trace_event_file` must call `event_file_file(filp)` under `event_mutex` and return `-ENODEV` if NULL. `register_synth_event()` and `user_event_trace_register()` translate `0` from `register_trace_event()` to `-ENODEV`, and `register_synth_event()`/`create_hist_data()` reset `event->tp`/`hist_data->map` to `NULL` after `IS_ERR()`. [F4, F44, F46, F47]
- `create_hist_field()` returns `NULL` (never `ERR_PTR`); callers and `hist_field_name()` must NULL-check `hist_field`. `hist_field_div()` returns `-1` on `!val2` before `__ffs64()`/`div64_u64()`. Record-consuming triggers like `event_hist_trigger()` return early if `unlikely(!rbe)`. `synth_event_trace{_array,_start}()` translate `-ENOENT` from `__synth_event_trace_init()` to `0`. [F53, F61, F124, F177]

## External Contracts

- `user_{reg,unreg}_get()` bound `size` to `[offsetofend(...), PAGE_SIZE]`, use `copy_struct_from_user()`, and reject unknown `flags`, unaligned/inaccessible `enable_addr`, invalid `enable_size`/`enable_bit`, or non-zero reserved fields. `user_event_{ftrace,perf}()` validate dynamic fields via `user_event_validate()` after copying into the kernel buffer. [F86, F163, F165]
- `user_event_parse()` uses `user_event_argv_split()`, and `user_field_set_string()`/`user_event_show()` append `" %d"` (`field->size`) when `field->type` starts with `"struct "`. `__create_synth_event()` allows multiple fields per `;` segment when `cmd_version == 1`. `__array()` in `trace_export.c` sets `.len = _len`. `__create_val_field()` rejects `GRAPH`/`PERCENT`/`BUCKET`/`LOG2` on `HIST_FIELD_FL_VAR`, and rejects `SYM`/`SYM_OFFSET`/`SYSCALL`/`STACKTRACE` only on non-variable values. [F91, F92, F97, F98, F104]

## Known Pitfalls

- `parse_field()` sets `HIST_FIELD_FL_*` alongside a dummy `ftrace_event_field` (`size == 0`) for legacy `cpu`/`stacktrace`/`comm`, so `create_tracing_map_fields()` must check `hist_field->flags` before `field->size`. In `parse_entry()`, `entry` must be refreshed from `*pentry` after `krealloc()` and freed on `krealloc()` failure. `user_events_write_core()` passes a fresh `copy = *i` of the `iov_iter` to each probe. [F70, F79, F84]
- `align_addr_bit()` aligns `uaddr` to `sizeof(long)` and adds 32 to `bit` for `ENABLE_VAL_32_ON_64_BIT` (big-endian aligned, little-endian unaligned). `user_event_parse_field()` checks `"__{data,rel}_loc unsigned "` before `"__{data,rel}_loc "`. Two-pass `snprintf` helpers pass `LEN_OR_ZERO` (`len ? len - pos : 0`). [F90, F93, F109]
- In `trace_events_synth.c`, access `entry->fields[n_u64]` via width-matched `union trace_synth_field` members (`as_u8`..`as_u64`, `as_dynamic`), chain `is_string`/`is_stack`/scalar branches with `if`/`else if`/`else`, return `"%s"` in `synth_field_fmt()`, and advance `t` by `sizeof("__data_loc")` in `__synth_event_show()`. [F94, F106, F132, F134]
- Trigger unregister loops (`{hist,try,event_enable}_unregister_trigger()`) save a matched entry in a separate NULL-initialized pointer before `break`. `check_expr_operands()`/`parse_expr()` resolve `HIST_FIELD_FL_VAR_REF`/`ALIAS` via `find_var_field(operand->var.hist_data, ...)`. In `event_enable_*()`, `trace_event_trigger_enable_disable()`/`update_cond_flag()` target `file`, while soft-mode `trace_event_enable_disable(..., 1)`/`trace_event_try_get_ref()` target `enable_data->file`. `__get_percentage()` re-checks `!total` after `div64_u64(total, 10000)`, and `hist_field_bucket()` uses `div64_ul()` when `val >= LONG_MAX`. [F113, F118, F119, F125, F126]
