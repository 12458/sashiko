# USB NETWORKING DRIVERS — drivers/net/usb (part 1)

`usbnet` minidrivers (`aqc111`, `asix_*`/`ax88172a`/`ax88179_178a`, `mcs7830`, `ch9200`, `cx82310_eth`, `gl620a`, `huawei_cdc_ncm`, `int51x1`, `kalmia`, `lg-vl600`, `net1080`) and standalone USB network drivers (`catc`, `cdc-phonet`, `ipheth`, `kaweth`, `pegasus`).

## Architecture & Data Flow

- Structs overlaid onto `usbnet::data` (`unsigned long[5]`, 20B on 32-bit)—`asix_data`, `mcs7830_data`, `huawei_cdc_ncm_state`—must fit in `sizeof(dev->data)`; `huawei_cdc_ncm_state` must keep `struct cdc_ncm_ctx *ctx` at offset 0. [F83, F125]
- In `aqc111_rx_fixup()` and `ax88179_rx_fixup()`, validate trailer bounds (`skb->len >= sizeof(desc_hdr)`, `start_of_descs == desc_offset`, `pkt_count * 2 + desc_offset < skb_len` in `aqc111`; `pkt_cnt * 4 + hdr_off <= skb->len` after 4B trim in `ax88179`), set `pkt_desc_ptr`/`pkt_hdr` from `skb->data`, and `skb_trim()` to `desc_offset`/`hdr_off` before `skb_pull()`. [F76, F78, F129]
- In `aqc111_rx_fixup()`, check `pkt_len <= dev->hard_mtu + AQ_RX_HW_PAD` and cumulative `pkt_total_offset` (`(pkt_len + 7) & 0x7FFF8`) `<= desc_offset` (`==` when `pkt_count == 0`). In `ax88179_rx_fixup()`, skip `pkt_len == 0` dummy headers and verify `pkt_len_plus_padd <= skb->len` (`(pkt_len + 7) & 0xfff8`) and `pkt_len >= 2 + ETH_HLEN`. In `aqc111_rx_checksum()`/`ax88179_rx_checksum()`, check L3/L4 error bits before comparing masked L4 proto (`==`, not `&`). [F77, F79, F98]
- In `aqc111`, keep `aqc111_data->rx_checksum` and `SFR_RXCOE_CTL` synced in `aqc111_set_features()` and `aqc111_configure_csum_offload()`. Keep `aqc111_data->rxctl` synced with `SFR_RX_CTL` in `aqc111_set_rx_mode()`/`aqc111_link_reset()`, but use `temp_rx_ctrl` in `aqc111_suspend()` so `aqc111_resume()` restores `rxctl`. In `aqc111_set_phy_speed()`, `SPEED_5000..SPEED_100` fall through when `autoneg == AUTONEG_ENABLE`, else `break`. [F64, F65, F112]
- `ax88179_status()` must defer via `usbnet_link_change()` to `ax88179_link_reset()`, which checks `GMII_PHY_PHYSR_LINK`, updates `AX_RX_BULKIN_QCTRL` and `dev->rx_urb_size` together, and sets carrier on. Because `ax88179_stop()` clears `AX_MEDIUM_RECEIVE_EN`, `driver_info` entries using it need `.reset = ax88179_net_reset`, which checks hardware `GMII_PHY_PHYSR` (running `ax88179_reset()` if 0, else restoring `AX_MEDIUM_RECEIVE_EN`). [F59, F60, F140]
- `ax88179_bind()` must run `ax88179_reset()`, and `ax88179_get_mac_addr()` must read platform MAC or `AX_NODE_ID` and call `eth_hw_addr_set()` (setting `NET_ADDR_PERM` if `!is_local_ether_addr(mac)`) before writing `dev_addr` to `AX_NODE_ID`. Functions in `ax88179_178a.c`/`asix_devices.c` changing `GMII_PHY_PAGE_SELECT` (`0x1f`) must restore page 0 on all return paths. In `ax88772_init_phy()`, `priv->phydev_int` is `NULL` when `priv->embd_phy` is true. [F44, F62, F141, F179]
- In `ipheth_probe()`, call `ipheth_enable_ncm()` before `ipheth_alloc_urbs()` and update `rx_buf_len` and `rcvbulk_callback` together. `ipheth_rcvbulk_callback()` must jump to `rx_submit` on 0B or 4B `0x00, 0x01` URBs. `ipheth_rcvbulk_callback_ncm()` must check `actual_length >= IPHETH_NCM_HEADER_SIZE`, `wNdpIndex == cpu_to_le16(sizeof(struct usb_cdc_ncm_nth16))`, and bound `dpe16` to `IPHETH_NDP16_MAX_DPE` (22). [F69, F80, F104]
- In `catc`, for `is_f5u011`, `catc_irq_done()` seeing `hasdata` while `RX_RUNNING` is set increments `recq_sz`, and `catc_rx_done()` must break after 1 packet (advancing `pkt_start` by 64B stride only on non-F5U011), decrement `recq_sz`, resubmit `rx_urb`, and clear `RX_RUNNING` only when `recq_sz == 0`. `catc_stats_timer()` must queue `EthStats + 7..0` descending for `catc_stats_done()`. [F71, F105, F107]
- In `pegasus.c`, `usb_dev_id[]` and `pegasus_ids[]` must match in order and keep two trailing `{}` sentinels. `read_bulk_callback()` must check `count >= 4`, mask `buf[count - 2]` with `0x1c` (ignoring `0x02` `Long_pkt`), and check `pkt_len <= PEGASUS_MTU`. `pegasus_resume()` must zero `status`/`actual_length` on `rx_urb`/`intr_urb` before calling their callbacks. [F73, F91, F97, F130]
- Check `fw->size <= KAWETH_FIRMWARE_BUF_SIZE` in `kaweth_download_firmware()`, and `count > 2 && pkt_len <= count - 2` in `kaweth_usb_receive()`. Keep `vl600_pkt_hdr` 14B (`h_proto` at 12), and in `vl600_rx_fixup()` check `frame->magic` (`0x53544448`/`0x44544d48`) and `skb->len + s->current_rx_buf->len <= le32_to_cpup(&frame->len)`. [F85, F86, F92, F93]
- Preserve `TTL_OTHER(ttl)` via `MK_TTL()` in `net1080_reset()`, and in `net1080_rx_fixup()` check `skb->len >= hard_header_len`, `skb->len & 1`, `FRAMED_SIZE(packet_len) <= NC_MAX_PACKET`, `hdr_len >= MIN_HEADER`, and even `PAD_BYTE` (`0xAC`). In `cx82310_rx_fixup()`, reject `len > CX82310_MTU` before saving to `dev->partial_data` and pull `(len + 1) & ~1`. In `cdc-phonet.c`, allocate `netdev` with `struct_size(pnd, urbs, rxq_size)`, and set `pnd->disconnected = 1` before `usb_driver_release_interface()` on `(pnd->intf == intf) ? pnd->data_intf : pnd->intf`. [F74, F87, F109, F114, F121, F132]

## Synchronization

- In `usbnet`, `.ndo_set_rx_mode` (`aqc111_set_rx_mode`, `asix`/`ax88172`/`ax88179`/`mcs7830`/`int51x1_set_multicast`) runs in BH context and must use `usbnet_write_cmd_async()`, `driver_info->status` (`aqc111`/`asix`/`ax88179`/`ch9200`/`mcs7830_status`) runs in IRQ context and must defer via `usbnet_defer_kevent()`/`usbnet_link_change()`, and `rx_fixup` runs in BH context (`cx82310_rx_fixup` uses `schedule_work(&priv->reenable_work)`; `nc_ensure_sync` uses `usbnet_write_cmd_async()`). [F156, F158, F159]
- Hold `dev->phy_mutex` in `__asix_mdio_read()`/`__asix_mdio_write()` (across `asix_check_host_enable()`, MII transfer, and `asix_set_hw_mii()`) and in `mcs7830_read_phy()`/`mcs7830_write_phy()` (across command, `HIF_REG_PHY_CMD2_READY_FLAG_BIT` poll, and data read). [F21, F137]
- `ax88772_bind()` must hold `pm_runtime_get_noresume(&intf->dev)` until `ax88772_unbind()` calls `pm_runtime_put()` to avoid `rtnl_lock` deadlock between `ndo_open()` and `ax88772_resume()`, and `ax88772_suspend`/`resume`/`init_phy`/`unbind` must wrap `phylink_suspend()`, `phylink_resume()`, and `phylink_disconnect_phy()` in `rtnl_lock()`/`rtnl_unlock()`. [F152, F153]
- In `catc.c`, use `spin_lock_irqsave()` for `tx_lock` (toggling `tx_idx = !tx_idx` and zeroing `tx_ptr` in `catc_tx_run()`) and `ctrl_lock` (masking `ctrl_head`/`ctrl_tail` with `CTRL_QUEUE - 1`, advancing `ctrl_tail` on overflow, never sleeping or calling `catc_ctrl_async()` in callbacks). `catc_stop()` must call `timer_delete_sync(&catc->timer)` before `usb_kill_urb(catc->ctrl_urb)`. [F70, F89, F160, F161]
- In `cdc-phonet.c:rx_complete()`, hold `spin_lock_irqsave(&pnd->rx_lock, flags)` around `pnd->rx_skb`, copy the 1B header via `skb_put_data()` before attaching `page` at offset 1, set `page = NULL` when consumed so `resubmit` only calls `put_page(page)` on unused pages, clear `pnd->rx_skb = NULL` only when `actual_length < PAGE_SIZE`, and set `req = NULL` on `-ENOENT`/`-ECONNRESET`/`-ESHUTDOWN`. [F5, F68, F113, F162]
- In `kaweth.c`, set `KAWETH_STATUS_CLOSING`/`SUSPENDING` before `kaweth_kill_urbs()`, which kills URBs before and after `cancel_delayed_work_sync(&kaweth->lowmem_work)`; `kaweth_set_rx_mode()` only updates `packet_filter_bitmap`, and `kaweth_async_set_rx_mode()` returns early if `!may_sleep`. In `pegasus.c`, `pegasus_set_multicast()` must use `update_eth_regs_async()`, `pegasus_close()` calls `tasklet_kill(&pegasus->rx_tl)` before `unlink_all_urbs()`, and `pegasus_disconnect()` sets `PEGASUS_UNPLUG` before `cancel_delayed_work_sync()`/`unregister_netdev()`. `ipheth_sndbulk_callback()` must defer carrier checks to `dev->carrier_work`. [F28, F165, F166, F167, F168]

## Object Lifetimes

- `ax88772_bind()` uses `devm_kzalloc()` and manually sets up `priv->mdio`, `priv->phylink`, PHY, and `pm_runtime_get_noresume()` (never `devm_mdiobus_*` on `&dev->udev->dev`), which `ax88772_unbind()` and error paths unwind in reverse order (`pm_runtime_put`, `phylink_disconnect_phy` under `rtnl_lock`, `phylink_destroy`, `ax88772_mdio_unregister`); `ax88178_bind()` uses `kzalloc()` and pairs with `ax88178_unbind()` (`kfree`). [F1, F2, F46, F134]
- Clear `rx->ax_skb` (`asix_rx_fixup_internal()`) and `s->current_rx_buf` (`vl600_rx_fixup()`) to `NULL` on `usbnet_skb_return()` or error free (`reset_asix_rx_fixup_info()`/`dev_kfree_skb_any()`), and free on unbind. If `netdev_alloc_skb_ip_align()` fails in `asix_rx_fixup_internal()`, still set `rx->remaining = size` and advance `offset` while guarding `rx->ax_skb`. [F3, F4, F42, F101]
- On `usbpn_open()` failure, `usb_free_urb(req)` for unsubmitted `req` and call `usbpn_close(dev)` (which kills/frees and NULLs `pnd->urbs[i]`). In `huawei_cdc_ncm_bind()`, check `!IS_ERR(subdriver)` before setting `drvstate->subdriver` and NULL `usbnet_dev->status`; `huawei_cdc_ncm_unbind()` must call `subdriver->disconnect()` and NULL `subdriver` before `cdc_ncm_unbind()`. [F7, F8, F45]
- If `irq_urb` submit fails in `kaweth_open()`, kill `rx_urb` and call `usb_autopm_put_interface()`. In `pegasus_disconnect()`, `dev_kfree_skb(pegasus->rx_skb)` only after `unregister_netdev()` and `unlink_all_urbs()`. In `ipheth_disconnect()`, call `unregister_netdev()` and `ipheth_kill_urbs()` before freeing URBs, `ctrl_buf`, and `netdev`. In `cx82310_unbind()`, `cancel_work_sync(&priv->reenable_work)` before freeing `driver_priv` and `partial_data`. Pass persistent `<= 64`B buffers to `catc_ctrl_async()` and array lvalues to `f5u011_*_async()`. [F11, F12, F15, F16, F127]

## API Contracts

- Direct `usb_control_msg()`/`usb_bulk_msg()` callers (`__aqc111_write_cmd`, `ch9200`, `cx82310_cmd`, `kalmia`, `catc_probe`) must use heap buffers. Reinitializing coherent URBs with `usb_fill_bulk_urb()`/`usb_fill_int_urb()` in `ipheth`/`kaweth` must re-set `URB_NO_TRANSFER_DMA_MAP`. [F163, F169]
- In `usbnet`, `rx_fixup` must check `skb->len` against header/trailer sizes. With `FLAG_MULTI_PACKET` (`aqc111`, `asix_devices`, `ax88172a`), `rx_fixup` passes all frames to `usbnet_skb_return()` and returns 0, and `tx_fixup` calls `usbnet_set_skb_tx_stats()`. `aqc111`/`ax88179_rx_fixup()` must copy sub-packets into `netdev_alloc_skb_ip_align()` SKBs (never `skb_clone()`). Never use `% dev->maxpacket` in `bind`; `ax88178_change_mtu()` rejects `ll_mtu % dev->maxpacket == 0` with `-EDOM`, calls `ax88178_set_mfb()` if `rx_urb_size` grows, and calls `usbnet_update_max_qlen()`. [F95, F117, F170, F173, F186]
- With `NETIF_F_SG`, `ax88179_tx_fixup()` (always) and `aqc111_tx_fixup()` (if `!dev->can_dma_sg`) must call `skb_linearize()`. `asix_tx_fixup()` frames in-place only if `!skb_header_cloned(skb)`, `!(padlen && skb_cloned(skb))`, and `headroom + tailroom >= 4 + padlen`. Shifting `skb->data` in `tx_fixup` must use `memmove()` and `skb_set_tail_pointer()`. [F128, F174, F175]
- Check `asix_read_phy_addr() < 0` in signed `int`, and set `priv->mdio->phy_mask = ~(BIT(priv->phy_addr & 0x1f) | BIT(AX_EMBD_PHY_ADDR))` in `ax88772_init_mdio()`. In `ax88772_init_phy()`, set `mac_managed_pm = true` and `phy_suspend()` on `phydev`/`phydev_int`, disconnecting `phylink` under `rtnl_lock()` on error. Non-`asix_common_private` drivers (`ax88172a`) must call `asix_rx_fixup_internal()` directly. In `pegasus.c`, check `mii_phy_probe() == 0xff`, and in `pegasus_siocdevprivate()` check `capable(CAP_NET_ADMIN)` on `SIOCDEVPRIVATE + 2` and mask `data[1] & 0x1f`. [F39, F41, F96, F116, F126, F136, F177]
- In `ax88179_178a.c`, bracket PM commands with `ax88179_set_pm_mode(dev, true/false)`, and pass `>= size`B buffers to `ax88179_read`/`write_cmd*()` (which byte-swap `u16`/`u32` in place) or use `__ax88179_read_cmd()`. `nc_vendor`/`register_read()` return `0` and byte-swap `*retval_ptr` in place. `aqc111_bind()` requires config 1 and gates `SPEED_2500`/`5000` on `USB_SPEED_SUPER`. Gate `HIF_REG_PAUSE_THRESHOLD` and 32B regs on `mcs7830_get_rev(dev) == 2`. `ch9200.c` uses 2B control transfers at MII `loc * 2`. [F40, F123, F149, F150, F151, F155]

## Error Handling

- `aqc111_read_cmd*()` and `mcs7830_get_reg()` convert `0 <= ret < size` to `-ENODATA` (`aqc111` logging `ret` first), and `ch9200.c:control_read()` converts `0 <= err < size` to `-EINVAL`; callers must check `< 0`. Callers of `ax88179_read_cmd()` with `size != 2 && size != 4` must zero `data` or check errors; `usb_bulk_msg()` callers (`kalmia`, `cx82310_cmd`) must check `ret == 0` before reading `act_len`; `aqc111_suspend()` must `memset(&wol_cfg, 0, sizeof(wol_cfg))`. [F34, F36, F37, F38, F48, F49]
- `huawei_cdc_ncm_suspend()`/`resume()` must roll back the first layer if the second fails. `asix_suspend()`/`resume()` must check `priv` and `priv->suspend`/`resume` for non-NULL. `ax88179_disconnect()` sets `ax179_data->disconnecting = 1` before `usbnet_disconnect()` to suppress `-ENODEV` warnings in `__ax88179_read`/`write_cmd()`. [F9, F43, F180]

## Known Pitfalls

- On `continue` in `aqc111_rx_fixup()`, advance both `skb_pull(skb, pkt_len_with_padd)` and `pkt_desc_ptr++`. In `ax88179_rx_fixup()`, `pkt_len == 0` continues without pulling, whereas dropped non-zero packets must call `skb_pull(skb, pkt_len_plus_padd)`. In `vl600_rx_fixup()`, when the last packet (`count == 0`) comes from `s->current_rx_buf`, call `usbnet_skb_return()`, NULL `current_rx_buf`, and return `0`. [F99, F100, F108]
- In `asix`/`ax88179_*_eeprom()`, check `eeprom->len != 0`, use `first_word = offset >> 1` and `last_word = (offset + len - 1) >> 1` (`last_word - first_word + 1` words), index `eeprom_buff[i - first_word]`, and pre-read odd boundary words in `set_eeprom`. [F84, F111, F118]
- Cast `AQ_TX_DESC_MSS`/`VLAN_MASK` values to `u64` before shifting by `0x20`/`0x30` in `aqc111_tx_fixup()`. Keep `msleep(500)`/`msleep(200)` in `ax88179_reset()` and use `unsigned long` with `time_after()` for `jiffies` deadlines. In `kaweth_probe()`, download firmware only if `!(le16_to_cpu(udev->descriptor.bcdDevice) >> 8)`, then free buffers/netdev and return `-EIO`. [F115, F119, F139, F145]
