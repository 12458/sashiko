# READ-COPY UPDATE (RCU) — (top level) (part 2)

This component implements core extensions to Tree RCU (`tree_nocb.h`, `tree_plugin.h`, `tree_stall.h`), generic RCU update and lockdep primitives (`update.c`), and the Rust RCU read-side lock guard (`rust/kernel/sync/rcu.rs`).

## Architecture & Data Flow

- Manipulate NOCB GP kthread state (`nocb_gp_lock`, `nocb_defer_wakeup`, `nocb_timer`, `nocb_gp_sleep`, `nocb_gp_wq`, `nocb_head_rdp`, `nocb_toggling_rdp`) only on the group leader `rdp->nocb_gp_rdp`, never on a per-CPU `rdp`. Whenever `timer_delete(&rdp_gp->nocb_timer)` runs in `__wake_nocb_gp()` or `nocb_gp_wait()`, reset `rdp_gp->nocb_defer_wakeup = RCU_NOCB_WAKE_NOT` under `rdp_gp->nocb_gp_lock`. [F54, F55]
- `rdp->cblist.len` counts both `rdp->cblist` and `rdp->nocb_bypass`: call `rcu_segcblist_inc_len(&rdp->cblist)` when enqueuing a new callback in `rcu_nocb_try_bypass()` or `rcu_nocb_do_flush_bypass()`, and never add count again on bypass flush. `rdp->lazy_len` counts only lazy callbacks in `nocb_bypass`, so `rcu_nocb_do_flush_bypass()` must enqueue a new lazy `rhp` onto `nocb_bypass` and set `rhp = NULL` before `rcu_cblist_flush_enqueue()` and zeroing `rdp->lazy_len`. [F56, F57]
- In `nocb_gp_wait()`, update `wait_gp_seq = cur_gp_seq` whenever `!needwait_gp || ULONG_CMP_LT(cur_gp_seq, wait_gp_seq)` before `needwait_gp = true`, and after scanning `my_rdp->nocb_head_rdp`, schedule `RCU_NOCB_WAKE_LAZY` only when `lazy && !bypass` (else `RCU_NOCB_WAKE_BYPASS` if `bypass`). Index `rnp->nocb_gp_wq` in `rcu_nocb_gp_get()` and `nocb_gp_wait()` via `rcu_seq_ctr(...) & 0x1`. [F82, F83, F94]
- `rcu_init_nohz()` must mask `rcu_nocb_mask` with `cpu_possible_mask` via `cpumask_and()` before indexing per-CPU `rcu_data`. In `rcu_organize_nocb_kthreads()`, compute the next GP kthread CPU threshold as `nl = DIV_ROUND_UP(rdp->cpu + 1, ls) * ls`. [F71, F96]
- Call `rcu_preempt_check_blocked_tasks()` under `rnp->lock` before advancing `rnp->gp_seq`, verifying `!rnp->gp_tasks` and setting `rnp->gp_tasks = rnp->blkd_tasks.next` if `rcu_preempt_has_tasks(rnp) && (rnp->qsmaskinit || rnp->wait_blkd_tasks)`. In `rcu_preempt_ctxt_queue()`, insert `t->rcu_node_entry` after `rnp->exp_tasks` / `rnp->gp_tasks` only when `RCU_EXP_TASKS` / `RCU_GP_TASKS` is set in `blkd_state`, then initialize `gp_tasks` / `exp_tasks` to `&t->rcu_node_entry` if NULL when `RCU_GP_BLKD` / `RCU_EXP_BLKD` is set. [F62, F86]
- To walk tasks blocking the current normal GP in `rcu_print_detail_task_stall_rnp()` and `rcu_print_task_stall()`, hold `rnp->lock`, check `rcu_preempt_blocked_readers_cgp(rnp)`, seed `t = list_entry(rnp->gp_tasks->prev, struct task_struct, rcu_node_entry)`, and use `list_for_each_entry_continue()`. When `rcu_preempt_deferred_qs_handler()` runs while `rcu_preempt_depth() > 0` (or in `rcu_preempt_deferred_qs_irqrestore()`), reset `rdp->defer_qs_iw_pending` from `DEFER_QS_PENDING` to `DEFER_QS_IDLE`. [F61, F88]
- `rcu_cpu_stall_reset()` must set `rcu_state.nr_fqs_jiffies_stall = 3` and `rcu_state.jiffies_stall = ULONG_MAX`, and `record_gp_stall_check_time()` must reset `nr_fqs_jiffies_stall = 0`. In `check_cpu_stall()`, the `cmpxchg()` offset added to `jiffies` for `jiffies_stall` must not exceed `ULONG_MAX / 2`. [F63, F99]
- In `print_cpu_stat_info()`, use `rdp->snap_record` only if `rsrp->gp_seq == rdp->gp_seq`, and sum `kstat_cpu_irqs_sum(cpu)` and `arch_irq_stat_cpu(cpu)` against `rsrp->nr_hardirqs`. `gp_state_names[]` in `tree_stall.h` must match all `RCU_GP_*` states in `tree.h`. In `rcu_bootup_announce_oddness()`, clamp `nohz_full_patience_delay` to `[0, 5 * MSEC_PER_SEC]` before `msecs_to_jiffies()`. [F64, F68, F72]
- `rcu_async_hurry_nesting` and `rcu_expedited_nesting` start at `1` until `rcu_end_inkernel_boot()`; pair every `rcu_async_hurry()` / `rcu_expedite_gp()` 1-to-1 with `rcu_async_relax()` / `rcu_unexpedite_gp()`. `rcu_gp_is_normal()` must return false during `RCU_SCHEDULER_INIT`, and `rcu_nocb_try_bypass()` must reject bypass queuing whenever `rcu_scheduler_active != RCU_SCHEDULER_RUNNING`. Both `#ifdef` and `#else` stubs of `rcu_print_task_stall()`, `rcu_initiate_boost()`, and `rcu_nocb_unlock_irqrestore()` must unlock `rnp->lock` and/or restore `flags` identically. [F16, F66, F91]

## Synchronization

- `__wake_nocb_gp()` and `do_nocb_deferred_wakeup_common()` consume caller-held `rdp_gp->nocb_gp_lock` (and `flags`) and must unlock via `raw_spin_unlock_irqrestore(&rdp_gp->nocb_gp_lock, flags)` on all paths (before `swake_up_one(&rdp_gp->nocb_gp_wq)` in `__wake_nocb_gp()`). `__call_rcu_nocb_wake()` consumes `rdp->nocb_lock` and must call `rcu_nocb_unlock(rdp)` on every branch (and `lazy_rcu_shrink_scan()` must unlock `rdp->nocb_lock`) before `wake_nocb_gp()` / `wake_nocb_gp_defer()`; in `__call_rcu_nocb_wake()`, when `was_alldone` is true for non-lazy callbacks, call `wake_nocb_gp(rdp, false)` only if `!irqs_disabled_flags(flags)`, else `wake_nocb_gp_defer(rdp, RCU_NOCB_WAKE, ...)`. [F1, F4, F28, F113]
- `rdp->nocb_bypass_lock` nests inside `rdp->nocb_lock`; `rcu_nocb_do_flush_bypass()` requires both held with hard IRQs disabled and releases `nocb_bypass_lock`. In `nocb_gp_wait()` and `nocb_cb_wait()`, lock `rdp->nocb_lock` before `rnp->lock`, and unlock both before `swake_up_one(&rdp->nocb_cb_wq)` or `rcu_gp_kthread_wake()`. In `nocb_cb_wait()`, run `rcu_do_batch(rdp)` with `local_bh_disable()` and hard IRQs enabled. Calling `rcu_rdp_is_offloaded(rdp)` (or `rcu_nocb_lock` / `unlock`) requires holding `barrier_mutex`, `cpus_read_lock`, `rdp->nocb_lock`, or `nocb_mutex`, or running on `rdp`'s CPU with preemption/softirq disabled, or on `rdp->nocb_cb_kthread` / `nocb_gp_kthread`. [F23, F29, F114, F117]
- Toggling NOCB offload must synchronize `SEGCBLIST_OFFLOADED` on `rdp->cblist`, `rdp->nocb_entry_rdp` in `rdp_gp->nocb_head_rdp` (under `raw_spin_lock_irqsave(&rdp->nocb_lock, flags)` in `nocb_gp_toggle_rdp()` and the offload/deoffload wait conditions), and `rcu_nocb_mask` (under `rcu_state.nocb_mutex`). When `rdp_gp->nocb_gp_kthread` exists, only `nocb_gp_wait()` via `nocb_gp_toggle_rdp()` may modify `nocb_head_rdp` while `rcu_nocb_rdp_offload()` / `deoffload()` queue `rdp` in `rdp_gp->nocb_toggling_rdp` and wait on `rdp->nocb_state_wq`. `rcu_nocb_cpu_deoffload()` and `rcu_nocb_cpu_offload()` must acquire `cpus_read_lock()` before `mutex_lock(&rcu_state.nocb_mutex)` and verify `!cpu_online(cpu)` under both. In `lazy_rcu_shrink_count()` and `lazy_rcu_shrink_scan()`, acquire `nocb_mutex` via `mutex_trylock()`, and recheck `READ_ONCE(rdp->lazy_len)` under `rcu_nocb_lock_irqsave()`. [F25, F26, F30, F58, F84]
- `rcu_preempt_ctxt_queue()` consumes caller-held `rnp->lock` (IRQs disabled) and unlocks via `raw_spin_unlock_rcu_node(rnp)` leaving hard IRQs disabled. `rcu_initiate_boost()` consumes `rnp->lock` and `flags` and unlocks via `raw_spin_unlock_irqrestore_rcu_node(rnp, flags)` on all paths. In `rcu_boost()`, recheck `rnp->exp_tasks` / `boost_tasks` and call `rt_mutex_init_proxy_locked(&rnp->boost_mtx.rtmutex, t)` under `rnp->lock`, then unlock with IRQs restored before `rt_mutex_lock(&rnp->boost_mtx)`. In `rcu_preempt_deferred_qs_irqrestore()`, snapshot `rt_mutex_owner(&rnp->boost_mtx.rtmutex) == t` and `sync_rcu_exp_done(rnp)` under `rnp->lock` before unlocking or calling `rcu_report_unblock_qs_rnp()` / `rt_mutex_futex_unlock()`. [F9, F12, F31, F60]
- In `__rcu_read_unlock()`, place a compiler `barrier()` before `rcu_preempt_read_exit()`, and when it returns `0`, another `barrier()` before `READ_ONCE(t->rcu_read_unlock_special.s)`. In `rcu_read_unlock_special()`, return immediately if `in_nmi()`; when preemption/BH/IRQs are disabled, call `raise_softirq_irqoff(RCU_SOFTIRQ)` only if `use_softirq && (in_hardirq() || (needs_exp && !irqs_were_disabled))` (else set resched flags), and queue `rdp->defer_qs_iw` only when `irqs_were_disabled && needs_exp`, `cpu_online(rdp->cpu)`, and `rdp->defer_qs_iw_pending != DEFER_QS_PENDING`. [F37, F109, F110, F111]
- `rcu_note_context_switch()`, `rcu_flavor_sched_clock_irq()`, `rcu_cpu_stall_reset()`, `check_cpu_stall()`, `print_cpu_stall()`, and `print_other_cpu_stall()` require hard IRQs disabled; `rcu_qs()` requires preemption disabled. In `rcu_all_qs()` and `!CONFIG_PREEMPT_RCU` `rcu_note_context_switch()`, read `this_cpu_ptr(&rcu_data.rcu_urgent_qs)` with `smp_load_acquire()` before `rcu_need_heavy_qs`; in `!CONFIG_PREEMPT_RCU`, `rcu_all_qs()` must wrap `rcu_qs()` in `preempt_disable()` and `rcu_momentary_eqs()` in `local_irq_save()`, and `rcu_read_unlock_strict()` must return if `irqs_disabled() || in_atomic_preempt_off() || !rcu_state.gp_kthread`. [F38, F121, F122, F123, F128]
- In `record_gp_stall_check_time()`, order `WRITE_ONCE(rcu_state.gp_start, j)` before `WRITE_ONCE(rcu_state.jiffies_stall, j + j1)` with `smp_mb()`, pairing with `smp_rmb()`-separated reads and `gs1 != gs2` in `check_cpu_stall()`. In `rcu_check_gp_kthread_expired_fqs_timer()`, load `rcu_state.gp_state` with `smp_load_acquire()` before `READ_ONCE(rcu_state.jiffies_force_qs)`. In `rcu_print_task_stall()`, pin tasks with `get_task_struct(t)` under `rnp->lock` and unlock before `task_call_func(t, check_slow_task, &rscr)` and `put_task_struct(t)`. In `rcu_check_gp_start_stall()`, lock leaf `rnp->lock` before `rnp_root->lock` and unlock both (`rnp_root->lock` first) before `show_rcu_gp_kthreads()`. [F33, F34, F35, F36]

## Object Lifetimes

- In `nocb_gp_wait()`, clear `my_rdp->nocb_toggling_rdp = NULL` under `my_rdp->nocb_gp_lock` before `nocb_gp_toggle_rdp()` and waking `rdp_toggling->nocb_state_wq`. `rcu_nocb_rdp_deoffload()` must run `rcu_barrier()` and `kthread_park(rdp->nocb_cb_kthread)` before clearing `SEGCBLIST_OFFLOADED`, `nocb_cb_wait()` must call `kthread_parkme()` only when `rdp->nocb_cb_sleep` is true (with `rcu_segcblist_n_cbs(&rdp->cblist) == 0` under `rcu_nocb_lock_irqsave`), and `rcu_nocb_rdp_offload()` must wait for `SEGCBLIST_OFFLOADED` before `kthread_unpark(rdp->nocb_cb_kthread)`. [F6, F7, F21]
- When removing `t` from `rnp->blkd_tasks` in `rcu_preempt_deferred_qs_irqrestore()`, under `rnp->lock` compute `np = rcu_next_node_entry(t, rnp)`, unlink `t->rcu_node_entry`, clear `t->rcu_blocked_node = NULL`, and advance any of `rnp->gp_tasks`, `exp_tasks`, or `boost_tasks` matching `&t->rcu_node_entry` to `np`. Initialize `rdp->defer_qs_iw` only once at boot in `rcu_preempt_deferred_qs_init()`, never in `rcu_read_unlock_special()`. [F10, F18]
- In `__wait_rcu_gp()`, both loops must apply identical `checktiny && crcu_array[i] == call_rcu` and deduplication checks so each active on-stack `rs_array[i]` runs `init_rcu_head_on_stack()` and `init_completion()` before `crcu_array[i](&rs_array[i].head, wakeme_after_rcu)`, and `destroy_rcu_head_on_stack()` only after `wait_for_completion_state()`. Pair `printk_deferred_enter()` / `exit()` on every leaf iteration in `rcu_dump_cpu_stacks()`, and bracket `print_other_cpu_stall()` / `print_cpu_stall()` output with `nbcon_cpu_emergency_enter()` / `exit()` before `panic_on_rcu_stall()`. `kernel::sync::rcu::Guard` must stay `!Send` (`NotThreadSafe`), calling `rcu_read_lock()` only in `Guard::new()` and `rcu_read_unlock()` only in `Drop::drop()`. [F17, F67, F131, F139, F140]

## API Contracts

- When `rcu_nocb_try_bypass()` returns `false`, it has not enqueued `rhp`, sets `*was_alldone = !rcu_segcblist_pend_cbs(&rdp->cblist)`, and holds `rdp->nocb_lock` (if offloaded); when `true`, `rhp` is enqueued and `nocb_lock` is unlocked. `rcu_nocb_do_flush_bypass()` / `rcu_nocb_flush_bypass()` always return `true` when `rhp_in` is `NULL`, and `false` only when `rhp_in` is non-NULL and `rdp->nocb_bypass` was empty (caller must enqueue `rhp_in` onto `rdp->cblist`). [F3, F41, F42]
- `rcu_read_lock_held_common(bool *ret)` checks `rcu_is_watching()` and `rcu_lockdep_current_cpu_online()` before callers query `rcu_lock_map` / `rcu_bh_lock_map` / `rcu_sched_lock_map`, setting `*ret = false` and returning `true` when not watching/online; callers must not read `*ret` when it returns `false`. `debug_lockdep_rcu_enabled()` must be `noinstr` and `notrace` and return false when `rcu_scheduler_active == RCU_SCHEDULER_INACTIVE`, `!READ_ONCE(debug_locks)`, or `current->lockdep_recursion != 0`. [F47, F129, F142]
- `rcu_check_boost_fail()` takes a nullable `cpup` (if non-NULL and returning `false`, sets `*cpup` to first holdout CPU or `-1`). `rcu_is_gp_kthread_starving()` and `rcu_is_rcuc_kthread_starving()` take a nullable `unsigned long *jp`, and `rcu_is_rcuc_kthread_starving()` writes `*jp` only when returning `true` (in `print_cpu_stall_info()`, format `buf` with `snprintf(buf, sizeof(buf), ...)` and read `j` and `buf` only when `rcuc_starved` is true). `wakeme_after_rcu()` requires a `struct rcu_head *` embedded as `head` in `struct rcu_synchronize`. `rcu_stall_chain_notifier_register()` gates on `rcu_cpu_stall_notifiers` (returning `-EEXIST` if 0), and `rcu_stall_notifier_call_chain()` passes the jiffies stall duration cast to `void *`. [F49, F50, F100, F103, F143]

## Error Handling

- Check `kthread_run()` / `kthread_create()` with `IS_ERR()` before assigning `rdp_gp->nocb_gp_kthread`, `rdp->nocb_cb_kthread`, or `rnp->boost_kthread_task`; on failure in `rcu_spawn_cpu_nocb_kthread()`, lock `rcu_state.nocb_mutex` and if offloaded call `rcu_nocb_rdp_deoffload(rdp)` and `cpumask_clear_cpu(cpu, rcu_nocb_mask)`. Check `rdp->nocb_gp_rdp` for `NULL` in `do_nocb_deferred_wakeup()` and `rcu_nocb_rdp_offload()` (also checking `rdp->nocb_gp_kthread`). In `rcu_nocb_rdp_deoffload()`, check `rdp->nocb_cb_kthread` and `rdp_gp->nocb_gp_kthread` for `NULL`, directly clearing `SEGCBLIST_OFFLOADED` and `list_del(&rdp->nocb_entry_rdp)` if `nocb_gp_kthread` is `NULL`. Check `rcu_state.gp_kthread` for `NULL` in early-boot/stall/strict-GP paths. [F8, F39, F40, F44, F45, F52]
- `lazy_rcu_shrink_count()` and `lazy_rcu_shrink_scan()` return `0` when `!cpumask_available(rcu_nocb_mask)` or `!mutex_trylock(&rcu_state.nocb_mutex)`, but when a scan finishes with `count == 0` they must return `SHRINK_EMPTY` and `SHRINK_STOP` respectively. In `rcu_print_task_stall()`, read `rscr` only when `task_call_func(t, check_slow_task, &rscr)` returns `0`. In `check_cpu_stall()`, check `kvm_check_and_clear_guest_paused()` after winning `cmpxchg()` before incrementing `rcu_stall_count`, calling notifiers, or printing. `panic_on_rcu_stall()` must call `scx_rcu_cpu_stall()` and return early if it succeeds before incrementing `cpu_stall` or calling `panic()`. [F43, F48, F137, F138]

## External Contracts

- `rcu_jiffies_till_stall_check()` clamps `rcu_cpu_stall_timeout` (seconds) to `[3, 300]`, writes it back, and returns `till_stall_check * HZ + RCU_STALL_DELAY_DELTA`. `rcu_exp_jiffies_till_stall_check()` treats `rcu_exp_cpu_stall_timeout` as ms (defaulting to `jiffies_to_msecs(rcu_jiffies_till_stall_check())` when `0`), clamps `msecs_to_jiffies()` to `[2UL, 300UL * HZ]`, writes back `jiffies_to_msecs()` if changed, and returns jiffies. [F135, F136]

## Known Pitfalls

- In `wake_nocb_gp_defer()`, `RCU_NOCB_WAKE_LAZY` (2) arms `nocb_timer` only when `nocb_defer_wakeup == RCU_NOCB_WAKE_NOT`, whereas `RCU_NOCB_WAKE_BYPASS` (1) unconditionally overrides any deferral and higher wake types upgrade when `nocb_defer_wakeup < waketype`. Check `cpumask_available(rcu_nocb_mask)` before accessing `rcu_nocb_mask` unless `rcu_state.nocb_is_setup` is guaranteed. In `rcu_nocb_try_bypass()`, check `ULONG_CMP_LT(rdp->nocb_nobypass_count, nocb_nobypass_lim_per_jiffy)` for underflow before comparing `c > nocb_nobypass_lim_per_jiffy`. Guard all `pr_alert()` / `pr_cont()` in `rcu_organize_nocb_kthreads()` with `dump_tree`. [F81, F85, F97, F106]
- In `rcu_print_task_stall()`, iterate `ts[0..i-1]` with `while (i) { t = ts[--i]; ... }` so `ts[0]` is not skipped. `union rcu_special` subfields `b.{blocked,need_qs,exp_hint}` index 2-char literals and alias `u32 s`, so they must only hold `0` or `1` and clearing `.s = 0` clears all of them. Use `1UL << (cpu - rnp->grplo)` or `leaf_node_cpu_bit(rnp, cpu)` (never 32-bit `1 << ...`) for `rnp->qsmask` / `expmask`, and `div_u64()` (never `/`) for `u64` cputime deltas in `print_cpu_stat_info()`. [F76, F78, F92, F95]
