# BTRFS FILE SYSTEM — fs/btrfs (part 2)

Implements Btrfs copy-on-write B-tree operations, transparent data compression/decompression workspace and bio management, file and B-tree defragmentation, delalloc space reservation, and delayed metadata updates (delayed inode items and delayed extent references).

## Architecture & Data Flow

- `btrfs_path` arrays (`nodes`, `slots`, `locks`) are indexed by `0 .. BTRFS_MAX_LEVEL - 1` (0 is leaf); parent access at `level + 1` requires `level < BTRFS_MAX_LEVEL - 1`. Whenever slot 0's key changes (`btrfs_set_item_key_safe`, `btrfs_truncate_item`, `setup_items_for_insert`, `btrfs_del_ptr`, `btrfs_del_items`, `__push_leaf_left`, `split_leaf`), call `fixup_low_keys()` before `btrfs_unlock_up_safe()`. [F71, F92]
- Leaf item data grows downward from `BTRFS_LEAF_DATA_SIZE(fs_info)` toward headers: for `start <= end`, the range starts at `btrfs_item_offset(leaf, end)` with length `btrfs_item_data_end(leaf, start) - btrfs_item_offset(leaf, end)`. Sibling moves (`push_node_left`, `balance_node_right`, `push_leaf_right`, `push_leaf_left`) must call `check_sibling_keys(left, right)` first and abort with `-EUCLEAN` if `left`'s last key `>=` `right`'s first key. [F84, F86]
- In-memory `root->root_item`, `delayed_node->inode_item`, and `delayed_item->data`'s `btrfs_dir_item` are little-endian (`btrfs_stack_*`/`btrfs_root_*` or `cpu_to_le*`). `btrfs_insert_delayed_dir_index()` stores the un-NUL-terminated name at `(char *)(dir_item + 1)`; bound it by `name_len` (`%.*s` or `btrfs_stack_dir_name_len`). [F100, F142]
- All xarray ops on `delayed_refs->head_refs` and `dirty_extents` must index by `bytenr >> fs_info->sectorsize_bits`, and on 32-bit `add_delayed_ref_head()` must reject `bytenr >= MAX_LFS_FILESIZE` with `-EOVERFLOW` (releasing any reserved `dirty_extents` slot). `tree_ref`/`data_ref` is discriminated by `node->type` (`BTRFS_EXTENT_DATA_REF_KEY` or `BTRFS_SHARED_DATA_REF_KEY` for `data_ref`) in `btrfs_delayed_ref_node`, and by `ref->type` (`BTRFS_REF_DATA` vs `BTRFS_REF_METADATA`) in `btrfs_ref`. [F53, F81, F158]
- A `btrfs_delayed_ref_node` in `head->ref_tree` must be linked on `ref_add_list` iff `action == BTRFS_ADD_DELAYED_REF`, including when `insert_delayed_ref()` flips `exist->action` or `drop_delayed_ref()` removes it. Under `delayed_refs->lock`, `num_heads` counts `head_refs` with `tracked == true` and `num_heads_ready` counts tracked heads with `processing == false` (`btrfs_delete_ref_head()` decrements `num_heads_ready` only if `!head->processing`). [F62, F64]
- For data ref heads (`is_data`), adjust `delayed_refs->pending_csums` and csum leaf reservations (`trans->delayed_ref_csum_deletions` or `btrfs_delayed_refs_rsv_release()`) when `add_delayed_ref_head()` inserts with `ref_mod < 0` or `update_existing_head_ref()` flips `total_ref_mod` across zero. `btrfs_update_delayed_refs_rsv()` must zero `trans->delayed_ref_updates` and `delayed_ref_csum_deletions` after updating `delayed_refs_rsv`. [F63, F65]
- Every change to `btrfs_delayed_node::count` (`ins_root`/`del_root`, `BTRFS_DELAYED_NODE_INODE_DIRTY`, `BTRFS_DELAYED_NODE_DEL_IREF`) must update `delayed_root->items` (calling `finish_one_item()` on decrement). In `btrfs_insert_delayed_item()`, check the post-batching `next` (`NULL` iff all `ins_root` items were batched) to release `node->index_item_leaves` (skipping partial-batch decrements if `continuous_keys_only`) before reusing `next` in `list_for_each_entry_safe`. [F67, F68, F115]
- In `struct compressed_bio`, `bbio` must be the last member, and the union holds `orig_bbio` only on reads and `write_end_work` only on writes. `btrfs_alloc/free_compr_folio()` must bypass `compr_pool` if `fs_info->block_min_order > 0` or `folio_order(folio) > 0`. [F56, F164]

## Synchronization

- `should_cow_block()` must run `smp_mb__before_atomic()` before testing `BTRFS_ROOT_FORCE_COW`. Replacements of `root->node` (`btrfs_force_cow_block`, `balance_level`, `insert_new_root`) must log the root replacement, increment `cow->refs`, and use `rcu_assign_pointer(root->node, cow)` before dropping `buf`'s ref; `btrfs_root_node()` must read `root->node` under `rcu_read_lock()` with `refcount_inc_not_zero(&eb->refs)` and call `synchronize_rcu()` before retrying. [F21, F22, F156]
- In `btrfs_search_slot()` and `setup_nodes_for_search()`, if `level` needs a write lock at `level` or `level + 1` and `write_lock_level` is lower, raise `write_lock_level`, call `btrfs_release_path(p)`, and restart. When `!p->skip_locking`, call `btrfs_maybe_reset_lockdep_class(root, eb)` before locking a child; if `read_block_for_search()` reads from disk with `!p->skip_locking`, unlock above `parent_level`, read-lock `tmp`, call `btrfs_release_path(p)` before `btrfs_read_extent_buffer()`, and return `-EAGAIN`. [F23, F25, F147]
- In `btrfs_next_old_leaf()`, unlock and free levels `0 .. level - 1` before reading/locking the next child at `level - 1`, and if `time_seq != 0` and `btrfs_try_tree_read_lock(next)` fails, release path and retry. When `path->need_commit_sem` is set, `btrfs_next_old_leaf()` must clear it before `btrfs_search_slot()` under `commit_root_sem` and restore it after, and both functions must call `finish_need_commit_sem_search(path)` before `up_read(&fs_info->commit_root_sem)`. [F27, F74, F155]
- Release any locked `btrfs_path` before calling `btrfs_release_delayed_node()` or `btrfs_release_prepared_delayed_node()`, as `delayed_node->mutex` ranks outside B-tree locks. In `btrfs_defrag_leaves()`, call `btrfs_realloc_node()` on `path->nodes[1]` before `btrfs_find_next_key()`, which can release `path` and re-search with `cow = 0`. [F29, F113]
- `btrfs_get_or_create_delayed_node()` must `xa_reserve(&root->delayed_nodes, ino, GFP_NOFS)` before `xa_lock`, using `GFP_ATOMIC` for `__xa_store()` and `btrfs_delayed_node_ref_tracker_alloc()` under the lock. When `btrfs_get_delayed_node()` finds an uncached node in `root->delayed_nodes`, use `refcount_inc_not_zero(&node->refs)` under `xa_lock` and take two refs (for `btrfs_inode->delayed_node` and caller). [F12, F145]
- `btrfs_insert_delayed_dir_index()` must hold `delayed_node->mutex` across `__btrfs_add_delayed_item()`, `btrfs_delayed_item_reserve_metadata()`, and updating `index_item_leaves`. `btrfs_log_get/put_delayed_items()` require `node->mutex` for `item->logged` and `item->log_list` (checking `!item->logged && list_empty(&item->log_list)`). When `btrfs_readdir_get_delayed_items()` returns `true`, it upgraded the dir lock to exclusive, requiring `btrfs_readdir_put_delayed_items()` on all exits to `downgrade_write(&inode->vfs_inode.i_rwsem)`. [F13, F30, F32]
- `add_delayed_ref()` must `xa_reserve()` in `head_refs` (and `dirty_extents` if qgroup active) with `GFP_NOFS` before `delayed_refs->lock`, holding `delayed_refs->lock` across `add_delayed_ref_head()` and `insert_delayed_ref()`. When `btrfs_delayed_refs_rsv_refill()` drops `block_rsv->lock` for `btrfs_reserve_metadata_bytes()`, re-check `block_rsv->reserved < block_rsv->size` after relocking and free excess. `btrfs_delalloc_reserve_metadata()` must use `BTRFS_RESERVE_NO_FLUSH` if `noflush || btrfs_is_free_space_inode(inode)`, and `BTRFS_RESERVE_FLUSH_LIMIT` if `current->journal_info`. [F33, F36, F152]
- When `btrfs_delayed_ref_lock()` drops `delayed_refs->lock` to lock `head->mutex`, pin `head->refs` first and re-check `head->tracked` after relocking `delayed_refs->lock` (unlocking `head->mutex` if false). Release `btrfs_select_ref_head()` via `btrfs_unselect_ref_head()` or `btrfs_delete_ref_head()`. `btrfs_delete_ref_head()` requires `delayed_refs->lock` and `head->lock`; `btrfs_select_delayed_ref()` requires `head->mutex` and `head->lock`. [F17, F34, F35]
- `defrag_one_range()` must lock folios via `defrag_prepare_one_folio()` (setting failed `folios[i] = NULL`) and `folio_wait_writeback()` before `btrfs_lock_extent()`, then re-run `defrag_collect_targets(..., locked = true)` and skip `EXTENT_DELALLOC` ranges before `defrag_one_locked_target()`; teardown must `btrfs_unlock_extent()` before unlocking/putting folios. Whenever `defrag_prepare_one_folio()` unlocks a folio for ordered extents or read, re-verify `folio->mapping == mapping && folio->private` after relocking. [F18, F19, F39]
- `btrfs_submit_compressed_write()` must initialize all `compressed_bio` fields and call `btrfs_add_compressed_bio_folios()` before `btrfs_submit_bbio()`. In `add_ra_bio_pages()`, after inserting a folio, lock the range in `io_tree`, verify under `read_lock(&em_tree->lock)` that the extent map still matches `bi_sector`, and if `sectorsize < PAGE_SIZE` call `btrfs_folio_set_lock()` before putting the folio. [F40, F41, F162]

## Object Lifetimes

- Call `btrfs_clear_buffer_dirty()` before `btrfs_free_tree_block()` on a dirtied block (`insert_new_root`, `balance_level`, `btrfs_del_items`). In `btrfs_del_leaf()`, after `btrfs_del_ptr()` and `btrfs_unlock_up_safe(path, 0)`, take `refcount_inc(&leaf->refs)` before `btrfs_free_tree_block()` and `free_extent_buffer_stale(leaf)` so `path->nodes[0]` stays valid until `btrfs_release_path()`. [F1, F5]
- `btrfs_submit_compressed_read()` consumes `bbio`: on error before `btrfs_submit_bbio()`, call `kfree(cb->compressed_folios)`, `bio_put(&cb->bbio.bio)`, and `btrfs_bio_end_io(bbio, status)`. `btrfs_submit_compressed_write()` transfers ownership of `compressed_folios` to `cb`; in `btrfs_finish_compressed_write_work()`, `btrfs_finish_ordered_extent()` must precede `end_compressed_writeback()`, and `cb->bbio.inode` must never be accessed after `end_compressed_writeback()` (or after `btrfs_finish_ordered_extent()` if `!cb->writeback`). [F6, F7, F161]
- Read-only delayed-item helpers (`btrfs_readdir_get_delayed_items`, `btrfs_log_get/put_delayed_items`) must drop `node` via `btrfs_delayed_node_ref_tracker_free()` and `refcount_dec(&node->refs)`, not `btrfs_release_delayed_node()`. When iterating `delayed_root->node_list`, call `btrfs_next_delayed_node(curr, ...)` before `btrfs_release_delayed_node(curr, ...)`, using `delayed_root->node_list.next` if `BTRFS_DELAYED_NODE_IN_LIST` is clear. [F14, F114]
- `add_delayed_ref_head()` frees `head_ref` if already in `head_refs` and frees `qrecord` only when `btrfs_qgroup_trace_extent_nolock() > 0` (leaving `qrecord` for `add_delayed_ref()` to `kfree()` on `< 0`). `insert_delayed_ref()` returns `true` when `node` was merged so `add_delayed_ref()` frees `node` after tracepoints run. [F16]

## API Contracts

- On success, `btrfs_force_cow_block()` (and `btrfs_cow_block()` when it COWs) consumes `buf` via `free_extent_buffer_stale(buf)`, unlocks `buf` if `*cow_ret == buf`, and returns the new write-locked buffer in `*cow_ret`; on error, `buf` remains locked and referenced by the caller. [F2]
- `btrfs_search_slot()` and `btrfs_search_old_slot()` require `p->nodes[0] == NULL` on entry, and `btrfs_search_slot()` calls `btrfs_release_path(p)` on `< 0` error unless `p->skip_release_on_error`. In `btrfs_search_slot()`, `cow` must be non-zero if `ins_len != 0`, `ins_len > 0` must include `sizeof(struct btrfs_item)` unless `p->search_for_extension`, `p->search_commit_root` requires `p->skip_locking = 1` (`p->need_commit_sem` requires `search_commit_root`), and `p->nowait` requires `!cow && !time_seq` (using trylocks and returning `-EAGAIN`). [F3, F45, F46, F138, F154]
- `memmove/copy_leaf_data()` take offsets relative to `btrfs_item_nr_offset(leaf, 0)` (`btrfs_item_offset`, `leaf_data_end`), whereas `read/write/memcpy/memmove_extent_buffer()` take full extent-buffer offsets (`btrfs_item_ptr_offset`). `memmove/copy_leaf_items()` take item counts, whereas node pointer moves with `memmove/copy_extent_buffer()` must multiply by `sizeof(struct btrfs_key_ptr)`. In `btrfs_item_batch`, `total_data_size` is the sum of `data_sizes[]` excluding `sizeof(struct btrfs_item)`. [F135, F136, F139]
- `btrfs_add_delayed_tree_ref()` and `btrfs_add_delayed_extent_op()` take ownership of `extent_op` only on success; on error, call `btrfs_free_delayed_extent_op(extent_op)`. Set `generic_ref->ref_root` before `btrfs_init_tree_ref()` or `btrfs_init_data_ref()`. Delayed item/inode flushers (`__btrfs_run_delayed_items`, `btrfs_commit_inode_delayed_items/inode`, `btrfs_async_run_delayed_root`) must switch `trans->block_rsv` to `&fs_info->delayed_block_rsv` and restore it on exit. [F15, F50, F69]
- Pass the exact same `type` to `put_workspace()` / `btrfs_put_workspace()` as to `get_workspace()`, and validate `type < BTRFS_NR_COMPRESS_TYPES` before `btrfs_compress_level_valid()`, `btrfs_compress_set_level()`, or `btrfs_compress_folios()`. In `btrfs_compress_folios()`, `@out_folios` and `@total_out` are in/out (freeing `*out_folios` on failure). In `btrfs_delalloc_release_metadata/space()` and `btrfs_delayed_inode_release_metadata()`, `@qgroup_free` is `true` on error rollback and `false` on normal completion. `btrfs_free_reserved_data_space_noquota()` requires `len` aligned to `sectorsize`. [F54, F58, F96, F99, F132]
- When `!IS_ENABLED(CONFIG_BTRFS_EXPERIMENTAL)`, `defrag_prepare_one_folio()` must reject `folio_test_large(folio)` with `ERR_PTR(-ETXTBSY)`. `btrfs_run_defrag_inode()` must bracket `btrfs_defrag_file()` with `sb_start_write()` / `sb_end_write()`. `btrfs_defrag_file()` must check `IS_SWAPFILE()` (`-ETXTBSY`) and `SB_ACTIVE` under `btrfs_inode_lock()` each cluster, validate `range->start < isize`, `type < BTRFS_NR_COMPRESS_TYPES`, `btrfs_compress_level_valid()`, and `range->start + range->len > range->start`, and reset `inode->defrag_compress = BTRFS_COMPRESS_NONE` under `btrfs_inode_lock()` on exit. [F77, F167, F169, F170, F171]

## Error Handling

- `btrfs_insert_empty_items/item()` return `-EEXIST` without releasing `@path` when `btrfs_search_slot()` returns `0`, whereas other `< 0` errors release `@path`. In `read_block_for_search()`, if `btrfs_read_extent_buffer()` returns `0` on a block that is still `!extent_buffer_uptodate(tmp)`, set `ret = -EIO` (not `-EAGAIN`). `btrfs_select_ref_head()` returns a locked head, `NULL`, or `ERR_PTR(-EAGAIN)`; check both `!head` and `IS_ERR(head)`. `defrag_get_extent()` returns a valid `extent_map *`, `NULL`, or `ERR_PTR`, whereas `defrag_lookup_extent()` converts `IS_ERR(em)` to `NULL`. `btrfs_check_data_free_space()` and `btrfs_delalloc_reserve_space()` normalize positive qgroup returns to `0`, and on error call `extent_changeset_free(*reserved)` and set `*reserved = NULL`. [F47, F49, F57, F59, F104]

## Known Pitfalls

- `btrfs_item_ptr()` returns an extent-buffer offset cast to a pointer, so byte arithmetic on it must cast to `unsigned long` or `char *`. `split_item()` must copy the original payload to a buffer before updating offsets because `orig_slot` moves to `orig_offset + item_size - split_offset` while `slot` is written at `orig_offset`. When `btrfs_truncate_item()` truncates from the front (`!from_end`) of an inline `BTRFS_EXTENT_DATA_KEY`, shift `BTRFS_FILE_EXTENT_INLINE_DATA_START` forward before `memmove_leaf_data()`, add `size_diff` to the key offset, and call `fixup_low_keys()` if `slot == 0`. [F72, F73, F137]
- `btrfs_search_slot()` must reset `prev_cmp = -1` at `again:` so `search_for_key_slot()` does not skip `btrfs_bin_search()`. In `btrfs_bin_search()`, read a key via `folio_address(eb->folios[idx]) + oil` only if `oil + sizeof(struct btrfs_disk_key) <= eb->folio_size`. `btrfs_submit_compressed_read()` must refresh `cb->len = bbio->bio.bi_iter.bi_size` after `add_ra_bio_pages()`, and every `continue` in `add_ra_bio_pages()` must advance `cur` to the end of the folio before `folio_put()`. `btrfs_decompress_buf2page()` must use `file_offset_from_bvec()` (never `bv_page->index`) and wrapping subtraction `file_offset_from_bvec(&bvec) - cb->start` because `cb->start` (`em->start - em->offset`) can underflow `u64`. [F78, F85, F102, F108, F123, F160]
- In `btrfs_merge_delayed_refs()`, whenever `merge_ref()` erases the outer loop's `ref` from `head->ref_tree`, return `true` to restart at `again:`. In `btrfs_run_defrag_inodes()` and `btrfs_select_ref_head()`, if a lookup from a non-zero cursor finds nothing, reset the cursor to `0` and retry. [F116, F118]
