# DRM DRIVERS FOR ROCKCHIP — drivers/gpu/drm/rockchip (part 2)

Implements the second-generation Video Output Processor (VOP2) CRTC, plane, overlay, and register drivers for RK3566, RK3568, RK3576, and RK3588 SoCs, plus legacy VOP1 register tables and the LVDS and parallel RGB output drivers. VOP2 manages multiple video ports (CRTCs), movable windows (Cluster, Esmart, Smart), dynamic layer/port muxing, AFBC decoding, and SoC display routing.

## Architecture & Data Flow

- In `struct vop2`, `sys_grf`, `vop_grf`, `vo1_grf`, and `sys_pmu` are only looked up when their `VOP2_FEATURE_HAS_*` flag is set in `vop2->data->feature`, and `vop2->lut_regs` is `NULL` when the optional `"gamma-lut"` resource is absent; callers must check the feature or pointer before use. [F207]
- Because video port and window registers in `vop2_nonvolatile_range` are cached in `vop2->map` (`REGCACHE_MAPLE`) until `vop2_cfg_done()` latches them, `vop2_disable()` and `__vop2_regs_dump()` must call `regcache_drop_region(vop2->map, 0, vop2_regmap_config.max_register)`. Broken by: dropping `regcache_drop_region()` or adding non-latched status registers to `vop2_nonvolatile_range`. [F221]
- On `VOP_VERSION_RK3568` (`!vop2_supports_seamless_gamma_lut_update(vop2)`), `vop2_crtc_atomic_check_gamma()` must reject enabling gamma LUT on a second CRTC via `vop2_gamma_lut_in_use()`, and `vop2_crtc_atomic_set_gamma_rk356x()` must disable `DSP_LUT_EN`, call `vop2_cfg_done()`, and poll `vop2_vp_dsp_lut_poll_disabled()` before writing `vop2->lut_regs`. [F284]
- In `rk3568_vop2_setup_overlay()` and `rk3576_vop2_setup_overlay()`, `vp->win_mask` and each plane's `win->delay` must be updated before calling `vop2_setup_alpha()` (which calls `vop2_find_start_mixer_id_for_vp()` on `vp->win_mask`) and `rk3568_vop2_setup_dly_for_windows()`. In `vop2_setup_alpha()`, the mixer loop must skip `zpos == 0`, compute offsets as `(mixer_id + zpos - 1) * 0x10`, and apply non-cluster `bottom_layer_alpha_en` at `zpos == 1`. [F226, F254]
- For cluster windows (`vop2_cluster_window(win)`), `vop2_plane_atomic_update()` and `vop2_win_disable()` must update `VOP2_WIN_CLUSTER_ENABLE` alongside `VOP2_WIN_ENABLE`, and `vop2_plane_atomic_update()` must clear `VOP2_WIN_AFBC_ENABLE` and `VOP2_WIN_TRANSFORM_OFFSET` to `0` when `!afbc_en`. [F225]
- On VOP2 SoCs with `vop2->version > VOP_VERSION_RK3568`, each window on an AXI bus in `struct vop2_win_data` must have unique non-zero `axi_yrgb_r_id` and `axi_uv_r_id` (cluster IDs `< 0xf`), and `vop2_plane_atomic_update()` must program `VOP2_WIN_AXI_BUS_ID`, `VOP2_WIN_AXI_YRGB_R_ID`, and `VOP2_WIN_AXI_UV_R_ID`. [F280]
- In `rockchip_vop2_mod_supported()`, SoC/window restrictions (rejecting `DRM_FORMAT_MOD_LINEAR` on `vop2_cluster_window(win)` for `VOP_VERSION_RK3568`, and rejecting non-AFBC `DRM_FORMAT_XRGB2101010`/`DRM_FORMAT_XBGR2101010` for `VOP_VERSION_RK3588`) must precede the generic `modifier == DRM_FORMAT_MOD_LINEAR` acceptance. [F279]
- `vop2_scale_factor()` must guard against `dst < 2` and `src < 2` before decrementing `src` and `dst`, use `DIV_ROUND_UP(src << shift, dst) - 1`, and clamp `fac` to `U16_MAX`. [F258]
- VOP2 interrupt registers (`RK3568_VP_INT_EN`, `RK3568_VP_INT_CLR`, `RK3568_SYS0_INT_EN`, `RK3568_SYS0_INT_CLR`, `RK3568_SYS1_INT_EN`, `RK3568_SYS1_INT_CLR`) and per-VP bits in `RK3568_REG_CFG_DONE` require upper-16-bit write masks (`mask << 16 | val`). [F289]
- In `vop2_create_crtcs()`, `possible_crtcs` bit positions must use the sequential index `nvp` of connected ports (`vp->crtc.port != NULL`) rather than `vp->id`, `vop2_is_mirror_win()` windows must be skipped on RK3566, and `vp->nlayers` must only be set for connected ports. [F231]
- In `struct vop2`, flexible array `struct vop2_win win[]` must remain last (sized via `struct_size(vop2, win, vop2_data->win_size)`). In `struct vop2_data` and `struct vop_data`, `win_size` and `regs_dump_size` must use `ARRAY_SIZE(...)`, and each `struct vop2_regs_dump.size` must be a multiple of `0x10` bytes for `vop2_regs_print()`. [F240, F242, F265]
- Every `struct vop2_video_port_data` entry used with `rk3576_set_intf_mux()` (`rk3576_vop_video_ports`) must initialize `pixel_rate` to a non-zero value, because `rk3576_set_intf_mux()` divides `adjusted_mode->crtc_clock` by `vp->data->pixel_rate` when `DRM_MODE_FLAG_DBLCLK` is clear. [F261]
- Every `format_modifiers` array in `vop2_win_data` or `vop_win_phy` must end with `DRM_FORMAT_MOD_INVALID`. In `rk3399_vop_win_data`, `rk3399_win0_data` and `rk3399_win1_data` must stay separate `struct vop_win_phy` instances so `format_modifiers_win_full_afbc` is only on `win0`. [F233, F268]
- In `rockchip_vop_reg.c`, VOP1 SoCs with internal parallel RGB (`px30_vop_big`, `px30_vop_lit`, `rk3066_vop`, `rk3188_vop`) must set `VOP_FEATURE_INTERNAL_RGB`, SoCs with a DMA stop bit (`rk3066_common`) must set `.dma_stop` in `struct vop_common`, and `struct vop_intr.intrs` arrays (`px30_intr`, `rk3368_vop_intr`) are indexed by bit position (`1 << i`) so unused bits must be padded with `0`. [F243, F282]
- In `rk3288_writel()`, when `lvds->output != DISPLAY_OUTPUT_LVDS` (`DISPLAY_OUTPUT_RGB` or `DISPLAY_OUTPUT_DUAL_LVDS`), writes to channel 0 (`lvds->regs + offset`) must also be mirrored to channel 1 (`lvds->regs + offset + RK3288_LVDS_CH1_OFFSET`). [F232]

## Synchronization

- `vop2_lock(vop2)` (`vop2->vop2_lock`) must be held across `vop2_crtc_atomic_enable()` and `vop2_crtc_atomic_disable()` and released via `vop2_unlock(vop2)` on every return path (including `clk_prepare_enable(vp->dclk)` failure or `setup_intf_mux()` returning `0`) to serialize `vop2->enable_count` transitions, `vop2_enable()`/`vop2_disable()`, and `vop2_crtc_atomic_try_set_gamma()`. `vop2_crtc_atomic_disable()` must set `RK3568_VP_DSP_CTRL__STANDBY` and wait for `vp->dsp_hold_completion` before decrementing `vop2->enable_count` and calling `vop2_disable()`, and must restore `vp->dclk` to `vp->dclk_src` if reparented to `pll_hdmiphy0`/`pll_hdmiphy1`. [F184, F195, F227, F295]
- On `vop2->version <= VOP_VERSION_RK3588`, `vop2_enable()` must initialize `vop2->old_layer_sel` and `vop2->old_port_sel` from `RK3568_OVL_LAYER_SEL` and `RK3568_OVL_PORT_SEL`, and `rk3568_vop2_setup_layer_mixer()` must hold `vop2->ovl_lock`, swap displaced `old_win` into `old_layer_id`, poll `rk3568_vop2_wait_for_port_mux_done()` when `port_sel != old_port_sel`, and poll `rk3568_vop2_wait_for_layer_cfg_done()` before writing `RK3568_OVL_LAYER_SEL`. [F219, F220, F286]
- `vop2_crtc_atomic_flush()` must call `vop2_cfg_done(vp)` before moving `crtc->state->event` to `vp->event` under `crtc->dev->event_lock`, and `vop2_isr()` / `rk3576_vp_isr()` must only deliver `vp->event` (and call `drm_crtc_vblank_put()`) when `BIT(vp->id)` in `RK3568_REG_CFG_DONE` has cleared. [F228]
- In `IRQF_SHARED` handlers `vop2_isr()` and `rk3576_vp_isr()`, check `pm_runtime_get_if_in_use(vop2->dev)` and return `IRQ_NONE` before any register access, and release with non-sleeping `pm_runtime_put(vop2->dev)`. [F294]
- Debugfs callbacks (`vop2_summary_show()` and `__vop2_regs_dump()`) must hold `drm_modeset_lock_all(drm_dev)` while inspecting `crtc->state`, `plane->state`, `vop2->enable_count`, or calling `regcache_drop_region()` and reading registers. [F298]

## Object Lifetimes

- In `vop2_destroy_crtcs()`, all planes in `drm->mode_config.plane_list` must be cleaned up via `drm_plane_cleanup()` before iterating `drm->mode_config.crtc_list` to call `of_node_put(crtc->port)` and `drm_crtc_cleanup()`. [F274]
- In `vop2_bind()`, per-VP `irq_name` passed to `devm_request_irq()` must be allocated with `devm_kasprintf()` rather than a stack buffer, as `devm_request_irq()` stores the pointer directly. [F271]
- In `rockchip_lvds_bind()` and `rockchip_rgb_init()`, breaking out of `for_each_child_of_node(port, endpoint)` requires `of_node_put(endpoint)`, and `of_node_put(port)` must be called on all exit paths. [F194]
- In `rk3288_lvds_probe()`, if `devm_pinctrl_get()` or `pinctrl_lookup_state()` fails, `lvds->pins` must be freed and set to `NULL` so `rk3288_lvds_grf_config()` does not pass an error pointer to `pinctrl_select_state()`. Because `lvds->pclk` is acquired with `devm_clk_get_prepared()`, `rk3288_lvds_poweron()`/`rk3288_lvds_poweroff()` must use `clk_enable()`/`clk_disable()` (and `clk_disable()` on `pm_runtime_resume_and_get()` failure). [F192, F291]

## API Contracts

- `vop2_vp_write()`/`vop2_vp_read()` add `vp->data->offset` and take VP-relative offsets (e.g., `RK3568_VP_DSP_CTRL`), `vop2_writel()`/`vop2_readl()` take absolute offsets, and `vop2_win_write()` takes an `enum vop2_win_regs` index. [F216]
- In `vop2_plane_atomic_update()`, `VOP2_WIN_YRGB_VIR` and `VOP2_WIN_UV_VIR` take 4-byte dwords (`DIV_ROUND_UP(fb->pitches[i], 4)`), whereas `VOP2_WIN_AFBC_PIC_VIR_WIDTH` takes 16-byte AFBC header stride units (`ALIGN((fb->pitches[0] << 3) / bpp, block_w) / block_w * 16`). [F306]
- `vop2_parse_alpha()` must zero-initialize `src_color_ctrl.val`, `dst_color_ctrl.val`, `src_alpha_ctrl.val`, and `dst_alpha_ctrl.val` in `struct vop2_alpha` before setting `.bits`, as callers pass an uninitialized stack struct. [F211]
- `rk3588_calc_dclk(child_clk, max_dclk)` arguments and `vop2_ops->setup_intf_mux()` return values are in Hz (`0` on failure), whereas `drm_display_mode.crtc_clock` is in kHz and must be multiplied by `1000`. [F213]
- `rockchip_rgb_init()` returns `NULL` when unused, `ERR_PTR` on error, or a valid pointer; `vop2_bind()` must call `vop2_destroy_crtcs()` on `-EPROBE_DEFER`, set `vop2->rgb = NULL` on other `IS_ERR` returns, and call `rockchip_rgb_fini(vop2->rgb)` in `vop2_unbind()` only if non-NULL. [F277]
- `vop2_debugfs_list` show callbacks receive `struct drm_info_node *` in `s->private` and must get `struct vop2 *` from `node->info_ent->data`, not by casting `s->private`. [F273]

## Error Handling

- Because `enum vop2_data_format` has only non-negative values (`0..0x16`), callers of `vop2_convert_format()` must store the result in a signed `int` before checking `< 0`. [F204]
- `vop2_create_crtcs()` must check `vp->primary_plane` for `NULL` before `drm_crtc_init_with_planes()` dereferences `&vp->primary_plane->base`, and `vop2_crtc_duplicate_state()` must check `WARN_ON(!crtc->state)` and return `NULL` before `kmemdup()`. [F205, F206]
- In `vop2_isr()` and `rk3576_vp_isr()`, `VP_INT_POST_BUF_EMPTY` and `VOP2_INT_BUS_ERRPR` must be logged via `drm_err_ratelimited()`. [F300]
- In `rockchip_lvds_bind()`, when `drm_of_find_panel_or_bridge()` fails, return its exact `ret` without overwriting it. [F208]

## External Contracts

- In `vop2_plane_atomic_check()`, a visible plane with `src` (`>> 16`) or `dest` smaller than 4x4 must set `pstate->visible = false` and return `0`, whereas `src` exceeding `vop2_data->max_input` or YUV planes with odd `pstate->src.x1 >> 16` must return `-EINVAL`. [F307]

## Known Pitfalls

- In `rk3568_vop_cluster_regs`, `rk3568_vop_smart_regs`, `rk3576_vop_cluster_regs`, and `rk3576_vop_smart_regs`, any unsupported `enum vop2_win_regs` entry written by `vop2_win_write()` must be initialized to `{ .reg = 0xffffffff }` so `vop2_regmap_init()` does not add `win->offset` to register `0`. [F222]
- In `vop2_plane_atomic_update()`, when `afbc_en` is true: compute `afbc_tile_num` and write `VOP2_WIN_AFBC_PIC_SIZE` from unrotated `actual_w`/`act_info` before the `rotate_90 || rotate_270` swap; program `VOP2_WIN_AFBC_HDR_PTR` (and on `VOP_VERSION_RK3576`+, `VOP2_WIN_AFBC_PLD_OFFSET` with `VOP2_WIN_AFBC_PLD_OFFSET_EN`) with zero-offset `rk_obj->dma_addr + fb->offsets[0]` while putting crop offsets in `VOP2_WIN_TRANSFORM_OFFSET` and `VOP2_WIN_AFBC_PIC_OFFSET`; and write `VOP2_WIN_AFBC_AUTO_GATING_EN` as `0` on `VOP_VERSION_RK3568` and `1` on other versions. [F224, F287, F288]
- In `vop2_afbc_transform_offset()` and `vop2_plane_atomic_update()`, obtain bpp via `vop2_get_bpp(fb->format)` rather than `drm_format_info_bpp()`, as `DRM_FORMAT_YUV420_8BIT`/`10BIT` have zero `cpp` in DRM core and would divide by zero. [F257]
- Because cluster `enum vop2_layer_phy_id` values (`ROCKCHIP_VOP2_CLUSTER0..3` = `0, 1, 6, 7`) are non-contiguous, `vop2_setup_cluster_alpha()` and hardware-indexed code must switch on `win->data->phys_id` rather than multiplying by a stride. [F235]
- Because RK3566 and RK3568 share `VOP_VERSION_RK3568` and `rk3568_vop_win_data`, RK3566 quirks (`RK3568_OTP_WIN_EN` in `vop2_enable()` and skipping mirror windows via `vop2_is_mirror_win()`) must test `vop2->data->soc_id == 3566` rather than `vop2->version`. [F278]
- In `struct vop2_video_port_data`, `rk3568_vop2_setup_bg_dly()` reads `pre_scan_max_dly[3]` directly, whereas `rk3576_vop2_setup_bg_dly()` sums `VOP2_DLY_WIN` (0), `VOP2_DLY_LAYER_MIX` (1), and `VOP2_DLY_HDR_MIX` (2). [F241]
- In `rk3568_set_intf_mux()`, each endpoint case must update both `die` (`RK3568_DSP_IF_EN`) and its polarity field in `dip` (`RK3568_DSP_IF_POL`). In `rk3588_set_intf_mux()`, each case must update the matching `RK3588_SYS_DSP_INFACE_EN_*` fields in `die`. In `rk3568_vop2_setup_layer_mixer()`, each port (`vp0..vp2`) must write its layer boundary into its own `PORT0_MUX`/`PORT1_MUX`/`PORT2_MUX` mask in `port_sel`. [F246, F247, F249]
- In `rk3588_calc_cru_cfg()`, assign raw power-of-two factors (`1, 2, 4`) to `*if_pixclk_div`, `*if_dclk_div`, and `*dclk_out_div` before the trailing `ilog2()` conversions. In `vop2_setup_scale()`, test `>= (4 * dst_h)` before `>= (2 * dst_h)` and reset `gt4 = 0; gt2 = 0;` before `cbcr_src_h` prescaling. In `vop2_create_crtcs()`, `char dclk_name[9]` fits only single-digit `vp->id` with `"dclk_vp%d"`. [F253, F262, F272]
