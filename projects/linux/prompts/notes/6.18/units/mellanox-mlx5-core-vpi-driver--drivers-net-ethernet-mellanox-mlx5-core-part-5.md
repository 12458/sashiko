# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 5)

Implements device health monitoring and devlink health reporters, hwmon thermal sensors, IP-over-InfiniBand (IPoIB) parent/PKey child netdevices, IRQ CPU affinity pools, and Link Aggregation (LAG) across multi-port ConnectX functions (RoCE LAG, SR-IOV VF LAG, Multipath, Multi-Port E-Switch, and port selection steering).

## Architecture & Data Flow

- In `mlx5_health_check_fatal_sensors()`, check `sensor_pci_not_working(dev)` before `mlx5_get_nic_state(dev)` and `sensor_fw_synd_rfr(dev)`, as offline PCI reads return `0xffffffff`, aliasing `MLX5_INITIAL_SEG_NIC_INTERFACE_SW_RESET` (`0x7`) and setting `rfr`/`synd` bits. `mlx5_set_nic_state()` must update `dev->iseg->cmdq_addr_l_sz` via read-modify-write preserving `cur_cmdq_addr_l_sz & 0xFFFFF000`. `mlx5_start_health_fw_log_up()` must check `mlx5_core_is_pf(dev)` and `MLX5_CAP_MCAM_REG(dev, mrtc)` before queueing `update_fw_log_ts_work`. [F427, F459, F483]
- In `struct mlx5_hwmon`, `chip_channel_config`, `channel_info`, and `temp_channel_config` must be zero-allocated with `+ 1` trailing sentinel elements. `mlx5_hwmon_init_sensors_indexes()` packs ASIC sensors into `temp_channel_desc[0 .. i - 1]` and the optional module sensor at `temp_channel_desc[i]`; hwmon channels densely index `temp_channel_desc[channel]`, whereas MTMP register queries must use `temp_channel_desc[channel].sensor_index`. [F409, F445, F461]
- In `struct mlx5i_priv`, `struct rdma_netdev rn` must be first and `char *mlx5e_priv[]` the trailing flexible array (`sizeof(struct mlx5i_priv) + sizeof(struct mlx5e_priv)`), so `netdev_priv(netdev)` yields `struct mlx5i_priv` and `mlx5i_epriv(netdev)` yields `struct mlx5e_priv`. `mlx5_rdma_setup_rn()` detects PKey sub-interfaces via `mlx5_is_sub_interface(mdev)` (`pdn != 0`); `mlx5e_create_mdev_resources()` and `mlx5i_pkey_qpn_ht_init()` (and teardown in `mlx5_rdma_netdev_free()`) must run only when `!ipriv->sub_interface`. [F431, F447]
- `mlx5i_dev_init()` encodes 24-bit `ipriv->qpn` into bytes 1..3 of `dev->dev_addr` (`dev_addr_mod()`) and registers `(dev, ipriv->qpn)` via `mlx5i_pkey_add_qpn()`; `mlx5i_dev_cleanup()` must call `mlx5i_uninit_underlay_qp()` and `mlx5i_pkey_del_qpn()`. [F433]
- In `mlx5_irq_affinity_request()` and `mlx5_irq_affinity_irq_release()`, `pci_irq_vector()` must use `pool->dev->pdev`, whereas SF sysfs calls (`mlx5_sf_coredev_to_adev()`) must use the requesting `dev`. [F454]
- `mlx5_lag_is_supported()` bounds `num_lag_ports` to `[2, MLX5_MAX_PORTS]` (`[2, 8]`) so `GENMASK(ldev->ports - 1, 0)` and `u8` port bitmasks (`lag_active_port_bits`, `bond_status`) do not overflow. `ldev->v2p_map` and `lag_definer->rules` are indexed by `[i * ldev->buckets + j]`; `ldev->v2p_map` stores 1-based PF numbers (`i + 1`), while `mlx5_infer_tx_enabled()`/`disabled()` output 0-based PF indices. Only call `mlx5_infer_tx_affinity_mapping()` when all `ldev->ports` functions are present or at least one port is TX-enabled so `rand % enabled_ports_num` cannot divide by zero. [F450, F463, F464]
- When `MLX5_LAG_MODE_FLAG_HASH_BASED` is set, `mlx5_activate_lag()` must call `mlx5_lag_port_sel_create()` before `mlx5_create_lag()` (`MLX5_CMD_OP_CREATE_LAG`); `mlx5_deactivate_lag()` must run `MLX5_CMD_OP_DESTROY_LAG` before `mlx5_lag_port_sel_destroy()`, reset `ldev->buckets = 1`, `ldev->mode = MLX5_LAG_MODE_NONE`, `ldev->mode_flags = 0`, `mlx5_lag_mp_reset(ldev)`, and `mlx5_lag_drop_rule_cleanup(ldev)`. `mlx5_lag_drop_rule_setup()` must also call `mlx5_lag_drop_rule_cleanup(ldev)` before installing new uplink drop rules. [F437, F438, F490]
- In `mlx5_do_bond()` and `mlx5_modify_lag()`, when `tracker.tx_type == NETDEV_LAG_TX_TYPE_ACTIVEBACKUP`, notify `dev0->priv.lag_nh` with `MLX5_DRIVER_EVENT_ACTIVE_BACKUP_LAG_CHANGE_LOWERSTATE` passing `mlx5_lag_active_backup_get_netdev(dev0)`, then call `dev_put()`. [F436]
- `mlx5_lag_add_netdev()` resets `ldev->tracker.netdev_state[fn]` and sets `MLX5_LAG_FLAG_NDEVS_READY` only when `mlx5_lag_num_netdevs(ldev) >= ldev->ports`; `mlx5_lag_remove_netdev()` clears `ldev->pf[i].netdev` and `MLX5_LAG_FLAG_NDEVS_READY`, queuing `ldev->bond_work` if LAG is active. [F439]
- `enable_mpesw()` must verify `MLX5_ESWITCH_OFFLOADS`, `port_select_flow_table`, `create_lag_when_not_master_up`, `mlx5_lag_check_prereq(ldev)`, and `mlx5_lag_shared_fdb_supported(ldev)`. `mlx5_mpesw_metadata_set()` and `mlx5_mpesw_metadata_cleanup()` must keep `ldev->lag_mpesw.pf_metadata[i]`, `mlx5_esw_acl_ingress_vport_metadata_update()`, and `MLX5_DEV_EVENT_MULTIPORT_ESW` notifications synchronized across all PFs. [F442, F491]

## Synchronization

- In `mlx5_start_health_poll()`, initialize `fatal_error`, `flags`, `health`, and `health_counter` before `add_timer(&health->timer)`. `poll_health()` runs in atomic timer context and must only do MMIO reads and `dev->state` assignment, deferring sleeping/locks to `health->wq`. `mlx5_drain_health_wq()` must set `MLX5_DROP_HEALTH_WORK` before cancelling health works, and `mlx5_fw_fatal_reporter_err_work()` must check `MLX5_DROP_HEALTH_WORK` under `dev->intf_state_mutex`. [F389, F390, F494]
- In `mlx5_enter_error_state()`, after transitioning `dev->state` to `MLX5_DEVICE_STATE_INTERNAL_ERROR`, lock `dev->intf_state_mutex` and recheck `dev->state` when `!err_detected` to avoid duplicate `enter_error_state()` calls. `mlx5_health_try_recover()` requires `devl_lock` held and `dev->intf_state_mutex` unlocked. [F392, F495]
- In `mlx5_error_sw_reset()`, acquire `MLX5_SEMAPHORE_SW_RESET` via `lock_sem_sw_reset(dev, true)`, re-check `mlx5_health_check_fatal_sensors()` in `reset_fw_if_needed()` before setting `MLX5_INITIAL_SEG_NIC_INTERFACE_SW_RESET`, and call `lock_sem_sw_reset(dev, false)` only if `lock_sem_sw_reset(dev, true)` returned `0`. `lock_sem_sw_reset()` must bracket `mlx5_vsc_sem_set_space()` with `mlx5_vsc_gw_lock()` / `mlx5_vsc_gw_unlock()`. [F387, F428, F496]
- In `mlx5_irq_affinity_request()`, hold `pool->lock` continuously across `irq_pool_find_least_loaded()`, `irq_pool_request_irq()`, and `mlx5_irq_get_locked(least_loaded_irq)`. [F394]
- In IPoIB (`ipoib.c`, `ipoib_vlan.c`), hold `priv->state_lock` across `MLX5E_STATE_OPENED` transitions, channel open/close/reconfig, and `WRITE_ONCE(netdev->mtu, ...)`. In `mlx5i_pkey_add_qpn()` / `mlx5i_pkey_del_qpn()`, hold `spin_lock_bh(&ht->ht_lock)` around `ht->buckets` mutations and initialize `new_node` before `hlist_add_head()`. [F397, F398]
- Always lock `dev->priv.hca_devcom_comp` before `ldev->lock`; `mlx5_lag_get_devcom_comp()` must drop `ldev->lock` before the caller locks devcom. `mlx5_lag_disable_change()` increments `ldev->mode_changes_in_progress` under both locks and must pair with `mlx5_lag_enable_change()`. Check/modify `mode_changes_in_progress` under `ldev->lock`, aborting bond/MPESW/add/remove work when non-zero and revalidating after dropping `ldev->lock` to sleep. [F385, F399, F402]
- Never sleep or take locks (`ldev->lock`, `mlx5_cmd_exec_inout()`, `blocking_notifier_call_chain()`) under `lag_lock`: `mlx5_lag_active_backup_get_netdev()` must `dev_hold(ndev)` under `lag_lock`, and `mlx5_lag_query_cong_counters()` must snapshot `ldev->pf[i].dev` under `lag_lock`. Enclose `for_each_netdev_in_bond_rcu` and `bond_slave_get_rcu()` in `rcu_read_lock()` / `rcu_read_unlock()`. [F400, F504]
- In `mlx5_lag_mpesw_queue_work()`, initialize `work->work`, `comp`, `op`, and `lag` before `queue_work(ldev->wq, &work->work)`, and never access `mpesww` in `mlx5_mpesw_work()` after `complete(&mpesww->comp)`. [F406]

## Object Lifetimes

- In `mlx5_health_cleanup()`, cancel `update_fw_log_ts_work` and `destroy_workqueue(health->wq)` before `mlx5_reporter_vnic_destroy()` and `mlx5_fw_reporters_destroy()`. In `mlx5_fw_reporter_dump()` / `mlx5_fw_fatal_reporter_dump()`, `priv_ctx` is `NULL` or a stack `struct mlx5_fw_reporter_ctx *`; check for `NULL` and never retain it. [F391, F474]
- `mlx5_hwmon_dev_register()` must set `mdev->hwmon = hwmon` only after `hwmon_device_register_with_info()` succeeds. `mlx5_hwmon_dev_unregister()` must call `hwmon_device_unregister(hwmon->hwmon_dev)` before `mlx5_hwmon_free(hwmon)` and set `mdev->hwmon = NULL`. [F388, F410]
- `mlx5_irq_affinity_irq_release()` must read `pool`, `cpu`, `mlx5_irq_get_index(irq)`, and `mlx5_irq_get_irq(irq)` before `mlx5_irq_put(irq)`, and call `cpu_put(pool, cpu)` only when `mlx5_irq_put(irq)` returns non-zero. [F379]
- Under `ASSERT_RTNL()`, `mlx5i_parent_get()` takes a parent netdev ref, inherits `qpn_htbl`, and increments `parent_ipriv->num_sub_interfaces`; any failure after it in `mlx5i_pkey_dev_init()` and teardown in `mlx5i_pkey_dev_cleanup()` must call `mlx5i_parent_put()` under RTNL, and `mlx5i_set_channels()` must reject changes while `num_sub_interfaces > 0`. [F380, F396, F432]
- `__mlx5_lag_dev_add_mdev()` sets `ldev->ref = 1` on `mlx5_lag_dev_alloc()` for the first PF and calls `mlx5_ldev_get(ldev)` only for subsequent PFs after checking `!ldev->mode_changes_in_progress`. In `mlx5_lag_remove_mdev()`, call `mlx5_ldev_remove_debugfs()` before `mlx5_ldev_remove_mdev()` clears `dev->priv.lag` and before `mlx5_ldev_put(ldev)`. [F384, F403]
- In `mlx5_ldev_free()` and `mlx5_lag_mp_cleanup()`, unregister `ldev->nb` and `mp->fib_nb` before cancelling work and destroying `ldev->wq` / `mp->wq`; if notifier registration fails in init, clear `notifier_call = NULL`. [F404, F425]
- In `mlx5_lag_fib_event()` and `mlx5_lag_fib_update()`, each `mlx5_fib_event_work` must `fib_info_hold()` the union member matching `event` (`fen_info.fi` for `ENTRY_REPLACE`/`DEL`, `fnh_info.fib_nh->nh_parent` for `NH_ADD`/`DEL`) and `fib_info_put()` that same member before `kfree(fib_work)`. `ldev->lag_mp.fib.mfi` is unreferenced and must be cleared to `NULL` on `FIB_EVENT_ENTRY_DEL`, when `!nh_dev0` on replace, and in `mlx5_lag_mp_init()`/`reset()`/`cleanup()`. [F382, F383, F424]

## API Contracts

- Expose `.dump` callbacks (`mlx5_fw_reporter_pf_ops`, `mlx5_fw_fatal_reporter_pf_ops`/`ecpf_ops`) only on PF/ECPF devices, never VF/SF. `lock_sem_sw_reset()` must map `-EBUSY` from `mlx5_vsc_gw_lock()` to `-EINVAL`, reserving `-EBUSY` for non-PF or `mlx5_vsc_sem_set_space(..., MLX5_SEMAPHORE_SW_RESET, ...)` contention. [F408, F514]
- Callers of `mlx5_hwmon_is_module_mon_cap()` must initialize `*mon_cap = false` first. Map module numbers to MTMP sensor index `64 + idx` (`to_mtmp_module_sensor_idx()`), scale MTMP temperatures by 125 (`mtmp_temp_to_mdeg()`), and in `mlx5_hwmon_enable_max_temp()` query current `MLX5_REG_MTMP` via `mlx5_hwmon_query_mtmp()` before setting `mte = 1`. [F411, F412, F430]
- `mlx5i_build_nic_params()` must disable RX striding RQ, packet merge, and RX CQE compression after `mlx5e_build_nic_params()`. `mlx5i_get_tisn()` requires `lag_port == 0` and `tc == 0`. [F416, F509]
- `mlx5_activate_lag()` allows `tracker == NULL` when `mode == MLX5_LAG_MODE_MPESW`, so guard `tracker` dereferences in `mlx5_activate_lag()` / `mlx5_create_lag()`. Initialize `i = 0` before calling `mlx5_lag_get_next_peer_mdev(dev, &i)`. After `mlx5_ldev_for_each(i, ...)`, check `i < MLX5_MAX_PORTS` before indexing `ldev->pf[i]`. [F421, F422, F455]
- `mlx5_lag_get_slave_port()` returns a 1-based port from `ldev->v2p_map` only when `__mlx5_lag_is_roce(ldev)` is true (and `0` otherwise). In `mlx5_lag_query_cong_counters()`, `offsets[j]` is a byte offset into `out`, read via `be64_to_cpup((__be64 *)(out + offsets[j]))`. `mlx5_lag_fib_event()` must check `info->family == AF_INET` before `container_of()` casts. [F423, F452, F473]

## Error Handling

- Check `IS_ERR_OR_NULL()` on `health->fw_reporter` and `health->fw_fatal_reporter` before use or teardown. `mlx5_irq_affinity_request()` returns `ERR_PTR` (never `NULL`) and must call `mlx5_irq_put()` if `auxiliary_device_sysfs_irq_add()` fails. In `mlx5i_init_underlay_qp()`, transition the QP to error via `MLX5_CMD_OP_2ERR_QP` if `INIT2RTR` or `RTR2RTS` fails. [F407, F417, F488]
- Store returns from `mlx5_lag_get_dev_index_by_seq()` and `mlx5_lag_dev_get_netdev_idx()` in a signed `int` and check `< 0` before indexing `ldev->pf[]`. In `mlx5_lag_port_sel_create()` error paths and `mlx5_lag_port_sel_destroy()`, destroy `outer.ttc` and `inner.ttc` before `mlx5_lag_destroy_definers()` and `memset(port_sel, 0, sizeof(*port_sel))`. Rollback after `mlx5_lag_remove_devices(ldev)` in `shared_fdb` or MPESW mode must call both `mlx5_lag_add_devices(ldev)` and `mlx5_eswitch_reload_ib_reps()`. [F377, F378, F418]

## External Contracts

- In `mlx5_fw_fatal_reporter_err_work()`, if `devlink_health_report()` returns `-ECANCELED`, call `mlx5_unload_one(dev, false)`. `mlx5i_get_rxnfc()` must handle `ETHTOOL_GRXRINGS` directly before `mlx5e_ethtool_get_rxnfc()`, and `mlx5i_set_rxnfc()` must reject `ETHER_FLOW` with `-EINVAL`. For SF IRQ pools (`mlx5_irq_pool_is_sf_pool(pool)`), pair `auxiliary_device_sysfs_irq_add()` (after dropping `pool->lock`) with `auxiliary_device_sysfs_irq_remove()`. Scope LAG netdevice notifiers (`register_netdevice_notifier_net()`) and HCA devcom matching (`MLX5_DEVCOM_MATCH_FLAGS_NS`) to `ldev->net`. [F511, F513, F515, F516]

## Known Pitfalls

- Use `time_after(jiffies, end)` for timeout loops in `mlx5_error_sw_reset()` and `mlx5_health_wait_pci_up()`. In `hwmon.c`, convert 64-bit `sensor_map` via `bitmap_from_u64()` before `for_each_set_bit()`, and keep `temp_channel_desc` zero-allocated with `sizeof(sensor_name) > 8` since `mlx5_hwmon_init_channels_names()` `memcpy()`s 8 bytes without a NUL terminator. [F466, F467, F471]
- In `mlx5_irq_affinity_irq_release()`, get the pool via `mlx5_irq_get_pool(irq)`, not `mlx5_irq_table_get_comp_irq_pool(dev)`. In `mlx5_modify_lag()`, pass a separate `ports` buffer to `_mlx5_modify_lag(ldev, ports)` before copying `ports` into `ldev->v2p_map`. In `mlx5_lag_create_port_sel_table()` error unwind, decrement `j` from the failed bucket on `k == i`, then reset `j = ldev->buckets` at the end of each pass for `k < i`. Keep `ldev->buckets == 1` when `MLX5_LAG_MODE_FLAG_HASH_BASED` is unset so `mlx5_lag_print_mapping()` does not overrun `buf`. In `mlx5_lag_fib_event()`, ignore `FIB_EVENT_ENTRY_REPLACE`/`DEL` when `fi->nh != NULL`. [F435, F453, F456, F475, F518]
