# NETWORKING DRIVERS — drivers/net (part 3)

This unit covers virtual networking drivers (`tun`, `veth`, `pfcp`, `nlmon`), RapidIO Ethernet (`rionet`), MII/PHY libraries (`sungem_phy`, `mii`), parallel-port IP (`plip`), SLIP/VJ compression (`slip`, `slhc`), and PPP BSD compression and PPTP (`bsd_comp`, `pptp`).

## Architecture & Data Flow

- `veth` (`rq->xdp_ring`) and `tun` (`tfile->tx_ring`) multiplex `sk_buff *` and `xdp_frame *` in one `ptr_ring` by tagging bit 0 on `xdp_frame` (`veth_xdp_to_ptr()`, `tun_xdp_to_ptr()`); consumers must test `veth_is_xdp_frame()` / `tun_is_xdp_frame()` and strip bit 0 before dereferencing. [F773]
- `struct sock sk` must be first in `struct tun_file` (`tun_chr_open()` casts `sk_alloc()` directly). `tun->tfiles[0..numqueues-1]` is dense (`numqueues + numdisabled <= MAX_TAP_QUEUES`); `__tun_detach()` must swap `tfiles[numqueues - 1]` into `index` and update its `queue_index` and `xdp_rxq.queue_index`. Iterating `tun->disabled` with `tun_enable_queue()` requires `list_for_each_entry_safe()`. [F764, F781, F810]
- `tun_ebpf_select_queue()` and `tun_xdp_xmit()` must snapshot `READ_ONCE(tun->numqueues)` and return if 0 before `% numqueues`. `tun_flow_cleanup()` must compare `e->updated + delay` against `jiffies` and `next_timer` with `time_before_eq()` / `time_before()`. [F792, F800]
- `tun_get_user()` and `tun_xdp_one()` must reject TAP frames `< ETH_HLEN` (and non-zero `virtio_net_hdr` `hdr_len < ETH_HLEN`) before `eth_type_trans()`. `tun_napi_alloc_frags()` must reject `it->nr_segs > MAX_SKB_FRAGS + 1`, `len > ETH_MAX_MTU - NET_SKB_PAD - NET_IP_ALIGN`, or segment `i >= 1` with `iov_len == 0` or `> PAGE_SIZE`. [F758, F763]
- In `set_offload()`, each `TUN_F_*` flag in `arg` must be checked only inside its prerequisite block (`TUN_F_CSUM` for all; `features & PLAIN_GSO` for `TUN_F_UDP_TUNNEL_GSO*`) and cleared from `arg` before `if (arg) return -EINVAL;`. [F787]
- `veth_xdp_xmit()` and `veth_xmit()` must verify `rcu_access_pointer(rq->napi)` before producing to `rq->xdp_ring`. `veth_xdp_rcv_one()` sets `vxbuf.skb = NULL`, so `veth_xdp_metadata_ops` callbacks must return `-ENODATA` if `!_ctx->skb`. [F727, F729]
- In `veth_xdp_rcv_skb()`, `xdp->data` and `xdp->data_end` must be saved before `bpf_prog_run_xdp()`, and on `XDP_PASS` the SKB geometry (`data`, `tail`, `mac_header`, `data_len` from `xdp_frags_size`, `protocol`, metadata length) resynchronized with `xdp`. [F746]
- `veth_set_channels()` must reject zero `rx_count` or `tx_count` with `-EINVAL`. `veth_get_strings()`, `veth_get_sset_count()`, and `veth_get_ethtool_stats()` must use `real_num_rx_queues` and `real_num_tx_queues`. `veth_set_rx_headroom()` must record `priv->requested_headroom` and set both `dev` and `peer` `needed_headroom` to `max(priv->requested_headroom, peer_priv->requested_headroom)`. [F749, F793, F813]
- In `sl_realloc_bufs()`, remaining TX bytes (`sl->xleft <= len`) must be copied from `sl->xhead` to the new `sl->xbuff` and `sl->xhead` reset to `sl->xbuff` before `kfree(xbuff)`. [F750]
- `slhc_compress()` and `slhc_remember()` must validate `isize >= sizeof(struct iphdr)`, `ip->ihl >= 5`, `isize >= ip->ihl * 4 + sizeof(struct tcphdr)`, `th->doff >= 5`, and `isize >= ip->ihl * 4 + th->doff * 4` before accessing TCP fields or options. `slhc_remember()` must sample the slot index in `iph->protocol` and restore `IPPROTO_TCP` before `ip_fast_csum()` and saving `cs->cs_ip`. In `slhc_uncompress()`, explicit slot `x` (`NEW_C`) requires `0 <= x <= comp->rslot_limit` (`rslots - 1`) and `rstate[x].initialized`; implicit slots must be dropped if `comp->flags & SLF_TOSS`. [F751, F765, F766]
- `pptp_create()` sets `seq_recv` and `ack_sent` to `0xffffffff` (so 32-bit `seq_recv + 1` wraps to `0`). `pptp_rcv_core()` must pair seq/ack comparisons with `WRAPPED(curseq, lastseq)`, subtract `sizeof(header->ack)` from `headersize` when `!GRE_IS_ACK()`, and pass `pskb_may_pull(skb, headersize + payload_len)` before reading `skb->data + headersize`. [F769, F798, F799]
- `bsd_alloc()` must restrict `BSD_NBITS` to `9..15` (`unsigned short` `cptr` overflows at 16-bit `hsize = 69001`) and allocate `db->lens` with `maxmaxcode + 1` elements when `decomp != 0`. `bsd_decompress()` must reject non-`CLEAR` `incode > max_ent + 2`, `> db->maxmaxcode`, or `> max_ent && oldcode == CLEAR`, and check `explen += codelen + extra <= osize` before writing `obuf`. [F770, F771, F804]
- `bsd_compress()` and `bsd_decompress()` must update `in_count` and `bytes_out` (including dribble byte when `bitno < 32`) identically before `bsd_check(db)`, and `bsd_compress()` must increment `n_bits` when `max_ent >= mxcode && max_ent < db->maxmaxcode`. `bsd_check()` must age counts (`-= count >> 2`) at `RATIO_MAX` and check `bytes_out != 0` before dividing. [F753, F794]
- In `generic_mii_ioctl()`, `SIOCSMIIREG` must update cached `mii_if` state only when `mii_data->phy_id == mii_if->phy_id`. `mii_phy_table[]` in `sungem_phy.c` must end with `NULL`. [F756, F774]
- In `plip.c`, `enum plip_connection_state` indexes `connection_state_table[]` directly. `plip_send_packet()` and `plip_receive_packet()` states `PLIP_PK_TRIGGER..PLIP_PK_CHECKSUM` must advance `state` and `fallthrough;`. `plip_receive_packet()` must check `rcv->length.h` in `[8, dev->mtu + dev->hard_header_len]` before allocating `rcv->skb`. [F757, F776, F779]
- `rionet_add_dev()` must check `is_rionet_capable()` before `rionet_setup_netdev()`, and `rionet_add_dev()` / `rionet_remove_dev()` must check `dev_rionet_capable(rdev)`. [F826]

## Synchronization

- `tfile->tun` and `tun->tfiles[]` require `rcu_read_lock()` or `rtnl_lock()`; blocking callers must use `tun_get()` / `tun_put()`. `tun_attach()` must publish `tfile->tun` and `tun->tfiles[numqueues]` via `rcu_assign_pointer()` only after `tx_ring`, `queue_index`, `xdp_rxq`, and `napi` init, and after `register_netdevice()` in `tun_set_iff()`. [F704, F832]
- With `tfile->napi_enabled` (`!frags`), `tun_get_user()` and `tun_xdp_one()` must check `tfile->detached` under `tfile->sk.sk_write_queue.lock` before queueing and scheduling NAPI. With `tun_napi_frags_enabled(tfile)`, `tun_get_user()` must hold `tfile->napi_mutex` from `tun_napi_alloc_frags()` through `do_xdp_generic()` and `napi_gro_frags()`, clearing `tfile->napi.skb` or calling `napi_free_frags()` on error before unlock. [F707, F708]
- `tun_queue_resize()` must use `ptr_ring_resize_multiple_bh()` (`tun_ptr_free()` calls `__page_pool_put_page()`, which forbids hardirq-disabled context). Non-timer callers must take `tun->lock` with `spin_lock_bh()`, and `tun_flow_uninit()` must call `timer_delete_sync(&tun->flow_gc_timer)` before `tun_flow_flush()`. [F831, F838]
- Process-context XDP in `tun.c` (`tun_build_skb()`, `tun_get_user()`, `tun_sendmsg()`) requires `local_bh_disable()`, `rcu_read_lock()`, and (for native XDP) `bpf_net_ctx_set()` / `bpf_net_ctx_clear()`. Process-context `dev_sw_netstats_rx/tx_add()` calls require `preempt_disable()`. [F835, F837]
- `update_filter()` must set `filter->count = 0` and `wmb()` before updating `addr`/`mask`, and `wmb()` before storing `filter->count`. In `tun_chr_poll()`, if `!tun_sock_writeable()`, set `SOCKWQ_ASYNC_NOSPACE` via `test_and_set_bit()` and recheck `tun_sock_writeable()`. [F710, F711]
- `__veth_xdp_flush()` must run `smp_mb()` after `xdp_ring` produce and before reading `rx_notify_masked`, pairing with `smp_store_mb(rq->rx_notify_masked, false)` before `!__ptr_ring_empty(&rq->xdp_ring)` in `veth_poll()`. In `veth_poll()`, `xdp_set/clear_return_frame_no_direct()` must bracket both `veth_xdp_rcv()` and `veth_xdp_flush()`. [F712, F843]
- On `NETDEV_TX_BUSY` in `veth_xmit()` (with qdisc queue), restore `__skb_push(skb, ETH_HLEN)`, call `netif_tx_stop_queue(txq)`, `smp_mb__after_atomic()`, and `netif_tx_wake_queue(txq)` if `__ptr_ring_empty(&rq->xdp_ring)`. `rq->stats.vs` accesses require `rq->stats.syncp`. [F842, F844]
- In `pptp.c`, `add_chan()` / `del_chan()` require `chan_lock`, `lookup_chan()` requires `rcu_read_lock()` through `sock_hold()`, and `pptp_release()` must run `del_chan(po)` and `synchronize_rcu()` before `pppox_unbind_sock(sk)` and `sk->sk_state = PPPOX_DEAD` (checked by `pptp_sock_destruct()`). [F699, F715]
- `sl_encaps()` must `set_bit(TTY_DO_WRITE_WAKEUP, &sl->tty->flags)` before `tty->ops->write()`. Process/workqueue callers in `slip.c` must use `spin_lock_bh(&sl->lock)`. [F716, F845]
- In `plip_send_packet()`, after unlocking `nl->lock` for `DISABLE(dev->irq)` and `synchronize_irq()`, recheck `nl->connection == PLIP_CN_RECEIVE` (`ENABLE(dev->irq)` on collision); `plip_bh_timeout_error()` must call `DISABLE(dev->irq)` only on `HS_TIMEOUT`. With `dev->irq == -1`, `plip_close()` must set `nl->kill_timer = 1` and wait on `killed_timer_cmp` before releasing `pardev` and SKBs. [F718, F820]
- Non-IRQ callers in `rionet.c` must take `rnet->tx_lock` and `nets[netid].lock` with `spin_lock_irqsave()`, and `rionet_outb_msg_event()` must use `dev_kfree_skb_irq()`. [F849]

## Object Lifetimes

- In `tun_recvmsg()` and `tun_do_read()`, a non-NULL `msg_control` / `ptr` must be freed via `tun_ptr_free()`, `xdp_return_frame()`, or `kfree/consume_skb()` on every exit path. In `tun_build_skb()`, on `XDP_REDIRECT` / `XDP_TX`, a negative `tun_xdp_act()` error must call `put_page(alloc_frag->page)`. [F684, F692]
- `tun_file` gets one `sk` ref from `sk_alloc()` (dropped on `tun_chr_close()`) and a second from `sock_hold()` on initial `tun_attach()`, kept while detached and dropped only on clean detach. `TUNSETPERSIST` calls `__module_get(THIS_MODULE)` only on 0-to-1 transitions, paired with `module_put()` when cleared or in `tun_detach_all()`. [F688, F689]
- On failure, `veth_convert_skb_to_xdp_buff()` calls `consume_skb(skb)` and sets `*pskb = NULL`. In `veth_xdp_rcv_skb()`, `XDP_TX` / `XDP_REDIRECT` call `veth_xdp_get(xdp)` and `consume_skb(skb)`, so later failures must jump to `err_xdp` (`xdp_return_buff(xdp)`), not `xdp_drop`. `veth_napi_del_range()` must clear `rq->napi = NULL`, disable/del NAPI, and call `synchronize_net()` before `ptr_ring_cleanup()` and `page_pool_destroy()`. [F693, F694, F840]
- `pfcp_newlink()` must bind `pfcp->net` and `pfcp->list` to `rtnl_newlink_link_net(params)`, and if `register_netdevice()` fails, call `pfcp_del_sock(pfcp)` and clear `pfcp->net = NULL`. [F700, F853]
- `slip_close()` must clear `tty->disc_data` and `sl->tty` under `spin_lock_bh(&sl->lock)`, then run `synchronize_rcu()`, `flush_work(&sl->tx_work)`, and `timer_delete_sync()` on both timers before `unregister_netdev(sl->dev)` (which frees `sl->dev`; pre-registration failure in `slip_open()` must call `sl_free_netdev()` before `rtnl_unlock()` and `free_netdev()` after). SLIP buffers and `slcomp` must be swapped with `xchg()` and freed outside `sl->lock`. [F702, F703, F829]
- `plip_wakeup()` must not call `parport_claim()` if `!(dev->flags & IFF_UP)`. When `nl->connection != PLIP_CN_NONE`, `plip_preempt()` must set `should_relinquish = 1` and return `1` until `plip_connection_close()`. `bcm5421_init()` must pair `of_get_parent()` with `of_node_put()`. `rionet_remove_dev()` must not send `RIONET_DOORBELL_LEAVE` if `rdev->state` is `GONE` or `INITIALIZING`, and must call `rio_release_outb_dbell()` outside `nets[netid].lock` before `kfree(peer)`. [F818, F819, F825, F827]

## API Contracts

- `tun_build_skb()` returns `ERR_PTR(err)`, `NULL` (XDP drop/consume), or `sk_buff *`; `tun_get_user()` must check `PTR_ERR_OR_ZERO(skb)` first. `tun_net_xmit()` must call `skb_orphan_frags_rx()`, `skb_tx_timestamp()`, `skb_orphan()`, and `nf_reset_ct()` before `tx_ring` enqueue. `tun_get_socket()` and `tun_get_tx_ring()` must check `file->f_op == &tun_fops`. [F719, F857, F862]
- `veth_newlink()` must use `rtnl_newlink_peer_net(params)`. `veth_xdp_rcv()` must check `skb_shared(skb) || skb_unclone(skb, GFP_ATOMIC)` before `napi_gro_receive()`, falling back to `netif_receive_skb()`. `pptp_xmit()` must call `pskb_may_pull(skb, 3)` after `skb_realloc_headroom()` before reading `skb->data`. [F732, F851, F868]
- Under `CONFIG_INET`, `slhc_init()` requires slots in `[0, 255]` and returns `ERR_PTR` on error (`slhc_free()` accepts `IS_ERR_OR_NULL()`). Callers of `mii_ethtool_gset()` / `mii_ethtool_get_link_ksettings()` must zero-init output structs; `generic_mii_ioctl()` must init `*duplex_chg_out = 0`; `MII_CTRL1000`/`MII_STAT1000` require `mii->supports_gmii` and `MII_ESTATUS` requires `BMSR_ESTATEN`. `bsd_compress()` must accept `obuf == NULL` and return `0` if incompressible; `bsd_decompress()` returns `DECOMP_ERROR` on seq mismatch and `DECOMP_FATALERROR` on mid-packet `CLEAR`, bad code, or MRU overflow. [F733, F736, F738, F821]

## Error Handling

- In `tun_attach_filter()`, failure at queue `i` must call `tun_detach_filter(tun, i)`. `tun_get_user()` must `memset(&hdr, 0, sizeof(hdr))`, and `__tun_vnet_hdr_put()` must zero trailing bytes past `tun_vnet_parse_size(features)` with `iov_iter_zero()`. [F690, F724]
- Readers of `veth` `priv->peer` must null-check `peer` and derived queues. `veth_xdp_set()` error paths must jump to `err` to restore `priv->_xdp_prog = old_prog`. In `veth_newlink()`, `register_netdevice(peer)` failure calls `free_netdev(peer)`, while later failures call `unregister_netdevice()`. In `veth_set_channels()`, `revert:` must swap `new_rx_count` and `old_rx_count` before `veth_disable_range_safe()`. [F696, F697, F728, F731]
- In `pptp_xmit()`, errors before a valid `rt` jump to `tx_drop` (`kfree_skb()`), while errors after obtaining `rt` (before `skb_dst_set()`) jump to `tx_error` (`ip_rt_put(rt)`). `sungem_phy_probe()` must not `memset(phy)` on entry, but must zero `speed`, `duplex`, `pause`, and `advertising` on failure. [F698, F737]

## External Contracts

- `__tun_chr_ioctl()` must copy `ifreq` using `ifreq_len`, zero-init `ifr` when not copied, NUL-terminate `ifr.ifr_name[IFNAMSIZ - 1]` before `tun_set_iff()`, and in `TUNSETLINK` reject `IFF_UP` (`-EBUSY`) and wrap type/addr_len updates with `NETDEV_PRE/POST_TYPE_CHANGE`. 16-bit `virtio_net_hdr` fields must use `tun_vnet16_to_cpu()` / `cpu_to_tun_vnet16()`. `tun_not_capable()` denies only when owner or group check fails and `!ns_capable(..., CAP_NET_ADMIN)`. [F723, F761, F814, F852, F863]
- `generic_mii_ioctl()` must mask `phy_id` and `reg_num` with `phy_id_mask` and `reg_num_mask`. `sl_siocdevprivate()` and `plip_siocdevprivate()` must reject `in_compat_syscall()` with `-EOPNOTSUPP`. [F775, F777]

## Known Pitfalls

- In `tun_xdp_one()`, `metasize = xdp->data - xdp->data_meta` must be signed `int` checked with `> 0`. When `hdr->gso_type != 0`, skip `bpf_prog_run_xdp()` and run `do_xdp_generic()` after `tun_vnet_hdr_tnl_to_skb()`. `tun_napi_alloc_frags()` loop `i = 1..nr_segs-1` must use `iter_iov(it) + i` and fragment `i - 1`. [F725, F778, F858]
- `veth_enable_xdp_range()` saves `rq->xdp_rxq.mem` in `rq->xdp_mem`, and `veth_xdp_rcv_skb()` (`XDP_TX`/`XDP_REDIRECT`) and `veth_disable_xdp_range()` must restore `rq->xdp_rxq.mem = rq->xdp_mem`. `__veth_napi_enable_range()` must reset `i = end` between `err_xdp_ring:` and `err_page_pool:`. `veth_get_ethtool_stats()` must accumulate peer TX stats with `+=` at `idx + (i % dev->real_num_tx_queues) * VETH_TQ_STATS_LEN`. `veth_newlink()` must read peer attrs from `tbp` (`peer_tb`). [F784, F785, F786, F866]
- `slhc_uncompress()` callers must ensure `count + 80 <= sl->buffsize`. `sl_bump()` must test `c & SL_TYPE_COMPRESSED_TCP` (`0x80`) before `c >= SL_TYPE_UNCOMPRESSED_TCP` (`0x70`). `slhc_compress()` must compute `deltaA`/`deltaS` in 32-bit unsigned arithmetic before checking `> 0x0000ffff`. `mii_link_ok()` and `genmii_poll_link()` must read `MII_BMSR` twice. [F767, F790, F797, F822]

## Other

- `bcm5221_init()` and `bcm5241_init()` must set `MII_BCM5221_TEST_ENABLE_SHADOWS` in `MII_BCM5221_TEST` before accessing shadow registers and clear it before returning. [F824]
