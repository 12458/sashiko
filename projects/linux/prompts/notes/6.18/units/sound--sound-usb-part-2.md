# SOUND — sound/usb (part 2)

Implements the ALSA USB audio mixer, PCM substream operations, UAC3 power domains, procfs diagnostics, and vendor mixer quirks.

## Architecture & Data Flow
- For multi-channel `usb_mixer_elem_info` (`cval->cmask != 0`), `BIT(c)` in `cmask` and `ch_readonly` maps to 1-based USB `channel = c + 1` and `BIT(c + 1)` in `cval->cached`, while `cval->cache_val[idx]` uses the dense 0-based count of set bits in `cmask`. In `restore_mixer_value()`, `idx` must increment for every set bit in `cval->cmask` even when `!(cval->cached & BIT(c + 1))`. [F350, F366]
- In `snd_usb_create_mixer()`, add `mixer->list` to `chip->mixer_list` only after `snd_usb_mixer_apply_create_quirk()` and `snd_device_new()`, because quirks like `snd_sc1810_init_mixer()` check `list_empty(&chip->mixer_list)` to run once on the first mixer. [F297]
- Validate raw UAC descriptors via `snd_usb_validate_audio_desc(p, protocol)` before accessing protocol-specific fields or variable arrays. `parse_audio_unit()` and `snd_usb_mixer_controls()` must mark visited IDs in `state.unitbitmap`, and `check_input_term()` must zero `state->termbitmap` before `__check_input_term()` uses `test_and_set_bit(id, state->termbitmap)` to reject cycles with `-EINVAL`. [F347, F362, F364]
- In `parse_audio_feature_unit()`, `bmaControls` index `0` is the master mask and `bmaControls + csize * (j + 1)` is 0-based channel `j`; build per-channel controls via `build_feature_ctl()` only when `ch_bits & 1` is set. [F352]
- In `get_ctl_value_v1()`/`get_ctl_value_v2()`, pass `snd_usb_combine_bytes()` through `convert_signed_value()`, and in UAC2 `UAC2_CS_RANGE` skip the 2-byte `sizeof(__u16)` count header before reading `MIN`/`MAX`/`RES` at `val_size` strides. In `get_min_max_with_quirks()`, save/restore the current value via `get_cur_mix_raw()` / `snd_usb_set_cur_mix_value()` around resolution probing, pass `cval->min`/`max` through `convert_signed_value()` before computing `dBmin`/`dBmax`, and keep `cval->res` non-zero (while `get_relative_value()`, `get_abs_value()`, and `get_max_exposed()` guard against `cval->res == 0`). When lazy init in `mixer_ctl_feature_info()` finds `dBmin >= dBmax`, clear TLV access flags and emit `SNDRV_CTL_EVENT_MASK_INFO`. [F334, F336, F356, F371, F373]
- In `snd_usb_mixer_notify_id()` and `snd_usb_mixer_interrupt_v2()`, clear `info->cached` (or `BIT(channel)` for per-channel `UAC2_CS_CUR`) before `snd_ctl_notify()`. [F331]
- Every `USB_MIXER_*` enum in `mixer.h` needs a designated entry in `snd_usb_mixer_dump_cval()`'s `val_types[]`, and `restore_mixer_value()` must skip `USB_MIXER_BESPOKEN`. Static lookup tables (`usbmix_name_map`, `usbmix_selector_map`, `usbmix_connector_map`, `usbmix_ctl_map`, `procunit_info`, `procunit_value_info`, `std_mono_table`) must end with a zero sentinel. [F337, F355]
- In `mixer_quirks.c`, every `SND_DJM_*_IDX` needs a `[SND_DJM_*_IDX] = SND_DJM_DEVICE(...)` entry in `snd_djm_devices[]` and handling in `snd_djm_get_label_cap()` / `snd_djm_get_label_caplevel()`. DJM models with distinct capture level options (DJM-A9, DJM-V10) must use dedicated arrays (`snd_djm_opts_a9_cap_level`, `snd_djm_opts_v10_cap_level`) rather than appending to `snd_djm_opts_cap_level`. [F338, F390]
- In `mixer_us16x08.c`, `comp_msg` and `eqs_msq` overwrite all channel/band parameters at once, so `snd_us16x08_comp_put()`, `snd_us16x08_eq_put()`, and `snd_us16x08_eqswitch_put()` must populate all sibling parameters (and all `SND_US16X08_ID_EQ_BAND_COUNT` bands) from `comp_store`/`eq_store`. EQ callbacks subtract 1 from `EQ_STORE_BAND_IDX(elem->head.id)` to index `eq_store->val`; compressor callbacks use `COMP_STORE_IDX(elem->head.id)`. [F340, F353]
- In PCM hw_params rules (`hw_rule_rate`, `hw_rule_format`, `hw_rule_period_size_implicit_fb`, `hw_rule_periods_implicit_fb`), `get_endpoint_in_use()` must pass `subs->data_endpoint` or `subs->sync_endpoint` as `ref_ep` so an assigned endpoint only constrains parameters when `ep->opened > 1`. [F343]
- In `snd_usb_pcm_prepare()`, early `start_endpoints(subs)` when `!subs->lowlatency_playback` must check `substream->stream == SNDRV_PCM_STREAM_PLAYBACK`. In `snd_usb_substream_playback_trigger()`, `SNDRV_PCM_TRIGGER_START` must re-check `in_free_wheeling_mode(substream->runtime)` and clear `subs->lowlatency_playback = false` before `start_endpoints(subs)`. [F344, F359]
- Pass `urb_ctx_queue_advance()` only consumed PCM DMA bytes (excluding DSD DoP markers or `copy_to_urb_quirk()` headers). In `prepare_playback_urb()`, guard the packet-loop break on `period_elapsed || transfer_done >= frame_limit` with `!snd_usb_endpoint_implicit_feedback_sink(ep)`. Because `runtime->dma_area` uses vmalloc/SG, `copy_to_urb()` and `retire_capture_urb()` must `memcpy` via `urb->transfer_buffer`, splitting wraps where `hwptr_done + bytes > subs->buffer_bytes`. `snd_usb_pcm_delay()` must mask `(current_frame_number - subs->last_frame_number) & 0xff`. [F345, F354, F369, F375, F412]

## Synchronization
- Runtime ALSA PCM and mixer callbacks doing USB transfers or endpoint reconfigurations must guard access with `snd_usb_lock_shutdown(chip)` (or `CLASS(snd_usb_lock, pm)(chip)`). `chip->mutex` protects `subs->opened` and `subs->cur_audiofmt` (including in `proc_dump_substream_status()`), and must be released before calling `snd_usb_lock_shutdown()`, `snd_usb_autoresume()`, or `snd_usb_autosuspend()`. [F305, F408]
- `subs->lock` protects `hwptr_done`, `transfer_done`, `inflight_bytes`, `last_frame_number`, and `period_elapsed_pending` in `retire_capture_urb()`, `retire_playback_urb()`, and `prepare_playback_urb()`, and must be held across reading `hwptr_done` and `snd_usb_pcm_delay()` in `snd_usb_pcm_pointer()`. Release `subs->lock` before `snd_pcm_period_elapsed()` or (when `in_stream_lock`) `snd_pcm_period_elapsed_under_stream_lock()`. If a period elapses in `prepare_playback_urb()` while `!subs->running && subs->lowlatency_playback`, set `subs->period_elapsed_pending = 1` so `retire_playback_urb()` fires it after `subs->running` becomes 1. [F300, F301, F302, F346]
- `snd_usb_pcm_playback_ack()` must pass `in_stream_lock = true` to `snd_usb_queue_pending_output_urbs()` and return its result directly so `-EPIPE` is handled by the PCM core without calling `snd_pcm_xrun()` under the stream lock. [F299]
- In `snd_usb_substream_playback_trigger()`, `SNDRV_PCM_TRIGGER_START` falls through to `SNDRV_PCM_TRIGGER_PAUSE_RELEASE`; when `subs->lowlatency_playback` is set and `cmd == SNDRV_PCM_TRIGGER_START`, call `snd_usb_endpoint_set_callback()` before `start_endpoints(subs)` and reset callbacks to `NULL` if `start_endpoints(subs)` fails. [F303, F361]
- `start_endpoints()` and `stop_endpoints()` must track endpoint started state with `test_and_set_bit()` / `test_and_clear_bit()` on `subs->flags`. On `snd_usb_endpoint_start()` failure in `start_endpoints()`, clear that endpoint's bit and call `stop_endpoints(subs, false)`. Callers closing or restarting stopped endpoints (`snd_usb_hw_params()`, `snd_usb_hw_free()`, `snd_usb_pcm_prepare()`) must call `sync_pending_stops(subs)` first. [F286, F304]
- Initialize `list->kctl`, `list->is_std_info`, and `list->next_id_elem` before setting `mixer->id_elems[list->id] = list` in `snd_usb_mixer_add_list()`. In `snd_usb_soundblaster_remote_init()`, call `init_waitqueue_head(&mixer->rc_waitq)` before `snd_hwdep_new()`, and consume `mixer->rc_code` via `xchg(&mixer->rc_code, 0)` in `snd_usb_sbrc_hwdep_read()`. In `snd_us16x08_controls_create()`, set `meter_store->comp_store = comp_store` before `add_new_ctl()` registers `snd_us16x08_meter_ctl`. [F308, F309, F312]
- `snd_usb_mixer_suspend()` must call `snd_usb_mixer_inactivate()` (`usb_kill_urb()` on `mixer->urb` and `mixer->rc_urb`) before `mixer->private_suspend(mixer)`. `snd_usb_mixer_activate()` resubmits `mixer->urb` with `GFP_NOIO`, whereas interrupt handlers (`snd_usb_mixer_interrupt()`, `snd_usb_mixer_rc_memory_change()`) must use `GFP_ATOMIC` and skip resubmission on `-ENOENT`, `-ECONNRESET`, or `-ESHUTDOWN`. [F401, F402, F406]
- In `snd_sc1810_init_mixer()`, initialize `data_mutex`, `usb_mutex`, `seqnum`, and `mixer->private_data` before `snd_s1810c_switch_init()`. Switch callbacks must lock `data_mutex` before `usb_mutex` and hold `usb_mutex` across `snd_sc1810c_get_status_field()`, which sends an empty `SC1810C_SET_STATE_REQ` then `SC1810C_GET_STATE_REQ` with the same `*seqnum` in `wValue` before incrementing `(*seqnum)++`. [F311, F339]

## Object Lifetimes
- `snd_usb_pcm_open()` must call `snd_usb_autosuspend()` if `snd_media_stream_init()` fails and reset `subs->opened = 0` under `chip->mutex` on any failure after setting `subs->opened = 1`. [F288]
- In `snd_usb_mixer_disconnect()` and `snd_usb_mixer_free()`, call `usb_kill_urb()` on `mixer->urb` and `mixer->rc_urb` before `mixer->private_free(mixer)` or freeing `id_elems`, URB buffers, and `mixer`. If `snd_usb_soundblaster_remote_init()` or `snd_usb_mixer_status_create()` frees `rc_urb` or `urb` on error, it must reset the pointer to `NULL`. [F306, F320]
- In `usb_mixer_selector_elem_free()`, read `cval->max` (count of `namelist` strings at `kctl->private_value`) from `kctl->private_data` before freeing `kctl->private_data` and `kctl->private_value`. When multiple kcontrols share `comp_store` or `eq_store` in `snd_us16x08_controls_create()`, only one may set `kctl->private_free = elem_private_free` (`do_private_free = true`); all others must use `snd_usb_mixer_elem_free`. [F292, F386]
- In `snd_dualsense_jack_create()`, `snd_usb_mixer_add_control()` must precede `input_register_handler(&mei->ih)` (clearing `mei->ih.event = NULL` on failure), and `snd_dualsense_mixer_elem_free()` must call `input_unregister_handler(&mei->ih)` before `snd_usb_mixer_elem_free(kctl)`. In `snd_dualsense_ih_connect()`, if `input_open_device(handle)` fails, call `input_unregister_handle(handle)` before `kfree(handle)`. [F296, F310]

## API Contracts
- `snd_usb_mixer_add_list()` and `snd_usb_mixer_add_control()` transfer ownership of `kctl` and `kctl->private_data` to ALSA via `snd_ctl_add()` on both success and failure; set `kctl->private_free` beforehand and never free `kctl`, `cval`, `elem`, or `list` on error. Pass `is_std_info = false` for a bare `usb_mixer_elem_list` (e.g., `add_single_ctl_with_resume()`), never use `usb_mixer_elem_info` callbacks (like `snd_usb_mixer_vol_tlv()`) on it, and check `list->is_std_info` before `mixer_elem_list_to_info(list)`. [F289, F351, F378]
- Buffers passed to `usb_fill_int_urb` or `usb_fill_control_urb` must be heap-allocated, and stack-buffer callers must use `snd_usb_ctl_msg()` instead of `usb_control_msg()`. Any `data` buffer passed to `snd_usb_ctl_msg()` (or `snd_us16x08_send_urb()`) with `size > 0` must be writable (never `const` `.rodata`), even for `USB_DIR_OUT`, because `snd_usb_ctl_msg()` always runs `memcpy(data, buf, size)`. [F376, F411]
- Both `snd_usb_hw_params()` and `snd_usb_pcm_prepare()` must set UAC3 power state `UAC3_PD_STATE_D0` via `snd_usb_pcm_change_state()` before configuring/preparing endpoints (`close`/`resume` set `D1`; `suspend` sets `D2`). Configure and prepare `subs->sync_endpoint` before `subs->data_endpoint`, and pass `is_sync_ep` as `fmt == sync_fmt` to `snd_usb_endpoint_open()`. In `snd_usb_pcm_prepare()`, `snd_usb_endpoint_prepare()` returns `> 0` when reconfigured (requiring `snd_usb_set_format_quirk()`), so reset `ret = 0` afterward. [F327, F329, F397, F398]
- `snd_usb_find_power_domain()` returns a newly `kzalloc`-allocated `snd_usb_power_domain` on match (caller must `kfree()`, as `free_substream()` does for `subs->str_pd`) and frees internally before returning `NULL` on mismatch. `snd_usb_pcm_has_fixed_rate()` and `find_format()` accept a nullable `subs` and must check `if (subs)` before dereferencing it. [F298, F315]
- For low-latency playback (`as->chip->lowlatency`), `snd_usb_pcm_open()` must set `SNDRV_PCM_INFO_SYNC_APPLPTR` (not `SNDRV_PCM_INFO_EXPLICIT_SYNC`). In `snd_usb_pcm_pointer()`, return `SNDRV_PCM_POS_XRUN` immediately if `atomic_read(&subs->stream->chip->shutdown)` is set. [F413, F415]
- `get_max_exposed()` and the `val >= cval->max` branch of `get_relative_value()` must use `DIV_ROUND_UP(cval->max - cval->min, cval->res)`. `snd_usb_mixer_vol_tlv()` must convert UAC 1/256 dB values to ALSA 1/100 dB TLV units, return `-ENOMEM` if `size < sizeof(scale)`, and use `SNDRV_CTL_TLVT_DB_MINMAX_MUTE` when `cval->min_mute` is set. [F372, F418]

## Error Handling
- If `snd_usb_hw_params()` fails after `snd_media_start_pipeline(subs)` succeeds, it must call `close_endpoints(chip, subs)` (if `snd_usb_lock_shutdown(chip)` succeeded), `snd_usb_unlock_shutdown(chip)`, and `snd_media_stop_pipeline(subs)`. In `snd_usb_pcm_prepare()`, when `start_endpoints(subs)` returns `-EPIPE`, bound the `again:` retry to one attempt via `!retry++` and call `sync_pending_stops(subs)` before re-running `snd_usb_endpoint_prepare()`. [F285, F360]
- In `retire_capture_urb()`, log ISO packet status errors and misaligned lengths with `dev_dbg_ratelimited()` / `dev_warn_ratelimited()` and truncate to whole frames (`frames * stride`) without `WARN_ON()` or aborting the loop. [F422]
- Because `filter_error(cval, err)` returns `0` when `ignore_ctl_error` is set, helpers and `.get` callbacks returning `filter_error()` (`get_connector_value()`, `mixer_ctl_feature_get()`, `mixer_ctl_procunit_get()`, `mixer_ctl_selector_get()`) must initialize output values on or before the error path. Similarly, `snd_us16x08_recv_urb()` ignores `snd_usb_ctl_msg()` errors and returns `0`, so callers like `snd_us16x08_meter_get()` must zero-initialize the buffer beforehand. In `restore_mixer_value()` and `connector_mixer_resume()`, ignore USB transfer errors and return `0` so `snd_usb_mixer_resume()` proceeds to `snd_usb_mixer_activate()`. [F316, F319, F400]

## External Contracts
- In `snd_usb_audioformat_set_sync_ep()`, return early if `fmt->sync_ep` is set, `snd_usb_parse_implicit_fb_quirk() > 0`, or `fmt->ep_idx > 0`. Verify `bLength >= USB_DT_ENDPOINT_AUDIO_SIZE` before reading `bSynchAddress` on endpoint 0 or 1, and when `is_playback && attr == USB_ENDPOINT_SYNC_NONE`, return `0` instead of `-EINVAL` if endpoint 1 fails sync validation. [F328, F388, F389]
- UAC unit control requests (`UAC_GET_*`, `UAC_SET_*`, `UAC2_CS_*`) must encode `wValue` (`validx`) as `(control << 8) | channel`. In `snd_usb_set_cur_mix_value()`, check `cval->master_readonly` (channel 0) or `cval->ch_readonly & BIT(channel - 1)` (1-based channels) and return `0` without writing if read-only. In `get_ctl_value_v1()` and `snd_usb_mixer_set_ctl_value()`, retry loops must abort immediately on `-ETIMEDOUT`. [F318, F393, F394]

## Known Pitfalls
- Because `__check_input_term()` mutates `struct usb_audio_term *term` during recursion, callers (`parse_term_uac2_iterm_unit()`, `parse_term_uac3_iterm_unit()`, `parse_term_selector_unit()`, `parse_term_proc_unit()`, `parse_term_effect_unit()`) must assign `term->id` and `term->type` after `__check_input_term()` returns. [F335]
- In `parse_audio_mixer_unit()`, `num_ins` accumulates `iterm.channels` across all `input_pins` and `ich` is initialized to 0 once before the outer `pin` loop, advancing without resetting per pin. Mixer `bmControls` are unaligned MSB-first byte arrays (`0x80 >> (idx & 7)`) and must be checked via `mixer_bitmap_overflow()` and read via `check_matrix_bitmap()`, never `unsigned long *` bitmap ops. [F368, F383]
- Cast 8-bit `u8`/`unsigned char` values to `unsigned long` or `unsigned int` before shifting left by 24 (`SND_DJM_DEVICE_SHIFT` or `24`) into `private_value` (`snd_djm_controls_create()`, `snd_ni_control_init_val()`) to avoid sign-extending bit 31. Use `__be32` / `__le32` rather than `u32` for fixed-endianness USB payload buffers. In `snd_rme_current_freq_get()`, check `den == 0` and use `div64_u64(num, den)`. In `snd_dualsense_ih_match()`, `usb_dev_path[usb_dev_path_len] = '/'` overwrites the NUL terminator, so only access `usb_dev_path` with explicit length `usb_dev_path_len + 1`. [F357, F370, F374, F382]
