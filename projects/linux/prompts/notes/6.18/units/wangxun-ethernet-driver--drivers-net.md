# WANGXUN ETHERNET DRIVER — drivers/net

10/25/40GbE PF/VF PCI Ethernet drivers (`txgbe`, `txgbevf`) and XPCS helper (`pcs-xpcs-wx.c`) for WangXun Sapphire (SP1000/WX1820) and Amber Lite (AML50xx/51xx) controllers. Built on `libwx`, `txgbe` adds Flow Director, UDP tunnel offload, misc IRQ domains, swnodes for I2C/GPIO/SFP/phylink, and XPCS SERDES setup.

## Architecture & Data Flow

- On `wx_mac_aml40`, `txgbe_init_phy()` and `txgbe_setup_misc_irq()` skip creating `wx->phylink` and `txgbe->misc.domain` (though `txgbe_setup_misc_irq()` sets `wx->misc_irq_domain = true` on all MACs and skips `txgbe_request_gpio_irq()` on `wx_mac_sp`). Thus `txgbe_up_complete()`, `txgbe_down()`, `txgbe_remove_phy()`, `txgbe_free_misc_irq()`, and `txgbe_get_link_ksettings()` must guard against `wx_mac_aml40`, and `txgbe_free_misc_irq()` must only free `txgbe->gpio_irq` on `wx_mac_aml`. In `txgbe_link_irq_handler()`, check `if (txgbe->pcs)` (NULL on `wx_mac_aml` and copper `wx_mac_sp`) to choose `phylink_pcs_change()` vs `phylink_mac_change()`. [F204, F205, F281]
- Helpers shared with `txgbevf` or called in `txgbe_probe()` before `wx->priv = txgbe` (`txgbe_sw_init()`, `txgbe_reset_hw()`, `txgbe_validate_eeprom_checksum()`, `txgbe_init_service()`, `txgbe_test_hostif()`) must never dereference `wx->priv` (NULL until `txgbe` is allocated and always NULL in `txgbevf`). [F268]
- In `txgbe_irq_enable()`, `txgbe_misc_irq_handle()`, and `txgbe_misc_irq_thread_fn()`, queue IRQs use bits `0..wx->num_q_vectors - 1` (`TXGBE_INTR_QALL(wx)`) and the misc IRQ uses bit `wx->num_q_vectors` (`TXGBE_INTR_MISC(wx)`). `txgbe_misc_irq_handle()` must save `wx_misc_isb(wx, WX_ISB_MISC)` into `txgbe->eicr` and, when `!wx->pdev->msix_enabled`, zero `wx->isb_mem[WX_ISB_VEC0]` before returning `IRQ_WAKE_THREAD`. [F228, F240]
- Whenever the MAC is reset/reconfigured on link-up (`txgbe_mac_link_up_aml()` after `txgbe_reconfig_mac()`, `txgbe_mac_finish()` after `txgbe_mac_prepare()`, and `txgbe_up_complete()` on `wx_mac_aml40`), call `txgbe_enable_sec_tx_path(wx)` to clear `WX_TSC_CTL_TX_DIS` and flush. `txgbe_reconfig_mac()` must save and restore `WX_MAC_WDG_TIMEOUT` and `WX_MAC_RX_FLOW_CTRL` across `TXGBE_MIS_RST_MAC_RST(wx->bus.func)` / `wx_reset_mac(wx)`. [F226, F284]
- Both phylink MAC ops tables (`txgbe_mac_ops`, `txgbe_mac_ops_aml`) must set `wx->speed` (`speed` on link up, `SPEED_UNKNOWN` on link down), call `wx_ptp_reset_cyclecounter(wx)` when `WX_STATE_PTP_RUNNING`, and call `wx_ping_all_vfs_with_link_status()`. In `txgbe_xpcs_switch_mode()`, check `if (xpcs->interface == interface && !txgbe_xpcs_mode_quirk(xpcs))` before assigning `xpcs->interface = interface` so `txgbe_xpcs_mode_quirk()` catches `MDIO_CTRL2` resets. [F233, F250]
- `txgbe_setup_link()` must zero `txgbe->sfp_interfaces` and `txgbe->sfp_support` before `txgbe_identify_sfp(wx)` so `txgbe_sfp_to_linkmodes()` detects a mode change, updates `sfp_support`/`sfp_interfaces`/`advertising`, and sets `WX_FLAG_NEED_LINK_CONFIG`. In `txgbe_get_phy_link()`, test `!(status & TXGBE_CFG_PORT_ST_LINK_UP)` before `TXGBE_CFG_PORT_ST_LINK_AML_25G`/`10G` so `txgbe_get_link_state()` reports `SPEED_UNKNOWN` when link is down. [F230, F253]
- Each `struct txgbe` must populate its own embedded `struct txgbe_nodes` (`nodes->group` sized `SWNODE_MAX + 1` with `nodes->group[SWNODE_MAX] == NULL`) and qualify swnode names, `mii_bus->id`, GPIO labels, clkdev names, and `i2c_designware`/`sfp` platform device IDs with `pci_dev_id(pdev)`. [F231, F241]
- `txgbe_add_ethtool_fdir_entry()` must bound `fsp->location < (1024 << TXGBE_FDIR_PBALLOC_64K) - 2` before narrowing to `input->sw_idx` (`u16`), validate `vf <= wx->num_vfs` and `ring < wx->num_rx_queues_per_pool` when `vf` is non-zero before computing `queue = ((vf - 1) * wx->num_rx_queues_per_pool) + ring`, and only update `txgbe->fdir_mask` / call `txgbe_fdir_set_input_mask()` when `txgbe->fdir_filter_list` is empty (rejecting differing masks when non-empty). [F219, F261]
- Keep `txgbe->fdir_filter_list` sorted in ascending `rule->sw_idx` order via `txgbe_update_ethtool_fdir_entry()`; after `hlist_for_each_entry_safe(rule, ...)` in `txgbe_get_ethtool_fdir_entry()` and `txgbe_update_ethtool_fdir_entry()`, check `rule != NULL` before reading `rule->sw_idx`. [F236, F248]
- Zero-initialize `union txgbe_atr_input` instances passed to `txgbe_atr_compute_perfect_hash()` and `txgbe_fdir_write_perfect_filter()` before setting IPv4 fields (all 11 `dword_stream` words are hashed and `src_ip[0..2]` written to `TXGBE_RDB_FDIR_IP6(0..2)`). In `txgbe_atr()`, zero-initialize `union txgbe_atr_hash_dword` locals `input` and `common` (`.dword = 0`) and check `ring->q_vector != NULL`. [F210, F211]
- In `TXGBE_COMPUTE_SIG_HASH_ITERATION`, test `TXGBE_ATR_COMMON_HASH_KEY` before `TXGBE_ATR_BUCKET_HASH_KEY` and `TXGBE_ATR_SIGNATURE_HASH_KEY`. In `txgbe_atr_compute_sig_hash()` and `txgbe_atr_compute_perfect_hash()`, execute `lo_hash_dword ^= flow_vm_vlan ^ (flow_vm_vlan << 16)` after iteration 0 and before the `i = 1..15` loop. [F245, F260]
- In `txgbe_set_ringparam()`, when `!netif_running(wx->netdev)`, updating `wx->tx_ring_count` and `wx->rx_ring_count` must also update `wx->tx_ring[i]->count` and `wx->rx_ring[i]->count`. In `txgbe_disable_device()`, skip clearing `WX_MAC_TX_CFG_TE` when `wx->subsystem_device_id` has `WX_NCSI_SUP` or `WX_WOL_SUP`, and call `wx_control_hw(wx, false)` in `txgbe_dev_shutdown()` and `txgbe_close()`. [F229, F288]
- `txgbe_init_thermal_sensor_thresh()` must zero `wx->mac.sensor` on all functions but only program thermal registers (`TXGBE_TS_CTL`, `WX_TS_*`) when `wx->bus.func == 0`. `txgbe_enumerate_functions()` must return `-EINVAL` if any device on `&pdev->bus->devices` mismatches `pdev->vendor`/`device`, and `txgbe_probe()` must only call `txgbe_check_minimum_link(wx)` when `expected_gts > 0`. [F232, F255]

## Synchronization

- Hold `txgbe->fdir_perfect_lock` across all accesses/updates to `txgbe->fdir_filter_list`, `txgbe->fdir_filter_count`, and `txgbe->fdir_mask` in `txgbe_add_ethtool_fdir_entry()`, `txgbe_del_ethtool_fdir_entry()`, `txgbe_update_ethtool_fdir_entry()`, `txgbe_fdir_filter_restore()`, and `txgbe_fdir_filter_exit()`. [F190]
- `txgbe_fdir_check_cmd_complete()` must poll with `read_poll_timeout_atomic()` because it runs in softirq Tx (`txgbe_atr()` -> `txgbe_fdir_add_signature_filter()`) and under `txgbe->fdir_perfect_lock` (`txgbe_fdir_write_perfect_filter()`, `txgbe_fdir_erase_perfect_filter()`). Those two functions and `txgbe_fdir_enable()` must call `WX_WRITE_FLUSH(wx)` after writing `TXGBE_RDB_FDIR_HASH`/`CTL` before writing `TXGBE_RDB_FDIR_CMD` or polling. [F289, F297]
- Initialize `wx->gpio_lock` via `raw_spin_lock_init()` in `txgbe_gpio_init()` before `devm_gpiochip_add_data()`, and hold it via `raw_spin_lock_irqsave()` in `txgbe_gpio_direction_in()`/`out()` across `WX_GPIO_DR`/`DDR` `wr32m()` updates. [F198]
- Child IRQs in `txgbe->misc.domain` (`txgbe->link_irq`, `txgbe->gpio_irq`) use `irq_set_nested_thread(irq, true)` in `txgbe_misc_irq_domain_map()` and must be requested with `request_threaded_irq(..., NULL, thread_fn, IRQF_ONESHOT, ...)` and dispatched via `handle_nested_irq()` from `txgbe_misc_irq_thread_fn()`, never from `txgbe_misc_irq_handle()`. [F293]
- In `txgbe_up_complete()`, `smp_mb__before_atomic()` must precede `wx_napi_enable_all(wx)`. `txgbe_disable_device()` and `txgbe_down()` must stop Tx queues and call `wx_irq_disable()`, `wx_napi_disable_all()`, and `timer_delete_sync(&wx->service_timer)` before flushing hardware Tx queues and cleaning rings. [F201]

## Object Lifetimes

- `txgbe_sw_init()` (`wx->rss_key`, `wx->mac_table`) and `txgbevf_sw_init()` (plus `wx->vfinfo`) free their own allocations on internal failure; `txgbe_probe()` and `txgbevf_probe()` must jump to `err_pci_release_regions` when `*_sw_init()` fails, and unwind through `err_free_mac_table` / `err_free_sw_init` on later errors. [F177, F178]
- In `txgbe_probe()`, complete `txgbe_init_fdir()` and `txgbe_init_phy()` before `register_netdev()`. In `txgbe_remove()`, complete `cancel_work_sync(&wx->service_task)`, `wx_disable_sriov(wx)`, and `unregister_netdev(netdev)` before `txgbe_remove_phy(txgbe)` and `wx_free_isb_resources(wx)` (`wx->isb_mem` persists across `txgbe_close()`). [F182, F200]
- In `txgbe_open()` rollback and `txgbe_close()`, call `wx_free_irq(wx)` before `txgbe_free_misc_irq(wx->priv)` (`txgbe_free_misc_irq()` clears `wx->misc_irq_domain = false`, checked by `wx_free_irq()`). In `txgbe_open()`, failures after `txgbe_setup_misc_irq()` must unwind via `err_free_misc_irq` (`txgbe_free_misc_irq()` then `wx_reset_interrupt_capability()`) before `wx_free_resources()`. [F179, F180]
- In `txgbe_setup_misc_irq()` rollback and `txgbe_free_misc_irq()` (`wx_mac_sp`, `wx_mac_aml`), `free_irq()` `txgbe->gpio_irq` (on `wx_mac_aml`), `txgbe->link_irq`, and `txgbe->misc.irq` before `txgbe_del_irq_domain()`. [F181]
- For non-copper `wx_mac_sp`, `txgbe_init_phy()` rollback and `txgbe_remove_phy()` must release in reverse (LIFO) order: `txgbe->sfp_dev`, `txgbe->i2c_dev`, `txgbe->clock`/`clk`, `wx->phylink`, `txgbe->pcs`, `txgbe->nodes.group`. For copper `wx_mac_sp`, `txgbe_phylink_init()` calls `phylink_connect_phy()` (destroying `phylink` on failure), so `txgbe_remove_phy()` must call `phylink_disconnect_phy()` before `phylink_destroy()`. [F183, F184]
- In `txgbe_add_ethtool_fdir_entry()`, error paths before `txgbe_update_ethtool_fdir_entry()` links `input` must unlock `txgbe->fdir_perfect_lock` (if held) and `kfree(input)`. Linked entries persist across `txgbe_down()`/`up()` and are freed in `txgbe_close()` by `txgbe_fdir_filter_exit(wx)` (or individually by `txgbe_update_ethtool_fdir_entry()`), which under `txgbe->fdir_perfect_lock` must `hlist_del()`, `kfree()`, and update `txgbe->fdir_filter_count`. [F185, F186]
- In `txgbe_set_ringparam()` and `txgbe_reinit_locked()`, once `wx_set_state_reset(wx)` sets `WX_STATE_RESETTING`, every exit path must clear it. `txgbe_service_task()` must always call `wx_service_event_complete(wx)` before returning. `txgbe_calc_eeprom_checksum()` must `kvfree(eeprom_ptrs)` on all returns. [F187, F188, F189]

## API Contracts

- In `txgbe_phy.c`, MDIO (`mii_bus->priv`), GPIO (`gpiochip_get_data()`), and I2C regmap (`context`) callbacks store/cast `struct wx *`; in `txgbe_irq.c`, `txgbe->misc.domain` `host_data` and `misc.irq`/`link_irq`/`gpio_irq` handlers store/cast `struct txgbe *`. [F269]
- In `pcs-xpcs-wx.c`, `txgbe_write_pma()` and `txgbe_modify_pma()` add `TXGBE_PMA_MMD` (`0x8020`) in `MDIO_MMD_PMAPMD`, so pass only the relative offset (`0x11`..`0x76`). `txgbe_xpcs_switch_mode()` must only run in process context (`txgbe_pcs_poll_power_up()` and `txgbe_pma_init_done()` sleep). `txgbe_phylink_mac_select()` must return `txgbe->pcs` when `wx->media_type != wx_media_copper` and `NULL` when copper. [F216, F278, F298]
- Host interface structs (`txgbe_hic_ephy_getlink`, `txgbe_hic_i2c_read`, `txgbe_hic_ephy_setlink`) must be 4-byte (`u32`) padded, passing `sizeof(buffer)` to `wx_host_interface_command()` and `hdr.buf_len = sizeof(buffer) - sizeof(struct wx_hic_hdr)`. [F263]
- Call `txgbe_atr_compute_perfect_hash()` with `input_mask->formatted.bkt_hash == 0` before `txgbe_match_ethtool_fdir_entry()`, `txgbe_fdir_write_perfect_filter()`, or saving the rule. `rule->action` holds the raw `ring_cookie`, whereas `txgbe_fdir_write_perfect_filter()` requires `queue` mapped to the hardware index (`wx->rx_ring[ring]->reg_idx` for PF, `((vf - 1) * wx->num_rx_queues_per_pool) + ring` for VF). [F220, F302]
- In `txgbe_flowspec_to_flow_type()`, mask `fsp->flow_type` with `~FLOW_EXT` before switching, and under `IP_USER_FLOW` only accept `proto == 0` (`TXGBE_ATR_FLOW_TYPE_IPV4`) when `fsp->m_u.usr_ip4_spec.proto == 0`. [F249]
- In `txgbe_set_ringparam()`, allocate `temp_ring` with `max(wx->num_tx_queues, wx->num_rx_queues)` elements of `sizeof(struct wx_ring)` (not pointer size). In `txgbe_udp_tunnel_sync()`, convert `ti.port` with `ntohs()` before writing `TXGBE_CFG_VXLAN`/`VXLAN_GPE`/`GENEVE`. Verify `_i < 2` before `TXGBE_MIS_PRB_CTL_LAN_UP(_i)` (`BIT(1 - (_i))`), and check `if (checksum_val)` in `txgbe_validate_eeprom_checksum()`. [F209, F257, F264, F304]

## Error Handling

- In `txgbe_phy.c` and `txgbe_aml.c`, `xpcs_create_pcs_mdiodev()`, `phylink_create()`, `clk_register_fixed_rate()`, `devm_regmap_init()`, and `platform_device_register_full()` return `ERR_PTR`; check with `IS_ERR()` in a local variable before assigning to `txgbe->pcs`, `wx->phylink`, `txgbe->clk`, `txgbe->i2c_dev`, or `txgbe->sfp_dev`. [F206]
- In `txgbe_add_ethtool_fdir_entry()`, `err` starts at `-EINVAL` for the `txgbe_flowspec_to_flow_type()`, mask `memcmp()`, and `txgbe_match_ethtool_fdir_entry()` jumps to `err_out`/`err_unlock`; no intermediate call may leave `err == 0` before those jumps. [F207]

## External Contracts

- In `txgbe_clock_register()`, format `clk_name` as `"i2c_designware.%d"` with `pci_dev_id(pdev)` (`< 24` bytes, matching `txgbe_i2c_register()`) and pass to `clkdev_create()` via `"%s"`. In `txgbe_gpio_init()`, `gc->label` (`"txgbe_gpio-%x"`, `pci_dev_id(wx->pdev)`) must match `nodes->gpio_name` (`swnodes[SWNODE_GPIO].name`). In `txgbe_mdio_pcs_init()`, `mii_bus->phy_mask = ~0` and `txgbe_pcs_read()`/`write()` must reject non-zero `addr` (`-EOPNOTSUPP`). [F270, F271, F309]
- In `txgbe_ethtool.c`, only call `txgbe_fdir_write_perfect_filter()` or `txgbe_fdir_erase_perfect_filter()` when `netif_running(wx->netdev)` is true. In `txgbe_get_ethtool_fdir_all()`, set `cmd->data = (1024 << TXGBE_FDIR_PBALLOC_64K) - 2`, return `-EMSGSIZE` if `cnt == cmd->rule_cnt` before writing `rule_locs[cnt]`, and set `cmd->rule_cnt = cnt`. [F299, F300]
- `txgbe_fdir_set_input_mask()` must bitwise-invert host-order port and IPv4 masks (`~fdirtcpm`, `ntohl(~input_mask->formatted.src_ip[0])`, `ntohl(~input_mask->formatted.dst_ip[0])`) before writing `TXGBE_RDB_FDIR_*_MSK`. In `txgbe_atr()`, when `wx_decode_ptype(ptype).etype` is non-zero (tunneled), hash `skb_inner_network_header()` and `inner_tcp_hdr()` with inverted ports (`common.port.src ^= th->dest`, `common.port.dst ^= th->source`). [F239, F303]

## Known Pitfalls

- In `txgbe_reset()`, copy `wx->mac_table[0].addr` into a temporary buffer before `wx_flush_sw_mac_table(wx)` (which zeroes entries in place) and restore it via `wx_mac_set_default_filter(wx, old_addr)`. [F224]
- In `union txgbe_atr_input`, `vlan_id`, IPs, ports, and `flex_bytes` are big-endian (use `ntohl()`/`ntohs()` for registers), whereas `bkt_hash` is stored in host byte order via `(__force __be16)` and read via `(__force u32)` without swapping. Widen `ntohs(dst_port)` and `ntohs(flex_bytes)` to `u32` before shifting left by 16 (`TXGBE_RDB_FDIR_PORT_DESTINATION_SHIFT` / `FLEX_SHIFT`). [F238, F259]
- In `txgbe_calc_eeprom_checksum()`, callers must zero `*checksum` beforehand; replace words in `[TXGBE_EEPROM_I2C_SRART_PTR, TXGBE_EEPROM_I2C_END_PTR)` (`0x580..0x7ff`) with `0xffff` on `wx_mac_aml`, skip `wx->eeprom.sw_region_offset + TXGBE_EEPROM_CHECKSUM`, and compute `*checksum = TXGBE_EEPROM_SUM - *checksum` with wrapping `u16` arithmetic. [F244, F258]
- In `txgbe_gpio_irq_handler_aml()` (on `txgbe_irq_chip` with no `irq_ack`), mask `WX_GPIO_INTMASK`, write each handled bit (`TXGBE_GPIOBIT_2`/`3`) to `WX_GPIO_EOI`, and unmask `WX_GPIO_INTMASK`. In `txgbe_pma_config_10gbaser()`/`1g()`, use `txgbe_modify_pma(xpcs, reg, mask, set)` so RMW updates write back to the same `TXGBE_PMA_MMD + reg`. [F251, F274]
