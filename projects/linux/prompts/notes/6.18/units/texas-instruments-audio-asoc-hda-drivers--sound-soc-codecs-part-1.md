# TEXAS INSTRUMENTS AUDIO (ASoC/HDA) DRIVERS — sound/soc/codecs (part 1)

Covers `tas2781-fmwlib.c`, `tas2781-i2c.c`, `tas2783-sdw.c`, and TLV320 codecs/ADCs (`tlv320adc3xxx`, `tlv320adcx140`, `tlv320aic23`, `tlv320aic26`, `tlv320aic31xx`, `tlv320aic32x4`, `tlv320aic3x`).

## Architecture & Data Flow

- In `tasdevice_fw_ready()`, `fw_state` is `TASDEVICE_RCA_FW_OK` after `tasdevice_rca_parser()` and `TASDEVICE_DSP_FW_ALL_OK` only after `tasdevice_dsp_parser()` and `tasdevice_dsp_create_ctrls()` succeed; if still `TASDEVICE_RCA_FW_OK` at `out:`, `tasdevice_dsp_remove()` sets `tas_priv->fmw = NULL`. `tasdevice_tuning_switch()` and `tasdevice_startup()` must allow both states and check `tas_priv->fmw != NULL` before dereferencing it. [F191, F209, F285]
- In `tasdevice_select_tuningprm_cfg()` and `tasdevice_prmg_load()`, setting `tasdevice[i].is_loading = true` must reset `cur_conf = -1`, and `tasdev_load_calibrated_data()` must run after `tasdevice_load_data(tas_priv, &(conf->dev_data))`. Signed indices (`prm_no`, `cfg_no`, `rca_conf_no`, `conf_no`) can be `-1` and must be checked for `>= 0` before indexing `programs`, `configs`, or `rca->cfg_info`. [F206, F220, F283]
- `tasdevice_config_info_remove()` and `tasdevice_select_cfg_blk()` must bound loops by `rca->ncfgs` and `cfg_info[i]->real_nblocks` (not `fw_hdr.nconfig`/`nblocks`). `rcabin.init_profile_id` starts at `-1` and updates without breaking whenever a profile's 64-byte name contains `"init"` (`rcabin.ncfgs - 1` after `ncfgs++`). [F247, F248]
- In `tas2781-fmwlib.c`, `tasdev_blk_data::dev_idx` and `tasdev_blk::dev_idx & 0x3F` use `0` for broadcast and `1..ndev` as 1-based indices (subtract 1 before indexing `tasdevice[]` or shifting `active_dev`); `dev_idx & 0xC0` in `tasdevice_process_block()`/`map_dev_idx()` tags RCA (`0x00`), DSP program (`0x80`), and coeff/pre (`0xC0`) blocks. [F221, F222]
- In `tasdevice_dspfw_ready()`, every non-`0x100` `fw_fixed_hdr->drv_ver` needs a `switch` case (`dspfw_default_callback()` rejects `!= 0x100`). In `map_dev_idx()`, `dspbin_type_check()`, and `dspfw_default_callback()`, order `ppcver >= ...` checks from highest (`PPC3_VERSION_TAS5825_BASE`, `BETA_MIN`, `BASIC_MIN`) down to `PPC3_VERSION_BASE`. In `fw_parse_variable_header_kernel()` and `fw_parse_variable_hdr()`, reject `fw_hdr->device >= TASDEVICE_DSP_TAS_MAX_DEVICE` or `== 6` before indexing `deviceNumber[]`. [F224, F245, F246]
- Non-kernel blocks (`fw_parse_block_data()`) size `block->data` as `nr_cmds * 4` bytes and step by 4-byte words in `tasdev_load_blk()` (where `offset == 0x85` in `tasdev_multibytes_wr()` increments `nr_cmds` once and advances `*nr_cmds` by `1 + (len >= 2 ? ((len - 2) / 4) + 1 : 0)`), whereas kernel blocks (`fw_parse_block_data_kernel()`) size `block->data` as `blk_size` bytes for `tasdevice_load_block_kernel()`. [F251, F270]
- In `tasdevice_load_block()`, reset `block->nr_retry = 6` per channel before `tasdev_load_blk()`, and each retry pass in `tasdev_load_blk()` must reset `TASDEVICE_CHECKSUM_REG`, `crc_chksum = 0`, and `nr_cmds = 0`. In `tasdev_multibytes_chksum()`, reject `(reg + len - 1) > 127` before reading into `nBuf1[128]`. [F228, F250]
- In `tas2781-i2c.c`, `sngl_calib_start()` and `tas2563_calib_start_put()` must save current register values into `cali_data_backup` (and `alp_cali_bckp` for `TASDEV_ALPHA`) before writing start values. `sngl_calib_start()` loops `j` to `ARRAY_SIZE(tas2781_cali_start_reg) - 4` for 1-byte writes and indexes `p[j..j+3]` for 4-byte bulk writes, so the last 4 entries of `tas2781_cali_start_reg[]` must stay the 4-byte registers. [F211, F229]
- In `tasdev_cali_data_get()`, every `continue` in `for (j = 0, k = 0; j < priv->ndev; j++)` must advance `i` and `k` by the remaining bytes of the 21-byte record (`+21`, `+20`, `+16`, `+12`, or `+8`). In `acoustic_ctl_write()`, check `if (j >= priv->ndev)` before using `chn`. Keep `tasdevice_id[]` 1-to-1 with `enum audio_device` for `tasdevice_parse_dt()`. In `tasdevice_digital_gain_get()`/`_put()`, set `mc->max` to `ARRAY_SIZE(table) - 1` on ascending `dvc_tlv_table[]`. [F232, F253, F256, F280]
- In `tas2783-sdw.c`, `tas_update_status()` must clear `hw_init = false` on `SDW_SLAVE_UNATTACHED` and, on `SDW_SLAVE_ATTACHED` with `!hw_init`, exit cache-only mode, sync regcache, and run `tas_io_init()` (resetting `fw_dl_task_done` and `fw_dl_success` to `false`) before setting `hw_init = true`. In `tas2783_sdca_dev_resume()`, if `slave->unattach_request` is set, wait on `slave->initialization_complete` and clear `unattach_request = 0` before exiting cache-only mode and syncing regcache. [F212, F289]
- In `tas2783-sdw.c`, every register in `tas2783_reg_default[]`, `tas2783_init_seq[]`, or accessed via `regmap` needs a case in `tas2783_sdca_mbq_size()` (`tas2783_readable_register()`). `tas2783_validate_calibdata()` must verify `spk_count <= 8` and `size >= (spk_count * TAS2783_CALIB_PARAMS * sizeof(u32)) + TAS2783_CALIB_HDR_SZ + TAS2783_CALIB_CRC_SZ` before `tas2783_set_calib_params_to_device()`. [F233, F235]
- In paged regmaps (`aic32x4_regmap_config`, `aic31xx_i2c_regmap`, `adc3xxx_regmap`), adding a higher-paged register requires updating both `max_register` and `range_max`. Dynamic DAPM routes in `aic31xx_clock_master_routes()` (`master_dapm_route_applied`), `adc3xxx_hw_params()` (`use_pll`), and `adc3xxx_set_dai_fmt()` (`master`) must only be added when the flag is false and deleted when true. [F214, F215]
- In `tlv320aic31xx.c`, when `sysclk_id == AIC31XX_PLL_CLKIN_BCLK`, `aic31xx_hw_params()` must set `sysclk = params_rate(params) * params_width(params) * params_channels(params)` and `p_div = 1` before `aic31xx_setup_pll()`. `aic31xx_setup_pll()` must verify `sysclk` and `p_div` are non-zero before dividing, and only set `rate_div_line = match` when `match != -1` (`aic31xx_clk_on()` indexes `aic31xx_divs[rate_div_line]` unchecked). [F216, F237, F264]
- In `tlv320aic31xx.c`, `aic31xx_power_on()` must call `aic31xx_set_jack(component, aic31xx->jack, NULL)` after reset/sync (`AIC31XX_HSDETECT` is volatile); `aic31xx_set_bias_level()` only enters `SND_SOC_BIAS_STANDBY` from `BIAS_OFF`/`BIAS_PREPARE` (else `BUG()`); `aic31xx_dapm_power_event()` must poll `AIC31XX_DACFLAG1`/`ADCFLAG` via `aic31xx_wait_bits()` (7s `POST_PMU` timeout on `AIC31XX_HPDRIVER`). [F217, F260, F296]
- In `tlv320aic31xx.c`, `aic31xx_set_dai_fmt()` sets `dsp_a_val = 0x1` on `DSP_A` and falls through to `DSP_B`, which XORs `iface_reg2 ^= AIC31XX_BCLKINV_MASK` after the polarity switch; DAC-only variants (`codec_type & DAC31XX_BIT`) must skip ADC controls, widgets, routes, and capture DAI; `tlv320dac3100_fw_load()` requires `size == 153`. [F236, F259, F295]
- In `tlv320aic32x4.c`, `aic32x4_probe()` must call `aic32x4_register_clocks()` after `aic32x4_setup_regulators()` and resets, and before `devm_snd_soc_register_component()`. Check `if (aic32x4->setup)` before `aic32x4_setup_gpios()`. For `AIC32X4_TYPE_TAS2505`, never write `AIC32X4_ADCSPB`/`ADCSETUP`, reject `r_block != 0` or `p_block > 3` in `aic32x4_set_processing_blocks()`, and use `soc_component_dev_aic32x4_tas2505`. In `clk_aic32x4_div_recalc_rate()`, map `!val` (after `AIC32X4_DIV_MASK`) to `AIC32X4_DIV_MAX` (`128`). [F202, F242, F297, F299]
- In `tlv320adc3xxx.c`, `gpio_cfg[]` stores DT values `+ 1` (`0` = unconfigured), so `adc3xxx_gpio_request()` checks `ADC3XXX_GPIO_GPO + 1` and `adc3xxx_init_gpio()` decrements `cfg--`; offsets `2..3` must subtract `ADC3XXX_GPIO_PINS` (`2`) before indexing `micbias_gpo[]`, `micbias_vg[]`, or `adc3xxx_micbias_shift[]`. In `adc3xxx_divs[]`, PLL entries (`pll_p != 0`) must precede non-PLL entries (`pll_p == 0`) for the same `(mclk, rate)`. [F238, F239, F240]
- In `tlv320adcx140.c`, when `supply_areg` is `NULL`, `adcx140_codec_probe()` must set `ADCX140_AREG_INTERNAL | ADCX140_WAKE_DEV` in `ADCX140_SLEEP_CFG` after reset and wait >= 1 ms. `adcx140_hw_params()` and `adcx140_set_dai_fmt()` must call `adcx140_pwr_ctrl(adcx140, false)` before changing `ADCX140_ASI_CFG0`, `MST_CFG0`, or `ASI_CFG1`, and `adcx140_pwr_ctrl(adcx140, true)` must write `ADCX140_PHASE_CALIB` before `ADCX140_PWR_CFG`. In `tlv320aic23_shutdown()`, clear the closing stream's `requested_dac`/`requested_adc` to `0`. [F218, F219, F293]

## Synchronization

- `tas2781-fmwlib.c` functions (`tasdevice_rca_parser()`, `tasdevice_dsp_parser()`, `tas2781_load_calibration()`, `tasdevice_prmg_load()`, `tasdevice_select_cfg_blk()`, `tasdevice_tuning_switch()`) do not lock `codec_lock`; callers in `tas2781-i2c.c` (`tasdevice_fw_ready()`, `tasdevice_dapm_event()`, `tasdev_cali_data_get()`/`_put()`, `tas2781_calib_start_put()`, `tas2563_calib_start_put()`, `tasdev_calib_stop_put()`, `tasdevice_active_num_put()`, `acoustic_ctl_write()`) must hold `codec_lock`. [F177, F180]
- In `tasdevice_i2c_probe()`, finish `tasdevice_parse_dt()`, `tasdevice_init()`, and `tasdevice_reset()` before `devm_snd_soc_register_component()`. In `tasdevice_fw_ready()`, call `tasdevice_create_control()` only after `tasdevice_rca_parser()` succeeds, and `tasdevice_dsp_create_ctrls()`/`tasdevice_create_cali_ctrls()` only after `tasdevice_dsp_parser()` populates `tas_priv->fmw`. [F178, F181]
- In `tas2783-sdw.c`, `tas_io_init()` must not hold `pde_lock` or `calib_lock` while waiting on `fw_wait`, and `tas2783_fw_ready()` must use `sdw_nwrite_no_pm()`. `tas_sdw_hw_params()` must hold `pde_lock` and retry writing `TAS2783_SDCA_POW_STATE_ON` to `TAS2783_SDCA_ENT_PDE23` up to 4 times (2 ms delay) before `sdw_stream_add_slave()`, and `tas_sdw_pcm_hw_free()` must write `TAS2783_SDCA_POW_STATE_OFF` under `pde_lock` after `sdw_stream_remove_slave()`. [F288, F301, F302]
- In `tlv320aic31xx.c`, `aic31xx_irq()` must be a threaded IRQ (`IRQF_ONESHOT`, NULL hardirq handler) and check `if (aic31xx->jack)` before `snd_soc_jack_report()`. In `aic31xx_codec_probe()`, set `disable_nb[i].nb.notifier_call` and `disable_nb[i].aic31xx` before `devm_regulator_register_notifier()`. [F186, F187, F306]

## Object Lifetimes

- Every exit path of `tasdevice_fw_ready()` must `goto out` to unlock `codec_lock` and `release_firmware(fmw)`. In `tas2781_load_calibration()`, initialize `fw_entry = NULL`, set negative `ret` on every failure after `request_firmware()`, and `goto out` to `release_firmware(fw_entry)` while leaving `tasdev->cali_data_fmw` attached for `tasdevice_calbin_remove()`. [F161, F166, F190]
- In `tas2783-sdw.c`, `tas_sdw_probe()` must initialize `calib_lock`, `pde_lock`, `fw_wait`, and `regmap` before `tas_init()`, and `tas_sdw_remove()` must call `pm_runtime_disable()` and `tas_remove()` before destroying those locks. Every exit path of `tas2783_fw_ready()` must jump to `out:` (with non-zero `ret` on error so `fw_dl_success` stays `false`) to unlock `pde_lock`, set `fw_dl_task_done = true`, `wake_up(&tas_dev->fw_wait)`, and `release_firmware(fmw)`. [F162, F185, F197]
- In `tas2781-fmwlib.c`, `tasdevice_rca::cfg_info` and `tasdevice_config_info::blk_data` are pointer arrays of `kzalloc` elements (`tasdevice_config_info_remove()` must `kfree` each element first), whereas `programs`, `configs`, `calibrations`, and `dev_blks` are contiguous struct arrays where `tas2781_clear_calfirmware()` only `kfree`s each `block->data` and the base pointer. In `tas2781-i2c.c`, `tasdev[i].cali_data_backup` uses non-devm `kmemdup()` (`kfree()` in `tasdevice_deinit()`), while kcontrols, `cali_data->data`, and `ext_cali_data`/`ext_cali_start` use `devm_*`. [F167, F268, F269, F278]
- In `tlv320aic32x4.c`, guard `supply_ldo`, `supply_dv`, and `supply_av` (`devm_regulator_get_optional()`) with `!IS_ERR(...)` in `aic32x4_setup_regulators()` (with LIFO rollback) and `aic32x4_disable_regulators()`, and jump to `err_disable_regulators` if `aic32x4_probe()` fails after setup. Keep `clk_bulk_data` arrays passed to `devm_clk_bulk_get()` `static`/devm-allocated, skip `clk_bulk_disable_unprepare()` in `SND_SOC_BIAS_STANDBY` when coming from `BIAS_OFF`, and do not read `aic32x4_clkdesc_array[0..1].parent_names` outside `aic32x4_register_clocks()`. [F170, F171, F172, F276, F277]
- If `regcache_sync()` fails in `aic31xx_power_on()`, restore `regcache_cache_only(regmap, true)` and `regulator_bulk_disable()`. In `tlv320adc3xxx.c`, jump to `err_unprepare_mclk` on probe errors after `clk_prepare_enable(adc3xxx->mclk)` and do not mark `adc3xxx_i2c_remove()` `__exit`. In `adcx140_i2c_probe()`, reset `supply_areg = NULL` on non-`-EPROBE_DEFER` errors from `devm_regulator_get_optional()`, and on success enable it and register `adcx140_disable_regulator()` via `devm_add_action_or_reset()`. [F173, F176, F290]

## API Contracts

- `tas2781-fmwlib.c` exports use `EXPORT_SYMBOL_NS_GPL(..., "SND_SOC_TAS2781_FMWLIB")` and must never downcast `tas_priv->codec` or `dev_get_drvdata(tas_priv->dev)` (shared by ASoC/HDA). `tasdevice_add_config()` never clears `*status` and returns a non-NULL partial struct on error (stored in `rca->cfg_info[i]` after `rca->ncfgs++`), so callers must initialize `*status = 0`, check `*status`, and call `tasdevice_config_info_remove()` on failure. `fw_parse_*()` helpers return signed `int` (positive offset or negative errno). [F163, F188, F189, F275, F321]
- In `tas2781_cali_start_reg`, protected test registers (`TAS2781_PRM_TEST_57_REG`, `TEST_62_REG`) must set `is_locked = true` (`X2781_CL_STT_VAL`). In `tasdevice_parse_dt()`, pass `"reset"` (not `"reset-gpios"`) to `devm_gpiod_get_optional()` and never pass IRQs to GPIO APIs. In `tas2783-sdw.c`, `tas_sdw_hw_params()` must set `port_config.num = 1` (playback) and `2` (capture) to match `tas_read_prop()`. [F282, F286, F318]
- In `tlv320aic32x4-clk.c`, check `clk_aic32x4_pll_calc_muldiv() < 0` (signed `int`) before `clk_aic32x4_pll_calc_rate()` (`unsigned long`), and wire clock gating to `.prepare`/`.unprepare`/`.is_prepared`. Copy `aic32x4_regmap_config` locally to set `reg_bits`/`val_bits` in I2C/SPI probes; force `channels = 2` for `SND_SOC_DAIFMT_I2S` in `aic32x4_setup_clocks()`; keep `aic32x4_tas2505_dai.playback.channels_max = 2`. Keep `adc3xxx_gpio_chip.can_sleep = 1` and have `adc3xxx_gpio_set()` call `adc3xxx_gpio_direction_out()`. Require `tx_mask == GENMASK(__fls(tx_mask), 0)` in `adcx140_set_dai_tdm_slot()`. [F198, F203, F241, F305, F307, F308, F309, F312]

## Error Handling

- Check both `cali_data_fmw` and `cal_fmw->calibrations` for non-NULL in `tasdev_load_calibrated_data()`. Store `device_property_count_u32()` in signed `int` and check `<= 0` in `tlv320adcx140.c`. Pass `PTR_ERR(regmap)` (not `PTR_ERR(tas_dev->regmap)`) to `dev_err_probe()` in `tas_sdw_probe()`. [F192, F199, F243]

## External Contracts

- `fw_parse_variable_header_kernel()` must advance `offset` past all `4 * 5` program and `4 * max_confs` (64 or 10) config size slots; `fw_parse_fct_param_address()`/`fct_param_address_parser()` require `offset + 520 <= fmw->size` and stop on `dat[23] != 1`. `TASDEVICE_CMD_BURST` in `tasdevice_process_block()` has payload at `data[subblk_offset + 4]`, requiring `subblk_offset + 4 + len <= sublocksize` and `len % 4 == 0`. [F225, F226, F227]
- `Speaker Calibrated Data` packets have a 17-byte header + `ndev` 21-byte records with `src[17 + j * 21] == j`. `struct acoustic_data` has a 6-byte header and 128-byte `data` (write `len = src[0] - 6`; read `len = src[6]` and `p->len = len + 6`). In `tas2783_fw_ready()`, `read_header()` advances `offset` by 12 (`FW_FL_HDR`), so payload size is `hdr.length - FW_FL_HDR`. [F230, F231, F234]

## Known Pitfalls

- In `cali_reg_update()` and `partial_cali_data_update()`, switch on `tas2781_cali_start_reg[j].reg` (not `p[j].reg`), and keep `bulk_reg_val::val` >= 4 bytes for `(unsigned int *)` casts in `tasdevice_dev_read()`. Do not confuse `unsigned int` `cali_reg_array.r0_reg` (`tasdev_r0_data_get()`) with 3-byte `fct_par_addr.r0_reg` (`tasdev_re_data_get()`). Bound `tasdevice_config::name`/`tasdevice_data::name` (`char[64]`) string reads to 64 bytes. [F210, F255, F272, F279]
- In `tas_read_prop()`, copy `u32` `source_ports`/`sink_ports` to `unsigned long` before `for_each_set_bit()`. Test optional reset GPIOs (`devm_gpiod_get_optional()`) with `if (gpio)`. Cast rates to `u64` and use `DIV_ROUND_UP_ULL`/`do_div` in `clk_aic32x4_pll_calc_*()`, and use `DIV_ROUND_UP((32 * resource_class), osr)` for `madc`/`min_mdac` in `aic32x4_setup_clocks()`. [F244, F261, F263, F281]
