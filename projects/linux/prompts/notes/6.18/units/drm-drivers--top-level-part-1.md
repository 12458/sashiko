# DRM DRIVERS — (top level) (part 1)

This component defines core DRM headers (`include/drm/*.h`), display/bridge headers (`include/drm/display/*.h`, `include/drm/bridge/*.h`), AMD ASIC definitions, and GPU memory tracepoints (`drivers/gpu/trace/trace_gpu_mem.c`).

## Architecture & Data Flow

- Before downcasting `drm_private_obj` or `drm_private_state` in `state->private_objs[]` (e.g., via `to_dp_mst_topology_state()` or `drm_priv_to_bridge_state()`), verify `objs_state->ptr->funcs` matches the target `drm_private_state_funcs` vtable. [F50]
- `drm_atomic_state.connectors` is dynamically sized to `state->num_connector` with `NULL` holes at unplugged indices, and `drm_connector_mask()` shifts `1 << connector->index` into a `u32` (`connector_mask`): keep `connector->index` in `[0, 31]`, check `index < state->num_connector` on direct lookups, and guard loops on `state->connectors[__i].ptr != NULL`. [F79, F108]
- In `drm_plane_state`, `crtc` and `fb` must both be non-NULL when enabled and both NULL when disabled (`WARN_ON` in `drm_atomic_plane_enabling()`/`disabling()`). [F67]
- `drm_connector.registration_state` is a tristate (`INITIALIZING`, `REGISTERED`, `UNREGISTERED`); `drm_connector_is_unregistered()` is true only for `DRM_CONNECTOR_UNREGISTERED`, allowing modesets during init while blocking userspace modesets on removed connectors. [F126]
- In `struct drm_dp_mst_branch`, `port_parent` is `NULL` and `rad[8]` is zero (`lct == 1`) on `mgr->mst_primary`; `rad` nibbles are valid only for link counts `2 .. mstb->lct`. DPCD capability size macros for inclusive `[start, end]` ranges (e.g., `DP_DSC_RECEIVER_CAP_SIZE`, `DP_PCON_DSC_ENCODER_CAP_SIZE`) must be `end - start + 1`. [F52, F83]
- In `struct drm_crtc_crc`, `DRM_CRC_ENTRIES_NR` (`128`) must be a power of two, and `verify_crc_source`'s `values_cnt` must be in `1..DRM_MAX_CRC_NR` (`10`). In `drm_client_dev`, `client->modesets` must have `num_crtc + 1` entries terminated by a `crtc == NULL` sentinel for `drm_client_for_each_modeset()`. [F92, F93]
- `drm_arch_can_wc_memory()` must return `false` on ARM, arm64, LoongArch, Loongson64 MIPS, and cache-coherent PowerPC. Every `enum amd_asic_type` before `CHIP_LAST` must have a matching entry in `amdgpu_asic_name[]`. DRM/HDA binding state (`master_bind_complete`, `dev`) must be per-instance in `struct drm_audio_component`, never static. [F62, F95, F137]

## Synchronization

- `__drm_atomic_get_current_plane_state()` reads `plane->state` without lock checks when `plane` is absent from `drm_atomic_state`; use it only when a lock protecting `plane->state` (e.g., a fixed CRTC's lock) is held, and use `drm_atomic_get_plane_state()` for reassignable planes. [F30]
- When a `drm_private_obj` is shared across CRTCs, store a `drm_crtc_commit` reference in private state during `atomic_commit_setup` and wait on it at the start of `atomic_commit_tail` to serialize nonblocking commits. [F29]
- In `struct drm_crtc`, `crtc->mutex` protects `crtc->state` (outside nonblocking commits ordered by `drm_crtc_commit`), `commit_lock` protects `commit_list`, `fence_lock` protects `fence_context`, and `crc.lock` protects `drm_crtc_crc`. [F38]
- `drm_device.vbl_lock` wraps inner `vblank_time_lock`; `enable_vblank`, `disable_vblank`, `get_vblank_counter`, and `get_vblank_timestamp` run with both spinlocks held and IRQs disabled and must never sleep. [F134]
- In `struct drm_connector`, `connection_mutex` protects `state`; `mode_config.mutex` protects `modes`, `status`, `probed_modes`, `display_info`, and `edid_blob_ptr`; `eld_mutex`, `edid_override_mutex`, `hdmi.infoframes.lock`, and `hdmi_audio.lock` protect `eld`, `edid_override`, `audio`, and `plugged_cb`; `connector->mutex` protects `registration_state` writes (unlocked readers must use `drm_connector_is_unregistered()`); and dropping the last ref under `connector_list_lock` in `drm_connector_list_iter` must defer cleanup via `free_node`/`connector_free_work` (`__drm_connector_put_safe()`). [F34, F40, F133]
- In `drm_dp_mst_topology_mgr`, `qlock` protects `tx_msg_downq` and `drm_dp_sideband_msg_tx.state`, `delayed_destroy_lock` protects `destroy_port_list`/`destroy_branch_device_list`, and `up_req_lock` protects `up_req_list`. `port->mstb` and `mstb->ports` are modified only by `work`/`up_req_work` under both `probe_lock` and `lock` (other readers need `lock`). Because `up_req_recv`/`down_rep_recv` are read unlocked, topology removal must set `mgr->reset_rx_state = true` under `lock` instead of zeroing them. [F22, F27, F138]
- In DP MST atomic state, `mgr->payload_count` and `mgr->next_start_slot` are commit-only (never access in `atomic_check`). `payload->vc_start_slot` is undefined in `atomic_check` and may only be read in commit after `drm_dp_mst_atomic_wait_for_dependencies()` (and `drm_dp_add_payload_part1()`/`drm_dp_remove_payload_part2()`), or under the MST modeset lock after `drm_crtc_commit_wait()` on `commit_deps`. [F24, F25]
- `drm_dp_aux.hw_mutex` only serializes one `drm_dp_aux`; drivers sharing AUX hardware or implementing `poll_hpd_irq` must lock across channels and HPD IRQs themselves. [F143]
- Guard hotpluggable hardware access with `drm_dev_enter()`/`drm_dev_exit()`, not `drm_dev_is_unplugged()`; on unload, calling `drm_dev_unplug()` before `drm_atomic_helper_shutdown()` skips disable hooks guarded by `drm_dev_enter()`. [F35, F120]
- In `struct drm_master`, `master_mutex` protects `unique`, `unique_len`, and `magic_map`, while `mode_config.idr_mutex` protects lease fields (`lessee_id`, `lessee_list`, `lessees`, `leases`, `lessee_idr`, where `lessee_idr`/`lessees` live on the top-level `lessor == NULL` owner). [F37, F78]
- `drm_client_dev` must be initialized via `drm_client_init()` before `drm_client_register()` publishes `client->list` under `clientlist_mutex`. `drm_client_for_each_modeset()` requires `modeset_mutex`, `drm_client_buffer_vmap_local()` must pair with `vunmap_local()`, and `drm_client_funcs.restore` must serialize master access itself (e.g., `drm_master_internal_acquire()`/`release()`). [F15, F31, F32]
- `struct drm_buddy` has no internal locking: callers must serialize `drm_buddy_alloc_blocks()`, `drm_buddy_block_trim()`, `drm_buddy_free_block()`, `drm_buddy_free_list()`, and `drm_buddy_reset_clear()` (required on resume if memory was dirtied), and must not touch `block->link` after free. [F39, F59]

## Object Lifetimes

- Initialize `struct drm_private_obj` with `drm_atomic_private_obj_init()` before `drm_dev_register()` and call `drm_atomic_private_obj_fini()` only after `drm_dev_unregister()`. [F1]
- Call `end_fb_access` and finish reading `new_crtc_state`/`new_plane_state` before `drm_atomic_helper_commit_hw_done()`; afterwards, wait on `state->crtcs[i].commit->flip_done`, not `new_crtc_state->commit->flip_done`. When `drm_atomic_helper_setup_commit()` takes an event completion ref on `drm_crtc_commit`, it sets `abort_completion = true` so `__drm_atomic_helper_crtc_destroy_state()` drops it if aborted with `state->event` non-NULL. [F3, F5, F6]
- Modify `drm_connector_state.crtc` only via `drm_atomic_set_crtc_for_connector()`. Pair `drm_connector_list_iter_begin()` with `drm_connector_list_iter_end()` on all paths and do not use the cursor past the next step or `iter_end` without `drm_connector_get()`. [F11, F20]
- Assigning `connector->fwnode` transfers a reference released by `drm_connector_cleanup()`. Set `drm_device.dma_dev` via `drm_dev_set_dma_dev()` and read it via `drm_dev_dma_dev()`. Release `drm_file_get_master()` refs with `drm_master_put(&master)` (which NULLs `master`). [F12, F16, F123]
- Do not call `drm_client_release()` outside `drm_client_funcs.unregister` after `drm_client_register()`. `drm_client_framebuffer_create()` must destroy its temporary GEM handle once `drm_framebuffer` is created, keeping only `gem` and `fb` refs. [F13, F14]
- Retain `drm_dp_mst_port` pointers via `drm_dp_mst_get_port_malloc()` inside `add_connector` and release with `drm_dp_mst_put_port_malloc()`, never touching `topology_kref`. Pair `drm_dp_tunnel_get()`/`drm_dp_tunnel_ref_get()` with `drm_dp_tunnel_put()` (same `ref_tracker **`) or `drm_dp_tunnel_ref_put()`. [F17, F18]

## API Contracts

- Atomic drivers must provide both `atomic_duplicate_state` and `atomic_destroy_state` on `drm_crtc_funcs` and `drm_connector_funcs`, refcounting all copied objects in `duplicate` and dropping them in `destroy`. `atomic_set_property` must only update the passed-in state without touching hardware or doing cross-property validation. [F7, F147, F151]
- `funcs->destroy` must be `NULL` for `drmm_crtc_*` and `drmm_connector_*` init helpers, and non-NULL for unmanaged `drm_crtc_init_with_planes()` and `drm_connector_init*()`. [F53]
- Never modify `state->allow_modeset`, use `drm_atomic_crtc_needs_modeset()` in commit paths, and check `allow_modeset` before adding unrelated CRTCs via `drm_atomic_get_crtc_state()`. Check `state->duplicated` in atomic check paths to allow modesets on unregistered connectors during suspend/resume. Use `drm_atomic_helper_commit_tail_rpm()` when CRTCs must be enabled before plane updates. [F65, F76, F131]
- The core calls `drm_crtc_vblank_get()` before `page_flip_target` and `drm_crtc_vblank_put()` on error return; on `0`, the driver owns the ref and must call `drm_crtc_vblank_put()` on flip completion. Non-zero `drm_device.max_vblank_count` must be a contiguous mask `(1 << N) - 1`. [F8, F110]
- Return conventions: `drm_atomic_get_{crtc,plane,connector,private_obj,bridge,mst_topology}_state()`, `devm_drm_dev_alloc()`, `drmm_crtc_alloc_with_planes()`, and `drm_client_framebuffer_create()` return `ERR_PTR()`; `drm_atomic_get_{old,new}_*_state()`, `drm_atomic_state_alloc()`, and `.atomic_duplicate_state()` return `NULL`; `devm_drm_dp_hpd_bridge_alloc()`/`drm_dp_hpd_bridge_register()` return `ERR_PTR()` on error or `NULL` when disabled; `of_dp_aux_populate_bus()`/`devm_of_dp_aux_populate_bus()` return `-ENODEV` when `aux-bus` is absent. [F44, F45, F46, F47]
- DP AUX/tunnel contracts: call `drm_dp_aux_init()` before pre-registration use and set `aux->drm_dev` before `drm_dp_aux_register()`; `drm_dp_aux.transfer()` must only mutate `msg->reply` and return bytes transferred or negative errno (`-EBUSY` retries); `drm_dp_dpcd_read()`/`write()`/`readb()`/`writeb()` return byte count or negative errno while `*_data()`/`*_byte()` return `0` or `-EPROTO`; `wait_hpd_asserted` waits indefinitely if `wait_us == 0` and returns `0` or `-ETIMEDOUT` silently; `drm_dp_tunnel_{get_allocated,available}_bw()` return `-1` when invalid/disabled, and `drm_dp_tunnel_{update_state,handle_irq}()` return `1` (changed), `0` (unchanged), or negative errno. [F41, F43, F48, F118, F130]
- `drm_dp_calc_pbn_mode()`, `drm_dp_bw_overhead()`, `drm_dp_link_symbol_cycles()`, and `drm_dsc_config.bits_per_pixel` take bpp in `.4` fixed-point (`bpp << 4`; extract integer bpp via `drm_dsc_get_bpp_int()` or `>> 4`). [F55, F109]
- Connectors and HDMI: update `edid_blob_ptr`, `path_blob_ptr`, and `tile_blob_ptr` only via their property helpers; never combine `DRM_CONNECTOR_POLL_HPD` with `CONNECT`/`DISCONNECT` or call `drm_connector_attach_encoder()` when `connector->encoder` is set; `drmm_connector_hdmi_init()` requires `HDMIA`/`HDMIB`, `max_bpc` in `{8, 10, 12}`, `BIT(HDMI_COLORSPACE_RGB)`, `ycbcr_420_allowed == !!(supported_formats & BIT(HDMI_COLORSPACE_YUV420))`, and `.write_infoframe`; `drm_connector_hdmi_audio_init()` requires `.prepare` and `.shutdown`; check `edid_hdmi_rgb444_dc_modes` vs `edid_hdmi_ycbcr444_dc_modes` for RGB vs YCbCr 4:4:4 deep color; `get_eld` callers must clamp positive returns to `max_bytes`; and `dw_hdmi_plat_data` tables (`mpll_cfg`, `cur_ctr`, `phy_config`) must end with `mpixelclock == ~0UL`. [F75, F90, F94, F125, F153, F154, F162]
- Buddy allocator: `drm_buddy_init()` requires power-of-two `chunk_size >= SZ_4K` (`u64`, with block order `<= DRM_BUDDY_MAX_ORDER` (`51`)) and `size >= chunk_size`; `drm_buddy_alloc_blocks()` requires power-of-two `min_page_size >= chunk_size` and `chunk_size`-aligned `start`/`end`/`size`; `drm_buddy_block_trim()` requires `list_is_singular(blocks)` and `chunk_size`-aligned `new_size`/`*start`. [F56, F57, F106]
- Features, debugfs, WC copy, and stubs: modify `drm_device.driver_features` (never `drm_driver.driver_features`), check features via `drm_core_check_*()`, and never combine `DRIVER_COMPUTE_ACCEL` with `DRIVER_RENDER`/`DRIVER_MODESET`; do not store per-device pointers in shared `drm_info_list.data` or `drm_debugfs_info.data` (use `seq_file->private`); call `drm_memcpy_from_wc()` only in process context (`!in_interrupt()`); and keep `#else` stubs in `aux-bridge.h`, `drm_debugfs.h`, `drm_drv.h`, and `drm_dp_tunnel.h` in sync with `#ifdef` declarations. [F60, F61, F63, F64, F77, F124, F136]

## Error Handling

- If an atomic commit fails after `drm_atomic_helper_prepare_planes()` but before `drm_atomic_helper_swap_state()`, call `drm_atomic_helper_unprepare_planes()` (operating on `new_plane_state`), not `drm_atomic_helper_cleanup_planes()` (`old_plane_state`). [F4]

## External Contracts

- In `drm_crtc_state`, `enable` governs shared resource reservation while `active` governs DPMS; never release shared resources when `active` becomes `false` with `enable == true` or fail `atomic_check` solely due to `active` toggling. [F70]
- Atomic drivers must set `drm_connector_state.best_encoder` when routing connectors, and virtualized drivers whose cursor planes require hotspot properties must set `DRIVER_CURSOR_HOTSPOT`. In `__drm_crtcs_state` and `__drm_connnectors_state`, `out_fence_ptr` must be `s32 __user *`. [F69, F82, F146]
- Wire endianness: `drm_dsc_picture_parameter_set` is a `__packed` 128-byte struct with `__be16` 16-bit fields; HDCP 3-byte `seq_num_v`/`seq_num_m` and 24-bit SRM VRL lengths use `drm_hdcp_be24_to_cpu()`/`cpu_to_be24()`; MHL burst `id`/`burst_id[]` are `__be16` while `mhl_burst_blk_rcv_buffer_info.size` is `__le16`. [F86, F87, F88]

## Known Pitfalls

- `drm_scdc_read()`/`write()` and `drm_dp_dual_mode_read()`/`write()` return `0` on success and negative errno on failure despite their `ssize_t` return type. [F42]
- In `drm_atomic.h`, `for_each_*_private_obj_in_state` must check `(__i) < (__state)->num_private_objs` via `&&` before indexing; sparse-array iterators (`for_each_*_{connector,crtc,plane}_in_state*`) must assign cursors only inside `for_each_if` after `.ptr != NULL`; and `for_each_*_plane_in_state_reverse` require a signed `int` cursor. [F80, F81, F96]
- In `atomic_check` before state swap, walk planes with `drm_atomic_crtc_state_for_each_plane[_state]()` on `crtc_state`, not `drm_atomic_crtc_for_each_plane()`. Use `drm_atomic_crtc_effectively_active()` when self-refresh may be active, and explicitly update `crtc_state->no_vblank` when duplicating/checking state because `__drm_atomic_helper_crtc_duplicate_state()` does not reset it. [F66, F100, F103]
- Check `drm_buddy_block` state with `drm_buddy_block_state(block) == ...` (or `drm_buddy_block_is_*()`), never bitwise `&` (since `DRM_BUDDY_SPLIT` is `3 << 10`). [F97]
- Convert 0-based LTTPR indices with `DP_PHY_LTTPR(i)` (`DP_PHY_LTTPR1 = 1`, `DP_PHY_DPRX = 0`) before calling `DP_LTTPR_*()` or `DP_FEC_*()`, and parenthesize `(val & MASK)` before shifting or comparing multi-field DPCD bytes (e.g., `DP_DSC_MAX_BITS_PER_PIXEL_HI`, `DP_DSC_BITS_PER_PIXEL_INC`). [F84, F98]
- Use `drm_color_lut_size()` (not `blob->length`) for LUT entry counts; in `drm_color_lut_extract()`, `bit_precision > 16` requires `mul_u32_u32()` and `DIV_ROUND_CLOSEST_ULL()`. `drm_connector_hdmi.vendor` and `product` are `__nonstring` arrays and must not be passed to unbounded string functions. [F91, F104, F115]
