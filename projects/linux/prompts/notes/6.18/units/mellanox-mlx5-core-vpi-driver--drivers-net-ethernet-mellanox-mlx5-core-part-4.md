# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 4)

Implements E-Switch (SR-IOV/switchdev) offloads and termination tables, the core Flow Steering (FS) engine, device event dispatch, and firmware querying, flashing, and reset handling.

## Architecture & Data Flow
- `del_sw_prio`, `del_sw_ns`, and `del_sw_root_ns` call `kfree(node)` directly, requiring `node` first in `fs_prio`/`mlx5_flow_namespace` and `ns` first in `mlx5_flow_root_namespace`. Both root and sub-namespaces have `node.type == FS_TYPE_NAMESPACE`; downcasting to `mlx5_flow_root_namespace` must use `find_root(&ns->node)` or check `ns->node.parent == NULL`. [F333, F334]
- `build_match_list()` passes `mlx5_flow_spec` as key to `rhltable_lookup(&ft->fgs_hash, spec, rhash_fg)`, requiring `mlx5_flow_spec` to start with `match_criteria_enable` and `match_criteria` matching `mlx5_flow_group_mask` with zeroed padding. `fs_fte.val` and `fg->mask.match_criteria` have length `MLX5_ST_SZ_DW_MATCH_PARAM`, so copies in `alloc_fte()`/`alloc_flow_group()` must bound size by `sizeof(fte->val)` or `sizeof(fg->mask.match_criteria)`. [F300, F329]
- `alloc_flow_group()` treats `start_index`/`end_index` as inclusive (`max_ftes = end_index - start_index + 1`); `fte_allocator` uses 0-based offsets (`insert_fte()` adds `start_index`, `del_sw_fte()` frees `fte->index - start_index`). `FT_POOLS` in `fs_ft_pool.c` must stay sorted descending for `mlx5_ft_pool_get_avail_sz()`. `alloc_handle()` requires `>= 1` rule (`dest_num ? dest_num : 1`) and must set `handle->num_rules` before accessing `handle->rule[]` (`__counted_by`); `create_flow_handle[_dup]()` appends `FLOW_TABLE` rules with `list_add_tail()` and prepends others with `list_add()`. [F298, F303, F314, F331]
- When promoting `fte->dup` in `switch_to_pending_act_dests()` during `del_hw_fte()`, overwrite `fte->act_dests` with `fte->dup->act_dests`, set each child's `del_sw_func = del_sw_hw_rule`, and call `tree_get_node(&fte->node)`. In `_mlx5_modify_rule_destination()`, if `rule_is_pending(fte, rule)`, check `fte->dup->act_dests` for `FWD_DEST` and skip `root->cmds->update_fte()`. [F277, F278]
- Increment `KERNEL_NIC_PRIO_NUM_LEVELS` when adding a level to `MLX5_FLOW_NAMESPACE_KERNEL`. `mlx5_get_flow_namespace()` indexes `root_fs.children` by `type` (`is_nic_rx_ns`) and `egress_root_fs.children` by `type - MLX5_FLOW_NAMESPACE_EGRESS`, requiring enum order to match `init_tree_node` arrays. `steering->fdb_sub_ns` has `FDB_NUM_CHAINS` (`FDB_TC_MAX_CHAIN + 2`) slots filled sequentially by `store_fdb_sub_ns_prio_chain()`, so `create_fdb_fast_path()` must create TC chains before `FDB_FT_OFFLOAD` and `mlx5_get_fdb_sub_ns()` requires `n < FDB_NUM_CHAINS`. [F292, F293, F295]
- In `set_prio_attrs_in_prio()`, update `acc_level = acc_level_ns` after each child only when `prio->node.type == FS_TYPE_PRIO_CHAINS`. In `find_next_fwd_ft()`, when `MLX5_FLOW_CONTEXT_ACTION_FWD_NEXT_NS` is set, resolve starting `fs_prio` from `ft->ns->node.parent`, not `ft->node.parent`. [F318, F322]
- In `mlx5_pkt_reformat` and `mlx5_modify_hdr`, `id` is valid only when `owner == MLX5_FLOW_RESOURCE_OWNER_FW` (or use `mlx5_fs_get_packet_reformat_id()`). In `mlx5_fs_bulk`, `bitmask` uses `1` for free and `0` for acquired; `mlx5_fc_pool_release_counter()` passes `fc->id - fc->bulk->base_id`, `mlx5_fs_pool_release_index()` updates `available_units`/`used_units` only if `mlx5_fs_bulk_release_index()` confirms the bit was `0`, and `mlx5_fs_pool_free_bulk()` subtracts `bulk_len` from `available_units` and recomputes `threshold`. [F216, F256, F297]
- `esw_create_offloads_fdb_tables()` must revert `mlx5_flow_namespace_set_mode()` to `MLX5_FLOW_STEERING_MODE_DMFS` on error and in `esw_destroy_offloads_fdb_tables()`. In `mlx5_devlink_eswitch_encap_mode_set()`, if `esw_create_offloads_fdb_tables()` fails after `esw_destroy_offloads_fdb_tables()`, restore `esw->offloads.encap = !encap` and recreate FDB tables before clearing `eswitch_operation_in_progress`. In `mlx5_cmd_update_root_ft()`, updating an `FS_FT_FDB` root FT on a shared-FDB LAG master must update peers via `mlx5_cmd_set_slave_root_fdb()` and roll back peers and master to `ns->root_ft->id` on connect failure. [F282, F283, F284]
- `__esw_offloads_unload_rep()` on `REP_ETH` must unload `REP_IB` first. Set `MLX5_PRIV_FLAGS_SWITCH_LEGACY` only in `mlx5_devlink_eswitch_mode_set()` when entering `LEGACY` before `mlx5_eswitch_disable_locked()`, never during general teardown. In `mlx5_eswitch_block_encap()`, increment `num_block_encap` under `mode_lock` only when `esw->mode == MLX5_ESWITCH_LEGACY` or `encap == DEVLINK_ESWITCH_ENCAP_MODE_NONE && !from_fdb`. In `esw_mode_change()`, when `MLX5_PRIV_FLAGS_DISABLE_IB_ADEV` or `mlx5_core_mp_enabled()` holds, update `esw->mode` and call `mlx5_rescan_drivers_locked()` once under `hca_devcom_comp` lock without toggling `DISABLE_IB_ADEV`. [F272, F273, F286, F346]
- In `mlx5_esw_vports_inline_set()`, revert all modified PF/VF and EC-VF vports to `esw->offloads.inline_mode` on error. `mlx5_devlink_port_fn_max_io_eqs_get/set()` subtract/add `MLX5_ESW_MAX_CTRL_EQS` (4), requiring underflow clamp on get and `check_add_overflow` into `u16` on set. [F290, F307]
- `mlx5_fw_reset_init()` leaves `dev->priv.fw_reset` `NULL` when `!MLX5_CAP_MCAM_REG(dev, mfrl)`, so `fw_reset` lifecycle helpers must check `if (!fw_reset)`. `mlx5_sync_reset_set_reset_requested()` stops health polling, starts sync reset polling, and schedules `reset_timeout_work` (if `!DROP_NEW_REQUESTS`); `mlx5_sync_reset_clear_reset_requested()` cancels `reset_timeout_work`, stops sync reset polling, and restarts health polling if `poll_health`. `mlx5_pci_link_toggle()` must save state and lock config access on all `bridge_bus->devices` before toggling `PCI_EXP_LNKCTL_LD` and unlock/restore them on exit. `&dev->iseg->initializing` reset bits require `ioread32be`/`iowrite32be`, `mlx5_reg_mcda_set()` requires 4-byte aligned `size` with `htonl()`, and `temp_warn()` must mask `sensor_warning_lsb` with `0x1`. [F258, F291, F306, F308, F344, F349]

## Synchronization
- Acquire `fs_node.lock` top-down (`ft` `FS_LOCK_GRANDPARENT`, `fg` `FS_LOCK_PARENT`, `fte` `FS_LOCK_CHILD`) via `nested_down_read/write_ref_node()`. In `mlx5_del_flow_rules()`, hold `down_write_ref_node(&fte->node, false)` across the `tree_remove_node(&handle->rule[i]->node, true)` loop and any `del_hw_func`/`modify_fte()`. `alloc_insert_flow_group()` and `insert_fte()` insert with `node.active = false` before HW creation, so `lookup_fte_locked()` must acquire `nested_down_write_ref_node(&fte_tmp->node, FS_LOCK_CHILD)` after `tree_get_node()` before checking `node.active`. [F235, F237, F242, F356]
- `build_match_list()` pins flow groups under `rcu_read_lock()` via `tree_get_node(&g->node)` (no `GFP_KERNEL`), and `free_match_list(match_head, ft_locked)` requires `ft_locked = true` iff `ft->node.lock` is write-locked. When `_mlx5_add_flow_rules()` or `try_add_to_existing_fg()` drops locks during search, revalidate `ft->node.version` and `matched_fgs_get_version(match_head)` (summed as `u64`) before FTE insertion or autogroup allocation. [F210, F240, F241, F327]
- Hold `root->chain_lock` across flow table create/connect/disconnect, `FWD_NEXT_PRIO`/`FWD_NEXT_NS` rule insertion, and `underlay_qpns` updates. Hold `fs_pool->pool_lock` throughout `mlx5_fs_pool_acquire_index()` and `mlx5_fs_pool_release_index()`. [F238, F247]
- In `mlx5_fc_create()`, initialize `counter->cache.lastuse`, `lastbytes`, and `lastpackets` before `xa_store()` when `aging` is true. In `mlx5_fc_stats_query_all_counters()`, `bulk_base_id` is `counter->id & ~0x3`; after `xas_unlock(&xas)` for `mlx5_cmd_fc_bulk_query()`, call `xas_reset(&xas)` and `continue` under `xas_lock(&xas)` before indexing by `counter->id - bulk_base_id`, and only call `update_counter_cache()` if `time_after64(bulk_query_time, counter->cache.lastuse)`. [F226, F274, F275, F296]
- Hold `termtbl_mutex` while accessing `termtbl_tbl` and `tt->ref_count`, releasing it in `mlx5_eswitch_termtbl_put()` before `mlx5_del_flow_rules()`/`mlx5_destroy_flow_table()`. Hold `esw->state_lock` in devlink port fn callbacks accessing `vport->enabled`, `vport->info`, or `enabled_ipsec_vf_count` (fail with `-EBUSY` if `!enabled_ipsec_vf_count && dev->num_ipsec_offloads`). In `mlx5_devlink_eswitch_{mode,inline_mode,encap_mode}_set()`, drop `mode_lock` after setting `eswitch_operation_in_progress = true` and re-acquire to clear it. [F234, F248, F288, F363]
- Pass `locked = true` to `mlx5_sync_reset_unload_flow()` iff holding `devl_lock`. In `mlx5_fw_reset_complete_reload()`, if `MLX5_FW_RESET_FLAGS_PENDING_COMP` is set, only signal `complete(&fw_reset->done)` and do not call `mlx5_sync_reset_unload_flow()`, `mlx5_load_one()`, or `devl_lock()`. In `mlx5_cmd_fast_teardown_hca()`, bound `mlx5_get_nic_state()` polling by `mlx5_tout_ms(dev, TEARDOWN)` and abort with `-EACCES` if `pci_channel_offline(dev->pdev)`. [F231, F350, F361]

## Object Lifetimes
- `tree_add_node()` increments `parent->refcount`, released by `tree_put_node()` only after `node->refcount == 0`, `del_hw_func`, list unlink under `down_write_ref_node(parent_node, locked)`, and `del_sw_func`. `tree_remove_node()` decrements `node->refcount` and returns `-EEXIST` when `refcount > 1`, so `mlx5_destroy_flow_table()`/`group()` consume the caller's ref even when children defer destruction. `lookup_fte_locked()` returns an `fs_fte` with two refs and write lock, requiring both `up_write_ref_node(&fte->node, false)` and `tree_put_node(&fte->node, false)`. [F205, F206, F209]
- `mlx5_cmd_create_flow_table()` gets `size` via `mlx5_ft_pool_get_avail_sz()` (`0` = `-ENOSPC`), returns non-zero `size` via `mlx5_ft_pool_put_sz()` on error, and saves `ft->max_fte = size` for `mlx5_cmd_destroy_flow_table()`. [F211, F252]
- `mlx5_fc_local_create()` allocates `counter->bulk` without `fcs[]` or `bitmask`, initializes `hws_action_refcount = 0`, `hws_data.lock`, and `fc_local_refcount = 1`, and `del_sw_hw_rule()` must call `mlx5_fc_local_put()`. Never index `bulk->fcs[]` or pass `MLX5_FC_TYPE_LOCAL` to `mlx5_fc_release()`/`mlx5_fc_destroy()`; `mlx5_fc_local_get/put()` are no-ops for `MLX5_FC_TYPE_ACQUIRED` (freed via `mlx5_fc_destroy()`). `mlx5_cleanup_fc_stats()` must stop `work`, destroy `wq`, and `mlx5_fc_release()` all counters in `fc_stats->counters` before `mlx5_fc_pool_cleanup()`. [F203, F204, F215, F332]
- Symmetrically release table refs and `esw->offloads.num_flows` from `mlx5_eswitch_add_{offloaded,fwd}_rule()` in `__mlx5_eswitch_del_rule()` and on error paths. In `mlx5_esw_vport_vhca_id_map()`, free `vhca_map_entry` if `xa_is_err(old_entry)`, else `kfree(old_entry)`. `mlx5_events_stop()` unregisters `events->notifiers` in reverse order before `flush_workqueue(events->wq)`, and `mlx5_events_cleanup()` destroys `events->wq` before freeing `events`. `mlx5_fw_reset_set_reset_sync()` and `mlx5_fw_reset_wait_reset_done()` must clear `PENDING_COMP` on error/exit, and `mlx5_drain_fw_reset()` must set `DROP_NEW_REQUESTS` before cancelling work. [F221, F222, F223, F224, F232]

## API Contracts
- `mlx5_get_{flow,flow_vport,fdb_sub,root}_namespace()` return `NULL`; `mlx5_create_flow_table()` and `mlx5_{modify_header,packet_reformat}_alloc()` return `ERR_PTR`. Look up `ESW_EGRESS`, `ESW_INGRESS`, and `RDMA_TRANSPORT_{RX,TX}` via `mlx5_get_flow_vport_namespace()` using `vport->index` (not `vport->vport`). `mlx5_flow_namespace_set_mode()` requires root `FS_FT_FDB` (`&root->ns == ns`), and `cmds->create_ns(root)` must succeed before `root->cmds->destroy_ns(root)`. `mlx5_fs_mode_validate()` must reject changes when `mlx5_eswitch_mode(dev) == MLX5_ESWITCH_OFFLOADS` before mode-specific returns. [F214, F255, F268, F309, F375]
- `__mlx5_create_flow_table()` mutates managed `ft_attr->level += fs_prio->start_level` (`level < fs_prio->num_levels`). On auto-grouped tables, `mlx5_create_flow_group()` rejects `start_flow_index < ft->autogroup.max_fte` (`-EPERM`) and `_mlx5_add_flow_rules()` rejects `flow_act->fg` (`-EINVAL`). `dest_is_valid()` requires `dest->ft->level > ft->level` unless `FLOW_ACT_IGNORE_FLOW_LEVEL` is set on matching `FDB`/`NIC_RX`/`NIC_TX` tables. `mlx5_modify_rule_destination()` requires non-NULL `old_dest` when `handle->num_rules > 1`. [F266, F267, F270, F271]
- `cmds->create_match_definer` and `mlx5_esw_try_lock()` return `>= 0` on success or `< 0` on error (test `< 0`, never `if (err)`). `mlx5_eswitch_get_vport()` returns `ERR_PTR`; `mlx5_eswitch_{get,vport}_rep()` return `NULL`. `mlx5_esw_match_metadata_alloc()` returns `0` on failure (check `!metadata`), `mlx5_esw_match_metadata_free()` masks with `(1 << ESW_VPORT_BITS) - 1`, `esw_offloads_vport_metadata_cleanup()` skips `MLX5_VPORT_UPLINK`, and `mlx5_eswitch_get_vport_metadata_for_match()` shifts left by 16 bits unlike `_for_set()`. [F250, F251, F253, F254, F301, F302]
- Query `query_ctx` via `mlx5_vport_get_other_func_cap()` under `esw->state_lock` and pass `MLX5_ADDR_OF(query_hca_cap_out, query_ctx, capability)` to `mlx5_vport_set_other_func_cap()`. `mlx5_cmd_fc_get_bulk_query_out_len()` returns byte size while `mlx5_cmd_fc_bulk_query()` takes count. `mlx5_fs_pool_init()` requires non-NULL `bulk_destroy`, `bulk_create`, and `update_threshold`. `mlx5_notifier_register()` runs in atomic EQ context; sleeping callbacks require `mlx5_blocking_notifier_register()`. [F230, F289, F337, F339, F365]
- Check `MLX5_CAP_GEN(dev, mcam_reg)` and `MLX5_CAP_MCAM_REG/REG2/FEATURE()` before accessing `MCQI`/`MCC`/`MCDA`/`MCQS`/`MIRC`/`MPEIN`/`MFRL`. Initialize `*fwhandle = 0` before `mlx5_reg_mcc_query()`, and pass `data_size <= MLX5_UN_SZ_BYTES(mcqi_reg_data)` to `mlx5_reg_mcqi_query()`. `mlx5_is_reset_now_capable()` rejects sync reset when `!fast_teardown`, non-ECPF SFs exist, non-hot-reset PCIe hotplug interrupts are enabled, or unknown sibling PCI IDs exist. [F264, F340, F347, F348]

## Error Handling
- When `try_add_to_existing_fg()` skips `!g->node.active`, set `try_again = true` and return `ERR_PTR(-EAGAIN)` (not `-ENOENT`). In `__mlx5_create_flow_table()`, if `connect_flow_table()` fails, jump to `destroy_ft` (`destroy_flow_table()` and `rhltable_destroy()`). In `init_rdma_transport_{rx,tx}_root_ns_one()` and `mlx5_fs_add_vport_acl_root_ns()`, call `cleanup_root_ns()` on failure; in `init_*_root_ns()`, also reset `steering->*_root_ns = NULL`. [F212, F213, F249, F260]
- In `esw_chains_create()`, on error after setting `esw_chains_priv`, release tables, call `mlx5_chains_destroy()`, and clear `esw_chains_priv = NULL`. Guard `esw->devcom` with `IS_ERR_OR_NULL()` in `mlx5_esw_offloads_devcom_cleanup()`. In `mlx5_eswitch_add_termtbl_rule()`, index `dest` by `i` and `attr->dests` by `num_vport_dests`; `revert_changes` must restore VLAN actions, `attr->dests[curr_dest].termtbl = NULL`, `dest[i]` matching `tt->termtbl`, and call `mlx5_eswitch_termtbl_put()`. Store `mlx5_destroy_flow_table()` error-path return in `err2`. In `port_module()`, update `pme_stats` before `printk_ratelimit()`, and ratelimit `temp_warn()`/`mlx5_pcie_event()`. [F217, F220, F259, F261, F316, F373]

## External Contracts
- Entering `DEVLINK_ESWITCH_MODE_SWITCHDEV` in `mlx5_devlink_eswitch_mode_set()` must call `mlx5_devlink_netdev_netns_immutable_set(devlink, true)` under `rtnl_lock()` and verify `net_eq(dev_net(netdev), devlink_net(devlink))`, reverting to `false` on failure. [F366]

## Known Pitfalls
- Check `ft->node.parent` or `!(ft->flags & MLX5_FLOW_TABLE_UNMANAGED)` before `fs_get_obj(prio, ft->node.parent)`. In `check_conflicting_actions()`, test `== MLX5_FLOW_CONTEXT_ACTION_COUNT` before `xored_actions`. In `mlx5_get_flow_namespace()`, every non-root, non-NIC-RX `switch` case must set both `root_ns` and `prio`. Zero-initialize `flow_act->vlan` including padding before `mlx5_eswitch_termtbl_get_create()`. In `esw_add/del_fdb_peer_miss_rules()`, query `peer_dev`/`peer_esw` for sizing/vports/caps while inserting rules on local `esw`. In `mlx5_eswitch_add_send_to_vport_rule()`, use `from_esw` for source, `rep->esw` for dest, and `on_esw` for table/rule insertion. In `mlx5_get_boot_img_component_index()`, check `identifier == MCQS_IDENTIFIER_BOOT_IMG` after the loop. [F263, F310, F312, F319, F320, F321, F335]
