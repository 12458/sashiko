# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 15)

Hardware IP block driver for GFX v9.0 (Vega10/12/20, Raven, Picasso, Renoir, Arcturus, Aldebaran), plus RAS EDC error querying/injection and golden register/shader initialization for GFX v9.4 (Arcturus) and GFX v9.4.2 (Aldebaran).

## Architecture & Data Flow

- On compute-only GFX9 ASICs (`IP_VERSION(9, 4, 1)` Arcturus, `IP_VERSION(9, 4, 2)` Aldebaran), `adev->gfx.num_gfx_rings` is `0`; any code accessing `gfx_ring`, `sw_gfx_ring`, `muxer`, or 3D/CPG hardware state must guard on `adev->gfx.num_gfx_rings`. [F1680]
- `adev->gfx.ras` is only populated on `IP_VERSION(9, 4, 0)`, `9.4.1`, and `9.4.2`, and `enable_watchdog_timer` only on `gfx_v9_4_2_ras`, so callers must NULL-check both pointers. Likewise, `gfx_v9_0_alloc_ip_dump` sets `ip_dump_core` or `ip_dump_compute_queues` to `NULL` on `kcalloc` failure without failing `sw_init`, so `gfx_v9_ip_dump` and `gfx_v9_ip_print` must NULL-check both. [F1681, F1682]
- Compute `ring->me` is 1-based (`mec + 1`, as ME 0 is GFX): `soc15_grbm_select` and `gfx_v9_0_get_cpc_int_cntl` take `1 + i` for 0-based MEC index `i`, whereas `gfx_v9_0_kiq_map_queues` (`PACKET3_MAP_QUEUES_ME`) and `gfx_v9_0_compute_ring_init` EOP IRQ calculations use `ring->me - 1`. [F1712]
- MEC interrupt and wave-limit helpers (`gfx_v9_0_set_compute_eop_interrupt_state`, `gfx_v9_0_get_cpc_int_cntl`, `gfx_v9_0_set_cp_ecc_error_state`, `gfx_v9_0_emit_wave_limit`) must only touch MEC1 (`me == 1`, pipes 0–3) and never MEC2. When `gfx_v9_0_emit_wave_limit` throttles pipes for a high-priority compute ring, it must skip `ring->pipe` (`if (i != ring->pipe)`). [F1697, F1698]
- In `gfx_v9_0_kiq_init_queue` and `gfx_v9_0_kcq_init_queue`, fresh MQD init must `memset` the full `sizeof(struct v9_mqd_allocation)` (not `sizeof(struct v9_mqd)`) and set `dynamic_cu_mask` and `dynamic_rb_mask` to `0xFFFFFFFF` before `gfx_v9_0_mqd_init`; restoring from `mqd_backup` must reset `ring->wptr = 0`, call `amdgpu_ring_clear_ring(ring)`, and (for KCQ) zero `*ring->wptr_cpu_addr`. [F1688, F1700]
- Every compute and KIQ ring using `gfx_v9_0_ring_funcs_compute` or `gfx_v9_0_ring_funcs_kiq` must set `ring->use_doorbell = true`, as `gfx_v9_0_ring_get_wptr_compute` and `gfx_v9_0_ring_set_wptr_compute` invoke `BUG()` otherwise. [F1785]
- In `gfx_v9_0_do_edc_gpr_workarounds` and `gfx_v9_4_2_run_shader`, shader byte offsets (`vgpr_offset`, `sgpr_offset`, `shader_offset`) must be 256-byte aligned via `ALIGN(..., 256)` and added as `u64` to `ib.gpu_addr` before shifting right by 8 (`>> 8`) for `mmCOMPUTE_PGM_LO`/`HI`. `vgpr_init_regs`, `vgpr_init_regs_arcturus`, `sgpr1_init_regs`, and `sgpr2_init_regs` must keep 6 leading non-SE entries before `mmCOMPUTE_STATIC_THREAD_MGMT_SE0..SE7` to match `gpr_reg_size = adev->gfx.config.max_shader_engines + 6`. [F1704, F1736]
- In `gfx_v9_4_2_do_sgprs_init` and `gfx_v9_4_2_do_vgprs_init`, `wb_ib` must be allocated and zeroed for `(1 + wb_size) * sizeof(uint32_t)` bytes (`wb_ib.ptr[0]` is the stop-wave control word; `&wb_ib.ptr[1]` is `wb_ptr`). In `gfx_v9_4_2_wait_for_waves_assigned`, `wave_cnt` and `offset` must be reset to `0` at the start of each `do ... while (++loop < 2000 && wait)` pass, and `offset++` must run on every `(se, cu, simd, wave)` slot even when `(1 << wave) & mask` is false. [F1730, F1742]
- `gfx_v9_0_init_gds_vmid` must only clear GDS/GWS/OA registers for `vmid >= 1` (never VMID 0), whereas `gfx_v9_0_do_edc_gds_workarounds` must reset `mmGDS_VMID0_SIZE` back to `0` after temporarily setting it to `adev->gds.gds_size`. [F1699]
- In `gfx_v9_0_update_gfx_clock_gating` (under RLC safe mode), `gfx_v9_0_update_medium_grain_clock_gating` (MGCG/MGLS) must be enabled before `gfx_v9_0_update_3d_clock_gating` and `gfx_v9_0_update_coarse_grain_clock_gating` (CGCG/CGLS), and disabled after them. [F1705]
- In `gfx_v9_0_query_utc_edc_status`, `gfx_v9_0_reset_ras_error_count`, `gfx_v9_4_query_utc_edc_status`, and `gfx_v9_4_reset_ras_error_count`, all UTC L2 index registers (`*ECC_INDEX`, `*EDC_INDEX`, `*DSM_INDEX`) must be reset to `255` after iterating over subblocks. [F1707]
- `gfx_v9_ip_dump`, `gfx_v9_ip_print`, and `gfx_v9_0_alloc_ip_dump` must iterate `(mec, pipe, queue)` in identical order with stride `ARRAY_SIZE(gc_cp_reg_list_9)` and substitute `mmCP_MEC_ME2_HEADER_DUMP` when `mec > 0` and `reg_offset == mmCP_MEC_ME1_HEADER_DUMP`. [F1709]
- In `gfx_v9_1_parse_ind_reg_list` and `gfx_v9_1_init_rlc_save_restore_list`, the indirect section of `register_list_format` holds 3-dword tuples terminated by `0xFFFFFFFF`; the cursor must advance by 1 dword on `0xFFFFFFFF` and 3 dwords per indirect entry. [F1734]
- Sentinels & bounds: `gfx9_cs_data` and its `sect->section` arrays in `gfx_v9_0_get_csb_size`/`gfx_v9_0_cp_gfx_start` must end with `NULL` sentinels; `amdgpu_gfxoff_quirk_list` must stay `static const` with a `{ 0, 0, 0, 0, 0 }` sentinel and `gfx_v9_0_should_disable_gfxoff` must match all 5 PCI fields (`vendor`, `device`, `subsystem_vendor`, `subsystem_device`, `revision`); `gfx_v9_ring_insert_nop` must return early when `num_nop == 1` before evaluating `num_nop - 2`. [F1718, F1719, F1761]
- FW & IP dispatch: `gfx_v9_0_ring_emit_reg_write_reg_wait` may only emit combined `gfx_v9_0_wait_reg_mem` (`opt = 1`) when `me_fw_write_wait` (GFX) or `mec_fw_write_wait` (other rings) is set, else using `amdgpu_ring_emit_reg_write_reg_wait_helper`; `gfx_v9_0_ring_emit_cleaner_shader` emits `PACKET3_RUN_CLEANER_SHADER` on `IP_VERSION(9, 4, 2)` and `PACKET3_RUN_CLEANER_SHADER_9_0` otherwise (enabled in `sw_init` only when CP `me`/`pfp`/`mec` FW versions meet thresholds); `gfx_v9_0_init_golden_registers` skips `golden_settings_gc_9_x_common` on GC 9.3.0/9.4.1/9.4.2, and `gfx_v9_4_2_init_golden_registers` selects die 0/1 settings via `get_die_id(adev)`. [F1758, F1759, F1760]

## Synchronization

- Every function in `gfx_v9_0.c`, `gfx_v9_4.c`, and `gfx_v9_4_2.c` selecting an SE/SH/instance via `mmGRBM_GFX_INDEX` or `regGRBM_GFX_INDEX` under `adev->grbm_idx_mutex` (e.g., `gfx_v9_0_wait_for_rlc_serdes`) must restore broadcast addressing (`0xffffffff, 0xffffffff, 0xffffffff` or `0xe0000000`) before unlocking `grbm_idx_mutex` on every exit path. [F1664]
- Every function calling `soc15_grbm_select` for a non-zero ME/pipe/queue/VMID must hold `adev->srbm_mutex` and reset via `soc15_grbm_select(adev, 0, 0, 0, 0, 0)` before unlocking. When both RLC safe mode and `srbm_mutex` are needed (`gfx_v9_0_kiq_reset_hw_queue`, `gfx_v9_0_reset_kcq`), `amdgpu_gfx_rlc_enter_safe_mode` must precede `mutex_lock(&adev->srbm_mutex)` and `amdgpu_gfx_rlc_exit_safe_mode` must follow `mutex_unlock(&adev->srbm_mutex)`. [F1665, F1671]
- In `gfx_v9_0_kiq_read_clock`, errors between `amdgpu_ring_alloc` and `amdgpu_ring_commit` must jump to `failed_undo` (`amdgpu_ring_undo` under `kiq->ring_lock`); after unlocking `kiq->ring_lock`, if initial `amdgpu_fence_wait_polling` returns `< 1` while `amdgpu_in_reset(adev)` is true, it must jump immediately to `failed_kiq_read` (freeing `reg_val_offs` without sleeping or re-unlocking), and on success execute `mb()` before reading `adev->wb.wb[reg_val_offs]`. [F1657, F1673]
- When `adev->gfx.mcbp` is enabled: `gfx_v9_0_sw_init` must set `gfx_ring[i].no_scheduler = true` before `amdgpu_ring_init` so the scheduler runs only on `sw_gfx_ring[i]`; in `gfx_v9_0_eop_irq` (`me_id == 0`), `amdgpu_mcbp_handle_trailing_fence_irq(&adev->gfx.muxer)` must run first and `amdgpu_fence_process` on `sw_gfx_ring[i]` only when it returns false. [F1666, F1667]
- In `gfx_v9_0_ring_set_wptr_gfx` and `gfx_v9_0_ring_set_wptr_compute`, when `ring->use_doorbell` is true, `atomic64_set((atomic64_t *)ring->wptr_cpu_addr, ring->wptr)` must precede `WDOORBELL64(ring->doorbell_index, ring->wptr)`. In `gfx_v9_0_ring_emit_vm_flush` on `AMDGPU_RING_TYPE_GFX`, `PACKET3_PFP_SYNC_ME` must be emitted immediately after `amdgpu_gmc_emit_flush_gpu_tlb`. [F1675, F1676]

## Object Lifetimes

- `gfx_v9_4_2_run_shader` frees `ib` via `amdgpu_ib_free` if `amdgpu_ib_schedule` fails and only transfers ownership of `ib` and `*fence_ptr` on return `0`; callers (`gfx_v9_4_2_do_sgprs_init`, `gfx_v9_4_2_do_vgprs_init`) must branch past that dispatch's `amdgpu_ib_free`/`dma_fence_put` label on error. [F1654]
- In `gfx_v9_0_ring_test_ib` and `gfx_v9_0_do_edc_gpr_workarounds`, `struct dma_fence *f` must be initialized (or reset) to `NULL` before each `amdgpu_ib_schedule` call because `err2:` and `fail:` unconditionally call `dma_fence_put(f)`. [F1656]
- In `gfx_v9_0_mec_init`, each BO from `amdgpu_bo_create_reserved` (`hpd_eop_obj`, `mec_fw_obj`) must call `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` on success, and any error path must call `gfx_v9_0_mec_fini(adev)`. In `gfx_v9_0_init_cp_compute_microcode`, failure to load optional `mec2_fw` must reset `err = 0` and call `amdgpu_ucode_release(&adev->gfx.mec2_fw)`, whereas non-zero `err` at `out:` releases `mec_fw`. [F1658, F1659]
- `sw_init`/`sw_fini` ordering: `gfx_v9_0_mec_init` must precede `gfx_v9_0_compute_ring_init`, and `sw_fini` must call `amdgpu_ring_fini` on all compute rings before `gfx_v9_0_mec_fini`; in `sw_fini`, `amdgpu_gfx_mqd_sw_fini(adev, 0)` and `amdgpu_gfx_kiq_free_ring(&adev->gfx.kiq[0].ring)` must precede `amdgpu_gfx_kiq_fini(adev, 0)`; if `amdgpu_gfx_cleaner_shader_sw_init` fails in `sw_init`, `adev->gfx.enable_cleaner_shader` must be reset to `false`. [F1660, F1661, F1749]
- `gfx_v9_0_ring_begin_use_compute` and `gfx_v9_0_ring_end_use_compute` must bracket `gfx_v9_0_set_powergating_state` (`AMD_PG_STATE_UNGATE` on begin, `AMD_PG_STATE_GATE` on end for `IP_VERSION(9, 1, 0)`) inside `amdgpu_gfx_enforce_isolation_ring_begin_use` and `amdgpu_gfx_enforce_isolation_ring_end_use` in reverse order. [F1663]
- In `gfx_v9_0_hw_fini`, `amdgpu_gfx_disable_kcq` must run before disabling CP or stopping RLC (unless `amdgpu_ras_intr_triggered()` is true), and under `amdgpu_sriov_vf(adev)` `CP_PQ_WPTR_POLL_CNTL.EN` must be cleared to `0` after `gfx_v9_0_cp_gfx_enable(adev, false)`. [F1668]

## API Contracts

- `gfx_v9_0_query_ras_error_count`, `gfx_v9_4_query_ras_error_count`, and `gfx_v9_4_2_query_ras_error_count` must zero `err_data->ue_count` and `ce_count` before accumulating (`+=`) from SRAM/UTC helpers. `gfx_v9_4_2_query_sram_edc_count` and `gfx_v9_4_2_query_utc_edc_count` treat `NULL` `sec_count`/`ded_count` as reset-only mode (clearing counters without reading/logging) and zero non-NULL pointers at entry. [F1686, F1687]
- `gfx_v9_0_ras_fields`, `gfx_v9_4_ras_fields`, `gfx_v9_4_2_ras_fields`, and `gfx_v9_4_2_utc_blocks` store pre-shifted masks (`*_count_mask`) and shifts (`*_count_shift`), so counts must be extracted via `(value & mask) >> shift`. `gfx_v9_0_ras_error_inject` must check `sub_block_index < ARRAY_SIZE(ras_gfx_subblocks)`, non-NULL `name`, and matching `hw_supported_error_type`/`sw_supported_error_type` before `psp_ras_trigger_error`. [F1694, F1789]
- `gfx_v9_4_2_run_shader` takes `shader_size` in bytes (dividing by `sizeof(u32)` when copying to `ib->ptr`) and `regs_size` as an element count (`ARRAY_SIZE`), whereas `gfx_v9_4_2_wait_for_waves_assigned` takes `wb_ptr` as `&wb_ib.ptr[1]`. [F1692]
- Ring alignment: GPU addresses in `gfx_v9_0_wait_reg_mem` (`mem_space != 0`), `gfx_v9_0_ring_emit_ib_gfx`, and `gfx_v9_0_ring_emit_ib_compute` must be 4-byte aligned; `gfx_v9_0_ring_emit_fence` requires 8-byte alignment (`!(addr & 0x7)`) with `AMDGPU_FENCE_FLAG_64BIT` and 4-byte alignment otherwise, while `gfx_v9_0_ring_emit_fence_kiq` forbids `AMDGPU_FENCE_FLAG_64BIT` (32-bit KIQ writeback slots). [F1693, F1720, F1721]
- In `gfx_v9_0_ring_emit_ce_meta`, `gfx_v9_0_ring_emit_de_meta`, and `gfx_v9_0_ring_emit_ib_gfx`, `amdgpu_ring_ib_on_emit_ce`, `amdgpu_ring_ib_on_emit_de`, and `amdgpu_ring_ib_on_emit_cntl` must run immediately before writing the CE/DE payload or IB `control` dword so `gfx_v9_0_ring_patch_*` offsets match. Each callback in `gfx_v9_0_kiq_pm4_funcs` (`set_resources`, `map_queues`, `unmap_queues`, `query_status`, `invalidate_tlbs`) must emit the exact Dword count in its `*_size` field (8, 7, 6, 7, 2). [F1701, F1787]

## Error Handling

- In `gfx_v9_4_2_do_sgprs_init`, if `gfx_v9_4_2_wait_for_waves_assigned` fails for `disp_ibs[0..2]`, `wb_ib.ptr[0]` must be set to `0xdeadbeaf` to stop spinning shader waves before jumping to `disp0_failed`/`disp1_failed`/`disp2_failed` to free the IBs. [F1655]
- `gfx_v9_0_ring_test_ib` must store `dma_fence_wait_timeout` in a signed `long`, translating `0` to `-ETIMEDOUT` and propagating `< 0` errors before checking the writeback slot. [F1678]
- `gfx_v9_0_do_edc_gpr_workarounds`, `gfx_v9_4_2_do_sgprs_init`, and `gfx_v9_4_2_do_vgprs_init` must verify `amdgpu_ras_is_supported(adev, AMDGPU_RAS_BLOCK__GFX)` and `sched.ready` on every target `compute_ring` (including `compute_ring[1]` in `gfx_v9_4_2_do_sgprs_init`), returning `0` if not ready. [F1683]

## External Contracts

- `gfx_v9_0_read_wave_data` must write format version `1` into `dst[(*no_fields)++]` first, followed by the 15 wave status registers (16 dwords total, fitting in `amdgpu_debugfs_wave_read`'s `data[32]`). In `gfx_v9_0_mqd_init`, `mqd->cp_hqd_active` must only be set to `1` when `ring->funcs->type == AMDGPU_RING_TYPE_KIQ`. [F1723, F1792]

## Known Pitfalls

- In `gfx_v9_0_ring_patch_ce_meta` and `gfx_v9_0_ring_patch_de_meta`, `offset` and `ring->buf_mask + 1` are in dwords while `payload_size` is in bytes; when `offset + (payload_size >> 2) > ring->buf_mask + 1`, copy `(ring->buf_mask + 1 - offset) << 2` bytes first before wrapping the remainder to `&ring->ring[0]`. [F1713]
- In `gfx_v9_0_sw_init`, `j` iterates `num_queue_per_pipe` (outer) and `k` iterates `num_pipe_per_mec` (inner), so `k` (pipe) must be passed before `j` (queue) to `amdgpu_gfx_is_mec_queue_enabled` and `gfx_v9_0_compute_ring_init`, and `ring_id` must increment only for enabled queues. [F1724]
- In `gfx_v9_0_get_cu_info`, `disable_masks` is indexed by `[i * max_sh_per_se + j]`, but 4x4 arrays `cu_info->bitmap[0]` and `cu_info->ao_cu_bitmap` must be indexed as `[i % 4][j + i / 4]` so 8-SE/1-SH ASICs (Arcturus) do not overflow, and `ao_cu_mask |= (ao_bitmap << (i * 16 + j * 8))` must stay guarded by `if (i < 2 && j < 2)`. [F1732, F1738]
- Writeback offsets from `amdgpu_device_wb_get` (`gfx_v9_0_ring_test_ib`, `gfx_v9_0_kiq_read_clock`, `gfx_v9_0_ring_emit_rreg`) index `adev->wb.wb[]` as unscaled dword offsets on CPU, whereas GPU addresses added to `adev->wb.gpu_addr` must multiply the offset by 4. [F1746]
- In `gfx_v9_0_hw_fini`: on driver unbind (`!amdgpu_in_reset(adev) && !adev->in_suspend`), `gfx_v9_0_kiq_fini_register` must be called under `adev->srbm_mutex` with KIQ's ME/pipe/queue selected via `soc15_grbm_select`; `adev->gfx.rlc.funcs->stop(adev)` must be skipped when `adev->gmc.xgmi.connected_to_cpu && amdgpu_in_reset(adev)` or `GC_HWIP >= IP_VERSION(9, 4, 2)`. [F1752, F1753]
- Lifecycle & resume quirks: in `gfx_v9_0_ecc_late_init`, `gfx_v9_0_do_edc_gds_workarounds` must only run on cold boot (`!adev->in_suspend`) when `adev->gds.gds_size` is non-zero, and GPR/GDS ECC workarounds must stay in `late_init`; in `gfx_v9_0_cp_gfx_start`, APUs resuming from S3 without firmware (`AMD_IS_APU && adev->in_s3 && !pm_resume_via_firmware()`) must return early before submitting CSB packets to `gfx_ring[0]`. [F1755, F1773]
- Register access, clocks & PG: `gfx_v9_0_select_se_sh`, `gfx_v9_4_select_se_sh`, and `gfx_v9_4_2_select_se_sh` must write `GRBM_GFX_INDEX` via `WREG32_SOC15_RLC_SHADOW*`, and `wave_read_ind`/`wave_read_regs` must write `SQ_IND_INDEX` via `WREG32_SOC15_RLC*` per `rlcg_access_gc_9_0`; `gfx_v9_0_get_gpu_clock_counter` on `IP_VERSION(9, 3, 0)` reads SMUIO TSC under `preempt_disable()` with `RREG32_SOC15_NO_KIQ` and rollover check, while other GFX9 versions bracket the read with `amdgpu_gfx_off_ctrl` and `gpu_clock_mutex`; in `gfx_v9_0_set_powergating_state` on GC 9.1.0/9.2.2/9.3.0, `amdgpu_gfx_off_ctrl_immediate(adev, false)` must precede PG register writes when ungating (`!enable`), and `amdgpu_gfx_off_ctrl_immediate(adev, true)` must follow them when gating (`enable`). [F1764, F1766, F1771]
