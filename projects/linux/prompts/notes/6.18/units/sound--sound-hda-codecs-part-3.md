# SOUND — sound/hda/codecs (part 3)

This unit implements HD-Audio codec drivers for Realtek ALC codecs (`ALC260`–`ALC882/1220` and shared helpers) and the Silicon Labs `Si3054` modem codec, handling COEF registers, GPIO/mute LEDs, CTIA/OMTP headset detection, quirk fixup tables, and companion smart-amp binding.

## Architecture & Data Flow
- `struct alc_spec` must keep `struct hda_gen_spec gen` at offset 0 because `snd_hda_gen_*` callbacks cast `codec->spec` directly to `struct hda_gen_spec *`; `alc_set_beep_amp()` must keep `alc_beep_mixer` `static const` and only write `beep_amp` into `knew->private_value` returned by `snd_hda_gen_add_kctl()`; keycodes in `u8 alc_mute_keycode_map[1]` (`alc_register_micmute_input_device()`) must be `<= 255`. [F229, F236, F248]
- In `alc_update_headset_mode()`, `ALC_HEADSET_MODE_UNPLUGGED` must reset `spec->current_headset_type = ALC_HEADSET_TYPE_UNKNOWN` alongside `current_headset_mode` and `gen.hp_jack_present` (since `ALC_HEADSET_MODE_HEADSET` only calls `alc_determine_headset_type()` when type is `UNKNOWN`), and `ALC_HEADSET_MODE_MIC` must skip the post-switch `snd_hda_set_pin_ctl_cache()` block because `alc_headset_mode_mic_in()` disables `hp_pin` output and sets `PIN_VREF50` on `spec->headphone_mic_pin`. [F184, F214]
- On resume, `alc269_resume()` must call `alc_write_gpio_data(codec)` when `spec->gpio_data` is non-zero, and `alc_fixup_headset_mode()` (`HDA_FIXUP_ACT_INIT`) must reset `current_headset_mode` and `current_headset_type` to `UNKNOWN` when `is_s3_resume(codec) || is_s4_resume(codec)`; `*_no_hp_mic` / `alc662` headset-mode wrappers (`alc_fixup_headset_mode_no_hp_mic()`, `alc_fixup_headset_mode_alc255_no_hp_mic()`, `alc_fixup_headset_mode_alc662()`) must intercept `HDA_FIXUP_ACT_PRE_PROBE` in an `if ... else` branch rather than calling `alc_fixup_headset_mode()`. [F215, F261]
- In `alc256_shutup()`, when `spec->en_3kpull_low` is true, `alc_update_coef_idx(codec, 0x46, 0, 3 << 12)` must run unconditionally before `snd_hda_jack_detect()` or clearing `AC_VERB_SET_PIN_WIDGET_CONTROL` on `hp_pin` to avoid warm-reboot stalls; in `alc225_shutup()`, when `hp1_pin_sense || hp2_pin_sense` is true, setting `3 << 10` in COEF `0x4a` and muting/disabling HP pins must be bracketed by `alc_disable_headset_jack_key()` and `alc_enable_headset_jack_key()` (after clearing `3 << 10`). [F238, F239]
- Custom pin-shutup helpers (`alc_headset_mic_no_shutup()`) must return early when `codec->bus->shutdown` is set, clear `AC_VERB_SET_PIN_WIDGET_CONTROL` without modifying the cached pin target, and set `codec->pins_shutup = 1` for `restore_shutup_pins()`. [F192]
- In `alc225_init()` and `alc294_init()`, `alc285_hp_init()` / `alc294_hp_init()` must only run when `!spec->done_hp_init` or on `is_s3_resume` / `is_s4_resume` and must set `spec->done_hp_init = true`; in `alc_fixup_no_depop_delay()`, disabling depop delays must set both `spec->no_depop_delay = 1` and `codec->depop_delay = 0`. [F193, F195]
- Fixups enabling VREF on an output/amp pin at `HDA_FIXUP_ACT_INIT` via `snd_hda_set_pin_ctl()` (`alc889_fixup_mbp_vref()`, `alc889_fixup_mac_pins()`, `alc861_fixup_asus_amp_vref_0f()`) must set `spec->gen.keep_vref_in_automute = 1`; fixups registering `vref_mute_led_set` (`spec->mute_led_nid`) or `vref_micmute_led_set` (`spec->cap_mute_led_nid`) in `alc269.c` must set that NID field and `codec->power_filter = led_power_filter`. [F188, F222]
- In `alc269_fixup_hp_mute_led()`, the hex `pin` parsed from `"HP_Mute_LED_%d_%x"` must be bounds-checked to `[0x0a, 0x10)` before computing `spec->mute_led_nid = pin - 0x0a + 0x18`, and `sscanf()` `%x` must target an `int` / `unsigned int` before assigning to `hda_nid_t` (`u16`). [F203, F234]
- Table ordering invariants: in `rename_tbl` (`realtek.c`), narrower `coef_mask` entries (`0xffff`, `0xfff0`) must precede broader `0x00f0` entries whose `coef_bits` are a subset for the same `vendor_id`; in `snd_hda_id_alc861`, `snd_hda_id_alc662`, and `snd_hda_id_alc882`, `HDA_CODEC_ID_REV` entries must precede wildcard `HDA_CODEC_ID` entries for the same `vendor_id`; in `alc861_fixup_tbl`, `alc880_fixup_tbl`, and `alc882_fixup_tbl`, `SND_PCI_QUIRK` must precede `SND_PCI_QUIRK_VENDOR` for the same subvendor; in `alc269.c`, `SND_PCI_QUIRK_VENDOR` entries belong in `alc269_fixup_vendor_tbl` (not `alc269_fixup_tbl`, which precedes `snd_hda_pick_pin_fixup()`), and `alc269_fallback_pin_fixup_tbl` (`match_all_pins = false`) allows at most one `SND_HDA_PIN_QUIRK` per `(codec, subvendor)`. [F207, F208, F209, F210, F223]
- In `alc298_samsung_v2_init_amps()`, `spec->num_speaker_amps` must be set before `alc298_samsung_v2_disable_amps(codec)`, which must precede `alc298_samsung_v2_amp_desc_tbl` and `spec->gen.pcm_playback_hook`; in `alc260_fixup_gpio1_toggle()`, enabling HP automute on a single-output-pin board at `HDA_FIXUP_ACT_PROBE` must populate `spec->gen.autocfg.hp_pins[0]` alongside `detect_hp = 1`, `automute_speaker = 1`, and `automute_hook`. [F197, F240]
- Fallback SKU reads from pin NID `0x1d` (`0x17` on ALC260) in `alc_auto_parse_customize_define()` and `alc_subsystem_id()` must verify `ass & 1` and that bits `19:16` equal the popcount of bits `15:1`; `alc5505_dsp_init()`, `alc5505_dsp_suspend()`, and `alc5505_dsp_resume()` access NID `0x51` and require `snd_hda_codec_read(codec, 0x51, 0, AC_VERB_PARAMETERS, 0) == 0x10ec5505` (`spec->has_alc5505_dsp`). [F200, F246]
- In `si3054_pcm_prepare()`, `stream_tag & 0xf` goes into bits `15:12` (`SI3054_DTAG_MASK`) of `SI3054_LINE_LEVEL` for playback (preserving the low byte) and bits `7:4` (`SI3054_ATAG_MASK`) for capture (preserving the high byte). [F206]

## Synchronization
- `coef_mutex_lock()` must call `snd_hda_power_up_pm(codec)` before locking `spec->coef_mutex` and `coef_mutex_unlock()` must unlock before `snd_hda_power_down_pm(codec)`; callers holding `guard(coef_mutex)(codec)` (`alc_process_coef_fw()`) must use unlocked `__alc_*_coefex_idx()` helpers rather than `alc_*_coefex_idx()`. [F153]
- In `alc268_beep_switch_put()`, `codec->control_mutex` must be held while temporarily mutating `kcontrol->private_value` for NIDs `0x0f` and `0x10`, restoring `private_value` before unlocking. [F165]

## Object Lifetimes
- In `alc_alloc_spec()`, `codec->spec` and `mutex_init(&spec->coef_mutex)` must precede `alc_codec_rename_from_preset(codec)`, and any `alc*_probe` error path after `alc_alloc_spec()` succeeds must call `snd_hda_gen_remove(codec)` (`alc269_remove(codec)` in `alc269_probe()`) because `hda_codec_driver_probe()` does not call `ops->remove` on probe failure. [F160, F269]
- In `comp_master_ops`, `comp_bind()` must call `hda_component_manager_bind()` before `hda_component_manager_bind_acpi_notifications()` and `comp_unbind()` must unbind notifications before `hda_component_manager_unbind()`; `alc269_remove()` must call `hda_component_manager_free(&spec->comps, &comp_master_ops)` before `snd_hda_gen_remove(codec)` frees `codec->spec`. [F155, F156]
- In `find_cirrus_companion_amps()`, `if (!adev) return;` must guard all post-loop uses of `acpi_ids[i]`, and `acpi_dev_put(adev)` must release the `acpi_dev_get_first_match_dev()` reference after `fwnode_handle_get(acpi_fwnode_handle(adev))` (`__free(fwnode_handle)`) and before any early return. [F157, F218]
- In `alc_register_micmute_input_device()`, `spec->kb_dev` uses non-devres `input_allocate_device()`: failure must call `input_free_device()` and clear `spec->kb_dev = NULL`, registration must succeed before `snd_hda_jack_detect_enable_callback()` enables `gpio2_mic_hotkey_event` (`alc280_fixup_hp_gpio2_mic_hotkey()`, `alc233_fixup_lenovo_line2_mic_hotkey()`), and `HDA_FIXUP_ACT_FREE` must call `input_unregister_device()` and clear `spec->kb_dev = NULL`. [F164, F243]
- Arrays passed to `snd_hda_add_verbs()` (`struct hda_verb`) or `spec->gen.preferred_dacs` (`hda_nid_t` pairs) must be `static` (`static const` for `preferred_dacs`) and zero-terminated; `alc_update_vref_led()` must hold `CLASS(snd_hda_power_pm, pm)(codec)` while calling `snd_hda_set_pin_ctl_cache()`. [F230, F231, F266]

## API Contracts
- In `alc_update_coefex_idx()`, `alc_update_coef_idx()`, and `UPDATE_COEF` / `UPDATE_COEFEX`, `mask` clears bits and `bits_set` is ORed unmasked (`(val & ~mask) | bits_set`), whereas `alc_fix_pll_init()` takes a 0-based bit index `coef_bit`; `struct coef_fw` tables for `alc_process_coef_fw()` must end with a `{}` (`nid == 0`) sentinel and use `mask == (unsigned short)-1` for direct writes; `alc5505_coef_set()` / `alc5505_coef_get()` take an even byte-addressed `index_reg` (shifted via `index_reg >> 1` on NID `0x51`) for two 16-bit `AC_VERB_SET_PROC_COEF` / `AC_VERB_GET_PROC_COEF` verbs (LSB then MSB). [F177, F183, F198, F271]
- Runtime GPIO output updates must use `alc_update_gpio_data()` (with bits enabled in `spec->gpio_mask` and `spec->gpio_dir`) rather than direct `AC_VERB_SET_GPIO_DATA` writes; in `alc_write_gpio()`, `AC_VERB_SET_GPIO_MASK` and `AC_VERB_SET_GPIO_DIRECTION` must precede `alc_write_gpio_data()`, with `msleep(1)` in between when `spec->gpio_write_delay` is true. [F186, F255]
- `alc_subsystem_id()` returns `1` on valid SKU and `0` on invalid, whereas `alc_auto_parse_customize_define()` returns `0` on success and `-1` on failure; any non-NULL `ssid_nids` (`ports`) array passed to `alc_parse_auto_config()`, `alc_ssid_check()`, or `alc_subsystem_id()` must have at least 4 `hda_nid_t` elements `{ port-A, port-E, port-D, port-I }`. [F168, F181]
- Fixup stage contracts: `snd_hda_gen_add_mute_led_cdev()` / `snd_hda_gen_add_micmute_led_cdev()` (`alc_fixup_hp_gpio_led()`, `alc_fixup_micmute_led()`) must run at `HDA_FIXUP_ACT_PRE_PROBE`; custom `automute_hook` / `hp_automute_hook` combined with `alc_fixup_headset_mode()` (`alc_fixup_headset_mode_dell_alc288()`) must be set at `HDA_FIXUP_ACT_PROBE` after `alc_fixup_headset_mode()` and never pre-populate `spec->gen.cap_sync_hook`; `rename_ctl()` and `spec->gen.pcm_rec` edits must run at `HDA_FIXUP_ACT_BUILD`; dual-codec fixups (`alc_fixup_dual_codecs()`, `alc1220_fixup_gb_dual_codecs()`, `alc233_alc662_fixup_lenovo_dual_codecs()`) must set `suppress_vmaster`, `suppress_auto_mute`, `suppress_auto_mic`, `mixer_nid = 0`, and `codec->force_pin_prefix = 1` at `HDA_FIXUP_ACT_PRE_PROBE` and rename Capture controls by `codec->addr` at `HDA_FIXUP_ACT_BUILD`. [F191, F275, F276, F277]
- `comp_generic_fixup()` `match_str` is formatted by `hda_comp_match_dev_name()` with `(const char *hid, int index)` into `char tmp[32]`, so `find_cirrus_companion_amps()` must escape `%%s` and `%%d` in `devm_kasprintf()` and expansions must be `<= 31` chars; in `comp_bind()`, `void *data` for `hda_component_manager_bind_acpi_notifications()` must be `struct hda_codec *cdc`. [F232, F233]
- `set_eapd()` must verify `get_wcaps_type(get_wcaps(codec, nid)) == AC_WID_PIN` and `snd_hda_query_pin_caps(codec, nid) & AC_PINCAP_EAPD` before `AC_VERB_SET_EAPD_BTLENABLE`; `snd_hda_override_conn_list()` and `alc889_fixup_mac_pins()` take element counts (`ARRAY_SIZE(...)`), not `sizeof(...)`; COEF helpers, `alc_write_gpio()`, `alc_update_knob_master()`, and `alc_update_headset_jack_cb()` require sleepable context. [F235, F245, F264]

## Error Handling
- `alc_parse_auto_config()` returns `1` on success and negative errno on failure, so `.probe` functions must check `err < 0` (never `if (err)`) and `return 0` on success; in `alc269_probe()`, `set_beep_amp()` additionally requires `spec->gen.mixer_nid != 0`. [F167, F171]
- Guard `codec->bus->pci != NULL` before dereferencing it (can be `NULL` on non-PCI buses); check `snd_hda_find_mixer_ctl() != NULL` before dereferencing or calling `snd_ctl_rename()` (`rename_ctl()`, `alc_update_knob_master()`); check `alc_get_hp_pin()` and `alc_find_ext_mic_pin()` for `0` before using the NID, and only use `alc271_hp_gate_mic_jack()` when both pins exist (`snd_BUG_ON` otherwise). [F169, F170, F172, F278]

## Known Pitfalls
- `alc_fixup_gpio1()` (`0x01`), `alc_fixup_gpio2()` (`0x02`), `alc_fixup_gpio3()` (`0x03`, GPIO0+GPIO1), and `alc_fixup_gpio4()` (`0x04`, GPIO2) suffixes are hex bitmasks, not 1-based GPIO numbers; `alc_update_gpio_led()` inverts `enabled` (`!enabled`) because `micmute_led_set()` and `gpio_mute_led_set()` pass `!brightness`, whereas `alc_update_vref_led()` and `alc_update_coef_led()` take `brightness` directly without inversion when `polarity == 0`. [F180, F252]
- In `struct hda_fixup`, `.chain_id` is ignored unless `.chained = true` or `.chained_before = true` is set; companion-amp quirks (`tas2781_fixup_tias_i2c`, `cs35l41_fixup_i2c_two`) on boards needing dual-speaker DAC routing or headset-mic pin configs must chain those fixups (`ALC289_FIXUP_DUAL_SPK`, `ALC294_FIXUP_ASUS_I2C_HEADSET_MIC`); shared PCI SSIDs in `alc269_fixup_tbl` used across different codec chips must gate chip-specific actions on `codec->core.vendor_id` (`alc285_fixup_asus_ga403u()`, `alc256_fixup_mic_no_presence_and_resume()`). [F211, F247, F250]
- Do not break or reorder the intentional `fallthrough` chains in `alc_fill_eapd_coef()` (`0x10ec0225`/`0295`/`0299` -> `0215`..`0289` -> `0230`..`0300`, and `0234`/`0274` -> `0294`..`0711`); use `1ULL << nid` (`BIT_ULL(nid)`) when modifying `u64` `spec->gen.mute_bits` (`asus_tx300_automute()`). [F213, F224]
