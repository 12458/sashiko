# PERFORMANCE EVENTS SUBSYSTEM — tools/perf/util (part 7)

Provides core `perf` utilities (`tools/perf/util/`): machine state (`machine.c`), memory maps (`maps.c`, `map.c`), event/metric parsing (`parse-events.c`, `metricgroup.c`, `parse-branch-options.c`), ring-buffer mmaps (`mmap.c`), ordered events (`ordered-events.c`), LLVM disassembly (`llvm.c`), lock contention (`lock-contention.c`), memory/NUMA (`mem-events.c`, `mem2node.c`), namespaces (`namespaces.c`), LZMA (`lzma.c`), and mutexes (`mutex.c`).

## Architecture & Data Flow
- Only `map__new2()` and `map__clone()` allocate a trailing `struct kmap` at `&RC_CHK_ACCESS(map)[1]` when `dso__kernel(dso)` is true (`map__new()` allocates `sizeof(*map)`), so `__map__kmap()`/`map__kmap()` must check `dso && dso__kernel(dso)`. Every `maps.c` path inserting into `maps_by_address` (`__maps__insert()`, `__maps__insert_sorted()`, `__maps__fixup_overlap_and_insert()`, `maps__copy_from()`) must call `map__set_kmap_maps()`. [F369, F378]
- In `__maps__fixup_overlap_and_insert()`, splitting `pos` into a trailing `after` map at `map__end(new)` requires advancing `after`'s pgoff by `map__end(new) - map__start(pos)` via `map__add_pgoff()`. During index-based iteration over `maps_by_address` in `maps__remove_maps()` or `__maps__fixup_overlap_and_insert()`, do not increment `i` after `__maps__remove()` because `memmove()` shifts entries down. [F380, F414]
- When `__maps__insert()` sees `map__end(new) < map__start(new)` (`ends_broken = true`), call `maps__fixup_end()` after adding all kernel/module/extra maps in `machine__create_kernel_maps()` or `machine__load_kallsyms()`. `maps__find_next_entry()` must ensure `maps__maps_by_address_sorted(maps)` before `maps__by_address_index(maps, map)`, and pre-increment the index (`++i < maps__nr_maps(maps)`). [F383, F397]
- In `maps__set_module_path()`, when `m->comp && is_kmod_dso(dso)`, increment `dso__symtab_type(dso)` by 1 alongside `dso__set_comp()` to switch to `*_KMODULE_COMP`. `machine__get_kernel_start()` must initialize `machine->kernel_start` to `1ULL << 63` and keep it on `x86_64` so `machine__kernel_ip()` classifies PTI trampolines above `2^63` as kernel space. `thread__resolve_callchain_sample()` must reject `branch->nr > PERF_MAX_BRANCH_DEPTH` (127) before `remove_loops()`, which uses `0xff` (`NO_ENTRY`) in `unsigned char chash[]`. [F385, F403, F425]
- `ordered_events__queue()` rejects timestamps `0` and `~0ULL` (`-ETIME`), and `__ordered_events__flush()` computes `OE_FLUSH__HALF` as `first->timestamp + (last->timestamp - first->timestamp) / 2` (`ULLONG_MAX` for `FINAL`/`TOP`). In `do_flush()`, save `oe->last->timestamp` into `last_ts` before `ordered_events__delete()`, then set `oe->last` to `NULL` if `oe->events` is empty or `list_entry(head->prev, ...)` if `last_ts <= limit`. [F387, F432]
- `struct parse_events_term::val` is discriminated by `term->type_val` (`NUM` vs `STR`); check it before reading/freeing `term->val.str`. New `enum parse_events__term_type` values must update `config_term_names[]`, `config_term_avail()`, `config_term_common()`, `config_term_tracepoint()`, `get_config_terms()`, and `get_config_chgs()`. `parse_events_add_pmu()` must deep-copy `const_parsed_terms` via `parse_events_terms__copy()` before `fix_raw()`, `config_attr()`, and `perf_pmu__check_alias()` mutate terms. In `parse_events__modifier_list()`, evaluate `!exclude_GH && exclude_GH_default` only after `user`/`kernel`/`hypervisor`/`guest`/`host` modifiers. [F368, F391, F393, F410]
- In `resolve_metric()`, collect sub-metrics into `pending` during `hashmap__for_each_entry(root_metric->pctx->ids, ...)` and call `expr__del_id()` / `add_metric()` only after the loop. In `metricgroup__build_event_string()`, skip tool PMU events (`tool_pmu__str_to_event(id) != TOOL_PMU__EVENT_NONE`) during the `ctx->ids` group pass and emit them after `}:W`. `setup_metric_events()` must skip hybrid `evsel`s whose `ev->pmu->name` mismatches `pmu` when `!all_pmus`, put only the first `evsel` per `metric_id` in `metric_events`, and set `ev->metric_leader = metric_events[i]` on duplicates; terminate `metric_events` and `metric_refs` (`__add_metric()`) with `NULL`. [F394, F405, F417, F456]
- Store global memory recording selection in `perf_mem_record[PERF_MEM_EVENTS__MAX]` (not per-PMU `perf_mem_event`), as `perf_pmu__mem_events_parse()` runs only on the first memory PMU. Keep `PERF_MEM_LVLNUM_*` and `enum mem_stat_*` in sync with `mem_lvlnum[]`, `mem_stat_index()`, and `mem_stat_name()`, and in `c2c_decode_stats()` set `mrem = data_src->mem_remote && !data_src->mem_hops`. In `mem2node__init()`, call `phys_entry__insert(&entries[i], &map->root)` only after `realloc(entries, ...)` shrinks the array. [F389, F390, F422, F436]

## Synchronization
- In `__machine__findnew_thread()`, call `thread__init_maps(th, machine)` only after `threads__findnew()` inserts `th` and drops `table->lock`; on failure, call `threads__remove(&machine->threads, th)` before `thread__put()`. `struct mutex` (`mutex_init()`) uses `PTHREAD_MUTEX_ERRORCHECK` (`!NDEBUG`) and is non-recursive. In `perf_mmap__aio_mmap()`, initialize `map->aio.cblocks[i].aio_fildes = -1` before publishing `map` for `record__aio_sync()`. [F349, F357, F358]
- If a `struct maps` reader (`maps__for_each_map`, `maps__find`, `maps__find_by_name`, `maps__find_next_entry`, `maps__merge_in`) sees `maps_by_address_sorted` or `maps_by_name_sorted` false under `down_read`, drop the lock, sort under `down_write`, and re-check the flag. In `maps__merge_in()`, after acquiring `down_write(maps__lock(kmaps))`, re-verify `maps__maps_by_address_sorted(kmaps)` and recompute `first_after_`, `kmaps_maps_by_address`, and `kmaps__nr_maps`. In `maps__find_by_name()`, load `last_search_by_name_idx` once into local `unsigned int i` under `down_read` and bounds-check `i < maps__nr_maps(maps) && maps__maps_by_name(maps)`. `maps__copy_from(dest, parent)` locks `dest` (write) then `parent` (read) and requires `!maps__equal(dest, parent)`. [F350, F351, F353, F355]

## Object Lifetimes
- `map_symbol__copy()` and `addr_map_symbol__copy()` get `src->maps`/`src->map` without releasing `dst`; call `map_symbol__exit()` / `addr_map_symbol__exit()` on reused `dst` first. When `memcpy`ing `callchain_cursor_node` in `has_stitched_lbr()` and `save_lbr_cursor_node()`, call `maps__get()`/`map__get()` on `ms` and `map_symbol__exit()` before overwriting `prev_lbr_cursor[idx]` or splicing `lbr_stitch->lists` to `free_lists`. [F330, F331]
- In `struct maps`, non-NULL `maps_by_name` holds a separate `struct map` ref per entry alongside `maps_by_address`; balance `map__get()`/`map__put()` on both. `map__new()`, `map__new2()`, and `map__clone()` call `dso__get(dso)` (dropped in `map__exit()`), whereas `map__set_kmap_maps()` stores an un-refcounted `kmap->kmaps` pointer. In `machine__update_kernel_mmap()`, pin `orig = machine->vmlinux_map` with `map__get()` across `maps__remove()` and `maps__insert()`. In `machine__destroy_kernel_maps()`, call `maps__remove()` before freeing `kmap->ref_reloc_sym` and `map__zput(machine->vmlinux_map)`. [F332, F335, F338, F360]
- When `oe->copy_on_queue` is true, `alloc_event()` `memdup`s `event` and charges `oe->cur_alloc_size`; `ordered_events__delete()`, alloc failure, and `ordered_events__free()` must call `free_dup_event()`. In `ordered_events__free()`, if `oe->buffer` is non-NULL, unlink it from `oe->to_free` and free with `max = oe->buffer_idx` before freeing full `oe->to_free` buffers with `MAX_SAMPLE_BUFFER`. In `metricgroup__lookup()`, `metric_event_new()` must heap-allocate a copy of stack `entry` and call `INIT_LIST_HEAD(&me->head)` after `memcpy()`. [F341, F388, F440]

## API Contracts
- `maps__find()`, `maps__find_by_name()`, and `maps__find_next_entry()` return a `map__get()` ref. `maps__find_symbol()` and `maps__find_symbol_by_name()` store a `struct map *` ref in `*mapp` when non-NULL; `maps__find_symbol()` sets `*mapp = map` even when symbol lookup fails and returns `NULL`, whereas `maps__find_symbol_by_name()` sets `*mapp` only on match. Callers must `map__put()`. [F333, F334]
- `dso__set_nsinfo()` takes ownership of `nsi` (dropping old `dso->nsinfo` without `nsinfo__get()`). In `map__new()`, call `dso__set_nsinfo(dso, nsi)` under `mutex_lock(dso__lock(dso))`, call `nsinfo__put(nsi)` only on `out_delete`, and for `is_vdso_map(filename)` clear `need_setns` on a copy (`nsinfo__copy()` + `nsinfo__clear_need_setns()`). [F336, F464]
- `machine__findnew_thread()`, `machine__find_thread()`, `machine__idle_thread()`, `machine__findnew_guest_code()`, and `machines__findnew_guest_code()` return a refcounted `struct thread *` requiring `thread__put()`. `__machine__new_host()` / `machine__new_host()` must set `machine->env = host_env` after `machine__init()`. `machine__set_current_tid()` must pass `&init_val` (`const pid_t init_val = -1`) to `realloc_array_as_needed()`. [F339, F362, F447]
- In `add_callchain_ip()`, when `cpumode` is non-NULL and `ip < PERF_CONTEXT_MAX`, call `thread__find_map()` when `!symbols`. `map__load(map)` must return `>= 0` before `map__map_ip()` in `maps__find_symbol()`, before `map__for_each_symbol()`, and before `dso__data_write_cache_addr()` in `machine__process_text_poke()`. `map__new()` takes length `len` (`start + len`), whereas `map__init()` and `map__set_end()` take exclusive `end`. Size `buf` in `__map__fprintf_dsoname()` to at least `symbol_conf.pad_output_len_dso + 1` for `scnprintf_pad()`. [F363, F370, F371, F441, F477]
- `parse_events_error__handle()` owns heap `str` and `help` (freeing on error). `parse_events__set_default_name(list, name)` consumes heap `name`. `foreach_evsel_in_last_glob()` must call `func(last, arg)` even when `last == NULL`. `config_term_common()` must reject `AUX_SAMPLE_SIZE` with `term->val.num > UINT_MAX`. `parse_filter()` / `exclude_perf()` cast `opt->value` to `struct evlist **`, while `parse_branch_stack()` casts to `__u64 *`. `encode_metric_id()` escapes `code_characters` (`",-=@"`) as `'!'` + digit; `decode_metric_id()` must bounds-check the digit. [F344, F346, F408, F419, F429, F446]
- `perf_mmap__push()` masks `start`/`end` with `md->core.mask` on `data = md->core.base + page_size`, splitting reads at `md->core.mask + 1 - (start & mask)` on wrap. `MMAP_CPU_MASK_BYTES(m)` must be `BITS_TO_LONGS(nbits) * sizeof(unsigned long)`, and `mmap_cpu_mask__scnprintf()` must use a `MASK_SIZE + 1` buffer and set `buf[len] = '\0'` after `bitmap_scnprintf()`. `mem_bswap_32()`/`mem_bswap_64()` take signed `int byte_size` on 4/8-byte padded buffers. `perf_mem_events__record_args()` points `rec_argv` into `*event_name_storage_out` (advancing by `strlen + 1`, no `realloc`/free while live). `DECLARE_RC_STRUCT(nsinfo)` accessors must match field types (`bool` vs `pid_t`). [F400, F442, F443, F444, F445, F448]

## Error Handling
- `lzma_is_compressed()` returns `bool` and must return `false` (not `-1`) on I/O failure. `add_callchain_ip()` and `resolve_lbr_callchain_sample()` return `1` on non-fatal markers/LBR success; callers must clamp via `(err < 0) ? err : 0`. `parse_events__sort_events_and_fix_groups()` returns `1` when regrouped, `0` unchanged, `< 0` on error (`__parse_events()` fails only on `< 0`). `__parse_events()` and `metricgroup__add_metric()` must splice temporary lists into caller lists even on error. `tracepoint_error()` must normalize `err = abs(err)`. [F361, F364, F365, F366, F376]
- `nsinfo__mountns_enter()` must init `nc->oldns = -1` and `nc->newns = -1` before early return and set `oldcwd`/`oldns`/`newns` only after `setns()` succeeds. `nsinfo__new()` returns `NULL` for `pid == 0`, but if `nsinfo__init(nsi)` fails it must call `nsinfo__clear_need_setns(nsi)` and return `nsi`. `perf_mmap__push()` returns `1` on `-EAGAIN` from `perf_mmap__read_init()`, `0` on push, `-1` on error. `llvm__addr2line()` succeeds on `ret > 0`, whereas `symbol__disassemble_llvm()` succeeds on `err == 0`. [F372, F373, F375, F377]

## External Contracts
- `machine__process_text_poke()` writes `new_len` bytes from `event->text_poke.bytes + event->text_poke.old_len`. `machine__set_kernel_mmap()` sets `vmlinux_map` end to `~0ULL` when `start == 0 && end == 0`. `machine__resolve_kernel_addr()` must keep signature `char *(void *, unsigned long long *, char **)` for `tep_set_function_resolver()`. `namespaces__new()` must size `link_info` by `event->nr_namespaces` when `event != NULL`. [F406, F407, F409, F449]
- In `config_term_pmu()`, rewrite `TERM_TYPE_HARDWARE` to `TERM_TYPE_USER` (`no_value = true`, `alternate_hw_config = true`) if `perf_pmu__have_event(pmu, term->config)`, and decode `TERM_TYPE_LEGACY_CACHE` to `PERF_TYPE_HW_CACHE` only if `perf_pmu__supports_legacy_cache(pmu) && !perf_pmu__have_event(pmu, term->config)` (else rewrite to `TERM_TYPE_USER`, `no_value = true`). `parse_events_add_cache()` must check `perf_pmu__have_event(pmu, name)` first and skip `!pmu->is_core` before legacy cache decoding. [F450, F451, F452]
- `parse_events__sort_events_and_fix_groups()` and `evsel__compute_group_pmu_name()` split group members with differing `group_pmu_name` (software events and AUX-led groups adopt the group's PMU), reset `core.idx = idx++` and `core.nr_members = 0`, call `evsel__set_leader()`, and recompute `pos_leader->core.nr_members++`. `parse_events__modifier_list()` rejects `precise_ip > 3` (`-EINVAL`) and sets `pinned`/`exclusive` only on `evsel__is_group_leader(evsel)`. `metric__group_events()` returns `false` for `MetricNoGroupEventsNmi` (and `ThresholdAndNmi` when `!metric_no_threshold`) if `sysctl__nmi_watchdog_enabled()`, and for `MetricNoGroupEventsSmt` if `smt_on()`. `__perf_pmu__mem_events_init()` skips `e->tag == NULL` and checks `perf_pmu__mem_events_supported()`. [F392, F458, F459, F473, F474]

## Known Pitfalls
- `maps__for_each_map()` must reload `maps__nr_maps(maps)` and `maps__maps_by_address(maps)` each iteration because callbacks may insert maps when `perf_singlethreaded` makes `rw_semaphore` a no-op, `realloc`ing `maps_by_address`. For `DECLARE_RC_STRUCT` types (`map`, `maps`, `nsinfo`, `mem_info`), size allocations with `sizeof(RC_STRUCT(<type>))` and unwrap via `RC_CHK_ACCESS()`. [F354, F434]
- `map__start_cmp()` and `map__addr_cmp()` must use relational operators (`-1`, `0`, `1`) on `u64` and `intptr_t`, never `int` subtraction. `machine__get_running_kernel_start()` must look up `_edata`/`_etext` with `kallsyms__get_symbol_start()`. `match_callstack_filter()` breaks on `callstack[i] == 0` except at indices `1` and `2` on `"powerpc"`. `parse_events_add_pmu()` must call `fix_raw()` before `config_attr()`, and `fix_raw()` must check `perf_pmu__have_event()` before hex-parsing `TERM_TYPE_RAW`. Cast 32-bit PMU types to `u64`/`__u64` before shifting by `PERF_PMU_TYPE_SHIFT` (32) in `parse_events__decode_legacy_cache()`, `config_term_pmu()`, and `__parse_events_add_numeric()`. [F404, F412, F424, F427, F453]
