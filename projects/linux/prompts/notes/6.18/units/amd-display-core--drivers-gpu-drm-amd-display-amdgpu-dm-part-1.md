# AMD DISPLAY CORE — drivers/gpu/drm/amd/display/amdgpu_dm (part 1)

Core Display Manager (DM) glue layer bridging the Linux DRM/KMS atomic modesetting framework, AMDGPU base driver IP block lifecycle, and the OS-agnostic Display Core (DC) engine. It manages display hardware initialization/teardown, suspend/resume, DRM connectors/encoders/CRTCs/planes state translation and atomic commits, DMUB firmware loading and notifications, backlight control, and HDA audio component binding.

## Architecture & Data Flow

- In amdgpu_dm_commit_streams(), hardware backlight brightness must only be restored from dm->brightness[] when dm->restore_backlight is true, and dm->restore_backlight must be cleared immediately afterward so subsequent modesets do not overwrite user-adjusted HDR/gamma brightness. [F48]
- When registering an eDP backlight device in amdgpu_dm_register_backlight_device(), dm->brightness[aconnector->bl_idx] must be initialized to props.brightness, and amdgpu_dm_backlight_set_level() must only update dm->actual_brightness[bl_idx] when the DC link backlight update succeeds. [F49]
- In update_connector_ext_caps(), whenever caps->aux_support is set to true on an eDP connector, aconnector->dc_link->backlight_control_type must also be set to BACKLIGHT_CONTROL_AMD_AUX. [F50]
- is_dc_timing_adjust_needed() must return true when new_state->stream->adjust.timing_adjust_pending is set, in addition to VRR_STATE_ACTIVE_FIXED or VRR active state transitions, so deferred DRR timing adjustments are applied in amdgpu_dm_commit_planes(). [F51]
- In amdgpu_dm_enable_self_refresh(), both PSR SU and Panel Replay must decrement aconn->sr_skip_count on UPDATE_TYPE_FAST commits, update acrtc_attach->dm_irq_params.allow_sr_entry to !aconn->sr_skip_count, and gate entry on allow_sr_entry, !vrr_active, and the 500ms psr_dirty_rects_change_timestamp_ns delay. [F52]
- Before calling drm_atomic_helper_resume() in dm_destroy_cached_state(), dm->cached_state must have every CRTC's active_changed and color_mgmt_changed set to true, freesync config reset, and duplicated dc_stream_state and dc_plane_state pointers released and nulled. [F53]
- During GPU reset in dm_resume(), link_enc_cfg_copy(adev->dm.dc->current_state, dc_state) must be called on dm->cached_dc_state before dc_commit_streams(), and each stream's mode_changed and plane update_flags.raw must be forced to full update. [F54]
- On non-reset S3/S4 resume in dm_resume(), the private atomic state's dc_state context (dm_state->context) must be released and recreated with dc_state_create() before link detection and dm_destroy_cached_state(). [F55]
- Whenever any non-cursor plane on a CRTC is in drm_atomic_state, amdgpu_dm_atomic_check() must add all other non-cursor planes in crtc->state->plane_mask before calling drm_atomic_normalize_zpos(), and if dm_crtc_get_cursor_mode() selects DM_CURSOR_OVERLAY_MODE, drm_atomic_add_affected_planes() must also be called. [F57]

## Synchronization

- In amdgpu_dm_init(), dc_enable_dmub_outbox() must be called only after dmub_aux_transfer_done and fused_io[].replied completions are initialized, dmub_notify and delayed_hpd_wq are allocated, and DMUB notification callbacks are registered. [F16]
- In amdgpu_dm_fini(), when adev->dm.idle_workqueue->running is true, adev->dm.idle_workqueue->enable must be set to false and adev->dm.idle_workqueue->work flushed via flush_work() before freeing adev->dm.idle_workqueue. [F20]
- In dm_suspend(), amdgpu_dm_irq_suspend() must be called before hpd_rx_irq_work_suspend() flushes every dm->hpd_rx_offload_wq[i].wq workqueue, both during GPU reset and during S3/S0ix suspend. [F21]
- In amdgpu_dm_commit_planes() and amdgpu_dm_commit_streams(), dm->vblank_control_workqueue must be flushed via flush_workqueue() outside dm->dc_lock before disabling PSR/Replay or programming DC stream and plane updates. [F23]
- In do_aquire_global_lock(), crtc->commit_lock must be held while reading the head of crtc->commit_list and taking a reference with drm_crtc_commit_get(), and dropped before waiting on commit->hw_done and commit->flip_done. [F25]
- aconnector->audio_inst is protected by adev->dm.audio_lock; amdgpu_dm_commit_audio() must release adev->dm.audio_lock before calling amdgpu_dm_audio_eld_notify(), and amdgpu_dm_audio_component_get_eld() acquires connector->eld_mutex nested inside adev->dm.audio_lock. [F26]
- Synchronous DMUB DPIA AUX and SET_CONFIG transactions in amdgpu_dm_process_dmub_aux_transfer_sync() and amdgpu_dm_process_dmub_set_config_sync() must hold adev->dm.dpia_aux_lock across command submission, completion wait, reading adev->dm.dmub_notify, and calling reinit_completion(&adev->dm.dmub_aux_transfer_done). [F27]
- offload_wq->is_handling_mst_msg_rdy_event and offload_wq->is_handling_link_loss are protected by offload_wq->offload_lock; dm_handle_hpd_rx_offload_work() must clear is_handling_link_loss under offload_lock and re-read DPCD HPD RX IRQ data to revalidate link loss before calling dc_link_dp_handle_link_loss(). [F29]
- In dm_pflip_high_irq(), when VRR is active and scanout is inside front-porch (vpos >= v_blank_start), the handler must not call drm_crtc_accurate_vblank_count(), drm_crtc_arm_vblank_event(), or drm_crtc_vblank_put(), and must instead append the event to vblank_event_list under event_lock for dm_vupdate_high_irq() to send. [F30]

## Object Lifetimes

- `create_stream_for_sink()` must retain `aconnector->dc_sink` (or allocate a fake sink via `create_fake_sink()`) before calling `dc_create_stream_for_sink(sink)` and unconditionally call `dc_sink_release(sink)` before returning, because `dc_create_stream_for_sink()` takes its own reference to `sink`. [F1]
- In `amdgpu_dm_update_connector_after_detect()`, because local variable `sink` is declared with `__free(sink_release)`, storing `sink` or `aconnector->dc_em_sink` into `aconnector->dc_sink` requires an explicit `dc_sink_retain(aconnector->dc_sink)` after releasing any prior `aconnector->dc_sink` with `dc_sink_release()`. [F2]
- In `dm_update_crtc_state()`, `new_stream` returned by `create_validate_stream_for_sink()` owns a caller reference that is always dropped at `skip_modeset:` or `fail:`, so attaching `new_stream` to `dm_new_crtc_state->stream` requires an explicit `dc_stream_retain(new_stream)`. [F4]
- In `dm_update_plane_state()`, a newly created `dc_new_plane_state` from `dc_create_plane_state()` must be released with `dc_plane_state_release()` on any error prior to `dm_new_plane_state->dc_state = dc_new_plane_state`, after which ownership belongs to the atomic state. [F5]
- In the disable (`!enable`) pass of `dm_update_plane_state()` and `dm_update_crtc_state()`, after removing the plane or stream from `dm_state->context`, the duplicated reference must be dropped via `dc_plane_state_release()` / `dc_stream_release()` and `dm_new_plane_state->dc_state` / `dm_new_crtc_state->stream` set to `NULL`. [F6]
- Across modesets and CRTC active changes, `amdgpu_dm_commit_streams()` must call `manage_dm_interrupts(adev, acrtc, NULL)` and `dc_stream_release(dm_old_crtc_state->stream)` before committing streams, and `amdgpu_dm_atomic_commit_tail()` must retain `dm_new_crtc_state->stream` for `acrtc->dm_irq_params.stream` and enable interrupts afterward. [F8]
- `amdgpu_dm_handle_vrr_transition()` must pair `amdgpu_dm_crtc_set_vupdate_irq(crtc, true)` and `drm_crtc_vblank_get(crtc)` when transitioning VRR from inactive to active with `amdgpu_dm_crtc_set_vupdate_irq(crtc, false)` and `drm_crtc_vblank_put(crtc)` when transitioning VRR from active to inactive. [F9]
- During GPU reset (`amdgpu_in_reset(adev)`), `dm_gpureset_toggle_interrupts()` must toggle vblank interrupts directly with `dc_interrupt_set()` rather than `amdgpu_irq_get()` or `amdgpu_irq_put()` so that IRQ reference counts are not altered. [F10]
- In `amdgpu_dm_atomic_check()`, when `lock_and_validation_needed` is false (a fast update), any `dm_atomic_state` entry in `state->private_objs` must be destroyed with `dm_atomic_destroy_state()`, replaced with the last entry `state->private_objs[j]`, have slot `j` cleared to `NULL`, and `state->num_private_objs` decremented. [F11]
- `amdgpu_dm_atomic_commit_tail()` must not call `amdgpu_bo_free_kernel()` on `adev->mman.stolen_vga_memory` or `adev->mman.stolen_extended_memory` when `adev->in_suspend` is true. [F12]

## API Contracts

- In `dm_vupdate_high_irq()` and `dm_crtc_high_irq()`, `acrtc->dm_irq_params.stream` must be checked for non-NULL before dereferencing `stream->link` (to read `replay_settings` or `psr_settings`) or passing the stream to `mod_freesync_handle_v_update()`. [F33]
- In `amdgpu_dm_backlight_get_level()`, the return value of `dc_link_get_backlight_level()` must be stored in a signed `int` and checked against `DC_ERROR_UNEXPECTED` (falling back to `dm->brightness[bl_idx]`) before passing it to `convert_brightness_to_user()`. [F37]
- In `get_brightness_range()`, backlight range bounds must be scaled according to `caps->aux_support`: multiplying nits (`aux_min_input_signal`, `aux_max_input_signal`) by `1000` into millinits for AUX backlight, or multiplying 8-bit `min_input_signal` and `max_input_signal` by `0x101` into 16-bit PWM units. [F38]
- In `scale_input_to_fw()` and `scale_fw_to_input()`, custom brightness curve rescaling must use `AMDGPU_MAX_BL_LEVEL` (0xFF) to match the 8-bit `caps->luminance_data[].input_signal` table, whereas `amdgpu_dm_register_backlight_device()`'s fallback `props.max_brightness` must use `MAX_BACKLIGHT_LEVEL` (0xFFFF). [F39]
- In `amdgpu_dm_process_dmub_aux_transfer_sync()`, when extracting `payload->reply[0]` from `adev->dm.dmub_notify->aux_reply.command`, if the upper nibble is non-zero (`command & 0xF0`), the command byte must be right-shifted by 4 before masking with `0xF`. [F40]
- In `decide_crtc_timing_for_drm_display_mode()`, `copy_crtc_timing_for_drm_display_mode(native_mode, drm_mode)` must only be called if `native_mode->crtc_clock` is non-zero. [F41]
- When reading an EDID directly from a connector's DDC in `amdgpu_dm_connector_funcs_force()` and `create_eml_sink()`, callers must select `&aconnector->dm_dp_aux.aux.ddc` when `dc_link && dc_link->aux_mode` is true and `&aconnector->i2c->base` otherwise, passing that adapter to `drm_edid_read_ddc()`. [F42]
- In `fill_hdr_info_packet()`, the output `struct dc_info_packet *out` must be zero-initialized with `memset(out, 0, sizeof(*out))` before returning `0` when `!state->hdr_output_metadata`, so exiting HDR passes an invalidated (`out->valid == false`) packet to DC. [F44]
- In `dm_encoder_helper_atomic_check()` and `add_affected_mst_dsc_crtcs()`, `aconnector->mst_output_port` (and `aconnector->mst_root`) must be checked for non-NULL before dereferencing `&aconnector->mst_root->mst_mgr`, because SST and root MST connectors have a NULL `mst_root`. [F46]

## Error Handling

- In `dm_cache_state()`, `adev->dm.cached_state` returned by `drm_atomic_helper_suspend()` must be checked with `IS_ERR()` and reset to `NULL` after extracting `PTR_ERR()`, because `dm_suspend()` and `dm_destroy_cached_state()` treat any non-NULL `cached_state` as a valid `drm_atomic_state` pointer. [F36]
- In `load_dmcu_fw()`, `amdgpu_ucode_request()` returning `-ENODEV` must be treated as non-fatal by setting `adev->dm.fw_dmcu = NULL` and returning `0`, whereas any other non-zero error must call `amdgpu_ucode_release(&adev->dm.fw_dmcu)` and propagate `r`. [F43]
- In `dm_get_plane_scale()`, `plane_src_w` and `plane_src_h` obtained from `dm_get_oriented_plane_size()` must be checked for non-zero before dividing `plane_state->crtc_w * 1000` and `plane_state->crtc_h * 1000` by them (returning `0` when zero), because `dm_crtc_get_cursor_mode()` calls `dm_get_plane_scale()` before plane state validation. [F104]
- In `update_freesync_state_on_stream()` and `update_stream_irq_parameters()`, `new_stream->timing.h_total` and `new_stream->timing.v_total` must both be checked for non-zero before calling FreeSync helpers (`mod_freesync_handle_preflip()`, `mod_freesync_handle_v_update()`, `mod_freesync_build_vrr_infopacket()`). [F105]
- In `dm_vupdate_high_irq()`, the signed `ktime_t` difference `frame_duration_ns = vblank->time - previous_timestamp` must be checked with `frame_duration_ns > 0` before dividing `NSEC_PER_SEC` by `frame_duration_ns` via `ktime_divns()`. [F108]
- In `fill_stream_properties_from_drm_display_mode()`, negative returns from `drm_hdmi_avi_infoframe_from_display_mode()` and `drm_hdmi_vendor_infoframe_from_display_mode()` must be logged with `drm_warn_once()` rather than unconditional error logging. [F155]

## External Contracts

- `amdgpu_dm_process_dmub_aux_transfer_sync()` must accept successful DMUB AUX replies (`p_notify->result == AUX_RET_SUCCESS`) and copy `p_notify->aux_reply.length` bytes into `payload->data` even when `p_notify->aux_reply.length != payload->length`. [F87]
- In `amdgpu_dm_audio_component_get_eld()`, connector iteration must skip `DRM_MODE_CONNECTOR_WRITEBACK` connectors before calling `to_amdgpu_dm_connector()`, and must hold `adev->dm.audio_lock` around the search and `connector->eld_mutex` while sizing `connector->eld` with `drm_eld_size()` and copying `min(max_bytes, ret)` bytes. [F160]
- In `amdgpu_dm_register_backlight_device()`, native backlight registration via `backlight_device_register()` must be skipped in favor of `acpi_video_register_backlight()` when `!acpi_video_backlight_use_native()`, and an `IS_ERR()` return from `backlight_device_register()` must be reset to `NULL` in `dm->backlight_dev[aconnector->bl_idx]`. [F166]

## Known Pitfalls

- When iterating over `dc_state->streams[k]` (for `0 <= k < dc_state->stream_count`) in `dm_gpureset_commit_state()`, `dm_gpureset_toggle_interrupts()`, or `dm_resume()`, the parallel `dc_state->stream_status` array must be indexed with the same stream loop counter `k` rather than dereferenced as a single pointer. [F86]
- In `amdgpu_dm_commit_zero_streams()`, streams from `context->streams` must be copied into a separate `del_streams` array before calling `dc_state_remove_stream(dc, context, ...)` in a second loop, because `dc_state_remove_stream()` mutates `context->streams` and `context->stream_count` in place. [F89]
- `dm_free_gpu_mem()` and `dm_sw_fini()` iterate `adev->dm.da_list` with `list_for_each_entry` and must `break` immediately after calling `list_del(&da->list)` and `kfree(da)`, or use `list_for_each_entry_safe` if removing multiple `struct dal_allocation` entries. [F90]
- In `amdgpu_dm_commit_planes()`, `planes_count` indexes `bundle->surface_updates[]` and `bundle->scaling_infos[]` separately from the loop counter `i`, and must be incremented before `continue` when `!plane_needs_flip` as well as after populating flip state, but never on early skip `continue` paths. [F94]
- In `dm_dmub_outbox1_low_irq()`, the `do { ... } while (notify.pending_notification)` loop must call `dc_stat_get_dmub_notification(adev->dm.dc, &notify)` at the start of every iteration before any `continue` statement for invalid or unhandled `notify.type` values so `notify.pending_notification` is updated on every pass. [F95]
- In `create_validate_stream_for_sink()`, recursive DP YUV fallback must set `aconnector->force_yuv422_output` on the first retry and `aconnector->force_yuv420_output` on the second, break when both are already true, and reset both flags to `false` after the recursive call returns. [F96]
- In `add_affected_mst_dsc_crtcs()`, the `aconnector` cursor variable must be reset to `NULL` before continuing when `!aconnector->mst_output_port || !aconnector->mst_root` so that after loop termination without a `break`, `aconnector` does not remain non-NULL and point to a non-MST connector. [F98]
- In `convert_brightness_from_user()` and `convert_brightness_to_user()`, `(max - min)` and `max` must be widened to `u64` before multiplying by `brightness` or `(brightness - min)` and dividing via `DIV_ROUND_CLOSEST_ULL()`, because millinit AUX brightness values (`1000 * caps->aux_max_input_signal`) can overflow 32-bit multiplication. [F100]
- In `mmhub_read_system_context()`, the 32-bit shifted aperture values `logical_addr_low`, `logical_addr_high`, `agp_base`, `agp_bot`, and `agp_top` must be cast to `uint64_t` before left-shifting by 18 or 24 when assigning to `pa_config->system_aperture` 64-bit address fields. [F102]
