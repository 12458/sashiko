# INTEL ASoC DRIVERS — sound/soc/intel/boards

This component implements ALSA SoC (ASoC) machine drivers and shared board helpers (`sof_board_helpers`, `hda_dsp_common`, and vendor codec helpers) for Intel Bay Trail/Cherry Trail (SST), SOF, and HDA-DSP platforms, constructing DAI links, codec configs, DAPM routes, jack detection, and clocking from ACPI, DMI quirks, and platform IDs.

## Architecture & Data Flow
- In `sof_board_helpers.c`, `calculate_num_links()` and the `link_order` loop in `sof_intel_board_set_dai_link()` must count and populate the exact same enabled BE links in `struct sof_card_private` or `sof_intel_board_set_dai_link()` returns `-EINVAL` on `idx != num_links`; each 4-bit nibble in `ctx->link_id_overwrite` (`SOF_LINK_IDS`) must be `<= 0xF` and aligned 1:1 with `link_order` nibbles because `link_ids` shifts by `SOF_LINK_IDS_SHIFT` every iteration. [F37, F82]
- In `sof_es8336.c`, `sof_es8336_card.num_links` in `sof_es8336_probe()` must equal the total codec, DMIC, HDMI, and HDMI-In links created in `sof_card_dai_links_create()`, which must add `hdmi_id_offset = 2` to HDMI/HDMI-In link IDs when `dmic_be_num == 0`. [F50]
- When creating iDisp HDMI DAI links in `set_idisp_hdmi_link()`, `sof_es8336.c`, and `sof_pcm512x.c`, the HDMI index `i` (`hdmi_id`) must be 1-based (`1..hdmi_num`) for formatting `"iDisp%d"`, `"iDisp%d Pin"`, and `"intel-hdmi-hifi%d"` and checking `hdmi_id == 1`, while indexing `idisp_components[i - 1]` 0-based; in `ehl_rt5660.c`, `HDMI_LINK_START` (3) and `HDMI_LINE_END` (6) in `hdmi_link_init()` must match the `iDisp1..iDisp4` indices in `ehl_rt5660_dailink[]`. [F49, F61]
- In `sof_rt5682.c`, when `ctx->codec_type == CODEC_RT5650` and `ctx->amp_type == CODEC_NONE`, `sof_audio_probe()` must set `ctx->amp_type = CODEC_RT5650` before `sof_card_dai_links_create()` so `sof_intel_board_set_dai_link()` allocates `ctx->amp_link` for the RT5650 AIF2 speaker pipeline. [F48]
- In SOF `.late_probe` callbacks (`sof_card_late_probe` in `sof_rt5682.c`/`sof_nau8825.c`, `card_late_probe` in `sof_da7219.c`), codec and amplifier setup (such as disabling `'Left Spk'` and `'Right Spk'` for `CODEC_MAX98373`) must run before `sof_intel_board_card_late_probe()` or early HDMI returns. [F68]
- In `sof_cirrus_common.c`, `cs35l41_compute_codec_conf()` compacts present amplifiers into `cs35l41_components[sz]` and `cs35l41_codec_conf[sz]` using `sz` while indexing `cs35l41_name_prefixes[uid]` by ACPI UID (`0..3`), and `cs35l41_set_dai_link()` must be called to populate `cs35l41_codec_conf[]` whenever `cs35l41_set_codec_conf()` is used. [F56]
- In `max_98373_hw_params()`, `max_98390_hw_params()`, and `rt1011_hw_params()`, the codec loop index `i` from `for_each_rtd_codec_dais()` must be bounds-checked against `ARRAY_SIZE` of `max_98373_tdm_mask`, `max_98390_tdm_mask`, or `rt1011_tdm_mask`, and `max_98373_hw_params()` must also check `fls(tx_mask) <= tdm_slots` and `fls(rx) <= tdm_slots`; every `snd_soc_codec_conf.name_prefix` used with `max_98373_ops` (`max_98373_codec_conf`) must be at most `MAX_98373_PIN_NAME - 5` (11) bytes so `max_98373_trigger()` does not truncate `"%s Spk"`. [F59, F94]
- In `sof_da7219.c`, when `da7219_codec_init()` configures `DA7219_SYSCLK_MCLK` PLL bypass mode for 12.288/24.576 MHz MCLK, it must set `ctx->da7219.pll_bypass = true` so `platform_clock_control()` skips starting/stopping the SRM PLL. [F45]
- In `cht_bsw_max98090_ti.c`, `cht_mc_private.ts3a227e_present` couples `snd_soc_card_cht.aux_dev` in `snd_cht_mc_probe()` with `cht_codec_init()`: when true, `cht_max98090_headset_init()` creates `ctx->jack` and `cht_codec_init()` must only register `cht_jack_nb`; when false, clearing `aux_dev` also requires `num_aux_devs = 0`. [F44]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `sof_es8336.c`, codec software node properties (`byt_rt5640_add_codec_device_props`, `byt_rt5651_add_codec_device_props`, `device_add_software_node`) must be registered after DMI/`quirk_override` resolution and before `devm_snd_soc_register_card()`, and `MAX_NO_PROPS` sizing `props[MAX_NO_PROPS] = {}` must exceed the maximum `props[cnt++]` assignments on any path by at least 1 for the zero sentinel. [F42, F64]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, and `cht_bsw_rt5645.c`, SSP0/SSP2 and AIF1/AIF2 quirks must update BE cpu/codec `dai_name` in probe, SSP-to-AIF DAPM routes in `init`, and 16-bit (SSP0) vs 24-bit (SSP2) TDM slot width/PLL BCLK ratio in `be_hw_params_fixup` and `hw_params` in lockstep; in `bytcr_rt5640.c` and `bytcr_rt5651.c`, `suspend_pre` (`byt_rt5640_suspend`) and `resume_post` (`byt_rt5640_resume`) must guard `snd_soc_component_set_jack()` with the `init` `JDSRC` check and pass `&priv->jack_data` or `priv->hp_detect` on resume. [F52, F53]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `bytcr_wm5102.c`, `log_quirks()` must clamp unrecognized multi-bit routing fields in `byt_rt5640_quirk`, `byt_rt5651_quirk`, or `quirk` to a valid default before probe indexes `map_name`, `mic_name`, or `out_map_name`; in `byt_rt5640_quirk_table[]`, specific DMI entries must precede prefix matches (`T100TAF` before `T100TA`, and the generic Insyde catch-all last). [F55, F57]

## Synchronization
- In `sof_es8336_probe()` and `sof_audio_probe()` (`sof_pcm512x.c`), `INIT_LIST_HEAD()` on `hdmi_pcm_list`, `INIT_DELAYED_WORK(&priv->pcm_pop_work, pcm_pop_work_events)`, and `snd_soc_card_set_drvdata()` must complete before `devm_snd_soc_register_card()`. [F18]
- DAI links with sleeping callbacks require nonatomic substreams: `sof_es8336_ops` links in `sof_es8336.c` must set `link->nonatomic = true` (`sof_8336_trigger()` calls `gpiod_set_value_cansleep()`); `max_98373_ops` in `sof_maxim_common.c` requires nonatomic substreams (`max_98373_trigger()` calls `snd_soc_dapm_enable_pin()`, `snd_soc_dapm_disable_pin()`, and `snd_soc_dapm_sync()`, taking `card->dapm_mutex`); and BYT/CHT front-end DPCM links (`MERR_DPCM_AUDIO`, `MERR_DPCM_DEEP_BUFFER`) on `"sst-mfld-platform"` must set `.nonatomic = true`. [F110, F111, F112]
- In `bytcht_es8316.c`, `priv->speaker_en_gpio` must be requested with `GPIOD_FLAGS_BIT_NONEXCLUSIVE` in `snd_byt_cht_es8316_mc_probe()` and restored to `priv->speaker_en` in `byt_cht_es8316_resume()` (`snd_soc_card.resume_post`, PM `complete()` phase) so it runs after the silead touchscreen's `_PS0` method. [F19]

## Object Lifetimes
- Every `struct acpi_device *adev` from `acpi_dev_get_first_match_dev()` must be held until all `adev` uses (`acpi_dev_name()`, `acpi_get_first_physical_node()`, `acpi_dev_gpio_irq_get()`, `acpi_fwnode_handle()`) finish and then released via `acpi_dev_put(adev)` on all paths; because `acpi_get_first_physical_node()` returns a borrowed `struct device *` whereas `bus_find_device_by_name()` returns an owned reference, drivers storing `priv->codec_dev` from `acpi_get_first_physical_node()` (`snd_byt_rt5640_mc_probe`, `snd_cht_mc_probe`) must call `get_device()` and balance it with `put_device()` on probe error and `.remove`. [F1, F2]
- When `fwnode_create_software_node()` and `device_add_software_node()` attach properties to `codec_dev` (`byt_rt5640_add_codec_device_props`, `snd_byt_rt5640_mc_probe`, `snd_byt_cht_es8316_mc_probe`), callers must unconditionally call `fwnode_handle_put(fwnode)` before checking `device_add_software_node()`'s return value, and call `device_remove_software_node(priv->codec_dev)` before `put_device(priv->codec_dev)` on subsequent probe errors and in `.remove`. [F3, F96]
- Non-devm GPIOs acquired on `codec_dev` (`spkvdd_en_gpio` in `bytcr_wm5102.c`, `speaker_en_gpio` in `bytcht_es8316.c`, `gpio_speakers` in `sof_es8336.c`) must be released with `gpiod_put()` on probe failure and in `.remove` (never `devm_gpiod_get(codec_dev, ...)`), and in `sof_es8336_remove()`, `cancel_delayed_work_sync(&priv->pcm_pop_work)` must precede `gpiod_put(priv->gpio_speakers)`, `device_remove_software_node(priv->codec_dev)`, and `put_device(priv->codec_dev)` because `pcm_pop_work_events()` uses `priv->gpio_speakers`. [F6, F7]
- Direct `acpi_dev_add_driver_gpios()` calls in `bytcr_rt5640.c` (`byt_rt5640_get_amcr0f28_settings()`, `snd_byt_rt5640_mc_probe()` with `BYT_RT5640_JD_HP_ELITEP_1000G2`) must be balanced by `acpi_dev_remove_driver_gpios()` before dropping the device reference; codec link `.exit` callbacks (`sof_es8316_exit`, `sof_rt5682_codec_exit`, `da7219_codec_exit`, `sof_cs42l42_exit`, `sof_nau8825_codec_exit`) must call `snd_soc_component_set_jack(component, NULL, NULL)`; and `hda_dsp_hdmi_build_controls()` must release `snd_hdac_display_power(..., HDA_CODEC_IDX_CONTROLLER, false)` even if `snd_hda_codec_build_controls()` fails. [F8, F10, F11]
- Before `clk_set_rate()` on MCLK in codec `.init` callbacks (`byt_cht_es8316_init`, `sof_rt5682_codec_init`), drivers must cycle `clk_prepare_enable()` and `clk_disable_unprepare()` to sync with firmware boot state; in `platform_clock_control()` (`bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `cht_bsw_rt5645.c`, `cht_bsw_rt5672.c`), codec sysclk/FLL must switch to internal RC clock or `ARIZONA_FLL_SRC_NONE` before `clk_disable_unprepare(mclk)`; and in `cht_bsw_max98090_ti.c` with `QUIRK_PMC_PLT_CLK_0`, `mclk` is enabled once in `snd_cht_mc_probe()`, must not be disabled in `platform_clock_control()` or `cht_codec_init()`, and is disabled in `snd_cht_mc_remove()`. [F12, F13, F14]
- Strings assigned to `snd_soc_dai_link_component.name` (`codec_name` in `bytcht_es8316.c`, `bytcr_rt5640.c`, `bytcr_rt5651.c`, `cht_bsw_rt5645.c`, `cht_bsw_rt5672.c`, `sof_es8336.c`) or `snd_soc_card` `.name`, `.long_name`, or `.components` (`components_string`) must reside in static or `devm_*` storage, never a probe stack buffer. [F93]

## API Contracts
- `sof_intel_board_get_ctx()` returns `NULL` on allocation failure (test `!ctx`, not `IS_ERR(ctx)`), and `board_quirk` bits `8..31` are reserved for `sof_board_helpers.h` (`SOF_SSP_PORT_CODEC_MASK` through `SOF_BT_OFFLOAD_PRESENT`), restricting driver quirks to bits `0..7`; `SOF_SSP_PORT_CODEC()`, `SOF_SSP_PORT_AMP()`, and `SOF_SSP_PORT_BT_OFFLOAD()` take 0-based port numbers (`0..7`) whereas `SOF_SSP_MASK_HDMI_CAPTURE()` takes a 6-bit port bitmask; and `SOF_LINK_NONE` (0) in `SOF_LINK_ORDER()` must only appear after all active `SOF_LINK_*` arguments. [F21, F31, F81, F83]
- `sof_intel_board_set_dai_link()` allocates `card->dai_link` and sets `ctx->codec_link` and `ctx->amp_link` but leaves their `codecs`/`num_codecs` for the caller to populate before card registration, and any driver calling `sof_intel_board_set_dai_link()` or `sof_intel_board_card_late_probe()` must store the `sof_board_helpers.h` `struct sof_card_private *` in `card->drvdata` via `snd_soc_card_set_drvdata()`. [F15, F92]
- `sof_dai_get_mclk()`, `sof_dai_get_bclk()`, and `sof_dai_get_tdm_slots()` return a negative errno on error or `0` when unconfigured, so callers must store the result in a signed `int` and reject values `<= 0`. [F22]
- Drivers wiring `CODEC_MAX98373` via `max_98373_dai_link()` must also call `max_98373_set_codec_conf(card)` and disable `'Left Spk'` and `'Right Spk'` in `card->late_probe`; when `sof_rt5682_codec_init()` calls `snd_soc_component_set_jack()` with a non-NULL `jack` and `ctx->codec_type == CODEC_RT5650`, `data` (`extra_jack_data`) must be a non-NULL `int *` because `rt5645_component_set_jack()` dereferences `*(int *)data`. [F46, F87]
- `byt_rt5640_add_codec_device_props()` and `byt_rt5651_add_codec_device_props()` borrow `i2c_dev` without dropping its reference on error, leaving `put_device(priv->codec_dev)` to `snd_byt_rt5640_mc_probe()` and `snd_byt_rt5651_mc_probe()`; in `byt_rt5640_init()`, `rt5640_jack_gpio.data` must be `struct byt_rt5640_private *priv` (`byt_rt5640_hp_elitepad_1000g2_jack1_check`) whereas `rt5640_jack2_gpio.data` must be `struct snd_soc_component *component` (`byt_rt5640_hp_elitepad_1000g2_jack2_check`). [F5, F91]
- In dual SST/SOF BYT/CHT drivers (`bytcr_wm5102.c`, `bytcht_es8316.c`), when `snd_soc_acpi_sof_parent(dev)` is true, probe must set `card->name = SOF_CARD_NAME`, `card->driver_name = SOF_DRIVER_NAME` (`"SOF"`), and `dev->driver->pm = &snd_soc_pm_ops` before registering the card. [F123]

## Error Handling
- Loops scanning `snd_soc_dai_link` arrays with `COMP_DUMMY()` entries (`byt_rt5640_dais`, `byt_rt5651_dais`, `byt_cht_es8316_dais`, `byt_wm5102_dais`, `cht_dailink`) must check `num_codecs != 0` before dereferencing `codecs->name`; card `late_probe` callbacks (`sof_intel_board_card_late_probe`, `sof_card_late_probe`, `card_late_probe`) must check `idisp_codec` before calling `hda_dsp_hdmi_build_controls()`; and in `sof_rt5682.c`, `sof_rt5682_codec_init()` and `sof_rt5682_hw_params()` must check both `ctx->rt5682.mclk_en` and `ctx->rt5682.is_legacy_cpu` before using `ctx->rt5682.mclk`. [F20, F26, F27]
- When `devm_clk_get_optional()` returns `NULL` for `pmc_plt_clk_3` in `snd_byt_rt5640_mc_probe()` or `snd_byt_rt5651_mc_probe()`, `BYT_RT5640_MCLK_EN` / `BYT_RT5651_MCLK_EN` must be cleared so PLL falls back to BCLK; in `snd_byt_rt5651_mc_probe()`, `devm_fwnode_gpiod_get()` returning `ERR_PTR(-ENOENT)` must reset `priv->ext_amp_gpio` or `priv->hp_detect` to `NULL`; and in `snd_byt_wm5102_mc_probe()`, `gpiod_get(codec_dev, "wlf,spkvdd-ena", ...)` returning `ERR_PTR(-ENOENT)` must be converted to `-EPROBE_DEFER`. [F28, F29, F36]
- In `byt_rt5640_init()` with `BYT_RT5640_JD_HP_ELITEP_1000G2`, if adding `rt5640_jack2_gpio` fails, `rt5640_jack_gpio` must be freed with `snd_soc_jack_free_gpios(&priv->jack, 1, &rt5640_jack_gpio)`, and `byt_rt5640_exit()` must free both in reverse order; in `cht_codec_init()` (`cht_bsw_max98090_ti.c`), the `QUIRK_PMC_PLT_CLK_0` branch must `return 0` (not `ret` from non-fatal `snd_soc_jack_add_gpiods()`); and in DAI `.init` callbacks (`max_98390_init`, `max_98357a_init`, `dmic_init`), `snd_soc_dapm_new_controls()` failure must return immediately before `snd_soc_add_card_controls()` or `snd_soc_dapm_add_routes()`. [F9, F35, F125]

## External Contracts
- When parsing the ACPI `CHAN` package with format `"NN"` (`snd_byt_rt5640_mc_probe`, `snd_byt_rt5651_mc_probe`), `struct acpi_chan_package` must use `u64` fields (`aif_value`, `mclock_value`) matching `pkg_ctx.length = 2` and validate `aif_value` against `1` and `2`; static BYT/CHT DPCM BE links (`byt_wm5102_dais`, `byt_rt5640_dais`, `byt_rt5651_dais`, `byt_cht_es8316_dais`, `cht_dailink`) must keep `.name = "SSP2-Codec"` even on SSP0 while `set_ssp_codec_link()` and `sof_pcm512x.c` format `cpus->dai_name` as `"ssp%d-port"`; when `idisp_codec` is false, iDisp links in `set_idisp_hdmi_link()`, `sof_pcm512x.c`, and `ehl_rt5660.c` must still be created with `snd_soc_dummy_dlc`; and on 2-amp CML (`soc_intel_is_cml()`), `rt1011_init()` and `sof_rt1011_codec_conf()` must pass `num_codecs` (2) to `realtek_4spk_widgets`, `realtek_4spk_kcontrols`, `rt1011_4spk_routes`, and `rt1011_4spk_codec_confs`. [F58, F66, F67, F118]

## Known Pitfalls
- In `sof_es8336.c`, `priv->speaker_en` is inverted (`false` when `'Speaker Power'` is ON, `true` when OFF) because `enable_gpio0`/`enable_gpio1` set `active_low = true`, which `sof_es8316_speaker_power_event()` and `sof_8336_trigger()` must preserve; in `max_98373_trigger()`, `dapm` must come from `cpu_dai->component` while the pin prefix comes from `codec_dai->component->name_prefix`, and capture substreams must return 0 immediately. [F75, F76]
- Before computing `fls(mask) - 1` on NHLT link masks (`i2s_link_mask` in `sof_es8336_probe()`, `bt_link_mask` in `skl_hda_get_board_quirk()`), `mask` must be checked non-zero to avoid underflow; in drivers with signed `int quirk_override = -1` (`bytcht_es8316.c`, `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `sof_es8336.c`), quirk flags must not use `BIT(31)` or higher due to sign-extension into `unsigned long`; and drivers using `pdev->id_entry->driver_data` with DMI overrides (`sof_rt5682.c`, `sof_es8336.c`) must read `driver_data` before `dmi_check_system()` and include `.driver.name` plus a `{ }` sentinel in `.id_table` (`board_ids`, `ehl_board_ids`). [F84, F85, F98, F99]
