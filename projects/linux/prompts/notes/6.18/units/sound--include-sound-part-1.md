# SOUND — include/sound (part 1)

Core ALSA headers, hardware abstractions, and device definitions for sound cards, PCM streams, mixer controls, AC'97, HD-Audio (HDA), DMA memory allocation, and legacy ISA/PCI codecs.

## Architecture & Data Flow
- Allocate `struct snd_kcontrol` via `struct_size(..., vd, count)` and set `kctl->count = count` before indexing `vd[]` (`__counted_by(count)`); copy `vd[]` with explicit `memcpy`. Once added to a `snd_card`, rename only via `snd_ctl_rename()` or `snd_ctl_rename_id()` to keep `card->ctl_hash` and `card->ctl_numids` synchronized. In `snd_ctl_elem_id`, `numid` is 1-based (`0` is invalid) while `index` and `vd[]` offset `ioff` are 0-based (`snd_ctl_build_ioff()` adds 0-based `offset` to both). [F44, F57, F97]
- Userspace control allocations (`SNDRV_CTL_ELEM_ACCESS_USER`: data, enum `names_length`, TLV) must check `max_user_ctl_alloc_size` (`check_user_elem_overflow()`) and update `card->user_ctl_alloc_size` under `card->controls_rwsem` write lock on alloc, replace, error, and `private_free`. [F147]
- Update substream runtime DMA buffers only via `snd_pcm_set_runtime_buffer()` so `runtime->dma_buffer_p`, `dma_area`, `dma_addr`, and `dma_bytes` stay synchronized. In `snd_pcm_runtime`, `status->hw_ptr` and `control->appl_ptr` wrap modulo `runtime->boundary` (not `buffer_size`), so `snd_pcm_playback_avail()` and `snd_pcm_capture_avail()` wrap `< 0` and `>= runtime->boundary` by `runtime->boundary`. [F46, F63]
- In `snd_mask_leave(mask, val)`, sample `mask->bits[MASK_OFS(val)] & MASK_BIT(val)` before `snd_mask_none(mask)` so `val` is only kept if previously set. [F52]
- In `struct hdac_bus`, `caddr_tbl` has `HDA_MAX_CODEC_ADDRESS + 1` (16) slots, whereas `corb`/`rirb` `cmds`/`res` and `last_cmd` have only `HDA_MAX_CODECS` (8) slots (`HDA_CODEC_IDX_CONTROLLER` = 8 is reserved). Broken by: indexing `rirb` or `last_cmd` with `addr >= HDA_MAX_CODECS`. [F71]
- Because `struct nhlt_endpoint` and `struct nhlt_fmt_cfg` end with variable-length `struct nhlt_specific_cfg config` (`u32 size; u8 caps[];`), advance `nhlt->desc` by `(u8 *)epnt + epnt->length` and `fmt->fmt_config` by `cfg->config.caps + cfg->config.size`, never by pointer increment or indexing. Before reading `array_type` or `nb_mics` from `nhlt_dmic_array_config` in `epnt->config.caps`, check `device_config.config_type == NHLT_CONFIG_TYPE_MIC_ARRAY` (and `array_type == NHLT_MIC_ARRAY_VENDOR_DEFINED` before casting to `nhlt_vendor_dmic_array_config`). [F30, F67]
- When parsing ELD into `struct snd_parsed_hdmi_eld`, enforce `mnl <= ELD_MAX_MNL` (16), `ELD_FIXED_BYTES + mnl <= size`, and `ELD_FIXED_BYTES + mnl + 3 * (i + 1) <= size` for each SAD `i < sad_count` (`<= ELD_MAX_SAD` = 16); read `port_id`, `manufacture_id`, and `product_id` via `get_unaligned_le*()`. [F68]
- Keep `enum snd_jack_types` switch bits (0..6, `SND_JACK_SWITCH_TYPES` = 7) and button bits (`SND_JACK_BTN_0`..`5`) synchronized with `jack_switch_types[]` and `snd_jack.key[6]`. In `emu10k1.h`, `SUB_REG()`/`SUB_REG_NC()` `mask` must be a non-zero contiguous bit run with shift and width `<= 31` (`0xffffffff` overflows 5-bit `REG_SIZE`). [F73, F74]

## Synchronization
- Update `snd_card.power_state` via `snd_power_change_state()` (`WRITE_ONCE` + `wake_up(&card->power_sleep)`) and read locklessly via `snd_power_get_state()` (`READ_ONCE`). [F12]
- Control locking: call `snd_power_ref_and_wait(card)` before acquiring `card->controls_rwsem` (and `snd_power_unref()` after releasing); `card->controls_rwlock` nests inside `controls_rwsem`, and `snd_ctl_file.read_lock` (guarding `ctl->events`) nests inside `controls_rwlock`. `snd_ctl_find_numid()`, `snd_ctl_find_id()`, and `snd_ctl_find_id_mixer()` return unreferenced pointers, so hold `card->controls_rwsem` while dereferencing them. `snd_ctl_notify()` is IRQ/atomic-safe, whereas `snd_ctl_notify_one()` takes sleeping `snd_ctl_layer_rwsem` (process context only). [F15, F128, F129, F130]
- When `snd_pcm.nonatomic` is false, `snd_pcm_stream_lock*` takes spinlock `substream->self_group.lock` (IRQs off), so `trigger`, `pointer`, `get_time_info`, and `ack` must not sleep. When `nonatomic` is true, it takes `self_group.mutex`, so `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` sleep and cannot run in atomic/IRQ context. [F122, F123]
- `snd_pcm_start()`, `snd_pcm_stop()`, `snd_pcm_drain_done()`, `snd_pcm_period_elapsed_under_stream_lock()`, and `__snd_pcm_set_state()` (which updates both `runtime->state` and `runtime->status->state`) require holding `snd_pcm_stream_lock*`; `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` take the lock internally and must be called unlocked. [F16, F18, F125]
- Use `snd_pcm_stream_lock_irqsave_nested()` when locking a second `snd_pcm_substream` inside another substream lock. `substream->group` (`lock`/`mutex`) orders outside `substream->self_group`: to lock `group` while holding `self_group`, trylock first, or else pin `group->refs`, drop `self_group`, lock `group` then `self_group`, and recheck `substream->group == group`. [F17, F19]
- PCM read/write (`__snd_pcm_lib_xfer`) copying to/from userspace must not hold `runtime->buffer_mutex` (which nests inside `mm->mmap_lock`); guard with `runtime->buffer_accessing` and `snd_pcm_buffer_access_lock()`. [F126]
- `snd_hdac_stream_release_locked()` and `snd_hdac_ext_stream_decouple_locked()` require holding `bus->reg_lock`, whereas `snd_hdac_stream_assign/release()` and `snd_hdac_ext_stream_assign/release/decouple()` acquire `bus->reg_lock` internally. `snd_hdac_bus_exec_verb_unlocked()` requires holding `bus->cmd_mutex` in process context; `hdac_bus_eml_*_unlocked()` and `hdac_bus_eml_sdw_*_unlocked()` require holding `hdac_bus_eml_get_mutex(bus, alt, elid)`. [F26, F134, F135]
- Lock `struct snd_i2c_bus` via `snd_i2c_lock()`/`snd_i2c_unlock()` (not `bus->lock_mutex` directly, as slaves use `bus->master->lock_mutex`). Hold `emu->emu1010.lock` (`guard(snd_emu1010_fpga_lock)(emu)`) for `snd_emu1010_fpga_write/read()` and `link_dst_src_write/read()`. Hold `gus->active_voice_lock` in `snd_gf1_select_voice()` across `gus->gf1.active_voice` and `GUSP(gus, GF1PAGE)`. [F25, F49, F120]

## Object Lifetimes
- `snd_ctl_add()` and `snd_ctl_replace()` consume `kcontrol` and call `snd_ctl_free_one(kcontrol)` on error; never free `kcontrol` after calling them. [F2]
- Pair every `snd_power_ref()` and `snd_power_ref_and_wait()` with `snd_power_unref(card)` on all paths, including when `snd_power_ref_and_wait()` returns `-ENODEV`, or `snd_power_sync_ref()` will hang. Pair `snd_card_ref()` and non-NULL `snd_lookup_minor_data()` with `snd_card_unref(card)`. `snd_ctl_file.pid` and `snd_pcm_substream.pid` use `get_pid()`/`put_pid()` and must be formatted for userspace/procfs with `pid_vnr()`. [F3, F4, F148]
- If a driver uses `snd_devm_card_new()` and later allocates devres resources touched by `card->private_free` or `snd_device` `.dev_free`, probe errors before `snd_card_register()` must call `snd_card_free()` or `snd_card_free_on_error()`. Keep `SNDRV_DEV_CONTROL` last in `enum snd_device_type` so it registers last, disconnects first, and frees with `SNDRV_DEV_LOWLEVEL` in `snd_device_free_all()`'s final pass. [F106, F107]
- `snd_hda_power_up*()` / `snd_hdac_power_up*()` increment the runtime PM count or `codec->core.in_pm` even on error; callers not using `CLASS(snd_hda_power*, pm)(codec)` must call `snd_hda_power_down*()` on failure. `CLASS(snd_hda_power*, pm)(codec)` always powers down at scope exit and stores errors in `pm.err` without aborting, so check `pm.err` and never manually power down inside the scope. [F7, F37]
- Refcount active HDA PCM streams on `codec->pcm_ref` via `snd_hda_codec_pcm_get()` / `put()` on all open/error/close paths (never free `hda_pcm` in close), and wait on `codec->remove_sleep` for `pcm_ref == 0` during unbind. [F10, F21]
- After `snd_hdac_device_init()`, free via `put_device(&codec->dev)` and call `snd_hdac_device_exit()` in any custom `codec->dev.release`. Call `snd_hdac_bus_alloc_stream_pages()` only after `snd_hdac_stream_init()` populates `bus->stream_list`, and empty `stream_list` and `codec_list` before `snd_hdac_bus_exit()`. Manage `snd_es1688` port/irq/dma manually (`snd_es1688_free()`), never via `devm_*`, as ISA probing reuses the `struct device`. [F110, F111, F113]

## API Contracts
- Multi-element (`count > 1`) `snd_kcontrol` callbacks must compute 0-based element offsets via `snd_ctl_get_ioff()`, `snd_ctl_get_ioffnum()`, or `snd_ctl_get_ioffidx()` (`array_index_nospec()`), and `snd_kcontrol_info_t` must leave `uinfo->access == 0` (`snd_BUG_ON(info->access)`). When `SNDRV_CTL_ELEM_ACCESS_TLV_CALLBACK` is set in `access`, `tlv.c` is a `snd_kcontrol_tlv_rw_t` callback; otherwise `tlv.p` is an array with byte length in `tlv.p[1]`. [F56, F137, F139]
- Virtual master followers (`snd_ctl_add_follower*()`) must share the same `INTEGER`/`BOOLEAN` `type`, `min`/`max`, and `count <= 2`. In `snd_ctl_apply_vmaster_followers` callbacks `func(vfollower, follower, arg)`, use `vfollower->put` to update state and `snd_kcontrol_chip(follower)` for driver private data. [F85, F140]
- In `snd_info_entry`, `c.text` is active when `content == SNDRV_INFO_CONTENT_TEXT` and `c.ops` when `SNDRV_INFO_CONTENT_DATA`. Check `snd_card_proc_new(...) == 0` before dereferencing `*entryp` (unset when `!CONFIG_SND_PROC_FS`). [F32, F43]
- Use `snd_pcm_running(substream)` to check active DMA (includes playback `SNDRV_PCM_STATE_DRAINING`). Call `bytes_to_samples()`, `bytes_to_frames()`, and `frame_aligned()` only after `hw_params` sets `runtime->sample_bits`, `frame_bits`, and `byte_align`. In `snd_pcm_hardware`, `formats` is a 64-bit `SNDRV_PCM_FMTBIT_*` mask and `buffer_bytes_max`/`period_bytes_*`/`fifo_size` are bytes, whereas `runtime->buffer_size`/`period_size` and `params_buffer_size()`/`params_period_size()` are frames (use `params_buffer_bytes()`/`params_period_bytes()` for bytes). [F36, F81, F92, F145]
- Check `hw_is_mask(var)` before `hw_param_mask*()`/`constrs_mask()` and `hw_is_interval(var)` before `hw_param_interval*()`/`constrs_interval()`. Terminate `snd_pcm_hw_rule_add()` deps with `-1` (at most 4 deps to fit `deps[5]`). In `snd_pcm_group_for_each_entry(s, substream)`, filter `s` to the same hardware instance and call `snd_pcm_trigger_done(s, substream)` with `s` first. [F60, F61, F80, F82]
- `snd_pcm_indirect_playback/capture_pointer()` take a 0-based byte offset `ptr` and return `SNDRV_PCM_POS_XRUN` if `ops->ack()` returns `-EPIPE` or capture `hw_ready > qsize`. `snd_pcm_indirect_playback/capture_transfer()` wrap `diff < -(snd_pcm_sframes_t)(runtime->boundary / 2)` by `boundary` and return `-EPIPE` on other `diff < 0`; their `copy` callback must not modify `rec->hw_data`, `sw_data`, `hw_ready`, or `sw_ready`. [F76, F95, F150]
- For SG/non-contiguous buffers (`SNDRV_DMA_TYPE_DEV_SG`, `DEV_WC_SG`, `NONCONTIG`, `VMALLOC`), `dmab->addr` is only the first page; use `snd_sgbuf_get_addr/page/chunk_size()` and `snd_sgbuf_aligned_pages(size)`. `snd_devm_alloc_dir_pages()` / `snd_devm_alloc_pages()` require non-NULL `dev` and reject `CONTINUOUS` and `VMALLOC`. [F93, F131, F133]
- Required ops: `snd_pcm_set_ops()` needs `open`, `close`, `prepare`, `trigger`, `pointer` (plus `copy` or `dma_area`); `snd_ac97_controller_register()` needs `reset`, `warm_reset` (and `read` if `slots_available`); `hdmi_codec_pdata` needs `i2s || spdif`, `ops->audio_shutdown`, and `ops->hw_params || ops->prepare`. [F142, F143, F144]
- HDA codec suspend/resume must bracket with `snd_hdac_enter_pm()`/`leave_pm()` and use `snd_hdac_power_up_pm()`/`down_pm()` (`CLASS(snd_hda_power_pm, ...)`), setting `codec->no_stream_clean_at_suspend = 1` if converter stream IDs must persist. Use `snd_hdac_reg_readb/w`/`writeb/w`, `snd_hdac_chip_*`, or `snd_hdac_stream_*_poll` for 8/16-bit MMIO (`bus->aligned_mmio`), and `list_for_each_codec_safe()` when removing codecs. `drv_to_hdac_driver()` and `hdac_driver.match` require `const struct hdac_driver *` when given a `const` driver; `snd_hda_codec_device_init()` formatted names must be `< 31` bytes. [F79, F100, F104, F112, F114, F116]
- In `snd_array_init(array, size, align)`, `size` is byte size while `align` is element count; `snd_array_new()` invalidates element pointers via `krealloc()`. Sentinel requirements: `{}`/`NULL` terminates `snd_pci_quirk` (place specific `SND_PCI_QUIRK`/narrow masks before `SND_PCI_QUIRK_VENDOR`), `ac97_quirk`, `hda_verb` (`nid == 0`), `snd_pcm_chmap_elem`, `snd_ac97_res_table`, and vmaster follower arrays; `-1` terminates `snd_legacy_find_free_ioport/irq/dma()` tables; `REGLIST_END` (`~0`) terminates raw `(reg, data)` pairs in `snd_emu10k1_ptr_write_multiple()` (and DSP microcode writes to `MICROCODEBASE`/`A_MICROCODEBASE` must write `pc + 0` before `pc + 1`). [F69, F70, F86, F88, F98, F117, F121]

## Error Handling
- `snd_hdac_read_parm*()`, `snd_hdac_codec_read()`, `snd_hda_codec_read()`, and `snd_hda_param_read()` return `(int)-1` on failure (not `-errno`), whereas `_snd_hdac_read_parm()` returns `0` or `-errno`. `snd_hda_codec_device_init()` returns `ERR_PTR`, whereas `snd_hda_codec_pcm_new()`, `snd_ctl_new1()`, and `snd_devm_alloc_*_pages()` return `NULL`. [F27, F28]
- `snd_pcm_format_signed()`, `unsigned()`, and `*_endian()` return `1`, `0`, or `-EINVAL` (not boolean); `snd_pcm_format_width()`, `physical_width()`, `params_*width()`, and `snd_pcm_format_size()` return `-EINVAL` on unknown/variable formats and require signed storage. `snd_kcontrol_put_t` and `snd_hdac_regmap_update_amp*()` return `0` (unchanged), `1`/positive (changed), or `-errno`. Never use `snd_BUG()`/`snd_BUG_ON(cond)` (which always evaluates `cond`) for user input or hardware timeouts. [F33, F34, F41, F149]

## External Contracts
- Never renumber `SNDRV_PCM_RATE_*` bits, and keep `rates[]` / `snd_pcm_known_rates` in bit-position order (unsorted). For non-primary HDA codecs (`addr > 0`) without `codec->ctl_dev_id`, offset mixer `kctl->id.index` by `10 * addr` instead of setting `id.device`. Zero `reserved` and `rsvd[4]` in `snd_pcm_status64`/`32` before copying to userspace, and preserve low 16 bits (`*data &= 0xffff`) in `snd_pcm_pack_audio_tstamp_report()`. Strip `SNDRV_CTL_ELEM_ACCESS_SKIP_CHECK | SNDRV_CTL_ELEM_ACCESS_LED_MASK` from `snd_ctl_elem_info.access` before copying to userspace and reject them in `snd_ctl_elem_add()`. [F58, F59, F65, F66, F138]

## Known Pitfalls
- `snd_hdac_chip_updatel/w/b`, `snd_hdac_updatel/w`, and `snd_hdac_stream_updatel/w/b` compute `(read & ~(mask)) | (val)`; callers must pre-mask `val`. [F77]
- Post-loop after `snd_array_for_each(array, idx, ptr)`, check `idx < array->used` rather than `if (ptr)` (`ptr` is non-NULL one past the end). When narrowing `snd_interval` bounds directly, check `snd_interval_checkempty(i)` (not cached `snd_interval_empty(i)`) and read single values via `snd_interval_value(i)` (not `i->min`, which fails on `(min, min + 1]`). [F78, F83, F84]
- Use `1U << n` for `SNDRV_PCM_RATE_*` (bit 31 `SNDRV_PCM_RATE_KNOT`) and `1ULL << (__force int)fmt` for `_SNDRV_PCM_FMTBIT` / `pcm_format_to_bits()`. Use `snd_iprintf()` only in `c.text.read` callbacks (`seq_file *`) and `snd_info_get_line()` / `buf->buffer` char accesses only in `c.text.write`. Call `dev_to_snd_card(p)` only on `card->card_dev`, never on parent `card->dev`. [F89, F90, F101, F102]
