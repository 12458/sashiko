# NFS, SUNRPC, AND LOCKD CLIENTS — fs/nfs (part 2)

This unit implements NFS inode management and attribute cache revalidation (`inode.c`), mount option parsing and `fs_context` setup (`fs_context.c`, `getroot.c`, `mount_clnt.c`), automounts and referrals (`namespace.c`), fscache/netfs caching (`fscache.c`), local client-to-server bypass I/O (`localio.c`), and the pNFS NFSv4.1 file (`filelayout/*`) and flexfile (`flexfilelayout/*`) layout drivers.

## Architecture & Data Flow
- When `nfs_set_cache_invalid()` sets `NFS_INO_INVALID_DATA`, it must call `nfs_fscache_invalidate()` and, if `i_mapping->nrpages == 0` or `NFS_INO_INVALID_DATA` stays set, call `nfs_ooo_clear()`. When `nfs_inode_attach_open_context()` adds the first entry to `nfsi->open_files` while `nfs_ooo_test(nfsi)` is true, it must call `nfs_set_cache_invalid(inode, NFS_INO_INVALID_DATA | NFS_INO_REVAL_FORCED)` under `inode->i_lock`. [F246, F250]
- In `nfs_update_inode()`, sample `nfs_have_delegated_attributes(inode)` and `nfsi->cache_validity` and run `nfs_fattr_fixup_delegated()` before clearing `cache_validity` or running `nfs_wcc_update_inode()`. In `nfs_post_op_update_inode_force_wcc_locked()`, if `(fattr->valid & NFS_ATTR_FATTR) == 0` or `!attr_cmp`, call `nfs_ooo_record()` before stripping `NFS_ATTR_FATTR_PRECHANGE` and `PRE*` flags. [F248, F249]
- In `nfs_ooo_merge()`, when `start` or `end` merges with `nfsi->ooo->gap[i]`, replace `gap[i]` with `gap[--cnt]` and reset `i = -1`; if `cnt` reaches `ARRAY_SIZE(nfsi->ooo->gap)` for a new gap, free/NULL `nfsi->ooo` and set `NFS_INO_DATA_INVAL_DEFER` on `nfsi->cache_validity`. [F279, F285]
- `nfs_fattr_init()` must NULL-init `owner_name`, `group_name`, and `mdsthreshold` (and `nfs_alloc_fattr()` must NULL-init `label`) because NFSv4 XDR decoding checks non-NULL to decode into them. [F234]
- When `nfs_fs_context_validate()` updates `fc->fs_type` to `ctx->nfs_mod->nfs_fs`, transfer module refs via `module_put()` and `__module_get()`. In `param_set_nfs_timeout()`, updating `nfs_mountpoint_expiry_timeout` must call `mod_delayed_work(system_percpu_wq, &nfs_automount_task, num)` when `num > 0 && !list_empty(&nfs_automount_list)`, or `cancel_delayed_work(&nfs_automount_task)` when `num <= 0`. [F253, F264]
- In `nfs_fscache_open_file()`, if `inode_is_open_for_write(inode)` on a valid cookie, follow `fscache_use_cookie(cookie, true)` with `nfs_fscache_update_auxdata()` and `fscache_invalidate(..., FSCACHE_INVAL_DIO_WRITE)`. In `nfs_netfs_read_completion()`, set `NETFS_SREQ_CLEAR_TAIL` at `NFS_IOHDR_EOF` only when `sreq->rreq->origin` is neither `NETFS_UNBUFFERED_READ` nor `NETFS_DIO_READ`, and clear `hdr->netfs = NULL` after `nfs_netfs_put()`. [F254, F255]
- When `nfs_local_call_write()` falls back from DIO on `-ENOTBLK`, clear `IOCB_DIRECT` from `ki_flags` and reset `ki_complete` and `aio_complete_work` to `NULL` before retrying. When `nfs_local_write_done()` or `nfs_local_commit_done()` fails (`tk_status < 0` or `status < 0`), call `nfs_reset_boot_verifier(inode)`. [F258, F259]
- In `filelayout_write_done_cb()` and `ff_layout_write_done_cb()`, clear `hdr->fattr.valid = 0` before `nfs_writeback_update_inode(hdr)`. In `ff_layout_read/write_done_cb()`, clear both `NFS_IOHDR_RESEND_PNFS` and `NFS_IOHDR_RESEND_MDS` before setting the new resend bit. In flexfile I/O stats, gate `nfs4_ff_layout_stat_io_start/end_*()` on `test_and_set/clear_bit(NFS_IOHDR_STAT, &flags)` to pair `nfs4_ff_start/end_busy_timer()`. [F203, F238, F262]
- In `nfs4_fl_alloc_deviceid_node()`, enforce `stripe_count <= NFS4_PNFS_MAX_STRIPE_CNT`, `ds_num <= NFS4_PNFS_MAX_MULTI_CNT`, and `stripe_indices[i] < ds_num`, and set `dsaddr->ds_num = num` right after `kzalloc()` before touching `ds_list[]` (`__counted_by(ds_num)`) or `nfs4_fl_free_deviceid()`. `filelayout_check_layout()` must reject `!fl->stripe_unit`; `filelayout_check_deviceid()` must enforce `first_stripe_index < stripe_count` and `num_fh` in `{0, 1, ds_num}` (`STRIPE_SPARSE`) or `stripe_count` (`STRIPE_DENSE`). Filelayout `ds_commit_index` is DS index (`0..ds_num-1`) for `STRIPE_SPARSE` and stripe index (`0..stripe_count-1`) for `STRIPE_DENSE`. [F265, F266, F267, F292, F308]
- In `ff_layout_alloc_lseg()`, enforce `mirror_array_cnt` in `1..NFS4_FLEXFILE_LAYOUT_MAX_MIRROR_CNT`, identical `dss_count` in `1..NFS4_FLEXFILE_LAYOUT_MAX_STRIPE_CNT` across mirrors, and `stripe_unit != 0` when `dss_count > 1`, setting `fls->mirror_array_cnt` right after `kzalloc()` before touching `mirror_array[]` (`__counted_by(mirror_array_cnt)`). [F269, F309]
- In `ff_layout_encode_layoutstats()`, write the opaque length header at `start` as `cpu_to_be32((xdr->p - start - 1) * 4)`. In `ff_layout_match_io()`, verify `task->tk_ops` against flexfile rw/commit `rpc_call_ops` before casting `task->tk_calldata` in `ff_layout_match_rw/commit()`. [F278, F314]
- Bound XDR filehandle sizes before `memcpy` (`fh->size <= NFS_MAXFHSIZE` in `filelayout_decode_layout()`/`decode_nfs_fh()`; `size > 0 && size <= NFS3_FHSIZE` in `decode_fhandle3()`/`nfs23_parse_monolithic()`). In `decode_auth_flavors()`, clamp `entries` to `NFS_MAX_SECFLAVORS` before `xdr_inline_decode()` and to `*res->auth_count` before copying. [F270, F271]

## Synchronization
- In `nfs_fhget()`, when `iget5_locked()` returns an `I_NEW` inode, initialize all `nfs_inode` fields, `nfs_inode_init_regular/dir()`, op tables, timeouts, and `nfs_fscache_init_inode()` before `unlock_new_inode()`. [F205]
- On published inodes (`!I_NEW`), `nfs_set_cache_invalid()`, `nfs_set_inode_stale_locked()`, and `nfs_zap_caches_locked()` require `inode->i_lock`, and `nfs_ooo_merge()` must use `GFP_ATOMIC`. In `nfs_setattr()`, delegated mtime (`ATTR_MTIME`), `ATTR_ATIME`, and clearing `NFS_INO_INVALID_CTIME|MTIME|ATIME` must happen in one `inode->i_lock` critical section. [F206, F208, F325, F328]
- In `nfs_clear_invalid_mapping()`, pair `smp_rmb()` and `smp_load_acquire(&nfsi->cache_validity)` with `smp_wmb()` and `nfs_set_cache_invalid()`'s `smp_store_release()`, then under `inode->i_lock` re-check `NFS_INO_INVALIDATING` and `NFS_INO_INVALID_DATA`, set `NFS_INO_INVALIDATING`, and clear `NFS_INO_INVALID_DATA` (with `nfs_ooo_clear()`) before dropping `i_lock` for `nfs_invalidate_mapping()`. [F207, F247]
- `nfs_file_block_o_direct()` requires exclusive `inode->i_rwsem` and must precede `nfs_sync_inode()` in regular-file `nfs_setattr()`. When the `down_read_killable(&inode->i_rwsem)` check of `NFS_INO_ODIRECT` fails in `nfs_start_io_read/direct()`, drop `i_rwsem`, take `down_write_killable()`, re-test `NFS_INO_ODIRECT` in `nfs_file_block_o_direct()` or `nfs_block_buffered()`, and call `downgrade_write()`. `nfs_vmtruncate()` requires `inode->i_lock` on entry/exit to update `i_size` and clear `NFS_INO_INVALID_SIZE`, but must drop `i_lock` across `truncate_pagecache()`. [F209, F210, F211]
- `nfsi->open_files` and `ctx->lock_context.list` are RCU-protected and mutated under `inode->i_lock` with RCU list ops and `kfree_rcu()`: `nfs_find_open_context()` uses `rcu_read_lock()` + `get_nfs_open_context()`, `nfs_get_lock_context()` re-searches under `i_lock`, and `nfs_put_lock_context()` uses `refcount_dec_and_lock(&l_ctx->count, &inode->i_lock)`. `nfs_clear_pnfs_ds_commit_verifiers()` must iterate `cinfo->commits` with `list_for_each_entry_rcu()` under `rcu_read_lock()`. [F212, F337, F338]
- In `nfs_path()`, walk `d_parent` under `read_seqbegin(&rename_lock)` and `rcu_read_lock()`, locking one `dentry->d_lock` at a time and holding root `d_lock` across `read_seqretry()` and copying `d_fsdata`; keep `dentry_in`/`buflen_in` unmodified and check `read_seqretry()` in `Elong_unlock` before returning `-ENAMETOOLONG`. [F214, F283]
- Protect `clp->cl_nfssvc_boot` with seqlock `clp->cl_boot_lock`. `nfs_local_probe_async_work()` must pin `clp` via `refcount_inc_not_zero(&clp->cl_count)` (and `nfs_put_client()`), and `nfs_local_probe()` must bracket `nfs_server_uuid_is_local()` and `nfs_localio_enable_client()` with `nfs_uuid_begin/end(&clp->cl_uuid)`. Queue `nfs_local_call_read/write` on `nfslocaliod_workqueue` (no `WQ_MEM_RECLAIM`) and defer `nfs_local_pgio_release()` / `nfs_local_vfs_getattr()` from `nfs_local_*_aio_complete` to `nfsiod_workqueue`. [F216, F217, F218]
- In `nfs_io_gfp_mask()`, add `__GFP_NORETRY | __GFP_NOWARN` for `PF_WQ_WORKER` only when `current_gfp_context(GFP_KERNEL) == GFP_KERNEL`. In `nfs_local_iocb_init()`, pass `GFP_NOIO` to `nfs_local_iocb_alloc()` for writes (`!(hdr->rw_mode & FMODE_READ)`). [F319, F321]
- In `filelayout_check_deviceid()` and `ff_layout_init_mirror_ds()`, publish `fl->dsaddr` or `mirror_ds` via `cmpxchg(..., NULL, ...)`, dropping the extra ref on race. In flexfilelayout, read `ro_cred`/`rw_cred` under `rcu_read_lock()` via `get_cred_rcu()` and swap on existing mirrors with `xchg()`. `inode->i_lock` protects `flo->error_list` and `ff_layout->mirrors` and nests outer to `mirror->lock` (which protects `read_stat`/`write_stat`); call `pnfs_report_layoutstat()` outside `mirror->lock`. [F220, F221, F222]
- In `nfs_netfs_issue_read()`, `nfs_netfs_alloc()` sets `refcount = 1`, each split RPC increments it in `nfs_netfs_initiate_read()` and drops it in `nfs_netfs_read_completion()`, and `nfs_netfs_issue_read()` calls `nfs_netfs_put()` after `nfs_pageio_complete_read()` so `netfs_read_subreq_terminated()` runs once on `refcount_dec_and_test()` (clamping `sreq->transferred` to `sreq->len`). [F223, F346]

## Object Lifetimes
- In `nfs_local_call_read/write()`, call `revert_creds(save_cred)` before `nfs_local_pgio_release(iocb)`. Release `struct nfsd_file *` from `nfs_local_open_fh()` via `nfs_local_file_put()` (`nfs_to_nfsd_file_put_local()`). `nfs_local_commit()` owns `localio` and `data`: on `!ctx` failure call `nfs_local_commit_done()` and `nfs_local_release_commit_data()`; for `FLUSH_SYNC`, set `ctx->done` before `queue_work()` and call `complete(ctx->done)` in `nfs_local_fsync_work()` after `nfs_local_commit_done()` and before `nfs_local_fsync_ctx_free()`. [F184, F185, F186, F219]
- In `__put_nfs_open_context()`, release `dentry`, `cred`, `ctx->nfl`, and `nfs_sb_deactive()` only after `close_context()` completes and free via `kfree_rcu()`. `nfs_file_set_open_context()` takes its own ref, so `nfs_open()` must still call `put_nfs_open_context(ctx)`. `nfs_destroy_inodecache()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F188, F189, F224]
- In `nfs_superblock_set_dummy_root()`, `d_make_root(inode)` consumes the inode ref, so on success call `ihold(inode)` and unlink `sb->s_root->d_u.d_alias` under `inode->i_lock` and `d_lock`. In `nfs_get_root()`, after `fc->root = root`, `error_splat_root` must `dput(fc->root)` and set `fc->root = NULL`, and `name` must be nulled when moved to `root->d_fsdata`. [F193, F194, F351]
- `nfs_fs_context_dup()` must allocate a new `ctx->mntfh`, call `get_nfs_version()`, and NULL all owned pointers freed by `nfs_fs_context_free()`. `nfs_fs_context_parse_param()` must `kfree()` any prior `ctx` string before taking `param->string` and set `param->string = NULL`. `nfs_init_fs_context()` (on remount) and `nfs_d_automount()` must replace `fc->net_ns` with `client->cl_net` via `put_net()`/`get_net()`. [F195, F196, F352]
- `ff_layout_mirror_prepare_stats()` increments `mirror->ref` and sets `layoutstat_ops` on `devinfo->ld_private` (requiring `opaque->data == &mirror->dss[dss_id]`), which must be freed via `ff_layout_free_iostats_array()`. [F202, F316]

## API Contracts
- `filelayout_initiate_commit()` and `ff_layout_initiate_commit()` own `data`: pre-RPC errors must call `pnfs_generic_prepare_to_resend_writes(data)` and `pnfs_generic_commit_release(data)`. In `filelayout_set_layoutcommit()` and `ff_layout_write_done_cb()`, pass `end_offs = 0` when `hdr->res.verf->committed == NFS_UNSTABLE`. [F204, F239]
- In `nfs4_fl_select_ds_fh()` and `select_ds_fh_from_commit()`, `STRIPE_SPARSE` with `num_fh == 0` returns `NULL` (keep MDS `args.fh`). Pass `fail_return = false` to `nfs4_ff_layout_prepare_ds()` on reads and `true` on writes/commits. Bracket `prepare_kernel_cred()` in `ff_layout_alloc_lseg()` with `memalloc_nofs_save/restore()` when `!(gfp_flags & __GFP_FS)`. [F237, F240, F356]
- `nfs_netfs_init_request()` must check `file` before `nfs_file_open_context(file)`, and `nfs_netfs_free_request()` must check `rreq->netfs_priv`. When fscache is enabled, `nfs_fscache_init_inode()` calls `mapping_set_release_always()` and `nfs_netfs_folio_unlock()` returns 0. In `nfs_fscache_release_folio()`, if `folio_test_private_2(folio)` is set, return `false` when `current_is_kswapd()` or `!(gfp & __GFP_FS)`, else `folio_wait_private_2(folio)`. [F233, F347, F348]
- `nfs_path()` builds backwards from `buffer + buflen_in` and sets `*p = end` before prepending `d_fsdata`; callers read from the returned pointer and free the original `buffer`. In `nfs_local_iters_init()`, enable `IOCB_DIRECT` only when `nfs_is_local_dio_possible()` and `nfs_iov_iter_aligned_bvec()` succeed; `nfs_local_call_read/write()` must use `override/revert_creds(filp->f_cred)` and writes must set `PF_LOCAL_THROTTLE | PF_MEMALLOC_NOIO`. [F310, F311, F340, F344]

## Error Handling
- In `nfs_net_init()`, failure of `nfs_fs_proc_net_init(net)` must unwind `rpc_proc_unregister(net, "nfs")` and `nfs_clients_exit(net)`. [F187]
- `nfs4_ff_layout_prepare_ds()` and `ff_layout_choose/get_*_ds_for_read()` return `ERR_PTR` (check `IS_ERR()`, and set `ds_fatal_error = nfs_error_is_fatal(PTR_ERR(ds))` in `ff_layout_read/write_pagelist()`), whereas `nfs4_fl_prepare_ds()` returns `NULL` (check `!ds`). `mirror_ds` can be `NULL`, `ERR_PTR(-ENODEV)`, or valid: use `IS_ERR_OR_NULL()` in general accessors, but in `ff_read/rw_layout_has_available_ds()` treat `NULL` as available and only reject `IS_ERR()`. [F225, F227, F228, F229, F288]
- In `nfs_local_pgio/commit_done()`, set `res.op_status = nfs_localio_errno_to_nfs4_stat(status)` and `task.tk_status = status`. In `ff_layout_async_handle_error_v3/v4()`, switch on `op_status` before `task->tk_status`. Check `IS_ERR()` on `nfs4_label_alloc()`, check `NFS_FH(inode)->size != 0` in `nfs_namespace_get/setattr()`, and check both `status < 0` and `result.errno != 0` in `nfs_mount()`. [F230, F235, F243, F244, F280]

## External Contracts
- In `nfs23_parse_monolithic()`, normalize v1–5 `nfs_mount_data` fields, zero-pad `mntfh->data`, NUL-terminate `data->context`, and in `case 3` set `NFS_MOUNT_SECFLAVOUR` in `extra_flags` (not `data->flags`). `nfs_fscache_update_auxdata()` must `memset` `auxdata` to 0. `NFS_SB_MASK` must exclude `SB_RDONLY`. [F274, F277, F287, F339]

## Known Pitfalls
- In `nfs_fhget()`, call `nfs_attr_check_mountpoint()` before `nfs_attr_use_mounted_on_fileid()` and test `NFS_ATTR_FATTR_V4_REFERRAL` before `NFS_ATTR_FATTR_MOUNTPOINT`. In `ff_lseg_match_mirrors()`, derive `fl1`/`fl2` from `l1`/`l2`; in `ff_layout_choose_ds_for_read()`, reset `ds = ERR_PTR(-EINVAL)` when `check_device` fails; in `ff_layout_send_layouterror()`, reset `n = 0` after `nfs42_proc_layouterror()`. [F281, F282, F286, F289]
- Guard flexfile `stripe_unit` divisions with `dss_count > 1` / `ff_layout_lseg_is_striped()`, use `div_u64`/`div_u64_rem`/`do_div` for 64-bit stripe offsets, and use `pnfs_calc_offset_end()` / `pnfs_end_offset()` for layout/error ranges. [F293, F294, F295]
- Avoid overflow/wraparound: cast `report_interval`/`layoutstats_timer` to `s64` before `* 1000LL` in `nfs4_ff_layoutstat_start_io()`; guard `fileid >> ...` with `sizeof(ino) < sizeof(fileid)` in `nfs_compat_user_ino64()`; compare `gencount` via signed `(long)(a - b) > 0` (and vs `nfs_read_attr_generation_counter()`) and `change_attr` via `s64 diff`; use `time_in_range_open()` for `attrtimeo`; cast `tv_sec` to `u64` before `<< 30`; widen `base`/`len` to `unsigned long` in `nfs_page_array_len()`; clamp timeouts against `INT_MAX` in `param_set/get_nfs_timeout()`; and clamp `end < start` to `LLONG_MAX` in `nfs_local_run_commit()`. [F296, F297, F298, F299, F300, F301, F303, F305, F306]
- Keep `buflen` as `ssize_t` checked `< 0` before decrementing `end` in `nfs_path()`; allocate `NFS_MAX_KEY_LEN + 24` in `nfs_fscache_get_super_cookie()`; bound `decode_name()`'s XDR buffer by `len`; and in `nfs_local_call_write()` zero `status` on partial write at `i == iocb->end_iter_index`. [F272, F317, F318, F341]
