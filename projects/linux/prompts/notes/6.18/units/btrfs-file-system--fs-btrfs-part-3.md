# BTRFS FILE SYSTEM — fs/btrfs (part 3)

Handles Btrfs disk I/O and filesystem mount/unmount lifecycle (open_ctree/close_ctree, superblock read/write/validation, tree block read/validation, and btree_aops), online device replacement (dev-replace), directory item and xattr B-tree helpers, direct I/O via iomap, asynchronous discard/TRIM management, NFS file handle export operations, and per-range state tracking in extent_io_tree.

## Architecture & Data Flow

- `struct extent_state` nodes with `EXTENT_LOCK_BITS` or `EXTENT_BOUNDARY` set must never be merged with adjacent nodes in `merge_state()` or `insert_state()`, and `btrfs_convert_extent_bit()` must not be used with those bits. [F208]
- In `struct extent_io_tree`, the union holds `tree->inode` only when `tree->owner == IO_TREE_INODE_IO` and `tree->fs_info` for all other `IO_TREE_*` owners, so code must check `tree->owner == IO_TREE_INODE_IO` or call `btrfs_extent_io_tree_to_fs_info()` / `btrfs_extent_io_tree_to_inode()` before accessing either member. [F220]
- `ENUM_BIT(EXTENT_NOWAIT)` must remain the last entry in the extent state bit enum because `set_gfp_mask_from_bits()` clears it via `*bits &= EXTENT_NOWAIT - 1`, which masks out `EXTENT_NOWAIT` and all higher bits. [F221]
- In `struct btrfs_dio_private`, `struct btrfs_bio bbio` must remain the final member of the struct because `btrfs_init_dio()` initializes `btrfs_dio_bioset` with `front_pad = offsetof(struct btrfs_dio_private, bbio.bio)` and `BIOSET_NEED_BVECS`. [F229]
- When `tree->owner == IO_TREE_INODE_IO`, `set_state_bits()`, `clear_state_bit()`, `split_state()`, `merge_prev_state()`, `merge_next_state()`, and `insert_state()` must call the corresponding `btrfs_*_delalloc_extent()` helper on `tree->inode` before modifying `state->state` or the extent's `start`/`end` bounds. [F239]
- `set_state_bits()` and `clear_state_bit()` must call `add_extent_changeset()` before modifying `state->state`, because `add_extent_changeset()` checks `state->state & bits` to skip ranges where the target bits are already set or cleared. [F240]
- In `set_state_bits()` and `clear_state_bit()`, control flags in `EXTENT_CTLBITS` must be passed in `bits` to `btrfs_set_delalloc_extent()` and `btrfs_clear_delalloc_extent()` but masked out (`bits & ~EXTENT_CTLBITS`) before updating `state->state` or `changeset`. [F242]
- `btrfs_clear_extent_bit_changeset()` must automatically include `EXTENT_NORESERVE` in `bits` whenever `EXTENT_DELALLOC` is being cleared (`if (bits & EXTENT_DELALLOC) bits |= EXTENT_NORESERVE`). [F243]
- `remove_from_discard_list()` must clear `discard_ctl->block_group = NULL` when `block_group == discard_ctl->block_group` and return `true` so `btrfs_discard_cancel_work()` cancels `discard_ctl->work` synchronously and reschedules work for the remaining lists. [F248]

## Synchronization

- btrfs_dio_iomap_begin always clears EXTENT_LOCKED before returning 0, but clears EXTENT_DIO_LOCKED on [lockstart, lockend] only for writes; for reads, EXTENT_DIO_LOCKED on [start, start + len - 1] transfers to btrfs_dio_end_io and btrfs_dio_iomap_end while any unused tail [start + len, lockend] is unlocked in btrfs_dio_iomap_begin. [F176]
- lock_extent_direct must acquire EXTENT_DIO_LOCKED before EXTENT_LOCKED on BTRFS_I(inode)->io_tree, unlock EXTENT_LOCKED via btrfs_unlock_extent before waiting on an ordered extent or breaking out of the retry loop on conflict, and unlock EXTENT_DIO_LOCKED via btrfs_unlock_dio_extent whenever returning a non-zero error. [F179]
- When set_extent_bit fails with -EEXIST on an exclusive bit (EXTENT_LOCK_BITS) at failed_start > start, btrfs_try_lock_extent_bits and btrfs_lock_extent_bits must roll back the partially locked prefix [start, failed_start - 1] via btrfs_clear_extent_bit before returning 0 or sleeping in wait_extent_bit. [F191]
- When `lock_extent_direct()` is called for a direct I/O read (`!(iomap_flags & IOMAP_WRITE)`) and finds an ordered extent without `BTRFS_ORDERED_DIRECT` set, it must unlock `EXTENT_LOCKED` and return `-ENOTBLK` (or `-EAGAIN` if `IOMAP_NOWAIT`) rather than calling `btrfs_start_ordered_extent()`. [F196]
- In `btrfs_dio_iomap_begin()`, data space allocation (`btrfs_check_data_free_space()`) for direct writes must be attempted before locking the file range with `lock_extent_direct()`. [F197]
- In `btrfs_get_blocks_direct_write()`, extending `inode->i_size` via `i_size_write()` must be performed while holding the extent lock (`EXTENT_LOCKED`) before `btrfs_dio_iomap_begin()` clears `EXTENT_LOCKED`. [F198]
- When `btrfs_direct_write()` takes `btrfs_inode_lock()` with `BTRFS_ILOCK_SHARED`, it must recheck under the lock that `IS_NOSEC(inode)` holds and (after `generic_write_checks()`) that `pos + iov_iter_count(from) <= i_size_read(inode)`, relocking exclusively if either fails. [F199]
- In `btrfs_direct_write()` and `btrfs_direct_read()`, `iov_iter` page faults must be disabled (`from->nofault = true` for writes; `pagefault_disable()` and `to->nofault = true` for reads) while invoking `btrfs_dio_write()` or `btrfs_dio_read()`, faulting in user pages outside the iomap call before retrying. [F200]
- In `btrfs_dev_replace_start()`, after setting `dev_replace->replace_state = BTRFS_IOCTL_DEV_REPLACE_STATE_STARTED` and releasing `dev_replace->rwsem`, `btrfs_wait_ordered_roots()` and a transaction commit (`btrfs_commit_transaction()`) must complete before calling `btrfs_scrub_dev()`. [F202]

## Object Lifetimes

- In btrfs_get_blocks_direct_write, when metadata reservation fails in the can_nocow branch or when entering the !can_nocow COW branch, the input extent_map (*map) must be freed via btrfs_free_extent_map and *map cleared to NULL because btrfs_dio_iomap_begin does not free em when btrfs_get_blocks_direct_write returns an error. [F175]
- When btrfs_check_data_free_space succeeds in btrfs_dio_iomap_begin, any error exit must call both btrfs_free_reserved_data_space and extent_changeset_free(dio_data->data_reserved), whereas on a 0 return extent_changeset_free(dio_data->data_reserved) is deferred to btrfs_dio_iomap_end. [F177]
- In btrfs_dio_submit_io, btrfs_extract_ordered_extent either increments dio_data->ordered->refs or splits off a new btrfs_ordered_extent for bbio->ordered, leaving dio_data->ordered to be finished (if submitted < length), released via btrfs_put_ordered_extent, and cleared to NULL in btrfs_dio_iomap_end. [F178]
- In btrfs_direct_write, from->nofault must be restored to false immediately after btrfs_dio_write, and current->journal_info must be set to BTRFS_TRANS_DIO_WRITE_STUB (after asserting it is NULL) only around iomap_dio_complete(dio) and cleared back to NULL before faulting in pages or unlocking the inode. [F180]
- In btrfs_get_root_ref (and btrfs_get_new_fs_root), if btrfs_lookup_fs_root finds a cached root, any non-zero *anon_dev must be freed via free_anon_bdev and zeroed; if initializing or inserting a newly read root fails, root->anon_dev must be reset to 0 before btrfs_put_root(root) so the caller does not double-free *anon_dev. [F182]
- btrfs_insert_fs_root grabs a root reference via btrfs_grab_root and sets BTRFS_ROOT_IN_RADIX under fs_info->fs_roots_radix_lock upon insertion, and btrfs_drop_and_free_fs_root must only call btrfs_put_root(root) for the radix reference when test_and_clear_bit(BTRFS_ROOT_IN_RADIX, &root->state) succeeds under fs_roots_radix_lock. [F183]
- In close_ctree, reclaim_bgs_work must be canceled before kthread_park(fs_info->cleaner_kthread), all workqueues and reclaim works that add delayed iputs must be flushed/canceled and btrfs_run_delayed_iputs drained before kthread_stop(fs_info->cleaner_kthread), and endio_meta_workers must be destroyed last in btrfs_stop_all_workers. [F185]
- In close_ctree, free_root_pointers and btrfs_free_fs_roots must be called before btrfs_free_block_groups so that any leftover tree-log extent buffers from an I/O error are freed before block group accounting is verified and torn down. [F186]
- A btrfs_block_group holds one ref while on any discard_ctl->discard_list (taken when list_empty(&block_group->discard_list) before insertion and dropped on removal), plus a working ref taken in peek_discard_list for discard_ctl->block_group that btrfs_discard_workfn must drop and clear to NULL under discard_ctl->lock on every exit. [F187]

## API Contracts

- btrfs_global_root, btrfs_extent_root, and btrfs_csum_root return borrowed struct btrfs_root pointers without incrementing root->refs, whereas btrfs_get_global_root, btrfs_lookup_fs_root, btrfs_get_fs_root, and btrfs_get_fs_root_commit_root return a refcounted root that the caller must release with btrfs_put_root. [F184]
- `btrfs_lookup_dir_item()`, `btrfs_lookup_dir_index_item()`, and `btrfs_lookup_xattr()` return `NULL` when an entry is not found and `ERR_PTR` on other errors, whereas `btrfs_search_dir_index_item()` never returns `NULL` and returns `ERR_PTR(-ENOENT)` when not found. [F222]
- In `btrfs_lookup_dir_item()`, `btrfs_lookup_dir_index_item()`, and `btrfs_lookup_xattr()`, `@mod` must be `0` for read-only lookups (`ins_len = 0, cow = 0`, where `@trans` may be `NULL`), `1` for in-place modification lookups (`ins_len = 0, cow = 1`), and `-1` for deletion lookups (`ins_len = -1, cow = 1`). [F223]
- `btrfs_create_dio_extent()` returns `NULL` on success when `type == BTRFS_ORDERED_NOCOW` and `ERR_PTR` on failure, so `btrfs_get_blocks_direct_write()` must check `IS_ERR(em2)` (not `IS_ERR_OR_NULL(em2)`) and only replace `*map` with `em2` when `type == BTRFS_ORDERED_PREALLOC`. [F224]
- When direct read prerequisites are not met in `btrfs_direct_read()` (such as `fsverity_active(inode)` being true or `check_direct_read()` returning a negative error), `btrfs_direct_read()` must return `0` rather than a negative errno so `btrfs_file_read_iter()` falls back to buffered read. [F227]
- In `fs/btrfs/disk-io.c`, `btrfs_lookup_fs_root()`, `btrfs_get_global_root()`, `btrfs_global_root()`, `btrfs_csum_root()`, and `btrfs_extent_root()` return `NULL` when not found, whereas `btrfs_get_fs_root()`, `btrfs_get_new_fs_root()`, `btrfs_get_fs_root_commit_root()`, `btrfs_read_tree_root()`, and `btrfs_create_tree()` return `ERR_PTR`. [F230]
- `btrfs_dev_replace_by_ioctl()` must store the return value of `btrfs_dev_replace_start()` into `args->result` and translate `BTRFS_IOCTL_DEV_REPLACE_RESULT_SCRUB_INPROGRESS` (as well as `BTRFS_IOCTL_DEV_REPLACE_RESULT_NO_ERROR`) into a `0` return value. [F234]
- Callers of `btrfs_get_range_bits()` must pass a non-NULL `cached_state` pointer whose pointee `*cached_state` is initialized to `NULL`, because the function asserts `ASSERT(cached_state != NULL)` and `ASSERT(*cached_state == NULL)` and overwrites `*cached_state` without releasing any prior state. [F235]
- `btrfs_find_first_clear_extent_bit()` sets `*end_ret = -1` (`U64_MAX`) when the unset range extends past the last state entry in `tree` (or when `tree` is empty) and can set `*start_ret < start` when `start` falls inside an earlier unset range, so callers must clamp `*start_ret` and `*end_ret` to their target bounds. [F236]

## Error Handling

- In `load_global_roots_objectid()`, if `read_tree_root_path()` returns an error pointer (`IS_ERR(root)`), `ret` must be unconditionally set to `PTR_ERR(root)` before breaking out of the loop, even when `BTRFS_MOUNT_IGNOREBADROOTS` is enabled. [F217]
- In `btrfs_validate_super()`, `ret` must be checked (`if (ret) return ret;`) before calling `validate_sys_chunk_array(fs_info, sb)` and assigning its return value to `ret`, because preceding checks accumulate `-EINVAL` into `ret` without returning early. [F218]
- When a fallible call assigned directly to `root->node` (such as `read_tree_block()` in `read_tree_root_path()`, `load_super_root()`, or `btrfs_replay_log()`) or `fs_info->fs_root` (in `open_ctree()`) returns `IS_ERR()`, the field must be reset to `NULL` after extracting `PTR_ERR()` and before jumping to cleanup. [F219]
- In `btrfs_dio_iomap_begin()`, `dio_data` (`iter->private`) must be zeroed with `memset(dio_data, 0, sizeof(*dio_data))` before any code path that can jump to `err:` or `unlock_err:`, and any failure prior to that `memset` must return directly rather than jumping to `err:`. [F226]
- In `btrfs_cleanup_fs_roots()`, once `btrfs_grab_root()` has acquired references on `gang[0..found-1]`, the inner loop must iterate across all `found` entries to call `btrfs_put_root(gang[i])`, invoking `btrfs_orphan_cleanup(gang[i])` only while `!ret` so the first error is preserved. [F232]
- `backup_super_roots()` must zero the target `struct btrfs_root_backup` slot in `info->super_for_commit->super_roots` with `memset(root_backup, 0, sizeof(*root_backup))` before filling its fields and must copy the updated `super_roots` array back to `info->super_copy->super_roots`. [F233]

## External Contracts

- `btrfs_check_super_csum()` and `write_dev_supers()` must compute the superblock checksum over `[BTRFS_CSUM_SIZE, BTRFS_SUPER_INFO_SIZE)` (4096 bytes total), and any bytes in `fs_info->super_copy` and `fs_info->super_for_commit` beyond `sizeof(struct btrfs_super_block)` up to `BTRFS_SUPER_INFO_SIZE` must remain zeroed. [F274]
- In btrfs_get_name(), after copying name_len bytes from the on-disk btrfs_root_ref or btrfs_inode_ref item into name via read_extent_buffer(), name[name_len] must be explicitly set to '\0' so that VFS exportfs callers such as reconnect_path() can safely pass name to strlen(). [F300]
- In btrfs_dev_replace_by_ioctl(), btrfs_check_replace_dev_names() must verify that args->start.tgtdev_name (and args->start.srcdev_name when srcdevid == 0) contains a NUL byte within its fixed array bounds via memchr(), or force args->start.srcdev_name[0] = 0 when srcdevid != 0, before passing the paths to kernel lookup helpers. [F337]

## Known Pitfalls

- In `btrfs_direct_write()` and `btrfs_direct_read()`, `iomap_dio_complete()` and `btrfs_dio_read()` return a cumulative byte count that already includes the `done_before` argument (`written` or `read`), so a positive `ret` must be assigned (`written = ret` / `read = ret`) rather than added with `+=`. [F228]
- When searching for the highest key offset via `key.offset = (u64)-1` in `btrfs_get_parent()` and `btrfs_init_root_free_objectid()`, an exact match (`ret == 0`) must be rejected with `-EUCLEAN` and `path->slots[0]` must be checked for `> 0` before decrementing `path->slots[0]`. [F262]
- In `peek_discard_list()`, when an eligible block group on `BTRFS_DISCARD_INDEX_UNUSED` has `block_group->used != 0`, it must be moved to another list via `__add_to_discard_list()` (or unlinked with `list_del_init()` if not data-only) regardless of `btrfs_run_discard_work()` before jumping to `again`. [F277]
- In `btrfs_clear_extent_bit_changeset()`, `set_extent_bit()`, and `btrfs_convert_extent_bit()`, `state->end` must be saved into `last_end` at `hit_next` before calling `clear_state_bit()` or `merge_state()`, and loop progress must check `last_end >= end` and advance `start = last_end + 1` rather than reading `state->end`. [F279]
- In `btrfs_direct_write()` and `btrfs_direct_read()`, when retrying after `-EFAULT` or a partial transfer (`iov_iter_count() > 0`), the loop must compare `left = iov_iter_count()` against `prev_left` and stop retrying if `left == prev_left`. [F283]
- In `btrfs_read_extent_buffer()`, when the initial read with `mirror_num == 0` fails and `num_copies > 1`, `failed_mirror` must be latched once from `eb->read_mirror` (when `!failed_mirror`), and the retry loop over `mirror_num` (`1` to `num_copies`) must increment `mirror_num` a second time when `mirror_num == failed_mirror`. [F288]
- In btrfs_sb_offset(), the base offset SZ_16K must be widened to u64 before shifting left by `BTRFS_SUPER_MIRROR_SHIFT * mirror`, and `mirror` must be non-negative (or guarded by `mirror_num >= 0` as in btrfs_validate_super()), because mirror >= 2 shifts by at least 24 bits (reaching 256 GiB, overflowing 32-bit int). [F290]
- In __btrfs_discard_schedule_work(), `kbps_limit` (a u32 snapshot of `discard_ctl->kbps_limit` read via READ_ONCE) must be widened to u64 before multiplying by SZ_1K, and `bps_delay` must be computed with div64_u64() only after checking that the snapshot `kbps_limit` is non-zero. [F291]
