# GPIO SUBSYSTEM — drivers/gpio (part 3)

This component comprises GPIO controller drivers from `gpio-sim.c` to `gpio-xgs-iproc.c`, including `gpio-sim.c`, `gpio-virtuser.c`, NVIDIA Tegra (`gpio-tegra.c`, `gpio-tegra186.c`), Super I/O (`gpio-winbond.c`), USB bridges (`gpio-viperboard.c`), and PMIC/MFD expanders (TPS65xxx, TWL4030/6040, WM8xxx, STMPE, TC3589x).

## Architecture & Data Flow
- In `gpio-sim.c`, `gpio_sim_free()` must restore `chip->value_map` from `chip->pull_map` when clearing `chip->request_map` under `chip->lock`, and `gpio_sim_apply_pull()` must only update `chip->value_map` at `set_value:` when unrequested or input (`!test_bit(offset, chip->request_map) || test_bit(offset, chip->direction_map)`), while always updating `chip->pull_map` at `set_pull:`. [F234, F270]
- In `gpio-sim.c`, `gpio_sim_get_line_names_size()`, `gpio_sim_set_line_names()`, and `gpio_sim_add_hogs()` must skip `line->offset >= bank->num_lines`; when `!gpio_sim_bank_has_label(bank)`, `gpio_sim_add_hogs()` and `gpio_sim_add_bank()` must format default labels identically as `"gpio-sim.%u:%pfwP"`. In `gpio_sim_make_bank_swnode()`, `properties[GPIO_SIM_PROP_MAX]` (5) takes at most 4 entries to keep the sentinel, and `"gpio-reserved-ranges"` needs `size += 2` per invalid line in `gpio_sim_get_reserved_ranges_size()` to match `gpio_sim_set_reserved_ranges()`. [F235, F254, F256, F290]
- In `gpio_sim_add_bank()`, allocate `request_map`, `direction_map`, `value_map`, and `pull_map` via `devm_bitmap_alloc()`/`zalloc()` for `num_lines` bits so `bitmap_replace()` has `unsigned long`-aligned words. In `gpio_sim_setup_sysfs()`, `chip->attr_groups` needs `num_lines + 1` elements and each per-line `attrs` array `GPIO_SIM_NUM_ATTRS` (3) elements for `NULL` termination. [F289, F298]
- In `gpio-virtuser.c`, `gpio_virtuser_make_lookup_table()` must allocate `num_entries + 1` elements via `kzalloc(struct_size(table, table, num_entries + 1), ...)` for the sentinel and reset `con_id`-relative `idx` in `GPIO_LOOKUP_IDX()` to `0` on each outer `dev->lookup_list` iteration while flat `i` increments across `lookup->entry_list`. `gpio_virtuser_make_lookup_group()` must reject `strlen(name) > GPIO_VIRTUSER_NAME_BUF_LEN - 1`, and `gpio_virtuser_lookup_entry_config_drive_store()`/`pull_store()` must clear the other group flags (`GPIO_OPEN_DRAIN | GPIO_OPEN_SOURCE` or `GPIO_PULL_UP | GPIO_PULL_DOWN | GPIO_PULL_DISABLE`) before setting `entry->flags`. [F250, F252, F266, F271]
- In `gpio-virtuser.c`, `gpio_virtuser_direction_do_write()` and `gpio_virtuser_consumer_write()` must pass `available < sizeof(buf)` to `simple_write_to_buffer()` before `buf[ret] = '\0'`; `gpio_virtuser_value_array_do_read()` must allocate `>= descs->ndescs + 1` bytes (`bufsize = descs->ndescs + 2`) for `gpio_virtuser_dbgfs_emit_value_array()`; and `gpio_virtuser_get_ids()` must allocate `diff + 1` bytes via `devm_kmemdup()` and set `tmp[diff] = '\0'`. [F295, F296, F297]
- In `gpio-tegra186.c`, DT specifiers, `tegra186_pin_range::offset`, and parent IRQ offsets use a stride of 8 (`port * 8 + pin`), whereas `gpio_chip` and child `irq_domain` hwirqs sum `gpio->soc->ports[i].pins` (so `tegra186_gpio_irq()` must advance `offset += port->pins` at `skip:` on every iteration). MMIO offsets in `gpio->base`/`secure` must use `port->bank` and `port->port` (never the `soc->ports` index), and `tegra186_gpio_probe()` must compute `gpio->num_banks = 1 + max(port->bank)` before `tegra186_gpio_irqs_per_bank()` checks `num_banks >= 1` and `num_irq % num_banks == 0`. [F257, F258, F272, F281]
- In `gpio-tegra186.c`, `tegra186_gpio_is_accessible()` must check `TEGRA186_GPIO_SCR` read (`!SEC_REN || SEC_G1R`) and write (`!SEC_WEN || SEC_G1W`) access as independent clauses after `TEGRA186_GPIO_VM_RW_MASK`, and `tegra186_gpio_init_route_mapping()` must only write `TEGRA186_GPIO_INT_ROUTE_MAPPING(p, 0)` when `TEGRA186_GPIO_CTL_SCR` has both `SEC_REN` and `SEC_WEN` cleared. [F265, F309]
- In `gpio-tegra.c`, `tegra_gpio_irq_handler()` must guard both the early in-loop `chained_irq_exit(chip, desc)` (for edge pins `lvl & (0x100 << pin)`) and the post-loop `chained_irq_exit()` with `!unmasked`. In `tegra_gpio_suspend()`, save `GPIO_MSK_DBC_EN` as `(dbc_enb << 8) | dbc_enb` and replace `GPIO_INT_ENB` with `bank->wake_enb[p]`. [F273, F321]
- In `gpio-stmpe.c` and `gpio-tc3589x.c`, atomic IRQ callbacks (`*_irq_set_type`, `*_irq_mask`, `*_irq_unmask`) must only update `regs[][]`, while `*_irq_sync_unlock()` writes changed bytes and updates `oldregs[i][j] = new` under `irq_lock`. In `tc3589x_gpio_irq_mask()`/`unmask()`, toggle `regs[REG_IE]` and `regs[REG_DIRECT]` inversely; in `tc3589x_gpio_irq_set_type()`, return early on `IRQ_TYPE_EDGE_BOTH` after setting `REG_IBE`; and in `tc3589x_gpio_probe()`, write `TC3589x_DKBDMSK_ELINT | TC3589x_DKBDMSK_EINT` to `TC3589x_DKBDMSK` before `devm_request_threaded_irq()`. [F241, F242, F277, F304]
- In `gpio-stmpe.c`, skip `REG_RE`/`REG_FE` on `STMPE801`/`STMPE1600`, read `STMPE_IDX_GPMR_LSB`/`CSB` in `stmpe_gpio_irq_sync_unlock()` on `STMPE1600`, and do not write status/`GPEDR` in `stmpe_gpio_irq()` on `STMPE801`/`STMPE1600`/`STMPE1801`. In `stmpe_gpio_irq()`, `STMPE1600` uses `STMPE_IDX_ISGPIOR_LSB` with `bank = i`, while all other variants use `STMPE_IDX_ISGPIOR_MSB` with `bank = num_banks - i - 1`. [F275, F310]
- In `spacemit_gpio_irq_set_type()`, keep `gb->irq_rising_edge` and `gb->irq_falling_edge` synced with hardware so `spacemit_gpio_irq_mask()`/`unmask()` can clear (`SPACEMIT_GCRER`/`GCFER`) and restore (`SPACEMIT_GSRER`/`GSFER`) edge detection alongside `gb->irq_mask`. In IRQ handlers scanning 32-bit status registers with `for_each_set_bit()` (`tegra_gpio_irq_handler()`, `spacemit_gpio_irq_handler()`), store the register in an `unsigned long`, never a cast `u32 *`. [F243, F300]
- In `gpio-syscon.c`, `priv->dreg_offset` and `priv->dir_reg_offset` are in bits (`<< 3`), so compute byte offsets as `(offs / SYSCON_REG_BITS) * SYSCON_REG_SIZE` and bit indices as `offs % SYSCON_REG_BITS`. In `gpio-xgene-sb.c`, hwirqs (`0 .. priv->nirq - 1`) are offset from `gpio_chip` pins by `priv->irq_start` (`HWIRQ_TO_GPIO`/`GPIO_TO_HWIRQ`), with `MPA_GPIO_SEL_LO` indexed by `gpio * 2` and `MPA_GPIO_INT_LVL` by `d->hwirq`. [F262, F263]
- In `gpio-vx855.c`, partition `nr` into `< NR_VX855_GPI`, `< NR_VX855_GPInO` (subtract `NR_VX855_GPI`), and `>= NR_VX855_GPInO` (subtract `NR_VX855_GPInO`). In `timbgpio_irq_type()`, check `TGPIO_VER` before accessing `TGPIO_BFLR` (`ver > 2`) or accepting `IRQ_TYPE_EDGE_BOTH` (`-EINVAL` if `ver < 3`). In `ts4900_gpio_direction_output()`, write `TS4900_GPIO_OUT` before `TS4900_GPIO_OE` when switching from input, and clear only `TS4900_GPIO_OE` in `ts4900_gpio_direction_input()`; in `wm831x_gpio_direction_out()`/`wm8350_gpio_direction_out()`, set output mode before `wm831x_gpio_set()`/`wm8350_gpio_set()`. [F278, F311, F317, F318]

## Synchronization
- In `gpio-sim.c`, hold `chip->lock` across all reads and non-atomic bit updates (`__set_bit`, `__clear_bit`, `__assign_bit`, `bitmap_replace`) of `request_map`, `direction_map`, `value_map`, and `pull_map`. [F200]
- In `gpio-virtuser.c`, initialize `gpio_virtuser_line_data.consumer_lock` before `gpio_virtuser_create_debugfs_attrs()` and hold it across `data->consumer` accesses in `gpio_virtuser_consumer_read()`/`write()`. `IRQ_WORK_INIT_HARD` callbacks (`gpio_virtuser_*_atomic`) run in hardirq context, so `GFP_KERNEL` allocations, user copies, and `_cansleep` calls must stay in the caller. [F207, F323]
- In `gpio-twl4030.c`, `priv->mutex` protects `usage_count`, `direction`, `out_state`, and `cached_leden`, and `twl_direction_out()` must unlock `priv->mutex` before `twl_set()`. In `gpio-timberdale.c`, `timbgpio_irq_enable()`/`disable()` must update `tgpio->last_ier` under `tgpio->lock` when writing `TGPIO_IER` because `timbgpio_irq()` restores `TGPIO_IER` from `tgpio->last_ier`. [F214, F216]
- In `gpio-viperboard.c`, all accesses to the shared DMA buffer `vb->buf` (`gamsg`/`gbmsg`) and `usb_control_msg()` calls across `gpioa`/`gpiob` must hold `vb->lock`; `vprbrd_gpiob_direction_output()` must unlock `vb->lock` after `vprbrd_gpiob_setdir()` before `vprbrd_gpiob_set()`; and every GPIO A transfer on `vb->buf` must initialize all 11 fields of `struct vprbrd_gpioa_msg` (including `gamsg->__fill = 0x00`). [F224, F327]
- In `gpio-winbond.c`, every Super I/O register sequence must start with `winbond_sio_enter(base)` (`request_muxed_region()` + `WB_SIO_EXT_ENTER_KEY` twice) and end with `winbond_sio_leave(base)` on all paths. In MMIO/I/O-port drivers sharing registers without atomic set/clear ports (`sprd_gpio_update()`, `xgene_gpio_dir_out()`, `__xgene_gpio_set()` under `chip->lock`, and `gpio-vf610.c`), RMW sequences must hold an IRQ-saving spinlock; in `gpio-tegra.c`, `tegra_gpio_irq_set_type()` must use `raw_spin_lock_irqsave(&bank->lvl_lock[port], flags)` for `GPIO_INT_LVL`, whereas `tegra_gpio_set_debounce()` uses `spin_lock_irqsave(&bank->dbc_lock[port], flags)`. [F315, F319, F325, F331]

## Object Lifetimes
- In `gpio_sim_add_bank()`, register `devm_add_action_or_reset(dev, gpio_sim_dispose_mappings, chip)` after `devm_irq_domain_create_sim_full()` and before `devm_gpiochip_add_data()`; hand `chip->dev` from `device_find_child()` to `devm_add_action_or_reset(dev, gpio_sim_put_device, chip->dev)` and call `dev_set_drvdata(chip->dev, chip)` before `gpio_sim_setup_sysfs(chip)`. [F184, F185, F201]
- In `gpio-sim.c`, `gpio_sim_device_deactivate()` and `gpio_sim_device_activate()` error paths must read `swnode` from `dev->probe_data.pdev` before `dev_sync_probe_unregister(&dev->probe_data)`, then call `gpio_sim_remove_hogs(dev)`, then `gpio_sim_remove_swnode_recursive(swnode)`. `gpio_sim_add_hogs()` must allocate `num_hogs + 1` `struct gpiod_hog` entries and `kstrdup()` `chip_label`/`line_name`, and `gpio_sim_remove_hogs()` must call `gpiod_remove_hogs()` before freeing them. [F187, F337]
- In `gpio-sim.c`, `gpio_sim_device_lockup_configfs()` must pass `&line->hog->item` (if `line->hog`) or `&line->group.cg_item` to `configfs_depend_item_unlocked()`/`undepend_item_unlocked()`, and `gpio_sim_device_config_live_store()` must undepend when `live == !!ret`. Configfs `.release` callbacks must use the explicit `parent` field (not `item->ci_parent`) and unlink under `&dev->lock` before freeing. [F188, F189]
- In `gpio-virtuser.c`, `gpio_virtuser_device_activate()` must call `gpio_virtuser_make_device_swnode()` and `gpio_virtuser_make_lookup_table()` before `dev_sync_probe_register()`, and `gpio_virtuser_device_deactivate()` (and activate failure) must unregister `probe_data` before `gpio_virtuser_remove_lookup_table()` (which unregisters `dev->lookup_table`, frees `dev_id` and `lookup_table`, and NULLs it) and swnode removal. Callers of `gpio_virtuser_irq_work_queue_sync()` with a stack `gpio_virtuser_irq_work_context` must wait on `ctx->work_completion`, and the callback must not touch `ctx` after `complete()`. [F190, F208, F293]
- In `tb10x_gpio_probe()`/`remove()`, when `tb10x_gpio->chip.gc.to_irq` is set, release `tb10x_gpio->domain` via `irq_remove_generic_chip()`, `kfree(tb10x_gpio->domain->gc)`, and `irq_domain_remove()`. In `xgene_gpio_sb_remove()`, call `acpi_gpiochip_free_interrupts(&priv->chip.gc)` before `irq_domain_remove(priv->irq_domain)`, and in `xgene_gpio_sb_probe()`, remove `priv->irq_domain` if `devm_gpiochip_add_data()` fails. [F198, F199]
- In `tegra_gpio_probe()`, `tegra186_gpio_add_pin_ranges()`, and `tegra186_gpio_probe()`, release every `device_node *` from `of_find_matching_node()`/`of_find_compatible_node()` with `of_node_put(np)` on all paths (including `-EPROBE_DEFER`). In `vf610_gpio_probe()`, `clk_port` and `clk_gpio` are optional on `devm_clk_get()` errors except `-EPROBE_DEFER`, and each acquired clock must be enabled with `clk_prepare_enable()` and paired with `devm_add_action_or_reset(dev, vf610_gpio_disable_clk, ...)`. [F314, F320]

## API Contracts
- In `gpio-tegra186.c`, `tegra186_gpio_get_port()` mutates `*pin` in-place to a port-relative index and returns `NULL` if out of range, so callers of `tegra186_gpio_get_base()` must check for `NULL`. In `gpio-tegra.c` and `gpio-tegra186.c`, `PIN_CONFIG_INPUT_DEBOUNCE` (in usec) must be converted via `DIV_ROUND_UP(..., 1000)` and capped at 255 ms. [F225, F226]
- In `gpio-winbond.c`, `gpio_chip` offsets pack only enabled ports in `params.gpios` at 8 pins/port (5 for GPIO6 at `BIT(5)`). Callers of `winbond_sio_reg_bset()`, `bclear()`, and `btest()` must first pass `&offset` to `winbond_gpio_get_info()`, which translates `*gpio_num` in-place to a bit index (0..7) and returns `false` if modification is forbidden (mutating callbacks must return `-EACCES`). `winbond_gpio_imatch()` must return `winbond_gpio_check_chip(...) == 0`. [F227, F228, F260, F284]
- In `gpio-twl4030.c`, offsets `>= TWL4030_GPIO_MAX` are output-only LEDs in `TWL4030_MODULE_LED`, so callbacks must branch on `offset < TWL4030_GPIO_MAX` before `TWL4030_MODULE_GPIO` helpers and subtract `TWL4030_GPIO_MAX` for LED helpers. In `gpio-tps68470.c`, offsets `>= TPS68470_N_REGULAR_GPIO` are output-only sensor GPOs in `TPS68470_REG_SGPO` with no `TPS68470_GPIO_CTL_REG_A(offset)` register, so callbacks must guard `TPS68470_GPIO_CTL_REG_A` and subtract `TPS68470_N_REGULAR_GPIO` for `TPS68470_REG_SGPO`. [F229, F230]
- In `gpio-xgene-sb.c` (and other `struct gpio_generic_chip` drivers), use `gpio_generic_read_reg()`/`write_reg()` on `&priv->chip` rather than `gc->read_reg()`/`write_reg()`. In `gpio-xgs-iproc.c`, `iproc_gpio_irq_handler()` and `iproc_gpio_irq_chip` callbacks downcast `struct gpio_chip *` via `to_iproc_gpio()`, so `devm_request_irq()` in `iproc_gpio_probe()` must pass `&chip->gen_gc.gc` as `dev_id`. [F245, F299]
- In `gpio_virtuser_debounce_set()`, reject `val > UINT_MAX` with `-E2BIG` before casting to `unsigned int`, and translate `-ENOTSUPP` from `gpiod_set_debounce()` to `-EOPNOTSUPP`. In `gpio-wcd934x.c` and `gpio-winbond.c`, `can_sleep` must be `true`. [F218, F283, F328]

## Error Handling
- In `stmpe_gpio_irq_sync_unlock()`, store every `stmpe_reg_read()` result in a signed `int` and jump to `err:` if `< 0` so `stmpe_gpio->irq_lock` is unlocked. In `tegra_gpio_irq_set_wake()`, if `irq_chip_set_wake_parent(d, enable)` fails after `irq_set_irq_wake(tgi->irqs[bank->bank], enable)`, roll back with `irq_set_irq_wake(..., !enable)` without updating `bank->wake_enb[port]`. In `tegra186_gpio_probe()`, query `"security"` and `"gpio"` with `platform_get_resource_byname()` and fall back to indexed `platform_get_resource()` before `devm_ioremap_resource()`. [F217, F322, F334]

## External Contracts
- In `gpio-sim.c`, check `num_lines > GPIO_SIM_NGPIO_MAX` in `gpio_sim_add_bank()` during probe rather than in `gpio_sim_bank_config_num_lines_store()`, and in `gpio_sim_setup_sysfs()`, set `value`'s `.store = gpio_sim_sysfs_val_store` (`-EPERM`) rather than `NULL`. [F253, F339]
- In `gpio-virtuser.c`, `gpio_virtuser_value_array_do_write()` must check `count - 1 == descs->ndescs` before allocating `values` and parsing `count - 1` chars, and `gpio_virtuser_lookup_entry_config_offset_store()` must reject `offset > (U16_MAX - 1)` because negative `entry->offset` maps to `U16_MAX` in `chip_hwnum`. In `gpio-viperboard.c`, `vprbrd_gpiob_msg` `val`/`mask` must use `cpu_to_be16()`/`be16_to_cpu()`, and modular drivers must terminate match tables with `{}` and `MODULE_DEVICE_TABLE`. [F251, F259, F282, F313]

## Known Pitfalls
- In `gpio-virtuser.c`, `struct gpio_virtuser_attr_data ad` must stay at offset 0 of `gpio_virtuser_line_array_data` and `gpio_virtuser_line_data`, and `gpio_virtuser_value_array_do_read()`/`write()` must only access `data->ad`; compare `strcmp()` against `trimmed = strim(buf)` in `gpio_virtuser_direction_do_write()`; and use `strscpy()` (not `sprintf()`) for `data->consumer`. In `stmpe_gpio_irq_sync_unlock()` and `stmpe_gpio_irq()`, compute `num_banks` with `DIV_ROUND_UP(stmpe->num_gpios, 8)`. [F267, F285, F292, F294]
