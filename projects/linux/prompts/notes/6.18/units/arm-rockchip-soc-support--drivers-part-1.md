# ARM/Rockchip SoC support — drivers (part 1)

Core Rockchip SoC infrastructure drivers: Clock and Reset Units (CRU) for RK3528, RK3562, RK3568, RK3576, RK3588, RV1108, and RV1126, the Rockchip hardware clocksource/clockevent timer, the DDR Frequency Interface (DFI) devfreq-event and perf PMU monitor, and the GPIO/IRQ bank controller.

## Architecture & Data Flow

- `rockchip_clk_init_base()` fills `ctx->clk_data.clks` with `ERR_PTR(-EPROBE_DEFER)` (`rockchip_clk_init_early()`) or `ERR_PTR(-ENOENT)` (`rockchip_clk_init()` / `rockchip_clk_finalize()`), so `rockchip_clk_get_lookup()` returns an `ERR_PTR` (never `NULL`) for unregistered IDs. Also, `rockchip_clk_register_branches()` writes `ctx->clk_data.clks[list->id] = clk` via `rockchip_clk_set_lookup()` even when `list->id == 0`, so ID `0` is overwritten by every unexported clock and must never be used as a DT clock ID or `linked_clk_id`. [F27, F59]
- In `rockchip_clk_register_branches()`, reset `clk = NULL` and `flags = list->flags` at the top of each loop iteration so unhandled types hit `if (!clk)` and `CLK_SET_RATE_PARENT` from gate cases does not leak across iterations. For `branch_fraction_divider` clocks with a `child` mux (`COMPOSITE_FRACMUX` / `COMPOSITE_FRACMUX_NOGATE`), `child->branch_type` must be `branch_mux` and `child->parent_names` must contain the exact fractional divider `name` so `match_string()` wires up `rockchip_clk_frac_notifier_cb()`. [F53, F71]
- Every `struct rockchip_pll_rate_table` (`rk3568_pll_rates`, `rk3576_pll_rates`, `rk3588_pll_rates`, `rv1108_pll_rates`, `rv1126_pll_rates`) must be sorted in descending `rate` order, end with a zeroed `{ /* sentinel */ }` (`.rate = 0`), and have `RK3036_PLL_RATE` / `RK3588_PLL_RATE` dividers that arithmetically produce `.rate` from the 24 MHz oscillator. [F55, F60]
- When `ROCKCHIP_SOFTRST_HIWORD_MASK` is set, `rockchip_softrst_assert()` and `rockchip_softrst_deassert()` compute register byte offsets as `(id / 16) * 4`, so LUT macros (`rk3562_register_offset`, `rk3576_register_offset`, `rk3588_register_offset`) must scale any 4-byte-aligned sub-CRU byte offset `B` by `4` (`B * 4 + reg * 16 + bit`) with `bit < 16`. [F63]
- In `timer-rockchip.c`, call `rk_timer_disable(timer)` before `rk_timer_update_counter()` writes `TIMER_LOAD_COUNT0`/`1` in `rk_timer_set_next_event()` or `rk_timer_set_periodic()`, followed by `rk_timer_enable()`. In `rk_timer_sched_read()`, bitwise-negate the 32-bit down-counting `TIMER_CURRENT_VALUE0` as `u32` (`~readl_relaxed(...)`) before widening to `u64`. [F56, F90]
- In `struct rockchip_dfi`, `dfi->clk` must be a valid `struct clk *` (RK3399) or `NULL` (RK3568/RK3588), never an `ERR_PTR`, as `rockchip_dfi_enable()` / `rockchip_dfi_disable()` pass it directly to `clk_prepare_enable()` / `clk_disable_unprepare()`. In `rk3568_dfi_init()` and `rk3588_dfi_init()`, only OR `DRAMTYPE_INFO_V3 << 3` from `PMUGRF_OS_REG3` into `dfi->ddr_type` when `FIELD_GET(..._SYSREG_VERSION, reg3) >= 0x3`. Every `dfi->ddr_type` accepted by `rockchip_dfi_ddrtype_to_ctrl()` must also be handled in `rockchip_ddr_perf_init()` to set `dfi->burst_len`. [F35, F78, F107]
- In `struct rockchip_dfi`, `dfi->max_channels` must be `<= DMC_MAX_CHANNELS` (`4`), and per-channel MMIO loops must skip disabled channels (`!(dfi->channel_mask & BIT(i))`). `rockchip_dfi_enable()` and `rockchip_dfi_disable()` must `break` after the first enabled channel when `dfi->ddrmon_ctrl_single` is true, whereas `rockchip_dfi_read_counters()` must iterate all enabled channels. In `rockchip_ddr_perf_counters_add()` and `rockchip_dfi_get_event()`, cast `u64` `struct dmc_count_channel` deltas (`now - last`) to `u32` before widening/comparing to handle 32-bit MMIO counter wrap. [F65, F77, F84]
- `rockchip_ddr_perf_event_update()` rejects `event->attr.config >= PERF_ACCESS_TYPE_MAX`, so all `PERF_EVENT_*` in `rockchip_ddr_perf_event_get_count()` must be `< PERF_ACCESS_TYPE_MAX`. On `dfi->active_events` `0 -> 1` in `rockchip_ddr_perf_event_add()`, zero `dfi->total_count` and sample `dfi->last_perf_count` before starting `dfi->timer` and calling `rockchip_ddr_perf_event_start()`; cancel `dfi->timer` when `active_events` hits `0` in `rockchip_ddr_perf_event_del()`. In `ddr_perf_offline_cpu()`, update `dfi->cpu = target` with `perf_pmu_migrate_context(&dfi->pmu, cpu, target)`. [F48, F50, F64]
- In `rockchip_get_bank_data()`, all v2 version IDs (`GPIO_TYPE_V2`, `GPIO_TYPE_V2_1`, `GPIO_TYPE_V2_2`) must normalize `bank->gpio_type` to `GPIO_TYPE_V2` because all v2 paths test `bank->gpio_type == GPIO_TYPE_V2`. In `rockchip_interrupts_register()`, mask all 32 lines in `int_mask`, clear `port_eoi`, enable `int_en`, and set `gc->mask_cache = 0xffffffff` before `irq_set_chained_handler_and_data()` installs `rockchip_irq_demux()`. [F80, F100]
- In `rockchip_irq_set_type()`, changing trigger type off `IRQ_TYPE_EDGE_BOTH` must clear `BIT(d->hwirq)` in `int_bothedge` on `GPIO_TYPE_V2` and in `bank->toggle_edge_mode` on `GPIO_TYPE_V1` before writing `int_type` and `int_polarity`. On `GPIO_TYPE_V1` with `bank->toggle_edge_mode` set, `rockchip_irq_set_type()` and `rockchip_irq_demux()` must keep `int_polarity` inverted relative to live `ext_port`, with `rockchip_irq_demux()` re-reading `ext_port` in a loop until the pin level stabilizes. [F42, F43]
- In `rockchip_gpio_set_debounce()`, when `bank->gpio_type == GPIO_TYPE_V2` and `!IS_ERR(bank->db_clk)`, validate `debounce <= (GENMASK(23, 0) + 1) * 2 * 1000000 / freq` before computing `div_reg` so it fits the 24-bit `dbclk_div_con` register. [F68]

## Synchronization

- In `rockchip_softrst_assert()` and `rockchip_softrst_deassert()`, when `ROCKCHIP_SOFTRST_HIWORD_MASK` is absent from `softrst->flags`, serialize the 32-bit RMW on `softrst->reg_base + (bank * 4)` under `spin_lock_irqsave(&softrst->lock, flags)`. In `rk_timer_interrupt()`, when `clockevent_state_oneshot(ce)` is true, call `rk_timer_disable(timer)` before `ce->event_handler(ce)`. [F112, F123]
- In `rockchip-dfi.c`, hold `dfi->mutex` in `rockchip_dfi_enable()` and `rockchip_dfi_disable()` across `dfi->usecount` updates, `dfi->clk` prepare/enable/disable, and `DDRMON_CTRL` writes. Update `dfi->total_count` and `dfi->last_perf_count` together under `write_seqlock(&dfi->count_seqlock)` in `rockchip_dfi_timer()`, and read them together inside a `read_seqbegin()` / `read_seqretry()` loop in `rockchip_ddr_perf_event_get_count()`. [F15, F47]
- In `gpio-rockchip.c`, `bank->slock` (`raw_spinlock_t`) protects GPIO registers and `bank->toggle_edge_mode` across process and hardirq/irq_chip contexts, and must never be held across sleeping pinctrl or clock calls (`pinctrl_gpio_direction_input()`/`output()`, `clk_prepare_enable()`/`disable_unprepare()`). In `rockchip_gpio_probe()`, run both `rockchip_gpiolib_register(bank)` and `bank->deferred_pins` draining under `mutex_lock(&bank->deferred_lock)`. [F18, F119]

## Object Lifetimes

- Every `GATE_LINK` clock's `linked_clk_id` must already be in `ctx->clk_data.clks` before `rockchip_clk_register_late_branches()` processes it, as `rk_clk_gate_link_probe()` immediately looks it up via `rockchip_clk_get_lookup()` for `pm_clk_add_clk()`. Late branch arrays (e.g. `rk3588_clk_branches`) and their `parent_names` must not be `__initdata` or `__initconst` (`PNAME()`), as `rockchip_clk_register_gate_link()` keeps the `struct rockchip_clk_branch *` in platform data. Insert `struct rockchip_aux_grf` entries into `ctx->aux_grf_table` after `rockchip_clk_init()` and before `rockchip_clk_register_branches()` processes any `grf_type != grf_type_sys` branch. [F4, F6, F110]
- In `rk_clkevt_init()` and `rk_clksrc_init()`, `rk_timer_probe()` and initial counter setup must complete before publishing via `request_irq()`, `clockevents_config_and_register()`, `clocksource_mmio_init()`, or `sched_clock_register()`. On failure, call `rk_timer_cleanup()`, free the struct, and set `rk_clkevt` or `rk_clksrc` to `ERR_PTR(ret)` (not `NULL`) so future `rk_timer_init()` calls do not retry the failed role. [F7, F23]
- In `rockchip_ddr_perf_init()`, initialize and devres-track `dfi->count_seqlock`, cpuhp state/instance, `rockchip_dfi_enable()`, and `hrtimer_setup(&dfi->timer, ...)` before `perf_pmu_register(&dfi->pmu, ...)`, so devm teardown (`rockchip_ddr_perf_remove()`, `rockchip_ddr_cpuhp_remove_instance()`, `rockchip_ddr_cpuhp_remove_state()`) unregisters the PMU before removing cpuhp and disabling DFI. [F16]
- Because `rockchip_get_bank_data()` enables `bank->clk` via unmanaged `clk_prepare_enable()`, both the `rockchip_gpiolib_register()` error path in `rockchip_gpio_probe()` and `rockchip_gpio_remove()` must call `clk_disable_unprepare(bank->clk)`. In `rockchip_interrupts_register()`, call `irq_domain_remove(bank->domain)` if `irq_alloc_domain_generic_chips()` fails. Release every `struct device_node *` from `of_get_parent()` (`rockchip_gpiolib_register()`, `rockchip_gpio_probe()`) or `of_parse_phandle()` (`rockchip_dfi_probe()`) with `of_node_put()` right after `of_pinctrl_get()` or `syscon_node_to_regmap()`. [F11, F12, F109]

## API Contracts

- `rockchip_clk_find_max_clk_id()` returns the highest inclusive clock `id` (and must assign `max = list->child->id`, not `list->id`, when `list->child->id > max`), while `rockchip_clk_set_lookup()` indexes `ctx->clk_data.clks[id]` unchecked; add `1` when sizing `nr_clks`. Controllers using `rockchip_clk_init_early()` (e.g. `clk_rk3588_probe()`) must call `rockchip_clk_finalize(ctx)`, `of_clk_del_provider(np)`, and `rockchip_clk_of_add_provider(np, ctx)` after registering late branches. [F51, F58, F70]
- `rockchip_clk_register_branches()` rejects `branch_linked_gate` (`clk = NULL`), whereas `rockchip_clk_register_late_branches()` only accepts `branch_linked_gate`. In `rk_clk_gate_link_probe()`, call `devm_pm_runtime_enable(dev)`, `devm_pm_clk_create(dev)`, and `pm_clk_add_clk(dev, linked_clk)` before `rk_clk_gate_link_register()`, and call `pm_clk_remove_clk(dev, linked_clk)` if registration fails. In `rockchip_fractional_approximation()`, set `CLK_FRAC_DIVIDER_POWER_OF_TWO_PS` on `to_clk_fd(hw)->flags` before `clk_fractional_divider_general_approximation()`, and replace `*parent_rate` with the grandparent rate when `rate * 20 > p_rate && p_rate % rate != 0`. [F72, F115, F125]
- In `rockchip_register_softrst_lut()`, when `lookup_table` is non-NULL, `num_regs` sets `softrst->rcdev.nr_resets` and must equal `ARRAY_SIZE(lookup_table)`, and all `lookup_table[id]` entries must be non-negative because `rockchip_softrst_assert()` / `deassert()` cast them to `unsigned long` before division. [F62]
- In `timer-rockchip.c`, `rk_clkevt` (`struct rk_clkevt`) must pass `&rk_clkevt->ce` as `dev_id` to `request_irq()` for `rk_timer_interrupt()`, whereas `rk_clksrc` is a standalone `struct rk_timer` and must never be passed to `rk_timer()`. `rk_timer_sched_read()` must stay `notrace` and use only lockless `readl_relaxed()`. [F98, F122]
- In `rockchip_dfi_get_event()`, select only the single active channel in `dfi->channel_mask` with the largest access delta since `dfi->last_event_count` and set `edata->load_count = access * 4` and `edata->total_count = clock_cycles`. [F131]
- `rockchip_gpio_readl_bit()` returns `0` or `1` (`(val >> bit) & 1`), and both `rockchip_gpio_readl_bit()` and `rockchip_gpio_writel_bit()` take a `0..31` pin index (`bit`), never `BIT(offset)`. In `gpio-rockchip.c`, `irq_alloc_domain_generic_chips()` sets `gc->private = bank`, so `irq_chip` callbacks must read `((struct irq_chip_generic *)irq_data_get_irq_chip_data(d))->private` to get `struct rockchip_pin_bank *`. [F38, F97]

## Error Handling

- In `rk_timer_probe()`, `irq_of_parse_and_map()` returns `0` on failure after `clk_prepare_enable()` sets `ret = 0`, so the `!irq` branch must set `ret = -EINVAL` before `goto out_irq`. [F33]
- `rockchip_dfi_probe()` must fail if `"rockchip,pmu"` or its syscon regmap is missing, initialize `dfi->regmap_pmu` before `soc_init(dfi)`, and register `dfi->edev` via `devm_devfreq_event_add_edev()` before calling `rockchip_ddr_perf_init(dfi)` or `rockchip_dfi_enable(dfi)` (which log via `&dfi->edev->dev`). In `rockchip_ddr_perf_init()`, store `cpuhp_setup_state_multi(CPUHP_AP_ONLINE_DYN, ...)` in a signed `int` and check `ret < 0` before assigning to `dfi->cpuhp_state`. [F34, F36, F37]
- Because `bank->db_clk` is `NULL` on `GPIO_TYPE_V1` (`!IS_ERR(NULL)` is true) and `gpio_regs_v1` leaves `dbclk_div_en` / `dbclk_div_con` as `0` (aliasing `port_dr`), any code using `bank->db_clk` or dbclk divider registers must check `bank->gpio_type == GPIO_TYPE_V2 && !IS_ERR(bank->db_clk)`. [F39]

## External Contracts

- In `rockchip_ddr_perf_event_get_count()`, byte-counting perf events must return raw bytes (`accesses * dfi->burst_len * dfi->buswidth[i]`) to match `DFI_PMU_EVENT_ATTR` (`scale = 2^-20`, `unit = "MB"`), while `PERF_EVENT_CYCLES` multiplies channel 0 `clock_cycles` by `dfi->count_multiplier`. [F133]
- In `rockchip_gpio_set_config()`, `PIN_CONFIG_INPUT_DEBOUNCE` must return `-ENOTSUPP` after calling `rockchip_gpio_set_debounce(gc, offset, true)` so `gpiod_set_debounce()` callers keep their software fallback. In `rockchip_gpiolib_register()`, when `bank->of_node` lacks `"gpio-ranges"`, register the range from `of_pinctrl_get(of_get_parent(bank->of_node))` via `gpiochip_add_pin_range()`. [F69, F137]

## Known Pitfalls

- In `rockchip_clk_register_branches()`, local `struct regmap *grf` is initialized to `ctx->grf` only once before the loop and overwritten whenever a GRF branch has `list->grf_type != grf_type_sys`; placing a `grf_type_sys` GRF branch after a non-`grf_type_sys` branch without resetting `grf = ctx->grf` uses the wrong regmap. [F52]
- `rockchip_clk_register_branch()` and `rockchip_clk_register_frac_branch()` treat `gate_offset < 0` (`-1`) as "no gate" (`0` is valid), whereas `rockchip_clk_register_factor_branch()` treats `gate_offset == 0` as "no gate" and any non-zero value (including `-1`) as a valid offset. In `clk.h`, `HIWORD_UPDATE(val, mask, shift)` does not mask `val`, so callers must ensure `0 <= val <= mask` (1-based `_div` args to `RK3576_BIGCORE_CLKSEL2` / `RK3588_CORE_L_SEL2` must be `>= 1`) and `shift + fls(mask) <= 16`. [F61, F87]
- In `rockchip-dfi.c`, `perf_pmu_register()` sets the PMU sysfs device's drvdata to `struct pmu *` (not `struct rockchip_dfi *`), so PMU sysfs callbacks like `ddr_perf_cpumask_show()` must use `container_of(dev_get_drvdata(dev), struct rockchip_dfi, pmu)`. [F96]
- On `GPIO_TYPE_V2` banks, split per-pin control registers (`gpio_regs_v2`) require `rockchip_gpio_writel*()` / `rockchip_gpio_readl*()`, whereas single 32-bit registers (`ext_port`, `int_status`, `dbclk_div_con`) use plain `readl()` / `writel()`. In `rockchip_irq_set_type()`, `type & IRQ_TYPE_EDGE_BOTH` selects `handle_edge_irq`, whereas `type == IRQ_TYPE_EDGE_BOTH` must be tested with exact equality before single-edge `switch (type)` cases. [F67, F79]
- In `rockchip_gpio_find_bank()`, the loop advances `bank` one past `info->ctrl->pin_banks` on miss, so return `found ? bank : NULL`. In `rockchip_gpio_set_debounce()`, divide `u64 div = debounce * freq` with `DIV_ROUND_CLOSEST_ULL(div, 2 * USEC_PER_SEC)` (not `/`) for 32-bit ARM builds. In `rockchip_irq_demux()`, store `readl_relaxed()` in `unsigned long pending` before `for_each_set_bit(irq, &pending, 32)`. [F81, F89, F99]
