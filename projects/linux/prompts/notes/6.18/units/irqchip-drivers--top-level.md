# IRQCHIP DRIVERS — (top level)

Core irqchip probing (`drivers/irqchip/irqchip.c`, `include/linux/irqchip.h`), per-CPU IRQ partitioning (`irq-partition-percpu.c`), RISC-V interrupt controllers (SiFive PLIC, AIA APLIC, AIA IMSIC), and SoC controllers (MediaTek CIRQ, Qualcomm MPM, TI PRUSS, Renesas INTC-IRQPIN/RZ/G2L/RZ/V2H, STM32MP EXTI, Sophgo SG2042/SG2044 MSI, Allwinner sun4i/sun6i-r, Socionext EXIU, PIC32 EVIC, TS-4800, Xilinx INTC, ARM NVIC).

## Architecture & Data Flow
- In `irq-sifive-plic.c`, ID `0` is reserved: loops over `PRIORITY_BASE`, `prio_save`, or `enable_base` in `plic_probe()`, `plic_irq_suspend()`, and `plic_irq_resume()` must start at `1`. `priv->prio_save` is an `unsigned long` bitmap (`BIT_WORD`/`BIT_MASK`), whereas `handler->enable_save` is a `u32` array (`DIV_ROUND_UP(nr_irqs, 32)`). `plic_irq_enable()` must call both `plic_irq_toggle(..., 1)` and `plic_irq_unmask(d)`. In `plic_set_affinity()`, clear the old enable bit via `irq_data_get_effective_affinity_mask(d)` before `irq_data_update_effective_affinity()`, and enable the new bit only if `!irqd_irq_disabled(d)`. [F242, F244, F259, F304]
- In `irq-riscv-imsic-state.c`, size `lpriv->dirty_bitmap`, `lpriv->vectors`, and `imsic->matrix` to `global->nr_ids + 1`, reserving ID `0` in `imsic_matrix_init()` and skipping it in `__imsic_local_sync()`. In `__imsic_eix_read_clear()`/`__imsic_eix_update()`, `CSR_ISELECT` is `(id / BITS_PER_LONG) * (BITS_PER_LONG / IMSIC_EIPx_BITS)`; `__imsic_eix_update()` resets `ireg = 0` each outer pass and advances `id` in `for (i = id & (__riscv_xlen - 1); id < last_id && i < __riscv_xlen; i++)`. [F261, F262, F281]
- `aplic_msi_irq_eoi()` and `aplic_msi_irq_set_type()` must call `aplic_msi_irq_retrigger_level(d)` (`APLIC_SETIPNUM_LE`) when level-triggered. MSI compose callbacks (`sg2042_msi_irq_compose_msi_msg`, `sg2044_msi_irq_compose_msi_msg`, `imsic_irq_compose_vector_msg`) write physical addresses (`phys_addr_t`) into `struct msi_msg`, while CPU MMIO writes (`sg2042_msi_irq_ack`, `imsic_irq_retrigger`) use virtual addresses (`reg_clr`, `msi_va`). [F255, F343]
- `stm32mp_exti_mask()`/`unmask()` must update `chip_data->mask_cache` under `chip_data->rlock` whenever `imr_ofst` changes (`stm32mp_chip_suspend()` writes `wake_active`; `resume()` restores `mask_cache`). In `mtk_cirq_suspend()`, ACK each line `i` via `CIRQ_ACK` unless mapped and both `IRQCHIP_STATE_PENDING` and `IRQCHIP_STATE_MASKED` queries succeed with `pending && !masked`. [F246, F288]
- In `irq-pruss-intc.c`, `event_channel` and `channel_host` are refcounted under `intc->lock`: `pruss_intc_validate_mapping()` returns `-EBUSY` on conflict when `ref_count > 0`, and `pruss_intc_unmap()` writes `PRU_INTC_HIDISR` and clears `PRU_INTC_HMR` only when `--channel_host[ch].ref_count == 0`. In `pruss_intc_irq_handler()`, if `generic_handle_domain_irq()` fails, ACK `hwirq` via `PRU_INTC_SICR`. [F252, F283]
- In `irq-sun6i-r.c`, `sun6i_r_intc_nmi_ack()` sets `data->chip_data = SUN6I_NMI_NEEDS_ACK` for level NMIs, and `sun6i_r_intc_nmi_eoi()` defers `sun6i_r_intc_ack_nmi()` until `sun6i_r_intc_nmi_unmask()` if `irqd_irq_masked(data)`. `sun6i_r_intc_suspend()`/`shutdown()` program `wake_irq_enabled` and `wake_mux_enabled` into `SUN6I_IRQ_ENABLE`/`MUX_ENABLE`, while `sun6i_r_intc_resume()` enables only `SUN6I_NMI_BIT` in `SUN6I_IRQ_ENABLE(0)`. In `sun4i_handle_irq()`, verify an initial `hwirq == 0` against `SUN4I_IRQ_PENDING_REG(0) & BIT(0)` before `do { ... } while (hwirq != 0)`. [F253, F286, F328]
- In `irq-renesas-intc-irqpin.c`, `SOURCE`, `MASK`, and `CLEAR` are 8/32-bit MSB-first registers using `intc_irqpin_hwirq_mask()` (`BIT((width - 1) - hw_irq)`) and `p->iomem[reg].read`/`write`. `intc_irqpin_shared_irq_enable()`/`disable()` update `p->shared_irq_mask` (`&= ~BIT(hw_irq)` / `|= BIT(hw_irq)`); `intc_irqpin_shared_irq_handler()` tests `reg_source` with `BIT(7 - k)` and `p->shared_irq_mask` with `BIT(k)`. [F258, F272, F287]
- In `rzv2h_icu_eoi()`/`set_type()`, `hw_irq >= ICU_TINT_START` (17) must precede `else if (hw_irq >= ICU_IRQ_START)` (1); `rzv2h_hw_info.field_width` must be `>= 2` and divide 32. `rzg2l_clear_irq_int()`, `rzv2h_clear_irq_int()`, and `rzv2h_clear_tint_int()` may clear `ISCR`/`ICU_ISCLR`/`ICU_TSCLR` only when pending and edge-triggered in `IITSR`/`ICU_IITSR`/`ICU_TITSR`, and `rzg2l_clear_irq_int()`/`rzg2l_clear_tint_int()` must follow `ISCR`/`TSCR` writes with `readl_relaxed()`. [F250, F277, F300, F316]
- `exiu_irq_set_type()` must switch between `handle_fasteoi_irq` (level) and `handle_fasteoi_ack_irq` (edge) via `irq_set_handler_locked()` and clear `BIT(d->hwirq)` in `EIREQCLR`. `qcom_mpm_read()`/`write()` compute vMPM offsets as `(reg * priv->reg_stride + index + 2) * 4`. [F256, F307]

## Synchronization
- In `irq-riscv-imsic-state.c`, `lpriv->lock` nests outside `imsic->matrix_lock` (never take `lpriv->lock` or call `imsic_vector_alloc()`/`free()` under `matrix_lock`). Updates to `vec->enable`, `move_next`, `move_prev`, `lpriv->dirty_bitmap`, and `lpriv->timer` require `per_cpu_ptr(imsic->lpriv, vec->cpu)->lock` with IRQs disabled. `__imsic_local_timer_start()` must use `add_timer_on(&lpriv->timer, cpu)`. [F204, F205, F237]
- `__imsic_eix_update`, `__imsic_eix_read_clear`, `imsic_local_delivery`, `imsic_vector_mask`, and `imsic_vector_unmask` require local IRQs disabled; callers that may have IRQs enabled must use `raw_spin_lock_irqsave(&lpriv->lock, flags)`. `imsic_state_offline` must use `timer_delete_sync_try(&lpriv->timer)` under `lpriv->lock`. In `imsic_irq_set_affinity()`, when `!irq_can_move_in_process_context(d)` and `new_vec->local_id != old_vec->local_id`, `imsic_msi_update_msg()` must program `tmp_vec` (`old_vec->cpu`, `new_vec->local_id`) before `new_vec`, and `__imsic_local_sync()` must check pending bits on both `tvec` and `vec`. [F209, F333, F334, F336]
- In `imsic_early_probe()`, map and chain `imsic_parent_irq` before `cpuhp_setup_state(CPUHP_AP_IRQ_RISCV_IMSIC_STARTING, ...)`. In `plic_probe()`, call `irq_set_chained_handler()`, `cpuhp_setup_state()`, and `register_syscore_ops()` only after `priv->irqdomain` and all online CPUs' `plic_handlers` are initialized; post-init `handler->enable_base` accesses require `raw_spin_lock_irqsave(&handler->enable_lock, ...)`. [F201, F203, F344]
- `chip_data->rlock` (`irq-stm32mp-exti.c`), `priv->lock` (`irq-qcom-mpm.c`), and `priv->lock` (`irq-renesas-rzv2h.c`) serialize register/cache updates and must be dropped before `irq_resolve_mapping()`, `irq_set_irqchip_state()`, or parent `irq_chip` calls; in `stm32mp_exti_set_type()`, `host_data->hwlock` nests inside `chip_data->rlock` (`hwspin_lock_timeout_in_atomic` / `hwspin_unlock_in_atomic`). [F200, F210, F212, F215]
- In `irq-renesas-intc-irqpin.c`, RMW on `SENSE`, `PRIO`, and `IRLM` requires `intc_irqpin_read_modify_write()` under global `intc_irqpin_lock`. In `irq-pruss-intc.c`, sleeping `intc->lock` (`struct mutex`) is only for `pruss_intc_irq_domain_ops`, never `pruss_irqchip` or `pruss_intc_irq_handler`. In `irq-partition-percpu.c`, `partition_irq_mask`/`unmask`/`get_irqchip_state`/`set_irqchip_state` must check `partition_check_cpu(part, smp_processor_id(), d->hwirq)` before calling `part->chained_desc` chip ops. [F257, F342, F345]

## Object Lifetimes
- In `rzg2l_irqc_common_init`, `dev` from `of_find_device_by_node` has `__free(put_device)` and must be disarmed (`dev = NULL`) on success. In `rzv2h_icu_init_common`, bind `&pdev->dev` via `devm_add_action_or_reset(..., rzv2h_icu_put_device, &pdev->dev)`, and call `pm_runtime_put(&pdev->dev)` on failure after `pm_runtime_resume_and_get`. In `pruss_intc_probe` (`fail_irq`, using `while (--i >= 0)` and `if (intc->irqs[i])`) and `pruss_intc_remove`, clear chained handlers (`irq_set_chained_handler_and_data(..., NULL, NULL)`) and dispose mappings before `irq_domain_remove()`. [F191, F192, F194, F284]
- In `__imsic_local_sync`, the old CPU calls `imsic_vector_free(vec)` after clearing `vec->move_next`, and the new CPU must not clear `vec->move_prev` or its `dirty_bitmap` bit while `READ_ONCE(mvec->move_next)` is non-NULL. `imsic_setup_state` frees `mmios_va` and `mmios` on success (keeping `ioremap` in `global->local`), and on error runs `imsic_local_cleanup`, `iounmap(mmios_va[i])`, frees `mmios_va`/`mmios`/`imsic->global.local`/`imsic`, and sets `imsic = NULL`. [F195, F196]
- In `plic_probe` (`fail_cleanup_contexts`), reset `present = false` and clear `hart_base`, `enable_base`, `enable_save` (after `kfree`), and `priv` on all initialized `plic_handlers` before freeing `priv->prio_save` and `priv`. In `sg2042_msi_probe`, every successful `fwnode_property_get_reference_args` requires `fwnode_handle_put(args.fwnode)`. In `qcom_mpm_init()`, map `"qcom,rpm-msg-ram"` with `devm_ioremap()` and call `of_node_put(msgram_np)` on all paths. [F198, F199, F320]

## API Contracts
- `platform_irqchip_probe()` treats `of_device_get_match_data(&pdev->dev)` as `of_irq_init_cb_t` (`IRQCHIP_MATCH`), clears `par_np = NULL` if `par_np == np`, and returns `-EPROBE_DEFER` if `par_np && !irq_find_matching_host(par_np, DOMAIN_BUS_ANY)`. `partition_create_desc()` requires non-NULL `.select` and `.translate` in `ops` and enforces `nr_irqs == 1` in `partition_domain_alloc`/`free`. [F308, F330, F351]
- In RISC-V APLIC (`irq-riscv-aplic-*.c`), source 0 is reserved (`1..priv->nr_irqs`): `APLIC_SETIENUM`/`CLRIENUM`/`SETIPNUM_LE` take 1-based `d->hwirq`, whereas `APLIC_SOURCECFG_BASE`/`TARGET_BASE` use `(d->hwirq - 1) * sizeof(u32)` and domain size is `priv->nr_irqs + 1`. Shared helpers in `irq-riscv-aplic-main.c` must never downcast `struct aplic_priv *` to `struct aplic_direct *`. In `aplic_msi_setup()`, if `!dev_get_msi_domain(dev)`, resolve it via `of_msi_configure()` or `imsic_acpi_get_fwnode()`/`dev_set_msi_domain()` and return `-EPROBE_DEFER` if NULL; `aplic_msi_translate()` gets `aplic_priv` from `((struct msi_domain_info *)d->host_data)->data`. [F224, F309, F310, F358]
- `imsic_dying_cpu` must not call `imsic_local_delivery(false)` or `disable_percpu_irq(imsic_parent_irq)`. `imsic_irq_debug_show()` must check `if (!irqd)`. `imsic_irq_domain_alloc()` and `.irq_set_affinity` callbacks (`imsic_irq_set_affinity`, `aplic_direct_set_affinity`, `plic_set_affinity`) must call `irq_data_update_effective_affinity()`. Non-atomic MSI domains (`DOMAIN_BUS_PCI_DEVICE_MSI`/`MSIX`) in `imsic_init_dev_msi_info()` must set `IRQCHIP_MOVE_DEFERRED` (`irq_move_irq(d)` in `imsic_irq_ack()`), whereas `aplic_msi_template` must not. [F337, F348, F349, F350]
- `sg2042_msi_parent_ops`, `sg2044_msi_parent_ops`, and `imsic_msi_parent_ops` must set `MSI_CHIP_FLAG_SET_ACK`. `sg2042_msi_middle_irq_chip` and `sg2044_msi_middle_irq_chip` must wire `irq_chip_startup_parent`/`shutdown_parent` and require `MSI_FLAG_PCI_MSI_STARTUP_PARENT | MSI_FLAG_PCI_MSI_MASK_PARENT`. SG2042 uses a single register with `1 << d->hwirq`; SG2044 clears `(u32 __iomem *)data->reg_clr + d->hwirq` with `0`, adds `4 * (d->hwirq / 32)` to `data->doorbell_addr`, and sets `msg->data = d->hwirq % 32`. [F233, F305, F346, F347]
- In `irq-pruss-intc.c`, `SICR`/`SISR`/`EICR`/`EISR` take unshifted `hwirq`, whereas `ESR`/`ECR`/`SECR`/`SRSR` are banked by `hwirq / 32` with `BIT(hwirq % 32)`. In `qcom_mpm_alloc()`, `pin == GPIO_NO_WAKE_IRQ` disconnects `domain` immediately, whereas `map == NULL` disconnects `domain->parent` after `irq_domain_set_hwirq_and_chip()`. In `irq-renesas-rzg2l.c`, `irq-renesas-rzv2h.c`, and `irq-pic32-evic.c`, callbacks must get private data from `d->domain->host_data` (`irq_data_to_priv` / `irqd_to_priv`), never `d->chip_data`. [F228, F275, F311, F312]
- In `plic_probe()`, `is_of_node(fwnode)` paths may run with `fwnode->dev == NULL` and must use OF APIs without dereferencing `fwnode->dev`. `plic_irq_set_type()` returns `IRQ_SET_MASK_OK_NOCOPY` without `PLIC_QUIRK_EDGE_INTERRUPT`, and with it switches between `&plic_edge_chip` (`handle_edge_irq`) and `&plic_chip` (`handle_fasteoi_irq`). `rzv2h_icu_set_type`, `rzg2l_irqc_set_type`, `exiu_irq_set_type`, and `sun6i_r_intc_nmi_set_type` must pass `IRQ_TYPE_LEVEL_HIGH` to `irq_chip_set_type_parent()`. `handle_fasteoi_irq` chips (`aplic_direct_chip`, `nvic_of_init`) require non-NULL `.irq_eoi`. [F318, F354, F355, F356]

## Error Handling
- Check `if (!imsic || !imsic->fwnode)` in `imsic_irqdomain_init()`. In `imsic_vector_alloc()`, store `irq_matrix_alloc()` in signed `int`, check `< 0`, and initialize `irq`, `enable`, `move_next`, and `move_prev`. Validate bit widths/shifts against `BITS_PER_LONG`, `IMSIC_MMIO_PAGE_SHIFT`, and `IMSIC_MIN_ID`/`MAX_ID` in `imsic_parse_fwnode()`, and check `group_index_shift >= 2 * APLIC_xMSICFGADDR_PPN_SHIFT` and `APLIC_xMSICFGADDRH_*_MASK` in `aplic_msi_setup()`. [F216, F226, F263, F264]
- In `plic_probe()`, set negative `error` before jumping to `fail_cleanup_contexts` after `plic_parse_context_parent()`. Check `devm_ioremap()`/`of_iomap()` for `NULL` (`-ENOMEM`) and `devm_platform_ioremap_resource()` with `IS_ERR()`. Guard `irq_chip_*_parent(d)` with `if (d->parent_data)` in `qcom_mpm_*` and `if (d->parent_data->chip)` in `stm32mp_exti_*`. In `stm32mp_exti_probe()`, ignore `-ENOENT` from `of_hwspin_lock_get_id()` and check `devm_hwspin_lock_request_specific()` for `NULL`. [F218, F219, F221, F222, F235]
- Re-validate unpacked 16-bit `hwirq` against `IRQC_TINT_START..IRQC_NUM_IRQ - 1` / `ICU_TINT_START..ICU_NUM_IRQ - 1` in `rzg2l_irqc_alloc()` and `rzv2h_icu_alloc()`; in `rzv2h_tint_set_type()`, check `tint <= priv->info->max_tssel` and `priv->info->tssel_lut != NULL`. In `sg204x_msi_middle_domain_alloc()`, store `sg204x_msi_allocate_hwirq()` in signed `int` and on parent alloc failure at `i`, free `nr_irqs` hwirqs but only `i` parent IRQs. Validate `intspec[0..2]` against `soc_config` in `pruss_intc_irq_domain_xlate()`. Log unmapped IDs with `*_warn_ratelimited` in RISC-V handlers without breaking the claim loop. [F230, F232, F265, F267, F359]

## External Contracts
- `partition_irq_print_chip()` and `ts4800_irq_print_chip()` must not emit a leading space. `sun6i_r_intc_domain_translate()` must accept 2-cell NMI specifiers (`param_count == 2 && param[0] == 0` -> `nmi_hwirq`) and require 3 cells (`param[0] == GIC_SPI`) otherwise. [F271, F273]

## Known Pitfalls
- In `plic_irq_eoi()`, if `irqd_irq_disabled(d)`, temporarily set the context enable bit via `plic_toggle(handler, d->hwirq, 1)` around the `CONTEXT_CLAIM` write. In `irq-renesas-rzg2l.c`, shift `TSSR` fields by `TSSEL_SHIFT(tssr_offset)` (`8 * tssr_offset`), compute `TSSR_OFFSET`/`TSSR_INDEX` in `rzg2l_tint_set_edge()` before subtracting `TITSR0_MAX_INT` from `titseln`, pass `hwirq` to `rzg2l_clear_tint_int()`, and never cache/restore `TSSR` in `rzg2l_irqc_irq_suspend()`/`resume()`. In `irq-renesas-rzv2h.c`, write `BIT(tint_nr)` to `ICU_TSCLR` after updating `ICU_TSSR(k)` under `priv->lock`, and index `ICU_TSSR_*` with `tssel_n` and `ICU_TITSR_*` with `titsel_n`. [F220, F243, F249, F251, F276, F279]
- Call `of_node_clear_flag(node, OF_POPULATED)` in `imsic_early_dt_init()`; increment `__fls(*nr_parent_irqs)` if `BIT(hart_index_bits) < *nr_parent_irqs` in `imsic_populate_global_dt()`; align `resource_size(&mmios[j])` to `BIT(global->guest_index_bits) * IMSIC_MMIO_PAGE_SZ` when stepping `reloff` in `imsic_setup_state()`. Cast `irqc->intr_mask` to `u64` before `>> irqc->nr_irq` and verify `MER` readback for `xintc_is_be` in `xilinx_intc_of_init()`; cast `msg->address_hi` to `u64` before `<< 32` in `aplic_msi_write_msg()`. [F289, F290, F295, F296, F327, F329]
- Use `bitmap_to_arr32()`/`bitmap_from_arr32()` for `wake_*` bitmaps in `irq-sun6i-r.c`, and store `qcom_mpm_read()` in `unsigned long` before bitops in `irq-qcom-mpm.c`; use `qcom_mpm_write()` (`wmb()`) for vMPM writes and zero `MPM_REG_STATUS` before `mbox_send_message()` in `mpm_pd_power_off()`. Add `FIRST_PRU_HOST_INT` (`2`) to `host_irq` for `PRU_INTC_HIPIR()` in `pruss_intc_irq_handler()`. Check `hwirq == part->nr_parts` for `handle_bad_irq(desc)` in `partition_handle_irq()`. Write `BIT(d->hwirq)` to `EIREQCLR` for level IRQs in `exiu_irq_eoi()` and before unmasking in `exiu_irq_enable()`. [F268, F282, F302, F303, F321, F326]
