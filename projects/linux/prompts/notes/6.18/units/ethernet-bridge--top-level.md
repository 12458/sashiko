# ETHERNET BRIDGE — (top level)

Implements the Linux Ethernet bridge (802.1D/802.1Q) virtual netdev, port management, frame forwarding, unicast FDB, multicast MDB, ARP/ND proxy and neighbor suppression, MST, MRP (IEC 62439-2), CFM (802.1ag), netfilter bridge hooks, RTNetlink/ioctl UAPIs, and switchdev offload.

## Architecture & Data Flow

- `br->fdb_n_learned` tracks `BR_FDB_DYNAMIC_LEARNED` entries: `fdb_create()` increments it only after `rhashtable_lookup_insert_fast()` succeeds, and every deletion or promotion to `BR_FDB_ADDED_BY_USER`/`BR_FDB_LOCAL` must `test_and_clear_bit(BR_FDB_DYNAMIC_LEARNED, &fdb->flags)` before `atomic_dec(&br->fdb_n_learned)`. [F176]
- Static FDB MACs are refcounted in non-promiscuous (`!br_promisc_port(p)`), `IFF_UNICAST_FLT` ports via `dev_uc_add()`/`dev_uc_del()`: `fdb_add_entry()`/`fdb_delete()` call `fdb_add_hw_addr()`/`fdb_del_hw_addr()` only on `BR_FDB_STATIC` transitions; `br_port_clear_promisc()` must succeed at `br_fdb_sync_static()` before `dev_set_promiscuity(p->dev, -1)` and clearing `BR_PROMISC`; `br_port_set_promisc()` calls `br_fdb_unsync_static()`; and `br_add_if()` must call `br_fdb_sync_static()` if `nbp_update_port_count()` leaves `!br_promisc_port(p)` (unsyncing on `err6` rollback). [F177, F222, F223]
- Toggling `BROPT_FDB_LOCAL_VLAN_0` (`br_toggle_fdb_local_vlan_0()`) must sync per-VLAN local FDB entries via `br_fdb_toggle_local_vlan_0()` (with rollback on failure), and `br_fdb_changeaddr()`/`br_fdb_change_mac_address()` must not insert per-VLAN local entries while it is set. [F231]
- Every netlink attribute emitted by `fdb_fill_info()` must be accounted for in `fdb_nlmsg_size()`, as `fdb_notify()` allocates `nlmsg_new(fdb_nlmsg_size(), GFP_ATOMIC)` and hits `WARN_ON(err == -EMSGSIZE)` on overflow. [F255]
- Changing `p->flags` in `BR_AUTO_MASK` or `BR_NEIGH_SUPPRESS | BR_NEIGH_VLAN_SUPPRESS` via `br_port_flags_change()` (or port add/del) must update `br->auto_cnt`/promiscuity (`nbp_update_port_count()`) and `BROPT_NEIGH_SUPPRESS_ENABLED` (`br_recalculate_neigh_suppress_enabled()`). [F227]
- `br_add_if()` must register `br_get_rx_handler(dev)` (`br_handle_frame_dummy` on DSA conduits) via `netdev_rx_handler_register()` on every port so `br_port_get_check_rcu()`/`br_port_get_check_rtnl()` can validate `dev->rx_handler` before downcasting `dev->rx_handler_data`. [F280]
- `br_mst_vlan_set_state()` must update `vg->pvid_state` (`br_vlan_set_pvid_state()`) when `v->vid == vg->pvid`; `br_mst_vlan_set_msti()` must sync port VLAN entries via `br_mst_vlan_sync_state()`; and master `mv->msti` must stay `< VLAN_N_VID` because `br_mst_info_size()`/`br_mst_fill_info()` index `DECLARE_BITMAP(seen, VLAN_N_VID)` with `v->brvlan->msti`. [F229, F284]
- When `br_multicast_should_handle_mode()` holds, `br_mdb_add_group_sg()` must replicate `(*, G)` `MCAST_EXCLUDE` ports via `br_multicast_sg_add_exclude_ports()`, and `br_mdb_add_group_star_g()`/`br_mdb_replace_group_star_g()` must sync `(S, G)` entries via `br_multicast_star_g_handle_mode()`. Each MDB `mp->ports` list and router port list must stay sorted in descending `struct net_bridge_port *` order so `br_multicast_flood()` can merge-scan `lport` and `rport` in one pass. [F241, F262]
- `sizeof(struct br_input_skb_cb)` must fit in `skb->cb` (48 bytes); `br_handle_frame()` and `br_dev_xmit()` must zero `skb->cb` first; and `br_pass_frame_up()` and `br_dev_xmit()` must call `br_switchdev_frame_unmark(skb)` so stacked bridges do not inherit `skb->offload_fwd_mark`. [F257, F310]
- In `br_handle_frame()`, `fwd_mask & (1u << dest[5])` must only be evaluated inside `is_link_local_ether_addr(dest)` (where `dest[5] < 16`), initializing `fwd_mask` from `group_fwd_mask_required | p->group_fwd_mask` and ORing `p->br->group_fwd_mask` only for `0x0E` (LLDP) and `default` so `0x00` (STP) ignores bridge `group_fwd_mask` and `0x01` (Pause) is dropped. In `br_handle_frame_finish()` and `br_dev_xmit()`, test `is_broadcast_ether_addr()` before/inside `is_multicast_ether_addr()` so broadcasts do not go to `br_multicast_rcv()`. [F258, F259, F272]
- Forwarding helpers (`br_allowed_ingress`, `br_forward`, `br_flood`, `br_multicast_flood`, `__br_forward`) require `skb->data` at `skb_mac_header(skb) + ETH_HLEN` (pulled in `br_dev_xmit()`, pushed in `br_dev_queue_push_xmit()`). In `maybe_deliver_addr()`, `__skb_push(skb, ETH_HLEN)` must precede `pskb_copy()` and be balanced with `__skb_pull(skb, ETH_HLEN)` on `skb` and `nskb`. In `__br_forward()`, `nbp_switchdev_frame_mark_tx_fwd_offload(to, skb)` must precede `br_handle_vlan()`. [F234, F307, F308]
- `br_netif_receive_skb()` and `br_dev_queue_push_xmit()` must call `br_drop_fake_rtable(skb)` after `NFPROTO_BRIDGE` hooks. In `br_dev_queue_push_xmit()`, after `skb_push(skb, ETH_HLEN)`, software-VLAN-tagged `CHECKSUM_PARTIAL` skbs (`eth_type_vlan(skb->protocol)`) must update `skb->network_header` via `vlan_get_protocol_and_depth()` and `skb_set_network_header(skb, depth)` before `dev_queue_xmit()`. [F311, F312]
- Detaching MRP ports in `br_mrp_del_impl()` or `br_mrp_set_in_role()` must clear `BR_MRP_AWARE`, restore `p->state` (`BR_STATE_FORWARDING` if running else `BR_STATE_DISABLED`) under `br->lock`, call `br_mrp_port_switchdev_set_state()`, and null the RCU port pointer. `br_mrp_ring_test_hdr` and `br_mrp_in_test_hdr` must stay `__packed__` (32-bit `timestamp` at offset 14). [F237, F251]
- In `br_cfm_cc_config_set()`, when `config` changes, reset `mep->ccm_rx_snumber = 0` and `mep->ccm_tx_snumber = 1`, and on `config->enable` transitions call `cc_peer_enable()`/`cc_peer_disable()` across `mep->peer_mep_list`. [F239]

## Synchronization

- `br->lock` nests outside `br->hash_lock` and `br->multicast_lock` (`br_device_event()` -> `br_fdb_changeaddr()`, `br_stp_disable_port()` -> `br_fdb_delete_by_port()`/`br_multicast_disable_port()`); never acquire `br->lock` while holding either. [F291]
- `br_fdb_update()` uses bare `spin_lock(&br->hash_lock)` assuming BH disabled and `rcu_read_lock()` held; process-context callers (`__br_fdb_add()` for `NTF_USE`) must wrap it in `local_bh_disable()` + `rcu_read_lock()`, and other process/workqueue callers must use `spin_lock_bh(&br->hash_lock)`. [F290]
- `fdb_create()` must initialize `key`, `dst` (`WRITE_ONCE`), `flags`, `updated`, and `used` before `rhashtable_lookup_insert_fast()` and `hlist_add_head_rcu(&fdb->fdb_node, &br->fdb_list)`. In `net_bridge_fdb_entry`, `updated`/`used` are isolated via `____cacheline_aligned_in_smp` and only written when `!= now`. [F186, F301]
- When `br_fdb_cleanup()`/`br_fdb_flush()` walks `br->fdb_list` under RCU and takes `spin_lock_bh(&br->hash_lock)`, it must check `!hlist_unhashed(&f->fdb_node)` before `fdb_delete()`. RCU readers of `fdb->dst` (`fdb_fill_info()`, `__fdb_flush_matches()`, `br_fdb_test_addr()`, `br_fill_forward_path()`) must use `READ_ONCE(fdb->dst)` and null-check it. Lockless `BR_FDB_NOTIFY_INACTIVE` transitions in `br_fdb_cleanup()`/`__fdb_mark_active()` must use atomic `test_and_set_bit()`/`test_and_clear_bit()` before `fdb_notify()`. [F197, F199, F201]
- Set `IFF_BRIDGE_PORT` only after `netdev_rx_handler_register()` in `br_add_if()`, and clear it before `netdev_rx_handler_unregister()` in `del_nbp()` and error rollback. In `br_forward()`, recheck `rcu_dereference(to->backup_port)` for `NULL` after `rcu_access_pointer()` and read `to->backup_nhid` via `READ_ONCE()`. [F188, F198]
- Call `port_cost()` only in process context outside `br->lock` (`__ethtool_get_link_ksettings()` may sleep). `fdb_notify()`, `__br_mdb_notify()`, and `br_rtr_notify()` run under `hash_lock`/`multicast_lock` or softirq and must use `GFP_ATOMIC`. `br_mdb_get()` must hold `spin_lock_bh(&br->multicast_lock)` across `br_mdb_get_reply_alloc()` (`GFP_ATOMIC`) and `br_mdb_get_reply_fill()`, dropping it before `rtnl_unicast()`. In `br_ioctl.c`, drop `rcu_read_unlock()` before `copy_to_user()`. [F292, F294, F295, F296]

## Object Lifetimes

- In `br_add_if()`, errors before `kobject_init_and_add(&p->kobj, ...)` free `p` with `kfree(p)` after `netdev_put()`; errors at/after it must use `kobject_put(&p->kobj)` (`release_nbp()`) and never `kfree(p)`. `del_nbp()` detaches all subsystems under RTNL before `call_rcu(&p->rcu, destroy_nbp_rcu)` drops `netdev_put()` and `kobject_put()`. [F170, F171]
- `nbp_backup_change()` maintains `backup_redirected_cnt` (rejecting `p == backup_p`, no-op if `old_backup == backup_p`), and `nbp_backup_clear()` must clear both `p->backup_port` and any `cur_p->backup_port == p`. `br_netpoll_disable()` must set `p->np = NULL` before `__netpoll_free(np)`. [F178, F184]
- `br_dev_delete()` must call `cancel_delayed_work_sync(&br->gc_work)` before unregistering `br->dev`; `br_deinit()` must call `rcu_barrier()` after `unregister_pernet_subsys()` and before `br_fdb_fini()`. `br_mrp_del_impl()`, `mep_delete_implementation()`, and `br_cfm_cc_peer_mep_remove()` must `cancel_delayed_work_sync()` all delayed work before unlinking and `kfree_rcu()`. [F182, F192]
- `br_mdb_add()`/`br_mdb_del()` must call `br_mdb_config_fini(&cfg)` on all paths after `br_mdb_config_init()`, and `br_mdb_config_attrs_init()` must free `cfg->src_entries` (`br_mdb_config_src_list_fini()`) if failing after `br_mdb_config_src_list_init()`. In `br_mdb_add_group_srcs()`/`br_mdb_replace_group_srcs()`, failure at signed `int i` must roll back `for (i--; i >= 0; i--)` via `br_mdb_del_group_src()` and clear `BR_SGRP_F_DELETE` on `pg->src_list`. [F179, F180, F250]
- In `br_do_proxy_suppress_arp()` and `br_do_suppress_nd()`, release non-NULL `neigh_lookup()` results with `neigh_release(n)` on all exit paths, including when `!(READ_ONCE(n->nud_state) & NUD_VALID)`. [F181]

## API Contracts

- `br_forward()`, `br_flood()`, and `br_multicast_flood()` consume/free `skb` when `local_rcv == false`, and never consume/free `skb` when `local_rcv == true`. `br_frame_type.frame_handler` (`br_cfm_frame_rx()`, `br_mrp_process()`) returns `0` to forward or `1` when handled (must not free `skb` or pass `local_rcv = false` because `br_handle_frame()` returns `RX_HANDLER_PASS`). `br_handle_local_finish()` must return `1` so `NF_HOOK()` distinguishes accepted (`RX_HANDLER_PASS`) from stolen (`0`, `RX_HANDLER_CONSUMED`). [F173, F207, F305]
- `br_allowed_ingress()` (on `false`) and `br_handle_vlan()` (on `NULL`) free `skb`, whereas `br_multicast_rcv()` does NOT free `skb` on non-zero return (callers `br_dev_xmit()`/`br_handle_frame_finish()` must free it). [F175]
- `br_do_proxy_suppress_arp()`, `br_do_suppress_nd()`, and callees (`br_arp_send()`, `br_nd_send()`, `br_is_neigh_suppress_enabled()`) must null-check `struct net_bridge_port *p` (`NULL` from `br_dev_xmit()`). [F214]
- Bitops on `fdb->flags` and `br_opt_get()`/`br_opt_toggle()` take unshifted bit indices (`BR_FDB_*`, `BROPT_*`), whereas `fdb_create()`, `br_fdb_update()`, `net_bridge_fdb_flush_desc`, `br_port_flag_is_set()`, and `br_port_flags_change()` take shifted bitmasks (`BIT(...)`, `BR_*`). [F219, F220]
- Every `enum br_boolopt_id < BR_BOOLOPT_MAX` (< 32) must have cases in `br_boolopt_toggle()` and `br_boolopt_get()`; `br_boolopt_multi_toggle()` must copy `__u32 bm->optmask` into an `unsigned long` local before `find_next_bit()`/`for_each_set_bit()` and reject bits `>= BR_BOOLOPT_MAX` before `BIT(opt_id)`. [F260, F276, F282]
- Exported entry points/notifiers taking `struct net_device *` (`br_device_event`, `br_fdb_find_port`, `br_mst_enabled`, `br_mst_get_info`, `br_del_bridge`, `br_ioctl_stub`) must check `netif_is_bridge_master(dev)` before `netdev_priv(dev)`. `br_mst_get_info()` (requires caller-zeroed `vids` bitmap of `VLAN_N_VID` bits), `br_mst_get_state()`, `br_fdb_find_port()` (returns unreferenced `f->dst->dev`), `br_fdb_clear_offload()`, and `br_port_get_stp_state()` require `rtnl_mutex`; `br_port_flag_is_set()` and atomic `br_switchdev_event()` use `br_port_get_rtnl_rcu(dev)` and `br_switchdev_event()` must not sleep. [F185, F281, F283, F299, F300]
- Call `netif_pre_changeaddr_notify(br->dev, ...)` in process context (`br_add_if()`, `NETDEV_PRE_CHANGEADDR`) before `br_stp_recalculate_bridge_id()` updates `br->dev->dev_addr` under `br->lock`. In CFM/MRP timers, `tx_info.period` is in seconds (`* 1000000` for `usecs_to_jiffies()`), `ccm_rx_timer_start()` uses `interval_to_us(exp_interval) / 4`, and MRP test intervals/periods are in microseconds. [F221, F313]

## Error Handling & External Contracts

- `new_nbp()` returns `ERR_PTR` (never `NULL`); check `IS_ERR(p)`. `maybe_deliver()` returns `NULL`, valid `p`, or `ERR_PTR(err)`; `br_flood()`/`br_multicast_flood()` must check `IS_ERR(prev)` in and after the loop. `br_device_event()`, `br_switchdev_event()`, and `br_switchdev_blocking_event()` must wrap errnos with `notifier_from_errno(err)`. In `br_mst.c`, ignore `-EOPNOTSUPP` from `switchdev_port_attr_set()` (and reset `err = 0` in `br_mst_set_state()`). [F203, F204, F205, F206]
- Static FDB rollback: `br_fdb_sync_static()` iterates from `br->fdb_list` head stopping at `tmp == f`; `fdb_add_hw_addr()` uses `list_for_each_entry_continue_reverse()` from `p`. Guard RX fastpath warnings (`br_fdb_update()`) with `net_ratelimit()`. [F265, F322]
- `br_cfm_status_fill_info()` clears sticky `*_seen` flags only when `getlink == true`. In `br_ioctl.c`, clamp `maxnum` to `PAGE_SIZE / sizeof(struct __fdb_entry)`, `memset()` the buffer, split 16-bit `port_no` across `fe->port_no` and `fe->port_hi` (`port_no >> 8`), handle `in_compat_syscall()` in `br_dev_read_uargs()`, NUL-terminate `IFNAMSIZ` buffers (`buf[IFNAMSIZ - 1] = 0`), and check `ns_capable(net->user_ns, CAP_NET_ADMIN)` on mutating ioctls. [F238, F244, F289, F302, F316, F317]

## Known Pitfalls

- `br_mtu_auto_adjust()` must clear `BROPT_MTU_SET_BY_USER` after `dev_set_mtu(br->dev, ...)` if it was not previously set, because `br_change_mtu()` sets it unconditionally. [F228]
- Re-fetch `eth_hdr()`, `arp_hdr()`, and `ipv6_hdr()` after `pskb_may_pull()` or `br_allowed_ingress()`. In `br_do_proxy_suppress_arp()`, verify both `pskb_may_pull(skb, arp_hdr_len(dev))` and `parp->ar_hln == dev->addr_len && parp->ar_pln == 4` before reading `sha`/`sip`/`tip`. In `br_nd_send()`, abort if `!ns->opt[i + 1]` (zero-length ND option infinite loop) and add `na_olen` to `sizeof(*na)` for allocation, zeroing, checksums, and `payload_len`. [F232, F247, F269, F288]
- `mrp_frame_type` and `cfm_frame_type` are static singletons: call `br_add_frame()` only when `mrp_list`/`mep_list` is empty, and `br_del_frame()` only when it becomes empty. [F236]
- In `br_mdb.c`, validate `MDBE_ATTR_SOURCE` and `MDBE_SRCATTR_ADDRESS` with `is_valid_mdb_source()` before `nla_get_in6_addr()`/`nla_memcpy()`. In `br_mdb_fill_info()`, reset `pidx = 0` and `s_pidx = 0` after each outer MDB entry, and `goto out` on inner `__mdb_fill_info()` failure. [F249, F266]
- In `br_fdb_delete()` with `vid == 0`, combine `err &= __br_fdb_delete(...)` (which must return only `0` or `-ENOENT`) initialized from `-ENOENT`. For port VLANs in `nbp_vlan_group(p)->vlan_list`, read `v->brvlan->msti`, never `v->msti`. Compare `jiffies` deadlines with `time_before_eq()`/`time_after()`, and in `br_fdb_cleanup()` guard `min(work_delay, this_timer - now)` with `time_after(this_timer, now)`. [F268, F270, F273, F274]
