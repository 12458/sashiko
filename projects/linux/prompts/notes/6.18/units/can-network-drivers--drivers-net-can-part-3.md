# CAN NETWORK DRIVERS — drivers/net/can (part 3)

CAN controller drivers for NXP `sja1000` (core plus ISA, platform, PCI, PCMCIA frontends), Softing DPRAM cards (`softing`), SPI controllers (`hi311x`, `mcp251x`), Allwinner `sun4i_can`, TI `ti_hecc`, and USB adapters (`ems_usb`, `gs_usb`).

## Architecture & Data Flow
- `struct can_priv can` must be the first member of every `alloc_candev()` private struct (`sja1000_priv`, `softing_priv`, `hi3110_priv`, `mcp251x_priv`, `sun4ican_priv`, `ti_hecc_priv`, `ems_usb`, `gs_can`). Per-device `can_bittiming_const` limits in `softing_netdev_create()` and `gs_make_candev()` must be written to embedded `priv->btr_const`, `dev->bt_const`, or `dev->data_bt_const`, never mutating shared static templates (`softing_btr_const`). Every `ndo_stop` path must set `can.state = CAN_STATE_STOPPED`. [F235, F244, F344]
- In `gs_usb.c`, select `gs_host_frame` union members via `hf->flags & GS_CAN_FLAG_FD` and read `timestamp_us` only if `GS_CAN_FEATURE_HW_TIMESTAMP` is set. `gs_can_open()` sizes `dev->hf_size_tx` from `CAN_CTRLMODE_FD` and `GS_CAN_FEATURE_REQ_USB_QUIRK_LPC546XX`; `gs_usb_probe()` sets `parent->hf_size_rx` to `max()` across channels from `CAN_CTRLMODE_FD` and `GS_CAN_FEATURE_HW_TIMESTAMP`. `gs_usb_timestamp_work()` must refresh `&parent->tc` with `GS_USB_TIMESTAMP_WORK_DELAY_SEC < CYCLECOUNTER_MASK(32) / GS_USB_TIMESTAMP_TIMER_HZ / 2`. [F228, F260, F292]
- Free TX context slots in `gs_usb` and `ems_usb` use sentinel `echo_id = GS_MAX_TX_URBS` or `echo_index = MAX_TX_URBS` (never `0`/`-1`). In `gs_usb_receive_bulk_callback()`, increment `rx_over_errors` and `rx_errors` on `GS_CAN_FLAG_OVERFLOW` before `alloc_can_err_skb()`. In `ems_usb`, `ems_usb_write_mode()` and `ems_usb_set_bittiming()` must update cached `dev->active_params` in place and send it via `ems_usb_command_msg()`, where `msg->length <= sizeof(msg->msg)` (64) to fit `dev->tx_msg_buffer` after `CPC_HEADER_SIZE`. [F231, F233, F240, F299]
- In `mcp251x` and `hi311x`, `tx_work` moves `priv->tx_skb` to echo slot 0, sets `tx_busy = true`, and clears `tx_skb = NULL`; `mcp251x_clean()`/`hi3110_clean()` must free `tx_skb`, call `can_free_echo_skb()` if `tx_busy`, and reset both. On bus-off with `restart_ms == 0`, the IST sleeps the chip and sets `force_quit = 1`, so `mcp251x_do_set_mode()`/`hi3110_do_set_mode()` (`CAN_MODE_START`) must set `AFTER_SUSPEND_RESTART`/`HI3110_AFTER_SUSPEND_RESTART` alongside `restart_tx = 1`. In both ISTs, test bus-off (`EFLG_TXBO`/`HI3110_ERR_BUSOFF`) before error-passive and error-warning. [F236, F248, F282]
- In `mcp251x`: `mcp251x_can_ist()` must mask `intf` with `CANINTF_RX | CANINTF_TX | CANINTF_ERR` before `if (!intf) break`, and re-read/OR `CANINTF` and `EFLG` after `CANINTF_RX0IF` if `CANINTF_RX1IF` was clear; preserve `mcp251x_is_2510()` byte-by-byte and explicit RXIF-clear paths; in `SPI_CONTROLLER_HALF_DUPLEX` mode, `mcp251x_hw_rx_frame()` must copy `spi_rx_buf` into `buf + 1` (`SPI_TRANSFER_BUF_LEN - 1` bytes) because `mcp251x_hw_rx()` parses from index 1; and `priv->reg_bfpctrl` must shadow `BFPCTRL` across GPIO ops and be restored via `mcp251x_gpio_restore()` on `AFTER_SUSPEND_POWER`. [F239, F256, F271, F281]
- In `hi311x`: `hi3110_hw_reset()` must read `HI3110_READ_ERR` after `HI3110_MASTER_RESET`; `spi_tx_buf`/`spi_rx_buf` must be `>= HI3110_RX_BUF_LEN` (15 bytes) so `hi3110_hw_tx_frame()` can prepend 1-byte `HI3110_WRITE_FIFO` before `HI3110_TX_EXT_BUF_LEN` (14); and `hi3110_hw_tx()` uses offsets 3/4 (std) vs 5/6 (ext), whereas `hi3110_hw_rx()` always uses `HI3110_FIFO_WOTIME_DLC_OFF` (5) and `HI3110_FIFO_WOTIME_DAT_OFF` (6). [F250, F273, F298]
- In `softing`: update `card->tx.pending`, `priv->tx.pending`, and `echo_put`/`echo_get` in lockstep on TX/ACK and zero all four with `close_candev()` in `softing_startstop()`; `softing_startstop()` resets both buses so it must track running siblings in `bus_bitmask_start`, require matching `softing_error_reporting()`, cycle `close_candev()`/`open_candev()`, and send `CAN_ERR_RESTARTED`; `softing_handle_1()` pre-increments `fifo_rd` before reading `DPRAM_RX`, while `softing_netdev_start_xmit()` writes `DPRAM_TX` before post-incrementing `fifo_wr`; `pdat->nbus` must be `1..ARRAY_SIZE(card->net)`; and `softing_load_fw()` must verify the `0xffff` header, `(addr + len + offset) <= size`, and EOF (`type == 1`, plus entrypoint `type == 3` in `softing_load_app_fw()`). [F238, F246, F265, F267, F287]
- In `ti_hecc`: `HECC_MAX_TX_MBOX` must be `BIT(HECC_MB_TX_SHIFT)` (`< HECC_MAX_MAILBOXES`), and when `tx_head` wraps to `HECC_TX_MASK`, `ti_hecc_interrupt()` must not wake the queue until `tx_head == tx_tail`; `ti_hecc_mailbox_read()` must check `HECC_CANRML & mbx_mask` after reading `HECC_RX_LAST_MBOX` (returning `ERR_PTR(-ENOBUFS)` if set) before clearing `HECC_CANRMP`; and `HECC_CANMDL`/`HECC_CANMDH` require `be32_to_cpu()` on TX and `cpu_to_be32()` on RX. [F242, F252, F270, F289]
- In `sun4i_can_interrupt()`, call `sun4i_can_rx()` only when `SUN4I_INT_RBUF_VLD` is set and `SUN4I_INT_DATA_OR` is clear. In `sja1000_interrupt()`, both the outer `SJA1000_IR` and inner `SR_RBS` loops must exit if `status == 0xFF && sja1000_is_absent(priv)`. In `peak_pci` and `peak_pcmcia`, preserve other channels' bits in `card->led_cache`/`card->ccr` (initializing `card->ccr = ~ccr`), keep channel 0 at `card->reg_base`/`card->ioport_addr` spaced by `PEAK_PCI_CHAN_SIZE`/`PCC_CHAN_SIZE`, and never set `CDR_CLK_OFF` on channel 0 when `channels > 1`. [F241, F247, F253, F275, F300]

## Synchronization
- In `sja1000` and `sun4i_can`, all command register writes (`SJA1000_CMR`, `SUN4I_REG_CMD_ADDR`) must use `sja1000_write_cmdreg()`/`sun4i_can_write_cmdreg()` under `spin_lock_irqsave(&priv->cmdreg_lock, flags)`. Multi-step `sja1000` frontend `read_reg`/`write_reg` callbacks (`sja1000_isa_port_*_indirect`, `sp_technologic_*_reg16`, and `f81601_pci_write_reg` which flushes with `readb(priv->reg_base)` under `card->lock`) must use `spin_lock_irqsave()` nesting inside `cmdreg_lock`. `sja1000_reset_interrupt()` (`SJA1000_QUIRK_RESET_ON_OVERRUN`) must hold `netif_tx_lock(dev)` across `can_free_echo_skb(dev, 0, NULL)` and `sja1000_set_mode(dev, CAN_MODE_START)`. [F211, F212, F234, F307]
- In `gs_usb`: `gs_usb_timestamp_read()` drops `parent->tc_lock` (`spin_unlock_bh()`) for `gs_usb_get_timestamp()` and must re-acquire `spin_lock_bh(&parent->tc_lock)` before returning; `gs_can_open()` must call `gs_usb_timestamp_init(parent)` before submitting RX URBs when `!parent->active_channels`; and `gs_alloc_tx_context()`/`gs_get_tx_context()` must hold `dev->tx_ctx_lock` (`spin_lock_irqsave()`). [F190, F202, F204]
- In `softing`: `softing_enable_irq()` and sleeping DPRAM helpers (`_softing_fct_cmd()`, `softing_fct_cmd()`, `softing_bootloader_command()`, `softing_reset_chip()`, `softing_chip_poweron()`) require process context under `card->fw.lock`; `softing_startstop()` must unlock `card->fw.lock` before `dev_close(netdev)` on error; and sysfs `store_output()` must hold `card->fw.lock` and return `-EBUSY` if `netif_running(ndev)`. [F330, F332, F352]
- In `hi311x` and `mcp251x`: serialize all active SPI transfers and `spi_tx_buf`/`spi_rx_buf` accesses under `hi3110_lock`/`mcp_lock`; in `hi3110_stop()`/`mcp251x_stop()`, set `force_quit = 1` and call `free_irq(spi->irq, priv)` before acquiring `hi3110_lock`/`mcp_lock`; and in `mcp251x_hw_wake()` (called under `mcp_lock`), bracket forced wake interrupts with `disable_irq_nosync(spi->irq)` and `enable_irq(spi->irq)`. [F334, F335, F336]
- `ems_usb_command_msg()` (and callers) and `peak_pciec_set_leds()`/`peak_pciec_write_pca9553()` (`i2c_transfer()`) must only run in process/workqueue context; `peak_pciec_remove()` must call `peak_pciec_stop_led_work()` before `i2c_del_adapter()`. [F338, F341]

## Object Lifetimes
- In `hi3110_can_ist()`, `sja1000_err()`, `sun4i_can_err()`, and `ems_usb_rx_err()`, finish all writes to `cf` (including `can_change_state()`) before `netif_rx(skb)`. [F182]
- In `mcp251x` and `hi311x`, post-`register_candev()` probe errors (e.g., `mcp251x_gpio_setup()`) and `remove()` must call `unregister_candev(net)` before `destroy_workqueue(priv->wq)` and `free_candev(net)`. Enable `priv->power` (`vdd`) in probe/resume and disable in suspend/remove; enable `priv->transceiver` (`xceiver`) only while open and not suspended. [F184, F201, F315]
- In `gs_can_start_xmit()` and `gs_can_open()`, once `URB_FREE_BUFFER` is set, `usb_free_urb()` frees the buffer (do not `kfree()`). `ems_usb_start_xmit()` uses `usb_alloc_coherent()`, requiring explicit `usb_free_coherent()` in `ems_usb_write_bulk_callback()` and on error paths. In both drivers, `usb_submit_urb()` TX failure after `can_put_echo_skb()` must use `can_free_echo_skb()` (not `dev_kfree_skb()`), unanchor the URB, dec `active_tx_urbs`, and free the TX context. [F186, F187, F188]
- In `gs_can_close()`, stop `parent->rx_submitted` and `parent->timestamp` only when `--parent->active_channels == 0`, and call `usb_kill_anchored_urbs(&dev->tx_submitted)` before resetting `tx_context` and disabling `offload`. In `ems_usb_disconnect()`, call `unregister_netdev()` before `unlink_all_urbs()`, which must kill `rx_submitted` before `usb_free_coherent()` on `rxbuf[i]`. [F205, F206]
- In `peak_pci_probe()`, link `chan->prev_dev` and `pci_set_drvdata()` before `peak_pciec_probe()`, which must precede `register_sja1000dev()`; on error, restore `pci_set_drvdata(pdev, chan->prev_dev)` and call `free_sja1000dev(dev)`. In `peak_pci` channel teardown, save `chan->prev_dev` before `free_sja1000dev(dev)` and call `peak_pciec_remove()` only once (`!prev_dev`). In `pcan_free()` (`peak_pcmcia`), call `free_irq()` and `pcan_stop_led_timer()` before `pcan_free_channels()` and `ioport_unmap()`. [F191, F215, F284]
- In `softing`: `softing_load_fw()` must use a temp pointer for `krealloc()` and jump to `failed:` after `request_firmware()` to free both `buf` and `fw`; `softingcs_probe()` must use `platform_device_put(pdev)` (not `kfree(dev)`) after `platform_device_register()`; `softing_pdev_probe()` must run `softing_card_boot()` before sysfs/netdev creation; `softing_startstop()` must drain the IRQ via `softing_enable_irq(card, 0)` before `softing_reset_chip()`/`softing_fct_cmd()`; and `softing_pdev_remove()` must run `softing_card_shutdown()` before netdev unregistration and `iounmap()`. [F193, F194, F209, F312]
- In `ti_hecc`: probe error paths and `ti_hecc_remove()` must call `can_rx_offload_del()`, `clk_disable_unprepare()`, and `clk_put(priv->clk)` before `free_candev()`; `ti_hecc_suspend()` sets `HECC_CANMC_PDR` before `clk_disable_unprepare()`, and `ti_hecc_resume()` enables `clk` before clearing `HECC_CANMC_PDR`. In `sun4ican_open()`/`sun4ican_close()`, unwind `open_candev()`, `request_irq()`, `reset_control_deassert()`, `clk_prepare_enable()`, and `sun4i_can_start()` in strict reverse order. [F195, F197, F323]

## API Contracts
- Every `net_device_ops` table must set `.ndo_change_mtu = can_change_mtu`. Drivers with `CAN_CTRLMODE_CC_LEN8_DLC` (`sja1000`, `gs_usb`) must use `can_get_cc_dlc()` on TX and `can_frame_set_cc_len()` on RX. [F343, F351]
- Callers of `alloc_sja1000dev(0)` must assign `priv->priv` manually. Before `register_sja1000dev(dev)`, frontends must set `read_reg`, `write_reg`, `reg_base`, `cdr`, `ocr`, and `flags` (including `SJA1000_CUSTOM_IRQ_HANDLER` for card-level IRQs); on failure, callers must call `free_sja1000dev(dev)`. [F183, F219, F303, F305]
- `can_rx_offload` users (`ti_hecc`, `gs_usb`) must add offload before `register_candev()`, enable/disable it in `ndo_open`/`ndo_stop`, call `can_rx_offload_irq_finish()` after queueing in IRQ/URB context, and call `can_rx_offload_del()` on `register_candev()` failure or after `unregister_candev()`. `ti_hecc_mailbox_read()` must always clear `HECC_CANRMP`, return `ERR_PTR` on drop/error, and leave `rx_packets`/`rx_bytes` to NAPI. [F196, F348, F349]
- In `gs_usb`, gate `can_eth_ioctl_hwts()`/`can_ethtool_op_get_ts_info_hwts()` on `GS_CAN_FEATURE_HW_TIMESTAMP`, call `gs_usb_set_timestamp()` before `can_rx_offload_get_echo_skb_queue_timestamp()`, send `GS_USB_BREQ_BT_CONST_EXT` only when both `GS_CAN_FEATURE_FD` and `GS_CAN_FEATURE_BT_CONST_EXT` are set, and enable `GS_CAN_FEATURE_IDENTIFY` only when `sw_version > 1`. In `sun4i_can` and `ti_hecc`, write bittiming, acceptance filters (with `priv->acp_offset`), and mode registers only in reset/init mode. [F251, F318, F325, F350]

## Error Handling
- `sja1000_probe_chip()` returns `0` when absent and `-1` when present. In `sja1000_interrupt()`, if `sja1000_err()` returns non-zero (e.g., `IRQ_WAKE_THREAD`), preserve `IRQ_WAKE_THREAD` in `ret` and `break`. [F217, F276]
- `peak_pci_probe()` must wrap return values in `pcibios_err_to_errno(err)`. In `plx_pci_add_card()` and `softing_pdev_probe()`, reset `card->net_dev[i]` or `card->net[j]` to `NULL` after freeing a failed channel. `_softing_fct_cmd()` returns positive `DPRAM_FCT_RESULT` values, whereas `softing_fct_cmd()` converts `ret > 0` to `-EIO`. [F220, F222, F223]
- In `hi311x` and `mcp251x`, check `devm_regulator_get_optional()` pointers (`power`, `transceiver`) with `IS_ERR_OR_NULL()`, never a plain NULL check. In `gs_usb_receive_bulk_callback()`, per-frame drops after `urb->status == 0` must jump to `resubmit_urb`. [F224, F283]

## External Contracts
- In `gs_usb`: discover bulk pipes via `usb_find_common_endpoints()`; pass `dev->channel` in `wValue` and `0` in `wIndex` for per-channel control requests (vs `value = 1, index = bInterfaceNumber` for `HOST_FORMAT`/`DEVICE_CONFIG`); compute `icount = dconf.icount + 1` and reject `> GS_MAX_INTF`; and in `gs_usb_get_state()`, convert `ds.state` with `le32_to_cpu()` and reject `>= CAN_STATE_MAX`. In `ems_usb`, bulk transfers start at `CPC_HEADER_SIZE` (4), and `ems_usb_read_bulk_callback()` must advance `start` by `CPC_MSG_HEADER_LEN + msg->length` and break if `start > urb->transfer_buffer_length`. [F230, F257, F261, F262, F324]

## Known Pitfalls
- In `softing`: use `le16_to_cpup()`/`le32_to_cpup()` in `fw_parse()` and `softing_handle_1()`; bound unaligned/unterminated `dat` from `fw_parse()` by `len` (`strncmp`, `%.*s`); sum `addr`, `len`, and signed `offset` in 32-bit `uint32_t` arithmetic in `softing_load_fw()` before checking `> size`; advance `ptr` by 1 byte after a 2-byte standard ID in `softing_netdev_start_xmit()`; access odd-offset `DPRAM_FCT_HOST` (0x032b) via 8-bit `iowrite8()`/`ioread8()` pairs with `wmb()`/`rmb()`; and use `do_div(rawl, card->pdat->freq ?: 16)` for timestamps. [F264, F266, F285, F286, F301, F313]
- In `sp_populate_of()`, check `prop != 0` before dividing and `divider > 1` before `divider / 2 - 1`. In `peak_pcmcia`, check `pcan_pccard_present(card)` in `pcan_free_channels()` and `pcan_isr()`. In `mcp251x`, check `!mcp251x_gpio_is_input(offset)` before passing `offset - MCP251X_GPIO_RX0BF` to `BFPCTRL_BFE()`/`BFPCTRL_BFS()`. [F288, F291, F310]
