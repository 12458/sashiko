# AMD POWERPLAY AND SWSMU — drivers/gpu/drm/amd/pm (part 1)

This component provides the core Dynamic Power Management (DPM) dispatch layer, user-space telemetry and control interfaces (sysfs, hwmon, and debugfs), and the legacy DPM implementation (including Kaveri/Kabini SMU7 fusion support) for the AMDGPU driver, mediating clock, voltage, fan, thermal, and power-gating transitions between DRM/display subsystems, user space, VBIOS AtomBIOS tables, and PM backends.

## Architecture & Data Flow
- Before casting `adev->powerplay.pp_handle` in `amdgpu_dpm.c`, verify `is_support_sw_smu(adev)` for `struct smu_context *`, or verify both `!is_support_sw_smu(adev)` and `!amdgpu_dpm_is_legacy_dpm(adev)` for `struct pp_hwmgr *`. [F256]
- In `amdgpu_dpm_change_power_state_locked()`, sync `adev->pm.dpm.state = adev->pm.dpm.user_state` only when both `thermal_active` and `uvd_active` are false; when `thermal_active` is true, save `adev->pm.dpm.forced_level` before `pp_funcs->force_performance_level(adev, AMD_DPM_FORCED_LEVEL_LOW)` and restore it afterward. [F154, F188]
- In `amdgpu_dpm_pick_power_state()`, keep `restart_search:` below the initial `POWER_STATE_TYPE_PERFORMANCE` -> `POWER_STATE_TYPE_INTERNAL_3DPERF` rewrite, and never jump to `restart_search` from a `POWER_STATE_TYPE_PERFORMANCE` fallback case. [F221]
- In `amdgpu_dpm_set_powergating_by_smu()`, update `adev->pm.pwr_state[block_type]` only after `pp_funcs->set_powergating_by_smu` succeeds, and bypass the `pwr_state[block_type] == pwr_state` early return for `AMD_IP_BLOCK_TYPE_VCN` when `adev->vcn.num_vcn_inst > 1`. [F184]
- In `amdgpu_dpm_get_display_cfg()`, densely pack only enabled CRTCs into `adev->pm.pm_display_cfg.displays[num_crtcs++]` with `cfg->num_display = num_crtcs` (never index by `crtc_id`), and check `amdgpu_crtc->hw_mode.clock != 0` before dividing `vblank_in_pixels * 1000` by `hw_mode.clock`. [F200, F231]
- In `amdgpu_parse_extended_power_table()`, check `le16_to_cpu(power_info->pplib.usTableSize) >= sizeof(struct _ATOM_PPLIB_POWERPLAYTABLE3/4/5)` and non-zero sub-table offsets before reading `pplib3`/`pplib4`/`pplib5`; clamp `adev->pm.dpm.num_of_vce_states` to `AMD_MAX_VCE_LEVELS` (and check `idx < num_of_vce_states` in `amdgpu_get_vce_clock_state()`). [F205, F207]
- In `struct amdgpu_cac_leakage_table`, select the active `union amdgpu_cac_leakage_entry` variant via `adev->pm.dpm.platform_caps & ATOM_PP_PLATFORM_CAP_EVV` (`vddc1`/`vddc2`/`vddc3` when set, `vddc`/`leakage` when clear). [F180]
- In `amdgpu_set_pp_od_clk_voltage()` and `amdgpu_distribute_custom_od_settings()`, committing OverDrive (`PP_OD_COMMIT_DPM_TABLE`) via `amdgpu_dpm_odn_edit_dpm_table()` must be followed by `amdgpu_dpm_dispatch_task(adev, AMD_PP_TASK_READJUST_POWER_STATE, NULL)`. [F194]
- In `amdgpu_od_set_init()`, if no OverDrive sub-features are supported (`list_is_singular(&adev->pm.od_kobj_list)` with only `top_set`), call `amdgpu_od_set_fini()` to remove the empty `gpu_od` directory. [F258]
- In `amdgpu_read_mask()`, validate `ret == 0 && level <= 31` before computing `1 << level` into the `uint32_t` bitmask. [F214]
- In `pp_od_clk_voltage_attr_update()`, keep the `IP_VERSION(9, 4, 3)`, `IP_VERSION(9, 4, 4)`, and `IP_VERSION(9, 5, 0)` early return ahead of `if (!(attr->flags & mask))` so `pp_od_clk_voltage` (which lacks `ATTR_FLAG_ONEVF`) works in one-VF SR-IOV mode on those GC versions. [F217]
- In `kv_dpm.c`, `adev->pm.dpm.dyn_state.vddc_dependency_on_sclk` is optional (`count == 0` when absent); every consumer (such as `kv_program_bootup_state()`) must check `table && table->count` and fall back to `pi->sys_info.sclk_voltage_mapping_table` or `pi->sys_info.vid_mapping_table`. [F182]
- In `kv_dpm_init()`, run `kv_construct_boot_state()` before `kv_parse_power_table()`; inside `kv_parse_power_table()`, call `kv_parse_pplib_non_clock_info()` after the `kv_parse_pplib_clock_info()` loop for each state. [F225]
- `kv_update_current_ps()` and `kv_update_requested_ps()` must copy both `*rps` into `pi->current_rps`/`pi->requested_rps` and `*kv_get_ps(rps)` into `pi->current_ps`/`pi->requested_ps`, then rebind `ps_priv` and `adev->pm.dpm.current_ps`/`requested_ps` to those copies. [F243]
- In `kv_dpm_enable()`, call `kv_process_firmware_header()` before any SMU SRAM table uploads (populates `pi->dpm_table_start` and `pi->soft_regs_start`), and call `kv_set_thermal_temperature_range()` (when `kv_is_internal_thermal_sensor()`) before `amdgpu_irq_get()` unmasks `AMDGPU_THERMAL_IRQ_LOW_TO_HIGH`/`HIGH_TO_LOW`. [F248, F249]
- In `kv_dpm_suspend()`, cancel `thermal.work`, disable DPM, and reset `current_ps` and `requested_ps` to `boot_ps` (preserving `user_state`/`forced_level`) so `kv_dpm_resume()` transitions cleanly from `boot_ps` back to `user_state`. [F197]
- In `kv_enable_didt()`, bracket `didt_config_kv` programming and `kv_do_enable_didt()` with `amdgpu_gfx_rlc_enter_safe_mode(adev, 0)` and `amdgpu_gfx_rlc_exit_safe_mode(adev, 0)` on all return paths. [F196]
- In `kv_dpm.c`, `pi->lowest_valid` and `pi->highest_valid` form an inclusive range `[lowest_valid, highest_valid]` into `pi->graphics_level`; `kv_calculate_ds_divider()`, `kv_calculate_nbps_level_settings()`, and `kv_calculate_dpm_settings()` must reject `lowest_valid > highest_valid` with `-EINVAL`. [F209]
- Terminate `kv_pt_config_reg` tables passed to `kv_program_pt_config_registers()` with `{ 0xFFFFFFFF }` and clock-gating flag tables (`clocks[]`) passed to `amdgpu_parse_cg_state()` with `{ 0, NULL }`. [F211]

## Synchronization
- `amdgpu_set_power_dpm_force_performance_level()` must hold `adev->pm.stable_pstate_ctx_lock` across `amdgpu_dpm_force_performance_level()` (lock order: `stable_pstate_ctx_lock` -> `adev->pm.mutex`) and clear `adev->pm.stable_pstate_ctx = NULL` on success. [F153]
- `amdgpu_dpm_compute_clocks()` must update display bandwidth (if `num_crtc != 0`) and drain ready rings via `amdgpu_fence_wait_empty()` before acquiring `adev->pm.mutex`; callers must never hold `adev->pm.mutex` when calling `amdgpu_dpm_compute_clocks()`, whereas `amdgpu_legacy_dpm_compute_clocks()` and `amdgpu_dpm_change_power_state_locked()` require `adev->pm.mutex` held. [F253, F266]
- `kv_dpm_sw_init()` must `INIT_WORK(&adev->pm.dpm.thermal.work, ...)`, allocate `priv`/`ps`, and set `current_ps`/`requested_ps`/`boot_ps` before `kv_dpm_hw_init()` enables thermal IRQs or sets `adev->pm.dpm_enabled = true`; `kv_dpm_suspend()` (`cancel_work_sync`) and `kv_dpm_sw_fini()` (`flush_work`) must drain `thermal.work` without holding `adev->pm.mutex` and before `kv_dpm_fini()` frees `ps`/`priv`. [F161, F162]
- `kv_dpm_process_interrupt()` (IRQ context) and `kv_dpm_set_interrupt_state()` (atomic under `adev->irq.lock`) must never sleep or acquire `adev->pm.mutex`; `kv_dpm_process_interrupt()` only sets `thermal.high_to_low` and queues `thermal.work`, and `kv_dpm_set_interrupt_state()` only uses IRQ-safe `RREG32_SMC`/`WREG32_SMC`. [F264, F272]
- When iterating `mgpu_info.gpu_ins` (e.g., in `amdgpu_show_powershift_percent()`), hold `mgpu_info.mutex` during the lookup and release it before calling `amdgpu_pm_get_sensor_generic()` on the peer `adev`. [F164]
- In `amdgpu_od_set_init()`, initialize `INIT_LIST_HEAD(&container->attribute)` and `container->priv = adev` on `top_set` and `sub_set` before `sysfs_create_file()` publishes any attribute on that `kobj`. [F166]

## Object Lifetimes
- Runtime sysfs, hwmon, and debugfs handlers in `amdgpu_pm.c` that touch hardware or DPM state must gate access with `amdgpu_pm_get_access()` (writes/debugfs) or `amdgpu_pm_get_access_if_active()` (read telemetry) and release via `amdgpu_pm_put_access()` on all exit paths. [F165]
- Each `struct od_kobj` on `adev->pm.od_kobj_list` is freed by `od_kobj_release()` via `kobject_put(&container->kobj)`; `amdgpu_od_set_fini()` (and `amdgpu_od_set_init()` error paths after `kobject_init_and_add()`) must `sysfs_remove_file()` and `kfree()` every `struct od_attribute` before `kobject_put()`, and must never `kfree(container)` directly. [F147]
- In `amdgpu_pm_sysfs_init()`/`fini()`, `amdgpu_pm_policy_attr_group` and `amdgpu_board_attr_group` are devres-managed (`devm_device_add_group`) and must not be manually removed, whereas `int_hwmon_dev`, `pm_attr_list`, and `od_kobj_list` must be explicitly cleaned up in `amdgpu_pm_sysfs_fini()`. [F255]
- `amdgpu_parse_extended_power_table()` returns on allocation failure without internal rollback; every table allocated in `adev->pm.dpm.dyn_state` must be freed in `amdgpu_free_extended_power_table()`, and `kv_dpm_sw_init()` must call `kv_dpm_fini()` (which calls `amdgpu_free_extended_power_table()`) if `kv_dpm_init()` fails. [F149]
- In `kv_dpm_powergate_uvd()` and `kv_dpm_powergate_vce()`, gating (`gate == true`) must call `amdgpu_device_ip_set_powergating_state()`, disable block DPM, then send `PPSMC_MSG_UVDPowerOFF`/`VCEPowerOFF`; ungating (`gate == false`) must reverse this: power on via SMU, enable block DPM, then ungate the IP block. [F156]

## API Contracts
- `amdgpu_dpm_get_gpu_metrics()`, `amdgpu_dpm_get_pp_table()`, `amdgpu_dpm_get_smu_prv_buf_details()`, and `amdgpu_dpm_get_vce_clock_state()` output borrowed driver-owned pointers that callers must never `kfree()`, whereas `amdgpu_dpm_get_pm_metrics()` copies into a caller-preallocated buffer. [F146]
- Sysfs show handlers for `amdgpu_dpm_get_pp_table()` and `amdgpu_dpm_get_gpu_metrics()` must check `size > 0` and clamp `size` to `PAGE_SIZE - 1` before `memcpy()`; handlers for `amdgpu_dpm_get_temp_metrics()` must first pass `table = NULL` to get `size` and verify `size > 0 && size < PAGE_SIZE` before passing `buf`. [F238, F239]
- `kv_dpm_read_sensor()` requires `*size >= 4` on entry (returning `-EINVAL` otherwise); callers of `amdgpu_dpm_read_sensor()` or `pp_funcs->read_sensor` must initialize `*size` to the buffer byte capacity (`>= 4`) before calling. [F237]
- When formatting clock levels into `buf`, pass the base `buf` and in/out `&size` to `amdgpu_dpm_emit_clock_levels()`, but pass `buf + size` to the fallback `amdgpu_dpm_print_clock_levels()` and add its return value to `size`. [F247]
- Although declared returning `enum pp_smu_status`, `amdgpu_dpm_get_uclk_dpm_states()` returns `0` on success or a negative errno (`-EOPNOTSUPP`); store its return value in a signed `int` before mapping to `PP_SMU_RESULT_*`. [F168]
- When calling `amdgpu_dpm_set_power_profile_mode(adev, input, size)`, `size` is the count of custom heuristic parameters (`0` for non-custom profiles), and `profile_mode` must be stored at `input[size]` without incrementing `size`. [F174]
- In `parse_input_od_command_lines()`, on `'r'` (reset), save the caller's initial `*type` into `params[0]` and set `*num_of_params = 1` before overwriting `*type = PP_OD_RESTORE_DEFAULT_TABLE`. [F183]
- Every `amdgpu_dpm_enable_*` helper delegating to `amdgpu_dpm_set_powergating_by_smu()` (and `kv_update_{uvd,samu,acp}_dpm()` calling `kv_enable_*_dpm()`) must negate the boolean enable/gate argument (`!enable` or `!gate`). [F220]
- `amdgpu_dpm_is_baco_supported()` must return `0` whenever `adev->in_s3` is true, without querying `pp_funcs->get_asic_baco_capability`. [F257]
- When `.attr_update` callbacks (`pp_dpm_dcefclk_attr_update`, `pp_dpm_clk_default_attr_update`, `default_attr_update`) downgrade an attribute to read-only, they must both clear write bits in `dev_attr->attr.mode` and set `dev_attr->store = NULL`. [F284]
- `amdgpu_hwmon_show_power_cap_generic()` and `amdgpu_hwmon_set_power_cap()` convert between hwmon microWatts and DPM Watts (factor `1,000,000`), and `amdgpu_hwmon_set_power_cap()` must OR `(limit_type << 24)` (`enum pp_power_type`) into the `uint32_t` passed to `amdgpu_dpm_set_power_limit()`. [F280]
- In `amdgpu_kv_send_msg_to_smc_with_parameter()` and `amdgpu_kv_notify_message_to_smu()`, write `mmSMC_MSG_ARG_0` before `mmSMC_MESSAGE_0` and bound `mmSMC_RESP_0` polling by `adev->usec_timeout`. [F261]
- `amdgpu_kv_read_smc_sram_dword()` requires 4-byte aligned `smc_address` (`(smc_address & 3) == 0`) with `smc_address + 3 <= limit`, whereas `amdgpu_kv_copy_bytes_to_smc()` handles unaligned starts/lengths within `limit` by read-modify-writing partial 32-bit big-endian dwords at `mmSMC_IND_DATA_0`. [F181, F198]

## Error Handling
- In `amdgpu_dpm_force_performance_level()`, `amdgpu_dpm_enter_umd_state()` and `amdgpu_dpm_exit_umd_state()` must run outside `adev->pm.mutex`; if `pp_funcs->force_performance_level()` fails, unlock `adev->pm.mutex` and call the inverse UMD helper to roll back. [F152]

## External Contracts
- Kaveri SMU7 SRAM (`SMU7_Fusion_DpmTable`) is big-endian: byte-swap multi-byte fields with `cpu_to_be16()`/`cpu_to_be32()` before `amdgpu_kv_copy_bytes_to_smc()`, and read them back with `be32_to_cpu()`. [F273]
- In `amdgpu_set_pp_force_state()`, check `idx < ARRAY_SIZE(data.states)`, clamp `idx` with `array_index_nospec()`, and reject `POWER_STATE_TYPE_INTERNAL_BOOT` and `POWER_STATE_TYPE_DEFAULT` before dispatching `AMD_PP_TASK_ENABLE_USER_STATE`. [F278]
- `AMDGPU_PP_SENSOR_GFX_SCLK`/`MCLK` return 10 kHz units (`* 10000` for Hz in hwmon, `/ 100` for MHz in debugfs), while `AMDGPU_PP_SENSOR_GPU_AVG_POWER`/`INPUT_POWER` return 8-bit fixed-point Watts converted in `amdgpu_hwmon_get_power()` as `(query >> 8) * 1000000 + (query & 0xff) * 1000` uW. [F281]
- `amdgpu_hwmon_set_pwm1()` and `amdgpu_hwmon_set_fan1_target()` must verify via `amdgpu_dpm_get_fan_control_mode(adev, &pwm_mode)` that `pwm_mode == AMD_FAN_CTRL_MANUAL` before setting fan speed, returning `-EINVAL` (`pwm1`) or `-ENODATA` (`fan1_target`) otherwise. [F282]

## Known Pitfalls
- In `amdgpu_pm.c`, sysfs callbacks on `adev->dev` (`amdgpu_device_attrs`, `board_attrs`, `pm_policy_attrs`) must extract `adev` via `drm_to_adev(dev_get_drvdata(dev))`, `hwmon_attributes` callbacks on `adev->pm.int_hwmon_dev` get `struct amdgpu_device *` directly from `dev_get_drvdata(dev)`, and OverDrive (`struct od_feature_ops`) callbacks get `adev` via `container_of(kobj, struct od_kobj, kobj)->priv` (never `kobj_to_dev(kobj)`). [F245, F246]
- In `hwmon_attributes_visible()`, the GC 9.4.3/9.4.4/9.5.0 check returning `attr->mode` for `sensor_dev_attr_temp2_emergency` and `sensor_dev_attr_temp3_emergency` must stay above the general `(adev->flags & AMD_IS_APU) || gc_ver < IP_VERSION(9, 0, 0)` check. [F218]
- In sysfs parsers using `strsep(&tmp_str, delimiter)` (`amdgpu_set_pp_od_clk_voltage`, `amdgpu_set_pp_power_profile_mode`, `parse_input_od_command_lines`), check `if (!tmp_str) break;` before `isspace(*tmp_str)` or `skip_spaces(tmp_str)`; in `amdgpu_set_pp_od_clk_voltage()`, multi-char prefixes (`"vc"`, `"vo"`) must precede matching single-char `*buf ==` checks and advance `tmp_str` past all prefix chars before `while (isspace(*++tmp_str));`. [F219, F226]
- In `amdgpu_dpm_set_sclk_od()` and `amdgpu_dpm_set_mclk_od()`, when `amdgpu_dpm_dispatch_task(adev, AMD_PP_TASK_READJUST_POWER_STATE, NULL)` returns `-EOPNOTSUPP`, reset `adev->pm.dpm.current_ps = adev->pm.dpm.boot_ps` before calling `amdgpu_dpm_compute_clocks(adev)`. [F189]
- `kv_patch_voltage_values()` converts `uvd`, `vce`, `samu`, and `acp` dependency table `.v` fields in place from 8-bit VID indices to mV during `kv_dpm_init()`, while `vddc_dependency_on_sclk` stays raw 8-bit VID indices (which are inverted: `6200 - voltage * 25`); convert raw VID indices via `kv_convert_8bit_index_to_voltage()` before comparing against mV thresholds like `pi->high_voltage_t`, and never re-convert already-patched tables. [F191, F235]
- In `amdgpu_parse_extended_power_table()`, VBIOS VCE, UVD, SAMU, and ACP tables start with a 1-byte `revid` followed by packed variable-length sub-tables (must offset by `+ 1` plus preceding array byte sizes); in `kv_parse_power_table()`, advance `power_state_offset` by `2 + power_state->v2.ucNumDPMLevels`, index `clockInfo` by `clock_array_index * clock_info_array->ucEntrySize`, and cap levels at `SUMO_MAX_HARDWARE_POWERLEVELS`. [F208, F242]
- In `kv_dpm.c`, reverse loops over DPM levels with an unsigned `u32` counter (`kv_program_bootup_state`, `kv_set_valid_clock_range`, `kv_force_dpm_highest`, `kv_get_sleep_divider_id_from_clock`) must test `i > 0` (falling back to index 0), whereas loops testing `i >= 0` (`kv_get_high_voltage_limit`, `kv_apply_state_adjust_rules`) must use a signed `int` counter. [F210]
