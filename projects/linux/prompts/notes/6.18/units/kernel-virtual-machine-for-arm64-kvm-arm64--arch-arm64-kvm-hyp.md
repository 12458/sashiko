# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64) — arch/arm64/kvm/hyp

`arch/arm64/kvm/hyp` implements the EL2 hypervisor execution engine and page-table library for KVM/arm64 across common (`pgtable.c`, `vgic-v3-sr.c`, `exception.c`, `aarch32.c`, `include/hyp/`), VHE (`vhe/`), and nVHE/pKVM (`nvhe/`) code.

## Architecture & Data Flow

- `vm_table` indices are offset from `pkvm_handle_t` by `HANDLE_OFFSET` (`0x1000`), and `init_pkvm_hyp_vm()` sets `mmu->vmid.id = idx + 1` (0 is `host_mmu`). `get_vm_by_handle()` rejects `RESERVED_ENTRY` and `idx >= KVM_MAX_PVMS`. Check `vcpu_idx < hyp_vm->kvm.created_vcpus` under `vm_table_lock`, size `pkvm_hyp_vm` via `pkvm_get_hyp_vm_size(nr_vcpus)`, and set `hyp_vcpu->vcpu.kvm = &hyp_vm->kvm`. [F232, F271, F272, F310, F317]
- `pkvm_init_features_from_host()` copies `ctr_el0` and `KVM_ARCH_FLAG_MTE_ENABLED` to `hyp_vm->kvm.arch` for `pkvm_vcpu_reset_hcr()`, and `midr_el1` when `KVM_ARCH_FLAG_WRITABLE_IMP_ID_REGS`. `pvm_init_traps_hcr()` sets `HCR_TERR | HCR_TEA` and clears `HCR_FIEN` only when `!kvm_has_feat(kvm, ID_AA64PFR0_EL1, RAS, IMP)`. `flush_hyp_vcpu()`/`handle___pkvm_vcpu_load()` only copy `HCR_TWI | HCR_TWE` from `host_vcpu->arch.hcr_el2`, and `flush/sync_hyp_vcpu()` call `flush/sync_debug_state()`. [F247, F248, F249, F267, F285]
- `host_stage2_set_owner_locked()` updates both `host_mmu.pgt` owner annotations and `hyp_vmemmap` `__host_state` under `host_mmu.lock`. `host_stage2_force_pte_cb()` forces PTE mappings when `prot` is not `PKVM_HOST_MEM_PROT`/`MMIO_PROT`. `get/set_hyp_state()` XOR with `PKVM_PAGE_STATE_MASK` so zeroed `hyp_vmemmap` is `PKVM_NOPAGE`. `__pkvm_host_share/unshare_guest()` update `host_share_guest_count`, `set_host_state()`, and guest Stage-2 PTEs (`PKVM_PAGE_SHARED_BORROWED`) under `host_mmu.lock` and `vm->lock`, resetting `PKVM_PAGE_OWNED` only at count 0 (and rejecting `PKVM_PAGE_SHARED_OWNED` at count 0 with `-EPERM`). [F255, F256, F257, F280, F291]
- In `nvhe/sys_regs.c`, `pvm_sys_reg_descs[]` must be strictly ascending by `(Op0, Op1, CRn, CRm, Op2)` with no duplicates, `pvm_ftr_bits` arrays must end with `FEAT_END`, and `kvm_handle_pvm_sys64()` must call `kvm_hyp_handle_sysreg()` before `kvm_handle_pvm_sysreg()`. [F273, F274, F288]
- When `guest_owns_fp_regs()` and `vcpu_has_sve(vcpu)` hold, `fpsimd_lazy_switch_to_guest/host()` eagerly switch `SYS_ZCR` at EL1/EL2. In nVHE SVE save/restore, set `SYS_ZCR_EL2` to `sve_vq_from_vl(kvm_host_sve_max_vl) - 1` (host) and `vcpu_sve_max_vq(vcpu) - 1` clamped to `kvm_host_sve_max_vl` (guest). `__activate_cptr_traps()` dynamically recomputes `cptr_el2`/`cpacr_el1` and `fpexc32_el2` on trap activation and after `kvm_hyp_handle_fpsimd()` or `kvm_hyp_handle_cpacr_el1()`. [F250, F251, F268]
- In `__compute_hcr()`, when `vcpu_has_nv(vcpu)` and `is_hyp_ctxt(vcpu)` hold, merge only RES1 bits from `kvm_vcpu_apply_reg_masks(vcpu, HCR_EL2, 0) & ~NV_HCR_GUEST_EXCLUDE`, never raw guest `HCR_EL2`. `to_hw_pstate()` maps virtual `PSR_MODE_EL2t/h` to `PSR_MODE_EL1t/h`, so `__compute_hcr()` sets `VCPU_IN_HYP_CONTEXT` and `fixup_guest_exit()` restores `PSR_MODE_EL2*`. When `HCR_VSE` is set, `___activate/deactivate_traps()` use `vserror_state_is_nested(vcpu)` to pick between `vcpu->arch` and `vcpu->arch.ctxt` `HCR_EL2`/`VSESR_EL2`. [F252, F253, F254]
- Wire fast EL2 exit handlers across `vhe/switch.c:hyp_exit_handlers`, `nvhe/switch.c:hyp_exit_handlers`, and `pvm_exit_handlers`. `__kvm_adjust_pc()` clears `PENDING_EXCEPTION | EXCEPT_MASK` or `INCREMENT_PC` once applied. `__kvm_unexpected_el2_exception()` saves `elr_el2` into `this_cpu_ptr(&kvm_hyp_ctxt)->sys_regs[ELR_EL2]` before setting `elr_el2` to `__guest_exit_restore_elr_and_panic`. [F262, F263, F264]
- In nVHE `__kvm_vcpu_run()`, `__debug_save_host_buffers_nvhe()` + `dsb(nsh)` precede guest sysreg/`mdcr_el2` load, and `__debug_restore_host_buffers_nvhe()` follows `__sysreg_restore_state_nvhe(host_ctxt)`. `__sysreg32_restore_state(vcpu)` precedes 64-bit sysreg restore, which in nVHE precedes `__load_stage2()`. On nVHE with `ARM64_WORKAROUND_SPECULATIVE_AT`, `__sysreg_restore_el1_state()`/`__deactivate_traps()` set `TCR_EPD1_MASK | TCR_EPD0_MASK` + `isb()` and `SCTLR_ELx_M` before Stage-2 switch, restoring `SCTLR_EL1` + `isb()` + `TCR_EL1` after. [F322, F323, F324]
- Gate optional sysregs (`TCR2_EL1`, `PIR_EL1`, `PIRE0_EL1`, `POR_EL1`, `SCTLR2_EL1`, `_EL2`) with `ctxt_has_*()` (CPU cap + `kvm_has_*()`), and save/restore `SYS_POR_EL0` in `__sysreg_{save,restore}_common_state()`. Guard `HAFGRTR_EL2` with `cpu_has_amu()`, `*TR2_EL2` FGT regs with `ARM64_HAS_FGT2`, and shift `CNTHCTL_EL1PCTEN/PCEN` left by 10 in `nvhe/timer-sr.c` when `has_hvhe()`. [F320, F333, F334, F347]
- In `__vgic_v3_activate_traps()`, check `!(cpu_if->vgic_hcr & ICH_HCR_EL2_En)` before `else if (!cpu_if->vgic_sre)`. When `!cpu_if->vgic_sre`, write `0` to `ICC_SRE_EL1` + `isb()` before `ICH_VMCR_EL2` and `__vgic_v3_restore_state()`; save needs `dsb(sy)` + `isb()` before reading `ICH_*`, and restore/activate need `isb()` + `dsb(sy)` after writing `ICH_*`. `__vgic_v3_get_gic_config()` returns early if `ARM64_HAS_GICV5_CPUIF`, and masks IRQs (VHE) or sets `HCR_AMO | HCR_FMO | HCR_IMO` + `isb()` (nVHE) before clearing `ICC_SRE_EL1`. [F289, F326, F327, F328]
- Stage-2 TLBI (`ipas2e1*`) requires `dsb(ish/nsh)` before Stage-1 TLBI (`vmalle1*`). `nvhe/tlb.c:exit_vmid_context()` requires an unconditional `isb()` after `__load_stage2()`/`__load_host_stage2()`. On VHE, an `isb()` must follow `__deactivate_traps()` before `fpsimd_lazy_switch_to_host()`/`__fpsimd_save_fpexc32()`, and follow `__deactivate_cptr_traps()` before FP/SVE/FPMR access. [F341, F343, F346]
- `pkvm_create_stack()` aligns `2 * NVHE_STACK_SIZE` VAs and maps the upper half. `__pkvm_init_finalise()` runs `fix_host_ownership()` and `fix_hyp_pgtable_refcnt()` after `hyp_pool_init()`. `__kvm_host_psci_cpu_entry()` writes `INIT_SCTLR_EL1_MMU_OFF` to `SYS_SCTLR` and `INIT_PSTATE_EL1` to `SPSR_EL2` before `__host_enter()`. `stage2_set_prot_attr()` rejects `KVM_PGTABLE_PROT_DEVICE | KVM_PGTABLE_PROT_NORMAL_NC` with `-EINVAL`, `kvm_pgtable_walk_continue()` stops on `-EAGAIN` only with `KVM_PGTABLE_WALK_HANDLE_FAULT`, and page-table `level` variables must be signed (`s8`/`int`). [F276, F292, F295, F303, F318, F330]

## Synchronization

- Lock ordering: `vm_table_lock` outside `host_mmu.lock` (`host_lock_component()`) and `pkvm_pgd_lock` (`hyp_lock_component()`); `host_lock_component()` before `hyp_lock_component()` or `guest_lock_component(vm)` (`vm->lock`, which brackets any `vm->pgt` walk using `vm->mm_ops`/`current_vm->pool`). `host_mmu.lock` guards `__host_state` and `host_share_guest_count`; `pkvm_pgd_lock` guards `__hyp_state_comp`, `pkvm_pgtable`, and `__io_map_base`; `vm->lock` guards guest Stage-2 PTEs; `vm_table_lock` guards `vm_table`, `hyp_vm` refcounts, `loaded_hyp_vcpu`, `hyp_vm->vcpus[]`, and `kvm_init_pvm_id_regs()`. [F198, F214, F215, F217, F218, F220]
- In `nvhe/ffa.c`, hold `host_buffers.lock` across `memcpy()`ing `host_buffers.tx` into `hyp_buffers.tx` before parsing descriptors, calling `ffa_host_share_ranges()`, and issuing the SMC. Set `has_version_negotiated` via `smp_store_release()` after writing `hyp_ffa_version` and `hyp_ffa_post_init()` under `version_lock`, paired with `smp_load_acquire()` in `kvm_host_ffa_handler()`. [F208, F219, F258]
- In `hyp_map_walker_try_leaf()`, `hyp_map_walker()`, and `stage2_make_pte()`, child table init, cache maintenance (`dcache_clean_inval_poc`/`icache_inval_pou` after `stage2_try_break_pte()`), and `mm_ops->get_page(ctx->ptep)` must precede `smp_store_release(ctx->ptep, new)`. `KVM_PGTABLE_WALK_SHARED` walks hold `rcu_read_lock()` (`-EPERM` at EL2), update PTEs via `stage2_try_set_pte()` (`cmpxchg`), and lock broken PTEs with `KVM_INVALID_PTE_LOCKED` in `stage2_try_break_pte()`. [F211, F223, F349]
- `__apply_guest_page()` maps guest pages via per-CPU `hyp_fixmap_map/unmap()` or PMD `hyp_fixblock_map/unmap()` (holding `hyp_fixblock_lock`), and `fixmap_clear_slot()` uses `vale2is` TLBI. On VHE, `enter/exit_vmid_context()` and `__vcpu_load_activate_traps()`/`__vcpu_put_deactivate_traps()` disable local IRQs. Snapshot untrusted `host_kvm`/`host_vcpu` fields once via `READ_ONCE()`. [F221, F224, F344, F345, F348]

## Object Lifetimes

- `stage2_pte_is_counted()` counts valid and non-zero invalid PTEs, so `stage2_try_break_pte()`, `stage2_make_pte()`, and `stage2_map_walker_try_leaf()` balance `get/put_page()` on `ctx->ptep`, and `stage2_map_walk_leaf()` calls `put_page(childp)` if `stage2_try_break_pte()` fails. `fixmap_clear_slot()` clears `KVM_PTE_VALID` without `put_page()`. [F191, F200]
- `get_pkvm_hyp_vm()`, `get_np_pkvm_hyp_vm()`, and `pkvm_load_hyp_vcpu()` take a `hyp_page` refcount on `hyp_vm` under `vm_table_lock` (released via `put_pkvm_hyp_vm()`/`pkvm_put_hyp_vcpu()`), whereas `get_vm_by_handle()` and `pkvm_get_loaded_hyp_vcpu()` return borrowed pointers. In `__pkvm_teardown_vm()`, under `vm_table_lock`, verify `hyp_page_count(hyp_vm) == 0`, call `__kvm_tlb_flush_vmid()`, and `remove_vm_table_entry()` before unlocking, keeping `host_kvm` pinned until `reclaim_pgtable_pages()`, `unpin_host_vcpus()`, draining `pkvm_memcache`, and `teardown_donated_memory()` finish. `hyp_pin_shared_mem()` maps at `refcount` 0->1, `hyp_unpin_shared_mem()` unmaps at 1->0, and `__pkvm_host_unshare_hyp()` returns `-EBUSY` if `hyp_page_count() != 0`. [F192, F195, F196, F212]
- In `nvhe/page_alloc.c`, modify `hyp_page` refcounts and buddy lists under the same `pool->lock` critical section, split high-order allocations via `hyp_split_page()` before order-0 `hyp_put_page()`, and keep valid `p->order` only on head pages (`HYP_NO_ORDER` on tail pages; evaluate `PAGE_SIZE << p->order` before setting `HYP_NO_ORDER`). `guest_s2_zalloc_page()` zeroes pages popped from `pop_hyp_memcache()` and sets `refcount = 1`, `order = 0`. [F199, F239, F265, F306]
- In `psci_cpu_on()`, `try_acquire_boot_args()` locks `cpu_on_args`, writes `pc`/`r0`, and issues `wmb()` before `psci_call()`; on `PSCI_RET_SUCCESS` the target CPU releases it in `__kvm_host_psci_cpu_entry(true)` after reading `r0`/`pc`, otherwise `psci_cpu_on()` calls `release_boot_args()`. Save mutated host trap regs (`PMUSERENR_EL0`, `SYS_HCRX_EL2`, FGT, MPAM) into `host_data_ptr(host_ctxt)` on entry and restore on exit. Set `host_ctxt->__hyp_running_vcpu = vcpu` before guest sysreg/trap load and clear to `NULL` after host restore (`__hyp_running_vcpu != NULL` identifies `host_ctxt` in `sysreg-sr.h`). [F205, F206, F207, F210, F297, F315, F321]

## API Contracts

- `kvm_pgtable_stage2_free_unlinked()` calls `mm_ops->put_page(pgtable)` on the root table itself, so callers must not `put_page(pgtable)` again. `kvm_pgtable_stage2_split()` requires `mc` to be `&mmu->split_page_cache`. `kvm_pgtable_hyp_unmap()` requires `mm_ops->page_count` and returns unmapped bytes (`u64`), so check `!= size`. `kvm_pgtable_stage2_relax_perms()` rejects `KVM_PTE_LEAF_ATTR_HI_SW` (`PROT_SW0..3`) with `-EINVAL`. `_kvm_pgtable_walk()` rejects `addr` or `end > BIT(pgt->ia_bits)` with `-ERANGE`. [F190, F225, F282, F316, F356, F359]
- In `nvhe/mem_protect.c`, validate `[addr, addr + size)` with `range_is_memory()`/`check_range_allowed_memory()`, not `addr_is_memory()`. `__guest_check_transition_size()` restricts guest Stage-2 share/unshare/wrprotect/test_clear_young to `nr_pages == 1` or a PMD block. Pass `size = 0` to `assert_host_shared_guest()` when block mappings are possible. [F242, F266, F281]
- Pass `TLBI_TTL_UNKNOWN` (not `0` or `ctx->level`) when leaf level is unknown (`__kvm_tlb_flush_vmid_range()`, table PTE zapping). `__tlbi_level(ipas2e1*, ipa, level)` takes `ipa >> 12`, whereas `__flush_s2_tlb_range_op()` takes unshifted byte `start` and `pages`. Guard `enter/exit_vmid_context()` with `if (mmu)` in `vhe/tlb.c:__kvm_tlbi_s1e2()`. Check `fault.hpfar_el2 & HPFAR_EL2_NS` before reading `HPFAR_EL2_FIPA`. Unlink `pool->free_area` pages via `page_remove_from_list(p)` (never `list_del()`), pass 64-bit integers to `hyp_pfn_to_phys(pfn)`, and define `__pkvm_init_switch_pgd` with `SYM_TYPED_FUNC_START`. [F234, F240, F245, F246, F294, F301, F313]

## Error Handling

- In `__pkvm_init_vm()`, call `insert_vm_table_entry()` last and on error unmap `hyp_vm`/`pgd` and unpin `host_kvm`. In `__pkvm_init_vcpu()`/`init_pkvm_hyp_vcpu()`, on failure call `unpin_host_vcpu()`, clear `KVM_ARM_VCPU_SVE` on SVE failure, and call `unmap_donated_memory(hyp_vcpu, sizeof(*hyp_vcpu))` without dereferencing `hyp_vcpu` after. Restore `__io_map_base = prev_base` on error in `pkvm_create_stack()`, propagate all mapping errors in `recreate_hyp_mappings()`, and write `cpu_reg(host_ctxt, 1) = ret` before `__host_enter()` in `__pkvm_init_finalise()`. [F193, F194, F201, F237, F238]
- In `do_ffa_rxtx_map/unmap()`, unpin `tx`/`rx` before unsharing, NULL `host_buffers.tx`/`rx`, and call `ffa_unmap_hyp_buffers()`. Roll back the exact `u32` count from `__ffa_host_share/unshare_ranges()` when `< nranges`. Call `ffa_host_unshare_ranges()` on SMC failure in `__do_ffa_mem_xfer()`/`do_ffa_mem_frag_tx()`, `ffa_mem_reclaim()` on share failure in `do_ffa_mem_frag_tx()`, `ffa_rx_release(res)` on every error exit after `ffa_retrieve_req()`/`ffa_mem_frag_rx()` in `do_ffa_mem_reclaim()`, and `ffa_to_smccc_res(res, ret)` only when `ret != 0`. [F202, F203, F204, F230, F235]
- Store `allocate/find_free_vm_table_entry()` and `__pkvm_reserve_vm()` returns in a signed `int` and check `< 0`. Check `__vgic_v2/v3_perform_cpuif_access()` against `1` (handled), `0` (unhandled), and `-1` (v2 SError). Treat `!__get_fault_info()` or `-EAGAIN` from `host_stage2_idmap()` in `handle_host_mem_abort()` as a benign race. [F226, F229, F367]

## External Contracts

- Mask `ARM_SMCCC_CALL_HINTS` from `x0` in `handle_host_hcall/smc()`. Once `kvm_protected_mode_initialized` is set, reject `host_hcall` indices `< __KVM_HOST_SMCCC_FUNC___pkvm_prot_finalize`. `handle___pkvm_create_private_mapping()` writes `(unsigned long)ERR_PTR(err)` to `cpu_reg(host_ctxt, 1)` on error. Host guest-MMU hypercalls (`handle___pkvm_host_*_guest`, `handle___pkvm_tlb_flush_vmid`) must reject protected VMs. `kvm_host_psci_handler()` zeroes `cpu_reg(host_ctxt, 1..3)`, `ffa_set_retval()` copies `res->a0..a17`, and `__vgic_v2_perform_cpuif_access()` requires 4-byte aligned `sizeof(u32)` accesses (swapping with `__kvm_swab32()` when `__is_be(vcpu)`). [F228, F241, F270, F278, F279, F362, F363]

## Known Pitfalls

- `__vcpu_assign_sys_reg(vcpu, reg, val)` has opposite `(reg, val)` order to `vcpu_write_sys_reg(vcpu, val, reg)`. System register `_MASK` constants are pre-shifted (do not `<< _SHIFT`). In `nvhe/`, access `_EL12`-aliased EL1 sysregs (`SYS_PMSCR`, `SYS_TRFCR`, `SYS_BRBCR`, `SYS_SCTLR`, `SYS_TCR`) via `read/write_sysreg_el1()`, not `read/write_sysreg_s()`. In `__activate_cptr_traps_vhe()`, test nested `FPEN`/`ZEN` via `!(SYS_FIELD_GET(CPACR_EL1, FPEN/ZEN, cptr) & BIT(0))`. [F243, F244, F286, F319]
- Reload `ctx.old = READ_ONCE(*ptep)` and recompute `table` after `kvm_pgtable_visitor_cb()` in `__kvm_pgtable_visit()`. Align `ctx->addr` down to `kvm_granule_size(ctx->level)` when flushing broken table PTEs in `stage2_try_break_pte()`. Keep `end` across iterations and clamp `start = max(start, end)` in `hyp_back_vmemmap()`. [F259, F296, F342]
- Widen `pvm_ftr_bits` fields to 64-bit before `<< shift` in `get_restricted_features()`, and use `max(sys_val, pvm_max)` when `sign` is true with a negative value (`>= 1UL << (width - 1)`). In FF-A, cast `range->pg_cnt` to `u64` before `* FFA_PAGE_SIZE`, cast `struct ffa_mem_region *buf` to `(void *)` for byte offsets, and check `fraglen < offset + sizeof(struct ffa_composite_mem_region)` (as `size_t`) before `reg->constituents`. Use `u32` arithmetic in `kvm_skip_instr32()`/`enter_exception32()`. Translate host-shared pointers with `kern_hyp_va()`, pass `from + byte_size` to `hyp_pin/unpin_shared_mem()` for `void *` buffers, and give `HANDLE_FUNC(x)` handlers signature `void handle_*(struct kvm_cpu_context *)`. [F290, F300, F302, F305, F309, F311, F312, F314, F340]
