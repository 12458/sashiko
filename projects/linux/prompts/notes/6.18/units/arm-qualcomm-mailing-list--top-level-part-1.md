# ARM/QUALCOMM MAILING LIST — (top level) (part 1)

Core Qualcomm platform infrastructure (`qcom_scm`, 32-bit SMP `platsmp.c`, `qcom-cpufreq-hw`, `cpuidle-qcom-spm`, `timer-qcom`) and bus/peripheral drivers (`qcom_adm`, `i2c-qcom-geni`, `i2c-qup`, `qcom-ebi2`, `qcom-ssc-block-bus`, `qcom-rng`, `btqcomsmd`, `qcom_hwspinlock`).

## Architecture & Data Flow

- In `__scm_smc_do_quirk()`, initialize `quirk.state.a6 = 0` before the retry loop and preserve it across `QCOM_SCM_INTERRUPTED` iterations while updating `a0 = res->a0`; on `QCOM_SCM_WAITQ_SLEEP` in `__scm_smc_do_quirk_handle_waitq()`, `fill_wq_resume_args()` must zero all 8 entries of a local `struct arm_smccc_args resume` before populating `args[0..2]` and set `smc = &resume` without mutating the caller's `waitq`. `qcom_scm_assert_valid_wq_ctx()` must verify `wq_ctx == 0` before accessing `__scm->waitq_comp`. [F50, F80, F90]
- Under `__scm->scm_bw_lock`, `qcom_scm_bw_enable()` only increments `__scm->scm_vote_count` after `icc_set_bw(__scm->path, 0, UINT_MAX)` succeeds on the `0 -> 1` transition, and `qcom_scm_bw_disable()` only calls `icc_set_bw(__scm->path, 0, 0)` when `__scm->scm_vote_count-- == 1`. [F5]
- In `qcom_cpufreq_hw_read_lut()`, allocate `LUT_MAX_ENTRIES + 1` entries for `policy->freq_table`; when `dev_pm_opp_of_add_table()` succeeds, set `icc_scaling_enabled = true` and disable all DT OPPs via `for (rate = 0; ; rate++)` (incrementing `rate` after `dev_pm_opp_find_freq_ceil()` and breaking on `IS_ERR(opp)`) before re-enabling LUT-matched OPPs via `qcom_cpufreq_update_opp()`. `qcom_cpufreq_get_freq()` must clamp `reg_perf_state` to `LUT_MAX_ENTRIES - 1`. [F64, F92, F108]
- In `qcom_cpufreq_hw_target_index()` and `qcom_cpufreq_hw_fast_switch()`, when `data->per_core_dcvs` is true, write `index` to `soc_data->reg_perf_state + i * 4` for every sibling core `i` in `0 .. cpumask_weight(policy->related_cpus) - 1`. [F63]
- `spm_cpuidle_register()` must copy `qcom_spm_idle_driver` into per-CPU `data->cpuidle_driver` before setting `cpumask` and registering. `qcom_cpu_spc()` must restore `PM_SLEEP_MODE_STBY` via `spm_set_low_power_mode()` after `cpu_suspend()`. `qcom_boot_secondary()` must check `!per_cpu(cold_boot_done, cpu)` before `func(cpu)` and set `cold_boot_done = true` only when `func(cpu) == 0`. [F67, F83, F174]
- In `qcom_adm.c`, `adm_prep_slave_sg()` must snapshot `achan->mux`, `achan->crci`, and `blk_size` into `async_desc` so `adm_start_dma()` programs `ADM_CRCI_CTL` from `async_desc` (not `achan`), and when `achan->slave.device_fc` is true, validate `adm_get_blksize(burst)` and `(achan->crci & 0xf) != 0 && achan->crci <= 0x1f` before dividing by `burst`. [F77, F95]
- In `adm_prep_slave_sg()`, size `async_desc->dma_len` using `DIV_ROUND_UP` for `box_count` and `single_count` (incrementing `single_count` if `sg_dma_len(sg) % burst != 0`) plus `sizeof(*cple) + 2 * ADM_DESC_ALIGN`; align `cple` and `desc` with `PTR_ALIGN(..., ADM_DESC_ALIGN)`, shift DMA addresses `>> 3`, execute `wmb()` before writing `ADM_CH_CMD_PTR` in `adm_start_dma()`, and free unaligned `async_desc->cpl` in `adm_dma_free_desc()`. [F118, F131, F154]
- `adm_process_fc_descriptors()` and `adm_process_non_fc_descriptors()` must advance `desc` by `sizeof(*box_desc)` or `sizeof(*single_desc)` and return it; in `adm_process_fc_descriptors()`, set `ADM_CMD_LC` on `sg_is_last(sg)` on `single_desc->cmd` if `remainder != 0`, or on `box_desc->cmd` (if `box_desc` is non-NULL) when `remainder == 0`. `adm_dma_xlate()` must save a matched channel into `candidate` (not use the `list_for_each_entry` cursor after the loop). [F113, F114, F132]
- In `geni_i2c_probe()`, do not read `GENI_IF_DISABLE_RO` when `desc->no_dma_support` is set, and fall back to `desc->tx_fifo_depth` if `geni_se_get_tx_fifo_depth()` returns 0. Terminate `geni_i2c_clk_map_*` tables with `{}`. In `geni_i2c_irq()`, check transfer errors (`!cur || m_stat & (M_CMD_FAILURE_EN | M_CMD_ABORT_EN) || dm_rx_st & DM_I2C_CB_ERR`) before FIFO RX/TX and write 0 to `SE_GENI_TX_WATERMARK_REG` when `!dma`. In `geni_i2c_abort_xfer()` and `geni_i2c_*_fsm_rst()`, update `time_left = wait_for_completion_timeout(&gi2c->done, time_left)` until done or `!time_left`. [F100, F106, F107, F146]
- In `qup_i2c_probe()`, verify `clk_freq` is in `1..I2C_MAX_FAST_MODE_PLUS_FREQ` before dividing by `clk_freq`. `qup_i2c_disable_clocks()` must call `qup_i2c_vote_bw(qup, 0)` (clearing cached `qup->cur_bw_clk_freq`), `qup_i2c_change_state(qup, QUP_RESET_STATE)`, and set `QUP_CLOCK_AUTO_GATE` before `clk_disable_unprepare(qup->pclk)`. [F72, F121, F158]
- `qup_i2c_change_state()` must poll `qup_i2c_poll_state_valid()` before writing `QUP_STATE` and `qup_i2c_poll_state()` after, where `qup_i2c_poll_state_mask()` requires `QUP_STATE_VALID` and `(state & req_mask) == req_state`. `qup_i2c_bus_active()` must check `time_after(jiffies, timeout)` and on timeout set `ret = -ETIMEDOUT` and `break`. [F101, F103, F124, F152]
- In `i2c-qup.c`, `qup_i2c_determine_mode_v2()` must keep `qup->use_dma = false` if any `msgs[idx].buf` satisfies `is_vmalloc_addr()`; when `qup->use_dma` is true, `qup_i2c_interrupt()` must not write `QUP_RESET_STATE` on error, and `qup_i2c_xfer_v2()` must reset `qup->use_dma = false` after `qup_i2c_bam_xfer()`. [F74, F180]
- In `qup_i2c_set_blk_data()`, compute `qup->blk.count = DIV_ROUND_UP(msg->len, qup->blk_xfer_limit)`. In `qup_i2c_bam_xfer()`, flush via `qup_i2c_bam_schedule_desc()` when `sg_cnt > qup->max_xfer_sg_len`, and call `qup_i2c_bam_clear_tag_buffers()` (zeroing `btx.sg_cnt`, `brx.sg_cnt`, `tag_buf_pos`) before the loop and after each schedule. In `qup_i2c_read_rx_fifo_v2()`, `qup_i2c_recv_tags()` shifts `blk->rx_fifo_data` by `blk->rx_tag_len * 8`, sets `rx_fifo_data_pos = rx_tag_len`, and decrements `fifo_available` before `qup_i2c_recv_data()`. [F75, F99, F104, F122]
- In `msm_timer_set_next_event()`, if `sts_base` is non-NULL, spin until `TIMER_STS_GPT0_CLR_PEND` clears before setting `TIMER_ENABLE_EN`. In `qcom_rng_read()`, copy only `max - currsize` bytes when `< WORD_SZ` (4) remain. In `qcom_ebi2_setup_chipselect()`, cap non-boolean `val` to `xp->max` before shifting `val << xp->shift`. [F93, F125, F151]

## Synchronization

- `qcom_scm_probe()` must call `smp_store_release(&__scm, scm)` only after `scm->mempool`, clocks, reset, and `qcom_scm_irq_handler` are initialized, with no fallible steps after unless `__scm` is cleared. `qcom_rng_probe()` must initialize `rng` and set `qcom_rng_dev = rng` before `crypto_register_rng()`, resetting `qcom_rng_dev = NULL` on error or in `qcom_rng_remove()`. [F25, F41]
- In `__scm_smc_do()`, lock/unlock `qcom_scm_lock` around `__scm_smc_do_quirk_handle_waitq()` inside the `QCOM_SCM_V2_EBUSY` retry loop so it is released before `msleep()` or return; `qcom_scm_irq_handler()` and `scm_get_wq_ctx()` must call `__scm_smc_do_quirk()` directly with `ARM_SMCCC_FAST_CALL` without taking `qcom_scm_lock`. `__qcom_scm_qseecom_call()` requires `qcom_scm_qseecom_call_lock` held (outside `qcom_scm_lock`). [F9, F28, F160, F167]
- In `qcom-cpufreq-hw.c`, request `data->throttle_irq` with `IRQF_NO_AUTOEN` after initializing `throttle_lock` and `throttle_work`, enabling it only in `qcom_cpufreq_ready()`. `qcom_cpufreq_hw_cpu_offline()` must set `data->cancel_throttle = true` under `throttle_lock` and unlock before `cancel_delayed_work_sync(&data->throttle_work)`, while `qcom_lmh_dcvs_notify()` checks `cancel_throttle` under `throttle_lock` before re-arming. Set `policy->fast_switch_possible = true` only when `!icc_scaling_enabled`. [F32, F33, F171]
- In `qcom_adm.c`, acquire `achan->vc.lock` with `spin_lock_irqsave()` in process/softirq context (`adm_dma_irq()` takes it in hardirq); under `vc.lock`, `adm_start_dma()` sets `achan->curr_txd` and clears `achan->error = 0`, `adm_issue_pending()` calls `adm_start_dma()` only when `!achan->curr_txd`, and `adm_dma_irq()` clears `achan->curr_txd = NULL` before starting the next descriptor. [F78, F176]
- `geni_i2c_abort_xfer()` must hold `spin_lock_irqsave(&gi2c->lock, flags)` while updating `gi2c->cur`, `gi2c->abort_done`, and calling `geni_se_abort_m_cmd()`, and unlock before `wait_for_completion_timeout(&gi2c->done, ...)`. `btqcomsmd_recv()` runs in RPMSG interrupt callbacks and must use `GFP_ATOMIC`. [F175, F178]
- In `qup_i2c_probe()`, reset the core (`QUP_SW_RESET`) and poll `qup_i2c_poll_state_valid()` before requesting `qup->irq` with `IRQF_NO_AUTOEN`; transfer functions must pair `enable_irq(qup->irq)` and `disable_irq(qup->irq)` on all paths before clearing `qup->msg = NULL`. [F24, F39]

## Object Lifetimes

- `qcom_scm_pas_init_image()` must allocate `mdata_buf` via `dma_alloc_coherent()` (never `qcom_tzmem_alloc()`), transferring it to `*ctx` when `ctx && ret >= 0` and freeing it when `ret < 0 || !ctx`; `qcom_scm_pas_metadata_release()` must check `if (!ctx->ptr)` before `dma_free_coherent()` and zero `ctx->ptr`, `phys`, and `size`. In `qcom_scm.c` ICE key functions, wipe TZMem key/secret buffers with `memzero_explicit()` before `__free(qcom_tzmem)` runs. [F3, F4, F7, F169]
- Balance `of_iomap()`/`ioremap()` with `iounmap()` and `of_get_cpu_node()`/`of_cpu_device_node_get()`/`of_parse_phandle()` with `of_node_put()` across `*_release_secondary()`, `msm_dt_timer_init()`, `spm_cpuidle_register()` (also calling `put_device(&pdev->dev)` after `of_find_device_by_node()`), and early exits from `for_each_available_child_of_node()` / `for_each_of_cpu_node()`. [F10, F11, F14, F115]
- In `qcom-ssc-block-bus.c`, do not `iounmap()` `devm_ioremap_resource()` mappings, but detach power domains via `qcom_ssc_block_bus_pds_detach()` on probe error or remove; `qcom_ssc_block_bus_pds_attach()` and `qcom_ssc_block_bus_pds_enable()` must use signed `int i` and unwind `for (i--; i >= 0; i--)` on failure. [F13, F116, F141]
- In `qcom-cpufreq-hw.c`, release every non-error `opp` from `dev_pm_opp_find_freq_*()` with `dev_pm_opp_put(opp)`. In `adm_dma_remove()`, after unregistering DMA, mask channel IRQs in `ADM_CH_RSLT_CONF`, kill `vc.task`, and call `adm_terminate_all()` before `devm_free_irq()` and disabling clocks. In `btqcomsmd`, call `hci_unregister_dev()` and `hci_free_dev()` before `rpmsg_destroy_ept()` in reverse order. [F2, F16, F36]
- In `i2c-qcom-geni.c` and `i2c-qup.c`, release `dma_request_chan()` channels via `dma_release_channel()` on probe failure and remove; in `qup_i2c_bam_schedule_desc()`, if RX prep fails after `dma_async_issue_pending(qup->btx.dma)`, call `dmaengine_terminate_sync(qup->btx.dma)` before `dma_unmap_sg()`. [F23, F143]
- In `i2c-qcom-geni.c`, release `i2c_get_dma_safe_msg_buf()` buffers via `i2c_put_dma_safe_msg_buf()` after DMA unmapping (with `!gi2c->err`) or immediately (`false`) on prep/map failure, using `gi2c->se.dev->parent` for GPI `dma_map_single()`/`dma_unmap_single()`. In `geni_i2c_xfer()`, on `pm_runtime_get_sync() < 0` call `pm_runtime_put_noidle()` and `pm_runtime_set_suspended()`, and on exit clear `gi2c->cur = NULL` and `gi2c->err = 0`; runtime resume/suspend must manage interconnect, `core_clk`, `geni_se_resources_on/off()`, and `gi2c->irq` in symmetric LIFO order, re-enabling `gi2c->irq` if `geni_se_resources_off()` fails. [F19, F20, F21, F179]

## API Contracts

- `qcom_scm_call()` requires preemptible context; atomic/idle/IRQ callers must use `qcom_scm_call_atomic()`, where `scm_legacy_call_atomic()` takes at most 5 args and returns raw `smc_res.a0` without `qcom_scm_remap_error()`. `qcom_scm_shm_bridge_enable()` must use its `scm_dev` argument (never `__scm`) and map `SHMBRIDGE_RESULT_NOTSUPP` to `-EOPNOTSUPP`. [F44, F45, F138, F161, F164]
- In `qcom_scm_assign_mem()`, `*srcvm` is a `BIT(vmid)` mask updated to `next_vm` only on success, while `src[i++] = cpu_to_le32(b)` and `newvm[].vmid` use indices `0..63`; `ALIGN(..., SZ_64)` the buffer size and internal offsets, but pass unaligned `mem_to_map_sz`, `src_sz`, and `dest_sz` to `__qcom_scm_assign_mem()`. [F47, F112, F129]
- `qcom_scm_iommu_secure_ptbl_size()` puts size in `result[0]` and status in `result[1]`, whereas `qcom_scm_shm_bridge_create()` puts status in `result[0]` and handle in `result[1]`. `qcom_scm_ice_set_key()` takes `key_size` in bytes and `data_unit_size` in 512-byte sectors; `qcom_scm_iommu_set_cp_pool_size(spare, size)` sets `args[0] = size, args[1] = spare`. `qcom_scm_qseecom_app_send()` requires `qcom_tzmem_alloc()` buffers, and `qcom_scm_hdcp_req()` requires a `req` array of `>= 5` elements. [F46, F48, F49, F88]
- In `qcom_scm-legacy.c`, access buffers via `scm_legacy_command_to_response()` and `scm_legacy_get_*_buffer()`, and in `scm_legacy_call()` call `dma_sync_single_for_cpu(..., DMA_FROM_DEVICE)` in a loop until `rsp->is_complete` and again on the response buffer before reading `res_buf`. [F84, F165]
- In `qcom-cpufreq-hw.c`, convert between cpufreq kHz (`freq_table`, `qcom_cpufreq_get_freq()`, `__qcom_cpufreq_hw_get()`) and OPP/clk/LMh Hz (`dev_pm_opp_*`, `qcom_cpufreq_hw_recalc_rate()`, `qcom_lmh_get_throttle_freq()`) using `HZ_PER_KHZ` (1000), and keep `.determine_rate` in `qcom_cpufreq_hw_clk_ops`. Use `for_each_present_cpu()` in `qcom_get_related_cpus()` and `spm_cpuidle_drv_probe()`, and `device_get_match_data()` in DT+ACPI drivers (`qcom-rng.c`, `i2c-qcom-geni.c`). [F126, F148, F173, F185]
- `adm_slave_config()` must check `cfg->peripheral_size == sizeof(struct qcom_adm_peripheral_config)` before dereferencing `cfg->peripheral_config`. `btqcomsmd_setup()` must use `hci_set_quirk()` and `kfree_skb()` the `__hci_cmd_sync()` response. In `qup_i2c_xfer_v2_msg()` SMBus block reads (`I2C_M_RECV_LEN`), check `msg->buf[0] <= I2C_SMBUS_BLOCK_MAX` (`-EPROTO`), set `msg->len = msg->buf[0]` and `qup->is_smbus_read = true` (advancing `blk->cur_data += 1`), then clear `is_smbus_read` and restore `msg->len += 1`. [F76, F96, F184, F192]

## Error Handling

- Guard `__scm != NULL` in any SCM function reachable before `qcom_scm_probe()` completes, and in `qcom_scm_set_download_mode()` log `dev_err()` for missing support only if `dload_mode != 0`. In `qcom-cpufreq-hw.c`, check `reg_current_vote` and `reg_intr_clr` are non-zero before MMIO access, and check `data->throttle_irq > 0` (or `>= 0` in `__qcom_cpufreq_hw_get()`) before using LMh IRQ, lock, or work. [F42, F54, F56, F144, F193]
- In `geni_i2c_probe()`, check `desc != NULL` before dereferencing match data; in `geni_i2c_err()`, set `gi2c->err` only `if (!gi2c->err)` and log `NACK`/`GENI_TIMEOUT` with `dev_dbg()` without `geni_i2c_err_misc()`. Reset `qup->btx.dma` / `brx.dma` to `NULL` on `dma_request_chan()` failure in `qup_i2c_req_dma()`, and check `IS_ERR_OR_NULL(pds[i])` (returning `PTR_ERR(pds[i]) ?: -ENODATA`) in `qcom_ssc_block_bus_pds_attach()`. [F53, F58, F59, F60, F191]
- `qcom_hwspinlock_trylock()` returns `1` when acquired, `0` when busy, and `< 0` on error. `qcom_rng_read()` returns positive bytes or `< 0`, which `qcom_hwrng_read()` returns directly while `qcom_rng_generate()` maps `ret >= 0` to `0`. `btqcomsmd_send()` calls `kfree_skb(skb)` only when `ret == 0`. [F51, F52, F62]

## External Contracts

- In `__scm_smc_call()`, when `arglen > 4`, write `desc->args[3..9]` into the TZMem buffer as `__le32` (`ARM_SMCCC_SMC_32`) or `__le64` (`ARM_SMCCC_SMC_64`) with `smc.args[5]` holding the physical address; probe `SMC_CONVENTION_ARM_64` in `__get_convention()` only `#if IS_ENABLED(CONFIG_ARM64)`. [F86, F163]
- `set_download_mode()` must accept both `download_mode_name` strings and `kstrtobool()`. Mark `msm_read_timer_count()` and `msm_sched_clock_read()` `notrace`. In `i2c-qup.c`, encode block length `QUP_READ_LIMIT` (256) as `0` in tag bytes, and cap v2 RX `qup->blk_xfer_limit` to `RECV_MAX_DATA_LEN` (254). [F91, F97, F182]

## Known Pitfalls

- In `geni_i2c_rx_one_msg()` and `geni_i2c_tx_one_msg()`, snapshot `cur = gi2c->cur` before waiting on `gi2c->done` and calling `geni_i2c_abort_xfer()`, passing local `cur` to `geni_i2c_*_msg_cleanup()`. In `geni_i2c_irq()`, widen `cur->buf[gi2c->cur_wr++]` to `u32` before `<< (p * 8)`. In `qup_i2c_interrupt()`, gate write completion on `opflags & QUP_MX_OUTPUT_DONE` only when `blk->is_tx_blk_mode` is true. [F68, F102, F120]
