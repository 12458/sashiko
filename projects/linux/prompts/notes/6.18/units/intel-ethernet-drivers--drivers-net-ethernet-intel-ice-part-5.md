# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ice (part 5)

This unit manages MSI-X/virtual interrupt resource tracking, Link Aggregation (LAG) hardware offload and failover, LAN Tx/Rx descriptor formats, and core Virtual Station Interface (VSI) lifecycle routines across PF, VF, SF, and channel VSIs.

## Architecture & Data Flow
- `pf->vsi[]` is sparse (`ice_vsi_free()` clears slots to `NULL`), so `ice_for_each_vsi(pf, i)` loops must NULL-check `pf->vsi[i]`. `ICE_VSI_CHNL` VSIs do not allocate `tx_rings`, `rx_rings`, `txq_map`, `rxq_map`, `q_vectors`, or `pf->vsi_stats[vsi->idx]`, and `ICE_VSI_LB` VSIs do not allocate `q_vectors`. `vsi->vf` must be non-NULL for `ICE_VSI_VF`, while for `ICE_VSI_CTRL` it is non-NULL only for VF control VSIs. New `enum ice_vsi_type` values must update `ice_vsi_type_str`, `ice_vsi_set_num_qs`, `ice_vsi_alloc_def`, `ice_vsi_init`, `ice_set_agg_vsi`, and `ice_vsi_cfg_def`. [F46, F47, F78, F93]
- Partial VSI context updates via `ice_update_vsi` (`ice_vsi_update_security`, `ice_vsi_update_local_lb`, `ice_vsi_cfg_tc`) must seed `ctx.info` from `vsi->info`, set `ICE_AQ_VSI_PROP_*_VALID` in `ctx.info.valid_sections`, and copy updated fields back to `vsi->info` on success. `ICE_AQ_VSI_SEC_FLAG_ALLOW_DEST_OVRD` is set by default on `ICE_VSI_PF` in `ice_vsi_init` and must be preserved by `ice_vsi_update_security`. [F59, F60]
- Per-queue registers (`QRX_CTRL`, `QRXFLXP_CNTXT`, `QRX_CONTEXT`, `QINT_TQCTL`, `QINT_RQCTL`) and `ice_aqc_cfg_txqs_buf` queue handles take PF-space queue IDs from `vsi->rxq_map[q]` / `vsi->txq_map[q]`, while `rx_rings[q]` / `tx_rings[q]` use VSI-relative `q`. `ice_vsi_alloc_arrays()` must size `vsi->txq_map` as `vsi->alloc_txq + num_possible_cpus()` for XDP Tx rings mapped at `vsi->alloc_txq` before `vsi->num_xdp_txq` is initialized. [F84, F113]
- `ice_vsi_setup_q_map` and `ice_vsi_setup_q_map_mqprio` must verify total TC Tx/Rx queues do not exceed `vsi->alloc_txq` / `alloc_rxq` before setting `vsi->num_txq` / `num_rxq`. `ice_vsi_setup_q_map()` must clamp `vsi->tc_cfg.numtc` to `>= 1` before dividing `qcount_rx`/`qcount_tx`, and clamp `num_rxq_per_tc` to `>= 1` before `order_base_2()`. [F87, F109]
- Reset `vsi->stat_offsets_loaded = false` in `ice_vsi_cfg_def` and when `ice_is_reset_in_progress(pf->state)` in `ice_update_eth_stats` before sampling `GLV_*` counters. `ice_vsi_set_num_desc` must only set default `num_rx_desc`/`num_tx_desc` when zero. When `ice_vsi_cfg_rss_lut_key` restores `vsi->rss_size` from `vsi->orig_rss_size` after ADQ teardown, it must clear `vsi->orig_rss_size = 0`. [F65, F66, F67]
- In `ice_set_q_vector_intrl`, if `q_vector->tx` or `rx` has `ITR_IS_DYNAMIC`, program 4 us via `ice_write_intrl(q_vector, 4)` without overwriting `q_vector->intrl`. In `ice_vsi_ctrl_all_rx_rings()`, toggle all rings with `wait = false`, call `ice_flush(&vsi->back->hw)` once, then poll via `ice_vsi_wait_one_rx_ring()`. [F68, F103]
- `ice_set_agg_vsi` must skip aggregator nodes with `num_vsis >= ICE_MAX_VSIS_IN_AGG_NODE` (64), bound iteration by `ICE_MAX_PF_AGG_NODES` / `ICE_MAX_VF_AGG_NODES`, and update `agg_node->num_vsis` and `vsi->agg_node` together; `ice_vsi_decfg` must decrement `vsi->agg_node->num_vsis` for `ICE_VSI_VF`. [F69, F91]
- When `ice_is_safe_mode(pf)` is true, skip DDP-dependent RSS flow and switch filter ops in `ice_lib.c`. In Double VLAN Mode (`ice_is_dvm_ena`), `ice_vsi_add_vlan_zero` and `ice_vsi_del_vlan_zero` must manage both `ICE_VLAN(0, 0, 0)` and `ICE_VLAN(ETH_P_8021Q, 0, 0)` (matching `ICE_DVM_NUM_ZERO_VLAN_FLTRS` in `ice_vsi_num_zero_vlans`), vs. only `ICE_VLAN(0, 0, 0)` in SVM. [F130, F161]
- E810 clock features (`ICE_F_CGU`, `ICE_F_SMA_CTRL`, `ICE_F_GNSS`) in `ice_init_feature_support()` require `ice_pf_src_tmr_owned(pf)` and netlist/module presence. `ICE_F_SRIOV_LAG` and `ICE_F_SRIOV_AA_LAG` in `ice_lag_init_feature_support_flag()` require both `dev_caps.common_cap` (`sriov_lag` / `sriov_aa_lag`) and `ice_pkg_has_lport_extract(&pf->hw)`. [F128, F129]
- In `ice_lag_changeupper_event()` (on link) and `ice_lag_chk_comp()`, verify `ice_is_switchdev_running()` on the primary PF before configuring shared SWIDs, prune lists, or filters. On link in `ice_lag_set_swid`, cache `local_lag->bond_swid = primary_swid` so on unlink (`!link`) the secondary can free `bond_swid`, restore `port_info->sw_id`, and clear `bond_swid = 0` even if the primary already left. [F74, F131]
- When a primary SR-IOV LAG PF's active port changes or unlinks (`ice_lag_monitor_act_bkup`, `ice_lag_act_bkup_unlink`, `ice_lag_aa_move_vf_qs`), call `ice_lag_config_eswitch` with the active `net_device` to update `repr->dst->u.port_info.lower_dev` and call `netif_keep_dst(netdev)`. [F58, F152]
- In Active-Active LAG, `lag->sec_vf[ICE_MAX_SRIOV_VFS]` (indexed by `vf_id`) and `lag->q_home[ICE_MAX_SRIOV_VFS][ICE_MAX_RSS_QS_PER_VF]` must not be overrun. Secondary placeholder VF VSIs (`lag->sec_vf[vf->vf_id]`) created in `ice_lag_monitor_act_act` must clear anti-spoofing via `ice_lag_aa_clear_spoof`, and be released via `ice_vsi_release` and nulled on unlink in `ice_lag_changeupper_event`. [F75, F85]
- In `ice_lag_aa_move_vf_qs`, unlink each moved `q_node` from `parent->children` and `old_hw->port_info->sib_head[0][layer]`, link it into `new_hw->port_info->sib_head[0][layer]` and `n_prt->children`, and set `lag->q_home[vf_id][i] = dest`. In `ice_lag_qbuf_recfg()`, `i` indexes `ice_get_lan_q_ctx` while `count` indexes `qbuf->queue_info[count]`; callers must verify returned `valq` (`count`) is non-zero. Flexible-array AdminQ buffers in `ice_lag.c` must use `ICE_SW_RULE_*_SIZE()` or `struct_size()`, never `sizeof(*ptr)`. [F71, F98, F120]
- `ice_get_irq_res` uses inclusive `xa_limit` `[0, num_entries - 1]` (or `[0, num_static - 1]` if `!dyn_allowed`), setting `entry->dynamic` iff `index > num_static - 1`. 64-bit descriptor bitmask macros in `ice_lan_tx_rx.h` reaching bit 31+ must use `ULL` or `BIT_ULL()`. [F80, F106]

## Synchronization
- In `ice_init_lag`, initialize `lag->pf`, `lag->netdev`, `lag->role`, `lag->active_port`, and `lag->notif_block.notifier_call` before `ice_register_lag_handler(lag)`. Bond slave traversal (`for_each_netdev_in_bond_rcu`, `netdev_master_upper_dev_get_rcu`) in `ice_lag.c` requires `rcu_read_lock()` and `GFP_ATOMIC` allocations (including snapshotting `lag_work->netdev_list` and copying `*ptr` into `lag_work->info` in `ice_lag_event_handler`). [F23, F25, F151]
- Hold `pf->sw_mutex` for `pf->vsi[]` and `pf->next_vsi` updates in `ice_vsi_alloc` / `ice_vsi_free`, hold `pf->avail_q_mutex` for `pf->avail_txqs` / `avail_rxqs` in `ice_vsi_get_qs` / `ice_vsi_put_qs`, and hold `vsi->xdp_state_lock` across `ice_vsi_realloc_stat_arrays`, `ice_vsi_decfg`, `ice_vsi_cfg_def`, and `ice_vsi_cfg_tc_lan` in `ice_vsi_rebuild`. [F28, F144]
- `ice_ena_vsi()` and `ice_dis_vsi()` must take `rtnl_lock()` around `ice_open_internal()` / `ice_vsi_close()` on running PF/SF netdevs iff `locked == false`; after taking `rtnl_lock()`, `ice_dis_vsi()` must re-check `test_bit(ICE_VSI_DOWN, vsi->state)`. `ice_vsi_set_napi_queues` and `ice_vsi_clear_napi_queues` on registered netdevs require `rtnl_lock`. [F19, F33, F154]
- `vsi->tx_rings[]`, `rx_rings[]`, and `vsi_stat->tx_ring_stats[]` / `rx_ring_stats[]` entries must be allocated with `kzalloc` (never `devm_kzalloc`), assigned/cleared with `WRITE_ONCE`, and freed via `kfree_rcu(..., rcu)`; `ice_vsi_clear_rings` must null `q_vector->tx.tx_ring` and `rx.rx_ring` first. Per-ring counter updates (`ice_update_tx_ring_stats`, `ice_update_rx_ring_stats`, `ice_update_ring_stats`) require `u64_stats_update_begin` / `end` on `&ring->ring_stats->syncp`. [F30, F114, F142]

## Object Lifetimes
- If `pci_msix_alloc_irq_at()` fails in `ice_alloc_irq()`, release the tracker entry via `ice_free_irq_res(pf, entry->index)` before returning negative `msi_map.index`. [F1]
- `ice_lag_process_event()` must unlink and `kfree` all `lag_work->netdev_list` entries, reset `lag->netdev_head = NULL` under `pf->lag_mutex`, and `kfree(lag_work)` on all paths (`lag_cleanup`). Any temporary list attached to `lag->netdev_head` via `ice_lag_build_netdev_list()` must be cleaned up with `ice_lag_destroy_netdev_list()` before return. [F4, F119]
- `ice_deinit_lag()` must call `ice_unregister_lag_handler()` then `flush_workqueue(ice_lag_wq)` before freeing recipes, `kfree(lag)`, and setting `pf->lag = NULL`. If TX rule setup fails in `ice_lag_cfg_dflt_fltr()`, invert the RX rule via `ice_lag_cfg_fltr(..., ICE_FLTR_RX, !add)`. [F8, F10]
- `ice_vsi_alloc()` reserves `pf->vsi[]` and initializes `vsi->xdp_state_lock` under `pf->sw_mutex`, while `ice_vsi_free()` clears `pf->vsi[vsi->idx]`, updates `pf->next_vsi`, frees stats/arrays, and destroys `vsi->xdp_state_lock` under `pf->sw_mutex` before `devm_kfree(dev, vsi)`. `ice_vsi_alloc_arrays()` must roll back `tx_rings`, `rx_rings`, `txq_map`, `rxq_map`, and `q_vectors` in reverse order with `devm_kfree()` on failure, `ice_vsi_free_arrays()` must `devm_kfree()` and NULL all five, and those arrays, `rss_hkey_user`, `rss_lut_user`, and `struct ice_vsi` must use `devm_kfree()`, never `kfree()`. [F11, F13, F125]
- Ring, queue-map, and stat allocation/teardown (`ice_vsi_alloc_rings`, `ice_vsi_clear_rings`, `ice_vsi_alloc_ring_stats`, `ice_vsi_free_stats`, `ice_vsi_put_qs`) must iterate with `ice_for_each_alloc_txq` / `alloc_rxq`, and `ice_vsi_put_qs` must run before `ice_vsi_free_arrays`. [F64, F94]
- `ice_vsi_decfg()` preserves `pf->vsi_stats[vsi->idx]`. In `ice_vsi_rebuild()`, `ice_vsi_realloc_stat_arrays()` must run before `ice_vsi_decfg()` while `alloc_txq`/`alloc_rxq` hold old counts, `kfree_rcu()` excess entries before shrinking, pass `__GFP_ZERO` to `krealloc_array()`, restore old pointers on NULL return, and `ice_vsi_alloc_ring_stats()` must rebind `ring->ring_stats`. [F16, F62, F115]
- In `ice_vsi_close()`, `ice_vsi_clear_napi_queues()` and `ice_vsi_free_irq()` must precede `ice_vsi_free_tx_rings()` / `free_rx_rings()`. `ice_vsi_free_irq()` must check `vsi->irqs_ready`, call `ice_vsi_release_msix()`, clear `vsi->irqs_ready = false`, and only call `synchronize_irq()` / `devm_free_irq()` on non-VF `q_vectors` with `num_ring_tx > 0` or `num_ring_rx > 0`. [F18, F122]
- In `ice_vsi_release()`, call `ice_vsi_delete()` only when `!ice_is_reset_in_progress(pf->state)`. In `ice_vsi_cfg_tc()`, save `vsi->tc_cfg` to `old_tc_cfg` and restore it on `ice_vsi_setup_q_map*` failure. [F17, F20]

## API Contracts
- `ice_alloc_irq()` signals failure via `map.index < 0` (already freed in tracker); callers must not call `ice_free_irq()` on failure. `ice_virt_get_irqs()` returns `-ENOENT` or PF-relative MSI-X index (`res + pf->virt_irq_tracker.base`), which `ice_virt_free_irqs()` requires. [F35, F36]
- Pair `ice_lag_prepare_vf_reset()` and `ice_lag_complete_vf_reset(lag, act_prt)` under the same `pf->lag_mutex` hold. Suspend VF scheduler TEIDs via `ice_sched_suspend_resume_elems(..., true)` before moving/reconfiguring queues in `ice_lag_move_vf_node_tc`, `ice_lag_aa_move_vf_qs`, `ice_lag_reclaim_vf_tc`, and `ice_lag_move_vf_nodes_tc_sync`, and resume (`false`) on all exit paths. [F42, F136]
- `ice_lag_set_swid` and `ice_wait_for_reset` sleep and require process context. `ice_set_dflt_vsi` must return `0` without calling `ice_cfg_dflt_vsi` when `ice_lag_is_switchdev_running(vsi->back)` is true. [F141, F148, F153]
- `ice_vsi_setup()` requires `ICE_VSI_FLAG_INIT` and non-NULL `params->port_info`, returning `NULL` (not `ERR_PTR`) on failure. `ice_get_free_slot()` takes a pointer array and element count, returning `ICE_NO_VSI` (`0xffff`) when full. [F44, F45, F117]
- `ice_vsi_init()` sets `ctxt->vf_num = vsi->vf->vf_id + hw->func_caps.vf_base_id`, whereas `ice_vsi_stop_lan_tx_rings()` takes PF-relative `rel_vmvf_num`. `ICE_AQ_VSI_TC_Q_NUM_M` in `ctxt->info.tc_mapping[i]` takes `order_base_2(qcount)`, while `ctxt->info.q_mapping[1]` takes raw Rx queue count. [F52, F159]
- `ice_set_min_bw_limit()` / `ice_set_max_bw_limit()` take Kbps, validate against `ice_get_link_speed_kbps(vsi)`, and use `ice_cfg_vsi_bw_dflt_lmt_per_tc()` when rate is `0`. `ice_write_itr` and `ice_write_intrl` take microseconds; `ice_intrl_usec_to_reg()` requires non-zero `gran`. Only call `ice_napi_add` during initial driver load after `vsi->netdev` creation. [F54, F110, F156, F160]

## Error Handling
- Store `pci_alloc_irq_vectors()` in signed `int vectors` and check `vectors < 0` in `ice_init_interrupt_scheme()`, never comparing against unsigned `pf->msix.min`. [F34]
- Check both `pf->lag` and `lag->upper_netdev` for non-NULL in `ice_lag_is_switchdev_running()` and `ice_lag_prepare_vf_reset()`. Reset `notif_blk->notifier_call = NULL` if `register_netdevice_notifier()` fails in `ice_register_lag_handler()`. [F37, F40]
- Switch on `rc->type` and NULL-check the ring in `ice_pull_qvec_from_rc()`, and NULL-check its return in `ice_write_itr()`. Initialize `bool exists = false` before `ice_check_if_dflt_vsi(pi, 0, &exists)` in `ice_is_dflt_vsi_in_use()`. [F48, F51]
- Treat `-EIO` with `LIBIE_AQ_RC_EMODE` from `ice_aq_set_link_restart_an()` as `0` in `ice_set_link()`. Ignore `-EEXIST` from `vlan_ops->add_vlan` / `del_vlan` in `ice_vsi_add_vlan_zero` / `del_vlan_zero`. Do not abort `ice_vsi_cfg_def()` on `ice_vsi_cfg_rss_lut_key` or `ice_vsi_set_*_rss_flow_fld` failure. [F55, F56, F163]

## External Contracts
- Only call `pci_msix_alloc_irq_at` / `pci_msix_free_irq` in `ice_alloc_irq` / `ice_free_irq` when `entry->dynamic` is true; static entries use `pci_irq_vector()`. [F164]
- Check `netif_is_ice(netdev)` before `netdev_priv(netdev)` in LAG paths; `ice_lag_event_handler` also requires `NETDEV_CHANGEUPPER` / `BONDING_INFO` / `UNREGISTER`, `IFF_BONDING`, `lag->netdev != NULL`, and `net_eq(dev_net(netdev), &init_net)`. [F149, F150]
- Mask `union ice_32b_rx_flex_desc` `pkt_len` with `ICE_RX_FLX_DESC_PKT_LEN_M` and `ptype_flex_flags0` with `ICE_RX_FLEX_DESC_PTYPE_M`. In `struct ice_tx_desc`, `MACLEN` is in 2-byte words while `IPLEN` and `L4LEN` are in 4-byte dwords. [F89, F90]

## Known Pitfalls
- `vsi->idx` is the software index (`pf->vsi[]`, `pf->vsi_stats[]`, `hw->vsi_ctx[]`) while `vsi->vsi_num` is the hardware VSI ID (`GLV_*`, switch rules)—except in `ice_lag.c`, where `vsi_num` in `ice_lag_qbuf_recfg`, `ice_lag_move_vf_node_tc`, `ice_lag_move_single_vf_nodes`, `ice_lag_aa_qbuf_recfg`, `ice_lag_aa_move_vf_qs`, `ice_lag_reclaim_vf_tc`, and `ice_lag_move_vf_nodes_tc_sync` actually takes `vsi->idx`. [F82, F83]
- `lag->port_bitmap` uses bitmasks `ICE_LAGP_M`/`ICE_LAGS_M`, `lag->q_home` and `dest` in `ice_lag_aa_failover` / `ice_lag_aa_move_vf_qs` use indices `ICE_LAGP_IDX` (`0`) / `ICE_LAGS_IDX` (`1`), and `active_port` / `bond_lport_*` store `lport` (`ICE_LAG_INVALID_PORT` = `0xFF`). [F86]
- In `ice_lag_aa_move_vf_qs()`, toggle `*odd = !(*odd)` at the start of each queue iteration before any `continue`, and target `pri_hw` / primary `vsi_num` for `ice_get_lan_q_ctx`, `ice_lag_aa_qbuf_recfg`, and `ice_aq_cfg_lan_txq` (using `new_hw->port_info` and `dst_vsi_num` only for `ice_sched_get_free_qparent`). In `ice_lag_add_prune_list()` / `del_prune_list()`, call `ice_find_vsi_list_entry()` on `&lag->pf->hw` (`lag->pf->vsi[0]->idx`) and `ice_aq_sw_rules()` on `&event_pf->hw` (`event_pf->vsi[0]->vsi_num`). [F99, F100, F104]
- Increment `agg_node_iter++` before every `continue` in `ice_set_agg_vsi()`. Initialize `txq`/`rxq` to 0 outside `ice_for_each_q_vector` in `ice_vsi_cfg_msix()` / `release_msix()`. Do not reset `i = 0` in the second loop of `ice_vsi_rebuild_set_coalesce()`. Cast values to `u64` before shifting by `ICE_TXD_QW1_TX_BUF_SZ_S` (34), `ICE_TXD_QW1_L2TAG1_S` (48), or `ICE_TXD_CTX_QW1_MSS_S` (50). [F95, F96, F97, F107]
