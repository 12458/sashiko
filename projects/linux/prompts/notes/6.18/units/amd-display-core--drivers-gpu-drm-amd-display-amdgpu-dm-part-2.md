# AMD DISPLAY CORE — drivers/gpu/drm/amd/display/amdgpu_dm (part 2)

This unit implements AMDGPU Display Manager modules for color management, CRTC vblank/VRR/PSR/CRC and secure display, DP MST/DSC fairness, HDCP workqueues, two-tier IRQ dispatch, DC OS helpers, and debugfs.

## Architecture & Data Flow

- In `amdgpu_dm_crtc_set_panel_sr_feature()`, Panel Replay (`amdgpu_dm_replay_enable()`) and PSR (`amdgpu_dm_psr_enable()`) require `allow_sr_entry && !amdgpu_dm_crtc_vrr_active_irq() && !is_sr_active && !is_crc_window_active`; place `else if (vblank_enabled)` before PSR enablement so PSR1 (`< DC_PSR_VERSION_SU_1`) is disabled while PSR SU stays active and PSR is never newly enabled during vblank. In `amdgpu_dm_crtc_vblank_control_worker()`, update `dm->active_vblank_irq_count` under `dm->dc_lock`, disabling idle optimizations before `amdgpu_dm_crtc_set_panel_sr_feature()` when `> 0` and re-enabling them after `dc_post_update_surfaces_to_stream()` when `0`. [F235, F247, F274]
- Enable the CRTC degamma LUT property (`MAX_COLOR_LUT_ENTRIES`) in `amdgpu_dm_crtc_init()` only when `dc->caps.color.dpp.dcn_arch && dce_version != DCN_VERSION_4_01`, and attach `regamma_tf_property` in `dm_crtc_additional_color_mgmt()` only when `dc->caps.color.mpc.ogam_ram` is true. In `amdgpu_dm_update_plane_color_mgmt()`, reset `in_transfer_func` to `TF_TYPE_BYPASS` first and return `-EINVAL` if both plane degamma (`__set_dm_plane_degamma() != -EINVAL`) and CRTC degamma (`cm_has_degamma || cm_is_degamma_srgb`) are set. [F237, F309]
- In `amdgpu_dm_verify_lut3d_size()`, require both `dc->caps.color.dpp.hw_3d_lut` and `dc->caps.color.mpc.preblend` for 3D/shaper LUTs and verify `lut3d_size` is `MAX_COLOR_3DLUT_SIZE` cubed (4913) before `__drm_3dlut_to_dc_3dlut()` stripes `lut` across `lut0..lut3` in steps of 4 up to `lut3d_size - 4` and writes the final entry to `lut0[lut_i]`. [F252, F308]
- In `compute_mst_dsc_configs_for_state()` and `pre_compute_mst_dsc_configs_for_state()`, mark all streams on `stream->link` true in `computed_streams[]` after `compute_mst_dsc_configs_for_link()` succeeds, and index `params` at `0..count - 1` while indexing shared `vars` at `vars[i + k]` (`k = *link_vars_start_index`, advanced by `count` per link). [F261, F279]
- In `increase_dsc_bpp()` and `try_disable_dsc()`, if `drm_dp_mst_atomic_check()` fails after a trial `vars[next_index].pbn` update, restore `pbn` and call `drm_dp_atomic_find_time_slots()` again. Use ceiling division (`DIV64_U64_ROUND_UP` in `kbps_to_peak_pbn()` and `DIV_ROUND_UP(..., dfixed_trunc(mst_state->pbn_div))` in `increase_dsc_bpp()`); in `dm_dp_mst_is_port_support_mode()`, fall back `virtual_channel_bw_in_kbps` to `root_link_bw_in_kbps` when `passthrough_aux` and `immediate_upstream_port` are NULL (LCT=1) and still check `bw_range.min_kbps`. [F239, F267, F289]
- In `dm_helpers_dp_write_dsc_enable()` with `port->passthrough_aux`, write `DP_DSC_ENABLE` to `passthrough_aux` before `aconnector->dsc_aux` on enable, and `dsc_aux` before `passthrough_aux` on disable. In `write_dsc_enable_synaptics_non_virtual_dpcd_mst()`, clear `DP_DSC_ENABLE` only when `!stream->link->link_status.link_active`, and call `apply_synaptics_fifo_reset_wa(aux)` before enabling DSC on an inactive `"SYNA"` link. [F305, F312]
- In `dm_handle_mst_sideband_msg_ready_event()`, serialize the ESI loop with `aconnector->handle_mst_msg_ready`, bound it to `max_process_count` (30), and retry each ACK write to `dpcd_addr + 1` up to 3 times. In `dm_helpers_dp_handle_test_pattern_request()`, skip split/ODM slave pipes (`!pipes[i].top_pipe && !pipes[i].prev_odm_pipe`) and return false if `pipe_ctx` is NULL. [F278, F315]
- In `hdcp_workqueue`, index per-link state by `link_index`, per-display arrays by `aconnector->base.index`, and keep `srm`, `srm_temp`, `srm_size`, `srm_version`, `max_link`, and `attr` on `hdcp_work[0]`. Restore saved `hdcp_content_type`/`content_protection` onto `connector->state` in `dm_dp_mst_get_modes()` when creating a remote `dc_sink`, reload `hdcp_work->srm` via `psp_set_srm()` in `hdcp_update_display()` when enabling encryption with `srm_size > 0`, and check `psp->*_context.context.initialized` before accessing `shared_buf` or invoking PSP TAs (`psp_hdcp_invoke`, `psp_dtm_invoke`, `psp_securedisplay_invoke`). [F242, F255, F311, F319]
- In `amdgpu_dm_crtc_set_crc_source()`, balance `drm_crtc_vblank_get()` (before `amdgpu_dm_crtc_configure_crc_source()`) and `drm_crtc_vblank_put()`, reset `crc_skip_count = 0`, and call `amdgpu_dm_set_crc_window_default()`. For PSR1 (`psr_version < DC_PSR_VERSION_SU_1`), call `amdgpu_dm_psr_wait_disable()` under `dc_lock` before `dc_stream_configure_crc()`, and keep `AMDGPU_DM_PIPE_CRC_SOURCE_NONE` true in `dm_need_crc_dither()`. [F243, F275, F317]
- In `amdgpu_dm_crtc_handle_crc_window_irq()`, `window_param[i].update_win` must clear `update_win`, set `skip_frame_cnt = 1` and `crc_ready = false`, and skip reading CRC on the next frame; also reset `crc_info.crc[i].frame_count` to `0` at `UINT_MAX` or `reset_crc_frame_count[i]`. Bound connectors to `AMDGPU_DM_MAX_CRTC` in `update_phy_id_mapping()`, and unpack MST `rad` hops (`lct > 1`, `0 <= k < lct - 1`) via `(rad[k / 2] >> ((k % 2) ? 0 : 4)) & 0xf` in `update_phy_id_mapping()` and `get_phy_id()`. [F262, F276, F291]
- Mask `DC_IRQ_SOURCE_HPD1..DC_IRQ_SOURCE_HPD6RX` via `dc_interrupt_set(..., false)` first in `amdgpu_dm_hpd_init()`, and call `dc_interrupt_ack(adev->dm.dc, src)` before dispatching high/low work in `amdgpu_dm_irq_handler()`. Set `dsc_force_changed = true` in `dp_dsc_*_write()` while leaving it zeroed in `amdgpu_dm_crtc_duplicate_state()`, keep `struct drm_connector base` at offset 0 of `struct amdgpu_dm_connector`, and in `dmub_tracebuffer_show()`, offset `entries` past `dmub_debugfs_trace_header`, wrap `first_entry = num_entries % max_entries`, and clamp `num_entries = min(num_entries, max_entries)`. [F238, F264, F296, F301, F314]

## Synchronization

- In `amdgpu_dm_irq_register_interrupt()`, initialize all `handler_data` fields and `INIT_WORK(&handler_data->work, dm_irq_work_func)` before `list_add_tail()` under `irq_handler_list_table_lock`. High-context handlers (`irq_handler_list_high_tab`) run under `spin_lock_irqsave(&adev->dm.irq_handler_list_table_lock)` and must not sleep or re-lock it; `amdgpu_dm_irq_schedule_work()` must use `GFP_ATOMIC` when allocating extra work nodes; and `amdgpu_dm_irq_fini()` / `amdgpu_dm_irq_suspend()` must disable IRQ sources under `irq_handler_list_table_lock` then unlock before `flush_work(&handler->work)` and `unregister_all_irq_handlers()`. [F171, F197, F318, F321, F323]
- `amdgpu_dm_crtc_set_vblank()` runs in atomic context and must allocate `vblank_control_work` with `GFP_ATOMIC`, deferring `dm->dc_lock` operations to `amdgpu_dm_crtc_vblank_control_worker`. In `amdgpu_dm_idle_worker()`, after dropping `dc_lock` across `fsleep()`, re-lock `dc_lock` and recheck `!amdgpu_dm_is_headless(adev) && !amdgpu_dm_psr_is_active_allowed(dm)` and `idle_work->enable`. [F207, F325]
- `drm_device.event_lock` and `crtc_ctx->crc_info.lock` are used in hardirq context, so always use IRQ-disabling spinlocks and never sleep under them. In `LEGACY_MODE`, `amdgpu_dm_crtc_handle_crc_window_irq()` defers work to `forward_roi_work` and `notify_ta_work`, which copy `crc`/`roi` under `event_lock` and drop `event_lock` before locking `mode_config.mutex` (required around `get_phy_id()` and `update_phy_id_mapping()`), `dm->dc_lock`, or `psp->securedisplay_context.mutex`. [F200, F203, F327, F329, F330]
- In `crc_win_update_set()`, lock `dc_lock` before `event_lock` and call `amdgpu_dm_psr_disable()` before setting `crc_window_activated = true`. In `amdgpu_dm_set_crc_window_default()`, clear `crc_window_activated` under `event_lock` before flushing `notify_ta_work`/`forward_roi_work` and forwarding a `NULL` window. In `amdgpu_dm_crtc_set_crc_source()`, under `crtc->mutex`, lock `crtc->commit_lock` to get the head `drm_crtc_commit`, unlock `commit_lock`, and wait for `commit->hw_done`. [F177, F201, F202]
- In `hdcp_create_workqueue()`, initialize `srm`, `srm_temp`, `max_link`, and all per-link mutexes/works/`hdcp.config` before setting `cp_psp->handle` and creating `hdcp_srm`. Hold `hdcp_w->mutex` across `mod_hdcp_*`, `process_output()`, and `aconnector` updates; in `event_property_update()`, lock `connection_mutex` before `hdcp_work->mutex` and wait for `conn_state->commit->hw_done`; in `srm_data_write()`/`read()`, lock all links via `link_lock(work, true)`; and in `enable_assr()`, hold `psp->dtm_context.mutex`. [F190, F191, F192, F193, F194]
- In debugfs, acquire `aconnector->hpd_lock` outer-most before `dc_lock`, `mgr->base.lock`, or `drm_modeset_lock_all()`, and in `dp_dsc_*_write()`, lock `mode_config.mutex`, `connection_mutex`, and `crtc->mutex` in order and unlock in reverse order before freeing `wr_buf`. Hold `aconnector->dm_dp_aux.aux.hw_mutex` around `dc_link_is_dp_sink_present()` in `dm_helpers_is_dp_sink_present()`. [F187, F210, F212]

## Object Lifetimes

- Balance `dc_stream_retain()` and `dc_stream_release()` across `amdgpu_dm_crtc_duplicate_state()` / `destroy_state()` and `amdgpu_dm_crtc_set_vblank()` / `vblank_control_worker()` (with `kfree(vblank_work)`). Release `dc_create_gamma()` via `dc_gamma_release(&gamma)` in `__set_legacy_tf()`, `__set_output_tf()`, and `__set_input_tf()`, and in `pre_validate_dsc()`, release `local_dc_state->streams[i]` only when `!= dm_state->context->streams[i]` before `vfree(local_dc_state)`. [F174, F175, F179, F182]
- Pair `drm_dp_mst_get_port_malloc(port)` (with `drm_connector_dynamic_init()` and `amdgpu_dm_connector_funcs_reset()`) in `dm_dp_add_mst_connector()` with `drm_dp_mst_put_port_malloc()` in `dm_dp_mst_connector_destroy()`. When releasing an MST `aconnector->dc_sink` in `dm_dp_mst_detect()` or `amdgpu_dm_mst_connector_early_unregister()` (under `root->mst_mgr.base.lock`), remove it from `dc_link`, call `dc_sink_release()`, set `aconnector->dc_sink = NULL`, and call `amdgpu_dm_mst_reset_mst_connector_setting()`. [F181, F209, F349]
- In `hdcp_destroy()`, call `cancel_delayed_work_sync()` on `callback_dwork`, `watchdog_timer_dwork`, and `property_validate_dwork` for all links without holding `hdcp_work[i].mutex`, and remove `hdcp_work[0].attr` before freeing `srm`, `srm_temp`, and `hdcp_work`. Pair `drm_connector_get()`/`put()` when updating `hdcp_w->aconnector[conn_index]`. [F189, F307, F333]
- Call `dput(dir)` after `debugfs_lookup("crc", ...)` in `crtc_debugfs_init()`, `kfree(log_ctx.buf)` in `dtn_log_read()`, and `kfree(edid)` after bounds/revision checks in `dm_helpers_probe_acpi_edid()`. Zero `aconnector->notifier` after `cec_notifier_conn_unregister()` in `hdmi_cec_state_write()` and `link->local_sink` after `dc_sink_release()` in `trigger_hotplug()`. [F185, F186, F188, F313]

## API Contracts

- In `amdgpu_dm_crtc_helper_atomic_check()`, return `-EINVAL` if `crtc_state->enable` lacks `crtc->primary` in `plane_mask`, or if `async_flip` is set with `update_type != UPDATE_TYPE_FAST`. In `amdgpu_dm_crtc_set_vblank()`, toggle `vline0_irq` only when `amdgpu_ip_version(adev, DCE_HWIP, 0) != 0`, toggle vupdate IRQs only when `dc_supports_vrr()` is true, and call `drm_crtc_vblank_restore(crtc)` when enabling vblank with `disable_immediate` on PSR/Replay + IPS links. In `amdgpu_dm_crtc_handle_vblank()`, if `acrtc->event` is set and `pflip_status != AMDGPU_FLIP_SUBMITTED`, send the event under `event_lock`, call `drm_crtc_vblank_put(crtc)`, and clear `acrtc->event = NULL`. [F310, F343, F344, F346, F347]
- In `amdgpu_dm_check_crtc_color_mgmt()`, reset `cm_has_degamma` and `cm_is_degamma_srgb` to `false` first and use a temporary `out_tf` when `check_only` is true. Convert legacy 256-entry LUTs via `dc_fixpt_from_int()`, atomic 4096-entry LUTs via `dc_fixpt_from_fraction(..., MAX_DRM_LUT_VALUE)`, and UAPI S31.32 values via `amdgpu_dm_fixpt_from_s3132()`, using `__drm_ctm_to_dc_matrix()` for 9-element CRTC CTMs and `__drm_ctm_3x4_to_dc_matrix()` for 12-element plane CTMs. [F236, F253, F281, F294]
- Multiply whole-bpp DSC limits by `16` for `bpp_x16` APIs, reconstruct `old_payload` via `dm_helpers_construct_old_payload()` on MST payload removal, use `dm_dp_aux_transfer()` (`TO_DM_AUX`) only on `aconnector->dm_dp_aux.aux`, add `CONTROLLER_ID_D0` / `1` to `otg_inst` / `ddc_hw_inst` in `update_config()`, and subtract `x_start`/`y_start` from `x_end`/`y_end` for `roi[i].rect` width/height. [F226, F229, F256, F297, F350]
- Never call `amdgpu_dm_irq_register_interrupt()` (`GFP_KERNEL`) from atomic context. Use `amdgpu_irq_get()`/`put(&adev->hpd_irq)` only for `irq_source_hpd` with `irq_type < adev->mode_info.num_hpd` (and `dc_interrupt_set()` otherwise), and in `dp_phy_test_pattern_debugfs_write()`, call `dc_link_enable_hpd()` before `dc_link_dp_set_test_pattern()` when `!disable_hpd`, and `dc_link_disable_hpd()` after it when `disable_hpd`. [F322, F351, F352]

## Error Handling

- Verify `DAL_VALID_IRQ_SRC_NUM(irq_source)` and `int_context < INTERRUPT_CONTEXT_NUMBER` on IRQ registration/unregistration, check `handler_removed` before `kfree(handler)` in `remove_irq_handler()`, and reject `source < 0` from `dm_parse_crc_source()` so `"none"` (`0`) stays valid. Reject `srm_version == PSP_SRM_VERSION_MAX` (`0xFFFF`) with `-EINVAL` in `psp_set_srm()`, fall back from `dc_sink` to `dc_em_sink` (checking non-NULL) in `update_config()`, and in `dm_helpers_parse_edid_caps()`, return early if `sad_count <= 0`, clamp `sad_count` to `DC_MAX_AUDIO_DESC_COUNT`, and clamp negative `sadb_count` to `0`. [F220, F221, F225, F227, F250, F257, F270]
- Pass `dsc_branch_dec_caps` to `dc_dsc_parse_dsc_dpcd()` only if the 3-byte DPCD read returns `3`, and fall through to DSC compression when the uncompressed `drm_dp_mst_atomic_check()` returns `-ENOSPC` in `compute_mst_dsc_configs_for_link()`. In `dm_dp_aux_transfer()`, reject `msg->size > 16` with `-E2BIG`, return `payload.data[0]` on partial writes or `msg->size` when `result == 0 && !payload.reply[0]`, and log AUX errors with `drm_dbg_dp()`. [F228, F230, F260, F337]
- Check `adev->dm.dmub_srv != NULL` in `dmub_tracebuffer_show()`; clamp `*param_nums` to `max_param_num` and pass `long[]` to `parse_write_buffer_into_params()`; step by 2 in `edp_ilr_show()` and check `param[1] < edp_supported_link_rates_count` in `edp_ilr_write()`; and check `param[0] > 0` before `DIV_ROUND_UP` in `dp_dsc_slice_width_write()`/`height_write()`. [F214, F263, F266, F286, F299]

## External Contracts

- In `srm_data_write()`, stage chunks at `work->srm_temp + pos`, call `psp_set_srm()` with `pos + count`, and return `count` even if `psp_set_srm()` fails on an incomplete chunk. Require 4-byte aligned `*pos`/`size` in `dp_link_settings_read()`/`dp_phy_settings_read()`, and `param[0]` in `[6, 16]` in `dp_max_bpc_write()`. [F254, F265]

## Known Pitfalls

- Validate LUT sizes via `amdgpu_dm_verify_lut_sizes()` or `amdgpu_dm_verify_lut3d_size()` before `__drm_lut_to_dc_gamma()` or `__is_lut_linear()`. Store `block * EDID_LENGTH` in `unsigned short` in `dm_helpers_probe_acpi_edid()`, and compute raw EDID size as `(edid->extensions + 1) * EDID_LENGTH` after bounds checking in `dm_helpers_read_local_edid()` and `dm_dp_mst_get_modes()`. [F251, F282, F283, F300]
- Cast `edid->mfg_id[0..1]` to `u32` before shifting in `edid_extract_panel_id()`, use `u64` for `raw`/`mask` shifts in `dmub_trace_mask_show()`/`set()`, and in `dm_mst_get_pbn_divider()`, `kbps_to_peak_pbn()`, `bpp_x16_from_pbn()`, and `kbps_from_pbn()`, widen 32-bit operands to 64-bit unsigned before multiplying, use `div64_u64`/`div_u64`/`DIV64_U64_ROUND_UP`, and scale `pbn_div_x100` via `dfixed_const(pbn_div_x100) / 100`. [F284, F285, F287, F288]
