# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 8)

Implements AMDGPU VM page table management (`amdgpu_vm_pt`, CPU/SDMA updaters, TLB fences), DRM buddy VRAM allocation (`amdgpu_vram_mgr`), compute partitioning (`amdgpu_xcp`, `aqua_vanjaram`), XGMI hive/RAS (`amdgpu_xgmi`), VPE (`amdgpu_vpe`), ATHUB clockgating, and AtomBIOS interpreter/display helpers.

## Architecture & Data Flow
- In `amdgpu_vm_ptes_update`, overwriting a parent entry that has child PTs (`cursor.entry->bo` with `cursor.pfn < frag_start`) must set `params->needs_flush = true` and queue children onto `params->tlb_flush_waitlist` via `amdgpu_vm_pt_add_list`; when `params->unlocked` is true (`amdgpu_vm_ptes_update`, `amdgpu_vm_pt_free_list`), only modify leaf entries (descending until `amdgpu_vm_pt_descendant` is false) and never queue onto `tlb_flush_waitlist` [F1279, F1280].
- `struct amdgpu_bo_vm::entries` has 0 elements at `AMDGPU_VM_PTB`, so `amdgpu_vm_pt_descendant` must reject `level == AMDGPU_VM_PTB` before indexing `entries`; in `amdgpu_vm_pte_update_noretry_flags`, replace `*flags` with `adev->gmc.noretry_flags` only when `(*flags & AMDGPU_VM_NORETRY_FLAGS) == AMDGPU_VM_NORETRY_FLAGS` [F1300, F1322].
- In `amdgpu_vm_sdma_update`, 64-bit PTEs are staged backward in `ib->ptr` by decrementing `p->num_dw_left` by `nptes * 2` (after reserving `copy_pte_num_dw + 7` dwords), and `amdgpu_vm_sdma_copy_ptes` scales `p->num_dw_left * 4` for the byte address [F1345].
- In `amdgpu_vram_mgr_new`, non-kernel BOs (`tbo->type != ttm_bo_type_kernel`) are capped at `mc_vram_size - AMDGPU_VM_RESERVED_VRAM`; contiguous GFX12 DCC allocations (`adjust_dcc_size != 0`) must pass `roundup_pow_of_two(vres->base.size + adjust_dcc_size)` and `DRM_BUDDY_TRIM_DISABLE` to `drm_buddy_alloc_blocks` before aligning start to `adjust_dcc_size` and calling `drm_buddy_block_trim` [F1304, F1397].
- `amdgpu_vram_mgr_fini` must evict all resources (`ttm_resource_manager_evict_all`, returning early on error) and free `reserved_pages` (`drm_buddy_free_list`) before calling `drm_buddy_fini(&mgr->mm)`, which is skipped when `adev->gmc.is_app_apu` [F1370].
- `amdgpu_xcp_init` must clear `xcp[i].valid = false` across `MAX_XCP`, set `num_xcp_per_mem_partition` before `get_xcp_mem_id`, and call `amdgpu_xcp_update_partition_sched_list`; in `aqua_vanjaram_switch_partition_mode`, `adev->gfx.funcs->switch_partition_mode` must run before `amdgpu_xcp_init` to update `num_xcc_per_xcp` [F1288, F1290].
- `amdgpu_get_next_xcp` must not increment `*from` past the returned entry because `for_each_xcp` increments `++i`; in `__aqua_vanjaram_calc_xcp_mode`, `if (num_xcc_per_xcp == 1)` (`CPX`) must precede `switch (mode)`; in `__aqua_vanjaram_get_auto_mode`, keep `num_mem_partitions == 1`, `== num_xcc`, and `== num_xcc / 2` before `num_mem_partitions == 2 && !(adev->flags & AMD_IS_APU)` [F1327, F1328, F1332].
- In `amdgpu_xgmi_add_device`, if `supports_extended_data` is true, `amdgpu_xgmi_initialize_hive_get_data_partition(hive, true)` must be followed by `(..., false)` before returning; `pcs_clear_status` must write `0xFFFFFFFF` then `0` to `pcs_status_reg` via `WREG32_PCIE` [F1291, F1363].
- `vpe_hw_init` must ungate power (`AMD_PG_STATE_UNGATE`) before `vpe_load_microcode`/`vpe_ring_start`; `vpe_hw_fini` must call `cancel_delayed_work_sync(&adev->vpe.idle_work)` before `vpe_ring_stop` and `AMD_PG_STATE_GATE`; in `vpe_set_powergating_state`, `AMD_PG_STATE_GATE` must set `vpe->context_started = false` so `vpe_ring_begin_use` ungates power and toggles bit 0 of `context_indicator` [F1294, F1351].
- When `vpe.collaborate_mode` is true, `vpe_ring_emit_pipeline_sync`/`emit_wreg`/`emit_reg_wait` must emit `vpe_ring_emit_pred_exec(ring, 0, <exec_count>)` matching the following packet's dword length; `vpe_ring_emit_ib` requires `ib->gpu_addr & 0xffffffe0` (32B aligned) and `vpe_ring_emit_fence` requires `!(addr & 0x3)` (4B aligned); `vpe_ring_preempt_ib` must clear `queue0_preempt` and call `amdgpu_ring_set_preempt_cond_exec(ring, true)` even on poll timeout; `athub_v*_set_clockgating` must return early on `amdgpu_sriov_vf(adev)` and only write `ATHUB_MISC_CNTL` when `def != data` [F1295, F1305, F1354, F1357].
- Top-level `amdgpu_atom_execute_table` resets `data_block`, `reg_block`, `fb_base`, `divmul[0..1]` to `0` and `io_mode` to `ATOM_IO_MM` under `ctx->mutex`, while `atom_op_calltable` calls `amdgpu_atom_execute_table_locked` directly (setting `ctx->abort = true` on nested failure or `atom_op_jump` timeout); handlers calling `atom_put_dst` must snapshot `int dptr = *ptr` before `atom_get_dst`/`atom_skip_dst` and pass `&dptr` and `saved`; `ATOM_ARG_PS` uses little-endian words (`cpu_to_le16`/`32`) while `ATOM_ARG_FB` (`gctx->scratch`) uses host-endian `uint32_t` dwords (byte streams like DP AUX must use `amdgpu_atombios_copy_swap`) [F1296, F1297, F1313, F1314, F1330].
- `amdgpu_atombios_encoder_init_backlight` skips Apple `0x6741` and falls back to `acpi_video_register_backlight()` if `ATOM_BIOS_INFO_BL_CONTROLLED_BY_GPU` is unset or `!acpi_video_backlight_use_native()`; `amdgpu_atombios_encoder_set_backlight_level` updates `dig->backlight_level` and `mmBIOS_SCRATCH_2` before `setup_dig_transmitter`; in `amdgpu_atombios_encoder_setup_dig`, eDP `ATOM_ENABLE` powers on the panel before transmitter enable/link training, and `ATOM_DISABLE` disables video/D3/transmitter before panel power-off; `amdgpu_atombios_crtc_program_ss` skips `EnableSpreadSpectrumOnPPLL` when enabling with `ss->percentage == 0` or `ATOM_EXTERNAL_SS_MASK`, or when disabling if another enabled CRTC shares `pll_id` [F1299, F1366, F1367, F1368].

## Synchronization
- In `amdgpu_vm_pt_alloc`, call `amdgpu_vm_eviction_unlock(vm)` before `amdgpu_vm_pt_create` and `amdgpu_vm_eviction_lock(vm)` immediately after before checking `r`; before PTE/PDE writes, `amdgpu_vm_cpu_update` waits on `vmbo->bo.tbo.base.resv` (`DMA_RESV_USAGE_KERNEL`) and `amdgpu_vm_sdma_update` adds `DMA_RESV_USAGE_KERNEL` fences to `p->job` via `drm_sched_job_add_dependency` [F1222, F1242].
- `amdgpu_vm_cpu_commit` and `amdgpu_vm_sdma_commit` must atomically increment `p->vm->tlb_seq` when `p->needs_flush` is set; `amdgpu_vm_cpu_commit` then calls `mb()` and `amdgpu_device_flush_hdp`; in `amdgpu_vm_sdma_commit`, `p->unlocked` stores the fence in `p->vm->last_unlocked` instead of `root.bo->tbo.base.resv` (when `!p->unlocked`, add with `DMA_RESV_USAGE_BOOKKEEP`; when `fence && !p->immediate`, set `DRM_SCHED_FENCE_DONT_PIPELINE`) [F1243, F1244, F1282, F1391].
- `mgr->lock` in `amdgpu_vram_mgr` must be held for all `drm_buddy` calls on `mgr->mm` and all accesses to `reservations_pending`, `reserved_pages`, and `allocated_vres_list` (including `vres->task` updates/queries) [F1249, F1396].
- Pass `AMDGPU_XCP_FL_LOCKED` to `amdgpu_xcp_query_partition_mode` when holding `xcp_mgr->xcp_lock`; `__amdgpu_xcp_switch_partition_mode` must set `xcp_mgr->mode = AMDGPU_XCP_MODE_TRANS` under `xcp_lock`, restore it on failure, and call `amdgpu_xcp_sysfs_entries_update` on success; in `aqua_vanjaram_switch_partition_mode`, `amdgpu_amdkfd_check_and_lock_kfd` under `AMDGPU_XCP_OPS_KFD` must be paired with `amdgpu_amdkfd_unlock_kfd` on all paths [F1230, F1251, F1287].
- Hold `xgmi_mutex` across `xgmi_hive_list` accesses in `amdgpu_get_xgmi_hive` (initializing `hive` and calling `kobject_get` before unlocking) and `amdgpu_xgmi_remove_device`; in `amdgpu_xgmi_reset_on_init_work`, lock `hive->hive_lock` before `reset_domain`, and in `amdgpu_xgmi_reset_on_init`, unlock `hive->hive_lock` before `flush_work(&hive->reset_on_init_work)` [F1252, F1253].

## Object Lifetimes
- In `amdgpu_vm_tlb_fence_create`, `f->dependency` takes ownership of `*fence` without `dma_fence_get`, and `dma_fence_get(&f->base)` must precede `schedule_work(&f->work)` (if `kmalloc` fails, call `dma_fence_wait(*fence, false)`, `amdgpu_gmc_flush_gpu_tlb_pasid`, and set `*fence = dma_fence_get_stub()`); in `amdgpu_vm_sdma_commit`, `f = amdgpu_job_submit(p->job)` is paired with `dma_fence_put(f)` at exit, using `dma_fence_get(f)` + `swap` + `dma_fence_put(tmp)` for `last_unlocked` and `swap(*fence, f)` for `*fence` [F1218, F1220, F1241].
- In `amdgpu_vm_pt_alloc`, set `pt_bo->parent = amdgpu_bo_ref(cursor->parent->bo)`; in `amdgpu_vm_pt_free`, before `amdgpu_bo_unref(&entry->bo)`, call `amdgpu_vm_update_stats(..., -1)`, clear `entry->bo->vm_bo` and bulk_move, and unlink `entry->vm_status` under `status_lock`; in `amdgpu_vram_mgr_del`, under `mgr->lock`, unlink `vres_node` and sum `vis_usage` across `vres->blocks` before `drm_buddy_free_list` and `amdgpu_vram_mgr_do_reserve(man)`, then unlock and subtract `vis_usage` [F1223, F1224, F1226].
- `amdgpu_xcp_dev_unplug` must restore saved `rdev`, `pdev`, `driver`, and `vma_offset_manager` onto `p_ddev` (`i >= 1`) after `drm_dev_unplug` and before `amdgpu_xcp_drm_dev_free`; `amdgpu_xcp_select_scheds` increments `xcp[sel_xcp_id].ref_cnt` only if `num_scheds != 0`, and `amdgpu_xcp_release_sched` decrements it only if `drm_sched_wqueue_ready(entity->entity.rq->sched)` [F1228, F1229].
- `amdgpu_get_xgmi_hive` returns a kobject-referenced hive (creating a new hive holds both the list ref and a `kobject_get` caller ref, and initializes `hive->reset_domain` only when `!amdgpu_sriov_vf(adev)` by reusing `adev->reset_domain` if `type == XGMI_HIVE`), balanced by `amdgpu_put_xgmi_hive`; in `amdgpu_xgmi_remove_device`, clear `hive->hi_req_gpu = NULL` if `== adev` under `hive_lock`, call `amdgpu_xgmi_sysfs_rem_dev_info` before `atomic_dec_return(&hive->number_devices)` (putting the list ref if 0), and set `adev->hive = NULL` after `amdgpu_put_xgmi_hive` [F1231, F1232, F1292, F1360].
- Clear `adev->vpe.fw = NULL` after `release_firmware` in `amdgpu_vpe_init_microcode` (on error) and `vpe_sw_fini`; in `vpe_ring_test_ib`, free `ib` (`amdgpu_ib_free`) and `f` (`dma_fence_put`) before `amdgpu_device_wb_free(adev, index)`; in `amdgpu_atombios_encoder_init_backlight`/`fini_backlight`, `kfree(pdata)` on `IS_ERR(bd)` or after clearing `dig->bl_dev = NULL` and unregistering `bd`; in `amdgpu_atombios_encoder_get_lcd_info`, call `drm_edid_free(edid)` if `drm_edid_valid(edid)` is false [F1235, F1236, F1238, F1239].

## API Contracts
- In `amdgpu_vm_ptes_update`, `start`/`end` are 4KB PFNs while `dst` is a byte address/offset; `vm->update_funcs->update` takes byte offset `pe` (`entry_idx * 8`); `amdgpu_vm_pt_create` sets `bp.xcp_id_plus1 = xcp_id + 1` [F1258, F1259, F1344].
- In `amdgpu_vram_mgr.c`, `fpfn`/`lpfn`/`page_alignment`/`res->start` are PFNs while `drm_buddy` and `visible_vram_size` use bytes (`PAGE_SHIFT`); `to_amdgpu_vram_mgr_resource`, `amdgpu_vram_mgr_bo_visible_size`, and `amdgpu_vram_mgr_set_cleared` require `res && res->mem_type == TTM_PL_VRAM`; `amdgpu_vram_mgr_init` must register `man->cg` via `drmm_cgroup_register_region` and check `IS_ERR(man->cg)` before `ttm_resource_manager_init`; `amdgpu_vram_mgr_query_page_status` returns `0` (reserved), `-EBUSY` (pending), or `-ENOENT` (only call `amdgpu_vram_mgr_reserve_range` on `-ENOENT`); `amdgpu_vram_mgr_alloc_sgt`/`free_sgt` map chunks `<= AMDGPU_MAX_SG_SEGMENT_SIZE` with `dma_map_resource`/`dma_unmap_resource` (no `sg_page`) [F1263, F1346, F1380, F1387, F1395].
- `amdgpu_xcp_get_partition` takes 0-based `instance` and returns a partition bitmask (`BIT(i)`), not an index; `amdgpu_set_xcp_id` takes `ring->xcc_id` for compute/KIQ rings and `ring->me` otherwise; `xcp_metrics_show` must query size with `buf = NULL` and reject `size > PAGE_SIZE` (`-ENOSPC`) before filling `buf`; `aqua_vanjaram_encode_ext_smn_addressing` returns `0` when `ext_id == 0` and `(1ULL << 34) | ((u64)(ext_id & 0x3) << 32)` otherwise [F1265, F1266, F1268, F1307].
- `amdgpu_get_xgmi_link_status` returns `0` (inactive), `1` (active), or `< 0` (errno); `amdgpu_xgmi_get_bandwidth` requires non-NULL `min_bw`/`max_bw` (zeroed early) and non-NULL `peer_adev` in `AMDGPU_XGMI_BW_MODE_PER_PEER`; VPE ring wreg/reg_wait/rptr/wptr helpers convert dwords and bytes via `<< 2`/`>> 2`; `amdgpu_vpe_configure_dpm` must check all four `pratio_v*_freq` are non-zero before `vpe_internal_get_pratio`; `athub_v*_get_clockgating` must use `*flags |= ...` [F1261, F1269, F1270, F1273, F1340].
- `amdgpu_atombios_dp_aux_transfer` must return `msg->size` on write success (`ret >= 0`) and set `msg->reply = ack >> 4`; `amdgpu_atombios_crtc_program_pll` passes `clock / 10` for `crev` 1..6 and `clock * 10` for `crev` 7; `setup_dig_encoder` (v4) / `setup_dig_transmitter` (v5/v6) encode `hpd_id` as `0` (`AMDGPU_HPD_NONE`) or `hpd_id + 1` and `ucDigEncoderSel = 1 << dig_encoder`; in `amdgpu_atombios_encoder_get_lcd_info`, `usModePatchTableOffset` is absolute if `(frev == 1) && (crev < 2)` and relative to `data_offset` otherwise, while `ucFakeEDIDLength` is bytes if `128`, 128B blocks if `!= 0`, or 3B empty record if `0` [F1275, F1276, F1277, F1278].

## Error Handling
- On failure: `amdgpu_vm_sdma_prepare` must zero `p->num_dw_left` and call `amdgpu_job_free(p->job)` if `amdgpu_sync_push_to_job` fails; `amdgpu_vm_sdma_update` must call `dma_fence_put(fence)` and `dma_resv_iter_end(&cursor)` if `drm_sched_job_add_dependency` fails; `amdgpu_vram_mgr_new` must call `drm_buddy_free_list(mm, &vres->blocks, 0)` under `mgr->lock` if `drm_buddy_alloc_blocks` fails; `amdgpu_vram_mgr_alloc_sgt` must zero all `sg->length` after `sg_alloc_table` and only `dma_unmap_resource` where `sg->length != 0` [F1219, F1221, F1225, F1227].
- `amdgpu_xcp_dev_alloc` converts `-ENOSPC` from `amdgpu_xcp_drm_dev_alloc` to `ret = 0` (breaking to `out`); `amdgpu_xgmi_request_nps_change` reverts prior devices via `list_for_each_entry_continue_reverse` and sets `requested_nps_mode = UNKNOWN_MEMORY_PARTITION_MODE` under `hive_lock`; `amdgpu_xgmi_ras_late_init` calls `amdgpu_ras_block_late_fini` if `amdgpu_ras_bind_aca` fails; `amdgpu_ras_error_inject_xgmi` preserves `psp_ras_trigger_error` return (`ret2`) across cleanup calls; `vpe_ring_test_ib` maps `dma_fence_wait_timeout` `0` to `-ETIMEDOUT` and reassigns positive jiffies to `0`/`-EINVAL`; `amdgpu_atom_execute_table_locked` frees `ectx.ws` at `free:` on all paths [F1233, F1234, F1237, F1260, F1267, F1271].

## External Contracts
- In `aqua_vanjaram.c`, `aqua_vanjaram_read_*_state` must check `max_size >= sizeof(*state_header) + amdgpu_reginst_size(...)` (`-EOVERFLOW`), and `num_regs` sums in `*_reg_addrs` must match `NUM_*_SMN_REGS`; `amdgpu_xgmi_show_connected_port_num` formats 1-based node indices (`current_node + 1`, `i + 1`); `amd_sriov_msg_pf2vf_info` and `amd_sriov_msg_vf2pf_info` must remain 1024 bytes (`AMD_SRIOV_MSG_SIZE_KB << 10`) by adjusting `*_INFO_FILLED_SIZE` [F1309, F1310, F1393, F1394].

## Known Pitfalls
- `for_each_amdgpu_vm_pt_dfs_safe` with non-NULL `start` stops before visiting `start->entry`, so `amdgpu_vm_pt_add_list` must handle `start->entry` after the loop; in `amdgpu_vm_ptes_update`, skip `amdgpu_vm_pt_next` when `frag < shift` (`else if (frag >= shift)`) and cast `AMDGPU_GPU_PAGE_SIZE` and `mask + 1` to `uint64_t` before `<< shift`; in `amdgpu_vm_pte_fragment`, use `min_t(unsigned int, ffs(start) - 1, fls64(end - start) - 1)` and `~((1ULL << max_frag) - 1)` [F1319, F1321, F1333, F1334, F1335].
- In `amdgpu_vram_mgr_new`, on `-ENOSPC` contiguous fallback, change `pages_per_block` from `~0ul` before `continue`; guard `XCP_INST_MASK` with `num_inst ? ... : 0`; in `__aqua_vanjaram_get_xcp_ip_info`, use `DIV_ROUND_UP` for `num_sdma_xcp`/`num_vcn_xcp` and guard `num_xcp / num_vcn` with `if (num_vcn && num_xcp > num_vcn)`; in `aqua_vanjaram_read_*_state`, advance `p = reg_data` rather than indexing across flexible arrays; mask `num_hops & 0x7` in `amdgpu_xgmi_get_hops_count`; check both bounds and `!= NULL` on `xgmi_v6_4_0_ras_error_code_ext`; in `atom.c`, widen `atom_op_mul32` to `uint64_t`, guard `src != 0` with `do_div` in `atom_op_div32`, shift `val << 2` for `ATOM_IO_MM` `idx == 0` in `atom_put_dst`, and keep `amdgpu_atombios_dp_process_aux_ch` offsets at `base = (u8 *)(scratch + 1)` (4) and `recv = base + 16` (20) [F1311, F1312, F1325, F1338, F1339, F1341, F1347, F1349, F1369].
