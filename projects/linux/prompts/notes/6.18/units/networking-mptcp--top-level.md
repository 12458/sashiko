# NETWORKING [MPTCP] — (top level)

Implements Multipath TCP (MPTCP v1, RFC 8684) for IPv4/IPv6, multiplexing a `struct mptcp_sock` across TCP subflow sockets via ULP hooks, with option parsing/generation, SHA-256/HMAC handshakes, data sequence mapping/retransmission, pluggable schedulers, and kernel/userspace Path Managers (PM).

## Architecture & Data Flow
- Closed `msk->first` stays on `msk->conn_list`: `mptcp_close_ssk()` must gate close accounting on `subflow->close_event_done`, `mptcp_pm_rm_addr_or_subflow()` must skip `TCPF_FIN_WAIT1 | TCPF_FIN_WAIT2 | TCPF_CLOSING | TCPF_CLOSE`, and any `msk->conn_list` walk calling `mptcp_close_ssk()` / `__mptcp_close_ssk()` must use `mptcp_for_each_subflow_safe()`. [F8, F98]
- `__mark_subflow_endp_available()` and `mptcp_pm_nl_rm_addr()` do not decrement `local_addr_used` or `add_addr_accepted` for ID 0, so kernel PM subflow creation must not increment `local_addr_used` when `local.addr.id == msk->mpc_endpoint_id` or `add_addr_accepted` when `remote.id == 0`. [F9]
- In `mptcp_pm_create_subflow_or_signal_addr()` and `fill_local_addresses_vec_c_flag()`, `__clear_bit(local.addr.id, msk->pm.id_avail_bitmap)` must run right after `select_local_address()` before any `continue`. When `mptcp_pm_add_addr_c_flag_case(msk)` is true, `mptcp_pm_add_addr_received()` schedules `MPTCP_PM_ADD_ADDR_RECEIVED` for `addr->id > 0` even if `!READ_ONCE(pm->accept_addr)`, and `fill_local_addresses_vec()` pairs `MPTCP_PM_ADDR_FLAG_SUBFLOW` endpoints while updating `id_avail_bitmap` and `local_addr_used`. [F92, F106]
- Address ID bitmaps (`id_bitmap`, `id_avail_bitmap`, `unavail_id`) must be sized `MPTCP_PM_MAX_ADDR_ID + 1`, and `subflow->local_id` (`s16`, init `-1`) must be converted via `subflow_get_local_id()` before indexing. In `mptcp_pm_nl_append_new_local_addr()`, if `find_next_zero_bit()` wraps to 0 (`!entry->addr.id`) while `pernet->next_id != 1`, reset `pernet->next_id = 1` before `goto find_next`. [F82, F103]
- Mutating `pernet->endp_list` under `pernet->lock` must update `endp_signal_max`, `endp_subflow_max`, `endp_laminar_max`, `endpoints`, and `id_bitmap` in lockstep, while `__reset_counters()` on flush must preserve `limit_add_addr_accepted` and `limit_extra_subflows`. `parse_limit()` and `mptcp_pm_nl_append_new_local_addr()` must cap `limit_add_addr_accepted`, `limit_extra_subflows`, and `pernet->endpoints` at `MPTCP_PM_ADDR_MAX` (8). [F56, F75]
- `msk->first_pending` tracks the first unsent `mptcp_data_frag` in `msk->rtx_queue` (or `NULL`): `__mptcp_clean_una()` must advance `first_pending` before `dfrag_clear()` when `dfrag == msk->first_pending` during `msk->recovery` and clamp `dfrag->already_sent` up to `delta` (`snd_una - dfrag->data_seq`, after `delta <= dfrag->data_len`) before subtracting `delta`; `__mptcp_retransmit_pending_data()` must reset `first_pending` and zero `already_sent`. [F62, F85]
- `mptcp_data_queue_ofo()` must set `msk->ooo_last_skb = skb` when `out_of_order_queue` was empty or `!skb_rb_next(skb)`. In `__mptcp_ofo_queue()`, advance `p = rb_next(p)` before `rb_erase()`. `__mptcp_try_coalesce()` must reject coalescing if `cant_coalesce` is set (set on TFO data SKBs in `mptcp_fastopen_subflow_synack_set_params()`), `offset` is non-zero, or `(to->len + from->len) > (READ_ONCE(sk->sk_rcvbuf) >> 3)`. [F61, F100, F158]
- Every path populating a new `SKB_EXT_MPTCP` (`struct mptcp_ext`) must `memset(mpext, 0, sizeof(*mpext))` first because `mptcp_ext_matches()` uses `memcmp()`. `mptcp_skb_ext_copy()` must set `from_ext->frozen = 1`, and `mptcp_sendmsg_frag()` must check `mptcp_skb_can_collapse_to()` (`!mpext->frozen`), set `TCP_SKB_CB(skb)->eor = 1` when disallowed, and clamp `ssk->sk_gso_max_size` to `MPTCP_MAX_GSO_SIZE` before `tcp_send_mss()`. [F122, F160, F163]
- `mptcp_set_rwin()` must cap `new_win` to `(65535U << tp->rx_opt.rcv_wscale)` (or `MAX_TCP_WINDOW` unscaled) before writing `th->window`, and `WRITE_ONCE(msk->old_wspace, tp->rcv_wnd)` on all exit paths. `mptcp_rcv_space_adjust(msk, copied)` must run at the end of `__mptcp_recvmsg_mskq()` with single-walk bytes, and when `mptcp_rcvbuf_grow(sk)` grows `sk->sk_rcvbuf`, it must update `rcvq_space.space` and call `tcp_rcvbuf_grow(ssk)` under `lock_sock_fast(ssk)` for each subflow. [F55, F69, F102, F116]
- Because `opts->addr` and `opts->ahmac` alias `opts->ext_copy` in `struct mptcp_out_options`, `mptcp_established_options_add_addr()` must stage the address in a local `struct mptcp_addr_info` and only write `opts->addr` (and zero `opts->ahmac` if `drop_other_suboptions`) after confirming `OPTION_MPTCP_ADD_ADDR` fits. `MPTCPOPT_RM_ADDR` in `mptcp_parse_option()` and `mptcp_rm_addr_len()` requires `rm_list.nr` in `[1, MPTCP_RM_IDS_MAX]`. [F57, F77]
- When `mptcp_disconnect()` zeroes `msk->flags` under `msk->fallback_lock`, restore `allow_subflows = true` and `allow_infinite_fallback = true`; when `mptcp_sendmsg_fastopen()` calls `mptcp_disconnect(sk, 0)` directly and it returns 0, increment `sk->sk_disconnects` and set `sk->sk_socket->state = SS_UNCONNECTED`. Locked `sk` state transitions must use `mptcp_set_state(sk, state)`. Transitioning `sk` to `TCP_CLOSE` in `mptcp_check_data_fin_ack()` / `mptcp_check_data_fin()` must call `mptcp_shutdown_subflows(msk)`. [F53, F54, F59, F72]
- In `struct mptcp_subflow_context`, per-connection fields go inside `struct_group(reset, ...)` while persistent pointers/callbacks/nodes (`node`, `delegated_node`, `tcp_sock`, `conn`, `icsk_af_ops`, `tcp_state_change`, `tcp_error_report`) stay outside for `mptcp_subflow_ctx_reset()`. In `mptcp_pm_data_reset()`, set `pm->work_pending = true` only when `pm->pm_type == MPTCP_PM_TYPE_KERNEL`, preserving `pm->lock`, `pm->anno_list`, and `pm->userspace_pm_local_addr_list`. [F65, F66]
- In `mptcp_stream_accept()`, if `inet_csk_accept()` returns a fallback child where `!sk_is_mptcp(newsk)` (or `!subflow->conn`), set `newsock->sk->sk_socket->ops = mptcp_fallback_tcp_ops(newsock->sk)`. For IPv6 (`struct mptcp6_sock`), `mptcp_sk_clone_init()` must reset `inet_sk(nsk)->pinet6 = mptcp_inet6_sk(nsk)`. [F128, F129]

## Synchronization
- Under a subflow lock (`ssk`) or in BH context, never call `lock_sock(sk)` on parent `msk`; hold `mptcp_data_lock(sk)`, check `!sock_owned_by_user(sk)`, and if owned, defer via `msk->cb_flags` to `mptcp_release_cb()`. `mptcp_release_cb()` must splice `msk->join_list` and clear `msk->cb_flags & MPTCP_FLAGS_PROCESS_CTX_NEED` before dropping `sk->sk_lock.slock` to run callbacks or lock `ssk`, then re-acquire `sk->sk_lock.slock`. [F27, F107]
- Callers of `mptcp_pm_addr_send_ack()`, `mptcp_pm_remove_addr()`, `mptcp_pm_remove_anno_addr()`, `mptcp_pm_remove_addr_entry()`, and `mptcp_pm_rm_subflow()` must hold `lock_sock(sk)`. PM helpers entered with `msk->pm.lock` held (`mptcp_pm_send_ack()`, `mptcp_pm_rm_addr_or_subflow()`, `mptcp_pm_create_subflow_or_signal_addr()`, `mptcp_pm_nl_add_addr_received()`) must `spin_unlock_bh(&msk->pm.lock)` before locking/connecting/closing a subflow and re-acquire it before returning. Hold `spin_lock_bh(&msk->pm.lock)` continuously across any lookup-and-modify/unlink on `msk->pm.userspace_pm_local_addr_list`. [F17, F24, F25]
- Hold `spin_lock_bh(&msk->fallback_lock)` across checking and updating `msk->allow_subflows`, `msk->allow_infinite_fallback`, and `MPTCP_FALLBACK_DONE` in `__mptcp_finish_join()`, `mptcp_finish_join()`, `__mptcp_retrans()`, `mptcp_pm_mp_fail_received()`, and `__mptcp_try_fallback()`. [F21]
- Callers of `mptcp_sendmsg_frag()` holding a BH spinlock (`mptcp_data_lock(sk)` or `msk->fallback_lock`) must set `info.data_lock_held = true` so `mptcp_alloc_tx_skb()` uses `GFP_ATOMIC`. When `mptcp_try_fallback()` calls `tcp_shutdown(ssk, SEND_SHUTDOWN)`, temporarily set `ssk->sk_allocation = GFP_ATOMIC`. `mptcp_subflow_delegate()` requires softirq/BH context; process-context callers must disable BHs or set `subflow->delegated_status` directly when `sock_owned_by_user(sk)`. [F135, F136, F137]
- `__mptcp_push_pending()` locks `ssk` (releasing `prev_ssk` via `mptcp_push_release()`) only when `ssk != prev_ssk`, and must call `mptcp_push_release(ssk, &info)` after the outer loop if `ssk` is non-NULL. While `mptcp_sendmsg_fastopen()` holds `lock_sock(ssk)` and sets `msk->fastopening = 1`, `mptcp_connect()` must skip locking `ssk` and `mptcp_disconnect()` must return `-EBUSY`. [F104, F143]
- `mptcp_pm_nl_append_new_local_addr()` calls `synchronize_rcu()` when `replace == true` matches an implicit endpoint, so `mptcp_pm_nl_get_local_id()` (atomic/RCU receive path) must pass `replace = false`. `mptcp_sched_find()` and `mptcp_pm_find()` require `rcu_read_lock()` (held across `mptcp_init_sched()` until `bpf_try_module_get()` succeeds). `subflow_get_info()` requires `lock_sock_fast(sk)` and `rcu_read_lock()` with `rcu_dereference(inet_csk(sk)->icsk_ulp_data)`, and `mptcp_diag_dump_listeners()` must pin `ctx->conn` via `refcount_inc_not_zero(&sk->sk_refcnt)` under `rcu_read_lock()` and `ilb->lock`. [F138, F145, F148]

## Object Lifetimes
- `mptcp_userspace_pm_get_sock()` and `mptcp_token_get_sock()` return `msk` with a refcount callers must release via `sock_put((struct sock *)msk)`. `mptcp_schedule_work(sk)` calls `sock_hold(sk)` when `schedule_work(&msk->work)` succeeds; drop it via `sock_put(sk)` in `mptcp_worker()` or `__sock_put(sk)` in `mptcp_cancel_work()` when `cancel_work_sync()` returns `true`. When `mptcp_subflow_delegate()` sets `BIT(MPTCP_DELEGATE_SCHEDULED)`, it calls `sock_hold(ssk)`; only `mptcp_napi_poll()` on that CPU may dequeue it, clear `MPTCP_DELEGATE_SCHEDULED`, and call `sock_put(ssk)`. [F1, F11, F12]
- `mptcp_close_ssk()` and `__mptcp_close_ssk()` can free `subflow` and `sock_put(ssk)`, so read `subflow`/`ssk` fields beforehand. In `__mptcp_close_ssk()`, `msk->first` is only disconnected via `__mptcp_subflow_disconnect()` until `msk->free_first` is set by `mptcp_destroy()` (unless `msk->in_accept_queue` and `SOCK_DEAD`), and disposing of `msk->first` must `WRITE_ONCE(msk->first, NULL)`. [F6, F7]
- `mptcp_init_sched()` pins `sched` via `bpf_try_module_get()` before setting `msk->sched` and calling `sched->init(msk)`; `mptcp_release_sched()` must clear `msk->sched = NULL`, call `sched->release(msk)` if defined, and call `bpf_module_put()`. Removing a `struct mptcp_data_frag` via `dfrag_clear()` must unlink `dfrag->list`, `dfrag_uncharge()`, and `put_page(dfrag->page)` (and `__mptcp_clean_una()` must call `dfrag_uncharge(sk, delta)` when advancing `data_seq`). [F13, F14]
- Moving a received SKB from `ssk` to `msk` (`mptcp_init_skb()`, `mptcp_fastopen_subflow_synack_set_params()`) must unlink it and call `skb_ext_reset(skb)` and `skb_orphan(skb)` before `skb_set_owner_r(skb, sk)`. `mptcp_skb_ext_move(to, from)` must `skb_ext_put(to)` if active, copy extensions, and zero `from->active_extensions`. In `mptcp_incoming_options()`, zero-length packets (`seq == end_seq`) must process `DATA_FIN` and return before `skb_ext_add(skb, SKB_EXT_MPTCP)`. [F16, F161, F162]
- Removing `struct mptcp_pm_add_entry` from `msk->pm.anno_list` (`mptcp_pm_del_add_timer()`, `mptcp_pm_free_anno_list()`) must unlink under `msk->pm.lock`, drop `msk->pm.lock`, call `sk_stop_timer_sync(sk, &entry->add_timer)`, and `kfree(entry)`. `userspace_pm_local_addr_list` entries (`sock_kmemdup()`) must be freed via `sock_kfree_s()` or `kfree_rcu_mightsleep()` + `atomic_sub(sizeof(*match), &sk->sk_omem_alloc)`. `pernet->endp_list` requires `list_for_each_entry_rcu()` and `synchronize_rcu()` before `__mptcp_pm_release_addr_entry()`. When `mptcp_pm_nl_append_new_local_addr()` with `replace == false` matches an implicit endpoint, it frees `entry` internally; on `< 0` return, the caller must free `entry`. [F18, F41, F131, F146]

## API Contracts
- `mptcp_sk(sk)` is valid only on `IPPROTO_MPTCP` parent sockets; `tcp_sk(sk)` and `mptcp_subflow_ctx(sk)` are valid only on `IPPROTO_TCP` subflows (parent is `mptcp_sk(mptcp_subflow_ctx(sk)->conn)`). Before treating an arbitrary `struct sock *` as an MPTCP subflow, verify `sk_fullsock(sk)`, `sk->sk_protocol == IPPROTO_TCP`, and `sk_is_mptcp(sk)` (or `ctx && !strcmp(icsk_ulp_ops->name, "mptcp")` on listeners). [F51, F126]
- `mptcp_pm_get_local_id()`, `mptcp_pm_nl_get_local_id()`, `mptcp_userspace_pm_get_local_id()`, `mptcp_pm_nl_append_new_local_addr()`, and `mptcp_userspace_pm_append_new_local_addr()` return a non-negative `u8` ID (including 0) or negative `int` error; store in a signed `int` and test `< 0`. `mptcp_subflow_delegate()` takes an unshifted `MPTCP_DELEGATE_*` index; `mptcp_subflow_process_delegated()` takes a `BIT(MPTCP_DELEGATE_*)` mask. [F40, F46]
- `mptcp_crypto_hmac_sha()` writes `SHA256_DIGEST_SIZE` (32) bytes, requiring a `>= 32`-byte buffer. `mptcp_get_options()` only zeroes `*(u32 *)&mp_opt->status = 0`, so `mptcp_parse_option()` must initialize all fields read for any set `suboptions` flag (`addr.port = 0`, `ahmac = 0`). Sysctl handlers in `net/mptcp/ctrl.c` must resolve `struct mptcp_pernet` from `ctl->data` (never `current->nsproxy->net_ns`) and keep `path_manager` and `pm_type` synchronized. [F47, F125, F151, F153]

## Error Handling
- After `mptcp_alloc_tx_skb()` entails a new `skb` onto `ssk` in `mptcp_sendmsg_frag()`, any early return before attaching payload must call `tcp_remove_empty_skb(ssk)`. In `mptcp_connect()`, if `pre_connect`/`connect` fails after `mptcp_token_new_connect(ssk)`, call `mptcp_token_destroy(msk)` and `mptcp_set_state(sk, TCP_CLOSE)`. In `mptcp_pm_nl_subflow_create_doit()`, if `__mptcp_subflow_connect()` fails after `mptcp_userspace_pm_append_new_local_addr()`, call `mptcp_userspace_pm_delete_local_addr(msk, &entry)` under `msk->pm.lock` without overwriting `err`. [F15, F19, F50]
- In `mptcp_incoming_options()`, return `false` if `skb_ext_add(skb, SKB_EXT_MPTCP)` returns `NULL` on a payload packet. In `mptcp_recvmsg()`, abort immediately to `out_err` if `sk_wait_data() < 0`. In `__mptcp_move_skbs_from_subflow()`, peer DSS mismatches must use `DEBUG_NET_WARN_ON_ONCE(1)` and call `mptcp_dss_corruption(msk, ssk)`. [F35, F43, F169]

## External Contracts
- `mptcp_pm_nl_add_addr_doit()` and `mptcp_pm_nl_set_flags()` must reject `MPTCP_PM_ADDR_FLAG_IMPLICIT`, reject combining `FULLMESH` with `SIGNAL` or `IMPLICIT`, and reject non-zero `addr.port` unless `address_use_port()` is true (`SIGNAL && !SUBFLOW`). In `mptcp_pm_nl_ops`, `GET_ADDR` and `GET_LIMITS` must not set `GENL_UNS_ADMIN_PERM`, mutating commands must set it, `MPTCP_PM_EV_GRP_NAME` must set `GENL_MCAST_CAP_NET_ADMIN`, and `subflow_get_info()`/`subflow_get_info_size()` must gate sequence/offset attributes on `net_admin`. [F73, F74, F93, F164, F165]

## Known Pitfalls
- `struct mptcp_addr_info::port` is `__be16`: convert `MPTCP_PM_ADDR_ATTR_PORT` (`NLA_U16`) with `htons()`/`ntohs()`, while `MPTCP_ATTR_SPORT`/`DPORT` use `nla_put_be16()`. In `mptcp_write_options()`, `ptr` is `__be32 *` (advance by 32-bit words, not bytes). In `mptcp_stream_accept()` and `mptcp_diag_dump_listeners()`, `newsk` / `sk` starts as the TCP subflow and is reassigned in-place to `subflow->conn` (parent `msk`). Clamp 64-bit window deltas to `U32_MAX` in `mptcp_set_rwin()` and `mptcp_check_allowed_size()`. [F84, F110, F111, F115, F123]
