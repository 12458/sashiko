# NFS, SUNRPC, AND LOCKD CLIENTS — fs/nfs (part 1)

Implements core NFS client functionality including shared client and server lifecycle management (client.c), regular file and directory VFS operations (file.c, dir.c), uncached direct and swap I/O (direct.c), NFSv4 delegations (delegation.c), and the NFSv4 callback server (callback.c, callback_proc.c, callback_xdr.c). It also includes the pNFS block/SCSI layout driver (blocklayout/*), sunrpc cache and DNS resolution helpers (cache_lib.c, dns_resolve.c), and NFS re-export operations (export.c).

## Architecture & Data Flow

- In `struct pnfs_block_dev`, `dev->nr_children` discriminates composite volumes (`bl_parse_concat()` and `bl_parse_stripe()`, which increment `nr_children` only as each child succeeds) from leaf volumes (`dev->bdev_file`), so `bl_register_dev()`, `bl_unregister_dev()`, and `bl_free_device()` must branch on `dev->nr_children`. [F40]
- In `struct cb_layoutrecallargs`, `cbl_fh`, `cbl_range`, and `cbl_stateid` are populated only when `cbl_recall_type == RETURN_FILE` and `cbl_fsid` only when `cbl_recall_type == RETURN_FSID`, and `do_callback_layoutrecall()` and its helpers return host-endian `u32` status codes converted to `__be32` in `nfs4_callback_layoutrecall()`. [F50]
- Whenever `NFS4CLNT_DELEGRETURN`, `NFS4CLNT_DELEGRETURN_DELAYED`, or `NFS4CLNT_DELEGATION_EXPIRED` is set on `clp->cl_state` (including error-retry paths in `nfs_server_return_marked_delegations()` and `nfs_server_reap_expired_delegations()`), the matching `NFS4SERV_*` bit must be set on `server->delegation_flags`. [F59]
- Bit 0 (`1UL`) of `dentry->d_time` is reserved for the delegation verifier tag while `nfs_force_lookup_revalidate()` advances `NFS_I(dir)->cache_change_attribute` by 2, and `nfs_clear_verifier_delegated()` must be called whenever an attached delegation is revoked or transitions to `NFS_DELEGATION_RETURNING`. [F60]
- `server->nr_active_delegations` is decremented only when `NFS_DELEGATION_REVOKED` is newly set in `nfs_mark_delegation_revoked()`, and incremented when attaching a delegation in `nfs_inode_set_delegation()` or clearing `NFS_DELEGATION_REVOKED` in `nfs_inode_reclaim_delegation()` and `nfs_update_inplace_delegation()`. [F61]
- In `nfs_direct_read_completion()` and `nfs_direct_write_completion()`, non-redo O_DIRECT I/O completions must update delegated timestamps via `nfs_update_delegated_atime(dreq->inode)` on read and `nfs_update_delegated_mtime_locked(dreq->inode)` (under `inode->i_lock` with `nfs_direct_file_adjust_size_locked()`) on write. [F64]
- In `nfs_server_insert_lists()` and `nfs_server_remove_lists()`, `server->client_link` in `clp->cl_superblocks`, `server->master_link` in `nn->nfs_volume_list`, and `NFS_CS_STOP_RENEW` on `clp->cl_res_state` (cleared on insert, set when `clp->cl_superblocks` becomes empty) must be updated together under `nn->nfs_client_lock`. [F65]
- In `fs/nfs/dir.c`, every `struct nfs_access_entry` in `nfsi->access_cache` is paired with an entry in `nfsi->access_cache_entry_lru` under `inode->i_lock` and counted in `nfs_access_nr_entries`, while `NFS_INO_ACL_LRU_SET` in `nfsi->flags` tracks membership of `nfsi->access_cache_inode_lru` in `nfs_access_lru_list` under `nfs_access_lru_lock`. [F66]

## Synchronization

- `nfs_mark_client_ready()` must execute `smp_wmb()` before storing `clp->cl_cons_state`, paired with `smp_rmb()` in `nfs_found_client()` after `nfs_wait_client_init_complete()` confirms `clp->cl_cons_state == NFS_CS_READY`, so client fields initialized before publication are visible to concurrent callers. [F15]
- Attaching or detaching an inode's delegation (`nfsi->delegation`, `server->delegations`, and `server->delegation_hash_table`) in `nfs_inode_set_delegation()` and `nfs_detach_delegation_locked()` must be serialized by `clp->cl_lock`, with `delegation->lock` nested inside `clp->cl_lock` when updating or detaching an existing delegation. [F20]
- `nfs4_get_valid_delegation()` dereferences `NFS_I(inode)->delegation` via `rcu_dereference()` without taking a reference count, so callers must hold `rcu_read_lock()` across both the call and any subsequent access to the returned `struct nfs_delegation` unless they pin `delegation->refcount` via `nfs_get_delegation()`. [F21]
- When iterating `server->delegations` under `rcu_read_lock()` in `nfs_server_return_marked_delegations()` or `nfs_server_reap_unclaimed_delegations()`, the caller must pin the inode via `nfs_delegation_grab_inode()` and claim the delegation via `nfs_start_delegation_return_locked()` before calling `rcu_read_unlock()`. [F22]
- In `nfs_delegation_claim_opens()`, the caller must pin `ctx` with `get_nfs_open_context(ctx)` before dropping `rcu_read_lock()`, acquire `sp->so_delegreturn_mutex` around `nfs4_open_delegation_recall()` and `nfs_delegation_claim_locks()`, release `ctx`, and restart the `nfsi->open_files` list walk from the head. [F24]
- Callers of `nfs_force_lookup_revalidate(dir)` must hold `dir->i_lock` while it increments `NFS_I(dir)->cache_change_attribute` by 2. [F25]
- Setting `dentry->d_fsdata = NFS_FSDATA_BLOCKED` in `block_revalidate()` requires holding `dentry->d_lock`, and clearing it in `unblock_revalidate()` must use `store_release_wake_up(&dentry->d_fsdata, NULL)` to pair with `wait_var_event(&dentry->d_fsdata, smp_load_acquire(&dentry->d_fsdata) != NFS_FSDATA_BLOCKED)` in `__nfs_lookup_revalidate()`. [F26]
- In `nfs_rename()`, if `rpc_wait_for_completion_task(task)` fails (e.g. interrupted by a signal), setting `((struct nfs_renamedata *)task->tk_calldata)->cancelled = 1` must be followed by `smp_wmb()` before calling `rpc_put_task(task)` so `nfs_async_rename_release()` observes `cancelled == 1`. [F28]

## Object Lifetimes

- Once `nfs_get_client` links a newly allocated `nfs_client` onto `nn->nfs_client_list`, `rpc_ops->init_client` (such as `nfs_init_client`) must call `nfs_mark_client_ready` to set `cl_cons_state` and wake `nfs_client_active_wq` before calling `nfs_put_client` on failure. [F1]
- `nfs_detach_delegation_locked` (and its wrappers `nfs_detach_delegation` and `nfs_inode_detach_delegation`) unlinks the delegation from `nfsi->delegation`, `server->delegations`, and `delegation->hash` without decrementing `delegation->refcount`, transferring the initial reference to the caller that receives a non-NULL return. [F3]
- `nfs_direct_req_alloc` initializes `dreq->kref` to 2 (one for the caller and one for `nfs_direct_complete`), so any path in `nfs_file_direct_read` or `nfs_file_direct_write` that exits before scheduling I/O or schedules 0 bytes must call `nfs_direct_req_release(dreq)` twice (and balance `inode_dio_begin` with `inode_dio_end`). [F6]
- In `nfs4_callback_compound`, `nfs4_cb_free_slot(&cps)` must be called before `nfs_put_client(cps.clp)` because freeing the backchannel slot accesses `cps->clp->cl_session->bc_slot_table`. [F7]
- `ext_tree_prepare_commit` and `ext_tree_free_commitdata` use `arg->layoutupdate_pages != &arg->layoutupdate_page` to distinguish a multi-page `__vmalloc` buffer (`arg->start_p` and `arg->layoutupdate_pages`) from the single page `arg->layoutupdate_page`, and must free any allocated buffers before returning `-ENOMEM`. [F11]
- Every `nfs_cache_array_entry.name` in a directory folio is heap-allocated by `nfs_readdir_copy_name`, so any path that reinitializes a cached readdir folio or frees an anonymous uncached readdir folio must call `nfs_readdir_clear_array` before resetting `array->size` or calling `folio_put`. [F12]
- In `nfs_write_begin`, `write_begin_get_folio` returns a locked and referenced folio; if `nfs_flush_incompatible` fails, both `folio_unlock` and `folio_put` must be called, whereas if `nfs_read_folio` is called for read-modify-write, `nfs_read_folio` unlocks the folio so only `folio_put` is called before retrying or returning. [F14]
- `nfs_free_server()` must call `nfs_server_remove_lists()` (which unlinks `server->client_link` via `list_del_rcu()` and `server->master_link` under `nn->nfs_client_lock` and calls `synchronize_rcu()`) before invoking `server->destroy()`, shutting down RPC clients, or scheduling `delayed_free()` via `call_rcu()`. [F19]

## API Contracts

- `ext_tree_insert(bl, new)` takes ownership of `new` and its `new->be_device` reference when it returns 0 (either linking `new` into the rbtree or freeing it on merge/overlap), but leaves `new` and `new->be_device` owned by the caller when it returns a negative error. [F10]
- When extent decoding in `bl_alloc_lseg()` fails with `-ENODEV` (from `bl_find_get_deviceid()`), `bl_alloc_lseg()` must set `NFS_LSEG_UNAVAILABLE` on `lseg->pls_flags` and return the allocated `lseg` pointer rather than `ERR_PTR(-ENODEV)`, whereas all other negative status codes must free `lseg` and return `ERR_PTR(status)`. [F41]
- In `struct pnfs_block_extent`, `be_f_offset`, `be_length`, and `be_v_offset` are in 512-byte sectors (`SECTOR_SHIFT`) while `pnfs_block_dev_map` fields and XDR wire offsets are in bytes, and `be_v_offset` is only valid when `be_state != PNFS_BLOCK_NONE_DATA`. [F43]
- `clp->cl_cons_state` encodes in-progress initialization as `> NFS_CS_READY` (`0`), ready as `NFS_CS_READY` (`0`), and failure as `< 0` (negative errno), and `nfs_client_init_status(clp)` must only be called after `nfs_client_init_is_complete(clp)` returns `true`. [F46]
- `nfs_alloc_server()` returns `NULL` on failure, whereas `nfs_alloc_client()`, `nfs_get_client()`, `nfs_init_client()`, `nfs_create_server()`, and `nfs_clone_server()` return an `ERR_PTR(-errno)` on failure. [F47]
- Before each call to `xdr_decode()`, `nfs_readdir_entry_decode()` must reset `entry->fattr->label->len = NFS4_MAXLABELLEN` when `entry->fattr->label` is non-NULL because `decode_dirent` overwrites `label->len` in place, and `nfs_readdir_xdr_filler()` returns a non-negative byte length (`pglen`) on success or a negative errno on failure. [F58]
- When cloning or duplicating a `struct nfs_server` across filesystem boundaries (`nfs_clone_server()`, `nfs_server_copy_userdata()`), `server->caps` must not be copied from the source server; it must be reset to protocol defaults via `nfs_server_set_init_caps()` before probing the target filesystem. [F62]

## Error Handling

- Under `nfs_callback_mutex`, `nfs_callback_up` sets up the service (`nfs_callback_create_svc`), per-net transport (`nfs_callback_up_net`), and threads (`nfs_callback_start_svc`) before incrementing `cb_info->users`, and on failure rolls back `nfs_callback_down_net` and destroys `cb_info->serv` if `cb_info->users` is still 0. [F9]
- `bl_unregister_dev()` must test and clear `PNFS_BDEV_REGISTERED` in `dev->flags` before calling `bl_unregister_scsi()`, and `bl_free_device()` must check `dev->bdev_file` for NULL before `fput()`, because `bl_alloc_deviceid_node()` caches `pnfs_block_dev` nodes even when `bl_parse_deviceid()` or `bl_register_dev()` fails. [F39]
- `nfs_alloc_client()` and `nfs_alloc_server()` initialize `clp->cl_rpcclient`, `server->client`, and `server->client_acl` to `ERR_PTR(-EINVAL)` rather than `NULL` (and `nfs_init_server_rpcclient()` stores `ERR_PTR` into `server->client` on failure), so all checks before dereferencing or shutting them down must use `!IS_ERR()`. [F44]
- On any error path after assigning `server->nfs_client = clp`, `nfs_init_server()` must reset `server->nfs_client = NULL` before calling `nfs_put_client(clp)` because its caller `nfs_create_server()` cleans up via `nfs_free_server(server)`, which also calls `nfs_put_client(server->nfs_client)`. [F45]
- `nfs4_callback_sequence()` must always store `clp` into `cps->clp` and free `args->csa_rclists` on every exit path so `nfs4_callback_compound()` puts `cps->clp`, and when `validate_seqid()` returns `htonl(NFS4ERR_RETRY_UNCACHED_REP)` it must save that in `cps->drc_status` and return `0` so `process_op()` fails the next op. [F51]
- `decode_op_hdr()` and `encode_op_hdr()` return the internal status `htonl(NFS4ERR_RESOURCE_HDR)` (`11050`) when the XDR stream lacks space for an operation header, which `nfs4_callback_compound()` must translate to `htonl(NFS4ERR_RESOURCE)` while decrementing `nops` so the unencoded operation is excluded from `hdr_res.nops`. [F52]
- `block_revalidate()` passes `dentry->d_fsdata` to `kfree()` and sets `dentry->d_fsdata = NFS_FSDATA_BLOCKED`, so `nfs_unlink()` and `nfs_rename()` must first verify `!(dentry->d_flags & DCACHE_NFSFS_RENAMED)` (when `d_fsdata` points to `struct nfs_unlinkdata`) and must call `unblock_revalidate()` on every exit path before `nfs_d_release()` can run. [F54]

## External Contracts

- In `nfs4_callback_sequence()`, `slot->seq_nr` must not be updated to `args->csa_sequenceid` until after `nfs4_lookup_slot()`, `validate_seqid()`, `nfs4_try_to_lock_slot()`, the `args->csa_cachethis == 0` check, and `referring_call_exists()` have all succeeded. [F78]
- In encode_getattr_res(), the 4-byte attribute length word reserved at savep must be backfilled with htonl((unsigned int)((char *)xdr->p - (char *)(savep+1))), measuring only the encoded attribute payload bytes after savep. [F89]
- In bl_resolve_deviceid(), b->simple.len (which accumulates 4 + 4 + sum of 8 + 4 + (XDR_QUADLEN(sig_len) << 2) in nfs4_block_decode_volume() plus 4 for the volume count) must be checked not to exceed PAGE_SIZE before allocating sizeof(*bl_msg) + b->simple.len bytes and encoding with nfs4_encode_simple(). [F91]
- In ext_tree_try_encode_commit() and ext_tree_encode_commit(), the NFSv4 LAYOUTCOMMIT loca_last_write_offset (`*lastbyte`) is an inclusive 0-based byte offset computed as `bl->bl_lwb - 1` (or `U64_MAX` when `bl->bl_lwb == 0`), or `((be_prev->be_f_offset + be_prev->be_length) << SECTOR_SHIFT) - 1` on partial encoding. [F97]
- `nfs_encode_fh` must zero the last 32-bit word (`p[len - 1] = 0`) before calling `nfs_copy_fh` to avoid leaking uninitialized padding bytes when `server_fh->size` is not a multiple of 4, and `nfs_fh_to_dentry` must validate `fh_len` against both header and `NFS_MAXFHSIZE` bounds before using `server_fh->size`. [F178]
- `bl_pipe_downcall` must validate `mlen == sizeof(struct bl_dev_msg)` before `copy_from_user` into the per-net `nn->bl_mount_reply`, and `bl_resolve_deviceid` must serialize pipe upcalls and `nn->bl_mount_reply` reads under `nn->bl_mutex` in `server->nfs_client->cl_net`. [F183]

## Known Pitfalls

- Despite its stale comment claiming a `NULL` return, `nfs_delegation_find_inode()` (like `nfs_layout_find_inode()`) never returns `NULL` and instead returns `ERR_PTR(-ENOENT)` or `ERR_PTR(-EAGAIN)` on failure, and on success returns an inode and active superblock reference that must be released via `nfs_iput_and_deactive()`. [F48]
- The individual `RCA4_TYPE_MASK_*` and `PNFS_FF_RCA4_TYPE_MASK_*` constants in `fs/nfs/callback.h` are bit indices (`0`..`17`) that must be wrapped in `BIT()` when testing `args->craa_type_mask` in `nfs4_callback_recallany()`, whereas `RCA4_TYPE_MASK_ALL` (`0x3f31f`) is a pre-shifted bitmask tested directly in `validate_bitmap_values()`. [F49]
- In `nfs_server_set_fsinfo()`, capability bits in `server->caps` that may already be set (such as `NFS_CAP_XATTR`) must be explicitly cleared when the corresponding `struct nfs_fsinfo` field is false (`server->caps &= ~NFS_CAP_XATTR`) rather than only OR-ed when true. [F63]
- In `__ext_tree_remove()`, `be->be_v_offset` and `be->be_length` must be sampled into `orig_v_offset` and `orig_len` before `be->be_length` is shortened to `len1`, because computing the right-hand split extent's `be_v_offset` requires `orig_v_offset + orig_len - len2`. [F71]
- In bl_register_dev(), when registering child devices fails at index i, the rollback loop must guard `while (i > 0)` and decrement `i` (`&dev->children[--i]`) because `i` is an unsigned `u32`. [F93]
- In bl_mark_devices_unavailable(), the unsigned size_t bytes_left counter must be checked with `if (bytes_left > extent_length << SECTOR_SHIFT)` before subtracting `extent_length << SECTOR_SHIFT` (setting `bytes_left = 0` otherwise) so that an extent extending past the I/O range does not underflow bytes_left. [F95]
- In `nfs_fh_to_dentry`, `p[FILEID_HIGH_OFF]` (`u32`) must be cast to `u64` before shifting left by 32 bits when reconstructing `fattr->fileid` (`((u64)p[FILEID_HIGH_OFF] << 32) + p[FILEID_LOW_OFF]`) from the two 32-bit words written by `nfs_encode_fh`. [F123]
