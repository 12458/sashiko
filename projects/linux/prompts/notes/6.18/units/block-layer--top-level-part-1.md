# BLOCK LAYER — (top level) (part 1)

This unit covers TCG Opal SED (`block/sed-opal.c`), T10 PI (`block/t10-pi.c`), loopback (`drivers/block/loop.c`), Micron P320/P420 SSD (`drivers/block/mtip32xx/`), and m68k Amiga/Atari floppy drivers (`drivers/block/amiflop.c`, `drivers/block/ataflop.c`).

## Architecture & Data Flow

- In `loop_init()`, if `max_part > 0`, `part_shift = fls(max_part)` and `max_part = (1UL << part_shift) - 1`; reject `(1UL << part_shift) > DISK_MAX_PARTS` or `max_loop > 1UL << (MINORBITS - part_shift)` with `-EINVAL`. In `loop_validate_file()`, `while (is_loop_device(f))` checks `f->f_mapping->host->i_rdev == bdev->bd_dev` and `l->lo_state != Lo_bound` on cursor `f` before `f = l->lo_backing_file`. In `lo_rw_aio()`, multi-bio (`rq->bio != rq->biotail`) resets `bvec = cmd->bvec` (`offset = 0`), while single-bio uses `__bvec_iter_bvec(bio->bi_io_vec, bio->bi_iter)` (`offset = bio->bi_iter.bi_bvec_done`). [F520, F535, F548]
- In `sed-opal.c`, `cmd_finalize()` appends `CMD_FINALIZE_BYTES_NEEDED` (7) bytes (reserved by `generic_table_write_data()`) and sets `hdr->subpkt.length = cmd->pos - sizeof(*hdr)` before 4-byte padding, setting `hdr->pkt.length` and `hdr->cp.length` after padding. `response_parse()` tests `TINY_ATOM_BYTE`, `SHORT_ATOM_BYTE`, `MEDIUM_ATOM_BYTE`, and `LONG_ATOM_BYTE` in ascending `<=` order. `locking_range_status()` tests `if (rlocked && wlocked)` (`OPAL_LK`) before single-lock branches (`rlocked` alone returns `-EINVAL`); `set_lr_boolean_ace()` calls `add_boolean_object_ref(..., OPAL_BOOLEAN_OR)` only when `u > 0`. [F502, F503, F525, F526, F527]
- In `t10-pi.c`, PI tuples sit at `prot_buf + bi->pi_offset` with stride `bi->metadata_size`; if `bi->pi_offset` is non-zero, update the guard checksum over the leading `bi->pi_offset` bytes at `prot_buf` after hashing data. In `t10_pi_verify()` / `ext_pi_crc64_verify()`, escape checks `pi->app_tag == T10_PI_APP_ESCAPE` alone if `BLK_INTEGRITY_REF_TAG` is set (else both app and ref escape tags) and must `goto next` (not `continue`) to advance iterators. Type 1 prepare/complete (`t10_pi_type1_*`, `ext_pi_type1_*`) skip/set `BIP_MAPPED_INTEGRITY`, init physical `ref_tag` once per `request` and `virt = bip_get_seed(bip)` per `bio` in `__rq_for_each_bio`, and overwrite `pi->ref_tag` only when matching expected `virt` or `ref_tag`. [F498, F508, F522, F523]
- In `mtip32xx`, `mtip_cmd` shares `sg` and `icmd` in a union discriminated by `blk_rq_is_passthrough(rq)` in `mtip_queue_rq()`, and `mtip_work` keeps `work` at offset 0 for `DEFINE_HANDLER()` casts. Tag 0 (`MTIP_TAG_INTERNAL`) is reserved for non-NCQ internal commands, so `mtip_commands_active()`, `mtip_workq_sdbfx()`, `mtip_handle_tfe()`, and `mtip_service_thread()` exclude bit 0 of group 0 and start/wrap NCQ scans at slot 1. `mtip_hw_submit_io()` packs `MTIP_TAG_INDEX(tag)` (`tag >> 5`) and `MTIP_TAG_BIT(tag)` (`tag & 0x1F`) into `fis->sect_count` as `((rq->tag << 3) | (rq->tag >> 5))`. [F484, F513, F514, F552]
- In `mtip32xx`, `dd->slot_groups` is `(hwdata & HSORG_SLOTGROUPS) + 1` only when `HOST_HSORG & 0x8` (`HSORG_STYLE`), clamped to `MTIP_MAX_SLOT_GROUPS` (8); on 64-bit, `mtip_hw_read_registers()` extracts 32-bit group `n` via `cmds_to_issue[n / 2] >> (32 * (n & 1))`. DMA buffers and `mtip_cmd_sg` entries require 8-byte alignment in address and length, with `command_sg->info = (len - 1) & 0x3FFFFF`. Upper 32-bit DMA registers (`PORT_LST_ADDR_HI`, `PORT_FIS_ADDR_HI`) and `hdr->ctbau` are written only if `MTIP_PF_HOST_CAP_64` is set. [F515, F517, F567, F568]
- In `mtip32xx`, `mtip_init_port()` calls `mtip_deinit_port()`, sets `PORT_LST_ADDR`/`PORT_FIS_ADDR`, and clears `PORT_SCR_ERR`, `port->completed[i]`, `PORT_IRQ_STAT`, and `HOST_IRQ_STAT` before writing `DEF_PORT_IRQ` to `PORT_IRQ_MASK`; `hba_setup()` sets `HSORG_DISABLE_SLOTGRP_INTR | HSORG_DISABLE_SLOTGRP_PXIS` in `HOST_HSORG` in both `mtip_hw_init()` and `mtip_hw_resume()`. `mtip_hw_suspend()` calls `mtip_standby_drive()` before clearing `HOST_IRQ_EN` and `mtip_deinit_port()`. When `mtip_check_surprise_removal()` sets `dd->sr = true`, teardown (`mtip_pci_remove()`, `mtip_hw_exit()`, `mtip_standby_drive()`) skips `mtip_quiesce_io()`, `mtip_standby_immediate()`, `mtip_deinit_port()`, and `HOST_CTL` MMIO. [F563, F566, F569, F573]
- In `amiflop.c`, CIA-A/B floppy signals are active-low; before track changes in `get_track()`, `floppy_release()`, or `FDFLUSH`, if `unit[drive].dirty == 1` (or on `FDFLUSH`), delete `flush_track_timer + drive` and call `non_int_flush_track(drive)`. In `ataflop.c`, `fd_select_drive()` loads `UD.track` into `FDCREG_TRACK` and `UDT->fdc_speed` into `dma_wd.fdc_speed`; `check_change()` restores `sound_ym.wd_data = old_porta`; `fd_motor_off_timer` waits until `!(FDC_READ(FDCREG_STATUS) & 0x80)` while `!stdma_islocked()` before `fd_deselect()`; invalidating `TrackBuffer` sets `BufferDrive = -1`; `floppy_revalidate()` restores `UDT = &default_params[drive]` if `blocks != 0`; non-zero `type = MINOR(dev) >> 2` is 1-based and must be decremented before checking `type < NUM_DISK_MINORS` and indexing `minor2disktype[type]`. [F499, F500, F501, F518, F574, F576]

## Synchronization

- `loop_global_lock_killable(lo, global)` takes `loop_validate_mutex` (if `global`) before `lo->lo_mutex`, and `loop_global_unlock(lo, global)` requires the same `global` boolean (`loop_clr_fd()` passes `true`). In `loop_change_fd()`, if `!is_loop`, lock/unlock `loop_validate_mutex` after `loop_global_unlock()` and before `fput(old_file)`. `loop_configure()` orders `loop_assign_backing_file()` before `lo->lo_state = Lo_bound` with `wmb()`, pairing with `rmb()` in `loop_validate_file()`. `__loop_clr_fd()` clears `lo->lo_backing_file = NULL` under `spin_lock_irq(&lo->lo_lock)` before `fput()`, matching `loop_attr_backing_file_show()`. [F430, F431, F448, F451, F452]
- In `loop.c`, `fput(lo_backing_file)`, `loop_reread_partitions()`, and `vfs_getattr()` run outside `lo->lo_mutex` (`loop_get_status()` pins `lo_backing_file->f_path` with `path_get()` under `lo->lo_mutex` while `Lo_bound`). When `!(mode & BLK_OPEN_EXCL)`, `loop_configure()` and `loop_set_block_size()` wrap `lo->lo_mutex` in `bd_prepare_to_claim()` / `bd_abort_claiming()`. On a `Lo_bound` device, `loop_update_dio()` requires `lo->lo_mutex` and `blk_mq_freeze_queue()`, and enabling `LO_FLAGS_DIRECT_IO` requires `vfs_fsync()` first. `loop_add()` sets `lo->idr_visible = true` after `add_disk()`; `loop_control_remove()` clears `lo->idr_visible = false` under `loop_ctl_mutex` and drops it before `lo->lo_mutex`. [F454, F458, F602, F603, F604]
- In `sed-opal.c`, hold `dev->dev_lock` across `setup_opal_dev()`, `execute_step()`, `execute_steps()`, and `dev->unlk_lst` accesses (`add_suspend_info()`, `opal_lock_check_for_saved_key()`, `opal_unlock_from_suspend()`), whereas callers of `clean_opal_dev()` and `check_opal_support()` must not hold `dev->dev_lock`. [F460, F588]
- In `mtip_handle_irq()`, if `PORT_IRQ_SDB_FIS` queues `workers > 0`, do not write `HOST_IRQ_STAT` in the ISR (`do_irq_enable = 0`); the last worker decrementing `dd->irq_workers_active` to 0 in `mtip_workq_sdbfx()` writes `0xffffffff` to `HOST_IRQ_STAT`. `mtip_issue_ncq_command()` takes `port->cmd_issue_lock[group]` via `spin_lock()`, so never take it from hardirq or timer context. [F572, F589]
- In `amiflop.c`, timers (`fd_motor_off()`, `flush_track_callback()`) check `try_fdc()` and re-arm if busy before `get_fdc()` or `fd_select()`. In `ataflop.c`, early errors in `ataflop_queue_rq()` after `stdma_try_lock()` and `fd_request = bd->rq` call `fd_end_request_cur(BLK_STS_IOERR)` and `stdma_release()`; `do_format()` freezes/quiesces the queue and holds `stdma_lock()` around `TrackBuffer`/FDC work, finishing with `finish_fdc()`; if `NeedSeek` is set, `finish_fdc()` issues a dummy `FDCCMD_SEEK` and waits for `finish_fdc_done()` before `stdma_release()`, deferring `fd_timer` >= 5 jiffies; `sound_ym` accesses require `local_irq_save()`, and timers skip FDC/PSG access while `stdma_islocked()`. [F446, F465, F466, F575, F597]

## Object Lifetimes

- `loop_assign_backing_file()` saves `f_mapping`'s GFP mask in `lo->old_gfp_mask`; restore `old_file->f_mapping`'s mask from `lo->old_gfp_mask` before `loop_assign_backing_file()` in `loop_change_fd()` or clearing in `__loop_clr_fd()`. Under `lo->lo_work_lock`, `loop_queue_work()` calls `list_del_init(&worker->idle_list)`, and `loop_process_work()` adds `worker` to `idle_worker_list` only if `!work_pending(&worker->work)`. `lo_free_disk()` calls `destroy_workqueue(lo->workqueue)` before `loop_free_idle_workers(lo, true)` and `timer_shutdown_sync(&lo->timer)`. [F432, F435, F459]
- `lo_rw_aio()` sets `atomic_set(&cmd->ref, 2)` before `read_iter()`/`write_iter()`; `loop_handle_cmd()` saves `cmd->blkcg_css`/`memcg_css` before `do_req_filebacked()` and must not touch `cmd` on `-EIOCBQUEUED`; only when `atomic_dec_and_test(&cmd->ref)` succeeds in `lo_rw_aio_do_completion()` may `cmd->bvec` be freed/nulled, `kiocb_end_write()` called, and `rq` completed. [F436, F457]
- In `sed-opal.c`, `init_opal_dev()` allocates `dev->cmd` and `dev->resp` via separate `kmalloc(IO_BUFFER_LENGTH, GFP_KERNEL)` calls for DMA alignment, and `opal_discovery0_end()` masks `dev->flags &= OPAL_FL_SUPPORTED` before parsing Discovery 0 features. `gen_key()` and `start_SIDASP_opal_session()` `kfree()` and null `dev->prev_data` from `kmemdup()` in `get_active_key_cont()` / `get_msid_cpin_pin()`, whereas `read_table_data()` only nulls the borrowed `dev->resp` pointer from `read_table_data_cont()`. `add_suspend_info()` unlinks/`kfree()`s any existing `dev->unlk_lst` entry with matching `lr` before appending, and `clean_opal_dev()` frees all entries on `free_opal_dev()` or `opal_reverttper()`. [F439, F440, F495, F561]
- In `t10-pi.c`, every `bvec_kmap_local()` in `blk_integrity_verify_iter()`, `blk_integrity_generate()`, and Type 1 helpers must be paired with `kunmap_local()` before advancing or returning on error. [F441]
- In `mtip_exec_internal_command()`, release `rq` (`blk_mq_free_request()`) and `MTIP_PF_IC_ACTIVE_BIT` on both `mtip_quiesce_io()` failure and `exec_ic_exit`. Because `mtip_block_free_disk()` frees `rssd_index_ida` and `dd`, `mtip_pci_remove()` and `mtip_block_shutdown()` must finish `blk_mq_free_tag_set()`, `mtip_hw_exit()`, and `destroy_workqueue(dd->isr_workq)` before `put_disk(dd->disk)`. [F443, F444]

## API Contracts

- In `loop.c`, `lo_offset`/`lo_sizelimit` are bytes (`loff_t`), while `lo_calculate_size()` returns 512B sectors (`loopsize >> 9`) and uses `i_size_read(file->f_mapping->host)` when `S_ISBLK(file_inode(file)->i_mode)`. `loop_get_discard_config()` sets `*max_discard_sectors = bdev_write_zeroes_sectors(bdev)` for block-backed loops. `loop_check_backing_file()` requires `write_iter` only if `file->f_mode & FMODE_WRITE` (missing `FMODE_WRITE`, `BLK_OPEN_WRITE`, or `write_iter` in `loop_configure()` sets `LO_FLAGS_READ_ONLY`). `lo_rw_aio()` sets `IOCB_DIRECT` iff `cmd->use_aio`, calls `f_op->read_iter()`/`write_iter()` directly, and pairs `write_iter()` with `kiocb_start_write()` / `kiocb_end_write()`. `loop_change_fd()` and `loop_configure()` clear `dev_set_uevent_suppress(..., 0)` before `loop_reread_partitions()` and then emit `kobject_uevent(..., KOBJ_CHANGE)`. [F480, F519, F557, F558, F598, F599, F600, F607]
- In `sed-opal.c`, check `response_get_token()` with `IS_ERR()` and `response_get_string()` with `!*store`. `opal_unlock_from_suspend()` returns `true` on failure and `false` on success, and per `unlk_lst` entry resets `dev->tsn = 0` and `dev->hsn = 0`, calls `__opal_lock_unlock()`, and if `OPAL_FL_MBR_ENABLED`, calls `__opal_set_mbr_done()`. `build_locking_user()` writes `buffer[7] = lr + 1` (0-based `lr` in SUM mode, `who - 1` for 1-based `enum opal_user`). `opal_read_table()` rejects `size == 0`, and `read_table_data()` / `generic_table_write_data()` check `(size > table_len || offset > table_len - size)`. In `sed_ioctl()`, `p` is `memdup_user()`'d only for `IOC_IN` and never auto-copied back (`_IOR` uses `arg`; `_IOW` returning data must `copy_to_user()`). [F468, F469, F470, F504, F506, F546, F562]
- In `t10-pi.c`, `t10_pi_csum()` takes `__be16 csum`, while `ext_pi_crc64()` takes CPU `u64 crc` and returns `__be64` (convert intermediate guard tags with `be64_to_cpu()`). `crc64_pi_tuple::ref_tag` uses `get_unaligned_be48()` / `put_unaligned_be48()` and `lower_48_bits(seed)`. `blk_integrity_verify_iter()` uses `saved_iter->bi_sector` and `__bio_for_each_segment(..., *saved_iter)`, not `bio->bi_iter`. [F475, F510, F609]
- In `mtip32xx`, `mtip_hw_get_identify()` and `mtip_block_initialize()` return positive `MTIP_FTL_REBUILD_MAGIC` (`0xED51`), negative errno, or `0` (`mtip_pci_probe()` checks `rv < 0` for error and sets `MTIP_DDF_INIT_DONE_BIT` only if `rv != MTIP_FTL_REBUILD_MAGIC`). Check `mtip_hw_get_capacity()`'s bool return before using `*sectors`. `mtip_exec_internal_command()` takes an 8-byte-aligned `buffer`, `fis_len` in 32-bit DWords, `buf_len` in bytes, and `timeout` in ms. [F482, F483, F486]
- In `amiflop.c`, allocate `raw_buf` via `amiga_chip_alloc()` / `amiga_chip_free()`. In `ataflop.c`, allocate `DMABuffer`/`TrackBuffer` via `atari_stram_alloc()`, bounce `ReqData` through `DMABuffer` if `!ATARIHW_PRESENT(EXTD_DMA)`, and call `dma_cache_maintenance()` around DMA. Both drivers' `floppy_open()` return `-EBUSY` if the drive is already open under a different format minor. [F594, F596, F614]

## Error Handling

- In `loop_configure()` and `loop_change_fd()`, call `fput(file)` if `loop_check_backing_file(file)` fails. [F477]
- In `sed-opal.c`, `execute_steps()` calls `end_opal_session_error(dev)` on failure only when `state > 0`. `parse_and_check_status()`, `finalize_and_send()`, and `opal_step.fn` return negative errno or positive `u8` Opal status, so check `if (err)` (not `err < 0`). Initialize `err = 0` (or via `cmd_start()`) before `add_token_*()` and check `if (err)` before sending. [F438, F467, F471]
- In `mtip_hw_submit_io()`, save `blk_rq_map_sg()` in `command->scatter_ents` and check `dma_map_sg()` in a separate `nents` (`!nents` returns `-ENOMEM`). `mtip_quiesce_io()` inits `active = true` before its polling loop. In `exec_drive_taskfile()` and `mtip_block_initialize()`, reset `inbuf` or `dd->mtip_svc_handler` to `NULL` if `IS_ERR()` before cleanup, and zero `inbuf_dma`/`outbuf_dma` after `dma_unmap_single()`. In `ataflop.c`, `floppy_open()` error paths and `floppy_release()` set `p->ref = 0` when `p->ref < 0` (`BLK_OPEN_EXCL`) instead of `p->ref--`. [F481, F485, F487, F531]

## External Contracts

- In `sed-opal.c`, `opal_locking_range_status()` copies to user from `offsetof(struct opal_lr_status, range_start)`, and `opal_get_status()` / `opal_get_geometry()` zero-init stack structs. In `loop.c`, `loop_get_status()`, `loop_info64_to_old()`, and `loop_info64_to_compat()` `memset()` output structs and return `-EOVERFLOW` on truncation; `loop_set_status_from_info()` rejects `lo_offset > LLONG_MAX` or `lo_sizelimit > LLONG_MAX` (`-EOVERFLOW`) and NUL-terminates `lo_file_name[LO_NAME_SIZE - 1]`. In `exec_drive_taskfile()`, `outtotal` matches the native/compat header size and `out_size`/`in_size` are capped at `130560`. [F473, F479, F511, F516]

## Known Pitfalls

- In `sed-opal.c`, pass `body` (not `body->features`) to `check_geometry()` in `opal_discovery0_end()`; pass `OPAL_UID_LENGTH / 2` for `OPAL_HALF_UID_AUTHORITY_OBJ_REF` and `OPAL_HALF_UID_BOOLEAN_ACE`; check `tok->len > 9` and cast `(u64)pos[i] << (8 * b)` in `response_parse_short()`; use `DIV_ROUND_UP(msb, 8)` in `add_token_u64()`. `loop_attr_backing_file_show()` passes `PAGE_SIZE - 1` to `file_path()` and uses `memmove(buf, p, ret)`. In `mtip32xx.c`, widen `port->identify[100..103]` to `u64` before shifting, use `sector_div()` in `mtip_block_getgeo()`, and index `port->identify` by `u16` words (`+ 10`, `+ 23`, `+ 27`) while passing byte lengths (`20`, `8`, `40`) to `ata_swap_string()` and `byte_len + 1` to `strscpy()`. In `amiflop.c`, write initial gap words at `raw_buf[0]` before `encode_block()` / `dos_encode_block()` (which read `raw[-1]`) and advance `unsigned long *raw` by `len / 2`. [F505, F536, F537, F540, F545, F547, F555, F556]
