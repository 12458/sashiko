# PERFORMANCE EVENTS SUBSYSTEM — (top level) (part 1)

Defines kernel/UAPI perf headers (`include/linux/perf_event.h`, `include/uapi/linux/perf_event.h`), callchain management (`kernel/events/callchain.c`), and CPU PMU drivers/unwinders across Alpha, ARC, C-SKY, Hexagon, LoongArch, MIPS, PA-RISC, PowerPC, RISC-V, s390, SuperH, SPARC, x86, and Xtensa.

## Architecture & Data Flow

- `perf_callchain_entry__sizeof()` reserves `sysctl_perf_event_max_stack + sysctl_perf_event_max_contexts_per_stack` entries in `entry->ip[]`. `perf_callchain_store()` and `perf_callchain_store_context()` both append to `entry->ip[entry->nr++]`, separately bounding `ctx->nr` (`< ctx->max_stack` and `!ctx->contexts_maxed`) and `ctx->contexts` (setting `ctx->contexts_maxed` when full). [F65, F84]
- On slot reuse, `get_perf_callchain()` must reset `ctx.nr`, `entry->nr`, `ctx.contexts`, and `ctx.contexts_maxed`, and set `start_entry_idx = entry->nr` after storing `PERF_CONTEXT_USER` so `fixup_uretprobe_trampoline_entries()` scans only user frames. In `fixup_uretprobe_trampoline_entries()`, `cur_ip` advances every iteration of `while (ri && cur_ip <= last_ip)`, whereas `ri = ri->next` advances only when `*cur_ip == tramp_addr`. [F50, F83]
- `perf_sample_save_callchain()`, `perf_sample_save_raw_data()`, and `perf_sample_save_brstack()` must check that the matching `PERF_SAMPLE_*` bit in `data->sample_flags` is unset, then set it and add the exact serialized byte size to `data->dyn_size`. `perf_sample_save_brstack()` must add `sizeof(u64)` plus an optional `sizeof(u64)` only when `branch_sample_hw_index(event)` is true, never `sizeof(struct perf_branch_stack)`. [F62, F105]
- On s390, `guest_is_user_mode(regs)` and `instruction_pointer_guest(regs)` dereference `sie_block(regs)` (`NULL` if `regs->gprs[15] == 0`) and require `is_in_guest(regs)` first. `perf_misc_flags_sf(regs)` casts `&regs->int_parm_long` to `struct perf_sf_sde_regs *` and requires `regs->int_code == 0x1407`, `regs->int_parm == CPU_MF_INT_SF_PRA`, and `!regs->gprs[15]`. [F42, F110]
- On SPARC and Alpha, when constraint checking moves an event (`cpuc->current_idx[i] != event->hw.idx`), enabling the PMU must flush the old counter via `*_perf_event_update(..., cpuc->current_idx[i])` and reset `current_idx[i]` before reprogramming. `sparc_pmu_del()` and `alpha_pmu_del()` must shift `cpuc->event[]`, `cpuc->events[]`/`evtype[]`, and `cpuc->current_idx[]` in lockstep, and `sparc_pmu_del()` must call `sparc_pmu_stop()` before shifting because `active_event_index()` searches `cpuc->event[]`. [F53, F54]
- On SPARC, `hwc->event_base` packs `(encoding << 16) | pic_mask` (`PIC_UPPER` `0x1` -> `PIC_UPPER_INDEX` `0`; `PIC_LOWER` `0x2` -> `PIC_LOWER_INDEX` `1`). When `sparc_pmu->num_pcrs == 1`, both counters share `cpuc->pcr[0]` and `%pic`: `sparc_default_write_pmc()` must RMW only the target 32-bit half, `sparc_pmu->write_pmc(idx, val)` callers must pass `val & 0xffffffff`, and `sparc_pmu_disable_event()` must replace only `mask_for_index(idx)` with `nop_for_index(idx)` without clearing shared trace bits. [F55, F79, F95]
- `sparc_perf_event_update()` shifts `new_raw_count` and `prev_raw_count` left by 32 before subtracting and arithmetic-right-shifting `s64 delta` by 32. In `perf_event_nmi_handler()`, if `sparc_pmu->irq_bit` is set, `pcr_ops->write_pcr()` must clear PCR overflow bits before `sparc_perf_event_update()`, and a value with bit 31 set (`val & (1ULL << 31)`) means the 32-bit PIC did not wrap and must be skipped. [F88, F96, F125]
- On Alpha: `ev67_mapping[]` (0-based) must match `enum ev67_pmc_event_type` (1-based) order, with `evtype` in `[EV67_CYCLES, EV67_LAST_ET)`. `alpha_perf_event_set_period()` clamps `left` to `[pmc_left[idx], pmc_max_period[idx]]` before `alpha_write_pmc()`, which masks `val` with `pmc_count_mask[idx]`, shifts by `pmc_count_shift[idx]`, and ORs `(1<<idx)` for `wrperfmon(PERFMON_CMD_WRITE, val)`. `alpha_perf_event_update()` masks `prev_raw_count` with `pmc_count_mask[idx]` before subtracting from `new_raw_count`, adding `pmc_max_period[idx] + 1` if `delta < 0`. [F72, F73, F97, F118]
- On MIPS and LoongArch, while counters are paused (`pause_local_counters()`), enabling/disabling an event must update `cpuc->saved_ctrl[idx]` because `resume_local_counters()` restores hardware control registers from `saved_ctrl[]`. `mipspmu_event_set_period()` and `loongarch_pmu_event_set_period()` set `hwc->prev_count` and the counter to `overflow - left` (`overflow = 1ULL << (counter_bits - 1)`), with `max_period <= overflow - 1`. [F58, F93]
- On MIPS, `event_id == 0x00` is valid, so `mipspmu_map_general_event()` and `mipspmu_map_cache_event()` test `cntr_mask == 0` for unsupported entries; valid entries must set `cntr_mask` in bits 8..23 (or 10..23 on `LOONGSON_PMU_TYPE2` via `CNTR_EVEN`/`CNTR_ODD`/`CNTR_ALL`). On `LOONGSON_PMU_TYPE2`, `mipspmu_event_set_period()` and `loongson3_reset_counters()` must select the bank via `mipsxx_pmu_write_control()` before `mipspmu.write_counter()`. [F46, F77, F128]
- On ARC: `arc_pmu_stop()` writes `BIT(idx)` to `ARC_REG_PCT_INT_ACT` before clearing `BIT(idx)` in `ARC_REG_PCT_INT_CTRL`, and selects `idx` in `ARC_REG_PCT_INDEX` to write `0` to `ARC_REG_PCT_CONFIG`. `arc_pmu_read_counter()` selects `idx`, sets `ARC_REG_PCT_CONTROL_SN` in `ARC_REG_PCT_CONTROL`, and reads `ARC_REG_PCT_SNAPH`/`SNAPL` (not `COUNTH`/`COUNTL`). Before `perf_pmu_register()`, `arc_pmu_device_probe()` must request the IRQ and run `arc_cpu_pmu_irq_init()` on each CPU to clear `ARC_REG_PCT_INT_ACT`, or set `PERF_PMU_CAP_NO_INTERRUPT`. [F113, F114, F116]
- On C-SKY, 64-bit counter readers (`csky_pmu_read_cc()`) read 32-bit `hi`/`lo` via `cprgr` in a `do { tmp = hi; lo = ...; hi = ...; } while (hi != tmp)` loop, and `csky_perf_event_update()` calls `sign_extend64()` from bit `csky_pmu.count_width - 1` before subtracting `prev_raw_count`. On SH4A, RMWs of `PPC_PMCAT` (`sh4a_pmu_enable()`) must clear `PMCAT_EMU_CLR_MASK`. On Xtensa, `XTENSA_PMU_PMSTAT(i)` is write-1-to-clear (`set_er(get_er(XTENSA_PMU_PMSTAT(i)))`, not `0`). [F61, F94, F119, F130]

## Synchronization

- `callchain_mutex` serializes `nr_callchain_events` in `get_callchain_buffers()` / `put_callchain_buffers()`; `perf_event_max_stack_handler()` must hold `callchain_mutex` and return `-EBUSY` if `nr_callchain_events != 0`. `alloc_callchain_buffers()` allocates all `entries->cpu_entries[cpu]` before `rcu_assign_pointer(callchain_cpus_entries, entries)`, and `release_callchain_buffers()` clears `callchain_cpus_entries` and frees via `call_rcu(..., release_callchain_buffers_rcu)`. `get_callchain_entry()` / `get_perf_callchain()` callers must stay in RCU read-side or non-preemptible/NMI context while accessing the entry. [F16, F17, F131]
- Mutating `perf_event::sibling_list`, `perf_event_context::event_list`, or `perf_event_pmu_context` lists requires both `ctx->mutex` and `ctx->lock`; reading/iterating (`for_each_sibling_event()`) requires `ctx->mutex`, `ctx->lock`, or IRQs disabled. `perf_cgroup_from_task(task, ctx)` requires the cgroup CSS pinned and `ctx->lock` held if `ctx != NULL`. `__perf_sw_event_sched()` writes `this_cpu_ptr(&__perf_regs[0])` without recursion tracking and requires preemption disabled where software events cannot schedule. [F19, F138, F139]
- `alpha_pmu_add()`, `loongarch_pmu_add()`, `mipspmu_add()`, and `sh_pmu_add()` must pair `perf_pmu_disable(event->pmu)` with `perf_pmu_enable(event->pmu)` on all exit paths, including `-EAGAIN`. PMI/NMI-reenterable counter updates (`mipspmu_event_update()`, `loongarch_pmu_event_update()`, `sparc_perf_event_update()`, `alpha_perf_event_update()`) must update `hwc->prev_count` via `local64_cmpxchg()` before adding to `event->count`. [F13, F20]
- On MIPS and LoongArch, `__hw_perf_event_init()` for `PERF_TYPE_RAW` holds `raw_event_mutex` across `map_raw_event()` and `*_perf_event_encode(pev)` (unlocking on `IS_ERR(pev)`). Under `CONFIG_MIPS_PERF_SHARED_TC_COUNTERS`, `pause_local_counters()` precedes locking `pmuint_rwlock` in `mipspmu_disable()` / `mipsxx_pmu_handle_shared_irq()`, and `resume_local_counters()` follows unlocking `pmuint_rwlock` in `mipspmu_enable()` / `mipsxx_pmu_handle_shared_irq()`. `hw_perf_event_destroy()` and `perf_event_release_pmc()` use `atomic_dec_and_mutex_lock(&active_events, ...)` with `pmu_reserve_mutex` / `pmc_grab_mutex` (paired with `atomic_inc_not_zero(&active_events)`) and must not run with IRQs disabled. [F25, F26, F27]

## Object Lifetimes

- In `get_callchain_buffers()`, `nr_callchain_events` is incremented under `callchain_mutex` before validation or `alloc_callchain_buffers()`, so error paths must decrement it before unlocking. On allocation failure, `alloc_callchain_buffers()` must `kfree()` all allocated `entries->cpu_entries[cpu]` across possible CPUs and `kfree(entries)` without setting `callchain_cpus_entries`. Inherited children (`event->parent != NULL`) share their parent's `addr_filters` and `fasync`; use `perf_event_addr_filters(event)` and `perf_event_fasync(event)`. [F1, F2, F8]
- In `sparc_pmu_event_init()`, all validations must precede `perf_event_grab_pmc()` and `event->destroy = hw_perf_event_destroy`. `perf_event_grab_pmc()` and `perf_event_release_pmc()` serialize `active_events` 0<->1 under `pmc_grab_mutex` to call `perf_stop_nmi_watchdog()` and snapshot `pcr_ops->read_pcr(i)` into `cpuc->pcr[i]` on first use, and `start_nmi_watchdog()` on last release. On SPARC, `perf_callchain_user()` must save and restore `current_thread_info()->fault_address` and `get_thread_fault_code()` around `pagefault_disable()`/`enable()`. [F9, F14, F126]
- On SuperH, `__hw_perf_event_init()` sets `event->destroy = hw_perf_event_destroy` right after incrementing `num_events` and reserving PMC hardware, and `sh_pmu_event_init()` calls `event->destroy(event)` on error. `arc_pmu_del()`, `loongarch_pmu_del()`, and `mipspmu_del()` must stop the event with `PERF_EF_UPDATE`, clear `act_counter[idx]` / `cpuc->events[idx]`, and clear `idx` in `used_mask`. [F11, F12]

## API Contracts

- In `struct pmu`: `add()`, `del()`, `start()`, and `stop()` run with local IRQs and PMU disabled (`start()`/`stop()` may be in NMI); `addr_filters_validate()` runs unserialized in process context. `->del()` passes `PERF_EF_UPDATE`, and `->stop()` checks `PERF_HES_STOPPED` and `PERF_HES_UPTODATE` independently. `->commit_txn()` clears `txn_flags` and re-enables the PMU only on success; on error, `->cancel_txn()` does so after `->del()` rollback. `for_each_sibling_event(sibling, event)` only iterates `event->sibling_list` when `event->group_leader == event` and skips the leader, so group validators must pass `event->group_leader` and handle the leader and candidate event separately. [F7, F21, F51, F85, F150]
- `perf_arch_fetch_caller_regs(regs, __ip)` must set mode/status fields (`psw.mask = 0` on s390, `cs = __KERNEL_CS` on x86, `result = 0` on PowerPC) so `user_mode(regs)` is false. `get_perf_callchain()` must not call `perf_callchain_user()` when `crosstask` is true or when `!user_mode(regs)` and `current->flags & (PF_KTHREAD | PF_USER_WORKER)`. [F31, F133]
- `perf_sample_data_init()` sets only `sample_flags` (`PERF_SAMPLE_PERIOD`, plus `PERF_SAMPLE_ADDR` if `addr != 0`), `period`, and `dyn_size = 0`; other `perf_sample_data` fields are invalid without their `sample_flags` bit. `perf_clear_branch_entry_bitfields(br)` leaves `from`, `to`, `new_type`, and `priv` uninitialized. In a `perf_raw_frag` chain (`perf_sample_save_raw_data()`), non-last fragments need `frag->next >= sizeof(u64)` and the last needs `frag->pad < sizeof(u64)` (`perf_raw_frag_last()`). On x86, `intel_fixed_bits_by_idx(_idx, _bits)` takes `idx - INTEL_PMC_IDX_FIXED` and 64-bit unsigned `_bits` (`u64`/`ULL`), whereas `is_metric_idx(idx)`, `is_topdown_idx(idx)`, and `INTEL_PMC_OTHER_TOPDOWN_BITS(bit)` take `idx >= INTEL_PMC_IDX_FIXED`. [F33, F39, F40, F66, F99]

## Error Handling

- `struct pmu::event_init` must return `-ENOENT` when `event` does not target that PMU (e.g., unhandled `attr.type`), `0` on success, or a negative errno (`-EINVAL`, `-EOPNOTSUPP`, `-ENODEV`, `-EBUSY`, `-EACCES`) when invalid/unsupported. In `get_callchain_entry(int *rctx)`, if `rcu_dereference(callchain_cpus_entries)` is `NULL` after `get_recursion_context()` succeeds, it must call `put_recursion_context()`; callers getting a non-`NULL` entry must call `put_callchain_entry(rctx)`. In `csky_pmu_device_probe()`, failure in `cpuhp_setup_state()` or `perf_pmu_register()` must call `csky_pmu_free_irq()` and `free_percpu(csky_pmu.hw_events)`. [F28, F35, F120]

## External Contracts

- In `struct perf_event_mmap_page`: reading `data_head`/`aux_head` requires `smp_rmb()` before reading data, and updating `data_tail`/`aux_tail` (`PROT_WRITE`) requires `smp_mb()` between reading data and storing the tail; `index` (`pmu::event_idx`) is 1-based (`0` = inactive, `hwc->idx + 1` = active). In `include/uapi/linux/perf_event.h`, 64-bit bitfield unions (`perf_mem_data_src`, `perf_sample_weight`) must keep little/big-endian definitions in sync with reversed field order, and `PERF_MEM_S(a, s)` must cast to `__u64` before shifting. `perf_allow_cpu()` and `perf_allow_tracepoint()` must enforce both `sysctl_perf_event_paranoid` / `perfmon_capable()` (`-EACCES` for CPU > 0, `-EPERM` for tracepoint > -1) and `security_perf_event_open()`. [F23, F48, F69, F101, F154]

## Known Pitfalls

- `get_callchain_entry()` must cast `entries->cpu_entries[cpu]` to `void *` before adding `*rctx * perf_callchain_entry__sizeof()` due to the runtime-sized `ip[]` array. On x86, `ARCH_PERFMON_NUM_COUNTER_LEAF` (`0x1`) and `ARCH_PERFMON_ACR_LEAF` (`0x2`) are `ARCH_PERFMON_EXT_LEAF` (`0x23`) sub-leaf indices; check `cpuid35_eax` bitfields `cntr_subleaf` / `acr_subleaf`, not `eax & LEAF`. [F32, F103]
- On LoongArch, `perf_callchain_user()` and `user_backtrace()` must check `fp != 0`, `!((unsigned long)fp & 0xf)`, `access_ok(fp - sizeof(struct stack_frame), ...)`, and `(unsigned long)user_frame_tail < buftail.fp`. Every `general_event_map` and `cache_event_map` must start with `PERF_MAP_ALL_UNSUPPORTED` / `PERF_CACHE_MAP_ALL_UNSUPPORTED` (`0xffffffff`) since `0x00` is `PERF_COUNT_HW_CPU_CYCLES`. [F70, F71]
- On 64-bit SPARC, `perf_callchain_kernel()`, `perf_callchain_user_64()`, and the 64-bit branch of `perf_callchain_user_32()` must add `STACK_BIAS` (2047) to `UREG_FP` and `sf.fp`. In `sparc_check_constraints()`, when event 0 is unconstrained and event 1 is constrained, set `idx0 = 1` when `(msk1 & PIC_UPPER)` so event 1 gets `idx0 ^ 1` (`PIC_UPPER`, 0). On Alpha, `ev67_check_constraints()` checks the accompanying event at `evtype[idx0 ^ 1]` for `EV67_INSTRUCTIONS`, but at `evtype[idx0]` for `EV67_MBOXREPLAY` / `EV67_BCACHEMISS`. [F80, F89, F90]
- On MIPS, `CNTR_BIT_MASK(n)` must guard `(n) == 64` (`~0ULL`), and `mipsxx_pmu_read_counter()` must cast 32-bit `read_c0_perfcntr*()` to `(u32)` before returning `u64` while 64-bit accessors mask with `CNTR_BIT_MASK(counter_bits)`. In C-SKY, LoongArch, and MIPS PMU IRQ handlers, `irq_work_run()` requires local IRQs disabled and a regular IRQ (not NMI). [F92, F127, F143]
- On ARC, `arc_pmu_raw_alloc()` must use `__GFP_ZERO` and size `attrs` to `n_events + 1`, and `arc_pmu_device_probe()` must apply `le32_to_cpu()` to `ARC_REG_CC_NAME0`/`1` and NUL-terminate `cc_name.str[ARCPMU_EVENT_NAME_LEN - 1]`. On SuperH and Xtensa, `event->hw.idx` must stay non-negative across init and del for `__test_and_set_bit(idx, used_mask)` in `*_pmu_add()`, and Xtensa `xtensa_pmu_event_init()` / `xtensa_pmu_cache_event()` must bounds-check against `ARRAY_SIZE(xtensa_hw_ctl)` / `ARRAY_SIZE(xtensa_cache_ctl)` and reject `0` entries. [F74, F76, F107, F109]
