# LINUX FOR POWERPC (32-BIT AND 64-BIT) — arch/powerpc/kernel (part 1)

Implements core PowerPC subsystems: interrupt/syscall entry and exit, 64-bit lazy IRQ soft-masking, IOMMU TCE tables and DMA mapping, fadump, MCE handling, 32/64-bit ELF module relocation, NVRAM/pstore, hardware breakpoints, kprobes, and CPU feature discovery.

## Architecture & Data Flow

- In `interrupt_exit_user_prepare_main()`, test `(regs->msr & mathflags) != mathflags` (not `!(regs->msr & mathflags)`); when `syscall_exit_restart()` or `interrupt_exit_user_restart()` restarts exit, restore `AMR_KUAP_BLOCKED` and call `trace_hardirqs_off()`, `user_exit_irqoff()`, and `account_cpu_user_entry()`. In `irq_64.c`, `srr1_to_lazyirq[0]` must be `0`; in `irq_set_pending_from_srr1()`, dispatch `IRQ_SYSTEM_RESET` immediately via `replay_system_reset()` with `get_paca()->in_nmi = 1`, and call `ppc_msgclr(PPC_DBELL_MSGTYPE)` for `PACA_IRQ_DBELL` before setting `irq_happened`. [F210, F238, F245, F314]
- In `mce.c`, `save_mce_event()` increments `mce_nest_count` even when `index >= MAX_MC_EVT`, so `get_mce_event()` (`release == true`) must decrement `mce_nest_count` whenever `index >= 0`. `machine_check_ue_event()`/`machine_check_queue_event()` must decrement `mce_ue_count`/`mce_queue_count` when `index >= MAX_MC_EVT`, and `machine_process_ue_event()`/`machine_check_process_queued_event()` must decrement them on every iteration including `ignore_event`. In `mce_handle_derror()`, continue looping over `table[]` after the first match to flush all SLB/ERAT/TLB structures while populating `mce_err` and `*addr` only on the first match (uncorrectable errors must precede recoverable ones). [F153, F154, F258]
- In `iommu.c`, `tbl->it_map` and `struct iommu_pool` (`start`, `end`, `hint`) use 0-based indices relative to `tbl->it_offset`, whereas hardware TCE callbacks (`tbl->it_ops->set`, `clear`, `get`) take absolute TCE indices (`bitmap_index + tbl->it_offset`). [F221]
- In `fadump_add_mem_range()`, do not fold ranges when `start < fw_dump.boot_mem_top`; if `is_static` is true, return `-ENOSPC` at `max_mem_ranges` instead of calling `fadump_alloc_mem_ranges()`, and reload any local `mem_ranges` pointer after `fadump_alloc_mem_ranges()`. `fadump_free_mem_ranges()` must only reset `mem_range_cnt = 0` when `is_static` is true, else `kfree(mem_ranges)` and zero fields after `name` (`RNG_NAME_SZ`). `fadump_append_bootargs()` must call `memblock_reserve(fw_dump.param_area, COMMAND_LINE_SIZE)` when `param_area < boot_mem_top`. [F202, F203, F233, F242]
- In `module_64.c`/`module_32.c`, sort every `SHT_RELA` section with `sort(..., relacmp, NULL)` before `count_relocs()`/`count_pcpu_relocs()`. In `module_64.c`, `get_got_size()` starts at `relocs = 1` (zero sentinel for `got_for_addr()`) and counts all relocation types calling `got_for_addr()`; `struct ppc64_stub_entry` and `.stubs`/`.mygot`/`.toc` need `>= 8`-byte alignment with `offsetof(struct ppc64_stub_entry, funcdata) == 32`. `stub_for_addr()` and `setup_ftrace_ool_stubs()` must bound/advance `me->arch.stub_count` against `sh_size / sizeof(struct ppc64_stub_entry)`, sizing `ool_stubs` via `roundup(ool_stub_count * sizeof(struct ftrace_ool_stub), sizeof(struct ppc64_stub_entry)) / sizeof(struct ppc64_stub_entry)`. [F227, F228, F229, F251, F274]
- In `nvram_64.c`, `nvram_scan_partitions()` must rewind `cur_index` by `NVRAM_HEADER_LEN` after `nvram_read()`, reject `phead.length == 0`, and stop on bad checksum. OS partitions (`os_partition`) subtract `sizeof(struct err_log_info)` from `part->size`. `nvram_create_partition()` rounds sizes via `ALIGN(size, NVRAM_BLOCK_LEN) / NVRAM_BLOCK_LEN + 1` and saves candidates in `free_part` (not loop cursor `part`). Header updates in `nvram_remove_partition()`/`nvram_create_partition()` must update `nvram_checksum()` and call `nvram_write_header()`; `nvram_remove_partition()` uses `list_for_each_entry_safe()` and resets `prev = NULL` on non-free partitions. In `oops_to_nvram()`, `KMSG_DUMP_PANIC` sets `panicking = true` and `KMSG_DUMP_EMERG` aborts if `panicking`. [F216, F246, F249, F250, F256, F267, F281]
- In `hw_breakpoint_validate_len()` and `set_dawr()`, `hw->hw_len` is byte length `[start_addr, end_addr)` (pre-ISA v3.1 DAWR requires `ALIGN_DOWN(start_addr, SZ_512) == ALIGN_DOWN(end_addr - 1, SZ_512)`), while DAWRX `MRD` is `((brk->hw_len + 7) >> 3) - 1`. In `thread_change_pc()`, if any `bp_per_reg` slot has `perf_single_step`, clear `MSR_SE`, call `__set_breakpoint(i, info)`, and clear `perf_single_step`. [F212, F235]
- In `dt_cpu_ftrs.c`, check `-1` and `HV_SUPPORT_NONE`/`OS_SUPPORT_NONE` before shifting `1UL << bit_nr`; `feat_enable_dscr()` sets `f->fscr_bit_nr = -1` before `feat_enable(f)`; modify `LPCR`/`HFSCR`/`FSCR`/`PCR` before `cpufeatures_setup_finished()`. In `cpufeatures_cpu_quirks()`, `0xffffefff` POWER9 DD2.0–2.3 checks must precede `(version & 0xffff0000) == 0x004e0000`; in `update_tlbie_feature_flag()`, `((pvr & 0xe000) == 0)` precedes `((pvr & 0xc000) == 0)`. In `cputable.c`/`early_32.c`, early pre-relocation code must use `PTRRELOC()` and `memcpy()` into `the_cpu_spec` (preserving `old.num_pmcs`, `old.pmc_type`, `CPU_FTR_PMAO_BUG` when `!s->num_pmcs`). In `legacy_serial.c`, `legacy_serial_ports[]` (`MAX_LEGACY_SERIAL_PORTS + 1`) and `legacy_serial_infos[]` are parallel arrays indexed `< MAX_LEGACY_SERIAL_PORTS`. [F196, F215, F218, F239, F240, F241, F299, F301, F332]

## Synchronization

- In `prep_irq_for_enabled_exit()`, evaluate `exit_must_hard_disable()` once into a local bool reused across `__hard_EE_RI_disable()` and `lazy_irq_pending_nocheck()` recovery; call `trace_hardirqs_on()` before `__hard_EE_RI_disable()`, and on recovery when `must_hard_disable` is set, set `PACA_IRQ_HARD_DIS` and call `__hard_RI_enable()` before `trace_hardirqs_off()`. [F163, F308]
- In `interrupt_exit_kernel_prepare()`, call `kuap_get_and_assert_locked()` before `prep_irq_for_enabled_exit()` and pass it to `kuap_kernel_restore()`; clear `PACA_IRQ_HARD_DIS` only when `!arch_irq_disabled_regs(regs)` and `prep_irq_for_enabled_exit()` succeeds, and replay IRQs via `hard_irq_disable()` + `replay_soft_interrupts()` (not `local_irq_enable()`). In `check_return_regs_valid()`, read `srr_valid`/`hsrr_valid` with `READ_ONCE()` before reading SRR/HSRR and re-check with `READ_ONCE()` after a mismatch. [F164, F309, F310]
- In `arch_local_irq_restore()`, testing `irq_happened == 0` and storing `0` to `irq_soft_mask` must use `asm goto` with `RESTART_TABLE`; bracket `replay_soft_interrupts_irqrestore()` with `irq_enter()`/`irq_exit()` and jump to `again` if `irq_happened != PACA_IRQ_HARD_DIS`. `__replay_soft_interrupts()` must keep `PACA_IRQ_REPLAYING` set in `local_paca->irq_happened` and use `local_paca`. [F166, F169, F312]
- `iommu_range_alloc()` must use `spin_lock_irqsave(&pool->lock, flags)` and swap `pool->lock` with IRQs kept disabled when switching pools. After `tbl->it_ops->set()`, `iommu_alloc()`, `ppc_iommu_map_sg()`, and `iommu_flush_tce()` must call `tbl->it_ops->flush(tbl)` (if non-NULL) then `mb()`. In `__iommu_free()`, `tbl->it_ops->clear()` must precede `bitmap_clear()` under `pool->lock`. [F170, F171, F298]
- `fadump_process()` must finish `ops->fadump_process()` before setting `elfcorehdr_addr`; `release_mem_store()` and `fadump_free_elfcorehdr_buf()` must call `vmcore_cleanup()` and set `elfcorehdr_addr = ELFCORE_ADDR_ERR` before freeing memory. Hold `fadump_mutex` across checking `dump_active`/`dump_registered` and calling `fadump_cleanup()`, `register_fadump()`, `fadump_unregister()`, or `fadump_region_show()`. [F175, F176]
- `machine_check_early()` runs in NMI real-mode: defer `printk` to `mce_run_irq_context_handlers()` (`mce_irq_work_queue()`) and `mce_notifier_list`/`memory_failure()` to `machine_process_ue_event()`. In `mce_power.c`, skip host flushes, PTE walks, and UE recovery when `mce_in_guest()`, guard `addr_to_pfn()` / `mce_find_instr_ea_and_phys()` with `get_paca()->in_mce < MAX_MCE_DEPTH`, and disable IRQs around `__find_linux_pte()`. [F317, F318]
- `hw_breakpoint_handler()` must hold `rcu_read_lock()`, call `hw_breakpoint_disable()` on entry, use `perf_event_disable_inatomic()` on errors, and set `bp[i] = NULL` before `goto reset` when disabled, one-shot handled, or stepped (`stepping_handler()`). `wp_get_instr_detail()` wraps `__get_user_instr()` in `pagefault_disable()`/`enable()`. `oops_to_nvram()` and `nvram_pstore_write()` must use preallocated buffers without `kmalloc()` or blocking locks (`spin_trylock_irqsave()` in `oops_to_nvram()`) and abort if `clobbering_unread_rtas_event()`. [F198, F319, F320, F329]

## Object Lifetimes

- `iommu_alloc_coherent()` calls `free_pages()` if `iommu_alloc()` fails; `iommu_free_coherent()` calls `iommu_free()` before `free_pages()`. `iommu_init_table()` allocates `it_map`, reserves page 0 (if `it_offset == 0`) and `[res_start, res_end)`, inits pool locks, and runs `iommu_table_clear()` before `iommu_debugfs_add()`. `iommu_tce_table_get()` uses `kref_get_unless_zero()`, and `iommu_table_free()` calls `iommu_debugfs_del(tbl)` before freeing `it_map`/`tbl`. `ppc_iommu_register_device()` calls `iommu_device_sysfs_add()` before `iommu_device_register()` (reversed in `unregister`); `spapr_tce_*_iommu_attach_dev()` pairs `iommu_group_get(dev)` with `iommu_group_put(grp)`. [F146, F174, F284, F287, F288]
- `arch_prepare_kprobe()` checks `!kprobe_ftrace(prev)` before reading `prev->ainsn.insn` and calls `get_insn_slot()` only after all checks pass; `arch_remove_kprobe()` calls `free_insn_slot(p->ainsn.insn, 0)` and NULLs `p->ainsn.insn`. In `kprobe_handler()`, after `preempt_disable()` and `set_current_kprobe()` (`save_previous_kprobe(kcb)` on re-entry), every non-`prepare_singlestep()` exit must restore/reset `current_kprobe` (`restore_previous_kprobe(kcb)` on `KPROBE_REENTER`) and `preempt_enable()`. `arch_uninstall_hw_breakpoint()` NULLs `bp_per_reg[i]` and zeros the register; `flush_ptrace_hw_breakpoint()` NULLs `t->ptrace_bps[i]`. [F149, F150, F152, F179, F213]
- In `nvram_pstore_read()`, `kfree(buff)` on `nvram_read_partition()` failure and after `kmemdup()` for `PSTORE_TYPE_DMESG`, but transfer `record->buf = buff` for non-DMESG. In `nvram_init_oops_partition()`, return if `nvram_pstore_init() == 0`; on `stream.workspace` failure, free and NULL `big_oops_buf`; on `kmsg_dump_register()` failure, free `oops_buf`, `big_oops_buf`, and `stream.workspace`. `isa_bridge_find_late()`/`isa_bridge_remove()` pair `of_node_get()`/`put()` on `isa_bridge_devnode` and `vunmap_range(ISA_IO_BASE, ISA_IO_BASE + 0x10000)`. `ioremap_legacy_serial_console()` calls `early_iounmap(info->early_addr, 0x1000)` and NULLs `early_addr`. [F157, F158, F162, F291, F346]

## API Contracts

- `prep_irq_for_idle()` and `prep_irq_for_idle_irqsoff()` call `__hard_irq_disable()` and set `PACA_IRQ_HARD_DIS` before `lazy_irq_pending()`, returning `false` if pending; pair `prep_irq_for_idle_irqsoff() == true` with `fini_irq_for_idle_irqsoff()`. `arch_cpu_idle()` calls `raw_local_irq_disable()` if `!irqs_disabled()` after `ppc_md.power_save()`. `__setup()` callbacks return `1`, while `early_param()` callbacks return `0`. Export `mmu_feature_keys` with `EXPORT_SYMBOL`. [F160, F180, F305, F307, F333]
- In `iommu.c`, right-shift byte DMA masks and `res_start`/`res_end` by `tbl->it_page_shift` before `iommu_range_alloc()`, `iommu_alloc()`, `iommu_init_table()`, or `iommu_table_reserve_pages()`; use `IOMMU_PAGE_SIZE(tbl)`, `IOMMU_PAGE_ALIGN()`, and `IOMMU_PAGE_MASK(tbl)` (not CPU `PAGE_SIZE`/`MASK`); NULL-check optional `it_ops` (`flush`, `get`, `free`, `tce_kill`). Check `dev_is_pci(dev)` before `to_pci_dev(dev)`, and call `get_iommu_table_base()` in `dma_iommu_dma_supported()` only after `dma_iommu_bypass_supported()` is false. `iommu_add_device()` checks `device_is_registered()` (`-ENOENT`) and `!device_iommu_mapped()` (`-EBUSY`). Keep separate `iommu_domain_ops` for `spapr_tce_blocked_domain` (`take_ownership`) and `spapr_tce_platform_domain` (`release_ownership`). `iommu_tce_xchg_no_kill()` calls `SetPageDirty()` on replaced `DMA_FROM_DEVICE`/`BIDIRECTIONAL` pages when `!mm_iommu_is_devmem()`. [F182, F183, F199, F204, F205, F262, F325, F336, F337]
- `nvram_create_partition()` returns negative errno or data offset (`index + NVRAM_HEADER_LEN`), while `nvram_find_partition()` returns `0` on miss; treat `p <= 0` as failure (`part->index = -1`). Pass a temporary `loff_t` copy (not `&part->index`) to `ppc_md.nvram_read()`/`write()` (`rc <= 0` is error). `addr_to_pfn()` returns `ULONG_MAX` on failure (`phys_addr == ULONG_MAX` in MCE). `hmi_handle_debugtrig()` returns `-1` (unhandled), `0`, or `1` (check `ret >= 0` in a signed var). `stub_for_addr()`, `got_for_addr()`, and `do_plt_call()` return `0` on error (translate to `-ENOENT`/`-EFAULT`), and `get_stubs_size()` must not return negative errno when `__patchable_function_entries` is absent. [F185, F186, F188, F190, F191, F248]
- In `fadump.c`, NULL-check `fadump_get_metadata_size`, `fadump_setup_metadata`, and `fadump_cleanup`. `fadump_setup_param_area()` uses `early_radix_enabled()` and bounds Hash MMU to `[MIN_RMA * 1M, min(ppc64_rma_size, boot_mem_top)]`. `fadump_cma_init()` runs after `initmem_init()`, passes `boot_memory_size`, and calls `cma_reserve_pages_on_error()`. `setup_fadump()` uses `subsys_initcall_sync()`. `pci_iounmap()` skips `isa_vaddr_is_ioport()`/`pcibios_vaddr_is_ioport()`; `remap_isa_base()` uses `vmap_page_range()` or `early_ioremap_range()` (not `ioremap_page_range()`). In `ima_arch.c`, when `is_ppc_secureboot_enabled()`, call `set_module_sig_enforced()` if `CONFIG_MODULE_SIG` is enabled and include `MODULE_CHECK` rule only when disabled. [F195, F289, F330, F331, F340, F342, F345]

## Error Handling

- In `fadump_alloc_mem_ranges()`, call `fadump_free_mem_ranges()` if `krealloc()` fails. In `ppc_iommu_map_sg()`, init `outs->dma_length = 0`, zero failed segments' `dma_length`, and zero trailing `outs->dma_length` when `outcount < incount`; gate TCE failure `dev_info` logs with `!(attrs & DMA_ATTR_NO_WARN) && printk_ratelimit()`. In `process_ISA_OF_ranges()`, reject unaligned addresses (`-EINVAL`), clamp size to `0x10000`, and on `inval_range` map 64K at `phb_io_base_phys` if non-zero or return `-EINVAL`. [F156, F184, F244, F290, F338]

## External Contracts

- `nvram_header::name` is 12 bytes (not NUL-terminated at 12 chars); bound accesses to 12 bytes. In `nvram_pstore_read()`, if `be16_to_cpu(oops_hdr->version) < OOPS_HDR_VERSION`, header size is `sizeof(u16)`. In `fadump.c`, CPU notes `PT_NOTE` must be the first `elf_phdr`; check `is_fadump_header_compatible()` before `fadump_process()`; keep `/sys/kernel/` compat symlinks and `"1\n"` in `hotplug_ready_show()`. `set_dexcr_prctl()` requires `capable(CAP_SYS_ADMIN)` (`-EPERM`) for `PR_PPC_DEXCR_CTRL_CLEAR_ONEXEC` on `DEXCR_PR_NPHIE`. [F225, F226, F231, F232, F234, F344]

## Known Pitfalls

- Use distinct `notifier_block` structs in `fail_iommu_setup()`, `unsigned long` loop counter in `iommu_table_reserve_pages()`, and guard `tbl->it_page_shift < PAGE_SHIFT` for `align_order`. In `module_64.c`, `R_PPC64_TOC16_HA`/`REL16_HA` use `(value + 0x8000) >> 16` and `dedotify_versions()` uses `memmove()`. In `module_32.c`, `patch_location_16()` uses `PTR_ALIGN_DOWN(loc, sizeof(u32))` and `module_trampoline_target()` subtracts `0x10000` when `addr & 0x8000`. Mask `*ea &= 0xffffffffUL` when `!(regs->msr & MSR_64BIT)` in `wp_get_instr_detail()`; use `time_after()` in `fadump_free_reserved_memory()`; read `clock-frequency`/`reg` from `np` and PCI BAR/compat from `pci_dev` in `add_legacy_pci_port()`; constrain `[sp]` with `"b"` and `PPC_STLU` in `call_do_irq()`/`call_do_softirq()`. [F206, F230, F259, F261, F264, F268, F269, F270, F271, F275, F316]
