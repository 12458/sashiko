# GENERIC PHY FRAMEWORK — drivers/phy (part 2)

Implements generic PHY and clock provider drivers for Cadence (D-PHY RX/TX, Salvo USB, Sierra/Torrent SERDES) and Freescale/NXP i.MX8/i.MX95 (MIPI D-PHY, PCIe, USB, HSIO SERDES, LVDS, Samsung HDMI) transceivers.

## Architecture & Data Flow
- In `cdns-dphy.c` and `cdns-dphy-rx.c`, `bands` and `tx_bands` must stay sorted by ascending rate at hardware band indices; `cdns_dphy_rx_configure()` must check `lanes <= DPHY_LANES_MAX` (4) before `cdns_dphy_rx_wait_lane_ready()` indexes `data_lane_ctrl[4]`, and write `DPHY_LANE_RESET_CMN_EN` only when `!soc_data->has_hw_cmn_rstb` (`cdns_dphy_socinfo`). In `cdns_dphy_ops`, only `get_wakeup_time_ns` is mandatory; null-check all other hooks. In `cdns_dphy_get_pll_cfg()`, widen `dlane_bps` and `pll_ref_hz` to `u64` and use `DIV_ROUND_UP_ULL`/`div_u64`. [F30, F71, F86, F100]
- In `phy-cadence-sierra.c`, when `sp->nsubnodes > 1`, `cdns_sierra_phy_configure_multilink()` configures common CDB and deasserts `sp->phy_rst` at probe, so `cdns_sierra_phy_init()` returns early and `cdns_sierra_phy_on()` only deasserts `sp->phy_rst` when `sp->nsubnodes == 1`. If `sp->already_configured` is non-zero (`sp->pma_cmn_ready`), `PHY_CLK`, `phy_rst`, and `apb_rst` are not acquired, child PHYs use `noop_ops`, and `cdns_sierra_phy_disable_clocks()` skips `sp->input_clks[PHY_CLK]`. [F45, F47]
- In `phy-cadence-sierra.c`, index `regmap_phy_pma_lane_cdb` and `regmap_lane_cdb` by `i + ins->mlane` (`0 <= i < ins->num_lanes`) and link status (`phy_iso_link_ctrl_1`, `pllctrl_lock`) by `ins->mlane`. `cdns_sierra_phy` embeds flexible `clk_data` (`hws[]`) last, allocated with `CDNS_SIERRA_OUTPUT_CLOCKS`, bounding `clk_data.hws` indices. [F46, F95]
- In `cdns_torrent_phy_configure_multilink()` and `cdns_sierra_phy_configure_multilink()`, pass 2 (`protocol == 1` / `node == 1`) swaps `phy_t1`/`phy_t2` (and `ref_clk`/`ref_clk1` in Torrent) before table lookups; in Torrent, temporarily setting two PCIe subnodes to `TYPE_PCIE_ML` must be restored to `TYPE_PCIE` before returning. Every `cdns_torrent_vals` in `link_cmn_vals_tbl` must have `num_regs >= 1` with `PHY_PLL_CFG` at `reg_pairs[0]` (written to `cdns_phy->phy_pll_cfg`) and `reg_pairs[1..num_regs-1]` written to `regmap_common_cdb`. [F48, F62, F74]
- In `cdns_torrent_phy`, `base`, `regmap_dptx_phy_reg`, and `phy_reset_ctrl` are initialized only for `TYPE_DP`. `cdns_torrent_dp_get_pll()` must set `cdns_phy->dp_pll` (`DP_PLL0`/`DP_PLL1`) before `cdns_torrent_dp_common_init()`, `cdns_torrent_dp_pma_cmn_vco_cfg_100mhz()`, `cdns_torrent_dp_pma_cmn_rate()`, or `cdns_torrent_dp_configure_rate()`, and 100 MHz DP rate helpers must only touch PLLs in `cdns_phy->dp_pll`. [F31, F42, F51]
- In `phy-cadence-torrent.c`, `inst->mlane + inst->num_lanes` (and `+ dp->lanes`) must not exceed `MAX_NUM_LANES` (4) (`PHY_POWER_STATE_LN(ln)` shifts by `8 * ln`; `cdns_torrent_dp_set_lanes()` shifts `u8 pma_tx_elec_idle_mask` by `clane + 4`). In `cdns_torrent_dp_set_lanes()`, the first `PHY_RESET` loop before `cdns_torrent_dp_set_a0_pll()` must start at `i = 1` to keep master lane `clane + 0` in reset until the second `i = 0` loop. [F77, F92]
- In `cdns_torrent_dp_set_rate()`, call `cdns_torrent_dp_configure_rate()` only after placing lanes in `POWERSTATE_A3` and calling `cdns_torrent_dp_set_pll_en(false)`; `cdns_torrent_dp_configure_rate()` must disable `cdns_phy->dp_pll` in `phy_pma_pll_raw_ctrl` before VCO changes. In `cdns_torrent_dp_set_voltages()`, set `TX_DIAG_ACYA_HBDC_MASK` on `inst->mlane + lane` before writing `TX_TXCC_CTRL`, `DRV_DIAG_TX_DRV`, `TX_TXCC_MGNFS_MULT_000`, and `TX_TXCC_CPOST_MULT_00`, and clear it after. [F52, F53]
- In `mixel_dphy_priv` (`phy-fsl-imx8-mipi-dphy.c`), `lvds_regmap` and `ipc_handle` exist only when `devdata->is_combo` (`MIXEL_IMX8QXP`), while `reg_tx_rcal`, `reg_auto_pd_en`, `reg_rxlprp`, `reg_rxcdrp`, and `reg_rxhs_settle` exist only when `!is_combo` (`MIXEL_IMX8MQ`). `mixel_dphy_configure_lvds_phy()` sets `priv->is_slave = opts->lvds.is_slave` with `IMX_SC_C_DUAL_MODE`, and `mixel_dphy_power_on_lvds_phy()` skips `DPHY_LOCK` polling if `priv->is_slave`. [F29, F54]
- In `phy-fsl-imx8-mipi-dphy.c`, `mixel_dphy_configure_mipi_dphy()` computes into a local `mixel_dphy_cfg` via `mixel_dphy_config_from_opts()` before copying to `priv->cfg`, and `mixel_dphy_validate()` uses a stack-local `mixel_dphy_cfg` without mutating `priv->cfg`. In `get_best_ratio()`, when `n[i] > max_n || d[i] > max_d` in `while (b)`, toggle `i ^= 1` before `break`. [F55, F81]
- In `imx8_pcie_phy_power_on()` (`phy-fsl-imx8m-pcie.c`), write `AUX_PLL_REFCLK_SEL_SYS_PLL` to `IMX8MM_PCIE_PHY_CMN_REG063` only when `variant != IMX8MM`, and keep the `pad_mode` checks for `IMX8_PCIE_REFCLK_PAD_INPUT || IMX8_PCIE_REFCLK_PAD_UNUSED` and `IMX8_PCIE_REFCLK_PAD_OUTPUT || IMX8_PCIE_REFCLK_PAD_UNUSED` as separate `if`s so `PAD_UNUSED` runs both. [F83, F111]
- In `phy-fsl-imx8mq-usb.c`, `imx8m_get_phy_tuning_data()` branches on `device_is_compatible(dev, "fsl,imx95-usb-phy")`, `phy_tx_vboost_level_from_property()` maps `1156`/`844`/default uV to `5`/`3`/`4`, and `imx8m_phy_tune()` relies on `PHY_TUNE_DEFAULT == 0xffffffff` for its bitwise-AND untuned check. In `phy-fsl-imx8qm-hsio.c`, PCIe clock tables (`lan0_pcie_clks`, `lan1_pciea_clks`, `lan1_pcieb_clks`, `lan2_pcieb_clks`) require `LANE_NUM_CLKS` (5) entries with `apb_pclk` at index 0. In `phy-fsl-imx8qm-lvds-phy.c`, `PHY_NUM` is 2 (`id` 0 or 1) for `priv->phys[lvds_phy->id ^ 1]`. [F68, F70, F82, F114]
- In `phy-fsl-samsung-hdmi.c`, `phy->cur_cfg` is NULL until `fsl_samsung_hdmi_phy_configure()`, so `phy_clk_recalc_rate()` and `fsl_samsung_hdmi_phy_resume()` must null-check it. `fsl_samsung_hdmi_phy_configure()` uses 8-bit `writeb()`/`readb_poll_timeout()` at 4-byte `PHY_REG(reg)` offsets, sets `phy->cur_cfg = cfg`, mirrors `cfg->pll_div_regs[2] >> 4` (`REG03_PMS_S_MASK`, `s - 1`) into `REG21_PMS_S_MASK` of `PHY_REG(21)`, and writes `REG33_FIX_DA | REG33_MODE_SET_DONE` to `PHY_REG(33)` after all divider/lock-detector writes and before polling `PHY_REG(34)` (`REG34_PLL_LOCK`). [F33, F59, F66, F118]
- In `phy-fsl-samsung-hdmi.c`, `fsl_samsung_hdmi_calculate_phy()` only writes `pixclk` and `pll_div_regs[0..2]` on `calculated_phy_pll_cfg`, keeping `pll_div_regs[3..6]` at `{ 0x00, 0x00, 0x80, 0x00 }`. In `fsl_samsung_hdmi_phy_find_pms()`, cast `fout` and `_m` to `u64` before multiplying by `(_p * _s)` and `24 * MHZ`, use `do_div()`/`div64_ul()`, and check `tmp <= 255`. In `fsl_samsung_hdmi_phy_configure_pll_lock_det()`, divide `int_pllclk` below `50 * MHZ` (`div < 4`) and use `DIV_ROUND_UP(24 * MHZ * 256, int_pllclk)` for `fld_tg_code`. [F89, F90, F142]

## Synchronization
- In `phy-cadence-sierra.c` and `phy-cadence-torrent.c`, CDB `regmap_config` structs used by `clk_ops` (`cdns_sierra_common_cdb_config`, `cdns_torrent_common_cdb_config`, `cdns_torrent_phy_pcs_cmn_cdb_config`) must set `.fast_io = true`. All subnode PHYs, `nsubnodes`, and multilink configs must finish before `devm_of_phy_provider_register()`. In `cdns_torrent_clk_register()`, allocate `clk_hw_data` and register `derived_refclk` and `received_refclk` before `cdns_torrent_refclk_driver_register()`, and all three before `of_clk_add_hw_provider()`. [F18, F19, F21]
- In `phy-fsl-imx8mq-usb.c`, `imx95_usb_phy_get_tca()` must init `tca->base`, `tca->mutex`, and `tca->orientation` before `tca_blk_get_typec_switch()` (which maps `ERR_PTR` from `typec_switch_register()` to NULL on `tca->sw`, unregistered in `imx8mq_usb_phy_remove()` via `imx95_usb_phy_put_tca()`). `tca_blk_typec_switch_set()` enables `imx_phy->clk` around `tca_blk_orientation_set()`, which holds `tca->mutex` while writing `TCA_GCFG`, `TCA_TCPC`, and `TCA_SYSMODE_CFG` (`TCA_SYSMODE_TCPC_DISABLE` before `TCA_SYSMODE_TCPC_FLIP`) and caching `tca->orientation`; `tca_blk_init()` calls it unlocked after `TCA_CLK_RST_SW`. [F9, F16, F17, F58, F113]
- In `phy-fsl-imx8qm-lvds-phy.c`, `mixel_lvds_phy_probe()` must init `priv->lock` and `dev_set_drvdata(dev, priv)` before `pm_runtime_enable()` and `mixel_lvds_phy_reset()`, and populate `priv->phys[i]` before `devm_of_phy_provider_register()`. `mixel_lvds_phy_reset()` must not hold `priv->lock` across `pm_runtime_resume_and_get()`/`pm_runtime_put()`. `mixel_lvds_phy_validate()` caches `opts->lvds` in `lvds_phy->cfg` under `priv->lock`; `mixel_lvds_phy_power_on/off()` return 0 if `lvds_phy->cfg.is_slave`, while the master under `priv->lock` toggles `phy_ref_clk` and `CH_EN(0) | CH_EN(1)` when `companion->cfg.is_slave`. [F13, F14, F57, F117]

## Object Lifetimes
- In `cdns_dphy_probe()`, if `devm_phy_create()` fails after `dphy->ops->probe(dphy)`, call `dphy->ops->remove(dphy)` if non-NULL. In `cdns_dphy_power_on()`, prepare/enable `dphy->psm_clk` and `dphy->pll_ref_clk` before hardware config and disable/unprepare both in reverse order on error before setting `dphy->is_powered = true`. [F1, F2]
- In `cdns_sierra_phy_probe()`, non-devm `sp->phys[node].lnk_rst` (`of_reset_control_array_get_exclusive()`) must be freed via `reset_control_put()` for both the failing `node` and `0 .. node-1` on probe error, and in `cdns_sierra_phy_remove()`. In `cdns_torrent_phy_suspend_noirq()`, if `cdns_phy->already_configured` is non-zero, clear it to 0 without calling `clk_disable_unprepare()` on `clk1`/`clk` to keep `cdns_torrent_phy_resume_noirq()` balanced. [F3, F6]
- Clock providers from non-devm `of_clk_add_hw_provider()` in `cdns_sierra_clk_register()`, `cdns_torrent_clk_register()`, and `phy_clk_register()` (`phy-fsl-samsung-hdmi.c`) require `of_clk_del_provider()` in `.remove` and on probe errors. In `fsl_samsung_hdmi_phy_resume()`, re-enable `phy->apbclk` before calling `fsl_samsung_hdmi_phy_configure(phy, phy->cur_cfg)` when `phy->cur_cfg` is non-NULL. [F8, F119]
- In `phy-fsl-imx8qm-hsio.c`, `imx_hsio_power_on()` and `imx_hsio_power_off()` must update `priv->open_cnt` under `priv->lock`, configuring shared `priv->misc` (`HSIO_CTRL0`) registers only when `priv->open_cnt` transitions `0 -> 1` and asserting shared misc/ctrl/phy resets only when `priv->open_cnt` decrements to `0`. [F10]

## API Contracts
- In `phy-cadence-sierra.c`, `phy-cadence-torrent.c`, and `phy-fsl-imx8qm-lvds-phy.c`, `phy_set_drvdata()` stores the per-link instance (`cdns_sierra_inst`, `cdns_torrent_inst`, `mixel_lvds_phy`) on `struct phy`, while `dev_set_drvdata()` stores the controller state on `phy->dev.parent`. In Sierra and Torrent, CDB regmaps (`cdns_regmap_write`/`read`) shift offsets by `reg_offset_shift` (16-bit), whereas Torrent's DPTX regmap (`cdns_regmap_dptx_write`/`read`) uses unshifted byte offsets (32-bit). [F35, F96]
- In `cdns-dphy.c`, `get_wakeup_time_ns()` returns ns while `opts->wakeup` is us (`/ 1000` in `cdns_dphy_config_from_opts()`). In `cdns_dphy_rx_get_band_ctrl()`, compute `hs_clk_rate / 1000000UL * 2` before matching `bands[]` (Mbps). `cdns_dphy_validate()` must not mutate `dphy->cfg`; `cdns_dphy_configure()` only updates `dphy->cfg` and `dphy->is_configured = true`, while `cdns_dphy_power_on()` requires `dphy->is_configured && !dphy->is_powered` and programs/polls hardware after enabling clocks and `DPHY_CMN_SSM_EN`. [F41, F43, F98, F128]
- Before `cdns_torrent_dp_set_voltages()`, `cdns_torrent_dp_verify_config()` must check `voltage[i] <= 3`, `pre[i] <= 3`, and `voltage[i] + pre[i] <= 3` (`i < dp->lanes`) so `vltg_coeff` avoids out-of-bounds or `0xFFFF`. Because `cdns_torrent_derived_refclk_enable()` sets `cmn_cdiag_refclk_ovrd_4` and `phy_pipe_cmn_ctrl1_0` while `cdns_torrent_received_refclk_enable()` sets only `phy_pipe_cmn_ctrl1_0`, `cdns_torrent_received_refclk_is_enabled()` must return `val && !cmn_val`. [F63, F140]
- In `phy-fsl-imx8-mipi-dphy.c`, `phy_set_mode()` must precede `mixel_dphy_configure()` and `mixel_dphy_power_on/off()`, and `16 <= cm <= 255`, `1 <= cn <= 32`, `co` in `{1, 2, 4, 8}` must be checked before `CM()`, `CN()`, `CO()`. In `phy-fsl-imx8m-pcie.c`, `imx8_pcie_phy_init/exit()` own `imx8_phy->clk`, while `imx8_pcie_phy_power_on()` deasserts `perst` and `reset` before setting `IMX8MM_GPR_PCIE_CMN_RST` and polling `IMX8MM_PCIE_PHY_CMN_REG075`, and `power_off()` re-asserts both. [F67, F112, F126, F132]
- In `phy-fsl-imx8qm-hsio.c`, `imx_hsio_xlate()` checks `0 <= idx < priv->drvdata->lane_num` (`<= MAX_NUM_LANE` (3)); `phy_init()` (`imx_hsio_init`) must precede `imx_hsio_set_mode()`, `imx_hsio_set_speed()`, and `imx_hsio_power_on()`; `imx_hsio_set_speed()` treats `speed` as a boolean (`speed ? HSIO_LTSSM_ENABLE : 0` in `HSIO_CTRL2`). In `phy-fsl-samsung-hdmi.c`, `fsl_samsung_hdmi_phy_lookup_rate()` requires `rate >= phy_pll_cfg[0].pixclk` (`22250000`) and `phy_pll_cfg` sorted ascending. [F64, F69, F134, F135]

## Error Handling
- Store `cdns_dphy_rx_get_band_ctrl()` / `cdns_dphy_tx_get_band_ctrl()` returns in a signed `int` and check `< 0` (`0` is valid; error is `-EOPNOTSUPP`). In `fsl_samsung_hdmi_phy_configure_pll_lock_det()`, check `div == 4` (`-EINVAL`) after `for (div = 0; div < 4; div++)` before `FIELD_PREP(REG12_CK_DIV_MASK, div)`. [F22, F65]
- In `cdns_sierra_phy_probe()` and `cdns_torrent_phy_probe()`, validation failures jumping to cleanup labels after `ret = 0` must set a negative `ret`. In `cdns_torrent_phy_probe()`, child-loop errors before `of_reset_control_array_get_exclusive()` jump to `put_lnk_rst`, and after it to `put_child`. [F26, F27]
- In `cdns_torrent_refclk_driver_register()`, after `IS_ERR_OR_NULL(hw)`, return `IS_ERR(hw) ? PTR_ERR(hw) : -ENOENT`. Null-check pointers from `cdns_sierra_data` tables and `cdns_torrent_get_tbl_vals()`. In `phy-fsl-imx8mq-usb.c`, `imx95_usb_phy_get_tca()` returns NULL when `IORESOURCE_MEM` 1 is absent and `ERR_PTR` on failure; check `IS_ERR(imx_phy->tca)` in probe and null-check `imx_phy->tca` at runtime/remove. [F23, F24, F32]

## Known Pitfalls
- In `cdns_dphy_power_on()`, preserve `DPHY_CMN_SSM_CAL_WAIT_TIME` when writing `DPHY_CMN_SSM`. In `phy-cadence-sierra.c`, `cdns_sierra_pll_mux_get_parent()`/`set_parent()` must test `strstr(clk_hw_get_name(hw), clk_names[CDNS_SIERRA_PLL_CMNLC1])` before `CDNS_SIERRA_PLL_CMNLC` (`"pll_cmnlc"` is a prefix of `"pll_cmnlc1"`). In `phy-cadence-torrent.c`, `CDNS_TORRENT_KEY` uses 3-bit masks (`0..7`), and `enum cdns_torrent_phy_type` reaches `7` (`TYPE_PCIE_ML`). [F85, F97, F99]
- In `mixel_dphy_config_from_opts()`, check `hs_prepare < lp_t` (and `clk_prepare < lp_t`) before `2 * (dphy_opts->hs_prepare - lp_t)` to prevent 32-bit unsigned underflow. In `imx_hsio_pcie_power_on()`, after `imx_hsio_pcie_phy_resets()`, disable `lane->clks[0].clk`, `mdelay(1)`, and re-enable it before polling `HSIO_PCIE_STS0` (`HSIO_PM_REQ_CORE_RST`). In `fsl_samsung_hdmi_phy_find_pms()`, run `if (_s > 1 && (_s & 0x01) == 1) _s++;` before `if (_s == 14) continue;`, and cast both `rate` and `pixclk`/`int_div_clk` to `long` inside `abs()`. [F79, F88, F91, F116]
