# BONDING DRIVER — (top level)

This unit provides the core header definitions, UAPI structures, and sysfs management interfaces (`bonding_masters`, per-bond `bonding` attribute group, and per-slave attributes) for the Linux Ethernet Channel Bonding driver, defining primary data structures for bonding masters, enslaved interfaces, options, IEEE 802.3ad (LACP) state machines, and Adaptive Load Balancing (ALB/TLB) hash tables.

## Architecture & Data Flow
- `bond_set_slave_state` and `bond_commit_link_state` must clear `should_notify` and `should_notify_link` when `notify` is `true` and toggle them when `notify` is `false`; `bond_slave_state_notify` and `bond_slave_link_notify` must clear them after calling `bond_lower_state_changed`. Broken by: unconditionally setting them to `1` when `notify` is `false` or not resetting to `0` after `bond_lower_state_changed`. [F210]
- `bond_slave_state(slave)` returns the 1-bit `slave->backup` (`BOND_STATE_ACTIVE` = `0`, `BOND_STATE_BACKUP` = `1`), which `slave_do_arp_validate` shifts as `1 << bond_slave_state(slave)` to test bits 0–1 of `bond->params.arp_validate` while `slave_do_arp_validate_only` tests `BOND_ARP_FILTER` (`1 << 2`). Broken by: adding a slave state `>= 2` or testing `arp_validate` as a plain boolean. [F270]
- Every `bond->params` field formatted via `bond_opt_get_val()` in `bond_sysfs.c` (`mode`, `xmit_policy`, `arp_validate`, `fail_over_mac`, `lacp_active`, `lacp_fast`, `ad_select`, `primary_reselect`) must hold a value present in its option's `bond_opt_value` table, because `bonding_show_*` dereferences `val->string` unchecked. [F240]
- `slave_show()` in `slave_sysfs_ops` unconditionally downcasts `attr` via `to_slave_attr(attr)` and calls `slave_attr->show(slave, buf)`, so every attribute registered on `slave->kobj` (including all entries in `slave_attrs[]`) must be embedded in a `struct slave_attribute` with a non-NULL `.show` callback. [F282]
- The sysfs attribute pointer arrays `per_bond_attrs` (used by `bonding_group`) and `slave_attrs` (passed to `sysfs_create_files` and `sysfs_remove_files`) must be terminated with a `NULL` entry. [F253]
- `BOND_MAX_NS_TARGETS` must not exceed `BOND_MAX_ARP_TARGETS` because IPv6 NS target slots (`0 .. BOND_MAX_NS_TARGETS - 1`) index directly into `slave->target_last_arp_rx[BOND_MAX_ARP_TARGETS]`. [F257]
- `TLB_HASH_TABLE_SIZE` and `RLB_HASH_TABLE_SIZE` must each be at least 256 because `alb_bond_info.tx_hashtbl` and `alb_bond_info.rx_hashtbl` are indexed directly by the unmasked `u8` return value of `_simple_hash()`. [F260]
- `BOND_TLB_REBALANCE_INTERVAL` in `include/net/bond_alb.h` must remain strictly non-zero because TLB load calculations divide `entry->tx_bytes` and `bond_info->unbalanced_load` by `BOND_TLB_REBALANCE_INTERVAL`. [F273]
- In `include/net/bond_3ad.h`, `bond_3ad_churn_desc()` indexes `churn_description[]` directly by `churn_state_t` and clamps out-of-range values to `ARRAY_SIZE(churn_description) - 1` (`"unknown"`), so `churn_state_t` enumerators must stay 0-based and ordered identically to `churn_description[]` with `"unknown"` last. [F249]

## Synchronization
- In `bonding_store_bonds`, the `+` command path must invoke `bond_create` without holding `rtnl_lock`, whereas the `-` command path must hold `rtnl_lock` across both `bond_get_by_name` and `unregister_netdevice`; per-netns `bn->dev_list` traversal without `rtnl_lock` (e.g., `bonding_show_bonds`) must hold `rcu_read_lock()` and use `list_for_each_entry_rcu`. [F204, F213]
- `bond_for_each_slave`, `bond_first_slave`, `bond_last_slave`, and `bond_slave_has_mac` traverse `bond->dev->adj_list.lower` without RCU primitives and require `rtnl_lock`; concurrent readers without RTNL must use `bond_for_each_slave_rcu`, `bond_first_slave_rcu`, or `bond_slave_has_mac_rcu`, and callers of those helpers, `bond_slave_get_rcu`, or `bond_option_active_slave_get_rcu` must hold `rcu_read_lock()` (or RTNL for `bond_option_active_slave_get_rcu`) for the entire use of the returned borrowed pointers. [F211, F212]
- `bond_slave_get_rcu` dereferences `dev->rx_handler_data` with `rcu_dereference` and must be called inside `rcu_read_lock()` (as in `bond_is_active_slave_dev`), whereas `bond_slave_get_rtnl` uses `rtnl_dereference` and requires `rtnl_lock()`. [F216]
- `bond_option_active_slave_get_rcu(bond)` dereferences `bond->curr_active_slave` via `rcu_dereference_rtnl` without taking a device reference and returns `NULL` when `!bond_uses_primary(bond)` (modes other than active-backup, TLB, and ALB) or when `curr_active_slave` is `NULL`; callers like `bonding_show_active_slave` must hold `rcu_read_lock()` or `rtnl_lock()` across the call and all dereferences (or `dev_hold` before unlocking) and check for `NULL`. [F215, F232]
- `bond_set_active_slave`, `bond_set_backup_slave`, and `bond_set_slave_state` or `bond_commit_link_state` with `BOND_SLAVE_NOTIFY_NOW` require `rtnl_lock()` for `bond_lower_state_changed`; callers without RTNL (e.g., holding only `rcu_read_lock()` or `bond->mode_lock`) must pass `BOND_SLAVE_NOTIFY_LATER` and later call `bond_slave_state_notify` or `bond_slave_link_notify` under RTNL. [F217]
- `__bond_3ad_get_active_agg_info` traverses the slave list with `bond_for_each_slave_rcu` without acquiring `rcu_read_lock()`; callers not already in an RCU read-side critical section (such as `bonding_show_ad_aggregator` and other `bonding_show_ad_*` sysfs handlers) must call `bond_3ad_get_active_agg_info` instead. [F219]
- Because `slave->queue_id` and `slave->last_tx` are read locklessly under RCU in sysfs, packet TX/RX, and link monitors while updated on other CPUs, concurrent accesses to `slave->queue_id` must use `READ_ONCE`/`WRITE_ONCE` and accesses to `slave->last_tx` must use `slave_last_tx` and `slave_update_last_tx`. [F220]
- `bond->slave_cnt` must never be modified outside the slave attach and detach paths under `rtnl_lock`, and lockless readers (such as round-robin packet/XDP TX paths where it is a modulo divisor) must read it with `READ_ONCE(bond->slave_cnt)`. [F221]

## Object Lifetimes
- `bond_sysfs_slave_add` and `bond_sysfs_slave_del` must pass the identical `slave_attrs` array and `&slave->kobj` to `sysfs_create_files` and `sysfs_remove_files`, and during slave release or enslave rollback `bond_sysfs_slave_del` must synchronously remove `slave_attrs` before `bond_3ad_unbind_slave` clears 802.3ad state and before `kobject_put(&slave->kobj)` frees `SLAVE_AD_INFO(slave)` and `slave`. [F207, F223]
- `bond_create_sysfs` must copy `class_attr_bonding_masters` into `bn->class_attr_bonding_masters` and initialize it with `sysfs_attr_init` before calling `netdev_class_create_file_ns`, and `bond_destroy_sysfs` must pass `&bn->class_attr_bonding_masters` and `bn->net` to `netdev_class_remove_file_ns`. [F206]
- Per-bond sysfs attributes are registered by assigning `&bonding_group` to `bond->dev->sysfs_groups[0]` in `bond_prepare_sysfs_group` prior to netdevice registration; do not manually call `sysfs_create_group` or `sysfs_remove_group` for `bonding_group`. [F289]
- `bonding_sysfs_store_option` retains ownership of the `buffer_clone` heap string allocated with `kstrndup` and must free it with `kfree` after `bond_opt_tryset_rtnl` returns on both success and error paths. [F205]
- `bond_tx_drop` increments `dev`'s core `tx_dropped` counter, frees `skb` via `dev_kfree_skb_any(skb)`, and returns `NET_XMIT_DROP`; callers must not free `skb` or increment `tx_dropped` again. [F311]

## API Contracts
- `__bond_opt_init` and `bond_opt_initval` reserve `optval->value == ULLONG_MAX` as the sentinel to parse `optval->string` instead of a numeric value, and `__bond_opt_init` only copies `extra` into `optval->extra` when `extra_len <= BOND_OPT_EXTRA_MAXLEN` (16 bytes); callers must pass either a valid `string` (with `value == ULLONG_MAX`) or a numeric `value` (never both), and must not let signed 32-bit values (e.g., `-1` or `0xffffffff`) sign-extend to `ULLONG_MAX` for non-`BOND_OPTFLAG_RAWVAL` options. [F230, F277]
- `bond_get_targets_ip` and `bond_get_targets_ip6` stop scanning at the first zero/unspecified address (unless searching for `0` or `in6addr_any` to find a free slot) and return `-1` when not found; `targets` must remain packed without interior zero holes, and the return value must be stored in a signed `int` and checked for `-1` before indexing. [F233]
- Every `DEVICE_ATTR` in `drivers/net/bonding/bond_sysfs.c` that uses `bonding_sysfs_store_option` as `.store` must have an `attr.name` identical to the `.name` of an entry in `bond_opts[]`, because `bonding_sysfs_store_option()` resolves the option via `bond_opt_get_by_name(attr->attr.name)`. [F239]
- `bond_first_slave` and `bond_last_slave` guard `netdev_adjacent_get_private` with `bond_has_slaves(bond)` and return `NULL` when the slave list is empty; callers of `bond_first_slave`, `bond_last_slave`, and `bond_first_slave_rcu` must handle a `NULL` return. [F272]
- `bond_netpoll_send_skb` in `include/net/bonding.h` calls `BUG()` when `CONFIG_NET_POLL_CONTROLLER` is disabled, so callers must only invoke it when netpoll is active on the slave. [F292]

## Error Handling
- `bond_create_sysfs` must treat `-EEXIST` from `netdev_class_create_file_ns` as success (`ret = 0`) so secondary loads of the bonding module do not fail when `/sys/class/net/bonding_masters` already exists. [F227]
- `bond_3ad_get_active_agg_info` leaves its out-parameter `struct ad_info *ad_info` unpopulated when it returns non-zero (`< 0`), so callers must only read `ad_info` fields when it returns `0` (and when `BOND_MODE(bond) == BOND_MODE_8023AD`). [F229]

## External Contracts
- `bonding_sysfs_store_option` must duplicate at most `count` bytes of `buffer` via `kstrndup(buffer, count, GFP_KERNEL)` before calling `bond_opt_tryset_rtnl`, and both `bonding_store_bonds` and `bonding_sysfs_store_option` must translate a `0` success status into `count` and return either `count` or a negative errno (never `0`, which causes userspace writes to retry forever); in `bonding_store_bonds`, the input must be extracted via `sscanf(buffer, "%16s", command)` into `char command[IFNAMSIZ + 1]` and start with `'+'` or `'-'` followed by a name passing `dev_valid_name()`. [F250, F251, F305]
- Wire-format structures `struct mac_addr`, `struct lacpdu`, `struct lacpdu_header`, `struct bond_marker`, and `struct bond_marker_header` in `include/net/bond_3ad.h` must remain byte-packed (`__packed` / `#pragma pack(1)`). [F304]

## Known Pitfalls
- In `struct bond_marker`, `requester_port` (`u16`) and `requester_transaction_id` (`u32`) are typed as host integers rather than `__be16`/`__be32` despite holding big-endian wire values on receive, so any code interpreting or writing their numeric values must byte-swap them. [F264]
- In `struct bond_params`, `ad_actor_system` is declared as `u8 ad_actor_system[ETH_ALEN + 2]` (8 bytes) to provide 2 bytes of padding for `ether_addr_equal_64bits()`; code copying or exporting the MAC address in `ad_actor_system` must use `ETH_ALEN` (6) rather than `sizeof(bond->params.ad_actor_system)`. [F281]
