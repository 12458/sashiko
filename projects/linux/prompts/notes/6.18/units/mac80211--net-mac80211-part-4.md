# MAC80211 — net/mac80211 (part 4)

Implements the IEEE 802.11 client Station MLME state machine (`mlme.c`), OCB mode (`ocb.c`), off-channel/ROC operations (`offchannel.c`), IE parsing and defragmentation (`parse.c`), PM suspend/resume (`pm.c`), and rate control (`rate.c`/`rate.h`).

## Architecture & Data Flow
- In `struct ieee80211_elems_parse`, `elems` is at offset 0 and `scratch[]` is `3 * params->len`. `ieee802_11_parse_elems_full()` must call `ieee80211_clear_tpe()` on `elems->tpe` and `csa_tpe`, run `ieee80211_prep_mle_link_parse()` before the outer `_ieee802_11_parse_elems_full()` pass when `!params->bss` (passing per-STA `WLAN_EID_EXT_NON_INHERITANCE` to the outer pass), and set `skip_vendor` during the outer pass if `sub` has `WLAN_EID_VENDOR_SPECIFIC`, clearing it before the inner pass. [F222, F223, F240, F252]
- In `struct ieee80211_mle_per_sta_profile`, `sta_info_len` counts its 1-byte length field while `prof->variable` starts after it, so `ieee80211_prep_mle_link_parse()` and `ieee80211_assoc_config_link()` must check `elems->sta_prof_len >= sizeof(*prof) + prof->sta_info_len - 1 + 4` before skipping the 4-byte assoc-response fixed fields (`capab_info`, `status`) to `sub->start` at `prof->variable + prof->sta_info_len - 1`. [F251]
- In `_ieee802_11_parse_elems_full()`, reset `elem_parse_failed = 0` per element, set `__set_bit(id, seen_elems)` only when `!elem_parse_failed`, and on duplicate single-instance elements (`test_bit(id, seen_elems)`) record `IEEE80211_PARSE_ERR_DUP_ELEM` and `continue`. Testing `params->filter` or `care_about_ies` must guard `id < 64` and use `1ULL << id`. In `ieee80211_rearrange_tpe_psd()`, stage full-channel ordering into `tmp` before overwriting `psd->power`. [F245, F264, F279]
- In `ieee80211_mgd_assoc()` and `ieee80211_mgd_assoc_ml_reconf()`, call `ieee80211_mgd_get_ap_ht_vht_capa()` per link before `ieee80211_add_link_elems()`, and check `sband->vht_cap.vht_supported` alongside `conn.mode >= IEEE80211_CONN_MODE_VHT` and `band != NL80211_BAND_6GHZ` before adding/requiring VHT IEs. Size any IE emitted by `ieee80211_add_link_elems()`, `ieee80211_send_assoc()`, or `ieee80211_build_ml_reconf_req()` in `ieee80211_link_common_elems_size()` or `alloc_skb()`. [F224, F238, F295]
- In `ieee80211_add_link_elems()`, `present_elems` (`PRESENT_ELEMS_MAX` = 8) reserves its last slot for `0`, records standard IDs (`ADD_PRESENT_ELEM`) before extension IDs (`ADD_PRESENT_EXT_ELEM`), and must record any IE emitted after `ieee80211_assoc_add_ml_elem()` (e.g. `WLAN_EID_EXT_EHT_CAPABILITY`) before calling `ieee80211_assoc_add_ml_elem()`. [F237, F257]
- Assign new `auth_data` to `ifmgd->auth_data` before `ieee80211_set_disassoc()` in `ieee80211_mgd_auth()`; reset `assoc_data->comeback = false` in `ieee80211_do_assoc()`; init `wmm_last_param_set` and `mu_edca_last_param_set` to `-1` before `ieee80211_sta_wmm_params()` in `ieee80211_assoc_config_link()`; and mask wire AID with `0x1fff` (`s1g`) or `0x7ff` before `aid == 0 || aid > max_aid` in `ieee80211_rx_mgmt_assoc_resp()`. [F225, F233, F234, F259]
- In `ieee80211_determine_chan_mode()`, refresh `parse_params.mode = conn->mode` after `again:`, `kfree(elems)` before `goto again;`, and only decrease `conn->mode`. In `ieee80211_process_ml_reconf_resp()`, check `len >= count * 3` before duples and (if `added_links`) `len >= 1 && len >= 1 + *pos` before Group Key Data; init `link_mask = sta_changed_links`, require each duple to match and clear `BIT(link_id)` in `link_mask`, and `goto disconnect;` if `link_mask` remains non-zero. [F258, F271, F277]
- In `ieee80211_set_disassoc()`, clear `IEEE80211_CONF_PS` before sending deauth/disassoc, require an active link (`ieee80211_vif_link_active`) with `!link->u.mgd.csa.blocked_tx` when `tx == true`, and zero `deflink.u.mgd.bssid` and `vif.cfg.ap_addr` after `ieee80211_send_deauth_disassoc()`. Wait for `IEEE80211_STA_NULLFUNC_ACKED` before setting `IEEE80211_CONF_PS` when `PS_NULLFUNC_STACK` and `REPORTS_TX_ACK_STATUS` are set (`ieee80211_enable_ps()`, `ieee80211_dynamic_ps_enable_work()`), and postpone dynamic PS if `drv_tx_frames_pending(local)` or `queue_stop_reasons[q]` is non-zero. [F231, F304, F305, F307]
- Skip arming `bcn_mon_timer`, `conn_mon_timer`, and `monitor_work` when `CONNECTION_MONITOR` is set; return early in `ieee80211_mgd_probe_ap()` if `IEEE80211_STA_CONNECTION_POLL` was already set; require `CHANCTX_STA_CSA` in `ieee80211_sta_process_chanswitch()`; and in `run_again()` only `mod_timer()` on pending `mgd.timer` if `time_before(timeout, sdata->u.mgd.timer.expires)`. [F275, F284, F303, F309]
- In `ieee80211_offchannel_stop_vifs()`, stop queues (`IEEE80211_QUEUE_STOP_REASON_OFFCHANNEL`) and `ieee80211_flush_queues(local, NULL, false)` before setting `SDATA_STATE_OFFCHANNEL`, saving `enable_beacon` in `SDATA_STATE_OFFCHANNEL_BEACON_STOPPED`, and calling `ieee80211_offchannel_ps_enable()`. Keep started `ieee80211_roc_work` entries as a contiguous head prefix on `local->roc_list` (`list_for_each_entry_safe()`). In `ieee80211_mgmt_tx()`, set `IEEE80211_TX_CTRL_DONT_USE_RATE_MASK` and, if `dont_wait_for_ack`, `*cookie = 0xffffffff`. [F243, F247, F267, F300, F333]
- `idx = -1` (`< 0`) terminates `ieee80211_tx_rate` arrays (`rate_fixup_ratelist()` sets all slots after `idx < 0` or legacy `idx >= sband->n_bitrates` to `-1`), and positive `mcast_rate[sband->band]` maps to `idx = mcast_rate - 1` in `rate_control_send_low()`. In `rate_idx_match_mcs_mask()` / `rate_idx_match_vht_mcs_mask()`, HT splits `*rate_idx` into `(/ 8, % 8)` (`< IEEE80211_HT_MCS_MASK_LEN`) and VHT into `(>> 4, & 0xf)` (`< NL80211_VHT_NSS_MAX`), starting inner `j` at `rbit` on `i == ridx` and resetting `rbit` to `7`/`15` or `0` after each outer iteration. [F260, F261, F262, F269]

## Synchronization
- In `ieee80211_set_disassoc()`, cancel and clear `conn_mon_timer`, `bcn_mon_timer`, `ifmgd->timer`, `tx_tspec_wk`, `ttlm_work`, `neg_ttlm_timeout_work`, `ml_reconf_work`, and `teardown_ttlm_work` (`ieee80211_ml_reconf_reset()`) before `ieee80211_vif_set_links(sdata, 0, 0)`, and run `synchronize_net()` and `ieee80211_flush_queues(local, sdata, true)` after `netif_carrier_off()` before sending deauth/disassoc or removing STA state. [F207, F208]
- Cancel `local->dynamic_ps_enable_work` (`wiphy_work_cancel()`) whenever deleting `local->dynamic_ps_timer`. Use `spin_lock_irqsave(&local->queue_stop_reason_lock, flags)` for `queue_stop_reasons` in `ieee80211_dynamic_ps_enable_work()`, and `spin_lock_bh(&ifmgd->teardown_lock)` for `teardown_skb`/`orig_teardown_skb` in `ieee80211_mgd_stop()`. In `ieee80211_sta_work()`, do not update `assoc_data->timeout` on TX status when `assoc_data->comeback` is set. [F206, F209, F211, F320]
- `ieee80211_sta_bcn_mon_timer()` and `ieee80211_sta_conn_mon_timer()` run in softirq without `wiphy->mtx`, so `ieee80211_is_csa_in_progress()` and `ieee80211_latest_active_link_conn_timeout()` must use `guard(rcu)()` and RCU accessors (`for_each_link_data_rcu()`, `sta_info_get()`, `rcu_dereference()`). `ieee802_11_parse_elems_full()` must use `GFP_ATOMIC` and `parse.c` must not sleep. [F318, F322]
- Flush `hw_roc_start` before inspecting `roc_list` in `ieee80211_cancel_roc()` and cancel `hw_roc_done` after `drv_cancel_remain_on_channel()` before `ieee80211_start_next_roc()`; flush both `hw_roc_start` and `hw_roc_done` in `ieee80211_reconfig_roc()`. In `ieee80211_ocb_leave()`, set `ifocb->joined = false` before `timer_delete_sync(&sdata->u.ocb.housekeeping_timer)`; process-context `incomplete_lock` callers must use `spin_lock_bh()` and drop it before `ieee80211_ocb_finish_sta()` or `sta_info_free()`. [F203, F204, F311, F312]
- In `__ieee80211_suspend()`, order `suspending = true; mb();` before scan/ROC/BA/queue flush, `quiescing = true; mb();` before `flush_workqueue()` and timer/work cancellations, and `suspended = true; barrier();` before clearing `quiescing`/`suspending`. Run per-STA `rate_control_ops` under `spin_lock_bh(&sta->rate_ctrl_lock)` (`rcu_read_lock()` outside), set `WLAN_STA_RATE_CONTROL` after `rate_init()`, and never take `kernel_param_lock(THIS_MODULE)` under `rate_ctrl_mutex`. [F194, F197, F296, F315]

## Object Lifetimes
- `kfree()` the `struct ieee802_11_elems *` from `ieee802_11_parse_elems_full()` on every path, and hold `rcu_read_lock()` across `ieee80211_determine_chan_mode()` and all dereferences of its returned `elems`. In `ieee80211_assoc_config_link()`, keep `bss_ies` alive until `elems` is freed and never copy pointers into `bss_elems->scratch[]` into `elems`. [F176, F294, F319]
- In `ieee80211_mgd_auth()`, `err_clear:` before `cfg80211_ref_bss()` must free `auth_data` and NULL `ifmgd->auth_data` without `ieee80211_destroy_auth_data()`; when continuing auth (`cont_auth`) or promoting to assoc (`match_auth`), call `ieee80211_destroy_auth_data(sdata, true)`. In `ieee80211_rx_mgmt_assoc_resp()`, copy `assoc_data->link[link_id]` into `resp.links[link_id]` before `ieee80211_destroy_assoc_data()`; free `ifmgd->assoc_req_ies` before reassignment in `ieee80211_send_assoc()` and in `ieee80211_mgd_stop()`. [F180, F181, F182, F183]
- In `ieee80211_mgd_assoc_ml_reconf()`, call `ieee80211_build_ml_reconf_req()` before removing `req->rem_links`, and remove links before `ieee80211_tx_skb()`; never read `add_links_data->link[link_id].elems` after `ieee80211_mgd_assoc_ml_reconf()` returns, and on completion or `ieee80211_ml_reconf_reset()` call `cfg80211_mlo_reconf_add_done()` once and free/NULL `reconf.add_links_data`. [F187, F188, F289]
- When `IEEE80211_VIF_REMOVE_AP_AFTER_DISASSOC` is set in `ieee80211_set_disassoc()`, move `ap_sta` to `IEEE80211_STA_NONE` before `BSS_CHANGED_ASSOC` notification and call `sta_info_flush(sdata, -1)` after. After `ieee80211_attach_ack_skb()` in `ieee80211_mgmt_tx()`, free untransmitted SKBs with `ieee80211_free_txskb()` and NULL `roc->frame` on TX. In non-WoWLAN `__ieee80211_suspend()`, run `ieee80211_mgd_quiesce()`, flush `dec_tailroom_needed_wk`, and call `drv_remove_interface()` before `ieee80211_stop_device(local, true)`. In `rate_control_set_rates()`, free old `pubsta->rates` via `kfree_rcu(old, rcu_head)`. [F190, F193, F299, F306]

## API Contracts
- `ieee802_11_parse_elems_full()` returns `NULL` on error and rejects `params->link_id >= 0 && params->bss` (set `link_id = -1` when `bss` is set), whereas `ieee80211_determine_chan_mode()` returns `ERR_PTR()`. `ieee80211_prep_connection()` requires `ap_mld_addr != NULL` iff `link_id >= 0`, maps `link_id >= 0` to `new_links = BIT(link_id)` (else `0`), populates `link->conf` before `ieee80211_prep_channel()`, and notifies `ieee80211_link_info_change_notify()` after. [F212, F226, F228, F308]
- `ieee80211_prep_channel()` accepts nullable `link` (returning `0` before chanctx assignment when `!link`), and `ieee80211_sta_process_chanswitch()` accepts nullable `csa_elems` (`!csa_elems` -> `res = 1`). `ieee80211_assoc_config_link()` returns `true` on non-assoc link rejection, storing the status in `assoc_data->link[link_id].status`. `ieee80211_latest_active_link_conn_timeout()` initializes `latest_timeout = jiffies` (check with `time_is_after_jiffies()`). [F214, F215, F216, F217]
- Selector bitmaps in `ieee80211_determine_chan_mode()`, `ieee80211_parse_cfg_selectors()`, and `ieee80211_get_rates()` must be `BITS_TO_LONGS(128)` `unsigned long` words (zeroed if reused). `ieee80211_chswitch_done()` runs without `wiphy->mtx` (use `rcu_read_lock()` and queue `csa_connection_drop_work` or `switch_work`). `ieee80211_ap_probereq_get()` requires `wiphy->mtx` on a non-MLD station vif and `rcu_read_lock()` across `ieee80211_bss_get_elem()` and `ieee80211_build_probe_req()`. [F292, F323, F324]
- Reserve `local->hw.extra_tx_headroom` (or `local->tx_headroom` for TTLM) on TX SKBs in `mlme.c`/`offchannel.c`. Pair `ieee80211_ocb_finish_sta()` with `rcu_read_unlock()`. `drv_suspend()` returns `< 0`, `0`, or `1`. In `rate_control_tx_status()`, check `tx_status_ext` first and `st->skb != NULL` before `tx_status`. `ieee80211_get_tx_rates()` accepts nullable `vif` and `sta`. With `HAS_RATE_CONTROL`, `set_rts_threshold` is required, `local->rate_ctrl` is NULL, and `rate_control_get_rate()` returns early (skipping `ieee80211_get_tx_rates()` if `SUPPORTS_RC_TABLE`). [F218, F219, F310, F313, F329, F331]

## Error Handling
- In `ieee80211_mgd_assoc()`, MLO link errors must set `req->links[i].error = err` before `err_free`/`err_clear`, and `err_clear` zeroes `deflink.u.mgd.bssid` only when `!ifmgd->auth_data`. In `ieee80211_mgd_assoc_ml_reconf()`, errors after allocating `data` must jump to `err_free:`. In `ieee80211_prep_connection()`, errors before `sta_info_insert(new_sta)` call `sta_info_free()` and jump to `out_err`, whereas `sta_info_insert()` consumes `new_sta` so later errors jump to `out_release_chan`. In `__ieee80211_suspend()`, non-zero `drv_suspend()` returns must wake `IEEE80211_QUEUE_STOP_REASON_SUSPEND` queues, and `< 0` returns must clear `WLAN_STA_BLOCK_BA`, `quiescing`, and `wowlan`. [F186, F192, F220, F221]

## External Contracts
- Cast `cisco_dtpc_ie[4]` to `(__s8)` in `ieee80211_find_cisco_dtpc()`, and use `DIV_ROUND_UP(br->bitrate, 5)` when matching `sband->bitrates` against `srates[i] & 0x7f` in `ieee80211_parse_bitrates()` and `ieee80211_get_rates()`. [F281, F282]

## Known Pitfalls
- In `ieee80211_parse_extension_element()`, check `len >= sizeof(...)` then `len >= ieee80211_he_*_size(data) - 1`. In `ieee80211_parse_tpe()`, call `ieee80211_valid_tpe_element()` and handle `!count` before `N = 1 << (count - 1)`, clamp `K` to `IEEE80211_TPE_PSD_ENTRIES_320MHZ - N`, and read 320 MHz EIRP at `env->variable[4]` when `count == 3`. In `ieee802_11_find_bssid_profile()`, immediately `return profile_len` on BSSID match and return `0` after the outer loop. [F249, F250, F263, F280]
- Use `get_unaligned_le16(pos)` for variable-offset 16-bit fields in IEs/action frames (`ieee80211_ml_reconfiguration()`, `ieee80211_parse_adv_t2l()`, `ieee80211_get_ttlm()`, `ieee80211_process_ml_reconf_resp()`, `ieee80211_process_epcs_ena_resp()`), `cpu_to_le16()`/`le16_to_cpu()` for `ttlm_res.status_code`, and cast `sizeof()` to `ssize_t` when comparing against `cfg80211_defragment_element()`. Do not re-parse `elems->ml_basic` after `ieee80211_mgd_check_cross_link_csa()` defragments it in place. [F236, F254, F255, F278]
- In `ieee80211_rx_mgmt_beacon()`, offset S1G `variable` by `ieee80211_s1g_optional_len(ext->frame_control)` and call `ieee80211_is_s1g_short_beacon()` only when `ext != NULL`. Gate `vht_cap_elem`/`vht_operation` checks at `mode >= IEEE80211_CONN_MODE_VHT` on `NL80211_BAND_5GHZ` in `ieee80211_assoc_config_link()` and `ieee80211_determine_ap_chan()`. In `ieee80211_mgd_ssid_mismatch()`, negate `memcmp` for `zero_ssid` (`!memcmp(...)`) but not for `cfg->ssid`. [F253, F272, F273]
- Guard `link_removal_timeout[link_id] < 1` before subtracting 1 in `ieee80211_ml_reconfiguration()`, ignore `u16 delay = st_tu - beacon_ts_tu` above `IEEE80211_ADV_TTLM_ST_UNDERFLOW` in `ieee80211_process_adv_ttlm()`, and use signed `long remaining` in `ieee80211_end_finished_rocs()`. Save `roc->on_channel` before `ieee80211_recalc_sw_work()` in `__ieee80211_roc_work()`, and pass the exact member path to `container_of()` in `wiphy_work` handlers. Send nullfunc after clearing `IEEE80211_CONF_PS` in `ieee80211_offchannel_ps_enable()` when `!offchannel_ps_enabled || !PS_NULLFUNC_STACK`, and set `IEEE80211_CONF_PS` before WoWLAN `drv_suspend()` if `associated && powersave` and `!(hw.conf.flags & IEEE80211_CONF_PS)`. [F205, F256, F283, F285, F291, F297, F301]
