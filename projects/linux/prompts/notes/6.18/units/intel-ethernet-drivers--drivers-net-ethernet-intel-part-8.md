# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel (part 8)

Main driver, PHY, NVM, PTP, and TSN modules for Intel I225/I226 (`igc`), plus devlink, main header, and 82598 support for Intel 10GbE (`ixgbe`).

## Architecture & Data Flow
- `igc_clean_tx_irq()` does not reset `tx_buffer->type` on reclaim, and `igc_clean_tx_irq()`/`igc_clean_tx_ring()` switch on `type` to free `skb`, `xdpf`, or XSK frames; every Tx path in `igc_main.c` must set `type` on the packet's first `igc_tx_buffer`. [F710]
- In `igc_xdp_xmit_zc()`, `while (budget >= 4 && xsk_tx_peek_desc(pool, &xdp_desc))` must check `budget >= 4` first, and after `xsk_tx_metadata_request()`, refresh `ntu`, `bi`, and `budget` from `ring->next_to_use`, `meta_req.tx_buffer`, and `meta_req.used_desc` before populating `IGC_TX_DESC(ring, ntu)` and `bi`. [F722, F755]
- In `struct igc_rx_buffer`, page fields and `struct xdp_buff *xdp` share a union discriminated by `ring->xsk_pool`, so Rx alloc, poll, and `igc_clean_rx_ring()` must branch on `ring->xsk_pool`. `struct igc_xdp_buff` must embed `struct xdp_buff` first and fit in `xdp_buff_xsk->cb` for `xsk_buff_to_igc_ctx()`. [F712, F748]
- On `IGC_RXDADV_STAT_TSIP` in `igc_clean_rx_irq()`/`igc_clean_rx_irq_zc()`, save buffer start in `ctx.rx_ts`, advance `data` (and `data_meta` in ZC) by `IGC_TS_HDR_LEN` (16), and subtract `IGC_TS_HDR_LEN` from `size`. `struct igc_inline_rx_tstamps` has `timer1[2]` at DWORDs 0..1 and `timer0[2]` at 2..3 (nsecs `[0]`, secs `[1]`, `le32_to_cpu()` in `igc_ptp_rx_pktstamp()`). [F745, F746]
- When `igc_fpe_is_pmac_enabled() && igc_fpe_handle_mpacket()` intercepts an SMD frame in `igc_clean_rx_irq()`, call `igc_is_non_eop(rx_ring, rx_desc)` and increment `cleaned_count` before `continue`. In `igc_alloc_rx_buffers()`/`_zc()`, clear `wb.upper.length = 0` on the new `next_to_use` descriptor after advancing; in both and `igc_clean_tx_irq()`, index `i` is biased by `i -= ring->count` and must be restored with `i += ring->count` after the loop. [F749, F761, F768]
- `ixgbe_desc_unused()`/`igc_desc_unused()` reserve 1 descriptor (`- 1`), so `igc_watchdog_task()` must test `igc_desc_unused(tx_ring) + 1 < tx_ring->count`. `igc_alloc_q_vector()` must use `struct_size(q_vector, ring, ring_count)` and advance `ring++` after Tx ring init. `igc_rss_type_table[]` and `igc_xdp_rss_type[]` need `IGC_RSS_TYPE_MAX_TABLE` (16) entries. [F747, F779, F782]
- In `igc_rx_vlan()`, decode `rx_desc->wb.upper.vlan` with `be16_to_cpu()` if both `IGC_RXDEXT_STATERR_LB` and `IGC_RING_FLAG_RX_LB_VLAN_BSWAP` are set. `igc_fix_features()` must tie `NETIF_F_HW_VLAN_CTAG_TX` to `NETIF_F_HW_VLAN_CTAG_RX` (`IGC_CTRL_VME`). [F752, F844]
- In `igc_tsn_offload_apply()`, if `netif_running()` and `igc_tsn_will_tx_mode_change()`, schedule `adapter->reset_task` instead of calling `igc_tsn_reset()`. Update `IGC_RXPBS` via `igc_tsn_set_rxpbsize()` to preserve `IGC_RXPBS_CFG_TS_EN`. `igc_tsn_reset()` must sync the empty MAC filter with `fpe.mmsv.pmac_enabled`, and `igc_tsn_enable_offload()` must update `IGC_TXQCTL_PREEMPTIBLE` and `IGC_TXDCTL_PRIORITY_HIGH` together. Disabling MQPRIO in `igc_tsn_enable_mqprio()` must clear `strict_priority_enable`, call `igc_fpe_clear_preempt_queue()`, and call `netdev_reset_tc()` before `igc_tsn_offload_apply()`. [F724, F728, F729, F736]
- On I226 in `igc_tsn_enable_offload()`, for a future `base_time` with no GCL running (`!(rd32(IGC_BASET_H) || rd32(IGC_BASET_L))`), write `IGC_TQAVCTRL_FUTSCDDIS` to `IGC_TQAVCTRL` before `IGC_QBVCYCLET_S`/`IGC_QBVCYCLET`/`IGC_BASET_H`, and write `0` to `IGC_BASET_L` before `baset_l`. Keep `adapter->cycle_time` positive (`NSEC_PER_SEC` in `igc_qbv_clear_schedule()`). [F730, F774]
- In `igc_del_mac_filter()`, RAR index 0 must call `igc_set_mac_filter_hw(adapter, 0, type, addr, -1)` instead of clearing. `igc_add_nfc_rule()` must keep `nfc_rule_list` sorted by ascending `location`. `igc_write_flex_filter_ll()` must clear `IGC_WUFC_FLEX_HQ` before FHFT writes and re-enable it after, and `igc_del_flex_filter()` must keep it set while `igc_flex_filter_in_use()`. In `igc_deliver_wake_packet()`, check `wupl` in `1..IGC_WUPM_BYTES` (128) and call `skb_put(skb, wupl)` before `roundup(wupl, 4)`. [F732, F733, F744, F762]
- Call `igc_ptp_suspend()` (`igc_ptp_time_save()`) before reset/suspend so `igc_ptp_reset()` restores time and `tstamp_config`. In `igc_phc_get_syncdevicetime()`, each loop iteration must call `ktime_get_snapshot()` before `igc_ptm_trigger()`, call `igc_ptm_reset()` after polling, and `swab32(rd32(IGC_PTM_CURR_T2_H))`. [F734, F753, F758]
- In `igc_rd32()`, detach on `0xffffffff` only if `!reg || !(~readl(hw_addr))`; `igc_io_slot_reset()` must restore `hw->hw_addr = adapter->io_addr`, and `iounmap()` must use `adapter->io_addr`. On I226, disable `PCIE_LINK_STATE_L1_2` in `igc_probe()`, `__igc_resume()`, and (`pci_disable_link_state_locked()`) `igc_io_slot_reset()`. Skip `pm_runtime_*` in `__igc_open()`/`__igc_close()` when `resuming`/`suspending`. [F735, F763, F796, F810]
- `ixgbe_reset_hw_82598()` must save `IXGBE_AUTOC` once in `orig_autoc` and restore it + Atlas Tx lanes (`IXGBE_ATLAS_PDN_TX_REG_EN`) on resets. Multiply `hw->flash.sr_words` by `2u` for `shadow-ram` byte size, and `mdelay(500)` before polling `IXGBE_FWSM` in `ixgbe_devlink_reload_empr_finish()`. [F739, F769, F791]

## Synchronization
- PTM ops in `igc_ptp.c` require `adapter->ptm_lock` (`mutex`). Process-context callers of `adapter->tmreg_lock` must use `spin_lock_irqsave()`. In `igc_ptp_reset()`, lock `ptm_lock` outer to `tmreg_lock` and use `readx_poll_timeout_atomic()` inside `tmreg_lock`. [F692, F693, F819]
- Access `adapter->tx_tstamp[]` under `spin_lock_irqsave(&adapter->ptp_tx_lock, ...)`. `igc_ptp_disable_tx_timestamp()` must clear `IGC_RING_FLAG_TX_HWTSTAMP` before `igc_ptp_clear_tx_tstamp()`; `igc_ptp_enable_tx_timestamp()` must configure `IGC_TSYNCTXCTL` and read `IGC_TXSTMPL`/`H` before setting `IGC_RING_FLAG_TX_HWTSTAMP`. [F694, F695]
- Hold `__netif_tx_lock()` for `igc_xdp_init_tx_descriptor()`, `igc_fpe_init_tx_descriptor()`, and `igc_flush_tx_descriptors()`. Use `GFP_ATOMIC` in `igc_insert_empty_frame()` (under `__netif_tx_lock`) and in `igc_set_rx_mode()`/`igc_write_mc_addr_list()` (under `netif_addr_lock_bh`). [F696, F823, F824]
- `igc_tx_map()` needs `wmb()` before `first->next_to_watch = tx_desc` and `writel(i, tx_ring->tail)`, paired with `smp_rmb()` in `igc_clean_tx_irq()` before reading `eop_desc->wb.status`. `__igc_maybe_stop_tx()` needs `smp_mb()` after `netif_stop_subqueue()` before rechecking `igc_desc_unused()`, paired with `smp_mb()` in `igc_clean_tx_irq()` after `next_to_clean` before checking `__netif_subqueue_stopped()` and `!test_bit(__IGC_DOWN, &adapter->state)`. [F700, F702]
- Protect `qbv_transition`, `admin_gate_closed`, and `oper_gate_closed` with `spin_lock_irqsave(&adapter->qbv_tx_lock, flags)`; for future `base_time` in `igc_save_qbv_schedule()`, set `admin_gate_closed = true` (not `oper_gate_closed`). In `igc_clean_rx_irq_zc()`, hold `rcu_read_lock()` across `READ_ONCE(adapter->xdp_prog)` and `__igc_xdp_run_prog()`. Use `tx_syncp` for `tx_stats.{packets,bytes,restart_queue}` and `tx_syncp2` for `restart_queue2`. [F704, F705, F731, F828]
- In `igc_write_phy_reg_gpy()`/`igc_read_phy_reg_gpy()`, wrap direct MDIC (`dev_addr == 0`) with `phy.ops.acquire()`/`release()`, but not `igc_write_xmdio_reg()`/`igc_read_xmdio_reg()`. `ixgbe_read_i2c_phy_82598()` must hold `acquire_swfw_sync(hw, gssr)` across MDIO SDA/SCL ops. `ixgbe_devlink_nvm_snapshot()` must lock `ixgbe_acquire_nvm()` per block and release on error (as in `ixgbe_devlink_nvm_read()`). Hold `devl_lock()` for `ixgbe_devlink_register_port()` and `ixgbe_devlink_{init,destroy}_regions()`. [F707, F708, F833, F835]

## Object Lifetimes
- In `igc_probe()`, set `hw->device_id` before `igc_is_device_id_i226(hw)`, and call `igc_release_hw_control()` + `igc_ptp_stop()` on errors after `igc_ptp_init()`. In `igc_down()`/`igc_remove()`, set `__IGC_DOWN` before disabling IRQs/NAPI, deleting timers, or canceling work/hrtimers. `__igc_resume()` must call `igc_init_interrupt_scheme(adapter, true)` before `igc_reset()` and `__igc_open()`. [F675, F703, F795, F809]
- `igc_free_q_vector()` must use `kfree_rcu(q_vector, rcu)` after `igc_reset_q_vector()`, and `igc_update_stats()` needs `rcu_read_lock()`. Call `xdp_rxq_info_unreg()` and clear `rx_buffer_info = NULL` on `igc_setup_rx_resources()` error and in `igc_free_rx_resources()`. [F687, F826]
- `igc_request_tx_tstamp()` calls `skb_get(skb)` and `igc_xsk_request_timestamp()` sets `xsk_pending_ts = true`; `igc_ptp_free_tx_buffer()` must free `tstamp->skb` or clear `xsk_pending_ts`/`xsk_tx_buffer`/`buffer_type` and call `igc_xsk_wakeup()`. In `igc_clean_rx_irq_zc()`, free or redirect `bi->xdp` and set `bi->xdp = NULL` before advancing `ntc`. Allocate `ixgbe` devlink region snapshots with `kvzalloc()` (`.destructor = kvfree`). [F682, F683, F685, F792]

## API Contracts
- `igc_cleanup_headers()` frees `skb` when returning `true`. `igc_xdp_init_tx_descriptor()` consumes `xdpf` only when returning `0`. Rx pages using `IGC_RX_DMA_ATTR` require `dma_sync_single_range_for_cpu()` before unmap/read and `for_device()` on refill. [F676, F678, F830]
- `igc_features_check()` clears csum/TSO on oversized MAC/network headers and `NETIF_F_TSO` on encap without `NETIF_F_TSO_MANGLEID`. `igc_tso()` requires `skb_cow_head(skb, 0)`, zero-initialized `hdr_len`, and calling `igc_tx_csum()` only when `igc_tso()` returns `0`. [F718, F841]
- `igc_poll()` returns `budget` if `!clean_complete`, else enables IRQs only if `napi_complete_done()` returns `true` and returns `min(work_done, budget - 1)`. Write `IGC_GPIE_MSIX_MODE` before `IGC_IVAR_MISC`/`IGC_IVAR0`. In `igc_xsk_tx_metadata_ops`, request callbacks take `struct igc_metadata_request *` while `igc_xsk_fill_timestamp()` takes `u64 *`. [F789, F802, F843]
- `igc_set_mac_filter_hw()`/`igc_add_etype_filter()` take signed `int queue` (`< 0` disables steering). `igc_save_cbs_params()` requires queue 0 CBS enabled before enabling queue 1 CBS, and queue 1 disabled before disabling queue 0 (`-EINVAL`). `igc_phy_hw_reset()` treats positive `IGC_ERR_BLK_PHY_RESET` from `igc_check_reset_block()` as `0`. `igc_{read,write}_phy_reg_gpy()` put MMD in upper 16 bits; `__igc_access_xmdio_reg()` must reset `IGC_MMDAC = 0`. [F716, F719, F721, F767, F812]
- `igc_ptm_trigger()` needs `wrfl()`, and `igc_ptm_reset()` must clear `IGC_PTM_CTRL_TRIG` before `IGC_PTM_STAT_ALL`. `igc_ptp_set_timestamp_mode()` sets `rx_filter = HWTSTAMP_FILTER_ALL` when enabled. Read `IGC_GORCH`/`IGC_GOTCH` after `IGC_GORCL`/`IGC_GOTCL`. Set `*actions_performed = BIT(DEVLINK_RELOAD_ACTION_FW_ACTIVATE)` in `ixgbe_devlink_reload_empr_finish()`. [F799, F811, F846, F848]

## Error Handling
- On DMA error, `igc_tx_map()` unmaps fragments, frees `tx_buffer->skb`, sets `skb = NULL`, and rewinds `next_to_use`. In `ixgbe_set_ctx_dev_caps()`, clear `nvm_update_pending_* = false` if querying the inactive version fails. In `ixgbe_reset_hw_82598()`, keep `phy.ops.init()` in `phy_status` (`-EOPNOTSUPP` returns, `-ENOENT` skips PHY reset, non-zero overwrites `status` after MAC reset). Gate `ixgbe_devlink_init_regions()` on `ixgbe_mac_e610` and reset `IS_ERR()` region pointers to `NULL`. [F677, F714, F715, F814]

## External Contracts
- Pad SKBs `< 17` bytes in `igc_xmit_frame()`, and pad `tx_ring->preemptible` frames to `ETH_ZLEN` via `skb_padto()` + `skb_put()` in `igc_xmit_frame_ring()`. Gate `igc` PTM cross-timestamping on `CONFIG_X86_TSC && !CONFIG_UML`. Preserve exact link log strings in `igc_watchdog_task()` and `attrs.no_phys_port_name = 1` in `ixgbe_devlink_register_port()`. [F740, F794, F836, F842]

## Known Pitfalls
- `rd32()`/`wr32()` take byte offsets while `array_rd32()`/`array_wr32()` take DWORD indices (`<< 2`). Reading `IGC_TXSTMPH_0` clears all TXTT bits in `IGC_TSYNCTXCTL`, so `igc_ptp_tx_hwtstamp()` must save `IGC_TSYNCTXCTL` before reading `IGC_TXSTMPH_0`, and `igc_ptp_tx_hang()` must read `IGC_TXSTMPH_0` on timeout. [F790, F801]
- Resolve `first` / `meta_req->tx_buffer` from `tx_buffer_info[next_to_use]` after `igc_insert_empty_frame()` and before emitting context descriptors. In `igc_tx_csum()`, `skb_checksum_help()` must jump to `csum_failed:` so `no_csum:` still emits VLAN/launchtime context descriptors. [F757, F766]
- Check `igc_phy_has_link()` return value before `*success`. Do not reinitialize `i` in `ixgbe_set_rxpba_82598()` (`PBA_STRATEGY_WEIGHTED` fallthrough with `i == 4`). Stage ITR in `q_vector->itr_val` (`set_itr = 1`), guard `bytes / packets` with `packets != 0`, and clamp `PTP_CLK_REQ_PEROUT` start to `safe_start.tv_sec + 2`. [F717, F759, F775, F781, F803]
- Arithmetic/bounds: widen negated `scaled_ppm` to `u64 rate` before `<< 14` and `div_u64(rate, 78125)` in `igc_ptp_adjfine_i225()`; use `DIV_ROUND_UP_ULL(ring->idleslope * 61036ULL, 2500000)` in `igc_tsn_enable_offload()`; cast high 32-bit reads to 64-bit before `<< 32`; check `u64` `offset + size > nvm_size` before `u32` cast in `ixgbe_devlink_nvm_read()` and `words > nvm->word_size - offset` in `igc_read_nvm_eerd()`; use `DIV_ROUND_UP()` in `ixgbe_devlink_nvm_snapshot()` and `igc_alloc_q_vectors()`. [F770, F771, F772, F773, F777]
