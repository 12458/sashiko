# DRM DRIVERS AND MISC GPU PATCHES — drivers/gpu/drm (part 6)

Core DRM infrastructure: `drm_mm`, `drm_pagemap`, PRIME/DMA-BUF, KMS objects/properties, modeset locking, display modes, planes, output probing/polling, DT/DMI/panel quirks, privacy screens, panic rendering, and debug printing.

## Architecture & Data Flow
- `drm_mm_init()` sets `head_node.start = start + size` and `head_node.size = -size`, relying on u64 wraparound in `__drm_mm_hole_node_start()`. Because the interval tree uses inclusive `[START, start + size - 1]`, `drm_mm_reserve_node()` and `drm_mm_insert_node_in_range()` must reject `size == 0` or `start + size <= start` (`-ENOSPC`), and must update `node->node_list` and call `rm_hole()` before `add_hole()` (which computes `hole_size` from `list_next_entry(node, node_list)->start`). [F280, F307, F308]
- In `drm_pagemap_migrate_map_pages()`, `drm_pagemap_migrate_unmap_pages()`, and `drm_pagemap_migrate_populate_ram_pfn()`, each `npages` loop must reset `order = 0` per iteration and advance `i` by `NR_PAGES(order)` so high-order folios are processed once at their head index and empty slots advance by 1. [F320]
- `drm_prime_add_buf_handle()` and `drm_prime_remove_buf_handle()` must insert and erase each `drm_prime_member` in both `prime_fpriv->dmabufs` and `prime_fpriv->handles` in lockstep with a single `dma_buf` ref per entry. [F282]
- `drm_mode_object::free_cb` distinguishes refcounted KMS objects: `__drm_mode_object_add()` only initializes `obj->refcount` when `obj_free_cb` is non-NULL, `drm_mode_object_get()`/`put()` are no-ops when `free_cb` is NULL, and `drm_mode_object_find()` returns `NULL` on miss. IDs in `object_idr` must be 1-based (`start = 1`) as ID 0 is the unregistered sentinel. [F261, F303]
- `__drm_universal_plane_init()` must reject `num_total_plane >= 32` and `format_count > 64` (`-EINVAL`, 32-bit `drm_plane_mask()` and `1ULL << j` in `u64 mod->formats`). `drm_mode_config_validate()` requires `num_primary == num_crtc`, unique `crtc->primary` matching `drm_crtc_mask(crtc)`, and no CRTC setting both `crtc->cursor` and legacy `cursor_set`/`cursor_move`. In `drm_mode_cursor_universal()`, update `crtc->cursor_x/y` only after `__setplane_atomic()`/`__setplane_internal()` succeeds. [F293, F342, F414]
- In `drm_of_component_probe()`, add all CRTC `ports` phandles to `match` in a first loop before a second loop adds child endpoint remote encoder nodes. In `drm_mode_validate_pipeline()`, continue across rejected encoders/bridges/CRTCs and return `0` as soon as any combination sets `*status = MODE_OK`. [F327, F334]
- In `drm_mode_parse_cmdline_options()`, after defaulting to `DRM_MODE_ROTATE_0` if `!(rotation & DRM_MODE_ROTATE_MASK)`, check `is_power_of_2(rotation & DRM_MODE_ROTATE_MASK)`. In `drm_panel_orientation_quirks.c`, `orientation_data[]` must end with `{}` and every non-NULL `bios_dates` array must end with `NULL`. [F314, F332]
- In `draw_panic_plane()`, pair `drm_panic_set_description()` with `drm_panic_clear_description()` before `drm_panic_unlock()`. `QR_BUFFER1_SIZE` and `QR_BUFFER2_SIZE` must be >= 4071 bytes since `qrbuf1`/`qrbuf2` swap roles in `drm_panic_qr_generate()`. In `drm_privacy_screen_get()`, initialize `best = -1` and reset `match = 0` per entry (+2 for `dev_id`, +1 for `con_id`, skipping mismatches). [F296, F337, F361]

## Synchronization
- Lock order in `drmm_mode_config_init()` is `crtc_ww_class` (`drm_modeset_lock`) -> `mmap_lock` -> `reservation_ww_class` (`dma_resv_lock`). `drm_mm` has no internal locks; allocations in insertion/reservation paths (`save_stack()`) must use `GFP_NOWAIT`. [F384, F399]
- `drm_pagemap_migrate_to_devmem()` requires `mmap_assert_locked(mm)`, whereas `drm_pagemap_evict_to_ram()` pins `mm` via `mmget_not_zero()` / `mmput_async()`. `drm_pagemap_devmem_init()` must call `init_completion(&devmem_allocation->detached)`, and `drm_pagemap_zdd_destroy()` (called in `put_page()` / atomic context) must call `complete_all(&devmem->detached)` before `ops->devmem_release(devmem)` (which must not sleep). [F256, F257, F397]
- In `drm_gem_prime_fd_to_handle()`, `drm_gem_handle_create_tail()` unlocks `dev->object_name_lock`; if `drm_prime_add_buf_handle()` fails, unlock `file_priv->prime.lock` before `drm_gem_handle_delete()`. In `drm_gem_prime_handle_to_dmabuf()`, checking `obj->handle_count == 0` and calling `drm_prime_add_buf_handle()` must both hold `dev->object_name_lock`. `drm_gem_map_attach()`/`detach()` invoke `obj->funcs->pin`/`unpin` under `dma_resv_lock(obj->resv, NULL)`. [F223, F247, F393]
- On `-EDEADLK` from `drm_modeset_lock()`, `ctx->contended` is set and callers must call `drm_modeset_backoff(ctx)` before further lock/drop calls on `ctx`. `modeset_lock()` must convert `-EALREADY` to `0` without `list_add(&lock->head, &ctx->locked)`. Unlike `drm_modeset_lock_all()`, `drm_modeset_lock_all_ctx()` does not take `dev->mode_config.mutex` (acquire it outside `ctx`). [F228, F229, F322]
- `__drm_mode_object_add()`, `drm_mode_object_register()`, `drm_mode_object_unregister()`, and `__drm_mode_object_find()` must hold `dev->mode_config.idr_mutex` around `object_idr`, `obj->id`, and `kref_get_unless_zero(&obj->refcount)`. `dev->mode_config.connector_list_lock` must always be taken with `spin_lock_irq()` or `spin_lock_irqsave()`. [F240, F386]
- Hold `dev->mode_config.mutex` for `drm_mode_probed_add()`, `drm_connector_list_update()`, `drm_helper_probe_single_connector_modes()`, and `check_connector_changed()`, plus `connection_mutex` across `detect_connector_status()`. Call `drm_kms_helper_hotplug_event()` and `drm_kms_helper_connector_hotplug_event()` with no modeset locks held; `output_poll_execute()` must use `mutex_trylock(&dev->mode_config.mutex)` and unlock before `drm_kms_helper_hotplug_event()`. [F252, F254, F391]
- In suspend/poll teardown (`drm_mode_config_helper_suspend()`, `drm_kms_helper_poll_disable()`, `drm_kms_helper_poll_fini()`), call `drm_kms_helper_disable_hpd(dev)` before `cancel_delayed_work_sync(&dev->mode_config.output_poll_work)` only when `poll_enabled` is true; `.detect` callbacks must check `drm_kms_helper_is_poll_worker()` to avoid runtime PM deadlock. [F255, F380]
- `drm_privacy_screen_unregister()` removes `priv->list` under `drm_privacy_screen_devs_lock` and clears `priv->ops` and `priv->drvdata` under `priv->lock` before `device_unregister()`; callers must check `priv->ops != NULL` under `priv->lock`, and unlock `priv->lock` before `drm_privacy_screen_call_notifier_chain(priv)`. In `draw_panic_plane()`, `get_scanout_buffer`, `panic_flush`, and `set_pixel` run under `raw_spinlock_t` `panic_lock` with IRQs disabled and must not sleep. [F250, F381, F415]

## Object Lifetimes
- `drm_gem_dmabuf_export()` refs `drm_device` and `drm_gem_object`, requiring `drm_gem_dmabuf_release()`. Foreign imports in `drm_gem_prime_import_dev()` attach, `get_dma_buf()`, and map (requiring `drm_prime_gem_destroy()` in `funcs.free`), whereas self-imports (`drm_gem_is_prime_exported_dma_buf()`) only ref `dma_buf->priv` directly. In `drm_gem_prime_mmap()`, drop `drm_gem_object_get(obj)` on `funcs->mmap` error and pair `drm_vma_node_allow()` with `drm_vma_node_revoke()`. [F221, F222, F225, F404]
- In `drm_plane_force_disable()`, `__setplane_internal()`, and `drm_mode_page_flip_ioctl()`, reset `plane->old_fb = NULL` on callback failure so cleanup does not put the active FB. `__drmm_universal_plane_alloc()` requires `funcs->destroy == NULL`, while `drm_universal_plane_init()` requires non-NULL `funcs->destroy` (never `devm_kzalloc()`). [F231, F371]
- `drm_modeset_register_all()` registers planes, CRTCs, encoders, connectors, and rollback / `drm_modeset_unregister_all()` must reverse that order. `drm_mode_config_helper_suspend()` must reverse `drm_client_dev_suspend()` and `drm_kms_helper_poll_disable()` on error, and `drm_mode_config_helper_resume()` must clear `suspend_state = NULL`. [F237, F238]
- Every `drm_for_each_connector_iter()` must call `drm_connector_list_iter_end()` on all exits, and using a connector after `iter_end()` requires `drm_connector_get()`/`put()`. `drm_mode_config_cleanup()` must call `flush_work(&dev->mode_config.connector_free_work)` after `iter_end()` before checking `connector_list` or destroying KMS objects/IDRs, without holding `fb_lock`. [F239, F253, F325]
- `drm_of_component_match_add()` calls `of_node_get(node)`, so callers must still `of_node_put(node)`. Early exits in `for_each_endpoint_of_node()` / `for_each_child_of_node()` in `drm_of.c` must `of_node_put()` the loop cursor and any `remote_port`. [F234, F235]
- `drm_privacy_screen_lookup` structs must remain in non-init memory until `drm_privacy_screen_lookup_remove()`. `drm_panic_setup_logo()` must `kmemdup()` the `__init` struct and data from `fb_find_logo()`. In `drm_panic_blit_page()`/`fill_page()`, `kunmap_local(vaddr)` must be called before mapping a new page and after pixel loops finish. [F335, F373, F374]

## API Contracts
- Zero-initialize `struct drm_mm_node` before `drm_mm_insert_node_in_range()` or `drm_mm_reserve_node()` (`node->flags` is not cleared). `__drm_mm_interval_first(mm, start, last)` takes inclusive `last` and returns `&mm->head_node` (never `NULL`) on miss. Pass scanned nodes from `drm_mm_scan_add_block()` to `drm_mm_scan_remove_block()` in reverse order before `drm_mm_remove_node()`. [F259, F260, F281]
- `drm_prime_sg_to_page_array()` / `dma_addr_array()` return `-1` if pages > `max_entries`. `drm_gem_map_attach()`/`drm_gem_map_dma_buf()` require `funcs->get_sg_table` (`-ENOSYS` if NULL) and map/unmap with `DMA_ATTR_SKIP_CPU_SYNC`. `drm_gem_prime_handle_to_fd()` must only `fd_install()` after `drm_gem_prime_handle_to_dmabuf()` succeeds. [F272, F405, F406]
- Check `obj->type` before `obj_to_connector/crtc/plane()`. Call `drm_object_attach_property()` only before object registration. Atomic drivers may only call `drm_object_property_set_value()` on `DRM_MODE_PROP_IMMUTABLE` properties and must use `drm_object_property_get_default_value()` instead of `get_value()`. [F262, F358, F369]
- Terminate non-NULL `format_modifiers` with `DRM_FORMAT_MOD_INVALID`. `drm_plane_create_scaling_filter_property()` requires `BIT(DRM_SCALING_FILTER_DEFAULT)` in `supported_filters`, and `drm_plane_add_size_hints_property()` requires `DRM_PLANE_TYPE_CURSOR`. In `__setplane_check/internal/atomic()`, `crtc_x/y/w/h` are integer pixels (checked against `INT_MAX`) while `src_x/y/w/h` are 16.16 fixed-point. [F269, F302, F305]
- `drm_helper_probe_detect()` returns positive `drm_connector_status` when `ctx == NULL`, but may return `-EDEADLK` or `< 0` when `ctx != NULL`. `drm_connector_mode_valid()` and `drm_mode_validate_pipeline()` put mode rejection in `*status` (`MODE_OK == 0`) and return non-zero `int` only on lock errors (`-EDEADLK`). [F274, F275]
- `drm_display_mode::clock` is in kHz while `drm_analog_tv_mode()`'s `pixel_clock_hz` and `videomode::pixelclock` are in Hz; `drm_gtf_mode_complex()` takes `2 * C` and `2 * J`. In `drm_of_find_panel_or_bridge()`, if `of_drm_find_panel()` fails, clear `*panel = NULL` and keep `ret = -EPROBE_DEFER` to still query `of_drm_find_bridge()`. [F277, F329]
- `drm_privacy_screen_get()` and `drm_get_panel_backlight_quirk()` return `ERR_PTR` (never `NULL`) on failure, whereas `drm_get_panel_orientation_quirk()` returns `DRM_MODE_PANEL_ORIENTATION_UNKNOWN`. `get_scanout_buffer()` returning `0` requires single-plane `sb.format` and `sb.set_pixel`, `sb.pages`, or `sb.map[0]`. Bound `drm_panic_line` reads by `line->len` (not NUL), and clamp `nbits` to `BITS_PER_TYPE(value)` in `drm_print_bits()`. [F273, F278, F279, F315, F363]

## Error Handling
- In `drm_pagemap_migrate_to_devmem()` and `__drm_pagemap_migrate_to_ram()`, any error after `migrate_vma_setup()` finds `cpages > 0` must jump to `err_finalize`. `drm_pagemap_zdd_alloc()` returns `NULL` on failure, and `drm_pagemap_migrate_to_devmem()` only transfers the `devmem_allocation` ref after `ops->copy_to_devmem()` succeeds. [F219, F265]
- In `set_property_atomic()`, call `drm_atomic_state_clear(state)` before `drm_modeset_backoff(&ctx)` on `-EDEADLK`, and put state, drop locks, and fini `ctx` on exit. In `drm_mode_page_flip_ioctl()`, put and clear `fb = NULL` and `plane->old_fb = NULL` before `-EDEADLK` retry, cancel `e` via `drm_event_cancel_free()`, and call `drm_crtc_vblank_put(crtc)` only after the retry loop exits on error. `drm_mode_convert_umode()` must reject `in->clock > INT_MAX` or `in->vrefresh > INT_MAX` with `-ERANGE`. [F227, F232, F349]

## External Contracts
- In `__drm_pagemap_migrate_to_ram()`, return `0` without migrating if `get_jiffies_64()` is before `timeslice_expiration`, whereas negative errors return `VM_FAULT_SIGBUS`. [F403]
- `__drm_mode_object_find()` checks `_drm_lease_held()` for CRTCs, connectors, and planes, and legacy ioctls using `crtc->cursor`/`primary` must check `drm_lease_held()` on the plane. Resource/property enumeration ioctls must filter by `drm_file` capabilities and leases on both passes, increment `count` only for eligible items, guard `put_user()` with `count < user_capacity`, and continue counting past `user_capacity`. [F326, F408, F410]
- `create_in_format_blob()` must `ALIGN(formats_size, 8)` for both blob size and `modifiers_offset`. `FB_DAMAGE_CLIPS` (`drm_plane_get_damage_clips()`) uses integer FB rects `[x1, y1, x2, y2)`. `drm_mode_convert_umode()` masks `out->type` with `DRM_MODE_TYPE_ALL`, strips `DRM_MODE_FLAG_PIC_AR_MASK`, and uses `strscpy_pad()` for `name`. `drm_mode_page_flip_ioctl()` must reject `sequence != 0` without `DRM_MODE_PAGE_FLIP_TARGET` and reject having both target flags set. Non-Alpha `drm_get_pci_domain()` returns `0` when `dev->if_version < 0x10004`. [F299, F306, F311, F316, F333, F367]

## Known Pitfalls
- In `drm_mm_insert_node_in_range()`, mask `DRM_MM_INSERT_ONCE` out of `mode` before `first_hole()`/`next_hole()` and stop after one hole if set; use `div64_u64_rem()` when `alignment > 1` is not a power of two. In `drm_mm_scan_color_evict()`, check `&hole->hole_stack == &mm->hole_stack` after `list_for_each_entry()`. [F318, F319, F341]
- Scale offsets from `void *buf` in `drm_pagemap` by `sizeof(*src) * npages`, but from typed `migrate.src` by `npages`. Cast `nr_pages` to `unsigned long` before `<< PAGE_SHIFT` in `drm_prime_pages_to_sg()`. [F350, F357]
- Use `drm_mode_copy()` to update a list-linked `drm_display_mode` in place (preserving `mode->head` in `drm_connector_list_update()`) and `drm_mode_init()` for uninitialized stack modes. `drm_helper_move_panel_connectors_to_head()` must move panels to a temporary list with `list_move_tail()` and `list_splice()` to preserve order. [F288, F330, F338]
- In `drm_modes.c`, `remaining` after `simple_strtol()` must be signed `int` checked for `< 0`; skip hyphens where `!isdigit(bpp_ptr[1])` for named modes; check `*delim == '='` before `delim + 1`. Use `check_mul_overflow()` and `DIV_ROUND_CLOSEST_ULL(mul_u32_u32(num, 1000), den)` in `drm_mode_vrefresh()`, `u64` + `do_div()` in `fill_analog_mode()`/`drm_cvt_mode()`, and `DIV_ROUND_UP()` for `hslen`/`hfp_min`/`hbp_min`. [F312, F331, F346, F347, F348, F366]
- In `__drmm_universal_plane_alloc()`, pass `container` to `kfree()` on error but `plane` (`container + offset`) to `drmm_universal_plane_alloc_release`. `drm_mode_cursor_ioctl()` must copy only `sizeof(struct drm_mode_cursor)` bytes into `new_req` and zero `hot_x/y`. In `drm_mode_page_flip_ioctl()`, check `(int)(target_vblank - current_vblank) > 1` and set `e->event.base.length = sizeof(e->event)` (while allocating `sizeof(*e)`). [F345, F356, F359, F360]
- In `drm_panic.c`, use `DIV_ROUND_UP(width, 8)` for 1-bpp pitch, advance `kmsg` past `'\n'` after `zlib_deflateEnd()` before `try_again` in `drm_panic_get_qr_code_url()`, and add byte `offset` to `void *vaddr` before casting in `drm_panic_write_pixel16/24/32()`. `__drm_printfn_coredump()`'s `snprintf()` fast path requires `len < iterator->remain`. [F336, F352, F362, F364]
