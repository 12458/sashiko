# NETWORKING [IPv4/IPv6] — net/ipv6 (part 3)

Implements IPv6 generic and UDP tunneling (`ip6_tunnel.c`, `ip6_udp_tunnel.c`), IPv6 Multicast Routing (`ip6mr.c`), IPv6 socket options (`ipv6_sockglue.c`), MLDv1/MLDv2 and multicast management (`mcast.c`, `mcast_snoop.c`), Mobile IPv6 (`mip6.c`), and Neighbour Discovery (`ndisc.c`).

## Architecture & Data Flow
- `ip6_tnl_update` must call `ip6_tnl_unlink`, `synchronize_net()`, `ip6_tnl_change` (which calls `dst_cache_reset` and `ip6_tnl_link_config`), and `ip6_tnl_link`. `ip6_tnl_xmit` enables `use_cache` only if `!collect_md`, `!ipv6_addr_any(&raddr)`, `proto != 0`, and neither `IP6_TNL_F_USE_ORIG_TCLASS` nor `IP6_TNL_F_USE_ORIG_FWMARK` is set. In `ip6_tnl_lookup`, wildcard passes (`(&any, local)`, `(remote, &any)`) set `cand = t` only if `!cand`. `ip6_tnl_parse_tlv_enc_lim` advances `i` by `1` for `IPV6_TLV_PAD1` (`type == 0`) and `tel->length + 2` otherwise after checking `i + sizeof(*tel) <= optlen`. [F788, F789, F825, F826]
- `struct mr_mfc _c` must stay at offset 0 of `struct mfc6_cache` (`ip6mr_cache_free_rcu`, `_ip6mr_fill_mroute`, and `ip6mr_rht_params` rely on it). Non-default `mrt->id` must be `< 100000000` so `"pim6reg%u"` in `ip6mr_reg_vif` fits in `IFNAMSIZ`. SKBs on `mfc_un.unres.unresolved` with `ipv6_hdr(skb)->version == 0` are synthetic `ip6mr_get_route` requests that `ip6mr_cache_resolve` and `ip6mr_destroy_unres` must answer via `rtnl_unicast`. [F768, F850, F851]
- `mrt->maxvif` bounds `mrt->vif_table[MAXMIFS]` (`0 <= vifi < maxvif <= MAXMIFS`); validate userspace `mifi` (`< MAXMIFS` on add; `0 <= mifi < maxvif` on lookup/del, with `array_index_nospec` in ioctls). Because `minvif` is init `MAXMIFS` and `maxvif` is init `0`, reverse VIF loops in `ip6_mr_forward` and `ip6_mr_output_finish` require signed `int ct` (`maxvif - 1` down to `minvif`). [F810, F811]
- `mld_process_v1` calls `mld_set_v1_mode` only when `v1_query` (`len == MLD_V1_QUERY_LEN`) is true, and stops MLDv2 works (`mld_gq_stop_work`, `mld_ifc_stop_work`, `mld_clear_delrec`). `ipv6_mc_check_ip6hdr` rejects packets where `len = offset + ntohs(ip6h->payload_len)` satisfies `skb->len < len || len <= offset`. [F797, F821]
- In `do_ipv6_setsockopt`: non-zero `IPV6_MINHOPCOUNT` calls `static_branch_enable(&ip6_min_hopcount)` before setting `np->min_hopcount`; `IPV6_TCLASS` preserves `INET_ECN_MASK` on `SOCK_STREAM` and calls `sk_dst_reset(sk)`; `IPV6_TRANSPARENT`/`IPV6_FREEBIND` use `inet_assign_bit`/`inet_test_bit`. For `optlen > 0`, `ipv6_set_opt_hdr` verifies `optlen >= sizeof(struct ipv6_opt_hdr)`, `!(optlen & 0x7)`, `optlen <= 8 * 255`, and `ipv6_optlen(new) <= optlen`. `mip6_mh_filter` checks `((mh->ip6mh_hdrlen + 1) << 3) <= skb->len` and `mh->ip6mh_hdrlen >= mip6_mh_len(mh->ip6mh_type)`. [F783, F784, F818, F822, F883]
- `ndisc_constructor` replaces `neigh->parms` via `__neigh_parms_put` and `neigh_parms_clone(in6_dev->nd_parms)`. Updating `BASE_REACHABLE_TIME` (`ndisc_router_discovery`, `ndisc_ifinfo_sysctl_change`) recomputes `reachable_time` via `neigh_rand_reach_time()`, updates `in6_dev->tstamp = jiffies`, and (on RA) sets `GC_STALETIME = 3 * rtime`. `ndisc_recv_na` samples `neigh->flags` before `ndisc_update` and calls `rt6_clean_tohost` if `NTF_ROUTER` is cleared. [F801, F802, F803]
- Use `time_before`/`time_after` for jiffies: check `time_after(c->mfc_un.unres.expires, now)` before subtracting `now` in `ipmr_do_expire_process`, and use them for `idev->mc_v1_seen` (`mld_in_v1_mode`), `t->err_time + IP6TUNNEL_ERR_TIMEO` (`ip6_tnl_xmit`), and `last_assert + MFC_ASSERT_THRESH` (`ip6_mr_forward`). [F842, F843]

## Synchronization
- In `mcast.c`: under `idev->mc_lock`, `ip6_mc_source`, `ip6_mc_msfilter`, and `__ipv6_dev_mc_inc` must check `idev->dead` (`-ENODEV`); if `leavegroup == 1`, unlock `idev->mc_lock` before `ipv6_sock_mc_drop`. `ipv6_mc_down` calls `igmp6_group_dropped` on `idev->mc_list` before stopping MLD works, and calls `mld_report_stop_work` outside `idev->mc_lock`. `mc_query_queue`/`mc_report_queue` use `spin_lock_bh`; `mld_query_work`/`mld_report_work` splice SKBs and unlock before taking `idev->mc_lock`. [F745, F746, F747, F750]
- `ip6_tnl_encap_add_ops`/`ip6_tnl_encap_del_ops` update `ip6tun_encaps[num]` via `cmpxchg`, and `del_ops` calls `synchronize_net()`. [F753]
- In `ip6mr.c`, mutating `vif_table`, `mfc_hash`, `mfc_cache_list`, or `mroute_sk` requires `rtnl_lock()` (with `mrt_lock` inside it for VIFs, MFC thresholds, and `mroute_sk`). `ip6mr_sk_init`/`ip6mr_sk_done` update `mroute_sk` and `devconf_all->mc_forwarding` together under both locks, and `ip6mr_sk_done` calls `mroute_clean_tables(mrt, MRT6_FLUSH_MIFS | MRT6_FLUSH_MFC)`. `mfc_unres_lock` uses `spin_lock_bh` in non-timer paths and `spin_trylock` in `ipmr_expire_process`; `ip6mr_mfc_add` inserts into `mfc_hash`/`mfc_cache_list` before locking `mfc_unres_lock` to unlink `mfc_unres_queue` entries, calling `ip6mr_cache_resolve` after unlocking. [F756, F795, F856, F857]
- `ip6_mr_output` takes `guard(rcu)()` on entry. `ip6_mc_find_dev` and `ndisc_send_skb` require `rcu_read_lock()` and `dst_dev_rcu()`. In `do_ipv6_setsockopt`, recheck `sk->sk_family == AF_INET6` after `sockopt_lock_sock(sk)` (`IPV6_ADDRFORM` race). [F758, F852, F853]
- In `ndisc_router_discovery`, `fib6_set_expires` and `fib6_add_gc_list` require `spin_lock_bh(&rt->fib6_table->tb6_lock)`. `ndisc_alloc_skb`, `ndisc_ra_useropt`, and all `ndisc_rcv`/`ndisc_send_skb` paths must use `GFP_ATOMIC`. `mip6_destopt_output`, `mip6_rthdr_output`, and `mip6_report_rl_allow` must use `spin_lock_bh` on `x->lock` and `mip6_report_rl.lock`. [F761, F865, F866]

## Object Lifetimes
- Tombstone `ifmcaddr6` entries on `idev->mc_tomb` (`mld_add_delrec`) lack `mca_refcnt`/`mca_work` and are freed via `in6_dev_put(pmc->idev)` + `kfree_rcu` (not `ma_put`); in `mld_del_delrec`/`mld_clear_delrec`, call `in6_dev_put(pmc->idev)` only after `ip6_mc_clear_src(pmc)`. `__ipv6_dev_mc_inc` transfers its `in6_dev_get` ref to `mca_alloc` (`ma_put`) and calls `in6_dev_put(idev)` on all non-allocating paths. Pending `ma->mca_work` (`mca_refcnt`) and `inet6_dev` MLD works (`in6_dev_hold`) take a ref only when `!mod_delayed_work(...)`, drop it when `cancel_delayed_work*` returns true, and release it (`ma_put`/`in6_dev_put`) on completion without requeuing. [F719, F720, F721, F722, F773]
- Mutating or non-RCU walking `np->ipv6_mc_list` and `pmc->sflist` requires `lock_sock(sk)`. `ipv6_mc_socklist` and `ip6_sf_socklist` use `sock_kfree_s` before RCU publication, or `atomic_sub(..., &sk->sk_omem_alloc)` + `kfree_rcu` after; for `ip6_sf_socklist *psl`, uncharge `struct_size(psl, sl_addr, psl->sl_max)` (not `sl_count`). [F725, F844, F861]
- `ipv6_update_options` swaps `inet6_sk(sk)->opt` (updating `icsk_ext_hdr_len = psp_sk_overhead(sk) + opt->opt_flen + opt->opt_nflen` and calling `icsk_sync_mss` before `sk_dst_reset` on `IS_ICSK` sockets not in `TCPF_LISTEN | TCPF_CLOSE` with `inet_daddr != LOOPBACK4_IPV6`); callers (`ipv6_set_opt_hdr`, `do_ipv6_setsockopt`) must uncharge `opt->tot_len` from `sk_omem_alloc` and `txopt_put` the old `opt` (or new `opt` on error). [F727, F881]
- `ip6_ra_control` preallocates `new_ra` (`GFP_KERNEL`) before `write_lock_bh(&ip6_ra_lock)`, calls `sock_hold(sk)` on insert (`kfree(new_ra)` if `ra->sk == sk`), and calls `sock_put(sk)` + `kfree(ra)` on removal. `IPV6_ADDRFORM` calls `__ipv6_sock_mc_close`, `__ipv6_sock_ac_close`, `sock_prot_inuse_add`, zeroes `np->rxopt.all`, calls `inet6_cleanup_sock`, and `module_put(THIS_MODULE)`. [F728, F729]
- `ip6_tnl_dev_init_gen` inits `dst_cache` and `gro_cells` (`dst_cache_destroy` if `gro_cells_init` fails) and holds `dev_tracker`; `ip6_tnl_dev_uninit` unlinks `t`, resets `dst_cache`, and puts `dev_tracker`, while `ip6_dev_free` destroys `gro_cells` and `dst_cache`. [F732]
- `mif6_add` holds `dev`, calls `dev_set_allmulti(dev, 1)` (`unregister_netdevice` + `dev_put` on `MIFF_REGISTER` failure), increments `mc_forwarding`, and sets `v->dev_tracker`; `mif6_delete` reverses these, calling `unregister_netdevice_queue` on `MIFF_REGISTER` only if `!notify`. Unresolved `mfc6_cache` entries on `mfc_unres_queue` must drain skbs and decrement `cache_resolve_queue_len` (`ip6mr_destroy_unres` or `ip6mr_cache_resolve` + `ip6mr_cache_free`); resolved entries on `mfc_cache_list` use `mr_cache_put`. `ip6mr_free_table` calls `timer_shutdown_sync(&mrt->ipmr_expire_timer)` before `mroute_clean_tables` and `rhltable_destroy`. [F736, F738, F740]
- In `ndisc_recv_ns`/`ndisc_recv_na`, `addrconf_dad_failure(skb, ifp)` consumes `ifp` (return immediately, do not call `in6_ifa_put`). In `ndisc_router_discovery`, `ip6_del_rt(net, rt, false)` consumes `rt` (set `rt = NULL`), and `neigh_release(neigh)` must be called before a new `ip6_neigh_lookup`. [F742, F743]

## API Contracts
- On failure after `sock_create_kern`, `udp_sock_create6` calls `kernel_sock_shutdown(sock, SHUT_RDWR)`, `sock_release(sock)`, and `*sockp = NULL`. `udp_tunnel6_dst_lookup` never returns `NULL` (check `IS_ERR(dst)`). `udp_tunnel6_xmit_skb` requires writable headroom of `sizeof(struct ipv6hdr) + sizeof(struct udphdr)`. [F730, F766, F872]
- `ip6mr_cache_unresolved` always consumes `skb` (callers must never free it). `ndisc_send_skb` consumes `skb` and `skb_dst`; in `ndisc_send_redirect`, exits before `skb_dst_set(buff, dst)` must jump to `release:` (`dst_release(dst)`). `ndisc_alloc_skb` uses `alloc_skb(..., GFP_ATOMIC)` and `skb_set_owner_w(skb, dev_net_rcu(dev)->ipv6.ndisc_sk)` (not `sock_alloc_send_pskb`). [F739, F741, F889]
- `ip6_tnl_parse_tlv_enc_lim` returns `0` or a positive offset from `raw` and calls `pskb_may_pull` (re-read `skb->data`/`skb_network_header(skb)` afterwards). In `ip6_tnl_xmit`: `encap_limit < 0` (`-1`) omits the TLV and `>= 0` inserts it; `*pmtu` is set only on `-EMSGSIZE`; ensure `max_headroom` and clone writability via `skb_realloc_headroom` + `skb_set_owner_w(new_skb, skb->sk)`. Both `__ip6_tnl_rcv` and `ip6_tnl_xmit` call `skb_scrub_packet(skb, !net_eq(t->net, dev_net(dev)))`. `ip6_tnl_rcv_ctl` requires callers to hold `rcu_read_lock()`. [F762, F763, F854, F870, F871]
- `mip6_destopt_input`/`mip6_rthdr_input` return `nexthdr` (`>= 0`) or `-ENOENT`. `ndisc_mc_map` returns `0` or `-EINVAL`, falling back to `dev->broadcast` for unknown `dev->type` only if `dir != 0`. In `do_ipv6_mcast_group_source` (`MCAST_JOIN_SOURCE_GROUP`), ignore `-EADDRINUSE` from `ipv6_sock_mc_join_ssm` and call `ip6_mc_source`. In `ip6_mr_input` and `ndisc_send_redirect`, if `netif_is_l3_master(dev)`, resolve `dev_get_by_index_rcu(net, IPCB(skb)->iif)`. `ndisc_rcv` checks `ndisc_suppress_frag_ndisc(skb)`, calls `skb_linearize(skb)`, and zeroes `NEIGH_CB(skb)` before `ndisc_recv_ns` (`LOCALLY_ENQUEUED` marks `pndisc_redo`). [F778, F779, F780, F835, F875, F887]

## Error Handling
- `ip4ip6_err`/`ip6ip6_err` must check both `ip6_tnl_err(...) == 0` and `rel_msg != 0` before sending an inner ICMP error. In `__ip6_tnl_rcv`, `dscp_ecn_decapsulate` returns `0` (ok), `1` (log only), or `> 1` (drop); `__ip6_tnl_rcv` always consumes `skb`/`tun_dst` and returns `0`. [F764, F765]
- `ip6mr_fill_mroute` ignores `-ENOENT` from `mr_fill_mroute`. `do_ipv6_getsockopt` and `ip6_mc_msfget` must `memset` stack structs (`ip6_mtuinfo`, `in6_flowlabel_req`, `sockaddr_storage`) before copying to userspace. [F769, F772]
- `ip6_mc_add_src`/`ip6_mc_del_src` call `sf_markstate(pmc)` before updating `mca_sfcount[sfmode]` (when `delta == 0`) or calling `ip6_mc_add1_src`/`ip6_mc_del1_src`. If `ip6_mc_add1_src` fails at `i`, `ip6_mc_add_src` rolls back `mca_sfcount[sfmode]` (if `!delta`) and calls `ip6_mc_del1_src` for `0 <= j < i`. `ip6_mc_del1_src` returns `-ESRCH`, `0`, or `1` (moved to `mca_tomb`), so `ip6_mc_del_src` tracks `rv > 0` (`changerec`) separately from `rv < 0` (`err`). [F774, F775, F799]

## External Contracts
- `ipmr_mfc_seq_show` checks `it->cache != &mrt->mfc_unres_queue` before reading `mfc_un.res` or `minvif..maxvif`. `ip6mr_rtm_valid_getroute_req` rejects requests if `rtm_src_len`/`rtm_dst_len` is not `0` or `128`, `RTA_SRC`/`RTA_DST` has `0` len, or `rtm_tos`/`rtm_table`/`rtm_protocol`/`rtm_scope`/`rtm_type`/`rtm_flags` is non-zero. [F813, F814]
- `IPV6_UNICAST_IF` uses network byte order (`ntohl`/`htonl`) and requires `optlen == sizeof(int)` on `setsockopt`. `do_ipv6_setsockopt` capability checks use `sockopt_ns_capable(sock_net(sk)->user_ns, ...)`. [F817, F884]
- ND link-layer address options use `NDISC_OPT_SPACE(dev->addr_len + ndisc_addr_option_pad(dev->type))`; `__ndisc_opt_addr_data`/`ndisc_opt_addr_data` return `NULL` on length mismatch. `ndisc_send_redirect` rounds `rd_len &= ~0x7` before SKB allocation and `ndisc_fill_redirect_hdr_option`. On `ip6n->fb_tnl_dev` (`ip6tnl0`), `netns_immutable` is set, deletion is forbidden, and `ip6_tnl0_update` rejects changes other than `parms.proto` (`-EINVAL`). [F807, F840, F841, F867]

## Known Pitfalls
- `ipv6_mc_destroy_dev` calls `__ipv6_dev_mc_dec(idev, ...)` directly (not `ipv6_dev_mc_dec`, as `dev->ip6_ptr` is `NULL`). In `ip6_tnl_exit_rtnl_net`, walks over `tnls_r_l`/`tnls_wc` only call `unregister_netdevice_queue(t->dev, list)` when `!net_eq(dev_net(t->dev), net)`. [F724, F735]
- Re-fetch headers after SKB pull/cow: in `__ip6_tnl_rcv`, save `nh = skb_network_header(skb) - skb->head` before `pskb_inet_may_pull` and restore `ipv6h = (struct ipv6hdr *)(skb->head + nh)`; in `ip6mr_prepare_xmit`, re-fetch `ipv6h = ipv6_hdr(skb)` after `skb_cow`; in `__mld_query_work`, re-fetch `mlh2 = (struct mld2_query *)skb_transport_header(skb)` after the second `pskb_may_pull`. [F787, F792, F796]
- In `ip6mr_forward2`, save `indev = skb->dev` before `ip6mr_prepare_xmit` overwrites `skb->dev`. In `ip6_mr_forward`/`ip6_mr_output_finish`, defer TX on VIF `ct` via `psend = ct` and `skb_clone` for the previous `psend`, sending the original `skb` at `last_forward`. In `ip6_mroute_setsockopt`, init `parent = 0`, set `parent = -1` in `MRT6_ADD_MFC`/`MRT6_DEL_MFC` before falling through to `*_PROXY`, and set `parent = mfc.mf6cc_parent` only if `parent == 0`. In `mip6_destopt_output`/`mip6_rthdr_output`, copy `iph->saddr`/`daddr` into `hao->addr`/`rt2->addr` before overwriting with `x->coaddr`. [F791, F804, F833, F834]
- In `ndisc_parse_options`/`ndisc_next_option`/`ndisc_next_useropt`: check `opt_len >= sizeof(struct nd_opt_hdr)` and `0 < (l = nd_opt->nd_opt_len << 3) <= opt_len`; cast `nd_opt` to `(void *)` before adding `l`; index `nd_opt_array` only for `< __ND_OPT_ARRAY_MAX`; and run `ndisc_is_useropt` after `switch (nd_opt->nd_opt_type)`. In `ndisc_router_discovery`, bound `rtime / 1000 < MAX_SCHEDULE_TIMEOUT / HZ` (and `/ (3 * HZ)` for `reachable_time`) before multiplying. [F805, F806, F824, F837, F847]
- `ipv6_set_mcast_msfilter`/`compat_ipv6_set_mcast_msfilter` must reject `gf_numsrc >= 0x1ffffffU` or `> sysctl_mld_max_msf` before `GROUP_FILTER_SIZE`. `compat_ipv6_set_mcast_msfilter` allocates `optlen + 4` (`gf32` at `p + 4`), and `compat_ipv6_get_msfilter` subtracts `4` from `GROUP_FILTER_SIZE(num)`. In `add_grec`, `mld_clear_zeros`, and `mld_send_cr`, read `psf_next`/`pmc_next` before removal and advance `psf_prev`/`pmc_prev` only when retaining the node. [F815, F816, F828]
