# EDAC-CORE — (top level)

Contains the public EDAC header (`include/linux/edac.h`), core polling workqueue (`wq.c`), memory scrubber sysfs (`scrub.c`), and drivers for Intel Skylake/10nm (`skx_base.c`, `skx_common.c`), Apollo Lake/Denverton (`pnd2_edac.c`), Freescale MPC85xx (`mpc85xx_edac.c`), SiFive RISC-V (`sifive_edac.c`), and Intel X38 (`x38_edac.c`).

## Architecture & Data Flow

- In `skx_common.c`, `skx_dev->imc[]` is allocated via `struct_size(d, imc, imc_num)` (`cfg->ddr_imc_num + cfg->hbm_imc_num`) and indexed by logical IMC (`0..d->num_imc - 1`); changing `imc_num` requires `skx_remove()` and reallocation in `skx_get_all_bus_mappings()`. Physical IMC IDs from `adxl_decode()` must be converted via `skx_get_mc_mapping()`, and drivers skipping absent IMCs must call `skx_set_mc_mapping(d, pmc, lmc)` (physical `pmc` second, logical `lmc` third). [F208, F226, F254]
- Every enum constant before `INDEX_MAX` in `skx_common.h` needs a matching entry in `component_names[]` (`skx_common.c`), with mandatory ADXL components before `INDEX_NM_FIRST` and optional near-memory components at/after `INDEX_NM_FIRST`. `skx_adxl_decode()` must verify the `BIT_NM_*` bit in `adxl_nm_bitmap` before indexing `adxl_values[]` with `component_indices[INDEX_NM_*]`, and when `skx_res_cfg->type == GNR` and `err_src == ERR_SRC_2LM_FM` (set via `skx_set_res_cfg()`), switch `err_src` to `ERR_SRC_2LM_NM` if `adxl_values[component_indices[INDEX_MEMCTRL]] == -1`. [F215, F228, F265]
- In `struct skx_channel` (`skx_common.h`), `rrl_ctl[2][NUM_RRL_SET]` is indexed by sub-channel/HBM pseudo-channel first and bounded by `NUM_RRL_SET` (matching `struct reg_rrl`) second. In `skx_base.c`, `skx_close_row[]` and `skx_open_row[]` passed to `skx_bits()` in `skx_mad_decode()` must have at least `18` entries (max `dimm->rowbits` from `numrow()`). [F217, F227]
- In `skx_sad_decode()`, `prev_limit` must be reset to `0` after `restart:`, while `remote` is initialized to `0` before `restart:` and set to `1` before jumping to `restart:`. In `skx_tad_decode()`, when `res->chanways == 3` and `skt_interleave_bit > chn_interleave_bit`, `skx_do_interleave()` must de-interleave channel before socket passing `channel_addr` as `lowbits`; all other cases de-interleave socket before channel using `res->addr` as `lowbits`. [F238, F242]
- In `scrub.c`, `scrub_create_desc()` must zero-allocate `struct edac_scrub_context` with `scrub_attrs` sized to `SCRUB_MAX_ATTRS + 1` and copy local `dev_attr[]` into `scrub_ctx->scrub_dev_attr[]` before taking `.dev_attr.attr` addresses. Every `scrub_attrs[]` entry must be embedded in `struct edac_scrub_dev_attr` with a valid `instance` index for `TO_SCRUB_DEV_ATTR`, and `dev_attr[]` order and `scrub_attr_visible()` switch cases must match `enum edac_scrub_attributes`, gating read/write modes on non-NULL `ops` callbacks. [F219, F257, F258]
- In `pnd2_edac.c`, `get_registers()` on `DNV` must override `asym0.slice0_asym_channel_select`, `asym1.slice1_asym_channel_select`, `chash.sym_slice0_channel_enabled`, and `chash.sym_slice1_channel_enabled` after reading registers and before computing `two_slices`, `two_channels`, `sym_chan_mask` (`gen_sym_mask()`), and `asym_chan_mask` (`gen_asym_mask()`). `chan_mask` must be `unsigned long` (unlike `u8` `sym_chan_mask`/`asym_chan_mask`) for `for_each_set_bit(&chan_mask, ...)`. [F220, F264]
- In `pnd2_edac.h`, `struct b_cr_asym_mem_region0_mchbar`, `b_cr_asym_mem_region1_mchbar`, and `b_cr_asym_mem_region_denverton` must keep identical 32-bit layouts (bit 31 `enable`, matching `base`/`limit`) for `void *` casts in `apl_mk_region()`/`dnv_mk_region()`. In `dnv_pmi2mem()` and `dnv_get_dimm_config()`, check `dmap4[pmiidx].row14`..`row17 != 31` and (for DDR3) `dmap1[pmiidx].ca11 != 0x3f` before calling `dnv_get_bit()`. [F233, F260]
- In `pnd2_edac.c`, `sys2pmi()` must call `remove_addr_bit()` for `chan_intlv_bit_rm` on `contig_addr` before `slice_intlv_bit_rm`, and `remove_addr_bit()` must return early when `bitidx == -1` before `BIT_ULL(bitidx)`. In `get_memory_error_data()`, right-shift `pmiidx` from `sys2pmi()` by `ops->pmiidx_shift` before `ops->pmi2mem()` (`dnv_ops` sizes `dmap[]`/`drp[]` to `DNV_NUM_CHANNELS` = 2). [F230, F250]
- In `mpc85xx_pci_err_probe()` and `mpc85xx_l2_err_probe()`, `r.start` from `of_address_to_resource()` must be advanced by `0xe00` before `devm_request_mem_region()`/`devm_ioremap()` to match `+0xe00`-relative `MPC85XX_PCI_*`/`MPC85XX_L2_*` offsets. In `x38_edac.c`, `edac_mc_alloc()` uses `sz_pvt = 0` and stores the `void __iomem *` window from `x38_map_mchbar()` directly in `mci->pvt_info`. [F235, F261]

## Synchronization

- In `pnd2_edac.c`, all hardware config registers must be cached during `get_registers()` in `pnd2_probe()`; `ops->rd_reg` (`apl_rd_reg`/`dnv_rd_reg`), `RD_REG`, and `RD_REGP` must never be called from the MCE notifier path (`pnd2_mce_check_error()`, `pnd2_mce_output_error()`, `sys2pmi()`, `ops->pmi2mem()`). [F193]
- In `x38_edac.c`, `x38_get_and_clear_error_info()` must read `X38_ERRSTS` into `info->errsts` before and `info->errsts2` after reading `eccerrlog[]`, and re-read `eccerrlog[]` before clearing `X38_ERRSTS` if `X38_ERRSTS_BITS` changed; `x38_process_error_info()` must report the overwritten CE and set `info->errsts = info->errsts2`. [F224]
- `mpc85xx_pci_check()`, `mpc85xx_pcie_check()`, and `mpc85xx_l2_check()` run both on `'edac-poller'` in `EDAC_OPSTATE_POLL` mode and in hardirq handlers (`mpc85xx_pci_isr()`, `mpc85xx_l2_isr()`) in `EDAC_OPSTATE_INT` mode, so they must not sleep or take blocking locks. [F273]

## Object Lifetimes

- `edac_stop_work()` must call `cancel_delayed_work_sync(work)` then `flush_workqueue(wq)` before freeing an EDAC control struct, and `edac_workqueue_teardown()` must reset `wq = NULL` after `destroy_workqueue(wq)`. [F189]
- In `skx_base.c`, `mce_register_decode_chain(&skx_mce_dec)` and `skx_setup_debug()` must run only after `skx_get_all_bus_mappings()`, `skx_register_mci()`, and `skx_adxl_get()`, and `skx_exit()` must call `mce_unregister_decode_chain()` and `skx_teardown_debug()` before `skx_adxl_put()` and `skx_remove()`. In `skx_setup_debug()`, if `edac_debugfs_create_file()` fails, call `debugfs_remove(skx_test)` and set `skx_test = NULL`. [F178, F266]
- Both error paths in `skx_adxl_get()` and teardown in `skx_adxl_put()` must reset `adxl_component_count = 0` when freeing `adxl_values` and `adxl_msg`, as `skx_mce_check_error()` gates `skx_adxl_decode()` on `adxl_component_count`. [F172]
- If `skx_register_mci()` fails after `imc->mci = mci`, it must free `mci->ctl_name`, call `edac_mc_free(mci)`, and reset `imc->mci = NULL` before `skx_remove()`. `skx_unregister_mci()` must call `edac_mc_del_mc(mci->pdev)` before `kfree(mci->ctl_name)` and `edac_mc_free(mci)`. [F173, F174]
- In `get_all_munits()` and `skx_get_all_bus_mappings()` `pci_get_device(..., prev)` loops, any `pdev` saved in `struct skx_dev` needs `pci_dev_get(pdev)` before `prev = pdev`, and early loop exits must call `pci_dev_put(pdev)`. [F244]
- In `pnd2_edac.c`, `pnd2_init()` must finish `pnd2_probe()` before `mce_register_decode_chain(&pnd2_mce_dec)` and `setup_pnd2_debug()`, and `pnd2_exit()` must call `teardown_pnd2_debug()` and `mce_unregister_decode_chain(&pnd2_mce_dec)` before `pnd2_remove()`. When `_apl_rd_reg()` writes `0` to `P2SB_HIDE_OFF` (`hidden != 0`), all exit paths (`goto out`) must restore `P2SB_HIDE_OFF` to `hidden`; `get_mem_ctrl_hub_base_addr()` and `dnv_rd_reg()` must call `pci_dev_put(pdev)` and `iounmap(base)` before returning. [F179, F180, F181]
- In `sifive_edac.c`, `ecc_register()` must succeed in `edac_device_add_device(p->dci)` before `register_sifive_ccache_error_notifier(&p->notifier)` (freeing `p->dci` on error), and `ecc_unregister()` must call `unregister_sifive_ccache_error_notifier(&p->notifier)` before `edac_device_del_device()` and `edac_device_free_ctl_info(p->dci)`. `platform_device_unregister(sifive_pdev)` must run if `ecc_register(sifive_pdev)` fails in `sifive_edac_init()` and after `ecc_unregister(sifive_pdev)` in `sifive_edac_exit()`. [F182, F183]
- In `mpc85xx_edac.c`, `mpc85xx_pci_err_probe()` and `mpc85xx_l2_err_probe()` open a devres group (`devres_open_group()`), map `pci_vbase`/`l2_vbase` and register with EDAC before requesting IRQs/enabling interrupts, and must call `devres_remove_group()` on success or unwind (delete EDAC device, `irq_dispose_mapping()`, free ctl info, `devres_release_group()`) on error. `mpc85xx_pci_err_remove()` and `mpc85xx_l2_err_remove()` must restore `orig_pci_err_cap_dr`/`orig_pci_err_en` and `orig_l2_err_disable` (plus disabling `MPC85XX_L2_ERRINTEN` and calling `irq_dispose_mapping(pdata->irq)` in INT mode) before deleting and freeing the EDAC ctl info. [F184, F185, F199]
- In `x38_edac.c`, `x38_probe1()` must set `x38_channel_num`, `mci->pvt_info = window`, and `mci->edac_check = x38_check` before `edac_mc_add_mc(mci)`, and `x38_remove_one()` must call `edac_mc_del_mc(&pdev->dev)` before `iounmap(mci->pvt_info)` and `edac_mc_free(mci)`. [F197]

## API Contracts

- In `include/linux/edac.h`, `struct dimm_info` stores capacity in `nr_pages`, granularity in `grain` (bytes), and raw enums in `dtype`/`mtype`/`edac_mode`, while `struct mem_ctl_info` capability fields (`mtype_cap`, `edac_ctl_cap`, `edac_cap`, `scrub_cap`) store `BIT()` masks (`*_FLAG_*`). `edac_get_dimm(mci, layer0, layer1, layer2)` returns `NULL` if any active coordinate is `< 0` or index `>= mci->tot_dimms`, reading `layer1`/`layer2` only when `mci->n_layers > 1`/`2`. [F213, F284]
- `edac_scrub_get_desc()` stores a borrowed pointer to `devm_kzalloc()`-allocated `&scrub_ctx->group` in `attr_groups[0]`; callers must not `kfree(attr_groups[0])`. Work items queued via `edac_queue_work()`/`edac_mod_work()` (`edac_check` callbacks) run on the `WQ_MEM_RECLAIM` `'edac-poller'` workqueue and must not use `GFP_KERNEL` allocations or flush non-`WQ_MEM_RECLAIM` workqueues. [F188, F272]
- `skx_init()` and `pnd2_init()` must check `ghes_get_devices()` and `edac_get_owner()` (`-EBUSY`) and `cpu_feature_enabled(X86_FEATURE_HYPERVISOR)` (`-ENODEV`) before probing. `skx_mce_check_error()` and `pnd2_mce_check_error()` must return `NOTIFY_DONE` if `mce->kflags & MCE_HANDLED_CEC`, and set `mce->kflags |= MCE_HANDLED_EDAC` after reporting an error. [F289, F291]
- Functions in `skx_common.c` (`skx_edac_common` module) called by `skx_edac`/`i10nm_edac` must be `EXPORT_SYMBOL_GPL()` and never `__init`/`__exit`. `skx_get_all_bus_mappings()` returns `< 0` on error, `0` when no sockets are found, and `> 0` socket count on success (callers must treat `<= 0` as failure). `skx_get_hi_lo(did, off, tolm, tohm)` requires `off[3]` ordered as `{tolm, lower_tohm, upper_tohm}`. `skx_get_dimm_info()` and `skx_get_nvdimm_info()` must return `1` when a valid DIMM/NVDIMM is populated (`0` if NVDIMM size is `0`/`~0ull`) so `skx_get_dimm_config()` sums `ndimms` for `skx_check_ecc(mcmtr)`. [F202, F210, F287, F288]
- `GET_BITFIELD(v, lo, hi)` in `skx_common.h` and `pnd2_edac.c` takes `lo` before `hi` (`lo <= hi`, reverse of `GENMASK_ULL(hi, lo)`). In `pnd2_edac.c`, structs passed to `RD_REG()`/`RD_REGP()` must have `sizeof` 4 or 8 bytes (4 bytes when `r_opcode == 4`), and `msg` buffers passed to `get_memory_error_data()`, `sys2pmi()`, or `ops->pmi2mem()` must be at least `PND2_MSG_SIZE` (256) bytes. [F209, F259, F263]

## Error Handling

- `edac_device_alloc_ctl_info()`, `edac_pci_alloc_ctl_info()`, and `edac_mc_alloc()` return `NULL` on failure, whereas `platform_device_register_simple()` in `sifive_edac_init()` returns an `ERR_PTR` (`IS_ERR()`). [F200]
- In `skx_mce_check_error()`, zero-initialize `res` (`memset(&res, 0, sizeof(res))`), validate `res.addr` with `pfn_to_online_page(res.addr >> PAGE_SHIFT)` or `arch_is_platform_page(res.addr)` (logging `pr_err()` and returning `NOTIFY_DONE` if neither holds) before `driver_decode()`/`skx_adxl_decode()`, and check both `driver_decode` and `res.dev->imc[res.imc].mci` for `NULL`. In `skx_adxl_decode()`, check `res->imc < 0` before passing it as `u8 pmc` to `skx_get_mc_mapping()`. [F207, F252, F290]
- `_apl_rd_reg()` in `pnd2_edac.c` returns negative errno (`-EAGAIN`/`-EBUSY`) on timeout and positive `1..3` on P2SB status error bits `[2:1]`; `apl_rd_reg()` must initialize `ret = 0` before `ret |= _apl_rd_reg(...)`, and callers must check non-zero (not just `< 0`). [F212]

## External Contracts

- In `struct edac_scrub_ops` and `EDAC_SCRUB_ATTR_SHOW`, `get_min_cycle`, `get_max_cycle`, `get_cycle_duration`, and `set_cycle_duration` use seconds (`"%u\n"`), while `read_addr`, `write_addr`, `read_size`, and `write_size` use 64-bit hex (`"0x%llx\n"`). [F283]

## Known Pitfalls

- In `skx_adxl_decode()` and `skx_show_retry_rd_err_log()`, check signed `MSG_SIZE - len <= 0` or `len - n > 0` before subsequent `snprintf()` calls. After `list_for_each_entry(d, &dev_edac_list, list)` in `skx_adxl_decode()`, check `res->dev != NULL` before passing `d` to `skx_get_mc_mapping()`. [F236, F243]
- In `skx_get_dimm_info()`, use `1ull << (rows + cols + ranks)` before multiplying by `banks` (shift can reach 32). In `skx_get_dimm_config()`, read `mcmtr` (`0x87c`) from `imc->chan[0].cdev`, not `imc->chan[i].cdev`. In `get_all_munits()`, ignore `SAD` (`0x208e`) devices where config dword `0xB4` is `0`, and require non-zero reads to match `d->mcroute`. On UV systems (`is_uv_system()`), `skx_get_src_id()` must use `skx_get_pkg_id()` (checking `c->initialized && cpu_to_node(cpu) == node` before `topology_physical_package_id(cpu)`). [F249, F268, F269, F279]
- In `pnd2_edac.c` (`get_mem_ctrl_hub_base_addr`, `apl_mk_region`, `dnv_mk_region`, `get_registers`), widen `u32` bitfields via `U64_LSHIFT()` before shifting by 15..32 bits. In `mpc85xx_pci_check()`, mask out `PCI_EDE_MULTI_ERR` alongside `PCI_EDE_MST_ABRT` and `PCI_EDE_PERR_MASK` before `edac_pci_handle_npe()`. In `x38_map_mchbar()`, verify `u.mchbar == (resource_size_t)u.mchbar` before `ioremap()` to avoid 32-bit truncation. [F241, F248, F253]
