# BCACHE (BLOCK LAYER CACHE) — drivers/md/bcache (part 2)

This component implements bcache's background writeback subsystem, sysfs management interfaces, tracepoint exports, and generic data structure/formatting utilities. Writeback scans the btree for dirty keys, rate-limits I/O via a proportional-integral (PI) controller, and asynchronously reads dirty extents from the cache device and writes them to the backing device using closures and workqueues. The sysfs layer exposes runtime configuration, statistics, and lifecycle controls, while the utility layer provides generic heap, FIFO, array-allocator, rbtree, string parsing/printing, and bio mapping helpers.

## Architecture & Data Flow
- `dc->has_dirty` and superblock state `BDEV_STATE(&dc->sb)` must transition together with `bch_write_bdev_super()`: `bch_writeback_add()` sets `BDEV_STATE_DIRTY` when transitioning `dc->has_dirty` from 0 to 1, while `bch_writeback_thread()` clears `dc->has_dirty` to 0 and sets `BDEV_STATE_CLEAN` (or `BDEV_STATE_NONE` on detach) under `down_write(&dc->writeback_lock)` only when both `refill_dirty(dc)` returns `true` (`searched_full_index`) and `RB_EMPTY_ROOT(&dc->writeback_keys.keys)` is true. [F222, F245, F277]
- `dc->writeback_rate.rate`, `dc->writeback_rate_p_term_inverse`, and `dc->writeback_rate_i_term_inverse` must always be initialized and clamped to `>= 1` because `bch_next_delay()` and `__update_writeback_rate()` use them as divisors without zero checks. In `__calc_target_rate()`, `bdev_share` (from `div64_u64(bdev_nr_sectors(dc->bdev) << WRITEBACK_SHARE_SHIFT, c->cached_dev_sectors)`) must also be clamped to `>= 1` before scaling `cache_dirty_target`. [F239, F290]
- In `__cached_dev_store()`, updates to `writeback_rate_fp_term_low`, `writeback_rate_fp_term_mid`, and `writeback_rate_fp_term_high` must be clamped against adjacent tiers so `1 <= low < mid < high <= UINT_MAX` always holds; in `__update_writeback_rate()`, these `unsigned int` terms must be cast to `int64_t` before multiplying by the `in_use` threshold difference to prevent 32-bit overflow. [F258, F283]
- When `bcache_dev_sectors_dirty_add()` updates `d->stripe_sectors_dirty[stripe]`, it must update the bit in `d->full_dirty_stripes` in lockstep (setting when `sectors_dirty == d->stripe_size`, clearing otherwise), and if `UUID_FLASH_ONLY(&c->uuids[inode])` is true, add `nr_sectors` to `c->flash_dev_dirty_sectors`. [F244]
- `refill_dirty()` must reset `buf->last_scanned` to `KEY(dc->disk.id, 0, 0)` if it lies outside `[start, end]`, and on wraparound save `start_pos = buf->last_scanned` and scan from `start` only up to `&start_pos`; `refill_full_stripes()` must set `buf->last_scanned` to the stripe start key before each `bch_refill_keybuf()` call. [F252]
- In `read_dirty()`, every `break` in the inner `do-while` loop must only fire after at least one key is added to `keys[]` (`nk > 0`), because `next` is only advanced in the `while ((next = bch_keybuf_next(&dc->writeback_keys)))` tail condition. [F271]
- `struct bio bio` must remain the final field of `struct dirty_io`, and `read_dirty()` must allocate `DIV_ROUND_UP(KEY_SIZE(&w->key), PAGE_SECTORS)` trailing `struct bio_vec` elements past `sizeof(*io)` to match `max_vecs` passed to `bio_init_inline(&io->bio, NULL, ...)` in `dirty_init()`. [F336]
- `c->gc_after_writeback` combines `BCH_ENABLE_AUTO_GC` and `BCH_DO_AUTO_GC`: `update_gc_after_writeback()` must only OR in `BCH_DO_AUTO_GC` when `c->gc_after_writeback == BCH_ENABLE_AUTO_GC`, and `bch_writeback_thread()` must clear only `~BCH_DO_AUTO_GC` when waking GC so `BCH_ENABLE_AUTO_GC` stays set. [F253]
- In `idle_counter_exceeded()`, the signed 32-bit return of `atomic_inc_return(&c->idle_counter)` must be checked for overflow (`counter <= 0`), resetting `c->idle_counter` to 0 and returning `false` before comparing against `dev_nr * dev_nr * 6`. [F296]
- In `bch_cached_dev_store()`, `sysfs_writeback_running` must revert `dc->writeback_running = false` if `IS_ERR_OR_NULL(dc->writeback_thread)` (else call `bch_writeback_queue(dc)`), and `sysfs_writeback_percent` must only set `BCACHE_DEV_WB_RUNNING` and schedule `dc->writeback_rate_update` when `dc->disk.c != NULL`. [F248]
- When `sysfs_size` is updated in `__bch_flash_dev_store()`, it must update `u->sectors` in `d->c->uuids[d->id]`, persist the UUID table via `bch_uuid_write(d->c)`, and update gendisk capacity via `set_capacity(d->disk, u->sectors)`. [F247]
- In `drivers/md/bcache/sysfs.c`, string arrays `bch_cache_modes`, `bch_reada_cache_policies`, `bch_stop_on_failure_modes`, `cache_replacement_policies`, `error_actions`, and `states` in `__bch_cached_dev_show()` are indexed directly by their mode/state constants and must stay ordered in lockstep; every table passed to `bch_snprint_string_list()` and `__sysfs_match_string(..., -1, buf)` must have at least one entry and a trailing `NULL` sentinel. [F256, F261]
- In `struct time_stats`, `average_duration` and `average_frequency` are stored left-shifted by 8 bits (updated via `ewma_add(..., 8, 8)`) whereas `max_duration` and `last` are unshifted nanoseconds; readers of the averages must right-shift by 8 before unit conversion. [F293]
- 64-bit `local_clock()` timestamps (in `bch_time_stats_update()`, `bch_next_delay()`, and `__update_writeback_rate()`) must be compared using `time_after64()` or `time_before64()`, and `bch_time_stats_update()` must store `stats->last = now ?: 1` so 0 remains the uninitialized sentinel. [F295]
- `DECLARE_FIFO` ring buffers must be initialized with `_allocated_size = roundup_pow_of_two((fifo)->size + 1)` and `(fifo)->mask = _allocated_size - 1` so modular index masking (`& (fifo)->mask`) in `fifo_used()` and push/pop macros never aliases full with empty (`back == front`). [F297]
- In `DECLARE_ARRAY_ALLOCATOR(type, name, size)`, `array_free()` and `array_alloc()` store the intrusive freelist next-pointer in the first `sizeof(void *)` bytes of each free element in `array->data`, requiring `sizeof(type) >= sizeof(void *)`, forbidding reads of freed elements, and requiring an external lock for concurrent access (e.g., on `keybuf.freelist`). [F232, F300]

## Synchronization
- In `bch_writeback_thread()`, every path after `down_write(&dc->writeback_lock)` and `set_current_state(TASK_INTERRUPTIBLE)` must restore `TASK_RUNNING` (via `set_current_state(TASK_RUNNING)` or `schedule()`) and call `up_write(&dc->writeback_lock)` before sleeping, calling `read_dirty(dc)`, or breaking out of the loop. [F213]
- In `update_writeback_rate()`, `BCACHE_DEV_RATE_DW_RUNNING` must be set with `smp_mb__after_atomic()` at entry and cleared on every exit only after any `schedule_delayed_work(&dc->writeback_rate_update, ...)` (gated on `BCACHE_DEV_WB_RUNNING` and `!CACHE_SET_IO_DISABLE`). Acquiring `dc->writeback_lock` for `__update_writeback_rate(dc)` and `update_gc_after_writeback(c)` must try `down_read_trylock()` first and skip up to `BCH_WBRATE_UPDATE_MAX_SKIPS` times via `dc->rate_update_retry` (using `break`, never `return`, from the `do-while(0)` block) before blocking in `down_read()`. [F223, F276, F323, F325]
- Functions locking `c->root` directly with `rw_lock()`, such as `bch_root_usage()` and `bch_sectors_dirty_init()`, must recheck `b == c->root` after acquiring `rw_lock()` (unlocking and retrying if `c->root` changed concurrently) and must call `rw_unlock(0, b)` on the locked `b` before returning. [F218]
- Sysfs show/store handlers for `cached_dev`, `flash_dev` (store), `cache_set`, and `cache` must hold `bch_register_lock` (via `SHOW_LOCKED`, `STORE_LOCKED`, or explicit `mutex_lock(&bch_register_lock)`), and store handlers must return `-EBUSY` when `bcache_is_reboot` is true. [F230]
- In `sysfs.c`, iterating `c->btree_cache` in `bch_cache_size()`, scanning `c->bucket_hash` in `bch_cache_max_chain()`, reading bucket marks/priorities in `__bch_cache_show()`, and updating `CACHE_REPLACEMENT(&ca->sb)` in `__bch_cache_store()` must hold `mutex_lock(&c->bucket_lock)` (nested inside `bch_register_lock`). [F231]
- Bio `bi_end_io` callbacks `dirty_endio()` and `read_dirty_endio()` run in atomic completion context and must only record I/O errors, clear `KEY_DIRTY(&w->key)` on error, and call `closure_put(&io->cl)`, deferring blocking work (`bio_free_pages()`, `bch_btree_insert()`, `up(&dc->in_flight)`) to `write_dirty_finish()` on `dc->writeback_write_wq`. [F329]
- `bch_time_stats_update()` takes `spin_lock(&stats->lock)` without disabling IRQs, so it must only be called from process context and never from hardirq or softirq (`bi_end_io`) context. [F330]

## Object Lifetimes
- In `bch_cached_dev_writeback_start()`, `dc->writeback_write_wq` must be allocated, `cached_dev_get(dc)` acquired, and `BCACHE_DEV_WB_RUNNING` set before scheduling `dc->writeback_rate_update` or waking `dc->writeback_thread` via `bch_writeback_queue()`. If `kthread_create()` fails, it must roll back `cached_dev_put(dc)` and `destroy_workqueue(dc->writeback_write_wq)`; once `kthread_create()` succeeds, ownership of both transfers to `bch_writeback_thread()`, which must release both before `wait_for_kthread_stop()`. [F206, F219, F313]
- In `read_dirty()`, once `down(&dc->in_flight)` and `closure_call(&io->cl, read_dirty_submit, NULL, &cl)` run, the closure chain must always reach `write_dirty_finish()` and `dirty_io_destructor()` (even on read error) to call `bio_free_pages(&io->bio)`, `bch_keybuf_del(&dc->writeback_keys, w)`, `up(&dc->in_flight)`, and `kfree(io)`. In `write_dirty_finish()`, before `bch_btree_insert()` clears the dirty bit, every pointer bucket in `w->key` must have `PTR_BUCKET(dc->disk.c, &w->key, i)->pin` incremented, and `read_dirty()` must call `closure_sync(&cl)` before returning. [F207, F224, F251]
- `bch_sectors_dirty_init()` must bound `state.total_threads` via `bch_btre_dirty_init_thread_nr()` to `[1, BCH_DIRTY_INIT_THRD_MAX]`, increment `state.started` before each `kthread_run(bch_dirty_init_thread, ...)`, decrement `state.started` and stop already-started threads with a signed loop (`--i; i >= 0; i--`) if `kthread_run()` fails, and wait for `atomic_read(&state.started) == 0` on `state.wait` before calling `rw_unlock(0, b)` and returning. [F212, F268]
- `bch_cache_set_internal_release()` must remain a no-op because `c->internal` is a secondary `kobject` embedded in `struct cache_set`, whose memory and `THIS_MODULE` reference are released by `bch_cache_set_release()` when `c->kobj` is put. [F318]

## API Contracts
- `should_writeback()` must return `false` for `REQ_OP_DISCARD` bios, when `cache_mode != CACHE_MODE_WRITEBACK`, when `BCACHE_DEV_DETACHING` is set, or when `dc->disk.c->gc_stats.in_use > bch_cutoff_writeback_sync`; after those checks, `dc->partial_stripes_expensive && bcache_dev_stripe_dirty(...)` must precede both `if (would_skip) return false;` and `in_use <= bch_cutoff_writeback`. [F274, F343]
- `bch_bio_map()` requires `bio->bi_iter.bi_size > 0` and `bio->bi_vcnt == 0` on entry, and when `base == NULL` it must only set `bv_offset`, `bv_len`, and `bi_vcnt` without overwriting `bv_page` (preserving pages across `dirty_init()`). `bch_bio_alloc_pages()` requires `bio->bi_vcnt` to be populated beforehand (e.g., via `bch_bio_map(bio, NULL)`) and frees all pages it allocated on failure, so callers must not call `bio_free_pages()` when it returns `-ENOMEM`. [F209, F334]
- In `read_dirty()`, the initial `writeback_delay(dc, size)` call charges the batch's `size` sectors to `dc->writeback_rate.next`, so subsequent loop iterations after `schedule_timeout_interruptible()` must pass `0` sectors (`writeback_delay(dc, 0)`) to avoid double-counting. [F243]
- `offset_to_stripe()` must divide the 64-bit sector offset by `d->stripe_size` using `do_div()` and reject quotients `>= d->nr_stripes` with `-EINVAL` before narrowing to `int`; callers must check for `< 0`, and multi-stripe loops like `bcache_dev_sectors_dirty_add()` must stop when `stripe >= d->nr_stripes` before indexing `d->stripe_sectors_dirty` or `d->full_dirty_stripes`. [F265, F292]
- `bch_cache_set_internal_show()` and `bch_cache_set_internal_store()` must resolve `struct cache_set *c` via `container_of(kobj, struct cache_set, internal)` and pass `&c->kobj` (not `kobj`) to `bch_cache_set_show()` and `bch_cache_set_store()`. [F279]
- `bch_parse_uuid()` returns the number of input characters scanned rather than `0`/`-errno`, so callers must check that the return value is `< 16` to detect truncated or invalid UUID strings. [F238]
- `bch_hprint()` and `sysfs_hprint()` unconditionally divide input `v` by 1024 at least once (starting at unit `k`) and write up to 8 bytes (plus newline in `sysfs_hprint()`), so callers must pass byte counts (shifting sector counts by `<< 9`, after casting 32-bit sector counts like `dc->disk.stripe_size` and `bch_get_congested(c)` to `uint64_t`) and provide a buffer of at least 8 bytes. [F240, F282]
- `strtoi_h(cp, res)` (and wrappers `strtoi_h_or_return()` and `sysfs_hatoi()`) only supports destination variables of type `int`, `long`, `long long`, `unsigned int`, `unsigned long`, or `unsigned long long`, returning `-EINVAL` for narrower types like `uint16_t`, `uint8_t`, or `bool`. [F302]
- Callers of `fract_exp_two(x, fract_bits)` must bound `x` and `fract_bits` such that `(x >> fract_bits) + fract_bits < 32` (e.g., `x < CONGESTED_MAX = 1024` with `fract_bits = 6`) so `mantissa << x` does not overflow 32 bits or shift by `>= 32`. [F287]
- `init_heap()` and `__init_fifo()` (called by `init_fifo()` and `init_fifo_exact()`) mask their `gfp` argument with `(gfp) & GFP_KERNEL` when calling `kvmalloc()`, so they must only be called from sleepable process context. [F333]

## Error Handling
- `dirty_endio()` signals read or write bio failure by clearing `KEY_DIRTY(&w->key)`. When skipping a failed read in `write_dirty()`, it must still advance `dc->writeback_sequence_next` (truncating `io->sequence + 1` to `uint16_t` before `atomic_set(&dc->writeback_sequence_next, next_sequence)` so it wraps modulo 65536 with `uint16_t dirty_io.sequence`) and wake `dc->writeback_ordering_wait`; `write_dirty_finish()` must only insert the clean replacement key into the btree if `KEY_DIRTY(&w->key)` is still set. [F250, F294]

## External Contracts
- In `STRTO_H()`, `bch_strto*_h()` requires at least one digit before any unit suffix (`if (e++ == cp) return -EINVAL`), rejects trailing characters after an optional `'\n'`, and checks each `* 1024` step against `~0 / 1024` (unsigned) or `ANYSINT_MAX(type) / 1024` (signed) before multiplying to return `-EINVAL` on overflow. [F340]
- Updating `sysfs_label` in `__cached_dev_store()` requires `size <= SB_LABEL_SIZE`, strips a trailing newline in `dc->sb.label`, copies the label to `dc->disk.c->uuids[dc->disk.id].label` when attached, and emits a `KOBJ_CHANGE` uevent on `disk_to_dev(dc->disk.disk)->kobj` with `DRIVER=bcache`, `CACHED_UUID`, and `CACHED_LABEL`. [F341]

## Known Pitfalls
- In `__bch_cache_show()` for `sysfs_priority_stats`, `cached` is advanced past `BTREE_PRIO` entries while `p` retains the `vmalloc()` base address, so cleanup must always call `vfree(p)` (never `vfree(cached)`) and release `ca->set->bucket_lock` before sorting and freeing. [F216]
- In `sysfs.c`, dynamic statistics counts used as divisors (`c->gc_stats.nodes` in `bch_btree_used()`, `c->gc_stats.nkeys` in `bch_average_key_size()`, and filtered bucket count `n` in `__bch_cache_show()`) must be guarded against 0 before calling `div64_u64()`. [F288]
- Because `fifo_for_each(c, fifo, iter)` evaluates `c = (fifo)->data[iter]` before checking `iter != (fifo)->back`, it must only be used when `(fifo)->data` is non-NULL, and `c` must not be read after the loop terminates. [F278]
- In `util.h`, `heap_sift_down(h, i, cmp)` mutates its index argument `i` in-place as it walks toward index 0 (which `heap_add()` relies on when calling `heap_sift(h, _i, cmp)` afterward), so callers must pass a modifiable lvalue whose original value is no longer needed. [F281]
