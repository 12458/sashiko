# NETWORKING [GENERAL] — net (part 3)

Kernel Connection Multiplexor sockets (`net/kcm/`), L2TPv2/v3 core, IP/IPv6 sockets, Ethernet pseudowires, and Netlink control (`net/l2tp/`), L3 Master Device / VRF hooks (`net/l3mdev/`), and MPLS routing, GSO, and IP tunnels (`net/mpls/`).

## Architecture & Data Flow
- In `kcmsock.c`, unreserved `kcm_psock` is on `mux->psocks_avail` iff `!psock->tx_stopped` (`kcm_abort_tx_psock` unlinks when `!tx_kcm`; `unreserve_psock` skips `psock_now_avail` when `tx_stopped`; `kcm_unattach` unlinks only when `!tx_stopped`). Under `mux->rx_lock`, `psock->ready_rx_msg` and `mux->psocks_ready` update together: `reserve_rx_kcm` sets `ready_rx_msg`, pauses `strp`, and links `psock_ready_list`; `kcm_rcv_ready` (which calls `strp_unpause`) and `kcm_unattach` unlink and clear `ready_rx_msg = NULL`. [F637, F639]
- In `kcm_sendmsg()`, incomplete messages (`!eor`) set `kcm->seq_skb = head` and `kcm_tx_msg(head)->last_skb = skb`, clearing `seq_skb = NULL` when queued onto `sk_write_queue`; on `SOCK_SEQPACKET` error with `copied == 0`, free `head` only if `head != kcm->seq_skb`. In `kcm_write_msgs()`, if a reserved `kcm_psock` aborts (`tx_stopped` or non-`-EAGAIN` error), reset `kcm_tx_msg(head)->started_tx = false` to restart from `frag_offset = 0`, `sent = 0`. [F640, F641]
- `kcm_write_msgs` casts `skb_shinfo(skb)->frags` to `const struct bio_vec *`, so `sk_write_queue` SKBs must keep all payload in page-backed `frags` (`nr_frags > 0`, `skb_frag_page(&frags[0]) != NULL`) with zero linear data. `kcm_recvmsg` and `kcm_splice_read` must bound reads to `stm->full_len` at `stm->offset` (`strp_msg(skb)`), updating `stm->offset += copied` and `stm->full_len -= copied` on partial `SOCK_SEQPACKET` reads. [F671, F672]
- `init_kcm_sock` and `kcm_attach` keep `mux->kcm_socks` and `mux->psocks` sorted by ascending 0-based `index`, assigning the lowest unused `index`. `struct kcm_proc_mux_state` must keep `struct seq_net_private p` first (`/proc/net/kcm` uses `seq_file_net` and `seq->private`; `/proc/net/kcm_stats` sets `seq->private` to `struct net *`). [F670, F704]
- `struct l2tp_ip_sock` and `struct l2tp_ip6_sock` keep `struct inet_sock inet` first, and `l2tp_ip6_prot.ipv6_pinfo_offset = offsetof(struct l2tp_ip6_sock, inet6)`. Under `l2tp_ip_lock`/`l2tp_ip6_lock`, `l2tp_ip_bind`/`l2tp_ip6_bind` link `sk_bind_node`, `sk_del_node_init(sk)`, and clear `SOCK_ZAPPED`; `l2tp_ip_close`/`l2tp_ip6_close` unlink both `sk_bind_node` and `sk_node`. [F647, F701]
- Changing `session->send_seq`, `cookie_len`, or `l2specific_type` requires `l2tp_session_set_header_len` so `session->hdr_len` matches `l2tp_build_l2tpv2_header`/`v3_header`. Sequence numbers `nr`/`ns` use `session->nr_max` (`0xffff` v2, `0xffffff` v3) and `nr_window_size = nr_max / 2`, wrapping via `& session->nr_max` and checking distance against `nr_max + 1` in `l2tp_seq_check_rx_window`. [F664, F665]
- In `l2tp_recv_common`, when `!L2TP_SKB_CB(skb)->has_seq` and `!session->recv_seq`, the LAC check (`!session->lns_mode && session->send_seq`) disabling `send_seq` must precede `else if (session->send_seq)`. `L2TP_SKB_CB(skb)` is at `&skb->cb[sizeof(struct inet_skb_parm)]` to preserve `IPCB(skb)`, and `sizeof(struct inet_skb_parm) + sizeof(struct l2tp_skb_cb) <= sizeof(skb->cb)`. [F676, F705]
- In `l2tp_tunnel_get_next` and `l2tp_v2/v3_session_get_next`, every `goto again` and continuing caller must increment `(*key)++` before `idr_get_next_ul`. Skip `session_id == 0` (dummy `pppol2tp`) in `l2tp_v2_session_get_next` and `l2tp_dfs_seq_tunnel_show`. Keep `tunnel->name` (`L2TP_TUNNEL_NAME_MAX`=20) and `session->name` (`L2TP_SESSION_NAME_MAX`=32) NUL-terminated for tracepoint `memcpy`. [F667, F673, F706]
- In `l3mdev.c`, dereference `dev->l3mdev_ops` callbacks only after verifying `netif_is_l3_master(dev)` (or resolving via `netdev_master_upper_dev_get_rcu` if `netif_is_l3_slave(dev)`) and non-NULL callback pointer. In `l3mdev_update_flow`, if `fl->flowi_oif` is an L3 master, reset `fl->flowi_oif = 0` after setting `fl->flowi_l3mdev`. [F630, F731]
- `mpls_dev_table` and `mpls_table` store struct offsets (`MPLS_PERDEV_SYSCTL_OFFSET`, `MPLS_NS_SYSCTL_OFFSET`) in `.data`; `mpls_dev_sysctl_register` and `mpls_net_init` must `kmemdup` the template and add the instance base pointer to each `table[i].data`. In `resize_platform_label_table`, `platform_labels` is element count `limit`, so byte sizes for `platform_label` must scale `limit`/`old_limit` by `sizeof(struct mpls_route *)`. [F651, F698]
- Access `rt->rt_nh` (stride `rt->rt_nh_size`) and via addresses (offset `rt->rt_via_offset`) only via `for_nexthops`/`change_nexthops`/`mpls_get_nexthop` and `mpls_nh_via`. `nla_get_via` and `mpls_nh_assign_dev` require `nla_len(nla) >= offsetof(struct rtvia, rtvia_addr)` and `alen <= MAX_VIA_ALEN`, with `alen` matching `4` (`AF_INET`), `16` (`AF_INET6`), or `dev->addr_len` (`AF_PACKET`). [F656, F659]
- Validate user MPLS labels with `mpls_label_ok` (`MPLS_LABEL_FIRST_UNRESERVED <= *index < net->mpls.platform_labels`, clamped via `array_index_nospec`). `mpls_multipath_hash` bounds walk to `MAX_MP_SELECT_LABELS` (4) and must `break` after hashing an unreserved label following `MPLS_LABEL_ENTROPY` (`eli_seen`) or at `dec.bos`. Attributes added to `mpls_dump_route` or `mpls_netconf_fill_devconf` must be added to `lfib_nlmsg_size` or `mpls_netconf_msgsize_devconf`. [F657, F685, F738]

## Synchronization
- `kcm_attach` must verify `csk` is `AF_INET`/`AF_INET6` `IPPROTO_TCP` not in `TCP_LISTEN`/`TCP_CLOSE` and check `!csk->sk_user_data` under `csk->sk_callback_lock`. `kcm_unattach_ioctl` must check/set `psock->unattaching = 1` under `spin_lock_bh(&mux->lock)` before `kcm_unattach`. If `kcm_unattach` sees `psock->tx_kcm` under `mux->lock`, drop `mux->lock` for `kcm_abort_tx_psock`, re-lock, recheck `tx_kcm`, and if still set, mark `psock->done = 1` with `smp_mb()` and queue `tx_kcm->tx_work`. [F603, F606, F703]
- Updates to `kcm->rx_wait` and `kcm->rx_psock` under `mux->rx_lock` require `WRITE_ONCE()`, and clearing `kcm->rx_psock` in `unreserve_rx_kcm()` requires `smp_mb()` before reading `sk_rmem_alloc_get(&kcm->sk)` to pair with `smp_mb__after_atomic()` and `READ_ONCE()` in `kcm_rfree()`. [F605]
- `kcm_sendmsg()` acquires `kcm->tx_mutex` outside `lock_sock(sk)` (held across `sk_stream_wait_memory()`), while `kcm_tx_work()` and `kcm_splice_eof()` take only `lock_sock(sk)` and `mux->lock`. `kcm_release()` must unlink `kcm` from `mux->kcm_tx_waiters` (`kcm->tx_wait = false`) under `spin_lock_bh(&mux->lock)` before `disable_work_sync(&kcm->tx_work)` and before unreserving `kcm->tx_psock` under `lock_sock(sk)`. [F721, F722]
- In `l2tp_session_register` and `l2tp_session_unhash`, lock order is `spin_lock_bh(&tunnel->list_lock)` -> `spin_lock_bh(&pn->l2tp_session_idr_lock)` -> `clist->lock`, using `GFP_ATOMIC`. Because IDR slots start `NULL` and colliding sessions hash before `WRITE_ONCE(session->tunnel, tunnel)`, RCU-BH lookups (`l2tp_v3_session_get`, `l2tp_tunnel_get`) must check IDR entries and `READ_ONCE(session->tunnel)` for `NULL` and use `refcount_inc_not_zero()`. [F723, F724]
- `l2tp_xmit_core()` holds `spin_lock_nested(&sk->sk_lock.slock, L2TP_DEPTH_NESTING)` across `l2tp_xmit_queue()`, dropping if `sock_owned_by_user(sk)` or `tunnel->fd >= 0 && sk->sk_state != TCP_ESTABLISHED`. In `l2tp_recv_dequeue`, after dropping `reorder_q.lock` for `l2tp_recv_dequeue_skb`, `goto start` to restart `skb_queue_walk_safe`. `l2tp_nl_cmd_session_create()` must drop `genl_unlock()` around `request_module()` and recheck `l2tp_nl_cmd_ops[cfg.pw_type]` after `genl_lock()`. [F675, F725, F729]
- `l3mdev_ifindex_lookup_by_table_id()` calls `hdlr->dev_lookup` under `spin_lock(&l3mdev_lock)`, so callbacks must not sleep or re-lock `l3mdev_lock`. [F717]
- `mpls_route_input_rcu()` and `mpls_dev_get()` must use `rcu_dereference_rtnl()` for `platform_label`, `platform_label[index]`, and `dev->mpls_ptr`. `mpls_forward()` runs in softirq RCU context (`GFP_ATOMIC` only). `mpls_platform_labels()` must parse into a local via stack `struct ctl_table tmp` so `net->mpls.platform_labels` updates under `rtnl_lock()` in `resize_platform_label_table()`. [F652, F712, F713]
- Live `rt->rt_nhn_alive` and `nh->nh_flags` use `WRITE_ONCE()` under `rtnl_lock()` (`mpls_ifdown`/`mpls_ifup`) and `READ_ONCE()` under RCU (`mpls_select_multipath`). On `NETDEV_UNREGISTER` for a multipath route with other nexthops, `mpls_ifdown()` must `kmemdup()` the route, clear `nh->nh_dev = NULL` on the clone, and call `mpls_route_update()`. Use `MPLS_INC_STATS` / `MPLS_INC_STATS_LEN` for `struct mpls_pcpu_stats`. [F615, F616, F694]

## Object Lifetimes
- `kcm_attach` takes `sock_hold(csock->sk)` and owns `prog` only on success; `kcm_attach_ioctl` keeps `csock`'s file ref on success and calls `bpf_prog_put(prog)` and `sockfd_put(csock)` on error. In `kcm_unattach`, clear `sk_user_data`, restore `csk` callbacks, call `strp_stop`, and free/clear `ready_rx_msg` under `csk->sk_callback_lock`, then unlock `csk` before `strp_done(&psock->strp)`. In `kcm_done`, if `kcm->rx_psock` is set under `mux->rx_lock`, set `rx_disabled = 1` and `done = 1` so `unreserve_rx_kcm` queues `kcm->done_work` to requeue `sk_receive_queue`, release `mux`, and `sock_put(&kcm->sk)`. [F581, F583, F585]
- `l2tp_tunnel_register` reserves `tunnel_id` with `NULL` in `l2tp_tunnel_idr`, takes `sock_hold(sk)`, calls `sockfd_put(sock)` when `tunnel->fd >= 0`, and on error cleans up socket/IDR without freeing `tunnel`. `l2tp_tunnel_delete` increments `ref_count` when setting `tunnel->dead` bit 0 and queuing `del_work`; `l2tp_tunnel_del_work` calls `sock_release` only when `tunnel->fd < 0` and calls `l2tp_tunnel_put` twice. `l2tp_pre_exit_net` must call `__flush_workqueue(l2tp_wq)` twice so both tunnel and session delete works finish before `l2tp_exit_net`. [F588, F589, F590]
- `l2tp_session_register` increments `tunnel->ref_count` and sets `session->tunnel` only after `tunnel->acpt_newsess` and IDR insertion succeed under `list_lock` and `l2tp_session_idr_lock`. `l2tp_session_collision_del` replaces `session` in `l2tp_v3_session_idr` with `clist->list` head (or `idr_remove` if empty), clears `session->coll_list`, drops `clist->ref_count`, and calls `l2tp_session_put(session)`. [F591, F592]
- `l2tp_eth_create` holds an extra `session->ref_count` and `rtnl_lock` across `l2tp_session_register`, `register_netdevice`, and `rcu_assign_pointer(spriv->dev, dev)`; because `needs_free_netdev = true`, call `free_netdev(dev)` only on `l2tp_eth_create` failure before `register_netdevice` succeeds (with `l2tp_session_delete` and `l2tp_session_put` if `register_netdevice` fails). `l2tp_eth_dev_uninit` clears `spriv->dev` via `RCU_INIT_POINTER`. [F593, F708, F710]
- `l2tp_dfs_seq_open` tracks `pd->net` via `get_net_ns_by_pid(current->pid)` and `netns_tracker_alloc`, releasing via `put_net_track` on error and in `l2tp_dfs_seq_release`. `l2tp_dfs_seq_stop` must put non-NULL `pd->session` and `pd->tunnel` and reset both to `NULL`. [F595, F748]
- `find_outdev` drops the lookup's `dev_hold` via `dev_put(dev)` before returning `dev` under `rtnl_lock` (`nh->nh_dev` is unreferenced). On `NETDEV_UNREGISTER` in `mpls_dev_notify`, `mpls_ifdown`, `mpls_dev_sysctl_unregister`, and `RCU_INIT_POINTER(dev->mpls_ptr, NULL)` precede `call_rcu(&mdev->rcu, mpls_dev_destroy_rcu)`. `mpls_dev_sysctl_register` sets `mdev->sysctl = NULL` on error; `mpls_dev_sysctl_unregister` frees `ctl_table_arg` after `unregister_net_sysctl_table`. `resize_platform_label_table` sets `rt0`/`rt2` to `NULL` on transfer, frees unconsumed `rt0`/`rt2` via `mpls_rt_free` after `rtnl_unlock`, and calls `synchronize_rcu()` before `kvfree(old)`. [F596, F597, F598, F711]

## API Contracts
- `init_kcm_sock` sets `kcm->sk.sk_state = TCP_ESTABLISHED`, and `.splice_read = kcm_splice_read` is only on `kcm_seqpacket_ops`. `kcm_splice_read()` must translate `SPLICE_F_NONBLOCK` / `O_NONBLOCK` into `MSG_DONTWAIT` (or `0`) before `skb_recv_datagram()` and `skb_splice_bits()` (`SPLICE_F_NONBLOCK` aliases `MSG_PEEK`). [F618, F750]
- `l2tp_tunnel_create()` returns `0`/errno and sets `*tunnelp`, while `l2tp_session_create()` returns `ERR_PTR(-ENOMEM)` on failure (never `NULL`). `l2tp_validate_socket` checks `SOCK_DGRAM`, family, protocol, and (for UDP) `!sk->sk_user_data`, and `l2tp_sk_to_tunnel` uses `l2tp_tunnel_idr` (never `sk->sk_user_data`). `l2tp_ip_connect()` and `l2tp_ip6_connect()` reject `SOCK_ZAPPED` sockets with `-EINVAL`. [F622, F628, F702]
- Callers of `l2tp_session_get_next()` must reset `*key = 0` per tunnel. Before `l2tp_recv_common` on L2TPv3, callers must call `l2tp_v3_ensure_opt_in_linear(session, skb, &ptr, &optr)` to pull options and rebase `ptr`/`optr`. Before `dev_forward_skb` in `l2tp_eth_dev_recv`, check `pskb_may_pull(skb, ETH_HLEN)` and call `secpath_reset`, `skb->ip_summed = CHECKSUM_NONE`, `skb_clear_hash`, `skb_dst_drop`, and `nf_reset_ct`. [F626, F663, F744]
- `l3mdev_handlers` accessors must validate `l3type` with `l3mdev_check_type`. `l3mdev_ifindex_lookup_by_table_id()` returns `-EINVAL` on error, whereas `l3mdev_master_ifindex_rcu()`, `l3mdev_master_upper_ifindex_by_index_rcu()`, `l3mdev_fib_table_rcu()`, and `l3mdev_fib_table_by_index()` return `0`. `l3mdev_link_scope_lookup()` requires `rcu_read_lock()` across the call and use of the unreferenced returned `dst_entry *`. [F629, F669, F716]
- `mpls_xmit()` returns `LWTUNNEL_XMIT_DONE` once `skb` is passed to `neigh_xmit()`, or calls `kfree_skb(skb)` and returns `-EINVAL` on `drop:`. `mpls_forward` must call `skb_share_check`, `pskb_may_pull`, `skb_warn_if_lro`, `skb_forward_csum`, and `skb_cow(skb, hh_len + new_header_size)`. `nla_get_labels` requires `len % 4 == 0`, `len / 4 <= max_labels` (`<= 255`), and when `label != NULL` decodes in reverse requiring `dec.bos` only on the last entry, `ttl == 0`, `tc == 0`, and `label != MPLS_LABEL_IMPLNULL`; `mpls_build_state` calls `nla_get_labels` with `label = NULL` first to size `struct_size(tun_encap_info, label, n_labels)`. [F632, F658, F697, F735]

## Error Handling
- In `kcm_sendmsg()`, if `kcm_write_msgs()` fails after `head` is queued onto `sk_write_queue`, call `report_csk_error(&kcm->sk, -err)` and return `copied`. In `l2tp_tunnel_sock_create()`, on bind/connect failure, call `kernel_sock_shutdown(sock, SHUT_RDWR)` and `sock_release(sock)` and set `*sockp = NULL`. `mpls_rt_alloc()` and `find_outdev()` return `ERR_PTR` (never `NULL`); callers must check `IS_ERR` and never pass an `ERR_PTR` to `mpls_rt_free(rt)` or `nh->nh_dev`. [F619, F623, F634, F635]

## External Contracts
- In `kcm_ioctl` (`SIOCKCMCLONE`), call `fd_install(info.fd, file)` only after `kcm_clone(sock)` and `copy_to_user` succeed; on `copy_to_user` failure, call `put_unused_fd` and `fput`. L2TPv3 IP/IPv6 frames start with 4-byte big-endian `session_id` (`0` = control frame with 4-byte zero prefix stripped on rx and prepended on tx). `l2tp_ip/ip6_getname` and `recvmsg` must zero unused `sockaddr` fields/padding. In `l2tp_nl_tunnel_send_addr4`/`addr6`, `case L2TP_ENCAPTYPE_UDP:` must `fallthrough;` to `L2TP_ENCAPTYPE_IP`. All `l2tp_nl_ops` except `L2TP_CMD_NOOP` require `GENL_UNS_ADMIN_PERM`, and `l2tp_tunnel/session_notify` map `-ESRCH` to `0`. [F666, F679, F746, F747, F751]

## Known Pitfalls
- `requeue_rx_msgs()` must set `skb->destructor = sock_rfree` before `skb_orphan(skb)` so `kcm_rfree()` does not re-lock `mux->rx_lock`. `release_mux` must use `list_for_each_entry_safe` over `mux->psocks` for `kcm_unattach(psock)`. [F638, F682]
- In `l2tp_session_register`, call `idr_replace` on `l2tp_v3_session_idr` only when `!other_session`. Cast `u16 tunnel_id` to `u32` before `<< 16` in `l2tp_v2_session_key`. Use `time_after(jiffies, cb->expires)` in `l2tp_recv_dequeue`. In `l2tp_ip6_sendmsg`, reject `len > INT_MAX - transhdrlen` before `int ulen = len + transhdrlen`. [F677, F686, F688, F689]
- In `mpls_egress()`, only decrement non-zero IPv4 `hdr4->ttl` / IPv6 `hdr6->hop_limit`, and call `csum_replace2(&hdr4->check, htons(hdr4->ttl << 8), htons(new_ttl << 8))` before setting `hdr4->ttl = new_ttl`. `mpls_gso_segment()` must save `skb->mac_header`, `skb->mac_len`, and `skb->protocol` before stripping `mpls_hlen` for `skb_gso_error_unwind()` and segment restoration. [F654, F655]
