# NETWORKING DRIVERS — include

This unit provides the core kernel headers, UAPI definitions, and Device Tree bindings for Linux network devices (`include/linux/netdevice.h`), link-layer protocols (Ethernet, 802.1Q VLAN, MACVLAN, HSR, PPPoX, TUN/TAP, FDDI, Fibre Channel, ARP), IPv4 device configuration, and ethtool/netdev netlink interfaces.

## Architecture & Data Flow
- `NETIF_F_HW_CSUM` must not be set simultaneously with `NETIF_F_IP_CSUM` or `NETIF_F_IPV6_CSUM`; `can_checksum_protocol()` must test `protocol == htons(ETH_P_FCOE)` against `NETIF_F_FCOE_CRC` before `NETIF_F_HW_CSUM`; and multi-tagged VLAN packets must use `vlan_features_check()`, which strips all checksum offloads except `NETIF_F_HW_CSUM` [F1140, F1222].
- Adding a `NETIF_F_*_BIT` in `include/linux/netdev_features.h` requires updating `netdev_features_strings[]` in `net/ethtool/common.c`; GSO bits between `NETIF_F_GSO_SHIFT` and `NETIF_F_GSO_LAST` must match `SKB_GSO_*` bit order for `net_gso_ok()` (which normalizes `SKB_GSO_TCP_FIXEDID*` to `__SKB_GSO_TCP_FIXEDID` and checks `(features & feature) == feature`); and `NETIF_F_ETHTOOL_BITS` must use `(__NETIF_F_BIT(NETDEV_FEATURE_COUNT - 1) | (__NETIF_F_BIT(NETDEV_FEATURE_COUNT - 1) - 1))` to avoid shift overflow [F1120, F1142, F1149].
- Adding a constant to `enum netdev_cmd` in `include/linux/netdevice.h` requires updating `netdev_cmd_to_name()` in `net/core/dev.c` (and `rtnetlink_event()` if applicable) in lockstep [F1121].
- `struct net_device::priv` is `__counted_by(priv_len)`, so `dev->priv_len` must be set before calling `netdev_priv(dev)`; `vlan_dev_priv()` and `macvlan_dev_real_dev()` / `macvlan_accel_priv()` unconditionally cast `netdev_priv(dev)` and require callers with arbitrary devices to check `is_vlan_dev(dev)` or `netif_is_macvlan(dev)` first; and `dev->ml_priv` must only be accessed via `netdev_get_ml_priv(dev, type)` (with a `NULL` check) and `netdev_set_ml_priv()` [F1088, F1090, F1162].
- `__vlan_hwaccel_put_tag()` must populate both `skb->vlan_proto` and `skb->vlan_tci`, and `__vlan_hwaccel_push_inside()` must clear `skb->vlan_all` via `__vlan_hwaccel_clear_tag()` after inserting the tag into the payload [F1103].
- Because `is_multicast_ether_addr()` and `is_multicast_ether_addr_64bits()` return `true` for broadcast (`FF:FF:FF:FF:FF:FF`), `eth_skb_pkt_type()` must test `ether_addr_equal_64bits(eth->h_dest, dev->broadcast)` inside the multicast branch before classifying as `PACKET_MULTICAST` [F1143].
- `XPS_MAP_SIZE(_num)` scales by `sizeof(u16)` for `xps_map::queues[]`, whereas `XPS_CPU_DEV_MAPS_SIZE(_tcs)` and `XPS_RXQ_DEV_MAPS_SIZE(_tcs, _rxqs)` scale by `sizeof(struct xps_map *)` for `xps_dev_maps::attr_map[]` and save `nr_ids` and `num_tc` to bound indexing [F1163].
- `struct sock sk` must remain first in `struct pppox_sock` (for `pppox_sk()` / `sk_pppox()`), `sizeof(struct sockaddr_pppox)` in UAPI must remain fixed, and `struct netdev_notifier_info info` must remain first in all `netdev_notifier_*_info` extension structs [F1166, F1225].
- `GRO_HASH_BUCKETS` must not exceed `sizeof(unsigned long) * 8` (`gro_node::bitmask` width), `__ETHTOOL_LINK_MODE_MASK_NWORDS` must use `DIV_ROUND_UP(__ETHTOOL_LINK_MODE_MASK_NBITS, 32)`, and `dev->rx_cpu_rmap` must only be assigned if `dev->netdev_ops->ndo_rx_flow_steer` is defined [F1134, F1156, F1181].

## Synchronization
- `net_device::lock` (`netdev_lock()`) nests inside `rtnl_lock`; `dev->lock` protects `gro_flush_timeout`, `napi_defer_hard_irqs`, `napi_list`, `reg_state`, `threaded`, and `napi_struct` fields from `thread` through `config` (`gro_flush_timeout`, `irq_suspend_timeout`, `defer_hard_irqs`, `napi_id`, `dev_list`, `napi_hash_node`, `irq`, `notify`, `napi_rmap_idx`, `index`, `config`), while writing `dev->up`, `moving_ns`, `nd_net`, or `xdp_features` requires holding both `rtnl_lock` and `dev->lock` [F1057, F1060].
- `napi_struct::poll_list` must only be modified by the context atomically changing `NAPI_STATE_SCHED` in `napi->state`: added only by the setter of `NAPI_STATE_SCHED`, and removed right before clearing `NAPI_STATE_SCHED` by the clearer [F1056].
- `HARD_TX_LOCK(dev, txq, cpu)` and successful `HARD_TX_TRYLOCK(dev, txq)` must be paired on all paths with `HARD_TX_UNLOCK(dev, txq)` (never raw `__netif_tx_unlock()`); `__netif_tx_lock*()` / `__netif_tx_trylock()` must set `txq->xmit_lock_owner = cpu` via `WRITE_ONCE()` inside `txq->_xmit_lock` and `__netif_tx_unlock*()` must reset it to `-1` before unlocking; and `txq->_xmit_lock` nests inside `dev->tx_global_lock` with BH disabled (as in `netif_tx_disable()`) [F1053, F1064, F1065].
- `netif_tx_stop_queue()` must `WRITE_ONCE(dev_queue->trans_start, jiffies)` and issue `smp_mb__before_atomic()` before setting `__QUEUE_STATE_DRV_XOFF` (pairing with `dev_watchdog()`); in BQL, `netdev_tx_sent_queue()` must set `__QUEUE_STATE_STACK_XOFF` and issue `smp_mb__after_atomic()` before rechecking `dql_avail() >= 0`, pairing with `smp_mb()` after `dql_completed()` in `netdev_tx_completed_queue()` [F1062, F1063].
- Hardware address list updates must use `netif_addr_lock*()` (which uses `dev->nested_level` for `spin_lock_nested(&dev->addr_list_lock, ...)`), while lockless `for_each_dev_addr(dev, ha)` requires `rcu_read_lock()` [F1066].
- Per-CPU stats (`pcpu_sw_netstats`, `pcpu_dstats`, `pcpu_lstats`, `vlan_pcpu_stats`) must initialize `syncp` via `u64_stats_init()` on every possible CPU at allocation and update `u64_stats_t` inside `u64_stats_update_begin()` / `u64_stats_update_end()` with preemption/BH disabled (`dev_sw_netstats_*()`, `dev_lstats_add()`, and `dev_dstats_*()` use `this_cpu_ptr()` and require non-preemptible callers, while `macvlan_count_rx()` uses `get_cpu_ptr()`/`put_cpu_ptr()`) [F1071, F1195].
- `in_dev_for_each_ifa_rcu()` requires `rcu_read_lock()`, `in_dev_for_each_ifa_rtnl()` requires `rtnl_lock`, `in_dev_for_each_ifa_rtnl_net()` requires per-netns RTNL lock, and `vlan_{get,drop}_rx_{ctag,stag}_filter_info()` require `rtnl_lock` (`ASSERT_RTNL()`) [F1074, F1076].
- `____dev_forward_skb()` and `dev_hold()` run in atomic/RCU contexts and must pass `GFP_ATOMIC` to `skb_orphan_frags()` and `netdev_hold()`; TX recursion/batching state (`struct netdev_xmit`) must be accessed via `dev_recursion_level()`, `netdev_xmit_set_more()`, and `netdev_xmit_more()` (for `CONFIG_PREEMPT_RT` per-task state); and `vlan_dev_get_egress_qos_mask()` requires `smp_rmb()` before reading `egress_priority_map` [F1188, F1196, F1203].

## Object Lifetimes
- `in_dev_get(dev)` increments `in_dev->refcnt` and requires `in_dev_put()`, whereas `__in_dev_get_rcu()`, `__in_dev_get_rtnl()`, and `__in_dev_get_rtnl_net()` return borrowed pointers; `ip_dev_find(net, addr)` returns a refcounted `net_device *` requiring `dev_put()`, unlike `__ip_dev_find(net, addr, false)` [F1042, F1043].
- `netdev_tracker_alloc()` upgrades an existing untracked reference without calling `__dev_hold()`, whereas `netdev_hold()` increments both refcount and tracker; `netdev_ref_replace()` holds `@ndev` before putting `@odev` to handle `odev == ndev` safely [F1050].
- `netif_napi_add*()` must initialize `napi_struct` before any other NAPI call (and when `dev->irq_affinity_auto` is set, `netif_napi_add_config()` must precede `netif_napi_set_irq()`); unlike `netif_napi_del*()`, `__netif_napi_del()` and `__netif_napi_del_locked()` do not call `synchronize_net()`, so callers must wait for an RCU grace period before freeing `@napi` [F1045, F1046].
- `SET_NETDEV_DEVLINK_PORT(dev, port)` must only be called before registration while `dev->reg_state == NETREG_UNINITIALIZED`, and `dev->devlink_port` must remain static while registered [F1047].
- Releasing NAPI GRO fragments (`napi_free_frags()`) must clear `napi->skb = NULL` after `kfree_skb(napi->skb)`, and `macvlan_release_l2fw_offload()` must clear `macvlan->accel_priv = NULL` before `dev_uc_add()` [F1049].
- `vlan_insert_inner_tag()`, `vlan_insert_tag()`, `vlan_insert_tag_set_proto()`, and `__vlan_hwaccel_push_inside()` may reallocate `skb->head` via `skb_cow_head()` and on failure free `skb` via `dev_kfree_skb_any()` and return `NULL`, whereas `__vlan_insert_inner_tag()` and `__vlan_insert_tag()` return `-ENOMEM` without freeing `skb` [F1220].

## API Contracts
- In `ndo_start_xmit` (which must be non-NULL on every `net_device_ops`) and `__dev_direct_xmit()`, return codes `rc < NET_XMIT_MASK` (`dev_xmit_complete(rc)` is true, including `NETDEV_TX_OK`, negative errnos, and `NET_XMIT_*`) mean `@skb` was consumed, whereas `rc >= NET_XMIT_MASK` (e.g. `NETDEV_TX_BUSY`) leaves `@skb` unconsumed [F1039, F1207].
- `kfree_skb()` and `consume_skb()` must not be called in hardirq context or with IRQs disabled (`in_hardirq() || irqs_disabled()`); use `dev_{kfree,consume}_skb_{irq,any}()` instead [F1052].
- `napi_complete_done(napi, work_done)` must only be called when `work_done < budget`, and drivers must not rearm interrupts when it returns `false`; `napi_synchronize()` only waits for `NAPI_STATE_SCHED` to clear without preventing new `napi_schedule()` calls (use `napi_disable*()` or stop IRQs/timers first); and callers must externally serialize concurrent `netif_carrier_on()` and `netif_carrier_off()` calls on the same device [F1059, F1067, F1087].
- For BQL, `@bytes` passed to `netdev_tx_completed_queue()` / `netdev_completed_queue()` must match the exact sum passed to `*netdev*_sent_queue()` and run at most once per completion round; when `__netdev_tx_sent_queue()` or `__netdev_sent_queue()` returns `true` while `xmit_more` is set, the driver must ring the TX doorbell; and `netdev_tx_reset_queue()` / `netdev_tx_reset_subqueue()` must both clear `__QUEUE_STATE_STACK_XOFF` and call `dql_reset()` [F1097, F1116, F1182].
- Primary MAC mutations must use `dev_addr_mod()` / `dev_addr_set()` / `eth_hw_addr_set()` rather than writing `dev->dev_addr` directly (keeping `dev_addr_shadow` and `dev_addrs` synchronized); `eth_hw_addr_random()` sets `NET_ADDR_RANDOM` and `eth_hw_addr_inherit()` copies `addr_assign_type`, whereas `eth_hw_addr_set()` and `eth_hw_addr_gen()` leave `addr_assign_type` unchanged; and MAC arithmetic (`eth_addr_dec/inc/add`, `eth_hw_addr_gen`) must use `ether_addr_to_u64()` and `u64_to_ether_addr()` [F1101, F1102, F1152].
- `ether_addr_equal()`, `ether_addr_copy()`, `is_{link_local,zero,broadcast,valid}_ether_addr()`, and `compare_vlan_header()` require `u16`-aligned pointers (use `ether_addr_equal_unaligned()` if unaligned); `ether_addr_equal_64bits()`, `is_multicast_ether_addr_64bits()`, and `is_etherdev_addr()` require `u16` alignment plus 2 bytes of readable trailing padding; and `compare_ether_header()` requires headers offset by 2 bytes from a 4-byte boundary on platforms without `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` [F1123, F1124, F1204].
- `*vlan_insert*tag*()` and `__vlan_hwaccel_put_tag()` take `@vlan_proto` as `__be16` (`htons(ETH_P_8021Q)`) and `@vlan_tci` in host byte order (`u16`) [F1100].
- Non-RCU adjacency helpers (`netdev_lower_get_next*`) take an iterator starting at `dev->adj_list.lower.next`, whereas RCU helpers (`netdev_next_lower_dev_rcu`, `netdev_lower_get_next_private_rcu`, `netdev_upper_get_next_dev_rcu`) start at `&dev->adj_list.{lower,upper}`; `for_each_netdev_dump()` requires pre-initializing the `unsigned long ifindex` cursor and not incrementing it manually before breaking out [F1136, F1137].
- `ndo_fix_features` must be pure (no hardware/driver state mutations), whereas `ndo_set_features` applies changes and must return `> 0` or `-errno` if it modifies `dev->features` directly; `ndo_change_carrier` must only be implemented by virtual/software devices; and drivers must either implement `ndo_get_stats64` (populating caller-zeroed storage) or update `dev->stats` atomically (`DEV_STATS_INC`/`DEV_STATS_ADD`) [F1179, F1212, F1213].
- `dev_validate_header(dev, ll_header, len)` requires `ll_header` to be at least `dev->hard_header_len` bytes; `netdev_get_tx_queue()` requires clamping active queue indices via `netdev_cap_txqueue()`; `netif_oper_up()` treats both `IF_OPER_UP` and `IF_OPER_UNKNOWN` as operational; `txq->trans_start` comparisons must use `time_after()` / `time_before()`; `IN_DEV_*` combined macros (`IN_DEV_ANDCONF`, `IN_DEV_ORCONF`, `IN_DEV_MAXCONF`, `IN_DEV_RX_REDIRECTS`) must be used instead of raw `in_dev->cnf.data`; `netif_attrmask_next*()` must guard `cpu_max_bits_warn()` with `if (n != -1)`; and `netif_msg_init()` must check `debug_value < 0 || debug_value >= 32` and `debug_value == 0` before `1U << debug_value` [F1092, F1113, F1129, F1145, F1147, F1153, F1157].

## Error Handling
- `ndo_uninit` is not called if `ndo_init` fails, so `ndo_init` must clean up all its allocations before returning an error [F1044].
- Callers of `dev_queue_xmit()` must use `net_xmit_eval()` or `net_xmit_errno()` so `NET_XMIT_CN` is not treated as a packet drop [F1079].
- `ndo_xdp_xmit` must free un-transmitted frames via `xdp_return_frame()` when returning a non-negative count `< n`, and must not free any frames when returning a negative errno (the caller frees all `@n` frames) [F1081].
- In `ndo_bpf` (`XDP_SETUP_PROG` / `XDP_SETUP_PROG_HW`), drivers must not call `bpf_prog_put(bpf->prog)` on error, and on success must call `bpf_prog_put()` on any old replaced program [F1082].
- `__vlan_get_tag()` and `vlan_get_tag()` do not write `*vlan_tci` on `-ENODATA`, and `__vlan_get_protocol*()` / `vlan_get_protocol_and_depth()` return `0` without initializing `*depth` on invalid/deep (`>= VLAN_MAX_DEPTH`) headers, so callers must check return values before reading outputs [F1084, F1085].
- `tap_get_socket()`, `tap_get_ptr_ring()`, `tun_get_socket()`, and `tun_get_tx_ring()` return `ERR_PTR(-errno)` on failure (never `NULL`), requiring `IS_ERR()` checks; conversely, `*in_dev_get*()` can return `NULL` and must be checked before passing to `IN_DEV_*` macros [F1086, F1091].

## External Contracts
- Legacy `__be16` `TUNNEL_*` flags in `include/uapi/linux/if_tunnel.h` have exhausted all 16 bits; new IP tunnel flags must be added only to the `IP_TUNNEL_*_BIT` enum [F1133].

## Known Pitfalls
- `NETIF_F_*_BIT` are bit indices (`0..NETDEV_FEATURE_COUNT-1`) while `NETIF_F_*` are shifted `netdev_features_t` masks; similarly, `NAPI_STATE_*` and `__QUEUE_STATE_*` are bit indices for `test_bit()`/`set_bit()`, whereas `NAPIF_STATE_*` and `QUEUE_STATE_*` are shifted masks for `&` and `|` [F1095, F1096].
- `enum netdev_priv_flags` bits 30–31 must use `BIT_ULL()`, and because `net_device::priv_flags` is 32 bits wide, new private flags must be added as 1-bit bitfields on `struct net_device` rather than extending `enum netdev_priv_flags` [F1151].
- In `__vlan_insert_inner_tag()`, `veth` must be computed after `skb_cow_head()` and `skb_push()`, `skb->mac_header` must be decremented by `VLAN_HLEN` if `skb_mac_header_was_set(skb)`, `memmove()` must be used instead of `memcpy()` only when `mac_len > ETH_TLEN`, and `veth->h_vlan_proto` written only when `mac_len >= ETH_TLEN`; in `vlan_remove_tag()`, `vhdr->h_vlan_TCI` must be read before `memmove(skb->data + VLAN_HLEN, skb->data, 2 * ETH_ALEN)`; and in `skb_vlan_tagged_multi()`, `pskb_may_pull(skb, VLAN_ETH_HLEN)` must succeed before calling `skb_vlan_eth_hdr(skb)` [F1109, F1110, F1118, F1119, F1160].
- `for_each_netdev_feature(mask_addr, bit)` requires `bit` to be a signed `int` (`bit >= 0` termination); `netdev_for_each_synced_{uc,mc}_addr()` and `for_each_netdev_in_bond_rcu()` end with an unbraced `if`, so an `if-else` loop body must be braced [F1138, F1139].
- Reading `dev->up` under `netdev_lock(dev)` without `rtnl_lock` can observe false negatives during concurrent `.ndo_open`/`.ndo_close` on devices not using ops locking; before registration `dev->name` may contain unexpanded `%d`, so helpers must use `netdev_name(dev)`; and in `include/linux/inetdevice.h`, `inet_make_mask()` must guard `1U << (32 - logmask)` with `if (logmask)` and `inet_mask_len()` must guard `ffz(~hmask)` with `if (!hmask)` [F1061, F1154, F1169].
