# NETWORKING [GENERAL] — include/net (part 2)

Core networking headers for network namespaces, Netlink, Qdiscs, neighbour resolution, netdev locking/queues/netmem, PSP offload, and MANA/GDMA hardware.

## Architecture & Data Flow
- `qdisc_dequeue_internal()` must decrement `sch->qstats.backlog` via `qdisc_qstats_backlog_dec()` alongside `sch->q.qlen`, and `Qdisc_ops::change` handlers trimming packets must use it (not `&sch->q` alone). For `TCQ_F_CPUSTATS` (`qdisc_is_percpu_stats()`), `qdisc->q.qlen` is unused; check emptiness via `qdisc_is_empty()` and length via `qdisc_qlen_sum()`. [F246, F288]
- Qdisc private data in `skb->cb` must sit inside `qdisc_skb_cb::data` (`<= QDISC_CB_PRIV_LEN` = 20 bytes) and be checked with `qdisc_cb_private_validate()`. `tcf_block` software execution is tracked via `tp->usesw` (with `tp->counted` under `tp->lock`) and aggregated into `block->useswcnt`. [F249, F279]
- Updating `red_parms::max_P` must recompute `max_P_reciprocal`, calling `red_set_parms()` requires resetting `red_vars` via `red_set_vars()`, and `red_set_parms()` / `red_adaptative_algo()` must clamp `p->qth_delta` and `max_p_delta` to `>= 1` before dividing or calling `reciprocal_value()`. [F252, F294]
- `reqsk_queue_removed()` decrements `queue->young` only if `req->num_timeout == 0`; transitioning `req->num_timeout` from 0 to non-zero on a queued `request_sock` must decrement `queue->young`. [F190]
- Non-zero `neigh_table::entry_size` must be `>= offsetof(struct neighbour, primary_key) + tbl->key_len` and wrapped in `NEIGH_ENTRY_SIZE()`. `neigh_confirm()` and `neigh_event_send_probe()` must compare `confirmed`/`used` with `now` using `!=` before writing. [F303, F313]
- `__netmem_clear_lsb(netmem)` only allows accessing shared offset-checked fields (`_flags`, `pp_magic`, `pp`, `dma_addr`, `pp_ref_count`); `net_iov`-only fields (`owner`, `type`) require `netmem_to_net_iov()`. `struct strp_msg strp` must stay the first member of `struct _strp_msg` for `strp_msg(skb)`. `psp_is_allowed_nondata()` must test 1-byte pure FIN via `end_seq - seq == 1`. [F276, F302, F315]
- In `struct mana_cq`, check `cq->type` (`MANA_CQ_TYPE_RX` vs `MANA_CQ_TYPE_TX`) before dereferencing `rxq` or `txq`. For `GDMA_SQ`/`GDMA_RQ`, `gdma_queue` `head`/`tail` are in 32-byte `GDMA_WQE_BU_SIZE` units, whereas `gdma_doorbell_entry` requires `tail_ptr` in bytes (`head * GDMA_WQE_BU_SIZE`) and `rq.wqe_cnt = 0`. [F234, F326]
- MANA/GDMA `/* HW DATA */` structs lack `__packed` and require natural alignment with explicit padding. `MANA_STATS_RX_COUNT` / `MANA_STATS_TX_COUNT` must match `u64` field counts in `mana_stats_rx` / `mana_stats_tx`. Set `num_rx_buf`, `num_indir_entries`, and `num_reqs` before indexing `__counted_by()` arrays `rx_oobs[]`, `indir_tab[]`, and `reqs[]`. [F270, F271, F272]

## Synchronization
- `netdev_lock_ops*()` and `netdev_unlock_ops*()` branch on `netdev_need_ops_lock(dev)` (`request_ops_lock`, `queue_mgmt_ops`, `net_shaper_ops`); those fields must not change between lock and unlock, ops-locked paths must hold `dev->lock` when `netdev_need_ops_lock(dev)` is true (else `rtnl_lock`, per `netdev_ops_assert_locked()`), and calling code that unconditionally requires `dev->lock` from an ops-locked section requires `netdev_lock_ops_to_full()` / `netdev_unlock_full_to_ops()`. [F195, F205, F334]
- Locking multiple `net_device` instances via `netdev_lock()` requires holding `rtnl_lock`. RCU pointers serialized by `dev->lock` must use `netdev_lock_dereference(p, dev)` when holding `dev->lock` outside RCU, not `rtnl_dereference()`. [F333, F335]
- Call `netif_txq_try_stop()` / `netif_txq_maybe_stop()` only in `ndo_start_xmit` (which must still check for a full ring at entry). Update ring indexes before calling them or `__netif_txq_completed_wake()`, and pass a re-evaluated expression (not a cached variable) as `@get_desc`. [F208, F322]
- On `!TCQ_F_NOLOCK` Qdiscs, modify `__QDISC_STATE2_RUNNING` only under the root lock via `qdisc_run_begin()` / `qdisc_run_end()`. On `TCQ_F_NOLOCK` Qdiscs, `qdisc_run_end()` must issue `smp_mb()` after `spin_unlock(&qdisc->seqlock)` before testing `__QDISC_STATE_MISSED`, pairing with `qdisc_run_begin()`. [F210, F211]
- `sch_tree_lock(q)` requires `rtnl_lock` in process context for non-`TCQ_F_MQROOT` Qdiscs. Classifiers with `TCF_PROTO_OPS_DOIT_UNLOCKED` must implement `delete_empty()` and serialize `tcf_proto` state with `tp->lock` (`tcf_proto_dereference()`). [F345, F347]
- Lockless reads of `neighbour::ha` and `hh_cache` require seqlock retry loops on `n->ha_lock` (`neigh_ha_snapshot()`) and `hh->hh_lock` (`neigh_hh_output()`). `strp_pause()` requires holding `strp->sk`'s lock; `__SNMP_*` stats macros require BHs disabled. [F215, F221, F350]
- `pernet_operations` (`init`, `pre_exit`, `exit`, `exit_batch`) run without exclusive locks (only `exit_rtnl` holds `rtnl_lock`). Acquiring a `struct net` reference during RCU traversal (`for_each_net_rcu`) must use `maybe_get_net()`, never `get_net()`. [F217, F338]
- GDMA doorbell `writeq()` requires a prior `wmb()`, and reading `gdma_cqe`/`gdma_eqe` payload requires `rmb()` after checking `owner_bits`. `mana_rdma_remove()` must set `gd->rdma_teardown = true` and flush `gc->service_wq` before removing `gd->adev` and deregistering `gd`. [F327, F328]

## Object Lifetimes
- `__netns_tracker_alloc()` and `__netns_tracker_free()` must pass matching `refcounted` flags, and `put_net_track()` must free the tracker before `put_net()`. Register netdev pernet ops with `register_pernet_device()` and protocol/subsystem ops with `register_pernet_subsys()`. Never cache `struct net_generic *` or mutate `net->gen->ptr[id]` while `struct net` is alive. [F185, F186, F187]
- Replacing `neigh->parms` in `neigh_table::constructor` requires `__neigh_parms_put(neigh->parms)` and `neigh_parms_clone()`. In `Qdisc::enqueue()`, packets dropped under the root lock must be queued onto `*to_free` via `qdisc_drop*()` / `__qdisc_drop()`, never `kfree_skb()`. [F193, F201]
- After binding `gdma_mem_info.dma_region_handle` to an EQ or MANA WQ/CQ (`mana_create_wq_obj`), reset `dma_region_handle = GDMA_INVALID_DMA_REGION`. Pair every successful `mana_cfg_vport()` with `mana_uncfg_vport()`, and release non-NULL `mana_get_primary_netdev()` returns with `netdev_put(ndev, tracker)`. [F323, F324, F329]

## API Contracts
- `skb_steal_sock()` callers must drop the returned socket reference iff `*refcounted` is true; on a syncookie `TCP_NEW_SYN_RECV` socket (`inet_reqsk(sk)->syncookie`), it returns `req->rsk_listener` with `*refcounted = false`, clears `req->rsk_listener = NULL`, and leaves `skb->sk` attached. Call `inet_reqsk(sk)` only when `sk->sk_state == TCP_NEW_SYN_RECV`. [F188, F259, F306]
- `___neigh_lookup_noref()`, `__neigh_lookup_noref()`, and `ip_neigh_gw6()` return RCU-protected non-refcounted pointers (do not `neigh_release()`), whereas `neigh_lookup()`, `neigh_create()`, `__neigh_lookup()`, `__neigh_lookup_errno()`, and `__ipv6_neigh_lookup()` return refcounted pointers requiring `neigh_release()`. [F191, F192]
- `neigh_hh_output()` and `neigh_output()` always consume `skb`, and `hh_cache` callers must provide `HH_DATA_MOD` (or `HH_DATA_ALIGN(hh->hh_len)`) headroom. Initialize `*notify` before `neigh_update_is_router()`. Use `NEIGH_VAR_INIT()` in `ndo_neigh_setup` and `NEIGH_VAR_SET()` / `neigh_var_set()` for runtime per-device updates. [F194, F239, F250, F373]
- In `ndisc_ops`, `fill_addr_option` must write the exact length returned by `opt_addr_space`, and `neigh`/`ha_buf`/`ha` are `NULL` unless `icmp6_type == NDISC_REDIRECT`. Always NULL-check `ndisc_opt_addr_data()` / `__ndisc_opt_addr_data()`. [F258, F273, F274]
- Release the old Qdisc returned by `qdisc_replace()` and `dev_graft_qdisc()` with `qdisc_put()`. After `child->ops->peek()`, dequeue with `qdisc_dequeue_peeked()` instead of `child->dequeue()`. Pass `__u64` for both `bytes` and `packets` to `_bstats_update()`, and validate RED params with `red_check_params()` before `red_set_parms()`. [F200, F247, F292, F296]
- `nlmsg_unicast()` and `nlmsg_multicast*()` always consume `skb`. `nla_put_msecs()` takes jiffies and `nla_get_msecs*()` returns jiffies. Never set `cb->seq = 0` when using `nl_dump_check_consistent()`. [F202, F244, F253]
- Size `nla_policy` and `tb[]` arrays to `maxtype + 1` (index 0 holds `strict_start_type`). Under strict validation, `.type = NLA_UNSPEC` is rejected (use `NLA_POLICY_MIN_LEN()`), and `NLA_NESTED*` `.len` must be `ARRAY_SIZE(nested_policy) - 1` (`NLA_POLICY_NESTED()`). [F262, F287, F309]
- `netdev_stat_ops` structs are pre-filled with `0xff` (only assign collected fields; device-level stats require initialization in `get_base_stats`), while `netdev_stat_queue_sum()` callers must pre-initialize `rx_sum`/`tx_sum`. `ndo_queue_mem_alloc`/`free` may run while `!netif_running(dev)`. [F236, F237, F318, F320]
- `__netmem_to_page()`, `__netmem_to_nmdesc()`, `__netmem_get_pp()`, and `__netmem_address()` require page-backed `netmem_ref` (not `NET_IOV`). Unsupported `net_shaper_ops::group` must be `NULL` and `leaves` must use `NET_SHAPER_SCOPE_QUEUE`. Use `rtnl_newlink_link_net()` / `peer_net()` in `rtnl_link_ops::newlink`. [F230, F358, F360]
- `psp_sk_get_assoc_rcu()` requires `sk_is_inet(sk)` and `sk_state != TCP_NEW_SYN_RECV` (using `inet_twsk(sk)->psp_assoc` for `TCP_TIME_WAIT`). Pass explicit `sk` (not `skb->sk`) to `psp_reply_set_decrypted(sk, skb)` after `skb_set_owner_edemux()`. `psp_dev_create()` requires non-zero `versions`, all five `psp_dev_ops` callbacks, and persistent `psd_ops`/`psd_caps` pointers. [F232, F233, F330]
- Zero-initialize GDMA requests before `mana_gd_init_req_hdr()`. Do not combine `REGULATORY_WIPHY_SELF_MANAGED` with `REGULATORY_CUSTOM_REG`, `REGULATORY_STRICT_REG`, or `REGULATORY_COUNTRY_IE_*`. [F240, F332]

## Error Handling
- If `scm_send()` / `__scm_send()` returns 0, the caller must call `scm_destroy(&scm)`; on `< 0`, `__scm_send()` already destroyed it. `Qdisc_ops::destroy` runs even if `Qdisc_ops::init` fails, so `init` error paths must NULL out freed pointers in `qdisc_priv(sch)`. [F198, F199]
- Check `IS_ERR()` for `qdisc_alloc()`, `neigh_create()`, `__neigh_create()`, `__neigh_lookup_errno()`, `ip_neigh_gw6()`, `copy_net_ns()`, `get_net_ns()`, `get_net_ns_by_fd()`/`pid()`, `rtnl_link_ops::alloc`, `rtnl_create_link()`, `rtnl_get_net_ns_capable()`, and `rtnl_link_get_net()`; check `NULL` for `qdisc_create_dflt()`, `neigh_lookup()`, `__neigh_lookup()`, `maybe_get_net()`, `get_net_ns_by_id()`, and `*queue_get_dma_dev()`. [F224, F225, F226, F227]
- `netif_txq_maybe_stop()` and `__netif_txq_completed_wake()` return `0` (changed), `1` (enabled), or `-1` (race/unchanged). Store `nla_strscpy()`'s return in a signed `ssize_t` to catch `-E2BIG`. [F228, F229]

## External Contracts
- `nshhdr::ver_flags_ttl_len` encodes length in 4-byte words (`nsh_hdr_len()` / `nsh_set_flags_ttl_len()`), requiring 24 bytes for `NSH_M_TYPE1` and a 4-byte multiple `>= 8` for `NSH_M_TYPE2`. `psched_ratecfg_getrate()` clamps 32-bit `tc_ratespec::rate` to `~0U`, so 64-bit Qdisc rates need a separate 64-bit attribute. [F278, F280]
- `gdma_list_devices_resp.devs` may contain zero holes (`GDMA_DRV_CAP_FLAG_1_DEV_LIST_HOLES_SUP`); scan up to `GDMA_DEV_LIST_SIZE` while counting `resp.num_of_devs` non-zero entries. Read `NLA_UINT`/`NLA_SINT` with `nla_get_uint()`/`sint()` (not `u64`/`s64`), and build nested attributes for `nla_parse_nested()` with `nla_nest_start()` (not `_noflag()`). [F282, F301, F365]

## Known Pitfalls
- Never attach `skb_shinfo(skb)->frags` to an `nlmsg_new_large()` skb. `NLA_POLICY_RANGE()`/`MIN()`/`MAX()` bounds are `s16`; wider ranges need `NLA_POLICY_FULL_RANGE*()`, and policy introspection must check `NLA_VALIDATE_FUNCTION`/`MASK` before `nla_get_range_*()`. [F203, F263, F281]
- Verify `nlh->nlmsg_len >= nlmsg_msg_size(hdrlen)` before `nlmsg_data()`/`nlmsg_attrdata()` when not using `__nlmsg_parse()`. Keep `rem` as signed `int` in `nla_for_each_*()` / `nlmsg_for_each_msg()`, and mask types with `nla_type(nla)`. [F265, F266, F286]
- `NLA_STRING` is not NUL-terminated (use `NLA_NUL_STRING` or `nla_strscpy()`/`nla_strdup()`/`nla_strcmp()`). Use `nla_put_64bit()` / `nla_total_size_64bit()` and `nla_get_u64()`/`s64()`/`be64()` for 64-bit attributes due to 4-byte `nlattr` alignment. [F267, F310, F312]
- Never pass `NEIGH_VAR_QUEUE_LEN`..`NEIGH_VAR_GC_THRESH3` to `NEIGH_VAR*()` (`data[]` size is `NEIGH_VAR_DATA_MAX`). Clear `skb->prev = NULL` before passing a non-GSO-list `skb` to `qdisc_drop_all()`. [F275, F284]
- Use `red_maxp(Plog)` (guards `Plog < 32`), cast `us_idle` to `u64` in `red_calc_qavg_from_idle_time()`, and widen `len`/`pkt_num` to `u64` in `psched_l2t_ns()`/`psched_pkt2t_ns()` (using `DIV_ROUND_UP(len, 48) * 53` for ATM). [F293, F295, F297]
