# CAN NETWORK DRIVERS — drivers/net/can (part 1)

Core CAN network device framework (`drivers/net/can/dev/*`) and memory-mapped CAN controller drivers (`at91_can`, Bosch `c_can`/`d_can`, `cc770`, NXP `flexcan`, Aeroflex Gaisler `grcan`, and `ifi_canfd`).

## Architecture & Data Flow
- `alloc_candev_mqs()` places `can_ml_priv` and `echo_skb` after `sizeof_priv` in `netdev_priv(dev)`, so `candev` drivers must embed `struct can_priv` at offset 0 and pass `sizeof(*priv)`; `safe_candev_priv()` must verify both `dev->type == ARPHRD_CAN` and `dev->rtnl_link_ops == &can_link_ops`. [F71, F109, F112]
- `alloc_can*_skb()` must reserve `sizeof(struct can_skb_priv)` headroom via `init_can_skb_reserve()` before `skb_put_zero()` because `can_skb_prv(skb)` casts `skb->head`; mutating `can_skb_prv(skb)` or `skb->data` on a shared SKB requires `skb_copy()`, not `skb_clone()`. [F113, F171]
- RX paths must clamp 4-bit Classical CAN DLCs via `can_cc_dlc2len()` (and FD via `can_fd_dlc2len()`); error handlers (`c_can_handle_bus_err`, `ifi_canfd_handle_lec_err`, `at91_irq_err_frame`) must update `tx_errors` (ACK/bit), `rx_errors` (stuff/form/CRC/overload), and `IFI_CANFD_ERROR_CTR` even if `alloc_can_err_skb()` fails. [F51, F70]
- In `dev/netlink.c`, `can_get_size()` (`can_data_bittiming_get_size()`, `can_tdc_get_size()`, `can_ctrlmode_ext_get_size()`) must match `can_fill_info()`, using `sizeof(*ptr) * cnt` for pointer-backed constant arrays (`termination_const`, `bitrate_const`, `data_bitrate_const`); disabling `CAN_CTRLMODE_FD` in `can_ctrlmode_changelink()`/`can_dbt_changelink()` must zero `fd.data_bittiming`/`fd.tdc`, clear `CAN_CTRLMODE_FD_TDC_MASK`, and call `can_set_default_mtu(dev)`, and `can_tdc_changelink()` failure must clear `tdc_mask` from `priv->ctrlmode`. [F43, F65, F114, F177]
- Sub-32-bit hardware timestamps passed to `can_rx_offload_irq_offload_timestamp()`/`queue_timestamp()` must be left-shifted to fill `u32` (e.g., `<< 16` in `flexcan`, `at91_can`) so `(int)(cb_b->timestamp - cb_a->timestamp)` in `can_rx_offload_compare()` wraps cleanly. [F100]
- `flexcan_rx_offload_setup()` must recompute `mb_size`, `mb_count`, `tx_mb_reserved`, `tx_mb_idx`, `tx_mb`, `tx_mask`, and `rx_mask` on every `flexcan_open()`, and mailboxes must only be accessed via `flexcan_get_mb(priv, mb_index)` with `mb_index < priv->mb_count` after initialization (never linear indexing). [F46, F53, F115]
- In `flexcan_chip_start()`, `priv->reg_ctrl_default` must save `regs->ctrl` before clearing `FLEXCAN_CTRL_ERR_ALL`; writing `regs->mecr` requires setting `FLEXCAN_CTRL2_ECRWRE`, clearing and keeping `FLEXCAN_MECR_ECRWRDIS` cleared during writes, then re-locking both; `flexcan_suspend()`/`resume()` must only set `CAN_STATE_SLEEPING`/`ERROR_ACTIVE` when `netif_running(dev)` is true. [F52, F54, F62]
- In `flexcan_set_bittiming_cbt()`, `bt->phase_seg1 > 0x20` and `dbt->phase_seg1 > 0x8` must be clamped and excess added to `prop_seg` before `FIELD_PREP()`; in `flexcan-core.c`, `mb->data[]` (`u32[]`) words are big-endian (`be32_to_cpup()`/`cpu_to_be32()`) and indexed by `i / sizeof(u32)` while byte loop `i` indexes `cfd->data[i]`. [F83, F103, F117]
- In `c_can`, `enum reg` must keep the 11 `C_CAN_IF1_*` and 11 `C_CAN_IF2_*` entries (`IF_ENUM_REG_LEN = 11`) contiguous in matching order across `reg_map_c_can`/`d_can` with adjacent 32-bit pairs; `c_can_get_tx_head()`/`tail()` mask with `ring->obj_num - 1` (requiring power-of-2 `msg_obj_tx_num`), and `c_can_get_tx_free()` only uses `ring->obj_num - (ring->head - ring->tail)` on `BOSCH_D_CAN`. [F66, F105]
- `c_can_setup_tx_object()` must call `c_can_inval_msg_object()` and `change_bit()` when RTR differs from `priv->tx_dir` (`c_can_chip_config()` resets `tx_dir = 0`); `c_can_poll()` must only read `C_CAN_STS_REG` when `atomic_xchg(&priv->sie_pending, 0)` is non-zero (writing `LEC_UNUSED` on `BOSCH_C_CAN`); and `c_can_read_objects()` must clear `pend &= ~BIT(obj - 1)` before `continue` branches while keeping `if (!(ctrl & IF_MCONT_NEWDAT)) continue;`. [F58, F59, F94]
- In `at91_irq_tx()`, the `tx_tail`..`tx_head` loop must `break` on the first mailbox without `reg_sr & (1 << mb)`, and only call `netif_wake_queue()` when `(tx_head & get_head_mask(priv)) != 0` or `(tx_tail & get_head_mask(priv)) == 0`. [F92]
- In `cc770`, `cc770_msgobj` (16B with `u8 dontuse`) and `cc770_regs` must stay `__packed` for `offsetof()`; `msgobj[0]` aliases `0x00..0x0f`, so logical objects `0 .. CC770_OBJ_MAX - 1` map via `obj2msgobj(o)` and `intid2obj(intid)` in `cc770_interrupt()` must check `0 <= o < CC770_OBJ_MAX`. [F80, F119]
- In `grcan.c`, `txwr`, `txrd`, `rxwr`, `rxrd`, and `priv->eskbp` are byte offsets stepped by `GRCAN_MSG_SIZE` (16), `echo_skb` helpers take `offset / GRCAN_MSG_SIZE`, `grcan_txspace()` reserves one slot so `txwr != eskbp` when full, DMA handles must align to `GRCAN_BUFFER_ALIGNMENT` (1024), and ring sizes must satisfy `!GRCAN_INVALID_BUFFER_SIZE(s)`. [F84, F85]

## Synchronization
- In `can_restart()`, `netif_carrier_on(dev)` must precede `priv->do_set_mode(dev, CAN_MODE_START)` (reverted on error); `close_candev()` and `can_restart_now()` call `cancel_delayed_work_sync(&priv->restart_work)` under `rtnl_lock` before `can_flush_echo_skb()`/`can_restart()`, so `can_restart_work()` and `do_set_mode` must never take `rtnl_lock`. [F15, F16, F154]
- Config changes on a registered CAN device (`can_change_mtu`, `can_ctrlmode_changelink`, `can_dbt_changelink`, `can_changelink`, `at91_can` `mb0_id_store`) must hold `rtnl_lock` and reject `dev->flags & IFF_UP` with `-EBUSY`; `can_set_termination()` must use `gpiod_set_value_cansleep()`. [F29, F146, F161]
- `can_rx_offload_queue_timestamp()`/`queue_tail()` must enqueue to `skb_irq_queue` and splice into `skb_queue` under `skb_queue.lock` in `can_rx_offload_irq_finish()` or (for threaded IRQs, with `local_bh_disable()`/`enable()`) `can_rx_offload_threaded_irq_finish()`; `can_rx_offload_napi_poll()` must recheck `!skb_queue_empty(&offload->skb_queue)` and reschedule NAPI after `napi_complete_done()`. [F17, F18, F147]
- Echo SKB and `can_rx_offload_queue_*` helpers must use `dev_kfree_skb_any()`/`dev_consume_skb_any()`; in `c_can` and `flexcan`, IRQ/NAPI paths (`c_can_handle_state_change()`, `flexcan_irq_state()`) must call `__c_can_get_berr_counter()`/`__flexcan_get_berr_counter()` instead of the PM-wrapping `*_get_berr_counter()`. [F149, F150]
- In `c_can_main.c`, `c_can_start_xmit()` uses `IF_TX` (`1`) while NAPI and `c_can_configure_msg_objects()` use `IF_NAPI` (`0`); `c_can_tx_busy()` needs `smp_mb()` after `netif_stop_queue()` before rechecking `c_can_get_tx_free()`, pairing with `smp_mb()` in `c_can_do_tx()` before `netif_wake_queue()`; `c_can_hw_raminit_syscon()` must hold `raminit_lock`, mask regmap ops to `start | done`, and clear `done` in `ctrl` after pulsing `start`. [F21, F56, F57]
- `flexcan_chip_interrupts_enable()` must bracket writes to `regs->ctrl`, `imask2`, and `imask1` with `disable_irq(dev->irq)` and `enable_irq(dev->irq)`. [F28]
- In `grcan.c`, `priv->lock` (`spin_lock_irqsave()`) must protect `eskbp`, `resetting`, `closing`, `catch_up_echo_skb()`, `grcan_start()`, re-enabling `GRCAN_IRQ_TX | GRCAN_IRQ_RX` in `grcan_poll()`, and `netif_wake_queue()`/`grcan_reset_timer()` (only when `!resetting && !closing`); `grcan_reset()` syncs `eskbp = txrd` (`grcan_running_reset()` saves/restores `eskbp` and ring/imr regs); `grcan_close()` sets `closing = true` under `priv->lock`, drops it for `timer_delete_sync()`, re-locks for `grcan_stop_hardware()`, and unlocks before `free_irq()`/`grcan_free_dma_buffers()`; `grcan_receive()`/`grcan_start_xmit()` need `mb()`/`wmb()` before updating `rxrd`/`txwr`. [F23, F26, F60, F61, F141, F142, F151]

## Object Lifetimes
- In `c_can_start_xmit()`, `flexcan_start_xmit()`, `grcan_start_xmit()`, and `ifi_canfd_start_xmit()`, `can_put_echo_skb()` must precede the TX-triggering register write; all echo-SKB completion/free paths must set `priv->echo_skb[idx] = NULL`; and `can_skb_set_owner()` must use `refcount_inc_not_zero(&sk->sk_refcnt)`. [F2, F6, F7, F20]
- `alloc_c_can_dev()` devices must be freed with `free_c_can_dev()` (`netif_napi_del()`), `c_can_plat_probe()` jumps to `exit_free_device` before `pm_runtime_enable()` and `exit_pm_runtime` after, `register_c_can_dev()`/`c_can_stop()` select sleep pinctrl while `c_can_start()` activates pins (calling `pinctrl_put()` on the `pinctrl_get_select()` handle); `grcan_close()` must call `close_candev(dev)` before clearing `echo_skb_max`/`echo_skb` and `kfree(priv->echo_skb)`, `grcan_free_dma_buffers()` must free `dma->base_buf`/`base_handle`, `grcan_probe()`/`remove()` must call `of_node_put(sysid_parent)`, `irq_dispose_mapping()` after `unregister_candev()`, and `netif_napi_del()` before `free_candev()`; and `cc770` probe errors after `alloc_cc770dev()` must call `free_cc770dev(dev)` before `iounmap()`/region release. [F8, F9, F10, F11, F120, F138, F143]
- `register_flexcandev()` calls `pm_runtime_put()` only on success, so `flexcan_probe()` must call `pm_runtime_put_noidle()` on failure and `flexcan_remove()` must not; `flexcan_chip_start()` must keep IRQs masked until `can_rx_offload_enable()` and `request_irq()` succeed, and `flexcan_close()`/`open()` unwind must call `flexcan_chip_interrupts_disable()` before `free_irq()`, `can_rx_offload_disable()` before chip stop, and `can_rx_offload_del()` before `close_candev()`. [F12, F13, F130]
- When `netif_running(dev)` is true, `flexcan_suspend()`/`resume()` must disable/enable the transceiver when `!device_may_wakeup(device)` (and disable on `flexcan_chip_start()` failure), and `flexcan_noirq_suspend()`/`resume()` must guard `pm_runtime_force_suspend()`/`resume()` with `!(device_may_wakeup(device) && (priv->devtype_data.quirks & FLEXCAN_QUIRK_SETUP_STOP_MODE_SCMI))`. [F132, F133]

## API Contracts
- Before `register_candev()`, `can_priv` must set `termination_const`, `termination_const_cnt`, and `do_set_termination` all together or none, pair `bitrate_const` with `bitrate_const_cnt`, not set both `bitrate_const` and `bittiming_const`, set non-zero `sjw_max`, and call `can_set_static_ctrlmode()` after `ctrlmode_supported` with disjoint bits; `ndo_open`/`ndo_stop` must call `open_candev()`/`close_candev()`. [F163, F164, F165]
- `candev` drivers must validate TX SKBs in `ndo_start_xmit` with `can_dev_dropped_skb()` (not `can_dropped_invalid_skb()`, which must never cast `netdev_priv(dev)` to `can_priv *`) and return `NETDEV_TX_OK` if true; `can_put_echo_skb()` and `can_dropped_invalid_skb()` must accept `ETH_P_CANXL` alongside `ETH_P_CAN`/`ETH_P_CANFD`. [F34, F86, F110, F111, F168]
- `can_put_echo_skb()` consumes `skb` when `idx < echo_skb_max`, so `ndo_start_xmit` must finish reading `skb` and `NETDEV_TX_BUSY` checks first; echo helpers take 0-based `idx < echo_skb_max` (`at91_can` subtracts `get_mb_tx_first(priv)`; `c_can` maps `obj = idx + msg_obj_tx_first`); `__can_get_echo_skb()` requires non-NULL `len_ptr` while `frame_len_ptr` is optional. [F1, F35, F36, F75, F77]
- `can_rx_offload_add_timestamp()`/`add_fifo()` require `mailbox_read != NULL` (and `mb_first`, `mb_last < 64`, `mb_last > 0` if `mb_first >= mb_last`), while `add_manual()` requires `mailbox_read == NULL`; `mailbox_read` returns `NULL` when empty, `sk_buff *` when read, or `ERR_PTR` after mailbox ack on `drop`/error; `can_rx_offload_queue_*()` always consumes `skb`. [F3, F30, F32, F74]
- `alloc_can*_skb()` sets `*cf = NULL` on failure and `can_change_state()` accepts `cf == NULL`; RX/TX-echo byte stats must not add `cf->len` when `CAN_RTR_FLAG` or `CAN_ERR_FLAG` is set; NAPI polls must count all `netif_receive_skb()` frames (including error SKBs) in `work_done` and only complete NAPI/re-enable IRQs when `work_done < quota`. [F33, F172, F173]

## Error Handling
- `priv->do_set_mode` may be `NULL`, so `can_restart()` and `can_changelink()` (`IFLA_CAN_RESTART_MS`/`RESTART`) must check it and `can_restart_now()` must propagate `can_restart()` errors; echo SKB helpers must check `idx >= echo_skb_max` and return `-EINVAL`/`NULL` via `netdev_err()`, not `BUG_ON()`; `can_tdc_fill_info()` must keep `err` non-zero unless `tdc_manual` is true or `do_get_auto_tdcv` succeeds. [F38, F44, F180]
- `flexcan_probe()` must convert `ERR_PTR(-ENODEV)` from `devm_regulator_get_optional()` to `NULL` in `priv->reg_xceiver`, and `flexcan_setup_stop_mode()` must treat `-EINVAL` as `0` while propagating other negative errors; in `grcan_start_xmit()`, `grcan_txbug_workaround()` must precede `can_put_echo_skb()` and return `*netdev_tx_status` on `-EBUSY`. [F41, F42, F45]

## External Contracts
- `IFLA_CAN_RESTART` (`can_restart_now()`) requires `priv->do_set_mode != NULL`, `dev->flags & IFF_UP`, `priv->restart_ms == 0`, and `priv->state == CAN_STATE_BUS_OFF`. [F176]

## Known Pitfalls
- `can_dbt_changelink()`/`can_changelink()` must validate `bitrate_max` and `can_calc_tdco()` against local `dbt`/`bt` before `memcpy()`; `can_calc_bittiming()`/`can_fixup_bittiming()` must cast to `u64` before multiplying, use `do_div()`/`DIV_U64_ROUND_CLOSEST()`, and reset `best_sample_point_error = UINT_MAX` when `bitrate_error < best_bitrate_error`; `can_change_state()`/`flexcan_irq_state()` must use `>=` and `<=` for TX/RX state checks; `__skb_queue_add_sort()` must save `pos` into `insert` before `break`; and `can_rx_offload_irq_offload_timestamp()` loops must `break` when it returns 0. [F87, F89, F90, F96, F97, F101]
- In `flexcan`, 64-bit mailbox masks must use `BIT_ULL()`, `GENMASK_ULL()`, and `(u64)` before `<< 32` in `flexcan_read64_mask()`, passing `&regs->iflag1` or `&regs->imask1` (`iflag2`/`imask2` are at `addr - 4`); `flexcan_chip_freeze()` must guard `if (bitrate)` before dividing; `register_flexcandev()` must disable the chip around writing `FLEXCAN_CTRL_CLK_SRC`; `flexcan_ram_init()` must set `FLEXCAN_CTRL2_WRMFRZ` and precede `FLEXCAN_MCR_FEN`; `CAN_CTRLMODE_LOOPBACK` must clear `FLEXCAN_MCR_SRX_DIS` and `FLEXCAN_FDCTRL_TDCEN`; `tx_mb_reserved->can_ctrl` must be written twice with `FLEXCAN_MB_CODE_TX_INACTIVE` in `flexcan_start_xmit()` (ERR005829); and `flexcan_mailbox_read()` must always clear `iflag1` and read `regs->timer`. [F82, F102, F108, F125, F127, F128, F129, F131]
- `c_can_chip_config()` must test `LISTENONLY && LOOPBACK` before single flags; `at91_start_xmit()` must set `AT91_MB_MODE_DISABLED` before writing `AT91_MID(mb)`, `at91_get_reg_sr_rx()` must OR-accumulate `AT91_SR`, and `at91_chip_start()` must dummy-read `AT91_SR` before writing `AT91_IER`; `register_cc770dev()` must call `cc770_probe_chip()` (`!i82527_compat` for `CTRL_EAF`/`cc770_get_berr_counter`), `cc770_interrupt()` must check `CC770_OBJ_FLAG_RTR` before `RX`, and `cc770_tx_interrupt()` must handle `ctrl1 & NEWDAT_SET` via `cc770_rx()` + `cc770_tx()`; `ifi_canfd` must verify IP ID/revision in probe and write `IFI_CANFD_ERROR_CTR_UNLOCK_MAGIC` before enabling error counters. [F64, F93, F95, F139, F140, F144, F145]
