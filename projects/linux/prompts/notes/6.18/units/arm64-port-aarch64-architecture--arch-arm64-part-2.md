# ARM64 PORT (AARCH64 ARCHITECTURE) — arch/arm64 (part 2)

Provides core AArch64 architecture headers, UAPI definitions, and low-level ACPI boot and NUMA initialization routines, including page table layouts, TLB invalidation, uaccess/PAN/MTE, sysreg/instruction encodings, unwinding, RSI SMC, and vDSO helpers.

## Architecture & Data Flow
- `pte_present_invalid()`, `pte_valid_not_user()`, and `pte_access_permitted_no_overlay()` must test `(val & mask) == expected` (`PTE_PRESENT_INVALID` aliases `PTE_NG`; exec-only user PTEs clear `PTE_USER`). Hardware-bit predicates (`pte_young`, `pte_write`, `pte_user`, `pte_user_exec`, `pte_special`, `pte_cont`, `pte_tagged`) require `pte_present(pte)`. `pte_protnone()` requires `pte_present_invalid(pte) && !pte_user(pte) && !pte_user_exec(pte)`, and `pmd_trans_huge()` must OR `PTE_VALID` before `!pmd_table()`. [F42, F84, F85]
- Before `pte_wrprotect()` or `pte_modify()` alters `PTE_WRITE`/`PTE_RDONLY`, it must check `pte_hw_dirty(pte)` (`pte_write(pte) && !pte_rdonly(pte)`) and set `PTE_DIRTY`, and `pte_modify()` must call `pte_mkdirty(pte)` if `pte_sw_dirty(pte)`. `PTE_SWBITS_MASK` must cover all software PTE bits modified on live valid PTEs for `pgattr_change_is_safe()` (`__check_safe_pte_update()`). `__get_and_clear_full_ptes()` must accumulate `pte_dirty()` and `pte_young()` across all `nr` entries into the returned `pte`. [F86, F91, F138]
- In `asm/memory.h`: `MT_NORMAL` must be index 0 (`vm_get_page_prot()` ORs `MT_NORMAL_TAGGED` into `protection_map[]`); `untagged_addr(addr)` must AND `__addr` with `__untagged_addr(__addr)` (`sign_extend64((__force u64)(addr), 55)`); `VMEMMAP_SIZE` must use `_PAGE_END(VA_BITS_MIN) - PAGE_OFFSET` (`* sizeof(struct page)` per page) while `VMALLOC_END` adds `VMEMMAP_UNUSED_NPAGES * sizeof(struct page)` to `VMEMMAP_START`; and `PCI_IO_SIZE` must be a power of two for `IO_SPACE_LIMIT`. [F79, F99, F105, F116]
- Under `CONFIG_ARM64_LPA2`, `PHYS_MASK_SHIFT` (`MAX_PHYSMEM_BITS`) must check `lpa2_is_enabled()` and fall back to 48 bits when `TCR_DS` is clear. `ARM64_HW_PGTABLE_LEVELS(va_bits)` must use ceiling division `((va_bits) - PTDESC_ORDER - 1) / PTDESC_TABLE_SHIFT`. [F100, F118]
- In `acpi_numa.c`, `acpi_early_node_map` must use `[0 ... NR_CPUS - 1] = NUMA_NO_NODE` (`acpi_numa_get_nid()`). `acpi_numa_gicc_affinity_init()` must reject `header.length < sizeof(struct acpi_srat_gicc_affinity)`, and `acpi_parse_gicc_pxm()` must map `pa->acpi_processor_uid` via `get_cpu_for_acpi_id()` and return `0` (not negative errno) when `!(pa->flags & ACPI_SRAT_GICC_ENABLED)` or `cpu < 0`. [F33, F71, F122]
- `switch_mm()` must call `update_saved_ttbr0(tsk, next)` even when `prev == next`, and `enter_lazy_tlb()` must call `update_saved_ttbr0(tsk, &init_mm)`. In `asm/pkeys.h`, `mm_pkey_is_allocated()` must reject `pkey < 0 || pkey >= arch_max_pkey()` before `1U << pkey`, and `mm_pkey_alloc()` must check `mm_pkey_allocation_map(mm) == all_pkeys_mask` before `ffz()` and `mm_set_pkey_allocated()`. [F52, F97]
- In `__flush_tlb_range_op()`, non-range steps (`!system_supports_tlb_range()`, `__flush_pages == 1`, or `lpa2` with `__flush_start` unaligned to `SZ_64K`) must advance `__flush_start` by `stride`, decrement `__flush_pages` by `stride >> PAGE_SHIFT`, and `continue` before `scale` decrements from 3 to 0. [F87]
- In `arm64_mops_reset_regs()`, `regs->regs[srcreg]` must only be indexed when `ESR_ELx_MOPS_ISS_MEM_INST` is clear (SET* can encode `XZR` == 31, out of bounds for `user_pt_regs::regs[31]`). In `unwind_consume_stack()`, `*info` must be set to `stackinfo_get_unknown()` before restoring `state->stack = tmp` and setting `state->stack.low = sp + size`. [F65, F88]
- In `asm/processor.h`, `start_thread_common()` must only reset `regs->user_regs`, `regs->orig_x0`, and `regs->pmr`, preserving `regs->syscallno` and `regs->stackframe`; `thread_struct::uw` must have no compiler padding between `tp_value`, `tp2_value`, `fpmr`, `pad`, and `fpsimd_state` (`arch_thread_struct_whitelist()`). [F112, F129]
- In `asm/syscall.h`, for `is_compat_thread()`, `syscall_get_return_value()` must use `sign_extend64(val, 31)` and `syscall_set_return_value()` must use `lower_32_bits(val)`; `syscall_set_nr()` must set `-ENOSYS` via `syscall_set_return_value()` when `nr == -1`, and `syscall_set_arguments()` must set `regs->orig_x0 = regs->regs[0]`. [F98, F152]
- `arch_parse_debug_rodata()` must set both `rodata_enabled` and `rodata_full` for `"on"`, `"off"`, and `"noalias"`. `mod_arch_specific` and `asm/module.lds.h` must pair PLT and ftrace trampolines for both core and `.init` sections. `arm64_bp_harden_el1_vectors` and `arm64_hyp_spectre_vector` enumerators must match the `SZ_2K` assembly vector slot order. In `uapi/asm/bitsperlong.h`, `__BITS_PER_LONG` must be `32` when `defined(__KERNEL__) && !defined(__aarch64__)`. [F59, F60, F64, F92]

## Synchronization
- `flush_tlb_mm()`, `__flush_tlb_page_nosync()`, and `__flush_tlb_range_nosync()` must run `dsb(ishst)` after clearing a PTE and before reading `ASID(mm)` (`atomic64_read(&mm->context.id)`). Synchronous TLB flushes (`asm/tlbflush.h`) require `dsb(ishst)`/`dsb(nshst)` before `__tlbi()`, `dsb(ish)`/`dsb(nsh)` after, plus `isb()` for kernel mappings (`local_flush_tlb_all`, `flush_tlb_all`, `flush_tlb_kernel_range`, `__flush_tlb_kernel_pgtable`). [F13, F26]
- Live valid PTE flag updates (`__ptep_test_and_clear_young()`, `___ptep_set_wrprotect()`, `__clear_young_dirty_pte()`) must use a `cmpxchg_relaxed()` loop (saving `pte_hw_dirty(pte)` into `PTE_DIRTY` before clearing `PTE_WRITE`). Under `CONFIG_ARM64_CONTPTE`, public `asm/pgtable.h` PTE helpers except `ptep_get_lockless()` require holding the PTL, public setters (`set_pte`, `set_ptes`, `ptep_set_access_flags`) must call `pte_mknoncont()`, and `PTE_CONT`-aware callers must use `__set_ptes`/`__ptep_get`. [F23, F24, F45]
- `queue_pte_barriers()` and `arch_{enter,flush,leave}_lazy_mmu_mode()` must check `in_interrupt()` and bypass `TIF_LAZY_MMU`/`TIF_LAZY_MMU_PENDING` (`queue_pte_barriers()` calls `emit_pte_barriers()` immediately). In process context, `arch_leave_lazy_mmu_mode()` must call `arch_flush_lazy_mmu_mode()` before clearing `TIF_LAZY_MMU`. [F56, F123]
- When `CONFIG_PGTABLE_LEVELS <= 4`, `p4d_offset_lockless_folded()` must pass original table pointer `pgdp` (via `p4d_offset(pgdp, addr)`), not stack `&pgd`, because `p4d_to_folded_pud()` aligns down to `PAGE_SIZE`. `__uaccess_ttbr0_{enable,disable}()` must use `local_irq_save()` across reading `current_thread_info()->ttbr0` (`READ_ONCE()`) and writing `ttbr1_el1`/`ttbr0_el1` + `isb()`. [F15, F25]
- `set_page_mte_tagged()` and `folio_set_hugetlb_mte_tagged()` need `smp_wmb()` before `set_bit(PG_mte_tagged, ...)`; `page_mte_tagged()` and `folio_test_hugetlb_mte_tagged()` need `smp_rmb()` when `test_bit` is true; and `mte_check_tfsr_exit()` needs `dsb(nsh); isb()` before `mte_check_tfsr_el1()`. [F17, F19]
- `preempt_count_set()`, `__preempt_count_{add,sub}()`, and `__preempt_count_dec_and_test()` must only write 32-bit `ti->preempt.count` (preserving `preempt.need_resched`), and `__preempt_count_dec_and_test()` must reload 64-bit `READ_ONCE(ti->preempt_count)` after writing `--pc` when `pc != 0`. `__pmr_local_irq_{enable,restore}()` must call `pmr_sync()` after writing `SYS_ICC_PMR_EL1`, and `__pmr_local_irq_save()` must only disable when `!__pmr_irqs_disabled_flags(flags)`. [F27, F28, F63]
- `update_cpu_boot_status()` needs `WRITE_ONCE(secondary_data.status, ...)` + `dsb(ishst)` before `cpu_park_loop()`. Compat vDSO `__arch_get_hw_counter()` must bracket `mrrc` with leading and trailing `isb()`. `__io_ar(v)` must issue `dma_rmb()` plus `eor` + `cbnz` (`"memory"` clobber) on `v`. [F30, F31, F114]
- `apei_claim_sea(regs)` accepts `regs == NULL` (`arch_local_save_flags()`), sets `DAIF_ERRCTX` and wraps `ghes_notify_sea()` in `nmi_enter()`/`nmi_exit()`, runs `irq_work_run()` (under `DAIF_PROCCTX_NOIRQ` and `__irq_enter()`/`__irq_exit()`) only if interrupted IRQs were enabled, restores saved DAIF flags, and returns `0`, `-EINPROGRESS` (claimed with IRQs masked), or negative errno. `arm64_is_ras_serror()` and `arm64_ras_serror_get_severity()` require `!preemptible()`. [F37, F126, F127]

## Object Lifetimes
- In `acpi.c`, every `acpi_get_table()` pointer must be released with `acpi_put_table()` on all paths; in `acpi_boot_table_init()`, `facs` must be initialized to `NULL` and checked before use/put. When `CONFIG_PGTABLE_LEVELS > 3`, `pud_free()` must be a no-op if `!pgtable_l4_enabled()`. [F1, F4, F36]
- `cpu_{uninstall,install}_idmap()` and `cpu_install_ttbr0()` must call `cpu_set_reserved_ttbr0()` and `local_flush_tlb_all()` before updating `TCR_EL1.T0SZ` (`__cpu_set_tcr_t0sz`) and installing the new `TTBR0_EL1`. `init_new_context()` must set `BIT(0)` in `mm->context.pkey_allocation_map`, and `arch_dup_pkeys()` must copy it on fork. [F5, F6]

## API Contracts
- `acpi_os_ioremap()` returns `__phys_to_virt(phys)` for `EFI_ACPI_RECLAIM_MEMORY` when `memblock_is_map_memory(phys)`, rejects cross-descriptor ranges or mapped RAM (`memblock_is_map_memory(phys) || !memblock_is_region_memory(phys, size)`) for normal RAM types, and maps NOMAP RAM, `EFI_RUNTIME_SERVICES_CODE`, and `EFI_ACPI_MEMORY_NVS` with `PAGE_KERNEL_RO`. [F2, F140]
- `__TLBI_VADDR(addr, asid)` takes an unshifted VA (`__tlbi_level()` takes `0..3`), whereas `__TLBI_VADDR_RANGE(baddr, asid, scale, num, ttl)` takes pre-shifted `baddr` (`addr >> 16` for LPA2, else `addr >> PAGE_SHIFT`) and `ttl` in `1..3`. Callers of `__flush_{s2_,}tlb_range_op()` must cap `pages` at `MAX_TLBI_RANGE_PAGES` (`__flush_tlb_range_limit_excess()`). `{pte,pmd,pud,p4d}_offset_kimg()` only work on static kernel-image tables (`__phys_to_kimg()`). [F40, F43, F96]
- `{set_,try_,}page_mte_tagged*()` require `!folio_test_hugetlb(page_folio(page))`; hugetlb folios must use `folio_{set,test,try}_hugetlb_mte_tagged*()`. `arch_calc_vm_flag_bits()` returns `VM_MTE_ALLOWED` when `system_supports_mte()` and `(flags & (MAP_ANONYMOUS | MAP_HUGETLB)) || shmem_file(file) || is_file_hugepages(file)`. `arch_validate_flags()` rejects `VM_SHADOW_STACK | VM_EXEC` (and warns on `VM_SHARED` when `system_supports_gcs()`). `arch_vma_access_permitted()` returns `true` when `foreign || vma_is_foreign(vma)`. [F48, F82, F142, F153]
- In `asm/io.h`, `__iowrite{32,64}_copy()` `count` is in 32/64-bit words (not bytes) and for constant `count` in `{1,2,4,8}` must emit contiguous `str`s via `__const_memcpy_toio_aligned{32,64}()` + `dgh()`; `__raw_read{b,w,l,q}()` must use `ALTERNATIVE` with `ARM64_WORKAROUND_DEVICE_LOAD_ACQUIRE`. `may_use_simd()` requires `system_capabilities_finalized() && system_supports_fpsimd() && !in_hardirq() && !irqs_disabled() && !in_nmi()`. `aarch64_insn_is_mops()` (`0x3B200C00`/`0x19000400`) must match FEAT_MOPS for kprobes/uprobes rejection. [F106, F113, F115, F128, F137]

## Error Handling
- `__TLBI_RANGE_NUM(pages, scale)` clamps `pages` to `__TLBI_RANGE_PAGES(31, scale)` and returns a signed `int` in `[-1, 31]`; callers must check `num >= 0` before `__TLBI_VADDR_RANGE()`. `__{get,put}_user_error(x, ptr, err)` leave `err` unchanged on success, requiring `err = 0` initialization beforehand. [F41, F47, F66]

## External Contracts
- For CCA Realm (`asm/rsi*.h`, `asm/mem_encrypt.h`): `struct realm_config` is 4KB-aligned/sized; `rsi_attestation_token_init()` requires non-NULL `challenge` with `32 <= size <= 64` and zero-initializes `regs = { 0 }` before `memcpy`; `rsi_set_addr_range_state()` returns `-EPERM` if `res.a2 != RSI_ACCEPT` else `res.a0` as `long`, and `rsi_set_memory_range()` must check `ret == 0 && start <= top && top <= end`; when `is_realm_world()`, `force_dma_unencrypted()` is true and `dma_addr_{unencrypted,canonical}()` set/clear `PROT_NS_SHARED`. [F38, F39, F74, F117]
- In `asm/uaccess.h`, `access_ok()` must untag via `untagged_addr()` when `CONFIG_ARM64_TAGGED_ADDR_ABI` and `PF_KTHREAD` or `TIF_TAGGED_ADDR`, and all uaccess helpers must mask pointers via `{__,}uaccess_mask_ptr()` before dereferencing. `arch_untagged_si_addr()` preserves tags only for `sig == SIGTRAP && si_code == TRAP_BRKPT`. [F69, F149, F154]
- In `uapi/asm/{sigcontext,sve_context,ptrace}.h`: `{SVE,ZA}_{SIG,PT}_*` take `vq` in 128-bit quadwords (`sve_vq_from_vl(vl)`) and require `head.size >= {SVE,ZA}_SIG_CONTEXT_SIZE(vq)`; all `vq`/`n`/`vl` parameters in `ZA_SIG_*`, `ZT_SIG_*`, and `__SVE_*`/`__sve_*` macros must be parenthesized; and `_aarch64_ctx` records must be 16-byte aligned and null-terminated, with `fpsimd_context`, `esr_context`, and at most one `extra_context` in `sigcontext.__reserved[]`. In `asm/kgdb.h`, `NUMREGBYTES` must size `_EXTRA_REGS` (`pstate`, `fpsr`, `fpcr`) at 4 bytes each. [F50, F75, F78, F83]

## Known Pitfalls
- Use `pte_advance_pfn()` (never raw `pte_val` addition) to advance PTEs across pages (`PTE_ADDR_HIGH` is non-contiguous). Cast `pfn` to `phys_addr_t` before `<< PAGE_SHIFT` in `pfn_{pte,pmd,pud}()`. Keep `__boundary - 1 < (end) - 1` in `{pte,pmd}_cont_addr_end()` for top-of-VA wrap. Copy `start`/`pages` to locals in `__flush_tlb_range_op()`, and cast `asid` (`__TLBI_VADDR`) and `(num) + 1` (`__TLBI_RANGE_PAGES`) to `unsigned long` before shifting. [F58, F68, F94, F95, F101]
- In `__raw_{get,put}_user()` and `__{get,put}_kernel_nofault()`, evaluate macro args into locals outside the TTBR0/TCO critical section and disable TTBR0/TCO on both normal and fault paths. Cast `clear` to `u64` (`~(u64)(clear)`) in `sysreg_clear_set*()`. Use `le32_to_cpu()`/`cpu_to_le32()` and `lm_alias()` in `__runtime_fixup_{16,shift}()`, and `*start + (void *)start` in `runtime_const_fixup()`. Keep `OPTIMIZER_HIDE_VAR()` in `__arch_get_vdso_u_time_data()` under `CONFIG_CC_IS_GCC && CONFIG_PAGE_SIZE_64KB`. [F80, F90, F93, F108, F130]
