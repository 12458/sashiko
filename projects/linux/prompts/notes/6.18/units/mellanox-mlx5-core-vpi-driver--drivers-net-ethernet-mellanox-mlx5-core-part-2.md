# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 2)

Implements core Ethernet (`mlx5e`) data/control-path declarations, TC CT offload, IP tunnel encap/decap offloads, TIR/trap management, AF_XDP (XSK) zero-copy rings, and Event Queue (EQ) management.

## Architecture & Data Flow

- Zero-initialize every `struct mlx5_ct_tuple` before use (`tuples_ht_params` hashes padding). `mlx5_ct_entry` goes in `ct_tuples_nat_ht` (`MLX5_CT_ENTRY_IN_CT_NAT_TABLE`) iff `has_nat`, else `ct_tuples_ht` (`MLX5_CT_ENTRY_IN_CT_TABLE`); `mlx5_tc_ct_entry_remove_from_tuples` must match those flags. In `mlx5_tc_ct_entry_set_registers`, if `ns_type != MLX5_FLOW_NAMESPACE_FDB`, set both `ZONE_RESTORE_TO_REG` and `NIC_ZONE_RESTORE_TO_REG`. `mlx5_tc_ct_fs_init` must allocate `sizeof(*ct_priv->fs) + fs_ops->priv_size`. `mlx5_tc_ct_init_check_esw_support` requires `mlx5_eswitch_vlan_actions_supported`, `fdb_modify_header_fwd_to_table`, and `mlx5_eswitch_reg_c1_loopback_enabled`. [F59, F73, F75, F146, F167]
- In `mlx5e_tc_encap_flows_add` and `mlx5e_reoffload_encap`, flows with `MLX5_ESW_DEST_ENCAP` stay on slow path until `mlx5e_tc_flow_all_encaps_valid(esw_attr)` is true. In `mlx5e_set_int_port_tunnel`, reject (`-EINVAL`) uplink representor flows with `MLX5_ESW_DEST_ENCAP` routing to an OVS internal port in `MLX5_FLOW_STEERING_MODE_DMFS`. [F164, F196]
- Multi-WQEBB WQEs cannot cross page boundaries: when `contig_wqebbs < size`, `mlx5e_txqsq_get_next_pi` / `mlx5e_icosq_get_next_pi` pad with NOPs (`num_wqebbs = 1`, `MLX5E_ICOSQ_WQE_NOP` on ICOSQ), advance `sq->pc`, and recompute `pi`; room checks must reserve `MLX5E_STOP_ROOM(wqe_size)` (`2 * wqe_size - 1`). `mlx5e_get_max_sq_aligned_wqebbs` must clamp `<= MLX5_SEND_WQE_MAX_WQEBBS - 1` so `wqebbs * 4` fits in the 6-bit DS field. `MLX5E_KSM_UMR_WQEBBS`/`DS_CNT` use `DIV_ROUND_UP`, while `MLX5E_KSM_*_ENTRIES_PER_WQE` round down. Keep UMR/MPWRQ/TX WQE sizing in `xsk/rx.c`, `en.h`, and `txrx.h` in lockstep with `mlx5e_mpwrq_umr_entry_size`, `mlx5e_mpwrq_log_wqe_sz`, and `mlx5e_sq_calc_wqe_attr`. [F82, F83, F95, F126, F131]
- In `mlx5e_rqwq_reset`, reset `rq->mpwqe.actual_wq_head = 0` for `MLX5_WQ_TYPE_LINKED_LIST_STRIDING_RQ`. `mlx5e_shampo_hd::hd_per_wq` must be `u32` (`0x10000` wraps `u16`). Keep `MLX5E_NUM_RQ_STATES` / `MLX5E_NUM_SQ_STATES` last in `en.h` and synced with `en/reporter_rx.c` and `reporter_tx.c`. [F81, F84, F124]
- `struct mlx5e_xdp_buff` must start with `struct xdp_buff xdp` and fit in `xdp_buff_xsk->cb` (`XSK_CHECK_PRIV_TYPE`). `mlx5e_get_mpw_info` strides by `struct_size(..., alloc_units.frag_pages, pages_per_wqe)`, so `mlx5e_rq_alloc_mpwqe_info` must size with `frag_pages` even for XSK, and callers must use `mlx5e_get_mpw_info(rq, i)` instead of `rq->mpwqe.info[i]`. [F100, F135, F136]
- XSK RX allocators (`mlx5e_xsk_alloc_rx_mpwqe`, `_wqes_batched`, `_wqes`) must clear `skip_release_bitmap` and `consumed_strides` (or `MLX5E_WQE_FRAG_SKIP_RELEASE`). XSK cyclic RQs require `log_num_frags == 0` with `frags[j].xskp == &alloc_units->xsk_buffs[j]`. In `mlx5e_xsk_alloc_rx_wqes_batched`, when `wqe_bulk > contig`, only call the wrapped second `xsk_buff_alloc_batch` if the first returned `alloc == contig`. In `mlx5e_xsk_tx` / `mlx5e_xsk_tx_post_err`, push `xdpi` to `sq->db.xdpi_fifo`, plus `.xsk_meta` when `xp_tx_metadata_enabled(sq->xsk_pool)`. [F79, F80, F114, F144]
- `mlx5e_tir_init` must link `tir->list` under `res->td.list_lock` (`reg == true`) or call `INIT_LIST_HEAD(&tir->list)` (`reg == false`) for `mlx5e_tir_destroy`. `MLX5_EQ_POLLING_BUDGET` must be `<= MLX5_NUM_SPARE_EQE`, added to `param->nent` in `create_map_eq`. For SFs (`mlx5_core_is_sf`), `alloc_rmap` must skip `eq_table->rmap`, and `comp_irq_request_sf` / `release_sf` must update `used_cpus` and `comp_irqs` together. [F4, F86, F89]

## Synchronization

- Issue `dma_rmb()` after checking EQE ownership (`next_eqe_sw` / `eqe->owner`) before reading `eqe` in `mlx5_eq_comp_int`, `mlx5_eq_async_int`, and `mlx5_eq_get_eqe`. `mlx5e_notify_hw` requires `dma_wmb()` before writing `cpu_to_be32(pc)` to `*wq->db`, and `wmb()` before `mlx5_write64`. `create_comp_eq` requires `eq_table->comp_lock`; `create_async_eq` / `destroy_async_eq` use `eq_table->lock`. `mlx5_eq_async_int` serializes under `eq_async->lock` (`spin_lock_irqsave` for `ASYNC_EQ_RECOVER`, `spin_lock` in IRQ). [F40, F42, F154, F175]
- `mlx5e_tc_ct_restore_flow` (RX softirq) takes `ct_priv->ht_lock` with `spin_lock` and releases `entry` via `__mlx5_tc_ct_entry_put` (deferring `mlx5_tc_ct_entry_del` to `ct_priv->wq`), so process/workqueue contexts must use `spin_lock_bh` / `spin_unlock_bh` on `ct_priv->ht_lock`. [F168, F169]
- Set `MLX5_CT_ENTRY_FLAG_VALID` in `mlx5_tc_ct_block_flow_offload_add` only after `mlx5_tc_ct_entry_add_rules` succeeds; readers (`mlx5_tc_ct_entry_get`, del, stats) must check `mlx5_tc_ct_entry_valid(entry)` under `ht_lock`. Because `mlx5_tc_ct_block_flow_offload_update` drops `ht_lock` during `mlx5_tc_ct_entry_update_rules`, its error path must reacquire `ht_lock` and re-lookup `cookie` in `ft->ct_entries_ht` before removing/putting `entry`. [F25, F28]
- `__flow_flag_set` / `clear` require `smp_mb__before_atomic()`, and `__flow_flag_test` requires `smp_mb__after_atomic()`. In `mlx5e_take_tmp_flow`, if `IS_ERR(mlx5e_flow_get(flow))`, wait on `flow->del_hw_done`; if it succeeds, wait on `flow->init_done`. [F24, F34]
- In `mlx5e_attach_decap`, drop `decap_tbl_lock` before `wait_for_completion(&d->res_ready)` or `mlx5_packet_reformat_alloc`, and reacquire it to call `complete_all` or recheck `d->compl_result`. In `mlx5e_get_next_matching_encap`, call `mlx5e_encap_take(next)` under `rcu_read_lock()` and `rcu_read_unlock()` before `mlx5e_encap_put` or `wait_for_completion(&next->res_ready)`. [F23, F176]
- In `mlx5e_tc_tun_create_header_ipv4/ipv6`, call `mlx5e_rep_encap_entry_attach` before reading `attr.n->nud_state` under `read_lock_bh(&attr.n->lock)`; if `!(nud_state & NUD_VALID)`, call `neigh_event_send` and return `0` without allocating `e->pkt_reformat` or setting `MLX5_ENCAP_ENTRY_VALID` (callers and `mlx5e_encap_dealloc` must check `MLX5_ENCAP_ENTRY_VALID`). [F51, F195]
- In `get_route_and_out_devs`, `dev_hold(uplink_upper)` before `rcu_read_unlock()` to call `mlx5_lag_is_sriov`, then `dev_put`. In `mlx5e_tc_fib_event_work`, lock `rtnl_lock()` before `encap_tbl_lock`, and unlock both before `mlx5e_put_flow_list` and `mlx5e_route_put`. In `mlx5e_init_fib_work_ipv4/ipv6`, pass `GFP_ATOMIC` to `mlx5e_tc_init_fib_work` before `mlx5e_route_lookup_for_update`, with no fallible steps after. [F33, F170, F178]
- Bracket `MLX5E_RQ_STATE_ENABLED` changes on `c->xskrq.state` in `mlx5e_activate_xsk` / `deactivate_xsk` with `mlx5e_reporter_icosq_suspend_recovery` / `resume_recovery`, and call `synchronize_net()` in `mlx5e_deactivate_xsk`. In `mlx5e_xsk_wakeup`, if `!napi_if_scheduled_mark_missed(&c->napi)`, check `MLX5E_SQ_STATE_ENABLED` and `!test_and_set_bit(MLX5E_SQ_STATE_PENDING_XSK_TX, &c->async_icosq.state)` before `mlx5e_trigger_napi_icosq(c)`. [F35, F36]
- Under `priv->state_lock` (e.g. `mlx5e_wait_for_min_rx_wqes`), defer RX timeout recovery to `rq->rx_timeout_work` instead of calling devlink reporters synchronously. In `en/trap.c`, use `netif_napi_add_locked`, `napi_enable_locked`, `napi_disable_locked`, and `netif_napi_del_locked` (`netdev_lock` is held). [F38, F194]

## Object Lifetimes

- Callers of `mlx5_eq_cq_get` (`mlx5_eq_comp_int`, `cq_err_event_notifier`) must release non-NULL CQs with `mlx5_cq_put`. Call `mlx5_eq_enable` after `create_map_eq`, and `mlx5_eq_disable` before `destroy_unmap_eq` (`destroy_comp_eq` also calls `tasklet_disable` before `kfree`). Skip `table->pages_eq` when `MLX5_CAP_GEN(dev, page_request_disable)` is set. In `mlx5e_open_trap` / `mlx5e_close_trap`, open in order `netif_napi_add_locked`, `mlx5e_open_trap_rq`, `mlx5e_create_trap_direct_rq_tir`, and close in reverse order. [F1, F43, F149, F158]
- `mlx5e_xsk_enable_locked` / `disable_locked` only call `mlx5e_open_xsk` / `close_xsk` when `MLX5E_STATE_OPENED` and `params.xdp_prog` are set (still validating `mlx5e_validate_xsk_param` on enable). `mlx5e_xsk_disable_locked` must activate `c->rq`, wait for WQEs, and call `mlx5e_rx_res_xsk_update(..., false)` before deactivating/closing XSK; `enable_locked` must activate XSK and call `mlx5e_rx_res_xsk_update(..., true)` before deactivating `c->rq`. `mlx5e_close_xsk` must clear `MLX5E_CHANNEL_STATE_XSK`, call `synchronize_net()`, close XSK queues/CQs, and `memset` `c->xskrq` and `c->xsksq`. When `mlx5e_xdp_handle` returns true on XSK RX, test-and-clear `MLX5E_RQ_FLAG_XDP_XMIT` and set `skip_release_bitmap` or `MLX5E_WQE_FRAG_SKIP_RELEASE`. [F7, F9, F37, F64]
- Flush `ct_priv->wq` in `mlx5_tc_ct_del_ft_cb` and destroy it in `mlx5_tc_ct_clean` before freeing CT tables/rhashtables. `mlx5_tc_ct_delete_flow` must check both `!attr->ct_attr.offloaded` and `!attr->ct_attr.nf_ft` before `__mlx5_tc_ct_delete_flow`. [F14, F15]
- Balance `mlx5e_route_lookup_ipv4/ipv6_get` with `_put` on all exit paths. In `mlx5e_tc_tun_create/update_header_ipv4/ipv6`, set local `encap_header = NULL` after assigning `e->encap_header = encap_header`. Free `mlx5e_encap_entry`, `decap_entry`, and `route_entry` via `kfree_rcu`. In `mlx5e_detach_encap_route`, unlink `r->encap_entries` with `list_del_init(&e->route_list)` before `mlx5e_route_dealloc`. In `mlx5e_tc_tun_cleanup`, call `unregister_fib_notifier` before `flush_workqueue` and `kvfree(encap)`. [F19, F20, F32, F120, F179]

## API Contracts

- `mlx5_eq_notifier_register` callbacks run in atomic IRQ context under `eq->lock` and must not sleep. `mlx5_comp_eqn_get` must check `vecidx < table->max_comp_eqs`. `mlx5e_tir_builder_build_inline`/`_rqt`/`_direct`/`_tls` require `builder->modify == false`, whereas `_packet_merge`/`_rss` set `modify_tir_in` `bitmask` when `modify == true`; clear via `mlx5e_tir_builder_clear`. [F47, F87, F88, F173]
- `mlx5_wqe_eth_seg` `swp_*_offset` fields are in 2-byte units (`offset / 2`). `mlx5e_dma_push_netmem` must use `netmem_dma_unmap_addr_set` (paired with `netmem_dma_unmap_page_attrs`). [F63, F188]
- XSK entry points (`mlx5e_xsk_get_pool`, `setup_pool`, `wakeup`) must check `qid < params->num_channels`. `mlx5e_xsk_is_pool_sane` checks headroom/`chunk_size <= 0xffff`, and `mlx5e_validate_xsk_param` bounds `chunk_size` to `[MLX5E_MIN_XSK_CHUNK_SIZE, PAGE_SIZE]` (`page_shift >= 11`). XSK RX must call `xsk_buff_dma_sync_for_cpu` and TX must call `xsk_buff_raw_dma_sync_for_device` (`DMA_ATTR_SKIP_CPU_SYNC`). `mlx5e_xsk_tx` returns `!(budget && work_done)`. [F98, F99, F115, F129, F185]
- `mlx5e_get_next_matching_encap` (and `_valid_encap`/`_init_encap`) puts input `e` and returns a ref on next; early loop breaks must call `mlx5e_encap_put(priv, e)`. Check tunnel header size `<= MLX5_CAP_ESW(priv->mdev, max_encap_header_size)` before `mlx5_packet_reformat_alloc`. In Geneve helpers, divide byte lengths by 4 (`enc_opts.key->len / 4 <= (max_tlv_option_data_len + 1) * max_tlv_options`) and check `option_key->length <= max_tlv_option_data_len` before `* 4`. Only invoke `mlx5e_init_fib_work_ipv4/ipv6` on `FIB_EVENT_ENTRY_REPLACE`/`DEL` with matching `info->family`. [F16, F50, F106, F107, F145]

## Error Handling

- In `create_async_eqs` / `destroy_async_eqs`, after `mlx5_cmd_use_events`, `cmd_eq` teardown must call `mlx5_cmd_use_polling` and `mlx5_cmd_allowed_opcode(..., CMD_ALLOWED_OPCODE_ALL)` before unregistering `cq_err_nb` and freeing `ctrl_irq`. `create_comp_eq` returns `>= 0` EQN or `< 0` errno; `mlx5_eqn2comp_eq` returns `ERR_PTR(-ENOENT)`. `mlx5e_tir_builder_alloc` returns `NULL` on failure. In `mlx5e_handle_action_trap`, call `mlx5e_del_trap_queue` on error only if `open_queue` was true. In `mlx5e_xsk_alloc_rx_mpwqe`, continue from `batch` with `xsk_buff_alloc`, and on error free `0 .. batch - 1` via `while (--batch >= 0)`. [F3, F5, F46, F66, F113]
- `mlx5_tc_ct_init` returns `NULL` on failure (accepted by `mlx5_tc_ct_*`); `mlx5e_tc_tun_init` returns `ERR_PTR`. `mlx5_tc_ct_entry_get` returns pointer, `NULL`, or `ERR_PTR(-EINVAL)` (check both). `mlx5e_flow_get` returns `ERR_PTR(-EINVAL)` (never `NULL`), unlike `mlx5e_encap/decap/route_get` (`NULL`). [F53, F56, F61]
- In `mlx5_tc_ct_entry_add_rule`, pass local `attr` (not `zone_rule->attr`) on `err_rule`. In `mlx5_tc_ct_entry_update_rule`, on `ct_rule_update` failure, destroy new `mh`/`ct_labels_id` and restore `*attr = *old_attr`. In `mlx5e_attach_encap`, after `hash_add_rcu`, always call `complete_all(&e->res_ready)`, and on error set `e->compl_result < 0` and call `mlx5e_encap_put_locked`. `e->compl_result` is `1` on success (`> 0`), while `d->compl_result` is `0` (`!d->compl_result`). [F10, F12, F17, F52]

## External Contracts

- With `swp_csum_l4_partial` and `skb_is_gso(skb)`, `mlx5e_swp_encap_csum_partial` must use single-segment L4 length (`gso_size + hdrlen`). `mlx5e_tc_tun_parse_udp_ports` requires a full `0xffff` `enc_ports.mask->dst`, and `mlx5e_tc_tun_parse` must match `frag == 0` (mask 1). [F190, F199]

## Known Pitfalls

- Mask `be32_to_cpu(eqe->data.comp.cqn)` / `cq_err.cqn` with `0xffffff` before `mlx5_eq_cq_get`. Use `1ull << MLX5_EVENT_TYPE_*` in `MLX5_ASYNC_EVENT_MASK` and `gather_async_events_mask`. `rq->mpwqe.umr_wqe` is header-only (`mlx5e_umr_wqe_hdr`); never write `inline_mtts`/`klms`/`ksms` on it in `mlx5e_build_umr_wqe`. Keep `ix * rq->mpwqe.mtts_per_wqe` in `u32` before scaling to `MLX5_OCTWORD` in `mlx5e_xsk_alloc_rx_mpwqe`. [F90, F125, F127, F140]
- Cast `(*fifo->pc - *fifo->cc)` to `u16` in `mlx5e_skb_fifo_has_room`. Use `time_after((unsigned long)lastuse, nhe->reported_lastuse)` in `mlx5e_tc_update_neigh_used_value`. Recover `mlx5e_tc_flow` from `e->flows` via `container_of(efi, struct mlx5e_tc_flow, encaps[efi->index])`. In `mlx5e_tc_encap_flows_del`, clear `esw_attr->dests[flow->tmp_entry_index].flags` and `pkt_reformat` before `if (flow_flag_test(flow, SLOW)) continue;`. [F54, F117, F132, F133]
- `mlx5e_dup_tun_info` copies `sizeof(*tun_info) + tun_info->options_len`; check `test_bit(tun_type, ip_tun_key->tun_flags)` in `mlx5e_tc_tun_encap_info_equal_options`. In `mlx5e_tc_tun_parse_vxlan` with both VNI and GBP, write GBP to `misc5.tunnel_header_0` and `VNI << 8` to `misc5.tunnel_header_1`. In `mlx5_tc_ct_rule_to_tuple_nat`, use `ip6_offset = (act->mangle.offset - offsetof(struct ipv6hdr, saddr)) / 4` and check `< 4` / `< 8`. In `mlx5_tc_ct_entry_update_rule`, `*old_attr = *attr` does not copy trailing `esw_attr`/`nic_attr`. [F105, F108, F109, F143]
