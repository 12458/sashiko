# CRYPTO API — crypto (part 1)

This component implements the core Linux kernel cryptographic framework, the `acomp`, `aead`, `ahash`, and `akcipher` frontends, `AF_ALG` sockets, and cipher/hash/AEAD implementations including AES, ARIA, Anubis, ARC4, Blowfish, Camellia, CAST5, BLAKE2b, AEGIS-128, Adiantum, and Authenc.

## Architecture & Data Flow
- `crypto_alg_mod_lookup()` adds `CRYPTO_ALG_INTERNAL` to `mask` if neither `type` nor `mask` has it set. In `__crypto_alg_lookup()`, an exact `cra_driver_name` match breaks out of the `crypto_alg_list` scan after `crypto_mod_get(q)` and `crypto_mod_put(alg)` on any prior match; a fuzzy `cra_name` match continues scanning. When `crypto_create_tfm_node()` or `__crypto_alloc_tfmgfp()` fails in `init_tfm`/`cra_init` with `-EAGAIN`, it must call `crypto_shoot_alg(alg)` so `crypto_alloc_tfm_node()` (checking `fatal_signal_pending(current)`) does not re-select `alg`. [F90, F91, F103]
- In `crypto_remove_spawns()`, check `!spawn->registered`, `&inst->alg == nalg`, and `spawns->next == NULL` before iterating `inst->alg.cra_users`, and `crypto_more_spawns()` must propagate `!spawn->dead` to the parent on `stack`. In `struct cryptomgr_param`, `tb[0]` is `CRYPTOA_TYPE`, `tb[1..CRYPTO_MAX_ATTRS]` are 1-based `CRYPTOA_ALG` args, and `tb[i + 1]` is `NULL` (`CRYPTO_MAX_ATTRS + 2` slots). In `crypto_queue`, `queue->backlog` points to `&queue->list` or the first backlogged request, advancing in `crypto_dequeue_request()` and rewinding in `crypto_enqueue_request_head()` when `qlen >= max_qlen`. [F62, F83, F96]
- Because `struct acomp_req` unions `src`/`svirt` and `dst`/`dvirt`, `acomp_virt_to_sg()` must save `flags`, `svirt`, and `dvirt` into `req->chain` before `acomp_request_set_{src,dst}_sg()`. In `acomp_do_req_chain()`, `acomp_save_req()` must run unconditionally before `acomp_do_one_req()` because `acomp_reqchain_finish()` (called only when `err != -EINPROGRESS`) unconditionally calls `acomp_restore_req()` to restore `svirt`, `dvirt`, `CRYPTO_ACOMP_REQ_*_VIRT`, `complete`, and `data`. [F34, F35, F56]
- In `crypto_clone_ahash()`, set `crypto_ahash_tfm(nhash)->exit = crypto_ahash_exit_tfm` only after `alg->clone_tfm()` succeeds; copy `reqsize`/`statesize`, set `nhash->using_shash = true` with the cloned `crypto_shash` if `hash->using_shash`, or clone `crypto_ahash_fb(hash)` into `tfm->fb` (after checking `!IS_ERR(fb)`) if `crypto_ahash_need_fallback(hash)`. In `crypto_ahash_setkey()`, when `!tfm->using_shash` and `crypto_ahash_need_fallback(tfm)`, set the key on both `tfm` and `crypto_ahash_fb(tfm)` before clearing `CRYPTO_TFM_NEED_KEY`. [F41, F57, F58]
- For `CRYPTO_AHASH_ALG_BLOCK_ONLY`, `ahash_prepare_alg()` adds `cra_blocksize + 1` to `cra_reqsize` and `halg.statesize` (length at `ahash_request_ctx(req) + reqsize - 1`, buffer at `blenp - bs`); when `crypto_ahash_{update,finup}()` prepends `req->sg_head` to `req->src`, `ahash_{update,finup}_finish()` must restore `src`, `nbytes`, `complete`, and `data`. In `crypto_hash_walk_done()`, scatterlist walks (`!CRYPTO_AHASH_REQ_VIRT`) must subtract `walk->offset` from `walk->data` before `kunmap_local()`, and if `walk->entrylen != 0`, reset `walk->offset = 0` and increment `walk->pg` before `hash_walk_next()`. [F61, F102, F118]
- `af_alg_alloc_tsgl()` allocates `MAX_SGL_ENTS + 1` entries (`af_alg_sendmsg()` caps additions to `MAX_SGL_ENTS - sgl->cur`), and `struct af_alg_sgl` embeds `sgl[ALG_MAX_PAGES + 1]` (`af_alg_get_rsgl()` and `hash_sendmsg()` populate at most `ALG_MAX_PAGES`), reserving the trailing slot for `sg_chain()`. In `af_alg_sendmsg()` and `af_alg_pull_tsgl()`, `ctx->merge` is only used when `!(msg_flags & MSG_SPLICE_PAGES)` and cleared on `MSG_SPLICE_PAGES` or when `ctx->used` hits 0; in `af_alg_pull_tsgl()`, `j` increments only when `dst && dst_offset < plen`, and if `sg[i].length` stays non-zero it returns without `put_page()` or unlinking `sgl`. [F65, F74, F75, F100]
- In `{hash,aead,skcipher}_check_key()`, once `pask->private` clears `CRYPTO_TFM_NEED_KEY`, `atomic_dec(&pask->nokey_refcnt)` and `atomic_set(&ask->nokey_refcnt, 0)`. In `algif_skcipher.c`, when `_skcipher_recvmsg()` sets `CRYPTO_SKCIPHER_REQ_NOTFINAL`, `algif_skcipher_export()` saves `ctx->state`, and the next `_skcipher_recvmsg()` imports, frees, and nulls `ctx->state` and sets `CRYPTO_SKCIPHER_REQ_CONT`. In `algif_hash.c`, `hash_sendmsg()` starting `!ctx->more` or aborting on error calls `hash_free_result()` and resets `ctx->more = false` on error. [F67, F68, F105]
- Tail layouts: in `adiantum.c`, union `u` in `adiantum_request_ctx` and `req` in `adiantum_setkey()`'s `data` must be the final struct members; in `authenc.c`/`authencesn.c`, `reqoff >= 2 * digestsize` and `crypto_aead_set_reqsize()` adds `sizeof(*areq_ctx) + reqoff` to the max sub-request size; in `crypto_akcipher_sync_prep()`, `data->buf = (u8 *)(req + 1) + reqsize`. In `authencesn`, when `authsize > 0` rearranges the 8-byte ESN in `req->dst`, `crypto_authenc_esn_{genicv,decrypt}_tail()` must restore it before tag write/verify. [F69, F120, F121, F122]
- In `crypto_aegis128_decrypt_{generic,simd}()`, copy the tag from `req->src` before `skcipher_walk_aead_decrypt()`, and on mismatch wipe `req->dst` via `crypto_aegis128_wipe_chunk` before returning `-EBADMSG`. In `crypto_aegis128_{encrypt,decrypt}_chunk_neon()`, tail paths (`0 < size < AEGIS_BLOCK_SIZE`) bounce via `buf + AEGIS_BLOCK_SIZE - size` if `short_input` or restore `vst1q_u8(out - AEGIS_BLOCK_SIZE, msg)`; `crypto_aegis128_have_simd()` requires `cpu_feature(AES)` on 32-bit ARM and sets `aegis128_have_aes_insn = 1`. In `crypto_arc4_crypt()`, copy `crypto_lskcipher_ctx(tfm)` to `siv` when `!CRYPTO_LSKCIPHER_FLAG_CONT` and mutate only `siv`. In `le128_{add,sub}()`, snapshot `v1->b`/`v2->b` before writing `r->b`. [F70, F71, F107, F128, F129]

## Synchronization
- `crypto_algapi_init()` runs at `late_initcall`. `crypto_start_tests()` calls `set_crypto_boot_test_finished()` before taking `crypto_alg_sem`, and each iteration takes `crypto_alg_sem`, sets `l->test_started = true` on one larval, drops `crypto_alg_sem` before `crypto_schedule_test(larval)`, and restarts the scan; `crypto_start_test()` likewise sets `test_started = true` under `down_write(&crypto_alg_sem)` and unlocks before `crypto_schedule_test()`. `crypto_larval_lookup()` calls `crypto_larval_add()` only when `!(mask & CRYPTO_ALG_TESTED)`, always calls `crypto_larval_wait()` on an existing larval, and `crypto_larval_wait()` re-runs `crypto_alg_lookup()` if `larval->adult` is NULL or `-EEXIST`. [F17, F18, F19, F20, F98, F134]
- `crypto_grab_spawn()` takes `down_write(&crypto_alg_sem)` and checks `!crypto_is_moribund(alg)` before linking `spawn->list` into `alg->cra_users` (calling `crypto_mod_put(alg)` if moribund). In `crypto_spawn_alg()`, if `crypto_mod_get(alg)` fails under `down_read(&crypto_alg_sem)`, pin `alg` with `crypto_alg_get()` before `up_read()` to call `crypto_shoot_alg()` and `crypto_alg_put()` unlocked. `crypto_destroy_instance_workfn()` traverses `tmpl->dead` under `down_write(&crypto_alg_sem)` and only frees instances with `refcount_read(&inst->alg.cra_refcnt) == -1`; `crypto_unregister_template()` calls `up_write(&crypto_alg_sem)` before `crypto_free_instance()`, `crypto_remove_final()`, and `flush_work(&tmpl->free_work)`. [F22, F23, F24, F25]
- `AF_ALG` locking: lock child `sk` before `lock_sock_nested(psk, SINGLE_DEPTH_NESTING)`; under `lock_sock(sk)`, `alg_bind()` returns `-EBUSY` if `atomic_read(&ask->refcnt) != 0`, `alg_setsockopt()` returns `-EBUSY` if `refcnt != nokey_refcnt`, `hash_{send,recv}msg()` access `ctx->more`/`ctx->result` only under `lock_sock(sk)`, and `af_alg_sendmsg()` checks/sets `ctx->write = true` (returning `-EBUSY` if set) across `af_alg_wait_for_wmem()`. `af_alg_{wmem,data}_wakeup()` hold `rcu_read_lock()` around `sk->sk_wq` and `sk_wake_async_rcu()`. `af_alg_alloc_areq()` returns `-EBUSY` if `ctx->inflight` is true (cleared in `af_alg_free_resources()`); async AIO submission calls `sock_hold(sk)` and sets `areq->iocb`/`outlen` beforehand, returning `-EIOCBQUEUED` on `-EINPROGRESS`. [F28, F29, F30, F31, F32, F33, F147]
- Atomic contexts: `crypto_acomp_lock_stream_bh()` uses `spin_lock_bh(&ps->lock)` and, if `ps->ctx` is NULL, `spin_unlock(&ps->lock)` before `spin_lock(&ps->lock)` on `cpumask_first(cpu_possible_mask)`; atomic callers of `acomp_walk_virt()` pass `atomic = true`. `ahash_op_done()` clears `CRYPTO_TFM_REQ_MAY_SLEEP` before `finish`; `authenc`/`authencesn` continuation helpers pass their `flags` arg (0 in async callbacks) rather than `aead_request_flags(req)` to subrequests; `crypto_clone_tfm()`, `algif_skcipher_export()`, and `__crypto_alloc_tfmgfp()` in atomic paths use `GFP_ATOMIC`; `adiantum_hash_message()` uses `SG_MITER_ATOMIC`; `crypto_aegis128_{encrypt,decrypt}_simd()` check `aegis128_do_simd()` and bracket `*_neon` calls with `kernel_neon_begin()`/`end()`. [F135, F136, F138, F139, F143, F144, F149, F151]

## Object Lifetimes
- `crypto_create_tfm_node()` and `__crypto_alloc_tfmgfp()` consume `alg`'s ref only on success (freed in `crypto_destroy_tfm(mem, tfm)`, `mem = tfm - frontend->tfmsize`); on error the caller calls `crypto_mod_put(alg)`, and `frontend->init_tfm` (`crypto_{acomp,ahash}_init_tfm()`) rolls back fallback/init state. `crypto_mod_put()` reads `alg->cra_module` before `crypto_alg_put(alg)`. `crypto_larval_add()` sets `larval->completion` and `cra_refcnt = 2` before publishing to `crypto_alg_list`. `crypto_register_instance()` wrappers take ownership of `inst` only on success; `crypto_drop_spawn()` checks `spawn->alg != NULL` and calls `crypto_mod_put()` only if `!spawn->registered`. [F1, F2, F5, F6, F21, F45, F113]
- `crypto_acomp_{compress,decompress}()` and `crypto_ahash_{init,update,finup,digest}()` reject `CRYPTO_TFM_REQ_ON_STACK` when async unless cloned via `crypto_request_clone()`, `ahash_request_free()` skips `kfree()` on on-stack requests, and `acomp_request_clone()` rebases `nreq->src`/`dst` if pointing to `req->chain.{ssg,dsg}`. `crypto_acomp_alloc_streams()` preallocates `ps->ctx` on `cpumask_first(cpu_possible_mask)` and inits `ps->lock` on all possible CPUs before setting `s->streams`; `crypto_acomp_free_streams()` calls `cancel_work_sync(&s->stream_work)` first. [F116, F117, F131]
- `alg_bind()` swaps `(ask->type, ask->private)` under `lock_sock(sk)` when `ask->refcnt == 0` and calls `alg_do_release(type, private)` after `release_sock(sk)` (or `module_put(type->owner)` if `type->bind()` fails). After `sock_init_data(newsock, sk2)` in `af_alg_accept()`, never call `sock_put(sk2)` on error. `alg_setkey_by_key_serial()` calls `up_read(&key->sem)` and `key_put(key)` on all paths after `lookup_key()`. Set `sgl.need_unpin = iov_iter_extract_will_pin(&msg->msg_iter)` before `extract_iter_to_sg()`; `af_alg_get_rsgl()` inits `need_unpin`, `sgt.sgl`, `sgt.nents`, and `sg_num_bytes = 0` whenever `rsgl` is on `areq->rsgl_list`; `hash_sendmsg()` jumps to `unlock_free_result` before `ctx->sgl` is populated. Match `sock_kmalloc()` sizes in `sock_kfree_s()`, and skip freeing `areq->first_rsgl` in `af_alg_free_areq_sgls()` and `sgl->sgl` in `af_alg_free_sg()`. [F8, F10, F11, F14, F16, F124, F125, F167]

## API Contracts
- Keep `MODULE_SOFTDEP("pre: cryptomgr")` in `crypto/algapi.c`, guard `crypto_type.report` with `#if IS_ENABLED(CONFIG_CRYPTO_USER)`, and set `inst->free` before `*_register_instance()`. Registration: `crypto_check_alg()` requires non-empty names, `cra_priority >= 0`, power-of-two `cra_alignmask + 1`, and valid `cra_blocksize`/`alignmask`; `CRYPTO_ALG_DUP_FIRST` requires non-NULL `cra_type` and unembedded `alg`; `ahash_prepare_alg()` requires `statesize > 0`, `cra_reqsize` 0 or `>= statesize` (`<= MAX_SYNC_HASH_REQSIZE` if sync), and `finup` if `CRYPTO_AHASH_ALG_BLOCK_ONLY`; `aead_prepare_alg()` requires `maxauthsize`/`ivsize`/`chunksize <= PAGE_SIZE / 8`; `crypto_register_akcipher()` defaults NULL `encrypt`/`decrypt`/`set_priv_key` to `-ENOSYS` stubs. [F114, F153, F155, F157, F158, F159, F160, F161]
- `crypto_attr_alg_name()` returns an `ERR_PTR` or NUL-terminated name (accepted by `crypto_grab_spawn()`). `crypto_request_clone()` clears `CRYPTO_TFM_REQ_ON_STACK` on heap clones or switches `req->tfm` to `tfm->fb` on alloc failure. `CRYPTO_AHASH_ALG_BLOCK_ONLY` `update` returns non-negative residual bytes or negative errno; `crypto_hash_walk_{first,done}()` return positive bytes, 0, or negative errno (store in signed `int` and pass errors to `crypto_hash_walk_done()`). `crypto_aead_decrypt()` rejects `cryptlen < authsize`; `crypto_akcipher_sync_decrypt()` returns positive `data.dlen`. `crypto_authenc_extractkeys()` requires `RTA_OK`, exact `RTA_PAYLOAD`, `be32_to_cpu(param->enckeylen)`, and `keylen - rta_len >= enckeylen`. `blowfish_setkey()` requires `keylen != 0`. [F39, F40, F44, F52, F55, F79, F80, F109]
- In `af_alg.c`, `alg_proto` requires `.sysctl_mem` if `.memory_allocated` is set; `af_alg_pull_tsgl()` requires `dst` sized via `af_alg_count_tsgl()`; for `ALG_SET_IV`, `af_alg_cmsg_send()` checks `cmsg_len` before and after reading `con->iv->ivlen`, and `af_alg_sendmsg()` checks `ivlen == ivsize`. `crypto_aegis128_*_simd()` take `struct aegis_state *`; `crypto_aegis128_module_init()` registers `generic` before `simd`, enables `have_simd` after, and unregisters `generic` on failure. [F50, F78, F127, F130, F156]

## Error Handling
- `crypto_register_{acomps,aeads,ahashes,algs,templates}()` pre-decrement `i` (`for (--i; i >= 0; --i)`) on rollback. `ahash_do_req_chain()` checks `statesize <= HASH_MAX_STATESIZE`, `crypto_ahash_need_fallback(tfm)`, and `!crypto_hash_no_export_core(tfm)`, and restores `ahash_request_set_tfm(req, tfm)`. Zero netlink report structs with `memset()` and `strscpy()`. `af_alg_alloc_areq()` inits `areq->first_rsgl.sgl.sgt.sgl = areq->first_rsgl.sgl.sgl`. In `{aead,skcipher}_recvmsg()` loops, `err <= 0` overwrites `ret` only if `!ret`, `err == -EIOCBQUEUED`, or `err == -EBADMSG`. [F37, F46, F53, F95, F101]

## External Contracts
- `alg_bind()` checks `addr_len >= sizeof(struct sockaddr_alg_new) + 1`, masks `salg_feat`/`salg_mask` to `CRYPTO_ALG_KERN_DRIVER_ONLY`, and NUL-terminates `salg_type`/`salg_name`. `alg_setkey_by_key_serial()` uses `lookup_user_key(serial, 0, KEY_NEED_SEARCH)` and reads `"user"`/`"logon"`/`"encrypted"`/`"trusted"` keys under `down_read(&key->sem)`. In `af_alg_sendmsg()`, `ctx->init && !ctx->more` returns `-EINVAL` only if `ctx->used != 0`. In `hash_sendmsg()`, `!msg_data_left(msg)` frees results and returns 0 if `!ctx->more`, or allocates `ctx->result` and calls `crypto_ahash_final()` if `ctx->more && !(msg_flags & MSG_MORE)`. In `algif_rng.c`, `_rng_recvmsg()` clamps `len` to `MAXSIZE` (128), while `rng_test_sendmsg()` and `rng_setentropy()` (requiring `CAP_SYS_ADMIN` and `!pctx->entropy`) reject `len > MAXSIZE` with `-EMSGSIZE`. [F76, F77, F88, F94, F168, F169]

## Known Pitfalls
- In `crypto_acomp_{compress,decompress}()`, `return` the direct `tfm->{compress,decompress}(req)` call when `crypto_acomp_req_virt(tfm) || acomp_request_issg(req)`. In `ahash_def_finup_finish1()`, call `crypto_ahash_alg(tfm)->final(req)` directly. Normalize `sg->offset` with `offset_in_page()` before `PAGE_SIZE - offset` in `hash_walk_new_entry()` and `shash_ahash_digest()`. Call `flush_dcache_page(page)` before `kunmap_local()` when modifying mapped dst pages in `adiantum_finish()`. [F73, F92, F93, F148]
- Check `aead_sufficient_data()` and `used >= outlen - usedpages` in `_aead_recvmsg()`; check `cryptlen >= BLOCKCIPHER_BLOCK_SIZE` and `round_up(stream_len, CHACHA_BLOCK_SIZE) <= cryptlen` in `adiantum_crypt()`; check `sizeof(*req) + reqsize + mlen < mlen` with `mlen = max(slen, dlen)` in `crypto_akcipher_sync_prep()`; use `DIV_ROUND_UP(sk->sk_sndbuf, PAGE_SIZE)` in `hash_sendmsg()`; widen 32-bit lengths to 64-bit before `* 8` in `adiantum_hash_header()` and `crypto_aegis128_final{_neon}()`. [F81, F82, F85, F106, F108, F111]
- `crypto_inc()` requires alignment or `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` for `__be32` and falls through to `crypto_inc_byte()` on wrap. Call `preload_sbox()` before `aegis128_update_neon()` in `aegis128-neon-inner.c`. [F87, F152]
