# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 3)

Covers PCI/DRM (`amdgpu_drv.c`), GEM/DMA-BUF (`amdgpu_gem.c`, `amdgpu_dma_buf.c`), GART/doorbells (`amdgpu_gart.c`, `amdgpu_doorbell_mgr.c`), fences (`amdgpu_fence.c`, `amdgpu_eviction_fence.c`), GFX (`amdgpu_gfx.c`), legacy display (`amdgpu_display.c`, `amdgpu_encoders.c`), and EEPROM/FRU.

## Architecture & Data Flow
- Every `dma_fence` in `ring->fence_drv.fences[]` is embedded as `base` in `struct amdgpu_fence`; `to_amdgpu_fence()` returns `NULL` unless `f->ops` is `&amdgpu_fence_ops` or `&amdgpu_job_fence_ops`. Job fences (`amdgpu_job_fence_ops`) are embedded in `struct amdgpu_job` (`hw_fence.base`) and freed via `container_of(f, struct amdgpu_job, hw_fence.base)`, never `kfree(to_amdgpu_fence(f))`; check `fence->ops == &amdgpu_job_fence_ops` before downcasting `fences[]` entries to `amdgpu_job`. [F418, F494, F496]
- `ring->num_hw_submission` is a power of 2; `fences` has `num_hw_submission * 2` slots (`num_fences_mask = num_hw_submission * 2 - 1`; iterate full table with `i <= num_fences_mask`). `fence_drv.cpu_addr` and `trail_fence_cpu_addr` use `cpu_to_le32`/`le32_to_cpu`. In `amdgpu_fence_process()`, after `seq == last_seq` is false, mask `last_seq` and `seq` with `num_fences_mask` and advance `last_seq = (last_seq + 1) & drv->num_fences_mask` before `if (!fence) continue;`. In `amdgpu_ring_backup_unprocessed_commands()`, reset `ring_backup_entries_to_copy = 0`, init `wptr = fence_drv.signalled_wptr`, and advance `wptr = fence->wptr` on every unsignaled fence even when skipping `guilty_fence->context`. [F435, F456, F457, F471]
- In `amdgpu_dma_buf.c`, cast `dma_buf->priv` only if `dma_buf->ops == &amdgpu_dmabuf_ops`, and `attach->importer_priv` only if `attach->importer_ops == &amdgpu_dma_buf_attach_ops`. `amdgpu_dma_buf_map()` rejects `TTM_PL_VRAM` BOs when `amdgpu_dmabuf_is_xgmi_accessible(dma_buf_attach_adev(attach), bo)` instead of calling `amdgpu_vram_mgr_alloc_sgt()`. [F419, F520]
- In `amdgpu_gem_object_close()`, call `amdgpu_eviction_fence_detach(&fpriv->evf_mgr, bo)` only if `!amdgpu_vm_is_bo_always_valid(vm, bo)`. Call `amdgpu_vm_bo_update_shared(bo)` whenever a BO gains/loses a handle or attachment (`amdgpu_gem_object_open()`, `amdgpu_gem_object_close()` when `bo_va->ref_count` hits 0, `amdgpu_dma_buf_attach()`). [F432, F433]
- `amdgpu_gart_unbind()` remaps `gart.ptr` entries to `dummy_page_addr` (`flags = 0`) and calls `amdgpu_gart_invalidate_tlb()`. `amdgpu_gart_table_ram_free()` clears `p[x].mapping = NULL` on all `1UL << order` pages before `__free_pages()` and sets `gart.ptr = NULL`. `amdgpu_doorbell_create_kernel_doorbells()` updates `num_kernel_doorbells = size / sizeof(u32)` after page-aligning and adding the MES `PAGE_SIZE`. [F442, F443, F444]
- `amdgpu_queue_mask_bit_to_mec_queue()` returns 0-based `mec` while `ring->me = mec + 1`; in `amdgpu_gfx_kiq_acquire()`/`init_ring()`, each XCC's KIQ needs an unallocated bit in `mec_bitmap[xcc_id].queue_bitmap` with `queue == 0` (not `mec == 1 && pipe > 1`), `vm_hub = AMDGPU_GFXHUB(xcc_id)`, and doorbell offset `xcc_id * xcc_doorbell_range`. In `amdgpu_gfx_enable_kgq()` (non-MES) and `disable_kgq()`, map/unmap `gfx_ring[i + xcc_id * num_gfx_rings]` only when `amdgpu_gfx_is_master_xcc(adev, xcc_id)`. [F437, F438, F464]
- In `amdgpu_gfx_enforce_isolation_*`, remap `AMDGPU_XCP_NO_PARTITION` to `idx = 0` and check `idx < MAX_XCP`. After `amdgpu_gfx_set_enforce_isolation()` updates `enforce_isolation[]` under `enforce_isolation_mutex`, call `amdgpu_mes_update_enforce_isolation(adev)` unlocked. [F429, F465]

## Synchronization
- In `amdgpu_fence_emit()`, before overwriting `fences[seq & num_fences_mask]`, pin any existing fence via `dma_fence_get_rcu_safe()` under `rcu_read_lock()` and `dma_fence_wait()` outside RCU; finish init, ring emission, `wptr`, runtime PM ref, `start_timestamp`, and slot `dma_fence_get()` before `rcu_assign_pointer()`. `amdgpu_fence_process()` must win `atomic_cmpxchg(&drv->last_seq, last_seq, seq)` before clearing/signaling. `amdgpu_fence_driver_set_error()` holds `fence_drv.lock` (`spin_lock_irqsave`) around `!dma_fence_is_signaled_locked()` and `dma_fence_set_error()`. [F391, F392, F393, F397]
- `amdgpu_eviction_fence_enable_signaling()` (under `ev_fence->lock`) defers eviction to `evf_mgr->suspend_work`; `amdgpu_eviction_fence_suspend_worker()` locks `uq_mgr->userq_mutex` before `evf_mgr->ev_fence_lock` and unlocks `ev_fence_lock` before `amdgpu_userq_evict()`. [F526]
- In `amdgpu_gem_fault()`, after `ttm_bo_vm_reserve()` returns `0`, unlock `bo->base.resv` on all exit paths except when `ttm_bo_vm_fault_reserved()` or `ttm_bo_vm_dummy_page()` returns `VM_FAULT_RETRY` with `!(vmf->flags & FAULT_FLAG_RETRY_NOWAIT)`. [F385]
- In `amdgpu_gem_object_open()`, call `amdgpu_bo_unreserve(abo)` before `mutex_lock_nested(&vm->process_info->lock, 1)` (taken only for imported dynamic DMA-BUFs). In `amdgpu_dma_buf_move_notify()`, lock `vm->root.bo->tbo.base.resv` while `obj->resv` is held via `dma_resv_lock(resv, ticket)` (or `dma_resv_trylock(resv)` if `!ticket`) and skip contended VMs. [F410, F521]
- In `amdgpu_gem_list_handles_ioctl()`, after dropping `filp->table_lock` to `kvcalloc`, recheck `bo_index >= num_bos` (`-EAGAIN`) under `table_lock` in pass 2 and call `copy_to_user()` after unlocking. In `amdgpu_debugfs_gem_info_show()`, hold `rcu_read_lock()` around `rcu_dereference(file->pid)`, `pid_task()`, and `task->comm`. [F408, F409]
- In `amdgpu_gfx_do_off_ctrl()`, disabling GFXOFF (`!enable`) when `gfx_off_req_count == 0` cancels `gfx_off_delay_work`, and if `gfx_off_state` is true and SMU un-powergating succeeds, clears `gfx_off_state` and calls `amdgpu_gfx_init_spm_golden()` before incrementing `gfx_off_req_count` under `gfx_off_mutex`. [F427]
- `amdgpu_gfx_enforce_isolation_ring_begin_use()`/`end_use()` unlock `enforce_isolation_mutex` before `amdgpu_gfx_kfd_sch_ctrl()`, which when `!enable && userq_sch_req_count[idx] == 0` calls `cancel_delayed_work_sync(&enforce_isolation[idx].work)` before checking `userq_sch_inactive[idx]` or incrementing `userq_sch_req_count[idx]`. `amdgpu_gfx_profile_ring_begin_use()`/`end_use()` return early if `amdgpu_dpm_is_overdrive_enabled(adev)`; in `begin_use()`, `atomic_inc(&total_submission_cnt)` and `cancel_delayed_work_sync(&idle_work)` run outside `workload_profile_mutex` before checking `workload_profile_active`. [F404, F405, F511, F532]
- `amdgpu_kiq_rreg()`/`wreg()` take `kiq->ring_lock` via `spin_lock_irqsave()`, abort before the `msleep` loop if initial `amdgpu_fence_wait_polling()` times out while `amdgpu_in_reset(adev) || in_interrupt()`, and in `rreg()` issue `mb()` before reading `adev->wb.wb[reg_val_offs]`. In `amdgpu_display_crtc_page_flip_target()` and `flip_work_func()`, `crtc->dev->event_lock` (`spin_lock_irqsave`) protects `pflip_status`, `pflip_works`, `primary->fb`, and `page_flip()`. `amdgpu_display_set_pixel()` runs under the `drm_panic` spinlock and must use `WREG32_NO_KIQ`. [F407, F531, F535]

## Object Lifetimes
- In `amdgpu_drm_release()`, under `drm_dev_enter()` before `drm_release()`, set `fpriv->evf_mgr.fd_closing = true` and call `amdgpu_eviction_fence_destroy(&fpriv->evf_mgr)` (flushing `suspend_work` before waiting/putting `ev_fence`) and `amdgpu_userq_mgr_fini(&fpriv->userq_mgr)`. In `amdgpu_pci_remove()`, run `amdgpu_xcp_dev_unplug()`, `amdgpu_gmc_prepare_nps_mode_change()`, `drm_dev_unplug()`, and `pm_runtime_get_sync()`/`pm_runtime_forbid()` before `amdgpu_driver_unload_kms()`, which precedes `pci_disable_device()` and `pci_wait_for_pending_transaction()`. [F376, F400, F503]
- `amdgpu_fence_emit()` takes `pm_runtime_get_noresume()` and a slot `dma_fence_get()` consumed once by `amdgpu_fence_process()` (calling `pm_runtime_put_autosuspend()`); job fences (`af != NULL`) take an extra `dma_fence_get()` because `amdgpu_job_fence_release()` and `amdgpu_fence_release()` free via `call_rcu`. Run `amdgpu_fence_driver_hw_fini()` (waits/completes fences, puts IRQ, `timer_delete_sync(&fallback_timer)`) before `sw_fini()`. [F377, F378, F379, F394]
- In `amdgpu_gem_prime_import()`, if `dma_buf->ops == &amdgpu_dmabuf_ops` and `obj->dev == dev`, return `drm_gem_object_get(obj)`. In `amdgpu_dma_buf_vmap()`/`vunmap()`, pin `bo` via `amdgpu_bo_pin()` before `drm_gem_dmabuf_vmap()` and unpin on failure or after `vunmap()`. [F381, F537]
- In `amdgpu_gem_create_ioctl()` with `AMDGPU_GEM_CREATE_VM_ALWAYS_VALID`, reserve `vm->root.bo` before `amdgpu_gem_object_create()`, set `abo->parent = amdgpu_bo_ref(vm->root.bo)` on success, and unreserve `vm->root.bo` before return. In `amdgpu_gem_userptr_ioctl()`, once `amdgpu_ttm_tt_get_user_pages()` succeeds, all paths must call `amdgpu_ttm_tt_get_user_pages_done()` before `drm_gem_object_put()`. [F383, F384]
- In `amdgpu_display_crtc_set_config()`, keep `pm_runtime_get_sync()` only when `active && !adev->have_disp_power_ref`, calling `pm_runtime_put_autosuspend()` otherwise. `amdgpu_display_user_framebuffer_create()` must drop its lookup ref on `obj` (and clear `rfb->base.obj[0] = NULL` on init failure). In `amdgpu_display_flip_handle_fence()`, clear `*f = NULL` and pass the ref to `amdgpu_display_flip_callback()` or call `dma_fence_put(fence)`. Pair `drm_connector_list_iter_begin()` with `drm_connector_list_iter_end()`. [F386, F387, F388, F479]
- In `amdgpu_kiq_rreg()`, free `reg_val_offs` via `amdgpu_device_wb_free()` on all paths and call `amdgpu_ring_undo(ring)` if `amdgpu_fence_emit_polling()` fails after `amdgpu_ring_alloc()`. Pair every `amdgpu_gfx_off_ctrl*(adev, false)` with `true`, never passing `true` when `gfx_off_req_count == 0`. [F389, F390]

## API Contracts
- `amdgpu_pci_shutdown()`, `amdgpu_pmops_prepare()`, and `poweroff()` return early if `in_s4 && in_suspend`. `amdgpu_pmops_prepare()` returns `1` when `amdgpu_device_supports_boco(adev) && pm_runtime_suspended(dev)` or neither S0ix nor S3 is active. `amdgpu_pmops_thaw()` skips `amdgpu_device_resume()` only if `!pm_hibernate_is_recovering() && !pm_hibernation_mode_is_suspend()`. `amdgpu_pmops_resume()`/`runtime_resume()` set `no_hw_access = true` if `!pci_device_is_present(adev->pdev)`. Manual PCI power calls in `runtime_suspend()`/`resume()` run only for `AMDGPU_RUNPM_PX`. [F417, F505, F506, F507, F508]
- `amdgpu_file_to_fpriv()` verifies `filp && filp->f_op == &amdgpu_driver_kms_fops` (`-EINVAL`). `amdgpu_dma_buf_unmap()` branches on `sg_page(sgt->sgl)`: non-NULL (`TTM_PL_TT`) uses `dma_unmap_sgtable()`/`sg_free_table()`/`kfree()`, NULL (`TTM_PL_VRAM`) uses `amdgpu_vram_mgr_free_sgt()`. `amdgpu_dma_buf_pin()` starts from `bo->allowed_domains`, clears `VRAM` if `!IS_ENABLED(CONFIG_DMABUF_MOVE_NOTIFY)` or any attachment has `!attach->peer2peer`, and returns `-EINVAL` if `!domains`. [F380, F421, F468]
- `amdgpu_gem_object_create()` takes 1-based `xcp_id_plus1` (`0` sets `bo->xcp_id = -1`, so pass `xcp_id + 1`). `amdgpu_gem_va_update_vm()` always returns a valid fence ref (`dma_fence_get_stub()` or `amdgpu_vm_clear_freed()`) that `amdgpu_gem_va_ioctl()` passes to `amdgpu_gem_update_bo_mapping()` or `dma_fence_put()`. `amdgpu_gem_timeout()` takes an absolute `ktime_get()` ns deadline, clamping positive waits to `MAX_SCHEDULE_TIMEOUT - 1`. [F416, F423, F426]
- `amdgpu_fence_wait_polling()` returns remaining us or `0` on timeout (check `r < 1`). In `amdgpu_fence_driver_hw_fini()`/`hw_init()`, skip `amdgpu_irq_put()`/`get()` when `!amdgpu_fence_need_ring_interrupt_restore(ring)`. `amdgpu_eeprom_read()`/`write()` return bytes transferred or negative errno; callers like `amdgpu_fru_get_product_info()` convert `len != expected_size` to `-EIO`. [F414, F415, F510]
- `amdgpu_gart_unbind()`, `map()`, and `bind()` take byte `offset` and CPU `PAGE_SIZE` `pages`; `amdgpu_gart_invalidate_tlb()` runs `mb()` and `amdgpu_device_flush_hdp()` before `amdgpu_gmc_flush_gpu_tlb()`. `amdgpu_mm_rdoorbell*()`, `wdoorbell*()`, and `amdgpu_doorbell_index_on_bar()` use 32-bit dword indices (scale 64-bit assignments by `<< 1` or `DIV_ROUND_UP(db_size, 4)`), and `rdoorbell*()`/`wdoorbell*()` check `!amdgpu_device_skip_hw_access(adev)` and `index < num_kernel_doorbells`. [F424, F425, F481, F516, F518]

## Error Handling
- Translate non-zero `copy_to_user()` to `-EFAULT` in `amdgpu_gem_op_ioctl()` and `list_handles_ioctl()`. Read `args->in` before `memset(args, 0, sizeof(*args))` in `amdgpu_gem_create_ioctl()`, `mmap_ioctl()`, and `wait_idle_ioctl()`. Do not log `DRM_ERROR()` or retry fallback domains on `-ERESTARTSYS`. [F413, F422, F551]

## External Contracts
- Reject userptr (`amdgpu_ttm_tt_get_usermm() != NULL`) and `AMDGPU_GEM_CREATE_VM_ALWAYS_VALID` BOs in `amdgpu_gem_prime_export()` (`-EPERM`); in `amdgpu_gem_object_open()`, reject userptr BOs if `usermm != current->mm` and always-valid BOs if `!amdgpu_vm_is_bo_always_valid(vm, abo)` (`-EPERM`); in `amdgpu_gem_object_mmap()` and `amdgpu_mode_dumb_mmap()`, reject userptr and `AMDGPU_GEM_CREATE_NO_CPU_ACCESS` BOs (`-EPERM`). [F541, F542, F543]
- `amdgpu_gem_create_ioctl()` rejects flags outside `AMDGPU_GEM_CREATE_SETTABLE_MASK` and domains outside `AMDGPU_GEM_DOMAIN_MASK` or with `MMIO_REMAP` (`-EINVAL`). `amdgpu_gem_userptr_ioctl()` uses `untagged_addr(args->addr)`, requires page-aligned `addr`/`size`, and requires `AMDGPU_GEM_USERPTR_REGISTER` if writable (`-EACCES`). `amdgpu_gem_metadata_ioctl()` rejects `SET_METADATA` with `data_size_bytes > sizeof(args->data.data)` (`-EINVAL`). [F449, F452, F547]
- `amdgpu_gem_va_ioctl()` rejects `va_address < AMDGPU_VA_RESERVED_BOTTOM` or in `[AMDGPU_GMC_HOLE_START, AMDGPU_GMC_HOLE_END)`, applies `AMDGPU_GMC_HOLE_MASK`, checks `va_address + map_size <= max_pfn * AMDGPU_GPU_PAGE_SIZE - AMDGPU_VA_RESERVED_TOP`, rejects `args->flags` only if both `~valid_flags` and `~prt_flags` match, and looks up `args->handle` only if `operation != AMDGPU_VA_OP_CLEAR && !(flags & AMDGPU_VM_PAGE_PRT)`. [F453, F469]

## Known Pitfalls
- In `amdgpu_gem_create_ioctl()`, `retry:` on `r != -ERESTARTSYS` clears `AMDGPU_GEM_CREATE_CPU_ACCESS_REQUIRED` before widening `VRAM` with `GTT`. Use `size_mul()` for `memdup_user()` in `amdgpu_gem_add_input_fence()`. Use signed wraparound comparisons `(int32_t)(wait_seq - amdgpu_fence_read(ring)) > 0` in `amdgpu_fence_wait_polling()` and `(int)(work->target_vblank - amdgpu_get_vblank_counter_kms(crtc)) > 0` in `amdgpu_display_flip_work_func()`, and guard `amdgpu_gfx_enforce_isolation_wait_for_kfd()` with `time_after()` and `>= GFX_SLICE_PERIOD_MS`. [F470, F483, F484, F493, F497]
- Use 64-bit shifts `1ULL << bit_width` in `amdgpu_gfx_create_bitmask()` and `1ull << ...` in `amdgpu_gfx_enable_kcq()`; guard `num_xcc_per_xcp ? num_xcc_per_xcp : 1` before `%` in `amdgpu_gfx_is_master_xcc()`. [F486, F487, F488]
- In `amdgpu_display_framebuffer_init()`, verify `handles[i] == handles[0]` before `convert_tiling_flags_to_modifier*()` and set `rfb->base.obj[i] = rfb->base.obj[0]` after. In `extract_render_dcc_offset()`, check `size >= 40 && metadata[0] == 1` and cast `metadata[7,9]` to `u64` before shifting. In `amdgpu_display_verify_plane()`, guard `plane < format->num_planes`, widen `pitches[plane]` to `uint64_t`, and use `DIV_ROUND_UP(height, block_height)`. In `amdgpu_mode_dumb_create()`, use `DIV_ROUND_UP(args->bpp, 8)` and `(u64)args->pitch * args->height`. In `amdgpu_fru_get_product_info()`, mask length with `pia[addr] & 0x3F`, check `addr + 1 < len` (not `size`), clamp copy to `sizeof(fru_info->field)`, and NUL-terminate. [F439, F459, F462, F489, F490, F491, F492]
