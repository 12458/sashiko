# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 2)

Core device, buffer object (BO), execution queue, and diagnostic infrastructure for the Intel Xe DRM driver, implementing TTM buffer allocation and eviction, DMA-BUF import/export, DRM file/client tracking, workload submission (`xe_exec` and execlist backend), forcewake domain management, EU stall telemetry streaming, devcoredump crash snapshots, and configfs/debugfs/sysfs interfaces.

## Architecture & Data Flow

- `XE_BO_FLAG_{SYSTEM,VRAM0,VRAM1}` must stay contiguous (`xe_gem_create_ioctl()` shifts `args->placement`). In `try_add_system()`, when `bo_flags` has both `SYSTEM` and `VRAM_MASK`, `XE_PL_TT` must set `TTM_PL_FLAG_FALLBACK`. In `struct xe_ttm_tt`, `struct ttm_tt ttm` must stay at offset 0 (`xe_ttm_tt_destroy()` passes `struct ttm_tt *` to `kfree()`). Imported DMA-BUF checks in `xe_ttm_bo_is_imported()` and `xe_ttm_tt_{populate,unpopulate}()` require `TTM_TT_FLAG_EXTERNAL` set and `TTM_TT_FLAG_EXTERNAL_MAPPABLE` clear. [F58, F103, F120, F131]
- In `xe_ttm_tt_populate()`, backed-up `ttm_tt`s (`ttm_tt_is_backed_up(tt)`) call `ttm_tt_restore()` only when `!xe_tt->purgeable`; if `purgeable`, call `ttm_tt_clear_backed_up(tt)` before allocating pages and reset `purgeable = false`. `xe->mem.shrinker` counts must update via `xe_ttm_tt_account_{add,subtract}()` whenever a mappable `ttm_tt` is populated, unpopulated, shrunken, or pinned/unpinned or has `purgeable` mutated while populated. [F61, F68]
- `xe_bo_evict_all()` must evict GPU-migrated BOs (user, `xe->pinned.late.{external,kernel_bo_present}`) and call `xe_tile_migrate_wait()` before evicting `xe->pinned.early.kernel_bo_present` via CPU `memcpy`, restoring in reverse (`xe_bo_restore_early()` before GT init, `xe_bo_restore_late()` after) via `xe_bo_restore_and_map_ggtt()` back to `.kernel_bo_present`. In `xe_bo_evict_all_user()`, `!IS_DGFX(xe) && xe_device_has_flat_ccs(xe)` must not skip `XE_PL_TT`. [F65, F153, F154]
- `xe_bo_cpu_fault{_fastpath,}()` must check `xe_ttm_bo_is_imported()`, `xe_bo_fault_migrate()`, and `DMA_RESV_USAGE_KERNEL` fences before `__xe_bo_cpu_fault()`; in `xe_bo_cpu_fault()`, when `retry_after_wait` is true after `mmap_read_unlock()`, skip `__xe_bo_cpu_fault()` and return `VM_FAULT_RETRY`. `__xe_bo_cpu_fault()` links VRAM BOs into `vram_userfault.list` under `vram_userfault.lock`, which `xe_bo_move_notify()`, `xe_bo_runtime_pm_release_mmap_offset()`, and `xe_ttm_bo_destroy()` must unlink. [F62, F71, F184]
- `__xe_exec_queue_alloc()` must allocate `struct_size(q, lrc, width)`, set `q->width = width` before accessing `q->lrc`, and run `exec_queue_user_extensions()` before `__xe_exec_queue_init()`, while `xe_pxp_exec_queue_add()` runs after `__xe_exec_queue_init()`. In `calc_validate_logical_mask()`, bound `args->width * args->num_placements` to `[1, XE_HW_ENGINE_MAX_INSTANCE]` before copying `eci` (indexed `j * width + i`, lane `i > 0` having `current_mask == prev_mask << 1`). [F78, F91, F92]
- `vf_update_device_info()` clears VF-unsupported flags (`probe_display`, `has_heci_{cscfi,gscfi}`, `has_late_bind`) and sets `skip_{guc_pc,pcode}` after `xe_sriov_probe_early()` before PCODE/display probe; PF-only sysfs/debugfs (`auto_link_downgrade_attr_group`, `late_bind_attr_group`, `debugfs_residencies`) require `!IS_SRIOV_VF(xe)`. `xe_ttm_{sys,stolen}_mgr_init()` must run right before `xe_display_init_early()`. `wedged_mode_set()` must call `xe_guc_ads_scheduler_policy_toggle_reset()` on all GTs; `xe_device_declare_wedged()` must set `xe->needs_flr_on_fini = true`, wedge all GTs, and send `drm_dev_wedged_event()`. [F82, F148, F149, F151]
- `xe_devcoredump()` sets `coredump->captured = true` until `xe_devcoredump_free()` cancels `snapshot.work`, frees buffers, zeroes `snapshot`, and resets `captured = false`. `xe_devcoredump_deferred_snap_work()` frees `ss` only when `ss->read.size <= XE_DEVCOREDUMP_CHUNK_MAX`; otherwise `xe_devcoredump_read()` indexes `ss->read.buffer` via `div_u64_rem(offset, XE_DEVCOREDUMP_CHUNK_MAX, &chunk_offset)` after repopulating the chunk. In `xe_eu_stall.c`, size `stream->xecore_buf` and `stream->bo` by `xe_gt_topology_mask_last_dss(all_xecores) + 1`; `xecore_buf->{read,write}` keep an overflow bit masked by `(buf_size << 1) - 1` (updated with `XEHPC_EUSTALL_REPORT1`), while `vaddr` offsets use `buf_size - 1`, and `read_data_size == 0` in `xe_eu_stall_data_buf_read()` must `goto exit_drop`. [F75, F76, F80, F87, F88, F100, F116]

## Synchronization

- In BO creators taking a caller-locked `@vm` (`__xe_bo_create_locked()`, `xe_bo_create_user()`, `xe_bo_create_pin_map_at_aligned()`), exit/error paths must use `xe_bo_unlock_vm_held(bo)` (not `xe_bo_unlock(bo)`). `xe_ttm_bo_lock_in_destructor()` must call `dma_resv_trylock(ttm_bo->base.resv)` under `ttm_bo->bdev->lru_lock`. `xe_bo_addr()` requires holding `bo->ttm.base.resv` unless `READ_ONCE(bo->ttm.pin_count) != 0`. [F4, F31, F32]
- `xe_bo_put()` sleeps and takes reclaim-tainted locks, so atomic/spinlock/reclaim contexts must use `xe_bo_put_deferred()` + `xe_bo_put_commit()` or `xe_bo_put_async()`. In `show_meminfo()`, locking `bo` under `file->table_lock` or `client->bos_lock` must try `dma_resv_trylock()` first and, on failure, hold `kref_get_unless_zero()` while dropping the spinlock for `xe_bo_lock(bo, false)`, releasing via `xe_bo_put_deferred()` (never `xe_bo_put()` while unlocked). [F111, F166, F171]
- `xe_bo_init_locked()` must wait for `DMA_RESV_USAGE_KERNEL` fences on `ttm_bo_type_kernel` BOs, and `xe_bo_fault_migrate()` must wait/test `DMA_RESV_USAGE_KERNEL` via `xe_bo_wait_usage_kernel()` before `ttm_bo_populate()`. In `xe_bo_move()`, use `xe_pm_runtime_get_noresume(xe)` when `!xe_rpm_reclaim_safe(xe)`. `xe_bo_apply_to_pinned()` drops `xe->pinned.lock` around `pinned_fn(bo)`, so `xe_bo_notifier_prepare_pinned()` must recheck `xe_bo_is_pinned(bo)` after locking `bo`, and `xe_bo_apply_to_pinned()` must check `!list_empty(&bo->pinned_link)` after re-locking. [F21, F22, F66, F176, F183]
- In `xe_exec_ioctl()`, wait on `xe->pm_block` before `xe_validation_exec_lock()`. Lock order: `group->mode_sem`, `vm->lock` (write-locked for `xe_vm_userptr_pin(vm)` when `xe_vm_userptr_check_repin(vm)`, then downgraded to read), `xe_validation_exec_lock()`, and innermost `xe_svm_notifier_lock_interruptible(vm)` (held across `__xe_vm_userptr_needs_repin(vm)` and `xe_sched_job_arm(job)`, retrying on `-EAGAIN`) and `xe->ttm.lru_lock`. [F40, F152, F174]
- `xe_exec_queue_last_fence_{get,put,set,test_dep}()` require `vm->lock` for `EXEC_QUEUE_FLAG_VM` queues, or `vm` resv lock + `mode_sem` otherwise. `xef->exec_queue.pending_removal` is incremented on `xa_erase()` in `xe_exec_queue_destroy_ioctl()` and decremented in `xe_exec_queue_fini()` only after `xe_exec_queue_update_run_ticks()`. `xe_exec_queue_jobs_ring_restore()` holds spinlock `sched->base.job_list_lock` across `q->ring_ops->emit_job(job)`, which must not sleep. [F24, F173, F182]
- `__start_lrc()` needs `wmb()` after LRC memory writes before MMIO writes. `xe_execlist_port.lock` is taken in hardirq, so non-IRQ callers must use `spin_lock_irq{,save}()`, and `xe_execlist_port_destroy()` must delete `port->irq_fail` and clear `port->hwe->irq_handler` under `xe->irq.lock` before `xe_lrc_put()`. `xe_force_wake_{get,put}()` hold `fw->lock` (`spin_lock_irqsave`) across `__domain_wait()`, requiring `atomic = true` in `xe_mmio_wait32()`. [F28, F41, F164, F165]
- `gt->eu_stall->stream_lock` nests outside `stream->xecore_buf_lock` and is held across `cancel_delayed_work_sync(&stream->buf_poll_work)` in `xe_eu_stall_disable_locked()` (which disables `XEHPC_EUSTALL_BASE` and cancels work before dropping `XE_FW_RENDER` forcewake/RPM), so `eu_stall_data_buf_poll_work_fn()` must never take `stream_lock`. `xe_devcoredump()` / `devcoredump_snapshot()` run under `dma_fence_begin_signalling()` and reclaim-tainted `coredump->lock` (no `GFP_KERNEL` or `dev_coredumpm_timeout()`), and `flush_work()`, `cancel_work_sync()`, and `xe_pm_runtime_get()` in `xe_devcoredump_{read,free}()` must run outside `coredump->lock`. [F27, F167, F168, F177]

## Object Lifetimes

- TTM callbacks and shrinker paths (`xe_evict_flags()`, `xe_bo_eviction_valuable()`, `xe_bo_shrink()`, `xe_ttm_bo_{release,delete_mem}_notify()`) must check `xe_bo_is_xe_bo(tbo)` (excluding ghost BOs), and eviction/shrinker paths must take `xe_bo_get_unless_zero()` before accessing `struct xe_bo` fields. `__xe_bo_create_locked()` and `xe_ttm_bo_destroy()` take/put `bo->vm` only when `bo->vm && xe_bo_is_user(bo)` (never clear `XE_BO_FLAG_USER` early). Non-fault-mode VM user BOs must clear `vm->lru_bulk_move` via `ttm_bo_set_bulk_move(&bo->ttm, NULL)` under BO/VM lock on error or `xe_gem_object_close()`. `xe_gem_prime_import()` must complete `xe_bo_alloc()` and `dma_buf_dynamic_attach()` before `xe_dma_buf_init_obj()`. [F2, F5, F20, F72, F132]
- `bo->backup_obj` holds `backup->parent_obj = xe_bo_get(bo)`; removal (`xe_bo_notifier_unprepare_pinned()`, `xe_bo_restore_pinned()`, `xe_bo_unpin()`) must unpin if pinned, call `xe_bo_put()`, and set `bo->backup_obj = NULL`. `xe_bo_evict_pinned_copy()` / `xe_bo_restore_pinned()` always `xe_bo_vunmap(backup)` on exit, but unmap `bo` only if `iosys_map_is_null(&bo->vmap)` was true on entry. `xe_bo_dma_unmap_pinned()`, `xe_ttm_bo_delete_mem_notify()`, and `xe_tt_unmap_sg()` must set both `ttm_bo->sg = NULL` and `xe_tt->sg = NULL`. [F6, F12, F119]
- Managed kernel BO cleanup (`xe_bo_pinned_fini()`, `__xe_bo_unpin_map_no_vm()`) must use `devm_add_action_or_reset()` to run before `xe_device_destroy()` calls `xe_bo_dev_fini()` and `ttm_device_fini()` via `drmm`. `xe_device_remove()` must call `drm_dev_unplug()` before `xe_bo_pci_dev_remove_all()`. [F29, F150, F161]
- In `xe_exec_queue_create_ioctl()`, `xa_alloc(&xef->exec_queue.xa, ...)` must be last, calling `xe_exec_queue_kill(q)` before `xe_exec_queue_put(q)` on failure. `xe_exec_queue_destroy()` iterates `&q->multi_gt_list` only when `!(q->flags & EXEC_QUEUE_FLAG_BIND_ENGINE_CHILD)`. In `xe_exec_ioctl()`, errors before `xe_sched_job_arm(job)` must call `xe_sched_job_put(job)`, never after. `xe_dep_scheduler_fini()` calls `drm_sched_entity_fini()` before `drm_sched_fini()` and frees via `kfree_rcu()`. `xe_eu_stall_stream_free()` must reset `gt->eu_stall->stream = NULL` and `drm_dev_put()`; `find_xe_config_group_device()` callers must `config_group_put(&dev->group)`. [F9, F13, F14, F15, F112, F201]

## API Contracts

- Translate `XE_FORCEWAKE_ALL` to `fw->initialized_domains` before `for_each_fw_domain_masked()` and never pass it to `xe_force_wake_{ref,assert_held}()`. `xe_force_wake_get(fw, XE_FORCEWAKE_ALL)` callers must check `xe_force_wake_ref_has_domain(fw_ref, XE_FORCEWAKE_ALL)` and still call `xe_force_wake_put(fw, fw_ref)` on failure; failed `domain_wake_wait()` must decrement `domain->ref` to 0 and clear `BIT(domain->id)` from `fw->awake_domains` and `ref_incr`. [F43, F79, F98, F127]
- `xe_bo_init_locked()` rejects `XE_BO_FLAG_GGTTx` without `XE_BO_FLAG_GGTT` (`-EINVAL`) and rejects unaligned `ttm_bo_type_device` `size` (rounding up only kernel/sg BOs). `xe_bo_ggtt_addr(bo)` requires `bo->tile != NULL` (else `__xe_bo_ggtt_addr(bo, tile_id)`). Pass `offset = ~0ull` (not `0`) to `xe_bo_create_pin_map_at_{novm,aligned}()` for unconstrained placement. `xe_bo_vmap()` requires `XE_BO_FLAG_NEEDS_CPU_ACCESS`, `force_contiguous(bo->flags)`, and holding `bo->ttm.base.resv`. [F47, F50, F51, F95, F181]
- `xe_managed_bo_reinit_in_vram()` requires `!(*src)->vmap.is_iomem` and replaces `*src` (refresh cached BO/GGTT pointers). `xe_bo_validate()` returns 0 if `xe_bo_is_pinned(bo)`, and `xe_dma_buf_pin()` passes `in_place = true` to `xe_bo_pin_external()`. In `xe_bo_move()`, call `xe_bo_move_notify()` for `ttm_bo_type_sg` only when `new_mem->mem_type == XE_PL_SYSTEM` (and `dma_buf_move_notify()` only when `dma_buf && !import_attach`), and call `ttm_bo_move_accel_cleanup()` only when `!move_lacks_source` (else `dma_resv_add_fence` + `ttm_bo_move_null()`). [F59, F60, F69, F141, F188]
- `xe_gem_prime_export()` rejects `bo->vm != NULL` (`-EPERM`) and calls `ttm_bo_setup_export()` first; `xe_dma_buf_unmap()` frees VRAM P2P tables (`!sg_page(sgt->sgl)`) via `xe_ttm_vram_mgr_free_sgt()`. `xe_ttm_access_memory()` returns positive `len` on success, while `xe_bo_read()` returns `0` or `-EIO`. Bound `gt_id` by `tile_count * max_gt_per_tile` (never `XE_MAX_GT_PER_TILE`) and NULL-check `xe_device_get_gt()`. `xe_device_wmb()` does `wmb()` plus DGFX `VF_CAP_REG` write; `xe_sg_segment_size()` halves `min(UINT_MAX, dma_max_mapping_size(dev))`. [F49, F97, F178, F180, F190, F192]
- In `xe_exec_ioctl()`, non-zero `args->num_batch_buffer` must equal `q->width`, and `args->address` is a user pointer when `q->width > 1` (`xe_exec_queue_is_parallel(q)`) or a direct `u64` when `q->width == 1`. `devcoredump_snapshot()` must use `q->vm->xef->{process_name,pid}` (not `current`); `__xe_devcoredump_read()` printers must be idempotent, and `xe_print_blob_ascii85()` requires 4-byte aligned offset/size. [F90, F142, F143, F204]

## Error Handling

- `xe_bo_alloc()` returns `ERR_PTR(-ENOMEM)`; call `xe_bo_free(bo)` only before `xe_bo_init_locked()` / `xe_dma_buf_init_obj()`. In `xe_validation_guard()` loops, unlock and put `bo` before `drm_exec_retry_on_contention()` or `xe_validation_retry_on_oom()`. In `xe_bo_evict_pinned()`, set `bo->backup_obj` only after copy/fence succeeds and `xe_bo_put(backup)` on error only if `backup_created`. Failures after `__xe_exec_queue_init(q)` in `xe_exec_queue_create()` must call `__xe_exec_queue_fini(q)` before `__xe_exec_queue_free(q)`. `xe_eu_stall_stream_read_locked()` returns `total_size` if `total_size > 0` even on later `ret < 0`. Validate ioctl args with `XE_IOCTL_DBG()` (never `WARN_ON()`/`xe_assert()`). [F8, F45, F52, F54, F115, F197]

## External Contracts

- `xe_drm_{compat_}ioctl()` returns `-ECANCELED` if `xe_device_wedged(xe)`. User extension parsers must cap depth at `MAX_USER_EXTENSIONS` (`-E2BIG`), reject `pad != 0` (`-EINVAL`), and use `array_index_nospec()`. `exec_queue_set_priority()` returns `-EINVAL` above `HIGH` and `-EPERM` above `xe_exec_queue_device_get_max_priority(xe)` (`CAP_SYS_NICE`). `args->handle` must be `0` in `xe_gem_create_ioctl()` and for `DRM_XE_MMAP_OFFSET_FLAG_PCI_BARRIER` in `xe_gem_mmap_offset_ioctl()` (`-EINVAL`); `xe_pci_barrier_mmap()` requires `IS_DGFX(xe)`, size `<= SZ_4K`, `!is_cow_mapping()`, and `!(vm_flags & (VM_READ | VM_EXEC))`, clearing `VM_MAYREAD | VM_MAYEXEC`. Configfs store handlers require `dev->lock` and `!is_bound(dev)` (`-EBUSY`). [F57, F96, F195, F198, F199, F200, F205]

## Known Pitfalls

- `xe_bo_is_vram()` includes `XE_PL_STOLEN`, so `mem_type_is_vram()` excludes it and `xe_ttm_io_mem_pfn()` / `vram_region_gpu_offset()` must branch on `XE_PL_STOLEN` before `res_to_mem_region()`. In `xe_bo_move()`, `tt_has_data` must test `ttm_tt_is_populated(ttm) || ttm_tt_is_swapped(ttm)` (not `TTM_TT_FLAG_SWAPPED`). [F104, F109]
- Prevent 32-bit overflow: check `args->size > SIZE_MAX` in `xe_gem_create_ioctl()`; use `mul_u32_u32()` in `xe_bo_dumb_create()`; cast `unsigned long` page counts/offsets to `u64` before `<< PAGE_SHIFT` in `xe_tt_map_sg()` / `xe_ttm_io_mem_pfn()`; and use `DIV_ROUND_UP_ULL()` / `DIV_ROUND_UP()` in `xe_device_ccs_bytes()` / `xe_ttm_tt_create()`. [F121, F122, F123, F125]
- In `xe_exec_ioctl()`, non-retryable `-EWOULDBLOCK`/`-EAGAIN` paths (e.g., `xe_exec_queue_ring_full(q)`) must set `skip_retry = true`. `xe_exec_queue_num_job_inflight()` computes `next_seqno - xe_lrc_seqno(lrc) - 1` as 32-bit modular `s32`. In `xe_ttm_access_memory()`, call `xe_res_next()` only when `bytes_left != 0`. In `clear_dropped_eviction_line_bit()`, use `_MASKED_BIT_DISABLE` on `GRAPHICS_VER(xe) >= 20` and `_MASKED_BIT_ENABLE` on `< 20`. [F113, F117, F128, F157]
