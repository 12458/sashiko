# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 6)

Implements PCI/HCA lifecycle (`main.c`), FW 4KB page allocation (`pagealloc.c`), MSI-X IRQ pools (`pci_irq.c`), SR-IOV VFs (`sriov.c`), Subfunctions (`sf/`), HW object wrappers (`port.c`, `qos.c`, `rl.c`, `rdma.c`), and HWS actions, STE pools, buddy allocator, and BWC matchers/rules (`steering/hws/`).

## Architecture & Data Flow

- Every `enum mlx5_cap_type` passed to `mlx5_core_get_caps*()` must be in `types[]` (`main.c`). In `handle_hca_cap()`, enable `uar_4k` only when `MLX5_CAP_GEN_MAX(dev, uar_4k)` and `PAGE_SIZE > 4096` (`log_uar_page_sz = PAGE_SHIFT - 12`, `cache_line_128byte = (cache_line_size() >= 128)`). [F588, F697]
- In `pagealloc.c`, `fw_page->free_count`, `bitmask`, and `dev->priv.free_list` stay in lockstep: `insert_page()` sets bits `[0, MLX5_NUM_4K_IN_PAGE)` to `1` (free) leaving upper bits `0`, so `fwp_fill_manage_pages_out()` must bound `for_each_clear_bit` to `MLX5_NUM_4K_IN_PAGE`; `alloc_4k()` unlinks `fp->list` at `free_count == 0`, `free_4k()` re-adds on 0->1, and `free_fwp()` unlinks only if `in_free_list`. [F582, F665]
- `dev->priv.page_root_xa` and `free_list` are keyed by `get_function(func_id, ec_function)`, so `alloc_4k()` must skip `free_list` entries with `iter->function != function`. `give_pages()`, `reclaim_pages()`, and `release_all_pages()` must adjust both `dev->priv.page_counters[func_type]` and `dev->priv.fw_pages` by the 4KB count (`MLX5_NUM_4K_IN_PAGE - fwp->free_count` on release), and `reclaim_pages()` must check `num_claimed <= npages` first. [F583, F584, F607]
- For SFs (`mlx5_core_is_sf(dev)`), `dev->priv.irq_table` is `NULL`; always use `mlx5_irq_table_get(dev)`. `sf_ctrl_pool`/`sf_comp_pool` stay `NULL` if `irq_pools_init()` lacks vectors (`num_sf_ctrl + 1 > sf_vec_available` or when `!pci_msix_can_alloc_dyn(dev->pdev)` clamps counts to `pci_alloc_irq_vectors()`), so `mlx5_irq_table_get_comp_irq_pool()` and `ctrl_irq_pool_get()` must fall back to `pcif_pool`. [F565, F566, F674]
- In `pcif_pool`, MSI-X vector 0 is static for the async IRQ: call `pci_msix_alloc_irq_at()`/`pci_msix_free_irq()` only when index != 0 and `pci_msix_can_alloc_dyn(dev->pdev)`. `mlx5_irq_request_vector()` adds `MLX5_IRQ_VEC_COMP_BASE` (`1`) unless `!pool->xa_num_irqs.max` (single-IRQ mode: offset `0`, `mlx5_irq_table_get_num_comp()` returns `1`). `mlx5_irq_pool_is_sf_pool()` checks `!strncmp("mlx5_sf", pool->name, 7)`, and `pool->name` is `MLX5_MAX_IRQ_NAME - MLX5_MAX_IRQ_IDX_CHARS` bytes. [F614, F664, F675]
- SR-IOV `vf` indices (`sriov->vfs_ctx[]`) are 0-based, FW function IDs are `vf + 1`, and EC VF vports are `mlx5_core_ec_vf_vport_base(dev) + vf` (`+ func - 1` in `mlx5_core_func_to_vport()`). `mlx5_sf_hw_vhca_event()` and `mlx5_sf_dev_state_change_handler()` must check `event->function_id` is in `[base_id, base_id + max_fn)` before subtracting `base_id`. `mlx5_sf_dev_table::sf_bar_length` must be `u64`, and `MLX5_ADEV_NAME` must equal `KBUILD_MODNAME`. [F613, F615, F642, F679]
- `mlx5_query_module_eeprom()` must clamp `size` to `MLX5_EEPROM_PAGE_LENGTH - offset`, and `mlx5_query_mcia()` must clamp `params->size` to `mlx5_mcia_max_bytes(dev)` (48 or 128). [F609]
- In `mlx5hws_buddy_mem`, `max_order < 31`, and `bitmap`/`num_free` have `max_order + 1` entries (`bitmap[i]` has `1 << (max_order - i)` bits). `mlx5hws_buddy_alloc_mem()` shifts `seg << order`, `mlx5hws_buddy_free_mem()` shifts `seg >> order`, and every `bitmap[order]` change must update `num_free[order]` in lockstep. [F599, F616, F647]
- For `MLX5HWS_TABLE_TYPE_FDB`, `mlx5hws_action_alloc_single_stc()` and `mlx5hws_action_free_single_stc()` must modify both `mlx5hws_pool_get_base_id()` and `mlx5hws_pool_get_base_mirror_id()` at `stc->offset`, resetting `obj_0_id` to `DROP` if mirror modify fails. [F601]
- `hws_action_handle_tunnel_l3_to_l2()` allows only 14B or 18B headers for `mlx5hws_action_prepare_decap_l3_data()`. `mlx5hws_action_create_dest_match_range()` must reject `min > 0xffff || max > 0xffff` and write `htonl(min << 16)` / `htonl(max << 16)`. In `hws_action_modify_write()`, `for (i = 0, j = 0; j < num_of_actions; i++, j++)` must test `BIT(i) & nop_locations` on source `i` and increment destination `j`. [F622, F623, F634]
- In HWS WQE setters, host-endian `arg_idx`, `stc.offset`, and `num_of_actions << 29` require `htonl()`, whereas `push_vlan.vlan_hdr` and `MLX5_ADDR_OF(set_action_in, single_action, data)` are already `__be32`. `mlx5hws_action_template_process()` reserves `at->setters[0]` for jumbo STE jump-to-action and starts at `at->setters + 1`. [F624, F625]
- `mlx5hws_bwc_rule_create()` must verify `mlx5hws_context_bwc_supported(ctx)` (`queues >= 1`) before `hws_bwc_gen_queue_idx(ctx)`. `mlx5hws_bwc_rule_action_update()` must walk `while (bwc_rule->next_subrule) bwc_rule = bwc_rule->next_subrule;` before `hws_bwc_rule_action_update()`. [F604, F646]
- `mlx5hws_bwc_matcher::priority` must be `u32`. `hws_bwc_matcher_find_at()` starts at `i = 1` (skipping `at[0]`) and matches only when both `action_type_arr[j] == MLX5HWS_ACTION_TYP_LAST` and `rule_actions[j]` is at the end. `hws_bwc_matcher_extend_at()` must reject `size_of_at_array >= MLX5HWS_MATCHER_MAX_AT`, halve `size_of_at_array` if `krealloc()` fails, and increment `num_of_at` only after `mlx5hws_action_template_create()` succeeds. [F571, F618, F633, F640]
- Jiffies deadlines in `wait_fw_init()`, `mlx5_reclaim_root_pages()`, `mlx5_wait_for_pages()`, `mlx5hws_bwc_queue_poll()`, and `hws_action_ste_pool_element_collect_stale()` must use `unsigned long` and `time_after()`/`time_before()`. `mlx5_reclaim_root_pages()` and `mlx5_wait_for_pages()` refresh `end` on progress; `mlx5hws_bwc_queue_poll()` clears `queue_full = false` and subtracts `ret` from `*pending_rules` when `ret > 0`, sets `got_comp = !!ret`, and returns `-ETIMEDOUT` when `!got_comp && time_after(jiffies, timeout)`. [F635, F636, F653]

## Synchronization

- Acquire `devl_lock(priv_to_devlink(dev))` before `dev->intf_state_mutex` (`devl_assert_locked()` in `mlx5_load_one_devl_locked()`/`mlx5_unload_one_devl_locked()`). Removal/shutdown (`remove_one()`, `shutdown()`, `mlx5_sf_dev_remove()`, `mlx5_sf_dev_shutdown()`) must `set_bit(MLX5_BREAK_FW_WAIT, &dev->intf_state)` before draining `fw_reset` or `health` workqueues. [F539, F541]
- `dev->priv.page_root_xa` and `free_list` have no lock: runtime `PAGE_REQUEST` work runs on single-threaded `dev->priv.pg_wq`, and `mlx5_pagealloc_stop()` must unregister `pg_nb` and flush `pg_wq` before `mlx5_reclaim_startup_pages()`. `reclaim_pages_cmd()` must call `mlx5_cmd_do()` unconditionally and fall back to RB-tree reclamation on `-ENXIO`. [F543, F544]
- `req_pages_handler()` and `mlx5_vhca_state_change_notifier()` run in atomic EQ context: allocate work with `GFP_ATOMIC` and defer FW commands to `pg_wq` or `vhca_events`. Queue VHCA/SF active works to `handler[function_id % MLX5_DEV_MAX_WQS].wq`, and `mlx5_sf_dev_add_active_work()` must check `!xa_load(&work_ctx->table->devices, work_ctx->sf_index)` before `mlx5_sf_dev_add()`. [F549, F682]
- `mlx5_sf_table::sf_state_lock` protects `sf->hw_state` and `table->function_ids` in `mlx5_sf_vhca_event()`, `mlx5_sf_mdev_event()`, and `mlx5_sf_dealloc()`. When `sf->hw_state != MLX5_VHCA_STATE_ALLOCATED`, `mlx5_sf_dealloc()` must call `mlx5_sf_hw_table_sf_deferred_free()` (`pending_delete = true`, `allocated = true`); `mlx5_sf_hw_table::table_lock` serializes `allocated`/`pending_delete` and `mlx5_cmd_alloc_sf()`/`mlx5_cmd_dealloc_sf()`. [F552, F553, F592]
- `mlx5hws_action_ste_pool::lock` protects `elem->available` and `elem->full`: chunk alloc/free must move `action_tbl->list_node` between `elem->full` (when `mlx5hws_pool_empty()`) and `elem->available` and update `last_used = jiffies` under `pool->lock`; `hws_action_ste_pool_cleanup()` must destroy stale tables via `hws_action_ste_table_cleanup_list()` after unlocking `p->lock`; `mlx5hws_action_ste_pool_uninit()` must call `cancel_delayed_work_sync(&ctx->action_ste_cleanup)` first. [F535, F554, F600]
- `ctx->bwc_send_queue_locks[idx]` protects `ctx->send_queue[mlx5hws_bwc_get_queue_id(ctx, idx)]` and `bwc_matcher->rules[idx]`. `mlx5hws_bwc_rule_create_simple()` calls `hws_bwc_rule_list_add()` only after `hws_bwc_rule_create_sync()` succeeds under `queue_lock`; `mlx5hws_bwc_rule_destroy_simple()` and `hws_bwc_rule_action_update()` lock `bwc_rule->bwc_queue_idx`, and `hws_bwc_rule_list_remove()` must run before `hws_bwc_rule_cnt_dec_with_shrink()` drops `queue_lock`. [F556, F558]
- To extend `bwc_matcher->at` or resize/rehash `bwc_matcher->matcher`, unlock `queue_lock`, lock all BWC queues via `hws_bwc_lock_all_queues(ctx)`, revalidate (`hws_bwc_matcher_find_at()`, `rehash_required`, or `num_of_rules`), and unlock via `hws_bwc_unlock_all_queues(ctx)`. [F557, F658]

## Object Lifetimes

- In `mlx5_init_one_devl_locked()`, skip `mlx5_devlink_params_register()` and `mlx5_devlink_params_unregister()` when `mlx5_dev_is_lightweight(dev)`. Start health poll only after `mlx5_core_enable_hca()`, stop it before `mlx5_core_disable_hca()`, restart it in `mlx5_try_fast_unload()` if both teardown commands fail, and call `mlx5_drain_health_wq(dev)` in `mlx5_pci_close()` before `iounmap(dev->iseg)` / `release_bar()`. [F520, F521, F542, F668]
- `mlx5_irq_attach_nb()` must call `irq_get(irq)` before registering `nb`, and `mlx5_irq_detach_nb()` must unregister `nb` before `mlx5_irq_put(irq)`. `mlx5_rl_table::rl_lock` protects `table->refcount` and `table->rl_entry`: `find_rl_entry()` skips `dedicated` entries; rate add/remove pairs `mlx5_rl_entry_get()`/`put()` with `mlx5_rl_table_get()`/`put()`, and `mlx5_rl_table_put()` sets `table->rl_entry = NULL` at `refcount == 0`. [F526, F546, F548, F593]
- In `mlx5_sf_dev_add()`, after `auxiliary_device_init(&sf_dev->adev)` succeeds, error paths must call `auxiliary_device_uninit()` (never `mlx5_adev_idx_free()` or `kfree(sf_dev)`). `mlx5_sf_dev_table_destroy()` and `mlx5_sf_dev_table_create()` rollback must call `mlx5_sf_dev_destroy_active_works()`, `mlx5_vhca_event_notifier_unregister()`, and `mlx5_vhca_event_work_queues_flush()` before destroying devices or freeing `table`, and set `dev->priv.sf_dev_table = NULL`. [F530, F531]
- Bulk HWS actions (`mlx5hws_action_create_reformat()`, `mlx5hws_action_create_modify_header()`) share one `arg_id` across an `mlx5hws_action` array: rollback and `hws_action_destroy_hws()` must free per-element STCs/patterns across all initialized elements and destroy `arg_id` once. In `hws_bwc_matcher_move()`, once `mlx5hws_matcher_resize_set_target()` succeeds, even if `hws_bwc_matcher_move_all()` fails, set `bwc_matcher->matcher = new_matcher` and destroy `old_matcher`; re-read `bwc_matcher->matcher` after any call that may rehash or drop `queue_lock`. [F534, F536, F597]

## API Contracts

- `mlx5hws_buddy_alloc_mem()`, `mlx5_sf_hw_table_sf_alloc()`, and `mlx5_flexible_inlen()` (`MLX5_FLEXIBLE_INLEN()`) return non-negative values or negative errno (`int`, check `< 0`). `mlx5_irq_get_locked()` and `irq_get()` return `1` on success and `0` on failure (`!ret`). `mlx5_vf_get_core_dev()` returns `mlx5_core_dev *` (with `intf_state_mutex` held) or `NULL`, never `ERR_PTR`. [F559, F560, F561, F562, F563]
- `rl.c` hardware rate-limit indices are 1-based (`table->rl_entry[index - 1]` in `mlx5_rl_remove_rate_raw()`). `mlx5_max_tc(mdev)` returns `num_tc - 1` (iterate `<= mlx5_max_tc(mdev)`). Callers of `mlx5_get_default_msix_vec_count()` must ensure `num_vfs > 0`. Call `mlx5_sf_coredev_to_adev()` only when `mlx5_core_is_sf(mdev)`, and `mlx5_sf_by_dl_port()` only on SF devlink ports (`mlx5_esw_dl_sf_port_ops`). [F577, F610, F645, F660, F662]
- In `port.c`, `mlx5_query_port_fcs()` initializes `*supported = false` and `*enabled = true` first; query `mlx5_query_port_buffer_ownership()` instead of caching ownership; `mlx5_set_dscp2prio()` and `mlx5_set_port_fcs()` must query the register before modifying in place, and `mlx5_set_port_stall_watermark()` must set `pptx_mask_n`, `pprx_mask_n`, and `ppan_mask_n`. Check `mlx5_qos_element_type_supported()` and `mlx5_qos_tsar_type_supported()` before `mlx5_create_scheduling_element_cmd()`. [F575, F586, F594, F673]
- Pre-initialize `chunk->ste.order` and never pass both `skip_rx` and `skip_tx` to `mlx5hws_action_ste_chunk_alloc()`. Terminate `action_type[]` with `MLX5HWS_ACTION_TYP_LAST` and `rule_actions[]` with NULL `action` or `MLX5HWS_ACTION_TYP_LAST` within `MLX5HWS_BWC_MAX_ACTS`. `mlx5hws_pat_verify_actions()`/`mlx5hws_pat_get_pattern()` take byte sizes (`num_of_actions * MLX5HWS_MODIFY_ACTION_SIZE`), whereas `calc_nop`/`require_reparse`/`create_modify_header_arg` take action counts. Use `bwc_queue_idx` for `bwc_send_queue_locks[]`/`rules[]` and `mlx5hws_bwc_get_queue_id()` for `send_queue[]`/`queue_id`. [F579, F581, F619, F657]

## Error Handling

- In `give_pages()`, on error, free all `i` allocated 4KB subpages via `free_4k()` in reverse order and call `page_notify_fail()` if `notify_fail` is set. `mlx5_access_reg()` calls `mlx5_cmd_check()` only when `verbose` is true. [F523, F711]
- Zero-initialize `u8 mac[ETH_ALEN] = {}` in `mlx5_rdma_add_roce_addr()`, and unwind `mlx5_rdma_del_roce_addr()` / `mlx5_nic_vport_disable_roce()` on failure in `mlx5_rdma_enable_roce()`. In `mlx5_sf_add()`, call `mlx5_sf_function_id_erase(table, sf)` before `mlx5_sf_free()` on error. Guard `name` against `NULL` in `irq_pool_alloc()`. [F527, F528, F567, F572]
- In `hws_action_get_shared_stc_nic()`, jump to `free_shared_stc` on error after `kzalloc()`, and clear `ctx->common_res.shared_stc[stc_type] = NULL` in `hws_action_put_shared_stc()` at `refcount == 0`. [F532]
- In `mlx5hws_bwc_rule_create_simple()`, call `hws_bwc_rule_cnt_dec(bwc_rule)` on every error after `hws_bwc_rule_cnt_inc_with_rehash()`, and return immediately without rehashing on `-EBUSY`, `-ETIMEDOUT`, or `-EAGAIN`. In `hws_bwc_matcher_move_all_simple()`, record the first `move_error` and `continue` without incrementing `pending_rules` when `mlx5hws_matcher_resize_rule_move()` fails, abort on `-ETIMEDOUT`, and return the first non-zero of `move_error`, `poll_error`, `drain_error`. [F538, F569, F627]

## External Contracts

- In `mlx5_sf_dev_probe()`, call `mlx5_core_peer_devlink_set()` before `mlx5_init_one_light()`/`mlx5_init_one()`. `mlx5_sf_activate()` must return `-EBUSY` if an inactive SF has `sf->hw_state != MLX5_VHCA_STATE_ALLOCATED`. [F700, F706]
- In `mlx5hws_action_create_dest_array()`, `MLX5HWS_ACTION_TYP_TBL` destinations must set `fte_attr.ignore_flow_level = 1`, and `is_wire_ft` must be placed at `dest_list[num_dest - 1]`. In `hws_action_fill_stc_attr()`, pass `remove_words.num_of_words` in 2B words (`size / W_SIZE`) and `insert_header.header_size`/`insert_offset` in bytes. [F576, F580]

## Known Pitfalls

- Zero `set_ctx` (`memset(set_ctx, 0, set_sz)`) before each `handle_hca_cap*()` call in `set_hca_cap()`; use `is_roce_fw_disabled(dev)` instead of `MLX5_CAP_GEN(dev, roce)` in `handle_hca_cap_roce()`; use `dev->priv.numa_node` for NUMA allocations. [F573, F585, F587]
- `MLX5_U64_4K_PAGE_MASK` must widen `0U` to `u64` (`((~(u64)0U) << PAGE_SHIFT)`). Clamp negative `npages` with `max_t(s32, npages, MAX_RECLAIM_NPAGES)` in `req_pages_handler()`, and check `req->release_all` before `req->npages` in `pages_work_handler()`. [F606, F629, F641]
- Compute `num_sf_ctrl` with `DIV_ROUND_UP()` in `irq_pools_init()`. In `mlx5_sf_driver` callbacks, get `mdev` via `container_of(adev, struct mlx5_sf_dev, adev)->mdev` (never `pci_get_drvdata()` or `auxiliary_get_drvdata()`). In `mlx5_port_ptys2info()`, widen `u32 eth_proto_oper` to `unsigned long temp` for `find_first_bit()` and check `i < max_size && table[i].speed != 0`. [F611, F651, F661, F667]
- `MLX5HWS_ACTION_TYP_REFORMAT_TNL_L3_TO_L2` uses `action->modify_header` (not `action->reformat`). Index multi-header actions via `rule_action->action + rule_action->reformat.hdr_idx` in `hws_action_setter_insert_ptr()`/`hws_action_setter_tnl_l3_to_l2()`. In `mlx5hws_action_apply_setter()`, run `setter->set_ctr` before `stc_ix[MLX5HWS_ACTION_STC_IDX_CTRL] |= htonl(num_of_actions << 29)`. [F568, F602, F638]

## Other

- Read `&dev->iseg->initializing` and `health->health_counter` with `ioread32be()`, and ignore `0` and `0xffffffff` in `wait_vital()`. [F681]
