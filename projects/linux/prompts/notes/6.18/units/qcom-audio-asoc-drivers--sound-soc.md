# QCOM AUDIO (ASoC) DRIVERS — sound/soc

Qualcomm ASoC platform, CPU DAI, machine, and DSP IPC drivers, plus the WSA884x SoundWire speaker amplifier driver. Covers Low-Power Audio Subsystem (LPASS) direct DMA/CPU/HDMI/CDC-DMA drivers, machine sound card helpers (`common.c`, `apq8016_sbc.c`, `apq8096.c`), and QDSP6 firmware communication for legacy APR services (`q6afe`, `q6adm`) and GPR-based AudioReach graphs (`audioreach.c`).

## Architecture & Data Flow

- Playback and capture on the same MI2S DAI share `LPAIF_I2SCTL_REG(v, id)`, so `lpass_cpu_daiops_hw_params()`, `prepare()`, `trigger()`, and `shutdown()` must only touch `spken`/`spkmode`/`spkmono` for playback and `micen`/`micmode`/`micmono` for capture. In `lpass_cpu_daiops_hw_params()`, multi-line SD modes (`LPAIF_I2SCTL_MODE_QUAD01`, `QUAD23`, `6CH`, `8CH`) must be downgraded only in local `mode` for fewer channels, preserving `drvdata->mi2s_playback_sd_mode[id]` and `mi2s_capture_sd_mode[id]`. [F420, F458]
- `lpass_platform_pcmops_trigger()` and `lpass_dma_interrupt_handler()` must update shared IRQEN registers via `regmap_update_bits()` masked to `LPAIF_IRQ_ALL(ch)` and write IRQCLEAR via `regmap_write_bits()`. `lpass_dma_interrupt_handler()` must check `LPAIF_IRQ_PER(chan)`, `LPAIF_IRQ_XRUN(chan)`, `LPAIF_IRQ_ERR(chan)`, and `val` with separate `if` statements (never `else if`), returning `IRQ_HANDLED` for every matched bit. [F424, F455]
- `lpass_platform_pcmops_open()` and `close()` must keep `drvdata->substream[dma_ch]`, `hdmi_substream[dma_ch]`, `rxtx_substream[dma_ch]`, and `va_substream[dma_ch]` synchronized with `v->alloc_dma_channel()` and `v->free_dma_channel()`, as IRQ handlers only dispatch when the slot is non-NULL. [F423]
- In `struct lpass_data`, HDMI (`hdmiif_map`, `hdmiif_irq`, `hdmi_rd_dmactl`) and Codec DMA (`rxtx_lpaif_map`, `va_lpaif_map`, `rxtx_*_dmactl`, `va_wr_dmactl`) fields exist only when `hdmi_port_enable` or `codec_dma_enable` is set; probe, register, `lpass_platform_pcmops_suspend()`, and `resume()` must check those flags first. Optional `lpass_variant` callbacks (`init`, `exit`, `alloc_dma_channel`, `free_dma_channel`) must also be NULL-checked before calling. [F403, F406]
- `asoc_qcom_lpass_cpu_platform_probe()` must set `platform_set_drvdata(pdev, drvdata)` and `drvdata->variant` before `devm_regmap_init_mmio()` or `variant->init(pdev)`, set `.max_register` on `lpass_cpu_regmap_config`, `lpass_hdmi_regmap_config`, `lpass_rxtx_regmap_config`, and `lpass_va_regmap_config` from `variant` before `devm_regmap_init_mmio()`, and run `variant->init(pdev)` before `asoc_qcom_lpass_platform_register(pdev)`. [F483, F484]
- Because LPASS regmaps use `REGCACHE_FLAT`, `lpass_cpu_regmap_volatile()`, `lpass_rxtx_regmap_volatile()`, and `lpass_va_regmap_volatile()` must return `true` for all `IRQCLEAR`, `IRQSTAT`, `RDMACURR`, and `WRDMACURR` registers, and `lpass_hdmi_regmap_volatile()` must return `true` for `LPASS_HDMITX_APP_IRQSTAT_REG`, `LPASS_HDMI_TX_LEGACY_ADDR`, `LPASS_HDMI_TX_VBIT_CTL_ADDR`, `LPASS_HDMI_TX_PARITY_ADDR`, `LPAIF_HDMI_RDMACURR_REG`, `LPASS_HDMI_TX_DMA_ADDR`, `LPASS_HDMI_TX_CH_LSB_ADDR`, and `LPASS_HDMI_TX_CH_MSB_ADDR`. [F495, F496]
- `struct regmap_field *` members in `struct lpaif_dmactl`, `lpass_dp_metadata_ctl`, and `lpass_sstream_ctl` must match the exact order and count of `struct reg_field` members in `struct lpass_variant` for `devm_regmap_field_bulk_alloc()`. Also, `lpass_variant.dai_driver` arrays must be non-`const` (probe mutates `playback.channels_min`/`max` for `LPAIF_I2SCTL_MODE_QUAD01`), and `LPASS_MAX_PORTS` must be `>= DISPLAY_PORT_RX_7 + 1`. [F436, F438, F520]
- In `audioreach_populate_graph()`, `mp_data->mod_prop_obj[nmodule++]` must be populated via `apm_populate_module_prop_obj()` before `if (!module->max_op_port) continue;`, matching `audioreach_alloc_graph_pkt()`. Also, `mlobj` starts at `&ml_data->mod_list_obj[0]` and must be advanced by `APM_MOD_LIST_OBJ_PSIZE(mlobj, container->num_modules)` after each container because `struct apm_mod_list_obj` has a flexible `mod_cfg[]` array. [F453, F454]
- In `q6adm.c`, `adm->copp_bitmap` has `AFE_MAX_PORTS` `unsigned long` words; `q6adm_alloc_copp()` and `q6adm_free_copp()` must pass `&adm->copp_bitmap[port_idx]` with bit `< MAX_COPPS_PER_PORT`. In `q6afe-dai.c`, `q6afe_dai_prepare()` must call `q6afe_port_stop()` if `is_port_started[dai->id]` is true before restarting, and `q6afe_dai_shutdown()` must only stop when `is_port_started[dai->id]` is true before clearing it. `q6adm_probe()` and `q6afe_probe()` must init locks/lists/waitqueues and `dev_set_drvdata()` before `devm_of_platform_populate()`. [F430, F478, F485]
- In `qcom_snd_parse_of()`, `codec && platform` sets `no_pcm = 1`, `!codec` sets `dynamic = 1`, and `platform || !codec` sets `ignore_suspend` and `nonatomic`. In `apq8016_sbc.c`, `msm8916_qdsp6_startup()`/`shutdown()` must refcount `data->mi2s_clk_count[mi2s]` (`qdsp6_dai_get_lpass_id()`) so `LPAIF_BIT_CLK` is toggled only on first start and last shutdown, and `apq8016_sbc_device_id[].data` must have type `void (*)(struct snd_soc_card *)`. [F433, F452, F481]
- In `wsa884x.c`, `port_enable[]` and `port_prepared[]` are 0-indexed while SoundWire port numbers (`prepare_ch->num`, `wsa884x_pconfig[i].num`, `pdev->m_port_map[1..]`) are 1-based, and `wsa884x_hw_params()` must reset `wsa884x->active_ports = 0` before compacting `port_config`. `wsa884x_probe()` must set `regcache_cache_only(wsa884x->regmap, true)` before registering hwmon/ASoC and keep it cache-only while `SDW_SLAVE_UNATTACHED` until `SDW_SLAVE_ATTACHED`. [F464, F486]

## Synchronization

- In `q6afe.c`, `q6afe_port_get_from_id()` must init `port->wait`, `token`, `id`, `afe`, `cfg_type`, and `refcount` before adding `port->node` to `afe->port_list` under `afe->port_list_lock`. `q6afe_find_port()` must hold `afe->port_list_lock` (`spin_lock_irqsave()`) and call `kref_get(&p->refcount)` before unlocking. Because `q6afe_port_free()` takes `afe->port_list_lock`, never call `kref_put(&port->refcount, q6afe_port_free)` or `q6afe_port_put()` under `afe->port_list_lock`. [F387, F388, F503]
- In `q6adm.c`, all accesses to `adm->copps_list` and `adm->copp_bitmap` (`q6adm_open()`, `q6adm_free_copp()`, `q6adm_find_copp()`, `q6adm_find_matching_copp()`) must hold `adm->copps_list_lock` (`spin_lock_irqsave()`), so `q6adm_alloc_copp()` must use `GFP_ATOMIC` and never sleep. `q6adm_find_copp()` and `q6adm_find_matching_copp()` must call `kref_get(&c->refcount)` under `copps_list_lock`, and callers (`q6adm_callback()`, `q6adm_matrix_map()`) must call `kref_put(&copp->refcount, q6adm_free_copp)` outside `copps_list_lock`. [F390, F391, F501, F502]
- `afe_apr_send_pkt()` (`afe->lock`), `q6adm_apr_send_copp_pkt()` and `q6adm_matrix_map()` (`adm->lock`), and `audioreach_send_cmd_sync()` (`graph->lock` or `gdev->lock`) must hold their command mutex while zeroing `result->opcode` and `result->status`, sending the packet, and waiting on `wait_event_timeout()`. Callbacks (`q6afe_callback()`, `q6adm_callback()`) must never acquire `afe->lock` or `adm->lock`, and callers like `audioreach_map_memory_regions()` must unlock `graph->lock` before calling `audioreach_graph_send_cmd_sync()`. [F389, F392, F393, F463]
- In `lpass-cpu.c`, `lpass_cpu_daiops_trigger()` runs in atomic context and must only call `clk_enable()`/`clk_disable()` on `drvdata->mi2s_bit_clk[id]` unconditionally (never sleeping clock APIs). `lpass_cpu_daiops_startup()`/`shutdown()` handle `clk_prepare()`/`clk_unprepare()`, while `lpass_cpu_daiops_prepare()` enables `mi2s_bit_clk[id]` once guarded by `drvdata->mi2s_was_prepared[id]` (paired with `shutdown()`). [F498, F507]
- In `asoc_qcom_lpass_platform_register()`, host IRQ enable registers must be cleared and all `dmactl` regmap fields (`rd_dmactl`, `wr_dmactl`, `rxtx_rd_dmactl`, `rxtx_wr_dmactl`, `va_wr_dmactl`, `hdmi_rd_dmactl`) and IRQs initialized before `devm_snd_soc_register_component()`. [F395]
- `wsa884x_get_temp()` uses `guard(mutex)(&wsa884x->sp_lock)`: if `pa_on` is true it returns cached `wsa884x->temperature * 1000` without touching registers; if false and `pm_runtime_resume_and_get()` succeeds, every exit path must restore `WSA884X_TADC_VALUE_CTL_TEMP_VALUE_RD_EN_MASK` to 1, reset `WSA884X_PA_FSM_BYP0` to `0x0`, and jump to `out` for `pm_runtime_put_autosuspend()`, only updating `wsa884x->temperature` (in °C, scaled `* 1000` for `*temp`) when strictly between `WSA884X_LOW_TEMP_THRESHOLD` and `WSA884X_HIGH_TEMP_THRESHOLD`. [F385, F426, F466, F499]

## Object Lifetimes

- `audioreach_graph_free_buf()` must hold `graph->lock` while zeroing `num_periods`, calling `kfree(port->buf)`, and setting `port->buf = NULL` for `graph->rx_data` and `graph->tx_data`. [F380]
- Because `lpass_variant.init` callbacks (`apq8016_lpass_init()`, `ipq806x_lpass_init()`, `sc7180_lpass_init()`, `sc7280_lpass_init()`) enable clocks via unmanaged `clk_bulk_prepare_enable()`/`clk_prepare_enable()`, every LPASS CPU `platform_driver` must wire `.remove` to `asoc_qcom_lpass_cpu_platform_remove()` to call `variant->exit(pdev)`. In `apq8016_lpass_init()`, any error after `clk_bulk_prepare_enable()` must jump to `err_ahbix_clk` to call `clk_bulk_disable_unprepare()`. [F383, F488]
- In `wsa884x_probe()`, `regulator_bulk_enable()` must be paired with `devm_add_action_or_reset(dev, wsa884x_regulator_disable, wsa884x->supplies)` before `wsa884x_reset_deassert()` and `devm_add_action_or_reset(dev, wsa884x_reset_powerdown, wsa884x)`. [F386]

## API Contracts

- `__audioreach_alloc_pkt()` and `audioreach_alloc_*_pkt()` return `ERR_PTR(-ENOMEM)` (never `NULL`) and the packet is not freed by `audioreach_send_cmd_sync()`, `audioreach_graph_send_cmd_sync()`, or `gpr_send_port_pkt()`, so callers must check `IS_ERR(pkt)` and call `kfree(pkt)`. `audioreach_alloc_cmd_pkt()` and `audioreach_alloc_apm_cmd_pkt()` include `GPR_HDR_SIZE + APM_CMD_HDR_SIZE`, whereas `audioreach_alloc_pkt()` and `audioreach_alloc_apm_pkt()` include only `GPR_HDR_SIZE`. [F379, F397, F442]
- `audioreach_send_cmd_sync()` takes mutually optional `port` and `gdev`, and `afe_apr_send_pkt()` takes a nullable `port` (`NULL` in `q6afe_set_lpass_clock()` / `q6afe_vote_lpass_core_hw()`), so neither may dereference `port` or `gdev` without a NULL check. In `audioreach.c`, `audioreach_pcm_set_media_format()` and `audioreach_shmem_set_media_format()` must reject `mcfg->num_channels > 4` with `-EINVAL`. [F405, F450]
- In `q6afe.c` and `q6adm.c`, internal lookups (`q6afe_find_port()`, `q6adm_find_copp()`, `q6adm_find_matching_copp()`) return `NULL` when not found, whereas `q6afe_port_get_from_id()`, `q6adm_alloc_copp()`, and `q6adm_open()` return `ERR_PTR`. Because `q6afe_probe()` and `q6adm_probe()` store drvdata on the parent `apr_device`, exported `q6afe`/`q6adm` functions taking a child `struct device *dev` must call `dev_get_drvdata(dev->parent)`. [F398, F477]
- `asoc_qcom_lpass_cpu_platform_probe()` must check `of_parse_phandle(pdev->dev.of_node, "qcom,adsp", 0)` first and, if present, call `of_node_put(dsp_of_node)` and return `-EBUSY`. For `is_cdc_dma_port(dai_id)` streams, LPASS Codec DMA can only access LPM memory, so buffers must be preallocated from `rxtx_cdc_dma_lpm_buf`/`va_cdc_dma_lpm_buf` with `memremap(..., MEMREMAP_WC)`, mmapped via `io_remap_pfn_range()`, and copied via `copy_from_iter_toio()`/`copy_to_iter_fromio()`. [F482, F497]
- In `wsa884x.c`, `wsa884x_get_reset()` must try `devm_reset_control_get_optional_shared(dev, NULL)` first and fall back to `devm_gpiod_get_optional(dev, "powerdown", GPIOD_OUT_HIGH)` only if `sd_reset` is `NULL`. `devm_hwmon_device_register_with_info()` in `wsa884x_probe()` must be guarded by `IS_REACHABLE(CONFIG_HWMON)`, and kcontrol `.put` callbacks (`wsa884x_dev_mode_put()`, `wsa884x_set_swr_port()`) must return `0` if unchanged and `1` if changed. [F494, F513, F516]

## Error Handling

- `q6adm_apr_send_copp_pkt()` and `q6adm_matrix_map()` return positive remaining jiffies on success, so Q6ADM callers (`q6adm_open()`, `q6adm_close()`) must test `ret < 0` rather than `if (ret)`. In `q6adm_open()`, if `q6adm_device_open()` fails after `q6adm_alloc_copp()`, it must release `copp` via `kref_put(&copp->refcount, q6adm_free_copp)` and return `ERR_PTR(ret)`. [F399, F408]
- In `asoc_qcom_lpass_cpu_platform_probe()`, `devm_platform_ioremap_resource_byname()` returns `ERR_PTR` (`IS_ERR()`), whereas `platform_get_resource_byname()` returns `NULL` (`!res`, returning `-EINVAL`). Across LPASS probe/init helpers, every `devm_kzalloc()`/`devm_kcalloc()` return must be NULL-checked before passing to regmap-field or clock-bulk helpers. In `lpass-cdc-dma.c`, callers of `__lpass_get_dmactl_handle()` must initialize `dmactl = NULL` and check `if (!dmactl)`. [F401, F402, F409]
- In `lpass_dma_interrupt_handler()`, `LPAIF_IRQ_XRUN` must use `dev_warn_ratelimited()` and `snd_pcm_stop_xrun(substream)`, while `LPAIF_IRQ_ERR` must call `snd_pcm_stop(substream, SNDRV_PCM_STATE_DISCONNECTED)` after clearing the IRQ. In `wsa884x_get_temp()`, `d1 == d2` must be checked before dividing by `(d2 - d1)` because ignored OTP `regmap_read()` errors leave `d1` and `d2` as `0`. [F465, F519]
- In `qcom_snd_parse_of()`, error exits inside `for_each_available_child_of_node(dev->of_node, np)` must jump to `err_put_np` (before `of_get_child_by_name()`) or `err` (after acquiring `cpu`, `platform`, `codec`) so all `device_node` refs are put without clobbering `ret`. In `qcom_snd_wcd_jack_setup()`, `qcom_snd_dp_jack_setup()`, `apq8016_dai_init()`, and `msm_snd_hw_params()`, `-ENOTSUPP` from `snd_soc_component_set_jack()`, `set_sysclk()`, or `snd_soc_dai_get/set_channel_map()` must be treated as success. [F400, F407]

## External Contracts

- In `lpass_platform_pcmops_prepare()`, `LPAIF_DMABUFF_REG` and `LPAIF_DMAPER_REG` take sizes in 32-bit words minus one (`(bytes >> 2) - 1`), whereas `LPAIF_DMABASE_REG` and `LPAIF_DMACURR_REG` in `lpass_platform_pcmops_pointer()` report byte addresses converted with `bytes_to_frames()`. [F414]
- In `audioreach.c`, compound APM packets (`APM_CMD_GRAPH_OPEN`, multi-parameter `APM_CMD_SET_CFG`) must align each parameter section to 8 bytes (`ALIGN(..., 8)`) and set `param_data->param_size` to the aligned size minus `APM_MODULE_PARAM_DATA_SIZE`. `audioreach_map_memory_regions()` must align `mem_size_bytes` to 4096 (`ALIGN(buf_sz, 4096)`) and split `ab->phys` via `lower_32_bits()`/`upper_32_bits()`, while `audioreach_i2s_set_media_format()` and `audioreach_codec_dma_set_media_format()` must set `intf_cfg->cfg.lpaif_type = module->hw_interface_type`. [F411, F441, F443]
- In `q6tdm_set_channel_map()`, unused `tdm->ch_mapping` entries up to `AFE_PORT_MAX_AUDIO_CHAN_CNT` (8) must be set to `Q6AFE_CMAP_INVALID` (`0xFFFF`). In `qcom_snd_parse_of()`, `"qcom,model"` and `"qcom,audio-routing"` must be parsed as fallbacks alongside `"model"` and `"audio-routing"`. [F447, F448]

## Known Pitfalls

- For capture (WRDMA) channels, `regmap_fields_write()` on `wr_dmactl`, `rxtx_wr_dmactl`, and `va_wr_dmactl` must use the 0-based index (`pcm_data->dma_ch - v->*wrdma_channel_start`) from `__lpass_get_id()` or `__lpass_get_dmactl_handle()`, whereas `LPAIF_DMA*_REG`, `LPAIF_IRQ_ALL()`, and `drvdata->*substream[]` use raw `pcm_data->dma_ch`. Also, when iterating `i` to `variant->num_dai` in `lpass-cpu.c`, `drvdata->mi2s_*` arrays are indexed by `variant->dai_driver[i].id`, while `variant->dai_*_clk_names` are indexed by `i`. [F421, F435]
- In `audioreach.c`, `struct audioreach_module_priv_data` fields (like `module->data->size`) are `__le32` and require `le32_to_cpu()`. Also, because `struct param_id_mfc_media_format` uses `uint16_t channel_mapping[]` while `struct audioreach_module_config` uses `u8 channel_map[]`, `audioreach_mfc_set_media_format()` must size via `APM_MFC_CFG_PSIZE` and copy `channel_map` element-by-element, not with `memcpy()`. [F440, F476]
- In `q6afe-dai.c`, `dai->id & 0x1` distinguishes TX (odd) from RX (even) only for SLIMbus and TDM DAI IDs; Codec DMA DAI IDs (`WSA_CODEC_DMA_RX_0 ... RX_CODEC_DMA_RX_7`) must use explicit case labels. In `q6adm_find_copp()`, `q6adm_find_matching_copp()`, and `q6afe_find_port()`, `list_for_each_entry()` must save a match to a separate `ret = NULL` pointer (and `kref_get()` before unlocking) rather than using the loop cursor after the loop. [F459, F461]
