# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd (part 1)

This component implements core NFSv3 and NFSv4 server procedure handlers, NFSv2/v3/v4 ACL translation, NFSv4 ID mapping, pNFS layout management, NFSv4 backchannel callbacks, client reboot recovery tracking, lockd file-open bindings, netlink server configuration, and local-I/O (LOCALIO) support, along with `struct nfsd_net`.

## Architecture & Data Flow
- In `nfsd4_proc_compound()`, clear `RQ_USEDEFERRAL` in `rqstp->rq_flags` before running ops and restore it on `out:`; inside the loop, call `fh_clear_pre_post_attrs(current_fh)` before each op and `nfsd4_cstate_clear_replay(cstate)` at the end of every iteration; early exits to `out:` after `fh_init` are only safe before `current_fh`/`save_fh` are populated. Helpers indexing `nfsd4_ops[op->opnum]` (`OPDESC`) or `nn->counter` before checking `op->status` must guard against `OP_ILLEGAL`. [F16, F68, F69, F98]
- `nfsd4_savefh()` and `nfsd4_restorefh()` must copy `current_stateid`/`save_stateid` and `SAVED_STATE_ID_FLAG`/`CURRENT_STATE_ID_FLAG` alongside `save_fh`/`current_fh`; ops in `nfsd4_ops[]` replacing `current_fh` without setting a stateid must set `OP_CLEAR_STATEID`. For v4.0 opens (`!nfsd4_has_session`), `nfsd4_set_open_owner_reply_cache()` saves `resfh->fh_handle` into `rp_openfh`, and on `nfserr_replay_me` in `nfsd4_open()`, `current_fh` must be restored from `rp->rp_openfh` via `fh_copy_shallow()` and `fh_verify()`. [F67, F73]
- Whenever `do_open_lookup()` or `nfsd4_create()` sets `current->fs->umask`, reset `current->fs->umask = 0` on all exit paths. In `nfsd4_read()`, if `!nfsd4_last_compound_op(rqstp)`, set `argp->splice_ok = false`. [F70, F71]
- `cb->cb_held_slot` uses `-1` for "no slot held" (`nfsd4_init_cb`, `nfsd41_cb_release_slot`). `se_cb_seq_nr` is 0-indexed up to `ses->se_cb_highest_slot` (clamped to `NFSD_BC_SLOT_TABLE_SIZE - 1` in `update_cb_slot_table`, which resets `se_cb_seq_nr[i] = 1` for newly exposed slots under `ses->se_lock`). `grab_slot` and `highest_slotid` subtract 1 from `ffs`/`fls`, `grab_slot` checks `0 <= idx && idx <= ses->se_cb_highest_slot` before `BIT(idx)`, and `nfsd41_cb_release_slot` checks `cb->cb_held_slot >= 0` before `BIT(cb->cb_held_slot)`. [F50, F57, F85, F126]
- `nfsd4_cb_prepare()` sets `cb->cb_seq_status = 1` and `cb->cb_status = 0` before starting or `-NFS4ERR_DELAY`-restarting a task; on `-NFS4ERR_SEQ_MISORDERED` or `-NFS4ERR_BADSLOT` in `nfsd4_cb_sequence_done()`, call `nfsd4_mark_cb_fault()` and set `cb->cb_held_slot = -1` before `nfsd41_cb_release_slot()`. `nfs4_cb_fattr` (`NFSPROC4_CLNT_CB_GETATTR`) must be embedded at `nfs4_delegation.dl_cb_fattr`, and `nfsd4_cb_offload` (`nfsd4_cb_offload_ops`) at `nfsd4_copy.cp_cb_offload`. [F59, F60, F133]
- `nfsd4_layout_verify` must check `layout_type >= LAYOUT_TYPE_MAX` before `1 << layout_type` and indexing `nfsd4_layout_ops`. In `nfsd4_layoutcommit`, gate `lcp->lc_last_wr` on `lcp->lc_newoffset` and `ls` lookup/put on `!lcp->lc_reclaim`. `layout_end` saturates `seg->offset + seg->length` to `NFS4_MAX_UINT64` on wraparound, and `layout_update_len` keeps `lo->length = NFS4_MAX_UINT64` when `end == NFS4_MAX_UINT64`. [F37, F120, F125]
- Setting `ls->ls_recalled = true` in `nfsd4_recall_file_layout()` pairs with `atomic_inc(&fi->fi_lo_recalls)` under `ls->ls_lock`, and `nfsd4_free_layout_stateid()` decrements `fi_lo_recalls` iff `ls->ls_recalled`. When `nfsd4_return_file_layouts()` empties `ls->ls_layouts` under `ls->ls_lock`, set `SC_STATUS_CLOSED` and `lrp->lrs_present = false`; else set `lrp->lrs_present = true` and (if `found > 0`) `nfs4_inc_and_copy_stateid()`. [F64, F66]
- `nfsd3_init_dirlist_pages` clamps `count >= (u32)(XDR_UNIT * 2)` before subtracting `XDR_UNIT * 2` for `buf->buflen` and advances `rqstp->rq_next_page` by `(buf->buflen + PAGE_SIZE - 1) >> PAGE_SHIFT`; after encoding, `nfsd3_proc_readdir`/`readdirplus` reset `rqstp->rq_next_page = resp->xdr.page_ptr + 1`. In `svcxdr_encode_nfs_fh3`, when `size > 0`, zero `p[XDR_QUADLEN(size) - 1]` before `memcpy`. [F48, F75, F127]
- In `low_mode_from_nfs4`, test `NFS4_READ_MODE`, `write_mode`, and `NFS4_EXECUTE_MODE` with `(perm & mask) == mask`. In `_posix_to_nfsv4_one`, save `ACL_GROUP_OBJ` in `group_owner_entry` before group allow ACEs, then reset `pa = group_owner_entry` to emit group deny ACEs. In `nfsd4_alloc_devid_map`, size `map->fsid[]` via byte count `key_len(fsid_type)`. [F104, F105, F141]

## Synchronization
- In `nfsacld_proc_setacl`, `nfsd3_proc_setacl`, `nfsd3_create_file`, and `nfsd4_create_file`, acquire `fh_want_write` before `inode_lock`/`inode_lock_nested` and call `fh_drop_write` only after `inode_unlock`. [F172]
- In `nfs4layouts.c`, `ls->ls_lock` nests inside `fp->fi_lock` and `clp->cl_lock`, and `fp->fi_lock` nests inside `ls->ls_mutex`. In `nfsd4_insert_layout`, after dropping `ls->ls_lock` and `fp->fi_lock` to allocate with `GFP_KERNEL`, reacquire both and re-run `nfsd4_recall_conflict` and `layouts_try_merge` before inserting. `nfsd4_layout_lm_break` and `nfsd4_recall_file_layout` run under VFS `flc_lock` spinlock and must not sleep or block (defer via `nfsd4_run_cb`). [F25, F146, F148]
- In `nfsd4_alloc_layout_stateid`, initialize `ls->ls_file`, `ls->ls_recall`, locks, lists, and `nfsd4_layout_setlease` before publishing `ls` onto `clp->cl_lo_states` (`clp->cl_lock`) and `fp->fi_lo_states` (`fp->fi_lock`). In `nfsd4_close_layout`, extract and clear `ls->ls_file = NULL` under `fi_lock` before `kernel_setlease(..., F_UNLCK, ...)` and `nfsd_file_put`. In `nfsd4_cb_layout_done`, acquire `ls->ls_file` via `nfsd_file_get` inside `rcu_read_lock()`. [F26, F27, F149]
- In `nfsd4_copy`, initialize `async_copy` (`refcount`, `cp_nn`, `cp_src`, `cp_stateid`, `dup_copy_fields`, `copy_task`) before adding to `cp_clp->async_copies` under `async_lock` and waking `copy_task`. `clp->async_lock` nests inside `nn->client_lock` in `nfsd4_async_copy_reaper` (move expired copies to `reaplist` and call `cleanup_async_copy` outside both locks). In `nfsd4_shutdown_copy` / `nfsd4_offload_cancel`, increment `copy->refcount` (and unlink in `nfsd4_unhash_copy`) under `clp->async_lock` and drop it before `nfsd4_stop_copy`, which calls `kthread_stop` only if `!test_and_set_bit(NFSD4_COPY_F_STOPPED, &copy->cp_flags)`. [F28, F30, F155, F156]
- In `nfsd4_ssc_setup_dul`, call `prepare_to_wait(&nn->nfsd_ssc_waitq, &wait, TASK_IDLE)` before unlocking `nn->nfsd_ssc_lock` and `schedule_timeout`, and wake `nfsd_ssc_waitq` under `nfsd_ssc_lock` in `nfsd4_ssc_update_dul`/`cancel_dul`. Insert into `nfsd_devid_hash` under `nfsd_devid_lock` via `list_add_tail_rcu` and search under `rcu_read_lock()` via `list_for_each_entry_rcu`. [F144, F157]
- Only `nfsd4_process_cb_update()` on `clp->cl_callback_wq` may clear `NFSD4_CLIENT_CB_UPDATE`; while set, `nfsd4_mark_cb_down`/`fault` must not overwrite `clp->cl_cb_state`. Hold `ses->se_lock` when modifying `ses->se_cb_slot_avail`, and modify `se_cb_seq_nr[cb->cb_held_slot]` only while holding the slot. `nfsd4_shutdown_callback` must run in process context to flush `cl_callback_wq` and wait in `nfsd41_cb_inflight_wait_complete`. [F61, F151, F153]
- In `alloc_cld_upcall`, initialize `new` before adding to `cn->cn_list` under `cn->cn_lock`, restarting the `cn_list` scan if `cn->cn_xid` collides; in `cld_pipe_downcall`, keep all user-memory accesses outside `cn->cn_lock`. In `nfsd4_list_rec_dir`, call `iterate_dir` before `inode_lock_nested` on `d_inode(dir)`. Serialize `nfsd4_umh_cltrack_upcall` and `NFSD4_CLIENT_STABLE` with `nfsd4_cltrack_upcall_lock`/`unlock`. [F32, F115, F158, F159, F160]
- In `nfsd_open_local_fh`, fast-path `*pnf` lookup must dereference `*pnf` and call `nfsd_file_get` inside `rcu_read_lock()` after `nfsd_net_try_get(net)`; before `cmpxchg`, take a second `nfsd_net_try_get` and `nfsd_file_get`, dropping all three extra refs if `cmpxchg` loses. In `nfs4idmap.c`, `ent_put` must use `kfree_rcu`. [F142, F143, F154]

## Object Lifetimes
- `nfsacld_proc_setacl` and `nfsd3_proc_setacl` must `posix_acl_release` `argp->acl_access` and `acl_default` on all exits. `nfsd3_proc_fsstat`, `fsinfo`, and `pathconf` have no `.pc_release` and must call `fh_put(&argp->fh)`. In `nfsd4_open`, once `nfsd4_process_open1` runs, all exits must go through `out:` (`fput`, `fh_put`/`kfree(resfh)`, `nfsd4_cleanup_open_state`, `nfsd4_bump_seqid`). [F3, F15, F20]
- In `nfsd4_copy`, async copies must use heap `async_copy` and `async_copy->cp_src` (`dup_copy_fields`), init `copies` list and `refcount` right after `kzalloc` before any jump to `out_dec_async_copy_err`/`out_err`, and decrement `nn->pending_async_copies` only at `out_dec_async_copy_err` or end of `nfsd4_do_async_copy` (never in `cleanup_async_copy`/`nfs4_put_copy`). [F11, F12, F138]
- `nfsd4_process_cb_update` must call `svc_xprt_put(c->cn_xprt)` if `setup_callback_client` fails, and NULL `cb_xprt`/`cl_cb_client` on teardown. `nfsd4_run_cb` pairs `nfsd41_cb_inflight_begin` with `nfsd41_destroy_cb` or `nfsd4_cb_probe_release` (`nfsd41_cb_inflight_end`). In `nfsd41_cb_referring_call`, if a new `rcl` has `__nr_referring_calls == 0` on error, unlink `rcl->__list` and decrement `cb_nr_referring_call_list` before `kfree(rcl)`. [F5, F6, F7]
- `nfs4_client_to_reclaim` owns `name.data` and `princhash.data` only on success; callers must `kfree` both on `NULL` return. `nfsd_open_local_fh` must call `put_group_info(rq_cred.cr_group_info)` if non-NULL. [F18, F163]

## API Contracts
- In `nfsd4_preprocess_layout_stateid`, only downcast `stid` when `stid->sc_type == SC_TYPE_LAYOUT`; when `!= SC_TYPE_LAYOUT`, `nfs4_put_stid(stid)` drops the parent ref after `nfsd4_alloc_layout_stateid`, so `!ls` must jump to `out` (not `out_put_stid`); on `0` return, `*lsp` has `ls_stid` referenced and `ls_mutex` held. In `nfsd4_layout_setlease`, call `locks_free_lease(fl)` only on `kernel_setlease` failure; in `nfsd4_layout_lm_break`, set `fl->fl_break_time = 0` and return `false`. [F51, F109, F131, F175]
- `setup_callback_client` and `get_backchannel_cred` must only dereference `ses` when `clp->cl_minorversion != 0`. Passing `ops == NULL` to `nfsd4_init_cb` is valid only for `&clp->cl_cb_null`. `cb->cb_ops->done` in `nfsd4_cb_done` must return `0` (retry) or `1` (done) (`BUG()` otherwise). `nfsd41_cb_referring_call` sleeps and requires caller serialization. [F36, F39, F132, F152]
- `_nfsd4_verify` must return `nfserr_same` or `nfserr_not_same` (mapping `nfserr_resource` to `nfserr_not_same`), never `nfs_ok`. `set_change_info` requires `fhp->fh_pre_saved`, so `do_open_fhandle` must `memset` `open->op_cinfo` to 0. `nfs4_acl_nfsv4_to_posix` must call `sort_pacl` on `*pacl` and `*dpacl`. [F45, F54, F174]
- Use `nfsd_user_namespace(rqstp)` for wire UID/GID conversions. Bracket legacy recovery dir VFS calls with `nfs4_save_creds`/`nfs4_reset_creds` and reject `net != &init_net` in legacy/UMH tracking init. `nfsd_open_local_fh` must check `nfs_fh->size <= NFS4_FHSIZE`, and `nfsd_localio_ops` must provide `nfsd_file_dio_alignment`. `nlm_fopen` must pass `NFSD_MAY_NLM | NFSD_MAY_OWNER_OVERRIDE | NFSD_MAY_BYPASS_GSS` and map `nfserr_jukebox` to `nlm_drop_reply`. [F78, F89, F161, F164, F170, F181]

## Error Handling
- In `nfs4callback.c`, reply decoders must return `-EIO` on XDR stream/bounds failures (not `-NFSERR_BAD_XDR`), and check both `status == 0` and `cb_seq_status == 0` / `cb_status == 0` after `decode_cb_sequence4res` / `decode_cb_op_status` before decoding further. [F34, F35]
- In `nfsd4_verify_copy`, `out_put_dst`/`out_put_src` must call `nfsd_file_put` and NULL `*dst` and `*src`. When `nfsd4_ssc_is_inter(copy)` is true, `copy->nf_src` is NULL (`dup_copy_fields` must skip `nfsd_file_get(src->nf_src)`), and `out_err` in `nfsd4_copy` must `refcount_dec(&copy->ss_nsui->nsui_refcnt)`. In `nfsd4_do_copy`, return `nfs_ok` if `_nfsd_copy_file_range` fails after `wr_bytes_written > 0`. [F43, F44, F46]
- In `nfs4_acl_nfsv4_to_posix`, `posix_state_to_acl` returns `NULL` for empty default ACL or `ERR_PTR` on error; on `IS_ERR`, NULL the failed `*pacl`/`*dpacl` (and release `*pacl` if `*dpacl` failed). In `nfsacld_proc_getacl` / `nfsd3_proc_getacl`, check `IS_ERR(acl)` before storing, and release/NULL both on `fail:`. [F41, F42]
- On `out_toosmall` in `nfs3svc_encode_entry3`/`entryplus3`, reset `resp->cookie_offset = 0` and `resp->dirlist.len = starting_length`, set `nfserr_toosmall`, and return `-EINVAL`. In `nfsd3_proc_mknod` and `nfsd4_create`, reject `rdev = MKDEV(major, minor)` if `MAJOR`/`MINOR` do not round-trip. [F49, F124]
- In `cld_pipe_downcall`, on `-EINPROGRESS`, leave `cup` on `cn->cn_list` without `complete(&cup->cu_done)`. In `idmap_lookup`, on `-ETIMEDOUT`, retry only if `lookup_fn` returns `*item != prev_item` (else `cache_put` and return `-ETIMEDOUT`); callers `idmap_name_to_id`/`id_to_name` must `cache_put` on `0` and map `-ENOENT` to `nfserr_badowner`/`encode_ascii_id`. In `nfsd_open_local_fh`, convert non-zero `beres` via `ERR_PTR(nfs_stat_to_errno(be32_to_cpu(beres)))`. [F38, F52, F55, F116]

## External Contracts & Pitfalls
- Before running any `OP_MODIFIES_SOMETHING` op in `nfsd4_proc_compound`, `nfsd4_check_resp_size` must check space for `op_rsize_bop` plus `COMPOUND_ERR_SLACK_SPACE` when `resp->opcnt < args->opcnt`. In `nfsd4_create_file` / `do_open_lookup`, exclusive-create verifiers use `ia_mtime`/`ia_atime` (`FATTR4_WORD1_TIME_ACCESS | FATTR4_WORD1_TIME_MODIFY`); on a positive-dentry verifier match, `NFS4_CREATE_EXCLUSIVE` breaks to `out` while `NFS4_CREATE_EXCLUSIVE4_1` jumps to `set_attr`. In `nfsd4_setattr`, delegated timestamps require `deleg_attrs_deleg` and `vet_deleg_attrs`. [F72, F84, F100, F110]
- Clamp `offset`/`count` to `(u64)OFFSET_MAX` in v3/v4 `READ`, and return `nfserr_fbig` if `offset` or `offset + len > (u64)OFFSET_MAX` in `WRITE`. In `nfsd4_layoutget`, check `lg_seg.length` and `lg_minlength` against `> NFS4_MAX_UINT64 - lg_seg.offset` (when `!= NFS4_MAX_UINT64`), and reject `length == 0` or `< lg_minlength`. [F92, F95]
- Increment `se_cb_seq_nr[cb->cb_held_slot]` in `nfsd4_cb_sequence_done()` only when `cb_seq_status == 0`. Set `FATTR4_WORD0_CHANGE` in `encode_cb_getattr4args()` only when `!ncf->ncf_file_modified`, and check `attrlen <= maxlen` in `nfs4_xdr_dec_cb_getattr`. `nfs4_xdr_enc_cb_null` must call `xdr_reserve_space(xdr, 0)`. Cast `nn->nfsd4_lease` to `u64` in `nfsd4_cb_layout_done`, and in `max_cb_time` cap it to 3600 before `u32` `/ 10` and clamp to `>= 1u`. [F56, F58, F88, F121, F122, F176]
- `cld_pipe_downcall` must check `mlen == msglen`, `__cld_pipe_inprogress_downcall` must validate `namelen > 0 && namelen <= NFS4_OPAQUE_LIMIT` (and `princhashlen > 0`) before `memdup_user()` and use `memmove` to strip `"hash:"`, and `cm_xid` in packed `cld_msg` must use `get_unaligned`/`put_unaligned`. In `nfs4idmap.c`, `idtoname_parse`/`nametoid_parse` require trailing `'\n'` and `len < IDMAP_NAMESZ`, while `idmap_name_to_id`/`numeric_name_to_id` must bound `namelen + 1 <= sizeof(buf)` and NUL-terminate `buf[namelen]`. [F81, F82, F83, F90, F135, F137]
