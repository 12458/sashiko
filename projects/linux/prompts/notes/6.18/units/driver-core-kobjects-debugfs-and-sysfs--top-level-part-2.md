# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS — (top level) (part 2)

Implements C kobject/kset lifecycles and uevent delivery in `lib/kobject*.c`, plus Rust abstractions for the driver model, platform/faux buses, `fwnode` properties, ID tables, `devres`, and `debugfs` in `rust/kernel/`.

## Architecture & Data Flow
- `env->envp[0..envp_idx]` must point into `env->buf` in contiguous ascending order via `add_uevent_var`. On `KOBJ_UNBIND`, `kobject_uevent_env` calls `zap_modalias_env` after `envp_ext` and `uevent_ops->uevent`; `zap_modalias_env` shifts `env->buf`/`envp` down and must only increment `i` when `env->envp[i]` does not match `"MODALIAS="`. [F237, F247, F313]
- In `kobject_uevent_env`, `top_kobj` only walks `parent` pointers to find `top_kobj->kset`; `uevent_suppress`, `state_*_uevent_sent`, and `uevent_ops` (`filter`, `name`, `uevent`) must use `kobj`. `state_remove_uevent_sent = 1` is set on `KOBJ_REMOVE` entry before `kset`/`uevent_suppress`/`filter` checks; `state_add_uevent_sent = 1` is set only after `KOBJ_ADD` env generation succeeds. [F225, F250]
- Every enumerator in `enum kobject_action` must match the string at the same index in `kobject_actions[]` (`lib/kobject_uevent.c`). [F223]
- Every `kobj_ns_ops_tbl[type]` access must check `kobj_ns_type_is_valid(type)` (rejecting `<= KOBJ_NS_TYPE_NONE` (0) and `>= KOBJ_NS_TYPES`). In `create_dir`, any non-NULL `ops` from `kobj_child_ns_ops(kobj)` must have a valid `ops->type` registered via `kobj_ns_type_register` or `create_dir` hits `BUG_ON`. [F234, F310]
- `RawIdArray<T, N>` and `IdArray<T, U, N>` must be `#[repr(C)]` (`raw_ids` first in `IdArray`; `ids` then zeroed `sentinel` in `RawIdArray`), and `IdTable::as_ptr` must cast `self` (not `self.raw_ids.ids.as_ptr()`) so provenance covers `sentinel`. `IdArray::build` copies `T` via `transmute_copy`, writes `i: usize` at `DRIVER_DATA_OFFSET` (requiring `RawDeviceId` to match `RawType` layout and `DRIVER_DATA_OFFSET` to be a `usize` field), reads `ids[i].1` via `ptr::read`, and must call `mem::forget(ids)`. [F191, F241, F265]
- In `rust/kernel/debugfs/file_ops.rs`, `ReadWriteFile::FILE_OPS` (`writer_open`/`single_open`) pairs with `file_ops::write` (`private_data` as `seq_file`), whereas `WriteFile::FILE_OPS` (`write_only_open`) pairs with `write_only_write` (`private_data` as `T`). `FileOps::adapt()` transmutes `&FileOps<T>` to `&FileOps<T::Inner>`, requiring `Adapter` types (`WritableAdapter`, `FormatAdapter`, `NoWriter`) to be `#[repr(transparent)]` over `T::Inner`, and callback-file constructors on `Dir`/`ScopedDir` must take `&'static F` or `&'static W` before `materialize_zst` uses `NonNull::dangling()`. [F213, F269, F270]
- `PropertyInt::read_array_from_fwnode_property` and `FwNode::property_read_array_vec` must check `to_result(ret)?` from `fwnode_property_read_*_array` before transmuting `MaybeUninit<Self>` or calling `val.inc_len(len)`. [F277]

## Synchronization
- `kobject_get_path()` measures length in `get_kobj_path_length()` (1 for NUL + `strlen(name) + 1` per level) and fills backward in `fill_kobj_path()` into a `kzalloc` buffer without a lock blocking `kobject_rename()`; `fill_kobj_path()` must pre-decrement `length` and check `length <= 0` before `memcpy()`, and `kobject_get_path()` must free `path` and retry on error. Callers of `kobject_rename()` must externally serialize concurrent renames of the same `kobject`. [F192, F194, F263]
- `kset_find_obj` (and any `kset->list` lookup under `kset->list_lock`) must use `kobject_get_unless_zero` (not `kobject_get`, as `kobject_put` zeroes `kref` before `kobj_kset_leave` locks `list_lock`) and store matches in a separate `ret = NULL` variable rather than returning the loop cursor `k`. `kobj_kset_leave` must unlock `list_lock` before `kset_put(kobj->kset)`, which may sleep and free `kset`. [F253, F300, F301]
- `kobj_ns_current_may_mount`, `kobj_ns_grab_current`, and `kobj_ns_drop` invoke `kobj_ns_ops_tbl[type]` callbacks under the `kobj_ns_type_lock` spinlock, so those callbacks must not sleep. [F302]
- `uevent_sock_list` is protected by `uevent_sock_mutex`: `uevent_net_init()` must set `ue_sk->sk` before linking `ue_sk->list`, and `uevent_net_exit()` must unlink `ue_sk->list` under `uevent_sock_mutex` before `netlink_kernel_release(ue_sk->sk)`. [F198]
- `Devres<T>` (`rust/kernel/devres.rs`) must not implement `Deref<Target = Revocable<T>>` or expose `revoke()`/`revoke_nosync()` outside `drop()` and `devres_callback()`. `devres_callback` must call `inner.data.revoke()` (waiting for RCU readers from `try_access`) rather than `revoke_nosync()`. In `<Devres<T> as PinnedDrop>::drop`, if `revoke_nosync()` is `true` and `remove_action()` is `false`, `inner().revoke.complete_all()` must precede `inner().devm.wait_for_completion()`, and both paths must wait on `devm` before `drop_in_place(self.inner.get())`. [F200, F257, F304]
- `Devres<T>`, `Inner<T>`, `devres::register`, and `platform::Driver` must require `Send` because C devres and bus `remove` callbacks may drop values on another thread. [F278]

## Object Lifetimes
- A `kobject` holds a ref on `kobj->parent` only while `state_in_sysfs == 1`. On `create_dir` failure in `kobject_add_internal`, it must call `kobj_kset_leave(kobj)`, `kobject_put(parent)`, and set `kobj->parent = NULL` with `state_in_sysfs = 0`. `__kobject_del` clears `state_in_sysfs` and `kobj->parent` without dropping `parent`, so `kobject_del` and `kobject_cleanup` must cache `kobj->parent` first and only call `kobject_put(parent)` if `state_in_sysfs` was 1. [F173, F224]
- `kobject_cleanup` must cache `kobj->parent` and `kobj->name` before `t->release(kobj)` and call `kfree_const(name)` and `kobject_put(parent)` only after `t->release(kobj)` returns, as `t->release` may inspect them and free `kobj`. [F174]
- `create_dir` takes an extra ref via `sysfs_get(kobj->sd)`, and `__kobject_del` must release it via `sysfs_put(sd)` after `sysfs_remove_dir(kobj)`. [F175]
- `kobject_move` must capture `DEVPATH_OLD` via `kobject_get_path` before `sysfs_move_dir_ns`; once `sysfs_move_dir_ns` succeeds, it must set `kobj->parent = new_parent`, clear `new_parent = NULL` (so `out:` does not drop it), call `kobject_put(old_parent)`, and only then emit `KOBJ_MOVE`. [F176, F227]
- In `kobject_uevent_env`, once `call_usermodehelper_setup` registers `cleanup_uevent_env`, calling `call_usermodehelper_exec(info, UMH_NO_WAIT)` takes ownership of `env`, so `env` must be set to `NULL` to avoid a double-free at `exit:`. [F177]
- `uevent_net_broadcast_untagged` reuses one `skb` across `uevent_sock_list` by passing `skb_get(skb)` to each `netlink_broadcast` and calling `consume_skb(skb)` after the loop, whereas `uevent_net_broadcast_tagged` passes its single `skb` directly to `netlink_broadcast` (which consumes it). [F178]
- In `rust/kernel/debugfs.rs`, `Entry::dynamic_dir` and `Entry::dynamic_file` must retain the parent's `Option<Arc<Entry<'static>>>` in `_parent` so `debugfs_remove` on the parent cannot recursively delete live child dentries. In `Scope<T>`, `data: T` must be pinned before `init(&scope.data)` creates entries, and `_entry: Entry<'static>` must precede `data: T` in `struct Scope<T>` so `Entry::drop()` runs `debugfs_remove()` before `data` drops. [F181, F203]
- `Device::fwnode` must return a borrowed `Option<&property::FwNode>` (not `FwNode::from_raw`), as `bindings::__dev_fwnode` does not increment the refcount. In `fmt::Display` for `FwNode`, `depth == 0` must borrow `self` (`Node::Borrowed`), while `depth > 0` must wrap `fwnode_get_nth_parent` in `Node::Owned(FwNode::from_raw(ptr))`. [F186, F189]
- In `FwNode::children`, `fwnode_get_next_child_node` drops non-null `prev` and increments returned `next`, so each step must pass `ARef::into_raw(prev)`, wrap `next` in `FwNode::from_raw(next)`, and set `prev = Some(next.clone())`. In `FwNode::property_get_reference_args`, `fwnode_property_get_reference_args` increments `out_args.0.fwnode`, so `FwNodeReferenceArgs::drop` must check `!self.0.fwnode.is_null()` and drop via `FwNode::from_raw`. [F187, F188]
- `Devres::access` must verify `self.dev.as_raw() == dev.as_raw()` on `&'a Device<Bound>` before calling `self.data().access()`. [F280]

## API Contracts
- After `kobject_init` or `kobject_init_and_add`, callers must release via `kobject_put` even on error (never `kfree(kobj)` directly, which leaks `kobj->name`). By contrast, `kset_register` requires `k->kobj.ktype != NULL` (returning `-EINVAL` before init if NULL), and on post-init error frees `k->kobj.name` via `kfree_const` and sets `name = NULL` without `kobject_put`, so `kset_create_and_add` must use `kfree(kset)` (not `kset_unregister`) and callers must not read `k->kobj.name` on error. [F171, F283, F311]
- `kobject_add` does not emit `KOBJ_ADD`; callers must create sysfs attributes before calling `kobject_uevent(kobj, KOBJ_ADD)`. `kobject_uevent` and `kobject_uevent_env` require sleepable process context (`GFP_KERNEL` and `uevent_sock_mutex`), and any non-NULL `envp_ext` passed to `kobject_uevent_env` must be `NULL`-terminated. [F239, F284, F303]
- Registered kobjects must be renamed via `kobject_rename` (not `kobject_set_name`), which must capture `DEVPATH_OLD` via `kobject_get_path` and finish `sysfs_rename_dir_ns` before updating `kobj->name` and emitting `KOBJ_MOVE`. [F226]
- `kobj_attr_show()` and `kobj_attr_store()` downcast `attr` via `container_of(attr, struct kobj_attribute, attr)`, so any `kobj_type` using `kobj_sysfs_ops` must only attach `struct kobj_attribute` attributes. [F264]
- `FwNode::property_get_reference_args()` must pass `nargs = 0` when `nargs_prop` is non-null (`NArgs::Prop`) and `nargs_prop = ptr::null()` when numeric `nargs` is used (`NArgs::N`), with zero-initialized `out_args`. [F215]
- Device types using `impl_device_context_deref!` must be `#[repr(transparent)]` with layout independent of `DeviceContext`, and `AlwaysRefCounted` must only be implemented for `Device<Normal>` so scoped contexts (`CoreInternal`, `Core`, `Bound`) cannot be cloned into `ARef`. [F275]
- `Device<CoreInternal>::drvdata_obtain<T>` and `drvdata_borrow<T>` require a prior `set_drvdata` of the exact same `ForeignOwnable` type `T`. In `platform::Adapter`, `probe_callback` stores `Pin<KBox<T>>` via `set_drvdata`, and `remove_callback` must reclaim it once via `drvdata_obtain::<Pin<KBox<T>>>()` before `T::unbind(pdev, data.as_ref())` so `data` lives through `unbind` and drops on return. [F190, F276]
- `driver::Registration::new` must initialize `Opaque<T::RegType>` via `ptr.write(T::RegType::default())` before `T::register`, and `RegistrationOps::register` must only mutate fields on that initialized `RegType`. [F281]

## Error Handling
- `create_dir()`, `__kobject_del()`, `kobject_cleanup()`, and `kobj_child_ns_ops()` must check `kobj->ktype` (or `get_ktype(kobj)`) is non-NULL before dereferencing `default_groups`, `release`, or `child_ns_type`. `kobject_get_ownership()` must initialize `*uid = GLOBAL_ROOT_UID` and `*gid = GLOBAL_ROOT_GID` before calling optional `ktype->get_ownership`. [F204, F208]
- `uevent_net_broadcast_untagged()`, `uevent_net_broadcast_tagged()`, and `uevent_net_broadcast()` must convert `-ENOBUFS` and `-ESRCH` from `netlink_broadcast()` to `0`. [F209]
- In `Devres::new`, `inner` (`Opaque<Inner<T>>`) must be initialized before `devm_add_action`, and dropped via `drop_in_place` if `devm_add_action` fails. `devres::register_foreign` calls `data.into_foreign()` before registering `callback::<P>` and must use `devm_add_action_or_reset` (not `devm_add_action`) so `callback::<P>` drops `P` on error. [F183, F185]
- In `rust/kernel/debugfs.rs`, when a parent `Dir` holds `None`, `Dir::create`, `Dir::create_file`, and `Dir::scoped_dir` must return `None`, `Entry::empty()`, or `ScopedDir::empty()` instead of passing a NULL parent dentry to `debugfs_create_*`. [F212]
- In `FwNode::property_read_array_vec()`, errors from `T::read_array_from_fwnode_property()` must be stored in `PropertyGuard::inner` (not early-returned with `?`), while `KVec::with_capacity()` failure returns via the outer `Result`. `PropertyGuard::required_by` and `Device::irq_by_index`/`irq_by_name` log errors when missing, whereas `PropertyGuard::optional` and `Device::optional_irq_by_index`/`optional_irq_by_name` suppress logging. [F214, F322]
- `TryFrom<&device::Device<Ctx>>` for `&platform::Device<Ctx>` must check `bindings::dev_is_platform(dev.as_raw())` before downcasting with `container_of!`. [F220]

## External Contracts
- In `kobject_uevent_env`, `init_uevent_argv` must run only after `kobject_uevent_net_broadcast`, `zap_modalias_env`, and all `add_uevent_var` calls, as it writes bare `subsystem` into `env->buf` without an `env->envp` entry. `uevent_helper` is only executed when `kobj_usermode_filter(kobj) == 0` (requiring namespace-tagged kobjects to be in `ops->initial_ns()`). [F238, F317]
- `uevent_net_init`/`uevent_net_exit` only link `uevent_sock` into `uevent_sock_list` when `sock_net(ue_sk->sk)->user_ns == &init_user_ns`. When `uevent_net_broadcast_tagged` targets a netns with `owning_user_ns != &init_user_ns`, it must overwrite `NETLINK_CB(skb).creds` uid/gid with `make_kuid`/`make_kgid(owning_user_ns, 0)` if valid. [F315, F316]
- `uevent_net_rcv_skb` must verify `netlink_ns_capable(skb, net->user_ns, CAP_SYS_ADMIN)` on `net = sock_net(NETLINK_CB(skb).sk)`. `uevent_net_broadcast` must include the trailing NUL (`ret++`) in `"SEQNUM=%llu"`, reject `skb->len + ret > UEVENT_BUFFER_SIZE` before `skb_copy_expand`, and strip `NLMSG_HDRLEN` via `skb_pull(skbc, NLMSG_HDRLEN)` before `netlink_broadcast`. [F240, F318]

## Known Pitfalls
- In `kobject_set_name_vargs`, `kvasprintf_const` may return a `.rodata` pointer, so strings containing `'/'` must be duplicated with `kstrdup` before `strreplace` mutates `'/'` to `'!'`, and old `kobj->name` freed only after the new allocation succeeds. [F228]
- `kobject_action_args` requires synthetic uevent writes to start with a 36-char UUID (`SYNTH_UUID=`) followed by space-separated alphanumeric `KEY=VALUE` pairs prefixed as `SYNTH_ARG_`. After checking `count > 0`, scans must be bounded by `buf_end = buf + count - 1` and formatted with `%.*s`; after `action_arg_word_end(buf, buf_end, '=')`, callers must check `!next || next > buf_end || *next != '='` because it returns `buf_end + 1` at buffer end. [F236, F249, F312]
- `ScopedDir` wraps `Entry` in `ManuallyDrop` and `ScopedDir::create_file` calls `mem::forget(Entry::file(...))` because children are removed when the owning `Scope` drops; any root `ScopedDir` from `Dir::scoped_dir` or `ScopedDir::new` must have its `Entry` extracted via `into_entry()` into a `Scope`. [F182]
- In `rust/kernel/platform.rs`, `irq_by_index`, `optional_irq_by_index`, `irq_by_name`, and `optional_irq_by_name` must check `irq < 0` on the `c_int` from `platform_get_irq*` before casting `irq as u32`. [F245]
- `Devres<T>` must store `Self::devres_callback` in `self.callback` and pass `Some(self.callback)` to both `devm_add_action` and `devm_remove_action_nowarn` so C devres sees identical function pointer addresses. [F287]
