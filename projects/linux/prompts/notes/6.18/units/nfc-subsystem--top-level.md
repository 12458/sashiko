# NFC SUBSYSTEM — (top level)

This component covers core NFC device management (`net/nfc/core.c`), `PF_NFC` sockets (`net/nfc/af_nfc.c`), the NFC Digital stack (`net/nfc/digital_core.c`), NFC/NCI/HCI/Digital headers, and four driver families (`s3fwrn5`, `st-nci`, `st21nfca`, `st95hf`) over I2C, SPI, and UART.

## Architecture & Data Flow
- Apply `to_nfc_dev(d)` only to `nfc_class` devices (`nfc_release()`, `match_idx()`), never parent bus devices. `dev->targets_generation` (`nfc_allocate_device()`) and `nfc_devlist_generation` (`nfc_init()`) must start at `1` for Netlink `cb->seq`, incrementing `nfc_devlist_generation` under `nfc_devlist_mutex` on `device_add()` / `device_del()`. [F71, F97, F130]
- `digital_target_found()` must validate `protocol` (1..7, else `-EINVAL`) before `1 << protocol`, update `curr_rf_tech`, set `skb_add_crc` / `skb_check_crc` to non-NULL wrappers (`*_none` if `DIGITAL_DRV_CAPS_IN_CRC(ddev)`), and zero `poll_tech_count` before `nfc_targets_found()` (restoring on error). `digital_in_send()` branches to `digital_in_send_dep_req()` on `NFC_PROTO_NFC_DEP` before SoD/CRC; `digital_in_send_complete()` branches to `digital_in_recv_mifare_res()` on `NFC_PROTO_MIFARE` before `skb_check_crc`. [F72, F104, F115, F126]
- Size `nci_hci_dev`/`nfc_hci_dev` `pipes[]` to 128 (never index by `0x80`/`0x81`) and `gate2pipe[]` to 256. In `*_hci_init_data`, `gate_count` takes `ARRAY_SIZE` (`<= 50`), `memcpy` into `gates` takes `sizeof`, and `session_id[9]` must be NUL-terminated (`<= 8` chars) after verifying `find_first_zero_bit(dev_mask, 256) < 256` before `set_bit()`. `hdev->quirks` shares HCI (`0`) and `st21nfca` (`ST21NFCA_FACTORY_MODE = 2`) bit indices (`< BITS_PER_LONG`). [F87, F123, F131, F134, F135]
- `st21nfca_hci_load_session()` and `st_nci_hci_load_session()` must use the per-device `init_data.gates` copy (never static `*_gates`), check `*_DM_IS_PIPE_OPEN` (`(p & 0x0f) == 0x06`) and `j < ARRAY_SIZE(*_gates)`, and update `init_data.gates[j].pipe`, `gate2pipe[gate]`, and `pipes[pipe]` together. [F73, F100]
- In `st21nfca` and `st-nci`, `*_control_se()` arms `count_pipes`, `expected_pipes`, `req_completion`, `se_active_timer`, and `se_active = true` together; `EVT_HOT_PLUG` / `ANY_OPEN_PIPE` must `timer_delete_sync(&se_active_timer)` and set `se_active = false` before `complete(&req_completion)`. `*_se_get_bwi()` must advance `i` past `TA` when `*_ATR_TA_PRESENT(td)` holds before advancing `i` for `TB`. `st21nfca_im_recv_dep_res_cb()` must mask `curr_nfc_dep_pni` with `ST21NFCA_NFC_DEP_PFB_PNI()` (`& 0x03`). [F80, F109, F118]
- `ndlc_open()`/`ndlc_close()` must call `ndlc->ops->enable()` before setting `ndlc->powered = 1` or `0` (since `st_nci_*_enable()` checks `powered == 0 && irq_active == 0`). `t1_active`/`t2_active` must track `t1_timer`/`t2_timer` arming and expiry/deletion. `llt_ndlc_requeue_data_pending()` must `skb_dequeue_tail()`, set the PCB retransmit bit in `skb->data[0]`, and `skb_queue_head()` onto `send_q`. [F74, F75, F76]
- `st21nfca_hci_i2c_write()` byte-stuffs only `skb->data[1 .. skb->len - 2]` (not outer `ST21NFCA_SOF_EOF`). `st21nfca_hci_i2c_repack()` trims to `get_frame_size()`, unstuffs `ST21NFCA_ESCAPE_BYTE_STUFFING` in-place tracking count `j`, trims to `i - j`, pulls leading `ST21NFCA_SOF_EOF` before `check_crc()`, and strips `0x00` and 2-byte CRC after. Reset `phy->current_read_len = 0` on EOF, I2C error, `-EBADMSG`, or mid-frame `IS_START_OF_FRAME(buf)` (also `skb_trim(skb, 0)`). [F79, F90, F107, F108]
- Keep `struct phy_common common` at offset 0 of `s3fwrn5_i2c_phy` and `s3fwrn82_uart_phy`. `s3fwrn5_fw_request_firmware()` copies 12 date bytes into `fw->date[13]` and sets `fw->date[12] = '\0'`; `s3fwrn5_fw_init()` sets `fw_info->parity = 0x00`, and `s3fwrn5_fw_prep_msg()` ORs `parity` into `hdr.type` and toggles `parity ^= 0x80`. [F81, F129, F132]
- In `st95hf`, `dev_set_drvdata(&nfc_spi_dev->dev, ...)` stores `&st95context->spicontext` while `nfc_digital_set_drvdata()` and IRQ `dev_id` store `st95context`. `st95hf_send_recv_cmd()` copies `cmd_array[cmd].cmd_params` to stack `spi_cmd_buffer` before applying `param_list` overrides. `st95hf_in_configure_hw()` stores 106A `sendrcv_trflag` so RX strips 2-byte CRC (`skb_len - 5` vs `- 3`) only on `TRFLAG_NFCA_STD_FRAME_CRC`. `st95hf_spi_recv_response()` combines `(receivebuff[0] & 0x60) << 3` with `receivebuff[1]`, requiring `MAX_RESPONSE_BUFFER_SIZE` (280) for async `skb_resp`. [F83, F85, F95, F128]

## Synchronization
- In `net/nfc/core.c`, `nfc_unregister_device()` sets `dev->shutting_down = true` under `device_lock(&dev->dev)` before unlocking to `timer_delete_sync(&check_pres_timer)` and `cancel_work_sync(&check_pres_work)`; all core entry points check `!dev->shutting_down` under `device_lock`. Stop `check_pres_timer` with `timer_delete_sync()` before `deactivate_target` or `im_transceive` and re-arm only if `!dev->shutting_down`. [F23, F70, F152]
- `nfc_check_pres_work()` must copy `dev->active_target->idx` and call `device_unlock(&dev->dev)` before `nfc_target_lost()`. Serialize all `dev->rfkill` lifecycle and `nfc_dev_up()` reads under `device_lock(&dev->dev)`, setting `dev->rfkill = NULL` before unlocking on teardown. [F2, F25, F69, F151]
- In `net/nfc/af_nfc.c`, call sleeping `proto_register()` before `write_lock(&proto_tab_lock)` (calling `proto_unregister()` after unlock if `proto_tab[id]` is busy), and clear `proto_tab[id]` under `write_lock` before `proto_unregister()`. `nfc_sock_create()` calls `nfc_protocol.create` under `read_lock(&proto_tab_lock)`, so `.create` must not sleep or use `GFP_KERNEL`. [F4, F29, F148, F149]
- In `net/nfc/digital_core.c`, `ddev->cmd_lock` protects `cmd_queue` and head `cmd->pending`: `digital_wq_cmd()` keeps the active cmd at head with `pending = 1` until `digital_wq_cmd_complete()` (or sync error) unlinks it and schedules `cmd_work`, dropping `cmd_lock` before `ddev->ops` or `cmd->cmd_cb()`. Hold `ddev->poll_lock` to check `poll_tech_count != 0` in `digital_poll_next_tech()`, and zero `poll_tech_count` under `poll_lock` before unlocking to `cancel_delayed_work_sync(&poll_work)`. [F30, F32, F110, F114]
- In `st-nci`, `st_nci_open()` sets `ST_NCI_RUNNING` via `test_and_set_bit()` before `ndlc_open()` (clearing on error), `st_nci_send()` checks `test_bit()` before `ndlc_send()`, and `st_nci_close()` clears it after `ndlc_close()`. Softirq `ndlc_t1_timeout()` / `ndlc_t2_timeout()` must only schedule `ndlc->sm_work`. [F35, F155]
- In `st21nfca`, `info->info_lock` protects `info->state` and `phy_ops->enable()`/`disable()`, and `phy->phy_lock` protects I2C retry loops. Softirq `st21nfca_se_wt_timeout()` defers work to `se_info.timeout_work`, and `ST21NFCA_EVT_TRANSMIT_DATA` / teardown must call `timer_delete_sync(&bwi_timer)` before `cancel_work_sync(&timeout_work)`. [F37, F38, F39, F154]
- In `s3fwrn5`, lock order is `info->mutex` outer to `phy->common.mutex` inner; `s3fwrn5_nci_send()` holds `info->mutex` across mode check and `s3fwrn5_write()`. Under `phy->common.mutex`, `s3fwrn5_i2c_set_mode()` sets `phy->irq_skip = true` on mode change and `s3fwrn5_i2c_write()` clears it before TX. `s3fwrn5_fw_send_msg()` calls `reinit_completion(&fw_info->completion)` before `s3fwrn5_write()`, does not consume `msg`, and on `0` transfers `fw_info->rsp` to `*rsp` and clears `fw_info->rsp = NULL` (callers must `kfree_skb(msg)` and, on `0`, `kfree_skb(rsp)`). [F13, F40, F42, F82]
- In `st95hf`, hardirq `st95hf_irq_handler()` only completes `spicontext->done` if `req_issync` or returns `IRQ_WAKE_THREAD`. Lock order is `stcontext->rm_lock` (serializing `st95hf_remove()` and `nfcdev_free` against `st95hf_irq_thread_handler()`) outer to `spicontext->spi_lock` (held across `req_issync = true`, `reinit_completion`, `spi_sync`, and `wait_for_completion_timeout` on `SYNC` TX). [F43, F45, F156, F158]
- `st95hf_in_send_cmd()` sets `complete_cb_arg` and acquires `exchange_lock` via `down_killable()` before `ASYNC` TX; on `st95hf_spi_send()` error it calls `up(&exchange_lock)` and `kfree_skb(skb_resp)` without freeing `skb`, else it frees `skb` and leaves `exchange_lock` for `st95hf_irq_thread_handler()`. On `WTX_REQ_FROM_TAG`, `st95hf_irq_thread_handler()` calls `st95hf_handle_wtx(stcontext, true, ...)`, sets `wtx = true`, and returns without `up(&exchange_lock)`, freeing `skb_resp`, or calling `complete_cb`, restoring FDT via `st95hf_handle_wtx(stcontext, false, 0)` on the next reply (clearing `wtx` and `cb_arg->rats` on error). [F19, F44, F84, F111]

## Object Lifetimes
- Always call `nfc_free_device()` (never `kfree(dev)`) after `nfc_unregister_device()` or `nfc_register_device()` failure. Clear borrowed `dev->active_target = NULL` under `device_lock(&dev->dev)` in `nfc_deactivate_target()`, `nfc_dep_link_down()`, and `nfc_target_lost()` (if `i == dev->n_targets`, `nfc_target_lost()` unlocks and returns `-EINVAL`; else it compacts or frees `dev->targets`). [F3, F105, F136]
- `nfc_digital_unregister_device()` must unregister `nfc_dev`, zero `poll_tech_count` under `poll_lock`, cancel `poll_work`, `cmd_work`, and `cmd_complete_work`, and drain `cmd_queue` by calling `cmd->cmd_cb(ddev, cmd->cb_context, ERR_PTR(-ENODEV))` before freeing `cmd->mdaa_params` and `cmd`. [F9]
- In `s3fwrn5_firmware_update()`, return directly if `s3fwrn5_fw_setup()` fails (it releases firmware itself), jumping to `out: s3fwrn5_fw_cleanup()` only after `s3fwrn5_fw_setup()` succeeds. `s3fwrn82_uart_probe()` / `remove()` teardown order is `s3fwrn5_remove()`, `serdev_device_close()`, then `kfree_skb(phy->recv_skb)`. [F12, F14]
- `ndlc_remove()` must `timer_delete_sync()` `t1_timer`/`t2_timer` and `cancel_work_sync(&ndlc->sm_work)` before `st_nci_remove()` and queue purges. `st21nfca_hci_remove()` must run `st21nfca_dep_deinit()` and `st21nfca_se_deinit()` before unregistering/freeing `hdev` and `info`, and `st21nfca_hci_i2c_probe()` error paths / `remove()` must `kfree_skb(phy->pending_skb)`. [F34, F36, F139]

## API Contracts
- `nfc_allocate_device()` and `nfc_digital_allocate_device()` return `NULL` (never `ERR_PTR`) on failure. `nfc_allocate_device()` requires non-zero `supported_protocols` and only `start_poll`, `stop_poll`, `activate_target`, `deactivate_target`, `im_transceive` (so check all other `dev->ops` callbacks before calling, only touch `check_pres_timer`/`check_pres_work` if `ops->check_presence` is set, and populate both `enable_se` and `disable_se` if SE is supported). `nfc_digital_allocate_device()` requires `in_configure_hw`, `in_send_cmd`, `tg_listen`, `tg_configure_hw`, `tg_send_cmd`, `abort_cmd`, `switch_rf`, and `tg_get_rf_tech` if `tg_listen_md` is set. [F46, F58, F59, F161, F162]
- Call `nfc_targets_found()`, `nfc_target_lost()`, and `nfc_driver_failure()` only from sleepable context without `device_lock(&dev->dev)` held; `nfc_targets_found()` must guard `kmemdup()` with `if (targets)` for `targets == NULL, n_targets == 0`. `nfc_data_exchange()` and `nfc_tm_data_received()` always consume `skb` (even on error). `s3fwrn5_nci_send()` frees `skb` (`kfree_skb` on error, `consume_skb` on success), whereas PHY `write` callbacks (`st21nfca`, `st_nci`, `s3fwrn5`) and `nfc_hci_ops.xmit` must return `0` or `-errno` (never positive byte counts) and leave `skb` unconsumed and unaltered. [F5, F11, F49, F61, F150, F173]
- `digital_send_cmd()` does not free `skb` or `params` on error (`-ENOMEM`). If an async `nfc_digital_ops` callback returns non-zero, the driver must not free `skb` or call `nfc_digital_cmd_complete_t`; once it returns `0`, it must call `nfc_digital_cmd_complete_t`, freeing any pre-allocated response `skb` and passing `ERR_PTR(-errno)` (never `NULL`) on error, while the callback frees non-`ERR_PTR` `resp` (`digital_in_send_complete()` converts `IS_ERR(resp)` to `NULL` for `data_exchange_cb_t`). [F8, F10, F50, F165, F166]
- `in_configure_hw` and `tg_configure_hw` must enable the RF field (since `digital_poll_next_tech()` calls `digital_switch_rf(ddev, 0)` between polls). In `digital_start_poll()` for `NFC_PROTO_NFC_DEP_MASK`, check `tg_listen_mdaa` before `tg_listen_md` before `nfca`/`nfcf` fallback. Allocate RX `skb`s via `nfc_alloc_recv_skb()` (1-byte headroom) and declare max TX header/trailer bytes in `tx_headroom`/`tx_tailroom`. [F67, F102, F168, F169]
- `digital_target_found()`, `nfc_activate_target()`, and `curr_protocol` use `NFC_PROTO_*` numbers, while `nfc_*allocate_device()`, `nfc_start_poll()`, `nfc_tm_activated()`, and `supported_protocols` use `NFC_PROTO_*_MASK` bitmasks. `nfc_fw_download_done()` takes `0` or positive `u32` errno; `s3fwrn5_fw_init()` requires NUL-terminated `fw_name` (`<= 32` chars). Call `nfc_vendor_cmd_alloc_reply_skb()` / `nfc_vendor_cmd_reply()` only synchronously inside `.doit` without altering `skb->cb`, freeing `msg` on error. `PF_NFC` supports only `init_net`. [F18, F65, F66, F133, F164, F175]
- `st_nci_se_io()` and `st21nfca_hci_se_io()` must `kfree(cb_context)` on sync errors before arming `bwi_timer`. `*_control_se()` returns positive `se_idx` or `< 0` on error (check `r < 0`). Gate event `default:` branches must return `1` without freeing `skb`. `nci_core_conn_create()` with `params->length > 0` requires `sizeof(struct dest_spec_params)` backing `params->value` and `params_len = sizeof(*params) + params->length`. `st95hf_spi_recv_response()` callers must check both `< 0` and `receivebuff[0]`, and `st95hf_echo_command()` passes `recv_res = false` while other `SYNC` cmds pass `true`. [F6, F54, F55, F56, F103, F122]

## Error Handling
- Store `of_get_named_gpio()` in signed `int` (`phy_common`), check `devm_gpiod_get()` / `devm_clk_get_optional_enabled()` / `devm_regulator_get()` with `IS_ERR()`, and guard `regulator_disable(st95context->st95hf_supply)` with `if (st95context->st95hf_supply)` in `st95hf_probe()` error paths and `st95hf_remove()`. [F47, F48, F60, F141]
- In `s3fwrn82_uart_probe()`, `serdev_device_set_baudrate()` returns `115200`, so set `ret = -EINVAL` on mismatch and overwrite `ret` before error jumps. `s3fwrn82_uart_read()` must check `recv_skb->len >= S3FWRN82_NCI_HEADER` (3) before subtracting or indexing, with `recv_skb` sized to `NCI_SKB_BUFF_LEN` (258). [F57, F94]
- In `st21nfca` and `st-nci` `*_EVT_TRANSACTION` handlers, combine length and tag/bounds checks with `||` (`-EPROTO`), validate `skb->len` against `2`, `aid_len + 4`, and `aid_len + 4 + params_len`, check `aid_len <= sizeof(transaction->aid)`, and allocate `sizeof(*transaction) + params_len`. [F86, F99]
- `digital_skb_check_crc()` must reject `skb->len <= 2`. `st_nci_i2c_read()` and `st_nci_spi_read()` must verify 16-bit BE length at `buf + 2` is `<= 250` before reading payload into `buf`. `st95hf_send_recv_cmd()` must check `cmd_len <= MAX_CMD_LEN` (7), `no_cmd_params >= no_modif`, and `param_offset < no_cmd_params`. [F88, F93, F96]

## External Contracts
- SPI NFC drivers with `of_device_id` tables (`"st,st21nfcb-spi"`, `"st,st95hf"`) must list vendor-stripped names (`"st21nfcb-spi"`, `"st95hf"`) in `spi_device_id`. UAPI headers (`include/uapi/linux/nfc.h`) must use `__kernel_sa_family_t`, `__kernel_size_t`, `__u32`, `__u8` instead of libc types. [F147, F174]

## Known Pitfalls
- Look up `target_idx` via `nfc_find_target()`, never `dev->targets[target_idx]` (`idx` is monotonic `target_next_idx++`). Pass `ARRAY_SIZE(cmds)` (never `sizeof(cmds)`) to `nfc_set_vendor_cmds()`, `nci_set_vendor_cmds()`, and `nfc_hci_set_vendor_cmds()`. [F91, F177]
- In `st-nci/ndlc.c`, mask `pcb` with `PCB_TYPE_MASK` and `PCB_SYNC_MASK` before comparing against `PCB_TYPE_DATAFRAME` or `PCB_SYNC_ACK` (`PCB_TYPE_SUPERVISOR` and `PCB_SYNC_WAIT` are bit-supersets). Bound `*_BWI_TO_TIMEOUT(x)` (`(1 << x) * 200`) inputs to `0..15`. In `s3fwrn5_nci_rf_configure()`, compute `*((u32 *)(fw->data + i))` with `i += 4`, never `((u32 *)fw->data)[i]`. [F101, F116, F125]
