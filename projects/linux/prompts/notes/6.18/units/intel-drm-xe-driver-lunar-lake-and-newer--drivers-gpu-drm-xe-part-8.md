# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 8)

This unit implements GPU Virtual Memory (`xe_vm`, `xe_vm_madvise`), userptr mappings and MMU notifiers (`xe_userptr`), BO validation (`xe_validation`), TTM managers (`xe_ttm_vram_mgr`, `xe_ttm_stolen_mgr`, `xe_ttm_sys_mgr`), VRAM probing/resizing (`xe_vram`), TLB invalidation and jobs (`xe_tlb_inval`, `xe_tlb_inval_job`), uC firmware loading (`xe_uc`, `xe_uc_fw`), tile sysfs/debugfs/SR-IOV VF support, tunings (`xe_tuning`), VSEC PMT telemetry (`xe_vsec`), and tracepoints.

## Architecture & Data Flow

- Every `DRM_GPUVA_OP_REMAP` handler (`vm_bind_ioctl_ops_parse`, `xe_vma_op_commit`, `xe_vma_op_unwind`, `op_lock_and_prep`, `op_trace`, `op_add_ufence`) must check `op->remap.prev` and `op->remap.next` with independent `if` statements (not `else if`). When `skip_prev` or `skip_next` is true, `vm_bind_ioctl_ops_parse` must inherit `xe_vma_max_pte_size(old)` via `xe_vma_set_pte_size` while shrinking `op->remap.start`/`range`, and `xe_vma_op_commit` must copy `tile_present` from the unmapped VMA and clear `op->remap.prev`/`next` to `NULL`. [F1307, F1308, F1344]
- `vm_bind_ioctl_ops_parse` must call `xe_vma_ops_incr_pt_update_ops` for every PT sub-op `xe_pt_update_ops_prepare` will stage so `xe_vma_ops_alloc` sizes `vops->pt_update_ops[i].ops` sufficiently. In `xe_vm_alloc_vma`, propagate `is_cpu_addr_mirror` (`is_madvise`) or `default_pat` (`!is_madvise`) from `DRM_GPUVA_OP_REMAP`/`UNMAP` to the next `DRM_GPUVA_OP_MAP`, and for `is_madvise` save `tmp_attr = vma->attr` before `xe_vma_destroy` to copy onto `op->map.vma->attr`. [F1309, F1358]
- `xe_vma_is_userptr()` checks `!xe_vma_bo(vma) && !xe_vma_is_null(vma) && !xe_vma_is_cpu_addr_mirror(vma)`, so `xe_vma_create()` must set `DRM_GPUVA_SPARSE`, `XE_VMA_SYSTEM_ALLOCATOR`, or `gpuva.gem.obj` before any error calls `xe_vma_free()`, and callers must check `xe_vma_is_userptr()` before `to_userptr_vma()`. In `xe_vm_create_scratch()`/`xe_vm_free_scratch()`, `vm->scratch_pt[id][i]` is indexed by `i` in `[MAX_HUGEPTE_LEVEL, vm->pt_root[id]->level)`, leaving lower indices `NULL`. [F1285, F1342]
- `xe_vm_validate_rebind` must loop `drm_gpuvm_validate` and `xe_vm_rebind(vm, false)` while `!list_empty(&vm->gpuvm.evict.list)` before reserving fences, as PT allocs can evict BOs. `vm->preempt.num_exec_queues` must match `vm->preempt.exec_queues`, and `xe_vm_remove_compute_exec_queue` must only decrement it when `!list_empty(&q->lr.link)` using `list_del_init`. In `madvise_atomic`, update both `vmas[i]->attr.atomic_access` and `bo->attr.atomic_access`, clear `skip_invalidation = false`, and call `ttm_bo_unmap_virtual(&bo->ttm)` if in VRAM and switching to `DRM_XE_ATOMIC_CPU` or `GLOBAL`. [F1310, F1313, F1355]
- When `xe_ttm_vram_mgr_new()` rounds `size` up via `roundup_pow_of_two(size)` for `TTM_PL_FLAG_CONTIGUOUS` where `place->fpfn + (size >> PAGE_SHIFT) != lpfn`, expand `lpfn` to at least `place->fpfn + (size >> PAGE_SHIFT)` before `drm_buddy_alloc_blocks()`; after `drm_buddy_block_trim`, reset `size = vres->base.size` before computing `vres->used_visible_size` and subtracting from `mgr->visible_avail` (restored in `xe_ttm_vram_mgr_del`). [F1314, F1338]
- `tlb_inval->seqno` wraps in `[1, TLB_INVALIDATION_SEQNO_MAX - 1]` (skipping `0`), and `xe_tlb_inval_seqno_past()` must check `seqno - seqno_recv` against `+/-(TLB_INVALIDATION_SEQNO_MAX / 2)` before `seqno_recv >= seqno`. `xe_tlb_inval_fence_prep` appends to `pending_fences` in `seqno`/`inval_time` order under `seqno_lock`, so `xe_tlb_inval_done_handler` and `xe_tlb_inval_fence_timeout` must use `list_for_each_entry_safe` and `break` at the first non-expired/future-seqno fence. Queue `fence_tdr` when `pending_fences` becomes singular, re-arm if non-empty after signaling, and cancel when empty or in `xe_tlb_inval_reset` (which under `seqno_lock` and `pending_lock` sets `seqno_recv = seqno - 1` and signals all `pending_fences`). [F1316, F1317, F1348, F1364]
- Keep `struct dma_fence base` at offset 0 of `struct xe_tlb_inval_fence` (and allocate non-stack instances via standalone `kmalloc`, as `inval_fence_ops` omits `.release` and `dma_fence_release()` calls `kfree_rcu(&fence->base)`), and keep `struct kobject base` at offset 0 of `struct kobj_tile` (freed directly via `kfree(kobj)` in `xe_tile_sysfs_kobj_release()`). [F1369, F1371]
- In `xe_tile_sriov_vf_balloon_ggtt_locked()`, verify `ggtt_base >= wopcm`, `ggtt_base <= GUC_GGTT_TOP`, and `ggtt_size <= GUC_GGTT_TOP - ggtt_base`, and only insert balloon nodes when `start != end`. In `xe_tile_sriov_vf_fixup_ggtt_nodes`, call `xe_tile_sriov_vf_deballoon_ggtt_locked` before `xe_ggtt_shift_nodes_locked` and `xe_tile_sriov_vf_balloon_ggtt_locked` afterward under `ggtt->lock`. [F1319, F1339]
- In `xe_vram_probe()`, decrement `remain_io_size` by `min_t(u64, tile->mem.vram->actual_physical_size, remain_io_size)` per tile, and clamp `vram->io_size` in `vram_region_init()` to `min_t(u64, usable_size, remain_io_size)`. Order firmware tables in `xe_uc_fw.c` by descending `enum xe_platform` with newest versions first (`uc_fw_auto_select` loops while `p <= entries[i].platform`). In `xe_vsec.c`, terminate `bmg_capabilities[]` with `NULL` and bounds-check `xe->info.platform` in `get_platform_info()`. [F1340, F1341, F1350]

## Synchronization

- Lock order: `vm->lock` -> `xe_validation_device.lock` (`val->lock`) -> `drm_exec` (`dma_resv`) -> `vm->svm.gpusvm.notifier_lock` -> `vm->userptr.invalidated_lock`. `xe_validation_should_retry` must call `drm_exec_fini(ctx->exec)` before unlocking/relocking `ctx->val->lock`, and call `drm_exec_init(ctx->exec, ...)` afterward even on failure so `xe_validation_ctx_fini` is safe. In `xe_vm_create`, `XE_VM_FLAG_GSC` VMs must init `vm->lock` with `gsc_vm_key`. [F1258, F1279, F1401]
- `xe_vm_set_validating`, `xe_vm_clear_validating`, and `xe_vm_set_validation_exec` require holding `xe_vm_resv(vm)` and must be cleared before unlocking `drm_exec` or `xe_vm_resv(vm)`. `xe_vm_insert_vma` and `xe_vm_remove_vma` require both `vm->lock` and `vm->snap_mutex` (and must clear matching `vm->usm.last_fault_vma` on removal). `xe_vm_snapshot_capture` must use `GFP_NOWAIT` and only take `xe_bo_get`/`mmget_not_zero` refs under `vm->snap_mutex`, deferring `GFP_USER` allocs, `xe_bo_read`, and `copy_from_user` (under `kthread_use_mm`/`kthread_unuse_mm` and `mmput`) to `xe_vm_snapshot_capture_delayed`. [F1265, F1275, F1397, F1407]
- `xe_vm_has_valid_gpu_mapping`, `xe_vma_userptr_check_repin`, and `xe_vm_userptr_check_repin` are lockless advisory checks; reverify under `notifier_lock` (`__xe_vm_userptr_needs_repin`), `vm->lock` (`xe_vm_userptr_pin`), or the BO `dma_resv` lock. In `preempt_rebind_work_func`, after `xe_vm_rebind` and waiting on `DMA_RESV_USAGE_KERNEL` fences, hold `xe_svm_notifier_lock(vm)` and verify `__xe_vm_userptr_needs_repin(vm) == 0` before `arm_preempt_fences` and `resume_and_reinstall_preempt_fences`. [F1281, F1283, F1284]
- `xe_vm_invalidate_vma` requires the BO `dma_resv` lock or `vm->svm.gpusvm.notifier_lock` (write, or read plus `xe_vm_resv(vm)` with `DMA_RESV_USAGE_BOOKKEEP` signaled), and `xe_device_wmb(xe)` between `xe_pt_zap_ptes` and `xe_vm_range_tilemask_tlb_inval`. Both `xe_vm_invalidate_vma` and `xe_zap_ptes_in_madvise_range` must update `vma->tile_invalidated` via `WRITE_ONCE` for non-mirror VMAs. Bracket `dma_resv_for_each_fence_unlocked` in `__vma_userptr_invalidate` with `dma_resv_iter_begin`/`end`. [F1277, F1311, F1404]
- In `xe_vm_create_ioctl`, `xa_alloc` into `xef->vm.xa` must be the final fallible step. In `xe_vm_close_and_put`, `xe_vm_close` must set `vm->size = 0` under `vm->lock` (write) and drop `vm->lock` before unlinking `vm->preempt.pm_activate_link` under `xe->rebind_resume_lock` and calling `flush_work(&vm->preempt.rebind_work)`. `xe_vm_free` and `vma_destroy_cb` may run in IRQ context and must defer sleeping teardown (`vm_destroy_work_func`, `xe_vma_destroy_late`) to `system_unbound_wq`. [F1267, F1272, F1396]
- In `xe_tlb_inval`, `seqno_lock` (mutex) nests outside `pending_lock` (spinlock, always taken with IRQs disabled as `xe_tlb_inval_done_handler` runs in IRQ context). Hold `seqno_lock` across `xe_tlb_inval_fence_prep` and `xe_tlb_inval_issue` (assigning `seqno`, queuing on `pending_fences` under `pending_lock`, advancing `tlb_inval->seqno`, and calling the backend op, signaling via `xe_tlb_inval_fence_signal_unlocked` if `< 0`). Hold `mgr->lock` across all `drm_buddy` ops and `mgr->visible_avail` updates in `xe_ttm_vram_mgr`. Hold `xe->pmt.lock` and `xe_pm_runtime_get_if_active(xe)` (returning `-ENODATA` if false, balanced with `xe_pm_runtime_put`) in `xe_pmt_telem_read()`. [F1270, F1276, F1383, F1398, F1399]

## Object Lifetimes

- BO VMAs hold a GEM ref (`drm_gem_object_get`/`xe_bo_put`) without `xe_vm_get`, while userptr, null, and CPU mirror VMAs hold `xe_vm_get`/`xe_vm_put`. On userptr VMA destruction, set `XE_VMA_DESTROYED` under `xe_svm_notifier_lock` and call `xe_userptr_destroy` under `vm->lock` in `xe_vma_destroy`, but defer `xe_userptr_remove` (`mmu_interval_notifier_remove`) to `xe_vma_destroy_late` after the unbind fence signals. [F1259, F1271]
- `XE_VM_FLAG_LR_MODE` VMs hold `xe_pm_runtime_get_noresume(xe)` from `xe_vm_create()` until `vm_destroy_work_func()` (or `err_no_resv`). Guard `xe_pt_clear()` and `xe_tlb_inval_vm()` in `xe_vm_close()` with `drm_dev_enter`/`exit`. In `xe_vm_snapshot_capture_delayed`, clear `snap->snap[i].mm` and `bo` to `NULL` after `mmput`/`xe_bo_put`. Register `vram_fini()` via `devm_add_action_or_reset()` in `xe_vram_probe()` to clear `vram->mapping` pointers when `devm_ioremap_wc()` unmaps. [F1266, F1381, F1391, F1393]
- `xe_tlb_inval_fence_init` takes `xe_pm_runtime_get_noresume` released only in `xe_tlb_inval_fence_fini` upon signaling, so every initialized fence must be signaled and clear `fence->tlb_inval = NULL`. In `xe_tlb_inval_job_destroy`, `job->fence` (`ifence`) is raw `kmalloc` memory until `xe_tlb_inval_job_push` sets `job->fence_armed = true`, so call `kfree(ifence)` when `!job->fence_armed` and `dma_fence_put(job->fence)` when `job->fence_armed`. [F1251, F1252]

## API Contracts

- `xe_vma_create()` takes an inclusive `end` (`start + range - 1`), unlike `xe_vma_end()`. `xe_vma_need_vram_for_atomic()` returns signed `int` (`1`, `0`, `-EACCES`); check `< 0` before boolean tests. On `ERR_PTR(-ENODATA)` from `ops_execute()`, `vm_bind_ioctl_ops_execute()` must still call `vm_bind_ioctl_ops_fini`, and `xe_vm_bind_ioctl()` must skip unwind and call `vm_bind_ioctl_signal_fences()`. Preallocate slot 0 via `xe_tlb_inval_job_alloc_dep` before `xe_tlb_inval_job_push` with an unsignaled fence, and take `&job->dep.drm.s_fence->finished` ref before `drm_sched_entity_push_job`. `pde_pat_index()` requires `pat_index <= 3`; `xelp_pte_encode_addr()` requires `!(flags & ~XE_PTE_PS64)`. [F1253, F1288, F1289, F1290, F1304]
- In `xe_uc_fw_init()`, init `fw = NULL` and return `0` if `!fw` after `uc_fw_request()`. `xe_uc_fw_copy_rsa()` requires 4-byte aligned `min_t(u32, uc_fw->rsa_size, max_len)` and `xe_uc_fw_is_available(uc_fw)`. Hold `XE_FW_GT` forcewake in `uc_fw_xfer()` (which must unconditionally write `_MASKED_BIT_DISABLE(dma_flags)` to `DMA_CTRL` after `xe_mmio_wait32()`) and in non-VF `tile_vram_size()`/`get_flat_ccs_offset()`. When `xe_ttm_stolen_cpu_access_needs_ggtt(xe)`, leave `io_size = 0` in `xe_ttm_stolen_mgr_init()` and require `XE_BO_FLAG_GGTT` in `__xe_ttm_stolen_io_mem_reserve_stolen()`. `tile_debugfs_simple_show`/`show_with_rpm` require `.data` of type `int (*)(struct xe_tile *, struct drm_printer *)` under a parent with `i_private == struct xe_tile *`. [F1300, F1327, F1372, F1382, F1387, F1390]

## Error Handling

- Reset `vm->pt_root[id]`, `vm->scratch_pt[id][i]`, or `ops[i]` to `NULL` when `xe_pt_create` or `vm_bind_ioctl_ops_create` returns `ERR_PTR` before teardown/unwind. Unwind ops in reverse in `vm_bind_ioctl_ops_unwind` when `err && err != -ENODATA`. On mid-loop failure in `ops_execute`, call `xe_pt_update_ops_abort` on all tiles with `num_ops > 0`, decrement `vm->composite_fence_seqno` if `dma_fence_array_create` failed, and put `fences[0..current_fence-1]`. [F1261, F1264, F1323]
- In `xe_vm_userptr_pin`, remove `-EFAULT` VMAs from `vm->rebind_list`, and on error move `vm->userptr.repin_list` back to `vm->userptr.invalidated` under `notifier_lock` and `invalidated_lock`. Check `IS_ERR_OR_NULL(snap)` and `!IS_ERR(snap->snap[i].data)` in snapshot consumers. In `xe_vm_madvise_ioctl()`, skip `err_fini` (`kfree(madvise_range.vmas)`) when `err || !madvise_range.num_vmas`. Use `__GFP_RETRY_MAYFAIL | __GFP_NOWARN` (and `__GFP_ACCOUNT`) for user-scaled array allocs in VM ioctls and `xe_vma_ops_alloc()`, returning `-ENOBUFS` on failure. [F1256, F1291, F1302, F1423]
- In `xe_vm_range_tilemask_tlb_inval`, increment `fence_id` only after `xe_tlb_inval_range` succeeds, and on error wait on `fence[0..fence_id-1]` before returning. In `xe_ttm_vram_mgr_alloc_sgt`, clamp `cursor.size` to `SZ_2G` and zero `sg->length` so `error_unmap:` skips unmapped entries. In `parse_headers`, `XE_UC_FW_TYPE_HUC` only falls through to `parse_css_header` on `-ENOENT` from `parse_cpd_header`. Call `xe_guc_sanitize(&uc->guc)` on any error after `xe_guc_enable_communication()` in `xe_uc_load_hw()`/`vf_uc_load_hw()`. [F1347, F1351, F1356, F1385]

## External Contracts

- In `vma_userptr_invalidate`, return `false` immediately if `!mmu_notifier_range_blockable(range)` before locking/waiting; when blockable, call `mmu_interval_set_seq(mni, cur_seq)` under `notifier_lock`. Pass `uvma->userptr.notifier.mm` (not `current->mm`) to `drm_gpusvm_get_pages()` in `xe_vma_userptr_pin_pages()`. Only call `drmm_cgroup_register_region()` in `__xe_ttm_vram_mgr_init()` when `mem_type != XE_PL_STOLEN`. [F1278, F1416, F1422]
- Enforce `XE_64K_PAGE_MASK` alignment on `obj_offset`, `addr`, and `range` when `XE_BO_FLAG_INTERNAL_64K` and `XE_VRAM_FLAGS_NEED64K` are set. Clamp userspace `pat_index` and `args->type` with `array_index_nospec()`, and reject `coh_mode == 0`. In `xe_vm_query_vmas_attrs_ioctl()`, require `vector_of_mem_attr == 0 && sizeof_mem_range_attr == 0` when `num_mem_ranges == 0`, `sizeof_mem_range_attr == sizeof(struct drm_xe_mem_range_attr)` when `> 0`, and return `-ENOSPC` if count exceeds `*num_vmas`. Validate `fw_size` in `parse_css_header()` against `sizeof(struct uc_css_header) + ucode_size + rsa_size`, and mask `gsc_cpd_entry.offset` with `GSC_CPD_ENTRY_OFFSET_MASK` before bounds-checking. [F1325, F1326, F1330, F1333, F1335]

## Known Pitfalls

- Respect union aliasing: unlink `vma->combined_links.rebind`/`destroy` before `xe_vma_destroy`/`unlocked`; only `INIT_WORK(&vma->destroy_work, ...)` after `vma_destroy_cb()` fires; only access `op->prefetch_range.range` when `op->base.op == DRM_GPUVA_OP_PREFETCH && xe_vma_is_cpu_addr_mirror(vma)`. Only mutate `unmap->va->va.addr`/`range` in `xe_vma_op_commit` after `prep_vma_destroy`. Guard `kvfree(bind_ops)` with `if (args->num_binds > 1)`, and cast `devmem_fd` to `s32` before comparing to `DRM_XE_PREFERRED_LOC_DEFAULT_SYSTEM`. [F1306, F1331, F1334, F1352, F1374, F1375]
- Avoid 32-bit overflows: cast PFNs/alignments to `u64` before `<< PAGE_SHIFT` in `xe_ttm_vram_mgr_new()`; cast `si.totalram` to `u64` in `xe_ttm_sys_mgr_init()`; use `1ULL` and `(resource_size_t)SZ_1M` in `resize_vram_bar()`; widen `REG_FIELD_GET()` to `u64` in `get_flat_ccs_offset()`/`tile_vram_size()`; use `1ull << xe->info.va_bits`; and check `range <= limit` before `addr > limit - range`. [F1359, F1360, F1361, F1362, F1365, F1366]
- Allocate `xe_ttm_sys_node` with `struct_size(node, base.mm_nodes, 1)`, set `mm_nodes[0].size = PFN_UP(node->base.base.size)`, and note `man->size` is pages in `xe_ttm_sys_mgr.c` (`<< PAGE_SHIFT` vs bytes) and bytes in `xe_ttm_vram_mgr.c` (`>> PAGE_SHIFT` vs PFNs). Clear `PCI_COMMAND_MEMORY` and release `LMEM_BAR` before `pci_resize_resource` in `_resize_bar`/`resize_vram_bar`, then restore `PCI_COMMAND`. Multiply CSS `*_dw` fields by `sizeof(u32)`, and add `uc_fw->css_offset` to `uc_fw->bo` offsets in `uc_fw_xfer()` and `xe_uc_fw_rsa_offset()`. [F1315, F1367, F1376, F1377, F1378, F1379]
