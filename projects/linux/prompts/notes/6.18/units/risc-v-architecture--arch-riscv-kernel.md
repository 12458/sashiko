# RISC-V ARCHITECTURE — arch/riscv/kernel

Implements the core RISC-V kernel runtime: boot setup, CPU/vendor extension discovery, SMP/IPIs, SBI calls, traps/misaligned accesses, signals, context switching, ELF module relocation, runtime code patching, hibernation/suspend, kexec, ACPI/DT init, and `riscv_hwprobe`.

## Architecture & Data Flow

- In `module.c`, relocation types calling `module_emit_plt_entry()`/`got_entry()` must match in `rela_needs_plt_got_entry()` and `count_max_entries()`, with `mod->arch.plt` and `got_plt` sharing `max_entries` and lockstep `num_entries`. `module_frob_arch_sections()` must sort a `scratch` copy so `SHT_RELA` `HI20`/`LO12` pairs stay adjacent; in `apply_relocate_add()`, `PCREL_LO12` searches must start/wrap from `j_idx`, `HI20` math must add `0x800` before `& 0xfffff000`, and 32-bit offsets must pass `riscv_insn_valid_32bit_offset()`. [F202, F203, F204, F253, F271]
- `thread_struct` fields accessed in `__switch_to` via `a3`/`a4` (or `__fstate_save`/`restore` via `fstate.f[0]`) need relative `TASK_THREAD_*_RA` (`_F0`) offsets in `asm-offsets.c`, plus `FREGS_T2`–`FREGS_T6` under `CONFIG_DYNAMIC_FTRACE_WITH_ARGS && CONFIG_CC_IS_CLANG`. `flush_thread()` must call `riscv_v_vstate_ctrl_init(current)`, `riscv_v_vstate_off()`, free `vstate.datap`, zero `vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE`. [F206, F208, F317]
- In `traps_misaligned.c`, FP helpers (`set_f32_rd`, `set_f64_rd`, `get_f32_rs`, `get_f64_rs`) must set `regs->status |= SR_FS_DIRTY`, and scalar load/store decoding must mask with `INSN_MASK_*` (including Zcb `C_LHU`/`C_LH`/`C_SH` and rejecting `C_LDSP`/`C_LWSP` with `rd == 0`). [F213, F244]
- `check_unaligned_access_all_cpus()` must unconditionally register `riscv_online_cpu`/`offline_cpu` and `riscv_online_cpu_vec` via `cpuhp_setup_state_nocalls()`. Probing runs only when per-CPU state is `*_UNKNOWN`, and must check `word_cycles && byte_cycles` before `div_u64()`. [F246, F267, F319]
- In `riscv_cpufeature_patch_func`, standard alternatives (`id < RISCV_ISA_EXT_MAX`) must skip `alt->vendor_id != 0`. `disable_xtheadvector()` must clear `RISCV_ISA_VENDOR_EXT_XTHEADVECTOR` in `all_harts_isa_bitmap` and all `per_hart_isa_bitmap[cpu]` before `apply_boot_alternatives()`. [F216, F247]
- In `riscv_parse_isa_string`, `case 's':` must check `ext[-1] != '_' && ext[1] == 'u'` before falling through to `'S'`/`'z'`/`'Z'`. In `riscv_fill_hwcap_from_isa_string`/`ext_list`, `riscv_isa` and `elf_hwcap` must copy/assign on the first valid hart (`bitmap_empty(riscv_isa, ...)` / `!elf_hwcap`) and intersect (`bitmap_and`/`&=`) on subsequent harts. [F248, F259]
- In `temp_pgtable_mapping` and `temp_pgtable_map_p4d`/`pud`/`pmd`, compute `next = *_addr_end(start, end)` before `if (*_none(...)) continue;`. `arch_check_kprobe` must step `tmp` from `(unsigned long)p->addr - p->offset` by `GET_INSN_LENGTH(*(u16 *)tmp)` and require `tmp == addr`. [F255, F261]
- `__sbi_v01_cpumask_to_hartmask()` must reject `hartid >= BITS_PER_LONG`, and `__sbi_rfence_v02()` must flush/reset `hmask` when `hartid + BITS_PER_LONG <= htop` or `hbase + BITS_PER_LONG <= hartid` before shifting. Every key in `0 .. RISCV_HWPROBE_MAX_KEY` must be handled in `hwprobe_one_pair()`. [F269, F327]

## Synchronization

- Under `CONFIG_MMU`, `__patch_insn_set()`/`write()` require `text_mutex`, disable preemption while `FIX_TEXT_POKE0`/`1` are mapped, flush local icache before `patch_unmap()`, and re-enable preemption after. In `patch_text_cb()`, the last CPU (`atomic_inc_return(&patch->cpu_count) == num_online_cpus()`) writes the insn and executes `atomic_inc_return_release(&patch->cpu_count)` before others call `local_flush_icache_all()`. [F155, F167]
- `get_cpu_vector_context()`/`put_cpu_vector_context()` must bracket `RISCV_KERNEL_MODE_V` with `local_bh_disable()`/`enable()` (`!PREEMPT_RT`) or `preempt_disable()`/`enable()` (`PREEMPT_RT`). `kernel_fpu_begin()`/`end()` must bracket `fstate_save()`/`restore()` and `SR_FS` with `preempt_disable()`/`enable()`. [F169, F173]
- In `riscv_v_start_kernel_context()`, non-nested start must set `RISCV_PREEMPT_V | RISCV_PREEMPT_V_DIRTY` before saving `thread.vstate`, then clear dirty; nested start (`riscv_preempt_v_started(current)`) must call `get_cpu_vector_context()`, save `kernel_vstate` if dirty, clear dirty, and set `RISCV_PREEMPT_V_NEED_RESTORE`. `riscv_v_context_nesting_start()`/`end()` require local IRQs disabled. [F170, F171, F212]
- `sbi_cpu_start()` needs `smp_mb()` before writing `boot_data[cpuid]` and another `smp_mb()` before `sbi_hsm_hart_start()`. `cpu_update_secondary_bootdata()` needs `smp_mb()` before `WRITE_ONCE()` to `__cpu_spinwait_stack_pointer`/`task_pointer`. [F174, F175]
- `smp_callin()` must call `riscv_ipi_enable()`, `set_cpu_online(curr_cpuid, true)`, and flush local icache/TLB before `complete(&cpu_running)` and `local_irq_enable()`. `__cpu_disable()` must call `set_cpu_online(cpu, false)` and `riscv_ipi_disable()` before `irq_migrate_all_off_this_cpu()`, and `arch_cpu_idle_dead()` must call `cpuhp_ap_report_dead()` before `cpu_ops->cpu_stop()`. [F176, F177]
- `riscv_ipi_set_virq_range()` must populate `ipi_desc[i]` and call `request_percpu_irq()` before `riscv_ipi_enable()`. `crash_smp_send_stop()` must `atomic_set(&waiting_for_crash_ipi, num_other_online_cpus())` before `IPI_CPU_CRASH_STOP`, and `ipi_cpu_crash_stop()` must call `crash_save_cpu()` before decrementing it. [F178, F179]
- `set_unaligned_access_static_branches()`/`_except_cpu()` require the CPU hotplug lock; `riscv_offline_cpu(cpu)` must use `_except_cpu(cpu)` (`num_online_cpus() - 1`) because `cpu` is still online. [F180, F214]
- `die()` must hold `raw_spin_lock_irqsave(&die_lock, flags)` and unlock + `oops_exit()` before `panic()`/`make_task_dead()`. `copy_code()` (called under `die_lock`) must use `get_kernel_nofault()` or `copy_from_user_nofault()` (only if `regs == task_pt_regs(current)`). [F182, F305]
- `setup_singlestep()` must clear `SR_SPIE` via `kprobes_save_local_irqflag()` and restore it in single-step or non-reentrant fault handlers. User-mode traps in `traps.c` (`DO_ERROR_INFO`, `do_trap_insn_illegal`, `do_trap_misaligned`, `do_trap_break`) must bracket handlers with `local_irq_enable()`/`disable()` inside `irqentry_enter`/`exit_from_user_mode()`. [F183, F304]

## Object Lifetimes

- Free `MISALIGNED_BUFFER_ORDER` pages with `__free_pages()` on all paths in `check_vector_unaligned_access()` and for all allocated `bufs[cpu]` on failure in `check_unaligned_access_speed_all_cpus()` before `kfree(bufs)`. [F152, F153]
- In `module.c`, allocate `relocation_hashtable` with `kvmalloc_array()` and free with `kvfree()`; `kfree()` `entry`/`rel_head` on error in `add_relocation_to_accumulate()`, and use `*_for_each_entry_safe` across all three nested loops in `process_accumulated_relocations()`. [F154, F250, F279]
- Release every `acpi_get_table()` with `acpi_put_table()` and every `device_node *` from `of_*` helpers with `of_node_put()` on all loop/exit paths (including `of_node_put(prev)` per iteration and `of_node_put(np)` after `break` in `populate_cache_leaves()`). [F156, F263, F297]
- In `load_extra_segments()`, `vfree(headers)` and `kvfree(fdt)` on error, or save on `image` for `arch_kimage_file_post_load_cleanup()` to free and NULL. In `sbi_ipi_init()`, call `irq_dispose_mapping(sbi_ipi_virq)` if `ipi_mux_create()` fails. Do not free `get_safe_page()` pages in `hibernate.c`. [F158, F161, F164]
- In `init_resources()`, `mem_res` fills backwards (`res_idx--`); skipping a reserved region in `memblock_is_memory()` requires `res_idx++` before `continue`. Free unused prefix slots via `memblock_free()`, or on `add_resource()` error call `release_child_resources(&iomem_resource)` and `memblock_free(mem_res, mem_res_sz)`. [F163, F260]
- `arch_dup_task_struct()` must save `src` FPU state before `*dst = *src`, then zero `dst->thread.vstate` and `kernel_vstate` and clear `TIF_RISCV_V_DEFER_RESTORE`. [F207]

## API Contracts

- `elf_kexec_load()` and `image_load()` return `NULL` on success and `ERR_PTR(ret)` on failure (after `kexec_free_elf_info(&elf_info)`). `__patch_insn_set()`/`write()` return `-EINVAL` if `len + offset_in_page(addr) > 2 * PAGE_SIZE`; use `patch_insn_set()`/`write()` for arbitrary lengths. [F186, F200]
- In `riscv_resolve_isa()`, `.validate` returns `0` (enable), `-EPROBE_DEFER` (retry), or other non-zero (disable); bound passes by `max_loop_count`, reset `loop = false`, and stop when `bitmap_equal(prev_resolved_isa, resolved_isa, RISCV_ISA_EXT_MAX)`. Bounds-check `bit` against `RISCV_ISA_EXT_MAX`/`RISCV_ISA_VENDOR_EXT_MAX` (and skip `RISCV_ISA_EXT_INVALID`) in ISA bitmap helpers; `NULL` bitmap selects `riscv_isa`, `cpu == -1` selects `all_harts_isa_bitmap`, and `riscv_cpufeature_patch_func()` must subtract `RISCV_VENDOR_EXT_ALTERNATIVES_BASE`. [F188, F189, F190, F242, F252]
- `sbi_ecall(e, f, a0..a5)` passes `(f, e)` last to `__sbi_ecall()`, whose asm binds `a0`–`a5`, `a6` (fid), `a7` (ext) with `"+r" (a0)`, `"+r" (a1)`, and `"memory"` clobber. [F191, F325]
- In `restore_sigcontext()`, validate `RISCV_V_MAGIC`, vector support/active state, and `size == riscv_v_sc_size` before `__restore_v_state()`, advance `sc_ext_ptr` past `sizeof(*head)` before dispatch, set `sc_ext_ptr = (void __user *)head + size` after, and terminate on `END_MAGIC` (`size == END_HDR_SIZE`). `__restore_v_state()` must call `riscv_v_vstate_set_restore()` before `copy_from_user()`. [F225, F262, F332]
- On ACPI systems, `setup_smp()` must precede `acpi_init_rintc_map()`, which must precede `acpi_map_cpus_to_nodes()`. `acpi_os_ioremap()` must reject ranges crossing an EFI descriptor or covering mapped kernel memory, and map `EFI_RUNTIME_SERVICES_CODE` and NOMAP RAM as `PAGE_KERNEL_RO`. [F289, F300]
- Accessing `CSR_ENVCFG` or pointer-masking requires checking `RISCV_ISA_EXT_SUPM` or `XLINUXENVCFG`, and `riscv_isa_ext[]` entries implying `CSR_ENVCFG` must include `riscv_xlinuxenvcfg_exts`. `riscv_v_setup_vsize()` must prefer non-zero `thead_vlenb_of` over `CSR_VLENB` and bracket `CSR_VLENB` reads with `riscv_v_enable()`/`disable()`. [F292, F293, F294]
- `cpu_suspend()` must bracket `__cpu_suspend_enter()` with `suspend_save_csrs()`/`pause_graph_tracing()` and `unpause_graph_tracing()`/`suspend_restore_csrs()` on all paths (mapping `finish() == 0` to `-EOPNOTSUPP`). On `swsusp_arch_suspend()` restore, call `suspend_restore_csrs()`, flush TLB/icache, and reset `in_suspend = 0`, `sleep_cpu = -EINVAL`. `swsusp_arch_resume()` must map linear memory and `restore_cpu_addr` in `resume_pg_dir`, and `relocate_restore_code()` must call `set_memory_x()`. [F302, F303, F324]
- `riscv_sys_mmap()` must reject `offset & (~PAGE_MASK >> page_shift_offset)` before shifting. Misaligned trap handlers must use fault-capable `copy_from_user()`/`copy_to_user()`/`get_user()` for user mode. Trap/IRQ/idle/stackwalk entry functions must be `noinstr` (`handle_riscv_irq()` using `irq_enter_rcu()`/`irq_exit_rcu()`), `unwind_user_frame()` must use `access_ok()` + `__copy_from_user_inatomic()`, `__get_wchan()` must use `try_get_task_stack()`/`put_task_stack()`, and both `boot_cpu_hartid` and `__cpuid_to_hartid_map` must be `EXPORT_SYMBOL_GPL`. [F275, F306, F321, F322, F326]

## Error Handling

- Zero-initialize stack `struct kexec_buf kbuf = {}` and reset `kbuf.mem = KEXEC_BUF_MEM_UNKNOWN` before reuse. In `__setup_additional_pages()`, convert `IS_ERR_VALUE(vdso_base)` via `ERR_PTR()` and reset `mm->context.vdso = NULL` on `up_fail`. [F185, F199]
- `check_unaligned_access_all_cpus()` must check `!has_vector()` (setting `UNSUPPORTED`) before vector checks, and compare `unaligned_scalar_speed_param`/`unaligned_vector_speed_param` against `*_UNKNOWN` before `else if` probing branches. [F187, F245]
- `sbi_probe_extension()` returns `0` on error/unsupported and `> 0` when supported; `sbi_debug_console_write()`/`read()` must map `SBI_ERR_FAILURE` to `-EIO` before `sbi_err_map_linux_errno()`. [F192]
- Check `!relocation_hashtable` (not `!hashtable_bits`) in `apply_relocate_add()`. Check `relocated_restore_code == -ENOMEM` in `swsusp_arch_resume()` and reset `sleep_cpu = -EINVAL` on error in `arch_hibernation_header_restore()`. Check `of_get_cpu_hwid() != ~0UL` and `riscv_hartid_to_cpuid() >= 0` (in a signed `int`). Never call `die()`/`WARN*()` on user faults; gate logging with `show_unhandled_signals` and ratelimiting. [F193, F194, F196, F337]

## External Contracts

- Zero `sc->sc_extdesc.reserved` and `sc_fpregs->q.reserved[]` on signal delivery and reject non-zero with `-EINVAL` on sigreturn; terminate `sc_extdesc.hdr` with `END_MAGIC`/`END_HDR_SIZE`; always set `regs->a1 = &frame->info` and `regs->a2 = &frame->uc` in `setup_rt_frame()`/`compat_setup_rt_frame()`. [F227, F333, F334]
- Under `CONFIG_RISCV_ISA_SUPM`, user pointer masking length is in `task->thread.envcfg & ENVCFG_PMM` (`envcfg_update_bits()`), while `mm->context.pmlen` is locked by `MM_CONTEXT_LOCK_PMLEN` on `CLONE_VM`; `set_tagged_addr_ctrl()` must reject compat threads (`-EINVAL`) and check `MM_CONTEXT_LOCK_PMLEN` (`-EBUSY`) under `mmap_write_lock_killable(mm)`. [F209, F335]
- In `init_resources()`/`reserve_memblock_reserved_regions()`, resource `.end` is inclusive (`base + size - 1`) and memblock-reserved RAM sub-ranges must be split via `reserve_region_with_split()`. Keep `riscv_isa_ext[]` in canonical ISA order for `/proc/cpuinfo`. [F240, F298]
- Unknown hwprobe keys must set `pair->key = -1` without aborting; in `hwprobe_isa_ext0()`, guard `EXT_KEY()` with `has_vector()` or `IS_ENABLED(CONFIG_...)` where kernel support is required. On 32-bit builds, split 64-bit args in `__sbi_set_timer_v01()`/`v02()` and `sbi_debug_console_write()`/`read()`. [F249, F270, F329]

## Known Pitfalls

- `check_unaligned_access_nonboot_cpu()` must skip CPU 0 so it can service timer IRQs while other CPUs spin on `time_before(jiffies, ...)`. In `__switch_to`, mask `TASK_THREAD_SUM_RA(a4)` with `SR_SUM` before `csrs CSR_STATUS, s0`. [F181, F205, F268]
- Slot 0 of `pt_regs` is `epc`, not `x0`: guard `reg_num == 0` when indexing `(unsigned long *)regs`, and read `rs1_index` before writing `rd_index` in `simulate_jalr()`. [F219, F229]
- Return `-1UL` in `get_sigframe()`/`compat_get_sigframe()` if `on_sig_stack(sp) && !on_sig_stack(sp - framesize)`. `sizeof(struct rt_sigframe)` already includes the `END_MAGIC` header in `get_rt_frame_size()`. Use `offsetof(struct __riscv_v_ext_state, datap)` when copying/zeroing vector state metadata, and `sizeof(sc->sc_regs)` (not `sizeof(*regs)`) when copying GPRs. [F230, F276, F277, F278]
- Do not dereference loop cursors `rel_head_iter` or `md` after the loop. In `riscv_alternative_fix_offsets`, check `i < num_insn - 1` and increment `i++` for `auipc`+`jalr`, and skip `jal` targets inside `[alt_ptr, alt_ptr + len)`. [F251, F254]
- Store `args->flags` in `u64 clone_flags` in `copy_thread()`. In `perf_regs.c`, use `1ULL << PERF_REG_RISCV_MAX` for `REG_RESERVED` and cast `idx` to `u32` in `perf_reg_value()`. [F264, F274]
- In `handle_scalar_misaligned_load()`, zero `val.data_u64` and cast `(val.data_ulong << shift)` to `long` before right-shifting. Mask 16-bit `insn` with `GENMASK(15, 0)` in `get_insn()`, cast upper 16-bit parcels to `u32` before `<< 16`, sign-extend immediates to `s32` in `simulate-insn.c`, and cast `u32 *` probe pointers to `(void *)`/`unsigned long` before adding byte lengths. [F265, F266, F272, F273, F280]
- Check `name_end - name == strlen(ext->name)` before `strncasecmp()` in `match_isa_ext()`, and use `bitmap_*()` helpers on multi-word ISA bitmaps. Mark callers of `__init` as `__init`, `_apply_alternatives()`/`riscv_cpufeature_patch_func()` as `__init_or_module`, and never pass vmalloc or `DEFINE_PER_CPU()` addresses to `__pa()` for SBI calls. [F283, F284, F299, F314]
