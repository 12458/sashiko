# NETWORKING [IPv4/IPv6] — net/ipv4 (part 5)

Implements the core TCP receive engine (`tcp_input.c`), IPv4 TCP protocol glue (`tcp_ipv4.c`), TIME-WAIT and SYN-RECV minisocks (`tcp_minisocks.c`), peer TCP metrics cache (`tcp_metrics.c`), TCPv4 GSO/GRO offload (`tcp_offload.c`), and Illinois/NV congestion control.

## Architecture & Data Flow
- `tcp_can_ingest()` tests `sk_rmem_alloc + skb->len <= sk->sk_rcvbuf` using `skb->len` (not `truesize`), and `tcp_prune_queue()` returns `-1` before `tcp_clamp_window()` if `sk_rmem_alloc == 0`. `tcp_event_data_recv()` and `tcp_data_queue_ofo()` must call `tcp_measure_rcv_mss()` (widening `(u64)skb->len << TCP_RMEM_TO_WIN_SCALE`, flooring `scaling_ratio` at `1`), while `tcp_data_queue_ofo()` only calls `tcp_rcvbuf_grow()` when `sk->sk_socket != NULL`. [F51, F62, F63, F114, F159]
- When `tp->out_of_order_queue` is non-empty, `tp->ooo_last_skb` must equal `skb_rb_last()` across tail inserts (`tcp_data_queue_ofo`), collapse (`tcp_collapse_ofo_queue`), and tail pruning (`tcp_prune_ofo_queue`). In `tcp_collapse()` (`list == NULL`), queue new `nskb`s onto `tmp` and only call `tcp_rbtree_insert()` at `end:`. [F67, F100]
- In `tcp_add_backlog()`, undo `__skb_pull(skb, hdrlen)` with `__skb_push()` if `skb_try_coalesce()` fails, and on success propagate FIN to `thtail->fin` and `TCP_SKB_CB(tail)->tcp_flags`. Both `tcp_add_backlog()` and `tcp_ooo_try_coalesce()` saturate combined `gso_segs` via `min_t(u32, ..., 0xFFFF)`. [F86, F166]
- `tcp_mark_skb_lost()` calls `tcp_verify_retransmit_hint()` before mutating `lost_out`/`retrans_out`. `tcp_skb_shift()` rejects shifts when `to->len + shiftlen >= 65535 * TCP_MIN_GSO_SIZE` or `tcp_skb_pcount(to) + pcount > 65535`. [F64, F85]
- In `tcp_sacktag_write_queue()`, clamp `num_sacks` to `min(TCP_NUM_SACKS, (ptr[1] - TCPOLEN_SACK_BASE) >> 3)`, set `first_sack_index = -1` if `i == 0` is discarded, and update it to `j + 1` when `j == first_sack_index` swaps. In `tcp_sack_maybe_coalesce()` and `tcp_sack_remove()`, after shifting `selective_acks` down at `this_sack`, `continue` without incrementing `this_sack` or `swalk`/`sp`. [F83, F101, F102]
- Advance established `snd_una`/`rcv_nxt` via `tcp_snd_una_update()`/`tcp_rcv_nxt_update()` (and `twsk_rcv_nxt_update()` in `TCP_FIN_WAIT2`). TCP-AO SNE wraparound in `tcp_snd_sne_update()`, `tcp_rcv_sne_update()`, and `twsk_rcv_nxt_update()` uses unsigned `<` (not `before()`), whereas `tcp_in_window()` uses `after(end_seq, s_win) && before(seq, e_win)` (plus zero-length boundary equality). [F79, F124, F125]
- `tcp_rcv_established()` and `tcp_ack()` must not update `ts_recent` (`__tcp_replace_ts_recent`) until checksum and window checks pass. When `tp->retrans_stamp == 0`, `tcp_packet_delayed()` returns `false` if `(!tcp_is_sack(tp) && !before(tp->snd_una, tp->high_seq))` or `sk->sk_state == TCP_SYN_SENT`. [F77, F97]
- Non-EOL/NOP options in `tcp_parse_options()`, `tcp_parse_mss_option()`, and `tcp_do_parse_auth_options()` must check `length >= 2` and `opsize` in `[2, length]`. In `tcp_parse_options()`, `ptr` is 2 bytes past `opcode`/`opsize`, so offsets (`sacked`, `accecn`) are `(ptr - 2) - (unsigned char *)th`, iterations advance `ptr` by `opsize - 2` and `length -= opsize`, `snd_wscale` is clamped to `TCP_MAX_WSCALE` (14, or 0 if `!wscale_ok`), and `tcp_parse_fastopen_option()` requires `syn && len >= 0 && !(len & 1)` with `len` in `[TCP_FASTOPEN_COOKIE_MIN, TCP_FASTOPEN_COOKIE_MAX]` (else `foc->len = -1`). [F80, F82, F116, F134]
- `delivered_ecn_bytes`/`received_ecn_bytes` are indexed by `ecnfield - 1`, requiring `ecnfield != INET_ECN_NOT_ECT`. `__tcp_accecn_process()` computes `est_d_cep` via `DIV_ROUND_UP_ULL((u64)d_ceb * delivered_pkts, delivered_bytes)` after checking `!d_ceb` and `delivered_bytes <= d_ceb`. [F84, F122]
- `tcp_update_pacing_rate()` guards `do_div(rate, tp->srtt_us)` with `if (likely(tp->srtt_us))` (`tcp_rtt_estimator()` clamps `srtt_us = max(1U, srtt)`). `tcp_cwnd_reduction()` checks `tp->prior_cwnd != 0` before `div_u64()` and uses `(u64)tp->snd_ssthresh * tp->prr_delivered + tp->prior_cwnd - 1` when `delta < 0`. [F119, F120]
- `tcp_gso_segment()` clears `fin`/`psh` on non-final segments (`while (skb->next)`), masks `th->cwr &= ecn_cwr_mask` (`SKB_GSO_TCP_ACCECN`) on subsequent segments, and with `tcp_dsack_seen()` uses `DIV_ROUND_UP` for segment counts. [F109, F123]
- In `tcp_metrics_flush_all()`/`tcp_metrics_nl_cmd_del()`, advance `pp = &tm->tcpm_next` only when `tm` is not unlinked. In `tcp_metrics_nl_dump()`, reset `s_col = 0` when `row` increments, advance `col` on every node, and save `row`/`col` to `cb->args[0..1]` at `done:`. [F104, F105]
- `struct illinois`/`struct tcpnv` must fit in `ICSK_CA_PRIV_SIZE`. `tcp_illinois_acked()` clamps `rtt_us` to `RTT_MAX`, `update_params()`/`tcp_illinois_info()` check `cnt_rtt > 0` before dividing, and `beta()` returns `BETA_MAX` if `d3 <= d2`. `tcpnv_cong_avoid()` negates negative `cwnd_growth_factor` before `<<` (bounded `>= -8`) and floors `>>` with `max(4U, ...)`, while `tcpnv_acked()` uses `do_div(rate64, avg_rtt ?: 1)` and `div64_u64(..., 80000ULL * tp->mss_cache)`. [F111, F117, F118, F121, F131]

## Synchronization
- `tcp_add_backlog()` requires `bh_lock_sock(sk)`: returning `false` keeps the lock and consumes `skb`; returning `true` has already unlocked `sk` and leaves `skb` to drop. `tcp_child_process()` requires `bh_lock_sock(child)` and a ref, queues to `__sk_add_backlog()` if `sock_owned_by_user(child)`, and unconditionally unlocks and puts `child`. [F7, F33]
- Even under socket lock, `tcp_data_queue_ofo()`, `tcp_queue_rcv()`, `tcp_collapse()`, and `tcp_try_coalesce()` must update `sk_rmem_alloc` atomically (`skb_set_owner_r()` / `atomic_add()`) because `sock_queue_err_skb()` modifies it locklessly. [F17]
- Ordering: `tcp_rcv_synsent_state_process()` and `tcp_rcv_state_process()` must `WRITE_ONCE(tp->copied_seq, tp->rcv_nxt)` and `smp_mb()` before `TCP_ESTABLISHED`; `tcp_done_with_error()` needs `smp_wmb()` between `WRITE_ONCE(sk->sk_err, err)` and `tcp_done(sk)`; `tcp_check_space()` needs `smp_mb()` before testing `SOCK_NOSPACE`; `clean_acked_data_enable()` sets `tcp_clean_acked` before incrementing `clean_acked_data_enabled` (reversed in `clean_acked_data_disable()`). [F20, F21, F22, F38]
- In `tcp_rcv_state_process()` (`TCP_LISTEN`), wrap `conn_request()` in `rcu_read_lock()` and `local_bh_disable()`. On `TCP_TW_SYN`, writing `tcp_tw_isn` in `tcp_v4_rcv()` and consuming/zeroing it in `tcp_conn_request()` must stay in the same BH-disabled section. [F31, F154]
- In `tcp_v4_err()` and `tcp_ld_RTO_revert()`, `bh_lock_sock(sk)` cannot mutate queues/routes/state when `sock_owned_by_user(sk)`; `ICMP_FRAG_NEEDED` defers `tcp_v4_mtu_reduced()` via `TCP_MTU_REDUCED_DEFERRED` on `sk_tsq_flags` with `sock_hold(sk)`. [F27]
- In `tcp_v4_send_reset()`/`tcp_v4_send_ack()`, wrap `ipv4_tcp_sk.sock` in `local_bh_disable()` and `local_lock_nested_bh(&ipv4_tcp_sk.bh_lock)`, restoring `sock_net_set(ctl_sk, &init_net)` and `xfrm_sk_free_policy(ctl_sk)` before unlocking. [F26]
- Reading `tp->md5sig_info` requires `rcu_read_lock()` or socket lock; mutations require socket lock and `hlist_del_rcu()`/`kfree_rcu()`. In BH (`tcp_md5_key_copy()`), use `sk_gfp_mask(sk, GFP_ATOMIC)`, `tcp_md5_add_sigpool()`, and `static_key_fast_inc_not_disabled(&tcp_md5_needed.key.key)`. Pair successful `tcp_sigpool_start()` in `tcp_v4_md5_hash_hdr()`/`_skb()` with `tcp_sigpool_end()`. [F29, F146, F148]
- Hashed timewait sockets have no lock: access `tw_substate`, `tw_rcv_nxt`, `tw_ts_recent`, `tw_ts_recent_stamp`, and `tw_entry_stamp` via `READ_ONCE()`/`WRITE_ONCE()`. `get_tcp4_sock()` reads `icsk_pending` via `smp_load_acquire()` and clamps `READ_ONCE(tp->rcv_nxt) - READ_ONCE(tp->copied_seq)` with `max_t(int, ..., 0)`. [F40, F41]
- In `/proc/net/tcp` and BPF iterators, ehash locks use `spin_lock_bh`/`spin_unlock_bh` while `lhash2` uses `spin_lock`/`spin_unlock`. `bpf_iter_tcp_batch()` calls `bpf_iter_tcp_unlock_bucket()` before `GFP_USER` realloc or return (`GFP_NOWAIT` on locked retry). If `bpf_iter_tcp_resume_bucket()` returns `NULL` in `bpf_iter_tcp_resume_listening()`/`_established()`, unlock `st->bucket` before incrementing `st->bucket` and calling `*_get_first()`. [F35, F106, F149]
- In `tcp_metrics.c`, read netns via `dst_dev_net_rcu(dst)`. Under `spin_lock_bh(&tcp_metrics_lock)` in `tcpm_new()`, re-check `__tcp_get_metrics()` and initialize `tcpm_net`, addresses, and `tcpm_suck_dst()` (`fastopen_clear = true` on `reclaim`) before `rcu_assign_pointer()`. Protect `tm->tcpm_fastopen` with `fastopen_seqlock` (`write_seqlock*` / `read_seqbegin`+`read_seqretry`). [F24, F25, F75, F139]

## Object Lifetimes
- Release sockets from `__inet_lookup_established()` or ehash (`bpf_tcp_iter_state.batch`) via `sock_gen_put()`, not `sock_put()`. In `tcp_v4_syn_recv_sock()`, clear `ireq->ireq_opt = NULL` when `*own_req` is true, and `newinet->inet_opt = NULL` when `*own_req` is false or on `put_and_exit`. [F1, F3]
- `tcp_create_openreq_child()` clones `newsk` (`sk_refcnt == 2`, BH locked), zeroing/reinitializing `md5sig_info`, `ao_info`, `fastopen_req`, `fastopen_rsk`, `tsq_node`, `tsorted_sent_queue`, and `sk_user_frags`; aborting `newsk` before hashing requires `inet_csk_prepare_forced_close(newsk)` before `tcp_done(newsk)`. [F4, F73]
- In `tcp_time_wait()`, initialize all `tw`/`tcptw` fields before `inet_twsk_hashdance_schedule()` and never touch `tw` after. `tcp_sk_exit_batch()` runs `tcp_twsk_purge()` under `tcp_exit_batch_mutex` before `inet_pernet_hashinfo_free()` and checking `tw_refcount == 0`. [F16, F18]
- Unwind TCP-MD5 sigpool, key/info, and `tcp_md5_needed` in reverse order on failure and in `tcp_twsk_destructor()`. `tcp_md5_do_del()` and `tcp_clear_md5_list()` must `atomic_sub(sizeof(*key), &sk->sk_omem_alloc)` when freeing keys. Pair starting unqueued `compressed_ack_timer` in `__tcp_ack_snd_check()` with `sock_hold(sk)`, calling `__sock_put(sk)` in `tcp_sack_compress_send_ack()` only if `hrtimer_try_to_cancel() == 1`. [F11, F15, F130]
- Before `tcp_rtx_queue_unlink_and_free()`, update `retransmit_skb_hint` and `highest_sack`. In `tcp_sacktag_walk()`, if `tcp_shift_skb_data()` returns `tmp && tmp != skb`, set `skb = tmp` and `continue`. In `tcp_clean_rtx_queue()`, check `if (skb)` after the loop. [F66, F98, F99]
- In `tcp_ofo_queue()`, `break` after `tcp_fin(sk)` (purges rbtree). In `tcp_prune_ofo_queue()`, pass `in_skb` (not freed `skb`) to `tcp_can_ingest()`. In `tcp_v4_rcv()`, reload `th`/`iph` after `pskb_may_pull()`, `skb_checksum_init()`, or `tcp_filter()`. [F68, F69, F94]
- In `tcp_gso_segment()`, if `gso_skb->destructor == tcp_wfree`, `swap()` destructor/ownership to the final segment and adjust `sk_wmem_alloc` via `refcount_add()` or `refcount_sub_and_test(-delta, ...)`. Unlink `tcp_metrics_block` with `rcu_assign_pointer()` and `kfree_rcu()`. `tcp_v4_destroy_sock()` calls `tcp_release_user_frags(sk)` before `xa_destroy(&sk->sk_user_frags)`. [F39, F141, F174]

## API Contracts
- `tcp_timewait_state_process()` consumes `tw` ref on `TCP_TW_SUCCESS`, leaving it held on `TCP_TW_ACK`/`ACK_OOW`/`RST`/`SYN`. `tcp_rcv_synsent_state_process()` returns `-1` (run step 6 on `TCP_ESTABLISHED`), `0` (consumed/dropped), or `> 0` (`skb_drop_reason` to RST+drop). When `!fastopen`, `tcp_check_req()` returns `NULL`, listener `sk` (send RST), or locked child `nsk != sk`. [F5, F43, F44]
- `tcp_do_parse_auth_options()` zeroes `*md5_hash`/`*ao_hash` and points `*ao_hash` past the 2-byte header; `tcp_parse_auth_options()` subtracts 2 for `struct tcp_ao_hdr *`. Pre-clear `opt_rx` (`tcp_clear_options()`) and set `foc->len = -1` before `tcp_parse_options()`. [F58, F59]
- `tcp_md5_do_lookup_exact()` and `__tcp_md5_do_add()` bound `addr` ops to `sizeof(struct in_addr)` or `sizeof(struct in6_addr)` (never `sizeof(*addr)`), and attaching MD5 keys calls `sk_gso_disable()`. [F129, F168]
- `tcp_gso_segment()`/`tcp4_gso_segment()` return `ERR_PTR`, `NULL` (`skb_gso_ok()`), or segments; copy `SKBTX_ANY_TSTAMP` and `tskey` only where `before(ts_seq, seq + mss)`. For `SKB_GSO_FRAGLIST`, `tcp4_gso_segment()` only calls `__tcp4_gso_segment_list()` if `skb_pagelen(skb) - th->doff * 4 == gso_size`, else calls `__tcp_v4_send_check()`. In `tcp_gro_receive()` (`is_flist`), call `skb_set_network_header(skb, skb_gro_receive_network_offset(skb))` before `skb_gro_receive_list()`. [F46, F160, F161, F164]
- `parse_nl_addr()` returns `0`, `-EAFNOSUPPORT` (`!optional`), or `+1` (`optional`). `tcp_illinois_info()`/`tcpnv_get_info()` test `ext & (1 << (INET_DIAG_VEGASINFO - 1))` and set `*attr = INET_DIAG_VEGASINFO`. `bpf_iter_tcp_seq_show()` only locks/calls `sk_uid()` when `sk_fullsock(sk)` (checking `sk_unhashed(sk)`, using `req->rsk_listener` for `TCP_NEW_SYN_RECV`). `tcp_set_hashinfo()` reads `sysctl_tcp_child_ehash_entries` from `current->nsproxy->net_ns`. [F49, F60, F173, F176]

## Error Handling
- `tcp_ack()` returns `1`, `0`, or `-SKB_DROP_REASON_*` (cast to `int` for `< 0` and negate for `tcp_drop_reason()`). `tcp_match_skb_to_sack()` returns `1`, `0`, or `< 0` errno (`tcp_sacktag_walk()` breaks on `< 0`). Rejections after `tcp_parse_options()` in `tcp_rcv_synsent_state_process()` must jump to `discard_and_undo`/`reset_and_undo` (`tcp_clear_options()`, restore `saved_clamp`). [F42, F47, F78]
- Replace `TCP_METRICS_RECLAIM_PTR` (`0x1UL`) from `__tcp_get_metrics()` with `NULL`. `tcp_v4_md5_hash_hdr()`/`_skb()` must `memset(md5_hash, 0, 16)` on error, and `__tcp_md5_do_add()` allocates `tcp_md5sig_key` with `__GFP_ZERO`. In `tcp_v4_connect()`, set `rt = NULL` on `ERR_PTR` or after `sk_setup_caps()`. `bpf_skops_parse_hdr()`/`_established()` zero `bpf_sock_ops_kern` up to `temp` and check `if (skb)` before `bpf_skops_init_skb()`. [F45, F48, F53, F56, F57]

## External Contracts
- `tcp_v4_parse_md5_keys()` checks `optlen >= sizeof(struct tcp_md5sig)`, `tcpm_prefixlen <= 32`, `tcpm_keylen <= TCP_MD5SIG_MAXKEYLEN`, and `netif_is_l3_master(dev)` for `TCP_MD5SIG_FLAG_IFINDEX`. `tcp_v4_pre_connect()` and `tcp_v4_connect()` reject `addr_len < sizeof(struct sockaddr_in)`. `tcpm_suck_dst()` scales `RTAX_RTT`/`RTTVAR` by `USEC_PER_MSEC`, and `tcp_metrics_fill_info()` emits `i + 1` attributes with `TCP_METRIC_RTT`/`RTTVAR` `/ 1000` (clamped `>= 1`). `tcp4_seq_show()` pads lines to `TMPSZ - 1` (149) and formats pointers with `%pK`. [F90, F138, F170, F171, F172]

## Known Pitfalls
- Lookup results and `@sk` in `tcp_v4_send_reset()`/`_ack()` may be `TCP_TIME_WAIT` or `TCP_NEW_SYN_RECV` minisocks: check `sk_state`/`sk_fullsock(sk)` before `tcp_sk()`/`inet_sk()`, locking, or reading full-sock fields (`tw_mark`, `tw_priority`, `tw_txhash` on `TCP_TIME_WAIT`). When `tp->fastopen_rsk != NULL`, `tcp_v4_err()` checks `tcp_rsk(fastopen)->snt_isn` (not `snd_una`) and skips `tcp_ld_RTO_revert()`, and `tcp_rearm_rto()` returns early. [F50, F52, F136]
- `tcp_v4_fill_cb()` moves `IPCB(skb)` to `&TCP_SKB_CB(skb)->header.h4` + `barrier()` before writing `TCP_SKB_CB`, and `tcp_v4_restore_cb()` restores it before re-lookup in `tcp_v4_rcv()`. In `tcp_v4_do_rcv()`, pass `nsk` (`rsk`), not `sk`, to `tcp_v4_send_reset()` when `tcp_child_process()` fails. [F88, F108]
- `tcp_shifted_skb()` calls `tcp_sacktag_one()` before `TCP_SKB_CB(skb)->seq += shifted`. `tcp_ofo_queue()` keeps `dsack_high` invariant at initial `tp->rcv_nxt`. `tcp_validate_incoming()` only increments `LINUX_MIB_BEYOND_WINDOW` on `TCP_INVALID_SEQUENCE`/`END_SEQUENCE`. Read wire option multi-byte fields with `get_unaligned_be16`/`be32`. [F65, F81, F93, F95]
- Casts: in `tcp_add_backlog()`, cast `sk_rcvbuf` to `u64` (`<< 1`), `sk_sndbuf` to `u32` (`>> 1`), and clamp `limit` to `UINT_MAX`; in `tcp_ack()`, use `min_t(u64, tp->max_window, tp->bytes_acked)`; in `tcp_rtt_tsopt_us()` (`!tcp_usec_ts`), bound `delta < INT_MAX / (USEC_PER_SEC / TCP_TS_HZ)`; cast `tcp_jiffies32 - val` in `__tcp_oow_rate_limited()` and `ts_recent - rcv_tsval` in `tcp_timewait_state_process()`/`tcp_disordered_ack_check()` to `s32`. [F112, F113, F115, F126, F127]
