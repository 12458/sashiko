# MEMORY MANAGEMENT - CORE — (top level)

Core memory management and arch-independent page table layer (`mm/memory.c`, `mm/mmu_notifier.c`, `mm/highmem.c`, `mm/maccess.c`, `mm/debug.c`, `mm/folio-compat.c`, `mm/mmzone.c`, `mm/init-mm.c`, `mm/internal.h`, `include/linux/pgtable.h`), handling page faults, page table zapping/remapping, cross-process VM access, highmem mappings, nofault copies, and MMU notifiers.

## Architecture & Data Flow

- Device-exclusive swap entries retain their folio rmap mapcount and reference while non-present: `restore_exclusive_pte()` must not add to the folio rmap count, and `zap_nonpresent_ptes()` must call `folio_remove_rmap_pte()` and `folio_put()` for both device-private and device-exclusive entries. [F196]
- In `do_swap_page()`, `arch_swap_restore(folio_swap(entry, folio), folio)` must run before `swap_free_nr()` and `folio_free_swap()`; in `can_swapin_thp()`, `swap_pte_batch()`, `swap_zeromap_batch()`, and `non_swapcache_batch()` must all equal `nr_pages` before `alloc_swap_folio()` allocates a large folio. [F259, F290]
- When `do_wp_page()` clears uffd-wp in place (`userfaultfd_wp_async(vma)`) via `set_pte_at()`, it must update `vmf->orig_pte` to the modified `pte` before CoW handling; in `do_page_mkwrite()`, `vmf->flags` must be saved and restored around `page_mkwrite(vmf)`. [F253, F254]
- `handle_pte_marker()` must test `PTE_MARKER_POISONED` (`VM_FAULT_HWPOISON`) and `PTE_MARKER_GUARD` (`VM_FAULT_SIGSEGV`) before `pte_marker_entry_uffd_wp(entry)`. `gup_must_unshare()` must check `(flags & (FOLL_WRITE | FOLL_PIN)) != FOLL_PIN` so `FOLL_PIN` is set and `FOLL_WRITE` is clear. [F292, F294]
- In `mm/mmu_notifier.c`, `interval_sub->interval_tree` stores inclusive `[start, start + length - 1]`: `__mmu_interval_notifier_insert()` must reject `length == 0` or overflow with `-EOVERFLOW`, and `mn_itree_inv_start_range()`/`mn_itree_inv_next()` must query `[range->start, range->end - 1]`. `subscriptions->invalidate_seq` must be even when idle and odd (`seq |= 1`) while invalidating, and `interval_sub->invalidate_seq` must always be odd. [F275, F304]
- Under `kmap_lock` in `mm/highmem.c`, `kunmap_high()` only decrements `pkmap_count[nr]` to `1`; only `flush_all_zero_pkmaps()` transitions `1` to `0` while clearing `pkmap_page_table[i]`, `set_page_address(page, NULL)`, and flushing TLB. `kmap_local` fixmap addresses grow downward from `FIX_KMAP_BEGIN` (`addr >= __fix_to_virt(FIX_KMAP_END) && addr <= __fix_to_virt(FIX_KMAP_BEGIN)`, `&__kmap_pte[-idx]`); under `CONFIG_DEBUG_KMAP_LOCAL`, `kmap_local_idx_push()` steps by `KM_INCR` (2), leaving even `kmap_ctrl.pteval[]` slots as guard pages that sched out/in must skip. [F262, F278, F279]
- In `free_pgd_range()` and `free_p4d/pud/pmd_range()`, upper-bound checks must compare `end - 1 > ceiling - 1` and `addr > end - 1`, returning early if masking a non-zero `ceiling` yields `0`. In `unmap_mapping_pages()` and `unmap_mapping_range()`, `nr == 0` (`holelen == 0`) or `start + nr - 1 < start` must clamp `last_index` to `ULONG_MAX`. [F273, F274]
- In `__access_remote_vm()` and `__copy_remote_vm_str()`, `addr` must be untagged via `untagged_addr_remote(mm, addr)` under `mmap_read_lock_killable(mm)` before `vma_lookup()` or `get_user_page_vma_remote()`; in `__copy_remote_vm_str()`, when `strscpy()` returns `-E2BIG` and `bytes != len`, `maddr + (PAGE_SIZE - 1)` must be copied to `buf + bytes - 1`. [F276, F277]
- `copy_from_kernel_nofault()` and `strncpy_from_kernel_nofault()` must check `copy_from_kernel_nofault_allowed()` (`-ERANGE` on failure), while `copy_from_user_nofault()` checks `__access_ok()` and `nmi_uaccess_okay()`; without `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`, `copy_from/to_kernel_nofault()` must gate `u64`/`u32`/`u16` loops on `((unsigned long)dst | (unsigned long)src)` alignment. [F281, F282]
- File-mapping `xa_state` updates (`!dax_mapping && !shmem_mapping`) must call `mapping_set_update(xas, mapping)` to set `workingset_update_node` and `&shadow_nodes` together. `lruvec_init()` must poison `lruvec->lists[LRU_UNEVICTABLE]` via `list_del()`. `fault_around_bytes_set()` must clamp `val >= PAGE_SIZE` and reject `val / PAGE_SIZE > PTRS_PER_PTE` before `rounddown_pow_of_two(val) >> PAGE_SHIFT`. [F246, F267, F311]

## Synchronization

- Every successful `follow_pfnmap_start(args)` holds `args->lock` and maps `args->ptep`, requiring `follow_pfnmap_end(args)` before dropping `mmap_lock`/`i_mmap_rwsem`; in `generic_access_phys()`, after `follow_pfnmap_end()` and `ioremap_prot()`, `follow_pfnmap_start(&args)` must run again to reverify `pgprot`, `pfn`, and `writable` across `memcpy_toio()`/`memcpy_fromio()`. [F203, F224]
- Before `pgd/p4d/pud/pmd_populate*()`, `smp_wmb()` must follow page table initialization. Before mapping a newly allocated or COW-copied folio via `set_ptes()`/`set_pte_at()` (`do_anonymous_page()`, `wp_page_copy()`, `do_cow_fault()`, `copy_present_page()`), `__folio_mark_uptodate()` must be called after writing page contents. [F211, F342]
- `__do_fault()` must preallocate `vmf->prealloc_pte` before `vma->vm_ops->fault(vmf)` or `folio_lock(folio)`. Under `FAULT_FLAG_VMA_LOCK`, `__vmf_anon_prepare()` must `mmap_read_trylock(vma->vm_mm)` before `__anon_vma_prepare(vma)`, calling `vma_end_read(vmf->vma)` and returning `VM_FAULT_RETRY` on failure. [F223, F338]
- `__wp_can_reuse_large_anon_folio()` must acquire `folio_lock_large_mapcount(folio)` and reverify `FOLIO_MM_IDS_SHARED_BITNUM` and `folio_large_mapcount(folio) != folio_ref_count(folio)` under it; `wp_can_reuse_anon_folio()` must reverify `folio_test_ksm(folio)` and `folio_ref_count(folio)` after `folio_trylock(folio)` (and freeing swapcache) before `folio_move_anon_rmap()`. [F218, F219]
- In `copy_page_range()`, COW mappings (`is_cow_mapping(src_vma->vm_flags)`) require write-locking `src_vma` and bracketing with `mmu_notifier_invalidate_range_start/end()` and `raw_write_seqcount_begin/end(&src_mm->write_protect_seq)`. In `copy_pte_range()`, `dst_ptl` must be acquired before `spin_lock_nested(src_ptl, SINGLE_DEPTH_NESTING)`. [F227, F336]
- In `zap_pte_range()`, breaking early (`need_resched()` or `force_break`) to drop `ptl` and retry must set `direct_reclaim = false` so `try_get_and_clear_pmd()` cannot reclaim a concurrently repopulated PTE page. [F220]
- `remove_device_exclusive_entry()` must pin `folio` with `folio_try_get(folio)` before `folio_lock_or_retry()` and re-checking `pte_same()` under PTL. `folio_evictable()` must hold `rcu_read_lock()` across `folio_mapping(folio)` and `mapping_unevictable()`. [F334, F340]
- `__mmu_notifier_register()` must allocate `mmu_notifier_subscriptions` before `mm_take_all_locks(mm)` and publish `mm->notifier_subscriptions` with `smp_store_release()`, pairing with `smp_load_acquire()` in unlocked readers (`mmu_interval_notifier_insert()`). `mn_hlist_release()` and `mmu_notifier_unregister()` must both use `hlist_del_init_rcu()` under `subscriptions->lock` and call `synchronize_srcu(&srcu)` before returning/`mmdrop()`. [F213, F214]
- Callers of `mmu_interval_notifier_remove()` and `mmu_interval_read_begin()` must not hold locks taken inside `invalidate`/`invalidate_range_start` callbacks because they sleep on `subscriptions->wq`. `mn_itree_inv_end()` must drain `deferred_list` with `hlist_for_each_entry_safe()` under `subscriptions->lock`, checking `RB_EMPTY_NODE()` to choose `interval_tree_insert()` vs `remove()` before `hlist_del()`. [F216, F300]
- On `CONFIG_GUP_GET_PXX_LOW_HIGH`, `ptep/pmdp_get_lockless()` require interrupts disabled. `ptep_modify_prot_start()` (`modify_prot_start_ptes()`) must be committed with `ptep_modify_prot_commit()` (`modify_prot_commit_ptes()`) before dropping PTL. `__apply_to_page_range()` must use `*_alloc_track()` helpers and call `arch_sync_kernel_mappings()` when `mask & ARCH_PAGE_TABLE_SYNC_MASK` is set. `__might_fault()` must call `might_lock_read(&current->mm->mmap_lock)` when `!pagefault_disabled() && current->mm` without gating on `CONFIG_DEBUG_ATOMIC_SLEEP`. [F328, F329, F337, F345]

## Object Lifetimes

- Consuming `vmf->prealloc_pte` in `pmd_install()` or `deposit_prealloc_pte()` must zero `vmf->prealloc_pte` so `do_fault()` can `pte_free()` any remainder. In `copy_present_page()`, `*prealloc` is cleared to `NULL` only after `copy_mc_user_highpage()` succeeds; `copy_pte_range()` must `folio_put()` and zero unconsumed `prealloc` after each step and at exit. [F199, F200]
- In `wp_page_copy()`, `ptep_clear_flush()` and `set_pte_at()` must complete under `vmf->ptl` before `folio_remove_rmap_pte(old_folio, ...)`, transferring `old_folio`'s reference to `new_folio` to be dropped after `mmu_notifier_invalidate_range_end()`. [F204]
- `handle_mm_fault()` must not dereference `vma` after `hugetlb_fault()` or `__handle_mm_fault()` (cache `mm` and `is_droppable` beforehand). `fault_dirty_shared_page()` must sample `folio_raw_mapping(folio)` before `folio_unlock(folio)`. [F222, F255]
- `__mmu_notifier_register()` takes `mmgrab(mm)` for non-NULL `subscription`, released via `mmdrop(mm)` only after SRCU quiescence in `mmu_notifier_unregister()` or `mmu_notifier_free_rcu()` (modules using `mmu_notifier_put()` must call `mmu_notifier_synchronize()` in `__exit`). While `mn_itree_is_invalidating()` is true, `itree` insert/remove must defer via `deferred_list`, and `mmu_interval_notifier_remove()` must wait on `subscriptions->wq` before `mmdrop(mm)`. [F208, F210, F349]
- `__kmap_local_pfn_prot()` pushes onto `current->kmap_ctrl` and calls `migrate_disable()`, requiring strict LIFO unmapping via `kunmap_local_indexed()`. [F206]

## API Contracts

- `finish_fault()` requires a locked, referenced folio and consumes the reference iff it returns `0` (on non-zero `VM_FAULT_*`, the caller must unlock and `folio_put()`); for `nr_pages > 1`, it must check `!userfaultfd_armed(vma)` and VMA/PMD bounds, and if `!pte_range_none(vmf->pte, nr_pages)` under PTL, set `needs_fallback = true`, `pte_unmap_unlock()`, and jump to `fallback` (`nr_pages = 1`) instead of returning `VM_FAULT_NOPAGE`. [F201, F288, F361]
- `folio_pte_batch*()` and `swap_pte_batch()` require `max_nr >= 1` bounded to the current VMA and PMD; `folio_pte_batch_flags()` requires `@ptentp` to point to a local `pte_t` copy, clamps `max_nr` up front to `folio_pfn(folio) + folio_nr_pages(folio) - pte_pfn(pte)`, and returns `min(nr, max_nr)`. [F248, F268, F269]
- `pte_move_swp_offset()`, `pte_next_swp_offset()`, and `swap_pte_batch()` require `is_swap_pte(pte) && !non_swap_entry(pte_to_swp_entry(pte))`; `pte_move_swp_offset()` must preserve `pte_swp_soft_dirty`, `pte_swp_exclusive`, and `pte_swp_uffd_wp`. `modify_prot_start_ptes()` and `get_and_clear_full_ptes()` must merge `pte_dirty` and `pte_young` across all PTEs in the batch, and `modify_prot_commit_ptes()` must advance both `old_pte` and `pte` PFNs. [F241, F249, F265]
- `vm_iomap_memory()` must check `start + len >= start`, add `start & ~PAGE_MASK` to `len` before `pages = (len + ~PAGE_MASK) >> PAGE_SHIFT`, and verify `pfn + pages >= pfn`, `vma->vm_pgoff <= pages`, and `vma_pages(vma) <= pages - vma->vm_pgoff`. `__vm_map_pages()` must check `offset >= num` then `count > num - offset`. [F270, F271]
- In `insert_pages()`, `pages_to_write_in_pmd` must be capped at `PTRS_PER_PTE - pte_index(addr)`, `curr_page_idx` must never reset at `more:`, and `remaining_pages_total` must be decremented by `batch_size` or by `pte_idx` on mid-batch error before `*num = remaining_pages_total`. [F272, F299]
- `vm_insert_page(s)()` without `VM_MIXEDMAP` requires `mmap_lock` write-locked and `!VM_PFNMAP`. `vmf_insert_pfn*()` requires `VM_PFNMAP ^ VM_MIXEDMAP`, forbids COW on `VM_PFNMAP`, and forbids `pfn_valid(pfn)` on `VM_MIXEDMAP`. `validate_page_before_insert()` rejects unreferenced, anonymous, or typed pages (`-EINVAL`). [F356, F357, F358]
- `__mmu_notifier_register()` accepts `subscription == NULL` (for `itree` init) and rejects setting both `arch_invalidate_secondary_tlbs` and `invalidate_range_start/end` (`-EINVAL`). `handle_mm_fault()` enters memcg user fault OOM only for `FAULT_FLAG_USER` and must call `mem_cgroup_oom_synchronize(false)` if `task_in_memcg_oom(current)` without `VM_FAULT_OOM`. [F236, F351, F363]
- `clear/copy_user_gigantic_page()` and `process_huge_page()` must align `addr_hint` down to the huge folio size. `arch_enter/leave_lazy_mmu_mode()` must not nest, run in IRQ context, or wrap `set_ptes()`. `kmap_high()` sleeps and is forbidden in atomic context. `init/add_mm_rss_vec()` require `int[NR_MM_COUNTERS]`; `unmap_poisoned_folio()` must be used for poisoned folios; `pagecache_get_page()` must return `folio_file_page(folio, index)`. [F229, F315, F326, F331, F359, F360]

## Error Handling

- On `remap_pfn_range_internal()` failure, `remap_pfn_range_notrack()` must call `zap_page_range_single()`, and `remap_pfn_range()` must release `ctx` via `kref_put(&ctx->kref, pfnmap_track_ctx_release)`. Failed `vfs_mmap()` in `mmap_file()` and `vma_close()` must set `vma->vm_ops = &vma_dummy_vm_ops`. [F198, F243]
- When non-blocking `__mmu_notifier_invalidate_range_start()` returns `-EAGAIN`, callers must not call `end()`, so `mn_itree_invalidate()` calls `mn_itree_inv_end()` and `mn_hlist_invalidate_range_start()` calls `ops->invalidate_range_end`. Callers of `find_get_mmu_notifier()` / `mmu_notifier_get_locked()` must check `IS_ERR()`. [F209, F235]
- `do_anonymous_page()` must check `IS_ERR(folio)` (`-EAGAIN` -> return `0`) before `!folio` (`VM_FAULT_OOM`) after `alloc_anon_folio()`. In `do_swap_page()`, if `ksm_might_need_to_copy()` returns `NULL` or `ERR_PTR(-EHWPOISON)`, `folio = swapcache` must be restored before `goto out_page`. [F231, F232]
- In `copy_pte_range()`, `copy_nonpresent_pte()` returning `-ENOENT` must fall through to `copy_present_ptes()` (which returns copied count `>= 1` or `-EAGAIN`/`-EHWPOISON`). `vma_address()` returns `(unsigned long)-EFAULT` on non-overlap. `copy_from/to_user_nofault()` return `0` or `-EFAULT`, whereas `copy_folio_from_user()` returns positive uncopied bytes. [F233, F242, F244]

## External Contracts

- `copy_remote_vm_str()` and `__copy_remote_vm_str()` return `-EFAULT` on any error and must write `*(char *)buf = '\0'` whenever `len > 0` across all failure paths. `strncpy_from_kernel/user_nofault()` always NUL-terminate `dst` when `count > 0` and return length including NUL. `copy_to_kernel_nofault()` must not be exported to modules. [F238, F322, F350]

## Known Pitfalls

- `copy_pte_range()`, `zap_pte_range()`, `insert_pages()`, `remap_pte_range()`, and `apply_to_pte_range()` must pass the initial mapped `pte_t *` to `pte_unmap_unlock()`, not the incremented cursor; `apply_to_pte_range()` must increment `pte` in `while (pte++, addr += PAGE_SIZE, addr != end)`; `zap_pmd_range()` must do `if (addr != next) pmd--` when `zap_pte_range()` returns early; `__pte_map()` under `CONFIG_HIGHPTE` must cast `kmap_local_page()` to `pte_t *` before adding `pte_index(address)`. [F289, F296, F317, F318]
- `vma_soft_dirty_enabled()` must check `IS_ENABLED(CONFIG_MEM_SOFT_DIRTY)` before `!(vma->vm_flags & VM_SOFTDIRTY)`. On `CONFIG_SMP`, `global_zone_page_state()`, `global_node_page_state_pages()`, and `zone_page_state*()` must clamp negative signed `long` reads to `0`. `init_mm` must initialize `.cpu_bitmap = CPU_BITS_NONE`. [F293, F312, F313]
