# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ice (part 1)

Core headers, devlink management (devices, PF/VF/SF ports, regions, rate trees, and health reporters), base VSI/queue/IRQ configuration, shared `ice_adapter` tracking, and Accelerated RFS (aRFS) flow steering.

## Architecture & Data Flow

- When configuring or stopping an ADQ channel Tx ring (`ring->ch != NULL`) in `ice_base.c`, hardware VSI/queue indices must come from `ring->ch` (`vsi_num`, `ch_vsi->idx`, `base_q`, `tc = 0`) rather than the parent `vsi`. [F1102]
- In `ice_traverse_tx_tree`, VF/SF leaf scheduler nodes (`devl_rate_leaf_create`) must not set `node->rate_node`; on eswitch detach (`devl_rate_nodes_destroy`), `ice_devlink_rate_clear_tx_topology` must clear `node->rate_node` across the tree. [F1010]
- `vsi->arfs_fltr_cntrs` must be incremented via `ice_arfs_update_active_fltr_cntrs` only when `ice_fdir_write_fltr` succeeds in `ice_arfs_add_flow_rules`, and decremented when `ice_fdir_write_fltr` succeeds in `ice_arfs_del_flow_rules` or when `ice_rx_flow_steer` resets an `ICE_ARFS_ACTIVE` entry to `ICE_ARFS_INACTIVE`; all non-static functions in `ice_arfs.h` under `#ifdef CONFIG_RFS_ACCEL` require matching `static inline` `#else` stubs. [F1015, F1077]
- `ice_devlink_enable_roce_set()` and `ice_devlink_enable_iw_set()` must clear `IIDC_RDMA_PROTOCOL_ROCEV2` or `IIDC_RDMA_PROTOCOL_IWARP` in `pf->cdev_info->rdma_protocol` if `ice_plug_aux_dev(pf)` fails (and validate callbacks must reject enabling one while the other is set); `ice_clear_rdma_cap()` must clear `ICE_FLAG_PLUG_AUX_DEV` in `pf->flags` before setting `ICE_FLAG_UNPLUG_AUX_DEV`. [F1030, F1074]
- In `enum ice_pf_state`, non-nominal PF state bits must precede `ICE_STATE_NOMINAL_CHECK_BITS`, and `ICE_STATE_NBITS` must remain last; in `ice_devlink_port_split()`, the option loop must iterate `i` from `1` to `option_count` inclusive using `j = (active_idx + i) % option_count` so alternate options match before `active_idx`. [F1080, F1098]
- In `ice_adapter_index()`, non-E825C devices must mask `ICE_ADAPTER_FIXED_INDEX` (`BIT_ULL(63)`) from `pci_get_dsn(pdev)` to avoid colliding with `ICE_ADAPTER_INDEX_E825C`, and 32-bit builds must verify `adapter->index == ice_adapter_index(pdev)` after `xa_load()` to catch XOR folding collisions. [F1089]
- `ice_health_status_lookup` must remain sorted ascending by `enum ice_aqc_health_status` `.code`, and `ice_process_health_status_event()` must verify `count <= event->buf_len / sizeof(*health_info)` before indexing `event->msg_buf` and never `continue` before `health_info++` at loop end. [F1097, F1169]

## Synchronization

- `ice_adapter_get()` and `ice_adapter_put()` must run in sleepable process context and serialize `ice_adapters` xarray access and `adapter->refcount` updates under `ice_adapters_mutex`, calling `ice_adapter_free()` after unlocking when `refcount_dec_and_test(&adapter->refcount)` succeeds. [F1025, F1156]
- Functions acquiring the NVM lock via `ice_acquire_nvm` (`ice_devlink_nvm_snapshot`, `ice_devlink_nvm_read`, `ice_get_tx_topo_user_sel`, `ice_update_tx_topo_user_sel`, `ice_devlink_aq_set_port_option`) must call `ice_release_nvm(&pf->hw)` on every exit path. [F1007]
- PF devlink setup/teardown and SF allocation helpers (`ice_devlink_register()`, `ice_devlink_init_regions()`, `ice_health_init()`, `ice_allocate_sf()`, etc.) require `devl_lock(priv_to_devlink(pf))`; `ice_tear_down_devlink_rate_tree()` must acquire `devl_lock` before `pf->vfs.table_lock`, and devlink rate handlers traversing/mutating the Tx scheduler tree must hold `pi->sched_lock` inside `devl_lock`. [F1027, F1028, F1153]
- `ice_rx_xsk_pool()` and `ice_tx_xsk_pool()` must set `ring->xsk_pool` with `WRITE_ONCE()`, `ice_qp_ena()` must call `synchronize_net()` after enabling NAPI/IRQs and before `netif_tx_start_queue()`, `ice_is_xdp_ena_vsi()` must read `vsi->xdp_prog` with `READ_ONCE()`, and `ice_cfg_xps_tx_ring()` must `test_and_set_bit(ICE_TX_XPS_INIT_DONE, ring->xps_state)` before `netif_set_xps_queue()`. [F1034, F1039, F1041]
- `ice_qp_dis()` must call `synchronize_net()`, `netif_carrier_off()`, `netif_tx_stop_queue()`, `ice_qvec_dis_irq()`, and `ice_qvec_toggle_napi(vsi, q_vector, false)` before stopping rings and calling `ice_qp_clean_rings()`; both `ice_qp_dis()` and `ice_qp_ena()` must execute all steps even after a failure, preserving the first error via `if (!fail) fail = err`. [F1035, F1053]
- `ice_vsi_stop_tx_ring()` must clear `QINT_TQCTL_CAUSE_ENA_M` in `QINT_TQCTL(ring->reg_idx)`, wait `ndelay(100)`, and trigger a SW IRQ on `ring->q_vector` via `ice_trigger_sw_intr()` (if VF not disabled) before `ice_dis_vsi_txq()`, and treat `-EBUSY` and `-ENOENT` from `ice_dis_vsi_txq()` as `0`. [F1036, F1052]
- All `vsi->arfs_fltr_list` and filter state accesses must serialize on `vsi->arfs_lock` via `spin_lock_bh()`/`spin_unlock_bh()`, and `ice_is_arfs_using_perfect_flow()` must call `smp_mb__before_atomic()` before `atomic_read()` on `vsi->arfs_fltr_cntrs->active_{udpv4,udpv6,tcpv4,tcpv6}_cnt`. [F1040, F1146]
- `__ice_vsi_get_qs()` callers must run in sleepable process context without holding `qs_cfg->qs_mutex` (`pf->avail_q_mutex`), and if `__ice_vsi_get_qs_sc()` fails to find `qs_cfg->q_count` free bits, it must clear all `i` bits already set in `qs_cfg->pf_map` and zero their `qs_cfg->vsi_map` entries before unlocking `qs_cfg->qs_mutex`. [F1017, F1158]

## Object Lifetimes

- Every `struct ice_adapter` from `ice_adapter_get()` must be released with `ice_adapter_put()` after emptying `adapter->ports.ports`; `ice_adapter_get()` returns an `ERR_PTR` (converting `NULL` from `ice_adapter_new()` to `ERR_PTR(-ENOMEM)` after `xa_release()`), so callers must check `IS_ERR()`. [F1002, F1046]
- `ice_allocate_pf()` registers `ice_devlink_free` via `devm_add_action_or_reset` to free the PF `struct devlink` automatically, whereas `ice_allocate_sf()` returns an unmanaged `struct ice_sf_priv` requiring explicit `devlink_free()`; `ice_devlink_rate_node_new()` must allocate `struct ice_sched_node` via `devm_kzalloc(ice_hw_to_dev(pi->hw), ...)` to match `devm_kfree(ice_hw_to_dev(hw), node)` in `ice_free_sched_node()`. [F1003, F1009]
- In `ice_devlink_nvm_snapshot()` and `ice_devlink_devcaps_snapshot()`, `*data` must be allocated with `vzalloc()` (and freed with `vfree()` on error) because `ice_nvm_region_ops`, `ice_sram_region_ops`, and `ice_devcaps_region_ops` set `.destructor = vfree`. [F1006]
- `ice_devlink_register_params()` and `ice_devlink_unregister_params()` must gate `ice_dvl_sched_params` on `pf->hw.func_caps.common_cap.tx_sched_topo_comp_mode_en` and unwind `ice_dvl_msix_params`/`ice_dvl_rdma_params` in LIFO order on failure; `ice_devlink_reinit_up()` initializes `ice_init_hw`, `ice_init_dev`, `ice_vsi_cfg` (under `rtnl_lock`), and `ice_load`, unwinding in exact reverse order on error. [F1008, F1011]
- `ice_alloc_dynamic_port()` acquires `ice_reserve_sf_num` (`pf->sf_nums`), `kzalloc(sizeof(*dyn_port))`, `ice_vsi_alloc`, `xa_insert(&pf->dyn_ports, ...)`, and `ice_eswitch_attach_sf` and must unwind them in LIFO order on failure, while `ice_dealloc_dynamic_port()` must call `ice_deactivate_dynamic_port()` before releasing them. [F1013]
- `ice_arfs_add_flow_rules()` must only unlink and `devm_kfree` the temporary `struct ice_arfs_entry_ptr` (`ep`) without freeing `ep->arfs_entry`, whereas `ice_arfs_del_flow_rules()` unlinks and `devm_kfree`s `struct ice_arfs_entry` (`e`) after `ice_arfs_update_flow_rules()` removes it from `vsi->arfs_fltr_list`; `ice_init_arfs()` must publish `vsi->arfs_fltr_list` only after `ice_init_arfs_cntrs()` and `spin_lock_init(&vsi->arfs_lock)` succeed, and `ice_clear_arfs()` must NULL `arfs_fltr_list`, `arfs_last_fltr_id`, and `arfs_fltr_cntrs` after freeing. [F1014, F1016]
- `ice_vsi_alloc_q_vector()` must initialize `q_vector->irq.index = -ENOENT` so `ice_free_q_vector()` skips `ice_free_irq()` when `< 0`; VF control VSIs (`vsi->type == ICE_VSI_CTRL && vsi->vf`) share one MSI-X IRQ when `ice_get_vf_ctrl_vsi(pf, vsi)` is non-NULL (reusing `ctrl_vsi->q_vectors[0]->irq` on alloc and skipping `ice_free_irq()` on free); and both functions must guard `netif_napi_add_config()`/`netif_napi_del()` with `if (vsi->netdev)`. [F1018, F1051, F1174]
- `ice_mdd_reporter_dump()` and `ice_tx_hang_reporter_dump()` must not retain `priv_ctx` after returning because `ice_report_mdd_event()` and `ice_report_tx_hang()` pass stack-allocated event structs to `ice_devlink_health_report()`. [F1117]

## API Contracts

- `devlink_priv()` is `struct ice_pf *` for PF devlink instances (`ice_devlink_ops`) and `struct ice_sf_priv` for SF instances (`ice_sf_devlink_ops`); `ice_devlink_port_to_dyn(port)` is valid only on `ice_devlink_port_sf_ops` (`DEVLINK_PORT_FLAVOUR_PCI_SF`) ports; and `ice_netdev_to_pf()` must not be called on port representor netdevs (`np->repr` non-NULL, `np->vsi` `NULL`—check `ice_is_port_repr_netdev()` or use `ice_get_netdev_priv_vsi()`). [F1115, F1116, F1119]
- In `ice_vsi_alloc_q_vectors()`, failure at `v_idx > 0` shrinks `vsi->num_q_vectors` to `v_idx` and returns `0` (failing only when `v_idx == 0` or `vsi->q_vectors[0]` is non-NULL); `ice_get_ctrl_vsi()` returns `NULL` when `pf->vsi` is unallocated or `pf->ctrl_vsi_idx == ICE_NO_VSI` (`0xffff`); and `ice_vsi_wait_one_rx_ring()` / `ice_vsi_ctrl_one_rx_ring(..., true)` require sleepable context (`usleep_range(20, 40)` in `ice_pf_rxq_wait()`). [F1050, F1056, F1157]
- In `ice_devlink_info_get()`, `ice_devlink_versions` getters receive a zeroed `ctx->buf` and must leave `ctx->buf[0] == '\0'` when a version is absent; CGU helpers (`ice_info_cgu_fw_build()`, `ice_info_cgu_id()`, `ice_aq_get_cgu_info()`) require `ice_is_feature_supported(pf, ICE_F_CGU)`; `ice_sram_region_ops` byte size is `hw->flash.sr_words * 2u`, and `ice_devlink_nvm_read()` must reject `offset + size >= nvm_size` with `-ERANGE`. [F1057, F1087, F1138]
- `ice_set_txq_ctx_vmvf()` only writes `*vmvf_num` when `vsi->type == ICE_VSI_VF` (`hw->func_caps.vf_base_id + vsi->vf->vf_id`), relying on zero-initialized `tlan_ctx`/`txtime_ctx` in `ice_vsi_cfg_txq()` and `ice_cfg_tstamp()`; `ice_set_object_tx_share()` and `ice_set_object_tx_max()` must convert devlink `bw` (bytes/sec) to Kbps via `div_u64(bw, 125)` before `ice_sched_set_node_bw_lmt()`. [F1058, F1059]
- In `ice_setup_rx_ctx()`, `rlan_ctx` must be zero-initialized, `base` and `dbuf` set in 128B units (`ring->dma >> ICE_RLAN_BASE_S`, `DIV_ROUND_UP(ring->rx_buf_len, BIT_ULL(ICE_RLAN_CTX_DBUF_S))`), and `rxmax` capped at `ICE_MAX_CHAINED_RX_BUFS * ring->rx_buf_len`; for non-VF VSIs, enable `ice_set_ring_build_skb_ena(ring)` iff `vsi->netdev` is non-NULL and `ICE_FLAG_LEGACY_RX` is clear before setting `ring->rx_offset = ice_rx_offset(ring)`. [F1060, F1177]
- `ice_rx_flow_steer()` must reject encapsulated, non-IPv4/IPv6, fragmented IPv4, or non-TCP/UDP packets with `-EPROTONOSUPPORT`, reject flows without an active 4-tuple Flow Director profile with `-EOPNOTSUPP`, and return `fltr_info->fltr_id` (`0..RPS_NO_FILTER-1`) on success; `ice_arfs_cmp()` requires prior validation that `n_proto` is IPv4/IPv6 and `ip_proto` is TCP/UDP. [F1090, F1170]
- `ice_health_init()` and `ice_health_deinit()` must gate `pf->health_reporters.fw`/`port` and `ice_config_health_events()` on `ice_is_fw_health_report_supported(&pf->hw)`, and atomic contexts (`.ndo_tx_timeout`) must use `ice_prep_tx_hang_report()` rather than sleepable `ice_report_tx_hang()`; `ice_devlink_create_pf_port()` must call `ice_devlink_set_port_split_options()` only for `pf->hw.pf_id == 0`, and `ice_devlink_reload_up()` must set `BIT(DEVLINK_RELOAD_ACTION_*)` in `*actions_performed`. [F1141, F1142, F1148, F1162]

## Error Handling

- `ice_devlink_init_regions()` must reset `pf->nvm_region`, `pf->sram_region`, or `pf->devcaps_region` to `NULL` on `IS_ERR` from `devl_region_create()`, and `ice_init_devlink_rep()` must convert `IS_ERR` from `devl_health_reporter_create()` to `NULL`, because teardown/reporting helpers only test for non-NULL. [F1004, F1005]
- In `ice_vsi_cfg_txq()`, if `ice_is_txtime_ena(ring)` is true and `ice_alloc_setup_tstamp_ring()` or `ice_cfg_tstamp()` fails after `ice_ena_vsi_txq()` succeeds, the error path must call `ice_free_tx_tstamp_ring()` (if allocated) and `ice_dis_vsi_txq()`. [F1020]

## External Contracts

- In Disable Tx LAN Queues (`0x0C31`, `struct ice_aqc_dis_txq_item`), an even `item->num_qs` requires 2 bytes of padding after `q_id[]` to 4-byte align the next `parent_teid`; Add Tx LAN Queues (`struct ice_aqc_add_txqs_perq`) must use the 22-byte `ice_txq_ctx_buf_t` (`ICE_TXQ_CTX_SZ`), not the 40-byte `ice_txq_ctx_buf_full_t`. [F1061, F1086]
- `ice_vsi_ctrl_one_rx_ring()` (`wait == true`) must call `ice_flush(hw)` after writing `QRX_CTRL(pf_q)` before `ice_pf_rxq_wait()`; `ice_cfg_txq_interrupt()` and `ice_cfg_rxq_interrupt()` must call `ice_flush(hw)` after writing `QINT_TQCTL`/`QINT_RQCTL`, and when `ice_is_xdp_ena_vsi(vsi)` is true, `ice_cfg_txq_interrupt()` must also write `val` to `QINT_TQCTL(vsi->txq_map[txq + vsi->num_xdp_txq])`. [F1123, F1127]
- `ice_irq_dynamic_ena()` must return without writing `GLINT_DYN_CTL(vector)` if `vsi` is non-NULL and `test_bit(ICE_VSI_DOWN, vsi->state)` is true, and must set both `GLINT_DYN_CTL_INTENA_M` and `GLINT_DYN_CTL_CLEARPBA_M` when enabling; `ice_devlink_port_fn_hw_addr_set()` must reject SF MAC changes with `-EBUSY` when `dyn_port->attached` is true and `-EADDRNOTAVAIL` when `hw_addr_len != ETH_ALEN || !is_valid_ether_addr(hw_addr)`. [F1129, F1168]

## Known Pitfalls

- In `ice_pf_rxq_wait()` and `ice_vsi_ctrl_one_rx_ring()`, comparing `bool ena` against `QRX_CTRL_QENA_STAT_M` in `QRX_CTRL(pf_q)` requires `ena == !!(reg & QRX_CTRL_QENA_STAT_M)` because `QRX_CTRL_QENA_STAT_M` is not bit 0; in `ice_vsi_map_rings_to_vectors()`, `q_vector->tx.tx_ring` and `q_vector->rx.rx_ring` must be reset to `NULL` on each vector iteration before prepending rings and decrementing `tx_rings_rem`/`rx_rings_rem`. [F1101, F1103]
- `ice_arfs_is_flow_expired()` must test UDP aRFS expiration using `time_in_range64(arfs_entry->time_activated + ICE_ARFS_TIME_DELTA_EXPIRATION, arfs_entry->time_activated, get_jiffies_64())`; in `ice_xsk_pool_fill_cb()`, `desc.src` must be the address of a local pointer variable holding `&ring->pkt_ctx` (`desc.bytes = sizeof(void *)`), not `&ring->pkt_ctx` directly. [F1111, F1121]
