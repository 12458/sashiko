# LIBRARY CODE — lib (part 1)

Core utilities, data structures, allocators, parsers, and coders/decompressors in `lib/` (`argv_split.c`..`hweight.c`): `assoc_array.c`, `genalloc.c`, `btree.c`, `bch.c`, ASN.1 BER/DER, decompressors, `devres.c`, `cpu_rmap.c`, and `dynamic_queue_limits.c`.

## Architecture & Data Flow

- In `assoc_array_delete()`, keep `edit->ops_for_excised_subtree = NULL` when collapsing a subtree (surviving leaves copy to `new_n0` without new refs; only `edit->dead_leaf` is freed); when deleting the last leaf (`nr_leaves_on_tree == 1`), clear `array->root` via `edit->set[1]`, set `edit->excised_subtree = array->root`, and set `edit->adjust_count_on = NULL`. [F7, F54]
- In `assoc_array_apply_edit()`, if `edit->array->root` and `edit->adjust_count_on` are set, add `edit->adjust_count_by` to `nr_leaves_on_branch` up `back_pointer` and to `nr_leaves_on_tree`; `assoc_array_rcu_cleanup()` must set `edit->excised_subtree`'s root `back_pointer = NULL` before `assoc_array_destroy_subtree()`. [F52, F53]
- In `assoc_array_gc()`, if `retained && new_n->nr_leaves_on_branch <= ASSOC_ARRAY_FAN_OUT`, `goto retry_compress`, and when folding `new_n->slots[slot]`, set it to `NULL` and `if (slot < next_slot) next_slot = slot;`. In `assoc_array_insert_into_terminal_node()`, `all_leaves_cluster_together` must recompute `edit->segment_cache[0..ASSOC_ARRAY_FAN_OUT]` at `skip_to_level` before `do_split_node`. [F86, F87, F88]
- In `lib/genalloc.c`, `chunk->end_addr` is inclusive (`virt + size - 1`), so `chunk_size()` is `end_addr - start_addr + 1` and range checks (`gen_pool_virt_to_phys()`, `gen_pool_free_owner()`, `gen_pool_has_addr()`) use `<= chunk->end_addr`. `chunk->bits` is `BITS_TO_LONGS(nbits) * sizeof(long)` bytes; chunk capacity rounds down (`size >> order`), whereas alloc/free requests round up (`(size + (1UL << order) - 1) >> order`) and adjust `chunk->avail` by `(nbits << pool->min_alloc_order)`. [F47, F77, F106, F115]
- In `lib/btree.c`, each `NODESIZE` node stores `geo->no_pairs` keys (`0..geo->no_longs - 1`) then values (`node[geo->no_longs + n]`) in descending key order with `NULL` marking unused slots; `merge()` copies `right` into `left`, swaps `parent` child pointers at `lpos` and `lpos + 1`, and calls `btree_remove_level(head, geo, bkey(geo, parent, lpos), level + 1)` before freeing `right`. [F57, F80]
- In `lib/dynamic_queue_limits.c`, compare wrapping `unsigned int` counters (`num_queued`, `num_completed`, `prev_num_queued`, `adj_limit`) via signed differences (`POSDIFF`, `AFTER_EQ`, `dql_avail()`); `dql_queued()` rejects `count > DQL_MAX_OBJECT` and `dql_completed()` clamps `limit` to `dql->max_limit <= DQL_MAX_LIMIT`. [F81, F107]
- In `dql_completed()`, when clamped `limit != dql->limit`, update `dql->limit` and zero `ovlimit` before setting `prev_ovlimit = ovlimit` and `adj_limit = limit + completed`. `dql_reset()` zeroes counters and `history`, sets `limit = min_limit` and `lowest_slack = UINT_MAX`, and sets `slack_start_time`, `last_reap`, and `history_head` to `jiffies` while preserving `min_limit`, `max_limit`, `slack_hold_time`, and `stall_thrs`. [F50, F51]
- `alloc_cpu_rmap()` rejects `size > 0xffff` (and callers must not pass `size == 0`) and aligns `rmap->obj` to `ALIGN(offsetof(struct cpu_rmap, near[nr_cpu_ids]), sizeof(void *))`. In `cpu_rmap_update()`, before setting `dist = 0` for new `affinity`, all online CPUs with `rmap->near[cpu].index == index` must have `dist = CPU_RMAP_DIST_INF` and be added to `update_mask`. [F58, F78]
- In `lib/bch.c`, `mod_s(bch, v)` requires `v < 2 * GF_N(bch)`; use `modulo(bch, v)` when `v >= 2 * GF_N(bch)` (`a_pow()`, `find_poly_deg2_roots()`). Allocate `bch->elp` as `(t + 1) * sizeof(struct gf_poly_deg1)` (not `GF_POLY_SZ(2 * t)`) for in-place splitting in `factor_polynomial()`. [F105, F113]
- `asn1_ber_decoder()` rejects `datalen > 65535` (`-EMSGSIZE`) and definite length `n > 2` (`unsigned short` stacks); when `ASN1_OP_END_*` with `ASN1_OP_END__OF` loops to `machine[pc + 1]`, restore `csp++` and `dp--` (indefinite) or `datalen = len` (definite) after popping `cons_*_stack[--csp]`. [F67, F90]
- `argv_split()` allocates `argc + 2` pointers (`argv_str` at `argv[0]`, returns `++argv`, `NULL` at `argv_ret[argc]`) for `argv_free()`. In `digsig_verify_rsa()` and `pkcs_1_v1_5_decode_emsa()`, right-align MPI result `p` (len `l`) in zeroed `out1` of modulus length `mlen` (`memcpy(out1 + mlen - l, p, l)`), and verify `modulus_len >= 11` and `msg[0] == 0x00 && msg[1] == 0x01`. [F66, F71]
- `compressed_formats[]` (`lib/decompress.c`) ends with a zeroed sentinel for `decompress_method()`. In `get_next_block()` (`lib/decompress_bunzip2.c`), `hufGroup->base` and `limit` use 1-based pointers (`base - 1`, `limit - 1`) and `limit[maxLen + 1] = INT_MAX` uses the extra slot in `int limit[MAX_HUFCODE_BITS + 1]`. [F73, F74]
- Relative fields in `lib/extable.c` (`x->insn`, `x->fixup`) and `lib/bug.c` (`bug_addr_disp`, `file_disp`) are offsets from the field's own address, so `swap_ex()` adjusts `insn` and `fixup` by `b - a`. In `lib/devres.c` and `lib/genalloc.c`, `devres_alloc*()` stores a pointer (`void __iomem *` or `struct gen_pool *`), so release/match callbacks must dereference `*(void **)res`. [F121, F122]

## Synchronization

- `assoc_array_iterate()` and `assoc_array_find()` require `rcu_read_lock()` (or writer lock), walks must load `root`, `slots`, `next_node`, and `back_pointer` with `READ_ONCE()`, and `assoc_array_subtree_iterate()` must visit all leaf slots in a node before descending into metadata slots. [F15, F85]
- `assoc_array_insert()`, `delete()`, `clear()`, and `gc()` require sleepable context (`GFP_KERNEL`) and an exclusive lock held until `assoc_array_apply_edit()` or `cancel_edit()`. `assoc_array_apply_edit()` publishes `*edit->leaf_p`, `set_parent_slot`, `set_backpointers`, and `set` separated by `smp_wmb()` and frees via `call_rcu(&edit->rcu, assoc_array_rcu_cleanup)`, whereas `assoc_array_destroy()` frees immediately without RCU and requires all concurrent/RCU accesses prevented. [F16, F135, F136]
- `gen_pool_add_owner()` (and `gen_pool_add*`) runs in sleepable context (`vzalloc_node()`) and must initialize all `gen_pool_chunk` fields (`phys_addr`, `start_addr`, `end_addr`, `owner`, `avail`) before `spin_lock(&pool->lock)` and `list_add_rcu(&chunk->next_chunk, &pool->chunks)`. [F18, F140]
- Between `dql_queue_stall()` and `dql_check_stall()`, zeroing reused `dql->history` slots precedes `WRITE_ONCE(dql->history_head, now_hi)` via `smp_wmb()`, and `dql_check_stall()` issues `smp_rmb()` after `READ_ONCE(dql->history_head)` and retries if `READ_ONCE(dql->history_head)` changed after scanning `dql->history`. [F20]
- `fprop_new_period()` requires external serialization and wraps `p->events` and `p->period` updates in `preempt_disable_nested()` and `write_seqcount_begin`/`end(&p->sequence)`. `fprop_reflect_period_percpu()` rechecks `pl->period >= period` under `raw_spin_lock_irqsave(&pl->lock, flags)`. [F21, F22]
- `ei_mutex` (`lib/error-inject.c`) protects all `error_injection_list` accesses (`within_error_injection_list`, `get_injectable_error_type`, `populate_error_injection_list`, `module_unload_ei_list`, `ei_seq_start`..`ei_seq_stop`). `digsig_verify_rsa()` holds `down_read(&key->sem)` across `user_key_payload_locked(key)` and all `ukp->data` reads, checking `!ukp` after locking. [F25, F26]
- `dump_stack_lvl()` skips `printk_cpu_sync_get_irqsave()` / `put_irqrestore()` when `panic_on_this_cpu()`. `report_bug()` wraps `__report_bug()` in `warn_rcu_enter()` / `warn_rcu_exit()`, and `module_bug_list` uses RCU (`list_for_each_entry_rcu()`, `list_add_rcu()`, `list_del_rcu()`), not a spinlock. [F28, F144]
- `generic_atomic64_*` (`lib/atomic64.c`) uses `local_irq_save()` and `arch_spin_lock()` on `atomic64_lock` (not `raw_spin_lock_irqsave()`). `_atomic_dec_and_lock*()` (`_irqsave`, `_raw_lock`) locks before decrementing 1 to 0, unlocking (restoring IRQs) if `atomic_dec_and_test()` returns 0. `dhry_benchmark()` wraps `dhry()` in `get_cpu()` / `put_cpu()`, so `dhry()` allocations must use `GFP_ATOMIC`. [F131, F132, F133, F151]

## Object Lifetimes

- In `lib/cpu_rmap.c`, `irq_cpu_rmap_add()` (after IRQ alloc, before `request_irq()`) and `free_irq_cpu_rmap()` (before `free_irq()`) require sleepable context. `irq_cpu_rmap_add()` initializes `glue->notify`, `glue->rmap`, `cpu_rmap_get(rmap)`, and `glue->index = cpu_rmap_add(rmap, glue)` before `irq_set_affinity_notifier()`, and both `irq_cpu_rmap_release()` and `err_set` clear `rmap->obj[glue->index] = NULL` before `cpu_rmap_put(glue->rmap)`. [F1, F23, F123, F124]
- `of_gen_pool_get()` returns a borrowed `struct gen_pool *` and must call `of_node_put(parent)`, `put_device(&pdev->dev)`, and `of_node_put(np_pool)` before returning. All `gen_pool` allocations (including `devm_gen_pool_create()`) must be freed before `gen_pool_destroy()` / `devm_gen_pool_release()` (`BUG_ON(bit < end_bit)`). [F2, F128]
- `btree_destroy()` only frees `head->node` and `head->mempool`; populated trees must be emptied via `btree_grim_visitor()` or `btree_remove()` first. In `btree_merge()`, when `!target->node`, `victim->node` and `height` transfer to `target` and `victim` is reset via `__btree_init(victim)`. [F8, F9]

## API Contracts

- `assoc_array_delete()` and `clear()` return an edit pointer, `NULL` if absent/empty, or `ERR_PTR(-ENOMEM)`. `assoc_array_cancel_edit()` and `assoc_array_insert_set_object()` never free `edit->leaf`. In `assoc_array_gc()`, `iterator` must increment a retained leaf's refcount before returning `true` because both old-tree RCU cleanup and `enomem` rollback call `ops->free_object()` on all leaves in their subtrees. [F5, F6, F35]
- `devm_gen_pool_create()` keys pools by `pool->name` (`NULL` matches only unnamed pools in `devm_gen_pool_match()`) and returns `ERR_PTR(-EINVAL)` if `gen_pool_get(dev, name)` exists or `ERR_PTR(-ENOMEM)`, whereas `gen_pool_create()`, `gen_pool_get()`, and `of_gen_pool_get()` return `NULL`. `gen_pool_virt_to_phys()` returns `(phys_addr_t)-1` on failure, whereas `gen_pool_alloc_algo_owner()` returns `0`. [F31, F34, F49]
- In `lib/genalloc.c`, `min_alloc_order` is log2 bytes per bit (`gen_pool_fixed_alloc()` requires `offset` aligned to `1UL << min_alloc_order`). `genpool_algo_t` and `gen_pool_for_each_chunk()` callbacks run under `rcu_read_lock()` (must not sleep), `genpool_algo_t` returns `>= size` (`end_bit`) on failure (`0` is valid), and `gen_pool_alloc*` / `free*` are NMI-safe only if `CONFIG_ARCH_HAVE_NMI_SAFE_CMPXCHG`. [F32, F139, F141, F155]
- `devm_ioremap_resource*()` and `devm_of_iomap()` return `IOMEM_ERR_PTR()`, whereas `devm_ioremap*()` and `devm_ioport_map()` return `NULL`. `devm_iounmap()` and `devm_ioport_unmap()` require pointers from `devm_ioremap*()` / `devm_ioport_map()`. [F30, F125]
- `bch_init()` requires `m` in `[5, 15]`, `t` in `[1, 64]`, `m * t < (1 << m) - 1`, and under `CONFIG_BCH_CONST_PARAMS` rejects `(m, t) != (CONFIG_BCH_CONST_M, CONFIG_BCH_CONST_T)` with `NULL`. `bch_encode()` loads existing `ecc` when non-NULL (zero `ecc` to start fresh). `bch_decode()` rejects `8 * len > bch->n - bch->ecc_bits` (`-EINVAL`), returns error count `>= 0` or `-EBADMSG`, and places ECC bit errors at `errloc[i] >= 8 * len`. [F39, F40, F83, F161]
- `asn1_encode_integer()` requires `integer >= 0`, and `asn1_encode_tag()` requires `tag <= 30`. In-place recoding (`asn1_encode_tag()` with `string == NULL` or `asn1_encode_sequence()` with `seq == NULL`) requires `len <= 127` and `data` set to the pointer returned by the initial `len = -1` call (`data -= 2`). [F69, F159]
- `hex_to_bin()` returns signed `0..15` or `-1`; `hex2bin()` and `bin2hex()` take `@count` in binary bytes; and neither `bin2hex()` nor `base64_encode()` (`BASE64_CHARS(srclen)` bytes) NUL-terminates `@dst`. `get_options()` writes the count to `ints[0]` (even if `nints == 0`, so `ints` must be non-NULL) and values to `ints[1..nints-1]`; on range `M-N` (`get_option() == 3`), `get_range()` fills `[M, N-1]` and leaves `str` at `N`. [F46, F95, F117, F118, F119]
- `ip_fast_csum()` takes `ihl` in 32-bit words (unlike byte-length `ip_compute_csum()` / `csum_partial()`), and chained `csum_partial()` calls require even `len` on all non-final fragments. `btree_insert()` requires non-NULL `val` and a non-existent key (`BUG_ON`; use `btree_update()`). `dql_completed()` requires `count <= READ_ONCE(dql->num_queued) - dql->num_completed` (`BUG_ON`). `__clzdi2()` and `__ctzdi2()` take `u64` and use `fls64()` / `__ffs64()`. [F84, F97, F152, F153, F158]

## Error Handling

- In `gen_pool_alloc_algo_owner()`, if `bitmap_set_ll()` returns non-zero `remain`, roll back `nbits - remain` bits via `bitmap_clear_ll()` before `goto retry`. In `__devm_ioremap_resource()`, if `__devm_ioremap()` fails after `devm_request_mem_region()`, call `devm_release_mem_region()`. [F4, F11]
- `get_injectable_error_type()` defaults to `-EINVAL`. Every `asn1_encode_*()` checks `if (IS_ERR(data)) return data;` before checking space or writing `data`. `bch_alloc()` sets `*err = 1` on failure without clearing on success, so callers must init `err = 0` and check `err` before dereferencing. `digsig_verify_rsa()` must not pass `ERR_PTR()` from `mpi_read_from_buffer()` to `mpi_free()` (`while (--i >= 0) mpi_free(pkey[i])`). [F29, F37, F41, F43]

## External Contracts

- `asn1_encode_integer()` prepends `0x00` and decrements `data_len` (checking `data_len == 0` after) when a positive integer's MSB has `byte & 0x80`. Under `#ifdef PREBOOT`, `__decompress()` in `decompress_unlz4.c`, `decompress_bunzip2.c`, and `decompress_unlzma.c` passes `in_len - 4` (or `len - 4`) to exclude the 4-byte size trailer. [F70, F75]
- In `glob_match()`, an unclosed `[` reaching `'\0'` jumps to `literal:` with `pat` right after `'['`. In `of_gen_pool_get()`, a child DT node without its own `platform_device` looks up the pool on the parent device by `"label"`, falling back to `of_node_full_name(np_pool)`. [F96, F130]

## Known Pitfalls

- `btree_insert_level()` jumps to `retry` after splitting a full node to recompute `find_level()`, `getpos()`, and `getfill()`; `btree_get_prev()` clears `retry_key = NULL` before jumping from `miss` to `retry`. `asn1_find_indefinite_length()` and `asn1_ber_decoder()` check lengths via subtraction (`len > datalen - dp`, `pc + asn1_op_lengths[op] > machlen`), and `ASN1_OP_MATCH__SKIP` on tag mismatch decrements `dp--`. [F55, F68, F89, F91]
- `find_cpio_data()` checks both bounds and pointer wrap (`nptr > p + len || dptr < p || nptr < dptr`). `parse_header()` and `unlzo()` check `end - parse < l + 4`, `dst_len > LZO_BLOCK_SIZE`, and `src_len <= 0 || src_len > dst_len`. In `lib/decompress_bunzip2.c`, `temp[MAX_HUFCODE_BITS+1]` in `get_next_block()` must be `> 8` bits (`unsigned short`, `MAX_SYMBOLS == 258`), and `get_bits()` flushes `bd->inbufBits` when `bd->inbufBitCount >= 24` before `bd->inbufBits <<= 8`. [F72, F76, F99, F110]
- `hex_to_bin()` casts `((ch - '9' - 1) & ('0' - 1 - ch))` to `(unsigned)` before `>> 8`; `hex2bin()` verifies `hi >= 0` before reading the low nibble; `hex_dump_to_buffer()` uses `get_unaligned()` for 2/4/8-byte groups; and `get_option()` advances `cur` past `'-'` before `simple_strtoull(++cur, str, 0)` so `cur == *str` catches a bare hyphen. [F62, F63, F64, F108]
- `__fprop_add_percpu_max()` widens `numer`/`denom` to `u64` before `* max_frac` or `<< FPROP_FRAC_SHIFT` and uses `div_u64()`; `fprop_new_period()` and `fprop_reflect_period_percpu()` check elapsed periods `< 64` (or `< BITS_PER_LONG`) before right-shifting. In `lib/bch.c`, `1u << (32 - m)` (`compute_syndromes()`) and `g[j] << (d + 1)` (`build_mod8_tables()`) require `m != 0` and `d < 31`. `__cmpdi2()`, `__ashldi3()`, and `__ashrdi3()` cast `DWstruct.low` (and `high` for shift carries) to `unsigned int`. [F100, F101, F102, F104]
- `devmem_is_allowed()` uses `PFN_PHYS(pfn)` (not `pfn << PAGE_SHIFT`). `cmp_ex_sort()` and `cmp_ex_search()` compare `unsigned long` addresses with `>` and `<` (not `int` subtraction). Unlike `of_iomap()`, `devm_of_iomap()` calls `devm_ioremap_resource()` (`devm_request_mem_region()`), returning `ERR_PTR(-EBUSY)` on overlapping mappings. [F98, F109, F127]
