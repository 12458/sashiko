# USB SUBSYSTEM — drivers/usb (part 5)

`drivers/usb/mon/` (`usbmon`) provides binary ring-buffer and debugfs text interfaces for snooping URB traffic; `drivers/usb/misc/` contains 23 USB host, hub (`usb3503`, `usb4604`, `onboard_usb_dev_pdevs`), firmware (`ezusb`, `emi26`, `emi62`, `isight_firmware`), test (`usbtest`, `ehset`, `lvstest`), parallel-port (`uss720`), and char/sysfs drivers (`adutux`, `appledisplay`, `cypress_cy7c63`, `cytherm`, `idmouse`, `iowarrior`, `ldusb`, `trancevibrator`, `usblcd`, `usbsevseg`, `yurex`).

## Architecture & Data Flow
- In `mon_bin.c`, `mon_alloc_buff()` allocates each `CHUNK_SIZE` (`PAGE_SIZE`) page in `rp->b_vec` separately: translate offsets via `rp->b_vec[off / CHUNK_SIZE].ptr + off % CHUNK_SIZE`, chunk copies via `mon_copy_to_buff()`/`copy_from_buf()`, and wrap multi-slot advances (`lendesc`, `rp->b_read - hdrbytes`, `size`) by subtracting `rp->b_size` (not resetting to `0`). [F265, F283]
- In `mon_bin.c`, `mon_buff_area_alloc*()` and `mon_buff_area_free()` must align sizes to `PKT_ALIGN` (64, equal to `PKT_SIZE`) within `CHUNK_SIZE`-aligned `b_size` so `mon_bin_hdr` (64B) and `mon_bin_isodesc` (16B) never straddle boundaries; `ep->len_cap` excludes `PKT_SIZE`, ring payload starts at `rp->b_out + PKT_SIZE` even for 48B `PKT_SZ_API0`, and when `rp->mmap_active` is set, `mon_bin_event()` must use `mon_buff_area_alloc_contiguous()` (writing a `@` filler via `mon_buff_area_fill()`, wrapping `b_in` to `size`, and adding `size + fill_size` to `b_cnt`). [F224, F236, F238]
- In `mon_text_get_data()` and `mon_bin_get_data()`, use `urb->transfer_buffer` when `urb->num_sgs == 0`, else iterate `urb->sg` via `sg_virt(sg)` only when `!PageHighMem(sg_page(sg))` (and `!(urb->transfer_flags & URB_DMA_SG_COMBINED)` in `mon_bin_get_data()`). [F209]
- In `mon_main.c`, `ubus->monitored` must be `1` iff `mbus->nreaders` or `mon_bus0.nreaders` is non-zero across `mon_reader_add()`/`del()`, `mon_stop()`, and `mon_bus_add()`; since `mon_dissolve()` clears `mbus->u_bus = NULL` while readers hold `mbus->ref`, `mon_stop()` and `mon_bin_open()` must check `mbus->u_bus != NULL` (for `mbus != &mon_bus0`). In `mon_text.c`, `rp->e_list` insertions/removals must update `rp->nevents` in lockstep, and text formatters must use `scnprintf()` (never `snprintf()`). [F219, F220, F226, F241]
- In `usbtest.c`, every `id_table` entry must set `.driver_info` (`struct usbtest_info *`), `get_endpoints()` must reset all candidate endpoint pointers to `NULL` each `altsetting` iteration, `simple_io()` must restore `urb->transfer_buffer_length`, and `usbtest_ioctl()` must reset `dev->info->alt` (`>= 0`) via `set_altsetting()`. Also, `setup` must be first in `struct subcase` (`urb->setup_packet = &reqp->setup` for `ctrl_complete()`), `iso_alloc_urb()` must use `DIV_ROUND_UP(bytes, maxp)`, and `alloc_sglist()` (`pattern == 1`) must offset `j` by cumulative `n_size` (`((j + n_size) % maxpacket) % 63`). [F234, F258, F261, F272, F277, F289]
- In `iowarrior.c`, `dev->report_size` defaults to `usb_endpoint_maxp(dev->int_in_endpoint)` and on `bInterfaceNumber == 0` is overridden before buffer allocation to 7 (`IOW56`/`IOW56AM`), 4 (`IOW28`/`IOW28L`), or 12 (`IOW100`); only those 5 models use `int_out_endpoint` URBs in `iowarrior_write()`, while `IOW24*`/`IOWPV*`/`IOW40` use `usb_set_report()` and support `IOW_WRITE`. `read_queue` stride is `report_size + 1`, `iowarrior_read()` requires `count == report_size` or `report_size + 1`, and `iowarrior_write()` requires `0` or `report_size`. [F245, F292, F299]
- In `ldusb.c`, when optional `interrupt_out_endpoint` is absent, `interrupt_out_endpoint_size` falls back to `bMaxPacketSize0` and `ld_usb_write()` uses `usb_control_msg()` (`HID_REQ_SET_REPORT`). `ring_buffer` slot stride is `sizeof(size_t) + interrupt_in_endpoint_size`; `ld_usb_read()` must check `*actual_buffer <= interrupt_in_endpoint_size`, and after advancing `ring_tail` when `buffer_overflow` is set, clear `buffer_overflow = 0` and resubmit `interrupt_in_urb` (setting `buffer_overflow = 1` on error). [F229, F247, F300]
- In `usb3503.c`, never downcast `hub->dev` (`i2c_client` or `platform_device`), and guard `if (hub->regmap)` in `usb3503_connect()`. `usb3503_probe()` must parse `"refclk-frequency"` to set `secondary_ref_clk` before requesting `"intn"` GPIO; entering `USB3503_MODE_HUB` must deassert `reset`/`bypass`, sleep 4–10ms, bracket `USB3503_PDS`/`CFG1` writes with `USB3503_SP_ILOCK` set/clear, and assert `connect`; and `usb3503_switch_mode()`/`usb4604_switch_mode()` must not overwrite `hub->mode` on `*_MODE_STANDBY`. [F207, F231, F288, F306, F307]
- In `uss720.c`, `usb_set_intfdata()` stores `struct parport *pp` (`priv` is `pp->private_data`); IEEE 1284 registers `0..8` map to `priv->reg[0..6]` via `regindex[9]` (guard `reg < 9` in `get_1284_register()`); `change_mode()` must step through `ECR_PS2` between modes `> ECR_PS2`, and when leaving `ECR_PPF`/`ECP` to `<= ECR_PS2` with `!(priv->reg[1] & 0x20)`, poll reg 6 until `priv->reg[2] & 0x01` or timeout (`-EBUSY`). [F249, F287, F309]
- Hub ports are 1-based (`1..bNbrPorts` in `lvstest.c`, `1..maxchild` in `onboard_usb_dev_pdevs.c`). `lvs_rh_probe()` requires `bDeviceProtocol == USB_HUB_PR_SS && !hdev->parent` and `ret >= USB_DT_HUB_NONVAR_SIZE + 2`. `onboard_dev_create_pdevs()` must return early if `!parent_hub->parent && !usb_hcd_is_primary_hcd(hcd)` and skip any `peer-hub` child if `!usb_hcd_is_primary_hcd(hcd)` or `of_find_device_by_node(npc)` finds a peer. In `ehset.c`, reject `TEST_SINGLE_STEP_SET_FEATURE` unless `hub_udev == dev->bus->root_hub`, and in `ehset_prepare_port_for_testing()` clear `USB_PORT_FEAT_ENABLE` + sleep 100ms for `ehset_hub_list` hubs or set `USB_PORT_FEAT_SUSPEND` otherwise. [F235, F251, F302, F303]
- In `idmouse.c`, `bulk_in_buffer` is `IMGSIZE + bulk_in_size` bytes, `idmouse_read()` exposes at most `IMGSIZE` bytes, and `idmouse_create_image()` runs in `idmouse_open()` bracketed by `usb_autopm_get_interface()`/`put_interface()`. In `usbsevseg.c`, `text_store()`/`decimals_store()` must use `my_memlen(buf, count)`, reject `end > MAXLEN` (8), and reverse indices (`len - 1 - i`). In `.probe` callbacks (`adutux`, `idmouse`, `iowarrior`, `ldusb`, `lvstest`, `usblcd`, `yurex`, `appledisplay`), use `interface->cur_altsetting` (never `altsetting[0]`) and set up all state and `usb_set_intfdata()` before `usb_register_dev()`. [F248, F254, F291, F293, F313]

## Synchronization
- In `mon_main.c`, `mon_bus_lookup()` and `mon_buses` require `mon_lock`; `mon_reader_add()`/`del()` require `mon_lock`, hold `spin_lock_irqsave(&mbus->lock, flags)` to modify `nreaders`/`r_list`, and update `mbus->ref` under `mon_lock` outside `mbus->lock`. `mon_reader` callbacks (`rnf_*`) run under `mbus->lock` (no sleeping, use `GFP_ATOMIC`, do not lock `mbus->lock`); `mon_text_fetch()` must hold `mbus->lock` for `rp->e_list`/`nevents`, and `mon_text_release()` must call `mon_reader_del()` before draining `e_list` unlocked. [F185, F186, F316, F317]
- In `mon_bin.c`, `mon_bin_vma_fault()` must hold `rp->b_lock` across checking `b_size`, indexing `b_vec`, and `get_page()`. `MON_IOCT_RING_SIZE` must return `-EBUSY` if `rp->mmap_active`, else replace `b_vec`/`b_size` and zero `b_read`, `b_in`, `b_out`, `b_cnt`, and `cnt_lost` under `rp->fetch_lock` and `rp->b_lock`. `mon_buff_area_free()` also requires both `fetch_lock` and `b_lock`, resetting `rp->b_read = 0` under `fetch_lock`. [F189, F221, F223]
- Char `.release` callbacks (`ld_usb_release`, `adu_release`, `iowarrior_release`, `idmouse_release`) must use uninterruptible `mutex_lock()`. In `adutux.c`, lock order is `adutux_mutex` -> `dev->mtx` -> `dev->buflock`; in `adu_read()`, swapping `read_buffer_primary`/`secondary` and resetting `secondary_head`/`tail`/`read_buffer_length` requires `dev->buflock`; in `adu_write()`, signal/timeout paths while `dev->mtx` is unlocked on `write_wait` must jump to `exit_onqueue` (not `exit`). [F169, F172, F190, F227]
- In `iowarrior_read()`, lock `dev->mutex` (`mutex_trylock()` if `O_NONBLOCK`, else `mutex_lock_interruptible()`) before accessing `present`, `report_size`, or `read_queue`, and clear/retry on `dev->overflow_flag`. In `ld_usb_read()`, hold `dev->rbsl` while checking `ring_head == ring_tail` in a `while` loop around `wait_event_interruptible()`, and re-lock `dev->rbsl` after `copy_to_user()` to advance `ring_tail` and clear `buffer_overflow`. [F191, F193, F228]
- In `yurex.c`, `yurex_write()` must use `mutex_lock_interruptible(&dev->io_mutex)`, call `usb_kill_urb(dev->cntl_urb)` after `finish_wait()` before unlocking `io_mutex`, and unlock `io_mutex` on all return paths in `yurex_read()`/`write()`. In `usblcd.c`, `lcd_write()` acquires `limit_sem` before `down_read(&dev->io_rwsem)` and anchors URBs to `dev->submitted`, while `lcd_disconnect()` sets `disconnected = 1` under `down_write(&dev->io_rwsem)` before `usb_kill_anchored_urbs()`. In `usbtest.c:ctrl_complete()`, `spin_unlock(&ctx->lock)` (keeping IRQs disabled) around `usb_unlink_urb(u)`. [F166, F196, F326, F327, F330]

## Object Lifetimes
- In USB char drivers (`adutux`, `idmouse`, `iowarrior`, `ldusb`, `usblcd`, `yurex`), per-device state and buffers can outlive `.disconnect` while a file is open, so they must never use `devm_*` allocations and must be freed only when both disconnected and closed. [F297]
- In `yurex` and `iowarrior`: `yurex_probe()` pins `usb_get_dev()` and `usb_get_intf()`, `yurex_disconnect()` poisons `urb`/`cntl_urb` and sets `disconnected = 1` (keeping `dev->interface`), and `yurex_delete()` kills URBs and frees coherent buffers before `usb_put_intf()`/`put_dev()`. `iowarrior_probe()` pins `usb_get_intf()` (put in `iowarrior_delete()`); `iowarrior_disconnect()` holds `dev->mutex` to clear `present`, check `opened`, and kill `int_in_urb`/`submitted` or call `iowarrior_delete()`; in `iowarrior_write()`, after `atomic_inc(&dev->write_busy)`, anchor to `submitted` before `usb_submit_urb()` (or on error unanchor/free URB and `buf`, `atomic_dec(&dev->write_busy)`, and wake `write_wait`). [F164, F165, F170, F175, F192]
- In `adutux`, `ldusb`, and `usblcd`: `adu_probe()` pins `usb_get_dev()` (put in `adu_delete()`); `ld_usb_disconnect()` poisons `interrupt_in_urb`/`out_urb`, sets `disconnected = 1` under `dev->mutex`, and keeps `dev->intf` until `ld_usb_delete()`; `lcd_open()`/`release()` balance `usb_autopm_get_interface()`/`put_interface()` (putting `dev->kref` on `autopm_get` error), `lcd_suspend()` calls `lcd_draw_down()`, and `lcd_write()` transfers `buf` and `limit_sem` to `lcd_write_bulk_callback()` on `usb_submit_urb()` success (or unanchors/frees `urb`/`buf` and calls `up(&dev->limit_sem)` on error). [F171, F174, F194, F312]
- In `uss720.c`, `priv->usbdev` is owned by `priv` after `kref_init(&priv->ref_count)` and put in `destroy_priv()`. `submit_async_request()` initializes `rq->ref_count`/`compl`, gets `priv->ref_count`, links `rq->asynclist` under `priv->asynclock`, and calls `kref_get(&rq->ref_count)` before `usb_submit_urb()` (caller drops its ref via `kref_put(&rq->ref_count, destroy_async)`). `uss720_disconnect()` sets `priv->pp = NULL` (keeping `priv->usbdev`), removes/puts `parport`, calls `kill_all_async_requests_priv(priv)`, and puts `priv->ref_count`. [F167, F168, F199, F298]
- In `onboard_dev_create_pdevs()`, each iteration must put `np`/`npc` (`of_node_put`), peer `pdev` (`put_device`), and destroy `pdev` (`of_platform_device_destroy`) if `kzalloc(pdle)` fails. Call `usb_poison_urb(lvs->urb)` before `flush_work(&lvs->rh_work)` in `lvs_rh_disconnect()`, and in `appledisplay.c` check `if (pdata->bd)` before scheduling `pdata->work` and call `usb_kill_urb(pdata->urb)` before `cancel_delayed_work_sync(&pdata->work)`. [F176, F178, F294]
- Balance `clk_prepare_enable(hub->clk)` with `clk_disable_unprepare()` on error/remove/suspend in `usb3503.c`. In `usbsevseg.c`, `update_display_*()` must return early if `shadow_power != 1`, gate autopm on `has_interface_pm`, and use `GFP_NOIO` in `sevseg_resume()`/`reset_resume()`. In `usbtest.c`, set `urbs[i] = NULL` after `simple_free_urb(urbs[i])` on `test_queue()` submit error, and `kfree(buf - offset)` after `buf += offset` in `ctrl_out()`. [F184, F280, F310, F311]

## API Contracts
- In `mon_bin.c`, `mon_buff_area_alloc*()` return `unsigned int` offset (`0` is valid, `~0` on failure), and `mon_bin_get_data()` returns the `unsigned int` uncopied residual (subtracted from `ep->len_cap` and passed aligned to `mon_buff_area_shrink()`). Across `drivers/usb/misc/`, `usb_control_msg()` requires a DMA-capable heap buffer (unless `usb_control_msg_send()`/`recv()` is used), millisecond timeouts (never `* HZ`), and matching `bRequestType` (`USB_DIR_OUT`/`IN`) and pipe directions. [F202, F203, F215, F216, F290]
- Free `create_lvs_device()` devices via `destroy_lvs_device(udev)`. In `uss720.c`, atomic `parport_operations` (`frob_control`, `restore_state`) must pass `GFP_ATOMIC` and `val = NULL` to `get_1284_register()`/`set_1284_register()`. In `usbtest.c`, `subcase->expected` is `< 0` for mandatory faults and `> 0` for optional faults. `emi26_probe()`/`emi62_probe()` must return `-EIO` after firmware load. `iowarrior_open()`, `adu_open()`, `ld_usb_open()`, and `idmouse_open()` must return `-EBUSY` under their mutex if already open. [F179, F263, F325, F341, F343]

## Error Handling
- Check `usbtest_do_ioctl()` and `ehset_prepare_port_for_testing()` with `< 0` (not `if (ret)`). In `ctrl_complete()`, restore `status = ctx->status` after `usb_unlink_urb()` so `0` does not resubmit the URB. In `usbtest.c`, validate `sglen <= MAX_SGLEN`, `sglen > 0`, `iterations <= UINT_MAX / sglen` (`sglen >= 4` in case 24), and bounds-check BOS capability sizes against `dev->buf + total` in `ch9_postconfig()`. [F200, F201, F211, F243, F244]
- Check 2-byte `usb_control_msg()` reads with `retval < 2` in `appledisplay_bl_get_brightness()` (`-EMSGSIZE`) and `cypress_cy7c63.c:vendor_command()`, and check `!IS_ERR(backlight)` before setting `pdata->bd` in `appledisplay_probe()`. Zero `struct mon_bin_hdr` (`memset(ep, 0, PKT_SIZE)`) and `dp->_pad = 0` in `mon_bin.c`. [F204, F210, F212]
- Use `be32_to_cpu(rec->addr)`/`be16_to_cpu(rec->len)` and check `i + be16_to_cpu(rec->len) < FW_LOAD_SIZE` (1023) in `emi26.c`/`emi62.c`/`ezusb.c`; verify `ptr + 4` and `ptr + llen` (`min(len, 50)`) against `firmware->data + firmware->size` in `isight_firmware_load()`. Check `bNumEndpoints >= 2` (`>= 3` for `PARPORT_MODE_ECP`) on altsetting 2 in `uss720_probe()`, check `read_buffer_length < (4 * maxp) - actual_length` in `adu_interrupt_in_callback()`, use `simple_read_from_buffer()` in `yurex_read()`, and do not log or resubmit on `-ENOENT`/`-ECONNRESET`/`-ESHUTDOWN` in URB callbacks. [F250, F252, F253, F255, F257, F340]

## External Contracts
- `mon_bin_mmap()` must reject `VM_WRITE` (`-EPERM`) and clear `VM_MAYWRITE` via `vm_flags_mod()`; pointer ioctls (`MON_IOCX_GET*`, `MFETCH`, `STATS`) require compat handlers in `mon_bin_compat_ioctl()`; `mon_text_add()` debugfs files must use mode `0600`; and `usbtest_ioctl()` must support both `USBTEST_REQUEST_32` and `USBTEST_REQUEST_64`. [F332, F337, F338, F342]

## Known Pitfalls
- In `mon_text.c`, `mon_text_ctor()` poisons objects with `0xe5`: `mon_text_read_u()` must check `ep->type == 'E'` before `ep->xfertype`, `mon_text_read_*` must guard fields with `type`, `xfertype`, `setup_flag == 0`, and `data_flag == 0` while clamping `numdesc` to `ISODESC_MAX` (5) and `length` to `DATA_MAX` (32), and `mon_get_timestamp()` must mask `now.tv_sec` with `0xFFF`. In `mon_stop()`, `mbus` is reused as the `list_for_each_entry` cursor when `mbus == &mon_bus0`. [F213, F240, F268, F270]
- In `usbtest.c`, URB `offset` must be `< ARCH_KMALLOC_MINALIGN` for `buffer_offset(buf)`. In `iowarrior_ioctl()`, convert `idVendor`/`bcdDevice` with `le16_to_cpu()`, but never byte-swap `dev->product_id` or `dev->udev->speed`. Keep `dev->bbu` (`__s64`) and `c` (`unsigned long long`) 64-bit in `yurex.c`, match `hub_udev` via `usb_device_match_id()` (never `to_usb_interface()`) in `ehset.c`, and keep the `usb_string(udev, 255, ...)` quirk for `CASSY`/`COM3LAB` (`bcdDevice <= 0x103`) in `ld_usb_probe()`. [F242, F246, F271, F276, F301]
