# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers) — drivers/ata (part 2)

This component implements the core libata subsystem library (`libata-core.c`), the Error Handler (EH) and recovery engine (`libata-eh.c`), SATA-specific link/PHY/NCQ helpers (`libata-sata.c`), SATA Port Multiplier (PMP) support (`libata-pmp.c`), and PATA transfer timing calculations (`libata-pata-timings.c`). It manages the lifecycle of `ata_host`, `ata_port`, `ata_link`, `ata_device`, and `ata_queued_cmd` objects, device probing/IDENTIFY parsing, command issuing and completion, link power management, and multi-stage error recovery.

## Architecture & Data Flow

- `ata_qc_issue()` marks `qc` active (`ATA_QCFLAG_ACTIVE`, `ap->qc_active`, `ap->nr_active_links`, and `link->sactive` or `link->active_tag`) at entry, so every subsequent error path in `ata_qc_issue()` must complete `qc` via `ata_qc_complete()` (or `ata_link_abort()`) so `__ata_qc_complete()` reverses those state updates and unmaps DMA. [F195]
- When issuing or completing an ATA command in `ata_qc_issue()` and `__ata_qc_complete()`, `ap->nr_active_links` must be incremented and decremented on every non-NCQ command, but for NCQ commands only when `link->sactive` transitions from zero to non-zero or back to zero. [F235]
- When `ata_eh_get_ncq_success_sense()` reads a valid sense descriptor from `ATA_LOG_SENSE_NCQ`, it must copy `nsect`, `lbal`, `lbam`, `lbah`, their HOB counterparts, and (when `aux_icc_valid` is true) `auxiliary` into `qc->result_tf` in addition to building `qc->scsicmd->sense_buffer` and setting `ATA_QCFLAG_SENSE_VALID`. [F240]
- When `ata_eh_analyze_ncq_error()` identifies the single offending command from log page 10h, it must clear `ATA_ERR` from `qc->result_tf.status`, zero `qc->result_tf.error`, and set `ATA_QCFLAG_RETRY` on all other non-successful EH commands on that physical link, and clear `AC_ERR_DEV` from `ehc->i.err_mask`. [F241]
- In `ata_scsi_cmd_error_handler()`, `set_host_byte(scmd, DID_OK)` must first be called on every command in `eh_work_q`, and `set_host_byte(scmd, DID_TIME_OUT)` must then be restored along with `AC_ERR_TIMEOUT` and `ATA_QCFLAG_EH` when an active `qc` matching `scmd` does not yet have `ATA_QCFLAG_EH` set. [F242]
- When `ATA_PFLAG_RESUMING` is set on `ap->pflags` in `ata_scsi_port_error_handler()`, `ATA_DFLAG_RESUMING` must be set on each enabled `dev->flags` along with `ATA_EH_SET_ACTIVE` in `ehc->i.dev_action[devno]`, and `ATA_DFLAG_RESUMING` must be cleared on `dev->flags` if `ata_eh_revalidate_and_attach()` fails. [F243]
- Because `ata_read_log_directory()` caches log page 0 in `dev->gp_log_dir` and skips re-reading from the device whenever `get_unaligned_le16(&dev->gp_log_dir[0]) == 0x0001`, `ata_dev_configure()` must call `ata_clear_log_directory(dev)` before querying device logs, and `ata_read_log_directory()` must clear `dev->gp_log_dir` on error. [F244]
- When attaching a Port Multiplier in `sata_pmp_attach()`, `link->pmp` on the host link must be set to `SATA_PMP_CTRL_PORT` before reading GSCRs and reset to `0` on failure, and `sata_pmp_detach()` must reset both `ap->nr_pmp_links = 0` and `link->pmp = 0` under `ap->lock`. [F246]

## Synchronization

- `ata_exec_internal()` must save and zero `link->active_tag`, `link->sactive`, `ap->qc_active`, and `ap->nr_active_links` under `ap->lock` before issuing `ATA_TAG_INTERNAL`, freeze the port on timeout to force completion of the on-stack `wait` and `sgl`, and restore the saved values under `ap->lock` after `ata_qc_free(qc)`. [F197]
- In ata_port_alloc(), ap->pflags is initialized with ATA_PFLAG_INITIALIZING | ATA_PFLAG_FROZEN before the port is exposed, and ata_std_sched_eh() returns immediately without scheduling EH while ATA_PFLAG_INITIALIZING is set. [F199]
- In ata_port_detach(), async boot probing (async_synchronize_cookie) and active EH (ata_port_wait_eh) must be drained, and attached SCSI devices removed via scsi_remove_device() under ap->scsi_scan_mutex (dropping ap->lock around the call), before setting ATA_PFLAG_UNLOADING and scheduling EH. [F202]
- In ata_port_request_pm(), checking and setting ATA_PFLAG_PM_PENDING in ap->pflags, updating ap->pm_mesg and link->eh_info, and calling ata_port_schedule_eh(ap) must be performed under ap->lock, dropping ap->lock around blocking calls to ata_port_wait_eh(ap). [F205]
- All mutations to ap->qc_active, ap->nr_active_links, ap->excl_link, link->active_tag, link->sactive, and qc->flags (including ATA_QCFLAG_ACTIVE and ATA_QCFLAG_EH) during command issue (ata_qc_issue) and completion (__ata_qc_complete, ata_qc_complete, ata_qc_complete_multiple) must be performed while holding ap->lock. [F206]
- In ata_scsi_cmd_error_handler(), after flushing the SFF PIO task via ata_sff_flush_pio_task(ap), ap->lock must be held continuously across ap->ops->lost_interrupt(ap), scanning eh_work_q to set ATA_QCFLAG_EH on active timed-out commands, and freezing the port via __ata_port_freeze(ap) when nr_timedout > 0. [F207]
- In ata_port_freeze(), __ata_port_freeze(ap) must be called before ata_port_abort(ap) under ap->lock because hardware freeze operations may be required before taskfile registers are accessible during command completion/abort. [F208]
- In ata_scsi_port_error_handler(), at the start of each EH pass, timer_delete_sync(&ap->fastdrain_timer) must be called outside ap->lock before copying each link's eh_info into eh_context.i, zeroing link->eh_info, setting ATA_PFLAG_EH_IN_PROGRESS, and clearing ATA_PFLAG_EH_PENDING under ap->lock. [F209]

## Object Lifetimes

- Releasing a `struct ata_port` allocated by `ata_port_alloc()` must call `ata_port_free()` rather than `kfree()` directly so that `ap->pmp_link`, `ap->slave_link`, and `ap->print_id` in `ata_ida` are freed. [F187]
- `ata_host_start()` must pre-allocate the `ata_host_stop` devres node before starting any port, unwind already-started ports in reverse (`while (--i >= 0)`) and call `devres_free(start_dr)` if any `ap->ops->port_start()` fails, and only call `devres_add()` and set `ATA_HOST_STARTED` after all ports start. [F189]
- `ata_host_register()` requires `ATA_HOST_STARTED` to be set in `host->flags` before entry, and if `ata_tport_add()` or `ata_scsi_add_hosts()` fails, it must delete all previously added transport ports in reverse order via `ata_tport_delete()` to drop their `host->kref` references. [F190]
- `ata_port_detach()` must synchronize `ap->cookie`, remove all `dev->sdev` (setting `dev->sdev = NULL`), and wait via `ata_port_wait_eh()` for the `ATA_PFLAG_UNLOADING` EH run to set `ATA_PFLAG_UNLOADED` before canceling `hotplug_task` and `scsi_rescan_task` or deleting `ap->pmp_link`, `ap->scsi_host`, and `ap->tdev`. [F191]
- `ata_dev_config_cpr()` and `ata_dev_config_cdl()` must free and clear any previously allocated `dev->cpr_log` or `dev->cdl` (via `swap(dev->cpr_log, cpr_log)` / `kfree(cpr_log)` and `ata_dev_cleanup_cdl_resources()`) when revalidation finds the feature unsupported or log reading fails. [F193]
- In `sata_pmp_init_links()`, if `ata_tlink_add(&pmp_link[i])` fails during initial `ap->pmp_link` allocation, the error path must delete all previously registered transport links in reverse (`while (--i >= 0) ata_tlink_delete(&pmp_link[i])`), free `pmp_link`, and reset `ap->pmp_link = NULL`. [F194]
- `ata_dev_init()` zeroes `struct ata_device` from `ATA_DEVICE_CLEAR_BEGIN` (`n_sectors`) to `ATA_DEVICE_CLEAR_END` (`ering`), so any field that must persist across re-probing (such as `link`, `devno`, `sdev`, `tdev`, or `ering`) must be defined outside that range and any heap pointer inside it must be freed before `ata_dev_init()`. [F310]

## API Contracts

- `ata_sg_setup()` must save the original scatterlist entry count in `qc->orig_n_elem` before overwriting `qc->n_elem` with the coalesced count from `dma_map_sg()`, and `ata_sg_clean()` must pass `qc->orig_n_elem` to `dma_unmap_sg()` before clearing `ATA_QCFLAG_DMAMAP` and `qc->sg`. [F196]
- ata_host_start() must be called before ata_host_register() so that port_ops tables are finalized via ata_finalize_port_ops(), each port's ->port_start() is invoked and frozen via ata_eh_freeze_port(), and ATA_HOST_STARTED is set in host->flags before IRQs or async probes are registered. [F200]
- `ata_exec_internal()` and internal command wrappers (`ata_do_dev_read_id()`, `ata_dev_set_feature()`, `ata_read_log_page()`, `sata_pmp_read()`, `sata_pmp_write()`, `atapi_eh_tur()`, `atapi_eh_request_sense()`) return `0` on success and a positive `AC_ERR_*` bitmask on failure, which callers returning `int` must translate to negative errnos. [F221]
- `ata_id_string()` requires an even byte length `len` (`BUG_ON(len & 1)`) and does not append a NUL byte, whereas `ata_id_c_string()` requires an odd buffer length `len` (even character count plus 1 for the trailing NUL) and indexing `id` by 16-bit word offset `ofs`. [F222]
- `ata_xfer_mask2mode()` and `ata_timing_cycle2mode()` return `u8` with `0xff` when no transfer mode matches, whereas `ata_xfer_mode2shift()` returns `-1` and `ata_xfer_mode2mask()` returns `0` on failure. [F223]
- `ata_phys_link_online()` / `ata_link_online()` and `ata_phys_link_offline()` / `ata_link_offline()` both return `false` when SCR_STATUS cannot be read, so `!ata_link_online(link)` is not equivalent to `ata_link_offline(link)`; moreover, `ata_link_online()` and `ata_link_offline()` must not be called on `ap->slave_link`. [F224]
- `sata_link_hardreset()` and `sata_std_hardreset()` return `-EAGAIN` (not `0`) when a reset succeeds on an online link that requires a follow-up softreset, and `sata_link_hardreset()` keeps `*online = true` on `-EAGAIN` while clearing `*online = false` on all other non-zero return codes. [F227]
- `ata_qc_complete_multiple(ap, qc_active)` takes the bitmask of commands still active in hardware (not the mask of completed commands) and returns `-EINVAL` if any bit set in `qc_active` was not already active in `ap->qc_active`, or the count of completed commands (`>= 0`) on success. [F228]

## Error Handling

- When iterating `host->ports[i]` up to `host->n_ports` in `ata_devres_release()` or `ata_host_release()`, code must handle `NULL` `struct ata_port *` entries because `ata_host_alloc()` registers the devres release callback and sets `host->n_ports` before allocating individual ports. [F220]
- Functions called during the per-link recovery phase of `ata_eh_recover()` that take `struct ata_device **r_failed_dev` (`ata_eh_revalidate_and_attach()`, `ata_eh_set_mode()`, `ata_set_mode()`, `ap->ops->set_mode`, and `ata_eh_link_set_lpm()`) must set `*r_failed_dev` to the failing device whenever they return a non-zero error. [F226]
- `ata_eh_read_log_10h()` must reject NCQ error log page 10h when bit 7 (`buf[0] & 0x80`) is set and mask `*tag = buf[0] & 0x1f`, and `ata_eh_analyze_ncq_error()` must verify `link->sactive & BIT(tag)` before indexing `__ata_qc_from_tag(ap, tag)`. [F265]
- Because CHS sector numbers in `tf->lbal` are 1-based (`1..255`), `ata_build_rw_tf()` must compute `sect = (u32)block % dev->sectors + 1` and reject `(cyl >> 16) || (head >> 4) || (sect >> 8) || (!sect)`, and `ata_tf_read_block()` must reject `sect == 0` (returning `U64_MAX`) before subtracting `1`. [F275]
- In `ata_host_activate()`, if `ata_host_register(host, sht)` fails after `devm_request_irq()` has succeeded, `devm_free_irq(host->dev, irq, host)` must be called before returning the error. [F327]
- In `ata_eh_link_established()`, a non-zero return from `sata_scr_read(link, SCR_STATUS, &sstatus)` must return `true` rather than `false` so that IDE/PATA ports and adapters without `scr_read` support are treated as having an established link during revalidation. [F331]
- In `ata_eh_link_autopsy()`, block layer `RQF_QUIET` requests are mapped via `ata_eh_quiet(qc)` to `ATA_QCFLAG_QUIET`, and when all failed commands on a link are quiet (`nr_quiet == nr_failed`), `ATA_EHI_QUIET` must be set on `ehc->i.flags` so `ata_eh_link_report()` suppresses kernel error logs. [F368]

## External Contracts

- When reading a variable-length ATA General Purpose Log page such as `ATA_LOG_CONCURRENT_POSITIONING_RANGES` in `ata_dev_config_cpr()`, the buffer size and `ata_read_log_page()` sector count must be derived from the log's supported page count returned by `ata_log_supported()` rather than a hardcoded maximum size. [F260]
- Unlike `dev->id`, ATA General Purpose Log pages read via `ata_read_log_page()` into `u8` buffers remain in raw little-endian byte order and must be decoded with `get_unaligned_le16()`/`32()`/`64()`, and 64-bit capability QWords in `ATA_LOG_IDENTIFY_DEVICE` pages must have bit 63 (`BIT_ULL(63)`) set before their lower bits are used. [F263]
- `ata_eh_get_ncq_success_sense()` must validate that `ATA_LOG_SENSE_NCQ` (log 0x0F) has version `1` and log address `0x0f` in its 64-bit header and that `sense_valid & BIT(tag)` is set before indexing `&buf[32 + 24 * tag]` in `dev->cdl->ncq_sense_log_buf`. [F266]
- `ata_lpm_policy_names[]` must have an entry for every `enum ata_lpm_policy` enumerator, and `ata_scsi_lpm_store()` must iterate starting from `ATA_LPM_MAX_POWER` (excluding index 0, `ATA_LPM_UNKNOWN`) because `ata_eh_link_set_lpm()` rejects `ATA_LPM_UNKNOWN` with `WARN_ON_ONCE(policy == ATA_LPM_UNKNOWN)`. [F276]
- `ata_read_native_max_address` must add 1 to the 0-based maximum LBA returned by `ATA_CMD_READ_NATIVE_MAX(_EXT)` (and decrement it again if `ATA_QUIRK_HPA_SIZE` is set) to produce a sector count, whereas `ata_set_max_sectors` must decrement `new_sectors` by 1 before encoding the 0-based maximum LBA into `ATA_CMD_SET_MAX(_EXT)`. [F300]
- Drivers that expose `dev_attr_link_power_management_policy` in their `Scsi_Host` sysfs attribute tables must also expose `dev_attr_link_power_management_supported`, and LPM support checks in `ata_scsi_lpm_supported()` must be performed under `ap->lock` checking both `ATA_FLAG_NO_LPM` and `ATA_QUIRK_NOLPM`. [F362]
- When a command with `ATA_QCFLAG_HAS_CDL` completes with `ATA_SENSE` set in `qc->result_tf.status`, `ata_qc_complete()` must set `SCMD_FORCE_EH_SUCCESS`, `ATA_QCFLAG_EH_SUCCESS_CMD`, `ATA_EH_GET_SUCCESS_SENSE`, and `ATA_PFLAG_EH_PENDING` before `ata_qc_schedule_eh()`, and EH must call `ata_eh_decide_disposition()` after fetching sense. [F366]

## Known Pitfalls

- Because `ata_identify_page_supported()` overwrites `dev->sector_buf` with page 0 of `ATA_LOG_IDENTIFY_DEVICE`, any caller that also uses `dev->sector_buf` must finish calling `ata_identify_page_supported()` before reading its own log page into `dev->sector_buf`. [F245]
- Because `ata_dev_read_id()` converts `dev->id` from little-endian 16-bit words to native CPU `u16` words in-place via `swap_buf_le16()`, each `u16` word of an ATA string holds its first character in `id[ofs] >> 8` and its second character in `id[ofs] & 0xff`, requiring `ata_id_string()` or `ata_id_c_string()` instead of raw byte copies. [F262]
- When matching an ata_queued_cmd or ata_device to a physical ata_link during EH autopsy, sense retrieval, or error reporting, code must compare ata_dev_phys_link(qc->dev) == link rather than qc->dev->link == link, because slave-link devices have dev->link pointing to &ap->link while ata_dev_phys_link(dev) returns ap->slave_link. [F282]
- In `ata_tf_read_block` and `ata_tf_to_lba48`, the `u8` high-order LBA registers `tf->hob_lbah`, `tf->hob_lbam`, and `tf->hob_lbal` must be cast to `u64` before shifting left by 40, 32, and 24 bits. [F297]
- In the CHS branch of `ata_build_rw_tf`, `lba_28_ok(block, n_block)` must be verified before casting `block` (`u64`) to `u32` for division and modulo by `dev->sectors`, ensuring `block` fits in 28 bits and avoiding 64-bit division on 32-bit architectures. [F298]
- In `libata-pata-timings.c`, `ata_timing_quantize` must use `EZ(v, unit)` so that zero timing fields remain `0` while non-zero nanosecond values are scaled by 1000 and rounded up via `ENOUGH(v * 1000, unit)` (`((v * 1000 - 1) / unit + 1)`), and `ata_timing_compute` must subsequently clamp `t->cycle` to at least `t->active + t->recover`. [F301]
- In `sata_down_spd_limit` and the `ATA_DNXFER_DMA` path of `ata_down_xfermask_limit`, the bitmask must be verified non-zero (`mask > 1` or `udma_mask`/`mwdma_mask` non-zero) before shifting by `fls(mask) - 1` or `ffs(mask) - 1`, because `fls(0)` and `ffs(0)` return `0` and produce a `-1` shift exponent. [F302]
