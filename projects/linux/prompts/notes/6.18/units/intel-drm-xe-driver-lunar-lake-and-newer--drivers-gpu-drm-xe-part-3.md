# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 3)

GT management, GGTT, GSC, and GT-level SR-IOV PF services: GT init/reset, freq/idle/CCS sysfs, MCR steering, GPU pagefaults, GGTT allocation, GSC FW/MEI proxy, and SR-IOV PF provisioning, control, migration, monitoring, and policy.

## Architecture & Data Flow

- `xe_gt_init_early()` must call `xe_gt_mmio_init(gt)` before `xe_uc_init_noalloc()`, `xe_gt_mcr_init_early()`, and `xe_pat_init()`. `do_gt_restart()` must call `xe_gt_apply_ccs_mode(gt)`, and on `GRAPHICS_VERx100(xe) == 1200` SR-IOV PF, `xe_gt_sriov_pf_init_hw()` (in init and `do_gt_restart()`) writes `GUEST_GTT_UPDATE_EN` to `VIRTUAL_CTRL_REG`. [F262, F341, F364]
- In `xe_gt_mcr.c`, `xe_steering_types[LNCF].init` is `NULL` (set by `init_steering_mslice()`), so setting `gt->steering[LNCF].ranges` requires setting `MSLICE`. All `xe_mmio_range` tables end with `{}`. `dss_per_group()` checks `max_slices` and `max_subslices` non-zero before `DIV_ROUND_UP()`. `rw_with_mcr_steering()` keeps `MCR_MULTICAST` set in `steer_reg` during reads and restores it after unicast writes. `>=` version chains in `xe_gt_mcr_init_early()` and `pick_runtime_regs()` go highest to lowest. [F268, F284, F296, F323, F347]
- `xe_ggtt_set_pte()`/`read_pte()` index `ggtt->gsm` by `addr >> XE_PTE_SHIFT`, requiring page-aligned byte offset `< ggtt->size`. `xe_ggtt_invalidate()` reads root-tile `VF_CAP_REG` before `ggtt_invalidate_gt_tlb()` on `primary_gt` and `media_gt`. When `XE_GGTT_FLAGS_64K` is set, VRAM BOs in `__xe_ggtt_insert_bo_at()` and VF regions in `pf_get_ggtt_alignment()` use `SZ_64K` alignment, while `ggtt->scratch` uses `XE_BO_FLAG_SYSTEM`. [F285, F286, F369]
- `xe_ggtt_shift_nodes_locked()` moves all `drm_mm_node`s from `&ggtt->mm` to a temp list via `drm_mm_for_each_node_safe()` before shifting `node->start` and re-reserving. `xe_ggtt_largest_hole()`/`print_holes()` skip holes where `hole_start >= hole_end` after clamping/aligning. [F300, F306]
- `xe_gsc_init()` sets `XE_UC_FIRMWARE_NOT_SUPPORTED` and returns `0` if `tile->media_gt` exists and `gt != tile->media_gt`; `xe_gsc_proxy_init()` requires `IS_ENABLED(CONFIG_INTEL_MEI_GSC_PROXY)` and `xe_tile_is_root(tile)`. `gsc_upload()` sets `xe->needs_flr_on_fini = true`. When `gsc->fw` is loadable and not in error, `xe_gsc_stop_prepare()` asserts `XE_FW_GSC` forcewake and calls `xe_gsc_wait_for_proxy_init_done(gsc)`. [F355, F356, F357, F387]
- `gsc_work()` dispatches `gsc->work_actions` bits with independent `if`s, checking `GSC_ACTION_ER_COMPLETE` (`gsc_er_complete()`) first and jumping to `out` on error. `proxy_channel_alloc()` splits one `GSC_PROXY_CHANNEL_SIZE` buffer into `to_csme` and `from_csme` (`GSC_PROXY_BUFFER_SIZE` each); never free `from_csme` separately. `xe_gsc_read_out_header()` checks `size < GSC_HDR_SIZE` before `size - GSC_HDR_SIZE`. In `proxy_query()`, `validate_proxy_header()` checks `max_size = GSC_PROXY_BUFFER_SIZE - reply_offset`, CSME replies require `size >= PROXY_HDR_SIZE`, `GSC_PROXY_MSG_TYPE_PROXY_END` breaks, and `size += wr_offset` follows CSME replies. [F280, F281, F297, F308, F334]
- `pf_queue->num_dw` and `ACC_QUEUE_NUM_DW` are powers of two and multiples of 4-dword `PF_MSG_LEN_DW`/`ACC_MSG_LEN_DW`. `gt_reset()` calls `xe_gt_pagefault_reset(gt)` after `xe_uc_stop_prepare(&gt->uc)` to zero `head`/`tail` under each queue lock. In `pf_queue_work_func()` and `acc_queue_work_func()`, if `time_after(jiffies, threshold)` while `tail != head`, re-queue `w` before breaking. [F279, F283, F309, F326]
- In `emit_wa_job()`, `entry->reg.masked || entry->clr_bits == ~0` in the counting pass must match the emission passes, and `bb_len` must cover LRI (`count * 2 + 1`), MI_MATH (`count_rmw * 20 + 7`), and 3DSTATE (`xe_gt_lrc_size() / sizeof(u32)`). `struct drm_gpu_scheduler base` must be the first member of `struct xe_gpu_scheduler` for `xe_sched_entity_init()`. [F303, F329, F335]
- `ccs_mode_store()` rejects `!num_engines`, `num_engines > num_slices`, or `num_slices % num_engines != 0` (`num_slices = hweight32(CCS_MASK(gt))`). `__xe_gt_apply_ccs_mode()` initializes `cslice = 0` once before the outer `width` loop and increments it across all `width * num_engines` inner iterations after skipping fused-off bits. [F293, F304]
- `gt->sriov.pf.vfs` uses `PFID` (`0`) and `VFID(1..total_vfs)`: VF-only APIs (`save_guc_state`, `config_release`, `config_sanitize`) assert `vfid != PFID`, while `config_get/set_{ggtt,lmem,ctxs,dbs}()` route `0` to `pf.spare`. `pf_control_state_index()` and `pf_snapshot_index()` subtract against `pf.vfs[]`. VF/spare GGTT and LMEM live only on `tile->primary_gt`; media GT `pf_push_full_vf_config()` reads GGTT from `primary_gt`. On LMTT devices, `pf_provision_vf_lmem()` and `pf_release_vf_config()` update/invalidate all tiles' LMTTs via `pf_update_vf_lmtt()` or `pf_reset_vf_lmtt()`. [F255, F256, F274, F333]
- `pf_provision_sched_if_idle()` calls `pf_bulk_reset_sched_priority()`. On PF GT reset, `pf_restart()` calls `xe_gt_sriov_pf_config_restart()` and `xe_gt_sriov_pf_control_restart()` (`pf_enter_vf_ready()`). `pf_process_vf_state_machine()` checks state bits in priority order: `FLR`, `STOP`, `PAUSE`, `RESUME`. Before `GUC_PF_TRIGGER_VF_FLR_FINISH`, VF FLR runs `FLR_RESET_CONFIG` (`xe_gt_sriov_pf_config_sanitize()`), `FLR_RESET_DATA` (`xe_sriov_pf_service_reset_vf()`, `xe_gt_sriov_pf_monitor_flr()`), and `FLR_RESET_MMIO` (`xe_gt_sriov_pf_sanitize_hw()`). [F275, F277, F278, F298]
- Under `pfc->lock`, `pf_worker_find_work()` uses `list_del_init(&cs->link)` and re-queues via `pf_queue_control_worker(gt)` if `more || !empty`, and `pf_queue_vf()` uses `list_move_tail()`. `pf_process_runtime_query_msg()` clamps VF limit to `max_chunks`, and `pf_service_runtime_query()` rejects `start > runtime->size` (`-ERANGE`) before subtracting. [F289, F301]

## Synchronization

- `sched->msgs` uses `sched->base.job_list_lock` (`xe_sched_msg_lock()`/`unlock()`); `xe_sched_process_msg_work()` drops it via `xe_sched_get_msg()` before `sched->ops->process_msg(msg)`. `xe_sched_submission_stop()` calls `drm_sched_wqueue_stop(&sched->base)` before `cancel_work_sync(&sched->work_process_msg)`. [F231, F380]
- `gsc->lock` (protecting `gsc->work_actions`, taken in GSC IRQ handlers) and `pf_queue->lock` (taken in hardirq by `xe_guc_pagefault_handler()`) require `spin_lock_irq()`/`irqsave()` in process/worker contexts. `xe_gsc_proxy_request_handler()` revalidates `gsc->proxy.component != NULL` under `gsc->proxy.mutex` across `proxy_query()`. [F233, F235, F370]
- On `GRAPHICS_VERx100(xe) >= 1270`, `mcr_lock()`/`mcr_unlock()` pair `gt->mcr_lock` with polling/writing `0x1` on `STEER_SEMAPHORE` (`xe_mmio_wait32(..., atomic = true)`), with callers already holding forcewake. In `handle_vma_pagefault()`, `xe_vma_userptr_pin_pages()` runs under `vm->lock` outside `drm_exec_until_all_locked(&exec)`, jumps out call `xe_vm_set_validation_exec(vm, NULL)`, and `unlock_dma_resv` calls `xe_validation_ctx_fini(&ctx)` before `goto retry_userptr`. [F267, F302, F372, F373]
- `xe_gt_freq.c` sysfs handlers taking `&pc->freq_lock` first call `xe_pm_runtime_get()`. `gtidle->lock` is a `raw_spinlock_t` (`raw_spin_lock_irqsave()`); `get_residency_ms()` and `gtidle->idle_residency(pc)` must not sleep or take non-raw locks. `ccs_mode_store()` rejects `IS_SRIOV(xe)` (`-EOPNOTSUPP`) and holds `xe->drm.filelist_mutex` while checking `list_empty(&xe->drm.filelist)` (`-EBUSY`), updating `gt->ccs_mode`/engines, and calling `xe_gt_reset(gt)`. [F362, F375, F376]
- `pf_enter_vf_{pause,resume,stop,flr}_wip()` calls `pf_enter_vf_wip()` (`reinit_completion(&cs->done)`) before queuing work. `pf_exit_vf_pause_send_pause()` and `pf_exit_vf_flr_send_start()` set `PAUSE_WAIT_GUC`/`FLR_WAIT_GUC` before sending H2G (clearing on error). `xe_gt_sriov_pf_master_mutex(gt)` nests outside `&ggtt->lock` and BO `dma_resv` locks. `gt->sriov.pf.vfs[vfid].snapshot` requires `pf_migration_mutex(gt)`. [F241, F243, F276, F382]

## Object Lifetimes

- `xe_ggtt_init_early()` registers `dev_fini_ggtt` (`devm`, draining `ggtt->wq`) and `ggtt_fini_early` (`drmm`, destroying `wq`/`lock`/`mm`). `xe_ggtt_node_remove()` defers to `ggtt->wq` if `!xe_pm_runtime_get_if_active(xe)`, and `ggtt_node_remove()` guards `xe_ggtt_clear()`/`invalidate()` with `drm_dev_enter()` while always removing `node->base` and freeing `node`. [F210, F353]
- `xe_gsc_init_post_hwconfig()` acquires `bo`, `q`, `wq` (unwinding `q` then `bo`), and `free_resources()` destroys `gsc->wq` before `xe_exec_queue_put(gsc->q)` and NULLs both. `xe_gsc_proxy_remove()` disables HECI2 IRQs and flushes `gsc->work` (`xe_gsc_wait_for_worker_completion()`) before `component_del()`; `xe_gsc_proxy_component_unbind()` flushes `gsc->work` before clearing `gsc->proxy.component` under `gsc->proxy.mutex`. [F212, F359]
- `xe_gt_record_default_lrcs()` puts `nop_q` then `q` on all paths. `xe_gt_pagefault_init()` calls `destroy_workqueue(gt->usm.pf_wq)` if `acc_wq` fails. `pf_queue_restart()` takes `xe_pm_runtime_get_noresume()` for `workers.restart`, balanced by failed `queue_work()`, `pf_restart()`, or `pf_cancel_restart()`/`pf_fini_workers()` when `cancel/disable_work_sync()` returns true. [F214, F218, F219]
- In `pf_provision_vf_{ggtt,ctxs,dbs,lmem}()`, re-provisioning pushes a zeroed config to GuC before freeing old resources, and rolls back newly reserved resources in reverse order if GuC KLV push fails. `pf_alloc_guc_state()` calls `pf_free_guc_state()` first (also called on error in `pf_save_vf_guc_state()` / `write_guc_state()`). `pf_sanitize_lmem()` brackets `xe_migrate_clear()` with `xe_bo_lock()`/`unlock()` and puts `fence` after `dma_fence_wait_timeout()` before unlocking. [F220, F221, F223, F224]

## API Contracts

- `xe_ggtt_node_insert_balloon_locked()` takes exclusive `end` (not `size`) as arg 3. `xe_gsc_emit_header()` requires bits 63:56 (`HOST_SESSION_CLIENT_MASK`) of `host_session_id` == 0 and returns `offset + GSC_HDR_SIZE`. `xe_gt_mcr_get_nonterminated_steering()` sets `*group`/`*instance` and returns `true` only when not `IMPLICIT_STEERING`. MCR accessors assert `!IS_SRIOV_VF()`. [F247, F248, F251, F252]
- `xe_gt_sriov_pf_config_save()` asserts `!(!buf ^ !size)` (`size >= SZ_4K` when non-NULL). `config_save/restore()`, `snapshot->guc.size`, and `pf_alloc_guc_state()` use bytes, whereas `encode_config()`, `pf_restore_vf_config()`, and `guc_action_vf_save_restore()` / `pf_send_guc_*_vf_state()` use `u32` dwords (`* sizeof(u32)`). `xe_gt_clock_interval_to_ms()` uses `div_u64_roundup()`, and `pf_estimate_fair_ggtt()`/`lmem()` use `ALIGN_DOWN(div_u64(available, num_vfs), alignment)`. [F259, F322, F324, F331, F332]
- Sysfs under child kobjects (`freq0`, `gtidle`) pass `kobj->parent` to `kobj_to_gt()`; direct `gt->sysfs` attrs (`xe_gt_ccs_mode.c`) pass `&kdev->kobj`. In `xe_gt_debugfs.c`, PF-only entries go in `pf_only_debugfs_list`, and `xe_gt_debugfs_simple_show` requires `.data = print_fn` with `i_private == gt`. In `xe_gt_sriov_pf_debugfs.c`, `extract_gt()`/`extract_vfid()` require the `pf`/`vfN` dentry (`parent` in `debugfs_create_file_unsafe()`, `file_dentry(file)->d_parent` in `file_operations`), and setters reject `val > (TYPE)~0ull` (`-EOVERFLOW`). [F318, F336, F365, F389, F390]

## Error Handling

- `xe_ggtt_node_init()` returns `ERR_PTR(-ENOMEM)` while `xe_ggtt_node_{remove,allocated,fini}()` only check `NULL`, so reset nullable fields (`bo->ggtt_node[tile_id]`) to `NULL` on `IS_ERR()`. In `xe_ggtt_init()`, reset `ggtt->scratch = NULL` on `ERR_PTR` because `xe_ggtt_clear()` checks `if (ggtt->scratch)`. [F244, F246]
- Poison reused GSC reply buffers (`&gsc->proxy.from_gsc`) via `xe_gsc_poison_header()` before submission. `xe_gsc_init()` returns `0` when `!xe_uc_fw_is_enabled(&gsc->fw)` or `xe_gsc_proxy_init() == -ENODEV`. `asid_to_vm()` returns `ERR_PTR(-EINVAL)` and takes `xe_vm_get()`, requiring `IS_ERR(vm)` and `xe_vm_put(vm)`. In `gt_reset()`, errors after `xe_gt_sanitize(gt)` must put `fw_ref`, call `xe_uc_start()` and `xe_device_declare_wedged()`, and put runtime PM. [F249, F250, F253, F344]
- `pf_send_guc_{query_vf_state_size,save_vf_state,restore_vf_state}()` map `0` to `-ENODATA` and `ret > ndwords` to `-EPROTO`; `pf_alloc_guc_state()` requires `0 < size <= SZ_2M` and `size % sizeof(u32) == 0`. `pf_push_{vf,policy}_buf_klvs()` map `0 <= ret < num_klvs` to `-ENOKEY` and `ret > num_klvs` to `-EPROTO`. [F257, F258, F291]

## External Contracts

- SR-IOV PF GuC HXG handlers (`pf_process_handshake_msg()`, `xe_gt_sriov_pf_{monitor,control}_process_guc2pf()`) check message dword length and header MBZ == `0` (`-EPFNOSUPPORT`) before reading `msg[1..]`. `pf_restore_vf_config()` checks `num_dwords >= GUC_KLV_LEN_MIN`, `num_dwords >= len`, and expected KLV length before reading `value[]`. Debugfs `config_blob_write()` / `guc_state_write()` reject `*pos != 0`, empty writes (`-ENODATA`), `size % sizeof(u32) != 0` (`-EINVAL`), and `size > SZ_4K` / `SZ_2M`. [F290, F294, F392]

## Known Pitfalls

- In `pf_queue_work_func()`, `PFR_SUCCESS` is `0` on success and `1` on failure (`pf.fault_unsuccessful`, which must be initialized/reset to `0`). In `get_pagefault()`, cast `FIELD_GET(PFD_VIRTUAL_ADDR_HI, desc->dw3)` to `u64` before `<< 32`. `xe_gt_record_default_lrcs()` must run `emit_nop_job(gt, nop_q)` after `emit_wa_job(gt, q)` before copying `q->lrc[0]->bo->vmap`. In `validate_proxy_header()`, `GSC_PROXY_MSG_TYPE_PROXY_PAYLOAD` only `break`s if `length > 0`. [F254, F271, F299, F316]
- In `gsc_upload_and_init()`, WA `14018094691` targets `tile->primary_gt`. Non-VF `do_gt_reset()` brackets `GRDOM_FULL` `GDRST` reset with `xe_gsc_wa_14015076503(gt, true/false)`. `xe_ggtt_init_early()` casts `(gsm_size / 8) * (u64)XE_PAGE_SIZE`, and uses `xelpg_pt_wa_ops` (`xe_ggtt_set_pte_and_flush()` under `ggtt->lock`) for `Wa_22019338487`. `get_residency_ms()` adds `BIT_ULL(32) - prev_residency` on 32-bit wrap before `mul_u64_u32_div()`. `xe_gt_idle_pg_print()` skips `XE_FW_GT` forcewake in `GT_IDLE_C6`. `__xe_gt_apply_ccs_mode()` ORs `CCS_MODE_CSLICE_0_3_MASK << 16`. [F312, F315, F325, F345, F350, F360, F361]
