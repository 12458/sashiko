# WANGXUN ETHERNET DRIVER — drivers/net/ethernet/wangxun

Core shared library (`libwx`) and 1GbE PF/VF drivers (`ngbe`, `ngbevf`) for Beijing WangXun PCIe Ethernet controllers. `libwx` provides Tx/Rx ring management, NAPI, page pool, MSI-X/MSI/INTx interrupts, SR-IOV mailbox protocols, PTP timestamping, MAC/VLAN filtering, and ethtool support, while `ngbe` and `ngbevf` provide PCI bindings and MDIO/phylink integration for WX1860 adapters.

## Architecture & Data Flow

- Every `net_device` using `libwx` callbacks must allocate `sizeof(struct wx)` private space so `netdev_priv(netdev)` points directly to `struct wx` at offset 0 (driver state goes in `wx->priv`). [F125]
- `wx_alloc_q_vector()` must use `struct_size(q_vector, ring, txr_count + rxr_count)`, and `wx_alloc_q_vectors()` must partition queues with `DIV_ROUND_UP(remaining, q_vectors - v_idx)`. Because `struct wx_ring` instances are embedded in `q_vector->ring[]`, `wx_set_ring()` must stage new allocations in `temp_ring[]` and only after all queues succeed free old resources and `memcpy` `temp_ring[i]` into `wx->tx_ring[i]` / `wx->rx_ring[i]`. [F56, F116, F121]
- Ring counts (`ring->count`) must be clamped to `[WX_MIN_TXD, WX_MAX_TXD]` (`[128, 8192]`) and aligned to 128. Circular rings leave 1 slot unused (`wx_desc_unused()` subtracts 1); `wx_alloc_rx_buffers()` and `wx_clean_tx_irq()` bias loop index `i` by `-ring->count` and must add `ring->count` back before storing `next_to_use` / `next_to_clean`. In `wx_xmit_frame_ring()`, required Tx descriptors must be computed via `TXD_USE_COUNT(S)` (`DIV_ROUND_UP(S, WX_MAX_DATA_PER_TXD)`) plus 3 before `wx_maybe_stop_tx()`. [F76, F81, F115]
- All Rx DMA operations must use the single `dma` field of `struct wx_rx_buffer`. `wx_clean_rx_ring()` must zero `rx_ring->desc` and reset `next_to_alloc`, `next_to_clean`, and `next_to_use` to 0, while `wx_alloc_rx_buffers()` must zero `wb.upper.status_error` and `length` on the sentinel `next_to_use` descriptor. In `union wx_rx_desc`, status/error bits (`WX_RXD_STAT_*`, `WX_RXD_ERR_*`, `WX_RXD_STAT_IPV6EX`) are in `wb.upper.status_error` (tested via `wx_test_staterr()`), while packet/RSS types are in `wb.lower.lo_dword`. In `wx_clean_rx_irq()`, `wx_is_non_eop()` must run before any `continue` so `next_to_clean` always advances. [F51, F85, F92, F104]
- `wx_configure_tx()` must set `WX_TDM_CTL_TE` before `wx_configure_tx_ring()` and `WX_MAC_TX_CFG_TE` after. `wx_configure_rx()` must call `wx_set_rx_buffer_len()` before `wx_configure_rx_ring()`, and bracket `wx_enable_rx()` with `wx_disable_sec_rx_path()` / `wx_enable_sec_rx_path()`. `wx_disable_rx()` must save `WX_PSR_CTL_SW_EN` in `wx->mac.set_lben` and clear it for `wx_enable_rx()` to restore, and only clear `WX_MAC_RX_CFG_RE` when `wx->subsystem_device_id` lacks `WX_NCSI_SUP` and `WX_WOL_SUP`. `wx_stop_adapter()` must disable all Tx/Rx queues and call `WX_WRITE_FLUSH(wx)` before `wx_disable_pcie_master()`. [F55, F127, F128, F148, F149]
- In `ngbe_up()` and `wxvf_up_complete()`, `wx_napi_enable_all(wx)` and clearing interrupt cause registers (`WX_PX_IC(0)` / `WX_PX_MISC_IC` or `WX_VXICR`) must precede unmasking IRQs. `wx_acquire_msix_vectors()` places queue vectors at `0..num_q_vectors - 1` and MISC at `num_q_vectors` (`.post_vectors = 1`), except when `WX_FLAG_IRQ_VECTOR_SHARED` is set (`wx_mac_em` with `num_vfs == 7`), where PF misc and queue 0 share vector 0 via `ngbe_misc_and_queue()`. Helpers must check `pdev->msix_enabled` or `wx->msix_q_entries` before dereferencing MSI-X entries. [F40, F77, F130, F136]
- `wx_setup_mrqc()` must unconditionally call `wx_config_rss_field()`, `wx_enable_rss()`, and `wx_setup_reta()` even with `WX_FLAG_VMDQ_ENABLED`. When `WX_FLAG_SRIOV_ENABLED` and `WX_FLAG_MULTI_64_FUNC` are set, PF RSS helpers must program per-pool registers indexed by `wx->num_vfs` (`WX_RDB_VMRSSTBL`, `WX_RDB_VMRSSRK`, `WX_RDB_PL_CFG(wx->num_vfs)`). PF RETA loops must bound iteration by `wx_rss_indir_tbl_entries(wx)` (64 with SR-IOV, 128 otherwise). In `wx_set_rss_queues()`, when `WX_FLAG_FDIR_CAPABLE` is set, `ring_feature[RING_F_FDIR].indices` must be reset to 1 before checking `f->indices > 1`. [F49, F63, F82, F91]
- `wx_set_rar()` and `wx_get_mac_addr()` store MAC bytes reversed: `addr[2..5]` in `WX_PSR_MAC_SWC_AD_L` and `addr[0..1]` in `AD_H`. `wx_mta_vector()` masks to 12 bits (`0xFFF`), split into 7-bit reg (`WX_PSR_MC_TBL_REG`) and 5-bit shift (`WX_PSR_MC_TBL_BIT`). `wx_write_mc_addr_list()` must call `wx_restore_vf_multicasts()` when `WX_FLAG_SRIOV_ENABLED` is set; `wx_set_vf_multicasts()` must clamp `msgbuf[0]` count to `WX_MAX_VF_MC_ENTRIES` (30). [F54, F73, F87, F112]
- Per-VF/pool 32-bit registers split the index via `WX_VF_REG_OFFSET` and `WX_VF_IND_SHIFT`. VLVF index 0 is reserved for VLAN 0, so non-zero VLAN loops in `wx_find_vlvf_slot()`, `wx_find_vlvf_entry()`, `wx_vlan_promisc_enable()`, and `wx_scrub_vfta()` must iterate `1..WX_PSR_VLAN_SWC_ENTRIES - 1`, and `wx_vlan_promisc_disable()` must call `wx_scrub_vfta()`. [F53, F79, F113]
- `wx_configure_port()` must keep `wx->tpid[0..7]` synced with `WX_CFG_TAG_TPID(0..3)`. `wx_fix_features()` must reject mismatched CTAG/STAG bit pairs in `NETIF_VLAN_{STRIPPING,INSERTION,FILTERING}_FEATURES`. In `wx_set_features()`, `netdev->features` must be updated before calling `wx->do_reset(netdev)` (required when `NETIF_F_HW_VLAN_CTAG_RX` changes and `do_reset` is set) or `wx_set_rx_mode(netdev)`. [F68, F137, F138, F167]
- VF code must read `WX_VXMAILBOX` via `wx_read_v2p_mailbox()` to latch `WX_VXMAILBOX_R2C_BITS` in `wx->mbx.mailbox` and clear bits via `wx_check_for_bit_vf()`. `wx_get_queues_vf()` must clamp `max_tx_queues` and `max_rx_queues` to `1..4`, `*num_tcs <= max_rx_queues`, and `*default_tc < max_tx_queues`. `wx_set_rx_mode_vf()` must test `IFF_PROMISC`, then `IFF_ALLMULTI`, then `IFF_BROADCAST | IFF_MULTICAST`. `wx_reset_hw_vf()` must guard `wx->b4_addr` with `if (wx->b4_addr)`, and `wx_speed_lookup_vf[]` must stay synced with `enum wx_mac_type`. [F39, F64, F69, F74, F95]
- `WX_TSC_1588_*` registers require `rd32ptp()` / `wr32ptp()`, and `wx_ptp_rx_hwtstamp()` / `wx_ptp_tx_hwtstamp()` must read `STMPL` before `STMPH` (which unlatches the timestamp). `wx_ptp_set_timestamp_mode()` must stage `WX_FLAG_RX_HWTSTAMP_*` locally until 1588 registers are flushed and latches cleared. Callers of `wx->ptp_setup_sdp` must check `if (wx->ptp_setup_sdp)`. [F38, F59, F67, F145]
- `wx_update_stats()` must zero `hwstats->qmprc` before summing `WX_PX_MPRC(i)` across PF queues (from `wx->num_vfs * wx->num_rx_queues_per_pool`), and `wx_clear_hw_cntrs()` must write 0 to `WX_PX_MPRC(i)`. `wx_gstrings_stats[]` entries must be `u64` or `u32` fields of `struct wx` (`u64` for `wx_gstrings_fdir_stats[]`). [F50, F124]
- On non-WangXun OEM PFs, `wx_sw_init()` reads `wx->subsystem_device_id` from flash `0xfffdc` via `wx_flash_read_dword()` and `swab16()`. `ngbe_phylink_init()` must use `PHY_INTERFACE_MODE_RGMII_RXID`. With `wx->gpio_ctrl`, `NGBE_GPIO_DR_0` is active-low (0 powers on SFP), and `WX_GPIO_POLARITY` is 0 (0x3 when false). [F134, F135, F140]

## Synchronization

- `wx_tx_map()` needs `wmb()` after descriptor writes and before setting `first->next_to_watch` and `tx_ring->tail`, paired with `smp_rmb()` in `wx_clean_tx_irq()` before reading `eop_desc->wb.status`. `wx_maybe_stop_tx()` needs `smp_mb()` after `netif_stop_subqueue()` before rechecking `wx_desc_unused()`, paired with `smp_mb()` in `wx_clean_tx_irq()` before `__netif_subqueue_stopped()`. `wx_clean_rx_irq()` needs `dma_rmb()` after `WX_RXD_STAT_DD`, and `wx_alloc_rx_buffers()` needs `wmb()` before `writel(i, rx_ring->tail)`. [F26, F27, F28]
- `ring->stats.{packets,bytes}` accesses must use `&ring->syncp` (`u64_stats_update_begin`/`end` in IRQ cleaners and `u64_stats_fetch_begin`/`retry` in `wx_get_stats64()` / `wx_get_ethtool_stats()`). `wx_napi_enable_all()` must `INIT_WORK` on `rx.dim.work` and `tx.dim.work` before `napi_enable()`, and `wx_napi_disable_all()` must `napi_disable()` before `disable_work_sync()`. [F16, F29]
- Updates to `wx->hw_tc` and `wx->hw_cc` (including `timecounter_read()`) must hold `write_seqlock_irqsave(&wx->hw_tc_lock, flags)`, and `wx_ptp_timecounter_cyc2time()` must use `read_seqbegin`/`retry`. `wx->ptp_setup_sdp` must only be called outside `hw_tc_lock` and never from hardirq `wx_ptp_check_pps_event()`. `wx->base_incval` uses `WRITE_ONCE` + `smp_mb()` in `wx_ptp_reset_cyclecounter()` paired with `smp_mb()` + `READ_ONCE` in `wx_ptp_adjfine()`. `wx->ptp_tx_skb` is serialized by `WX_STATE_PTP_TX_IN_PROGRESS` (`test_and_set_bit_lock()` before assignment, `clear_bit_unlock()` after nulling). [F20, F22, F30, F151]
- `wx_acquire_sw_sync()` / `wx_release_sw_sync()` must hold mutex `wx_sw_sync_lock` and touch only mask bits in `WX_MNG_SWFW_SYNC`. `wx_host_interface_command_s()` must release `WX_MNG_SWFW_SYNC_SW_MB` on all exit paths, and `wx_host_interface_command_r()` must increment `swfw_index` and clear `WX_STATE_SWFW_BUSY` on all exit paths; both must use `cpu_to_le32()`, flush with `rd32a()`, poll `timeout * 1000` us, and unconditionally check status `0x80`. `wx_host_interface_command()` is sleepable-only, and EEPROM hostif reads must hold `WX_MNG_SWFW_SYNC_SW_FLASH` across both command and `FW_NVM_DATA_OFFSET` read. [F13, F31, F61, F142, F150]
- Mailbox memory accesses require `wx_obtain_mbx_lock_pf()` / `wx_obtain_mbx_lock_vf()`. VF mailbox callers must take `wx->mbx.mbx_lock` with `spin_lock_bh()` and poll with `readx_poll_timeout_atomic()`. PF `wx_msg_task()` and its SR-IOV handlers run in hardirq context and must not sleep or use `GFP_KERNEL`. [F24, F154, F155]

## Object Lifetimes

- In `wx_build_skb()`, when `size > WX_RXBUFFER_256`, `rx_buffer->page` is attached to `skb` with `skb_mark_for_recycle()`, so `wx_dma_sync_frag()` and `wx_put_rx_buffer()` must not call `page_pool_put_full_page()`. `wx_clean_rx_ring()` must sync each buffer for CPU before `page_pool_put_full_page(..., false)` and must run before `page_pool_destroy()` in `wx_free_rx_resources()`. [F1, F162]
- `wx_free_resources()` does not free `wx->isb_mem`; callers (`ngbe_open()` rollback, `ngbe_close()`) must call `wx_free_isb_resources(wx)` only after `wx_free_irq(wx)`. `wx_free_irq()` must skip `pdev->irq` / `msix_entry->vector` when `wx->misc_irq_domain` is true and skip `msix_q_entries` without rings. `wx_reset_interrupt_capability()` must check `pdev->msix_enabled` and free/null `msix_q_entries` and `msix_entry` before `pci_free_irq_vectors()`. [F3, F4, F6]
- `wx_free_q_vector()` must null `wx->tx_ring` / `wx->rx_ring` pointers and call `netif_napi_del()` before `kfree_rcu(q_vector, rcu)` (matching RCU readers in `wx_get_stats64()`). `wx_sriov_clear_data()` must zero `wx->num_vfs` before freeing/nulling `wx->vfinfo` and `wx->mv_list`. `wx_ptp_init()` must init `hw_tc_lock` before `wx_ptp_create_clock()`. [F11, F14, F17]
- `wx_get_mac_addr()` must run after `wx_check_flash_load()` and HW reset. `wx_control_hw(wx, true/false)` must be called on open and on close/shutdown/probe error. `unregister_netdev()` must precede freeing `rss_key`/`mac_table`/`vfinfo`, `wx_clear_interrupt_scheme()`, and `phylink_destroy()` (while `wx_disable_sriov()` precedes `unregister_netdev()`). Never call `free_netdev()`, `iounmap()`, or `mdiobus_unregister()` on devres-managed resources. [F126, F131, F132, F133]

## API Contracts

- On DMA failure, `wx_tx_map()` unmaps fragments, frees `first->skb`, nulls `first->skb`, and restores `next_to_use`, so `wx_xmit_frame_ring()` must jump to `cleanup_tx_tstamp` (not `out_drop`). `wx_tso()` must check `skb_cow_head(skb, 0)` before mutating headers and returns `< 0` on error, `1` for TSO, or `0` otherwise (`wx_tx_csum()` runs only on `0`). IPv6 parsing in Tx offloads must use `ipv6_skip_exthdr()` and handle both `IPPROTO_IPIP` and `IPPROTO_IPV6`; unsupported `CHECKSUM_PARTIAL` L4 protocols in `wx_tx_csum()` must call `skb_checksum_help()`. [F7, F36, F165, F166, F169]
- In `wx_get_rx_buffer()`, the first non-EOP buffer (`!*skb`) skips DMA sync and saves `WX_CB(skb)->dma` for `wx_dma_sync_frag()` at EOP. `wx_rx_checksum()` must bypass L4 offload when `WX_RXD_STAT_IPV6EX` is set on non-SCTP packets and call `__skb_incr_checksum_unnecessary()` when `dptype.etype >= WX_DEC_PTYPE_ETYPE_IG`. `wx_alloc_page_pool()` must set `pool_size = rx_ring->count` (not `size`). [F43, F161, F173]
- `wx_add_mac_filter()` returns RAR index `>= 0` or `< 0` errno (never check `if (ret)`). In `WX_VF_SET_MACVLAN`, index 0 clears all filters, 1 clears then adds first, and `> 1` appends. `wx_write_mbx_{pf,vf}()` reject `size > WX_VXMAILBOX_SIZE` (15 dwords) with `-EINVAL`. `wx_host_interface_command()` requires dword-aligned `length` in `1..256` and rejects replies with `length < buf_len + hdr_size`; `wx_hic_read_shadow_ram` fields `address`/`length` require `cpu_to_be32()`/`cpu_to_be16()`, and `wx_read_ee_hostif*()` take 16-bit word offsets (`eeprom->sw_region_offset = data >> 1`). [F35, F45, F71, F72, F80, F86]

## Error Handling

- `wx_sw_init()` frees `wx->rss_key` on failure, so `ngbe_sw_init()` failure in `ngbe_probe()` must jump to `err_pci_release_regions`, while later errors jump to `err_free_mac_table`; inside `wx_sw_init()`, the OEM `wx_flash_read_dword()` branch must only return early on `err < 0`. [F2, F90]
- `wx_setup_rx_resources()` must jump to `err_desc` if `wx_alloc_page_pool()` fails. Extract `PTR_ERR()` before nulling `rx_ring->page_pool` or `wx->ptp_clock` on `IS_ERR()`. `wx_alloc_mapped_page()` must return `false` on `NULL` from `page_pool_dev_alloc_pages()`. [F5, F32, F33]
- In `wx_set_interrupt_capability()`, MSI/INTx fallback must set `wx->num_q_vectors = 1`. `wx_set_vfta()` must verify `wx_set_vlvf() == 0` before writing `WX_PSR_VLAN_TBL` or `vft_shadow`. In `wx_tx_map()` rollback, check `if (tx_buffer == first) break;` before decrementing `i` (wrapping `i == 0` via `i += tx_ring->count`). [F41, F47, F84]

## External Contracts

- `wx_xmit_frame()` must pad via `skb_put_padto(skb, 17)` (returning `NETDEV_TX_OK` without freeing on error), and Tx BQL calls (`netdev_tx_sent_queue`, `completed_queue`, `reset_queue`) must stay balanced. In `wx_poll()`, return `budget` immediately if `budget <= 0` after Tx clean or if `!clean_complete`, and return `min(work_done, budget - 1)` after `napi_complete_done()`. [F105, F170, F171, F174]
- `wx_get_sset_count()`, `wx_get_strings()`, and `wx_get_ethtool_stats()` must match in count/order (`netdev->num_tx_queues` for both Tx and `WX_NUM_RX_QUEUES`). `wx_rcv_msg_from_vf()` must NACK non-reset commands when `!clear_to_send`, and VF MAC handlers must check `is_valid_ether_addr()` and `pf_set_mac`. [F88, F176]

## Known Pitfalls

- VF mailbox callers must mask off `WX_VT_MSGTYPE_CTS` from `msgbuf[0]` before checking `ACK`/`NACK`. After `list_for_each()` in `wx_set_vf_macvlan()`, check `!entry || !entry->free`. In `wx_get_ethtool_stats()`, advance `i += 2` only after the `u64_stats_fetch_retry()` loop. [F66, F98, F102]
- Cast high 32-bit register reads to `u64` before `<< 32`, bracket `WX_TSC_1588_SYSTIML` with two `SYSTIMH` reads in `wx_ptp_readtime()`, widen ns values to `u64` with `div_u64`/`div_u64_rem` in PTP math, and use `time_is_before_jiffies()` / `time_after()` for `jiffies`. Use `1ULL << pool` for `mac_table[i].pools`, guard `budget / q_vector->rx.count` with `rx.count > 1` and `max(..., 1)` in `wx_poll()`, and pass `WX_RSS_KEY_SIZE` (40) rather than `sizeof(wx->rss_key)`. [F109, F110, F111, F114, F117, F118, F119]
