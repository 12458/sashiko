# NETWORKING [MPTCP] — net/mptcp

Manages subflow lifecycle and TCP ULP integration (`subflow.c`), socket option and diagnostic synchronization across parent `struct mptcp_sock` and subflows (`sockopt.c`), token hashing/lookup (`token.c`, `token_test.c`), and `MP_JOIN` SYN-cookie state (`syncookies.c`).

## Architecture & Data Flow

- Unlinking from `token_bucket` in `mptcp_token_accept()`, `mptcp_token_destroy_request()`, and `mptcp_token_destroy()` must use `hlist_nulls_del_init_rcu()` or `__sk_nulls_del_node_init_rcu()`. `mptcp_token_accept()` moves `req->token_node` (`req_chain`) to `msk` (`msk_chain`) without changing `bucket->chain_len`, making later `mptcp_token_destroy_request(req)` a no-op and leaving `chain_len` decrement to `mptcp_token_destroy(msk)`. Hashing `msk` in `mptcp_token_new_connect()` or `mptcp_token_accept()` pairs with `sock_prot_inuse_add(..., 1)`, and `mptcp_token_destroy()` calls `sock_prot_inuse_add(..., -1)` and resets `msk->token = 0`. [F172, F221, F257]
- Check `tcp_rsk(req)->is_mptcp` before dereferencing `mptcp_subflow_rsk(req)` in `subflow_syn_recv_sock()` and `subflow_ulp_clone()`. IPv4/IPv6 request-sock slabs in `mptcp_subflow_init()` and `subflow_ops_init()` allocate `sizeof(struct mptcp_subflow_request_sock)` starting with `struct tcp_request_sock`, requiring `sizeof(struct tcp_request_sock) == sizeof(struct tcp6_request_sock)`. In `subflow_check_req()` and `mptcp_subflow_init_cookie_req()`, reject dual `opt_mp_capable && opt_mp_join` packets before the `opt_mp_capable` branch. [F252, F276, F280]
- Save `icsk->icsk_af_ops` to `subflow->icsk_af_ops` before overwriting it in `subflow_ulp_init()` or `mptcpv6_handle_mapped()` (which first checks `icsk->icsk_af_ops == target`), and copy it in `subflow_ulp_clone()`. In `subflow_ulp_fallback()`, `mptcp_subflow_tcp_fallback()` and `mptcp_subflow_ops_undo_override()` must restore `sk_data_ready`, `sk_state_change`, `sk_write_space`, `sk_error_report`, `icsk_af_ops`, and `sk_prot`, and clear `icsk_ulp_ops`, `icsk_ulp_data`, and `tcp_sk(sk)->is_mptcp`. [F228, F229]
- In `mptcp_subflow_create_socket()`, `sf->sk` must inherit parent `msk` cgroup (`mptcp_attach_cgroup()`), upgraded netns ref (`sk_net_refcnt_upgrade()`), socket options (`mptcp_sockopt_sync_locked()`), and `SOCK_INODE` `i_ino`, `i_uid`, `i_gid`. In `mptcp_subflow_fail()`, `fail_tout = jiffies + TCP_RTO_MAX` must replace `0` with `1` before setting `subflow->fail_tout`. [F234, F273]
- In `get_mapping_status()`, setting `subflow->map_valid = 1` for a new mapping requires resetting `subflow->map_csum_len = 0` and `subflow->map_data_csum = csum_unfold(mpext->csum)` before `validate_data_csum()`. When `mpext->data_fin == 1` and `data_len > 1`, `subflow->map_data_len` stores `data_len - 1`, so `__mptcp_make_csum()` in `get_mapping_status()` and `validate_data_csum()` takes `subflow->map_data_len + subflow->map_data_fin`. When `!mpext->dsn64`, mask `data_fin_seq = mpext->data_seq + data_len - 1` with `GENMASK_ULL(31, 0)` before `mptcp_update_rcv_data_fin()`. [F230, F244, F245]
- `get_mapping_status()` must call `skb_ext_del(skb, SKB_EXT_MPTCP)` once it accepts or merges a mapping. For a pure `DATA_FIN` (`mpext->data_fin == 1 && data_len == 1`) while `subflow->map_valid` is set, delete `SKB_EXT_MPTCP` and return `MAPPING_OK` (not `MAPPING_DATA_FIN`). For a 0-length skb without a map (`!mpext || !mpext->use_map`) while `!subflow->map_valid`, call `sk_eat_skb(ssk, skb)` and return `MAPPING_EMPTY`. [F231, F256, F263]
- When `mptcp_subflow_get_map_offset(subflow) >= subflow->map_data_len` in `mptcp_subflow_data_available()` or `mptcp_subflow_discard_data()`, reset `subflow->map_valid = 0` (and `subflow->data_avail = false` in `mptcp_subflow_data_available()`). `mptcp_subflow_discard_data()` must include `TCPHDR_FIN` (`avail_len + fin`) when advancing `tcp_sk(ssk)->copied_seq` across an skb end. [F232, F262]
- `sockopt_seq_inc()` must preserve `(u32)sk->sk_state << 24u` via `sockopt_seq_reset()` while incrementing the low 24 bits; every setter calling it needs a handler in `sync_socket_options()`. In `mptcp_sol_socket_sync_intval()` and `sync_socket_options()`, syncing `ssk->sk_sndbuf` under `SOCK_SNDBUF_LOCK` must also set `mptcp_subflow_ctx(ssk)->cached_sndbuf = sk->sk_sndbuf`, and changing `ssk->sk_mark` requires `sk_dst_reset(ssk)`. [F222, F223, F224, F226]
- `mptcp_sockopt_sync_locked()` keeps `ssk->sk_rcvlowat = 0` and `tcp_sk(ssk)->notsent_lowat = UINT_MAX` on subflows; `subflow_data_ready()` compares `mptcp_data_avail(msk)` against `parent->sk_rcvlowat`. `mptcp_setsockopt_sol_tcp_congestion()` checks `ns_capable(sock_net(sk)->user_ns, CAP_NET_ADMIN)`, whereas `sync_socket_options()` calls `tcp_set_congestion_control(ssk, msk->ca_name, false, true)` without re-checking `current`. [F265, F313]

## Synchronization

- In `token.c`, serialize all `req_chain`, `msk_chain`, and `chain_len` mutations under `spin_lock_bh(&bucket->lock)`. `mptcp_token_new_connect()` and `mptcp_sk_clone_init()` must set `msk->token` with `WRITE_ONCE()` before `__sk_nulls_add_node_rcu`. RCU scans in `mptcp_token_exists()` and `mptcp_token_get_sock()` must retry if `get_nulls_value(pos) != (token & token_mask)`. `mptcp_token_get_sock()` and `mptcp_token_iter_next()` must take `refcount_inc_not_zero(&sk->sk_refcnt)` under `rcu_read_lock()` and revalidate `sock_net(sk)` (and `READ_ONCE(msk->token)`), calling `sock_put(sk)` and retrying on mismatch. [F186, F187, F188, F189]
- `subflow_init_req_cookie_join_save()` and `mptcp_token_join_cookie_init_state()` must hold `spin_lock_bh(&join_entry_locks[i])` across the entire check, `e->valid` update, `mptcp_token_get_sock()` lookup, and `join_entries[i]` copy. [F190]
- `mptcp_subflow_queue_clean()` must splice `queue->rskq_accept_head`/`tail` under `queue->rskq_lock` and `release_sock(listener_ssk)` before locking each child's `sk = subflow->conn` and calling `mptcp_cancel_work(sk)`, then re-lock `listener_ssk` and restore the queue. [F184]
- `__subflow_state_change()` must use `rcu_dereference(sk->sk_wq)` inside `rcu_read_lock()` covering `skwq_has_sleeper(wq)` and `wake_up_interruptible_all(&wq->wait)`. `mptcp_diag_fill_info()` must call `unlock_sock_fast(sk, slow)` before `mptcp_data_lock(sk)`. [F199, F293]
- In `sockopt.c`, helpers calling `sock_setsockopt(sk->sk_socket, ...)` or `ip_setsockopt(sk, ...)` on parent `sk` must do so before `lock_sock(sk)`. In `mptcp_getsockopt_tcpinfo()`, `mptcp_getsockopt_subflow_addrs()`, and `mptcp_getsockopt_full_info()`, `mptcp_for_each_subflow()` runs under `lock_sock(sk)` and any `copy_to_user()` error must call `release_sock(sk)` before returning `-EFAULT`. [F296, F298]

## Object Lifetimes

- In `subflow_syn_recv_sock()`, attaching a passive `MP_JOIN` child transfers `subflow_req->msk` to `ctx->conn` and must set `subflow_req->msk = NULL` to avoid double-put in `subflow_req_destructor()` or `dispose_child`. `mptcp_subflow_reset()` must hold `sock_hold(sk)` on `sk = subflow->conn` across `tcp_done(ssk)` and `mptcp_schedule_work(sk)` because `tcp_done(ssk)` drops `ctx->conn`. [F173, F178]
- Every `__mptcp_subflow_connect()` error path must call `mptcp_pm_close_subflow(msk)`; if `mptcp_subflow_create_socket()` succeeded, set `subflow->disposable = 1` (and unlink `subflow->node` + `sock_put(ssk)` if linked) before `sock_release(sf)`. Once grafted via `mptcp_sock_graft(ssk, sk->sk_socket)`, discard `sf` via `iput(SOCK_INODE(sf))`, not `sock_release(sf)`. [F179, F180]
- `icsk_ulp_data` (`struct mptcp_subflow_context`) is published/cleared with `rcu_assign_pointer()` and freed via `kfree_rcu(ctx, rcu)`. In `subflow_ulp_release()`, when `ctx->conn` is non-NULL, free `ctx` only if `ctx->disposable || list_empty(&ctx->node)`; otherwise schedule `MPTCP_WORK_CLOSE_SUBFLOW` on `ctx->conn` for `__mptcp_close_ssk()`. `mptcp_attach_cgroup()` must check `cgroup_id` inequality before `cgroup_sk_free(child_skcd)`, copy, and `cgroup_sk_clone(child_skcd)`. [F181, F183, F292]

## API Contracts

- In `subflow_syn_recv_sock()`'s `dispose_child`, set `tcp_rsk(req)->drop_req = true`, call `inet_csk_prepare_for_destroy_sock(child)` and `tcp_done(child)`, and return the non-NULL `child`. `subflow_ulp_init()` returns `-EOPNOTSUPP` if `!sk->sk_kern_sock`. `subflow_ulp_clone()` must pass its `gfp_t priority` argument to `subflow_create_ctx(newsk, priority)`. [F174, F294, F299]
- `mptcp_propagate_state()` must guard `msk->snd_una`, `msk->wnd_end`, and `subflow_set_remote_key()` with `if (mp_opt)`. `get_mapping_status()` must expand `mpext->data_seq` via `mptcp_expand_seq(READ_ONCE(msk->ack_seq), mpext->data_seq, mpext->dsn64)`. [F211, F269]
- `subflow_generate_hmac(key1, key2, nonce1, nonce2, hmac)` takes sender `(key1, nonce1)` then receiver `(key2, nonce2)`, requires a `SHA256_DIGEST_SIZE` (32B) buffer (not 20B `subflow->hmac`), serializes nonces with `put_unaligned_be32()`, and reads `thmac` with `get_unaligned_be64()`. On a SYN-cookie third ACK (`!th->syn`), `mptcp_join_entry_hash()` and `mptcp_subflow_init_cookie_req()` must use `TCP_SKB_CB(skb)->seq - 1`. [F215, F217, F248]
- `__mptcp_nmpc_sk(msk)` requires `lock_sock((struct sock *)msk)`, an `IS_ERR(ssk)` check, and no `sock_put(ssk)`. `mptcp_setsockopt()` must check `mptcp_supported_sockopt(level, optname)` on non-`SOL_SOCKET` options before `__mptcp_tcp_fallback(msk)`. Callers of `mptcp_get_subflow_data()` and `mptcp_get_full_info()` must store the return value in a signed `int` and check `< 0`. [F185, F201, F254]
- `token_hash` has `token_mask + 1` buckets (`0..token_mask`), and `mptcp_token_iter_next()` loops `slot <= token_mask` with 1-based `num` (skipping `num <= *s_num`). Token test exports use `#if IS_MODULE(CONFIG_MPTCP_KUNIT_TEST)`, and `build_msk()` in `token_test.c` must set `sk->sk_protocol = IPPROTO_MPTCP` and `sk->sk_prot`. [F249, F282, F304]

## Error Handling

- `subflow_token_join_request()` must call `sock_put((struct sock *)msk)` if `mptcp_pm_get_local_id() < 0`. `subflow_v4_route_req()` and `subflow_v6_route_req()` must call `dst_release(dst)` if `subflow_check_req()` fails. Always call `subflow_init_req()` on new/cookie `struct mptcp_subflow_request_sock` (allocated from `SLAB_TYPESAFE_BY_RCU` without `__GFP_ZERO`) before any error path. [F175, F177, F213]
- In `__mptcp_subflow_connect()`, `-EINPROGRESS` from `kernel_connect()` is success and the function must return `0`. Check `sk_is_mptcp(ssk)`, `ctx`, and `ctx->conn` in `mptcp_subflow_queue_clean()`, `mptcp_subflow_drop_ctx()`, and `subflow_ulp_release()`, and check `sk->sk_socket` for NULL in `mptcp_subflow_create_socket()` and `subflow_error_report()`. [F203, F207, F209]
- Check `mpext = mptcp_get_ext(skb)` and `mpext->use_map` in `get_mapping_status()`; in `subflow_add_reset_reason()`, NULL-check `skb_ext_add()` and `memset(mpext, 0, sizeof(*mpext))`. In `mptcp_setsockopt_sol_tcp_congestion()`, require `optlen >= 1`, bound `strncpy_from_sockptr()` to `min_t(long, TCP_CA_NAME_MAX - 1, optlen)`, and set `name[ret] = 0`. Log peer wire errors via `MPTCP_INC_STATS` / `SUBFLOW_REQ_INC_STATS` and `pr_debug`, never `WARN_ON*` or unratelimited `pr_warn`/`pr_err`. [F210, F243, F315]

## External Contracts

- Zero-init `mptcp_info`, `mptcp_subflow_addrs`, and `mptcp_subflow_info` with `memset()` before early returns or conditional writes in `mptcp_diag_fill_info()`, `mptcp_get_sub_addrs()`, and `mptcp_getsockopt_full_info()`. `mptcp_getsockopt_info()` must return `0` immediately when `*optlen == 0`. [F214, F241]
- `mptcp_get_subflow_data()` and `mptcp_get_full_info()` must return `-EINVAL` if user `u32` sizes exceed `INT_MAX` or if output fields (`num_subflows`, `size_kernel`, `size_tcpinfo_kernel`, `size_sfinfo_kernel`) are non-zero; `mptcp_get_full_info()` requires `*optlen >= MIN_FULL_INFO_OPTLEN_SIZE` (40) and copies only 40 bytes. [F239, F310]
- Subflow entries in `mptcp_getsockopt_tcpinfo()` and `mptcp_getsockopt_subflow_addrs()` start at `optval + sfd.size_subflow_data`, and `mptcp_put_subflow_data()` sets `*optlen` to `sfd->size_subflow_data + copied` (or `min(sfd->size_subflow_data, sizeof(*sfd))` if `copied == 0`). `mptcp_getsockopt_full_info()` must count all subflows in `sfcount` (`mfi.num_subflows`) while only copying when `sfcount < mfi.size_arrays_user` and advancing pointers by clamped `mfi.size_sfinfo_user` / `mfi.size_tcpinfo_user`. [F238, F240]
- `mptcp_getsockopt_sol_tcp()` must divide `sysctl_tcp_keepalive_time` and `sysctl_tcp_keepalive_intvl` by `HZ` when `msk->keepalive_idle` or `msk->keepalive_intvl` is 0. `mptcp_put_int_option()` writes a single `unsigned char` with `*optlen = 1` when `0 < *optlen < sizeof(int)` and `0 <= val <= 255`. [F219, F242]

## Known Pitfalls

- In `validate_mapping()`, `subflow_check_data_avail()`, `skb_is_fully_mapped()`, and `mptcp_subflow_discard_data()`, compare 32-bit sequences with `before()`, compare 64-bit DSNs with `before64(ack_seq, old_ack)` and clamp `old_ack - ack_seq` to `avail_len` before narrowing to `u32`, and check `tp->copied_seq - TCP_SKB_CB(skb)->seq` against `skb->len` before subtracting. In `validate_data_csum()`, check `skb_queue_is_last(&ssk->sk_receive_queue, skb)` before `skb = skb->next`. [F246, F258, F271, F272]
- Pass `ssk->sk_family` (not `sk->sk_family`) to `mptcp_info2sockaddr()` in `__mptcp_subflow_connect()`. In `mptcp_set_rcvlowat()`, reject `sk->sk_protocol == IPPROTO_TCP` before calling `mptcp_sk(sk)` or MPTCP helpers. [F266, F275]
- In `mptcp_setsockopt_sol_tcp()`, handle non-int options (`TCP_CONGESTION`, `TCP_FASTOPEN_KEY`) and `mptcp_setsockopt_first_sf_only()` callers in the first switch before `lock_sock(sk)`. Pre-connect options apply to `ssk` first and mirror to `sk` in `mptcp_setsockopt_sol_socket()` / `mptcp_setsockopt_v6()`, but apply to `sk` first and mirror to `ssk` in `mptcp_setsockopt_sol_ip_set()`. [F255, F264]
