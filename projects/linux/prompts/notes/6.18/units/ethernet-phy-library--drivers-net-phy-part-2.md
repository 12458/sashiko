# ETHERNET PHY LIBRARY — drivers/net/phy (part 2)

Implements the core MDIO bus and device subsystem (`mdio_bus.c`, `mdio_bus_provider.c`, `mdio_device.c`, `mdio_devres.c`), Ethernet PHY drivers for Marvell (`marvell.c`), Micrel/Microchip (`micrel.c`, `microchip.c`), and Meson GXL (`meson-gxl.c`), and the Microchip RDS PTP library (`microchip_rds_ptp.c`).

## Architecture & Data Flow
- In `__mdiobus_register()`, `mdiobus_scan_bus_c22()` runs before `mdiobus_scan_bus_c45()`; `mdiobus_scan_bus_c45()` must be skipped if `mdiobus_prevent_c45_scan()` finds any C22 PHY with `MICREL_OUI` and must skip occupied `bus->mdio_map[i]` slots. `mdiobus_find_device()` (and `mdiobus_get_phy()`, `mdiobus_is_registered_device()`) must verify `0 <= addr < ARRAY_SIZE(bus->mdio_map)`. [F413, F425]
- `mdio_device_reset()` short-circuits when `mdiodev->reset_state == value` and updates `reset_state = value` after toggling `reset_gpio` and `reset_ctrl`, relying on `mdio_device_create()` initializing `reset_state = -1`. [F394]
- `mdio_bus_get_stat()` passes `(const char *)s + offset` as `const u64_stats_t *` to `u64_stats_read()`, so `mdio_bus_stat_attr::field_offset` (`MDIO_BUS_STATS_ATTR_DECL`, `MDIO_BUS_STATS_ADDR_ATTR_DECL`) must be `offsetof` a `u64_stats_t` field in `struct mdio_bus_stats`. [F447]
- In `marvell.c`, `m88e1111_config_aneg()`, `m88e1510_config_aneg()`, `marvell_suspend()`, and `marvell_resume()` must restore `MII_MARVELL_COPPER_PAGE` via `marvell_set_page()` on all exits (including `error:` paths without overwriting `err`), while `marvell_read_status()` stays on `MII_MARVELL_FIBER_PAGE` if fiber `phydev->link` is up (and restores copper page on error without overwriting `err`). When `phydev->interface == PHY_INTERFACE_MODE_SGMII`, none of them may access `MII_MARVELL_FIBER_PAGE`. [F355, F384, F430]
- When `m88e1111_config_init()` sets `PHY_INTERFACE_MODE_SGMII` and resets the PHY, it must re-read `genphy_read_abilities(phydev)` and OR `phydev->supported` into `phydev->advertising`. In `marvell_config_aneg()` and `m88e1121_config_aneg()`, `changed` must accumulate positive returns from `marvell_set_polarity()` (and `m88e1121_config_aneg_rgmii_delays()`), and `genphy_soft_reset(phydev)` must run after `genphy_config_aneg(phydev)` if `phydev->autoneg != AUTONEG_ENABLE || changed`. [F398, F429]
- In `marvell_of_reg_init()`, byte `len` from `of_get_property("marvell,reg-init")` must be checked against `4 * sizeof(*paddr)` and divided by `sizeof(*paddr)` before the `i < len - 3; i += 4` loop. In `marvell_hw_stats`, fiber entries must be at the end matching `NB_FIBER_STATS`, and `ARRAY_SIZE` of `marvell_hw_stats` and `marvell_hw_stats_simple` must not exceed `NB_STAT_MAX`. [F450, F451]
- In `micrel.c`, any `kszphy_type` using `ksz886x_cable_test_get_status()` must populate `.cable_diag_reg` and `.pair_mask`. `ksz9x31_cable_test_start()` caches `CTL1000_ENABLE_MASTER | CTL1000_AS_MASTER` of `MII_CTRL1000` in `priv->vct_ctrl1000` and `ksz9x31_cable_test_get_status()` restores it when `*finished = true`. In both `*_cable_test_get_status()` functions, if testing a pair in `for_each_set_bit(pair, &pair_mask, 4)` returns `-EAGAIN`, `continue` without clearing `pair` in `pair_mask`. [F401, F402, F435]
- `ksz9131_mdix_update()` and `ksz9477_mdix_update()` must never overwrite `phydev->mdix_ctrl`, and must copy `phydev->mdix_ctrl` to `phydev->mdix` when `!= ETH_TP_MDI_AUTO`. `kszphy_get_sqi()` must map `avg_raw_sqi >= ARRAY_SIZE(ksz_sqi_mapping)` to `0` before indexing `ksz_sqi_mapping`. `ksz8051_match_phy_device()` and `ksz8795_match_phy_device()` must read `MII_BMSR` and test `BMSR_ERCAP` to distinguish KSZ8051 PHY from KSZ87xx switches. [F403, F419, F468]
- Exiting `BMCR_PDOWN` resets KSZ PHYs, so `ksz8061_config_init()`, `ksz8061_resume()`, `ksz9477_resume()`, and `kszphy_resume()` must wait `usleep_range(1000, 2000)` before writing errata/config registers and calling `phydev->drv->config_intr()`. `ksz9477_phy_errata()` runs only when `(phydev->phy_id & 0xf) == 1`, sets `MII_BMCR` to `BMCR_SPEED100 | BMCR_FULLDPLX` before `ksz9477_errata_writes[]`, and calls `genphy_restart_aneg()` after. [F475, F476]
- In `lan8842_probe()` and `lan8842_handle_interrupt()`, check `priv->rev` against `LAN8842_REV_8832`: when `!= LAN8842_REV_8832`, `lan8842_probe()` must call `devm_phy_package_join()` (`sizeof(struct lan8814_shared_priv)`) and `lan8842_ptp_probe_once()` before `lan8814_ptp_init()`, while `LAN8842_REV_8832` skips package join, PTP init, and PTP/GPIO IRQ polling. In `lan8842_config_init()`, hardware LED blinking requires clearing `LAN8814_LED_CTRL_1_KSZ9031_LED_MODE_` and setting `LAN8814_LED_CTRL_2_LED1_COM_DIS` on `LAN8814_PAGE_PORT_REGS` alongside clearing `LAN8814_GPIO_EN2` on `LAN8814_PAGE_COMMON_REGS`. [F406, F467, F473]
- On LAN8841, `lan8841_ptp_perout()` and `lan8841_ptp_extts()` must check `0 <= pin < LAN8841_PTP_GPIO_NUM` (10), and `lan8841_ptp_enable_event()` / `lan8841_ptp_remove_event()` route pins `0..4` to `LAN8841_GPIO_DATA_SEL1` (`3 * pin`) and `5..9` to `LAN8841_GPIO_DATA_SEL2` (`3 * (pin - 5)`). On LAN8814/LAN8842, `lan8814_ptpci_verify()`, `lan8814_ptp_perout()`, and `lan8814_ptp_extts()` restrict `PTP_PF_PEROUT` to pins `0..1` with `pin == chan` and `PTP_PF_EXTTS` to pin `3`. In `microchip_rds_ptp.c`, `clock->mchp_rds_ptp_event` is initialized to `-1`, set to `pin` in `mchp_get_event()`, and reset to `-1` in `mchp_rds_ptp_perout_off()`. [F411, F421, F422]
- In `lan88xx_link_change_notify()`, both parallel-detection reinit (`phy_init_hw()`, `_phy_start_aneg()`) and the forced-100Mbps workaround (`!phydev->autoneg && phydev->speed == 100`) must be gated on `phydev->state == PHY_NOLINK`. [F423]

## Synchronization
- Locked MDIO accessors (`mdiobus_read/write/modify*`) acquire sleeping mutex `bus->mdio_lock` and unlocked accessors (`__mdiobus_*`) require `bus->mdio_lock` held; neither may run in atomic/IRQ context, and nested bus accesses must use `mdiobus_*_nested()` (`MDIO_MUTEX_NESTED`). In `mdiobus_stats_acct()`, `mdio_bus_stats` updates must disable preemption and use `u64_stats_update_begin/end(&stats->syncp)` under `bus->mdio_lock`, paired with `u64_stats_fetch_begin/retry()` in `mdio_bus_get_stat()`. [F362, F363, F481, F482]
- In `micrel.c`, `lanphy_read/write/modify_page_reg()` must hold `phy_lock_mdio_bus()` across the full `LAN_EXT_PAGE_ACCESS_*` sequence using `__phy_*` helpers. Shared PTP/GPIO accesses on `LAN8814_PAGE_COMMON_REGS` (`lan8814_ptpci_*`, `lan8814_ptp_perout/extts`, `lan8814_handle_gpio_interrupt`) must hold `shared->shared_lock` outside `mdio_lock`. [F367, F486]
- In `mchp_rds_ptp_ltc_adjtime()` and `lan8841_ptp_adjtime()`, unlock `ptp_lock` before calling `gettime64()` / `settime64()` and re-lock before updating registers. On LAN8841, `ptp_priv->seconds` accesses must hold `spin_lock_irqsave(&ptp_priv->seconds_lock, flags)` with `ptp_lock` released first, and `lan8841_ptp_enable_processing(false)` / `lan8841_suspend()` must call `ptp_cancel_worker_sync(ptp_priv->ptp_clock)` without holding `ptp_lock`. [F368, F370, F492]
- In `microchip_rds_ptp.c` and `micrel.c`, `txtstamp`/`rxtstamp` hooks run in atomic network context without MDIO I/O and synchronize with threaded IRQ handlers via `spin_lock_irqsave()` on `tx_queue.lock`, `rx_queue.lock`, and `rx_ts_lock`; `*_match_tx_skb()` and `*_match_skb()` must hold the queue spinlock while walking and calling `__skb_unlink()`, and release it before `skb_complete_tx_timestamp()` or `netif_rx()`. [F369, F490]

## Object Lifetimes
- `mdiobus_alloc_size()` allocates `mii_bus` and `bus->priv` in one block, sets `bus->state = MDIOBUS_ALLOCATED`, and initializes `bus->irq[] = PHY_POLL` and `bus->stats[].syncp`, so `mdiobus_release()` / `mdiobus_free()` must only `kfree(bus)`. `__mdiobus_register()` calls `fwnode_handle_get()` only when `state == MDIOBUS_ALLOCATED`, and `mdiobus_release()` calls `fwnode_handle_put()` only when `state == MDIOBUS_RELEASED`. [F348, F385, F446]
- `__mdiobus_register()` must init `mdio_lock` and `shared_lock` and cycle `bus->reset_gpiod` (assert, `reset_delay_us`, deassert, `reset_post_delay_us`) before `bus->reset()` and scanning; its error rollback and `mdiobus_unregister()` must call `device_remove()` then `device_free()` on every `bus->mdio_map[]` entry, assert `bus->reset_gpiod`, and call `device_del(&bus->dev)`. [F349, F365, F459]
- `mdiobus_register_gpiod/reset()` must use non-devres `gpiod_get_optional()` and `reset_control_get_optional_exclusive()`. In `mdio_device_remove()`, `device_del(&mdiodev->dev)` must precede `mdiobus_unregister_device(mdiodev)` (which releases `reset_gpio`/`reset_ctrl` and clears `bus->mdio_map[addr] = NULL`) so `mdio_remove()` can assert reset first, and callers must then call `mdio_device_free(mdiodev)`. [F346, F351, F364, F456]
- In `of_mdiobus_find_phy()`, when `child` matches `mdiodev->addr`, `device_set_node(dev, of_fwnode_handle(child))` takes ownership of `child` (dropped in `mdio_device_release()`), so do not call `of_node_put(child)` on that path (unlike the `ethernet-phy-package` early return). `mdio_find_bus()` and `of_mdio_find_bus()` increment `bus->dev` refcount; callers must call `put_device(&bus->dev)`. [F350, F462]
- `mchp_rds_ptp_txtstamp()` and `lan8814_txtstamp()` take ownership of `skb` and must either `kfree_skb(skb)` (including `HWTSTAMP_TX_ONESTEP_SYNC` when `ptp_msg_is_sync()`) or fall through to `HWTSTAMP_TX_ON` to set `SKBTX_IN_PROGRESS` and queue onto `tx_queue`. Allocated `rx_ts` nodes must either be freed via `kfree(rx_ts)` on immediate `rx_queue` match or added to `rx_ts_list` under `rx_ts_lock` to be unlinked and freed on SKB match or in `.hwtstamp`. [F357, F358, F434]
- `kszphy_probe()` must call `clk_disable_unprepare()` after `devm_clk_get_optional_enabled()` so `priv->clk` starts disabled, and `kszphy_generic_suspend/resume()` must balance `kszphy_disable_clk()` / `kszphy_enable_clk()` only when `genphy_suspend()` succeeds. [F474]

## API Contracts
- `mdio_bus.c` and `mdio_device.c` (`CONFIG_MDIO_BUS`) must not call `libphy` symbols (`get_phy_device()`, `phy_device_register()`, `phy_device_free()`) without `CONFIG_PHYLIB` guards. `__devm_mdiobus_register()` and `__devm_of_mdiobus_register()` require `mii_bus` allocated for the same `dev` via `devm_mdiobus_alloc_size()`. `__mdiobus_register()` requires `bus`, `bus->name`, paired `read`/`write` and `read_c45`/`write_c45`, and at least one read callback. [F353, F379, F495]
- `__mdiobus_read/write/c45_read/c45_write()` must reject `addr >= PHY_MAX_ADDR` with `-ENXIO`. `__mdiobus_modify_changed()`, `__mdiobus_c45_modify_changed()`, and `lanphy_modify_page_reg()` return `< 0` on error, `0` if unchanged, and `1` if modified, and because `__mdiobus_*_modify_changed()` compute `(ret & ~mask) | set` without masking `set`, shifted variable inputs must be clamped/masked first. [F374, F412, F445]
- `mdio_device_reset()` and `mchp_rds_ptp_handle_interrupt()` (plus `handle_interrupt` in `micrel.c` and `marvell.c`) sleep and must only run in process or threaded IRQ context. `phy_driver` entries relying on `phy_init_hw()` or soft reset in `config_init` (`lan88xx`, `ksz9031`, `ksz8061`) must populate `.soft_reset`. [F484, F491, F497]
- In `marvell.c`, modifying `MII_88E1510_GEN_CTRL_REG_1_MODE_MASK` requires setting `MII_88E1510_GEN_CTRL_REG_1_RESET` immediately after. `m88e1111/1011_set_downshift()` take 1-based `cnt` (`0` to disable, `1..8` encoded as `cnt - 1`, `> 8` returning `-E2BIG`) and `*_get_downshift()` add `1` when enabled. Drivers using `marvell_probe()` must only store `struct marvell_hwmon_ops *` or `NULL` in `driver_data` (reporting millidegrees Celsius). Cable test helpers must report fault lengths (only on faulted pairs) and TDR steps in cm (`marvell_vct5_cable_test_tdr_start()` converts via `marvell_vct5_cm2distance()` and rejects `> MII_VCT5_SAMPLE_POINT_DISTANCE_MAX` with `-EINVAL`) and amplitudes in mV. [F392, F397, F418, F452, F502, F503]
- `lanphy_read/write/modify_page_reg()` require the matching page constant (`LAN8814_PAGE_PORT_REGS` vs `LAN8814_PAGE_COMMON_REGS`), and `mchp_rds_phy_*_mmd()` require the matching `enum mchp_rds_ptp_base` (`MCHP_RDS_PTP_PORT` vs `MCHP_RDS_PTP_CLOCK`). `lan8841_ptp_remove/enable_event()` take `(ptp_priv, pin, event, ...)`. `lan8814_get_sig_rx()` must balance `skb_push(skb, ETH_HLEN)` before `ptp_classify_raw()` with `skb_pull_inline(skb, ETH_HLEN)` after. `mchp_rds_ptp_probe()` returns `ERR_PTR` on error, `NULL` when disabled, or valid pointer. `meson_gxl_read/write_reg()` must bracket bank access with `meson_gxl_open_banks()` and `meson_gxl_close_banks()`. [F376, F388, F390, F391, F469, F499]

## Error Handling
- `mdiobus_scan_bus_c22/c45()` must ignore `-ENODEV` from `mdiobus_scan*()` and only fail on `IS_ERR(phydev) && PTR_ERR(phydev) != -ENODEV`. `mdiobus_register_reset()` and `__mdiobus_register()` must check `IS_ERR()` on local variables before assigning `mdiodev->reset_ctrl` or `bus->reset_gpiod`. [F375, F382]
- In `micrel.c`, check `ptp_priv->ptp_clock != NULL` before calling `ptp_cancel_worker_sync()` or `ptp_clock_index()`. In `__lan8814_ptp_probe_once()` and `mchp_rds_ptp_probe()`, `memset()` each `struct ptp_pin_desc` from `devm_kmalloc_array()` to 0. `m88e1540_set_fld()` must reject enabling FLD with `-EBUSY` (`phydev_warn()`) when `eee_enabled` is set, and `lan8814/8841_ptp_perout()` must use `pr_warn_ratelimited()` for invalid user timings. [F380, F387, F509, F510]

## External Contracts
- `mdio_bus_match()` must verify `MDIO_DEVICE_IS_PHY` matches `MDIO_DEVICE_FLAG_PHY` before DT or `bus_match` checks, and every PHY ID in a driver array must appear in its `MODULE_DEVICE_TABLE(mdio, ...)` table. `lan8841_rxtstamp()` must decode `ptp_header->reserved2` with `__be32_to_cpu()` (2-bit seconds in `[31:30]`, ns in `[29:0]`) and zero `reserved2` before `netif_rx()`. [F420, F449, F464]

## Known Pitfalls
- In `marvell.c`, `marvell_vct7_cable_test_start()` and `marvell_vct5_cable_test_tdr_start()` must update `priv->cable_test_tdr` and reset the opposite VCT engine's registers. `m88e1510_resume()` must toggle downshift to `0` and back to saved `cnt` after `marvell_resume()`. `marvell_hwmon_name()` allocates `strlen(devname)` bytes without `+ 1`, relying on `isalnum()` stripping at least one char. `m88e3082/1111_vct_distrfln_2_cm()` and `ksz9x31_cable_test_fault_length()` must clamp raw values before subtracting calibration offsets. [F399, F400, F443, F453]
- `ksz8081/886x_config_aneg()` must call `*_config_mdix()` after `genphy_config_aneg()`. `ksz8041_suspend/resume()` must only toggle `priv->clk` without `genphy_suspend/resume()` (errata DS80000700A). Per-port suspend on LAN8814/LAN8842 must never reassert the shared `coma-mode` GPIO deasserted by `lan8814_release_coma_mode()`. `microchip_phy_driver` (`0x0007c132`) must omit `.config_intr`/`.handle_interrupt`, `lan88xx_suspend()` must skip `genphy_suspend()` when `priv->wolopts` is set, and `meson_gxl_read_status()` must return `genphy_restart_aneg()` immediately on corrupted `MII_LPA`. [F404, F405, F428, F466, F477, F478]
- In `mchp_rds_ptp_match_skb/tx_skb()` and `lan8814_match_skb/tx_skb()`, only dereference `skb` after unlocking if boolean `rc`/`ret` is `true`; in `mchp_rds_ptp_match_rx_skb()`, save the match in `rx_ts_var` rather than testing loop cursor `rx_ts`. For 48-bit PTP/stat registers (`lan8814`, `lan8841`, `lan8842`, `mchp_rds_ptp`), accumulate reads in a 64-bit variable shifting by 16 (`<<= 16`), write `upper_16_bits(sec)` to `*_SEC_MID` and `upper_32_bits(sec)` to `*_SEC_HI`, and split `scaled_ppm` multiplication in `*_adjfine()` into `upper_16_bits` and `lower_16_bits` to avoid 32-bit overflow. [F432, F433, F437, F438, F439]
