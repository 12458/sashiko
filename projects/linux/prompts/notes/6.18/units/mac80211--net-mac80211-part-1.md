# MAC80211 — net/mac80211 (part 1)

Implements `cfg80211` ops (`mac80211_config_ops`), channel contexts (`chan.c`), driver-op wrappers (`driver-ops.*`), EHT parsing (`eht.c`), ethtool (`ethtool.c`), and debugfs.

## Architecture & Data Flow
- `NL80211_IFTYPE_AP_VLAN` is never added to the driver (`drv_add_interface()` rejects it), so `drv_sta_*`, `drv_set_key`, `drv_ampdu_action`, `drv_flush*`, and `drv_net_*` must call `get_bss_sdata(sdata)` before `check_sdata_in_driver(sdata)` and `local->ops`. Updating an AP link's `link->conf->chanreq` requires `ieee80211_link_update_chanreq()` so `vlan_conf->chanreq` on `sdata->u.ap.vlans` stays in sync. [F45, F55]
- Replacement channel contexts (`IEEE80211_CHANCTX_REPLACES_OTHER`) are on `local->chanctx_list` before reaching the driver: `ctx->driver_present` must stay synced across `drv_add_chanctx()`, `drv_remove_chanctx()`, and `drv_switch_vif_chanctx()` (`CHANCTX_SWMODE_SWAP_CONTEXTS`), and `ieee80211_iter_chan_contexts_*()`, `_ieee80211_recalc_chanctx_min_def()`, and `drv_change_chanctx()` must gate on `ctx->driver_present`. Freeing either peer in `ieee80211_link_unreserve_chanctx()` or `ieee80211_vif_use_reserved_switch()` must reset the survivor's `replace_ctx = NULL` and `replace_state = IEEE80211_CHANCTX_REPLACE_NONE`, and loops over `ctx->reserved_links` unlinking `link->reserved_chanctx_list` must use `list_for_each_entry_safe()`. [F69, F73, F98, F135]
- In `ieee80211_recalc_chanctx_min_def()`, `_ieee80211_change_chanctx()`, and `ieee80211_vif_use_reserved_switch()`, call `ieee80211_chan_bw_change()` with `narrowed == true` before the driver update and `false` after; in `ieee80211_recalc_chanctx_chantype()`, filter `WLAN_STA_TDLS_WIDER_BW` peers by `rcu_access_pointer(link->conf->chanctx_conf) == conf`. During `local->in_reconfig`, `_ieee80211_link_use_channel()` skips releasing the channel, `ieee80211_assign_link_chanctx()` skips unassigning `curr_ctx` and adding `assigned_chanctx_list`, and `drv_wake_tx_queue()` sets `IEEE80211_TXQ_DIRTY`. [F66, F70, F97]
- When populating `cfg80211_mbssid_elems` or `cfg80211_rnr_elems` (`ieee80211_copy_mbssid_beacon()`, `ieee80211_copy_rnr_beacon()`), set `dst->cnt` before accessing `dst->elem[]` (`__counted_by(cnt)`). In `ieee80211_assign_beacon()`, read `link_conf->bssid_indicator` from `new->mbssid_ies->elem[0].data[2]` (if `len > 2`, else `0`), copy `tx_bss_conf->bssid_indicator` to non-TX BSSes in `ieee80211_set_ap_mbssid_options()`, and in `ieee80211_csa_finish` / `ieee80211_color_change_bss_config_notify` on a TX MBSSID link (`tx_bss_conf == link->conf`), propagate to all links with `conf->tx_bss_conf == link->conf`. [F56, F57, F74]
- In `sta_link_apply_parameters()`, apply capabilities in order HT -> VHT -> HE -> EHT (requiring `params->he_capa && params->eht_capa`) -> S1G, then `ieee80211_sta_init_nss()` and `__ieee80211_vht_handle_opmode()`. In `ieee80211_eht_cap_ie_to_sta_eht_cap()`, verify `eht_cap_len >= eht_total_size + sizeof(u16)` before reading `eht_ppe_hdr`, bound `eht_ppe_size` to `sizeof(eht_cap->eht_ppe_thres)`, and only parse `IEEE80211_EHT_MAC_CAP0_MAX_MPDU_LEN_MASK` on `NL80211_BAND_2GHZ`. [F76, F90, F94]
- Moving an authorized station to a VLAN (`sta->sdata = vlansdata`) in `ieee80211_change_station()` requires `ieee80211_vif_dec_num_mcast()` on old `sdata` before and `ieee80211_vif_inc_num_mcast()`, `ieee80211_check_fast_rx()`, and `ieee80211_check_fast_xmit()` after. `ieee80211_del_link_station()` must return `-EINVAL` if `sta->sta.valid_links == BIT(params->link_id)` or `!(sta->sta.valid_links & BIT(params->link_id))`. [F63, F108]
- `ieee80211_scan()`, `ieee80211_is_scan_ongoing()`, and `ieee80211_is_radar_required()` must map channels via `cfg80211_get_radio_idx_by_chan()` and check `ieee80211_is_radio_idx_in_scan_req()`, and `ieee80211_set_wiphy_params()` may only index `wiphy->radio_cfg[radio_idx]` when `radio_idx != -1 && radio_idx < wiphy->n_radio`. [F64, F83]
- In `ieee80211_set_mon_options()`, changing `MONITOR_FLAG_ACTIVE` while running returns `-EBUSY`, and updating `sdata->u.mntr.flags` while running requires `ieee80211_adjust_monitor_flags(sdata, -1)` before and `(+1)` + `ieee80211_configure_filter(local)` after. `ieee80211_cfg_get_channel()` and `ieee80211_get_stats()` must check `local->open_count == local->virt_monitors` (not `monitors`) for `local->monitor_chanreq.oper`. [F65, F91]
- In `ethtool.c`, `ieee80211_get_stats` and `ieee80211_get_strings` reserve `STA_STATS_LEN` entries before passing `&data[STA_STATS_LEN]` / `&data[sz_sta_stats]` to `drv_get_et_*` (`i == STA_STATS_LEN`), and the `drv_get_survey()` loop must reset `survey.filled = 0` before each call and on error before `break`. Debugfs writers (`aql_txq_limit_write`, `sta_aql_write`, `sta_agg_status_do_write`) must check `ac < IEEE80211_NUM_ACS` / `tid < IEEE80211_NUM_TIDS`. [F87, F106, F126]

## Synchronization
- Populate RCU-protected pointers on `link->u.ap` (`beacon`, `probe_resp`, `fils_discovery`, `unsol_bcast_probe_resp`, `s1g_short_beacon`) and `sdata->qos_map` before `rcu_assign_pointer` (or `RCU_INIT_POINTER`) and free old objects via `kfree_rcu`. [F26]
- `ieee80211_csa_finish`, `ieee80211_color_change_finish`, and `ieee80211_obss_color_collision_notify` must hold `rcu_read_lock()` across `rcu_dereference(sdata->link[link_id])` and `for_each_sdata_link_rcu()` until `wiphy_work_queue` / `wiphy_delayed_work_queue` finishes; `ieee80211_csa_finalize_work` and `ieee80211_color_change_finalize_work` must recheck `csa_active` / `color_change_active` and `ieee80211_sdata_running(sdata)` under the wiphy lock. [F31, F32, F139]
- Protect `sdata->u.nan.function_inst_ids` with `spin_lock_bh(&sdata->u.nan.func_lock)` using 1-based IDs `[1, max_nan_de_entries]` (`0` = not found in `ieee80211_del_nan_func()`), and unlock `func_lock` before `drv_add_nan_func`, `drv_del_nan_func`, or `cfg80211_nan_*`. [F29, F82]
- Callers of `ieee80211_attach_ack_skb()` must hold `wiphy->mtx` for `ieee80211_mgmt_tx_cookie(local)` (which skips `0` on `roc_cookie_counter` wrap), while `local->ack_status_lock` (and `local->queue_stop_reason_lock` in `queues_read()`) uses `spin_lock_irqsave()`. In `ieee80211_probe_client()`, pass `GFP_ATOMIC` to `ieee80211_attach_ack_skb()` and wrap `ieee80211_xmit()` in `local_bh_disable()`/`enable()` under `rcu_read_lock()`. [F30, F118, F143, F144]
- `ieee80211_set_ringparam`, `ieee80211_get_ringparam`, `ieee80211_get_stats`, and `aql_txq_limit_write` must take `guard(wiphy)(local->hw.wiphy)` before accessing `local->sta_list`, `aql_txq_limit_*`, or `drv_*`. Debugfs ops (`ieee80211_if_read/write_sdata`, `ieee80211_if_read/write_link`, `sta_agg_status_read/write`) must use `wiphy_locked_debugfs_read/write()`, and AQM/airtime handlers (`ieee80211_get_txq_stats`, `aqm_read`, `ieee80211_if_fmt_aqm`, `sta_aqm_read`, `sta_airtime_read/write`, `sta_aql_read`) must hold `spin_lock_bh()` on `fq.lock` or `active_txq_lock[ac]` with `GFP_KERNEL` allocs and user copies outside. [F36, F37, F145, F154]
- `drv_start()` sets `local->started = true` and `smp_mb()` before `ops->start()`; `drv_stop()` calls `ops->stop()`, `tasklet_disable/enable(&local->tasklet)`, and `barrier()` before `local->started = false`. `drv_link_sta_rc_update()` and `drv_get_key_seq()` run under `rcu_read_lock()` and must not sleep. In `ieee80211_del_tx_ts`, after `tx_tspec->up = -1`, run `synchronize_net()` and `ieee80211_flush_queues()` before `ieee80211_sta_handle_tspec_ac_params()`; in `reset_write()`, take `rtnl_lock()` before `wiphy_lock()`, and `wiphy_unlock()` before `cfg80211_shutdown_all_interfaces()`. [F28, F127, F138, F155]

## Object Lifetimes
- `local->chanctx_list` is RCU-read by `ieee80211_iter_chan_contexts_atomic()`, requiring `list_add_rcu()` and `list_del_rcu()` + `kfree_rcu()`. If `ieee80211_link_unreserve_chanctx` drops `ieee80211_chanctx_refcount()` to 0 on a `REPLACES_OTHER` ctx, reset `ctx->replace_ctx` and free via `list_del_rcu` + `kfree_rcu` without `ieee80211_free_chanctx`. [F3, F147]
- In `ieee80211_link_use_reserved_reassign` and `assign`, unlink `link->reserved_chanctx_list` and clear `link->reserved_chanctx` before `drv_switch_vif_chanctx` or `ieee80211_assign_link_chanctx`, freeing `new_ctx` via `ieee80211_free_chanctx` if refcount is 0 on error. `ieee80211_find_chanctx` must temporarily reserve a matched ctx on `ctx->reserved_links` before `ieee80211_change_chanctx`, unreserving in `_ieee80211_link_use_channel` after `ieee80211_assign_link_chanctx`. [F5, F25]
- `ieee80211_stop_ap()` checks `ieee80211_num_beaconing_links(sdata) <= 1` before `RCU_INIT_POINTER(link->u.ap.beacon, NULL)`, subtracts `skb_queue_len(&sdata->u.ap.ps.bc_buf)` from `local->total_ps_buffered` before `ieee80211_purge_tx_queue()`, calls `synchronize_net()` between `ieee80211_remove_link_keys()` and `ieee80211_free_key_list()` if `!list_empty(&keys)`, and calls `ieee80211_link_copy_chanctx_to_vlans(link, true)` before `ieee80211_link_release_channel(link)`. On `drv_start_ap` failure in `ieee80211_start_ap()`, free `link->u.ap.beacon` via `kfree_rcu`, reset to `NULL`, clear `sdata->u.ap.active` if `ieee80211_num_beaconing_links(sdata) == 0`, and call `ieee80211_link_release_channel(link)`. [F11, F12, F18, F24, F102]
- In `__ieee80211_channel_switch`, abort active color change via `ieee80211_color_change_abort(link_data)` before `ieee80211_set_csa_beacon()`. `ieee80211_free_next_beacon()` must `kfree` separately allocated `mbssid_ies` and `rnr_ies` before `link->u.ap.next_beacon`, whereas `struct beacon_data` in `ieee80211_assign_beacon()` embeds them in one block freed by `kfree_rcu`. [F7, F59, F120]
- `ieee80211_add_nan_func` never frees `nan_func` (`ieee80211_nan_func_terminated` frees it via `cfg80211_free_nan_func`); `ieee80211_nan_conf_copy` frees old buffers in `dst` when `CFG80211_NAN_CONF_CHANGED_CONFIG` is set and calls `ieee80211_nan_conf_free(dst)` on error. `ieee80211_attach_ack_skb()` stores an `skb_copy()` in `local->ack_status_frames` and frees it if `idr_alloc()` fails. [F13, F14, F164]
- `ieee80211_link_debugfs_remove` and `ieee80211_link_sta_debugfs_remove` must not call `debugfs_remove_recursive` when `debugfs_dir` aliases the parent vif/sta `debugfs_dir`. `drv_add_interface()` sets `IEEE80211_SDATA_IN_DRIVER` and adds debugfs after `ops->add_interface()`; `drv_remove_interface()` clears `IEEE80211_SDATA_IN_DRIVER` and calls `ieee80211_debugfs_recreate_netdev()` before `ops->remove_interface()`; `drv_change_vif/sta_links` removes link debugfs before the op and adds new ones after when `!local->in_reconfig && !local->resuming`. In `ieee80211_del_intf_link`, do not modify `wdev->valid_links` before `ieee80211_vif_set_links()`. [F15, F16, F17, F131]

## API Contracts
- Never index `sdata->link[]` or `sta->link[]` with a negative `link_id`: use `ieee80211_link_or_deflink()` (returns `ERR_PTR`, never `NULL`; check `IS_ERR()`) or clamp `link_id < 0` to `0` (`sta_link_apply_parameters()`, `drv_mgd_prepare/complete_tx()`, `drv_mgd_protect_tdls_discover()`). Driver callbacks (`ieee80211_csa_finish()`, `ieee80211_color_change_finish()`, `ieee80211_obss_color_collision_notify()`) must check `link_id < IEEE80211_MLD_MAX_NUM_LINKS`, and per-link `cfg80211` ops must pass `link_id` (not `0`) to `cfg80211_*_notify()` / `cfg80211_cac_event()`. [F39, F51, F52, F80, F81]
- In `ieee80211_add_link_station`, free `ieee80211_sta_allocate_link()` via `ieee80211_sta_free_link()` if `sta_link_apply_parameters` fails, whereas `ieee80211_sta_activate_link` consumes and frees it on error. Defer `sta_apply_auth_flags()` until after `sta_link_apply_parameters()` for TDLS or `ASSOCIATED`; call `rate_control_rate_init_all_links()` / `rate_control_rate_init()` before `sta_info_move_state(sta, IEEE80211_STA_ASSOC)` or `ieee80211_sta_activate_link()`; and order `sta_apply_auth_flags()` upward `AUTH` -> `ASSOC` -> `AUTHORIZED` then downward in reverse. `drv_flush_sta()` and `drv_get_expected_throughput()` must check `sta->uploaded`. [F9, F47, F62, F92, F136]
- `ieee80211_set_tx_power()` rejects `mbm < 0 || (mbm % 100)` with `-EOPNOTSUPP`, converts via `MBM_TO_DBM(mbm)` (`INT_MIN` for automatic), and when `!ieee80211_hw_check(&local->hw, NO_VIRTUAL_MONITOR)` skips `NL80211_IFTYPE_MONITOR` in `local->interfaces` and (like `ieee80211_set_mon_options()`) only acts on `local->monitor_sdata` if `WANT_MONITOR_VIF`; `ieee80211_get_tx_power()` returns `-EINVAL` if `*dbm == INT_MIN`. [F53, F104, F128]
- `ieee80211_add_chanctx()` calls `ieee80211_idle_off()` + `ieee80211_hw_config()` before `drv_add_chanctx()` and `ieee80211_recalc_idle()` on error; `ieee80211_chanreq/chanctx_compatible` must copy into `*tmp` and return `tmp`. Validate `chanreq.oper.width` is 20–320 MHz before `__ieee80211_vht_handle_opmode()`, bound CSA `n_counter_offsets_*` to `IEEE80211_MAX_CNTDWN_COUNTERS_NUM`, and never pass `RX_QUEUED` to `kfree_skb_reason()`. [F44, F75, F78, F122, F134]

## Error Handling
- `ieee80211_set_probe_resp()` returns `< 0` on error, `0` when installed (`BSS_CHANGED_AP_PROBE_RESP`), and `1` when absent. `ieee80211_parse_bitrates()` returns count (`0` on failure -> `-EINVAL`). `ieee80211_find/alloc_chanctx()` return `NULL`, whereas `ieee80211_new/replace_chanctx()` return `ERR_PTR`. `ieee80211_link_use_reserved_context()` treats `-EAGAIN` from `ieee80211_vif_use_reserved_switch()` as non-fatal and only propagates other errors for `REPLACES_OTHER`. [F40, F41, F42, F43]
- Reject `active_links == 0` with `-EINVAL` before `ieee80211_set_active_links()`; convert `-EALREADY` from `ieee80211_key_link()` to `0` in `ieee80211_add_key()`; suppress `WARN_ONCE` in `check_sdata_in_driver()` when `local->reconfig_failure` is set; and gate `drv_conf_tx()` CW warning on `local->ops->conf_tx`. [F156, F159, F160, F174]

## External Contracts
- In `ieee80211_add_iface()`, never call `drv_prep_add_interface()` for `AP_VLAN`, and for `MONITOR` only when `WANT_MONITOR_VIF` and `MONITOR_FLAG_ACTIVE`. When `fips_enabled`, `drv_set_key()` returns `-EOPNOTSUPP`, `drv_set_rekey_data()` is a no-op, and `ieee80211_add_key()` rejects WEP/TKIP (`-EINVAL`). `key_tx_spec_write()` rejects `pn >= (1ULL << 48)` (`-ERANGE`), and `ieee80211_add_tx_ts()` stores `32 * admitted_time`. [F85, F161, F162, F167]

## Known Pitfalls
- `for_each_sdata_link*()` uses nested loops over `interfaces` and `link[]`, so `break` only exits the inner loop. `drv_assign/unassign_vif_chanctx()` must return early before `check_sdata_in_driver(sdata)` when `MONITOR && local->emulate_chanctx && !WANT_MONITOR_VIF`. In `ieee80211_get_stats`, multiply `cfg80211_calculate_bitrate()` by `100000ULL` and cast `sinfo.signal_avg` and `survey.noise` (`s8`) to `u8`; in `mpath_set_pinfo`, guard `mpath->exp_time - jiffies` with `time_before(jiffies, mpath->exp_time)`. [F100, F110, F111, F117, F129]
