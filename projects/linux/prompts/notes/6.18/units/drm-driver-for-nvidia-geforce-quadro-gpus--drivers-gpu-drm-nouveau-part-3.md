# DRM DRIVER FOR NVIDIA GEFORCE/QUADRO GPUS — drivers/gpu/drm/nouveau (part 3)

This unit implements upper-layer DRM/GEM/TTM memory management, GPU virtual address space management (`nouveau_uvmm`), DRM GPU scheduler integration (`nouveau_sched`), Shared Virtual Memory (`nouveau_svm`), hardware fence backends (`nv04`–`nvc0`), hwmon/LED/VGA/PRIME integration, and the `nvif` client library (`drivers/gpu/drm/nouveau/nvif/*.c`).

## Architecture & Data Flow
- In `nouveau_uvmm_bo_validate()`, call `nouveau_bo_placement_set(nvbo, nvbo->valid_domains, 0)` before `nouveau_bo_validate()` to restore placement after eviction; in `nouveau_uvmm_bind_job_submit()`, `bind_lock_validate()` must validate all backing BOs before `bind_link_gpuvas()` links new `DRM_GPUVA_OP_MAP`/`REMAP` mappings so `validate()` does not synchronously update page tables before the bind job runs [F159, F161].
- `nouveau_uvmm_bo_unmap_all()` and `nouveau_uvmm_bo_map_all()` must call `drm_gpuva_invalidate(va, true/false)` in lockstep with `nouveau_uvma_unmap()`/`map()`, because `nouveau_uvma_unmap()` and `op_unmap_range()` skip `nouveau_uvmm_vmm_unmap()` when `drm_gpuva_invalidated` is true [F162].
- Every `nouveau_job` submitted to `cli->sched` must be a `nouveau_uvmm_bind_job`, because `bind_validate_map_sparse()` walks `sched->job.list.head` and downcasts via `to_uvmm_bind_job(__job)` [F229].
- `uvmm->region_mt` uses inclusive bounds `[addr, addr + range - 1]` in `__nouveau_uvma_region_insert()` and `nouveau_uvma_region_find_first()`. In `bind_validate_region()`, `OP_MAP_SPARSE` must set `sparse = true`, call `bind_validate_map_sparse()`, and fall through to `OP_MAP` (`bind_validate_map_common()`); any non-sparse `OP_MAP` intersecting a sparse region must be fully enclosed (`reg_addr <= addr && end <= reg_end`) or rejected with `-ENOSPC` [F182, F183, F198].
- In `bind_validate_op()`, `OP_MAP` must check page alignment of `op->gem.offset`, verify `obj->size <= op->gem.offset` before subtracting `obj->size - op->gem.offset`, and validate `op->va.addr`/`range` via `nouveau_uvmm_validate_range()` [F181].
- When mapping a reserved `nouveau_bo` via `ttm_bo_kmap()` during pushbuf validation, set `nvbo->validate_mapped = true` so `validate_fini_no_ticket()` calls `ttm_bo_kunmap(&nvbo->kmap)` and clears `validate_mapped` before unreserving [F167].
- In `nouveau_gem.c`, `validate_init()` stores a `nouveau_vma *` in `b->user_priv` when `chan->vmm->vmm.object.oclass >= NVIF_CLASS_VMM_NV50` and a `nouveau_bo *` otherwise; `nouveau_gem_pushbuf_reloc_apply()` (which casts `user_priv` to `nouveau_bo *`) must only run on pre-`NV50` channels, and `nouveau_gem_ioctl_pushbuf()` must only copy `bo[i].presumed` back to userspace, never the whole `bo[i]` struct [F231, F232].
- In `nouveau_gem_ioctl_pushbuf()` and `nouveau_gem_pushbuf_reloc_apply()`, reject 0-based indices (`push[i].bo_index`, `r->bo_index`, `r->reloc_bo_index`) when `>= req->nr_buffers`, and reject `r->reloc_bo_offset + 4 > nvbo->bo.base.size` before `nouveau_bo_wr32(nvbo, r->reloc_bo_offset >> 2, data)` [F177, F178].
- A `NOUVEAU_GEM_DOMAIN_NO_SHARE` (`nvbo->no_share`) BO shares `drm_gpuvm_resv(&uvmm->base)` and must be rejected with `-EPERM` in `nouveau_gem_prime_export()` and `nouveau_gem_object_open()` for any client with a different `drm_gpuvm_resv`. In `struct nouveau_sgdma_be`, `struct ttm_tt ttm` must remain at offset 0 for direct casts in `nouveau_sgdma_destroy()`/`bind()`/`unbind()` [F168, F233].
- On `NV_DEVICE_INFO_V0_TESLA`+ except chipset `0x50`, `nouveau_ttm_init()` registers `NVIF_MEM_KIND` in `drm->ttm.type_host[1]` and `type_ncoh[1]`, and `nouveau_mem_host()` selects `type_ncoh[!!mem->kind]`. In `nv84_fence.c`, `priv->bo` (allocated with `GART | COHERENT` when `ram_size == 0`) holds 16-byte slots indexed by `nv84_fence_chid(chan)`; `nv84_fence_context_del()` writes `fctx->base.sequence` back to the slot for `nv84_fence_context_new()`, and suspend/resume saves/restores all `drm->chan_total` slots [F170, F244, F245].
- In `nouveau_svm.c`, `buffer->id` must equal its index in `svm->buffer[]` before scheduling `buffer->work`. Fault ring entries in `buffer->object` are 32 bytes at `buffer->get * 0x20`, wrapping `buffer->get` to `0` at `buffer->entries`; `nouveau_svm_fault_cache()` must clear bit 31 (`0x80000000`) at `offset + 0x1c` before writing `buffer->get` to `buffer->getaddr`, and `nouveau_svm_fault_buffer_init()` must re-read `get`/`put` from HW on init and resume [F171, F185, F234].
- In `nvif/chan.c`, `nvif_chan_gpfifo_ctor()` sets `gpfifo.max = (gpfifo_size >> 3) - 1` and `push.hw.max = push_size >> 2` (Fermi+ `nvif_chan906f` packs 15-bit `pbptr` and 17-bit `gpptr`, limiting `push_size` to 64 KiB and power-of-two `gpfifo_size` to 1 MiB). `nvif_chan_dma_wait()` must reserve `gpfifo.post_size` words (`nr += post_size`, `push->end = push->bgn + free - post_size`), and on wrap (`get <= cur` and `hw.max - cur < nr`), kick and poll `push.read_get(chan)` until `get != 0` before setting `cur = 0` [F175, F188, F205].
- `nouveau_vga_init()`/`fini()` must skip `!dev_is_pci()` and skip `vga_switcheroo` on `pci_is_thunderbolt_attached(pdev)`. `nouveau_led_init()` requires `nvxx_gpio(drm)` and `nvkm_gpio_find(..., DCB_GPIO_LOGO_LED_PWM, ...) == 0`, and `nouveau_led_get_brightness()` must guard against `div == 0` on `0x61c880` [F212, F246, F247].

## Synchronization
- In `nouveau_ttm_fault()`, when `ttm_bo_vm_fault_reserved()` returns `VM_FAULT_RETRY` and `!(vmf->flags & FAULT_FLAG_RETRY_NOWAIT)`, return directly without unlocking `bo->base.resv`; all other paths after `ttm_bo_vm_reserve()` succeeds must unlock `bo->base.resv` [F108].
- In `nouveau_job_submit()`, hold `sched->mutex` continuously across `job->ops->submit()`, `list_add()`, `drm_sched_job_arm()`, `armed_submit()`, and `drm_sched_entity_push_job()`, setting `job->state = NOUVEAU_JOB_SUBMIT_SUCCESS` before `drm_sched_entity_push_job()` so `nouveau_job_run()` does not overwrite it [F123, F124].
- Hold `uvmm->mutex` (`nouveau_uvmm_lock()`, outside any GEM `dma_resv` lock) for all `uvmm->base` and `uvmm->region_mt` mutations, including continuously across op preparation, `drm_exec` lock/validate, and `bind_link_gpuvas()` (or unwind) in `nouveau_uvmm_bind_job_submit()`. Hold `obj->resv` for every `drm_gpuva_link()`/`unlink()` and `drm_gpuvm_bo_obtain()`/`put()` call [F126, F127, F259].
- In `bind_validate_map_common()` and `bind_validate_map_sparse()`, pin the kref (`nouveau_uvma_region_get()` / `nouveau_uvmm_bind_job_get()`) before dropping `uvmm->mutex` or `sched->job.list.lock` to wait on `complete`, then `goto again`. In `nouveau_uvmm_bind_job_cleanup()` (`OP_UNMAP_SPARSE`), call `nouveau_uvma_region_remove(op->reg)` under `uvmm->mutex` before `nouveau_uvma_region_complete()`. In `armed_submit()`, call `drm_gpuvm_exec_resv_add_fence()` before `drm_gpuvm_exec_unlock()` [F129, F130, F131].
- In `nouveau_svm_fault()`, acquire `mmget_not_zero(mm)` before faulting (canceling the fault if false). In `nouveau_range_fault()` and `nouveau_atomic_range_fault()`, drop `mmap_read_lock(mm)` before acquiring `svmm->mutex`, and hold `svmm->mutex` across `mmu_interval_read_retry()` and `nvif_object_ioctl()` [F135, F281].
- Hold `dma_resv_lock(robj, NULL)` across `nouveau_bo_alloc()`, `drm_gem_object_init()`, and `nouveau_bo_init()` in `nouveau_gem_prime_import_sg_table()`. In `nouveau_gem_ioctl_pushbuf()`, if `do_reloc` is true and `reloc` is not yet copied, call `validate_fini()` to drop BO locks before `u_memcpya(req->relocs, ...)`, then jump to `revalidate:` [F136, F137].
- Serialize `nvif_mem_ctor_type()`/`nvif_mem_dtor()` in `nouveau_mem.c` under `drm->client_mutex`, and `nouveau_vma_new()`/`del()` on `priv->bo` in `nv84_fence.c` under `priv->mutex`. In `nv17_fence_sync()`, use `mutex_trylock(&cli->mutex)` (`-EBUSY` on failure) and `spin_lock(&priv->lock)` for `priv->sequence`. In `nv04_fence_emit()`, use `unrcu_pointer(fence->channel)`. In `nvif_chanc36f_gpfifo_kick()`, run `wmb()` and `nvif_rd32(&chan->userd, 0)` before `doorbell()`. In `nvif_userc361_time()`, loop reading `hi` (`0x084`) and `lo` (`0x080`) until `hi` matches, casting `hi` to `u64` [F138, F139, F210, F248, F266, F267].

## Object Lifetimes
- In `nouveau_gem_new()` and `nouveau_gem_prime_import_sg_table()`, call `drm_gem_object_init(&nvbo->bo.base)` after `nouveau_bo_alloc()` and before `nouveau_bo_init()`. If `drm_gem_object_init()` fails, call `drm_gem_object_release()` and `kfree(nvbo)`; once `nouveau_bo_init()` is called, it consumes `nvbo` even on failure, so callers must not free `nvbo` or release `bo.base`. `nouveau_gem_object_del()` must only call `ttm_bo_put(&nvbo->bo)`. Pair `arch_io_reserve_memtype_wc()`/`arch_phys_wc_add()` in `nouveau_ttm_init()` with `arch_phys_wc_del()`/`arch_io_free_memtype_wc()` after `ttm_device_fini()` in `nouveau_ttm_fini()` [F105, F106, F107, F237, F238].
- In `nouveau_svmm_init()`, `__mmu_notifier_register()` takes ownership of `svmm` (freed in `nouveau_svmm_free_notifier()`); `nouveau_svmm_fini()` must set `svmm->vmm = NULL` under `svmm->mutex` and call `mmu_notifier_put(&svmm->notifier)` instead of `kfree(svmm)` [F111, F133].
- In `nouveau_atomic_range_fault()`, release `folio` from `make_device_exclusive()` via `folio_unlock()` and `folio_put()` on both retry and completion, and call `mmu_interval_notifier_remove()` before returning. In `nouveau_svm_fault_buffer_fini()`, call `nvif_event_block(&buffer->notify)` and `flush_work(&buffer->work)` before freeing fault entries or destroying `notify`/`object`. In `nouveau_sched_fini()`, wait via `wait_event(sched->job.wq, list_empty(&sched->job.list.head))` before `drm_sched_entity_fini()` and `drm_sched_fini()`, and call `destroy_workqueue(sched->wq)` only after both finish [F112, F125, F240].
- In `nouveau_uvmm_ioctl_vm_init()`, `drm_gpuvm_init()` takes ownership of `uvmm` and its own ref on `r_obj`, so call `drm_gem_object_put(r_obj)` immediately and clean up later errors via `drm_gpuvm_put(&uvmm->base)`. `op_map_prepare()` calls `nouveau_uvma_gem_get(uvma)`, so `op_map_prepare_unwind()`, `nouveau_uvmm_sm_cleanup()`, and `nouveau_uvmm_fini()` must call `nouveau_uvma_gem_put(uvma)` before `nouveau_uvma_free()`. On `nouveau_uvmm_bind_job_submit()` failure, unwind in reverse, free `op->ops`, clear `op->ops = NULL` and `op->reg = NULL`, and unlock `uvmm` and `vme` [F116, F117, F118].
- In `nouveau_vma_new()`, set `vma->addr = ~0ULL` before `nvif_vmm_get()` so `nouveau_vma_del()` skips `nvif_vmm_put()` on failure; `nvif_vmm_get()` must zero `vma->size` before `nvif_object_mthd()`, and `nvif_vmm_put()` must check `if (vma->size)` and reset `vma->size = 0`. In `nvif_object_map()`, if `nvif_object_map_handle()` returns `1` (`NVIF_IOCTL_MAP_V0_IO`) and `client->driver->map()` fails, call `nvif_object_unmap_handle(object)` [F119, F120, F122, F143].

## API Contracts
- UVMM and legacy GEM are mutually exclusive: `nouveau_gem_ioctl_new()` calls `nouveau_cli_disable_uvmm_noinit(cli)`, `nouveau_uvmm_ioctl_vm_init()` rejects `cli->uvmm.disabled`, and `nouveau_gem_object_open()`/`close()` and `nouveau_gem_ioctl_pushbuf()` check `nouveau_cli_uvmm(cli)` [F169].
- In `nouveau_job_submit()`, once `job->ops->submit()` succeeds, submission cannot fail and must call `armed_submit()` and `nouveau_job_fence_attach()`; if `submit()` fails, call `nouveau_job_fence_attach_cleanup()`. `nouveau_job_ops.run` returns `ERR_PTR(0)` (`NULL`) on sync completion or `ERR_PTR(ret)` on failure, so `nouveau_job_run()` must check `IS_ERR(fence)`. Bracket `nouveau_sched_timedout_job()` with `drm_sched_stop()` and `drm_sched_start()`. Pass `0` (not `sync->flags`) to `drm_syncobj_find_fence()` in `sync_find_fence()`. Gate `args` dereferences and `vmm_get`/`put` on `args != NULL` in `nouveau_uvmm_sm_prepare()`/`unwind()` [F115, F144, F148, F154, F271].
- `nouveau_svmm_init()` must return `-ENOSYS` when `cli->drm->svm` is NULL. Set `.dev_private_owner = drm->dev` on `struct hmm_range` in `nouveau_range_fault()`. In `nouveau_svmm_invalidate_range_start()` and `nouveau_svm_range_invalidate()`, check `mmu_notifier_range_blockable()` before `mutex_lock(&svmm->mutex)`, and ignore `MMU_NOTIFY_MIGRATE`/`EXCLUSIVE` when `owner == svmm->vmm->cli->drm->dev` [F151, F243, F277, F278].
- Pass the base pointer from `nouveau_pfns_alloc()` to `nouveau_pfns_map()` (with `npages` <= allocated count) and `nouveau_pfns_free()` (never `kfree()`). `nvif_vmm_raw_*()`, `nvif_vmm_get()`, and `nvif_mem_ctor_type()` take a page shift (`PAGE_SHIFT`) and byte `addr`/`size`; TTM `res->start` and `fpfn`/`lpfn` use pages (`>> PAGE_SHIFT`, `PFN_UP(size)` for `nouveau_mem_intersects()`/`compatible()` and `ttm_bo_kmap()`). `nvif_push` counts are `u32` words while `nvif_chan_gpfifo_push()` takes bytes (`<< 2`) [F156, F214, F221, F222, F227, F275].
- Use `check_add_overflow()` for `sizeof(*args) + size` in `nvif_object_mthd()`/`ctor()`. Pass only payload `data[]` length as `size` to `nvif_outp_infoframe()`. `nvif_client_ctor()`/`nvif_driver_init()` require non-NULL `name`. In `nvif_mem_ctor()`, match `(mmu->type[i].type & type) == type` and loop while `ret != 0`. `validate_list()` returns `< 0` on error or relocated buffer count (`> 0` sets `*apply_relocs = true`). In `nouveau_hwmon.c`, terminate `special_groups` with `NULL` (`N_ATTR_GROUPS`), and return `-EINVAL` in live `*_input` reads when `switch_power_state != DRM_SWITCH_POWER_ON` [F142, F176, F191, F204, F223, F235, F251].

## Error Handling
- NVIF constructors must set `object.client = NULL` and sub-pointers to `NULL` before any fallible step; after allocating `args` in `nvif_vmm_ctor()`, jump to `done:` on error to run `nvif_vmm_dtor()` and `kfree(args)`. Copy embedded user array pointers in ioctls with `u_memcpya()` and test with `IS_ERR()` (never pass `IS_ERR()` to `u_free()`). Capture `dma_resv_wait_timeout()` in a `long`, mapping `0` to `-EBUSY` and `> 0` to `0` [F121, F140, F141, F150, F286].
- In `nouveau_uvmm_sm_prepare_unwind()`, unwind GPUVAs in reverse from `last`, but unwind page tables in forward order stopping at `if (op == last) break;`. In `nouveau_uvmm_bind_job_submit()`, jump to `unwind_continue` inside `list_for_each_op` and set `op = list_last_op(&bind_job->ops)` before `unwind` after the loop. In `validate_init()` on `-EDEADLK`, use `list_splice_tail_init()` before `validate_fini_no_ticket()`, and finish `res_bo` setup after `ttm_bo_reserve_slowpath()` before `retry:`. Skip `NV_PRINTK(err, ...)` on `-ERESTARTSYS` in `nouveau_gem.c` [F193, F194, F200, F288].

## External Contracts
- Enforce `NOUVEAU_GEM_MAX_PUSH`/`BUFFERS`/`RELOCS` before `u_memcpya()` in `nouveau_gem_ioctl_pushbuf()`; check `kernel_managed_addr + size` with `check_add_overflow()` and `<= NOUVEAU_VA_SPACE_END` in `nouveau_uvmm_ioctl_vm_init()`; in `nouveau_svmm_bind()`, align `va_start`/`va_end` to `PAGE_SIZE` before checking `va_start >= va_end` and reject non-zero `reserved*`/`stride` or invalid `header` bits. Guard `nouveau_led.h` stubs with `IS_REACHABLE(CONFIG_LEDS_CLASS)` [F179, F180, F184, F270].

## Known Pitfalls
- Check `chan->func->gpfifo.post` for NULL (`nvif_chan506f`) in `nvif/chan.c`, and add `chan->gpfifo.max + 1` when `int chan->gpfifo.free < 0` before comparing with `u32 gpfifo_nr`. In `op_remap()` and `nouveau_uvmm_sm_cleanup()`, sample `end = addr + range` before advancing `addr` past `r->prev`. Skip `&uvmm->base.kernel_alloc_node` in `drm_gpuvm_for_each_va*` loops [F145, F160, F216, F230].
- In `nouveau_svm_fault()`, reset `args->p.addr`/`page`/`size` on each loop iteration, keep `fn = fi + 1` in the `for` header, sort `buffer->fault` (dereferencing `*(struct nouveau_svm_fault **)` in `nouveau_svm_fault_cmp()`) before resolving `svmm`, and use `time_after(jiffies, timeout)` in range fault loops. In `nouveau_hmm_convert_pfn()`, use `1UL << args->p.page` and sample `addr` before aligning `args->p.addr` to rewind `page`. Cast upper 32-bit words to `u64` before `<< 32` in `nouveau_svm_fault_cache()` and `nvif_chan506f_read_get()`, use `BIT_ULL(i)` on `u64 runm` in `nvif_fifo_runlist()`, and bound stalled timer reads to 16 in `nvif_timer_wait_test()` (`wait->reads`) [F172, F173, F202, F203, F206, F207, F208, F209, F211, F215, F228].
