# LINUX FOR POWERPC (32-BIT AND 64-BIT) — arch/powerpc (part 2)

Provides PowerPC architecture header definitions (internal `asm` and UAPI) and early kernel support for processor cache topology sysfs export, alignment exception emulation, early boot framebuffer text rendering (`btext`), and CPU feature specification tables, alongside low-level primitives for user memory access, spinlocks, SMP, VDSO, code patching, XICS/XIVE interrupt controllers, VIO, and VAS.

## Architecture & Data Flow

- In `arch/powerpc/kernel/cacheinfo.c`, `struct cache_dir::kobj` is a `struct kobject *` whereas `struct cache_index_dir::kobj` is embedded, so `kobj_to_cache_index_dir()` and `index_kobj_to_cache()` must never be called on `cache_dir->kobj`; `cache_index_show()` downcasts `attr` via `container_of(attr, struct kobj_attribute, attr)`, so all `cache_index_type` attributes must be embedded in `struct kobj_attribute`; and `cache_associativity()` must verify `nr_sets`, `size`, and `line_size` are strictly positive (after `nr_sets == 1`) before dividing, returning `-ENODEV` if zero/missing. [F51, F93, F94]
- In `arch/powerpc/kernel/cpu_setup_power.c`, every SPR initialization added to `__setup_cpu_power{7,8,9,10}()` must be mirrored in `__restore_cpu_power{7,8,9,10}()`, and both must verify `MSR_HV` is set (via `init_hvmode_206(t)` or `mfmsr() & MSR_HV`) before accessing hypervisor-privileged SPRs (`SPRN_LPID`, `SPRN_AMOR`, `SPRN_PCR`, `SPRN_LPCR`, `SPRN_PSSCR`, `SPRN_HFSCR`, `SPRN_MMCRC`, `SPRN_MMCRH`). [F36, F102]
- In `arch/powerpc/kernel/cpu_specs_*.h`, `cpu_specs[]` entries with more specific `pvr_mask` values must precede broader family entries, and the catch-all entry (`pvr_mask = 0`) must be last because `identify_cpu()` returns on the first match. [F67]
- In `arch/powerpc/kernel/audit.c` and `compat_audit.c`, syscall classifications (`audit_classify_syscall()` and `ppc32_classify_syscall()`) and class arrays (`dir_class`, `read_class`, `write_class`, `chattr_class`, `signal_class` and `ppc32_*_class`) must be updated in lockstep, and every class array passed to `audit_register_class()` must end with a `~0U` sentinel. [F50, F57]
- In `arch/powerpc/include/asm/thread_info.h`, `arch_within_stack_frames()` only accepts `[obj, obj + len)` within `[prev_frame + STACK_FRAME_PARAMS, frame]` of a single frame inside `[stack, stackend)`; `MIN_THREAD_SHIFT` must be `CONFIG_THREAD_SHIFT + 1` when `CONFIG_KASAN && CONFIG_THREAD_SHIFT < 15`, and `THREAD_ALIGN_SHIFT` must be `THREAD_SHIFT + 1` under `CONFIG_VMAP_STACK`; and `TLF_NAPPING` (0) and `TLF_SLEEPING` (1) in `local_flags` must not be renumbered or moved above bit 3 without updating `prepare_transfer_to_handler` in `entry_32.S`. [F54, F115, F116]
- In `arch/powerpc/include/asm/text-patching.h`, `R2_STACK_OFFSET` (24 on `CONFIG_PPC64_ELF_ABI_V2`, 40 otherwise) used by `PPC_INST_LD_TOC` must match `STK_GOT` in `asm/ppc_asm.h`, and `ppc_function_entry()` must skip the 2-instruction TOC prologue on ABIv2 or dereference `struct func_desc` on ABIv1. Broken by: patching at raw `ppc_global_function_entry()`. [F117]
- In `arch/powerpc/include/asm/sstep.h`, `enum instruction_type` values from `LOAD` through `STCX` must remain contiguous, and `OP_IS_LOAD()`, `OP_IS_STORE()`, and `OP_IS_LOAD_STORE()` must be passed `GETTYPE(op.type)` rather than raw `op.type` (which has flags and size ORed above `INSTR_TYPE_MASK`). [F68]
- In `arch/powerpc/include/asm/switch_to.h`, `clear_task_ebb()` on `CONFIG_PPC_BOOK3S_64` must zero all coupled EBB and PMU thread fields (`ebbrr`, `ebbhr`, `bescr`, `mmcr2`, `mmcr0`, `siar`, `sdar`, `sier`, `used_ebb`) together; and in `asm/xics.h`, per-CPU `xics_cppr::stack[MAX_NUM_PRIORITIES]` reserves `index == 0` for `xics_set_base_cppr()`, and `xics_push_cppr()` / `xics_pop_cppr()` must check `index >= MAX_NUM_PRIORITIES - 1` and `index < 1` before updating `index`. [F41, F56]

## Synchronization

- In `arch/powerpc/kernel/cacheinfo.c`, all functions traversing or mutating `cache_list`, `struct cache` nodes, or `cache_dir_pcpu` (`cacheinfo_cpu_online()`, `cacheinfo_cpu_offline()`, `cacheinfo_teardown()`, `cacheinfo_rebuild()`) must run in process context under the CPU hotplug lock; `cacheinfo_cpu_online()` must finish `cache_chain_instantiate()` (populating the `struct cache` chain and `shared_cpu_map` via `cache_cpu_set()`) before `cacheinfo_sysfs_populate()`; and `cacheinfo_create_index_dir()` must assign `index_dir->cache = cache` before `kobject_init_and_add()`. [F9, F10, F121]
- In `arch/powerpc/include/asm/simple_spinlock.h`, on `CONFIG_PPC64`, `__arch_spin_trylock()` and `__arch_write_trylock()` must store `LOCK_TOKEN` (`0x80000000 | smp_processor_id()`) for `splpar_{spin,rw}_yield()`, and `__arch_read_trylock()` must sign-extend the 32-bit `lwarx` value via `__DO_SIGN_EXTEND` (`extsw`); 4-operand `lwarx` must pass `IS_ENABLED(CONFIG_PPC64)` as the `eh` operand (never hardcoded `1`); and wait loops in `arch_{spin,read,write}_lock()` must restore `HMT_medium()` after `HMT_low()` and only call `splpar_{spin,rw}_yield()` when `is_shared_processor()` is true. [F13, F81, F111, F112]
- `ppc_after_tlbiel_barrier()` must execute `ptesync` followed by `PPC_CP_ABORT` on `CPU_FTR_ARCH_31` (POWER10+); `vas_user_win_add_mm_context()` must issue `PPC_CP_ABORT` after `mm_context_add_vas_window()`; and accesses to `struct vas_user_win_ref.vma` across `mmap()` and DLPAR close/reopen paths must hold `struct vas_user_win_ref.mmap_mutex`. [F15, F16, F17]
- On 32-bit builds (`!__is_defined(__powerpc64__)`), `get_tb()` must read `mftbu()`, `mftb()`, and `mftbu()` in a loop until both upper-word reads match, and `set_tb()` must zero `SPRN_TBWL` before writing `SPRN_TBWU` and `SPRN_TBWL`. [F18]

## Object Lifetimes

- In `arch/powerpc/kernel/cacheinfo.c`, every `struct cache` from `new_cache()` (`cache_init()`) must be freed via `release_cache()` (never raw `kfree()`) and only when `shared_cpu_map` is empty; `cache_cpu_set()` and `cache_cpu_clear()` must update `shared_cpu_map` across the entire `cache->next_local` chain; and `cache_cpu_clear()` must walk from lower to higher levels and save `next = cache->next_local` before `release_cache(cache)` so lower caches are unlinked before `release_cache_debugcheck()` inspects their `next_local` target. [F1, F31, F72]
- In `arch/powerpc/kernel/cacheinfo.c`, `cacheinfo_cpu_offline()` must call `remove_cache_dir()` and reset `per_cpu(cache_dir_pcpu, cpu_id) = NULL` before `cache_cpu_clear()`; after `kobject_init_and_add()` in `cacheinfo_create_index_dir()`, `index_dir` is owned by `cache_index_release()` and errors must call `kobject_put(&index_dir->kobj)` rather than `kfree(index_dir)`; and `remove_index_dirs()` must save `next = index->next` before `kobject_put(&index->kobj)`. [F4, F5, F73]
- `cache_lookup_or_instantiate()` and `cache_lookup_by_node_group()` borrow the caller's `device_node` reference, so callers (`do_subsidiary_caches()`, `cache_chain_instantiate()`, `cache_lookup_by_cpu()`) must call `of_node_put()` across all return/break paths; likewise, `btext_find_display()` in `btext.c` must call `of_node_put(np)` before breaking out of `for_each_node_by_type(np, "display")`. [F3, F74]

## API Contracts

- In `arch/powerpc/include/asm/uaccess.h`, `get_user(x, ptr)` and `__get_user_size_allowed(x, ptr, size, retval)` must zero `x` (including both words of a 64-bit load on PPC32) on fault or failed `access_ok()`; `__get_user_atomic_128_aligned(kaddr, uaddr, err)` requires `enable_kernel_vmx()` and pre-initialized `err = 0`; `unsafe_{get,put}_user()` and `unsafe_copy_{from,to}_user()` require wrapping in `user_*_access_begin()` and `user_*_access_end()` (including fault paths); and `unsafe_copy_{from,to}_user()` must advance `_i` by 4 in `(_len & 4)` and by 2 in `(_len & 2)`. [F24, F25, F52, F76]
- In `emulate_spe()` (`arch/powerpc/kernel/align.c`), `flush_spe_to_thread(current)` must precede reading/updating `current->thread.evr[reg]`, SPE loads must stage user bytes into `temp` before writing `*evr` and `regs->gpr[reg]`, and because the fallthrough byte-transfer switches on `nb` (8, 4, 2) access trailing bytes `v[8 - nb .. 7]`, `data.ll` and `temp.ll` must be zero-initialized and sub-8-byte operands accessed at `w[1]` or `h[2..3]`. [F37, F53]
- In `arch/powerpc/include/asm/syscall.h`, helpers taking `struct task_struct *task` (`syscall_get_arguments()`, `syscall_get_arch()`) must test `is_tsk_32bit_task(task)` rather than `is_32bit_task()`; `syscall_get_arguments()` and `syscall_set_arguments()` must read/update `regs->orig_gpr3` alongside `regs->gpr[3]` for argument 0 (with arguments 1..5 in `regs->gpr[4..8]`); `syscall_get_arguments()` must mask arguments with `0xffffffffUL` when `is_tsk_32bit_task(task)` is true; and `syscall_get_nr()` must return `int` so a 32-bit `0xffffffff` in `regs->gpr[0]` sign-extends to `-1`. [F59, F66, F133]
- In `arch/powerpc/include/asm/text-patching.h`, `create_branch()` must verify `is_offset_in_branch_range(offset)` (`offset >= -0x2000000 && offset <= 0x1fffffc && !(offset & 0x3)`) and mask `(flags & 0x3)` and `(offset & 0x03FFFFFC)`, returning `1` (`*instr = ppc_inst(0)`) if out of range; `patch_uint()` / `patch_u32()` and `patch_ulong()` / `patch_u64()` must require `IS_ALIGNED(addr, sizeof(...))` and return `-EINVAL` if unaligned. [F55, F91]
- In `arch/powerpc/include/asm/word-at-a-time.h`, all variants of `has_zero()` must return `unsigned long` (not `bool`) and store the byte mask into `*data` / `*bits`, and on 64-bit little-endian PowerPC, `zero_bytemask(mask)` computes `(1UL << mask) - 1` and must only be called when `mask < 64`; on `CONFIG_PPC64` (without `CONFIG_KASAN`), `__memset{16,32,64}()` take a byte count `n`, so element-count callers must use `memset{16,32,64}()` which scale `n` by 2, 4, and 8. [F45, F87, F97]
- Callers of `smu_queue_cmd()` must initialize all public fields of `struct smu_cmd`, and callers of `smu_queue_i2c()` must initialize `cmd->info` (including `info.data` for writes), `cmd->done`, and `cmd->misc` before queuing and not modify them while `status == 1`; on PowerNV VAS, `vas_rx_win_open()` must precede `vas_tx_win_open()` for coprocessor type `@cop`, and all attached send windows must be closed before `vas_win_close()` closes the receive window. [F20, F105]
- `init_LPCR_ISA300()` and `init_LPCR_ISA206()` expect `lpes` as an unshifted 2-bit value (not pre-shifted `LPCR_LPES*`); in `asm/xive-regs.h`, `XIVE_ESB_LOAD_EOI`, `XIVE_ESB_GET`, and `XIVE_ESB_SET_PQ_*` MMIO offsets require 8-byte load instructions; and in `asm/sfp-machine.h`, `udiv_qrnnd(q, r, n1, n0, d)` requires `n1 < d` and the MSB of `d` to be `1` (`UDIV_NEEDS_NORMALIZATION`). [F29, F65, F83]
- `boot_init_stack_canary()` (`asm/stackprotector.h`) must remain `__always_inline`, only be called from non-returning functions, and on `CONFIG_PPC64` update both `current->stack_canary` and `get_paca()->canary`; under `CONFIG_HOTPLUG_SMT`, `topology_is_core_online()` must check all sibling threads in `[cpu_first_thread_sibling(cpu), +threads_per_core)`; under `CONFIG_NUMA`, `early_cpu_to_node()` must return `0` when `numa_cpu_lookup_table[cpu] < 0`; and on `CONFIG_PPC64`, `arch_vmap_{pud,pmd}_supported()` must require `radix_enabled()`. [F123, F125, F126, F137]
- A `struct vio_driver` for a DMA-capable VDEVICE must implement `.get_desired_dma()` (or CMO probing fails with `-EINVAL`), and a `struct secvar_operations` passed to `set_secvar_ops()` that omits `.get_next` must provide a non-NULL, NULL-terminated `var_names` array. [F128, F129]

## Error Handling

- In `arch/powerpc/kernel/align.c`, `fix_alignment()` and `emulate_spe()` must return `1` on successful emulation, `-EFAULT` on user memory fault, and `0` or a negative errno (`-EIO` / `-EINVAL`) when unemulatable; `fix_alignment()` must translate `0` (success) from `emulate_dcbz()` and `emulate_loadstore()` into `1`; and unemulatable instructions (ISA 3.0 copy/paste, LARX/STCX) must return `-EIO` or `-EINVAL` without a kernel `WARN` (`WARN_ON_ONCE(!user_mode(regs))` is only for `dcbz`). [F21, F70, F140]
- In `arch/powerpc/kernel/cacheinfo.c`, optional cache sysfs `.show` callbacks (`size_show`, `line_size_show`, `nr_sets_show`, `associativity_show`) must return `-ENODEV` when the Device Tree property is missing/invalid, and `cacheinfo_create_index_opt_attrs()` must probe each attribute in `cache_index_opt_attrs` via `attr->show()` and only call `sysfs_create_file()` when `rc > 0`. [F27, F64]

## External Contracts

- `syscall_get_error()` and `syscall_set_return_value()` must branch on `trap_is_scv(regs)` (`scv` encodes negative `IS_ERR_VALUE` in `regs->gpr[3]`; non-`scv` sets `0x10000000UL` in `regs->ccr` with positive errno in `regs->gpr[3]`); `asm/syscall_wrapper.h` macros (`__SYSCALL_DEFINEx`, `SYSCALL_DEFINE0`, `COND_SYSCALL`) must use the `sys_` prefix (not `__powerpc_sys_*`); and on `CONFIG_PPC32` / `CONFIG_COMPAT` (`asm/syscalls.h`), syscalls with 64-bit arguments (`sys_ppc_pread64`, `sys_ppc_readahead`, `sys_ppc_fallocate`) must split 64-bit values into two 32-bit args with dummy padding when starting in an even GPR (`r4`, `r6`, `r8`) and combine via `merge_64()`. [F26, F62, F113]
- In UAPI headers: `struct user_pt_regs` / `struct pt_regs` (`uapi/asm/ptrace.h`) must match `PT_*` indices (`PT_R0`..`PT_RESULT`) and keep a 16-byte-multiple size; in `elf_vrregset_t` (`uapi/asm/elf.h`) and 64-bit `struct sigcontext` (`uapi/asm/sigcontext.h`), vector 32 stores `vscr` at byte offset 12, 64-bit vector 33 stores `vrsave` at offset 0, and `sigcontext.v_regs` must be `NULL` or 16-byte-aligned inside `vmx_reserve`; PAPR ioctl binary payloads (`papr_sysparm_io_block::data`, `papr_phy_attest_io_block::payload`) must use `__u8[]` (not `char[]`); and `COMMON_USER_BOOKE` (`cpu_specs_e500mc.h`) must include `PPC_FEATURE_BOOKE` on both `CONFIG_PPC64` and `CONFIG_PPC32`. [F60, F61, F63, F127]
- In vDSO headers: `struct vdso_arch_data::{syscall_map,compat_syscall_map}` (`asm/vdso/arch_data.h`) are `__u32` arrays (`SYSCALL_MAP_SIZE = (NR_syscalls + 31) / 32`) and must not be passed to `unsigned long *` helpers (`set_bit()`, `bitmap_*()`); `V_FUNCTION_BEGIN(name)` (`asm/vdso.h`) must emit `.type name,@function` on both `__VDSO64__` and `__VDSO32__`; and shared compat vDSO code in `asm/vdso/{timebase,gettimeofday}.h` must test `__powerpc64__` rather than `CONFIG_PPC64`. [F98, F119, F120]

## Known Pitfalls

- In `arch/powerpc/kernel/cacheinfo.c`, `cache_do_one_devnode_split()` allocates `dcache` before `icache` (`dcache->next_local = icache`) and `cache_init()` prepends each to `cache_list` so `icache` precedes `dcache` on `cache_list`; `cache_lookup_by_node_group()` must call `cache_find_first_sibling(iter)` to return `dcache`. [F71]
- In `arch/powerpc/kernel/btext.c`, `btext_setup_display()` and `btext_initialize()` must normalize 15-bit depth to `dispDeviceDepth = 16` (and fallback pitch to `width * ((depth + 7) / 8)`) because `calc_base()` and drawing helpers use `dispDeviceDepth >> 3`, and scanline advances on `unsigned int *base` must add `dispDeviceRowBytes >> 2` or cast `base` to `char *` before adding `dispDeviceRowBytes` (`rb`). [F85, F89]
- In `arch/powerpc/include/asm/text-patching.h`, `patch_site_addr(s32 *site)` must cast `site` to `unsigned long` before adding `*site` (never `site + *site` pointer arithmetic), and in `ppc_kallsyms_lookup_name()` under `CONFIG_PPC64_ELF_ABI_V1`, `dot_name` must be sized `1 + KSYM_NAME_LEN` and guarded by `strnlen(name, KSYM_NAME_LEN) >= KSYM_NAME_LEN` before prepending `'.'`. [F90, F96]
- Writes to `SPRN_PTCR` must use `set_ptcr_when_no_uv()` or check `!firmware_has_feature(FW_FEATURE_ULTRAVISOR)`; and in 64-bit non-prefixed inline asm in `asm/uaccess.h` (`__{put,get}_user_asm2_goto`), DS-form instructions (`std`, `ld`) must use `DS_FORM_CONSTRAINT` (`"YZ<>"` on GCC, `"Z<>"` on Clang) rather than `"m<>"`. [F107, F108]
