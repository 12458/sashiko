# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd (part 1)

Defines `amdgpu.h` (`struct amdgpu_device`), ACP audio, ACPI (ATIF/ATCS/XCC DSM), ACA error handling, Aldebaran Mode-2 reset, and the KGD-to-KFD compute interface (`amdgpu_amdkfd*`) across GFX v7–v12 and MI-series GPUs.

## Architecture & Data Flow

- `struct dma_fence base` must stay first (offset 0) in `struct amdgpu_amdkfd_fence` because `amdkfd_fence_release` passes `struct dma_fence *f` to `kfree_rcu(f, rcu)`. Downcast only via `to_amdgpu_amdkfd_fence(f)` (which checks `f && f->ops == &amdkfd_fence_ops`) and NULL-check the result. `struct dev_pagemap pgmap` (flexible array) must stay last in `struct amdgpu_kfd_dev`, and `kfd` must stay last in `struct amdgpu_device`. [F43, F108, F109]
- In `struct amdgpu_amdkfd_fence`, `fence->svm_bo` distinguishes SVM BOs from process BOs: `amdkfd_fence_check_mm` must require `!fence->svm_bo && fence->mm == mm` (returning `false` when `svm_bo` is set so SVM BOs can evict), and `amdkfd_fence_enable_signaling` must dispatch on `fence->svm_bo` and invert the `0`-on-success return of `kgd2kfd_schedule_evict_and_restore_process` / `svm_range_schedule_evict_svm_bo` to `bool`. [F44, F96]
- In `amdgpu_amdkfd_device_init`, after `bitmap_complement` populates `gpu_resources.cp_queue_bitmap` up to `AMDGPU_MAX_QUEUES`, clear bits `last_valid_bit` (`num_pipe_per_mec * num_queue_per_pipe`) through `AMDGPU_MAX_QUEUES - 1` with `clear_bit`. [F78]
- In `hqd_load` (GFX7–v11), `mqd_hqd = &m->cp_mqd_base_addr_lo` is indexed as a flat `uint32_t` array over `[hqd_base, hqd_end]`, requiring MQD fields to match HQD registers 1-to-1. On GFX9.4.3/v10/v10.3/v11, when `wptr` is non-NULL, `guessed_wptr` written to `CP_HQD_PQ_WPTR_LO/HI` must reconstruct the 64-bit RPTR from `cp_hqd_pq_rptr` and `cp_hqd_pq_wptr_lo/hi`, adding `queue_size` on wrap (`(cp_hqd_pq_wptr_lo & (queue_size - 1)) < (cp_hqd_pq_rptr & (queue_size - 1))`). [F81, F85]
- In `kgd_hqd_destroy` (GFX8, v10) and `hqd_destroy_v10_3`/`v11`, if `m->cp_hqd_vmid == 0` (HIQ), clear `RLC_CP_SCHEDULERS.scheduler1 = 0` under `acquire_queue` before `CP_HQD_DEQUEUE_REQUEST`. In SDMA `hqd_sdma_load`/`destroy`, clear `RB_CNTL.RB_ENABLE` and poll `CONTEXT_STATUS__IDLE_MASK` before mutating queue registers, and save `RB_RPTR`/`_HI` back to MQD on destroy. [F63, F64]
- In `kgd_set_pasid_vmid_mapping` (GFX7/v8) and `kgd_gfx_v9_4_3_set_pasid_vmid_mapping`, after writing `ATC_VMID0_PASID_MAPPING + vmid`, poll bit `1U << vmid` in `ATC_VMID_PASID_MAPPING_UPDATE_STATUS`, write `1U << vmid` to clear it, and write `IH_VMID_0_LUT + vmid`. On GC 9.4.3, save and restore `regIH_VMID_LUT_INDEX` around selecting XCC (`aid * 4 + (phy_inst % 2) + 1`) and AID (`aid * 4`) indices. [F58, F62]
- On GFX10: `kgd_gfx_v10_validate_trap_override_request` must restrict `*trap_mask_supported` to `KFD_DBG_TRAP_MASK_DBG_ADDRESS_WATCH` and `trap_override` to `KFD_DBG_TRAP_OVERRIDE_OR`; `kgd_gfx_v10_set_wave_launch_trap_override` must save `mmSPI_GDBG_WAVE_CNTL` before `kgd_gfx_v10_set_wave_launch_stall(adev, vmid, true)` and restore it after updating `mmSPI_GDBG_TRAP_MASK`; and `kgd_gfx_v10_set_address_watch` must clear `VALID = 0` in `mmTCP_WATCH0_CNTL`/`mmSQ_WATCH0_CNTL` before programming `ADDR_H`/`L` and set `VALID = 1` afterward. On GFX9.4.3/v11/v12, `set_wave_launch_trap_override` must decode `kfd_dbg_trap_cntl_prev` via `trap_mask_map_hw_to_sw` and re-encode via `trap_mask_map_sw_to_hw` to preserve `TRAP_ON_START`/`END`. [F59, F60, F61, F100]
- In `amdgpu_aca.c`: `aca_bank_is_valid` must check `ACA_BANK_ERR_IS_DEFFERED(bank)` before `aca_bank_hwip_is_matched` so deferred/poison banks route only to `ACA_HWIP_TYPE_UMC`; `aca_smu_get_valid_aca_banks` must `continue` past any `ACA_SMU_TYPE_UE` bank with `ACA_REG__STATUS__POISON` not matching `ACA_HWIP_TYPE_UMC`; and `aca_log_aca_error` must drain `handle->error_cache.errors[type]` under `aerr->lock` via `aca_bank_error_remove`, with `__aca_get_error_data` also draining `ACA_ERROR_TYPE_DEFERRED` when `type != ACA_ERROR_TYPE_DEFERRED`. [F66, F86, F87]
- In Aldebaran Mode-2 reset: `aldebaran_mode2_prepare_hwcontext` must call `aldebaran_mode2_suspend_ip` only when `!amdgpu_sriov_vf(adev)`, and `aldebaran_mode2_restore_ip` must call `adev->gfx.rlc.funcs->resume(adev)` after `psp_load_fw_list` and before `amdgpu_dpm_wait_for_event(adev, SMU_EVENT_RESET_COMPLETE, 0)`. [F118, F119]
- When `amd_acp_hw_init` returns `-ENODEV` (Azalia), `acp_hw_init` powergates ACP without allocating `acp_genpd`/`acp_cell`; `acp_suspend`, `acp_resume`, and `acp_hw_fini` must check `!adev->acp.acp_cell` / `!adev->acp.acp_genpd` to ungate on suspend/fini and re-gate on resume. [F135]
- `amdgpu_acpi_is_s0ix_active` requires `CHIP_RAVEN`+ APU (`AMD_IS_APU`), `pm_suspend_target_state == PM_SUSPEND_TO_IDLE`, `PP_GFXOFF_MASK`, `ACPI_FADT_LOW_POWER_S0`, and `CONFIG_AMD_PMC`. When `adev->in_s0ix` is true, `amdgpu_amdkfd_suspend`/`resume` must call `kgd2kfd_stop_sched_all_nodes` / `kgd2kfd_start_sched_all_nodes` instead of `kgd2kfd_suspend`/`resume`. [F136, F137]

## Synchronization

- Every `acquire_queue` or `lock_srbm` call (GFX v7–v12) locks `adev->srbm_mutex` and selects SRBM/GRBM pipe/queue/VMID, and must be paired with `release_queue` or `unlock_srbm` on all paths including `-ETIME` timeouts. [F8]
- In `kgd_hiq_mqd_load` (GFX10), `hiq_mqd_load_v10_3`/`v11`, and `amdgpu_amdkfd_unmap_hiq`, `kiq->ring_lock` (`adev->gfx.kiq[inst].ring_lock`) must be held across `amdgpu_ring_alloc`, packet writes, and `amdgpu_ring_commit`, nesting inside `adev->srbm_mutex` when `acquire_queue` is used. In `amdgpu_amdkfd_unmap_hiq`, unlock `kiq->ring_lock` if `amdgpu_ring_alloc` fails before jumping to `free_ring`. [F6, F31]
- `read_user_wptr` must wrap `get_user` in `pagefault_disable()`/`enable()` and only access `wptr` when `mmptr == current->mm` or `current->flags & PF_KTHREAD` (`kthread_use_mm`/`unuse_mm`). In GFX7/v8 `kgd_hqd_load`, call `release_queue(adev)` before `read_user_wptr` and `acquire_queue` afterward before writing `mmCP_HQD_PQ_WPTR`/`mmCP_HQD_ACTIVE`. In GFX9.4.3/v10/v10.3/v11 compute `hqd_load`, never read `wptr` with `get_user`; enable `DOORBELL_EN` first and trigger `CP_PQ_WPTR_POLL_CNTL1` before `CP_HQD_ACTIVE`. [F23, F24, F154]
- In GFX7/v8 `kgd_hqd_destroy`, polling `mmCP_HQD_IQ_TIMER` and `mmCP_HQD_DEQUEUE_REQUEST` (`IQ_REQ_PEND`) must run under `local_irq_save`/`preempt_disable`, restored before the `usleep_range` loop on `mmCP_HQD_ACTIVE`. [F29]
- In `kgd_wave_control_execute` (GFX7/v8/v10) and `wave_control_execute_v10_3`/`v11`/`v12`, hold `adev->grbm_idx_mutex` across writing `GRBM_GFX_INDEX`, issuing `SQ_CMD`, and restoring `GRBM_GFX_INDEX` broadcast bits. On GFX10, hold `adev->grbm_idx_mutex` and call `kgd_gfx_v10_set_wave_launch_stall(adev, vmid, true)` (110 reads of `mmSPI_GDBG_WAVE_CNTL`) before modifying `mmSPI_GDBG_TRAP_CONFIG`, `mmSPI_GDBG_TRAP_MASK`, or `mmSPI_GDBG_WAVE_CNTL2`. [F26, F28]
- In `set_barrier_auto_waitcnt` (called under `adev->grbm_idx_mutex`), after `WRITE_ONCE(adev->barrier_has_auto_waitcnt, ...)`, acquire `adev->reset_domain->sem` via `down_read_trylock` (never `down_read`); once acquired and `amdgpu_amdkfd_suspend(adev, true)` runs, every exit path must call `suspend_resume_compute_scheduler(adev, false)`, `amdgpu_amdkfd_resume(adev, true)`, and `up_read`. [F12, F27]
- `amdkfd_fence_enable_signaling` (under `fence->lock` spinlock) must defer eviction to workqueues (`kgd2kfd_schedule_evict_and_restore_process` / `svm_range_schedule_evict_svm_bo`) without sleeping. `amdgpu_amdkfd_send_close_event_drain_irq` must succeed in `amdgpu_ih_wait_on_checkpoint_process_ts` before calling `amdgpu_amdkfd_interrupt`. [F32, F34]
- In `aldebaran_mode2_perform_reset`, lock `tmp_adev->reset_cntl->reset_lock` and set `active_reset = AMD_RESET_METHOD_MODE2` for all devices in `reset_device_list` before queueing `reset_work`, `flush_work` all items before unlocking `reset_lock` and resetting `active_reset = AMD_RESET_METHOD_NONE` on all exit/error paths, and never lock `reset_cntl->reset_lock` inside `aldebaran_async_reset` / `aldebaran_mode2_reset`. [F13, F35, F148]
- In `aca_bank_should_update`, when `type == ACA_SMU_TYPE_UE` and `amdgpu_ras_intr_triggered()`, `atomic_cmpxchg(&aca->ue_update_flag, 0, 1) == 0` gates UE bank updates until `amdgpu_aca_reset` resets `ue_update_flag` to 0. [F36]

## Object Lifetimes

- `amdgpu_amdkfd_alloc_gtt_mem` reserves, pins, GART-binds, and kmaps the `amdgpu_bo` before unreserving; error rollback and `amdgpu_amdkfd_free_gtt_mem` must unmap and unpin while reserved before unreserving and calling `amdgpu_bo_unref`. [F2]
- When `adev->kfd.dev` is non-NULL, `amdgpu_amdkfd_device_fini_sw` must call `kgd2kfd_device_exit(adev->kfd.dev)`, set `adev->kfd.dev = NULL`, and subtract `adev->gmc.real_vram_size` from `amdgpu_amdkfd_total_mem_size`. [F3]
- `amdgpu_amdkfd_get_dmabuf_info` must call `dma_buf_put(dma_buf)` on all paths after `dma_buf_get`. `amdgpu_amdkfd_submit_ib` must call `amdgpu_job_free(job)` on all paths after `amdgpu_job_alloc`, and `dma_fence_put(f)` after `amdgpu_ib_schedule` succeeds. `amdgpu_amdkfd_fence_create` / `amdkfd_fence_release` must pair `mmgrab(mm)` with `mmdrop(fence->mm)` and `kfree_rcu(f, rcu)`. [F4, F5, F33]
- `amdgpu_atif_call` and `amdgpu_atcs_call` return a caller-owned `union acpi_object *` on success that every caller must `kfree`. If `amdgpu_atif_verify_interface` / `amdgpu_atcs_verify_interface` fails in `amdgpu_atif_pci_probe_handle` / `amdgpu_atcs_pci_probe_handle`, reset `.handle = 0` before returning `false`. [F17, F20]
- `amdgpu_acpi_get_numa_info` owns `struct amdgpu_numa_info` in `numa_info_xa` and lends pointers to `xcc_info->numa_info`; `amdgpu_acpi_release` must free `numa_info` only via `numa_info_xa` (never `kfree(xcc_info->numa_info)`) and use nested `list_for_each_entry_safe` loops to unlink/free every child `xcc_info` before its parent `dev_info`. [F19, F94]
- `acp_hw_fini` must call `device_for_each_child(adev->acp.parent, NULL, acp_genpd_remove_device)` and `mfd_remove_devices(adev->acp.parent)` before freeing `acp_res`, `acp_genpd`, and `acp_cell`. `amdgpu_aca_remove_handle` must call `remove_aca_sysfs(handle)` before `remove_aca_handle(handle)` (`aca_fini_error_cache`). [F21, F37]

## API Contracts

- All `hqd_dump` and `hqd_sdma_dump` callbacks allocate `*dump` via `kmalloc_array` for `HQD_N_REGS` elements (caller `kfree`s on `0` return); `HQD_N_REGS` must match the exact `DUMP_REG` count, and `RREG32` takes dword offset `addr` while `(*dump)[i][0]` stores byte offset `(addr) << 2`. Unconditional `kfd2kgd_calls` callbacks (e.g., `hqd_sdma_get_doorbell`) must be wired in all ten `*_kfd2kgd` tables. [F7, F52, F55, F82]
- `amdgpu_amdkfd_free_gtt_mem` takes `void **mem_obj` (`&bo_ptr`), whereas `amdgpu_amdkfd_free_gws` takes `void *mem_obj` (`bo_ptr`). `read_user_wptr(mmptr, wptr, dst)` only writes `dst` when returning `true`; `hqd_sdma_load` must fall back to writing saved `rb_rptr` into `RB_WPTR` when it returns `false`. [F48, F51]
- On GFX10/v10.3/v11, `lock_srbm` and `RLC_CP_SCHEDULERS` use 1-based `mec = (pipe_id / num_pipe_per_mec) + 1`, whereas `PACKET3_MAP_QUEUES_ME` in `hiq_mqd_load` requires 0-based `mec - 1`. In `kfd2kgd_calls`, `queue_address` in `hqd_is_occupied` and `tba_addr`/`tma_addr` in `program_trap_handler_settings` must be shifted `>> 8`. GFX7/v8 `set_vm_context_page_table_base` must check `amdgpu_amdkfd_is_kfd_vmid(adev, vmid)` (`vmid >= 8`) before `mmVM_CONTEXT8_PAGE_TABLE_BASE_ADDR + vmid - 8`. [F53, F54, F83]
- `amdgpu_ip_version` masks off the lower 8 variant/subrevision bits (`& ~0xFFU`); use `amdgpu_ip_version_full` to match non-zero variant/subrevision in `IP_VERSION_FULL`. `KFD_XCP_MEM_ID(adev, xcp_id)` can return `-1`, so verify `mem_id >= 0` and `xcp_id >= 0` before indexing `adev->gmc.mem_partitions[mem_id]`. `amdgpu_atif_get_sbios_requests` returns `< 0` on error, `0` when none pending, or positive count; callers must check `count <= 0` before reading `*req`. [F40, F76, F77]
- In `amdgpu_aca.c`: `aca_bank_get_error_code` (`parse_error_code`) returns a signed `int` (negative errno on failure), which `aca_bank_check_error_codes` must propagate before returning `0` on match or `-EINVAL`; reject negative `enum aca_error_type` / `enum aca_hwip_type` (`< 0` as well as `>= *_COUNT`) before array indexing; check `start + count` against `max_ue_bank_count` / `max_ce_bank_count` in `aca_smu_get_valid_aca_banks`; and delegate `aca_sysfs_read` to `amdgpu_ras_aca_sysfs_read` instead of `amdgpu_aca_get_error_data`. [F45, F73, F74, F161]

## Error Handling

- In `amdgpu_amdkfd_get_dmabuf_info`, verify `dma_buf->ops == &amdgpu_dmabuf_ops` and `obj->dev->driver == adev_to_drm(adev)->driver` before casting `dma_buf->priv` with `gem_to_amdgpu_bo`, reassign `adev = drm_to_adev(obj->dev)` before storing `*dmabuf_adev = adev`, and NULL-check all optional out-pointers. [F49, F95]
- In `amdgpu_acpi_dev_init` and `amdgpu_acpi_get_xcc_info`, initialize `*dev_info = NULL` on entry and set `obj = NULL` after `ACPI_FREE(obj)` if execution can still reach `out:`. In `aca_smu_get_valid_aca_banks`, `memset(&bank, 0, sizeof(bank))` each iteration, and in `aca_banks_update`, jump to `err_release_banks` (`aca_banks_release(&banks)`) on any error after `aca_banks_init`. [F42, F46]

## External Contracts

- For `ACPI_TYPE_BUFFER` from `amdgpu_atif_call` / `amdgpu_atcs_call`, validate the leading `u16` size `*(u16 *)info->buffer.pointer` against the minimum size, zero the destination struct, and clamp `memcpy` to `min(sizeof(output), size)`. In `amdgpu_atif_get_notification_params`, read `params.command_code` (offset 10) only in the custom-notify branch after checking `size >= 11`. `amdgpu_atif_handler` must return `NOTIFY_BAD` for handled ATIF SBIOS requests and unconfigured `ACPI_VIDEO_NOTIFY_PROBE` events. [F70, F71, F93]
- In `aca_banks_generate_cper`, when `type == ACA_SMU_TYPE_UE`, collect `ACA_ERROR_TYPE_DEFERRED` banks into `de_banks` for `amdgpu_cper_generate_ce_records` (and free via `aca_banks_release(&de_banks)`), encoding remaining UE banks via `amdgpu_cper_generate_ue_record`. [F89]

## Known Pitfalls

- Pass bitwise-inverted field masks (`~REG_FIELD_MASK(...)`) as `mask` to `WREG32_P`, `WREG32_PLL_P`, and `WREG32_SMC_P` (`mask` preserves bits). `BIT_MASK_UPPER(i)` must return `0` when `(i) >= BITS_PER_LONG`, and `for_each_inst(i, inst_mask)` bodies must not modify `i` or assume `i == 0` after the loop (`i` ends at `-1`). [F50, F91, F101]
- On GFX9/v10/v11, `hqd_sdma_load` must cast `uint32_t __user *wptr` to `uint64_t __user *` for `read_user_wptr` before writing `RB_WPTR`/`_HI`. On `CHIP_TONGA`, GFX8 `kgd_hqd_load` must skip `mmCP_HQD_EOP_RPTR`..`mmCP_HQD_EOP_WPTR_MEM`. In `kgd_gfx_v10_set_address_watch`, shift `watch_address_mask` by `>> 7` for `TCP_WATCH0_CNTL` vs. `>> 6` for `SQ_WATCH0_CNTL`. [F80, F84, F126]
- Poll `jiffies` timeouts in `amdgpu_amdkfd_*` with `time_after(jiffies, end_jiffies)`. Use `do_div` and `ALIGN_DOWN(..., PAGE_SIZE)` in `amdgpu_amdkfd_xcp_memory_size`, and ceiling division `((128 * freq / 1000) + (n - 1)) / n` for `mul` in `amdgpu_afmt_calc_cts`. Index `bank->regs[aca_regs[i].reg_idx]` (not `bank->regs[i]`, as `enum aca_reg_idx` skips 7), and track `found` in `find_bank_error` (`return found ? bank_error : NULL`). [F72, F88, F104, F105, F107]
