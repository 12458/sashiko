# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64) — arch/arm64

Host-side headers, UAPI, and core implementation for KVM/arm64 (`arch/arm64/include/asm/kvm_*.h`, `arch/arm64/include/uapi/asm/kvm.h`, `arch/arm64/kvm/{arm,arch_timer,at,config,debug}.c`).

## Architecture & Data Flow

- In `vcpu->arch.iflags`, `INCREMENT_PC` (`BIT(1)`) overlaps `EXCEPT_MASK` (`GENMASK(3, 1)`), making `kvm_incr_pc()` and `kvm_pend_exception()` mutually exclusive; `kvm_arch_vcpu_ioctl_run()` must commit pending `PENDING_EXCEPTION`/`INCREMENT_PC` via `kvm_call_hyp(__kvm_adjust_pc, vcpu)` before `vcpu_put()`. [F69]
- In `enum vcpu_sysreg`, index `kvm_sysreg_masks::mask` by `r - __SANITISED_REG_START__` and `vncr_array` by `r - __VNCR_START__`. Declare entries after `MARKER(__VNCR_START__)` with `VNCR(r)` to bound `NR_SYS_REGS`, and keep `APIAKEYLO_EL1`..`APGAKEYHI_EL1` contiguous and ordered for `PTRAUTH_REG_OFFSET` `stp`/`ldp` pairs. [F77, F78, F121]
- `IDREG_IDX(id)` only indexes `kvm->arch.id_regs` (`KVM_ARM_ID_REG_NUM` = 56) for `(3, 0, 0, crm, op2)` with `1 <= crm < 8`; access `CRm == 0` (`MIDR_EL1`, `REVIDR_EL1`, `AIDR_EL1`) or `CTR_EL0` via `__vm_id_reg()`. Gate `SYS_TCR2`, `SYS_PIR`, `SYS_PIRE0`, `SYS_POR`, `SYS_POR_EL0` and `vcpu_set_hcrx()` on guest VM helpers (`kvm_has_{tcr2,s1pie,s1poe,fpmr,sctlr2}`), not just host caps. [F81, F137]
- In `check_feature_map()`, the OR of `bits` across `bit_feat_map` must equal `reg_feat_map_bits(&r->feat_map)`. `CALL_FUNC` entries in `reg_bits_to_feat_map` must set `FIXED_VALUE` (`NEEDS_FEAT_FIXED`) iff the callback is `bool (*)(struct kvm *, u64 *)` (`fval`) rather than `bool (*)(struct kvm *)` (`match`). In `kvm_has_pauth()`/`kvm_has_full_ptr_auth()`, Pointer Auth requires `(pa + pi + pa3) == 1`. [F96, F108, F124]
- `timer_emulate()` must not return early after `kvm_timer_update_irq()`; always call `kvm_timer_update_status()` and `soft_timer_start()` when `!should_fire && kvm_timer_irq_can_fire(ctx)`. In `kvm_timer_sync_nested()`, when `!cpus_have_final_cap(ARM64_HAS_ECV)`, cancel/re-emulate only `map.emul_{vtimer,ptimer}` from `get_timer_map()`, never overwriting hardware EL1 timers with VNCR state. [F59, F60]
- In `timer_{save,restore}_state()`, put `isb()` between `CVAL` and `CTL` writes and between disabling `CTL` and zeroing `cntvoff`/`cntpoff`. Adjust `SYS_CNTP_CVAL` by `timer_get_offset(ctx)` and call `set_cntpoff(0)`/`set_cntpoff(offset)` for `TIMER_{PTIMER,HPTIMER}`; do the same for `SYS_CNTV_CVAL` (with `cntvoff = 0`) when `has_broken_cntvoff()`. [F61, F139, F140]
- `TIMER_REG_TVAL` is a 32-bit signed offset from `CVAL`: truncate reads with `lower_32_bits()` in `kvm_arm_timer_read()` and sign-extend writes with `(s32)val` in `kvm_arm_timer_write()`. Bound runtime active-timer loops (`kvm_timer_{earliest_exp,vcpu_reset}()`, `timer_irqs_are_valid()`, `kvm_arch_timer_get_input_level()`) by `nr_timers(vcpu)`, not `NR_KVM_TIMERS`. [F89, F90]
- In `setup_s1_walk()`, restrict `wi->pgshift` to `{12, 14, 16}` and validate `wi->txsz` in `[12, 48]` before `GENMASK(ia_bits - 1, 0)`/`GENMASK(63, ia_bits)`. In `check_output_size()`, guard `GENMASK_ULL(51, wi->max_oa_bits)` with `wi->max_oa_bits < 52` (`wi->pa52bit`) and `GENMASK_ULL(47, wi->max_oa_bits)` with `wi->max_oa_bits < 48` (`!wi->pa52bit`). [F113, F114]
- In `walk_s1()`, when `wi->s2` is true, overwrite `ipa` with `kvm_s2_trans_output(&s2_trans)` for `kvm_read_guest()` but keep `baddr` as untranslated IPA for `wi->filter->fn()`, and add `contiguous_bit_shift(desc, wi, level)` to `va_bottom` when `PTE_CONT` is set. In `compute_s1_permissions()`, apply `pan` to `wr->{pw,pr}` only after base, hierarchical, overlay, and `!wr->uov` WXN permissions finalize `wr->{ur,uw,ux}`. [F100, F102, F164]
- In `__kvm_at_s1e01()`/`__kvm_at_s1e2()`, a failed hardware `AT` (`par & SYS_PAR_EL1_F`) may skip `handle_at_slow()` only when `!(par & SYS_PAR_EL1_S)` (`par_check_s1_{perm,access}_fault`). In `__kvm_at_s12()`, check `compute_translation_regime(vcpu, op) == TR_EL20` for single-stage exit, and in `compute_par_s12()` use `min(s2_memattr_to_attr(s2_memattr), s1_parattr)` in the `HCR_FWB` Device `default:` branch. [F94, F95, F101]
- In `kvm_vcpu_wfi()`, set `IN_WFI` and call `kvm_vgic_put()` under `preempt_disable()` before `kvm_vcpu_halt()`, then clear `IN_WFIT`/`IN_WFI` and call `kvm_vgic_load()` under `preempt_disable()` on wakeup. `KVM_{SET,GET}_ONE_REG` must flush `KVM_REQ_VCPU_RESET` via `kvm_reset_vcpu()` before `kvm_arm_{set,get}_reg()`. In `kvm_arch_vcpu_ioctl_vcpu_init()`, clear `BIT(KVM_ARM_VCPU_POWER_OFF)` from `init->features[0]` before `kvm_vcpu_set_target()`, and if `vcpu_has_run_once(vcpu)`, unmap Stage-2 or invalidate I-cache and preserve `vcpu->arch.hcr_el2` in `vcpu_reset_hcr()`. [F71, F72, F143]
- For `KVM_GUESTDBG_SINGLESTEP`, `kvm_vcpu_{load,put}_debug()` must swap `DBG_SPSR_SS` with `{GUEST,HOST}_SS_ACTIVE_PENDING`. When `kvm_debug_handle_oslar()` updates `OSLSR_EL1_OSLK`, cycle `kvm_arch_vcpu_{put,load}()` under `preempt_disable()`. `{push,pop}_hyp_memcache()` must sync `mc->nr_pages` with `mc->head`; `pop_hyp_memcache()` must check `!mc->nr_pages` before dereferencing `p` and mask `mc->head` with `PAGE_MASK` before `to_va()`. `__hyp_pgtable_max_pages()` and `hyp_ffa_proxy_pages()` must use `DIV_ROUND_UP()`. [F15, F64, F65, F76, F116]
- In `hyp_init_cpu_pm_notifier()`, `CPU_PM_ENTER` must call `cpu_hyp_reset()` without clearing `kvm_hyp_initialized`. Flush host-initialized nVHE data read before EL2 MMU enable (`kvm_init_params`, `__hyp_bss_start`..`__hyp_bss_end`) via `kvm_flush_dcache_to_poc`, and save the pKVM hyp stack PA in `params->stack_pa` during `init_hyp_mode` rather than using `__hyp_pa()`. In `struct cpu_sve_state`, keep `fpsr`/`fpcr` adjacent `__u32` fields and `sve_regs` 16-byte aligned; `_kvm_extable`/`__KVM_EXTABLE` fixups must have hyp SCS in `x18` and restore `{SPSR,ELR}_EL2`; `{save,restore}_callee_saved_regs` must include `x18` and never take `x18`–`x28` as `ctxt`. [F75, F118, F160, F163, F165, F166]

## Synchronization

- Lock order: `kvm->lock` -> `vcpu->mutex` -> `kvm->arch.config_lock`. Hold `config_lock` in `__kvm_vcpu_set_target()` across `KVM_ARCH_FLAG_VCPU_FEATURES_CONFIGURED`, `vcpu_features`, `kvm_setup_vcpu()`, and `VCPU_INITIALIZED`. In `kvm_vm_ioctl_enable_cap()`, hold `kvm->lock` to check `!kvm->created_vcpus`, and hold `kvm->slots_lock` to check `kvm_are_all_memslots_empty(kvm)` and set `split_page_chunk_size`. [F31, F32, F154]
- In `kvm_arch_vcpu_ioctl_run()`, set `vcpu->mode = IN_GUEST_MODE` via `smp_store_mb()` after `local_irq_disable()` and before `kvm_vcpu_exit_request()`. Keep `kvm_arm_vcpu_enter_exit` `noinstr` (RCU EQS). On exit before `local_irq_enable()`, sync in order: `kvm_pmu_sync_hwstate()` -> `kvm_vgic_sync_hwstate()` -> `kvm_timer_sync_{user,nested}()`. [F19, F146, F156]
- `kvm->arch.mpidr_data` updates require `config_lock`, `rcu_assign_pointer()`, and `synchronize_rcu()` before free; `kvm_mpidr_to_vcpu()` requires `rcu_read_lock()`/`rcu_dereference()`. `vcpu->arch.mp_state` writes require `mp_state_lock` and `WRITE_ONCE()`; lockless readers require `READ_ONCE()`. `kvm_vcpu_sleep()` needs `smp_rmb()` after `rcuwait_wait_event()` so `KVM_REQ_VCPU_RESET` and `reset_state` are visible. [F21, F22, F23]
- Mutate `vcpu->arch.{cflags,iflags,sflags}` (`__vcpu_{set,clear}_flag`) only from the owning vCPU with preemption disabled. In `vcpu_interrupt_line()`, modify `HCR_{VI,VF}` in `*vcpu_hcr(vcpu)` with atomic bitops followed by `KVM_REQ_IRQ_PENDING` and `kvm_vcpu_kick()`. [F24, F25]
- `timer_{save,restore}_state()` must use `local_irq_save()`. In `kvm_arm_timer_{read,write}_sysreg()`, wrap direct timer save/restore in `preempt_disable()`, and call `soft_timer_cancel()`/`timer_emulate()` for emulated writes. `kvm_arch_timer_handler()` must null-check `vcpu` (`*dev_id`) before dereferencing. [F27, F62, F149]
- In `__kvm_at_s1e01_fast()`/`__kvm_at_s1e2()`, hold `write_lock_irqsave(&vcpu->kvm->mmu_lock)`, restore `HCR_HOST_VHE_FLAGS` before `__mmu_config_restore()`, and save/restore `SYS_PSTATE_PAN` in `at_s1e1p_fast()`. Software walks (`walk_s1()` from `handle_at_slow()`) must run in sleepable context under `srcu_read_lock(&vcpu->kvm->srcu)`. [F33, F70, F159]
- Pair `kvm_pgtable_walk_{begin,end}()`, never setting `KVM_PGTABLE_WALK_SHARED` in hyp context. In pKVM mode, Stage-2 fault paths must use `kvm_fault_{lock,unlock}()` (`write_lock(&kvm->mmu_lock)`), not `read_lock()`. Call sleeping debugfs helpers (`kvm_{sys_regs,s2_ptdump}_create_debugfs`) in `kvm_arch_create_vm_debugfs`, never in `kvm_reset_vcpu`. `kvm_arch_update_irqfd_routing()` runs under spinlock and must only call `kvm_vgic_v4_unset_forwarding()`, never `kvm_vgic_v4_set_forwarding()` (takes `its_lock` mutex). [F14, F38, F147, F148, F158]

## Object Lifetimes

- When `is_protected_kvm_enabled()`, `cpu_hyp_uninit()` must not reset hyp or clear `kvm_hyp_initialized`, and `teardown_hyp_mode()` must skip freeing per-CPU hyp memory where `per_cpu(kvm_hyp_initialized, cpu)` is set. Call `finalize_init_hyp_mode()` in `kvm_arm_init()` only after all fallible steps (`kvm_init()`) succeed, as it converts `sve_state` to a hyp VA in-place. [F1, F41]
- In `kvm_arch_vcpu_load()`, enforce order: (1) `kvm_vcpu_load_hw_mmu()` before reading `vcpu->arch.hw_mmu` (and `kvm_vcpu_put_hw_mmu()` after `kvm_vcpu_put_vhe()` in `put`); (2) `kvm_arm_vmid_update(&mmu->vmid)` before programming `VTTBR_EL2` (`kvm_vcpu_load_vhe()`) and before checking `mmu->last_vcpu_ran != vcpu->vcpu_idx` for `__kvm_flush_cpu_context`; (3) `kvm_timer_vcpu_load()` before `kvm_vgic_load()`; (4) `kvm_vcpu_load_debug()` before `kvm_vcpu_load_vhe()`. [F7, F8, F16, F74, F155]
- In `kvm_timer_vcpu_put()`, save direct timers (`timer_save_state()`), cancel emulated hrtimers (`soft_timer_cancel()`), and if `kvm_vcpu_is_blocking(vcpu)`, arm `timer->bg_timer` (`kvm_timer_blocking()`); cancel `bg_timer` in `kvm_timer_vcpu_{load,terminate}()`. [F144]

## API Contracts

- `kvm_vcpu_exit_request(vcpu, &ret)` leaves `*ret` unmodified when exiting to preemptible kernel context to re-enter the guest; callers looping on `ret > 0` must initialize `ret > 0` beforehand. Use `vcpu_{read,write}_sys_reg()` whenever a sysreg may be live on the CPU (`SYSREGS_ON_CPU`), as `__vcpu_sys_reg()`/`ctxt_sys_reg()` only access memory. Pass only ESR register numbers `0..31` (31 = `XZR`) to `vcpu_{get,set}_reg()`. [F44, F66, F83]
- `kvm_vcpu_get_fault_ipa()` returns `INVALID_GPA` if `HPFAR_EL2_NS` is clear, and the 4KB-aligned IPA (without `far_el2` offset) otherwise. In `kvm_is_write_fault()`, check `kvm_vcpu_abt_iss1tw()` before `kvm_vcpu_trap_is_iabt()` and `kvm_vcpu_dabt_iswrite()`, treating `S1PTW` faults as writes only on `kvm_vcpu_trap_is_permission_fault()`. [F55, F98]
- Zero-initialize `*wi` and `*wr` (setting `wi->{regime,as_el0,pan}`) before `__kvm_translate_va()`. In `walk_s1()`, endian-convert descriptors from `kvm_read_guest()` via `be64_to_cpu()` if `wi->be` is set and `le64_to_cpu()` otherwise. Pre-validate `regid` before `kvm_arm_timer_get_reg()`, which returns `(u64)-1` on error. [F46, F48, F85]
- Pass `__sve_{save,restore}_state()` a pointer offset by `sve_ffr_offset()` (`vcpu_sve_pffr(vcpu)`). In `kvm_arch_alloc_vm()`, use `kzalloc()` when `!has_vhe()` so `kvm_share_hyp(kvm, kvm + 1)` gets physically contiguous memory. `kvm_init_mpidr_data()` must cap `struct_size(data, cmpidr_to_idx, nr_entries)` to `PAGE_SIZE`, `kvm_mpidr_index()` must copy `u64` masks into `unsigned long` locals before `bitmap_gather()`, and `kvm_mpidr_to_vcpu()` must verify `mpidr == kvm_vcpu_get_mpidr_aff(vcpu)`. [F86, F119, F129, F170]
- Call TRBE callbacks (`kvm_{enable,disable}_trbe()`, `kvm_tracing_set_el1_configuration()`) with preemption disabled and guard with `skip_trbe_access()`. Callers of `kvm_pgtable_stage2_{wrprotect,test_clear_young}()` must invalidate TLBs afterwards. [F186, F187]

## Error Handling

- On error after `pkvm_init_host_vm(kvm)` in `kvm_arch_init_vm()`, unreserve the pKVM VM handle in addition to freeing `supported_cpus` and calling `kvm_unshare_hyp()`. On error after `kvm_vgic_vcpu_init()` in `kvm_arch_vcpu_create()`, call `kvm_vgic_vcpu_destroy()`. In `teardown_hyp_mode()`, check `kvm_nvhe_sym(kvm_arm_hyp_percpu_base)[cpu]` is non-zero before dereferencing `per_cpu_ptr_nvhe_sym(kvm_host_data, cpu)` or freeing the base, and read `sve_state` before `free_pages(kvm_arm_hyp_percpu_base[cpu], ...)`. [F3, F6, F40]
- On failure in `kvm_timer_hyp_init()`, free requested per-CPU IRQs (`host_{ptimer,vtimer}_irq`) with `free_percpu_irq(..., kvm_get_running_vcpus())`. In `kvm_irq_init()`, call `irq_domain_free_fwnode()` if `irq_domain_create_hierarchy()` returns `NULL`. Check `irq_entry->type == KVM_IRQ_ROUTING_MSI` before reading `irq_entry->msi` or calling `kvm_vgic_v4_{set,unset}_forwarding()` in `kvm_arch_irq_bypass_{add,del}_producer()` and `kvm_arch_update_irqfd_routing()`. [F42, F134, F135]
- Null-check `direct_ptimer`, `emul_vtimer`, and `emul_ptimer` from `get_timer_map()` when `!vcpu_has_nv(vcpu)` is possible. Check `wr->failed` before reading `struct s1_walk_result` union fields. When `vcpu_mode_is_bad_32bit(vcpu)` in `kvm_arch_vcpu_ioctl_run()`, clear `VCPU_INITIALIZED` and exit with `ARM_EXCEPTION_IL` without host `WARN`/`BUG`. [F43, F47, F176]

## External Contracts

- Match `KVM_REG_ARM_TIMER_{CVAL,CNT}` explicitly in UAPI handlers (their `(CRm, Op2)` encodings are swapped relative to `SYS_CNTV_CVAL_EL0`/`SYS_CNTVCT_EL0`). Use `KVM_ARM_FEATURE_ID_RANGE_IDX` (maps `Op1 == 3` to `2`) to index `reg_mask_range` (`KVM_ARM_FEATURE_ID_RANGE_SIZE` = 192). [F49, F82]
- `kvm_vcpu_init_check_features()` returns `-ENOENT` for unknown bits in `init->features[0..6]` and `-EINVAL` for unsupported valid bits. Require `kvm_vcpu_initialized()` (`-ENOEXEC`) before `KVM_{SET,GET}_ONE_REG`, `KVM_GET_REG_LIST`, `KVM_ARM_VCPU_FINALIZE`, and `kvm_arch_vcpu_run_pid_change()`, and `kvm_arm_vcpu_is_finalized()` (`-EPERM`) before `KVM_GET_REG_LIST` and `kvm_arch_vcpu_run_pid_change()`. [F87, F180]
- When `kvm_vm_is_protected(kvm)`, filter capabilities via `kvm_pvm_ext_allowed()` in `kvm_vm_ioctl_{enable_cap,check_extension}()`. Zero `kvm_vcpu_events` in `kvm_arm_vcpu_get_events()` and reject non-zero `reserved`/`exception.pad` with `-EINVAL` in `kvm_arm_vcpu_set_events()`. [F172, F179]
- In `kvm_vm_ioctl_irq_line()`, combine `KVM_ARM_IRQ_VCPU{,2}_MASK` for `vcpu_id` and validate `irq_num` against `KVM_ARM_IRQ_CPU_FIQ`, `VGIC_NR_SGIS`, and `VGIC_NR_PRIVATE_IRQS`. `kvm_vm_ioctl_set_counter_offset()` requires `offset->reserved == 0`, `kvm->lock`, and `kvm_trylock_all_vcpus()` (`-EBUSY`). `kvm_arm_timer_set_attr()` requires `irq_is_ppi()`, `config_lock`, and `!KVM_ARCH_FLAG_TIMER_PPIS_IMMUTABLE` (`-EBUSY`). [F88, F115, F184, F185]

## Known Pitfalls

- Sign-extend signed ID register fields via `sign_extend64()` in `idreg_feat_match()`, and keep relational comparisons inside `kvm_cmp_feat_{signed,unsigned}()` so C integer promotion across a ternary expression does not convert negative signed fields (`0b1111` = -1) to unsigned. [F93, F109]
- In `arch/arm64/kvm/config.c`, registers using `NEEDS_FEAT_FIXED` must call `compute_reg_fixed_bits()` in `get_reg_fixed_bits()` (as `compute_res0_bits()` excludes `FIXED_VALUE`), and `NEEDS_FEAT_RES0` (`RES0_POINTER`) must only be used in `reg_feat_map_desc.feat_map`, never inside a `bit_feat_map` array. [F97, F125]
- In `timer_set_traps()`, pass `(set, clr)` to `assign_clear_set_bit()` for negative-polarity enable bits (`CNTHCTL_EL1PC{,T}EN`) and `(clr, set)` for positive-polarity trap bits. In `cpu_prepare_hyp_mode()`, apply nVHE `TCR_EL2_*` masks only when `!cpus_have_final_cap(ARM64_KVM_HVHE)`. [F103, F136]
- Cast 32-bit masks/values to `u64` before shifting to bits >= 32 (`tcr_el2_ps_to_tcr_el1_ips()`, `VTTBR_VMID_MASK()`), and copy 32-bit values (`init->features[0]`, `timer_get_ctl()`) into `unsigned long` locals before passing their address to bitops. Use `kvm_s2_mmu_to_kvm(mmu)`, not `container_of(mmu, struct kvm, arch.mmu)`, and cast symbols to `unsigned long` before pointer arithmetic in `per_cpu_ptr_nvhe_sym()`. [F111, F122, F126, F127, F128]
