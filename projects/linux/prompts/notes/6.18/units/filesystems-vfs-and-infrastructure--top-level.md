# FILESYSTEMS (VFS and infrastructure) — (top level)

Defines core VFS and UAPI headers (`include/linux/fs*.h`, `include/uapi/linux/fs.h`, `openat2.h`), early boot rootfs and initramfs/initrd mounting (`init/do_mounts*.c`, `init/initramfs*.c`), and Rust abstractions for files, fds, `kiocb`, `seq_file`, and `poll_table` (`rust/kernel/fs*.rs`, `seq_file.rs`, `sync/poll.rs`).

## Architecture & Data Flow

- In `struct kiocb`, `ki_flags` discriminates the `ki_waitq` / `dio_complete` union: `ki_waitq` is valid iff `IOCB_WAITQ` is set; `dio_complete` may only be set when the issuer set `IOCB_DIO_CALLER_COMP` (with context in `iocb->private`) and must be checked for non-NULL in `ki_complete`. [F387]
- `file_dentry(file)` requires `d_inode(file->f_path.dentry) == file_inode(file)`. Stackable backing files (`FMODE_BACKING`, set only on `struct file` embedded in `struct backing_file`) have `f_inode` on the lower fs and must use `file_user_path(f)` / `file_user_inode(f)`, or verify `FMODE_BACKING` before calling `backing_file_user_path(f)`. [F413, F452]
- Remount can change `sb->s_flags` without updating `inode->i_flags` on existing inodes; test `IS_RDONLY()`, `IS_SYNC()`, `IS_DIRSYNC()`, and `IS_NOATIME()` rather than `inode->i_flags` directly. `inode_set_cached_link()` requires `strlen(link) == linklen` and `!(inode->i_opflags & IOP_CACHED_LINK)`, setting `i_link`, `i_linklen`, and `IOP_CACHED_LINK` together. [F408, F412]
- `FMODE_FSNOTIFY_HSM(exe_file->f_mode)` must stay constant while `exe_file` is open, and `exe_file_deny_write_access()` must pair with `exe_file_allow_write_access()` so `inode->i_writecount` is untouched when `FMODE_FSNOTIFY_HSM` is true. [F414]
- `super_block::s_uuid_len` must never exceed `sizeof(sb->s_uuid)` (16 bytes); use `super_set_uuid()` for variable-length UUIDs so `ioctl_getfsuuid()` (`FS_IOC_GETFSUUID`) cannot overflow `struct fsuuid2::uuid`. `super_set_sysfs_name_uuid(sb)` requires `s_uuid_len == sizeof(sb->s_uuid)`, and `sb->s_sysfs_name` must not be modified after registration. [F416, F423]
- In `struct file_handle`, `f_handle[]` is `__counted_by(handle_bytes)`, so `handle_bytes` must be set before writing `f_handle[]`. `struct address_space` must remain `__attribute__((aligned(sizeof(long))))` so bit 0 of `struct folio.mapping` is zero and can encode `FOLIO_MAPPING_ANON`. [F456, F479]
- In `init/initramfs.c`, `do_header()` must bound `name_len` to `1..=PATH_MAX` and `S_ISLNK(mode)` `body_len` to `<= PATH_MAX` before computing `N_ALIGN(name_len)` for `name_buf` or `symlink_buf`, and must collect symlinks into `symlink_buf` (`state = Collect`) rather than `read_into()` because `do_symlink()` writes `collected[N_ALIGN(name_len) + body_len] = '\0'`. [F420, F442]
- In `init/initramfs.c`, `do_name()` for `S_ISREG(mode)` must omit `O_TRUNC` if `maybe_link()` returns `1` and only truncate when `body_len != 0`. Directory mtimes must be deferred via `dir_add()` to `dir_list` and applied in `dir_utime()` via `list_for_each_entry_safe()` after extraction. `unpack_to_rootfs()` must save and reset `this_header = 0` before `decompress()`, require `state == Reset`, and restore `this_header = saved_offset + my_inptr`. [F405, F406, F437]
- `File`, `LocalFile`, and `SeqFile` must remain `#[repr(transparent)]` wrappers around `Opaque<bindings::file>` and `Opaque<bindings::seq_file>` because `from_raw_file`, `assume_no_fdget_pos`, `AlwaysRefCounted::dec_ref`, and `SeqFile::from_raw` cast raw pointers directly. [F457]

## Synchronization

- `sb->s_writers.rw_sem` (`SB_FREEZE_LEVELS` = 3, indexed by `level - 1`) only accepts `SB_FREEZE_WRITE` (1)..`SB_FREEZE_FS` (3) in `__sb_start_write()`, `__sb_end_write()`, `__sb_start_write_trylock()`, and `__sb_write_started()` (never `SB_UNFROZEN` or `SB_FREEZE_COMPLETE`). Lock order: `sb_start_write` -> `inode->i_rwsem` / `sb->s_umount`, and `mmap_lock` -> `sb_start_pagefault` -> `sb_start_intwrite`. Pair `kiocb_start_write` with `kiocb_end_write` to balance `__sb_writers_release`/`__sb_writers_acquired`. [F376, F422, F470]
- `__iget()` requires holding `inode->i_lock`, and `inode_is_dirtytime_only()` callers must hold or re-verify under `inode->i_lock`. After `dir_relax()` or `dir_relax_shared()` drops and reacquires `inode->i_rwsem`, callers must check the boolean return to verify the directory was not killed (`S_DEAD` / `IS_DEADDIR`). [F379, F380]
- `i_size_write` callers must hold an exclusive lock serializing size updates (typically `inode->i_rwsem`) so concurrent writers on 32-bit SMP do not corrupt `inode->i_size_seqcount` and spin `i_size_read` forever. [F468]
- `struct file` uses `SLAB_TYPESAFE_BY_RCU`, so lockless RCU readers must use `get_file_rcu` or `get_file_active`, never `get_file`. `file->f_lock` (protecting `f_ep` and `f_flags`) is not IRQ-safe and must never be acquired in hardirq context. [F467, F474]
- Non-blocking callback modes must not sleep: `inode_operations.permission` with `MAY_NOT_BLOCK` (return `-ECHILD`), `address_space_operations.migrate_folio` with `MIGRATE_ASYNC`, and `inode_operations.get_inode_acl` when `rcu == true` (`LOOKUP_RCU`, enabled when ACL is set to `ACL_DONT_CACHE`). [F463, F464, F466]
- In `populate_rootfs()`, `initramfs_cookie` must be assigned from `async_schedule_domain(do_populate_rootfs, NULL, &initramfs_domain)` before `usermodehelper_enable()` is called. [F381]

## Object Lifetimes

- `FileDescriptorReservation::fd_install` transfers ownership of `self.fd` and `ARef<File>` to `bindings::fd_install` and must `core::mem::forget` both `self` and `file` so `put_unused_fd` and `fput` do not run. [F362]
- `<PollCondVar as PinnedDrop>::drop` must call `bindings::__wake_up_pollfree` on `self.inner.wait_queue_head` before `bindings::synchronize_rcu()`, and `PollCondVar` must stay pinned and only be dropped in sleepable process context. [F364, F476]
- `unpack_to_rootfs` must call `dir_utime()`, `free_hash()` (clearing `head[]` and resetting `hardlink_seen = false`), and `kfree(bufs)` on all return paths. When `do_name` opens `wfile` for `S_ISREG(mode)`, it must unconditionally set `state = CopyFile` (even if `body_len == 0`) so `do_copy` calls `do_utime_path` and `fput(wfile)`. [F365, F366]
- `do_populate_rootfs` must reset `initrd_start = 0` and `initrd_end = 0` after freeing (`free_initrd_mem` / `kexec_free_initrd`) or retaining (`bin_attr_initrd`) initrd memory, and call `init_flush_fput()`. `initrd_load` must unlink `"/initrd.image"` on all return paths, and `rd_load_image` must unlink `"/dev/ram"` on exit. [F367, F373]

## API Contracts

- `File::from_raw_file` and `LocalFile::from_raw_file` borrow without incrementing `f_ref` (unlike `LocalFile::fget`), requiring a positive refcount for `'a`. `File::from_raw_file` and `LocalFile::assume_no_fdget_pos` also require no active unlocked `fdget_pos` (and `LocalFile::from_raw_file` requires any unlocked `fdget_pos` to be on the current thread) because `File` is `Send + Sync` and installable via `fd_install`. Use `LocalFile::cred()` (`file->f_cred`) for opener credentials. [F363, F458, F497]
- `Kiocb<'a, T>::from_raw` requires a non-null `kiocb` valid for `'a` whose `ki_filp->private_data` holds `<T as ForeignOwnable>::into_foreign`. `SeqFile::from_raw` requires exclusive thread access for `'a` and `SeqFile` must stay `!Send + !Sync` (`call_printf` mutates via `&self`). `PollTable` must tolerate a null `self.table` pointer from `PollTable::from_raw` and pass it directly to `bindings::poll_wait`. [F459, F460, F462]
- `replace_fops(f, fops)` drops the old `f->f_op` module ref via `fops_put` without taking a new ref on `fops` (and `BUG_ON`s if NULL); call only in `->open()` where `fops` is non-NULL and already module-pinned. `super_operations.alloc_inode` must use `alloc_inode_sb(sb, cache, gfp)` rather than `kmem_cache_alloc` to bind to `sb->s_inode_lru`. [F368, F372]
- Callers not already holding a like-signed ref on `inode->i_writecount` or `mapping->i_mmap_writable` must acquire/release via `get_write_access`/`put_write_access`, `deny_write_access`/`allow_write_access`, `mapping_map_writable`/`mapping_unmap_writable`, or `mapping_deny_writable`/`mapping_allow_writable`. [F371]
- In `generic_write_sync()`, `iocb->ki_pos` is already advanced by `count`, so `vfs_fsync_range()` and `filemap_fdatawrite_range_kick()` require inclusive `[iocb->ki_pos - count, iocb->ki_pos - 1]`. Setting `RWF_SYNC` in `kiocb_set_rw_flags()` must also set `IOCB_DSYNC` in `ki->ki_flags` because `generic_write_sync()` gates on `iocb_is_dsync(iocb)` before checking `IOCB_SYNC` for `datasync = 0` vs `1`. [F384, F432]
- `file_operations` must not define both `mmap` and `mmap_prepare`: `can_mmap_file()` warns (`WARN_ON_ONCE`) and returns `false` if both are set, and must return `false` without warning if neither is set. Stacked `.mmap()` callbacks must call `vfs_mmap()` (which dispatches `mmap_prepare` via `compat_vma_mmap_prepare()`) rather than `realfile->f_op->mmap()` directly. [F388, F481, F482]
- `fs_ftype_to_dtype()` takes an `FT_*` value (`0..FT_MAX-1`), whereas `fs_umode_to_ftype()` and `fs_umode_to_dtype()` take a `umode_t` (`S_DT(mode)` shifts by `S_DT_SHIFT` = 12). `dir_emit_dots()` must use sequential `if (ctx->pos == 0)` and `if (ctx->pos == 1)` (not `else if`) and only advance `ctx->pos` after `dir_emit_dot()` / `dir_emit_dotdot()` succeeds. [F394, F433]
- Never write `inode->__i_nlink` directly (use `inc_nlink()`, `drop_nlink()`, `clear_nlink()`, `set_nlink()`, `inode_inc_link_count()`, or `inode_dec_link_count()`), nor access `inode->i_ctime_nsec` directly (use `inode_get_ctime_nsec()`, `inode_get_ctime()`, `inode_set_ctime()`, or `inode_set_ctime_to_ts()` because bit 31 is `I_CTIME_QUERIED`). [F484, F485]
- In `.setattr`, test `(attr->ia_valid & ATTR_FILE)` rather than `attr->ia_file != NULL`. Filesystems with `FS_ALLOW_IDMAP` must set/update `i_uid` and `i_gid` via `mnt_idmap` helpers (`inode_fsuid_set()`, `inode_fsgid_set()`, `i_uid_update()`, `i_gid_update()`, `ia_vfsuid`, `ia_vfsgid`). LSM-enforced anonymous inodes must use `anon_inode_make_secure_inode()`, not `alloc_anon_inode()` alone (which leaves `S_PRIVATE` set). [F488, F489, F490]
- `kiocb_set_rw_flags()` rejects `RWF_NOWAIT`, `RWF_ATOMIC`, and `RWF_DONTCACHE` with `-EOPNOTSUPP` unless `FMODE_NOWAIT`, `FMODE_CAN_ATOMIC_WRITE` (with `WRITE`), or `FOP_DONTCACHE` (non-`IS_DAX`) is set. `IOCB_HAS_METADATA` requires `FMODE_HAS_METADATA` at open, and `IOCB_ATOMIC` write paths must check per-I/O `IOCB_DIRECT` via `generic_atomic_write_valid()` since `O_DIRECT` can change via `fcntl()`. [F491, F492]
- In `init/do_mounts.c`, `do_mount_root()` must copy non-NULL `data` into an `alloc_page(GFP_KERNEL)` page via `strscpy_pad(data_page, data, PAGE_SIZE)` before `init_mount()`. Callers iterating `split_fs_names()` (`mount_root_generic`, `mount_nodev_root`) must advance `p` by `strlen(p) + 1` and skip empty entries (`if (!*p) continue;`). In `init/initramfs.c`, `dir_add()` takes `nlen` including the trailing NUL (e.g. `name_len`), not `strlen(name)`. [F398, F399, F444]

## Error Handling

- `ACL_NOT_CACHED` (`-1`), `ACL_DONT_CACHE` (`-3`), and `uncached_acl_sentinel(task)` (`task + 1`) all have bit 0 set (`is_uncached_acl(acl)`), and the first two satisfy `IS_ERR()`; ACL consumers must check `is_uncached_acl(acl)` and `IS_ERR_OR_NULL(acl)`. `address_space_operations` callbacks (`read_folio`, `writepage`) can return `AOP_WRITEPAGE_ACTIVATE` (`0x80000`, page left locked) or `AOP_TRUNCATED_PAGE` (`0x80001`, page unlocked; drop ref and retry), not just `< 0`. [F390, F391]
- In `init/initramfs.c`, `xwrite()` returns the positive byte count already written on partial write followed by error or `0`, so check `xwrite(file, buf, len, &pos) != len` rather than `< 0`. In `init/do_mounts_rd.c`, `identify_ramdisk_image()` returns `< 0` on error, `0` for compressed images (where `*decompressor` may still be `NULL` if unconfigured, which callers like `crd_load()` must check), and `> 0` for size in 1 KiB units. [F395, F400]
- In `init/do_mounts.c`, `rootwait_timeout_setup` must reject `sec < 0` and use `check_mul_overflow(sec, MSEC_PER_SEC, &root_wait)`, falling back to `root_wait = -1` (indefinite wait) on failure; `wait_for_root` must only check `ktime_after(ktime_get_raw(), end)` when `root_wait > 0`. [F439, F440]

## External Contracts

- Never change or reorder `DT_*` (bits 12..15 of `st_mode`, `DT_MAX == 16`) or `FT_*` (bits 0..2, `FT_MAX == 8`) in `include/linux/fs_types.h` (`getdents(2)` ABI and on-disk encodings). Extensible ioctl handlers must validate `cmd` with `extensible_ioctl_valid(cmd, canonical_cmd, min_size)` before `copy_struct_from_user()`. [F424, F495]
- In `init/initramfs.c`, `do_name()` and `do_symlink()` must verify `collected[name_len - 1] == '\0'` before passing `collected` to C-string APIs (logging failures with `%.*s` and `(int)name_len`), while permitting embedded NUL bytes before `name_len - 1` for cpio alignment padding. [F419, F445]

## Known Pitfalls

- Because `(file->f_mode & FMODE_FSNOTIFY_MASK) == (FMODE_NONOTIFY | FMODE_NONOTIFY_PERM)` suppresses only `FAN_ACCESS_PERM`, test full suppression with `FMODE_FSNOTIFY_NONE(mode)` (`(mode & FMODE_FSNOTIFY_MASK) == FMODE_NONOTIFY`) rather than `mode & FMODE_NONOTIFY`, and set bits via `file_set_fsnotify_mode()`. [F430]
- `inode_state_wait_address(inode, bit)` computes `(char *)&(inode)->i_state + (bit)`, so `inode_state_wait_address()`, `inode_bit_waitqueue()`, and `inode_wake_up_bit()` only accept `enum inode_state_bits` indices (`0..3`), never shifted `I_*` masks or bits `>= 4`. `is_zero_ino(ino)` must test `(u32)ino == 0` so 32-bit userspace on 64-bit kernels never sees a truncated zero `ino_t`. [F438, F449]
- In `mount_root_generic()`, when `do_mount_root()` fails with `-EACCES` or `-EINVAL`, call `init_flush_fput()` before retrying or continuing. In `rd_load_image()`, verify `nblocks > 0` and `devblocks != 0` before computing `(nblocks - 1) / devblocks + 1` and `i % devblocks`. [F435, F443]
