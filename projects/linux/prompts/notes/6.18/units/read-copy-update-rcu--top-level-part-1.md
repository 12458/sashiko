# READ-COPY UPDATE (RCU) — (top level) (part 1)

This component implements the core Linux RCU subsystem—Tree RCU, Tiny RCU, Tasks/Rude/Trace RCU, `rcu_segcblist`, and `rcu_sync`—plus the public APIs for RCU read sections, pointer publication, grace-period waiting/polling, `rcuref_t`, `rcuwait`, and RCU lists.

## Architecture & Data Flow

- In `struct rcu_segcblist`, `tails[seg]` points to the `->next` ending `seg` (or `&rsclp->head`); `RCU_DONE_TAIL` (0) spans `[rsclp->head, *tails[0])` while `seg > 0` spans `[*tails[seg - 1], *tails[seg])`. Segment emptiness uses pointer equality (`rcu_segcblist_segempty`), while trailing emptiness dereferences `*tails[seg]` (`rcu_segcblist_restempty`). `gp_seq[seg]` is valid only for non-empty `RCU_WAIT_TAIL` or `RCU_NEXT_READY_TAIL` (check `rcu_segcblist_nextgp()`'s bool return), and `rcu_segcblist_advance()` must shift `RCU_NEXT_READY_TAIL` into `RCU_WAIT_TAIL` so `RCU_WAIT_TAIL` is never empty when `RCU_NEXT_READY_TAIL` is non-empty. [F196, F208, F232, F276]
- `rcu_segcblist_extract_done_cbs()` iterates backwards from `RCU_CBLIST_NSEGS - 1` to `RCU_DONE_TAIL` when resetting `tails[i] = &rsclp->head` so `tails[0]` is updated last, whereas `rcu_segcblist_insert_done_cbs()` iterates forwards and `break`s at the first non-empty segment. `rcu_cblist_flush_enqueue()` must replace `srclp`'s head/tail/`len` with non-NULL `rhp` in place without calling `rcu_cblist_init(srclp)`. [F210, F248]
- Runtime traversal of `rcu_state.node[]` and `rcu_state.level[]` must bound by `rcu_num_nodes` and `rcu_num_lvls` (`rcu_for_each_node_breadth_first()`, `rcu_for_each_leaf_node()`), as `rcu_init_geometry()` can shrink them below `NUM_RCU_NODES`/`RCU_NUM_LVLS`. `rcu_init_geometry()` clamps `rcu_fanout_leaf` to `[2, BITS_PER_LONG]` with capacity `>= nr_cpu_ids`, and `NUM_RCU_LVL_*`, `num_rcu_lvl[i]`, and `levelspread[i]` must use ceiling division. [F235, F236, F269]
- In `rcu_report_qs_rnp()`, `(!(rnp->qsmask & mask) && mask)` must keep `&& mask` because `rcu_gp_init()` passes `mask == 0` when `rnp->wait_blkd_tasks` is set on an all-offline leaf node. Unlike `qsmaskinitnext`, a CPU's bit in `rnp->expmaskinitnext` is never cleared on offline, and `rcu_state.ncpus` in `rcutree_report_cpu_starting()` increments only when `!(rnp->expmaskinitnext & mask)`. [F218, F259]
- At GP completion, `rcu_future_gp_cleanup()` advances `rnp->gp_seq_needed` to `rnp->gp_seq` when `!ULONG_CMP_LT(rnp->gp_seq, rnp->gp_seq_needed)`, and `rcu_exp_wait_wake()` advances `rnp->exp_seq_rq` to `s` when `ULONG_CMP_LT(rnp->exp_seq_rq, s)`. Index `rnp->exp_wq[4]` by `rcu_seq_ctr(s) & 0x3` (not `s & 0x3`). Clearing `rdp->rcu_forced_tick` or `rcu_forced_tick_exp` under `rdp->mynode->lock` must call `tick_dep_clear_cpu()` (`TICK_DEP_BIT_RCU` / `TICK_DEP_BIT_RCU_EXP`). [F212, F237, F272]
- `get_state_synchronize_rcu_full()` snapshots `rgosp->rgos_norm` from `rcu_state.gp_seq`, whereas `poll_state_synchronize_rcu_full()` tests it against root `rnp->gp_seq` via `rcu_seq_done_exact()` (`2 * RCU_SEQ_GP` guardband). When `rcu_poll_gp_seq_end()` ends a polled GP (`*snap && *snap == rcu_state.gp_seq_polled`), zero both `gp_seq_polled_snap` and `gp_seq_polled_exp_snap` under root `rnp->lock`; if `*snap != gp_seq_polled`, zero `*snap` without `rcu_seq_end()`. [F204, F213]
- `rcu_state.srs_next` mixes `struct rcu_synchronize` requests with dummy wait-heads from `srs_wait_nodes[]`; test `rcu_sr_is_wait_head(node)` before `rcu_sr_normal_complete()` or `rcu_sr_put_wait_head()`. Per-CPU `barrier_head.next` and `barrier_q_head.next` must init and reset to self in `rcu_barrier_callback()` and `rcu_barrier_tasks_generic_cb()` (`rcu_barrier_cb_is_done()` tests `rhp->next == rhp`). [F200, F239]
- In `struct rcu_tasks`, `rtp->rtpcp_array` is dense (indexed by `rtpcp->index`), whereas `rtp->rtpcpu` is indexed by sparse `rtpcp->cpu < rcu_task_cpu_ids` bounded by `percpu_dequeue_lim`. `cblist_init_generic()` clamps `lim` to `[1, rcu_task_cpu_ids]` and increments `shift = ilog2(rcu_task_cpu_ids / lim)` if `((rcu_task_cpu_ids - 1) >> shift) >= lim`. When shrinking queues in `rcu_tasks_need_gpcb()`, set `percpu_enqueue_lim = 1` and snapshot `percpu_dequeue_gpseq` first; lower `percpu_dequeue_lim = 1` only after `poll_state_synchronize_rcu()` and CPUs > 0 have zero callbacks. [F223, F238, F268]
- In RCU Tasks Trace, `rcu_read_unlock_trace()` sets `current->trc_reader_nesting = INT_MIN + nesting` after `barrier()` before reading `trc_reader_special.s`, so `trc_read_check_handler()` and `trc_inspect_reader()` must back off when `nesting < 0` and `rcu_tasks_trace_qs()` must check `___rttq_nesting != INT_MIN`. `rcu_read_unlock_trace_special()` transitions `need_qs` to `TRC_NEED_QS_CHECKED` (never `0`) and clears `blocked` before restoring `trc_reader_nesting = 0`. Update `per_cpu(trc_ipi_to_cpu, cpu)` and `t->trc_ipi_to_cpu` (`true`/`cpu` vs `false`/`-1`) in lockstep. [F205, F226, F254, F314]
- In `rcu_sync_func()`, check `if (rsp->gp_count)` before `else if (rsp->gp_state == GP_REPLAY)`, and in `rcu_sync_exit()` when `--rsp->gp_count == 0` in `GP_EXIT`, set `gp_state = GP_REPLAY` instead of calling `rcu_sync_call(rsp)`. `rcuref_t` biases `refcnt` by `-1` (`rcuref_init()` sets `cnt - 1`; `rcuref_read()` returns `c >= RCUREF_RELEASED ? 0 : c + 1`) so negative signed values mark zero/saturated/dead zones in `__rcuref_put()`. In `rculist_nulls.h`, list-end checks must test `!is_a_nulls()` rather than non-NULL. [F246, F249, F273]

## Synchronization

- Every `rcu_node` and `rcu_tasks_percpu` `->lock` must use `raw_spin_lock*_rcu_node()` / `raw_spin_unlock*_rcu_node()` with IRQs disabled. `rcu_report_qs_rnp()`, `rcu_report_unblock_qs_rnp()`, `__rcu_report_exp_rnp()`, and `rcu_report_exp_cpu_mult()` consume `rnp->lock` and restore IRQs on all paths, whereas `rcu_start_this_gp()` returns with `rnp_start->lock` still held and returns `true` when the caller must call `rcu_gp_kthread_wake()` after releasing all `rcu_node` locks. [F145, F146, F296, F300]
- For CPU hotplug (`rcu_gp_init()`, `rcutree_report_cpu_starting()`, `rcutree_report_cpu_dead()`), acquire `rcu_state.ofl_lock` with IRQs disabled before `barrier_lock` or leaf `rnp->lock`. Under `ofl_lock` and `rnp->lock`, `rcutree_report_cpu_starting()` sets `qsmaskinitnext` before `rcu_report_qs_rnp()`, whereas `rcutree_report_cpu_dead()` calls `rcu_report_qs_rnp()` before clearing `qsmaskinitnext`. In `rcu_gp_init()`, `rcu_sr_normal_gp_init()` and `rcu_seq_start(&rcu_state.gp_seq)` must run under root `rnp->lock` in that order before scanning leaf `qsmaskinitnext` masks. [F171, F217, F298]
- In `rcu_barrier_entrain()` and `rcutree_migrate_callbacks()`, lock order is `barrier_lock` -> `rdp->nocb_lock` -> leaf `rnp->lock`, and `wake_nocb_gp()` / `__call_rcu_nocb_wake()` must not be called under `rnp->lock` or `nocb_lock`. `rcu_nocb_lock_irqsave()` must call `local_irq_save()` before testing `rcu_segcblist_is_offloaded(&rdp->cblist)`. `rcu_gp_cleanup()` and `__note_gp_changes()` must not call `rcu_accelerate_cbs()` / `rcu_advance_cbs()` when `rcu_rdp_is_offloaded(rdp)` is true without `rdp->nocb_lock`. [F168, F173, F299]
- In `rcu_sr_normal_gp_cleanup()`, increment `srs_cleanups_pending` before `queue_work()` and decrement if `false`; access `srs_done_tail` with release-acquire ordering, and keep the `done` dummy node (`done->next = NULL`) in `rcu_sr_normal_gp_cleanup_work()`. In `rcu_exp_wait_wake()`, hold `exp_wake_mutex` before `rcu_exp_gp_seq_end()` until all `exp_seq_rq` updates and `wake_up_all(&rnp->exp_wq[...])` finish. In `sync_rcu_exp_select_cpus()`, reset `rnp->exp_need_flush = false` and set `true` only when queueing onto `rnp->exp_kworker` (never `rcu_exp_gp_kworker`). [F152, F175, F176, F262]
- Bracket `rcu_segcblist_add_len()` and `rcu_segcblist_inc_len()` with full `smp_mb()` barriers unless hotplug lock is held (`rcu_segcblist_merge()`). `rcu_barrier()` and `rcu_barrier_tasks_generic()` must init `barrier_cpu_count` / `barrier_q_count` to `2` before the entrain loop and finish with `atomic_sub_and_test(2, ...)`, and `rcu_barrier_callback()` must sample `barrier_sequence` before `atomic_dec_and_test(&rcu_state.barrier_cpu_count)`. [F222, F260, F310]
- In `call_rcu_tasks_generic()`, never acquire `rtp->cbs_gbl_lock` under `rtpcp->lock`, and keep `percpu_enqueue_shift` reading and `rcu_segcblist_enqueue()` inside `rcu_read_lock()`. `exit_tasks_rcu_finish()` must lock `per_cpu_ptr(rcu_tasks.rtpcpu, t->rcu_tasks_exit_cpu)` (not `this_cpu_ptr()`). When `rcu_tasks_postscan()` drops `rtpcp->lock` for `cond_resched()` on `rtp_exit_list`, anchor an on-stack `struct list_head tmp` after `t` and refresh `t1` after relocking; no other code may iterate `rtp_exit_list` and downcast nodes to `struct task_struct`. [F160, F178, F224, F284]
- In Tasks Trace RCU, `rcu_tasks_trace_pregp_step()` and `check_all_holdout_tasks_trace()` must hold `cpus_read_lock()`, and `rcu_tasks_trace_postgp()` must wait for `per_cpu(trc_ipi_to_cpu, cpu)` to clear. `rcu_tasks_trace_pregp_step()` must splice `rtpcp->rtp_blkd_tasks` to a local list and move each `t` back under `rtpcp->lock` and `rcu_read_lock()` before unlocking `rtpcp` for `rcu_tasks_trace_pertask()`. In `__list_splice_init_rcu()`, call `INIT_LIST_HEAD_RCU(list)` and `sync()` before mutating `last->next` and publishing `first`. [F180, F187, F225]

## Object Lifetimes

- After `rcu_segcblist_extract_done_cbs()`, `rcu_do_batch()` and `rcu_tasks_invoke_cbs()` must reinsert uninvoked callbacks via `rcu_segcblist_insert_done_cbs()` and subtract the invoked count via `rcu_segcblist_add_len()`. `rcutree_migrate_callbacks()` must merge all callbacks via `rcu_segcblist_merge()` before `rcu_segcblist_disable()`. Callers of `*list*_del*_rcu()` or `*list_replace_rcu()` must wait for a grace period before freeing the old entry. [F147, F154, F306]
- In `synchronize_rcu_normal()`, stack `struct rcu_synchronize rs` requires `init_rcu_head_on_stack(&rs.head)` before `rcu_sr_normal_add_req(&rs)` and `destroy_rcu_head_on_stack(&rs.head)` after `wait_for_completion(&rs.completion)`; `rcu_sr_normal_complete()` and callers must read `rcu->next` and `rs->oldstate` before `complete()`. In `wait_rcu_exp_gp()`, read stack `rewp->rew_s` before `rcu_exp_sel_wait_wake()`. [F153, F282, F283]
- In Classic RCU Tasks, `rcu_tasks_postscan()` must check `list_empty(&t->rcu_tasks_holdout_list)` before `rcu_tasks_pertask()` (`get_task_struct(t)`), and `check_holdout_task()` calls `put_task_struct(t)` after `list_del_init()`. In Tasks Trace, `trc_add_holdout()` and `trc_del_holdout()` guard task refs and `n_trc_holdouts` with `list_empty(&t->trc_holdout_list)`, and `trc_wait_for_one_reader()` must balance `get_task_struct(t)` around `task_call_func()` with `put_task_struct(t)` on both return paths. [F158, F159]
- Pair `prepare_to_rcuwait(w)` with `finish_rcuwait(w)` on all paths (serializing writers to `w->task`). `rcu_sync_is_idle()` requires `rcu_read_lock_any_held()`, while `rcu_sync_dtor()` requires sleepable context (`gp_count == 0`), transitions `GP_REPLAY` to `GP_EXIT` under `rss_lock`, and calls `rcu_barrier()` if `!GP_IDLE`. `rcu_tasks_kthread()` must init all `rtpcp->lazy_timer`s before `smp_store_release(&rtp->kthread_ptr, ...)`, and `tasks_cblist_init_generic()` runs in `rcu_init()` before `call_rcu_tasks_generic()`. [F164, F182, F288, F289, F309]

## API Contracts

- Vanilla `rcu_read_lock*()`/`unlock*()` require `rcu_is_watching()` (never idle/EQS; use `rcu_read_lock_trace()`). Never sleep or call `synchronize_rcu*()`, `rcu_softirq_qs()`, or single-arg `k[v]free_rcu_mightsleep()` in RCU read or atomic contexts (use two-arg `k[v]free_rcu(ptr, rhf)` with `rhf` offset `< 4096`); RCU callbacks run with BH disabled and cannot sleep. `rcu_momentary_eqs()` (non-EQS only) and `rcu_virt_note_context_switch()` require IRQs disabled. `rcu_is_watching()`, `rcu_read_*_sched_notrace()`, and `rcu_lockdep_current_cpu_online()` must use `preempt_*_notrace()`. [F293, F294, F295, F311, F315, F316]
- `rcu_dereference_protected()` requires holding the update-side lock (never just `rcu_read_lock()`). `RCU_INIT_POINTER(p, v)` has no ordering and is valid only for `NULL`, when readers cannot access `p`, or when `*v` is already published and unchanged. `rcuref_get()` requires RCU/memory stability and checking its bool return; `rcuref_put_rcusafe()` requires `rcu_read_lock()` or atomic context (else use `rcuref_put()`); never free on `rcuref_read() == 0` (check `rcuref_put*()` return or `rcuref_is_dead()`). [F183, F184, F192, F304, F307]
- `call_rcu*()` requires `sizeof(void *)`-aligned `rcu_head *`. `rcu_head_after_call_rcu(rhp, f)` requires prior `rcu_head_init(rhp)` and cannot race with or follow callback execution. `rcu_segcblist_extract_done/pend_cbs()` require pre-initialized destination `rcu_cblist`. Lists using `list_bidir_prev_rcu()` must use `list_bidir_del_rcu()` (never `list_del/replace_rcu()`). `list_for_each_entry_continue/from_rcu()` requires `pos` to be valid since `rcu_read_lock()` entry. `hlist_bl_head` requires `hlist_bl_first_rcu()` and `hlist_bl_set_first_rcu()` (with bit 0 of node clear). [F198, F199, F203, F241, F245, F278]
- `exp_funnel_lock()` returns `true` with `exp_mutex` unlocked if GP `s` is done, and `false` with `exp_mutex` held and `rcu_exp_gp_seq_start()` called otherwise. `force_qs_rnp()` callbacks (`rcu_watching_snap_save()`, `rcu_watching_snap_recheck()`) return signed tri-state `int` (`> 0` QS, `< 0` `resched_cpu()`, `0` none). [F189, F190]

## Error Handling

- If `rcu_segcblist_entrain()` returns `false` in `rcu_barrier_entrain()`, call `debug_rcu_head_unqueue(&rdp->barrier_head)` without incrementing `barrier_cpu_count`. Clear `IS_ERR_OR_NULL()` kworker returns to `NULL` in `rcu_spawn_exp_par_gp_kworker()` and `rcu_start_exp_gp_kworker()`. `trc_inspect_reader()` returns `0` on success / `-EINVAL` on error, whereas `trc_check_slow_task()` returns `true` (`1`) on success / `false` (`0`) when `*trc_rdrp` is uninitialized. [F148, F188, F193]

## External Contracts

- `rcutree_report_cpu_starting()` and `rcutree_report_cpu_dead()` must run on the transitioning CPU with IRQs disabled, with no RCU read sections before `starting` or after `dead`. In `rcupdate_trace.h`, `call_rcu_tasks_trace()`, `rcu_read_lock_trace()`, and `rcu_read_unlock_trace()` must remain defined as `BUG()` stubs when `!CONFIG_TASKS_TRACE_RCU` for BPF JIT. [F312, F320]

## Known Pitfalls

- Use `rcu_segcblist_n_cbs()` rather than `rcu_segcblist_empty()` when accounting for in-flight extracted callbacks (`rcu_barrier()`, `rcu_segcblist_entrain()`). Use `list_first_or_null_rcu()` in lockless readers instead of `!list_empty()` + `list_first_entry()`. `for_each_leaf_node_cpu_mask()` and `leaf_node_cpu_bit()` take global `cpu` in `[rnp->grplo, rnp->grphi]` and node-relative `mask`, whereas `rcu_find_next_bit(rnp, cpu, mask)` takes a 0-based offset `cpu - rnp->grplo` and returns a global CPU ID. [F197, F234, F244, F251, F264]
- In `rcu_print_task_exp_stall()` and `rcu_exp_print_detail_task_stall_rnp()`, init `t = list_entry(rnp->exp_tasks->prev, struct task_struct, rcu_node_entry)` without dereferencing `t` before `list_for_each_entry_continue()`. Mask `gp_seq` and `expedited_sequence` with `0xffffULL` / `0xffffffULL` before shifting in `rcutorture_gather_gp_seqs()`, clamp local `rcu_divisor` to `[0, sizeof(long) * 8 - 2]` in `rcu_do_batch()`, and check `delay > 0` before modulo in `rcu_gp_slow()`. [F261, F263, F265, F267]
