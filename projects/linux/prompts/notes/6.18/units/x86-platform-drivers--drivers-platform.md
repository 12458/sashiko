# X86 PLATFORM DRIVERS — drivers/platform

This component contains x86 and OLPC platform drivers (OLPC EC, AMD ISP4/WBRF, Apple gmux, Dell SMBIOS/WMI/UART backlight, HP/Huawei WMI, Inspur platform profiles, and Intel IFS/TPMI/SoC power and GPIO drivers) bridging vendor firmware with standard Linux subsystems.

## Architecture & Data Flow
- In `dell-smbios-base.c`, `parse_da_table()` must ignore DMI `0xda` records with `dm->length < 17` and append `(dm->length - 11) / sizeof(struct calling_interface_token) - 1` tokens to `da_tokens`. `build_tokens_sysfs()` must run only after `dmi_walk(find_tokens, NULL)` finishes all `krealloc()` calls on `da_tokens` (`token_entries[i].token` caches `&da_tokens[i]`). [F65, F79]
- In `intel/ifs/`, `IFS_TYPE_ARRAY_BIST` has `.test_msrs = NULL`, so `ifs_get_test_msrs(dev)` must never be dereferenced on paths shared with array BIST. `doscan()` and `ifs_test_core()` must select `.gen2` on `union ifs_scan`/`union ifs_status` when `ifsd->generation != 0` and `.gen0` when `0` (clearing `activate.gen0.rsvd = 0`). `ifs_load_firmware()` must set `ifsd->loaded = (ret == 0)` on every exit path, and `find_meta_data()` must stop when `meta_header->type == MC_HEADER_META_TYPE_END`, `blk_size == 0`, or `meta_size >= total_meta`. [F51, F52, F66, F91]
- In `ifs_test_core()`, `ifs_array_test_core()`, and `ifs_sbaf_test_core()`, check retry deadlines with `time_after(jiffies, timeout)`. In `ifs_sbaf_test_core()`, `sbaf_bundle_completed(status)` must set `activate.bundle_idx = status.bundle_idx + 1`, `activate.pgm_idx = 0`, and `retries = MAX_IFS_RETRIES`, while partial progress (`status.pgm_idx != activate.pgm_idx`) updates both indices and resets `retries`. [F98, F114]
- In `tpmi_power_domains.c`, `tpmi_power_domain_mask` and `domain_die_map` are sized by `topology_max_packages() * MAX_POWER_DOMAINS`; `tpmi_get_logical_id()` must set `info->pkg_id` via `topology_logical_package_id(cpu)` and callers must validate `pkg_id < topology_max_packages()` and `domain_id < MAX_POWER_DOMAINS`. [F77]
- In `apple-gmux.c`, `gmux_get_brightness()` must mask `GMUX_PORT_BRIGHTNESS` with `GMUX_BRIGHTNESS_MASK`, and `gmux_probe()` must cap `props.max_brightness` to `GMUX_MAX_BRIGHTNESS`. On `APPLE_GMUX_TYPE_MMIO`, `gmux_probe()` must force `iolen = 16` and `max_brightness = MMIO_GMUX_MAX_BRIGHTNESS` (`0xffff`); `gmux_mmio_read32()`/`write32()` must use `ioread32be()`/`iowrite32be()` under `index_lock`, and `gmux_clear_interrupts()` must invoke ACPI `"GMSP"` with `0` after writing `GMUX_PORT_INTERRUPT_STATUS`. When `!external_switchable`, `gmux_switchto()` must keep `switch_state_external` at `VGA_SWITCHEROO_DIS`. [F75, F115, F138, F139]
- In `gmux_probe()`, `dell_uart_bl_pdev_probe()`, and `oaktrail_init()`, gate `backlight_device_register()` on `acpi_video_get_backlight_type()`. In `dell_uart_bl_receive()`, `RESP_LEN` must satisfy `MIN_RESP_LEN <= resp_len <= resp_max_len` before storing bytes, and `resp[resp_len - 1]` must match `dell_uart_checksum(resp, resp_len - 1)`. [F89, F137]
- In `hp-wmi.c`, Omen/Victus profile setters must update `active_platform_profile` under `active_platform_profile_lock`, and `platform_profile_omen_get()`/`victus_get()` must return `active_platform_profile`. On `has_omen_thermal_profile_ec_timer()` boards, `platform_profile_omen_set_ec()` must call `omen_thermal_profile_ec_timer_set(0)` and `omen_thermal_profile_ec_flags_set()` after `omen_thermal_profile_set()`. `victus_s_gpu_thermal_profile_set()` must populate `gpu_slowdown_temp` via `victus_s_gpu_thermal_profile_get()` first. `hp_wmi_rfkill2_setup()` must reject `state.count > HPWMI_MAX_RFKILL2_DEVICES` (`7`), and `hp_wmi_rfkill2_refresh()` must check `rfkill2[i].num < state.count` and `state.device[num].rfkill_id == rfkill2[i].id`. [F68, F69, F70, F85]
- In `huawei-wmi.c`, `huawei_wmi_battery_get()` must stop its reverse scan of `ret[0x100]` at `i > 2` (skipping `ret[0]`), and `huawei_wmi_fn_lock_get()` must scan `i = 1` while `i < 0xff`. [F83]
- In `olpc_ec_suspend()`/`olpc_xo175_ec_suspend()`, run pre-suspend EC commands before setting `suspended = true`, and clear `suspended` on resume before resume EC commands. `olpc_ec_mask_write()`/`olpc_ec_sci_query()` may only use 2-byte big-endian `EC_WRITE_EXT_SCI_MASK`/`EC_EXT_SCI_QUERY` when `ec->version >= 0x5f`. `olpc_xo175_ec_cmd()` requires `inlen <= 5` and must wait for `nr_bytes` from `olpc_xo175_ec_resp_len(cmd)` before copying `min(resp_len, nr_bytes)`. In `ec_dbgfs_cmd_write()`, reset `ec_dbgfs_resp_bytes = 0` under `ec_dbgfs_lock` if `sscanf()` parses `< 2` items or `> EC_MAX_CMD_REPLY`. [F61, F62, F92, F140]
- In `amd_isp4.c`, `i2c_bus_type` callbacks (`isp_i2c_bus_notify()`, `try_to_instantiate_i2c_client()`) must check `i2c_verify_adapter()`/`i2c_verify_client()` before downcasting, and `swnodes` arrays (e.g. `amd_isp4_nodes`) must place the root camera at `[0]`, sensor at `[6]`, and end with `NULL`. [F95, F122]
- In `crc_pwrsrc_probe()`, read and clear `CRYSTALCOVE_RESETSRC0_REG`, `RESETSRC1_REG`, and `WAKESRC_REG` via `crc_pwrsrc_read_and_clear()` at probe time. In `ibm_rtl_exit()`, call `ibm_rtl_write(0)` before sysfs teardown and unmapping `ebda_map`/`rtl_cmd_addr`. [F131, F134]

## Synchronization
- In `intel/ifs/`, hold `ifs_sem` across `do_core_test()` and `ifs_load_firmware()`, and acquire it before `cpus_read_lock()` in `do_core_test()` and `scan_chunks_sanity_check()`; every exit path after `cpus_read_lock()` must jump to `out:` to unlock. Reset `scan_cpus_in`/`array_cpus_in`/`sbaf_cpus_in` to `0` via `atomic_set()` before each `stop_core_cpuslocked()` retry. `doscan()` and `dosbaf()` must sync SMT siblings via `wait_for_sibling_cpu()` before all threads write `MSR_ACTIVATE_SCAN`/`SBAF`, whereas only `cpumask_first(cpu_smt_mask(cpu))` records results or writes `MSR_ARRAY_BIST`. In `copy_hashes_authenticate_chunks_gen2()`, wrap `wrmsrq(msrs->copy_chunks, ...)` in `local_irq_disable()` and retry up to `IFS_AUTH_RETRY_CT` times on `AUTH_INTERRUPTED_ERROR`. [F5, F31, F67, F146, F148]
- In `olpc-ec.c`, `ec->cmd_q_lock` (`spin_lock_irqsave()`) protects `ec->cmd_q` and must be released before `olpc_ec_worker()` takes mutex `ec->cmd_lock` for `ec_driver->ec_cmd()`. In `olpc_xo175_ec_probe()`, initialize `cmd_state_lock`, `cmd_done`, `xfer`, and `olpc_ec_driver_register()` before registering the `olpc-ec` pdev and calling `olpc_xo175_ec_set_event_mask()`. [F23, F25]
- In `apple-gmux.c`, all indexed and MMIO port accessors must hold `gmux_data->index_lock`. `init_completion(&gmux_data->powerchange_done)` must precede `gmux_enable_interrupts()` in `gmux_probe()`, and `reinit_completion()` must precede writing `GMUX_PORT_DISCRETE_POWER` in `gmux_set_discrete_state()`. In `gmux_remove()`, unregister debugfs, `vga_switcheroo`, interrupts, GPE/notify handler, and backlight before unmapping `iomem_base`, releasing I/O, clearing `apple_gmux_data`, and freeing `gmux_data`. [F26, F27, F28]
- In `tpmi_power_domains.c`, `tpmi_lock` protects `tpmi_cpu_hash` and `tpmi_power_domain_mask`, and `tpmi_exit()` must call `cpuhp_remove_state()` before freeing `tpmi_power_domain_mask` and `domain_die_map`. In `plr_tpmi.c`, skip dies with `PLR_HEADER == PLR_INVALID`, and hold `plr_die->lock` in `plr_read_cpu_status()`/`plr_clear_cpu_status()` while polling `PLR_MAILBOX_INTERFACE` until `PLR_RUN_BUSY` clears. [F33, F141]
- In `turbo_max_3.c`, `itmt_legacy_cpu_online()` must defer `sched_set_itmt_support()` via `schedule_work(&sched_itmt_work)`. In `int0002_vgpio.c`, `int0002_irq()` runs in hardirq context and must use `generic_handle_domain_irq_safe()` and `pm_wakeup_hard_event()` without sleeping. [F35, F156]
- In `dell-lis3lv02d.c`, `instantiate_i2c_client()` must use `bus_for_each_dev(&i2c_bus_type, ...)` (not `i2c_for_each_dev()`), and `dell_lis3lv02d_module_exit()` must call `bus_unregister_notifier()` and `cancel_work_sync(&i2c_work)` before `i2c_unregister_device()`. In `dell_uart_bl_serdev_probe()`, call `serdev_device_set_drvdata()` and `serdev_device_set_client_ops()` before `devm_serdev_device_open()`. [F37, F125]

## Object Lifetimes
- In `dell-smbios-base.c`, `dell_smbios_register_device()`/`unregister_device()` must update `smbios_device_list` under `smbios_mutex` while balancing `get_device()`/`put_device()`, and `dell_smbios_call()` must hold `smbios_mutex` across backend selection and `selected->call_fn(buffer)`. [F135]
- In `olpc_ec_cmd()`, stack-allocated `struct ec_cmd_desc desc` is queued on `ec->cmd_q`, so it must wait uninterruptibly via `wait_for_completion(&desc.finished)`. [F7]
- In `huawei-wmi.c`, init rollback and `huawei_wmi_exit()` must unregister the platform device and driver before `kfree(huawei_wmi)`. [F9]
- In `cht_int33fe_typec.c`, `cht_int33fe_add_nodes()` must set `fusb302_mux_refs[0].node` before `software_node_register_node_group()`. Probe rollback and `cht_int33fe_typec_remove()` must call `i2c_unregister_device()` on `pi3usb30532`, `fusb302`, and `battery_fg` in reverse order before `cht_int33fe_remove_nodes()` unregisters `node_group`, puts/clears `fusb302_mux_refs[0].node`, and clears `data->dp->secondary = NULL` before putting `data->dp`. [F11, F73]
- In `amd_isp4.c`, `isp_i2c_bus_notify()` must clear `isp4_platform->i2c_dev = NULL` under `isp4_platform->lock` on `BUS_NOTIFY_REMOVED_DEVICE`, and `amd_isp_remove()` must unregister `i2c_nb` before `i2c_unregister_device()` and `software_node_unregister_node_group()`. [F12]
- In `dell_uart_bl_pdev_probe()`, call `put_device(ctrl_dev)` after `serdev_device_alloc()`, and after `serdev_device_add()`, rollback and remove must call `serdev_device_driver_unregister()` then `serdev_device_remove()`. [F15]
- In `crystal_cove_charger_probe()`, `irq_domain_create_linear()`, `devm_add_action_or_reset(..., crystal_cove_charger_rm_irq_domain, ...)`, `charger_irq` chip setup, and initial `MCHGRIRQ_REG` masking must all precede `devm_request_threaded_irq()`. [F21, F38]

## API Contracts
- In `dell-smbios-base.c`, `dell_smbios_find_token()` returns a borrowed pointer into `da_tokens` (never `kfree()` or use after exit). `dell_smbios_call()` returns only transport status, so callers must use `dell_send_request()` or `dell_smbios_error(buffer->output[0])`. Backends must pass priority to `dell_smbios_register_device(d, priority, call_fn)` (not `d->id`) with `int (*call_fn)(struct calling_interface_buffer *)`. `dell_smbios_call_filter()` and `dell_smbios_class_is_supported()` must reject `class > 30` before `1 << class`, and `dell_smbios_call_filter()` must check `token_blacklist`/`token_whitelist` before `call_whitelist`. [F3, F46, F64, F80, F100, F120]
- In `hp-wmi.c`, `hp_wmi_perform_query()` requires `buffer` `>= max(insize, outsize)` with `outsize <= 4096` (allocating `max(insize, 128)` data bytes) and returns `0`, negative errno, or positive `bios_return->return_code` (callers must map positive returns to negative errnos). `hp_wmi_hwmon_read()`/`write()` must invert hwmon PWM values (`0` full, `2` auto) and HP WMI max-fan states (`1` max, `0` auto). Every `platform_profile_ops.profile_get` callback (`hp-wmi.c`, `inspur_platform_profile.c`) must store the profile in `*profile` and return `0`. [F44, F84, F163, F168]
- In `huawei-wmi.c`, `huawei_wmi_cmd()` copies into `buf` even when status `buf[0] != 0` (returning `-ENODEV`), so callers must check the return value and read payload from `buf[1]`. `huawei_wmi_battery_set()` must validate `start` and `end` in `[0, 100]`. [F47, F81]
- In `intel/ifs/`, `validate_ifs_metadata()` must enforce `IS_ALIGNED(ifs_test_image_ptr, IFS_CHUNK_ALIGNMENT)` (256 bytes, as chunk index `i` is ORed into `linear_addr`) and `starting_chunk` as a multiple of non-zero `chunks_per_stride`. `scan_chunks_sanity_check()` must use `INIT_WORK_ONSTACK(&local_work.w, ...)`. Symbols in `tpmi_power_domains.c` use `EXPORT_SYMBOL_NS_GPL(..., "INTEL_TPMI_POWER_DOMAIN")`. [F53, F90, F165, F176]
- Use `apple_gmux_detect()` (not `apple_gmux_present()` or `_HID` alone) to detect gmux hardware. In `wbrf_record()`, `in->num_of_ranges` must match the count of non-zero `in->band_list` entries. In `int0002_vgpio.c`, pass `IRQF_ONESHOT | IRQF_SHARED` to `devm_request_irq()`, and gate `enable_irq_wake()`/`disable_irq_wake()` on `!pm_suspend_via_firmware() && wake_enable_count`. In Intel SoC PMIC child drivers, pass `platform_get_irq(pdev, 0)` directly to `devm_request_threaded_irq()`. [F87, F136, F143, F144]

## Error Handling
- In `dell-smbios-base.c`, `build_tokens_sysfs()` frees all partial allocations on error (including `location_name` when `value_name` fails), so `fail_sysfs` in `dell_smbios_init()` must not call `free_group()`. [F2, F101]
- In `intel/ifs/`, once `request_firmware_direct()` succeeds in `ifs_load_firmware()`, all error paths must jump to `release:` for `release_firmware(fw)`. Zero-initialize `union ifs_status`/`ifs_sbaf_status status = {}` in `ifs_test_core()` and `ifs_sbaf_test_core()` before retry loops. [F4, F40]
- In `olpc_ec_probe()`, jump to `error:` on failure after setting `ec_priv = ec` to clear `ec_priv` and `kfree(ec)`. In `ec_dbgfs_cmd_write()`, zero-initialize `char cmdbuf[64] = ""` before `simple_write_to_buffer()`. [F6, F43]
- In `huawei_wmi_battery_add()` and `irst_add()`, roll back the first `device_create_file()` if the second fails. In `huawei-wmi.c`, check `acpi_status` with `ACPI_FAILURE()` and assign `arg.cmd` before `arg.args[2]`/`[3]` on `union hwmi_arg`. In `hp_wmi_perform_query()`, jump to `out_free:` on all paths after `kmalloc()`. [F8, F17, F42, F48]
- In `intel_plr_probe()`, jump to `err:` to remove `plr->dbgfs_dir` on per-die loop failure. In `tpmi_init()`, set `ret = -ENOMEM` on `kcalloc()` failure after `rdmsrq_safe()`. In `tpmi_cpu_online()` and `itmt_legacy_cpu_online()`, return `0` on MSR/mailbox errors. [F19, F39, F54]
- In `apple-gmux.c`, set `gmux_data->gpe = -1` if `GMGP` fails and check `gpe >= 0` on wait/teardown paths; map non-zero `copy_from_user()` to `-EFAULT` in `gmux_selected_port_data_write()`. In `cht_int33fe_typec_probe()`, use `regulator_get_optional()`, mapping `-ENODEV` to `-EPROBE_DEFER` and calling `regulator_put()` on success. [F41, F55, F58]

## External Contracts
- In `dell-smbios-base.c`, `dell_smbios_call_filter()` must reject invalid/blacklisted calls with `-EINVAL` before checking `capable(CAP_SYS_RAWIO)` (`-EACCES`), and `location_show()`/`value_show()` must require `capable(CAP_SYS_ADMIN)` (`-EPERM`). `dell_led_blink()` must round delays with `DIV_ROUND_UP(..., 125)` and clamp to `[1, 255]`. [F111, F166, F167]
- `huawei_wmi_cmd()` requires an `ACPI_TYPE_BUFFER` of length `0x104` or a 2-element `ACPI_TYPE_PACKAGE` with buffer `elements[1]`, copying `min(buflen, len)`. `hp_wmi_notify()` requires buffer length `8` (`event_data` at `location[1]`) or `16` (`location[2]`). `amd_wbrf_retrieve_freq_band()` requires `4 <= obj->buffer.length <= sizeof(struct amd_wbrf_ranges_out)`. `gmux_selected_port_data_write()` must reject `*ppos != 0` or sizes other than `1` or `4` with `-EINVAL`. [F82, F86, F88, F177]

## Known Pitfalls
- In `dell-smbios-base.c`, `location_show()`/`value_show()` must use `container_of(attr, struct token_sysfs_data, ...)->token` (not `token_attrs` index). `dell_smbios_call()` must save the chosen backend in `selected` (not dereferencing loop cursor `priv`), and `dell_smbios_unregister_device()` must use `list_for_each_entry_safe()`. [F78, F106]
- In `hp-wmi.c`, `IS_HWBLOCKED(x)` must be `((x & HPWMI_POWER_FW_OR_HW) != HPWMI_POWER_FW_OR_HW)`; `hp_wmi_get_fan_speed()` must cast `char fan_data` bytes to `u8` before shifting; `zero_if_sup(tmp)` must not be passed a pointer; `hp_wmi_driver` requires `__refdata`. [F99, F108, F117, F142]
- Cast typed pointers (`ifs_header_ptr`, `meta_header`, `ifs_meta`) to `void *`/`u64` before adding byte offsets in `intel/ifs/load.c`; use 64-bit shifts/`BIT_ULL()` for `MSR_OC_MAILBOX` in `get_oc_core_priority()`; use `BITMAP_FROM_U64(val)` in `plr_print_bits()`. In `olpc_xo175_ec_complete()`, `CHAN_NONE` and `CHAN_SWITCH` must `return;` rather than `break;`. Format bounded strings with `"%.*s"` (not `"%s"` or `"%*s"`). [F102, F113, F119, F123, F124]
