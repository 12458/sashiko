# EDAC-CORE — drivers/edac

Provides the core EDAC subsystem for memory controllers, generic non-memory ECC devices, PCI parity checking, debugfs error injection, and RAS feature sysfs attributes (ECS, memory repair, scrub), plus hardware drivers for Altera/Intel SoCFPGA, Freescale DDR/Layerscape, IBM CPC925, AMD 76x, and Intel 3200/5100/82860/82875p.

## Architecture & Data Flow

- `edac_mc_alloc_csrows()`/`edac_mc_alloc_dimms()` allocate `mci->csrows`, `csr->channels`, and `mci->dimms` as pointer arrays (`sizeof(*ptr)`) to individually allocated structs (`sizeof(**ptr)`), which `mci_release()` frees before the outer arrays; `edac_mc_alloc_dimms()` and `edac_get_dimm()` must share row-major layer order and keep `mci->dimms[idx]->idx == idx`. Conversely, `edac_device_alloc_ctl_info()` allocates `dev_ctl->blocks` as one contiguous array into which `dev_inst[i].blocks` points, so `__edac_device_free_ctl_info()` must only `kfree(ci->blocks)`. [F61, F116, F117]
- `struct attribute attr` must stay at offset 0 in `edac_dev_sysfs_attribute`, `edac_dev_sysfs_block_attribute`, and `edac_pci_dev_attribute` for direct casts. `dynamic_csrow_dimm_attr[]` and `dynamic_csrow_ce_count_attr[]` must grow in lockstep because `csrow_dev_is_visible()` bounds-checks both against `ARRAY_SIZE(dynamic_csrow_ce_count_attr) - 1`. [F57, F78]
- Because `edac_create_sysfs_mci_device()` and `edac_create_csrow_objects()` skip unpopulated DIMMs (`!dimm->nr_pages`) and csrows (`!nr_pages_per_csrow(csrow)`), teardown/rollback loops must check `device_is_registered()` before `device_unregister()`. [F99]
- In `edac_dev_register()`, the first-pass `attr_gcnt` sum across `ras_features[]` must match pass-two `attribute_group` slots (`1` for scrub/mem_repair, `ecs_info.num_media_frus` for ECS), allocating `attr_gcnt + 1` for the NULL sentinel. Keep `edac_mem_repair_attributes`, `mem_repair_dev_attr[]` (copied into `ctx->mem_repair_dev_attr[]` with `instance` set), and `mem_repair_attr_visible()` aligned 1-to-1; keep `edac_ecs_attributes`, `fru_ctx->dev_attr[]` (`fru_id` set), and `ecs_attr_visible()` aligned. [F58, F59, F76]
- In `edac_mc_handle_error()`, `row` and `chan` start at `-1`, take the first matching populated DIMM's `csrow`/`cschannel`, and stick at `-2` if another matching DIMM differs; `edac_raw_mc_handle_error()` must clamp `e->grain` to `1` when zero before `fls_long(e->grain - 1)`. `mci_reset_counters_store()` must reset all controller, csrow, channel, and DIMM counters plus `mci->start_time = jiffies`; `edac_device_handle_ce_count()`/`ue_count()` must add `count` to `block->counters` (if `nr_blocks > 0`), `instance->counters`, and `edac_dev->counters`. [F62, F63, F101, F107]
- In `fsl_ddr_edac.c`, all register I/O must use `ddr_in32()`/`ddr_out32()` (`pdata->little_endian` and `TYPE_IMX9` `inject_vbase` remapping). `fsl_mc_err_probe()` saves `FSL_MC_ERR_DISABLE` and `FSL_MC_ERR_SBE`, which `fsl_mc_err_remove()` restores after zeroing `FSL_MC_ERR_INT_EN` and before `edac_mc_del_mc()`. `fsl_ddr_mc_init()` must return `-EBUSY` when `ghes_get_devices()` is non-NULL. [F86, F132, F138]
- In `altera_edac.c`, `altr_check_ecc_deps()`, `altr_l2_check_deps()`, and `altr_sdram_probe()` must return `-ENODEV` if firmware did not enable ECC. `altr_sdram_probe()` must verify `mem_size != 0` before `((mem_size - 1) >> PAGE_SHIFT) + 1`, disable `ecc_irq_en_mask` and pulse `ecc_cnt_rst_mask` before `edac_mc_add_mc()` and `devm_request_irq()`, and enable `ecc_irq_en_mask` only after both succeed. [F109, F130, F136]
- In `altera_edac.c`, the Arria10 64-IRQ domain maps SERR to hwirq `0..31` and DERR to `32..63` (`dberr * 32 + bit`). `altr_init_a10_ecc_block()`/`altr_init_memory_port()` must mask `A10_SYSMGR_ECC_INTMASK_SET_OFST` and disable ECC with `wmb()`, poll `ALTR_A10_ECC_INITSTAT_OFST`, and clear `ALTR_A10_ECC_INTSTAT_OFST` before re-enabling ECC and unmasking the IRQ. `s10_edac_dberr_handler()` saves `S10_SYSMGR_ECC_INTSTAT_DERR_OFST` to `S10_SYSMGR_UE_VAL_OFST` (`0x220`) and matches `BIT(ed->db_irq)` in `edac->a10_ecc_devices` to log `ALTR_S10_DERR_ADDRA_OFST` to `S10_SYSMGR_UE_ADDR_OFST` (`0x224`). [F88, F143, F145]

## Synchronization

- Hold `mem_ctls_mutex`, `device_ctls_mutex`, or `edac_pci_ctls_mutex` around `__find_mci_by_dev()`/`add_mc_to_global_list()`, `find_edac_device_by_dev()`/`add_edac_dev_to_global_list()`, and `find_edac_pci_by_dev()`/`add_edac_pci_to_global_list()`. Callers must set the device pointer and unique index (`mc_idx`, `dev_idx`, `pci_idx`) first, and `add_*_to_global_list()` must insert in ascending index order. [F24, F100, F154]
- `del_mc_from_global_list()`, `del_edac_device_from_global_list()`, and `del_edac_pci_from_global_list()` must use `list_del_rcu()` + `synchronize_rcu()` before `INIT_LIST_HEAD()` for NMI readers. `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` must set `op_state = OP_OFFLINE` and remove from the global list under the subsystem mutex, then unlock before `edac_stop_work()`/`edac_device_workq_teardown()`. [F10, F20]
- Polling work is initialized and queued in `edac_mc_add_mc_with_groups()`, `edac_device_add_device()`, and `edac_pci_add_device()` only when `edac_check` is non-NULL, after sysfs creation succeeds and `op_state = OP_RUNNING_POLL` under the subsystem mutex. `edac_mc_reset_delay_period()` must hold `mem_ctls_mutex` and check `mci->op_state == OP_RUNNING_POLL` before `edac_mod_work()`. [F25, F26]
- Never call `edac_mc_handle_error()` concurrently on the same `mci` (e.g., from `edac_check` and an ISR) as it mutates `mci->error_desc` and counters unlocked. In `edac_pci_sysfs.c`, `edac_pci_main_kobj_setup()`/`teardown()` must gate `edac_pci_top_main_kobj` and `THIS_MODULE` refcounting on `atomic_inc_return(&edac_pci_sysfs_refcount) == 1` and `atomic_dec_return(...) == 0`. [F27, F156]
- In `altr_edac_a10_probe()`, initialize `a10_ecc_devices`, `ecc_mgr_map`, `irq_chip`, and `domain` and mask pending DDR0/SDMMCB IRQs in `A10_SYSMGR_ECC_INTMASK_SET_OFST` before `irq_set_chained_handler_and_data()` and `atomic_notifier_chain_register()`. Regmaps in `altera_edac.c` IRQ/panic paths require `.fast_io = true`. In Altera debugfs injection callbacks, finish `get_user()` and allocations before `local_irq_save()`/`disable()`, and flush injected buffers from caches (`wmb()` + `flush_cache_all()`, or `dma_alloc_coherent()` + barriers). [F34, F158, F159, F161]
- In `i5100_init_one()` (`bail_scrub`) and `i5100_remove_one()`, set `priv->scrub_enable = 0` before `cancel_delayed_work_sync(&priv->i5100_scrubbing)`, and cancel work before disabling/putting PCI devices and freeing `mci`. [F133]

## Object Lifetimes

- `mci->dev` is initialized in `edac_mc_alloc()` and freed by `edac_mc_free()`: `edac_create_sysfs_mci_device()` must not call `put_device(&mci->dev)` on `device_add()` failure, and `edac_remove_sysfs_mci_device()` must call `device_del(&mci->dev)`, not `device_unregister()`. `csrow_release()` and `dimm_release()` must remain no-ops because `mci_release()` frees them and `mci_for_each_dimm()` dereferences `(dimm)->idx` after each loop body. [F1, F3, F91]
- `edac_mc_del_mc()` and `edac_device_del_device()` must drain polling work via `edac_stop_work()` before removing sysfs. Under `mem_ctls_mutex`, `edac_mc_add_mc_with_groups()` sets `edac_mc_owner = mci->mod_name` only after list insertion and sysfs creation succeed, and `edac_mc_del_mc()` clears `edac_mc_owner = NULL` when `del_mc_from_global_list(mci)` returns true. [F11, F23]
- Once `edac_device_register_sysfs_main_kobj()` succeeds in `edac_device_alloc_ctl_info()`, free via `edac_device_free_ctl_info()`, never `__edac_device_free_ctl_info()` or `kfree()`. `cpc925_remove()` must call `cpc925_del_edac_devices()` before `cpc925_mc_exit()`, `edac_mc_del_mc()`, and `edac_mc_free()` because child devices share `vbase`. [F6, F15]
- In `altr_edac_a10_device_add()` and `altr_portb_setup()`, wrap `devm_ioremap_resource()` and `devm_request_irq()` in `devres_open_group()` and on failure call both `edac_device_free_ctl_info(dci)` and `devres_release_group()`. Child nodes in `altr_init_a10_ecc_device_type()`, `altr_edac_a10_device_add()`, and `socfpga_init_sdmmc_ecc()` must pass `validate_parent_available()` (which puts `"altr,ecc-parent"`) before register access. [F135, F141]

## API Contracts

- `find_mci_by_dev()` and `edac_mc_find()` return borrowed pointers; `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` return detached controllers that callers must free. `edac_mc_add_mc_with_groups()` returns `0` or negative errno (requiring `dimm->nr_pages` and `mci->pdev`, `mod_name`, `ctl_name`, `dev_name` preset), whereas `edac_device_add_device()` and `edac_pci_add_device()` return `0` or positive `1` on failure (check non-zero, not `< 0`, and return negative errno from probe). [F12, F35, F36, F47]
- Set `edac_check` before registration and never change its nullness before removal. `edac_device_add_device()` preserves non-zero `poll_msec` over `DEFAULT_POLL_INTERVAL`, and `edac_device_workq_setup()`/`edac_device_reset_delay_period()` must update `poll_msec` and `delay = msecs_to_jiffies(msec)` in lockstep before passing jiffies to `round_jiffies_relative()`, `edac_queue_work()`, or `edac_mod_work()`. [F44, F49, F64]
- In `edac_mc_handle_error()` and `edac_raw_mc_handle_error()`, `page_frame_number` is a PFN, `offset_in_page` is a byte offset, and `grain` is a non-zero byte size; direct `edac_raw_mc_handle_error()` callers must pass `&mci->error_desc` with non-NULL `msg` and `other_detail`. In `edac_ce_error()`/`edac_mc_scrub_block()`, translate PFN via `ctl_page_to_phys()` if set, check `pfn_valid()`, use `kmap_atomic()`/`kunmap_atomic()`, and wrap `PageHighMem(pg)` in `local_irq_save()`/`restore()`. [F45, F155, F168]
- `set_sdram_scrub_rate`/`get_sdram_scrub_rate` return bytes/sec (`>= 0`) or negative errno in a signed `int`. `csrow_info::first_page` and `last_page` are inclusive (`first_page + nr_pages - 1`), and `edac_mc_find_csrow_by_page()` returns `-1` on miss (check `row >= 0` before `mci->csrows[row]`). `edac_device_ctl_info::sysfs_attributes` is NULL-terminated while `block_attributes` uses `nr_attribs`; `off_val` in `edac_device_alloc_ctl_info()` only offsets sysfs names while `edac_device_handle_ce`/`ue*()` take 0-based `inst_nr` and `block_nr`. [F38, F39, F77, F79, F83]
- `edac_pci_do_parity_check()` and `edac_pci_handle_pe()`/`npe()` require sleepable context with IRQs enabled (`for_each_pci_dev()`); disable local IRQs only inside `edac_pci_dev_parity_test()`. In `ecs.c`, `mem_repair.c`, and `scrub.c`, `*_attr_visible()` must gate read/write modes on non-NULL getters/setters, heap attributes need `sysfs_attr_init()`, and `edac_dev_register()` requires non-NULL ops plus 0-based sequential `instance` numbers for scrub/mem_repair and non-zero `ecs_info.num_media_frus` for ECS. [F46, F157, F163, F164]
- In `altera_edac.c`, `altr_sdr_mc_err_inject_write()` calls `dma_free_coherent()` only if `dma_alloc_coherent()` succeeded; `altr_edac_device_trig()` sets `generic_ptr = edac_dci->dev`, passes `&generic_ptr` to `alloc_mem()`, and passes `generic_ptr` to `free_mem()`. `altr_edac_a10_irq_handler()` must bracket status reads and `generic_handle_domain_irq()` with `chained_irq_enter()`/`exit()`. [F16, F123, F160]

## Error Handling

- `edac_create_dimm_object()` and `edac_create_csrow_object()` must call `put_device()` when `device_add()` fails, while post-registration teardown calls `device_unregister()`. `edac_device_create_instance()`, `edac_device_create_block()`, and `edac_pci_create_instance_kobj()` must call `kobject_get()` on the parent main kobject before `kobject_init_and_add()`. [F2, F8]
- In `edac_dev_register()`, errors before `device_register(&ctx->dev)` jump to `data_mem_free` (while `ecs_create_desc()`/`mem_repair_create_desc()` are devm-managed on `parent`); once `device_register()` is called on `&ctx->dev` or on `mci_pdev` in `edac_mc_sysfs_init()`, call `put_device()` and return without manual `kfree()`. [F4, F5, F42]
- In `fsl_mc_err_probe()` and `altr_sdram_probe()`, errors after `edac_mc_add_mc*()` must call `edac_mc_del_mc()`, then `devres_release_group()` before `edac_mc_free(mci)`, and close/remove the devres group on success. Propagate negative `platform_get_irq()` errors directly instead of `-ENODEV`, and check `si == 0` before dividing in `cpc925_get_sdram_scrub_rate()`. [F13, F37, F43, F110]

## External Contracts

- `dimmdev_label_store()` and `channel_dimm_label_store()` must reject empty strings (after stripping trailing `'\0'`/`'\n'`) and inputs `>= sizeof(dimm->label)` (32 bytes), and NUL-terminate `dimm->label`. `altr_sdram_prepare()` must return `-EPERM` to block suspend. [F81, F149]

## Known Pitfalls

- `edac_mc_add_mc_with_groups()` compares `edac_mc_owner != mci->mod_name` by pointer equality, so multi-instance drivers must share one `mod_name` pointer. Keep reverse-loop counters `layer` (`edac_mc_alloc_dimms()`) and `i` (`edac_create_csrow_objects()`) as signed `int`. Reset `list_for_each()` cursor pointers to `NULL` on miss in `edac_mc_find()`. [F84, F92, F166]
- `edac_mc_handle_error()` must `memset()` `mci->error_desc` and set NULL `msg`/`other_detail` to `""`, resetting `p = e->label` and `*p = '\0'` if `> EDAC_MAX_LABELS` DIMMs match; when `edac_get_dimm()` is `NULL`, increment `ue_noinfo_count` in `edac_inc_ue_error()` and `ce_noinfo_count` in `edac_inc_ce_error()`. Use `scnprintf()` (not `snprintf()`) when advancing buffer pointers in `edac_dimm_info_location()`, `edac_mc_alloc_dimms()`, and `edac_mc_handle_error()`. [F66, F67, F94, F128]
- Cast `kp->arg` to `unsigned int *` in `edac_set_poll_msec()` (`param_get_uint`), and pass literal `"%s"` to `dev_set_name()`/`kobject_init_and_add()`. `edac_pci_alloc_ctl_info()` requires `strlen(edac_pci_name) <= 31`; `EDAC_PCI_ATTR()` with `edac_pci_int_show`/`store` requires 4-byte `int` targets; `get_pci_parity_status()` must ignore `0xFFFF` if config dword 0 is `0xFFFFFFFF` and mask `status` to `PCI_STATUS_DETECTED_PARITY | PCI_STATUS_SIG_SYSTEM_ERROR | PCI_STATUS_PARITY` before writing back. [F68, F85, F112, F114, F120]
- In `ecs.c`, `mem_repair.c`, and `scrub.c`, read-write attributes require a non-NULL getter in `*_attr_visible()` to be visible; in `ecs.c`/`mem_repair.c` callbacks, use `dev_get_drvdata(ras_feat_dev)` for `ctx` and pass `ras_feat_dev->parent` plus `ctx->ecs.private` or `ctx->mem_repair[inst].private` to `ops->cb()`. Pass `&mci->dev` to debugfs files using `to_mci(file->private_data)` (`edac_fake_inject_write`, `inject_enable_write`), but `mci` to `altr_sdr_mc_err_inject_write()`. [F97, F126, F165]
- In `altera_edac.c`: wrap `a10_get_irq_mask()` in `BIT()` for `altr_init_a10_ecc_block()`; keep `limit` signed (`limit < 0`) in `altr_init_memory_port()`; cast `p` to `unsigned long` in `ocram_free_mem()`; copy 32-bit `irq_status` to `unsigned long` for `for_each_set_bit()`; check `ecc_cecnt_offset` for CE and `ecc_uecnt_offset` for UE in `altr_sdram_mc_err_handler()`; bound `ptemp` by `trig_alloc_sz / sizeof(*ptemp)` (`>= 128` bytes) in `altr_edac_device_trig()`; pass `edac_device_ctl_info *` to `altr_edac_device_handler()` vs `altr_edac_device_dev *` to `prv->ecc_irq_handler`; overwrite PortB's `edac_dev_name`, `edac_idx`, `edac_dev`, `data` (`&a10_sdmmceccb_data`), `dci->dev` (`&altdev->ddev`), `sb_irq`, and `db_irq` after `*altdev = *device` in `altr_portb_setup()`; read `ALTR_S10_ECC_CTRL_SDRAM_OFST` via `arm_smccc_smc()`; and use `writew()` for `set_err_ofst` (`INTTEST`) in `altr_edac_a10_device_trig()`/`trig2()`. [F52, F70, F93, F104, F108, F113, F124, F125, F137, F142]
- In `cpc925_edac.c`, use `CPC925_BIT(nr)` (`1UL << (31 - nr)`), set `reg_end = reg + len/4` in `get_total_mem()`, and never clear `ECC_MASK_ENABLE`, `CPU_MASK_ENABLE`, or `MCCR_ECC_EN` on exit. In `fsl_mc_check()`, guard `bad_data_bit >= 0` and `bad_ecc_bit >= 0` and shift `1ULL` on 64-bit `cap`. In `i3200`/`i82860`/`i82875p`, read `ERRSTS` before and after error logs (re-reading on `errsts ^ errsts2` as `"UE overwrote CE"`) and test UE before CE. In `i5100_edac.c`, widen shifts/multiplies in `i5100_npages()` and `i5100_init_interleaving()` to `u64`/`1ULL`, and write `0xaa` then `0xab` to `I5100_DINJ0`. [F53, F69, F71, F102, F106, F111, F122, F147]
