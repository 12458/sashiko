# FUNCTION HOOKS (FTRACE) — (top level)

Provides the public header interface (`include/linux/ftrace.h`) and per-architecture backends (`arch/*/kernel/ftrace.c`, `arch/*/include/asm/ftrace.h`) for function tracing, dynamic callsite patching, function graph return hooking, and kprobes-on-ftrace.

## Architecture & Data Flow

- With `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, every path in `ftrace_init_nop()`, `ftrace_make_nop()`, and `ftrace_replace_code()` converting a callsite to NOP (including OOL stubs) must call `ftrace_rec_set_nop_ops(rec)` (`&ftrace_nop_ops`), and every path enabling/modifying a callsite (`ftrace_make_call()`, `ftrace_modify_call()`, `ftrace_replace_code()`) must update its literal via `ftrace_rec_update_ops()` / `ftrace_rec_set_ops()` to `ftrace_find_unique_ops(rec)` if `FTRACE_FL_CALL_OPS_EN` or `&ftrace_list_ops` otherwise. [F43, F44]
- On arm64 and riscv with `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, `ftrace_rec_set_ops()` must compute the pre-function literal slot as `ALIGN_DOWN(rec->ip - 12, 8)` (handling 4-byte `BTI` shifts), and on riscv must pass `&ops` and `sizeof(ops)` (not `ops` or `sizeof(*ops)`) to `patch_text_nosync()`. [F65, F98]
- In `arch/x86/kernel/ftrace.c:ftrace_replace_code()`, all records must pass `ftrace_verify_code()` via `ftrace_test_record()` before any callsite is queued with `smp_text_poke_batch_add()` or mutated with `ftrace_update_record()`. Any pointer assigned to `ftrace_expected` (`old_code` in `ftrace_verify_code()` / `ftrace_modify_code_direct()`) must point to static storage or be reset to `NULL` after `ftrace_bug()` before going out of scope. [F46, F103]
- On x86_64, `create_trampoline()` and `set_ftrace_ops_ro()` must size dynamic trampolines as `(end_offset - start_offset) + RET_SIZE + sizeof(void *)` with return at `+ size`, `ftrace_ops *` at `+ size + RET_SIZE`, and `npages = DIV_ROUND_UP(..., PAGE_SIZE)`. `create_trampoline()` must check `cpu_wants_rethunk_at(ip)` at `trampoline + size` to emit a `JMP32_INSN_OPCODE` to `x86_return_thunk` instead of `RET_INSN_OPCODE`, and for `ftrace_regs_caller` (`FTRACE_OPS_FL_SAVE_REGS`) must verify `ftrace_regs_caller_jmp` starts with `0x75`, overwrite it with a 2-byte NOP, and retarget `op_offset`'s RIP-relative `movq` to the trailing `ftrace_ops` pointer. [F48, F73, F94, F106]
- On architectures with separate default and regs trampolines without `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS` (x86, powerpc, arm, csky), `ftrace_update_ftrace_func()` must patch both `ftrace_call` and `ftrace_regs_call`. [F49]
- In `ftrace_find_callable_addr()` (arm64, LoongArch) and `ftrace_get_call_inst()` (powerpc), an unreachable custom trampoline must fall back to `FTRACE_ADDR` or `FTRACE_REGS_ADDR` before testing reachability or resolving a module PLT/stub. On arm64, `get_ftrace_plt(mod, pc)` takes callsite `pc` (not `*addr`) and checks `within_module_mem_type(addr, mod, MOD_INIT_TEXT)` for `init_ftrace_trampolines` vs `MOD_TEXT` for `ftrace_trampolines`. [F85, F123]
- On powerpc with `CONFIG_PPC_FTRACE_OUT_OF_LINE`, `ftrace_get_ool_stub(rec)` (`rec->arch.ool_stub`) stores `&ool_stub->insn[0]` (`ftrace_op` at `- sizeof(unsigned long)`, `bl` at `+ MCOUNT_INSN_SIZE`). `ftrace_init_ool_stub()` must check `*ool_stub_index > ool_stub_count` (falling back from `ftrace_ool_stub_text` to `ftrace_ool_stub_text_end`) and verify `&ool_stub->insn[0]` and `&ool_stub->insn[3]` satisfy `is_offset_in_branch_range()`. `ftrace_make_call()` and `ftrace_replace_code()` must patch both `ftrace_get_ool_stub(rec) + MCOUNT_INSN_SIZE` and `rec->ip`. [F50, F69, F100]
- On powerpc: `ftrace_call_adjust()` must return `0` for `addr` in `[__exittext_begin, __exittext_end)` before adding `MCOUNT_INSN_SIZE`; on 64-bit when `!CONFIG_MPROFILE_KERNEL`, `__ftrace_make_nop()` (`ftrace_64_pg.c`) must verify `ip + 4` is `PPC_INST_LD_TOC` and patch to `PPC_RAW_BRANCH(8)` (`b +8`) rather than `PPC_RAW_NOP()` so preempted tasks restore `r2`. [F67, F129]
- `FTRACE_MCOUNT_MAX_OFFSET` must cover the max prologue offset to `rec->ip` (`16` on 64-bit powerpc with `MPROFILE_KERNEL` or `PATCHABLE_FUNCTION_ENTRY`, `8` on `PPC32`, `ENDBR_INSN_SIZE` on x86 `HAVE_FENTRY`). On x86, `arch_ftrace_get_symaddr(fentry_ip)` must subtract `ENDBR_INSN_SIZE` when `is_endbr((void *)(fentry_ip - ENDBR_INSN_SIZE))` is true. [F68, F125]
- On arm64 with `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, `ftrace_call_adjust()` must verify 8-byte alignment, skip the two literal NOPs, skip `BTI` if `CONFIG_ARM64_BTI_KERNEL` and `aarch64_insn_is_bti()`, and skip `MOV X9, LR`. In `arch_ftrace_get_symaddr()`, reading `fentry_ip - AARCH64_INSN_SIZE * 2` under `CONFIG_ARM64_BTI_KERNEL` must use `get_kernel_nofault()` if `(fentry_ip & ~PAGE_MASK) < AARCH64_INSN_SIZE * 2` and pass `le32_to_cpu((__le32)insn)` to `aarch64_insn_is_bti()`. [F64, F124]
- On s390, `ftrace_make_call()`, `ftrace_make_nop()`, and `ftrace_modify_call()` must check `cpu_has_seq_insn()`, calling `ftrace_patch_branch_insn()` (which checks `IS_ALIGNED(ip, 8)`) only when supported, and otherwise patching `trampoline->interceptor` and the 1-byte mask via `ftrace_patch_branch_mask()`. `ftrace_init_nop()` must check `*next_trampoline >= trampolines_end` (`-ENOMEM`), `struct ftrace_hotpatch_trampoline` must stay `__packed` at `SIZEOF_FTRACE_HOTPATCH_TRAMPOLINE` (24 bytes), and `ftrace_insn::disp` halfwords must be widened to `(s64)insn.disp * 2` in `ftrace_get_trampoline()`. [F71, F72, F105]
- On 32-bit ARM, `ftrace_call_adjust()` must clear bit 0 (`addr & ~1`), and `ftrace_modify_code()` must convert `old` via `__opcode_to_mem_thumb32(old)` or `__opcode_to_mem_arm(old)` before comparing with `replaced`. On RISC-V, `to_auipc_t0(offset)` must add `AUIPC_PAD` (`0x1000`) when `offset & JALR_SIGN_MASK` (`0x800`), and `ftrace_make_call()` must fall back to `FTRACE_ADDR` if distance from `ftrace_caller` exceeds `JALR_RANGE` (`0x7ff`). On 64-bit PARISC, `ftrace_make_call()` must use `ftrace_trampoline_unaligned` when `rec->ip & 0x4` and patch at `rec->ip + 4 - size`. [F66, F74, F77]
- In `ftrace_partial_regs()` and `arch_ftrace_fill_perf_regs()`, backends must initialize the kernel-mode state field in `struct pt_regs` (`pstate = PSR_MODE_EL1h` on arm64, `cs = __KERNEL_CS` on x86, `psw.mask = 0` on s390, `msr` on powerpc) so `user_mode(regs)` is false; on arm64/riscv, `memcpy()` in `ftrace_partial_regs()` must be bounded by the source array (`sizeof(afregs->regs)` / `sizeof(afregs->args)`), not `pt_regs`. [F33, F99]
- On arm64, `sizeof(struct __arch_ftrace_regs)` must be a 16-byte multiple (via `__unused` when `!CONFIG_DYNAMIC_FTRACE_WITH_DIRECT_CALLS`) to preserve SP alignment. On RISC-V with `CONFIG_DYNAMIC_FTRACE_WITH_ARGS`, `struct __arch_ftrace_regs` must include `t2`–`t6` under `CONFIG_CC_IS_CLANG`. [F96, F127]
- `ftrace_regs_get_kernel_stack_nth()` must verify `stackp + nth` and `stackp` share the same `~(THREAD_SIZE - 1)` mask before dereferencing. In LoongArch `ftrace_get_parent_ra_addr()`, backward `insn--` scanning must bound `limit = 32` and return `-EINVAL` on exhaustion. On 64-bit MIPS, `arch_syscall_addr(nr)` must check `nr` is in `[__NR_<ABI>_Linux, __NR_<ABI>_Linux + __NR_<ABI>_Linux_syscalls)` before indexing syscall tables. [F57, F75, F76]
- `FTRACE_FL_*` constants in `struct dyn_ftrace.flags` must use `1UL` shifts at or above `FTRACE_REF_MAX_SHIFT` (bit 19). `ftrace_ops_list` traversal (`do_for_each_ftrace_op()` / `while_for_each_ftrace_op()`) must stop at `&ftrace_list_end` as well as `NULL`. [F59, F89]

## Synchronization

- On x86, `ftrace_arch_code_modify_prepare()` locks `text_mutex` and sets `ftrace_poke_late = 1`, and `ftrace_arch_code_modify_post_process()` must run `smp_text_poke_batch_finish()` and reset `ftrace_poke_late = 0` before unlocking `text_mutex`. On x86_64, `create_trampoline()` and `arch_ftrace_update_trampoline()` must hold `text_mutex` around `text_gen_insn()` / `smp_text_poke_single()`, and `create_trampoline()` must call `set_memory_rox()` only after writing all instructions and the `ops` pointer. [F3, F21, F119]
- On RISC-V, `ftrace_init_nop()` must acquire `text_mutex` itself before `ftrace_rec_set_nop_ops()` and `patch_insn_write()`, `arch_ftrace_update_code()` must call `flush_icache_all()` after `ftrace_modify_all_code()`, and when `!CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, `ftrace_update_ftrace_func()` must execute `smp_wmb()` and `smp_call_function(ftrace_sync_ipi, NULL, 1)` with IRQs enabled after `WRITE_ONCE(ftrace_call_dest, func)`. [F22, F120]
- On s390, when `!cpu_has_seq_insn()`, `ftrace_init_nop()` must write `ftrace_hotpatch_trampoline` before patching `insn->disp` at `rec->ip`, and `ftrace_make_trampoline_call()` must write `trampoline->interceptor` before enabling the branch mask; `ftrace_arch_code_modify_post_process()` must call `text_poke_sync_lock()`. [F26, F121]
- On SuperH, `do_ftrace_mod_code()` must publish `mod_code_ip` and `mod_code_newcode` before `smp_mb()` and `wait_for_nmi_and_set_mod_flag()`, and clear `MOD_CODE_WRITE_FLAG` and call `wait_for_nmi()` after `ftrace_mod_code()`. On C-SKY without `CONFIG_CPU_HAS_ICACHE_INS`, `__ftrace_modify_code()` must have only CPU 1 (`atomic_inc_return(&param->cpu_count) == 1`) run `ftrace_modify_all_code()` and increment `cpu_count` while other CPUs spin until `cpu_count > num_online_cpus()` before `local_icache_inv_all()`. [F27, F28]
- Callers of `function_graph_enter_regs()` and `function_graph_enter()` must not wrap the call in `ftrace_test_recursion_trylock()` (acquired internally). Every `kprobe_ftrace_handler()` must acquire `ftrace_test_recursion_trylock(ip, parent_ip)` before calling `get_kprobe()` or touching `current_kprobe` / `get_kprobe_ctlblk()`, and must reset `current_kprobe = NULL` and call `ftrace_test_recursion_unlock(bit)` on all exit paths. [F5, F29]
- Static `struct ftrace_ops` registered on `ftrace_ops_list` must never be freed or have `ops->next` modified after `unregister_ftrace_function()` due to lockless readers; freeing `ops->private` on a non-`FTRACE_OPS_FL_DYNAMIC` `ftrace_ops` requires `schedule_on_each_cpu()` after unregistering. [F15, F16]
- `ops_func` callbacks are invoked with `direct_mutex` and `ftrace_lock` held for `FTRACE_OPS_CMD_ENABLE_SHARE_IPMODIFY_SELF`, and `direct_mutex` only for `ENABLE_SHARE_IPMODIFY_PEER` / `DISABLE_SHARE_IPMODIFY_PEER`. `stack_tracer_disable()` and `stack_tracer_enable()` require preemption/IRQs disabled across the pair. `__ftrace_enabled_save()` and `__ftrace_enabled_restore()` require caller synchronization across the pair. [F17, F18, F19]

## Object Lifetimes

- On x86_64, `arch_ftrace_update_trampoline()`, `set_ftrace_ops_ro()`, `arch_ftrace_trampoline_func()`, and `arch_ftrace_trampoline_free()` must check `ops->flags & FTRACE_OPS_FL_ALLOC_TRAMP` before acting on `ops->trampoline`. `arch_ftrace_trampoline_free()` must zero `ops->trampoline = 0` after `tramp_free()`, and `create_trampoline()` must call `tramp_free(trampoline)` without setting `FTRACE_OPS_FL_ALLOC_TRAMP` on failure. [F2, F47]
- On powerpc, `ftrace_free_init_tramp()` must zero the `ftrace_tramps[]` entry matching `ftrace_tramp_init` when `.init.text` is freed, and `find_ftrace_tramp()` must `continue` past zero entries rather than stopping. `ftrace_enable_ftrace_graph_caller()` and `ftrace_disable_ftrace_graph_caller()` must symmetrically enable and disable the graph branch/static key. [F8, F10, F83]

## API Contracts

- `mod` in `ftrace_make_nop()` is non-NULL only during module load. When `mod` is `NULL` at runtime, arm (`CONFIG_ARM_MODULE_PLTS`) must fall back to `rec->arch.mod` cached during load, while `ftrace_find_callable_addr()` (arm64, LoongArch), `ftrace_lookup_module_stub()` (powerpc), and `ftrace_lookup_module()` (ppc64) must call `__module_text_address()` under `guard(rcu)()` with `ftrace_lock` held. [F11, F38, F53]
- `struct ftrace_ops->flags` attribute bits (`SAVE_REGS`, `SAVE_REGS_IF_SUPPORTED`, `RECURSION`, `STUB`, `IPMODIFY`) must not be modified while registered. With `CONFIG_HAVE_DYNAMIC_FTRACE_WITH_ARGS`, `arch_ftrace_get_regs()` must return `NULL` unless full `pt_regs` were saved (`regs.cs` on x86, `PIF_FTRACE_FULL_REGS` on s390, `regs.msr` on powerpc, `NULL` on arm64/riscv). Callers of `ftrace_partial_regs(fregs, regs)` must pass a valid scratch `regs` and use the returned pointer. [F14, F32, F102]
- `ftrace_regs_set_instruction_pointer(fregs, ip)` must write the saved PC (`pc` on arm64, `epc` on riscv, `psw.addr` on s390, `regs_set_return_ip()` on powerpc, `instruction_pointer_set()` on LoongArch), not the return-value register. On arm64/riscv, `ftrace_regs_get_argument()` must return `0` for `n >= 8`. `arch_ftrace_set_direct_caller(fregs, addr)` must write `addr` to the slot read by `ftrace_caller` (`direct_tramp` on arm64, `t1` on riscv, `regs[13]` on LoongArch, `orig_ax` on x86, `orig_gpr2` on s390, `orig_gpr3` on powerpc). [F34, F62, F130]
- `retp` passed to `function_graph_enter_regs()` / `function_graph_enter()` must match the stack/frame pointer passed by the unwinder to `ftrace_graph_ret_addr()`. Architectures with wrapper-prefixed syscall symbols must define `ARCH_HAS_SYSCALL_MATCH_SYM_NAME` and `arch_syscall_match_sym_name()`, and 64-bit architectures with separate compat syscall tables must define `ARCH_TRACE_IGNORE_COMPAT_SYSCALLS` and `arch_trace_is_compat_syscall()`. [F35, F134, F135]

## Error Handling

- `function_graph_enter()` / `function_graph_enter_regs()` return `0` on success; callers must only redirect the return address on `0`, and architectures overwriting `*parent = return_hooker` beforehand (ARM, MIPS, SuperH, MicroBlaze) must restore `*parent = old` on non-zero return. [F9, F36]
- `ftrace_make_nop()`, `ftrace_init_nop()`, `ftrace_make_call()`, and `ftrace_modify_call()` must return `0` on success, `-EFAULT` on read fault, `-EINVAL` on instruction mismatch, or `-EPERM` on write fault. On s390, `ftrace_get_trampoline()` returns `ERR_PTR()`, so callers must check `IS_ERR(trampoline)`. [F30, F41]

## External Contracts

- When `!ARCH_SUPPORTS_FTRACE_OPS`, `arch_ftrace_ops_list_func()` must take two parameters (`ip, parent_ip`), while `ftrace_ops_list_func` is linker-aliased to it with four parameters (`ftrace_func_t`). [F104]

## Known Pitfalls

- `ftrace_need_init_nop()` is a boolean predicate returning nonzero (`true`) when `ftrace_init_nop()` is required (the header comment in `include/linux/ftrace.h` is inverted). In `ftrace_replace_code()`, `ftrace_get_addr_curr(rec)` must precede `ftrace_update_record(rec, enable)`. [F31, F45]
- Signedness and macro parenthesization: in `reachable_by_bl()` (arm64, LoongArch), compute `long offset = (long)addr - (long)pc` before comparing with `±SZ_128M`; in powerpc `find_bl_target()`, sign-extend 26-bit `PPC_LI()` from bit 25 (`|= 0xfe000000`) and cast to `long`; in powerpc `ftrace_dyn_arch_init()`, cast `SZ_8G` and `SZ_2G` to signed types before negation; in riscv `make_call_t0`, parenthesize `caller` and `callee` before casting/subtracting. [F78, F91, F93, F95]
- `get_lock_parent_ip()` and s390's `return_address(n)` must be `__always_inline`, and s390's `return_address(n)` must check `if (!n)` before `do { ... } while (--n);`. On x86, `prepare_ftrace_return()` and `ftrace_graph_func()` must call `skip_ftrace_return()` (rejecting `(long)__builtin_frame_address(0) >= 0`). On 32-bit ARM with `CONFIG_UNWINDER_FRAME_POINTER`, `prepare_ftrace_return()` must read `frame_pointer - 8` via inline `__get_kernel_nofault()`. [F88, F108, F118, F128]
