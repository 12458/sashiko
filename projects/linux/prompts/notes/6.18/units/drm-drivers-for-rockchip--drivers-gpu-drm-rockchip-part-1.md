# DRM DRIVERS FOR ROCKCHIP — drivers/gpu/drm/rockchip (part 1)

This unit implements the core Rockchip DRM master driver, GEM/DMA/IOMMU memory management, framebuffer creation, the first-generation Video Output Processor (VOP) CRTC/plane controller, and display encoder/bridge subdrivers for DisplayPort (Analogix DP, Cadence DP, DesignWare DP), MIPI DSI (DesignWare DSI v1/v2), and HDMI (DesignWare HDMI, DesignWare HDMI QP, Innosilicon HDMI, RK3066 HDMI).

## Architecture & Data Flow

- `rockchip_drm_dma_init_device()` sets `private->iommu_dev = ERR_PTR(-ENODEV)` if any VOP lacks IOMMU. `rockchip_drm_init_iommu()` must check `IS_ERR_OR_NULL(private->iommu_dev)` and reset `private->domain = NULL` if `iommu_paging_domain_alloc()` returns an `ERR_PTR`, because downstream checks test `private->domain` for non-NULL [F5, F38].
- Every Rockchip GEM object must be a `struct rockchip_gem_object` (allocated via `rockchip_gem_alloc_object()` with `round_up(size, PAGE_SIZE)` before `drm_gem_object_init()`, as page counts use `size >> PAGE_SHIFT`), because `vop_plane_atomic_update()` and GEM callbacks downcast via `to_rockchip_obj()` [F110, F123].
- In `rockchip_gem_object`, PRIME imports are discriminated via `obj->import_attach` (and `private->domain`), whereas internal buffers use `rk_obj->pages != NULL` (IOMMU vs DMA). When `!private->domain`, `rockchip_gem_dma_map_sg()` must verify `drm_prime_get_contiguous_size(sg) >= attach->dmabuf->size` after `dma_map_sgtable()` or unmap and return `-EINVAL` [F41, F160].
- For DMA-backed `rockchip_gem_object` (`!rk_obj->pages`) with `!alloc_kmap`, `rk_obj->kvaddr` is a non-NULL DMA cookie, so `rockchip_gem_prime_vmap()` must check `rk_obj->dma_attrs & DMA_ATTR_NO_KERNEL_MAPPING`. `rockchip_gem_create_with_handle()` must pass `alloc_kmap = true` when `file_priv == drm->fb_helper->client.file` [F40, F172].
- In `vop_reg_set()` (`VOP_REG_SET`, `VOP_WIN_SET`, `VOP_INTR_SET_MASK`), `reg->mask != 0` marks presence and `_mask`/`v` are passed unshifted; `write_mask = true` fields must fit in bits `[15:0]` with 4-byte aligned offsets `< vop->len`. `VOP_WIN_TO_INDEX(vop_win)` uses `(vop_win) - (vop_win)->vop->win` (`vop->win[]`); if `vop_data->win_yuv2yuv` is set, it needs `>= win_size` entries with non-NULL `phy` [F48, F85, F86, F116].
- `vop_plane_atomic_update()` and `vop_win_disable()` must update `vop->win_enabled` in lockstep with the hardware `enable` bit under `vop->reg_lock`. During PSR (`self_refresh_active`), VOP must only toggle hardware enables via `rockchip_drm_set_win_enabled()` without mutating `vop->win_enabled`, disabling clocks, or detaching IOMMU [F60, F178].
- `vop_plane_atomic_check()` must reject YUV planes with odd `(src.x1 >> 16) % 2` or `DRM_MODE_REFLECT_Y`, and AFBC planes with non-zero `src.x1`/`y1` or rotation != `DRM_MODE_ROTATE_0`. In `vop_plane_atomic_update()`, `src` uses `>> 16` while `dst` is integer, `act_info`/`dsp_info` pack `(height - 1) << 16 | ((width - 1) & 0xffff)`, `yrgb_vir`/`uv_vir` use `DIV_ROUND_UP(fb->pitches[i], 4)`, and alpha blending is enabled only when `fb->format->has_alpha` and `VOP_WIN_TO_INDEX(vop_win) > 0`. In `has_rb_swapped()`, `DRM_FORMAT_RGB888` checks `VOP_MAJOR(version) == 3` and `BGR888` checks `!= 3` [F49, F87, F89, F90].
- `vop_bind()` must validate `lut_size` is `256` or `1024` before mapping `lut_regs`, and `vop_crtc_atomic_check()` must verify `drm_color_lut_size(gamma_lut) == crtc->gamma_size`. After `vop_crtc_gamma_set()` sets `update_gamma_lut = 1` and polls `vop_lut_buffer_index()`, it must write `VOP_REG_SET(vop, common, update_gamma_lut, 0)` under `reg_lock` to clear `regsbak`. In `vop_crtc_mode_fixup()`, if `clk_round_rate(dclk, clock * 1000)` mismatches in kHz, add `999` Hz and set `clock = DIV_ROUND_UP(rate, 1000)`; in `vop_crtc_atomic_enable()`, set `intr->line_flag_num[0]` to `vact_end` [F59, F62, F88, F108, F111].
- GRF/table sentinels: `rockchip_dw_dsi_chip_data` unsigned GRF offsets use `0` as unpopulated; `rockchip_hdmi_chip_data.lcdsel_grf_reg` is signed `int` using `-1` (`< 0`); `analogix_dp-rockchip.c` `rockchip_grf_reg_field` must use `GRF_REG_FIELD()` (`.valid = true`) and check `field->valid` (`0x0000` is valid on `rk3588_edp`). `rockchip_dp_chip_data` and `rockchip_dw_dsi_chip_data` arrays must end with `.reg == 0`, `inno_hdmi_phy_config` with `.pixelclock == ~0UL` (and non-NULL `default_phy_config`), and `cdn_dp_data.max_phy <= MAX_PHY` (2) [F50, F51, F75, F78, F79, F80].
- In `cdn_dp_device`, `active_port` is `-1` when inactive (`cdn_dp_check_sink_connection()` must check `>= 0 && < dp->ports`). `cdn_dp_disable()` resets `active = false`, `max_lanes = 0`, `max_rate = 0` (`cdn_dp_disable_phy()` resets `phy_enabled = false`, `lanes = 0`, `active_port = -1`). Before `cdn_dp_train_link()` in `cdn_dp_pd_event_work()`, sample `max_rate`/`max_lanes` and call `cdn_dp_config_video()` if `mode.clock` is set and either changed [F54, F71, F72].
- When external `dsi->phy` is present, `dw_mipi_dsi_rockchip_probe()` resets `IS_ERR(dsi->pllref_clk)` to `NULL`, and `dw_mipi_dsi_phy_init()` / `dw_mipi_dsi_get_lane_mbps()` must return early if `dsi->phy` is set; `get_lane_mbps()` must bound `_prediv` with `DIV_ROUND_UP(fin, 40 * USEC_PER_SEC)` and `fin / (5 * USEC_PER_SEC)`. In dual-DSI, if `of_node` lacks `"clock-master"`, `bind` sets `dsi->is_slave = true` and returns `0` (and `unbind` returns early); when `dsi->slave` is set, master performs runtime PM, `dw_mipi_dsi_rockchip_config()`, and `set_lcdsel()` on both `dsi` and `dsi->slave` [F56, F68, F97, F109].
- `dw_mipi_dsi2_encoder_atomic_check()` and `atomic_enable()` must handle identical `MIPI_DSI_FMT_*` cases (including `RGB666` and `RGB666_PACKED`). `inno_hdmi_i2c_init()` must run in both `inno_hdmi_init_hw()` and `inno_hdmi_setup()` (`tmds_char_rate`) because video setup switches TMDS clock to `DCLK_LCDC` [F74, F98].

## Synchronization

- `private->mm_lock` protects `drm_mm_insert_node_generic()` and `drm_mm_remove_node()` in `rockchip_gem_iommu_map()`/`unmap()`, and `unmap` must call `iommu_unmap()` before `drm_mm_remove_node()` [F29].
- Hold `vop->reg_lock` (`spin_lock`, never in `vop_isr()`/hardirq, release before sleeping `readx_poll_timeout()` in `vop_crtc_gamma_set()`) for plane registers, `win_enabled`, and `vop_cfg_done()`. Before setting `VOP_PENDING_FB_UNREF`, take `drm_framebuffer_get()` and `drm_crtc_vblank_get()` and call `drm_flip_work_queue(&vop->fb_unref_work, ...)`. In `vop_crtc_atomic_flush()`, call `vop_wait_for_irq_handler()` after releasing `reg_lock` (`cfg_done`) and before taking `event_lock` to arm `vop->event` [F19, F21, F151, F153, F157].
- In `vop_enable()`, enable runtime PM and clocks before `rockchip_drm_dma_attach_device()`, call `vop_win_disable()` on all windows unless exiting PSR, and set `vop->is_enabled = true` before `drm_crtc_vblank_on()`. In `vop_crtc_atomic_disable()`, `reinit_completion(&vop->dsp_hold_completion)` and `vop_dsp_hold_valid_irq_enable()` must precede standby=1, `wait_for_completion_timeout()` must finish before detaching IOMMU or disabling clocks, and `vop_dsp_hold_valid_irq_disable()` must precede `vop->is_enabled = false` [F16, F17, F18].
- `rockchip_drm_wait_vact_end()` must hold `vop->vop_lock` across checking `vop_line_flag_irq_is_enabled()`, `reinit_completion`, enabling `LINE_FLAG_INTR`, waiting, and disabling the IRQ. `vop_initial()` leaves `hclk`, `aclk`, and `dclk` prepared until `vop_unbind()` so `vop_isr()` (`IRQF_SHARED`) can use `pm_runtime_get_if_in_use()` and atomic `vop_core_clks_enable()`/`disable()` [F22, F130, F154].
- In `cdn-dp-core.c`, `dp->lock` protects all mailbox transactions, power/link/audio state, and `dp->suspended` in `suspend`/`resume`/`cdn_dp_pd_event_work()`. `cdn_dp_request_firmware()` requires `dp->lock` on entry, drops it for `request_firmware()`, and must re-acquire it on all paths; `cdn_dp_pd_event_work()` must unlock `dp->lock` before `drm_bridge_hpd_notify()` [F11, F25, F145, F165].
- `dw_mipi_dsi_rockchip_host_attach()` and `dw_mipi_dsi_dphy_init()` must check `usage_mode == DW_DSI_USAGE_IDLE` and set `usage_mode` under `dsi->usage_mutex` before `component_add()`, and reset it under `usage_mutex` after `component_del()` (never holding `usage_mutex` across `component_add`/`del`). `dw_mipi_dsi_rockchip_driver` requires `PROBE_FORCE_SYNCHRONOUS` and `SET_LATE_SYSTEM_SLEEP_PM_OPS` [F31, F143].
- `dw_hdmi_qp_rk3576_hardirq()` and `rk3588_hardirq()` must mask the HPD IRQ in `regmap` before `IRQ_WAKE_THREAD` (threaded handler clears, schedules `hpd_work`, and unmasks). In `inno_hdmi.c` and `rk3066_hdmi.c`, `i2c_xfer` holds the adapter mutex across unmasking EDID IRQ, `reinit_completion()` (before `HDMI_EDID_SEGMENT_POINTER`), waiting, and re-masking; hardirq completes DDC and returns `IRQ_WAKE_THREAD` for `drm_helper_hpd_irq_event()` [F35, F166, F167].

## Object Lifetimes

- `rockchip_drm_init()` registers `rockchip_sub_drivers` before `rockchip_drm_platform_driver` (unregistering in reverse). `rockchip_drm_match_add()` passes cursor `p` to `platform_find_device_by_driver(p, ...)`, calls `put_device(p)`, and updates `p = d`; stateless links must be removed via `rockchip_drm_match_remove()` on probe failure and in `rockchip_drm_platform_remove()`. In `rockchip_drm_bind()`, `component_bind_all()` precedes `rockchip_drm_init_iommu()` and `drm_vblank_init()`, and `unbind` calls `drm_atomic_helper_shutdown()` and `component_unbind_all()` before `rockchip_iommu_cleanup()` [F12, F13, F100, F125].
- `rockchip_gem_prime_vunmap()` calls `vunmap(map->vaddr)` only when `rk_obj->pages && map->vaddr != rk_obj->kvaddr`. In `rockchip_fb_create()`, use `kfree(afbc_fb)` if `drm_gem_fb_init_with_funcs()` fails, but `drm_framebuffer_put(&afbc_fb->base)` if `drm_gem_fb_afbc_init()` fails afterwards [F4, F175].
- In `vop_bind()`, locks, `vop_create_crtc()`, `pm_runtime_enable()`, and `vop_initial()` must precede `devm_request_irq()`. `vop_destroy_crtc()` must call `drm_plane_cleanup()` on all planes before `drm_crtc_cleanup()` and before `vop_unbind()` returns. `vop_get_edp_connector()` must call `drm_connector_list_iter_end()` before returning early [F23, F94, F177].
- Initialize work/bridges before IRQ/notifiers and cancel work first in `unbind`: `cdn_dp_bind()` inits `dp->event_work` and bridge before `devm_extcon_register_notifier()`, and `cdn_dp_unbind()` calls `cancel_work_sync(&dp->event_work)` before encoder teardown, PM disable, or `release_firmware()`; `dw_hdmi_qp_rockchip_bind()` inits `hdmi->hpd_work` before `devm_request_threaded_irq()`, and `unbind` calls `cancel_delayed_work_sync(&hdmi->hpd_work)` before `drm_encoder_cleanup()`. In `dw_mipi_dsi_rockchip_find_second()`, call `of_node_put(remote)` each iteration, and put `remote`, `node`, and `local` on early return [F28, F34, F96].

## API Contracts

- `rockchip_drm_gem_object_mmap()` borrows the caller's object reference (do not put/close on error), and must set `vma->vm_pgoff = 0` and clear `VM_PFNMAP` via `vm_flags_mod()`. `rockchip_gem_prime_get_sg_table()` must allocate a new `sg_table` for the caller (not `rk_obj->sgt`), and `rockchip_gem_get_pages()` must set `sg_dma_address(s) = sg_phys(s)` before `dma_sync_sgtable_for_device()`. Under `CONFIG_ARM_DMA_USE_IOMMU`, `rockchip_drm_dma_attach_device()` must detach and release `to_dma_iommu_mapping(dev)` before `iommu_attach_device()`. `rockchip_drm_endpoint_is_subdriver()` returns `1`, `0` (external bridge), or `-ENODEV` (check `== 0`) [F2, F3, F39, F149, F159, F173].
- `vop_create_crtc()` inits primary/cursor planes (`possible_crtcs = 0`) before `drm_crtc_init_with_planes()`, and overlay planes (`drm_crtc_mask(crtc)`) after. `vop_crtc_reset()` and `vop_crtc_duplicate_state()` must allocate `struct rockchip_crtc_state` (`to_rockchip_crtc_state()`). `vop_crtc_atomic_begin()` calls `vop_crtc_gamma_set()` only when `color_mgmt_changed && !active_changed` [F91, F121, F176].
- `rockchip_rgb_init()` returns `ERR_PTR`, `NULL`, or pointer (`vop_bind()` fails only on `IS_ERR`, `vop_unbind()` checks `if (vop->rgb)`). `dw_mipi_dsi_rockchip_find_second()` returns `NULL`, `ERR_PTR(-EPROBE_DEFER)`, or `struct device *` (check both `IS_ERR` and non-NULL). Pass `&dp->plat_data` embedded in `rockchip_dp_device` to `analogix_dp_probe()` (`pdata_encoder_to_dp()`) [F47, F55, F122].
- Wrap GRF `regmap_write()` with `clk_prepare_enable()`/`disable_unprepare()` on `grf_clk`/`grfclk` when present. `dw_hdmi_rk3328_setup_hpd()` must end with `dw_hdmi_rk3328_read_hpd()`; `dw_hdmi_qp_rockchip_resume()` must call `hdmi->ctrl_ops->io_init(hdmi)` before `dw_hdmi_qp_resume()`. `inno_hdmi` and `rk3066_hdmi` DDC writes only allow 1-byte writes to `0x50`/`0x30` (`-EINVAL` otherwise), `.master_xfer` returns `num` on `ret == 0`, and infoframe upload must call `disable_frame`/`clear_infoframe` before writing `buffer[i]` [F58, F102, F139, F140, F141, F180].

## Error Handling

- Signedness and mailbox: in `rockchip_gem_iommu_map()`, store `iommu_map_sgtable()` in `ssize_t` and compare to `(ssize_t)rk_obj->base.size`; store `vop_convert_format()` in `int` (not `enum vop_data_format`) and `cdn_dp_mailbox_read()` in `int` to check `< 0`. `cdn_dp_mailbox_validate_receive()` must drain `mbox_size` bytes on header mismatch before returning `-EINVAL`, and on success the caller must read `req_size` bytes via `cdn_dp_mailbox_read_receive()` [F37, F42, F53, F76, F99].
- Guards and cleanup: `vop_plane_atomic_async_check()` falls back to `plane->crtc->state` if `drm_atomic_get_existing_crtc_state()` is `NULL`; `vop_crtc_duplicate_state()` and `inno_hdmi_connector_duplicate_state()` check `WARN_ON(!state)` before downcasting; `vop_crtc_reset()` passes `NULL` to `__drm_atomic_helper_crtc_reset()` if `kzalloc()` fails; `vop_bind()` calls `resource_size(res)` only after `devm_ioremap_resource()`. Call `drm_encoder_cleanup()` if `dw_hdmi[_qp]_bind()` fails; check `IS_ERR(dp->adp)` in `rockchip_dp_suspend()`/`resume()`; treat `-ENODEV` from `devm_of_dp_aux_populate_bus()`/`drm_of_find_panel_or_bridge()` as non-fatal in `rockchip_dp_probe()`; log atomic check rejections with `DRM_DEBUG_KMS()` and suppress `-EPROBE_DEFER` logs [F10, F43, F44, F45, F46, F52, F101, F171, F183].

## External Contracts

- `rockchip_gem_dumb_create()` aligns `args->pitch` to 64 bytes. `cdn_dp_mailbox_send()` and `validate_receive()` encode multi-byte integers in big-endian. `inno_hdmi` and `rk3066_hdmi` timing setup programs `HDELAY`/`VDELAY` with `htotal - hsync_start` and `vtotal - vsync_start` (`+ vsync_offset` on RK3066) [F77, F83, F146].

## Known Pitfalls

- 64-bit math: never divide `u64`/`unsigned long long` with `/`; use `div_u64()`, `do_div()`, or `DIV_ROUND_CLOSEST_ULL()`. Widen operands to `u64` in `dw_mipi_dsi_get_lane_mbps()` (`(u64)fout * _prediv`, `(u64)_fbdiv * fin`), `cdn_dp_config_video()` (`(u64)tu_size_reg * mode->clock * bit_per_pix`, `u64 symbol`), and `rockchip_drm_init_iommu()` (`u64` `start`/`end` for `end - start + 1`) [F104, F105, F106, F107].
- Offsets and pointers: index `vop->regsbak` (`uint32_t *`) with `offset >> 2` or `i / 4` (`vop->regs`/`len` use bytes); in `cdn_dp_firmware_init()`, add byte sizes to `fw->data` (`const u8 *`) before `(const u32 *)` cast and step `i_mem++`/`d_mem++` per `i += 4` in `cdn_dp_load_firmware()`; pass unscaled register indices to `inno_hdmi.c` `hdmi_readb`/`writeb` (which multiply by 4), unlike byte-indexed `rk3066_hdmi.c`; in `dw_hdmi_rockchip_bind()`, save `.phy_data` to `hdmi->chip_data` and set `plat_data->phy_data = hdmi` and `priv_data = hdmi` on a `devm_kmemdup()` copy [F115, F117, F118, F119].
- Sequencing: in `dw_mipi_dsi_phy_init()`, write `PLL_INPUT_AND_LOOP_DIVIDER_RATIOS_CONTROL` (`PLL_LOOP_DIV_EN | PLL_INPUT_DIV_EN`) after both `LOW_PROGRAM_EN` and `HIGH_PROGRAM_EN` writes to `PLL_LOOP_DIVIDER_RATIO`; in `dw_mipi_dsi_phy_get_timing()`, decrement `i` if `i == ARRAY_SIZE(hstt_table)`; in `cdn-dp-core.c`, poll `jiffies` with `time_before(jiffies, timeout)` [F69, F95, F114].
