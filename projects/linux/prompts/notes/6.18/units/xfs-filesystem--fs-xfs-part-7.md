# XFS FILESYSTEM — fs/xfs (part 7)

This unit implements XFS VFS superblock lifecycle and mount context operations (`xfs_super.c`), copy-on-write and file range remapping (`xfs_reflink.c`), realtime volume extent allocation and growfs (`xfs_rtalloc.c`), symbolic links (`xfs_symlink.c`), refcount/rmap log items and recovery (`xfs_refcount_item.c`, `xfs_rmap_item.c`), and sysfs/sysctl/procfs/tracepoint glue.

## Architecture & Data Flow
- In `xfs_fs_parse_param()` and `xfs_fs_reconfigure()`, `fc->s_fs_info` (`parsing_mp`/`new_mp`) has `m_super == NULL` and unpopulated `m_sb`: never dereference `parsing_mp->m_super`, ensure each `Opt_*` case breaks/returns without fallthrough, set `XFS_QFLAGS_MNTOPTS` on quota options (and clear it in `xfs_fs_fill_super()` and `xfs_fs_reconfigure()`), and in `xfs_fs_reconfigure()` call `xfs_finish_flags()` on `mp = XFS_M(fc->root->d_sb)` and `xfs_set_inode_alloc(mp, mp->m_sb.sb_agcount)` when `XFS_FEAT_SMALL_INUMS` changes. [F223, F237, F247, F279]
- `xfs_init_fs_context()` must set `mp->m_finobt_nores = true` so log recovery `ifree` transactions do not require per-AG finobt reservations, and must not read `fc->sb_flags` (copy those in `xfs_fs_fill_super()` before `xfs_fs_validate_params(mp)`). In `xfs_setup_devices()`, `xfs_configure_buftarg()` must use `sb_dblocks` for `m_ddev_targp`, `sb_logblocks` for external `m_logdev_targp`, and `sb_rblocks` for external `m_rtdev_targp`. [F189, F244, F264]
- Drain reserve pools into `mp->m_free[i].res_saved` via `xfs_save_resvblks(mp)` before `xfs_remount_ro()` or `xfs_fs_freeze()` syncs/quiesces metadata, and restore them via `xfs_restore_resvblks(mp)` in `xfs_remount_rw()` and `xfs_fs_unfreeze()`. In `xfs_reinit_percpu_counters()`, only set `XC_FREE_RTEXTENTS` from `sb_frextents` when `!xfs_has_zoned(mp)`. Clamp `st->f_bfree` and `st->f_ffree` at `0` with signed comparisons in `xfs_statfs_data()` and `xfs_statfs_inodes()`. [F236, F238, F265]
- `rtg->rtg_rsum_cache` shares a union with `rtg_open_zone` (valid only when `!xfs_has_zoned(mp)`), must be initialized to `0xFF` (`memset(..., -1, rbmblocks)`) in `xfs_alloc_rsum_cache()`, and stores a strict upper bound on free summary levels: `xfs_rtany_summary()` clamps `high = min(high, rsum_cache[bbno] - 1)` and sets `rsum_cache[bbno] = log + 1` only when `log + 1 < rsum_cache[bbno]`. [F213, F234]
- Before `xfs_rtallocate_range()` clears `[start, end]` via `xfs_rtmodify_range()`, it must find the enclosing free extent `[preblock, postblock]`, decrement its summary count via `xfs_rtmodify_summary()`, and increment summary counts for remaining fragments. `xfs_rtallocate_clamp_len()` must clamp `rtxlen` so `startrtx + rtxlen <= rtg->rtg_extents` before rounding down to a multiple of `prod` via `xfs_rtalloc_align_len()`. On `-ENOSPC` (`!noalign`) retry in `xfs_bmap_rtalloc()`, restore `ap->offset = orig_offset` and `ap->length = orig_length` and set `noalign = true`. [F233, F246, F260]
- In `xfs_growfs_rt()`, validate `XFS_FSB_TO_B(mp, in->extsize)` against `[XFS_MIN_RTEXTSIZE, XFS_MAX_RTEXTSIZE]` and `in->newblocks` via `xfs_sb_validate_fsb_count()` and `xfs_rt_check_size(mp, in->newblocks - 1)`. Compute `sb_rextslog` via `xfs_compute_rextslog()`. Growing the RT volume in `xfs_growfs_rt_bmblock()` or `xfs_growfs_rt_zoned()` must set `XFS_FEAT_REALTIME` and call `xfs_rtrmapbt_compute_maxlevels(mp)` and `xfs_rtrefcountbt_compute_maxlevels(mp)` (plus update `m_rsumlevels`, `m_rsumblocks`, and `xfs_trans_resv_calc(mp, &mp->m_resv)` in `xfs_growfs_rt_bmblock()`). [F232, F261, F262]
- In `xfs_reflink_end_cow_extent_locked()`, copy `got` to `del`, trim `del` to `[*offset_fsb, end_fsb)` with `xfs_trim_extent()` and `min(data.br_blockcount, del.br_blockcount)` before remapping into the data fork, and pass untrimmed `got` to `xfs_bmap_del_extent_cow()`. `xfs_reflink_clear_inode_flag()` must verify `xfs_can_free_cowblocks(ip)` before canceling CoW blocks or clearing `XFS_DIFLAG2_REFLINK`. [F256, F320]
- In `xfs_inactive_symlink_rmt()`, setting `ip->i_disk_size = 0` before truncating blocks requires changing `VFS_I(ip)->i_mode` from `S_IFLNK` to `S_IFREG` and logging `XFS_ILOG_CORE` in the same transaction. [F239]
- In `xlog_recover_{cui,rtcui,rui,rtrui}_commit_pass2()`, check `iov_len` against the 0-extent format size before reading `nextents`, and then against the exact `nextents` format size. In `xfs_refcount_recover_work()` and `xfs_rmap_recover_work()`, validate every extent via `xfs_cui_validate_phys()` / `xfs_rui_validate_map()` (`xfs_verify_rtbext()` if `isrt` else `xfs_verify_fsbext()`) before `xfs_trans_alloc()`. Allocate/free CUI and RUI items with `nextents > 16` via `kzalloc()`/`kfree()`, and use `xfs_cui_cache`/`xfs_rui_cache` only when `nextents <= 16`. [F252, F253, F254]
- Keep `struct __xfsstats` `uint32_t` fields, `xstats[]` in `xfs_stats_format()`, `XFSSTAT_START_XQMSTAT`/`XFSSTAT_END_XQMSTAT`, and `struct xfsstats::a` in lockstep (`uint64_t` fields at the end); `xfs_stats_clearall()` must save/restore `per_cpu_ptr(stats, c)->s.vn_active` under `preempt_disable()`. Keep `xfs_error_meta_init[]` ordered to match `XFS_ERR_*` enum indices used by `xfs_error_get_cfg()`. [F248, F250, F251]

## Synchronization
- In `xfs_remount_ro()`, after `sync_filesystem()`, call `xfs_blockgc_stop(mp)`, `xfs_blockgc_free_space(mp, &icw)` with `XFS_ICWALK_FLAG_SYNC`, `xfs_inodegc_stop(mp)`, and `xfs_zone_gc_stop(mp)` before `xfs_log_clean(mp)` and `xfs_set_readonly(mp)`. Wrap `xfs_save_resvblks(mp)` and `xfs_log_quiesce(mp)` in `memalloc_nofs_save()`/`restore()` in `xfs_fs_freeze()`. [F192, F303]
- Never call `xfs_flush_inodes()` under `XFS_ILOCK` or a folio lock, and serialize it via `flush_work(&mp->m_flush_inodes_work)` before and after queueing on `mp->m_sync_workqueue`. Use non-blocking `xfs_inodegc_push(mp)` (not `xfs_inodegc_flush(mp)`) in `xfs_fs_statfs()`. Keep `WQ_MEM_RECLAIM` on `xfs_alloc_wq`, `m_buf_workqueue`, `m_unwritten_workqueue`, `m_reclaim_workqueue`, `m_blockgc_wq`, and `m_inodegc_wq`. [F200, F201, F304]
- In `xfs_reflink_remap_prep()`, hold `xfs_ilock2_io_mmap(src, dest)` across prep, `xfs_reflink_set_inode_flag()`, and `xfs_flush_unmap_range()`, demoting `src`'s `IOLOCK_EXCL | MMAPLOCK_EXCL` only after setting `XFS_IREMAPPING` when `inode_in != inode_out`. In `xfs_reflink_set_inode_flag()`, each locked inode (`src`, and `dest` if `src->i_ino != dest->i_ino`) must be joined with `XFS_ILOCK_EXCL` or unlocked before `xfs_trans_commit(tp)`. After dropping `XFS_ILOCK` for `xfs_trans_alloc_inode()` in `xfs_reflink_fill_cow_hole()` or `xfs_reflink_fill_delalloc()`, re-run `xfs_find_trim_cow_extent()` under `XFS_ILOCK_EXCL` and cancel `tp` if `!*shared` or `found`. [F181, F206, F242]
- In `xfs_rtallocate_rtg()` on `xfs_has_rtgroups(mp)` mounts, `args.rtg` is locked with `XFS_RTGLOCK_BITMAP` without joining `tp` until `xfs_rtallocate_adjust_for_busy()` succeeds; earlier failures must jump to `out_unlock` (`*rtlocked = false`), whereas after `xfs_rtgroup_trans_join()` `tp` owns the lock (`out_release`). At mount, `xfs_rtmount_rtg()` must call `xfs_rtmount_iread_extents()` under `XFS_ILOCK_EXCL` on all `rtg->rtg_inodes[i]`. [F186, F187]
- In `xfs_growfs_rt_bmblock()`, lock/join `rtg` with `XFS_RTGLOCK_BITMAP | XFS_RTGLOCK_RMAP` and update both `i_disk_size` and `i_size_write()` on `rbmip` and `rsumip`. In `xfs_rtalloc_reinit_frextents()`, hold `XFS_RTGLOCK_BITMAP_SHARED` around `xfs_rtalloc_query_all()`, and update `mp->m_sb.sb_frextents` (under `mp->m_sb_lock`) and `XC_FREE_RTEXTENTS` via `xfs_set_freecounter()`. [F197, F198, F235]
- Dispatch realtime intents (`ri->ri_realtime`) in `xfs_refcount_defer_add()` and `xfs_rmap_defer_add()` to `xfs_rtrefcount_update_defer_type` and `xfs_rtrmap_update_defer_type` to avoid mixing RT and data AGF locks. In sysfs, hold `log->l_icloglock` in `log_head_lsn_show()` and use `xlog_crack_atomic_lsn()` in `log_tail_lsn_show()`. [F199, F308]

## Object Lifetimes
- `xfs_cui_init()` and `xfs_rui_init()` set `cui_refcount`/`rui_refcount` to 2; `xfs_cui_release()` and `xfs_rui_release()` delete from the AIL and free only when `atomic_dec_and_test()` hits 0. `xfs_refcount_intent` and `xfs_rmap_intent` hold `ri_group` dropped by `xfs_{refcount,rmap}_update_cancel_item()`; do not cancel when `finish_item` returns `-EAGAIN` (`ri_blockcount > 0`). In `xfs_{refcount,rmap}_recover_work()`, allocate `tp` with `xlog_recover_resv(&M_RES(mp)->tr_itruncate)`; `xlog_recover_finish_intent(tp, dfp)` transfers `dfp` ownership to `tp`. [F163, F164, F166]
- In `xfs_open_devices()`, `xfs_alloc_buftarg()` consumes `rtdev_file`/`logdev_file` only on success; on error or when `file_bdev(logdev_file) == ddev`, reset `ERR_PTR` `mp->m_*_targp` fields to `NULL`, free allocated buftargs with `xfs_free_buftarg()`, and close unconsumed files with `bdev_fput()` (not `fput()`). [F170, F319]
- `xfs_init_fs_context()` allocates `fc->s_fs_info`; once transferred to `sb->s_fs_info`, `xfs_kill_sb()` frees it via `xfs_mount_free(XFS_M(sb))` after `kill_block_super(sb)` (else `xfs_fs_free()` frees it). `xfs_fs_parse_param()` must `kfree(parsing_mp->m_logname)`/`m_rtname` before overwriting with `kstrdup()`. In `xfs_fs_fill_super()`, errors after `xfs_mountfs(mp)` succeeds must jump to `out_unmount` (`xfs_filestream_unmount()` + `xfs_unmountfs()`). `xfs_destroy_caches()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F174, F175, F176, F316]
- In `xfs_reflink_remap_extent()`, `xfs_trans_alloc_inode()` must reserve `XFS_EXTENTADD_SPACE_RES(mp, XFS_DATA_FORK)` blocks, and on `-EDQUOT`/`-ENOSPC` fallback must call `xfs_trans_reserve_quota_nblks()` for `dmap->br_blockcount` if `!smap_real && dmap_written`. [F182]

## API Contracts
- Callers of `xfs_reflink_cancel_cow_blocks()` and `xfs_reflink_clear_inode_flag()` must hold `XFS_ILOCK_EXCL` and join `ip` via `xfs_trans_ijoin(*tpp, ip, 0)`. Convert byte ranges `[offset, offset + count)` in CoW helpers using floor `XFS_B_TO_FSBT()` for `offset_fsb` and ceiling `XFS_B_TO_FSB()` for `end_fsb`. `xfs_reflink_cancel_cow_range()` takes byte `offset`/`count` and asserts `ip->i_cowfp != NULL`, whereas `xfs_reflink_cancel_cow_blocks()` takes `offset_fsb` and exclusive `end_fsb` and checks `xfs_inode_has_cow_data(ip)`. [F179, F218, F287]
- Check `shared_len != 0` before reading `*shared_offset` after `xfs_reflink_find_shared()` / `xfs_reflink_find_rtshared()`. Pass `offset + len - 1` to `filemap_write_and_wait_range()` in `xfs_reflink_unshare()`. `xfs_reflink_end_cow_extent_locked()` must always advance `*offset_fsb` (to `end_fsb` or `del.br_startoff + del.br_blockcount`). Never call `xfs_reflink_recover_cow()` when cached inodes could hold live CoW extents (e.g. `xfs_remount_rw()`). [F216, F217, F219, F241]
- `xfs_reflink_remap_prep()` must reject cross-RT or mixed-DAX remaps with `-EINVAL`, and when `pos_out > XFS_ISIZE(dest)`, zero post-EOF preallocations and flush/unmap from `XFS_ISIZE(dest)` across `*len + (pos_out - XFS_ISIZE(dest))`. `xfs_reflink_max_atomic_cow()` must apply `rounddown_pow_of_two()`. `xfs_reflink_remap_extent()` must clamp `dmap->br_blockcount = min(dmap->br_blockcount, smap.br_blockcount)` before any no-op return, and `xfs_reflink_remap_blocks()` must always set `*remapped` before returning. [F220, F271, F331, F332]
- `xfs_rtallocate_rtgs()` and `xfs_rtallocate_rtg()` take `minlen`, `maxlen`, `prod` in `xfs_rtxlen_t`, while `bno_hint` (sentinel `NULLFSBLOCK`, not `0`; test `bno_hint != NULLFSBLOCK`) and `*bno`, `*blen` are in FS blocks. `xfs_rtallocate_extent_{exact,near,size}()` require `minlen` and `maxlen` aligned to `prod` via `xfs_rtalloc_align_minmax()`. `xfs_rtany_summary()` sets signed `int *maxlog = -1` on no free extents even when returning `0` (check `maxlog >= 0`). In `xfs_rtmount_readsb()`, compute buffer length via `mp->m_sb.sb_blocksize >> BBSHIFT` (not `XFS_FSB_TO_BB()`). [F207, F208, F209, F212, F215]
- `xfs_shutdown_devices()` must call `blkdev_issue_flush()` and `invalidate_bdev()` on log, RT, and data devices. `xfs_fs_drop_inode()` must return `0` when `XFS_IRECOVERY` is set, and `xfs_fs_evict_inode()` must call `dax_break_layout_final(inode)` when `IS_DAX(inode)` before page truncation. [F326, F327]
- `xfs_symlink()` rejects `strlen(target_path) >= XFS_SYMLINK_MAXLEN` (`-ENAMETOOLONG`), sets `args.idmap` and `args.pip = dp`, and calls `xfs_icreate_dqalloc()`. `xfs_readlink()` requires a `XFS_SYMLINK_MAXLEN + 1` buffer and validates `ip->i_disk_size` in `1..XFS_SYMLINK_MAXLEN` and (for `XFS_DINODE_FMT_LOCAL`) `ip->i_df.if_data != NULL`, marking `XFS_SICK_INO_SYMLINK` on corruption. [F255, F321, F329]
- Set `cui_next_extent`/`rui_next_extent` to `nextents` when bulk-copying extents into CUI/RUI items, and pass the intent type (`XFS_LI_CUI`, `XFS_LI_CUI_RT`, `XFS_LI_RUI`, `XFS_LI_RUI_RT`) to `xlog_recover_release_intent()` in CUD/RUD pass2 recovery. Embed all sysfs attributes on `xfs_sysfs_ops` ktypes in `struct xfs_sysfs_attr`. [F228, F229, F299]

## Error Handling
- In `xfs_{refcount,rmap}_finish_one_cleanup()`, read `rcur->bc_ag.agbp` before `xfs_btree_del_cursor(rcur, error)` and call `xfs_trans_brelse(tp, agbp)` only when `error && agbp`. In `xfs_symlink()`, join `dp` with `lock_flags = 0` only after `xfs_dialloc()` and `xfs_icreate()` succeed; on error after `xfs_icreate()`, call `xfs_trans_cancel(tp)` before unlocking/finishing/releasing `du.ip`, and unlock `dp` if `unlock_dp_on_error`. [F165, F167, F195]
- If `xfs_fs_freeze()` fails on a non-readonly mount, restart `inodegc`, `blockgc`, and `zone_gc` (stopped in `xfs_fs_sync_fs()` at `SB_FREEZE_PAGEFAULT`). Unwind `mp->m_free[i].count` in `xfs_init_percpu_counters()` with `while (--i >= 0)`. [F172, F173]
- In `xfs_growfs_rtg()`, save `old_rsum_cache` so on `xfs_growfs_rt_bmblock()` failure `out_error` restores geometry, frees the new cache, and restores `old_rsum_cache`. In `xfs_growfs_rt()`, if `xfs_growfs_rtg()` fails for `rgno >= old_rgcount`, grab `rtg`, call `xfs_rtunmount_rtg(rtg)`, `xfs_rtgroup_rele(rtg)`, and `xfs_rtgroup_free(mp, rgno)`; store post-loop `xfs_update_secondary_sbs()` and `xfs_metafile_resv_init()` returns in `error2` (ignoring `-ENOSPC` from `resv_init`). In `xfs_rtallocate_rtg()`, when `xfs_rtallocate_extent_near()` returns `-ENOSPC`, call `xfs_rtbuf_cache_relse(&args)` and reset `error = 0` to fall back to `xfs_rtallocate_extent_size()`. [F184, F185, F211, F214]

## External Contracts
- Never rename slab cache strings passed to `kmem_cache_create()` in `xfs_init_caches()` (exposed via `/proc/slabinfo` and `/sys/kernel/slab`). [F266]

## Known Pitfalls
- In `xfs_reflink_cancel_cow_blocks()`, non-deleting branches must call `xfs_iext_prev(ifp, &icur)` before `xfs_iext_get_extent()` (deleting helpers reposition `icur`). Call `xfs_iext_count_extend()` in `xfs_reflink_end_cow_extent_locked()` and `xfs_reflink_remap_extent()` only after all no-op early-exit checks. Loop `xfs_bmapi_write()` in `xfs_reflink_fill_delalloc()` until `cmap->br_startoff + cmap->br_blockcount > imap->br_startoff`. [F243, F249, F267]
- Pass `&M_RES(nmp)->tr_growrtfree` (not `&M_RES(mp)->tr_growrtfree`) to `xfs_trans_alloc(mp, ...)` in `xfs_growfs_rt_{bmblock,zoned}()`. In `xfs_rtcopy_summary()`, subtract `sum` via `oargs`, add via `nargs`, and keep the `(xfs_srtblock_t)bbno >= 0` cast. In `xfs_rtallocate_rtgs()`, reset `bno_hint = NULLFSBLOCK` each iteration and `rtlocked = false` inside the loop. Check `ap->datatype & XFS_ALLOC_INITIAL_USER_DATA` (not `ap->eof && ap->offset == 0`) for `xfs_rtpick_extent()`. [F273, F274, F275, F277]
- Avoid 32-bit overflow/shift bugs: widen `sb_rgcount - 1` to `xfs_rtxnum_t` in `xfs_last_rtgroup_extents()`; use `howmany_64()` for RT group counts; check `log2 != -1` before `1ULL << log2` in `xfs_rtpick_extent()`; in `xfs_rtallocate_extent_near()`, use `(1ULL << (maxlog + 1)) - 1` with `min_t(xfs_rtblock_t, ...)` and guard `2 << (maxlog - mp->m_blkbit_log)` behind `maxlog < mp->m_blkbit_log`; in `xfs_fs_fill_super()`, validate `XFS_B_TO_FSBT(mp, MAX_LFS_FILESIZE)` with `xfs_verify_fileoff()`. [F282, F283, F285, F286, F288, F291]
- In `xfs_stats_format()`, do not reset `j = 0` in the inner loop and use `scnprintf(buf + len, PATH_MAX - len, ...)`. Never add attributes calling `err_to_mp()` (like `fail_at_unmount`) to `xfs_error_ktype.default_groups`. [F280, F298, F300]
