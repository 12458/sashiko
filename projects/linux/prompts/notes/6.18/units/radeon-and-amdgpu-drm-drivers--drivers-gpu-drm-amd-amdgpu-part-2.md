# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 2)

Implements `amdgpu` device lifecycle and reset (`amdgpu_device.c`), IP discovery parsing/sysfs (`amdgpu_discovery.c`), execution contexts (`amdgpu_ctx.c`), debugfs (`amdgpu_debugfs.c`), and hang coredumps (`amdgpu_dev_coredump.c`).

## Architecture & Data Flow
- In `amdgpu_discovery.c`, validate `instance < HWIP_MAX_INSTANCE` and `hw_id < HW_ID_MAX` via `amdgpu_discovery_validate_ip()` before indexing arrays, jumping to `next_ip` to advance `ip_offset` on failure. Read `ip->sub_revision`/`variant` only if `ihdr->version >= 3`. When `ihdr->base_addr_64_bit` is set, convert `base_address_64[]` from LE, mask lower 32 bits with `0x3FFFFFFF`, and advance `ip_offset` via `struct_size(ip, base_address_64, ...)`. [F227, F254, F327]
- In `amdgpu_discovery_read_binary_from_mem()`, non-VFs (`!amdgpu_sriov_vf(adev)`) must poll `mmMP0_SMN_C2PMSG_33` for `0x80000000` before reading `mmRCC_CONFIG_MEMSIZE`. In `amdgpu_discovery_set_ip_blocks()`, run `amdgpu_discovery_harvest_ip()` after `amdgpu_discovery_reg_base_init()` and before `get_mall_info()` and `sysfs_init()`; on VFs, `amdgpu_discovery_set_psp_ip_blocks()` must precede `set_ih_ip_blocks()`. [F239, F272, F328]
- `amdgpu_discovery_read_from_harvest_table()` reads at most 32 `harvest_info->list` entries until `hw_id == 0`. Harvesting `VCN_HWID` clears `vcn.inst_mask` and `jpeg.inst_mask` together, and sets `AMD_HARVEST_IP_VCN_MASK` and `AMD_HARVEST_IP_JPEG_MASK` when `vcn_harvest_count == num_vcn_inst`, which `amdgpu_device_ip_block_add()` checks to skip VCN/JPEG. Allocate `ip_hw_instance` with `struct_size` and set `num_base_addresses` before writing `base_addr[]`; stop `base_addr_show()` when `at + 12 > PAGE_SIZE`. [F240, F257, F258, F304, F326]
- `amdgpu_device_pm_notifier()` only sets/clears `in_s4` on hibernation prepare/post, deferring `amdgpu_device_evict_resources()` to `prepare()`/`suspend()`. `amdgpu_device_suspend()` disables `amdgpu_ttm_set_buffer_funcs_status(adev, false)` after `evict_resources()`; `in_s0ix` in phase 2 skips PSP, GFX, MES, and SDMA 5.x+, requiring `cancel_delayed_work_sync(&adev->gfx.idle_work)` on GC 10.x+. Resume re-enables TTM buffer funcs after phase 2 (`sched.ready`) and calls `amdgpu_vram_mgr_clear_reset_blocks()` before clearing `in_suspend`. [F229, F243, F333, F334]
- Bare-metal `amdgpu_device_pre_asic_reset()` must call each IP's `dump_ip_state()` before `amdgpu_device_ip_suspend()` for `amdgpu_coredump()`. On lost VRAM in `amdgpu_device_reinit_after_reset()`, call `amdgpu_inc_vram_lost()` and `amdgpu_device_fill_reset_magic()`. Reference job hw fences as `&job->hw_fence.base`. `amdgpu_device_set_cg_state()`/`pg_state()` iterate `ip_blocks` forward when gating and in reverse when ungating. Increment `index++` on `timeout == 0` in `amdgpu_device_get_job_timeout_settings()`. [F230, F244, F277, F278, F312]
- `mgr->ctx_handles` uses `idr_init_base(..., 1)` (`[1, AMDGPU_VM_MAX_NUM_CTX)`, `*id = 0` on error). `amdgpu_device_check_arguments()` enforces power-of-two `amdgpu_sched_jobs >= 4` for `seq & (amdgpu_sched_jobs - 1)`. `amdgpu_ctx_priority_override()` updates `override_priority` and calls `amdgpu_ctx_set_entity_priority()` (`drm_sched_entity_set_priority()` and GFX/COMPUTE `drm_sched_entity_modify_sched()`) on existing entities. `amdgpu_device_cache_switch_state()` requires non-NULL ATI downstream `swds` and ATI/AMD upstream `swus`. [F235, F251, F287, F323]

## Synchronization
- In `amdgpu_device_gpu_recover()`, every exit after `amdgpu_device_recovery_get_reset_lock()` must call `amdgpu_device_recovery_put_reset_lock()` before unlocking `hive->hive_lock` and `amdgpu_put_xgmi_hive()`. In `amdgpu_pci_error_detected()` (`pci_channel_io_frozen`), the reset lock stays held until `amdgpu_pci_slot_reset()` fails or `amdgpu_pci_resume()` (only if `pci_channel_state == pci_channel_io_frozen`) releases it. [F170, F338]
- In `amdgpu_device_gpu_recover()`, check `dma_fence_is_signaled(&job->hw_fence.base)` after `amdgpu_device_halt_activities()` and before `amdgpu_device_asic_reset()`. In `amdgpu_do_asic_reset()`, multi-node XGMI resets must queue `xgmi_reset_work` on `system_unbound_wq` for all devices before flushing any (`hive->tb` barrier), and `amdgpu_device_asic_reset()` must call `amdgpu_device_stop_pending_resets()` before `amdgpu_device_sched_resume()`. [F190, F191, F192]
- Call `amdgpu_register_gpu_instance()` before `amdgpu_device_ip_late_init()` in `amdgpu_device_init()` so `mgpu_info.num_dgpu` is updated for `amdgpu_device_enable_mgpu_fan_boost()`. In `amdgpu_device_halt()`, call `drm_dev_unplug()`, `amdgpu_irq_disable_all()`, `amdgpu_fence_driver_hw_fini()`, and set `no_hw_access = true` before `amdgpu_device_unmap_mmio()`. In `amdgpu_device_resume()` (`CONFIG_PM`), bracket hotplug/HPD calls with `dev->dev->power.disable_depth++` / `--`. [F185, F189, F202]
- Hold `mgr->lock` when accessing `mgr->ctx_handles` and call `kref_get(&ctx->refcount)` before unlocking (`amdgpu_ctx_get()`); `mgr->lock` nests outside `ctx->ring_lock` and `stable_pstate_ctx_lock`. Drop `ctx->ring_lock` before `dma_fence_wait()`/`put()` in `amdgpu_ctx_wait_prev_fence()`. Finish `drm_sched_entity_init()` before `cmpxchg(&ctx->entities[hw_ip][ring], NULL, entity)` in `amdgpu_ctx_init_entity()`. Guard `amdgpu_ctx_set_stable_pstate()` with `drm_dev_enter()`/`exit()` in `amdgpu_ctx_fini()`. [F186, F194, F346, F347, F354]
- In `amdgpu_debugfs.c`, hold `grbm_idx_mutex` (`amdgpu_gfx_select_se_sh`) or `srbm_mutex` (`amdgpu_gfx_select_me_pipe_q`) across selection, access, and reset to `0xFFFFFFFF`/`0`, locking in order `rd->lock -> grbm_idx_mutex -> srbm_mutex -> pm.mutex`. Hold `reset_domain->sem` (write in `test_ib_show`, read in `ib_preempt`) across `drm_sched_wqueue_stop()`/`start()`. [F198, F199, F201]
- Read `adev->gang_submit` via `dma_fence_get_rcu_safe()` under `rcu_read_lock()` in `amdgpu_device_get_gang()` and update via `cmpxchg()` in `amdgpu_device_switch_gang()` only after `dma_fence_is_signaled(old)` (putting `old` twice on swap). `amdgpu_device_enforce_isolation()` requires `enforce_isolation_mutex`, returns any unsignaled `gang_submit` fence before switching `isolation->owner`, and passes `GFP_NOWAIT` to `amdgpu_sync_fence()`. `amdgpu_coredump()` also requires `GFP_NOWAIT`. [F203, F204, F341, F342]
- Separate `memcpy_toio()`/`fromio()` and HDP flush/invalidate with `mb()` in `amdgpu_device_aper_access()`. Indirect PCIe accessors must hold `spin_lock_irqsave(&adev->pcie_idx_lock, flags)`, read back writes, and reset `pcie_index_hi_offset` to `0` in `*_ext`. SR-IOV runtime KIQ access in `amdgpu_device_rreg`/`wreg` and `xcc_rreg`/`wreg` must use `down_read_trylock(&adev->reset_domain->sem)`. `amdgpu_device_wb_get()`/`free()` require `spin_lock_irqsave(&adev->wb.lock, flags)`. [F206, F330, F340, F345]

## Object Lifetimes
- In `amdgpu_ctx_mgr_entity_fini()`, after `drm_sched_entity_fini()` on entities with `kref_read(&ctx->refcount) == 1`, call `kref_put(&ctx->refcount, amdgpu_ctx_fini)`. `amdgpu_ctx_fini()` must call `amdgpu_ctx_set_stable_pstate(ctx, ctx->stable_pstate)` under `stable_pstate_ctx_lock` before `kfree(ctx)` to clear unreferenced `adev->pm.stable_pstate_ctx`. In `amdgpu_ctx_init_entity()`, stack `&sched` for `drm_sched_entity_init()` is valid only when `num_scheds == 1`. [F164, F168, F300]
- In `amdgpu_device_ip_init()`, `COMMON` and `GMC` run `hw_init()` inline during `sw_init` before `amdgpu_ib_pool_init()` and `amdgpu_ucode_create_bo()`, with `wb_init()`, `allocate_static_csa()`, and `seq64_init()` right after GMC `hw_init()`; `amdgpu_ras_recovery_init()` runs after `hw_init_phase2()`. In `amdgpu_device_ip_fini()`, free kernel BOs (`ucode`, CSA, wb, `mem_scratch`, IB pool, `seq64`, `doorbell_fini()`) at `AMD_IP_BLOCK_TYPE_GMC` before GMC `sw_fini`. [F169, F316, F317]
- In `amdgpu_device_init()`, `amdgpu_reset_create_reset_domain()` must precede `amdgpu_virt_init()`, `ip_early_init()`, and `RREG32()`, while sysfs inits (`atombios`, `pm`, `ucode`, `device_attr`, `fru`, `reg_state`, `xcp`) must follow `amdgpu_device_ip_late_init()`. Replacing `adev->reset_domain` with `hive->reset_domain` in `amdgpu_device_ip_init()` requires `amdgpu_reset_get_reset_domain()` before `put_reset_domain()` and `amdgpu_put_xgmi_hive()` on all paths. [F172, F315, F319]
- In `amdgpu_device_fini_hw()`, `flush_delayed_work(&adev->delayed_init_work)` precedes `amdgpu_virt_request_full_gpu()` and `amdgpu_irq_disable_all()`, and `amdgpu_ras_pre_fini()` precedes `amdgpu_device_ip_fini_early()`. `ip_fini_early()` runs `amdgpu_device_smu_fini_early()` (`SMC` on `GC <= 9.0.0`) before the reverse `amdgpu_ip_block_hw_fini()` loop. `amdgpu_device_cache_pci_state()` must `kfree(adev->pci_state)` first; `cache_switch_state()` returns early if `swus` is set. BACO/Mode1 resets pair `suspend_display_audio()` with `resume_display_audio()`. [F173, F174, F176, F336]
- `amdgpu_discovery_reg_base_init()` stores interior pointers of `adev->mman.discovery_bin` into `adev->reg_offset`, so `discovery_bin` must stay fixed until `amdgpu_discovery_fini()`, and `amdgpu_discovery_init()` failure must free and NULL it. In `amdgpu_discovery_sysfs_fini()`/`die_free()`/`ip_hw_free()`, `list_del_init` and `kobject_put()` all child kobjects (dropping `kset->list_lock` around `kobject_put()`) before putting parents; `die_kobj_release()` uses `to_kset(kobj)` and leaves `kfree(ip_top)` to `ip_disc_release()`. [F177, F178, F237, F305]
- In `amdgpu_debugfs.c`, pair `pm_runtime_get_sync()` (even if `< 0`) with `pm_runtime_put_autosuspend()`, and `amdgpu_virt_enable_access_debugfs()` with `disable_access_debugfs()` on all exits. In `amdgpu_pt_info_read()`, pair `amdgpu_bo_ref()` with `amdgpu_bo_unref(&root_bo)` on `amdgpu_bo_reserve()` error and after `unreserve()`. In `amdgpu_coredump()`, copy `*ti` from `amdgpu_vm_get_task_info_pasid()` into `coredump->reset_task_info` and call `amdgpu_vm_put_task_info(ti)` before `dev_coredumpm()`. [F180, F182, F183]

## API Contracts
- `amdgpu_ctx_get_entity()` requires `hw_ip < AMDGPU_HW_IP_NUM`, `instance == 0`, and `ring < amdgpu_ctx_num_entities[hw_ip]`. `amdgpu_ctx_add_fence()`, `get_fence()`, and `wait_prev_fence()` downcast `entity` via `to_amdgpu_ctx_entity()`. `amdgpu_ctx_add_fence()` requires a `struct drm_sched_fence` (for `to_drm_sched_fence()`), calls `dma_fence_get()`, adds displaced `other` time to `mgr->time_spend`, and puts `other`. `centity->sequence` starts at `1`; `get_fence()` maps `~0ull` to `sequence - 1` and returns `ERR_PTR(-EINVAL)` (`seq >= sequence`), `NULL` (evicted), or a new `dma_fence_get()` ref. [F165, F166, F248, F250, F299, F301]
- `amdgpu_discovery_get_nps_info()` allocates `*ranges` with `kvcalloc()` and transfers ownership on `0` return. `amdgpu_device_switch_gang()` and `amdgpu_device_enforce_isolation()` return `NULL` to proceed or a refcounted `struct dma_fence *` dependency. In `amdgpu_coredump()`, `job` is nullable (check before `job->pasid`/`job->base.sched`), and `coredump->ring` must be checked for `NULL` in `amdgpu_devcoredump_read()`. [F179, F215, F226]
- In `amdgpu_debugfs.c`, `RREG32`, `amdgpu_mm_wreg_mmio_rlc`, and `RREG32_DIDT`/`WREG32_DIDT` take `*pos >> 2`, while `RREG32_PCIE*`/`WREG32_PCIE*` and `RREG32_SMC`/`WREG32_SMC` take unshifted `*pos`. `amdgpu_debugfs_process_reg_op()` rejects setting both bit 61 and 62 in `*pos` (`-EINVAL`) and masks `*pos` with `(1UL << 22) - 1`. GRBM `sh`/`se` must be `0xFFFFFFFF` or `< max_sh_per_se`/`< max_shader_engines`. `gprwave_read()`/`gpr_read()` reject `size > 4096`, `size & 0x3`, or `*pos & 0x3`. Call `amdgpu_ib_preempt_fences_swap()` only when masked `last_seq != sync_seq`. [F212, F259, F260, F275, F276]
- `amdgpu_device_supports_baco()` returns a bitmask (`BACO_SUPPORT | MACO_SUPPORT`); test `(val & BACO_SUPPORT)`. `amdgpu_device_ip_block_version_cmp()` returns `0` when version `>= (major, minor)`, else `1`. `amdgpu_device_program_register_sequence()` takes total `u32` elements (`ARRAY_SIZE`, multiple of 3). `amdgpu_device_wb_get()`/`free()` use dword offsets (`offset << 3`). `amdgpu_device_aper_access()` returns transferred `size_t` bytes; `amdgpu_device_mm_access()` requires 4-byte aligned `pos`/`size` (`BUG_ON`), `drm_dev_enter()`, and `mmio_idx_lock`. [F216, F217, F219, F220, F221, F331]
- Pass `struct amdgpu_device *` as `void *dev` to `amdgpu_device_ip_set_clockgating_state()`/`powergating_state()`. In `amdgpu_device_init()`, call `aperture_remove_conflicting_pci_devices()` only when `(pdev->class >> 8)` is `PCI_CLASS_DISPLAY_VGA` or `OTHER`. `amdgpu_switcheroo_set_state()` must set `dev->switch_power_state = DRM_SWITCH_POWER_CHANGING` before resume/prepare/suspend and `DRM_SWITCH_POWER_ON`/`OFF` after. [F311, F371, F372]

## Error Handling
- In `amdgpu_device_ip_early_init()`, `-ENOENT` from `early_init` marks `status.valid = false`, whereas other errors fail init with `-ENODEV`. On Vega, Raven, Arcturus, and Aldebaran, `amdgpu_discovery_init()` failure is non-fatal, so callers like `amdgpu_discovery_sysfs_init()` must check `if (!adev->mman.discovery_bin)`. Clear `-EOPNOTSUPP` from `amdgpu_reset_prepare_hwcontext()`/`perform_reset()` to `r = 0` in `amdgpu_device_pre_asic_reset()`/`amdgpu_do_asic_reset()`. Clear `tmp_adev->asic_reset_res = 0` after reading it in `amdgpu_device_sched_resume()`. Do not log `DRM_ERROR()` on `-ERESTARTSYS` in `amdgpu_ctx_wait_prev_fence()`. [F222, F223, F224, F228, F361]

## External Contracts
- In `amdgpu_ctx_ioctl()`, `args->in.flags` must be `0` except in `AMDGPU_CTX_OP_SET_STABLE_PSTATE` (within `AMDGPU_CTX_STABLE_PSTATE_FLAGS_MASK` and `<= AMDGPU_CTX_STABLE_PSTATE_PEAK`). Normalize invalid/`UNSET` `priority` to `AMDGPU_CTX_PRIORITY_NORMAL` via `amdgpu_ctx_priority_is_valid()`, and check `amdgpu_ctx_priority_permit()` for `> NORMAL`. `amdgpu_ctx_query()` and `query2()` must zero `out->state.flags` and `out->state.hangs` first; `query()` updates `ctx->reset_counter_query`, while `query2()` compares `ctx->reset_counter` without modifying it. [F209, F210, F236, F253, F357]
- In `amdgpu_debugfs_gca_config_read()`, only append new fields to the end of `config[]` while incrementing `config[0]`, preserving existing DWORD offsets. In `amdgpu_debugfs_regs2_ioctl()`, `AMDGPU_DEBUGFS_REGS2_IOC_SET_STATE` copies v1 `struct amdgpu_debugfs_regs2_iocdata` and must zero `rd->id.xcc_id = 0` in `rd->id` (`struct amdgpu_debugfs_regs2_iocdata_v2`). [F246, F261]

## Known Pitfalls
- `amdgpu_device_init()` defaults indirect reg callbacks (`smc_rreg`/`wreg`, `didt_rreg`/`wreg`) to `&amdgpu_invalid_rreg`/`wreg` (`BUG()`), so ASIC `early_init` must set unsupported ones to `NULL`. Convert `pci_get_drvdata()`/`dev_get_drvdata()` (`struct drm_device *`) via `drm_to_adev()`. Traverse `hive->device_list` via `gmc.xgmi.head` and recovery `device_list` via `reset_list`. In `amdgpu_device_pre_asic_reset()`, set `job = reset_context->job` only if `reset_context->reset_req_dev == adev`. In `amdgpu_devcoredump_read()`, index `ring->ring[j / 4]` and use `drm_coredump_printer(&iter)`. [F213, F279, F280, F310, F314]
- In `amdgpu_discovery_reg_base_init()`, for `VCN_HWID`, save `ip->revision & 0xc0` to `adev->vcn.inst[num_vcn_inst].vcn_config` (`num_vcn_inst < AMDGPU_MAX_VCN_INSTANCES`) and clear `ip->revision &= ~0xc0` before computing `adev->ip_versions`. Cast `RREG32(mmRCC_CONFIG_MEMSIZE)` to `uint64_t` before `<< 20`, and cast v2 `mall_size_per_umc` to `uint64_t` before `* adev->gmc.num_umc`. In `amdgpu_device_parse_gpu_info_fw()`, `CHIP_NAVI12` skips `gfx.config` but must jump to `parse_soc_bounding_box`. [F256, F292, F294, F325]
- Write `pos >> 31` (not `>> 32`) to `mmMM_INDEX_HI` in `amdgpu_device_mm_access()`. Cast `readl(pcie_data_offset)` to `u64` before `<< 32` in `amdgpu_device_indirect_rreg64*()`. Cast `si.totalram` to `uint64_t` before `* si.mem_unit` and restrict `amdgpu_smu_memory_pool_size` to `{1, 2, 4, 8}` before `<< 28` in `amdgpu_device_check_smu_prv_buffer_size()`. Clamp `max(1u, max_MBps)` before `ilog2()`. Use `~((1ULL << 32) - 1)` and `aper_base + aper_size - 1` in `amdgpu_device_is_peer_accessible()`. Use `RREG32_PCIE_EXT`/`WREG32_PCIE_EXT` when `upper_32_bits(*pos)` is set, and reject `size & 0x3` before `while (size)` (`size -= 4`) loops in `amdgpu_debugfs.c`. [F282, F285, F289, F290, F291, F296, F297]
