# SPI SUBSYSTEM — drivers/spi (part 1)

This component contains core SPI helpers (`internals.h`), the generic bitbang library (`spi-bitbang.c`, `spi-bitbang-txrx.h`), and SPI/Quad/Octal (`spi-mem`) controller drivers (Atmel QSPI, Cadence QSPI/XSPI, Broadcom BCM2835/BCM2835aux, Altera, Armada 3700, Cavium Octeon/ThunderX, Au1550, Amlogic SPIFC, Butterfly, and ColdFire QSPI).

## Architecture & Data Flow
- `spi-bitbang.c` casts `spi_controller_get_devdata()` to `struct spi_bitbang *`, so `struct butterfly`, `struct ath79_spi`, and `struct au1550_spi` must put `struct spi_bitbang` first. In `bitbang_txrx_8/16/32()`, `count` is in bytes while typed `tx`/`rx` pointers advance by 1 word, so loops must decrement `count` by 1/2/4 and guard with `count > 0/1/3`. In `bitbang_txrx_le_cpha0/1()`, capture `rxbit = bits - 1` before the `bits--` loop. [F93, F123, F128]
- In `bcm2835_spi_setup()`, allocate `struct bcm2835_spidev *target` aligned to `dma_get_cache_alignment()`, keep `clear_rx_cs` `____cacheline_aligned` at the end, and when updating `target->prepare_cs`, update `target->clear_rx_cs` (`cs | TA | DMAEN | CLEAR_RX`) and call `dma_sync_single_for_device()` on `clear_rx_addr` if `ctlr->dma_rx` is set. [F58, F154]
- In `spi-bcm2835.c`, `bcm2835_spi_can_dma()` rejects `< BCM2835_SPI_DMA_MIN_LENGTH` (96, for the 6-byte prologue in `sgl[0..1]`), and `bcm2835_spi_max_transfer_size()` caps DMA at `65532` (not `65535`). `bcm2835_spi_interrupt()` takes `struct bcm2835_spi *bs` as `dev_id`, whereas `bcm2835_spi_dma_rx/tx_done()` take `struct spi_controller *ctlr`. In `bcm2835_spi_transfer_one()`, when `0 < spi_hz < bs->clk_hz / 2`, compute even `cdiv = DIV_ROUND_UP(bs->clk_hz, spi_hz)` (`cdiv += (cdiv % 2)`), wrapping `>= 65536` to `0` (treated as `65536` in `effective_speed_hz`), and guard `polling_limit_us` and `hz_per_byte` divisions against zero in both `bcm2835` and `bcm2835aux`. [F83, F84, F112, F113, F132]
- In `spi-bcm2835aux.c`, `bcm2835aux_spi_transfer_one()` zeroes `bs->pending` and clears `BCM2835_AUX_SPI_CNTL0_SPEED` in `bs->cntl[0]` before ORing speed. `bcm2835aux_wr_fifo()` packs up to 3 bytes from bit 16, updates `pending` and `tx_len` by `count`, then tests `if (bs->tx_len)` to pick `TXHOLD` vs `IO`; `bcm2835aux_rd_fifo()` unpacks via fallthrough `case 3..1` while decrementing `rx_len` and `pending`. [F59, F60, F101]
- In `atmel-quadspi.c`, updates to `QSPI_SCR` or `QSPI_MR` must mask only the target bitfield in `aq->scr` or `aq->mr` and pass the matching shadow field to `atmel_qspi_write()`. DLL control requires `aq->caps->has_dllon`, `atmel_qspi_set_pad_calibration()` requires `aq->caps->octal && aq->caps->has_padcalib`, and `atmel_qspi_exec_op()` rejects `op->addr.val + op->data.nbytes > aq->mmap_size` or `op->addr.nbytes > 4`. [F53, F77, F95, F144]
- `cqspi_probe()` stores `struct cqspi_st *` in `drvdata` and `amlogic_spifc_a1_probe()` stores `struct amlogic_spifc_a1 *`, so PM/remove callbacks must cast `dev_get_drvdata()` to those structs and pass `cqspi->host` / `spifc->ctrl`. After `cqspi_controller_init()`, reset `cqspi->current_cs = -1` and `sclk = 0`. In `cqspi_write_setup()`, setting `CQSPI_REG_WR_DISABLE_AUTO_POLL` must also set `cqspi->use_direct_mode_wr = false`. [F61, F62, F121, F122]
- In `spi-cadence-quadspi.c`, `cqspi_command_read/write()` reject `op->data.nbytes > 8` (`CQSPI_STIG_DATA_LEN_MAX`), and DAC mode in `cqspi_read/write()` requires `addr + nbytes <= cqspi->ahb_size`. In `cqspi_indirect_read_execute()`, when `remaining < 4`, the `!word_remain && mod_bytes` branch must read the final word and set `bytes_to_read = mod_bytes`. In `cqspi_versal_indirect_read_dma()`, program `dma_addr` with `lower/upper_32_bits()`, and revert `PM_OSPI_MUX_SEL_DMA` + `CQSPI_REG_CONFIG_DMA_MASK` to `PM_OSPI_MUX_SEL_LINEAR` on all exit paths before `cqspi_indirect_read_execute()`. [F63, F78, F79, F107, F120]
- In `spi-cadence.c`, raising `CDNS_SPI_THLD` above `1` requires resetting it to `0x1` (`cdns_spi_detect_fifo_depth()`, `cdns_unprepare_transfer_hardware()`). In `cdns_spi_irq()` on `CDNS_SPI_IXR_TXOW`, compute `trans_cnt` from `CDNS_SPI_THLD` before lowering `CDNS_SPI_THLD` to `1`, and test `if (xspi->tx_bytes)` before `cdns_spi_process_fifo()` decrements `tx_bytes`. `cdns_xspi_adjust_mem_op_size()` and `amlogic_spifc_a1_adjust_op_size()` clamp `op->data.nbytes` to `cdns_xspi->sdmasize` and `SPIFC_A1_BUFFER_SIZE` (512). In `cdns_mrvl_xspi_setup_clock()`, bound `i` to `ARRAY_SIZE(cdns_mrvl_xspi_clk_div_list) - 1`. [F69, F75, F87, F104]
- In `spi-altera-core.c`, `ALTERA_SPI_CONTROL` writes must update and write `hw->imr`. `altera_spi_txrx()` sets `hw->bytes_per_word = DIV_ROUND_UP(t->bits_per_word, 8)` and `hw->len = t->len / hw->bytes_per_word` (words); `altera_spi_tx/rx_word()` scale `hw->count` by `hw->bytes_per_word` when indexing `hw->tx`/`rx`. Drivers without an IRQ must set `hw->irq < 0`. [F49, F64, F111, F129]
- In `spi-au1550.c`, `au1550_spi_chipsel()` and `au1550_spi_setupxfer()` must call `au1550_spi_bits_handlers_set()` and update `PSC_SPICFG_DD_DISABLE` per `hw->usedma && bpw <= 8`. In `au1550_spi_dma_txrxb()`, map `t->tx_buf` before `t->rx_buf`, and when `!t->rx_buf`, reallocate `dma_rx_tmpbuf` if `t->len > hw->dma_rx_tmpbuf_size` before setting `hw->rx`, `dma_rx_addr`, and `hw->tx = hw->rx` (syncing `dma_rx_addr` as `DMA_BIDIRECTIONAL` when `!t->tx_buf`). [F66, F67, F156]
- In `spi-armada-3700.c`, `a3700_spi_bytelen_set()` updates `A3700_SPI_BYTE_LEN` and `a3700_spi->byte_len` together, and `a3700_spi_transfer_setup()` resets `byte_len` to 4. In `a3700_spi_transfer_one_fifo()`, when `tx_buf` is set and `buf_len % 4 != 0`, `a3700_spi_header_set()` must send the leading `buf_len % 4` bytes before `a3700_spi_fifo_write()`. In `a3700_spi_clock_set()`, `prescale > 15` uses `A3700_SPI_CLK_EVEN_OFFS + DIV_ROUND_UP(prescale, 2)`. [F68, F89, F115]
- In `octeon_spi_do_transfer()`, guard `p->cs_enax |= 1ull << (12 + cs)` with `cs < 4`, OR `cs_enax` into `mpi_cfg.u64` before updating `p->last_cfg`, and loop `while (len > OCTEON_SPI_MAX_BYTES)` with `leavecs = 1` so the tail sets `leavecs = last_xfer ? xfer->cs_change : !xfer->cs_change`. In `spi-cavium.h`, `union cvmx_mpi_*` bitfields must match across `#ifdef __BIG_ENDIAN_BITFIELD` and `#else`. `ath79_exec_mem_op()` must restore `AR71XX_SPI_FS_GPIO` and `sp->ioc_base` after mmap reads. In `spi-butterfly.c`, parport writes must update `pp->lastbyte`. Polling in `spi-bcm2835.c`, `spi-bcm2835aux.c`, and `cqspi_wait_idle()` must use `time_after(jiffies, timeout)`. [F65, F71, F74, F88, F105, F114, F118]

## Synchronization
- In `bcm2835_spi_transfer_one_dma()`, set `bs->tx_dma_active = true` + `smp_wmb()` before `dma_async_issue_pending(ctlr->dma_tx)`, and `bs->rx_dma_active = true` + `smp_mb()` after `dma_async_issue_pending(ctlr->dma_rx)`, pairing with `smp_wmb()` and `cmpxchg(&bs->rx_dma_active, true, false)` in `bcm2835_spi_dma_tx_done()`. Set `bs->target = target` before `dmaengine_submit()` in `bcm2835_spi_prepare_sg()`. `bcm2835_spi_dma_rx/tx_done()` run in atomic context and must use `dmaengine_terminate_async()`. [F15, F16, F152]
- `bcm2835_spi_interrupt()` and `bcm2835aux_spi_interrupt()` use `IRQF_SHARED` unlocked: `bcm2835_spi_transfer_one_irq()` and `bcm2835aux_spi_transfer_one_irq()` must configure registers and pre-fill the TX FIFO before enabling IRQ bits (`INTR | INTD` or `TXEMPTY | IDLE`), and both ISRs must return `IRQ_NONE` if IRQ-enable bits are clear. [F19, F20, F150]
- In `atmel_qspi_wait_for_completion()`, after reading `QSPI_SR`, set `reinit_completion(&aq->cmd_completion)`, `aq->pending = sr & irq_mask`, and `aq->irq_mask = irq_mask` before writing `QSPI_IER`, and test `((... & irq_mask) == irq_mask)` while ORing into `aq->pending`. In `atmel_qspi_transfer()`, read `QSPI_IFR` before `aq->mem` access and put `rmb()`/`wmb()` before writing `QSPI_CR_LASTXFER`. [F21, F22, F96]
- `spi_bitbang_init()` must init `bitbang->lock` (protecting `bitbang->busy`) and `bitbang->ctlr` before `spi_bitbang_start()`. In `au1550_spi_probe()`, call `au1550_spi_bits_handlers_set(hw, 8)` before `request_irq()`. In `altera_spi_probe()` and `altera_spi_txrx()`, call `altera_spi_init_host()` before `devm_request_irq()` and set `hw` transfer fields before `IRRDY_MSK`. In `cdns_spi_probe()` and `cdns_transfer_one()`, call `cdns_spi_init_hw()` before `devm_request_irq()` and set counters/pre-fill FIFO before `CDNS_SPI_IER`. [F27, F28, F30, F31]
- In `spi_clps711x_probe()` and `spi_clps711x_transfer_one()`, `readl(hw->syncio)` before `devm_request_irq()` and set `hw` state before `SYNCIO_TXFRMEN`. In `a3700_spi_transfer_wait()`/`wait_completion()`, set `wait_mask`, poll `IF_CTRL_REG`, and `reinit_completion()` before unmasking `INT_MASK_REG`. In `cdns_xspi_send_stig_command()`, set `sdma_error = false` and buffers before triggering, and call `sdma_handler()` only after `wait_for_completion()` with `!sdma_error`. [F32, F33, F34]
- Runtime PM callbacks (`cqspi_runtime_suspend/resume()`) must not call `spi_controller_suspend/resume()` (deadlocks on `bus_lock_mutex`). `indirect_bus_reg_read/write()` (`spi-altera-dfl.c`) and any regmap backing `struct altera_spi` must not sleep (called from hardirq `altera_spi_irq()`). [F149, F158]

## Object Lifetimes
- When `spi_alloc_host()` is paired with `devm_spi_register_controller()` (`mcfqspi_probe()`), call `spi_controller_put(host)` on pre-registration failure paths, never in `.remove`. `atmel_qspi_probe()` uses `devm_pm_runtime_set_active_enabled()` and `devm_pm_runtime_get_noresume()` with `pm_runtime_put_autosuspend()` on success (no manual `pm_runtime_disable/put_noidle` in error/remove), and `atmel_qspi_exec_op()` owns the per-op runtime PM ref (`set_cfg`/`transfer` must not call `pm_runtime_put*()`). [F3, F4, F137]
- In `bcm2835_spi_transfer_one_dma()`, after `bcm2835_spi_transfer_prologue()`, all exit/error paths must call `bcm2835_spi_undo_prologue(bs)` (clearing `bs->tx_prologue = 0` even when `!bs->tx_buf`) before unmapping. Terminate cyclic descriptors (`fill_tx_desc`, `clear_rx_desc`) before resubmission or teardown, and in `bcm2835_spi_remove()`, call `spi_unregister_controller()` before `bcm2835_dma_release()` terminates, unmaps, and releases DMA. [F8, F18, F99, F140]
- In `atmel_qspi_dma_xfer()` and `cqspi_direct_read_execute()`, `reinit_completion()` precedes DMA issue, and on timeout `dmaengine_terminate_sync()` must run before unmapping. In `au1550_spi_dma_txrxb()`, call `au1xxx_dbdma_stop()` on both channels before unmapping; in `au1550_spi_remove()`, call `spi_bitbang_stop()` and `free_irq()` before freeing DMA. [F23, F24, F29]
- `cqspi_probe()` initializes `cqspi->refcount` and `inflight_ops` to 1 before `spi_register_controller()`, and `cqspi_remove()` sets `refcount = 0` and calls `cqspi_wait_idle()` if `!refcount_dec_and_test(&cqspi->inflight_ops)` before `spi_unregister_controller()` and hardware disable. `butterfly_detach()` must clear global `butterfly = NULL` before teardown. In `cdns_xspi_of_get_plat_data()`, early returns inside `device_for_each_child_node()` must call `fwnode_handle_put(fwnode_child)`. [F12, F26, F106]

## API Contracts
- `spi_bitbang_start()` calls `spi_controller_get()`, so `spi_alloc_host()` callers must call both `spi_bitbang_stop()` and `spi_controller_put()`. Before `spi_bitbang_init()`, set `bitbang->ctlr`, leave `ctlr->transfer*` `NULL`, and set `bitbang->chipselect` if `!ctlr->use_gpio_descriptors || (ctlr->flags & SPI_CONTROLLER_GPIO_SS)`. Custom `txrx_bufs` must return `transfer->len` on success, and default `!bitbang->txrx_bufs` owns `spi->controller_state`. In `spi-bitbang-txrx.h`, `getmiso()` must return `0` or `1`, `bits` must be in `1..32`, and `(NSEC_PER_SEC / 2) / hz` in `spi_bitbang_setup_transfer()` must stay guarded by `if (hz)`. [F1, F36, F38, F108, F109, F110, F124]
- `bcm2835_rd/wr_fifo_count()` require `BCM2835_SPI_CS_DMAEN` set. When `bcm2835_spi_transfer_one_poll()` falls back to `bcm2835_spi_transfer_one_irq()`, pass `fifo_empty = false`. `bcm2835_spi_setup()` allocates `gpiod_lookup_table` with `struct_size(lookup, table, 2)` via `kzalloc()` for the zeroed sentinel. [F42, F57, F76]
- Use `atmel_qspi_set_serial_memory_mode()` to set `QSPI_MR_SMM`, and when `!aq->caps->octal`, `atmel_qspi_supports_op()` must reject `addr.nbytes == 2 && dummy.nbytes == 0 && cmd.buswidth != addr.buswidth`. `cqspi_supports_mem_op()` requires `dtr == true` and `buswidth == 8` across all non-empty phases for DTR ops. Callers of `cdns_xspi_trigger_command()` must `memset(cmd_regs, 0, sizeof(cmd_regs))`. `cdns_spi_config_clock_mode()` must disable `CDNS_SPI_ER` before changing `CPHA`/`CPOL`. Before `altera_spi_init_host(host)`, init `hw->regmap`, and pass `host` as `dev_id` to `devm_request_irq()`. `mcfqspi_transfer_one()` must pass `t->len / 2` (words) to `mcfqspi_transfer_msg16()`. [F52, F54, F70, F130, F164, F166, F167]

## Error Handling
- In `spi_bitbang_setup()`, only `kfree(cs)` on `err_free` when `initial_setup` is true. Unwind enabled clocks on failure in `atmel_qspi_runtime_resume()`, `atmel_qspi_resume()`, `cdns_spi_runtime_resume()`, `cqspi_jh7110_clk_init()`, `amlogic_spifc_a1_resume()`, and `cqspi_probe()` (jump to `probe_reset_failed` after `clk_prepare_enable()` / `cqspi_jh7110_clk_init()`, including on `dma_set_mask()` failure). [F2, F5, F6, F14, F46]
- In `bcm2835_dma_init()`, `atmel_qspi_dma_init()`, and `cqspi_request_mmap_dma()`, propagate `-EPROBE_DEFER`, but on other errors reset channel pointers from `ERR_PTR` to `NULL` (clearing both `rx_chan`/`tx_chan` in `atmel_qspi_dma_init()` and on release in `bcm2835_dma_release()`). Reset `fill_tx_addr`/`clear_rx_addr` to `0` on `dma_mapping_error()`, and guard `gpiod_put(bs->cs_gpio)` with `if (!IS_ERR(bs->cs_gpio))` in `bcm2835_spi_cleanup()`. [F7, F39, F40, F45, F135]
- In `atmel_qspi_probe()`, keep `platform_get_resource_byname()` + `devm_ioremap_resource()` for `"qspi_mmap"` (`res` is read afterwards). In `atmel_qspi_set_cs_timing()`, check `delay < 0` from `spi_delay_to_ns()` before multiplying by `clk_rate`. In `spi-au1550.c`, `au1xxx_dbdma_*` and `au1xxx_ddma_add_device()` return `0` on failure (`!ret`), and `au1550_spi_dma_rxtmp_alloc/free()` must reset both `dma_rx_tmpbuf` and `dma_rx_tmpbuf_size` to `0`. In `cqspi_setup_flash()`, init `max_cs = -1` and check `max_cs < 0` after the loop. `cdns_transfer_one()` returns `transfer->len`, and on `CDNS_SPI_IXR_MODF`, `cdns_spi_irq()` calls `spi_finalize_current_transfer()` with `tx_bytes`/`rx_bytes` non-zero. [F43, F50, F51, F94, F116, F165]

## External Contracts
- In `cdns_xspi_probe()`, when `mrvl_hw_overlay` is true and `"xfer"` (or resource 3) is missing, fall back to `cdns_xspi->xferbase = cdns_xspi->iobase + 0x8000`. Without `cs-gpios`, `bcm2835aux_spi_setup()` rejects `cs != 0`, and `bcm2835_spi_setup()` rejects `cs > 1` and checks `of_find_compatible_node()` for a BCM2835/2711/7211 GPIO controller before registering the `pinctrl-bcm2835` lookup table. [F91, F92, F138]

## Known Pitfalls
- In `spi-bcm2835.c`, TX halts when the RX FIFO is full: `bcm2835_wait_tx_fifo_empty()` callers must ensure TX bytes fit in the RX FIFO, and `bcm2835_spi_dma_tx_done()` must write `bs->target->clear_rx_cs` inside its `BCM2835_SPI_CS_DONE` poll loop. In `spi-au1550.c`, `au1550_spi_pio_irq_callback()` must call `hw->tx_word(hw)` only inside the `!(stat & PSC_SPISTAT_RE)` block after `hw->rx_word(hw)`, and every `hw->regs->psc_*` write or status poll read must be followed by `wmb()`. [F98, F102, F148]
- In `spi-cadence-quadspi.c`, `cqspi_configure()` must disable the controller (`cqspi_controller_enable(cqspi, 0)`) before changing CS, baudrate, delays, or read capture. Flush writes to `CQSPI_REG_SIZE` and `CQSPI_REG_INDIRECTRD/WR` with `readl()` before accessing `cqspi->ahb_base`. Check `virt_addr_valid(buf)` (and `(dma_align & CQSPI_DMA_UNALIGN) == 0` for `indirect_read_dma`) before DMA mapping in `cqspi_direct_read_execute()` and `cqspi_read()`, and pass word counts (`bytes / 4`) to `ioread32_rep()`/`iowrite32_rep()` while advancing `rxbuf`/`txbuf` in bytes. [F131, F134, F146, F155]
