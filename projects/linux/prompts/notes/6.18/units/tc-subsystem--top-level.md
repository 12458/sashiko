# TC subsystem — (top level)

This component provides the Traffic Control (TC) classifier/action UAPI and internal headers, the core TC action lifecycle and execution engine (`net/sched/act_api.c`), and concrete packet action modules (`act_ct`, `act_mirred`, `act_gate`, `act_csum`, `act_nat`, `act_mpls`, `act_ife`, `act_connmark`, `act_ctinfo`, `act_gact`), handling rtnetlink configuration, per-netns IDR indexing, hardware offload, and softirq packet processing.

## Architecture & Data Flow

- Every concrete `struct tcf_*` must embed `struct tc_action common` at offset 0 (for `tcf_idr_create()`, `free_tcf()`, and `to_<act>()` casts), and per-netns structs registered via `tcf_register_action()` (e.g., `struct tc_ct_action_net`) must embed `struct tc_action_net` at offset 0 (for `net_generic()` casts in walkers, search, reoffload, and exit). [F128, F130]
- Actions created via `tcf_idr_create_from_flags()` have NULL `cpu_bstats`/`cpu_qstats` when `TCA_ACT_FLAGS_NO_PERCPU_STATS` is set; update stats via `tcf_action_update_bstats()`, `tcf_action_inc_drop_qstats()`, and `tcf_action_inc_overlimit_qstats()` instead of `this_cpu_ptr()`. [F53]
- In `tcf_bind_filter()`, `tcf_unbind_filter()`, and `tcf_block_q()`, `tp->chain->block->q` is NULL when `tcf_block_shared(block)` is true; check `!tcf_block_shared(block)` or `q != NULL` before dereferencing `q`. Call `tcf_proto_update_usesw()` on every filter insertion to set `tp->usesw = true` unless both `SKIP_SW` and `IN_HW` are set, so `tcf_block_bypass_sw()` does not skip software filters. [F55, F69]
- In `tcf_action_exec()`, `jmp_ttl` is initialized once to `TCA_ACT_MAX_PRIO` (32) before `restart_act_graph:` to bound total `TC_ACT_JUMP` restarts (validating `jmp_prgcnt = ret & TCA_ACT_MAX_PRIO_MASK` is non-zero and `<= nr_actions`, and `jmp_ttl > 0` after decrementing), while `repeat_ttl` is reset to 32 inside the loop before `repeat:` (returning `TC_ACT_OK` with `net_warn_ratelimited()` on exhaustion). In `tcf_mirred_act()`, `tcf_mirred_nest_level_inc_return()` enforces `MIRRED_NEST_LIMIT` (4, logging via `net_warn_ratelimited()` and returning `TC_ACT_SHOT`), and every exit after incrementing must reach `dec_nest_level:` to call `tcf_mirred_nest_level_dec()`. [F85, F107, F115, F189]
- In `tcf_mirred_init()`, `tcfm_dev` and `tcfm_blockid` are mutually exclusive: setting `parm->ifindex` under `m->tcf_lock` must zero `m->tcfm_blockid` and update `m->tcfm_mac_header_xmit`, whereas setting `TCA_MIRRED_BLOCKID` must call `tcf_mirred_replace_dev(m, NULL)` and set `m->tcfm_mac_header_xmit = false`. In `mirred_device_event()`, `NETDEV_UNREGISTER` must only release `m->tcfm_dev_tracker` and clear `m->tcfm_dev` when `tcf_mirred_dev_dereference(m) == dev`, without touching `m->tcfm_blockid`. [F60, F61]
- In `tcf_ct_flow_table_lookup()`, call `nf_conn_act_ct_ext_fill()` and `tcf_ct_flow_ct_ext_ifidx_update()` before `flow_offload_refresh()`. If `IPS_ASSURED_BIT` is unset on `ct->status`, still call `flow_offload_refresh()` (forcing refresh on reply packets if `!NF_FLOW_HW_ESTABLISHED`) and return `false` so software conntrack can promote `ct` to `ASSURED`. `tcf_ct_flow_is_outdated()` requires `IPS_HW_OFFLOAD_BIT` and `!NF_FLOW_HW_PENDING` in addition to `IPS_SEEN_REPLY_BIT` and `!NF_FLOW_HW_ESTABLISHED`. [F64, F65, F104]
- In `act_gate.c`, `fill_gate_entry()` rejects `interval == 0` and `tcf_gate_init()` requires non-zero `cycletime` before dividing by `tcfg_cycletime`. `gate_timer_func()` must check `list_is_last(&next->list, &p->entries)` and wrap via `list_first_entry()` rather than calling `list_next_entry()` unconditionally. [F95, F117]
- `tcf_csum_ipv4()` and `tcf_nat_act()` must gate their L4 switch with `iph->frag_off & htons(IP_OFFSET) ? 0 : iph->protocol`. In `tcf_csum_ipv6_hopopts()`, loop with `while (len > 1)` before reading `xh[off + 1]`, and for `IPV6_TLV_JUMBO` verify `optlen == 6`, `len >= 6`, and `(off & 3) == 2`. `tcf_csum_ipv4/ipv6_udp()` must validate `ntohs(udph->len)` against `ipl - ihl` and replace a 0 computed checksum with `CSUM_MANGLED_0`. [F90, F120, F181]
- In `tc_pedit.h`, `tcf_pedit_htype()` and `tcf_pedit_cmd()` must check `if (parms->tcfp_keys_ex)` before indexing. In `act_mpls.c`, `TCA_MPLS_LABEL` requires `valid_label()`, and `ACT_MPLS_*_NOT_SET` (not `0`) are the unset sentinels. In `tcf_ctinfo_init()`, `dscpmask` must be 6 contiguous set bits and not overlap `dscpstatemask`. [F56, F92, F93]

## Synchronization

- Every process-context acquisition of `tc_action.tcfa_lock` (`tcf_lock`) must use `spin_lock_bh()` / `spin_unlock_bh()` because softirq/timer paths (`tcf_action_update_bstats()`, `tcf_gate_act()`, `gate_timer_func()`, `tcf_ife_encode()`) acquire it. When updating an existing action in `->init()`, run `tcf_action_set_ctrlact()` and `rcu_replace_pointer()` under `spin_lock_bh(&a->tcfa_lock)`, and call `tcf_chain_put_by_act()` after unlocking. [F29, F151]
- `offload_action_init()` and `tc_setup_action()` call `offload_act_setup()` under `spin_lock_bh(&act->tcfa_lock)`, so callbacks and helpers (`tcf_gate_get_list()`, `tcf_tunnel_info_copy()`) must not sleep, must use `GFP_ATOMIC`, and must not re-lock `tcfa_lock`. Helpers using `rcu_dereference_protected(..., lockdep_is_held(&a->tcfa_lock))` (`to_ct_params()`, `tcf_ct_zone()`, `tcf_tunnel_info()`, `tcf_police_rate_bytes_ps()`) require holding `tcfa_lock`. [F30, F154]
- Dropping the final `tc_action` reference outside `idrinfo->lock` in `__tcf_action_put()` must use `refcount_dec_and_mutex_lock(&p->tcfa_refcnt, &idrinfo->lock)` before `idr_remove()`, paired with `refcount_inc_not_zero(&p->tcfa_refcnt)` during lockless `rcu_read_lock()` lookup in `tcf_idr_check_alloc()`. When already holding `idrinfo->lock` (`tcf_del_walker()`, `tcf_reoffload_del_notify()`), call `tcf_idr_release_unsafe()` instead of `tcf_idr_release()` or `__tcf_action_put()`. [F25, F160, F161]
- When `tc_action_load_ops()` drops `rtnl_unlock()` for `request_module()`, it must re-acquire `rtnl_lock()`, call `module_put()`, and return `ERR_PTR(-EAGAIN)` for replay. Process-context callers of `tcf_action_stats_update()` (`tcf_action_update_hw_stats()`, `tcf_exts_hw_stats_update()`) must wrap it in `preempt_disable()` / `preempt_enable()`. [F31, F165]
- In `act_mirred.c`, lock order is `mirred_list_lock` outer, `m->tcf_lock` inner; never acquire `mirred_list_lock` under `m->tcf_lock`. In `tcf_mirred_forward()`, egress-to-ingress (`!at_ingress && want_ingress`) must use `netif_rx(skb)`, not `netif_receive_skb(skb)`. [F34, F35]
- In `act_gate.c`, `parse_gate_list()` runs under `spin_lock_bh(&gact->tcf_lock)` and must use `GFP_ATOMIC`; when `gate_setup_timer()` reconfigures an existing timer (`!do_init`), it must drop `gact->tcf_lock` around `hrtimer_cancel(&gact->hitimer)`. In `act_ife.c`, `__add_metainfo()` must use `atomic = true` (`GFP_ATOMIC`) under `read_lock(&ife_mod_lock)` and hold `spin_lock_bh(&ife->tcf_lock)` when `exists` is true. [F18, F157, F162]
- In `tcf_gact_init()`, write non-zero `tcfg_pval` and `tcfg_paction` then `smp_wmb()` before `tcfg_ptype`, paired with `READ_ONCE(gact->tcfg_ptype)` and `smp_rmb()` in `gact_net_rand()` / `gact_determ()`. `struct tcf_ctinfo` stats must use `atomic64_t`, and `psched_mtu()` must use `READ_ONCE(dev->mtu)`. [F38, F39, F40]

## Object Lifetimes

- When `tcf_idr_check_alloc()` returns 0, it inserts `ERR_PTR(-EBUSY)` at `*index`; on error before `tcf_idr_create()` succeeds, remove it with `tcf_idr_cleanup(tn, index)`. Once `tcf_idr_check_alloc()` returns 1 or `tcf_idr_create()` succeeds, roll back any later `->init()` error via `tcf_idr_release(*a, bind)`. [F1, F2]
- `tcf_action_check_ctrlact()` acquires `*newchain` for `TC_ACT_GOTO_CHAIN`, and `tcf_action_set_ctrlact()` swaps `a->goto_chain` and returns the old chain; NULL-initialize the chain pointer and release any non-NULL chain (on error or after swap) with `tcf_chain_put_by_act()`. [F3]
- `tcf_action_init()` must call `module_put(ops[i]->owner)` for every loaded `ops[i]` on both success and failure, and complete `tcf_action_offload_add()` and flag validation before `tcf_idr_insert_many()` (which skips `ACT_P_BOUND`). `tcf_action_add()` must call `tca_put_bound_many()` (skipping `ACT_P_CREATED`) to drop the extra reference on pre-existing actions. [F5, F75, F143]
- `tcf_action_destroy()` and `tcf_action_delete()` must set `actions[i] = NULL` as each element is released because `tcf_act_for_each_action()` stops at the first NULL. `tcf_action_cleanup()` must call `tcf_action_offload_del(p)` before `p->ops->cleanup(p)` and `free_tcf(p)`. In `tcf_idrinfo_destroy()`, if any action has `tc_act_in_hw(p)`, hold `rtnl_lock()` across `__tcf_idr_release()`. [F6, F142, F145]
- When `offload_act_setup` (`bind == true`) acquires a ref or memory for a `flow_action_entry`, set `entry->destructor` and `entry->destructor_priv`, and call `tc_cleanup_offload_action()` before freeing `fl_action`. [F144]
- `tcf_register_action()` requires `.act`, `.dump`, and `.init`, and must call `register_pernet_subsys()` before linking into `act_base` under `act_mod_lock` (and unlink before `unregister_pernet_subsys()`). `ct_init_module()` must init `act_ct_wq` and `zones_ht` before `tcf_register_action()`, and `mirred_init_module()` must register `mirred_device_notifier` before `tcf_register_action()` (reversing order on cleanup). [F139, F140, F141, F167]
- `flowtable_ct` must provide `.get`/`.put` (`tcf_ct_nf_get/put`); `tcf_ct_flow_table_get()` must use `refcount_inc_not_zero(&ct_ft->ref)`, and `tcf_ct_flow_table_put()` must defer `nf_flow_table_free()` and `kfree(ct_ft)` via `queue_rcu_work(act_ct_wq, &ct_ft->rwork)`. [F11, F163]
- In `tcf_ct_act()`, re-read `ct = nf_ct_get(skb, &ctinfo)` after `nf_conntrack_confirm(skb)` (setting `skip_add = true` if NULL) because clash resolution may replace `ct`. In `tcf_ctinfo_act()`, call `nf_ct_put(ct)` on exit if and only if `thash != NULL`. [F14, F177]
- When replacing or clearing `m->tcfm_dev`, call `netdev_put(odev, &m->tcfm_dev_tracker)` and update `m->tcfm_dev`. Callers of `find_ife_oplist()` must balance `try_module_get(o->owner)` with `module_put()` on error, after validation, or in `_tcf_ife_cleanup()`. [F16, F19]

## API Contracts

- `tc_action_ops->init` must validate `parm->action` via `tcf_action_check_ctrlact()`, returning `ACT_P_CREATED` (`1`), `ACT_P_BOUND` (`0`), or `-errno`. When `tcf_idr_check_alloc()` finds an existing action (`err > 0`) and `TCA_ACT_FLAGS_BIND` is set, return `ACT_P_BOUND` immediately without modifying parameters or `goto_chain`, even if `TCA_ACT_FLAGS_REPLACE` is set. [F43, F73, F86]
- `tc_action_ops.act` and `tcf_action_exec()` run in softirq under `rcu_read_lock_bh()`, requiring `rcu_dereference_bh()` and `GFP_ATOMIC`. `tc_action_ops->dump` must return positive `skb->len` on success and negative after `nlmsg_trim()` on failure. `offload_act_setup` must check `bind` before casting `entry_data` or dereferencing `index_inc`, and return `-EOPNOTSUPP` for software-only options (e.g., `tcf_ct_helper()`, `DEC_TTL`/`MAC_PUSH` in MPLS, `continue`/`reclassify`/`pipe` in gact). [F45, F131, F146, F152]
- If `tcf_exts_get_net()` returns `false`, clean up synchronously; if `true`, call `tcf_exts_put_net()`. Pass `0` to `tcf_exts_init()` / `tcf_exts_init_ex()` for unsupported `action` or `police` attributes. [F22, F58]
- `tcf_mirred_to_dev()` clones `skb` unless `skb_at_tc_ingress(skb) && is_redirect && tcf_mirred_can_reinsert(retval)`, calls `nf_reset_ct()`, drops dst on egress-to-ingress, adjusts L2/L3 offset via `skb_pull/push_rcsum()`, and transmits via `tcf_dev_queue_xmit()`. `tcf_mirred_forward()` consumes `skb_to_send` even on error; when `skb == skb_to_send`, keep `retval = TC_ACT_CONSUMED` (never `TC_ACT_SHOT`). [F8, F172, F178]
- In `tcf_ct_act()`, balance `skb_pull_rcsum(skb, nh_ofs)` with `skb_push_rcsum()` at `out_push:`. When `defrag == true`, set `tc_skb_cb(skb)->mru = mru` and `qdisc_skb_cb(skb)->pkt_len = skb->len`. Return `TC_ACT_CONSUMED` (not `TC_ACT_SHOT`) if `tcf_ct_handle_fragments()` fails or a hook returns `NF_STOLEN`. `tcf_ct_add_mangle_action()` stores `~mask`, and `tcf_ct_flow_table_restore_skb()` must mask `cookie` with `NFCT_PTRMASK`. [F9, F51, F62, F137, F176]
- `tcf_mpls_act()` must push/pull `skb->mac_len` at TC ingress and materialize offloaded VLAN tags via `__vlan_insert_inner_tag()` before `TCA_MPLS_ACT_MAC_PUSH`. In `act_csum.c`, skip GSO packets matching the protocol's GSO flag, verify `pskb_may_pull()`, `ipl >= ihl + jhl`, and `skb_try_make_writable()` in `tcf_csum_skb_nextlayer()`, and push back `vlan_hdr_count` pulled VLAN headers at `out:`. [F88, F119, F179, F180]
- `register_ife_op()` requires non-NULL `metaid`, `metatype`, `name`, `check_presence`, `encode`, `decode`, `get`, and `alloc` (defaulting `release` to `ife_release_meta_gen()`); `TCA_IFE_METALST` allows `len == 0` or validates `len > 0` via `ife_validate_metatype()`. Validate ematch offsets with `tcf_valid_offset()`, copy `sizeof(*tun) + tun->options_len` in `tcf_tunnel_info_copy()`, use `div_u64()` in `tcf_police_burst*()`, and never set `tc_taprio_caps.broken_mqprio` in new drivers. [F91, F97, F127, F133, F149, F168]

## Error Handling

- `tcf_idr_check_alloc()` must return `-EAGAIN` immediately on `IS_ERR(p)`. Before jumping to an error label that calls `tcf_idr_release()` on `ACT_P_CREATED`, `ops->init` must initialize all fields torn down by `ops->cleanup` (e.g., `hitimer`/`entries` in gate, `tcfm_list` in mirred, `metalist` in ife). [F47, F103]
- On `tcf_ct_fill_params()` error after allocating `p->tmpl`, call `nf_connlabels_put()`, `nf_ct_put(p->tmpl)`, and set `p->tmpl = NULL`. Mask conntrack/NAT/helper verdicts with `NF_VERDICT_MASK` in `tcf_ct_act()`. On `tcf_ct_flow_table_add()` failure, free `entry` and `clear_bit(IPS_OFFLOAD_BIT, &ct->status)`. On `tcf_ct_flow_table_add_action_nat()` failure in `tcf_ct_flow_table_fill_actions()`, zero appended `action->entries` and restore `action->num_entries`. [F12, F13, F52, F114]

## External Contracts

- `tc_ctl_action()` uses `sock_net(skb->sk)` and requires `netlink_capable(skb, CAP_NET_ADMIN)` when `nlmsg_type != RTM_GETACTION`. `tcf_action_init()` parses `TCA_ACT_MAX_PRIO + 1` into `tb[TCA_ACT_MAX_PRIO + 2]`, mapping 1-based `tb[i]` to 0-based arrays. `tcf_action_dump()` uses 1-based nest types `i + 1`; `tcf_dump_walker()` uses 0-based types, caps at `TCA_ACT_MAX_PRIO` unless `LARGE_DUMP_ON`, and decrements `index--` on entry dump failure before `cb->args[0] = index + 1`. [F83, F84, F106, F187]
- Zero `tca__pad1`/`tca__pad2` in `struct tcamsg`, subtract `ref`/`bind` offsets in `.dump()`, and use `nla_put_64bit()` / `nla_put_u64_64bit()` with `TCA_*_PAD` for `struct tcf_t` and `u64` stats. [F98, F185]
- Reject `SKIP_HW | SKIP_SW`. Only classifier-bound actions (`tc_act_bind(act->tcfa_flags)`) may inherit `SKIP_SW`/`SKIP_HW` on bind; standalone actions fail with `-EINVAL` on mismatch. Standalone `SKIP_SW` actions require `tc_act_in_hw(action)` and must be deleted via `tcf_reoffload_del_notify()` if `in_hw_count` drops to 0. Keep `qopt` at offset 0 in `tc_mqprio_qopt_offload`, place fixed fields inside `tc_u32_sel_hdr`, and use `TCA_RED_FLAGS` for new RED flags. [F74, F101, F129, F132, F150, F183]

## Known Pitfalls

- All `idrinfo->action_idr` lookups/walkers must check `IS_ERR(p)` before dereferencing `p`. In `tcf_action_delete()`, save `a->ops`, `a->idrinfo`, and `a->tcfa_index` to locals before `tcf_action_put(a)` and `tcf_idr_delete_index()`. [F44, F72]
- Re-fetch `skb_network_header()`, `ip_hdr()`, or `ipv6_hdr()` after any `pskb_may_pull()`, `pskb_network_may_pull()`, `skb_try_make_writable()`, or `tcf_csum_skb_nextlayer()` call. [F136]
- In `act_ct.c`, `zones_ht` is keyed by `struct zones_ht_key` (`net` and `zone`) with `key_len = offsetofend(struct zones_ht_key, zone)` to avoid hashing padding, and `tcf_ct_fill_params()` must check `name[len - 1] == '\0'` for `TCA_CT_HELPER_NAME`. [F49, F138, F174]
- `tcf_blockcast_redir()` must lag one iteration with `dev_prev` so only the final port receives redirect `m_eaction` while earlier ports mirror. Use `time_after(jiffy_since, (unsigned long)p->tcfa_tm.lastuse)` in `tcf_dump_walker()`, and `PSCHED_TICKS2NS(x)` (`s64` cast) before shifting by `PSCHED_SHIFT`. [F116, F125, F126]
