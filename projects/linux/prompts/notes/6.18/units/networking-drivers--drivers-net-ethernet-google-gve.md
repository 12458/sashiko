# NETWORKING DRIVERS — drivers/net/ethernet/google/gve

The Google Virtual Ethernet (`gve`) driver supports Google Cloud's gVNIC PCIe device, implementing an admin queue and supporting GQI and DQO queue formats in QPL or RDA modes, XDP, AF_XDP (XSK), PTP, RSS, and flow steering.

## Architecture & Data Flow
- `priv->rx` and `priv->tx` are `NULL` when closed; callbacks reachable while down (XSK, stats, `netdev_queue_mgmt_ops`) must check `priv->rx`/`priv->tx`, `netif_running(dev)`, or `gve_get_napi_enabled(priv)` before indexing. Control-plane paths (`gve_set_xdp()`, `gve_adjust_*()`, `gve_set_hsplit_config()`, `gve_set_features()`, `gve_reset()`, `gve_shutdown()`, `gve_suspend()`) must check `netif_running(dev)`, never `netif_carrier_ok(dev)`. [F39, F57]
- `rx->dqo.page_pool` is allocated only in DQO RDA mode (`cfg->raw_addressing`) and is `NULL` in QPL mode; all DQO RX paths must check `rx->dqo.page_pool` before calling `page_pool` APIs and use it to discriminate `page_info.netmem` from `page_info.page`. [F37]
- In `gve_tx_pending_packet_dqo`, `pending_packet->type` discriminates `skb`/`xdpf`, and `tx->dqo.qpl != NULL` discriminates `tx_qpl_buf_ids` vs `dma`/`len`. `GVE_PACKET_STATE_UNALLOCATED` must remain 0 and be restored by `gve_free_pending_packet()`. [F46, F49]
- In DQO pools, `0` is a valid index; empty `gve_index_list` and `s16` heads/tails must be initialized to `-1`. In `gve_rx_buf_state_dqo`, `buf_state->next == buf_state - rx->dqo.buf_states` marks an allocated entry (`gve_buf_state_is_allocated()`), which `gve_rx_dqo()` must verify along with `buffer_id < rx->dqo.num_buf_states`. `rx->dqo.used_buf_states_cnt` must track `used_buf_states`, and `gve_get_recycled_buf_state()` must bound its search over `used_buf_states` to 5 attempts. [F50, F68, F80, F108]
- In `gve_tx_alloc_ring_dqo()`, `tx->dqo.num_pending_packets` is reduced by `(complq_mask + 1) / GVE_TX_MIN_RE_INTERVAL`, halved, and clamped to `S16_MAX`. In DQO TX completions, `compl_tag` must have `GVE_ALT_MISS_COMPL_BIT` (`BIT(15)`) stripped when `type == GVE_COMPL_TYPE_DQO_PKT` and be bounds-checked against `num_pending_packets`. [F81, F118]
- Ring sizes (`tx_desc_cnt`, `rx_desc_cnt`) must be powers of two (`gve_validate_req_ring_size()`). GQI/QPL `u32` counters (`req`/`done`, `fill_cnt`/`cnt`, `alloc_tx_qpl_buf_cnt`/`free_tx_qpl_buf_cnt`) are unmasked (`producer - consumer`), whereas DQO `head`/`tail` are masked in `[0, mask]`, with used `(tail - head) & mask` and available `mask - num_used`. [F77, F115, F116]
- In GQI RX, `rx->desc.seqno` is 1-based in `[1, 7]` (`gve_next_seqno()`). The first fragment includes 2-byte `GVE_RX_PAD` in `desc->len`; `gve_rx()` must check `frag_size > rx->packet_buffer_size` before subtracting `page_info->pad`, and drop paths (`ctx->drop_pkt = true`) must `goto finish_frag`. `gve_clean_rx_done()` may exceed `budget` only while `ctx->frag_cnt != 0`, and on seqno mismatch with `frag_cnt != 0` must call `napi_free_frags()`, `gve_rx_ctx_clear()`, and schedule a reset. [F78, F98, F105, F160]
- In DQO completion rings, `cur_gen_bit` flips when `head` wraps to 0 and descriptors require `compl_desc->generation != cur_gen_bit` then `dma_rmb()`. In `gve_rx_poll_dqo()`, `complq->head`, `num_free_slots`, `cur_gen_bit`, `bufq->head`, and `rx->cnt` must update on every descriptor before any `continue`, while `work_done` increments only on `end_of_packet`. In `gve_rx_dqo()`, `if (rx->ctx.skb_head)` must run `gve_rx_append_frags()` and return before `xprog` or `rx_copybreak`. [F79, F100, F107]
- In DQO TX, `buf_size` is capped at `GVE_TX_MAX_BUF_SIZE_DQO` (`16383`, splitting larger buffers). Hardware allows at most `GVE_TX_MAX_DATA_DESCS` (10) data descriptors per non-TSO packet or TSO segment: RDA non-GSO SKBs >10 descriptors must call `skb_linearize()`, and `gve_can_send_tso()` (`gve_features_check_dqo()`) must clear `NETIF_F_GSO_MASK` if any TSO segment spans >10 descriptors (including mid-fragment starts after a split fragment). `report_event` is set only on a packet's last descriptor at intervals `>= GVE_TX_MIN_RE_INTERVAL` (32). [F93, F94, F95, F157]
- In GQI QPL TX FIFO (`gve_tx_alloc_fifo()`), `fifo->head` is aligned to `L1_CACHE_ALIGN(fifo->head)`, so `gve_skb_fifo_bytes_required()` must include both wrap `pad_bytes` and `L1_CACHE_ALIGN(hlen) - hlen`. [F152]
- When `priv->xdp_prog != NULL`, `tx_cfg.num_xdp_queues` (and `num_xdp_rings`) must equal `rx_cfg.num_queues` (0 when `NULL`), `NETIF_F_LRO` and `header_split_enabled` must be off, and `rx_cfg.num_queues == tx_cfg.num_queues` with `2 * tx_cfg.num_queues <= tx_cfg.max_queues`. `gve_reg_xsk_pool()`/`gve_unreg_xsk_pool()` must update `rx[qid].xsk_pool`, `tx[xdp_qid].xsk_pool`, and `priv->xsk_pools` together. XSK TX polling runs in the `block->rx` NAPI branch, so `gve_xsk_wakeup()` must schedule RX NAPI (`gve_rx_idx_to_ntfy()`) for both RX and TX. [F54, F55, F60, F156, F167]
- QPL IDs split at `tx_cfg.max_queues`: TX uses `q`, RX uses `tx_cfg.max_queues + q`, and `gve_qpl_dma_dir()` checks `id < gve_rx_start_qpl_id(&priv->tx_cfg)`. When `pci_enable_msix_range()` returns fewer vectors, `num_ntfy_blks` must be rounded down to even `(vecs_enabled - 1) & ~0x1`, `mgmt_msix_idx = num_ntfy_blks`, and `tx_cfg`/`rx_cfg` clamped. `priv->irq_db_indices` is an array of cacheline-aligned `struct gve_irq_db`, not contiguous `__be32`. [F65, F83, F128]
- In `gve_adminq_describe_device()`, `queue_format` priority is `dqo_rda`, `dqo_qpl`, `gqi_rda`, `GVE_GQI_RDA_FORMAT`, then `GVE_GQI_QPL_FORMAT`. Reset recovery and resume must pass `skip_describe_device = true` to `gve_init_priv()`. `gve_adminq_release()` must clear `DEVICE_RINGS_OK`, `DEVICE_RESOURCES_OK`, and `ADMIN_QUEUE_OK`. [F70, F71, F99]
- Stack `union gve_adminq_command` instances must be zeroed with `memset()`. Every AdminQ opcode needs a case in `gve_adminq_issue_cmd()`. In `gve_adminq_process_flow_rules_query()` and `gve_adminq_process_rss_query()`, `be32_to_cpu(descriptor->total_length)` must equal `sizeof(*descriptor) + payload_len`. `priv->rss_lut_size` is in 32-bit entries (multiply by 4 for bytes) and must stay synced in `priv->rss_config` when `cache_rss_config` is true. [F48, F59, F73, F90, F126]
- `priv->stats_report->stats[]` has driver-written stats before NIC-written stats (`gve_set_priv_flags()` zeroes only the driver prefix); `gve_handle_report_stats()` must index `priv->tx[idx]`/`rx[idx]` with `idx` and a single shared `stats_idx`. `gve_get_ethtool_stats()` must offset `base_stats_idx` by stopped queues, bounds-check `queue_id`, reset `skip_nic_stats = false` before TX NIC stats, and advance `i` in lockstep with `gve_gstrings_*_stats`. [F74, F91, F110, F111, F127]

## Synchronization
- Callers of `gve_reset()`, `gve_close()`, or `gve_reset_recovery()` outside NDO callbacks (`gve_handle_reset()`, `gve_shutdown()`, `gve_suspend()`, `gve_resume()`) must acquire `rtnl_lock()` then `netdev_lock(dev)`. In `gve_turndown()`, `gve_turnup()`, `gve_add_napi()`, and `gve_remove_napi()`, NAPI and XDP feature helpers must use `_locked` variants. [F24, F25]
- Callers of `gve_adminq_issue_cmd()` / `gve_adminq_kick_and_wait()` must hold `priv->adminq_lock` in process context (`msleep()`). In `gve_probe()`, `gve_set_probe_in_progress()` is set before requesting the mgmt IRQ and cleared only after `register_netdev()`, followed by queuing `service_task`. [F15, F26]
- In `gve_turnup()`, `mb()` must run after unmasking the IRQ before `napi_schedule()`. In `gve_turndown()`, disable all NAPIs, call `netif_tx_disable()`, clear XDP redirect, call `gve_clear_napi_enabled()`, and run `synchronize_net()` before destroying rings. In `gve_rx_alloc_ring_gqi()`, `dma_wmb()` must follow `gve_rx_prefill_pages()`. In `gve_napi_poll()`, `mb()` must follow writing `GVE_IRQ_ACK | GVE_IRQ_EVENT` before checking pending work. [F16, F17, F20, F34]
- GQI TX holds `tx->clean_lock` across reading events, `gve_clean_tx_done()`, `gve_can_tx()`, and stopping the queue in `gve_maybe_stop_tx()`. DQO TX pairs `mb()` after `netif_tx_stop_queue()` (before rechecking `gve_has_avail_slots_tx_dqo()`) with `mb()` after `gve_clean_tx_done_dqo()` (before `netif_tx_queue_stopped()`). [F27, F33]
- XDP TX submissions (`ndo_xdp_xmit`, `XDP_TX`, XSK TX) must hold `tx->xdp_lock` / `tx->dqo_tx.xdp_lock`. `gve_xsk_pool_disable()` must `napi_disable()` both `napi_rx` and `napi_tx` before `gve_unreg_xsk_pool()`, and run `smp_mb()` before `napi_enable()`. `gve_xsk_wakeup()` must bracket `napi_schedule()` with `local_bh_disable()`/`enable()`. [F21, F28, F142]
- DQO TX completions push to `dqo_compl.free_pending_packets` and `free_tx_qpl_buf_head` via `atomic_cmpxchg()`, and TX steals via `atomic_xchg(..., -1)` when its local list is `-1`. `gve_xsk_reorder_queue_push_dqo()` pairs `atomic_set_release(&xsk_reorder_queue_tail)` with `atomic_read_acquire()` in `gve_xsk_reorder_queue_head()`. [F32, F35]

## Object Lifetimes
- `gve_queues_start()` takes ownership of `tx_alloc_cfg->tx` and `rx_alloc_cfg->rx` and frees them on error, so callers must never call `gve_queues_mem_free()` after it. `gve_rx_queue_stop()` rejects `idx == 0` on DQO (`-ERANGE`); both `gve_rx_queue_stop()` and `gve_rx_queue_start()` must bracket AdminQ ops with `gve_turndown()`/`gve_turnup_and_check_status()` and zero `priv->rx[idx]` when leaving the slot inactive. [F2, F40, F165]
- In GQI QPL mode, `rx->data.page_info[i].page` borrows from `qpl->pages[i]` (only subtract `pagecnt_bias - 1`, no `put_page()`), whereas `qpl_copy_pool` needs `put_page()`. In DQO QPL mode, `gve_free_qpl_page_dqo()` must subtract `pagecnt_bias - 1` and clear `buf_state->page_info.page = NULL`. [F3, F4]
- In DQO RDA mode, `gve_reuse_buffer()` clears `netmem = 0`, while `gve_free_buffer()` calls `gve_free_to_page_pool()` (`page_pool_put_full_netmem()`, clearing `netmem = 0`). In `gve_xdp_done_dqo()`, `XDP_TX`/`XDP_REDIRECT` call `gve_reuse_buffer()` on success and `gve_free_buffer()` on failure/drop. In DQO RX teardown, call `page_pool_disable_direct_recycling()` before `gve_remove_napi()`, release all `buf_states` with `allow_direct = false` before `page_pool_destroy()`, and check `gve_buf_state_is_allocated()` before `xsk_buff_free()`. `gve_rx_free_skb()` must clear `napi->skb = NULL` if `rx->ctx.skb_head == napi->skb`. [F5, F6, F10, F12, F148, F149, F168]
- `gve_tx_stop_ring_gqi()` must drain all descriptors via `gve_clean_tx_done()` or `gve_clean_xdp_done()` before `gve_tx_fifo_release()`. In DQO TX, timed-out `miss_completions` move to `timed_out_completions` (not `gve_free_pending_packet()`), and completed `GVE_TX_PENDING_PACKET_DQO_XSK` packets set `state = GVE_PACKET_STATE_XSK_COMPLETE` so `gve_tx_process_xsk_completions()` frees them in order. [F7, F8, F103]
- `gve_set_xdp()` must only replace `priv->xdp_prog` and `bpf_prog_put(old_prog)` after `gve_configure_rings_xdp()` succeeds. `priv->num_registered_pages` must be incremented in `gve_register_qpl()`, decremented in `gve_unregister_qpl()`, and reset to 0 in `gve_init_priv()`. [F11, F13]
- `gve_queues_stop()` (when `DEVICE_RINGS_OK`) must run `gve_turndown()`, `gve_destroy_rings()`, and `gve_unregister_qpls()`—falling back to `gve_reset_and_teardown()` on error—before freeing queue DMA memory. `gve_teardown_device_resources()` (when `DEVICE_RESOURCES_OK`) must deconfigure flow rules, stats, and device resources via AdminQ—calling `gve_trigger_reset()` on error—before freeing DMA buffers. `gve_shutdown()` must call `netif_device_detach()` first, and `gve_remove()` must finish `unregister_netdev()` and `gve_teardown_priv_resources()` before `destroy_workqueue(priv->gve_wq)`. [F18, F19, F471, F472]

## API Contracts
- Ring alloc/free functions (`gve_tx_alloc/free_rings_*`, `gve_rx_alloc/free_ring*`) must read ring pointers, sizes, and queue counts from `cfg`, never `priv`. [F112]
- `gve_rx_can_recycle_buffer()` returns `1`, `0`, or `-1` (`< 0` schedules reset; check before converting to `bool`). In GQI TX, `gve_tx_add_skb_*()` returns `nsegs` or `0` on drop (`gve_tx()` frees `skb`); in DQO TX, `gve_try_tx_skb()` returns `0` on transmit/drop (frees `skb` internally) and `-1` when full. Both `gve_tx()` and `gve_tx_dqo()` must ring the doorbell before returning `NETDEV_TX_BUSY` or after a drop. [F43, F44, F169]
- `tx->netdev_txq` is `NULL` on XDP TX queues; DQO TX functions must guard `netdev_tx_*` calls with `if (tx->netdev_txq)`, pass `pkt_compl_* + miss_compl_*` (excluding `reinject_compl_*`) to `netdev_tx_completed_queue()`, and pass `!!napi` to `napi_consume_skb()`. `dev->netmem_tx` is enabled only for DQO RDA, where `dma[0]` uses `dma_unmap_single()` and `1..num_bufs-1` use `netmem_dma_unmap_page_attrs()`. [F45, F143, F151, F164, F170]
- `gve_prep_tso()` must call `skb_cow_head(skb, 0)` before modifying `tcp_hdr(skb)->check` and validate MSS, GSO type, and header size. `gve_napi_poll_dqo()` returns `budget` on `reschedule` only if `gve_is_napi_on_home_cpu()`, else decrements `work_done` if `== budget` and calls `napi_complete_done()`. DQO RSC completions (`desc->rsc`) must call `gve_rx_complete_rsc()` before GRO. `gve_set_netdev_xdp_features()` omits `NETDEV_XDP_ACT_NDO_XMIT`, which `gve_turnup()`/`gve_turndown()` toggle via `xdp_features_set/clear_redirect_target_locked()`. [F155, F158, F161, F162]

## Error Handling
- In `gve_tx_add_skb_no_copy()`, `info->skb` is set on the first descriptor and `NULL` on fragments, and `unmap_drop` must skip the unmapped metadata descriptor (`i == 1 && mtd_desc_nr == 1`). Callers of `gve_alloc_pending_packet(tx)` must check for `NULL`. `gve_rx_alloc_ring_dqo()` must check `IS_ERR(pool)` before assigning `rx->dqo.page_pool`. `gve_adminq_configure_flow_rule()` calls `gve_reset(priv, true)` only on `-ETIME` and sets `rules_cache_synced = false` only when `!err`. [F9, F36, F38, F166]

## External Contracts
- GQI TX descriptor offsets (`l4_csum_offset`, `l4_hdr_offset`, `l3_offset`) must be shifted `>> 1`. In `gve_extract_tx_metadata_dqo()`, a zero 15-bit folded `skb->hash` must be bitwise-inverted for `metadata->path_hash`. [F53, F120]
- `gve_get_next_option()` must bounds-check option length against `descriptor->total_length`; `gve_parse_device_option()` must accept larger/unknown options, set `default_min_ring_size = true` on 8-byte `GVE_DEV_OPT_ID_MODIFY_RING`, and `gve_enable_supported_features()` must require the `GVE_SUP_*_MASK` bit in `supported_features_mask`. AdminQ commands >56 bytes must use `gve_adminq_execute_extended_cmd()`, `-EOPNOTSUPP` in `gve_verify_driver_compatibility()` is treated as `0`, and `gve_adminq_alloc()`/`release()` must branch on `pdev->revision < 0x1`. [F87, F88, F89, F478, F479, F480]

## Known Pitfalls
- BAR0 registers, AdminQ structs, and GQI descriptors/doorbells are big-endian (`__be*`, `iowrite32be`), whereas DQO descriptors and BAR2 doorbell values are little-endian (`__le*`, `iowrite32`) at a big-endian `db_index`. [F86]
- `gve_set_features()` must update `netdev->features` with `NETIF_F_LRO` before `gve_adjust_config()` and restore `orig_features` on error. In `remove_miss_completions()` and `remove_timed_out_completions()`, save `next_index = pending_packet->next` before list mutation/free and check `timeout_jiffies` with `time_is_after_jiffies()`. [F72, F104, F123]
- `gve_clean_xdp_done()` and `gve_clean_tx_done()` must loop `for (i = 0; i < to_do; i++)` incrementing `tx->done`. `gve_rx_skb_hwtstamp()` must store `hwts - (u32)last_read` in `s32 diff`. `gve_rx_dqo()` must check `!netmem_is_net_iov(netmem)` before `netmem_to_page()` or CPU reads when `header_split_enabled` is true. `gve_gstrings_adminq_stats` is `__nonstring_array` and requires `ethtool_cpy()`. [F114, F117, F133, F150]
