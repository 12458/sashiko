# SOUND - SOC LAYER / DYNAMIC AUDIO POWER MANAGEMENT (ASoC) — sound/soc (part 8)

Implements ALSA SoC audio drivers for Allwinner sunxi SoCs (`sun4i`/`sun6i`/`sun7i`/`sun8i`/`sun50i` codecs, I2S, SPDIF) and NVIDIA Tegra SoCs (`Tegra20` AC'97/DAS/I2S/SPDIF, `Tegra186` ASRC/DSPK, `Tegra210`/`Tegra264` ADMAIF/ADX).

## Architecture & Data Flow
- In `tegra186_asrc.c`, `tegra186_asrc_runtime_resume()` must write `TEGRA186_ASRC_GLOBAL_SCRATCH_ADDR` and `GLOBAL_ENB` before `regcache_sync()`, then restore volatile `RATIO_INT_PART` and `RATIO_FRAC_PART` from `asrc->lane[]` for `TEGRA186_ASRC_RATIO_SOURCE_SW` lanes. Any write to those ratio registers (`runtime_resume`, `out_hw_params`, `put_ratio_int`/`frac`) must call `tegra186_asrc_lock_stream(asrc, id)`. In `tegra186_asrc_wr_reg()`, `rd_reg()`, and `volatile_reg()`, reduce `reg %= TEGRA186_ASRC_STREAM_STRIDE` only when `reg < TEGRA186_ASRC_STREAM_LIMIT` (`0x2f0`). [F177, F178, F210]
- DAI array indexing: `tegra186_asrc_out_hw_params()` uses `id = dai->id - 7` into `asrc->lane[]` (`TEGRA186_ASRC_STREAM_MAX = 6`), requiring the 6 `OUT_DAI` entries in `tegra186_asrc_dais` at indices 7..12 after the 7 `IN_DAI` entries. `tegra210_adx_out_hw_params()` uses `TEGRA210_ADX_TX1_CIF_CTRL + ((dai->id - 1) * TEGRA210_ADX_AUDIOCIF_CH_STRIDE)`, requiring `IN_DAI` at index 0 of `tegra210_adx_dais` and `OUT_DAI(1..4)` at `dai->id` 1..4. [F189, F195]
- In `tegra210_adx.c`, `TEGRA210_ADX_CFG_RAM_CTRL`/`DATA` are volatile, so `tegra210_adx_runtime_resume()` must call `tegra210_adx_write_map_ram(adx)` after `regcache_sync()`. Both `IN_DAI` and `OUT_DAI` must advertise `SNDRV_PCM_FMTBIT_S8`, `S16_LE`, `S24_LE`, and `S32_LE` without duplicates. [F176, F201]
- In `tegra186_dspk_hw_params()`, `tegra_admaif_hw_params()`, and `tegra210_adx_set_audio_cif()`, set `cif_conf.client_bits` in lockstep with `cif_conf.audio_bits` per format branch (`TEGRA_ACIF_BITS_16` for `S16_LE`), and on 32-channel Tegra264 variants (`max_stream_ch == TEGRA264_ADMAIF_MAX_CHANNEL` or `adx->soc_data->max_ch == 32`) call `tegra264_set_cif()` instead of `tegra_set_cif()`. In `tegra_admaif_set_pack_mode()`, set the selected pack bit (`PACK8_EN` or `PACK16_EN`) and explicitly clear the other (or clear both for `DATA_32BIT`) in lockstep with `valid_bit`. [F181, F182, F239]
- FIFO thresholds and regmap: `tegra186_dspk_hw_params()` must clamp `dspk->rx_fifo_th` to `(TEGRA186_DSPK_RX_FIFO_DEPTH / cif_conf.audio_ch) - 1`. In `tegra20_spdif.c`, TX FIFO attention level in `TEGRA20_SPDIF_DATA_FIFO_CSR` must be `>= spdif->playback_dma_data.maxburst`. In `tegra20_ac97.c`, `tegra20_i2s.c`, and `tegra20_spdif.c`, all data FIFO registers (`FIFO_TX1`/`RX1`, `FIFO1`/`FIFO2`, `DATA_OUT`/`DATA_IN`/`USR_STA_RX_A`/`USR_DAT_TX_A`) must be both `volatile_reg` and `precious_reg`. [F196, F197, F246]
- In `tegra20_i2s_runtime_resume()` and `tegra20_spdif_runtime_resume()`, assert reset, enable module clock, wait `usleep_range(10, 100)`, and deassert reset before leaving cache-only mode and calling `regcache_sync()`. In `tegra20_i2s_filter_rates()` and `tegra20_spdif_filter_rates()`, if `valid_rates == 0`, set `valid_rates = BIT(ARRAY_SIZE(...)) - 1` before `snd_interval_list()`. In `tegra20_ac97.c`, poll loops in `codec_reset`, `codec_warm_reset`, `codec_read`, and `codec_write` must use `time_after(jiffies, timeout)`. [F220, F221, F231]
- In `sun8i-codec.c`, `clk_set_rate_exclusive()` and `scodec->sysclk_refcnt++` in `hw_params` run only when `aif->open_streams == 0`; `clk_rate_exclusive_put()`, `sysclk_refcnt--`, and zeroing `aif->lrck_div_order`/`sample_rate` in `hw_free` run only when `aif->open_streams == BIT(substream->stream)`. Call `sun8i_codec_update_sample_rate(scodec)` whenever `aif->sample_rate` or `aif->active_streams` (`sun8i_codec_aif_event()`) changes. [F184, F185]
- In `sun8i-codec.c`, AIF2 and AIF3 share `SUN8I_AIF_CLK_CTRL(SUN8I_CODEC_AIF2)`: `sun8i_codec_hw_params()` must write AIF2/AIF3 LRCK/BCLK dividers to `AIF2`'s register after verifying any open stream on the partner AIF (`(AIF2 + AIF3) - dai->id`) has matching `lrck_div_order` and `sample_rate`. In `sun8i_codec_set_fmt()`, `dai->id == SUN8I_CODEC_AIF3` must reject slave mode (`value != 0`) and non-DSP formats (`format != 3`) with `-EINVAL` and not write `MSTR_MOD` or `DATA_FMT_MASK`; `scodec->quirks->lrck_inversion` must only be XORed into `invert` when `format != 0x3`, whereas in DSP mode (`format == 0x3`) `invert & BIT(0)` selects DSP_A/B and caller LRCK inversion returns `-EINVAL`. [F206, F237, F238]
- `sun8i_codec_get_lrck_div_order()` must reject `div = slots * slot_width` outside `[16, 256]` and use `order_base_2(div)` (ceiling log2, not `ilog2`) so `lrck_div_order` stays in `[4, 8]`. [F217, F218]
- In `sun8i_codec_jack_irq()`, `SUN8I_HMIC_STS` is volatile W1C (`JACK_OUT_IRQ_ST` must be checked before `JACK_IN_IRQ_ST`). On `HMIC_DATA_IRQ_ST`, return early unless `scodec->jack_status == SUN8I_JACK_STATUS_CONNECTED`, and only call `snd_soc_jack_report()` when `scodec->jack_last_sample >= 0` matches the current ADC sample. In `sun8i_codec_jack_work()`, guard `ktime_ms_delta(scodec->jack_hbias_ready, ktime_get())` with `!ktime_after(ktime_get(), scodec->jack_hbias_ready)` and add 10 ms before `msecs_to_jiffies()`. [F203, F222, F243]
- In `sun50i_a64_codec_set_bias_level()`, entering `SND_SOC_BIAS_STANDBY` must query `snd_soc_dapm_get_pin_status(dapm, "HBIAS")` and restore `SUN50I_ADDA_JACK_MIC_CTRL_MICADCEN` alongside `JACKDETEN`. In `sun4i_spdif_hw_params()`, multiply both `mclk` and `mclk_div` by `host->quirks->mclk_multiplier`. [F187, F234]
- In `sun4i-i2s.c`, `sun4i_i2s_set_fmt()` must cache `i2s->format = fmt`. In `sun8i_i2s_set_chan_cfg()` and `sun50i_h6_i2s_set_chan_cfg()`, `LEFT_J`/`RIGHT_J` group with `I2S` (`lrck_period = slot_width`), while `DSP_A`/`B` use `slot_width * slots`. In `sun8i_i2s_set_soc_fmt()` and `sun50i_h6_i2s_set_soc_fmt()`, init `lrclk_pol` to `START_LOW` for `I2S` and `START_HIGH` for DSP/left-J/right-J before XORing `LRCLK_POLARITY_MASK` on `IB_IF`/`NB_IF`. `sun4i_i2s_quirks::pcm_formats` must be `u64` for `snd_pcm_hw_constraint_mask64()`; `get_sr`/`get_wss` must use `switch (width)` returning `-EINVAL` on default; `sun4i_i2s_set_clk_rate()` must validate `rate` and `sun4i_i2s_oversample_is_valid(i2s->mclk_freq / rate)` before calling `get_bclk_div`/`get_mclk_div`. [F188, F200, F214, F219, F235, F236]

## Synchronization
- In `sun8i-codec.c`, `sun8i_codec_enable_jack_detect()` must set `scodec->jack` and init `SUN8I_HMIC_CTRL1`/`CTRL2`/`STS` before `devm_request_threaded_irq()`. `sun8i_codec_jack_irq()` and `sun8i_codec_jack_work()` must hold `scodec->jack_mutex` around `last_hmic_irq`, `jack_status`, `jack_last_sample`, `jack_hbias_ready`, and `SUN8I_HMIC_STS`. [F156, F252]
- `sun4i_spdif_get_status()` and `sun4i_spdif_set_status()` must hold `host->lock` (`spin_lock_irqsave`) across `SUN4I_SPDIF_TXCHSTA0`, `TXCHSTA1`, and `TXCFG` accesses. In `sun8i-adda-pr-regmap.c`, `adda_reg_read()`/`write()` multiplex 5-bit registers over `ADDA_PR` (deasserting `ADDA_PR_RESET`, setting `ADDR_SHIFT`, strobing `ADDA_PR_WRITE`), so `adda_pr_regmap_cfg` must keep `.fast_io = true` without `.disable_locking`. [F158, F242]
- `tegra_admaif_stop()` must poll channel disable and soft reset with `regmap_read_poll_timeout_atomic()` (keeping `RX_STATUS`/`TX_STATUS` and `RX_SOFT_RESET`/`TX_SOFT_RESET` volatile), whereas process-context `tegra210_adx_startup()` must use sleeping `regmap_read_poll_timeout()` for `TEGRA210_ADX_STATUS` and `SOFT_RESET`. [F244, F250]

## Object Lifetimes
- In `sun4i_i2s_runtime_resume()` and `suspend()`, `i2s->bus_clk` must be enabled before leaving cache-only mode, syncing regcache, or accessing `SUN4I_I2S_CTRL_REG` (and disabled on resume error), and in suspend `i2s->mod_clk` and `SUN4I_I2S_CTRL_REG` must be disabled and regcache set cache-only before disabling `i2s->bus_clk`. In `sun4i-i2s.c`, `sun4i-spdif.c`, and `sun8i-codec.c`, when `!pm_runtime_enabled()` triggers manual `runtime_resume` in probe, error paths and `.remove` must check `!pm_runtime_status_suspended()` and call `runtime_suspend`. [F148, F149]
- In `sun8i_codec_disable_jack_detect()`, call `devm_free_irq(component->dev, scodec->jack_irq, scodec)` before `cancel_delayed_work_sync(&scodec->jack_work)`, and complete both before clearing `SUN8I_HMIC_CTRL1` IRQ bits and setting `scodec->jack = NULL`. In `sun4i_codec_probe()`, attach `scodec` via `snd_soc_card_set_drvdata(card, scodec)`, not `platform_set_drvdata()`. [F154, F233]
- In `tegra_admaif_probe()`, set `admaif->soc_data` and `dev_set_drvdata(&pdev->dev, admaif)` before `devm_regmap_init_mmio()` and `tegra_isomgr_adma_register()`, pair `tegra_isomgr_adma_unregister(&pdev->dev)` in `tegra_admaif_remove()`, and pair `tegra_isomgr_adma_setbw(..., true/false)` in `prepare`/`shutdown`. In `tegra20_ac97.c` and `tegra20_i2s.c`, error paths and `.remove` must call `tegra_pcm_platform_unregister()` before `snd_soc_unregister_component()`. [F150, F152, F267]

## API Contracts
- In `tegra186_dspk.c`, `tegra186_asrc.c`, and `tegra210_admaif.c`, `kcontrol` callbacks must use `ucontrol->value.enumerated.item[0]` for `SOC_ENUM_EXT`/`NV_SOC_ENUM_EXT` and `value.integer.value[0]` for `SOC_SINGLE_EXT`/`SOC_SINGLE_EXT_FRAC`. In `tegra186_asrc.c`, cast `kcontrol->private_value` to `struct soc_mreg_control *` for `SOC_SINGLE_EXT_FRAC`, `struct soc_enum *` for `SOC_ENUM_EXT`, and `struct soc_mixer_control *` for `SOC_SINGLE_EXT`. Custom `put` callbacks across `tegra186_dspk`, `tegra186_asrc`, `tegra210_admaif`, `tegra210_adx`, and `sun4i-spdif` must return `1` on change, `0` if unchanged, or negative errno; `tegra186_asrc_put_ratio_int()`/`frac()` must return `-EINVAL` if `ratio_source == TEGRA186_ASRC_RATIO_SOURCE_ARAD`. [F159, F161, F179, F226]
- In `tegra210_admaif.c`, `CH_REG`, `CH_TX_REG`, `CH_RX_REG`, `admaif->mono_to_stereo[path]`, `admaif->stereo_to_mono[path]`, and `NV_SOC_ENUM_EXT` `xreg` (`ec->reg`) take 0-based channel indices (`0..num_ch - 1`), whereas `ADMAIF_REG_DEFAULTS(id, chip)` and `TEGRA_ADMAIF_CIF_CTRL(reg)` take 1-based channel numbers (`1..num_ch`). In `tegra20_das.c`, `tegra20_das_connect_dap_to_dac(das, dap, dac)` takes `(DAP_ID_*, DAP_SEL_*)`, whereas `connect_dac_to_dap(das, dac, dap)` takes `(DAC_ID_*, DAC_SEL_DAP*)`. [F167, F169, F191]
- `tegra_admaif_trigger()` must call `snd_dmaengine_pcm_trigger(substream, cmd)` before starting/stopping the channel. `sun8i_adda_pr_regmap_init()` passes raw `void __iomem *base` as the regmap context to `devm_regmap_init()`. `snd_dmaengine_dai_dma_data.addr` across all sunxi and Tegra drivers must be computed from physical `res->start` / `mem->start`, never the ioremapped pointer. In `sun4i-codec.c`, `create_card` callbacks must set `card->owner = THIS_MODULE`. [F227, F254, F261, F266]

## Error Handling
- In `sun4i-codec.c`, `sun4i_codec_create_link()` returns `NULL` on failure, whereas `sun4i_codec_quirks.create_card` must return an `ERR_PTR`. `sun4i_codec_get_mod_freq()` returns `0` on error, whereas `sun4i_codec_get_hw_rate()` (where `0` is valid for 48/44.1 kHz) and divider/resolution helpers in `sun4i-i2s.c` and `sun8i-codec.c` (`get_bclk_div`, `get_mclk_div`, `get_sr`, `get_wss`, `get_hw_rate`, `get_lrck_div_order`) return `>= 0` on success and `-EINVAL` on error, requiring signed `int` variables and `< 0` checks. [F170, F171, F172]

## External Contracts
- In `tegra_admaif_probe()`, Device Tree `"dma-names"` has capture (RX) at even index `i * 2` (`capture_dma_data[i].chan_name`) and playback (TX) at odd index `(i * 2) + 1` (`playback_dma_data[i].chan_name`) for 0-based channel `i`. [F168]

## Known Pitfalls
- In `tegra186_dspk_hw_params()`, write `(dspk->ch_sel + 1) << CH_SEL_SHIFT` to `TEGRA186_DSPK_CORE_CTRL` because `dspk->ch_sel` is 0-based (`0..2`). In `tegra186_asrc_put_input_threshold()` and `put_output_threshold()`, preserve upper watermark bits `(thresh & ~(0x3))` (`0x00201002`) when updating `asrc->lane[id].input_thresh`/`output_thresh`. [F164, F180]
- In `tegra210_adx.c`, `adx->map` is `ram_depth` 32-bit `unsigned int` words for `write_map_ram()`, but cast to `unsigned char *` (`bytes_map`) in `get_byte_map()`/`put_byte_map()` indexed by `mc->reg` (up to `ram_depth * 4 - 1`); for value `256` (disabled), `put_byte_map` stores `value % 256` and clears bit `mc->reg % 32` in `adx->byte_mask[mc->reg / 32]`, which `get_byte_map` checks to return `256`. In `tegra210_admaif.c`, `.num_reg_defaults` in `regmap_config` is `TEGRA*_ADMAIF_CHANNEL_COUNT * 6 + 1` and must be updated if `REG_DEFAULTS()` changes. [F194, F224, F225]
- In `sun4i-codec.c`, `sun50i-codec-analog.c`, `sun8i-codec-analog.c`, and `sun8i-codec.c`, bit-index macros (`SUN4I_CODEC_DAC_FIFOC_*`, `SUN50I_ADDA_*`, `SUN8I_ADDA_*`, `SUN8I_HMIC_CTRL1_*`) are unshifted and must be wrapped in `BIT()` or `<<`. In `sun8i-codec.c`, `sun8i_codec_aif_event()` indexes `scodec->aifs[]` via `w->sname[3] - '1'`, requiring widget `.sname` to start with `"AIF1".."AIF3"`. In `sun4i-spdif.c`, `sun4i_spdif_get_status()`/`set_status()` must use `snd_kcontrol_chip(kcontrol)` to get `struct snd_soc_dai *` (DAI-attached controls) and cast `u8` `status[]` bytes to `u32` before shifting (`(u32)status[3] << 24`). [F174, F198, F215, F263]
