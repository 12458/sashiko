# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 1)

Hardware abstraction layer, MAC/PHY/EEPROM ops for 82599 and E610 controllers, Data Center Bridging (DCB) configuration and `dcbnl` netlink interface, and debugfs interface for the Intel 10GbE (`ixgbe`) driver.

## Architecture & Data Flow

- In `ixgbe_reset_hw_82599`, reset `hw->mac.num_rar_entries` to `IXGBE_82599_RAR_ENTRIES` before `init_rx_addrs()`, `set_rar()`, and `clear_vmdq()`, and decrement it only after programming a valid SAN MAC at `san_mac_rar_index`; also sample pre-reset `IXGBE_AUTOC_LMS_MASK` before writing `IXGBE_CTRL` and merge it into `hw->mac.orig_autoc` before restoring `IXGBE_AUTOC` on subsequent resets when `(hw->phy.multispeed_fiber && ixgbe_mng_enabled(hw)) || hw->wol_enabled`. [F1219, F1228]
- In `ixgbe_reset_pipeline_82599`, after writing `IXGBE_AUTOC` with `LMS[2]` toggled (`autoc_reg ^ (0x4 << IXGBE_AUTOC_LMS_SHIFT)`) and `IXGBE_AUTOC_AN_RESTART` set, restore untoggled `autoc_reg` to `IXGBE_AUTOC` and flush on all exit paths, including `IXGBE_ANLP1_AN_STATE_MASK` poll timeout. [F1229]
- In `ixgbe_init_mac_link_ops_82599`, do not set `mac->ops.setup_link` to `ixgbe_setup_mac_link_smartspeed` when `ixgbe_verify_lesm_fw_enabled_82599(hw)` is true, and set laser ops (`disable_tx_laser`, `enable_tx_laser`, `flap_tx_laser`) to `NULL` when `ixgbe_mng_enabled(hw)` is true. In `ixgbe_get_link_capabilities_82599`, when `hw->phy.multispeed_fiber` is true, set `*autoneg = false` for `ixgbe_media_type_fiber_qsfp` and `true` otherwise. [F1304, F1305]
- When `ixgbe_disable_pcie_primary` sets `IXGBE_FLAGS_DOUBLE_RESET_REQUIRED` in `hw->mac.flags`, `ixgbe_clear_tx_pending` must flush PCIe buffers and restore `IXGBE_HLREG0` and `IXGBE_GCR_EXT` before `ixgbe_reset_hw_82599` or `ixgbe_reset_hw_e610` performs the second MAC reset and clears the flag. [F1231]
- When disabling Rx on non-82598 MACs (`ixgbe_disable_rx_generic`, `ixgbe_disable_rx_e610`) while `IXGBE_RXCTRL_RXEN` is set, clear `IXGBE_PFDTXGSWC_VT_LBEN` in `IXGBE_PFDTXGSWC` and set `hw->mac.set_lben = true` so `ixgbe_enable_rx_generic` restores `VT_LBEN` and clears `set_lben`. In `ixgbe_enable_rx_dma_82599`, wrap `enable_rx()`/`disable_rx()` between `hw->mac.ops.disable_rx_buff(hw)` and `enable_rx_buff(hw)`. [F1220, F1230]
- `ixgbe_set_rar_generic` and `ixgbe_clear_rar_generic` must preserve the upper 16 VMDq bits of `IXGBE_RAH(index)`, flushing `IXGBE_RAL(index)` before setting `IXGBE_RAH_AV` when setting, and flushing `IXGBE_RAH(index)` with `IXGBE_RAH_AV` cleared before zeroing `IXGBE_RAL(index)` when clearing. In `ixgbe_set_vmdq_generic` and `ixgbe_set_vmdq_san_mac_generic`, shift pools `vmdq >= 32` as `BIT(vmdq - 32)` into `IXGBE_MPSAR_HI(rar)`. [F1223, F1270]
- When Tx flow control or PFC is disabled on an active TC `i` in `ixgbe_fc_enable_generic` or `ixgbe_dcb_config_pfc_82599`, set `IXGBE_FCRTL_82599(i)` to `0` and `IXGBE_FCRTH_82599(i)` to `IXGBE_READ_REG(hw, IXGBE_RXPBSIZE(i)) - 24576` (not `0`). [F1224]
- In `ixgbe_dcb_config_rx_arbiter_82599` and `ixgbe_dcb_config_tx_data_arbiter_82599`, set `IXGBE_RTRPCS_ARBDIS` in `IXGBE_RTRPCS` (or `IXGBE_RTTPCS_ARBDIS` in `IXGBE_RTTPCS`) before modifying UP2TC mappings and TC credit registers, and clear `ARBDIS` afterward. In `ixgbe_dcb_calculate_tc_credits` and `ixgbe_ieee_credits`, update `min_percent` only from non-zero TC bandwidth percentages so `min_percent >= 1` before dividing `min_credit / min_percent`. [F1225, F1268]
- `adapter->ixgbe_ieee_ets` and `adapter->ixgbe_ieee_pfc` are `NULL` until lazily allocated in `ixgbe_dcbnl_ieee_setets` and `ixgbe_dcbnl_ieee_setpfc`; readers must null-check them, and `ixgbe_dcbnl_setdcbx` must call `ixgbe_dcbnl_ieee_setets` before `ixgbe_dcbnl_ieee_setpfc` (which dereferences `ixgbe_ieee_ets->prio_tc`). When `ixgbe_dcbnl_ieee_setapp` or `ixgbe_dcbnl_ieee_delapp` modifies an `IEEE_8021QAZ_APP_SEL_ETHERTYPE` entry for protocol `0`, update `adapter->default_up` and call `ixgbe_set_vmvir` for each VF with `vfinfo->pf_qos` unset. [F1208, F1227]
- CEE DCB setters in `ixgbe_dcb_nl.c` stage changes in `adapter->temp_dcb_cfg` while getters read `adapter->dcb_cfg`; `ixgbe_dcbnl_set_all` commits `temp_dcb_cfg` via `ixgbe_copy_dcb_cfg`, updates `netdev_set_prio_tc_map` on PG changes and `ixgbe_set_rx_drop_en` on PFC changes, and resets `adapter->dcb_set_bitmap` to `0`. [F1226]
- In `ixgbe_reinit_fdir_tables_82599`, before rewriting `IXGBE_FDIRCTRL` with `IXGBE_FDIRCTRL_INIT_DONE` cleared, poll `ixgbe_fdir_check_cmd_complete`, zero `IXGBE_FDIRFREE`, pulse `IXGBE_FDIRCMD_CLEARHT` on/off in `IXGBE_FDIRCMD` with flushes, and zero `IXGBE_FDIRHASH`. In `union ixgbe_atr_input`, `input_mask->formatted.bkt_hash` (upper 16 bits of `dword_stream[10]`) must be `0` when passed to `ixgbe_atr_compute_perfect_hash_82599`. [F1234, F1248]
- In `ixgbe_write_eeprom_buffer_bit_bang`, the inner SPI burst loop increments outer index `i` (`while (++i < words)`) and must break when `page_size == 0` or `((offset + i) & (page_size - 1)) == (page_size - 1)` to avoid page wrap. In `ixgbe_detect_eeprom_page_size_generic`, set `hw->eeprom.word_page_size = IXGBE_EEPROM_PAGE_SIZE_MAX` for the probe call to `ixgbe_write_eeprom_buffer_bit_bang` and reset it to `0` before checking write status or reading back. [F1235, F1258]
- In `ixgbe_aci_send_cmd`, retries on `LIBIE_AQ_RC_EBUSY` are restricted to opcodes allowed by `ixgbe_should_retry_aci_send_cmd_execute`, restoring `*desc` from `desc_cpy` (and `buf` from `buf_cpy`) before sleeping and re-calling `ixgbe_aci_send_cmd_execute`, bounded by `IXGBE_ACI_SEND_MAX_EXECUTE` and `IXGBE_ACI_SEND_TIMEOUT_MS`. `ixgbe_get_link_status` queries E610 FW only when `hw->link.get_link_info` is `true`, and `ixgbe_aci_get_link_info` clears `get_link_info` to `false`; callers like `ixgbe_check_link_e610` must set `get_link_info = true` before each poll. [F1232, F1251]
- In `ixgbe_get_media_type_from_phy_type`, simultaneously non-zero `phy_type_low` and `phy_type_high` return `ixgbe_media_type_unknown` first, and `IXGBE_PHY_TYPE_LOW_1G_SGMII` with active/passive SFP+ copper `module_type` returns `ixgbe_media_type_da` before the `phy_type_low` switch. In `ixgbe_get_pfa_module_tlv`, start TLV scan at `pfa_ptr + 1`, advance `next_tlv` by `tlv_len + 2` words while `next_tlv < pfa_ptr + pfa_len`, and return `-EIO` if a matching `module_type` has `tlv_len == 0`. [F1253, F1255]

## Synchronization

- `ixgbe_acquire_eeprom` acquires `IXGBE_GSSR_EEP_SM` then `IXGBE_EEC_REQ` (rolling both back on `IXGBE_EEC_GNT` timeout); once it succeeds, call `ixgbe_release_eeprom` on all exit paths. `ixgbe_get_eeprom_semaphore` acquires `IXGBE_SWSM_SMBI` then `IXGBE_SWSM_SWESMBI` in `IXGBE_SWSM(hw)` and calls `ixgbe_release_eeprom_semaphore` on timeout; `ixgbe_acquire_swfw_sync` and `ixgbe_release_swfw_sync` must release it before returning or sleeping. [F1183, F1184]
- In `ixgbe_read_i2c_byte_82599` and `ixgbe_write_i2c_byte_82599`, when `hw->phy.qsfp_shared_i2c_bus` is true, setting `IXGBE_ESDP_SDP0` to request I2C bus ownership must be paired with clearing `IXGBE_ESDP_SDP0` and flushing `IXGBE_ESDP` on both transfer completion and SDP1 grant timeout. On 82599 with LESM enabled (`ixgbe_verify_lesm_fw_enabled_82599(hw)`), hold `IXGBE_GSSR_MAC_CSR_SM` before writing `IXGBE_AUTOC` or calling `ixgbe_reset_pipeline_82599`, and pair `prot_autoc_read` with `prot_autoc_write` passing `locked`. [F1185, F1316]
- Call `ixgbe_aci_send_cmd_execute` only while holding `hw->aci.lock`; callers of `ixgbe_aci_send_cmd` or `ixgbe_aci_get_event` must not hold `hw->aci.lock` (nor read `hw->aci.last_status` after unlock). All E610 ACI callers (`ixgbe_check_link_e610`, `ixgbe_disable_rx_e610`, `ixgbe_read_ee_aci_e610`, etc.) must run in sleepable process context. [F1189, F1314]
- On E610, low-level NVM helpers (`ixgbe_aci_read_nvm`, `ixgbe_read_flat_nvm`, `ixgbe_read_sr_word_aci`, `ixgbe_read_sr_buf_aci`, `ixgbe_aci_erase_nvm`, `ixgbe_aci_update_nvm`, `ixgbe_nvm_write_activate`) require the caller to hold NVM ownership via `ixgbe_acquire_nvm` and release it via `ixgbe_release_nvm`; `ixgbe_read_ee_aci_e610` and `ixgbe_read_ee_aci_buffer_e610` acquire it internally and must not be called while holding it. [F1190]
- `ixgbe_fdir_set_input_mask_82599`, `ixgbe_fdir_write_perfect_filter_82599`, and `ixgbe_fdir_erase_perfect_filter_82599` require `adapter->fdir_perfect_lock`. `ixgbe_reinit_fdir_tables_82599`, `ixgbe_init_fdir_signature_82599`, and `ixgbe_init_fdir_perfect_82599` (via `ixgbe_fdir_enable_82599`) sleep with `usleep_range` and must run in process context outside spinlocks. `ixgbe_fdir_add_signature_filter_82599` runs locklessly on Tx (`ixgbe_atr`), must not block, and must write `IXGBE_FDIRHASH` and `IXGBE_FDIRCMD` via `IXGBE_WRITE_REG64`. [F1198, F1310, F1311]
- `ixgbe_set_rar_generic`, `ixgbe_clear_rar_generic`, `ixgbe_clear_vmdq_generic`, and `ixgbe_update_mc_addr_list_generic` run under `netif_addr_lock_bh` (`ixgbe_set_rx_mode`) and must not sleep or allocate with `GFP_KERNEL`. `ixgbe_dcbnl_devreset` must acquire `__IXGBE_RESETTING` in `adapter->state` via `test_and_set_bit` polling before stopping the netdev and reinitializing interrupts, and clear it afterwards. MMIO write helpers (`ixgbe_write_reg`, `ixgbe_write_reg64`) must load `hw->hw_addr` once via `READ_ONCE` and check `ixgbe_removed(reg_addr)` before dereferencing. [F1199, F1200, F1312]

## Object Lifetimes

- `ixgbe_fwlog_init` passes `adapter->ixgbe_dbg_adapter` to `libie_fwlog_init`, so call `ixgbe_dbg_adapter_init` before `ixgbe_fwlog_init` on probe and `ixgbe_fwlog_deinit` before `ixgbe_dbg_adapter_exit` on removal. [F1308]

## API Contracts

- When `ixgbe_acquire_res` (or `ixgbe_acquire_nvm`) returns `-EALREADY` or any non-zero code, the caller does not hold the resource and must neither perform the protected work nor call `ixgbe_release_res` / `ixgbe_release_nvm`. [F1191]
- Null-check optional vtable ops (`hw->mac.ops.disable_tx_laser`, `enable_tx_laser`, `flap_tx_laser`, `setup_fc`, `init_led_link_act`, `init_uta_tables`, `fw_recovery_mode`, `hw->phy.ops.reset`, `set_phy_power`) and optional out-parameters (`checksum_val` in `ixgbe_validate_eeprom_checksum_*`, `pending` in `ixgbe_aci_get_event`, `cap_count` in `ixgbe_aci_list_caps`, `link` in `ixgbe_aci_get_link_info`, `node_part_number`/`node_handle` in `ixgbe_aci_get_netlist_node`). [F1207, F1209]
- In `ixgbe_reset_hw_82599`, call `hw->phy.ops.init(hw)` and (if `hw->phy.sfp_setup_needed`) `hw->mac.ops.setup_sfp(hw)` before PHY/MAC reset, aborting immediately on `-EOPNOTSUPP`. `ixgbe_get_san_mac_addr_generic` must fill `san_mac_addr` with `0xFF` when the SAN MAC pointer is `0`/`0xFFFF` or read fails, as callers test `is_valid_ether_addr(hw->mac.san_addr)`. [F1214, F1287]
- `ixgbe_read_sr_word_aci`, `ixgbe_read_sr_buf_aci`, `ixgbe_read_ee_aci_e610`, and `ixgbe_read_ee_aci_buffer_e610` take `offset`/`words` in 16-bit words, whereas `ixgbe_read_flat_nvm` and `ixgbe_aci_read_nvm` take `offset`/`length` in bytes (`ixgbe_read_flat_nvm` overwrites `*length` with bytes read). `ixgbe_read_flat_nvm` must validate `(offset + *length) <= hw->eeprom.word_size * 2u` when `read_shadow_ram` is true and clamp each `ixgbe_aci_read_nvm` call to `min(IXGBE_ACI_MAX_BUFFER_SIZE - (offset % IXGBE_ACI_MAX_BUFFER_SIZE), inlen - bytes_read)`. [F1217, F1239]
- In `ixgbe_aci_send_cmd_execute`, indirect transfers must reject `buf_size > IXGBE_ACI_MAX_BUFFER_SIZE`, set `LIBIE_AQ_FLAG_LB` when `((buf_size + 3) & ~0x3) > LIBIE_AQ_LG_BUF`, and copy trailing `buf_size % 4` bytes via `u32 buf_tail` and `memcpy` when accessing `IXGBE_PF_HIBA(i)`. `ixgbe_aci_list_caps` takes `buf_size` in bytes, while `*cap_count` receives the `le32_to_cpu(cmd->count)` element count for `ixgbe_parse_dev_caps` / `ixgbe_parse_func_caps`. [F1238, F1279]
- `ixgbe_hic_unlocked` and `ixgbe_host_interface_command` require buffer `length` in `1..IXGBE_HI_MAX_BLOCK_BYTE_LENGTH` and a multiple of 4 bytes; when `return_data` is true, `ixgbe_host_interface_command` must verify `length >= round_up(hdr->buf_len, 4) + sizeof(struct ixgbe_hic_hdr)` before reading reply dwords. `ixgbe_get_thermal_sensor_data_generic` and `ixgbe_init_thermal_sensor_thresh_generic` must return `-EOPNOTSUPP` when `IXGBE_READ_REG(hw, IXGBE_STATUS) & IXGBE_STATUS_LAN_ID_1` is non-zero (port 0 only) and clamp `ets_cfg & IXGBE_ETS_NUM_SENSORS_MASK` to `IXGBE_MAX_SENSORS`. [F1240, F1249, F1306]
- `ixgbe_dcb_calculate_tc_credits` and `ixgbe_dcb_unpack_*` require `direction` to be `DCB_TX_CONFIG` (`0`) or `DCB_RX_CONFIG` (`1`). In `ixgbe_dcb_nl.c`, `ixgbe_dcbnl_getcap` reports `DCB_CAP_ATTR_PG_TCS` and `DCB_CAP_ATTR_PFC_TCS` as a bitmask (`0x80`), whereas `ixgbe_dcbnl_getnumtcs`, `ixgbe_dcbnl_ieee_getets`, and `ixgbe_dcbnl_ieee_getpfc` report integer counts. Gate CEE ops on `adapter->dcbx_cap & DCB_CAP_DCBX_VER_CEE` and IEEE ops on `DCB_CAP_DCBX_VER_IEEE` (returning `-EINVAL`). [F1218, F1324, F1326]

## Error Handling

- `hw->eeprom.ops.calc_checksum` (`ixgbe_calc_eeprom_checksum_generic`) returns a 16-bit checksum in `int` or `-EIO`; check `status < 0` before casting to `u16`. `ixgbe_get_flash_bank_offset` returns `0` for an invalid module/bank; check `if (!start)` and return `-EINVAL`. `ixgbe_find_vlvf_slot` returns a slot index (`0 .. IXGBE_VLVF_ENTRIES - 1`) or `-ENOSPC`; when `vlvf_bypass` is true and it returns `< 0`, `ixgbe_set_vfta_generic` must jump to `vfta_update` rather than returning the error. [F1203, F1205, F1206]
- In `ixgbe_aci_send_cmd_execute`, a response `desc->opcode` mismatch with the sent opcode returns `-EIO` except for `ixgbe_aci_opc_get_fw_event` (`0x0014`), whereas in `ixgbe_aci_get_event`, `desc.opcode == cpu_to_le16(ixgbe_aci_opc_get_fw_event)` means no event was retrieved and returns `-ENOENT`. [F1250]

## External Contracts

- In `ixgbe_dcbnl_ops`, `ixgbe_dcbnl_set_state` and `ixgbe_dcbnl_setdcbx` return `u8` (`0` success, `1` failure), `ixgbe_dcbnl_set_all` returns `DCB_HW_CHG_RST` (`0`), `DCB_NO_HW_CHG` (`1`), or `DCB_HW_CHG` (`2`), while `ixgbe_dcbnl_getapp`, `ieee_*`, `getnumtcs`, and `setnumtcs` return negative errno on failure. In `ixgbe_dbg_*_ops_read`/`write`, return `0` when `*ppos != 0`, and `-ENOSPC` when write `count >= sizeof(buf)` (`256`) or read `count < strlen(buf)`. [F1204, F1236]

## Known Pitfalls

- Call `ixgbe_fill_dflt_direct_cmd_desc(&desc, opcode)` before writing any fields in `desc.params` or `libie_aq_raw(&desc)` (it zeroes `desc`). In `ixgbe_get_media_type_e610`, check `highest_bit = fls64(...)` is non-zero and shift with `BIT_ULL(highest_bit - 1)`. In `ixgbe_get_orom_srev`, verify `orom_size_word >= hdr_len` before computing `css_start = orom_size_word - hdr_len`. [F1211, F1245, F1265]
- In `ixgbe_dcbnl_ieee_setets`, convert max 0-based TC in `ets->prio_tc` to a 1-based count via `if (max_tc) max_tc++;` and check `max_tc <= adapter->dcb_cfg.num_tcs.pg_tcs` before `ixgbe_setup_tc`. In `ixgbe_dcbnl_ieee_delapp`, store `dcb_ieee_getapp_mask(dev, app)` in `unsigned long app_mask` before `find_first_bit(&app_mask, 8)`. In `ixgbe_dcb_get_tc_from_up`, return `0` when `cfg->num_tcs.pg_tcs == 0` before `for (tc--; tc; tc--)`. [F1243, F1244, F1282]
- In `ixgbe_fdir_set_input_mask_82599` and `ixgbe_fdir_write_perfect_filter_82599`, write IP address/mask registers and `flex_bytes` in big-endian (`IXGBE_WRITE_REG_BE32`, `IXGBE_STORE_AS_BE16`) and port/VLAN fields in CPU endianness. In `ixgbe_atr_compute_sig_hash_82599` and `ixgbe_atr_compute_perfect_hash_82599`, XOR `flow_vm_vlan ^ (flow_vm_vlan << 16)` into `lo_hash_dword` only after iteration 0 (`IXGBE_COMPUTE_*_HASH_ITERATION(0)`). In `ixgbe_set_rxpba_generic`, `PBA_STRATEGY_WEIGHTED` configures the first `num_pb / 2` buffers using `i` and falls through to `PBA_STRATEGY_EQUAL` without resetting `i`, dividing remaining `pbsize` by `(num_pb - i)`. [F1247, F1257, F1261]

## Other

- In `ixgbe_stop_mac_link_on_d3_82599`, set `IXGBE_AUTOC2_LINK_DISABLE_ON_D3_MASK` in `IXGBE_AUTOC2` only when `!ixgbe_mng_present(hw)`, `!hw->wol_enabled`, and `ee_ctrl_2 & IXGBE_EEPROM_CCD_BIT` all hold. [F1307]
