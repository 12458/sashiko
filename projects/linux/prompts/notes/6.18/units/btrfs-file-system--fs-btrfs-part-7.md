# BTRFS FILE SYSTEM — fs/btrfs (part 7)

Implements Btrfs subvolume quota groups (qgroups/squota reservation, tracing, accounting, and rescan in `qgroup.c`), zoned RAID stripe tree (`raid-stripe-tree.c`), RAID5/6 RMW, recovery, scrub, and stripe cache (`raid56.c`), extent ref verification (`ref-verify.c`), and file extent cloning/deduplication (`reflink.c`).

## Architecture & Data Flow

- In `btrfs_raid_bio`, `stripe_pages`, `bio_sectors`, `stripe_sectors`, `finish_pointers`, and `error_bitmap` are sized for `rbio->real_stripes` (`bioc->num_stripes - bioc->replace_nr_stripes`), while `bioc->stripes[rbio->real_stripes]` is the dev-replace target. `csum_buf`/`csum_bitmap` cover only data sectors (`nr_data * stripe_nsectors`), and `dbitmap`/`finish_pbitmap` are single `unsigned long` words bounded to `stripe_nsectors` (`<= BITS_PER_LONG`), never `nr_sectors`. [F931, F958, F959]
- `rbio->refs` counts separate refs for creator, `h->hash_list`, and `RBIO_CACHE_BIT` on `table->stripe_cache`; `__remove_rbio_from_cache()` drops the cache ref via `free_raid_bio()` and, if `bio_list` is empty and `hash_list` non-empty, unlinks `hash_list` and calls `refcount_dec(&rbio->refs)`. `merge_rbio()` must also add `victim->bio_list_bytes` to `dest->bio_list_bytes` and OR `victim->dbitmap` into `dest->dbitmap`. [F852, F915]
- `rbio->error_bitmap` is shared between read recovery and write submission, so `rmw_rbio()`, `rmw_assemble_write_bios()`, and `finish_parity_scrub()` must `bitmap_clear(rbio->error_bitmap, 0, rbio->nr_sectors)` before assembling write bios. [F917]
- In `btrfs_qgroup_account_extents()`, if `!record->old_roots` and `BTRFS_QGROUP_RUNTIME_FLAG_NO_ACCOUNTING` is clear, call `btrfs_find_all_roots()` on the commit root first. In `btrfs_qgroup_account_extent()`, advance `fs_info->qgroup_seq` by `max(nr_old_roots, nr_new_roots) + 1` after `qgroup_update_counters()` so lazy refcnt resets work. [F911, F940]
- `__qgroup_excl_accounting()` must adjust each ancestor's `rfer`/`excl` by `src->excl`, `rfer_cmpr`/`excl_cmpr` by `src->excl_cmpr`, and reservations via `qgroup_rsv_add_by_qgroup()` / `qgroup_rsv_release_by_qgroup()`. `btrfs_record_squota_delta()` must ignore extents with `delta->generation < fs_info->qgroup_enable_gen`. [F844, F957]
- `__btrfs_qgroup_free_meta()` and `btrfs_qgroup_convert_reserved_meta()` must clamp `@num_bytes` via `sub_root_meta_rsv(root, num_bytes, type)` before calling `btrfs_qgroup_free_refroot()` or `qgroup_convert_meta()`. [F847]
- Parent-child qgroup relations require strictly increasing levels (`btrfs_qgroup_level(src) < btrfs_qgroup_level(dst)` in `btrfs_add_qgroup_relation()`, and `> 0` for inherited parents in `btrfs_qgroup_check_inherit()`). [F927]
- In `adjust_slots_upwards()`, never unlock or free `path->nodes[level]` when `level == root_level`, as the post-loop check reads `path->nodes[root_level]` to stop `btrfs_qgroup_trace_subtree()`. [F942]
- In `btrfs_delete_raid_extent()`, check hole-punch (`found_start < start && found_end > end`) before (`found_start < start`) or (`found_end > end`), because `found_start < start` assumes deletion reaches `found_end`. [F944]
- In `btrfs_build_ref_tree()`, maintain `bytenr`, `num_bytes`, and `tree_block_level` across `walk_down_tree()` and `process_leaf()` calls, and in `process_leaf()` `BTRFS_EXTENT_ITEM_KEY` must update `*num_bytes` before falling through to `BTRFS_METADATA_ITEM_KEY`. [F950]
- In `btrfs_clone()`, set `BTRFS_I(inode)->last_reflink_trans = trans->transid` on every cloned extent, and also on `BTRFS_I(src)` when `extent_gen == trans->transid && disko > 0`. `clone_finish_inode_update()` must clamp `endoff` to `destoff + olen` before updating `i_size`. [F923, F936]
- In `btrfs_extent_same()`, increment `root_dst->dedupe_in_progress` under `root_dst->root_item_lock` after verifying `send_in_progress == 0`, and decrement it under `root_item_lock` on all exit paths. [F861]

## Synchronization

- In `btrfs_quota_enable()` and `btrfs_quota_disable()`, unlock `fs_info->qgroup_ioctl_lock` before starting/committing a transaction. In `btrfs_quota_enable()`, call `btrfs_release_path(path)` on `tree_root` before `add_qgroup_item()` on `quota_root`, and publish `quota_root` and `BTRFS_FS_QUOTA_ENABLED` (under `qgroup_lock`) only after `btrfs_commit_transaction()`. In `btrfs_quota_disable()`, after unlocking `qgroup_ioctl_lock` and clearing `BTRFS_FS_QUOTA_ENABLED`, call `btrfs_qgroup_wait_for_completion()` and `flush_reservations()` before starting the transaction, restoring `BTRFS_FS_QUOTA_ENABLED` on error. [F842, F864, F865, F866]
- In `btrfs_create_qgroup()`, `btrfs_remove_qgroup()`, `btrfs_limit_qgroup()`, `btrfs_add_qgroup_relation()`, and `__del_qgroup_relation()`, check `fs_info->quota_root` under `qgroup_ioctl_lock` without an unlocked `btrfs_qgroup_mode()` pre-check. Callers of `btrfs_run_qgroups()` must hold `qgroup_ioctl_lock` when `trans->transaction->state != TRANS_STATE_COMMIT_DOING`, whereas `btrfs_qgroup_inherit()` must not acquire `qgroup_ioctl_lock` during `TRANS_STATE_COMMIT_DOING`. [F862, F971]
- In `btrfs_remove_qgroup()` and `btrfs_free_qgroup_config()`, unlink the qgroup from `qgroup_tree` and relation lists under `fs_info->qgroup_lock`, and unlock `qgroup_lock` before `btrfs_sysfs_del_one_qgroup()` and `kfree()`. In `btrfs_qgroup_trace_subtree_after_cow()`, unlink the `btrfs_qgroup_swapped_block` and unlock `blocks->lock` before `read_tree_block()` and `qgroup_trace_subtree_swap()`. [F843, F873]
- After `btrfs_qgroup_trace_extent_nolock()` inserts a new record into `delayed_refs->dirty_extents` under `xa_lock`, call `btrfs_qgroup_trace_extent_post()` outside spinlock context, which must call `btrfs_find_all_roots(&ctx, true)` with `ctx.trans == NULL` and `skip_commit_root_sem == true`. [F869]
- In `btrfs_qgroup_rescan()`, commit the current transaction after `qgroup_rescan_init()` before `qgroup_rescan_zero_tracking()`, and recheck `btrfs_qgroup_full_accounting(fs_info)` under `qgroup_rescan_lock` before queuing `qgroup_rescan_work`. In `qgroup_rescan_leaf()`, update `qgroup_rescan_progress.objectid` and clone `path->nodes[0]` into `scratch_leaf` before releasing `path` and `qgroup_rescan_lock`. [F870, F912]
- `raid56.c` spinlock order is `table->cache_lock` -> `h->lock` -> `rbio->bio_list_lock`; never call `cache_rbio()` or `remove_rbio_from_cache()` while holding `h->lock` or `rbio->bio_list_lock`. [F874]
- In `submit_read_wait_bio_list()` and `submit_write_bios()`, set `rbio->stripes_pending = bio_list_size(bio_list)` (and finish `fill_data_csums(rbio)` for reads) before `submit_bio()`, and set `rbio->error_bitmap` bits in endio handlers via atomic `set_bit()`, not `bitmap_set()`. `fill_data_csums()` must skip csum lookups if `rbio->bioc->map_type & BTRFS_BLOCK_GROUP_METADATA` to avoid deadlocking on the full-stripe lock. [F877, F986]
- `add_block_entry()` (`ref-verify.c`) returns with `fs_info->ref_verify_lock` held on success, but does not lock it on `ERR_PTR(-ENOMEM)`, so callers must unlock `ref_verify_lock` only when `!IS_ERR(be)`. [F856]
- In `btrfs_remap_file_range()`, lock `btrfs_inode_lock(src_inode, BTRFS_ILOCK_MMAP)` if `dst_inode == src_inode`, else `lock_two_nondirectories()` then `btrfs_double_mmap_lock()`, unlocking in reverse order. In `btrfs_clone_files()`, call `btrfs_wait_ordered_range()` after `btrfs_cont_expand()` before `btrfs_clone()`, and again on `[destoff, destoff + len)` after `btrfs_clone()` before `truncate_inode_pages_range()`. [F860, F981]

## Object Lifetimes

- `add_qgroup_rb()` and `__add_relation_rb()` / `add_relation_rb()` unconditionally consume or `kfree()` `@prealloc`, and `btrfs_qgroup_account_extent()` unconditionally frees `@old_roots` and `@new_roots` via `ulist_free()` on all paths; callers must immediately set their pointers to `NULL`. [F838, F840]
- Use `btrfs_qgroup_release_data()` once data is written and `FILE_EXTENT` is inserted (clearing `EXTENT_QGROUP_RESERVED` while keeping `BTRFS_QGROUP_RSV_DATA` until commit), and `btrfs_qgroup_free_data()` on invalidation or error cleanup to also free `BTRFS_QGROUP_RSV_DATA`. [F846]
- When seeding `path->nodes[root_level]` with a caller-owned `extent_buffer` in `qgroup_trace_extent_swap()`, `qgroup_trace_subtree_swap()`, or `btrfs_qgroup_trace_subtree()`, call `refcount_inc(&eb->refs)` and set `path->locks[root_level] = 0`. [F848]
- `steal_rbio_page()` must `__free_page()` any existing `dest->stripe_pages[page_nr]`, move `src`'s page to `dest`, and null `src->stripe_pages[page_nr]`; `steal_rbio()` must call `index_stripe_sectors()` on both `dest` and `src`. In `rbio_orig_end_io()`, free/null `csum_buf` and `csum_bitmap` and clear `dbitmap` before `unlock_stripe(rbio)`, then drain `rbio->bio_list` a second time after `unlock_stripe(rbio)` before `free_raid_bio(rbio)`. [F851, F853]
- In `recover_vertical()`, save every `kmap_local_sector()` address in `unmap_array[]` and unmap in reverse order (`real_stripes - 1` down to 0) using `unmap_array[]`, not `pointers[]`. [F854]
- In `btrfs_insert_raid_extent()`, after all `btrfs_insert_one_raid_extent()` calls succeed, unlink every `btrfs_io_context` on `ordered_extent->bioc_list` and drop its ref via `btrfs_put_bioc(bioc)`. [F857]

## API Contracts

- `btrfs_qgroup_trace_extent_nolock()` takes ownership of `@record` only when returning 0; on `> 0` or `< 0`, the caller must call `xa_release(&delayed_refs->dirty_extents, index)` and `kfree(record)`. [F839]
- `can_delete_qgroup()` returns 0 when deletion is disallowed, `> 0` when allowed, and `< 0` on error; `btrfs_remove_qgroup()` must map 0 to `-EBUSY`. [F886]
- `btrfs_qgroup_reserve_meta()` and `__btrfs_qgroup_free_meta()` `BUG_ON` if `@num_bytes` is not aligned to `fs_info->nodesize` when quotas are enabled on an fstree root. Passing `num_bytes == (u64)-1` to `btrfs_qgroup_free_refroot()` is valid only for `BTRFS_QGROUP_RSV_META_PERTRANS`. [F888, F890]
- Never call `try_flush_qgroup()` with `current->journal_info != NULL`, and never call `btrfs_qgroup_reserve_data()` or `__btrfs_qgroup_reserve_meta(..., false)` with a dirty folio locked or an open transaction. [F972]
- Before calling `qgroup_trace_new_subtree_blocks()`, populate `dst_path->nodes[root_level]` and ensure `0 <= cur_level <= root_level < BTRFS_MAX_LEVEL - 1` (else `-EUCLEAN`). [F892]
- `lock_stripe_add(rbio)` consumes `@rbio` when returning 1 (merged/freed or queued on `plug_list`), leaving caller ownership only on 0. `alloc_rbio()` returns `ERR_PTR(-ENOMEM)` on failure, whereas `raid56_parity_alloc_scrub_rbio()` converts `IS_ERR(rbio)` to `NULL`. [F850, F895]
- `sector_in_rbio()` returns `NULL` when `bio_list_only` is true and `!bio_sectors[index].has_paddr`; `rbio_qstripe_sector()` returns `NULL` on RAID5. In `get_rbio_veritical_errors()`, `@faila` and `@failb` must both be `NULL` or both non-NULL (`ASSERT(faila && failb)`). [F896, F897]
- `btrfs_get_raid_extent_offset()` must clamp `*length` to `found_end - logical` when the range exceeds `found_end`, and for `BTRFS_BLOCK_GROUP_DUP` must match `stripe_index == i` in addition to `devid`. [F934]
- `clone_copy_inline_extent()` sets `*trans_out` to an open transaction on every 0 return, and ends any transaction it started via `btrfs_end_transaction()` on error without modifying `*trans_out`. `btrfs_clone_files(file, file_src, ...)` takes destination file first, unlike `btrfs_remap_file_range()`, `btrfs_extent_same()`, and `btrfs_clone()` which take source first. [F858, F904]

## Error Handling

- In `qgroup_reserve_data()`, if `qgroup_reserve()` fails after `btrfs_set_record_extent_bits()`, call `qgroup_unreserve_range()` to revert `EXTENT_QGROUP_RESERVED` bits, and free/null `*reserved_ret` only if allocated by this call. [F845]
- `btrfs_qgroup_cleanup_dropped_subvolume()` must clear both `-EBUSY` and `-ENOENT` from `btrfs_remove_qgroup()` to 0. [F994]
- If `rbio_add_io_sector()` fails while building `bio_list` in `recover_rbio()`, `rmw_read_wait_recover()`, `rmw_assemble_write_bios()`, `finish_parity_scrub()`, or `scrub_assemble_read_bios()`, release queued bios via `bio_list_put(&bio_list)`. [F855]
- On error in `btrfs_ref_tree_mod()` and `btrfs_build_ref_tree()`, call `btrfs_free_ref_cache(fs_info)` before `btrfs_clear_opt(fs_info->mount_opt, REF_VERIFY)`. [F900]
- `clone_finish_inode_update()` always ends `@trans` via `btrfs_end_transaction(trans)` on both success and error. In `btrfs_clone_files()`, store `btrfs_wait_ordered_range()` status in `wb_ret` (`ret = ret ? ret : wb_ret`) so it does not clobber a `btrfs_clone()` error. [F901, F903]

## External Contracts

- `btrfs_qgroup_check_inherit()` must reject unknown flags (`-EOPNOTSUPP`), non-zero `num_ref_copies`/`num_excl_copies`, size != `struct_size(inherit, qgroups, inherit->num_qgroups)` or outside `[sizeof(*inherit), PAGE_SIZE]`, and level-0 qgroup IDs (`-EINVAL`). [F989]
- In `btrfs_limit_qgroup()`, when a limit flag is set and its value is `(u64)-1` (`CLEAR_VALUE`), clear the flag in both `qgroup->lim_flags` and `limit->flags` and zero the field. `qgroup_reserve()` bypasses `qgroup_check_limits()` when `BTRFS_FS_QUOTA_OVERRIDE` is set and `capable(CAP_SYS_RESOURCE)`. [F990, F991]
- `btrfs_remap_file_range_prep()` must call `filemap_flush()` on source and `btrfs_wait_ordered_range()` on source and destination before `generic_remap_file_range_prep()`. In `btrfs_remap_file_range()`, if either `src_file` or `dst_file` has `file_sync_write()`, call `btrfs_sync_file()` on both ranges after unlocking. [F980, F983]

## Known Pitfalls

- Any list populated with `qgroup_iterator_add()` / `qgroup_iterator_nested_add()` must be emptied with `qgroup_iterator_clean()` / `qgroup_iterator_nested_clean()` under `fs_info->qgroup_lock`. Breadth-first loops over `btrfs_qgroup.iterator` (`__qgroup_excl_accounting()`, `qgroup_update_refcnt()`, `qgroup_reserve()`, `btrfs_record_squota_delta()`) must update and walk `groups` on the loop cursor, not the initial level-0 qgroup pointer. [F938, F939]
- `delayed_refs->dirty_extents` is indexed by `bytenr >> fs_info->sectorsize_bits`; `btrfs_qgroup_trace_extent_nolock()` must reject `bytenr >= MAX_LFS_FILESIZE` on 32-bit builds, and `btrfs_qgroup_account_extents()` must cast `index` to `u64` before `<< fs_info->sectorsize_bits`. [F928, F952]
- `btrfs_qgroup_add_swapped_blocks()` runs before the swap, so it must store `reloc_parent`/`reloc_slot` into `block->subvol_bytenr`/`subvol_generation` and `subvol_parent`/`subvol_slot` into `block->reloc_bytenr`/`reloc_generation`. [F913]
- Use `rbtree_iterate_from_safe()` before `ulist_del()` in `qgroup_unreserve_range()`, and advance `n = rb_next(n)` at the top of the `while (n)` loop in `btrfs_free_ref_tree_range()` before `continue` or `rb_erase()`. [F943, F951]
- In `finish_parity_scrub()`, copy `rbio->dbitmap` to `rbio->finish_pbitmap` before the parity check loop clears unchanged bits in `dbitmap`. In `rmw_assemble_write_bios()`, add `rbio->stripe_nsectors - 1` to `total_sector_nr` before `continue` when skipping a non-source replace stripe. [F919, F949]
- In `copy_inline_to_page()`, inline payload starts at `inline_data + btrfs_file_extent_calc_inline_size(0)` with length `size - btrfs_file_extent_calc_inline_size(0)`, and `folio_zero_range()` must zero `[datal, block_size)` when `datal < sectorsize`. In `btrfs_clone()`, set `prev_extent_end = key.offset + datal` before clipping `datal`, and if `key.offset + datal <= prev_extent_end`, increment `path->slots[0]` and `goto process_slot`. [F935, F946]
