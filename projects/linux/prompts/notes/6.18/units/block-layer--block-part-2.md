# BLOCK LAYER — block (part 2)

`blk-mq` core and request management: software/hardware queues, bitmap tags, elevator dispatch, DMA mapping, queue limits, QoS/WBT, zoned write plugging, runtime PM, timeouts, and sysfs.

## Architecture & Data Flow
- `blk_mq_init_allocated_queue()` sets `q->mq_ops` and `q->tag_set` before `blk_mq_realloc_hw_ctxs()`. `blk_mq_update_queue_map()` calls `blk_mq_clear_mq_map()` before `ops->map_queues()`, and `blk_mq_map_swqueue()` never frees `set->tags[0]`. `hctx->ctxs[]` and `hctx->ctx_map` are indexed in `[0, hctx->nr_ctx)` by `ctx->index_hw[hctx->type]` (not `ctx->cpu`); check `blk_mq_hw_queue_mapped(hctx)` before `hctx->tags`. [F242, F275, F291, F316]
- `blk_mq_alloc_tag_set()` caps `queue_depth` to `BLK_MQ_MAX_DEPTH`. In `blk_mq_tags`, `[0, nr_reserved_tags)` map to `breserved_tags` and `[nr_reserved_tags, nr_tags)` to `bitmap_tags` (offset `bitmap_tags` bits by `nr_reserved_tags` for `rqs[]`/`static_rqs[]`). Updating `tags->active_queues` under `tags->lock` requires `blk_mq_update_wake_batch()`. `blk_mq_alloc_rqs()` stores page order in `page->private`. When `blk_mq_is_shared_tags(set->flags)` is true, driver tags are in `set->shared_tags`, sched tags in `et->tags[0]`, and `blk_mq_alloc/free_map_and_rqs()` and `blk_mq_free_rqs()` take `BLK_MQ_NO_HCTX_IDX`. [F274, F293, F315, F358, F360]
- `queue_requests_store()` rejects `nr <= set->reserved_tags` (and `> MAX_SCHED_RQ` with elevator or `> set->queue_depth` without). Growing non-shared sched tags in `blk_mq_update_nr_requests()` updates every `hctx->sched_tags` and `q->elevator->et`, calling `ops.depth_updated(q)` after `q->nr_requests = nr`. `blk_set_queue_depth()` calls `rq_qos_queue_depth_changed(q)`. [F288, F307, F314]
- `RQF_SPECIAL_PAYLOAD` uses `rq->special_vec` instead of `rq->bio`; flush requests may have `rq->bio == NULL`. Partial completions in `blk_update_request()` update `__data_len`, `__sector`, `REQ_FAILFAST_MASK` (if `RQF_MIXED_MERGE`), and `nr_phys_segments` (unless `RQF_SPECIAL_PAYLOAD`). `blk_rq_prep_clone()` copies `nr_phys_segments` and `nr_integrity_segments`. `__blk_mq_requeue_request()` on a started request sets `rq->state = MQ_RQ_IDLE` and clears `RQF_TIMED_OUT`. `blk_mq_extract_queue_requests()` updates `rqs->tail = last`. [F277, F294, F295, F296, F333]
- `rq_qos_add()` sets `QUEUE_FLAG_QOS_ENABLED`, and `rq_qos_del()` (when `q->rq_qos` is NULL) and `rq_qos_exit()` clear it; `__rq_qos_*()` callers must check both `QUEUE_FLAG_QOS_ENABLED` and `q->rq_qos != NULL`. Use `wbt_rq_qos(q)` before `RQWB()`. `rwb->sync_cookie` is never dereferenced and is cleared with `rwb->sync_issue = 0` in `wbt_done()`/`wbt_requeue()`. `wbt_enable/disable_default()` under `disk->rqos_state_mutex` preserve `WBT_STATE_ON/OFF_MANUAL`. `QUEUE_FLAG_STATS` is updated under `q->stats->lock` and cleared only when `callbacks` is empty and `!accounting`. `RQF_PM` skips `pm_runtime_mark_last_busy()`. [F220, F273, F308, F309, F310, F365, F387]
- `blk_validate_limits()` recomputes derived limits/flags and clears `BLK_FEAT_FUA` if `!BLK_FEAT_WRITE_CACHE`; `queue_limits_commit_update()` rejects active `q->crypto_profile` with `integrity.tag_size`. `blk_validate_atomic_write_limits()` zeroes all derived `atomic_write_*` limits on invalid/unset limits (including `atomic_write_hw_max_sectors > chunk_sectors`). `blk_apply_bdi_limits()` never lowers `bdi->ra_pages`. `queue_limit_discard_alignment()` and `blk_stack_limits()` check for `0` discard limits before dividing. [F303, F305, F306, F353, F383]
- Zoned disks: `blkdev_zone_mgmt()` and `blkdev_truncate_zone_range()` check `sector + nr_sectors <= sector` and `> capacity` (unaligned `nr_sectors` allowed only at `capacity`). `disk_zone_is_full()` uses `last_zone_capacity` for the last zone and `zone_capacity` otherwise. `blk_revalidate_disk_zones()` checks `chunk_sectors` is non-zero power of two before ceiling shift. `disk_update_zone_resources()` sets `disk->nr_zones` before `disk_set_conv_zones_bitmap()`. `blk_zone_issue_zeroout()` calls `disk_zone_sync_wp_offset()` after `-EOPNOTSUPP`. Emulated zone append sets/clears `BIO_EMULATES_ZONE_APPEND`, and BIO errors call `disk_zone_wplug_abort()` and set `BLK_ZONE_WPLUG_NEED_WP_UPDATE` under `zwplug->lock`. [F299, F300, F302, F319, F321, F354, F370]

## Synchronization
- Freeze (`blk_mq_freeze_queue()`) must precede quiesce (`blk_mq_quiesce_queue()`). Lock order: `set->update_nr_hwq_lock` -> `set->tag_list_lock` / `blk_mq_freeze_queue(q)` -> `q->elevator_lock` (write-locking `update_nr_hwq_lock` allows reading `q->elevator` without `elevator_lock`). `__blk_mq_update_nr_hw_queues()` calls `blk_mq_elv_switch_none()` before freezing and keeps `q` frozen for `blk_mq_elv_switch_back()`. `queue_requests_store()` calls `blk_mq_alloc_sched_tags()` before freezing. [F256, F257, F390, F398]
- Dispatch runs inside `[__]blk_mq_run_dispatch_ops()` (`srcu_read_lock` if `BLK_MQ_F_BLOCKING`, else `rcu_read_lock`). If lockless `blk_mq_hw_queue_need_run()` is `false` in `blk_mq_run_hw_queue()`, recheck under `q->queue_lock`. `blk_mq_hctx_stopped()` needs `smp_mb()` before retesting `BLK_MQ_S_STOPPED` (pairing with `blk_mq_start_stopped_hw_queue()`). `blk_mq_dispatch_rq_list()` needs `smp_mb()` after splicing to `hctx->dispatch` before `blk_mq_sched_needs_restart()` (pairing with `__blk_mq_sched_restart()`). If `blk_mq_get_dispatch_budget()` succeeds but `!rq` is dequeued, put budget and call `blk_mq_delay_run_hw_queues(q, BLK_MQ_BUDGET_DELAY)` if nothing dispatched. [F250, F251, F263, F264, F340]
- `blk_mq_mark_tag_wait()` locks `wq->lock` before `hctx->dispatch_wait_lock` with `smp_mb()` between `__add_wait_queue()` and `blk_mq_get_driver_tag()`. After `io_schedule()` in `blk_mq_get_tag()`, reload `ctx`/`hctx`/`tags`/`bt` (waking `bt_prev` if changed), and at `found_tag:`, put tag if `BLK_MQ_S_INACTIVE` is set. [F258, F260]
- `blk_mq_queue_tag_busy_iter()` requires `percpu_ref_tryget(&q->q_usage_counter)` and `srcu_read_lock(&set->tags_srcu)`. `blk_mq_find_and_get_req()` checks `rq != NULL`, `rq->tag == bitnr`, and `req_ref_inc_not_zero(rq)`; `bt_iter()` rechecks `rq->q == q && (!hctx || rq->mq_hctx == hctx)`. `blk_mq_free_rqs()` and `blk_mq_exit_hctx()` clear stale `drv_tags->rqs[]` via `blk_mq_clear_[flush_]rq_mapping()`. `blk_mq_timeout_work()` uses `percpu_ref_tryget(&q->q_usage_counter)` (never `blk_queue_enter()`), calls `blk_mq_wait_quiesce_done()`, and resets `expired.next = 0` before `blk_mq_handle_expired()`. `blk_mq_remove_hw_queues_cpuhp()` splices `q->unused_hctx_list` under `q->unused_hctx_lock` and drops it before locking `blk_mq_cpuhp_lock`. `blk_mq_complete_send_ipi()` requires `!force_irqthreads()` and `cpu_online()`; `blk_mq_raise_softirq()` requires `preempt_disable()`. [F253, F254, F259, F262, F338, F393, F397]
- `queue_limits_start_update()` locks `q->limits_lock`, and `queue_limits_commit_update[_frozen]()` always unlocks it (requiring live queues frozen/idle); call `queue_limits_cancel_update()` only when aborting before commit. `queue_ra_store()` also holds `q->limits_lock` and freezes `q`. [F225, F405]
- `rq_qos_add/del()` require `q->rq_qos_mutex` and freeze `q` around mutating `q->rq_qos`/`QUEUE_FLAG_QOS_ENABLED`, registering debugfs outside freeze under `q->debugfs_mutex`. In `rq_qos_wait()`, if `first_waiter` gets a token via `acquire_inflight_cb()`, call `finish_wait()` then `cleanup_cb()` if `data.got_token` is set. `blk_throtl_activated()` checks both `q->td != NULL` and `blkcg_policy_enabled()`. `blk_stat_add()` uses `rcu_read_lock()` + `get_cpu()`, and `blk_stat_remove_callback()` unlinks under `q->stats->lock` + `timer_delete_sync()` before `call_rcu()`. In `blk_zone_wplug_bio_work()`, if `blk_zone_wplug_prepare_bio()` fails, unlock `zwplug->lock` before `blk_zone_wplug_bio_io_error()` and `goto again`. `BLKRESETZONE` locks `inode_lock` then `filemap_invalidate_lock`. [F221, F241, F255, F342, F403, F404, F422]

## Object Lifetimes
- `blk_mq_sysfs_init()` gets `q->mq_kobj` per CPU and `blk_mq_ctx_sysfs_release()` puts it so `blk_mq_sysfs_release()` frees `ctxs` last. `blk_mq_unregister_hctx()` calls `kobject_del()` only if `state_in_sysfs`. `blk_register_queue()` sets `QUEUE_FLAG_REGISTERED` before `wbt_enable_default()`, and sets `QUEUE_FLAG_INIT_DONE` + `percpu_ref_switch_to_percpu()` last. `blk_unregister_queue()` clears `QUEUE_FLAG_REGISTERED` under `q->sysfs_lock` and removes child sysfs before `kobject_del(&disk->queue_kobj)` and `elevator_set_none(q)`. `blk_mq_destroy_queue()` requires `!blk_queue_registered(q)` and runs `blk_sync_queue()` + `blk_mq_cancel_work_sync()` before `blk_mq_exit_queue()`, leaving `blk_put_queue()` to caller. [F217, F218, F371, F372, F373, F376]
- In `blk_mq_exit_queue()`, `blk_mq_exit_hw_queues()` precedes `blk_mq_del_queue_tag_set()`. `blk_mq_exit_hctx()` calls `exit_request` on `flush_rq` before `exit_hctx` and freeing `hctx->fq`, moving `hctx` to `q->unused_hctx_list` (reusable only when `blk_mq_hctx_is_reusable()`). `blk_mq_free_rqs()` calls `exit_request`, clears `static_rqs[i]`, and runs `blk_mq_clear_rq_mapping()` before `call_srcu(&set->tags_srcu, ...)`; `blk_mq_free_tag_set()` calls `srcu_barrier(&set->tags_srcu)` before `cleanup_srcu_struct()`. [F227, F228, F246, F377]
- `blk_mq_get_new_requests()` calls `rq_qos_cleanup()` if `__blk_mq_alloc_requests()` fails after `rq_qos_throttle()`. `blk_mq_use_cached_rq()` pops `rq` from `plug->cached_rqs` before `rq_qos_throttle()`, and `blk_mq_flush_plug_list()` zeroes `plug->rq_count` before dispatching. [F231, F261]
- `disk_zone_wplug_add_bio()` takes an extra `q_usage_counter` ref consumed by new request alloc or dropped via `blk_queue_exit(q)` on merge, abort, cached-rq reuse, or bio-based submit; in `blk_mq_submit_bio()`, cached `rq != NULL` skips `bio_queue_enter()` and `queue_exit`'s `blk_queue_exit(q)`. `disk_get_and_lock_zone_wplug()` sets `ref = 2` on alloc and checks `BLK_ZONE_WPLUG_UNHASHED` under `zwplug->lock` on lookup. `disk_free_zone_resources()` destroys `zone_wplugs_wq`, unhashes plugs, and runs `rcu_barrier()` before `mempool_destroy()`. [F235, F237, F301, F415]
- `blk_complete/update_request()` release crypto keyslots and read `bio->bi_next` before `bio_endio(bio)`. Cloned requests (`blk_rq_prep_clone()`) must complete before `@rq_src`. `rq_qos_wake_function()` calls `list_del_init_careful(&curr->entry)` last after `data->got_token = true` and `default_wake_function()`. `blk_end_sync_rq()` writes `wait->ret = ret` before `complete(&wait->done)`. Unqueued dispatch budgets must be released via `blk_mq_put_dispatch_budget()` / `blk_mq_release_budgets()`. `blk_hctx_poll()` restores `TASK_RUNNING` on all exits. `blk_pre_runtime_suspend()` calls `blk_set_pm_only(q)` and switches `q_usage_counter` to atomic mode before checking `percpu_ref_is_zero()`, calling `blk_clear_pm_only(q)` on `-EBUSY` or in `blk_post_runtime_suspend()` error / `blk_post_runtime_resume()`. [F232, F234, F239, F240, F334, F366, F367, F385, F418]

## API Contracts
- `__blk_mq_alloc_disk()`, `blk_mq_alloc_queue()`, `blk_mq_alloc_request()`, and `blk_mq_alloc_request_hctx()` (requires `BLK_MQ_REQ_NOWAIT | BLK_MQ_REQ_RESERVED`) return `ERR_PTR()`, whereas `blk_mq_alloc_disk_for_queue()`, `__blk_mq_alloc_requests()`, `blk_mq_alloc_cached_request()`, and `blk_mq_get_new_requests()` return `NULL`. `blk_mq_get_tag()` returns `BLK_MQ_NO_TAG` (`-1U`) on failure; `blk_mq_get_tags()` returns `0`. [F267, F268, F269, F285]
- `blk_mq_alloc_tag_set()` requires `ops->queue_rq`, matching `get/put_budget`, and `ops->map_queues` when `nr_maps > 1`. CPU hotplug checks use `blk_mq_map_queue_type()` instead of `hctx->cpumask`. `blk_mq_init_sched()` leaves freeing `et` to the caller on error. Passthrough requests bypass `q->elevator`, `rq_qos_done()`, and `RQF_STATS`, and `blk_mq_insert_request()` routes passthrough and `REQ_OP_FLUSH` to `blk_mq_request_bypass_insert()` before checking `q->elevator`. `blk_mq_run_hw_queue(hctx, false)` is forbidden in `in_interrupt()` or atomic context when `BLK_MQ_F_BLOCKING` is set. Dispatch loops call `blk_mq_commit_rqs()` on leftover requests, `ret != BLK_STS_OK`, or `hctx` switch. `rq->end_io` frees `rq` only if it returns `RQ_END_IO_FREE`. [F222, F233, F327, F331, F392, F407, F410, F427]
- `blk_rq_dma_map_iter_*()` return `false` on both completion and error (check `iter->status != BLK_STS_OK`); IOVA coalescing requires `blk_can_dma_map_iova()`, and `PCI_P2PDMA_MAP_BUS_ADDR` uses `blk_dma_map_bus()`. `__blk_rq_map_sg()` and `blk_rq_map_integrity_sg()` require `blk_rq_nr_phys_segments(rq)` / `rq->nr_integrity_segments` entries and `*last_sg = NULL` on start. [F266, F284, F318, F408]
- `blk_set_default_limits()` sets user discard/wzeroes limits to `UINT_MAX`; `blk_set_stacking_limits()` sets `atomic_write_hw_max = UINT_MAX`. `blk_validate_limits()` rejects `< PAGE_SECTORS` `max_hw_sectors`, `< BLK_MIN_SEGMENT_SIZE` segment limits, `dma_alignment > PAGE_SIZE`, or zoned limits without `BLK_FEAT_ZONED`/`CONFIG_BLK_DEV_ZONED`. `atomic_write_hw_*` and `atomic_write_unit_*` are in bytes; `atomic_write_*_sectors` are in sectors. `blk_stack_limits()` returns `-1` (still updating `t`) on misalignment; `bdev_alignment_offset()` returns signed `-1`. `blkdev_report_zones()` returns `0` when no zones are reported. `REQ_NOWAIT` bios in `blk_zone_wplug_handle_write()` use `GFP_NOWAIT` and queue via `disk_zone_wplug_add_bio()`. In `queue_sysfs_entry`, `.store` returns byte count while `.store_limit` returns `0`. `cb->bucket_fn(rq)` returns `< 0` or `< cb->buckets`. [F270, F271, F272, F283, F287, F324, F382, F402, F412]

## Error Handling
- `blk_register/unregister_queue()` pair `kobject_add/del(&disk->queue_kobj)` without `kobject_init/put()`, rolling back `blk_mq_sysfs_unregister(disk)` on error. `blk_mq_init_tags()` inits `tags->page_list`, `blk_mq_alloc_rqs()` clears `static_rqs[i] = NULL` on `blk_mq_init_request()` failure, `blk_mq_alloc_sched_tags_batch()` frees `et` before reverse-unwinding on `xa_insert()` failure, and `blk_mq_init_allocated_queue()` / `blk_mq_init_sched()` reset `q->mq_ops` and `q->elevator` (`blk_mq_sched_tags_teardown()`) to `NULL` on error. `blk_mq_submit_bio()` calls `blk_mq_bio_issue_init()` after splitting/integrity prep and before merge/alloc. `blk_update_request()` skips error logging/tracing if passthrough, `RQF_QUIET`, or `GD_DEAD`. `blk_insert_cloned_request()` returns `BLK_STS_NOTSUPP` silently if `max_sectors == 0`. [F219, F278, F279, F282, F337, F425, F426]

## External Contracts
- `blk_validate_limits()` forces `lim->discard_granularity = 0` when `lim->max_discard_sectors == 0`. `blkdev_report_zones_ioctl()` requires `rep.nr_zones != 0`, copies to `rep.zones`, and sets `rep.nr_zones = ret` and `rep.flags = BLK_ZONE_REP_CAPACITY`. [F312, F322]

## Known Pitfalls
- `blk_mq_rq_ctx_init()` does not `memset()` `rq`; init new `struct request` fields there as well as `blk_rq_init()`. `blk_mq_finish_request()` clears `RQF_USE_SCHED` after `ops.finish_request(rq)`. `blk_mq_get_hctx_type()` tests `REQ_POLLED` before `REQ_OP_READ`. `blk_account_io_done()` tests `(req->rq_flags & (RQF_IO_STAT | RQF_FLUSH_SEQ)) == RQF_IO_STAT`. `wbt_should_throttle()` tests `(bio->bi_opf & (REQ_SYNC | REQ_IDLE)) == (REQ_SYNC | REQ_IDLE)`. In `blk_mq_dispatch_rq_list()`, only `BLK_STS_RESOURCE` sets `needs_resource = true` before falling through to `BLK_STS_DEV_RESOURCE`. `blk_mq_delay_run_hw_queues()` skips `hctx` if `delayed_work_pending(&hctx->run_work)`. [F297, F328, F329, F330, F332, F341, F362]
- Avoid overflow/underflow/div-by-zero: widen `io_opt`/`max_sectors` to 64-bit in `blk_apply_bdi_limits()` and `QUEUE_SYSFS_LIMIT_SHOW_SECTORS_TO_BYTES`; use `check_shl_overflow()` in `blk_stack_atomic_writes_chunk_sectors()`; test `seg_boundary_mask > max_segment_size - 1` in `blk_validate_limits()`; check `nr_samples` wrap in `blk_rq_stat_sum()`; clamp `min(31, rqd->scale_step)` in `rq_depth_calc_max_depth()`; scale window in `rwb_arm_timer()` only when `scale_step > 0`; use ceiling division in `calc_wb_limits()`; check `if (!users) return true;` in `hctx_may_queue()`; check `now >= rq->io_start_time_ns` in `blk_stat_add()`; and check `time_before(expiry, q->timeout.expires)` in `blk_add_timer()`. [F344, F345, F346, F347, F349, F350, F351, F352, F355, F356, F357]
