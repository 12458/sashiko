# NETWORKING DRIVERS — drivers/net/ethernet/marvell

This unit contains the Marvell Octeon PCIe Endpoint PF (`octeon_ep`) and VF (`octeon_ep_vf`) Ethernet drivers for CN9K and CN10K (CNXK) SoCs, using Instruction Queues (IQ/TX), Output Queues (OQ/RX), PF-to-firmware control mailboxes, and PF-to-VF mailboxes.

## Architecture & Data Flow
- On PF, `oct->iq[]` and `oct->oq[]` use 0-based `q_no`, but per-queue SDP CSR accesses must add `CFG_GET_PORTS_PF_SRN(oct->conf)` (`conf->pf_ring_cfg.srn`) to `q_no`. In `octep_request_irqs()` and `octep_free_irqs()`, `oct->msix_entries[0 .. CFG_GET_NON_IOQ_MSIX(oct->conf) - 1]` are for non-IOQ interrupts (`non_ioq_msix_names` must have `>= non_ioq_msix` unique-prefix entries); I/O queue `j` (`oct->ioq_vector[j]`) pairs with `oct->msix_entries[j + CFG_GET_NON_IOQ_MSIX(oct->conf)]`. [F229, F230, F275]
- On PF, VF `vf`'s mailbox in `oct->mbox[]`, `SDP_MBOX_PF_VF_DATA` / `VF_PF_DATA` CSRs, and `SDP_EPF_MBOX_RINT` bit use index `vf_mbox_queue = vf * rings_per_vf`, whereas `oct->vf_info[vf]` uses `vf`. In `octep_poll_pfvf_mailbox()`, check `vf_mbox_queue < 64`: test `0x1UL << vf_mbox_queue` on `CN93_SDP_EPF_MBOX_RINT(0)` when `< 64`, and `0x1UL << (vf_mbox_queue - 64)` on `RINT(1)` when `>= 64`. [F259, F293]
- In `__octep_oq_process_rx()` and `__octep_vf_oq_process_rx()`, only the head descriptor has `octep_oq_resp_hw` and—when `fw_info.rx_ol_flags` is non-zero—`octep_oq_resp_hw_ext` / `octep_vf_oq_resp_hw_ext` (subtracting `OCTEP_*OQ_RESP_HW_EXT_SIZE` from `max_single_buffer_size` and `buff_info->len` and adding it to `data_offset`); subsequent fragments start at offset 0 up to `oq->buffer_size`. Both functions must return whole packet count (`pkt`) for `oq->pkts_pending` and NAPI budget, while adding total descriptors consumed (`desc_used`, including fragments) to `oq->refill_count`. [F199, F234, F235]
- In `octep_setup_iq()` and `octep_vf_setup_iq()`, `octep_*iq_reset_indices()` must zero `iq->pkt_in_done` and `setup_iq_regs` must write `readl(iq->inst_cnt_reg)` back to `iq->inst_cnt_reg`. In `octep_enable_ioq_irq()` and `octep_vf_enable_ioq_irq()`, writing `iq->pkts_processed` to `iq->inst_cnt_reg` must subtract `iq->pkts_processed` from `iq->pkt_in_done` (and zero `iq->pkts_processed`), and writing `oq->last_pkt_count - pkts_pend` to `oq->pkts_sent_reg` must set `oq->last_pkt_count = pkts_pend`. [F211, F221]
- `iq->max_count` (`CFG_GET_IQ_NUM_DESC(oct->conf)`) must be a power of 2 (`ring_size_mask = max_count - 1`). `OCTEP_*SGLIST_ENTRIES_PER_PKT` must round `(MAX_SKB_FRAGS + 1)` up via `((MAX_SKB_FRAGS + 1 + 3) / 4)`. In `octep_tx_desc_hw` / `octep_vf_tx_desc_hw`, convert `hw_desc->txm64[0]` with `cpu_to_be64()` after setting `hw_desc->txm`, and set `hw_desc->ih.tlen = skb->len + hw_desc->ih.fsz`. [F232, F236, F261]
- In `octep_set_mac`, `octep_change_mtu`, `octep_set_features`, `octep_set_link_ksettings`, and VF counterparts, update local shadow fields (`oct->mac_addr`, `oct->link_info`, `netdev->mtu`, `netdev->features`) only after the firmware/PF mailbox request succeeds. [F213]
- Keep `oct->vf_info[vf_id].mac_addr` in sync on VF MAC get/set (`octep_pfvf_get`/`set_mac_addr`, `octep_set_vf_mac`) and zero `oct->vf_info[vf_id]` in `octep_pfvf_dev_remove()`. `octep_sriov_enable()`/`disable()` must keep `CFG_GET_ACTIVE_VFS(oct->conf)` synchronized with enabled VFs, resetting to `0` on `pci_enable_sriov()` failure or disable. [F210, F215]
- In `octep_vf_mbox_bulk_read()` and `octep_pfvf_pf_get_data()`, reset the multi-fragment cursor and buffer (`mbox_data.data_index` and `recv_data` on VF; `config_data_index` and `config_data` on PF) to zero at the start of a non-fragment request and on VF completion or error. [F222]

## Synchronization
- `octep_get_stats64()` and `octep_vf_get_stats64()` run under RCU (`dev_get_stats()`) and must only read in-memory counters (`stats_iq`, `stats_oq`), never sleeping mailbox helpers (`octep_ctrl_net_get_if_stats()`, `octep_vf_get_if_stats()`). [F295, F296]
- `octep_tx_timeout()` and `octep_vf_tx_timeout()` run in atomic context and must defer reset (`octep_stop()`/`open()` under `rtnl_lock()`) to `oct->tx_timeout_task`. `octep_vf_tx_timeout()` must take `netdev_hold(netdev, NULL, GFP_ATOMIC)` and call `netdev_put()` if `schedule_work()` fails or after `rtnl_unlock()` in `octep_vf_tx_timeout_task()`. [F297, F298]
- `cancel_work_sync(&oct->tx_timeout_task)` and `cancel_delayed_work_sync(&oct->hb_task)` in teardown (`octep_remove()`, `octep_device_cleanup()`, `octep_vf_remove()`) must run outside `rtnl_lock()` (never inside `octep_stop()` or `octep_vf_stop()`) because their handlers acquire `rtnl_lock()`. [F300]
- Schedule PF-VF mailbox work (`oct->mbox[vf_mbox_queue]->wk.work`, `octep_pfvf_mbox_work`) on `system_wq` via `schedule_work()`, never on single-threaded `octep_wq`, because `octep_pfvf_mbox_work()` blocks in `octep_send_mbox_req()` waiting for `oct->ctrl_mbox_task` on `octep_wq`. [F299]
- `octep_poll_pfvf_mailbox*()` and `octep_poll_oei_*()` run from hardirq and `octep_intr_poll_task`; they must not sleep or lock mutexes (`mbox->lock`, `f2hq_lock`) and must defer work via `schedule_work()` and `queue_work(octep_wq, &oct->ctrl_mbox_task)`. [F301]
- `octep_ctrl_mbox_send()` must hold `mbox->h2fq_lock` and `octep_ctrl_mbox_recv()` must hold `mbox->f2hq_lock` across index reads, data copy, and index updates, unlocking on early `-EAGAIN` returns. Accessing `struct octep_mbox` state (`pf_vf_data_reg`, `vf_pf_data_reg`, `config_data*`, `message_len`) requires `mutex_lock(&mbox->lock)`, which nests outside `ctrl_mbox.h2fq_lock`. [F181, F303]
- In `octep_ctrl_mbox_init()`, write `OCTEP_CTRL_MBOX_STATUS_INIT` to `OCTEP_CTRL_MBOX_INFO_HOST_STATUS(mbox->barmem)` before setting queue pointers and `mbox->version`, and issue `wmb()` before writing `OCTEP_CTRL_MBOX_STATUS_READY`. In `octep_ctrl_mbox_uninit()`, clear `HOST_VERSION`, write `OCTEP_CTRL_MBOX_STATUS_INVALID` to `HOST_STATUS`, and issue `wmb()` before destroying `h2fq_lock` and `f2hq_lock`. [F183, F294]
- In `octep_device_setup()`, `octep_ctrl_net_init()` and `INIT_WORK(&oct->ctrl_mbox_task, ...)` must finish before queueing `oct->intr_poll_task`. `octep_open()` must set `poll_non_ioq_intr = false` before `enable_interrupts()`, and `octep_stop()` must set `poll_non_ioq_intr = true` and queue `intr_poll_task` after `disable_interrupts()` and `octep_clean_irqs()`. In `octep_open()` and `octep_vf_open()`, call `octep_*napi_add()` and `napi_enable()` before `enable_interrupts()` and `octep_*oq_dbell_init()`. [F184, F185, F279]
- `octep_iq_full_check()` must issue `smp_mb()` after `netif_stop_subqueue()` and recheck `IQ_INSTR_SPACE(iq) > OCTEP_WAKE_QUEUE_THRESHOLD` (`netif_start_subqueue()` if true). Before writing doorbell or interrupt-resend MMIO registers (`doorbell_reg`, `pkts_credit_reg`, `pkts_sent_reg`, `inst_cnt_reg`), issue a write barrier (`wmb()` on PF, `smp_wmb()` on VF). [F305, F307]

## Object Lifetimes
- In `octep_open()` and `octep_vf_open()`, `octep_*setup_iqs()` and `setup_oqs()` must succeed before `octep_*setup_irqs()` reads `oct->num_oqs`, `oct->iq[i]`, and `oct->oq[i]`. In `open`/`stop` (PF and VF), `octep_*clean_irqs()` must run before `octep_*free_oqs()` (since `free_ioq_vectors()` loops to `oct->num_oqs`, which `free_oq()` decrements), and `octep_*clean_iqs()` must run before `octep_*free_iqs()` to unmap/free pending SKBs. [F172, F173, F175]
- `octep_*free_oqs()`, `octep_*oq_free_ring_buffers()`, `octep_free_ioq_vectors()`, and `octep_delete_pfvf_mbox()` iterate the full range and skip only `NULL` slots, so teardown/rollback paths must set freed pointers to `NULL` (including `oq->buff_info[read_idx].page = NULL` when handing an RX page to an SKB in `octep_oq_next_pkt()` or `__octep_vf_oq_process_rx()`). [F174, F207]
- In `octep_start_xmit()` and `octep_vf_start_xmit()`, advance `iq->host_write_index` and call `__netdev_tx_sent_queue()` / `netdev_tx_sent_queue()` only after all DMA mappings succeed; on error, unmap prior segments, call `dev_kfree_skb_any(skb)`, and return `NETDEV_TX_OK`. Complete BQL bytes in `octep_*iq_process_completions()` or reset via `netdev_tx_reset_queue()` in `octep_*iq_free_pending()`. [F176, F312]
- In `octep_remove()`, `unregister_netdev()` and `cancel_work_sync(&oct->tx_timeout_task)` must precede `octep_device_cleanup()` (which sets `poll_non_ioq_intr = false` and cancels `intr_poll_task` and `ctrl_mbox_task`), which must precede `octep_delete_pfvf_mbox()` and `octep_ctrl_net_uninit()`. In `octep_vf_remove()`, `octep_vf_mbox_dev_remove()`, `cancel_work_sync(&oct->tx_timeout_task)`, and `unregister_netdev()` must precede `octep_vf_delete_mbox()`, which must precede `octep_vf_device_cleanup()` unmapping `oct->mmio.hw_addr`. [F178, F179]
- Since `octep_ctrl_net_*` callers allocate `struct octep_ctrl_net_wait_data d` on the stack, `octep_send_mbox_req()` must only add `d->list` to `oct->ctrl_req_wait_list` when `wait_for_response` is true and must unconditionally `list_del(&d->list)` after `wait_event_interruptible_timeout()` before returning. [F274]

## API Contracts
- Callers of `init_send_req()` must zero-initialize `struct octep_ctrl_net_wait_data` and pass `sz` excluding `union octep_ctrl_net_req_hdr` (`req_hdr_sz`). Callers of `octep_write_mbox_data()` / `octep_read_mbox_data()` must first verify `octep_ctrl_mbox_circq_space()` / `depth()`. [F202, F233, F268]
- `octep_ctrl_net_get_mtu()` and `octep_pfvf_get_mtu()` return max frame length including `ETH_HLEN + ETH_FCS_LEN` (18 bytes), whereas `netdev->max_mtu`, `octep_ctrl_net_set_mtu()`, and `octep_vf_mbox_set_mtu()` use L3 MTU excluding `ETH_HLEN + ETH_FCS_LEN`. [F209]
- `octep_*iq_process_completions()` returns `!budget` (`1` if more TX work remains, `0` if done), not packet count. In `octep_*napi_poll()`, if `tx_pending` is non-zero or `rx_done >= budget`, return `budget` without completing NAPI or calling `octep_*enable_ioq_irq()`. `octep_*iq_full_check()` returns `1` when full/stopped; when `1`, `octep_*start_xmit()` must bypass `xmit_more` and ring `iq->doorbell_reg`. [F208, F246, F309]
- In PF scatter-gather TX (`octep_start_xmit()`, `octep_iq_process_completions()`, `octep_iq_free_pending()`), `sglist[0].dma_ptr[0]` (`sglist[0].len[3]`) uses `dma_map_single()` / `dma_unmap_single()`, while fragment `si >= 1` (`sglist[si >> 2].dma_ptr[si & 3]`, `len[3 - (si & 3)]`) uses `skb_frag_dma_map()` / `dma_unmap_page()`. [F306]
- PF `ndo_*_vf_*` callbacks (`octep_get_vf_config()`, `octep_set_vf_mac()`) must check `octep_is_vf_valid(oct, vf)` (`vf < CFG_GET_ACTIVE_VFS(oct->conf)`). Only `hw_ops.ioq_intr_handler` receives `struct octep_ioq_vector *`; the 11 non-IOQ `hw_ops.*_intr_handler` callbacks receive `struct octep_device *`. [F227, F272]
- `OCTEP_PCI_WIN_READ(oct, addr)` must set bit 53 (`addr |= 1ull << 53`) before writing `pci_win_rd_addr`, and windowed reset writes in `octep_soft_reset_cn93_pf()` / `cnxk_pf()` must first write `0xFF` to `SDP_WIN_WR_MASK_REG`. Background recovery work (`octep_hb_timeout_task()`) under `rtnl_lock()` must call `dev_close(oct->netdev)`, not `octep_stop()`. [F287, F308]

## Error Handling
- In `__octep_oq_process_rx()`, if `build_skb()` returns `NULL` after `octep_oq_next_pkt()` unmapped the head descriptor, call `octep_oq_drop_rx()` to unmap and advance `read_idx` and `desc_used` past remaining fragments and `continue`. [F197]
- `octep_ctrl_net_get_link_status()` and `octep_ctrl_net_get_mtu()` return `< 0` on error and `>= 0` on success (store in signed `int`, test `< 0`). `__octep_vf_mbox_send_cmd()`, `octep_vf_mbox_send_cmd()`, and `octep_vf_mbox_bulk_read()` return positive `OCTEP_PFVF_MBOX_CMD_STATUS_*` (`1`..`3`) or `-EOPNOTSUPP` on failure; test `if (ret)`, not `if (ret < 0)`. [F200, F201]

## External Contracts
- In `octep_probe()`, `get_fw_ready_status(pdev)` must verify PCI VSEC `FW_STATUS_VSEC_ID` (`0xA3`) reports `FW_STATUS_READY` (`1`) at `pos + 8` before `octep_device_setup()`, returning `-EPROBE_DEFER` otherwise. Before programming IQ/OQ CSRs in `octep_*setup_iq`/`oq_regs_*`, poll `SDP_R_IN`/`OUT_CONTROL(q)` for `IDLE`. When enabling an IQ in `octep_*enable_iq_*`, write `0xFFFFFFFF` to `SDP_R_IN_INSTR_DBELL(iq_no)` and poll until 0 before setting `SDP_R_IN_ENABLE(iq_no)`. [F282, F289, F290]
- New commands in `octep_ctrl_net_h2f_cmd`, `f2h_cmd`, or `octep_pfvf_mbox_opcode` need a non-zero version in `*_cmd_versions[]` (PF and VF). `octep_vf_iface_rx_stats`, `tx_stats` (`reserved[13]`), and `link_info` must match PF `octep_iface_*` layouts byte-for-byte. Every PF-VF mailbox handler in `octep_pfvf_mbox_work()` must set `rsp->s.type` to `OCTEP_PFVF_MBOX_TYPE_RSP_ACK` or `RSP_NACK`, and `octep_pfvf_set_mac_addr()` must return `RSP_NACK` if `OCTEON_PFVF_FLAG_MAC_SET_BY_PF` is set in `oct->vf_info[vf].flags`. [F238, F239, F241, F314]

## Known Pitfalls
- In `octep_*enable_ioq_irq()`, write processed counts with 32-bit `writel()` to `iq->inst_cnt_reg` and `oq->pkts_sent_reg`, issue a write barrier, then write `1UL << OCTEP_OQ`/`IQ_INTR_RESEND_BIT` (bit 59) with 64-bit `writeq()`. Cast 32-bit `time_threshold` to `u64` before `<< 32` for `R_OUT_INT_LEVELS`, and cast `pem` to `uint64_t` before `<< 36` in `CNXK_PEMX_PFX_CSX_PFCFGX`. [F256, F257, F288]
- In `octep_*setup_iq()`, scale `iq->sglist` by element count `i * OCTEP_*SGLIST_ENTRIES_PER_PKT` and offset `iq->sglist_dma` by byte size `i * OCTEP_*SGLIST_SIZE_PER_PKT`. In PF `octep_pfvf_mbox_wk`, `wk->ctxptr` is `struct octep_mbox *`; in VF `octep_vf_mbox_wk`, `wk->ctxptr` is `struct octep_vf_device *`. [F266, F273]
- On CNXK PF, write `FW_STATUS_RUNNING` to `CNXK_PCIEEP_VSECST_CTL` via `OCTEP_PCI_WIN_WRITE` in `octep_device_setup_cnxk_pf()` and before `CNXK_RST_CHIP_DOMAIN_W1S` in `octep_soft_reset_cnxk_pf()`. In `octep_device_setup_cn93_pf()`, check `oct->chip_id == OCTEP_PCI_DEVICE_ID_CN98_PF` to use `CN98_SDP_MAC_PF_RING_CTL_SRN`/`RPPF` and `octep_soft_reset_cn98_pf`. [F283, F284]
