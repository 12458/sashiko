# SCHEDULER — kernel/sched (part 3)

Implements the EEVDF Completely Fair Scheduler class (`fair.c`), CPU idle loop (`idle.c`), and CPU isolation / housekeeping cpumasks (`isolation.c`).

## Architecture & Data Flow

- Delayed-dequeued tasks (`se->sched_delayed == 1`) decrement `cfs_rq->h_nr_runnable` via `set_delayed()` while staying counted in `h_nr_queued` and `rq->nr_running`; runnable-task checks (e.g. `wake_affine_idle()`) must subtract `cfs_h_nr_delayed(rq)` from `rq->nr_running`. `set_delayed()` and `clear_delayed()` must return early when `!entity_is_task(se)`. `util_est_dequeue()` runs when a task initially dequeues (`!p->se.sched_delayed`), and `util_est_enqueue()` runs when `!p->se.sched_delayed || (flags & ENQUEUE_DELAYED)`. [F190, F256, F257]
- `enqueue_task_fair()` must sample `rq->cfs.h_nr_queued` before `for_each_sched_entity(se)` increments it; on 0-to-nonzero transition, call `dl_server_update_idle_time(rq, rq->curr)` (if `!rq->nr_running`) and `dl_server_start(&rq->fair_server)`. In `enqueue_entity()`, `place_entity()` must precede `update_curr()` when `cfs_rq->curr == se`, and follow `update_curr()`, `update_load_avg()`, and `update_cfs_group()` when `cfs_rq->curr != se`. [F263, F272]
- In `dequeue_entities()`, whenever the first `for_each_sched_entity(se)` loop breaks, `slice = cfs_rq_min_slice(cfs_rq)` must be sampled at the break point, and if `cfs_rq->load.weight` is non-zero, `se` must advance to `parent_entity(se)` before breaking so the second loop does not decrement `h_nr_*` twice on `cfs_rq`. In `dequeue_entity()`, `if ((flags & (DEQUEUE_SAVE | DEQUEUE_MOVE)) != DEQUEUE_SAVE)` guards `update_min_vruntime(cfs_rq)`. [F282, F283, F293]
- `place_entity()` and `update_deadline()` must overwrite `se->slice` with `sysctl_sched_base_slice` only when `!se->custom_slice`. Updating `se->slice` on an already-queued group `se` (`se != cfs_rq->curr`) requires `min_vruntime_cb_propagate(&se->run_node, NULL)`. [F254, F270]
- `__pick_eevdf()` must check if `node->rb_left` is non-NULL with `vruntime_eligible(cfs_rq, __node_2_se(left)->min_vruntime)` and descend left before testing `entity_eligible(cfs_rq, se)`. `cfs_rq->avg_vruntime` and `avg_load` weight `entity_key(cfs_rq, se)` by `scale_load_down(se->load.weight)`; `__update_min_vruntime()` calls `avg_vruntime_update()`; `avg_vruntime()` subtracts `load - 1` from negative `avg` before `div_s64(avg, load)`; and `vruntime_eligible()` cross-multiplies `avg >= (s64)(vruntime - cfs_rq->min_vruntime) * load`. [F284, F304, F305]
- Under proxy execution (`cfs_rq->curr == &rq->donor->se`), `update_se()` accounts task execution runtime to `rq->curr` and `cgroup_account_cputime()` / EEVDF vruntime to `donor`. In `check_preempt_wakeup_fair()`, `se = &donor->se` is used for group matching and eligibility while `test_tsk_need_resched()` tests `rq->curr`; preempting `se` on `cse_is_idle && !pse_is_idle` or `do_preempt_short` must call `cancel_protect_slice(se)` before `resched_curr_lazy(rq)`. Walking `se` and `pse` up in `pick_next_task_fair()` or `cfs_prio_less()` must snapshot both depths before advancing either pointer. [F255, F268, F290, F292]
- For `root_task_group`, `tg->se[cpu]` is NULL; code handling arbitrary `tg` must check `tg->se[cpu]` or `tg != &root_task_group`. `alloc_fair_sched_group()` must allocate `tg->se[i]` with `sizeof(struct sched_entity_stats)` for `__schedstats_from_se()`. [F235, F316]
- `list_add_leaf_cfs_rq()` callers (`enqueue_task_fair()`, `unthrottle_cfs_rq()`) must walk ancestors until it returns true and `rq->tmp_alone_branch == &rq->leaf_cfs_rq_list`. Iterating `rq->leaf_cfs_rq_list` must use `for_each_leaf_cfs_rq_safe()` and unlink decayed entries via `list_del_leaf_cfs_rq()` (which steps `rq->tmp_alone_branch` to `.prev` if equal); `child_cfs_rq_on_list()` must verify `prev != &rq->leaf_cfs_rq_list` before `container_of()`. [F201, F262, F286, F314]
- Modifying `load_weight::weight` requires zeroing or updating `inv_weight` (`update_load_add/sub/set()`, `reweight_task_fair()`). `__calc_delta()` must shift out non-zero `(u32)(fact >> 32)` before `mul_u32_u32()` and `mul_u64_u32_shr()`, with `weight == NICE_0_LOAD` or `weight <= lw->weight`. `reweight_entity()` must rescale `se->vlag` and (if `se->rel_deadline`) `se->deadline` before `update_load_set()`; `place_entity()` inflates `se->vlag` by `(load + scale_load_down(se->load.weight)) / load` under `PLACE_LAG`. `calc_group_shares()` bounds `load` below by `cfs_rq->avg.load_avg`, guards `shares /= tg_weight` with `if (tg_weight)`, and clamps to `[MIN_SHARES, tg_shares]`. [F251, F306, F309, F310]
- PELT updates on `cfs_rq->avg` (`dequeue_load_avg()`, `update_cfs_rq_load_avg()`) must clamp underflow to `0` (`sub_positive()`/`add_positive()`) and clamp `*_sum` to at least `*_avg * PELT_MIN_DIVIDER`. `update_cfs_rq_h_load()` must initialize the starting `cfs_rq->h_load_next = NULL`, link `cfs_rq->h_load_next = se` bottom-up, and walk top-down to compute `group_cfs_rq(se)->h_load`. [F296, F307]
- `init_sd_lb_stats()` must set `sds->busiest_stat.idle_cpus = UINT_MAX` and `group_type = group_has_spare`. `group_classify()` must evaluate `sgs->group_type` in decreasing pull-priority order matching `enum group_type`. `select_idle_core()` and `should_we_balance()` must clear `cpu_smt_mask(core)` from the candidate cpumask when an SMT core is not idle. [F245, F297, F298]
- In `detach_tasks()`, rejected tasks must jump to `next:` (`list_move(&p->se.group_node, tasks)`), and `migrate_load` subtracts `max_t(unsigned long, task_h_load(p), 1)`. In `sched_balance_rq()`, `LBF_DST_PINNED` and `LBF_ALL_PINNED` must clear the rejected CPU from `env.cpus` and reset `env.loop = 0` and `env.loop_break`, whereas `LBF_NEED_BREAK` preserves them. `sched_balance_domains()` must `continue` (not `break`) when `!continue_balancing && need_decay`. Aborting `_nohz_idle_balance()` early on `!idle_cpu(this_cpu) && need_resched()` must restore `has_blocked_load = true` and `nohz.needs_update = 1`. [F287, F288, F295, F300]
- `p->sched_throttle_work` and `p->numa_work` use `work.next == &work` when unqueued and must reset `work->next = work` in init and callbacks. `throttle_cfs_rq_work()` must call `dequeue_task_fair(rq, p, DEQUEUE_SLEEP | DEQUEUE_THROTTLE)` before setting `p->throttled = true`. [F246, F271]
- `task_numa_fault()` must return if `!current->mm`, and sizes `p->numa_faults` with `NR_NUMA_HINT_FAULT_BUCKETS` while `grp->faults[]` has `NR_NUMA_HINT_FAULT_STATS` (`NUMA_MEM`/`NUMA_CPU` only). In `should_numa_migrate_memory()`, every `return true` under `folio_use_access_time(folio)` must account `folio_nr_pages(folio)` via `mod_node_page_state()`. `task_numa_work()` must skip RO file mappings, `!vma->vm_mm`, and `!vma_is_accessible(vma)`; advance `mm->numa_scan_offset = vma->vm_end` when skipping `prev_scan_seq == mm->numa_scan_seq`; and call `reset_ptenuma_scan(p)` at `out:` when `!vma`. [F264, F294, F317, F354, F357]
- `do_idle()` pairs `__current_set_polling()` / `tick_nohz_idle_enter()` with `tick_nohz_idle_exit()`, `__current_clr_polling()`, and `smp_mb__after_atomic()` before `flush_smp_call_function_queue()` and `schedule_idle()`. Every path out of `cpu_idle_poll()`, `cpuidle_idle_call()`, `call_cpuidle()`, and `default_idle_call()` must re-enable local IRQs and restore `__current_set_polling()`. [F208, F301]
- `housekeeping_isolcpus_setup()` must advance `str` past each comma-delimited token and validate unknown tokens contain only `isalpha(*str) || *str == '_'`. In `housekeeping_setup()`, if `housekeeping_staging & cpu_present_mask` has no CPU `< min(nr_cpu_ids, setup_max_cpus)`, `smp_processor_id()` must be forced into `housekeeping_staging` and cleared from `non_housekeeping_mask`. [F278, F302]

## Synchronization

- `task_tick_fair()` and `task_tick_idle()` (and callees) can run remotely via `nohz_full` tick offload and must use `@rq` and `@curr`, never `this_rq()`, `smp_processor_id()`, or `current`. [F326]
- `sched_group_set_shares()`, `sched_group_set_idle()`, and `__sched_group_set_shares()` must hold `shares_mutex` outside `rq->__lock`. `cfs_rq->removed.lock` requires `raw_spin_lock_irqsave` when `rq->__lock` is not held (`remove_entity_load_avg()`) and nests inside `rq->__lock`. [F230, F328]
- `update_cfs_rq_load_avg()` must update `cfs_rq->last_update_time_copy` via `u64_u32_store_copy()`, and lockless readers must use `cfs_rq_last_update_time()`. `migrate_se_pelt_lag()` must read `rq->clock_pelt_idle` via `u64_u32_load`, execute `smp_rmb()`, then read `cfs_rq_last_update_time()` and `u64_u32_load(rq->clock_idle)`. [F261, F343]
- `rq->__lock` nests outside `cfs_b->lock`: timer callbacks must drop `cfs_b->lock` before `distribute_cfs_runtime()`, while `runtime_refresh_within()` and `start_cfs_slack_bandwidth()` require `cfs_b->lock`. `throttle_cfs_rq_work()` must recheck `p->sched_class == &fair_sched_class` and `cfs_rq->throttle_count != 0` under `task_rq_lock(p)`. `__unthrottle_cfs_rq_async()` requires `rq->__lock` and may call `smp_call_function_single_async(cpu_of(rq), &rq->cfsb_csd)` only when `rq->cfsb_csd_list` was empty. [F219, F221, F327, F330]
- `select_task_rq_fair()` requires `p->pi_lock`; `select_idle_sibling()`, `select_idle_cpu()`, `select_idle_capacity()`, and `find_energy_efficient_cpu()` require IRQs disabled and `rcu_read_lock()`. `sched_balance_newidle()` must pair `rq_unpin_lock()` / `rq_repin_lock()` around dropping `this_rq` lock and return `< 0` if `this_rq->nr_running != this_rq->cfs.h_nr_queued` so `pick_next_task_fair()` returns `RETRY_TASK`. [F336, F339]
- `kick_ilb()` may call `smp_call_function_single_async()` only when `atomic_fetch_or(flags, nohz_flags(ilb_cpu))` had no `NOHZ_KICK_MASK` bits set. `nohz_balance_enter_idle()` must set `nohz.idle_cpus_mask` and execute `smp_mb__after_atomic()` before setting `nohz.needs_update = 1` and `nohz.has_blocked = 1` (paired with `smp_mb()` in `_nohz_idle_balance()`). [F341, F342]
- `task_numa_group()` must initialize all `numa_group` fields before `rcu_assign_pointer(p->numa_group, grp)`. `deref_task_numa_group()` requires `p == current`, `rcu_read_lock()`, or holding `task_rq(p)->__lock` while `!READ_ONCE(p->on_cpu)`. [F209, F212]
- `__cpuidle` functions (`cpu_idle_poll()`, `default_idle_call()`) must wrap tracepoints/RCU calls in `instrumentation_begin()`/`instrumentation_end()` and wrap the idle wait in `ct_cpuidle_enter()`/`ct_cpuidle_exit()`. [F322]
- `housekeeping.cpumasks[type]` and `housekeeping.flags` must be populated before `housekeeping_init()` enables `housekeeping_overridden`, and readers (`housekeeping_cpumask()`, `housekeeping_affine()`, `housekeeping_test_cpu()`, `housekeeping_any_cpu()`) must check both `housekeeping_overridden` and `housekeeping.flags & BIT(type)`. [F232, F351]

## Object Lifetimes

- When `dequeue_entities()` runs with `DEQUEUE_DELAYED`, it calls `__block_task(rq, p)` and returns `1`; callers must not dereference `se` or `p` afterwards, and `pick_next_entity()` must return `NULL` so `pick_task_fair()` restarts at `again:`. Before `remove_entity_load_avg(se)` in `task_dead_fair()` or `unregister_fair_sched_group()`, if `se->sched_delayed` is set, lock rq, recheck `se->sched_delayed`, update rq clock, and call `dequeue_entities(rq, se, DEQUEUE_SLEEP | DEQUEUE_DELAYED)`. [F192, F238, F291]
- Before dropping `busiest->__lock` during load balance, `detach_task()` must call `deactivate_task(env->src_rq, p, DEQUEUE_NOCLOCK)` and `set_task_cpu(p, env->dst_cpu)`; every task from `detach_tasks(&env)` must be attached via `attach_tasks(&env)` under `env.dst_rq` lock. `busiest->active_balance_work` is serialized by `busiest->active_balance` under `busiest->__lock`, which `active_load_balance_cpu_stop()` must clear to `0` on all exit paths before unlocking and attaching any detached task via `attach_one_task()`. [F195, F196, F225, F226]
- `destroy_cfs_bandwidth()` must cancel `period_timer` and `slack_timer` first, then flush non-empty `rq->cfsb_csd_list` across all possible CPUs via `__cfsb_csd_unthrottle(rq)` with IRQs disabled. [F199]
- `task_numa_free(p, final)` must subtract `p`'s faults from `grp` under `grp->lock` before clearing `p->numa_group` and `put_numa_group(grp)`, and `kfree(p->numa_faults)` only when `final` is true. Switching `p->numa_group` in `task_numa_group()` requires `get_numa_group(grp)` under `rcu_read_lock()`, transferring faults and `nr_tasks` under `double_lock_irq(&my_grp->lock, &grp->lock)`, and `put_numa_group(my_grp)`. `task_numa_work()` must check `p->flags & PF_EXITING` before reading `p->mm`, publish `vma->numab_state` via `cmpxchg()` (freeing `ptr` on race loss), and restore `work->next = work` before returning. [F202, F203, F205, F266]
- `housekeeping_setup()` must free `housekeeping_staging` and `non_housekeeping_mask` in reverse order on all exit paths and call `housekeeping_setup_type()` only after conflict checks pass. `play_idle_precise()` must restore `cpuidle_use_deepest_state(0)`, `~PF_IDLE`, `preempt_fold_need_resched()`, and `preempt_enable()` after its loop. [F206, F207]

## API Contracts

- Guard `task_of(se)` with `entity_is_task(se)`. Calling `place_entity()` on an `on_rq` entity requires decrementing `cfs_rq->nr_queued` and (if `se != cfs_rq->curr`) calling `__dequeue_entity()` first, then restoring both. Call `update_cfs_rq_load_avg()` before `attach_entity_load_avg()` or `detach_entity_load_avg()`. [F233, F249, F253]
- In `pick_next_task_fair()`, switching between fair tasks under `CONFIG_FAIR_GROUP_SCHED` must call `__put_prev_set_next_dl_server(rq, prev, p)`, update entities to `is_same_group(se, pse)`, and call `__set_next_task_fair(rq, p, true)`, or else `put_prev_set_next_task()`. `sched_group_set_shares()` and `sched_group_set_idle()` must reject `!tg->se[0]` with `-EINVAL`, and `sched_group_set_shares()` must also reject `tg_is_idle(tg)` under `shares_mutex`. [F347, F355]
- `util_fits_cpu()` returns `1` (fits), `0` (exceeds capacity), or `-1` (`uclamp_min` exceeds capacity); check `> 0` for full fit. Pass `dst_cpu = -1` (not `0`) to `cpu_util()` when discounting `p` without migration. Idle CPU selectors (`select_idle_*`, `find_energy_efficient_cpu`, `find_new_ilb`) return `-1` on failure, whereas `wake_affine_idle`/`wake_affine_weight` return `nr_cpumask_bits`. [F236, F239, F250]
- Scale real-ns `se->slice` and `delta_exec` via `calc_delta_fair()` before combining with virtual times. Convert `sysctl_sched_cfs_bandwidth_slice` (us) via `sched_cfs_bandwidth_slice()` (ns), and `sysctl_numa_balancing_scan_size` / `sysctl_numa_balancing_promote_rate_limit` (MB) via `MB_TO_PAGES()`. Public housekeeping helpers take `enum hk_type`, whereas `housekeeping.flags` and `housekeeping_setup()` take `HK_FLAG_* = BIT(HK_TYPE_*)`. `play_idle_precise()` requires a non-sleeping per-CPU `SCHED_FIFO` kthread and `_HARD` hrtimer mode. [F241, F248, F325, F348, F349]

## Error Handling

- On allocation failure in `alloc_fair_sched_group()` before `init_tg_cfs_entry()`, free only the uncommitted local `cfs_rq` at `err_free_rq`; `free_fair_sched_group()` frees `tg->cfs_rq`, `tg->se`, and committed entries. `task_numa_assign()` and `task_numa_migrate()` must clear `rq->numa_migrate_on = 0` and `put_task_struct(env.best_task)` when replacing or finishing with `env.best_task`. [F200, F244]
- `sched_cfs_period_timer()` must handle overruns (`++count > 3`) with `pr_warn_ratelimited`, not `WARN_ON_ONCE`. `housekeeping_any_cpu()` must suppress `WARN_ON_ONCE` when `system_state != SYSTEM_RUNNING && type == HK_TYPE_TIMER`. [F358, F359]

## Known Pitfalls

- Compare `u64` virtual times (`vruntime`, `deadline`, `min_vruntime`) by casting their difference to `s64` (`entity_before()`, `vruntime_gt()`), never `<` or `>`. Cast `se_weight(se)` to `s64` before multiplying by `se->avg.load_sum` in `update_tg_cfs_load()`. Add `+ 1` to divisors in `update_cfs_rq_h_load()`, `task_h_load()`, `numa_get_avg_runtime()`, and `task_numa_placement()` (clamping negative `(s64)*period` to `0`), and clamp `rq->misfit_task_load` to `>= 1`. Widen 32-bit ms/us values to `u64` before `* NSEC_PER_*`. Hash PIDs with `hash_32(current->pid, ilog2(BITS_PER_LONG))` in `vma_is_accessed()`, and log `par` with `%.*s` in `housekeeping_isolcpus_setup()`. [F303, F308, F311, F312, F313, F320, F321]
