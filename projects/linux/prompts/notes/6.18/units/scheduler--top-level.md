# SCHEDULER — (top level)

This component defines core scheduler headers (`include/linux/sched.h`, `include/linux/preempt.h`, `include/linux/wait.h`, `include/uapi/linux/sched.h`), unity-build units (`kernel/sched/build_policy.c`, `kernel/sched/build_utility.c`), and foundational utilities (`kernel/sched/autogroup.c`, `kernel/sched/clock.c`, `kernel/sched/completion.c`) for `task_struct`, preemption/migration control, waitqueues, completions, autogroups, and CPU scheduling clocks.

## Architecture & Data Flow

- In `struct task_struct`, `thread_info` must be the first field when `CONFIG_THREAD_INFO_IN_TASK` is enabled, and only scheduling-critical fields may precede `randomized_struct_fields_start`. Bit 31 (`0x80000000`, `UTIL_AVG_UNCHANGED`) of `sched_avg::util_est` is reserved as a flag bit (`util_est` never exceeds `SCHED_CAPACITY_SCALE` = 1024); mask it when reading arithmetic values. [F620, F643]
- `__task_state_index()` and `task_index_to_char()` require `TASK_REPORT` to occupy contiguous low bits (`0x01`..`0x40`) so `TASK_REPORT_IDLE` (`TASK_REPORT + 1`) is a power of two and `fls(state)` yields a valid index (`0..8`) into `state_char[]`. Because `TASK_IDLE` is `TASK_UNINTERRUPTIBLE | TASK_NOLOAD` (`TASK_NOLOAD` outside `TASK_REPORT`), `__task_state_index()` must test `(tsk_state & TASK_IDLE) == TASK_IDLE` after masking with `TASK_REPORT`. [F622, F628]
- `__migrate_disable()` increments `this_rq_pinned()` only on the outer `0 -> 1` transition of `p->migration_disabled` with preemption disabled. Overflow/underflow checks on the `unsigned short` `migration_disabled` counter in `__migrate_disable()` and `__migrate_enable()` must cast it to `s16` before comparing against `0`. [F605, F642]
- On `!CONFIG_PREEMPT_COUNT`, `preempt_disable()` and `preempt_enable()` (plus `_notrace` and `_no_resched` variants) must still expand to `barrier()` so faulting calls (`get_user()`, `put_user()`) are not reordered into preempt-disabled regions. [F667]
- In `interrupt_context_level()`, each `level += !!(pc & ...)` step must include all higher-priority masks (`NMI_MASK`, then `NMI_MASK | HARDIRQ_MASK`, then `NMI_MASK | HARDIRQ_MASK | SOFTIRQ_OFFSET`) so NMI/hardirq return levels 3 and 2 even if lower bits are clear. [F627]
- In `___wait_event()`, `if (condition) break;` must precede `if (___wait_is_interruptible(state) && __int)` so an already-woken waiter consumes the condition before returning `-ERESTARTSYS`, and only the `__int` path may `goto __out` past `finish_wait()`; `cmd` exits must `break`. [F631]
- `autogroup_task_group(p, tg)` must gate `p->signal->autogroup->tg` access on `task_wants_autogroup(p, tg)` (`false` when `tg != &root_task_group` or `p->flags & PF_EXITING`). `autogroup_default` wraps `root_task_group` with `root_task_group.autogroup == NULL`, so `proc_sched_autogroup_show_task()` and `autogroup_path()` must check `task_group_is_autogroup()`. In `proc_sched_autogroup_set_nice()`, sanitize `nice + 20` with `array_index_nospec(nice + 20, 40)` before indexing `sched_prio_to_weight[]`, and update `ag->nice` only if `sched_group_set_shares()` succeeds. [F592, F610, F617]
- Under `CONFIG_HAVE_UNSTABLE_SCHED_CLOCK`, `__set_sched_clock_stable()` must compute `__sched_clock_offset` (`scd->tick_gtod + __gtod_offset - scd->tick_raw`) with IRQs disabled before enabling `__sched_clock_stable`, then call `tick_dep_clear(TICK_DEP_BIT_CLOCK_UNSTABLE)`. `__clear_sched_clock_stable()` must call `tick_dep_set(TICK_DEP_BIT_CLOCK_UNSTABLE)` before scheduling `sched_clock_work`, where `__sched_clock_work()` stamps and clones per-CPU `sched_clock_data` before clearing `__sched_clock_stable`. [F611, F660]
- Comparisons and clamping of 64-bit timestamps in `sched_clock_local()` and `sched_clock_remote()` must use signed 64-bit differences (`(s64)(x - y) < 0` via `wrap_min()`/`wrap_max()`) rather than unsigned `<` or `>`. [F639]

## Synchronization

- In `struct task_struct`, scheduler-lock-serialized bitfields (`sched_reset_on_fork`..`sched_task_hot`) must be separated from `sched_remote_wakeup` and later unserialized bitfields by `unsigned :0;`. Updating `uclamp_req[]` or `uclamp[]` requires `task_rq_lock()`; RMW updates to `rseq_event_mask` must be atomic with respect to preemption. [F573, F621, F674]
- On `!CONFIG_PREEMPT_RT`, `__get_task_blocked_on()`, `__set_task_blocked_on()`, and `__clear_task_blocked_on()` require holding `m->wait_lock`, and `__set_task_blocked_on()` requires `p == current` without overwriting a different mutex. `current_save_and_set_rtlock_wait_state()` and `current_restore_rtlock_saved_state()` require IRQs disabled and `current->pi_lock` held while saving/restoring `current->__state` and resetting `current->saved_state` to `TASK_RUNNING`. [F570, F571]
- When `__migrate_enable()` transitions `current->migration_disabled` from `1` to `0`, it must disable preemption, restore `current->cpus_ptr` via `___migrate_enable()` if needed, and issue `barrier()` before setting `current->migration_disabled = 0` and decrementing `this_rq_pinned()`. [F566]
- Code inside a spinlock, rwlock, softirq, or regular interrupt handler requiring CPU-local preemption serialization without a dedicated lock must pair `preempt_disable_nested()` and `preempt_enable_nested()`, as those contexts remain preemptible on `CONFIG_PREEMPT_RT`. [F665]
- Wait loops not serialized with wakeup under a shared lock must use `set_current_state()` (`smp_store_mb()`), not `__set_current_state()`, before testing the condition. Lockless wakeup checks via `waitqueue_active()` or `wq_has_single_sleeper()` require a prior `smp_mb()` (as in `wq_has_sleeper()`) after storing the wake condition. [F578, F579]
- `__wait_event_interruptible_locked()` requires `wq.lock` held on entry matching `fn` (`spin_lock()` for `do_wait_intr`, `spin_lock_irq()` for `do_wait_intr_irq`), and unlinks `__wait` via `__remove_wait_queue()` and sets `TASK_RUNNING` under `wq.lock` on all exits. `__wait_event_lock_irq*()` macros require `lock` held on entry, unlock via `spin_unlock_irq(&lock)` only around `cmd` and `schedule*()`, and relock before rechecking `condition` or exiting (`cmd` must not return, break, or relock). [F555, F556]
- `try_wait_for_completion()` and `do_wait_for_common()` must recheck `x->done` under `x->wait.lock` before decrementing `x->done` (`!= UINT_MAX`), even after an earlier `READ_ONCE(x->done)` or after reacquiring `x->wait.lock` from `action(timeout)`. [F577]
- `autogroup_create()` must initialize `ag->kref`, `ag->lock`, `ag->id`, `ag->tg`, `tg->rt_se`, `tg->rt_rq`, and `tg->autogroup` before `sched_online_group(tg, &root_task_group)` and publication to `p->signal->autogroup`. `sched_autogroup_create_attach()` must never be called under any spinlock (`GFP_KERNEL` allocation and `sighand->siglock`), and `sched_autogroup_detach()` must never be called under `sighand->siglock`. `proc_sched_autogroup_set_nice()` and `proc_sched_autogroup_show_task()` must pin `ag` via `autogroup_task_get(p)`, hold `ag->lock` (`down_write` to set shares/nice, `down_read` to read nice), and release via `autogroup_kref_put(ag)`. [F561, F568, F575]
- Reading/stamping `scd->tick_gtod` and `scd->tick_raw` to compute `__sched_clock_offset` or `__gtod_offset` (via `__sched_clock_gtod_offset()`) requires local IRQs disabled; `sched_clock_init()` must do this before `static_branch_inc(&sched_clock_running)`. `sched_clock_init_late()` (`late_initcall`) and `clear_sched_clock_stable()` must execute paired `smp_mb()` barriers between updating/reading `sched_clock_running` and `__sched_clock_stable_early`. Under `CONFIG_HAVE_UNSTABLE_SCHED_CLOCK`, `sched_clock_idle_wakeup_event()` must return early before `sched_clock_tick()` if `timekeeping_suspended` is set. [F562, F574, F659, F661]
- `sched_clock_local()` and `sched_clock_remote()` must update `scd->clock` via `raw_try_cmpxchg64()`/`try_cmpxchg64()` loops, and on 32-bit kernels `sched_clock_remote()` must read remote `scd->clock` via `cmpxchg64(&scd->clock, 0, 0)` and call `sched_clock_local(my_scd)` inside the retry loop. `local_clock_noinstr()` must be called with preemption disabled and call only `noinstr`-safe helpers. [F581, F681]

## Object Lifetimes

- In `autogroup_destroy()`, reset `ag->tg->rt_se` and `ag->tg->rt_rq` to `NULL` (under `CONFIG_RT_GROUP_SCHED`) before `sched_destroy_group(ag->tg)` (as `autogroup_create()` aliased them to `root_task_group`). Once `tg->autogroup = ag` is set, never `kfree(ag)` in `autogroup_destroy()`; `sched_destroy_group()` defers freeing across RCU until `sched_free_group()` calls `autogroup_free(tg)`. [F546, F547]
- `autogroup_move_group()` borrows `ag`: it leaves refcounts unchanged if `prev == ag` or `lock_task_sighand()` fails, otherwise calls `autogroup_kref_get(ag)` under sighand lock and calls `autogroup_kref_put(prev)` only after `for_each_thread()` `sched_move_task()` and `unlock_task_sighand()`. [F549]
- After observing `READ_ONCE(x->done)` non-zero, `completion_done()` must still lock and unlock `x->wait.lock` before returning `true` so a caller freeing `x` cannot race with `complete()` releasing `x->wait.lock`. In `do_wait_for_common()`, on-stack `DECLARE_SWAITQUEUE(wait)` must be unlinked and `TASK_RUNNING` restored via `__finish_swait(&x->wait, &wait)` under `x->wait.lock` on every loop exit. [F550, F551]
- Before freeing a polled `wait_queue_head` whose lifetime is shorter than the polled `struct file`, call `wake_up_pollfree(wq_head)` and RCU-delay freeing it. In `__wait_event_hrtimeout()`, `hrtimer_setup_sleeper_on_stack(&__t, ...)` must be paired with `hrtimer_cancel(&__t.timer)` and `destroy_hrtimer_on_stack(&__t.timer)` on all exit paths, even when `timeout == KTIME_MAX`. [F552, F554]

## API Contracts

- `alloc_tag_save(tag)` swaps `current->alloc_tag` with `tag` and returns `old`; callers must pass both to `alloc_tag_restore(tag, old)` on all exit paths. [F560]
- `set_current_state()` and `__set_current_state()` only accept `!is_special_task_state(state_value)`; special states (`__TASK_STOPPED`, `__TASK_TRACED`, `TASK_PARKED`, `TASK_DEAD`, `TASK_FROZEN`) require `set_special_state()` (serialized under `current->pi_lock`). `task_index_to_char(state)` expects a state index (`0..8`) from `task_state_index()`, never a raw `TASK_*` bitmask. [F601, F602]
- `cond_resched_lock()`, `cond_resched_rwlock_read()`, and `cond_resched_rwlock_write()` must not be called inside an explicit RCU read-side critical section. `preempt_ops::sched_out()` runs with `rq->lock` held and IRQs disabled; `sched_in()` runs without `rq->lock` and with IRQs enabled. [F576, F675]
- Do not use `in_atomic()` in drivers to detect atomic context or decide if sleeping is allowed (`PREEMPT_DISABLE_OFFSET` is `0` on `!CONFIG_PREEMPT_COUNT`; `PREEMPT_LOCK_OFFSET` is `0` on `CONFIG_PREEMPT_RT`). Do not use deprecated `in_irq()`, `in_softirq()`, or `in_interrupt()`; use `in_hardirq()`, `in_serving_softirq()`, `in_nmi()`, or `in_task()`. `*preempt_enable_no_resched*` and `preempt_check_resched` are undefined under `#ifdef MODULE` and must not be used in modules or module-exposed headers. [F662, F663, F697]
- Jiffies-based `wait_event_*_timeout()` and `wait_for_completion_*_timeout()` return signed `long`: `0` on timeout, `>= 1` on completion, or `-ERESTARTSYS` on signal (non-timeout interruptible/killable completion variants return `0` or `-ERESTARTSYS`). By contrast, `wait_event_*hrtimeout()` take relative `ktime_t` (`KTIME_MAX` disables timer) and return `0` on success, `-ETIME` on timeout, or `-ERESTARTSYS` on signal. [F583, F584, F585]
- Once `complete_all()` sets `x->done = UINT_MAX`, `completion_done()` and `try_wait_for_completion()` always return `true` without decrementing `x->done` until `reinit_completion()`, so `completion_done()` cannot detect active waiters after `complete_all()`. Also, `complete_all()` must not be called from hardirq/NMI context on `CONFIG_PREEMPT_RT` (`lockdep_assert_RT_in_threaded_ctx()`). [F586, F684]

## Error Handling

- In `autogroup_create()`, validate `sched_create_group()` with `IS_ERR(tg)` before setting `ag->tg = tg`. On failure, `out_free` must `kfree(ag)` without setting `ag = NULL` (as `out_fail` checks `ag ? "sched_create_group()" : "kzalloc()"`), log a `printk_ratelimit()`-guarded `KERN_WARNING`, and return `autogroup_kref_get(&autogroup_default)`. [F589, F694]

## External Contracts

- `CLONE_NEWTIME` (`0x00000080`) overlaps `CSIGNAL` (`0x000000ff`) and is valid only with `unshare()` and `clone3()`. Clone flags `>=` bit 32 (`CLONE_CLEAR_SIGHAND`, `CLONE_INTO_CGROUP`) require `ULL` suffixes and `clone3()`. In `struct clone_args`, `flags` forbids `CSIGNAL` and `CLONE_DETACHED` (use `exit_signal`), `stack` is the lowest stack address with byte size in `stack_size`, `set_tid_size` is the `pid_t` element count (not bytes), and new fields must be appended at the end using `__aligned_u64`. Any new `SCHED_FLAG_*` in `include/uapi/linux/sched.h` must be added to `SCHED_FLAG_ALL`. [F603, F644, F645, F687, F689]

## Known Pitfalls

- `tsk_used_math(p)` and `used_math()` return `0` or `PF_USED_MATH` (`0x00002000`), never `1`; do not compare `== 1`. `task_struct::flags` uses shifted `PF_*` masks (`&`, `|`), whereas `atomic_flags` uses `PFA_*` bit indices (`test_bit()`/`set_bit()` via `TASK_PFA_*`). Similarly, `*_tsk_thread_flag()` take `TIF_*` bit indices, while direct `atomic_long_*` ops on `task_thread_info(tsk)->flags` require shifted `_TIF_*` masks. [F587, F599, F600]
- `in_serving_softirq()`, `in_task()`, and `interrupt_context_level()` must test `SOFTIRQ_OFFSET` rather than `SOFTIRQ_MASK` so BH-disabled task context (`SOFTIRQ_DISABLE_OFFSET`) is not misclassified as softirq execution. [F626]
- `wait_queue_entry` structs passed to `prepare_to_wait*()`/`finish_wait()` must be initialized via `DEFINE_WAIT*()` or `init_wait*()` (initializing `entry` list head), never `DECLARE_WAITQUEUE()` or `init_waitqueue_entry()`. On-stack `wait_queue_head` variables must use `DECLARE_WAIT_QUEUE_HEAD_ONSTACK()` (or `init_waitqueue_head()`), not `DECLARE_WAIT_QUEUE_HEAD()`. [F595, F596]
- `__add_wait_queue()` must track the insertion point in `head` (initialized to `&wq_head->head` and updated to `&wq->entry` for each `WQ_FLAG_PRIORITY` entry) rather than inserting at the loop cursor `wq`. Every macro invoking `___wait_cond_timeout()` must declare `long __ret = timeout`, as `___wait_cond_timeout()` directly reads and mutates `__ret`. [F630, F632]
- In `proc_sched_autogroup_set_nice(p, nice)`, `security_task_setnice()` and `can_nice()` must check `current`, whereas `autogroup_task_get(p)` resolves `p`. In default `sched_clock()`, cast `(jiffies - INITIAL_JIFFIES)` to `unsigned long long` before multiplying by `(NSEC_PER_SEC / HZ)`. [F636, F638]
