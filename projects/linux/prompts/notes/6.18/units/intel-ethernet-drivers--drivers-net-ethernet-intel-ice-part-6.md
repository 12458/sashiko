# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ice (part 6)

This unit implements the `ice` driver entry point and `net_device_ops` (`ice_main.c`), NVM access (`ice_nvm.c`), and the DDP packet parser engine (`ice_parser.c`).

## Architecture & Data Flow

- If `ice_init_ddp_config()` fails or leaves `ice_is_safe_mode(pf)` true, `ice_init_dev()` must call `ice_set_safe_mode_caps(hw)` before `ice_init_pf(pf)`. In Safe Mode, `ice_init_features()` and `ice_deinit_features()` must return at entry, `ice_set_netdev_features()` must restrict features to `NETIF_F_SG | NETIF_F_HIGHDMA`, `ice_set_ops()` must bind `ice_netdev_safe_mode_ops` (with `.ndo_bpf = ice_xdp_safe_mode` and no tunnel/XDP offloads), and `netif_is_ice()` must check both `&ice_netdev_ops` and `&ice_netdev_safe_mode_ops`. [F204, F217, F294, F326]
- In `ice_prepare_xdp_rings()`, call `ice_vsi_assign_bpf_prog(vsi, prog)` only when `!ice_is_xdp_ena_vsi(vsi)`, as it drops a ref on the old `vsi->xdp_prog` and VSI rebuilds pass the existing prog without an extra ref. `ice_map_xdp_rings()` must compute `DIV_ROUND_UP(xdp_rings_rem, vsi->num_q_vectors - v_idx)` and prepend XDP rings to the head of `q_vector->tx.tx_ring` so `ice_unmap_xdp_rings()` can restore `q_vector->tx.tx_ring` to the first non-XDP ring (`!ring->tx_buf || !ice_ring_is_xdp(ring)`). [F223, F225, F272]
- In `ice_reset_subtask()`, evaluate pending reset bits (`ICE_CORER_RECV`, `ICE_GLOBR_RECV`, `ICE_EMPR_RECV` and `ICE_PFR_REQ`, `ICE_CORER_REQ`, `ICE_GLOBR_REQ`) in ascending scope order via sequential `if` statements (not `else if`). In `ice_prepare_for_reset()`, flush switchdev FDB via `ice_eswitch_br_fdb_flush()` under `rtnl_lock()` before `ice_clear_hw_tbls(hw)`; if `ICE_FLAG_TC_MQPRIO` is set and `reset_type != ICE_RESET_PFR`, call `ice_remove_q_channels(vsi, true)` and clear `old_ena_tc`, `all_enatc`, `old_numtc`, `all_numtc`, `req_txq`, `req_rxq`, `ICE_FLAG_TC_MQPRIO`, and `mqprio_qopt`. [F218, F219, F251]
- In `ice_rebuild()`, clear `pf->fw_emp_reset_disabled` on `ICE_RESET_EMPR`; if `ICE_FLAG_PTP_SUPPORTED` is set, call `ice_ptp_rebuild()` before `ice_vsi_rebuild_by_type(pf, ICE_VSI_PF)` and `ice_ptp_restore_timestamp_mode()` after; in `ice_req_irq_msix_misc()`, when `ice_is_reset_in_progress(pf->state)` is true, skip IRQ allocation (`goto skip_req_irq`) while still re-enabling OICR and controlq interrupt registers. [F228, F229, F230]
- `ice_remove_q_channels()` must clear `ch` pointers on all `vsi->tx_rings[ch->base_q + i]`, `vsi->rx_rings[ch->base_q + i]`, and their `q_vector`s before freeing `ch`, null `vsi->tc_map_vsi[i]`, and zero `all_enatc`/`all_numtc`. When `ice_rem_all_chnl_fltrs()` removes a rule on an `ICE_VSI_CHNL` VSI, decrement `fltr->dest_vsi->num_chnl_fltr` and (for `ICE_TC_FLWR_FIELD_DST_MAC` / `ENC_DST_MAC`) `pf->num_dmac_chnl_fltrs`. [F220, F221]
- In `ice_set_vlan_filtering_features()`, only call `vlan_ops->ena_rx_filtering` when CTAG/STAG filtering is set and `!ice_is_eswitch_mode_switchdev(vsi->back)`. In `ice_vlan_rx_add_vid()` / `ice_vlan_rx_kill_vid()`, when `IFF_ALLMULTI` is set, swap VLAN-0 `ICE_MCAST_PROMISC_BITS` with `ICE_MCAST_VLAN_PROMISC_BITS` on adding the first non-zero VLAN (`ice_vsi_num_non_zero_vlans(vsi) == 1`) and reverse on killing the last (`!ice_vsi_has_non_zero_vlans(vsi)`). [F216, F227]
- In `ice_set_features()`, check each bit in `changed` in an independent `if` statement (not `else if`). In `ice_add_mac_to_unsync_list()`, return 0 if `ether_addr_equal(addr, netdev->dev_addr)` so `__dev_uc_sync()` never deletes the VSI's own MAC filter. [F250, F322]
- In `ice_update_pf_stats()`, clear `pf->stat_prev_loaded = false` before reading port counters if `ice_is_reset_in_progress(pf->state)`, and in `ice_update_vsi_ring_stats()` only add deltas when `pf->stat_prev_loaded` is true. In `ice_check_for_hang_subtask()`, mask `ring_stats->stats.pkts` with `INT_MAX` when assigning to `int packets` so `-1` in `prev_pkt` uniquely marks zero pending Tx descriptors. [F226, F273]
- `ice_clean_sbq_subtask()` must clear `ICE_SIDEBANDQ_EVENT_PENDING` without cleaning `ICE_CTL_Q_SB` when `!ice_is_generic_mac(&pf->hw)`, and `ice_ena_ctrlq_interrupts()` must not enable `PFINT_SB_CTL` when `ts_ll_int_read` is true. [F297]
- In `ice_nvm.c`: `ice_read_sr_pointer()` must mask bit 15 (`ICE_SR_NVM_PTR_4KB_UNITS`) before multiplying by 4096 when set, or multiply by 2 when clear; `ice_get_nvm_css_hdr_len()` computes `(hdr_len_dword * 2) + ICE_NVM_AUTH_HEADER_LEN` words, which `ice_read_nvm_sr_copy()` must `roundup(..., 32)` before adding to `offset`; `ice_get_orom_civd_data()` scans 512-byte boundaries within `orom_size` and requires both `"$CIV"` and a 0 byte-sum across `sizeof(struct ice_orom_civd_info)`. [F244, F266, F267]
- In `ice_parser.c`: `ice_parser_dvm_set()` must update both `ICE_LBL_BST_TYPE_DVM` (`on`) and `ICE_LBL_BST_TYPE_SVM` (`!on`), writing to both `key[ICE_BT_VM_OFF]` and `key_inv[ICE_BT_VM_OFF]`; in `ice_ternary_match_byte()`, check don't-care (`bit_key != 0 && bit_key_inv != 0`) before mismatch; `ice_nearest_proto_id()` must skip `offset < rslt->po[i].offset` and return `false` when `dist % 2 != 0`. [F232, F249, F274]
- DDP parser structs: pattern buffers passed to `ice_bst_tcam_match()` (e.g. `bst_key`) must be >= `ICE_BST_TCAM_KEY_SIZE` (20) bytes; `struct ice_pg_cam_key::val` must match `struct ice_pg_nm_cam_key::val` with `next_proto` last, and `__ice_pg_nm_cam_match()` must `memcmp` `sizeof(item->key.val)`; `struct ice_lbl_item` software fields must follow `idx` and `label`, with `ice_parse_lbl_item()` copying only `idx` and `label`; `struct ice_ptype_mk_tcam_item` must stay `__packed` and `ICE_SID_RXPARSER_MARKER_TYPE_ENTRY_SIZE` (24) bytes. [F275, F276, F277, F278]

## Synchronization

- `ice_load()` and `ice_unload()` require `devl_lock(priv_to_devlink(pf))` and must unwind resources in exact reverse order: RDMA, features, TC indirect block, netdev registration, devlink PF port, netdev alloc. In `ice_setup_tc()` (`TC_SETUP_QDISC_MQPRIO`), when `cdev->adev` is non-NULL, lock in order `pf->adev_mutex`, `device_lock(&cdev->adev->dev)`, `pf->tc_mutex` (and check `adev->dev.driver`). [F171, F200]
- `ice_service_task_complete()` must run `smp_mb__before_atomic()` before `clear_bit(ICE_SERVICE_SCHED, pf->state)` on all exit paths of `ice_service_task()` and `ice_service_task_recovery_mode()`. In `ice_clean_{adminq,mailboxq,sbq}_subtask()`, keep `ICE_*Q_EVENT_PENDING` set if `__ice_clean_ctrlq()` returns non-zero, and re-check `ice_ctrlq_pending()` after clearing. [F183, F261]
- Only the waiting thread in `ice_aq_wait_for_event()` may `hlist_del(&task->entry)` from `pf->aq_wait_list` under `pf->aq_wait_lock`; `ice_aq_check_events()` and `ice_aq_cancel_waiting_tasks()` only update `task->state`. [F256]
- `ice_set_rx_mode()` runs in atomic context and must only set `ICE_VSI_UMAC_FLTR_CHANGED`, `ICE_VSI_MMAC_FLTR_CHANGED`, and `ICE_FLAG_FLTR_SYNC` and schedule `serv_task`. `ice_vsi_sync_fltr()`, `ice_vlan_rx_add_vid()`, and `ice_vlan_rx_kill_vid()` must acquire `ICE_CFG_BUSY` in `vsi->state`; in `ice_vsi_sync_fltr()`, release `netif_addr_lock_bh(netdev)` after `__dev_uc_sync()`/`__dev_mc_sync()` before calling `ice_fltr_{remove,add}_mac_list()`. [F186, F187, F307]
- In `ice_xdp()`, hold `vsi->xdp_state_lock` across `ice_xdp_setup_prog()` and `ice_xsk_pool_setup()`. `ice_vsi_assign_bpf_prog()` must `xchg(&vsi->xdp_prog, prog)`, `WRITE_ONCE` to all `rx_rings[i]->xdp_prog`, and `bpf_prog_put()` the old prog. When `vsi->num_xdp_txq < num_possible_cpus()`, `ice_vsi_determine_xdp_res()` must increment `ice_xdp_locking_key` and `ice_destroy_xdp_rings()` must decrement it. [F188, F192, F324]
- `ice_update_vsi_ring_stats()` must use `GFP_ATOMIC` and access `tx_rings`, `rx_rings`, `xdp_rings`, and `ring_stats` via `READ_ONCE()` under `rcu_read_lock()`. `ice_check_for_hang_subtask()` needs `smp_rmb()` between reading `ring_stats->stats.pkts` and `ice_get_tx_pending()`. `ice_ll_ts_intr()` must hold `pf->ptp.port.tx.lock` (`spin_lock_irqsave`) and check `tx->init` before accessing `tx->in_use` or timestamp helpers. [F179, F185, F309]
- In `ice_nvm.c`, when `!hw->flash.blank_nvm_mode`, `ice_read_flash_module()`, `ice_read_sr_word()`, `ice_discover_flash_size()`, and `ice_nvm_validate_checksum()` must hold `ICE_NVM_RES_ID` via `ice_acquire_nvm()` / `ice_release_nvm()`. [F201]

## Object Lifetimes

- In `ice_probe()`, if `is_kdump_kernel()`, save PCI state, run `pci_clear_master()` and `pcie_flr()`, and restore state before `pcim_enable_device()`; set `ICE_DOWN` and `ICE_SERVICE_DIS` before HW init/IRQs; call `ice_init_supported_rxdids()` after `ice_load_pkg()` and always include `BIT(ICE_RXDID_LEGACY_1)`. `ice_init_devlink()` must register devlink before `ice_health_init()`, and `ice_deinit_devlink()` must deinit health before unregistering devlink. [F195, F286, F295, F299]
- `ice_service_task_stop()` must set `ICE_SERVICE_DIS` before `timer_delete_sync(&pf->serv_tmr)` and `cancel_work_sync(&pf->serv_task)`, then clear `ICE_SERVICE_SCHED`. `ice_remove()` must call `ice_service_task_stop()` and `ice_aq_cancel_waiting_tasks()` before `ice_unload()`/`ice_deinit()`, and if `ice_is_recovery_mode(&pf->hw)` is true, return right after stopping `serv_task` and calling `ice_deinit_devlink()`. [F172, F184, F196]
- `ice_suspend()` must stop `serv_task`, deinit RDMA, run `ice_prepare_for_shutdown()`, and free MSI-X IRQs, `q_vectors`, and the interrupt scheme (`ice_clear_interrupt_scheme()`); `ice_resume()` must restore them via `ice_reinit_interrupt_scheme()`, `ice_init_rdma()`, and `ice_schedule_reset(pf, ICE_RESET_PFR)`. [F300]
- `ice_ena_misc_vector()` must zero `PFINT_OICR_ENA`, read `PFINT_OICR`, and set `GL_MDCK_TX_TDPU_RCU_ANTISPOOF_ITR_DIS_M` before enabling `PFINT_OICR_ENA`. `ice_free_irq_msix_misc()` must call `ice_dis_ctrlq_interrupts()`, zero `PFINT_OICR_ENA`, `ice_flush()`, `synchronize_irq()`, and `devm_free_irq()` before `ice_free_irq()`. [F287, F288]
- Callers of `ice_down()` must set `ICE_VSI_DOWN` first; `ice_down()` must call `ice_vsi_dis_irq()` (which disables `QINT_RQCTL`, zeroes `GLINT_DYN_CTL`, flushes, and calls `synchronize_irq()` only when `vsi->type != ICE_VSI_VF`), stop HW rings, and run `ice_napi_disable_all()` (which must call `napi_disable()` and `cancel_work_sync()` on both `tx.dim.work` and `rx.dim.work`) before cleaning rings. [F198, F199, F318]
- `ice_destroy_xdp_rings()` must call `synchronize_rcu()` before `ice_free_tx_ring()` when `desc` is non-NULL, and free `ring_stats` and `xdp_rings[i]` via `kfree_rcu()`; when `cfg_type == ICE_XDP_CFG_PART`, skip `ice_unmap_xdp_rings()` and return before clearing `xdp_prog`, `num_xdp_txq`, or updating Tx scheduler. `ice_vsi_release_all()` must skip `ICE_VSI_CHNL` VSIs. In `ice_indr_setup_tc_block()`, `FLOW_BLOCK_BIND` transfers `indr_priv` ownership to `flow_block_cb` on success, or must `list_del()` and `kfree(indr_priv)` if `flow_indr_block_cb_alloc()` fails. [F168, F176, F177, F190]

## API Contracts

- `ice_hw_to_dev()` uses `container_of(hw, struct ice_pf, hw)` and dereferences `pf->pdev->dev`, so `hw` must be embedded in an initialized `struct ice_pf`. `ice_aq_wait_for_event()` requires a prior `ice_aq_prep_for_event()` call before sending the AQ command, and `ice_aq_check_events()` only copies `msg_buf` if `task_ev->msg_buf` is non-NULL with `buf_len >= event->buf_len`. [F211, F247, F284]
- `ice_xdp_setup_prog()` and `ice_change_mtu()` must reject `mtu + ICE_ETH_PKT_HDR_PAD > ice_max_xdp_frame_size(vsi)` when `prog && !prog->aux->xdp_has_frags`. `ice_vlan_rx_add_vid()` and `ice_vlan_rx_kill_vid()` must return 0 when `vid == 0`. `ice_init_phy_user_cfg()` must only call `ice_init_phy_cfg_dflt_override()` when `!ice_fw_supports_report_dflt_cfg(pi->hw)` and `ICE_LINK_OVERRIDE_EN` is set. [F296, F325, F327]
- `ice_fix_features()` must clear STAG Rx/Tx offloads if CTAG is requested, and in DVM (`ice_is_dvm_ena()`) keep CTAG and STAG filtering synced; `ice_set_vlan_features()` and `ice_set_features()` must reject `NETIF_F_RXFCS` with `NETIF_VLAN_STRIPPING_FEATURES` (`-EIO`); `ice_set_features()` must reject clearing `NETIF_F_HW_TC` while `ice_is_adq_active(pf)` (`-EACCES`) and on `ICE_F_GCS` devices reject simultaneous `NETIF_F_HW_CSUM` and `NETIF_F_ALL_TSO` (`-EIO`). [F329, F330, F331]
- In `ice_nvm.c`: `ice_read_sr_word*()`, `ice_read_nvm_module()`, `ice_read_nvm_sr_copy()`, and `ice_read_netlist_module()` take word offsets, whereas `ice_read_flat_nvm()`, `ice_read_flash_module()`, and `ice_aq_{read,update}_nvm()` take byte offsets/lengths. `ice_get_flash_bank_offset()` returns `0` on error (callers must check `!start`). `ice_read_flat_nvm()` bounds Shadow RAM reads to `sr_words * 2u`, chunks reads within 4 KB (`ICE_AQ_MAX_BUF_LEN`) and 4 KB sector boundaries (`last_cmd` on final chunk), and overwrites `*length` with `bytes_read` (loop callers must reset `*length`). `ice_aq_{read,update}_nvm()` must reject `offset > ICE_AQC_NVM_MAX_OFFSET` (`-EINVAL`). `ice_nvm_pass_component_tbl()` must follow `ice_nvm_set_pkg_data()`, both setting `LIBIE_AQ_FLAG_RD`. [F205, F206, F207, F269, F303, F306]
- In `ice_parser.c`: `ice_parser_create()`, `ice_parser_create_table()`, and `ice_xlt_kb_get()` return `ERR_PTR` (check `IS_ERR()`). `ice_parser_create_table()` must pass `no_offset = true` for Boost TCAM, Boost label, and Marker PType sections. `ice_parser_sect_item_get()` must keep `u32 __maybe_unused *offset` and use `ICE_SEC_LBL_DATA_OFFSET` (2) for `ICE_SID_LBL_RXPARSER_TMEM` vs `ICE_SEC_DATA_OFFSET` (4). `ice_parser_run()` must call `ice_parser_rt_reset()` and `ice_parser_rt_pktbuf_set()` before `ice_parser_rt_execute()`. Loop callers of `ice_bst_tcam_search()` must increment `*start` after each match. [F208, F233, F237, F238, F257, F285]

## Error Handling

- In `ice_prepare_xdp_rings()`, failure after `ice_map_xdp_rings()` must call `ice_unmap_xdp_rings(vsi)`, clear `avail_txqs`/`txq_map` under `avail_q_mutex`, and set `vsi->xdp_rings = NULL` after freeing. In `ice_xdp_setup_prog()`, failure after `ice_down(vsi)` must jump to `resume_if` (`ice_up(vsi)`). In `ice_init_tx_topology()`, convert all non-`-ENODEV` errors from `ice_cfg_tx_topo()` to `0`. In `ice_suspend()`, only call `ice_service_task_restart()` on early exit if `!disabled`. In `ice_vsi_sync_fltr()`, clear `-EEXIST` from `ice_fltr_add_mac_list()` or `ice_set_dflt_vsi()` to `0`. [F165, F166, F169, F174, F252]

## External Contracts

- `ice_pci_tbl` must be `const`, place `PCI_ANY_ID` after specific entries, and end with `{}`; `ice_probe()` must reject `pdev->is_virtfn` with `-EINVAL`. In `ice_fdb_add()`, clear `-EEXIST` from `dev_{uc,mc}_add_excl()` to `0` unless `flags & NLM_F_EXCL`. [F298, F328]

## Known Pitfalls

- In `ice_chnl_cfg_res()` and `ice_remove_q_channels()`, index rings from the parent VSI (`vsi->tx_rings[ch->base_q + i]`), not `ch->ch_vsi`; in `ice_set_tx_maxrate()`, read `q_handle` and `tc` from the main VSI before `vsi = ice_locate_vsi_using_queue()`. Use `div_u64()` and `iter_div_u64_rem()` for u64 mqprio rates. In `ice_features_check()`, only compute `skb_inner_network_header(skb) - skb_transport_header(skb)` when `gso` and `gso_type & (SKB_GSO_GRE | SKB_GSO_UDP_TUNNEL)`. In `ice_set_dflt_mib()`, advance `tlv` by `(char *)tlv + sizeof(tlv->typelen) + len`. In `ice_set_wake()`, write `U32_MAX` to `PFPM_WUS` first. Use `check_add_overflow()` for u16 TLV offsets in `ice_get_pfa_module_tlv()`, and validate `pba_tlv_len >= pba_size` and `pba_num_size >= pba_size * 2 + 1` in `ice_read_pba_string()`. [F242, F243, F262, F263, F271, F280, F301, F335]
