# ETHERNET PHY LIBRARY — (top level)

Contains the SFP state machine and bus (`sfp.c`, `sfp-bus.c`, `sfp.h`), Realtek, SMSC, Vitesse, STE10Xp, Teranetics, uPD60620, and Xilinx GMII2RGMII PHY drivers, `swphy.c`, `net/core/of_net.c`, and phylib/MDIO/MII headers (`phy.h`, `mdio.h`, `mii.h`).

## Architecture & Data Flow

- In `sfp-bus.c`, `sfp_upstream_start()`/`stop()` must update `bus->started` regardless of `bus->registered`, while `sfp_register_bus()`/`sfp_unregister_bus()` check `bus->started` to call `socket_ops->start()`/`stop()`. Socket-to-upstream helpers must fetch `upstream_ops` via `sfp_get_upstream_ops(bus)` and null-check callbacks; `sfp_upstream_start()`, `sfp_upstream_stop()`, and `sfp_upstream_set_signal_rate()` must check `bus->registered` before dereferencing `bus->socket_ops`. [F544, F572]
- In `__sfp_sm_event()`, call `sfp_sm_device()`, `sfp_sm_module()`, `sfp_sm_main()` in that order. Adding any enumerator to `SFP_MOD_*`, `SFP_DEV_*`, `SFP_E_*`, or `SFP_S_*` requires a matching entry in `mod_state_strings[]`, `dev_state_strings[]`, `event_strings[]`, or `sm_state_strings[]`. [F578, F597]
- In `sfp_check_state()`, OR `sfp->state & SFP_F_OUTPUTS` (`SFP_F_TX_DISABLE | SFP_F_RS0 | SFP_F_RS1`) into `sfp_get_state(sfp)` before assigning `sfp->state` under `sfp->st_mutex`. In `sfp_gpio_set_state()`, drive `GPIO_TX_DISABLE`, `GPIO_RS0`, and `GPIO_RS1` (`GPIOD_ASIS`) via `gpiod_direction_output()` only when `state & SFP_F_PRESENT` and their bit in `sfp->state_hw_drive` are set; otherwise use `gpiod_direction_input()`. [F569, F642]
- In `sfp_sm_mod_probe()` and `sfp_sm_module()`, reset per-module fields (`i2c_block_size`, `module_t_start_up`, `module_t_wait`, `phy_t_retry`, `state_ignore_mask`, `state_hw_mask`) before `sfp->quirk->fixup(sfp)` and schedule `sfp->poll` after updating `state_hw_mask`. In `sfp_cotsworks_fixup_check()`, modifying `id->base` in EEPROM requires recomputing `sfp_check(&id->base, sizeof(id->base) - 1)` and writing it to `SFP_CC_BASE`. [F570, F573]
- `sfp_i2c_read()` must chunk transfers to `<= sfp->i2c_block_size`, advancing `dev_addr` and `buf`. `sfp_hwmon_probe()` must skip hwmon registration when `sfp->i2c_block_size < 2`. In `sfp_sm_link_check_los()`, `sfp_los_event_active()`, and `sfp_los_event_inactive()`, mask `sfp->id.ext.options` with `los_inverted | los_normal` and compare for equality against a single flag rather than bitwise AND. [F582, F583, F593]
- Realtek (`realtek_main.c`, `realtek_hwmon.c`): access `priv->phycr2` and `RTL8211F_CLKOUT_EN` only when `priv->has_phycr2`; cache `priv->iner` in `rtl8211f_config_intr()` so `rtl8211f_resume()` restores it after `rtl8211f_suspend()` writes `RTL8211F_INER_PME`; in `rtl8211f_probe()`, call `device_set_wakeup_capable()`/`devm_pm_set_wake_irq()` only when both `"wakeup-source"` and `phy_interrupt_is_valid(phydev)` are true; in `rtl8211f_led_hw_control_set()`/`rtl8211e_led_hw_control_set()`, use paged RMW with masks shifted by `SHIFT * index` and preserve `RTL8211F_LEDCR_MODE`; in `rtl822x_hwmon_get_temp()`, sign-extend 10-bit `raw` (`if (raw >= 512) raw -= 1024;`). [F548, F566, F567, F592, F633]
- SMSC (`smsc.c`): null-check `phydev->priv` in `smsc_phy_config_init()`, `lan87xx_read_status()`, and `smsc_phy_get/set_edpd()`. EDPD defaults off when `phydev->irq != PHY_POLL`; `smsc_phy_set_edpd()` must reject TX wake-up intervals (`edpd` other than `DISABLE`/`NO_TX`) with `-EOPNOTSUPP` when `phydev->irq != PHY_POLL`, validate non-special `edpd` in `[PHY_STATE_MACH_MS, PHY_STATE_MACH_MS + 1000]` before subtracting `PHY_STATE_MACH_MS`, and set `priv->edpd_mode_set_by_user = true` so `smsc_phy_config_init()` checks `!priv->edpd_mode_set_by_user` before clearing `priv->edpd_enable`. [F549, F564, F614, F630]
- In `lan87xx_phy_config_init()` and `lan87xx_config_aneg()`, always set `SPECIAL_CTRL_STS_OVRRD_AMDIX_`, and set `phydev->mdix_ctrl = ETH_TP_MDI_AUTO` when enabling Auto-MDIX in `lan87xx_phy_config_init()`. When `phydev->autoneg == AUTONEG_DISABLE` and `phydev->mdix_ctrl == ETH_TP_MDI_AUTO` in `lan87xx_config_aneg()`, program fixed `ETH_TP_MDI` into `SPECIAL_CTRL_STS` and `phydev->mdix` without overwriting `phydev->mdix_ctrl`. In `lan874x_set_wol()`, reject `WAKE_ARP | WAKE_MCAST` and update `priv->wol_arp`. [F562, F563, F565, F629]
- In `xgmiitorgmii_probe()`, store `priv` on `&priv->phy_dev->mdio` (not `mdiodev`), save `priv->phy_dev->drv` in `priv->phy_drv`, copy `struct phy_driver` into `priv->conv_phy_drv` before overriding `.read_status`/`.set_loopback`, point `priv->phy_dev->drv` at `&priv->conv_phy_drv`, and delegate through `priv->phy_drv`. In `swphy.c`, every `speed[]` entry must set both duplex bits and every `duplex[]` entry must set all speed bits. [F568, F574, F602]
- Headers: check `pdn->upstream_type` before accessing `phy_device_node::upstream`; check `mdiodev->flags & MDIO_DEVICE_FLAG_PHY` before downcasting `mdio_device` to `phy_device`; keep `mdio_bus_stats` fields as `u64_stats_t` above `syncp` (last); update `phy_modes()` with `enum phy_interface_t`; update `phy_interrupt_is_valid()` with negative IRQ sentinels; update both `#if IS_ENABLED(CONFIG_PHYLIB)` and `#else` blocks in `phylib_stubs.h`. [F547, F575, F576, F577, F618, F624]

## Synchronization

- In `sfp.c`, lock order is `rtnl_lock` -> `sfp->sm_mutex` -> `sfp->st_mutex`: callers of `sfp_sm_event()`/`__sfp_sm_event()` hold `rtnl_lock` outside `sfp->sm_mutex`, and `sfp_get_state()`, `sfp_set_state()`, and updates to `state_hw_drive`, `state_hw_mask`, `state_soft_mask`, and `sfp->state` output bits after `sfp_probe()` require `sfp->st_mutex`. Never call `cancel_delayed_work_sync()` on `sfp->timeout` or `sfp->poll` under `RTNL` or `sfp->sm_mutex`; use `cancel_delayed_work()` via `sfp_sm_set_timer()`. [F527, F650, F651]
- In `sfp-bus.c`, modifying `upstream_ops`, `upstream`, `sfp_dev`, `sfp`, `socket_ops`, and `registered` on `struct sfp_bus` requires `rtnl_lock()`. `sfp_buses` list operations use `sfp_mutex` via `kref_put_mutex(&bus->kref, sfp_bus_release, &sfp_mutex)`, so `sfp_bus_release()` must call `mutex_unlock(&sfp_mutex)`. `phylib_stubs.h` helpers require `rtnl_lock` (`ASSERT_RTNL()`). Unlocked helpers (`__phy_read()`, `__phy_write()`, `__phy_modify()`, `__mdiobus_c45_*()`) and `.read_page`/`.write_page`/`.read_mmd`/`.write_mmd` callbacks require `mdio_lock` held and must not call locking `phy_read()`/`phy_write()`. [F532, F533, F655, F656]

## Object Lifetimes

- In `sfp_bus_find_fwnode()`, call `fwnode_handle_put(ref.fwnode)` on both the unavailable-device return and after `sfp_bus_get()`; callers release the returned bus via `sfp_bus_put()`. If `sfp_register_bus()` fails in `sfp_bus_add_upstream()` or `sfp_register_socket()`, call `sfp_upstream_clear()`/`sfp_socket_clear()` before `rtnl_unlock()` and `sfp_bus_put()` after `rtnl_unlock()`. `sfp_unregister_bus()` tears down in reverse order: `upstream_ops->detach`, `socket_ops->stop` (if `started`), `socket_ops->detach`, `ops->disconnect_phy` (if `phydev`), and clears `registered`. [F511, F512, F513]
- `sfp_sm_probe_phy()` rolls back `phy_device_register()` + `sfp_add_phy()` with `phy_device_remove()` and `phy_device_free()`; `sfp_sm_phy_detach()` runs `sfp_remove_phy`, `phy_device_remove`, `phy_device_free`, and sets `sfp->mod_phy = NULL`. When `sfp_sm_main()` leaves an active state (`sm_mod_state != SFP_MOD_PRESENT` or `sm_dev_state != SFP_DEV_UP`), call `sfp_sm_phy_detach()` before `sfp_i2c_mdiobus_destroy()` (which sets `sfp->i2c_mii = NULL`). [F515, F516]
- In `sfp_sm_module()`, `SFP_E_REMOVE` must unconditionally call `sfp_sm_mod_remove()` so `sfp_hwmon_remove()` always runs, while `sfp_sm_mod_remove()` only calls `sfp_module_remove()` when `sm_mod_state > SFP_MOD_WAITDEV` (and `SFP_MOD_HPOWER` calls `sfp_module_remove()` before `SFP_MOD_ERROR`). `sfp_hwmon_remove()` must call `cancel_delayed_work_sync(&sfp->hwmon_probe)` before checking `!IS_ERR_OR_NULL(sfp->hwmon_dev)`, unregistering it, setting `sfp->hwmon_dev = NULL`, and freeing `sfp->hwmon_name`. [F517, F518]
- In `sfp_probe()`, register `devm_add_action_or_reset(sfp->dev, sfp_cleanup, sfp)` before requesting GPIOs or `devm_request_threaded_irq()`. On `sfp_i2c_configure()` failure, set `sfp->i2c = NULL` and have `sfp_i2c_get()` call `i2c_put_adapter(i2c)` and `fwnode_handle_put(h)` so `sfp_cleanup()` does not double-put `sfp->i2c`. [F519, F640]
- In `of_get_mac_address_nvmem()`, release `pdev` with `put_device(&pdev->dev)`, and release `cell` and `mac` with `nvmem_cell_put(cell)` and `kfree(mac)` on all returns. In `xgmiitorgmii_probe()`, call `of_node_put(phy_node)` after `of_phy_find_device()`, and `put_device(&priv->phy_dev->mdio.dev)` if `!priv->phy_dev->drv` or probe fails. In `rtl821x_suspend()`/`resume()`, disable `priv->clk` only when `!phydev->wol_enabled` and `genphy_suspend()` succeeds, and re-enable it in resume only when `!phydev->wol_enabled`. [F520, F521, F523]

## API Contracts

- `sfp_bus_find_fwnode()` returns a refcounted `sfp_bus *`, `NULL` (`-ENOENT`/unavailable), or `ERR_PTR`. `sfp_register_socket()` returns `NULL` on error; `sfp_alloc()` returns `ERR_PTR`. `sfp_get_name()` requires RTNL and is valid only until `rtnl_unlock()`. `sfp_register_bus()`/`sfp_unregister_bus()` require non-NULL `upstream_ops->attach`/`detach` and `socket_ops->attach`/`detach`/`start`/`stop`. `sfp_get_module_info/eeprom*()` require a registered socket and buffer `>= ee->len`. `sfp_upstream_set_signal_rate()` takes `rate_kbd` in kBd. `sfp_select_interface()` checks highest to lowest speed with `1000baseT` (`SGMII`) before `1000baseX`. [F514, F537, F538, F595, F657, F658, F660]
- `phy_read*()`/`mdiobus_read*()` return `0..0xffff` as `int` or `< 0` on error; store in signed `int` and check `< 0` before narrowing to `u16`. `*phy_modify*_changed()` return `< 0` on error, `0` if unchanged, and `1` if changed; check `ret < 0`, not `if (ret)`. `swphy_read_reg()` returns `-1` for `reg > MII_REGS_NUM` or `MII_MMD_CTRL`/`DATA`, `0xffff` for unimplemented MII regs, and `0` (`WARN_ON`) if `state->speed` is invalid. Guard `phy_hwtstamp/rxtstamp/ts_info/txtstamp()` with `phy_has_*()`. Call `phy_disable_eee_mode()` only while `phydev->state < PHY_UP`, and `free_mdio_bitbang()` only after `mdiobus_unregister()`. Use `container_of_const()` in MDIO/PHY downcast macros. Pass `>= 3` `u16` elements to `mii_c73_mod_linkmode()`. [F536, F540, F541, F542, F545, F617, F625, F664]
- In `struct phy_driver`: `get_phy_stats`/`get_link_stats` only overwrite supported fields (pre-set to `ETHTOOL_STAT_NOT_SET`), while `get_stats` (`smsc_get_stat`) stores `U64_MAX` on error; `led_blink_set` takes ms, defaults when both are `0`, and writes back actual `*delay_on`/`*delay_off`; do not set both `features` and `get_features`, only set `phydev->supported` in `get_features`, and do not mutate `phydev` in `link_change_notify`. All `struct phy_plca_cfg` fields use `-1` (not `0`) as "not available / don't set". [F555, F556, F662, F663]
- `of_get_phy_mode()` sets `*interface = PHY_INTERFACE_MODE_NA` on error; `of_get_ethdev_address()` only calls `eth_hw_addr_set()` when `of_get_mac_address()` returns `0`; `of_get_mac_addr()` and `of_get_mac_address_nvmem()` require `length == ETH_ALEN` and `is_valid_ether_addr()`. When `!CONFIG_OF_MDIO` or `!CONFIG_ACPI_MDIO`, `(devm_)of_mdiobus_register()` and `acpi_mdiobus_register()` fall back to `(devm_)mdiobus_register()`, while `fwnode_mdiobus_register_phy()` returns `-EINVAL` when `!CONFIG_FWNODE_MDIO`. [F553, F580, F675]
- Drivers: in `realtek_main.c`, `RTL822X_VND2_C22_REG(reg)` is for `phydev->is_c45`, while `rtlgen_read/write_vend2()` hardcode PHY address `0` for internal PHYs; `rtl8211x_led_hw_is_supported()` rejects `index >= RTL8211x_LED_COUNT` (3) (`-EINVAL`) and requires `TRIGGER_NETDEV_RX` and `TX` to be both set or both clear (`-EOPNOTSUPP`). In `vitesse.c`, `vsc73xx_get_downshift()` adds `2` to `MII_VSC73XX_PHY_CTRL_EXT3_DOWNSHIFT_CNT`, and `vsc73xx_set_downshift()` rejects `cnt == 1` (`-EINVAL`) and `cnt > 5` (`-E2BIG`) before subtracting `2`. `xgene_enet_set/get_field_value()` require `len` in `[1, 63]`, `pos + len <= 64`, and `1ULL << len`. [F560, F561, F615, F672]

## Error Handling

- Pair every `phy_save_page()` or `phy_select_page()` with `phy_restore_page(phydev, oldpage, ret)` even when `oldpage < 0`, passing both `oldpage` and `ret`. When polling PHY registers with `read_poll_timeout` (`phy_read_poll_timeout`, `phy_read_mmd_poll_timeout`, `lan87xx_read_status`), include `val < 0` in the break condition and check `val < 0` afterward. [F550, F608]
- In `sfp.c`, set `sfp->i2c = NULL` on `sfp_i2c_configure()` failure, set `sfp->gpio_irq[i] = 0` when IRQ setup fails in `sfp_probe()`, and check `!IS_ERR_OR_NULL(sfp->hwmon_dev)` in `sfp_hwmon_remove()`. In `sfp_sm_mod_probe()`, a `cc_base` mismatch on non-Cotsworks modules aborts with `-EINVAL`, whereas a `cc_ext` mismatch zeroes `id.ext` and continues, and `sfp_init_module()` must zero `bus->caps` first. [F551, F554]

## External Contracts

- In `sfp.c`, 16-bit fields in `sfp->id.ext.options` and `struct sfp_diag` are `__be16`, and `sfp_hwmon_calibrate_temp()` must sign-extend `long *value` (`if (*value >= 0x8000) *value -= 0x10000;`) after `sfp_hwmon_calibrate()` and before `DIV_ROUND_CLOSEST(*value * 1000, 256)` (signed `256`). In `sfp_module_parse_support()`, when `id->base.br_nominal == 255` and `id->ext.br_max != 0`, decode `br_nom = 250 * id->ext.br_max` and scale both `br_max` and `br_min` tolerances using `id->ext.br_min`. [F584, F610, F612]
- `sfp_module_eeprom()` and `sfp_module_eeprom_by_page()` return `-ENODEV` when `!(sfp->state & SFP_F_PRESENT)`. `sfp_module_eeprom()` maps `[0, ETH_MODULE_SFF_8079_LEN)` to 0x50 (`a2 = false`) and `[ETH_MODULE_SFF_8079_LEN, ETH_MODULE_SFF_8472_LEN)` to 0x51 (`a2 = true`), subtracting `ETH_MODULE_SFF_8079_LEN` from the offset for the second region. `sfp_module_eeprom_by_page()` rejects non-zero `bank`/`page` or `i2c_address` other than `0x50`/`0x51` with `-EOPNOTSUPP`. `mdio_phy_id_is_c45()` must check `(phy_id & MDIO_PHY_ID_C45) && !(phy_id & ~MDIO_PHY_ID_C45_MASK)`. [F585, F590, F670]

## Known Pitfalls

- `linkmode_*_bit()`, `phy_disable_eee_mode()`, and `phy_remove_link_mode()` take a bit index (`ETHTOOL_LINK_MODE_*_BIT`), whereas `phy_set_bits()`, `phy_clear_bits()`, `phy_modify()`, and `ethtool_adv_to_*()` take shifted masks. `DECLARE_PHY_INTERFACE_MASK` bitmaps (`caps->interfaces`, `possible_interfaces`, `host_interfaces`) must only use `phy_interface_*`/`PHY_INTERFACE_MODE_*` helpers, never `linkmode_*` or `phylink_set()`. `mdiobb_read/write_c45()` take `(bus, int phy, int devad, int reg, ...)` despite swapped `(devad, phy)` parameter names in `mdio-bitbang.h`. [F557, F558, F621]
- In `sfp.c`/`sfp-bus.c`: bound non-NUL-terminated `sfp_eeprom_id` strings with `sfp_strlen(..., ARRAY_SIZE(...))` or `%.*s`; pass `sizeof(id.base) - 1` or `sizeof(id.ext) - 1` to `sfp_check()`; in `sfp_module_parse_rate_select()`, convert `rate_id == 3` to `SFF_RID_8431` before `if (rate_id & SFF_RID_8079)`; in `sfp_module_parse_support()`/`sfp_init_module()`, run `if (linkmode_empty(modes) && br_nom)` before setting `Autoneg`, `Pause`, `FIBRE`, or `TP`; in `sfp_sm_main()`, set `sfp->sm_phy_retries = R_PHY_RETRY` before jumping to `phy_probe`, and check `timeout > sfp->module_t_wait` in `SFP_S_WAIT` before subtracting `module_t_wait` from `module_t_start_up` (clamping to `1`). [F581, F594, F596, F599, F609, F620]
- In `lan874x_chk_wol_pattern()`, the inner `for (j = 0; j < 16; j++, i++, len--)` loop must `if (!len) break;` before `len--` runs in the header. In `vsc82xx_config_intr()`, read `MII_VSC8244_ISTAT` before writing `0` to `MII_VSC8244_IMASK` when disabling interrupts, and do not ACK before unmasking when enabling. On Realtek internal PHYs, `rtl8226/8221b/internal_nbaset_match_phy_device()` must check `rtlgen_supports_mmd()`, and `rtlgen/rtl822x_read_mmd()` must redirect to `__mdiobus_c45_read` at address `0`. Callers of `swphy_read_reg()` must set `state->speed` to `10`, `100`, or `1000` even when `state->link == 0`. [F607, F628, F635, F667]
