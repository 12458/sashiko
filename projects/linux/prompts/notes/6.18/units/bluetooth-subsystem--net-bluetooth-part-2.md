# BLUETOOTH SUBSYSTEM — net/bluetooth (part 2)

This component implements Bluetooth HCI event packet processing (`hci_event.c`) and the `PF_BLUETOOTH`/`BTPROTO_HCI` socket layer (`hci_sock.c`).

## Architecture & Data Flow
- `hci_ev_table` and `hci_le_ev_table` entries must use designated `[op]` macros (`HCI_EV*`/`HCI_LE_EV*`). `struct hci_ev` unions `func` and `func_req` via `ev->req`; `hci_event_func()` must check `!ev->func` and branch on `ev->req` (`HCI_EV_REQ*`). Fixed-length `hci_cc_table` entries with fields after `status` must use `HCI_CC(..., sizeof(struct hci_rp_...))`, not `HCI_CC_STATUS`. [F46, F64, F67]
- In `hci_cmd_complete_evt`, if `ev->opcode` misses `hci_cc_table`, initialize `*status = skb->data[0]` before `hci_req_cmd_complete`. When matching `hdev->req_skb` by `hci_skb_event`, `hci_event_packet` requires `hci_opcode_ogf(...) != 0x08` while `hci_le_meta_evt` requires OGF `0x08` (or `HCI_OP_NOP`). [F87, F94]
- Before accessing `conn->iso_qos.ucast` (unioned with `bcast`), handlers (`hci_unbound_cis_failed()`, `hci_le_cis_established_evt()`) must verify `conn->type == CIS_LINK`. In `hci_le_big_info_adv_report_evt`, set `pa_sync->iso_qos.bcast.encryption = ev->encryption` before `hci_connect_cfm(pa_sync, 0)`. [F42, F52]
- In `hci_le_big_sync_established_evt`, on `!ev->status`, each `bis` in the `ev->num_bis` loop requires `bis->state = BT_CONNECTED`, `HCI_CONN_PA_SYNC` and `HCI_CONN_BIG_SYNC` in `bis->flags`, `bis->sync_handle = conn->sync_handle`, `iso_qos` set, and `hci_debugfs_create_conn(bis)` + `hci_conn_add_sysfs(bis)` before `hci_iso_setup_path(bis)`, while `HCI_CONN_CREATE_BIG_SYNC` is updated on parent `conn`. [F47, F98]
- In `hci_le_big_sync_lost_evt`, `hci_disconn_complete_evt`, and `hci_cs_disconnect`, pass `test_and_clear_bit(HCI_CONN_MGMT_CONNECTED, &conn->flags)` to `mgmt_device_disconnected` before `hci_conn_del`. In `hci_cs_disconnect`, if `hdev->suspended`, do not wait for `HCI_EV_DISCONN_COMPLETE` even on `!status`; set `conn->state = BT_CLOSED` and run `mgmt_device_disconnected`, `hci_disconn_cfm`, and `hci_conn_del`. [F49, F50]
- In `le_set_scan_enable_complete`, `LE_SCAN_ENABLE` only calls `clear_pending_adv_report` and `hci_discovery_set_state(hdev, DISCOVERY_FINDING)` when `hdev->le_scan_type == LE_SCAN_ACTIVE`; `LE_SCAN_DISABLE` cancels `hdev->le_scan_disable` and flushes pending reports via `mgmt_device_found`. In `hci_cc_le_set_adv_set_random_addr`, only update `adv->random_addr` when `cp->handle != 0`. When disabling/terminating one ext adv set (`hci_cc_le_set_ext_adv_enable` with `cp->num_of_sets != 0`, `hci_le_ext_adv_term_evt`), do not clear `HCI_LE_ADV` if any `adv` in `hdev->adv_instances` has `adv->enabled`. [F53, F58, F59]
- In `hci_cc_read_buffer_size` and `hci_cc_le_read_buffer_size{,_v2}`, setting `*_pkts` must initialize matching `*_cnt`; reject `!hdev->acl_mtu || !hdev->acl_pkts` and `hdev->le_mtu && hdev->le_mtu < HCI_MIN_LE_MTU` with `HCI_ERROR_INVALID_PARAMETERS`. In `hci_num_comp_pkts_evt` and `hci_cc_delete_stored_link_key`, clamp `conn->sent` and `hdev->stored_num_keys` to 0 on underflow, and clamp `hdev->*_cnt` to `hdev->*_pkts`. [F54, F70, F103]
- Check `page < HCI_MAX_PAGES` before indexing `hdev->features[page]` (`hci_cc_read_local_ext_features`) or `conn->features[page]` (`hci_remote_ext_features_evt`). Quirk/state gates: skip `hdev->max_page = rp->max_page` under `HCI_QUIRK_BROKEN_LOCAL_EXT_FEATURES_PAGE_2`; mask `primary_phy`/`secondary_phy` with `0x1f` under `HCI_QUIRK_FIXUP_LE_EXT_ADV_REPORT_PHY` in `hci_le_ext_adv_report_evt`; in `hci_encrypt_change_evt`, only send `HCI_OP_WRITE_AUTH_PAYLOAD_TO` when `!HCI_QUIRK_BROKEN_WRITE_AUTH_PAYLOAD_TIMEOUT`, `HCI_CONN_ENCRYPT`, `HCI_CONN_AES_CCM`, and Ping support (`lmp_ping_capable` or `HCI_LE_PING`); in `check_pending_le_conn`, abort if `hdev->suspended` or (`le_num_peripheral > 0` and (`HCI_QUIRK_BROKEN_LE_STATES` or `!(hdev->le_states[3] & 0x10)`)). [F71, F113, F114, F115, F116]
- In `hci_event_packet()`, call `hci_store_wake_reason()` after `skb_pull(skb, HCI_EVENT_HDR_SIZE)` and before `hci_event_func()`, updating `wake_reason`/`wake_addr` under `hci_dev_lock(hdev)` only when `hdev->suspended && !hdev->wake_reason`. [F118]
- `hci_pi(sk)` casts `struct sock *` to `struct hci_pinfo *`, requiring `struct bt_sock bt` first in `struct hci_pinfo` and allocation via `hci_sk_proto`. In `hci_sock_bind`, if `hci_sock_gen_cookie(sk)` returns false (`HCI_CHANNEL_RAW`/`USER`/`CONTROL`), call `create_monitor_ctrl_close(sk)` before updating `hci_pi(sk)->hdev` and calling `create_monitor_ctrl_open(sk)`. [F62, F109]
- `is_filtered_packet` returns `true` to drop and `false` to pass, returning `false` after `flt->type_mask` for non-`HCI_EVENT_PKT` and after `flt->event_mask` when `!flt->opcode`. Mask bit indices passed to `test_bit`/`hci_test_bit` in `is_filtered_packet` and `hci_sock_sendmsg` with `HCI_FLT_TYPE_BITS`, `HCI_FLT_EVENT_BITS`, or `HCI_FLT_OCF_BITS` (with `ogf <= HCI_SFLT_MAX_OGF`). [F86, F100]
- `hci_mgmt_cmd()` and `hci_logging_frame()` must check `skb->len >= sizeof(*hdr)` (or `+ 3`) before subtracting `sizeof(*hdr)`. `hci_mgmt_cmd()` checks `__le16_to_cpu(hdr->len) == skb->len - sizeof(*hdr)`, `opcode < chan->handler_count`, and `len` vs `handler->data_len` (`>=` if `HCI_MGMT_VAR_LEN`, else `==`). `hci_logging_frame()` checks `hdr->len`, `hdr->opcode == 0`, `priority <= 7`, `ident_len <= skb->len - sizeof(*hdr) - 3`, and NULs at `skb->data[sizeof(*hdr) + ident_len + 1]` and `skb->data[skb->len - 1]`. [F76, F77, F102]

## Synchronization
- `hci_ev_table`, `hci_le_ev_table`, `hci_cc_table`, and `hci_cs_table` callbacks enter unlocked and must release any `hci_dev_lock(hdev)` they take. `check_pending_le_conn`, `process_adv_report`, and `hci_unbound_cis_failed` require `hci_dev_lock(hdev)` held. Because `hci_conn_hash_lookup_*` drops `rcu_read_unlock()` and returns an unreferenced `hci_conn *`, event handlers (e.g., `hci_num_comp_pkts_evt`) must hold `hci_dev_lock(hdev)` across lookup and `hci_conn_tx_dequeue`. [F12, F22, F23]
- Loops deleting from `hdev->conn_hash.list` or `hdev->adv_instances` (`hci_unbound_cis_failed`, `hci_cc_le_clear_adv_sets`) must hold `hdev->lock` and use `list_for_each_entry_safe`. When iterating BIS connections in `hci_le_create_big_complete_evt` or `hci_le_big_sync_lost_evt` to call `hci_debugfs_create_conn` or `hci_conn_del`, hold `hci_dev_lock(hdev)` and loop on `hci_conn_hash_lookup_big_state`, not `list_for_each_entry_rcu`. [F93, F121]
- In `hci_conn_complete_evt` and `le_conn_complete_evt`, verify `conn->state == BT_CONNECT` on any looked-up `HCI_ROLE_MASTER` `hci_conn` before using it. Before `HCI_OP_READ_ENC_KEY_SIZE` in `hci_read_enc_key_size`, pre-populate `conn->enc_key_size` from `hci_conn_key_enc_size(conn)` or `hdev->min_enc_key_size`; in `hci_cc_read_enc_key_size`, if the size is smaller than `hdev->min_enc_key_size` or `*key_enc_size`, clear `HCI_CONN_ENCRYPT` and `HCI_CONN_AES_CCM` and set `status = HCI_ERROR_AUTH_FAILURE`. [F16, F17, F55]
- In `handle_cmd_cnt_and_timer`, check `!test_bit(HCI_RESET, &hdev->flags)` and `!hci_dev_test_flag(hdev, HCI_CMD_DRAIN_WORKQUEUE)` and queue `hdev->ncmd_timer` under `rcu_read_lock()`. In `hci_cc_inquiry_cancel` and `hci_inquiry_complete_evt`, call `smp_mb__after_atomic()` between `clear_bit(HCI_INQUIRY, &hdev->flags)` and `wake_up_bit`. [F28, F29]
- `lock_sock(sk)` nests outside `mgmt_chan_list_lock`, `hdev->lock`, `hci_dev_list_lock`, and `hci_sk_list.lock`; `hci_sock_ioctl` must drop `lock_sock(sk)` before unbound device ioctls (`hci_dev_open`/`close`/`reset`/`cmd`, `hci_inquiry`). Serialize all `mgmt_chan_list` accesses and `hci_mgmt_cmd` under `mgmt_chan_list_lock`. [F127, F128]
- `hci_sock_bind` must finish initializing `hci_pi(sk)` under `lock_sock(sk)` before setting `sk->sk_state = BT_BOUND`. All SKB allocations/clones under `read_lock(&hci_sk_list.lock)` or `read_lock(&hci_dev_list_lock)` in `hci_sock.c` must use `GFP_ATOMIC`. [F15, F126]

## Object Lifetimes
- In `hci_le_big_sync_established_evt`, when `ev->status != 0x42` and `HCI_CONN_PA_SYNC` is set on `bis`, clear `conn->cleanup = NULL` on temporary `PA_LINK` `conn` before deleting it. In `check_pending_le_conn`, implicit auto-connect (`!params->explicit_connect`) takes `params->conn = hci_conn_get(conn)`, which `le_conn_complete_evt` must release via `hci_conn_drop`, `hci_conn_put`, and `params->conn = NULL`. Entering `BT_CONFIG` in `hci_conn_complete_evt` / `le_conn_complete_evt` takes `hci_conn_hold(conn)`, balanced by `hci_conn_drop(conn)` when `BT_CONFIG` ends. [F1, F2, F10]
- Under `hci_dev_lock(hdev)`, unlink debug `struct link_key` (`hci_link_key_notify_evt`) and single-use `SMP_STK` `struct smp_ltk` (`hci_le_ltk_request_evt`) with `list_del_rcu` and free with `kfree_rcu`. [F25]
- `hci_event_packet` frees `skb` at `done:`, so event/CC handlers must never `kfree_skb(skb)`. In `hci_sock.c`, `sock_queue_rcv_skb(sk, skb)` requires `kfree_skb(skb)` on non-zero return; `hci_send_to_sock` and `hci_send_to_monitor` must copy via `__pskb_copy_fclone` before `skb_push`. [F14, F135, F137]
- `hci_sock_dev_event(..., HCI_DEV_UNREG)` only sets `sk->sk_err = EPIPE`; `hci_pi(sk)->hdev` is only cleared/put under `lock_sock(sk)` in `hci_sock_bind` or `hci_sock_release`. Re-binding a socket with `HCI_UNREGISTER` on `hci_pi(sk)->hdev` must clear `hci_pi(sk)->hdev = NULL`, set `sk->sk_state = BT_OPEN`, and `hci_dev_put(hdev)` before checking `BT_BOUND`. [F5, F20]
- If `hci_dev_open` fails (not `-EALREADY`) when binding `HCI_CHANNEL_USER`, `hci_sock_bind` must clear `HCI_USER_CHANNEL`, call `mgmt_index_added(hdev)`, and `hci_dev_put(hdev)`. In `hci_sock_release` for `HCI_CHANNEL_USER`, only call `hci_dev_do_close`, `hci_dev_clear_flag(hdev, HCI_USER_CHANNEL)`, and `mgmt_index_added` if `!hci_dev_test_flag(hdev, HCI_UNREGISTER)`, but always run `atomic_dec(&hdev->promisc)` and `hci_dev_put(hdev)`. Free `hci_pi(sk)->cookie` in `hci_sock_release` via `hci_sock_free_cookie` after `create_monitor_ctrl_close(sk)`. [F4, F9, F119]

## API Contracts
- `hci_hdev_from_sock(sk)` returns a borrowed `hci_dev *` or `ERR_PTR(-EBADFD)`/`ERR_PTR(-EPIPE)` (never NULL); callers must hold `lock_sock(sk)`, check `IS_ERR(hdev)`, and never call `hci_dev_put`. [F7, F30]
- In `hci_sock_sendmsg`, `hci_logging_frame` and `hci_mgmt_cmd` borrow `skb` and jump to `drop:`, whereas `HCI_CHANNEL_RAW`/`USER` queue `skb` to `raw_q`/`cmd_q`. Non-vendor (`ogf != 0x3f`) `HCI_COMMAND_PKT` SKBs from `HCI_CHANNEL_RAW` must set `hci_skb_opcode(skb)` and `bt_cb(skb)->hci.req_flags |= HCI_REQ_START`. [F6, F134]
- In `hci_mgmt_cmd()`, `hdev = hci_dev_get(index)` (when `index != MGMT_INDEX_NONE`) is owned by `hci_mgmt_cmd()` and may be NULL (`HCI_MGMT_NO_HDEV`/`HDEV_OPTIONAL`); check `if (hdev && chan->hdev_init)` and jump to `done:` for `if (hdev) hci_dev_put(hdev)`. Reject handlers without `HCI_MGMT_UNTRUSTED` unless `hci_sock_test_flag(sk, HCI_SOCK_TRUSTED)`. In `hci_sock_ioctl`, check `sk_capable(sk, CAP_NET_ADMIN)` (not `capable`) when setting `HCI_SOCK_TRUSTED`. [F8, F33, F142, F143]
- `hci_event_func()`, `hci_le_meta_evt()`, and `hci_cc_func()` already pull `min_len` (`sizeof(*ev)`), so variable-length handlers must pull trailing data via `hci_{ev,cc,le_ev}_skb_pull()` using `flex_array_size` (not `struct_size`) and check for NULL. `hci_cc_func()` callbacks return `u8` HCI status (`0` or `HCI_ERROR_*`), never negative errno. Always NULL-check `hci_sent_cmd_data()`. [F37, F38, F39, F66, F105]
- `hci_conn_add{,_unset}()` and `hci_connect_le()` return `ERR_PTR` on failure (check `IS_ERR`), whereas `hci_conn_hash_lookup_*()` returns NULL. Connection-complete handlers must abort `hci_debugfs_create_conn()` and `hci_conn_add_sysfs()` if `!HCI_CONN_HANDLE_UNSET(conn->handle)` or `hci_conn_set_handle()` returns non-zero. [F40, F43]

## Error Handling
- Use `copy_safe_from_sockptr()` (not `copy_from_sockptr()`) in `hci_sock_setsockopt{,_old}()`. In `check_pending_le_conn()`, check `!IS_ERR(conn)` on `hci_connect_le()` before `hci_conn_get(conn)` and return NULL on error. In `hci_cs_disconnect`, `HCI_ERROR_UNKNOWN_CONN_ID` must take the normal disconnect path, not `mgmt_disconnect_failed`. In `hci_event_func`/`hci_le_meta_evt`/`hci_cc_func`, reject `skb->len < min_len` with `bt_dev_err`, but on `skb->len > max_len` only warn and still invoke the handler. [F31, F41, F89, F144]

## External Contracts
- In `hci_le_cis_established_evt()`, compute `qos->ucast.{in,out}.interval` as `(cig_sync_delay + ft * le16_to_cpu(ev->interval) * 1250) - latency`, convert `latency` with `DIV_ROUND_CLOSEST(..., 1000)`, map `c_*`/`p_*` by `conn->role`, and set `sdu = 0` when `c_bn`/`p_bn` is `0`. `hci_inquiry_result_with_rssi_evt()` must match `skb->len` against `array_size(ev->num, ...)` for both `inquiry_info_rssi_pscan` and `inquiry_info_rssi`. [F44, F51, F74]
- Zero-init stack `struct sockaddr_hci haddr` in `hci_sock_bind()` (copying `min_t(..., sizeof(haddr), addr_len)`) and `struct hci_ufilter uf` in `hci_sock_getsockopt_old()`. Test/copy `hci_sec_filter` and `hci_filter` masks as 32-bit `u32` words via `hci_test_bit`. `hci_sock_compat_ioctl()` passes `HCIDEVUP`/`DOWN`/`RESET`/`RESTAT` `arg` directly and wraps pointer ioctls in `compat_ptr(arg)`. `hci_sock_cmsg` emits `old_timeval32` for `MSG_CMSG_COMPAT` when `!COMPAT_USE_64BIT_TIME`. Reject `BT_SNDMTU`/`BT_RCVMTU` with `-ENOPROTOOPT` on `HCI_CHANNEL_RAW`/`USER`. [F34, F36, F81, F129, F139, F140]

## Known Pitfalls
- Clone `orig_skb = skb_clone(skb, GFP_KERNEL)` in `hci_event_packet` before `skb_pull(skb, HCI_EVENT_HDR_SIZE)` when `req_complete_skb` is set or `event` is `HCI_EV_CMD_STATUS`/`COMPLETE`. Zero trailing `sizeof(cp.ltk) - ltk->enc_size` bytes of `cp.ltk` in `hci_le_ltk_request_evt()`, bound `ev->name` with `strnlen(..., HCI_MAX_NAME_LENGTH)` in `hci_remote_name_evt`, and use `get_unaligned_le16()` on raw `hci_sent_cmd_data()` offsets. [F45, F57, F73, F111]
- In `hci_le_{ext_}adv_report_evt`, pull `sizeof(*info)` then `info->length + 1` (legacy) or `info->length` (ext) per report. In `ext_evt_type_to_legacy`, mask out `LE_EXT_ADV_DATA_STATUS_MASK` before testing `!evt_type`, and check `LE_EXT_ADV_DIRECT_IND` before returning `LE_ADV_IND`. In `process_adv_report`, gate `direct_addr` RPA/IRK checks on `!HCI_MESH && direct_addr && HCI_PRIVACY`, and keep `!ext_adv` on the inner `store_pending_adv_report` check, not the outer `!has_pending_adv_report` branch. [F82, F83, F84, F106]
- In `hci_user_confirm_request_evt`, jump to `confirm` with `confirm_hint = 1` if `(!test_bit(HCI_CONN_AUTH_PEND, &conn->flags) && conn->io_capability != HCI_IO_NO_INPUT_OUTPUT)` or `hci_find_link_key` matches. In `hci_num_comp_pkts_evt`, handle `SCO_LINK`+`ESCO_LINK` for `sco_cnt`, `CIS_LINK`+`BIS_LINK`+`PA_LINK` for `iso_cnt`, and `acl_cnt` fallback for `LE_LINK` when `!hdev->le_pkts`. Fall back to `ESCO_LINK` lookup (setting `conn->type = SCO_LINK`) when `SCO_LINK` lookup misses in `hci_{sync_}conn_complete_evt`. [F85, F88, F92]
- Guard `hci_conn_params_lookup` and `hci_update_passive_scan` with `conn->type == LE_LINK` (and `HCI_AUTO_CONN_LINK_LOSS` with `ev->reason == HCI_ERROR_CONNECTION_TIMEOUT`) in `hci_disconn_complete_evt`. In `hci_cc_le_set_cig_params`, verify `rp->num_handles == cp->num_cis` and `rp->cig_id == cp->cig_id` before indexing `cp->cis[i]`, failing only unbound CIS via `hci_unbound_cis_failed`. In `hci_sock_copy_creds`, reassign `sk = bt_sk(sk)->parent` when `!sk->sk_peer_pid` and parent has `sk_peer_pid`. [F90, F95, F99]
