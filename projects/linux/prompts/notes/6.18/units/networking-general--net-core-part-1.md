# NETWORKING [GENERAL] — net/core (part 1)

Core networking subsystem implementing `net_device` lifecycle, TX/RX datapaths (`__dev_queue_xmit`, `netif_receive_skb`, NAPI), device adjacency graphs, XDP (`net/core/dev.c`), datagram socket `iov_iter` ops (`net/core/datagram.c`), and BPF socket storage (`net/core/bpf_sk_storage.c`).

## Architecture & Data Flow

- `__netif_receive_skb_core()` walks `ptype_all` before protocol handlers, flushes/NULLs `pt_prev` via `deliver_skb()` before `sch_handle_ingress()`, `nf_ingress()`, `vlan_do_receive()`, or `rx_handler(&skb)`, and keeps `*pskb` non-NULL whenever `*ppt_prev` is non-NULL; if `skb_pfmemalloc(skb)`, skip `ptype_all` and drop (`SKB_DROP_REASON_PFMEMALLOC`) unless `skb_pfmemalloc_protocol(skb)`. `__netif_receive_skb_list_core()` calls `skb_list_del_init(skb)` first and flushes `sublist` via `__netif_receive_skb_list_ptype()` when `pt_curr != pt_prev || od_curr != orig_dev`. [F436, F483, F485, F574]
- Query XDP programs via `dev_xdp_prog(dev, mode)` (`xdp_state[mode].link` and `.prog` are mutually exclusive). In `generic_xdp_install()`, changing `dev->xdp_prog` from `NULL` to non-`NULL` increments `generic_xdp_needed_key` and calls `netif_disable_lro()` and `dev_disable_gro_hw()` (decrementing on removal). `bpf_prog_run_generic_xdp()` samples `orig_data*`/`orig_eth_type`/`orig_host`/`orig_bcast` before `bpf_prog_run_xdp()` and refreshes `skb` pointers, `data_len` (`xdp_frags_size`), and `eth` afterward. `tc_run()` resets `tc_skb_cb(skb)->mru = 0` and `post_ct = false` and sets `tcf_set_drop_reason()` after checking `tcf_sw_enabled_key` and `tcf_block_bypass_sw()`. [F437, F446, F452, F457]
- Subordinate devices (`sb_dev`) store `sb_dev->num_tc = -channel`; `netdev_bind_sb_channel_queue()` rejects `sb_dev->num_tc >= 0` or `tc >= dev->num_tc`. `__netif_set_xps_queue()` rejects `dev->num_tc < 0` (`-EINVAL`), switches `dev` to `txq->sb_dev` when non-NULL, and calls `xps_copy_dev_maps()` only if both `num_tc` and `nr_ids` match. Decreasing `real_num_tx_queues` in `netif_set_real_num_tx_queues()` calls `synchronize_net()`, `qdisc_reset_all_tx_gt()`, and `netif_reset_xps_queues_gt()`; `netdev_reset_tc()`/`netdev_set_num_tc()` calls `netif_reset_xps_queues_gt(dev, 0)` and `netdev_unbind_all_sb_channels()`. [F432, F443, F444, F456, F511]
- Datapath queue selectors bound indices by `real_num_tx/rx_queues`, whereas teardown/reset iterates up to `num_tx/rx_queues`. `skb->sender_cpu` (`cpu + 1`) and `skb->napi_id` (`>= MIN_NAPI_ID`) share a union (`0` = unset), so CPU/XPS indexing uses `skb->sender_cpu - 1`. `netif_napi_add_config_locked()` requires `index < max(dev->num_tx_queues, dev->num_rx_queues)`. `netif_set_threaded()` updates both `napi_list` (`napi_set_threaded()`) and `dev->napi_config[i].threaded`; `napi_disable/enable_locked()` calls `napi_save/restore_config()` when `n->config != NULL`. [F441, F442, F464, F465, F477]
- Detaching `sd->output_queue = NULL` in `net_tx_action()` or `dev_cpu_dead()` requires resetting `sd->output_queue_tailp = &sd->output_queue` with IRQs disabled; removing SKBs from `sd->input_pkt_queue` or `process_queue` outside `process_backlog()` (`flush_backlog()`, `dev_cpu_dead()`) calls `rps_input_queue_head_incr(sd)`. `__netdev_upper_dev_link()` rejects `dev->lower_level + upper_dev->upper_level > MAX_NEST_DEV` (`-EMLINK`) and cycles (`__netdev_has_upper_dev(upper_dev, dev)`). `__netdev_adjacent_dev_insert()` inserts master entries at head (`list_add_rcu()`) and non-master at tail (`list_add_tail_rcu()`). [F447, F448, F476, F489]
- `validate_xmit_skb()` runs `validate_xmit_unreadable_skb()` first so `!skb_frags_readable(skb)` packets drop unless `dev->netmem_tx` and devmem bindings match `dev`; `validate_xmit_skb_list()` sets `skb->prev = skb` before `validate_xmit_skb()` so `tail = skb->prev` tracks GSO segments. `sk_validate_xmit_skb()` reads `sk_validate_xmit_skb` only if `sk_fullsock(sk)` and `tw_validate_xmit_skb` only if `sk_is_inet(sk) && sk->sk_state == TCP_TIME_WAIT`. On IPv6 packets with extension headers and `!ipv6_has_hopopt_jumbo(skb)`, `gso_features_check()` clears `NETIF_F_IPV6_CSUM | NETIF_F_TSO6 | NETIF_F_GSO_UDP_L4` and `skb_csum_hwoffload_help()` (`!NETIF_F_HW_CSUM`) calls `skb_checksum_help()`. [F494, F520, F561, F562, F563]
- In `__netdev_update_features()` for `NETIF_F_RX_UDP_TUNNEL_PORT` and `NETIF_F_HW_VLAN_CTAG/STAG_FILTER`, set `dev->features = features` before `*_get_rx_*_info()` on enable, and after `*_drop_rx_*_info()` on disable. `skb_set_peeked()` on `skb_shared(skb)` calls `skb_clone()`, replaces/consumes old `skb` in `queue`, sets `peeked = 1`, and returns the clone. `zerocopy_fill_skb_from_iter/devmem()` caps `nr_frags` by `MAX_SKB_FRAGS` (`-EMSGSIZE`). `bpf_iter_attach_map()` rejects `max_rdwr_access > map->value_size` (`-EACCES`); `bpf_sk_storage_charge()` checks `size <= optmem_max` first. [F445, F454, F470, F473, F474]

## Synchronization

- `NETDEV_REGISTER`, `NETDEV_UP`, and `NETDEV_CHANGE` require `netdev_lock_ops(dev)` held, and their callbacks must use unlocked `netif_*` helpers (`netif_xdp_propagate()`, `netif_set_promiscuity()`, `netif_state_change()`). Recursive lower updates (`netdev_sync_lower_features()`, `netif_disable_lro()`) take `netdev_lock_ops(lower)`. Pre-registration helpers (`netif_state_change()`, `netif_queue_set_napi()`) use `netdev_ops_assert_locked_or_invisible(dev)`. [F408, F409, F410]
- `__dev_close_many()` disables netpoll, notifies `NETDEV_GOING_DOWN`, clears `__LINK_STATE_START` + `smp_mb__after_atomic()`, and runs `dev_deactivate_many()` before `ndo_stop()` under `netdev_ops_assert_locked()`. Batch closes (`unregister_netdevice_many_notify()`) close ops-locked devices and drop `dev->lock` before calling `netif_close_many()` on non-ops-locked devices. Unregistration/netns move calls `unlist_netdevice()`, marks `NETREG_UNREGISTERING`/`moving_ns` under `dev->lock`, and calls `synchronize_net()` before `dev_shutdown()` (and TCX/XDP/MP uninstall) under `netdev_lock_ops(dev)`. `netdev_run_todo()` snapshots `net_todo_list` and calls `__rtnl_unlock()` before `rcu_barrier()`, `NETREG_UNREGISTERED`, `linkwatch_sync_dev()`, and `netdev_wait_allrefs_any()`. [F404, F405, F406, F407]
- Lockless locked-device lookups (`__netdev_put_lock()`, `netdev_napi_by_id_lock()`, `netdev_get_by_index_lock()`, `netdev_xa_find_lock()`) take `dev_hold()` under RCU, drop RCU before `netdev_lock(dev)`, and verify `reg_state <= NETREG_REGISTERED`, `!moving_ns`, and `net_eq(dev_net(dev), net)`. `rtnl_net_dev_lock(dev)` takes `net_passive_inc(net)` under RCU before `rtnl_net_lock(net)` and reverifies `dev->nd_net.net`. `netdev_rx_handler_register()` publishes `rx_handler_data` before `rx_handler`; `unregister()` clears `rx_handler` and calls `synchronize_net()` before clearing `rx_handler_data`. `netif_change_name()` requires `write_seqlock_bh(&netdev_rename_lock)` and `synchronize_net()` between node del and add. [F401, F546, F547, F549]
- `napi_schedule_prep()` and `napi_complete_done()` coordinate `NAPIF_STATE_SCHED`/`MISSED` via `try_cmpxchg(&n->state, ...)`. `____napi_schedule()` requires hardirqs disabled, so `__napi_schedule_irqoff()` calls `__napi_schedule()` on `CONFIG_PREEMPT_RT`. `napi_set_threaded()` needs `smp_mb__before_atomic()` after kthread creation before setting `NAPI_STATE_THREADED`; `netif_napi_add_weight_locked()` gates `napi_kthread_create()` on `napi_get_threaded_config()`; `napi_stop_kthread()` clears `NAPIF_STATE_THREADED` via `try_cmpxchg()` and waits for `NAPI_STATE_SCHED_THREADED` to clear before `kthread_stop()`. [F402, F403, F414, F524, F555]
- BPF entry points (`tcx_run()`, `do_xdp_generic()`, `busy_poll_stop()`, `__napi_busy_loop()`, `napi_threaded_poll_loop()`, `net_rx_action()`) bracket BH/migration-disabled sections with `bpf_net_ctx_set/clear()`; `__napi_busy_loop()` calls `busy_poll_stop()` before `rcu_read_unlock()`/`cond_resched()` and re-lookups `napi_by_id()` after `restart:`. `__netif_receive_skb[_list]()` on `sk_memalloc_socks() && skb_pfmemalloc(skb)` uses `memalloc_noreclaim_save/restore()`. [F487, F556, F558]
- `sd->output_queue` and `completion_queue` require local hardirqs disabled; `net_tx_action()` reads `head->next_sched` + `smp_mb__before_atomic()` before `clear_bit(__QDISC_STATE_SCHED, &q->state)`. In `__dev_xmit_skb()`, when `contended`, take `q->busylock` before `qdisc_lock(q)` and drop it before `__qdisc_run(q)`. Queueless TX in `__dev_queue_xmit()` checks `txq->xmit_lock_owner != cpu` and `!dev_xmit_recursion()` with BH disabled and brackets xmit with `dev_xmit_recursion_inc/dec()`. `sd->input_pkt_queue` requires `backlog_lock_irq_save/disable()`; `sd->process_queue` requires `local_lock_nested_bh(&softnet_data.process_queue_bh_lock)` (dropped before `__netif_receive_skb()`); `dev_cpu_dead()` must not schedule `process_backlog` NAPI on the new CPU, instead clearing `NAPI_STATE_SCHED` and draining via `netif_rx()`. [F412, F543, F544, F551, F552, F554, F560]
- XPS map writers (`__netif_set_xps_queue()`, `netif_reset_xps_queues()`) hold `cpus_read_lock()` outside `xps_map_mutex`. `dev_fetch_dstats/sw_netstats()` accumulates into `rtnl_link_stats64` only after `u64_stats_fetch_retry()` succeeds. `__sk_queue_drop_skb()`/`skb_kill_datagram()` on `MSG_PEEK` takes `spin_lock_bh(&sk_queue->lock)` and verifies `skb->next != NULL` before unlinking. `bpf_sk_storage_free/clone()` requires `migrate_disable()` around `rcu_read_lock()`; `bpf_sk_storage_clone_elem()`/`diag_get()` uses `copy_map_value_locked()` if the map has `BPF_SPIN_LOCK`; `bpf_sk_storage_map_seq_find_next()` holds RCU only on non-NULL return, so `seq_stop()` unlocks RCU only when `v != NULL`. [F418, F419, F482, F496, F536, F550]

## Object Lifetimes

- `free_netdev()` on `NETREG_UNREGISTERING` asserts RTNL, sets `dev->needs_free_netdev = true`, and returns; otherwise `mutex_destroy(&dev->lock)` runs after `netif_free_rx_queues()`, `netdev_napi_exit()`, and all `dev->lock` users, and final release uses `kvfree(dev)` for `NETREG_UNINITIALIZED`/`DUMMY` or sets `NETREG_RELEASED` and calls `put_device(&dev->dev)` for `NETREG_UNREGISTERED`. Clear `rmap->obj[napi->napi_rmap_idx] = NULL` before `cpu_rmap_put()`. On `netif_alloc_rx_queues()` failure at `i`, unregister only `while (i--)`, free `dev->_rx`, and set `dev->_rx = NULL`. [F376, F377, F387, F526, F527]
- `dev_xdp_install()` calls `bpf_prog_inc(prog)` for the driver before `bpf_op()` (and `bpf_prog_put()` on failure). `bpf_xdp_link` holds no `net_device` ref and `dev_xdp_uninstall()`/`bpf_xdp_link_release()` must NULL `link->dev` under `rtnl_lock()`; `bpf_xdp_link_update()` calls `bpf_prog_put(new_prog)` when returning `0` on `old_prog == new_prog`, but not on negative returns before `xchg()`. `__dev_remove_pack()` does not wait for RCU (`dev_remove_pack()` does). `unregister_netdevice_many_notify()` and `__dev_close()` must `list_del()` the caller's stack `list_head`. `netdev_adjacent_change_prepare/commit()` must not disable/unlink `old_dev` when `new_dev == old_dev`. [F383, F384, F385, F389, F393, F521]
- `zerocopy_fill_skb_from_iter()` drops coalesced page refs via `page_ref_sub(last_head, refs)`; `__zerocopy_sg_from_iter()` charges `skb->truesize - orig_size` to socket wmem even on partial-fill errors. `bpf_sk_storage_clone()` pins `smap->map` via `bpf_map_inc_not_zero()`; under `bpf_rcu_lock_held()`, `bpf_sk_storage_get(CREATE)`/`delete()` verifies `sk_fullsock(sk)` and `refcount_inc_not_zero(&sk->sk_refcnt)`/`sock_put()`; `bpf_sk_storage_diag_alloc()` increments `diag->nr_maps` only as each map is stored. [F399, F400, F417, F522, F538]

## API Contracts

- `__netdev_put_lock[_ops_compat]()` always consumes the caller's `dev` ref via `dev_put(dev)`. `__dev_get_by_name/index()` and `*_rcu()` return borrowed pointers; `dev_get_by_name/index()`, `netdev_get_by_name/index()`, and `dev_getfirstbyhwtype()` increment refcount. `__netif_napi_del_locked()` requires `NAPI_STATE_SCHED` set and `napi->dev` locked. `__napi_poll()` touches `n` or sets `*repoll = true` only when `work >= weight`. `__netdev_update_features()` returns `1` (changed) or `-1` (`ndo_set_features` failed) to trigger `netdev_features_change()`, or `0`. `dev_xdp_attach()` rejects dev-bound programs in `XDP_MODE_SKB`, offloaded programs in `!= XDP_MODE_HW`, and `BPF_XDP_DEVMAP`/`CPUMAP` (`-EINVAL`). `dev_xdp_install()` and `netif_xdp_propagate()` reject XDP (`-EBUSY`) if `dev_get_min_mp_channel_count(dev) != 0` or `ETHTOOL_TCP_DATA_SPLIT_ENABLED` with `!prog->aux->xdp_has_frags`. [F380, F381, F438, F486, F528, F565, F566]
- `__skb_wait_for_more_packets()` returns `1` with `*err = 0` on `RCV_SHUTDOWN` (EOF), `0` to retry, or `< 0`. In `__skb_try_recv_from_queue/datagram()` with `MSG_PEEK`, `*off` is input skip offset and overwritten with intra-SKB offset. `__skb_datagram_iter()`, `zerocopy_fill_skb_from_iter()`, and `skb_checksum_help()` check `skb_frags_readable(skb)`; `zerocopy_fill_skb_from_devmem()` requires `ITER_IOVEC` or `ITER_UBUF` (`-EFAULT`). `skb_copy_and_csum_datagram_msg()` on truncated reads (`msg_data_left(msg) < chunk`) calls `__skb_checksum_complete(skb)` before `skb_copy_datagram_msg()`. `bpf_fd_sk_storage_lookup_elem()` returns `ERR_PTR(err)` on bad FD, `NULL` on miss, or `sdata->data`. [F422, F425, F426, F468, F542, F577]

## Error Handling

- `register_netdevice()` normalizes `ndo_init() > 0` to `-EIO`; pre-`list_netdevice()` errors unwind `NETDEV_PRE_UNINIT`, `dev_index_release()`, `netdev_do_free_pcpu_stats()`, `ndo_uninit()`, `priv_destructor()`, and `netdev_name_node_free()`; `NETDEV_REGISTER` failure sets `dev->needs_free_netdev = false` and calls `unregister_netdevice_queue()`. `netif_set_real_num_queues()` increases queues before decreasing and rolls back `rxq` if `txq` fails. `__netif_set_xps_queue()` cleanup calls `kfree(new_map)` only when `new_map != map`. `napi_kthread_create()` resets `n->thread = NULL` on `IS_ERR()`. [F379, F386, F390, F431, F439]
- Notifier replay rollback uses `for_each_net/netdev_continue_reverse()`. `__netdev_adjacent_dev_insert()`/`__netdev_upper_dev_link()` errors unwind `netdev_hold()`/sysfs links and `__netdev_adjacent_dev_unlink_neighbour()`. `netif_change_name()` rollback guards `if (err >= 0)`. `__dev_set_promiscuity()`/`netif_set_allmulti()` return `-EOVERFLOW` if `inc > 0` wraps to `0`. `__skb_datagram_iter()` on short/unreadable copy when `fault_short || iov_iter_count(to)` (or remaining `len`) calls `iov_iter_revert(to, offset - start_off)` and returns `-EFAULT`. `bpf_sk_storage_clone()` locally frees/uncharges `copy_selem` if the first `bpf_local_storage_alloc()` fails; `bpf_sk_storage_diag_put[_all]()` on `-EMSGSIZE` continues the loop to sum `*res_diag_size` and calls `nla_nest_cancel()` if `saved_len == skb->len`. [F391, F392, F423, F424, F427, F430, F501]

## Known Pitfalls

- Pass `NAPI_STATE_*` indices to `test/set/clear/assign_bit()` on `&napi->state`, and shifted `NAPIF_STATE_*` masks to bitwise ops and `try_cmpxchg()`. In `netif_receive_generic_xdp()`, dereference `*pskb` after `netif_skb_check_for_xdp(pskb, ...)`. In `dev_queue_xmit_nit()`, preserve `pt_prev` and `skb2` across `goto again`. `netdev_lower_get_next[_private]()` takes `*iter` as current node (`list_entry`), whereas `*_rcu()`/`netdev_next_lower_dev()` takes `*iter` as prior node (`(*iter)->next`). [F420, F451, F460, F484]
