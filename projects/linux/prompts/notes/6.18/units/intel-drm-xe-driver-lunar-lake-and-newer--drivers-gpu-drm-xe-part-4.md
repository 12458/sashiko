# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 4)

Manages GT state, topology, sysfs/throttle/stats, SR-IOV VF GT operations, and the GuC stack (`xe_guc`, `xe_guc_ct`, `xe_guc_ads`, `xe_guc_capture`, `xe_guc_pc`, ID/doorbell managers, engine activity, hwconfig, and logging).

## Architecture & Data Flow

- `guc_ctb_info` stores `size`, `resv_space`, `head`, `tail`, and `space` in `u32` dwords matching `guc_ct_buffer_desc`, while `iosys_map` `cmds` accesses and `GUC_KLV_SELF_CFG_*_CTB_SIZE_KEY` scale by `sizeof(u32)`. In `h2g_write`, updating H2G tail (on wrap and after write) must update `h2g->info.tail`, deduct from `h2g->info.space` via `h2g_reserve_space`, and call `desc_write` under `ct->lock`. [F1121, F1144]
- Under `ct->fast_lock`, `__g2h_reserve_space`, `__g2h_release_space`, and `guc_ct_change_state` keep `g2h.info.space`, `ct->g2h_outstanding`, and a runtime PM ref (`xe_pm_runtime_get_noresume` when non-zero, `xe_pm_runtime_put` at zero) in sync. G2H events with reserved space (`g2h_len > 0`) must release `len` dwords via `g2h_release_space()` in `parse_g2h_event()` (or `__g2h_release_space()` in `g2h_fast_path()`), while unsolicited events must not; `g2h_read` (`fast_path`) and `g2h_fast_path` must handle the exact same event actions. [F1122, F1124, F1166]
- `next_ct_seqno` masks `ct->fence_seqno++` with `CT_SEQNO_MASK` (`GENMASK(14, 0)`) and sets `CT_SEQNO_UNTRACKED` (`BIT(15)`) only when `!is_g2h_fence`. In `guc_ct_send_locked()`, when `__guc_ct_send_locked()` returns `-EBUSY`, `!h2g_has_room(ct, len + GUC_CTB_HDR_LEN)` must precede the general `-EBUSY` branch that waits for and dequeues G2H. `xe_guc_ct_fixup_messages_with_ggtt` must check `!h2g->info.broken`, refresh `head`, verify `head <= size` and `tail < size`, and verify `len <= (u32)avail` and exact message lengths in `ct_fixup_ggtt_in_buffer`/`message`. [F1126, F1164, F1179]
- Under `submission_state.lock`, `idm_reserve_chunk_locked()` and `idm_release_chunk_locked()` keep `idm->used` equal to `idm->bitmap` weight. Regular IDs (`retain == 0`) allocate from the low end (`bitmap_find_next_zero_area`), while PF reservations for VFs (`retain > 0`, or `spare > 0` in `dbm_reserve_chunk_locked()`) return `-EDQUOT` if PF quota (`idm->used + count + retain > idm->total`) is exceeded and allocate IDs from the high end (`find_last_zero_area`). [F1077, F1161]
- `gt->sriov` is a union of `pf` (`IS_SRIOV_PF`) and `vf` (`IS_SRIOV_VF`). On VFs, `xe_guc_init*` skips `log`, `capture`, `ads`, `dbm`, `pc`, and `engine_activity` (`guc->log.bo`, `guc->capture`, `guc->ads.bo`, `guc->pc.bo` are NULL); VF-reachable code must gate on `!IS_SRIOV_VF(xe)` or NULL-check them. In `vf_get_ggtt_info`, compute `config->ggtt_shift = start - (s64)config->ggtt_base` before updating `ggtt_base`, and return `-EREMCHG` if an already-initialized `ggtt_size` changes. `vf_lookup_reg` requires `runtime.regs` sorted by GSI-adjusted `offset` and callers (`xe_gt_sriov_vf_read32`) to pass `xe_mmio_adjusted_addr(&gt->mmio, reg.addr)`. [F1106, F1107, F1137, F1157]
- When `xe->info.skip_guc_pc` is true, `xe_guc_pc_init` skips `pc->freq_lock` and `pc->bo`, so `xe_guc_pc_start`, `xe_guc_pc_stop`, `xe_guc_pc_gucrc_disable`, and `xe_guc_pc_restore_stashed_freq` must check `skip_guc_pc` first. On `XE_PVC`, `xe_guc_pc_start` must disable GuC/host RC6 (`xe_guc_pc_gucrc_disable` or skipping `xe_gt_idle_enable_c6`). `pc_set_cur_freq` must bracket `RPNSWREQ` writes and the 100-300 us pcode wait with `pc_set_manual_rp_ctrl(pc, true/false)`. [F1108, F1213, F1215]
- `xe_guc_hwconfig_init` only allocates `guc->hwconfig.bo` on `XE_GT0`, so check `xe_guc_hwconfig_size(guc) != 0` before `xe_guc_hwconfig_copy`. In `xe_guc_ads.c`, section offset helpers (`guc_ads_golden_lrc_offset` to `guc_ads_private_data_offset`) chain sequentially from `regset_size`, `golden_lrc_size`, `ads_waklv_size`, and `capture_size` within `MAX_GOLDEN_LRC_SIZE` slack. [F1110, F1130]
- In `xe_guc_capture.c`, 64-bit `__guc_mmio_reg_descr` entries must pair `REG_64BIT_LOW_DW` (`regname = NULL`) then `REG_64BIT_HI_DW`, and `__guc_mmio_reg_descr_group` arrays (`xe_lp_lists`, `xe_hpg_lists`, `extlists`) must end with `.list == NULL`. Loops unlinking from `outlist`/`cachelist` must use `list_for_each_entry_safe*`. `__guc_capture_process_output` must copy `guc_log_buffer_state` to stack once before extracting, then update `read_ptr = write_offset`, clear `GUC_LOG_BUFFER_STATE_FLUSH_TO_FILE`, write back, and call `__guc_capture_flushlog_complete`. In `guc_capture_extract_reglists()`, drain all `numregs` entries via `guc_capture_log_get_register()` when skipping `datatype > GUC_STATE_CAPTURE_TYPE_ENGINE_INSTANCE`. [F1135, F1136, F1150, F1168, F1170]
- `guc_bo_ggtt_addr` requires GuC BOs mapped in the target tile's GGTT (`__xe_bo_ggtt_addr`) in `[xe_wopcm_size(xe), GUC_GGTT_TOP)`. `guc_ctl_log_params_flags` (`GUC_LOG_*`) and `XE_G2G_REGISTER_SIZE` encode `size / UNIT - 1`, whereas `DOORBELLS_PER_SQIDI_MASK` in `guc_doorbell_init` requires `+ 1`. In `xe_guc_engine_activity.c`, `allocate_engine_activity_group` sizes `eag` to `totalvfs + 1` on PF (1 otherwise) and `engine_activity_enable_function_stats` sets `num_functions = num_vfs + 1`, gated by `is_function_valid`. [F1158, F1159, F1160]
- In `__xe_guc_upload`, `guc_write_params` and `guc_prepare_xfer` must precede `guc_xfer_rsa` and `xe_uc_fw_upload`. `guc_wait_ucode()` must check `guc_load_done(status)` and bound cumulative elapsed time via `ktime_get()` against `GUC_LOAD_RETRY_LIMIT * 1000`. `guc_enable_irq` must use `xe_mmio_rmw32` on `GUC_SG_INTR_MASK` (`ENGINE0_MASK` on media, `ENGINE1_MASK` on primary). In `xe_guc_mmio_send_recv()`, polling after `GUC_HXG_TYPE_NO_RESPONSE_BUSY` must use `FIELD_PREP(GUC_HXG_MSG_0_TYPE, GUC_HXG_TYPE_RESPONSE_SUCCESS & GUC_HXG_TYPE_RESPONSE_FAILURE)`. [F1163, F1171, F1204, F1206]
- Populate `xe_dss_mask_t`, `xe_eu_mask_t`, and `xe_l3_bank_mask_t` via `bitmap_from_arr32` (or `bitmap_set_value8` on a zeroed mask) using `XE_MAX_*_BITS`; pre-Xe_HP fuse bits (`GRAPHICS_VERx100 < 1250` in `load_eu_mask`, non-DG2/PVC `< 1270` in `load_l3_bank_mask`) must be bitwise-negated. Every `enum xe_gt_stats_id` needs a `stat_description` entry, and `kobj_gt::base` must stay at offset 0 for `xe_gt_sysfs_kobj_release`. [F1141, F1195, F1199, F1216]

## Synchronization

- In `xe_guc_ct.c`, lock order is `ct->lock` -> `ct->fast_lock`; call `xa_destroy(&ct->fence_lookup)` outside `ct->fast_lock` under `ct->lock`. `ct->lock` is reclaim-primed (`primelockdep`) and `ct->fast_lock` is taken in hardirq (`xe_guc_ct_fast_path`): process context must use `spin_lock_irq`/`irqsave` for `ct->fast_lock`, and code under either lock (`h2g_write`, `fast_req_track`, `fast_req_report`, `g2h_fast_path`) must never sleep or use `GFP_KERNEL`. [F1080, F1222, F1223, F1224, F1230]
- `ct->fast_lock` protects `g2h.info.space`, `g2h.info.head`, and `ct->g2h_outstanding`; `__guc_ct_send_locked` must hold `ct->fast_lock` across `has_room`, `h2g_write`, and `__g2h_reserve_space` when `g2h_len > 0`. `h2g_write` needs `xe_device_wmb(xe)` between `xe_map_memcpy_to(h2g->cmds)` and `desc_write(tail)`. After `wait_event_timeout` on `ct->g2h_fence_wq`, `guc_ct_send_recv` must lock `ct->lock` before reading `g2h_fence` or erasing `seqno` on timeout; `parse_g2h_response` and `guc_ct_change_state` must set `g2h_fence->done = true` and `smp_mb()` before `wake_up_all`. [F1081, F1083, F1084, F1085]
- `xe_guc_ct_disable` and `xe_guc_ct_stop` must transition `ct->state` via `guc_ct_change_state` and drop `ct->lock`/`ct->fast_lock` before canceling `safe_mode_worker` and `g2h_worker`. `xe_guc_ct_enable` must zero `ct->bo`, init/register CTBs, and call `guc_ct_control_toggle(ct, true)` before setting `XE_GUC_CT_STATE_ENABLED`. `xe_guc_ct_fast_path` and `receive_g2h` must use `xe_pm_runtime_get_if_active` (or fallback `xe_pm_read_callback_task != NULL`) and put only if `ongoing`. `ct_dead_capture` must use `spin_lock_irqsave(&ct->dead.lock, flags)` and `GFP_ATOMIC` snapshots, deferring work to `ct->dead.worker`. [F1087, F1088, F1089, F1090, F1229]
- `pc->freq_lock` protects `pc->freq_ready`, `user_requested_min`/`max`, `stashed_min_freq`/`max_freq`, and `power_profile`; `pc_init_freqs` sets `freq_ready = true` after `pc_adjust_freq_bounds` and `pc_adjust_requested_freq`. With WA 22019338487, `xe_guc_pc_set_max_freq` calls `wait_for_flush_complete(pc)` before locking `pc->freq_lock`, and `xe_guc_pc_remove_flush_freq_limit` clears `flush_freq_limit` under `freq_lock` then calls `wake_up_var`. `pc_action_query_task_state` and `enable_*_engine_activity_stats` must use `xe_guc_ct_send_block`. `xe_gt_sriov_vf_migrated_event_handler` needs `smp_mb__after_atomic()` between `set_bit(gt_flags)` and `xe_sriov_vf_start_migration_recovery`. `xe_guc_id_mgr` and `xe_guc_db_mgr` use `guc->submission_state.lock` (`*_locked` iff held). [F1092, F1093, F1094, F1095, F1232]

## Object Lifetimes

- Check `xe_guc_buf_reserve()` / `xe_guc_buf_from_data()` with `xe_guc_buf_is_valid()` before accessing `buf.sa` and free via `xe_guc_buf_release()` or `CLASS(xe_guc_buf*)`. In `guc_g2g_alloc()`, GT 0 owns a managed BO (`owned = true`) while other GTs call `xe_bo_get()` (`owned = false`); `guc_g2g_fini()` calls `xe_bo_put` only when `!owned` and sets `bo = NULL`. `xe_guc_comm_init_early` must init `guc->notify_reg` before GuC MMIO sends. [F1068, F1074, F1200]
- On DGFX, `xe_guc_realloc_post_hwconfig` and `xe_guc_ct_init_post_hwconfig` replace `fw.bo`, `log.bo`, `ads.bo`, and `ct.bo` via `xe_managed_bo_reinit_in_vram`; `xe_guc_ct_init_post_hwconfig` requires `!xe_guc_ct_enabled(ct)` and must re-register `guc_action_disable_ct` after the new `ct->bo`, and `guc_init_params_post_hwconfig`, `xe_guc_ads_populate`, and `xe_guc_ct_enable` must refresh cached GGTT addresses and `iosys_map` views. [F1071, F1123, F1193]
- `__guc_capture_parsed_output` nodes in `devcoredump->snapshot.matched_node` must set `node->locked = 1` and be freed to `cachelist` via `guc_capture_free_outlist_node()` on replacement or `xe_guc_capture_put_matched_nodes()`. `guc_capture_init_node()` must save `node->reginfo[i].regs` pointers before `memset`, zero their arrays (`max_mmio_per_node`), and restore pointers and `node->link`. When `vf_prepare_runtime_info()` frees `runtime.regs`, it must clear `regs = NULL`, `num_regs = 0`, and `regs_size = 0` before `drmm_kcalloc()`, and `vf_query_runtime_info()` must call `vf_prepare_runtime_info(gt, 0)` on error. [F1076, F1079, F1097, F1112]

## API Contracts

- G2H handlers in `process_g2h_msg` run under `ct->lock` and must use `xe_guc_ct_send_g2h_handler`. In `__guc_ct_send_locked` / `xe_guc_ct_send*`, `g2h_len` and `num_g2h` must both be `0` or both non-zero, and both `0` when `g2h_fence` is non-NULL. `xe_guc_mmio_send_recv` and `xe_guc_mmio_send` return negative errno or `DATA0` (callers expecting no payload treat `ret > 0` as `-EPROTO`; `guc_self_cfg` treats `0` as `-ENOKEY`), and `response_buf` needs `>= VF_SW_FLAG_COUNT` dwords. `xe_guc_ct_send_recv*` returns dword length when `response_buffer` is non-NULL (`GUC_CTB_MAX_DWORDS`), `DATA0` when NULL, or negative errno. [F1086, F1098, F1099, F1100, F1115]
- `xe_guc_buf_reserve` takes `u32 dwords` while `xe_guc_buf_from_data` takes byte `size_t`, and callers must pass `xe_guc_buf_flush(buf)` to H2G actions. `xe_guc_id_mgr_reserve*` and `xe_guc_db_mgr_reserve*` return signed `int` (`>= 0` valid, `< 0` error); `xe_guc_id_mgr_init(idm, 0)` returns `-EINVAL` while `xe_guc_db_mgr_init(dbm, 0)` leaves `dbm->bitmap = NULL`. `get_capture_list` returns `false` on success and `true` on failure, unlike `xe_guc_capture_getlist*` (`0` on success). [F1103, F1104, F1105, F1120, F1236]
- `xe_guc_pc` APIs/SLPC params use MHz, `RPNSWREQ`/`MTL_*`/`GT_PERF_STATUS`/`task_state_data.freq` use 16.66 MHz units (`encode_freq`/`decode_freq`), and `xe_pcode_init_min_freq_table` uses 50 MHz units, all using `DIV_ROUND_CLOSEST`. Callers of `gen_l3_mask_from_pattern` must zero-init stack `dst` (`= {}`) and ensure `patternbits * (__fls(mask) + 1) <= XE_MAX_L3_BANK_MASK_BITS`. `guc_debugfs_show` files must live in a child of the GT debugfs dir, while `xe_gt_debugfs_simple_show` subdirs must set `subdir->d_inode->i_private = gt`; guard `pf_only_debugfs_list` with `!IS_SRIOV_VF(xe)` and `slpc_debugfs_list` with `!IS_SRIOV_VF(xe) && !xe->info.skip_guc_pc`. [F1114, F1116, F1181, F1183, F1196, F1242]

## Error Handling

- In `xe_guc_engine_activity.c`, unpin `metadata_bo` if `activity_bo` fails, and call `free_engine_activity_buffers()` and reset `num_functions = 0` if `enable_function_engine_activity_stats()` fails. Check `IS_ERR()` on a local variable before assigning to struct BO/`sam` fields. `xe_guc_ads_populate*` must zero `ads->bo` then call `guc_mapping_table_init_invalid` (`GUC_MAX_INSTANCES_PER_CLASS`). `guc_capture_extract_reglists` must clamp `numregs` to `max_mmio_per_node`. SLPC CT helpers must suppress `xe_gt_err` when `xe_device_wedged(xe) && ret == -ECANCELED`. [F1075, F1109, F1113, F1153, F1249]
- In `guc_ct_send_recv`, call `g2h_fence_init` initially and on `goto retry`, but preserve `seqno` on `goto retry_same_fence`. In `parse_g2h_response`, `CT_SEQNO_UNTRACKED` must call `CT_DEAD` and return `-EPROTO`, whereas a NULL `xa_erase` for a tracked fence must call `g2h_release_space(ct, GUC_CTB_HXG_MSG_MAX_LEN)` and return `0`. `ct_dead_capture` must set `ctb->info.broken = true` before checking `xe_is_injection_active()`, `ct->dead.reported`, or `CT_DEAD_STATE_CAPTURE`. [F1101, F1247, F1248, F1250]

## External Contracts

- `guc_golden_lrc_init` sets `ads.eng_state_size[guc_class]` to `real_size - xe_lrc_skip_size(xe)`. `GUC_ACTION_HOST2GUC_SELF_CFG` and `XE_GUC_ACTION_CLIENT_SOFT_RESET` must use `xe_guc_mmio_send`. Gate L3 bank mask loading/reporting on `xe_gt_topology_report_l3(gt)`. `pc_set_min_freq`/`pc_set_max_freq` validate `[rpn_freq, rp0_freq]` without requiring `min <= max`. [F1118, F1209, F1244, F1246]

## Known Pitfalls

- `g2h_read` uses signed `s32 avail = tail - g2h->info.head` (plus `size` if `< 0`), checks `len <= avail`, and splits wrap copies when `(len - 1) + head > size` (`msg` is `u32 *`, `&g2h->cmds` is byte-indexed). In `h2g_write`, after `--len; ++action;`, the HXG header is `*(action - 1)`. `process_g2h_msg()` passes `(payload, adj_len)` to standard event handlers but `(hxg, hxg_len)` to SR-IOV relay/PF handlers. `CT_DEAD_*` enums must remain bit indices `0..31`. [F1146, F1172, F1178, F1191, F1192]
- `guc_capture_log_remove_bytes` requires `u32`-aligned `bytes_needed` and subtracts `avail % sizeof(u32)` before wrapping. `xe_guc_log_snapshot_alloc` must use `GUC_LOG_CHUNK_SIZE` (`SZ_2M`) `kmalloc` chunks. `xe_guc_klv_print`/`count` must check `num_dwords >= GUC_KLV_LEN_MIN` and `num_dwords >= len` before advancing. `vf_query_runtime_info` must validate `ret >= VF2PF_QUERY_RUNTIME_RESPONSE_MSG_MIN_LEN`, even payload length, `count == num`, and `start + num <= num_regs`. [F1152, F1155, F1156, F1162]
- Cast high dwords to `u64` before `<< 32` (`make_u64*`), and pass `(int)(len * sizeof(u32))` as width for `%*ph` on `u32` arrays. `cpu_ns_to_guc_tsc_tick` must use `mul_u64_u32_div`, and `get_engine_active_ticks` must use `lower_32_bits(gpm_ts)` before subtracting `last_update_tick`. Check WA `14022085890` on `tile->primary_gt` in `pc_adjust_freq_bounds()`, and read back `VF_SW_FLAG(LAST_INDEX)` before `xe_guc_notify` in `xe_guc_mmio_send_recv`. [F1173, F1174, F1176, F1177, F1198, F1207]
