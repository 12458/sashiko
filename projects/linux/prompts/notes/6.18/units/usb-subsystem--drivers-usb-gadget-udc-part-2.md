# USB SUBSYSTEM — drivers/usb/gadget/udc (part 2)

UDC drivers for NXP LPC32xx (`lpc32xx_udc`), Renesas M66592 (`m66592-udc`), Maxim MAX3420E/MAX3421E (`max3420_udc`), NetChip/PLX NET2280/USB338x (`net2280`), and TI OMAP1 (`omap_udc`).

## Architecture & Data Flow
- In `net2280.c`, `queue_dma` swaps `req->td`/`req->td_dma` with `ep->dummy`/`ep->td_dma` without clearing `dmacount`, so abort paths (`net2280_dequeue`, `handle_ep_small`) must set `req->td->dmacount = 0` before `dma_done`. In `net2280_dequeue`, unlinking the queue head (`ep->queue.next == &req->queue`) must reset `req = NULL` after completion so `if (req) done(...)` is skipped and `start_dma` runs on the new head. [F62, F89]
- In `net2280.c`, `start_dma` sets `req->td->dmadesc = 0` and `req->td->dmacount = req->req.length - tmp` for single-transfer buffered short-packet OUT reads so `scan_dma_completions` checks `ep->dma->dmacount`. In `handle_ep_small`, reset `stuck = 0` when `num_completed != 0` or `stuck_req != req`, and break with `req = NULL` if `stuck++ > 5`. Also, `net2280_queue` must pass `valid = 0` to `queue_dma` when an IN request's ZLP/short-packet need differs from `ep->in_fifo_validate` (`DMA_FIFO_VALIDATE` in `ep->dma->dmactl`). [F48, F63, F90]
- In `net2280.c`/`net2280.h`, on `PLX_PCIE` (USB338x) in `enhanced_mode`, `usb_reinit_338x()` offsets IN `ep->regs` by `0xC0` while same-numbered IN/OUT endpoints share `ep->cfg` (`&dev->epregs[ne[i]]`); access `ep->cfg->ep_cfg` (not `ep->regs->ep_cfg`) and preserve the sibling direction's bits. `dev->usb_ext`, `dev->llregs`, and `dev->plregs` are only mapped under `dev->quirks & PLX_PCIE`. Keep the 9-element endpoint order (`ep0`, `ep1in`, `ep2out`, `ep3in`, `ep4out`, `ep1out`, `ep2in`, `ep3out`, `ep4in`) synchronized across `ep_info_adv`, `ep_bit`, `ep_key`, `ne`, `ep_reg_addr`, `ep_pl`, and `ep_enhanced`, and in `net2280_match_ep` test `USB_ENDPOINT_XFER_INT` before `!= USB_ENDPOINT_XFER_BULK`. [F65, F66, F76, F88, F132]
- In `omap_udc.c`, `udc->ep[32]` is indexed by `addr & 0xf` (EP0/OUT) and `16 + (addr & 0xf)` (IN), while `ep->dma_channel` is 1-based (`1..3`, `0` = unassigned) for `UDC_TXDMA()`, `UDC_RXDMA()`, `UDC_TX_DONE_IE()`, `UDC_RX_EOT_IE()`, and `4 * (ep->dma_channel - 1)` shifts; callers of `dma_channel_release` (`omap_ep_dequeue`, `omap_ep_set_halt`, `nuke`) must check `ep->dma_channel != 0` (not `ep->has_dma`). [F79, F100]
- In `omap_udc.c`, `ep0_irq` sets `UDC_DEV_CFG` in `UDC_SYSCON2` and `udc->ep0_set_config = 1` before `driver->setup()`; write `UDC_CLR_CFG` if `setup()` fails or `ep0` stalls, and enable `UDC_EPN_RX_IE | UDC_EPN_TX_IE` in `omap_ep_queue` on success. In `read_fifo`, break before `if (is_last) done(ep, req, 0);` on EP0 (`!ep->bEndpointAddress`) so `ep0_irq` deselects EP0 (`omap_writew(0, UDC_EP_NUM)`) before calling `done()`. [F68, F97]
- In `omap_udc_setup()`, program all `UDC_EP_RX`/`UDC_EP_TX` FIFOs (8-byte aligned, total `<= 2048` bytes) while `UDC_SYSCON1` is 0 and before setting `UDC_CFG_LOCK`. `machine_without_vbus_sense()` must include `machine_is_omap_osk()`, `machine_is_omap_palmte()`, and `machine_is_sx1()`. On OMAP16xx, `omap_udc_probe()` prepares `dc_clk`/`hhc_clk`, so `omap_udc_enable_clock()` (called under `udc->lock`) must only call `clk_enable()` + `udelay(100)` and `clk_disable()`. [F135, F136, F138]
- In `lpc32xx_udc.c`, `iso_status` in `struct lpc32xx_usbd_dd_gad` must stay at offset 24 (`dd->this_dma + 24` in `lpc32xx_ep_queue()`). `lpc32xx_ep_enable` must reject `maxpacket == 0` (`udc_ep_in_req_dma` divides by `ep->ep.maxpacket`). `lpc32xx_udc_probe` must bind `udc->ep[i].udc = udc`, `udc->gadget.ep0`, and call `udc_reinit(udc)`. `lpc32xx_ep_enable`/`lpc32xx_ep_disable` must keep `ep->hwep_num`, `udc->udca_v_base[ep->hwep_num]`, and `udc->enabled_ep_cnt` synced, waking `udc->ep_disable_wait_queue` on disable. [F55, F56, F70, F105]
- In `m66592-udc.c`, guard `clk_disable`/`clk_put` with `if (m66592->pdata->on_chip)`. In `free_pipe_config`, call `pipe_buffer_release` before `m66592_ep_release` clears `ep->pipenum = 0`. In `enable_pipe_irq`/`disable_pipe_irq`, sample `M66592_INTENB0`, clear `M66592_BEMPE | M66592_NRDYE | M66592_BRDYE` before modifying `M66592_BRDYENB`/`M66592_BEMPENB`/`M66592_NRDYENB`, and restore `M66592_INTENB0`. [F39, F58, F59]
- In `max3420_udc.c`, `spi_max3420_enable()` and `spi_max3420_stall()` must return early when `ep->id == 0`. In `max3420_thread`, reset `loop_again = 0` after the sleep block and set `loop_again = 1` whenever any work helper returns true. [F75, F91]
- In register polling loops in `m66592-udc.c` (`set_feature`) and `lpc32xx_udc.c` (`udc_protocol_cmd_w`, `udc_protocol_cmd_r`, `udc_realize_hwep`, `udc_read_hwep`), join the state check and timeout countdown with `&&` (not `||`). In `.dequeue` callbacks (`lpc32xx_ep_dequeue`, `max3420_ep_dequeue`, `net2280_dequeue`, `omap_ep_dequeue`), save a `list_for_each_entry` match into a `NULL`-initialized pointer before `break` rather than testing the loop cursor after the loop. [F84, F86]

## Synchronization
- When draining `ep->queue` via `done()` (`nuke` in `lpc32xx_udc.c`, `net2280.c`, `omap_udc.c`; `handle_stat0_irqs` in `net2280.c`) or `transfer_complete()` (`m66592_disable`), loop with `while (!list_empty(&ep->queue))` and re-fetch `ep->queue.next` because completion drops the spinlock. In `net2280.c` and `omap_udc.c`, `done()` must save `ep->stopped`, set `ep->stopped = 1` before dropping the lock for `usb_gadget_giveback_request()`, and restore `ep->stopped` after relocking. [F13, F87]
- In `m66592-udc.c`, `m66592->ep[0].ep.desc` is `NULL`; `m66592_queue` and `transfer_complete` (after relocking `ep->m66592->lock` and re-reading `ep->queue.next`) must check `ep->ep.desc != NULL` before calling `start_packet(ep, req)`. [F40, F147]
- In `lpc32xx_udc.c`, `done()`, `stop_activity()`, and `udc_handle_ep0_setup()` require `udc->lock` on entry and drop it around `usb_gadget_giveback_request()`, `driver->disconnect()`, and `driver->setup()`. Callers of `isp1301_pullup_enable()` in atomic/`udc->lock` context (`stop_activity()`, `pullup()`) must pass `block = 0` (`pullup_work`), and `lpc32xx_usb_vbus_irq()` must be a threaded IRQ (`IRQF_ONESHOT`) because `vbus_work()` sleeps. [F27, F139, F142]
- In `max3420_udc.c`, SPI helpers (`spi_*`) call `spi_sync()` and must run in kthread context under `udc->spi_bus_mutex` without holding `udc->lock` or `ep->lock` (also dropped for `max3420_req_done()`); IRQ/gadget/ep callbacks must set `udc->todo`/`ep->todo` under spinlock and wake `udc->thread_task`. `max3420_irq_handler()` must only call `disable_irq_nosync(spi->irq)` when `(udc->todo & ENABLE_IRQ) == 0` and set `ENABLE_IRQ` under `udc->lock`, paired with `max3420_thread()` clearing `ENABLE_IRQ` and calling `enable_irq(spi->irq)` under `udc->lock`. [F16, F29, F144]
- In `omap_udc.c`, runtime accesses selecting an endpoint via `UDC_EP_NUM` (`use_ep()`) must hold `udc->lock`, and any path setting `UDC_EP_SEL` must call `deselect_ep()` before unlocking. `ep0_irq()` must bracket `udc->driver->setup()` (with `udc->lock` dropped) with `udc->ep0_setup = 1` and `0` so synchronous EP0 OUT `omap_ep_queue()` calls jump to `irq_wait`. [F21, F32]
- In `net2280.c`/`net2280.h`, after `ep0_start()`, callers of `get_idx_reg()`, `set_idx_reg()`, and `set_max_speed()` must hold `dev->lock`. Under `ep->dev->lock`, `net2280_dequeue()` on a DMA endpoint must set `ep->stopped = 1`, call `stop_dma(ep->dma)`, and run `scan_dma_completions(ep)` before searching `ep->queue`. `fill_dma_desc()` must issue `wmb()` after writing `td->dmaaddr`/`td->dmadesc` before writing `td->dmacount` (`BIT(VALID_BIT)`), paired with `rmb()` in `scan_dma_completions()`. [F22, F23, F24]

## Object Lifetimes
- In `m66592_probe()`, at `err_add_udc`, set `m66592->ep0_req = NULL` after `m66592_free_request()` before falling through to `clean_up:`. In `m66592_remove()`, call `usb_del_gadget_udc()` and `timer_shutdown_sync(&m66592->timer)` before `iounmap()` and `kfree()`. In `get_status`, point `m66592->ep0_req->buf` to `m66592->ep0_data`, not a stack variable. [F1, F31, F112]
- In `max3420_probe()`, any failure after `usb_add_gadget_udc()` must jump to `del_gadget` (`usb_del_gadget_udc()`). [F2]
- In `omap_udc.c`, `dma_channel_release()` must clear `ep->dma_channel = 0` and `ep->lch = -1` but leave `ep->has_dma` set until `nuke()` finishes `done()` (which gates `usb_gadget_unmap_request()` on `use_dma && ep->has_dma`). In `omap_udc_remove()`, set `udc->done` and `wait_for_completion()` after `usb_del_gadget_udc()` before `release_mem_region()`. [F3, F5]
- In `net2280.c`, `net2280_free_request()` frees whatever `req->td` currently points to, and `net2280_remove()` must free `dev->ep[i].dummy` (`i = 1..4`) before `dma_pool_destroy(dev->requests)`, calling `usb_put_gadget(&dev->gadget)` (`gadget_release` calls `kfree(dev)`) only after all `dev` accesses complete. [F6, F7]
- In `lpc32xx_udc.c`, `lpc32xx_stop()` and `!udc->driver` in `lpc32xx_vbus_session()` must drop `udc->lock` and wait on `udc->ep_disable_wait_queue` for `enabled_ep_cnt == 0` before relocking and calling `udc_clk_set(udc, 0)`. `lpc32xx_udc_probe()` must call `of_node_put()` after `isp1301_get_client()`, and teardown must call `dma_pool_destroy()`, `dma_free_coherent()`, and `clk_disable_unprepare()` in reverse order (with `udc_clk_set(udc, 1)` before `udc_disable(udc)` in `lpc32xx_udc_remove()`). [F8, F10, F115]
- In `lpc32xx_udc.c`, `net2280.c`, and `omap_udc.c`, use `list_del_init(&req->queue)` (not `list_del()`). For non-EP0 (`ep->lep != 0`) in `lpc32xx_udc.c`, `lpc32xx_ep_queue()` calls `usb_gadget_map_request()` and `udc_dd_alloc()`, paired with `usb_gadget_unmap_request()` and `udc_dd_free()` in `done()`. [F9, F17]

## API Contracts
- In `lpc32xx_udc.c`, `net2280.c`, and `omap_udc.c`, map DMA requests with `usb_gadget_map_request()` in `.queue` before locking and unmap with `usb_gadget_unmap_request()` in `done()` before unlocking for `usb_gadget_giveback_request()`. `.udc_start` callbacks across all five drivers must not modify `driver->driver.bus`. [F152, F156]
- In `lpc32xx_udc.c`, `udc_ep0_in_req`/`udc_ep0_out_req` return `1` on completion, so `lpc32xx_ep_queue` must return `(status < 0) ? status : 0`. `udc_dd_alloc()` must use `GFP_ATOMIC | GFP_DMA`. `uda_enable_devint`/`uda_disable_devint`/`uda_clear_devint` take pre-shifted bitmasks, whereas `uda_*_hwepint` and `udc_ep_dma_*` take unshifted `hwep` (`0..31`). [F37, F38, F143]
- In `m66592-udc`, `m66592_mdfy(m66592, val, pat, offset)` takes set-bits `val` second and clear-mask `pat` third. `setup_packet` returns `1` to delegate to `driver->setup` and `0` when handled internally (never negative errno). In `max3420_udc.c`, `spi_rd_buf()`/`spi_wr_buf()` require `len <= MAX3420_EP_MAX_PACKET` (64). [F42, F43, F74]
- In `net2280.c`, `net2280_alloc_request()` must pass `gfp_flags` to both `kzalloc()` and `dma_pool_alloc()` and free `req` on pool failure. `net2280_queue()` rejects `_req->length > DMA_BYTE_COUNT_MASK`; PIO `write_fifo()`/`read_fifo()` must use `get_unaligned()`/`put_unaligned()` with `cpu_to_le32s()` and call `set_fifo_bytecount()` only on the final word. `registers_show`/`queues_show` must use `scnprintf(next, size, ...)` and abort `queues_show` if `t <= 0 || t > size`. [F78, F151, F162]
- In `omap_udc.c`, `write_fifo`/`read_fifo` return `1` when complete (having called `done()` for non-EP0), so `omap_ep_queue` must set `req = NULL` on `1`. Endpoint names passed to `omap_ep_setup` (including `OMAP_*_EP` suffixes) must be `<= 13` chars (`ep->name` is `char[14]`). [F50, F113]

## Error Handling
- In `lpc32xx_udc_probe`, check `devm_platform_ioremap_resource`/`devm_clk_get` with `IS_ERR` and `isp1301_get_client`/`dma_alloc_coherent`/`dma_pool_create` for `NULL`. In `lpc32xx_ep_*` callbacks, do not dereference `ep->udc` (or call `ep_dbg`) before verifying `_ep`/`ep` non-NULL. [F34, F35]
- In `max3420_probe`, `of_irq_get_byname(..., "vbus") <= 0` is non-fatal (sets `is_selfpowered = 1`, `vbus_active = true`), unlike `"udc"`. In `net2280_*` ep ops, early `!_ep` checks must use `pr_err` and return (not `goto print_err;`). In `omap_udc.c`, check `!IS_ERR_OR_NULL(udc->transceiver)` because `usb_get_phy()` can return `ERR_PTR`. [F45, F46, F51]

## Known Pitfalls
- In `m66592-udc.c`, `pipenum2ep` is indexed by `pipenum` (`0..M66592_MAX_NUM_PIPE - 1`) while `epaddr2ep` is indexed by USB ep number (`w_index & USB_ENDPOINT_NUMBER_MASK`); pass `ep->pipenum` to pipe helpers, and handle `pipenum == 0` via `M66592_DCPCTR` because `get_pipectr_addr(pipenum)` is 1-based. Internal control transfers without a queued request (`clear_feature`, `set_feature`) must call `control_end(m66592, 1)`. [F57, F72, F92]
- In `m66592-udc.c`, `m66592_read_fifo` uses ceiling division (`(len + 3) / 4` or `(len + 1) / 2`) and `start_packet_read` programs `ep->fifotrn` with `(req->req.length + ep->ep.maxpacket - 1) / ep->ep.maxpacket`, whereas `m66592_write_fifo` uses truncating division (`len / 4` or `len / 2`) and writes tail bytes via `iowrite8()` to `fifoaddr + (3 - i)` if `M66592_CFBCFG` else `fifoaddr + i` (toggling `M66592_MBW_16` when `wr0_shorted_to_wr1`). Wait `ndelay(450)` in `pipe_change()`/`pipe_initialize()` after writing `M66592_CURPIPE` before setting `MBW` or accessing FIFO. `m66592_irq()` must save/restore `M66592_CFIFOSEL` and, if `on_chip` and `intsts0 == 0 && intenb0 == 0`, call `m66592_start_xclock()` and re-read. [F73, F102, F103, F104, F122, F125]
- In `lpc32xx_udc.c`, `udc->ep[]` uses logical index `ep->lep`, whereas `udc->udca_v_base[]`, protocol engine commands, and bitmasks use `ep->hwep_num` (`0..31`). In `udc_pop_fifo`/`udc_stuff_fifo`, shift by `i * 8` (not `n * 8`) with `bl` capped to `4`. `udc_protocol_cmd_w()` must read `USBD_DEVINTST` before clearing `USBD_CCEMPTY` and polling. When `udc->atx == STOTG04`, omit `MC2_SPD_SUSP_CTRL` and `MC2_GLOBAL_PWR_DN`. [F83, F94, F119, F120]
- In `net2280`, in `handle_stat0_irqs` (`USB_RECIP_ENDPOINT`), target `e = get_ep_by_addr(dev, w_index)` for halt/DMA helpers and `ep` (`&dev->ep[0]`) for `allow_status`/`set_fifo_bytecount`. `set_fifo_bytecount()` uses `writeb()` to offset 2 of `&ep->regs->ep_cfg` on vendor `0x17cc` and 32-bit RMW of `&ep->cfg->ep_cfg` otherwise. On `PLX_PCIE`, `net2280_irq()` must clear and restore bit 31 of `dev->regs->pciirqenb1`. [F98, F129, F130]
- In `omap_udc.c`, RMW of `UDC_TXDMA_CFG`/`UDC_RXDMA_CFG` in `dma_channel_claim`/`dma_channel_release` must OR `UDC_DMA_REQ`, and `write_packet`/`read_packet` must set `buf = (u8 *)wp` after the 16-bit loop. In `max3420_udc.c`, clear `ENABLE_EP`/`STALL_EP` before setting `ep->todo` and test `todo` with `==` (not `&`) because `DISABLE`/`UNSTALL` are 2-bit supersets of `ENABLE`/`STALL`. [F67, F85, F110]
