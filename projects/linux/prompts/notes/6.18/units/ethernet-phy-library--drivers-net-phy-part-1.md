# ETHERNET PHY LIBRARY — drivers/net/phy (part 1)

Ethernet PHY drivers for Broadcom, TI DP83xxx (including DP83640 PTP), Marvell 88Q2xxx/88X2222, Intel XWAY, ICPlus, LXT, Cicada, Cortina, Davicom, ET1011C, `fixed_phy.c`, and `linkmode.c`.

## Architecture & Data Flow
- In `fixed_phy.c`, `fp->phydev` is only set by `fixed_phy_set_link_update()` alongside `fp->link_update` (remaining NULL after `__fixed_phy_add()` / `fixed_phy_register()`), so `fixed_mdio_read()`, `fixed_phy_change_carrier()`, and `fixed_phy_del()` must gate `fp->phydev` dereferences on `fp->link_update` or a NULL check. [F217]
- In `dp83640_probe()`, `phydev->mdio.addr == BROADCAST_ADDR` returns 0 without allocating `dp83640_private` or a `dp83640_clock`, so `dp83640_remove()` must return immediately on `BROADCAST_ADDR` before dereferencing `phydev->priv`. [F193]
- In `dp83640.c`, `enable_status_frames()` must set `ENDIAN_FLAG` in `PSF_CFG0` because `decode_status_frame()` and `decode_evnt()` cast packet bytes directly to host-endian `u16`, `phy_rxts`, and `phy_txts`. `decode_evnt()` must verify `len >= parsed` before dereferencing `data` and only read `phy_txts` words up to `words` (`0..3`). `recalibrate()` must save `PSF_CFG0` (`PAGE5`) into `tmp->cfg0` and master `cfg0`, clear it to 0 before calibration, and restore it on all PHYs before unlocking `extreg_lock`. [F227, F251, F252]
- In `dp83640.c`, `gpio_tab` only seeds `clock->caps.pin_config` in `dp83640_clock_init()`; `periodic_output()`, `ptp_dp83640_enable()`, and `recalibrate()` must query `clock->ptp_clock` via `ptp_find_pin*()`. External timestamp channels (`rq->extts.index`, `event.index`) are `0..N_EXT_TS - 1` while hardware events start at `EXT_EVENT` (1), so `ptp_dp83640_enable()`, `decode_evnt()`, and `exts_chan_to_edata()` must translate via `ch + EXT_EVENT` and bounds-check `index < N_EXT_TS`. [F229, F250]
- In `dp83822.c` and `marvell-88q2xxx.c`, every `phy_driver` entry using callbacks that dereference `phydev->priv` (`dp83825_config_init`, `dp83826_config_init`, `dp83822_set_wol`, `mv88q2xxx_config_init`, etc.) must wire a `.probe` callback (`dp8382x_probe`, `dp83822_probe`, `dp83826_probe`, `mv88q2xxx_probe`). [F208]
- In `bcm54140.c`, `bcm54140_get_base_addr_and_port()` must check `(max_addr - min_addr + 1) % 4 == 0` to derive `priv->port` (`0..3`), and reset `addr = phydev->mdio.addr` before `step++` on boundary/ID mismatch. Global RDB registers (`BCM54140_RDB_TOP_IMR`) require `bcm54140_base_read_rdb()` / `bcm54140_base_write_rdb()`, and `bcm54140_config_intr()` must modify only `port_to_imr_bit[priv->port]`. [F231, F253, F271]
- In `bcm7xxx.c`, 28nm GPHY Wirespeed/downshift and EEE are mutually exclusive: `bcm7xxx_28nm_config_init()` and `bcm7xxx_28nm_set_tunable()` must call `bcm_phy_set_eee(phydev, count == DOWNSHIFT_DEV_DISABLE)` (and restart AN in `set_tunable`). [F232]
- In `bcm84881.c`, `bcm84881_probe()` must check `(phydev->c45_ids.devices_in_package & mmd_mask) != mmd_mask` for `MDIO_DEVS_PMAPMD | MDIO_DEVS_AN`. In `bcm84881_read_status()`, after `phy_resolve_aneg_linkmode()`, it must read `MDIO_MMD_VEND1` `0x4011` and update `phydev->interface` and `phydev->speed` in lockstep. [F247, F263]
- In `bcm87xx_of_reg_init()`, `len` must be divided by `sizeof(*paddr)` and iterated with `while (paddr + 3 < paddr_end)` so each 4-cell tuple is in bounds. [F257]
- In `dp83td510.c` and `dp83tg720.c`, TDR completion in `dp83td510_cable_test_get_tdr_status()` or `dp83tg720_cable_test_get_status()` must call `phy_init_hw(phydev)` to exit TDR test mode. On `dp83tg720`, `dp83tg720_update_stats()` must run before `phy_init_hw()` (and `dp83tg720_config_aneg()` after `phy_init_hw()` in `dp83tg720_read_status()`). `dp83tg720_config_aneg()` and `dp83tg720_config_init()` must call `genphy_c45_pma_baset1_read_master_slave(phydev)`. [F235, F236, F237]
- All `jiffies` deadlines (`rxts->tmo`, `skb_info->tmo`, `priv->last_link_down_jiffies`) must use `unsigned long` and `time_after()` / `time_before()`. In `dp83tg720_get_next_update_time()`, `priv->last_link_down_jiffies` must be cleared to 0 when `phydev->link` is true, and returned jiffies must be clamped via `max(next_time_jiffies, 1U)`. [F238, F281, F338]
- In `dp83td510_get_sqi()`, `dp83td510_mse_sqi_map[]` must stay in descending MSE order for `mse_val >= dp83td510_mse_sqi_map[sqi]`. [F265]
- In `marvell-88q2xxx.c`, volatile settings (`mv88q2xxx_enable_temp_sense()`, LED0 `TX_DISABLE` clear) must be applied in `mv88q2xxx_config_init()`. In `mv88q2xxx_read_status()`, when `AUTONEG_ENABLE`, `mv88q2xxx_read_aneg_speed()` must precede `mv88q2xxx_read_link()`. In `mv88q2xxx_handle_interrupt()`, `MDIO_MMD_PCS_MV_COPPER_INT_STAT` must be read before `MDIO_MMD_PCS_MV_GPIO_INT_STAT` without returning early on 100BASE-T1 events. [F239, F240, F274]
- In `marvell-88x2222.c`, mutating `priv->line_interface` (`mv2222_sfp_insert()`, `mv2222_swap_line_type()`) requires calling `mv2222_config_line(phydev)`. [F243]
- In `dp83822_phy_reset()` and `dp83869_phy_reset()`, writing `SW_RESET` resets all registers and must be followed by `config_init(phydev)`. [F244]
- In `dp83867_led_hw_control_set()` and `dp83td510_led_hw_control_set()`, setting triggers in `LEDCR1` / `LEDS_CFG_1` must clear `LED_DRV_EN(index)` in `LEDCR2` / `LEDS_CFG_2`. Conversely, in `xway_gphy_led_hw_control_set()`, configuring `XWAY_MMD_LEDxH`/`LEDxL` must set `XWAY_GPHY_LED_EN(index)` in `XWAY_MDIO_LED`. [F245, F246]

## Synchronization
- In `dp83640.c`, `dp83640_clock_get()` and `dp83640_clock_get_bus()` return `clock` with `clock->clock_lock` held, requiring `dp83640_clock_put()` on every exit path. `clock_lock` protects `chosen`, `phylist`, and `ptp_clock`, and must never be held while acquiring `phyter_clocks_lock`. In `dp83640_clock_get_bus()`, `dp83640_clock_init()` must complete before linking into `phyter_clocks` and unlocking `phyter_clocks_lock`. In `dp83640_probe()`, `clock->chosen` must be set before `ptp_clock_register()` and reset to NULL on failure before `dp83640_clock_put()` and `kfree(dp83640)`. [F188, F200, F201, F202]
- In `dp83640.c`, `ext_read()`, `ext_write()`, `tdr_write()`, and `enable_broadcast()` require holding `clock->extreg_lock`. `dp83640_rxtstamp()`, `dp83640_txtstamp()`, and `decode_status_frame()` run in packet contexts and must never do sleeping MDIO accesses or take mutexes. In `decode_rxts()`, `dp83640->rx_lock` must be acquired before `dp83640->rx_queue.lock`, and both released before `netif_rx()`. [F197, F199, F319]
- In `bcm54140.c`, `priv->alarm_lock` must be initialized before `bcm54140_probe_once()` and held across the `BCM54140_RDB_MON_ISR` read, `priv->alarm` latch, and clear sequence in `bcm54140_hwmon_read_alarm()`. `bcm54140_base_read_rdb()` and `bcm54140_base_write_rdb()` must hold `phy_lock_mdio_bus(phydev)` across both address and data phases on `BCM54140_BASE_ADDR`. [F204, F205]
- Callbacks invoked with `mdio_lock` held—`bcm7xxx_28nm_ephy_read_mmd()`, `bcm7xxx_28nm_ephy_write_mmd()`, `ip101g_read_page()`, `ip101g_write_page()`, and regions between `phy_select_page()` and `phy_restore_page()` in `icplus.c`—must use unlocked helpers (`__phy_read`, `__phy_write`, `__phy_modify`, `__phy_set_clr_bits`). [F206, F325]
- In `mv2222_sfp_insert()`, `mv2222_config_aneg(phydev)` must be guarded by `mutex_trylock(&phydev->lock)`, not `mutex_lock()`. [F342]

## Object Lifetimes
- In `dp83640_remove()`, clear `phydev->mii_ts`, call `enable_status_frames(phydev, false)`, `cancel_delayed_work_sync(&dp83640->ts_work)`, and `skb_queue_purge()` on `rx_queue`/`tx_queue` before unregistering `ptp_clock` or freeing `dp83640_private`. When `!clock->chosen && list_empty(&clock->phylist)`, unlink `clock->list` under `phyter_clocks_lock`, destroy `extreg_lock` and `clock_lock`, call `put_device(&clock->bus->dev)`, and `kfree(clock->caps.pin_config)` and `clock`. [F191, F291]
- In `fixed_phy_register()`, `__fixed_phy_add()` must precede `get_phy_device()`, and errors must unwind `ida_alloc_max()`, `__fixed_phy_add()`, `get_phy_device()`, and `of_node_get(np)`. `fixed_phy_unregister()` must call `phy_device_remove()`, `of_node_put()`, `fixed_phy_del()`, and `phy_device_free()` in that order. [F207, F295]
- In `bcm54140_probe()`, `devm_phy_package_join()` must precede `phy_package_init_once(phydev)`, gating `bcm54140_probe_once()`. [F298]
- In `dp83822_of_init_leds()` and `mv88q2xxx_leds_probe()`, `leds` from `of_get_child_by_name()` requires `of_node_put(leds)` on every exit path, even with `for_each_available_child_of_node_scoped()`. In `dp83867_of_init_io_impedance()`, release `cell` via `nvmem_cell_put(cell)` and `kfree(buf)` when `!IS_ERR(buf)`. [F195, F306]

## API Contracts
- `dp83640_rxtstamp()` consumes `skb` iff it returns `true`; `dp83640_txtstamp()` unconditionally consumes `skb` on every path. `decode_evnt()` must always return a positive byte count (`parsed` or `len` on truncation) so `decode_status_frame()` advances `ptr` and terminates. [F192, F285]
- In `dp83640.c`, GPIO numbers in `gpio_tab[]`, `TRIG_GPIO`, and `EVNT_GPIO` are 1-based (`0` = disabled), while `pin_config[]` indices and `ptp_find_pin*()` returns are 0-based (or `-1`), requiring `- 1` / `1 +` (with `< 1` check) conversions. In `ptp_dp83640_enable()`, rejecting dual-edge requests under `PTP_STRICT_FLAGS` requires `(rq->extts.flags & PTP_EXTTS_EDGES) == PTP_EXTTS_EDGES`. [F212, F264]
- `fixed_phy_register()` always returns an `ERR_PTR` on failure (never NULL); callers must check `IS_ERR()`. [F218]
- In `bcm7xxx.c`, `__phy_set_clr_bits(dev, loc, set_mask, clr_mask)` and `phy_set_clr_bits()` take `set_mask` 3rd and `clr_mask` 4th (opposite to `phy_modify`). [F223]
- In `mv88q222x`, `dp83td510`, and `dp83tg720` cable test status callbacks: fault distance in meters must be multiplied by 100 for `ethnl_cable_test_fault_length*()`; `*finished` must be initialized to `false` before polling completion bits; and `PHY_POLL_CABLE_TEST` must be set in `phy_driver::flags` (`bcm54140`, `dp83td510`, `dp83tg720`, `mv88q2220`). [F224, F225, F335]
- In `bcm54140.c` and `marvell-88q2xxx.c`, hwmon `drvdata` is `struct phy_device *`, so callbacks must access private state via `phydev->priv`. In tunable callbacks (`bcm54140`, `dp83867`, `dp83869`, `bcm7xxx`), `void *data` is `u8 *` for `ETHTOOL_PHY_DOWNSHIFT` and `u16 *` for `ETHTOOL_PHY_EDPD`. [F289, F290]
- In `dp83869_configure_mode()`, `PHY_INTERFACE_MODE_MII` must permit `DP83869_RGMII_COPPER_ETHERNET` alongside `100M_MEDIA_CONVERT` and `RGMII_100_BASE`. [F262]
- In `config_intr` callbacks, enabling interrupts must ack pending status before unmasking; disabling must mask before acking. `linkmode_set_pause()` sets `Pause_BIT` to `rx` and `Asym_Pause_BIT` to `rx ^ tx`. DT MDIO guards must use `#if IS_ENABLED(CONFIG_OF_MDIO)`, not `#ifdef`. [F326, F341, F345]

## Error Handling
- In `dp83640_clock_get_bus()`, if `pin_config` allocation fails, `kfree(clock)` and set `clock = NULL` before `goto out`. In `enable_status_frames()`, check `if (!phydev->attached_dev)` before `dev_mc_add()` / `dev_mc_del()`. [F215, F216]
- In `dp83869_of_init()`, reset `ret = 0` after using `ret` for `phy_read_mmd()` so `dp83869_probe()` does not see a non-zero error. [F219]
- In `icplus.c`, after `oldpage = phy_select_page()`, all paths must return via `phy_restore_page(phydev, oldpage, ret)` with `ret` initialized. In `ip101g_get_stat()`, store `phy_read_paged()` in signed `int val` and return `U64_MAX` if `val < 0`. [F220, F221]
- In `xway_gphy_led_polarity_set()`, return `-EINVAL` if neither polarity flag is set. In `bcm84881_aneg_done()` and `bcm84881_read_status()`, check and return `bmsr` (not `val`) on the second `phy_read_mmd()`. In all `handle_interrupt` callbacks, negative read errors must call `phy_error(phydev)` and return `IRQ_NONE`. [F260, F261, F340]

## External Contracts
- In `dp83640.c`: `dp83640_soft_reset()` must delay >= 3 us (`udelay(10)`) after `genphy_soft_reset()`; `dp83640_hwtstamp()` must update `cfg->rx_filter` to the programmed `*_EVENT` filter and return `-ERANGE` for unsupported filters; `ptp_dp83640_verify()` must return `1` if `func == PTP_PF_PHYSYNC` or if `pin_config[pin].func == PTP_PF_PHYSYNC && !list_empty(&clock->phylist)`. [F294, F331, F333]
- In `mv88q2xxx_read_link_gbit()` and `mv88q2xxx_read_link_100m()`, when `phy_polling_mode(phydev) && phydev->link`, read the status register only once to preserve latched-low link drops. [F241]
- In `dp83822`, `dp83tc811`, `dp83867`, and `dp83869` WoL: pack 6-byte `dev_addr` (`is_valid_ether_addr()`) and `sopass` into `DA1..DA3` / `RXSOP1..RXSOP3` as `(byte[2*i + 1] << 8) | byte[2*i]`. In `dp83822_suspend()` and `dp83811_suspend()`, skip `genphy_suspend()` if `WOL_EN` is set, and set `WOL_CLR_INDICATION` on resume. [F256, F304]
- In `dp83td510_update_stats()` and `dp83tg720_update_stats()`, read `PKT_STAT_1..3` and `PKT_STAT_4..6` in strict ascending order, checking each `ret < 0` and combining halves in `u32 count` (`count |= ret << 16`) before adding to `u64` stats. [F258, F283]
- `bcm84881_config_aneg()` must call `bcm84881_wait_init()` before writing AN registers. `dp83848.c` drivers must set `PHY_RST_AFTER_CLK_EN`. `dp83867_link_change_notify()` must toggle `DP83867_SGMII_AUTONEG_EN` on `PHY_INTERFACE_MODE_SGMII` without mutating `struct phy_device`. `dp83869` in `DP83869_RGMII_1000_BASE` mode must use `genphy_c37_config_aneg()` / `genphy_c37_read_status()`. `dp83tg720_config_init()` must write `DP83TG720S_LPS_CFG3_PWR_MODE_0` after `dp83tg720_soft_reset()`. [F301, F305, F307, F308, F310, F339]

## Known Pitfalls
- In `lxt.c`, `lxt973_probe()` sets `phydev->priv = lxt973_probe` as a boolean flag; never dereference or `kfree(phydev->priv)`. [F222]
- In `mv2222_set_sgmii_speed()`, `SPEED_1000` and `SPEED_100` must `fallthrough` when unsupported in `priv->supported`. [F266]
- In `dp83640.c`: `dp83640_txtstamp()` `HWTSTAMP_TX_ONESTEP_SYNC` must free `skb` and return only if `ptp_msg_is_sync(skb, type)`, else `fallthrough`; `decode_rxts()` must `break` after `__skb_unlink()` and guard `netif_rx(skb)` with `if (shhwtstamps)`; `rx_timestamp_work()` must `break` (not `continue`) after `skb_queue_head()` on an unexpired SKB. [F268, F269, F273]
- In `dp83640.c`: `phy2rxts()` / `phy2txts()` must mask `p->ns_hi & 0x3fff` and form `u32 sec` before `(u64)sec * 1000000000ULL`; `ptp_dp83640_gettime()` must hold `PTP_TDR` reads in `unsigned int val[]` so `val[3] << 16` does not sign-extend; `ptp_dp83640_adjfine()` must negate negative `scaled_ppm` and widen to `u64 rate` before `<< 13` and `div_u64(rate, 15625)`. [F278, F279, F280]
- In `bcm54140_hwmon_write_temp()` and `bcm54140_hwmon_write_in()`, clamp `val` with `clamp_val()` (note `TO_TEMP(mask)` is the lower bound) before `FROM_TEMP()` / `FROM_IN()`. [F282]
