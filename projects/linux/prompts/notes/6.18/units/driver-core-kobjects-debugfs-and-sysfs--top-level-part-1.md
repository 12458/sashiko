# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS — (top level) (part 1)

Implements core Linux device model subsystems (platform bus, NUMA node and CPU topology sysfs interfaces, SoC bus, syscore PM, pinctrl binding, MSI helpers, and transport classes), along with sysfs, debugfs, and core headers for devices, kobjects, devres, and firmware properties.

## Architecture & Data Flow

- `struct bin_attribute` must keep `struct attribute attr` at offset 0 so `sysfs_kf_bin_*()` can cast `of->kn->priv` (`&battr->attr`) to `const struct bin_attribute *`. In `sysfs_add_{bin_}file_mode_ns()`, `kernfs_ops` selection must check combined callbacks (`show && store`, or `battr->mmap` then `read && write`) before single callbacks. [F95, F118]
- In `__first_visible()`, check both `grp->attrs` / `grp->bin_attrs` and `[0]` for non-`NULL`; if both arrays exist, only `grp->is_visible(kobj, grp->attrs[0], 0)` controls directory visibility. Guard `kernfs_remove(kn)` with `if (grp->name)` in `internal_create_group()` and `sysfs_remove_group()` (`kn` aliases `kobj->sd` when `grp->name == NULL`). `sysfs_kf_read()` must verify `buf == of->prealloc_buf` before `ops->show()` and shift non-zero `pos` via `memmove(buf, buf + pos, len)`. `sysfs_{link_change_owner,rename_link_ns}()` must look up `kn` under `kobj->sd` using `targ->sd->ns` and check `kernfs_type(kn) == KERNFS_LINK` and `kn->symlink.target_kn->priv == targ`. [F51, F67, F69, F98, F109]
- In `__debugfs_create_file()`, `real_fops == NULL` requires `inode->i_fop = &debugfs_noop_file_operations` (not proxy fops), and `mode` must only use `S_IFREG`. `__debugfs_file_get()` must set the matching `HAS_*` bit in `fsd->methods` for every callback proxied by `FULL_PROXY_FUNC` / `SHORT_PROXY_FUNC`. `debugfs_get_tree()` must call `debugfs_reconfigure(fc)` after `get_tree_single(fc, debugfs_fill_super)` succeeds. On remount, `_debugfs_apply_options()` must only update root inode fields whose `BIT(Opt_*)` is set in `fsi->opts` (preserving `~S_IALLUGO` on `i_mode`), and `debugfs_parse_param()` must check `opt < 0` before `BIT(opt)`. [F49, F57, F58, F65, F113]
- In `drivers/base/node.c`, `node_state_attr[]` needs `NR_NODE_STATES` entries and `node_state_attrs[]` needs `NR_NODE_STATES + 1`; `register_memory_node_under_compute_node()` links `"targets"` under `&initiator->dev.kobj` to `&targ_node->dev.kobj` and `"initiators"` under `&target->dev.kobj` to `&init_node->dev.kobj`; updating `ACCESS_COORDINATE_CPU` in `node_{set,update}_perf_attrs()` must call `mempolicy_set_node_perf(nid, coord)`. In `platform_get_{resource,mem_or_io}()`, `resource_type(r)` must precede `num-- == 0` in `&&`. In `devm_platform_get_irqs_affinity()`, set `ptr->count = nvec` before indexing `ptr->irq[]`, after checking `maxvec >= minvec` and clamping `nvec`. Unsigned rollback loops in `platform_device_add()` and `platform_*register_drivers()` must use `while (i--)` / `while (count--)`. [F62, F83, F85, F88, F102, F105]
- In `struct property_entry`, `is_inline` selects `value` (`true`) vs `pointer` (`false`), and `length` is byte size (`_len_ * sizeof(element)`), not element count. In `drivers/base/soc.c`, every `soc_attr[]` entry must be handled in both `soc_attribute_mode()` and `soc_info_show()`. Zero-initialized `struct device` boolean bitfields (e.g., `dma_skip_sync`) must treat `0` (`false`) as the safe default. [F56, F64, F93]

## Synchronization

- In `__debugfs_file_get()`, initialize all `struct debugfs_fsdata` fields (`active_users`, `active_users_drained`, `cancellations`, `cancellations_mtx`) before `cmpxchg(&dentry->d_fsdata, NULL, fsd)` (destroying `cancellations_mtx` before `kfree(fsd)` on race loss), and check `d_unlinked(dentry)` between `cmpxchg` and `refcount_inc_not_zero(&fsd->active_users)`, pairing with `smp_mb()` before `READ_ONCE(dentry->d_fsdata)` in `__debugfs_file_removed()`. [F20, F21]
- `fsd->cancellations` requires `fsd->cancellations_mtx`: `__debugfs_file_removed()` returns immediately if `refcount_dec_and_test(&fsd->active_users)` is `true`, and when `false` dequeues entries via `list_del_init(&c->list)` and calls `c->cancel()` under `cancellations_mtx` before `wait_for_completion(&fsd->active_users_drained)`. `debugfs_enter_cancellation()` must call `if (d_unlinked(dentry)) complete(&fsd->active_users_drained);` after unlocking `cancellations_mtx`, and `debugfs_leave_cancellation()` checks `!list_empty(&cancellation->list)` under `cancellations_mtx`. [F22, F23, F90]
- `sysfs_file_kobj()` must read `rcu_dereference(kn->__parent)->priv` under RCU read lock, and `sysfs_file_ops()` requires an active reference on `kn`. Sysfs cpumask binary readers (`cpumap_read()`, `cpulist_read()`, `define_siblings_read_func()`) must copy the live cpumask into a local `cpumask_var_t` before `cpumap_print_*_to_buf()`. [F27, F59]
- `platform_dma_configure()` must load `READ_ONCE(dev->driver)` once and check non-`NULL` before `to_platform_driver(drv)->driver_managed_dma`. `driver_override_show()` must hold `device_lock(dev)` while reading `pdev->driver_override`. `__platform_driver_probe()` must reject `PROBE_PREFER_ASYNCHRONOUS`, set `PROBE_FORCE_SYNCHRONOUS`, `prevent_deferred_probe = true`, and `suppress_bind_attrs = true` before registration, and set `drv->probe = platform_probe_fail` after. [F29, F30, F31]
- `syscore_ops_lock` serializes `{un}register_syscore_ops()` and `syscore_shutdown()` (`.shutdown` callbacks must not register/unregister ops), while `syscore_suspend()` and `syscore_resume()` run locklessly on one CPU with IRQs disabled. `device_lock_{set,reset}_class()` require `device_lock(dev)` held, and `device_lock_set_class()` requires `dev->mutex` to match `__lockdep_no_validate__`. [F33, F145, F156]

## Object Lifetimes

- In `register_one_node()`, run `INIT_LIST_HEAD(&node->access_list)` before setting `node_devices[nid]` and calling `register_node()`; if `device_register(&node->dev)` fails, `put_device()` frees `node` via `node_device_release()`, so set `node_devices[nid] = NULL` and return without `kfree(node)`. `unregister_node()` must unregister all children (`node_remove_accesses()`, `node_remove_caches()`—`cache_attrs` before `cache_dev`—using `list_for_each_entry_safe()`, plus hugetlb/compaction/reclaim) before `device_unregister(&node->dev)`, and `unregister_one_node()` must clear `node_devices[nid] = NULL`. [F1, F2, F32, F101]
- `platform_device_release()` frees `platform_data`, `resource`, and `struct platform_object`, so `platform_device_add_{resources,data}()` require `platform_device_alloc()` devices and must `kmemdup*()` the new buffer before `kfree()`ing the old one. On `platform_device_add()` failure or `platform_device_del()`, if `pdev->id_auto` is set, call `ida_free(&platform_devid_ida, pdev->id)` and reset `pdev->id = PLATFORM_DEVID_AUTO`, and `release_resource(r)` on resources with `r->parent`. [F6, F7, F119]
- In `soc_device_register()`, once `soc_dev->dev.release = soc_release` is set, `device_register()` failure must clean up via `put_device(&soc_dev->dev)` without jumping to `out3`, while `soc_dev->attr` remains caller-owned until after `soc_device_unregister()`. `transport_remove_device()` does not drop the `classdev` reference; callers not using `transport_unregister_device()` must also call `transport_destroy_device()`. [F9, F143]
- After `debugfs_start_creating()`, any failure must call `failed_creating(dentry)` (unlocking the parent inode, `dput(dentry)`, and `simple_release_fs()`) and free caller allocations (e.g., `link` in `debugfs_create_symlink()`). `debugfs_enter_cancellation()` must be paired with `debugfs_leave_cancellation()` before stack `struct debugfs_cancellation` scope ends and before `debugfs_file_put()`. [F13, F15]
- `full_proxy_release()` must call `real_fops->release(inode, file)` unconditionally without `debugfs_file_get()`, and `.release` handlers must not assume `inode->i_private` outlives `debugfs_remove()`. Writable `debugfs_create_str()` requires a `kmalloc`-allocated `*value` because `debugfs_write_file_str()` `kfree()`s the old buffer. `debugfs_create_devm_seqfile()` stores `devm_kzalloc()` memory in `inode->i_private` without auto-removing the dentry, so the dentry must be removed before `device_del()` (which releases all `devm_*` resources even without a driver or bus). [F24, F122, F130, F132]
- `sysfs_break_active_protection()` must pin `kobj` and `kn` before `kernfs_break_active_protection(kn)`, and `sysfs_unbreak_active_protection()` must read `kobj = sysfs_file_kobj(kn)` before `kernfs_unbreak_active_protection(kn)` and `kernfs_put(kn)`. In `internal_create_group()`, if `update && grp->name` and `kernfs_find_and_get()` returns `NULL`, reset `update = 0` to skip the extra exit `kernfs_put(kn)`. Early exits from `{fwnode,device}_for_each_*child_node()` require `fwnode_handle_put(child)`. [F19, F28, F97]

## API Contracts

- After `platform_device_{alloc,register}()` initializes `pdev->dev`, use `platform_device_put(pdev)` on error, never `kfree(pdev)`. `platform_device_alloc()` and `platform_get_{resource,mem_or_io,resource_byname}()` return `NULL` on failure, whereas `platform_device_register_full()`, `__platform_create_bundle()`, and `devm_platform_*ioremap_resource*()` return `ERR_PTR()`. `platform_get_irq*()` rejects IRQ `0` with `-EINVAL`, falls through from `of_irq_get()` to `IORESOURCE_IRQ` on non-`-EPROBE_DEFER` errors, returns `-ENXIO` if missing, and returns `> 0` on success. [F5, F34, F35, F36, F106]
- In `platform_match()`, non-`NULL` `pdev->driver_override` must immediately return `!strcmp(pdev->driver_override, drv->name)`, and non-`NULL` `pdrv->id_table` must return `platform_match_id()` without falling back to `pdev->name`. `platform_dma_{configure,cleanup}()` use `iommu_device_use_default_domain` unless `pdrv->driver_managed_dma` is `true`. `*devm_add_action_or_reset()` runs `action(data)` on error so callers must not re-invoke it; `devm_{kmalloc,kcalloc,krealloc,kmemdup}_array` must check overflow via `check_mul_overflow()` or `size_mul()`. [F18, F103, F114, F142]
- In `debugfs_{start_creating,lookup,create_devm_seqfile}()`, `parent == NULL` selects the root while `IS_ERR(parent)` must abort. Dentry-returning `debugfs_create_*()` always return `ERR_PTR()` on error or `CONFIG_DEBUG_FS=n`, whereas `debugfs_lookup()` returns `NULL` on miss when `CONFIG_DEBUG_FS=y` and `ERR_PTR(-ENODEV)` when `n`. `debugfs_enter_cancellation()` requires non-`NULL` `cancellation->cancel` and must run `INIT_LIST_HEAD(&cancellation->list)` before any early return. [F45, F46, F48]
- `debugfs_file_get()` uses `DBGFS_GET_ALREADY` (`-EINVAL` if unopened); proxy `.open` handlers (`open_proxy_open()`, `full_proxy_open_short()`) must pass `DBGFS_GET_{REGULAR,SHORT}` to `__debugfs_file_get()` and map `-EIO` to `-ENOENT`. `debugfs_create_file()` forbids `real_fops->open` from replacing `filp->f_op`, while `debugfs_create_file_unsafe()` replaces `filp->f_op` with `real_fops` so its callbacks must bracket private-data access with `debugfs_file_{get,put}()`. Signed debugfs attributes (`DEFINE_DEBUGFS_ATTRIBUTE_XSIGNED`, `fops_atomic_t`) must use `DEFINE_DEBUGFS_ATTRIBUTE_SIGNED`. [F44, F110, F159, F161]
- `sysfs_emit{_at}()` require page-aligned `buf`, and `sysfs_emit_at()` requires `0 <= at < PAGE_SIZE` and returns bytes written at `buf + at` (not cumulative offset); `sysfs_kf_seq_show()` zeroes `buf` and warns/clamps if `.show()` returns `>= PAGE_SIZE`. `is_{bin_}visible()` must return `0`, `SYSFS_GROUP_INVISIBLE` (at index `0`), or `SYSFS_PREALLOC | 0664` bits, and `create_files()` must mask `mode &= ~SYSFS_GROUP_INVISIBLE` before testing `!mode` or warning. Heap attributes require `sysfs_{bin_}attr_init()`, and `sysfs_bin_attr_simple_read()` (`BIN_ATTR_SIMPLE_*RO()`) requires non-zero `.size` (or `.bin_size`) and `.private`. [F50, F52, F54, F75, F96, F165]
- `{fwnode,device}_property_read_string_array()` return positive count on success when `val != NULL` (unlike integer array and single-string readers returning `0`). `{fwnode_}device_is_big_endian()` returns `true` only for `"big-endian"` or `CONFIG_CPU_BIG_ENDIAN` with `"native-endian"`. `dev_fwnode()` must preserve `const` via `_Generic`. `DEVICE_STRING_ATTR_RO()` must stay read-only (`(_mode) & ~0222`, `NULL` `.store`) with `dev_ext_attribute.var` holding the `char *` address directly. Before `soc_bus_register()`, `soc_device_register()` saves `early_soc_dev_attr` and returns `NULL` (or `ERR_PTR(-EBUSY)`), so early callers must check `IS_ERR()`; `soc_device_match()` tables must end with an all-`NULL` entry (`machine`, `family`, `revision`, `soc_id`). System sleep paths must check `dev_pm_smart_suspend(dev)` rather than `dev_pm_test_driver_flags(dev, DPM_FLAG_SMART_SUSPEND)`. [F55, F108, F123, F125, F137, F139, F141]

## Error Handling

- In `devm_platform_get_irqs_affinity()`, `kfree(desc)` is required on both `irq_update_affinity_desc()` failure and success after `devres_add()`, and `devres_free(ptr)` on errors before `devres_add()`. In `platform_device_add()`, `failed:` unwinds via `while (i--)`, requiring `i` to be the failing resource index on `insert_resource()` error and `pdev->num_resources` on `device_add()` error. In `modalias_show()` and `platform_uevent()`, OF/ACPI modalias helpers fall back only on `-ENODEV`. [F8, F37, F104]
- `syscore_suspend()` iterates via `list_for_each_entry_reverse` and on failure must unwind only already-suspended entries via `list_for_each_entry_continue`. In `transport_add_class_device()`, `sysfs_create_group()` failure must call `attribute_container_class_device_del(classdev)` before `tclass->remove()`, and `attribute_container_add_class_device()` failure must still call `tclass->remove()`. On error, `pinctrl_bind_pins()` must free and `NULL` `dev->pins`, propagating only `-ENOMEM`, `-EPROBE_DEFER`, or `-EINVAL` (mapping others like `-ENOENT`/`-ENODEV` to `0`). [F10, F11, F41]
- In `dev_add_physical_location()`, check `dev->physical_location` for `NULL` after `kzalloc()` and call `ACPI_FREE(pld)` on both failure and success. In `sysfs_{merge_group,create_files}()`, the loop header advances `i` (and `attr`) before testing `!error`, so rollback must pre-decrement via `while (--i >= 0)`. Use `sysfs_create_link_nowarn()` and ratelimited logging when `-EEXIST` is expected at runtime (e.g., `do_register_memory_block_under_node()`). [F42, F99, F169]

## External Contracts

- `debugfs_parse_param()` must ignore `-ENOPARAM` (returning `0`) and handle `Opt_source` in `debugfs_param_specs`. `debugfs_locked_down()` bypasses `security_locked_down(LOCKDOWN_DEBUGFS)` only if `(inode->i_mode & 07777 & ~0444) == 0`, `!(filp->f_mode & FMODE_WRITE)`, and `real_fops` lacks `unlocked_ioctl`, `compat_ioctl`, and `mmap`. `debugfs_write_file_str()` requires `pos == 0 || pos == strlen(old)` (`-EINVAL`), `pos + count + 1 <= PAGE_SIZE` (`-E2BIG`), and `rcu_assign_pointer()` + `synchronize_rcu()` before freeing `old`. Userspace sysfs mounts (`!(fc->sb_flags & SB_KERNMOUNT)`) in `sysfs_init_fs_context()` must check `kobj_ns_current_may_mount(KOBJ_NS_TYPE_NET)`, grab `kfc->ns_tag` (dropped in `sysfs_{fs_context_free,kill_sb}()`), and set `fc->user_ns = netns->user_ns`. `{panel,vertical_position,horizontal_position}_show()` must handle every non-unknown enum variant in `switch`. [F80, F94, F107, F163, F168]

## Known Pitfalls

- Never tag pointers in `DEBUGFS_I(inode)->raw` or `dentry->d_fsdata` with bit 1; use separate proxy fops and `enum dbgfs_get_mode`. Use `debugfs_create_xul()` for hex `unsigned long`, never `debugfs_create_x64((u64 *)...)`. `platform_device_msi_init_and_alloc_irqs()` passes `nvec - 1` to `msi_domain_alloc_irqs_range()`, requiring `nvec >= 1`. Topology and NUMA cpumask/cpulist sysfs files must use `BIN_ATTR_RO()` with `CPUMAP_FILE_MAX_BYTES` / `CPULIST_FILE_MAX_BYTES`, not `DEVICE_ATTR`. [F78, F79, F84, F126]
