# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers) — drivers/ata (part 1)

This component contains the common AHCI library (`libahci.c`, `ahci.h`), PCI AHCI/SATA/PATA drivers (`ahci.c`, `acard-ahci.c`, `ata_piix.c`, `ata_generic.c`), SoC platform AHCI drivers (`ahci_imx.c`, `ahci_tegra.c`, `ahci_xgene.c`, `ahci_brcm.c`, `ahci_dwc.c`, etc.), and the libata ACPI binding layer (`libata-acpi.c`).

## Architecture & Data Flow
- When `pp->fbs_enabled` is true, `pp->active_link` is invalid (valid only when `!pp->fbs_enabled && ap->qc_active`); `ahci_qc_complete`, `ahci_qc_fill_rtf`, and `ahci_qc_ncq_fill_rtf` must not use `pp->active_link` and must offset `pp->rx_fis` by `qc->dev->link->pmp * AHCI_RX_FIS_SZ` (256), while `acard_ahci_qc_fill_rtf` on `acard_ops` ports strides by `ACARD_AHCI_RX_FIS_SZ` (128). `ahci_port_start` and `acard_ahci_port_start` must allocate `AHCI_PORT_PRIV_FBS_DMA_SZ` whenever `pp->fbs_supported` is true so PMP FIS indexing does not overrun `pp->cmd_tbl`. [F62, F93, F126, F127]
- `ahci_enable_fbs()` must set `pp->fbs_enabled = true` and `pp->fbs_last_dev = -1`; when `ahci_qc_issue()` or `ahci_exec_polled_cmd()` writes a PMP index to `PORT_FBS`, it must update `pp->fbs_last_dev` and mask off `PORT_FBS_DEC`. Before softresetting a PMP link (`!ata_is_host_link(link)`) in `ahci_do_softreset()`, disable FBS via `ahci_disable_fbs(ap)` if `pp->fbs_enabled` and re-enable via `ahci_enable_fbs(ap)` on success. [F61, F64]
- In `ahci_error_intr()`, `SCR_ERROR` must be read and written back via `ahci_scr_write(&ap->link, SCR_ERROR, serror)`. When `pp->fbs_enabled && (fbs & PORT_FBS_SDE)`, verify `pmp = fbs >> PORT_FBS_DWE_OFFSET < ap->nr_pmp_links` before indexing `ap->pmp_link[pmp]`; after searching via `PORT_FBS_SDE` or `ata_for_each_link`, set `if (!link) link = &ap->link;`. Record link-specific errors (`PORT_IRQ_TF_ERR` without `active_qc`, `PORT_IRQ_UNK_FIS`, `PORT_IRQ_BAD_PMP`, `PORT_IRQ_IF_ERR` with `fbs_need_dec`) on `active_ehi` (`&link->eh_info`), and port-wide/hotplug errors on `host_ehi` (`&ap->link.eh_info`). [F95, F110, F117, F153]
- In `ahci_handle_port_interrupt()`, mask `PORT_IRQ_BAD_PMP` (when `ATA_PFLAG_RESETTING`) and `PORT_IRQ_PHYRDY` (when `sata_lpm_ignore_phy_events(&ap->link)`) out of `status` before testing `status & PORT_IRQ_ERROR`. Per-port IRQ changes must update `pp->intr_mask` for `ahci_thaw()`, and `ahci_pmp_attach()`/`detach()` must not write `PORT_IRQ_MASK` when `ata_port_is_frozen(ap)`. [F63, F106]
- Before `ahci_init_controller()` sets `HOST_IRQ_EN`, stop each non-dummy port via `ahci_deinit_port()` and clear pending IRQs via `ahci_port_clear_pending_irq()`. `ahci_do_hardreset()` must also call `ahci_port_clear_pending_irq(ap)` after `hpriv->stop_engine(ap)`. Before calling `sata_link_hardreset()` with `ahci_check_ready` (`ahci_do_hardreset`, `xgene_ahci_do_hardreset`, `ahci_qoriq_hardreset`, `ahci_avn_hardreset`), write `tf.status = ATA_BUSY` to `pp->rx_fis + RX_FIS_D2H_REG` via `ata_tf_to_fis`, and write `*class` only when `online` is true. [F52, F136, F137]
- `ahci_save_initial_config()` must record `hpriv->saved_cap`/`saved_cap2` before applying `AHCI_HFLAG_*` overrides so `ahci_restore_initial_config()` writes back raw values. `ahci_init_one()` and `acard_ahci_init_one()` must size `ata_host` ports as `max(ahci_nr_ports(hpriv->cap), fls(hpriv->port_map))`. `ahci_update_initial_lpm_policy()` must disable LPM (`ATA_FLAG_NO_LPM`, `ATA_LPM_MAX_POWER`) if `ATA_PFLAG_EXTERNAL` or if `ATA_HOST_NO_PART`, `ATA_HOST_NO_SSC`, and `ATA_HOST_NO_DEVSLP` are all set. `ahci_set_aggressive_devslp()` must clamp `dito` to `0x3ff` before shifting by `PORT_DEVSLP_DITO_OFFSET`. [F60, F96, F122, F144]
- In `ahci_qc_fill_rtf()`, PIO data-in (`ATA_PROT_PIO && DMA_FROM_DEVICE && !(qc->flags & ATA_QCFLAG_EH)`) and NCQ (`ata_is_ncq(qc->tf.protocol)`) must return before reading `RX_FIS_D2H_REG`. In `ahci_qc_ncq_fill_rtf()`, both `while (done_mask)` loops must clear `done_mask &= ~(1ULL << tag)` unconditionally on every iteration (64-bit `1ULL` for `tag == ATA_TAG_INTERNAL` = 32). [F108, F115, F119]
- SoC state: `xgene_ahci_softreset()` records `ctx->class[ap->port_no]`, and `xgene_ahci_qc_issue()` writes `qc->dev->link->pmp` to `PORT_FBS` when `ATA_DEV_PMP` and updates `ctx->last_cmd[ap->port_no]`. `ahci_mvebu_stop_engine()` must save/restore `PORT_FBS` across clearing `PORT_CMD_START`. `ahci_qoriq_hardreset()` on `AHCI_LS1021A` must save/restore `PORT_CMD` and `PORT_IRQ_STAT`. `ahci_dwc_init_timer()`/`init_dmacr()` must cache `dpriv->timv` and `dpriv->dmacr[port]` for `ahci_dwc_reinit_host()`. In `ahci_imx.c`, `__sata_ahci_read_temperature()` must save/restore `SATA_PHY_CR_CLOCK_MPLL_TST`/`_RTUNE_CTL`/`_DAC_CTL`, floor `m2` (`if (!(m2 / 1000)) m2 = 1000;`), and bound `read_adc_sum()` with `read_attempt > attempt_limit`. [F78, F80, F81, F82, F84, F116, F123]
- In `ata_piix.c`, `piix_init_one()` must save/restore `hpriv->saved_iocfg` and copy `piix_port_info[ent->driver_data]` into a local `port_info[2]` before `piix_init_sata_map()` (which must mask `map_value & map_db->mask` and pair even `IDE` entries with `i + 1`). When `piix_init_sidpr()` sets `piix_sidpr_sata_ops`, it must call `ata_slave_link_init(ap)` if `ATA_FLAG_SLAVE_POSS` and use `&piix_sidpr_sht`. `piix_set_timings()` clears the drive's UDMA bit in `0x48` and sets DTE (`control |= 8`) if MWDMA exceeds `adev->pio_mode`, so `set_dmamode` must follow `set_piomode`. When `piix_pci_device_suspend()` sets `PIIX_HOST_BROKEN_SUSPEND` under `host->lock`, `piix_pci_device_resume()` must clear it and call `pci_reenable_device()`. [F72, F73, F74, F75, F103]
- In `libata-acpi.c`, use `ata_dev_acpi_handle(dev)` (not `ACPI_HANDLE(&dev->tdev)`) to respect `ATA_DFLAG_ACPI_DISABLED`. `ata_acpi_bind_dev()` must pass `ACPI_COMPANION(ap->host->dev)` as `parent` for `ATA_FLAG_ACPI_SATA` and `ACPI_COMPANION(&ap->tdev)` for PATA. Retrieve `ap->__acpi_init_gtm` only via `ata_acpi_init_gtm(ap)` and null-check it. `ata_acpi_push_id()` must call `swap_buf_le16(dev->id, ATA_ID_WORDS)` both before and after `_SDD`, and `ata_acpi_on_devcfg()` must call `ata_dev_reread_id(dev, 0)` when `nr_executed > 0`. Keep generic `PCI_ANY_ID` entries last before `{ }` in `ata_generic[]`/`ahci_pci_tbl[]`, and `{ 0, }` at the end of `ich_laptop[]`. [F47, F48, F76, F99, F118, F151]

## Synchronization
- `ahci_handle_port_intr()` callers must hold `host->lock` with IRQs disabled; `ahci_single_level_irq_intr()` and `ahci_thunderx_irq_handler()` must clear `HOST_IRQ_STAT` with unmasked `irq_stat` under `host->lock` after `ahci_handle_port_intr(host, irq_masked)`, while `xgene_ahci_irq_intr()` writes `irq_stat` to `HOST_IRQ_STAT` under `host->lock` before `xgene_ahci_handle_broken_edge_irq()`. With `AHCI_HFLAG_MULTI_MSI`, `ahci_port_start()` must init `pp->lock` and set `ap->lock = &pp->lock`. [F23, F25, F26, F161]
- `ahci_deinit_port()` calls `hpriv->stop_engine(ap)` before `ahci_stop_fis_rx(ap)`, while `ahci_start_port()` calls `ahci_start_fis_rx(ap)` before `hpriv->start_engine(ap)`. In `ahci_xgene.c`, `xgene_ahci_hardreset()` must save/restore `PORT_CMD`, `PORT_LST_ADDR`/`_HI`, and `PORT_FIS_ADDR`/`_HI` across `xgene_ahci_do_hardreset()`, and `xgene_ahci_restart_engine()` must poll `PORT_CMD_ISSUE` to `0x0` before `hpriv->stop_engine(ap)`, then re-run `ahci_start_fis_rx(ap)` and re-enable `PORT_FBS_EN`. [F31, F34, F79]
- `ahci_transmit_led_message()` and `seattle_transmit_led_message()` must update `emp->led_state` under `ap->lock`, and `ahci_activity_store()` must sync `ATA_LFLAG_SW_ACTIVITY` with `emp->blink_policy`. `ahci_sw_activity_blink()` must hold `ap->lock` across `emp->saved_activity` and `mod_timer()`, dropping it before `transmit_led_message`. In `ahci_start_port()`, retry `-EBUSY` LED transmission with `msleep(1)` (not `ata_msleep`). [F28, F30, F67]
- PCI AHCI suspend paths must clear/flush `HOST_IRQ_EN` in `HOST_CTL` before suspend/D3. `brcm_ahci_read_id()` must hold `host->lock` (`spin_lock_irqsave`) to clear/flush `HOST_IRQ_EN`, drop it across `msleep`/`phy_init`/`phy_calibrate`, and re-acquire to re-enable `HOST_IRQ_EN`. Platform AHCI drivers must call `ahci_platform_suspend_host()` before disabling clocks/PHYs and re-enable resources before `ahci_platform_resume_host()`. `ata_acpi_handle_hotplug()` must hold `ap->lock` while updating `eh_info` and calling `ata_port_freeze`/`ata_acpi_detach_device`, unlocking before `ata_port_wait_eh(ap)`. In `ata_piix.c`, accesses to PCI registers `0x40`–`0x54` must hold `piix_lock`, mask only target bits, and keep `SITRE` (`0x4000`) set. [F36, F37, F39, F41, F71]

## Object Lifetimes
- Balance runtime PM and PCI/sysfs resources: in `ahci_init_one()`/`ahci_remove_one()`, call `pm_runtime_put_noidle()` only after `ahci_host_activate()`, `pm_runtime_get_noresume()` before `ata_pci_remove_one()`, remove `dev_attr_remapped_nvme` on error and remove, call `pcim_pin_device(pdev)` if `pcim_request_all_regions()` returns `-EBUSY` (also in `acard_ahci_init_one()`), and call `pci_free_irq_vectors(pdev)` in `ahci_init_irq()` if `HOST_MRSM` triggers single-MSI fallback. `ahci_port_resume()`/`start()` and `ahci_port_suspend()`/`stop()`, plus all non-EH MMIO sysfs/LED helpers (`ahci_show_port_cmd`, `ahci_read`/`store_em_buffer`, `ahci_show_em_supported`, `ahci_transmit_led_message`), must balance `ahci_rpm_get_port(ap)` and `ahci_rpm_put_port(ap)`. [F2, F3, F4, F5, F140, F158]
- In `ahci_host_activate_multi_irqs()`, `ata_host_start(host)` must precede `devm_request_irq()`, and dummy ports (`!pp`) must call `disable_irq(irq)` before `ata_host_register()`. `ahci_init_sw_activity()` must init `emp` and `timer_setup()` before setting `ATA_LFLAG_SW_ACTIVITY`. `ata_acpi_bind_port()`/`bind_dev()` must set `context->data.ap`/`.dev` before `acpi_initialize_hp_context()`, and callbacks must only read the matching union member. Free `output.pointer` in `ata_acpi_gtm()`, `info` in `xgene_ahci_probe()`, and `pci_iounmap(pdev, mmio)` in `piix_disable_ahci()`. [F16, F18, F22, F24, F27, F38, F132]
- Platform resource ordering: in `ahci_brcm.c`, run `brcm_sata_init()` and `brcm_sata_phys_enable()` after clocks/regulators and before `hpriv->mmio` access or `ahci_platform_enable_phys()`, call `ahci_platform_enable_phys()` + `ahci_platform_resume_host()` in `brcm_ahci_resume()`, unwind with `brcm_sata_phys_disable()`, and use `brcm_sata_readreg`/`writereg` on `top_ctrl`. In `ahci_imx.c`, call `imx_sata_disable()` before `clk_disable_unprepare(sata_clk)`, set `imxpriv->no_device = true` only after `imx_sata_disable()` in `ahci_imx_error_handler()`, and power off/exit `cali_phy1` then `cali_phy0` in `imx8_sata_enable()`. Unwind `ceva_ahci_platform_enable_resources()` and `tegra_ahci_power_on()` in reverse order; in `ahci_dwc.c`, call `dpriv->pdata->clear(hpriv)` before `ahci_platform_disable_resources()` and `of_node_put(child)` on early loop exit in `ahci_dwc_init_dmacr()`. [F8, F9, F11, F12, F13, F14, F15, F83, F101, F150, F159]

## API Contracts
- Call `ahci_enable_ahci()` before reading `HOST_CAP` in `ahci_save_initial_config()` and before/after `HOST_RESET` in `ahci_reset_controller()`. Stop the port engine via `hpriv->stop_engine(ap)` before modifying `PORT_FBS_EN` or `PORT_DEVSLP` and restart afterward. Only read `HOST_CAP2` on AHCI >= 1.2. Bounds-check `sc_reg` (and `HOST_CAP_SNTF` for `SCR_NOTIFICATION`) in `ahci_scr_offset()` and `reg < ARRAY_SIZE(piix_sidx_map)` in `piix_sidpr_scr_read`/`write()`. Only mask `port_map` with `hpriv->mask_port_map` when `mask_port_map != 0`. Zero the 32-byte `AHCI_CMD_TBL_CDB` before copying `qc->cdb` in `ahci_qc_prep()`/`acard_ahci_qc_prep()`, and zero `pp->cmd_slot[tag].status` in `ahci_fill_cmd_slot()`. [F55, F65, F97, F104, F135, F143]
- `AHCI_HFLAG_MULTI_MSI` requires `hpriv->get_irq_vector` and forbids custom `hpriv->irq_handler` (`ahci_multi_irqs_intr_hard` takes `struct ata_port *`, not `struct ata_host *`). Each AHCI driver must define its own `AHCI_SHT(drv_name)`. `.read_id` callbacks return `unsigned int` `AC_ERR_*` (mapping negative errnos to `AC_ERR_OTHER`) and must use `cpu_to_le16()` masks on `__le16 *id`. [F43, F102, F134, F176, F178]
- `dev->gtf_cache` holds `output.pointer` while `ata_dev_get_GTF()` outputs `*gtf = out_obj->buffer.pointer` and returns `length / REGS_PER_GTF` (`0` on `AE_NOT_FOUND`, `-EINVAL` on error, calling `ata_acpi_clear_gtf(dev)` on error/completion/resume/disable). Pass `hwmon_dev` (not `&pdev->dev`) to `devm_thermal_of_zone_register()` in `ahci_imx.c`. Check `pdev` bus/slot/devfn in DMI quirks, use `board_ahci` for new Intel IDs, preserve `pdev->dma_mask < DMA_BIT_MASK(32)` in `ahci_configure_dma_masks()`, and require `PCI_COMMAND_IO` in `ata_generic_init_one()`. [F44, F129, F133, F141, F146, F147, F148, F149]

## Error Handling
- `ahci_stop_engine()` and `ahci_mvebu_stop_engine()` return early only when `(tmp & (PORT_CMD_START | PORT_CMD_LIST_ON)) == 0`; `ahci_stop_engine()` must wake the link via `ahci_set_lpm()` if `AHCI_HFLAG_WAKE_BEFORE_STOP` and return `-ENODEV` if `PORT_CMD == 0xffffffff`. `ata_acpi_run_tf()` returns `0` on `AC_ERR_DEV` or filtered `_GTF` without advancing `pgtf`/`*nr_executed`. Set `ret = PTR_ERR(...)` before `goto` in `imx_ahci_probe()`, null-check `dmi->driver_data` before `strcmp()`, and ratelimit hardware warnings in `ahci_handle_port_intr()`/`ahci_read_em_buffer()` without `WARN_ON`. [F42, F105, F109, F145, F155, F185]

## External Contracts
- `ahci_fill_sg()` writes `cpu_to_le32(sg_len - 1)` and `n_elem << 16`, whereas `acard_ahci_fill_sg()` writes `cpu_to_le32(sg_len)` with bit 31 set on the last SG entry and omits `n_elem`. `ahci_set_em_messages()` multiplies `HOST_EM_LOC` offset/size by 4; `ahci_read_em_buffer()` adds `hpriv->em_buf_sz` when `!(em_ctl & EM_CTL_SMB)`; `ahci_store_em_buffer()` checks `size % 4 == 0 && size <= hpriv->em_buf_sz` and casts `buf` to `const unsigned char *`; LED handlers bounds-check `pmp < EM_MAX_SLOTS` (with `array_index_nospec` in `ahci_led_store()`). Validate `ACPI_TYPE_BUFFER` and exact `sizeof(struct ata_acpi_gtm)` in `ata_acpi_gtm()` or `length % REGS_PER_GTF == 0` in `ata_dev_get_GTF()`, and force `unit = 0` when `!(gtm->flags & 0x10)` in `ata_acpi_gtm_xfermask()`. [F56, F57, F68, F88, F89, F91, F121, F130, F182]

## Known Pitfalls
- Add byte offsets to `void *` `pp->cmd_tbl`/`pp->rx_fis` before casting to typed pointers; copy `u32` `port_map` fields into `unsigned long` before `for_each_set_bit()`; shift `dma_addr_t` upper bits via `(addr >> 16) >> 16`; override `.pmp_reset` alongside `.reset` on PMP-enabled `ahci_ops` ports; keep `int i` signed for `while (--i >= 0)` unwinds; guard `deadline - now` with `time_after(deadline, now)` in `ahci_do_softreset()`; and pre-divide `refclk_rate` by 10/100 before dividing `1500000000` in `ahci_da850_calculate_mpy()`/`ahci_dm816_get_mpy_bits()`. [F100, F120, F124, F125, F128, F131, F180]
