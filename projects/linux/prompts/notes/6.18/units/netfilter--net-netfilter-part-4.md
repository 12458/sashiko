# NETFILTER — net/netfilter (part 4)

Implements Netfilter NAT core (`nf_nat_core.c`), L3/L4 header manipulation (`nf_nat_proto.c`), NAT modes (masquerade, redirect, OVS, BPF), NAT helpers (FTP, IRC, SIP, TFTP, Amanda), SYNPROXY (`nf_synproxy_core.c`), packet queueing (`nf_queue.c`), and socket option dispatch (`nf_sockopt.c`).

## Architecture & Data Flow

- In `nf_nat_packet`, `nf_nat_icmp_reply_translation`, and `nf_nat_icmpv6_reply_translation`, `statusbit` (`IPS_SRC_NAT` or `IPS_DST_NAT`) must be inverted via `statusbit ^= IPS_NAT_MASK` when `dir == IP_CT_DIR_REPLY` before testing `ct->status`. In `nf_nat_icmp[v6]_reply_translation`, translate the inner packet first using `!manip` and `&ct->tuplehash[!dir].tuple`, recompute the ICMP/ICMPv6 checksum (if `skb->ip_summed != CHECKSUM_PARTIAL`), and then translate the outer packet using `manip` and `!dir`. [F630, F646]
- In `nf_nat_inet_fn` and `nf_ct_nat_execute`, `case IP_CT_RELATED:` and `case IP_CT_RELATED_REPLY:` must fall through to `case IP_CT_NEW:` for non-ICMP/ICMPv6 packets so `!nf_nat_initialized(ct, maniptype)` initializes NAT. `nf_nat_inet_fn` must return `NF_ACCEPT` without NAT when `in_vrf_postrouting(state)` is true, and when `nf_nat_oif_changed(state->hook, ctinfo, nat, state->out)` is true (`nat->masq_index` non-zero and `!= state->out->ifindex` in `POST_ROUTING` `IP_CT_DIR_ORIGINAL`) it must call `nf_ct_kill_acct(ct, ctinfo, skb)` and return `NF_DROP`. [F650, F698, F699]
- `nf_nat_l4proto_unique_tuple` treats `range->min_proto` and `max_proto` as inclusive big-endian bounds, swaps `min`/`max` if `max < min` so `range_size = max - min + 1 >= 1`, and wraps ports via `htons(min + off % range_size)`. Cap `attempts` at `NF_NAT_MAX_ATTEMPTS`; on `another_round`, return if `attempts >= range_size || attempts < 16`, else halve `attempts` (`attempts /= 2`) with a new random `off`. [F640, F654]
- `hash_by_src` and `find_best_ips_proto` scale 32-bit hashes into `[0, nf_nat_htable_size)` and `[0, dist)` via `reciprocal_scale()` (`((u64)val * ep_ro) >> 32`); un-widened 32-bit math or `dist = maxip - minip + 1` wraps to `0` on a full `0..0xffffffff` range. [F664]
- `tcp_manip_pkt` and `sctp_manip_pkt` require only `hdrsize = 8` bytes when `skb->len < hdroff + sizeof(*hdr)` and skip L4 checksum updates when `hdrsize < sizeof(*hdr)` (for 8-byte inner ICMP headers). `gre_manip_pkt` must pass `hdroff + sizeof(*pgreh) - 8` to `skb_ensure_writable`. In `__udp_manip_pkt`, if `do_csum` is true (`hdr->check != 0` in `udp_manip_pkt`, always in `udplite_manip_pkt`), a resulting `hdr->check == 0` must become `CSUM_MANGLED_0`. [F636, F691, F692]
- `__nf_nat_mangle_tcp_packet` and `nf_nat_mangle_udp_packet` must reject `skb->len + extra > 65535` in `enlarge_skb`. `mangle_contents` must `memmove` trailing payload (`data + match_offset + match_len` to `skb_tail_pointer(skb)`) before `memcpy` and before `skb_put`/`__skb_trim`, and when `skb->len` changes it must update `ip_hdr(skb)->tot_len` + `ip_send_check` or `ipv6_hdr(skb)->payload_len` (and `nf_nat_mangle_udp_packet` must set `udph->len = htons(skb->len - protoff)` before `nf_nat_csum_recalc`). In `nf_nat_sip.c`, modifying SDP content (`nf_nat_sdp_addr`, `nf_nat_sdp_port`, `nf_nat_sdp_session`) requires calling `mangle_content_len` afterwards. [F621, F623, F637, F669]
- In `nf_xfrm_me_harder`, clear `sk = NULL` before `xfrm_lookup` if `!net_eq(net, sock_net(sk))`; cast `dst` to `struct xfrm_dst *` for `->route` only after verifying `dst->xfrm != NULL`; and after replacing `skb_dst`, call `pskb_expand_head` if `skb_headroom(skb) < skb_dst(skb)->dev->hard_header_len`. [F678, F697]
- `synproxy_parse_options` must compute signed `int length = (th->doff * 4) - sizeof(*th)` and reject `length < 0` before `skb_header_pointer`; verify `length >= 2`, `opsize >= 2`, and `opsize <= length` per non-NOP/EOL option; use `get_unaligned_be16`/`be32`; and clamp `opts->wscale` to `TCP_MAX_WSCALE` (`14`). `synproxy_tstamp_adjust` must call `skb_ensure_writable(skb, optend)` before accessing `skb->data + optoff` and verify `optoff + 1 != optend`, `optoff + op[1] <= optend`, and `op[1] >= 2`. [F631, F633, F703]
- `synproxy_options_size` and `synproxy_build_options` must match on exact 4-byte option word counts (`synproxy_build_options` writes at `(__be32 *)(th + 1)`). Synthetic packets in `nf_synproxy_core.c` must `skb_reserve(nskb, MAX_TCP_HEADER)` and set `CHECKSUM_PARTIAL` (`csum_start`, `csum_offset`, inverted pseudo-header checksum in `nth->check`) in `synproxy_send_tcp[_ipv6]`. When `ipv[46]_synproxy_hook` reopens `TCP_CONNTRACK_CLOSE` on an original-direction SYN, reset both `nf_ct_seqadj_init(ct, ctinfo, 0)` and `synproxy->tsoff = 0`. [F627, F673, F702]
- `__nf_queue` must allocate `sizeof(*entry) + route_key_size` bytes (`sizeof(struct ip_rt_info)` for `AF_INET`, `sizeof(struct ip6_rt_info)` for `AF_INET6`, `0` otherwise) and only call `nf_ip_saveroute`/`nf_ip6_saveroute` for that matching `state->pf`. [F643]

## Synchronization

- `hash_by_src` must keep `combined` aligned to `SIPHASH_ALIGNMENT` and `memset` to 0 before `siphash`. Modifying `ct->nat_bysource` in `nf_nat_bysource[h]` (`nf_nat_setup_info`, `nf_nat_cleanup_conntrack`) requires `spin_lock_bh(&nf_nat_locks[h % CONNTRACK_LOCKS])` where `h` hashes `ct->tuplehash[IP_CT_DIR_ORIGINAL].tuple`, while `find_appropriate_src` reads under RCU. [F580, F642]
- `nf_ct_nat_ext_add` and `nf_nat_setup_info` must only mutate `ct->ext`, `ct->tuplehash[IP_CT_DIR_REPLY].tuple`, and `ct->status` when `!nf_ct_is_confirmed(ct)` holds (since `ct->status` is updated with non-atomic OR). [F582]
- Hold `nf_nat_proto_mutex` across all accesses to `nat_proto_net->nat_hook_ops`, `nat_proto_net->users`, and `priv->entries` in `nf_nat_register_fn`/`nf_nat_unregister_fn`; on last user removal, complete `nf_unregister_net_hooks` before `kfree_rcu(priv, rcu_head)`. [F583]
- In `nf_nat_used_tuple_new` and `nf_nat_used_tuple_harder`, after `nf_conntrack_find_get`, recheck `thash->tuple.dst.dir`, read `ct->status` and `ct->proto.tcp.state` with `READ_ONCE`, and call `nf_ct_put(ct)` on all paths. [F584]
- Hold `spin_lock_bh(&nf_conntrack_expect_lock)` when iterating `&help->expectations` in `nf_nat_sip_expected`, and hold `read_lock_bh(&idev->lock)` when iterating `&idev->addr_list` in `nf_nat_redirect_ipv6`. In `nf_nat_{sip,ftp,irc,tftp}_fini`, clear the RCU hook pointer with `RCU_INIT_POINTER(..., NULL)` and call `synchronize_rcu()` before unload. [F589, F590, F591]

## Object Lifetimes

- Before `qh->outfn(entry, queuenum)`, `__nf_queue` must convert any non-refcounted `skb->sk` to `sock_edemux`, call `skb_dst_force(skb)`, and call `nf_queue_entry_get_refs(entry)`. `nf_queue_entry_get_refs` increments `state->sk` via `refcount_inc_not_zero` before `dev_hold` on devices, so a `false` return holds no refs and callers (`__nf_queue`, `nf_queue_entry_dup`) must `kfree(entry)`, whereas a negative `qh->outfn` return requires `nf_queue_entry_free(entry)`. [F563, F586]
- `nf_sockopt_find` acquires `ops->owner` via `try_module_get` under `nf_sockopt_mutex` (calling `module_put` if out of range) and unlocks before returning; `nf_setsockopt`/`nf_getsockopt` must call `module_put(ops->owner)` after `ops->set`/`ops->get`. [F566]
- `nf_nat_masq_schedule` acquires `maybe_get_net`, `try_module_get`, `kzalloc`, `atomic_inc(&masq_worker_count)`, and `netns_tracker_alloc`, rolling back `module_put`/`put_net` if `kzalloc` fails and transferring cleanup (`put_net_track`, `kfree`, `atomic_dec`, `module_put`) to `iterate_cleanup_work`. `nf_nat_masquerade_inet_register_notifiers` registers `masq_dev_notifier`, `masq_inet_notifier`, and `masq_inet6_notifier` under `masq_mutex` on `masq_refcnt` `0 -> 1`, and on failure must unregister prior notifiers in reverse order and decrement `masq_refcnt`. [F567, F568]
- In `nf_nat_setup_info`, fallible calls like `nfct_seqadj_ext_add(ct)` must succeed before linking `ct->nat_bysource` into `nf_nat_bysource` and setting `IPS_SRC_NAT_DONE`/`IPS_DST_NAT_DONE`. In `nf_nat_cleanup`, `nf_ct_iterate_destroy(nf_nat_proto_clean, &clean)` (clearing `IPS_SRC_NAT_DONE_BIT` via `test_and_clear_bit` and calling `nf_nat_cleanup_conntrack`) and `synchronize_net()` (after clearing `nf_nat_hook`) must run before `kvfree(nf_nat_bysource)`. [F569, F570]
- `nf_nat_inet_register_fn` registers `NFPROTO_IPV6` before `NFPROTO_IPV4`, and on `NFPROTO_IPV4` failure must roll back via `nf_nat_unregister_fn(net, NFPROTO_IPV6, ops, ARRAY_SIZE(nf_nat_ipv6_ops))`. [F579]
- `nf_nat_ipv[46]_local_in` must call `skb_orphan(skb)` when `nf_nat_ipv[46]_fn` returns `NF_ACCEPT`, `skb->sk` is non-NULL and `!inet_sk_transparent(sk)`, and SNAT changed the source IP or `nf_nat_inet_port_was_mangled(skb, sk->sk_dport)`. In `nf_nat_ipv4_pre_routing` and `nf_nat_ipv6_in`, when DNAT changes the destination IP and the verdict is not `NF_DROP`/`NF_STOLEN`, call `skb_dst_drop(skb)`. [F576, F577]
- In `nf_nat_ftp`, `help` (`nf_nat_irc.c`), `nf_nat_sip_expect`, and `nf_nat_sdp_media`, if formatting/mangling or `rtcp_exp` insertion fails after `nf_nat_exp_find_port` or `nf_ct_expect_related`, roll back with `nf_ct_unexpect_related` before returning `NF_DROP`. [F575]
- `synproxy_net_init` allocates `snet->tmpl` via `nf_ct_tmpl_alloc`, freeing it with `nf_ct_tmpl_free(ct)` (and `free_percpu(snet->stats)`) on init error and `nf_ct_put(snet->tmpl)` in `synproxy_net_exit`. `synproxy_send_tcp[_ipv6]` only attaches `nfct` and calls `nf_conntrack_get(nfct)` after routing succeeds, calling `kfree_skb(nskb)` on routing error. In `ipv[46]_synproxy_hook`, `NF_STOLEN` paths must call `consume_skb(skb)`, whereas `NF_DROP` paths must not free `skb`. [F573, F574, F578]

## API Contracts

- Callers of `nf_unregister_queue_handler` must flush all queued packets first, and every packet accepted by `qh->outfn` must be reinjected or freed via `nf_queue_entry_free`. `nf_queue` passes `verdict >> NF_VERDICT_QBITS` to `__nf_queue`, returns `1` without freeing `skb` only on `-ESRCH` with `NF_VERDICT_FLAG_QUEUE_BYPASS`, and otherwise frees `skb` on error and returns `0`. [F565, F610]
- `nf_sockopt_find` returns `ERR_PTR(-ENOPROTOOPT)` on failure (never `NULL`) and treats `[optmin, optmax)` as half-open, so callers must test `IS_ERR(ops)`. Callers of `nf_ct_nat_ext_add` and `nfct_nat` must NULL-check the returned `struct nf_conn_nat *`. [F596, F612]
- `nf_nat_alloc_null_binding`, `nf_nat_packet`, and `nf_nat_icmp[v6]_reply_translation` take an `NF_INET_*` `hooknum` (converted via `HOOK2MANIP`), whereas `nf_nat_setup_info` and `nf_nat_manip_pkt` take `enum nf_nat_manip_type`. `nf_ct_nat` must read `*action`, immediately reset `*action = 0` before any early return, and only set `BIT(maniptype)` when `nf_ct_nat_execute` returns `NF_ACCEPT`. [F599, F600]
- `__nf_nat_mangle_tcp_packet` and `nf_nat_mangle_udp_packet` take `match_offset` relative to the L4 payload start (`protoff + tcph->doff * 4` or `protoff + sizeof(*udph)`), so `mangle_packet` (`nf_nat_sip.c`) must add `dataoff - baseoff`. [F605]
- `nf_nat_register_fn` and `nf_nat_unregister_fn` must check `pf < ARRAY_SIZE(nat_net->nat_proto_net)`, map sparse `ops->hooknum` to dense index `0 .. ops_count - 1` by scanning `nat_ops[i].hooknum`, and never modify `nf_nat_ipv[46]_ops` in place, instead duplicating via `kmemdup_array(orig_nat_ops, ops_count, sizeof(*orig_nat_ops), GFP_KERNEL)`. [F626, F641, F667]

## Error Handling

- Callers of `nf_nat_setup_info` and `__nf_nat_alloc_null_binding` returning negative errnos (e.g. `nfnetlink_parse_nat_setup`) must map `NF_DROP` (`0`) to `-ENOMEM` and `NF_ACCEPT` (`1`) to `0`. `nf_nat_icmp[v6]_reply_translation` returns `1` on success and `0` on failure, which callers must map to `NF_ACCEPT`/`NF_DROP`. [F593, F601]
- Store `ipv6_skip_exthdr` returns in a signed `int` and check `< 0` before use. Check `xfrm_lookup` returns with `IS_ERR(dst)` before `skb_dst_set` (and in `nf_xfrm_me_harder`, call `skb_dst_drop(skb)` only after `xfrm_lookup` succeeds). Wrap negative routing errnos with `NF_DROP_ERR(err)` in `nf_nat_ipv[46]_{out,local_fn}`. [F602, F603, F604]
- In `nf_nat_sip.c`, `mangle_sdp_packet` returns `0` on success, `-ENOENT`, or `-EINVAL`, whereas `mangle_packet`, `mangle_content_len`, and `nf_nat_sdp_{addr,port,session}` return `1` on success and `0` on failure. In `ipv[46]_synproxy_hook`, check `if (!synproxy) return NF_ACCEPT;` before accessing `synproxy` or calling `nf_ct_seqadj_init`. [F607, F614]

## External Contracts

- `synproxy_cpu_seq_{start,next,show}` use `*pos == 0` for `SEQ_START_TOKEN` and `*pos = cpu + 1` for CPUs `0 .. nr_cpu_ids - 1`, formatting six tab-separated `%08x` columns with column 1 fixed at `0`. `nf_nat_ftp` and `nf_nat_irc` must retain their no-op `ports` `module_param_call(..., warn_set, ...)` returning `0`. [F644, F645]

## Known Pitfalls

- In `nf_nat_ipv[46]_manip_pkt`, call `l4proto_manip_pkt` before overwriting L3 addresses (`saddr`/`daddr`) so `nf_csum_update` reads pre-NAT addresses. Reload `iph`, `ipv6h`, and `inside` from `skb->data` after `l4proto_manip_pkt` or `nf_nat_ipv[46]_manip_pkt`, and compute `tcph`/`udph` in `__nf_nat_mangle_tcp_packet`/`nf_nat_mangle_udp_packet` only after `skb_ensure_writable` and `enlarge_skb`, which may reallocate `skb->head`. [F618, F619, F620]
- In `ipv[46]_synproxy_hook` (`TCP_CONNTRACK_SYN_RECV`), strip `NF_SYNPROXY_OPT_MSS | NF_SYNPROXY_OPT_WSCALE | NF_SYNPROXY_OPT_SACK_PERM` from `opts.options`, and swap `opts.tsval`/`opts.tsecr` before `synproxy_send_server_ack[_ipv6]` and back before `synproxy_send_client_ack[_ipv6]`. [F628]
- In `nf_nat_icmp[v6]_reply_translation`, `ICMP_REDIRECT`/`NDISC_REDIRECT` require `(ct->status & IPS_NAT_DONE_MASK) == IPS_NAT_DONE_MASK` and `!(ct->status & IPS_NAT_MASK)`, else return `0`. [F647]
- `ipv6_addr_cmp` returns non-zero when addresses differ, whereas `nf_inet_addr_cmp` returns non-zero when equal (negate as `!nf_inet_addr_cmp(...)` for change detection) and compares all 128 bits (`all[0..3]`), so IPv4 `union nf_inet_addr` instances must be zero-initialized before setting `.ip`. In `find_best_ips_proto`, pass word count `sizeof(tuple->src.u3) / sizeof(u32)` to `jhash2` and compute `max` in `sizeof(u32)` words. [F648, F668, F674]
