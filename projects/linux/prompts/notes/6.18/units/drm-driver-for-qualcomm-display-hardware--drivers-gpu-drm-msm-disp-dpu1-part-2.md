# DRM DRIVER for Qualcomm display hardware — drivers/gpu/drm/msm/disp/dpu1 (part 2)

This unit implements the physical encoder backends (`dpu_encoder_phys_vid`, `dpu_encoder_phys_cmd`, `dpu_encoder_phys_wb`), pixel format descriptors (`dpu_formats`), the hardware catalog (`dpu_hw_catalog`), the core interrupt controller (`dpu_hw_interrupts`), and low-level DPU hardware block drivers (`dpu_hw_*` for CTL, SSPP, LM, INTF, PP, DSC, DSPP, WB, CWB, CDM, VBIF, MERGE3D, and TOP).

## Architecture & Data Flow
- `struct dpu_hw_blk base` must stay at offset 0 of `struct dpu_hw_mixer` because `dpu_rm_init` checks only `IS_ERR(hw)` after `dpu_hw_lm_init` and assigns `&hw->base`, relying on it evaluating to `NULL` when `hw` is `NULL`. [F147]
- `dpu_encoder_phys_vid_init` allocates only `sizeof(struct dpu_encoder_phys)`, whereas cmd/wb constructors allocate subclass structs; apply `to_dpu_encoder_phys_cmd` and `to_dpu_encoder_phys_wb` only when `intf_mode` is `INTF_MODE_CMD` or `INTF_MODE_WB_LINE`. [F239]
- In `dpu_hw_ctl.c`, every `dpu_hw_ctl_update_pending_flush_*_v1` helper (and `dpu_hw_ctl_update_pending_flush_dspp_sub_blocks`) must set both the sub-block bit in `ctx->pending_*_flush_mask` and its `BIT(*_IDX)` summary bit in `ctx->pending_flush_mask` for `dpu_hw_ctl_trigger_flush_v1`. [F183]
- `dpu_hw_ctl_intf_cfg_v1` must update `CTL_{INTF,WB,CWB,DSC,MERGE_3D}_ACTIVE` via read-modify-write; `dpu_hw_ctl_reset_intf_cfg_v1` must invoke all implemented staging callbacks (`clear_all_blendstages`, `set_active_{lms,fetch_pipes,pipes}`) with `NULL` and mask off only the `CTL_*_ACTIVE` bits specified in `cfg` (never writing `0` unconditionally to `CTL_*_ACTIVE` or `CTL_INTF_MASTER`). [F184, F185]
- `CTL_LAYER(lm)` maps `LM_5` to `0x024` (not `0x014`, which is `CTL_TOP`). In `dpu_hw_ctl_setup_blendstage`, `CTL_LAYER` (`cfg->idx == 0`) takes 3-bit stage values (`(i + 1) & 0x7`) with bit 3 when `i >= 7` in `CTL_LAYER_EXT(lm)` (`mixercfg[1] |= (i >= 7) << cfg->ext_shift`), whereas `cfg->idx > 0` takes 4-bit `((i + 1) & 0xf) << cfg->shift` and `mixercfg[4]` (`CTL_LAYER_EXT4(lm)`) is only written on `core_major_ver >= 9`. [F210, F225]
- `dpu_hw_lm_setup_out` (`BIT(31)`) and `dpu_hw_lm_setup_color3` (`BIT(31) | BIT(30)` on DPU < 12) share `LM_OP_MODE` and must read-modify-write. In `struct dpu_lm_sub_blks`, `maxblendstages` excludes `DPU_STAGE_BASE` (`0`) and `blendstage_base[]` is 0-indexed from `DPU_STAGE_0` (`1`), so `_stage_offset` checks `DPU_STAGE_0 <= stage <= sblk->maxblendstages` and indexes `blendstage_base[stage - DPU_STAGE_0]`, while `dpu_hw_stage_cfg` arrays use `enum dpu_stage` directly. [F195, F202]
- When `pipe->multirect_index != DPU_SSPP_RECT_SOLO`, `dpu_hw_sspp_setup_multirect` and `dpu_hw_sspp_setup_sourceaddress` must read-modify-write `SSPP_MULTIRECT_OPMODE`, `SSPP_SRC_YSTRIDE0`, and `SSPP_SRC_YSTRIDE1` to preserve the sibling rectangle's bits. [F192]
- `irq_idx` in `dpu_hw_interrupts` is 1-based (`1..DPU_NUM_IRQS`, `0` invalid): `DPU_IRQ_IDX` adds 1, `DPU_IRQ_REG`/`DPU_IRQ_BIT` subtract 1, and `dpu_core_irq_get_entry` indexes `irq_tbl[irq_idx - 1]`. In `dpu_core_irq`, the `ffs(irq_status)` loop must use `bit - 1` for both `DPU_IRQ_IDX` and `irq_status &= ~BIT(bit - 1)` on every path. `MDP_INTF0_INTR`..`MDP_INTF8_INTR` in `enum dpu_hw_intr_reg` must stay contiguous and synced with `dpu_intr_set_legacy`/`7xxx`. [F187, F196, F211]
- In `dpu_core_irq_preinstall()` and `dpu_core_irq_uninstall()`, bracket `dpu_clear_irqs()` and `dpu_disable_all_irqs()` with `pm_runtime_get_sync` and `pm_runtime_put_sync` on `&dpu_kms->pdev->dev`. Because `DPU_REG_WRITE`/`READ` use relaxed MMIO, IRQ register writes in `dpu_hw_interrupts.c`, watchdog enables in `dpu_hw_setup_wd_timer()`, and MISR clears before enable in `dpu_hw_setup_misr()` require an explicit `wmb()`. [F243, F245]
- In `dpu_encoder_phys_vid_enable`, set `enable_state = DPU_ENC_ENABLING` and defer `enable_timing(phys_enc->hw_intf, 1)` and `DPU_ENC_ENABLED` until `dpu_encoder_phys_vid_handle_post_kickoff`. Call `update_pending_flush_intf` unconditionally in `dpu_encoder_phys_cmd_enable_helper`, whereas `dpu_encoder_phys_vid_enable` skips slave INTF flush only when `dpu_encoder_phys_vid_needs_single_flush(phys_enc)` is true. [F190, F253]
- On cmd or wb kickoff timeout, `_dpu_encoder_phys_cmd_handle_ppdone_timeout` and `_dpu_encoder_phys_wb_handle_wbdone_timeout` must decrement `pending_kickoff_cnt`, set `enable_state = DPU_ENC_ERR_NEEDS_HW_RESET`, and increment the timeout counter (reset to `0` on success). [F189]
- In `dpu_encoder_phys_vid_setup_timing_engine` and `drm_mode_to_intf_timing_params`, apply split-display, `DRM_FORMAT_YUV420`, DP widebus, and DSC adjustments to a local mode copy without mutating `phys_enc->cached_mode`. Query `timing->wide_bus_en = dpu_encoder_is_widebus_enabled(phys_enc->parent)` before `INTF_DP` adjustments and only shift porches or halve horizontal timings when `wide_bus_en` is true; for `INTF_DSI`, force `hsync_polarity` and `vsync_polarity` to `0`. [F191, F250, F251]
- In `dpu_encoder_phys_vid_setup_timing_engine`, `dpu_encoder_phys_vid_enable`, `dpu_encoder_phys_wb_setup_ctl`, and `_dpu_encoder_phys_wb_update_flush`, set `intf_cfg.merge_3d` and call `update_pending_flush_merge_3d()` only when both `dpu_encoder_helper_get_3d_blend_mode(phys_enc)` is non-zero and `phys_enc->hw_pp->merge_3d` is non-NULL. [F249]
- Tearcheck ops live on `dpu_hw_pingpong` for `core_major_ver < 5` and `dpu_hw_intf` (`INTF_DSI` only) for `>= 5`; `dpu_encoder_phys_cmd` must check `phys_enc->has_intf_te` before selecting TE ops or `INTR_IDX_RDPTR`. `dpu_hw_{intf,pp}_disable_autorefresh()` must disconnect TE, clear autorefresh, poll `wr_ptr_line_count` (`KICKOFF_TIMEOUT_MS`) until `!(0 < count < vdisplay)`, and reconnect TE. In `_setup_mdp_ops()`, `setup_vsync_source` uses `dpu_hw_setup_vsync_sel` (`< 5`), `dpu_hw_setup_wd_timer` (`5..7`), and is NULL on `>= 8`. [F254, F255, F256]
- `_dpu_format_populate_plane_sizes_{ubwc,linear}` must `memset(layout, 0, sizeof(*layout))` upfront. Linear non-interleaved formats must get `h_subsample`/`v_subsample` (`1` or `2`) from `_dpu_get_v_h_subsample_rate` and reject `fb->width % h_subsample || fb->height % v_subsample` before dividing. UBWC puts bitstream planes in `0`/`1` and metadata in `2`/`3`. `dpu_format_populate_addrs` stores 32-bit device IOVAs (never CPU pointers) in `plane_addr[]`. [F204, F232, F235, F267]
- In `struct dpu_qos_lut_tbl`, non-zero `fl` entries must be sorted ascending and any catch-all `fl == 0` entry must be last (`entries[nentry - 1]`). In `dpu_hw_set_qos_remap`, `VBIF_XINL_QOS_LVL_REMAP_000` is at `VBIF_XINL_QOS_RP_REMAP_000 + qos_rp_remap_size`, so catalog `qos_rp_remap_size` must equal `8 * npriority_lvl`. In `_dpu_hw_setup_scaler3_lut`, reset `lut_offset = 0` per `filter < QSEED3_FILTERS` (not per `QSEED3_LUT_REGIONS`). VIG SSPPs without CSC (`_VIG_SBLK_NOSCALE`) must use `plane_formats` (RGB only). [F203, F207, F213, F258]

## Synchronization
- Lock order is `phys_enc->vblank_ctl_lock` -> `dpu_kms->hw_intr->irq_lock` -> `phys_enc->enc_spinlock`. Because `dpu_core_irq` holds `irq_lock` during callbacks, code under `enc_spinlock` must never call `dpu_core_irq_*` functions that take `irq_lock`, and callbacks must never take `vblank_ctl_lock`. In process context, use `spin_lock_irqsave` for `irq_lock` and `enc_spinlock`, and hold `irq_lock` for `dpu_hw_intr_{enable,disable}_irq_locked` and `cache_irq_mask`/`irq_tbl` updates. [F158, F160, F265]
- `dpu_encoder_phys_vid_vblank_irq` must hold `phys_enc->enc_spinlock` while checking `!(hw_ctl->ops.get_flush_register(hw_ctl) & hw_ctl->ops.get_pending_flush(hw_ctl))` and decrementing `phys_enc->pending_kickoff_cnt`. [F162]
- In `dpu_encoder_phys_vid_disable`, after clearing `enable_timing(phys_enc->hw_intf, 0)` under `enc_spinlock`, a master encoder must call `dpu_encoder_phys_inc_pending` and `dpu_encoder_phys_vid_wait_for_tx_complete` before `dpu_encoder_helper_phys_cleanup`. `dpu_hw_ctl_reset_control` and `dpu_hw_ctl_wait_reset_status` sleep via `usleep_range` in `dpu_hw_ctl_poll_reset_status` and must not be called in atomic context or under `enc_spinlock`. [F163, F266]

## Object Lifetimes
- All `dpu_hw_*_init` and `dpu_encoder_phys_*_init` constructors allocate with `drmm_kzalloc`; never `kfree()` returned pointers. Each `irq_idx` in `dpu_hw_intr->irq_tbl` holds one callback: `dpu_core_irq_register_callback` rejects occupied slots with `-EBUSY`, and `dpu_core_irq_unregister_callback` disables the IRQ and clears `cb`/`arg` to `NULL` under `irq_lock`. [F145, F148]
- Toggle `INTR_IDX_RDPTR` and `INTR_IDX_VSYNC` via `dpu_encoder_phys_{cmd,vid}_control_vblank_irq` under `vblank_ctl_lock` (skipping slaves and registering/unregistering on `0 <-> 1` of `vblank_refcount`). Call `dpu_encoder_phys_wb_irq_{enable,disable}` in pairs (`INTR_IDX_WB_DONE` follows `1`/`0` of `wbirq_refcount`). Pair `msm_framebuffer_{prepare,cleanup}(job->fb, false)` in `dpu_encoder_phys_wb_{prepare,cleanup}_wb_job`, and clear `wb_job`/`wb_conn` to `NULL` on cleanup. [F149, F150, F271]

## API Contracts
- `dpu_hw_lm_init()` and `dpu_hw_intf_init()` return `NULL` for `PINGPONG_NONE` / `INTF_NONE` and `ERR_PTR(-ENOMEM)` on alloc failure (other `dpu_hw_*_init()` return only `ERR_PTR`); callers must check both `IS_ERR` and `NULL`. NULL-check version-gated ops before calling: `ctl->ops.{clear_all_blendstages,setup_blendstage}` (`< 12`), `ctl->ops.set_active_{pipes,lms}` and `lm->ops.{setup_blendstage,clear_all_blendstages}` (`>= 12`), and `ctl->ops.{reset_intf_cfg,update_pending_flush_{periph,merge_3d,cwb,dsc}}` (`>= 5`). [F165, F171, F172]
- `dpu_hw_pp_setup_dither()`, `dpu_setup_dspp_pcc()`, `dpu_hw_{ctl,lm}_setup_blendstage()`, and `dpu_hw_ctl_set_active_{lms,pipes,fetch_pipes}()` treat a `NULL` config pointer as the command to disable/unstage the feature rather than an invalid no-op. [F174]
- Zero-initialize `struct dpu_hw_intf_cfg` before `setup_intf_cfg`/`reset_intf_cfg`. In `dpu_hw_intf_cfg`, `intf`, `intf_master`, `wb`, and `merge_3d` take 1-based enum IDs while `cwb` and `dsc` take bitmasks (`BIT(idx - *_0)`); by contrast, all `dpu_hw_ctl_update_pending_flush_*_v1` callbacks take 1-based enum IDs, `dpu_hw_ctl_set_active_{fetch_pipes,pipes,lms}` take bitmaps indexed by 1-based `enum dpu_sspp`/`dpu_lm`, and `dpu_hw_{intf,wb,cdm,dsc}_bind_pingpong_blk*` take 1-based `enum dpu_pingpong` (`PINGPONG_NONE == 0` unbinds). [F177, F179, F180, F200, F201]
- `dpu_hw_clk_force_ctrl()` returns `true` only if the clock-force bit was previously `0`; callers must save that boolean in `forced_on` and only call `setup_clk_force_ctrl(..., false)` when `forced_on` is `true`. `dpu_hw_ctl_poll_reset_status()` returns the raw `CTL_SW_RESET` bit (`0` done, `1` timeout), whereas `dpu_hw_ctl_{reset_control,wait_reset_status}()` return `0` or `-EINVAL`. [F168, F169]
- `dpu_format_populate_plane_sizes()` must reject `fb->width > DPU_MAX_IMG_WIDTH` or `fb->height > DPU_MAX_IMG_HEIGHT` (`0x3fff`), and must succeed before calling `dpu_format_populate_addrs()` on that `dpu_hw_fmt_layout`. For `DPU_SSPP_CSC_10BIT` (`dpu_hw_sspp_setup_csc`, `dpu_hw_cdm_enable`), pass base `+ CSC_10BIT_OFFSET` (`0x4`) and `csc10 = true` to `dpu_hw_csc_setup()`. In `dpu_hw_pp_setup_dither()`, `c0_bitdepth`..`c3_bitdepth` index `dither_depth_map[9]` directly (`0..8`). [F175, F181, F209, F226]
- In `dpu_hw_dsc_config_1_2()`, `dsc->slice_count` must be `>= 1` (`>= 2` with `DSC_MODE_MULTIPLEX`) to avoid division by zero in `_dsc_calc_output_buf_max_addr`, and `dsc->bits_per_pixel` must be doubled for `DSC_MAIN_CONF` when `native_422` or `native_420` is true. IRQ callbacks must have signature `void (*)(void *arg)` without function-pointer casts. Once `drm_writeback_queue_job()` runs in `dpu_encoder_phys_wb_prepare_for_kickoff()`, both `dpu_encoder_phys_wb_done_irq()` and `_dpu_encoder_phys_wb_handle_wbdone_timeout()` must call `drm_writeback_signal_completion(wb_enc->wb_conn, 0)` if `wb_conn` is non-NULL. [F231, F241, F270, F274]

## Error Handling
- Store the return value of `dpu_encoder_helper_wait_for_irq()` in a signed `int` to check negative error codes (`-ETIMEDOUT`, `-EWOULDBLOCK`, `-EINVAL`). `dpu_core_irq_callback_handler()` must return early if `!irq_entry->cb` before incrementing `count` or calling `cb`. Check optional `phys_enc->hw_cdm` and `phys_enc->hw_pp->merge_3d` for non-NULL before dereferencing. [F166, F167, F173]

## External Contracts
- DRM format arrays in `dpu_hw_catalog.c` (`plane_formats`, `plane_formats_yuv`, `wb2_formats_rgb_yuv`) must not contain duplicate `DRM_FORMAT_*` entries. [F268]

## Known Pitfalls
- Mask signed/multi-bit fields to their bitfield widths before shifting/ORing into registers: `dpu_hw_scaler3_de_cfg` / `dpu_hw_scaler3_cfg` (`_dpu_hw_setup_scaler3_de`, `dpu_hw_setup_scaler3`), `dpu_hw_pixel_ext` (`dpu_hw_sspp_setup_pe_config`: `& 0xff`/`0xffff`), `data->csc_mv` (`dpu_hw_csc_setup`: `(val >> 7) & 0x1FFF`), and `drm_dsc_config` (`dpu_hw_dsc_config*`: `bits_per_component == 10` or `& 0xf`). In `dpu_hw_sspp_setup_pe_config()`, `color == 2` is skipped in the loop, leaving `lr_pe[2]`, `tb_pe[2]`, and `tot_req_pixels[2]` uninitialized; never read index `[2]`. [F176, F222, F223, F224, F257]
- In `dpu_hw_setup_scaler3()`, `!scaler3_cfg->enable` must `goto end;` (not `return;`) so `QSEED3_OP_MODE` is written. In `_dpu_hw_setup_scaler3{,lite}_lut`, `dir_len`/`cir_len`/`sep_len` are byte sizes while `u32 *` `cir_lut`/`sep_lut` offsets use element counts (`QSEED3{,LITE}_LUT_SIZE`), and `u32 lut_flag` must be copied to an `unsigned long` before `test_bit()`. Keep QoS `creq_lut` as `u64` in `_dpu_hw_{get,setup}_qos_lut` for `QOS_CREQ_LUT_1` (`>> 32`). [F215, F221, F236, F237]
- `dsc->bits_per_pixel` is 6.4 fixed-point: use `drm_dsc_get_bpp_int(dsc)` when scaling `timing->width` in `drm_mode_to_intf_timing_params`, but write raw 6.4 fixed-point to `dpu_hw_dsc_config*`. In `dpu_hw_intf_setup_timing_engine`, halve `data_width` (`p->width >> 1`) only when `p->wide_bus_en && !dp_intf` (`INTF_DP` is already halved in `drm_mode_to_intf_timing_params`). [F227, F228]
- In `dpu_hw_{cdm,wb}_bind_pingpong_blk`, test `if (pp >= PINGPONG_CWB_0)` before `else if (pp)`. In `dpu_hw_ctl.c`, check 1-based block enums for non-zero before `BIT(id - *_0)` and check `fetch_tbl`/`lm_tbl` against `CTL_INVALID_BIT` (`0xffff`) before `BIT(tbl[i])`. In `programmable_fetch_get_num_lines`, guard `start_of_frame_lines >= worst_case_needed_lines` before subtracting and clamp to `v_front_porch`. In `dpu_hw_pp_get_line_count`, return `0xFFFF` if `height < init` and add `0xFFFF - init` when `line < init`. [F212, F230, F233, F234]
