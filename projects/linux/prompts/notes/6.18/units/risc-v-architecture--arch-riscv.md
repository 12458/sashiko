# RISC-V ARCHITECTURE — arch/riscv

Provides core RISC-V headers (MMU, CSRs, SBI, atomics, uaccess, vector state, instructions, UAPI), vendor errata patching (Andes, MIPS, SiFive, T-Head), and RV64 vector crypto glue (AES, GHASH, SM3, SM4).

## Architecture & Data Flow
- Modify/query vector status in `pt_regs->status` only via `__riscv_v_vstate_or` and `__riscv_v_vstate_check` (`SR_VS_THEAD` when `has_xtheadvector()`, else `SR_VS`). In `__vstate_csr_save`/`__vstate_csr_restore`, when `has_xtheadvector()` is true, set `SR_FS_DIRTY` in `CSR_STATUS` before accessing `CSR_VXSAT`/`CSR_VXRM` and restore `CSR_STATUS` if `(status & SR_FS) != SR_FS_DIRTY`. `riscv_v_vsize` is `32 * vlenb` (all 32 registers), so single-register `vlenb` is `riscv_v_vsize / 32` and `riscv_vector_vlen()` is `riscv_v_vsize / 32 * 8`. [F36, F37, F102]
- `riscv_v_vstate_discard` must call `__riscv_v_vstate_dirty(regs)` after `__riscv_v_vstate_discard()`, while `riscv_v_vstate_save`/`riscv_v_vstate_restore` must call `__riscv_v_vstate_clean(regs)`. `riscv_v_vstate_set_restore` must set both `TIF_RISCV_V_DEFER_RESTORE` and `riscv_v_vstate_on(regs)` when `riscv_v_vstate_query(regs)` holds. In `__switch_to_vector`, if `riscv_preempt_v_started(prev) && riscv_v_is_on()`, call `riscv_v_disable()` and set `RISCV_PREEMPT_V_IN_SCHEDULE`; if `next` has `RISCV_PREEMPT_V_IN_SCHEDULE`, clear it and call `riscv_v_enable()` instead of `riscv_preempt_v_set_restore(next)`. [F38, F39, F40]
- `__riscv_v_vstate_save`, `__riscv_v_vstate_restore`, and `__riscv_v_vstate_discard` must bracket vector ops with `riscv_v_enable()`/`riscv_v_disable()`; in save/restore, the four `M8` stores/loads per pointer advance must address `v0`, `v8`, `v16`, `v24` in sequence (`THEAD_VSB_V_V0T0`..`V24T0`, `THEAD_VLB_V_V0T0`..`V24T0`, `vse8.v`, `vle8.v`). [F5, F117]
- `envcfg_update_bits` must immediately write `CSR_ENVCFG` when `task == current` (besides `__switch_to_envcfg`). Under `CONFIG_RISCV_ISA_SUPM`, `init_new_context` must clear `MM_CONTEXT_LOCK_PMLEN`, `activate_mm` must reset `next->context.pmlen = 0`, `__untagged_addr_remote()` must sign-extend via `(long)(addr << pmlen) >> pmlen` on `CONFIG_MMU` (zero-extend otherwise), and `access_ok()` must call `untagged_addr()` before `__access_ok()`. [F41, F48, F56]
- In `pgd_alloc`, `sync_kernel_mappings(pgd)` must copy from `init_mm.pgd + USER_PTRS_PER_PGD` (unscaled pointer add) with byte count `(PTRS_PER_PGD - USER_PTRS_PER_PGD) * sizeof(pgd_t)`. On RV64, `flush_cache_vmap` on `is_vmalloc_or_module_addr` must set all `new_vmalloc` per-CPU bitmask entries to `-1ULL`. [F45, F46, F103]
- Test `pgtable_l5_enabled` before `pgtable_l4_enabled` in `PGDIR_SHIFT`, `P4D_SHIFT`, and `VA_BITS` (`pgtable_l4_enabled` stays true under Sv57). Sparse `vmemmap` must be biased by `vmemmap_start_pfn`, not `ARCH_PFN_OFFSET`. Under `CONFIG_TRANSPARENT_HUGEPAGE`, `pmd_present(pmd)` must include `_PAGE_LEAF` alongside `_PAGE_PRESENT | _PAGE_PROT_NONE`. Under `CONFIG_ERRATA_THEAD_MAE`, `pfn_pgd`, `pfn_pmd`, `pfn_pte`, and `pte_modify` must apply `ALT_THEAD_PMA` (`_PAGE_PMA_THEAD` when `_PAGE_MTMASK_THEAD` is 0). [F49, F59, F74, F139]
- `struct thread_info` must stay at offset 0 of `struct task_struct` and match `asm-offsets.c` (`riscv_current_is_tp`); `asm_per_cpu` must read `TASK_TI_CPU_NUM(tp)` (and `TASK_TI_PREEMPT_COUNT(tp)`) with 32-bit `lw`, not `REG_L`. Under `CONFIG_SHADOW_CALL_STACK`, `gp` holds `scs_sp`, so `load_global_pointer` must be a no-op and entry/exit assembly must preserve `gp` via `scs_*`. [F52, F58, F128]
- In `riscv_isainfo`, indices `0..25` are single-letter extensions, multi-letter IDs are in `[RISCV_ISA_EXT_BASE, RISCV_ISA_EXT_MAX)`, and bundles use `RISCV_ISA_EXT_INVALID`. Vendor extension IDs (`riscv_isavendorinfo`) must be `< RISCV_ISA_VENDOR_EXT_MAX` (32) and offset by `RISCV_VENDOR_EXT_ALTERNATIVES_BASE` (`0x8000`) in alternatives; vendor errata IDs must be `< ERRATA_<VENDOR>_NUMBER` (`< 32` for `u32` bitmasks), and all `ERRATA_SIFIVE_* < ERRATA_SIFIVE_NUMBER` need non-NULL `check_func` in `sifive/errata.c`'s `errata_list`. [F54, F60, F61]
- Non-coherent DMA errata probes (`errata_probe_cmo` in `thead/errata.c`, `errata_probe_iocp` in `andes/errata.c`) must set non-zero `riscv_cbom_block_size` with `riscv_noncoherent_supported()`. `errata_probe_iocp()` requires matching `ANDES_AX45MP_MARCHID`/`MIMPID` and `ax45mp_iocp_sw_workaround() != 0`; `errata_probe_mae()` requires `arch_id == 0 && impid == 0` before reading `CSR_TH_SXSTATUS` (`SXSTATUS_MAEE`). [F53, F105, F106]
- `ALTERNATIVE_CFG`/`ALT_NEW_CONTENT` blocks must wrap both old and new code in `.option push; .option norvc; .option norelax; .option pop` with equal byte length. `__ALT_PTR(a, f)` must cast `&(a)->f` to `(void *)` before adding `(a)->f`, and `runtime_const_fixup()` must use `*start + (void *)start`. `runtime_const_ptr()`/`runtime_const_shift_right_32()` (`RISCV_RUNTIME_CONST_64_*`) must place `.option norvc` after any `.option arch`; in `__runtime_fixup_32()`, when `lui_insn == RISCV_INSN_NOP4`, the `addi` branch must still run even if `lower_immediate & 0xfff` is 0 to emit `li rd, 0`. [F69, F73, F95, F96, F116, F127]
- `riscv_insn_is_c_jr()` and `riscv_insn_is_c_jalr()` must check `(code & RVC_INSN_J_RS1_MASK) != 0` alongside `RVC_MATCH_C_JR/JALR`. `csr_seed_long()` must poll `CSR_SEED` via `csr_swap(CSR_SEED, 0)` up to `SEED_RETRY_LOOPS`, abort on `SEED_OPST_DEAD`, and return `true` only after `SEED_OPST_ES16` fills all `needed_seeds` (`sizeof(long) / sizeof(u16)`) 16-bit words. [F75, F79]
- `riscv64_aes_xts_supported()` must require `riscv_vector_vlen() < 2048`. In `riscv64_aes_ctr_crypt()`, compute `nblocks` (`DIV_ROUND_UP(nbytes, AES_BLOCK_SIZE)` on the final `nbytes == walk.total` chunk), detect 32-bit wrap via `ctr32 += nblocks` (`ctr32 < nblocks`), split encryption at `p1_nbytes` before `aes_ctr32_crypt_zvkned_zvkb()`, call `crypto_inc(req->iv, 12)`, and process the remaining `nbytes - p1_nbytes` when `ctr32 != 0`. [F68, F77, F87]

## Synchronization
- On `CONFIG_SMP`, `ptep_get_and_clear`, `pmdp_huge_get_and_clear`, `pudp_huge_get_and_clear`, `pmdp_establish`, and `pudp_establish` must use `atomic_long_xchg()` or `xchg()`. In `__set_pte_at()`, when `pte_present(pteval) && pte_exec(pteval)`, call `flush_icache_pte(mm, pteval)` before `set_pte()`. Callers of `untagged_addr_remote(mm, addr)` must hold `mm->mmap_lock` (`mmap_assert_locked(mm)` in `__untagged_addr_remote()`). [F9, F11, F130]
- `riscv_preempt_v_clear_dirty()` and `riscv_preempt_v_set_restore()` need `barrier()` before modifying `task->thread.riscv_v_flags`, and `riscv_v_flags()` must use `READ_ONCE()`. `may_use_simd()` must return `false` if `in_hardirq() || in_nmi()`, and in non-preemptible fallback require `!irqs_disabled() && !(riscv_v_flags() & RISCV_KERNEL_MODE_V)`. [F14, F112]
- Non-relaxed `readb/w/l/q` and `writeb/w/l/q` must use `__io_ar` (`RISCV_FENCE(i, ir)`) after reads and `__io_bw` (`RISCV_FENCE(w, o)`) + `__io_aw` (`mmiowb_set_pending()`) around writes, paired with `mmiowb()` (`RISCV_FENCE(o, w)`). `smp_mb__after_spinlock()` must use `RISCV_FENCE(iorw, iorw)`, `cpu_do_idle()` must run `mb()` before `wait_for_interrupt()`, and fully ordered LR/SC `arch_xchg()`/`arch_cmpxchg()` must emit a trailing `RISCV_FULL_BARRIER` on the successful `sc.w.rl`/`sc.d.rl` path (or use `.aqrl` on `amoswap`/`amocas`). [F17, F18, F111, F123]
- `mips_errata_patch_func()`, `sifive_errata_patch_func()`, `thead_errata_patch_func()`, `__runtime_fixup_32()`, and `__runtime_fixup_shift()` must hold `text_mutex` around `patch_text_nosync()`/`patch_insn_write()`, while `RISCV_ALTERNATIVES_EARLY_BOOT` before MMU uses `memcpy()` + `local_flush_icache_all()`. [F122]

## Object Lifetimes
- In `riscv64_aes_cbc_cts_crypt` and `riscv64_aes_xts_crypt`, if the initial `skcipher_walk_virt(&walk, req, false)` is partial and switches to a subrequest, call `skcipher_walk_abort(&walk)` first. In `riscv64_aes_mod_init`/`riscv64_aes_mod_exit`, gate `riscv64_zvkned_zvkb_aes_skcipher_alg` and `riscv64_zvkned_zvbb_zvkg_aes_skcipher_alg` with identical `ZVKB` and `riscv64_aes_xts_supported()` checks and reverse-order unwind. [F1, F2]
- `pud_free` and `__pud_free_tlb` must only free/remove descriptors when `pgtable_l4_enabled` is true, and `__p4d_free_tlb` only when `pgtable_l5_enabled` is true. [F3]

## API Contracts
- Bracket every vector crypto assembly call (`*_zvkned*`, `*_zvkg`, `*_zvksh_zvkb`, `*_zvksed_zvkb`) with `kernel_vector_begin()`/`kernel_vector_end()` with no early return or sleep between; synchronous `crypto_alg`/`shash_alg` callbacks (`riscv64_aes_encrypt`/`decrypt`, `riscv64_sm4_setkey`/`encrypt`/`decrypt`, `riscv64_ghash_blocks`, `sm3_block`) must check `crypto_simd_usable()` and provide a scalar C fallback. [F8, F113]
- `aes_ecb_*_zvkned()`, `aes_cbc_*_zvkned()`, and `ghash_zvkg()` require non-zero lengths that are multiples of 16. `riscv64_aes_cbc_cts_crypt()` and `riscv64_aes_xts_crypt()` must reject `req->cryptlen < AES_BLOCK_SIZE` with `-EINVAL` and pass at least the final full block + partial tail block together when ciphertext stealing crosses scatterlist segments. `riscv64_aes_setkey()` must use `aes_expandkey()` (populating `key_dec` and supporting AES-192), and `riscv64_zvkned_zvbb_zvkg_aes_skcipher_alg` must use `sizeof(struct riscv64_aes_xts_ctx)` and `riscv64_aes_xts_setkey`. [F65, F66, F97, F132]
- Mask PMU events by bits `[63:62]`: `RISCV_PMU_RAW_EVENT_MASK` (48-bit) or `RISCV_PMU_RAW_EVENT_V2_MASK` (56-bit, SBI v3.0) for raw events (`00`), vs `RISCV_PMU_PLAT_FW_EVENT_MASK` (62-bit) for firmware events (`11`). In `THEAD_CMO_OP()` (`thead_errata_cache_*`), align `_start` down to `_cachesize`, loop to `_start + _size`, and end with `THEAD_SYNC_S`. [F21, F108]
- Without `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`, unaligned `__gu_ptr` in `__get_user_nocheck()`/`__put_user_nocheck()` must fall back to `__asm_copy_from/to_user_sum_enabled()`. `regs_get_register()` rejects `@offset > MAX_REG_OFFSET` (`offsetof(struct pt_regs, orig_a0)`). `syscall_get_nr()` must return signed `int` (`regs->a7`), and `syscall_get_arguments`, `syscall_set_arguments`, `SC_RISCV_REGS_TO_ARGS`, and `syscall_rollback` must use `regs->orig_a0` for arg0. `__io_reads_ins`/`__io_writes_outs` must use `__raw_read*`/`__raw_write*` inside `bfence`/`afence`, and `ip_fast_csum(iph, ihl)` requires 4-byte aligned `iph` and `ihl >= 5`. [F57, F70, F90, F110, F136, F145]

## Error Handling
- Translate non-zero `struct sbiret.error` from `sbi_ecall()`/`__sbi_ecall()` via `sbi_err_map_linux_errno()`. `riscv64_ghash_update()` must pass `round_down(srclen, GHASH_BLOCK_SIZE)` to `riscv64_ghash_blocks()` and return `srclen - round_down(srclen, GHASH_BLOCK_SIZE)`. [F20, F31]
- `__get_user_error()`, `__get_user()`, and `get_user()` must zero `x` (and `__hi` in 32-bit `__get_user_8`) on `access_ok()` or fault failure and return `-EFAULT`; treat any non-zero residual byte count from `__asm_copy_to/from_user_sum_enabled()`, `raw_copy_to/from_user()`, or `clear_user()` as a fault. Non-`asm_goto_output` blocks using `_ASM_EXTABLE_UACCESS_ERR*` (`__get_user_asm`, `__get_user_8`, `__futex_atomic_op`, `arch_futex_atomic_op_inuser`, `futex_atomic_cmpxchg_inatomic`) must init the error var to `0` with `"+r"`; `ALT_SVPBMT(_val, prot)` (`"=r"(_val)`) must default to `"li %0, 0\t\nnop"`. [F23, F24, F26, F32]

## External Contracts
- New `RISCV_HWPROBE_KEY_*` constants require updating `RISCV_HWPROBE_MAX_KEY`, adding bitmask keys to `hwprobe_key_is_bitmask()`, and using `1ULL << n` for bitflags at bit `>= 31` (`RISCV_HWPROBE_EXT_ZVFHMIN`+). `struct user_regs_struct` must match the prefix of `struct pt_regs` (`pc`/`epc`..`t6`); `uc_mcontext` must stay last in `struct ucontext`, and `struct __riscv_extra_ext_header` (`sc_extdesc`) must keep its 129-`u32` `__padding` and zeroed `reserved` word before `hdr` (`END_MAGIC`/`END_HDR_SIZE`). [F62, F64, F82, F142]

## Known Pitfalls
- `aes_encrypt_zvkned()`, `aes_decrypt_zvkned()`, and `sm4_crypt_zvksed_zvkb()` take `(key, src, dst)`, whereas scalar `aes_encrypt()`, `aes_decrypt()`, and `sm4_crypt_block()` take `(key, dst, src)`. In `riscv64_aes_xts_crypt()`, when `tail > 0 && walk.nbytes < walk.total`, `req` is reassigned to `&subreq` (`cryptlen = req->cryptlen - tail - AES_BLOCK_SIZE`), which post-loop `scatterwalk_ffwd()` relies on. [F29, F78]
- In `__put_user(x, ptr)`, evaluate `x` into `__val` before `__enable_user_access()` and call `__disable_user_access()` right after `__put_user_error()`. Name the unaligned fallback temp in `__put_user_nocheck()` `___val` (3 underscores); cast 64-bit values in 32-bit `__get_user_8`/`__put_user_8` via `(__typeof__((x) - (x)))`; and wrap `__get_user_asm`, `__get_user_8`, `__put_user_asm`, and `__put_user_8` in `do { ... } while (0)`. [F71, F92, F121, F146]
- Sign-extend 32-bit `lr.w` comparands on RV64: cast `oldval` as `(long)(int)oldval` in `futex_atomic_cmpxchg_inatomic()` and `__old` as `(long)(int)(long)` in the 4-byte case of `_arch_cmpxchg()`. In `__arch_cmpxchg128()`, bind `amocas.q` register pairs to `t3`/`t4` (`"+&r"`) and `t1`/`t2` (`"rJ"`). [F80, F81, F125]
- Add `0x1000` to the upper 20-bit immediate in `riscv_insn_insert_utype_itype_imm()` and `__runtime_fixup_32()` when bit 11 of the 12-bit immediate is set. Shift Zbb `rev8` output right by `(BITS_PER_LONG - size)` in `ARCH_SWAB()`. Use `~((_cachesize) - 1UL)` in `THEAD_CMO_OP()`/`ALT_CMO_OP()`, and `_AC(..., ULL)`/`_ULL(1)` for `ENVCFG_*`/`SMSTATEEN0_*` bits `32..63` in `csr.h`. [F84, F85, F88, F91]
- In `ip_fast_csum()`, `CONFIG_32BIT` must add carry per word (`csum += csum < word`), while 64-bit folds upper-32-bit carries after the loop. Under `CONFIG_RISCV_ISA_SVNAPOT`, extract PFNs via `pte_pfn(pte)` (stripping the lowest set PFN bit when `has_svnapot() && pte_napot(pte)`), not `__page_val_to_pfn()`. Copy `regs->a1`..`a5` per-field in `syscall_get/set_arguments()` (avoiding `FORTIFY_SOURCE` on `memcpy`); use `"=r"(ret)` (not `"+r"`) when sharing `asm("a0")` with an `"r"` input in vDSO `ecall`s; and keep `arch_kgdb_breakpoint()` `noinline` out-of-line (`kgdb_compiled_break`). [F89, F94, F115, F119, F140]
