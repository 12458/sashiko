# IO_URING — io_uring

Implements the `io_uring` opcode dispatch table, `io_uring_register(2)` and fixed resource tables, per-task context management, SQPOLL offload, and request handlers for polling, timeouts, file/block I/O, networking, zero-copy RX/TX, `IORING_OP_URING_CMD`, and VFS/process opcodes.

## Architecture & Data Flow

- Every opcode in `[0, IORING_OP_LAST)` needs entries in `io_issue_defs[]` (non-NULL `.prep`, non-NULL `.issue` if `.prep != io_eopnotsupp_prep`, and `.async_size = sizeof(...)` if calling `io_uring_alloc_async_data(NULL, req)`) and `io_cold_defs[]` (non-NULL `.name`) [F268, F315].
- Poll waitqueue entries tag `IO_WQE_F_DOUBLE` in bit 0 of `poll->wait.private` (`wqe_to_req()`) and store single/double `io_poll` in `req->cmd`/`req->async_data` for `POLL_ADD` vs `req->apoll` for others (`io_poll_get_single()`/`io_poll_get_double()`). `io_poll_parse_events()` must `swahw32(sqe->poll32_events)` on `__BIG_ENDIAN`, and `io_poll_remove()` only updates the low 16 bits (`0xffff`) of `poll->events`. In `__io_arm_poll_handler()`, inline completion without `cancel_table` requires `(poll->events & (EPOLLET|EPOLLONESHOT)) == (EPOLLET|EPOLLONESHOT)`. Generic poll handlers (`io_poll_check_events()`, `io_poll_task_func()`) must not call `req_set_fail()` on `EPOLLERR`; `io_connect()` handles `EPOLLERR` when `connect->in_progress` is set [F231, F280, F288, F291].
- When a timeout on `ctx->timeout_list` expires (`io_timeout_fn()`) or is killed (`io_kill_timeout()`), increment `ctx->cq_timeouts` under `ctx->timeout_lock`; `io_timeout()` and `io_flush_timeouts()` subtract `atomic_read(&ctx->cq_timeouts)` from `ctx->cached_cq_tail`, update `ctx->cq_last_tm_flush`, and compare sequences via unsigned modular differences relative to `ctx->cq_last_tm_flush` (or `tail`) [F254, F284].
- Issuing `IORING_SETUP_IOPOLL` requests (`io_uring_cmd()`, `io_rw_init_file()`) resets `req->iopoll_completed = 0`, and under `IORING_SETUP_HYBRID_IOPOLL` clears `REQ_F_IOPOLL_STATE` and sets `req->iopoll_start = ktime_get_ns()`. `io_uring_classic_poll()` and `io_do_iopoll()` must check `req->opcode == IORING_OP_URING_CMD` before downcasting `req->cmd` to `io_rw` or calling `io_req_rw_cleanup()`. When `io->iter` or `io->meta` is imported/advanced, save `io->iter_state`/`io->meta_state` and restore via `iov_iter_restore()`/`io_meta_restore()` before partial-read advance, `-EAGAIN`, or reissue [F261, F265, F323].
- On partial network transfer retry (`ret > 0 && io_net_retry(sock, flags)`), `io_send()`, `io_recv()`, and `io_recvmsg()` must call `io_net_kbuf_recyle()` (`REQ_F_BL_NO_RECYCLE` and `io_kbuf_commit()` if `REQ_F_BUFFERS_COMMIT`). In `io_recv_finish()` for bundles, pass `this_ret = sel->val - sr->done_io` to `io_put_kbufs()`/`io_bundle_nbufs()`, retry only if `!(sr->flags & IORING_RECV_NO_RETRY)` and `!iov_iter_count(&kmsg->msg.msg_iter)`, and reset `sr->done_io`, `sr->len`, and `IORING_RECV_RETRY_CLEAR` in `io_mshot_prep_retry()`. Multishot recvmsg prep must check `hdr = sizeof(struct io_uring_recvmsg_out) + namelen + controllen` for negative `namelen`, overflow, and `*len >= hdr` [F262, F263, F278].
- Because `struct iou_vec` aliases `iovec` and `bvec`, `io_prep_reg_iovec()` and `io_import_reg_vec()` must right-align `iovec` entries at `vec->iovec + (vec->nr - nr_iovs)` and add `nr_iovs` extra slots when `sizeof(struct bio_vec) > sizeof(struct iovec)` [F273].
- `io_alloc_imu()` callers must set `imu->nr_bvecs` before indexing `imu->bvec[]` or calling `io_free_imu()`. For `!imu->is_kbuf`, only `imu->bvec[0]` may have non-zero `bv_offset`, and `io_import_fixed()`/`io_vec_fill_bvec()` must add `bvec->bv_offset` before `>> imu->folio_shift`. Kernel buffers (`io_buffer_register_bvec()`) set `imu->is_kbuf = true` and `imu->dir = 1 << rq_data_dir(rq)`; `io_import_fixed()`/`io_import_reg_vec()` check `imu->dir & (1 << ddir)` and dispatch `is_kbuf` to `io_import_kbuf()`/`io_vec_fill_kern_bvec()`, while `loop_rw_iter()` rejects `is_kbuf` (`-EFAULT`) [F306, F310, F356].
- `io_validate_user_buf_range()` checks `ulen > SZ_1G || !ulen` and `PAGE_ALIGN(ulen)` before `check_add_overflow()`. `io_clone_buffers()` requires matching `user` and `mm_account`, and checks `arg->nr + arg->dst_off` (overflow, `<= IORING_MAX_REG_BUFFERS`) and `arg->nr + arg->src_off` (overflow, `<= src_ctx->buf_table.nr`). `io_sqe_files_register()`/`io_sqe_files_unregister()` set `io_file_table_set_alloc_range()` to `[0, nr)`/`[0, 0)`, and call `io_clear_table_tags()` before `io_sqe_files_unregister()` on register failure. Reject `io_is_uring_fops(file)` in fixed-file register/update and `io_close()`. Opcodes allocating normal fds (`io_openat2`, `io_accept`, `io_socket`, `io_pipe_fd`) save `rlimit(RLIMIT_NOFILE)` in `.prep` for `__get_unused_fd_flags()` in `.issue` [F252, F259, F269, F308, F357, F360].
- In zcrx: round `reg.rq_entries` up to a power of two (`<= IO_RQ_MAX_ENTRIES`) and verify `rd->size` in `io_allocate_rbuf_ring()`; `ifq->niov_shift` must be `>= PAGE_SHIFT` and match `pp->p.order + PAGE_SHIFT`. Call `io_zcrx_get_rqe()` at `io_zcrx_ring_refill()` loop start before any `continue`, and in `io_parse_rqe()` check `rqe->__pad == 0`, `rqe->off >> IORING_ZCRX_AREA_SHIFT == 0`, and `niov_idx < area->nia.num_niovs` (`array_index_nospec()`). `io_zcrx_recv_skb()` returns `0` if `!len`, `-EAGAIN` if `args->nr_skbs++ > IO_SKBS_PER_CALL_LIMIT`, and saves/restores `desc->count` around `skb_walk_frags()`. `io_zcrx_recv_frag()` requires `niov->pp->mp_ops == &io_uring_pp_zc_ops` and matching `ifq`, calling `page_pool_ref_netmem()` before `io_zcrx_get_niov_uref()` [F189, F276, F277, F297, F298, F309, F355].

## Synchronization

- `sqd->lock` nests outside `ctx->uring_lock` (drop `uring_lock` before `sqd->lock`, `io_sq_thread_park()`, or `io_put_sq_data()`). `__io_uring_add_tctx_node()` and `io_uring_alloc_task_context()` take `ctx->uring_lock` internally (unlock first). In `io_register_clone_buffers()` when `src_ctx != ctx`, drop `ctx->uring_lock`, call `lock_two_rings(ctx, src_ctx)`, and unlock only `src_ctx->uring_lock` before `fput()`. In `io_register_resize_rings()`, park `ctx->sq_data` (with `uring_lock` dropped) and hold `uring_lock`, `mmap_lock`, and `completion_lock` in order while resetting `cqe_cached`/`cqe_sentinel` and updating ring pointers/sizes [F201, F221, F224, F251, F336].
- `ctx->completion_lock` nests outside `ctx->timeout_lock`. Task context must take `ctx->timeout_lock` (`raw_spinlock_t` used in hardirq `io_timeout_fn`/`io_link_timeout_fn`) with `raw_spin_lock_irq()`/`raw_spin_lock_irqsave()`. In `io_link_timeout_fn()`, pin `prev = timeout->head` via `req_ref_inc_not_zero(prev)` under `ctx->timeout_lock`. Atomic/irq callbacks (`io_poll_wake`, `io_waitid_wait`, `io_async_buf_func`, `io_timeout_fn`, `io_link_timeout_fn`, `io_complete_rw`, `io_tx_ubuf_complete`) must defer user copies and `ctx->uring_lock` to `task_work`. IOPOLL callbacks (`io_complete_rw_iopoll()`, `__io_uring_cmd_done()`) must update `req->cqe`, `req->flags`, and cleanup state before `smp_store_release(&req->iopoll_completed, 1)` [F226, F330, F331, F334, F342].
- Hold `rcu_read_lock()` in `io_poll_remove_entries()` and `io_poll_double_prepare()` from before `smp_load_acquire(&poll->head)` until after `spin_unlock_irq(&head->lock)`. `io_poll_double_prepare()` must hold the first entry's `head->lock` before setting `REQ_F_DOUBLE_POLL | REQ_F_ASYNC_DATA`. In `io_pollfree_wake()`, execute `smp_store_release(&poll->head, NULL)` only after `io_poll_mark_cancelled(req)`, `io_poll_execute(req, 0)`, and `list_del_init(&poll->wait.entry)`. In `__io_arm_poll_handler()`, when `issue_flags & IO_URING_F_UNLOCKED`, set `req->poll_refs = 1` before `vfs_poll()` and release via `atomic_cmpxchg(&req->poll_refs, 1, 0)` (else `__io_poll_execute(req, 0)`). In `io_poll_check_events()`, clear `IO_POLL_RETRY_FLAG` via `atomic_andnot()` before `vfs_poll()` [F204, F209, F216, F217, F227].
- `sqd->thread` is `__rcu`: under `sqd->lock` (or after `io_sq_thread_park()`), use `sqpoll_task_locked(sqd)` and verify non-NULL; unlocked readers need `rcu_read_lock()`, `rcu_dereference()`, and `get_task_struct()`. `io_sq_thread_unpark()` must `clear_bit(IO_SQ_THREAD_SHOULD_PARK, &sqd->state)` before `atomic_dec_return(&sqd->park_pending)` and re-set if non-zero. Before sleeping, `io_sq_thread()` must `atomic_or(IORING_SQ_NEED_WAKEUP, ...)` and `smp_mb__after_atomic()` before `io_sqring_entries(ctx)`. `__io_sq_thread()` brackets `io_do_iopoll()`/`io_submit_sqes()` with `override_creds(ctx->sq_creds)`/`revert_creds()` when `ctx->sq_creds != current_cred()` [F225, F228, F229, F258, F341].
- In `io_waitid()`, `atomic_set(&iw->refs, 1)` before `add_wait_queue()` and call `io_waitid_drop_issue_ref(req)` on `-ERESTARTSYS`. In `io_waitid_wait()`, after `pid_child_should_wake()`, run `list_del_init(&wait->entry)` before checking `atomic_fetch_inc(&iw->refs) & IO_WAITID_REF_MASK`. In `io_recv_buf_select()`, use `io_buffers_peek()` for bundles only when `!(issue_flags & IO_URING_F_UNLOCKED)`. In `io_uring/zcrx.c`, always take `ifq->rq_lock` and `area->freelist_lock` with `spin_lock_bh()`, and hold `ifq->rq_lock` around `io_zcrx_put_niov_uref(niov)`. In `io_close_queue()`, clear `ifq->netdev` under `ifq->pp_lock` and unlock before `net_mp_close_rxq()`. Call `io_zcrx_sync_for_device(pp, niov)` before `net_mp_netmem_place_in_cache()` [F207, F213, F218, F219, F223, F332, F344].

## Object Lifetimes

- In `io_sqe_buffer_register()`, any failure after `io_pin_pages()` jumps to `done` (freeing `imu`, unpinning pages, freeing `node`), and always calls `kvfree(pages)`. Both `io_sqe_buffer_register()` and `io_release_ubuf()` must unpin via `unpin_user_folio(page_folio(page), 1)` [F191, F350].
- In `io_import_umem()`, call `unpin_user_pages()` if `sg_alloc_table_from_pages()` fails, but if `io_account_mem()` fails, zero `mem->account_pages` and still assign `mem->pages`, `mem->nr_folios`, and `mem->sgt` for `io_zcrx_free_area()`. For `!area->mem.is_dmabuf`, call `io_zcrx_map_area()` in `io_pp_zc_init()` and `io_zcrx_unmap_area()` in `io_pp_uninstall()` under `ifq->pp_lock`. `io_pp_zc_destroy()` unconditionally calls `percpu_ref_put(&ifq->ctx->refs)` [F186, F212, F352].
- In `io_send_select_buffer()` and `io_recv_buf_select()`, if `arg.iovs` was dynamically allocated, save it in `kmsg->vec` and set `REQ_F_NEED_CLEANUP` before the `ret == 1` branch. In `io_send_zc_import()`, pass `sr->notif` (not `req`) to `io_import_reg_buf()`. When `io_send_zc()`/`io_sendmsg_zc()` flushes `zc->notif` inline (`!(issue_flags & IO_URING_F_UNLOCKED)`), set `zc->notif = NULL` [F193, F194, F195].
- `io_req_rw_cleanup()` must not call `io_rw_recycle()` when `req->flags & (REQ_F_REISSUE | REQ_F_REFCOUNT)`. When `io_kiocb_start_write()` sets `IOCB_WRITE` (`REQ_F_ISREG`), every completion, retry, and error path must call `io_req_end_write()`. `io_uring_cmd_sqe_copy()` copies `uring_sqe_size(req->ctx)` bytes to `ac->sqes` and sets `ioucmd->sqe = ac->sqes` before async execution; `io_req_uring_cleanup()` clears `ioucmd->sqe = NULL`. Call `io_alloc_cache_vec_kasan(&...->vec)` before `io_alloc_cache_put()` on `io_async_rw`, `io_async_msghdr`, or `io_async_cmd`. In `io_uring_clean_tctx()`, remove all `tctx->xa` nodes via `io_uring_del_tctx_node()` before `io_wq_put_and_exit(wq)` [F196, F200, F256, F316, F349].

## API Contracts

- `io_uring_register_get_file()` callers must `fput(file)` when `!IS_ERR(file)`. Initialize `unsigned long id = 0` before each `xa_find()` in `io_unregister_zcrx_ifqs()`. `io_sqe_buffer_register()` returns `NULL` (empty iov), `ERR_PTR`, or `node`; check `IS_ERR(node)` first and reject `tag != 0` (`-EINVAL`) when `!node`. Batch update/refill functions (`__io_sqe_files_update`, `__io_sqe_buffers_update`, `io_files_update_with_index_alloc`, `io_ringfd_register`, `io_zcrx_return_bufs`) return the positive count of committed entries if any succeeded, rolling back uncommitted slots on `copy_to_user()` failure. `__io_fixed_fd_install()`, `io_fixed_fd_install()`, and `io_close_fixed()` take 1-based `file_slot`s; `io_fixed_fd_remove()`, `__io_close_fixed()`, and `io_rsrc_node_lookup()` take 0-based offsets [F205, F233, F236, F238, F274].
- `io_uring_cmd_buffer_select()` can return `-errno` in `sel.val` (unioned with `sel.addr`) and any selected buffer must be passed to `io_uring_mshot_cmd_post_cqe()` with the byte count or errno in `sel->val`. When `__io_arm_poll_handler()` returns `0`, callers must not touch `req`; `ipt->result_mask` is valid only when `> 0`. In `io_do_iopoll()`, the completed sublist head is `start ? start->next : ctx->iopoll_list.first`, unlinked via `wq_list_cut(&ctx->iopoll_list, prev, start)`. `io_alloc_cache_free()` callbacks require `void (*)(const void *)`. `__io_uring_cmd_done()` calls `io_req_complete_defer()` only when `(issue_flags & (IO_URING_F_COMPLETE_DEFER | IO_URING_F_UNLOCKED)) == IO_URING_F_COMPLETE_DEFER`. Blocking-only opcodes set `REQ_F_FORCE_ASYNC` in `.prep` (`io_openat_force_async()` tests `__O_TMPFILE`, not `O_TMPFILE`) [F206, F230, F247, F290, F292, F317, F328, F329].

## Error Handling

- In `io_zcrx_create_area()`, set `area->ifq = ifq` before any `goto err`. Keep `ifq->if_rxq = -1` until `net_mp_open_rxq()` succeeds (pass `reg.if_rxq` earlier). In `io_import_dmabuf()`, reset failed `mem` pointers to `NULL` and jump to `err` on any post-get failure. On `overflow` in `io_register_resize_rings()`, restore `o.rings`/`o.sq_sqes` and set `to_free = &n` before unlocking, freeing `to_free`, and unparking `ctx->sq_data` [F187, F188, F203, F232].
- Zero `sr->done_io` before any early error return in `io_sendmsg_prep()`, `io_recvmsg_prep()`, and `io_send_zc_prep()`. Initialize `ix->filename = NULL` before setting `REQ_F_NEED_CLEANUP` in xattr prep, and clear `ix->filename = NULL` right after `filename_getxattr()`/`filename_setxattr()`. Translate `-ERESTARTSYS` to `-EINTR` in synchronous `.issue` handlers, but treat `-ERESTARTSYS` from `__do_wait()` in `io_waitid()` as an armed wait. Check `ret == IOU_REQUEUE` (-3072) before `ret < 0` in `io_poll_check_events()` and `io_recvzc()` [F240, F244, F249, F289].

## External Contracts

- `io_import_area()` and `io_import_dmabuf()` require page-aligned `addr`/`len` passing `io_validate_user_buf_range()`, and `IORING_ZCRX_AREA_DMABUF` requires `area_reg->addr == 0` and `area_reg->len == total_size`. Under `io_is_compat(ctx)` / `in_compat_syscall()`, use `compat_iovec`, `compat_msghdr`, `compat_siginfo`, and `compat_get_bitmap()` (clamping `len` to `cpumask_size()` in `io_register_iowq_aff()`). `io_handle_query_entry()` requires zeroed `__resv`/`result`, `size > 0`, `copy_struct_to_user()`, and `<= IO_MAX_QUERY_ENTRIES` [F270, F279, F282, F325].
- `REQ_F_HAS_METADATA` in `io_rw_init_file()` requires `FMODE_HAS_METADATA` (`-EINVAL`) and `O_DIRECT` (`-EOPNOTSUPP`). `io_install_fixed_fd_prep()` rejects `REQ_F_CREDS` (`-EPERM`) and requires `REQ_F_FIXED_FILE` (`-EBADF`). Bundle retry/peek checks `kmsg->msg.msg_inq > 1`, whereas `IORING_CQE_F_SOCK_NONEMPTY` checks `> 0`. `io_link_skb()` requires matching `io_ubuf_ops`, `ctx`, `tctx`, and `nd->head == nd && !nd->next`. `io_sg_from_iter()` requires `SKBFL_MANAGED_FRAG_REFS` on `frag == 0` or `skb_zcopy_managed(skb)`, while `io_sg_from_iter_iovec()` calls `skb_zcopy_downgrade_managed(skb)` [F348, F351, F353, F354, F361].

## Known Pitfalls

- `io_read_mshot()` must reset `rw->len = 0` on `-EAGAIN` recycle and after `io_put_kbuf()`. `io_sendmsg()`/`io_sendmsg_zc()` must restore `kmsg->msg.msg_control_user = sr->msg_control` before each call (and clear `msg_controllen`/`msg_control` after partial `io_sendmsg()`) [F264, F267].
- In `io_sqe_buffer_register()`, coalesced `imu->bvec[0]` offset is `((unsigned long)iov->iov_base & ~PAGE_MASK) + (data.first_folio_page_idx << PAGE_SHIFT)`. Cast `area->area_id` (`u16`) to `u64` before `<< IORING_ZCRX_AREA_SHIFT`. In `io_copy_page()`, normalize subpages and clamp to `PAGE_SIZE` when `folio_test_partial_kmap()` is true, unmap in reverse order, and advance `src_offset += n` each iteration. Use a separate `req` match pointer in `io_timeout_extract()`/`io_linked_timeout_update()` loops, and operate on target `preq` (not `req`) in `io_poll_remove()` [F271, F285, F294, F301, F304, F345].
