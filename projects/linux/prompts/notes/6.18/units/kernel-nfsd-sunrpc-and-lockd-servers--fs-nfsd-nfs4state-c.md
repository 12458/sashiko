# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd/nfs4state.c

This component implements the NFSv4.0, NFSv4.1, and NFSv4.2 state manager in `fs/nfsd/nfs4state.c`. It manages the lifecycles, hash/IDR lookups, and locking for clients (`nfs4_client`), sessions (`nfsd4_session`), open/lock stateowners, open/lock/delegation stateids (`nfs4_stid`), opened files (`nfs4_file`), POSIX byte-range locks, VFS file leases (delegations), and the background laundromat expiration worker.

## Architecture & Data Flow

- `alloc_init_deleg` increments `num_delegations` on entry and must decrement `num_delegations` via `out_dec` on any failure before `nfs4_alloc_stid(clp, deleg_slab, nfs4_free_deleg)` succeeds, because once `stid` is allocated, `nfs4_free_deleg` decrements `num_delegations`. [F196]
- `nfsd_total_target_slots` tracks the sum of `ses->se_target_maxslots - 1` across all allocated sessions: `alloc_session` adds `i - 1`, `nfsd4_sequence` slot growth adds `s - session->se_target_maxslots`, and `reduce_session_slots` and `free_session_slots` subtract any reduction in `se_target_maxslots` down to 1. [F197]
- Setting `SC_STATUS_ADMIN_REVOKED` on a `struct nfs4_stid` (in `unhash_delegation_locked` or `nfsd4_revoke_states`) must be paired with `atomic_inc(&clp->cl_admin_revoked)`, which is decremented in `nfs4_put_stid` or `put_ol_stateid_locked` when the stateid is removed from `clp->cl_stateids`. [F198]
- When inspecting a VFS `file_lease` or `file_lock` (`nfsd4_deleg_getattr_conflict()` and `nfs4_set_lock_denied()`), `fl->c.flc_owner` must only be cast to `struct nfs4_delegation *` if `fl->fl_lmops == &nfsd_lease_mng_ops`, or to `struct nfs4_lockowner *` if `fl->fl_lmops == &nfsd_posix_mng_ops`. [F221]
- Both `nfs4_openowner` and `nfs4_lockowner` reside in `clp->cl_ownerstr_hashtbl` and must be discriminated by `so->so_is_open_owner` before calling `openowner(so)` or `lockowner(so)`, while `nfs4_ol_stateid` entries on `fp->fi_stateids` are discriminated by `st->st_openstp` (`NULL` for open stateids, parent open stateid for lock stateids). [F224]
- `struct nfs4_clnt_odstate` pointers (`open->op_odstate`, `stp->st_clnt_odstate`, `dp->dl_clnt_odstate`) are only allocated when `nfsd4_has_session(cstate)` and `NFSEXP_PNFS` are both set and are `NULL` otherwise, so any code handling them must tolerate `NULL` (as `get_clnt_odstate()`, `put_clnt_odstate()`, and `find_or_hash_clnt_odstate()` do). [F227]
- Each bit set in `nfs4_ol_stateid.st_access_bmap` holds one corresponding reference in `nfs4_file.fi_access[O_RDONLY]` and/or `fi_access[O_WRONLY]`, so callers must check `test_access()` before calling `__nfs4_file_get_access()` or `nfs4_file_put_access()` when mutating `st_access_bmap`. [F237]
- `nfs4_file.fi_share_deny` caches the bitwise union of `bmap_to_share_mode(stp->st_deny_bmap)` across all `stp` on `fp->fi_stateids`, and must be updated under `fp->fi_lock` when adding deny bits or recomputed via `recalculate_deny_mode()` when clearing or unhash-releasing them. [F238]
- When `nfsd4_add_rdaccess_to_wrdeleg()` grants read access for a write-only OPEN delegation by setting `fp->fi_fds[O_RDONLY]` and `fp->fi_rdeleg_file` and incrementing `fp->fi_access[O_RDONLY]`, `put_deleg_file()` must release `fp->fi_rdeleg_file` via `nfs4_file_put_access(fp, NFS4_SHARE_ACCESS_READ)` when `fp->fi_delegees` reaches zero. [F240]
- `nfs4_open_delegation()` must snapshot original file timestamps via `nfs4_delegation_stat()` into `dp->dl_atime`, `dp->dl_mtime`, and `dp->dl_ctime`, and `cb_getattr_update_times()` must vet delegated timestamps against those saved fields via `nfsd4_vet_deleg_time()` rather than current inode timestamps. [F241]

## Synchronization

- When dropping the persistent reference to an unhashed open or lock stateid while holding `clp->cl_lock`, callers must use `put_ol_stateid_locked(stp, &reaplist)` and invoke `free_ol_stateid_reaplist(&reaplist)` only after unlocking `clp->cl_lock`. [F191]
- `nfs4_preprocess_seqid_op` and `nfs4_preprocess_confirmed_seqid_op` return `nfs_ok` with `*stpp` holding a reference on `stp->st_stid` and `stp->st_mutex` locked (`LOCK_STATEID_MUTEX`), whereas on any non-zero return neither `stp->st_mutex` nor the `stp->st_stid` reference is held. [F199]
- `nfsd4_drop_revoked_stid` is entered with `s->sc_client->cl_lock` held and must release `s->sc_client->cl_lock` across every branch before returning (and before calling `free_ol_stateid_reaplist` or `nfs4_put_stid`). [F201]
- In `nfsd_break_one_deleg`, which executes under the VFS `flc_lock` spinlock via `nfsd_break_deleg_cb`, failure of `nfsd4_run_cb(&dp->dl_recall)` must drop the delegation reference with `refcount_dec(&dp->dl_stid.sc_count)` rather than `nfs4_put_stid(&dp->dl_stid)`, and `nfs4_free_deleg` must never sleep. [F204]
- Callers that unhash a delegation to invoke `revoke_delegation` (`nfs4_laundromat` and `nfsd4_revoke_states`) must increment `dp->dl_stid.sc_count` before dropping `state_lock`, and `revoke_delegation` and `nfsd4_free_stateid` must synchronize `clp->cl_revoked` list membership under `clp->cl_lock` using `SC_STATUS_FREEABLE` and `SC_STATUS_FREED`. [F206]
- In `nfsd4_free_stateid`, when freeing a delegation with `SC_STATUS_REVOKED`, `s->sc_status` must be marked with `SC_STATUS_CLOSED` under `s->sc_lock` and `SC_STATUS_FREED` under `cl->cl_lock` before dropping `cl->cl_lock` to call `nfs4_put_stid(s)`. [F207]
- Spinlocks in `fs/nfsd/nfs4state.c` must nest in the order `state_lock` -> `clp->cl_lock` -> `fp->fi_lock`, and `nn->client_lock` must nest outside `clp->cl_lock` -> `nfsd_session_list_lock`. [F209]
- Because `stp->st_mutex` nests outside `clp->cl_lock` and `fp->fi_lock`, callers locking an existing `struct nfs4_ol_stateid` must first pin `stp->st_stid.sc_count`, drop spinlocks, and call `nfsd4_lock_ol_stateid(stp)` to acquire `stp->st_mutex` and revalidate `stp->st_stid.sc_status` via `nfsd4_verify_open_stid`. [F211]
- In `init_open_stateid` and `init_lock_stateid`, after acquiring `cl_lock` (and `fi_lock`), the function must verify that the parent openowner (`!nfs4_openowner_unhashed(oo)`) or parent open stateid (`!nfs4_ol_stateid_unhashed(open_stp)`) is still hashed before linking the new stateid into `so_stateids`, `fi_stateids`, or `open_stp->st_locks`. [F212]
- In `move_to_close_lru`, `store_release_wake_up(&oo->oo_owner.so_replay.rp_locked, RP_UNHASHED)` must be called before `wait_event(close_wq, refcount_read(&s->st_stid.sc_count) == 2)` so threads waiting in `nfsd4_cstate_assign_replay` while holding a reference on `s->st_stid.sc_count` wake up, see `RP_UNHASHED`, and drop their reference. [F213]

## Object Lifetimes

- `nfsd4_sequence_check_conn` unconditionally consumes its `new` `struct nfsd4_conn *` argument (either hashing it onto `ses->se_conns` or freeing it via `free_conn(new)`), so `nfsd4_sequence` must clear `conn = NULL` immediately after calling `nfsd4_sequence_check_conn`. [F185]
- When `nfsd4_process_open2` or `init_open_stateid` hashes the pre-allocated `open->op_file`, `open->op_stp`, or `open->op_odstate` from `nfsd4_process_open1`, it must set that field of `struct nfsd4_open` to `NULL` so `nfsd4_cleanup_open_state` only frees unconsumed allocations. [F186]
- When tearing down a delegation in `destroy_unhashed_deleg` or rolling back `nfs4_set_delegation`, the VFS lease must be removed via `kernel_setlease(..., F_UNLCK, ...)` before `nfs4_put_stid(&dp->dl_stid)` drops the delegation reference. [F189]
- In `nfsd4_cb_getattr_release`, `nfsd4_cb_recall_release`, `nfsd4_cb_notify_lock_release`, and `nfsd4_cb_recall_any_release`, dropping the enclosing object's reference (`nfs4_put_stid`, `free_blocked_lock`, or `drop_client`) must be the final action because it can immediately free the structure containing `struct nfsd4_callback`. [F192]
- `move_to_close_lru` must set `s->st_stid.sc_file = NULL` after calling `put_nfs4_file(s->st_stid.sc_file)` when placing an NFSv4.0 open stateid onto `oo->oo_last_closed_stid` and `nn->close_lru`. [F193]
- In `__nfs4_file_put_access` and `put_deleg_file`, when `fp->fi_access[oflag]` or `fp->fi_delegees` reaches zero, `fp->fi_fds[]`, `fp->fi_deleg_file`, and `fp->fi_rdeleg_file` must be cleared to `NULL` under `fp->fi_lock` before calling `nfsd_file_put` outside the lock. [F195]
- In `nfsd4_create_session`, if `mark_client_expired_locked(old)` fails with `nfserr_jukebox` after `cs_slot->sl_seqid` was incremented, `out_expired_error` must revert `cs_slot->sl_seqid--` and skip `nfsd4_cache_create_session` before unlocking `nn->client_lock` and freeing `conn` and `new`. [F202]
- In `nfsd4_deleg_getattr_conflict`, before unlocking `ctx->flc_lock` to wait on `NFSD4_CALLBACK_RUNNING` or call `nfsd_open_break_lease`, a reference on `dp->dl_stid.sc_count` must be taken under `ctx->flc_lock` and either returned via `*pdp` or released with `nfs4_put_stid(&dp->dl_stid)`. [F208]
- Before freeing an `nfs4_ol_stateid` via `free_ol_stateid_reaplist()` on a v4.1+ client (`clp->cl_minorversion > 0`) or via `nfs4_put_stid()`, `nfs4_free_cpntf_statelist()` must empty `stid->sc_cp_list` and remove any child `nfs4_cpntf_state` entries from `nn->s2s_cp_stateids`. [F256]
- When `kernel_setlease()` is called in `nfs4_set_delegation()` to install a lease allocated by `nfs4_alloc_init_lease()`, the caller must check `if (fl) locks_free_lease(fl)` afterward because the VFS lease subsystem may either consume and clear `fl` or leave it non-NULL. [F325]

## API Contracts

- `nfs4_preprocess_stateid_op` transfers the `struct nfs4_stid` reference to `*cstid` only when returning `nfs_ok` (`status == 0`) with a non-NULL `cstid`; when `cstid` is `NULL` or `status` is non-zero, `nfs4_preprocess_stateid_op` drops `s` via `nfs4_put_stid(s)` before returning. [F188]
- Callers of `get_client_locked(clp)` under `nn->client_lock` must check that it returns `nfs_ok` before treating `clp` as active or later releasing `clp->cl_rpc_users`, because `get_client_locked()` returns `nfserr_expired` without incrementing `clp->cl_rpc_users` if `is_client_expired(clp)` is true. [F219]
- `stp->st_access_bmap` and `stp->st_deny_bmap` store bit indices `1 << mode` (bits 1..3 for READ, WRITE, BOTH) rather than wire `NFS4_SHARE_*` masks, so converting a bitmap to a wire share mode requires `bmap_to_share_mode(bmap)`, and `reset_union_bmap_deny(deny, stp)` must be passed a wire `NFS4_SHARE_DENY_*` mask rather than a raw `st_deny_bmap`. [F225]
- In `struct nfs4_file`, `fi_fds[3]` is indexed by `O_RDONLY`, `O_WRONLY`, or `O_RDWR` via `nfs4_access_to_omode()`, whereas `fi_access[2]` and `__nfs4_file_put_access(fp, oflag)` only accept `O_RDONLY` (0) or `O_WRONLY` (1) because `__nfs4_file_put_access()` uses `1 - oflag` to check the opposite access counter. [F226]
- `nfs4_set_delegation()` returns an `ERR_PTR(-errno)` on failure and never `NULL`, whereas `nfs4_init_cp_state()` and `nfs4_init_copy_state()` return `1` on success and `0` on failure (not a negative errno or `__be32` status). [F229]
- In `nfs4_preprocess_stateid_op()`, `*nfp` (when `nfp != NULL`) is initialized to `NULL` on entry, but `*cstid` (when `cstid != NULL`) is not written when `stateid` is a special stateid (`ZERO_STATEID` or `ONE_STATEID`), so callers passing a non-NULL `cstid` must initialize `*cstid = NULL` beforehand and check `*cstid` for `NULL` even on `nfs_ok`. [F230]
- `manage_cpntf_state(nn, st, clp, cps)` uses `clp` as a mode selector: when `clp == NULL`, it takes a reference on `state->cp_stateid.cs_count` and writes the entry to `*cps` (requiring `cps != NULL` and a later `nfs4_put_cpntf_state()`), whereas when `clp != NULL`, it drops a reference via `_free_cpntf_state_locked(nn, state)` and ignores `cps`. [F231]
- `nfsd4_deleg_getattr_conflict(rqstp, dentry, pdp)` only writes `*pdp = dp` (transferring a `dp->dl_stid` reference) when returning `nfs_ok` with `ncf->ncf_file_modified` true and drops `dp->dl_stid` on all other paths, so callers must initialize `*pdp = NULL` beforehand and call `nfs4_put_stid(&dp->dl_stid)` if `*pdp` is non-NULL. [F234]
- Before passing an NFSv4 lock `(offset, length)` to the VFS in `struct file_lock`, callers must validate it with `check_lock_length()`, set `fl_end = last_byte_offset(offset, length)`, and call `nfs4_transform_lock_offset()` to clamp negative signed `loff_t` `fl_start`/`fl_end` values to `OFFSET_MAX`. [F236]

## Error Handling

- In `nfsd4_sequence()`, response fields `seq->maxslots`, `seq->target_maxslots`, and `seq->status_flags` must be populated after the `out:` label so that cached replay requests (`status == nfserr_replay_cache`) jumping to `out:` still return initialized slot counts and status flags. [F220]
- In `nfs4_get_vfs_file()`, `stp->st_access_bmap` and `stp->st_deny_bmap` must be sampled before in-place mutation so that if file acquisition, lease break, or truncation fails, `out_put_access` restores `st_access_bmap`, drops the new `fi_access` ref, and resets `st_deny_bmap` and `fi_share_deny`. [F239]

## External Contracts

- In `nfsd4_process_open2()`, `OPEN4_SHARE_ACCESS_WANT_OPEN_XOR_DELEGATION` (`open_xor_delegation()`) must only release `stp` and zero `open->op_stateid` when `new_stp` is true; when upgrading an existing open stateid (`!new_stp`), the updated open stateid must be preserved and returned. [F253]
- In `create_client`, `client_files[]` passed to `nfsd_client_mkdir` must keep `"info"` at index 0 and terminate with an empty-name sentinel `{""}` because `clp->cl_nfsd_info_dentry` is assigned unconditionally from `dentries[0]` for `fsnotify_dentry` notifications. [F266]
- In `nfsd4_lookup_stateid()`, `statusmask` must always include `SC_STATUS_ADMIN_REVOKED | SC_STATUS_FREEABLE` (and `SC_STATUS_REVOKED` when `typemask & SC_TYPE_DELEG`) before calling `find_stateid_by_type()`, which rejects any stateid where `(s->sc_status & ~ok_states) != 0`. [F267]
- In `check_special_stateids()`, `ONE_STATEID(stateid) && (flags & RD_STATE)` must return `nfs_ok` before checking `opens_in_grace(net)`, whereas WRITE with `one_stateid` and READ/WRITE with `zero_stateid` must check `opens_in_grace(net)` and return `nfserr_grace` before calling `nfs4_share_conflict()`. [F281]

## Known Pitfalls

- In `nfs4_open_delegation()` and `nfs4_delegation_stat()`, `currentfh` is `&resp->cstate.current_fh` (the parent directory during `NFS4_OPEN_CLAIM_NULL`), so delegation file attributes must be queried from `file_dentry(nf->nf_file)` on `dp->dl_stid.sc_file` with `STATX_MODE` rather than `currentfh->fh_dentry`. [F268]
- In `nfsd_slot_scan()`, rotating the global list head `nfsd_session_list` after `ses->se_all_sessions` via `list_move(&nfsd_session_list, &ses->se_all_sessions)` mutates the loop's termination sentinel and must be immediately followed by `break`. [F275]
- In `nfsd4_lock()`, when `lock->lk_is_new` is true, `cstate->replay_owner` is set to `&open_sop->oo_owner`, so `out:` must also manually increment `lock_sop->lo_owner.so_seqid++` when `cstate->replay_owner && cstate->replay_owner != &lock_sop->lo_owner && seqid_mutating_err(ntohl(status))`. [F285]
- In `nfsd4_setclientid_confirm()`, `old` holds the client to be destroyed by `expire_client(old)` after dropping `nn->client_lock`, so if any check in the `!conf` branch fails after `old = find_confirmed_client_by_name(...)`, `old` must be reset to `NULL` before `goto out`. [F286]
- In `nfsd4_init_leases_net`, `si.totalram` must be widened to `u64` before multiplying by `si.mem_unit` to compute `max_clients`, preventing 32-bit `unsigned long` overflow on 32-bit systems with 4 GiB or more of RAM. [F288]
- `nn->s2s_cp_stateids` stores `copy_stateid_t *` entries embedded in both `struct nfsd4_copy` (`NFS4_COPY_STID`) and `struct nfs4_cpntf_state` (`NFS4_COPYNOTIFY_STID`), so any lookup or iteration must verify `cs_type == NFS4_COPYNOTIFY_STID` before accessing `struct nfs4_cpntf_state` fields via `container_of`. [F298]
- `struct xdr_netobj` buffers duplicated via `xdr_netobj_dup` (`cl_name`, `cl_nii_domain`, `cl_nii_name`, `so_owner`, `ld_owner`) are allocated with `kmemdup` of exact length `.len` without a NUL terminator, so formatting or comparing them must bound reads by `.len` (e.g., via `seq_quote_mem`, `same_owner_str`, or `compare_blob`). [F303]
