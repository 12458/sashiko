# COMMON INTERNET FILE SYSTEM CLIENT (CIFS and SMB3) — fs/smb/client (part 4)

This component implements SMB session setup and authentication (NTLMSSP, Kerberos/SPNEGO), multichannel interface management, directory enumeration (`readdir`), reparse point and symlink/special-file handling (Native, NFS, WSL), SMB1 version operations, and SMB2/3 compounded metadata operations and message validation.

## Architecture & Data Flow

- In `smb2_compound_op()`, slot `0` of `rsp_iov`/`resp_buftype` is for `SMB2_CREATE` and `num_cmds + 1` for `SMB2_CLOSE`, so `cmds[i]` is at `rsp_iov[i + 1]`. `cmds[0] == SMB2_OP_OPEN_QUERY` is skipped before the build loop and parsed from `rsp_iov[0]`, and `SMB2_OP_MKDIR` neither increments `num_rqst` nor calls `*_free(&rqst[num_rqst++])`. After adding 2 to `num_cmds` to copy/free `Open`/`Close` responses, `num_cmds -= 2` must be restored before `goto replay_again` (resetting `flags`, `oplock`, `num_rqst`, `server`, `vars`, `resp_buftype`). [F408, F418, F446]
- `smb2_rsp_struct_sizes[]`, `has_smb2_data_area[]`, and `switch (shdr->Command)` in `smb2_get_data_area_len()` must stay in lockstep; arrays are indexed by `le16_to_cpu(shdr->Command)` after checking `command < NUMBER_OF_SMB2_COMMANDS`, while `smb2_rsp_struct_sizes[]` stores `__le16` values to compare with `pdu->StructureSize2`. [F416, F428]
- In `smb2_compound_op()` (`SMB2_OP_POSIX_QUERY_INFO`), `parse_posix_sids()` must verify `out_len > sizeof(data->posix_fi)` and validate owner and group SIDs within `[sidsbuf, sidsbuf_end)` via `posix_info_sid_size()`. For `SMB2_OP_QUERY_WSL_EA`, `check_wsl_eas()` must verify `OutputBufferLength` in `[SMB2_WSL_MIN_QUERY_EA_RESP_SIZE, SMB2_WSL_MAX_QUERY_EA_RESP_SIZE]`, each EA fits in `rsp_iov`, and 4-byte-aligned `next_entry_offset` without overflow; `wsl_to_fattr()` must verify `S_DT` of `$LXMOD` matches `S_DT(fattr->cf_mode)` and require `$LXDEV` on `IO_REPARSE_TAG_LX_CHR`/`BLK`. [F425, F426, F427]
- When `cifs_query_path_info()` (`smb1ops.c`) sees `ATTR_REPARSE`, it queries `$LXMOD` and `$LXDEV` via `CIFSSMBQAllEAs()`, chains entries in `data->wsl.eas` with 4-byte-aligned `next_entry_offset`, and updates `data->wsl.eas_len`; non-negative returns not equal to expected WSL EA size map to `-EINVAL`, while negative errnos reset to `rc = 0`. [F398, F413]
- `reparse_buf_ptr()` must verify `OutputOffset + OutputCount <= iov->iov_len` (no overflow) and `OutputCount >= sizeof(struct reparse_data_buffer) + le16_to_cpu(buf->ReparseDataLength)`. SMB1 (`cifs_get_reparse_point_buffer`) offsets `DataOffset` from `(__u8 *)&io->hdr.Protocol`, whereas SMB2 (`smb2_get_reparse_point_buffer`, `reparse_buf_ptr`) offsets `OutputOffset` from `(u8 *)io`. [F420, F479]
- `symlink_data()` and `smb2_parse_symlink_response()` must verify error contexts fit in `iov_len` (stepping by `ALIGN(ErrorDataLength, 8)`) and `SMB2_SYMLINK_STRUCT_SIZE` plus `sub_offs + sub_len` and `print_offs + print_len` fit within `iov->iov_len`. [F437]
- Reparse special-file creation requires `CIFS_REPARSE_SUPPORT(tcon)` (`tcon->posix_extensions` or `FILE_SUPPORTS_REPARSE_POINTS`), checked in `cifs_make_node()` after `tcon->unix_ext` and `CIFS_MOUNT_UNX_EMUL`. In `smb2_create_reparse_inode()`, if `CREATE` (`out_iov[0]`) succeeds with `STATUS_SUCCESS` but `SMB2_OP_SET_REPARSE` (`out_iov[1]`) fails, call `smb2_unlink()`. [F440, F506]
- `nxt_dir_entry()` must check pointer wraparound, `new_entry < end_of_smb`, and that the minimum entry struct + 1 byte fits before `end_of_smb`; `SMB_FIND_FILE_INFO_STANDARD` lacks `NextEntryOffset` and advances by `sizeof(FIND_FILE_STANDARD_INFO) + 1 + pfData->FileNameLength`. [F430, F482]
- When `cifs_prime_dcache()` updates an existing inode (`!d_in_lookup(dentry)`), if `!CIFS_MOUNT_SERVER_INUM` it must set `fattr->cf_uniqueid = CIFS_I(inode)->uniqueid` before comparing `uniqueid`, and if `reparse_inode_match()` succeeds it must preserve `i_mode`, `i_rdev`, `i_uid`, `i_gid`, and `remote_i_size` before `cifs_fattr_to_inode()`. [F406, F501]
- In `cifs_readdir()`, populating `cached_dirents` sets `cfid->dirents.pos = 2` at `ctx->pos == 0`, calls `add_cached_dirent()` before `ctx->pos++` and `update_cached_dirents_count()`, and sets `cde->is_valid = 1` only if `ctx->pos == cde->pos`; `cifs_dir_emit()` updates `total_dirents_bytes`, `total_dirents_entries`, and `cifs_dircache_bytes_used` by `sizeof(struct cached_dirent) + namelen + 1`. [F407, F451]
- In `cifs_try_adding_channels()` and `cifs_chan_update_iface()`, `last_iface->speed` divides `iface->speed` under `ses->iface_lock` only after checking `ses->iface_count != 0`. `cifs_try_adding_channels()` caps at `tries > 3 * ses->chan_max` and increments `iface->weight_fulfilled++` on `cifs_ses_add_channel()` failure; `cifs_chan_update_iface()` copies `iface->sockaddr` to `server->dstaddr` under `server->srv_lock` and updates `num_channels`/`weight_fulfilled` under `ses->iface_lock`. [F401, F453, F463]
- In `cifs_get_next_mid()`, `cur_mid` and `last_mid` must be `__u16` (skipping `0xffff` and `0`, stopping at `cur_mid == last_mid`, and reconnecting if `pending_mid_q` > 32768). In `coalesce_t2()`, `total_in_tgt` and `byte_count` must be `unsigned int` (not `__u16`) to check `> USHRT_MAX` before writing `DataCount` and `BCC`. [F454, F461, F462]

## Synchronization

- Session locks nest `ses->iface_lock` -> `ses->chan_lock`: drop `ses->chan_lock` before taking `ses->iface_lock` in `cifs_disable_secondary_channels()` (starting at `i = 1` and moving `iface`/`server` to locals first) and `cifs_chan_update_iface()` (re-verifying `cifs_ses_get_chan_index(ses, server) != CIFS_INVAL_CHAN_INDEX` after relocking). All `cifs_chan_*` helpers and `cifs_ses_get_chan_index()` require `ses->chan_lock`. [F364, F365, F368, F457]
- In `smb2_is_valid_lease_break()` and `smb2_is_valid_oplock_break()`, locks nest `cifs_tcp_ses_lock` -> `tcon->open_file_lock` -> `cfile->file_info_lock`: drop `file_info_lock` before `cifs_queue_oplock_break(cfile)`, and drop all spinlocks before `smb2_queue_pending_open_break()`. [F377]
- In `find_cifs_entry()`, hold `cfile->file_info_lock` while checking `dir_needs_close(cfile)` and setting `cfile->invalidHandle = true`, and drop it before `close_dir()`. In `cifs_readdir()`/`cifs_dir_emit()`, `cfid->dirents.de_mutex` protects `cfid->dirents`, and `close_cached_dir()` must precede `initiate_cifs_search()` or `find_cifs_entry()`. [F371, F372]
- `smb2_push_mandatory_locks()` requires the caller to hold `cinode->lock_sem`, whereas `smb2_unlock_range()` takes `cinode->lock_sem` for write internally, uses `list_for_each_entry_safe()` on `&cfile->llist->locks` (skipping `current->tgid != li->pid` unless `FL_FLOCK | FL_OFDLCK`), and stages non-cached locks on `tmp_llist` (restoring on `smb2_lockv()` error). Both must snapshot `server->maxBuf` into a local and check `>= sizeof(struct smb2_lock_element)` before dividing. [F373, F448, F493, F509]
- Hold `cifs_server_lock(server)` for `smb311_update_preauth_hash()`, when setting `session_key`/`sequence_number`/`session_estab` in `sess_establish_session()`, and in `send_nt_cancel()` while signing/sending `SMB_COM_NT_CANCEL` and decrementing `server->sequence_number` (twice if `smb_send()` fails). [F380, F415, F496]

## Object Lifetimes

- In `find_cifs_entry()`, freeing `ntwrk_buf_start` requires setting `ntwrk_buf_start`, `srch_entries_start`, and `last_entry` to `NULL`; check `query_dir_next()` and `initiate_cifs_search()` for error before `cifs_save_resume_key(cfile->srch_inf.last_entry, cfile)`. [F344, F345]
- In `cifs_prime_dcache()`, if `d_in_lookup(dentry)`, call `d_lookup_done(dentry)` after `d_splice_alias()`, `dput()` any non-error alias, and `dput(dentry)` on all exit/retry paths; if an existing positive dentry is `d_mountpoint(dentry)`, `dput(dentry)` and return without `d_invalidate()`. [F346, F498]
- Zero the source `kvec` and set buftype to `CIFS_NO_BUFFER` when moving a reparse response out of `rsp_iov[i + 1]` in `smb2_compound_op()` or `data.reparse.io` in `smb2_query_reparse_point()`. [F350]
- `smb2_queue_pending_open_break()` owns the caller's `tcon_link` and must `cifs_put_tlink()` on `kmalloc()` failure or in `cifs_ses_oplock_break()`. `__smb2_handle_cancelled_cmd()` callers must pin `tcon` (`tc_count > 0` under `cifs_tcp_ses_lock` or `smb2_find_smb_tcon()`) and `cifs_put_tcon()` on failure; when `tc_count <= 0` in `smb2_handle_cancelled_close()`, check `tcon->ses != NULL` before reading `tcon->ses->server`. [F354, F378, F381]
- `sess_data->iov[1]` is caller-owned (not freed by `sess_free_buffer()`). `sess_auth_rawntlmssp_negotiate()` must `kfree_sensitive()` and NULL `ses->ntlmssp` and `ses->auth_key.response` on error, or pass ownership to `sess_auth_rawntlmssp_authenticate()` to free and NULL. [F358, F359]
- Set `smb_target = NULL` when assigned to `linux_target` in `smb2_parse_native_symlink()`. Guard `kfree(p)` with `if (S_ISLNK(mode))` in `mknod_nfs()` (non-symlinks use stack `buf[sizeof(*p) + sizeof(__le64)]`). In `cifs_check_trans2()`, set `mid->large_buf = true` and `server->bigbuf = NULL` when assigning `mid->resp_buf`. In `smb_set_file_info()`, release `open_file` via `cifsFileInfo_put()` or close `fid.netfid` via `CIFSSMBClose()`. [F361, F362, F363, F474]

## API Contracts

- Non-NULL `out_iov`/`out_buftype` in `smb2_compound_op()` need `>= num_cmds + 2` elements and must be freed via `free_rsp_buf()`/`free_rsp_iov()`. Because `smb2_compound_op()` drops `cfile`, retry/fallback callers must re-fetch `cfile`. For `SMB2_OP_RENAME`/`HARDLINK`, `in_iov[i]` must be NUL-terminated UTF-16 with `iov_len` excluding the 2-byte NUL. [F349, F409, F477]
- `check_smb2_hdr()` and `smb2_check_message()` return `0` for valid and `1` on error. `check2ndT2()` returns `< 0` on error, `0` if complete/non-T2, and `> 0` for missing bytes; `coalesce_t2()` returns `< 0` on error, `1` for more responses, and `0` when complete. [F382, F397]
- `smb2_get_data_area_len()` zeroes `*off`/`*len` on entry and when out of `[1..4096]` / `[1..128K]`, returning `NULL` unless both `> 0`; non-zero `Status` with `StructureSize == SMB2_ERROR_STRUCTURE_SIZE2_LE` returns `NULL` unless `Status == STATUS_MORE_PROCESSING_REQUIRED`. [F383, F442]
- `cifs_filldir()` returns `1` when full (reset to `0` in `cifs_readdir()`); uncached `cifs_readdir()` must succeed in `initiate_cifs_search()` before `dir_emit_dots()`; `emit_cached_dirents()` must set `ctx->pos = dirent->pos` before `dir_emit()`. [F395, F497, F502]
- Call `cifs_autodisable_serverino(cifs_sb)` (do not clear `CIFS_MOUNT_SERVER_INUM` directly); check `tcon != NULL` in `cifs_get_srv_inum()`; return `-EOPNOTSUPP` on unhandled tags in `parse_reparse_point()`, and `false` in `cifs_reparse_point_to_fattr()` unless `ATTR_DIRECTORY` and name-surrogate/`IO_REPARSE_TAG_INTERNAL`; honor `CIFS_MOUNT_OVERR_UID`/`GID` in `wsl_make_kuid()`/`kgid()`; query existing timestamps via `cifs_query_path_info()` when `!CAP_NT_SMBS` and any timestamp is 0 in `smb_set_file_info()`. [F399, F400, F404, F444, F508]

## Error Handling

- In `cifs_ses_add_channel()`, reset `chan->server = NULL` if `cifs_get_tcp_session()` returns `ERR_PTR`; if failing after `ses->chan_count++`, call `cifs_put_tcp_session()` and `cifs_chan_clear_need_reconnect()` (under `ses->chan_lock`) before `ses->chan_count--`. [F357, F393]
- Save `compound_send_recv()` status in `tmp_rc` and restore `rc = tmp_rc` after the loop in `smb2_compound_op()`. Clear post-open resilience/inum errors to `rc = 0` in `smb2_open_file()`. Clear `NT_STATUS_MORE_PROCESSING_REQUIRED` to `rc = 0` in `sess_auth_rawntlmssp_negotiate()`. Reset `dentry = NULL`, `retries = 0`, `cur_sleep = 1` on `-EINVAL` lease fallback in `smb2_unlink()`. [F385, F389, F394, F450]

## External Contracts

- Set `ReparseDataLength` to total byte length minus `sizeof(struct reparse_data_buffer)` (8 bytes) in `create_native_symlink()`, `nfs_set_reparse_buf()`, and `wsl_set_reparse_buf()`. In `parse_reparse_wsl_symlink()`, verify `ReparseDataLength > 4`, `Version == cpu_to_le32(2)`, and no NULs in `Target`, and multiply signed `utf8s_to_utf16s()` by 2. Validate `IO_REPARSE_TAG_NFS` in `parse_reparse_nfs()` before `cifs_reparse_point_to_fattr()` (`ReparseDataLength >= 8`, +8 for `CHR`/`BLK`, +0 for `FIFO`/`SOCK`), and subtract 2 from `cifs_strndup_to_utf16()` length in `mknod_nfs()`. [F391, F421, F423, F469, F471, F511]
- In `smb2_file_full_ea_info`, value is at `&ea_data[ea_name_length + 1]`; allow/skip `vlen == 0` for known WSL EAs in `check_wsl_eas()`/`wsl_to_fattr()`; encode `$LXDEV` as `((u64)MINOR(_dev) << 32) | MAJOR(_dev)`. Fall back to `out_unhandled_target` on unknown NT symlink prefixes in `smb2_parse_native_symlink()`, and enforce trailing `'/'` rules in `smb2_fix_symlink_target_type()` when `!CIFS_MOUNT_POSIX_PATHS`. [F439, F445, F458, F475, F505]
- `smb311_update_preauth_hash()` hashes `SMB2_NEGOTIATE` unconditionally and `SMB2_SESSION_SETUP` responses only on `SMB311_PROT_ID` with `NT_STATUS_MORE_PROCESSING_REQUIRED`. `smb2_is_valid_oplock_break()` requires `StructureSize == 44` for lease breaks. `cifs_make_node()` (`unix_ext`) masks `~current_umask()` and checks `CIFS_MOUNT_SET_UID`. `sess_auth_kerberos()` checks `CIFS_SPNEGO_UPCALL_VERSION` and always calls `key_invalidate()` and `key_put()`. [F443, F486, F507, F510]

## Known Pitfalls

- Pass `cfile = NULL` in `smb2_set_file_info()` if any timestamp is non-zero. Check `offset + 1 < len` in `smb2_calc_size()`/`get_neg_ctxt_len()`. Set `retry_without_read_attributes` in `smb2_open_file()` only if no read/generic/max access bit is set. [F410, F429, F441]
- Mask `sym[0..2]`/`sym[5]` in `create_native_symlink()` and advance `__le16 *path` by `poff = 4` (`plen -= 2 * poff`); advance `abs_path` by `sizeof("GLOBALROOT") - 1` in `smb2_parse_native_symlink()`. Pass `len / 2` (even `len > 0`) to `UniStrnlen()` in `parse_reparse_nfs()`/`smb2_parse_native_symlink()`; subtract `nls_nullsize(nlt)` in `cifs_filldir()`; scale `cifs_strtoUTF16()` by `sizeof(__le16)` (+2 slack in `size_of_ntlmssp_blob()`); copy `DataLength` from `&cc->ea` in `mknod_wsl()`. [F438, F455, F470, F473, F476, F480, F485]
- Check `list_entry_is_head()` after `ses->iface_list` loops and reset `iface = NULL`. Traverse `smb_ses_list` on `SERVER_IS_CHAN(server) ? server->primary_server : server`. [F447, F456]
