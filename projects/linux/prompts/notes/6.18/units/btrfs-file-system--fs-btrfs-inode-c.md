# BTRFS FILE SYSTEM — fs/btrfs/inode.c

Implements core Btrfs VFS inode, directory, symlink, and `address_space` operations, including inode lifecycle, namespace mutations, buffered delalloc writeback (COW, NOCOW, async compressed), encoded I/O, truncation, and swapfile activation.

## Architecture & Data Flow

- In `struct btrfs_inode`: `->root` can be NULL during eviction/destruction and `->file_extent_tree` is NULL on NO_HOLES, non-regular, and free-space inodes (use `btrfs_inode_*_file_extent_range()`); `delalloc_bytes`, `new_delalloc_bytes`, and `csum_bytes` share unions with directory fields (`S_ISDIR`), and `defrag_bytes` with `reloc_block_group_start` (`btrfs_is_data_reloc_root`); atomic bitops (`set_bit`/`clear_bit`) must only target `runtime_flags`, while 32-bit `flags`/`ro_flags` use bitwise ops. [F561, F562, F631]
- On non-free-space inodes, `btrfs_{set,clear}_delalloc_extent()` sync `delalloc_bytes` with `root->delalloc_inodes`, `nr_delalloc_inodes`, and `fs_info->delalloc_roots` via `btrfs_{add,del}_delalloc_inode()`. Delalloc extent counts must use ceiling `count_max_extents(fs_info, size)` (not `/`), and `btrfs_{merge,split}_delalloc_extent()` on ranges `> max_extent_size` must only adjust `outstanding_extents` if combined `count_max_extents()` differs from the sum of parts. [F572, F618, F619]
- Before `fallback_to_cow()` calls `cow_file_range()`, count `EXTENT_NORESERVE` bytes in `io_tree` (or `range_bytes` for free-space/reloc inodes), add to `data_sinfo` `bytes_may_use`, and clear `EXTENT_NORESERVE`. In `can_nocow_file_extent()`, 64-bit `btrfs_file_extent_generation(leaf, fi)` must be strictly `>` `btrfs_root_last_snapshot(&root->root_item)`. [F569, F624]
- An `extent_map` pinned by `btrfs_create_io_em()` stays cached in `insert_reserved_file_extent()` (`drop_cache = false`) and is unpinned by `btrfs_unpin_extent_cache()` in `btrfs_finish_one_ordered()`, or dropped via `btrfs_drop_extent_map_range()` on setup failure, I/O error, or truncation. For non-truncated regular delalloc COW extents in `btrfs_finish_one_ordered()`, clear `EXTENT_DELALLOC_NEW | EXTENT_ADD_INODE_BYTES` before `btrfs_update_inode_fallback()`. Call `btrfs_inode_set_file_extent_range()` before `btrfs_inode_safe_disk_i_size_write()` when inserting extents/holes. [F571, F573, F576]
- `can_cow_file_range_inline()` requires `offset == 0`, `size <= sectorsize`, `data_len < sectorsize`, `data_len <= min(BTRFS_MAX_INLINE_DATA_SIZE, max_inline)`, and `size >= i_size_read()`. `btrfs_symlink()` requires `name_len < sectorsize` and stores `symname` inline without a NUL, relying on `read_inline_extent()` and `uncompress_inline()` clamping `ram_bytes` to `sectorsize` and zeroing `[max_size, blocksize)` via `folio_zero_range()`. [F588, F591, F628]
- In `inode_need_compress()` and `compress_file_range()`, check `inode->defrag_compress` before mount options, `BTRFS_INODE_NOCOMPRESS`, and `prop_compress`. In `compress_file_range()` and `btrfs_do_encoded_write()`, zero trailing sub-folio bytes past compressed payloads before submission, using `min_folio_shift` (`PAGE_SHIFT + block_min_order`) and `min_folio_size` (not `PAGE_SHIFT`/`PAGE_SIZE`). [F565, F603, F623]
- In `btrfs_invalidate_folio()`, sub-folio calls (`!(offset == 0 && length == folio_size(folio))`) must only call `btrfs_release_folio(folio, GFP_NOFS)` and return; full-folio truncation on an active ordered extent (`btrfs_folio_test_ordered`) must set `BTRFS_ORDERED_TRUNCATED` and update `truncated_len` under `ordered_tree_lock` while leaving `EXTENT_DELALLOC_NEW` set until `btrfs_finish_ordered_io()`. [F584, F651]
- `inode->dir_index` is non-zero only when `i_nlink == 1`; `btrfs_{link,rename,rename_exchange}()` must zero `dir_index` before inserting a new `btrfs_inode_ref` (restoring after `btrfs_add_link()` only if `i_nlink == 1`). In `btrfs_read_locked_inode()`, set `last_{unlink,reflink}_trans = last_trans`, and set `BTRFS_INODE_NEEDS_FULL_SYNC` if `last_trans == btrfs_get_fs_generation(fs_info)`. Zero new leaf `btrfs_inode_item` buffers with `memzero_extent_buffer()` before `fill_inode_item()`, and stack `btrfs_file_extent_item` with `memset()`. [F560, F577, F581]

## Synchronization

- `btrfs_{set,clear,split,merge}_delalloc_extent()` require `io_tree.lock` held and nest `inode->lock` or `root->delalloc_lock` (`-> delalloc_root_lock`) inside `io_tree.lock`. `btrfs_init_file_extent_tree()` sets `file_extent_tree_class` (`file_extent_tree->lock` nests inside `inode->lock`). Updates to `new_delalloc_bytes` and `inode_{add,sub}_bytes()` require `inode->lock`. [F570, F639, F640]
- In `btrfs_invalidate_folio()`, `folio_wait_writeback()` and `wait_subpage_spinlock()` must precede inspecting/clearing `Ordered` bits or `btrfs_dec_test_ordered_pending()`, and `wait_subpage_spinlock()` must precede `clear_folio_extent_mapped()` in both `__btrfs_release_folio()` and `btrfs_invalidate_folio()`. [F533, F534]
- `delayed_iput_lock` requires IRQs disabled (`spin_lock_irqsave()`/`spin_lock_irq()`), and `run_delayed_iput_locked()` unlocks before `iput()`. `evict_refill_and_join()` must use `BTRFS_RESERVE_FLUSH_EVICT` and `btrfs_join_transaction()` (never `btrfs_start_transaction()` or `FLUSH_ALL`). `btrfs_writepage_fixup_worker()` must call `btrfs_delalloc_reserve_space()` before `folio_lock()`, unlock before `btrfs_start_ordered_extent()`, and release the inode via `btrfs_add_delayed_iput()`. [F537, F538, F634, F635]
- When `cow_file_range()` stops early on zoned `-EAGAIN` (`start > orig_start`, `done_offset != NULL`), set `end = start - 1` and `ret = 0` before `extent_clear_unlock_delalloc()`. In `__btrfs_prealloc_file_range()`, call `btrfs_dec_block_group_reservations()` only after `insert_prealloc_file_extent()`. [F515, F587]
- Tree-log/snapshot locks: `btrfs_alloc_inode()` initializes `new_delalloc_bytes = 0`; in `btrfs_rmdir()`, if `inode->last_unlink_trans >= trans->transid`, call `btrfs_record_snapshot_destroy(trans, dir)` before unlinking; in `btrfs_rename_exchange()` and `btrfs_rename()`, for non-root inodes, pin log transactions on `root` and `dest` via `btrfs_pin_log_trans()` before unlinking and release via `btrfs_end_log_trans()` after `btrfs_log_new_name()`. [F529, F539, F540]
- In `btrfs_setsize()`, expanding truncates (`newsize > oldsize`) must hold `btrfs_drew_write_lock(&root->snapshot_lock)` across `btrfs_cont_expand()`, `btrfs_start_transaction()`, `i_size_write()`, and `btrfs_update_inode()`. In `btrfs_truncate()`, call `btrfs_end_transaction(trans)` before `btrfs_truncate_block()` on `BTRFS_NEED_TRUNCATE_BLOCK`. [F541, F653]
- In `btrfs_swap_activate()`, before locking `io_tree`, hold `i_mmap_lock`, start `BTRFS_EXCLOP_SWAP_ACTIVATE`, take `btrfs_drew_try_write_lock(&root->snapshot_lock)`, and under `root_item_lock` check `!btrfs_root_dead(root)` before `atomic_inc(&root->nr_swapfiles)`; call `btrfs_release_path(path)` before `btrfs_is_data_extent_shared()`. [F542, F658]
- In `btrfs_encoded_read()` and `btrfs_do_encoded_write()`, after `btrfs_wait_ordered_range()`, lock the extent and recheck `btrfs_lookup_ordered_range()` (plus `filemap_range_has_page()` in write), retrying if found. Encoded read paths must release `path`, `io_tree` lock, and `BTRFS_ILOCK_SHARED` (`*unlocked = true`) before `copy_to_iter()`/`copy_page_to_iter()`/`iov_iter_zero()`, and `btrfs_encoded_read()` transfers `[start, lockend]` and `BTRFS_ILOCK_SHARED` to the caller iff returning `-EIOCBQUEUED`. In `btrfs_encoded_read_endio()`, `WRITE_ONCE(priv->status)` before `refcount_dec_and_test(&priv->pending_refs)`, and `READ_ONCE()` only after `pending_refs == 0` or `wait_for_completion_io()`. [F527, F543, F545, F642]
- In `start_delalloc_inodes()` and `btrfs_start_delalloc_roots()`, hold `delalloc_{root_}mutex`, splice under `delalloc_{root_}lock`, pin with `igrab()`/`btrfs_grab_root()` before dropping the spinlock, and restore unvisited entries on exit. `btrfs_add_inode_to_root(inode, false)` requires a prior `xa_reserve(&root->inodes, objectid, GFP_NOFS)` (and `xa_release()` on early error); `btrfs_del_inode_from_root()` must use `__xa_cmpxchg(..., inode, NULL, GFP_ATOMIC)` under `root->inodes` lock; `btrfs_destroy_cachep()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F544, F580, F643, F646]

## Object Lifetimes

- When `btrfs_iget_locked()` returns `I_NEW`, `btrfs_read_locked_inode()` calls `iget_failed()` on error, so callers call `iget_failed()` only if aborting before it and never release again after it fails. `btrfs_create_new_inode()` keeps the caller's ref on `args->inode` on failure (`ihold()` before `discard_new_inode()` if hashed), so callers must `iput()` on error (nulling their pointer if released early). Both must call `btrfs_init_file_extent_tree()` only after `vfs_inode.i_mode` is set. [F511, F512, F521]
- In `run_delalloc_compressed()`, pass `locked_folio` only to `async_chunk[0]`; each chunk takes `ihold()`, optional `css_get()`, and `ctx->num_chunks` ref released in `submit_compressed_extents(..., true)` (`btrfs_add_delayed_iput()`, `css_put()`, `atomic_dec_and_test()`). In `submit_one_async_extent()`, `btrfs_submit_compressed_write(..., true)` owns `async_extent->folios`, whereas `submit_uncompressed_range()` fallback or `out_free_reserve` must call `free_async_extent_pages()` before `kfree(async_extent)`. [F513, F520]
- `can_nocow_file_extent()` may release `path` (`nodes[0] == NULL`); when `args->free_path` is true it calls `btrfs_free_path(path)` (callers with `BTRFS_PATH_AUTO_FREE(path)` must set `path = NULL`), whereas callers keeping `path` (`run_delalloc_nocow()`) must check `path->nodes[0]` before advancing `slots[0]` and re-search if NULL. [F519, F578]
- In `btrfs_finish_one_ordered()`, non-NOCOW extents must lock `io_tree` before joining a transaction; on error or `!logical_len` before `insert_ordered_extent_file_extent()` on a COW extent, `out:` must free the reserved disk extent and `qgroup_rsv` before removing and double-putting `ordered_extent`. [F524]
- In `btrfs_swap_activate()`, errors after `atomic_inc(&root->nr_swapfiles)` must jump to `out:` (free `map`, unlock `io_tree`, `btrfs_swap_deactivate()`, unlock `snapshot_lock`, finish exclop, `up_write(&i_mmap_lock)`), and `btrfs_put_block_group(bg)` must be called if `btrfs_add_swapfile_pin()` returns `1` or `< 0`. In `btrfs_free_swapfile_pins()`, advance `next = rb_next(node)` before `rb_erase()` and `kfree(sp)`. [F526, F609]
- During eviction (`I_FREEING`), `evict_inode_truncate_pages()` drains `io_tree->state` by copying `start`, `end`, and `state_flags` from `rb_first()` before dropping `io_tree->lock` (never dereferencing `state` after unlock) and calling `btrfs_qgroup_free_data()` for `EXTENT_DELALLOC`. In `btrfs_encoded_read_regular_fill_pages()`, stack `sync_priv` is valid only when `uring_ctx == NULL` (waiting on `sync_reads`); when non-NULL, heap-allocate `priv` and free when `pending_refs == 0`. [F528, F608, F629]

## API Contracts

- `__cow_file_range_inline()` (requires `can_cow_file_range_inline()` first) and `cow_file_range_inline()` return `0` (inserted), `1` (fallback to regular), or `< 0` (error); `cow_file_range_inline()` must set `locked_folio = NULL` before `extent_clear_unlock_delalloc()` when `ret == 0` and keep it non-NULL when `ret < 0`. [F516, F550, F589]
- `btrfs_cleanup_ordered_extents()` takes byte `@bytes` (not inclusive `@end` like `extent_clear_unlock_delalloc()`). `btrfs_create_io_em()` takes an unshifted `BTRFS_ORDERED_{REGULAR,PREALLOC,COMPRESSED}` enum (never `NOCOW`), whereas `btrfs_alloc_ordered_extent()` takes `1U << BTRFS_ORDERED_*`. [F546, F549, F605]
- `btrfs_lookup_{inode,file_extent}()` and `btrfs_search_slot()` return `> 0` when not found (convert to `< 0` errno on error paths). `btrfs_iget_locked()` returns NULL on failure, whereas `btrfs_iget{_path}()` return `ERR_PTR`. [F556, F558]
- `btrfs_inode_unlock()` requires the exact `ilock_flags` passed to `btrfs_inode_lock()`, and `BTRFS_ILOCK_TRY | BTRFS_ILOCK_MMAP` must never be combined. `btrfs_item_ptr()` returns leaf offsets (use `extent_buffer`/`btrfs_*` helpers, never direct dereference/`memcpy`), and inline extent offsets/sizes must use `btrfs_file_extent_inline_start()` and `btrfs_file_extent_calc_inline_size()`. `btrfs_create_new_inode()` must call `btrfs_set_inode_mapping_order()` for all inodes before `btrfs_insert_inode_locked()`. `btrfs_tmpfile()` must call `set_nlink(inode, 1)` before `d_tmpfile()`. `btrfs_calculate_block_csum()` must check `folio_test_partial_kmap(folio)` and hash page-by-page via `kmap_local_folio()` when true. [F566, F604, F626, F630, F647, F654, F663]

## Error Handling

- On delalloc error after ordered extents exist (`cow_file_range()`, `nocow_one_range()`, `run_delalloc_nocow()`), never pass `EXTENT_DO_ACCOUNTING` or `EXTENT_CLEAR_META_RESV` to `extent_clear_unlock_delalloc()` for ordered ranges: `cow_file_range()` splits `out_unlock` into `[orig_start, start - 1]` (ordered), `[start, start + cur_alloc_size - 1]` (`CLEAR_META_RESV` only), and `[start + cur_alloc_size, end]` (with `CLEAR_DATA_RESV`), advancing `start += cur_alloc_size` and `cur_alloc_size = 0` if `btrfs_reloc_clone_csums()` fails; `run_delalloc_nocow()` resets `cow_start = (u64)-1` after `fallback_to_cow()` succeeds and sets `cow_end`/`nocow_end` to the failed subrange end before `goto error`. [F517, F518, F567, F611]
- Rollbacks: in `btrfs_truncate_block()`, when `only_release_metadata == true`, call `btrfs_delalloc_release_metadata()` (not `release_space`) and `btrfs_check_nocow_unlock()` at `out:`; in `insert_prealloc_file_extent()`, jump to `free_qgroup` on error after `btrfs_qgroup_release_data()`; in `btrfs_delete_subvolume()`, zero `qgroup_reserved` after `btrfs_qgroup_convert_reserved_meta()` (or free if `start_transaction` fails), detach `trans->block_rsv` before `end_transaction`, and clear `BTRFS_ROOT_SUBVOL_DEAD`; in `btrfs_do_encoded_write()`, skip `btrfs_free_reserved_data_space_noquota()` once `extent_reserved == true`, and jump to `out_delalloc_release` with `extent_reserved == false` when `__cow_file_range_inline()` returns `<= 0`. [F514, F522, F523, F525]
- Reset `trans = NULL` on `IS_ERR(trans)` before cleanup labels testing `if (trans) btrfs_end_transaction(trans)`, and capture `btrfs_end_transaction()` in `ret2` so earlier `ret` errors are preserved. In `btrfs_setsize()`, if shrinking `btrfs_truncate()` fails with `i_nlink > 0`, call `btrfs_wait_ordered_range()` and restore `i_size` to `disk_i_size`. On `btrfs_alloc_extent_map()` failure after btree update in `btrfs_cont_expand()` or `__btrfs_prealloc_file_range()`, call both `btrfs_drop_extent_map_range()` and `btrfs_set_inode_full_sync()`. [F555, F563, F574, F575]
- In `btrfs_writepage_fixup_worker()`, check `!folio->mapping || !folio_test_dirty() || !folio_test_checked()` after locking `folio` before checking `ret` from `btrfs_delalloc_reserve_space()` (releasing space if `!ret` and setting `ret = 0`). Validate on-disk items: `btrfs_lookup_dentry()`/`btrfs_inode_by_name()` reject `len > BTRFS_NAME_LEN` (`-ENAMETOOLONG`) and invalid `DIR_ITEM` key types or `btrfs_inode_type(inode) != di_type` (`-EUCLEAN`); `btrfs_get_extent()` rejects `REG`/`PREALLOC` on `!S_ISREG` (`-EUCLEAN`) and `!(em->start <= start && btrfs_extent_map_end(em) > start)` (`-EIO`). [F582, F595, F596]

## Known Pitfalls

- In `btrfs_real_readdir()`, access `dir_entry` via `get_unaligned()`/`put_unaligned()`, release `path` before `btrfs_filldir()` and restart at `again:` with `key.offset = ctx->pos` when `filldir_buf` fills, and cap EOF `ctx->pos` to `INT_MAX` when `< INT_MAX` (`LLONG_MAX` otherwise). [F579, F593, F662]
- In `btrfs_truncate_block()`, call `set_folio_extent_mapped(folio)` and clear `EXTENT_DELALLOC | EXTENT_DO_ACCOUNTING | EXTENT_DEFRAG` before `btrfs_set_extent_delalloc()`, and clamp `zero_end` against inclusive `folio_end(folio) - 1` or `block_end` (never `end + 1`, as `end` can be `(u64)-1`). In `insert_reserved_file_extent()`, when `file_pos == 0` and `bytes_found` is unaligned to `sectorsize`, account the dropped inline extent via `btrfs_update_inode_bytes(inode, sectorsize, inline_size)` and subtract `inline_size` and `sectorsize`. In `btrfs_rename_exchange()`, allocate `old_idx` from `new_dir` (for `old_inode` in `dest`) and `new_idx` from `old_dir` (for `new_inode` in `root`). [F583, F592, F617, F622]
