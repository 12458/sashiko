# QCOM AUDIO (ASoC) DRIVERS — sound/soc/codecs (part 2)

Qualcomm ASoC codec drivers for WCD9340/WCD9341 (SLIMbus/MFD), WCD9370/WCD9375 (SoundWire), and WCD9380/WCD9385 SoundWire slave transport, covering DAI operations, clock gates, SoundWire port/stream management, interrupt domains, impedance measurement, and DAPM routing.

## Architecture & Data Flow

- `wcd934x_codec_probe` must copy `wcd934x_rx_chs`/`wcd934x_tx_chs` into `wcd->rx_chs`/`wcd->tx_chs`, and `wcd934x_set_channel_map` must call `INIT_LIST_HEAD` on their `.list` nodes. `slim_rx_mux_put` and `slim_tx_mixer_put` must use `list_del_init()` (not `list_del()`) when removing from `wcd->dai[...].slim_ch_list`, and check `list_empty()` and unchanged control value before adding. [F136, F170]
- In `wcd934x.c`, `wcd934x_rx_chs` stores `.port = p + WCD934X_RX_START` (16..28) and `.shift = p` (0..12); indexing RX arrays (`wcd->rx_chs`, `wcd->rx_port_value`) or `WCD934X_SLIM_PGD_PORT_INT_EN0` must subtract `WCD934X_RX_START` from `ch->port`. [F187]
- In `wcd9370_probe` and `wcd9380_probe`, the highest bit in `pdev->prop.source_ports` and `sink_ports` must not exceed `WCD937X_MAX_SWR_PORTS - 1` or `WCD938X_MAX_SWR_PORTS - 1`, as `GENMASK` is inclusive and indexes 0-based `wcd937x_dpn_prop`/`wcd938x_dpn_prop`. [F184]
- `wcd937x_connect_port` must update `wcd->port_config[port_idx - 1].ch_mask` and `wcd->master_channel_map[sdev->m_port_map[port_num]]` in lockstep, and `wcd937x_set_compander` must call `wcd937x_connect_port` when `comp1_enable` or `comp2_enable` changes. `wcd937x_sdw_hw_params` and `wcd938x_sdw_hw_params` must reset `wcd->sconfig.ch_count = 1` and `wcd->active_ports = 0` before compacting non-zero `wcd->port_config` entries into the local array passed to `sdw_stream_add_slave`. [F167, F168]
- In `wcd934x_micbias_control` and `wcd937x_micbias_control`, the `ANA_MICBn` enable field (`0xc0`) must only be set to pull-up (`BIT(7)`) when `micb_ref[i] == 0 && pullup_ref[i] > 0`, and cleared to 0 only when both counters are 0 under `micb_lock`. In `wcd934x_mbhc_micb_adjust_voltage` and `wcd937x_mbhc_micb_adjust_voltage`, changing VOUT while `micb_en == MICB_ENABLE` must temporarily set the enable field to `MICB_PULL_UP` before writing VOUT, then restore `MICB_ENABLE` and wait 2 ms. [F174, F175]
- `wcd934x_wcd_mbhc_calc_impedance` and `wcd937x_wcd_mbhc_calc_impedance` must save `ANA_MBHC_BTN5..BTN7`, `MBHC_CTL_CLK`, `MBHC_NEW_ZDET_ANA_CTL`, and `ANA_MBHC_ELECT` `FSM_EN` before zdet ramps, and every exit path must jump to `zdet_complete` to restore them and `ANA_MBHC_MECH`. If the left-channel ramp yields floating impedance (`ZDET_FLOATING_IMPEDANCE` or `> ZDET_VAL_100K`), `zdet_param_ptr` and `d1` must be reset to `&zdet_param[1]` and `d1_a[1]` before the right-channel ramp. [F176, F196]
- In `wcd934x_mbhc_get_result_params` and `wcd937x_mbhc_get_result_params`, `denom = (x1 * d1) - (1 << (14 - noff))` must be evaluated as signed 32-bit and checked for `denom > 0` before dividing `WCD934X_MBHC_ZDET_CONST * 1000` or `WCD937X_MBHC_ZDET_CONST * 1000` by `denom`. [F200]
- In `wcd937x_mbhc_moisture_config` and `wcd937x_mbhc_get_moisture_status`, if `!wcd937x->mbhc_cfg.hphl_swh` or `moist_rref == R_OFF`, `WCD937X_M_RTH_CTL_MASK` in `WCD937X_MBHC_NEW_CTL_2` must be set to `R_OFF` and moisture detection must not be enabled. [F180]
- In `wcd934x.c`, `wcd934x_int_dem_inp_mux_put` must update `WCD934X_RX_DLY_ZN_EN_MASK` in `WCD934X_CDC_RX{0,1,2}_RX_PATH_CFG0` in lockstep with `RX_PATH_SEC0`, and `wcd934x_codec_hphl_dac_event`/`hphr_dac_event` require `SEC0 & 0x03 == 0x01` when `hph_mode` is Class-H. In `wcd934x_compander_set`, toggling `wcd->comp_enabled[COMPANDER_1/2]` must update `WCD934X_HPH_GAIN_SRC_SEL_MASK` in `WCD934X_HPH_L_EN`/`HPH_R_EN`, and `wcd934x_config_compander` must gate setup on `wcd->comp_enabled[interp_n - 1]`. [F178, F181]
- In `wcd934x_dec_enum_put`, changing an ADC mux in `WCD934X_CDC_TX_INP_MUX_ADC_MUX{0..3}_CFG1` must update `BIT(7)` of the paired decimator's `WCD934X_CDC_TX{0..8}_TX_PATH_CFG0` (1 for DMIC when `val == 0`, 0 for AMIC otherwise) before calling `snd_soc_dapm_put_enum_double`. In `wcd934x_set_prim_interpolator_rate` and `wcd934x_set_mix_interpolator_rate`, loops over `0..WCD934X_NUM_INTERPOLATORS - 1` must skip `INTERP_LO3_NA` and `INTERP_LO4_NA`. [F179, F194]
- In `wcd934x_put_iir_band_audio_mixer` and `wcd934x_get_iir_band_audio_mixer`, `ctl->bytes_ext.max` (`WCD_IIR_FILTER_SIZE` in `WCD_IIR_FILTER_CTL`) must not exceed `sizeof(u32) * BAND_MAX` because `memcpy` uses stack buffer `u32 coeff[BAND_MAX]`. [F205]
- In `wcd937x_soc_codec_probe`, PDM watchdog IRQs (`hphr_pdm_wd_int`, `hphl_pdm_wd_int`, `aux_pdm_wd_int`) must be disabled with `disable_irq_nosync` right after `devm_request_threaded_irq` so `enable_irq` in `POST_PMU` and `disable_irq_nosync` in `PRE_PMD` stay balanced. In `wcd937x_codec_enable_ear_pa`, `wcd937x->ear_rx_path` must be latched from `WCD937X_DIGITAL_CDC_EAR_PATH_CTL` in `PRE_PMU` and used across `POST_PMU`, `PRE_PMD`, and `POST_PMD` to select between `aux_pdm_wd_int`/`PDM_WD_CTL2` and `hphl_pdm_wd_int`/`PDM_WD_CTL0`. [F197, F217]

## Synchronization

- All updates to `micb_ref`, `pullup_ref`, and `ANA_MICB*` enable/voltage fields in `wcd934x_micbias_control`, `wcd934x_mbhc_micb_adjust_voltage`, `wcd937x_micbias_control`, and `wcd937x_mbhc_micb_adjust_voltage` must hold `micb_lock`. Because `wcd934x_micbias_control` and `wcd937x_micbias_control` call `wcd_mbhc_event_notify` under `micb_lock`, any `wcd_mbhc_cb` callback reachable from `wcd_mbhc_event_notify` (such as `micbias_enable_status`) must never acquire `micb_lock`. [F146, F230]
- In `wcd934x.c`, `wcd->sysclk_mutex` must only guard the `wcd->sysclk_users` update inside `wcd934x_enable_ana_bias_and_sysclk` and `wcd934x_disable_ana_bias_and_syclk` and must never nest with `wcd->micb_lock`. `__wcd934x_cdc_mclk_enable(wcd, false)` must not disable sysclk or `wcd->extclk` while `WCD934X_CDC_SWR_CLK_EN_MASK` is set in `WCD934X_CDC_CLK_RST_CTRL_SWR_CONTROL`, and `wcd934x_swrm_clock(wcd, false)` must clear `WCD934X_CDC_SWR_CLK_EN_MASK` before calling `__wcd934x_cdc_mclk_enable(wcd, false)`. [F148, F231]
- In `wcd934x.c`, `swclk_gate_enable` and `swclk_gate_disable` must be wired to `.prepare`/`.unprepare` in `swclk_gate_ops`, never `.enable`/`.disable` (atomic context), because `wcd934x_swrm_clock` locks `wcd->sysclk_mutex`, sleeps, and performs SLIMbus regmap I/O. [F227]
- In `wcd937x_bind`, `wcd937x->regmap`, `wcd937x->virq` (via `wcd937x_irq_init`), and `sdw_priv[AIF1_PB/AIF1_CAP]->slave_irq` must be initialized before calling `snd_soc_register_component`. [F149]

## Object Lifetimes

- In `wcd934x_codec_parse_data`, `wcd->sidev` from `of_slim_get_device` must be released with `put_device(&wcd->sidev->dev)` if `devm_regmap_init_slimbus` fails, and otherwise registered with `devm_add_action_or_reset(..., wcd934x_put_device_action, ...)` in `wcd934x_codec_probe`. [F130]
- In `wcd934x_trigger`, `SNDRV_PCM_TRIGGER_STOP`, `SUSPEND`, and `PAUSE_PUSH` must call `slim_stream_disable(dai_data->sruntime)` before `slim_stream_unprepare(dai_data->sruntime)`. [F132]
- In `wcd937x-sdw.c`, `wcd_sdw_component_ops` enables/disables runtime PM on bind/unbind, so `wcd9370_probe` must not call `pm_runtime_enable` (only `pm_runtime_set_suspended` after `component_add`) and `wcd9370_remove` must only call `component_del`. In `wcd938x-sdw.c`, `wcd9380_probe` enables runtime PM and autosuspend before `component_add`, so both its error path and `wcd9380_remove` (after `component_del`) must call `pm_runtime_disable`, `pm_runtime_set_suspended`, and `pm_runtime_dont_use_autosuspend`. [F212, F213]
- In `wcd937x_bind`, stateless PM runtime links (`DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME`) must make `wcd937x->txdev` (which hosts `wcd937x->regmap`) a supplier to `wcd937x->rxdev` and `dev` (and `rxdev` a supplier to `dev`), and `wcd937x_unbind` must call `device_link_remove` on all three before `component_unbind_all`. [F214]
- `wcd937x_soc_codec_probe` must wait on `tx_sdw_dev->initialization_complete` and call `pm_runtime_resume_and_get(dev)` before reading `WCD937X_DIGITAL_EFUSE_REG_0` or calling `wcd937x_io_init`, balancing it with `pm_runtime_put(dev)` on all paths. In `wcd937x_probe`, `wcd937x_supplies` uses `devm_regulator_bulk_get_enable`, so error paths and `wcd937x_remove` must not call `regulator_bulk_disable` or `regulator_bulk_free`. [F215, F219]

## API Contracts

- In `wcd934x.c`, `pdev->dev`/`component->dev` driver data is `struct wcd934x_codec *`, while `dev->parent` driver data is `struct wcd934x_ddata *`. In `wcd937x.c` and `wcd937x-sdw.c`, `component->dev`/`dai->dev` driver data is `struct wcd937x_priv *`, while SoundWire slave devices (`rxdev`, `txdev`, `&slave->dev`) store `struct wcd937x_sdw_priv *` (indexed from a DAI via `wcd937x->sdw_priv[dai->id]`). [F207, F208]
- In `wcd9370_probe` and `wcd9380_probe`, only the TX slave (`wcd->is_tx`) initializes `wcd->regmap` and must immediately call `regcache_cache_only(wcd->regmap, true)` until `wcd_update_status` syncs on `SDW_SLAVE_ATTACHED`. In `wcd937x_sdw_runtime_suspend`/`resume` and `wcd938x_sdw_runtime_suspend`/`resume`, when `wcd->regmap` is non-NULL, suspend must set cache-only and `regcache_mark_dirty`, and resume must clear cache-only and `regcache_sync`. [F210, F211]
- In `wcd937x_get_channel_map` and `wcd934x_get_channel_map`, playback DAIs (`AIF1_PB..AIF4_PB`) must only touch `rx_slot`/`rx_num` and capture DAIs (`AIF1_CAP..AIF3_CAP`) must only touch `tx_slot`/`tx_num` (other direction pointers may be NULL). `wcd934x_set_channel_map` must reject `tx_num > WCD934X_TX_MAX || rx_num > WCD934X_RX_MAX` or NULL slot pointers. [F160, F189]
- In `wcd9370_probe` and `wcd9380_probe`, DT port mappings (`qcom,tx/rx-port-mapping`) must be read into `&pdev->m_port_map[1]`, and `wcd937x_connect_port` indexes `wcd->port_config[port_idx - 1]` and `sdev->m_port_map[port_num]`. In `wcd9370_probe`, 1-based DT channel mappings (`qcom,tx/rx-channel-mapping`) must be converted via `WCD937X_SWRM_CH_MASK` (`BIT(ch_idx - 1)`) before storing into `wcd->ch_info[i].master_ch_mask`. [F236, F237]
- Every `SOC_SINGLE_EXT` control using `wcd937x_set_compander`, `wcd937x_get_swr_port`, or `wcd937x_set_swr_port` must set `xreg` (`mc->reg`) to a `wcd937x_rx_sdw_channels` or `wcd937x_tx_sdw_channels` enum (never `SND_SOC_NOPM`). DAPM micbias widgets using `wcd934x_micbias_control` or `wcd937x_micbias_control` must store a 1-based `MIC_BIAS_*` constant in `w->shift` (since `micb_index = micb_num - 1`). [F183, F186]
- DAPM widgets using `wcd934x_codec_enable_dmic` must have a name whose first digit in `"012345"` starts a DMIC index (0..5), and widgets using `wcd934x_codec_enable_dec` must have a space-separated name (`<= 15` chars) whose second token's first digit in `"012345678"` starts a decimator index (0..8). [F165]
- `wcd937x_mbhc_zdet_ramp` and `wcd934x_mbhc_zdet_ramp` accept nullable `zl`/`zr` and must initialize local `zdet = 0` before calling `*_mbhc_get_result_params` (which leaves `*zdet` unchanged on ramp error). Callers of `wcd934x_wcd_mbhc_qfuse_cal` and `wcd937x_wcd_mbhc_qfuse_cal` must divide ramp impedance by 1000 (milliohms to ohms) before passing `z_val`. [F158, F201]
- In `wcd937x_soc_codec_probe`, `wcd9375_dapm_widgets` and `wcd9375_audio_map` must only be registered when `WCD937X_DIGITAL_EFUSE_REG_0` is `CHIPID_WCD9375`, and any error after `wcd_clsh_ctrl_alloc` must call `wcd_clsh_ctrl_free(wcd937x->clsh_info)`. [F216]
- `wcd_irq_chip_map` in `wcd937x.c` must call `irq_set_nested_thread(virq, 1)` on `wcd->virq` so `wcd9370_interrupt_callback` and `wcd9380_interrupt_callback` can invoke `handle_nested_irq` from the SoundWire IRQ thread. Cross-module SoundWire helpers (`wcd937x_sdw_hw_params`, `wcd938x_sdw_hw_params`, `wcd938x_sdw_free`, `wcd938x_sdw_set_sdw_stream`) require `EXPORT_SYMBOL_GPL` and `-EOPNOTSUPP` header stubs when `CONFIG_SND_SOC_WCD937X_SDW` / `WCD938X_SDW` is disabled. [F228, F240]

## Error Handling

- In `wcd934x_mbhc_init`, if `wcd_mbhc_init` returns an `ERR_PTR`, `wcd->mbhc` must be reset to NULL because `wcd934x_comp_probe` ignores the failure and callers (`wcd934x_codec_set_jack`, `wcd934x_mbhc_deinit`, `wcd_mbhc_event_notify`) only check for NULL. [F153]
- If `wcd934x_slim_set_hw_params` fails after allocating `cfg->chs`, it must both `kfree(cfg->chs)` and set `cfg->chs = NULL` to avoid double-free in `wcd934x_hw_free`. `wcd934x_get_dmic_clk_val` must check `dmic_clk_rate != 0` before dividing `mclk_rate / dmic_clk_rate`. [F157, F202]

## Known Pitfalls

- In `wcd937x.c`, unshifted field constants (`WCD937X_MICB_ENABLE`, `WCD937X_MICB_PULL_UP`, `zdet_param->ldo_ctl`) must use `snd_soc_component_write_field()`, whereas pre-shifted values (`BIT(6)`, `BIT(7)`, `zdet_param->btn5/6/7`) must use `snd_soc_component_update_bits()`. [F163]
- In `wcd934x_get_dmic_sample_rate`, any `continue` path inside `while (!dec_found && adc_mux_index < WCD934X_MAX_VALID_ADC_MUX)` must increment `adc_mux_index`. In `wcd937x_mbhc_get_result_params`, both polls on `WCD937X_ANA_MBHC_RESULT_1`/`RESULT_2` must be bounded by `WCD937X_ZDET_NUM_MEASUREMENTS` (900), and `WCD937X_ANA_MBHC_ZDET` bit `0x20` must be cleared after reading. [F193, F226]
- In `wcd937x_reset`, `gpiod_set_value(wcd937x->reset_gpio, 1)` must be followed after 20–30 us by `gpiod_set_value(wcd937x->reset_gpio, 0)` and another 20–30 us delay. In `wcd934x_comp_init`, `wcd934x_enable_efuse_sensing` must run before `wcd934x_get_version`, enabling MCLK, setting `WCD934X_EFUSE_SENSE_EN_MASK`, sleeping 5 ms, checking `WCD934X_CHIP_TIER_CTRL_EFUSE_STATUS` bit 0, and disabling MCLK. [F218, F223]
- Because `WCD934X_CDC_SIDETONE_IIR0_IIR_COEF_B1_CTL` auto-increments on `B2_CTL` writes but not reads, `get_iir_band_coeff` must write each byte offset (`& 0x7F`) to `B1_CTL` before each byte read from `B2_CTL`, while `set_iir_band_coeff` masks the 4th `B2_CTL` byte with `0x3F`. [F224]
