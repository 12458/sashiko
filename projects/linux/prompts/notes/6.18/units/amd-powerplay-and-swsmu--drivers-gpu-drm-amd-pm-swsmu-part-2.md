# AMD POWERPLAY AND SWSMU — drivers/gpu/drm/amd/pm/swsmu (part 2)

This unit provides common SMU communication helpers (`smu_cmn.c`), internal macro dispatchers (`smu_internal.h`), and the SMU v14.0 backend (`smu_v14_0.c`, `smu_v14_0_0_ppt.c`, `smu_v14_0_2_ppt.c`) for AMD GPUs and APUs, managing firmware loading, C2PMSG mailbox transactions, DRAM table transfers, DPM/OverDrive configuration, I2C transfers, and thermal/MP1 interrupts.

## Architecture & Data Flow
- In `__smu_cmn_send_msg()`, write `resp_reg = 0`, `param_reg = param`, then `msg_reg = msg` (writing `msg_reg` triggers PMFW; `__smu_cmn_poll_stat()` waits for `resp_reg != 0`). In `smu_cmn_send_smc_msg_with_param()` and `smu_cmn_send_msg_without_waiting()`, skip pre-send polling on `SMU_FW_INIT -> SMU_FW_RUNTIME` or when `__smu_cmn_ras_filter_msg()` sees `resp_reg == 0` for a priority/RAS message (`SMU_FW_CAP_RAS_PRI` with `amdgpu_ras_get_fed_status(adev)`, which also rejects non-`SMU_MSG_RAS_PRI` messages with `-EACCES`); when polling runs, abort only on `reg == SMU_RESP_NONE` or `res == -EREMOTEIO`. [F80, F105, F109]
- `smu_v14_0_0_set_ppt_funcs()` and `smu_v14_0_0_init_smc_tables()` leave `clock_map`, `pwr_src_map`, `workload_map`, and `smu_dpm.dpm_context` NULL on APU SMU v14.0.0, so `smu_v14_0_0_ppt_funcs` cannot use `smu_v14_0.c` helpers that dereference `dpm_context` (`smu_v14_0_set_performance_level()`) or require `CMN2ASIC_MAPPING_CLK` (`smu_v14_0_set_soft_freq_limited_range()`, `smu_v14_0_get_dpm_ultimate_freq()`). [F33]
- In `smu_v14_0_0_ppt.c`, `smu_table.clocks_table` holds `DpmClocks_t_v14_0_1` on `IP_VERSION(14, 0, 1)` and `DpmClocks_t` otherwise (allocate with `max(sizeof(DpmClocks_t), sizeof(DpmClocks_t_v14_0_1))` and branch on IP version before casting); in both, `MemPstateTable` is ordered highest-to-lowest (`0 .. NumMemPstatesEnabled - 1`), so `SMU_MCLK`/`SMU_UCLK` queries use `0` for max, `NumMemPstatesEnabled - 1` for min, and `count - i - 1` when printing ascending levels. [F66, F67]
- In `smu_v14_0_common_set_performance_level()` and `smu_v14_0_od_edit_dpm_table()`, `gfx_actual_hard_min_freq` and `gfx_actual_soft_max_freq` track active/staged SCLK limits and must be zeroed when `smu_v14_0_common_set_fine_grain_gfx_freq_parameters()` reinitializes defaults. In `smu_v14_0_set_single_dpm_table()` and `smu_v14_0_2_set_default_dpm_table()`, `dpm_table->min`/`max` must match `dpm_levels[0].value`/`dpm_levels[count - 1].value` (including after capping top GFX level to `GameClockAc`). When `single_dpm_table->is_fine_grained` is true, `dpm_levels` only populates indices `0` and `1`, so `smu_v14_0_2_force_clk_levels()` must clamp user indices `>= 1` to `1`. [F47, F48, F68]
- In `smu_v14_0_2_od_edit_dpm_table()`, `smu_v14_0_2_restore_user_od_settings()`, and `smu_v14_0_2_set_default_od_settings()`: save/restore `OverDriveTable.FeatureCtrlMask` across `PP_OD_RESTORE_DEFAULT_TABLE` copies from `boot_overdrive_table` (which falls through to `PP_OD_COMMIT_DPM_TABLE`, unlike `smu_v14_0_od_edit_dpm_table()`), skip `FeatureCtrlMask` via `offset_of_voltageoffset` (cast typed `OverDriveTableExternal_t *` to `(u8 *)`/`(void *)` first) when updating `user_overdrive_table`, and zero it after upload; on suspend (`adev->in_suspend && user_dpm_profile.user_od`), back up `user_od_table` to `user_od_table_bak`, refresh from `boot_od_table`, and restore all user-editable fields. [F53, F54, F77, F98]
- In `smu_v14_0_2_ppt.c`, user-visible OD fan curve points are restricted to `0 .. NUM_OD_FAN_MAX_POINTS - 2` (5 of 6 elements); `PP_OD_EDIT_FAN_CURVE` must set `FanMode = FAN_MODE_MANUAL_LINEAR` and `BIT(PP_OD_FEATURE_FAN_CURVE_BIT)` in `FeatureCtrlMask`, while acoustic/target/min-PWM edits and fan restores must set `FanMode = FAN_MODE_AUTO`. In `smu_v14_0_2_set_power_limit()`, `limit > msg_limit` clamps `SMU_MSG_SetPptLimit` to `msg_limit` and uploads excess percentage in `OverDriveTable.Ppt`, whereas `limit <= msg_limit` when `current_power_limit > msg_limit` must first reset `OverDriveTable.Ppt = 0` and upload `od_table`. [F55, F56, F70]
- In `smu_v14_0_2_set_power_profile_mode()`, `custom_profile_params` (`2 * 9` `long`s) is indexed by `idx = custom_params[0] * SMU_14_0_2_CUSTOM_PARAMS_COUNT` (validate `custom_params_max_idx == SMU_14_0_2_CUSTOM_PARAMS_COUNT` and `custom_params[0] < SMU_14_0_2_CUSTOM_PARAMS_CLOCK_COUNT`), with `idx` as enable flag and `idx + 1 .. idx + 8` as coefficients; reset `custom_profile_params[idx] = 0` on upload/`SMU_MSG_SetWorkloadMask` failure or when `PP_SMC_POWER_PROFILE_CUSTOM` is deselected. [F57, F73]
- In SMU v14.0.2, `smu_14_0_pcie_table` stores 0-based `pcie_gen[i]` (`0..4`) and encoded `pcie_lane[i]` (`1..7`), whereas `SmuMetrics_t` reports 1-based `PcieRate` (`1..5`) and decoded `PcieWidth` (`1..32`), requiring `DECODE_GEN_SPEED` and `DECODE_LANE_WIDTH` when comparing; in `smu_v14_0_2_update_pcie_parameters()`, repopulate `pcie_table` from `skutable` (resetting `num_of_link_levels = 0`) before clamping `pcie_gen[i]`/`pcie_lane[i]` and sending `SMU_MSG_OverridePcieParameters`. [F58, F64]
- In `smu_v14_0_2_i2c_xfer()`, the request loop must clear `CMDCONFIG_RESTART_MASK` when setting `CMDCONFIG_STOP_MASK` on `cmd->CmdConfig` for the last byte of the last or `I2C_M_STOP` message, and the response loop must advance `c += msg[i].len` before `continue` on write messages (`!(msg[i].flags & I2C_M_RD)`). [F75, F76]
- In `smu_v14_0_set_irq_state()`, `smu_v14_0_check_fw_status()`, and `smu_v14_0_load_microcode()`, branch on `smu->is_apu` to select `smnMP1_FIRMWARE_FLAGS_14_0_0`/`regMP1_SMN_IH_SW_INT*_mp1_14_0_0` vs dGPU offsets. In `smu_v14_0_enable_thermal_alert()`/`disable_thermal_alert()`, skip `amdgpu_irq_get()`/`put()` when `irq_source.num_types == 0` (SR-IOV VFs), and call `smu_v14_0_allow_ih_interrupt()` only after `amdgpu_irq_get()` succeeds. [F113, F116]
- In `smu_v14_0_baco_set_armd3_sequence()` and `smu_v14_0_baco_set_state()`, update `smu_baco.state` only after `SMU_MSG_ArmD3`/`EnterBaco`/`ExitBaco` succeeds, and zero VBIOS scratch regs 6 and 7 on `ExitBaco`; in `smu_v14_0_2_baco_enter()`/`exit()`, use `smu_v14_0_baco_set_armd3_sequence()` when `adev->in_runpm && smu_cmn_is_audio_func_enabled(adev)`. In `smu_v14_0_0_system_features_control()`, send `SMU_MSG_PrepareMp1ForUnload` only when `!en && !adev->in_s0ix`; in `smu_v14_0_set_vcn_enable()`/`set_jpeg_enable()`, skip harvested instances and only send `SMU_MSG_PowerUpJpeg1`/`PowerDownJpeg1` on APUs when `IP_VERSION(14, 0, 1)`. [F49, F117, F119, F120]

## Synchronization
- `smu_cmn_send_smc_msg_with_param()` must hold `smu->message_lock` across `__smu_cmn_ras_filter_msg()`, `smc_fw_state` updates, pre-send polling, `__smu_cmn_send_msg()`, post-send `__smu_cmn_poll_stat()`, and `smu_cmn_read_arg()`; `smu_cmn_send_msg_without_waiting()` and `smu_cmn_wait_for_response()` must NOT lock `smu->message_lock` internally. [F15, F16]
- In `smu_cmn_update_table()`, call `amdgpu_asic_flush_hdp()` after `memcpy()` into `table->cpu_addr` and before `SMU_MSG_TransferTableDram2Smu` (`drv2smu`), and call `amdgpu_asic_invalidate_hdp()` after `SMU_MSG_TransferTableSmu2Dram` and before `memcpy()` from `table->cpu_addr` (`!drv2smu`). [F18]
- In `smu_v14_0_2_i2c_xfer()`, hold `adev->pm.mutex` (which nests outside `smu->message_lock`) around `smu_cmn_update_table()` and unlock before checking `r`; every exit after `req = kzalloc(...)` must reach `fail:` to `kfree(req)`. [F11, F19]
- `smu_v14_0_irq_process()` runs in interrupt context and must not call sleeping SMU mailbox functions: defer `THM_11_0__SRCID__THM_DIG_THERM_L2H` to `smu->swctf_delayed_work`, and handle `SMU_IH_INTERRUPT_ID_TO_DRIVER` via MMIO, setting `MP1_SMN_IH_SW_INT_CTRL__INT_ACK = 1` in `regMP1_SMN_IH_SW_INT_CTRL` and clearing `THM_THERMAL_INT_CTRL__THERM_TRIGGER_MASK_MASK` when updating `DIG_THERM_INTH` in `regTHM_THERMAL_INT_CTRL`. [F20, F115]

## Object Lifetimes
- `smu_cmn_is_audio_func_enabled()` must call `pci_dev_put(p)` before returning whenever `p` from `pci_get_domain_bus_and_slot()` is non-NULL. `smu_v14_0_fini_power()` must reset both `smu_power->power_context = NULL` and `power_context_size = 0` after freeing because `smu_v14_0_init_power()` fails with `-EINVAL` if either is non-zero. [F2, F3]
- `smu_v14_0_init_microcode()` must call `amdgpu_ucode_release(&adev->pm.fw)` on error; when `load_type == AMDGPU_FW_LOAD_PSP` (in `smu_v14_0_init_microcode()` and `smu_v14_0_init_pptable_microcode()`), `ucode[AMDGPU_UCODE_ID_SMC].fw` borrows `adev->pm.fw` until `smu_v14_0_fini_microcode()`, and populating `AMDGPU_UCODE_ID_SMC`/`PPTABLE` must add `ALIGN(size, PAGE_SIZE)` to `adev->firmware.fw_size`. [F14, F45]
- In `smu_v14_0_setup_pptable()` and `smu_v14_0_2_setup_pptable()`, `smu_table->power_play_table` borrows from VBIOS tables, `adev->pm.fw->data`, or `smu_table->combo_pptable` (via `smu_v14_0_2_get_pptable_from_pmfw()`, which must precede `smu_v14_0_2_store_powerplay_table()` copying `smc_pptable` to `driver_pptable` and `smu_v14_0_2_check_powerplay_table()` setting `smu->od_settings = &powerplay_table->overdrive_table`); never `kfree()` `power_play_table` or `smu->od_settings`. [F4, F5, F52]
- `smu_v14_0_0_init_smc_tables()` allocates `metrics_table`, `clocks_table`, `watermarks_table`, and `gpu_metrics_table` with reverse-order `kfree()` unwind, and `smu_v14_0_0_fini_smc_tables()` must `kfree()` and null all four; for SMU v14.0.2, `smu_v14_0_2_init_smc_tables()` must call `smu_v14_0_2_tables_init()` before `smu_v14_0_init_smc_tables()`, and `smu_v14_0_fini_smc_tables()` must free and null all allocations from `smu_v14_0_2_tables_init()`, `smu_v14_0_2_allocate_dpm_context()`, and `smu_v14_0_init_smc_tables()`. [F7, F8, F34]
- `smu_cmn_get_metrics_table()` caches `SMU_TABLE_SMU_METRICS` in `smu_table->metrics_table` timestamped by `metrics_time` (checked via `!smu_table->metrics_time || time_after(jiffies, smu_table->metrics_time + msecs_to_jiffies(1))`); zero `metrics_time` whenever `metrics_table` is allocated or freed and update it only after `smu_cmn_update_table()` succeeds. [F44, F91]
- In `smu_v14_0_2_i2c_control_init()`, initialize `smu_i2c->adev`, `port`, `mutex`, `control->algo`, `control->quirks`, and `i2c_set_adapdata(control, smu_i2c)` before `devm_i2c_add_adapter(adev->dev, control)`; `smu_v14_0_2_i2c_control_fini()` must only null `ras_eeprom_i2c_bus` and `fru_eeprom_i2c_bus` without calling `i2c_del_adapter()`. [F10, F21]

## API Contracts
- `smu_cmn_to_asic_specific_index()` returns negative errnos on unmapped/restricted IDs (`-ENOTSUPP` for unmapped `CMN2ASIC_MAPPING_WORKLOAD`, which `smu_v14_0_2_get_power_profile_mode()` relies on to `continue`; `-EACCES` on SR-IOV VFs for `CMN2ASIC_MAPPING_MSG` without `SMU_MSG_VF_FLAG`; `-EINVAL` otherwise), so check `< 0` before shifting/indexing. `smu_cmn_send_smc_msg_with_param()` translates `-EACCES` or `adev->no_hw_access` into `0` without writing `*read_arg`, but after sending a message it overwrites `*read_arg` with `smu->param_reg` even on error. [F26, F60, F78, F108]
- `smu_cmn_feature_is_supported()` and `smu_cmn_feature_is_enabled()` return boolean `1` or `0` (never `< 0`); if `__smu_get_enabled_features()` sets `enabled_features == ULLONG_MAX`, `smu_cmn_feature_is_enabled()` must return `1` before calling `smu_cmn_to_asic_specific_index()`. `smu_cmn_feature_is_supported()`, `smu_cmn_feature_is_enabled()`, `smu_cmn_feature_set_enabled()`, and `smu_cmn_disable_all_features_with_exception()` take an `enum smu_feature_mask` bit index, whereas `smu_cmn_feature_update_enable_state()` and `smu_cmn_set_pp_feature_mask()` take `1ULL << feature_id`. [F24, F40, F107]
- `smu_v14_0_0_get_gpu_metrics()` and `smu_v14_0_2_get_gpu_metrics()` return `ssize_t`: allocate `gpu_metrics_table` to at least `sizeof(struct gpu_metrics_v*)` in table init, call `smu_cmn_init_soft_gpu_metrics()` before setting fields, return a negative errno without modifying `*table` on `smu_cmn_get_metrics_table()` failure, and on success set `*table = smu_table->gpu_metrics_table` (borrowed) and return the struct size. In `smu_v14_0_2_ppt.c`, pass `SmuMetricsExternal_t` and `DpmActivityMonitorCoeffIntExternal_t` (not inner structs) to `smu_cmn_get_metrics_table()`/`smu_cmn_update_table()`. [F6, F27, F28, F32, F97]
- `print_clk_levels` callbacks (`smu_v14_0_0_print_clk_levels()`, `smu_v14_0_2_print_clk_levels()`) using `sysfs_emit_at(buf, size, ...)` must first call `smu_cmn_get_sysfs_buf(&buf, &size)`. In `smu_v14_0_2_ppt.c`, `smu_v14_0_2_is_od_feature_supported()` takes a `PP_OD_FEATURE_*_BIT` bit index, whereas `smu_v14_0_2_get_od_setting_limits()` takes a `PP_OD_FEATURE_*` selector (`0..11`). [F29, F36]
- `smu_table.boot_values` clocks and `read_sensor` `AMDGPU_PP_SENSOR_GFX_{MCLK,SCLK}` outputs are in 10 kHz, whereas `smu_14_0_dpm_table`, `get_dpm_ultimate_freq`, and `SmuMetrics_t` clocks are in MHz (`/ 100` and `* 100` required); in `smu->thermal_range`, `min`/`max`/`*_crit_max`/`*_emergency_max` are in millidegrees Celsius, whereas `software_shutdown_temp` and `software_shutdown_temp_offset` are in whole degrees Celsius. [F38, F39]
- `smu_v14_0_2_get_allowed_feature_mask(smu, feature_mask, num)` requires `num == 2` and a `uint32_t[2]` array (`*(uint64_t *)feature_mask`). Shared table location helpers (`smu_v14_0_set_driver_table_location()`, etc.) must send GPU `mc_address` (not `cpu_addr`). `smu_v14_0_2_i2c_control_init()` must register `smu_v14_0_2_i2c_control_quirks` (limiting lengths to `MAX_SW_I2C_COMMANDS` and `I2C_AQ_COMB_SAME_ADDR`), and `smu_v14_0_2_i2c_xfer()` must set `SlaveAddress = msg[0].addr << 1` and return `num_msgs` on success. [F101, F128, F144]

## Error Handling
- In `__smu_cmn_reg_print_error()`, suppress logs for `SMU_RESP_CMD_FAIL` (`-EIO`) and use `dev_err_ratelimited` for other mailbox errors (except `SMU_RESP_UNEXP` when `amdgpu_device_bus_status_check()` shows device off bus); in `smu_cmn_send_msg_without_waiting()`, `smu_cmn_wait_for_response()`, and `smu_cmn_send_smc_msg_with_param()`, call `amdgpu_device_halt()` and `WARN_ON(1)` on error only when `adev->pm.smu_debug_mask & SMU_DEBUG_HALT_ON_ERROR` is set. [F130, F131]

## External Contracts
- `smu_v14_0_get_dpm_freq_by_index()` must mask `SMU_MSG_GetDpmFreqByIndex` responses with `0x7fffffff` (bit 31 is fine-grained DPM status). In `smu_v14_0_set_pptable_v2_0()`/`v2_1()` and `smu_v14_0_get_pptable_from_firmware()`, convert header/entry fields via `le16_to_cpu()`/`le32_to_cpu()` and cast `v2`/`v2_1` to `(uint8_t *)` before adding byte offsets. `smu_v14_0_od_edit_dpm_table()` requires `dpm_level == AMD_DPM_FORCED_LEVEL_MANUAL` (`-EINVAL` otherwise) and `gfx_actual_hard_min_freq <= gfx_actual_soft_max_freq` on commit. [F69, F74, F99, F141]

## Known Pitfalls
- `pcie_gen_to_speed()` indexes the 6-element `link_speed` array with `gen - 1` without bounds checks, so callers like `smu_v14_0_2_get_gpu_metrics()` must bound-check `metrics->PcieRate` first. In `smu_v14_0_0_get_smu_metrics_data()`, check `StapmOpnLimit > 0` (`METRICS_SS_APU_SHARE`) and `StapmCurrentLimit > StapmOpnLimit` (`METRICS_SS_DGPU_SHARE`) before dividing. [F63, F87]
- In `smu_v14_0_0_set_watermarks_table()`, `WM_DCFCLK` maps `MinClock`/`MaxClock` to `drain_clk` and `MinMclk`/`MaxMclk` to `fill_clk`, whereas `WM_SOCCLK` swaps them. In `smu_v14_0_2_get_smu_metrics_data()` and `smu_v14_0_2_get_gpu_metrics()`, FCLK/UCLK deep-sleep frequency selection tests `AverageUclkActivity <= SMU_14_0_2_BUSY_THRESHOLD`, whereas GFXCLK tests `AverageGfxActivity`. [F82, F84]
- In `smu_v14_0_2_print_clk_levels()` and `smu_v14_0_2_force_clk_levels()`, every `clk_type` in the second `switch (clk_type)`'s DPM-level group must also bind `single_dpm_table` in the first `switch`; in `smu_v14_0_0_force_clk_levels()` and `smu_v14_0_2_force_clk_levels()`, guard against `mask == 0` before `ffs(mask) - 1` and `fls(mask) - 1`. [F83, F92]
- Feature masks passed to `smu_cmn_get_enabled_mask()` or cast to `(unsigned long *)` for `test_bit()` in `smu_cmn_feature_is_enabled()`/`smu_cmn_get_pp_feature_mask()` must be `uint64_t`, never 32-bit. In `smu_v14_0_2_ppt.c`, I2C callbacks receiving `struct amdgpu_smu_i2c_bus *smu_i2c` must use `smu_i2c->adev`, not `to_amdgpu_device()`. [F102, F103]
