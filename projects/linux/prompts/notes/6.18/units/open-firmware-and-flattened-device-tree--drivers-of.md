# OPEN FIRMWARE AND FLATTENED DEVICE TREE — drivers/of

`drivers/of` unflattens early-boot FDT blobs and PROM trees into reference-counted `struct device_node` and `struct property` hierarchies, exposes them in sysfs/procfs, and provides APIs for node/property queries, phandle/graph walks, NUMA/CPU/reserved-memory setup, address/DMA/IRQ translation, device creation, and runtime changesets/overlays.

## Architecture & Data Flow

- `of_node_release()` requires `OF_DETACHED` before refcount hits 0 (never format `node` with `%pOF` when `!OF_DETACHED`, as `%pOF` calls `of_node_get()`); it only frees a node and its `properties`/`deadprops` when `OF_DETACHED` and `OF_DYNAMIC` are set and, for `OF_OVERLAY`, `OF_OVERLAY_FREE_CSET` was set by `__of_changeset_entry_destroy()` at kref 1. [F11, F33]
- `__of_attach_node()` must set `FWNODE_FLAG_NOT_DEVICE` on `np->fwnode.flags`, and `of_platform_notify()` must clear it before `of_platform_device_create()` on `OF_RECONFIG_CHANGE_ADD` so `fw_devlink` does not skip consumers. [F57]
- On `OF_RECONFIG_UPDATE_PROPERTY`, `__of_changeset_entry_apply()` saves the displaced property in `ce->old_prop`, and `__of_changeset_entry_invert()` swaps `ce->prop` and `ce->old_prop` (or sets `OF_RECONFIG_REMOVE_PROPERTY` if `!ce->old_prop`). Property builders must pass stack properties to `of_changeset_{add,update}_prop_helper()` for `__of_prop_dup()`, and convert `struct property.value` big-endian cells via `cpu_to_be32()` / `be*_to_cpup()` / `of_read_number()`. [F60, F92, F130]
- `of_overlay_remove()` returns `-EBUSY` if `overlay_removal_is_ok()` finds an overlapping node in a later overlay on `ovcs_list`, and only zeroes `*ovcs_id` and calls `free_overlay_changeset()` after `OF_OVERLAY_PRE_REMOVE` and `__of_changeset_revert_entries()` succeed. `of_overlay_remove_all()` and `of_changeset_destroy()` must iterate via `list_for_each_entry_safe_reverse()`. If changeset rollback fails in `of_overlay_apply()` or `of_overlay_remove()`, set `DTSF_APPLY_FAIL`/`DTSF_REVERT_FAIL` in `devicetree_state_flags` permanently so `devicetree_corrupt()` blocks future overlay ops with `-EBUSY`. [F19, F61, F104]
- `of_resolve_phandles()` requires `OF_DETACHED` and `of_overlay_phandle_mutex`, and `adjust_overlay_phandles()` must add `live_tree_max_phandle() + 1` to `overlay->phandle` and `phandle`/`linux,phandle` properties before `__local_fixups__`. `init_overlay_changeset()` must put `"__symbols__"` at `ovcs->fragments[ovcs->count - 1]` with `ovcs->symbols_fragment = true`. In `add_changeset_{property,node}()`, `/__symbols__` additions fail (`-EINVAL`) if the symbol exists and otherwise use `dup_and_fixup_symbol_prop()`; on `target->in_livetree`, `#address-cells`/`#size-cells` must not be updated (`-EINVAL` if unequal via `of_prop_val_eq()`, `0` if equal) and conflicting phandles on `node` and `tchild` return `-EINVAL`. [F68, F69, F70, F87]
- `of_platform_device_create_pdata()` and `of_amba_device_create()` atomically set `OF_POPULATED` (clearing on failure); `of_platform_device_destroy()` and `of_platform_depopulate()` clear `OF_POPULATED`/`OF_POPULATED_BUS` and check `dev->bus` (`&platform_bus_type` vs `&amba_bustype`) before downcasting. [F62, F129]
- In `of_translate_one()`, a missing `rprop` on `parent` fails unless `rprop` is `"dma-ranges"` or `of_empty_ranges_quirk(parent)` is true; for 1:1 translation, read `offset = of_read_number(addr, na)` before mutating `addr` and zero only `addr + pbus->flag_cells` (`(pna - pbus->flag_cells) * 4` bytes). In `of_busses[]`, `pci`, `isa`, and `default-flags` must precede `default`. [F65, F97, F141]
- `__of_address_resource_bounds()` checks `overflows_type(start, r->start)` and sets `r->end` via `check_add_overflow()` when `size > 0` or `wrapping_sub(typeof(r->end), r->start, 1)` when `size == 0`. `"nonposted-mmio"` sets `IORESOURCE_MEM_NONPOSTED`, which `of_iomap()` / `of_io_request_and_map()` must map via `ioremap_np()`. [F75, F147]
- `of_irq_init()` initializes `"interrupt-controller"` nodes parent-first from roots (`desc->interrupt_parent == NULL`), setting `OF_POPULATED` before `irq_init_cb` and clearing it on error. In `of_irq_parse_raw()`, `"interrupt-map"` takes precedence over `"interrupt-controller"` unless absent or matching `of_irq_imap_abusers`. In `of_parse_phandle_with_args_map()`, each nexus step must update both `initial_match_array[i]` and `out_args->args[i]` before `cur = new`. [F64, F134, F140]
- `unflatten_device_tree()` must unflatten `initial_boot_params` whenever non-NULL (even with ACPI enabled); `__unflatten_device_tree()` requires identical `unflatten_dt_alloc()` sizes/alignments between dry-run (`mem == NULL`) and live passes of `unflatten_dt_nodes()` to preserve the `0xdeadbeef` canary. [F85, F133]
- `fdt_scan_reserved_mem()` reserves all static `reg` nodes (`__reserved_mem_reserve_reg()`) before allocating dynamic `size` nodes (`__reserved_mem_alloc_size()`). `__reserved_mem_alloc_in_range()` only calls `memblock_set_bottom_up(bottom_up)` when `bottom_up != top_down` and restores `prev_bottom_up`. `__rmem_cmp()` sorts by `ra->size` after `ra->base`. `of_reserved_mem_region_to_resource()` sets `res->flags = IORESOURCE_MEM`, and `of_numa_parse_memory_nodes()` calls `node_set(nid, numa_nodes_parsed)`. [F45, F63, F67, F96, F131]
- `__of_match_node()` requires a zeroed sentinel entry and scans the full table for the highest score. `of_supplier_bindings[]` must never parse standalone `"interrupt-parent"`. Updates to `OF_RECONFIG_*` or `enum of_overlay_notify_action` must update `action_names[]` and `of_overlay_action_name[]`, and API changes in `drivers/of/` must update `!CONFIG_OF*` stubs in `include/linux/of.h` and `drivers/of/of_private.h`. [F73, F74, F143, F145]

## Synchronization

- `devtree_lock` (`raw_spin_lock_irqsave()`) protects live `parent`/`child`/`sibling` pointers, `properties`/`deadprops` lists, and `phandle_cache`; pin nodes with `of_node_get()` before unlocking, and in `__of_detach_node()`, set `OF_DETACHED` and call `__of_phandle_cache_inv_entry(np->phandle)` under `devtree_lock` before `__of_detach_node_sysfs()`. `__of_*` lookup helpers do not take `devtree_lock` and require callers to hold it or pass an `OF_DETACHED` tree. [F23, F24, F56]
- `of_mutex` serializes live tree mutations, `__of_*_sysfs()` updates, and `aliases_lookup` walks; drop `devtree_lock` before any `__of_*_sysfs()` call. `__of_changeset_{apply,revert}_notify()` are called with `of_mutex` held and must unlock `of_mutex` around `__of_changeset_entry_notify()`. [F14, F27, F29]
- `of_overlay_fdt_apply()` locks `of_overlay_phandle_mutex` before `of_mutex` (unlocking in reverse) across `of_resolve_phandles()` and `of_overlay_apply()`. `of_reserved_mem_device_release()` unlinks `rmem_assigned_device` entries under `of_rmem_assigned_device_mutex` and unlocks before `rd->rmem->ops->device_release()`. [F16, F158]

## Object Lifetimes

- Iterative node helpers (`of_find_all_nodes`, `of_find_node_by_*`, `of_find_compatible_node`, `of_find_matching_node_and_match`, `of_get_next_*`, `of_graph_get_next_*`) put `prev`/`from` and get the returned node, and `of_phandle_iterator_next()` puts the previous `it->node` on each step/error; early exits from non-scoped `for_each_*` or `of_for_each_phandle()` loops must call `of_node_put()`. [F1, F3]
- `__of_remove_property()` and `__of_update_property()` move live nodes' removed/replaced properties to `np->deadprops` until `of_node_release()`. `__of_changeset_entry_destroy()` does not free `ce->prop`, so `of_changeset_add_prop_helper()` must call `__of_prop_free(new_pp)` on error and link `new_pp` onto `np->deadprops` on success. [F9, F10]
- `of_changeset_destroy()` calls `device_link_wait_removal()` before destroying entries in reverse. When `of_kset` is initialized, `__of_attach_node_sysfs()` calls `of_node_get(np)` after `kobject_add()` and frees `safe_name()`, while `__of_detach_node_sysfs()` removes bin_files and `np->kobj` before `of_node_put(np)`. [F12, F15]
- In `of_irq_parse_raw()`, self-referencing `interrupt-map` entries (`ipar == newpar`) require `of_node_put(ipar)` before returning `0` because `of_irq_parse_imap_parent()` already got `out_irq->np`. `of_irq_init()` must `of_node_put()` both `desc->dev` and `desc->interrupt_parent` before `kfree(desc)` on error. `of_resolve_phandles()` must free `local_fixups`, `tree_symbols`, and each `refnode` from `of_find_node_by_path()`. `of_reserved_mem_device_init_by_{idx,name}()` entries on `of_rmem_assigned_device_list` require `of_reserved_mem_device_release(dev)`. [F5, F6, F22, F138]

## API Contracts

- `__of_find_node_by_path()` gets the returned node, and `__of_find_node_by_full_path()` consumes the caller's `node` reference while returning an owned reference. `of_irq_parse_raw()` gets `out_irq->np` on success without putting the initial `out_irq->np`, so `of_irq_parse_one()` must put its initial parent `p` and callers must `of_node_put(out_irq->np)`. `irq_of_parse_and_map()` returns `0` on failure, whereas `of_irq_get*()` and `of_irq_to_resource()` return `< 0`, `0` (mapping failure), or `> 0`. [F2, F4, F42]
- `of_map_id()` transfers `phandle_node` into `*target` only when `*target == NULL` (otherwise putting `phandle_node` and matching `*target`). `__of_translate_address()` transfers `dev` into `*host = no_free_ptr(dev)` on indirect-IO match (`iorange->flags != LOGIC_PIO_CPU_MMIO`), requiring `of_node_put(host)`. `of_translate_*address()` and `of_translate_ioport()` return `OF_BAD_ADDR` (`(u64)-1`) on error; `of_dma_get_range()` skips `OF_BAD_ADDR`, returns `-EINVAL` if `!num_ranges`, and allocates `num_ranges + 1` via `kcalloc()` for a zero sentinel. [F7, F8, F40, F86]
- `of_find_property()` and `of_get_property()` leave `*lenp` unmodified when returning `NULL`. `of_read_number()` / `of_read_ulong()` take `size` in 32-bit cells, not bytes; `of_property_read_variable_*_array()` must scale `sz_min`/`sz_max` by `sizeof(*out_values)` for `of_find_property_value_of_size()` and divide the returned byte size by `sizeof(*out_values)`. [F38, F50, F122]
- `of_phandle_iterator_init()` zeroes `*it` and requires `cells_name || cell_count >= 0`; `of_phandle_iterator_next()` resets `it->cur = it->phandle_end`, falls back to `it->cell_count >= 0` when `cells_name` is absent, and sets `it->phandle_end = it->cur + count`. `of_fwnode_get_reference_args()` calls `of_node_put(of_args.np)` when `!args`, and zero-fills `args->args` up to `NR_FWNODE_REFERENCE_ARGS` when `args` is non-NULL. [F51, F108, F169]
- In `of_link_property()`, `supplier_bindings.parse_prop` and `.get_con_dev` return refcounted nodes; `.parse_prop` returns the first supplier at `index == 0` and `NULL` past the end, and non-device subnode bindings (`parse_remote_endpoint`) must set `.get_con_dev` (`of_graph_get_port_parent`) so `of_link_to_phandle()` uses `con_dev_np`. `of_match_device()` and `of_device_*modalias()` reject `dev->of_node_reused`, and string arrays passed to `of_*_compatible_match()`, `of_flat_dt_match()`, or `__of_device_is_status()` must be `NULL`-terminated. [F90, F99, F111, F142, F144, F170]
- `early_init_dt_scan_memory()` returns `1` if memory was registered and `0` otherwise. Disabled `memory-region` targets return `0` in `of_reserved_mem_device_init_by_idx()` but `-ENODEV` in `of_reserved_mem_region_to_resource()`. `__reserved_mem_{reserve_reg,alloc_size}()` call `dma_contiguous_early_fixup()` for `"shared-dma-pool"` with `"reusable"`; `early_init_dt_alloc_reserved_memory_arch()` calls `kmemleak_ignore_phys(base)` on success; `early_init_dt_reserve_memory()` returns `-EBUSY` without `memblock_mark_nomap()` if a `nomap` region in `memblock.memory` is already reserved. [F49, F53, F132, F166, F168]

## Error Handling

- `__of_changeset_{apply,revert}_entries()` keep the primary error in `ret`, roll back prior entries in the opposite direction (`list_for_each_entry_continue_reverse()` / `list_for_each_entry_continue()`), and write rollback errors to caller-zeroed `*ret_revert` / `*ret_apply`. [F13, F48]
- `of_overlay_fdt_apply()` validates `overlay_fdt_size >= sizeof(struct fdt_header)`, `!fdt_check_header()`, and `overlay_fdt_size >= fdt_totalsize()`, stores unaligned `kmalloc()` in `ovcs->new_fdt` while unflattening `PTR_ALIGN(new_fdt, FDT_ALIGN_SIZE)`, sets `ovcs->notify_state = OF_OVERLAY_INIT` and `of_changeset_init(&ovcs->cset)` on `ovcs_list` insertion, and if `of_overlay_apply()` fails, returns `*ret_ovcs_id = ovcs->id` for `of_overlay_remove()` instead of calling `free_overlay_changeset()`. [F37, F47, F80, F124]
- Callers of `of_match_bus()` must check for `NULL`, and bus matchers must check `of_property_present(np, "#address-cells")` before `of_bus_n_addr_cells()`. `__of_translate_address()` and `fdt_translate_address()` validate cell counts with `OF_CHECK_COUNTS()` before copying into `addr[OF_MAX_ADDR_CELLS]`. [F43, F82]
- In `of_parse_phandle_with_args_map()`, `ret` is clobbered with `0` by `of_property_read_u32()`, so every `goto put` branch must set `ret < 0`; advancing past a phandle cell here or in `of_irq_parse_imap_parent()` must decrement `map_len`/`len` before checking remaining length and `MAX_PHANDLE_ARGS`. `of_phandle_iterator_next()` must check `it->cur + count <= it->list_end`. [F44, F76, F84]
- Phandle fixups (`update_usages_of_a_phandle_reference()`, `adjust_local_phandle_references()`) check `offset + 4 <= prop->length` and `prop_fix->length % 4 == 0`. Property string readers and `dup_and_fixup_symbol_prop()` verify NUL-termination via `strnlen()` within `prop->length`. In `of_dma_configure_id()`, only reset `dev->dma_range_map = NULL` on `-EPROBE_DEFER` when `set_map` is true. `alloc_reserved_mem_array()` checks `array_size() == SIZE_MAX`, and `fdt_scan_reserved_mem_reg_nodes()` requires `len % t_len == 0` and warns if `len > t_len`. [F54, F81, F83, F118, F167]

## External Contracts

- `of_platform_default_populate_init()` names the primary PowerPC boot display (`"linux,opened"` and `"linux,boot-display"`) `"of-display"` and subsequent displays `"of-display.%d"`. In `/chosen/linux,usable-memory-range` (`MAX_USABLE_RANGES == 2`), `crashk_res` precedes `crashk_low_res`; `of_kexec_alloc_and_setup_fdt()` deletes existing `"kaslr-seed"` and `"linux,ima-kexec-buffer"` (`remove_ima_buffer()`) and only writes fresh `"kaslr-seed"`/`"rng-seed"` if `rng_is_initialized()`. `__of_add_property_sysfs()` sets mode `0400` and `size = 0` on `"security-*"` properties, and `early_init_dt_scan_chosen()` scrubs `/chosen/rng-seed` via `fdt_nop_property()` and updates `of_fdt_crc32`. [F79, F93, F164, F165, F172]

## Known Pitfalls

- Never use `%pOF` under `devtree_lock` (deadlocks in `of_get_parent()`), and never place an alphanumeric character directly after `%pOF*` in a format string (use `%c`). `of_modalias()` rejects `(len > 0 && !str) || len < 0` and clamps `csize` when `csize >= len`; callers sizing with `of_modalias(np, NULL, 0)` must add `1` to `size` for both allocation and `of_modalias(np, str, size)`. [F25, F91, F126, F127]
- Divide byte lengths from `of_get_property()` / `fdt_getprop()` by `4` (`sizeof(__be32)`) when indexing `__be32 *` or passing cell counts to `of_read_number()` (including `"linux,initrd-start"`/`"linux,initrd-end"`), and scale untyped `const void *` offsets by `4 * addr_cells` (`do_get_kexec_buffer()`). Bound alias and path components by `'/'` and `':'` (`strcspn(path, "/:")`) in `of_find_node_opts_by_path()` and `__of_find_node_by_path()`. [F77, F78, F120, F121]
- In `of_dma_configure_id()`, pass `__of_get_dma_parent(np)` to `of_dma_get_range()` when `np == dev->of_node` and `of_node_get(np)` otherwise, and ensure `end != 0` (`(1ULL << 32) - 1` fallback) before `DMA_BIT_MASK(ilog2(end) + 1)`. `early_init_dt_add_memory_arch()` bounds-checks `size` before `PAGE_ALIGN(base)` and `phys_offset` adjustments and clamps against `MAX_MEMBLOCK_ADDR`; use `initial_boot_params_pa` instead of `__pa(initial_boot_params)`. `parse_gpios()` ignores `",nr-gpios"`; `of_graph_get_next_endpoint()` resets `prev = NULL` when advancing `port`; `of_irq_init()` breaks and cleans up if `intc_parent_list` is empty. [F98, F107, F109, F110, F115, F116, F117, F159]
