# IRQCHIP DRIVERS — drivers/irqchip (part 1)

Implements core and SoC interrupt/MSI controllers: ARM GICv3/v4, ITS, MBI, GICv2m, GIC PM, RISC-V ACLINT SSWI, and platform controllers for Aspeed, ATH79, Atmel AIC/AIC5, BCM2712/2835/2836, Exynos, TI Crossbar, and DaVinci.

## Architecture & Data Flow
- `irq_to_cpuid_lock()`/`unlock()` must check `d->chip == &its_vpe_irq_chip` before casting `d->chip_data` to `struct its_vpe *`; non-vPE IRQs store `struct its_device *` and resolve a vPE via `get_vlpi_map(d)`. [F42]
- Callers of `its_send_mapti()` must update `event_map.col_map[event]` before the call, whereas callers of `its_send_movi()` must update `col_map[event]` only after it returns so `its_build_movi_cmd()` reads the old collection via `dev_event_to_col()` for `SYNC`. [F59]
- In `its_vlpi_map()`/`unmap()`, `irqd_set_forwarded_to_vcpu(d)` must precede `lpi_write_config()` on map, and `irqd_clr_forwarded_to_vcpu(d)` must precede `lpi_update_config()` on unmap, as `get_vlpi_map()` checks `irqd_is_forwarded_to_vcpu(d)` to select `vprop_page` vs `prop_table_va`. In `lpi_update_config()`, `direct_lpi_inv(d)` requires `gic_rdists->has_direct_lpi && (is_v4_1(its_dev->its) || !irqd_is_forwarded_to_vcpu(d))`; GICv4.0 vLPIs must use `its_send_vinv()`. [F61, F105]
- `event_lpi_map` arrays (`lpi_map`, `col_map`, `vlpi_maps`) are 0-indexed by `its_get_event_id(d)` (`d->hwirq - lpi_base`), while property tables (`prop_table_va`, `vprop_page`) are byte-indexed by `hwirq - 8192` in `lpi_write_config()`. `its_create_device()` sizes `col_map` to `nr_lpis` when `alloc_lpis` is true and `nr_ites` when false (`vpe_proxy.dev`), and requires `dev->nr_ites >= 2` and `dev->itt_sz` aligned to `ITS_ITT_ALIGN` (256B). [F89, F94, F124, F128]
- In `its_set_affinity()`, `its_dec_lpi_count(d, prev_cpu)` runs before CPU selection; every exit path must call `its_inc_lpi_count(d, cpu)` on success or restore `its_inc_lpi_count(d, prev_cpu)` on error. [F60]
- In `its_vpe_set_affinity()`, when `from != cpu`, always call `its_send_vmovp()` and `its_vpe_db_proxy_move()` after updating `vpe->col_idx` even if both CPUs share a GICv4.1 `vpe_table_mask`. In `its_send_vmovp()`, zero-initialize `struct its_cmd_desc desc = {}` for the `!its_list_map` path. Under `vpe_proxy.lock`, `its_vpe_db_proxy_map_locked()`/`unmap_locked()` must keep `vpe->vpe_proxy_event` (`-1` when unmapped) and `vpe_proxy.vpes[slot]` synced, evicting `vpe_proxy.next_victim` before reuse. [F48, F58, F63]
- `its_allocate_entry()` must zero `cmd->raw_cmd[0..3]`, and all command builders must call `its_fixup_cmd(cmd)`. `its_cmd_ptr_to_offset()` scales `ptr - its->cmd_base` by `sizeof(*ptr)` (32B) for `GITS_CWRITER`, while `its_queue_full()` divides `GITS_CREADR` by `sizeof(struct its_cmd_block)`. In `its_restore_enable()`, writing `GITS_CBASER` resets `GITS_CREADR` to 0, requiring `its->cmd_write = its->cmd_base` and `gits_write_cwriter(0, ...)`. In `its_wait_for_range_completion()`, add `ITS_CMD_QUEUE_SZ` on `to_idx < prev_idx` and `rd_idx < prev_idx` wrap-around while updating `prev_idx = rd_idx`. [F47, F67, F106, F126]
- `its_alloc_collections()` must set `target_address = ~0ULL` because `valid_col()` rejects non-zero bits `[15:0]`; when `!GITS_TYPER_PTA`, left-shift `GICR_TYPER_CPU_NUMBER()` by 16. [F49, F92]
- Write `GITS_BASER<n>` via `its_write_baser()` to update `baser->val`. In `its_setup_baser()`, `its_probe_one()`, and `its_cpu_init_lpis()`, if read-back shareability in `GITS_BASER`, `GITS_CBASER`, `GICR_PROPBASER`, or `GICR_PENDBASER` is 0, set cacheability to `*_nC`. 52-bit `GITS_BASER` PAs require `psz == SZ_64K` and `GITS_BASER_PHYS_52_to_48()`/`ADDR_48_to_52()`. [F68, F71, F95]
- In `its_alloc_table_entry()` and `allocate_vpe_l2_table()`, bounds-check `id` (flat) or `idx = id >> ilog2(psz / esz)` (L1) and write `cpu_to_le64(page_to_phys(page) | GITS_BASER_VALID)`. `its_parse_indirect_baser()` requires `u64 esz` for `esz << ids`; `allocate_vpe_l1_table()` requires `DIV_ROUND_UP(npg * psz, PAGE_SIZE)`. [F91, F114, F118]
- In `merge_lpi_ranges(a, b)`, check `&a->entry == &lpi_range_list || &b->entry == &lpi_range_list` before dereferencing, and fold `a` into `b` (`kfree(a)`) so `new` stays valid in `free_lpi_range()`. [F100]
- `its_of_probe()` and `its_acpi_probe()` must run `its_reset_one()` on all nodes before any `its_probe_one()`. `its_probe_one()` must call `its_enable_quirks(its)` before `is_v4()`, `its_alloc_pages_node()`, or `its_alloc_tables()`. All `struct gic_quirk` arrays require a `.desc = NULL` sentinel. [F97, F139, F142]
- `redist_disable_lpis()` must issue `dsb(sy)`, wait for `GICR_CTLR_RWP == 0`, and verify `GICR_CTLR_ENABLE_LPIS == 0` before programming `GICR_PROPBASER`/`PENDBASER`. In `its_cpu_init_lpis()`, jumping to `out` when `RDIST_FLAGS_RD_TABLES_PREALLOCATED` and `GICR_CTLR_ENABLE_LPIS` are set must still run GICv4 `GICR_VPROPBASER`/`VPENDBASER` setup and `allocate_vpe_l1_table()`. [F77, F141]
- On GICv4.0 (`its_vpe_deschedule()`), `its_clear_vpend_valid()` must poll `GICR_VPENDBASER_Dirty` clear before and after clearing `Valid`, saving `IDAI` and `PendingLast` to `vpe`. On GICv4.1 (`__gic_update_rdist_properties()`, `allocate_vpe_l1_table()`), if `GICR_VPENDBASER_Valid` is set, write `GICR_VPENDBASER_PendingLast` (clearing `Valid`) before clearing `GICR_VPROPBASER_4_1_VALID` or writing `GICR_VPROPBASER`. `inherit_vpe_l1_table_from_rd()` must clear `GICR_VPROPBASER_4_1_Z`. [F70, F74, F151]
- In `irq-gic-v3.c`, `gic_cpu_sys_reg_enable()` must precede `gic_prio_init()`, `gic_cpu_init()`, and `gic_cpu_sys_reg_init()`. In `gic_prio_init()`, under `FLAGS_WORKAROUND_INSECURE && !gic_dist_security_disabled()`, set `GICD_CTLR_DS` only if `cpus_have_group0`, else set `nmi_support_forbidden = true`. In `gic_dist_init()`, write `GICD_CTLR = 0` + `gic_dist_wait_for_rwp()` before SPI setup, and enable `GICD_CTLR_ARE_NS` + `gic_dist_wait_for_rwp()` before writing `GICD_IROUTER*`. [F135, F137, F146]
- Keep `gic_chip` and `gic_eoimode1_chip` in sync for shared callbacks, flags, and errata. Use `__gic_get_rdist_index()` (`hwirq - EPPI_BASE_INTID + 32`) and `__gic_get_ppi_index()` (`+ 16`) for EPPIs, and `hwirq - ESPI_BASE_INTID` for ESPIs. In `gic_iterate_rdists()`, stop when `fn` returns 0 or `single_redist` is true, and when `!redist_stride && (typer & GICR_TYPER_VLPIS)`, advance `ptr` by an extra `SZ_64K * 2`. [F82, F96, F103]
- Subtract controller base offsets (`mip->msi_offset`, `v2m->spi_start`, `mbi->spi_start`, `lpi_base`) from `hwirq` before freeing bitmap bits in `mip_middle_domain_free()`, `gicv2m_unalloc_msi()`, `mbi_free_msi()`, and `its_irq_domain_free()`. Validate GICv2m SPI ranges with `is_msi_spi_valid()` before allocating `v2m->bm`. [F85, F86, F133]
- In `aic5_mask()`/`unmask()`, manually update `gc->mask_cache`, and in `sama5d2_aic5_of_init()`, allocate `smr_cache` with `DIV_ROUND_UP(nirqs, 32) * 32` entries. In `exynos-combiner.c`, mask per-group register accesses with `combiner_data->irq_mask`. In `crossbar_of_init()`, validate DT indices `< max`; skip only `IRQ_RESERVED` when computing `register_offsets`, but skip both `IRQ_RESERVED` and `IRQ_SKIP` for `safe_map`. [F64, F69, F83, F107, F119]

## Synchronization
- `its_irq_set_vcpu_affinity()` runs under `irq_desc` lock with IRQs disabled: acquire `its_dev->event_map.vlpi_lock` via `raw_spinlock` (never `raw_spinlock_irq`) across all vLPI calls (`its_vlpi_map()`, `get()`, `unmap()`, `prop_update()`), using `GFP_ATOMIC` for allocations. [F1, F18, F166]
- `its->dev_alloc_lock` (mutex) serializes `its_msi_prepare()`/`teardown()`; `its->lock` (raw spinlock) nests inside it to protect `its_device_list` and command queue writes, held across `its_flush_cmd()`, reading `GITS_CREADR`, and `its_post_commands()`, and dropped before `its_wait_for_range_completion()`. [F24, F163]
- GICv4 ITSList operations must lock in order `vm->vmapp_lock` -> `vpe->vpe_lock` -> `vmovp_lock` -> `its->lock`, holding `vmovp_lock` across `vmovp_seq_num` and `GITS_CMD_VMOVP`. In `its_vpe_4_1_deschedule()`, when `info->req_db`, hold `vpe->vpe_lock` (IRQs off) across `its_clear_vpend_valid()` and updating `vpe->pending_last`. [F29, F164]
- Follow `*cfg` writes in `lpi_write_config()` with `gic_flush_dcache_to_poc()` (if `RDIST_FLAGS_PROPBASE_NEEDS_FLUSHING`) or `dsb(ishst)` before invalidation. In `its_alloc_table_entry()`/`allocate_vpe_l2_table()`, flush the L2 page to PoC (if non-shareable) before setting `GITS_BASER_VALID` in `table[idx]`, then flush `table + idx` and `dsb(sy)`. [F26, F27]
- Issue `dsb(ishst)` before and `isb()` after `ICC_SGI1R_EL1` in `gic_ipi_send_mask()`, and `smp_wmb()` in `bcm2836_arm_irqchip_ipi_send_mask()`. In `gic_irq_set_irqchip_state()`, follow `gic_poke_irq(d, GICD_ISACTIVER)` with `gic_peek_irq(d, reg)`. [F33, F149]
- In `__gic_handle_irq_from_irqsoff()`, call `gic_pmr_mask_irqs()` + `isb()` before `gic_read_iar()`, then restore `ICC_PMR_EL1`. In `__gic_handle_irq_from_irqson()`, handle NMIs inside `nmi_enter()`/`exit()` before `gic_pmr_mask_irqs()` and `gic_arch_enable_irqs()`. `gic_complete_ack()` requires `isb()` before calling domain handlers. [F168, F169, F174]
- In `irq-atmel-aic5.c`, lock `&bgc->lock` on chip 0 while updating `gc->mask_cache`/`wake_active`. In `aic_irq_domain_xlate()` and `aic5_irq_domain_xlate()`, use `raw_spinlock_irqsave`. [F108, F158]

## Object Lifetimes
- `its_alloc_pages_node()`/`its_free_pages()` pass `order` to page allocators but `1 << order` to `set_memory_decrypted()`/`encrypted()`, and must leak pages if encryption state change fails. `its_create_device()` must save exact `sz` in `dev->itt_sz` for `itt_free_pool()`. [F3, F123, F125]
- `its_vlpi_map()` increments `nr_vlpis` and calls `its_map_vm()` only when `!irqd_is_forwarded_to_vcpu(d)`; `its_vlpi_unmap()` clears `event_map.vm = NULL` and frees `vlpi_maps` when `!--nr_vlpis == 0`. `its_msi_teardown()` (under `dev_alloc_lock`) must skip unmapping/freeing `its_dev` if `its_dev->shared` or `!bitmap_empty(lpi_map, ...)`. [F6, F7]
- In `its_cpu_memreserve_lpi()`, if `RD_LOCAL_PENDTABLE_PREALLOCATED`, free `pend_page` via `its_free_pending_table()` and set `pend_page = NULL`; else call `gic_reserve_range()`. [F9]
- `gicv2m_init_one()` takes `fwnode` ownership only on success; callers must free `child`/`fwnode` on error or early loop break. Do not mark `gicv2m_get_fwnode()` or `gic_v3_get_gsi_domain_id()` `__init`. In `irq-gic-pm.c`, `gic_runtime_resume()` must return 0 if `!chip_pm->chip_data`, and `gic_probe()` must unwind PM and `irq_dispose_mapping(irq)` on error. [F13, F16, F99, F134]

## API Contracts
- `gic_retrigger()`, `its_irq_retrigger()`, and `its_vpe_retrigger()` must negate (`!`) the return of `*_set_irqchip_state()`. [F40]
- `its_irq_set_vcpu_affinity()` must check `!info` (unmap) before reading `info->cmd_type`; `its_vlpi_get()`/`unmap()`/`prop_update()` must check `event_map.vm && irqd_is_forwarded_to_vcpu(d)` before indexing `vlpi_maps`. [F44]
- Upper-layer ITS `msi_prepare` callbacks must round `nvec` to a power of two and set `scratchpad[0].ul = dev_id` (plus `scratchpad[1].ul = pa` on GICv5). `gicv2m_irq_domain_alloc()`/`unalloc_msi()` also require power-of-two `nr_irqs`. [F52, F88, F121, F178]
- `msi_parent_ops` using `msi_lib_init_dev_msi_info()` over fasteoi parents must set `MSI_CHIP_FLAG_SET_EOI` and omit `MSI_CHIP_FLAG_SET_ACK`. GIC MSI `.alloc` must call `iommu_dma_prepare_msi()`, and `.irq_compose_msi_msg` must use `msi_msg_set_addr()`. `mbi_init_dev_msi_info()` enables level MSI (`mbi_compose_mbi_msg()`) only for `DOMAIN_BUS_DEVICE_MSI`. [F175, F176, F179, F180]
- Child domains of `gic_irq_domain_translate()` must pass 3-cell `irq_fwspec` on OF (`param[1] = hwirq - 32` for SPIs) and 2-cell on `is_fwnode_irqchip`. `gic_irq_domain_map()` must call `irqd_set_handle_enforce_irqctx()`. `gic_eoimode1_mask_irq()` must write `GICD_ICACTIVER` if `irqd_is_forwarded_to_vcpu(d)`. `gic_irq_nmi_setup()`/`teardown()` require `desc->lock`, reject enabled IRQs/LPIs, and refcount redistributor `desc->handle_irq` updates via `rdist_nmi_refs[idx]`. [F172, F181, F182, F183]
- `its_sgi_irq_domain_deactivate()` must call `its_configure_sgi()` twice (`false`, then `true`). `its_build_vmapp_cmd()` must return `NULL` when `!valid && is_v4_1(its)`. In `its_vpe_set_affinity()`, when `!atomic_read(&vpe->vmapp_count)`, return `-EINVAL` only if `gic_requires_eager_mapping()`, else update affinity and return `IRQ_SET_MASK_OK_DONE`. [F56, F98, F140]

## Error Handling
- On loop failure in `its_vpe_irq_domain_alloc()` after setting `db_bitmap`/`vprop_page`, unwind only via `its_vpe_irq_domain_free(domain, virq, i)`. Callers of `its_lpi_alloc()` requiring `nr_irqs` must check `*nr_ids < nr_irqs` and call `its_lpi_free()`. [F2, F37]
- If `its_force_quiescent()` fails in `its_save_disable()`, restore `ctlr_save` on the current and all preceding `its_nodes` via `list_for_each_entry_continue_reverse()`. In `gic_acpi_parse_madt_its()`, deregister the IORT token before `irq_domain_free_fwnode()`. [F10, F11]
- Check `IS_ERR()` on `gic_of_iomap()` and `aic_common_of_init()`. In `crossbar_of_init()`, unwind all allocations and set `cb = NULL` on error. Handle `CPU_PM_ENTER_FAILED` alongside `CPU_PM_EXIT` in `gic_cpu_pm_notifier()`. Return 0 with `pr_warn()` if `gic_configure_irq()` fails for PPI/EPPI in `gic_set_type()`, and use `pr_err_ratelimited()` for runtime polling timeouts. [F15, F38, F39, F136, F188, F189]

## External Contracts
- Call `its_force_quiescent()` before writing `GITS_BASER<n>` or `GITS_CBASER`. In `gic_enable_redist(false)`, verify `GICR_WAKER_ProcessorSleep` stuck before polling `ChildrenAsleep`. `gic_mask_irq()` must wait for RWP after `GICD_ICENABLER`, and `gic_set_affinity()` must mask enabled IRQs while writing `GICD_IROUTER`. [F28, F34, F111]

## Known Pitfalls
- In `gic_compute_target_list()`, decrement `cpu--` on MPIDR cluster mismatch before `*base_cpu = cpu`. In `its_vpe_*mask_irq()`, pass `d->parent_data` to `lpi_write_config()`, but pass `d` and `d->parent_data->hwirq` to `its_vpe_send_inv()`/`__direct_lpi_inv()`. On GICv4.0, `its_vlpi_set_doorbell()` must use `its_send_vmovi()` (not `vmapti`) on mapped vLPIs. [F102, F104, F186]
- Access `GITS_SGIR` via `its->sgir_base + GITS_SGIR - SZ_128K`, and check `numlpis > 2` in `its_lpi_init()`. Preserve `fallthrough` across `switch(pribits)` in `gic_cpu_sys_reg_init()`, and reject `broken_rdists` in `gic_check_rdist()` (`CPUHP_BP_PREPARE_DYN`), not `gic_starting_cpu()`. [F109, F120, F127, F173]
- Errata: guard `GICD_TYPER2` on `!FLAGS_WORKAROUND_CAVIUM_ERRATUM_38539` after `gic_enable_quirks()`; under `gic_nvidia_t241_erratum`, use `gic_dist_base_alias(d)` in `gic_peek_irq()`/`gic_set_type()` but `dist_base` in `gic_poke_irq()`; under `gic_arm64_erratum_2941627_needed(d)`, deactivate SPIs/ESPIs with `gic_poke_irq(d, GICD_ICACTIVER)`; under `GICV2M_GRAVITON_ADDRESS_ONLY`, never read `V2M_MSI_TYPER`/`IIDR`. [F145, F147, F148, F155]
