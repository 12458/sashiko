# EXT4 FILE SYSTEM — fs/ext4 (part 5)

This unit implements ext4 superblock/mount lifecycle, quota/journal attachment, and lazyinit (`super.c`), online resize (`resize.c`), buffered readpage/readahead with fscrypt/fs-verity (`readpage.c`), fs-verity metadata (`verity.c`), symlinks (`symlink.c`), xattrs (`xattr*.c`), and sysfs/procfs (`sysfs.c`).

## Architecture & Data Flow
- In `ext4_load_super()`, bound `s_log_block_size` (<= 6) and `s_log_cluster_size` (<= 20) before shifting; reject `clustersize < s_blocksize` in `ext4_handle_clustersize()` before computing `s_cluster_bits`; and recompute `sbi->s_es = bh->b_data + offset` after `sb_set_blocksize()`. `ext4_block_group_meta_init()` / `ext4_check_geometry()` must verify `s_inodes_per_block != 0`, `s_blocks_per_group != 0`, `s_inodes_per_group` in `[s_inodes_per_block, s_blocksize * 8]`, and `(u64)s_groups_count * s_inodes_per_group == le32_to_cpu(es->s_inodes_count)`. `ext4_fill_flex_info()` resets `s_log_groups_per_flex` to `0` if `< 1` or `> 31`. [F322, F323, F342, F343, F344]
- Group descriptor accessors (`ext4_block_bitmap()`, `ext4_inode_bitmap()`, `ext4_inode_table()`, `ext4_free_group_clusters()`, `ext4_free_inodes_count()`, `ext4_used_dirs_count()`, `ext4_itable_unused_count()`, `*_set()`) touch `*_hi` fields only when `EXT4_DESC_SIZE(sb) >= EXT4_MIN_DESC_SIZE_64BIT`. `ext4_group_desc_csum()` hashes `s_desc_size - offset` bytes after `bg_checksum` only if `offset < s_desc_size`. [F319, F320]
- `__ext4_fill_super()` and `__ext4_remount()` reset `s_stripe` to 0 if `ext4_is_stripe_incompatible()`. Set `SB_I_VERSION` on `fc->sb_flags` in `ext4_init_fs_context()`. Clear `needs_recovery` in `__ext4_fill_super()` if `bdev_read_only(sb->s_bdev)`. In `ext4_load_journal()`, save/restore `EXT4_S_ERR_START..EXT4_S_ERR_END` in `es` and `s_mount_state & EXT4_ERROR_FS` across `jbd2_journal_load()`, calling `ext4_commit_super()` only if changed and `!really_read_only`. [F287, F288, F289, F290]
- In `_ext4_show_options()`, `MOPT_SET` checks `(mount_opt & m->mount_opt) == m->mount_opt`, `MOPT_CLEAR` checks `!(mount_opt & m->mount_opt)`, and `emergency_ro` is emitted when `ext4_emergency_ro(sb)`. `ext4_statfs_project()` clamps `f_blocks`, `f_bfree`, `f_bavail` (and `f_files`, `f_ffree`) independently with `min()` against `limit` and `limit > cur ? limit - cur : 0`. [F324, F328, F339]
- In `ext4_flex_group_add()` and `descriptor_loc()`, use `meta_bg` only when `ext4_has_feature_meta_bg(sb)` and index `>= le32_to_cpu(es->s_first_meta_bg)` (incrementing `has_super` by 1 in `descriptor_loc()` if `s_blocksize == 1024 && nr == 0 && s_first_data_block == 0`). `ext4_convert_meta_bg()` clears `resize_inode`, sets `meta_bg` and `s_first_meta_bg = num_desc_blocks(sb, sbi->s_groups_count)`, and frees/zeroes `resize_inode`'s `EXT4_DIND_BLOCK` and `i_blocks`. [F284, F327, F329]
- In `ext4_update_super()` (`resize.c`), update `s_freeclusters_counter`, `s_freeinodes_counter`, `fg->free_clusters`, `fg->free_inodes`, `s_overhead`, `es->s_overhead_clusters`, and superblock checksum under `lock_buffer(sbi->s_sbh)`. `add_new_gdb()` zeroes `dind->b_data[gdb_num % EXT4_ADDR_PER_BLOCK(sb)]`, decrements `inode->i_blocks` and `es->s_reserved_gdt_blocks`, and `rcu_assign_pointer()`s `s_group_desc` before incrementing `s_gdb_count`. `reserve_backup_gdb()` wraps `data` to `(__le32 *)dind->b_data` when `++data >= end`. [F282, F283, F318]
- In `alloc_flex_gd()`, cap `resize_bg` at `umin(flexbg_size, MAX_RESIZE_BG)` and shrink to `1 << fls(n_group - o_group)` without adding 1. `verify_group_input()` checks that `block_bitmap`, `inode_bitmap`, and `[inode_table, inode_table + s_itb_per_group)` lie within `[start + overhead, start + blocks_count)` without overlap and `free_blocks_count >= 0`; keep those three `__u64` fields contiguous in `ext4_new_group_data`. In `ext4_resize_fs()` with `bigalloc`, mask `n_blocks_count` to a cluster boundary and drop final `n_group` if `< overhead + 2 + s_itb_per_group + s_cluster_ratio`. [F315, F316, F317, F365]
- In-inode xattr `e_value_offs` and `s->base` are relative to `IFIRST(header)`; block xattrs are relative to `BHDR(bh)`. `ext4_expand_extra_isize_ea()` shifts xattrs and adjusts non-external `e_value_offs` via `ext4_xattr_shift_entries()`, then calls `ext4_find_inline_data_nolock()` if inline data exists. `ext4_xattr_make_inode_space()` must never move `system.data` to a block. [F293, F359, F404]
- In `ext4_xattr_ibody_set()`, update `header->h_magic` and `EXT4_STATE_XATTR` together based on `!IS_LAST_ENTRY(s->first)`. Clear `MBE_REUSABLE_B` when `h_refcount` hits `EXT4_XATTR_REFCOUNT_MAX` and set it under `lock_buffer(bh)` at `EXT4_XATTR_REFCOUNT_MAX - 1`. `ext4_write_lock_xattr()` saves `EXT4_STATE_NO_EXPAND` in `*save` before setting it, and `ext4_write_unlock_xattr()` clears it only if `*save == 0`. In `ext4_xattr_inode_update_ref()` under `inode_lock_nested(ea_inode, I_MUTEX_XATTR)`, `ref_count` `0 -> 1` requires `set_nlink(1)` + `ext4_orphan_del()`, and `-> 0` requires `clear_nlink()` + `ext4_orphan_add()`. [F296, F299, F301, F302]
- Verity metadata starts at `round_up(inode->i_size, 65536)` with `__le32` `desc_size` at the end of the last extent's final block (`(u64)end_lblk << inode->i_blkbits`); `ext4_get_verity_descriptor_location()` rejects `desc_size > INT_MAX || desc_size > desc_size_pos` and `desc_pos = round_down(desc_size_pos - desc_size, i_blocksize(inode)) < ext4_verity_metadata_pos(inode)`. [F310, F311, F353]

## Synchronization
- `ext4_handle_error()` sets `EXT4_FLAGS_EMERGENCY_RO` (not `SB_RDONLY`), skips `ERRORS_PANIC` when `system_going_down()`, and schedules `s_sb_upd_work` only when `continue_fs && journal && !ext4_test_mount_flag(sb, EXT4_MF_JOURNAL_DESTROY)` (else `ext4_commit_super()`); `ext4_journal_destroy()` sets `EXT4_MF_JOURNAL_DESTROY` before `ext4_force_commit()` and `flush_work(&sbi->s_sb_upd_work)`. `__ext4_grp_locked_error()` drops the group lock around `ext4_handle_error()` when `!test_opt(sb, ERRORS_CONT)`. [F240, F244, F398]
- In `__ext4_remount()`, serialize `ext4_apply_options()` and `restore_opts` under `ext4_writepages_down_write(sb)`. `sbi->s_qf_names[]` uses `rcu_read_lock()` / `rcu_dereference()` outside `s_umount` and `rcu_replace_pointer()` + RCU-freeing under `s_umount`. [F242, F243]
- `ext4_li_mtx` nests outside `eli->li_list_mtx`; at `exit_thread` in `ext4_lazyinit_thread()`, hold both and recheck `list_empty(&eli->li_request_list)` before freeing `ext4_li_info`. Drop `li_list_mtx` around `ext4_run_li_request(elr)` only while holding `down_read_trylock(&elr->lr_super->s_umount)` and `sb_start_write_trylock()`, reloading `n = pos->next` after relocking `li_list_mtx`. [F246, F247]
- Bracket online resize in `ext4_resize_begin()` / `ext4_resize_end()`. In `ext4_update_super()`, issue `smp_wmb()` before incrementing `s_groups_count` (pairing with `smp_rmb()` in `ext4_get_groups_count()`). Dereference `s_group_desc` and `s_flex_groups` via `sbi_array_rcu_deref()` and free old arrays via `ext4_kvfree_array_rcu()`. [F248, F250, F375]
- In `ext4_quota_operations`, start the JBD2 handle before `dquot_commit`/`acquire`/`release`/`commit_info`; in `ext4_release_dquot()`, call `sb_start_intwrite()` only when `!ext4_journal_current_handle()`, and still call `dquot_release()` if `ext4_journal_start()` fails. [F228, F400]
- In `bio_post_read_processing()`, disabled cases in `switch (++ctx->cur_step)` increment `ctx->cur_step` before fallthrough; `decrypt_work` and `verity_work` use separate workqueues; and in `verity_work()`, `STEP_VERITY` is the last step and `ctx` is freed to `bio_post_read_ctx_pool` with `bio->bi_private = NULL` before `fsverity_verify_bio(bio)`. [F251, F330, F373]
- In RCU-walk (`!dentry`), `ext4_encrypted_get_link()` and inline symlinks in `ext4_get_link()` return `ERR_PTR(-ECHILD)`, and block symlinks use `EXT4_GET_BLOCKS_CACHED_NOWAIT` and return `-ECHILD` if `!bh` or `!ext4_buffer_uptodate(bh)`. [F254]
- In `ext4_xattr_set_handle()`, re-read the xattr block via `ext4_xattr_get_block()` and reverify `jbd2_handle_buffer_credits(handle) >= credits` via `__ext4_xattr_set_credits()` after `ext4_write_lock_xattr()`. Call `ext4_xattr_inode_lookup_create()` before `lock_buffer(bs->bh)`; `ext4_xattr_inode_iget()` rejects `parent->i_ino == ea_ino` and calls `ext4_xattr_inode_set_class()`. [F256, F259]
- Delete `ea_block_cache` entries via `mb_cache_entry_delete_or_get()` under `lock_buffer(bh)` before modifying (`h_refcount == 1`) or freeing an xattr block. In `ext4_xattr_release_block()` when `h_refcount > 1`, call `ext4_handle_dirty_metadata()` before `unlock_buffer(bh)` if `ext4_handle_valid(handle)`, else after. `ext4_truncate_failed_write()` holds `filemap_invalidate_lock()` across `truncate_inode_pages()` and `ext4_truncate()`. In `__ext4_read_bh()`, call `clear_buffer_uptodate(bh)` before `unlock_buffer(bh)` on `simu_fail`. [F241, F258, F298, F395]

## Object Lifetimes
- In `ext4_put_super()`, call `ext4_unregister_sysfs(sb)` before destroying `s_journal` or flushing `s_sb_upd_work`, and pair `kobject_put(&sbi->s_kobj)` with `wait_for_completion(&sbi->s_kobj_unregister)` after teardown. Assign `j_commit_callback` only after `ext4_mb_init(sb)` in `__ext4_fill_super()`. Call `rcu_barrier()` before `kmem_cache_destroy(ext4_inode_cachep)`. [F221, F237, F260]
- `__ext4_fill_super()` error paths and `ext4_put_super()` must `invalidate_bdev()` `s_bdev` and `s_journal_bdev_file`, releasing `s_journal_bdev_file` via `bdev_fput()` (and clearing `sb->s_fs_info = NULL` on mount error). `ext4_apply_quota_options()` and `ext4_apply_test_dummy_encryption()` must NULL transferred fields in `ctx`. In `ext4_load_super()`, `brelse(bh)` before `sb_set_blocksize()` and NULL `bh` on error. In `ext4_register_li_request()`, set local `elr = NULL` after list insertion before `ext4_run_lazyinit_thread()`. [F222, F223, F226, F227]
- `ext4_mark_iloc_dirty()` consumes `iloc.bh` even on error, so set `iloc.bh = NULL` afterwards. In `ext4_resize_fs()`, release and NULL `resize_inode` and `flex_gd` before jumping to `retry:`. In `ext4_xattr_*_cache_find()`, `mb_cache_entry_find_next()` consumes `ce`, so call `mb_cache_entry_put()` on early exit and never before `find_next()`; `ext4_xattr_block_set()` releases and NULLs `ce` and `new_bh` on retry/cleanup. [F230, F231, F236, F340]
- After `ext4_xattr_inode_lookup_create()`, callers must `iput(ea_inode)` and on error call `ext4_xattr_inode_dec_ref()` + `ext4_xattr_inode_free_quota()`; in `ext4_xattr_block_set()`, after `ext4_xattr_inode_inc_ref_all()` on a new block, call `ext4_xattr_inode_dec_ref()`, `iput(ea_inode)`, and set `ea_inode = NULL`. `ext4_xattr_inode_dec_ref_all()` transfers `ea_inode` to `*ea_inode_array` via `ext4_expand_inode_array()` (using `struct_size` and incrementing `count` before storing into `inodes[count - 1]`), zeroes `e_value_inum`/`e_value_size` in the same transaction, and runs `ext4_xattr_restart_fn()` + `ext4_journal_get_write_access()` if `ext4_journal_ensure_credits_fn()` returns `> 0`. `ext4_read_merkle_tree_page()` must `folio_put()` non-uptodate folios from `__filemap_get_folio()` before `read_mapping_folio()`. [F220, F232, F233, F234, F303, F363]

## API Contracts
- `ext4_get_link()` calls `nd_terminate_link(bh->b_data, inode->i_size, s_blocksize - 1)` and passes `bh` to `set_delayed_call()`, while `ext4_encrypted_get_link()` clamps `max_size` to `sizeof(i_data)` / `s_blocksize` and calls `brelse(bh)`. Both check `IS_ERR(bh)` and `!bh`. `ext4_sb_bread*()` always returns `ERR_PTR(-errno)`. `__ext4_error*()`, `save_error_info()`, `ext4_error_err()`, and `ext4_abort()` take positive `errno` (or `0`); `ext4_decode_error()` and `ext4_std_error()` take negative `-errno`. `ext4_journal_ensure_credits_fn()` returns `< 0` on error, `0` if ok, `1` on restart. `ext4_count_free()` takes bytes; `ext4_mark_bitmap_end()` / `mb_set_bits()` take bits. [F218, F261, F262, F265, F273, F325, F370]
- `ext4_begin_enable_verity()` calls `ext4_inode_attach_jinode()` and `dquot_initialize()` before `ext4_convert_inline_data()` and `ext4_truncate()`. `ext4_end_enable_verity()` jumps to `cleanup` if `desc == NULL`, runs `filemap_write_and_wait()` before clearing `EXT4_STATE_VERITY_IN_PROGRESS` and setting `EXT4_INODE_VERITY`, and on error truncates post-EOF pages/blocks, deletes the orphan, and clears `EXT4_STATE_VERITY_IN_PROGRESS`. `ext4_get_verity_descriptor()` returns `desc_size` without reading if `buf_size == 0`; `ext4_read_merkle_tree_page()` / `ext4_write_merkle_tree_block()` offset `index`/`pos` by `ext4_verity_metadata_pos(inode)`. [F219, F270, F271, F272, F393]
- `ext4_readpage_limit()` allows `s_maxbytes` for `IS_VERITY(inode)`, `ext4_need_verity()` restricts `STEP_VERITY` to `< DIV_ROUND_UP(i_size, PAGE_SIZE)`, and `ext4_mpage_readpages()` verifies full-hole data folios via `fsverity_verify_folio()` and falls back to `block_read_full_folio()` if a folio has buffers, a mapped block after a hole, or discontiguous blocks. `ext4_journalled_submit_inode_data_buffers()` calls `folio_redirty_for_writepage()` before `folio_unlock()` if `ext4_journalled_writepage_needs_redirty()`. `ext4_quota_write()` requires an active handle and single-block range; `ext4_quota_enable()` sets `S_NOQUOTA` before `dquot_load_quota_inode()`. `ext4_xattr_hash_entry*()` takes `name_len` in bytes (`(unsigned char)*name`) and `value_count` in `__le32` words (`new_size >> 2`) with zeroed padding. [F358, F362, F390, F391, F397, F401]

## Error Handling
- In `__ext4_fill_super()`, after `d_make_root(root)`, clean up via `dput(sb->s_root)` (never `iput(root)`); errors after `ext4_enable_quotas(sb)` jump to `failed_mount9` (`ext4_quotas_off(sb, EXT4_MAXQUOTAS)`), and `ext4_enable_quotas()` calls `ext4_quotas_off(sb, type)` on failure. Set `sbi->s_gdb_count = i` on read error in `ext4_group_desc_init()`. In `__ext4_remount()`, handle `ABORT` last, and in `restore_opts` call `dquot_resume(sb, -1)` before restoring `sb->s_flags`. [F224, F225, F277, F280]
- Reset any `buffer_head *` or `inode *` variable to `NULL` after `PTR_ERR` before jumping to a shared `brelse()`/`iput()` label, and use `ext4_sb_bread_nofail()` or filter `-ENOMEM` where read failure triggers `ext4_error*()`. Capture `ext4_journal_stop(handle)` in `err2` and assign to `err` only if `!err`. In `ext4_xattr_inode_inc_ref_all()`, rollback only entries before `failed_entry`. Zero trailing/padding bytes in `ext4_xattr_inode_write()`, `update_backups()`, and `ext4_xattr_set_entry()` (and zero `raw_inode` + clear `EXT4_STATE_NEW` in `ext4_xattr_set_handle()`). In `ext4_mpage_readpages()`, on `ext4_map_blocks()` or `fsverity_verify_folio()` failure, zero and unlock the folio without marking it uptodate and continue. [F263, F264, F266, F267, F269, F274, F279, F338, F388]

## External Contracts
- `check_xattrs()` checks both `size > end - value` and `EXT4_XATTR_SIZE(size) > end - value`, `value >= (void *)e + sizeof(u32)`, and `offs <= end - value_start` before `buffer_verified(bh)`. In `sysfs.c`, use `__le32`/`__le64` accessors for `ptr_ext4_super_block_offset` matching field widths, format `s_*_error_func` with `%.*s` (`a->attr_size`), bound `attr_clusters_in_group` (`<= s_clusters_per_group`) and `reserved_clusters_store()` (`0 <= val < clusters`), and never dereference `sbi` in `ext4_feat_attrs`. [F278, F313, F314, F366, F367, F402]

## Known Pitfalls
- In `ext4_xattr_make_inode_space()`, restart from `IFIRST(header)` after `ext4_xattr_move_to_block()`, and NUL-terminate `entry->e_name` in an `e_name_len + 1` buffer. When cloning in `ext4_xattr_block_set()`, use local `s_copy = bs->s`, rebase `first`/`here`/`end`, and zero `e_value_inum`/`e_value_size`; in `ext4_xattr_set_handle()`, call `ext4_xattr_block_find()` on `-ENOSPC` fallback if `i_file_acl && !bs.s.base`. In `ext4_alloc_group_tables()`, initialize `bb_index`, `ib_index`, and `it_index` to 0 before `next_group:`. Use `EXT4_NUM_B2C()` (not `EXT4_B2C()`) for metadata/overhead/journal cluster counts, and widen 32-bit operands before 64-bit shifts/multiplies (`(loff_t)ppb`, `(time64_t)*hi << 32`, `div64_u64`, `(ext4_fsblk_t)group * bpg`, `(sector_t)folio->index`, `(u32)inode_peek_iversion_raw()`, and `time_before`/`time_after_eq` on `jiffies`). [F294, F297, F332, F334, F347, F348, F349, F350, F351, F352, F355, F356, F364]
