# EXTENSIBLE FIRMWARE INTERFACE (EFI) — (top level) (part 1)

This component implements core EFI infrastructure (`drivers/firmware/efi/efi.c`), architecture-specific EFI initialization and virtual memory mapping (ARM, ARM64, LoongArch, RISC-V, x86), UEFI Capsule updates, CPER error parsing, ESRT sysfs, earlycon, BGRT, Apple device properties, and embedded firmware extraction.

## Architecture & Data Flow

- On x86_64, `efi_map_region()` and `efi_map_region_fixed()` map regions in `efi_mm.pgd` at both `md->phys_addr` (1:1) and `md->virt_addr`, so `efi_update_mappings()` and `efi_unmap_pages()` must update/unmap both in lockstep. `efi_map_next_entry()` must iterate `efi.memmap` in reverse (`efi_map_next_entry_reverse()`) because virtual addresses are allocated top-down from `EFI_VA_START` while `EFI_PROPERTIES_TABLE` requires ascending virtual addresses. [F59, F84]
- On x86_64, `arch_efi_call_virt_setup()` must run `efi_sync_low_kernel_mappings()`, `efi_fpu_begin()`, `firmware_restrict_branch_speculation_start()`, and `efi_enter_mm()`; `arch_efi_call_virt_teardown()` reverses this exact order. `efi_sync_low_kernel_mappings()` (also required before `efi_thunk_set_virtual_address_map()`) must skip PUD entries in `[EFI_VA_END, EFI_VA_START)`. [F60, F144]
- On arm64 with `system_uses_ttbr0_pan()`, `efi_set_pgd()` must call `update_saved_ttbr0(current, mm)`, `uaccess_ttbr0_enable()`, and `post_ttbr_update_workaround()` when entering `efi_mm`, and `uaccess_ttbr0_disable()` plus `update_saved_ttbr0(current, current->active_mm)` on exit. On 32-bit ARM with `CONFIG_CPU_TTBR0_PAN`, `arch_efi_call_virt()` must bracket calls with `uaccess_save_and_enable()` and `uaccess_restore(flags)`. [F141, F142]
- In ARM `efi_create_mapping()`, test `md->attribute` in an `if`/`else if` chain ordered `EFI_MEMORY_WB`, `EFI_MEMORY_WT`, `EFI_MEMORY_WC`, then `MT_DEVICE`. In arm64 `create_mapping_protection()` and riscv `efimem_to_pgprot_map()`, test `(attr & (EFI_MEMORY_XP | EFI_MEMORY_RO)) == (EFI_MEMORY_XP | EFI_MEMORY_RO)` before `attr & EFI_MEMORY_RO`. In arm64 `create_mapping_protection()`, `code_is_misaligned` must stay `static` and latched via `|=` so subsequent misaligned runtime regions get `PAGE_KERNEL_EXEC`. [F90, F91, F92]
- In x86 `should_map_region()`, `EFI_MEMORY_RUNTIME` (`true`) must precede all exclusions, and `EFI_CONVENTIONAL_MEMORY` with `EFI_MEMORY_SP` (`efi_soft_reserve_enabled()`, `false`) must precede `efi_is_mixed()`. In `efi_merge_regions()`, merging `md` into `prev_md` must set `md->type = EFI_RESERVED_TYPE`, `md->attribute = 0`, and `continue` without updating `prev_md = md`. [F93, F94]
- In x86 `efi_reserve_boot_services()`, boot services regions already memblock-reserved or failing `can_free_region()` must get `EFI_MEMORY_RUNTIME`. In `efi_free_boot_services()`, regions with `EFI_MEMORY_RUNTIME` or `< SZ_1M` must never be passed to `memblock_free_late()`, and both descriptor loops must use the exact same filter (skipping all non-`EFI_MEMORY_RUNTIME` boot services descriptors). On kexec, `efi_reuse_config()` must set `EFI_MEMORY_ATTRIBUTES_TABLE_GUID`'s table address to `EFI_INVALID_TABLE_ADDR`. [F52, F96, F160]
- In `capsule-loader.c`, `cap_info->pages` and `cap_info->phys` (sized with `sizeof(phys_addr_t)`, not `sizeof(void *)`) must be allocated in `efi_capsule_open()`, resized in `__efi_capsule_setup_info()`, and populated at `cap_info->index` in `efi_capsule_write()` in lockstep before incrementing `cap_info->index`. In `efi_capsule_update()`, scatter-gather allocation must use `DIV_ROUND_UP(imagesize, PAGE_SIZE)` and `sg_pages_num(count)` (`SGLIST_PER_PAGE` reserves 1 continuation slot per page), clamping block lengths to `PAGE_SIZE - (u64)*pages % PAGE_SIZE`. [F55, F112, F114]
- `__efi_mem_desc_lookup()` must reject `md->num_pages <= 0` or `> (U64_MAX - md->phys_addr) >> EFI_PAGE_SHIFT`. `efi_memmap_entry_valid()` must reject `md->num_pages == 0`, `> EFI_PAGES_MAX`, or `EFI_PAGES_MAX - md->num_pages < (md->phys_addr >> EFI_PAGE_SHIFT)`. Buffer iteration/copying in `efi.memmap` must use `desc_size`, whereas copying a single descriptor into a standalone `efi_memory_desc_t` variable/member must use `sizeof(efi_memory_desc_t)`. [F106, F107, F115, F116]
- `efi_esrt_init()` must verify `tmpesrt.fw_resource_count <= 128` and that header + entries fit within `efi_mem_desc_end(&md) - efi.esrt`. In `efi_get_fdt_params()`, a missing `j == 0` (`SYSTAB`) jumps to `notfound` silently, while `j > 0` logs `pr_err()`; `efi_get_fdt_prop()` must write `*(u64 *)var` when `size == 8` and saturating `*(u32 *)var` otherwise. In `efi_earlycon_setup()`, if `screen_info.orig_video_isVGA != VIDEO_TYPE_EFI`, set `fb_probed = true` after option parsing so `init_screen_info()` triggers `efi_earlycon_reprobe()`. [F77, F105, F124, F128]
- In `cper_estatus_print_section()`, verify `gdata->error_data_length` is at least the section header size (`sizeof(*proc_err)`, `sizeof(struct cper_sec_mem_err_old)`, `sizeof(*pcie)`, `sizeof(*arm_err)`, `sizeof(*ia_err)`, `SZ_16`, `sizeof(*prot_err)`) before dereferencing payload. In `cper_print_fw_err()`, trailing data offset in `cper_sec_fw_err_rec_ref` is `offsetof(..., record_identifier_guid)` (rev 0), `offsetof(..., record_identifier)` (rev 1), or `sizeof(*fw_err)` (rev >= 2). [F79, F81]

## Synchronization

- On arm64, `arch_efi_call_virt_setup()` calls `efi_virtmap_load()` (disabling preemption), takes `efi_rt_lock`, and calls `__efi_fpsimd_begin()`; `arch_efi_call_virt_teardown()` must unwind in reverse (`__efi_fpsimd_end()`, `raw_spin_unlock(&efi_rt_lock)`, `efi_virtmap_unload()`). On x86_64 mixed mode, `efi_thunk()` requires holding `efi_runtime_lock` with IRQs disabled, while `*_nonblocking` thunks must use `spin_trylock_irqsave()` and return `EFI_NOT_READY` on contention. [F17, F29]
- In `efi_capsule_update()`, populate `sg_pages`, flush cache via `efi_capsule_flush_cache_range()`, and unmap before taking `capsule_mutex` and calling `efi_capsule_update_locked()`. `efi_capsule_update_locked()` and `capsule_reboot_notify()` must hold `capsule_mutex` when accessing `stop_capsules`, `efi_reset_type`, or `capsule_pending`; runtime callers must not use lockless `efi_capsule_pending()`. [F24, F25, F150]
- `efi_check_for_embedded_firmwares()` must populate `efi_embedded_fw_list` before setting `efi_embedded_fw_checked = true` (which `efi_get_embedded_fw()` checks first), and on x86 must run in `__efi_enter_virtual_mode()` before `efi_free_boot_services()`. [F13, F32]
- `efi_mem_reserve_persistent()` and `efi_mem_reserve_iomem()` must use `GFP_ATOMIC`, claim slots via `atomic_fetch_add_unless(&rsv->count, 1, rsv->size)`, hold `efi_mem_reserve_persistent_lock` when linking into `efi_memreserve_root->next`, and size/reserve new entries with `SZ_4K` (`EFI_MEMRESERVE_COUNT(SZ_4K)`), not `PAGE_SIZE`. [F153, F167]
- When `nonblocking` is true, `efi_query_variable_store()` must call `query_variable_store_nonblocking()` via `efi.query_variable_info_nonblocking()` without `GFP_KERNEL` allocations or blocking `efi.set_variable()` calls. Both must return `efi_status_t`, never negative errno. [F33, F40]

## Object Lifetimes

- When `efi_capsule_update()` returns 0, neither `sg_pages[i]` nor `cap_info->pages` may be freed; `efi_capsule_update()` only frees `sg_pages[i]` when `rv != 0` (always freeing the `sg_pages` array). `cap_info->index` must be set to `NO_FURTHER_WRITE_ACTION` (`-1`) when `efi_free_all_buff_pages()` frees pages on failure and when `efi_capsule_submit_update()` succeeds. [F1, F56]
- In `efivar_ssdt_load()`, `acpi_load_table(data, NULL)` takes ownership of `data` on success; only `kfree(data)` when `efi.get_variable()` or `acpi_load_table()` fails. In `efi_query_variable_store()`, if the dummy `efi.set_variable()` returns `EFI_SUCCESS`, call `efi_delete_dummy_variable()` before `kfree(dummy)`. [F4, F21]
- `efi_memmap_install()` must only call `__efi_memmap_free()` after `efi_memmap_unmap()` and a successful `__efi_memmap_init(data)`; `__efi_memmap_init()` must never free the old physical map. In `efi_init()` (`efi-init.c`), `early_init_dt_check_for_usable_mem_range()` must run after `reserve_regions()`, and `uefi_init()` failure must call `efi_memmap_unmap()`. [F5, F18]
- In `apple-properties.c`, `map_properties()` must only free `pa_data + sizeof(*data)` (length `data_len`) via `memblock_free_late()` after setting `data->len = 0` and unmapping `data`, preserving the `setup_data` header. `unmarshal_devices()` must allocate `dev_header->prop_count + 1` `property_entry` elements and free `entry[i].name`, `entry`, and `put_device(dev)` after `device_create_managed_software_node()`; in `unmarshal_key_value_pairs()`, subtract `sizeof(u32)` from `key_len` and `val_len`. [F8, F9, F71, F72]
- `esrt_sysfs_init()` cleanup must unwind in reverse: `cleanup_entry_list()` (using `list_for_each_entry_safe()` as `kobject_put()` -> `esre_release()` deletes/frees entries), `kset_unregister(esrt_kset)`, `sysfs_remove_group()`, `kobject_put(esrt_kobj)`, and `memunmap(esrt)` with `esrt = NULL`. `efisubsys_init()` cleanup must unwind: `sysfs_remove_group()`, `generic_ops_unregister()`, `kobject_put(efi_kobj)` with `efi_kobj = NULL`, and `destroy_workqueue(efi_rts_wq)`. [F10, F11, F99]
- In `efi_earlycon_unmap_fb()`, only call `memunmap(efi_fb)` when `!console_is_registered(earlycon_console)`. In `efi_bgrt_init()`, any failure after copying `*table` into `bgrt_tab` must jump to `out:` to zero `bgrt_tab` and skip `efi_mem_reserve()`. In x86_64 `efi_alloc_page_tables()`, allocate `efi_pgd` with `__get_free_pages()` (not `pgd_alloc()`), and on `pud_alloc()` failure free the 5-level p4d page (`pgtable_l5_enabled()`) before `efi_pgd`. [F19, F20, F22]

## API Contracts

- `efi_get_embedded_fw()` returns a borrowed pointer in `*data` to `fw->data`; callers must copy it and never `kfree(*data)`. In x86 `realloc_pages(old_memmap, old_shift)`, `old_memmap` is always freed even when returning `NULL`. [F14, F15]
- `efi_get_device_by_path()` must run at `fs_initcall` or later; callers jumping to shared `put_device(dev)` cleanup must set `dev = NULL` on `IS_ERR(dev)`. Node parsers (`parse_acpi_path()`, `parse_pci_path()`, `parse_end_path()`) must check `node->header.length`, return a refcounted `*child` (in `parse_acpi_path()`, calling `get_device(phys_dev)` and `acpi_dev_put(adev)` when `phys_dev` is non-NULL, or transferring `adev` when NULL), and only `parse_end_path()` may return `> 0`. [F7, F41, F73, F132, F133]
- `__setup()` handlers (`efivar_ssdt_setup`, `dump_properties_enable`) return 1 on success; `early_param()` handlers return 0. `efi_mem_type()` returns a signed int (`0` is `EFI_RESERVED_TYPE`, or `< 0` on error), whereas `efi_mem_attributes()` returns a `u64` mask or `0`. Every `efi_config_table_type_t` array passed to `efi_config_parse_tables()` must end with a `{}` (`NULL_GUID`) sentinel. [F38, F39, F83]
- Capsule quirks (e.g., `qrk_capsule_setup_info()`) return `> 0` to proceed to `__efi_capsule_setup_info()`, `0` when `hdr_bytes` is too small, or `< 0` on error. `efi_capsule_submit_update()` must only `vmap()`/`vunmap()` `cap_info->capsule` when it was `NULL`. [F43, F57]
- `efi_memmap_insert()` requires `EFI_PAGE_SIZE`-aligned `mem->range.start` and `end + 1`, and `buf` sized for `old_memmap->nr_map + efi_memmap_split_count(&md, &mem->range)` entries; its four unchained `if` blocks must remain mutually exclusive and match `efi_memmap_split_count()`. [F85, F97]
- Gate `generic_ops.set_variable` and `efibc_reboot_notifier` registration on `efi_rt_services_supported(EFI_RT_SUPPORTED_SET_VARIABLE)`. Drivers retaining `EFI_BOOT_SERVICES_DATA` across boot (`efi_esrt_init()`, `efi_bgrt_init()`) must call `efi_mem_reserve()`; on x86, `efi_arch_mem_reserve()` requires a single `EFI_BOOT_SERVICES_DATA` descriptor and must update `e820_table` to `E820_TYPE_RESERVED` via `e820__range_update()` and `e820__update_table()`. `reserve_unaccepted()` must page-align `efi.unaccepted` and call `memblock_add()` before `memblock_reserve()`. [F62, F127, F131, F168]
- On arm64, `efi_runtime_fixup_exception()` requires `current_in_efi()` and `regs->pc < TASK_SIZE_64`, restoring `x30` from `efi_rt_stack_top[-1]` and `x18` from `efi_rt_stack_top[-2]` (`CONFIG_SHADOW_CALL_STACK`). On x86_64, all runtime calls (including `set_virtual_address_map`) must use `arch_efi_call_virt()` (not `efi_call()`) to save/restore IBT via `ibt_save(efi_disable_ibt_for_runtime)`/`ibt_restore(ibt)`. [F140, F143]
- `efi_set_mapping_permissions()` (arm, arm64, riscv) must only call `apply_to_page_range()` on page-mapped `efi_mm` regions (skipping ARM32 section mappings and arm64 `region_is_misaligned(md)`). In `set_permissions()`, `EFI_MEMORY_RO` and `EFI_MEMORY_XP` updates must accumulate into local `pte`/`val` before writing `*ptep`. [F54, F151]
- `cper_estatus_check()`, `cper_estatus_check_header()`, and `cper_estatus_print()` run in NMI/hardirq/panic contexts and must not sleep. `cper_estatus_check()` must validate `raw_data_offset >= sizeof(*estatus) + estatus->data_length` and that each section's `acpi_hest_get_size(gdata)` and `acpi_hest_get_record_size(gdata)` fit in `data_len` until `data_len == 0`. [F78, F154]

## Error Handling

- Optional table addresses in `struct efi` (`acpi`, `smbios`, `esrt`, `tpm_log`, `mokvar_table`, `coco_secret`, `unaccepted`) are initialized to `EFI_INVALID_TABLE_ADDR` (`~0UL`), not `0`. Check optional runtime pointers (`efi.get_next_variable`, `generic_ops.get_variable`) for non-NULL before calling or unregistering. [F34, F35]
- In `efi_mem_reserve_persistent()`, check `efi_memreserve_root` against both `(void *)ULONG_MAX` and `NULL`, and check each `memremap()` return for `NULL`. On x86_64, `efi_crash_gracefully_on_page_fault()` must return if `in_interrupt()`, `efi_rts_id == EFI_NONE`, `current_work() != &efi_rts_work.work`, or `phys_addr <= 0x0fff`, and otherwise run `arch_efi_call_virt_teardown()`, complete `efi_rts_comp`, and park in `TASK_IDLE` `schedule()`. [F37, F148]

## External Contracts

- In x86 mixed mode, `__efi64_argmap_<func>` must match the exact `mixed_mode` method name in `efi_fn_call()`, zero upper 32 bits of output pointers via `efi64_zero_upper()`, split 64-bit values via `__efi64_split()`, and widen status via `__efi64_widen_efi_status()`. Variable thunks (`efi_thunk_*_variable()`) reject non-linear page-crossing buffers via `virt_to_phys_or_null_size()` and must copy `vendor` into `PTR_ALIGN((efi_guid_t *)buf, sizeof(*vnd))`. [F53, F87, F88]
- Do not add new fields to `systab_show()`, and keep `SMBIOS3=` printed before `SMBIOS=`. Sysfs attributes in `runtime-map.c`, `esrt.c`, and `efi_attr_systab` must use mode `0400` (`__ATTR_RO_MODE(..., 0400)`). [F165, F166]

## Known Pitfalls

- In `reserve_regions()` (`efi-init.c`), decrement `r--` after `memblock_remove(r->base, r->size)` inside `for_each_mem_region(r)`. Shift `md->num_pages` by `EFI_PAGE_SHIFT` (12), not `PAGE_SHIFT`, when converting directly to bytes. Cast split upper 32-bit address fields (`efi_memmap_hi`, `efi_systab_hi`, `ext_lfb_base`) to `u64` before `<< 32`. [F98, F108, F111]
- In `cper_print_proc_arm()` and `cper_print_proc_ia()`, advance `ctx_info` by `ALIGN(sizeof(*ctx_info) + reg_size, 16)` bytes, not `ctx_info++`. In `cper.c`, format `gdata->fru_text` with `%.20s` and accumulate buffer offsets in `cper_mem_err_location()` and `cper_print_bits()` with `scnprintf()`, not `snprintf()`. On x86, `efi_config_init()` and `efi_config_parse_tables()` must index config tables as `efi_config_table_64_t` when `efi_enabled(EFI_64BIT)` and `efi_config_table_32_t` otherwise. [F122, F123, F125]
