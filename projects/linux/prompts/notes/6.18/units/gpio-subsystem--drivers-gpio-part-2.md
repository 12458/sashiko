# GPIO SUBSYSTEM — drivers/gpio (part 2)

This component contains GPIO controller drivers (`gpio-max732x.c` to `gpio-sifive.c`), the generic MMIO GPIO library (`gpio-mmio.c`), and the single-register helper (`gpio-reg.c`) for SoC MMIO blocks, I2C/SPI expanders, USB MPSSE bridges, and firmware mailbox expanders.

## Architecture & Data Flow

- In `gpio-mmio.c`, `chip->bits` must remain the physical width `cfg->sz * 8` even if `gc->ngpio` is smaller (for big-endian `BIT(chip->bits - 1 - line)` in `bgpio_line2mask()`). `bgpio_line2mask()`, `chip->sdata`, and `chip->sdir` must use `unsigned long` and `BIT()` for 64-bit registers. When `chip->be_bits` (`GPIO_GENERIC_BIG_ENDIAN`) is true, `bgpio_setup_io()` must never assign `bgpio_get_multiple` or `bgpio_get_set_multiple`. [F72, F100, F126]
- In `struct gpio_generic_chip`, `reg_dir_in` and `reg_dir_out` are independently optional and must be null-checked before `read_reg`/`write_reg`. `chip->sdir` uses `1` = out, `0` = in; direction updates must write `chip->sdir` to `reg_dir_out` and `~chip->sdir` to `reg_dir_in`. `bgpio_get_dir()` must check `chip->dir_unreadable` first and invert `reg_dir_in` (`0` = out, `1` = in). [F33, F49, F87]
- In `gpio-mmio.c`, `bgpio_setup_io()` must always set `gc->set` (`bgpio_set_none` for `GPIO_GENERIC_NO_OUTPUT`), and any setter migration must update `bgpio_simple_dir_out()`, `bgpio_dir_out_dir_first()`, `bgpio_dir_out_val_first()`, and `gpio_generic_chip_set()` in lockstep. In `bgpio_pdev_probe()`, optional MMIO resources (`"set"`, `"clr"`, `"dirout"`, `"dirin"`) must match the `"dat"` `resource_size()`. [F51, F71]
- In `gpio-pca953x.c`, `ngpio <= MAX_LINE` (40); `NBANK(chip)` must use `DIV_ROUND_UP(chip->gpio_chip.ngpio, BANK_SZ)` for partial banks (4/18/34-pin chips), and `pca953x_bank_shift()` must compute `fls((chip->gpio_chip.ngpio - 1) / BANK_SZ)` after `ngpio > 0` is set. `pisosr_gpio_probe()` must also size `gpio->buffer_size` via `DIV_ROUND_UP(gpio->chip.ngpio, 8)`. [F103, F104, F107, F109]
- In `gpio-pca953x.c`, `pca953x_irq_setup()` seeds `chip->irq_stat` from `regs->input & regs->direction`, and `pca953x_irq_pending()` must compare `regs->input & reg_direction` against `chip->irq_stat` under `chip->i2c_lock` (not separate I2C status/input reads). On `PCA_PCAL`, `pca953x_irq_bus_sync_unlock()` must write `irq_mask` to `PCAL953X_IN_LATCH`, `~irq_mask` to `PCAL953X_INT_MASK` under `i2c_lock`, and switch triggered outputs to inputs. [F55, F124]
- In `pca953x_restore_context()`, `pca953x_regcache_sync()` must run before `regcache_sync()` and sync `direction` and `output` (plus `IN_LATCH`/`INT_MASK` on `PCA_PCAL`) first. In `pca953x_gpio_set_pull_up_down()`, `PIN_CONFIG_BIAS_PULL_PIN_DEFAULT` and `PIN_CONFIG_BIAS_DISABLE` leave `PCAL953X_PULL_SEL` unchanged (`ret = 0`), after which only `BIAS_DISABLE` clears `PCAL953X_PULL_EN`. [F53, F89]
- In `gpio-mxc.c`, `GPIO_EDGE_SEL` (`edge_sel_reg`) is `-EINVAL` when absent, so `gpio_set_irq_type()` must check `GPIO_EDGE_SEL >= 0` and only store validated `IRQ_TYPE_* <= IRQ_TYPE_LEVEL_LOW` (8) into `port->pad_type[gpio_idx]` (used to index 9-element `pad_type_map[]`). `mxc_gpio_noirq_resume()` must call `mxc_gpio_set_pad_wakeup(port, false)` and clear `port->is_pad_wakeup = false`. `mxc_gpio_runtime_suspend/resume()` must detach chained IRQ handlers while `port->clk` is disabled (and on `clk_prepare_enable()` error). [F45, F61, F81, F129]
- In `gpio-rcar.c`, `gpio_rcar_config_interrupt_input_mode()` must program `POSNEG`, `EDGLEVEL`, and `BOTHEDGE` under `p->lock` before setting `IOINTSEL`, and write `BIT(hwirq)` to `INTCLR` when `!level_trigger`. `gpio_rcar_config_general_input_output_mode()` must clear `POSNEG` and `IOINTSEL` under `p->lock` alongside `INOUTSEL`. When `!p->info.has_always_in`, `gpio_rcar_get/_multiple()` must read `OUTDT` for outputs (`INOUTSEL` set) and `INDT` for inputs. [F62, F131, F132]
- In `gpio-mpsse.c`, `gpio_mpsse_probe()` must send `SET_BITMODE_REQUEST` with `MODE_RESET` (`0`) before `MODE_MPSSE` (`2 << 8`). `mpsse_read()` must clamp `desc.len` to `min_t(size_t, len + 2, usb_endpoint_maxp(priv->bulk_in))`, check `desc.len_actual >= desc.len`, and strip the 2-byte status header from `priv->bulk_in_buf`. `gpio_mpsse_poll()` must init/reset `old_value[offset] = -1` when disabled/masked and skip edge detection when `-1`. [F58, F117, F138]
- In `gpio-max732x.c`, `max732x_setup_gpio()` uses `i` (`0..15`) for feature slots (`i < 8` Group A) and increments `port` (`mask = 1 << port`) only after skipping `PORT_NONE`. In `max732x_gpio_direction_input()`, pins in both `dir_input` and `dir_output` (`PORT_OPENDRAIN`) require `max732x_gpio_set_value(gc, off, 1)`. [F60, F92]
- In `gpio-mpc8xxx.c`, lines use big-endian `mpc_pin2mask(offset)` (`BIT(31 - offset)`). `mpc8572_gpio_get()` reads outputs from `sdata & out_mask` and inputs from `GPIO_DAT & ~out_mask`; `mpc5121_gpio_dir_out()` and `mpc5125_gpio_dir_out()` reject input-only lines `28..31` and `0..3`. On QorIQ/Layerscape/ACPI, `mpc8xxx_probe()` must write `0xffffffff` to `GPIO_IBE` and set `sdata = GPIO_DAT & GPIO_DIR`. [F83, F143, F144]
- In `gpio-realtek-otto.c`, `realtek_gpio_probe()` must enforce `ngpios <= REALTEK_GPIO_MAX` (32) and cap `nr_cpus` to `min(resource_size(res) / REALTEK_GPIO_PORTS_PER_BANK, num_present_cpus())`. `realtek_gpio_irq_set_type/mask/unmask()` must update `intr_type[line]` and `intr_mask[line]` under `ctrl->lock` and write their bitwise AND via `realtek_gpio_update_line_imr()`, splitting `line_shift = ctrl->line_imr_pos(line)` into word offset `4 * (line_shift / 32)` and shift `line_shift % 32`. [F63, F79, F105]
- In `gpio-pl061.c`, `pl061_direction_output()` must write `!!value << offset` to `base + BIT(offset + 2)` both before and after setting `GPIODIR` under `pl061->lock`, and `pl061_suspend()` must zero `csave_regs.gpio_data` before ORing in output values. In `gpio-reg.c`, `gpio_reg_init()` sets `to_irq` only when `irqs` is non-NULL, and `gpio_reg_get()` returns `r->out` for outputs and reads `r->reg` twice for inputs. [F47, F65, F134, F145]
- In `gpio-mlxbf3.c`, `mlxbf3_gpio_irq_disable()` must clear `BIT(offset)` in `MLXBF_GPIO_CAUSE_OR_CLRCAUSE` after clearing `EVTEN0`, and `mlxbf3_gpio_shutdown()` must zero `EVTEN0` and clear all ints. In `pcf857x_probe()`, when `reset_gpio` is present, pulse it (`fsleep(4)` high, `fsleep(100)` low) and keep `n_latch = 0` instead of reading `"lines-initial-states"`. In `gpio-sch311x.c`, `request`/`free` must reject `config_regs[offset] == 0`. In `mediatek_gpio_irq_type()` and `sa1100_gpio_type()`, handle `IRQ_TYPE_PROBE` before altering trigger bitmaps. [F82, F90, F125, F140]

## Synchronization

- In `gpio-mmio.c`, `chip->lock` (`raw_spin_lock_irqsave`) must cover every `chip->sdata` or `chip->sdir` update and its `chip->write_reg()` call, but `bgpio_dir_in()` and `bgpio_dir_out()` must drop `chip->lock` before calling `gc->set()` or `bgpio_dir_return()`. [F16, F17]
- In `gpio-pca953x.c`, `pca953x_probe()` must set clientdata, `driver_data`, `ngpio`, and `check_reg` before `devm_regmap_init_i2c()`, and set `chip->i2c_lock` subclass to `i2c_adapter_depth(client->adapter)`. Since regmap has `.disable_locking = true`, all post-probe regmap accesses (and `disable/enable_irq` + `regcache_cache_only` in save/restore context) must hold `chip->i2c_lock`. Lock order is `irq_lock` before `i2c_lock`; `irq_mask/unmask/set_type/shutdown` only touch bitmaps, and `pca953x_irq_handler()` must drop `i2c_lock` before `handle_nested_irq()`. [F18, F19, F21, F54, F149, F151]
- In `gpio-mpsse.c`, `priv->irq_mutex` nests outside `priv->io_mutex`, and `gpio_mpsse_direction_output()` must drop `io_mutex` before `gpio_mpsse_gpio_set()`. `mpsse_read()` callers must hold `io_mutex` (protecting `bulk_in_buf`), and `set_multiple`/`direction_output`/`direction_input` must update `gpio_outputs[bank]` and `gpio_dir[bank]` under `io_mutex` and send both via `SET_BITS_CMD`. [F23, F57, F155]
- In `gpio-max732x.c`, lock order is `irq_lock` before `chip->lock`; `max732x_irq_update_mask()` must hold `chip->lock` and OR `reg_out[0]` with `irq_mask` when writing `client_group_a`. In `gpio-pcf857x.c`, `gpio->lock` protects `out`, `status`, and `irq_enabled`, and must be dropped before `handle_nested_irq()`. In `gpio-pmic-eic-sprd.c`, `irq_mask/unmask/set_type` only update `pmic_eic->reg[]` under `buslock`, deferring regmap I/O to `bus_sync_unlock()`. [F29, F59, F160, F161]
- In `gpio-mlxbf2.c`, writes to `YU_GPIO_MODE0_SET/CLEAR` or `MODE1_CLEAR` must be bracketed by `mlxbf2_gpio_lock_acquire()` and `mlxbf2_gpio_lock_release()` (holding mutex `yu_arm_gpio_lock_param.lock` then `raw_spinlock_t` `gs->chip.lock`); callers must not sleep while held or call release on acquire failure. [F67, F156]
- In `gpio-mxc.c`, `GPIO_ICR1`/`GPIO_ICR2` RMWs in `gpio_set_irq_type()` and `mxc_flip_edge()` must hold `gpio_generic_lock_irqsave(&port->gen_gc)`, dropping it before `direction_input()`. In `gpio-sifive.c` (`.disable_locking = true`), post-probe `chip->regs` accesses must hold `gpio_generic_lock_irqsave(&chip->gen_gc)`, dropping it in `sifive_gpio_irq_enable()` before `direction_input()` or `sifive_gpio_set_ie()`. [F158, F159]
- In `gpio-pl061.c`, `pl061->lock` is used in hardirq context, so non-IRQ callers must use `raw_spin_lock_irqsave()`. In `gpio-realtek-otto.c`, `realtek_gpio_irq_cpu_mask()` loops must iterate only over `ctrl->cpu_irq_maskable` (under `raw_spin_lock_irqsave(&ctrl->lock, ...)` in `set_affinity`). In `gpio-rdc321x.c`, `gpch->lock` must cover `data_reg` and PCI config RMWs. In `gpio-mpc5200.c`, `gpio_lock` (`spin_lock_irqsave`) must cover `shadow_dvo/ddr/gpioe` updates and `__mpc52xx_*_gpio_set()`. In `gpio-mm-lantiq.c`, `ltq_mm_apply()` must hold `ebu_lock` while toggling `LTQ_EBU_WP`. In `gpio-sch311x.c`, `sch311x_sio_enter/exit()` must bracket `0x55`/`0xaa` keys with `request_muxed_region`/`release_region`. [F30, F141, F142, F162, F163, F164]

## Object Lifetimes

- In `gpio-rcar.c`, `gpio_rcar_parse_dt()` must call `of_node_put(args.np)` when `of_parse_phandle_with_fixed_args()` returns 0. `gpio_rcar_request()` must call `pm_runtime_put(p->dev)` if `pm_runtime_get_sync()` or `pinctrl_gpio_request()` fails; `gpio_rcar_free()` must switch the pin to input before `pm_runtime_put()`. `gpiochip_remove()` must precede `pm_runtime_disable()` in probe error and remove. [F1, F2, F3, F133]
- In `mxc_gpio_probe()`, failure after `pm_runtime_enable()` must jump to `out_bgio` or `out_irqdomain_remove` to balance runtime PM and `irq_domain_remove()`, and `list_add_tail(&port->node, &mxc_gpio_ports)` must happen only after all fallible steps succeed. In `gpio-pca953x.c`, `pca953x_suspend/resume()` must disable/enable `chip->regulator` only when `!atomic_read(&chip->wakeup_path)`. [F4, F5, F8]
- `mpc8xxx_probe()` error paths and `mpc8xxx_remove()` must call `irq_domain_remove(mpc8xxx_gc->irq)`. `mb86s70_gpio_remove()` must call `acpi_gpiochip_free_interrupts()` before `gpiochip_remove()`. `men_z127_probe()` must register `men_z127_release_mem` via `devm_add_action_or_reset()` immediately after `mcb_request_mem()`. `sch311x_gpio_pdev_add()` must call `platform_device_put()` on failure after `platform_device_alloc()`. `rpi_exp_gpio_probe()` and `mxs_gpio_probe()` must call `of_node_put()` on the `of_get_parent()` node. [F11, F12, F13, F14, F15]
- `girq->parents` (when `num_parents > 0`), `names`/`irqs` passed to `gpio_reg_init()`, and `sch311x_gpio_blocks` are stored by pointer and must have non-stack, non-`__initdata`/`__initconst` lifetime. [F118, F119, F120]

## API Contracts

- In `bgpio_get_set_multiple()`, `bgpio_get_multiple()`, `bgpio_get_multiple_be()`, and `pcf857x_get_multiple()`, `*bits` must be masked with `~*mask` before ORing in read values. [F50]
- In `gpio-mmio.c`, `gpio_generic_chip_init()` requires `cfg->sz` in bytes (power of 2, `cfg->sz * 8 <= BITS_PER_LONG`, no `GPIO_GENERIC_BIG_ENDIAN_BYTE_ORDER` when `sz == 8`) and `gc.ngpio <= chip->bits`; internal callbacks must use `to_gpio_generic_chip(gc)`, never `gpiochip_get_data(gc)`. In `gpio-mt7621.c`, callbacks must use `to_mediatek_gpio(chip)` for `struct mtk_gc *` and `gpiochip_get_data(chip)` for `struct mtk *`. In `gpio-rtd.c`, `irq_desc_get_handler_data(desc)` in `rtd_gpio_irq_handle()` returns `struct rtd_gpio *` directly. [F113, F114, F115, F121, F173]
- `gpio_chip.set_config` callbacks must return `-ENOTSUPP` for unsupported parameters and convert `PIN_CONFIG_INPUT_DEBOUNCE` arguments from microseconds. Shared parent IRQs (`IRQF_SHARED`) must use `devm_request_irq()` with `girq->parent_handler = NULL` and `num_parents = 0`. Non-nested `irq_chip`s using `handle_edge_irq` must define `.irq_ack`. [F171, F172, F177, F178]

## Error Handling

- `bgpio_map()` returns `NULL` when an optional resource is absent and `IOMEM_ERR_PTR()` on error, so `bgpio_pdev_probe()` must check `IS_ERR()`, not `IS_ERR_OR_NULL()`. In `rpi_exp_gpio_probe()`, `devm_rpi_firmware_get()` returns `NULL` on unavailability (check `!fw`, put `fw_node`, return `-EPROBE_DEFER`). Check `devm_mutex_init()` returns in `gpio_mpsse_probe()` and `pisosr_gpio_probe()`, pass negative errnos (never `client->irq`) to `dev_err_probe()`, and use `platform_get_irq_optional()` in `mlxbf2/mlxbf3/realtek/sifive` probes. [F32, F37, F38, F42, F165]
- Check `< 0` on signed `int` returns from `gpio_mpsse_get_bank()` and `pcf857x` `gpio->read()`; convert positive `i2c_master_send()` counts to `0` in `i2c_write_le16()` and `PCIBIOS_*` codes via `pcibios_err_to_errno()` in `gpio-rdc321x.c`. [F39, F43, F44]

## External Contracts

- In `gpio-raspberrypi-exp.c`, `rpi_firmware_property()` calls must pass `off + RPI_EXP_GPIO_BASE` in `.gpio`, check both `ret == 0` and `.gpio == 0` on return, and preserve existing polarity via `rpi_exp_gpio_get_polarity()` in `rpi_exp_gpio_dir_in/out()`. In `gpio-mpsse.c`, `SET_BITMODE_REQUEST` must pass `priv->intf_id + 1` as `wIndex`. In `gpio-mmio.c`, `"gpio-mmio,base"` requires `base <= INT_MAX` and must not be used in DT. [F66, F69, F73, F76]

## Known Pitfalls

- In `gpio-pca953x.c`, `chip->check_reg` is `NULL` on `TCA6418_TYPE`, so regmap callbacks must dispatch `TCA6418_TYPE` first; single-line masks must use `pca953x_get_bit_mask()` (reversing bits only in bank 0 on `TCA6418_TYPE`); `pcal6534_check_register()` must test `reg >= 0x54` before `reg >= 0x30`; bitmap ops on `pca953x_read_regs()` output must use `gc->ngpio`, not `MAX_LINE`. [F52, F78, F86, F110]
- `struct gpio_chip` must stay at offset 0 of `struct mpsse_priv`, `struct pcf857x`, and `struct max732x_chip`. In `gpio-mxc.c` and `gpio-mxs.c`, `irq_data_get_irq_chip_data(d)` is `struct irq_chip_generic *` (port in `gc->private`), not `struct gpio_chip *`. In `gpio-rc5t583.c`, pass MFD parent `rc5t583_gpio->rc5t583->dev`, not `gc->parent`. [F98, F99, F112]
- In `gpio-rtd.c`, `gpa/gpda_offset` pack 31 GPIOs in bits 31:1 (bit 0 is `write_en`), requiring `/ 31`, `% 31`, and `<< 1` shifts; `rtd_gpio_info` arrays must be sized for `/ 32`, `/ 31`, and `/ 8` (debounce) respectively. In `gpio-realtek-otto.c`, when `!GPIO_PORTS_REVERSED`, bank regs use `ioread32be`/`iowrite32be` while IMR regs use `ioread32`/`iowrite32` with `realtek_gpio_line_imr_pos_swapped()`. In `gpio-max732x.c`, upper-32-bit `max732x_features[]` flags require `INT_CAPS(x)` (`uint64_t`) and `>> 32` before `uint32_t` truncation. [F80, F102, F106, F116]
- Test `(trigger & IRQ_TYPE_EDGE_BOTH) == IRQ_TYPE_EDGE_BOTH` before single-edge flags in `pl061_irq_type()`; set `state = post_state` before `goto retry` in `sprd_pmic_eic_toggle_trigger()`; always clear the current bit on every path through manual bit-scan loops in `mxc`, `mxs`, and `max732x` IRQ handlers. [F84, F94, F96]
