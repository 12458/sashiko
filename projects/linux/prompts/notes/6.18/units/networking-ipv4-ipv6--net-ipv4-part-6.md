# NETWORKING [IPv4/IPv6] — net/ipv4 (part 6)

Implements the TCP transmit and retransmission engine (`tcp_output.c`), TCP timers (`tcp_timer.c`), recovery/rate/PLB helpers (`tcp_recovery.c`, `tcp_rate.c`, `tcp_plb.c`), TCP Upper Layer Protocol registration (`tcp_ulp.c`), per-CPU crypto ahash pool for TCP-MD5/AO (`tcp_sigpool.c`), additional congestion control algorithms (Vegas, Veno, Westwood, YeAH, Scalable), IPv4 tunnel demux (`tunnel4.c`), UDP-Lite (`udplite.c`), UDP socket diagnostics (`udp_diag.c`), and UDP tunnel GSO/GRO/NIC port offload infrastructure (`udp_offload.c`, `udp_tunnel_core.c`, `udp_tunnel_nic.c`).

## Architecture & Data Flow

- Before invoking a tunnel socket's `udp_sk(sk)->gro_complete` callback, `udp_gro_complete` must clear `NAPI_GRO_CB(skb)->encap_mark = 0` and set `skb->encapsulation = 1` so inner `gro_complete` handlers configure inner header offsets and allow inner fraglist GRO completion. [F241]
- During `udp_tunnel_nic_replay`, all non-free table entries must be marked with `UDP_TUNNEL_NIC_ENTRY_FROZEN` via `udp_tunnel_nic_entry_freeze_used` before calling `udp_tunnel_get_rx_info` and unfrozen via `udp_tunnel_nic_entry_unfreeze` afterward so existing ports do not have `use_cnt` incremented again. [F243]
- When `tcp_fragment` or `__tcp_retransmit_skb` recomputes `tcp_set_skb_tso_segs` on a segment that has already been sent (`!before(tp->snd_nxt, TCP_SKB_CB(buff)->end_seq)` or in `tcp_rtx_queue`), `tcp_adjust_pcount` must be called with the old minus new pcount sum so `packets_out`, `sacked_out`, `retrans_out`, and `lost_out` stay consistent. [F246]
- When splitting an SKB in `tcp_fragment` or `tso_fragment`, `TCPHDR_FIN` and `TCPHDR_PSH` in `TCP_SKB_CB(skb)->tcp_flags` and `TCP_SKB_CB(skb)->eor` must be cleared on the first segment and transferred only to the second segment (`buff`). [F247]
- Before `tcp_collapse_retrans` unlinks and frees `next_skb` after shifting its payload into `skb`, it must update `tp->highest_sack` via `tcp_highest_sack_replace(sk, next_skb, skb)`, repoint `tp->retransmit_skb_hint = skb` if it matched `next_skb`, and call `tcp_adjust_pcount(sk, next_skb, tcp_skb_pcount(next_skb))`. [F250]
- When `tcp_send_fin` tacks `TCPHDR_FIN` onto the last SKB in `sk->tcp_rtx_queue` because `sk->sk_write_queue` is empty under memory pressure, it must increment `tp->snd_nxt` (`WRITE_ONCE(tp->snd_nxt, tp->snd_nxt + 1)`) in addition to `TCP_SKB_CB(tskb)->end_seq++` and `tp->write_seq++` because the retransmit path does not advance `tp->snd_nxt`. [F251]
- When `tcp_event_ack_sent` flushes `tp->compressed_ack`, it must add `tp->compressed_ack` to `LINUX_MIB_TCPACKCOMPRESSED`, zero `tp->compressed_ack`, and call `__sock_put(sk)` if `hrtimer_try_to_cancel(&tp->compressed_ack_timer) == 1`; conversely, `tcp_compressed_ack_kick` must decrement `tp->compressed_ack` before `tcp_send_ack(sk)`. [F252]
- In `tcp_rate_skb_delivered`, once a SACKed SKB (`scb->sacked & TCPCB_SACKED_ACKED`) is sampled, `scb->tx.delivered_mstamp` must be reset to `0` so that when the SKB is later cumulatively ACKed, `tcp_rate_skb_delivered` returns early instead of generating a duplicate rate sample from it. [F253]
- When `tcp_plb_check_rehash` or an RTO (`tcp_plb_update_state_upon_rto`) triggers `sk_rethink_txhash(sk)`, `plb->consec_cong_rounds` must be reset to `0` (and on RTO `plb->pause_until` set to `tcp_jiffies32 + pause`) so congestion rounds from the old path do not trigger immediate rehashing on the new path. [F254]
- In tcp_select_window() and __tcp_transmit_skb(), SYN/SYN-ACK segments are never scaled and must clamp rcv_wnd to 65535U, while non-SYN segments must clamp new_win to (65535U << tp->rx_opt.rcv_wscale) (or MAX_TCP_WINDOW when unscaled with sysctl_tcp_workaround_signed_windows) before shifting right by rcv_wscale. [F256]

## Synchronization

- Because `tcp_sigpool_release` defers freeing `cpool` entries to `cpool_cleanup_work`, `tcp_sigpool_alloc_ahash` must use `kref_get_unless_zero` (falling back to `kref_init`) when reusing an entry under `cpool_mutex`, and `cpool_cleanup_work_cb` must recheck `kref_read(&cpool[i].kref) > 0` under `cpool_mutex` before freeing. [F188]
- sigpool_reserve_scratch() must be called with cpool_mutex held and must hold cpus_read_lock() while replacing per-CPU sigpool_scratch.pad pointers via rcu_replace_pointer(), freeing old scratch buffers immediately only for offline CPUs and deferring online CPUs' old buffers via call_rcu(). [F201]
- __tcp_ulp_find_autoload() must drop rcu_read_lock() before calling request_module(), re-acquire rcu_read_lock() to look up the ULP in tcp_ulp_list again, and pin ulp->owner with try_module_get() before calling rcu_read_unlock(). [F204]
- xfrm4_tunnel_register() and xfrm4_tunnel_deregister() must serialize modifications to tunnel4_handlers, tunnel64_handlers, and tunnelmpls4_handlers under tunnel4_mutex, publish new nodes via rcu_assign_pointer(), and call synchronize_net() after removal in xfrm4_tunnel_deregister(). [F205]
- udp_tunnel_notify_add_rx_port() and udp_tunnel_notify_del_rx_port() must be called with RTNL held and must bracket each per-device udp_tunnel_nic_add_port() or udp_tunnel_nic_del_port() call with udp_tunnel_nic_lock(dev) and udp_tunnel_nic_unlock(dev). [F208]
- udp_tunnel_update_gro_lookup() must hold udp_tunnel_gro_lock while modifying net->ipv4.udp_tunnel_gro[is_ipv6].list and publishing udp_tunnel_gro->sk via rcu_assign_pointer() when the list has a single entry (or clearing it with RCU_INIT_POINTER() otherwise). [F212]
- Under udp_tunnel_gro_type_lock in udp_tunnel_update_gro_rcv(), enabling the static call must update udp_tunnel_gro_rcv via static_call_update() before static_branch_enable(&udp_tunnel_static_call), and disabling it must call static_branch_disable(&udp_tunnel_static_call) before resetting udp_tunnel_gro_rcv to dummy_gro_rcv. [F213]
- When tcp_write_timer(), tcp_delack_timer(), tcp_compressed_ack_kick(), or tcp_tsq_handler() sees sock_owned_by_user(sk) under bh_lock_sock(sk), it must not run its handler directly, but instead set the matching *_DEFERRED bit in sk->sk_tsq_flags via test_and_set_bit() and call sock_hold(sk) if newly set. [F214]
- In tcp_small_queue_check() and skb_still_in_host_queue(), after setting TSQ_THROTTLED in sk->sk_tsq_flags via set_bit(), the caller must execute smp_mb__after_atomic() and re-test the throttling condition (sk_wmem_alloc > limit or skb_fclone_busy). [F215]

## Object Lifetimes

- `tcp_clone_payload` must validate all source SKBs (`!skb_headlen(skb)` and `nr_frags < MAX_SKB_FRAGS`) before taking page references via `skb_frag_ref(to, i)` and setting `skb_shinfo(to)->nr_frags` in the `commit` phase. [F183]
- When splitting a queued SKB in `tcp_fragment` or `tso_fragment`, only the new SKB's base `buff->truesize` is charged via `sk_wmem_queued_add` and `sk_mem_charge`, while the split payload length `nlen` is moved from `skb->truesize` to `buff->truesize` without recharging socket memory. [F184]
- In `tcp_ca_dst_init`, the module reference on the new congestion control ops must be acquired via `bpf_try_module_get(ca, ca->owner)` before releasing the existing reference via `bpf_module_put(icsk->icsk_ca_ops, icsk->icsk_ca_ops->owner)`. [F185]
- `__tcp_ulp_find_autoload` transfers a `try_module_get(ulp->owner)` reference to `__tcp_set_ulp`, which must call `module_put(ulp_ops->owner)` on every error path before `icsk->icsk_ulp_ops` is assigned, while `tcp_cleanup_ulp` releases it and clears `icsk->icsk_ulp_ops = NULL` on teardown. [F189]
- `udp_tunnel_sock_release` must clear `sock->sk->sk_user_data` with `rcu_assign_sk_user_data(sock->sk, NULL)` and call `synchronize_rcu()` before `kernel_sock_shutdown` and `sock_release`. [F192]
- When `gso_skb->destructor == sock_wfree`, `__udp_gso_segment` must clear `gso_skb->destructor` and `gso_skb->sk` before calling `skb_segment`, restore them if `skb_segment` fails, or attach `sock_wfree` and `sk` to every segment and adjust `sk->sk_wmem_alloc` by `sum_truesize - gso_skb->truesize` on success. [F197]
- In `udp_dump_one`, `rep` allocated by `nlmsg_new` must be freed with `kfree_skb(rep)` if `inet_sk_diag_fill` fails, whereas `nlmsg_unicast` consumes `rep` on both success and failure, and `sock_put(sk)` must be called on all exit paths after `refcount_inc_not_zero(&sk->sk_refcnt)` succeeds. [F200]
- In udp_dump_one() and __udp_diag_destroy(), the socket returned by __udp4_lib_lookup() or __udp6_lib_lookup() must be pinned with refcount_inc_not_zero(&sk->sk_refcnt) before rcu_read_unlock(), and released with sock_put(sk) on all exit paths after rcu_read_unlock(). [F206]
- Whenever tcp_pacing_check() starts tp->pacing_timer via hrtimer_start(), it must first verify !hrtimer_is_queued(&tp->pacing_timer) and take a socket reference with sock_hold(sk) to match the unconditional sock_put(sk) in tcp_pace_kick(). [F217]

## API Contracts

- Every successful call to `tcp_sigpool_start(id, &c)` must be paired with `tcp_sigpool_end(&c)`, which unlocks `sigpool_scratch.bh_lock` and `rcu_read_unlock_bh()` and frees `c->req` and its cloned `crypto_ahash` in reverse order of acquisition. [F186]
- `tcp_mtu_probe()` returns `0` when probing must wait for send or congestion window space, `1` when a probe packet was sent, and `-1` when probing is disabled, not ready, or fails; `tcp_write_xmit()` immediately returns `false` without sending queued data when `tcp_mtu_probe()` returns `0`. [F219]
- `tcp_established_options()` is called with `skb == NULL` and an uninitialized stack `struct tcp_out_options` from `tcp_current_mss()`, so `tcp_established_options()` and its callees (`bpf_skops_hdr_opt_len()`) must check `skb` for `NULL` before dereferencing it and explicitly initialize all `opts` fields they read or set. [F224]
- `tcp_options_write()` and `process_tcp_ao_options()` are invoked with `tp == NULL` and `tcprsk != NULL` from `tcp_make_synack()`, and with `tp != NULL` and `tcprsk == NULL` from `__tcp_transmit_skb()`, so any option path reachable on SYNACK packets must guard `tp` dereferences with `if (tp)` or `if (tcprsk)`. [F225]
- All callers of `tcp_select_initial_window()` must guarantee that the `mss` argument is at least `1`, because `rounddown(space, mss)` divides by `mss` when `space > mss`. [F226]
- `tcp_sigpool_hash_skb_data()` returns `0` on success and positive `1` (not a negative errno) when `crypto_ahash_update()` fails on the linear payload, paged fragments, or `frag_list` SKBs. [F228]
- `udp_tunnel_dst_lookup()` returns an `ERR_PTR` (`-ENETUNREACH` or `-ELOOP`, never `NULL`) on failure, calls `ip_rt_put(rt)` when rejecting a self-routed `rt->dst.dev == dev` loop, and populates `*saddr` on every successful return path. [F232]
- `udp_tunnel_nic_register()` requires `dev->udp_tunnel_nic_info` to provide either both `set_port` and `unset_port` or `sync_table` (mutually exclusive), a non-zero `tables[0].n_entries` with no empty table slots preceding populated tables, and never combines `info->shared` with `UDP_TUNNEL_NIC_INFO_OPEN_ONLY`. [F233]
- `__udp_tunnel_nic_get_port()` only writes to `*ti` when `utn->entries[table][idx].use_cnt` is non-zero (relying on `udp_tunnel_nic_get_port()` zero-initializing `*ti` to indicate an empty entry), and `__udp_tunnel_nic_dump_write()` converts the `BIT()` mask in `entry->type` to a bit index via `ilog2()` for `ETHTOOL_A_TUNNEL_UDP_ENTRY_TYPE`. [F234]

## Error Handling

- In `__skb_udp_tunnel_segment`, if `gso_inner_segment(skb, features)` returns an error or `NULL` after `__skb_pull(skb, tnl_hlen)` and inner header setup, `skb_gso_error_unwind` must be called to restore `skb`'s outer headers and protocol. [F198]
- `__tcp_transmit_skb()`, `__tcp_retransmit_skb()`, `tcp_retransmit_skb()`, and `tcp_write_wakeup()` return `0` on success, `< 0` on local allocation or routing failure, and `> 0` (`net_xmit_eval()` of `queue_xmit`) only when a packet is dropped by local qdisc or device congestion. [F218]
- In `tcp_connect()`, once the SYN SKB is queued in `sk->tcp_rtx_queue`, only `-ECONNREFUSED` from `tcp_send_syn_data()` or `tcp_transmit_skb()` is propagated to the caller; all other transmit errors are ignored and `tcp_connect()` arms `ICSK_TIME_RETRANS` and returns `0`. [F223]
- `tcp_sigpool_alloc_ahash()` returns a non-negative pool index on success or a negative errno on failure (which callers must check in a signed `int` before passing as `unsigned int id`), and `__cpool_alloc_ahash()` must reset `e->alg = NULL` on failure because `cpool[id].alg != NULL` discriminates populated entries. [F227]
- `udp_sock_create4()` must shut down and release any allocated socket (`kernel_sock_shutdown(sock, SHUT_RDWR); sock_release(sock);`) and set `*sockp = NULL` whenever any post-creation step (`sock_bindtoindex()`, `kernel_bind()`, or `kernel_connect()`) fails. [F231]

## External Contracts

- In tcp_vegas_get_info() and tcp_westwood_info(), the inet_diag extension bitmask ext uses 0-based bit positions for 1-based INET_DIAG_* attribute constants, so INET_DIAG_VEGASINFO must be tested with ext & (1 << (INET_DIAG_VEGASINFO - 1)). [F267]
- In net/ipv4/udp_diag.c, udp_dump_one() must pass req->id.idiag_src/idiag_sport as remote (saddr/sport) and req->id.idiag_dst/idiag_dport as local (daddr/dport) to __udp4_lib_lookup() and __udp6_lib_lookup() for historical UAPI compatibility, unlike __udp_diag_destroy() which passes idiag_dst as remote and idiag_src as local. [F269]

## Known Pitfalls

- In __tcp_retransmit_skb(), if ACK-trimming and retransmit collapsing leave skb->data unaligned on architectures where NET_IP_ALIGN != 0 or grow skb_headroom(skb) to >= 0xFFFF, the skb must be copied via __pskb_copy(skb, MAX_TCP_HEADER, GFP_ATOMIC) before calling tcp_transmit_skb(). [F263]
- In tcp_sigpool_hash_skb_data(), head_data_len must be clamped to 0 when skb_headlen(skb) <= header_len to prevent unsigned underflow, and each page fragment offset must be normalized to a sub-page page pointer and offset via skb_frag_page(f) + (offset >> PAGE_SHIFT) and offset_in_page(offset) before calling sg_set_page(). [F265]
- In __udp_diag_destroy(), when req->sdiag_family == AF_INET6 and both idiag_dst and idiag_src are IPv4-mapped IPv6 addresses, the IPv4 addresses passed to __udp4_lib_lookup() must be extracted from index [3] of idiag_dst and idiag_src (unlike AF_INET, which uses index [0]). [F270]
- In __skb_udp_tunnel_segment(), pskb_may_pull(skb, tnl_hlen) must succeed before pulling tnl_hlen, and when subtracting the old packet length from uh->check, htonl(skb->len) must be used instead of uh->len whenever SKB_GSO_PARTIAL is not set because an encapsulated GSO frame's length can overflow the 16-bit uh->len field. [F272]
- In `tcp_options_write`, the `OPTION_WSCALE` branch must only consume `leftover_highbyte` when `leftover_highbyte != TCPOPT_NOP && leftover_lowbyte == TCPOPT_NOP` (never splitting a 2-byte AccECN leftover across options), and when `opts->num_sack_blocks` is zero any remaining non-NOP leftover bytes must be flushed with trailing `TCPOPT_NOP`s. [F278]
- When `__tcp_transmit_skb` clones or copies a queued SKB (`clone_it != 0`) or `__tcp_retransmit_skb` allocates `nskb` via `__pskb_copy`, `dev` on the transmitted copy must be cleared to `NULL`, and post-send state updates (`tcp_update_skb_after_send`, `tcp_rate_skb_sent`) must be called on the queued SKB (`oskb` or `skb`), not the transmitted copy. [F281]
- In `__tcp_retransmit_skb`, when `before(TCP_SKB_CB(skb)->seq, tp->snd_una)` is true and `TCPHDR_SYN` is set on `skb`, clearing `TCPHDR_SYN` and incrementing `TCP_SKB_CB(skb)->seq` must jump back to `start:` so any payload bytes also before `tp->snd_una` are trimmed by `tcp_trim_head`. [F286]
- In `tcp_write_timer_handler`, `icsk->icsk_pending` must only be cleared before calling `tcp_retransmit_timer` (`ICSK_TIME_RETRANS`) and `tcp_probe_timer` (`ICSK_TIME_PROBE0`), and must remain set upon entering `tcp_rack_reo_timeout` (`ICSK_TIME_REO_TIMEOUT`) and `tcp_send_loss_probe` (`ICSK_TIME_LOSS_PROBE`). [F288]
- In `__udp_gso_segment`, the `for (;;)` loop over `segs` must break on `!seg->next` after setting `seg->destructor`, `seg->sk`, and `sum_truesize` on the last segment but before applying the full-MSS `newlen` and `check`, so post-loop code can compute the tail segment's own length and checksum. [F289]
