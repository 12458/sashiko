# AMD DISPLAY CORE — drivers/gpu/drm/amd/display/dc (part 1)

Display Core VBIOS/ATOMFirmware parser (`dc/bios`) and Display Clock Manager base/DCE implementations (`dc/clk_mgr`). `dc/bios` parses legacy ATOMBIOS (`bios_parser.c`, `command_table.c`) and ATOMFirmware (`bios_parser2.c`, `command_table2.c`) data tables and executes VBIOS command tables via the interpreter or DMUB. `dc/clk_mgr` dispatches clock manager construction across ASIC families and manages display/pixel/DP reference clocks, DENTIST dividers, and PSR/Replay power state transitions.

## Architecture & Data Flow

- `bios_parser_types_internal.h` and `bios_parser_types_internal2.h` define incompatible `struct bios_parser` layouts; `BP_FROM_DCB` must only be used inside callbacks of the matching parser's `vbios_funcs` table, never in shared helpers like `bios_parser_helper.c`. [F431]
- In `command_table2.c`, DMUB-capable initializers (`init_dig_encoder_control`, `init_transmitter_control`, `init_set_pixel_clock`, `init_enable_disp_power_gating`) must wire unrecognized table revisions to their `*_fallback` handlers rather than `NULL` so DMUB works when VBIOS omits those tables. [F394]
- When adding an `enum encoder_id` mapped from VBIOS object IDs, update `encoder_id_from_bios_object_id()` (`bios_parser_common.c`), `dal_cmd_table_helper_encoder_id_to_atom()` (`command_table_helper.c`), and `dal_cmd_table_helper_encoder_id_to_atom2()` (`command_table_helper2.c`) in lockstep; in `dal_graphics_object_id_is_valid()`, `id.id == 0` is valid for `OBJECT_TYPE_GPU` and `OBJECT_TYPE_ENGINE` (requiring only `id.enum_id != ENUM_ID_UNKNOWN`), whereas other types require both `id.id != 0` and `id.enum_id != ENUM_ID_UNKNOWN`. [F377, F393]
- In `construct_integrated_info()` (`bios_parser.c`, `bios_parser2.c`), `info->disp_clk_voltage[]` must be sorted in-place in ascending order of `max_supported_clk` before returning, as `dce_clock_read_integrated_info()` maps indices 0..3 to `DM_PP_CLOCKS_STATE_ULTRA_LOW`..`DM_PP_CLOCKS_STATE_PERFORMANCE`. [F389]
- In `dc_clk_mgr_create()`, the `FAMILY_SI` case must only call `dce60_clk_mgr_construct(ctx, clk_mgr)` and return `&clk_mgr->base` without calling `dce_clk_mgr_construct()`; in `dce_clk_mgr_construct()`, `base->clks.max_supported_dispclk_khz` must be initialized from `clk_mgr->max_clks_by_state[DM_PP_CLOCKS_STATE_PERFORMANCE].display_clk_khz` after `max_clks_by_state` is populated. [F382, F434]
- In `dce_set_clock()`, `pxl_clk_params.pll_id` must be `CLOCK_SOURCE_ID_PLL0` on `DCE_VERSION_6_0`/`DCE_VERSION_6_4` and `CLOCK_SOURCE_ID_DFS` on newer DCE; when `clk_mgr_dce->dfs_bypass_active` is true, set `pxl_clk_params.flags.SET_DISPCLK_DFS_BYPASS` before `program_display_engine_pll()`, and update both `clk_mgr_dce->dfs_bypass_disp_clk` and `actual_clock` from `pxl_clk_params.dfs_bypass_display_clock`; when `requested_clk_khz == 0`, reset `clk_mgr_dce->cur_min_clks_state` to `DM_PP_CLOCKS_STATE_NOMINAL` so resume re-invokes `dm_pp_apply_power_level_change_request()`. [F383, F384, F439]
- In `dce_update_clocks()` and `dce11_update_clocks()`, update `clk_mgr_base->clks.dispclk_khz` before calling `dce_pplib_apply_display_requirements()` / `dce11_pplib_apply_display_requirements()` (which copies it into `pp_display_cfg->disp_clk_khz` via `dce110_fill_display_configs()`); in `dce_update_clocks()`, clamp `patched_disp_clk` with `MIN(max_disp_clk, context->bw_ctx.bw.dce.dispclk_khz)` rather than scaling by 115/100 as in `dce11_update_clocks()`. [F385, F435]
- In `dce110_fill_display_configs()`, index `pp_display_cfg->disp_configs[]` by `num_cfgs` (incremented only for `!stream->dpms_off` streams) rather than loop index `j`, and reset `pp_display_cfg->crtc_index` and `line_time_in_us` to 0 when `num_cfgs == 0`. [F386]
- Skip `SUBVP_PHANTOM` streams (`dc_state_get_stream_subvp_type(context, stream) == SUBVP_PHANTOM`) in `clk_mgr_helper_get_active_display_cnt()`, and skip `pipe_ctx` entries with `!pipe_ctx->stream` or `pipe_ctx->top_pipe != NULL` in `dce_get_max_pixel_clock_for_all_paths()`. [F416, F417]
- `dentist_get_divider_from_did()` must clamp `did` to `[DENTIST_BASE_DID_1, DENTIST_MAX_DID]` (`[0x08, 0x7f]`), guaranteeing a return `>= DENTIST_DIVIDER_RANGE_1_START` (`8`) so callers like `dce_get_dp_ref_freq_khz()` can divide without zero-checking. [F402]

## Synchronization

- Every DMUB VBIOS command helper in `command_table2.c` (`encoder_control_dmcub`, `transmitter_control_dmcub`, `transmitter_control_dmcub_v1_7`, `set_pixel_clock_dmcub`, `enable_disp_power_gating_dmcub`, `enable_lvtma_control_dmcub`) must invoke `dc_wake_and_execute_dmub_cmd()` with `DM_DMUB_WAIT_TYPE_WAIT`. [F360]
- `dc_clk_mgr_create()`, `dal_bios_parser_create()`, `bios_parser_create()`, and `firmware_parser_create()` allocate with `kzalloc(..., GFP_KERNEL)` and must only be called from sleepable process context. [F447]

## Object Lifetimes

- `bios_parser_construct()` and `bios_parser2_construct()` must not return `false` after allocating `bp->base.integrated_info` or `bp->base.bios_local_image` without freeing them, because `bios_parser_create()` and `firmware_parser_create()` only call `kfree(bp)` on failure without calling `bios_parser_destruct()` / `bios_parser2_destruct()`; `bios_get_image()` (`GET_IMAGE`) returns a borrowed pointer into caller-owned `init->bios` (`bp->base.bios`), so `master_data_tbl` and `object_info_tbl` must never be `kfree`d and `init->bios` must outlive `struct dc_bios`. [F354, F355]
- `dc_destroy_clk_mgr()` frees the outer struct via `kfree(TO_CLK_MGR_INTERNAL(clk_mgr_base))`: every ASIC-specific clock manager struct in `dc_clk_mgr_create()` must embed `struct clk_mgr_internal base` at offset 0, no `*_clk_mgr_destroy()` may `kfree(clk_mgr)` itself, and any family/revision constructor allocating internal resources (`dcn3`, `dcn31`, `dcn35`, `dcn401`, etc.) must have a matching `*_clk_mgr_destroy()` case in `dc_destroy_clk_mgr()`. [F357, F388]
- `dc_clk_mgr_create()` must be called after `ctx->dc_bios` is initialized (and constructors must set `clk_mgr->base.ctx = ctx`), and `dc_destroy_clk_mgr()` must be called before `ctx` is freed because `dce_clk_mgr_construct()` reads `ctx->dc_bios` and `dc_destroy_clk_mgr()` dereferences `clk_mgr_base->ctx`. [F358]
- `clk_mgr_exit_optimized_pwr_state()` and `clk_mgr_optimize_pwr_state()` must be called in matched pairs without back-to-back exits, preserving LIFO order (`hwss.exit_optimized_pwr_state` before disabling eDP PSR/Replay, and restoring PSR/Replay from `clk_mgr->psr_allow_active_cache` before `hwss.optimize_pwr_state`). [F359]

## API Contracts

- `dal_bios_parser_destroy()` dispatches through `(*dcb)->funcs->bios_parser_destroy(dcb)` (`bios_parser_destroy` or `firmware_parser_destroy`), which requires non-NULL `dcb` and `*dcb` and zeroes `*dcb = NULL` after freeing `bp`. [F356]
- `EXEC_BIOS_CMD_TABLE(command, params)` (`command_table.c`, `command_table2.c`) takes `&params` and `sizeof(params)` and evaluates `amdgpu_atom_execute_table(...) == 0`; callers must pass the struct lvalue directly (never a pointer), pass the outer `*_PS_ALLOCATION_*` wrapper struct for `SetPixelClock` v5/v6 (`set_pixel_clock_v5/v6`, `program_clock_v5/v6`) and `ExternalEncoderControl` v3 (`external_encoder_control_v3`), and treat a truthy return as `BP_RESULT_OK` (`false` as `BP_RESULT_FAILURE`). [F372, F405, F429]
- When mapping flexible-array VBIOS tables in `bios_parser.c` (`ATOM_OBJECT_TABLE`, `ATOM_ASIC_INTERNAL_SS_INFO_V2`/`V3`, `ATOM_GPIO_PIN_LUT`), call `bios_get_image()` with `struct_size(..., 1)` rather than `GET_IMAGE`, which only checks `sizeof(header)`. [F395]
- `set_pixel_clock_v3/v5/v6()` and `program_clock_v5/v6()` must divide `bp_params->target_pixel_clock_100hz` by 100 (to 10kHz units) whereas `set_pixel_clock_v7()` passes it unscaled; `set_pixel_clock_v3()` must also divide `bp_params->fractional_feedback_divider` by 100,000 before casting to `uint8_t` for `ucFracFbDiv`, whereas v5/v6 pass it unscaled to `ulFbDivDecFrac`. [F363, F365]
- `set_crtc_using_dtd_timing_v3()` (`command_table.c`, `command_table2.c`) must subtract `h_addressable` from `h_total` and `h_sync_start`, subtract `v_addressable` from `v_total` and `v_sync_start`, and add 1 to `usV_SyncOffset`/`v_syncoffset` when `bp_params->flags.INTERLACE` is set. [F367]
- `clock_source_id_to_atom_phy_clk_src_id()` and `hpd_sel_to_atom()` in `dce60`/`dce80`/`dce110` must right-shift `ATOM_TRANSMITTER_CONFIG_V5_*` masks (`>> 2` and `>> 4`) while `dce112` `hpd_sel_to_atom()` returns `ATOM_TRANSMITTER_V6_HPD*_SEL` unshifted; `dig_encoder_sel_to_atom()` must return `0` (no FE) in `dce110`/`dce112` helpers, whereas `dce60`/`dce80` translate `ENGINE_ID_DIGA..G` to `ATOM_TRANMSITTER_V5__DIGA..G_SEL`. [F374, F444]
- In `transmitter_control_v2/v3/v4()`, divide `cntl->pixel_clock` by 20 instead of 10 for `params.usPixelClock` when `cntl->lanes_number > LANE_COUNT_FOUR` (dual-link); in `transmitter_control_v1_7()`, compute `dig_v1_7.HPO_instance` as `cntl->hpo_engine_id - ENGINE_ID_HPO_DP_0` when `dc_is_dp_signal(cntl->signal)` is true and `cntl->hpo_engine_id - ENGINE_ID_HPO_0` otherwise; in `external_encoder_control_v3()`, decrement 1-based `encoder.enum_id` by 1 before shifting into `ucConfig` (`(encoder.enum_id - 1) << 4`). [F375, F376, F401]
- In `command_table_helper` vtables, `assign_control_parameter`, `clock_source_id_to_ref_clk_src`, and `transmitter_bp_to_atom` are `NULL` on DCE110/DCE112, and `dc_clock_type_to_atom` and `transmitter_color_depth_to_atom` are only populated on DCE112; never invoke them on DCE versions where they are `NULL`. [F454]
- Guard all DCN family cases (`FAMILY_RV`..`AMDGPU_FAMILY_GC_12_0_0`) in `dc_clk_mgr_create()` and `dc_destroy_clk_mgr()` with `CONFIG_DRM_AMD_DC_FP`, and guard all `FAMILY_SI` / `DCE_VERSION_6_*` references (`dce60_clk_mgr_construct`, `dal_cmd_tbl_helper_dce60_get_table`) in `clk_mgr.c`, `command_table_helper.c`, and `command_table_helper2.c` with `CONFIG_DRM_AMD_DC_SI`. [F448, F450]

## Error Handling

- `dc_bios->integrated_info` is `NULL` when `bios_parser_create_integrated_info()` finds no supported `IntegratedSystemInfo` table, and `bp->cmd_tbl` members are `NULL` when `dal_bios_parser_init_cmd_tbl()` / `dal_firmware_parser_init_cmd_tbl()` find an absent/unsupported command table; all readers (`dce_clock_read_integrated_info()`, `get_ss_info_v4_5()`) and `bp->cmd_tbl.*` callers must null-check before dereferencing or calling. [F370, F371]
- `get_atom_data_table_revision()` (`bios_parser.c`, `bios_parser2.c`) must zero `tbl_revision->major` and `minor` before returning when `!atom_data_tbl`, as callers pass unchecked `GET_IMAGE()` results; in `bios_parser_get_vram_info()`, `enum bp_result result` must be a non-static local initialized to `BP_RESULT_BADBIOSTABLE` so each call falls back from `umc_info` to `vram_info`. [F364, F378]
- In `bios_parser_get_gpio_pin_info()` and `get_gpio_i2c_info()` (`bios_parser.c`, `bios_parser2.c`), verify `usStructureSize` / `structuresize` is at least the table header size plus one entry size before subtracting the header size to compute unsigned `count`. [F396]
- `dce_get_required_clocks_state()` must return `DM_PP_CLOCKS_STATE_INVALID` when `dispclk_khz` exceeds `max_clks_by_state[max_clks_state].display_clk_khz`, but clamp to `max_clks_state` when only `max_pix_clk` exceeds `pixel_clk_khz`; in `dce_clock_read_integrated_info()`, only overwrite `max_clks_by_state[clk_state].display_clk_khz` when `max_supported_clk >= 100000` (100 MHz); in `dce_adjust_dp_ref_freq_for_ss()`, verify `dprefclk_ss_divider != 0` before calling `dc_fixpt_from_fraction()`. [F380, F381, F424]

## External Contracts

- In `bios_parser_get_connectors_number()` and `bios_parser_get_connector_id()` (`bios_parser.c`, `bios_parser2.c`), skip `display_path[i]` entries where `encoderobjid == 0`; an out-of-range index `i` or an entry with `encoderobjid == 0` or `display_objid == 0` in `bios_parser_get_connector_id()` is a sparse slot and must return `OBJECT_TYPE_UNKNOWN` silently without `dm_error()` or `ASSERT()`. [F404, F449]
- In `transmitter_control_v1_7()`, when executing via DMUB on a link with non-zero `phy_transition_bitmask`, call `dm_acpi_process_phy_transition_interlock()` before `transmitter_control_dmcub_v1_7()` for `TRANSMITTER_CONTROL_ENABLE` and after it for `TRANSMITTER_CONTROL_DISABLE`; in `set_dce_clock_v2_1()`, divide `bp_params->target_clock_frequency` (kHz) by 10 into `ulDCEClkFreq`/`dceclk_10khz` only when `clock_type != DCECLOCK_TYPE_DPREFCLK`, and multiply the VBIOS output by 10 back to kHz. [F440, F452]

## Known Pitfalls

- Loops walking variable-length VBIOS object records (`bios_parser.c`, `bios_parser2.c`) must break when `record_type` is `LAST_RECORD_TYPE`/`ATOM_RECORD_END_TYPE` (`0xff`) or `record_size` (`ucRecordSize`) is `0`, verify `sizeof(record) <= header->record_size` before casting `header`, and advance byte `offset` by `ucRecordSize`/`record_size` (never via typed `header++`/`record++`) before any `continue`. [F397, F411, F432]
- In `bios_parser_construct()`, test `bp->object_info_tbl.revision.minor >= 3` before `revision.minor >= 1` so v1.3+ headers are bounds-checked as `ATOM_OBJECT_HEADER_V3` via `GET_IMAGE`. [F413]
- In `dce_clock_read_ss_info()`, `get_spread_spectrum_info()` for `AS_SIGNAL_TYPE_GPU_PLL` must check both `result == BP_RESULT_OK` and `info.spread_spectrum_percentage != 0` before enabling `ss_on_dprefclk` and returning early, and only set `dprefclk_ss_percentage` when `info.type.CENTER_MODE == 0`; in `get_firmware_info_v2_1/v2_2()`, increment `memory_clk_ss_percentage` and `engine_clk_ss_percentage` by 1 before dividing by 2 when `CENTER_MODE` is set. [F419, F426]
- In `transmitter_control_v1_6()` (`command_table.c`, `command_table2.c`) and `transmitter_control_v1_7()` (`command_table2.c`), `dplaneset` (`ucDPLaneSet`) and `digmode` (`ucDigMode`) share a union and must be assigned in mutually exclusive `if (cntl->action == TRANSMITTER_CONTROL_SET_VOLTAGE_AND_PREEMPASIS) ... else ...` branches; in `enable_spread_spectrum_on_ppll_v2/v3()`, left-shift `feedback_amount` and `nfrac_amount` by `ATOM_PPLL_SS_AMOUNT_*_SHIFT` before masking with pre-shifted `ATOM_PPLL_SS_AMOUNT_*_MASK`. [F420, F422]
- In `adjust_display_pll_v2/v3()`, widen `bp_params->pixel_clock` and the 10 kHz output frequency to `uint64_t` before multiplying and divide via `div_u64` only after checking `pixel_clock_10KHz_in != 0`; in `dce11_pplib_apply_display_requirements()`, use `div64_s64` (not `/`) when dividing 64-bit `dc->bw_vbios->high_yclk.value`. [F423, F427]
