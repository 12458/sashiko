# CAN NETWORK DRIVERS — drivers

USB CAN/CAN-FD adapter drivers (`kvaser_usb`, `peak_usb`, `ucan`, `usb_8dev`), virtual CAN interfaces (`vcan`, `vxcan`), and the CAN transceiver PHY driver (`phy-can-transceiver.c`).

## Architecture & Data Flow
- `vcan` and `vxcan` allocate `net_device` via `rtnl_link_ops` without `struct can_priv` at `netdev_priv(dev)`, so callbacks must never call `can_dev_dropped_skb()`, `can_change_mtu()`, or helpers casting `netdev_priv(dev)` to `struct can_priv *`. `vxcan_link_ops.priv_size` reserves `ALIGN(sizeof(struct vxcan_priv), NETDEV_ALIGN) + sizeof(struct can_ml_priv)`, and `vxcan_setup()` places `can_ml_priv` after `ALIGN(sizeof(struct vxcan_priv), NETDEV_ALIGN)`. `vxcan_open()` calls `netif_carrier_on()` on `dev` and `peer` only when `peer->flags & IFF_UP`; `vxcan_close()` calls `netif_carrier_off()` on both. [F401, F428, F450]
- In `kvaser_usb_probe()`, `dev_init_card`, `dev_get_software_info`, `dev_get_software_details`, `dev_get_card_info`, and `dev_get_capabilities` must finish before `kvaser_usb_init_one()` or `kvaser_usb_setup_rx_urbs()`. `kvaser_usb_init_one()` calls `alloc_candev()` with `struct_size(priv, tx_contexts, dev->max_tx_urbs)` after `max_tx_urbs` is finalized. Optional `kvaser_usb_dev_ops` (`dev_reset_chip`, `dev_init_channel`, `dev_remove_channel`, `dev_get_software_details`, `dev_get_capabilities`) must be null-checked. [F391, F453, F476]
- In `kvaser_usb`, cap `dev->nchannels` to `KVASER_USB_MAX_NET_DEVICES` (`MAX_USBCAN_NET_DEVICES` for `KVASER_USBCAN`) and verify `channel < dev->nchannels` before indexing `dev->nets[channel]`. Free `priv->tx_contexts[]` slots have `echo_index = dev->max_tx_urbs`; acquiring/releasing slots updates `echo_index` and `active_tx_contexts` under `priv->tx_contexts_lock`. `kvaser_usb_leaf_set_mode(CAN_MODE_START)` and `kvaser_usb_close()` must call `kvaser_usb_unlink_tx_urbs(priv)` to kill `tx_submitted` URBs and reset `active_tx_contexts` and `echo_index`. [F359, F407, F420]
- In `kvaser_usb_hydra.c`, cast `struct kvaser_cmd *` to `struct kvaser_cmd_ext *` only when `cmd->header.cmd_no == CMD_EXTENDED`, and format TX frames as `kvaser_cmd_ext` only when `KVASER_USB_HYDRA_CAP_EXT_CMD` is set. In `kvaser_usb_hydra_read_bulk_callback()`, verify bytes copied into `usb_rx_leftover` do not exceed `KVASER_USB_HYDRA_MAX_CMD_LEN`. `kvaser_usb_hydra_set_cmd_dest_he()` and `kvaser_usb_hydra_set_cmd_transid()` must mask inputs with `KVASER_USB_HYDRA_HE_ADDR_DEST_MASK` and `KVASER_USB_HYDRA_TRANSID_MASK`. [F393, F417, F419]
- `kvaser_usb_hydra_stop_chip()` sets `priv->can.state = CAN_STATE_STOPPED` before `CMD_STOP_CHIP_REQ`, and `kvaser_usb_hydra_update_state()` ignores `old_state == CAN_STATE_STOPPED && new_state == CAN_STATE_BUS_OFF`. `kvaser_usb_hydra_get_busparams()` sets `hydra->pending_get_busparams_type` before `CMD_GET_BUSPARAMS_REQ` so the reply handler populates `busparams_nominal`/`busparams_data` and resets `pending_get_busparams_type = -1` before completing `get_busparams_comp`. [F405, F409]
- In `kvaser_usb_leaf.c`, every command in `kvaser_usb_leaf_wait_cmd()` or `kvaser_usb_leaf_handle_command()` must have its minimum size in `kvaser_usb_leaf_cmd_sizes_leaf` / `kvaser_usb_leaf_cmd_sizes_usbcan` (or `CMD_SIZE_ANY`), pass `kvaser_usb_leaf_verify_size()`, and branch on `dev->driver_info->family` before accessing `u.leaf` or `u.usbcan`. Bus-off restart detection must check `state == CAN_STATE_BUS_OFF` (not `>=`). USBCanII 16-bit timestamps must be ORed with `usbcan_timestamp_msb` and multiplied by `KVASER_USB_USBCAN_TIMESTAMP_FACTOR` before `kvaser_usb_ticks_to_ktime()`. [F395, F415, F430, F449]
- `kvaser_usb_leaf_rx_error()` ignores events when `!netif_running(priv->netdev)` and schedules `leaf->chip_state_req_work` when `new_state < CAN_STATE_BUS_OFF` and `es->rxerr`, `es->txerr`, `new_state == CAN_STATE_ERROR_PASSIVE`, or `leaf->joining_bus` is non-zero; `kvaser_usb_leaf_stop_chip()` and `kvaser_usb_leaf_remove_channel()` must cancel `chip_state_req_work`. In `kvaser_usb_hydra_rx_msg_ext()` and `pcan_usb_fd_decode_canmsg()`, Classical CAN frames in `struct canfd_frame *` via `alloc_can_skb()` must set `cf->len` via `can_frame_set_cc_len()` (not `can_fd_dlc2len()`). [F403, F404, F463]
- In `pcan_usb_pro` and `pcan_usb_fd`, `usb_if->dev_opened_count` is incremented in `start()` after enabling timestamps when `0`, and decremented in `stop()` after disabling them when `1`. In `pcan_usb_fd_init()`, extended endpoints in `pcan_ufd_fw_info` require `le16_to_cpu(fw_info->type) >= PCAN_USBFD_TYPE_EXT`; `CAN_CTRLMODE_FD_NON_ISO` is supported only when `fw_version[0] >= 2` (and `pcan_usb_fd_build_restart_cmd()` emits `PUCAN_OPTION_CANDFDISO` only when supported). `dev_restart_async` commands must fit in `PCAN_USB_MAX_CMD_LEN` (32 bytes). [F363, F398, F460, F474]
- In `pcan_usb.c`, `CAN_CTRLMODE_ONE_SHOT | CAN_CTRLMODE_LOOPBACK` requires `device_rev >= 41`, `pcan_usb_set_silent()` requires `device_rev > 3`, and `pcan_usb_set_can_channel_id()` rejects `can_ch_id > U8_MAX` or `IFF_UP`. `pcan_usb_decode_status()` and `pcan_usb_decode_data()` pass `!mc->rec_ts_idx` to `pcan_usb_decode_ts()` and increment `mc->rec_ts_idx` per timestamped record. `peak_usb_get_ts_time()` compensates wrap-around between `ts_dev_1`, `ts_dev_2`, and `ts` by `+/-BIT_ULL(ts_used_bits)` before adding `(signed int)(ts - time_ref->ts_dev_2)`. [F413, F447, F481]
- In `ucan.c`, every TX URB `urb->context` must belong to `up->context_array` (indexed via `context - up->context_array`), acquired/released via `ucan_alloc_context()` / `ucan_release_context()`, and `ucan_tx_complete_msg()` calls `can_get_echo_skb()` / `can_free_echo_skb()` only when `ucan_release_context()` returns `true`. `ucan_tx_complete_msg()` computes entry count as `(len - UCAN_IN_HDR_SIZE) / 2` (verifying `len` is even and `>= UCAN_IN_HDR_SIZE`). In `ucan_handle_error_frame()`, `CAN_ERR_CRTL` checks on `data[1]` must remain sequential `if` statements (`ACTIVE` -> `WARNING` -> `PASSIVE`). [F365, F440, F455, F457]

## Synchronization
- In `vxcan`, `vxcan_priv::peer` is published via `rcu_assign_pointer()` in `vxcan_newlink()` and cleared via `RCU_INIT_POINTER()` in `vxcan_dellink()`; non-RTNL readers (`vxcan_xmit()`, `vxcan_get_iflink()`) must hold `rcu_read_lock()` across all uses of `rcu_dereference(priv->peer)` (including `netif_rx()` and `peer->stats`) and check for `NULL`. [F373]
- In `kvaser_usb`, synchronous `kvaser_usb_recv_cmd()` (`kvaser_usb_hydra_wait_cmd`, `kvaser_usb_leaf_wait_cmd`) is restricted to probe before `kvaser_usb_setup_rx_urbs()` sets `dev->rxinitdone`; later replies use `struct completion` (initialized once via `init_completion()` in `kvaser_usb_init_one()` and reset via `reinit_completion()`). In `kvaser_usb_hydra_read_bulk_callback()`, `card_data->usb_rx_leftover_lock` wraps `kvaser_usb_hydra_handle_cmd()`, so paths holding `priv->tx_contexts_lock` or `card_data->transid_lock` must never acquire `usb_rx_leftover_lock`. [F368, F370, F489]
- In `ucan`, `up->context_lock` protects `context_array[i].allocated`, `available_tx_urbs`, and `netif_stop_queue()` / `netif_wake_queue()`; `up->echo_skb_lock` protects all `can_put_echo_skb()`, `can_get_echo_skb()`, and `can_free_echo_skb()` calls. In `usb_8dev`, `priv->usb_8dev_cmd_lock` must be held across both `usb_8dev_send_cmd_msg()` and `usb_8dev_wait_cmd_msg()`. [F375, F376, F378]
- In `peak_usb`, `PCAN_USB_STATE_STARTED` is set after `dev_start()` succeeds and cleared at the start of `peak_usb_ndo_stop()`, and `peak_usb_read_bulk_callback()` checks `dev->state & PCAN_USB_STATE_STARTED` before `dev_decode_buf()`. `peak_usb_restart()` and `dev_restart_async` must use `GFP_ATOMIC` and async `usb_submit_urb()`, and `pcan_usb_restart_async()` returns `-EBUSY` if `timer_pending(&pdev->restart_timer)`. [F380, F381]

## Object Lifetimes
- Because `vxcan_setup()` sets `dev->needs_free_netdev = true`, `vxcan_newlink()` calls `free_netdev(peer)` if `register_netdevice(peer)` fails, or `unregister_netdevice(peer)` (without `free_netdev`) if a later step fails. `vxcan_dellink()` clears `peer` on both devices and enqueues both via `unregister_netdevice_queue()`. In `vxcan_xmit()`, after `can_dropped_invalid_skb()`, `oskb` must be consumed via `consume_skb(oskb)` after cloning or freed via `kfree_skb(oskb)`, setting `skb->csum_start = 0`, `pkt_type = PACKET_BROADCAST`, `dev = peer`, and `ip_summed = CHECKSUM_UNNECESSARY` before `netif_rx(skb)` under `rcu_read_lock()`. [F353, F355, F483, F501]
- `kvaser_usb_unlink_tx_urbs()` must never run in atomic URB completion context. `kvaser_usb_remove_interfaces()` calls `unregister_candev()` on all channels, then `kvaser_usb_unlink_all_urbs(dev)`, before `dev_remove_channel(priv)`, `kvaser_usb_devlink_port_unregister(priv)`, and `free_candev()`. In `kvaser_usb_unlink_all_urbs()` and `usb_8dev.c:unlink_all_urbs()`, `usb_kill_anchored_urbs(&...->rx_submitted)` must finish before `usb_free_coherent()` frees `rxbuf`. [F358, F372, F493]
- In `peak_usb_write_bulk_callback()`, when `netif_device_present(netdev)` is true, call `can_get_echo_skb()` and reset `context->echo_index = PCAN_USB_MAX_TX_URBS` even on non-zero `urb->status` (waking the queue only when `!urb->status`). `peak_usb_unlink_all_urbs()` frees unsubmitted `tx_contexts[i].urb` (`echo_index == PCAN_USB_MAX_TX_URBS`) via `usb_free_urb()` before `usb_kill_anchored_urbs(&dev->tx_submitted)`. `peak_usb_disconnect()` sets `dev->next_siblings = NULL` before `dev_free()` so `usb_if` is freed only when `!prev_siblings && !next_siblings`. [F360, F362, F379]
- In `ucan_submit_rx_urbs()`, submitted `urbs[i]` must be freed via `usb_free_urb()` and set to `NULL` so `ucan_cleanup_rx_urbs()` frees only unsubmitted URBs while `ucan_read_bulk_callback()` calls `usb_free_coherent()` whenever it exits without resubmitting. In `ucan_close()`, kill `tx_urbs` and `rx_urbs` via `usb_kill_anchored_urbs()` before `ucan_release_context_array(up)`. In `can_transceiver_phy_probe()`, initialize `mux_state`, GPIOs, `max_link_rate`, and `phy_set_drvdata()` before `devm_of_phy_provider_register()`. [F364, F377, F382, F492]

## API Contracts
- Every `cmd` passed to `kvaser_usb_send_cmd()` or `kvaser_usb_send_cmd_async()` must be heap-allocated; `kvaser_usb_send_cmd_async()` owns `cmd` only when returning `0` (callers `kfree(cmd)` on error). `kvaser_usb_hydra_wait_cmd()` rejects `CMD_EXTENDED`. In `kvaser_usb_*_get_single_capability()`, `cmd->cap_res` is valid only when `err == 0` and `*status == KVASER_USB_*_CAP_STAT_OK`. `kvaser_usb_hydra_map_channel()` `name` is `<= 15` chars. `kvaser_usb_ticks_to_ktime()` uses `div_u64()` with non-zero `timestamp_freq`. `kvaser_usb_init_one()` sets `dev_id` and `dev_port` to `channel` and registers `devlink_port` before `register_candev()`. [F356, F394, F446, F462, F465, F467, F504]
- PEAK bittiming callbacks subtract 1 from 1-based `can_bittiming` fields (`sjw - 1`, `phase_seg2 - 1`, `prop_seg + phase_seg1 - 1`, `brp - 1`). `dev_restart_async` owns `urb` and `buf` only on `0` return, and its completion callback calls `peak_usb_async_complete(urb)` and `peak_usb_restart_complete(dev)`. `pcan_usb_pro_send_req()` zeroes `req_addr` on `USB_DIR_IN` and clamps non-negative `usb_control_msg()` returns to `0`. `pcan_msg_add_rec()` callers must match `va_arg()` types. `pcan_usb_fd_send_cmd(dev, cmd_tail)` takes a pointer one past the last command. Non-NULL `p` in `pcan_usb_send_cmd()` / `pcan_usb_wait_rsp()` must be `>= PCAN_USB_CMD_ARGS_LEN` (14) bytes. [F396, F399, F458, F461, F468, F495]
- `ucan_ctrl_command_out()` returns positive byte counts when `datalen > 0`, so callbacks like `ucan_set_bittiming()` must clamp non-negative returns to `0`. `ucan_open()` zeroes `ctrlmode` before writing shared `up->ctl_msg_buffer->cmd_start.mode`. `ucan_prepare_and_anchor_rx_urbs()` and `ucan_cleanup_rx_urbs()` clear `urbs` with `sizeof(*urbs) * UCAN_MAX_RX_URBS`. `vcan_change_mtu()` and `vxcan_change_mtu()` reject changes when `IFF_UP` (`-EBUSY`) or invalid CAN/FD/XL MTU (`-EINVAL`). `vxcan_newlink()` uses `rtnl_newlink_peer_net()` and `rtnl_nla_parse_ifinfomsg()` with `.peer_type = VXCAN_INFO_PEER`. `can_transceiver_phy_power_on()` selects `mux_state` before setting GPIOs via `gpiod_set_value_cansleep()`, and `power_off()` sets GPIOs before `mux_state_deselect()`. [F386, F389, F429, F456, F500, F507]

## Error Handling
- In `kvaser_usb_init_one()`, any error after `dev->nets[channel] = priv` must unregister `devlink_port` if registered, `free_candev(netdev)`, and reset `dev->nets[channel] = NULL`. In `kvaser_usb_set_bittiming()`, `-EOPNOTSUPP` from `dev_get_busparams()` returns `0` before `memcmp()`, and `kvaser_usb_set_data_bittiming()` null-checks `dev_set_data_bittiming` and `dev_get_data_busparams`. Zero-initialize `struct kvaser_cmd` before `kvaser_usb_hydra_wait_cmd()` or `kvaser_usb_hydra_set_cmd_dest_he()`. [F357, F390, F392]
- In `peak_usb_create_dev()`, `dev_init(dev)` failure skips `dev_free(dev)`, so `pcan_usb_pro_init()` and `pcan_usb_fd_init()` must free their own allocations on error. In `pcan_usb_fd_decode_status()` and `pcan_usb_decode_error()`, `can_change_state()` and `can_bus_off()` must run on `CAN_STATE_BUS_OFF` even if `alloc_can_err_skb()` fails. [F397, F506]
- In `ucan_open()`, `err_stop` and `err_reset` store cleanup results in `ret_cleanup` (not `ret`). `ucan_get_fw_str()` passes `size - 1` to `usb_control_msg()` and sets `fw_str[ret] = '\0'` on `ret > 0` (or `"unknown"` on `<= 0`). In `usb_8dev_start_xmit()`, `nofreecontext` frees `buf` and `urb` without freeing `skb` before returning `NETDEV_TX_BUSY`, while `NETDEV_TX_OK` error paths also free `skb`. `usb_8dev_send_cmd()` verifies `begin == USB_8DEV_CMD_START`, `end == USB_8DEV_CMD_END`, `num_bytes_read == 16`, and `opt1 == 0`. In `can_transceiver_phy_probe()`, initialize `max_bitrate = 0` and ignore `-EINVAL` from `"max-bitrate"`; check `IS_ERR()` on optional mux/GPIOs and null-check them in power callbacks. [F366, F383, F384, F387, F388, F400]

## External Contracts
- In `pcan_usb_fd_send_cmd()`, append an 8-byte `0xff` end record if `cmd_tail - cmd_head <= PCAN_UFD_CMD_BUFFER_SIZE - sizeof(u64)`, and split into `PCAN_UFD_LOSPD_PKT_SIZE` (64-byte) chunks when `speed != USB_SPEED_HIGH`. `pcan_usb_fd_encode_msg()` and `pcan_usb_fd_decode_buf()` use 4-byte aligned records terminated by `size == 0` at `(struct pucan_tx_msg *)(obuf + tx_msg_size)` (never `tx_msg + tx_msg_size`). `peak_usb_get_eeprom()` / `peak_usb_set_eeprom()` convert `ch_id` to `__le32` (`pcan_usb` uses `sizeof(u8)` and `<= U8_MAX`). In `ucan`, access `msg.can_msg.dlc` only when `CAN_RTR_FLAG` is set, computing length from `m->len - (UCAN_IN_HDR_SIZE + sizeof(msg->id))` otherwise. [F421, F422, F424, F426, F459]

## Known Pitfalls
- `kvaser_usb_leaf_start_chip()` and `kvaser_usb_leaf_set_mode()` set `leaf->joining_bus = true` before `CMD_START_CHIP`; `kvaser_usb_leaf_rx_error_update_can_state()` derives `new_state` from `es->txerr`/`es->rxerr` without requiring `M16C_STATE_BUS_ERROR`. In `kvaser_usb_leaf_rx_can_msg()`, check `KVASER_LEAF && cmd->id == CMD_LEAF_LOG_MESSAGE` before `MSG_FLAG_ERROR_FRAME | MSG_FLAG_NERR | MSG_FLAG_OVERRUN`. On `cmd->len == 0` in Leaf RX loops, advance `pos` to `round_up(pos, le16_to_cpu(dev->bulk_in->wMaxPacketSize))` and continue. Cast `le16_to_cpu(timestamp[1..2])` to `u64` before shifting in `kvaser_usb_timestamp48_to_ktime()`, and keep `kvaser_usb_devlink_info_get()` `buf` strings `<= 15` chars. [F402, F416, F431, F433, F445, F466]
- In `pcan_usb_pro_handle_error()`, reset `new_state = CAN_STATE_MAX` to `CAN_STATE_ERROR_ACTIVE` in `default:`. In `peak_usb_update_ts_now()` and `peak_usb_get_ts_time()`, shift by `ts_used_bits` (up to 32) using `1ULL` / `BIT_ULL`. In `vxcan_newlink()`, gate `tbp[IFLA_IFNAME]` on `ifmp` because `tbp` aliases `tb` when `ifmp == NULL`. [F439, F443, F444]
