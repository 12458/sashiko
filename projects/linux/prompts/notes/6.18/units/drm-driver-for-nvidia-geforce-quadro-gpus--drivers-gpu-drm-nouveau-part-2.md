# DRM DRIVER FOR NVIDIA GEFORCE/QUADRO GPUS — drivers/gpu/drm/nouveau (part 2)

This component implements the core DRM driver layer for NVIDIA GPUs (`nouveau`), bridging DRM/TTM/KMS/HMM with NVIF/NVKM to manage probing, PM/Optimus DSM, clients, channels, DMA pushbuffers, TTM BOs, fences, modesetting, VBIOS parsing, DMEM migration, and ABI16/EXEC ioctls.

## Architecture & Data Flow

- In `struct nouveau_channel`, `dma.{cur,put,free,max}` are `u32` word indices matching `chan.push.{bgn,cur,end}`, whereas `chan->push.addr` and `user_get`/`user_put` are byte addresses (`<< 2`). `nouveau_channel_wait()` and `nouveau_channel_kick()` must add `push.cur - push.bgn` to `dma.cur` before `RING_SPACE()`/`FIRE_RING()`, and `nouveau_channel_wait()` must refresh `push.{bgn,cur,end}` from `push.mem.object.map.ptr + dma.cur` after `RING_SPACE()`. [F358, F417]
- `WRITE_PUT` requires `mb()` and `nouveau_bo_rd32(chan->push.buffer, 0)` before writing `chan->user_put`. On ring wrap in `nouveau_dma_wait()`, emit a jump to `chan->push.addr`, spin on `READ_GET()` until `get > NOUVEAU_DMA_SKIPS`, then call `WRITE_PUT(NOUVEAU_DMA_SKIPS)` and set `dma.cur = dma.put = NOUVEAU_DMA_SKIPS`. `READ_GET` must reset `*timeout = 0` whenever `val != *prev_get`. [F327, F359, F395]
- `nouveau_fence_enable_signaling()` increments `fctx->notify_ref` (allowing `fctx->event` at 1) and sets `DMA_FENCE_FLAG_USER_BITS` only if `nouveau_fence_no_signaling()` returns true; otherwise decrement `notify_ref` and call `nvif_event_block(&fctx->event)` at 0. Loops over `fctx->pending` calling `nouveau_fence_signal()` must use `list_for_each_entry_safe`. [F300, F393]
- In `nouveau_fence_update()` and `nouveau_fence_is_signaled()`, compare `fctx->read(chan)` and `fence->base.seqno` via `(int)(seq - fence->base.seqno) >= 0`. In `nouveau_fence_wait_legacy()` and `nouveau_fence_wait_busy()`, check `jiffies` deadlines with `time_after_eq()`. [F404, F405]
- `nouveau_bo_pin_locked()` subtracts `bo->base.size` from `vram_available`/`gart_available` only when `pin_count` goes `0 -> 1`, and `nouveau_bo_unpin_locked()` adds it back only at `0`; if validation fails after forcing `nvbo->contig = true`, reset `nvbo->contig = false`. [F355]
- `nouveau_exec_ioctl_exec()` bounds `req->push_count` to `nouveau_exec_push_max_from_ib_max(chan->chan.gpfifo.max)` (which returns `ib_max > 1 ? ib_max / 2 - 1 : 0`), and `nouveau_exec_job_init()` rejects `va_len > NV50_DMA_PUSH_MAX_LENGTH`. [F374, F410]
- On pre-Fermi (`family < NV_DEVICE_INFO_V0_FERMI`), `nouveau_accel_gr_init()` must allocate `drm->notify` and `NvNotify0` (`drm->ntfy`) on `drm->channel` for M2MF moves. In `nouveau_channels_init()`, `drm->runl` is sized to `fls64(runlists->data)` and indexed by bit position; when `drm->chan_nr == 0`, skip indices where `!(runlists->data & BIT(i))`. [F388, F436]
- `nouveau_dp_probe_dpcd()` must zero `lttpr.nr`, `rate_nr`, `link_nr`, `link_bw` before probing and zero `sink_count` if not connected; `nouveau_dp_power_down()` zeroes `lt.nr` under `hpd_irq_lock`. DP symbol rate conversions in `nouveau_dp_train()` and `nv50_dp_mode_valid()` must use `DIV_ROUND_UP(..., 8)`. [F361, F412]
- `nouveau_connector_set_edid()` must check `nv_connector->edid != edid` before updating the EDID property and freeing the old EDID; `nouveau_connector_detect()` must sync DP CEC EDID; `nouveau_connector_get_modes()` must destroy and NULL `native_mode` before probing, and call `nouveau_connector_detect_depth()` before `nouveau_conn_native_mode()` for non-LVDS but after determining `native_mode` for LVDS. [F311, F362, F363]
- `nouveau_conn_atomic_duplicate_state()` copies `dither`, `scaler`, `procamp` and resets `asyc->set.mask = 0`. `nouveau_conn_atom.dither` enums must match NV507D/NV907D hardware encodings. Modifier arrays must end with `DRM_FORMAT_MOD_INVALID` and `nouveau_drm_prop_enum_list` arrays with `{}`. [F364, F365, F384]
- In `parse_bit_structure()`, parse BIT `'i'` first so `feature_byte` and `is_mobile` are set. Keep `enum LVDS_script` 1-based (`LVDS_INIT = 1`..`6`) as a byte offset into BMP entries. `call_lvds_script()` and `run_tmds_table()` must save/restore `NV_PRAMDAC_SEL_CLK & 0x50000`; `call_lvds_script()` must set `lvds_init_run = true` before recursive `LVDS_INIT`, set `last_script_invoc = (script << 1 | head)`, and zero `NV_PBUS_POWERCTRL_2`. On resume, `nouveau_run_vbios_init()` resets `crtchead = 0` and (if `bios->execute`) `last_script_invoc = 0` and `lvds_init_run = false`. [F367, F370, F372, F380, F402]
- If `quirk_broken_nv_runpm()` zeroes `pdev->pm_cap`, save it in `drm->old_pm_cap` and restore it in `nouveau_drm_remove()`. In `nouveau_debugfs_pstate_get()`, reset `attr.index = 0` before the `do-while` loop and set `attr.state = state` on each iteration. [F369, F400]

## Synchronization

- `nouveau_abi16_get()` returns with `cli->mutex` held on success; every caller receiving a non-NULL `abi16` must call `nouveau_abi16_put(abi16, ret)` on all return paths. [F303]
- `drm->clients_lock` protects `drm->clients` (never acquire under `cli->mutex`, and finish `nouveau_cli_init()` before adding `cli->head` in `nouveau_drm_open()`). `drm->client_mutex` serializes `nvif_client_ctor(&drm->_client, ...)` and `nvif_client_dtor(&cli->base)`. In `nouveau_cli_init()`, pass `NULL` (not `drm->sched_wq`) to `nouveau_sched_create(&cli->sched, drm, NULL, 1)`. [F319, F329, F330]
- In `nouveau_exec_job_submit()`, hold `nouveau_uvmm_lock(uvmm)` across `drm_gpuvm_exec_lock(vme)` and unlock before `drm_gpuvm_exec_validate(vme)`; release `vme` locks via `drm_gpuvm_exec_unlock(vme)` on error or in `nouveau_exec_job_armed_submit()` after `drm_gpuvm_exec_resv_add_fence()`. [F325]
- `nouveau_bo_init()` must only call `ttm_bo_unreserve()` when `robj` is NULL. In `nouveau_bo_new()`, call `drm_gem_gpuva_init(&nvbo->bo.base)` before `nouveau_bo_init()`. [F294, F313]
- `drm->ttm.io_reserve_mutex` protects `io_reserve_lru` and BAR1 mapping/unmapping. Evicting from `io_reserve_lru` in `nouveau_ttm_io_mem_reserve()` under `io_reserve_mutex` must unlink the BO, call `drm_vma_node_unmap()` and `nouveau_ttm_io_mem_free_locked()`, and clear `resource->bus.{offset,addr}`. [F297, F328]
- `fctx->lock` protects `fctx->pending`, `fctx->killed`, and `fctx->notify_ref`; `nouveau_fence_emit()` must check `fctx->killed` under `fctx->lock` before queuing (dropping `dma_fence_put()` and returning `-ENODEV` if killed). `fence->channel` is cleared via `rcu_assign_pointer()` under `fctx->lock`; unlocked readers must use `rcu_read_lock()`, and `nouveau_fence_context_del()` must cancel `uevent_work`, call `nouveau_fence_context_kill()`, destroy `fctx->event`, set `fctx->dead = 1`, and call `synchronize_rcu()` before `nouveau_channel_del()` frees the channel. [F298, F314, F316]
- `dmem->mutex` protects `dmem->chunks`; `dmem->lock` protects `dmem->free_pages` and `chunk->callocated` (incremented on page alloc, decremented on free). Drop `dmem->lock` in `nouveau_dmem_page_alloc_locked()` before calling `nouveau_dmem_chunk_alloc()`. [F323, F354]
- In `nouveau_dmem_migrate_to_ram()`, hold `svmm->mutex` across `nouveau_svmm_invalidate()` and `nouveau_dmem_copy_one()`. Wait via `nouveau_dmem_fence_done(&fence)` before `dma_unmap_page()` in all DMEM migration/eviction paths. [F324, F459]
- `drm->hpd_lock` (with IRQs disabled) protects `drm->hpd_pending` and `nv_connector->hpd_pending`. In `nv50_edp_get_brightness()` and `nv50_edp_set_brightness()`, acquire `connection_mutex` and `crtc->mutex` via `drm_modeset_lock()` with `-EDEADLK` backoff before reading CRTC state or setting brightness. [F321, F326]

## Object Lifetimes

- `nouveau_bo_del_ttm()` must call `dma_resv_fini(&bo->base._resv)` instead of `drm_gem_object_release(&bo->base)` when `bo->base.dev` is NULL; otherwise, if `nvbo->no_share` is set, call `drm_gem_object_put(nvbo->r_obj)`. [F292]
- `nouveau_fence_create()` does not run `dma_fence_init()` (done in `nouveau_fence_emit()`): free unemitted fences with `kfree()`, and release emitted fences with `nouveau_fence_unref()` while nulling `exec_job->fence`. [F299]
- `nouveau_abi16_chan_fini()` must guard each step (`chan->sched`, `chan->chan`, `chan->ntfy`, `chan->heap.block_size`) and run `drm_sched_entity_fini(&chan->sched->entity)`, `nouveau_channel_idle(chan->chan)`, and `nouveau_sched_destroy(&chan->sched)` before freeing notifiers, `ntfy`, `heap`, and `nouveau_channel_del(&chan->chan)`. [F304, F343]
- `nouveau_cli_fini()` must `flush_work(&cli->work)` before destroying `sched`/`uvmm`/`svm`/`vmm`/`mmu`, and set `cli->device.object.map.ptr = NULL` before `nvif_device_dtor(&cli->device)`. Guard `nouveau_drm_postclose()` with `drm_dev_enter()`/`drm_dev_exit()`. [F306, F308]
- `nouveau_cli_work_queue()` takes `dma_fence_get(fence)`. `nouveau_cli_work_fence()` must defer `work->func` via `schedule_work(&work->cli->work)` under `cli->lock`, and `nouveau_cli_work_ready()` must call `dma_fence_put(fence)` only when `dma_fence_is_signaled_locked(fence)` is true. [F307, F455]
- In `nouveau_drm_probe()`, `nvkm_device_pci_new()` must precede `aperture_remove_conflicting_pci_devices()`. In `nouveau_drm_device_init()`, `nouveau_accel_init()` must precede `nouveau_dmem_init()`. [F426, F428]
- `nouveau_dmem_fini()` must call `nouveau_dmem_evict_chunk(chunk)` before `nouveau_bo_unpin_del(&chunk->bo)` and `memunmap_pages(&chunk->pagemap)`. `nouveau_do_suspend()` must call `nouveau_dmem_suspend()` before `ttm_resource_manager_evict_all()` and `nvif_client_suspend()`, and `nouveau_do_resume()` must call `nouveau_dmem_resume()` after `nvif_client_resume()`. [F305, F447]
- `nouveau_display_fini()` must block `conn->irq` and `conn->hpd` on all non-MST connectors before `cancel_work_sync(&drm->hpd_work)` and `disp->fini()`. Reset `disp->suspend = NULL` on `drm_atomic_helper_suspend()` error and after `drm_atomic_helper_resume()`. [F310, F322]

## API Contracts

- Callers of `nouveau_fence_no_signaling()` must hold a reference beyond `fctx->pending`'s reference (`refcount > 1`). [F301]
- `nouveau_framebuffer_new()` must validate all `info->num_planes` against `nvbo->bo.base.size` (validating `tile_mode` with `nouveau_check_tile_mode()` before `nouveau_get_gobs_in_block()`/`nouveau_get_height_in_blocks()` in `nouveau_check_bl_size()`), returning `-ERANGE` on overflow; on error, callers must `drm_gem_object_put(gem)`. [F309, F383, F406]
- `nvif_outp_dp_aux_xfer()` returns `< 0` on error or `>= 0` AUX reply while updating `*psize`; `nouveau_connector_aux_xfer()` stores `ret >= 0` in `msg->reply` and returns `size`, whereas direct callers like `nouveau_dp_probe_lttpr()` must treat any `ret != 0` as failure. [F333]
- `nouveau_display_fini(dev, suspend, runtime)` takes `(suspend, runtime)`, whereas `disp->fini(dev, runtime, suspend)` takes `(runtime, suspend)`. [F349]
- `nouveau_bo_{wr16,rd32,wr32}()` take element indices, not byte offsets. `nouveau_bo_{alloc,init,new}()` take `align` in bytes. On Tesla+, `nouveau_bo_move_prep()` attaches both `vma[0]` and `vma[1]` to `nouveau_mem(old_reg)`. [F350, F352, F396]
- `nouveau_channel_new()`/`ctor()` take a non-zero `runm` bitmask. `struct nv_dma_v0.limit` must be inclusive (`start + size - 1`). [F351, F377]
- `nouveau_abi16_ioctl()` subhandlers must verify and subtract header size from `argc` before casting payload. Copy variable-length arrays in `nouveau_exec_ucopy()` with `u_memcpya()` and free with `u_free()`. [F373, F375]
- Access `nvbios.data` multi-byte fields/offsets via `ROM16()`, `ROM32()`, and `ROMPTR()`. Use NVIF instead of legacy `nvxx_*` macros, and return early in `nouveau_bios_init()` when `nvkm_gsp_rm()` is true. [F379, F434]
- `nouveau_conn_reset()` and `nouveau_conn_attach_properties()` are shared with `nv50_mstc`: only use `nv_connector->properties_state` when `!drm_drv_uses_atomic_modeset()`, otherwise `nouveau_conn_atom(connector->state)`. Backlight callbacks get `nouveau_encoder *` from `bl_get_data(bd)` and `drm_connector *` from `dev_get_drvdata(bd->dev.parent)`. [F422, F423]
- `drm_debugfs_create_files()` callbacks get `drm_info_node *` in `m->private`, whereas `debugfs_create_file()` callbacks get `drm_device *`. `nouveau_debugfs_pstate_set()` must reject `len >= sizeof(buf)` before `copy_from_user()`. [F385, F424]
- In `nouveau_dmem_migrate_to_ram()`, if `migrate_vma_setup(&args)` yields `args.cpages > 0`, all paths must call `migrate_vma_finalize(&args)` (after `migrate_vma_pages()`, `nouveau_dmem_fence_done()`, and `dma_unmap_page()` if copied). [F478]

## Error Handling

- On `nouveau_bo_move()` failure after `nouveau_bo_move_ntfy()` (except `-EMULTIHOP`), roll back via `nouveau_bo_move_ntfy(bo, bo->resource)`, `drm_gpuvm_bo_gem_evict(obj, !evict)`, and `nouveau_bo_vm_cleanup(bo, NULL, &new_tile)`. `nouveau_ttm_fault_reserve_notify()` must return `VM_FAULT_NOPAGE` on `-EBUSY`/`-ERESTARTSYS`. [F296, F469]
- Treat `>= 0` and `-EACCES` from `pm_runtime_get_sync()` as success, and on other `< 0` errors still call `pm_runtime_put_autosuspend()`. `nouveau_connector_detect()` must use `pm_runtime_get_noresume()` when `drm_kms_helper_is_poll_worker()` is true. `nouveau_display_acpi_ntfy()` must use `pm_runtime_put_noidle()` when `pm_runtime_get()` returns `0` or `-EINPROGRESS`. [F312, F331, F449]
- In `nouveau_ttm_io_mem_reserve()`, translate `nvif_object_map_handle() == 0` to `-EINVAL` and reset `1` to `0`. `nouveau_fence_wait()` must map `dma_fence_wait_timeout()` `0` to `-EBUSY` and `> 0` to `0`. [F332, F334]
- In `nouveau_do_suspend()`, set `ret = -ENOMEM` when `nouveau_fence(drm)->suspend(drm)` returns `false`. In `nouveau_dmem_migrate_copy_one()`, set `*dma_addr = DMA_MAPPING_ERROR` when `spage == NULL`. [F335, F336]
- Initialize `nouveau_dsm_pci_probe()` out-params to `NULL`/`false` before calling. In `nouveau_backlight_init()`, convert `-ENODEV` from `nv40`/`nv50_backlight_init()` to `0` before `fail_alloc`. [F346, F348]

## External Contracts

- `nouveau_optimus_dsm()` must pack `arg` in little-endian and verify `obj->buffer.length == 4`. Probe Optimus DSM via `nouveau_optimus_dsm(handle, 0, 0, &result)` checking bit 0 and `1 << NOUVEAU_DSM_OPTIMUS_CAPS`. Call `pci_d3cold_disable()` if `!bridge_d3`, and set `optimus_skip_dsm` if `pci_pr3_present()`. Call `nouveau_switcheroo_optimus_dsm()` before `nouveau_do_suspend()` in runtime suspend, and return `1` from `nouveau_pmops_runtime_idle()`. [F387, F439, F440, F448]
- `nouveau_exec_ioctl_exec()` must require `nouveau_cli_uvmm(cli)` and `chan->user.oclass >= NV50_CHANNEL_GPFIFO` (else `-ENOSYS`). `nouveau_abi16_ioctl_grobj_alloc()` must translate class low bytes `0x6e`, `0xb1`, `0xb2`, `0xb3` against `sclass`. [F390, F472]
- Mask `conf` with `0xffff` (`version < 0x30`) or `0xff` (`>= 0x30`) in `parse_dcb20_entry()` for `DCB_OUTPUT_ANALOG`. Power down `nv_connector->aux` in `nouveau_dp_detect()` on `NOUVEAU_DP_NONE`. Set `vbios.rom` inode `i_size = drm->vbios.length`. [F381, F386, F444]

## Known Pitfalls

- Verify `nouveau_local_fence()` before `to_nouveau_fence()`, and check `rcu_dereference(f->channel)` under `rcu_read_lock()`. Keep `sizeof(fctx->name) >= sizeof(cli->name)` for `strcpy()`. [F337, F425]
- Check `bo->destroy == nouveau_bo_del_ttm` in `nouveau_bo_move_ntfy()` before accessing `nouveau_bo(bo)`. In `nouveau_ttm_io_mem_reserve()`, `TTM_PL_TT` must fall through to `TTM_PL_VRAM` when `oclass >= NVIF_CLASS_MEM_NV50 && mem->kind`, and BAR1 mappings must use `ttm_uncached` when `family >= TESLA` and `NVIF_MEM_UNCACHED` is set. [F338, F397, F437]
- Do not dereference `pdev` in `nouveau_abi16_ioctl_getparam()` when `platform == NV_DEVICE_INFO_V0_SOC`. Use `nouveau_for_each_non_mst_connector_iter` before calling `nouveau_connector()`. [F341, F391]
- In `nouveau_exec_ioctl_exec()`, record a `list_for_each_entry(chan16, ...)` match in `chan` and check `if (!chan)` after the loop. In `dcb_fake_connectors()`, store `++idx` in `map[i2c]` and assign `map[i2c] - 1`. [F382, F392]
- Use `roundup_64()` (and check `nvbo->mode != 0` before `64 * nvbo->mode`) in `nouveau_bo_fixup_align()`, `1ULL << vmm->page[i].shift` in `nouveau_bo_alloc()`, and `(u64)pci_domain_nr(pdev->bus) << 32` in `nouveau_pci_name()`. [F407, F408, F413]
