# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 2)

Implements ethtool operations, FCoE Direct Data Placement (DDP) offload, E610 PLDM firmware flash update, IPsec (XFRM) offload, and ring/interrupt vector helpers for ixgbe.

## Architecture & Data Flow
- `ixgbe_set_num_queues()` and `ixgbe_cache_ring_register()` must invoke feature helpers in decreasing order (`dcb_sriov`, `dcb`, `sriov`, `rss`), stopping at the first returning `true`. If `IXGBE_FLAG_FCOE_ENABLED` is set on `adapter->flags`, `adapter->ring_feature[RING_F_FCOE].indices` must be non-zero; setting `fcoe->indices` to 0 (as in `ixgbe_set_dcb_sriov_queues`) must clear `IXGBE_FLAG_FCOE_ENABLED`. [F1369, F1417]
- In `ixgbe_set_dcb_sriov_queues`, `ixgbe_set_sriov_queues`, `ixgbe_cache_ring_dcb_sriov`, and `ixgbe_cache_ring_sriov`, assign a non-zero pool mask to `vmdq_m`/`vmdq->mask` before `__ALIGN_MASK(1, ~mask)`. In the SR-IOV ring-caching helpers, set `adapter->rx_ring[i]->netdev` to `NULL` for `pool != 0` and `adapter->netdev` for pool 0 (and FCoE rings) so `ixgbe_process_skb_fields` distinguishes PF from offloaded macvlan pools. [F1418, F1473]
- In `ixgbe_alloc_q_vectors`, compute per-vector ring counts (`rqpv`, `tqpv`, `xqpv`) with `DIV_ROUND_UP(remaining, q_vectors - v_idx)` and subtract from remaining counts each iteration. `ixgbe_alloc_q_vector` allocates `struct_size(q_vector, ring, txr_count + rxr_count + xdp_count)`, interleaving Tx/Rx rings by adding `v_count` to `txr_idx`/`rxr_idx` while incrementing `xdp_idx` by 1. [F1404, F1420]
- In `ixgbe_ipsec_add_sa()`, zero-initialize `struct rx_sa rsa` before populating `rsa.ipaddr` (`AF_INET` writes 4 bytes at `&rsa.ipaddr[3]`, while `ip_tbl` `memcmp` and `ixgbe_ipsec_set_rx_ip()` read 16 bytes). [F1365]
- In `ixgbe_ipsec_restore`, purge `IXGBE_RXTXMOD_VF` entries from `rx_tbl`/`tx_tbl` via `ixgbe_ipsec_del_sa` before reloading `ipsec->ip_tbl` via `ixgbe_ipsec_set_rx_ip`. In `ixgbe_ipsec_clear_hw_tables`, call `ixgbe_ipsec_set_rx_ip` only for `idx < IXGBE_IPSEC_MAX_RX_IP_COUNT` (128), continuing `ixgbe_ipsec_set_tx_sa`/`ixgbe_ipsec_set_rx_sa` in a second loop from 128 to `IXGBE_IPSEC_MAX_SA_COUNT` (1024). [F1380, F1414]
- `ixgbe_fcoe_clear_ddp` must set `ddp->err = 1` so `ixgbe_fcoe_ddp_put` invalidates hardware DDP context unless `ixgbe_fcoe_ddp` received an error-free `IXGBE_RXDADV_STAT_FCSTAT_FCPRSP` frame and cleared `ddp->err = 0` (while unmapping and NULLing `ddp->sgl`). [F1389]
- `ixgbe_flash_pldm_image` seeds `priv.activate_flags` with the NVM preservation policy, so `ixgbe_flash_component` must OR (`|=`) `IXGBE_ACI_NVM_ACTIV_SEL_*` into `priv->activate_flags` for `ixgbe_finalize_update` to pass to `ixgbe_switch_flash_banks`. [F1390]
- In `ixgbe_add_ethtool_fdir_entry()`, `memset` `union ixgbe_atr_input mask` to 0 before setting fields (compared via full-union `memcmp`). `ethtool_get_flow_spec_ring_vf(fsp->ring_cookie)` is 1-based: `vf == 0` maps `ring < num_rx_queues` to `rx_ring[ring]->reg_idx`; `vf != 0` requires `vf <= num_vfs` and `ring < num_rx_queues_per_pool`, mapping to `(vf - 1) * num_rx_queues_per_pool + ring`. [F1374, F1400]
- In `ixgbe_set_coalesce`, sample `tx_itr_prev` from `adapter->rx_itr_setting` (when `q_vector[0]` has both `tx.count` and `rx.count`) or `adapter->tx_itr_setting` before mutating either field, so transitions across `IXGBE_100K_ITR` or `1` trigger `ixgbe_do_reset`. [F1387]
- `reg_test_82599` and `reg_test_82598` in `ixgbe_ethtool.c` must be `const`, end with `{ .reg = 0 }`, and `ixgbe_reg_test` must set `IXGBE_RXDCTL_ENABLE` on `IXGBE_RXDCTL(0..3)` before pattern-testing `IXGBE_RDT(0..3)` and clear `IXGBE_RXDCTL(0..3)` afterward (never testing read-only `IXGBE_RDH` on 82598). [F1450]

## Synchronization
- In `ixgbe_flash_pldm_image()`, call `ixgbe_cancel_pending_update()` before `ixgbe_acquire_nvm()`; all `ixgbe_fwu_ops_e610` callbacks invoked by `pldmfw_flash_image()` (`ixgbe_send_package_data`, `ixgbe_send_component_table`, `ixgbe_flash_component`, `ixgbe_finalize_update`) must assume the NVM lock is already held without acquiring or releasing it. [F1337]
- In `ixgbe_alloc_q_vector`, initialize each embedded `ixgbe_ring` (`dev`, `netdev`, `q_vector`, `count`, `queue_index`, XDP `tx_lock`/Rx `state`) and link it into `q_vector->tx` or `rx` before publishing to `adapter->tx_ring`, `xdp_ring`, or `rx_ring` via `WRITE_ONCE`. [F1346]
- On non-X550 MACs (`hw->mac.type != ixgbe_mac_X550`), `ixgbe_fcoe_ddp_setup` and `ixgbe_fcoe_ddp_put` must hold `spin_lock_bh(&fcoe->lock)` across the entire indirect DDP/filter register sequence (`IXGBE_FCPTRL`, `FCPTRH`, `FCBUFF`, `FCDMARW`, `FCPARAM`, `FCFLT`, `FCFLTRW`). [F1348]
- In `ixgbe_ipsec_add_sa`, fully initialize `ipsec->rx_tbl[sa_idx]` and hardware Rx SA registers before `hash_add_rcu` into `ipsec->rx_sa_list`. `ixgbe_ipsec_find_rx_state` must hold `rcu_read_lock()`, skip `IXGBE_RXTXMOD_VF` entries, and call `xfrm_state_hold(rsa->xs)` before `rcu_read_unlock()`. [F1350, F1456]
- `ixgbe_ipsec_vf_add_sa` and `ixgbe_ipsec_vf_del_sa` run in atomic VF mailbox context (`ixgbe_msix_other` -> `ixgbe_msg_task`), so allocations/helpers there and in `ixgbe_ipsec_add_sa`/`ixgbe_ipsec_del_sa` must use `GFP_ATOMIC` and never sleep. [F1455]
- `ixgbe_set_link_ksettings` must hold `__IXGBE_IN_SFP_INIT` on `adapter->state` around `hw->mac.ops.setup_link`, and `ixgbe_get_module_eeprom` must return `-EBUSY` when `__IXGBE_IN_SFP_INIT` is set. [F1355]

## Object Lifetimes
- `ixgbe_fcoe_ddp_setup()` must reject XIDs with non-NULL `ddp->sgl` before `ixgbe_fcoe_clear_ddp(ddp)`, balance `get_cpu()` with `put_cpu()`, and unwind failures via `out_noddp_free` (`dma_pool_free`, `ixgbe_fcoe_clear_ddp`), `out_noddp_unmap` (`dma_unmap_sg`), and `out_noddp` (`put_cpu`). `ixgbe_fcoe_ddp_put()` must set `ddp->pool = NULL` and call `ixgbe_fcoe_clear_ddp(ddp)` after freeing `udl`/`sgl`; `ixgbe_free_fcoe_ddp_resources()` must call `ixgbe_fcoe_ddp_put()` on all XIDs before `ixgbe_fcoe_dma_pool_free()` and NULL `ddp_pool->pool` and `fcoe->extra_ddp_buffer`. [F1333, F1334, F1336]
- `ipsec->ip_tbl[ipi].ref_cnt` tracks inbound SAs sharing an IP; `ixgbe_ipsec_del_sa()` may only clear `ip_tbl[ipi]` and call `ixgbe_ipsec_set_rx_ip()` with zeros when `ref_cnt` reaches 0. Increment `num_rx_sa`/`num_tx_sa` in `ixgbe_ipsec_add_sa()` only after all checks/allocations succeed; in `ixgbe_ipsec_del_sa()`, call `ixgbe_ipsec_stop_engine()` and clear `IXGBE_FLAG2_IPSEC_ENABLED` when both reach 0. [F1338, F1339]
- `ixgbe_ipsec_vf_add_sa()` must free its synthetic `xs` and `xs->aead` with `kfree_sensitive()` if `ixgbe_ipsec_add_sa()` fails; `ixgbe_ipsec_vf_del_sa()` must free `xs` after `ixgbe_ipsec_del_sa()` (never inside `ixgbe_ipsec_del_sa()`, where PF `xs` is stack-owned). [F1340]
- `ixgbe_free_q_vector()` must NULL `adapter->xdp_ring[]`, `tx_ring[]`, and `rx_ring[]` via `WRITE_ONCE()`, clear `adapter->q_vector[v_idx]`, and call `__netif_napi_del()` before `kfree_rcu(q_vector, rcu)`. If `ixgbe_alloc_q_vectors()` fails in `ixgbe_init_interrupt_scheme()`, free vectors `[0 .. v_idx-1]`, zero queue/vector counts, and call `ixgbe_reset_interrupt_capability()`. [F1342, F1343]
- In `ixgbe_set_ringparam()`, allocate all new Tx, XDP, and Rx ring resources in `temp_ring` (zeroing `temp_ring[i].xdp_rxq` before `ixgbe_setup_rx_resources()`) before freeing active rings; on failure, free `temp_ring[0 .. i-1]` before `ixgbe_up()`. [F1344]
- Call `ixgbe_update_ethtool_fdir_entry()` under `adapter->fdir_perfect_lock`; it takes ownership of non-NULL `input` into `fdir_filter_list` (freeing any displaced rule at `sw_idx` and updating `fdir_filter_count`), so callers only `kfree(input)` on errors prior to calling it. [F1345]

## API Contracts
- `ixgbe_fcoe_ddp()` returns `< 0` on non-DDP/errored frames, `0` when DDP placed payload and the caller (`ixgbe_clean_rx_irq`) must drop/free the skb, or `> 0` bytes when DDP completes and the skb goes to the ULD. `ixgbe_fcoe_ddp_setup()` (and `ddp_get`/`ddp_target`) returns `1` on success and `0` on failure, never `< 0`. [F1357, F1359]
- In `ixgbe_fso`, when `skb_is_gso(skb)` is true, `gso_type` must be `SKB_GSO_FCOE`, `first->gso_segs` and `first->bytecount` must include `(first->gso_segs - 1) * *hdr_len` and trailers, and `type_tucmd` must set `IXGBE_ADVTXD_TUCMD_L4T_RSV`. [F1465]
- In `ixgbe_switch_flash_banks()`, guard optional `emp_reset_available` for `NULL` before dereferencing. On E610, `ixgbe_flash_pldm_image()` must allow updates when `!nvm_unified_update` if `hw->mac.ops.fw_recovery_mode(hw)` is true, and `ixgbe_check_component_response()` must accept `IXGBE_ACI_NVM_PASS_COMP_PARTIAL_CHECK` in recovery mode. [F1362, F1446]
- In `ixgbe_ipsec_add_sa()`, `extack` is `NULL` from VF paths, so use `NL_SET_ERR_MSG_MOD()`. Store `ixgbe_ipsec_find_empty_idx()` in a signed `int` and check `< 0` (`-ENOSPC`) before casting to `u16 sa_idx`. Subtract `IXGBE_IPSEC_BASE_RX_INDEX` (0) or `IXGBE_IPSEC_BASE_TX_INDEX` (1024) from `xs->xso.offload_handle` before indexing `rx_tbl`/`tx_tbl`. [F1363, F1364, F1366]
- Callers of `ixgbe_ipsec_tx()` must zero-initialize `struct ixgbe_ipsec_tx_data` because `ixgbe_tso()`/`ixgbe_tx_csum()` unconditionally OR `itd->sa_idx`, `flags`, and `trailer_len` into the Tx context descriptor. `ixgbe_ipsec_parse_proto_keys` requires `alg_icv_len == 128` and `alg_key_len` of 160 (reading salt at `((u32 *)key_data)[4]`) or 128 (salt 0) before copying 16 key bytes. [F1367, F1396]
- `ixgbe_init_ipsec_offload()` must abort on `82598EB` or when `IXGBE_SECTXSTAT_SECTX_OFF_DIS`/`IXGBE_SECRXSTAT_SECRX_OFF_DIS` is set, and must call `ixgbe_ipsec_stop_engine()` and `ixgbe_ipsec_clear_hw_tables()` before setting `netdev->xfrmdev_ops`. [F1438]
- If `ixgbe_acquire_msix_vectors()` fails in `ixgbe_set_interrupt_capability()`, disable multi-TC DCB, SR-IOV, and RSS (`RING_F_RSS` limit = 1), call `ixgbe_set_num_queues()`, and set `adapter->num_q_vectors = 1`. [F1436]
- In `ixgbe_get_ethtool_stats()`, NULL-check `adapter->tx_ring[j]` and `rx_ring[j]` before dereferencing. `rx_itr_setting` and `tx_itr_setting` store `0` and `1` unshifted but values `> 1` shifted (`usecs << 2`), so `ixgbe_get_coalesce()`/`ixgbe_set_coalesce()` must shift by 2 only when `> 1`. [F1371, F1375]
- `ixgbe_get_eeprom()`/`ixgbe_set_eeprom()` convert byte `offset`/`len` to 16-bit word offsets (`offset >> 1`) and word counts for `hw->eeprom.ops`, swapping buffers with `le16_to_cpus()`/`cpu_to_le16s()`. [F1376]
- Offline `ixgbe_diag_test()` must abort if any VF has `clear_to_send`, run `ixgbe_link_test()` before `ixgbe_close()`/`ixgbe_reset()`, skip `ixgbe_loopback_test()` in SR-IOV/VMDq mode, and call `ixgbe_open()` or `disable_tx_laser()` after clearing `__IXGBE_TESTING`. `ixgbe_clean_test_rings` must bracket `ixgbe_check_lbtest_frame` page reads with `dma_sync_single_for_cpu` and `dma_sync_single_for_device` (`DMA_FROM_DEVICE`). [F1451, F1461]

## Error Handling
- In `ixgbe_ipsec_vf_del_sa`, if `!rsa->used` or `!tsa->used`, silently return `0` without logging an error (PF reset/VF down clears VF SAs before the VF deletes them). [F1470]

## External Contracts
- In `ixgbe_fcoe_ddp_setup()`, all buffers in `ddp->udl` except the first (`j == 0`) must start 4096-byte (`IXGBE_FCBUFF_MIN`) aligned, all except the last must end on a 4096-byte boundary, and if the final buffer's `lastsize == 4096`, append `fcoe->extra_ddp_buffer_dma` with `lastsize = 1`. [F1360]
- `ixgbe_get_regs` must stay within `IXGBE_REGS_LEN` (1145) `u32` elements, splitting 64-bit counters (`gorc`, `gotc`, `tor`) into low then high 32 bits at fixed indices. [F1402]
- `ixgbe_ipsec_vf_add_sa` requires `vfinfo[vf].trusted` and `IXGBE_FLAG2_VF_IPSEC_ENABLED`; `ixgbe_ipsec_vf_del_sa` requires `vfinfo[vf].trusted`, `IXGBE_RXTXMOD_VF`, and `rsa->vf == vf` (or `tsa->vf == vf`). [F1468]

## Known Pitfalls
- `netdev->fcoe_ddp_xid` is `ddp_max - 1`; `ixgbe_fcoe_ddp_setup`/`put` reject `xid >= netdev->fcoe_ddp_xid`, while `ixgbe_fcoe_ddp`/`ixgbe_free_fcoe_ddp_resources` check `xid >= ddp_max`. In `ixgbe_fcoe_ddp`, dereference `fh` before `skb_linearize(skb)` or recompute `fh` from `skb->data` afterward. [F1393, F1434]
- Cast `ddp->udp` (`dma_addr_t`) to `u64` before `>> 32` in `ixgbe_fcoe_ddp_setup`, and cast `u16 prefix` and `u8 mac->san_addr[0..4]` to `u64` before left-shifting in `ixgbe_fcoe_get_wwn`. [F1415, F1416]
- In `ixgbe_ipsec_set_tx_sa`, `ixgbe_ipsec_set_rx_sa`, and `ixgbe_ipsec_set_rx_ip`, convert `key[0..3]` and `salt` with `cpu_to_be32` (writing `key[3 - i]` in reverse order) and `spi`/`addr[0..3]` with `cpu_to_le32`. In `ixgbe_ipsec_vf_add_sa`, read all `sam` fields (`&msgbuf[1]`) before overwriting `msgbuf[1]`. [F1397, F1433]
- In `ixgbe_ipsec_stop_data()`, if `SECTX_RDY` and `SECRX_RDY` are not both set and `!adapter->link_up`, temporarily set `IXGBE_MACC_FLU` and `IXGBE_HLREG0_LPBK` around the readiness poll and clear both afterward. [F1440]
- Check `if (tcs <= 1) return false;` before dividing by `tcs` in `ixgbe_set_dcb_sriov_queues`/`ixgbe_set_dcb_queues`. Every `IXGBE_STAT`/`IXGBE_NETDEV_STAT` field in `ixgbe_gstrings_stats` must be 32-bit or 64-bit (`ixgbe_get_ethtool_stats` casts to `u64 *` or `u32 *`). [F1419, F1423]

## Other
- `ixgbe_ipsec_set_tx_sa()`, `ixgbe_ipsec_set_rx_sa()`, and `ixgbe_ipsec_set_rx_ip()` must write input data registers, call `IXGBE_WRITE_FLUSH(hw)`, write `IXGBE_IPSTXIDX`/`IXGBE_IPSRXIDX` with `IXGBE_RXTXIDX_WRITE` while preserving `IXGBE_RXTXIDX_IPS_EN`, and call `IXGBE_WRITE_FLUSH(hw)`. [F1441]
