# SCHEDULER — kernel/sched (part 2)

Implements the Deadline scheduling class (`SCHED_DEADLINE` with EDF, CBS, GRUB reclaiming, and DL servers like `fair_server`), the BPF extensible scheduler class (`sched_ext` / `SCHED_EXT`) and its built-in idle CPU selector, and scheduler debugfs/procfs interfaces.

## Architecture & Data Flow

- Standalone deadline servers (`dl_se->dl_server` set, e.g., `rq->fair_server`) are not in `struct task_struct`: check `!dl_server(dl_se)` before `dl_task_of(dl_se)` or `update_stats_dequeue_dl()`, and subtract raw unscaled `delta_exec` (not `dl_scaled_delta_exec()`) in `update_curr_dl_se()` and `dl_server_update_idle_time()`. [F43, F143]
- When `__pick_task_dl()` picks a `dl_server` whose `server_pick_task(dl_se)` returns `NULL`, call `dl_server_stop(dl_se)` and retry (never set `dl_se->dl_yielded`). When `update_curr_dl_se()` throttles a `dl_server` and `is_dl_boosted(dl_se)` holds or `start_dl_timer(dl_se)` returns 0, call `replenish_dl_new_period(dl_se, rq)` and `start_dl_timer(dl_se)` rather than `enqueue_task_dl()`. In `replenish_dl_new_period()`, `replenish_dl_entity()`, and `dl_entity_overflow()`, read static `dl_runtime`/`dl_deadline`/`dl_period` from `pi_of(dl_se)` while updating dynamic `runtime`/`deadline` on `dl_se`. [F66, F67, F128]
- `__enqueue_dl_entity()`/`__dequeue_dl_entity()` on `dl_rq->root` must update `dl_nr_running`, `earliest_dl`, `cpudl`, and `cpupri` via `inc_dl_tasks()`/`dec_dl_tasks()` (adjusting `rq->nr_running` only when `!dl_server(dl_se)`). `enqueue_pushable_dl_task()`/`dequeue_pushable_dl_task()` on `pushable_dl_tasks_root` must track the leftmost deadline in `earliest_dl.next` and toggle `rq->dl.overloaded`, `dlo_mask`, and `dlo_count` via `dl_set_overload()`/`dl_clear_overload()`. In `dl_clear_root_domain()`, zeroing `rd->dl_bw.total_bw` requires resetting `cpu_rq(i)->dl.extra_bw = cpu_rq(i)->dl.max_bw` for every CPU in `rd->span` before re-adding `dl_server` bandwidth via `__dl_add()`. `__sub_running_bw()` and `__sub_rq_bw()` must clamp to `0` if the new `u64` value exceeds `old`. [F64, F68, F69, F134]
- All `struct sched_ext_ops` fields before `init` must be function pointers (online ops before `cpu_online`, hotplug ops before `init`) so `SCX_OP_IDX(op)` can index `ops` into `sch->has_op`. Changing `sched_ext_ops` requires updating `enum scx_opi`, `__bpf_ops_sched_ext_ops`, `bpf_scx_check_member()`, and `bpf_scx_init_member()`; changing `struct scx_event_stats` requires updating `scx_read_events()`, `scx_attr_events_show()`, and `scx_dump_state()`. [F82, F83, F148]
- `container_of(dsq, struct rq, scx.local_dsq)` is valid only when `dsq->id == SCX_DSQ_LOCAL`. Decoding `SCX_DSQ_LOCAL_ON` requires testing `(dsq_id & SCX_DSQ_LOCAL_ON) == SCX_DSQ_LOCAL_ON` before extracting `dsq_id & SCX_DSQ_LOCAL_CPU_MASK` and checking `ops_cpu_valid()`. User DSQs must never mix FIFO and `SCX_ENQ_DSQ_PRIQ`; PRIQ enqueue in `dispatch_enqueue()` must insert into both `dsq->priq` and `dsq->list` with `SCX_TASK_DSQ_ON_PRIQ` set, and `task_unlink_from_dsq()` must erase `dsq_priq` when set. [F74, F95, F147]
- `scx_dsq_insert_commit()` must check `dspc->cursor >= scx_dsp_max_batch` before writing `dspc->buf`, and `scx_bpf_dispatch_cancel()` must check `dspc->cursor > 0`. In `balance_one()`, the dispatch loop must reset `dspc->nr_tasks = 0` on every iteration and break after `scx_kick_cpu(sch, cpu_of(rq), 0)` when `nr_loops` (`SCX_DSP_MAX_LOOPS`) hits 0. `bpf_iter_scx_dsq_next()` must skip tasks where `u32_before(kit->cursor.priv, p->scx.dsq_seq)`, and `scx_dsq_move()` must clear `__SCX_DSQ_ITER_HAS_SLICE | __SCX_DSQ_ITER_HAS_VTIME` on every exit path. [F79, F92, F120, F124]
- `update_curr_scx()` must not decrement `curr->scx.slice` when `SCX_SLICE_INF` and otherwise subtract `min_t(u64, curr->scx.slice, delta_exec)` when `delta_exec > 0`. In `set_next_task_scx()`, changes to `(p->scx.slice == SCX_SLICE_INF)` vs `SCX_RQ_CAN_STOP_TICK` require `sched_update_tick_dependency(rq)` and `update_other_load_avgs(rq)`. In `pick_task_scx()`, keeping `prev` under `SCX_RQ_BAL_PENDING` must check `prev->scx.flags & SCX_TASK_QUEUED`, not `prev->sched_class == &ext_sched_class`. [F80, F108, F139]
- In `select_cpu_from_kfunc()`, tasks with `p->nr_cpus_allowed == 1` or `is_bpf_migration_disabled(p)` must bypass `scx_select_cpu_dfl()` and only claim `prev_cpu` if in `allowed ?: p->cpus_ptr`. `scx_select_cpu_dfl()` must verify `cpumask_test_cpu(prev_cpu, allowed)` before returning `prev_cpu` on any idle fast path. When `sched_smt_active()`, `scx_idle_test_and_clear_cpu(cpu)` must clear `cpu` and `cpu_smt_mask(cpu)` from `idle_cpumask(node)->smt` unconditionally before testing `idle_cpus`, including when `!cpumask_intersects(smt, idle_smts)`. [F73, F86, F123]

## Synchronization

- `dl_set_overload()` must order `cpumask_set_cpu()` in `dlo_mask` with `smp_wmb()` before `atomic_inc(&rq->rd->dlo_count)`, paired with `smp_rmb()` after `dl_overloaded(this_rq)` in `pull_dl_task()`. Callers with pinned `rq->__lock` (`__push_dl_task()`, `balance_dl()`, `dl_task_timer()`) must unpin before `push_dl_task()`, `pull_dl_task()`, or `dl_task_offline_migration()`, and repin after. In `pull_dl_task()`, when a pushable task on `src_rq` has `is_migration_disabled(p)`, `stop_one_cpu_nowait()` must run only after `double_unlock_balance(this_rq, src_rq)` and `raw_spin_rq_unlock(this_rq)` with preemption disabled. [F20, F176, F177]
- Accessing `dl_bw_of(cpu)`, `dl_bw_cpus(cpu)`, or `__dl_update()` requires RCU-sched (`rcu_read_lock_sched()` or `rq->__lock`), and mutating `dl_b->total_bw`, `dl_b->bw`, or `rq->dl.extra_bw` requires `dl_b->lock`. Deduplicating root domains via `dl_bw_visited()` in `sched_dl_global_validate()`/`sched_dl_do_global()` requires `sched_domains_mutex` and `rcu_read_lock_sched()`. Updating `rq->fair_server` via `dl_server_apply_params()` and `setup_new_dl_entity()` requires holding `rq`'s lock and calling `update_rq_clock(rq)` before comparing `rq_clock(rq)`; `sched_fair_server_write()` must also call `dl_server_stop()` before `dl_server_apply_params()` and `dl_server_start()` after if `rq->cfs.h_nr_queued` is non-zero. [F23, F24, F25, F188]
- Clearing `SCX_OPSS_QUEUEING` or `SCX_OPSS_DISPATCHING` from `p->scx.ops_state` (`atomic_long_t`, held in `unsigned long`) requires `atomic_long_set_release()` (paired with `atomic_long_read_acquire()` in `wait_ops_state()`/`ops_dequeue()`), and `dispatch_to_local_dsq()` must clear `SCX_OPSS_DISPATCHING` before locking `src_rq`. In `ops_dequeue()`, when `atomic_long_try_cmpxchg()` fails in `SCX_OPSS_QUEUED` and falls through, pass `SCX_OPSS_DISPATCHING` (not `opss`) to `wait_ops_state()`. [F27, F101, F112]
- Non-local `dsq->lock` nests inside `rq->__lock`: `unlink_dsq_and_lock_src_rq()` must set `p->scx.holding_cpu = raw_smp_processor_id()`, drop `dsq->lock` before locking `src_rq`, and recheck `holding_cpu == cpu`. Because `move_remote_task_to_local_dsq()` unlocks `src_rq` and returns with `dst_rq` locked, `dispatch_to_local_dsq()` and `scx_dsq_move()` (`move_task_between_dsqs()`) must update `locked_rq = dst_rq` and relock the entry `rq` on exit. [F9, F28]
- In `direct_dispatch()`, remote `SCX_DSQ_LOCAL` dispatches while `rq->__lock` is pinned on enqueue must queue onto `rq->scx.ddsp_deferred_locals` via `schedule_deferred(rq)`. `process_ddsp_deferred_locals()` must drain it by popping `list_first_entry_or_null()` and `list_del_init()` before `dispatch_to_local_dsq()` (never `list_for_each_entry_safe()`). [F29, F115]
- Pass a non-NULL `rq` to `SCX_CALL_OP*()` only when `rq->__lock` is held (pass `NULL` in `handle_hotplug()`). In `scx_bpf_cpuperf_set()`, if `scx_locked_rq()` is non-NULL and `!= cpu_rq(cpu)`, call `scx_error()`; if NULL, lock `rq` and call `update_rq_clock(rq)` before `cpufreq_update_util(rq, 0)`. [F30, F31]
- In `scx_enable()`/`scx_disable_workfn()`, updating `scx_root`, `scx_idle_enable()`, and `scx_idle_update_selcpu_topology()` requires `cpus_read_lock()`, with `scx_idle_enable()` before `ops.init()`. `scx_pre_fork()`'s `percpu_down_read(&scx_fork_rwsem)` must be released in `scx_post_fork()` or `scx_cancel_fork()` (after `scx_exit_task(p)` under `task_rq_lock()` if `scx_enabled()`). `switch_class()` must update `rq->scx.pnt_seq` with `smp_store_release()`, paired with `smp_load_acquire(wait_pnt_seq)` in `kick_cpus_irq_workfn()`. `scx_kick_cpu()` must defer remote `rq` locking to `kick_cpus_irq_workfn()` and suppress `irq_work_queue()` when `scx_rq_bypassing(this_rq)`. `scx_bypass()` must not acquire mutexes/rwsems or toggle static keys, using only `bypass_lock` and `raw_spin_rq_lock(rq)`. [F19, F32, F37, F169, F171]
- `scx_select_cpu_dfl()` must disable preemption for per-CPU masks/`smp_processor_id()` and hold `rcu_read_lock()` for `numa_span()`/`llc_span()`. `select_cpu_from_kfunc()` requires `task_rq_lock()` when unlocked or `scx_locked_rq()`/`p->pi_lock` when locked to read `p->cpus_ptr`/`nr_cpus_allowed`. Kfuncs returning RCU-protected pointers or relying on caller RCU without internal `rcu_read_lock()` (`scx_bpf_cpu_curr()`, `bpf_iter_scx_dsq_new()`) require `KF_RCU_PROTECTED`, and kfuncs/handlers callable from BPF timers or when disabled must dereference `scx_root` under RCU/RCU-bh and check for NULL. [F40, F162, F163, F164]

## Object Lifetimes

- When arming/canceling `dl_timer` or `inactive_timer`, call `get_task_struct(dl_task_of(dl_se))` only when `!dl_server(dl_se)` and `!hrtimer_is_queued(timer)`, and `put_task_struct()` on cancel only when `hrtimer_try_to_cancel() == 1` and `!dl_server(dl_se)`. In `dl_task_timer()` and `inactive_task_timer()`, call `put_task_struct(p)` only after `task_rq_unlock()`, without dereferencing `p` or `timer` after. [F2, F3]
- In `sched_dl_overflow()`, do not subtract `p->dl.dl_bw` when leaving `SCHED_DEADLINE` (done in `switched_from_dl()`), and subtract old `p->dl.dl_bw` before adding `new_bw` when re-entering while `hrtimer_active(&p->dl.inactive_timer)`. In `push_dl_task()` and `find_lock_later_rq()`, pin `next_task` with `get_task_struct()` before `double_lock_balance()`, revalidate after locking (`!is_migration_disabled()`, `cpus_mask`, `pick_next_pushable_dl_task()`), and call `put_task_struct(next_task)` before reassigning `next_task = task` on retry. [F5, F6, F22]
- In `scx_enable()`, `scx_cgroup_init()` and `scx_init_task()` iteration must run under `scx_cgroup_lock()`. In `scx_disable_workfn()`, call `scx_bypass(true)` before `scx_enable_mutex`, run `scx_cgroup_exit()` under `scx_cgroup_lock()` before `scx_exit_task()`, disable `__scx_enabled`, zero `sch->has_op`, clear `scx_root` under `cpus_read_lock()`, call `synchronize_rcu()` before `ops.exit()` and `free_percpu(scx_dsp_ctx)` (setting `scx_dsp_ctx = NULL`), and run `cancel_delayed_work_sync(&scx_watchdog_work)` and `kobject_del(&sch->kobj)` before `scx_bypass(false)` and unlocking `scx_enable_mutex` (`sch` is freed in `bpf_scx_unreg()`). [F13, F33, F34]
- `scx_task_iter_start()` inserts stack `iter->cursor.tasks_node` (`SCX_TASK_CURSOR`) into `scx_tasks`: skip `SCX_TASK_CURSOR` before `container_of()`, always call `scx_task_iter_stop()`, and pin `p` with `tryget_task_struct(p)` before `scx_task_iter_unlock(&sti)` (releasing with `put_task_struct(p)`). `destroy_dsq()` must set `dsq->id = SCX_DSQ_INVALID` under `dsq->lock` (checked in `dispatch_enqueue()`) and queue to `dsqs_to_free` so `free_dsq_irq_workfn()` calls `kfree_rcu()` outside scheduler locks. `bpf_iter_scx_dsq_new()` must set `kit->dsq = NULL` before any error check, and `bpf_iter_scx_dsq_destroy()` must unlink `kit->cursor.node` under `kit->dsq->lock` and clear `kit->dsq = NULL`. [F17, F35, F36, F146]

## API Contracts

- Non-nesting `sched_ext_ops` callbacks taking a task under `rq` lock (`enqueue`, `dequeue`, `tick`, `enable`, `disable`, `exit_task`) must use `SCX_CALL_OP_TASK*()`. Test optional callbacks with `SCX_HAS_OP(sch, op)` (`sch->has_op`), not `sch->ops.op`. Call `task_can_run_on_remote_rq()` only when `src_rq != dst_rq`, checking `is_migration_disabled(p)` before `task_allowed_on_cpu(p, cpu)`. `init_scx_entity()` must set `sticky_cpu = -1`, `holding_cpu = -1`, `ddsp_dsq_id = SCX_DSQ_INVALID`, and `RB_CLEAR_NODE(&scx->dsq_priq)`. [F38, F50, F51, F53, F62]
- Validate BPF CPU args with `ops_cpu_valid()`, and per-node idle kfunc `@node` args with `validate_node()` before `idle_cpumask(node)`; list idle kfuncs only in `scx_kfunc_ids_idle`. Non-`KF_RET_NULL` `KF_ACQUIRE` kfuncs must never return `NULL`: `scx_bpf_task_cgroup()` must return a `cgroup_get()`-ed pointer (fallback `&cgrp_dfl_root.cgrp`), and `scx_bpf_get_idle_cpumask*()`/`smtmask*()` must return `cpu_none_mask` on error. `scx_bpf_select_cpu_dfl()` must always set `*is_idle` when `scx_root` exists and return `prev_cpu` on `-EBUSY`. `scx_bpf_pick_any_cpu_node()` fallback must intersect `cpus_allowed` with `cpumask_of_node(node)` when `SCX_PICK_IDLE_IN_NODE` is set. [F18, F56, F59, F85, F87, F109, F179]
- `bpf_scx_btf_struct_access()` only allows writes within `scx.slice`, `scx.dsq_vtime`, or `scx.disallow`. `bpf_scx_check_member()` only allows `prog->sleepable` on `init_task`, `cgroup_init`, `cgroup_exit`, `cgroup_prep_move`, `cpu_online`, `cpu_offline`, `init`, and `exit`. `bpf_scx_init_member()` must validate `dispatch_max_batch <= INT_MAX`, `!(flags & ~SCX_OPS_ALL_FLAGS)`, `timeout_ms`, and `name`, returning `1` for value members. `scx_dsq_insert_preamble()` must reject `enq_flags & __SCX_ENQ_INTERNAL_MASK`. `scx_bpf_create_dsq()` must reject `dsq_id & SCX_DSQ_FLAG_BUILTIN` and invalid `@node`, and insert via `rhashtable_lookup_insert_fast()`. [F48, F61, F89, F90, F93, F94, F157]

## Error Handling

- `start_dl_timer()` returns `0` if activation time is in the past; throttling callers must check `!start_dl_timer(dl_se)` and replenish/re-enqueue on `0`. Guard `div64_long()` in `task_non_contending()` with `dl_se->dl_runtime != 0` and `__dl_add()` in `__dl_server_attach_root()` with `dl_bw_cpus(cpu) != 0`. [F44, F135]
- After `scx_set_enable_state(SCX_ENABLING)` in `scx_enable()`, errors must jump to `err_disable*`, call `scx_error()`, flush `sch->disable_work`, and return `0`. Pass `-errno` returns from `sched_ext_ops` callbacks through `ops_sanitize_err()`. Set per-CPU `direct_dispatch_task = p` before `ops.select_cpu()`/`ops.enqueue()` and reset to `NULL` after; `mark_direct_dispatch()` sets `ERR_PTR(-ESRCH)` and must check `IS_ERR(ddsp_task)`, and `dispatch_enqueue()` must reset `ddsp_dsq_id = SCX_DSQ_INVALID` and `ddsp_enq_flags = 0`. [F12, F14, F54, F183]
- In `scx_cgroup_init()`, call `css_put(css)` before returning on `ops.cgroup_init()` error inside `css_for_each_descendant_pre()`. In `scx_cgroup_can_attach()`, set `p->scx.cgrp_moving_from` only after `ops.cgroup_prep_move()` succeeds (`from != to`), and clear it to `NULL` after `ops.cgroup_cancel_move()`/`scx_cgroup_move_task()`. In `scx_select_cpu_dfl()`, return `-EBUSY` when `SCX_PICK_IDLE_CORE` finds no full idle SMT core. [F15, F16, F49]

## Known Pitfalls

- In `pull_dl_task()`, preserve `dmin` across `for_each_cpu(cpu, this_rq->rd->dlo_mask)` iterations while resetting `push_task = NULL` on each iteration. In `grub_reclaim()`, check `u_inact + rq->dl.extra_bw > rq->dl.max_bw - dl_se->dl_bw` before unsigned subtraction. [F122, F133]
- Append to `rq->scx.runnable_list` with `list_add_tail()` in `set_task_runnable()` and iterate with `list_for_each_entry_safe_reverse()` in `scx_bypass()`. In `scx_bpf_reenqueue_local()`, move candidate tasks (skipping only `p->migration_pending`) to a private list before `do_enqueue_task()`. In `nldsq_next_task()`, only access `&cur->scx.dsq_list.node` without dereferencing `cur` (which may be `&kit->cursor`) and skip `SCX_DSQ_LNODE_ITER_CURSOR`. [F77, F116, F117, F144]
