# ANALOG DEVICES INC IIO DRIVERS — drivers/iio (part 1)

This component contains Linux IIO accelerometer and ADC drivers for Analog Devices hardware (ADIS16201/16209, ADXL345/372, AD7124, AD7173/AD411x, AD7266, AD7280A, AD7291, AD7298, AD7405, AD7606, AD7766, AD7779, AD7791) across SPI, I2C, and parallel/IIO-backend buses.

## Architecture & Data Flow

- In `ad7124` and `ad7173`, runtime edits to `ad7124_channel_config` or `ad7173_channel_config` must update `cfg` and set `cfg->live = false` rather than writing `AD7124_CONFIG`/`AD7124_FILTER` or `AD7173_REG_SETUP`/`AD7173_REG_FILTER` directly. Hardware setup fields must reside in `struct_group(config_props, ...)` and match the `static_assert` and field-by-field checks in `ad7124_find_similar_live_cfg()` and `ad7173_is_setup_equal()`. [F44, F106]
- Evicting a slot in `ad7124_pop_config()` or `ad7173_free_config_slot_lru()` must clear `st->channels[i].cfg.live = false` on all channels sharing that `cfg_slot`. `ad7173_config_channel()` must call `ad7173_reset_usage_cnts()` when `st->config_usage_counter == U64_MAX` so `<` comparisons in `ad7173_free_config_slot_lru()` do not wrap. In `ad7124_state`, `cfg_slots_status` must remain `unsigned long` for `find_first_zero_bit()`/`assign_bit()`. [F45, F98, F112]
- In `ad7124`, `ad7124_set_filter_type_attr()` (or power-mode updates in `st->adc_control`) must call `ad7124_set_channel_odr(st, chan->address)` to recompute `cfg->odr_sel_bits`, which must be clamped to `[1, 2047]`. In `ad7173`, setting sampling rate in `ad7173_write_raw()` and `ad7173_fw_parse_channel_config()` must update both `cfg->sinc5_odr_index` and `cfg->sinc3_odr_div` (clamped to `[1U, AD7173_FILTER_SINC3_MAP_DIV]` in `ad7173_sinc3_odr_div_from_odr()`). Also, `ad_sigma_delta_info.num_slots` must equal `info->num_channels` (4/8/16), whereas setup slot IDA allocation in `ad7173_load_config()`/`ad7173_free_config_slot_lru()` is bounded by `info->num_configs` (4/8). [F47, F49, F95, F97, F123]
- In `__ad7124_calibrate_all()` and `ad7173_calibrate_all()`, skip channels with `type != IIO_VOLTAGE`. In `ad7124.c`, every `ad_sd_calibrate()` call (including `ad7124_syscalib_locked()`) must read back `AD7124_GAIN(cfg_slot)` or `AD7124_OFFSET(cfg_slot)` into `cfg->calibration_gain`/`calibration_offset`, and full-scale (`AD7124_ADC_CONTROL_MODE_INT_GAIN_CALIB`, when `pga_bits > 0`) must run and read back `AD7124_GAIN` before zero-scale calibration. [F35, F87]
- In `ad7124_parse_channel_config()`, enforce `num_channels <= AD7124_MAX_CHANNELS` (16), child `"reg" < num_channels`, and `ad7124_valid_input_select()` on `"diff-channels"` pins (rejecting `[info->num_inputs, 16)` and `> 31`). In `ad7173_fw_parse_channel_config()`, validate current pins with `ad4111_validate_current_ain()` and voltage pins with `ad7173_validate_voltage_ain_inputs()`. [F64, F65, F66]
- In `ad7606.c`, `ad7606_get_chan_config()` converts 1-based DT `"reg"` to 0-based `reg - 1`. Scale accesses index `st->chan_info[0]` when `!st->sw_mode_en` and `st->chan_info[chan->scan_index]` when `st->sw_mode_en`, passing `i + ci->reg_offset` to `st->write_scale()` while storing `i` in `ci->range`. In `ad7616_write_scale_sw()`, split `ch` into group `ch & 0x1` and `ch_index = ch >> 1` before `AD7616_RANGE_CH_ADDR/MSK/MODE`. [F57, F69, F71]
- In `ad7606_set_sampling_freq()`, sample `ad7606_pwm_is_swinging(st)` and `duty_cycle == period` before updating `cnvst_pwm_state.period`, then set `duty_cycle` to `period`, `period / 2`, or `0`. In `ad7606_scan_direct()`, read `buf32[ch]` (`realbits > 16`) or `buf16[ch]`, mask with `GENMASK(realbits - 1, 0)`, and sign-extend if `sign == 's'`. In `ad7606_par16_read_block()`/`ad7606_par8_read_block()`, when `st->gpio_frstdata` is set, read the first sample alone and check `gpiod_get_value(st->gpio_frstdata)` high before `_buf++` and `num--` (else `ad7606_reset(st)` and `-EIO`). Callbacks using `to_spi_device()` on `dev`/`st->dev` must never run on `ad7606_par.c` paths. [F56, F73, F91, F113]
- In `adxl345_core.c`, runtime FIFO/event/measurement changes (`adxl345_set_fifo`, `adxl345_set_act_inact_en`, `adxl345_write_raw`, `adxl345_write_event_value`, `adxl345_fifo_reset`) must bracket writes with `adxl345_set_measure_en(st, false)` and `true`. `adxl345_set_range()` must sample `range_old` before updating range, then rescale `ADXL345_REG_THRESH_ACT` and `st->inact_threshold` (via `adxl345_set_inact_threshold()`, writing `THRESH_INACT` and `THRESH_FF`) by `adxl345_range_factor_tbl`, clamped to `[1, U8_MAX]`. `adxl345_set_odr()` must call `adxl345_set_inact_time(st, 0, 0)` after updating `ADXL345_REG_BW_RATE`. [F26, F54, F55, F104]
- In `adxl345_core.c`, `adxl345_set_tap_duration()` rejects `val_int != 0 || val_fract_us > 159375`, `adxl345_set_tap_window()`/`latent()` reject `val_int != 0 || val_fract_us > 318750`, and `_adxl345_set_tap_int()` requires `tap_window_us >= tap_latent_us` for double-tap. In `adxl345_push_event()`, each `int_stat` flag must use an independent `if` (not `else if`), with `ret = -ENOENT` default so unhandled IRQs trigger `adxl345_fifo_reset()`. [F77, F88]
- In `ad7280a.c`, `ad7280_chain_setup()` loops `n = 0..AD7280A_MAX_CHAIN` inclusive so a full chain ends with `val == 0` at `AD7280A_MAX_CHAIN`. Changes to `oversampling_ratio`, `acquisition_time`, or `slave_num` must call `ad7280_update_delay(st)` (using `DIV_ROUND_UP(st->readback_delay_us, 1000)` + 5 us). 32-bit SPI writes compute CRC-8 over `reg >> 11` into `GENMASK(10, 3)` before ORing `AD7280A_TRANS_WRITE_RES_PATTERN`; reads verify CRC-8 over `val >> 10` against `GENMASK(9, 2)` and use `CONV_*` vs `REG_*` masks for conversion vs register reads. [F59, F76, F93, F102]
- In `ad7779.c`, `ad7779_set_filter()` must call `ad7779_set_sampling_frequency(st, st->sampling_freq)` and update `st->filter_enabled`; `ad7779_set_data_lines()` must update `ad7779_set_sampling_frequency()`, `iio_backend_num_lanes_set()`, and `AD7779_REG_DOUT_FORMAT` together. In `ad7405_probe()`, call `ad7405_set_dec_rate()` (enforcing `[32, 4096]`) before registering the IIO device. [F60, F105]
- In `ad7291` and `ad7298`, voltage channel `x` (`0..7`) uses reversed bits `BIT(15 - x)` in `AD7291_COMMAND` and `AD7298_CH(x) = BIT(13 - x)`. In `ad7291.c`, `chip->command` must keep `AD7291_T_SENSE_MASK` set and set `chip->c_mask | AD7291_AUTOCYCLE` iff `chip->c_mask != 0`; `ad7291_read_raw()` must return `-EBUSY` for voltage reads when `AD7291_AUTOCYCLE` is set and never persist single-channel bits into `chip->command` (or `AD7291_ALERT_CLEAR` in `ad7291_event_handler()`). [F62, F78]
- In `adxl345_state`, `ad7266_state`, `ad7280_state`, `ad7298_state`, `ad7606_state`, `ad7766`, and `ad7779_state`, `__aligned(IIO_DMA_MINALIGN)` buffers (`data`, `fifo_buf`, `tx`, `rx_buf`) must stay at the end of the struct and be sized for all channels plus an `aligned_s64` timestamp when passed to `iio_push_to_buffers_with_ts`/`_timestamp`. [F136, F156]

## Synchronization

- In `ad7124.c`, `st->cfgs_lock` protects `st->channels[].cfg`, `st->cfg_slots_status`, and `st->live_cfgs_fifo`; `ad7124_update_scan_mode()` must call `__ad7124_set_channel()` while holding `st->cfgs_lock`. Always acquire `iio_device_claim_direct()` before `st->cfgs_lock` (never under `st->cfgs_lock`), as `ad7124_update_scan_mode()` takes `st->cfgs_lock` under IIO `mlock`. [F15, F16]
- In `ad7606.c`, `ad7606_write_raw()` takes `st->lock` before `iio_device_claim_direct()`, so callbacks under IIO `mlock` (`ad7606_update_scan_mode()`, `ad7606_buffer_ops`, `ad7606_backend_buffer_ops`) must never take `st->lock`. `ad7606_interrupt()` calls `iio_trigger_poll_nested(st->trig)` from a threaded IRQ without `iio_pollfunc_store_time()`, so `ad7606_trigger_handler()` must use `iio_get_time_ns(indio_dev)` instead of `pf->timestamp`. [F17, F138]
- Direct-mode sysfs callbacks must wrap hardware/state access in `iio_device_claim_direct()`/`iio_device_release_direct()`: `ad7606_read_raw()` (`RAW`, `CALIBBIAS`, `CONVDELAY`), `ad7779_read_raw()`/`ad7779_write_raw()`, `ad7266_read_raw()`, `ad7298_read_raw()`, and `ad7173_write_raw()`/`ad7173_set_filter_type()`/`ad7173_write_syscalib()`. Also, `ad7173_set_channel()` must run in process context (`ad7173_load_config()` uses `GFP_KERNEL`). In `ad7291.c`, hold `chip->state_lock` across checking `AUTOCYCLE`, writing `AD7291_COMMAND`, and reading `AD7291_VOLTAGE` in `ad7291_read_raw()`, and across updating `c_mask`/`command` in `ad7291_write_event_config()`. [F18, F20, F24, F142, F143]

## Object Lifetimes

- In `ad7606`, `ad7606_spi_offload_buffer_postenable()` acquires `spi_optimize_message()`, `spi_offload_trigger_enable()`, `ad7606_pwm_set_swing()`, and must unwind in reverse (`ad7606_pwm_set_low()`, `spi_offload_trigger_disable()`, `spi_unoptimize_message()`) on error and in `predisable`. In `ad7606_probe()`, when `!st->gpio_convst || st->offload_en`, `st->cnvst_pwm` must be acquired, set low via `ad7606_pwm_set_low()`, and registered with `ad7606_pwm_disable()` via `devm_add_action_or_reset()` before `iio_backend_config()`; runtime stop paths must use `ad7606_pwm_set_low()` (not `pwm_disable()`), and `ad7606_scan_direct()` must reset `gpio_convst`/`cnvst_pwm` low on all exit paths. [F1, F9, F10, F127]
- In `ad7766_preenable()`/`ad7766_postdisable()`, enable `ad7766->reg` regulators before and disable after `ad7766->mclk`, and assert `pd_gpio` high + sleep 20 ms before `clk_disable_unprepare(ad7766->mclk)`. In `ad7766_probe()` and `ad7779_setup_without_backend()`, request `spi->irq` with `IRQF_NO_AUTOEN` and balance `enable_irq()`/`disable_irq()` in trigger/buffer enable/disable. Call `iio_trigger_get(st->trig)` when assigning `indio_dev->trig = st->trig` in `ad7606_probe()` and `ad7779_setup_without_backend()`. [F2, F11, F12]
- In `ad7173.c`, initialize `cfg.openwire_comp_chan = -1` in `ad7173_fw_parse_channel_config()`, and reset `openwire_comp_chan = -1` and clear `AD4111_GPIO_GP_OW_EN` on all exit paths of `ad4111_openwire_event()`. In `ad7280_chain_setup()`, write `AD7280A_CTRL_HB_PWRDN_SW` on any error after reset and register `ad7280_sw_power_down()` via `devm_add_action_or_reset()` in `ad7280_probe()`. In `ad7124_probe()` and `ad7173_probe()`, `devm_ad_sd_setup_buffer_and_trigger()` must precede calibration/setup. In `adxl345_core_probe()`, clear `ADXL345_REG_INT_ENABLE` and run `devm_iio_kfifo_buffer_setup()` before `devm_request_threaded_irq()`. [F4, F7, F14, F25, F34]

## API Contracts

- In `ad7173.c` and `ad7124.c`, pass the 0-based slot index (`chan->address` or `i`)—never `chan->channel` or `ch->ain`—to `ad_sd_calibrate()` and `ad_sigma_delta_info` callbacks. In `ad7124_calibrate_all()`, lower `AD7124_ADC_CONTROL_POWER_MODE` to `AD7124_MID_POWER` when `>= AD7124_FULL_POWER` before `__ad7124_calibrate_all()` and restore after. In `ad7173_update_scan_mode()`, if enabled channels have `!ad7173_is_setup_equal()` on the same `cfg_slot`, clear all `st->channels[k].cfg.live` before returning `-EINVAL`; if any uses `AD7173_FILTER_SINC3`, all must share `SINC3` and `sinc3_odr_div`. [F29, F118, F157]
- In `ad7606`, `ad7606_set_sampling_freq()` rejects `freq == 0` and uses `DIV_ROUND_UP_ULL(NSEC_PER_SEC, freq)`. Pass `DECLARE_BITMAP(..., 3)` to `gpiod_multi_set_value_cansleep()` for `st->gpio_os`. Set `.cs_change = 1` on the first `spi_transfer` in `ad7606_spi_reg_read()`. Store `reg_read()` into `*readval` and return `0` in `ad7606_reg_access()`. Require all `num_adc_channels` enabled in `ad7606_spi_update_scan_mode()` when `st->offload_en`; omit `IIO_CHAN_SOFT_TIMESTAMP` when `!slow_bus` (`iio_backend_config` or `offload_en`), and omit `INDIO_DIRECT_MODE` and `BIT(IIO_CHAN_INFO_RAW)` when `iio_backend_config` is set. Copy channel templates per-device with `scan_type.endianness = IIO_CPU` for `ad7779`/`ad7173` backend/offload. [F100, F107, F125, F147, F149, F151, F153]
- Compare `adxl345_get_int_line()` against `ADXL345_INT_NONE` (`0xff`), not `< 0` or `0`. Pass `ad7280a_devaddr()`-reversed addresses to `ad7280_write()`, `ad7280_read_reg()`, and `ad7280_read_channel()`. In `ad7779_conf()`, set `AD7779_SPI_CRC_EN_MSK` in `AD7779_REG_GEN_ERR_REG_1_EN` first, and omit the 3rd CRC8 byte in `ad7779_spi_read()`/`write()` iff `reg == AD7779_REG_GEN_ERR_REG_1_EN`. Set `*length` to `2 *` pair count for `[][2]` `IIO_AVAIL_LIST` tables (`adxl345`, `ad7124`, `ad7606`); return `len` (`ret ?: len`) from `iio_chan_spec_ext_info.write`; and call `iio_trigger_notify_done()` on all exit paths of trigger poll handlers (with `ad7606_trigger_handler()` also asserting `st->gpio_convst` high). [F37, F39, F111, F133, F152, F155]

## Error Handling

- In `ad7606.c`, NULL-check optional `ad7606_bus_ops` callbacks (`sw_mode_config`, `update_scan_mode`, `offload_config`, `iio_backend_config`); check `st->offload_en` rather than `st->bus_data` or `bus_data->offload` (`ERR_PTR(-ENODEV)` when absent); and never use PWM helpers or `IIO_CHAN_INFO_SAMP_FREQ` when `st->gpio_convst && !st->offload_en`. [F28, F31, F41]
- Check `ret < 0` after `iio_device_release_direct()` for helpers run under `iio_device_claim_direct()` (`ad7266_read_single`, `ad7606_scan_direct`, `ad7298_scan_direct`, `iio_backend_oversampling_ratio_set`). When `devm_regulator_get_optional()` returns `ERR_PTR(-ENODEV)`, keep `ERR_PTR(-ENODEV)` in `ad7124` `st->vref[i]`, but set `chip->reg` / `st->reg` to `NULL` in `ad7291_probe()` and `ad7298_probe()`. Check `< 0` on tri-state `adxl345_is_act_inact_ac()`/`en()`, and reject `<= 0` ODR in `ad7124_write_raw()`. [F30, F32, F33, F36, F94]

## External Contracts

- In `ad7606_probe_channels()`, when `st->sw_mode_en` is true, put `BIT(IIO_CHAN_INFO_OVERSAMPLING_RATIO)` in `info_mask_shared_by_type` on slow buses and `info_mask_shared_by_all` on backend/offload buses. Do not set `.indexed = 1` on `IIO_TEMP` in `ad7173` or `ad7124`. In `ad7173_validate_voltage_ain_inputs()`, never pair divided (`< num_voltage_in_div`) and undivided (`>= num_voltage_in_div`) pins (including `AD4111_VINCOM_INPUT`). In `adxl345_fifo_transfer()`, call `udelay(3)` after each 6-byte read when `st->fifo_delay && samples > 1`. [F79, F124, F144, F148]

## Known Pitfalls

- In `ad7173_fw_parse_channel_config()`, index 0 holds `ad7173_temp_iio_channel_template` (`chan_index = 1`) when `has_temp` is true, and `is_current_chan = false` and `*chan = ad7173_channel_template` must reset each iteration; ODR indices start at `st->info->odr_start_value`; `ad7173_read_raw()` (`IIO_TEMP` offset) must widen `temp` to `u64` before `<< realbits`; and shadow bitfields (`st->adc_mode`, `st->adc_control`) must be cleared with `& ~mask` (not `& !mask`). [F81, F82, F83, F96, F122]
- In `ad7606`: size `xfer->len` in `ad7606_spi_offload_buffer_postenable()` from `realbits` (not `storagebits`); pass byte counts (`2` and `num * 2`) to `insb()` in `ad7606_par8_read_block()` while advancing `u16 *_buf`; ensure `num_scales > 0` and `num_os_ratios > 0` for `buf[len - 1] = '\n'`; mask `val & 0xFF` in `ad7606_spi_reg_write()` and `GENMASK(realbits - 1, 0)` before sign-extending in `ad7606_scan_direct()`; and in `ad7606_par_probe()` with `dev_fwnode()`, use `device_get_match_data()` and route `"io-backends"` to `&ad7606_bi_bops` before IRQ/MMIO. [F72, F109, F114, F126, F128]
- In `adxl345`: run `setup()` before reading `ADXL345_REG_DEVID` and use `regmap_update_bits()` with `data_format_mask` on `ADXL345_REG_DATA_FORMAT`; scale `st->fifo_buf` offsets by `i * ADXL345_DIRS` and `regmap_bulk_read()` by `sizeof(st->fifo_buf[0]) * ADXL345_DIRS`; and `sign_extend32(regval, 7)` before `* 4` for `CALIBBIAS`. In `ad7298_update_scan_mode()`, samples use `ring_xfer[i + 2]` and `ring_xfer[i + 1].cs_change = 0` clears the last transfer. In `ad7779_set_calibscale()`, use 64-bit `val * 5592405LL` with `DIV_ROUND_CLOSEST_ULL(..., MEGA)`. [F92, F99, F103, F110, F116]
