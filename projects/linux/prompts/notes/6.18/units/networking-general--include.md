# NETWORKING [GENERAL] — include

Core and protocol-level kernel headers (`include/linux/` and `include/net/`) defining `struct sk_buff`, `struct skb_shared_info`, `struct socket`, `struct dst_entry`, `struct metadata_dst`, Netlink/RTNetlink, Ethtool, TC actions, CoDel (`codel_impl.h`), framers, and protocol headers.

## Architecture & Data Flow

- `skb->_skb_refdst` and `skb_dstref_steal()` encode `SKB_DST_NOREF` (`1UL`) in bit 0; extract pointers via `skb_dst()`/`refdst_drop()` (`SKB_DST_PTRMASK`), never raw casts. `skb_dst(skb)` may be a routing `dst_entry` or `metadata_dst` (`DST_METADATA`); downcast via `skb_metadata_dst(skb)`, check `md_dst->type` before reading `md_dst->u`, and check `skb_valid_dst(skb)` for routing entries. Every `enum metadata_type` needs a `case` in `skb_metadata_dst_cmp()` (`default` returns `1`), and `METADATA_IP_TUNNEL` allocations, copies, and comparisons must include `u.tun_info.options_len` bytes past `sizeof(struct ip_tunnel_info)`. [F795, F796, F859, F879]
- `dst->_metrics` encodes `DST_METRICS_FLAGS` (`DST_METRICS_READ_ONLY` `0x1UL`, `DST_METRICS_REFCOUNTED` `0x2UL`) in low bits. Extract pointers with `DST_METRICS_PTR(dst)`/`__DST_METRICS_PTR()`, 4-byte-align arrays in `dst_init_metrics()`, and never write directly to `DST_METRICS_PTR(dst)`—use `dst_metric_set()` or `dst_metrics_write_ptr(dst)` (checking for `NULL` in case `cow_metrics()` fails). [F789, F797, F821]
- In `struct sk_buff`, `next`/`prev` must stay first (matching `sk_buff_head`/`sk_buff_list`); clone-preserved fields belong in `struct_group(headers, ...)`, keeping `tail`, `end`, `head`, `data`, `truesize`, `users`, and `extensions` at the end. Moving `cloned`, `pkt_type`, `tstamp_type`, or `tc_at_ingress` relative to `__cloned_offset`, `__pkt_type_offset`, or `__mono_tc_offset` requires updating `CLONED_*`, `PKT_TYPE_*`, or `SKB_TSTAMP_TYPE_MASK`/`TC_AT_INGRESS_MASK`/`SKB_BF_MONO_TC_OFFSET`. [F811, F812, F847]
- In `struct skb_shared_info`, fields before `dataref` are bulk-cleared in `__alloc_skb()`, and `frags[MAX_SKB_FRAGS]` must stay last (`pskb_expand_head()` copies up to `frags[nr_frags]`). `dataref` packs total refs in low 16 bits (`SKB_DATAREF_MASK`) and `nohdr` refs in high 16 bits (`>> SKB_DATAREF_SHIFT`), so `skb_header_cloned()` checks `(dataref & SKB_DATAREF_MASK) - (dataref >> SKB_DATAREF_SHIFT) != 1` and `skb_data_unref()` subtracts `(1 << SKB_DATAREF_SHIFT) + 1` when `skb->nohdr` is set. `container_of(skb, struct sk_buff_fclones, skb1)` requires `skb->fclone == SKB_FCLONE_ORIG`. [F813, F872, F885]
- Coupled `sk_buff` state: set `skb->slow_gro |= !!val` when attaching `_skb_refdst` or `_nfct`; `skb->sk` requires non-NULL `skb->destructor` (`BUG_ON` in `skb_orphan()`); update `hash`, `sw_hash`, and `l4_hash` together via `__skb_set_hash()`, `skb_clear_hash()`, or `skb_copy_hash()`; set unioned `inner_protocol`/`inner_ipproto` via `skb_set_inner_protocol()`/`skb_set_inner_ipproto()`; `skb_tstamp()` is 0 and `skb_clear_tstamp()` is a no-op when `tstamp_type != 0`, so use `skb_clear_delivery_time()` on ingress and reset `tstamp_type` when `kt == 0`; unioned `napi_id`/`sender_cpu` requires `napi_id_valid()` before setting `skb->napi_id` or calling `napi_busy_loop()`, and `sk_mark_napi_id()` updates `sk->sk_napi_id` with `sk_rx_queue_update()`. [F810, F815, F816, F817, F825, F826]
- `skb_shinfo(skb)->destructor_arg` is a zerocopy pointer only when `skb_zcopy(skb)` is true and may carry bit `0x1UL` (`skb_zcopy_set_nouarg()`); check `!skb_zcopy_is_nouarg(skb)` before `skb_uarg(skb)`, and check `uarg->ops == &msg_zerocopy_ubuf_ops` before `uarg_to_msgzc()`. `skb->extensions` is valid only when `skb->active_extensions != 0` (`skb_ext_exist()`/`skb_ext_find()`); `skb_ext.offset[]` and `chunks` use 8-byte units (`0` = absent; `<< 3`), and `SKB_EXT_NUM <= 8`. [F798, F799, F853]
- `__skb_fill_netmem_desc()` must set `skb->unreadable = true` for `net_iov` frags and `skb->pfmemalloc = true` for `pfmemalloc` pages; never use `*_noacc()` for new RX pages or `net_iov`s. In `skb_mac_header_rebuild*()`, read `old_mac = skb_mac_header(skb)` before `skb_set_mac_header()` and use `memmove()`. [F819, F824]
- Layout and Ethtool invariants: `dst_entry.__rcuref` must stay at offset 64 (`dst_hold()`); `socket_wq.wait` must be first; `prefix_info` must be 32 bytes; `skb->cb` (`netlink_skb_parms`) and `netlink_callback.ctx` (`NL_ASSERT_CTX_FITS()`) must be `<= 48` bytes. Access `ethtool_rxfh_context.data[]` only via `ethtool_rxfh_context_priv()`, `ethtool_rxfh_context_indir()` (`ALIGN(priv_size, 4)`), and `ethtool_rxfh_context_key()`. New `ETH_RSS_HASH_*_BIT` values require updating `rss_hash_func_strings[]`. [F829, F832, F838, F839, F840, F845]
- Time and CoDel: `dst_set_expires()` substitutes `1` if `jiffies + timeout == 0` and uses `time_before()`; `busy_loop_timeout()`/`sk_busy_loop_timeout()` use `time_after()`; `codel_time_t` uses `codel_time_after*`/`codel_time_before*`. In `codel_dequeue()`, the drop loop must `goto end;` after `INET_ECN_set_ce(skb)` and clear `vars->dropping = false` when `codel_should_drop()` is `false`. [F862, F867, F870, F871]

## Synchronization

- With `CONFIG_NETPOLL` and `dev->npinfo`, NAPI polling must serialize via `netpoll_poll_lock(napi)` (`cmpxchg` on `poll_owner`) and `netpoll_poll_unlock()` (`smp_store_release`). In `skb_unref()` (`users == 1` with `!CONFIG_DEBUG_NET`) and `skb_data_unref()` (`dataref == bias`), the non-atomic fast path must execute `smp_rmb()` before returning `true`. [F776, F777]
- Per-CPU `dst_cache_get*()`/`dst_cache_set*()` require local BH disabled. Live `dst_cache` invalidation must use `dst_cache_reset()`; `dst_cache_reset_now()` and `dst_cache_destroy()` are unsynchronized and require no concurrent users. [F778, F779]
- `tc_action_ops->act` runs under RCU BH lock (no sleeping) and `tcf_register_action()` requires non-NULL `act`, `dump`, and `init`. Updating `a->tcfa_bstats` when `a->cpu_bstats == NULL` requires holding `a->tcfa_lock` (`tcf_action_update_bstats()`). [F780, F929]
- Non-atomic `__skb_insert`, `__skb_unlink`, `__skb_dequeue`, and `__skb_queue_*` require `list->lock` (or queue ownership) and must update `next`, `prev`, and `qlen` with `WRITE_ONCE()` to pair with `READ_ONCE()` in `skb_queue_empty_lockless()` and `skb_peek_tail()`. [F781]
- `rtnl_dereference()` and `dev_ingress_queue()` require `rtnl_lock()`; RCU-only readers must use `rcu_dereference_rtnl()`/`rcu_dereference()` (`dev_ingress_queue_rcu()`). `task_cls_classid()` returns `0` when `in_interrupt()` and reads `task_css()` under `rcu_read_lock()`; `task_get_classid()` checks `softirq_count()` and uses `sk->sk_cgrp_data` in softirq. [F783, F912]

## Object Lifetimes

- `skb_dst_set()`, `skb_dst_set_noref()`, and `skb_dstref_restore()` assert via `skb_dst_check_unset()` that no refcounted dst is held; call `skb_dst_drop(skb)` first. `SKB_DST_NOREF` requires RCU/RCU-BH read lock for `skb_dst_set_noref()` and `skb_dst()`, and `skb_dst_force()` under `rcu_read_lock()` before leaving RCU or queuing. [F753, F913]
- `*skb_fill_netmem_desc()` and `*skb_fill_page_desc()` transfer the caller's page/netmem ref without incrementing it. When `SKBFL_MANAGED_FRAG_REFS` (`skb_zcopy_managed(skb)`) is set, `skb_frag_unref()` is a no-op; call `skb_zcopy_downgrade_managed(skb)` before taking or dropping individual frag refs. [F757, F937]
- Use `skb_ext_reset(skb)` (not `skb_ext_put(skb)`, which leaves `active_extensions` set) on live skbs. Use `skb_ext_copy()` and `nf_copy()` instead of `__skb_ext_copy()` and `__nf_copy()` when `dst` may already hold a reference. [F759, F760]
- `skb_zcopy_set(skb, uarg, &have_ref)` consumes `*have_ref` on the first call (`*have_ref = false`) and calls `net_zcopy_get()` thereafter; error paths must call `net_zcopy_put_abort(uarg, have_ref)`. `mm_account_pinned_pages(&uarg->mmp, ...)` requires a zeroed `mmp->user` and pairs with `mm_unaccount_pinned_pages(&uarg->mmp)`. [F761, F944]
- `skb_peek*()` returns a borrowed pointer without incrementing `skb->users`; hold the queue lock or `skb_get()` before unlocking. Use `netlink_skb_clone()` (not `skb_clone()`) on Netlink skbs to preserve `destructor` when `is_vmalloc_addr(skb->head)`. [F762, F770]
- Initialize shared/static dst metrics (e.g., `dst_default_metrics`) with `dst_init_metrics(dst, src, true)`. In `tun_dst_unclone()`, re-init non-NULL `new_md->u.tun_info.dst_cache.cache` via `dst_cache_init()` and call `metadata_dst_free(new_md)` on error before dropping `skb`'s old dst. [F764, F765]
- `__in6_dev_get*()` requires RCU or RTNL and takes no ref (use `__in6_dev_stats_get(dev, skb)` for L3 master/VRF stats); otherwise use `in6_dev_get()`/`in6_dev_put()`. `__in6_dev_put()` and `__in6_ifa_put()` only call `refcount_dec()` without destroy, so use them only when another ref is held; under RCU lookup where refcnt may be 0, use `in6_ifa_hold_safe()` (`refcount_inc_not_zero()`, as in `__ipv4_neigh_lookup()`). [F767, F784, F923, F939]
- In `tc_action_net_exit()`, call `tcf_idrinfo_destroy(tn->ops, tn->idrinfo)` before `kfree(tn->idrinfo)`. Framer users must call `framer_init()` before `framer_power_on()`/`get_status()`/`*config()` and `framer_power_off()` before `framer_exit()`; `FRAMER_FLAG_POLL_STATUS` requires `.get_status`. When `ethtool_ops.begin` returns 0, the core always calls `.complete` even on callback error—do not release `begin` state in the callback error path. [F768, F890, F896, F928]

## API Contracts

- `skb_share_check()` and `skb_unshare()` always consume the input `skb` (freeing on `NULL` return); along with `skb_unclone*()` and `skb_header_unclone()`, they call `might_sleep_if()`, so atomic/RCU/softirq callers must pass `GFP_ATOMIC`. `skb_pad*()`/`skb_put_padto()` free `skb` on error, whereas `__skb_pad()`/`__skb_put_padto(..., false)` do not. [F755, F756, F919]
- Use `skb_tail_pointer()`, `skb_end_pointer()`, `skb_end_offset()`, and `skb_*_tail_pointer()` for `tail`/`end`. `transport_header`/`mac_header` use `~0U` when unset (`skb_*_header_was_set()`), whereas `inner_network_header` checks `> 0`. Use `skb_reset_transport_header_careful()` when `skb->data - skb->head` may exceed `u16` or be untrusted. `__skb_pull()`/`skb_pull_inline()` `BUG()` if `len > skb_headlen(skb)`; use `pskb_may_pull()` or `skb_header_pointer()` for nonlinear data. [F850, F851, F852, F947]
- Loops unlinking/freeing `skb` must use `skb_queue_walk_safe()` (or `*_safe`) or `skb_rbtree_walk_from_safe()`. `skb_queue_next()`/`skb_queue_prev()` `BUG_ON()` at the ends—check `!skb_queue_is_last()`/`!skb_queue_is_first()` or use `skb_peek_next()`. Check `skb_rx_queue_recorded(skb)` before `skb_get_rx_queue(skb)` (`queue_mapping - 1`) and never mix with `skb_set_queue_mapping()`/`skb_get_queue_mapping()`. [F805, F854, F856, F857]
- Checksums: with `CHECKSUM_PARTIAL`, `skb->csum_start` is from `skb->head` (`skb_checksum_start_offset()` is from `skb->data`). Never set `NETIF_F_IP_CSUM`/`NETIF_F_IPV6_CSUM` with `NETIF_F_HW_CSUM`, and check `skb->csum_not_inet` with `NETIF_F_SCTP_CRC`. On RX, `CHECKSUM_UNNECESSARY` must not modify the header checksum, and whole-packet hardware csums must use `CHECKSUM_COMPLETE`. [F809, F901, F902]
- TX-to-RX forwarding/loopback must call `skb_orphan_frags_rx()` (not `skb_orphan_frags()`, which skips `SKBFL_DONT_ORPHAN`). Validate zero-copy send pages with `sendpage_ok()`/`sendpages_ok()`. `skb_irq_freeable()` requires no `destructor`, `secpath`, `nfct`, `_skb_refdst`, or `frag_list`. [F920, F936, F940]
- `netdev_alloc_frag_align()`/`napi_alloc_frag_align()` take power-of-2 `align`; `__*` variants take `-align`. `__dev_alloc_page*()` ORs `__GFP_COMP | __GFP_MEMALLOC`, so non-RX callers must pass `__GFP_NOMEMALLOC`. Map frags with `skb_frag_dma_map()` (not `dma_map_page()`, which fails on `net_iov`). Iterate compound/highmem frags with `skb_frag_foreach_page()` and `skb_frag_address_safe()`. [F806, F916, F917, F918]
- `dst_metric*()` indexes `p[metric - 1]` (`RTAX_*`), `dst_metric_locked()` shifts `1 << metric`, and `dst_metric()` warns on `RTAX_HOPLIMIT`/`RTAX_ADVMSS`/`RTAX_MTU`. `ipv4_change_dsfield()` and `ipv6_change_dsfield()` compute `(dsfield & mask) | value` (`mask` = bits kept, `value` pre-shifted; cast to `u16` before `<< 4` in IPv6). Access split ERSPAN `vlan`, `session_id`, and `hwid` via `get_*()`/`set_*()`. Use `INDIRECT_CALL_INET()` when IPv6 may be `=m`. Netlink privilege checks must use `netlink_ns_capable()`/`netlink_net_capable()`/`netlink_capable()`. `NL_SET_ERR_MSG()` requires a string literal; use `NL_SET_ERR_MSG_FMT()` for format strings (`<= 80` bytes). [F804, F808, F836, F875, F887, F921, F943]
- Ethtool: `ethtool_get_phc_vclocks()` returns a caller-freed `*vclock_index` when `> 0`; `ethtool_sprintf()`/`ethtool_puts()`/`ethtool_cpy()` advance `*data` by `ETH_GSTRING_LEN`; link mode bitmaps use `__ETHTOOL_LINK_MODE_MASK_NBITS` and `bitmap_*_arr32()`/`ethtool_convert_*_u32*()`; `ethtool_rxfh_indir_default()` requires `n_rx_rings != 0`; `ethtool_mmsv` commits preemptible TCs in `configure_tx` only when `tx_active` and calls `ethtool_mmsv_stop()` on teardown. [F769, F844, F873, F888, F889, F897]
- `ethtool_ops`: `set_coalesce` requires `supported_coalesce_params`; `supported_input_xfrm` requires `get_rxfh_fields` and `rxfh_per_ctx_fields == rxfh_per_ctx_key`; `rxfh_max_num_contexts` is exclusive (`!= 1`); `create_rxfh_context` requires `modify`/`remove_rxfh_context` and populates `@ctx` defaults when `NULL`/`NO_CHANGE`; `*per_queue_coalesce` must bounds-check queue indices; RMON/FEC hist ranges need a `{}` sentinel; `get_fec_stats` sets either `total` or `lanes[]` (`ETHTOOL_STAT_NOT_SET` when unused). [F828, F841, F843, F899, F924, F927]

## Error Handling

- `devm_framer_optional_get()` returns `NULL` when absent/disabled and `ERR_PTR` on error, whereas `framer_init()`/`power_on()`/`power_off()`/`exit()` dereference `framer` unconditionally; check both `IS_ERR()` and non-`NULL`. `tun_dst_unclone()` returns `ERR_PTR` on error, whereas `skb_tunnel_info_unclone()`, `tun_rx_dst()`, `__ip*_tun_set_dst()`, and `dst_neigh_lookup*()` return `NULL`. [F787, F788, F790]
- `NL_REQ_ATTR_CHECK()` returns `1` when missing; return `-EINVAL`, not its return value. Use `NL_SET_ERR_MSG_WEAK*()` in outer cleanup paths to preserve inner `extack->_msg`. `*skb_checksum_validate*()`, `skb_checksum_complete()`, and `skb_checksum_init*()` return `0` when valid and non-zero when invalid. `skb_frag_page()`/`skb_frag_address*()` return `NULL` on `net_iov` frags; `skb_frag_net_iov()` returns `NULL` on page frags. [F791, F792, F800, F803]

## External Contracts

- 32-bit compat structs with 64-bit fields or `__kernel_sockaddr_storage` (`compat_ethtool_rx_flow_spec`, `compat_ethtool_rxnfc`, `compat_group_*`) must use `compat_u64` or `__aligned(4) __packed`. `sctphdr.checksum` is `__le32` while `source`/`dest`/`vtag` are big-endian. Stats structs using `ethtool_stats_init()` (`link_down_events`) must use `u64` set to `ETHTOOL_STAT_NOT_SET`. `proto_ops::recvmsg` must set `msg->msg_namelen` only if `msg->msg_name != NULL`. [F837, F846, F874, F941]

## Known Pitfalls

- Reload `skb->data`, `skb_network_header(skb)`, and `skb_shinfo(skb)` after calls that may reallocate `skb->head` (`pskb_expand_head()`, `pskb_may_pull()`, `skb_cow()`, `skb_try_make_writable()`, `pskb_trim_rcsum()`). After `skb_queue_walk*()` finishes without `break`, `skb` is `(struct sk_buff *)(queue)`, not `NULL`. In `skb_frag_foreach_page()`, when `!skb_frag_must_loop(p)`, `p_len` is the full compound `f_len` (`> PAGE_SIZE`). In `__skb_metadata_differs()`, `32->24->16->8` and `28->20->12->4` mutate `a`/`b` in-place and must not fall through to `default:`/`slow:`. `skb_dst_set_noref(skb, NULL)` sets `SKB_DST_NOREF`, so always test `skb_dst_is_noref(skb)`. [F814, F855, F858, F860, F864]
- Overflow guards: in `codel_Newton_step()`, cast `invsqrt` to `u64` before squaring and shift `val >>= 2` before `* invsqrt`; in `codel_time_to_us()`, cast `val` to `u64` before `<< CODEL_SHIFT` and use `do_div()`; in `codel_control_law()`, shift `rec_inv_sqrt << REC_INV_SQRT_SHIFT`; in `addrconf_timeout_fixup()`, return `~0UL` for `INFINITY_LIFE_TIME` and clamp to `LONG_MAX / unit`. [F865, F866, F868, F869]
