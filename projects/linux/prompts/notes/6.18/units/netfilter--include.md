# NETFILTER — include

Core kernel-internal headers, data structures, and inline helpers for Netfilter, spanning hook dispatch (`linux/netfilter.h`), `nf_tables` (`net/netfilter/nf_tables.h`), conntrack (`net/netfilter/nf_conntrack*.h`), flow tables (`net/netfilter/nf_flow_table.h`), IP sets (`linux/netfilter/ipset/*.h`), and Xtables (`linux/netfilter/x_tables.h`).

## Architecture & Data Flow

- `nf_tables` allocates registers in 32-bit (`NFT_REG32_SIZE`) units, and in `struct nft_regs` and `struct nft_data`, `verdict` (`struct nft_verdict`) aliases `data[0..3]`. Writes to `regs->data` not a multiple of 4 bytes must zero the trailing bytes of the last 32-bit slot (`nft_reg_store8`, `nft_reg_store16`, `nft_data_copy`), and mutating `regs->verdict` clobbers `regs->data[0..3]` and vice versa. [F36, F49]
- In `nf_tables` objects and `struct nft_set_ext`, a set bit in `genmask` marks it inactive in that generation; active checks (`nft_is_active`, `nft_is_active_next`, `nft_active_genmask`, `nft_set_elem_active`) must test `!(genmask & mask)`. `struct nft_set_ext` must be aligned to `BITS_PER_LONG / 8` with `genmask` at offset 0 (and `set->ops->elemsize` in `nft_set_elem_ext()` must preserve word alignment) because `nft_set_elem_dead()` and `nft_set_elem_is_dead()` cast `struct nft_set_ext *` to `unsigned long *` for atomic bitops. [F79, F114]
- `nft_set_ext_add_length()` must check `tmpl->len > U8_MAX` after aligning `tmpl->len` (`u16`) before storing `tmpl->offset[id] = tmpl->len`, as `offset` is a `u8` array where `0` means absent. `__nft_set_elem_expired()` must check both `nft_set_ext_exists(ext, NFT_SET_EXT_TIMEOUT)` and `nft_set_ext_timeout(ext)->timeout != 0` before `time_after_eq64(tstamp, expiration)`, as `timeout == 0` marks a permanent element. [F92, F93]
- `nft_setelem_expr_foreach(__expr, __elem_expr, __size)` bounds iteration by `(__elem_expr)->size` and advances by `(__expr)->ops->size`; increment `elem_expr->size` only after each expression in `elem_expr->data` is initialized, and keep `(__expr)->ops` valid through the loop step. [F82]
- In `struct nft_rule`, `rule->dlen` is a 12-bit bitfield (`< 4096` bytes of packed expressions in `rule->data[]`). When `rule->udata` is non-zero, `struct nft_userdata` is at `&rule->data[rule->dlen]` (`nft_userdata(rule)`) and encodes payload length `ulen` as `udata->len = ulen - 1`; check `rule->udata` first and use `udata->len + 1` as byte size. In `struct nft_rule_blob`, rules advance by `sizeof(struct nft_rule_dp) + rule->dlen` via `nft_rule_next()` and end at `(void *)blob + sizeof(*blob) + blob->size`, with a `struct nft_rule_dp_last` trailer (`end.is_last = 1` at offset 0) past `blob->size`. [F77, F96, F99]
- `struct nft_trans` must be the first member of every transaction subtype, and `struct nft_trans_binding` must be first in binding-capable subtypes (`struct nft_trans_set`, `struct nft_trans_chain`); check `trans->msg_type` before downcasting via `nft_trans_container_*`. Pending `NFT_MSG_NEWSET` transactions must be linked via `struct nft_trans_set::list_trans_newset` into `nftables_pernet::commit_set_list` and unlinked on commit/abort. [F40, F84]
- In `__nft_set_pktinfo_ipv4_validate()` and `__nft_set_pktinfo_ipv6_validate()`, compare packet/payload lengths (`skb_len < len`, `len < thoff`, `pkt_len + sizeof(*ip6h) > skb_len`) against `pkt->skb->len - skb_network_offset(pkt->skb)`. In IPv4, check `len < thoff` before adding `skb_network_offset(pkt->skb)` to `pkt->thoff`; in IPv6, verify `ipv6_find_hdr()`'s `thoff <= U16_MAX` before storing into `u16 pkt->thoff`. [F62, F63]
- In `struct nf_conn`, `nf_conntrack_alloc()` only zeroes fields after `__nfct_init_offset` via `memset_after()`, and `union nf_conntrack_proto proto` must remain the last member. `nf_ct_tuplehash_to_ctrack(hash)` uses `container_of(hash, struct nf_conn, tuplehash[hash->tuple.dst.dir])`, requiring `hash` in `ct->tuplehash[]` with `tuple.dst.dir` set and placed after `dst.__nfct_hash_offsetend`. `ct->timeout` stores a relative jiffies duration while unconfirmed (`!nf_ct_is_confirmed(ct)`) and an absolute `nfct_time_stamp` expiration once confirmed; never call `nf_ct_expires()`/`nf_ct_is_expired()` on an unconfirmed `ct`. [F43, F55, F102]
- In `ip_set`, `IP_SET_INIT_UEXT` sets `ext.bytes` and `ext.packets` to `ULLONG_MAX`, and `ip_set_init_counter()` only writes counters that are not `ULLONG_MAX`. `opt->ext.timeout` uses `IPSET_NO_TIMEOUT` (`UINT_MAX`) to fall back to `set->timeout` via `ip_set_adt_opt_timeout()`, while `IPSET_ELEM_PERMANENT` (`0`) in a stored timeout word means permanent; if `msecs_to_jiffies(value * MSEC_PER_SEC) + jiffies` wraps to `0` in `ip_set_timeout_set()`, decrement it (`t--`). [F32, F33, F61]

## Synchronization

- `nf_hook_ingress()` requires `rcu_read_lock()` and must recheck `rcu_dereference(skb->dev->nf_hooks_ingress)` even after `nf_hook_ingress_active(skb)`. In `nf_hook_egress()`, even under `rcu_read_lock_bh()`, `nf_hook_slow()` must be wrapped in `rcu_read_lock()` / `rcu_read_unlock()`. [F17, F18]
- `xt_write_recseq_begin()` requires preemption and softirqs disabled, and its returned `addend` (`0` or `1`) must be passed unchanged to `xt_write_recseq_end(addend)` on the same CPU. `NF_CT_STAT_INC()` and `NF_FLOW_TABLE_STAT_INC()`/`DEC()` use `__this_cpu_inc()`/`dec()` and require BH/preemption disabled; otherwise use the `*_ATOMIC()` variants. [F10, F113]
- In `nf_flow_table_offload_add_cb()` and `nf_flow_table_offload_del_cb()`, protect `flow_table->flow_block.cb_list` with `down_write(&flow_table->flow_block_lock)`, and call `flow_table->type->get` or `put` after `up_write(&flow_table->flow_block_lock)`. [F19]
- Readers checking the active `nf_tables` generation bitmask must use `nft_genmask_cur(net)` (`READ_ONCE(net->nft.gencursor)`). `nft_rule_expr_deactivate()` and `nf_tables_deactivate_set()` require `nft_pernet(net)->commit_mutex`, and `nf_tables_rule_destroy()` / `nf_tables_chain_destroy()` must run in sleepable context only after `synchronize_rcu()` once unlinked. [F23, F116]
- When saving or restoring per-CPU inner tunnel header offsets in `struct nft_inner_tun_ctx`, disable BH (`local_bh_disable()`) while checking `cookie == (unsigned long)pkt->skb` (with `NFT_PKTINFO_INNER_FULL` and `type`) and copying to/from a stack `struct nft_inner_tun_ctx`. [F117]
- `nf_conntrack_get_ht()` requires `rcu_read_lock()` so `*hash` read under `nf_conntrack_generation` is not freed during `nf_conntrack_hash_resize()`. Callers of `nf_ct_should_gc()` must hold a reference on `ct`, and `nf_ct_should_gc()` must run `smp_acquire__after_ctrl_dep()` after `nf_ct_is_confirmed(ct)` and before `nf_ct_is_expired(ct)`. In `nf_conntrack_event_cache()`, update `e->timestamp` only when `local64_read(&e->timestamp) != 0` and `READ_ONCE(e->cache) == 0` before `set_bit(event, &e->cache)`. [F24, F109, F110]

## Object Lifetimes

- `nf_ct_get()` returns a borrowed `struct nf_conn *` from `skb->_nfct` without incrementing `ct->ct_general.use`; do not pass it to `nf_ct_put()` without taking a reference first. In `nf_conntrack_confirm()`, after `__nf_conntrack_confirm(skb)` returns `NF_ACCEPT`, reload `ct` from `skb_nfct(skb)` because clash resolution can replace `skb->_nfct` and free the losing `ct`. [F4, F53]
- `nf_ct_expect_alloc()` sets `exp->use = 1`, and `nf_ct_expect_related_report()` (or `nf_ct_expect_related()`) takes internal references only when insertion succeeds; callers must call `nf_ct_expect_put()` after `nf_ct_expect_related_report()` on both success and failure. [F5]
- `flow_offload_alloc(ct)` increments `ct->ct_general.use` into `flow->ct`, and `flow_offload_free(flow)` drops it via `nf_ct_put(flow->ct)` and frees `NF_FLOW_OFFLOAD_ROUTE` `dst_cache` entries before `kfree_rcu()`; never `kfree(flow)` or call `nf_ct_put(flow->ct)` manually before `flow_offload_free(flow)`. [F7]
- `nf_tproxy_sk_is_transparent(sk)` calls `sock_gen_put(sk)` when returning `false`; when `true`, `nf_tproxy_assign_sock(skb, sk)` orphans `skb` and transfers `sk` ownership to `skb->sk` (`sock_edemux`). Never call `sock_gen_put(sk)` after either call. [F9]
- When `nft_data_init()` succeeds with `NFT_DATA_VERDICT`, it increments `chain->use` for `NFT_JUMP`/`NFT_GOTO`; later init errors or teardown must call `nft_data_release(data, desc.type)`. When `nft_trans_gc_queue_async()` or `nft_trans_gc_queue_sync()` fills a batch (`NFT_TRANS_GC_BATCHCOUNT`), it queues the old `gc` and returns a new `struct nft_trans_gc *` (or `NULL`), which the caller must assign back to `gc` and finish with `*_done()` or `nft_trans_gc_destroy()`. [F11, F12]

## API Contracts

- `nf_hook()` only dispatches `NFPROTO_IPV4`, `NFPROTO_IPV6`, `NFPROTO_ARP`, and `NFPROTO_BRIDGE`, and `NF_HOOK_LIST()` only dispatches `NFPROTO_IPV4`/`NFPROTO_IPV6`; `NFPROTO_NETDEV` must use `nf_hook_ingress()` or `nf_hook_egress()`. `nf_hook_egress()` returns `skb` on pass (`ret == 1`), or `NULL` after `nf_hook_slow()` consumed `skb` (storing `NET_XMIT_DROP` or `NET_XMIT_SUCCESS` in `*rc`). `NF_DROP_REASON(skb, reason, err)` requires positive 16-bit `err <= 0xffff`, frees `skb` via `kfree_skb_reason()`, and returns `((err << 16) | NF_STOLEN)` (decoded to `-err` by `NF_DROP_GETERR()`). [F3, F27, F80]
- In `struct nf_sockopt_ops`, `[set_optmin, set_optmax)` and `[get_optmin, get_optmax)` are non-inclusive upper bounds; unused directions must set `optmin`, `optmax`, and callback to `0`, `0`, `NULL`. All three buffers passed to `ifname_compare_aligned(_a, _b, _mask)` must be `>= IFNAMSIZ` (16) bytes and aligned to `sizeof(unsigned long)`. [F30, F72]
- 64-bit accesses on `nf_tables` `u32` registers (`&regs->data[i]`) must use `nft_reg_load64()` and `nft_reg_store64()` (`get_unaligned`/`put_unaligned`). Expression `.reduce` callbacks must update or invalidate `struct nft_regs_track` via `nft_reg_track_update()` or `nft_reg_track_cancel()` with full byte length `len` rather than assigning `track->regs[dreg]` directly. [F50, F67]
- `nft_set_elem_ext()` computes `(void *)elem_priv + set->ops->elemsize` and `nft_set_ext(ext, id)` uses `ext->offset[id]` unconditionally; set backends must set `ops.elemsize = offsetof(elem_type, ext)`, and callers of optional `nft_set_ext_*` accessors must check `nft_set_ext_exists(ext, id)` first. [F97]
- Verify `nft_is_base_chain(chain)` (`NFT_CHAIN_BASE`) before calling `nft_base_chain(chain)`. In `nft_ctx_update()`, `ctx->chain` is populated only for `NFT_MSG_NEWRULE`/`DELRULE`/`DESTROYRULE` and `NFT_MSG_NEWCHAIN`/`DELCHAIN`/`DESTROYCHAIN`, and reset to `NULL` for all other `msg_type` values. [F51, F100]
- Family-specific `struct nft_object_type` or `struct nft_expr_type` definitions must set `.family` to that `NFPROTO_*` constant rather than `0` (`NFPROTO_UNSPEC`). In `nft_fib` evaluation (`nft_fib4_eval`, `nft_fib6_eval`, `nft_fib6_eval_type`), resolve the VRF master ifindex via `nft_fib_l3mdev_master_ifindex_rcu(pkt, dev)` so `dev == NULL` falls back to `pkt->skb->dev`. [F122, F124]
- Before cloning an SKB carrying an unconfirmed `struct nf_conn` (`!nf_ct_is_confirmed(ct)`) for parallel paths, confirm `ct` (`nf_ct_hook->confirm(skb)` / `nf_conntrack_confirm(skb)`) or detach it. `nf_ct_ext_add()` and `nf_conntrack_alter_reply()` require `!nf_ct_is_confirmed(ct)`, and `nf_ct_ext_add()` reallocates `ct->ext` via `krealloc()`, invalidating prior `nf_ct_ext_find()` pointers (`nfct_help(ct)`, `nfct_nat(ct)`). [F54, F131]
- `nfct_help_data(ct)` returns the 32-byte `char data[32] __aligned(8)` in `struct nf_conn_help` by dereferencing `nf_ct_ext_find(ct, NF_CT_EXT_HELPER)` unchecked; assert `NF_CT_HELPER_BUILD_BUG_ON(sizeof(priv_type))` and use `nfct_help(ct)` with a `NULL` check when `NF_CT_EXT_HELPER` might be absent. Verify `nf_ct_protonum(ct) == IPPROTO_TCP` before calling `nf_ct_set_tcp_be_liberal(ct)` or `nf_conntrack_tcp_established(ct)` on `union nf_conntrack_proto`. [F44, F104, F129]
- Before calling `__nf_flow_pppoe_proto(skb)` or reading the inner PPPoE header from `skb_mac_header(skb)`, ensure `pskb_may_pull(skb, ETH_HLEN + PPPOE_SES_HLEN)` succeeds. Before destroying an `ip_set` via `set->variant->destroy(set)` (directly or via `call_rcu()`), call `set->variant->cancel_gc(set)` synchronously. Bound `pfxlen` to `0..32` (IPv4) and `0..128` (IPv6) before calling `ip_set_netmask*()` / `ip_set_hostmask*()` / `ip6_netmask()`. [F20, F88, F121]

## Error Handling

- `nf_hook()` returns `1` only when the packet passes (`okfn` must run); `0` or `-ERRNO` means the hook consumed `skb`. Conversely, `nf_hook_ingress(skb)` converts `0` from `nf_hook_slow()` into `-1`, so `< 0` means consumed/dropped and `>= 0` (`0` no hooks, `1` passed) means continue processing `skb`. [F26, F29]
- `struct ip_set_type_variant` callbacks `kadt` and `uadt` return signed tri-state values: `< 0` errno on failure, `0` on non-match (`IPSET_TEST`) or success (`IPSET_ADD`/`IPSET_DEL`), and `> 0` on match. An `xt_match->match` callback returns `bool` and can only force an immediate drop on error by setting `par->hotdrop = true` while returning `false`. [F31, F34]

## External Contracts

- Pass `nft_set_datatype(set)` rather than raw `set->dtype` to `nft_parse_register_store()` and `nft_data_dump()` so userspace-defined numeric datatypes normalize to `NFT_DATA_VALUE`. Any `struct xt_match` or `struct xt_target` with kernel-internal fields in its private struct must set `.usersize` to the offset of the first kernel-only field so `xt_data_to_user()` zeroes the trailing region. [F123, F127]

## Known Pitfalls

- `NF_INVF(ptr, flag, boolean)` in `linux/netfilter/x_tables.h` applies bitwise XOR (`^`) to `boolean` without `!!`; always pass a `0`-or-`1` boolean expression. [F78]
- `nft_rule_for_each_expr()` advances via `nft_expr_next(expr)` (`expr + expr->ops->size`) until `nft_expr_last(rule)`; cleanup paths that may run on a partially initialized `struct nft_rule` (`nft_rule_expr_deactivate()`, `nf_tables_rule_destroy()`) must use `nft_expr_more(rule, expr)` to stop at the first `NULL` `expr->ops`. [F81]
- Clamp timeout values in seconds to `IPSET_MAX_TIMEOUT` via `ip_set_timeout_uget()` before calling `ip_set_timeout_set()`, which multiplies `u32 value * MSEC_PER_SEC` in 32-bit arithmetic. [F86]
