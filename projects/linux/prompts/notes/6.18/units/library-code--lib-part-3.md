# LIBRARY CODE — lib (part 3)

Provides reference-counting (`rcuref.c`, `refcount.c`, `ref_tracker.c`), scatterlist helpers (`scatterlist.c`, `sg_pool.c`, `sg_split.c`), stack trace storage (`stackdepot.c`), usercopy (`usercopy.c`, `strncpy_from_user.c`, `strnlen_user.c`), text search (`textsearch.c`, `ts_bm.c`, `ts_fsm.c`, `ts_kmp.c`), utilities (`seq_buf.c`, `sort.c`, `timerqueue.c`, `ucs2_string.c`, `win_minmax.c`, `xxhash.c`), and self-tests (`test_firmware.c`).

## Architecture & Data Flow

- In `sg_append_table`, `sgt.orig_nents` and `sgt.nents` count only populated entries; `total_nents` tracks all allocated entries across chained chunks and must be freed via `sg_free_append_table` (not `sg_free_table(&append->sgt)`). [F212]
- In `sg_split`, `sg_split_phys` must precede `sg_calculate_split(..., true)` and `sg_split_mapped` because `sg_calculate_split` overwrites `splitters[i]` with DMA geometry and `sg_split_phys` zeroes `dma_address`/`dma_length` after `*out_sg = *in_sg`; in `sg_split_phys`, only `!j` adjusts `offset`/`length` by `split->skip_sg0`, while `j > 0` keeps `in_sg->offset`. [F217, F218]
- `__sg_page_iter_next()` and `__sg_page_iter_dma_next()` must use `while (piter->sg_pgoffset >= sg_page_count(piter->sg))` (not `if`) to skip zero-length SG entries. In `extract_bvec_to_sg()` and `extract_kvec_to_sg()`, `start` (`iter->iov_offset`) is decremented across skipped segments and must be reset to `0` after the first extracted segment. [F247, F250]
- In `lib/stackdepot.c`, `handle_parts.pool_index_plus_1` (`DEPOT_POOL_INDEX_BITS` wide) is 1-based so `0` is the empty handle: `stack_max_pools` must not exceed `(1LL << DEPOT_POOL_INDEX_BITS) - 1`, `depot_fetch_stack()` must subtract 1 into `u32 pool_index` and reject `>= pools_num_cached` before indexing `stack_pools[]`, and `depot_pop_free_pool()` sizes must be aligned to `1 << DEPOT_STACK_ALIGN` via `depot_stack_record_size()`. [F231, F262, F263]
- In `struct stack_record`, `entries` is unioned with `free_list`/`rcu_state`, so records may be on `free_stacks` only while `refcount_read(&stack->count) == 0`, and `depot_alloc_stack` must size evictable (`STACK_DEPOT_FLAG_GET`) records for `CONFIG_STACKDEPOT_MAX_FRAMES`. [F220]
- In `struct seq_buf`, overflow sets `s->len = s->size + 1` (`seq_buf_set_overflow`), so readers must clamp with `seq_buf_used(s)`. String writers (`seq_buf_puts`, `seq_buf_vprintf`, `seq_buf_bprintf`) require `s->len + text_len < s->size` for NUL without counting it in `s->len`, whereas raw writers (`seq_buf_putmem`, `seq_buf_putc`) allow `s->len == s->size` and require `seq_buf_str()` before C-string use. [F225, F235]
- In `lib/ts_fsm.c`, `fsm_init()` must reject pattern sizes not a multiple of `sizeof(struct ts_fsm_token)`, `type > TS_FSM_TYPE_MAX`, `recur > TS_FSM_RECUR_MAX`, and `TS_FSM_HEAD_IGNORE` at `i != 0` or `i == ntokens - 1`, then translate `t->type` in-place via `token_map[t->type]`. In `fsm_find()`, `TS_FSM_MULTI` must `block_idx++` before `fallthrough` to `TS_FSM_ANY`, and `TS_FSM_ANY`, `TS_FSM_HEAD_IGNORE`, and unmatched `TS_FSM_PERHAPS` must `continue` (not `break`) when `next` matches `data[block_idx]`. [F227, F243, F254]
- In `bm_init` and `kmp_init`, `pattern` follows the `unsigned int` flexible array (`good_shift[]`/`prefix_tbl[]`), so `priv_size` is `sizeof(*bm) + len + len * sizeof(unsigned int)` and `pattern` is offset by `len * sizeof(unsigned int)` bytes (cast to `u8 *` first). [F280]
- In `lib/sort.c`, `is_aligned(base, size, align)` must check `size` is a multiple of `align` (4/8) even with `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`, and check `base` when disabled. Because `SWAP_WORDS_64` is `(swap_r_func_t)0`, `__sort_r()` must unwrap `SWAP_WRAPPER` with `NULL` inner swap before `if (!swap_func)`, and `do_swap()` must check `swap_func == SWAP_WORDS_64` before the indirect call. [F244, F256]
- In `ref_tracker_get_stats()`, `++stats->total` and the search loop over `0 .. stats->count - 1` must precede `if (i >= limit) continue;`. `timerqueue_del` must call `RB_CLEAR_NODE(&node->node)` after `rb_erase_cached()`. `lib/xxhash.c` word loads must use `get_unaligned_le32()`/`le64()`. `lib/win_minmax.c` must compute `u32` `val.t - m->s[i].t` before comparing with `win`. [F228, F245, F260, F272]

## Synchronization

- `__rcuref_put` / `rcuref_put_rcusafe` require preemption disabled or `rcu_read_lock()`. `rcuref_get_slowpath()` returns `false` (`RCUREF_DEAD`) when `cnt >= RCUREF_RELEASED` and `true` (`RCUREF_SATURATED`) when `cnt > RCUREF_MAXREF`. Callers may deconstruct the object iff `rcuref_put_slowpath()` transitions `ref->refcnt` from `RCUREF_NOREF` to `RCUREF_DEAD` via `atomic_try_cmpxchg_release()` and issues `smp_acquire__after_ctrl_dep()`. [F168, F179, F208]
- `refcount_dec_and_mutex_lock`, `refcount_dec_and_lock`, and `refcount_dec_and_lock_irqsave` acquire `@lock` when `refcount_dec_not_one(r)` is `false` and unlock it if `refcount_dec_and_test(r)` is `false`, holding `@lock` on return iff returning `true`. [F169]
- In `lib/ref_tracker.c`, `debugfs_reap_worker`, `debugfs_dentries`, and `debugfs_symlinks` must be initialized in `postcore_initcall(ref_tracker_debugfs_postcore_init)` with `XA_FLAGS_LOCK_IRQ`. `ref_tracker_dir_exit()` must mark xarrays `REF_TRACKER_DIR_DEAD` and schedule `debugfs_reap_worker` before taking `dir->lock`, while `ref_tracker_debugfs_show()` must check `debugfs_dentries` under `xa_lock_irqsave()` and take `dir->lock` before dropping `xa_lock`. [F182, F297]
- In `lib/ref_tracker.c`, `__ref_tracker_dir_pr_ostream()`, `ref_tracker_dir_print_locked()`, and `ref_tracker_get_stats()` require `dir->lock` held, and their `kmalloc()` calls (and `stack_depot_save()` in `ref_tracker_free()`) must use `GFP_NOWAIT`. Under `dir->lock`, `ref_tracker_free()` appends `tracker->head` to `dir->quarantine` and decrements `dir->quarantine_avail` or pops the oldest entry to `kfree` after unlocking. [F183, F223, F298]
- In `lib/stackdepot.c`, `pool_lock` (`raw_spinlock_t`) guards `stack_pools`, `new_pool`, `pools_num`, `pool_offset`, and `free_stacks`; `depot_fetch_stack()` must never hold `pool_lock`. In `depot_init_pool()`, `stack_pools[pools_num] = new_pool` must precede `WRITE_ONCE(pools_num, pools_num + 1)` to pair with `READ_ONCE(pools_num)`. [F185, F186]
- In `stack_depot_save_flags()`, when `in_nmi()` or `!gfpflags_allow_spinning(alloc_flags)` (`!allow_spin`), `pool_lock` must use `raw_spin_trylock_irqsave()` and never allocate pages (`can_alloc` requires `allow_spin`). After a lockless `find_stack()` miss, `find_stack()` must be re-run under `pool_lock` before `depot_alloc_stack()`. [F187, F291]
- In `lib/stackdepot.c`, `find_stack()` must use `rcu_read_lock_sched_notrace()` and, for `STACK_DEPOT_FLAG_GET`, `refcount_inc_not_zero(&stack->count)`. `depot_free_stack()` must `list_del_rcu(&stack->hash_list)`, set `stack->rcu_state = get_state_synchronize_rcu()`, and `list_add_tail(&stack->free_list, &free_stacks)`, while `depot_pop_free()` must check `poll_state_synchronize_rcu(stack->rcu_state)` on the head entry. [F188, F189]
- In `lib/textsearch.c`, `textsearch_register()`/`unregister()` must hold `ts_mod_lock` and use RCU list ops on `ts_ops`, while `lookup_ts_algo()` must hold `rcu_read_lock()` across `list_for_each_entry_rcu()` and `try_module_get(o->owner)`. `textsearch_prepare()` may call `request_module()` only when `ops == NULL` and `flags & TS_AUTOLOAD`. [F190, F306]
- `sg_pool_init()` (`lib/sg_pool.c`) must use `subsys_initcall()`. In `extract_xarray_to_sg()`, `xas_for_each()` requires `rcu_read_lock()` and `if (xas_retry(&xas, folio)) continue;`. In `noinstr` `check_preemption_disabled()`, `current->migration_disabled` must be checked without `#ifdef CONFIG_SMP`, and `preempt_disable_notrace()` + `instrumentation_begin()` must pair with `instrumentation_end()` + `preempt_enable_no_resched_notrace()` on all exit paths. [F192, F289, F290, F303]
- In `lib/test_firmware.c`, sysfs store/trigger handlers (`config_num_requests_store`, `config_buf_size_store`, `config_file_offset_store`, `trigger_batched_requests_store`, `trigger_batched_requests_async_store`) must hold `test_fw_mutex` across the `test_fw_config->reqs != NULL` check (`-EBUSY` unless cleared by `__test_release_all_firmware()`) and `__test_dev_config_update_*()`. [F176, F191]

## Object Lifetimes

- If `__sg_alloc_table` fails, it leaves the partial chain in `table->sgl` (incrementing `table->orig_nents` if `prv` is non-NULL) for `__sg_free_table`. `__sg_free_table` requires the same `max_ents` and `nents_first_chunk` (skipping `free_fn` on chunk 0 when `nents_first_chunk != 0`), must read `next = sg_chain_ptr(&sgl[curr_max_ents - 1])` before `free_fn(sgl, alloc_size)`, and in `sg_free_table_chained` must normalize `nents_first_chunk == 1` to `0`. [F162, F163, F165, F249]
- Every `struct sg_mapping_iter` advanced by `sg_miter_next()` holds a page mapping while `miter->addr != NULL` that `sg_miter_stop()` must unmap with the matching variant (`SG_MITER_ATOMIC` -> `kunmap_atomic`, `SG_MITER_LOCAL` -> `kunmap_local`, else `kunmap`), calling `flush_dcache_page(miter->page)` when `SG_MITER_TO_SG` is set. [F166, F301]
- In `stack_depot_save_flags()`, `prealloc` is consumed under `pool_lock` by `depot_init_pool()` (setting `new_pool = NULL` while `pools_num < stack_max_pools`, else `STACK_DEPOT_POISON`) or `depot_keep_new_pool()` (never overwriting non-NULL `new_pool`, clearing `*prealloc = NULL`), or freed at `exit` via `free_pages_nolock()` when `!allow_spin` and `free_pages()` otherwise. [F172, F221, F295]
- `textsearch_prepare()` must transfer `lookup_ts_algo()`'s `try_module_get(ops->owner)` ref to `conf->ops` for `textsearch_destroy()` or call `module_put(ops->owner)` if `ops->init` fails. [F174]
- In `lib/test_firmware.c`, `test_fw_run_batch_request` must free `test_buf` if `!req->fw` or save it in `req->fw_buf` for `__test_release_all_firmware` (`kfree_const`). `upload_unregister_store`/`upload_release_all` must clear `test_fw_config->upload_name` if it aliases `tst->name` and call `firmware_upload_unregister(tst->fwl)` in `upload_release` before freeing `tst`. `test_firmware_init` must init `test_fw_config` before `misc_register()`, and `test_firmware_exit` must `misc_deregister()` and `upload_release_all()` before freeing `test_fw_config`. [F175, F286, F287]

## API Contracts

- In `lib/scatterlist.c`, `pages_are_mergeable(a, b)` takes the next page as `a` and preceding page as `b`. `sg_alloc_append_table_from_pages()` rejects `max_segment < PAGE_SIZE` or non-zero `offset` when `sgt_append->prv != NULL` (`-EINVAL`) and sets `sg_mark_end()` only when `left_pages == 0`. `sgl_alloc_order()` strips `GFP_DMA` (`gfp & ~GFP_DMA`) for `kmalloc_array()` while passing `gfp` to `alloc_pages()`. [F193, F242, F302]
- `extract_iter_to_sg()` pins pages only for `ITER_UBUF`/`ITER_IOVEC`, updates `sgtable->nents` (not `orig_nents`), and omits `sg_mark_end()`. `extract_folioq_to_sg()` and `extract_xarray_to_sg()` use `folio_page(folio, 0)` with `offset_in_folio(folio, start)`, and `extract_xarray_to_sg()` `WARN_ON`s on value/hugetlb entries. [F315, F316]
- `ref_tracker_alloc()` and `ref_tracker_free()` treat `trackerp == NULL` as untracked (`dir->no_tracker`); `ref_tracker_alloc()` adds `__GFP_NOFAIL` only if `gfp & __GFP_DIRECT_RECLAIM`, and on `-ENOMEM` sets `*trackerp = NULL` and increments `dir->untracked` for `ref_tracker_free()` to balance when `*trackerp == NULL` (`-EEXIST`). [F207, F296]
- When `handle == 0`, `stack_depot_set_extra_bits()` must return `0` without setting bits, and `stack_depot_fetch()` must set `*entries = NULL` and return `0`. `seq_buf_vprintf`/`printf`/`puts`/`putc`/`putmem` return `0` on success and `-1` on overflow, whereas `seq_buf_path()` returns bytes written or `-1`. [F199, F206]
- In `check_zeroed_user()`, `strncpy_from_user()`, and `strnlen_user()`, all `unsafe_get_user()` calls must be bracketed by `user_read_access_begin()`/`masked_user_access_begin()` and `user_read_access_end()`. `strnlen_user(str, count)` returns `0` on fault/limit/`count <= 0`, NUL-inclusive length on success, and `> count` on truncation; `check_zeroed_user(from, size)` returns `1` if zeroed, `0` if non-zero, or `-EFAULT` (signed `int`). [F201, F202, F307]
- Concurrent `textsearch_find`/`next` callers may share `struct ts_config` only with separate `struct ts_state` and unmutated `conf`. `sort()`/`sort_r()` pass `may_schedule = false` to `__sort_r()`, whereas `sort_nonatomic()`/`sort_r_nonatomic()` pass `true`. `ucs2_strnlen`/`strscpy`/`strncmp` take `count` in 16-bit units, whereas `ucs2_strsize`/`as_utf8` take byte `maxlength` (`ucs2_as_utf8` omits NUL when `maxlength == 0`). [F226, F240, F304, F320]

## Error Handling

- `get_next_sg()` returns `ERR_PTR(-ENOMEM)` (not `NULL`), and `sg_alloc_append_table_from_pages()` must check `IS_ERR(s)` and restore `sgt_append->prv->length = prv_len`. `sg_split()` allows `out_mapped_nents == NULL` when `in_mapped_nents == 0`, writes `out[i]`/`out_mapped_nents[i]` only after all splits succeed, and frees `splitters[i].out_sg` on `err:`. [F197, F209]
- In `lib/test_firmware.c`, `test_fw_upload_prepare` must reset `tst->inject.err_code` and `tst->inject.prog` on its own `err_out` path, and `fw_upload_err_str[]` must stay synced with `enum fw_upload_err`. In `lib/syscall.c`, `collect_syscall()` must zero-init `unsigned long args[6]` and call `syscall_get_arguments()` (copying to `__u64 info->data.args[6]`) only when `info->data.nr != -1L` (or zero `*info` and set `nr = -1` if `!try_get_task_stack(target)`), returning `-EAGAIN` only when `!task_pt_regs(target)`. [F177, F211, F230, F274]

## External Contracts

- In `strncpy_from_user()` and `strnlen_user()`, `kasan_check_write()` and `check_object_size()` must precede `if (can_do_masked_user_access())`, and the unmasked path must strip tags via `untagged_addr()`, check `src_addr < TASK_SIZE_MAX`, and clamp `max`. `do_strncpy_from_user()` must mask trailing bytes after NUL (`c & mask`) in the final word written to `dst`. [F236, F257, F312]
- `ref_tracker_dir_debugfs()` and `__ref_tracker_dir_pr_ostream()` must format pointers with `%p` (never `%px`), and `ostream` callbacks must tolerate `sbuf == NULL` on `GFP_NOWAIT` allocation failure. [F283, F308]

## Known Pitfalls

- In `do_strnlen_user()` and `check_zeroed_user()`, aligning down by `align` requires adding `align` to `max`/`size`, masking the first word with `aligned_byte_mask(align)`, stopping the loop at `<= sizeof(unsigned long)`, and masking the final word in `check_zeroed_user()` with `aligned_byte_mask(size)`. In `seq_buf_putmem_hex()`, each iteration must cap `start_len` to `MAX_MEMHEX_BYTES` (8, not `HEX_CHARS`) and advance both `len` and `data`. [F233, F237, F252, F258]
- `extract_user_to_sg()` uses the tail of `sgtable->sgl` as `struct page *` scratch space (requiring `sgtable->nents + sg_max` contiguous entries) and must treat `res <= 0` from `iov_iter_extract_pages()` as failure. `sgl_alloc_order()` must check `length > (nent << (PAGE_SHIFT + order))` and `nalloc + 1 < nalloc`, and `sg_page_count()`, `sg_dma_page_count()`, and `extract_user_to_sg()` must round `offset + length` up to `PAGE_SIZE` before shifting. [F246, F269, F270, F282]
- In `bm_find()`, `int shift = bm->patlen - 1;` must be reset inside the outer `for (;;)` loop. After `list_for_each_entry()`/`_rcu()`, never test the loop cursor; use a separate `NULL`-initialized match pointer. `stack_depot_init()` must branch on `scale > PAGE_SHIFT` when shifting `entries`. `refcount_dec_not_one()` must keep `val` and `new` as `unsigned int` so `val == 0` triggers `new > val`. In `lib/sort.c`, `parent()` must apply `i -= size & -(i & lsbit)` before `/ 2`, and `sort`/`sort_nonatomic` must use `struct wrapper` (`_CMP_WRAPPER`/`SWAP_WRAPPER`). `__ucmpdi2()` must cast `DWstruct` `high`/`low` to `unsigned int`. `stmp_reset_block`/`stmp_clear_poll_bit` must write to `STMP_OFFSET_REG_SET`/`CLR` and poll base `reset_addr` with a timeout. [F253, F261, F264, F266, F267, F273, F276, F284]
