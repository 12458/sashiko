# XFS FILESYSTEM — fs/xfs/libxfs (part 4)

Provides core XFS metadata algorithms and on-disk/UAPI format definitions (`xfs_format.h`, `xfs_fs.h`), including shortform and node-format directories (`xfs_dir2_sf.c`, `xfs_dir2_node.c`), inode allocation and inobt/finobt B+trees (`xfs_ialloc.c`, `xfs_ialloc_btree.c`), the in-core extent B+tree (`xfs_iext_tree.c`), atomic file mapping exchanges (`xfs_exchmaps.c`), dquot buffer verification (`xfs_dquot_buf.c`), per-AG/RT-group reference management (`xfs_group.c`), and health/error-injection definitions (`xfs_health.h`, `xfs_errortag.h`).

## Architecture & Data Flow
- Containers in `mp->m_groups` (`struct xfs_perag`, `struct xfs_rtgroup`) must embed `struct xfs_group` at offset 0 for `kfree_rcu_mightsleep(xg)` in `xfs_group_free()`; `xg_busy_extents` shares a union with `xg_next_reset`, so guard its allocation/freeing with `xfs_group_has_extent_busy(mp, type)`. [F35, F119]
- In `xfs_iext_tree.c`, a height-1 root (`if_height == 1`) has no `prev`/`next` pointers until `RECS_PER_LEAF` (where `xfs_iext_realloc_root()` expands `new_size` to `NODE_SIZE` and zeros `[if_bytes, new_size)`); bound leaf indices by `xfs_iext_max_recs(ifp)` and check `if_height > 1` before accessing `leaf->next`/`prev`. [F53, F86, F122]
- In `xfs_iext_tree.c`, inner nodes (`struct xfs_iext_node`) mark unused keys with `XFS_IEXT_KEY_INVALID` (`1ULL << 63`) while leaves check `rec->hi == 0` (`xfs_iext_rec_is_empty()`); mask `rec->lo` with `XFS_IEXT_STARTOFF_MASK` when reading file offsets, and call `xfs_iext_update_node()` whenever `pos == 0` changes in a leaf or node. [F61, F87, F103]
- Shortform directories (`xfs_dir2_sf.c`) must keep `sfp->i8count` equal to the count of entries (including parent) with `ino > XFS_DIR2_MAX_SHORT_INUM` and `dp->i_disk_size == dp->i_df.if_bytes`, calling `xfs_dir2_sf_toino4()`/`toino8()` when `i8count` crosses 0 and 1; entry inos sit at `sfep->name + sfep->namelen + (xfs_has_ftype(mp) ? 1 : 0)` and require `get/put_unaligned_be32/64()`. [F65, F126]
- In `xfs_dir2_sf_verify()`, validate `(char *)sfep + sizeof(*sfep) < endp` and non-zero `sfep->namelen` before calling `xfs_dir2_sf_nextentry()` and checking `endp < (char *)next_sfep`. [F77]
- In `xfs_dir2_node_replace()`, save `args->inumber` and `args->filetype` before `xfs_da3_node_lookup_int()` overwrites them; in `xfs_dir2_node_addname_int()` and `xfs_dir2_leafn_remove()`, if a data block's `bf[0].length` changes, update and log `freehdr.bests[findex]` (and `nvalid`/`nused`). [F66, F67]
- In `xfs_dialloc_ag_inobt()`, on the left branch (`useleft && trec.ir_freecount`), set `pag->pagl_leftrec = trec.ir_startino` and `pag->pagl_rightrec = rec.ir_startino` before `rec = trec`; if `doneleft && doneright` with `searchdistance > 0`, reset `pagl_pagino`, `pagl_leftrec`, and `pagl_rightrec` to `NULLAGINO` and delete `tcur` and `cur` before `goto restart_pagno`. [F54, F55]
- In `xfs_ialloc_ag_alloc()`, call `xfs_inobt_insert_sprec()` before `xfs_finobt_insert_sprec()` so `rec` is merged before updating `finobt`; also reset `args.minalignslop = 0` after `xfs_alloc_vextent_exact_bno()` before fallback `xfs_alloc_vextent_near_bno()` calls increase `args.alignment`. [F57, F58]
- In `xfs_ialloc.c` (`xfs_ialloc_ag_alloc()`, `xfs_difree()`, `xfs_imap()`), bound `agbno` and `max_agbno` with `xfs_ag_block_count(mp, pag_agno(pag))` rather than `mp->m_sb.sb_agblocks`; keep `offsets[]` and `XFS_AGI_NUM_BITS_R1`/`R2` in `xfs_ialloc_log_agi()` synced with `struct xfs_agi`. [F60, F73]
- In `xfs_exchmaps_one_step()`, after `swap(irec1->br_startoff, irec2->br_startoff)`, call `xfs_exchmaps_update_size()` using `irec2` for `xmi_ip1` and `irec1` for `xmi_ip2`; in `xfs_exchmaps_finish_one()`, recheck `xmi_has_more_exchange_work(xmi)` after `xfs_exchmaps_find_mappings()` before `xfs_exchmaps_one_step()`, and return `-EAGAIN` if `xmi_has_more_exchange_work(xmi)` or `xmi_has_postop_work(xmi)` is true. [F69, F90]
- In `xmi_delta_nextents_step()`, when `(state & CBOTH_CONTIG) == CBOTH_CONTIG` or `(state & NBOTH_CONTIG) == NBOTH_CONTIG`, check `xmi_can_merge_all()` and clear `CRIGHT_CONTIG` or `NRIGHT_CONTIG` if the 3-extent sum exceeds `XFS_MAX_BMBT_EXTLEN`. [F101]
- In `xfs_format.h`, keep `sb_icount`, `sb_ifree`, `sb_fdblocks`, and `sb_frextents` contiguous in `struct xfs_sb`/`xfs_dsb`; set `XFS_SB_VERSION_MOREBITSBIT` in `sb_versionnum` when setting any V4 `sb_features2` bit; bound `sb_fname`/`rsb_fname` (`__nonstring`) to `XFSLABEL_MAX` (12); and keep `XFS_ERRTAG_*` consecutive up to `XFS_ERRTAG_MAX` (retaining deprecated slots like `XFS_ERRTAG_DROP_WRITES`). [F80, F130, F131, F155]

## Synchronization
- `xfs_group_insert()` must initialize all `xg_*` fields and set `xg_active_ref` to 1 before `xa_insert(&mp->m_groups[type].xa, ...)`; accessing `xg_checked` or `xg_sick` requires holding `xg->xg_state_lock`. [F25, F28]
- `xfs_ialloc_read_agi()` must set `pag->pagi_freecount` and `pag->pagi_count` before setting `XFS_AGSTATE_AGI_INIT`; `xfs_dialloc_try_ag()` must lock the AGI via `xfs_ialloc_read_agi()` and recheck `pagi_freecount` after lockless `xfs_dialloc_good_ag()` before calling `xfs_dialloc_ag()`. [F29, F31]
- Callers of `xfs_exchange_mappings()` and `xfs_exchmaps_estimate()` must flush `req->ip1` and `req->ip2` and hold `XFS_ILOCK_EXCL` on both; `xfs_exchange_mappings()` requires both joined to `tp` on entry and exit, and must call `xfs_exchmaps_ensure_reflink()` and `xfs_exchmaps_upgrade_extent_counts()`. [F16, F32, F161]
- Every in-core extent tree mutation (`xfs_iext_insert_raw()`, `xfs_iext_remove()`, `xfs_iext_update_extent()`) must call `xfs_iext_inc_seq(ifp)` before mutating records. [F33]

## Object Lifetimes
- `xfs_group_get()`/`hold()` increment passive `xg_ref` (`xfs_group_put()`), whereas `xfs_group_grab()`/`grab_next_mark()` use `atomic_inc_not_zero(&xg->xg_active_ref)` (`xfs_group_rele()`) under `rcu_read_lock()`; on `xa_insert()` failure, `xfs_group_insert()` cleans up `xg_intents_drain` and `xg_busy_extents` without freeing `xg`, whereas `xfs_group_free()` (sleepable context only, after all non-mount refs are gone) calls `xfs_group_rele(xg)` and `kfree_rcu_mightsleep(xg)`. [F1, F3, F26, F27, F136]
- In `__xfs_dir3_free_read()`, if `xfs_dir3_free_header_check()` fails, call `xfs_trans_brelse(tp, *bpp)` and set `*bpp = NULL`; in `xfs_dir2_node_find_freeblk()`, if `fblk` has `fblk->index < 0`, call `xfs_trans_brelse(tp, fbp)` and clear `fbp = NULL` and `fblk->bp = NULL`. [F4, F5]
- When `xfs_dir2_shrink_inode()` returns 0, it invalidates the buffer: `xfs_dir2_leafn_remove()` must clear `dblk->bp = NULL` and `hdr = NULL`; `xfs_dir3_data_block_free()` must clear `fbp = NULL` and `logfree = 0`; `xfs_dir2_node_trim_free()` must call `xfs_trans_brelse(tp, bp)` if `freehdr.nused > 0` or `xfs_dir2_shrink_inode()` fails; and `xfs_dir2_block_to_sf()` must format `bp->b_addr` into `sfp` before `xfs_dir2_shrink_inode()` and `kfree(sfp)` on all paths. [F6, F8, F12]
- `xfs_da_state_free()` does not release buffers: `xfs_dir2_node_lookup()` and `xfs_dir2_node_replace()` must `xfs_trans_brelse()` all `state->path.blk[i].bp` and unlogged `state->extrablk.bp` first; in `xfs_dir2_leafn_lookup_for_entry()`, never `xfs_trans_brelse(tp, curbp)` if `curbp == state->extrablk.bp`. [F7, F102]
- In `xfs_dir2_sf_addname_easy()`, save `byteoff` before `xfs_idata_realloc()` and recompute `sfep` from the new `if_data`; in `xfs_dir2_sf_addname_hard()`, `toino4()`, and `toino8()`, copy `if_data` to `kmalloc` `buf`, call `xfs_idata_realloc(dp, -oldsize, ...)` then `xfs_idata_realloc(dp, newsize, ...)`, and `kfree(buf)`. [F9, F10]
- `xfs_exchmaps_estimate()` must free `xmi` via `kmem_cache_free(xfs_exchmaps_intent_cache, xmi)` on all paths, whereas `xfs_exchange_mappings()` transfers `xmi` to `tp` via `xfs_exchmaps_defer_add(tp, xmi)`. [F14]
- In `xfs_exchmaps_link_to_sf()`, allocate `ip->i_disk_size + 1` bytes for `buf` (for the NUL from `xfs_symlink_remote_read()`), call `xfs_symlink_remote_truncate()` and `xfs_idestroy_fork(ifp)` before `xfs_init_local_fork(..., ip->i_disk_size)`, and `kfree(buf)` on all paths. [F15, F133]
- `xfs_inobt/finobt_init_cursor()` hold `cur->bc_group` (freed by `xfs_btree_del_cursor()`), but borrow `agbp` in `cur->bc_ag.agbp` (callers must `xfs_trans_brelse(agbp)`); in `xfs_dialloc_ag_finobt_near()`, selecting `rcur` deletes `lcur` (`*ocur`) and sets `*ocur = rcur`, while selecting `lcur` or erroring deletes `rcur` and leaves `*ocur` for the caller. [F17, F21]
- In `xfs_dialloc_roll()`, before `xfs_trans_roll(&tp)`, call `xfs_trans_bhold(tp, agibp)` and detach `tp->t_dqinfo`, and afterwards restore `tp->t_dqinfo`, call `xfs_trans_bjoin(tp, agibp)` even on error, and set `*tpp = tp`; in `xfs_ialloc_inode_init()`, attach `fbuf` to `tp` when `tp != NULL`, or queue via `xfs_buf_delwri_queue()` and call `xfs_buf_relse(fbuf)` when `tp == NULL`. [F19, F20]
- In `xfs_iext_tree.c`, `xfs_iext_realloc_root()` at `if_height == 1` must update `ifp->if_data` and `cur->leaf` to `new`, and `xfs_iext_free_last_leaf()` frees `if_data`, sets `if_data = NULL`, and decrements `if_height` when `nr_entries == 0`; `xfs_iext_rebalance_leaf()` must redirect `cur->leaf` and adjust `cur->pos` before `xfs_iext_remove_node()`; and `xfs_iext_destroy()` must free child subtrees at `level > 1` and zero `if_bytes`, `if_height`, and `if_data`. [F22, F23, F24]

## API Contracts
- `xfs_group_next_range()`, `xfs_group_grab_next_mark()`, and `for_each_perag_wrap_at()` consume `@xg` via `xfs_group_rele(xg)` on each step, so early loop exits must release `@xg`; verify `XG_TYPE_AG` vs `XG_TYPE_RTG` before `to_perag()` or `to_rtg()`. [F2, F120]
- `xfs_ialloc_read_agi()` returns locked `*agibpp` or releases `agibp` when `agibpp == NULL`; `xfs_difree()` only populates `xic->first_ino` and `xic->alloc` when `xic->deleted` is `true`; `xfs_finobt_calc_reserves()` adds to `*ask` and `*used` with `+=` (caller must initialize); and `XFS_INOBT_REC/KEY/PTR_ADDR()` take a 1-based `index`. [F18, F44, F45, F49]
- Callers of `xfs_dir2_free_try_read()` must check both `error` and `bp == NULL` (hole), and freeindex reads must use `xfs_dir2_free_read()` / `__xfs_dir3_free_read()` so `xfs_dir3_free_header_check()` runs. [F50, F78]
- `xfs_dir2_block_sfsize()` returns `size > xfs_inode_data_fork_size(dp)` without initializing `*sfhp`; in `xfs_dir2_sf.c`, set `sfp->i8count` before calling `xfs_dir2_sf_put_parent_ino()`, `firstentry()`, `nextentry()`, or `put_ino()`, and use `xfs_dir2_sf_hdr_size(i8count)` instead of `sizeof(struct xfs_dir2_sf_hdr)`. [F51, F123]
- Zero-initialize `struct xfs_exchmaps_req` output fields before `xfs_exchmaps_estimate()`; `xmi_isize1`/`2` use `-1` as a sentinel (`xfs_exchmaps_update_size()` returns early if `new_isize < 0`); and `xfs_exchmaps_find_mappings()` clamps `irec1->br_blockcount` and advances `xmi` on skipped/equal mappings, but leaves `xmi_advance()` to the caller on differing pairs. [F40, F42, F89]
- `xfs_iext_remove()` positions `cur` at the next extent (do not call `xfs_iext_next()`); when `cur->leaf == NULL`, `xfs_iext_prev()` calls `xfs_iext_last()` and `xfs_iext_next()` calls `xfs_iext_first()`. [F92, F93]
- `xfs_dquot/dqblk_verify()` treat `id == -1` as a wildcard whereas `xfs_dqblk_repair()` requires `id != -1`; `xfs_dquot_buf_readahead_verify()` passes `readahead = true` and on failure calls `xfs_buf_ioerror(bp, -EIO)` and clears `XBF_DONE`; `xfs_dquot_buf_write_verify()` must not compute CRCs; and runtime paths must call `xfs_*_mark_sick()` rather than scrub-only `xfs_*_mark_corrupt/healthy()`. [F39, F147, F148, F157]

## Error Handling
- Verifiers returning `xfs_failaddr_t` return `NULL` on success and `__this_address`/`fa` on corruption; post-read checks in `xfs_dir2_node.c` (`__xfs_dir3_free_read()`, `xfs_dir2_leaf_to_node()`, `xfs_dir2_leafn_lookup_for_entry()`) must call `xfs_buf_mark_corrupt()` / `__xfs_buf_mark_corrupt()` rather than `xfs_verifier_error()`. [F34, F146]
- In `xfs_dir2_sf_replace()`, if `i8elevated` is set and the entry is not found, call `xfs_dir2_sf_toino4(args)` before returning `-ENOENT`; in `xfs_dqinode_load()`, call `xfs_irele(ip)` if validation fails after loading `ip`; and in `xfs_inobt/finobt_init_cursor()`, check `agbp != NULL` before dereferencing `agbp->b_addr`. [F11, F13, F43]
- In `xfs_dialloc()`, reset `error = 0` on `-EAGAIN` from `xfs_dialloc_try_ag()`, clear `flags = 0` (and set `ok_alloc = true` if `low_space`) before `goto retry`, and verify `ino != parent && xfs_verify_dir_ino(mp, ino)` before returning; in `xfs_imap()` with `XFS_IGET_UNTRUSTED`, suppress debug alerts and call `xfs_imap_lookup()`. [F95, F150, F151]

## External Contracts
- `fs/xfs/libxfs/xfs_fs.h` must keep legacy `XFS_IOC_GET/SETXFLAGS`, `XFS_IOC_GETVERSION`, and `XFS_IOC_FSGET/SETXATTR` macros, keep `struct xfs_attrlist`/`xfs_attrlist_ent` ABI-compatible with `libattr`, and keep `struct xfs_bulkstat` timestamp seconds signed `int64_t` with padding zeroed. [F75, F145, F159]

## Known Pitfalls
- Never use `sizeof(struct xfs_btree_block)`—use `XFS_BTREE_SBLOCK/LBLOCK[_CRC]_LEN` or `XFS_INOBT_BLOCK_LEN(mp)`, and only access v5 fields when `xfs_has_crc(mp)` is true; `finobt` helpers must call `xfs_finobt_init_cursor()`, not `xfs_inobt_init_cursor()`. [F82, F88]
- On sparse inobt records (`xfs_inobt_issparse(irec->ir_holemask)`), mask `ir_free` with `xfs_inobt_irec_to_allocmask(irec)`; in `xfs_inobt_irec_to_allocmask()` and `xfs_inobt_rec_check_count()`, mask `~rec->ir_holemask` with `((1 << XFS_INOBT_HOLEMASK_BITS) - 1)`, use `uint64_t inodespbit`, and pass `unsigned long` (`DECLARE_BITMAP`) to `find_first/next_zero_bit()` or `uint *` and word count to `xfs_next_bit()`. [F83, F107, F132]
- Prevent 32-bit overflow/UB: cast `xg->xg_gno` to `xfs_fsblock_t` in `xfs_group_start_fsb()` and `xfs_gbno_to_daddr()`; check `!mp->m_groups[type].blklog` in `xfs_fsb_to_gno()`; reject `glen == 0` before `check_add_overflow()` in `xfs_verify_gbext()`; guard `n >= XFS_INODES_PER_CHUNK` in `xfs_inobt_maskn()`; use `1ULL`/`1LL` in `XFS_INO_MASK()` and `xfs_ialloc_setup_geometry()`; check `inobt_mxr[0] == 0` and widen `agblocks` to `uint64_t` in `xfs_inobt_max_size()`; guard `sb_imax_pct && ialloc_blks` and use `do_div()` in `xfs_ialloc_setup_geometry()`; use `howmany()` in `xfs_ialloc_calc_rootino()`; and use `(atomic_inc_return(&mp->m_agirotor) - 1) % mp->m_maxagi` in `xfs_dialloc_pick_ag()`. [F74, F104, F105, F106, F108, F109, F110, F111, F112]
- In `xfs_exchmaps.c`, use `isaligned_64()`/`roundup_64()`/`rounddown_64()` with `sb_rextsize` in `xfs_exchmaps_can_skip_mapping()`; use `howmany_64()` in `xfs_exchmaps_bmbt/rmapbt_blocks()`; return `0` when `delta < 0` in `xmi_ensure_delta_nextents()` and pass `d_nexts1 + d_nexts2` when `ip1 == ip2`; and use ceiling `XFS_B_TO_FSB()` in `xmi_can_exchange_reflink_flags()`. [F113, F114, F115, F116]
- In `xfs_dir2_sf_removename()`, call `memmove()` before shrinking via `xfs_idata_realloc()`; in `struct xfs_dir3_icleaf_hdr` and `struct xfs_dir3_icfree_hdr`, use `sizeof(ents[0])` and `sizeof(bests[0])` (not `sizeof(ents)`/`sizeof(bests)`). [F125, F127]
- In `xfs_dquot_buf.c`, when `mp->m_quotainfo == NULL` (log recovery), fall back to `xfs_calc_dquots_per_chunk(bp->b_length)`; add `XFS_DQ_BIGTIME_SLACK` before `>> XFS_DQ_BIGTIME_SHIFT` in `xfs_dq_unix_to_bigtime()`, and test 64-bit `timer != 0` in `xfs_dquot_to_disk_ts()`. [F117, F149]
