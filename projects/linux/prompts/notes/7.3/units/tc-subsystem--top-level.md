# TC subsystem — (top level)

This component provides the Traffic Control (TC) classifier/action UAPI and kernel headers, the core TC action lifecycle and execution engine (`net/sched/act_api.c`), and concrete packet action modules (`act_ct`, `act_mirred`, `act_gate`, `act_csum`, `act_nat`, `act_mpls`, `act_ife`, connmark, ctinfo, and gact).

## Architecture & Data Flow

- Every `struct tcf_*` must embed `struct tc_action common` at offset 0 (cast directly by `tcf_idr_create()`, `free_tcf()`, and `to_<act>()`), and every per-netns struct registered via `tcf_register_action()` (`struct tc_ct_action_net`) must embed `struct tc_action_net` at offset 0 (cast from `net_generic(net, id)` by `__tcf_generic_walker()`, `__tcf_idr_search()`, `tcf_action_reoffload_cb()`, and `tc_action_net_exit()`). [F128, F130]
- Actions created via `tcf_idr_create_from_flags()` have NULL `cpu_bstats`/`cpu_qstats` when `TCA_ACT_FLAGS_NO_PERCPU_STATS` is set; update stats via `tcf_action_update_bstats()`, `tcf_action_inc_drop_qstats()`, and `tcf_action_inc_overlimit_qstats()` instead of `this_cpu_ptr()`. [F53]
- In `tcf_action_exec()`, `jmp_ttl` is set once to `TCA_ACT_MAX_PRIO` (32) before `restart_act_graph:` to bound `TC_ACT_JUMP` restarts (`jmp_prgcnt = ret & TCA_ACT_MAX_PRIO_MASK` must be `1..nr_actions`, `jmp_ttl > 0` after decrement), while `repeat_ttl` is reset to 32 inside the loop before `repeat:` (returning `TC_ACT_OK` via `net_warn_ratelimited()` on exhaustion); `tcf_mirred_act()` bounds recursion to `MIRRED_NEST_LIMIT` (4) via `net_warn_ratelimited()` and returns `TC_ACT_SHOT`. [F85, F107, F189]
- In `tcf_bind_filter()`, `tcf_unbind_filter()`, and `tcf_block_q()`, `tp->chain->block->q` is NULL when `tcf_block_shared(block)` is true; check `q` before dereferencing. `tcf_proto_update_usesw()` must set `tp->usesw = true` on every filter insertion lacking both `TCA_CLS_FLAGS_SKIP_SW` and `TCA_CLS_FLAGS_IN_HW` so `tcf_block_bypass_sw()` does not bypass software classification. [F55, F69]
- In `tcf_mirred_init()`, `m->tcfm_dev` and `m->tcfm_blockid` are mutually exclusive under `m->tcf_lock`: setting `parm->ifindex` zeroes `m->tcfm_blockid` and updates `m->tcfm_mac_header_xmit`; setting `TCA_MIRRED_BLOCKID` calls `tcf_mirred_replace_dev(m, NULL)` and sets `m->tcfm_mac_header_xmit = false`. In `mirred_device_event()` (`NETDEV_UNREGISTER`), only release `m->tcfm_dev_tracker` and clear `m->tcfm_dev` when `tcf_mirred_dev_dereference(m) == dev`, leaving `m->tcfm_blockid` intact. [F60, F61]
- In `tcf_ct_flow_table_lookup()`, call `nf_conn_act_ct_ext_fill()` and `tcf_ct_flow_ct_ext_ifidx_update()` before `flow_offload_refresh()`. When `IPS_ASSURED_BIT` is unset on `ct->status`, still call `flow_offload_refresh()` (forcing refresh on reply packets if `NF_FLOW_HW_ESTABLISHED` is unset) and return `false` so software conntrack promotes `ct` to `ASSURED`. [F64, F65]
- `tcf_csum_ipv4()` and `tcf_nat_act()` must gate their L4 switch with `iph->frag_off & htons(IP_OFFSET) ? 0 : iph->protocol`. In `tcf_csum_ipv6_hopopts()`, guard with `while (len > 1)` before reading `xh[off + 1]`, and for `IPV6_TLV_JUMBO` verify `optlen == 6`, `len >= 6`, and `(off & 3) == 2` before reading `*(__be32 *)(xh + off + 2)`. [F90, F120]
- In `act_gate.c`, reject `interval == 0` in `fill_gate_entry()` and require non-zero `cycletime` in `tcf_gate_init()` before dividing by `tcfg_cycletime`; in `gate_timer_func()`, wrap `next` via `list_is_last(&next->list, &p->entries)` and `list_first_entry()`. In `tc_pedit.h`, `tcf_pedit_htype()` and `tcf_pedit_cmd()` must check `if (parms->tcfp_keys_ex)` before indexing. [F56, F95, F117]
- In `act_mpls.c`, validate `TCA_MPLS_LABEL` via `valid_label()` and use `ACT_MPLS_*_NOT_SET` (`0xffffffff`/`0xff`) as unset sentinels. In `tcf_ctinfo_init()`, `dscpmask` must be 6 contiguous bits (`(~0 & (dscpmask >> dscpmaskshift)) == 0x3f`) and not overlap `dscpstatemask`. [F92, F93]

## Synchronization

- Every process-context acquisition of `tc_action.tcfa_lock` (`tcf_lock`) must use `spin_lock_bh()` / `spin_unlock_bh()` because datapath/timer callbacks (`tcf_action_update_bstats()`, `tcf_gate_act()`, `gate_timer_func()`, `tcf_ife_encode()`) take it in softirq/BH. In `->init()`, `tcf_action_set_ctrlact()` and `rcu_replace_pointer()` must run under `spin_lock_bh(&a->tcfa_lock)`, calling `tcf_chain_put_by_act()` after unlocking. [F29, F151]
- `offload_action_init()` and `tc_setup_action()` call `act->ops->offload_act_setup()` under `spin_lock_bh(&act->tcfa_lock)`, so `offload_act_setup` callbacks and helpers (`tcf_gate_get_list()`, `tcf_tunnel_info_copy()`) must not sleep, must use `GFP_ATOMIC`, and must not re-lock `tcfa_lock`. Helpers using `rcu_dereference_protected(..., lockdep_is_held(&a->tcfa_lock))` (`to_ct_params()`, `tcf_ct_zone()`, `tcf_tunnel_info()`, `tcf_police_rate_bytes_ps()`) require `tcfa_lock` held. [F30, F154]
- Lockless `idrinfo->action_idr` lookups under `rcu_read_lock()` (`tcf_idr_check_alloc()`) and all IDR walkers (`tcf_idr_search()`, `tcf_dump_walker()`, `tcf_del_walker()`, `tcf_action_reoffload_cb()`) must check `IS_ERR(p)` for `ERR_PTR(-EBUSY)` reservations and use `refcount_inc_not_zero(&p->tcfa_refcnt)`. `__tcf_action_put()` must use `refcount_dec_and_mutex_lock(&p->tcfa_refcnt, &idrinfo->lock)` before `idr_remove()`, whereas callers already holding `idrinfo->lock` (`tcf_del_walker()`, `tcf_reoffload_del_notify()`) must call `tcf_idr_release_unsafe()`. [F25, F44, F160, F161]
- Process-context callers of `tcf_action_stats_update()` (`tcf_action_update_hw_stats()`, `tcf_exts_hw_stats_update()`) must wrap it in `preempt_disable()` / `preempt_enable()`. Lockless datapath counters in `struct tcf_ctinfo` (`stats_dscp_set`, `stats_dscp_error`, `stats_cpmark_set`) must be `atomic64_t`. [F31, F38]
- In `act_mirred.c`, lock order is `mirred_list_lock` outer then `m->tcf_lock` inner (`mirred_device_event()`); never acquire `mirred_list_lock` under `m->tcf_lock`. In `tcf_gact_init()`, write non-zero `tcfg_pval` and `tcfg_paction` then `smp_wmb()` before `tcfg_ptype`, paired with `READ_ONCE(gact->tcfg_ptype)` in `tcf_gact_act()` and `smp_rmb()` in `gact_net_rand()`/`gact_determ()`. `psched_mtu()` must use `READ_ONCE(dev->mtu)`. [F34, F39, F40]
- When `tc_action_load_ops()` drops `rtnl_unlock()` for `request_module()` (`!(flags & TCA_ACT_FLAGS_NO_RTNL)`), it must re-acquire `rtnl_lock()`, call `module_put()`, and return `ERR_PTR(-EAGAIN)` to replay. [F165]

## Object Lifetimes

- When `tcf_idr_check_alloc()` returns 0, it inserts `ERR_PTR(-EBUSY)` at `*index`, so error paths before `tcf_idr_create()` succeeds must call `tcf_idr_cleanup(tn, index)`. Once `tcf_idr_check_alloc()` returns 1 or `tcf_idr_create()` succeeds, error paths must call `tcf_idr_release(*a, bind)` after initializing all fields torn down by `ops->cleanup` (`hitimer`/`param.entries` in `tcf_gate_init()`, `tcfm_list` in `tcf_mirred_init()`, `metalist` in `tcf_ife_init()`). [F1, F2, F47]
- `tcf_action_init()` must call `module_put(ops[i]->owner)` for every `ops[i]` loaded by `tc_action_load_ops()` on both success and failure. Standalone offload (`tcf_action_offload_add()`) and flag checks must succeed for the whole batch before `tcf_idr_insert_many()` publishes new actions (skipping `ACT_P_BOUND`), and `tcf_action_add()` must call `tca_put_bound_many()` (skipping `ACT_P_CREATED`) to drop the extra ref on pre-existing actions. [F5, F75, F143]
- `tcf_action_destroy()` and `tcf_action_delete()` must set `actions[i] = NULL` as each element is released because `tcf_act_for_each_action()` stops at the first NULL. In `tcf_action_delete()`, save `a->ops`, `a->idrinfo`, and `a->tcfa_index` before `tcf_action_put(a)` for `tcf_idr_delete_index()`. `tcf_action_cleanup()` must call `tcf_action_offload_del(p)` before `p->ops->cleanup(p)` and `free_tcf(p)`. In `tcf_idrinfo_destroy()`, if any action has `tc_act_in_hw(p)`, hold `rtnl_lock()` across `__tcf_idr_release()`. [F6, F72, F142, F145]
- `tcf_action_check_ctrlact()` acquires a chain ref in `*newchain` for `TC_ACT_GOTO_CHAIN`, and `tcf_action_set_ctrlact()` swaps `a->goto_chain` and returns the old chain; pass a NULL-initialized pointer and call `tcf_chain_put_by_act()` on the old chain after swap or on `*newchain` on error. [F3]
- `tcf_register_action()` rejects `tc_action_ops` missing `.act`, `.dump`, or `.init` with `-EINVAL`, and must call `register_pernet_subsys()` and `tcf_pernet_add_id_list()` before linking `act->head` into `act_base` under `act_mod_lock` (and `tcf_unregister_action()` unlinks `act->head` before `unregister_pernet_subsys()`). `ct_init_module()` must init `act_ct_wq` and `zones_ht` before `tcf_register_action()` and destroy them after `tcf_unregister_action()`; `mirred_init_module()` must register `mirred_device_notifier` before `tcf_register_action()` and unregister it after `tcf_unregister_action()`. [F139, F140, F141, F167]
- In `act_ct.c`, `flowtable_ct` must provide `.get` (`tcf_ct_nf_get`) and `.put` (`tcf_ct_nf_put`) using `refcount_inc_not_zero(&ct_ft->ref)` (also used in `tcf_ct_flow_table_get()`), and `tcf_ct_flow_table_put()` (called from RCU callback `tcf_ct_params_free_rcu()`) must defer `nf_flow_table_free()` and `kfree(ct_ft)` via `queue_rcu_work(act_ct_wq, &ct_ft->rwork)`. [F11, F163]
- In `tcf_ct_act()`, return `TC_ACT_CONSUMED` (not `TC_ACT_SHOT`) when `tcf_ct_handle_fragments()` returns non-zero or a hook returns `NF_STOLEN`. After `nf_conntrack_confirm(skb)`, re-read `ct = nf_ct_get(skb, &ctinfo)` (setting `skip_add` if NULL) before `tcf_ct_flow_table_process_conn()`. In `tcf_ctinfo_act()`, call `nf_ct_put(ct)` on exit if and only if `thash != NULL` (`nf_conntrack_find_get()` path). [F9, F14, F177]
- When `offload_act_setup` (`bind == true`) acquires a ref or allocates memory (`tcf_mirred_get_dev()`, `tcf_gate_get_entries()`), set `entry->destructor` and `entry->destructor_priv`; callers of `tc_setup_action()` (`tcf_action_offload_add_ex()`) must call `tc_cleanup_offload_action()` before freeing `fl_action`. [F144]
- When replacing `m->tcfm_dev` in `tcf_mirred_replace_dev()` or clearing it in `mirred_device_event()`, call `netdev_put(odev, &m->tcfm_dev_tracker)` and update `m->tcfm_dev`. In `act_ife.c`, `find_ife_oplist()` calls `try_module_get(o->owner)`; callers must call `module_put(ops->owner)` after validation (`load_metaops_and_vet()`), on `__add_metainfo()` failure, or in `_tcf_ife_cleanup()`. [F16, F19]

## API Contracts

- `tc_action_ops->init` must validate `parm->action` via `tcf_action_check_ctrlact()`, return `ACT_P_CREATED` (`1`) or `ACT_P_BOUND` (`0`), and when `tcf_idr_check_alloc()` returns `> 0` with `TCA_ACT_FLAGS_BIND` set, return `ACT_P_BOUND` immediately without modifying parameters even if `TCA_ACT_FLAGS_REPLACE` is set. `tc_action_ops->dump` must return positive `skb->len` on success and a negative value after `nlmsg_trim()` on error (`tcf_action_dump_1()` treats `<= 0` as error). [F43, F45, F73, F86]
- `tc_action_ops.act` and `tcf_action_exec()` run in softirq under `rcu_read_lock_bh()`, requiring `rcu_dereference_bh()` for RCU fields and `GFP_ATOMIC` allocations. Egress xmit paths (`tcf_mirred_forward()`) must use `tcf_dev_queue_xmit(skb, dev_queue_xmit)` so `sch_frag_xmit_hook()` handles `act_ct` defragmented packets when `tcf_frag_xmit_count` is enabled. [F152, F172]
- `tc_action_ops.offload_act_setup` must check `bind` before casting `entry_data` or dereferencing `index_inc` (`bind == true`: `struct flow_action_entry *` and non-NULL `index_inc`; `bind == false`: `struct flow_offload_action *` and NULL `index_inc`), and reject software-only options (`tcf_ct_helper(act)`, `TCA_MPLS_ACT_DEC_TTL`/`MAC_PUSH`, `gact` `continue`/`reclassify`/`pipe`) with `-EOPNOTSUPP`. New `TC_SETUP_QDISC_TAPRIO` drivers must not set `tc_taprio_caps.broken_mqprio`. [F131, F146, F149]
- Pass `0` for unsupported `action`/`police` types in `tcf_exts_init()`/`tcf_exts_init_ex()`. If `tcf_exts_get_net()` returns `false` (`exts->net = NULL`), clean up synchronously; if `true`, call `tcf_exts_put_net()`. In `tcf_action_init()`, parse `nla` up to `TCA_ACT_MAX_PRIO + 1` into `tb[TCA_ACT_MAX_PRIO + 2]` to reject excess actions, mapping 1-based `tb[i]` to 0-based `ops[i - 1]`, `init_res[i - 1]`, and `actions[i - 1]`. [F22, F58, F83]
- `tcf_ct_add_mangle_action()` takes a positive `mask` and stores `~mask` in `entry->mangle.mask`. `tcf_ct_flow_table_restore_skb()` must mask `cookie & NFCT_PTRMASK` before casting to `struct nf_conn *`. [F51, F137]
- In `act_csum.c`, skip L4 csum updates when `skb_is_gso(skb)` matches the protocol's GSO flag, validate/pull/COW via `tcf_csum_skb_nextlayer()` (`pskb_may_pull(skb, ipl + ntkoff)`, `ipl >= ihl + jhl`, `skb_try_make_writable(skb, hl + ntkoff)`), and restore pulled VLAN headers in `tcf_csum_act()`. In `tcf_mpls_act()`, push `skb->mac_len` via `skb_push_rcsum()` at ingress and pull it back on exit, materializing `skb_vlan_tag_present(skb)` via `__vlan_insert_inner_tag()` before `TCA_MPLS_ACT_MAC_PUSH`. [F88, F179, F180]
- `register_ife_op()` requires `metaid`, `metatype`, `name`, `check_presence`, `encode`, `decode`, `get`, and `alloc` (defaulting `release` to `ife_release_meta_gen()`); `TCA_IFE_METALST` allows `len == 0` and requires `ife_validate_metatype()` when `len > 0`. Ematch offsets from `tcf_get_base_ptr()` require `tcf_valid_offset(skb, ptr, len)`. `tcf_tunnel_info_copy()` must `kmemdup()` `sizeof(*tun) + tun->options_len`. `tcf_police_burst()`/`tcf_police_burst_pkt()` must use `div_u64(..., NSEC_PER_SEC)`. [F91, F97, F127, F133, F168]

## Error Handling

- When `tcf_idr_check_alloc()` finds `IS_ERR(p)` (`ERR_PTR(-EBUSY)`) at `*index`, return `-EAGAIN` immediately rather than looping in-place. [F103]
- On failure in `tcf_ct_fill_params()` after allocating `p->tmpl`, call `nf_connlabels_put(net)` (if `put_labels`), `nf_ct_put(p->tmpl)`, and set `p->tmpl = NULL` to prevent double-put in `tcf_ct_params_free()`. In `tcf_ct_act()`, mask netfilter returns with `NF_VERDICT_MASK`. In `tcf_ct_flow_table_fill_actions()`, snapshot `num_entries = action->num_entries` and zero/restore appended entries if `tcf_ct_flow_table_add_action_nat()` fails. [F12, F52, F114]

## External Contracts

- `tc_ctl_action()` uses `sock_net(skb->sk)` and requires `netlink_capable(skb, CAP_NET_ADMIN)` when `nlmsg_type != RTM_GETACTION`. Zero `tca__pad1`/`tca__pad2` in `struct tcamsg`, subtract `ref`/`bind` in `.dump`, and dump `struct tcf_t` (`TCA_*_TM`) and `u64` stats via `nla_put_64bit()`/`nla_put_u64_64bit()` with `TCA_*_PAD`. `tcf_action_dump()` uses 1-based nest `i + 1`; `tcf_dump_walker()` uses 0-based nests, caps at `TCA_ACT_MAX_PRIO` unless `TCA_ACT_FLAG_LARGE_DUMP_ON`, and must `index--` on error after `index++` before `cb->args[0] = index + 1`. [F84, F98, F106, F185, F187]
- `SKIP_HW` and `SKIP_SW` are mutually exclusive (`tc_act_flags_valid()`, `tc_flags_valid()`). When `tc_act_bind(flags)` is true in `tcf_action_init()`, only classifier-bound actions (`tc_act_bind(act->tcfa_flags)`) may inherit `SKIP_SW`/`SKIP_HW`; standalone actions must fail with `-EINVAL` on mismatch. Standalone `SKIP_SW` actions require `tc_act_in_hw(action)` in `tcf_action_offload_add_ex()` and must be deleted via `tcf_reoffload_del_notify()` if `in_hw_count` drops to 0. [F74, F150, F183]
- Keep `qopt` at offset 0 of `struct tc_mqprio_qopt_offload`, place new fixed `struct tc_u32_sel` fields inside `__struct_group(tc_u32_sel_hdr, hdr, ...)`, and put new RED flags in `TCA_RED_FLAGS` rather than `tc_red_qopt.flags` outside `TC_RED_HISTORIC_FLAGS`. [F101, F129, F132]

## Known Pitfalls

- Re-fetch `skb_network_header(skb)`, `ip_hdr(skb)`, or `ipv6_hdr(skb)` after every `pskb_may_pull()`, `pskb_network_may_pull()`, `skb_try_make_writable()`, or `tcf_csum_skb_nextlayer()` call. [F136]
- In `act_ct.c`, `zones_ht` is keyed by `struct zones_ht_key` (`net` and `zone`) with `zones_params.key_len = offsetofend(struct zones_ht_key, zone)` to exclude trailing alignment padding, and `tcf_ct_fill_params()` must verify `len <= NF_CT_HELPER_NAME_LEN` and `name[len - 1] == '\0'` for `NLA_STRING` `TCA_CT_HELPER_NAME`. [F49, F138, F174]
- Use `time_after(jiffy_since, (unsigned long)p->tcfa_tm.lastuse)` in `tcf_dump_walker()`, and `PSCHED_TICKS2NS(x)` (which casts `x` to `s64` before `<< PSCHED_SHIFT`) in `pkt_sched.h`. [F125, F126]
