# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 6)

PCI driver entry point, system/runtime PM, GPU migration engine, MMIO accessors, memirq, MOCS/PAT tables, OA streams, PMU counters, PCODE mailbox, NVM, PSMI, and preemption fences.

## Architecture & Data Flow
- In `xe_migrate.c`, level-2 PDE indices (`IDENTITY_OFFSET` `256ULL`, `255ULL` in `xe_migrate_prepare_vm()`, `slot + 1ULL` in `xe_migrate_vm_addr()`) must be 64-bit unsigned before shifting left by `xe_pt_shift()` (30 bits at level 2). `xe_migrate_prepare_vm()` and `xe_migrate_vram_ofs()` must use `DIV_ROUND_UP_ULL(actual_phy_size, SZ_1G)` to offset the Xe2+ compressed VRAM identity map, and `xe_migrate_program_identity()`'s 1GiB loop must switch to 2MiB pages when `pos + SZ_1G >= vram_limit` and `break` after the inner 2MiB loop. [F682, F700, F701]
- Migration jobs writing VM PTEs in their preamble (`xe_migrate_copy()`, non-identity `xe_migrate_clear()`, `__xe_migrate_update_pgtables()`, `xe_migrate_vram()`) must end the preamble with `MI_BATCH_BUFFER_END` at `update_idx` and pass `MI_INVALIDATE_TLB` to `xe_sched_job_add_migrate_flush()`. `MI_STORE_DATA_IMM` PTE writes must cap at `MAX_PTE_PER_SDI` (`0x1FE` qwords), and `write_pgtable()` must pad `bb->cs` with `MI_NOOP` when `!(bb->len & 1)` to 8-byte align qwords after the 3-dword header. [F679, F753]
- On integrated flat-CCS platforms, `max_mem_transfer_per_pass()` must cap passes at `MAX_CCS_LIMITED_TRANSFER` (`SZ_4M`) to fit the 10-bit `XE2_CCS_SIZE_MASK` in `emit_copy_ccs()`. `xe_migrate_dma_map()` must resolve pages via `vmalloc_to_page(buf)` when `is_vmalloc_addr(buf)` is true and `virt_to_page(buf)` otherwise. [F703, F758]
- `xe->oa.xe` is set only when OA is initialized in `xe_oa_init()` (and cleared on failure/`xe_oa_fini()`), so all OA entry points (`xe_oa_stream_open_ioctl()`, `xe_oa_add_config_ioctl()`, `xe_oa_remove_config_ioctl()`, `xe_oa_register()`, `xe_oa_fini()`) must check `if (!oa->xe)`. `xe_oa_set_property_funcs_open` and `xe_oa_set_property_funcs_config` must have equal array sizes (using `xe_oa_set_prop_ret_inval` for config-unsupported props), and `struct xe_mmio_range` tables for `xe_oa_reg_in_range_table()` must have non-zero `.start`/`.end` and end with `{}`. [F637, F662, F694]
- Batchbuffers for `write_cs_mi_lri()` (e.g., `__xe_oa_alloc_config_buffer()`) must be sized in dwords via `num_lri_dwords()` (1 header per `MI_LOAD_REGISTER_IMM_MAX_REGS` (126) + 2 per reg). `oa_exponent_to_ns()` requires a validated exponent in `0..31` (`OA_EXPONENT_MAX`) and must shift `2ULL` before multiplying by `NSEC_PER_SEC`. In `xe_oa_init_oa_buffer()`, `OABUFFER_SIZE_MASK` must subtract 20 from `size_exponent` when `> 24` (`> SZ_16M`) and 17 otherwise, matching `oag_buf_size_select()`. [F705, F706, F714]
- Circular OA buffer math (`xe_oa_circ_diff()`, `xe_oa_circ_incr()`, `xe_oa_append_report()`, `xe_oa_append_reports()`) must wrap at `stream->oa_buffer.circ_size` (not BO size or a power-of-two mask). When `stream->no_preempt` is set, `xe_oa_enable_locked()` zeroes `timeslice_us` and `preempt_timeout_us` on `stream->exec_q` via `xe_oa_disable_preempt_timeslice()`, and both `xe_oa_disable_locked()` and `xe_oa_disable_preempt_timeslice()`'s error path must restore them from `stream->hwe->eclass->sched_props`. [F651, F663]
- In `xe_pmu`, monotonic counter events (`!is_gt_frequency_event(event)`) must initialize `event->hw.prev_count` in `xe_pmu_enable()` and accumulate `new - prev` into `event->count` via `local64_read()` / `local64_try_cmpxchg()` around `__xe_pmu_event_read()` in `xe_pmu_event_update()`, while frequency events add `new` directly via `local64_add()`. `event_supported()` must check `id < sizeof(pmu->supported_events) * BITS_PER_BYTE` before `BIT_ULL(id)`. [F610, F659, F720]
- Every platform in `get_mocs_settings()` must set `info->table_size <= info->num_mocs_regs` and a non-zero `info->unused_entries_index < info->table_size` for `get_entry_control()` / `get_entry_l3cc()` fallback. `xe_memirq_init()` must allocate `memirq->bo` in system memory with `XE_BO_FLAG_SYSTEM | XE_BO_FLAG_GGTT | XE_BO_FLAG_GGTT_INVALIDATE | XE_BO_FLAG_NEEDS_UC | XE_BO_FLAG_NEEDS_CPU_ACCESS`, sized to `XE_HW_ENGINE_MAX_INSTANCE * SZ_4K` when `xe_device_has_msix(xe)` and `SZ_4K` otherwise. [F676, F740]
- In `xe_pci.c`, `pciidlist` (ordered most-specific to most-general), `xe_device_desc.subplatforms`, and subplatform ID arrays (`adls_rpls_ids`, etc.) must end with a zero/empty sentinel. In `xe_pm_runtime_suspend()` and `xe_pm_wake_rebind_workers()`, iterating `vram_userfault.list` and `rebind_resume_list` must use `list_for_each_entry_safe()` under their mutexes because entries are removed via `list_del_init()`. [F697, F737]

## Synchronization
- In `xe_migrate_job_lock()`, arming/pushing jobs on `m->q` and updating `m->fence` must hold `m->job_mutex` (primed under `fs_reclaim`, forbidding `GFP_KERNEL` allocations), whereas `q != m->q` requires holding `q->vm`'s `dma_resv` lock (`xe_vm_assert_held(q->vm)`). `xe_migrate_update_pgtables_cpu()` must call `xe_device_wmb(vm->xe)` after CPU PTE writes before returning `dma_fence_get_stub()`. [F618, F619]
- `xe_pm_runtime_suspend()` and `xe_pm_runtime_resume()` must set `xe->pm_callback_task` to `current` via `xe_pm_write_callback_task()` (`WRITE_ONCE()` + `smp_mb()`) and clear it to `NULL` on all exit paths, pairing with `xe_pm_read_callback_task()`. Callers holding locks acquired inside runtime suspend/resume (BO `dma_resv` when `xe->d3cold.capable`, `vram_userfault.lock`, or `fs_reclaim` when `!xe_rpm_reclaim_safe(xe)`) must never call synchronous resume helpers (`xe_pm_runtime_get()`, `xe_pm_runtime_get_ioctl()`, `xe_pm_runtime_resume_and_get()`). [F603, F604]
- `xe_pm_set_vram_threshold()` and `xe_pm_d3cold_allowed_toggle()` must hold `xe->d3cold.lock` when accessing `vram_threshold` and `allowed`, converting VRAM bytes to MiB via `DIV_ROUND_UP_ULL(val, 1024 * 1024)`. In `xe_pm_notifier_callback()`, `PM_SUSPEND_PREPARE` / `PM_HIBERNATION_PREPARE` must call `reinit_completion(&xe->pm_block)` before evicting BOs, and `PM_POST_SUSPEND` / `PM_POST_HIBERNATION` must call `complete_all(&xe->pm_block)` before `xe_pm_wake_rebind_workers()`. [F607, F709, F723]
- Runtime PCODE calls via `pcode_mailbox_rw()` must hold `tile->pcode.lock`; `xe_pcode_ready()` must pass `locked = true` on resume paths and `locked = false` only in `xe_pcode_probe_early()`. In `xe_pcode_request()`, retrying `pcode_try_request()` under `preempt_disable()` must pass `atomic = true` so `xe_mmio_wait32()` uses `udelay()`. [F602, F751]
- Dynamic OA configs in `oa->metrics_idr` (base 1, IDs `>= 1`) and `oa->metrics_kobj` sysfs groups must be modified together under `oa->metrics_lock`; `xe_oa_remove_config_ioctl()` must remove both before `xe_oa_config_put()`, `xe_oa_config_release()` must use `kfree_rcu()`, and `xe_oa_get_oa_config()` must hold `rcu_read_lock()` across `idr_find()` and `kref_get_unless_zero()`. [F611, F650, F668]
- Opening/destroying an OA stream (`xe_oa_stream_open_ioctl_locked()`, `xe_oa_destroy_locked()`) and updating `oa_unit->exclusive_stream` must hold `gt->oa.gt_lock`. In `xe_oa_emit_oa_config()`, `xe_oa_update_last_fence(stream, fence)` must precede `dma_fence_add_callback(fence, &ofence->cb, xe_oa_config_cb)` because `xe_oa_config_cb()` drops the caller's `fence` ref. [F612, F616]
- `xe_pmu_register()` must set `pmu->registered = true` only after `set_supported_events()` and `perf_pmu_register()` succeed, and `xe_pmu_unregister()` must clear `pmu->registered = false` before `perf_pmu_unregister()` and `kfree(pmu->name)`. In `preempt_fence_work_func()`, the entire body (through `xe_vm_queue_rebind_worker()` and `xe_exec_queue_put()`) must stay inside `dma_fence_begin_signalling()` / `dma_fence_end_signalling()`. [F608, F745]

## Object Lifetimes
- In multi-pass migration loops (`xe_migrate_copy()`, `xe_migrate_clear()`, `xe_migrate_access_memory()`), the previous pass's `fence` must not be dropped via `dma_fence_put()` until the next pass's submission succeeds, because the error path waits on `fence`. In migration/OA batch teardown, `xe_bb_free()` and `drm_suballoc_free()` must be passed `NULL` when aborting before `xe_sched_job_push()`, and the armed job's `fence` after push. [F583, F586]
- An open OA stream holds `xe_pm_runtime_get()` and `XE_FORCEWAKE_ALL` from `xe_oa_stream_init()` until `xe_oa_stream_destroy()`, and `drm_dev_get()` from `xe_oa_stream_open_ioctl_locked()` until `xe_oa_release()` after `xe_oa_destroy_locked()` finishes. In `xe_oa_destroy_locked()`, `xe_oa_disable_locked()` (which stops hardware and calls `hrtimer_cancel(&stream->poll_check_timer)`) must finish before `xe_oa_stream_destroy()` unpins `oa_buffer.bo`. In `xe_oa_add_config_ioctl()`, once `oa_config->regs = regs` is set, `xe_oa_config_put()` frees `regs`, so error paths must not `kfree(regs)`. [F595, F615, F732]
- In `xe_pmu_event_init()`, only `!event->parent` events take `drm_dev_get()`, `xe_pm_runtime_get()`, and `event_gt_forcewake()`, rolling back on `event_gt_forcewake()` failure and releasing all three in `xe_pmu_event_destroy()`. On SR-IOV PF, `pf_enable_vfs()` holds `xe_pm_runtime_get_noresume()` (put in `pf_disable_vfs()`) and calls `pf_link_vfs()`, and `xe_pci_remove()` must call `xe_pci_sriov_configure(pdev, 0)` before `xe_device_remove()`. [F591, F620]
- In `xe_nvm.c`, after `auxiliary_device_init(&nvm->aux_dev)`, `xe_nvm_release_dev()` owns `kfree(nvm)`, so `xe_nvm_fini()` must only call `auxiliary_device_delete()`, `auxiliary_device_uninit()`, and `xe->nvm = NULL`. In `xe_psmi.c`, region bit `id >= 1` indexes `capture_obj[id]` and `tiles[id - 1]`; `psmi_cleanup()` unpins BOs under `xe_bo_lock()` and zeroes `capture_obj[id]`, `psmi_resize_object()` calls `psmi_cleanup()` before allocation and on failure (checking `IS_ERR(bo)` before storing), and `psmi_debugfs_capture_region_mask_set()` must reject changes when `size != 0`. [F589, F590, F645, F658]

## API Contracts
- `xe_migrate_get_vm()` returns a refcounted `struct xe_vm *` requiring `xe_vm_put()`, whereas `xe_migrate_lrc()` and `xe_migrate_exec_queue()` return borrowed pointers. In `xe_migrate_pt_update_ops`, `.populate()`/`.clear()` receive non-NULL `map` (`pos == NULL`, `ofs` in qwords) during CPU updates and `map == NULL` (`pos` 64-bit aligned, `ofs` unused) during GPU updates. [F585, F625]
- `xe_mmio_rmw32(mmio, reg, clr, set)` takes a positive bitmask of bits to clear in `clr` (inverted internally) and returns the old unmasked value. `xe_mmio_wait32()` and `xe_mmio_wait32_not()` write the last unmasked register read into `*out_val` on both success and `-ETIMEDOUT`. In `xe_pcode_read(tile, mbox, val, val1)`, `val` must be non-NULL and pre-initialized with the input `PCODE_DATA0` value, while `val1` may be `NULL`. [F629, F630, F642]
- `xe_pm_runtime_get_ioctl()` returns `>= 0` on success (`0` or `1`) and `< 0` on error while still incrementing usage count (except `-ELOOP`), whereas `xe_pm_runtime_get_if_active()`, `xe_pm_runtime_get_if_in_use()`, and `xe_pm_runtime_resume_and_get()` return `true` only when a ref was acquired. `xe_pm_runtime_init()` must set `DPM_FLAG_NO_DIRECT_COMPLETE` on `IS_DGFX(xe)`. [F643, F770]

## Error Handling
- In `xe_migrate_update_pgtables()`, `ERR_PTR(-ETIME)` from `xe_migrate_update_pgtables_cpu()` (when `pt_update->job == NULL`) is the sole sentinel that falls back to `__xe_migrate_update_pgtables()`; any other `IS_ERR` is returned as a failure. [F624]
- In `xe_oa_read()`, `xe_oa_append_reports()` returns `-ENOSPC` when the buffer is full; `xe_oa_read()` must return `offset ?: (ret ?: -EAGAIN)` and keep `stream->pollin` true on `-ENOSPC` or `-EIO`. In `xe_oa_emit_oa_config()`, `-ENOENT` from `dma_fence_add_callback()` (already signaled) must invoke `xe_oa_config_cb()` directly and return `0`. In `xe_oa_stream_open_ioctl()`, `param.period_exponent` must be initialized to `-1` before `xe_oa_user_extensions()` because `0` is a valid exponent. [F633, F634, F636]
- `xe_pci_probe()` must check `xe_survivability_mode_is_boot_enabled(xe)` to return `0` before checking `err` from `xe_device_probe_early(xe)`, and `xe_pci_remove()` / `xe_pci_suspend()` must also guard against boot survivability mode. In `xe_pm_notifier_callback()`, `xe_bo_evict_all_user()` or `xe_bo_notifier_prepare_all_pinned()` failures during prepare must not call `xe_pm_runtime_put(xe)` or return `NOTIFY_BAD`. [F639, F724]

## External Contracts
- `xe_pmu_register()` must replace `':'` with `'_'` in `pmu->name` before `perf_pmu_register()`. `event_param_valid()` must require `engine_class`, `engine_instance`, and `function_id` to be 0 for GT events, and for engine events reject `function_id > xe_sriov_pf_get_totalvfs(xe)` on PF or `!= 0` on non-PF. [F678, F761]
- `xe_oa_user_extensions()` and `xe_oa_user_ext_set_property()` must reject non-zero `ext.pad`, cap extensions at `MAX_USER_EXTENSIONS` (16, `-E2BIG`), bounds-check IDs, and wrap indices in `array_index_nospec()`. In `xe_mmio_gem_create()` / `xe_mmio_gem_mmap()`, MMIO regions must be `PAGE_SIZE`-aligned, `VM_SHARED`, and match `base->size`, and `xe_mmio_gem_vm_fault()` must guard PFN insertion with `drm_dev_enter()` or fall back to `xe_mmio_gem_vm_fault_dummy_page()`. [F739, F766]

## Known Pitfalls
- In `xe_migrate_copy()`, both source and destination calls to `pte_update_size()` must pass `&src_L0` (after `src_L0 = min(src_L0, dst_L0)`) so non-identity clipping applies equally to both cursors and the copy command. `LNCFCMOCS` loops (`init_l3cc_table()`, dump helpers) must bound `i` by `(info->num_mocs_regs + 1) / 2` because each register packs two 16-bit entries via `l3cc_combine()` and `num_mocs_regs` can be odd. [F677, F683]
- In `xe_pmu.c` sysfs callbacks (`XE_EVENT_ATTR_GROUP`), `dev_get_drvdata(kobj_to_dev(kobj))` is `struct pmu *` and must be downcast via `container_of(..., struct xe_pmu, base)`. In `xe_oa_add_config_ioctl()`, `oa_config` must be allocated with `kzalloc()` so `oa_config->uuid` (`UUID_STRING_LEN + 1` bytes) remains NUL-terminated after copying the 36-byte `arg->uuid`. In `xe_pm_resume()`, `xe_i2c_pm_resume(xe, true)`, `xe_pcode_ready()`, `xe_bo_restore_early()`, `xe_bo_restore_late()`, and `xe_late_bind_fw_load()` must run unconditionally without gating on `xe->d3cold.allowed`. [F717, F718, F722]
