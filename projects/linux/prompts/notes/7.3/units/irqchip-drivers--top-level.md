# IRQCHIP DRIVERS — (top level)

This component provides core irqchip probing, per-CPU IRQ partitioning, RISC-V controllers (PLIC, APLIC, IMSIC), and SoC-specific controllers (MediaTek CIRQ, Qualcomm MPM, TI PRUSS, Renesas RZ/G2L, RZ/V2H, and INTC-IRQPIN, STM32MP EXTI, Sophgo SG204x MSI, Allwinner sun4i/sun6i-r, Socionext EXIU, Microchip PIC32, Xilinx, and TS4800).

## Architecture & Data Flow

- In `irq-riscv-imsic-state.c`, `global->nr_ids` is the max inclusive 1-based ID: size `lpriv->dirty_bitmap`, `lpriv->vectors`, and `imsic->matrix` to `global->nr_ids + 1`, reserving ID 0 in `imsic_matrix_init()` and skipping it in `__imsic_local_sync()`. In `__imsic_eix_read_clear()` and `__imsic_eix_update()`, scale `CSR_ISELECT` by `(id / BITS_PER_LONG) * (BITS_PER_LONG / IMSIC_EIPx_BITS)`, and in `__imsic_eix_update()` reset `ireg = 0` per `while (id < last_id)` pass and advance `id` inside `for (i = id & (__riscv_xlen - 1); id < last_id && i < __riscv_xlen; i++)` so XLEN-wide `CSR_IREG` accesses do not corrupt adjacent IDs. [F261, F262, F281]
- In `irq-sifive-plic.c`, `plic_irq_enable()` must call both `plic_irq_toggle(..., 1)` (per-hart enable) and `plic_irq_unmask(d)` (source priority). In `plic_set_affinity()`, clear the old per-hart enable bit using `irq_data_get_effective_affinity_mask(d)` before `irq_data_update_effective_affinity()` overwrites it, and enable the new entry only if `!irqd_irq_disabled(d)`. [F242, F244]
- In `irq-riscv-aplic-msi.c`, both `aplic_msi_irq_eoi()` and `aplic_msi_irq_set_type()` must call `aplic_msi_irq_retrigger_level(d)` (`APLIC_SETIPNUM_LE`) when level-triggered. MSI message composition (`sg2042_msi_irq_compose_msi_msg()`, `sg2044_msi_irq_compose_msi_msg()`, `imsic_irq_compose_vector_msg()`) must write the physical doorbell address (`phys_addr_t`) into `struct msi_msg`, whereas CPU MMIO writes must use the ioremapped virtual address (`reg_clr` or `msi_va`). [F255, F343]
- In `irq-pruss-intc.c`, `event_channel` and `channel_host` are refcounted under `intc->lock`: `pruss_intc_validate_mapping()` must return `-EBUSY` on conflicts when `ref_count > 0`, and `pruss_intc_unmap()` must only write `PRU_INTC_HIDISR` and clear `PRU_INTC_HMR` when `--channel_host[ch].ref_count == 0`. In `pruss_intc_irq_handler()`, if `generic_handle_domain_irq()` fails in the `while (true)` loop, write `hwirq` to `PRU_INTC_SICR`. [F252, F283]
- In `irq-stm32mp-exti.c`, `stm32mp_exti_mask()`/`unmask()` must update `chip_data->mask_cache` under `chip_data->rlock` whenever `imr_ofst` changes so `stm32mp_chip_resume()` can restore it after `stm32mp_chip_suspend()` overwrites `imr_ofst` with `wake_active`. In `mtk_cirq_suspend()`, ACK each line `i` via `CIRQ_ACK` unless `irq_find_mapping()` is non-zero and `IRQCHIP_STATE_PENDING`/`MASKED` queries succeed with `pending && !masked`. [F246, F288]
- In `irq-sun6i-r.c`, `sun6i_r_intc_nmi_ack()` sets `data->chip_data = SUN6I_NMI_NEEDS_ACK` for level NMIs, and `sun6i_r_intc_nmi_eoi()` must defer clearing `chip_data` and calling `sun6i_r_intc_ack_nmi()` until `sun6i_r_intc_nmi_unmask()` if `irqd_irq_masked(data)`. In `sun4i_handle_irq()`, verify an initial `hwirq == 0` from `SUN4I_IRQ_VECTOR_REG` against `SUN4I_IRQ_PENDING_REG(0) & BIT(0)` before `do { ... } while (hwirq != 0)`. [F253, F286]
- In `exiu_irq_set_type()`, changing between level and edge triggers in `EIEDG` must update the flow handler via `irq_set_handler_locked()` (`handle_fasteoi_irq` vs `handle_fasteoi_ack_irq`) and clear `BIT(d->hwirq)` in `EIREQCLR`. In `rzg2l_clear_irq_int()`, `rzv2h_clear_irq_int()`, and `rzv2h_clear_tint_int()`, only write `ISCR`/`ICU_ISCLR`/`ICU_TSCLR` when pending and edge-triggered in `IITSR`/`ICU_IITSR`/`ICU_TITSR`, never when level-triggered. [F256, F316]
- In `irq-renesas-intc-irqpin.c`, `SOURCE`, `MASK`, and `CLEAR` may be 8- or 32-bit MSB-first: compute masks via `intc_irqpin_hwirq_mask()` (`BIT((p->iomem[reg].width - 1) - hw_irq)`) and use `p->iomem[reg].read`/`write`. `intc_irqpin_shared_irq_enable()`/`disable()` must update `p->shared_irq_mask` (`&= ~BIT(hw_irq)` / `|= BIT(hw_irq)`) in lockstep with `CLEAR`/`MASK`; in `intc_irqpin_shared_irq_handler()`, test `reg_source` with `BIT(7 - k)` and `p->shared_irq_mask` with `BIT(k)`. [F258, F272, F287]
- In `irq-qcom-mpm.c`, `qcom_mpm_read()`/`write()` must compute vMPM SRAM byte offsets as `(reg * priv->reg_stride + index + 2) * 4`, adding 2 words to skip `TIMER0`/`1`. [F307]

## Synchronization

- Once `struct imsic_vector` is allocated, all updates to `enable`, `move_next`, `move_prev`, `lpriv->dirty_bitmap`, and `lpriv->timer` in `__imsic_local_sync()`, `__imsic_local_timer_start()`, and `__imsic_remote_sync()` must hold that CPU's `lpriv->lock` (`raw_spinlock_t`) with IRQs disabled. `imsic_vector_mask()`/`unmask()` use `raw_spin_lock(&lpriv->lock)` and require local IRQs already disabled. `imsic_local_priv::lock` nests outside `imsic_priv::matrix_lock`: never acquire `lpriv->lock` or call `imsic_vector_free()`/`alloc()` while holding `imsic->matrix_lock`. [F204, F205, F334]
- All callers of `__imsic_eix_update()` (including `__imsic_id_set_enable()`/`clear_enable()`), `__imsic_eix_read_clear()`, and `imsic_local_delivery()` must run with local IRQs disabled. `__imsic_local_timer_start()` must pass the target `cpu` to `add_timer_on(&lpriv->timer, cpu)`, and `imsic_state_offline()` must cancel `lpriv->timer` under `lpriv->lock` using `timer_delete_sync_try(&lpriv->timer)`, never `timer_delete_sync()`. [F237, F333, F336]
- In `imsic_irq_set_affinity()`, when `!irq_can_move_in_process_context(d)` and `new_vec->local_id != old_vec->local_id`, `imsic_msi_update_msg()` must first program `tmp_vec` (`old_vec->cpu`, `new_vec->local_id`) before `new_vec`, and `__imsic_local_sync()` must check pending bits on both `tvec` and `vec`. [F209]
- In `irq-qcom-mpm.c`, `priv->lock` (`raw_spinlock_t`) serializes vMPM register accesses in `qcom_mpm_enable_irq()`, `mpm_set_type()`, and `qcom_mpm_handler()`, and must be released before calling `irq_resolve_mapping()`, `irq_set_irqchip_state()`, or parent callbacks. In `irq-renesas-intc-irqpin.c`, RMW accesses to `SENSE`, `PRIO`, and `IRLM` must use `intc_irqpin_read_modify_write()` under module-global `intc_irqpin_lock`. In `irq-pruss-intc.c`, `intc->lock` is a sleeping `struct mutex` for domain ops (`xlate`, `map`, `unmap`) and must never be taken in `pruss_irqchip` callbacks or `pruss_intc_irq_handler()`. [F212, F257, F342]

## Object Lifetimes

- In `__imsic_local_sync()`, the old CPU frees the old vector via `imsic_vector_free(vec)` after clearing `vec->move_next`, and the new CPU must not clear `vec->move_prev` or its `dirty_bitmap` bit while `READ_ONCE(mvec->move_next)` is non-NULL. `imsic_setup_state()` must free temporary `mmios_va` and `mmios` arrays before returning 0 while keeping `ioremap` mappings alive in `global->local`, and on error tear down `imsic_local_cleanup()`, `iounmap(mmios_va[i])`, `mmios_va`, `mmios`, `imsic->global.local`, and `imsic`, resetting `imsic = NULL`. [F195, F196]
- `pruss_intc_probe()` at `fail_irq` (pre-decrementing `while (--i >= 0)` and checking `if (intc->irqs[i])`) and `pruss_intc_remove()` must clear chained handlers via `irq_set_chained_handler_and_data(intc->irqs[i], NULL, NULL)` (and in `remove` call `irq_dispose_mapping()`) before `irq_domain_remove()`. On failure at `fail_cleanup_contexts`, `plic_probe()` must reset `present = false` and clear `hart_base`, `enable_base`, `enable_save` (after `kfree`), and `priv` on all initialized `plic_handlers` entries before freeing `priv`. [F194, F199, F284]
- In `sg2042_msi_probe()`, release `args.fwnode` via `fwnode_handle_put()` after each `fwnode_property_get_reference_args()` call before overwriting `args` or returning. In `qcom_mpm_init()`, map `"qcom,rpm-msg-ram"` with `devm_ioremap()` (not `devm_ioremap_resource()`) and call `of_node_put(msgram_np)` on all paths. [F198, F320]

## API Contracts

- In RISC-V APLIC (`irq-riscv-aplic-*.c`), source 0 is reserved (`1..priv->nr_irqs`): `APLIC_SETIENUM`, `CLRIENUM`, and `SETIPNUM_LE` take 1-based `d->hwirq`, whereas `APLIC_SOURCECFG_BASE` and `TARGET_BASE` use `(d->hwirq - 1) * sizeof(u32)` and domain size is `priv->nr_irqs + 1`. Shared helpers in `irq-riscv-aplic-main.c` must only access `struct aplic_priv` via `irq_data_get_irq_chip_data(d)` and never downcast to `struct aplic_direct`. In `aplic_msi_setup()`, if `!dev_get_msi_domain(dev)`, resolve the parent IMSIC domain (`of_msi_configure()` or `imsic_acpi_get_fwnode()`) and return `-EPROBE_DEFER` if NULL before `msi_create_device_irq_domain()`. In `aplic_msi_translate()`, get `struct aplic_priv *` from `((struct msi_domain_info *)d->host_data)->data`. [F224, F309, F310, F358]
- `imsic_irq_domain_alloc()` and `.irq_set_affinity` callbacks (`imsic_irq_set_affinity()`, `aplic_direct_set_affinity()`, `plic_set_affinity()`) must call `irq_data_update_effective_affinity()`. Set `IRQCHIP_MOVE_DEFERRED` in `imsic_init_dev_msi_info()` for PCI MSI/MSI-X domains, but never on `aplic_msi_template`. `imsic_irq_debug_show()` must check `if (!irqd)` before dereferencing `irqd`. [F348, F349, F350]
- `sg2042_msi_parent_ops`, `sg2044_msi_parent_ops`, and `imsic_msi_parent_ops` must set `MSI_CHIP_FLAG_SET_ACK`. `sg2042`/`sg2044` middle chips must set `.irq_startup = irq_chip_startup_parent`, `.irq_shutdown = irq_chip_shutdown_parent`, and `MSI_FLAG_PCI_MSI_STARTUP_PARENT | MSI_FLAG_PCI_MSI_MASK_PARENT`. SG2042 uses a single register with `1 << d->hwirq`; SG2044 clears `((u32 __iomem *)data->reg_clr) + d->hwirq` with `0`, adds byte offset `4 * (d->hwirq / 32)` to `data->doorbell_addr`, and sets `msg->data = d->hwirq % 32`. [F233, F305, F346, F347]
- In `plic_probe()`, `is_of_node(fwnode)` paths must use OF APIs and never dereference `fwnode->dev` (NULL in `plic_early_probe()`). `plic_irq_set_type()` must return `IRQ_SET_MASK_OK_NOCOPY` when `PLIC_QUIRK_EDGE_INTERRUPT` is unset, and when set switch between `&plic_edge_chip` (`handle_edge_irq`) and `&plic_chip` (`handle_fasteoi_irq`) via `irq_set_chip_handler_name_locked()`. [F318, F356]
- In `irq-pruss-intc.c`, `PRU_INTC_SICR`, `SISR`, `EICR`, and `EISR` take unshifted `hwirq`, whereas `PRU_INTC_ESR(x)`, `ECR(x)`, `SECR(x)`, and `SRSR(x)` are banked by `hwirq / 32` and take `BIT(hwirq % 32)`. In `qcom_mpm_alloc()`, `pin == GPIO_NO_WAKE_IRQ` must return `irq_domain_disconnect_hierarchy(domain, virq)` early, whereas `map == NULL` must disconnect `domain->parent` after `irq_domain_set_hwirq_and_chip()`; `qcom_mpm_mask()`, `unmask()`, and `set_type()` must check `if (d->parent_data)`. [F221, F228, F275]
- In `irq-renesas-rzg2l.c`, `irq-renesas-rzv2h.c`, and `irq-pic32-evic.c`, callbacks must get private data via `d->domain->host_data` (`irq_data_to_priv()`/`irqd_to_priv()`), never `d->chip_data`. `rzv2h_icu_set_type()`, `rzg2l_irqc_set_type()`, `exiu_irq_set_type()`, and `sun6i_r_intc_nmi_set_type()` must pass `IRQ_TYPE_LEVEL_HIGH` to `irq_chip_set_type_parent()`. `irq_chip`s using `handle_fasteoi_irq` (`aplic_direct_chip`, `nvic_of_init()`) must provide a non-NULL `.irq_eoi`. [F311, F312, F354, F355]

## Error Handling

- In `imsic_irqdomain_init()`, check `!imsic || !imsic->fwnode` before dereferencing `*imsic`. In `imsic_vector_alloc()`, store `irq_matrix_alloc()` in a signed `int`, check `< 0`, and initialize `irq`, `enable`, `move_next`, and `move_prev` on `&lpriv->vectors[local_id]`. In `imsic_parse_fwnode()`, validate index bit widths/shifts against `BITS_PER_LONG` and `IMSIC_MMIO_PAGE_SHIFT` before computing `BIT(...)` masks, and `nr_ids`/`nr_guest_ids` against `IMSIC_MIN_ID`/`MAX_ID`. In `aplic_msi_setup()`, check `group_index_shift >= 2 * APLIC_xMSICFGADDR_PPN_SHIFT` before subtracting into `mc->hhxs`, and check `lhxs`, `lhxw`, `hhxw`, `hhxs` against `APLIC_xMSICFGADDRH_*_MASK`. [F216, F226, F263, F264]
- In `plic_probe()`, set a negative `error` before jumping to `fail_cleanup_contexts` after `plic_parse_context_parent()` overwrites `error` with `0`. In `qcom_mpm_init()` and `plic_probe()`, check `devm_ioremap()`/`of_iomap()` for `NULL` and `devm_platform_ioremap_resource()` with `IS_ERR()`. [F218, F219]
- In `stm32mp_exti_chip` callbacks, check `if (d->parent_data->chip)` before `irq_chip_*_parent()`; in `stm32mp_exti_probe()`, ignore `-ENOENT` from `of_hwspin_lock_get_id()`, return other `< 0` errnos, and check `devm_hwspin_lock_request_specific()` for `NULL`. In `sg204x_msi_middle_domain_alloc()`, store `sg204x_msi_allocate_hwirq()` in a signed `int`, and at `err_hwirq` free all `nr_irqs` bitmap bits but only `i` parent IRQs (`irq_domain_free_irqs_parent(domain, virq, i)`). [F222, F232, F235]
- In `rzv2h_tint_set_type()`, check `tint > priv->info->max_tssel` and `if (priv->info->tssel_lut)` before indexing `tssel_lut[tint]`. In `pruss_intc_irq_domain_xlate()`, validate `intspec[0..2]` against `soc_config` limits before `pruss_intc_validate_mapping()`. In RISC-V chained handlers (`aplic_direct_handle_irq()`, `plic_handle_irq()`, `imsic_handle_irq()`), log unmapped IDs with `*_warn_ratelimited` and continue the claim loop. [F230, F267, F359]

## External Contracts

- `partition_irq_print_chip()` and `ts4800_irq_print_chip()` must not emit a leading space. In `sun6i_r_intc_domain_translate()`, accept 2-cell specifiers (`param_count == 2 && param[0] == 0`) for `nmi_hwirq` and require 3 cells (`param[0] == GIC_SPI`) otherwise. [F271, F273]

## Known Pitfalls

- In `imsic_populate_global_dt()`, increment `__fls(*nr_parent_irqs)` if `BIT(global->hart_index_bits) < *nr_parent_irqs`. In `imsic_setup_state()`, round up `resource_size(&mmios[j])` with `ALIGN(..., BIT(global->guest_index_bits) * IMSIC_MMIO_PAGE_SZ)` when subtracting from `reloff`. In `imsic_early_dt_init()`, call `of_node_clear_flag(node, OF_POPULATED)` so `imsic_platform_driver` binds. In `aplic_msi_write_msg()`, cast `msg->address_hi` to `u64` before `<< 32`. [F290, F295, F296, F329]
- In `irq-renesas-rzg2l.c`, shift `TSSR` fields by `TSSEL_SHIFT(tssr_offset)` (`8 * tssr_offset`), never `tssr_offset`. In `rzv2h_tint_irq_endisable()`, write `BIT(tint_nr)` to `ICU_TSCLR` after updating `ICU_TSSR(k)` under `priv->lock`. In `pruss_intc_irq_handler()`, add `FIRST_PRU_HOST_INT` (`2`) to `host_irq_data->host_irq` before indexing `PRU_INTC_HIPIR()`. [F220, F249, F268]
- In `irq-qcom-mpm.c`, store `qcom_mpm_read()` in an `unsigned long` before passing `&val` to `__assign_bit()`/`for_each_set_bit()`; use `qcom_mpm_write()` (includes `wmb()`) for all SRAM writes, and zero `MPM_REG_STATUS` in `mpm_pd_power_off()` before `mbox_send_message()`. In `irq-sun6i-r.c`, use `bitmap_to_arr32()`/`bitmap_from_arr32()` between `unsigned long` bitmaps and `u32` arrays/registers. [F302, F303, F321]
- In `exiu_irq_eoi()` (when `irqd_is_level_type(d)`) and `exiu_irq_enable()`, write `BIT(d->hwirq)` to `EIREQCLR` before EOIing parent or unmasking `EIMASK`. In `xilinx_intc_of_init()`, read back `MER` after writing `MER_HIE | MER_ME` to set `xintc_is_be` and always use `xintc_read()`/`xintc_write()`. [F326, F327]
