# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 11)

Hardware IP block driver for GFX v10.0 (`gc_10_1` Navi1x/RDNA1 and `gc_10_3` Sienna Cichlid/RDNA2), managing graphics and compute rings, MEC/PFP/CE/ME/RLC microcode loading, MQD initialization, KIQ, clockgating/powergating, cleaner shaders, and GFX interrupts.

## Architecture & Data Flow

- In `gfx_v10_0_hw_init`, when `adev->firmware.load_type == AMDGPU_FW_LOAD_DIRECT`, `amdgpu_pm_load_smu_firmware` and `gfx_v10_0_disable_gpa_mode` must run before `gfx_v10_0_rlc_resume`. On GC 10.1.10, 10.1.1, and 10.1.2, `gfx_v10_0_tcp_harvest` must run after both `gfx_v10_0_init_golden_registers` and `gfx_v10_0_rlc_resume` so golden/RLC writes do not overwrite harvested TCP/SQC disables. [F1437, F1490]
- In `gfx_v10_0_tcp_harvest`, updates to `mmUTCL1_UTCL0_INVREQ_DISABLE` and `mmGCRD_SA_TARGETS_DISABLE` must preserve upper non-TCP/SQC bits by masking existing values with `(0xffffffffU << (4 * max_wgp_per_sh))` and `(0xffffffffU << (3 * max_wgp_per_sh))` before ORing in the disable bitmasks. [F1436]
- In `gfx_v10_0_sw_init`, `gfx_v10_0_mec_init` must complete before `gfx_v10_0_compute_ring_init` is called for any compute ring, because `ring->eop_gpu_addr` is derived from `adev->gfx.mec.hpd_eop_gpu_addr`. [F1492]
- On non-reset, non-resume init in `gfx_v10_0_kgq_init_queue`, `gfx_v10_0_kiq_init_queue`, and `gfx_v10_0_kcq_init_queue`, `ring->mqd_ptr` must be zeroed via `memset` before `amdgpu_ring_init_mqd(ring)`, and `mqd_backup` must be checked for non-NULL before `memcpy_fromio`/`memcpy_toio`. In `gfx_v10_0_kgq_init_queue`, `gfx_v10_0_cp_gfx_set_doorbell` must only be called for the first GFX ring (`ring->doorbell_index == adev->doorbell_index.gfx_ring0 << 1`) to avoid overwriting `mmCP_RB_DOORBELL_RANGE_LOWER`. [F1426, F1440]
-When `gfx_v10_0_cp_compute_enable` halts MEC engines (`enable == false`), it must set `adev->gfx.kiq[0].ring.sched.ready = false` in lockstep. [F1442]
- `gfx_v10_0_get_cpc_int_cntl` and `gfx_v10_0_set_compute_eop_interrupt_state` must only program interrupt control registers for MEC1 (`me == 1`), as `amdkfd` manages interrupts for all other pipes. [F1439]
- In `gfx_v10_0_kiq_pm4_funcs`, `set_resources_size` (8), `map_queues_size` (7), `unmap_queues_size` (6), `query_status_size` (7), and `invalidate_tlbs_size` (2) must equal the exact DWord counts written by `gfx10_kiq_set_resources`, `gfx10_kiq_map_queues`, `gfx10_kiq_unmap_queues`, `gfx10_kiq_query_status`, and `gfx10_kiq_invalidate_tlbs`. Likewise, `emit_frame_size` and `emit_ib_size` in `gfx_v10_0_ring_funcs_gfx`, `gfx_v10_0_ring_funcs_compute`, and `gfx_v10_0_ring_funcs_kiq` must be updated in lockstep with their emission callbacks. [F1450, F1451]
- `gfx_v10_0_get_csb_size` must match the exact DWord count written by `gfx_v10_0_get_csb_buffer`, and `gfx_v10_0_cp_gfx_start` must allocate `gfx_v10_0_get_csb_size(adev) + 4` DWords on `gfx_ring[0]` to fit the trailing 4-DWord `PACKET3_SET_BASE`. [F1460]
- In `gfx_v10_0_ring_emit_vm_flush`, emitting a GPU TLB flush on `AMDGPU_RING_TYPE_GFX` must be followed by `PACKET3_PFP_SYNC_ME`. [F1446]
- In `gfx_v10_0_ring_preempt_ib`, `amdgpu_ring_set_preempt_cond_exec(ring, false)` before `PREEMPT_QUEUES_NO_UNMAP` must be paired with `amdgpu_ring_set_preempt_cond_exec(ring, true)` after polling the trailing fence, even on timeout. [F1447]
- `gfx_v10_ring_insert_nop` must handle `num_nop == 1` before computing `min(num_nop - 2, 0x3ffe)` for `PACKET3_NOP`, and must not be called with `num_nop == 0`. [F1459]
- `gfx_v10_0_init_gds_vmid` must start at `vmid = 1` (never clearing VMID 0), and all per-VMID GDS accesses (`gfx_v10_0_init_gds_vmid`, `gfx_v10_0_init_compute_vmid`, `gfx_v10_0_ring_emit_gds_switch`) must index `mmGDS_VMID0_BASE` and `mmGDS_VMID0_SIZE` by `2 * vmid` while indexing `mmGDS_GWS_VMID0` and `mmGDS_OA_VMID0` by `vmid`. [F1456]
- `gfx_v10_0_rlc_backdoor_autoload_copy_ucode` must verify `id > FIRMWARE_ID_INVALID && id < FIRMWARE_ID_MAX`, clamp `fw_size` to `rlc_autoload_info[id].size`, and zero-fill trailing bytes up to `rlc_autoload_info[id].size` in `adev->gfx.rlc.rlc_autoload_ptr`. [F1454]
- `gfx_v10_0_check_grbm_cam_remapping` must save and restore `mmVGT_ESGS_RING_SIZE` (or `mmVGT_ESGS_RING_SIZE_Sienna_Cichlid`) around writing the `0xDEADBEEF` probe to `mmVGT_ESGS_RING_SIZE_UMD` on both remapped and non-remapped branches. [F1448]
- Allocation sizes in `gfx_v10_0_alloc_ip_dump` and traversal order / MEC2 header substitution in `gfx_v10_ip_dump` and `gfx_v10_ip_print` must stay synchronized across `gc_reg_list_10_1`, `gc_cp_reg_list_10`, and `gc_gfx_queue_reg_list_10`. [F1449]

## Synchronization

- Every call to `gfx_v10_0_select_se_sh` (`gfx_v10_0_setup_rb`, `gfx_v10_0_tcp_harvest`, `gfx_v10_0_get_cu_info`) must hold `adev->grbm_idx_mutex` and restore broadcast mode via `gfx_v10_0_select_se_sh(adev, 0xffffffff, 0xffffffff, 0xffffffff, 0)` before unlocking. [F1404]
- Every path calling `nv_grbm_select` must hold `adev->srbm_mutex` and reset selection with `nv_grbm_select(adev, 0, 0, 0, 0)` before unlocking `adev->srbm_mutex`. In `gfx_v10_0_cp_gfx_resume`, `gfx_v10_0_cp_gfx_switch_pipe` must be protected by `adev->srbm_mutex`, and after configuring `gfx_ring[1]` on `PIPE_ID1`, `gfx_v10_0_cp_gfx_switch_pipe(adev, PIPE_ID0)` must be called under `adev->srbm_mutex` before `gfx_v10_0_cp_gfx_start`. [F1405, F1407]
- When acquiring both RLC safe mode and `adev->srbm_mutex` (`gfx_v10_0_kiq_reset_hw_queue`, `gfx_v10_0_reset_kcq`), `amdgpu_gfx_rlc_enter_safe_mode` must precede `mutex_lock(&adev->srbm_mutex)` and `amdgpu_gfx_rlc_exit_safe_mode` must follow `mutex_unlock(&adev->srbm_mutex)`. [F1406]
- In `gfx_v10_0_ring_preempt_ib`, `gfx_v10_0_reset_kgq`, and `gfx_v10_0_reset_kcq`, KIQ ring allocation and packet emission must be serialized under `spin_lock_irqsave(&kiq->ring_lock, flags)`, unlocking both on `amdgpu_ring_alloc` failure and after `amdgpu_ring_commit`. [F1412]
- In `gfx_v10_0_get_gpu_clock_counter`, reading the 64-bit Golden TSC counter across upper/lower SMUIO registers must occur under `preempt_disable()` / `preempt_enable()` using `RREG32_SOC15_NO_KIQ` with an upper-register carry-over recheck (`hi_check != clock_hi`). [F1419]
- IRQ `.process` callbacks (`gfx_v10_0_eop_irq`, `gfx_v10_0_priv_reg_irq`, `gfx_v10_0_bad_op_irq`, `gfx_v10_0_priv_inst_irq`, `gfx_v10_0_kiq_irq`, and helper `gfx_v10_0_handle_priv_fault`) run in atomic context and must only call `amdgpu_fence_process` or `drm_sched_fault` without sleeping locks (`srbm_mutex`, `grbm_idx_mutex`) or KIQ register reads. [F1519]

## Object Lifetimes

- In `gfx_v10_0_mec_init`, `adev->gfx.mec.hpd_eop_obj` and `adev->gfx.mec.mec_fw_obj` created with `amdgpu_bo_create_reserved` must be unmapped and unreserved via `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` after CPU initialization, and any error path must call `gfx_v10_0_mec_fini(adev)`. [F1402]
- All kernel BOs (`pfp_fw_obj`, `ce_fw_obj`, `me_fw_obj`, `clear_state_obj`, `cp_table_obj`, `hpd_eop_obj`, `mec_fw_obj`, `rlc_toc_bo`, `rlc_autoload_bo`), firmware blobs, and `kcalloc`-allocated IP dump arrays (`ip_dump_core`, `ip_dump_compute_queues`, `ip_dump_gfx_queues`) are unmanaged and must be freed in `gfx_v10_0_sw_fini`. KIQ teardown in `gfx_v10_0_sw_fini` must call `amdgpu_gfx_kiq_free_ring(&adev->gfx.kiq[0].ring)` before `amdgpu_gfx_kiq_fini(adev, 0)`. [F1403, F1494]
- In `gfx_v10_0_update_gfx_clock_gating`, clockgating must be enabled in order FGCG, MGCG/MGLS, 3D CGCG/CGLS, then CGCG/CGLS, and disabled in exact reverse order, all bracketed by `amdgpu_gfx_rlc_enter_safe_mode` and `amdgpu_gfx_rlc_exit_safe_mode`. [F1410]
- In `gfx_v10_0_set_powergating_state` on GC 10.3.1, 10.3.3, 10.3.6, and 10.3.7, `amdgpu_gfx_off_ctrl(adev, false)` must precede `gfx_v10_cntl_pg(adev, false)` when ungating, and `amdgpu_gfx_off_ctrl(adev, true)` must follow `gfx_v10_cntl_pg(adev, true)` when gating. [F1411]
- In `gfx_v10_ip_dump`, each dump stage must verify its destination buffer (`ip_dump_core`, `ip_dump_compute_queues`, `ip_dump_gfx_queues`) is non-NULL before calling `amdgpu_gfx_off_ctrl(adev, false)` and pair it with `amdgpu_gfx_off_ctrl(adev, true)` outside `adev->srbm_mutex`. [F1413]

## API Contracts

- `gfx_v10_0_compute_ring_init` takes a 0-based `mec` index and sets `ring->me = mec + 1`, whereas `gfx_v10_0_get_cpc_int_cntl` and `gfx_v10_0_set_compute_eop_interrupt_state` take a 1-based `me` index (`1` for MEC1, `2` for MEC2), and `gfx10_kiq_map_queues` encodes `PACKET3_MAP_QUEUES_ME` as `ring->me == 1 ? 0 : 1`. [F1427]
- `ring->mqd_ptr` and `ring->mqd_obj` hold `struct v10_gfx_mqd` for GFX rings (`gfx_v10_0_gfx_mqd_init`, `gfx_v10_0_kgq_init_queue`, `gfx_v10_0_reset_kgq`) and `struct v10_compute_mqd` for compute and KIQ rings (`gfx_v10_0_compute_mqd_init`, `gfx_v10_0_kcq_init_queue`, `gfx_v10_0_kiq_init_queue`). [F1483]
- `gfx_v10_0_select_se_sh` uses `0xffffffff` as the broadcast sentinel for `se_num`, `sh_num`, and `instance`. In GFX10, the SIMD ID must be encoded in `instance` via `gfx_v10_0_select_se_sh` while passing `simd == 0` to `gfx_v10_0_read_wave_data` and `gfx_v10_0_read_wave_sgprs`. [F1458]
- `amdgpu_ring_write_multiple` takes a count in 32-bit DWords, so `gfx_v10_0_ring_emit_ce_meta` and `gfx_v10_0_ring_emit_de_meta` must pass `sizeof(ce_payload) >> 2` and `sizeof(de_payload) >> 2`. [F1482]
- `gfx_v10_0_me_init` and `gfx_v10_0_mec_init` must pass bit counts `AMDGPU_MAX_GFX_QUEUES` and `AMDGPU_MAX_COMPUTE_QUEUES` (not byte sizes) to `bitmap_zero` on `adev->gfx.me.queue_bitmap` and `adev->gfx.mec_bitmap[0].queue_bitmap`. [F1489]
- `gfx_v10_0_ring_emit_init_cond_exec` must capture and return `ring->wptr & ring->buf_mask` before calling `amdgpu_ring_write(ring, 0)` for the skip-count placeholder. [F1524]
- Per-queue reset callbacks `gfx_v10_0_reset_kgq` and `gfx_v10_0_reset_kcq` must call `amdgpu_ring_reset_helper_begin(ring, timedout_fence)` before unmapping/resetting the queue and clearing the ring, and return `amdgpu_ring_reset_helper_end(ring, timedout_fence)` after remapping. [F1527]

## Error Handling

- `gfx_v10_0_get_cpg_int_cntl` and `gfx_v10_0_get_cpc_int_cntl` return `0` for unsupported `me` or `pipe` indices (`me != 0` for CPG, `me != 1` for CPC); callers must check that the returned offset is non-zero before passing it to `RREG32_SOC15_IP` or `WREG32_SOC15_IP`. [F1422]
- `gfx_v10_0_alloc_ip_dump` treats allocation failures of `ip_dump_core`, `ip_dump_compute_queues`, and `ip_dump_gfx_queues` as non-fatal by setting the pointer to `NULL`; `gfx_v10_ip_dump` and `gfx_v10_ip_print` must check each buffer pointer for `NULL` before dereferencing. [F1424]

## External Contracts

- HQD ring base (`cp_gfx_hqd_base`, `cp_hqd_pq_base_lo`, `mmCP_RB0_BASE`, `mmCP_RB1_BASE`), EOP base (`cp_hqd_eop_base_addr_lo`), and KIQ `PACKET3_SET_RESOURCES` cleaner shader addresses require 256-byte-granularity GPU addresses (`>> 8`), whereas MQD base (`cp_mqd_base_addr`), RPTR (`rptr_gpu_addr`), and WPTR poll (`wptr_gpu_addr`) take unshifted byte addresses masked with `0xfffffffc`. [F1431]

## Known Pitfalls

- In `gfx_v10_0_sw_init`, GFX and compute ring init loops iterate `j` over queues and `k` over pipes to allocate horizontally across pipes; pass `(adev, ..., i, k, j)` (`k` as `pipe`, `j` as `queue`) to `amdgpu_gfx_is_me_queue_enabled`, `gfx_v10_0_gfx_ring_init`, `amdgpu_gfx_is_mec_queue_enabled`, and `gfx_v10_0_compute_ring_init`. [F1465]
- In `gfx_v10_0_get_cu_info`, `bitmap` first holds the linear SA index `i * adev->gfx.config.max_sh_per_se + j` to test `gfx_v10_3_get_disabled_sa(adev)` before being overwritten with `gfx_v10_0_get_cu_active_bitmap_per_sh(adev)`, and `mask = 1`, `ao_bitmap = 0`, and `counter = 0` must be reset on every `(i, j)` iteration. [F1468]
- In `gfx_v10_0_ring_get_wptr_gfx`, the 32-bit `RREG32_SOC15` read of `mmCP_RB0_WPTR_HI` / `mmCP_RB1_WPTR_HI` must be cast to `u64` before `<< 32`. [F1477]
- Because `gfx_v10_0_parse_rlc_toc` aligns CP firmware offsets up via `ALIGN(rlc_toc->offset * 4, PAGE_SIZE)`, `gfx_v10_0_calc_toc_total_size` must bound `total_size` by at least `rlc_autoload_info[FIRMWARE_ID_MAX-1].offset + rlc_autoload_info[FIRMWARE_ID_MAX-1].size`, not just the sum of sizes. [F1479]
- In `struct gfx_firmware_header_v1_0` and `struct sdma_firmware_header_v1_0`, `ucode_array_offset_bytes` and `ucode_size_bytes` are byte counts whereas `jt_offset` and `jt_size` are DWord counts; add `jt_offset` to a 32-bit pointer (`__le32 *` or `uint32_t *`) and multiply `jt_size` by 4 for byte calculations. [F1481]
- In `gfx_v10_0_sw_init`, `adev->gfx.cleaner_shader_size` must be set to `sizeof(gfx_10_*_cleaner_shader_hex)` in bytes (not `sizeof(pointer)` or `ARRAY_SIZE`). Enabling the cleaner shader (`enable_cleaner_shader = true` and `amdgpu_gfx_cleaner_shader_sw_init`) must be gated on both `GC_HWIP` version and minimum `me_fw_version`, `pfp_fw_version`, and `mec_fw_version` thresholds, resetting `enable_cleaner_shader = false` if `sw_init` fails. [F1484, F1496]
- Writeback slot offsets from `amdgpu_device_wb_get` (`index`, `reg_val_offs`) are DWord indices: index `adev->wb.wb[index]` directly, but multiply by 4 when adding to `adev->wb.gpu_addr` in `gfx_v10_0_ring_test_ib` and `gfx_v10_0_ring_emit_rreg`. [F1485]
- In `gfx_v10_0_ring_emit_reg_write_reg_wait`, combined write-and-wait (`gfx_v10_0_wait_reg_mem` with `opt = 1`) must only be used when `adev->gfx.cp_fw_write_wait` is true; otherwise fall back to `amdgpu_ring_emit_reg_write_reg_wait_helper`. [F1497]
- Hardware-specific quirks that must be preserved: on `IP_VERSION(10, 1, 10)` (Navi10), `gfx_v10_0_check_gfxoff_flag` must clear `PP_GFXOFF_MASK` unless `adev->pdev->revision` is `0xc2` or `0xc3` (`gfx_v10_0_navi10_gfxoff_should_enable`); `SOC15_REG_GOLDEN_VALUE(GC, 0, mmLDS_CONFIG, 0x00000020, 0x00000020)` in `golden_settings_gc_10_3_2` and `golden_settings_gc_10_3_vangogh` must not be removed; on `IP_VERSION(10, 1, 2)`, writes to `mmRLC_CSIB_ADDR_HI/LO`, `mmRLC_CSIB_LENGTH` in `gfx_v10_0_init_csb` and `mmCP_ME_CNTL` in `gfx_v10_0_cp_gfx_enable` must use `WREG32_SOC15_RLC`. [F1498, F1499, F1507]
- In `gfx_v10_0_hw_fini`: on `amdgpu_sriov_vf(adev)`, only call `gfx_v10_0_cp_gfx_enable(adev, false)` and return early without halting MEC or clearing KIQ (`gfx_v10_0_cp_enable(adev, false)`); on `IP_VERSION(10, 3, 1)` (VanGogh), call `gfx_v10_0_set_powergating_state(ip_block, AMD_PG_STATE_UNGATE)` before disabling KGQ/KCQ and halting CP. [F1510, F1511]
