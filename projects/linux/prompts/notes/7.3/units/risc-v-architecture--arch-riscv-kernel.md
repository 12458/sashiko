# RISC-V ARCHITECTURE — arch/riscv/kernel

`arch/riscv/kernel` implements the core RISC-V kernel runtime: boot setup, CPU/vendor extension discovery, SMP/IPI, SBI calls, traps/misaligned accesses, signals, context switching, module relocation, code patching, suspend/hibernate, kexec, ACPI/DT init, and `riscv_hwprobe`/vDSO.

## Architecture & Data Flow
- Every relocation in `module.c` calling `module_emit_plt_entry()` or `module_emit_got_entry()` must be in `rela_needs_plt_got_entry()` and `count_max_entries()`. `mod->arch.plt` and `mod->arch.got_plt` must share `max_entries` and increment `num_entries` in lockstep. `apply_relocate_add()` LO12 lookups must start at `j_idx`, wrap at `num_relocations`, and save `j_idx = j`, while `module_frob_arch_sections()` must sort a scratch copy of `SHT_RELA`. HI20/LO12 relocations must add `0x800` before `& 0xfffff000`, and 64-bit PC-relative offsets must pass `riscv_insn_valid_32bit_offset()`. [F202, F203, F253, F271]
- `thread_struct` fields accessed in `__switch_to` via `a3`/`a4` (or `__fstate_save`/`__fstate_restore` via `fstate.f[0]`) need relative `TASK_THREAD_*_RA` (`TASK_THREAD_F*_F0`) offsets in `asm_offsets()`, which must also define `FREGS_T2`..`FREGS_T6` under `CONFIG_DYNAMIC_FTRACE_WITH_ARGS && CONFIG_CC_IS_CLANG`. [F206, F317]
- In `traps_misaligned.c`, `set_f32_rd()`, `set_f64_rd()`, `get_f32_rs()`, and `get_f64_rs()` must set `regs->status |= SR_FS_DIRTY`. `handle_scalar_misaligned_load()`/`store()` must mask `insn` with `INSN_MASK_*` before comparing `INSN_MATCH_*` (including Zcb `C_LHU`/`C_LH`/`C_SH` and rejecting `C_LDSP`/`C_LWSP` when `rd == 0`). [F213, F244]
- `disable_xtheadvector()` must clear `RISCV_ISA_VENDOR_EXT_XTHEADVECTOR` in both `all_harts_isa_bitmap` and all `per_hart_isa_bitmap[cpu]` before `apply_boot_alternatives()`. `riscv_cpufeature_patch_func()` must skip standard extension alternatives (`id < RISCV_ISA_EXT_MAX`) when `alt->vendor_id != 0`. [F216, F247]
- In `riscv_parse_isa_string()`, `case 's':` must check `ext[-1] != '_' && ext[1] == 'u'` before falling through to `'S'`/`'z'`/`'Z'`. In `riscv_fill_hwcap_from_isa_string()` and `riscv_fill_hwcap_from_ext_list()`, `riscv_isa` and `elf_hwcap` must initialize on the first valid hart (`bitmap_empty(riscv_isa, ...)` / `!elf_hwcap`) via `bitmap_copy`/assignment and intersect subsequent harts via `bitmap_and`/`&=`. [F248, F259]
- In `temp_pgtable_mapping()` and `temp_pgtable_map_p4d`/`pud`/`pmd()`, compute `next = *_addr_end(start, end)` before `continue` on `*_none(...)` so `dst_*`, `src_*`, and `start` advance together. [F255]
- `__sbi_v01_cpumask_to_hartmask()` must reject `hartid >= BITS_PER_LONG`, and `__sbi_rfence_v02()` must flush/reset `hmask` when `hartid + BITS_PER_LONG <= htop` or `hbase + BITS_PER_LONG <= hartid` before shifting. [F269]

## Synchronization
- Under `CONFIG_MMU`, `__patch_insn_set()`/`write()` require `text_mutex`, disable preemption while `FIX_TEXT_POKE0`/`1` are mapped, call `local_flush_icache_range()` before `patch_unmap()` (unmapping `FIX_TEXT_POKE1` when `across_pages`), and re-enable preemption after. In `patch_text_cb()`, the last CPU (`atomic_inc_return(&patch->cpu_count) == num_online_cpus()`) calls `patch_insn_write()` and `atomic_inc_return_release(&patch->cpu_count)` before `local_flush_icache_all()`. [F155, F167]
- `riscv_v_context_nesting_start()`/`end()` require local IRQs disabled while updating `riscv_v_flags` and restoring `kernel_vstate`. `kernel_fpu_begin()`/`end()` must bracket `fstate_save()`/`fstate_restore()` and `SR_FS` changes with `preempt_disable()`/`preempt_enable()`. [F171, F173]
- `sbi_cpu_start()` needs `smp_mb()` before writing `bdata->task_ptr`/`stack_ptr` and another `smp_mb()` before `sbi_hsm_hart_start()`. `cpu_update_secondary_bootdata()` needs `smp_mb()` before `WRITE_ONCE()` to `__cpu_spinwait_stack_pointer`/`task_pointer`. `crash_smp_send_stop()` must `atomic_set(&waiting_for_crash_ipi, num_other_online_cpus())` before `IPI_CPU_CRASH_STOP`, and `ipi_cpu_crash_stop()` must call `crash_save_cpu()` before decrementing it. [F174, F175, F179]
- `die()` holds `die_lock` (`raw_spin_lock_irqsave`) across oops output, `die_counter`, `notify_die()`, and `crash_kexec()`, unlocking before `oops_exit()`, `panic()`, or `make_task_dead()`. Because `dump_instr()` runs under `die_lock` with IRQs off, `copy_code()` must use `get_kernel_nofault()` or `copy_from_user_nofault()` (only if `regs == task_pt_regs(current)`). In `traps.c`, `DO_ERROR_INFO`, `do_trap_insn_illegal`, `do_trap_misaligned`, and `do_trap_break` must bracket user-mode handling with `local_irq_enable()`/`local_irq_disable()`. [F182, F304, F305]

## Object Lifetimes
- `check_vector_unaligned_access()` must call `__free_pages(page, MISALIGNED_BUFFER_ORDER)` on both normal exit and `!word_cycles || !byte_cycles`. In `sbi_ipi_init()`, call `irq_dispose_mapping(sbi_ipi_virq)` if `ipi_mux_create()` fails. [F152, F164]
- In `module.c`, `relocation_hashtable` uses `kvmalloc_array()`/`kvfree()`. `add_relocation_to_accumulate()` must `kfree()` `entry` and `rel_head` on error, and all three nested loops in `process_accumulated_relocations()` must use `*_for_each_entry_safe` before `kfree()`. [F154, F250, F279]
- Release every `acpi_get_table()` with `acpi_put_table()` (`acpi_fadt_sanity_check()`, `riscv_fill_hwcap_from_isa_string()`, `time_init()`) and every `of_*` node with `of_node_put()` on all loop and error paths. [F156, F297]
- In `load_extra_segments()`, `vfree(headers)` and `kvfree(fdt)` on `kexec_add_buffer()` error, or store them in `image->elf_headers` and `image->arch.fdt` for `arch_kimage_file_post_load_cleanup()` to free and NULL. Do not free `get_safe_page(GFP_ATOMIC)` pages in `swsusp_arch_resume()`. [F158, F161]
- In `init_resources()`, `mem_res` fills backwards via `res_idx--`; if skipping a reserved region where `memblock_is_memory(res->start)`, increment `res_idx++` before `continue`. Free unused prefix slots via `memblock_free(mem_res, (res_idx + 1) * sizeof(*mem_res))`, and on `add_resource()` failure call `release_child_resources(&iomem_resource)` and `memblock_free(mem_res, mem_res_sz)`. [F163, F260]
- `arch_dup_task_struct()` must save `src` FPU state before `*dst = *src` and zero `vstate`, zero `kernel_vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE` on `dst`. `flush_thread()` must call `riscv_v_vstate_ctrl_init(current)` and `riscv_v_vstate_off()`, free `vstate.datap`, zero `vstate`, and clear `TIF_RISCV_V_DEFER_RESTORE`. [F207, F208]

## API Contracts
- In `riscv_resolve_isa()`, `.validate` returns `0` (enable), `-EPROBE_DEFER` (retry), or other non-zero (clear `source_isa`), and the loop must bound passes with `max_loop_count`, reset `loop = false`, and stop when `bitmap_equal(prev_resolved_isa, resolved_isa, RISCV_ISA_EXT_MAX)`. `NULL` `isa_bitmap` in `riscv_isa_extension_base()` / `__riscv_isa_extension_available()` selects `riscv_isa`. Bounds-check `bit < RISCV_ISA_EXT_MAX` / `RISCV_ISA_VENDOR_EXT_MAX` (`riscv_isa_set_ext()` skips `RISCV_ISA_EXT_INVALID`), and subtract `RISCV_VENDOR_EXT_ALTERNATIVES_BASE` before `__riscv_isa_vendor_extension_available()` (`cpu == -1` or valid CPU). [F188, F189, F190, F242, F252]
- `sbi_ecall(e, f, a0..a5)` passes `(f, e)` last to `__sbi_ecall()`, which binds `a0`–`a5`, `a6` (`fid`), `a7` (`ext`) with `"+r" (a0)`, `"+r" (a1)`, and `"memory"` clobber. [F191, F325]
- `__patch_insn_set()`/`write()` reject `len + offset_in_page(addr) > 2 * PAGE_SIZE` with `-EINVAL`; use `patch_insn_set()`/`write()` for arbitrary lengths. `riscv_sys_mmap()` must reject `offset & (~PAGE_MASK >> page_shift_offset)` with `-EINVAL` before shifting. [F200, F275]
- On ACPI systems, `setup_smp()` -> `acpi_init_rintc_map()` -> `acpi_map_cpus_to_nodes()`. `acpi_os_ioremap()` must reject `phys + size > end` or `memblock_is_map_memory(phys) || !memblock_is_region_memory(phys, size)`, mapping `EFI_RUNTIME_SERVICES_CODE` and NOMAP RAM as `PAGE_KERNEL_RO`. [F289, F300]
- Check `riscv_has_extension_unlikely(RISCV_ISA_EXT_SUPM)` or `RISCV_ISA_EXT_XLINUXENVCFG` before accessing `CSR_ENVCFG` or pointer-masking state, and include `riscv_xlinuxenvcfg_exts` on any `riscv_isa_ext[]` entry implying `CSR_ENVCFG`. `riscv_v_setup_vsize()` must prefer non-zero `thead_vlenb_of` over `CSR_VLENB` and bracket `CSR_VLENB` reads with `riscv_v_enable()`/`disable()`. [F292, F293, F294]
- On resume in `swsusp_arch_suspend()`, call `suspend_restore_csrs()`, `flush_tlb_all()`, `flush_icache_all()`, and reset `in_suspend = 0`, `sleep_cpu = -EINVAL`. In `swsusp_arch_resume()`, `resume_pg_dir` must map linear memory (`_PAGE_WRITE | _PAGE_EXEC`) and `resume_hdr.restore_cpu_addr` (`_PAGE_WRITE`), and `relocate_restore_code()` must copy to a `get_safe_page()` page and call `set_memory_x()`. [F303, F324]
- User-mode accesses in `traps_misaligned.c` must use fault-capable `copy_from_user()`/`copy_to_user()`/`get_user()`. Trap/IRQ/idle/stackwalk entry points must be `noinstr` (`handle_riscv_irq()` uses `irq_enter_rcu()`/`irq_exit_rcu()`). `unwind_user_frame()` requires `access_ok()` and `__copy_from_user_inatomic()`, and `__get_wchan()` requires `try_get_task_stack()`/`put_task_stack()`. Export both `boot_cpu_hartid` and `__cpuid_to_hartid_map` with `EXPORT_SYMBOL_GPL`. [F306, F321, F322, F326]

## Error Handling
- Zero-initialize stack `struct kexec_buf kbuf = {}` and reset `kbuf.mem = KEXEC_BUF_MEM_UNKNOWN` before each reuse; `elf_kexec_load()` and `image_load()` return `NULL` on success and `ERR_PTR(ret)` on error after `kexec_free_elf_info(&elf_info)`. In `__setup_additional_pages()`, convert failed `vdso_base` via `ERR_PTR(vdso_base)` and clear `mm->context.vdso = NULL` on `up_fail`. [F185, F186, F199]
- Check `!has_vector()` in `check_unaligned_access_all_cpus()` (setting `RISCV_HWPROBE_MISALIGNED_VECTOR_UNSUPPORTED`), and only probe in `riscv_online_cpu_vec()`, `check_vector_unaligned_access()`, and `check_unaligned_access()` when state is `*_UNKNOWN`. [F187, F246]
- `sbi_probe_extension()` returns `0` on failure/unsupported and `> 0` when supported; `sbi_debug_console_write()`/`read()` map `SBI_ERR_FAILURE` to `-EIO` before `sbi_err_map_linux_errno()`. `relocate_restore_code()` returns `(unsigned long)-ENOMEM` on failure, and `arch_hibernation_header_restore()` must reset `sleep_cpu = -EINVAL` on error. [F192, F194]
- Check `of_get_cpu_hwid() != ~0UL` (`INVALID_HARTID`) in `riscv_*_hartid()`, and check `riscv_hartid_to_cpuid() < 0` in a signed `int`. User trap/sigframe faults must never call `die()`/`WARN*()`, gating ratelimited logs with `show_unhandled_signals`. [F196, F337]

## External Contracts
- Zero `reserved` sigcontext fields on delivery and reject non-zero with `-EINVAL` on `rt_sigreturn`. Terminate `sc_extdesc.hdr` with `END_MAGIC`/`END_HDR_SIZE`. `restore_sigcontext()` advances `sc_ext_ptr` past `sizeof(*head)` before dispatch, sets `sc_ext_ptr = (void __user *)head + size` after, and checks `RISCV_V_MAGIC`, active vector state, and `size == riscv_v_sc_size` before `__restore_v_state()`, which calls `riscv_v_vstate_set_restore()` before `copy_from_user()`. `setup_rt_frame()`/`compat_setup_rt_frame()` unconditionally set `regs->a1 = &frame->info` and `regs->a2 = &frame->uc`. [F225, F227, F262, F332, F333, F334]
- Resource ends in `init_resources()` are inclusive (`base + size - 1`), and `reserve_memblock_reserved_regions()` splits reserved ranges with `reserve_region_with_split()`. `hwprobe_one_pair()` must handle all `0 .. RISCV_HWPROBE_MAX_KEY`, and unknown hwprobe keys set `pair->key = -1` (`value = 0` or clear cpumask) without returning an error. [F240, F249, F327]
- On RV32, pass `stime_value >> 32` as the second arg to `__sbi_set_timer_v01()`/`v02()` and split `base_addr` with `lower_32_bits()`/`upper_32_bits()` in `sbi_debug_console_write()`/`read()`. Keep `riscv_isa_ext[]` in canonical ISA order. Under `CONFIG_RISCV_ISA_SUPM`, `mm->context.pmlen` is non-zero only when `PR_TAGGED_ADDR_ENABLE` is set (`task->thread.envcfg & ENVCFG_PMM` holds the active length, updated via `envcfg_update_bits()`), and `set_tagged_addr_ctrl()` rejects compat threads (`-EINVAL`) and holds `mmap_write_lock_killable(mm)` while checking `MM_CONTEXT_LOCK_PMLEN` (`-EBUSY` after `CLONE_VM`). [F209, F270, F298, F335]

## Known Pitfalls
- Mask `TASK_THREAD_SUM_RA(a4)` with `SR_SUM` before `csrs CSR_STATUS, s0` in `__switch_to`. Slot 0 of `pt_regs` is `epc`, not `x0`: treat register 0 as 0 when indexing `(unsigned long *)regs`, and read `rs1_index` before writing `rd_index` in `simulate_jalr()`. [F205, F219, F229]
- Return `(void __user __force *)(-1UL)` in `get_sigframe()`/`compat_get_sigframe()` if `on_sig_stack(sp) && !on_sig_stack(sp - framesize)`. `get_rt_frame_size()` must not add `sizeof(struct __riscv_ctx_hdr)` for `END_MAGIC`, and `restore_sigcontext()`/`setup_sigcontext()` must copy `sizeof(sc->sc_regs)`, not `sizeof(*regs)`. [F230, F276, F278]
- Do not dereference loop cursors `rel_head_iter` or `md` after the loop in `add_relocation_to_accumulate()` / `acpi_os_ioremap()`. In `riscv_alternative_fix_offsets()`, check `i < num_insn - 1` and increment `i++` for `auipc`+`jalr`, and skip `jal` targets in `[alt_ptr, alt_ptr + len)`. [F251, F254]
- Use `u64 clone_flags` in `copy_thread()`, `1ULL << PERF_REG_RISCV_MAX` for `REG_RESERVED`, and `(u32)idx` in `perf_reg_value()`. In `handle_scalar_misaligned_load()`, zero `val.data_u64` and cast `(val.data_ulong << shift)` to `long` before `>> shift`; in `get_insn()`, mask 16-bit `insn` with `GENMASK(15, 0)`. [F264, F265, F266, F274]
- Cast upper 16-bit parcels to `u32`/`kprobe_opcode_t` before `<< 16`, convert extracted immediates in `simulate-insn.c` to `s32`, and cast `u32 *` (`p->addr`, `p->ainsn.api.insn`) to `(void *)`/`unsigned long` before adding byte offsets in `kprobes.c`. [F272, F273, F280]
- Check `name_end - name == strlen(ext->name)` with `strncasecmp()` in `match_isa_ext()`, and use `bitmap_*()` helpers on multi-word ISA bitmaps. Mark callers of `__init` as `__init`, `_apply_alternatives()`/`riscv_cpufeature_patch_func()` as `__init_or_module`, and never pass vmalloc or `DEFINE_PER_CPU()` pointers to `__pa()` for SBI calls. [F283, F284, F299, F314]
