# GENERIC PHY FRAMEWORK — drivers/phy (part 2)

Implements generic PHY and clock provider drivers for Cadence (D-PHY RX/TX, Salvo USB, Sierra/Torrent SERDES) and Freescale/NXP i.MX8/i.MX95 (MIPI D-PHY, PCIe, USB, HSIO SERDES, LVDS, Samsung HDMI) transceivers.

## Architecture & Data Flow

- In `cdns_dphy_ops`, only `get_wakeup_time_ns` is mandatory; `probe`, `remove`, `set_psm_div`, `set_clk_lane_cfg`, `set_pll_cfg`, `wait_for_pll_lock`, and `wait_for_cmn_ready` must be null-checked. In `cdns_dphy_get_pll_cfg()`, `dlane_bps` and `pll_ref_hz` must be widened to `u64` before multiplying by `pll_opdiv`/`pll_ipdiv`/`pll_fbdiv` and divided via `DIV_ROUND_UP_ULL`/`div_u64`. [F30, F86]
- In `cdns-dphy.c` and `cdns-dphy-rx.c`, `tx_bands`/`bands` must stay sorted by ascending rate at hardware band indices; `cdns_dphy_rx_configure` must check `lanes <= DPHY_LANES_MAX` (4) before `cdns_dphy_rx_wait_lane_ready` indexes `data_lane_ctrl`, and must only write `DPHY_LANE_RESET_CMN_EN` when `soc_device_match(cdns_dphy_socinfo)` does not match `has_hw_cmn_rstb` (J721E SR1.0). [F71, F100]
- In `phy-cadence-sierra.c`, when `sp->nsubnodes > 1`, common CDB regs and `sp->phy_rst` are set once in `cdns_sierra_phy_configure_multilink`, so `cdns_sierra_phy_init` must return early and `cdns_sierra_phy_on`/`off` must only toggle `sp->phy_rst` if `sp->nsubnodes == 1`. When `sp->already_configured` is non-zero, `PHY_CLK` and `phy_rst`/`apb_rst` are not acquired, child PHYs use `noop_ops`, and `cdns_sierra_phy_disable_clocks` must skip `sp->input_clks[PHY_CLK]`. [F45, F47]
- In `phy-cadence-sierra.c`, lane regmaps (`regmap_phy_pma_lane_cdb`, `regmap_lane_cdb`) are indexed by `i + ins->mlane` (`0 <= i < ins->num_lanes`) and status fields (`phy_iso_link_ctrl_1`, `pllctrl_lock`) by `ins->mlane`. `struct cdns_sierra_phy` ends in flexible array `clk_data.hws[]` allocated for `CDNS_SIERRA_OUTPUT_CLOCKS`, which bounds `hws` indices. [F46, F95]
- In `cdns_sierra_phy_configure_multilink()` and `cdns_torrent_phy_configure_multilink()`, pass 2 (`node == 1` / `protocol == 1`) must swap `phy_t1`/`phy_t2` (and `ref_clk`/`ref_clk1` in Torrent) before table lookups. In Torrent multilink, two `TYPE_PCIE` subnodes temporarily set to `TYPE_PCIE_ML` must be restored to `TYPE_PCIE` before returning. Every `link_cmn_vals_tbl` entry must have `num_regs >= 1` with `PHY_PLL_CFG` at `reg_pairs[0]`. [F48, F62, F74]
- In `cdns_torrent_phy`, `base`, `regmap_dptx_phy_reg`, and `phy_reset_ctrl` are only initialized when a subnode has `phy_type == TYPE_DP`. `cdns_torrent_dp_get_pll()` must populate `cdns_phy->dp_pll` (`DP_PLL0`/`DP_PLL1`) before `cdns_torrent_dp_common_init()`, `cdns_torrent_dp_pma_cmn_vco_cfg_100mhz()`, `cdns_torrent_dp_pma_cmn_rate()`, or `cdns_torrent_dp_configure_rate()`, which must only touch/poll PLL0/PLL1 regs set in `cdns_phy->dp_pll`. [F31, F42, F51]
- In `phy-cadence-torrent.c`, `inst->mlane + inst->num_lanes` (and `+ dp->lanes`) must not exceed `MAX_NUM_LANES` (4). In `cdns_torrent_dp_set_lanes()`, the first `PHY_RESET` loop before `cdns_torrent_dp_set_a0_pll()` must start at `i = 1` (keeping master lane `clane + 0` in reset) before the `i = 0` loop releases all lanes. [F77, F92]
- In `cdns_torrent_dp_set_rate`, `cdns_torrent_dp_configure_rate` requires lanes in `POWERSTATE_A3` (`cdns_torrent_dp_set_power_state`) and PLL clocks disabled (`cdns_torrent_dp_set_pll_en`), and must disable `cdns_phy->dp_pll` in `phy_pma_pll_raw_ctrl` before VCO changes. In `cdns_torrent_dp_set_voltages`, `TX_DIAG_ACYA_HBDC_MASK` on `inst->mlane + lane` must bracket writes to `TX_TXCC_CTRL`, `DRV_DIAG_TX_DRV`, `TX_TXCC_MGNFS_MULT_000`, and `TX_TXCC_CPOST_MULT_00`. [F52, F53]
- In `phy-fsl-imx8-mipi-dphy.c`, `lvds_regmap`/`ipc_handle` exist only when `devdata->is_combo` is true (`MIXEL_IMX8QXP`), while `reg_tx_rcal`/`reg_auto_pd_en`/`reg_rxlprp`/`reg_rxcdrp`/`reg_rxhs_settle` exist only when `is_combo` is false (`MIXEL_IMX8MQ`). `mixel_dphy_configure_lvds_phy` must set `priv->is_slave = opts->lvds.is_slave` alongside `IMX_SC_C_DUAL_MODE`, and `mixel_dphy_power_on_lvds_phy` must skip `DPHY_LOCK` polling when `priv->is_slave` is true. [F29, F54]
- In `phy-fsl-imx8-mipi-dphy.c`, `mixel_dphy_configure_mipi_dphy` and `mixel_dphy_validate` must pass a stack-local `mixel_dphy_cfg` to `mixel_dphy_config_from_opts`, copying to `priv->cfg` only in `configure` after validation. In `get_best_ratio()`, when `n[i] > max_n || d[i] > max_d` inside `while (b)`, `i ^= 1` must precede `break`. [F55, F81]
- In `imx8_pcie_phy_power_on()` (`phy-fsl-imx8m-pcie.c`), write `AUX_PLL_REFCLK_SEL_SYS_PLL` to `IMX8MM_PCIE_PHY_CMN_REG063` only when `drvdata->variant != IMX8MM`, and keep the `IMX8_PCIE_REFCLK_PAD_INPUT || IMX8_PCIE_REFCLK_PAD_UNUSED` and `IMX8_PCIE_REFCLK_PAD_OUTPUT || IMX8_PCIE_REFCLK_PAD_UNUSED` checks as separate `if`s so `UNUSED` runs both. [F83, F111]
- In `phy-fsl-imx8mq-usb.c`, `imx8m_get_phy_tuning_data()` branches on `device_is_compatible(dev, "fsl,imx95-usb-phy")`, `phy_tx_vboost_level_from_property()` maps `1156`/`844`/default uV to `5`/`3`/`4`, and `imx8m_phy_tune()` relies on `PHY_TUNE_DEFAULT == 0xffffffff` for its bitwise-AND untuned check. [F82, F114]
- In `phy-fsl-imx8qm-hsio.c`, PCIe clock arrays (`lan0_pcie_clks`, `lan1_pciea_clks`, `lan1_pcieb_clks`, `lan2_pcieb_clks`) must have `LANE_NUM_CLKS` (5) entries with `apb_pclk*` at index 0. In `phy-fsl-imx8qm-lvds-phy.c`, `PHY_NUM` must be 2 and `lvds_phy->id` in `{0, 1}` for `priv->phys[lvds_phy->id ^ 1]` companion lookups. [F68, F70]
- In `fsl_samsung_hdmi_phy`, `cur_cfg` is NULL until `fsl_samsung_hdmi_phy_configure()`, so `phy_clk_recalc_rate()` and `fsl_samsung_hdmi_phy_resume()` must null-check it. `fsl_samsung_hdmi_calculate_phy` only writes `pixclk` and `pll_div_regs[0..2]` on `calculated_phy_pll_cfg` (keeping `pll_div_regs[3..6]` at `{0x00, 0x00, 0x80, 0x00}`), with `s - 1` in `REG03_PMS_S_MASK` (`GENMASK(7, 4)`) of `pll_div_regs[2]`. [F33, F66, F142]
- `fsl_samsung_hdmi_phy_configure()` must use 8-bit `writeb()`/`readb_poll_timeout()` at 4-byte `PHY_REG(reg)` offsets, set `phy->cur_cfg = cfg`, mirror `cfg->pll_div_regs[2] >> 4` into `REG21_PMS_S_MASK` of `PHY_REG(21)`, and write `REG33_FIX_DA | REG33_MODE_SET_DONE` to `PHY_REG(33)` after `fsl_samsung_hdmi_phy_configure_pll_lock_det` and before polling `PHY_REG(34)` for `REG34_PLL_LOCK`. [F59, F118]
- In `fsl_samsung_hdmi_phy_find_pms()`, widen `fout` and `_m` to `u64` with `do_div()`/`div64_ul()` and check `tmp <= 255` before assigning `_m`. In `fsl_samsung_hdmi_phy_configure_pll_lock_det()`, divide `int_pllclk` below `50 * MHZ` (returning `-EINVAL` if `div == 4` before `FIELD_PREP(REG12_CK_DIV_MASK, div)`) and compute `fld_tg_code` with `DIV_ROUND_UP(24 * MHZ * 256, int_pllclk)`. [F65, F89, F90]

## Synchronization

- In `phy-cadence-sierra.c` and `phy-cadence-torrent.c`, `cdns_sierra_common_cdb_config`, `cdns_torrent_common_cdb_config`, and `cdns_torrent_phy_pcs_cmn_cdb_config` must set `.fast_io = true`. `cdns_torrent_clk_register` must register `derived_refclk` and `received_refclk` before `cdns_torrent_refclk_driver_register` and `of_clk_add_hw_provider`. Subnode setup, `nsubnodes`, and `configure_multilink` must finish before `devm_of_phy_provider_register`. [F18, F19, F21]
- In `phy-fsl-imx8mq-usb.c`, `tca_blk_orientation_set` must hold `tca->mutex`, set `TCA_SYSMODE_TCPC_DISABLE` in `TCA_SYSMODE_CFG` before changing `TCA_SYSMODE_TCPC_FLIP`, program `TCA_GCFG`/`TCA_TCPC`, and update `tca->orientation`. `tca_blk_init` must not hold `tca->mutex` when calling `tca_blk_orientation_set` to restore `tca->orientation` after `TCA_CLK_RST_SW`, and `tca_blk_typec_switch_set()` must enable `imx_phy->clk` around it. [F16, F58, F113]
- In `phy-fsl-imx8qm-lvds-phy.c`, `mixel_lvds_phy_probe` must call `mutex_init(&priv->lock)` and `dev_set_drvdata` before `pm_runtime_enable` and `mixel_lvds_phy_reset` (which must not hold `priv->lock` across `pm_runtime_resume_and_get`/`put`), and populate `priv->phys[i]` before `devm_of_phy_provider_register`. `mixel_lvds_phy_validate` caches `opts->lvds` in `lvds_phy->cfg` under `priv->lock`; `mixel_lvds_phy_power_on`/`off` return 0 for slaves while the master under `priv->lock` toggles `phy_ref_clk` and `CH_EN(0) | CH_EN(1)`. [F13, F14, F57, F117]

## Object Lifetimes

- In `cdns_dphy_probe`, errors after `dphy->ops->probe(dphy)` must call `dphy->ops->remove(dphy)` if non-NULL. `cdns_dphy_power_on` must enable `psm_clk` and `pll_ref_clk` before hardware writes and disable them in reverse order on error before `dphy->is_powered = true`. [F1, F2]
- In `cdns_sierra_phy_probe`, `sp->phys[node].lnk_rst` (`of_reset_control_array_get_exclusive`) must be freed via `reset_control_put` for both the failing `node` and `0 .. node-1` on error, and in `remove`. Clock providers from `of_clk_add_hw_provider` in Sierra, Torrent, and `phy-fsl-samsung-hdmi.c` must call `of_clk_del_provider` in `.remove` and on probe error. [F3, F8]
- In `cdns_torrent_phy_suspend_noirq`, if `cdns_phy->already_configured` is non-zero, clear it to 0 without calling `clk_disable_unprepare` on `clk1`/`clk` so resume/suspend clock counts stay balanced. [F6]
- In `phy-fsl-imx8qm-hsio.c`, `imx_hsio_power_on`/`off` must update `priv->open_cnt` under `priv->lock`, configuring shared `HSIO_CTRL0` in `priv->misc` only on `0 -> 1` and asserting shared resets only on `1 -> 0`. In `phy-fsl-samsung-hdmi.c`, `fsl_samsung_hdmi_phy_resume()` must enable `phy->apbclk` before re-applying `phy->cur_cfg`. [F10, F119]

## API Contracts

- In `cdns-dphy.c`, `cdns_dphy_config_from_opts()` must divide `cdns_dphy_get_wakeup_time_ns(dphy)` by 1000 for `opts->wakeup` (us). `cdns_dphy_validate` must not mutate `dphy->cfg`; `cdns_dphy_configure` only updates `dphy->cfg` and `dphy->is_configured = true`; and `cdns_dphy_power_on` requires `dphy->is_configured && !dphy->is_powered`, programming PLLs and polling lock/ready after enabling clocks and `DPHY_CMN_SSM_EN`. In `cdns_dphy_rx_get_band_ctrl`, multiply `hs_clk_rate / 1000000UL` by `2` before matching `bands[]`. [F41, F43, F98, F128]
- In Sierra, Torrent, and `phy-fsl-imx8qm-lvds-phy.c`, `phy_set_drvdata()` stores the per-link instance while `dev_set_drvdata()` on `phy->dev.parent` stores controller state. Sierra/Torrent CDB regmaps shift offsets by `reg_offset_shift` (16-bit), whereas Torrent's DPTX regmap uses unshifted byte offsets (32-bit). [F35, F96]
- `cdns_torrent_dp_verify_config` must check `dp->voltage[i] <= 3`, `dp->pre[i] <= 3`, and `voltage[i] + pre[i] <= 3` before `cdns_torrent_dp_set_voltages` indexes `vltg_coeff`. `cdns_torrent_received_refclk_is_enabled` must return `val && !cmn_val` because `derived_refclk_enable` sets both `cmn_cdiag_refclk_ovrd_4` and `phy_pipe_cmn_ctrl1_0`. [F63, F140]
- In `phy-fsl-imx8-mipi-dphy.c`, `phy_set_mode()` must precede `phy_configure()`/`phy_power_on()`, and `cm` (`16..255`), `cn` (`1..32`), and `co` (`{1, 2, 4, 8}`) must be validated before `CM()`, `CN()`, and `CO()`. [F67, F132]
- In `phy-fsl-imx8m-pcie.c`, `imx8_phy->clk` enable/disable belongs in `init`/`exit`, while `power_on` deasserts `perst` and `reset` before setting `IMX8MM_GPR_PCIE_CMN_RST` and polling `IMX8MM_PCIE_PHY_CMN_REG075` (`power_off` re-asserts both). [F112, F126]
- In `phy-fsl-imx8qm-hsio.c`, `imx_hsio_xlate` must check `0 <= idx < priv->drvdata->lane_num` (`<= MAX_NUM_LANE`); `phy_init()` must precede `set_mode`, `set_speed`, or `power_on`; and `imx_hsio_set_speed` treats `speed` as a boolean for `HSIO_LTSSM_ENABLE`. In `phy-fsl-samsung-hdmi.c`, callers of `fsl_samsung_hdmi_phy_lookup_rate` must ensure `rate >= phy_pll_cfg[0].pixclk` (`22250000`) with `phy_pll_cfg` sorted ascending. [F64, F69, F134, F135]

## Error Handling

- Store `cdns_dphy_rx_get_band_ctrl()` and `cdns_dphy_tx_get_band_ctrl()` returns in a signed `int` and test `< 0` (band `0` is valid; error is `-EOPNOTSUPP`). Null-check `cdns_sierra_data` and `cdns_torrent_get_tbl_vals()` pointers before reading `reg_pairs`/`num_regs`. [F22, F32]
- In `cdns_sierra_phy_probe()` and `cdns_torrent_phy_probe()`, set negative `ret` before jumping to cleanup labels after `ret = 0`. In `cdns_torrent_phy_probe()`, child-loop errors before `of_reset_control_array_get_exclusive()` jump to `put_lnk_rst`, and after it to `put_child`. In `cdns_torrent_refclk_driver_register()`, `IS_ERR_OR_NULL(hw)` must return `IS_ERR(hw) ? PTR_ERR(hw) : -ENOENT`. [F24, F26, F27]

## Known Pitfalls

- In `cdns_dphy_power_on()`, update `DPHY_CMN_SSM` via read-modify-write preserving `DPHY_CMN_SSM_CAL_WAIT_TIME`. In `phy-cadence-sierra.c`, `cdns_sierra_pll_mux_get_parent()`/`set_parent()` must test `strstr(..., clk_names[CDNS_SIERRA_PLL_CMNLC1])` before `CDNS_SIERRA_PLL_CMNLC`. In `phy-cadence-torrent.c`, `CDNS_TORRENT_KEY` uses 3-bit masks (`0..7`), and `enum cdns_torrent_phy_type` is already at `7` (`TYPE_PCIE_ML`). [F85, F97, F99]
- In `mixel_dphy_config_from_opts()`, check `hs_prepare < lp_t` and `clk_prepare < lp_t` before unsigned subtraction. In `imx_hsio_pcie_power_on()`, toggle `lane->clks[0].clk` off, `mdelay(1)`, and on after `imx_hsio_pcie_phy_resets()` before polling `HSIO_PCIE_STS0`. In `phy-fsl-samsung-hdmi.c`, `if (_s > 1 && (_s & 0x01) == 1) _s++;` must precede `if (_s == 14) continue;` in `fsl_samsung_hdmi_phy_find_pms()`, and `rate`/`pixclk` must be cast to `long` inside `abs()`. [F79, F88, F91, F116]
