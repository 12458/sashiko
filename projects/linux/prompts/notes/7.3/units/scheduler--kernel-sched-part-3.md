# SCHEDULER — kernel/sched (part 3)

Implements the EEVDF Completely Fair Scheduler class (`fair.c`)—including hierarchical cgroup scheduling, CFS bandwidth throttling, and SMP/NUMA/EAS load balancing—along with scheduler feature flags (`features.h`), the CPU idle loop and `idle_sched_class` (`idle.c`), and CPU isolation/housekeeping cpumask management (`isolation.c`) for `isolcpus` and `nohz_full`.

## Architecture & Data Flow
- `rq->leaf_cfs_rq_list` maintains bottom-up child-before-parent order via `rq->tmp_alone_branch`: callers of `list_add_leaf_cfs_rq()` (`enqueue_task_fair()`, `unthrottle_cfs_rq()`) must walk ancestors until it returns true (`rq->tmp_alone_branch == &rq->leaf_cfs_rq_list`, `assert_list_leaf_cfs_rq`); iteration must use `for_each_leaf_cfs_rq_safe()` and unlink decayed entries via `list_del_leaf_cfs_rq()`, which steps `tmp_alone_branch` back to `prev` if it points to `&cfs_rq->leaf_cfs_rq_list`; `child_cfs_rq_on_list()` must verify `prev != &rq->leaf_cfs_rq_list` before `container_of()`. [F201, F262, F286, F314]
- In `__pick_eevdf()`, the augmented rbtree traversal must check whether `node->rb_left` is non-NULL and has an eligible subtree minimum (`vruntime_eligible(cfs_rq, __node_2_se(left)->min_vruntime)`) and descend left before testing `entity_eligible(cfs_rq, se)` on the current node or descending right. [F284]
- `se->custom_slice` marks entities with an explicitly configured `se->slice` (via `__setparam_fair()` with `attr->sched_runtime` or `enqueue_task_fair()` for group entities); `place_entity()` and `update_deadline()` must overwrite `se->slice` with `sysctl_sched_base_slice` only when `!se->custom_slice`. [F270]
- Whenever `struct load_weight::weight` is modified (`se->load.weight` or `cfs_rq->load.weight`), `load_weight::inv_weight` must be reset to `0` (as in `update_load_add()`, `update_load_sub()`, `update_load_set()`) or updated in lockstep (as in `reweight_task_fair()`), because `__update_inv_weight()` skips recomputation when `inv_weight` is non-zero. [F251]
- Delayed-dequeued tasks (`se->sched_delayed == 1`) have decremented `cfs_rq->h_nr_runnable` via `set_delayed()` while remaining counted in `cfs_rq->h_nr_queued` and `rq->nr_running`; checks for actually running/runnable tasks on `rq` (e.g., `wake_affine_idle()`) must subtract `cfs_h_nr_delayed(rq)` from `rq->nr_running`. [F256]
- When PELT sums on `cfs_rq->avg` are reduced or propagated (`dequeue_load_avg()`, `update_cfs_rq_load_avg()`), `sub_positive()` / `add_positive()` must clamp underflow to `0` and `*_sum` must be clamped to at least `*_avg * PELT_MIN_DIVIDER` so `load_avg_is_decayed()` never sees a zero `*_sum` with a non-zero `*_avg`. [F307]
- Both `p->sched_throttle_work` and `p->numa_work` use a self-pointing `work.next == &work` sentinel when unqueued, which `init_cfs_throttle_work()`, `throttle_cfs_rq_work()`, `init_numa_balancing()`, and `task_numa_work()` must initialize and reset before checking or re-adding; in `throttle_cfs_rq_work()`, `dequeue_task_fair(rq, p, DEQUEUE_SLEEP | DEQUEUE_THROTTLE)` must be called after resetting `next` and before setting `p->throttled = true`, or `dequeue_task_fair()` diverts to `dequeue_throttled_task()`. [F246, F271]
- `init_sd_lb_stats()` must initialize `sds->busiest_stat.idle_cpus = UINT_MAX` and `sds->busiest_stat.group_type = group_has_spare` before `update_sd_lb_stats()`, because `update_sd_pick_busiest()` compares against `sds->busiest_stat` before `sds->busiest` is assigned; in `group_classify()`, `sgs->group_type` predicates must be evaluated in decreasing pull-priority order (`group_overloaded` down to `group_has_spare`), matching the ascending `enum group_type` order compared in `update_sd_pick_busiest()` and `update_pick_idlest()`. [F245, F298]
- In `detach_tasks()`, while scanning `env->src_rq->cfs_tasks` from tail (`list_last_entry`), every rejected task must jump to `next:` to be rotated to the list head with `list_move(&p->se.group_node, tasks)` (never `continue`), and under `migrate_load` the subtracted load from `env->imbalance` must be `max_t(unsigned long, task_h_load(p), 1)`. [F287]
- In `sched_balance_rq()`, retrying on `LBF_DST_PINNED` (`goto more_balance`) or `LBF_ALL_PINNED` (`goto redo`) must clear the rejected CPU (`env.dst_cpu` or `cpu_of(busiest)`) from `env.cpus` and reset `env.loop = 0` and `env.loop_break = SCHED_NR_MIGRATE_BREAK`, whereas `LBF_NEED_BREAK` must preserve `env.loop` and `env.loop_break`. [F288]
- In `task_numa_work()`, the VMA scanner must skip read-only file-backed mappings (`vma->vm_file && (vma->vm_flags & (VM_READ|VM_WRITE)) == VM_READ`), special mappings (`!vma->vm_mm`), and inaccessible VMAs (`!vma_is_accessible(vma)`) before `change_prot_numa()`; when skipping a VMA because `vma->numab_state->prev_scan_seq == mm->numa_scan_seq`, it must advance `mm->numa_scan_offset = vma->vm_end` before `continue`, and at `out:` call `reset_ptenuma_scan(p)` whenever `vma == NULL`. [F294, F354]
- `task_numa_fault()` must return immediately when `!current->mm` so kernel threads temporarily faulting in a user `mm` (e.g., `ksmd`) do not allocate or record `numa_faults`; it sizes `p->numa_faults` for `NR_NUMA_HINT_FAULT_BUCKETS * nr_node_ids` elements, whereas `task_numa_group()` sizes `grp->faults[]` for `NR_NUMA_HINT_FAULT_STATS * nr_node_ids` (`NUMA_MEM` and `NUMA_CPU` only), so `grp->faults[]` must never be indexed with `NUMA_MEMBUF` or `NUMA_CPUBUF`. [F317, F357]
- In `should_numa_migrate_memory()`, when `folio_use_access_time(folio)` is true, every path that returns `true` must account `folio_nr_pages(folio)` in the target `pgdat`'s promotion candidate stats via `mod_node_page_state()` (`PGPROMOTE_CANDIDATE_NRL` on the `pgdat_free_space_enough()` fast path, or `PGPROMOTE_CANDIDATE` in `numa_promotion_rate_limit()`). [F264]
- In `do_idle()`, `__current_set_polling()` and `tick_nohz_idle_enter()` before the idle loop must be paired with `tick_nohz_idle_exit()`, `__current_clr_polling()`, and `smp_mb__after_atomic()` before `flush_smp_call_function_queue()` and `schedule_idle()`, and `cpuidle_idle_call()` must restore `__current_set_polling()` on `exit_idle`. [F208]
- In `housekeeping_setup()`, if the complement of the parsed `non_housekeeping_mask` contains no CPU in `cpu_present_mask` with ID below both `nr_cpu_ids` and `setup_max_cpus`, `smp_processor_id()` must be forced into `housekeeping_staging` and cleared from `non_housekeeping_mask`. [F278]

## Synchronization
- In CFS bandwidth control, `rq->__lock` nests outside `cfs_b->lock`: `throttle_cfs_rq()`, `unthrottle_cfs_rq()`, and `distribute_cfs_runtime()` acquire `cfs_b->lock` under `rq->__lock`, whereas `do_sched_cfs_period_timer()` and `do_sched_cfs_slack_timer()` must release `cfs_b->lock` before calling `distribute_cfs_runtime()`; conversely, `runtime_refresh_within()` and `start_cfs_slack_bandwidth()` require `cfs_b->lock` held so `hrtimer_expires_remaining(&cfs_b->period_timer)` cannot race with `hrtimer_start()` clearing the timer base. [F327, F330]
- In `throttle_cfs_rq_work()`, after acquiring `task_rq_lock(p)`, the callback must revalidate that `p->sched_class == &fair_sched_class` and `cfs_rq->throttle_count != 0` before dequeuing `p` and adding `p->throttle_node` to `cfs_rq->throttled_limbo_list`. [F219]
- `cfs_rq->removed.lock` is a raw spinlock shared between `remove_entity_load_avg()` (which may run without `rq->__lock` held, e.g., from `migrate_task_rq_fair()` under `p->pi_lock` or `task_dead_fair()`, and must use `raw_spin_lock_irqsave()`) and `update_cfs_rq_load_avg()` (which runs under `rq->__lock` with IRQs disabled and uses `raw_spin_lock()`). Broken by: acquiring `cfs_rq->removed.lock` without disabling IRQs when `rq->__lock` is not held, or acquiring `rq->__lock` under `cfs_rq->removed.lock`. [F328]
- In `update_cfs_rq_load_avg()`, after `__update_load_avg_cfs_rq(now, cfs_rq)` updates `cfs_rq->avg.last_update_time`, `u64_u32_store_copy()` must update `cfs_rq->last_update_time_copy` in lockstep, and lockless readers must use `cfs_rq_last_update_time(cfs_rq)` (`u64_u32_load_copy()`); in `migrate_se_pelt_lag()`, locklessly reading a remote idle CPU's PELT clocks requires `u64_u32_load(rq->clock_pelt_idle)`, `smp_rmb()` (paired with `_update_idle_rq_clock_pelt()`), and then `cfs_rq_last_update_time(cfs_rq)` and `u64_u32_load(rq->clock_idle)`. [F261, F343]
- `select_task_rq_fair()` requires `p->pi_lock` held (`lockdep_assert_held(&p->pi_lock)`), and `select_idle_sibling()` (along with `select_idle_cpu()`, `select_idle_capacity()`, and `find_energy_efficient_cpu()`) requires IRQs disabled (`lockdep_assert_irqs_disabled()`) and `rcu_read_lock()` when using per-CPU `select_rq_mask` and `sched_domain` pointers. [F336]
- In `kick_ilb()`, cross-CPU access to `cpu_rq(ilb_cpu)->nohz_csd` is serialized by `NOHZ_KICK_MASK` in `nohz_flags(ilb_cpu)`: `smp_call_function_single_async()` must only be invoked when `atomic_fetch_or(flags, nohz_flags(ilb_cpu))` returns a value with no `NOHZ_KICK_MASK` bits previously set. [F341]
- Dereferencing `p->numa_group` via `deref_task_numa_group()` requires either `p == current` (`deref_curr_numa_group()`), an RCU read-side critical section, or holding `task_rq(p)->__lock` while `!READ_ONCE(p->on_cpu)`. [F212]
- `task_tick_fair()` and `task_tick_idle()` (and callees `entity_tick()`, `task_tick_numa()`, `task_tick_core()`) can be invoked remotely from the `nohz_full` tick offload CPU and must access all runqueue and task state through their `@rq` and `@curr` arguments rather than `this_rq()`, `smp_processor_id()`, or `current`. [F326]
- `cpu_idle_poll()` and `default_idle_call()` are marked `__cpuidle` (`noinstr` section) and must bracket tracepoints and RCU-visible calls with `instrumentation_begin()`/`instrumentation_end()`, and wrap the idle wait (`arch_cpu_idle()` or the `cpu_relax()` loop) inside `ct_cpuidle_enter()`/`ct_cpuidle_exit()` with critical timings stopped. [F322]

## Object Lifetimes
- In `sched_balance_rq()` and `active_load_balance_cpu_stop()`, `detach_task()` / `detach_tasks()` / `detach_one_task()` must call `deactivate_task(env->src_rq, p, DEQUEUE_NOCLOCK)` (`TASK_ON_RQ_MIGRATING`) and `set_task_cpu(p, env->dst_cpu)` under `src_rq->__lock`, and every detached task must be attached via `attach_tasks(&env)` or `attach_one_task(target_rq, p)` after dropping `src_rq->__lock`; `sched_balance_rq()` may queue `busiest->active_balance_work` via `stop_one_cpu_nowait()` only when transitioning `busiest->active_balance` from `0` to `1` under `busiest->__lock`, and `active_load_balance_cpu_stop()` must clear `busiest_rq->active_balance = 0` under `busiest_rq->__lock` on every exit path. [F195, F196, F225, F226]
- When `task_numa_group()` switches `p->numa_group` from `my_grp` to `grp`, it must acquire `get_numa_group(grp)` under `rcu_read_lock()`, transfer `p->numa_faults`, `p->total_numa_faults`, and `nr_tasks` under `double_lock_irq(&my_grp->lock, &grp->lock)`, assign `p->numa_group`, and call `put_numa_group(my_grp)`; in `task_numa_free(p, final)`, `p->numa_faults` and `p->total_numa_faults` must be subtracted from `grp->faults` and `grp->total_faults` under `grp->lock` before clearing `p->numa_group` and calling `put_numa_group(grp)`, and `p->numa_faults` must only be `kfree()`d when `final` is true (zeroed in place when false). [F202, F203]
- In `task_numa_work()`, `(p->flags & PF_EXITING)` must be checked before dereferencing `p->mm`, and `work->next = work` must be restored before any return so `p->numa_work` is marked unqueued. [F266]
- In `play_idle_precise()`, `preempt_disable()`, `current->flags |= PF_IDLE`, and `cpuidle_use_deepest_state(latency_ns)` must be restored in reverse order (`cpuidle_use_deepest_state(0)`, `current->flags &= ~PF_IDLE`, `preempt_fold_need_resched()`, `preempt_enable()`) after the `while (!READ_ONCE(it.done))` loop completes. [F207]

## API Contracts
- Callers of `task_of(se)` must first verify `entity_is_task(se)` (`!se->my_q`), or descend `group_cfs_rq(se)` until NULL, because non-task `sched_entity` instances are embedded in `struct sched_entity_stats` rather than `struct task_struct`. [F233]
- Callers of `attach_entity_load_avg(cfs_rq, se)` and `detach_entity_load_avg(cfs_rq, se)` must call `update_cfs_rq_load_avg()` (e.g., via `update_load_avg()`) on `@cfs_rq` first so `cfs_rq->avg.last_update_time` and `cfs_rq->avg.period_contrib` are current. [F249]
- `util_fits_cpu(util, uclamp_min, uclamp_max, cpu)` (and `task_fits_cpu()`) returns a tri-state `int`: `1` when all requirements fit, `0` when capacity does not fit, and `-1` when capacity fits but `uclamp_min` exceeds `get_actual_cpu_capacity(cpu)`; callers requiring a full fit must check `util_fits_cpu(...) > 0`, not boolean truth. [F236]
- `__select_idle_cpu()`, `select_idle_core()`, `select_idle_smt()`, `select_idle_cpu()`, `select_idle_capacity()`, `find_energy_efficient_cpu()`, and `find_new_ilb()` return `-1` on failure, whereas `wake_affine_idle()` and `wake_affine_weight()` return `nr_cpumask_bits`; callers must check `(unsigned int)cpu < nr_cpumask_bits` or `cpu >= 0` accordingly. [F239]
- `play_idle_precise()` must only be called from a non-sleeping context (`rcu_sleep_check()`) by a per-CPU `SCHED_FIFO` kernel thread (`PF_KTHREAD | PF_NO_SETAFFINITY`, `nr_cpus_allowed == 1`, `!current->mm`) with a non-zero `duration_ns`, using `HRTIMER_MODE_REL_HARD` / `HRTIMER_MODE_REL_PINNED_HARD` for its stack `idle_timer`. [F325]
- `sysctl_sched_cfs_bandwidth_slice` (`kernel.sched_cfs_bandwidth_slice_us`) is in microseconds and must be converted to nanoseconds via `sched_cfs_bandwidth_slice()` (`(u64)sysctl_sched_cfs_bandwidth_slice * NSEC_PER_USEC`) before comparing or adding to `cfs_b->runtime` or `cfs_rq->runtime_remaining`; similarly, 32-bit `curr->numa_scan_period` in `task_tick_numa()` must be widened to `u64` before multiplying by `NSEC_PER_MSEC`. [F313, F348]
- `sysctl_numa_balancing_scan_size` and `sysctl_numa_balancing_promote_rate_limit` (`kernel.numa_balancing_promote_rate_limit_MBps`) are stored in megabytes and must be converted to page counts via `MB_TO_PAGES()` (or `<< (20 - PAGE_SHIFT)`) before bounding page scans or comparing against `PGPROMOTE_CANDIDATE` page counters. [F349]

## Error Handling
- `task_numa_assign()` sets `rq->numa_migrate_on = 1` on `env->best_cpu` and takes a ref on `env->best_task` via `get_task_struct()`, so both `task_numa_assign()` when replacing a candidate and `task_numa_migrate()` on every exit path after `task_numa_find_cpu()` sets `env.best_cpu != -1` must clear `numa_migrate_on = 0` and call `put_task_struct(env.best_task)`. [F244]

## Known Pitfalls
- Hierarchical load calculations in `update_cfs_rq_h_load()` and `task_h_load()` must divide by `cfs_rq_load_avg(cfs_rq) + 1` using `div64_ul()`, and `rq->misfit_task_load` must clamp `task_h_load(p)` to at least `1` via `max_t(unsigned long, task_h_load(p), 1)`. [F312]
- In `numa_get_avg_runtime()` and `task_numa_placement()`, `*period` must be checked for `(s64)*period < 0` and clamped to `0`, and fault weight normalization `div64_u64(runtime << 16, period + 1)` must add `1` to `period` and `total_faults` before dividing. [F311]
- In `vma_is_accessed()`, the bit number passed to `test_bit(..., &pids)` on the single-word `unsigned long pids` stack variable (and `vma->numab_state->pids_active[]`) must be hashed to `ilog2(BITS_PER_LONG)` bits (`hash_32(current->pid, ilog2(BITS_PER_LONG))`) so the bit index stays within `[0, BITS_PER_LONG - 1]`. [F321]
- In `housekeeping_isolcpus_setup()`, each comma-delimited sub-parameter token starting at `par` is scanned in-place without writing a NUL terminator over the trailing comma, so log messages printing `par` must use `%.*s` bounded by `len`. [F320]
