# MEMORY MANAGEMENT - CORE — (top level) (part 1)

Core memory management public headers defining foundational types, page/folio descriptors, virtual memory areas, address space structures, NUMA zones, and allocation flags, with helpers for reference counting, page flags, highmem mapping, MMU notifiers, page table walks, and hotplug.

## Architecture & Data Flow

- `PG_waiters` must stay at bit 7 of `folio->flags` alongside `PG_locked`, and `folio_xor_flags_has_waiters()` only takes `mask` bits 0..6 under the folio lock (`xor_unlock_is_negative_byte()` tests bit 7 as sign). `FOLIO_SECOND_PAGE` flags (`PG_has_hwpoisoned`, `PG_large_rmappable`, `PG_partially_mapped`) must be in `PAGE_FLAGS_SECOND`, avoid bits 0..7 (`0xffUL`, used by `folio_large_order()` in `folio->_flags_1`), and use atomic `FOLIO_FLAG(..., FOLIO_SECOND_PAGE)` rather than `__FOLIO_SET/CLEAR_FLAG`. [F23, F98, F99]
- Page-flag masks (`ZONES_MASK`, `NODES_MASK`, `SECTIONS_MASK`, `LAST_CPUPID_MASK`, `KASAN_TAG_MASK`, `ZONEID_MASK`) must use `1UL` so narrow operands promote to `unsigned long` before `<< *_PGSHIFT`, and `*_PGSHIFT` must multiply `*_PGOFF` by `(*_WIDTH != 0)` (or `(ZONEID_SHIFT != 0)`) so zero-width fields shift by 0 instead of `BITS_PER_LONG`. [F131, F132]
- Each `mm_id_t` in `folio->_mm_id[0..1]` must fit in `MM_ID_BITS` (`<= MM_ID_MAX`), reserving the top bit of `_mm_id[0]` (`FOLIO_MM_IDS_LOCK_BITNUM`) and `_mm_id[1]` (`FOLIO_MM_IDS_SHARED_BITNUM`) in unioned `unsigned long _mm_ids`; in `folio_maybe_mapped_shared()`, small/hugetlb folios return `mapcount > 1` first, and large folios return `false` if `folio_mapcount(folio) <= 1` before testing `FOLIO_MM_IDS_SHARED_BITNUM`. [F93, F126]
- `page->pp_magic` (aliasing `page->lru.next` and `page->compound_head`) encodes `PP_SIGNATURE` while preserving bit 0 (`PageTail()`), bit 1 (`page_is_pfmemalloc()`), and `PP_DMA_INDEX_MASK`; `page_pool_page_is_pp()` must mask with `PP_MAGIC_MASK`, and `PP_DMA_INDEX_BITS` must stay below `__ffs(POISON_POINTER_DELTA)` (when `> 0`) or `__ffs(PAGE_OFFSET)` (when constant and aligned to `PP_DMA_INDEX_MIN_OFFSET`, else `0`). [F84, F90]
- New `struct vm_area_struct` fields must be copied in `vm_area_init_from()`; changes to `___GFP_*_BIT` or `VM_*` flags must sync with `include/trace/events/mmflags.h` (and `tools/perf/builtin-kmem.c` for GFP), `enum migratetype` with `migratetype_names[]` (`mm/page_alloc.c`), `MM_*PAGES` with `resident_page_types[]` (`kernel/fork.c`), and 64-bit `sizeof(struct page)` in `[56, 96]` with `__mm_zero_struct_page()`. [F68, F81, F124]
- `enum lru_list` order (`LRU_INACTIVE_ANON..LRU_UNEVICTABLE`) must match `NR_ZONE_LRU_BASE`, `NR_LRU_BASE`, and `vmstat_text`, keeping `LRU_ACTIVE` (+1) and `LRU_FILE` (+2) offsets; `MEMCG_NR_GENS` must be `>= 3` so stale lockless `(seq - 1) % MEMCG_NR_GENS` never aliases young `(seq + 1) % MEMCG_NR_GENS`. [F106, F139]
- In `struct zone`, unusable-free watermark checks must subtract `nr_free_highatomic` (actual free pages in `MIGRATE_HIGHATOMIC` under `zone->lock`) rather than `nr_reserved_highatomic`, and free-page reads below `zone->percpu_drift_mark` must use `zone_page_state_snapshot()`. Under `CONFIG_NUMA_BALANCING`, promotions bypassing rate-limiting due to fast-tier free space must increment `PGPROMOTE_CANDIDATE_NRL`, not `PGPROMOTE_CANDIDATE`. [F78, F79]
- In `gfp_zone()`, at most one of `__GFP_DMA`, `__GFP_DMA32`, and `__GFP_HIGHMEM` may be set (`GFP_ZONE_BAD`), and `__GFP_MOVABLE` selects `ZONE_MOVABLE` only with `__GFP_HIGHMEM`. In `enum fault_flag`, `!(flags & FAULT_FLAG_ALLOW_RETRY) && (flags & FAULT_FLAG_TRIED)` and `(flags & FAULT_FLAG_WRITE) && (flags & FAULT_FLAG_UNSHARE)` are illegal; retries setting `FAULT_FLAG_TRIED` must keep `FAULT_FLAG_ALLOW_RETRY` if retries remain allowed. [F83, F113]
- `vm_start_gap(vma)` and `vm_end_gap(vma)` must clamp `vma->vm_start - stack_guard_start_gap(vma)` to `0` on underflow and `vma->vm_end + stack_guard_gap` to `-PAGE_SIZE` on overflow. `struct mem_section` must keep a power-of-two size `<= PAGE_SIZE`, `NR_SECTION_ROOTS` must use `DIV_ROUND_UP(NR_MEM_SECTIONS, SECTIONS_PER_ROOT)`, and `next_valid_pfn()` only calls `first_valid_pfn()` at section (or `CONFIG_SPARSEMEM_VMEMMAP` subsection) boundaries. [F110, F122, F137]

## Synchronization

- Lockless `page_folio(page)` can race with folio split; after `folio_try_get(folio)`, callers must recheck `page_folio(page) == folio`. [F36]
- `pte_offset_map()` and `pte_offset_map_lock()` enter an RCU read-side critical section; callers (`pte_unmap_unlock()`, `folio_walk_end()`) must not sleep while mapped and must `spin_unlock(ptl)` before `pte_unmap()`. `folio_needs_cow_for_dma(vma, folio)` requires holding `ptl` inside `write_seqcount_begin(&vma->vm_mm->write_protect_seq)`. [F35, F167]
- `vma->vm_lock_seq` is only written (`WRITE_ONCE()`) while holding both write `mmap_lock` and the VMA lock (`VMA_LOCK_OFFSET`); `mm->mm_lock_seq` is updated under write `mmap_lock` with RELEASE and read outside it with ACQUIRE. Updating `mm->owner` requires `current == mm->owner`, `current->mm != mm`, `new_owner->mm == mm`, and `task_lock(new_owner)` (`new_owner->alloc_lock`). [F38, F39]
- `pgdat->node_size_lock` (`pgdat_resize_lock()`) protects `node_start_pfn`, `node_present_pages`, `node_spanned_pages`, `nr_zones`, and `first_deferred_pfn`, and nests above `zone->lock` and `zone->span_seqlock` (which protects `zone_start_pfn` and `spanned_pages`). [F34]
- Per-page KASAN tags in `page->flags.f` are stored XORed with `0xff` and updated in `page_kasan_tag_set()` via `READ_ONCE(page->flags.f)` + `try_cmpxchg()`. `gfpflags_allow_spinning()` checks `__GFP_RECLAIM` (`__GFP_DIRECT_RECLAIM | __GFP_KSWAPD_RECLAIM`), so `GFP_ATOMIC`/`GFP_NOWAIT` can spin on locks and are unsafe in NMI or `raw_spinlock_t` contexts (use `alloc_pages_nolock()`); `folio_put()`, `folio_put_refs()`, `folios_put()`, and `put_page()` are also forbidden in NMI context. [F88, F156, F169]

## Object Lifetimes

- `folio_release_kmap(folio, addr)` must call `kunmap_local(addr)` before `folio_put(folio)`. A non-NULL `folio_walk_start(fw, vma, ...)` returns a borrowed folio with `fw->ptl` locked, `fw->ptep` mapped if `fw->level == FW_LEVEL_PTE`, and VMA pgtable walk active; callers must clean up via `folio_walk_end(fw, vma)` (`spin_unlock(fw->ptl)`, conditional `pte_unmap(fw->ptep)`, `vma_pgtable_walk_end(vma)`) and take a reference before `folio_walk_end()` if retaining the folio. [F5, F7]
- `anon_vma_name(vma)` returns a borrowed pointer protected by `mmap_lock`; callers must hold `mmap_lock` and take a `kref` before unlocking to retain it. `release_fault_lock(vmf)` calls `vma_end_read(vmf->vma)` if `FAULT_FLAG_VMA_LOCK` is set or `mmap_read_unlock(vmf->vma->vm_mm)` otherwise; fault handlers must not call `mmap_read_unlock()` directly. In `mm_walk_ops::hugetlb_entry`, dropping and retaking the hugetlb VMA lock requires revalidating `pte` and `ptl`. [F13, F16, F21]
- Private users of `alloc_pages()` pages must keep bit 0 of the first union word (`page->compound_head` / `page->lru.next`) clear, restore `page->mapping` to `NULL` before freeing, and reset the low 16 bits of `page->page_type` to `0xffff` before clearing a page type. `FOLL_PIN` and `FOLL_GET` are mutually exclusive: never pass `FOLL_PIN` to `get_user_pages*()`, and always release `pin_user_pages*()` pages with `unpin_user_page*()` / `unpin_folio*()`, never `put_page()` / `folio_put()`. [F15, F190]

## API Contracts

- `folios_put()` and `folio_batch_release()` consume all references and empty `struct folio_batch`, but batches that may contain exceptional (shadow/swap/DAX) entries must call `folio_batch_remove_exceptionals()` first. [F19]
- In `struct vm_operations_struct`, `set_policy` must reference any non-NULL `@new` `struct mempolicy` it retains; `get_policy` must call `mpol_get()` only if the policy at `(vma, addr)` is `MPOL_SHARED` (returning `NULL` if none); `mprotect` must only validate permissions without mutating `vma`. In `struct vm_special_mapping`, if `.fault == NULL`, `.pages` must be a non-NULL, `NULL`-terminated `struct page *` array. [F12, F102, F180]
- `struct vm_area_struct` uses exclusive `vm_end` (`[vm_start, vm_end)`), whereas `mm->mm_mt` indexes inclusive `[vm_start, vm_end - 1]`, so VMA iterator helpers (`vma_find`, `vma_iter_clear_gfp`, `vma_iter_bulk_store`) must pass `end - 1` to `mas_*` primitives. [F95]
- `mm_walk_ops::test_walk` returns `0` to walk the VMA, `1` to skip it, or `< 0` to abort, and is not called by `walk_page_vma()`. `mmu_notifier_ops` whose `invalidate_range_start` can return `-EAGAIN` when `!mmu_notifier_range_blockable(range)` must not implement `invalidate_range_end`, and callers of `mmu_notifier_invalidate_range_start_nonblock()` must not modify PTEs on non-zero return. [F27, F46]
- `page_mapcount_is_type()` expects biased `page->_mapcount + 1`; callers inspecting unbiased `page->page_type` or raw `page->_mapcount` must use `page_type_has_type()` or `page_has_type()`. `Set/Clear/__ClearPageAnonExclusive()` require the head page on HugeTLB pages (unlike `PageAnonExclusive()`) and `PageAnonNotKsm(page)`. `PG_writeback` has no unconditional set/clear helpers (`PF_NO_TAIL`); use `folio_start_writeback()`, `__folio_start_writeback()`, or `set_page_writeback()`. [F40, F63, F187]
- Callers of `compound_order(page)` or `page_size(page)` without a reference must validate the order before shifting (`1UL << order`), as lockless reads of `folio->_flags_1 & 0xff` can return up to 255. [F135]
- `kmap()` requires preemptible task context, whereas `kmap_local_page/folio()` work in any context and must be unmapped via `kunmap_local()` in LIFO order. `kmap_local_folio(folio, offset)` takes a byte offset and maps one `PAGE_SIZE` page when `folio_test_partial_kmap(folio)` is true (clamping access to `PAGE_SIZE - offset_in_page(offset)`), and `folio_zero_tail(folio, offset, kaddr)` remaps subpages so its return value—not `kaddr`—must be passed to `kunmap_local()`. [F51, F147, F159]
- `folio_zero_segment/segments()` and `zero_user_segment()` take an exclusive end byte offset, whereas `folio_zero_range()` and `memzero_page()` take a byte length. `copy_mc_user_highpage()` and `copy_mc_highpage()` return `0` or positive uncopied bytes on MCE (never negative errno). `page_frag_alloc_align()` takes a power-of-two `align` (and negates it), whereas `__page_frag_alloc_align()` takes a pre-negated `align_mask`. `get_user_page_vma_remote()` returns an `ERR_PTR` (never `NULL`) on error, leaving `*vmap` untouched, and rejects `FOLL_NOWAIT` with `ERR_PTR(-EINVAL)`. [F50, F52, F53, F59]
- `mm_flags_t` (`mm->flags`) is a 64-bit bitmap (`NUM_MM_FLAG_BITS == 64`): `mm_flags_test/set/clear/test_and_set/test_and_clear()` take a bit index (`MMF_*`), whereas `__mm_flags_get_word()`, `__mm_flags_set_word()`, and `__mm_flags_set_mask_bits_word()` take shifted masks (`MMF_*_MASK`) and only access the first `BITS_PER_LONG` word (dropping bits `>= 32` on 32-bit). [F64, F155]
- Under `CONFIG_HUGETLB_PMD_PAGE_TABLE_SHARING`, hugetlb PMD page table sharing must use `ptdesc->pt_share_count` (`ptdesc_pmd_pts_init/inc/dec()`, `ptdesc_pmd_is_shared()`) rather than `page_count()`. `folio_mk_pte/pmd/pud()` map normal refcounted folios without setting `*_mkspecial` (which must never be set on refcounted folios). [F66, F177]
- `page_ext` clients using `page_ext->flags` must set `.need_shared_flags = true` in `struct page_ext_operations`. `page_ext_lookup()` and `for_each_page_ext()` (`page_ext_iter_begin/next()`) require `rcu_read_lock()` (and `page_ext_get()` callers must not sleep before `page_ext_put()`), and multi-page PFN iteration must use `for_each_page_ext()` instead of `page_ext_next()` across `PAGES_PER_SECTION` boundaries. [F91, F165, F193]
- `pfn_valid(pfn)` must check both `PHYS_PFN(PFN_PHYS(pfn)) == pfn` and `pfn_to_section_nr(pfn) < NR_MEM_SECTIONS` before `__pfn_to_section(pfn)`. `first_zones_zonelist()` and `next_zones_zonelist()` return a sentinel with `zoneref->zone == NULL` (never `NULL`); callers must test `zonelist_zone(z) != NULL` and pre-increment `++z` before `next_zones_zonelist()`. [F108, F121]
- `__GFP_NORETRY`, `__GFP_RETRY_MAYFAIL`, and `__GFP_NOFAIL` require `__GFP_DIRECT_RECLAIM`, and `__GFP_NOFAIL` is unsupported for `order > 1`; nested internal allocations must filter GFP flags via `gfp_nested_mask()`. Static `__warned` flags in `VM_WARN_ON_ONCE_PAGE/FOLIO/MM/VMA()` must use `__section(".data..once")`. [F157, F158, F179]

## External Contracts

- User-facing memory reporting paths requiring accurate RSS/swap counts on high-CPU-count systems must read `mm->rss_stat` via `get_mm_counter_sum()` rather than `get_mm_counter()`. [F178]

## Known Pitfalls

- `folio_test_anon()`, `PageAnon()`, `PageAnonNotKsm()`, and `folio_test_ksm()` do not check page type, so callers on arbitrary/PFN-walked pages must check `!folio_test_slab(folio)` first; because `FOLIO_MAPPING_KSM` includes `FOLIO_MAPPING_ANON`, `folio_test_anon()` is true for KSM, and distinguishing non-KSM anon or KSM requires masking `folio->mapping` with `FOLIO_MAPPING_FLAGS` (`PageAnonNotKsm()` / `folio_test_ksm()`). [F41, F115]
- `PG_swapcache` aliases `PG_owner_priv_1` and `PG_movable_ops` aliases `PG_uptodate`, so callers must use `folio_test_swapcache()` (gating on `folio_test_swapbacked()`) and `page_has_movable_ops()` (gating `PageMovableOps()` on `PageOffline(page) || PageZsmalloc(page)`). Although `PagePrivate` uses `PF_ANY`, the VM checks `PAGE_FLAGS_PRIVATE` only on the head page (`folio_has_private()`), so setting `PagePrivate` only on a tail page will not invoke `release_folio()`. [F116, F188]
- `FOLIO_TYPE_OPS` and `PAGE_TYPE_OPS` must cast `PGTY_*` (`0xf0..0xf8`) to `unsigned int` before `<< 24`, whereas `page_type_has_type()` must take a signed `int` to compare `page_type < (PGTY_mapcount_underflow << 24)`. `folio_maybe_dma_pinned()` and `folio_ref_zero_or_close_to_overflow()` must cast `folio_ref_count()` to `unsigned int` before comparing against `GUP_PIN_COUNTING_BIAS` or adding `127u`. [F133, F134]
- Because `sizeof(struct folio) == 4 * sizeof(struct page)`, subpage indexing and advancing to the next folio must use `folio_page(folio, n)` and `folio_next(folio)`, never `folio + n` or `folio++`. On `!CONFIG_64BIT`, `folio->_entire_mapcount` and `folio->_pincount` live in `folio->__page_2` (absent on order-1 folios), so callers must use `folio_entire_mapcount()` and guard pincount access with `folio_has_pincount(folio)` (`folio_order(folio) > 1`). [F145, F146]
- `mmu_notifier_range_init()` leaves `range->owner` uninitialized; use `mmu_notifier_range_init_owner()` for `MMU_NOTIFY_MIGRATE` and `MMU_NOTIFY_EXCLUSIVE`, and only read `range->owner` on those two events. `next_present_section_nr(section_nr)` pre-increments `++section_nr`, so scans starting at `@start` must pass `start - 1` initially and check for `-1UL`. [F58, F123]
- On an on-stack `struct folio` snapshot (`ps.folio_snapshot` in `__dump_folio()`), pass the original PFN to `is_migrate_cma_folio(folio, pfn)` or `get_pfnblock_migratetype(&folio->page, pfn)` instead of `folio_migratetype()`/`folio_pfn()`. Use `lruvec_pgdat(lruvec)` instead of `container_of(lruvec, struct pglist_data, __lruvec)`. Printk `%pGp`, `%pGg`, and `%pGv` take pointers (`&folio->flags`, `&gfp_mask`, `&vma->vm_flags`). Allocating zeroed user folios (`vma_alloc_zeroed_movable_folio()`) must check `user_alloc_needs_zeroing()` and call `clear_user_highpage()`/`folio_zero_user()` rather than `__GFP_ZERO` or `init_on_alloc`. [F142, F149, F153, F161]
