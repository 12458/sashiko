# ETHERNET BRIDGE — net/bridge (part 1)

This component implements Linux Ethernet bridge IGMP/MLD multicast snooping and Explicit Host Tracking (EHT), Spanning Tree Protocol (STP), bridge Netfilter (`br_netfilter`), and RTNetlink/VLAN tunnel configuration.

## Architecture & Data Flow
- `br_multicast_new_port_group()` inserts `p->rhnode` into `br->sg_port_tbl` only when `!br_multicast_is_star_g(group)`, so `br_multicast_del_pg()` and `br_multicast_del_port_group()` must guard `rhashtable_remove_fast(&br->sg_port_tbl, &pg->rhnode, ...)` with `!br_multicast_is_star_g()`. [F5]
- Stack `struct br_ip`, `struct net_bridge_port_group_sg_key`, and `union net_bridge_eht_addr` keys must be zeroed with `memset` before setting fields or calling `br_multicast_ip_src_to_eht_addr()`, as `mdb_hash_tbl`/`sg_port_tbl` rhashtables and EHT RB-tree comparators (`br_multicast_eht_{host,set,set_entry}_lookup()`) hash or `memcmp` the full struct/union including padding. [F54, F128]
- In `br_multicast.c`, `pmctx` is `NULL` for host-originated packets, so handlers must check `pmctx != NULL` before dereferencing `pmctx->port`. `pmctx->vlan` and `brmctx->vlan` are `NULL` for non-VLAN contexts and require `br_multicast_port_ctx_is_vlan(pmctx)` or `br_multicast_ctx_is_vlan(brmctx)` first; `br_multicast_ctx_vlan_global_disabled()` must check `br_multicast_ctx_is_vlan(brmctx)` before returning true if `BROPT_MCAST_VLAN_SNOOPING_ENABLED` is off or `BR_VLFLAG_GLOBAL_MCAST_ENABLED` is unset on `brmctx->vlan->priv_flags`. [F47, F48, F104]
- When a `(*,G)` entry's `host_joined` changes in `br_multicast_host_{join,leave}()`, `br_multicast_star_g_host_state()` must propagate it to installed `(S,G)` entries (`BR_SGRP_F_INSTALLED`), and `br_multicast_sg_host_state()` must copy `star_mp->host_joined` to new `(S,G)` entries. [F73]
- Toggling `BROPT_MULTICAST_ENABLED` after init (in `br_multicast_new_group()` at `hash_max` or `br_multicast_toggle()`) requires `br_mc_disabled_update()` to sync `SWITCHDEV_ATTR_ID_BRIDGE_MC_DISABLED`. `br_multicast_toggle_vlan()` must also check `br_vlan_is_brentry(vlan)` and call `br_multicast_toggle_one_vlan(vlan, on)` on the master VLAN. [F65, F66]
- In `br_multicast_rport_del_notify()`, once `pmctx->ip4_rlist` and `ip6_rlist` are unhashed, reset `pmctx->multicast_router == MDB_RTR_TYPE_TEMP` to `MDB_RTR_TYPE_TEMP_QUERY` while preserving `DISABLED` and `PERM`. User query intervals must go through `br_multicast_set_{startup_}query_intvl()` to clamp `clock_t_to_jiffies()` to `[BR_MULTICAST_QUERY_INTVL_MIN, BR_MULTICAST_QUERY_INTVL_MAX]` without error. [F79, F83]
- In EHT, `__eht_lookup_create_set_entry()` must bypass `eht_host->num_entries >= PG_SRC_ENT_LIMIT` and not increment `num_entries` when `allow_zero_src` is true; `__eht_del_set_entry()` must only decrement `num_entries` when `set_h->h_addr` is non-zero. In `br_ip{4,6}_multicast_alloc_query()`, the source-counting pass and SKB-filling pass must use identical filters and `lmqt`/`llqt` timestamps, resetting the counter to 0 in between. [F89, F111]
- Master `net_bridge_vlan` entries without `BRIDGE_VLAN_INFO_BRENTRY` are context placeholders; active VLAN iterations must check `br_vlan_should_use(v)`. `__get_num_vlan_infos()` and `br_fill_ifvlaninfo_compressed()` must use identical `br_vlan_should_use(v)` checks, range coalescing (`(v->vid - vid_range_end) == 1 && flags == vid_range_flags`), and trailing flushes. [F46, F114]
- `br_vlan_valid_id()` requires VIDs in `1..VLAN_VID_MASK-1`, and `br_vlan_valid_range()` requires `cur->vid > last->vid` and no `BRIDGE_VLAN_INFO_PVID`. Per-VLAN `__be64` `v->tinfo.tunnel_id` must be converted via `be32_to_cpu(tunnel_id_to_key32(...))` in `vlan_tunid_inrange()` and `br_fill_vlan_tinfo()`. [F91, F103]
- `br_set_{hello_time,max_age}()` and `__br_set_forward_delay()` always update `br->bridge_*`, but only update active `br->{hello_time,max_age,forward_delay}` when `br_is_root_bridge(br)` is true. `br_changelink()` must validate `br->group_addr` with `is_link_local_ether_addr()` before `br_recalculate_fwd_mask()` evaluates `~(1u << br->group_addr[5])`. [F80, F124]
- `p->port_no` is 1-based (`1..BR_MAX_PORTS-1`), with `0` reserved for "no root port" (`br->root_port`) and bridge-level `br_info_notify()`; `br_make_port_id()` packs 6-bit priority above 10-bit `port_no`, so `br_stp_set_port_priority()` rejects `newprio > BR_MAX_PORT_PRIORITY` (`-ERANGE`). `struct bridge_id` keeps big-endian `prio[2]` before `addr[ETH_ALEN]` for 8-byte `memcmp()`. Odd-offset BPDU timers use `get/put_unaligned_be16()` in `br_get_ticks()` (`DIV_ROUND_UP(ticks * HZ, STP_HZ)`) and `br_set_ticks()`, and non-root `br_transmit_config()` adds `MESSAGE_AGE_INCR` (`(HZ / 256) + 1`) to `jiffies - root->designated_age`. [F93, F94, F97, F99, F122]
- `br_netfilter_rtable_init()` must bind writable `br->metrics` via `dst_init_metrics(&rt->dst, br->metrics, false)`. In `br_nf_pre_routing_finish_bridge()`, calling `neigh->output` requires saving MAC/EtherType in `nf_bridge->neigh_header` and setting `bridged_dnat = 1`, which `br_nf_pre_routing_finish_bridge_slow()` restores while clearing `bridged_dnat = 0` and `physoutdev = NULL`. [F63, F70]
- Netlink attributes added to `br_fill_ifinfo()`, `br_port_fill_attrs()`, `br_fill_info()`, or `br_multicast_dump_querier_state()` must be accounted for in `br_nlmsg_size()`, `br_port_info_size()`, `br_get_size()`, and `br_multicast_querier_state_size()` (using `nla_total_size_64bit()` for 64-bit attrs). In `br_fill_linkxstats()`, `vl_idx` is 1-based (`++vl_idx` vs `*prividx`); on `-EMSGSIZE`, call `nla_nest_end()` and set `*prividx = vl_idx`, resetting `*prividx = 0` on success. [F96, F163]

## Synchronization
- Process-context and workqueue paths acquiring `br->multicast_lock` (`br_multicast_set_{port_}router()`, `br_multicast_toggle_one_vlan()`, `br_multicast_gc_work()`) or `br->lock` (`br_stp_{en,dis}able_bridge()`, `br_stp_set_bridge_priority()`, `br_setlink()`, `br_changelink()`) must use `spin_lock_bh()` / `spin_unlock_bh()`. [F136, F137]
- Never call `timer_delete_sync()` or `cancel_delayed_work_sync()` (`br_stp_disable_bridge()`, `__br_multicast_stop()`, `br_multicast_port_ctx_deinit()`) while holding `br->lock` or `br->multicast_lock`. `br_multicast_toggle()` must drop `br->multicast_lock` before `br_multicast_{join,leave}_snoopers(br)`, and `br_ip4_multicast_{join,leave}_snoopers()` must pair `in_dev_get()` with `in_dev_put()`. [F18, F143]
- Callers of `br_ip{4,6}_multicast_{mark,add}_router()` (including `br_multicast_pim()`, `br_ip{4,6}_multicast_mrd_rcv()`) must hold `br->multicast_lock`. `br_multicast_ctx_init()` must initialize `brmctx->ip{4,6}_querier.seq` (`seqcount_spinlock_t`) with `seqcount_spinlock_init(..., &br->multicast_lock)`. [F20, F26]
- In `br_ip4_multicast_igmp3_report()` and `br_ip6_multicast_mld2_report()`, after `br_ip{4,6}_multicast_add_group()` re-acquires `br->multicast_lock`, revalidate `br_multicast_ctx_should_use(brmctx, pmctx)`, re-lookup `mdst` and `pg`, and check `!(pg->flags & MDB_PG_FLAGS_PERMANENT)`. [F29]
- Multicast expiration timer callbacks (`br_multicast_{group,port_group,eht_set,eht_set_entry}_expired()`) must check `!hlist_unhashed()` / `!RB_EMPTY_NODE()` and `!timer_pending()` after acquiring `br->multicast_lock`. `br_message_age_timer_expired()` must recheck `p->state == BR_STATE_DISABLED` after `spin_lock(&br->lock)`. [F30, F36]
- `struct bridge_mcast_stats` updates/reads require `u64_stats_update_{begin,end}(&pstats->syncp)` and `u64_stats_fetch_{begin,retry}()`. `p->stp_xstats` must be copied under `spin_lock_bh(&br->lock)` in process context (`br_fill_linkxstats()`). `pmctx->mdb_{n,max}_entries` must use `READ_ONCE()` / `WRITE_ONCE()`. [F38, F39, F40]
- Paths reading VLAN groups without `rtnl_lock` (`br_multicast_pg_to_port_ctx()`, `br_multicast_port_vid_to_port_ctx()`, `br_multicast_start_querier()`, `br_fill_ifinfo()`) must use `nbp_vlan_group_rcu()` / `br_vlan_group_rcu()` under `rcu_read_lock()`. `br_port_fill_attrs()` must read `p->backup_port` via `rcu_dereference()` under `rcu_read_lock()`. `br_info_notify()` and `br_multicast_list_adjacent()` must allocate with `GFP_ATOMIC`. [F138, F140, F146]
- In `br_nf_dev_queue_xmit()`, using `brnf_frag_data_storage` and calling `br_nf_ip_fragment()` / `v6ops->fragment()` with `br_nf_push_frag_xmit()` requires `local_lock_nested_bh(&brnf_frag_data_storage.bh_lock)`. In `br_nf_local_in()`, before confirming an unconfirmed `nf_conn` on a non-`PACKET_HOST` skb, verify `refcount_read(&nfct->use) == 1` (or call `nf_reset_ct(skb)` if shared). [F71, F152]

## Object Lifetimes
- Multicast entries removed under `br->multicast_lock` (`net_bridge_mdb_entry`, `net_bridge_port_group`, `net_bridge_group_src`, `net_bridge_group_eht_set{_entry}`) must unhash their node (`hlist_del_init*` / `RB_CLEAR_NODE`) and defer `timer_shutdown_sync()` and freeing to `br->mcast_gc_list`. `br_multicast_del_port()` must `flush_work(&br->mcast_gc_work)` after deleting `port->mglist` and before deinitializing `port->multicast_ctx` / freeing `mcast_stats`; `br_multicast_dev_del()` must drain `mcast_gc_list`, `cancel_work_sync(&br->mcast_gc_work)`, and call `rcu_barrier()`. [F6, F10]
- In `br_multicast_toin()` and `br_multicast_block()`, after `br_multicast_find_del_pg()` deletes `pg`, set `changed = false` and do not dereference `pg`. In `br_multicast_del_eht_host()`, do not touch `eht_host` after `hlist_for_each_entry_safe(set_h, tmp, &eht_host->set_entries, host_list)` because `__eht_del_set_entry()` frees `eht_host` when `set_entries` empties. [F77, F110]
- `setup_pre_routing()` stores ingress port ifindex `physinif` in `nf_bridge_info`; resume callbacks (`br_nf_pre_routing_finish*`, `br_nf_forward_finish`) must resolve it via `nf_bridge_get_physindev()` and free `skb` if `NULL`. Attaching `fake_rtable` (`bridge_parent_rtable()`) requires `skb_dst_drop()` then `skb_dst_set_noref()`. `ip_sabotage_in()` must set `nf_bridge->sabotage_in_done = 1` instead of calling `nf_bridge_info_free(skb)`. [F2, F3, F150]
- In `br_nf_local_in()`, never dereference `nfct`/`ct` after `ct_hook->confirm(skb)`; if `confirm()` returns `NF_VERDICT_MASK == NF_STOLEN`, return `NF_STOLEN` immediately without touching `skb`. `br_stp_rcv()` owns `skb` and must unlock `br->lock` (if held) and `kfree_skb(skb)` on all paths. Non-`init_net` `br_netfilter_sysctl_{init,exit}_net()` must `kmemdup(brnf_table)` and `kfree(table)`, while `init_net` uses static `brnf_table` without freeing it. [F14, F19, F62, F158]

## API Contracts
- `br_multicast_new_group()` returns `ERR_PTR` on failure (never `NULL`), whereas `br_multicast_new_{port_group,group_src}()` return `NULL` (never `ERR_PTR`). `__br_multicast_add_group()` returns `ERR_PTR` on error, `NULL` when disabled or `!pmctx`, or a valid `net_bridge_port_group *` (check `IS_ERR_OR_NULL()`). `br_multicast_ctx_should_use()` checks `!br_multicast_port_ctx_state_disabled(pmctx)` when `pmctx` is non-NULL and `!br_multicast_ctx_vlan_disabled(brmctx)` only when `!pmctx`. [F41, F42, F105]
- `br_vlan_add()` and `nbp_vlan_add()` (and stubs) must set `*changed = false` before any return; `br_cfm_{peer_}mep_count()` (and stubs) must set `*count = 0` even on `-EOPNOTSUPP`. `br_set_{forward_delay,hello_time,max_age,ageing_time}()` and `br_multicast_set_*_query_intvl()` take `clock_t`, while `__br_set_forward_delay()` and `__set_ageing_time()` take `jiffies`. `br_multicast_has_{querier_anywhere,querier_adjacent,router_adjacent}()` take host-order `ETH_P_IP`/`ETH_P_IPV6`, while `br_ip.proto` and `br_multicast_querier_exists()` take `htons(ETH_P_*)`. [F56, F57, F60, F61]
- IGMPv3/MLDv2 `void *srcs` arrays (`br_multicast_isinc_allow()`, `__grp_src_isexc_incl()`, `__eht_{create,del}_set_entries()`) must be indexed as `srcs + (src_idx * addr_size)` and copied with `addr_size`. RCU paths on unverified `dev` must use `br_port_get_check_rcu(dev)` or `netif_is_bridge_port(dev)` before `br_port_get_rcu(dev)`; callers of `br_multicast_{enabled,router}(dev)` must verify `netif_is_bridge_master(dev)`. [F129, F132, F133]
- `setup_pre_routing()` must call `skb_orphan(skb)`. `ip_sabotage_in()` only intercepts packets when `!nf_bridge->in_prerouting && !netif_is_l3_master(skb->dev) && !netif_is_l3_slave(skb->dev)`. `br_nf_forward_ip()` must call `nf_bridge_unshare(skb)` and reload `nf_bridge` before mutating it. `br_nf_{pre_routing_finish*,forward_finish,dev_queue_xmit}()` must call `nf_bridge_update_protocol(skb)` before `nf_bridge_push_encap_header(skb)` and before fragmentation. `br_nf_push_frag_xmit()` must check `skb_cow_head(skb, data->size)` before writing `data->mac`, and both xmit paths must call `nf_bridge_info_free(skb)` before `br_dev_queue_push_xmit()`. [F68, F153, F155, F156, F157]

## Error Handling
- In `br_multicast_create_eht_set_entry()`, only destroy `eht_host` if `hlist_empty(&eht_host->set_entries)` and only delete `eht_set` if `RB_EMPTY_ROOT(&eht_set->entry_tree)`. `br_dev_newlink()` must call `br_dev_delete(dev, NULL)` if `br_changelink()` fails after `register_netdevice()`, and `br_netlink_init()` must unwind `rtnl_af_register()` and `br_vlan_rtnl_init()` on error. [F7, F17]
- Ignore `-EOPNOTSUPP` from `switchdev_port_attr_set()` (`br_set_state()`, `__set_ageing_time()`, `br_multicast_add_port()`, `br_multicast_toggle()`, `br_mc_disabled_update()`). In `br_multicast_ipv{4,6}_rcv()`, `-ENOMSG` / `-ENODATA` from `ip_mc_check_igmp()` / `ipv6_mc_check_mld()` must return `0` without `br_multicast_err_count()`. `br_nf_dev_queue_xmit()` must verify `skb_valid_dst(skb)` before IPv4/IPv6 fragmentation. [F43, F44, F50]

## External Contracts
- In `br_nf_local_in()`, `BR_INPUT_SKB_CB(skb)->promisc` packets must call `nf_reset_ct(skb)` and return `NF_ACCEPT` without confirming conntrack. `br_fill_ifinfo()` must open one `IFLA_AF_SPEC` nest and close it with `nla_nest_end()` if non-empty or `nla_nest_cancel()` if empty; `br_fill_linkxstats()` must zero `struct bridge_vlan_xstats vxi` with `memset` before `nla_put()`. `IFLA_BR_GROUP_FWD_MASK` rejects `BR_GROUPFWD_RESTRICTED` (`STP | MACPAUSE | LACP`), while `IFLA_BRPORT_GROUP_FWD_MASK` rejects `BR_GROUPFWD_MACPAUSE`. [F151, F162, F164, F166]

## Known Pitfalls
- `br_stp_set_bridge_priority()` and `br_stp_change_bridge_id()` must update port `designated_bridge`/`designated_root` before mutating `br->bridge_id`, and MAC buffers passed to `ether_addr_equal()` must be 2-byte aligned. [F81, F98]
- Reload SKB pointers (`buf`, `grec`, `h_addr`, `iph`) after `pskb_may_pull()` / `ip_mc_may_pull()` in `br_stp_rcv()`, `br_ip4_multicast_igmp3_report()`, and `br_validate_ipv4()`. `br_stp_rcv()` must call `pskb_may_pull(skb, 32)`, reload `buf`, and check `bpdu.message_age <= bpdu.max_age`; `br_ip6_multicast_mld2_report()` must bounds-check `nsrcs_offset + sizeof(__nsrcs)` against `ipv6_transport_len(skb)` and use `skb_header_pointer()` for `grec_nsrcs` before `ipv6_mc_may_pull()`. [F85, F87, F130]
- `br_multicast_rcv()` must check `br_vlan_is_master(vlan)` so `BR_VLFLAG_GLOBAL_MCAST_ENABLED` and `*brmctx` come from `vlan` or `vlan->brvlan`. In `br_multicast_list_adjacent()`, `port` is reused as the loop cursor, so filter with `port->dev == dev`. `br_multicast_rport_from_node{_skb}()` must use `ip6_rlist` for IPv6 and `ip4_rlist` for IPv4. In `br_setlink()`, `br_dellink()`, `br_afspec()`, `br_vlan_info()`, `br_process_vlan_{tunnel_}info()`, and `br_info_notify()`, use `p->br` whenever `p` is non-NULL. [F106, F113, F131, F135]
- `br_nf_hook_thresh()` must skip `priority < NF_BR_PRI_BRNF`, break on `> NF_BR_PRI_BRNF`, and increment `i++` before breaking when `ops[i]->hook == br_nf_pre_routing`. Querier delay windows use `!timer_pending(&querier->delay_timer)` in `__br_multicast_querier_exists()`, and timer shortening in `br_ip{4,6}_multicast_query()` / `br_multicast_leave_group()` must check `time_after(timer.expires, deadline)`. Pass `0` (not `sizeof(0)`) to `nla_total_size(0)` for empty netlink nests. [F118, F119, F125, F127]

## Other
- In `br_process_vlan_info()`, when `*vinfo_last != NULL`, track contiguous modified VIDs in `v_change_start`, emit `br_vlan_notify(br, p, v_change_start, v - 1, rtm_cmd)` and reset `v_change_start = 0` on unmodified VIDs or loop end, and clear `*vinfo_last = NULL` before returning. [F115]
