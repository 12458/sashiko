# TRACING — (top level) (part 1)

This component implements the `tracefs` pseudo-filesystem and its just-in-time (JIT) `eventfs` inode/dentry management layer (`fs/tracefs/`), alongside the core kernel tracepoint, trace event, recursion-protection, sequence-buffer, and BPF raw-tracepoint header infrastructure (`include/linux/trace*.h`, `include/trace/`), plus subsystem trace event definitions (`include/trace/events/alarmtimer.h` through `kyber.h`).

## Architecture & Data Flow

- In `struct tracefs_inode`, `ti->private` points to a root `struct inode` when `TRACEFS_EVENT_INODE` is clear, to `struct eventfs_inode` on eventfs directories, and is `NULL` on eventfs regular files (which store their parent `eventfs_inode` in `dentry->d_fsdata`). Broken by: dereferencing `ti->private` on an inode with `TRACEFS_EVENT_INODE` set without checking for `NULL`, or passing an eventfs inode to `set_tracefs_inode_owner()`. [F213]
- In `tracefs_apply_options()`, remounting with `Opt_uid` or `Opt_gid` must update `ti->flags` (`TRACEFS_UID_PERM_SET`/`TRACEFS_GID_PERM_SET`) and `ti->vfs_inode.i_uid`/`i_gid` on each `tracefs_inode` before calling `eventfs_remount()`, which propagates `i_uid` and `i_gid` into `eventfs_set_attrs()`. [F227]
- When changing UID or GID on a `tracefs` inode, `tracefs_setattr()` must set `TRACEFS_UID_PERM_SET` or `TRACEFS_GID_PERM_SET` in `ti->flags` so `set_tracefs_inode_owner()` (called on `permission` and `getattr`) does not overwrite the explicit ownership with default root or instance inode ownership. [F228]
- In `eventfs_set_attr()`, attribute changes on JIT-created `eventfs` dentries must be recorded in `ei->attr` (for non-root directories where `!ei->is_events`) or `ei->entry_attrs[i]` (for regular files) with `EVENTFS_SAVE_MODE`/`UID`/`GID` flags under `eventfs_mutex` so `update_inode_attr()` restores them upon recreation. `eventfs_attr.mode` packs both the 16-bit file mode (`EVENTFS_MODE_MASK`) and upper flag bits, so `update_attr()` must preserve `~EVENTFS_MODE_MASK` when setting the mode and `update_inode_attr()` must mask `attr->mode` with `EVENTFS_MODE_MASK` when writing `inode->i_mode`. [F229, F246]
- `eventfs_dir_ino` must never assign `EVENTFS_FILE_INODE_INO` (`0x12c4e37`) to an `eventfs_inode` directory (`ei->ino`), because all eventfs regular files share `EVENTFS_FILE_INODE_INO`. [F297]
- The `eventfs_inode` directory hierarchy rooted at `events/` must not exceed a nesting depth of 3 (`level > 3`), because `eventfs_set_attrs()` and `eventfs_remove_rec()` both warn and abort recursion when `level > 3`. [F239]
- In `struct trace_event_fields` arrays, the anonymous union is discriminated by `type`: when `type == TRACE_FUNCTION_TYPE` (`(const char *)~0UL`), the `define_fields` function pointer variant is active instead of the field metadata struct (`name`, `size`, `align`, `is_signed`, `needs_test`, `filter_type`, `len`). Broken by: iterating `call->class->fields_array` and dereferencing `field->type` or `field->name` as a string without checking `field->type == TRACE_FUNCTION_TYPE`. [F217]
- In `struct tracepoint`, `tp->ext` is `NULL` for tracepoints defined via `DEFINE_TRACE` and non-NULL only for `DEFINE_TRACE_FN` or `DEFINE_TRACE_SYSCALL`; always check `if (tp->ext)` before accessing `faultable`, `regfunc`, or `unregfunc` (as in `tracepoint_is_faultable`). [F218]
- In `__DEFINE_TRACE_EXT()`, `__traceiter_##_name()` iterates over `(&__tracepoint_##_name)->funcs` with a `do-while` loop that dereferences `it_func_ptr[0].func` unconditionally on the first pass and stops when `(++it_func_ptr)->func` is `NULL`; any non-NULL `funcs` array must have at least one non-NULL entry followed by a `NULL`-`func` terminator. [F251]
- In `struct trace_iterator`, all per-entry transient state reset on each `pipe_read` cycle must be placed at or after `struct trace_seq seq`, while persistent session state (`tr`, `trace`, `array_buffer`, `buffer_iter`, `iter_flags`, `temp`, `fmt`, `tmp_seq`, `started`, `closed`, `snapshot`) must precede `seq`. [F233]
- `struct trace_dynamic_info` must place `len` before `offset` under `CONFIG_CPU_BIG_ENDIAN` and `offset` before `len` on little-endian CPUs so its 16-bit fields match the `offset | (len << 16)` bit layout of 32-bit `__data_loc_<item>` dynamic field locators. [F236]
- The recursion context bit enums starting at `TRACE_FTRACE_BIT` and `TRACE_INTERNAL_BIT` must remain ordered as `[BASE, NMI, IRQ, SIRQ, TRANSITION]` because `trace_test_and_set_recursion()` indexes them by adding `TRACE_CTX_NORMAL - interrupt_context_level()` (or `TRACE_CTX_TRANSITION`) to `start`. [F242]
- In `include/trace/bpf_probe.h`, `__CAST_TO_U64(x)` must copy the tracepoint argument into a same-width unsigned integer type (`UINTTYPE(sizeof(x))`) before casting to `u64` so narrow signed integers and small structs are zero-extended rather than sign-extended when passed to `bpf_trace_run1`..`bpf_trace_run12`. [F260]

## Synchronization

- An `eventfs_callback` implementation (`struct eventfs_entry::callback`) is invoked under `eventfs_mutex` (and `eventfs_srcu` during iteration) and must never call back into `tracefs` or `eventfs` APIs (e.g., `eventfs_create_dir`, `eventfs_remove_dir`, `tracefs_create_file`). [F197]
- `tracefs_d_revalidate` may be invoked under RCU-walk (`LOOKUP_RCU`), so it must not acquire `eventfs_mutex` or any sleeping lock and must check `ei->is_freed` locklessly. [F278]
- The global `tracefs_inodes` list must only be mutated under `spin_lock_irqsave(&tracefs_inode_lock, flags)` using RCU list primitives (`list_add_rcu` in `tracefs_alloc_inode`, `list_del_rcu` in `tracefs_destroy_inode`) and traversed under `rcu_read_lock()` with `list_for_each_entry_rcu`. [F199]
- Writers modifying `struct trace_event_file::flags` (`EVENT_FILE_FL_*`) must use atomic bit operations (`set_bit`/`clear_bit`) to prevent races with concurrent writers, whereas readers in tracing critical sections (such as `trace_trigger_soft_disabled`) may read `file->flags` non-atomically. [F205]
- `bpf_prog_array_valid(call)` performs an optimistic lockless `READ_ONCE(call->prog_array)` check outside `rcu_read_lock()`; callers entering an RCU read-side critical section afterward must re-check `call->prog_array` under `rcu_read_lock()` before invoking BPF programs. [F206]
- `current->trace_recursion` may only be modified by `current`; `trace_test_and_set_recursion` must set the bit in `current->trace_recursion` and issue `barrier()` before `preempt_disable_notrace()`, and `trace_clear_recursion` must call `preempt_enable_notrace()` and `barrier()` before `trace_recursion_clear(bit)`. [F286]
- `hist_poll_wakeup` may be called from arbitrary trace event trigger contexts (including hardirq and NMI), so it must defer waking `hist_poll_wq` via `irq_work_queue(&hist_poll_work)` after testing `wq_has_sleeper(&hist_poll_wq)` rather than calling `wake_up` directly. [F287]

## Object Lifetimes

- Only `dentry->d_fsdata` holds a `kref` reference on `struct eventfs_inode` (acquired via `get_ei()` in `lookup_file()`, `lookup_dir_entry()`, and `eventfs_create_events_dir()`, and released via `put_ei()` in `eventfs_d_release()`); `tracefs_inode.private` stores an uncounted pointer and must not increment or decrement `ei->kref`. [F180]
- `free_ei_rcu()` must free `ei->name` with `kfree_const()` (matching `kstrdup_const()` in `init_ei()`) and must check `ei->is_events` to free `get_root_inode(ei)` (`struct eventfs_root_inode`) for root event directories rather than passing `ei` directly to `kfree()`. [F183]
- `tracepoint_string(str)` records the raw pointer `str` in the `__tracepoint_str` section so binary trace buffers store only the pointer address; `str` must be a persistent constant string valid for the lifetime of the kernel or containing module, never a stack or dynamically freed heap buffer. [F191]

## API Contracts

- `trace_test_and_set_recursion()` (and `ftrace_test_recursion_trylock()`) disables preemption via `preempt_disable_notrace()` and sets a bit in `current->trace_recursion` only when returning `bit >= 0`; callers must call `trace_clear_recursion(bit)` (or `ftrace_test_recursion_unlock(bit)`) if and only if `bit >= 0`, passing the exact returned `bit`. [F188]
- `trace_recursion_set`, `trace_recursion_clear`, `trace_recursion_test`, and `trace_clear_recursion` take an unshifted bit index (`TRACE_FTRACE_BIT`, `TRACE_RECORD_RECURSION_BIT`, or the index returned by `trace_test_and_set_recursion`) and shift by `1 << (bit)` internally, never a pre-shifted bitmask (`BIT(...)`). [F224]
- `tracing_gen_ctx_dec()` must only be called from contexts where preemption is already disabled; when `CONFIG_PREEMPTION` is enabled, it directly decrements the packed `trace_ctx` word (`trace_ctx--`), underflowing the low 4-bit preempt-count field into upper bitfields if the preempt count is 0. [F259]
- When `CONFIG_TRACING` is enabled, `tracefs_create_file`, `tracefs_create_dir`, and `tracefs_create_instance_dir` always return `NULL` (never an `ERR_PTR`) on failure by translating `IS_ERR(dentry)` from `tracefs_start_creating` and `tracefs_failed_creating` into `NULL`. [F209]
- Both `tracefs_create_file` and `lookup_file` require `mode` to either omit file-type bits (`!(mode & S_IFMT)`, defaulting to `S_IFREG`) or specify a regular file (`S_ISREG(mode)`): `tracefs_create_file` calls `BUG_ON(!S_ISREG(mode))` and `lookup_file` warns and returns `-EIO` otherwise. [F299]
- An `eventfs_callback` function must return `<= 0` when the dynamic file entry should be omitted and `> 0` (after populating `*mode`, `*fops`, and optionally replacing `*data`) when the file should be created or emitted by `eventfs_root_lookup` and `eventfs_iterate`. Before invoking `entry->callback(name, &mode, &data, &fops)` on each iteration, the caller must initialize the local `data` pointer to `ei->data` because callbacks may leave `*data` unchanged to use the directory default. [F210, F221]
- In `struct trace_event_class`, the `reg` callback uses a boolean return convention for `TRACE_REG_PERF_ADD` and `TRACE_REG_PERF_DEL`: returning `1` (`true`) indicates a custom action was taken and the default per-CPU perf event list operation must be skipped, whereas `0` (`false`) triggers the default action. [F212]
- In `trace_trigger_soft_disabled()`, `EVENT_FILE_FL_TRIGGER_COND` must be checked to return `false` before calling `__trace_trigger_soft_disabled()` so soft-disabled events with conditional triggers still format the event record rather than short-circuiting early. [F247]
- Callers copying or measuring valid bytes in a `struct trace_seq` buffer must use `trace_seq_used(s)` (`seq_buf_used(&s->seq)`) rather than `s->seq.len`, because `s->seq.len` can exceed `TRACE_SEQ_BUFFER_SIZE` when the buffer overflows. [F223]
- In `include/linux/tracepoint.h`, `__DEFINE_RUST_DO_TRACE` defines `rust_do_trace_##name` to call `__do_trace_##name(args)` directly without checking `__tracepoint_##name.key`, relying on the Rust caller to gate the FFI call on the static branch when disabled. In `include/trace/define_trace.h`, `DEFINE_RUST_DO_TRACE` expands to `__DEFINE_RUST_DO_TRACE` only during the `TRACE_INCLUDE` pass when `CREATE_RUST_TRACE_POINTS` is defined alongside `CREATE_TRACE_POINTS`, and is reset to a no-op before `define_trace.h` finishes. [F274, F275]
- Every trace event header under `include/trace/events/` must guard its definitions with `#if !defined(_TRACE_<SYSTEM>_H) || defined(TRACE_HEADER_MULTI_READ)` and place `#include <trace/define_trace.h>` outside that `#endif` guard. [F303]
- In trace events using `__bitmask(item, nr_bits)` or `__cpumask(item)`, the `src` pointer passed to `__assign_bitmask` or `__assign_cpumask` must point to an `unsigned long` bitmap array (such as `cpumask_bits(mask)`) because the copy size is padded to `unsigned long` multiples. [F272]
- In `include/trace/events/firewire_ohci.h`, when skipping the first quadlet of a `u32` dynamic array in `TP_printk`, `__get_dynamic_array(self_id_receive)` (which returns `void *`) must be cast to `const u32 *` before pointer addition (`((const u32 *)__get_dynamic_array(self_id_receive)) + 1`) and the element count decremented by 1. [F273]

## Error Handling

- When `eventfs_create_dir()` or `eventfs_create_events_dir()` fails after initializing `ei->entries` and `ei->nr_entries`, rollback must free `ei` via `cleanup_ei(ei)` rather than `free_ei(ei)` or `put_ei(ei)` so `ei->nr_entries` is zeroed and `release_ei()` does not invoke `entry->release` callbacks on an uncreated directory. [F181]

## External Contracts

- `tracefs_create_file`, `tracefs_create_dir`, and `eventfs_create_events_dir` must check `security_locked_down(LOCKDOWN_TRACEFS)` and return `NULL` when kernel lockdown is active. [F298]

## Known Pitfalls

- In `set_tracefs_inode_owner()`, when `root_inode` (from `ti->private`) is not the superblock root, `rti` holds the instance root's `tracefs_inode` while `root_inode` is reassigned to the superblock root; `rti->flags` must be tested for fallback to the mount root's UID/GID, whereas `ti->flags` must be tested before updating `inode->i_uid` and `inode->i_gid`. [F253]
- In `eventfs_get_inode()`, the ancestor walk must advance `dentry = dentry->d_parent` before reading `pei = dentry->d_fsdata` in a `do-while` loop until `pei->is_events` is set, because the child dentry being instantiated does not have `d_fsdata` populated until after `eventfs_get_inode()` returns. [F255]
- In trace event definitions (`include/trace/events/*.h`), `__dynamic_array(type, item, len)` takes an element count `len` (multiplying `len` by `sizeof(type)`), whereas `__get_dynamic_array_len(item)` returns the total byte size (`len * sizeof(type)`). Thus, `__print_array()` calls in `TP_printk` must divide `__get_dynamic_array_len(item)` by `sizeof(type)`, and byte lengths such as `packet->header_length` in `include/trace/events/firewire.h` must be divided by `QUADLET_SIZE` (`sizeof(u32)`) when passed to `__dynamic_array(u32, header, ...)`. [F237, F266]
- In `include/trace/events/firewire.h`, `ASYNC_HEADER_GET_OFFSET(header)` must cast the masked 32-bit quadlet `(header)[1] & ASYNC_HEADER_Q1_OFFSET_HIGH_MASK` to `unsigned long long` before shifting left by 32 (`<< 32`) to construct the 48-bit FireWire offset. [F263]
- In `include/trace/events/filemap.h`, every tracepoint recording `s_dev` from `mapping->host` must check `if (mapping->host->i_sb)` and fall back to `mapping->host->i_rdev` when `i_sb` is `NULL`. [F307]
