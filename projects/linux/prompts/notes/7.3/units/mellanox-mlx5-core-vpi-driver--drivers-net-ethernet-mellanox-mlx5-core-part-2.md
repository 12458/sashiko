# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 2)

Implements core Ethernet (`mlx5e`) data/control-path declarations, TC connection tracking (CT) offload, IP tunnel encap/decap offloads (VXLAN, GENEVE, GRE, MPLS-over-UDP), TIR/trap management, AF_XDP (XSK) zero-copy RX/TX rings, and hardware Event Queue (EQ) management.

## Architecture & Data Flow
- Multi-WQEBB SQ/ICOSQ WQEs cannot cross page boundaries: when `contig_wqebbs < size`, `mlx5e_txqsq_get_next_pi()` and `mlx5e_icosq_get_next_pi()` pad page-edge space with up to `wqe_size - 1` NOPs, setting `.num_wqebbs = 1` (and `.wqe_type = MLX5E_ICOSQ_WQE_NOP` on ICOSQ) in `sq->db.wqe_info`, advancing `sq->pc` via `mlx5e_post_nop()`, and refreshing `pi = mlx5_wq_cyc_ctr2ix(wq, sq->pc)`, while room checks reserve `MLX5E_STOP_ROOM(wqe_size)` (`2 * wqe_size - 1`). `mlx5e_get_max_sq_aligned_wqebbs()` must clamp to `<= MLX5_SEND_WQE_MAX_WQEBBS - 1` (and `ALIGN_DOWN` to 2 if `L1_CACHE_BYTES >= 128`) so `wqebbs * 4` fits the 6-bit DS field. [F82, F95, F126]
- Keep UMR/MPWRQ/TX sizing in lockstep: inline `xlt_offset`/UMR entry size in `mlx5e_xsk_alloc_rx_mpwqe()` with `mlx5e_mpwrq_umr_entry_size()`, `MLX5_UMR_MAX_FLEX_SPACE`/`MLX5_MPWRQ_MAX_PAGES_PER_WQE` (`en.h`) with `mlx5e_mpwrq_log_wqe_sz()`, and `MLX5E_MAX_TX_WQEBBS` (`txrx.h`) with `mlx5e_sq_calc_wqe_attr()`. `MLX5E_KSM_UMR_WQEBBS` and `MLX5E_KSM_UMR_DS_CNT` use `DIV_ROUND_UP` on `MLX5E_KSM_UMR_WQE_SZ(ksm_entries)`, whereas `MLX5E_KSM_MAX_ENTRIES_PER_WQE` and `MLX5E_KSM_ENTRIES_PER_WQE` round down. [F83, F131]
- In `mlx5e_rqwq_reset()`, if `rq->wq_type == MLX5_WQ_TYPE_LINKED_LIST_STRIDING_RQ`, reset `rq->mpwqe.actual_wq_head = 0` alongside `mlx5_wq_ll_reset(&rq->mpwqe.wq)`. Any change to `MLX5E_RQ_STATE_*` / `MLX5E_SQ_STATE_*` in `en.h` must keep `MLX5E_NUM_RQ_STATES` / `MLX5E_NUM_SQ_STATES` last and update string arrays in `en/reporter_rx.c` and `en/reporter_tx.c`. [F81, F84]
- `struct mlx5e_xdp_buff` must start with `struct xdp_buff xdp` and fit in `xdp_buff_xsk->cb` (`XSK_CHECK_PRIV_TYPE`) for `xsk_buff_to_mxbuf()`. XSK cyclic RQs (`mlx5e_xsk_alloc_rx_wqes_batched()`, `mlx5e_xsk_alloc_rx_wqes()`) require `log_num_frags == 0` with `rq->wqe.frags[j].xskp == &rq->wqe.alloc_units->xsk_buffs[j]`; when `wqe_bulk > contig` in `mlx5e_xsk_alloc_rx_wqes_batched()`, only call the wrapped `xsk_buff_alloc_batch()` if the first returned `alloc == contig`. In `mlx5e_xsk_tx()` and `mlx5e_xsk_tx_post_err()`, every XSK WQE or error NOP must push `xdpi` to `sq->db.xdpi_fifo`, plus a `.xsk_meta` entry if `xp_tx_metadata_enabled(sq->xsk_pool)` (closing any MPWQE session before `mlx5e_xsk_tx_post_err()`). [F80, F100, F114, F144]
- `mlx5e_tir_init()` must link `tir->list` into `res->td.tirs_list` under `res->td.list_lock` (`reg == true`) or call `INIT_LIST_HEAD(&tir->list)` (`reg == false`), as `mlx5e_tir_destroy()` checks `!list_empty(&tir->list)` before locking and calling `list_del()`. [F4]
- `MLX5_EQ_POLLING_BUDGET <= MLX5_NUM_SPARE_EQE`, and `create_map_eq()` must add `MLX5_NUM_SPARE_EQE` to `param->nent`. For SubFunctions (`mlx5_core_is_sf(dev)`), `alloc_rmap()` must not allocate `eq_table->rmap` (using `parent_mdev->priv.eq_table->rmap`), and `comp_irq_request_sf()` / `comp_irq_release_sf()` must update `table->used_cpus` and `table->comp_irqs` together. [F86, F89]
- Zero-init every `struct mlx5_ct_tuple` (`mlx5e_tc_ct_restore_flow()`, `mlx5_tc_ct_block_flow_offload_add()`) as `tuples_ht_params` / `tuples_nat_ht_params` hash `sizeof(struct mlx5_ct_tuple)` including padding. Insert `mlx5_ct_entry` into `ct_tuples_nat_ht` (`MLX5_CT_ENTRY_IN_CT_NAT_TABLE`) iff `has_nat`, else `ct_tuples_ht` (`MLX5_CT_ENTRY_IN_CT_TABLE`), matching flags in `mlx5_tc_ct_entry_remove_from_tuples()`. In `mlx5_tc_ct_entry_set_registers()`, if `ct_priv->ns_type != MLX5_FLOW_NAMESPACE_FDB`, write `zone_restore_id` to both `ZONE_RESTORE_TO_REG` (`reg_c1`) and `NIC_ZONE_RESTORE_TO_REG` (`reg_b`). `mlx5_tc_ct_init_check_esw_support()` requires `mlx5_eswitch_vlan_actions_supported(esw->dev, 1)`, `fdb_modify_header_fwd_to_table`, and `mlx5_eswitch_reg_c1_loopback_enabled(esw)`. `mlx5_tc_ct_fs_init()` must allocate `sizeof(*ct_priv->fs) + fs_ops->priv_size`. [F59, F73, F75, F146, F167]
- In `mlx5e_tc_encap_flows_add()` and `mlx5e_reoffload_encap()`, only transition `MLX5_ESW_DEST_ENCAP` flows from slow path to FDB rules if `mlx5e_tc_flow_all_encaps_valid(esw_attr)` is true. In `mlx5e_set_int_port_tunnel()`, reject (`-EINVAL`) uplink representor flows with `MLX5_ESW_DEST_ENCAP` to OVS internal ports under `MLX5_FLOW_STEERING_MODE_DMFS`. [F164, F196]

## Synchronization
- `mlx5e_notify_hw()` must issue `dma_wmb()` before writing `cpu_to_be32(pc)` to `*wq->db`, and `wmb()` before `mlx5_write64()` to `uar_map`. EQ pollers (`mlx5_eq_comp_int()`, `mlx5_eq_async_int()`, `mlx5_eq_get_eqe()`) must issue `dma_rmb()` after checking `next_eqe_sw()` / `eqe->owner` before reading `eqe`. [F40, F154]
- `mlx5_eq_async_int()` must hold `eq_async->lock` (`spin_lock_irqsave` for `ASYNC_EQ_RECOVER` in `mlx5_cmd_eq_recover()`, `spin_lock` in IRQ) while polling and calling `eq_update_ci()`. `create_comp_eq()` and runtime `comp_eqs` mutations require `table->comp_lock`, whereas `create_async_eq()` / `destroy_async_eq()` require `table->lock`. [F42, F175]
- `mlx5e_activate_xsk()` / `mlx5e_deactivate_xsk()` must bracket `MLX5E_RQ_STATE_ENABLED` changes on `c->xskrq.state` with `mlx5e_reporter_icosq_suspend_recovery(c)` / `resume_recovery(c)` (`c->icosq_recovery_lock`), and `mlx5e_deactivate_xsk()` / `mlx5e_close_xsk()` must call `synchronize_net()`. Callers holding `priv->state_lock` (`mlx5e_xsk_disable_locked()` -> `mlx5e_wait_for_min_rx_wqes()`, `mlx5e_open_locked()`) must defer RX timeout recovery to `rq->rx_timeout_work` instead of taking the devlink lock synchronously. Because `mlx5e_handle_trap_event()` and `mlx5e_open_locked()` hold `netdev_lock(priv->netdev)`, `en/trap.c` (`mlx5e_open/activate/deactivate/close_trap()`) must use `netif_napi_add_locked()`, `napi_enable_locked()`, `napi_disable_locked()`, and `netif_napi_del_locked()`. [F35, F38, F194]
- `mlx5e_tc_ct_restore_flow()` runs in RX softirq and takes `ct_priv->ht_lock` with `spin_lock()`, so process/workqueue callers (`mlx5_tc_ct_entry_del()`, `mlx5_tc_ct_shared_counter_get()`, `mlx5_tc_ct_block_flow_offload_add()`) must use `spin_lock_bh()`, and `mlx5e_tc_ct_restore_flow()` must use `__mlx5_tc_ct_entry_put()` to defer `mlx5_tc_ct_entry_del()` to `ct_priv->wq`. [F168, F169]
- In `mlx5_tc_ct_block_flow_offload_add()`, only set `MLX5_CT_ENTRY_FLAG_VALID` after `mlx5_tc_ct_entry_add_rules()` succeeds, and check `mlx5_tc_ct_entry_valid(entry)` under `ct_priv->ht_lock` in `mlx5_tc_ct_entry_get()`, `del`, and `stats`. In `mlx5_tc_ct_block_flow_offload_update()`, since `ct_priv->ht_lock` is dropped during `mlx5_tc_ct_entry_update_rules()`, the error path must re-lock `ht_lock` and re-lookup `cookie` in `ft->ct_entries_ht` before removing and putting `entry`. [F25, F28]
- `__flow_flag_set()` / `__flow_flag_clear()` on `mlx5e_tc_flow->flags` require `smp_mb__before_atomic()`, and `__flow_flag_test()` requires `smp_mb__after_atomic()`. In `mlx5e_take_tmp_flow()`, wait on `flow->del_hw_done` if `mlx5e_flow_get(flow)` returns `IS_ERR`, or on `flow->init_done` if it succeeds. [F24, F34]
- In `mlx5e_get_next_matching_encap()`, pin `next` via `mlx5e_encap_take(next)` and call `rcu_read_unlock()` before `mlx5e_encap_put()` or `wait_for_completion(&next->res_ready)`. In `get_route_and_out_devs()`, pin `uplink_upper` (`netdev_master_upper_dev_get_rcu()`) with `dev_hold()` before `rcu_read_unlock()` so `mlx5_lag_is_sriov()` runs outside RCU, then `dev_put()`. [F33, F176]
- In `mlx5e_tc_tun_create_header_ipv4/ipv6()`, call `mlx5e_rep_encap_entry_attach()` before checking `attr.n->nud_state` under `read_lock_bh(&attr.n->lock)`; if `!(nud_state & NUD_VALID)`, call `neigh_event_send(attr.n, NULL)` and return `0` without setting `MLX5_ENCAP_ENTRY_VALID` or `e->pkt_reformat`, so callers and `mlx5e_encap_dealloc()` must check `e->flags & MLX5_ENCAP_ENTRY_VALID`. [F51, F195]
- In `mlx5e_init_fib_work_ipv4/ipv6()` (atomic `mlx5e_tc_tun_fib_event()`), call `mlx5e_tc_init_fib_work(..., GFP_ATOMIC)` before `mlx5e_route_lookup_for_update()`, with no fallible steps after acquiring `r`. In `mlx5e_tc_fib_event_work()`, lock `rtnl_lock()` before `esw->offloads.encap_tbl_lock`, and unlock both before `mlx5e_put_flow_list()` and `mlx5e_route_put()`. [F170, F178]

## Object Lifetimes
- `mlx5_eq_cq_get()` holds the CQ under `rcu_read_lock()`; callers (`mlx5_eq_comp_int()`, `cq_err_event_notifier()`) must call `mlx5_cq_put()`. Call `mlx5_eq_enable()` only after `create_map_eq()`, and `mlx5_eq_disable()` before `destroy_unmap_eq()` (plus `tasklet_disable()` before `kfree(eq)` in `destroy_comp_eq()`). Skip `table->pages_eq` in `create_async_eqs()` / `destroy_async_eqs()` when `MLX5_CAP_GEN(dev, page_request_disable)`. `mlx5e_open_trap()` / `mlx5e_close_trap()` must init in order `netif_napi_add_locked()`, `mlx5e_open_trap_rq()`, `mlx5e_create_trap_direct_rq_tir()`, and tear down in reverse. [F1, F43, F149, F158]
- When `mlx5e_xdp_handle()` returns true in `mlx5e_xsk_skb_from_cqe_mpwrq_linear()` or `mlx5e_xsk_skb_from_cqe_linear()`, test-and-clear `MLX5E_RQ_FLAG_XDP_XMIT` and set `wi->skip_release_bitmap` or `MLX5E_WQE_FRAG_SKIP_RELEASE`; clear `skip_release_bitmap`, `consumed_strides`, and `MLX5E_WQE_FRAG_SKIP_RELEASE` when allocating in `mlx5e_xsk_alloc_rx_mpwqe()`, `mlx5e_xsk_alloc_rx_wqes_batched()`, and `mlx5e_xsk_alloc_rx_wqes()`. [F9, F79]
- Flush `ct_priv->wq` in `mlx5_tc_ct_del_ft_cb()` and destroy it in `mlx5_tc_ct_clean()` before tearing down CT flow tables, mappings, or rhashtables. In `mlx5e_tc_tun_cleanup()`, call `unregister_fib_notifier()` before `flush_workqueue(encap->priv->wq)` and `kvfree(encap)`. In `mlx5_tc_ct_delete_flow()`, check both `!attr->ct_attr.offloaded` and `!attr->ct_attr.nf_ft` before `__mlx5_tc_ct_delete_flow()`. [F14, F15, F32]
- Pair every successful `mlx5e_route_lookup_ipv4/ipv6_get()` with `mlx5e_route_lookup_ipv4/ipv6_put()`. In `mlx5e_tc_tun_create/update_header_ipv4/ipv6()`, null local `encap_header` after `e->encap_header = encap_header` so `free_encap` does not double-free it. Free `mlx5e_encap_entry`, `mlx5e_decap_entry`, and `mlx5e_route_entry` via `kfree_rcu()`, and in `mlx5e_detach_encap_route()`, unlink all `r->encap_entries` with `list_del_init(&e->route_list)` before `mlx5e_route_dealloc()`. [F19, F20, F120, F179]

## API Contracts
- `mlx5_comp_eqn_get()` must check `vecidx < table->max_comp_eqs`. `mlx5_eq_notifier_register()` callbacks run in `atomic_notifier_call_chain()` under `eq->lock` with IRQs disabled and must not sleep. Only `mlx5e_tir_builder_build_packet_merge()` and `mlx5e_tir_builder_build_rss()` support `builder->modify == true` (setting `modify_tir_in` `bitmask`); `inline`, `rqt`, `direct`, and `tls` require `modify == false`. Use `mlx5e_tir_builder_clear()` to zero `builder->in` while keeping `builder->modify`. [F47, F87, F88, F173]
- `mlx5_wqe_eth_seg->swp_*_offset` fields use 2-byte words (byte offset / 2) in `mlx5e_set_eseg_swp()` and `mlx5e_eseg_swp_offsets_add_vlan()`. `mlx5e_dma_push_netmem()` must use `netmem_dma_unmap_addr_set()` paired with `netmem_dma_unmap_page_attrs()` for `MLX5E_DMA_MAP_PAGE` in `mlx5e_tx_dma_unmap()`. [F63, F188]
- `mlx5e_xsk_get_pool()`, `mlx5e_xsk_setup_pool()`, and `mlx5e_xsk_wakeup()` must check `qid < params->num_channels`. Check `mlx5e_xsk_is_pool_sane()` (`headroom`, `chunk_size <= 0xffff`) and `mlx5e_validate_xsk_param()` (`chunk_size` in `[MLX5E_MIN_XSK_CHUNK_SIZE, PAGE_SIZE]`, keeping `rq->mpwqe.page_shift >= 11`). Because XSK pools use `DMA_ATTR_SKIP_CPU_SYNC`, call `xsk_buff_dma_sync_for_cpu()` on RX and `xsk_buff_raw_dma_sync_for_device()` in `mlx5e_xsk_tx()`, which must return `!(budget && work_done)`. [F98, F99, F115, F129, F185]
- `mlx5e_get_next_matching_encap()` (and `valid`/`init` wrappers) puts input `e` and returns a referenced next entry; early loop exits must call `mlx5e_encap_put(priv, e)`. Check header size `<= MLX5_CAP_ESW(priv->mdev, max_encap_header_size)` before `mlx5_packet_reformat_alloc()`. In `mlx5e_tc_tun_parse_geneve_options()` and `mlx5e_gen_ip_tunnel_header_geneve()`, divide byte lengths (`enc_opts.key->len`, `options_len`) by 4 and check `<= (max_tlv_option_data_len + 1) * max_tlv_options`, and check `option_key->length <= max_tlv_option_data_len` before multiplying by 4. Only call `mlx5e_init_fib_work_ipv4/ipv6()` from `mlx5e_tc_tun_fib_event()` on `FIB_EVENT_ENTRY_REPLACE`/`DEL` with matching `info->family`. [F16, F50, F106, F107, F145]

## Error Handling
- Once `mlx5_cmd_use_events()` activates `table->cmd_eq`, teardown/rollback in `create_async_eqs()` / `destroy_async_eqs()` must call `mlx5_cmd_use_polling(dev)` and `mlx5_cmd_allowed_opcode(dev, CMD_ALLOWED_OPCODE_ALL)` before unregistering `cq_err_nb` and `cleanup_async_eq()`. [F3]
- Return conventions: `create_comp_eq()` returns `eqn >= 0` or `-errno`; `mlx5_eqn2comp_eq()` and `mlx5e_flow_get()` return `ERR_PTR` (never `NULL`), whereas `mlx5e_encap/decap/route_get()` return `NULL`; `mlx5_tc_ct_init()` returns `NULL` (accepted by `mlx5_tc_ct_*`), whereas `mlx5e_tc_tun_init()` returns `ERR_PTR`; `mlx5_tc_ct_entry_get()` returns valid pointer, `NULL`, or `ERR_PTR(-EINVAL)` (check both `!entry` and `IS_ERR(entry)`). [F53, F56, F61, F66]
- In `mlx5e_handle_action_trap()`, only call `mlx5e_del_trap_queue(priv)` on error if `open_queue` was true. In `mlx5e_xsk_alloc_rx_mpwqe()`, continue `xsk_buff_alloc()` fallback from `batch` and on error free only `while (--batch >= 0)`. In `mlx5_tc_ct_entry_add_rule()`, pass local `attr` (not `zone_rule->attr`) on `err_rule`. [F5, F10, F113]
- In `mlx5e_attach_encap()`, after `hash_add_rcu()`, any error must set `e->compl_result < 0`, call `complete_all(&e->res_ready)`, and call `mlx5e_encap_put_locked(priv, e)`. On success, `mlx5e_encap_entry.compl_result` is `1` (`mlx5e_encap_dealloc()` checks `> 0`), whereas `mlx5e_decap_entry.compl_result` is `0` (`mlx5e_decap_dealloc()` checks `!d->compl_result`). [F17, F52]

## External Contracts
- When `MLX5_CAP_ETH(mdev, swp_csum_l4_partial)` is set and `skb_is_gso(skb)`, `mlx5e_swp_encap_csum_partial()` must compute the L4 pseudo-header checksum using single-segment length (`gso_size + inner_tcp_hdrlen(skb)` or `gso_size + sizeof(struct udphdr)`). `mlx5e_tc_tun_parse_udp_ports()` requires a full `0xffff` `enc_ports.mask->dst`, and `mlx5e_tc_tun_parse()` must match outer `frag == 0` (mask 1). [F190, F199]

## Known Pitfalls
- Mask `be32_to_cpu(eqe->data.comp.cqn)` and `cq_err.cqn` with `0xffffff` before `mlx5_eq_cq_get()`, and use `1ull << MLX5_EVENT_TYPE_*` in `MLX5_ASYNC_EVENT_MASK` / `gather_async_events_mask()`. [F90, F127]
- `rq->mpwqe.info` strides by `struct_size(rq->mpwqe.info, alloc_units.frag_pages, rq->mpwqe.pages_per_wqe)` for all RQs (even XSK); always use `mlx5e_get_mpw_info(rq, i)`. Never write to `inline_mtts`/`klms`/`ksms` on `rq->mpwqe.umr_wqe` (`struct mlx5e_umr_wqe_hdr`) in `mlx5e_build_umr_wqe()`. Keep `offset = ix * rq->mpwqe.mtts_per_wqe` in `u32` before scaling to `xlt_offset` in `mlx5e_xsk_alloc_rx_mpwqe()`, and cast `(*fifo->pc - *fifo->cc)` to `u16` in `mlx5e_skb_fifo_has_room()`. [F125, F132, F135, F136, F140]
- In `mlx5_tc_ct_entry_update_rule()`, `*old_attr = *attr` does not copy trailing `esw_attr`/`nic_attr`. In `mlx5_tc_ct_rule_to_tuple_nat()`, compute `ip6_offset = (offset - offsetof(struct ipv6hdr, saddr)) / 4` and check `< 4` / `< 8`. Recover `mlx5e_tc_flow` from `e->flows` via `container_of(efi, struct mlx5e_tc_flow, encaps[efi->index])`; in `mlx5e_tc_encap_flows_del()`, clear `MLX5_ESW_DEST_ENCAP_VALID` and `pkt_reformat` before `if (flow_flag_test(flow, SLOW)) continue;`; in `mlx5e_tc_update_neigh_used_value()`, use `time_after((unsigned long)lastuse, nhe->reported_lastuse)`. [F54, F109, F117, F133, F143]
- `mlx5e_dup_tun_info()` must copy `sizeof(*tun_info) + tun_info->options_len`, and `mlx5e_tc_tun_encap_info_equal_options()` must check `test_bit(tun_type, ip_tun_key->tun_flags)`. In `mlx5e_tc_tun_parse_vxlan()`, when matching both VNI and GBP, put GBP in `misc5.tunnel_header_0` and `vni << 8` in `misc5.tunnel_header_1`. [F105, F108]
