# ARM/Rockchip SoC support — drivers

Rockchip peripheral, bus, memory management, and PHY drivers comprising RK3x I2C, SARADC (IIO), IOMMU (v1/v2), mailbox, DesignWare MMC platform glue, eFuse/OTP NVMEM, AXI PCIe RC/EP controllers, and DP/MIPI D-PHY/eMMC/HDMI/USB2 PHYs.

## Architecture & Data Flow
- In `rockchip-iommu.c`, detached `iommu->domain` equals `&rk_identity_domain`, so any path calling `to_rk_domain(iommu->domain)` (`rk_iommu_enable`, `rk_iommu_identity_attach`, `rk_iommu_suspend`, `rk_iommu_resume`) must check `iommu->domain != &rk_identity_domain`. `RK_IOMMU_PGSIZE_BITMAP` (`0x007ff000`) must not exceed 4 MiB (`NUM_PT_ENTRIES * SPAGE_SIZE`) because `rk_iommu_map`/`rk_iommu_unmap` index a single DTE. v2 DTEs/PTEs pack address bits 35:32 into `DTE_HI_MASK1` (11:8) and 39:36 into `DTE_HI_MASK2` (7:4); `rk_mk_pte_v2` must not set v1 cache flags (`RK_PTE_PAGE_FLAGS_MASK`) and addresses must be extracted via `rk_ops->pt_address`. [F183, F220, F221]
- Callers of `rockchip_pcie_parse_dt()` must first set `rockchip->dev` and `rockchip->is_rc` (`true` in RC, `false` in EP). `struct rockchip_pcie` is inside `struct pci_host_bridge` only when `is_rc` is true and inside `struct rockchip_pcie_ep` when false; `pci_host_bridge_from_priv(rockchip)` and `rockchip->reg_base` require `is_rc == true`, and `rockchip->mem_res` requires `!is_rc`. `rockchip_pci_core_rsts` must stay ordered `"pipe"`, `"mgmt"`, `"core"`, `"mgmt-sticky"` for reverse `reset_control_bulk_deassert()`. [F180, F264, F272]
- In `pcie-rockchip-host.c`, `rockchip_pcie_wr_own_conf()` must use 4-byte aligned 32-bit `readl`/`writel` RMW for `size < 4` because `PCIE_RC_CONFIG_NORMAL_BASE` lacks sub-word writes. In `rockchip_pcie_cfg_atu()`, region 0 is reserved for config accesses, MEM/IO use `1 .. offset + reg_no`, and `AXI_WRAPPER_NOR_MSG` uses `reg_no + 1 + offset` with `rockchip->msg_bus_addr` advanced by `(reg_no + offset) << 20`. [F205, F228]
- In `pcie-rockchip-ep.c`, `rockchip_pcie_ep_map_addr()` must check `test_bit(r, &ep->ob_region_map)`, set `ep->ob_addr[r]` and bit `r`, and `rockchip_pcie_ep_unmap_addr()` must verify `addr == ep->ob_addr[r]` and `test_bit(r, &ep->ob_region_map)` before clearing ATU (`rockchip_pcie_clear_ep_ob_atu`), `ep->ob_addr[r] = 0`, and bit `r`. `rockchip_pcie_ep_send_msi_irq()` caches the MSI ATU window at `rockchip_ob_region(ep->irq_phys_addr)` by both `ep->irq_pci_addr` (init `ROCKCHIP_PCIE_EP_DUMMY_IRQ_ADDR`) and `ep->irq_pci_fn`, reprogramming via `rockchip_pcie_prog_ep_ob_atu()` whenever either changes. [F146, F202]
- In `i2c-rk3x.c`, every `REG_CON` write (`rk3x_i2c_start`, non-last reset in `rk3x_i2c_stop`, timeout in `rk3x_i2c_xfer_common`) must preserve `i2c_readl(i2c, REG_CON) & REG_CON_TUNING_MASK`. In `rk3x_i2c_clk_notifier_cb()`, `PRE_RATE_CHANGE` must validate `ndata->new_rate` via `calc_timings()`, calling `rk3x_i2c_adapt_div()` in `PRE_RATE_CHANGE` (reverting on `ABORT_RATE_CHANGE`) when `new_rate > old_rate` and in `POST_RATE_CHANGE` when `new_rate < old_rate`. In `rk3x_i2c_v0_calc_timings()`/`rk3x_i2c_v1_calc_timings()`, clamp `t->bus_freq_hz >= 1000` before `/ 1000`, round up `min_total_div`/`min_low_div`/`min_high_div` with `DIV_ROUND_UP()`, and truncate v0 `max_low_div`. [F198, F200, F251, F252]
- In `i2c-rk3x.c`, `rk3x_i2c_setup()` may use `REG_CON_MOD_REGISTER_TX` only when `msgs[0].len < 4` (3 bytes in `REG_MRXRADDR` + `REG_MRXADDR_VALID(0..2)`). `rk3x_i2c_prepare_read()`/`rk3x_i2c_handle_read()` cap chunks at 32 bytes (`RXBUFFER_BASE`), clearing `REG_CON_LASTACK` when `len > 32` and setting `REG_CON_MOD_RX` when `i2c->processed != 0`. In `rk3x_i2c_fill_transmit_buf()`, when `i2c->processed == 0 && cnt == 0`, byte 0 of `TXBUFFER_BASE` is `((i2c->addr & 0x7f) << 1)` without incrementing `i2c->processed`, so chunk 0 carries at most 31 payload bytes while `REG_MTXCNT` gets `cnt`. [F216, F217, F218]
- In `dw_mmc-rockchip.c`, `priv->drv_clk` and `priv->sample_clk` hold `ERR_PTR` when absent, so callers must check `!IS_ERR()`, and `rockchip_mmc_get_phase()`/`rockchip_mmc_set_phase()` must check `priv->internal_phase`. In `dw_mci_rk3288_execute_tuning()`, the loop must handle `i == priv->num_phases - 1` by `i++` before the 20-degree skip (clamped to `priv->num_phases - 1`), and wrapped ranges must compute signed `int len = ranges[i].end - ranges[i].start + 1` (`if (len < 0) len += priv->num_phases`) and reduce `middle_phase %= priv->num_phases`. [F190, F236, F255]
- In `rockchip_rk3328_efuse_read()`, `rockchip_rk3399_efuse_read()`, and `rk3588_otp_read()`, unaligned reads must round start down and `offset + bytes` up to 4-byte boundaries (`RK3399_NBYTES`/`RK3588_NBYTES`), read `addr_end - addr_start` words into a bounce buffer, and copy from `buf + (offset % 4)`. In `rockchip_saradc.c`, `rockchip_saradc_data::num_channels` must be `<= SARADC_MAX_CHANNELS`, and `rockchip_saradc_trigger_handler()` must index `i_dev->channels[i]` by active-channel bit `i` and `data.values[j]` by a separate sequential counter `j`. [F223, F245, F267]
- In `phy-rockchip-inno-usb2.c`, when a `USB2PHY_PORT_OTG` port has `rport->mode` in `{USB_DR_MODE_HOST, USB_DR_MODE_UNKNOWN}`, `rport->otg_sm_work` and `rport->chg_work` are uninitialized, so `rockchip_usb2phy_init()`, `rockchip_usb2phy_exit()`, and `rockchip_usb2phy_irq()` must guard against both modes. `rockchip_usb2phy_irq()` and `rockchip_usb2phy_otg_mux_irq()` must OR sub-handler returns (`ret |= ...`), routing OTG to `rockchip_usb2phy_otg_mux_irq()` and HOST to `rockchip_usb2phy_linestate_irq()`. Writable `usb2phy_reg` fields passed to `property_enable()` must have `bitend <= 15` (`BIT_WRITEABLE_SHIFT == 16`). [F175, F233, F239]
- In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_otg_port_init()` without an `"extcon"` DT property must sample `utmi_id` via `property_enabled()` and call `extcon_set_state_sync(rphy->edev, EXTCON_USB_HOST, !id)`. Both port inits must set `rport->suspended = true` for `rockchip_usb2phy_power_on()`/`power_off()` gating. On `PHY_STATE_DISCONNECT`, `rockchip_usb2phy_sm_work()` powers off, enables `ls_det_clr`/`ls_det_en`, and returns without rearming `sm_work` until `rockchip_usb2phy_linestate_irq()` disables `ls_det_en` and re-invokes `sm_work`. `rockchip_chg_detect_work()` must re-enable `chg_det.opmode` at `USB_CHG_STATE_DETECTED`, and `rockchip_usb2phy_otg_sm_work()` must reset `chg_state`/`chg_type` on VBUS detach. [F208, F209, F210, F211]
- In `phy-rockchip-inno-hdmi.c`, `inno_hdmi_phy_rk3328_clk_recalc_rate()` must round `vco` to kHz (`DIV_ROUND_CLOSEST((unsigned long)vco, 1000) * 1000`) to match `pre_pll_cfg_table`. `inno_hdmi_phy_power_off()` must clear `inno->tmdsclock = 0` so `set_rate` does not short-circuit on `inno_hdmi_phy_power_on()`. `pre_pll_cfg_table`, `post_pll_cfg_table`, `rk3228_phy_cfg`, and `rk3328_phy_cfg` must end with a zeroed sentinel, with `post_pll_cfg_table` and `phy_cfg_table` sorted by `.tmdsclock` ascending. [F206, F207, F231]
- In `phy-rockchip-inno-dsidphy.c`, `inno_mipi_dphy_timing` tables must be sorted by `.rate` ascending; `inno_dsidphy_mipi_mode_enable()` must clamp `i` to `num_timings - 1`, guard `lpx >= 2` before `lpx -= 2` in `MAX_1GHZ` mode, and loop over all five `FIRST_ADDRESS` banks (`REGISTER_PART_CLOCK_LANE`..`REGISTER_PART_DATA3_LANE`) when writing timing registers `0x05`..`0x12`. In `phy-rockchip-inno-csidphy.c` and `phy-rockchip-dphy-rx0.c`, `hsfreq_ranges` tables must be sorted by `.range_h` ascending, and CSIDPHY callers must check `pwrctl_offset >= 0`, `calib_offset >= 0`, and `reg->valid`. `rockchip_emmc_phy_power()` must return `0` before polling `PHYCTRL_IS_DLLRDY` when `rate == 0`. [F191, F212, F229, F230, F243]

## Synchronization
- In `rockchip-iommu.c`, `rk_iommu_domain::dt_lock` nests outside `iommus_lock`, so never acquire `dt_lock` under `iommus_lock`. Hold `dt_lock` for `rk_dte_get_page_table()` (which must allocate with `GFP_ATOMIC | rk_ops->gfp_flags`), `rk_iommu_map_iova()`, and `rk_iommu_unmap_iova()`; hold `iommus_lock` for all `rk_domain->iommus` and `iommu->node` accesses. [F158, F159, F288]
- In `i2c-rk3x.c`, `rk3x_i2c_xfer_common()` must hold `i2c->lock` across `clk_enable()`, `rk3x_i2c_setup()`, timeout recovery, and `clk_disable()`, unlocking only during transfer wait and re-locking before checking results or exiting; when `polling == true`, call `disable_irq(i2c->irq)` while unlocked before `rk3x_i2c_start()`/`rk3x_i2c_wait_xfer_poll()` and `enable_irq(i2c->irq)` before re-locking. [F149, F162]
- In `pcie-rockchip-ep.c`, `rockchip->perst_gpio` is optional; when non-NULL, `rockchip_pcie_ep_setup_irq()` must set `ep->perst_asserted = true` and `IRQ_NOAUTOEN` on `ep->perst_irq`, `rockchip_pcie_ep_start()`/`stop()` must check `rockchip->perst_gpio` before `enable_irq`/`disable_irq(ep->perst_irq)`, and `rockchip_pcie_ep_stop()` must set `ep->perst_asserted = true` and `disable_irq(ep->perst_irq)` before `cancel_delayed_work_sync(&ep->link_training)`. [F181, F278]
- In `rockchip_saradc_conversion()`, set `info->last_chan = chan` under `info->lock` before `rockchip_saradc_start()`. In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_linestate_irq()` must unlock `rport->mutex` before calling `rockchip_usb2phy_sm_work(&rport->sm_work.work)`. [F167, F214]

## Object Lifetimes
- In `rockchip-iommu.c`, `rk_iommu_of_xlate()` must `devm_kzalloc()` `rk_iommudata` on `&iommu_dev->dev` and call `platform_device_put(iommu_dev)`. `rk_iommu_release_device()` must call `device_link_del(data->link)` (created with `DL_FLAG_STATELESS | DL_FLAG_PM_RUNTIME`). `rk_iommu_shutdown()` must `devm_free_irq()` before `pm_runtime_force_suspend()`. In `rk_iommu_zap_iova()` and `rk_iommu_irq()`, access MMU registers and `clk_bulk_enable()` only when `pm_runtime_get_if_in_use(iommu->dev) > 0`, balanced with `clk_bulk_disable()` and `pm_runtime_put()`. [F142, F143, F170, F269]
- `rockchip_pcie_deinit_phys()` must call `phy_power_off()` only on lanes in `rockchip->lanes_map` (since `rockchip_pcie_host_init_port()` powers off unused lanes) while calling `phy_exit()` on all `MAX_LANE_NUM` PHYs. `rockchip_pcie_suspend_noirq()` must mask `PCIE_CLIENT_INT_MASK` and `PCIE_CORE_INT_MASK` before `rockchip_pcie_wait_l2()` and call `rockchip_pcie_enable_interrupts()` if L2 fails. [F144, F171]
- `rk3x_i2c_probe()` error paths and `rk3x_i2c_remove()` must call both `clk_unprepare(i2c->pclk)` and `clk_unprepare(i2c->clk)` after `clk_notifier_unregister()` even when `pclk == clk`. `rockchip_mbox_isr()` (after `mbox_chan_received_data()`) and `rockchip_mbox_shutdown()` must clear `mb->chans[idx].msg = NULL`. `dw_mci_rockchip_probe()` must unwind runtime PM (`pm_runtime_disable`, `pm_runtime_set_suspended`, `pm_runtime_put_noidle`) on `dw_mci_pltfm_register()` failure, and `dw_mci_rockchip_remove()` must call `pm_runtime_get_sync()` before `dw_mci_pltfm_remove()`. [F148, F151, F152]
- `rockchip_emmc_phy_init()` gets `rk_phy->emmcclk` via non-devm `clk_get_optional()` (setting `NULL` if `IS_ERR()`), released by `clk_put()` in `rockchip_emmc_phy_exit()`. `inno_hdmi_phy_rk3328_init()` must call `nvmem_cell_put(cell)` and `kfree(efuse_buf)` (`!IS_ERR(efuse_buf)`). [F153, F154]

## API Contracts
- In `rockchip-iommu.c`, `rk_table_flush()` takes `count` in 4-byte `u32` entries while `rk_iommu_unmap_iova()`/`rk_iommu_zap_iova()` take `size` in bytes. `rk_iommu_enable_stall()` must do nothing when `!rk_iommu_is_paging_enabled(iommu)`. `rk_iommu_attach_device()` must return `0` when `rk_iommu_from_dev(dev)` is `NULL`. [F185, F270, F303]
- In `pcie-rockchip-host.c`, config accessors (`rockchip_pcie_rd_conf`, `wr_conf`, `rd_own_conf`, `wr_own_conf`, `rd_other_conf`, `wr_other_conf`) return `PCIBIOS_*` codes, zeroing `*val = 0` on read errors and rejecting `PCI_SLOT(devfn) != 0` on the root bus and its immediate child via `rockchip_pcie_valid_device()`. `rockchip_pcie_prog_ob_atu()`/`prog_ib_atu()` take `num_pass_bits` as `bits - 1` (and `prog_ib_atu()` shifts `lower_addr << 8`), whereas `rockchip_pcie_prog_ep_ob_atu()` subtracts 1 internally. In RC mode, `perst_gpio` is requested `GPIOD_OUT_LOW` and held low until `PCIE_CLIENT_LINK_TRAIN_ENABLE` + `PCIE_T_PVPERL_MS`; Gen2 retraining (`PCI_EXP_LNKCTL_RL`) requires Gen1 `PCIE_LINK_UP` and `PCI_EXP_LNKCTL2_TLS_5_0GT` first. [F178, F179, F273, F274, F304]
- In `pcie-rockchip-ep.c`, `rockchip_pcie_epc_features.align` and `rockchip_pcie_ep_align_addr()` use `ROCKCHIP_PCIE_AT_SIZE_ALIGN` (256). `rockchip_pcie_ep_set_bar()`/`clear_bar()` use `BAR_CFG0(fn)` for BARs 0..3 and `BAR_CFG1(fn)` (`b = bar - BAR_4`) for BARs 4..5; 64-bit BARs reject `bar & 1` with `-EINVAL`, clamp size to `>= MIN_EP_APERTURE`, and round up via `1ULL << fls64(sz - 1)`. `rockchip_pcie_ep_send_msi_irq()` treats `interrupt_num` as 1-based (`!interrupt_num || interrupt_num > msi_count` -> `-EINVAL`, payload `(interrupt_num - 1) & data_mask`). [F227, F300, F305, F306]
- `rk3x_i2c_setup()` returns positive consumed msg count (1 or 2) or negative errno, and `rk3x_i2c_xfer_common()` returns `ret < 0 ? ret : num`. Both `econfig` and `otp_config` must set `.add_legacy_fixed_of_cells = true`, and `rockchip_efuse_match` `.data` entries must have `nvmem_reg_read_t` signature. In `phy-rockchip-inno-usb2.c`, `dev_get_drvdata(phy->dev.parent)` yields `struct rockchip_usb2phy *` while `phy_get_drvdata(phy)` yields `struct rockchip_usb2phy_port *`. [F193, F263, F266, F299]
- In `phy-rockchip-inno-hdmi.c`, `inno_write`/`read`/`update_bits`/`poll` take 1-based register indices (multiplying by 4 internally), and `inno_hdmi_phy_get_pre_pll_cfg()` returns `ERR_PTR(-EINVAL)`. In `phy-rockchip-inno-dsidphy.c`, `inno_dsidphy_configure()` requires `PHY_MODE_MIPI_DPHY` and `phy_mipi_dphy_config_validate()`, `inno_dsidphy_power_on()` requires `PHY_MODE_MIPI_DPHY` or `PHY_MODE_LVDS`, and `inno_dsidphy_mipi_mode_enable()` converts `cfg->clk_pre` via `DIV_ROUND_UP(cfg->clk_pre, BITS_PER_BYTE)` vs picosecond fields divided by `t_txbyteclkhs`. [F176, F192, F309]

## Error Handling
- On `rockchip_saradc_conversion()` error, callers must call `rockchip_saradc_power_down(info)` before unlocking `info->lock`, and `rockchip_saradc_trigger_handler()` must call `iio_trigger_notify_done(i_dev->trig)` on all exit paths. [F150, F298]
- `rockchip->vpcie12v` and `rockchip->vpcie3v3` hold `ERR_PTR(-ENODEV)` when absent, so consumers must check `!IS_ERR()`. In `rockchip_pcie_init_port()`/`host_init_port()`, `i` must hold the active PHY count at `goto err_power_off_phy`/`err_exit_phy`, and `err_power_off_phy` must reset `i = MAX_LANE_NUM`. In `rockchip_pcie_ep_init_ob_mem()`, set `err` to a negative errno if `pci_epc_mem_alloc_addr()` returns NULL after `pci_epc_multi_mem_init()`. In `rockchip_usb2phy_otg_port_init()`, do not overwrite `ret` with `property_enabled()`, and jump to `out` on `devm_extcon_register_notifier()` failure. [F172, F174, F177, F238]

## External Contracts
- In `rockchip_saradc_trigger_handler()`, the stack scan buffer `data` passed to `iio_push_to_buffers_with_ts()` must be zero-initialized so inactive channels and padding before `data.timestamp` do not leak stack memory. [F297]

## Known Pitfalls
- In `pcie-rockchip-ep.c`, do not mask unshifted `pci_epf_header` fields with upper-bit masks (`GENMASK(31, 16)`) in `rockchip_pcie_ep_write_header()`; `PCIE_ADDR_MASK` must be 64-bit (`GENMASK_ULL(63, MIN_AXI_ADDR_BITS_PASSED)`); and `ROCKCHIP_PCIE_EP_MSI_CTRL_REG` accesses must use `u32` with `PCI_MSI_FLAGS_*` shifted by `ROCKCHIP_PCIE_EP_MSI_FLAGS_OFFSET` (16). In `rk_dte_pt_address_v2()`, widen `u32 dte` to `u64` before shifting by `DTE_HI_SHIFT2` (32) or `DTE_HI_SHIFT1` (24). [F173, F246, F247, F249]
- In `phy-rockchip-inno-usb2.c`, `rockchip_usb2phy_cfg` arrays must end with `{ .reg = 0 }`, and any valid entry with `.reg == 0` (`rk3576_phy_cfgs`, `rk3588_phy_cfgs`) must be at index 0 for the `do { ... } while (phy_cfgs[index].reg)` loop. In `phy-rockchip-inno-hdmi.c` and `phy-rockchip-inno-dsidphy.c`, keep `RK3328_*` and `RK3228_*` macros in their respective callbacks, and use `u64` casts and `do_div()`/`div_u64()` for `(u64)rate * bus_width / 8`, `vco`, `(u64)fout * _prediv`, `(u64)_fbdiv * fref`, and `PSEC_PER_SEC` divisions. [F232, F241, F256, F257]
