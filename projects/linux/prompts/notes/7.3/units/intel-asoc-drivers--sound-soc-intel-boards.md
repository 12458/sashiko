# INTEL ASoC DRIVERS — sound/soc/intel/boards

This component implements ALSA SoC (ASoC) machine drivers and common board helpers (`sof_board_helpers`, `hda_dsp_common`, and vendor codec helpers) for Intel platforms from Bay Trail/Cherry Trail (SST/Atom) to SOF and HDA-DSP systems, dynamically building DAI links, codec configs, DAPM routes, jack pins, and clocking from ACPI, DMI quirks, and platform IDs.

## Architecture & Data Flow
- In `sof_board_helpers.c`, `calculate_num_links()` and the `link_order` loop in `sof_intel_board_set_dai_link()` must count and populate the exact same enabled BE links in `struct sof_card_private` or `sof_intel_board_set_dai_link()` fails with `-EINVAL` (`idx != num_links`). In `SOF_LINK_ORDER(k1..k7)`, `SOF_LINK_NONE` (0) must only trail active `SOF_LINK_*` entries, and each 4-bit nibble in `ctx->link_id_overwrite` (`SOF_LINK_IDS`) must be `<= 0xF` and aligned 1:1 with `link_order` nibbles because `link_ids` shifts by `SOF_LINK_IDS_SHIFT` every iteration. [F37, F81, F82]
- In `sof_es8336.c`, `sof_es8336_card.num_links` in `sof_es8336_probe()` must equal the total codec, DMIC, HDMI, and HDMI-In links created by `sof_card_dai_links_create()`, and when `dmic_be_num == 0`, `sof_card_dai_links_create()` must add `hdmi_id_offset = 2` to HDMI and HDMI-In link IDs. [F50]
- When creating iDisp HDMI links in `sof_board_helpers.c` (`set_idisp_hdmi_link`), `sof_es8336.c`, and `sof_pcm512x.c`, the HDMI index `i` (`hdmi_id`) must be 1-based (`1..hdmi_num`) when formatting `"iDisp%d"`, `"iDisp%d Pin"`, and `"intel-hdmi-hifi%d"` and checking `hdmi_id == 1`, while indexing `idisp_components[i - 1]` 0-based. In `ehl_rt5660.c`, `HDMI_LINK_START` (3) and `HDMI_LINE_END` (6) in `hdmi_link_init()` must match the `iDisp1..iDisp4` indices in `ehl_rt5660_dailink[]`. [F49, F61]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `sof_es8336.c`, codec software-node properties (`byt_rt5640_add_codec_device_props`, `byt_rt5651_add_codec_device_props`, `device_add_software_node`) must be registered after DMI/`quirk_override` resolution and before `devm_snd_soc_register_card()`. `MAX_NO_PROPS` sizing `struct property_entry props[MAX_NO_PROPS] = {}` must exceed the max `props[cnt++]` assignments on any path by at least 1 for the zeroed sentinel entry. [F42, F64]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcht_es8316.c`, and `bytcr_wm5102.c`, `log_quirks()` must validate multi-bit routing fields in `byt_rt5640_quirk`, `byt_rt5651_quirk`, or `quirk` and reset unrecognized values to a valid default before probe indexes `map_name`, `mic_name`, or `out_map_name`. In `byt_rt5640_quirk_table[]`, specific DMI entries must precede prefix matches (`T100TAF` before `T100TA`, and the generic Insyde catch-all last). [F55, F57]
- In `bytcr_rt5640.c`, `bytcr_rt5651.c`, and `cht_bsw_rt5645.c`, SSP0/SSP2 and AIF1/AIF2 quirks must update BE cpu/codec `dai_name` in probe, SSP-to-AIF DAPM routes in `init`, and 16-bit (SSP0) vs 24-bit (SSP2) TDM slot width / PLL BCLK ratio in `be_hw_params_fixup` and `hw_params` in lockstep. In `bytcr_rt5640.c` (`byt_rt5640_suspend`/`byt_rt5640_resume`) and `bytcr_rt5651.c`, `suspend_pre`/`resume_post` must guard `snd_soc_component_set_jack()` with the same `JDSRC` check as `init` and pass `&priv->jack_data` or `priv->hp_detect` on resume. [F52, F53]
- In `cht_bsw_max98090_ti.c`, when `cht_mc_private.ts3a227e_present` is true, `cht_max98090_headset_init()` creates `ctx->jack` via `snd_soc_card_cht.aux_dev` and `cht_codec_init()` must only register `cht_jack_nb` (not call `snd_soc_card_jack_new_pins()`); when false, clearing `aux_dev` in `snd_cht_mc_probe()` requires setting `num_aux_devs = 0`. [F44]
- In `sof_da7219.c`, when `da7219_codec_init()` sets `DA7219_SYSCLK_MCLK` for a 12.288/24.576 MHz MCLK, it must set `ctx->da7219.pll_bypass = true` so `platform_clock_control()` skips starting/stopping the SRM PLL. In `sof_rt5682.c`, when `ctx->codec_type == CODEC_RT5650` and `ctx->amp_type == CODEC_NONE`, `sof_audio_probe()` must set `ctx->amp_type = CODEC_RT5650` before `sof_card_dai_links_create()` so `ctx->amp_link` is allocated for the AIF2 speaker pipeline. [F45, F48]
- In `sof_cirrus_common.c`, `cs35l41_compute_codec_conf()` compacts present amps into `cs35l41_components[sz]` and `cs35l41_codec_conf[sz]` using `sz` while indexing `cs35l41_name_prefixes[uid]` by ACPI UID (`0..3`), and `cs35l41_set_dai_link()` must be called before `cs35l41_set_codec_conf()`. [F56]
- In `max_98373_hw_params()`, `max_98390_hw_params()`, and `rt1011_hw_params()`, loop index `i` from `for_each_rtd_codec_dais()` must be checked against `ARRAY_SIZE` of `max_98373_tdm_mask`, `max_98390_tdm_mask`, or `rt1011_tdm_mask`, and `max_98373_hw_params()` must check `fls(tx_mask) <= tdm_slots` and `fls(rx) <= tdm_slots`. Any `snd_soc_codec_conf.name_prefix` used with `max_98373_ops` (`max_98373_codec_conf`) must be `<= MAX_98373_PIN_NAME - 5` (11) bytes so `"%s Spk"` in `max_98373_trigger()` does not truncate. [F59, F94]
- In SOF `.late_probe` callbacks (`sof_card_late_probe` in `sof_rt5682.c` and `sof_nau8825.c`, `card_late_probe` in `sof_da7219.c`), codec/amp init (such as disabling `'Left Spk'`/`'Right Spk'` for `CODEC_MAX98373`) must run before `sof_intel_board_card_late_probe()` and before early returns for missing HDMI/iDisp. [F68]

## Synchronization
- In `sof_es8336_probe()` and `sof_audio_probe()` (`sof_pcm512x.c`), `INIT_LIST_HEAD()` on `hdmi_pcm_list`, `INIT_DELAYED_WORK(&priv->pcm_pop_work, pcm_pop_work_events)`, and `snd_soc_card_set_drvdata()` must complete before `devm_snd_soc_register_card()`. [F18]
- In `bytcht_es8316.c`, `priv->speaker_en_gpio` must be requested with `GPIOD_FLAGS_BIT_NONEXCLUSIVE` in `snd_byt_cht_es8316_mc_probe()` and restored to `priv->speaker_en` in `byt_cht_es8316_resume()` (`snd_soc_card.resume_post`, PM `complete()` phase) so it runs after the silead touchscreen `_PS0` method. [F19]
- Links with sleeping/mutex-taking triggers require nonatomic substreams: `sof_es8336_ops` (`sof_8336_trigger` calls `gpiod_set_value_cansleep()`), `max_98373_ops` (`max_98373_trigger` locks `card->dapm_mutex` via `snd_soc_dapm_enable_pin`/`disable_pin`/`sync`), and BYT/CHT front-end DPCM links (`MERR_DPCM_AUDIO`, `MERR_DPCM_DEEP_BUFFER`) on `"sst-mfld-platform"` must use `.nonatomic = true`. [F110, F111, F112]

## Object Lifetimes
- Every `struct acpi_device *adev` from `acpi_dev_get_first_match_dev()` must be held until all uses (`acpi_dev_name()`, `acpi_get_first_physical_node()`, `acpi_dev_gpio_irq_get()`, `acpi_fwnode_handle()`) complete, then released with `acpi_dev_put(adev)` on all paths. Because `acpi_get_first_physical_node()` returns a borrowed `struct device *` (unlike `bus_find_device_by_name()`), drivers storing `priv->codec_dev` from it (`snd_byt_rt5640_mc_probe`, `snd_cht_mc_probe`) must call `get_device()` and balance it with `put_device()` on probe error and in `.remove`. [F1, F2]
- When `fwnode_create_software_node()` and `device_add_software_node()` attach properties to `codec_dev`, `fwnode_handle_put(fwnode)` must be called unconditionally before checking `device_add_software_node()`, and `device_remove_software_node(priv->codec_dev)` must precede `put_device(priv->codec_dev)` on probe error and in `.remove` (`snd_byt_cht_es8316_mc_remove`, `snd_byt_rt5640_mc_remove`). `byt_rt5640_add_codec_device_props()` and `byt_rt5651_add_codec_device_props()` borrow `i2c_dev`, so their callers remain responsible for `put_device(priv->codec_dev)` on error. [F3, F5, F96]
- Non-devm GPIOs acquired on `codec_dev` via `gpiod_get()`/`gpiod_get_optional()` (`spkvdd_en_gpio` in `bytcr_wm5102.c`, `speaker_en_gpio` in `bytcht_es8316.c`, `gpio_speakers` in `sof_es8336.c`) must be released with `gpiod_put()` on probe failure and in `.remove` (never `devm_gpiod_get(codec_dev, ...)`). In `sof_es8336_remove()`, `cancel_delayed_work_sync(&priv->pcm_pop_work)` must precede `gpiod_put(priv->gpio_speakers)`, `device_remove_software_node()`, and `put_device()`. [F6, F7]
- In `bytcr_rt5640.c`, direct `acpi_dev_add_driver_gpios()` calls (`byt_rt5640_get_amcr0f28_settings`, `snd_byt_rt5640_mc_probe` with `BYT_RT5640_JD_HP_ELITEP_1000G2`) must be balanced by `acpi_dev_remove_driver_gpios()` before dropping the device reference on error and in `snd_byt_rt5640_mc_remove()`. [F8]
- Codec DAI link `.exit` callbacks (`sof_es8316_exit`, `sof_rt5682_codec_exit`, `da7219_codec_exit`, `sof_cs42l42_exit`, `sof_nau8825_codec_exit`) must call `snd_soc_component_set_jack(component, NULL, NULL)`. In `hda_dsp_hdmi_build_controls()`, `snd_hdac_display_power(hcodec->core.bus, HDA_CODEC_IDX_CONTROLLER, true)` must be balanced with `snd_hdac_display_power(..., false)` even when `snd_hda_codec_build_controls(hcodec)` fails. [F10, F11]
- Before `clk_set_rate()` on `mclk` in codec `.init` callbacks (`byt_cht_es8316_init`, `sof_rt5682_codec_init`), drivers must call `clk_prepare_enable()` followed by `clk_disable_unprepare()`. In `platform_clock_control()` for PLL-off-MCLK codecs (`bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `cht_bsw_rt5645.c`, `cht_bsw_rt5672.c`), codec sysclk/FLL must be switched to internal RC clock or `ARIZONA_FLL_SRC_NONE` before `clk_disable_unprepare(mclk)` on power-down. In `cht_bsw_max98090_ti.c`, when `QUIRK_PMC_PLT_CLK_0` is set, `snd_cht_mc_probe()` enables `mclk` once, `platform_clock_control()` and `cht_codec_init()` must not disable/reconfigure it, and `snd_cht_mc_remove()` must call `clk_disable_unprepare(ctx->mclk)`. [F12, F13, F14]
- Strings assigned to `snd_soc_dai_link_component.name` (`codec_name`) or `snd_soc_card` `.name`, `.long_name`, or `.components` (`components_string`) must use static or `devm_*` storage, never a probe stack buffer. [F93]

## API Contracts
- `sof_intel_board_get_ctx()` returns `NULL` on `devm_kzalloc()` failure (check `!ctx`, not `IS_ERR(ctx)`), and callers must keep driver-specific `board_quirk` flags in bits `0..7` because bits `8..31` are reserved for `SOF_SSP_PORT_CODEC_MASK` through `SOF_BT_OFFLOAD_PRESENT`. [F21, F83]
- `sof_intel_board_set_dai_link()` allocates `card->dai_link` and sets `ctx->codec_link` and `ctx->amp_link`, but the caller must populate `codecs`/`num_codecs` on both before card registration. Any driver using `sof_intel_board_set_dai_link()` or `sof_intel_board_card_late_probe()` must store the `sof_board_helpers.h` `struct sof_card_private *` in `card->drvdata`. [F15, F92]
- `SOF_SSP_PORT_CODEC()`, `SOF_SSP_PORT_AMP()`, and `SOF_SSP_PORT_BT_OFFLOAD()` take a 0-based SSP index (`0..7`), whereas `SOF_SSP_MASK_HDMI_CAPTURE()` takes a 6-bit SSP port bitmask (`set_hdmi_in_link`). `sof_dai_get_mclk()`, `sof_dai_get_bclk()`, and `sof_dai_get_tdm_slots()` return `< 0` on error or `0` when unconfigured; callers must store results in a signed `int` and reject `<= 0`. [F22, F31]
- In `sof_rt5682_codec_init()`, when `ctx->codec_type == CODEC_RT5650` and `jack` is non-NULL, `snd_soc_component_set_jack()`'s `data` (`extra_jack_data`) must be a non-NULL `int *` of `SND_JACK_*` flags. In `byt_rt5640_init()`, `rt5640_jack_gpio.data` must be `struct byt_rt5640_private *priv` (`byt_rt5640_hp_elitepad_1000g2_jack1_check`) while `rt5640_jack2_gpio.data` must be `struct snd_soc_component *component` (`byt_rt5640_hp_elitepad_1000g2_jack2_check`). [F87, F91]
- In dual SST/SOF BYT/CHT drivers (`bytcr_wm5102.c`, `bytcht_es8316.c`), when `snd_soc_acpi_sof_parent(dev)` is true, probe must set `card->name = SOF_CARD_NAME`, `card->driver_name = SOF_DRIVER_NAME` (`"SOF"`), and `dev->driver->pm = &snd_soc_pm_ops`. [F123]

## Error Handling
- In `byt_rt5640_init()` (`BYT_RT5640_JD_HP_ELITEP_1000G2`), if adding `rt5640_jack2_gpio` fails, `rt5640_jack_gpio` must be freed via `snd_soc_jack_free_gpios(&priv->jack, 1, &rt5640_jack_gpio)`, and `byt_rt5640_exit()` must free both in reverse order. [F9]
- Loops scanning `snd_soc_dai_link` arrays with `COMP_DUMMY()` (`byt_rt5640_dais`, `byt_rt5651_dais`, `byt_cht_es8316_dais`, `byt_wm5102_dais`, `cht_dailink`) must check `dais[i].num_codecs != 0` before dereferencing `dais[i].codecs->name`. Card `late_probe` callbacks (`sof_intel_board_card_late_probe`, `sof_card_late_probe`, `card_late_probe`) must check `idisp_codec` before calling `hda_dsp_hdmi_build_controls()`. [F20, F26]
- In `sof_rt5682.c`, `ctx->rt5682.mclk` is only acquired when both `ctx->rt5682.mclk_en` and `ctx->rt5682.is_legacy_cpu` are true; `sof_rt5682_codec_init()` and `sof_rt5682_hw_params()` must check both before using `mclk`. In `snd_byt_rt5640_mc_probe()` and `snd_byt_rt5651_mc_probe()`, if `devm_clk_get_optional()` returns `NULL` for `pmc_plt_clk_3`, clear `BYT_RT5640_MCLK_EN` / `BYT_RT5651_MCLK_EN` so PLL falls back to bitclock. [F27, F29]
- In `snd_byt_rt5651_mc_probe()`, `devm_fwnode_gpiod_get()` returning `ERR_PTR(-ENOENT)` must reset `priv->ext_amp_gpio` or `priv->hp_detect` to `NULL`. In `snd_byt_wm5102_mc_probe()`, `gpiod_get(codec_dev, "wlf,spkvdd-ena", ...)` returning `ERR_PTR(-ENOENT)` must be converted to `-EPROBE_DEFER`. In `cht_bsw_max98090_ti.c:cht_codec_init()`, `snd_soc_jack_add_gpiods()` failure is non-fatal, so the `QUIRK_PMC_PLT_CLK_0` early exit must `return 0` (not `ret`). [F28, F35, F36]

## External Contracts
- When parsing BIOS ACPI `CHAN` via `snd_soc_acpi_find_package_from_hid()` with format `"NN"` (`snd_byt_rt5640_mc_probe`, `snd_byt_rt5651_mc_probe`), `struct acpi_chan_package` must use `u64` fields (`aif_value`, `mclock_value`) and validate `aif_value` against `1` and `2`. [F58]
- BYT/CHT static DPCM backend links must keep `.name = "SSP2-Codec"` even on SSP0, while `set_ssp_codec_link()` and `sof_pcm512x.c` must format `cpus->dai_name` as `"ssp%d-port"`. When `idisp_codec` is false, iDisp HDMI links in `set_idisp_hdmi_link()`, `sof_pcm512x.c`, and `ehl_rt5660.c:hdmi_link_init()` must still be included in `card->dai_link` bound to `snd_soc_dummy_dlc`. [F66, F118]
- On Comet Lake (`soc_intel_is_cml()`) with `num_codecs == 2`, `rt1011_init()` and `sof_rt1011_codec_conf()` must pass `num_codecs` (2) to register only the first two `WL`/`WR` entries of `realtek_4spk_widgets`, `realtek_4spk_kcontrols`, `rt1011_4spk_routes`, and `rt1011_4spk_codec_confs`. [F67]

## Known Pitfalls
- In `sof_es8336.c`, `priv->speaker_en` has inverted polarity (`false` when `'Speaker Power'` is ON, `true` when OFF) due to `active_low = true` on `enable_gpio0`/`enable_gpio1`; `sof_es8316_speaker_power_event()`, `sof_8336_trigger()`, and `pcm_pop_work_events()` must preserve this convention. [F75]
- Check NHLT link masks (`i2s_link_mask` in `sof_es8336_probe()`, `bt_link_mask` in `skl_hda_get_board_quirk()`) non-zero before computing `fls(mask) - 1` to avoid underflowing `0 - 1` to `ULONG_MAX`. [F84]
- In drivers with signed `int quirk_override = -1` (`bytcht_es8316.c`, `bytcr_rt5640.c`, `bytcr_rt5651.c`, `bytcr_wm5102.c`, `sof_es8336.c`), never define a quirk at `BIT(31)` or higher because `quirk = quirk_override` sign-extends across upper bits of `unsigned long`. Read `pdev->id_entry->driver_data` before `dmi_check_system()` and do not assign default quirks afterward (`sof_audio_probe` in `sof_rt5682.c`, `sof_es8336_probe`), or `sof_rt5682_quirk_table` / `sof_es8336_quirk_table` overrides are clobbered. [F85, F98]
