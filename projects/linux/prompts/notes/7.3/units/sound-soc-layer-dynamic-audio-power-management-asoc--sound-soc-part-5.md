# SOUND - SOC LAYER / DYNAMIC AUDIO POWER MANAGEMENT (ASoC) — sound/soc (part 5)

Contains ASoC platform, DAI, and machine drivers for MediaTek MT8365, Freescale MXS (SAIF/SGTL5000), and Renesas SuperH (SH7760, SIU, HAC, SSI, Migo-R), plus SoundWire utilities (`sdw_utils`) and core ASoC card, AC'97, and ACPI helpers.

## Architecture & Data Flow

- In `struct mt8365_afe_private`, `be_data` (`MT8365_AFE_BACKEND_NUM` elements) is indexed by `dai_id - MT8365_AFE_BACKEND_BASE`, whereas `dai_priv` and `dai_on` (`MT8365_AFE_BACKEND_END` elements) use the unshifted `dai->id`. Every DAI using `mt8365_afe_i2s_ops` or `mt8365_afe_2nd_i2s_ops` must populate `afe_priv->dai_priv[dai->id]` with a `struct mtk_afe_i2s_priv` instance, as `mt8365_dai_i2s_startup/shutdown/prepare()` unconditionally dereference it. [F61, F97]
- In MT8365 backend DAIs (`mt8365_dai_int_adda_prepare()`, `mt8365_dai_i2s_prepare()`, `mt8365_afe_hw_gain1_prepare()`), `be->prepared[substream->stream]` must guard enabling refcounted clocks/blocks (`mt8365_dai_enable_adda_on()`, `mt8365_afe_set_i2s_out_enable()`, `mt8365_afe_enable_apll_associated_cfg()`) and be cleared in `.shutdown`. [F10]
- In `mt8365-afe-pcm.c`, optional offsets/shifts in `struct mtk_base_memif_data` (`mono_reg`, `mono_shift`, `fs_reg`, `fs_shift`, `hd_reg`) and `memif->irq_usage` use `-1` as the unpopulated sentinel (`0` is valid); test `< 0` or `>= 0`, never `!field`. In `mt8365_afe_fe_hw_params()`, program the end register with inclusive `memif->phys_buf_addr + memif->buffer_size - 1` at `reg_ofs_base + 4` for `MT8365_AFE_MEMIF_TDM_IN` (`AFE_HDMI_IN_2CH_END`) and `+ 8` for other FE memifs. [F42, F62]
- In `mt8365_afe_irq_handler()`, mask `AFE_IRQ_MCU_STATUS` with `AFE_IRQ_MCU_EN` before dispatching periods and writing `AFE_IRQ_MCU_CLR` so DSP interrupts sharing the status register are not cleared. `mt8365_dai_configure_dmic()` must set `dmic_data->dmic_channel = dai->symmetric_channels` before `mt8365_dai_enable/disable_dmic()` pass it to `get_chan_reg()`. [F54, F108]
- Every `MT8365_CLK_*` enum (`0 .. MT8365_CLK_NUM - 1`) needs a non-NULL entry in `aud_clks[MT8365_CLK_NUM]`, and every `MT8365_TOP_CG_*` enum must be handled in both `get_top_cg_reg()` and `get_top_cg_mask()`. [F55]
- In `mxs-saif.c`, `mxs_saif_trigger()` must check `saif->state == MXS_SAIF_STATE_RUNNING` before enabling clocks on start and `MXS_SAIF_STATE_STOPPED` before disabling on stop. `master_saif->ongoing` and `master_saif->cur_rate` must be updated in lockstep by `mxs_saif_set_clk()` and `mxs_saif_trigger()`, and `mxs_saif_set_clk()` must return `-EINVAL` if `rate != master_saif->cur_rate` while `master_saif->ongoing` is non-zero. When `master_saif->mclk_in_use` is set (`mxs_saif_get_mclk()`), `mxs_saif_trigger()` must not set/clear `BM_SAIF_CTRL_RUN` on `master_saif`, and `mxs_saif_hw_params()` must skip the `BM_SAIF_STAT_BUSY` check until `mxs_saif_put_mclk()`. [F12, F56, F57]
- In `struct siu_firmware`, fields must match the `"siu_spb.bin"` binary image and `yram0..yram4` must stay contiguous in order because `siu_dai_spbstart()` sets `ydef = fw->yram0` and indexes `ydef[0 .. YRAM_DEF_SIZE - 1]`. `siu_pcm_prepare()` must reject buffers where `buf_bytes % period_bytes != 0` or `xfer_cnt` is outside `1..0x1000000` (`siu_dma_tx_complete()` wraps `cur_period` at `GET_MAX_PERIODS` and `siu_io_work()` submits full `period_bytes` transfers). `siu_dai_put_volume()` must check both `value[0]` and `value[1]` are in `[0, SIU_MAX_VOLUME]` before packing `value[0] | (value[1] << 16)`. [F64, F65, F92]
- In `ssi_hw_params()`, sample widths in `(16, 24]` must be rounded up to `bits = 24` for hardware padding, and `channels` must be validated as an even integer in `[2, 8]` before computing `((channels >> 1) - 1) << CR_CHNL_SHIFT` and `swl = (bits * channels) / 2`. [F94]
- In `asoc_sdw_parse_sdw_endpoints()`, set `soc_end->name_prefix` and `soc_end->include_sidecar` once per `adr_dev` in the outer loop and execute `soc_end++` only at the end of the inner loop after all `continue` filters. When `check_sdca` is true for a multi-endpoint SDCA device, apply `dai_info->quirk` filtering only if `(dai_info->quirk & ctx->mc_quirk)` is non-zero; otherwise call `is_sdca_endpoint_present()` (which returns `1` present, `0` absent, `< 0` error; check `ret < 0` then `!ret`). [F31, F76, F120]
- In `rt_amp_add_device_props()`, `rt711_add_codec_device_props()`, and `rt_sdca_jack_add_codec_device_props()`, `props[]` must keep a trailing zeroed sentinel element (within `SOC_SDW_MAX_NO_PROPS`), and `pdata->bq_params_cnt` must not exceed `RT_AMP_MAX_BQ_REG`. [F71]
- In `snd_soc_acpi_sdw_link_slaves_found()`, require `peripheral->id.unique_id == SDW_UNIQUE_ID(adr)` only when `reported_part_count > 1` (after checking `reported_part_count == expected_part_count`), ignoring `unique_id` when `reported_part_count == 1`. In `snd_soc_acpi_find_package()`, verify `myobj->package.count == pkg_ctx->length` before calling `acpi_extract_package()`. [F68, F81]
- In `soc-card.c`, `snd_soc_card_probe()` and `snd_soc_card_late_probe()` must set `card->probed = 1` only after `card->probe` / `card->late_probe` succeed, and `snd_soc_card_remove()` must check `card->probed` before calling `card->remove(card)` and resetting `card->probed = 0`. [F124]

## Synchronization

- In `mt8365_afe_pcm_dev_probe()`, `afe->regmap`, `afe->memif`, and `afe->irqs` (including `afe->irqs[i].irq_data`) must be initialized before `devm_request_irq()` registers `mt8365_afe_irq_handler()`. `mt8365_afe_enable/disable_apll_tuner_cfg()` acquire `afe_priv->afe_clk_mutex` to serialize `apll_tuner_ref_cnt`, so they and `mt8365_afe_enable/disable_apll_associated_cfg()` must only be called in sleepable context outside `afe_ctrl_lock`. [F19, F126]
- In `mxs-saif.c`, `mxs_saif_trigger()` runs in atomic trigger context and must only call non-sleeping `clk_enable()`, `clk_disable()`, and `udelay()`, relying on `mxs_saif_startup()` / `mxs_saif_hw_params()` to call `clk_prepare()`. [F127]
- In `siu_dai.c`, `siu_dai_prepare()` calls `siu_dai_spbstart()` only when `port_info->play_cap == 0` (before setting the stream bit). In `siu_dai_shutdown()`, call `siu_dai_spbstop()` and `siu_dai_stop()` only when clearing the stream bit leaves `port_info->play_cap == 0` AND both `port_info->playback.rw_flg` and `port_info->capture.rw_flg` are zero. [F15, F21]
- In `camelot_pcm_open()` (`dma-sh7760.c`), assign `cam->rx_ss` or `cam->tx_ss` before `dmabrg_request_irq()` registers `camelot_rxdma()` / `camelot_txdma()`, and call `dmabrg_free_irq()` in `camelot_pcm_close()`. In `hac.c`, `hac_read_codec_aux()` and `hac_ac97_write()` must wrap the `HACTSR` clear and `HACCSDR`/`HACCSAR` writes in `local_irq_disable()` / `local_irq_enable()`, re-enabling IRQs before `udelay(1)` polling. [F22, F131]
- In `soc-card.c`, `jack_new()` must initialize `jack->mutex`, `jack->card`, `jack->pins`, `jack->jack_zones`, and `jack->notifier` before calling `snd_jack_new()` or `snd_soc_jack_add_pins()`. `snd_soc_card_get_kcontrol()` must return `NULL` if `!name`, and look up controls via `snd_ctl_find_id_mixer(soc_card->snd_card, name)` rather than walking `snd_card->controls` unlocked. [F27, F28, F135]

## Object Lifetimes

- `snd_soc_alloc_ac97_component()` and `snd_soc_new_ac97_component()` return `ERR_PTR(-errno)` (never `NULL`); after `device_initialize(&ac97->dev)` in `snd_soc_alloc_ac97_component()`, error paths must use `put_device(&ac97->dev)`, not `kfree()`. `snd_soc_free_ac97_component()` must call `snd_soc_ac97_free_gpio(ac97)` before `device_del(&ac97->dev)`, set `ac97->bus = NULL`, and then call `put_device(&ac97->dev)`. [F2, F36]
- `rt711_add_codec_device_props()`, `rt_sdca_jack_add_codec_device_props()`, and `rt_amp_add_device_props()` must call `fwnode_handle_put(fwnode)` after `device_add_software_node()` to drop the reference from `fwnode_create_software_node()`. [F6]
- `mt8365_afe_disable_main_clk()` must reverse `mt8365_afe_enable_main_clk()` in exact LIFO order (`mt8365_afe_disable_afe_on()`, `mt8365_afe_disable_top_cg(MT8365_TOP_CG_AFE)`, then `MT8365_CLK_TOP_AUD_SEL`). `mt8365_afe_disable_apll_associated_cfg()` must likewise reverse `mt8365_afe_enable_apll_associated_cfg()` in exact LIFO order (APLL tuner cfg, APLL tuner top CG, HD engen, 22M/24M top CG, then `MT8365_CLK_ENGEN1`/`2`). [F8, F9]
- In `mt8365_dai_i2s_startup/shutdown()`, capture in consumer mode (`SND_SOC_DAIFMT_CBP_CFP`) gates `MT8365_TOP_CG_I2S_IN` instead of `clocks[i2s_data->clk_id_in]`, and `mt8365_afe_disable_apll_associated_cfg()` must only run in shutdown if `be->prepared[substream->stream]` is true. In `mt8365_afe_fe_hw_free()`, only call `snd_pcm_lib_free_pages()` and `mt8365_afe_emi_clk_off()` when `!fe_data->use_sram`. [F111, F144]
- Every `device_node` from `of_parse_phandle()` in `mxs_saif_probe()` and `mxs_sgtl5000_probe()` must be released with `of_node_put()` on all paths. `siu_pcm_free()` must call `cancel_work_sync()` on both `capture.work` and `playback.work` before `siu_free_port(port_info)`. `snd_soc_acpi_find_package()` must call `kfree(buffer.pointer)` on every path after `acpi_evaluate_object_typed()` returns `AE_OK`. [F14, F16, F113]

## API Contracts

- `mt8365_afe_fs_timing()` (`afe->memif_fs()`) returns `0..14` or `-EINVAL`; store in a signed `int` and check `fs >= 0` before calling `get_iir_coef()` or shifting into registers. In `mt8365_dai_set_priv()`, `priv_size` must match the source object size (e.g., `sizeof(mt8365_i2s_priv[i])`), not `sizeof(*afe_priv)`, to avoid `memcpy()` out-of-bounds reads. [F43, F96]
- `snd_soc_acpi_find_package()` resets `pkg_ctx->data_valid = false` per device and returns `AE_OK` on failure so scanning continues; `snd_soc_acpi_find_package_from_hid()` must check both `!ACPI_FAILURE(status)` and `ctx->data_valid`. Every `struct snd_soc_acpi_mach` table must end with a zeroed sentinel (`id[0] == 0` and `!comp_ids`) and be non-`const` if `comp_ids` is used, because `snd_soc_acpi_id_present()` writes the matched ID into `machine->id` via `strscpy()`. [F44, F45, F67]
- Machine drivers using `soc_sdw_utils` must set `card->drvdata` to `struct asoc_sdw_mc_private *` (driver data in `ctx->private`), set `ctx->codec_info_list_count = asoc_sdw_get_codec_info_list_count()`, run codec `.init` callbacks before `snd_soc_register_card()`, and call `asoc_sdw_mc_dailink_exit_loop(card)` on remove/error to run `.exit` callbacks and reset `codec_info_list[].dais[].rtd_init_done`. Multi-amp `rtd_init` callbacks (`asoc_sdw_cs_spk_rtd_init()`, `asoc_sdw_ti_spk_rtd_init()`, `asoc_sdw_rt_amp_spk_rtd_init()`) must iterate `for_each_rtd_codec_dais(rtd, i, codec_dai)`. [F47, F78, F102, F118]
- `asoc_sdw_find_dailink()` requires a zero-initialized `struct asoc_sdw_dailink` array large enough for all endpoints (plus sentinel). `asoc_sdw_find_codec_info_acpi()` compares `ACPI_ID_LEN` (`16`) bytes via `memcmp()`, requiring a zero-padded `16`-byte buffer. All `sound/soc/sdw_utils/` exports must use `EXPORT_SYMBOL_NS(..., "SND_SOC_SDW_UTILS")`. [F70, F107, F140]
- `hac_get_codec_data()` returns remaining retries (non-zero on success, `0` on timeout); `hac_read_codec_aux()` checks non-zero for success. Cards binding to `siu_component` must have `card->dev` as a `platform_device` with `pdev->id` in `[0, SIU_PORT_NUM)`. [F85, F100]
- `snd_soc_ac97_gpio_chip` must keep `.can_sleep = 1`. `snd_soc_set_ac97_ops_of_reset()` mutates `ops` in place (requiring non-`const` `ops`), and drivers must call `snd_soc_set_ac97_ops(NULL)` on teardown so `soc_ac97_ops` does not return `-EBUSY`. Jacks that use `snd_soc_jack_add_pins()` must be created with `snd_soc_card_jack_new_pins()`, not `snd_soc_card_jack_new()`. [F132, F134, F138]

## Error Handling & External Contracts

- Capture `platform_get_irq()` in a signed `int` and check `< 0` in `mt8365_afe_pcm_dev_probe()` and `mxs_saif_probe()`. Check every `clk_enable()` in `mxs_saif_hw_params()` and `mxs_saif_trigger()`, and unwind `clk_disable(master_saif->clk)` if `clk_enable(saif->clk)` fails. In `snd_soc_ac97_parse_pinctl()`, pass `PTR_ERR()` of the specific failed GPIO field (`sync_gpio`, `sdata_gpio`, `reset_gpio`) to `dev_err_probe()`. [F34, F35, F75]
- For ALSA UCM compatibility, `card->components` must append `"-sdca"` when `name_prefix` matches `need_sdca_suffix` (`"rt711"`, `"rt713"`) in `asoc_sdw_rt_sdca_jack_rtd_init()`, and format `"rt714"` as `"mic:rt715-sdca"` in `asoc_sdw_rt_dmic_rtd_init()`. [F73]

## Known Pitfalls

- `mt8365_afe_get_cm_update_cnt()` must compute `ch_pair` with ceiling division (`(channel / 2) + 1` when odd) to avoid division by zero when `channel == 1`, and preserve descending fallthrough cases `16..1` in `switch (channel)`. In `mt8365_afe_set_2nd_i2s_asrc()`, only compute/pass `iir_stage = ((u32)coef_count / 6) - 1` to `FIELD_PREP` inside `if (coef)` to avoid `0xffffffff` underflow when `coef_count == 0`. In `mt8365_dai_set_adda_in_enable()` and `mt8365_dai_dmic_shutdown()`, wait `usleep_range(125..150, 300)` after clearing `AFE_ADDA_UL_SRC_CON0` / `DMIC_TOP_CON` before disabling `ADDA_AFE_ON` or `MT8365_TOP_CG_DMIC*_ADC`. [F82, F90, F95, F110]
- In `mxs-saif.c`, clear `BM_SAIF_CTRL_SFTRST` and `BM_SAIF_CTRL_CLKGATE` before writing `SAIF_CTRL`, and reject config changes with `-EBUSY` if `BM_SAIF_STAT_BUSY` is set. In `mxs_saif_trigger()`, perform two 32-bit accesses to `SAIF_DATA` on start, and wait `udelay(USEC_PER_SEC / master_saif->cur_rate)` after clearing `BM_SAIF_CTRL_RUN` before disabling clocks on stop. [F114, F115]
- Preserve intentional fallthroughs in `ssi_hw_params()` and `ssi_set_clkdiv()` `switch` statements. Scale offsets added to `u32 __iomem *` fields (`pram`, `xram`, `yram`, `reg`) in `struct siu_info` by `sizeof(u32)`. Keep `SNDRV_DMA_TYPE_CONTINUOUS` in `camelot_pcm_new()` (`camelot_prepare()` uses `runtime->dma_area` as a physical address). Use `asoc_sdw_startup/shutdown()` in `snd_soc_ops` (never cast `sdw_startup/shutdown_stream()`), and keep `CODEC_NAME_SIZE` at `7` (`soc_sdw_rt_amp.c`) and `6` (`soc_sdw_rt_mf_sdca.c`) so `snprintf()` truncates the DAI suffix. [F84, F98, F101, F105, F130]
