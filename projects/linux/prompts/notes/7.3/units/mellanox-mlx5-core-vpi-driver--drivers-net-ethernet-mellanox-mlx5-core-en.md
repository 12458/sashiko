# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core/en

Implements `mlx5e` NIC and switchdev representor subsystems for RX/TX resources, PTP, QoS, health reporting, representor neigh/bridge/bond plumbing, and TC flower/action offloads.

## Architecture & Data Flow
- Netdev TXQs map to regular `[0, num_channels * num_tcs)`, PTP `[num_regular_queues, num_regular_queues + num_tcs)`, and HTB from `(num_channels + is_ptp) * num_tcs`. In `mlx5e_select_queue`, evaluate `selq->htb_maj_id` (including `selq->is_ptp && mlx5e_use_ptpsq(skb)` fallback) before standalone PTP, and normalize `netdev_pick_tx` via `mlx5e_txq_to_ch_ix` or `mlx5e_txq_to_ch_ix_htb` before adding `up * selq->num_channels`. A 0-based QoS leaf `node_qid` stripes across channel `node_qid % params->num_channels` at `c->qos_sqs[node_qid / params->num_channels]`. [F1146, F1147, F1148, F1160]
- `priv->channels.ptp` may be `NULL` or open with only `MLX5E_PTP_STATE_TX` or `MLX5E_PTP_STATE_RX` in `c->state`; gate `c->ptpsq` and `c->rq` on those bits. For PTP queues, `rq->channel`, `rq->icosq`, and `sq->channel` are `NULL`, so health reporters must null-check them before ICOSQ access or `mlx5e_trigger_napi_icosq`. [F1108, F1109]
- `mlx5e_ptp_alloc_traffic_db` caps power-of-two `db_sz <= 1 << MLX5E_PTP_MAX_LOG_SQ_SIZE` (256) so `u8` indices masked with `ts_cqe_ctr_mask` and `u8` FIFO `cc`/`pc` wrap safely. Timed-out CQEs in `mlx5e_ptpsq_mark_ts_cqes_undelivered` have `pos->inuse` cleared and `undelivered_counter` incremented; `mlx5e_ptp_handle_ts_cqe` must check `nodes[metadata_id].inuse` and decrement `undelivered_counter` if false. [F1131, F1149]
- `rss->tir[tt]` and `rss->inner_tir[tt]` are `NULL` under `MLX5E_RSS_INIT_NO_TIRS` until `mlx5e_rss_obtain_tirn`; check `mlx5e_rss_valid_tir` before `mlx5e_rss_get_tirn`. In `mlx5e_rss_set_hash_fields`, when `inner_ft_support` is set, update both outer and inner TIRs and roll back both on error. `indir->table` is allocated to `max_table_size`, while `mlx5e_calc_indir_rqns`, `mlx5e_rss_get_rxfh`, and `mlx5e_rss_set_rxfh` use power-of-two `actual_table_size` entries (`< num_rqns`) because `ETH_RSS_HASH_XOR` bit-inverts `ilog2(actual_table_size)` bits via `mlx5e_bits_invert`. [F1110, F1127, F1150, F1184]
- In `mlx5e_rqt_init` and `mlx5e_rqt_redirect`, scale `inlen` by `MLX5_ST_SZ_BYTES(rq_vhca)` when `vhca_ids` is non-NULL and `MLX5_ST_SZ_BYTES(rq_num)` when NULL. In `mlx5e_rx_res_xsk_update`, redirect both active RSS contexts (`mlx5e_rx_res_rss_enable`) and the channel's direct RQT (`mlx5e_rx_res_channel_activate_direct`). [F1123, F1188]
- `meter->meters_obj` is `NULL` when `meter->params.mtu != 0`; only dereference it (or call `mlx5e_flow_meter_get_base_id`) when `!meter->params.mtu`. Each ASO object holds 2 meters (`obj_id = base_id + pos / 2`, `idx = pos % 2`), and `mlx5e_tc_meter_modify` uses byte offset `meter->idx * 8` and mask shift `meter->idx ? 0 : 32`. `__mlx5e_flow_meter_alloc`/`free` must move `meters_obj` between `partial_list` and `full_list` at weight `total`/`total - 1` and free it at 0. [F1107, F1140, F1151]
- In `port_buffer.c`, `pbmc_reg` `buffer[0..MLX5E_MAX_NETWORK_BUFFER - 1]` are network buffers and `[MLX5E_MAX_NETWORK_BUFFER..MLX5E_TOTAL_BUFFERS - 1]` are internal, scaled by `port_buff_cell_sz` with `port_buffer_size` zeroed before `mlx5e_port_set_pbmc`. In `select_sbcm_params` and `port_update_pool_cfg`, check `buffer->size == 0` before `buffer->lossy`, excluding zero-sized buffers from `lossless_buff_count` and returning `&sbcm_default`. [F1154, F1159]
- In `mlx5e_rep_changelowerstate_event`, only one `rx_rule` per `bond_metadata` may exist: passive slaves must delete their `rx_rule` via `mlx5e_rep_bond_update(priv, true)` and bond egress ACLs before `mlx5e_rep_bond_update(netdev_priv(netdev), false)` adds the active slave's `rx_rule`. [F1133]
- In `tc_act_can_offload_mirred` / `tc_act_parse_mirred`, enforce `out_count < MLX5_MAX_FLOW_FWD_VPORTS` (and `total_vlan < MLX5_FS_VLAN_DEPTH` in `parse_tc_vlan_action`), check `parse_state->encap` before `netdev_port_same_parent_id` and `netif_is_ovs_master`, and clear `encap` and `mpls_push` in `parse_mirred_encap`. FDB packet/CT-mutating parsers after outputs (`vlan`, `vlan_mangle`, `pedit`, `ct`) must set `esw_attr->split_count = esw_attr->out_count` and `parse_state->if_count = 0`. [F1137, F1156, F1161]
- In `mlx5e_tc_act_stats_add_flow`, keep `curr_counter` and `last_cookie` across the outer `list_for_each_entry(attr, &flow->attrs, list)` loop so split attributes inherit counters and duplicate consecutive cookies (`pedit`) are added once. [F1169]
- In `add_post_rule`, when `!mlx5e_tc_act_sample_is_multi_table`, isolate the default table per `(vport, chain, prio)` via `mlx5_esw_vporttbl_get`, copy `attr` to `post_attr` using `ns_to_attr_sz(MLX5_FLOW_NAMESPACE_FDB)` (not `sizeof(*attr)`, which drops the trailing `esw_attr` flexible array) with `chain = 0`, `prio = 0`, `MLX5_ATTR_FLAG_NO_IN_PORT`, and clear source port match via `mlx5_eswitch_clear_rule_source_port`. [F1142, F1187]

## Synchronization
- `mlx5e_selq_init` must set non-zero defaults (`num_regular_queues = 1`, `num_channels = 1`, `num_tcs = 1`) before publishing `selq->active`. `mlx5e_select_queue` must read `priv->selq.active` via `rcu_dereference_bh` and return 0 if NULL. `mlx5e_qid_from_qos` may read `chs->params` locklessly only when `selq->htb_maj_id != 0` under RCU, and channel/PTP changes must be rejected while `mlx5e_selq_is_htb_enabled(&priv->selq)` is true. [F1077, F1079, F1219]
- Hold `down_write(&res->pkt_merge_param_sem)` in `mlx5e_rx_res_packet_merge_set_param` while updating `res->pkt_merge_param`, non-NULL `res->rss[ix]`, and `direct_tir`s (excluding `res->ptp.tir`), and `down_read` in `mlx5e_rx_res_tls_tir_create`. Protect `ptpsq->ts_cqe_pending_list->tracker_list_head` with `spin_lock_bh(&cqe_list->tracker_list_lock)`. [F1094, F1099, F1124]
- `mlx5e_rx_reporter_err_icosq_cqe_recover` must hold `icosq->channel->icosq_recovery_lock` and deactivate `rq`, `xskrq`, wait for `mlx5e_wait_for_icosq_flush`, and deactivate `icosq` before `mlx5e_reset_icosq_cc_pc`. `mlx5e_tx_reporter_recover_from_ctx` and `mlx5e_tx_reporter_err_cqe_recover` must not lock `priv->state_lock`, and CQE recovery must call `mlx5e_tx_disable_queue` and `mlx5e_wait_for_sq_flush` before resetting SQ indices. [F1097, F1098]
- In `mlx5e_rep_neigh_update`, snapshot `n->ha`, `n->nud_state`, `n->dead`, and `READ_ONCE(nhe->neigh_dev) == n->dev` under `read_lock_bh(&n->lock)` before calling `mlx5e_rep_update_flows`, which requires `ASSERT_RTNL()` and `esw->offloads.encap_tbl_lock`. [F1087, F1232]
- `mlx5e_rep_bond_enslave` and `mlx5e_rep_bond_unslave` require `ASSERT_RTNL()`. `mdata` is refcounted by `mdata->slaves` and freed via `mlx5e_rep_bond_metadata_release` when `slaves == 0` on enslave error or after `list_del(&s_entry->list)` in `unslave` (after resetting vport ingress metadata to 0, unbonding egress ACLs, and updating RX rules). [F1074, F1084, F1216]
- In `mlx5_esw_bridge_switchdev_event`, `SWITCHDEV_FDB_DEL_TO_BRIDGE` for a peer device must call `mlx5_esw_bridge_fdb_mark_deleted` synchronously before queuing `fdb_work`, and because it falls through, compute `add` as `event == SWITCHDEV_FDB_ADD_TO_DEVICE`. [F1089, F1163]
- In `mlx5e_tc_act_stats_del_flow`, hold `handle->ht_lock` for lookup/remove and free via `kvfree_rcu(act_stats, rcu_head)`. In `tc/meter.c`, hold `flow_meters->sync_lock` for meter hashtable/bitmap/list/refcnt ops and `flow_meters->aso_lock` in `mlx5e_tc_meter_modify`. [F1092, F1093]
- In `mlx5_ct_fs_hmfs_matcher_get` and `mlx5_ct_fs_smfs_matcher_get`, retry `refcount_inc_not_zero` after acquiring `fs_hmfs->lock` / `fs_smfs->lock` before creating a matcher, and use `refcount_dec_and_mutex_lock` in `matcher_put`. [F1100]
- In `tc/int_port.c`, `mlx5e_int_port_add`/`remove` require `priv->int_ports_lock`, `mlx5e_tc_int_port_put` must use `refcount_dec_and_mutex_lock`, and `remove` must use `list_del_rcu` and `kfree_rcu_mightsleep`. `mlx5e_tc_int_port_dev_fwd` must read `int_port->ifindex` and `type` before `rcu_read_unlock()`. [F1233, F1234]

## Object Lifetimes
- Create RQTs (pointing to `drop_rqn`) before TIRs and destroy TIRs (`mlx5e_tir_destroy`) before RQTs (`mlx5e_rqt_destroy`). In `mlx5e_rx_res_channels_deactivate`, redirect RSS, direct, and PTP RQTs to `res->drop_rqn` before closing RQs. `mlx5e_rss_cleanup` frees `rss` only when `refcount_dec_if_one(&rss->refcnt)` succeeds (else `-EBUSY`), and `__mlx5e_rx_res_rss_destroy` clears `res->rss[rss_idx] = NULL` only when it returns 0. [F1070, F1198, F1199]
- In `mlx5e_ptp_open_queues` / `close_queues`, open CQs before SQs/RQ and close SQs/RQ before CQs. `mlx5e_ptp_metadata_map_remove` must clear `map->data[metadata] = NULL` when detaching an SKB. In `mlx5e_close_qos_sq` and `mlx5e_qos_close_queues`, clear `qos_sqs[qid]` or `c->qos_sqs` via `rcu_replace_pointer` and `synchronize_rcu()` before closing SQ/CQ and freeing. In `mlx5e_mqprio_rl_cleanup`, destroy all leaf nodes (`rl->leaves_id[tc]`) before `rl->root_id`. [F1073, F1075, F1202, F1203]
- Call `mlx5e_rep_neigh_entry_lookup` under `encap_lock` or `rcu_read_lock()` and release `nhe` via `mlx5e_rep_neigh_entry_release` in non-atomic context; in `mlx5e_get_next_nhe`, hold `next` under RCU before releasing `nhe`. `mlx5e_rep_encap_entry_attach` increments `tun_entropy` and holds `e->nhe`; on error or in `mlx5e_rep_encap_entry_detach`, release both and set `e->nhe = NULL`. [F1067, F1069, F1166]
- `mlx5e_rep_neigh_cleanup` must unregister `netevent_nb` and flush `priv->wq` and `neigh_stats_work` before destroying `encap_lock` and `neigh_ht`. `mlx5e_rep_bridge_cleanup` must cancel `update_work` and unregister `netdev_nb`, `nb_blk`, and `nb` before `destroy_workqueue(br_offloads->wq)` and `mlx5_esw_bridge_cleanup`. `mlx5e_rep_tc_receive` must call `dev_put(tc_priv.fwd_dev)` on both forwarding and `free_skb` paths after `mlx5e_tc_update_skb`. [F1068, F1076, F1090]
- In `sample_modify_hdr_get`, call `mlx5e_mod_hdr_dealloc(mod_acts)` once `mlx5e_tc_match_to_reg_set` succeeds (on both success and `mlx5_modify_header_alloc` error). `mlx5e_tc_sample_unoffload` and `offload` rollback must tear down in strict reverse order: `pre_rule`, `sample_restore_put`, `mapping_remove`, `sampler_put`, then `del_post_rule`. [F1060, F1061]
- `mlx5e_post_meter_add_rule` borrows `act_counter`/`drop_counter` into `attr->counter` and must clear `MLX5_FLOW_CONTEXT_ACTION_COUNT` from `attr->action` before returning. `tc_act_police_offload` must call `mlx5e_tc_meter_put` after `mlx5e_tc_meter_update` when `mlx5e_tc_meter_get` succeeds, and `tc_act_police_destroy` must call `mlx5e_tc_meter_put` twice after `mlx5e_tc_meter_get`. [F1062, F1064]
- `mlx5_ct_fs_hmfs_fill_rule_actions` calls `mlx5_fc_get_hws_action` on `attr->counter`; `ct_rule_update` (and `ct_rule_add` on error) must put `attr->counter` on failure and put the old `hmfs_rule->counter` on success. Clear `int_port->rx_rule = NULL` in `mlx5e_tc_int_port_cleanup_rep_rx` and `handle->rule = NULL` in `mlx5e_tc_post_act_unoffload` after deleting the rule. [F1063, F1065, F1066]

## API Contracts
- `mlx5e_selq_prepare_params` and `mlx5e_selq_prepare_htb` require `selq->state_lock` while `!selq->is_prepared`, must copy `*selq->standby = *selq->active` first, and must pair with `mlx5e_selq_apply` or `mlx5e_selq_cancel`. [F1071, F1122]
- `mlx5e_ptp_poll_ts_cq` must cap its loop to `min(napi_budget, MLX5E_TX_CQ_POLL_BUDGET)` while passing uncapped `napi_budget` to `napi_consume_skb`, and run `mlx5_cqwq_update_db_record` and `wmb()` before pushing to `metadata_freelist` and waking `txqsq`. `mlx5e_ptp_napi_poll` must skip `mlx5e_poll_rx_cq` when `budget == 0` and return `budget` without `napi_complete_done` if any queue is `busy`. [F1095, F1248, F1249]
- In `reporter_tx.c`, `err_ctx.ctx` must match the pointer type expected by `recover` and `dump` (`mlx5e_txqsq *`, `mlx5e_tx_timeout_ctx *`, or `mlx5e_ptpsq *`). In `rep/bond.c` and `rep/bridge.c`, verify `mlx5e_eswitch_rep(dev)` or `mlx5e_eswitch_vf_rep(dev)` before casting `netdev_priv(dev)` to `mlx5e_priv *` and dereferencing `ppriv`. [F1194, F1195]
- Guard SBPR/SBCM calls in `port_buffer.c` with `MLX5_CAP_GEN(mdev, sbcam_reg)`. In `tc_act_post_parse_vlan`, when `MLX5_CAP_GEN(esw->dev, prio_tag_required)` is set, replace `MLX5_FLOW_CONTEXT_ACTION_VLAN_POP` with `add_vlan_prio_tag_rewrite_action`. Every `mlx5e_tc_act` in `tc_acts_fdb`/`nic` must define a non-NULL `parse_action`. [F1212, F1217, F1239]
- `mlx5e_tc_act_pedit_parse_action` expects `act->mangle.mask` (0-bits active) and `val` in network byte order cast to `u32`. In `struct pedit_headers`, `vlan` must immediately follow `eth`, and `pedit_header()` must add `pedit_header_offsets[hdr_type]` and `offset` as `void *` bytes before casting to `u32 *`. `fill_meter_params_from_act` shifts `rate_bytes_ps << 3` for BPS while leaving PPS `rate_pkt_ps`/`burst_pkt` unscaled for `mlx5e_tc_meter_modify` (`<< 10` / `<< 7`). [F1116, F1144, F1145, F1193]
- `mlx5e_tc_int_port_init` returns `NULL` on failure, whereas `mlx5e_tc_int_port_get` returns `ERR_PTR`. `mlx5e_int_port_metadata_free` must mask `id` with `(1 << ESW_VPORT_BITS) - 1` before `mapping_remove`, and `metadata_reg_c_0` matches must use `mlx5e_tc_int_port_get_metadata_for_match`. `mlx5e_tc_int_port_dev_fwd` sets `skb->dev = dev_get_by_index(&init_net, ifindex)` and, for `MLX5E_TC_INT_PORT_EGRESS`, calls `skb_reset_network_header` and `skb_push_rcsum(skb, skb->mac_len)` with `*forward_tx = true`. `mlx5e_tc_sample_skb` must call `skb_push(skb, skb->mac_len)` and set `psample_group.net = &init_net`. [F1102, F1119, F1251, F1252]

## Error Handling
- Check `IS_ERR(rss)` on `mlx5e_rss_init` before storing into nullable `res->rss[i]`. In `mlx5e_ptp_open_tx_cqs` and `mlx5e_rx_res_channels_init`, reset the shared loop variable (`tc = num_tc` or `ix = res->max_nch`) between sequential unwind loops. [F1111, F1168]
- Store `mlx5e_htb_get_txq_by_classid`, `mlx5e_htb_leaf_alloc_queue`, and `mlx5e_select_htb_queue` results in a signed `int` and check `< 0` / `> 0` before narrowing to `u16`. In `ct_fs_smfs.c` and `ct_fs_hmfs.c`, `mlx5_smfs_*` and `mlx5hws_*` create calls return `NULL` on error (check `!ptr`, not `IS_ERR`). In `tc_act_can_offload_mirred`, do not set `extack` on parent-ID mismatch when `parse_attr->filter_dev != priv->netdev`. [F1103, F1104, F1255]

## External Contracts
- `mlx5e_rep_setup_ft_cb` and `mlx5e_rep_indr_setup_ft_cb` only accept `chain_index == 0` with `prio < mlx5_chains_get_prio_range(esw_chains(esw))`, remapping `chain_index` to `mlx5_chains_get_nf_ft_chain` and `prio + 1` on a local copy. [F1120]

## Known Pitfalls
- In `mlx5e_ptp_close_txqsq`, only call `cancel_work_sync(&ptpsq->report_unhealthy_work)` when `current_work() != &ptpsq->report_unhealthy_work`. When `db_sz == 256`, `u8 metadata_freelist->pc` wraps to `0 == cc` at init, so only test `mlx5e_ptpsq_metadata_freelist_empty` after popping or while the TXQ is stopped. [F1072, F1181]
- In `mlx5e_rss_set_rxfh`, changing `rss->hash.hfunc` must set `changed_indir` as well as `changed_hash`, and roll back via `mlx5e_rss_copy` on `mlx5e_rss_apply` error; `mlx5e_rss_copy` must save and restore `to->indir.table` around `*to = *from`. Zero-initialize (`= {}`) stack `struct mlx5e_neigh` and `struct mlx5_mapped_obj` keys so union/padding bytes do not corrupt hash/mapping keys. [F1113, F1114, F1125, F1126]
- Use `mlx5e_rep_to_rep_priv(attr->esw_attr->in_rep)->netdev` (not `priv->netdev`) in `verify_uplink_forwarding`; use `netdev_priv(indr_priv->rpriv->netdev)` for `priv` and `indr_priv->netdev` as filter dev in `mlx5e_rep_indr_offload`; in `parse_mirred`, check `is_duplicated_output_device` before unwrapping `out_dev` and read `netdev_priv(out_dev)` after unwrapping. [F1172, F1173, F1175]
- Pass `(u64)cbs_man` to `MLX5_CALC_CBS(m, e)` to avoid 32-bit shift overflow; in `mlx5e_flow_meter_cir_calc`, check `(s64)m < 0` and use `div64_u64(m, MLX5_CONST_CIR)`; in `update_xoff_threshold`, verify `size >= xoff + max_mtu + port_buff_cell_sz` before subtracting `xoff` and `max_mtu`. [F1177, F1178, F1185]
