# LINUX FOR POWERPC (32-BIT AND 64-BIT) — arch/powerpc/kernel (part 1)

This unit implements core PowerPC subsystems including interrupt/syscall entry and exit preparation, 64-bit lazy IRQ soft-masking and replay, IOMMU TCE table management and DMA mapping, Firmware-Assisted Dump (fadump), Machine Check Exception (MCE) handling, 32/64-bit ELF module relocation, NVRAM partitioning with pstore/kmsg_dump integration, hardware breakpoints, kprobes, legacy serial/ISA I/O, and CPU feature discovery.

## Architecture & Data Flow
- In `mce.c`, `save_mce_event()` increments `mce_nest_count` even when `index >= MAX_MC_EVT`, so `get_mce_event()` (`release == true`) must decrement `mce_nest_count` whenever `index >= 0`. `machine_check_ue_event()` and `machine_check_queue_event()` must decrement `mce_ue_count`/`mce_queue_count` when `index >= MAX_MC_EVT`, and `machine_process_ue_event()` / `machine_check_process_queued_event()` must decrement their counter on every iteration including `ignore_event` continues. In `mce_handle_derror()`, continue iterating `table[]` after the first match to flush all structures (SLB, ERAT, TLB) while populating `mce_err` and `*addr` only from the first match. [F153, F154, F258]
- In `iommu.c`, `tbl->it_map` and `struct iommu_pool` (`start`, `end`, `hint`) use 0-based indices relative to `tbl->it_offset`, whereas hardware TCE callbacks (`tbl->it_ops->set`, `clear`, `get`) take absolute TCE indices (`entry = bitmap_index + tbl->it_offset`). [F221]
- In `module_64.c` and `module_32.c`, sort every `SHT_RELA` section with `sort(..., relacmp, NULL)` before `count_relocs()` or `count_pcpu_relocs()`. In `module_64.c`, `get_got_size()` must init `relocs = 1` to zero-terminate `.mygot` for `got_for_addr()` and count every relocation type calling `got_for_addr()`. `struct ppc64_stub_entry` and `.stubs`, `.mygot`, `.toc` require `>= 8`-byte alignment with `offsetof(struct ppc64_stub_entry, funcdata) == 32`. Bound `.stubs` allocation (`stub_for_addr()`, `setup_ftrace_ool_stubs()`) via `me->arch.stub_count` against `sh_size / sizeof(struct ppc64_stub_entry)` (not a sentinel), and size/claim `me->arch.ool_stubs` using `roundup(me->arch.ool_stub_count * sizeof(struct ftrace_ool_stub), sizeof(struct ppc64_stub_entry)) / sizeof(struct ppc64_stub_entry)`. [F227, F228, F229, F251, F274]
- In `fadump_add_mem_range()`, do not fold adjacent ranges when `start < fw_dump.boot_mem_top`, and if `mrange_info->is_static` is true, return `-ENOSPC` at `max_mem_ranges` instead of `fadump_alloc_mem_ranges()`. In `fadump_free_mem_ranges()`, preserve `name` and `mem_ranges` when `is_static` is true (`mem_range_cnt = 0`), and when false `kfree(mrange_info->mem_ranges)` and zero only fields after `name` (`RNG_NAME_SZ`). In `fadump_append_bootargs()`, call `memblock_reserve(fw_dump.param_area, COMMAND_LINE_SIZE)` when `fw_dump.param_area < fw_dump.boot_mem_top`. [F203, F233, F242]
- In `nvram_create_partition()` and `nvram_remove_partition()`, recompute `nvram_checksum()` and call `nvram_write_header()` whenever `header.signature`, `length`, or `name` changes. Round sizes in `nvram_create_partition()` via `ALIGN(size, NVRAM_BLOCK_LEN) / NVRAM_BLOCK_LEN + 1`; in `nvram_remove_partition()`, merge contiguous `NVRAM_SIG_FREE` entries with `list_for_each_entry_safe()`, `kfree()` merged entries, and reset `prev = NULL` on non-free partitions. Exclude `sizeof(struct err_log_info)` from `part->size` when `part->os_partition == true`. In `oops_to_nvram()`, `KMSG_DUMP_PANIC` must set `panicking = true` and `KMSG_DUMP_EMERG` must return early when `panicking` is true. [F216, F246, F249, F267, F281]
- In `hw_breakpoint_validate_len()` and `set_dawr()`, `hw->hw_len` is `[start_addr, end_addr)` (pre-ISA v3.1 DAWR requires `ALIGN_DOWN(start_addr, SZ_512) == ALIGN_DOWN(end_addr - 1, SZ_512)`), whereas DAWRX `MRD` is `((brk->hw_len + 7) >> 3) - 1`. In `thread_change_pc()`, if any `bp_per_reg` slot has `perf_single_step` set, clear `MSR_SE`, call `__set_breakpoint(i, info)`, and set `info->perf_single_step = false`. In `kprobe_handler()`, on re-entry (`kprobe_running() != NULL`), pair `save_previous_kprobe(kcb)` before `set_current_kprobe()` with `restore_previous_kprobe(kcb)` (not `reset_current_kprobe()`). [F212, F213, F235]
- In `dt_cpu_ftrs.c`, check `-1` and `HV_SUPPORT_NONE`/`OS_SUPPORT_NONE` sentinels before `1UL << bit_nr` in `feat_enable()` / `feat_try_enable_unknown()`, set `f->fscr_bit_nr = -1` in `feat_enable_dscr()` before `feat_enable(f)`, and modify `SPRN_LPCR`/`HFSCR`/`FSCR`/`PCR` before `cpufeatures_setup_finished()` snapshots `system_registers`. In `cpufeatures_cpu_quirks()`, place `0xffffefff` POWER9 DD2.0–2.3 checks before `(version & 0xffff0000) == 0x004e0000`; in `update_tlbie_feature_flag()`, check Nimbus `((pvr & 0xe000) == 0)` before Cumulus `((pvr & 0xc000) == 0)`. Copy matched specs into `the_cpu_spec` in `set_cur_cpu_spec()`/`setup_cpu_spec()` and preserve `old.num_pmcs`, `old.pmc_type`, and `CPU_FTR_PMAO_BUG` when `!s->num_pmcs`. [F196, F215, F240, F241, F299, F301]
- Keep `srr1_to_lazyirq[0] == 0` in `irq_64.c`. In `legacy_serial.c`, `legacy_serial_ports[]` (sized `MAX_LEGACY_SERIAL_PORTS + 1`, index `< MAX_LEGACY_SERIAL_PORTS`) and `legacy_serial_infos[]` are parallel arrays that must be relocated together in `add_legacy_port()`. [F218, F238, F239]

## Synchronization
- In `prep_irq_for_enabled_exit()`, evaluate `exit_must_hard_disable()` once into a local boolean for both `__hard_EE_RI_disable()` and `lazy_irq_pending_nocheck()` recovery; call `trace_hardirqs_on()` before `__hard_EE_RI_disable()`, and on recovery set `PACA_IRQ_HARD_DIS` and `__hard_RI_enable()` before `trace_hardirqs_off()`. [F163, F308]
- In `arch_local_irq_restore()`, test `local_paca->irq_happened == 0` and store `0` to `local_paca->irq_soft_mask` inside an `asm goto` block with `RESTART_TABLE`; wrap `replay_soft_interrupts_irqrestore()` in `irq_enter()`/`irq_exit()` and jump to `again` if `irq_happened != PACA_IRQ_HARD_DIS`. `__replay_soft_interrupts()` must keep `PACA_IRQ_REPLAYING` set in `local_paca->irq_happened` and use `local_paca` (not `get_paca()`). [F166, F169, F312]
- `iommu_range_alloc()` must use `spin_lock_irqsave(&pool->lock, flags)` and switch pool locks with IRQs disabled. In `__iommu_free()`, call `tbl->it_ops->clear(tbl, entry, npages)` before `bitmap_clear()` under `pool->lock`. After `tbl->it_ops->set()`, `iommu_alloc()`, `ppc_iommu_map_sg()`, and `iommu_flush_tce()` must call `tbl->it_ops->flush(tbl)` (if present) then `mb()`. [F170, F171, F298]
- `fadump_process()` must finish `fw_dump.ops->fadump_process()` before setting `elfcorehdr_addr`, and `release_mem_store()` / `fadump_free_elfcorehdr_buf()` must call `vmcore_cleanup()` and set `elfcorehdr_addr = ELFCORE_ADDR_ERR` before freeing memory. Hold `fadump_mutex` across `dump_active`/`dump_registered` checks and `fadump_cleanup()`, `register_fadump()`, `fadump_unregister()`, or `fadump_region_show()`. [F175, F176]
- In NMI real-mode `machine_check_early()`, defer `printk` via `mce_irq_work_queue()` and defer `mce_notifier_list` / `memory_failure()` to `machine_process_ue_event()`. In `mce_power.c`, skip host flushes, PTE walks, and UE recovery when `mce_in_guest()`, and guard `addr_to_pfn()` (which disables IRQs around `__find_linux_pte()`) and `mce_find_instr_ea_and_phys()` with `get_paca()->in_mce < MAX_MCE_DEPTH`. [F317, F318]
- Wrap `__get_user_instr()` in `pagefault_disable()`/`pagefault_enable()` in `wp_get_instr_detail()`. In atomic `oops_to_nvram()` (`spin_trylock_irqsave`) and `nvram_pstore_write()`, use preallocated buffers without `kmalloc()` or blocking locks and abort if `clobbering_unread_rtas_event()`. Use `PTRRELOC()` and `memcpy()` (not `*t = *s`) in early `cputable.c` / `early_32.c` functions. [F320, F329, F332]

## Object Lifetimes
- Pair `free_pages()` on `iommu_alloc()` failure in `iommu_alloc_coherent()`, and call `iommu_free()` before `free_pages()` in `iommu_free_coherent()`. In `iommu_init_table()`, allocate `it_map`, reserve page 0 (if `it_offset == 0`) and `[res_start, res_end)`, init pool locks, and call `iommu_table_clear()` before `iommu_debugfs_add()`. Use `kref_get_unless_zero(&tbl->it_kref)` in `iommu_tce_table_get()`, and call `iommu_debugfs_del(tbl)` before freeing `it_map`/`tbl` in `iommu_table_free()`. Pair `iommu_device_sysfs_add()` before `iommu_device_register()` in `ppc_iommu_register_device()` and reverse in `ppc_iommu_unregister_device()`. [F146, F174, F284, F287]
- Call `get_insn_slot()` in `arch_prepare_kprobe()` only after validations pass; call `free_insn_slot(p->ainsn.insn, 0)` and set `p->ainsn.insn = NULL` in `arch_remove_kprobe()`. In `kprobe_handler()`, every non-`prepare_singlestep()` exit after `set_current_kprobe()` must restore/reset `current_kprobe` and call `preempt_enable()`. [F149, F150]
- Clear `bp_per_reg[i] = NULL` and zero the register in `arch_uninstall_hw_breakpoint()`, and set `t->ptrace_bps[i] = NULL` in `flush_ptrace_hw_breakpoint()`. In `hw_breakpoint_handler()`, hold `rcu_read_lock()`, call `hw_breakpoint_disable()` on entry, and use `perf_event_disable_inatomic()` on error. [F152, F319]
- In `nvram_pstore_read()`, `kfree(buff)` on error and after `kmemdup()` for `PSTORE_TYPE_DMESG`, but set `record->buf = buff` for non-DMESG. Call `early_iounmap(info->early_addr, 0x1000)` and NULL `early_addr` in `ioremap_legacy_serial_console()`. Pair `of_node_get(devnode)` in `isa_bridge_find_late()` with `of_node_put(isa_bridge_devnode)` and `vunmap_range(ISA_IO_BASE, ISA_IO_BASE + 0x10000)` in `isa_bridge_remove()`. [F157, F162, F291]

## API Contracts
- `prep_irq_for_idle()` and `prep_irq_for_idle_irqsoff()` must call `__hard_irq_disable()` and set `PACA_IRQ_HARD_DIS` before checking `lazy_irq_pending()`, returning `false` if pending; call `fini_irq_for_idle_irqsoff()` on wakeup iff `prep_irq_for_idle_irqsoff()` returned `true`. `arch_cpu_idle()` must call `if (!irqs_disabled()) raw_local_irq_disable();` after `ppc_md.power_save()`. In `irq_set_pending_from_srr1()`, dispatch `IRQ_SYSTEM_RESET` immediately via `replay_system_reset()` (`in_nmi = 1`), and call `ppc_msgclr(PPC_DBELL_MSGTYPE)` before setting `PACA_IRQ_DBELL`. [F160, F305, F307, F314]
- Store `hmi_handle_debugtrig()` (`-1`, `0`, `1`) in a signed variable in `hmi_exception_realmode()` and early-return only if `ret >= 0`. `addr_to_pfn()` returns `ULONG_MAX` on failure (`phys_addr == ULONG_MAX` sentinel in `save_mce_event()` / `mce_handle_error()`). [F188, F190]
- Right-shift byte DMA masks and `res_start`/`res_end` by `tbl->it_page_shift` for `iommu_range_alloc()`, `iommu_alloc()`, `iommu_init_table()`, and `iommu_table_reserve_pages()`. Use `IOMMU_PAGE_SIZE(tbl)`, `IOMMU_PAGE_ALIGN(size, tbl)`, and `IOMMU_PAGE_MASK(tbl)` in `iommu.c`. NULL-check optional `tbl->it_ops` (`flush`, `get`, `free`, `tce_kill`) and `fw_dump.ops` (`fadump_get_metadata_size`, `fadump_setup_metadata`, `fadump_cleanup`) callbacks. Check `dev_is_pci(dev)` before `to_pci_dev(dev)`; check `device_is_registered(dev)` (`-ENOENT`) and `!device_iommu_mapped(dev)` (`-EBUSY`) in `iommu_add_device()`; in `iommu_tce_xchg_no_kill()`, call `SetPageDirty(pfn_to_page(*hpa >> PAGE_SHIFT))` when old `*direction` was `DMA_FROM_DEVICE`/`DMA_BIDIRECTIONAL` and `!mm_iommu_is_devmem(...)`. [F182, F183, F195, F199, F262, F325, F336, F337]
- Call `fadump_cma_init()` after `initmem_init()` on `[reserve_dump_area_start, reserve_dump_area_start + boot_memory_size)` with `cma_reserve_pages_on_error(fadump_cma)`, and keep `subsys_initcall_sync(setup_fadump)`. [F340, F342]
- Treat `p <= 0` from `nvram_create_partition()` or `nvram_find_partition()` as failure (`part->index = -1`). Pass a temporary `loff_t` (not `&part->index`) to `ppc_md.nvram_read()`/`nvram_write()` and check `rc <= 0`. In `nvram_init_oops_partition()`, return immediately if `nvram_pstore_init() == 0`. [F185, F186, F346]
- `stub_for_addr()`, `got_for_addr()`, and `do_plt_call()` return `0` on failure (check `!value` and return `-ENOENT`/`-EFAULT`); `get_stubs_size()` must not return negative errno when `__patchable_function_entries` is absent. Check `!kprobe_ftrace(prev)` before reading `prev->ainsn.insn`. Return `1` from `__setup()` and `0` from `early_param()`. Exclude `isa_vaddr_is_ioport()` / `pcibios_vaddr_is_ioport()` in `pci_iounmap()`, use `vmap_page_range()` / `early_ioremap_range()` in `remap_isa_base()`, and keep `EXPORT_SYMBOL(mmu_feature_keys)`. [F179, F180, F191, F248, F289, F330, F333]

## Error Handling
- Call `fadump_free_mem_ranges(mrange_info)` if `krealloc()` fails in `fadump_alloc_mem_ranges()`. In `nvram_init_oops_partition()`, free and NULL `big_oops_buf` if `stream.workspace` fails, and free `oops_buf`, `big_oops_buf`, and `stream.workspace` if `kmsg_dump_register()` fails. [F156, F158]
- In `ppc_iommu_map_sg()`, init `outs->dma_length = 0`, reset failed `s->dma_length = 0` on rollback, and zero trailing `outs->dma_length` when `outcount < incount`; gate TCE alloc failure logs on `!(attrs & DMA_ATTR_NO_WARN) && printk_ratelimit()` at `dev_info`. Set `bp[i] = NULL` before `goto reset` in `hw_breakpoint_handler()` when disabled or single-stepped. In `process_ISA_OF_ranges()`, `inval_range` must map 64K at `phb_io_base_phys` and return `0` if non-zero, else `-EINVAL`. [F184, F198, F244, F338]

## External Contracts
- Bound `nvram_header::name` to 12 bytes; in `nvram_pstore_read()`, if `be16_to_cpu(oops_hdr->version) < OOPS_HDR_VERSION`, header size is `sizeof(u16)`. In `fadump.c`, keep CPU notes as the first `elf_phdr` at `bufp + sizeof(struct elfhdr)`, check `is_fadump_header_compatible()` before `fadump_process()`, and preserve `/sys/kernel/fadump_*` symlinks and `hotplug_ready` (`"1\n"`). Require `capable(CAP_SYS_ADMIN)` (`-EPERM`) for `DEXCR_PR_NPHIE` with `PR_PPC_DEXCR_CTRL_CLEAR_ONEXEC` in `set_dexcr_prctl()`. [F225, F226, F231, F232, F234, F344]

## Known Pitfalls
- Reload `mrange_info->mem_ranges` pointers after `fadump_alloc_mem_ranges()`, and use `time_after(jiffies, time_limit)` in `fadump_free_reserved_memory()`. Use distinct `notifier_block`s in `fail_iommu_setup()`, `unsigned long` loop counters in `iommu_table_reserve_pages()`, and check `tbl->it_page_shift < PAGE_SHIFT` before `PAGE_SHIFT - tbl->it_page_shift`. Use `(value + 0x8000) >> 16` for `R_PPC64_TOC16_HA`/`REL16_HA`, `memmove()` in `dedotify_versions()`, `PTR_ALIGN_DOWN(loc, sizeof(u32))` in `patch_location_16()`, and `- 0x10000` when `addr & 0x8000` in `module_trampoline_target()`. Mask `*ea &= 0xffffffffUL` when `!(regs->msr & MSR_64BIT)` in `wp_get_instr_detail()`. In `add_legacy_pci_port(np, pci_dev)`, read `clock-frequency`/`reg` from `np` and PCI BAR/compat from `pci_dev`. [F202, F206, F230, F259, F261, F264, F268, F269, F270, F271, F275]
