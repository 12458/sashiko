# FIREWIRE SUBSYSTEM — drivers/firewire

The FireWire (`drivers/firewire`) subsystem implements the IEEE 1394 core bus (`firewire-core`), `/dev/fw*` UAPI, OHCI controller driver (`firewire-ohci`), IP over 1394 (`firewire-net`), PCILynx sniffer (`nosy`), and early boot physical DMA (`init_ohci1394_dma`).

## Architecture & Data Flow

- `struct fw_device` and `struct fw_unit` share `fw_bus_type`, so `struct device *` callbacks (`fw_unit_match()`, `show_immediate()`, `show_text_leaf()`, `update_unit()`, `compare_configuration_rom()`) must check `is_fw_unit()` or `is_fw_device()` first. Likewise, `client->resource_xa` stores heterogeneous `struct client_resource` items discriminated by `resource->release`, which callers must check before `to_*_resource()`. [F45, F46]
- `struct fw_transaction` completion paths must branch on `t->with_tstamp` for `union fw_transaction_callback`. In `core-cdev.c`, `complete_transaction()` and `outbound_phy_packet_callback()` must switch on `.without_tstamp.type` for `rsp`/`phy_packet` unions (closing `{ ... }` before the next label), and every queued event struct must embed `struct event` at offset 0 for `kfree()`. [F47, F48, F105, F127]
- Modifying `descriptor_list` under `card_mutex` must adjust `config_rom_length` by `required_space(desc)`, adjust `descriptor_count` by `1 + (desc->immediate > 0 ? 1 : 0)`, and call `update_config_roms()`. Modifying `card->split_timeout.hi`/`.lo` in `handle_registers()` requires calling `update_split_timeout(card)` under `card->split_timeout.lock` (clamping `.cycles` to `[800u, 3u * 8000u]`), and `compute_split_timeout_timestamp()` must wrap the 13-bit cycle count at 8000 cycles/s. [F59, F66, F122]
- Callers of `for_each_fw_node()` or `update_tree()` must increment `card->color`, and `update_tree()` must set `node0->color = card->color` before iterating `node0->ports[i]`. Consecutive generation checks must use `is_next_generation()`. In `bm_work()`, `card->gap_count == GAP_COUNT_MISMATCHED` (`0`) must set `stand_for_root = true`, reset `card->bm_retries = 0`, and pass `short_reset = false` to `reset_bus()`. [F103, F114, F121]
- In `ohci.c`, `ar_context_init()` maps `AR_WRAPAROUND_PAGES` alias pages after `AR_BUFFERS`, so `handle_ar_packet()` must abort if `p.payload_length > MAX_ASYNC_PAYLOAD`, and `ohci_ar_context_work()` must subtract `AR_BUFFERS * PAGE_SIZE` from `p` on wrap-around (`end_buffer_index < ar_first_buffer_index(ctx)`). [F70, F87]
- In `struct descriptor_buffer`, `buffer_size`/`used` are in bytes while `desc->buffer` is a `struct descriptor` array (scale by `sizeof(*d)`). `context_add_buffer()` offsets `desc->buffer_bus` by `(void *)&desc->buffer - (void *)desc` and reserves `0x10` padding bytes in `desc->buffer_size`, so `context_release()` must subtract that offset in `dmam_free_coherent()`. [F135, F136]
- `context_append(ctx, d, z, extra)` encodes hardware count `z` in `branch_address` (`d_bus | z`) and adds `(z + extra) * sizeof(*d)` to `ctx->buffer_tail->used` (`find_branch_descriptor()` uses `d[0]` when `z == 2` and `DESCRIPTOR_BRANCH_ALWAYS`, else `d[z - 1]`). In `context_retire_descriptors()`, set `ctx->current_bus = address` before `ctx->callback()`, and only recycle `old_desc` (`used = 0`, move to `buffer_list` tail) and update `ctx->last` if `callback` returns non-zero. [F57, F72, F89, F113]
- In `at_context_queue_packet()`, `struct driver_data` overlays `&d[3]` with `inline_data` at offset 0 (`sizeof(struct driver_data) <= sizeof(struct descriptor)`). Both `at_context_queue_packet()` and `handle_ar_packet()` must byte-swap `header[3]` only when `tcode_is_block_packet(tcode)`. [F90, F137]
- Staging a Config ROM in `ohci_enable()`/`ohci_set_config_rom()` must save quadlet 0 in `ohci->next_header` and zero `ohci->next_config_rom[0]` before writing `OHCI1394_ConfigROMmap`, restoring `ohci->config_rom[0]`, `OHCI1394_BusOptions`, and `OHCI1394_ConfigROMhdr` in `handle_selfid_complete_event()`. Writing `CSR_BUS_TIME` in `ohci_write_csr()` must preserve `(update_bus_time(ohci) & 0x40)` in `ohci->bus_time`, and `ohci_enable()` must reset `ohci->bus_time_running = false`. [F74, F76]
- `pci_suspend()` must keep `ctx->context.running` set on active iso contexts, and `ohci_start_iso()` must save `ctx->sync`/`ctx->tags` for `ohci_resume_iso_dma()`. In `ohci_quirks[]`, specific device/revision entries must precede `PCI_ANY_ID` entries for the same vendor. Iso/net descriptor and fragment counts (`queue_iso_*()`, `fwnet_tx()`) must use `DIV_ROUND_UP()`. [F78, F111, F126]
- In `fwnet_incoming_packet()`, verify `len > RFC2374_FRAG_HDR_SIZE` and `fg_off + len <= dg_size`, discard existing `pd` on size mismatch or `fwnet_frag_overlap()`, and adjust `peer->pdg_size` on every `fwnet_pd_new()`/`fwnet_pd_delete()` under `dev->lock`. In `fwnet_transmit_packet_done()`, read `ptask->hdr` before `fwnet_make_sf_hdr()` overwrites it, `skb_pull()` the sent payload, and update `ptask->max_payload` on the last fragment. `fwnet_add_peer()`/`fwnet_remove_peer()` must update `dev->peer_count` and call `set_carrier_state(dev)` under `dev->lock`, and `fwnet_probe()` must cap `net->max_mtu` at `4096U`. [F79, F80, F81, F83, F96, F115]

## Synchronization

- `__fw_send_request()` can run in atomic context and synchronously invokes `handle_local_request()` -> `fw_core_handle_request()` -> `fw_address_callback_t`, so inbound request paths (`allocate_request()`, `handle_fcp_region_request()`, `handle_request()`, `fwnet_receive_packet()`) must use `GFP_ATOMIC` and never sleep, and `card->transactions.lock`, `card->split_timeout.lock`, `card->topology_map.lock`, and `phy_receiver_list_lock` must use `spin_lock_irqsave()`. `contend_for_bm()` drops `card->lock` around `fw_run_transaction()` and must re-acquire `spin_lock_irq(&card->lock)` before returning. [F10, F155, F156]
- Writers of `node_id` and `generation` on `fw_card`/`fw_device` must store `node_id` before `smp_wmb()` and `generation`; lockless readers must load `generation` before `smp_rmb()` and `node_id`. Replacing `device->config_rom` in `read_config_rom()` requires `down_write(&fw_device_rwsem)` before freeing `old_rom`, and readers outside `fw_unit` lifetime (`config_rom_show()`, `ioctl_get_info()`, `compare_configuration_rom()`) must hold `fw_device_rwsem` for read. [F22, F34]
- Iso callbacks (`iso_callback`, `iso_mc_callback`) allocate with `GFP_KERNEL` and must only run in sleepable context, never from hardirq or under spinlocks. `fw_iso_context_flush_completions()`, `fw_iso_context_stop()`, `at_context_flush()`, and `ohci_cancel_packet()` must return early if `current_work() == &ctx->work` before calling `disable_work_sync()`/`cancel_work_sync()`. [F29, F159]
- `ohci->lock` is taken in `irq_handler()`, so non-hardirq callers must use `spin_lock_irq*()` and never invoke external callbacks (`packet->callback()`, `fw_core_handle_*()`) while holding it. PHY helpers (`read_phy_reg()`, `write_phy_reg()`, `update_phy_reg()`, `read_paged_phy_reg()`) call `msleep(1)` and require `ohci->phy_reg_mutex` (except in `ohci_enable()`), so never call them in IRQ context or under `ohci->lock`. [F160, F161]
- In `ohci.c:irq_handler()`, exclude `OHCI1394_busReset | OHCI1394_postedWriteErr` from the initial `OHCI1394_IntEventClear` write (clear `postedWriteErr` after reading `PostedWriteAddressHi`/`Lo`). In `handle_selfid_complete_event()`, read `ohci->self_id[0]` before `rmb()`, copy `self_id[]`, issue `rmb()`, and verify `OHCI1394_SelfIDCount` generation matches; before dropping `ohci->lock` to `at_context_flush()` both AT contexts, set `ohci->generation = -1` and stop them, setting `ohci->generation = generation` and clearing `OHCI1394_busReset` only after flushing. [F25, F73, F146]
- In `ar_context_link_page()` and `context_append()`, write all new descriptor fields before `wmb()` and before updating the previous descriptor's `branch_address`. In `ar_search_last_active_buffer()`, separate `READ_ONCE()` reads of `res_count` with `rmb()`, issue a final `rmb()` before reading DMA data, and when `next_res_count == cpu_to_le16(PAGE_SIZE)` (`MAX_AR_PACKET_SIZE > PAGE_SIZE`), peek one descriptor further (`ar_next_buffer_index(next_i)`) before breaking. [F27, F28, F71, F112]
- `fwnet_header_cache()` must write `hh->hh_data` before `smp_store_release(&hh->hh_len, FWNET_HLEN)`. In `nosy.c`, `packet_buffer_get()`/`packet_buffer_put()` must copy data and advance `head`/`tail` (using strict `< end` for wrap-around) before `atomic_sub()`/`atomic_add()` on `buffer->size`. [F38, F98, F179]

## Object Lifetimes

- `fw_device_init()` does not call `device_initialize()` until Config ROM reading finishes, so early error paths must call `fw_device_release(&device->device)` directly; when reviving a `reused` device, it must swap `device->node` and `reused->node` via `fw_node_set_device()` under `card->lock` before `fw_device_release()`. `fw_device_refresh()` must unregister child `fw_unit` devices (`shutdown_unit`) before `read_config_rom()` replaces and frees `device->config_rom`. [F5, F6, F63]
- In `update_tree()`, before `fw_node_put(node1)` frees `node1`, save `next1 = fw_node(node1->link.next)`, repoint `card->root_node`/`card->irm_node` from `node1` to `node0`, and update moved children's parent pointers in `move_tree()`. [F61, F104]
- In `fw_card_add()`, assign `isoc_wq` and `async_wq` (`__free(workqueue_destroy)`) to `card` before `card->driver->enable()`, null them on `card` if `enable()` fails, and call `retain_and_null_ptr()` on success. In `fw_core_remove_card()`, unlink `card` from `card_list` under `card_mutex` before binding `dummy_driver` (preserving `free_iso_context`/`stop_iso`), and destroy `isoc_wq`/`async_wq` only after `fw_destroy_nodes()`, `fw_card_put()`, and `wait_for_completion(&card->done)`. [F7, F8, F139]
- `fw_schedule_bus_reset()`, `fw_schedule_bm_work()`, and `schedule_iso_resource()` must take a ref (`fw_card_get()`/`client_get()`) before queueing delayed work and drop it if queueing returns `false`; `br_work()` reuses its ref when postponing. [F9]
- `handle_exclusive_region_request()` and `handle_fcp_region_request()` must pin `handler->kref` under `rcu_read_lock()` and call `address_callback` outside RCU, while `fw_core_remove_address_handler()` calls `list_del_rcu()`, `synchronize_rcu()`, and waits on `handler->done`. In `handle_fcp_region_request()`, guard `handlers != buffer_on_kernel_stack` before `krealloc_array()` and `kfree()`. [F30, F134]
- In `fw_device_op_release()`, destroy `client->iso_context` before `client->buffer`, and set `client->in_shutdown = true` under `client->lock` before waiting on `tx_flush_wait` and draining `resource_xa`/`event_list`. In `fw_iso_resource_manage()`, if channel allocation succeeds (`c >= 0`) but `manage_bandwidth()` fails, roll back via `deallocate_channel()` and set `*channel = ret`. [F12, F14]
- In `ohci.c`, buffers from `dmam_alloc_coherent()` freed early must use `dmam_free_coherent()`; in `handle_selfid_complete_event()`, only free old `ohci->config_rom` when `ohci->next_config_rom != ohci->config_rom` (aliased on resume). When `at_context_queue_packet()` sets `packet->payload_mapped = true`, it must `dma_unmap_single()` on generation mismatch or once in `ohci_cancel_packet()` (clearing `driver_data->packet = NULL` with `ctx->work` disabled) or `handle_at_packet()`. `pci_remove()` must call `free_irq()` before `pci_free_irq_vectors()`. [F16, F18, F138, F142]
- `fwnet_send_packet()` and TX completion callbacks coordinate `ptask` freeing under `dev->lock` via `ptask->outstanding_pkts` and `ptask->enqueued`. In `fwnet_incoming_packet()`, call `skb_get(pd->skb)` before `fwnet_pd_delete(pd)` on completed datagrams. `__fwnet_broadcast_stop()` only tears down `broadcast_rcv_buffer` when `broadcast_state != FWNET_BROADCAST_ERROR` and resets `broadcast_rcv_context`, `broadcast_rcv_buffer_ptrs`, and `broadcast_state = FWNET_BROADCAST_ERROR`. In `nosy.c:remove_card()`, use `list_del_init(&lynx->link)` and `lynx_put(lynx)` (not `kfree()`). [F19, F20, F21, F143]

## API Contracts

- When `release_client_resource()` gets a non-NULL `return_resource`, it skips `resource->release()` and transfers ownership of the resource and its inner refs (`r->request`, `r->card`) to the caller. `ioctl_send_response()` must reject non-FCP responses where `a->length != fw_get_response_length(r->request)`. [F3, F94]
- In `__fw_send_request()`, `fw_send_request*()`, and `fw_run_transaction()`: lock requests must use `TCODE_LOCK_MASK_SWAP`..`TCODE_LOCK_VENDOR_DEPENDENT` (not `TCODE_LOCK_REQUEST`); `TCODE_STREAM_DATA` must use `fw_stream_packet_destination_id()`; `TCODE_WRITE_QUADLET_REQUEST` requires a valid 4-byte `payload`; and non-local payloads `> 8` bytes must be DMA-mappable (not stack/vmalloc) and live until callback completion. [F53, F54, F55, F168]
- `fw_iso_resource_manage()` reports errors in `*channel` (`< 0`) and zeroes `*bandwidth` if unchanged. For `FW_ISO_CONTEXT_RECEIVE`, `ioctl_create_iso_context()` must reject `header_size < 4` or `& 3`, and `ioctl_queue_iso()` must reject `header_length == 0` or `% ctx->header_size != 0`. `show_immediate()`/`show_text_leaf()` must check `if (!buf)`, and `ohci_enable()` must check `if (config_rom)` (NULL on `pci_resume()`). Non-DMA async completions in `ohci.c` must set `timestamp = cycle_time_to_ohci_tstamp(get_cycle_time(ohci))`. `fwnet_tx()` must call `skb_share_check()`, and RX SKBs in `net.c` must `skb_reserve(skb, LL_RESERVED_SPACE(net))`. [F43, F44, F49, F75, F125, F177, F178]

## Error Handling

- `fw_run_transaction()`, `read_rom()`, `reread_config_rom()`, and `read_config_rom()` return `RCODE_COMPLETE` (`0`) on success and positive `RCODE_*` on failure (check `!= RCODE_COMPLETE`, not `< 0`). In `ohci.c`, `read_phy_reg()`/`write_phy_reg()`/`update_phy_reg()`/`read_paged_phy_reg()` return negative errnos (check `< 0` in signed `int` before masking/bool conversion). Callers of `fw_card_read_cycle_time()` ignoring its return value must zero-initialize `*cycle_time` (unchanged on `-ENODEV`). [F39, F42, F51]

## External Contracts

- New `FW_CDEV_VERSION_*` features in `core-cdev.c` must bump `FW_CDEV_KERNEL_VERSION`. `dispatch_ioctl()` must check `_IOC_SIZE(cmd) <= sizeof(union ioctl_arg)` and `memset(&buffer, 0, sizeof(buffer))`. Reject `!client->device->is_local` with `-ENOSYS` in descriptor/PHY ioctls and offsets `< CSR_REGISTER_BASE + CSR_CONFIG_ROM_END` with `-EACCES` in `ioctl_send_broadcast_request()`. Convert `__u64` user pointers with `u64_to_uptr()`/`uptr_to_u64()`, copy only 36 bytes to `a->bus_reset` in `ioctl_get_info()`, and keep the second iovec after `sizeof(*rsp)` for `rsp->length <= 4` in `complete_transaction()`. [F67, F93, F186, F187, F189]
- In `core-iso.c`, split 64-bit `channels_mask` at 32 (`CSR_CHANNELS_AVAILABLE_HI`/`LO`), map `channel` `0..31` to `cpu_to_be32(1 << (31 - channel))` in `manage_channel()`, and fall through to `default:` (`retry--`, `channel--`) when `RCODE_COMPLETE` fails CAS. [F109, F119]

## Known Pitfalls

- Use `1ULL << channel` for 64-bit channel masks, cast high 32-bit words to `u64` before `<< 32` for 48-bit CSR offsets/64-bit GUIDs, and use `u64`/`div_u64()` in `isoc_cycles_to_jiffies()`. Subtract 1 (`ci.p - 1 + value`) when resolving relative ROM offsets after `fw_csr_iterator_next()`. In `ioctl_queue_iso()`, set `transmit_header_bytes = u->header_length` only for `FW_ISO_CONTEXT_TRANSMIT` (`0` for receive). Check `device->irmc && device->max_rec >= 8` and `BC_IMPLEMENTED` before writing `CSR_BROADCAST_CHANNEL` in `set_broadcast_channel()`, and OR `PHY_INT_STATUS_BITS` into `clear_bits` when `addr == 5` in `update_phy_reg()`. [F69, F85, F106, F116, F118, F120, F152]
- `get_cycle_time()` must not sleep, must return 0 if `has_reboot_by_cycle_timer_read_quirk(ohci)`, and must use `cycle_timer_ticks()` and check `diff01 <= 0 || diff12 <= 0` before dividing. Skip the coherent descriptor page in `sync_it_packet_for_cpu()`, check/poll `OHCI1394_HCControl_LPS` before SClk/PHY accesses in `pci_remove()`/`ohci_enable()`, use unaligned accessors on `union fwnet_hwaddr`, clear `LINK_INT_STATUS` before `PCI_INT_STATUS` in `nosy.c:irq_handler()`, and call `init_ohci1394_enable_physical_dma()` only after `init_ohci1394_wait_for_busresets()`. [F97, F123, F141, F147, F150, F170, F174]
