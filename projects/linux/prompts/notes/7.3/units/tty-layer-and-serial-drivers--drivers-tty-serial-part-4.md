# TTY LAYER AND SERIAL DRIVERS — drivers/tty/serial (part 4)

This component contains the `serial-base` bus layer (`serial_base_bus.c`, `serial_base.h`) and UART drivers for OMAP, Actions Semi Owl, Intel EG20T PCH, Microchip PIC32, PowerMac Zilog ESCC, Intel PXA, Renesas RSCI, StrongARM SA1100, Broadcom SB1250 DUART, NXP SC16IS7xx, and NXP SCCNXP.

## Architecture & Data Flow
- On `serial_base_bus_type`, `serial_ctrl_device` and `serial_port_device` are distinguished by `dev->type` (`&serial_ctrl_type` vs `&serial_port_type`); bus callbacks must check `dev->type` before calling `to_serial_base_ctrl_device()` or `to_serial_base_port_device()`. [F121]
- In `pmac_zilog.h` (`to_pmz(p)`) and `pxa.c` (`serial_pxa_pops`), `struct uart_port *` is downcast via a direct C pointer cast, so `struct uart_port port` must remain at offset 0 of `struct uart_pmac_port` and `struct uart_pxa_port`. [F114, F115]
- In `omap-serial.c`, `serial_omap_restore_context()` reprograms registers from `struct uart_omap_port` shadow fields (`dll`, `dlh`, `ier`, `fcr`, `mcr`, `scr`, `efr`, `lcr`, `mdr1`, `wer`), so persistent hardware writes must update the matching shadow field. In `serial_omap_rlsi()`, read `serial_in(up, UART_RX)` whenever `lsr & UART_LSR_DR` is set before the `uart_handle_break(&up->port)` early return so RX does not stall. [F60, F96]
- When `SER_RS485_ENABLED` is set in `serial_omap_stop_tx()`, if `OMAP_UART_SCR_TX_EMPTY` is not yet set in `up->scr`, set it in `up->scr` and `UART_OMAP_SCR` and leave `UART_IER_THRI` enabled, only clearing `OMAP_UART_SCR_TX_EMPTY`, toggling `up->rts_gpiod`, and disabling `UART_IER_THRI` on the next THR IRQ. In `calculate_baud_abs_diff()`, clamp `n = port->uartclk / (mode * baud)` to `1` when `0`. [F63, F106]
- In `sc16is7xx_i2c_probe()` and `sc16is7xx_spi_probe()`, copy `sc16is7xx_regcfg` per channel with `sc16is7xx_regmap_name(i)` and `sc16is7xx_regmap_port_mask(i)` (plus `SC16IS7XX_SPI_READ_BIT` in SPI `read_flag_mask`). `sc16is7xx_setup_irda_ports()` must check `"irda-mode-ports"` count `<= SC16IS7XX_MAX_PORTS` and each `irda_port[i] < s->devtype->nr_uart`. `sc16is7xx_gpio_init_valid_mask()` requires `nr_gpio <= BITS_PER_LONG`, and `sc16is7xx_devtype::name` (`char[10]`) must be `<= 9` bytes. [F58, F79, F118, F123]
- In `sb1250-duart.c`, `sbd_probe_duarts()` only sets `sport->duart` for the first `max_lines` ports, so `sbd_console_setup()`, `sbd_init()`, and `sbd_exit()` must check `sport->duart != NULL`. Shared `sport->memctrl` accesses must index the channel as `(uport->line) % 2`, and `sport->tx_stopped` must track `M_DUART_TX_DIS` (`1`) and `M_DUART_TX_EN` (`0`) writes to `R_DUART_CMD` so `sbd_set_termios()` and `sbd_console_write()` restore TX state. [F51, F67, F83]
- In `sa1100.c`, `sa1100_start_tx()` and `sa1100_stop_tx()` gate TX in `sa1100_int()` via `UTSR0_TO_SM(UTSR0_TFS)` in `sport->port.read_status_mask`; `sa1100_set_termios()` must preserve `UTSR0_TO_SM(UTSR0_TFS)`, and every `UART_GET_UTSR0(sport)` read in `sa1100_int()` must be masked with `SM_TO_UTSR0(sport->port.read_status_mask) | ~UTSR0_TFS`. [F69, F104]
- In `pch_uart_hal_set_fifo()`, check `if (trigger & ~PCH_UART_FCR_RFTL) return -EINVAL;` before indexing `trigger_level_*`, and cache `UART_FCR` in `priv->fcr` and `priv->trigger_level` so `pch_uart_hal_fifo_reset()` preserves and restores `priv->fcr`. In `pch_uart_hal_read()`, re-read `lsr = ioread8(priv->membase + UART_LSR)` in the `for` step while incrementing `i` only on `buf[i++] = rbr`. [F71, F100, F113]
- In `pmac_zilog.c`, console ports (`ZS_IS_CONS(uap)`) must not call `__pmz_startup(uap)` in `pmz_startup()` or clear `RxENABLE`/`TxENABLE` or call `pmz_set_scc_power(uap, 0)` in `pmz_shutdown()`. In `pmz_transmit_chars()`, paths not calling `write_zsdata()` (except `ZS_IS_CONS(uap)` when `!(status & Tx_BUF_EMP)`) must jump to `ack_tx_int` (`RES_Tx_P` to `R0`), whereas `write_zsdata()` paths must return without `RES_Tx_P`. [F102, F143]
- In `owl-uart.c`, `owl_uart_receive_chars()` must clear `OWL_UART_CTL_TRFS_TX` in `OWL_UART_CTL` before polling `OWL_UART_STAT_RFEM`, and `owl_uart_port_write()` must set `OWL_UART_CTL_TRFS_TX` before polling `OWL_UART_STAT_TRFL_MASK` and restore `old_ctl`. [F72]

## Synchronization
- In `pmz_interrupt()`, Z8530 `R3` is only readable on Channel A (`uap_a = pmz_get_port_A(uap)`): lock `uap_a->port.lock` to read `R3` and service A, unlock before pushing flip buffers, then lock `uap_b->port.lock` (`uap_a->mate`) for B. `pmz_load_zsregs()` requires `uap->port.lock` held with IRQs disabled and TX idle; runtime `uap->curregs[]` updates must call `pmz_maybe_update_regs(uap)` to defer via `PMACZILOG_FLAG_REGS_HELD` while `ZS_TX_ACTIVE(uap)`. In `pmz_shutdown()`, call `pmz_interrupt_control(uap, 0)` under `uap->port.lock`, unlock before `free_irq()`, and clear `PMACZILOG_FLAG_IS_OPEN` under `uap->port.lock` before `pmz_set_scc_power(uap, 0)`. [F21, F23, F24]
- In `sccnxp.c`, chip-wide `s->lock` (not `port->lock`) protects `s->imr`, `s->opened[]`, and multi-port register accesses (`sccnxp_enable_irq()`, `sccnxp_disable_irq()`, `sccnxp_set_bit()`, `sccnxp_handle_events()`). In `sccnxp_remove()`, stop the IRQ or timer via `devm_free_irq()` or `timer_delete_sync(&s->timer)` before removing ports, unregistering the driver, and disabling `s->regulator`. [F25, F26]
- In `sa1100.c`, `sa1100_mctrl_check()` requires `sport->port.lock` held, while `sa1100_shutdown()` and `sa1100_set_termios()` must call `timer_delete_sync(&sport->timer)` unlocked. In `omap-serial.c`, `wait_for_xmitr()` must save `UART_LSR_BI` in `up->lsr_break_flag` and `MSR_SAVE_FLAGS` in `up->msr_saved_flags`, and `serial_omap_console_write()` must call `check_modem_status(up)` if `up->msr_saved_flags` is non-zero. [F27, F28]
- In `pic32_uart.c`, `pic32_uart_irqtxen()` must gate `enable_irq()`/`disable_irq_nosync(sport->irq_tx)` on `sport->enable_tx_irq` under `port->lock`. In `pic32_uart_startup()`, set `IRQ_NOAUTOEN` on `irq_fault`, `irq_rx`, and `irq_tx` before `request_irq()`, and only call `enable_irq(sport->irq_rx)` after `pic32_uart_en_and_unmask(port)`. [F30, F31]
- In `pch_uart.c`, when `priv->use_dma` is set, disable `PCH_UART_HAL_RX_INT | PCH_UART_HAL_RX_ERR_INT` before `dma_handle_rx()` and re-enable in `pch_dma_rx_complete()` (or in `pch_uart_interrupt()` if `dma_handle_rx()` returns `0`), and gate TX DMA on `priv->tx_dma_use` until `pch_dma_tx_complete()` clears it and re-enables `PCH_UART_HAL_TX_INT`. `dma_handle_tx()` runs under `priv->port.lock` in hardirq context and must use `GFP_ATOMIC`. [F33, F52, F154]
- In `pch_console_write()`, `serial_omap_console_write()`, `owl_uart_port_write()`, and `serial_pxa_console_write()`, use `uart_port_trylock_irqsave()` when `oops_in_progress` is non-zero and only unlock if `locked` is true. [F160]

## Object Lifetimes
- After `serial_base_device_init()` in `serial_base_ctrl_add()` or `serial_base_port_add()`, error paths must call `put_device()` (not `kfree()`) so `.release` drops `dev->of_node`. Free `port->port_id` with `ida_free(&ctrl_dev->port_ida, ...)` on failure and in `serial_base_port_device_remove()`, which must run while `port_dev->port` and parent `ctrl_dev` remain valid and before `serial_base_ctrl_device_remove()`. [F1, F2, F163]
- In `sc16is7xx_remove()` and `sc16is7xx_shutdown()`, cancel `one->ms_work` and (when `s->polling`) `s->poll_work` via `kthread_cancel_delayed_work_sync()` and flush `s->kworker` before stopping `s->kworker_task` or disabling `s->clk`. [F4]
- In `sb1250-duart.c`, `sbd_request_port()` reserves `duart->mapctrl` only when `refcount_read(&duart->map_guard) == 1`, and `sbd_release_port()` / error paths release it only when `refcount_dec_and_test(&duart->map_guard)` is true. After `iounmap()`, `sbd_release_port()` and `sbd_map_port()` must clear `uport->membase = NULL` (and `sport->memctrl = NULL` in `sbd_release_port()`). [F5, F6]
- In `pch_uart.c`, every return path in `pch_request_dma()` must call `pci_dev_put(dma_dev)` and release `priv->chan_tx` on RX failure; `pch_free_dma()` must clear `chan_tx = NULL`, `chan_rx = NULL`, `rx_buf_virt = NULL`, and `rx_buf_dma = 0`; and `pch_uart_set_termios()` must only enable `UART_MCR_AFE` when `priv->fifo_size == 256` (UART0). [F8, F148]
- In `serial_omap_startup()`, if `up->wakeirq` is non-zero and `dev_pm_set_dedicated_wake_irq()` fails, call `free_irq(up->port.irq, up)`, and `serial_omap_shutdown()` must call `dev_pm_clear_wake_irq(up->dev)`. In `serial_omap_probe()` (`err_add_port`) and `serial_omap_remove()`, run `pm_runtime_put_sync()`, `pm_runtime_disable()`, `cpu_latency_qos_remove_request(&up->pm_qos_request)`, and `device_init_wakeup(..., false)`. [F9, F10]
- Under `CONFIG_PPC_PMAC`, `pmz_detach()` must only call `macio_release_resources(uap->dev)` when `PMACZILOG_FLAG_RSRC_REQUESTED` is set. In `owl_uart_probe()`, reset `owl_uart_ports[pdev->id] = NULL` if `uart_add_one_port()` fails and in `owl_uart_remove()`. In `pic32_uart_probe()`, if `uart_console_registered(port)` is true after `uart_add_one_port()`, call `clk_disable_unprepare(sport->clk)`. [F12, F13, F14]
- In `sccnxp_probe()` and `sccnxp_remove()`, `s->regulator` can hold a non-deferral `ERR_PTR`; once `regulator_enable(s->regulator)` succeeds when `!IS_ERR(s->regulator)`, every error path (`err_out`) and `sccnxp_remove()` must call `regulator_disable(s->regulator)` guarded by `if (!IS_ERR(s->regulator))`. [F15, F45]

## API Contracts
- `serial_base_ctrl_device_remove()` and `serial_base_port_device_remove()` must accept `NULL`. `serial_base_match_and_update_preferred_console()` must treat `-ENOENT` from `match_devname_and_update_preferred_console()` as `0`. Drivers on `serial_base_bus_type` must have `drv->name` prefixed with `"ctrl"` or `"port"`. [F35, F105, F162]
- `sc16is7xx_probe()` must check all `regmaps[0 .. devtype->nr_uart - 1]` with `IS_ERR()` before dereferencing `regmaps[0]`, and `devtype->nr_uart` must not exceed `SC16IS7XX_MAX_PORTS`. `sc16is7xx_set_baud()` callers must clamp `baud` to `[port->uartclk / 16 / 4 / 0xffff, port->uartclk / 16]`. `SC16IS7XX_TCR_RX_HALT(words)` and `SC16IS7XX_TCR_RX_RESUME(words)` take character counts `0..60` with halt strictly greater than resume. [F39, F44, F107, F116]
- In `sccnxp.c`, `sccnxp_update_best_err(a, b, &besterr)` returns `0` when `abs(a - b) < *besterr` and requires `besterr = INT_MAX` initially. In `s->pdata.mctrl_cfg`, output nibbles (`MCTRL_OBIT`) use `LINE_OP0..LINE_OP7` (`1..8`) and input nibbles (`MCTRL_IBIT`) use `LINE_IP0..LINE_IP6` (`9..15`), and callers must check `cfg & MCTRL_MASK(sig)` before shifting by `MCTRL_OBIT`/`MCTRL_IBIT`. [F46, F84, F112]
- In `sa1100.c`, `read_status_mask` and `ignore_status_mask` pack `UTSR0` in `[7:0]` (`UTSR0_TO_SM`) and `UTSR1` in `[15:8]` (`UTSR1_TO_SM`), so `UTSR1_*` flags must be shifted with `UTSR1_TO_SM()` when stored/tested against those masks or passed to `uart_insert_char()`. [F49]
- In `omap-serial.c`, `serial_omap_runtime_suspend()` must return `-EBUSY` when `up->is_suspending && !console_suspend_enabled && uart_console(&up->port)`, and `serial_omap_runtime_resume()` must call `serial_omap_restore_context(up)` if `serial_omap_get_context_loss_count(up)` is negative or differs from `up->context_loss_cnt`. [F137]
- In `pch_uart.c`, `dma_sync_sg_for_device()` and `dma_unmap_sg()` must pass the original scatterlist count (`num` / `priv->orig_nent`), whereas segment iteration and `dmaengine_prep_slave_sg()` use the mapped count (`nent` / `priv->nent`). In `pmac_zilog.c` (`pmz_get_mctrl()` and `pmz_status_handle()`), Z8530 `R0` `CTS` is active-low (`!(status & CTS)`), while `DCD` and `SYNC_HUNT` are active-high. [F153, F169]

## Error Handling
- In `sc16is7xx_probe()`, `s->p[i].port.line` is pre-initialized to `SC16IS7XX_MAX_DEVS` and `port_registered[i]` is set only after `uart_add_one_port()` succeeds, so `out_ports` only frees IDA lines `< SC16IS7XX_MAX_DEVS` and removes ports with `port_registered[i]`. In `sc16is7xx_handle_rx()`, `sc16is7xx_handle_tx()`, and `sc16is7xx_port_irq()`, out-of-range `RXLVL`/`TXLVL` or unexpected `IIR` values must use `dev_warn_ratelimited()`/`dev_err_ratelimited()` and clamping, never `WARN_ON()`. [F3, F170]
- In `sa1100_serial_add_one_port()`, when `mctrl_gpio_init_noauto()` returns an `ERR_PTR` other than `-EPROBE_DEFER`, reset `sport->gpios = NULL`. [F38]

## External Contracts
- `serial_base_device_init()` and `serial_base_match_and_update_preferred_console()` must both format port names as `"%s:%d.%d"` using `(dev_name(port->dev), ctrl_id, port_id)`. In `sc16is7xx_rs485_supported`, keep `.delay_rts_after_send = 1` so `sc16is7xx_config_rs485()` receives `rs485->delay_rts_after_send` and returns `-EINVAL` when non-zero. In `owl_uart_set_termios()`, `pch_uart_set_termios()`, `pic32_uart_set_termios()`, and `sccnxp_set_termios()`, only call `tty_termios_encode_baud_rate(termios, baud, baud)` when `tty_termios_baud_rate(termios)` is non-zero. [F75, F167, F168]

## Known Pitfalls
- In `pmac_zilog.c`, `R7P` (`16`) is a `uap->curregs[]` index and must never be passed to `read_zsreg()`/`write_zsreg()` (toggle `EN85C30` in `R15` and access `R7` instead). In `pmz_convert_to_zs()`, baud rates `230400`, `115200`, and IrDA `>= 115200` must bypass `BPS_TO_BRG(baud, ZS_CLOCK / 16)`. In `pmz_startup()`, `sprintf(uap->irq_name, ...)` must fit in `uap->irq_name` (`unsigned char[8]`). [F48, F111, F122]
- In `omap-serial.c`, `serial_in()`/`serial_out()` shift `offset` by `up->port.regshift` for 16-bit `readw()`/`writew()`, whereas direct `up->port.membase` accesses must shift by `<< up->port.regshift`; `omap_serial_fill_features_erratas()` must run after `pm_runtime_get_sync()` and use 32-bit `readl()` on `UART_OMAP_MVER` (bit 30 `OMAP_UART_MVR_SCHEME_SHIFT`). When `UART_ERRATA_i202_MDR1_ACCESS` is set, `UART_OMAP_MDR1` writes must use `serial_omap_mdr1_errataset()`, polling `(serial_in(up, UART_LSR) & (UART_LSR_THRE | UART_LSR_DR)) != UART_LSR_THRE` with a bounded `timeout`. In `serial_omap_set_termios()`, modify `UART_FCR` only while `UART_DLL`/`UART_DLM` are `0` in `UART_LCR_CONF_MODE_A`, and `UART_MCR_TCRTLR` only while `UART_EFR_ECB` is set. [F62, F88, F97, F120, F134]
- In `sb1250-duart.c`, MMIO helpers must use 64-bit `__raw_readq()`/`__raw_writeq()`, `write_sbdchn()` must take `unsigned int` (for 12-bit `R_DUART_CLK_SEL` divisors), and all accesses must go through `read_sbdchn()`, `read_sbdshr()`, `write_sbdchn()`, or `write_sbdshr()` so `__war_sbd1956()` runs. [F66, F82]
- In `sc16is7xx_probe()`, set `s->polling = (irq <= 0)` (not `!!irq` or `irq < 0`), and in `sc16is7xx_gpio_direction_output()`, set `SC16IS7XX_IODIR_REG` before writing `SC16IS7XX_IOSTATE_REG`. In `sccnxp.c`, pass unshifted register indices to `sccnxp_read()`/`sccnxp_write()`/`sccnxp_port_read()`/`sccnxp_port_write()`, delay by `ndelay(s->chip->trwd)` in `sccnxp_read()`/`sccnxp_write()`, and gate `OPCR`/`SOP`/`ROP`/`IPCR` and `MR0` accesses on `SCCNXP_HAVE_IO` and `SCCNXP_HAVE_MR0`. [F59, F91, F119, F146]
- In `rsci.c`, `rsci_start_tx()` must set `CCR0_TE` after or with `CCR0_TIE`, and `rsci_receive_chars()` must read `CSR` (and `RDR` if `copied == 0` when `tty_buffer_request_room()` returns `0`) before calling `rsci_clear_DRxC(port)`. In `pxa.c`, `receive_chars()` must clear `UART_IER_RTOIE` before reading `UART_RX`, `goto ignore_char` on break/SysRq to refresh `*status = serial_in(up, UART_LSR)`, and re-enable `UART_IER_RTOIE` after draining; keep `UART_IER_UUE` set in `UART_IER` while active or in console/poll write. [F99, F103, F138, F147]
- In `pic32_uart.c`, call `pic32_wait_deplete_txbuf(sport)` before clearing `PIC32_UART_STA_UTXEN` or `PIC32_UART_MODE_ON`. In `owl-uart.c`, `OWL_UART_STAT_RIP` and `OWL_UART_STAT_TIP` in `OWL_UART_STAT` are write-1-to-clear (OR to clear). [F140, F149]
