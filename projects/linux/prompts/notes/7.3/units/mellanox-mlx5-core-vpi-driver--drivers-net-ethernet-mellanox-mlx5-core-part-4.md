# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 4)

Implements E-Switch offloads and termination tables, the core Flow Steering (FS) engine, event dispatch, and firmware management/reset.

## Architecture & Data Flow
- `del_sw_prio`, `del_sw_ns`, and `del_sw_root_ns` pass `fs_node *` directly to `kfree()`, requiring `node` to be first in `fs_prio` and `mlx5_flow_namespace`, and `ns` first in `mlx5_flow_root_namespace`. Both root and sub-namespaces set `node.type == FS_TYPE_NAMESPACE`; downcasting `mlx5_flow_namespace` to `mlx5_flow_root_namespace` must use `find_root(&ns->node)` or check `ns->node.parent == NULL`. [F333, F334]
- `build_match_list` passes `mlx5_flow_spec *` as the key to `rhltable_lookup(&ft->fgs_hash, spec, rhash_fg)`, requiring `mlx5_flow_spec` to start with `match_criteria_enable` and `match_criteria` matching `mlx5_flow_group_mask` with zeroed padding. `fs_fte.val` and `fg->mask.match_criteria` have length `MLX5_ST_SZ_DW_MATCH_PARAM`, so copies in `alloc_fte`/`alloc_flow_group` must bound size by `sizeof(fte->val)` or `sizeof(fg->mask.match_criteria)`. [F300, F329]
- `alloc_flow_group` treats `start_index`/`end_index` as inclusive table-wide indices (`fg->max_ftes = end_index - start_index + 1`), while `fg->fte_allocator` uses 0-based group offsets: `insert_fte` adds `fg->start_index` and `del_sw_fte` frees `fte->index - fg->start_index`. `alloc_handle` requires at least 1 rule (`dest_num ? dest_num : 1`) and must set `handle->num_rules` before accessing `handle->rule[]`. In `create_flow_handle` and `create_flow_handle_dup`, `MLX5_FLOW_DESTINATION_TYPE_FLOW_TABLE` rules must use `list_add_tail()` while other types use `list_add()`. [F298, F314, F331]
- When `switch_to_pending_act_dests()` promotes `fte->dup` in `del_hw_fte()`, overwrite `fte->act_dests` with `fte->dup->act_dests`, set each promoted child's `del_sw_func = del_sw_hw_rule`, and call `tree_get_node(&fte->node)`. In `_mlx5_modify_rule_destination()`, when `rule_is_pending(fte, rule)` is true, check `fte->dup->act_dests` for `MLX5_FLOW_CONTEXT_ACTION_FWD_DEST` and skip `root->cmds->update_fte()`. [F277, F278]
- In `set_prio_attrs_in_prio()`, update `acc_level` to `acc_level_ns` across child namespaces only when `prio->node.type == FS_TYPE_PRIO_CHAINS`. In `find_next_fwd_ft()`, when `MLX5_FLOW_CONTEXT_ACTION_FWD_NEXT_NS` is set, resolve the starting `fs_prio` from `ft->ns->node.parent`, not `ft->node.parent`. [F318, F322]
- `KERNEL_NIC_PRIO_NUM_LEVELS` bounds levels in `MLX5_FLOW_NAMESPACE_KERNEL` (`root_fs`) and must be incremented when adding a level. `mlx5_get_flow_namespace` indexes `root_fs.children` by `type` (`is_nic_rx_ns`) and `egress_root_fs.children` by `type - MLX5_FLOW_NAMESPACE_EGRESS`. `steering->fdb_sub_ns` has `FDB_NUM_CHAINS` (`FDB_TC_MAX_CHAIN + 2`) slots filled sequentially by `store_fdb_sub_ns_prio_chain`: `create_fdb_fast_path` must create TC chains before `FDB_FT_OFFLOAD`, and `mlx5_get_fdb_sub_ns` requires `n < FDB_NUM_CHAINS`. [F292, F293, F295]
- In `mlx5_pkt_reformat` and `mlx5_modify_hdr`, `id` in the action union is valid only when `owner == MLX5_FLOW_RESOURCE_OWNER_FW`; check `owner` or call `mlx5_fs_get_packet_reformat_id`. [F256]
- In `mlx5_fs_bulk`, `bitmask` uses `1` = free and `0` = acquired; `mlx5_fc_pool_release_counter` passes `fc->id - fc->bulk->base_id` to `mlx5_fs_pool_release_index()`. `mlx5_fs_pool_release_index()` updates `available_units`/`used_units` only if `mlx5_fs_bulk_release_index()` confirms the bit was `0`, and `mlx5_fs_pool_free_bulk()` subtracts `bulk->bulk_len` from `available_units` and updates `threshold` when `bulk_free_amount == bulk->bulk_len`. `FT_POOLS` in `fs_ft_pool.c` must remain sorted descending. [F216, F297, F303]
- In `mlx5_cmd_update_root_ft()`, updating an `FS_FT_FDB` root table on the shared-FDB LAG master must update peer devices via `mlx5_cmd_set_slave_root_fdb()`, rolling back peers and master to `ns->root_ft->id` on connect (`!disconnect`) failure. [F283]
- In `mlx5_eswitch_block_encap()`, increment `esw->offloads.num_block_encap` under `esw->mode_lock` only when `esw->mode == MLX5_ESWITCH_LEGACY` or when `esw->offloads.encap == DEVLINK_ESWITCH_ENCAP_MODE_NONE` and `!from_fdb`. In `mlx5_devlink_eswitch_encap_mode_set()`, if `esw_create_offloads_fdb_tables(esw)` fails after changing `esw->offloads.encap`, restore `esw->offloads.encap = !encap` and recreate FDB tables before clearing `eswitch_operation_in_progress`. [F272, F284]
- In `mlx5_esw_vports_inline_set()`, if `mlx5_modify_nic_vport_min_inline()` fails on any PF/VF or EC-VF vport, revert all previously modified vports across both loops to `esw->offloads.inline_mode`. `mlx5_devlink_port_fn_max_io_eqs_get`/`_set` subtract/add `MLX5_ESW_MAX_CTRL_EQS` (4), requiring an underflow clamp on get and `check_add_overflow` into `u16` on set. [F290, F307]
- `mlx5_fw_reset_init` leaves `dev->priv.fw_reset = NULL` when `!MLX5_CAP_MCAM_REG(dev, mfrl)`, so `mlx5_fw_reset_events_start`/`_stop`, `mlx5_drain_fw_reset`, and `mlx5_fw_reset_cleanup` must check `if (!fw_reset)`. `mlx5_sync_reset_set_reset_requested()` stops health polling, starts sync reset polling, and schedules `reset_timeout_work` (unless `DROP_NEW_REQUESTS` is set); `mlx5_sync_reset_clear_reset_requested()` cancels `reset_timeout_work`, stops sync reset polling, and restarts health polling when `poll_health` is true. [F258, F344]
- In `mlx5_pci_link_toggle()`, call `pci_save_state` and `pci_cfg_access_lock` for all `bridge_bus->devices` before toggling `PCI_EXP_LNKCTL_LD`, and unlock/restore all at `restore`. `&dev->iseg->initializing` reset bits must use `ioread32be`/`iowrite32be`, and `mlx5_reg_mcda_set` requires `size` to be a 4-byte multiple and converts words with `htonl`. In `temp_warn`, mask `sensor_warning_lsb` with `0x1` before `print_sensor_names_in_bit_set`. [F291, F306, F308, F349]

## Synchronization
- Acquire `fs_node.lock` top-down (`ft->node`: `FS_LOCK_GRANDPARENT`, `fg->node`: `FS_LOCK_PARENT`, `fte->node`: `FS_LOCK_CHILD`) via `nested_down_{read,write}_ref_node`. Hold `root->chain_lock` across flow table creation/connection/destruction, `FWD_NEXT_PRIO`/`FWD_NEXT_NS` rule insertion, and `root->underlay_qpns` updates. [F238, F356]
- `alloc_insert_flow_group()` and `insert_fte()` insert into `fgs_hash`/`ftes_hash` with `node.active = false` before HW creation. In `lookup_fte_locked()`, after `tree_get_node(&fte_tmp->node)`, acquire `nested_down_write_ref_node(&fte_tmp->node, FS_LOCK_CHILD)` before checking `fte_tmp->node.active`; callers must release both via `up_write_ref_node(&fte_tmp->node, false)` and `tree_put_node(&fte_tmp->node, false)`. [F209, F235, F242]
- In `mlx5_del_flow_rules()`, hold `down_write_ref_node(&fte->node, false)` across the `tree_remove_node(&handle->rule[i]->node, true)` loop and any `del_hw_func` or `modify_fte()` call. In `_mlx5_add_flow_rules()` and `try_add_to_existing_fg()`, revalidate `ft->node.version` and `matched_fgs_get_version(match_head)` (`u64` sum) after dropping read locks. [F237, F241, F327]
- In `mlx5_fc_create()`, when `aging` is true, initialize `counter->cache.lastuse`, `lastbytes`, and `lastpackets` before `xa_store()`. In `mlx5_fc_stats_query_all_counters()`, `bulk_base_id` must be `counter->id & ~0x3`; when dropping `xas` lock for `mlx5_cmd_fc_bulk_query()`, call `xas_reset(&xas)` and `continue` after `xas_lock(&xas)`, then index `flow_statistics` by `counter->id - bulk_base_id` in `update_counter_cache()` only if `time_after64(bulk_query_time, counter->cache.lastuse)`. Hold `fs_pool->pool_lock` throughout `mlx5_fs_pool_acquire_index()` and `mlx5_fs_pool_release_index()`. [F226, F247, F274, F275, F296]
- Hold `esw->state_lock` across devlink port fn callbacks accessing `vport->enabled`, `vport->info`, or `esw->enabled_ipsec_vf_count`; `mlx5_devlink_port_fn_ipsec_{crypto,packet}_set` must fail with `-EBUSY` if `!esw->enabled_ipsec_vf_count && esw->dev->num_ipsec_offloads` and update `enabled_ipsec_vf_count` in lockstep. In `mlx5_devlink_eswitch_{mode,inline_mode,encap_mode}_set`, set `esw->eswitch_operation_in_progress = true` under `esw->mode_lock`, drop `up_write(&esw->mode_lock)` during the transition, and re-acquire it to clear the flag. [F248, F288, F363]
- Pass `locked = true` to `mlx5_sync_reset_unload_flow()` iff holding `devl_lock`. `mlx5_fw_reset_set_reset_sync()` sets `MLX5_FW_RESET_FLAGS_PENDING_COMP` before `MLX5_REG_MFRL` (clearing on error) and `mlx5_fw_reset_wait_reset_done()` clears it on all exits; while set, `mlx5_fw_reset_complete_reload` must only call `complete(&fw_reset->done)`. In `mlx5_cmd_fast_teardown_hca()`, bound `mlx5_get_nic_state(dev)` polling by `mlx5_tout_ms(dev, TEARDOWN)` and abort with `-EACCES` if `pci_channel_offline(dev->pdev)`. [F224, F231, F350, F361]

## Object Lifetimes
- `tree_add_node()` increments `parent->refcount` per child, and `tree_put_node()` drops it only after `node->refcount` hits zero, `del_hw_func` runs, `node->list` is unlinked under `down_write_ref_node(parent_node, locked)`, and `del_sw_func` finishes. `tree_remove_node()` decrements `node->refcount` and returns `-EEXIST` when `refcount > 1`, so `mlx5_destroy_flow_{table,group}()` consume the caller's reference even when children defer teardown. [F205, F206]
- `mlx5_fc_local_create()` allocates `counter->bulk` without `fcs[]` or `fs_bulk.bitmask` and initializes `hws_data.hws_action_refcount = 0`, `hws_data.lock`, and `counter->fc_local_refcount = 1`; `del_sw_hw_rule()` must call `mlx5_fc_local_put()` so the counter outlives `del_hw_fte()`. `mlx5_fc_release()` rejects `MLX5_FC_TYPE_LOCAL` (`WARN_ON`), while `mlx5_fc_local_{get,put}` are no-ops for `MLX5_FC_TYPE_ACQUIRED` counters (freed via `mlx5_fc_destroy()`). `mlx5_cleanup_fc_stats()` must stop `work`, destroy `wq`, and release all counters in `fc_stats->counters` via `mlx5_fc_release()` before `mlx5_fc_pool_cleanup()`. [F203, F204, F215, F332]
- `mlx5_cmd_create_flow_table()` gets `size` from `mlx5_ft_pool_get_avail_sz()` (`!size` is `-ENOSPC`), returns `size` via `mlx5_ft_pool_put_sz()` on failure, and saves `ft->max_fte = size` for `mlx5_cmd_destroy_flow_table()`. In `mlx5_flow_namespace_set_mode()`, `cmds->create_ns(root)` must succeed before `root->cmds->destroy_ns(root)` and updating `root->cmds`/`root->mode`. [F211, F214, F252]
- Table references and `esw->offloads.num_flows` acquired in `mlx5_eswitch_add_{offloaded,fwd}_rule()` (`esw_setup_dests`, chains, vporttbl, termtbl) must be symmetrically released in `__mlx5_eswitch_del_rule()` (`esw_cleanup_dests`) and on error paths. [F221]
- `mlx5_events_stop()` must unregister `events->notifiers` in reverse order via `mlx5_eq_notifier_unregister()` before `flush_workqueue(events->wq)`, and `mlx5_events_cleanup()` destroys `wq` before freeing `events`. `mlx5_drain_fw_reset()` must set `MLX5_FW_RESET_FLAGS_DROP_NEW_REQUESTS` before cancelling work, and all `fw_reset.c` work-queueing paths must check it first. [F223, F232]

## API Contracts
- Namespace lookups (`mlx5_get_flow_{namespace,vport_namespace}`, `mlx5_get_fdb_sub_ns`, `mlx5_get_root_namespace`) return `NULL`, whereas allocators (`mlx5_create_flow_table`, `mlx5_modify_header_alloc`, `mlx5_packet_reformat_alloc`) return `ERR_PTR`. Look up `MLX5_FLOW_NAMESPACE_ESW_{EGRESS,INGRESS}` and `MLX5_FLOW_NAMESPACE_RDMA_TRANSPORT_{RX,TX}` via `mlx5_get_flow_vport_namespace` using `vport->index` (not `vport->vport`). `mlx5_eswitch_get_vport` returns `ERR_PTR`, whereas `mlx5_eswitch_{get_rep,vport_rep}` return `NULL`. `mlx5_esw_try_lock` and `cmds->create_match_definer` return non-negative values or negative errno; test `< 0` in a signed `int`. [F250, F253, F254, F255, F268]
- In `__mlx5_create_flow_table`, managed `ft_attr->level` (`< fs_prio->num_levels`) is mutated in place (`+= fs_prio->start_level`). On autogrouped tables, `mlx5_create_flow_group` rejects `start_flow_index < ft->autogroup.max_fte` (`-EPERM`), and `_mlx5_add_flow_rules` rejects `flow_act->fg` (`-EINVAL`). `dest_is_valid` requires `dest->ft->level > ft->level` unless `FLOW_ACT_IGNORE_FLOW_LEVEL` is set (valid when `ft->type` is `FS_FT_FDB`, `FS_FT_NIC_RX`, or `FS_FT_NIC_TX` and matches `dest->ft->type`). `mlx5_modify_rule_destination` requires non-NULL `old_dest` when `handle->num_rules > 1`. `mlx5_flow_namespace_set_mode` applies only to root `FS_FT_FDB` when idle, and `mlx5_fs_mode_validate` rejects changes in `MLX5_ESWITCH_OFFLOADS`. [F266, F267, F270, F271, F375]
- `mlx5_fs_pool_init` requires non-NULL `bulk_destroy`, `bulk_create`, and `update_threshold` in `mlx5_fs_pool_ops`. `mlx5_cmd_fc_get_bulk_query_out_len(bulk_len)` returns bytes, whereas `mlx5_cmd_fc_bulk_query` takes counter count `bulk_len`. `mlx5_eswitch_get_vport_metadata_for_match` shifts `vport->metadata` left 16 bits, whereas `_for_set` is unshifted. `mlx5_vport_set_other_func_cap` expects `MLX5_ADDR_OF(query_hca_cap_out, query_ctx, capability)`. `mlx5_notifier_register` (`events->fw_nh`) is atomic; sleeping callbacks must use `mlx5_blocking_notifier_register` (`events->sw_nh`). [F230, F302, F337, F339, F365]
- Verify `MLX5_CAP_GEN(dev, mcam_reg)` and `MLX5_CAP_MCAM_{REG,REG2,FEATURE}` before accessing `MCQI`, `MCC`, `MCDA`, `MCQS`, `MIRC`, `MPEIN`, or `MFRL`. Initialize `*fwhandle = 0` before `mlx5_reg_mcc_query` when no handle is active, and pass `data_size <= MLX5_UN_SZ_BYTES(mcqi_reg_data)` to `mlx5_reg_mcqi_query`. `mlx5_is_reset_now_capable()` requires `fast_teardown`, no active SFs on non-ECPF, no PCIe hotplug interrupts on non-hot-reset, and known sibling PCI IDs (`mlx5_check_dev_ids`). [F264, F340, F347, F348]

## Error Handling
- In `__mlx5_create_flow_table()`, if `connect_flow_table()` fails, call `root->cmds->destroy_flow_table(root, ft)` and `rhltable_destroy(&ft->fgs_hash)` before `kfree(ft)`. Store teardown return codes (e.g., `mlx5_destroy_flow_table` in `mlx5_eswitch_termtbl_create`) in `err2` to preserve `err`. In `init_*_root_ns`, reset `steering->*_root_ns = NULL` after `cleanup_root_ns()`, and in `init_rdma_transport_{rx,tx}_root_ns_one()` and `mlx5_fs_add_vport_acl_root_ns()`, call `cleanup_root_ns(root_ns)` on failure after `create_root_ns()`. [F212, F213, F260, F261]
- When `try_add_to_existing_fg` skips an inactive group (`!g->node.active`), set `try_again = true` and return `ERR_PTR(-EAGAIN)` if no group accepts the FTE. In `esw_chains_create()`, on error after setting `esw->fdb_table.offloads.esw_chains_priv = chains`, release acquired tables in reverse order, call `mlx5_chains_destroy(chains)`, and clear `esw_chains_priv = NULL`. [F220, F249]
- In `mlx5_eswitch_add_termtbl_rule()`, index `dest` by `i` and `attr->dests` by `num_vport_dests`; on error, `revert_changes` must move VLAN push actions back to `flow_act`, clear `attr->dests[curr_dest].termtbl = NULL`, restore `dest[i]` matching `dest[i].ft == tt->termtbl` to `MLX5_FLOW_DESTINATION_TYPE_VPORT`, and call `mlx5_eswitch_termtbl_put()`. In `port_module` (`events.c`), update `events->pme_stats` before `printk_ratelimit()`, and ratelimit `temp_warn` and `mlx5_pcie_event` logs. [F217, F316, F373]

## External Contracts
- Entering `DEVLINK_ESWITCH_MODE_SWITCHDEV` in `mlx5_devlink_eswitch_mode_set` must call `mlx5_devlink_netdev_netns_immutable_set(devlink, true)` under `rtnl_lock()` and verify `net_eq(dev_net(netdev), devlink_net(devlink))`, resetting `netns_immutable` to `false` on failure. [F366]

## Known Pitfalls
- Unmanaged flow tables (`MLX5_FLOW_TABLE_UNMANAGED`) have `ft->node.parent == NULL`; check `ft->node.parent` or `!(ft->flags & MLX5_FLOW_TABLE_UNMANAGED)` before `fs_get_obj(prio, ft->node.parent)`. In `check_conflicting_actions()`, test exact equality (`== MLX5_FLOW_CONTEXT_ACTION_COUNT`) before `xored_actions`. In `mlx5_get_flow_namespace()`, every non-root, non-NIC-RX `switch (type)` case must set both `root_ns` and `prio`. [F310, F312, F335]
- Zero-initialize `flow_act->vlan` including padding before `mlx5_eswitch_termtbl_get_create` (`mlx5_eswitch_termtbl_hash`/`_cmp`). In `mlx5_eswitch_add_send_to_vport_rule()`, take source attributes from `from_esw`, destination vport/VHCA from `rep->esw`, and table/rule insertion from `on_esw`. In `mlx5_get_boot_img_component_index()`, verify `identifier == MCQS_IDENTIFIER_BOOT_IMG` after the `mlx5_reg_mcqs_query()` loop. [F263, F319, F321]
