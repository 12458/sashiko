# BTRFS FILE SYSTEM — fs/btrfs (part 4)

Implements Btrfs extent allocation and backref management in the extent tree (`extent-tree.c`), extent buffer and folio I/O (`extent_io.c`), in-memory file extent mappings (`extent_map.c`), and FIEMAP reporting (`fiemap.c`).

## Architecture & Data Flow
- In `struct extent_map`, `disk_bytenr` is a disk address only when `< EXTENT_MAP_LAST_BYTE` (`(u64)-4`); for `EXTENT_MAP_HOLE`/`EXTENT_MAP_INLINE`, `offset` and `disk_num_bytes` must stay `0` and `em->offset` must never be added to `disk_bytenr`. `btrfs_extent_map_end()`, `range_end()`, and `extent_map_block_end()` must clamp `u64` overflow (`start + len < start`) to `(u64)-1`. [F392, F460]
- `add_extent_mapping()` and `remove_em()` on a fstree root (`!btrfs_is_testing(fs_info) && btrfs_is_fstree(btrfs_root_id(inode->root))`) must increment/decrement `fs_info->evictable_extent_maps` in lockstep; `replace_extent_mapping()` must not alter it. [F406]
- `btrfs_remove_extent_mapping()` and `replace_extent_mapping()` must call `list_del_init(&em->list)` only if `!(em->flags & EXTENT_FLAG_LOGGING)`, and must call `RB_CLEAR_NODE(&em->rb_node)`. Loops in `btrfs_drop_extent_map_range()`, `drop_all_extent_maps_fast()`, and `btrfs_scan_inode()` must fetch the next node before removal/replacement, and `drop_all_extent_maps_fast()` must restart at `rb_first(&tree->root)` if `cond_resched_rwlock_write()` rescheduled. [F407, F451]
- In `btrfs_extent_map_shrinker_worker()`, when `radix_tree_gang_lookup()` returns 0 roots at `next_root_id`, wrap `next_root_id`, `em_shrinker_last_root`, and `em_shrinker_last_ino` to `0` only if `start_root_id > 0 && !cycled` (setting `cycled = true`), else `break`. When `btrfs_scan_root()` finishes a root (`inode == NULL`), reset `em_shrinker_last_ino = 0` alongside updating `em_shrinker_last_root`. [F411, F453]
- `extent_buffer::addr` is non-`NULL` only when `alloc_extent_buffer()` finds all pages in `eb->folios[]` contiguous (`page_contig`); helpers must fall back to `eb->folios[]` via `get_eb_folio_index()`/`get_eb_offset_in_folio()` when `NULL`. On 32-bit (`BITS_PER_LONG == 32`), `alloc_extent_buffer()` must reject `start >= MAX_LFS_FILESIZE` with `-EOVERFLOW`. [F393, F465]
- `num_extent_pages()` must clamp `(eb->len >> PAGE_SHIFT) ?: 1` for subpage buffers (`eb->len < PAGE_SIZE`). On metadata folios, `folio_get_private(folio)` is `struct extent_buffer *` only when `!btrfs_meta_is_subpage(fs_info)` and `struct btrfs_folio_state *` when subpage. [F466, F474]
- `extent_buffer` bitmap helpers (`extent_buffer_test_bit`, `extent_buffer_bitmap_set`, `extent_buffer_bitmap_clear`) must use byte-granular (`u8`) little-endian masks (`BITMAP_FIRST_BYTE_MASK`, `BITMAP_LAST_BYTE_MASK`), never `unsigned long` word bitops. [F431]
- When `dst_offset >= src_offset` on a multi-folio buffer (`dst->addr == NULL`), `memmove_extent_buffer()` must copy backwards from `dst_offset + len - 1` and `src_offset + len - 1` in chunks of `min3(len, src_off_in_folio + 1, dst_off_in_folio + 1)`. Before submitting metadata in `write_one_eb()`, `prepare_eb_write()` must zero unused space via `memzero_extent_buffer()`. [F432, F507]
- In `submit_extent_folio()`, update `bio_ctrl->generation = max(bio_ctrl->generation, read_em_generation)` only after `bio_add_folio()` succeeds; `submit_one_bio()` must reset `bio_ctrl->generation = 0` after `bio_set_csum_search_commit_root(bio_ctrl)`. [F454]
- Before downcasting `struct btrfs_extent_inline_ref *iref`, check `btrfs_get_extent_inline_ref_type()` for `BTRFS_REF_TYPE_INVALID` and use `&iref->offset` for `BTRFS_EXTENT_DATA_REF_KEY`/`BTRFS_EXTENT_OWNER_REF_KEY` vs `(iref + 1)` for `BTRFS_SHARED_DATA_REF_KEY`. `struct btrfs_tree_block_info` follows `struct btrfs_extent_item` (`ei + 1`) only for non-skinny `BTRFS_EXTENT_ITEM_KEY` (`!skinny_metadata`); for `BTRFS_METADATA_ITEM_KEY`, inline refs start at `ei + 1` and `extent_op` in `alloc_reserved_tree_block()` may be `NULL`. [F394, F395]
- When `btrfs_run_delayed_refs_for_head()` dequeues a `delayed_ref_node` under `locked_ref->lock`, it must update `locked_ref->ref_mod`, sample and clear `locked_ref->must_insert_reserved`, and take and `NULL` out `locked_ref->extent_op` before dropping `locked_ref->lock`. [F420]
- `block_group_bits(cache, bits)` checks `(cache->flags & bits) == bits`. In `find_free_extent_clustered()`, when `btrfs_lock_cluster()` returns `cluster_bg != bg`, it must verify `!cluster_bg->ro`, `block_group_bits(cluster_bg, ffe_ctl->flags)`, and `find_free_extent_check_size_class(ffe_ctl, cluster_bg)`. In `find_free_extent()`, set `ffe_ctl->retry_uncached = true` before jumping from `loop:` to `have_block_group` after `btrfs_wait_block_group_cache_progress()`, and reset it to `false` in `release_block_group()`. [F441, F444, F448]
- In `emit_fiemap_extent()`, if `cache->offset + cache->len > offset`, adjust `cache->len` or trim `[offset, offset + len)` against `cache_end` to avoid overlap or underflow. When `cache->entries_pos == cache->entries_size`, set `cache->next_search_offset` to `entry->offset + entry->len` of `cache->entries[cache->entries_size - 1]` and `cache->cached = false` before returning `BTRFS_FIEMAP_FLUSH_CACHE`. [F440, F458]

## Synchronization
- `release_extent_buffer()` requires `eb->refs_lock` held on entry and unlocks it on all return paths. `folio->mapping->i_private_lock` nests outside `eb->refs_lock` in `try_release_extent_buffer()` and must be dropped before `release_extent_buffer(eb)` (which calls `detach_extent_buffer_folio()`). [F347, F481]
- All `fs_info->buffer_tree` XArray lock acquisitions must disable IRQs (`xa_lock_irq`, `xas_lock_irq`, `xas_lock_irqsave`, `xa_cmpxchg_irq`) because `end_bbio_meta_write()` calls `buffer_tree_clear_mark()` from IRQ bio completion. Lockless lookups (`find_extent_buffer_nolock()`, `buffer_tree_get_ebs_tag()`) require `rcu_read_lock()` and `refcount_inc_not_zero(&eb->refs)`, paired with `call_rcu()` in `release_extent_buffer()`. [F478, F479]
- `try_release_subpage_extent_buffer()` must iterate `fs_info->buffer_tree` under `rcu_read_lock()` (never taking `eb->refs_lock` under the IRQ-safe `buffer_tree` lock), acquire `eb->refs_lock` before `rcu_read_unlock()`, and call `rcu_read_unlock()` before `release_extent_buffer(eb)`. [F365, F482]
- In `find_extent_buffer()`, if `EXTENT_BUFFER_STALE` is set after `find_extent_buffer_nolock()`, acquire and release `eb->refs_lock` before `mark_extent_buffer_accessed()`. In `set_extent_buffer_dirty()`, when `!was_dirty` and `btrfs_meta_is_subpage(eb->fs_info)`, lock `eb->folios[0]` via `folio_lock()` across `btrfs_meta_folio_set_dirty()` and `buffer_tree_set_mark(eb, PAGECACHE_TAG_DIRTY)`. [F369, F383]
- `lock_delalloc_folios()` and `process_one_folio()` (via `__process_folios_contig()`, `unlock_delalloc_folio()`, `extent_clear_unlock_delalloc()`) must skip locking/unlocking `locked_folio` so the caller retains its lock. [F351]
- In `btrfs_split_extent_map()` and `btrfs_drop_extent_map_range()`, call `btrfs_alloc_extent_map()` (`GFP_NOFS`) and `btrfs_lock_extent(&inode->io_tree, ...)` before acquiring `write_lock(&inode->extent_tree.lock)`. [F487]
- In `btrfs_cross_ref_exist()`, `btrfs_lookup_extent_info()`, and `check_ref_exists()`, keep the extent tree leaf in `path` locked while trylocking `head->mutex`; if `mutex_trylock()` fails, increment `head->refs`, unlock `delayed_refs->lock`, and call `btrfs_release_path(path)` before sleeping on `mutex_lock(&head->mutex)`. [F357]
- In `cleanup_ref_head()`, deleting a `delayed_ref_head` requires dropping `head->lock`, acquiring `delayed_refs->lock` then `head->lock`, and re-verifying `RB_EMPTY_ROOT(&head->ref_tree.rb_root)` and `!head->extent_op` before `btrfs_delete_ref_head()`. [F376]
- In `extent_fiemap()`, `fiemap_search_slot()` and `fiemap_next_leaf_item()` must copy the leaf into an unmapped clone `extent_buffer` and call `btrfs_release_path(path)` before `btrfs_is_data_extent_shared()`. In `can_allocate_chunk_zoned()`, call `btrfs_zone_finish_one_bg()` only for `BTRFS_BLOCK_GROUP_DATA`, never metadata. [F381, F494]

## Object Lifetimes
- In `alloc_extent_buffer()`, folios attached via `attach_eb_folio_to_filemap()` must stay locked until `eb` is in `fs_info->buffer_tree`; on `out:` rollback, call `detach_extent_buffer_folio()` before `folio_unlock()`, `folio_put()`, and setting `eb->folios[i] = NULL` before `btrfs_release_extent_buffer()`. [F348]
- Once `submit_one_bio()` submits `bio_ctrl->bbio` or `submit_write_bio()` ends it via `btrfs_bio_end_io()`, ownership transfers to `end_io` and `bio_ctrl->bbio` must be set to `NULL`. In `writepage_delalloc()`, `break` as soon as `found_start + found_len >= last_delalloc_end + 1` without touching `folio` again. [F350, F456]
- Clearing `locked_ref->must_insert_reserved = false` in `btrfs_run_delayed_refs_for_head()` transfers reserved-extent and squota ownership to `run_one_delayed_ref()`, which must call `btrfs_pin_extent()` and `free_head_ref_squota_rsv()` on error/abort. [F356]
- When `btrfs_lock_cluster()` returns `cluster_bg != bg`, it holds a ref and (if `delalloc`) `cluster_bg->data_rwsem`; `find_free_extent_clustered()` must call `btrfs_release_block_group(cluster_bg, ffe_ctl->delalloc)` on failure or pass it via `*cluster_bg_ret`. [F358]
- In `fiemap_next_leaf_item()`, `refcount_inc(&clone->refs)` keeps the unmapped clone alive across `btrfs_next_leaf()`; if `ret != 0`, `free_extent_buffer(clone)` must be called to drop the extra ref. [F363]

## API Contracts
- `alloc_extent_buffer()`, `btrfs_alloc_tree_block()`, and `get_extent_map()` return `ERR_PTR()` (never `NULL`); `find_extent_buffer()`, `btrfs_clone_extent_buffer()`, `alloc_dummy_extent_buffer()`, `btrfs_alloc_extent_map()`, `btrfs_lookup_extent_mapping()`, and `btrfs_search_extent_mapping()` return `NULL` (never `ERR_PTR()`). [F386, F387]
- `btrfs_remove_extent_mapping()` and `replace_extent_mapping()` do not decrement refcounts; callers must call `btrfs_free_extent_map()` for the removed tree ref. When `add_extent_mapping()` returns `-EEXIST` in `btrfs_add_extent_mapping()`, it frees `*em_in` and sets `*em_in` to the existing map (or `NULL` if `merge_extent_mapping()` fails). [F354, F355]
- `btrfs_drop_extent_map_range()` and `fiemap_process_hole()` take an inclusive `end` offset (and `btrfs_drop_extent_map_range()` must increment `end` or clamp `len` to `(u64)-1` before comparing against exclusive `btrfs_extent_map_end()`), whereas `btrfs_lookup_extent_mapping()`, `btrfs_search_extent_mapping()`, `btrfs_unpin_extent_cache()`, `btrfs_split_extent_map()`, and `extent_fiemap()` take a byte length `len`. [F403, F427]
- In `extent_buffer` data/bitmap helpers (`read_extent_buffer()`, `write_extent_buffer()`, `memzero_extent_buffer()`, `copy_extent_buffer()`, `memcpy_extent_buffer()`, `memmove_extent_buffer()`, `extent_buffer_bitmap_*()`), `start` is a 0-based byte offset in `eb` (`<= eb->len`), while bitmap `pos`/`nr`/`len` are in bits. Overlapping shifts with `dst_offset > src_offset` must use `memmove_extent_buffer()`, not `memcpy_extent_buffer()`. [F404, F472]
- In `try_release_extent_mapping()`, call `cond_resched()` only if `gfpflags_allow_blocking(mask)`; if `need_resched()` and `!gfpflags_allow_blocking(mask)`, `break` immediately. [F484]
- When `check_next_block_uptodate()` fails, it unlocks and frees `next` before returning non-zero, so `do_walk_down()` must return immediately rather than jumping to `out_unlock`. `find_free_extent_clustered()` returns `0` on success, `1` when no free extent is found, and `-ENOENT` to make `do_allocation_clustered()` fall back to `find_free_extent_unclustered()`. [F360, F390]
- In `btrfs_lookup_extent_info()`, `offset` is the B-tree `level` when `metadata != 0` (not `nodesize`) and byte length when `metadata == 0`. `emit_fiemap_extent()` returns `BTRFS_FIEMAP_FLUSH_CACHE` (`-(MAX_ERRNO + 1)`) when `cache->entries` is full; `extent_fiemap()` must intercept it after unlocking the `io_tree` range, release `path`, call `flush_fiemap_cache()`, and restart from `cache.next_search_offset`. [F391, F405]

## Error Handling
- `btrfs_finish_extent_commit()` must latch the first error from `unpin_extent_range()` into `unpin_error` and return it after all pinned ranges and `deleted_bgs` discards finish. `find_free_extent()` must latch `btrfs_cache_block_group()` / `BTRFS_CACHE_ERROR` failures in `cache_block_group_error` (resetting `ret = 0`) and return `cache_block_group_error` instead of `-ENOSPC`. [F396, F397]
- In `end_bbio_meta_write()`, `set_btree_ioerr()` must call `mapping_set_error(eb->fs_info->btree_inode->i_mapping, -EIO)` AND set `BTRFS_FS_BTREE_ERR`/`BTRFS_FS_LOG1_ERR`/`BTRFS_FS_LOG2_ERR` on `fs_info->flags` per `eb->log_index`. `btrfs_get_extent_inline_ref_type()` and `lookup_inline_extent_backref()` must validate that shared ref offsets are non-zero, `sectorsize`-aligned, and `ptr <= end`, returning `-EUCLEAN` otherwise. [F506, F509]

## External Contracts
- `hash_extent_data_ref()` must convert `root_objectid`, `owner`, and `offset` via `cpu_to_le64` before `crc32c`, and cast `high_crc`/`low_crc` to `u64` before `(high_crc << 31) ^ low_crc`. `btrfs_trim_fs()` must reject `range->start == U64_MAX`, check `check_add_overflow(range->start, range->len, &range_end)` with `-EINVAL` when `range->len != U64_MAX`, and write total trimmed bytes into `range->len`. [F436, F437, F462]
- For `FIEMAP_FLAG_SYNC`, `btrfs_fiemap()` must call `btrfs_wait_ordered_range(btrfs_inode, 0, LLONG_MAX)` in addition to `fiemap_prep()` (and repeat it under `BTRFS_ILOCK_SHARED`). In `submit_one_sector()` and `extent_writepage_io()`, when sector writeback fails before bio submission or all sectors are `>= i_size`, call `btrfs_folio_clear_dirty()`, `btrfs_folio_set_writeback()`, and `btrfs_folio_clear_writeback()`. [F496, F501]

## Known Pitfalls
- `try_merge_map()` must only mutate `em` in place if `refcount_read(&em->refs) <= 2` and `can_merge_extent_map(em)`, and `merge_ondisk_extents()` must compute `new_disk_bytenr`, `new_disk_num_bytes`, and `new_offset` into locals before writing `merged` (which aliases `prev`/`next`). In `btrfs_scan_root()`, `while (inode)` calls `iput(&inode->vfs_inode)` before breaking, so post-loop `if (inode)` must never dereference `inode`. [F409, F452]
- In `btrfs_do_readpage()`, if `compress_type != BTRFS_COMPRESS_NONE` and `bio_ctrl->last_em_start != U64_MAX && bio_ctrl->last_em_start != em->start`, call `submit_one_bio(bio_ctrl)` before adding the folio. In `submit_extent_folio()`, decrement `bio_ctrl->len_to_oe_boundary` by `len` only when `!= U32_MAX`. [F415, F467]
- `num_extent_folios(eb)` returns `0` when `eb->folios[0]` is `NULL`; loops clearing `eb->folios[i] = NULL` must cache `num_extent_folios(eb)` beforehand or use `num_extent_pages(eb)`. In `btrfs_init_new_buffer()`, call `btrfs_set_header_generation(buf, trans->transid)` before `btrfs_clear_buffer_dirty(trans, buf)` and again after `memzero_extent_buffer()`, while setting `buf->log_index` and clearing `EXTENT_BUFFER_STALE` and `EXTENT_BUFFER_ZONED_ZEROOUT`. [F424, F429]
- During snapshot deletion, if a tree block lock is dropped and reacquired (`check_next_block_uptodate()`, `walk_up_proc()`), refresh `wc->refs[level]` and `wc->flags[level]` via `btrfs_lookup_extent_info()`. In `setup_inline_extent_backref()`, save `item_offset = (unsigned long)iref - (unsigned long)ei` before `btrfs_extend_item()` and recompute `ei` and `ptr = (unsigned long)ei + item_offset` after. [F425, F469]
- Callers inspecting `struct btrfs_file_extent_item` must check `btrfs_file_extent_type(leaf, ei) == BTRFS_FILE_EXTENT_INLINE` before reading `btrfs_file_extent_disk_bytenr(leaf, ei)`. When reusing `clone` in `fiemap_next_leaf_item()`, update `clone->start` before `copy_extent_buffer_full()`. [F442, F470]
