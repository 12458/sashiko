# ETHERNET BRIDGE — (top level)

This component implements the Linux Ethernet bridge (802.1D/802.1Q) virtual device, port management, frame forwarding, unicast FDB, Multicast Database (MDB), ARP/ND proxy and neighbor suppression, MST, MRP (IEC 62439-2), and CFM (802.1ag), integrating with netfilter bridge hooks, RTNetlink/ioctl UAPIs, and switchdev offload.

## Architecture & Data Flow

- `sizeof(struct br_input_skb_cb)` must fit in `skb->cb` (48B), and `br_handle_frame()` and `br_dev_xmit()` must zero `skb->cb` before using `BR_INPUT_SKB_CB(skb)`. `br_pass_frame_up()` and `br_dev_xmit()` must call `br_switchdev_frame_unmark(skb)` to clear `skb->offload_fwd_mark`, and `__br_forward()` must call `nbp_switchdev_frame_mark_tx_fwd_offload(to, skb)` before `br_handle_vlan(to->br, to, vg, skb)` so `br_handle_vlan()` sees `tx_fwd_offload`. [F234, F257, F310]
- Forwarding helpers (`br_allowed_ingress`, `br_forward`, `br_flood`, `br_multicast_flood`, `__br_forward`) require `skb->data` at `skb_mac_header(skb) + ETH_HLEN` (`br_dev_xmit()` pulls `ETH_HLEN`; `br_dev_queue_push_xmit()` pushes `ETH_HLEN`). `br_netif_receive_skb()` and `br_dev_queue_push_xmit()` must call `br_drop_fake_rtable(skb)`, and in `br_dev_queue_push_xmit()` after `skb_push()`, if `skb->ip_summed == CHECKSUM_PARTIAL` and `eth_type_vlan(skb->protocol)`, `skb->network_header` must be set past VLAN headers via `vlan_get_protocol_and_depth()`. [F307, F311, F312]
- In `br_handle_frame_finish()` and `br_dev_xmit()`, test `is_broadcast_ether_addr()` before or inside `is_multicast_ether_addr()` so broadcasts are not passed to `br_multicast_rcv()`. In `br_handle_frame()`, link-local frames set `fwd_mask = p->br->group_fwd_mask_required | p->group_fwd_mask` before `switch (dest[5])`, ORing `p->br->group_fwd_mask` only for `0x0E` (LLDP) and `default` (so `0x00` BPDU ignores bridge mask and `0x01` Pause is dropped), and only evaluate `1u << dest[5]` inside `is_link_local_ether_addr(dest)`. [F258, F259, F272]
- `br->fdb_n_learned` tracks `BR_FDB_DYNAMIC_LEARNED` entries: `fdb_create()` increments it only after `rhashtable_lookup_insert_fast()` succeeds, and every deletion or promotion to `BR_FDB_ADDED_BY_USER`/`BR_FDB_LOCAL` must guard `atomic_dec(&br->fdb_n_learned)` with `test_and_clear_bit(BR_FDB_DYNAMIC_LEARNED, &fdb->flags)`. Every netlink attribute in `fdb_fill_info()` must be counted in `fdb_nlmsg_size()` so `fdb_notify()` does not overflow with `-EMSGSIZE`. [F176, F255]
- Static FDB MACs are refcounted in non-promiscuous ports via `dev_uc_add()`/`dev_uc_del()`: `fdb_add_entry()` and `fdb_delete()` call `fdb_add_hw_addr()`/`fdb_del_hw_addr()` only when `BR_FDB_STATIC` transitions. In `br_add_if()`, a new port starts without `BR_PROMISC`, so if `nbp_update_port_count()` leaves `!br_promisc_port(p)` and `IFF_UNICAST_FLT` is set, `br_add_if()` must call `br_fdb_sync_static(br, p)` and undo it with `br_fdb_unsync_static(br, p)` on rollback. [F177, F223]
- `br_toggle_fdb_local_vlan_0()` must sync per-VLAN local FDB entries via `br_fdb_toggle_local_vlan_0()` (with rollback on failure). When `p->flags` bits in `BR_AUTO_MASK` or `BR_NEIGH_SUPPRESS | BR_NEIGH_VLAN_SUPPRESS` change, `br_port_flags_change()` (or port add/del) must call `nbp_update_port_count()` and `br_recalculate_neigh_suppress_enabled()`. `br_add_if()` must register `br_get_rx_handler(dev)` (`br_handle_frame_dummy` on DSA conduits) so `br_port_get_check_rcu()`/`_rtnl()` can validate `dev->rx_handler`. [F227, F231, F280]
- In `br_mst_vlan_set_state()`, changing `v->state` must update `vg->pvid_state` via `br_vlan_set_pvid_state()` when `v->vid == vg->pvid`; in `br_mst_vlan_set_msti()`, changing `mv->msti` must sync all ports via `br_mst_vlan_sync_state()`. Master `mv->msti` must remain `< VLAN_N_VID` because `br_mst_info_size()` and `br_mst_fill_info()` index `DECLARE_BITMAP(seen, VLAN_N_VID)` with `v->brvlan->msti`, and per-port VLAN loops must read `v->brvlan->msti`, not `v->msti`. [F229, F270, F284]
- `mp->ports` (in `br_mdb_add_group_sg()` and `br_mdb_add_group_star_g()`) and router port lists must stay sorted in descending `struct net_bridge_port *` order for `br_multicast_flood()`. When `br_multicast_should_handle_mode()` holds, `br_mdb_add_group_sg()` must call `br_multicast_sg_add_exclude_ports()`, and `br_mdb_add_group_star_g()` / `br_mdb_replace_group_star_g()` must call `br_multicast_star_g_handle_mode()`. [F241, F262]
- In `br_cfm_cc_config_set()`, when `config` changes, reset `mep->ccm_rx_snumber = 0` and `mep->ccm_tx_snumber = 1`, and when `config->enable` transitions, call `cc_peer_enable()` or `cc_peer_disable()` on all `mep->peer_mep_list` entries. `struct br_mrp_ring_test_hdr` and `struct br_mrp_in_test_hdr` must remain `__attribute__((__packed__))` because 32-bit `timestamp` sits at offset 14. [F239, F251]

## Synchronization

- `br->lock` nests outside `br->hash_lock` and `br->multicast_lock` (e.g., `br_fdb_changeaddr()`, `br_stp_disable_port()`), so never take `br->lock` while holding either. `br_fdb_update()` takes `br->hash_lock` with bare `spin_lock()` requiring BH disabled and `rcu_read_lock()` (process callers like `__br_fdb_add()` must wrap it in `local_bh_disable()` + `rcu_read_lock()`); other process/workqueue callers must use `spin_lock_bh()`. [F290, F291]
- `fdb_notify()`, `__br_mdb_notify()`, and `br_rtr_notify()` run under `br->hash_lock` or `br->multicast_lock` (and softirq), so `nlmsg_new()` and `rtnl_notify()` must use `GFP_ATOMIC`. In `br_mdb_get()`, hold `br->multicast_lock` with `spin_lock_bh()` across both `br_mdb_get_reply_alloc()` (`GFP_ATOMIC`) and `br_mdb_get_reply_fill()`, releasing it before `rtnl_unicast()`. [F294, F295]
- In `fdb_create()`, initialize `fdb->key`, `fdb->dst` (`WRITE_ONCE`), `fdb->flags`, `fdb->updated`, and `fdb->used` before `rhashtable_lookup_insert_fast()` and `hlist_add_head_rcu(&fdb->fdb_node, &br->fdb_list)`. In `struct net_bridge_fdb_entry`, `updated` and `used` are isolated via `____cacheline_aligned_in_smp` from lookup fields, and `br_handle_frame_finish()` and `br_fdb_update()` only write them when `now` differs. [F186, F301]
- When `br_fdb_cleanup()` or `br_fdb_flush()` walks `br->fdb_list` under RCU and takes `spin_lock_bh(&br->hash_lock)`, it must check `!hlist_unhashed(&f->fdb_node)` before `fdb_delete()`. Lockless FDB activity notifications must use `!test_and_set_bit(BR_FDB_NOTIFY_INACTIVE, &f->flags)` in `br_fdb_cleanup()` and `test_and_clear_bit(BR_FDB_NOTIFY_INACTIVE, &fdb->flags)` in `__fdb_mark_active()` before `fdb_notify()`. [F197, F201]
- `fdb->dst` can be `NULL` and changes locklessly via `WRITE_ONCE(fdb->dst, source)` in `br_fdb_update()`, so RCU readers (`fdb_fill_info()`, `__fdb_flush_matches()`, `br_fdb_test_addr()`, `br_fill_forward_path()`) must load `READ_ONCE(fdb->dst)` into a local variable and null-check it. In `br_forward()`, after `rcu_access_pointer(to->backup_port)`, recheck `rcu_dereference(to->backup_port)` for `NULL` and read `to->backup_nhid` with `READ_ONCE()`. [F198, F199]
- Set `IFF_BRIDGE_PORT` on `dev->priv_flags` only after `netdev_rx_handler_register()` succeeds in `br_add_if()`, and clear it before `netdev_rx_handler_unregister()` in `del_nbp()` and `br_add_if()` rollback. In `br_ioctl.c`, `get_fdb_entries()` (`br_fdb_fillbuf()`) and `br_dev_siocdevprivate()` (`BRCTL_GET_BRIDGE_INFO`/`BRCTL_GET_PORT_INFO`) must copy data into a kernel buffer under `rcu_read_lock()` and call `rcu_read_unlock()` before `copy_to_user()`. [F188, F296]

## Object Lifetimes

- In `br_add_if()`, errors before `kobject_init_and_add(&p->kobj, ...)` must free `p` via `kfree(p)` after `netdev_put()`, while errors at or after `kobject_init_and_add()` must use `kobject_put(&p->kobj)` (`release_nbp()`) and never `kfree(p)`. `del_nbp()` must detach the port from sysfs, STP, MRP, CFM, `port_list`, VLANs, FDB, `backup_port`, upper links, `rx_handler`, multicast, and netpoll under RTNL before deferring `destroy_nbp_rcu` via `call_rcu(&p->rcu, ...)` to drop `netdev_put()` and `kobject_put()`. [F170, F171]
- `nbp_backup_change()` maintains `backup_redirected_cnt` (rejecting `p == backup_p` and ignoring `old_backup == backup_p`), and `nbp_backup_clear()` during port deletion must clear both `p->backup_port` and any `cur_p->backup_port` pointing to `p` so `p->backup_redirected_cnt` reaches zero. `br_dev_delete()` must call `cancel_delayed_work_sync(&br->gc_work)` before unregistering `br->dev`, and `br_deinit()` must call `rcu_barrier()` after `unregister_pernet_subsys(&br_net_ops)` and before `br_fdb_fini()`. [F178, F192]

## API Contracts

- `br_forward()`, `br_flood()`, and `br_multicast_flood()` consume/free `@skb` when `@local_rcv` is `false`, but never when `@local_rcv` is `true` (cloning/copying `@skb` instead). Unlike `br_allowed_ingress()` (frees `@skb` on `false`) and `br_handle_vlan()` (frees `@skb` on `NULL`), `br_multicast_rcv()` does not free `@skb` on error, so callers must free it. `br_handle_local_finish()` must return `1` as the `NF_BR_LOCAL_IN` `okfn` so `br_handle_frame()` distinguishes `RX_HANDLER_PASS` (`1`) from `RX_HANDLER_CONSUMED` (`0`). [F173, F175, F305]
- `br_do_proxy_suppress_arp()` and `br_do_suppress_nd()` take a nullable `struct net_bridge_port *p` (`NULL` from `br_dev_xmit()`), so they and `br_arp_send()`, `br_nd_send()`, and `br_is_neigh_suppress_enabled()` must null-check `p`. Before `br_stp_recalculate_bridge_id()` adopts a port MAC under `br->lock` (when `addr_assign_type != NET_ADDR_SET`), `netif_pre_changeaddr_notify(br->dev, ...)` must run in process context (`br_add_if()`, `NETDEV_PRE_CHANGEADDR`). [F214, F313]
- Bitops on `fdb->flags` (`test_bit`, `set_bit`, `clear_bit`) take an unshifted `BR_FDB_*` index, whereas `fdb_create()`, `br_fdb_update()`, and `net_bridge_fdb_flush_desc` take `BIT(BR_FDB_*)`. `br_port_flag_is_set()` and `br_port_flags_change()` take a shifted `BR_*` mask, whereas `br_opt_get()` and `br_opt_toggle()` take an unshifted `enum net_bridge_opts` index. [F219, F220]
- Every `enum br_boolopt_id` `< BR_BOOLOPT_MAX` must fit in 32-bit `__u32` (`struct br_boolopt_multi`) and have cases in `br_boolopt_toggle()` and `br_boolopt_get()` (`default` triggers `WARN_ON(1)`). In `br_boolopt_multi_toggle()`, copy `bm->optmask` (`__u32`) into an `unsigned long` local before passing its address to `find_next_bit()`/`for_each_set_bit()`, and reject bits `>= BR_BOOLOPT_MAX` before `BIT(opt_id)`. [F260, F276, F282]
- Entry points and notifiers taking `struct net_device *` (`br_device_event`, `br_fdb_find_port`, `br_mst_enabled`, `br_mst_get_info`, `br_del_bridge`, `br_ioctl_stub`) must check `netif_is_bridge_master(dev)` before `netdev_priv(dev)`. `br_mst_get_info()` (which requires a zeroed `vids` bitmap of `>= VLAN_N_VID` bits), `br_mst_get_state()`, `br_fdb_find_port()`, `br_fdb_clear_offload()`, and `br_port_get_stp_state()` require `rtnl_mutex`, whereas `br_port_flag_is_set()` and atomic notifier `br_switchdev_event()` must use `br_port_get_rtnl_rcu(dev)` and never sleep. [F281, F283, F299, F300]
- `br_cfm_cc_ccm_tx_info.period` is in seconds (`* 1000000` for `usecs_to_jiffies()`), `ccm_rx_timer_start()` schedules `ccm_rx_dwork` at `interval_to_us(exp_interval) / 4`, and `br_mrp_start_test` / `br_mrp_start_in_test` intervals/periods are in microseconds. [F221]

## Error Handling

- `new_nbp()` returns `ERR_PTR` (never `NULL`), so `br_add_if()` must check `IS_ERR(p)`. `maybe_deliver()` returns `NULL` (no match yet), `p`, or `ERR_PTR(err)`, so `br_flood()` and `br_multicast_flood()` must check `IS_ERR(prev)` each iteration. In `br_device_event()`, `br_switchdev_event()`, and `br_switchdev_blocking_event()`, encode negative errnos with `notifier_from_errno(err)`. In `br_mst_set_state()`, `br_mst_vlan_set_msti()`, and `br_mst_set_enabled()`, ignore `-EOPNOTSUPP` from `switchdev_port_attr_set()` (and reset `err = 0` in `br_mst_set_state()`). [F203, F204, F205, F206]
- In `br_mdb_add_group_srcs()` and `br_mdb_replace_group_srcs()`, failure at signed index `i` must delete added sources `0..i-1` in reverse (`for (i--; i >= 0; i--)`) via `br_mdb_del_group_src()` and clear `BR_SGRP_F_DELETE` on `pg->src_list`. Static FDB rollback in `br_fdb_sync_static()` must walk from `br->fdb_list` head with cursor `tmp` stopping at `tmp == f`, while `fdb_add_hw_addr()` uses `list_for_each_entry_continue_reverse()` from `p`. RX fastpath warnings (`br_fdb_update()`) must use `net_ratelimit()`. [F180, F250, F265, F322]

## External Contracts

- In `br_ioctl.c`, `get_fdb_entries()` must clamp `maxnum` to `PAGE_SIZE / sizeof(struct __fdb_entry)`, and `br_fdb_fillbuf()` must `memset()` the buffer and split 16-bit `f->dst->port_no` across `fe->port_no` and `fe->port_hi` (`port_no >> 8`). Mutating ioctls must check `ns_capable(net->user_ns, CAP_NET_ADMIN)`, `br_dev_read_uargs()` must handle `in_compat_syscall()` (`cargs` and `compat_ptr(args[1])`), and `IFNAMSIZ` name buffers from userspace must set `buf[IFNAMSIZ - 1] = 0`. `br_cfm_status_fill_info()` must clear sticky `*_seen` flags only when `getlink` is `true`. [F238, F244, F289, F302, F316, F317]

## Known Pitfalls

- `pskb_may_pull()` and `br_allowed_ingress()` can reallocate `skb->head`, so `br_dev_xmit()`, `br_handle_frame_finish()`, and `br_do_proxy_suppress_arp()` must re-fetch `eth_hdr()`, `arp_hdr()`, and `ipv6_hdr()` afterward, and `br_do_proxy_suppress_arp()` must verify `pskb_may_pull(skb, arp_hdr_len(dev))` and `parp->ar_hln == dev->addr_len && parp->ar_pln == 4` before reading `sha`/`sip`/`tip`. In `maybe_deliver_addr()`, wrap `pskb_copy()` with `__skb_push(skb, ETH_HLEN)` and `__skb_pull(..., ETH_HLEN)` on `skb` and `nskb` so the Ethernet header is copied. [F232, F247, F308]
- `dev_set_mtu(br->dev, ...)` calls `br_change_mtu()` which sets `BROPT_MTU_SET_BY_USER`, so `br_mtu_auto_adjust()` must clear `BROPT_MTU_SET_BY_USER` afterward. In `br_fdb_delete()`, when `vid == 0`, `err` starts at `-ENOENT` and uses `err &= __br_fdb_delete(...)`, relying on `__br_fdb_delete()` returning only `0` or `-ENOENT`. FDB (`has_expired`, `br_fdb_cleanup`), CFM (`ccm_tx_work_expired`), and MRP (`br_mrp_test_work_expired`, `br_mrp_in_test_work_expired`) deadline checks must use `time_before_eq()` / `time_after()`. [F228, F268, F273]
- In `br_mdb.c`, callers must validate `MDBE_ATTR_SOURCE` and `MDBE_SRCATTR_ADDRESS` with `is_valid_mdb_source()` before `nla_get_in6_addr()` or `nla_memcpy()`. In `br_mdb_fill_info()`, reset `pidx = 0` and `s_pidx = 0` after each outer `net_bridge_mdb_entry`, and jump directly to `out:` if `__mdb_fill_info()` fails so `cb->args[1..2]` save `idx` and `pidx`. [F249, F266]
