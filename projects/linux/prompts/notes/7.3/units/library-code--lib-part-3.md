# LIBRARY CODE — lib (part 3)

Provides core reference-counting primitives (`rcuref.c`, `refcount.c`, `ref_tracker.c`), scatterlist and DMA/page iteration helpers (`scatterlist.c`, `sg_pool.c`, `sg_split.c`), deduplicated stack trace storage (`stackdepot.c`), safe usercopy and string helpers (`usercopy.c`, `strncpy_from_user.c`, `strnlen_user.c`, `ucs2_string.c`, `seq_buf.c`), pluggable text search (`textsearch.c`, `ts_bm.c`, `ts_fsm.c`, `ts_kmp.c`), general utilities (`sort.c`, `timerqueue.c`, `win_minmax.c`, `xxhash.c`, `syscall.c`, `smp_processor_id.c`), and self-test modules (`test_firmware.c`, etc.).

## Architecture & Data Flow

- In `sg_append_table`, `sgt.orig_nents` and `sgt.nents` count only populated SG entries, while total allocated entries across chained chunks are tracked in `total_nents` and freed via `sg_free_append_table`. In `sg_split_phys`, after `*out_sg = *in_sg`, only the first entry (`!j`) adjusts `offset`/`length` by `split->skip_sg0`; `j > 0` keeps `in_sg->offset`, and all output entries must zero `dma_address` and `dma_length`. [F212, F217]
- In `extract_bvec_to_sg` and `extract_kvec_to_sg`, `start` starts at `iter->iov_offset`, decrements across skipped segments (`start >= len`), and resets to `0` after the first extracted segment. In `__sg_page_iter_next` and `__sg_page_iter_dma_next`, a `while` loop (not `if`) must check `piter->sg_pgoffset >= sg_page_count(piter->sg)` to skip empty entries until `--piter->__nents == 0`. [F247, F250]
- In `lib/stackdepot.c`, `union handle_parts` stores `pool_index + 1` in `pool_index_plus_1` (`DEPOT_POOL_INDEX_BITS` wide) so valid handles are non-zero; `stack_max_pools` must not exceed `(1LL << DEPOT_POOL_INDEX_BITS) - 1`, `depot_fetch_stack` must subtract 1 into `u32 pool_index` and reject `>= pools_num_cached`, and `size` in `depot_pop_free_pool` must be aligned via `depot_stack_record_size`. In `struct stack_record`, `entries` unions with `free_list`/`rcu_state` (valid only when `refcount_read(&stack->count) == 0`), and `depot_alloc_stack` sizes `STACK_DEPOT_FLAG_GET` records for `CONFIG_STACKDEPOT_MAX_FRAMES`. [F220, F231, F262, F263]
- Under `dir->lock`, `ref_tracker_free` appends `tracker->head` to `dir->quarantine` and either decrements `dir->quarantine_avail` or pops the head entry to `kfree` after unlocking (`ref_tracker_dir_exit` increments `quarantine_avail` per freed entry). In `ref_tracker_get_stats`, `++stats->total` and the `0 .. stats->count - 1` search must precede `if (i >= limit) continue;`. [F223, F260]
- In `struct seq_buf`, overflow sets `s->len = s->size + 1` (`seq_buf_set_overflow`), so bound valid bytes with `seq_buf_used(s)`. String writers (`seq_buf_puts`, `seq_buf_vprintf`, `seq_buf_bprintf`) require room for NUL (`s->len + text_len < s->size`) without counting it in `s->len`, whereas raw writers (`seq_buf_putmem`, `seq_buf_putc`) allow `s->len == s->size` and require `seq_buf_str()` before C-string use. [F225, F235]
- In `lib/ts_fsm.c`, `fsm_init` rejects patterns not a multiple of `sizeof(struct ts_fsm_token)`, tokens with `type > TS_FSM_TYPE_MAX` or `recur > TS_FSM_RECUR_MAX`, and `TS_FSM_HEAD_IGNORE` at `i != 0` or `i == ntokens - 1`, before translating `t->type` in-place to `token_map[t->type]`. In `fsm_find`, `TS_FSM_MULTI` increments `block_idx++` before falling through to `TS_FSM_ANY`, and `TS_FSM_ANY`, `TS_FSM_HEAD_IGNORE`, and unmatched `TS_FSM_PERHAPS` must end with `continue` (not `break`) when `next` matches `data[block_idx]`. [F227, F243, F254]
- In `lib/sort.c`, `is_aligned(base, size, align)` checks `size` is a multiple of `align` (4 or 8) even with `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` (and checks `base` when disabled). In `__sort_r`, `SWAP_WORDS_64` is `(swap_r_func_t)0`, so unwrapping `SWAP_WRAPPER` when `!((struct wrapper *)priv)->swap` to `NULL` must precede `if (!swap_func)`, and `do_swap` must check `swap_func == SWAP_WORDS_64` before the indirect call. [F244, F256]
- `timerqueue_del` must call `RB_CLEAR_NODE(&node->node)` after `rb_erase_cached`. In `lib/xxhash.c`, all 32/64-bit loads from input and `state->mem64` must use `get_unaligned_le32`/`le64`. In `lib/win_minmax.c`, `minmax_subwin_update` and `minmax_running_max`/`min` must compute elapsed time as `u32` modular difference `val.t - m->s[i].t` before comparing against `win`. [F228, F245, F272]

## Synchronization

- `refcount_dec_and_mutex_lock`, `refcount_dec_and_lock`, and `refcount_dec_and_lock_irqsave` acquire `@lock` when `refcount_dec_not_one(r)` is `false` and release `@lock` if `refcount_dec_and_test(r)` is `false`, so `@lock` is held on return iff they return `true`. [F169]
- In `lib/ref_tracker.c`, initialize `debugfs_reap_worker`, `debugfs_dentries`, and `debugfs_symlinks` in `postcore_initcall` with `XA_FLAGS_LOCK_IRQ` (not `late_initcall`). `ref_tracker_dir_exit` marks dentries/symlinks `REF_TRACKER_DIR_DEAD` and schedules `debugfs_reap_worker` before taking `dir->lock`, while `ref_tracker_debugfs_show` checks `debugfs_dentries` under `xa_lock_irqsave` and acquires `dir->lock` before dropping `xa_lock`. `__ref_tracker_dir_pr_ostream`, `ref_tracker_dir_print_locked`, and `ref_tracker_get_stats` require `dir->lock` held, and internal `kmalloc`/`stack_depot_save` calls (including in `ref_tracker_free`) must use `GFP_NOWAIT`. [F182, F183, F297, F298]
- In `lib/stackdepot.c`, `pool_lock` (`raw_spinlock_t`) protects all writes to `stack_pools`, `new_pool`, `pools_num`, `pool_offset`, and `free_stacks`, while `depot_fetch_stack` must never hold `pool_lock`; in `depot_init_pool`, `stack_pools[pools_num] = new_pool` must precede `WRITE_ONCE(pools_num, pools_num + 1)`. In `stack_depot_save_flags`, re-run `find_stack` under `pool_lock` before `depot_alloc_stack`; when `in_nmi()` or `!gfpflags_allow_spinning(alloc_flags)` (`!allow_spin`), `pool_lock` uses `raw_spin_trylock_irqsave`, skips page allocation, and frees unused `prealloc` at `exit` with `free_pages_nolock` (vs. `free_pages`). [F185, F186, F187, F291, F295]
- In `find_stack`, traverse buckets under `rcu_read_lock_sched_notrace()` and, when `STACK_DEPOT_FLAG_GET` is set, succeed in `refcount_inc_not_zero(&stack->count)`. `depot_free_stack` unlinks `stack->hash_list` (`list_del_rcu`), sets `stack->rcu_state = get_state_synchronize_rcu()`, and appends to `free_stacks` tail; `depot_pop_free` checks `poll_state_synchronize_rcu(stack->rcu_state)` on the first entry before reuse. [F188, F189]
- In `lib/textsearch.c`, `textsearch_register`/`unregister` hold `ts_mod_lock` and use `list_add_tail_rcu`/`list_del_rcu` on `ts_ops`, while `lookup_ts_algo` holds `rcu_read_lock()` across `list_for_each_entry_rcu` and `try_module_get(o->owner)`; `textsearch_prepare` calls `request_module` only when `ops == NULL` and `flags & TS_AUTOLOAD`, and either transfers the module ref into `conf->ops` for `textsearch_destroy` or calls `module_put(ops->owner)` if `ops->init` fails. [F174, F190, F306]
- `sg_pool_init` (`lib/sg_pool.c`) must use `subsys_initcall`. In `extract_xarray_to_sg`, `xas_for_each` on `iter->xarray` runs under `rcu_read_lock()` and checks `if (xas_retry(&xas, folio)) continue;`. In `noinstr` `check_preemption_disabled` (`lib/smp_processor_id.c`), check `current->migration_disabled` without `#ifdef CONFIG_SMP`, and pair `preempt_disable_notrace()` + `instrumentation_begin()` with `instrumentation_end()` + `preempt_enable_no_resched_notrace()` on all exits. [F192, F289, F290, F303]
- In `lib/test_firmware.c`, sysfs store handlers (`config_num_requests_store`, `config_buf_size_store`, `config_file_offset_store`) and batch triggers (`trigger_batched_requests_store`, `trigger_batched_requests_async_store`) must hold `test_fw_mutex` across checking `test_fw_config->reqs` (rejecting non-NULL with `-EBUSY` unless freed by `__test_release_all_firmware`) and updating config or allocating `reqs`. [F176, F191]

## Object Lifetimes

- If `__sg_alloc_table` fails after allocating chunks, it leaves the partial chain in `table->sgl` (incrementing `table->orig_nents` if `prv != NULL`) and requires `__sg_free_table` with the same `max_ents` and `nents_first_chunk` (skipping `free_fn` on chunk 0 when `nents_first_chunk != 0`, and normalizing `nents_first_chunk == 1` to `0` in `sg_free_table_chained`); when `alloc_size > curr_max_ents`, `__sg_free_table` reads `next = sg_chain_ptr(&sgl[curr_max_ents - 1])` before `free_fn(sgl, alloc_size)` and decrements `num_ents` by `sg_size` (`curr_max_ents - 1`). [F162, F163, F165, F249]
- Every `struct sg_mapping_iter` advanced by `sg_miter_next` holds a page mapping when `miter->addr != NULL` that must be released by `sg_miter_stop`; both must match `miter->__flags` (`kmap_atomic` for `SG_MITER_ATOMIC`, `kmap_local_page` for `SG_MITER_LOCAL`, else `kmap`), and `sg_miter_stop` calls `flush_dcache_page(miter->page)` when `SG_MITER_TO_SG` is set. [F166, F301]
- `__rcuref_put` (and `rcuref_put_rcusafe`) requires preemption disabled or `rcu_read_lock()`, and the caller may deconstruct the object iff `rcuref_put_slowpath` sees `cnt == RCUREF_NOREF`, transitions `ref->refcnt` to `RCUREF_DEAD` via `atomic_try_cmpxchg_release`, issues `smp_acquire__after_ctrl_dep()`, and returns `true`; `rcuref_get_slowpath` returns `false` (setting `RCUREF_DEAD`) when `cnt >= RCUREF_RELEASED` and `true` (setting `RCUREF_SATURATED`) when `cnt > RCUREF_MAXREF`. [F168, F179, F208]
- In `stack_depot_save_flags`, a `prealloc` pool page is either consumed under `pool_lock` by `depot_init_pool` or `depot_keep_new_pool` (setting `prealloc = NULL` only if `new_pool == NULL`) or freed on exit; `depot_init_pool` resets `new_pool` to `NULL` only while `pools_num < stack_max_pools` and sets `new_pool = STACK_DEPOT_POISON` at capacity. [F172, F221]
- In `lib/test_firmware.c`, `release_firmware(req->fw)` does not free `test_buf` (`test_fw_config->into_buf`), so `test_fw_run_batch_request` frees `test_buf` if `!req->fw` or saves it in `req->fw_buf` for `__test_release_all_firmware` (`kfree_const`). In `upload_unregister_store` / `upload_release_all`, clear `test_fw_config->upload_name` if it aliases `tst->name` and call `firmware_upload_unregister(tst->fwl)` in `upload_release` before freeing `tst->buf`, `tst->name`, and `tst`. [F175, F286]

## API Contracts

- `pages_are_mergeable(a, b)` takes the next candidate `struct page *` as `a` and the preceding page as `b` (`page_to_pfn(a) != page_to_pfn(b) + 1`). `sg_alloc_append_table_from_pages` aligns `max_segment` down to `PAGE_SIZE`, rejects `max_segment < PAGE_SIZE` or non-zero `offset` when `sgt_append->prv != NULL` (`-EINVAL`), and sets `sg_mark_end` only when `left_pages == 0`. `extract_iter_to_sg` pins pages only for `ITER_UBUF`/`ITER_IOVEC`, updates `sgtable->nents` (not `orig_nents`), and does not call `sg_mark_end`; `extract_folioq_to_sg` and `extract_xarray_to_sg` add multi-page folios via `folio_page(folio, 0)` and `offset_in_folio(folio, start)`. [F193, F242, F315, F316]
- `seq_buf_vprintf`, `seq_buf_printf`, `seq_buf_puts`, `seq_buf_putc`, and `seq_buf_putmem` return `0` on success and `-1` on overflow, whereas `seq_buf_path` returns written bytes on success and `-1` on overflow. [F199]
- In `check_zeroed_user`, `strncpy_from_user`, and `strnlen_user`, bracket all `unsafe_get_user` calls with `user_read_access_begin` (or `masked_user_access_begin`) and `user_read_access_end` on every exit. `strnlen_user(str, count)` returns `0` (not `-EFAULT`) on fault, limit overflow, or `count <= 0`, length including NUL on success, and `> count` on truncation; `check_zeroed_user(from, size)` returns `1` if all zero, `0` if non-zero, or `-EFAULT` (signed `int`). [F201, F202, F307]
- When `handle == 0` in `lib/stackdepot.c`, `stack_depot_set_extra_bits` returns `0` without setting `extra_bits`, and `stack_depot_fetch` sets `*entries = NULL` and returns `0`. A `struct ts_config` is shareable across concurrent `textsearch_find`/`next` calls only if each caller uses its own `struct ts_state` and does not mutate `conf->get_next_block` or `conf->finish`. In `lib/sort.c`, `sort_r` and `sort` pass `may_schedule = false` (atomic-safe), whereas `sort_r_nonatomic` and `sort_nonatomic` pass `may_schedule = true`. [F206, F226, F304]
- In `lib/ucs2_string.c`, `ucs2_strnlen`, `ucs2_strscpy`, and `ucs2_strncmp` take bounds in `ucs2_char_t` units (`count <= INT_MAX / sizeof(ucs2_char_t)` in `ucs2_strscpy`), whereas `ucs2_strsize` and `ucs2_as_utf8` take `maxlength` in bytes; `ucs2_as_utf8` stops before any multi-byte UTF-8 char exceeding `maxlength` and writes `'\0'` only if `maxlength > 0` after the loop. [F240, F320]

## Error Handling

- `get_next_sg` (`lib/scatterlist.c`) returns `ERR_PTR(-ENOMEM)` (not `NULL`), and `sg_alloc_append_table_from_pages` must check `IS_ERR(s)` and restore `sgt_append->prv->length = prv_len` before returning `PTR_ERR(s)`. [F197]
- `collect_syscall` (`lib/syscall.c`) passes a zeroed `unsigned long args[6]` to `syscall_get_arguments` only when `info->data.nr != -1L` and copies elements to `info->data.args` (`__u64[6]`), or zeroes `*info` and sets `info->data.nr = -1` when `try_get_task_stack(target)` fails, returning `0` in both cases and `-EAGAIN` only when `!task_pt_regs(target)`. [F211, F274]
- In `lib/test_firmware.c`, `test_fw_cleanup` runs only if `test_fw_upload_prepare` succeeds, so `test_fw_upload_prepare` must reset `tst->inject.err_code` and `tst->inject.prog` on its `err_out` path, and `fw_upload_err_str[]` must stay synced with `enum fw_upload_err`. [F177, F230]

## External Contracts

- When `do_strncpy_from_user` finds NUL during word copying, zero all bytes after NUL in the final `unsigned long` written to `dst` (`c & mask`). When `can_do_masked_user_access()` is false, `strncpy_from_user` and `strnlen_user` must strip tags (`untagged_addr`), check `src_addr < TASK_SIZE_MAX`, and clamp `max` to `min(TASK_SIZE_MAX - src_addr, count)`. Format `struct ref_tracker_dir *` pointers with `%p` (never `%px`/`%lx`). [F236, F308, F312]

## Known Pitfalls

- In `seq_buf_putmem_hex`, cap `start_len` to `MAX_MEMHEX_BYTES` (8) rather than `HEX_CHARS` (17), and both decrement `len` and advance `data` by `start_len`. When `do_strnlen_user` and `check_zeroed_user` align the pointer down by `align` and add `align` to `max`/`size`, mask leading bytes with `aligned_byte_mask(align)` (and trailing bytes with `aligned_byte_mask(size)` in `check_zeroed_user`), and stop the word loop when remaining bytes are `<= sizeof(unsigned long)`. [F233, F237, F252, F258]
- In `extract_user_to_sg`, treat `res <= 0` from `iov_iter_extract_pages` as failure jumping to `failed`. In `sgl_alloc_order`, check `if (length > (nent << (PAGE_SHIFT + order))) return NULL;` after narrowing `nent` to `unsigned int` (and `nalloc + 1 < nalloc` when `chainable`), and in `sg_page_count`, `sg_dma_page_count`, and `extract_user_to_sg`, round `offset + length` up to `PAGE_SIZE` before dividing. [F246, F269, F270]
- In `bm_find` (`lib/ts_bm.c`), reinitialize `int shift = bm->patlen - 1` at the start of every outer `for (;;)` iteration. After `list_for_each_entry` / `list_for_each_entry_rcu` (`upload_read_show`, `find_stack`), never test or dereference the loop cursor; use a separate `NULL`-initialized match pointer. [F253, F261]
- In `stack_depot_init`, scaling `entries` must branch on `scale > PAGE_SHIFT` (`>>=` vs. `<<=`) for 64KB pages. In `refcount_dec_not_one`, `val` and `new = val - 1` must be `unsigned int` so decrementing from `0` wraps and triggers `new > val`. In `lib/sort.c`, `parent()` adjusts `i -= size & -(i & lsbit)` before dividing by 2, and `sort`/`sort_nonatomic` pass `cmp_func_t`/`swap_func_t` via `struct wrapper` (`_CMP_WRAPPER`/`SWAP_WRAPPER`). [F264, F266, F267, F276]
- Cast `au.s.high`, `bu.s.high`, `au.s.low`, and `bu.s.low` to `unsigned int` in `__ucmpdi2`; tolerate `sbuf == NULL` on `kmalloc` failure in `__ref_tracker_dir_pr_ostream`; and in `stmp_reset_block`/`stmp_clear_poll_bit`, write bitmasks to `reset_addr + STMP_OFFSET_REG_SET`/`CLR` while polling base `reset_addr` after `udelay(1)` with a bounded `timeout`. [F273, F283, F284]
