# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 5)

GuC workload submission, SR-IOV GuC relay, GuC TLB invalidation, HuC/late-binding firmware, hardware engines/groups, hardware fences, PCI/MSI-X and error interrupts, hwmon, DesignWare I2C, LMTT, and LRC management.

## Architecture & Data Flow
- `alloc_guc_id()` stores a parallel `xe_exec_queue` at every ID in `q->guc->id .. q->guc->id + q->width - 1` in `exec_queue_lookup`; per-queue transition loops (`xe_guc_submit_stop()`/`_start()`) must skip `q->guc->id != index`. In `guc_exec_queue_start()`, before `xe_sched_resubmit_jobs(sched)` on an active queue, set every LRC's head (`0 .. q->width - 1`) to `q->lrc[i]->ring.tail` via `xe_lrc_set_ring_head()`, and `register_exec_queue()` must reset `wqi_head`/`wqi_tail` to 0 for parallel queues. [F461, F463]
- In `xe_lrc.c`, `__xe_lrc_wa_bb_offset()`, `__xe_lrc_indirect_ctx_offset()`, and `__xe_lrc_indirect_ring_offset()` compute offsets backward from `xe_bo_size(lrc->bo)` and must be updated in lockstep with `xe_lrc_init()`/`xe_gt_lrc_size()`. When `xe_lrc_has_indirect_ring_state(lrc)` is true, ring registers (`START`, `HEAD`, `TAIL`, `CTL`) reside in the indirect ring state page (`xe_lrc_read_indirect_ctx_reg()`/`xe_lrc_write_indirect_ctx_reg()`), not the main context image (`xe_lrc_read_ctx_reg()`/`xe_lrc_write_ctx_reg()`). [F455, F456]
- Every `u8` offset table passed to `set_offsets()` must end with a `0` sentinel byte (`MI_BATCH_BUFFER_END | BIT(0)`), and `set_offsets()` must advance `regs += 2` per `MI_LOAD_REGISTER_IMM` entry (`regs[0]` offset, `regs[1]` value) without overwriting `regs[1]`. `xe_lrc_setup_wa_bb_with_scratch()` must set `reserve_dw = 1` in `struct bo_setup_state` for `MI_BATCH_BUFFER_END`, and `setup_indirect_ctx()` must pad `state.written` with `MI_NOOP` to 16 dwords (64 bytes) before writing `CTX_CS_INDIRECT_CTX`. [F487, F488, F520]
- `xe_hw_engine_setup_groups()` leaves `hwe->hw_engine_group` as `NULL` for `XE_ENGINE_CLASS_OTHER`, and `xe_hw_engine_group_add_exec_queue()`/`_del_exec_queue()` assert `group` is non-NULL; check `q->hwe->hw_engine_group` first. In `gt_irq_handler()`, check `xe_gt_hw_engine(engine_gt, class, instance, false)` before `class == XE_ENGINE_CLASS_OTHER` so `XE_HW_ENGINE_GSCCS0` reaches `xe_hw_engine_handle_irq()`. [F443, F501]
- `hwe->eclass->defaults` is snapshotted once from `sched_props` in `hw_engine_init_early()`; sysfs store handlers in `xe_hw_engine_class_sysfs.c` must only mutate `eclass->sched_props`. [F466]
- `late_bind_fw_to_xe()` and `xe_late_bind_work()` use `lb_fw->id` inside `container_of(..., late_bind_fw[lb_fw->id])`; initialize `lb_fw->id = fw_id` in `__xe_late_bind_fw_init()` before calling `parse_lb_layout()`, `parse_cpd_header()`, `late_bind_fw_to_xe()`, or queuing `lb_fw->work`. [F522]
- In `relay_send_message_and_wait()`, call `reinit_completion(&txn->done)` before jumping to `resend` (`-EAGAIN`) or `wait` (`-EBUSY`), and call `list_del_init(&txn->link)` under `relay->lock` before returning. [F494]
- `xe_hw_fence_signaled()` must compare the 32-bit seqno from `fence->seqno_map` against `dma_fence->seqno` via `!__dma_fence_is_later(dma_fence, dma_fence->seqno, seqno)`, and `gt_engine_identity()` must compare `local_clock() >> 10` against `timeout_ts` via `time_after32()`. In `xe_hwmon_energy_get()`, compute `reg_val - ei->reg_val_prev` in `u32` arithmetic before adding to `ei->accum_energy` (`long`) and scaling via `mul_u64_u32_shr()`. [F509, F511, F512]

## Synchronization
- `xe_guc.submission_state.lock` is primed under `fs_reclaim_acquire(GFP_KERNEL)` and held in the dma-fence signaling path; holders (`alloc_guc_id()`, `xe_guc_jobs_ring_rebase()`) must not do `GFP_KERNEL` allocations or wait on GuC/HW responses. [F411]
- Queuing `STATIC_MSG_SUSPEND`/`STATIC_MSG_RESUME` via `guc_exec_queue_try_add_msg()` and setting `q->guc->suspend_pending = true` must hold `xe_sched_msg_lock(sched)` (`sched->base.job_list_lock`) and check `list_empty(&msg->link)`. In `wq_item_append()`, issue `xe_device_wmb(xe)` after writing `guc_submit_parallel_scratch.wq` and before updating `wq_desc.tail`, and keep each `struct sync_semaphore` padded to `CACHELINE_BYTES` (64B). [F418, F563]
- Mutating `group->exec_queue_list` or `group->cur_mode` requires write-locking `group->mode_sem` (`hw_engine_group_resume_lr_jobs_func()` read-locks it). In `switch_mode()`, changing `group->cur_mode` requires first suspending/waiting on faulting LR queues (`xe_hw_engine_group_suspend_faulting_lr_jobs()`) or waiting on DMA-fence jobs (`xe_hw_engine_group_wait_for_dma_fence_jobs()`). [F427, F467]
- `xe->irq.lock` is taken with `spin_lock()` in hardirq (`gt_irq_handler()`) and required by `gt_engine_identity()` and `csc_hw_error_handler()`; `hw_error_source_handler()` (called from both IRQ and `xe_hw_error_init()`) must use `spin_lock_irqsave()`. `gt_engine_identity()` must write `BIT(bit)` to `IIR_REG_SELECTOR(bank)`, poll `INTR_IDENTITY_REG(bank)` for `INTR_DATA_VALID` up to ~100us, and write `ident` back to clear it. [F528, F560]

## Object Lifetimes
- Every `xe_sched_msg` queued by `guc_exec_queue_add_msg()` takes `xe_pm_runtime_get_noresume()` released in `guc_exec_queue_process_msg()`; `SET_SCHED_PROPS` must be freed via `kfree(msg)`, while `CLEANUP`, `SUSPEND`, and `RESUME` use `q->guc->static_msgs` and must not be freed. [F399]
- `xe_hw_fence_alloc()` / `xe_lrc_alloc_seqno_fence()` returns an uninitialized `struct dma_fence *`; before `xe_hw_fence_init()` sets `fence->ops = &xe_hw_fence_ops` and passes `&ctx->irq->lock` to `dma_fence_init()` (so `xe_hw_fence_irq()` can use `container_of(fence->dma.lock, ...)`), error paths must use `xe_hw_fence_free()` (never `dma_fence_put()` or `to_xe_hw_fence()`). `xe_hw_fence_enable_signaling()` takes `dma_fence_get()` on `irq->pending`, which `hw_fence_irq_run_cb()` and `xe_hw_fence_irq_finish()` must drop after `list_del_init(&fence->irq_link)`. `xe_hw_fence_release()` uses `call_rcu(&dma_fence->rcu, fence_free)`, `xe_hw_fence_irq_finish()` calls `synchronize_rcu()`, and `xe_hw_fence_module_exit()` calls `rcu_barrier()` before `kmem_cache_destroy()`. [F401, F442, F523, F568]
- `xe_lrc_snapshot_capture()` takes `snapshot->lrc_bo = xe_bo_get(lrc->bo)` which `xe_lrc_snapshot_capture_delayed()` puts and clears to `NULL`; `xe_lrc_snapshot_free()` must still conditionally `xe_bo_put(snapshot->lrc_bo)`. `xe_hw_engine_snapshot_capture()` locks `matched_node` via `xe_guc_capture_get_matching_and_lock(q)`, which `xe_hw_engine_snapshot_free()` must release via `xe_guc_capture_put_matched_nodes(&gt->uc.guc)` before freeing `snapshot`. [F402, F407]
- In `hw_engine_init()`, error paths must reset `hwe->name = NULL` (and unpin `hwe->hwsp`) because `xe_hw_engine_is_valid(hwe)` tests `hwe->name != NULL`. Sysfs kobjects in `xe_hw_engine_class_sysfs.c` must use `kzalloc()` (never `devm_kzalloc()`) and `kobject_put()` via `devm_add_action_or_reset()` because `xe_hw_engine_sysfs_kobj_release()` calls `kfree(kobj)`. [F410, F540]
- All VF LMTT pages from `xe_lmtt_prepare_pages()` must be freed via `xe_lmtt_drop_pages()` before teardown (`lmtt_fini_pd()` asserts `!pd->entries[n]`). `lmtt_drop_pages()` must clear `pd->entries[vfid] = NULL`, write `LMTT_PTE_INVALID` (`lmtt_write_pte()`), and flush TLBs (`lmtt_invalidate_hw()`) before `lmtt_destroy_pt()`. `xe_lmtt_init()` must clear `lmtt->ops = NULL` if `lmtt_init_pd()` fails (`fini_lmtt()` asserts `!(!!lmtt->ops ^ !!lmtt->pd)`). [F406, F448, F468]
- In `heci_gsc_add_device()`, set `heci_gsc->adev = adev` after `auxiliary_device_init()` and before `auxiliary_device_add()`. If `auxiliary_device_init()` fails, call `kfree(adev)`; if `auxiliary_device_add()` fails, set `heci_gsc->adev = NULL` and call `auxiliary_device_uninit()` without `kfree(adev)` (`heci_gsc_release_dev()` frees it). [F432, F453]
- `xe_late_bind_fw_load()` takes `xe_pm_runtime_get_noresume(xe)` before queuing `lbfw->work`; `xe_late_bind_work()` must call `xe_pm_runtime_put(xe)` on every exit path and free/clear `lbfw->payload` (`drmm_kfree()`, `lbfw->payload = NULL`) on any non-zero final result from `push_payload()` (negative errno or positive `INTEL_LB_STATUS_*` decoded by `xe_late_bind_parse_status()`) or timeout. [F438, F535]

## API Contracts
- G2H handlers run under `guc->ct.lock` and cannot reserve G2H space: `disable_scheduling_deregister()` must reserve G2H space for both `G2H_LEN_DW_SCHED_CONTEXT_MODE_SET` and `G2H_LEN_DW_DEREGISTER_CONTEXT`, and `deregister_exec_queue()` must use `xe_guc_ct_send_g2h_handler()`. [F552]
- In `xe_guc_relay.c`, all lengths, buffer sizes, and positive return values in `xe_guc_relay_send_to_vf()`, `xe_guc_relay_send_to_pf()`, `__relay_get_transaction()`, and `relay_action_handler()` are `u32` dword counts (`memcpy()` multiplies by `sizeof(u32)`). Pass `buf`/`buf_size` either both `NULL`/`0` or both non-zero with `GUC_RELAY_MSG_MIN_LEN <= buf_size <= GUC_RELAY_MSG_MAX_LEN`. [F441, F516]
- `xe_guc_relay_process_guc2vf()`/`_guc2pf()` must check `len` in `[MIN_LEN, MAX_LEN]` (and `origin <= relay_get_totalvfs(relay)` on PF) before subtracting the outer header length and calling `relay_process_msg()` (`len >= GUC_HXG_MSG_MIN_LEN`). `__relay_get_transaction()` must use `GFP_ATOMIC` for incoming requests (under `ct->lock` in reclaim) and `GFP_NOWAIT` for outgoing requests, deferring `relay_send_transaction()` for incoming actions to `relays_worker_fn()`. [F476, F559]
- `xe_lrc_write_ring()` requires 4B-aligned `size`, splits writes across `lrc->ring.size`, pads odd-dword writes with `MI_NOOP` (8B-aligned `lrc->ring.tail`), and only updates software `lrc->ring.tail`; `submit_exec_queue()` must flush it via `xe_lrc_set_ring_tail()` (single-LRC) or `wq_item_append()` encoding `lrc->ring.tail / sizeof(u64)` (parallel). `scratch` passed to `xe_guc_contexts_hwsp_rebase()` must be non-NULL when `lrc->bo->vmap.is_iomem` is true and at least `max(xe_lrc_reg_size(xe), LRC_WA_BB_SIZE)` bytes. [F457, F489, F518]
- `xe_lmtt_prepare_pages()`, `xe_lmtt_populate_pages()`, and `xe_lmtt_drop_pages()` require an initialized `lmtt->pd`, 1-based `vfid` (`1 <= vfid <= lmtt->ops->lmtt_pte_num(pd->level)`), and 2 MiB (`lmtt_page_size(lmtt)`) aligned `range`, `offset`, and `xe_bo_size(bo)`; `pt->entries[]` exists only when `pt->level > 0`. [F447, F486]
- `xe_hw_engine_lookup()` must bounds-check `eci.engine_class` against `ARRAY_SIZE(user_to_xe_engine_class)` with `array_index_nospec()`. In `check_gsc_availability()`, if `XE_HW_ENGINE_GSCCS0` is in `engine_mask` but `!xe_uc_fw_is_available(&gt->uc.gsc.fw)`, clear `BIT(XE_HW_ENGINE_GSCCS0)` and set `GUNIT_GSC_INTR_ENABLE = 0`, `GUNIT_GSC_INTR_MASK = ~0`. [F484, F539]
- In `xe_irq_msix_request_irq()`, `u16 *msix` is an in-parameter when `!dynamic_msix` and an out-parameter (`[NUM_OF_STATIC_MSIX, nvec - 1]`) when `dynamic_msix`. In `xe_irq_reset()` (`GRAPHICS_VERx100(xe) >= 1210`, non-VF), reset per-tile lower IRQs (`dg1_irq_reset()`, `GU_MISC_IRQ_OFFSET`, display) before `dg1_irq_reset_mstr()` (`GFX_MSTR_IRQ`). `mask_and_disable()` must write `~0` to `IMR` with a posting read before clearing `IER` to `0`, and write `~0` to `IIR` with a posting read twice. `xe_irq_suspend()` must clear `xe->irq.enabled = 0` and sync MSI/MSI-X before `xe_irq_reset(xe)`; `xe_irq_resume()` must set `xe->irq.enabled = 1` and call `xe_irq_reset()`, `xe_irq_postinstall()`, and `xe_irq_enable_hwe(gt)`. [F449, F526, F527, F530]
- `xe_i2c_probe()` must call `xe_i2c_pm_resume(xe, true)` before registering regmap/adapter; `xe_i2c_pm_resume()` must set `PCI_COMMAND_MEMORY | PCI_COMMAND_MASTER` in `I2C_CONFIG_CMD` when `d3cold` is true before writing `PCI_D0` to `I2C_CONFIG_PMCSR` (paired with `PCI_D3hot` in `xe_i2c_pm_suspend()`). [F534]
- In `__xe_late_bind_fw_init()`, `parse_lb_layout()`, and `parse_cpd_header()`, validate blob size against `XE_LB_MAX_PAYLOAD_SIZE`, `sizeof(*header)`, `header_length + sizeof(*entry) * num_of_entries`, and `offset + sizeof(target_header)` (masking CPD `entry->offset` with `GSC_CPD_ENTRY_OFFSET_MASK`). Guard `xe_late_bind_init()` component registration with `IS_ENABLED(CONFIG_INTEL_MEI_LB) && IS_ENABLED(CONFIG_INTEL_MEI_GSC)`, and call `xe_late_bind_wait_for_worker_completion()` in `xe_late_bind_component_unbind()`/`xe_late_bind_remove()` before clearing `component.ops`. [F483, F578]
- When `has_mbx_power_limits` is true, `xe_hwmon_get_preregistration_info()` must read PL1/PL2 with `READ_PL_FROM_FW` (while `!boot_power_limit_read`), write them via `xe_hwmon_pcode_rmw_power_limit()`, and set `boot_power_limit_read = true`; `xe_hwmon_power_max_write()` must clamp `reg_val` to `pl1_on_boot[channel]`/`pl2_on_boot[channel]` masked with `PWR_LIM_VAL`. [F475, F542]

## Error Handling
- Initialize `u32 offset = 0;` before the loop in `parse_cpd_header()` and `parse_lb_layout()` prior to checking `if (!offset)`, and check the return value of `xe_late_bind_fw_num_fans()` in `__xe_late_bind_fw_init()` before reading `num_fans`. [F436, F437]
- `relay_send_transaction()` converts positive returns from `xe_guc_ct_send_block()` into `-EPROTO`, while `relay_send_message_and_wait()` returns positive `txn->response_len` (dwords) and converts positive `txn->reply` via `from_relay_error()`. In `relay_handle_reply()`, when `reply == 0`, verify `len <= pending->response_len` before copying `4 * len` bytes (else `-ENOBUFS`). [F440, F477]
- In `xe_hwmon_fan_input_read()`, check `time != 0` (returning `-EAGAIN` before updating `fi->reg_val_prev`/`fi->time_prev`) prior to `DIV_ROUND_UP_ULL(rotations * (MSEC_PER_SEC * 60), time)`. Use ratelimited/warn-once logging (`drm_err_ratelimited`, `xe_gt_err_ratelimited`, `drm_warn_once`) in `csc_hw_error_handler()`, `hw_error_source_handler()`, `xe_heci_gsc_irq_handler()`, `xe_heci_csc_irq_handler()`, and `xe_guc_exec_queue_memory_cat_error_handler()`. [F510, F582]

## External Contracts
- In `relay_process_incoming_action()`, pass error replies for remote VFs (`txn->remote != 0`) through `sanitize_relay_error()` and `sanitize_relay_error_hint()` before `prepare_error_reply()`. [F478]
- In `xe_hwmon.c`, scale values with `SF_POWER` (uW), `SF_CURR` (mA), `SF_VOLTAGE` (mV), `MILLIDEGREE_PER_DEGREE` (mC), `SF_ENERGY` (uJ), and `SF_TIME` (ms); expose/scale pcode `I1` (`xe_hwmon_pcode_read_i1()`, `xe_hwmon_power_curr_crit_read()`/`_write()`) as `hwmon_power_crit` (`SF_POWER`, `CHANNEL_CARD`) when `POWER_SETUP_I1_WATTS` is set and `hwmon_curr_crit` (`SF_CURR`, `CHANNEL_PKG`) when clear. [F454, F574, F576]

## Known Pitfalls
- Keep `if (ret == -EINPROGRESS)`, `if (ret > 0)`, and `if (ret < 0)` sequential (not `else if`) in `relay_process_incoming_action()`, setting `again = false` on `ret < 0`. In `__lmtt_alloc_range()`, compute `next = min(end, round_up(offset + 1, pte_addr_shift))` with `offset + 1`. [F495, F498]
- In `xe_guc_submit.c`, `wqi_head`, `wqi_tail`, `wq_desc.head`/`tail`, and `WQ_SIZE` are in bytes: divide by `sizeof(u32)` when indexing `u32` arrays `wq`/`snapshot->parallel.wq`, and divide `lrc->ring.tail` by `sizeof(u64)` in `wq_item_append()`. For `%*ph` on `u32 *` buffers in `xe_guc_relay.c`/`xe_lrc.c`, pass `4 * len`. [F519, F524]
- In `xe_hw_engine_class_sysfs.c`, `.defaults` is a plain `struct kobject` whose parent is `struct kobj_eclass`; use `kobj_xe_hw_engine_type_def` and `kobj_to_eclass(kobj->parent)`. [F521]
- Store 32-bit interrupt/error masks iterated with `for_each_set_bit()` in `unsigned long` (`unsigned long intr_dw[2]`, `unsigned long fw_err`) in `gt_irq_handler()`, `xelp_irq_handler()`, `dg1_irq_handler()`, and `csc_hw_error_handler()`, never `u32` cast to `unsigned long *`. In `dg1_irq_handler()`, return `IRQ_HANDLED` immediately if `GFX_MSTR_IRQ` reads `0xffffffff`. [F525, F529]
- In `xe_hwmon.c`: clamp `value` to `max_supp_power_limit`/`max_crit_power_curr` before `DIV_ROUND_CLOSEST_ULL()` in `xe_hwmon_power_max_write()`/`xe_hwmon_power_curr_crit_write()`; in `xe_hwmon_power_max_interval_show()`/`_store()`, cast `(1 << x_w) | x` to `u64` before `<< y`, shift right by `hwmon->scl_shift_time + x_w`, guard `!val` before `ilog2(val)`, and compute `x = (val - (1ul << y)) << x_w >> y`; on `XE_DG2`, `xe_hwmon_pcode_read_i1()` returns `-ENXIO` and `xe_hwmon_pcode_read_fan_control()` returns `*uval = 2` for `FSC_READ_NUM_FANS` without pcode calls. [F506, F507, F508, F543]
