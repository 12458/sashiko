# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/idpf

This component implements the Intel Infrastructure Data Path Function (idpf) driver, supporting split-queue and single-queue Tx/Rx datapaths, vport lifecycle management, PCI probe/remove, VF register initialization, and IEEE 1588 PTP clock/timestamping via BAR registers or Virtchnl2 mailbox messages.

## Architecture & Data Flow

- In `struct idpf_tx_queue`, `txq_grp` unions with `complq` and `{last_re, tx_max_bufs, cleaned_bytes, clean_budget, cleaned_pkts, refillq}` unions with `{pending, xdp_tx, timer, xdp_lock}`; check `idpf_queue_has(XDP, txq)` before access. Dedicated XDP TX queues `[vport->num_txq - vport->num_xdp_txq, vport->num_txq)` are not in `idpf_set_real_num_queues()`; `idpf_tx_start()` must reject them and `idpf_tx_desc_rel()` must skip `netdev_tx_reset_subqueue()` on XDP queues. [F381, F496]
- In `idpf_rx_queue` and `idpf_rxq_group`, split-queue fields (`rx_qgrp->splitq`, `rxq->bufq_sets`, `rxq->napi`, `rxq->xdp_prog`) union with single-queue fields (`rx_qgrp->singleq`, `rxq->rx_buf`, `rxq->pp`, `rxq->tail`), and `idpf_rx_queue` is embedded in `idpf_rxq_set` only in split-queue mode; guard both with `idpf_is_queue_model_split(vport->rxq_model)`. [F382, F453]
- When `__IDPF_Q_FLOW_SCH_EN` is set on `idpf_tx_queue`, `idpf_tx_buf_alloc_all()`, `idpf_tx_desc_alloc()`, and `idpf_tx_buf_clean()` must size/iterate `tx_buf` and `refillq->ring` using `buf_pool_size` (`U16_MAX`), not `desc_count`. `idpf_compl_queue` uses 8B descriptors (`comp`) with `FLOW_SCH_EN` and 4B (`comp_4b`) otherwise; `idpf_compl_desc_alloc()` and `idpf_wait_for_sw_marker_completion()` must branch on `FLOW_SCH_EN`. [F404, F410]
- In split-queue mode, keep `txq_grp->num_completions_pending` and `complq->num_completions` synced across `idpf_tx_splitq_frame()`, `idpf_tx_clean_complq()`, and `idpf_clean_queue_set()` (zeroing both on disabled queue sets). In `idpf_tx_clean_complq()`, verify `rel_tx_qid < complq->txq_grp->num_txq` and `txqs[rel_tx_qid] != NULL`. [F399, F411]
- Ring distance/pending math (`IDPF_DESC_UNUSED`, `IDPF_TX_COMPLQ_PENDING`, `idpf_tx_splitq_get_free_bufs()`, `idpf_tx_splitq_need_re()`, `idpf_rx_clean_refillq()`) must add the modulus (`desc_count` or `U32_MAX`) on wrap. Allocating/resetting split-queue rings (`idpf_tx_desc_alloc()`, `idpf_compl_desc_alloc()`, `idpf_rx_desc_alloc()`, `idpf_bufq_desc_alloc()`) must zero `next_to_use`/`next_to_clean`/`next_to_alloc` and call `idpf_queue_set(GEN_CHK, q)`. [F402, F446]
- In split-queue Rx, each bufq's `desc_count` must not exceed `IDPF_RX_BUFQ_DESC_COUNT(vport->rxq_desc_count, num_bufqs)`, and `idpf_rx_buf_alloc_all()` posts at most `IDPF_RX_BUFQ_WORKING_SET(rxbufq)` (`desc_count - 1`) buffers. In `idpf_rx_clean_refillq()`, advance refillq `ntc` (and `RFL_GEN_CHK` on wrap) and `bufq_nta`/`buf_desc` only after `idpf_rx_update_bufq_desc()` succeeds; break on failure. [F407, F432]
- Store persistent vport settings (`rss_data`, `q_coalesce`, queue/desc counts, `xdp_prog`, `user_flags`, `mac_filter_list`) in `adapter->vport_config[idx]->user_config` to survive hard resets. In `idpf_set_mac()`, update `vport->default_mac_addr` before `idpf_add_mac_filter()`, and on error restore it from `netdev->dev_addr` after `__idpf_del_mac_filter()`. In `idpf_addr_unsync()`, return 0 if `ether_addr_equal(addr, netdev->dev_addr)`; in `idpf_set_rx_mode()`, clear `__IDPF_PROMISC_MC` only when neither `IFF_ALLMULTI` nor `IFF_PROMISC` is set. [F389, F393, F421, F500]
- In `idpf_vector_lifo`, indices `[0, stack->base)` are reserved (`IDPF_MIN_Q_VEC` per default vport + mailbox); `idpf_vector_stash()` and `idpf_req_rel_vector_indexes()` must never push/pop them on `vector_stack` or count them in `num_avail_msix`. Since `q_vector_idxs[]` is 1-based (`IDPF_MBX_Q_VEC = 1`), `idpf_vf_intr_reg_init()` must verify `num_regs >= num_vecs` and subtract `IDPF_MBX_Q_VEC` when indexing `reg_vals[]`. [F397, F413]
- Both `idpf_intr_reg_init()` and `idpf_vf_intr_reg_init()` must populate all `idpf_intr_reg` fields (`dyn_ctl_itridx_s`, `dyn_ctl_intrvl_s`, etc.). In `idpf_vport_intr_update_itr_ena_irq()`, call `idpf_vport_intr_buildreg_itr(q_vector)` before clearing `q_vector->wb_on_itr` so `dyn_ctl_swint_trig_m` is set. [F396, F458]
- `reg_ops.ptp_reg_init` is NULL on VF (`idpf_vf_dev_ops_init()`), and `ptp->dev_clk_regs` may only be read when access mode is `IDPF_PTP_DIRECT`; `idpf_ptp_get_access()` must test `@direct` in `ptp->caps` before `@mailbox`. Every function under `#if IS_ENABLED(CONFIG_PTP_1588_CLOCK)` in `idpf_ptp.h` needs a `#else` stub. [F388, F403, F423]
- In `idpf_tx_singleq_csum()`, when `skb->encapsulation` is true, outer IP flags in `off->tx_flags` (`IDPF_TX_FLAGS_IPV4 | IDPF_TX_FLAGS_IPV6`) and `ip.hdr`/`l4.hdr` are overwritten in place with inner headers after encoding `off->cd_tunneling`. [F400]

## Synchronization

- Non-datapath `net_device` callbacks must take `vport_ctrl_lock` (`idpf_vport_ctrl_lock()`) before `idpf_netdev_to_vport()`; `idpf_init_hard_reset()` holds it until `idpf_init_task()` clears `IDPF_HR_RESET_IN_PROG`. Callbacks running unlocked during hard reset (`idpf_features_check()`, `idpf_set_rx_mode()`, `idpf_get_stats64()`, `idpf_tx_timeout()`) must use `idpf_netdev_priv` or `np->adapter` since `np->vport` is NULL. Callers of `idpf_vport_open()`/`idpf_vport_stop()` holding `rtnl_lock` (`idpf_open()`, `idpf_stop()`, `idpf_initiate_soft_reset()`) pass `rtnl = false`; unlocked callers (`idpf_init_task()`, `idpf_vport_dealloc()`) pass `true`. [F362, F363, F374]
- Accesses to `user_config.mac_filter_list` (`idpf_find_mac_filter()`, etc.) must hold `mac_filter_list_lock` via `spin_lock_bh()`, allocate with `GFP_ATOMIC`, and unlock before sleeping virtchnl calls in `idpf_add_del_mac_filters()`. `idpf_set_rx_mode()`, `idpf_addr_sync()`, and `idpf_addr_unsync()` run under `netdev->addr_list_lock` (BH disabled) and must use `async = true` without sleeping. Accesses to `adapter->vector_stack` and `num_avail_msix` must hold `adapter->vector_lock`. [F365, F366, F471]
- In `idpf_rx_splitq_clean()` and `idpf_rx_singleq_clean()`, issue `dma_rmb()` after checking descriptor completion (`GEN_M` vs `GEN_CHK`, or `IDPF_RXD_DD`) before reading other `rx_desc` fields. In `idpf_tx_buf_hw_update()`, update `next_to_use` and issue `wmb()` before writing `tx_q->tail`. In `idpf_tx_singleq_clean()`, issue `smp_rmb()` after checking `tx_buf->type == LIBETH_SQE_SKB` before reading `rs_idx` and `eop_desc->qw1`. [F352, F355]
- Any TX path that stops a queue, drops a packet, or rolls back DMA (`idpf_tx_start()`, `idpf_tx_splitq_frame()`, `idpf_tx_singleq_frame()`, `idpf_tx_drop_skb()`) must call `idpf_tx_buf_hw_update(..., false)`. In `idpf_tx_maybe_stop_splitq()`, evaluate all stop conditions (`IDPF_DESC_UNUSED()`, `IDPF_TX_COMPLQ_PENDING()`, `idpf_tx_splitq_get_free_bufs()`) inside `idpf_txq_has_room()` via `netif_subqueue_maybe_stop()`. [F353, F354]
- Direct MMIO clock reads (`idpf_ptp_read_src_clk_reg_direct()`, `idpf_ptp_get_sync_device_time_direct()`) must hold `ptp->read_dev_clk_lock` across `idpf_ptp_enable_shtime()` and all low/high `readl()` calls. `idpf_ptp_update_cached_phctime()` and `idpf_ptp_update_phctime_rxq_grp()` must update `cached_phc_time`, `cached_phc_jiffies`, and `rxq->cached_phc_time` with `WRITE_ONCE()` within `< 2 * HZ` (paired with `READ_ONCE()` in `idpf_rx_hwtstamp()`). [F370, F373]

## Object Lifetimes

- During hard reset (`IDPF_HR_RESET_IN_PROG`), `idpf_vport_dealloc()` must skip `idpf_decfg_netdev()` and set `np->vport = NULL`, and `idpf_cfg_netdev()` reuses `adapter->netdevs[idx]` when `IDPF_VPORT_REG_NETDEV` is set. Set `IDPF_VPORT_REG_NETDEV` in `idpf_init_task()` only after `register_netdev() == 0`, and guard `unregister_netdev()`/`free_netdev()` in `idpf_decfg_netdev()` with `test_and_clear_bit(IDPF_VPORT_REG_NETDEV, ...)`. [F342, F375]
- `idpf_remove()` must set `IDPF_REMOVE_IN_PROG` and `cancel_delayed_work_sync(&adapter->vc_event_task)` before tearing down SR-IOV, virtchnl, mailbox, netdevs, or workqueues. `idpf_deinit_task()` must synchronously cancel `init_task` and `stats_task` before `idpf_vport_dealloc()`. `idpf_shutdown()` must cancel `serv_task` before `vc_event_task` and `idpf_vc_core_deinit()`, deinit default mailbox, and set `PCI_D3hot` on power off, without calling `idpf_remove()` or `idpf_sriov_configure(pdev, 0)`. [F343, F358, F361, F456]
- When releasing Rx rings (`idpf_rx_buf_rel_bufq()`, `idpf_rx_hdr_buf_rel_all()`, `idpf_rx_buf_rel_all()`), recycle all `libeth_fqe` entries via `idpf_rx_page_rel()` before `libeth_rx_fq_destroy()`. In `idpf_rx_desc_rel()`, call `libeth_xdp_return_stash(&rxq->xdp)` when `!idpf_queue_has(XSK, rxq)`. [F348, F502]
- `idpf_ptp_release_vport_tstamp()` must `cancel_work_sync(&vport->tstamp_task)` before locking `latches_lock` to drain `latches_free`/`latches_in_use` and freeing `tx_tstamp_caps` (using `list_for_each_entry_safe()`, as in `idpf_del_all_mac_filters()`). In `idpf_ptp_init()` (error path) and `idpf_ptp_release()`, call `ptp_cancel_worker_sync(ptp->clock)` when `get_dev_clk_time_access != IDPF_PTP_NONE` before `ptp_clock_unregister()`. `idpf_ptp_request_ts()` calls `skb_get(skb)` and sets `SKBTX_IN_PROGRESS`; `idpf_tx_clean_bufs()` must check `SKBTX_IN_PROGRESS` and call `idpf_tx_read_tstamp()` before `libeth_tx_complete()`. [F350, F426, F468, F505]

## API Contracts

- `idpf_vector_to_queue_set()` transfers ownership of the allocated `struct idpf_queue_set *` to its caller (`kfree()`). `idpf_req_rel_vector_indexes()` returns the positive count of allocated vectors or `0` on failure when `num_req_vecs > 0` (treat `<= 0` as failure). `idpf_rx_singleq_buf_hw_alloc_all()` returns `false` on success and `true` (`!!cleaned_count`) on partial failure—opposite to `idpf_rx_post_init_bufs()` and `idpf_rx_post_buf_desc()`. [F345, F376, F387]
- `idpf_tso()` and `idpf_tx_singleq_csum()` return `< 0` on error (drop SKB), `0` if unused/software-handled, and `1` if hardware-offloaded (`idpf_tx_splitq_frame()` adds `idpf_tso()` to `count`). `idpf_tx_res_count_required()` only adds `nr_frags` to `*bufs_needed` for nonlinear SKBs and returns `0` if `__skb_linearize()` fails; callers must init `buf_count = 1` and drop via `idpf_tx_drop_skb()` when `count == 0`. [F377, F378]
- `idpf_tx_tstamp()` returns a non-negative latch index (including `0`) or `-1`; store in signed `int` and check `idx != -1`. In `idpf_tx_start()`, if `skb_put_padto()` fails, `skb` is already freed: only call `idpf_tx_buf_hw_update(tx_q, tx_q->next_to_use, false)` and return `NETDEV_TX_OK`. [F379, F495]
- Use `idpf_is_cap_ena_all()` (not `idpf_is_cap_ena()`) for multi-bit capability masks (`IDPF_CAP_HSPLIT`, `IDPF_CAP_RSC`, checksum masks in `idpf_cfg_netdev()`). In `idpf_vport_set_hsplit()`, `ETHTOOL_TCP_DATA_SPLIT_UNKNOWN` must return `true` when `!idpf_is_hsplit_supported(vport)` and fall through to `ETHTOOL_TCP_DATA_SPLIT_ENABLED` when supported. In `idpf_rx_splitq_clean()`, when `rx_bufq->hdr_pp != NULL` and `!hdr_len && !xdp->data`, `idpf_rx_hsplit_wa()` must copy the header into `hdr` and advance `rx_buf->offset`, or zero `pkt_len` on `0` return. [F422, F424, F501]

## Error Handling

- In `idpf_tx_splitq_frame()` and `idpf_tx_splitq_map()`, cache `tx_params.prev_ntu` (and when `FLOW_SCH_EN` is set, `refillq->next_to_clean` and `RFL_GEN_CHK`) before allocating descriptors or popping buffer IDs (`idpf_tx_get_free_buf_id()`), and restore all on rollback. Terminate multi-fragment `idpf_tx_buf_next(tx_buf)` chains with `IDPF_TXBUF_NULL` (`U32_MAX`) both at EOP and before `idpf_tx_splitq_pkt_err_unmap()`. [F336, F337, F405]
- In `idpf_tx_singleq_dma_map_error()`, wrap `idx` from `0` to `txq->desc_count` before `idx--`, and if `skb_is_gso(skb)`, zero the context descriptor and decrement `idx` one extra time before updating `txq->tail`. In `idpf_tx_singleq_csum()`, on an unsupported protocol in the switch default branch, return `-1` if `is_tso`, else call `skb_checksum_help(skb)` and return `0`. [F415, F425]
- `idpf_rx_rsc()` must check `rsc_seg_len != 0` before `DIV_ROUND_UP(skb->data_len, rsc_seg_len)`. NAPI queue-clean helpers (`idpf_tx_singleq_clean_all()`, `idpf_rx_singleq_clean_all()`, `idpf_tx_splitq_clean_all()`, `idpf_rx_splitq_clean_all()`) must check that `num_txq`/`num_rxq`/`num_complq` on `q_vec` is non-zero before dividing `budget`. [F440, F441]

## External Contracts

- In `idpf_vport_splitq_napi_poll()` and `idpf_vport_singleq_napi_poll()`, if `budget <= 0`, only clean Tx queues and return. Otherwise, combine `clean_complete` with bitwise `&=`; if `!clean_complete`, call `idpf_vport_intr_set_wb_on_itr()` and return `budget` without `napi_complete_done()`; if complete, clamp `work_done` to `budget - 1` and call `idpf_vport_intr_update_itr_ena_irq()` only if `napi_complete_done()` returns `true`. [F434, F487, F489]
- For Tx fragments `> IDPF_TX_MAX_DESC_DATA` (`SZ_16K - 1`), `idpf_tx_splitq_map()`, `idpf_tx_singleq_map()`, and `idpf_chk_tso_segment()` must cap the first chunk to `IDPF_TX_MAX_DESC_DATA_ALIGNED + (-dma & (IDPF_TX_MAX_READ_REQ_SIZE - 1))` and subsequent chunks to `IDPF_TX_MAX_DESC_DATA_ALIGNED` (12K). Split-queue Rx `idpf_rx_buf_hw_update()` tail writes must be aligned down to 8 (`IDPF_RX_BUF_STRIDE` / `IDPF_RX_BUF_POST_STRIDE`). [F408, F409]
- `idpf_features_check()` must clear `NETIF_F_CSUM_MASK | NETIF_F_GSO_MASK` when `skb_network_offset(skb) & ~126`, header length `> np->max_tx_hdr_size`, or encap L4 tunnel length `& ~(127 * 2)`, and clear `NETIF_F_GSO_MASK` when `gso_size < IDPF_TX_TSO_MIN_MSS` (88) or `idpf_chk_tso_segment()` fails. In `idpf_cfg_netdev()`, gate Tx checksums on `IDPF_CAP_TX_CSUM_*` via `idpf_is_cap_ena_all()` and set `hw_enc_features` only to `dflt_features | other_offloads`. [F416, F459, F497]
- Single-queue Rx (`__idpf_rx_singleq_process_skb_fields()`, `idpf_rx_singleq_extract_fields()`) must check `rx_q->rxdids == VIRTCHNL2_RXDID_1_32B_BASE_M` (`base_wb` vs `flex_nic_wb`), and `idpf_rx_splitq_clean()` must check `rxdid == VIRTCHNL2_RXDID_2_FLEX_SPLITQ`. Because `__idpf_rx_process_skb_fields()` calls `idpf_rx_rsc()` without `idpf_rx_csum()`, `idpf_rx_rsc()` must set `gso_size`, `gso_type`, and TCP pseudo-header csum and call `tcp_gro_complete(skb)` even when `rsc_segments == 1`. [F420, F492]
- `idpf_ptp_adjtime()` must route `delta > S32_MAX || delta < S32_MIN` to `idpf_ptp_adjtime_nonatomic()`. On `CONFIG_X86`, `idpf_ptp_set_caps()` sets `info->getcrosststamp` only when `pcie_ptm_enabled(adapter->pdev)`, `X86_FEATURE_ART`, and `X86_FEATURE_TSC_KNOWN_FREQ` are all true, and `idpf_ptp_get_sync_device_time()` sets `system->cs_id` to `CSID_X86_ART` (x86) or `CSID_ARM_ARCH_COUNTER` (ARM). [F419, F488]

## Known Pitfalls

- `txq->desc_ring` and `rxq->desc_ring` use `dmam_alloc_coherent()` / `dmam_free_coherent()` (`idpf_tx_desc_rel()`, `idpf_rx_desc_rel()`), whereas `complq->desc_ring` and `bufq->split_buf` use unmanaged `dma_alloc_coherent()` / `dma_free_coherent()` (`idpf_compl_desc_rel()`, `idpf_rx_desc_rel_bufq()`). [F346]
- `idpf_tx_clean_complq()` and `idpf_tx_singleq_clean()` bias signed `s16 ntc` by subtracting `desc_count` before the loop (wrapping at `++ntc == 0`) and must add `desc_count` back before storing `next_to_clean`. [F414]
- Cast 32-bit upper register reads (`hi`, `dev_time_hi`, `sys_time_hi`) to `u64` before `<< 32` in `idpf_ptp_read_src_clk_reg_direct()` and `idpf_ptp_get_sync_device_time_direct()`. In `idpf_tx_singleq_build_ctob()`, cast `size` to `u64` and keep `td_offset` and `td_tag` as `u64` before shifting by `IDPF_TXD_QW1_TX_BUF_SZ_S` (34), `IDPF_TXD_QW1_OFFSET_S` (16), and `IDPF_TXD_QW1_L2TAG1_S` (48). [F437, F438]
- `idpf_rx_hsplit_wa()` copies `LARGEST_ALIGN(copy)` bytes into the header buffer via `memcpy()` while returning unaligned `copy` (`data_len` or `ETH_HLEN`), so header buffers must have at least `LARGEST_ALIGN(copy)` writable bytes. [F450]
