# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 2)

Implements core `amdgpu` device lifecycle management (`amdgpu_device.c`), hardware IP discovery parsing and sysfs (`amdgpu_discovery.c`), per-file GPU execution contexts (`amdgpu_ctx.c`), debugfs inspection (`amdgpu_debugfs.c`), and GPU hang coredumps (`amdgpu_dev_coredump.c`).

## Architecture & Data Flow

- When parsing `struct ip_v4` in `adev->mman.discovery_bin`, read `ip->sub_revision` and `ip->variant` only if `ihdr->version >= 3` (else `0`). If `ihdr->base_addr_64_bit` is set, convert `ip->base_address_64[]` from LE, truncate to lower 32 bits masked with `0x3FFFFFFF`, and advance `ip_offset` via `struct_size(ip, base_address_64, ...)` rather than `base_address`. [F227, F327]
- Before indexing `hw_id_names`, `adev->reg_offset`, or `adev->ip_versions` from the discovery binary, validate `instance < HWIP_MAX_INSTANCE` and `hw_id < HW_ID_MAX` via `amdgpu_discovery_validate_ip()`, and still advance `ip_offset` by the entry's `struct_size` on failure (use `goto next_ip`, not `continue`). [F254]
- Because `struct ip_hw_instance` has `u32 base_addr[] __counted_by(num_base_addresses)`, `amdgpu_discovery_sysfs_ips()` must allocate with `struct_size(ip_hw_instance, base_addr, ip->num_base_address)` and set `num_base_addresses` before writing `base_addr[]`. [F304]
- In `amdgpu_discovery_set_ip_blocks()`, `amdgpu_discovery_harvest_ip()` must run after `amdgpu_discovery_reg_base_init()` and before `amdgpu_discovery_get_mall_info()` and `amdgpu_discovery_sysfs_init()` (which consume `adev->gmc.num_umc` and harvest masks). On SR-IOV VFs (`amdgpu_sriov_vf(adev)`), call `amdgpu_discovery_set_psp_ip_blocks()` before `amdgpu_discovery_set_ih_ip_blocks()` so PSP precedes IH in `adev->ip_blocks[]`. [F239, F272]
- On bare-metal GPU reset, call `ip_block->version->funcs->dump_ip_state()` in `amdgpu_device_pre_asic_reset()` before `amdgpu_device_ip_suspend()` and HW reset, so `amdgpu_coredump()` in `amdgpu_device_reinit_after_reset()` can format pre-reset state via `print_ip_state()`. When `amdgpu_device_check_vram_lost()` detects lost VRAM during reinit, call both `amdgpu_inc_vram_lost()` and `amdgpu_device_fill_reset_magic()`. [F230, F244]
- `amdgpu_device_resume()` must call `amdgpu_vram_mgr_clear_reset_blocks(adev)` before clearing `adev->in_suspend` because suspend/VBIOS POST clobbers VRAM tracked as zero-cleared. `amdgpu_device_pm_notifier()` must only set `adev->in_s4 = true` on `PM_HIBERNATION_PREPARE` and `false` on `PM_POST_HIBERNATION`, deferring `amdgpu_device_evict_resources()` to `amdgpu_device_prepare()`/`amdgpu_device_suspend()` after user tasks freeze. [F229, F333]
- In `amdgpu_device_set_cg_state()` and `amdgpu_device_set_pg_state()`, iterate `adev->ip_blocks` in forward order (`i = j`) when gating (`AMD_CG_STATE_GATE` / `AMD_PG_STATE_GATE`) and reverse order (`i = adev->num_ip_blocks - j - 1`) when ungating. [F278]
- `amdgpu_ctx_priority_override()` must update `ctx->override_priority` and propagate the new effective priority to every allocated `ctx->entities[i][j]` via `amdgpu_ctx_set_entity_priority()`, calling both `drm_sched_entity_set_priority()` and (for GFX/COMPUTE) `drm_sched_entity_modify_sched()`. [F235]
- `amdgpu_device_check_arguments()` must enforce power-of-two `amdgpu_sched_jobs >= 4` because `amdgpu_ctx_add_fence()`, `amdgpu_ctx_get_fence()`, and `amdgpu_ctx_wait_prev_fence()` index `centity->fences[]` via `seq & (amdgpu_sched_jobs - 1)`. [F287]

## Synchronization

- When resetting a multi-node XGMI hive in `amdgpu_do_asic_reset()`, queue `xgmi_reset_work` on `system_unbound_wq` for every device in `device_list_handle` before flushing it for any device, as `amdgpu_device_xgmi_reset_func()` blocks on `hive->tb` barriers across all nodes. Broken by: flushing inside the queueing loop or using a single-threaded ordered wq. [F192]
- In `amdgpu_device_asic_reset()`, after ASIC reset/reinit and before `amdgpu_device_sched_resume()` restarts DRM schedulers, call `amdgpu_device_stop_pending_resets()` on each device to cancel non-scheduler reset works (`reset_work`, `kfd.reset_work`, `virt.flr_work`, `con->recovery_work`) queued prior to reset. [F191]
- In `amdgpu_debugfs_test_ib_show()` (write-locked) and `amdgpu_debugfs_ib_preempt()` (read-locked), hold `adev->reset_domain->sem` across `drm_sched_wqueue_stop()` and `drm_sched_wqueue_start()` so debugfs does not unpark scheduler threads during a GPU reset. [F201]
- In `amdgpu_device_init()`, call `amdgpu_register_gpu_instance(adev)` before `amdgpu_device_ip_late_init(adev)` so `mgpu_info.num_dgpu` (under `mgpu_info.mutex`) includes the new device when `amdgpu_device_enable_mgpu_fan_boost()` and XGMI p-state sync check total dGPU count. [F185]
- In `amdgpu_device_resume()`, bracket `drm_helper_hpd_irq_event()` or `drm_kms_helper_hotplug_event()` with `dev->dev->power.disable_depth++` and `--` under `CONFIG_PM`, because connector probing acquires runtime PM refs while the runtime PM lock may be held. [F202]
- In `amdgpu_device_aper_access()`, a full `mb()` must separate `memcpy_toio()` and `amdgpu_device_flush_hdp()` on writes, and `amdgpu_device_invalidate_hdp()` and `memcpy_fromio()` on reads. [F206]

## Object Lifetimes

- In `amdgpu_device_init()`, create `adev->reset_domain` via `amdgpu_reset_create_reset_domain()` before `amdgpu_virt_init()`, `amdgpu_device_ip_early_init()`, or any `RREG32()` call, because `amdgpu_device_skip_hw_access()` and early init access `adev->reset_domain->sem` and `in_gpu_reset`. [F315]
- In `amdgpu_device_ip_init()`, when replacing a non-VF XGMI device's `adev->reset_domain` with `hive->reset_domain`, `amdgpu_reset_get_reset_domain(hive->reset_domain)` must succeed before `amdgpu_reset_put_reset_domain(adev->reset_domain)`, and `amdgpu_put_xgmi_hive(hive)` must run on all paths. Also call `amdgpu_ras_recovery_init()` after `amdgpu_device_ip_hw_init_phase2()` so the SMU is ready for RAS EEPROM I2C. [F172, F317]
- `amdgpu_discovery_reg_base_init()` converts IP base addresses in-place in `adev->mman.discovery_bin` and stores interior `ip->base_address` pointers in `adev->reg_offset[hw_ip][inst]`, so `discovery_bin` must stay allocated at a fixed address until `amdgpu_discovery_fini()` in `amdgpu_device_fini_sw()`. [F237]
- Before BACO or Mode1 reset in `amdgpu_device_halt_activities()`, `amdgpu_device_suspend_display_audio()` runtime-suspends and calls `pm_runtime_disable()` on sibling PCI audio function (slot 1); `amdgpu_device_gpu_resume()` must call `amdgpu_device_resume_display_audio()` when `pcie_reset_ctx.audio_suspended` is true. [F336]
- In `amdgpu_pt_info_read()`, pair `root_bo = amdgpu_bo_ref(fpriv->vm.root.bo)` with `amdgpu_bo_unref(&root_bo)` both when `amdgpu_bo_reserve(root_bo, true)` fails and after `amdgpu_bo_unreserve(root_bo)` on success. [F182]

## API Contracts

- `amdgpu_ctx_add_fence()`, `amdgpu_ctx_get_fence()`, and `amdgpu_ctx_wait_prev_fence()` downcast `struct drm_sched_entity *` via `to_amdgpu_ctx_entity()`, so callers must only pass entities from `amdgpu_ctx_get_entity()`. Every non-NULL `fence` passed to `amdgpu_ctx_add_fence()` must be a `struct drm_sched_fence` because `amdgpu_ctx_fence_time()` downcasts via `to_drm_sched_fence(fence)` without a NULL check. [F299, F301]
- `amdgpu_ctx_add_fence()` takes a new ref via `dma_fence_get(fence)`, stores it in `centity->fences[idx]` under `ctx->ring_lock`, adds displaced fence runtime to `ctx->mgr->time_spend`, and calls `dma_fence_put(other)` (callers keep their own `fence` ref). `centity->sequence` starts at 1; under `ctx->ring_lock`, `amdgpu_ctx_get_fence()` maps `seq == ~0ull` to `centity->sequence - 1`, returns `ERR_PTR(-EINVAL)` if `seq >= centity->sequence`, `NULL` if evicted (`seq + amdgpu_sched_jobs < centity->sequence`), or a new `dma_fence_get()` ref that callers must release with `dma_fence_put()`. [F165, F166, F250]
- In `amdgpu_debugfs.c`, MMIO/DIDT accessors (`RREG32`, `amdgpu_mm_wreg_mmio_rlc`, `RREG32_DIDT`, `WREG32_DIDT`) take dword indices (`*pos >> 2`), while PCIe/SMC accessors (`RREG32_PCIE*`, `WREG32_PCIE*`, `RREG32_SMC`, `WREG32_SMC`) take byte offsets (`*pos`); `amdgpu_debugfs_regs_pcie_read()`/`write()` must use `*_PCIE_EXT` when `upper_32_bits(*pos)` is non-zero. [F212, F296]
- In `amdgpu_debugfs_process_reg_op()`, reject setting both bit 62 (GRBM) and bit 61 (SRBM) in `*pos` with `-EINVAL`, and mask `*pos` with `(1UL << 22) - 1` before the MMIO loop. `amdgpu_debugfs_gprwave_read()` and `amdgpu_debugfs_gpr_read()` must reject `size > 4096`, `size & 0x3`, or `*pos & 0x3` with `-EINVAL` before reading into the 1024-dword `data` buffer. [F260, F275]
- Call `amdgpu_ib_preempt_fences_swap()` only after checking `atomic_read(&ring->fence_drv.last_seq) != ring->fence_drv.sync_seq` (masked with `num_fences_mask`), because its `do { ++last_seq; ... } while (last_seq != sync_seq)` loop pre-increments `last_seq`. [F276]
- In `amdgpu_coredump()`, `job` is nullable (e.g. full GPU resets); check `job` before dereferencing `job->pasid` or `job->base.sched`, and check `coredump->ring` for `NULL` in `amdgpu_devcoredump_read()`. [F215]
- `amdgpu_device_supports_baco()` returns a bitmask (`0`, `BACO_SUPPORT` (`1`), or `BACO_SUPPORT | MACO_SUPPORT` (`3`)); test `(val & BACO_SUPPORT)` or non-zero rather than `val == BACO_SUPPORT`. [F216]
- `amdgpu_device_aper_access()` returns `size_t` bytes transferred (`0` or partial if `pos + size > adev->gmc.visible_vram_size`), not a status code; `amdgpu_device_mm_access()` and `amdgpu_device_vram_access()` require 4-byte aligned `pos` and `size` (`BUG_ON`). `amdgpu_device_program_register_sequence()` takes total `u32` count (`ARRAY_SIZE(registers)`, a multiple of 3), not triplet count or byte size. [F217, F219]
- In `amdgpu_device_init()`, call `aperture_remove_conflicting_pci_devices()` only when `(pdev->class >> 8)` is `PCI_CLASS_DISPLAY_VGA` or `PCI_CLASS_DISPLAY_OTHER`. In `amdgpu_switcheroo_set_state()`, set `dev->switch_power_state = DRM_SWITCH_POWER_CHANGING` before `amdgpu_device_resume()`, `amdgpu_device_prepare()`, or `amdgpu_device_suspend()`, and set `DRM_SWITCH_POWER_ON`/`OFF` only after completion. [F371, F372]

## Error Handling

- In `amdgpu_device_ip_early_init()`, `early_init` returning `-ENOENT` marks `adev->ip_blocks[i].status.valid = false` without failing init; any other error fails `amdgpu_device_ip_early_init()` with `-ENODEV`. [F222]
- In `amdgpu_device_pre_asic_reset()` and `amdgpu_do_asic_reset()`, clear `-EOPNOTSUPP` from `amdgpu_reset_prepare_hwcontext()` or `amdgpu_reset_perform_reset()` to `r = 0` so reset falls back to the default bare-metal path. [F223]
- On Vega, Raven, Arcturus, and Aldebaran, `amdgpu_discovery_init()` failure in `amdgpu_discovery_set_ip_blocks()` is non-fatal, so helpers called afterwards like `amdgpu_discovery_sysfs_init()` must check `if (!adev->mman.discovery_bin)` before dereferencing. [F228]

## External Contracts

- `union drm_amdgpu_ctx` overlays `in` and `out`; `amdgpu_ctx_query()` and `amdgpu_ctx_query2()` must zero `out->state.flags` and `out->state.hangs` before bitwise-ORing flags. `amdgpu_ctx_ioctl()` requires `args->in.flags == 0` except in `AMDGPU_CTX_OP_SET_STABLE_PSTATE` (no bits outside `AMDGPU_CTX_STABLE_PSTATE_FLAGS_MASK`, masked value `<= AMDGPU_CTX_STABLE_PSTATE_PEAK`). [F209, F253]
- In `amdgpu_ctx_ioctl()`, normalize unrecognized or `AMDGPU_CTX_PRIORITY_UNSET` `args->in.priority` to `AMDGPU_CTX_PRIORITY_NORMAL` via `amdgpu_ctx_priority_is_valid()` rather than returning `-EINVAL` or storing `UNSET` in `ctx->init_priority`. `priority > AMDGPU_CTX_PRIORITY_NORMAL` in `amdgpu_ctx_init()` requires `amdgpu_ctx_priority_permit()` (`CAP_SYS_NICE` or DRM master), else `-EACCES`. [F210, F357]
- In `amdgpu_debugfs_gca_config_read()`, only append new fields to the end of `config[]` while incrementing `config[0]`. In `amdgpu_debugfs_regs2_ioctl()`, `AMDGPU_DEBUGFS_REGS2_IOC_SET_STATE` copies v1 `amdgpu_debugfs_regs2_iocdata` and must zero `rd->id.xcc_id`. [F246, F261]

## Known Pitfalls

- `pci_get_drvdata(pdev)` and `dev_get_drvdata(dev)` return `struct drm_device *` (at a non-zero offset in `struct amdgpu_device`); always convert via `drm_to_adev()`. [F310]
- In `amdgpu_discovery_reg_base_init()`, for `VCN_HWID`, save bits `[7:6]` (`0xc0`) of `ip->revision` to `adev->vcn.inst[adev->vcn.num_vcn_inst].vcn_config` (if `num_vcn_inst < AMDGPU_MAX_VCN_INSTANCES`) and clear `ip->revision &= ~0xc0` before computing `adev->ip_versions`. [F256]
- Avoid 32-bit overflow/UB: in `amdgpu_device_check_smu_prv_buffer_size()`, cast `si.totalram` to `uint64_t` before `* si.mem_unit` and restrict `amdgpu_smu_memory_pool_size` to `{1, 2, 4, 8}` before `<< 28`; in `amdgpu_device_init()`, clamp `max(1u, max_MBps)` before `ilog2()`; in `amdgpu_device_is_peer_accessible()`, use `~((1ULL << 32) - 1)` for the default mask and `aper_base + aper_size - 1` for `aper_limit`; in `amdgpu_discovery_read_binary_from_mem()` and `amdgpu_discovery_refresh_nps_info()`, cast `RREG32(mmRCC_CONFIG_MEMSIZE)` to `uint64_t` before `<< 20`. [F289, F290, F291, F292]
- In `amdgpu_device_parse_gpu_info_fw()`, `CHIP_NAVI12` skips populating `adev->gfx.config` from `gpu_info_fw`, but must still jump to `parse_soc_bounding_box` to set `adev->dm.soc_bounding_box`. [F325]
- In `amdgpu_device_ip_suspend_phase2()`, when `adev->in_s0ix` is true, suspend is skipped for `PSP`, `GFX`, `MES`, and (`SDMA0_HWIP >= IP_VERSION(5, 0, 0)`) `SDMA`, so `cancel_delayed_work_sync(&adev->gfx.idle_work)` must be called explicitly for GFX on `GC_HWIP >= IP_VERSION(10, 0, 0)`. [F334]

## Other

- In `amdgpu_discovery_read_binary_from_mem()`, on bare metal (`!amdgpu_sriov_vf(adev)`), poll `mmMP0_SMN_C2PMSG_33` for bit `0x80000000` (up to 2000 x 1 ms) before reading `mmRCC_CONFIG_MEMSIZE` so IFWI init has completed on hotplugged dGPUs. [F328]
