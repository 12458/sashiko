# NETWORKING DRIVERS — drivers/net (part 2)

This unit covers virtual and tunnel network devices (`geneve`, `ifb`, `ipvlan`/`ipvtap`, `loopback`/`blackhole_netdev`, `macvlan`/`macvtap`), the Fujitsu Extended Socket (`fjes`) ACPI driver, the MHI bus network driver (`mhi_net`), the Clause 22/45 MDIO library (`mdio`), and hamradio AX.25 drivers (`bpqether`, `hdlcdrv`, `mkiss`).

## Architecture & Data Flow

- `struct ipvtap_dev` and `struct macvtap_dev` must keep `vlan` at offset 0. `ipvtap_device_event()` and `macvtap_device_event()` must check `dev->rtnl_link_ops == &ipvtap_link_ops` / `&macvtap_link_ops` before downcasting `netdev_priv(dev)`—not `netif_is_ipvlan()` / `netif_is_macvlan()`. On `NETDEV_UNREGISTER`, `macvlan_device_event()` and `ipvlan_device_event()` must iterate `port->vlans` / `port->ipvlans` with `list_for_each_entry_safe()` and call `dev->rtnl_link_ops->dellink`, not `macvlan_dellink()` or `ipvlan_link_delete()` directly. [F604, F634, F635]
- MAC buffers passed to `macvlan_eth_hash()`, `macvlan_hash_lookup()`, `macvlan_hash_lookup_source()`, or `macvlan_addr_busy()` need >= 8 readable bytes (6-byte MAC + 2 padding) and 2-byte alignment for `ether_addr_equal_64bits()` (`macvlan_source_entry::addr`). `macvlan_eth_hash()` must shift `get_unaligned((u64 *)addr)` right 16 bits on big-endian or left 16 bits on little-endian before `hash_64()`. Broken by: passing `unsigned char addr[ETH_ALEN]`. [F588, F618]
- A `macvlan_port` in `MACVLAN_MODE_PASSTHRU` (`MACVLAN_F_PASSTHRU`) allows at most one `macvlan_dev` (`port->count == 0` when enabling), and `macvlan_changelink()` cannot toggle `MACVLAN_MODE_PASSTHRU` on an existing device. [F570]
- IPv4 and IPv6 `struct ipvl_addr` entries share `ipvlan->addrs` and `port->hlhead[]`, so any access to `addr->ipu` (`ip4addr`/`ip6addr`) must first verify `addr->atype` (`IPVL_IPV4` or `IPVL_IPV6`). In `ipvlan_link_new()`, slave `dev->dev_id` values come from `ida_alloc_range()` in `[0x1, 0xFFFD]`, wrapping `port->dev_id_start` from `0xFFFE` to `0x1` (`0xFFFE` is reserved for master). [F551, F591]
- In `ipvlan_set_port_mode()`, `port->mode` must keep the old value until the `list_for_each_entry` loop over `port->ipvlans` and `ipvlan_l3s_register()` succeed, without modifying `ipvlan` before `goto fail` (`fail` uses `list_for_each_entry_continue_reverse` and reads `port->mode` to restore `IFF_NOARP`). When an `IPVLAN_MODE_L3S` `port->dev` moves netns (`NETDEV_REGISTER` in `ipvlan_device_event()`), update `port->pnet` and call `ipvlan_migrate_l3s_hook(oldnet, newnet)` under RTNL. [F601, F673]
- In `geneve.c`, `struct ip_tunnel_info info` must remain the last member of `struct geneve_config`, and `cfg` the last member of `struct geneve_dev` (`ip_tunnel_info` ends with flexible array `options[]`). Wire `genevehdr.opt_len` is in 4-byte words while `ip_tunnel_info.options_len` is in bytes (multiply by 4 on RX in `geneve_rx`/`geneve_udp_encap_recv`/`geneve_hlen`, divide by 4 on TX in `geneve_build_header`). In `geneve_nl2info()`, `IFLA_GENEVE_REMOTE6` must precede `IFLA_GENEVE_LABEL`, `IFLA_GENEVE_UDP_ZERO_CSUM6_TX`, and `IFLA_GENEVE_UDP_ZERO_CSUM6_RX`. [F606, F624, F625]
- In `ifb_ri_tasklet()`, before reinjecting via `dev_queue_xmit()` or `netif_receive_skb()`, clear `skb->redirected = 0`, set `skb->tc_skip_classify = 1`, call `nf_skip_egress(skb, true)`, and resolve `skb->dev` from `skb->skb_iif` via `dev_get_by_index_rcu()` before overwriting `skb->skb_iif` with `txp->dev->ifindex`. If `dev_get_by_index_rcu()` returns `NULL`, jump to `resched` if `txp->tq` is non-empty or `break` to the `txp->rq` drain/wake check rather than returning early. [F582, F608]
- In `fjes_hw_setup_epbuf()`, save `info->v1i.vlan_id[]` before `memset(info, 0, ...)` and restore it, setting `head = 0`, `tail = 1`, and `FJES_RX_MTU_CHANGING_DONE` in `rx_status`. Because rings start at `head = 0, tail = 1`, `fjes_hw_epbuf_tx_pkt_send()` indexes `EP_RING_INDEX(info->v1i.tail - 1, info->v1i.count_max)` while `fjes_hw_epbuf_rx_curpkt_get_addr()` indexes `EP_RING_INDEX(info->v1i.head, info->v1i.count_max)`. [F576, F592]
- `fjes_hw_setup()` only allocates `tx`/`rx` epbufs in `hw->ep_shm_info[epidx]` for `epidx != hw->my_epid`: every loop over `0..hw->max_epid - 1` accessing `tx.info`/`rx.info` or emitting ethtool stats (`fjes_get_ethtool_stats()`, `fjes_get_strings()`) must skip `epidx == hw->my_epid` and emit `FJES_EP_STATS_LEN` (14) stats per remaining EP to match `FJES_STATS_LEN`. [F593, F629]
- In `fjes_poll()`, preserve `cur_epid` across iterations of `while (work_done < budget)` for round-robin `fjes_rxframe_search_exist()`, and call `fjes_rxframe_release()` on every non-NULL `frame` even if `napi_alloc_skb()` fails. In `fjes_open()`, `napi_enable()` and `fjes_request_irq()` must succeed before `fjes_hw_set_irqmask(hw, REG_ICTL_MASK_ALL, false)`; `fjes_free_irq()` must cancel `interrupt_watch_task` and mask `REG_ICTL_MASK_ALL` before `free_irq()`. [F611, F641]
- `fjes_hw_register_buff_addr()` writes two `__le64` sizes plus `(tx.size + rx.size) / EP_BUFFER_INFO_SIZE` page addresses into `req_buf->share_buffer.buffer[]`, bounded by `FJES_DEV_COMMAND_SHARE_BUFFER_REQ_LEN` and `FJES_DEV_REQ_BUF_SIZE`. `fjes_support_mtu[]` must keep its trailing `0` sentinel for `fjes_change_mtu()`. Because `fjes_acpi_ids` matches `PNP0C02`, `acpi_find_extended_socket_device()` and `fjes_acpi_add()` must verify both `is_extended_socket_device()` and `acpi_check_extended_socket_status()`. [F594, F627, F643]
- In `mhi_net_newlink()`, initialize `mhi_netdev` fields (`ndev`, `mdev`, `rx_refill`, `u64_stats_init`) and `dev_set_drvdata(&mhi_dev->dev, mhi_netdev)` before `mhi_prepare_for_transfer(mhi_dev)`, and set `rx_queue_sz` from `mhi_get_free_desc_count()` before `register_netdev(ndev)`. [F639]

## Synchronization

- Stacked/virtual drivers (`bpq_setup`, `ipvlan_init`, `macvlan_set_lockdep_class`, `geneve_init`, `loopback_dev_init`) must call `netdev_lockdep_set_classes()` before `register_netdevice()` completes, and `macvlan_set_lockdep_class()` must also set a lockdep class on `dev->addr_list_lock`. `macvlan_hash_change_addr()` must call `macvlan_hash_del(vlan, true)` (`hlist_del_rcu()` + `synchronize_rcu()`) before mutating `vlan->dev->dev_addr` and calling `macvlan_hash_add()`. [F520, F657]
- `ipvlan_l3s_register()` must set `dev->l3mdev_ops` before `IFF_L3MDEV_RX_HANDLER` in `dev->priv_flags`, and `ipvlan_l3s_unregister()` must clear `IFF_L3MDEV_RX_HANDLER` without clearing `dev->l3mdev_ops`. In workqueue context, `ipvlan_process_multicast()` must use `spin_lock_bh(&port->backlog.lock)` and wrap `dev_forward_skb()`/`netif_rx()` and `ipvlan_count_rx()` in `local_bh_disable()`/`local_bh_enable()`. [F519, F655]
- `ifb_ri_tasklet()` must hold `__netif_tx_trylock(txq)` both when splicing `txp->rq` into `txp->tq` and when checking `skb_peek(&txp->rq)` before clearing `txp->tasklet_pending` and waking `txq`, rescheduling `txp->ifb_tasklet` if trylock fails. [F653]
- Callers of `fjes_hw_request_info()`, `fjes_hw_register_buff_addr()`, `fjes_hw_unregister_buff_addr()`, `fjes_hw_start_debug()`, and `fjes_hw_stop_debug()` must hold `mutex_lock(&hw->hw_info.lock)` across execution and any read of `hw->hw_info.res_buf`. When `fjes_hw_update_zone_task()` or `fjes_watch_unshare_task()` hits a fatal error, schedule `adapter->force_close_task` rather than taking `rtnl_lock()` / calling `dev_close()` directly. [F537, F540]
- All calls to `fjes_hw_setup_epbuf()` and updates to `ep_shm_info[epidx].tx.info->v1i.rx_status` must hold `spin_lock_irqsave(&hw->rx_status_lock, flags)` (or `spin_lock(&hw->rx_status_lock)` in `fjes_poll()`), and `fjes_irq_watch_task()` must disable local IRQs around `fjes_intr()`. When `netif_running(netdev)` in `fjes_change_mtu()`, clear `FJES_RX_MTU_CHANGING_DONE` on all peers under `hw->rx_status_lock` before stopping queues/NAPI and changing `netdev->mtu`, then restore via `fjes_hw_setup_epbuf()` under `hw->rx_status_lock`. [F578, F661]

## Object Lifetimes

- Every SKB queued on `port->bc_queue` by `macvlan_broadcast_enqueue()` with non-NULL `MACVLAN_SKB_CB(nskb)->src` holds `dev_hold(src->dev)` that must be released with `dev_put(src->dev)` when dequeued in `macvlan_process_broadcast()` and `macvlan_port_destroy()` (and not taken if dropped when full). In `ipvtap_dellink()` and `macvtap_dellink()`, call `netdev_rx_handler_unregister(dev)` before `tap_del_queues()` and `ipvlan_link_delete()` / `macvlan_dellink()`. [F506, F526]
- In the `AF_INET6` branch of `ipvlan_l3_rcv()`, call `skb_dst_drop(skb)` before `ip6_route_input_lookup()` and `skb_dst_set(skb, dst)`. When `skb_tunnel_check_pmtu()` returns > 0 in `geneve_xmit_skb()` or `geneve6_xmit_skb()`, unshare `ip_tunnel_info` via `skb_tunnel_info_unclone(skb)` before swapping addresses, and return `-EMSGSIZE` after `__netif_rx(skb)` so `geneve_xmit()` does not double-free `skb`. [F510, F669]
- In `ifb_dev_free()`, call `tasklet_kill(&txp->ifb_tasklet)` on each queue before `__skb_queue_purge(&txp->rq)`, `__skb_queue_purge(&txp->tq)`, and `kfree(dp->tx_private)`. [F514]
- In `fjes_close()`, disable NAPI/IRQ and synchronously cancel all work items (`interrupt_watch_task`, `unshare_watch_task`, `raise_intr_rxdata_task`, `tx_stall_task`, `update_zone_task`, `epstop_task`) before `fjes_hw_wait_epstop()` and `fjes_free_resources()`. In `fjes_hw_setup()` and `fjes_hw_cleanup()`, null out `hw->ep_shm_info`, `req_buf`, `res_buf`, `share`, and EP `tx`/`rx` buffer pointers when freeing. In `is_extended_socket_device()`, free `buffer.pointer` via `kfree()` whenever `acpi_evaluate_object()` succeeds. [F518, F539, F644]
- MHI does not free SKBs queued via `mhi_queue_skb()`: `mhi_net_ul_callback()` and `mhi_net_dl_callback()` must always free or consume `mhi_res->buf_addr` (including on `-ENOTCONN`). In `mhi_net_dellink()`, complete `unregister_netdev(ndev)` and `mhi_unprepare_from_transfer(mhi_dev)` before `kfree_skb(mhi_netdev->skbagg_head)`, `free_netdev(ndev)`, and `dev_set_drvdata(&mhi_dev->dev, NULL)`. [F531, F679]

## API Contracts

- `ipvlan_port_get_*()` and `macvlan_port_get_*()` downcast `dev->rx_handler_data`: callers on unverified devices must check `netif_is_ipvlan_port(dev)` / `netif_is_macvlan_port(dev)` and pass `phy_dev`/`lowerdev` (not `ipvtap`/`macvtap` dev). In `ipvtap_newlink()` and `macvtap_newlink()`, `netdev_rx_handler_register()` must precede `ipvlan_link_new()` / `macvlan_common_newlink()`, with no fallible steps afterward. [F636, F670]
- Check `ns_capable(dev_net(phy_dev)->user_ns, CAP_NET_ADMIN)` against `phy_dev`'s user_ns in `ipvlan_nl_changelink()` and when stacking `ipvlan` in `ipvlan_link_new()`; `macvlan_hwtstamp_set()` must return `-EOPNOTSUPP` if `!net_eq(dev_net(dev), &init_net)`. In `ipvlan_nl_validate()`, check mutual exclusion via `(flags & (IPVLAN_F_PRIVATE | IPVLAN_F_VEPA)) == (IPVLAN_F_PRIVATE | IPVLAN_F_VEPA)`. [F602, F671, F672]
- In `ipvlan_xmit_mode_l3()` and `ipvlan_process_outbound()`, scrub SKBs via `ipvlan_skb_crossing_ns()`, strip L2 headers (`skb->mac_header = ~0U`, `skb_reset_network_header(skb)`), and zero `IPCB(skb)`/`IP6CB(skb)` before `ip_local_out()`/`ip6_local_out()`. In `macvlan_open()` (non-passthru), if `ndo_dfwd_add_station()` returns `IS_ERR_OR_NULL(vlan->accel_priv)`, set `vlan->accel_priv = NULL` and call `dev_uc_add(lowerdev, dev->dev_addr)`. [F676, F678]
- In `geneve_rx()`, `IP_ECN_decapsulate()` / `IP6_ECN_decapsulate()` return `1` for a warning and `> 1` for framing error; only drop when `err > 1`. In `loopback_xmit()`, call `skb_clear_tstamp(skb)`, `skb_orphan(skb)`, and `skb_dst_force(skb)` before `__netif_rx(skb)`. `blackhole_netdev_ops` must set `.ndo_neigh_construct = blackhole_neigh_construct` (`n->output = blackhole_neigh_output`). [F549, F665, F674]
- `fjes_hw_issue_request_command()` returns positive `enum fjes_dev_command_response_e` (`FJES_CMD_STATUS_NORMAL == 1`); callers must zero `req_buf`/`res_buf` first and check `res_buf->*.length` and `res_buf->*.code == FJES_CMD_REQ_RES_CODE_NORMAL`. Because `tx.buffer`, `rx.buffer`, and `hw_info.trace` use `vzalloc()`, translate pages with `page_to_phys(vmalloc_to_page(addr)) + offset_in_page(addr)`, never `__pa()`. [F560, F662]
- `mdio45_links_ok()` takes a shifted `u32 mmd_mask` (`1 << devad`) and returns bool (`1` = OK, `0` = fault/error), whereas `mdio_set_flag()` returns `0` or `-errno`. For each MMD in `mmd_mask`, `mdio45_links_ok()` must clear `1 << devad`, read `MDIO_STAT1` (and `MDIO_STAT2` for `PMAPMD`/`PCS`/`PHYXS`/`DTEXS`) once to clear latched bits, and re-read `MDIO_STAT1` to check `(reg & (MDIO_STAT1_FAULT | MDIO_STAT1_LSTATUS)) == MDIO_STAT1_LSTATUS`. Only access `MDIO_MMD_AN` when `mdio->mmds & MDIO_DEVS_AN`, and zero-initialize `ethtool_link_ksettings` before `mdio45_ethtool_ksettings_get_npage()`. [F557, F612, F647, F648, F683]

## Error Handling

- On `destroy_macvlan_port` in `macvlan_common_newlink()`, only call `macvlan_flush_sources()` and `macvlan_port_destroy()` if `create && macvlan_port_get_rtnl(lowerdev)` (`macvlan_uninit()` may have already destroyed `port`). On `NETDEV_UNREGISTER` in `ipvtap_device_event()` and `macvtap_device_event()`, check `vlantap->tap.minor == 0` and skip sysfs removal, `device_destroy()`, and `tap_free_minor()` if `NETDEV_REGISTER` failed early. [F505, F542]
- In `ipvlan_route_v6_outbound()`, `ip6_route_output()` always returns a non-NULL `dst_entry`; when `dst->error` is non-zero, call `dst_release(dst)` before returning `dst->error`. [F552]
- In `fjes_open()`, call `fjes_free_irq(adapter)` when `fjes_request_irq()` fails even if `!adapter->irq_registered` (to stop `interrupt_watch_task`). `fjes_hw_epbuf_rx_is_empty()` must check `info->v1i.count_max == 0` before `EP_RING_EMPTY()` (`% _max`), and `fjes_hw_init()` must reject `hw->max_epid == 0`. [F517, F622]
- In `mhi_net_dl_callback()`, `mhi_res->transaction_status == -EOVERFLOW` marks a valid non-final fragment for `mhi_net_skb_agg()`, and `mhi_netdev->skbagg_head` must be reset to `NULL` once the final (`status == 0`) fragment is aggregated. [F558]

## External Contracts

- In `geneve_validate()` and `geneve_nl2info()`, convert `__be16` `ifla_geneve_port_range` `low`/`high` with `ntohs()` before comparing or storing in `cfg->port_min`/`port_max`. In `macvlan.c`, `IFLA_MACVLAN_MACADDR_COUNT` and `IFLA_MACVLAN_BC_QUEUE_LEN_USED` are dump-only and must be rejected in `macvlan_validate()` / `macvlan_policy`. [F587, F589]

## Known Pitfalls

- In `ndo_start_xmit` (`geneve_xmit_skb()`, `ipvlan_xmit_mode_l2()`, `macvlan_queue_xmit()`), use `skb_eth_hdr(skb)` rather than `eth_hdr(skb)` and call `skb_reset_mac_header(skb)` before helpers that call `eth_hdr(skb)`. `macvlan_handle_frame()` must return `RX_HANDLER_PASS` when `skb->pkt_type == PACKET_LOOPBACK` (no L2 header). [F667, F677]
- In `macvlan_handle_frame()` and `ipvlan_rcv_frame()`, update `*pskb = skb` (and refresh `eth = eth_hdr(skb)`) whenever `ip_check_defrag()` or `skb_share_check()` replaces `skb`. In `geneve_rx()`, save `nh = skb_network_header(skb) - skb->head` before `pskb_inet_may_pull(skb)` and compute `oiph = skb->head + nh` only afterward. In `ipvlan_get_L3_hdr()` for `ETH_P_IPV6` dad (`ipv6_addr_any(&ip6h->saddr)` + `NEXTHDR_ICMP`), `pskb_may_pull()` must include `sizeof(struct in6_addr)` and refresh `icmph` for `NDISC_NEIGHBOUR_SOLICITATION`. [F590, F638, F668]
- In `vni_to_tunnel_id()`, cast each `vni[0..2]` byte to `u64` on little-endian before shifting by 40, 48, and 56 bits into `&tun_id[5]`. In `is_extended_socket_device()`, pass `sizeof(str_buf) - 1` to `utf16s_to_utf8s()` and explicitly set `str_buf[result] = 0`. [F617, F628]
