# SPI SUBSYSTEM — drivers/spi (part 1)

Core SPI helpers (`internals.h`), bitbanging library (`spi-bitbang.c`, `spi-bitbang-txrx.h`), and SPI/`spi-mem` host drivers (Atmel QSPI, Cadence QSPI/XSPI, BCM2835/BCM2835aux, Altera, Armada 3700, Cavium Octeon, Au1550, Amlogic SPIFC, ColdFire QSPI, CLPS711X, ATH79, Butterfly).

## Architecture & Data Flow

- `spi-bitbang.c` casts `spi_controller_get_devdata()` to `struct spi_bitbang *`, so `butterfly`, `ath79_spi`, and `au1550_spi` must put `struct spi_bitbang` first. In `bitbang_txrx_8/16/32()`, `count` is in bytes while typed `tx`/`rx` (`u8/u16/u32 *`) advance 1 element per loop, so decrement `count` by 1, 2, or 4 and guard with `count > 0/1/3`. In `bitbang_txrx_le_cpha0/1()`, capture `rxbit = bits - 1` before the `bits--` loop. [F93, F123, F128]
- In `spi-bcm2835.c`, `bcm2835_spi_can_dma()` rejects `< 96` bytes (`BCM2835_SPI_DMA_MIN_LENGTH`) so `bcm2835_spi_transfer_prologue()` can write 6 bytes (4-byte spillover into `tx_sg.sgl[1]`), and `bcm2835_spi_max_transfer_size()` must return `65532` (4-byte aligned in 16-bit `DLEN`). `bs->tx_prologue` is the sole active-prologue guard (set `> 0` when `rx_prologue > 0`), and `bcm2835_spi_undo_prologue()` must reset `bs->tx_prologue = 0` even when `!bs->tx_buf`. [F83, F84, F99]
- In `struct bcm2835_spidev`, keep `clear_rx_cs` `____cacheline_aligned` and allocate `target` aligned to `dma_get_cache_alignment()`. In `bcm2835_spi_setup()`, updating `target->prepare_cs` must update `target->clear_rx_cs` (`cs | TA | DMAEN | CLEAR_RX`) and call `dma_sync_single_for_device()` on `clear_rx_addr` if `ctlr->dma_rx`. `bcm2835_spi_interrupt()` takes `bs` as `dev_id`, whereas `bcm2835_spi_dma_rx/tx_done()` take `ctlr` as `data`. [F58, F132, F154]
- In `bcm2835_spi_transfer_one()`, when `0 < spi_hz < bs->clk_hz / 2`, `cdiv = DIV_ROUND_UP(bs->clk_hz, spi_hz)` must be made even (`cdiv += (cdiv % 2)`) and wrap to `0` at `65536` (`effective_speed_hz` treating `0` as `65536`). In `bcm2835` and `bcm2835aux`, guard divisions by `polling_limit_us` (`0664` param) and `hz_per_byte` against `0`, and use `time_after(jiffies, timeout)` in poll loops (including `cqspi_wait_idle()`). [F112, F113, F114]
- In `spi-bcm2835aux.c`, `bcm2835aux_spi_transfer_one()` must clear `BCM2835_AUX_SPI_CNTL0_SPEED` in `bs->cntl[0]` before ORing speed and zero `bs->pending` per transfer. `bcm2835aux_wr_fifo()` packs up to 3 bytes from bit 16 (`8 * (2 - i)`), increments `bs->pending`, and decrements `bs->tx_len` by `count` before testing `if (bs->tx_len)` for `TXHOLD` vs `IO`; `bcm2835aux_rd_fifo()` decrements `bs->rx_len` and `bs->pending` and unpacks via fallthrough `case 3`..`1`. [F59, F60, F101]
- In `atmel-quadspi.c`, `atmel_qspi_exec_op()` must reject `op->addr.val + op->data.nbytes > aq->mmap_size` or `op->addr.nbytes > 4`. Updating `QSPI_SCR` or `QSPI_MR` must mask only the target bitfield in `aq->scr`/`aq->mr`, OR in new bits, and pass `aq->mr` for `QSPI_MR` and `aq->scr` for `QSPI_SCR` to `atmel_qspi_write()`. DLL control (`DLLON`/`DLLOFF`, `DLLCFG`, `SR2_DLOCK`) requires `aq->caps->has_dllon`, and `atmel_qspi_set_pad_calibration()` requires `aq->caps->octal && aq->caps->has_padcalib`. [F53, F77, F95, F144]
- `cqspi_probe()` stores `struct cqspi_st *` and `amlogic_spifc_a1_probe()` stores `struct amlogic_spifc_a1 *` in drvdata; PM/remove callbacks must cast `dev_get_drvdata()` to those structs and pass `cqspi->host` or `spifc->ctrl` to `spi_controller_suspend/resume()`. Whenever `cqspi_controller_init()` runs (`cqspi_probe()`, `cqspi_runtime_resume()`), reset `cqspi->current_cs = -1` and `cqspi->sclk = 0`. [F61, F121, F122]
- In `spi-cadence-quadspi.c`, `cqspi_command_read/write()` must reject `op->data.nbytes > 8` (`CQSPI_STIG_DATA_LEN_MAX`). In `cqspi_indirect_read_execute()`, when `remaining < 4` makes `round_down(bytes_to_read, 4)` zero, `else if (!word_remain && mod_bytes)` must read the final word and set `bytes_to_read = mod_bytes`. In `cqspi_versal_indirect_read_dma()`, use `lower/upper_32_bits(dma_addr)` and restore `CQSPI_REG_CONFIG_DMA_MASK` and `PM_OSPI_MUX_SEL_LINEAR` on completion and `failrd`. [F63, F78, F107, F120]
- `cdns_xspi_adjust_mem_op_size()` must clamp `op->data.nbytes` to `cdns_xspi->sdmasize` and `amlogic_spifc_a1_adjust_op_size()` to `SPIFC_A1_BUFFER_SIZE` (512). In `cdns_mrvl_xspi_setup_clock()`, bound `i` to `ARRAY_SIZE(cdns_mrvl_xspi_clk_div_list) - 1`. In `spi-altera-core.c`, glue drivers without an IRQ must set `hw->irq < 0`; all `ALTERA_SPI_CONTROL` changes (`SSO_MSK`, `IRRDY_MSK`) must update and write `hw->imr`; `altera_spi_txrx()` sets `hw->bytes_per_word = DIV_ROUND_UP(t->bits_per_word, 8)` and `hw->len = t->len / hw->bytes_per_word` (words), while `tx/rx_word` index `hw->tx/rx` by `hw->count * hw->bytes_per_word`. [F49, F64, F75, F87, F111, F129]
- In `spi-au1550.c`, `au1550_spi_chipsel/setupxfer()` must call `au1550_spi_bits_handlers_set()` and set `PSC_SPICFG_DD_DISABLE` per `hw->usedma && bpw <= 8`. In `au1550_spi_dma_txrxb()`, map `tx_buf` (`DMA_TO_DEVICE`) before `rx_buf` (`DMA_FROM_DEVICE`); when `!t->rx_buf && t->len > hw->dma_rx_tmpbuf_size`, reallocate `dma_rx_tmpbuf` before caching `hw->rx` and `dma_rx_addr`; when `!t->tx_buf`, sync `dma_rx_addr` with `DMA_BIDIRECTIONAL` (`hw->tx = hw->rx`). [F66, F67, F156]
- In `spi-armada-3700.c`, `a3700_spi_bytelen_set()` updates `A3700_SPI_BYTE_LEN` and `a3700_spi->byte_len` in lockstep, and `a3700_spi_transfer_setup()` resets `byte_len` to 4; in `a3700_spi_transfer_one_fifo()`, when `tx_buf && buf_len % 4`, `a3700_spi_header_set()` sends leading `buf_len % 4` bytes via `IF_ADDR_REG` before `a3700_spi_fifo_write()`; in `a3700_spi_clock_set()`, `prescale > 15` uses `A3700_SPI_CLK_EVEN_OFFS + DIV_ROUND_UP(prescale, 2)`. [F68, F89, F115]
- In `spi-cavium.c`/`.h`, bitfields in `union cvmx_mpi_cfg/datx/sts/tx` must have matching `#ifdef __BIG_ENDIAN_BITFIELD` and `#else` definitions totaling 64 bits. In `octeon_spi_do_transfer()`, `p->cs_enax |= 1ull << (12 + cs)` (guarded by `cs < 4`) must be ORed into `mpi_cfg.u64` before updating `p->last_cfg` and `OCTEON_SPI_CFG(p)`, and the chunk loop must be `while (len > OCTEON_SPI_MAX_BYTES)` with `leavecs = 1` so the tail sets `leavecs = last_xfer ? xfer->cs_change : !xfer->cs_change`. [F71, F88, F105, F118]
- In `spi-cadence.c`, raising `CDNS_SPI_THLD` above `1` requires resetting it to `0x1`. In `spi-ath79.c`, `ath79_exec_mem_op()` must restore `AR71XX_SPI_FS_GPIO` in `REG_FS` and `sp->ioc_base` in `REG_IOC`. In `spi-butterfly.c`, parport writes must update and write `pp->lastbyte`. [F65, F69, F74]

## Synchronization

- In `bcm2835_spi_transfer_one_dma()`, `bs->tx_dma_active = true` + `smp_wmb()` must precede `dma_async_issue_pending(ctlr->dma_tx)`, and `bs->rx_dma_active = true` + `smp_mb()` must follow `dma_async_issue_pending(ctlr->dma_rx)`, pairing with `smp_wmb()` and `cmpxchg(&bs->rx_dma_active, true, false)` in `bcm2835_spi_dma_tx_done()`. In `bcm2835_spi_prepare_sg()`, set `bs->target = target` before `dmaengine_submit()` for TX-only DMA. `bcm2835_spi_dma_rx/tx_done()` run in atomic context and must use `dmaengine_terminate_async()`. [F15, F16, F152]
- Because `bcm2835` and `bcm2835aux` ISRs use `IRQF_SHARED` without a lock, `bcm2835_spi_transfer_one_irq()` must set `CS_TA` and fill the TX FIFO before enabling `CS_INTR | CS_INTD`, `bcm2835aux_spi_transfer_one_irq()` must program `CNTL1`/`CNTL0` and fill the FIFO before enabling `TXEMPTY | IDLE`, and both ISRs must return `IRQ_NONE` if IRQ-enable bits are clear. [F19, F20, F150]
- In `atmel_qspi_wait_for_completion()`, after reading `QSPI_SR`, set `reinit_completion(&aq->cmd_completion)`, `aq->pending = sr & irq_mask`, and `aq->irq_mask = irq_mask` before `QSPI_IER`, and test `((... & irq_mask) == irq_mask)` while ORing bits into `aq->pending`. In `atmel_qspi_transfer()`, a dummy `atmel_qspi_read(aq, QSPI_IFR)` must precede `aq->mem` accesses, and `rmb()`/`wmb()` must precede `QSPI_CR_LASTXFER`. [F21, F22, F96]
- `spi_bitbang_init()` must init `bitbang->lock` and `bitbang->ctlr` callbacks before `spi_bitbang_start()`, and `bitbang->lock` must guard `bitbang->busy` in `prepare/unprepare_hardware()`. In `altera_spi_probe()`, `altera_spi_init_host()` must precede `devm_request_irq()`; in `altera_spi_txrx()`, `hw` fields must be set before `IRRDY_MSK` and `altera_spi_tx_word(hw)`; regmaps backing `struct altera_spi` (and `indirect_bus_reg_read/write()`) must not sleep (`altera_spi_irq()` runs in hardirq). [F27, F30, F158]
- `au1550_spi_bits_handlers_set(hw, 8)` must precede `request_irq()` in `au1550_spi_probe()`. In `spi_clps711x_probe()`, `readl(hw->syncio)` must precede `devm_request_irq()`, and `spi_clps711x_transfer_one()` must init `hw` state before `SYNCIO_TXFRMEN`. In `cdns_xspi_send_stig_command()`, set `sdma_error = false` and buffers before triggering, and run `sdma_handler()` only after `wait_for_completion(&cdns_xspi->sdma_complete)` when `!sdma_error`. In `a3700_spi_transfer_wait/wait_completion()`, set `wait_mask`, poll `IF_CTRL_REG`, and `reinit_completion(&a3700_spi->done)` before unmasking `INT_MASK_REG`. [F28, F32, F33, F34]

## Object Lifetimes

- In `bcm2835_spi_transfer_one_dma()`, after `bcm2835_spi_transfer_prologue()` mutates `tx_sg`/`rx_sg`, all completion/error/abort paths must call `bcm2835_spi_undo_prologue(bs)` before unmapping, and cyclic descriptors (`fill_tx_desc`, `clear_rx_desc`) must be terminated on the peer channel before reuse/free. In `bcm2835_spi_remove()`, `spi_unregister_controller()` must precede `bcm2835_dma_release()`, which must `dmaengine_terminate_sync()` `dma_tx`/`dma_rx` before freeing `fill_tx_desc`, unmapping `fill_tx_addr`, and releasing channels. [F8, F18, F140]
- In `atmel_qspi_dma_xfer()` and `cqspi_direct_read_execute()`, `reinit_completion()` must precede DMA issue, and on `wait_for_completion_timeout()` timeout, call `dmaengine_terminate_sync()` before unmapping DMA buffers. In `atmel-quadspi.c`, `atmel_qspi_exec_op()` owns the runtime PM reference from `pm_runtime_resume_and_get()`, so `aq->ops->set_cfg` and `aq->ops->transfer` callbacks must not call `pm_runtime_put*()`. [F23, F24, F137]
- `cqspi_probe()` must init `cqspi->refcount` and `cqspi->inflight_ops` to 1 before `spi_register_controller()`, and `cqspi_remove()` must set `cqspi->refcount = 0` and call `cqspi_wait_idle()` if `!refcount_dec_and_test(&cqspi->inflight_ops)` before `spi_unregister_controller()` and disabling hardware. In `cdns_xspi_of_get_plat_data()`, every early return inside `device_for_each_child_node()` must call `fwnode_handle_put(fwnode_child)`. [F26, F106]
- In `au1550_spi_dma_txrxb()`, call `au1xxx_dbdma_stop()` on `dma_tx_ch` and `dma_rx_ch` after `wait_for_completion(&hw->host_done)` and before DMA sync/unmap, and `au1550_spi_remove()` must call `spi_bitbang_stop()` and `free_irq()` before freeing DMA resources. In `butterfly_detach()`, clear global `butterfly = NULL` before unregistering the controller and releasing parport/host resources. [F12, F29]

## API Contracts

- Before `spi_bitbang_init/start()`, set `bitbang->ctlr`, leave `ctlr->transfer` and `transfer_one_message` `NULL`, and set `bitbang->chipselect` if `!ctlr->use_gpio_descriptors || (ctlr->flags & SPI_CONTROLLER_GPIO_SS)`. With default `!bitbang->txrx_bufs`, `spi->controller_state` is owned by `spi_bitbang` (use `spi->controller_data`). Custom `bitbang->txrx_bufs` must return `transfer->len` on success. `getmiso()` must return `0` or `1`, and `bitbang_txrx_*()` / `ath79_spi_txrx_mode0()` require `bits` in `1..32`. [F36, F38, F108, F109, F124]
- When `bcm2835_spi_transfer_one_poll()` falls back to `bcm2835_spi_transfer_one_irq()`, pass `fifo_empty = false`. `bcm2835_rd/wr_fifo_count()` require `BCM2835_SPI_CS_DMAEN` set in `BCM2835_SPI_CS` and `rx_len`/`tx_len >= count` (toggling `DMAEN` switches 8/32-bit FIFO width). In `atmel-quadspi.c`, entering Serial Memory Mode must use `atmel_qspi_set_serial_memory_mode()` (updates `aq->mr` with `QSPI_MR_SMM`, writes `QSPI_MR`, and calls `atmel_qspi_update_config(aq)` if `has_gclk`), and when `!aq->caps->octal`, `atmel_qspi_supports_op()` must reject `addr.nbytes == 2 && dummy.nbytes == 0 && cmd.buswidth != addr.buswidth`. [F42, F54, F57, F166]
- `cqspi_supports_mem_op()` must verify DTR ops have `dtr == true` and `buswidth == 8` on all non-empty phases (`nbytes > 0`) and reject mixed STR/DTR phases. In `spi-cadence-xspi.c`, zero `u32 cmd_regs[6]` with `memset()` before `cdns_xspi_trigger_command()`. In `spi-cadence.c`, `cdns_spi_config_clock_mode()` must disable `CDNS_SPI_ER` before changing `CPHA`/`CPOL` in `CDNS_SPI_CR`. Before `altera_spi_init_host(host)`, set `hw->regmap` (and `hw->regoff`) and pass `host` (not `hw`) as `dev_id` to `devm_request_irq(..., altera_spi_irq, ...)`. `mcfqspi_transfer_one()` must pass `t->len / 2` (16-bit words) to `mcfqspi_transfer_msg16()`. [F52, F70, F130, F164, F167]

## Error Handling

- When requesting optional DMA channels in `bcm2835_dma_init()`, `atmel_qspi_dma_init/probe()`, and `cqspi_request_mmap_dma()`, propagate `-EPROBE_DEFER`, but on other errors (and in `bcm2835_dma_release()`) reset `ctlr->dma_tx/rx`, both `aq->rx_chan` and `aq->tx_chan`, or `cqspi->rx_chan` to `NULL`. In `bcm2835_dma_init()` and `bcm2835_spi_setup_dma()`, reset `fill_tx_addr` and `clear_rx_addr` to `0` on `dma_mapping_error()`. In `bcm2835_spi_cleanup()`, guard `gpiod_put(bs->cs_gpio)` with `!IS_ERR(bs->cs_gpio)`. [F7, F39, F40, F45, F135]
- In `amlogic_spifc_a1_resume()`, call `clk_disable_unprepare(spifc->clk)` if `spi_controller_resume()` fails. In `atmel_qspi_set_cs_timing()`, check signed `int delay = spi_delay_to_ns()` for `< 0` before multiplying by `unsigned long` clock rate. In `cqspi_setup_flash()`, init `max_cs = -1`, update via `max_t(int, cs, max_cs)`, and check `max_cs < 0` before `cqspi->num_chipselect = max_cs + 1`. [F14, F94, F116]
- In `spi-au1550.c`, `au1xxx_dbdma_*()` and `au1xxx_ddma_add_device()` return `0` on failure (check `!ret`), and `au1550_spi_dma_rxtmp_alloc/free()` must reset both `dma_rx_tmpbuf` and `dma_rx_tmpbuf_size` to `0` on free/error. In `spi-cadence.c`, `cdns_transfer_one()` returns `transfer->len`, and on `CDNS_SPI_IXR_MODF`, `cdns_spi_irq()` must call `spi_finalize_current_transfer(ctlr)` with `tx_bytes`/`rx_bytes` non-zero. [F50, F51, F165]

## External Contracts

- In `cdns_xspi_probe()`, if `mrvl_hw_overlay` is true and `"xfer"` (or index 3) MMIO resource is missing, fall back `cdns_xspi->xferbase` to `cdns_xspi->iobase + 0x8000`. Without GPIO CS (`spi_get_csgpiod(spi, 0)`), `bcm2835_spi_setup()` must reject `chipselect > 1` with `-EINVAL` (GPIO `8 - cs`), and `bcm2835aux_spi_setup()` must reject `chipselect != 0` with `-EINVAL`. [F91, F92]

## Known Pitfalls

- In `spi-bcm2835.c`, hardware halts TX when the RX FIFO is full: `bcm2835_wait_tx_fifo_empty()` callers must ensure the RX FIFO fits all TX bytes, and `bcm2835_spi_dma_tx_done()` must repeatedly write `bs->target->clear_rx_cs` inside its `BCM2835_SPI_CS_DONE` poll loop. In `spi-au1550.c`, every `hw->regs->psc_*` write and status poll read needs a trailing `wmb()`, and in `au1550_spi_pio_irq_callback()`, `hw->tx_word(hw)` must only run inside the `!(stat & PSC_SPISTAT_RE) && hw->rx_count < hw->len` block after `hw->rx_word(hw)`. [F98, F102, F148]
- In `spi-cadence-quadspi.c`, `cqspi_configure()` must disable the controller (`cqspi_controller_enable(cqspi, 0)`) before changing CS, baudrate, delays, or read capture. Writes to `CQSPI_REG_SIZE` and `CQSPI_REG_INDIRECTRD/WR` must be flushed with `readl()` before accessing `cqspi->ahb_base`. `cqspi_direct_read_execute()` and `cqspi_read()` must check `virt_addr_valid(buf)` (and `(dma_align & CQSPI_DMA_UNALIGN) == 0` for `indirect_read_dma`) before DMA, and `ioread32_rep()`/`iowrite32_rep()` take 32-bit word counts (`bytes / 4`) while `rxbuf`/`txbuf` and `remaining` advance in bytes. [F131, F134, F146, F155]
