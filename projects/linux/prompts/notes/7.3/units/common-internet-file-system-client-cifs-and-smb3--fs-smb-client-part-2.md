# COMMON INTERNET FILE SYSTEM CLIENT (CIFS and SMB3) — fs/smb/client (part 2)

This unit implements core network connection and session lifecycle management, socket demultiplexing, SMB1 PDU construction and transport, SMB3 message compression (LZ77), and Distributed File System (DFS) referral walking and caching.

## Architecture & Data Flow
- In `struct cifs_ses`, `ses->chans[0]` is the primary channel and secondary channels are `1..ses->chan_count - 1`; secondary channel loops in `cifs_signal_cifsd_for_reconnect()` and `__cifs_put_smb_ses()` must start at 1. In `cifs_mark_tcp_ses_conns_for_reconnect()`, iterate `&pserver->smb_ses_list` (`pserver = server->primary_server` for secondary channels), but pass `server` to per-channel helpers (`cifs_ses_get_chan_index()`, `cifs_chan_set_need_reconnect()`). [F104, F130]
- When `__cifs_reconnect()` runs with `mark_smb_session` true, it must call `cifs_signal_cifsd_for_reconnect(server, mark_smb_session)` before `cifs_mark_tcp_ses_conns_for_reconnect()` so `tcpStatus` becomes `CifsNeedReconnect` on primary and all secondary channels. `cifs_mark_tcp_ses_conns_for_reconnect()` only sets `ses->ses_status = SES_NEED_RECON` and marks `tcon_list` and `tcon_ipc` `need_reconnect = true` / `status = TID_NEED_RECON` (canceling `tcon->query_interfaces`) when `mark_smb_session` is true or `CIFS_ALL_CHANS_NEED_RECONNECT(ses)` becomes true. [F69, F70]
- In `cifs_negotiate_protocol()`, setting `server->tcpStatus = CifsInNegotiate` under `srv_lock` must set `server->neg_start = jiffies` without touching `server->lstrp`, and `server_unresponsive()` checks the 20s negotiate timeout against `neg_start`. On `-EAGAIN` from `server->ops->negotiate()`, jumping to `retry:` is guarded by `in_retry` (converting a second `-EAGAIN` to `-EHOSTDOWN`). In `cifs_get_smb_ses()`, `retry_old_session:` and `retry_new_session:` on `-EACCES`, `-EKEYEXPIRED`, or `-EKEYREVOKED` require `(!retries && ses->password2)`, incrementing `retries` and swapping `ses->password` with `ses->password2`. [F68, F123, F124]
- In `cifs_demultiplex_thread()`, jumping to `next_pdu:` for a compounded response (`pdu_length > server->pdu_size`) must call `allocate_buffers()`, subtract `server->pdu_size` from `pdu_length`, reset `server->total_read = 0`, `server->large_buf = false`, and `buf = server->smallbuf`, and defer `pending_reconnect` until frame end. [F122]
- `match_server()` requires `net_eq(cifs_net_ns(server), current->nsproxy->net_ns)`. In `match_session()`, `Kerberos` or `IAKerb` security requires `uid_eq(ctx->cred_uid, ses->cred_uid)`. In multiuser `struct tcon_link`, `tl_tcon` holds an `ERR_PTR` while `TCON_LINK_PENDING` is set or after `cifs_construct_tcon()` fails; `cifs_put_tlink()` and `cifs_sb_tlink()` must check `!IS_ERR(tlink_tcon(tlink))` before dereferencing or calling `cifs_put_tcon()`. [F53, F178, F182]
- In `dfs_mount_share()`, once `dfs_get_referral()` confirms DFS and `!ctx->dfs_conn`, it must set `ctx->dfs_conn = true`, call `cifs_mount_put_conns(mnt_ctx)`, and re-call `get_session(mnt_ctx, NULL)` for a dedicated `server->dfs_conn = true` connection. `DFS_INTERLINK(v)` requires `DFSREF_REFERRAL_SERVER` set and `DFSREF_STORAGE_SERVER` clear; `setup_dfs_ref()` and `__dfs_referral_walk()` treat a target as interlink only if `tgt->server_type == DFS_TYPE_LINK && DFS_INTERLINK(tgt->flags)`. [F83, F110]
- `ref_walk_advance(rw)` must call `__ref_walk_free(ref)` on `ref = ref_walk_cur(rw) + 1` before advancing `ref_walk_cur(rw)` to free prior deeper-walk state. In `__dfs_referral_walk()`, advancing into a nested referral via `ref_walk_advance(rw)` and `setup_dfs_ref(&tgt, rw)` must call `ref_walk_mark_end(rw)` (`ref->tit = ERR_PTR(-ENOENT)`) before `goto again`. In `lookup_cache_entry()`, prefix lookups on >2 components must strip trailing separators and back `e` up to the previous separator to match whole components. [F86, F125, F129]
- In `cifs_are_all_path_components_accessible()`, after setting `tmp = *s; *s = 0;` for `server->ops->is_path_accessible()`, restore `*s = tmp` immediately before inspecting/freeing `full_path`, and advance `s` past leading separators and the current component before `if (skip) { skip = 0; continue; }`. [F88, F127]
- In `CIFSSMBQAllEAs()`, `ea_response_data + list_len` must not exceed `end_of_smb` (`(char *)pByteArea(&pSMBr->hdr) + get_bcc(&pSMBr->hdr)`), and `list_len` must be signed `int`, aborting with `-EIO` if subtracting `4` or `name_len + 1 + value_len` makes `list_len < 0`. In `cifs_to_posix_acl()`, verify `size_of_data_area >= sizeof(struct cifs_posix_acl) + sizeof(struct cifs_posix_ace) * access_entry_count` (plus `* default_entry_count` with default ACEs at `&cifs_acl->ace_array[access_entry_count]` for `ACL_TYPE_DEFAULT`). In `access_flags_to_smbopen_mode()`, `(with_write_flags && with_read_flags)` must precede individual `with_write_flags` and `with_execute_flags` checks. [F98, F99, F111]

## Synchronization
- Lock order: `ses->session_mutex` -> `cifs_tcp_ses_lock` -> `server->srv_lock` -> `ses->ses_lock` -> `ses->chan_lock` -> `tcon->tc_lock` (drop `chan_lock` before taking `session_mutex`). `match_server()` requires `srv_lock`, `match_session()` requires `ses_lock` + `chan_lock`, and `match_tcon()` requires `tc_lock`. `cifs_tcp_ses_lock` must protect all changes to `srv_count`, `ses_count` (`cifs_smb_ses_inc_refcount()`), `tc_count`, `cifs_tcp_ses_list`, `server->smb_ses_list`, and `ses->tcon_list`. [F32, F33, F163]
- `cifs_signal_cifsd_for_reconnect()` must never take `server->srv_lock` (`set_need_reco()`) under `ses->ses_lock` or `ses->chan_lock`; pin secondary channels (`nserver->srv_count++`) onto a local list under `cifs_tcp_ses_lock` and `chan_lock`, then update `tcpStatus` under `srv_lock` after dropping session locks. [F22]
- In `cifs_reconnect_tcon()`, after locking `ses->session_mutex`, revalidate `server->tcpStatus` under `srv_lock` and `cifs_chan_needs_reconnect(ses, server)` and `ses->ses_status` under `ses_lock` + `chan_lock` before `cifs_negotiate_protocol()`. In `cifs_negotiate_protocol()`, `cifs_setup_session()`, and `cifs_tree_connect()`, post-RPC state updates must re-lock `srv_lock`/`ses_lock`/`tc_lock` and only transition if still `CifsInNegotiate`, `SES_IN_SETUP`, or `TID_IN_TCON`. [F36, F37]
- `cifs_put_tcp_session()` and `cifs_demultiplex_thread()` coordinate exit via `xchg(&server->tsk, NULL)`; if `cifs_demultiplex_thread()` gets `NULL`, it must sleep until `signal_pending(current)` before exiting. `cifs_put_tcp_session()` must drop `cifs_tcp_ses_lock` before cancelling echo/reconnect work, and `smb2_reconnect_server` must pass `from_reconnect != 0` so it uses `cancel_delayed_work(&server->reconnect)`. `reconn_set_ipaddr_from_hostname()` requires `cifs_server_lock(server)` (`_srv_mutex`) and must drop `srv_lock` across `dns_resolve_name()`. [F28, F166, F170]
- In `dfs_cache.c`, drop `htable_rw_lock` before `get_dfs_referral()`, and after `down_write(&htable_rw_lock)` re-check `lookup_cache_entry(path)` and `cache_entry_expired(ce)` before updating/adding. `cache_refresh_path()` returns valid `ce` with `htable_rw_lock` read-locked and unlocks on `IS_ERR(ce)`, so callers call `up_read(&htable_rw_lock)` iff `!IS_ERR(ce)`. [F15, F34]
- Populate `tcon->origin_fullpath` and `tcon->dfs_ses_list` (`ref_walk_set_tcon()`) under `tcon->tc_lock` before queuing `tcon->dfs_cache_work` in `__dfs_mount_share()` and `cifs_construct_tcon()`. In `cifs_umount()`, call `cancel_delayed_work_sync(&cifs_sb->prune_tlinks)` before unlinking `tcon_sb_link`, draining `tlink_tree`, or `call_rcu(&cifs_sb->rcu, delayed_free)`. In `cifs_set_cifscreds()`, hold `down_read(&key->sem)` across `user_key_payload_locked(key)` and `upayload->data` reads, calling `up_read(&key->sem)` before `key_put(key)`. [F25, F39, F183]

## Object Lifetimes
- `cifs_get_smb_ses()` and `cifs_get_tcon()` require an active caller reference on `server->srv_count` / `ses->ses_count`: each drops it (`cifs_put_tcp_session(server, 0)` / `cifs_put_smb_ses(ses)`) when returning an existing object, transfers it to `ses->server` / `tcon->ses` for a new one, and leaves it with the caller on `ERR_PTR` return. [F1, F2]
- In `cifs_get_tcp_session()`, the netns ref (`get_net()`) and any `tcp_ses->primary_server` ref (`SERVER_IS_CHAN(tcp_ses)`) must be put on error before `cifs_demultiplex_thread` starts (`out_err_crypto_release`), and otherwise in `clean_demultiplex_info()` and `cifs_put_tcp_session()`. `cifsd`-used fields (`server->hostname`, `server->leaf_fullpath`) and `server` itself must only be freed in `clean_demultiplex_info()` on thread exit, never in `cifs_put_tcp_session()`. [F5, F23]
- Every `sock_release(server->ssocket)` path (`cifs_abort_connection()`, `clean_demultiplex_info()`, `generic_ip_connect()` error) must set `server->ssocket = NULL`. In `generic_ip_connect()`, after `sock_create_kern()`, immediately call `sk_net_refcnt_upgrade(server->ssocket->sk)`, set `sk_allocation = GFP_NOFS` and `sk_use_task_frag = false`, and call `cifs_reclassify_socket4/6()`; `cifs_demultiplex_thread()` must keep `memalloc_noreclaim_save()` active for its whole lifetime. [F4, F161, F175, F177]
- `cifs_put_tcon()` must return immediately if `tcon->ipc` is true (`ses->tcon_ipc` is freed only in `__cifs_put_smb_ses()`), and otherwise call `cancel_delayed_work_sync()` on `tcon->query_interfaces` and `tcon->dfs_cache_work` before draining `tcon->dfs_ses_list` (`dfs_put_root_smb_sessions()`) or freeing `tcon`. When removing a `tcon_link` from `cifs_sb->tlink_tree` in `cifs_prune_tlinks()` or `cifs_umount()`, advance the rbtree cursor, call `cifs_get_tlink(tlink)`, clear `TCON_LINK_IN_TREE`, and `rb_erase()` under `tlink_tree_lock` before dropping it to call `cifs_put_tlink(tlink)`. [F7, F24, F120]
- In DFS walks, `set_root_smb_session()` pins `mnt_ctx->ses` in `ref_walk_ses(rw)`; `ref_walk_set_tcon()` moves `ref->ses` to `tcon->dfs_ses_list` and clears `ref->ses = NULL` so `ref_walk_free()` skips them. In `dfs.c`, `get_session()` temporarily aliases `ctx->leaf_fullpath` and `ctx->dns_dom` for `cifs_mount_get_session()` and must reset both to `NULL` before returning. [F13, F152]
- `alloc_cache_entry()` steals `refs[0].path_name` (`ce->path = refs[0].path_name; refs[0].path_name = NULL`), so `cache_entry_hash()` in `add_cache_entry_locked()` must run before `alloc_cache_entry()`. In `purge_cache()`, update `oldest = ce` only in the `else if` branch when `ce->numtgts != 1` (not freed by `flush_cache_ent(ce)`). [F14, F121]
- After `CIFS_open()` succeeds: `cifs_query_reparse_point()` must call `CIFSSMBClose()` on all paths and transfer `io_rsp` (`io_req`) to `rsp->iov_base` (`*rsp_buftype = CIFS_LARGE_BUFFER`) on success while calling `cifs_buf_release(io_req)` only on error; `cifs_create_reparse_inode()` (`FILE_CREATE`) must preserve the error `rc` across both `CIFSSMBClose()` and `CIFSSMBDelFile()` before returning `ERR_PTR(rc)`. [F18, F19, F58]

## API Contracts
- Only `cifs_demultiplex_thread` may call `cifs_reconnect()` or `cifs_mark_tcp_ses_conns_for_reconnect()`; other threads must use `cifs_signal_cifsd_for_reconnect()`. `CIFSSMBQFSUnixInfo()` and `CIFSSMBSetFSUnixInfo()` must use `smb_init_no_reconnect()` (called from `reset_cifs_unix_caps()` during reconnect), and `CIFSTCon()` must clear `tcon->need_reconnect = false` before calling `reset_cifs_unix_caps()`. [F29, F43, F78]
- `target_share_matches_server()` and `match_target_ip()` return `0` on evaluation success and set `*target_match` / `*result` (callers must check both `rc` and `target_match`). `extract_unc_hostname()` returns a non-NUL-terminated `dfs_host` of length `dfs_host_len`; bound all uses (`strlen(server->hostname) == dfs_host_len`, `strncasecmp()`, `%.*s`, `match_target_ip()`). `cifs_get_dfs_tcon_super()` returns `ERR_PTR` on failure (check `!IS_ERR(sb)` before `CIFS_SB(sb)`). [F48, F51, F154]
- `compress.c` (`collect_sample()`, `smb_compress()`) must use generic `iov_iter` helpers (`copy_from_iter()`, `copy_from_iter_full()`, `iov_iter_advance()`, `iov_iter_count()`) rather than accessing `iter->xarray`/`bvec`/`kvec` directly. In `CIFSSMBRead()`, if `*buf != NULL`, copy data to `*buf` and `free_rsp_buf()`; if `*buf == NULL` and `resp_buf_type != CIFS_NO_BUFFER`, transfer `rsp_iov.iov_base` and `resp_buf_type` to `*buf` and `*pbuf_type`. [F52, F55]
- DFS cache/referral helpers (`dfs_cache_find()`, `dfs_cache_noreq_find()`, `dfs_cache_noreq_update_tgthint()`, `dfs_cache_get_tgt_referral()`, `dfs_cache_get_tgt_share()`, `dfs_parse_target_referral()`) expect single-slash paths: pass `path + 1` for `\\`-prefixed UNC strings. Scale `ctx->echo_interval` (seconds) by `HZ` for `server->echo_interval` (jiffies) in `cifs_get_tcp_session()` and `match_server()`. In `cifs_writev_callback()`, set `NETFS_SREQ_NEED_RETRY` with `result = -EAGAIN` (`MID_REQUEST_SUBMITTED` / `MID_RETRY_NEEDED`) and `NETFS_SREQ_MADE_PROGRESS` when `written >= wdata->subreq.len && written > 0` before `cifs_write_subrequest_terminated()`. [F64, F67, F181]

## Error Handling
- `cifs_reconnect_tcon()` returns `-EAGAIN` after reconnect for handle-based commands (`SMB_COM_READ_ANDX`, `SMB_COM_WRITE_ANDX`, `SMB_COM_CLOSE`, `SMB_COM_FIND_CLOSE2`, `SMB_COM_LOCKING_ANDX`): callers must never retry on `-EAGAIN`, and `CIFSSMBClose()`, `CIFSFindClose()`, `CIFSSMBTDis()`, and `CIFSSMBLogoff()` must map `-EAGAIN` to `0`. In `is_smb_response()`, after `cifs_reconnect_once()` for RFC1002 NetBIOS negotiate, map `0` to `mid->mid_rc = -EAGAIN` and `-EAGAIN` to `-EHOSTDOWN`. [F45, F46]
- In `dfs_referral_walk()`, if `ref_walk_alloc()` returns `IS_ERR(*rw)`, reset `*rw = NULL` so `__dfs_mount_share()` cleanup (`ref_walk_free(rw)`) does not dereference an `ERR_PTR`. In `cifs_fill_unix_set_info()`, initialize `EndOfFile`, `NumOfBytes`, and invalid `uid`/`gid` in `FILE_UNIX_BASIC_INFO` to `cpu_to_le64(NO_CHANGE_64)`, never `0` (which truncates the file). [F57, F61]

## External Contracts
- In `posix_acl_to_cifs()`, set the unused entry count field in `struct cifs_posix_acl` to `cpu_to_le16(0xFFFF)`, not `0`. `dfscache_proc_write()` must read the first byte via `get_user(c, buffer)`, return `-EINVAL` unless `c == '0'`, and flush under `down_write(&htable_rw_lock)`. In `CIFSSMBWrite`, `cifs_writev_callback`, and `CIFSSMBWrite2`, if `(le16_to_cpu(CountHigh) << 16) + le16_to_cpu(Count)` exceeds the requested write length, mask it with `&= 0xFFFF`. [F100, F107, F133]

## Known Pitfalls
- `free_xid()` evaluates `(int)rc`: initialize `int rc = 0` on all paths reaching `free_xid()` or use `_free_xid()`. In `CIFSFindNext()`, `psrch_inf->presume_name` aliases `psrch_inf->ntwrk_buf_start`; copy `presume_name` and validate the new response (`SendReceive()` + `validate_t2()`) before freeing old `ntwrk_buf_start`. In `cifs_enable_signing()`, check `((global_secflags & CIFSSEC_MUST_SIGN) == CIFSSEC_MUST_SIGN)` because `CIFSSEC_MUST_SIGN` includes `CIFSSEC_MAY_SIGN`. [F62, F80, F109]
- Reset `length = 0` before `continue` after negative recv returns in `cifs_readv_from_socket()`, and set `l1 = 1` before `continue` when `l1 < 0 && l2 < 0 && s1[i] == s2[i]` in `dfs_path_equal()`. In `refresh_ses_referral()` and `refresh_tcon_referral()`, evaluate `dfs_ses_refpath(ses)` before overwriting `ses = CIFS_DFS_ROOT_SES(ses)`. [F126, F128, F131]
- Cast `le16_to_cpu(pSMBr->ServerTimeZone)` to `(__s16)` before multiplying by `60` in `CIFSSMBNegotiate`, and use `time_before()` / `time_after()` for `jiffies` comparisons (`lstrp`, `neg_start`, `tl_time`) in `connect.c`. Allocate `ppath` with `kzalloc()` in `dfs_cache_get_tgt_share()` so `ppath[c + 1]` is NUL after `ppath[c] = sep` before `strlcat()`, and pass `len = s - line + 1` (`s = strchrnul(s, ',')`) to `strscpy(root_dev, line, len)` in `cifs_root_setup()`. [F134, F138, F157, F158]
