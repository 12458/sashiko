# ETHERNET PHY LIBRARY — drivers/net/phy (part 1)

`drivers/net/phy` (part 1) contains Ethernet PHY drivers for Broadcom, TI DP83xxx (including DP83640 PTP), Marvell (88Q2xxx, 88X2222), Intel XWAY, ICPlus, LXT, Cicada, Cortina, Davicom, and ET1011C, plus `fixed_phy.c` and `linkmode.c`.

## Architecture & Data Flow
- In `dp83822.c` and `marvell-88q2xxx.c`, every `struct phy_driver` entry wiring callbacks that dereference `phydev->priv` (`dp83825_config_init`, `dp83826_config_init`, `dp83822_set_wol`, `mv88q2xxx_config_init`, `config_intr`) must wire a `.probe` callback (`dp8382x_probe`, `dp83822_probe`, `dp83826_probe`, `mv88q2xxx_probe`) to allocate `phydev->priv`. [F208]
- In `dp83640.c`, `enable_status_frames()` must set `ENDIAN_FLAG` (`PSF_ENDIAN` on LE, `0` on BE) in `PSF_CFG0` because `decode_status_frame()` and `decode_evnt()` cast status bytes directly to host-endian `u16`, `struct phy_rxts`, and `struct phy_txts`. `decode_evnt()` must check `len >= parsed` before dereferencing `data` and read `struct phy_txts` words only up to `words` (`0..3`). [F251, F252]
- In `recalibrate()` (`dp83640.c`), `PSF_CFG0` on `PAGE5` must be saved into `dp83640_private::cfg0` (slaves) and local `cfg0` (master), cleared to `0` before calibration events, and restored on all PHYs before releasing `clock->extreg_lock`. [F227]
- In `dp83640.c`, `gpio_tab` only seeds `clock->caps.pin_config` in `dp83640_clock_init()`; `periodic_output()`, `ptp_dp83640_enable()`, and `recalibrate()` must query `clock->ptp_clock` via `ptp_find_pin*()`. External timestamp channels (`rq->extts.index`, `event.index` in `0..N_EXT_TS - 1`) are 0-based while hardware event units start at `EXT_EVENT` (`1`), so `ptp_dp83640_enable()`, `decode_evnt()`, and `exts_chan_to_edata()` must translate between `ch` and `ch + EXT_EVENT` and verify `index < N_EXT_TS`. [F229, F250]
- In `bcm54140.c`, `bcm54140_get_base_addr_and_port()` must reset `addr = phydev->mdio.addr` before `step++` on bus boundary or PHY ID mismatch, and verify `(max_addr - min_addr + 1) % 4 == 0` before deriving `priv->port` (`0..3`). Global `BCM54140_RDB_TOP_IMR` must be accessed only via `bcm54140_base_read_rdb()`/`bcm54140_base_write_rdb()`, and `bcm54140_config_intr()` must modify only `port_to_imr_bit[priv->port]`. [F231, F253, F271]
- On BCM7xxx 28nm GPHYs (`bcm7xxx.c`), Wirespeed/downshift and EEE are mutually exclusive: `bcm7xxx_28nm_config_init()` and `bcm7xxx_28nm_set_tunable()` must call `bcm_phy_set_eee(phydev, count == DOWNSHIFT_DEV_DISABLE)`. [F232]
- In `dp83td510_cable_test_get_tdr_status()` and `dp83tg720_cable_test_get_status()`, TDR completion must call `phy_init_hw(phydev)`. On DP83TG720, before `phy_init_hw()` in `dp83tg720_cable_test_get_status()` or `dp83tg720_read_status()` (`!phydev->link`), `dp83tg720_update_stats()` must run first, and `dp83tg720_read_status()` must call `dp83tg720_config_aneg()` afterward. `dp83tg720_config_aneg()` and `dp83tg720_config_init()` must call `genphy_c45_pma_baset1_read_master_slave(phydev)`. [F235, F236, F237]
- `jiffies` deadlines (`rxts->tmo` in `expired()`, `skb_info->tmo` in `decode_txts()`/`rx_timestamp_work()`, `priv->last_link_down_jiffies` in `dp83tg720_get_next_update_time()`) must use `unsigned long` and `time_after()`/`time_before()`. `dp83tg720_get_next_update_time()` must clear `priv->last_link_down_jiffies = 0` when `phydev->link` is true. [F238, F281]
- In `marvell-88q2xxx.c`, volatile settings cleared by GPIO reset (`mv88q2xxx_enable_temp_sense(phydev)`, LED0 `TX_DISABLE` clearing) must be applied in `mv88q2xxx_config_init()`. In `mv88q2xxx_read_status()`, when `AUTONEG_ENABLE`, `mv88q2xxx_read_aneg_speed(phydev)` must precede `mv88q2xxx_read_link(phydev)`. In `mv88q2xxx_handle_interrupt()`, `MDIO_MMD_PCS_MV_COPPER_INT_STAT` must be read before `MDIO_MMD_PCS_MV_GPIO_INT_STAT` without returning early on 100BASE-T1 events. [F239, F240, F274]
- In `marvell-88x2222.c`, updating `mv2222_data::line_interface` (`mv2222_sfp_insert()`, `mv2222_swap_line_type()`) must be followed by `mv2222_config_line(phydev)`. [F243]
- In `dp83822_phy_reset()` and `dp83869_phy_reset()`, a global software reset (`DP83822_SW_RESET`/`DP83869_SW_RESET`) resets all registers and must be followed by `config_init(phydev)`. [F244]
- In `dp83867_led_hw_control_set()` and `dp83td510_led_hw_control_set()`, setting triggers in `LEDCR1`/`LEDS_CFG_1` must clear `DP83867_LED_DRV_EN(index)`/`DP83TD510E_LED_DRV_EN(index)` in `LEDCR2`/`LEDS_CFG_2`. Conversely, `xway_gphy_led_hw_control_set()` must set `XWAY_GPHY_LED_EN(index)` in `XWAY_MDIO_LED` because `xway_gphy_led_brightness_set()` clears it when turning the LED off. [F245, F246]
- In `bcm84881.c`, `bcm84881_probe()` must check `(phydev->c45_ids.devices_in_package & mmd_mask) != mmd_mask` for `MDIO_DEVS_PMAPMD | MDIO_DEVS_AN`. In `bcm84881_read_status()`, after `phy_resolve_aneg_linkmode()`, it must read `MDIO_MMD_VEND1` `0x4011` and update `phydev->interface` and `phydev->speed` together. [F247, F263]
- In `bcm87xx_of_reg_init()`, `len` must be divided by `sizeof(*paddr)` and iterated with `while (paddr + 3 < paddr_end)` for each 4-cell tuple. In `dp83td510_get_sqi()`, `dp83td510_mse_sqi_map[]` must be in descending MSE order. [F257, F265]

## Synchronization
- In `dp83640.c`, `dp83640_clock::clock_lock` protects `chosen`, `phylist`, and `ptp_clock`, and must never be held while acquiring `phyter_clocks_lock`. Callers of `ext_read()`, `ext_write()`, `tdr_write()`, and `enable_broadcast()` must hold `clock->extreg_lock` across `PAGESEL` writes, `clock->page` updates, and multi-word `PTP_TDR`/`PTP_EDATA` accesses. [F197, F200]
- In `dp83640.c`, `dp83640_rxtstamp()`, `dp83640_txtstamp()`, and `decode_status_frame()` run in packet contexts and must not perform sleeping MDIO accesses or take mutexes like `extreg_lock`. In `decode_rxts()`, `dp83640->rx_lock` must be acquired before `dp83640->rx_queue.lock`, and both released before `netif_rx()`. [F199, F319]
- In `bcm54140.c`, `priv->alarm_lock` must be initialized before `bcm54140_probe_once()` and held across the `BCM54140_RDB_MON_ISR` read, `priv->alarm` latch, and bit clear in `bcm54140_hwmon_read_alarm()`. `bcm54140_base_read_rdb()`/`bcm54140_base_write_rdb()` must hold `phy_lock_mdio_bus(phydev)` across both address and data phases on `BCM54140_BASE_ADDR`. [F204, F205]
- Callbacks invoked under `mdio_lock`—`bcm7xxx_28nm_ephy_read_mmd()`/`write_mmd()` in `bcm7xxx.c`, and `ip101g_read_page()`, `ip101g_write_page()`, and code between `phy_select_page()` and `phy_restore_page()` in `icplus.c`—must use unlocked helpers (`__phy_read()`, `__phy_write()`, `__phy_modify()`, `__phy_set_clr_bits()`). [F206, F325]

## Object Lifetimes
- In `dp83822_of_init_leds()` and `mv88q2xxx_leds_probe()`, `leds` from `of_get_child_by_name()` must be released with `of_node_put(leds)` on all exit paths, even when using `for_each_available_child_of_node_scoped(leds, led)`. In `dp83867_of_init_io_impedance()`, `cell` from `of_nvmem_cell_get()` requires `nvmem_cell_put(cell)` and `buf` from `nvmem_cell_read()` requires `kfree(buf)` when `!IS_ERR(buf)`. [F195, F306]
- In `fixed_phy.c`, `fixed_phy_register()` must call `__fixed_phy_add()` before `get_phy_device()`, and `fixed_phy_unregister()` must call `phy_device_remove()` before `fixed_phy_del()`. In `bcm54140_probe()`, `devm_phy_package_join()` must precede `phy_package_init_once(phydev)`, gating `bcm54140_probe_once()`. [F207, F298]

## API Contracts
- `dp83640_rxtstamp()` consumes `skb` iff it returns `true`, whereas `dp83640_txtstamp()` unconditionally consumes `skb` on every path. [F192]
- In `dp83640.c`, hardware GPIO numbers (`gpio_tab[]`, `TRIG_GPIO`, `EVNT_GPIO`) are 1-based (`1..DP83640_N_PINS`, `0` = disabled) while `pin_config[]` indices and `ptp_find_pin*()` returns are 0-based (`-1` on failure), requiring `- 1` for `pin_config` and `1 +` (checked `< 1`) for registers. `decode_evnt()` must always return a positive byte count (`parsed`, or `len` when `len < parsed`) so `decode_status_frame()` terminates. In `ptp_dp83640_enable()`, rejecting dual-edge requests requires `(rq->extts.flags & PTP_EXTTS_EDGES) == PTP_EXTTS_EDGES`. [F212, F264, F285]
- In `bcm7xxx.c`, `__phy_set_clr_bits()` and `phy_set_clr_bits()` take `(dev, location, set_mask, clr_mask)`, opposite to `phy_modify(phydev, regnum, mask, set)`. [F223]
- In `mv88q222x_cable_test_get_status()`, `dp83td510_cable_test_get_tdr_status()`, and `dp83td510_cable_test_get_alcd_status()`, register fault distance (in meters) must be multiplied by `100` for `ethnl_cable_test_fault_length*()`. `dp83td510_cable_test_get_status()` and `dp83tg720_cable_test_get_status()` must set `*finished = false` before polling completion bits. Drivers without a cable-test interrupt (`bcm54140`, `dp83td510`, `dp83tg720`, `mv88q2220`) must set `PHY_POLL_CABLE_TEST`. [F224, F225, F335]
- In `dp83869_configure_mode()`, `PHY_INTERFACE_MODE_MII` must permit `DP83869_RGMII_COPPER_ETHERNET` alongside `DP83869_100M_MEDIA_CONVERT` and `DP83869_RGMII_100_BASE`. [F262]
- In `bcm54140.c` and `marvell-88q2xxx.c`, hwmon `drvdata` is `phydev`, so callbacks must get `struct phy_device *` via `dev_get_drvdata(dev)` and read `phydev->priv`. In tunable callbacks (`bcm54140`, `dp83867`, `dp83869`, `bcm7xxx_28nm`), `void *data` is `u8 *` for `ETHTOOL_PHY_DOWNSHIFT` and `u16 *` for `ETHTOOL_PHY_EDPD`. [F289, F290]
- Use `#if IS_ENABLED(CONFIG_OF_MDIO)` (not `#ifdef`) for DT MDIO helpers. `dp83tg720_get_next_update_time()` must clamp jiffies with `max(next_time_jiffies, 1U)`. In `config_intr`, clear pending interrupts before unmasking on enable, and mask before clearing on disable. `linkmode_set_pause()` sets `Pause_BIT = rx` and `Asym_Pause_BIT = rx ^ tx`. [F326, F338, F341, F345]

## Error Handling
- `enable_status_frames()` (`dp83640.c`) must check `phydev->attached_dev` for `NULL` before `dev_mc_add()`/`dev_mc_del()`. In `dp83869_of_init()`, `ret` must be reset to `0` after holding the `DP83869_STRAP_STS1` read value. [F216, F219]
- In `icplus.c`, after `oldpage = phy_select_page()`, all exit paths must call `phy_restore_page(phydev, oldpage, ret)` with `ret` initialized; `ip101g_get_stat()` must store `phy_read_paged()` in signed `int val` and return `U64_MAX` if `val < 0`. [F220, F221]
- `xway_gphy_led_polarity_set()` must fall through to `return -EINVAL` if neither polarity is set. In `bcm84881_aneg_done()` and `bcm84881_read_status()`, the second `phy_read_mmd()` error check must test and return `bmsr`, not `val`. In `handle_interrupt` callbacks, negative read errors must call `phy_error(phydev)` and return `IRQ_NONE`. [F260, F261, F340]

## External Contracts
- In `mv88q2xxx_read_link_gbit()` and `mv88q2xxx_read_link_100m()`, when `phy_polling_mode(phydev)` and `phydev->link` are true, status registers must be read only once so latched-low link drops are not cleared. [F241]
- In `dp83822_config_wol()`, `dp83811_set_wol()`, `dp83867_set_wol()`, and `dp83869_set_wol()`, 6-byte `ndev->dev_addr` and `wol->sopass` must be packed into 16-bit MMD registers as `(byte[2*i + 1] << 8) | byte[2*i]` for `i = 0..2`. `dp83822_suspend()` and `dp83811_suspend()` must skip `genphy_suspend()` when `WOL_EN` is set, and resume must set `WOL_CLR_INDICATION`. [F256, F304]
- In `dp83td510_update_stats()` and `dp83tg720_update_stats()`, TX (`PKT_STAT_1..3`) and RX (`PKT_STAT_4..6`) register groups freeze on reading the first register and clear only after reading all three in ascending order (`1, 2, 3` and `4, 5, 6`); each read must be checked for `< 0` and combined in `u32 count` (`count |= ret << 16`) before adding to `u64` stats. [F258, F283]
- Hardware rules: `dp83640_soft_reset()` must delay `>= 3` us (`udelay(10)`) after `genphy_soft_reset()`; `bcm84881_config_aneg()` must call `bcm84881_wait_init()` before writing AN registers; `DP83848_PHY_DRIVER` entries must set `PHY_RST_AFTER_CLK_EN`; `dp83869_config_aneg()`/`read_status()` must use `genphy_c37_*()` when `mode == DP83869_RGMII_1000_BASE`; `dp83tg720_config_init()` must write `DP83TG720S_LPS_CFG3_PWR_MODE_0` after `dp83tg720_soft_reset()`; `ptp_dp83640_verify()` must return `1` if `func == PTP_PF_PHYSYNC` or if overwriting an active `PTP_PF_PHYSYNC` pin when `!list_empty(&clock->phylist)`. [F294, F301, F305, F308, F310, F333]

## Known Pitfalls
- In `lxt.c`, `lxt973_probe()` sets `phydev->priv` to the function pointer `lxt973_probe` (or `NULL`) as a fiber-mode flag; never dereference or `kfree()` it. In `mv2222_set_sgmii_speed()`, `SPEED_1000` and `SPEED_100` cases must fall through to lower speeds when unsupported. [F222, F266]
- In `dp83640_txtstamp()`, `HWTSTAMP_TX_ONESTEP_SYNC` must free `skb` and return early only when `ptp_msg_is_sync(skb, type)` is true, falling through to `HWTSTAMP_TX_ON` otherwise. In `rx_timestamp_work()`, after pushing an unexpired SKB back via `skb_queue_head()`, the loop must `break` (not `continue`). [F268, F273]
- In `dp83640.c`: `phy2rxts()`/`phy2txts()` must mask `p->ns_hi & 0x3fff` and assemble `u32 sec` before casting to `u64` for `* 1000000000ULL`; `ptp_dp83640_gettime()` must hold `PTP_TDR` reads in `unsigned int val[]` before `val[2] | (val[3] << 16)` to avoid sign-extension into `ts->tv_sec`; `ptp_dp83640_adjfine()` must negate negative `scaled_ppm` and widen to `u64 rate` before `<< 13` and `div_u64(rate, 15625)`. [F278, F279, F280]
- In `bcm54140_hwmon_write_temp()` and `bcm54140_hwmon_write_in()`, `val` must be clamped with `clamp_val()` to `[BCM54140_HWMON_TO_TEMP(mask), BCM54140_HWMON_TO_TEMP(0)]` or `[0, BCM54140_HWMON_TO_IN(channel, mask)]` before `BCM54140_HWMON_FROM_*()` so `DIV_ROUND_CLOSEST_ULL()` never gets a negative dividend. [F282]
