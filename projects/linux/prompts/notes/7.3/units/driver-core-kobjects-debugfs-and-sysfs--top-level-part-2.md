# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS — (top level) (part 2)

Implements the C kobject lifecycle, kset hierarchy, and userspace uevent (netlink and usermodehelper) delivery in `lib/kobject*.c`, alongside Rust abstractions in `rust/kernel/` for the driver model, platform and faux buses, device properties (`fwnode`), device ID tables, device-managed resources (`devres`), and `debugfs`.

## Architecture & Data Flow

- `kobject_uevent` and `kobject_uevent_env` must be called after all sysfs attributes for `kobj` are created (`kobject_add` does not emit `KOBJ_ADD`). In `kobject_uevent_env`, `kobj->state_remove_uevent_sent = 1` is set on `KOBJ_REMOVE` entry before `kset`, `uevent_suppress`, or `filter` checks, whereas `kobj->state_add_uevent_sent = 1` is set only after `KOBJ_ADD` environment generation succeeds (gating automatic `KOBJ_REMOVE` in `__kobject_del`). `top_kobj` is only used to locate `top_kobj->kset`; `uevent_suppress`, `state_*_uevent_sent`, and `uevent_ops` (`filter`, `name`, `uevent`) must operate on `kobj`. [F225, F250, F284]
- All pointers in `env->envp[0..env->envp_idx]` must point into `env->buf` in contiguous ascending order via `add_uevent_var`, because `zap_modalias_env` shifts `env->buflen - (env->envp[i + 1] - env->envp[0])` bytes and subtracts `strlen(env->envp[i]) + 1` from later `env->envp[j]` pointers. In `zap_modalias_env`, the outer loop must only increment `i` when `env->envp[i]` does not match `"MODALIAS="`, as matching iterations shift `env->envp[i + 1..]` down and decrement `env->envp_idx`. [F237, F247]
- Every `kobj_ns_ops_tbl[type]` access in `lib/kobject.c` must validate `type` with `kobj_ns_type_is_valid(type)` (rejecting `type <= KOBJ_NS_TYPE_NONE` (0) and `type >= KOBJ_NS_TYPES`). In `create_dir`, if `kobj_child_ns_ops(kobj)` returns a non-NULL `kobj_ns_type_operations` pointer, its `ops->type` must be valid and already registered via `kobj_ns_type_register`, or `create_dir` triggers `BUG_ON` before `sysfs_enable_ns`. [F234, F310]
- Every enumerator in `enum kobject_action` (`include/linux/kobject.h`) must have a matching string entry at the same index in `kobject_actions[]` (`lib/kobject_uevent.c`), as `kobject_uevent_env` indexes `kobject_actions[action]` directly and `kobject_action_type` maps indices back to `enum kobject_action`. [F223]
- In `rust/kernel/debugfs.rs`, `FileOps::adapt()` transmutes `&FileOps<T>` to `&FileOps<T::Inner>` while keeping `T`'s C callbacks (`writer_open::<T>`, `write::<T>`, `write_only_write::<T>`), so every `Adapter` implementer (`WritableAdapter`, `FormatAdapter`, `NoWriter`) must be `#[repr(transparent)]` over `T::Inner`. Every `Dir` and `ScopedDir` callback-file constructor instantiating `FormatAdapter<D, F>` or `WritableAdapter<D, W>` must require `&'static F` or `&'static W` so `F`/`W` are proven inhabited before `materialize_zst` uses `NonNull::dangling()`. [F269, F270]
- `PropertyInt::read_array_from_fwnode_property` and `FwNode::property_read_array_vec` must check `to_result(ret)?` from `fwnode_property_read_*_array` before transmuting `&mut [MaybeUninit<Self>]` to `&mut [Self]` or calling `val.inc_len(len)`. [F277]

## Synchronization

- In `lib/kobject.c`, `kset_find_obj` (and any `kset->list` traversal under `kset->list_lock`) must acquire references via `kobject_get_unless_zero` rather than `kobject_get` because `kobject_put` drops `kobj->kref` to zero before `kobject_cleanup` takes `kset->list_lock` in `kobj_kset_leave`. Also in `kset_find_obj`, a separate `ret` variable initialized to `NULL` must capture the match before `break` rather than returning the `list_for_each_entry` cursor `k` (which points to the list head on no match). [F253, F300]
- In `lib/kobject.c`, `kobj_kset_leave` must unlock `kobj->kset->list_lock` before calling `kset_put(kobj->kset)`, because dropping the last `kset` reference runs `kobject_cleanup` (sleeping sysfs/uevent operations) and `kset_release` (freeing the `struct kset` containing `list_lock`). [F301]
- `kobject_get_path()` measures the path with `get_kobj_path_length()` (starting `length` at 1 for NUL and adding `strlen(kobject_name(parent)) + 1` per level) and fills it backward in `fill_kobj_path()` (pre-decrementing `length` into a `kzalloc(len, gfp_mask)` buffer) without a lock against concurrent `kobject_rename()`; therefore `fill_kobj_path()` must check `length <= 0` before each `memcpy()` and `kobject_get_path()` must `kfree(path)` and `goto retry` on error. Callers of `kobject_rename()` must externally serialize concurrent renames on the same `struct kobject`. [F192, F194, F263]
- In `lib/kobject_uevent.c`, `uevent_sock_list` is protected by `uevent_sock_mutex`: `uevent_net_init()` must initialize `ue_sk->sk` before linking `ue_sk->list` under `uevent_sock_mutex`, and `uevent_net_exit()` must unlink `ue_sk->list` under `uevent_sock_mutex` before `netlink_kernel_release(ue_sk->sk)`. [F198]
- In `rust/kernel/devres.rs`, `Devres::devres_callback` must revoke `inner.data` with `Revocable::revoke` (awaiting `synchronize_rcu()` before dropping `T`) rather than `revoke_nosync`, because other threads may hold RCU-protected `RevocableGuard`s from `Devres::try_access`. `Devres<T>`, `Inner<T>`, `devres::register`, and `platform::Driver` must require `Send` because C devres and bus `remove` callbacks may drop values on another thread. [F278, F304]

## Object Lifetimes

- A `struct kobject` only holds a reference on `kobj->parent` while `kobj->state_in_sysfs` is 1. If `create_dir` fails in `kobject_add_internal` after `kobject_get(parent)` and `kobj_kset_join`, it must call `kobj_kset_leave(kobj)`, `kobject_put(parent)`, and clear `kobj->parent = NULL` while leaving `state_in_sysfs` as 0. `__kobject_del` clears `state_in_sysfs` and `kobj->parent` without dropping `parent`, so `kobject_del` and `kobject_cleanup` must cache `kobj->parent` beforehand and only call `kobject_put(parent)` when `state_in_sysfs` was set. [F173, F224]
- `kobject_cleanup` must cache `kobj->parent` and `kobj->name` before invoking `t->release(kobj)`, and must free `name` (`kfree_const`) and drop `parent` (`kobject_put`) only after `t->release(kobj)` returns, because `t->release` may free `kobj` while still reading `kobject_name(kobj)` or `kobj->parent`. [F174]
- `create_dir` takes an extra reference on `kobj->sd` via `sysfs_get(kobj->sd)` after creating the directory and default groups, and `__kobject_del` must release it via `sysfs_put(sd)` after `sysfs_remove_dir(kobj)` so `kobj->sd` remains valid until `kobj` leaves sysfs even if an ancestor directory is removed. [F175]
- In `kobject_move`, once `sysfs_move_dir_ns` succeeds and `kobj->parent = new_parent` is assigned, `new_parent` must be set to `NULL` and `old_parent` released with `kobject_put(old_parent)` so the `out:` label's `kobject_put(new_parent)` only drops `new_parent` on failure. [F176]
- In `kobject_uevent_env`, once `call_usermodehelper_setup` returns a non-NULL `info` with `cleanup_uevent_env` registered, calling `call_usermodehelper_exec(info, UMH_NO_WAIT)` transfers ownership of `env` and `env` must be set to `NULL` so `exit:`'s `kfree(env)` does not double-free it. [F177]
- `uevent_net_broadcast_untagged` reuses one lazily allocated `skb` across `uevent_sock_list` by passing `skb_get(skb)` to each `netlink_broadcast` call and calling `consume_skb(skb)` after the loop, whereas `uevent_net_broadcast_tagged` passes its single `skb` directly to `netlink_broadcast`, which consumes it. [F178]
- In `rust/kernel/debugfs.rs`, `Entry<'static>` created by `Entry::dynamic_dir` or `Entry::dynamic_file` must store `Option<Arc<Entry<'static>>>` in `_parent` so a parent `Dir`'s dentry is not recursively removed by `debugfs_remove` while child `Entry` handles exist. In `Scope<T>`, `data: T` must be initialized in pinned memory before `init(&scope.data)` creates debugfs entries in `Scope::new()`, and `_entry: Entry<'static>` must be declared before `data: T` in `struct Scope<T>` so `Entry::drop()` runs `debugfs_remove()` before `data` is dropped. [F181, F203]
- `Device::fwnode` must return a borrowed `Option<&property::FwNode>` tied to `&self` rather than `FwNode::from_raw`, because `bindings::__dev_fwnode` does not increment the refcount. In `fmt::Display` for `FwNode`, `depth == 0` must borrow `self` (`Node::Borrowed(self)`) whereas `depth > 0` must wrap `bindings::fwnode_get_nth_parent` in `Node::Owned(FwNode::from_raw(ptr))` so the parent refcount is dropped at the end of the loop iteration. [F186, F189]
- In `FwNode::children`, `bindings::fwnode_get_next_child_node` drops the refcount of a non-null `prev` and increments the refcount of the returned `next` pointer, so each step must pass `ARef::into_raw(prev)`, wrap `next` in `FwNode::from_raw(next)`, and store `Some(next.clone())` in `prev`. In `FwNode::property_get_reference_args`, `bindings::fwnode_property_get_reference_args` increments `out_args.0.fwnode`'s refcount when non-null, so `FwNodeReferenceArgs::drop` must check `!self.0.fwnode.is_null()` and drop it via `FwNode::from_raw(self.0.fwnode)`. [F187, F188]
- `Devres::access` must verify `self.dev.as_raw() == dev.as_raw()` on the caller's `&'a Device<Bound>` before calling `unsafe { self.data().access() }`, proving `self.data` is not revoked during `'a`. [F280]

## API Contracts

- Once `kobject_init` or `kobject_init_and_add` has been called, callers must release `kobj` via `kobject_put` even if `kobject_add` or `kobject_init_and_add` fails, because `kobject_add_varg` allocates `kobj->name` before `kobject_add_internal` runs and only `kobject_cleanup` frees `kobj->name` and calls `t->release`. Conversely, `kset_register` requires `k->kobj.ktype` to be non-NULL (returning `-EINVAL` if unset), and if `kset_register` fails it frees `k->kobj.name` with `kfree_const` and sets `k->kobj.name = NULL` without `kobject_put`, so `kset_create_and_add` must free `kset` with `kfree` (not `kset_unregister`) and callers must not read `k->kobj.name`. [F171, F283, F311]
- Once a `struct kobject` is in sysfs, its name must be changed via `kobject_rename` (not `kobject_set_name`). Both `kobject_rename` and `kobject_move` must capture `DEVPATH_OLD` via `kobject_get_path` and succeed in `sysfs_rename_dir_ns` / `sysfs_move_dir_ns` before updating `kobj->name` or `kobj->parent`, and must update `kobj->name` / `kobj->parent` before calling `kobject_uevent_env(kobj, KOBJ_MOVE, envp)`. [F226, F227]
- `kobject_uevent` and `kobject_uevent_env` must only be called from sleepable process context (`GFP_KERNEL` allocations and `uevent_sock_mutex`). Any non-NULL `envp_ext` passed to `kobject_uevent_env` must be `NULL`-terminated. [F239, F303]
- When `FwNode::property_get_reference_args()` calls `bindings::fwnode_property_get_reference_args()`, it must zero-initialize `out_args` (`FwNodeReferenceArgs::default()`) and pass `nargs = 0` when `nargs_prop` is non-null (`NArgs::Prop`) or `nargs_prop = ptr::null()` when a numeric `nargs` is given (`NArgs::N`). [F215]
- Any device wrapper passed to `impl_device_context_deref!` must be `#[repr(transparent)]` with layout independent of its `DeviceContext` parameter, and `AlwaysRefCounted` must only be implemented for `Device<Normal>` so scoped contexts (`CoreInternal`, `Core`, `Bound`) cannot be cloned into `ARef`. [F275]

## Error Handling

- In `lib/kobject.c`, `create_dir()`, `__kobject_del()`, `kobject_cleanup()`, and `kobj_child_ns_ops()` must check that `kobj->ktype` (or `get_ktype(kobj)`) is non-NULL before dereferencing `default_groups`, `release`, or `child_ns_type`. `kobject_get_ownership()` must initialize `*uid = GLOBAL_ROOT_UID` and `*gid = GLOBAL_ROOT_GID` before invoking the optional `kobj->ktype->get_ownership` callback. [F204, F208]
- In `lib/kobject_uevent.c`, `uevent_net_broadcast_untagged()`, `uevent_net_broadcast_tagged()`, and `uevent_net_broadcast()` must convert `-ENOBUFS` and `-ESRCH` from `netlink_broadcast()` to `0`. [F209]
- `devres::register_foreign` converts `data` via `data.into_foreign()` before registering `callback::<P>` and must use `bindings::devm_add_action_or_reset` (not `devm_add_action`) so `callback::<P>` reconstructs and drops `P::from_foreign` if registration fails. [F185]
- In `rust/kernel/debugfs.rs`, when a parent `Dir` holds `None` (failed `Arc<Entry>` allocation), `Dir::create`, `Dir::create_file`, and `Dir::scoped_dir` (`Entry::dynamic_dir` / `Entry::dynamic_file`) must short-circuit to `None` or `Entry::empty()` / `ScopedDir::empty()` rather than passing a NULL parent dentry to `debugfs_create_*` (which would create entries in the debugfs root). [F212]
- In `FwNode::property_read_array_vec()`, errors from `T::read_array_from_fwnode_property()` must be stored in `PropertyGuard::inner` (not early-returned with `?`), whereas `KVec::with_capacity()` allocation failure is returned via the outer `Result`. `PropertyGuard::required_by` and `platform::Device::irq_by_index`/`irq_by_name` log device errors when missing, whereas `PropertyGuard::optional` and `optional_irq_by_index`/`optional_irq_by_name` suppress error logging. [F214, F322]
- In `rust/kernel/platform.rs`, `TryFrom<&device::Device<Ctx>>` for `&platform::Device<Ctx>` must check `bindings::dev_is_platform(dev.as_raw())` before using `container_of!` to downcast to `bindings::platform_device`. [F220]

## External Contracts

- In `kobject_uevent_env`, `zap_modalias_env` must run on `KOBJ_UNBIND` after `envp_ext` and `uevent_ops->uevent` populate `env` to strip all `MODALIAS=` variables before broadcast. `init_uevent_argv` must only be called after `kobject_uevent_net_broadcast`, `zap_modalias_env`, and all `add_uevent_var` calls because it writes raw `subsystem` bytes into `env->buf` and advances `env->buflen` without adding an `env->envp` entry. `uevent_helper` is only executed via `call_usermodehelper_exec` when `!kobj_usermode_filter(kobj)` (requiring namespace-tagged kobjects to belong to `ops->initial_ns()`). [F238, F313, F317]
- `uevent_net_init` and `uevent_net_exit` only link `uevent_sock` into `uevent_sock_list` when `sock_net(ue_sk->sk)->user_ns == &init_user_ns`, preventing untagged uevents from broadcasting to non-initial user namespaces. When `uevent_net_broadcast_tagged` sends to a netns with `owning_user_ns != &init_user_ns`, it must overwrite `NETLINK_CB(skb).creds.uid`/`gid` with `make_kuid(owning_user_ns, 0)` and `make_kgid(owning_user_ns, 0)` if valid. [F315, F316]
- `uevent_net_rcv_skb` must authorize userspace netlink uevents with `netlink_ns_capable(skb, net->user_ns, CAP_SYS_ADMIN)` (`net = sock_net(NETLINK_CB(skb).sk)`). `uevent_net_broadcast` must include the trailing NUL byte (`ret++`) in `"SEQNUM=%llu"`, reject `skb->len + ret > UEVENT_BUFFER_SIZE` before `skb_copy_expand`, and strip `NLMSG_HDRLEN` via `skb_pull(skbc, NLMSG_HDRLEN)` before `netlink_broadcast`. [F240, F318]

## Known Pitfalls

- `ScopedDir` wraps its `Entry` in `ManuallyDrop` and `ScopedDir::create_file` calls `core::mem::forget(Entry::file(...))` because child entries are recursively cleaned up when the owning `Scope` drops; therefore any root `ScopedDir` from `Dir::scoped_dir` or `ScopedDir::new` must have its `Entry` extracted via `into_entry()` into a `Scope`. [F182]
- In `kobject_set_name_vargs`, `kvasprintf_const` may return a `.rodata` pointer, so any string containing `'/'` must be duplicated with `kstrdup` before `strreplace` mutates `'/'` to `'!'` in place, and the old `kobj->name` must only be freed after the new string is allocated. [F228]
- In `kobject_action_args`, after `action_arg_word_end(buf, buf_end, '=')` scans a key, the caller must check `next > buf_end || *next != '='` in addition to `!next`, because `action_arg_word_end` returns `buf_end + 1` when it reaches the end of the buffer without finding the delimiter. [F249]
- In `rust/kernel/platform.rs`, `irq_by_index`, `optional_irq_by_index`, `irq_by_name`, and `optional_irq_by_name` must check `irq < 0` on the `c_int` returned by `platform_get_irq*` before casting `irq as u32` to construct an `IrqRequest`. [F245]
