# COMMON INTERNET FILE SYSTEM CLIENT (CIFS and SMB3) — fs/smb/client (part 4)

This component implements SMB session setup and authentication (NTLMSSP, Kerberos/SPNEGO), multichannel interface management, directory enumeration (`readdir`), reparse point and symlink/special-file handling (Native, NFS, WSL), SMB1 version operations, and SMB2/3 compounded metadata operations, message validation, and status-to-errno mapping.

## Architecture & Data Flow
- In `smb2_compound_op()`, `cmds[0] == SMB2_OP_OPEN_QUERY` is skipped before the request-build loop and parsed from `rsp_iov[0]` before the response loop, and `SMB2_OP_MKDIR` neither increments `num_rqst` nor calls `*_free(&rqst[num_rqst++])`. After temporarily adding 2 to `num_cmds` to copy/free `Open` and `Close` buffers in `rsp_iov`/`resp_buftype`, `num_cmds` must be decremented by 2 before `goto replay_again`, where `flags`, `oplock`, `num_rqst`, `server`, `vars`, and `resp_buftype` are reinitialized. [F408, F446]
- In `smb2_compound_op()` for `SMB2_OP_POSIX_QUERY_INFO`, after `smb2_validate_and_copy_iov()` copies the fixed `sizeof(data->posix_fi)` header, `parse_posix_sids()` must verify `out_len > sizeof(data->posix_fi)` and validate both variable-length owner/group SIDs within `[sidsbuf, sidsbuf_end)` via `posix_info_sid_size()` before `memcpy`. [F427]
- `smb2_rsp_struct_sizes[]` and `has_smb2_data_area[]` are indexed by host-endian `le16_to_cpu(shdr->Command)` after `smb2_check_message()` verifies `command < NUMBER_OF_SMB2_COMMANDS`, whereas `smb2_rsp_struct_sizes[]` elements are stored as `__le16` to compare directly with `pdu->StructureSize2`. [F428]
- In `cifs_readdir()`, populating `struct cached_dirents` requires setting `cfid->dirents.pos = 2` at `ctx->pos == 0`, calling `add_cached_dirent()` (which sets `cde->is_failed = 1` if `ctx->pos != cde->pos`) before `ctx->pos++` and `update_cached_dirents_count()`, and setting `cde->is_valid = 1` only if `ctx->pos == cde->pos` and `!cde->is_failed`. When `add_cached_dirent()` updates `entries_count` and `bytes_used`, `cifs_dir_emit()` must update `cfid->cfids->total_dirents_bytes`, `cfid->cfids->total_dirents_entries`, and `cifs_dircache_bytes_used` by the same `sizeof(struct cached_dirent) + namelen + 1` delta. [F407, F451]
- `nxt_dir_entry()` must check pointer wraparound (`old_entry + next_offset < old_entry`), verify `new_entry < end_of_smb`, and ensure the minimum entry header plus 1 byte (`sizeof(FIND_FILE_STANDARD_INFO) + 1` or `sizeof(FILE_DIRECTORY_INFO) + 1`) fits before `end_of_smb`. [F430]
- In `smb2_create_reparse_inode()` and `cifs_make_node()`, reparse special-file creation is permitted via `CIFS_REPARSE_SUPPORT(tcon)` when `tcon->posix_extensions` is enabled or `FILE_SUPPORTS_REPARSE_POINTS` is set in `tcon->fsAttrInfo.Attributes`, and in `cifs_make_node()` only after `tcon->unix_ext` and `CIFS_MOUNT_UNX_EMUL` checks. [F440]
- In `smb2_unlock_range()`, iterating `&cfile->llist->locks` requires `list_for_each_entry_safe()` because matching locks are either deleted/freed immediately (`cinode->can_cache_brlcks`) or moved via `list_move(&li->llist, &tmp_llist)` for batched `smb2_lockv()` calls that restore `tmp_llist` via `cifs_move_llist()` on error. [F448]
- In `cifs_get_next_mid()`, `cur_mid` and `last_mid` must remain `__u16` (even though `server->current_mid` is `__u64`): the loop records `last_mid = cur_mid` before advancing, skips `0xffff` and `0`, relies on 16-bit wraparound of `cur_mid++` to stop at `cur_mid == last_mid`, and calls `cifs_signal_cifsd_for_reconnect(server, false)` if `server->pending_mid_q` exceeds 32768 entries. [F454, F462]
- When `cifs_chan_update_iface()` updates `ses->chans[chan_index].iface`, it must copy `iface->sockaddr` to `server->dstaddr` under `server->srv_lock` and adjust `num_channels` and `weight_fulfilled` on both old and new interfaces under `ses->iface_lock`. In `cifs_try_adding_channels()` and `cifs_chan_update_iface()`, `last_iface->speed` must only be used as the divisor in `iface->speed / iface_min_speed` under `ses->iface_lock` after verifying `ses->iface_count` is non-zero. [F401, F463]

## Synchronization
- All channel helpers in `fs/smb/client/sess.c` (`cifs_ses_get_chan_index`, `cifs_chan_set_in_reconnect`, `cifs_chan_clear_in_reconnect`, `cifs_chan_set_need_reconnect`, `cifs_chan_clear_need_reconnect`, `cifs_chan_needs_reconnect`, `cifs_chan_is_iface_active`) require `ses->chan_lock`. [F364]
- Session locks order `ses->iface_lock` outer to `ses->chan_lock`: `is_ses_using_iface()` acquires `ses->chan_lock` under `ses->iface_lock`, while `cifs_disable_secondary_channels()` and `cifs_chan_update_iface()` must drop `ses->chan_lock` before taking `ses->iface_lock`. After `cifs_chan_update_iface()` relocks `ses->chan_lock`, it must re-verify `chan_index = cifs_ses_get_chan_index(ses, server) != CIFS_INVAL_CHAN_INDEX` before setting `ses->chans[chan_index].iface`. [F365, F368]
- In `find_cifs_entry()`, when rewinding a search, `cfile->file_info_lock` must be held while checking `server->ops->dir_needs_close(cfile)` and setting `cfile->invalidHandle = true`, and dropped before calling `server->ops->close_dir`. [F371]
- In `cifs_readdir()` and `cifs_dir_emit()`, `cfid->dirents.de_mutex` must protect all reads/updates to `cfid->dirents` (`emit_cached_dirents`, `add_cached_dirent`, `update_cached_dirents_count`, `finished_cached_dirents_count`), and `cached_fid` must be released via `close_cached_dir()` before `initiate_cifs_search()` or `find_cifs_entry()`. [F372]
- In `smb2_unlock_range()` and `smb2_push_mandatory_locks()`, `server->maxBuf` must be snapshotted into a local variable and checked to be `>= sizeof(struct smb2_lock_element)` before dividing to compute `max_num`, as `cifs_reconnect()` can concurrently zero `server->maxBuf`. Callers of `smb2_push_mandatory_locks()` must hold `cinode->lock_sem`, whereas `smb2_unlock_range()` takes `cinode->lock_sem` for write internally. [F373, F493]
- In `smb2_is_valid_lease_break()` and `smb2_is_valid_oplock_break()`, locks nest as `cifs_tcp_ses_lock` -> `tcon->open_file_lock` -> `cfile->file_info_lock`: drop `cfile->file_info_lock` before `cifs_queue_oplock_break(cfile)` (under `tcon->open_file_lock`), and drop all spinlocks before `smb2_queue_pending_open_break()`. [F377]
- Callers of `smb311_update_preauth_hash()` must hold `cifs_server_lock(server)` to serialize `server->secmech.sha512` and enter `memalloc_nofs_save`. [F496]

## Object Lifetimes
- In `find_cifs_entry()`, freeing `cfile->srch_inf.ntwrk_buf_start` during a rewind requires resetting `ntwrk_buf_start`, `srch_entries_start`, and `last_entry` to `NULL`. Also, check `server->ops->query_dir_next()` and `initiate_cifs_search()` for errors before passing `cfile->srch_inf.last_entry` to `cifs_save_resume_key()`. [F344, F345]
- When transferring a reparse IOCTL response buffer out of `rsp_iov[i + 1]` in `smb2_compound_op()` (`SMB2_OP_GET_REPARSE`) or `data.reparse.io` in `smb2_query_reparse_point()`, zero the source `kvec` and set its `buftype` to `CIFS_NO_BUFFER` to prevent double-free. [F350]
- In `smb2_parse_native_symlink()`, when transferring `smb_target` directly to `linux_target` without a new allocation, set `smb_target = NULL` before `goto out` so `out` does not free `*target`. [F361]
- In `smb_set_file_info()`, a non-NULL `open_file` from `find_writable_file()` must be released via `cifsFileInfo_put(open_file)` on both the `cifs_query_path_info()` error path and `set_via_filehandle` completion, whereas when `open_file == NULL` any temporary `fid.netfid` must be closed via `CIFSSMBClose()`. [F363]
- In `mknod_nfs()`, non-symlinks point `p` at stack buffer `__u8 buf[sizeof(*p) + sizeof(__le64)]`, so `out:` must guard `kfree(p)` with `if (S_ISLNK(mode))` and `nfs_set_reparse_buf()` must never write more than `sizeof(__le64)` bytes into `p->DataBuffer` for non-symlinks. [F474]

## API Contracts
- Non-NULL `out_iov` and `out_buftype` passed to `smb2_compound_op()` must have at least `num_cmds + 2` elements and be freed via `free_rsp_buf()`/`free_rsp_iov()` before return or reuse. Because `smb2_compound_op()` unconditionally calls `cifsFileInfo_put(cfile)`, callers retrying or falling back (`smb2_rename_path`, `smb2_set_path_size`, `smb2_rename_pending_delete`, `smb2_query_path_info`) must re-fetch `cfile` first. [F349, F409]
- For `SMB2_OP_RENAME` and `SMB2_OP_HARDLINK` in `smb2_compound_op()`, callers (`smb2_set_path_attr`, `smb2_rename_pending_delete`) must pass a NUL-terminated UTF-16 buffer in `in_iov[i].iov_base` with `in_iov[i].iov_len` excluding the 2-byte NUL (`FileNameLength = len`, `size[1] = len + 2`). [F477]
- `check_smb2_hdr()` and `smb2_check_message()` return `0` on valid PDUs and positive `1` (not negative errno) on validation failure. `smb2_get_data_area_len()` must zero `*off` and `*len` on entry and whenever wire offset/length is negative, exceeds `max_off` (4096) or `max_len` (128 KiB), or `*off == 0`, returning `NULL` unless both `*off > 0` and `*len > 0`. [F382, F383]
- In `parse_reparse_wsl_symlink()`, store `utf8s_to_utf16s()` in a signed `int`, check `< 0`, and multiply by 2 (wchar count to bytes) before `cifs_strndup_from_utf16()`. `parse_reparse_point()` must return `-EOPNOTSUPP` for unhandled tags, and `cifs_reparse_point_to_fattr()` must return `false` in its default branch unless `fattr->cf_cifsattrs & ATTR_DIRECTORY` and `IS_REPARSE_TAG_NAME_SURROGATE(tag)` or `tag == IO_REPARSE_TAG_INTERNAL`. [F391, F444]
- `cifs_filldir()` returns `0` on emit/skip, `-EINVAL` on malformed entries, and `1` (`!cifs_dir_emit(...)`) when `dir_context` is full; `cifs_readdir()` must reset `rc > 0` to `0` after the loop. In `cifs_readdir()`, when `!file->private_data` and uncached, `initiate_cifs_search()` must succeed before `dir_emit_dots()`. In `emit_cached_dirents()`, set `ctx->pos = dirent->pos` before `dir_emit()` and increment after. [F395, F497, F502]
- In `smb_set_file_info()`, zero timestamps in `FILE_BASIC_INFO` mean "do not change"; when `!(tcon->ses->capabilities & CAP_NT_SMBS)` and any timestamp is zero, fetch existing timestamps via `cifs_query_path_info()` into a copy while preserving `buf->LastWriteTime` for `SMBSetInformation()`. In `cifs_get_srv_inum()`, `tcon` can be `NULL`, so check `tcon != NULL` before `tcon->ses->capabilities`. [F399, F400]
- In `smb2_unlock_range()`, skip locks with `current->tgid != li->pid` unless `flock->c.flc_flags & (FL_FLOCK | FL_OFDLCK)`. [F509]

## Error Handling
- In `cifs_ses_add_channel()`, if setup fails after adding `chan->server` to `ses->chans[]` and incrementing `ses->chan_count`, call `cifs_put_tcp_session(chan->server, 0)` and, under `ses->chan_lock`, call `cifs_chan_clear_need_reconnect(ses, chan->server)` before decrementing `ses->chan_count`. [F357]
- In `smb2_handle_cancelled_close()`, when `tcon->tc_count <= 0`, verify `tcon->ses != NULL` before reading `tcon->ses->server` and calling `cifs_server_dbg()`. [F381]
- In `smb2_compound_op()`, save `compound_send_recv()` status in `tmp_rc` before the per-command loop overwrites `rc`, and restore `rc = tmp_rc` after the loop before `is_replayable_error(rc)`. [F385]
- In `cifs_query_path_info()`, `CIFSSMBQAllEAs()` returns positive byte size on success or negative errno; map non-negative returns not equal to expected WSL EA size to `-EINVAL`, and reset negative errnos to `rc = 0`. [F398]

## External Contracts
- In `create_native_symlink()`, `nfs_set_reparse_buf()`, and `wsl_set_reparse_buf()`, set `ReparseDataLength` to total buffer length minus `sizeof(struct reparse_data_buffer)` (8 bytes), not minus the subtype struct `sizeof`. In `struct reparse_wsl_symlink_data_buffer`, `Version` is `cpu_to_le32(2)`, and `parse_reparse_wsl_symlink()` must verify `ReparseDataLength > 4` and `strnlen(buf->Target, symname_utf8_len) == symname_utf8_len`. [F421, F469]
- `cifs_strndup_to_utf16()` includes the 2-byte UTF-16 NUL in `utf16_len`, so `mknod_nfs()` must subtract 2 from `symname_utf16_len` before sizing `struct reparse_nfs_data_buffer` and copying `symname_utf16` (`NFS_SPECFILE_LNK` has no wire NUL). [F471]
- In `smb2_parse_native_symlink()`, if an absolute NT symlink does not match a known prefix or drive-letter path, fall back to `out_unhandled_target` and return `smb_target` with `\` converted to `/` rather than returning an error. [F439]
- In `cifs_get_reparse_point_buffer()` (SMB1), add `le32_to_cpu(io->DataOffset)` to `(__u8 *)&io->hdr.Protocol` (skipping the 4-byte length preamble); in `smb2_get_reparse_point_buffer()` and `reparse_buf_ptr()` (SMB2), add `le32_to_cpu(io->OutputOffset)` directly to `(u8 *)io`. [F479]
- In `struct smb2_file_full_ea_info` (`wsl_set_xattrs`, `wsl_to_fattr`, `check_wsl_eas`, `cifs_query_path_info`), `ea_name_length` excludes the NUL byte, value bytes start at `&ea_data[ea_name_length + 1]`, and `next_entry_offset` is 4-byte aligned. `check_wsl_eas()` must allow `vlen == 0` for known WSL EA names (`$LXUID`, `$LXGID`, `$LXMOD`, `$LXDEV`), and `wsl_to_fattr()` must `continue` on `ea_value_length == 0`. In `wsl_set_xattrs()`, encode `$LXDEV` as `((u64)MINOR(_dev) << 32) | MAJOR(_dev)` to match `reparse_mkdev()`. [F445, F458, F475]
- In `smb2_get_data_area_len()`, responses with non-zero `shdr->Status` and `StructureSize == SMB2_ERROR_STRUCTURE_SIZE2_LE` return `NULL` unless `shdr->Status == STATUS_MORE_PROCESSING_REQUIRED`. [F442]
- In `nxt_dir_entry()` and `cifs_fill_dirent()`, `SMB_FIND_FILE_INFO_STANDARD` (`FIND_FILE_STANDARD_INFO`) has no `NextEntryOffset` and advances by `sizeof(FIND_FILE_STANDARD_INFO) + 1 + pfData->FileNameLength`, unlike `FILE_DIRECTORY_INFO`. [F482]
- In `smb2_is_valid_oplock_break()`, only cast `buffer` to `struct smb2_lease_break *` (via `smb2_is_valid_lease_break()`) after verifying `rsp->hdr.Command == SMB2_OPLOCK_BREAK` and `le16_to_cpu(rsp->StructureSize) == 44` (vs 24-byte `smb2_oplock_break`). [F486]

## Known Pitfalls
- In `smb2_calc_size()` and `get_neg_ctxt_len()`, check variable data/context overlap with `offset + 1 < len` (and `nc_offset + 1 < non_ctxlen`), because odd `StructureSize2` values include the first variable byte. [F429]
- In `cifs_try_adding_channels()` and `cifs_chan_update_iface()`, check `list_entry_is_head(iface, &ses->iface_list, iface_head)` after `ses->iface_list` loops, reset all `weight_fulfilled = 0`, and set `iface = NULL` before retrying. [F447]
- In `smb2_parse_native_symlink()`, when matching `"GLOBALROOT\\"` before `goto globalroot`, advance `abs_path` by `sizeof("GLOBALROOT") - 1` (keeping the leading `'\\'` required at `globalroot:`). [F455]
- In `smb2_check_message()`, `smb2_is_valid_lease_break()`, `smb2_is_valid_oplock_break()`, and `cifs_is_network_name_deleted()`, traverse `smb_ses_list` on `pserver = SERVER_IS_CHAN(server) ? server->primary_server : server`. [F456]
- In `mknod_wsl()`, populate `data.wsl.eas` by copying `le32_to_cpu(cc->ctx.DataLength)` bytes from `&cc->ea`, not `xattr_iov.iov_len` from `xattr_iov.iov_base`. [F476]
- In `cifs_filldir()`, subtract `nls_nullsize(nlt)` from `cifs_from_utf16()`'s return value before setting `name.len` for `cifs_prime_dcache()` and `cifs_dir_emit()`. In `unicode_oslm_strings()`, `unicode_domain_string()`, `unicode_ssetup_strings()`, and `cifs_security_buffer_from_str()`, multiply `cifs_strtoUTF16()`'s return value by `sizeof(__le16)`, and keep `+ 2` NUL slack in `size_of_ntlmssp_blob()`. [F480, F485]
