# NETWORKING [IPv4/IPv6] — (top level)

Implements the core TCP receive/transmit/timer engines, IPv4/IPv6 TCP protocol glue, `TIME_WAIT`/`SYN_RECV` minisocks, peer TCP metrics cache, TCP/UDP GSO/GRO and UDP tunnel NIC offload, IPv4/IPv6 XFRM tunnel dispatch, TCP ULPs, congestion control (`illinois`, `nv`, `vegas`, `veno`, `westwood`, `yeah`), and `/proc/net/tcp*`, `inet_diag`, and BPF TCP iterators.

## Architecture & Data Flow
- On established sockets, advance `snd_una`/`rcv_nxt` via `tcp_snd_una_update()`/`tcp_rcv_nxt_update()` (and `twsk_rcv_nxt_update()` in `TCP_FIN_WAIT2` timewait) so byte and TCP-AO SNE counters update on wrap. `tcp_in_window()` uses wrap-safe `after(end_seq, s_win) && before(seq, e_win)`; `tcp_plb_check_rehash()` compares `pause_until` to `tcp_jiffies32` via `before()` bounded by `max_suspend`. [F79, F124, F306]
- `tcp_mark_skb_lost()` calls `tcp_verify_retransmit_hint()` before mutating `lost_out`/`retrans_out`. Changing `tcp_skb_pcount()` on an already-sent SKB (`tcp_fragment()`, `__tcp_retransmit_skb()`) requires `tcp_adjust_pcount()`. `tcp_set_skb_tso_segs()`, `tcp_gso_segment()`, and `tcp_dsack_seen()` compute segment counts with `DIV_ROUND_UP()`. [F64, F123, F246, F299]
- Queued write/rtx data SKBs require `skb_headlen(skb) == 0`. `__pskb_trim_head()` compacts frags via index `k` (`nr_frags = k`, zeroing `eat` after partial trim). Splitting in `tcp_fragment()`/`tso_fragment()` moves `TCPHDR_FIN`, `TCPHDR_PSH`, and `eor` only to `buff`. `tcp_skb_shift()` caps `to->len + shiftlen < 65535 * TCP_MIN_GSO_SIZE` and `pcount <= 65535`. [F85, F247, F261, F282]
- `tcp_write_xmit()` breaks if `end_seq == seq` and calls `tcp_event_new_data_sent()` on every sent SKB before `if (push_one) break;`. Tacking `TCPHDR_FIN` onto the last `tcp_rtx_queue` SKB in `tcp_send_fin()` must increment `tp->snd_nxt`. `__tcp_transmit_skb()` zeroes `skb->cb` over `max(sizeof(struct inet_skb_parm), sizeof(struct inet6_skb_parm))` before `queue_xmit`. [F251, F260, F285]
- When `out_of_order_queue` is non-empty, `tp->ooo_last_skb` tracks `skb_rb_last()`. `tcp_collapse()` on the OOO rbtree (`list == NULL`) queues `nskb`s on `tmp` and calls `tcp_rbtree_insert()` only at `end:`. `tcp_prune_queue()` returns `-1` before `tcp_clamp_window()` if `sk_rmem_alloc == 0`. `tcp_ooo_try_coalesce()` and `tcp_add_backlog()` saturate `gso_segs` to `0xFFFF` in `u32`. [F62, F67, F86, F100]
- Non-EOL/NOP options in `tcp_parse_options()`, `tcp_parse_mss_option()`, and `tcp_do_parse_auth_options()` require `length >= 2` and `opsize` in `[2, length]` (`ptr` is +2 past `opcode`/`opsize` in `switch`, advancing by `opsize - 2`), clamping `snd_wscale` to `TCP_MAX_WSCALE` (14) and zeroing `wscale` if `!wscale_ok`. `tcp_parse_fastopen_option()` requires `syn && !(len & 1)` and bounds `foc->val` to `[TCP_FASTOPEN_COOKIE_MIN, TCP_FASTOPEN_COOKIE_MAX]`. [F80, F82, F116, F134]
- `tcp_parse_options()` sets `sacked` only if `opsize >= TCPOLEN_SACK_BASE + TCPOLEN_SACK_PERBLOCK` and `(opsize - TCPOLEN_SACK_BASE) % TCPOLEN_SACK_PERBLOCK == 0`. `tcp_sacktag_write_queue()` clamps `num_sacks` to `min(TCP_NUM_SACKS, (ptr[1] - TCPOLEN_SACK_BASE) >> 3)` and tracks `first_sack_index`. Shifting `selective_acks` in `tcp_sack_maybe_coalesce()`/`tcp_sack_remove()` must `continue` without incrementing `this_sack` or `swalk`/`sp`. [F83, F101, F102]
- 3-element ECN byte arrays (`delivered_ecn_bytes`, `received_ecn_bytes`, `synack_ecn_bytes`) are indexed by `ecnfield - 1` (`ecnfield != INET_ECN_NOT_ECT`). `tcp_options_fit_accecn()` restores `opts->num_sack_blocks += sack_blocks_reduce` if `num_accecn_fields < required`. `tcp_rate_gen()` masks `delivered_ce` delta with `TCPCB_DELIVERED_CE_MASK`. [F84, F258, F279, F304]
- SYN/SYN-ACK windows are unscaled (`<= 65535U`); non-SYN windows align to `1 << rcv_wscale` and clamp to `65535U << rcv_wscale` (or `MAX_TCP_WINDOW`). Update `ts_recent` only after `tcp_checksum_complete()` and window checks. When `retrans_stamp == 0`, `tcp_packet_delayed()` returns `false` if `(!tcp_is_sack(tp) && !before(snd_una, high_seq))` or `TCP_SYN_SENT`. `tcp_event_ack_sent()` adds `compressed_ack` to MIB, zeroes it, and `__sock_put(sk)` if `hrtimer_try_to_cancel() == 1`; `tcp_compressed_ack_kick()` decrements it before `tcp_send_ack()`. `__tcp_oow_rate_limited()` checks `0 <= (s32)(tcp_jiffies32 - val) < sysctl_tcp_invalid_ratelimit`. [F77, F97, F126, F252, F256, F297]
- Reclaiming in `tcpm_new()` passes `fastopen_clear = true` to `tcpm_suck_dst()`. `tcp_metrics_flush_all()`/`nl_cmd_del()` advance `pp = &tm->tcpm_next` only when not unlinking. `tcp_metrics_nl_dump()` resets `s_col = 0` on `row++`; `udp_dump()` uses `continue` (no `num++`) for `!net_eq()`, `goto next` (`num++`) for filter mismatch, `goto done` on dump error, and `s_num = 0` on `slot++`. [F75, F104, F105, F290]
- `tcp_gso_segment()` clears `fin`/`psh` on non-last segments and masks `cwr &= ecn_cwr_mask` on subsequent segments. `__tcpv6_gso_segment_list_csum()`/`csum()` compare `seg->next` to `segs` and update csum before overwriting `*oldip`/`*oldport`. `__udp_gso_segment()` rejects `len <= sizeof(*uh) + mss` with `ERR_PTR(-EINVAL)` and recomputes `gso_segs` on `skb_gso_ok()`. `udp6_ufo_fragment()` checks UDP tunnel GSO before `SKB_GSO_UDP|UDP_L4`, expands head, samples `*prevhdr` before `NEXTHDR_FRAGMENT`, and decrements `mac_offset`/`mac_header`/`network_header` by `frag_hdr_sz`. `udp_gro_complete()` sets `encap_mark = 0` and `encapsulation = 1`. [F109, F241, F273, F1101, F1103, F1122, F1124]
- Congestion structs fit in `ICSK_CA_PRIV_SIZE` (`yeah` keeps `vegas` first). `tcp_illinois_acked()` clamps `rtt_us` to `RTT_MAX`, checks `cnt_rtt > 0` before dividing, and `beta()` checks `d3 <= d2`. `tcpnv_cong_avoid()` negates negative `cwnd_growth_factor` (`>= -8`) and floors right-shifts at `4U`. `tcp_cwnd_reduction()` requires `prior_cwnd != 0` and ceiling `u64` division when `delta < 0`. [F111, F117, F118, F120, F131, F266]
- `inet6_sk_rx_dst_set()` records `sk_rx_dst_ifindex` and cookie (verified by `tcp_v6_do_rcv()`/`early_demux()`). `tcp_v6_connect()` resets `ts_recent`/`ts_recent_stamp`/`write_seq` if peer `sin6_addr` changes. `tcp_v6_init_req()` sets `ir_rmt_addr`/`ir_loc_addr` to `LOOPBACK4_IPV6`. `tcp_v6_send_response()` option lengths in `tot_len` must be 4B-aligned. `udp_tunnel_nic` requires `unsigned long missed`, freezes entries during `udp_tunnel_nic_replay()`, enforces `OPEN_ONLY`/`STATIC_IANA_VXLAN`/`IPV4_ONLY`, and flushes `OPEN_ONLY` on `NETDEV_GOING_DOWN`. [F243, F315, F331, F332, F1098, F1099, F1100, F1127]

## Synchronization
- Under socket lock, `tcp_data_queue_ofo()`, `tcp_queue_rcv()`, `tcp_collapse()`, and `tcp_try_coalesce()` update `sk_rmem_alloc` atomically (`skb_set_owner_r()`/`atomic_add()`). Hashed `TCP_TIME_WAIT` sockets lack a lock, so `tw_substate`, `tw_rcv_nxt`, `tw_ts_recent`, `tw_ts_recent_stamp`, and `tw_entry_stamp` use `READ_ONCE()`/`WRITE_ONCE()`. [F17, F40]
- Under `bh_lock_sock(sk)`, if `sock_owned_by_user(sk)` is true, timers/TSQ and `tcp_v4`/`v6_err()` (`mtu_reduced`, `redirect`, `tcp_done_with_error()`, `sk_error_report()`, `tcp_ld_RTO_revert()`) must not mutate state, instead setting `*_DEFERRED` in `sk_tsq_flags` via `test_and_set_bit()` with `sock_hold(sk)` on transition. [F27, F214, F1055, F1073]
- Order `WRITE_ONCE(tp->copied_seq, tp->rcv_nxt)` with `smp_mb()` before `TCP_ESTABLISHED`, and `WRITE_ONCE(sk->sk_err, err)` with `smp_wmb()` before `tcp_done(sk)`. Wrap `conn_request()` in `rcu_read_lock()` + `local_bh_disable()`. After `set_bit(TSQ_THROTTLED)` in `tcp_small_queue_check()`/`skb_still_in_host_queue()`, run `smp_mb__after_atomic()` and re-test. `tcp_wfree()` defers TX to `system_bh_wq`, uses `local_irq_save()`/`restore()` on `tsq_work.head` (with `tcp_tsq_workfn()`), and keeps 1 ref on `sk_wmem_alloc` until `sk_free(sk)`. [F20, F21, F31, F215, F216, F351]
- `tcp_v4_send_reset()`/`send_ack()` lock `ipv4_tcp_sk.bh_lock` under `local_bh_disable()` and restore `&init_net`/XFRM policy. Hold `rcu_read_lock()` across key lookup + `tcp_v6_send_response()` in `tcp_v6_send_reset()`, and `np->opt` + `ip6_xmit()` in `tcp_v6_send_synack()`. `tp->md5sig_info` reads need RCU or socket lock; writes need socket lock + `kfree_rcu()`. `tm->tcpm_fastopen` uses `fastopen_seqlock`, and `tcp_metrics.c` uses `dst_dev_net_rcu(dst)`. [F25, F26, F29, F139, F1078, F1150]
- Order `tp->tcp_clean_acked` before `clean_acked_data_enabled++` and after `--`. `__tcp_ulp_find_autoload()` drops RCU before `request_module()` and calls `try_module_get()` under RCU; `tcp_set_ulp()` requires `sock_owned_by_me(sk)` (not `tcp_cleanup_ulp()`). `inet_ehash_lockp()` uses `spin_lock_bh()` while `lhash2` uses `spin_lock()`; `bpf_iter_tcp_resume_*()` unlocks `st->bucket` if `resume_bucket()` returns `NULL`. [F38, F106, F149, F204, F339]
- Hold `udp_tunnel_gro_lock` in `udp_tunnel_update_gro_lookup()`. Under `udp_tunnel_gro_type_lock`, update `udp_tunnel_gro_rcv` before enabling `udp_tunnel_static_call` and disable before resetting to `dummy_gro_rcv` (compacting array and aborting if `> UDP_MAX_TUNNEL_TYPES`). Hold `rcu_read_lock()` across `skb_udp_tunnel_segment()`. Hold `utn->lock` for sync `__udp_tunnel_nic_device_sync()` in `__udp_tunnel_nic_reset_ntf()`. Hold `tunnel4`/`6_mutex` and call `synchronize_net()` on xfrm tunnel deregister (ascending `priority`, `-EEXIST` in IPv6). [F205, F212, F213, F271, F333, F349, F1120]

## Object Lifetimes
- Release lookup/iterator sockets via `sock_gen_put()` (or state-specific put in `tcp_v6_err()`), never `sock_put()`. `tcp_timewait_state_process()` consumes `tw` only on `TCP_TW_SUCCESS`. Initialize all `tw` fields before `inet_twsk_hashdance_schedule()` and never touch `tw` after. [F1, F5, F18, F1054]
- `tcp_create_openreq_child()` returns `newsk` BH-locked (`sk_refcnt == 2`) and zeroes listener pointers/lists; aborting before hash requires `inet_csk_prepare_forced_close(newsk)` before `tcp_done()`. In `tcp_v4`/`v6_syn_recv_sock()`, clear `ireq_opt` (or `consume_skb(pktopts)` and clear) if `*own_req`, or clear `newinet->inet_opt` otherwise; if `*own_req == false`, unlock/put `newsk` only when `!req_unhash && found_dup_sk`; release `dst` before `ip6_dst_store()`, not after. `tcp_make_synack()` always consumes `dst`. `inet6_sk_rx_dst_set()` uses `dst_hold_safe()`. Pairing `sock_hold()`/`__sock_put()` with `compressed_ack_timer` and `pacing_timer` checks `!hrtimer_is_queued()` and `hrtimer_try_to_cancel() == 1`. [F3, F4, F15, F73, F217, F222, F1057, F1060, F1061, F1148]
- Before freeing `tcp_rtx_queue` SKBs (`tcp_rtx_queue_unlink_and_free()`, `tcp_collapse_retrans()`), update `retransmit_skb_hint`, `highest_sack`, and `tcp_adjust_pcount()`. Use `*_from_safe` in `tcp_mtu_probe()`/`tcp_retrans_try_collapse()`, set `skb = tmp; continue;` in `tcp_sacktag_walk()`, guard post-loop `skb` in `tcp_clean_rtx_queue()`, and call `tcp_skb_tsorted_anchor_cleanup()` on aborted `tcp_stream_alloc_skb()` SKBs. Break after `tcp_fin()` in `tcp_ofo_queue()`, pass `in_skb` to `tcp_can_ingest()` in `tcp_prune_ofo_queue()`, and reload `th`/`iph`/`hdr` after pull/csum/filter in `tcp_v4`/`v6_rcv()` (`th->doff >= 5`). [F66, F68, F69, F94, F98, F99, F249, F250, F283, F1112]
- Move `tcp_wfree`/`sock_wfree` and adjust `sk_wmem_alloc` in `tcp_gso_segment()`/`__udp_gso_segment()`. Charge only base `buff->truesize` in `tcp_fragment()`/`tso_fragment()`, and validate frags before `skb_frag_ref()` in `tcp_clone_payload()`. Call `tcp_release_user_frags()` before `xa_destroy()`, balance `ulp_ops->owner` module refs, free `tcp_metrics_block` via `kfree_rcu()`, free `traffic_key` iff `allocated_traffic_key`, `synchronize_rcu()` in `udp_tunnel_sock_release()`, `kfree_skb(rep)` only before `nlmsg_unicast()` in `udp_dump_one()`, and order `udp_tunnel_nic` init/register before locking. [F39, F141, F174, F183, F184, F189, F192, F197, F200, F326, F327, F1058]

## API Contracts
- Return conventions: `tcp_rcv_synsent_state_process()` (`-1` established, `0` consumed, `> 0` drop reason); `tcp_check_req()` (`NULL` handled, `sk` RST, `nsk != sk` child); `tcp_mtu_probe()` (`0` wait, `1` sent, `-1` disabled/failed); `tcp_gso_segment()` (`ERR_PTR` error, `NULL` `skb_gso_ok()`); `udp_tunnel_dst_lookup()`/`ip6_dst_lookup_flow()` (`ERR_PTR`) vs `inet6_csk_route_req()`/`tcp_v6_route_req()` (`NULL`); `tunnel*_rcv()` handlers (`0` consumed, non-zero unfreed; `cb_handler <= 0` stop; `synchronize_net()` on `xfrm6_tunnel_deregister()`). [F43, F44, F46, F219, F232, F268, F373, F1066, F1081, F1090, F1165]
- Pre-init `opt_rx` and `foc->len = -1` for `tcp_parse_options()`; `tcp_parse_auth_options()` subtracts 2 from `*ao_hash` and must succeed before reading IPv6 auth options. Guard `skb == NULL` in `tcp_established_options()` and `tp == NULL` in `tcp_options_write()`/`process_tcp_ao_options()`. Require `mss >= 1` in `tcp_select_initial_window()`, and right-shift `win` by `rcv_wscale` for `tcp_v6_send_ack()`. Call `tcp_v6_fill_cb()` after `xfrm6_policy_check()` (use `inet6_iif`/`sdif` before), delegate `ETH_P_IP` to IPv4 (with `tcp_sync_mss()`), and pass `ntohs(hnum)` to IPv6 lookups. [F58, F59, F224, F225, F226, F1087, F1110, F1128, F1153, F1155, F1158]
- Bound MD5 `addr` by family size, query keys on `sk` and addr/dev on `addr_sk` in `tcp_v6_md5_lookup()`, map v4-mapped sin6 to `AF_INET` (`l3flag ? l3index : -1` for AO), and call `sk_gso_disable()`. Set `skb_set_network_header()` before `skb_gro_receive_list()` when `is_flist`, and check `SKBTX_ANY_TSTAMP` in TCP GSO. Guard `sk_fullsock()` in `bpf_iter_tcp_seq_show()`, read child ehash from `current->nsproxy->net_ns`, require `.clone` on `TCP_LISTEN` ULPs, balance `udp_tunnel_update_gro_rcv()` (`UDP_MAX_TUNNEL_TYPES`), validate `udp_tunnel_nic_register()`/`get_port()`/`ilog2()`, ignore `rtt_us < 0` (+1 in Vegas/Veno, `jiffies_to_usecs()` in Westwood), and scale `retrans_stamp` by `USEC_PER_MSEC` when `tcp_usec_ts`. [F129, F160, F161, F168, F173, F176, F233, F234, F236, F237, F238, F307, F357, F358, F361, F1086, F1119]

## Error Handling
- Negate `< 0` `tcp_ack()` drop reasons; check signed `< 0` from `tcp_match_skb_to_sack()` and `ip6_find_1stfragopt()`; replace `TCP_METRICS_RECLAIM_PTR` with `NULL`; distinguish `< 0` vs `> 0` in `parse_nl_addr()` and `__tcp_transmit_skb()`; propagate only `-ECONNREFUSED` in `tcp_connect()`; undo `rx_opt` in `tcp_rcv_synsent_state_process()`. Use `__GFP_ZERO` for MD5 keys, zero `md5_hash` on IPv6 error, zero-init `struct tcp_key`, use `net_info_ratelimited()`, zero `bpf_sock_ops_kern` (`if (skb)`), call `skb_gso_error_unwind()`, and set `flush = 1` on GRO error. [F42, F45, F47, F49, F56, F57, F78, F198, F218, F223, F1080, F1088, F1089, F1091, F1166]

## External Contracts
- Test `ext & (1 << (INET_DIAG_VEGASINFO - 1))`; scale `tcpm_vals` RTT by `USEC_PER_MSEC` and emit `i + 1` attributes; pad `/proc/net/tcp` to `TMPSZ - 1` with `%pK`; validate MD5 `optlen`, `TCP_MD5SIG_MAXKEYLEN`, `TCP_MD5SIG_EXT` flags, `netif_is_l3_master()`, and `tcp_ao_required()`; check `SIN6_LEN_RFC2133` and `sizeof(struct sockaddr_in6)` in IPv6 connect. [F60, F90, F138, F170, F172, F267, F1106, F1108, F1156, F1160]

## Known Pitfalls
- Guard fullsock helpers against `TCP_TIME_WAIT`/`TCP_NEW_SYN_RECV` (`is_fullsock = 0` for `req`), handle `fastopen_rsk` in ICMP/RTO, use `get_unaligned_be*()`, advance `__be32 *ptr` by 4B words, and `memmove` `IPCB(skb)`. Order `tcp_sacktag_one()` before `seq += shifted`, keep `dsack_high` invariant, `goto start` after stripping `SYN` and update queued SKB on retransmit, keep `icsk_pending` for `REO_TIMEOUT`/`LOSS_PROBE`, widen to `u64` / bound shifts and divisors in congestion/window/RTT math, use `<` for AO SNE wrap, `s32` for `ts_recent - rcv_tsval`, `between()` in `tcp_v6_err()`, clamped `long` for `/proc/net/tcp6`, `offs >= maxlen` in `tcp_get_available_ulp()`, `dst_xfrm() || skb_sec_path()`, and `list_entry_is_head()` + `sizeof(**utn->entries)`.
