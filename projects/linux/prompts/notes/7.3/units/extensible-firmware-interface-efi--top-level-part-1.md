# EXTENSIBLE FIRMWARE INTERFACE (EFI) — (top level) (part 1)

This component implements architecture-specific EFI initialization and virtual memory mapping (ARM, ARM64, LoongArch, RISC-V, x86), core EFI infrastructure (`drivers/firmware/efi/efi.c`), UEFI Capsule updates, CPER parsing, ESRT sysfs, early EFI framebuffer, BGRT, Apple device properties, and embedded firmware extraction.

## Architecture & Data Flow

- On x86_64, `arch_efi_call_virt_setup()` must call `efi_sync_low_kernel_mappings()`, `efi_fpu_begin()`, `firmware_restrict_branch_speculation_start()`, and `efi_enter_mm()`; `arch_efi_call_virt_teardown()` reverses this exact sequence. `efi_sync_low_kernel_mappings()` (also required before `efi_thunk_set_virtual_address_map()`) must skip `[EFI_VA_END, EFI_VA_START)` so EFI runtime PUDs are not overwritten. [F60, F144]
- On x86_64, `efi_map_region()` and `efi_map_region_fixed()` map each region in `efi_mm.pgd` at both `md->phys_addr` (1:1) and `md->virt_addr`, so `efi_update_mappings()` and `efi_unmap_pages()` must update/unmap both in lockstep. `efi_map_next_entry()` must iterate `efi.memmap` in reverse via `efi_map_next_entry_reverse()` because `efi_map_region()` allocates top-down from `EFI_VA_START` while `EFI_PROPERTIES_TABLE` requires ascending virtual addresses. [F59, F84]
- In `should_map_region()` (x86), `EFI_MEMORY_RUNTIME` (`true`) must precede all exclusions, and `EFI_CONVENTIONAL_MEMORY` with `EFI_MEMORY_SP` (`false`) must precede `efi_is_mixed()`. In `efi_merge_regions()`, when merging `md` into `prev_md`, set `md->type = EFI_RESERVED_TYPE` and `md->attribute = 0`, and `continue` without updating `prev_md = md`. [F93, F94]
- In `arch/x86/platform/efi/quirks.c`: `efi_reuse_config()` must set `EFI_MEMORY_ATTRIBUTES_TABLE_GUID`'s `table` to `EFI_INVALID_TABLE_ADDR` on kexec boots; `efi_arch_mem_reserve()` must update and sort `e820_table` (`E820_TYPE_RAM` to `E820_TYPE_RESERVED` via `e820__range_update()`/`e820__update_table()`) when installing a reserved `EFI_MEMORY_RUNTIME` descriptor; and both loops in `efi_free_boot_services()` must use the identical non-`EFI_MEMORY_RUNTIME` filter even when sub-1M pages are not freed. [F52, F62, F96]
- In `create_mapping_protection()` (arm64) and `efimem_to_pgprot_map()` (riscv), check `(attr & (EFI_MEMORY_XP | EFI_MEMORY_RO)) == (EFI_MEMORY_XP | EFI_MEMORY_RO)` before `attr & EFI_MEMORY_RO`. On arm64, `code_is_misaligned` in `create_mapping_protection()` must stay a `static` bool latched via `|=` so once a misaligned `EFI_RUNTIME_SERVICES_CODE` region is seen, later misaligned runtime regions use `PAGE_KERNEL_EXEC`. [F91, F92]
- On 32-bit ARM, `efi_create_mapping()` must test `md->attribute` in an `if`/`else if` chain ordered `EFI_MEMORY_WB`, `EFI_MEMORY_WT`, `EFI_MEMORY_WC`, then `MT_DEVICE`; under `CONFIG_CPU_TTBR0_PAN`, `arch_efi_call_virt()` must bracket calls with `uaccess_save_and_enable()` and `uaccess_restore(flags)`. [F90, F142]
- When iterating or copying within an EFI memory map buffer (`efi.memmap` or `struct efi_memory_map`), stride and size by `desc_size` (`efi.memmap.desc_size`); when copying one entry into a standalone `efi_memory_desc_t` (`out_md` in `__efi_mem_desc_lookup()`, `entry->md` in `add_sysfs_runtime_map_entry()`), bound `memcpy()` to `sizeof(efi_memory_desc_t)`. [F115, F116]
- `__efi_mem_desc_lookup()` must reject `md->num_pages <= 0` or `md->num_pages > (U64_MAX - md->phys_addr) >> EFI_PAGE_SHIFT` before shifting. `efi_memmap_entry_valid()` must reject `md->num_pages == 0`, `md->num_pages > EFI_PAGES_MAX`, or `EFI_PAGES_MAX - md->num_pages < (md->phys_addr >> EFI_PAGE_SHIFT)`. [F106, F107]
- `efi_memmap_insert()` requires `EFI_PAGE_SIZE`-aligned `mem->range.start` and `mem->range.end + 1`, `buf` sized for `old_memmap->nr_map + efi_memmap_split_count(&md, &mem->range)` entries of `old_memmap->desc_size`, and mutually exclusive conditions across its four unchained `if` blocks matching `efi_memmap_split_count()`. [F85, F97]
- In `efi_capsule_update()`, use `DIV_ROUND_UP(imagesize, PAGE_SIZE)` and `sg_pages_num(count)` (`DIV_ROUND_UP(count, SGLIST_PER_PAGE)`), clamping block lengths to `PAGE_SIZE - (u64)*pages % PAGE_SIZE`. In `capsule-loader.c`, `cap_info->pages` and `cap_info->phys` must be allocated in `efi_capsule_open()`, resized in `__efi_capsule_setup_info()`, and populated at `cap_info->index` in `efi_capsule_write()` in lockstep before incrementing `cap_info->index`. [F55, F112]
- In x86 mixed-mode variable thunks (`efi_thunk_get_variable()`), `virt_to_phys_or_null_size()` rejects non-linear (`!virt_addr_valid()`) buffers crossing a page boundary, and `vendor` must be copied to `PTR_ALIGN((efi_guid_t *)buf, sizeof(*vnd))` on the stack before checking `!phys_name || (data && !phys_data)`. [F88]
- `efi_esrt_init()` must verify `tmpesrt.fw_resource_count <= 128` and `sizeof(*esrt) + tmpesrt.fw_resource_count * sizeof(struct efi_system_resource_entry_v1) <= efi_mem_desc_end(&md) - efi.esrt`. In `cper_print_fw_err()`, trailing data offset in `struct cper_sec_fw_err_rec_ref` must branch on `fw_err->revision` (`record_identifier_guid` for rev 0, `record_identifier` for rev 1, `sizeof(*fw_err)` for rev >= 2). [F77, F81]
- In `unmarshal_key_value_pairs()` (`apple-properties.c`), `struct dev_header`'s `key_len` and `val_len` include their 4-byte length prefix, so check `key_len >= sizeof(key_len) + sizeof(efi_char16_t)` and `val_len >= sizeof(val_len)` and subtract `sizeof(u32)`. In `efi_get_fdt_params()`, `SYSTAB` must stay at `target[0]` because `j == 0` jumps to `notfound` silently while `j > 0` logs `pr_err()`. [F71, F105]

## Synchronization

- On arm64, `arch_efi_call_virt_setup()` calls `efi_virtmap_load()` (disabling preemption), locks `efi_rt_lock`, and calls `__efi_fpsimd_begin()`; `arch_efi_call_virt_teardown()` must unwind in reverse (`__efi_fpsimd_end()`, `raw_spin_unlock(&efi_rt_lock)`, `efi_virtmap_unload()`). [F17]
- On x86_64 mixed mode, `efi_thunk()` calls must hold `efi_runtime_lock` with IRQs disabled, while `efi_thunk_set_variable_nonblocking()` and `efi_thunk_query_variable_info_nonblocking()` must use `spin_trylock_irqsave()` and return `EFI_NOT_READY` on contention. When `nonblocking` is true, `efi_query_variable_store()` must call `query_variable_store_nonblocking()` and never allocate with `GFP_KERNEL` or call blocking `efi.set_variable()`. [F29, F33]
- In `capsule.c`, `efi_capsule_update()` must populate `sg_pages`, call `efi_capsule_flush_cache_range()` on ARM/ARM64, and unmap `sglist` before locking `capsule_mutex` and calling `efi_capsule_update_locked()`. `efi_capsule_update_locked()` and `capsule_reboot_notify()` must hold `capsule_mutex` when accessing `stop_capsules`, `efi_reset_type`, or `capsule_pending`. Runtime callers must not call lockless `efi_capsule_pending()` before `efi_capsule_update()`. [F24, F25, F150]
- In `efi_mem_reserve_persistent()` and `efi_mem_reserve_iomem()`, use `GFP_ATOMIC`, claim slots with `atomic_fetch_add_unless(&rsv->count, 1, rsv->size)`, and hold `efi_mem_reserve_persistent_lock` when linking into `efi_memreserve_root->next`. In `embedded-firmware.c`, `efi_check_for_embedded_firmwares()` must finish populating `efi_embedded_fw_list` before setting `efi_embedded_fw_checked = true`, which `efi_get_embedded_fw()` must check before iterating. [F32, F153]

## Object Lifetimes

- When `efi_capsule_update()` returns 0, callers must not free `pages` or `sg_pages[i]`; `efi_capsule_update()` only frees `sg_pages[i]` on error (always freeing the `sg_pages` array). In `capsule-loader.c`, set `cap_info->index = NO_FURTHER_WRITE_ACTION` (`-1`) both when `efi_free_all_buff_pages()` frees pages on error and when `efi_capsule_submit_update()` succeeds, so `efi_capsule_release()` does not free submitted pages. [F1, F56]
- `efi_memmap_install()` must only call `__efi_memmap_free(phys, size, flags)` after `efi_memmap_unmap()` and a successful `__efi_memmap_init(data)`; `__efi_memmap_init()` itself must never free the old physical map. In `arch/x86/platform/efi/efi.c`, `realloc_pages(old_memmap, old_shift)` always frees `old_memmap` even on allocation failure, so callers must not double-free it. [F5, F15]
- In `efi_get_device_by_path()`, node parsers (`parse_acpi_path()`, `parse_pci_path()`, `parse_end_path()`) return a refcounted `struct device` in `*child` and `efi_get_device_by_path()` calls `put_device(parent)` each step. In `parse_acpi_path()`, if `acpi_get_first_physical_node(adev)` returns `phys_dev`, call `get_device(phys_dev)` and `acpi_dev_put(adev)`; if `NULL`, transfer `adev`'s ref to `*child = &adev->dev`. Callers jumping to `put_device(dev)` on `IS_ERR(dev)` (e.g., `unmarshal_devices()`) must set `dev = NULL`. [F7, F41, F132]
- Error cleanup must unwind in reverse order: in `esrt_sysfs_init()`, call `cleanup_entry_list()` (using `list_for_each_entry_safe()` as `kobject_put()` triggers `esre_release()`), `kset_unregister(esrt_kset)`, `sysfs_remove_group()`, `kobject_put(esrt_kobj)`, and `memunmap(esrt)` with `esrt = NULL`; in `efisubsys_init()`, call `sysfs_remove_group()`, `generic_ops_unregister()`, `kobject_put(efi_kobj)` with `efi_kobj = NULL`, and `destroy_workqueue(efi_rts_wq)`. [F10, F11, F99]
- In `efivar_ssdt_load()`, `acpi_load_table(data, NULL)` takes ownership of `data` on success, so only `kfree(data)` on failure. In `efi_query_variable_store()`, if the dummy `efi.set_variable()` call returns `EFI_SUCCESS`, call `efi_delete_dummy_variable()` before `kfree(dummy)`. `efi_get_embedded_fw()` returns a borrowed pointer in `*data`, so callers must copy it and never `kfree(*data)`. [F4, F14, F21]
- On x86, `__efi_enter_virtual_mode()` must call `efi_check_for_embedded_firmwares()` before `efi_free_boot_services()`. In `efi_alloc_page_tables()` (x86_64), allocate `efi_pgd` with `__get_free_pages()` (not `pgd_alloc()`), and on `pud_alloc()` failure free the 5-level p4d page before `efi_pgd`. In `efi_init()` (`efi-init.c`), call `early_init_dt_check_for_usable_mem_range()` after `reserve_regions()`, and call `efi_memmap_unmap()` if `uefi_init()` fails beforehand. [F13, F18, F22]

## API Contracts

- On x86_64, invoke all runtime services (including `set_virtual_address_map`) via `arch_efi_call_virt()`, not raw `efi_call()`, to save/disable and restore IBT (`ibt_save(efi_disable_ibt_for_runtime)` / `ibt_restore(ibt)`). On arm64, `efi_runtime_fixup_exception()` requires `current_in_efi()` (`!preemptible()`, `efi_rt_stack_top` on `current`'s stack) and `regs->pc < TASK_SIZE_64`, restoring `x30` from `efi_rt_stack_top[-1]` and `x18` from `efi_rt_stack_top[-2]` (`CONFIG_SHADOW_CALL_STACK`). [F140, F143]
- `efi_set_mapping_permissions()` (arm, arm64, riscv) must only call `apply_to_page_range()` on `efi_mm` regions using page-level PTEs (skipping section mappings on ARM32 and `region_is_misaligned(md)` regions on ARM64). [F151]
- `cper_estatus_check()`, `cper_estatus_check_header()`, and `cper_estatus_print()` (`cper*.c`) run in NMI/hardirq/panic contexts and must not sleep or allocate with `GFP_KERNEL`. `cper_estatus_check()` must verify `raw_data_offset >= sizeof(*estatus) + estatus->data_length` (if `raw_data_length != 0`) and that `acpi_hest_get_size(gdata)` and `acpi_hest_get_record_size(gdata)` fit within `data_len` and `data_len` reaches `0`. [F78, F154]
- Capsule quirks in `arch/x86/platform/efi/quirks.c` (`qrk_capsule_setup_info()`) must return `> 0` to proceed, `0` when `hdr_bytes` is incomplete, and `< 0` on error. `efi_capsule_submit_update()` must only `vmap()`/`vunmap()` `cap_info->capsule` when it is `NULL`, because quirks point `cap_info->capsule` at `&cap_info->header`. [F43, F57]
- Parsers in `dev-path-parser.c` must check `node->header.length` against the exact struct size, and only `parse_end_path()` may return `> 0`. Callers of `efi_get_device_by_path()` (`map_properties()`) must run at `fs_initcall` or later. [F73, F133]
- Drivers retaining `EFI_BOOT_SERVICES_DATA` tables across boot (`efi_esrt_init()`, `efi_bgrt_init()`) must call `efi_mem_reserve()`; on x86, the range must lie within one `EFI_BOOT_SERVICES_DATA` descriptor. `efi_mem_reserve_persistent()` must size new `linux_efi_memreserve` entries with `EFI_MEMRESERVE_COUNT(SZ_4K)` and reserve `SZ_4K` (never `PAGE_SIZE`). [F131, F167]
- Gate variable writers (`generic_ops.set_variable` in `generic_ops_register()`, `efibc_init()`) on `efi_rt_services_supported(EFI_RT_SUPPORTED_SET_VARIABLE)`. `efi_query_variable_store()` and `query_variable_store_nonblocking()` must return `efi_status_t`, never negative errno. Terminate `efi_config_table_type_t` arrays with `{}` (`NULL_GUID`). `__setup()` handlers return `1` on success; `early_param()` handlers return `0`. [F38, F40, F83, F127]

## Error Handling

- In `drivers/firmware/efi/efi.c`, check optional `struct efi` physical table addresses (`acpi`, `smbios`, `esrt`, `tpm_log`, `mokvar_table`, `coco_secret`, `unaccepted`) against `EFI_INVALID_TABLE_ADDR` (`~0UL`), not `0`. Check optional runtime pointers (`efi.get_next_variable` in `generic_ops_supported()`, `generic_ops.get_variable` in `generic_ops_unregister()`) for non-NULL before calling/unregistering. In `efi_mem_reserve_persistent()`, check `efi_memreserve_root` against both `(void *)ULONG_MAX` and `NULL`, and check `memremap()` returns for `NULL`. [F34, F35, F37]

## External Contracts

- In x86 mixed mode (`CONFIG_EFI_MIXED`), zero upper 32 bits of output pointers with `efi64_zero_upper()`, split 64-bit values with `__efi64_split()`, widen returns with `__efi64_widen_efi_status()`, and name every `__efi64_argmap_<func>` macro in `arch/x86/include/asm/efi.h` to match the exact `mixed_mode` method name passed to `efi_fn_call()`. [F53, F87]
- Do not add fields to `systab_show()`, and keep `SMBIOS3=` before `SMBIOS=`. Sysfs attributes in `runtime-map.c`, `esrt.c`, and `efi_attr_systab` must use mode `0400` (`__ATTR_RO_MODE(..., 0400)`). [F165, F166]

## Known Pitfalls

- In `set_permissions()` (riscv, arm64, arm), accumulate `EFI_MEMORY_RO` and `EFI_MEMORY_XP` changes into local `pte`/`val` before writing `*ptep`, never re-reading `ptep_get(ptep)`. In `reserve_regions()` (`efi-init.c`), decrement `r--` after `memblock_remove(r->base, r->size)` inside `for_each_mem_region(r)`. [F54, F98]
- Shift `efi_memory_desc_t.num_pages` by `EFI_PAGE_SHIFT` (12), not `PAGE_SHIFT`, when converting to bytes without `memrange_efi_to_native()`. Cast `efi_memmap_hi`, `efi_systab_hi`, and `ext_lfb_base` to `u64` before `<< 32`. [F108, F111]
- On x86, `efi_config_init()` and `efi_config_parse_tables()` must use `efi_config_table_64_t` or `efi_config_table_32_t` based on `efi_enabled(EFI_64BIT)`, never `efi_config_table_t`. `efi_get_fdt_prop()` must branch on `size == 8` (`*(u64 *)var` vs `*(u32 *)var`). [F124, F125]
- In `cper_print_proc_arm()` and `cper_print_proc_ia()`, advance `ctx_info` by `ALIGN(sizeof(*ctx_info) + reg_size, 16)` bytes, not `ctx_info++`. In `cper.c`, format `gdata->fru_text` with `%.20s`, and accumulate offsets in `cper_mem_err_location()` and `cper_print_bits()` with `scnprintf()`, not `snprintf()`. [F122, F123]
