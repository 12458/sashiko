# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers) — drivers/ata (part 2)

Core libata library (`libata-core.c`), Error Handler (`libata-eh.c`), SATA link/PHY/NCQ helpers (`libata-sata.c`), Port Multiplier (`libata-pmp.c`), and PATA timings (`libata-pata-timings.c`).

## Architecture & Data Flow

- `ata_qc_issue()` sets `ATA_QCFLAG_ACTIVE`, `ap->qc_active`, `ap->nr_active_links`, and `link->sactive`/`active_tag` at entry; every later error path must call `ata_qc_complete()` (or `ata_link_abort()`) so `__ata_qc_complete()` reverses state and unmaps DMA. `ap->nr_active_links` changes per command for non-NCQ, but for NCQ only when `link->sactive` transitions between 0 and non-zero. [F195, F235]
- `ata_exec_internal()` uses `qc->tag = ATA_TAG_INTERNAL` (bit 32 in `ap->qc_active`) with `qc->hw_tag = 0`; `ata_qc_get_active()` shifts bit 32 to bit 0 and `ata_qc_complete_multiple()` shifts bit 0 back to `1ULL << ATA_TAG_INTERNAL`. [F264]
- In `ata_qc_complete()`, scheduling EH via `ata_qc_schedule_eh()` when `!(qc->flags & ATA_QCFLAG_EH)` requires both `ATA_QCFLAG_HAS_CDL` and `qc->result_tf.status & ATA_SENSE`, setting `SCMD_FORCE_EH_SUCCESS`, `ATA_QCFLAG_EH_SUCCESS_CMD`, `ATA_EH_GET_SUCCESS_SENSE`, and `ATA_PFLAG_EH_PENDING`; EH must call `ata_eh_decide_disposition()` after fetching sense. [F277, F366]
- `ata_eh_analyze_ncq_error()` must clear `ATA_ERR` in `qc->result_tf.status`, zero `qc->result_tf.error`, and set `ATA_QCFLAG_RETRY` on all non-offending non-successful EH QCs on that physical link, and clear `AC_ERR_DEV` from `ehc->i.err_mask`. In `ata_eh_autopsy()`, run `ata_eh_link_autopsy()` on `EDGE` links and `ap->slave_link` before `&ap->link` when `sata_pmp_attached(ap)`. [F241, F292]
- `ata_eh_reset()` must set `link->lpm_policy = ATA_LPM_UNKNOWN` on success so `ata_eh_recover()` re-applies `ap->target_lpm_policy`, and pass `clear_classes = false` to `ata_do_reset()` when hardresetting `ap->slave_link` after master. Helpers returning `-EAGAIN` to `ata_eh_recover()` (`ata_do_link_spd_quirk()`) must mutate state because `ata_eh_handle_dev_fail()` does not decrement `ehc->tries` on `-EAGAIN`. [F250, F286, F291]
- In `ata_eh_revalidate_and_attach()`, iterate `ALL_REVERSE` for revalidation/IDENTIFY before host cable detection, and `ALL` for `ata_dev_configure()`. `ata_dev_reread_id()` and `sata_pmp_revalidate()` must read into `dev->sector_buf` and verify `ata_dev_same_device()` / `sata_pmp_same_pmp()` before overwriting `dev->id` / `dev->gscr`. [F253, F284]
- In `ata_dev_read_id()`, every `goto retry` path must disarm its trigger (`may_fallback = 0`, `tried_spinup = 1`, `flags &= ~ATA_READID_POSTRESET`) and clear `may_fallback = 0` once `read_id` succeeds. In `ata_read_log_page()`, DMA retry must set `ATA_QUIRK_NO_DMA_LOG` and check `!ata_port_is_frozen(ap)`. [F285, F287]
- `ata_dev_configure()` must call `ata_clear_log_directory(dev)` to invalidate cached `dev->gp_log_dir` before querying logs, and `ata_read_log_directory()` must clear `gp_log_dir` on error. `ata_dev_config_cpr()` must set `cpr_log->nr_cpr = nr_cpr` before indexing `cpr_log->cpr[]` (`__counted_by(nr_cpr)`). [F244, F306]
- `ata_dev_init()` clears only `ATA_DFLAG_INIT_MASK` (under `ap->lock`) and `ata_dev_configure()` only `ATA_DFLAG_CFG_MASK` on `dev->flags`. Every enabled `ATA_DEV_*` enum must have `*_UNSUP` at `class + 1` for `dev->class++` in `ata_eh_dev_disable()`. Every `enum ata_quirks` bit (`< __ATA_QUIRK_MAX <= 32`) needs a matching `ATA_QUIRK_*` and `ata_quirk_names[]` entry; `ata_dev_print_quirks()` gates on `ata_dev_print_info(dev)` and `ATA_EHI_DID_PRINT_QUIRKS`; ATI quirks must check `ata_dev_check_adapter(dev, PCI_VENDOR_ID_ATI)`. [F249, F251, F256, F257, F329]
- Non-host, non-slave links must live in `ap->pmp_link[0 .. ap->nr_pmp_links - 1]` for `ata_link_next()`. `sata_pmp_init_links()` allocates/adds all `SATA_PMP_MAX_PORTS` links. `sata_pmp_configure()` rejects `nr_ports <= 0 || nr_ports > SATA_PMP_MAX_PORTS`, and `SATA_PMP_MAX_PORTS`-sized arrays may only be indexed by `link->pmp` on `EDGE` links (host link has `pmp == 15`). [F267, F309, F314]
- On `ATA_PFLAG_RESUMING` in `ata_scsi_port_error_handler()`, set `ATA_DFLAG_RESUMING` on enabled devices (with `ATA_EH_SET_ACTIVE`) and clear it if `ata_eh_revalidate_and_attach()` fails. `ata_port_suspend()` passes `ATA_EHI_QUIET | ATA_EHI_NO_AUTOPSY | ATA_EHI_NO_RECOVERY` (`action = 0`). `ata_eh_handle_port_suspend()` skips `ata_dev_power_set_standby()` on `PM_EVENT_FREEZE`, and otherwise spins down devices and runs `zpodd_on_suspend()` before `ata_eh_freeze_port()` and `port_suspend()`. [F243, F337, F338]
- `ata_dev_power_set_standby()` checks `!(dev->flags & ATA_DFLAG_SLEEPING)` and `ata_dev_power_is_active(dev)` before `ATA_CMD_STANDBYNOW1`; `ata_dev_power_set_active()` skips `ATA_CMD_VERIFY` if already active. `ata_port_runtime_idle()` returns `-EBUSY` if any enabled ATAPI device has `!zpodd_dev_enabled(adev)`. [F252, F339]
- `sata_link_debounce()` must keep polling when `cur == last && cur == 1` until `deadline` expires before checking `duration`. `ata_wait_register()` must do the first `ioread32(reg)` before computing `deadline`. `sata_down_spd_limit()` when `spd <= 1` only returns `-EINVAL` without updating `sata_spd_limit` if `link->sata_spd != 0`. [F279, F288, F289]

## Synchronization

- `ap->lock` (`&ap->host->lock`) requires `spin_lock_irqsave()`. `ap->scsi_scan_mutex` and `ap->host->eh_mutex` nest outside `ap->lock`; never acquire them or call sleeping SCSI functions (`scsi_remove_device()`, `scsi_change_queue_depth()`) under `ap->lock`. [F340, F345]
- Mutations to `ap->qc_active`, `nr_active_links`, `excl_link`, `link->active_tag`, `sactive`, and `qc->flags` require `ap->lock`. `__ata_eh_qc_complete()` sets `qc->scsidone = ata_eh_scsidone` and calls `__ata_qc_complete(qc)` under `ap->lock`, then calls `scsi_eh_finish_cmd()` unlocked. [F206, F219]
- `ata_exec_internal()` saves/zeroes `active_tag`, `sactive`, `qc_active`, and `nr_active_links` under `ap->lock`, calls `ata_eh_release(ap)` before `wait_for_completion_timeout()`, calls `ata_eh_acquire(ap)` and `ata_sff_flush_pio_task(ap)` after, freezes the port on timeout, and restores saved state under `ap->lock` after `ata_qc_free(qc)`. `ata_msleep()` releases/reacquires EH if `ap && ap->host->eh_owner == current`. [F197, F211, F214]
- In `ata_scsi_cmd_error_handler()`, after `ata_sff_flush_pio_task(ap)`, hold `ap->lock` across `lost_interrupt(ap)`, setting `ATA_QCFLAG_EH` on timed-out QCs, and `__ata_port_freeze(ap)`. `ata_port_freeze()` must call `__ata_port_freeze(ap)` before `ata_port_abort(ap)` under `ap->lock`. [F207, F208]
- `ata_scsi_port_error_handler()` calls `timer_delete_sync(&ap->fastdrain_timer)` outside `ap->lock` before copying/zeroing `link->eh_info`, setting `ATA_PFLAG_EH_IN_PROGRESS`, and clearing `ATA_PFLAG_EH_PENDING` under `ap->lock`; at exit, check `ATA_PFLAG_EH_PENDING`, clear `eh_info`, and call `end_eh(ap)` in one `ap->lock` section before `ata_eh_release(ap)`. `ata_eh_pull_park_action()` reinitializes `park_req_pending` and moves `ATA_EH_PARK` bits in one `ap->lock` section. [F209, F210, F215]
- `ata_port_alloc()` sets `ATA_PFLAG_INITIALIZING | ATA_PFLAG_FROZEN` (`ata_std_sched_eh()` is a no-op while `INITIALIZING`). `ata_port_request_pm()` sets `ATA_PFLAG_PM_PENDING`, `pm_mesg`, and `eh_info` and schedules EH under `ap->lock`, dropping it for `ata_port_wait_eh()`. `ata_port_detach()` and `ata_port_suspend()` call `cancel_delayed_work_sync()` on `scsi_rescan_task` (and `hotplug_task` in detach, after `ata_port_wait_eh()`) outside `scsi_scan_mutex` and `ap->lock`. [F199, F205, F346]
- `sata_pmp_attach()` sets `link->pmp = SATA_PMP_CTRL_PORT` before reading GSCRs (0 on error) and sets `ap->nr_pmp_links` under `ap->lock` after `sata_pmp_init_links()`; `sata_pmp_detach()` zeroes `nr_pmp_links` and `link->pmp` under `ap->lock` without freeing `ap->pmp_link`. `sata_pmp_eh_handle_disabled_links()` drops `ap->lock` around `sata_link_hardreset()` and `sata_scr_write()`. [F218, F246, F354]
- `ata_ncq_prio_enable()` checks `!(dev->flags & ATA_DFLAG_CDL_ENABLED)` and `ATA_DFLAG_NCQ_PRIO` under `ap->lock`. `ata_change_queue_depth()` caps `queue_depth` at `min3(ATA_MAX_QUEUE, sdev->host->can_queue, ata_id_queue_depth(dev->id))` and updates `ATA_DFLAG_NCQ_OFF` under `ap->lock` before calling `scsi_change_queue_depth()` unlocked. [F364, F365]

## Object Lifetimes

- In `ata_host_alloc()`, errors before `devres_add()` must `kfree(host)` directly, while errors after must only call `devres_release_group(dev, NULL)`. `ata_devres_release()` and `ata_host_release()` must check `host->ports[i]` for `NULL` and call `ata_port_free()` (never `kfree(ap)` directly). [F187, F220, F308, F325]
- `ata_host_start()` must precede `ata_host_register()`: it calls `ata_finalize_port_ops()`, pre-allocates `ata_host_stop` devres, unwinds started ports in reverse and frees `start_dr` if `port_start()` fails, freezes ports, and only calls `devres_add()` and sets `ATA_HOST_STARTED` after all ports start. `ata_host_register()` requires `ATA_HOST_STARTED` and unwinds added tports via `ata_tport_delete()` on error; `ata_host_activate()` calls `devm_free_irq()` if `ata_host_register()` fails. [F189, F190, F200, F327]
- `ata_dev_init()` and `ata_link_init()` zero `[ATA_DEVICE_CLEAR_BEGIN, ATA_DEVICE_CLEAR_END)` and `[ATA_LINK_CLEAR_BEGIN, ATA_LINK_CLEAR_END)`; persistent fields must stay outside those ranges, and heap pointers inside must be freed in `ata_dev_free_resources()`. `ata_force_param_buf` and `force_tbl[]` are `__initdata`/`__initconst` (param perm `0`); post-init code must use `ata_force_tbl`. [F310, F311, F333]

## API Contracts

- In `struct ata_port_operations`, `inherits` must be last, all prior fields pointers, and `NULL` overrides use `ATA_OP_NULL`; `ata_finalize_port_ops()` must run before use. Command/EH-scheduling ops (`qc_defer`, `check_atapi_dma`, `qc_prep`, `qc_issue`, `qc_fill_rtf`, `qc_ncq_fill_rtf`, `freeze`, `thaw`, `sched_eh`, `end_eh`, `lost_interrupt`) and `qc->complete_fn` run under `ap->lock` (IRQs off) and must not sleep. PMP `sata_scr_read/write/write_flush()` sleep (`ata_exec_internal()`), while host-link `ap->ops->scr_read/write` must be atomic-safe. [F313, F341, F343, F356]
- `ata_exec_internal()` and wrappers (`ata_do_dev_read_id()`, `ata_dev_set_feature()`, `ata_read_log_page()`, `sata_pmp_read/write()`, `atapi_eh_tur()`, `atapi_eh_request_sense()`) return `0` or positive `AC_ERR_*` (not `-errno`), and DMA buffers (`dma_dir != DMA_NONE`) must be DMA-safe (never stack). `ata_read_log_page()` takes `sectors` in 512B units; `ata_exec_internal()` takes bytes. [F221, F307, F353]
- `ata_sg_setup()` saves `qc->orig_n_elem = qc->n_elem` before `dma_map_sg()`, and `ata_sg_clean()` passes `qc->orig_n_elem` to `dma_unmap_sg()`. `ata_qc_complete_multiple(ap, qc_active)` takes the mask of *still active* hardware tags, returning `-EINVAL` if any bit is not in `ap->qc_active`, or completed count (`>= 0`). `ata_qc_for_each*()` visits all tags (`qc` may be `NULL`); EH must use `ata_qc_for_each_raw()` and filter `ATA_QCFLAG_EH`. [F196, F228, F280, F281]
- `pio/mwdma/udma_mask` are unshifted; `ata_xfer_mask2mode()` (returns `0xff` on failure, like `ata_timing_cycle2mode()`), `ata_mode_string()`, and `mode_filter()` require `ata_pack_xfermask()` (`ata_xfer_mode2shift()` returns `-1`, `ata_xfer_mode2mask()` returns `0`). [F223, F233]
- `sata_link_hardreset()` must use `sata_scr_write_flush()` for `0x301` before `ata_msleep(ap, 1)` and `sata_link_resume()`. `sata_link_resume()` retries `(scontrol & 0x0f0) | 0x300` up to `ATA_LINK_RESUME_TRIES` times (200 ms delay unless `ATA_LFLAG_NO_DEBOUNCE_DELAY`) until readback is `0x300`, and clears `SCR_ERROR` after debounce. `sata_link_hardreset()` / `sata_std_hardreset()` return `-EAGAIN` when an online link needs follow-up softreset (`*online = true`). [F227, F335, F336]
- `sata_set_spd()` returns `0` (unchanged), `1` (changed), or `-errno`; `sata_spd_string(spd)` takes 1-based `spd` (`1..3`). `ata_ering_record()` pre-increments `cursor`; `ata_ering_map()` walks backward via `(idx - 1 + ATA_ERING_SIZE) % ATA_ERING_SIZE` until `!ent->err_mask` or `map_fn != 0`. In `ata_host_alloc_pinfo()`, advance `j` only when `ppi[j]` is non-NULL. Call `ata_port_desc()` only while `ATA_PFLAG_INITIALIZING`. Guard `to_pci_dev()` with `dev_is_pci()` in generic code, and pass `ap` explicitly to `libsas`-shared helpers (`ata_change_queue_depth()`, `ata_ncq_prio_enable()`). [F229, F268, F269, F293, F294, F317, F318, F358]

## Error Handling & External Contracts

- `ata_eh_recover()` helpers taking `r_failed_dev` (`ata_eh_revalidate_and_attach()`, `ata_eh_set_mode()`, `ata_set_mode()`, `ap->ops->set_mode`, `ata_eh_link_set_lpm()`) must set `*r_failed_dev` on non-zero return. `ata_eh_link_established()` returns `true` when `sata_scr_read()` fails. `ata_eh_link_autopsy()` sets `ATA_EHI_QUIET` when `nr_quiet == nr_failed`. [F226, F331, F368]
- `ata_eh_read_log_10h()` rejects `buf[0] & 0x80` and masks `*tag = buf[0] & 0x1f`; `ata_eh_analyze_ncq_error()` checks `link->sactive & BIT(tag)` before `__ata_qc_from_tag()`. `ata_eh_get_ncq_success_sense()` verifies log 0x0F version `1`, address `0x0f`, and `sense_valid & BIT(tag)` before indexing `&buf[32 + 24 * tag]`, and copies `nsect`, `lbal/m/h`, HOBs, and `auxiliary` into `qc->result_tf`. [F240, F265, F266]
- CHS `tf->lbal` is 1-based: `ata_build_rw_tf()` checks `lba_28_ok()` before `(u32)block` division, sets `sect = (u32)block % dev->sectors + 1`, and rejects `(cyl >> 16) || (head >> 4) || (sect >> 8) || !sect`; `ata_tf_read_block()` rejects `sect == 0` (`U64_MAX`) before `- 1`. `ata_read_native_max_address()` adds 1 to the 0-based LBA (minus 1 if `ATA_QUIRK_HPA_SIZE`); `ata_set_max_sectors()` subtracts 1 from `new_sectors`. [F275, F298, F300]
- `dev->id` is native `u16` (`swap_buf_le16()`), requiring `ata_id_string()` (even `len`) or `ata_id_c_string()` (odd `len`, word `ofs`), whereas `ata_read_log_page()` buffers are raw LE requiring `get_unaligned_le16/32/64()` and `BIT_ULL(63)` check on `ATA_LOG_IDENTIFY_DEVICE` QWords; variable-length GP logs (`ata_dev_config_cpr()`) must size reads via `ata_log_supported()`. `ata_scsi_lpm_store()` iterates `ata_lpm_policy_names[]` from `ATA_LPM_MAX_POWER` (skipping `0`, `ATA_LPM_UNKNOWN`). [F222, F260, F262, F263, F276]

## Known Pitfalls

- `ata_identify_page_supported()` overwrites `dev->sector_buf`; call it before reading your own log page into `dev->sector_buf`. Match physical links in EH via `ata_dev_phys_link(qc->dev) == link`, not `qc->dev->link == link`. `ata_timing[]` must be sorted by `.mode` ending with `{ 0xFF }`; `ata_eh_cmd_timeout_table` needs `0` and `UINT_MAX` terminators; `ehi->desc` must use `__ata_ehi_pushv_desc()` and `ata_ehi_clear_desc()`. [F245, F271, F272, F282, F320]
- Use 64-bit ops (`1ULL << tag`, `BIT_ULL(tag)`, `__ffs64()`) on `ap->qc_active`/`done_mask`, and cast `tf->hob_lbah/m/l` to `u64` before shifting by 40/32/24. Check masks non-zero before `fls/ffs(mask) - 1` in `sata_down_spd_limit()` and `ata_down_xfermask_limit()`. Use `EZ(v, unit)` in `ata_timing_quantize()` and clamp `t->cycle >= t->active + t->recover` in `ata_timing_compute()`. Clamp `get_jiffies_64()` windows with `now - min(now, interval)` and check `time_before(now, deadline)` before sleeping `deadline - now`. [F297, F301, F302, F304, F305, F321]
