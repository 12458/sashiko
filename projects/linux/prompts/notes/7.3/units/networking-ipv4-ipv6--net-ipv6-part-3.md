# NETWORKING [IPv4/IPv6] — net/ipv6 (part 3)

Implements IPv6-in-IPv6 and IPv4-in-IPv6 generic tunneling (`ip6_tunnel.c`), IPv6 UDP tunnel helpers (`ip6_udp_tunnel.c`), IPv6 Multicast Routing and PIMv6 (`ip6mr.c`), IPv6 socket options (`ipv6_sockglue.c`), Multicast Listener Discovery MLDv1/MLDv2 and multicast group management (`mcast.c`, `mcast_snoop.c`), Mobile IPv6 extension headers and XFRM state (`mip6.c`), and IPv6 Neighbour Discovery Protocol (`ndisc.c`).

## Architecture & Data Flow

- SKBs queued on `c->_c.mfc_un.unres.unresolved` use `ipv6_hdr(skb)->version == 0` as a discriminator for synthetic netlink `RTM_GETROUTE` requests created by `ip6mr_get_route`, which `ip6mr_cache_resolve` and `ip6mr_destroy_unres` must reply to via `rtnl_unicast` instead of forwarding as IPv6 packets. [F768]
- When `do_ipv6_setsockopt()` sets a non-zero `np->min_hopcount` for `IPV6_MINHOPCOUNT`, it must enable the `ip6_min_hopcount` static key via `static_branch_enable(&ip6_min_hopcount)` before storing `np->min_hopcount`. [F783]
- When `do_ipv6_setsockopt()` updates `np->tclass` for `IPV6_TCLASS`, it must preserve `np->tclass & INET_ECN_MASK` on `SOCK_STREAM` sockets and call `sk_dst_reset(sk)` whenever `np->tclass` changes. [F784]
- `ip6_tnl_update()` must unlink the tunnel from `ip6n` via `ip6_tnl_unlink(ip6n, t)` and call `synchronize_net()` before mutating `t->parms` in `ip6_tnl_change(t, p)` (which must also call `dst_cache_reset(&t->dst_cache)` and `ip6_tnl_link_config(t)`), and then re-link via `ip6_tnl_link(ip6n, t)`. [F788]
- `ip6_tnl_xmit()` may only enable `t->dst_cache` (`use_cache = true`) when `!t->parms.collect_md`, `!ipv6_addr_any(&t->parms.raddr)`, `t->parms.proto != 0`, and neither `IP6_TNL_F_USE_ORIG_TCLASS` nor `IP6_TNL_F_USE_ORIG_FWMARK` is set in `t->parms.flags`. [F789]
- `mld_process_v1()` must set `idev->mc_v1_seen` via `mld_set_v1_mode(idev)` only when `v1_query` (`len == MLD_V1_QUERY_LEN`, 24 octets) is true, and must cancel MLDv2 general-query work (`mld_gq_stop_work`), interface-change work (`mld_ifc_stop_work`), and deleted-record tombstones (`mld_clear_delrec`). [F797]
- Both `ip6_mc_add_src()` and `ip6_mc_del_src()` must call `sf_markstate(pmc)` to snapshot each source filter's pre-update active state into `psf->sf_oldin` before modifying `pmc->mca_sfcount[sfmode]` or calling `ip6_mc_add1_src()` / `ip6_mc_del1_src()`. [F799]
- `ndisc_constructor()` must release the initial default `neigh->parms` reference via `__neigh_parms_put(neigh->parms)` and replace it with `neigh_parms_clone(in6_dev->nd_parms)` so each neighbour entry uses its interface's `nd_parms` instance rather than the shared `nd_tbl.parms`. [F801]
- `ndisc_recv_na()` must sample `neigh->flags` before calling `ndisc_update()` and, if `NTF_ROUTER` transitions from set to clear (`(old_flags & ~neigh->flags) & NTF_ROUTER`), must call `rt6_clean_tohost(dev_net(dev), saddr)`. [F803]

## Synchronization

- In `ip6_mc_source` and `ip6_mc_msfilter` (`net/ipv6/mcast.c`), when an `MCAST_INCLUDE` source filter becomes empty (`leavegroup = 1`), `idev->mc_lock` must be unlocked before calling `ipv6_sock_mc_drop`. [F745]
- After acquiring `idev->mc_lock`, `ip6_mc_source`, `ip6_mc_msfilter`, and `__ipv6_dev_mc_inc` (`net/ipv6/mcast.c`) must check `idev->dead` and abort with `-ENODEV` if the device is dead. [F746]
- In `ipv6_mc_down` (`net/ipv6/mcast.c`), `igmp6_group_dropped` must be called for all `idev->mc_list` entries before stopping MLD delayed works, and `mld_report_stop_work` (`cancel_delayed_work_sync(&idev->mc_report_work)`) must be called without holding `idev->mc_lock`. [F747]
- In `net/ipv6/mcast.c`, `idev->mc_query_queue` and `idev->mc_report_queue` are protected by `spin_lock_bh(&idev->mc_query_lock)` and `spin_lock_bh(&idev->mc_report_lock)`; `mld_query_work` and `mld_report_work` must dequeue SKBs to a private queue and unlock the spinlock before acquiring `idev->mc_lock`. [F750]
- In `ip6_tnl_encap_add_ops` and `ip6_tnl_encap_del_ops` (`net/ipv6/ip6_tunnel.c`), `ip6tun_encaps[num]` is updated atomically via `cmpxchg`, and `ip6_tnl_encap_del_ops` must call `synchronize_net()` after clearing the slot before returning. [F753]
- In `ndisc_router_discovery` (`net/ipv6/ndisc.c`), updating a default router route's expiration via `fib6_set_expires` and inserting it onto the GC list via `fib6_add_gc_list` must be protected by `spin_lock_bh(&rt->fib6_table->tb6_lock)`. [F761]
- `ip6_mr_output()` must establish its own RCU read-side critical section (`guard(rcu)()`) on entry because callers such as UDP tunnel transmit workers can invoke `dst_output` in process context without holding `rcu_read_lock()`. [F852]
- `ip6_mc_find_dev()` and `ndisc_send_skb()` must hold `rcu_read_lock()` and use `dst_dev_rcu()` (rather than `dst_dev()`) when reading a route's `net_device` prior to acquiring a device reference or accessing per-device IPv6 state. [F853]

## Object Lifetimes

- In `mld_del_delrec` and `mld_clear_delrec`, `in6_dev_put(pmc->idev)` must only be called after `ip6_mc_clear_src(pmc)` has returned because `ip6_mc_clear_src` dereferences `pmc->idev` to assert lock ownership and traverse `pmc->mca_tomb` and `pmc->mca_sources`. [F719]
- Pending `mc->mca_work` delayed work holds a reference in `mc->mca_refcnt`: callers must increment `mca_refcnt` only when `!mod_delayed_work(mld_wq, &ma->mca_work, delay)`, decrement `mca_refcnt` whenever `cancel_delayed_work(&ma->mca_work)` returns true, and release it via `ma_put(ma)` at the end of `mld_mca_work`. [F721]
- Pending `inet6_dev` MLD delayed works (`mc_gq_work`, `mc_ifc_work`, `mc_dad_work`, `mc_query_work`, `mc_report_work`) hold one `idev` reference acquired via `in6_dev_hold(idev)` only when `!mod_delayed_work(...)`, and released via `__in6_dev_put(idev)` on `cancel_delayed_work*` or `in6_dev_put(idev)` on work completion without requeuing. [F722]
- Socket multicast objects (`struct ipv6_mc_socklist` and `struct ip6_sf_socklist`) allocated via `sock_kmalloc` must be freed with `sock_kfree_s` if aborted before RCU publication, but once published on `np->ipv6_mc_list` or `pmc->sflist` must be released by subtracting their exact allocated size from `sk->sk_omem_alloc` and calling `kfree_rcu`. [F725]
- `ipv6_update_options` atomically swaps `inet6_sk(sk)->opt` and returns the old `ipv6_txoptions *`; callers (`ipv6_set_opt_hdr` and `do_ipv6_setsockopt`) must subtract `opt->tot_len` from `sk->sk_omem_alloc` and call `txopt_put(opt)` on the returned old `opt` (or on the new `opt` if aborted before `ipv6_update_options`). [F727]
- `ip6_tnl_dev_init_gen` initializes `t->dst_cache` and `t->gro_cells` (destroying `t->dst_cache` if `gro_cells_init` fails) and holds `t->dev_tracker`; `ip6_tnl_dev_uninit` unlinks `t`, resets `t->dst_cache`, and puts `t->dev_tracker`, while `ip6_dev_free` destroys `t->gro_cells` and `t->dst_cache`. [F732]
- `mif6_add` holds `dev` (via `ip6mr_reg_vif` or `dev_get_by_index`), calls `dev_set_allmulti(dev, 1)`, increments `in6_dev->cnf.mc_forwarding`, and transfers the ref to `v->dev_tracker`; `mif6_delete` must reverse all of these, calling `unregister_netdevice_queue(dev, head)` for `MIFF_REGISTER` only when `!notify`. [F736]
- Unresolved `mfc6_cache` entries on `mrt->mfc_unres_queue` must have their queued skbs drained and `mrt->cache_resolve_queue_len` decremented (via `ip6mr_destroy_unres` or `ip6mr_cache_resolve` plus `ip6mr_cache_free`), whereas resolved entries on `mrt->mfc_cache_list` must be released via `mr_cache_put`. [F738]

## API Contracts

- `ndisc_send_skb` always consumes `skb` (and any `dst_entry` already attached to `skb` via `skb_dst_set`); in `ndisc_send_redirect`, all exits prior to `skb_dst_set(buff, dst)` must jump to `release:` to call `dst_release(dst)`, whereas after `skb_dst_set(buff, dst)`, `ndisc_send_skb` owns `dst` through `buff`. [F741]
- `ip6_tnl_parse_tlv_enc_lim` returns `0` if no valid encapsulation limit TLV is found or a positive byte offset relative to the `raw` IPv6 header pointer, and because it calls `pskb_may_pull`, callers must re-read `skb->data` or `skb_network_header(skb)` after the call before indexing by the returned offset. [F762]
- In `net/ipv6/mip6.c`, the XFRM input callbacks `mip6_destopt_input` and `mip6_rthdr_input` must return the non-negative next-header protocol number (`destopt->nexthdr` or `rt2->rt_hdr.nexthdr`) on success, or `-ENOENT` when the packet address does not match `x->coaddr`. [F778]
- `ndisc_mc_map` maps an IPv6 multicast address into `buf` and returns `0` on success or `-EINVAL` on unsupported `dev->type`, falling back to `memcpy(buf, dev->broadcast, dev->addr_len)` for unknown `dev->type` values only when `dir != 0`. [F779]
- `ndisc_rcv` must zero `NEIGH_CB(skb)` before invoking `ndisc_recv_ns(skb)` on incoming `NDISC_NEIGHBOUR_SOLICITATION` packets so `ndisc_recv_ns` can test `NEIGH_CB(skb)->flags & LOCALLY_ENQUEUED` to distinguish fresh packets from proxy-delayed packets replayed by `pndisc_redo`. [F780]
- `__ndisc_opt_addr_data` and `ndisc_opt_addr_data` require `(p->nd_opt_len << 3) == NDISC_OPT_SPACE(dev->addr_len + ndisc_addr_option_pad(dev->type))` and return `NULL` on any length mismatch, so callers must check the returned pointer before dereferencing or passing it to `memcpy`. [F807]
- In `do_ipv6_mcast_group_source`, when `optname == MCAST_JOIN_SOURCE_GROUP`, `-EADDRINUSE` from `ipv6_sock_mc_join_ssm` must be ignored so execution proceeds to `ip6_mc_source` to add the new source to the existing group membership. [F835]
- Callers of `ip6_tnl_rcv_ctl()` must hold `rcu_read_lock()` because it calls `dev_get_by_index_rcu(net, p->link)` without establishing its own RCU read-side critical section, unlike `ip6_tnl_xmit_ctl()` which takes `rcu_read_lock()` internally. [F854]

## Error Handling

- Callers of `ip6_tnl_err` (`ip4ip6_err` and `ip6ip6_err`) must check both `err == 0` and `*msg != 0` (`rel_msg`) before generating an inner ICMP error, because `ip6_tnl_err` returns `0` with `*msg == 0` when the tunnel is matched but the outer ICMPv6 error should not be relayed. [F764]
- In `__ip6_tnl_rcv`, the `dscp_ecn_decapsulate` callback returns `0` on success, `1` when a non-ECT ECN condition should only be logged, and `> 1` when the frame must be dropped; `__ip6_tnl_rcv` always consumes or frees `skb` (and `tun_dst` if non-NULL) and returns `0`. [F765]
- `ip6mr_fill_mroute` must ignore `-ENOENT` from `mr_fill_mroute` (`if (err < 0 && err != -ENOENT)`), because `mr_fill_mroute` returns `-ENOENT` after setting `RTNH_F_UNRESOLVED` on unresolved cache entries (`c->mfc_parent >= MAXVIFS`) and `1` on resolved entries. [F769]
- `do_ipv6_getsockopt` and `ip6_mc_msfget` must explicitly `memset` stack-allocated output structures (`struct ip6_mtuinfo mtuinfo`, `struct in6_flowlabel_req freq`, and `struct sockaddr_storage ss`) to zero before populating partial fields and copying them to `optval`. [F772]
- `ip6_mc_del1_src` returns `-ESRCH` (`< 0`) on error, `0` when a source is decremented or freed without a change record, and `1` (`> 0`) when the source is moved to `pmc->mca_tomb`, so `ip6_mc_del_src` must separate `rv > 0` (`changerec`) from `rv < 0` (`err`). [F774]
- In `ip6_mc_add_src` and `ip6_mc_del_src`, `delta == 0` adjusts the group-level filter mode counter `pmc->mca_sfcount[sfmode]` whereas `delta != 0` leaves it unchanged, and if `ip6_mc_add1_src` fails at index `i`, `ip6_mc_add_src` must roll back `pmc->mca_sfcount[sfmode]` (when `!delta`) and call `ip6_mc_del1_src` for `0 <= j < i`. [F775]
- When `fib6_nh_init()` fails (`err != 0`), its `out:` path must release any temporary `idev` reference via `in6_dev_put()`, call `fib_nh_common_release(&fib6_nh->nh_common)`, clear `nhc_pcpu_rth_output` and `fib_nh_lws` to `NULL`, and release `dev` via `netdev_put(dev, dev_tracker)`. [F890]
- In `ip6_route_multipath_add()`, if `__ip6_ins_rt()` fails at `err_nh = nh` or `call_fib6_multipath_entry_notifiers()` fails (`err_nh = NULL`), `add_errout:` must delete every already-inserted nexthop in `rt6_nh_list` up to `err_nh` via `ip6_route_del(&nh->r_cfg, extack)` before `cleanup:` releases `nh->fib6_info`. [F893]

## External Contracts

- `ipmr_mfc_seq_show` must check `it->cache != &mrt->mfc_unres_queue` before reading `mfc->_c.mfc_un.res` counters or iterating `minvif..maxvif` in `/proc/net/ip6_mr_cache`, and must emit `0ul, 0ul, 0ul` with no Oifs for unresolved entries. [F813]
- `ip6mr_rtm_valid_getroute_req` must reject `RTM_GETROUTE` requests where `rtm_src_len` or `rtm_dst_len` is neither `0` nor `128`, where `RTA_SRC`/`RTA_DST` is present with a `0` prefix length, or where any of `rtm_tos`, `rtm_table`, `rtm_protocol`, `rtm_scope`, `rtm_type`, or `rtm_flags` is non-zero. [F814]
- Unlike `IPV6_MULTICAST_IF` (which exchanges the interface index in host byte order and accepts `optlen >= sizeof(int)`), `IPV6_UNICAST_IF` in `do_ipv6_setsockopt` and `do_ipv6_getsockopt` exchanges the interface index in network byte order (`ntohl`/`htonl`) and requires `optlen == sizeof(int)` on `setsockopt`. [F817]
- Neighbour Discovery link-layer address options must be sized with `NDISC_OPT_SPACE(addr_len + pad)` (`(((len)+2+7)&~7)`) so that `__ndisc_fill_addr_option()` writes an exact 8-octet multiple (`space >> 3`) into `opt[1]` and `__ndisc_opt_addr_data()` matches `p->nd_opt_len << 3`. [F840]
- In `ndisc_send_redirect()`, the Redirected Header option length `rd_len` must be rounded down to an 8-byte multiple via `rd_len &= ~0x7` before allocating the SKB and passing `rd_len` to `ndisc_fill_redirect_hdr_option()`, which writes `rd_len >> 3` into the option length field and copies `rd_len - 8` bytes. [F841]
- On the per-netns fallback tunnel `ip6n->fb_tnl_dev` (`ip6tnl0`), `netns_immutable` is set, `ip6_tnl_dellink` and `SIOCDELTUNNEL` forbid deletion, and `ip6_tnl_changelink`/`ip6_tnl0_update` reject any netlink change other than `parms.proto` (ignoring `TUNNEL_ENCAP_FLAG_CSUM6` in `ip_tunnel_encap`) with `-EINVAL`. [F867]
- In `do_ipv6_setsockopt` (`ipv6_set_opt_hdr`, `IPV6_TRANSPARENT`, `IPV6_IPSEC_POLICY`, `IPV6_XFRM_POLICY`), privilege checks must use `sockopt_ns_capable(sock_net(sk)->user_ns, ...)` rather than global `capable(...)`. [F884]
- In `rt6_fill_node()`, `rtm->rtm_table` in `struct rtmsg` must be set to `table` when `table < 256` and `RT_TABLE_COMPAT` otherwise, while the full 32-bit `table` ID is emitted in `RTA_TABLE`. [F964]

## Known Pitfalls

- `ipv6_mc_destroy_dev` must call `__ipv6_dev_mc_dec(idev, ...)` directly rather than `ipv6_dev_mc_dec(idev->dev, ...)`, because its caller in `addrconf.c` has already cleared `dev->ip6_ptr` so `in6_dev_get(dev)` would return `NULL` and leak the multicast group memberships. [F724]
- In `ip6_tnl_exit_rtnl_net`, after queuing all `ip6_link_ops` devices residing in `net`, the loops over `ip6n->tnls_r_l` and `ip6n->tnls_wc` must only call `unregister_netdevice_queue(t->dev, list)` when `!net_eq(dev_net(t->dev), net)` so devices in `net` are not queued for unregistration twice. [F735]
- `ip6mr_forward2()` must save the incoming `skb->dev` in a local variable (`indev`) before calling `ip6mr_prepare_xmit()`, because `ip6mr_prepare_xmit()` overwrites `skb->dev` with the outgoing `vif_dev` before `NF_HOOK(NFPROTO_IPV6, NF_INET_FORWARD, ...)` is invoked. [F791]
- In `ip6mr_prepare_xmit()`, `skb_cow(skb, sizeof(*ipv6h) + LL_RESERVED_SPACE(vif_dev))` must be called and `ipv6h = ipv6_hdr(skb)` must be re-fetched after `skb_cow()` before decrementing `ipv6h->hop_limit` in place. [F792]
- In `mip6_destopt_output()` and `mip6_rthdr_output()`, the original Home Address in `iph->saddr` or `iph->daddr` must be copied into the extension header (`hao->addr` or `rt2->addr`) before `iph->saddr` or `iph->daddr` is overwritten in place with `x->coaddr`. [F804]
- `ndopts->nd_opt_array` is sized to `__ND_OPT_ARRAY_MAX` (`ND_OPT_NONCE + 1`) with index `0` reserved for `__ND_OPT_PREFIX_INFO_END`, so `ndisc_parse_options` must only index `nd_opt_array[nd_opt->nd_opt_type]` for option types strictly below `__ND_OPT_ARRAY_MAX`. [F806]
- `ipv6_set_mcast_msfilter` and `compat_ipv6_set_mcast_msfilter` must reject `gf_numsrc >= 0x1ffffffU` or `gf_numsrc > sysctl_mld_max_msf` before evaluating `GROUP_FILTER_SIZE(gsf->gf_numsrc)` or `offsetof(struct compat_group_filter, gf_slist_flex[n])` against `optlen`. [F815]
