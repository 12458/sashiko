# VIRTIO CORE — drivers

Implements the vDPA bus core, Generic Netlink management interface, vDPA device backends (VDUSE userspace vDPA with bounce-buffer IOTLB, vDPA network/block simulators, Alibaba ENI vDPA, and modern Virtio-PCI vDPA bridge), and the Virtio crypto driver.

## Architecture & Data Flow
- Accessing `vdpa_vq_state` or `vduse_vq_info` union members requires checking `driver_features & BIT_ULL(VIRTIO_F_RING_PACKED)`, and `get_driver_features()` may only be called after `VIRTIO_CONFIG_S_FEATURES_OK` is set in `get_status()`. [F52, F145]
- `vdpa_mgmtdev_get_classes()` must skip `mdev->id_table[i].device > 63` before `BIT_ULL(device)`, and `vdpa_dev_vendor_stats_fill()` must reject `index > VIRTIO_NET_CTRL_MQ_VQ_PAIRS_MAX` with `-ERANGE` before calling `vendor_stats_fill()` (`u16` idx). [F90, F91]
- In `vdpa_sim.c`, `vdpasim->running` is `false` on reset/suspend and `true` only on resume or `vdpasim_set_status()` with `VIRTIO_CONFIG_S_DRIVER_OK`; `vdpasim_kick_vq()` when `!running && DRIVER_OK` sets `pending_kick = true`, which `vdpasim_resume()` (after kicking all vqs) and `vdpasim_do_reset()` clear. [F59, F60]
- `vdpasim_create()` must reject `max_iotlb_entries < 2` and check `vhost_iotlb_add_range(..., 0, ULONG_MAX, ...)`. `vdpasim_set_map()`, `reset_map()`, `dma_map()`, and `dma_unmap()` must reject `asid >= vdpasim->dev_attr.nas` with `-EINVAL`, and map/unmap/set_map must reset `iommu[asid]` and clear `iommu_pt[asid]` before modifying the initial passthrough range. [F62, F93, F94]
- In `vdpasim_blk.c`, when `blk->shared_backend` is true, `blk->buffer` accesses require `vdpasim_blk_buffer_lock()`/`unlock()` and `vdpasim_blk_free()` must not free `blk->buffer`. `vdpasim_blk_handle_req()` must verify `out_iov.used >= 1`, `in_iov.used >= 1`, and last `in_iov.iov_len >= 1` before `to_push = vringh_kiov_length(&vq->in_iov) - 1`, verify `vringh_iov_pull_iotlb(..., &hdr, sizeof(hdr)) == sizeof(hdr)` before `to_pull -= bytes`, and add pushed bytes to `pushed` so `err_status` advances `in_iov` by `to_push - pushed`. [F63, F96, F112]
- `vduse_ioctl()` must set `name[VDUSE_NAME_MAX - 1] = '\0'` in `VDUSE_CREATE_DEV`/`DESTROY_DEV`, and `vduse_validate_config()` requires power-of-two `vq_align` in `[VRING_USED_ALIGN_SIZE, PAGE_SIZE]`. VDUSE dev ioctls indexing `dev->vqs[]` must reject `index >= dev->vq_num` and clamp with `array_index_nospec()`. `VDUSE_VQ_SETUP` must reject `group != 0` on API v0 and `group >= dev->ngroups` on API >= v1. `VDUSE_DEV_SET_CONFIG` and `vduse_vdpa_get_config()` must check `offset <= dev->config_size` before `length > dev->config_size - offset`. [F76, F78, F79, F80, F82]
- `vduse_vq_kick()` on a ready vq with `!vq->kickfd` sets `vq->kicked = true` under `vq->kick_lock`, and `vduse_kickfd_setup()` must check `(vq->ready && vq->kicked && vq->kickfd)` to signal the new eventfd and clear `vq->kicked`. `vduse_vq_update_effective_cpu()` requires an online CPU in `vq->irq_affinity` and resets `curr_cpu = IRQ_UNBOUND` (`-1`) when `curr_cpu >= nr_cpu_ids`. [F65, F104]
- `vduse_domain_create()` must reject `iova_limit <= bounce_size`, bound `stream_iovad` to `bounce_size - 1`, and start `consistent_iovad` at PFN `PAGE_ALIGN(bounce_size) >> BOUNCE_MAP_SHIFT`. `vduse_domain_reset_bounce_map()` only deletes IOTLB entries in `[0, bounce_size - 1]` and clears `bounce_map = 0`. When `PAGE_SIZE > BOUNCE_MAP_SIZE`, `vduse_domain_map_bounce_page()` allocates at `(iova & PAGE_MASK) >> BOUNCE_MAP_SHIFT` and `vduse_domain_free_kernel_bounce_pages()` only calls `__free_page()` when `!((pfn << BOUNCE_MAP_SHIFT) & ~PAGE_MASK)`. [F70, F86, F87]
- `vduse_dev_reg_umem()` and `vduse_domain_add_user_bounce_pages()` require `iova == 0`, page-aligned `uaddr`, `size == bounce_size`, and `count == (bounce_size >> PAGE_SHIFT)`; under `write_lock(&domain->bounce_lock)`, add/remove paths must copy active pages (`orig_phys != INVALID_PHYS_ADDR`) between `head_map->bounce_page` and `user_bounce_page` before toggling `user_bounce_pages`. Every `vhost_iotlb_map` in `domain->iotlb` or `vduse_domain_set_map()` must have `map->opaque` set to a `vdpa_map_file *` with `get_file()`. [F69, F88, F137]
- `vp_vdpa_request_irq()` increments `msix_vec` only for vqs with `vring[i].cb.callback` while passing vq index `i` to `vp_modern_queue_vector(mdev, i, msix_vec)`. `eni_vdpa_set_status()` and `eni_vdpa_reset()` must sample old status before `vp_legacy_set_status()` to request/free IRQs on `VIRTIO_CONFIG_S_DRIVER_OK` transitions. [F71, F110]
- In `virtio_crypto`, rekeying (`ctx->vcrypto != NULL`) in `skcipher_setkey()` and `rsa_set_key()` must close old sessions first, and `skcipher_setkey()` must call `virtcrypto_dev_put()` and clear `ctx->vcrypto` on failure. Every `data_vq` buffer queued via `virtqueue_add_sgs()` must use a `virtio_crypto_request *` token at the request's `__ctx`; `__virtio_crypto_skcipher_do_req()` places output sgs (`outhdr`, `iv_sg`, `src_nents` of `req->src`) at `sgs[num_out++]` before input sgs (`req->dst`, `status_sg`). `virtio_crypto_dataq_akcipher_callback()` clamps `dst_len` to `len - sizeof(vc_req->status)`, and `virtcrypto_algo_is_supported()` uses `*_algo_h` with `algo -= 32` when `algo > 31`. [F73, F97, F99, F116, F129]

## Synchronization
- `vdpa_mgmtdev_ops.dev_add`/`dev_del` run under `vdpa_dev_lock` (write) and must set `vdev->mdev` and call `_vdpa_register_device()`/`_vdpa_unregister_device()`. Lock order in `vdpa.c`: `vdpa_dev_lock` -> `vdev->cf_lock` -> backend locks (`vdpasim->mutex`). [F3, F32]
- `vduse_dev_open()` holds `vduse_lock` across `idr_find(&vduse_idr, ...)` until `dev->lock` is acquired and `dev->connected = true`. `vduse_dev_msg_sync()` rechecks `dev->broken` under `dev->msg_lock` before enqueueing onto `send_list`, and re-acquires `dev->msg_lock` after `wait_event_killable*()` before checking `msg->completed` and `list_del()`. `vduse_dev_read_iter()` copies `msg->req` and moves `msg` to `recv_list` before dropping `msg_lock`, and re-lookups via `vduse_find_msg(&dev->recv_list, req.request_id)` under `msg_lock` on `copy_to_iter()` failure. [F20, F21, F26]
- `vduse_vdpa_kick_vq()` checks `eventfd_signal_allowed()` and defers to `schedule_work(&vq->kick)` if false. `vduse_vq_kick()` never takes `dev->rwsem`; it checks `READ_ONCE(vq->dev->suspended)` under `vq->kick_lock`, and `vduse_vdpa_suspend()` cycles every `vq->kick_lock` after setting `dev->suspended`. `vduse_dev_reset()` and `vduse_vdpa_suspend()` must drop `dev->rwsem` before flushing/canceling `dev->inject` and `vq->inject`. [F22, F161, F162]
- VDUSE per-vq lock order: `vq->kick_lock` or `vq->irq_lock` before `vq->ready_lock` (BH/IRQs disabled). `vduse_map_ops` accesses to `token.group->as` require `vq_group_as_read_lock()`, and `vduse_set_group_asid()` requires `vq_group_as_write_lock()`. [F24, F25]
- VDUSE umem lock order: `dev->domain_lock` -> `dev->as[asid].mem_lock` -> `mmap_read_lock(current->mm)` -> `write_lock(&domain->bounce_lock)`. `vduse_domain_map_bounce_page()` runs under `read_lock(&domain->bounce_lock)` and must allocate `tmp_page` with `GFP_ATOMIC` and install via `cmpxchg()`. `vduse_dev_iotlb_entry()` holds `domain_lock` and `iotlb_lock` and calls `get_file()` before unlocking `iotlb_lock`. `vduse_domain_init/reset_bounce_map()` revalidates `bounce_map` under `iotlb_lock`, and `vduse_iotlb_add_range()` (under `iotlb_lock`) allocates `vdpa_map_file` with `GFP_ATOMIC`. [F27, F29, F30, F165, F166, F168]
- In `vdpa_sim`, `mm_bound` updates run on `vdpasim->worker` via `vdpasim_worker_change_mm_sync()`, and `vdpasim_work_fn()` brackets `work_fn()` with `mmget_not_zero()`/`kthread_use_mm()` and `kthread_unuse_mm()`/`mmput()` when `use_va && mm`. Request completion in `vdpa_sim_net`/`blk` requires `smp_wmb()` before and after `vringh_complete_iotlb()` and `local_bh_disable()`/`enable()` around callbacks; `vdpa_sim_net` stats require `u64_stats_update_begin/end()` and `u64_stats_fetch_begin/retry()`. [F35, F36, F170]
- `vp_vdpa_get_config()` loops MMIO reads until `config_generation` matches. In `virtio_crypto`, call `init_completion()` before locking `ctrl_lock` in `virtio_crypto_ctrl_vq_request()`; hold `ctrl_lock` or `data_vq->lock` across `virtqueue_disable_cb()`, `get_buf()`, and `enable_cb()` in `virtcrypto_ctrlq_callback()` and `virtcrypto_done_work()` (re-locking after each callback); and hold `cpus_read_lock()` around `virtcrypto_set_affinity()`. [F37, F40, F114, F174]

## Object Lifetimes
- After `__vdpa_alloc_device()`, error paths must call `put_device(&vdev->dev)` instead of `kfree(vdev)`, and `bus_find_device(&vdpa_bus, ...)` must be paired with `put_device(dev)`. Backends must finish all device init before `_*vdpa_register_device()`, and call `vdpa_mgmtdev_unregister()` before tearing down parent hardware or freeing `mdev`. `vdpasim_free()` must cancel `work` and destroy `worker` before freeing iovs, calling `dev_attr.free()`, resetting `iommu`, or freeing `vqs`/`config`. [F1, F4, F33, F34, F143]
- `vduse_dev_release()` must call `vduse_dev_dereg_umem()` on all ASes under `domain_lock` and splice `recv_list` onto `send_list` under `msg_lock` before clearing `connected`. `vduse_dev_reg/dereg_umem()` must pair page pinning, `mm->pinned_vm`, `mmgrab()`/`mmdrop()`, and `umem = NULL`, while keeping kernel `map->bounce_page` allocated when attaching `user_bounce_page`. [F8, F9, F164]
- Self-references from `get_file(domain->file)` in `domain->iotlb` must be removed via `vduse_dev_reset()` and `vduse_domain_free_coherent()` before `vduse_domain_destroy()` calls `fput(domain->file)`. Callers of `vduse_dev_iotlb_entry(..., &f, ...)` must call `fput(f)` on error and after `receive_fd()`. Added `vduse_virtqueue` kobjects are freed via `kobject_put()`, and `vduse_dev_init_vqs()` resets `dev->vqs = NULL` on error. `vduse_create_dev()` takes `config_buf` and calls `__module_get()` only on success; `vdpa_exit()` and `vduse_exit()` must destroy `vdpa_index_ida` and `vduse_idr`. [F10, F12, F13, F14, F15]
- `vp_vdpa_free_irq()` and `eni_vdpa_free_irq()` must set hardware MSI-X vectors to `VIRTIO_MSI_NO_VECTOR` before `devm_free_irq()`, and reset `irq = VIRTIO_MSI_NO_VECTOR` and `vectors = 0` after `pci_free_irq_vectors()`. `virtio_crypto` alg registration/unregistration is serialized under `algs_lock` on `active_devs` 0<->1 transitions, with `virtcrypto_dev_start()` unregistering skcipher algs if akcipher registration fails. [F16, F19]

## API Contracts
- `vdpa_device` (and `vdpasim` in `vdpasim_blk`/`net`) must be at offset 0. `__vdpa_alloc_device()` requires `dma_map`/`dma_unmap` both set or both NULL, and `use_va` requires `dma_map` or `set_map`. `vdpa_mgmt_dev` requires `device`, `ops->dev_add`/`dev_del`, and a `.device == 0`-terminated `id_table`. Netlink dumpit helpers in `vdpa.c` increment `idx` only for skipped (`< start_idx`) or filled entries and save it to `cb->args[0]`. [F45, F46, F109, F130]
- `features_is_valid()` in `vduse_dev.c` rejects `VIRTIO_BLK_F_CONFIG_WCE`, `VIRTIO_NET_F_CTRL_VQ`, net devices without `VIRTIO_F_VERSION_1`, and any device without `VIRTIO_F_ACCESS_PLATFORM`. `vduse_domain_map_page()` and `alloc_coherent()` return `DMA_MAPPING_ERROR` on failure (whereas `alloc_iova()` returns `0`), and `vhost_iotlb_*`, `vduse_iotlb_*`, and `vduse_domain_alloc_iova()` take inclusive `last`/`limit` (`start + size - 1`). [F50, F51, F154]
- In `virtcrypto_probe()`/`restore()`, init vqs and start `crypto_engine` before `virtio_device_ready()`; in `remove()`/`freeze()`, flush `config_work` and call `virtio_reset_device()` before freeing unused reqs and deleting vqs. `virtio_crypto_skcipher_encrypt()`/`decrypt()` return `0` when `!req->cryptlen` and reject `req->cryptlen % AES_BLOCK_SIZE != 0`. [F117, F157]

## Error Handling
- On `vdpa_dev_add()` failure in `vduse_dev.c`, destroy each `dev->as[j].domain` and set it to `NULL` under `domain_lock`, and call `put_device(&dev->vdev->vdpa.dev)`. In `vduse_vdpa_set_map()`, call `vduse_domain_clear_map()` if `vduse_dev_update_iotlb()` fails. In `vdpasim_create()`, reset any `ERR_PTR` field (`vdpasim->worker = NULL`) before `goto err_iommu`. Store `vringh_iov_pull/push_iotlb()` results in signed `ssize_t` and check for errors. [F11, F42, F43, F67]
- All `virtio_crypto` sg buffers/headers must be heap-allocated and zero-initialized, with response status pre-set to `VIRTIO_CRYPTO_ERR`. `virtcrypto_update_status()` must call `virtio_break_device()` and return `-EPERM` if `status` has bits outside `VIRTIO_CRYPTO_S_HW_READY`. [F55, F156]

## External Contracts
- `VIRTIO_ID_NET` creation in `vduse_create_dev()` requires `capable(CAP_NET_ADMIN)`, and `VDPA_DEV_NET_ATTRS_MASK` in `vdpa_nl_cmd_dev_add_set_doit()` requires `netlink_capable(skb, CAP_NET_ADMIN)`. Netlink config fill helpers in `vdpa.c` must use `__virtio16/32/64_to_cpu(true, ...)`. `vduse_validate_config()` rejects non-zero `ngroups`/`nas` on API v0 and requires `1..MAX` on API >= v1. `vduse_dev_compat_ioctl()` translates `COMPAT_VDUSE_IOTLB_GET_FD` and `COMPAT_VDUSE_VQ_GET_INFO`. VDUSE bounce/coherent pages require `__GFP_ZERO`. `virtio_crypto_rsa_set_key()` with `PKCS1_PADDING` requires a valid `hash_algo` (`RSA_SHA1`), not `NO_HASH`. [F58, F77, F84, F92, F181, F185]

## Known Pitfalls
- `vduse_vdpa_get_config()` must `memset(buf, 0, len)` before checking `offset > dev->config_size`. `VDUSE_IOTLB_GET_FD*` ioctls must zero-init stack `vduse_iotlb_entry_v2 entry = {0}`. `vduse_dev_broken()` must use `list_for_each_entry_safe()` and unlink each `msg` before `wake_up()`. `vduse_iotlb_del_range()` must re-query `vhost_iotlb_itree_first()` on each iteration. `vduse_domain_bounce()` adds `offset_in_bounce_page(iova)` to `map->orig_phys` and `offset_in_page(iova)` to `kmap_local_page()`, and `do_bounce()` resets `offset = 0` after each page. [F54, F103, F106, F107, F124, F132]
- `vdpasim_queue_ready()` must save `last_avail_idx` before `vringh_init_iotlb*()` and restore it to `last_avail_idx` and `last_used_idx`. In `vdpasim_net_work()`, every `continue` after `vringh_getdesc_iotlb()` on `txq` must call `vdpasim_net_complete(txq, 0)`. `vdpasim_blk_check_range()` checks `start_sector < VDPASIM_BLK_CAPACITY` before `num_sectors > VDPASIM_BLK_CAPACITY - start_sector` and before `num_sectors << SECTOR_SHIFT`. [F61, F113, F121]
- `virtio_crypto_rsa_do_req()` must set `vc_req->sgs = NULL`. `virtio_crypto_alg_akcipher_init_session()` bounds `memcpy()` by `sizeof(*para)`. `__virtio_crypto_skcipher_do_req()` checks `dst_len > U32_MAX` and `max_size` in `u64`, and on CBC decrypt copies `req->iv` to the request's `iv` buffer before updating `req->iv` from `req->src`. `virtcrypto_start_crypto_engines()` loop index `i` must be signed. [F56, F72, F115, F118, F126]

## Other
- `vp_vdpa_kick_vq()` uses `vp_iowrite16(qid, vp_vdpa->vring[qid].notify)`, whereas `vp_vdpa_kick_vq_with_data()` masks `qid = data & 0xFFFF` and uses `vp_iowrite32(data, ...)`. [F150]
