# QCOM AUDIO (ASoC) DRIVERS — sound/soc

Qualcomm ASoC platform, CPU DAI, machine, and DSP IPC drivers, plus the WSA884x SoundWire speaker amplifier driver (`sound/soc/codecs/wsa884x.c`). Covers LPASS direct DMA/CPU/HDMI/Codec-DMA drivers (`sound/soc/qcom/lpass*`), machine helpers (`common.c`, `apq8016_sbc.c`, `apq8096.c`), and QDSP6 APR (`q6afe`, `q6adm`) and GPR AudioReach (`audioreach.c`) layers.

## Architecture & Data Flow

- In `asoc_qcom_lpass_cpu_platform_probe()`, set `platform_set_drvdata(pdev, drvdata)` and `drvdata->variant` before `devm_regmap_init_mmio()` or `variant->init(pdev)`, compute `.max_register` from `variant` on `lpass_{cpu,hdmi,rxtx,va}_regmap_config` before `devm_regmap_init_mmio()` (all use `REGCACHE_FLAT`), and run `variant->init(pdev)` to enable clocks before `asoc_qcom_lpass_platform_register(pdev)` touches MMIO. [F483, F484]
- In `struct lpass_data`, HDMI resources (`hdmiif_map`, `hdmiif_irq`, `hdmi_rd_dmactl`) and Codec DMA resources (`rxtx_lpaif_map`, `va_lpaif_map`, `rxtx_*_dmactl`, `va_wr_dmactl`) are only populated when `hdmi_port_enable` or `codec_dma_enable` is set; probe, register, suspend, and resume paths must check those flags first. In `struct lpass_variant`, `init`, `exit`, `alloc_dma_channel`, and `free_dma_channel` are optional and must be NULL-checked before calling. [F403, F406]
- In `lpass.h` and `lpass-hdmi.h`, `struct regmap_field *` members in `struct lpaif_dmactl`, `lpass_dp_metadata_ctl`, and `lpass_sstream_ctl` must match the exact order and count of the corresponding `struct reg_field` members in `struct lpass_variant` for `devm_regmap_field_bulk_alloc()`. [F438]
- Because LPASS regmaps use `REGCACHE_FLAT`, `lpass_{cpu,rxtx,va}_regmap_volatile()` must return `true` for all `IRQCLEAR`, `IRQSTAT`, `RDMACURR`, and `WRDMACURR` registers, and `lpass_hdmi_regmap_volatile()` must return `true` for `LPASS_HDMITX_APP_IRQSTAT_REG`, `LPASS_HDMI_TX_LEGACY_ADDR`, `LPASS_HDMI_TX_VBIT_CTL_ADDR`, `LPASS_HDMI_TX_PARITY_ADDR`, `LPAIF_HDMI_RDMACURR_REG`, `LPASS_HDMI_TX_DMA_ADDR`, and `LPASS_HDMI_TX_CH_{LSB,MSB}_ADDR`. [F495, F496]
- Playback and capture on the same MI2S DAI share `LPAIF_I2SCTL_REG(v, id)`; `lpass_cpu_daiops_{hw_params,prepare,trigger,shutdown}()` must only touch `spken`/`spkmode`/`spkmono` for playback and `micen`/`micmode`/`micmono` for capture. In `hw_params()`, multi-line SD modes (`QUAD01`, `QUAD23`, `6CH`, `8CH`) must be downgraded only in the local `mode` variable without overwriting `drvdata->mi2s_{playback,capture}_sd_mode[id]`. [F420, F458]
- `lpass_cpu_daiops_prepare()` enables `drvdata->mi2s_bit_clk[id]` at most once guarded by `drvdata->mi2s_was_prepared[id]` (paired with `lpass_cpu_daiops_shutdown()`), whereas `lpass_cpu_daiops_trigger()` must unconditionally call `clk_enable()`/`clk_disable()` on `mi2s_bit_clk[id]` without checking `mi2s_was_prepared`. [F498]
- `lpass_platform_pcmops_{open,close}()` must keep `drvdata->{substream,hdmi_substream,rxtx_substream,va_substream}[dma_ch]` synchronized with `v->alloc_dma_channel()` and `v->free_dma_channel()`, because LPASS IRQ handlers only dispatch channel interrupts when the substream slot is non-NULL. [F423]
- In `lpass_platform_pcmops_trigger()` and `lpass_dma_interrupt_handler()`, update shared `IRQEN` registers via `regmap_update_bits()` masked to `LPAIF_IRQ_ALL(ch)` and write `IRQCLEAR` registers via `regmap_write_bits()`. `lpass_dma_interrupt_handler()` must check `LPAIF_IRQ_PER(chan)`, `LPAIF_IRQ_XRUN(chan)`, `LPAIF_IRQ_ERR(chan)`, and `val` with separate `if` statements (never `else if`) and return `IRQ_HANDLED` for every matched bit so the `lpass_platform_*_irq` loop does not abort early. [F424, F455]
- In `audioreach_populate_graph()`, `mp_data->mod_prop_obj[nmodule++]` must be populated via `apm_populate_module_prop_obj()` before `if (!module->max_op_port) continue;` because `audioreach_alloc_graph_pkt()` sizes `mod_prop_data` for all modules. Also, `mlobj` starts at `&ml_data->mod_list_obj[0]` and must advance by `APM_MOD_LIST_OBJ_PSIZE(mlobj, container->num_modules)` per container because `struct apm_mod_list_obj` has a flexible `mod_cfg[]` array. [F453, F454]
- `q6adm_probe()` and `q6afe_probe()` must initialize mutexes, waitqueues, spinlocks, and lists (`copps_list`, `port_list`) and call `dev_set_drvdata(dev, ...)` before `devm_of_platform_populate(dev)`. In `q6adm.c`, `adm->copp_bitmap` has `AFE_MAX_PORTS` separate `unsigned long` words, so `q6adm_alloc_copp()` and `q6adm_free_copp()` must pass `&adm->copp_bitmap[port_idx]` with bit index `< MAX_COPPS_PER_PORT`. [F478, F485]
- In `q6afe-dai.c`, `q6afe_dai_prepare()` must call `q6afe_port_stop()` if `dai_data->is_port_started[dai->id]` is already true before re-preparing and starting it, and `q6afe_dai_shutdown()` must only call `q6afe_port_stop()` when `is_port_started[dai->id]` is true before clearing it to false. [F430]
- In `apq8016_sbc.c`, QDSP6 `*_MI2S_RX` and `*_MI2S_TX` DAIs map to the same MI2S port via `qdsp6_dai_get_lpass_id()`, so `msm8916_qdsp6_{startup,shutdown}()` must refcount `data->mi2s_clk_count[mi2s]` to enable/disable `LPAIF_BIT_CLK` only on first start and last shutdown. Also, every `.data` entry in `apq8016_sbc_device_id[]` must be `void (*)(struct snd_soc_card *card)` for `add_ops(card)` in `apq8016_sbc_platform_probe()`. [F433, F481]
- `wsa884x_probe()` must set `regcache_cache_only(wsa884x->regmap, true)` before registering hwmon or ASoC, and `wsa884x_update_status()` must keep it cache-only while `SDW_SLAVE_UNATTACHED` until `SDW_SLAVE_ATTACHED`. `wsa884x->port_enable[]` and `port_prepared[]` are 0-indexed (`0 .. WSA884X_MAX_SWR_PORTS - 1`) while SoundWire port numbers (`prepare_ch->num`, `wsa884x_pconfig[i].num`, `pdev->m_port_map[1..]`) are 1-based, and `wsa884x_hw_params()` must reset `wsa884x->active_ports = 0` before compacting `port_config`. [F464, F486]

## Synchronization

- In `q6adm.c`, all mutations and traversals of `adm->copps_list` and `adm->copp_bitmap` (`q6adm_open()`, `q6adm_free_copp()`, `q6adm_find_copp()`, `q6adm_find_matching_copp()`) must hold `adm->copps_list_lock` via `spin_lock_irqsave()`. Because `q6adm_open()` holds this spinlock across `q6adm_alloc_copp()`, allocations inside `q6adm_alloc_copp()` must use `GFP_ATOMIC` and never sleep. [F390, F501]
- In `audioreach_send_cmd_sync()`, `q6adm_apr_send_copp_pkt()`, `q6adm_matrix_map()`, and `afe_apr_send_pkt()`, hold the command mutex (such as `adm->lock`) while resetting `result->opcode = 0` and `result->status = 0`, sending the packet, and waiting on `wait_event_timeout()`; `q6adm_callback()` must never acquire `adm->lock`. [F392, F463]
- In `asoc_qcom_lpass_platform_register()`, clear host IRQ enable registers and initialize all dmactl regmap fields (`rd_dmactl`, `wr_dmactl`, `rxtx_rd_dmactl`, `rxtx_wr_dmactl`, `va_wr_dmactl`, `hdmi_rd_dmactl`) and IRQs before `devm_snd_soc_register_component()`. [F395]
- `lpass_cpu_daiops_trigger()` runs in atomic trigger context and must only call `clk_enable()`/`clk_disable()` on `drvdata->mi2s_bit_clk[id]`, relying on process-context `startup()`/`shutdown()` for `clk_prepare()`/`clk_unprepare()`. [F507]
- `wsa884x_get_temp()` holds `wsa884x->sp_lock` via `guard(mutex)(&wsa884x->sp_lock)` (never unlock manually). `wsa884x->temperature` stores degrees Celsius; when `wsa884x->pa_on` is true, return `*temp = wsa884x->temperature * 1000` without touching registers. When `pa_on` is false, after `pm_runtime_resume_and_get(wsa884x->dev)` succeeds, every exit path must restore `WSA884X_TADC_VALUE_CTL_TEMP_VALUE_RD_EN_MASK` to 1, reset `WSA884X_PA_FSM_BYP0` to `0x0`, and jump to `out` for `pm_runtime_put_autosuspend()`, only updating `wsa884x->temperature` when strictly between `WSA884X_LOW_TEMP_THRESHOLD` and `WSA884X_HIGH_TEMP_THRESHOLD` and scaling `*temp` by 1000. [F385, F426, F466, F499]

## Object Lifetimes

- Because `lpass_variant.init` callbacks (`{apq8016,ipq806x,sc7180,sc7280}_lpass_init()`) enable clocks via unmanaged `clk_[bulk_]prepare_enable()`, every LPASS CPU `platform_driver` must wire `.remove` to `asoc_qcom_lpass_cpu_platform_remove()` to call `variant->exit(pdev)`. In `apq8016_lpass_init()`, any error after `clk_bulk_prepare_enable(drvdata->num_clks, drvdata->clks)` must jump to `err_ahbix_clk` to call `clk_bulk_disable_unprepare()`. [F383, F488]
- In `wsa884x_probe()`, pair `regulator_bulk_enable()` with `devm_add_action_or_reset(dev, wsa884x_regulator_disable, wsa884x->supplies)` before `wsa884x_reset_deassert()` and `devm_add_action_or_reset(dev, wsa884x_reset_powerdown, wsa884x)` so devres asserts reset before disabling regulators. [F386]
- `q6adm_find_copp()` and `q6adm_find_matching_copp()` must call `kref_get(&c->refcount)` under `adm->copps_list_lock`, and transient callers (`q6adm_callback()`, `q6adm_matrix_map()`) must release it via `kref_put(&copp->refcount, q6adm_free_copp)`. In `q6adm_open()`, once `q6adm_alloc_copp()` links `copp` onto `adm->copps_list`, any `q6adm_device_open()` failure must release `copp` via `kref_put(&copp->refcount, q6adm_free_copp)` (never `kfree(copp)`) and return `ERR_PTR(ret)`. [F391, F408]

## API Contracts

- `__audioreach_alloc_pkt()` and `audioreach_alloc_{pkt,apm_pkt,cmd_pkt,apm_cmd_pkt}()` return `ERR_PTR(-ENOMEM)` on failure (never `NULL`); callers must check `IS_ERR(pkt)` and must `kfree(pkt)` after `audioreach_[graph_]send_cmd_sync()` or `gpr_send_port_pkt()`. `audioreach_alloc_{cmd,apm_cmd}_pkt()` include `GPR_HDR_SIZE + APM_CMD_HDR_SIZE`, whereas `audioreach_alloc_{pkt,apm_pkt}()` include only `GPR_HDR_SIZE`. [F379, F397, F442]
- `audioreach_send_cmd_sync()` takes mutually optional `port` and `gdev`, and `afe_apr_send_pkt()` takes a nullable `port` (`NULL` for service-level commands like `q6afe_set_lpass_clock()` and `q6afe_vote_lpass_core_hw()`); neither may dereference `port` or `gdev` without a non-NULL check. [F405]
- `audioreach_{pcm,shmem}_set_media_format()` only support up to 4 channels (matching `audioreach_set_default_channel_mapping()`) and must reject `mcfg->num_channels > 4` with `-EINVAL`. [F450]
- In `q6afe.c` and `q6adm.c`, internal lookups (`q6afe_find_port()`, `q6adm_find_copp()`, `q6adm_find_matching_copp()`) return `NULL` when not found, whereas `q6afe_port_get_from_id()`, `q6adm_alloc_copp()`, and `q6adm_open()` return `ERR_PTR` and never `NULL`. Because `q6afe_probe()` and `q6adm_probe()` store drvdata on the parent `apr_device`, exported `q6afe`/`q6adm` functions taking a child `struct device *dev` must call `dev_get_drvdata(dev->parent)`. [F398, F477]
- `asoc_qcom_lpass_cpu_platform_probe()` must check `of_parse_phandle(pdev->dev.of_node, "qcom,adsp", 0)` first and, if present, call `of_node_put(dsp_of_node)` and return `-EBUSY`. For `is_cdc_dma_port(dai_id)` streams, LPASS Codec DMA can only access LPM memory, so buffers must be preallocated from `{rxtx,va}_cdc_dma_lpm_buf` with `memremap(..., MEMREMAP_WC)`, mmapped via `io_remap_pfn_range()`, and copied with `copy_{from_iter_toio,to_iter_fromio}()`. [F482, F497]
- `wsa884x_get_reset()` must try `devm_reset_control_get_optional_shared(dev, NULL)` before falling back to `devm_gpiod_get_optional(dev, "powerdown", GPIOD_OUT_HIGH)` when `sd_reset` is `NULL`, with `wsa884x_reset_{deassert,powerdown}()` branching on `sd_reset`. Guard `devm_hwmon_device_register_with_info()` in `wsa884x_probe()` with `IS_REACHABLE(CONFIG_HWMON)`. [F494, F516]

## Error Handling

- `q6adm_apr_send_copp_pkt()` and `q6adm_matrix_map()` return positive remaining jiffies from `wait_event_timeout()` on success, so Q6ADM callers (`q6adm_open()`, `q6adm_close()`, callers of `q6adm_device_{open,close}()`) must test `ret < 0` rather than `if (ret)`. [F399]
- In `qcom_snd_{wcd,dp}_jack_setup()`, `apq8016_dai_init()`, and `msm_snd_hw_params()`, treat `-ENOTSUPP` from `snd_soc_component_set_{jack,sysclk}()` or `snd_soc_dai_{get,set}_channel_map()` as success. [F400]
- In `asoc_qcom_lpass_cpu_platform_probe()`, check `devm_platform_ioremap_resource_byname()` with `IS_ERR()` and `platform_get_resource_byname()` with `if (!res)` (returning `-EINVAL`). In all LPASS probe/init helpers, NULL-check every `devm_k{z,c}alloc()` return before passing it to regmap-field or clock-bulk helpers. [F401, F402]
- In `lpass-cdc-dma.c`, `__lpass_get_dmactl_handle()` leaves `*dmactl` unmodified when `dai_id` is unknown, so callers must initialize `dmactl = NULL` before calling and check `if (!dmactl)`. [F409]
- In `lpass_dma_interrupt_handler()`, log `LPAIF_IRQ_XRUN` with `dev_warn_ratelimited()` and call `snd_pcm_stop_xrun(substream)`, and on `LPAIF_IRQ_ERR` call `snd_pcm_stop(substream, SNDRV_PCM_STATE_DISCONNECTED)` after clearing the IRQ. [F519]
- In `wsa884x_get_temp()`, check `d1 == d2` before dividing by `d2 - d1`, because ignored `regmap_read()` errors on `WSA884X_OTP_REG_1..4` leave `d1 == d2 == 0`. [F465]

## External Contracts

- In `lpass_platform_pcmops_prepare()`, write `LPAIF_DMABUFF_REG` and `LPAIF_DMAPER_REG` in 32-bit words minus one (`(bytes >> 2) - 1`), whereas `LPAIF_DMABASE_REG` and `LPAIF_DMACURR_REG` in `pointer()` are byte addresses converted with `bytes_to_frames()`. [F414]
- In `audioreach.c`, compound APM packets (`APM_CMD_GRAPH_OPEN`, multi-param `APM_CMD_SET_CFG`) must 8-byte align (`ALIGN(..., 8)`) each parameter section when advancing the pointer and set `param_data->param_size` to the aligned size minus `APM_MODULE_PARAM_DATA_SIZE`. In `audioreach_{i2s,codec_dma}_set_media_format()`, populate `intf_cfg->cfg.lpaif_type = module->hw_interface_type` alongside the interface index. [F411, F441]
- In `q6tdm_set_channel_map()`, after validating `tx_num`/`rx_num <= AFE_PORT_MAX_AUDIO_CHAN_CNT` (8) and copying active slots into `tdm->ch_mapping`, initialize all trailing entries up to `AFE_PORT_MAX_AUDIO_CHAN_CNT` to `Q6AFE_CMAP_INVALID` (`0xFFFF`). In `qcom_snd_parse_of()`, fall back to `"qcom,model"` and `"qcom,audio-routing"` alongside `"model"` and `"audio-routing"`. [F447, F448]

## Known Pitfalls

- For WRDMA capture channels, pass the 0-based index (`pcm_data->dma_ch - v->*wrdma_channel_start`) from `__lpass_get_id()` / `__lpass_get_dmactl_handle()` to `regmap_fields_write()` on `{wr,rxtx_wr,va_wr}_dmactl`, but pass raw `pcm_data->dma_ch` to `LPAIF_DMA*_REG`, `LPAIF_IRQ_ALL()`, and `drvdata->*substream[]`. [F421]
- When iterating `i < variant->num_dai` in `lpass-cpu.c`, index `drvdata->mi2s_{playback_sd_mode,capture_sd_mode,osr_clk,bit_clk,was_prepared}` by `variant->dai_driver[i].id`, but index `variant->dai_{osr,bit}_clk_names` by `i`. [F435]
- In `audioreach.c`, convert `__le32` fields of `struct audioreach_module_priv_data` (`module->data->size`) with `le32_to_cpu()`. In `audioreach_mfc_set_media_format()`, size the payload with `APM_MFC_CFG_PSIZE` and copy `u8 cfg->channel_map[]` into `uint16_t media_format->channel_mapping[]` element-by-element (never `memcpy()`). [F440, F476]
- In `q6afe-dai.c`, `dai->id & 0x1` distinguishes TX from RX only for SLIMbus and TDM DAI IDs; Codec DMA DAI IDs (`WSA_CODEC_DMA_RX_0 ... RX_CODEC_DMA_RX_7`) must use explicit case labels. In `q6adm_find_{copp,matching_copp}()` and `q6afe_find_port()`, store a `list_for_each_entry()` match in a separate `ret = NULL` pointer (calling `kref_get()` before unlocking) rather than using the loop cursor after the loop. [F459, F461]
