# NVM EXPRESS TARGET DRIVER — drivers/nvme/target (part 2)

This unit implements the NVMe/RDMA (`rdma.c`) and NVMe/TCP (`tcp.c`) target fabric transports (including optional TLS 1.3 PSK and CRC32C digests), Zoned Namespaces (ZNS) command support (`zns.c`), and ftrace tracepoint helpers (`trace.h`, `trace.c`).

## Architecture & Data Flow

- When `nvmet_rdma_read_data_done()` or `nvmet_rdma_write_data_done()` refunds `rsp->n_rdma` to `queue->sq_wr_avail` and calls `nvmet_rdma_rw_ctx_destroy(rsp)`, it must reset `rsp->n_rdma = 0` so `nvmet_rdma_release_rsp(rsp)` only credits 1 send WR and does not destroy the RW ctx twice. Recycling `rsp` in `nvmet_rdma_recv_done()` must clear `rsp->flags`, `rsp->n_rdma`, and `rsp->invalidate_rkey` to 0, and `nvmet_rdma_queue_response()` must reset `rsp->send_wr.opcode = IB_WR_SEND` when `rsp->invalidate_rkey == 0`. [F202, F256]
- In `rdma.c`, `cm_id->context` always points to `struct nvmet_rdma_port`, while `struct nvmet_rdma_queue *` is only in `cm_id->qp->qp_context` (and `wc->qp->qp_context`). In `nvmet_rdma_cm_handler()`, `RDMA_CM_EVENT_ADDR_CHANGE` must check `if (!queue)` to schedule `port->repair_work` and `break` for listener `cm_id`s, only falling through to `nvmet_rdma_queue_disconnect(queue)` when `queue` is non-NULL. [F288, F313]
- In `__nvmet_rdma_queue_disconnect()`, `case NVMET_RDMA_Q_CONNECTING:` must drain `queue->rsp_wait_list` via `nvmet_rdma_put_rsp()` and fall through to `case NVMET_RDMA_Q_LIVE:` to set `queue->state = NVMET_RDMA_Q_DISCONNECTING` and `disconnect = true`, while `case NVMET_RDMA_Q_DISCONNECTING:` must leave `disconnect` false. [F289]
- In `struct nvmet_rdma_rsp`, `send_cqe`, `read_cqe`, and `write_cqe` are distinct `struct ib_cqe` fields whose callbacks recover `rsp` via `container_of(wc->wr_cqe, ...)` on that specific field; each WR must pass its matching `ib_cqe`. Even when `nvmet_rdma_use_srq` is true, `nvmet_rdma_init_srqs()` leaves `ndev->srqs` NULL if the IB device lacks SRQ support; code must test `ndev->srqs`, `queue->nsrq`, or `cmd->nsrq` rather than `nvmet_rdma_use_srq`. [F243, F314]
- `nvmet_rdma_cmd.sge[0]` maps the 64-byte `nvme_cmd` capsule while `c->sge[1 .. ndev->inline_page_count]` map `c->inline_sg[]`, so `nvmet_rdma_alloc_inline_pages()`/`nvmet_rdma_free_inline_pages()` must start `sge` at `&c->sge[1]` and receive SGE counts must reserve 1 SGE for `nvme_cmd`. `nport->inline_data_size` must be clamped to `NVMET_RDMA_MAX_INLINE_DATA_SIZE` in `nvmet_rdma_add_port()` and `inline_sge_count * PAGE_SIZE` in `nvmet_rdma_find_get_device()`. When `NVME_RW_PRINFO_PRACT` is set in `nvmet_rdma_set_sig_attrs()`, it must be cleared in `cmd->rw.control` in lockstep with adding `req->metadata_len` to `req->transfer_len` before `nvmet_req_alloc_sgls()`. [F257, F274, F311]
- In `nvmet_tcp_handle_h2c_data_pdu()`, `exp_data_len` from `le32_to_cpu(data->hdr.plen)` must subtract `sizeof(*data)`, `nvmet_tcp_hdgst_len(queue)`, and `nvmet_tcp_ddgst_len(queue)`. Before `nvmet_tcp_build_pdu_iovec()`, validate that `cmd->pdu_len` is non-zero, equals `exp_data_len`, and `<= NVMET_TCP_MAXH2CDATA`, and that `le32_to_cpu(data->data_offset) == cmd->rbytes_done`. [F262, F263]
- In `nvmet_tcp_try_send_one()` and `nvmet_tcp_try_recv_one()`, `cmd->state` and `queue->rcv_state` checks must remain sequential `if` statements (not `else if`/`switch`). In `nvmet_tcp_io_work()`, return immediately on negative return from `nvmet_tcp_try_recv()`/`nvmet_tcp_try_send()` without requeuing `io_work`, and requeue `queue->io_work` when `pending` is true at `ops >= NVMET_TCP_IO_WORK_BUDGET` or `nvmet_tcp_check_queue_deadline()` (which must use `!time_after(jiffies, queue->poll_end)`). [F295, F296, F302]
- In `nvmet_tcp_alloc_queue()`, when TLS is enabled (`NVMET_TCP_Q_TLS_HANDSHAKE`), `sk->sk_user_data` and `sk->sk_data_ready` inherited from the listener must be reset to `NULL` and `port->data_ready` before `nvmet_tcp_try_peek_pdu()` and `nvmet_tcp_tls_handshake()`. `nvmet_tcp_restore_socket_callbacks()` must guard with `if (!queue->state_change) return;`. [F252, F253]
- `nvme_tcp_pdu_sizes[]`, `nvmet_tcp_pdu_valid()`, and `nvmet_tcp_done_recv_pdu()` must be updated in lockstep for any H2C PDU type. Lookups in sparse tables (`nvme_tcp_pdu_sizes[]`, `zsa_strs`, `zrasf_strs`) must check both `index < ARRAY_SIZE(table)` and `table[index] != 0/NULL`. [F261, F279]
- In `zns.c`, `nvmet_bdev_zns_enable()` must reject devices where `get_capacity(bd_disk)` is not a multiple of `bdev_zone_sectors(ns->bdev)` or `validate_conv_zones_cb` finds `BLK_ZONE_TYPE_CONVENTIONAL`. In `nvmet_bdev_zone_zmgmt_recv_work()`, `nvmet_bdev_validate_zone_mgmt_recv()` must run before `blkdev_report_zones()`, and every non-`NVME_ZRASF_ZONE_REPORT_ALL` case must have a valid entry in `nvme_zrasf_to_blk_zcond[]`. Every `req_op` from `zsa_req_op()` (`!= REQ_OP_LAST`) must be handled in `nvmet_bdev_execute_zmgmt_send_all()` and (if emulated) `zmgmt_send_scan_cb()`, with `d.zbitmap` allocated as `BITS_TO_LONGS(nr_zones)` `unsigned long`s. [F283, F285, F317, F328]
- In `trace.h`, `parse_nvme_cmd()` must test `opcode == nvme_fabrics_command` before branching on `qid`, and `__assign_req_name()` must populate `__entry->disk` with `strscpy_pad(..., DISK_NAME_LEN)` (or `memset(..., 0, DISK_NAME_LEN)` when `!req->ns`). [F281, F303]

## Synchronization

- In `tcp.c`, softirq socket callbacks (`nvmet_tcp_data_ready`, `nvmet_tcp_write_space`, `nvmet_tcp_state_change`, `nvmet_tcp_listen_data_ready`) must hold `read_lock_bh(&sk->sk_callback_lock)` to read `sk->sk_user_data`, and updates to `sk->sk_user_data` or `sk_*` callbacks must hold `write_lock_bh(&sk->sk_callback_lock)` (`nvmet_tcp_set_queue_sock()` must also verify `sk_state == TCP_ESTABLISHED` under it). `nvmet_tcp_queue.state_lock` must use `spin_lock_bh()`/`spin_unlock_bh()` and nest inside `sk->sk_callback_lock`; `nvmet_tcp_schedule_release_queue()` transitions to `NVMET_TCP_Q_DISCONNECTING` and calls `kref_put(&queue->kref, nvmet_tcp_release_queue)` under `state_lock`, so `nvmet_tcp_release_queue()` runs in atomic BH context and must defer sleeping teardown to `queue->release_work`. [F219, F220, F337, F338, F339]
- `nvmet_prepare_receive_pdu()` must clear `WRITE_ONCE(queue->cmd, NULL)` before `smp_store_release(&queue->rcv_state, NVMET_TCP_RECV_PDU)`, pairing with `smp_load_acquire(&queue->rcv_state)` before `READ_ONCE(queue->cmd)` in `nvmet_tcp_queue_response()`. Cross-CPU completions in `nvmet_tcp_queue_response()` must use `llist_add(&cmd->lentry, &queue->resp_list)`, whereas `queue->resp_send_list` and `queue->free_list` are unguarded and must only be modified from `queue->io_work` (or init/teardown). [F341, F342]
- When `nvmet_rdma_recv_done()` sees `queue->state != NVMET_RDMA_Q_LIVE`, `nvmet_rdma_recv_not_live()` must recheck `queue->state` under `spin_lock_irqsave(&queue->state_lock, flags)` before queuing `rsp` on `queue->rsp_wait_list` or calling `nvmet_rdma_put_rsp(rsp)`. `nvmet_rdma_queue_established()` and `nvmet_rdma_process_wr_wait_list()` must drop `queue->state_lock` (`spin_lock_irqsave`) and `queue->rsp_wr_wait_lock`, respectively, before calling `nvmet_rdma_handle_command()` or `nvmet_rdma_execute_command()`. [F223, F231, F330]
- Removals from `nvmet_rdma_queue_list` must hold `nvmet_rdma_queue_mutex`, use `list_for_each_entry_safe()`, and unlink with `list_del_init(&queue->queue_list)`. Callers iterating `nvmet_tcp_queue_list` (`nvmet_tcp_destroy_port_queues`, `nvmet_tcp_delete_ctrl`, `nvmet_tcp_exit`) must only call `kernel_sock_shutdown()` and let `nvmet_tcp_release_queue_work()` unlink `queue->queue_list`. [F286, F287]
- `nvmet_bdev_execute_zone_mgmt_recv()` and `nvmet_bdev_execute_zone_mgmt_send()` must defer work to `zbd_wq` (`WQ_MEM_RECLAIM`), and `nvmet_bdev_zone_mgmt_emulate_all()` must allocate `d.zbitmap` with `GFP_NOIO`. In `nvmet_execute_identify_ns_zns()`, when `nvmet_ns_revalidate(req->ns)` returns true, `nvmet_ns_changed()` requires `mutex_lock(&req->ns->subsys->lock)`. [F344, F345]

## Object Lifetimes

- Listening `nvmet_rdma_port->cm_id` ownership is claimed via `xchg(&port->cm_id, NULL)` between `nvmet_rdma_disable_port()` (calling `rdma_destroy_id(cm_id)` before `nvmet_rdma_destroy_port_queues(port)`) and `nvmet_rdma_device_removal()` (returning 1 for listener `cm_id`s or 0 for queue `cm_id`s). `nvmet_rdma_remove_port()` must call `cancel_delayed_work_sync(&port->repair_work)` before `nvmet_rdma_disable_port(port)`. [F200, F226]
- `nvmet_rdma_cm_handler()` callbacks must never call `rdma_destroy_id(queue->cm_id)`: `nvmet_rdma_queue_connect()` must set `queue->cm_id = NULL` before `nvmet_rdma_free_queue()` on accept failure, and disconnect/connect-failure paths must defer `nvmet_rdma_free_queue()` to `queue->release_work` on `nvmet_wq`. In `nvmet_rdma_free_queue()` and `nvmet_rdma_release_queue_work()`, `ib_drain_qp(queue->qp)` must complete before `nvmet_rdma_destroy_queue_ib()`, freeing `cmds`/`rsps`, and `kref_put(&dev->ref, nvmet_rdma_free_dev)`. [F201, F227, F331]
- `nvmet_rdma_init()` registers `nvmet_rdma_ib_client` before `nvmet_rdma_ops`, and `nvmet_rdma_exit()` unregisters in reverse order before `ida_destroy(&nvmet_rdma_queue_ida)`. `nvmet_rdma_remove_one()` must disconnect all queues on the `ib_device` and call `flush_workqueue(nvmet_wq)` before returning. `nvmet_rdma_put_rsp()` requires `rsp->queue` to be set before checking `rsp->tag == NVMET_RDMA_DISCRETE_RSP_TAG`. [F203, F205, F318]
- When `nvmet_req_init()` fails in `nvmet_tcp_done_recv_pdu()` on an inline-write command, `nvmet_tcp_queue_response()` defers queuing `cmd` while `rcv_state == NVMET_TCP_RECV_PDU`, and `nvmet_tcp_handle_req_failure()` maps a receive buffer and sets `NVMET_TCP_F_INIT_FAILED` so `nvmet_tcp_execute_request()` queues `cmd` after draining inline data. [F207]
- Before `nvmet_tcp_install_queue()` succeeds (or if `nvmet_tcp_alloc_cmds()` fails), `queue->nr_cmds` must be 0 and the queue uses `queue->connect`; `nvmet_tcp_put_cmd()` must not return `queue->connect` to `queue->free_list`, while `nvmet_tcp_free_cmds()` and `nvmet_tcp_free_cmd_data_in_buffers()` must clean up both `queue->cmds` and `queue->connect`. `nvmet_tcp_free_cmd_buffers()` must set `cmd->iov = NULL` and `cmd->req.sg = NULL` after freeing them. [F208, F212, F238]
- `nvmet_tcp_alloc_queue()` must initialize `tls_handshake_tmo_work`, `release_work`, and `io_work` unconditionally. In `nvmet_tcp_release_queue_work()`, `nvmet_tcp_uninit_data_in_cmds()` must run between the first `cancel_work_sync(&queue->io_work)` and `nvmet_sq_destroy(&queue->nvme_sq)`, and a second `cancel_work_sync(&queue->io_work)` must run after `nvmet_sq_destroy()` before freeing buffers, `fput()`, and `nvmet_tcp_free_cmds()`. [F209, F217]
- `nvmet_tcp_remove_port()` must restore `sk_data_ready` and clear `sk_user_data = NULL` under `write_lock_bh(&port->sock->sk->sk_callback_lock)`, then `cancel_work_sync(&port->accept_work)` before `nvmet_tcp_destroy_port_queues(port)` and `sock_release(port->sock)`. `nvmet_tcp_exit()` must unregister `nvmet_tcp_ops`, flush `nvmet_wq`, shut down all sockets on `nvmet_tcp_queue_list`, and flush `nvmet_wq` again before destroying `nvmet_tcp_wq` and `nvmet_tcp_queue_ida`. [F326, F327]

## API Contracts

- `nvmet_rdma_rw_ctx_init()` returns a negative errno or positive WR count; `nvmet_rdma_map_sgl_keyed()` must store it in a signed `int`, check `ret < 0`, and add it to `rsp->n_rdma`. When `req->metadata_len` is non-zero, `nvmet_rdma_rw_ctx_init()`/`nvmet_rdma_rw_ctx_destroy()` must use the `_signature` variants, and `nvmet_rdma_queue_response()` must pass `&rsp->write_cqe` (not `&rsp->send_wr`) to `rdma_rw_ctx_wrs()`. `cmd->sge[0]` and `rsp->send_sge` stay DMA-mapped and require `ib_dma_sync_single_for_cpu()` before CPU access and `ib_dma_sync_single_for_device()` before posting WRs. [F244, F334, F351]
- In `nvmet_bdev_zone_mgmt_emulate_all()`, the positive zone count from `blkdev_report_zones()` must be converted to `-EIO` when `ret != nr_zones` and `0` when `ret == nr_zones`. `nvmet_zasl()` and `nvmet_execute_identify_ctrl_zns()` express `zasl` as `ilog2` in 4 KiB page units (`NVMET_MPSMIN_SHIFT = 12`). In `nvmet_bdev_zone_append_bio_done()`, on `BLK_STS_OK`, store `nvmet_sect_to_lba(req->ns, bio->bi_iter.bi_sector)` in `req->cqe->result.u64` before `nvmet_req_complete()`. [F234, F359, F362]
- In `nvmet_rdma_disc_port_addr()` and `nvmet_tcp_disc_port_addr()`, when `inet_addr_is_any()` is true, `traddr` must be formatted with `%pISc` from the queue's local address. Each transport module must declare `MODULE_ALIAS("nvmet-transport-<type>")` matching `nvmet_fabrics_ops.type`. Every `trace_seq` helper in `trace.c` must call `trace_seq_putc(p, 0)` before returning `trace_seq_buffer_ptr(p)`. [F306, F364, F365]

## Error Handling

- Before Fabrics Connect, `queue->nvme_sq.ctrl` is NULL, so `nvmet_rdma_error_comp()` and `nvmet_tcp_fatal_error()` must check `queue->nvme_sq.ctrl` before calling `nvmet_ctrl_fatal_error()` and otherwise disconnect the queue or shut down the socket directly. When `nvmet_tcp_map_data()` fails in `nvmet_tcp_done_recv_pdu()` and `!nvmet_tcp_has_inline_data(queue->cmd)`, it must call `nvmet_req_complete(req, ret)` and `nvmet_prepare_receive_pdu()` and return `-EAGAIN`. [F242, F294]

## External Contracts

- In `nvmet_rdma_parse_cm_connect_req()`, 0-based `req->hsqsize` is incremented by 1 for `queue->recv_queue_size`, whereas 1-based `req->hrqsize` is assigned directly to `queue->send_queue_size`. In `nvmet_execute_identify_ns_zns()`, 1-based `bdev_max_open_zones()` and `bdev_max_active_zones()` (0 = no limit) must map 0 to `U32_MAX` and decrement non-zero values by 1 for `id_zns->mor` and `id_zns->mar`. [F268, F276]
- In `nvmet_bdev_zone_zmgmt_recv_work()`, `rz_data.nr_zones` must be clamped to `rz_data.out_nr_zones` when `req->cmd->zmr.pr` is set. In `nvmet_bdev_zmgmt_send_work()`, `req->cmd->zms.select_all` must be dispatched via `nvmet_bdev_execute_zmgmt_send_all()` before validating `sect` against capacity or zone alignment. [F259, F282]

## Known Pitfalls

- In `nvmet_tcp_queue_response()` and `nvmet_tcp_handle_req_failure()`, check `req->cmd->common.dptr.sgl.length` directly rather than `nvmet_tcp_has_inline_data(cmd)` because `cmd->pdu_len` is 0 when `nvmet_req_init()` fails. In `nvmet_tcp_handle_icreq()`, read all `icreq` fields before `memset(icresp, 0, sizeof(*icresp))` (which aliases `queue->pdu`), and in `nvmet_tcp_verify_hdgst()`, sample `recv_digest` at `pdu + hdr->hlen` before `nvmet_tcp_hdgst(pdu, len)` overwrites it in place. [F239, F241, F251]
- In `tcp.c`, cast typed PDU/digest pointers to `void *` or `u8 *` before adding `offset`, and convert `__le32`/`__le16` header fields with `cpu_to_le32()`/`le32_to_cpu()`. In `nvmet_rdma_map_sgl_keyed()`, decode `struct nvme_keyed_sgl_desc` with `get_unaligned_le24(sgl->length)` and `get_unaligned_le32(sgl->key)`. Keep error-unwind loop index `i` signed (`int`) in `nvmet_tcp_alloc_cmds()`, `nvmet_rdma_alloc_cmds()`, `nvmet_rdma_alloc_rsps()`, `nvmet_rdma_init_srqs()`, and `nvmet_rdma_alloc_inline_pages()`, and guard `bufsize <= sizeof(struct nvme_zone_report)` in `get_nr_zones_from_buf()`. [F267, F277, F280, F298, F310]
- In `trace.h`, null-check `req->sq`, `req->sq->ctrl`, and `req->ns` in `nvmet_req_to_ctrl_id()` and `__assign_req_name()`, and copy 24 bytes from `&cmd->common.cdws` (not `&cmd->common.cdw10`) in `TRACE_EVENT(nvmet_req_init)`. In `trace.c`, `cdw10`/`spc` are `u8 *` byte pointers, so `cdwN` is at byte offset `(N - 10) * 4` via `get_unaligned_le16/32/64()`. [F304, F305, F347]
