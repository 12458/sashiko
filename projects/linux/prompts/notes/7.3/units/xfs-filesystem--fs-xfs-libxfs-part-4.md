# XFS FILESYSTEM — fs/xfs/libxfs (part 4)

Provides core shared XFS metadata algorithms and on-disk/UAPI format definitions (`xfs_format.h`, `xfs_fs.h`), including shortform and node-format directory manipulation (`xfs_dir2_sf.c`, `xfs_dir2_node.c`), inode allocation and inobt/finobt B+trees (`xfs_ialloc.c`, `xfs_ialloc_btree.c`), and the in-core B+tree for inode extent maps (`xfs_iext_tree.c`). It also implements atomic file mapping exchange intents (`xfs_exchmaps.c`), dquot buffer verification (`xfs_dquot_buf.c`), generic per-AG/RT-group reference management (`xfs_group.c`), and health/error-injection definitions (`xfs_health.h`, `xfs_errortag.h`).

## Architecture & Data Flow

- Containers inserted into `mp->m_groups` via `xfs_group_insert()` (`xfs_perag`, `xfs_rtgroup`) must embed `struct xfs_group` at offset 0 for `kfree_rcu_mightsleep(xg)` in `xfs_group_free()`. Because `xg_busy_extents` and `xg_next_reset` share a union, guard `xg_busy_extents` alloc/free with `xfs_group_has_extent_busy(mp, type)`. [F35, F119]
- In `xfs_iext_tree.c`, at `ifp->if_height == 1`, `ifp->if_data` lacks `prev`/`next` pointers until `RECS_PER_LEAF`; bound leaf indices by `xfs_iext_max_recs(ifp)` and only access `leaf->next`/`prev` when `if_height > 1`. Inner nodes (`xfs_iext_node`) mark unused keys with `XFS_IEXT_KEY_INVALID` (`1ULL << 63`) rather than `0`, leaves detect empty slots via `rec->hi == 0`, reading file offsets from `rec->lo` must mask with `XFS_IEXT_STARTOFF_MASK`, and any change to `pos == 0` in an existing leaf or node must call `xfs_iext_update_node()` to update ancestor separator keys. [F61, F86, F87, F103]
- In `xfs_dir2_sf.c`, keep `sfp->i8count` equal to the count of entries (including parent) with `ino > XFS_DIR2_MAX_SHORT_INUM` and `dp->i_disk_size == dp->i_df.if_bytes`, calling `xfs_dir2_sf_toino4()`/`toino8()` when `i8count` crosses 0 and 1. Read/write shortform inos via unaligned big-endian accessors (`get`/`put_unaligned_be32`/`64`) at `sfep->name + sfep->namelen + (xfs_has_ftype(mp) ? 1 : 0)`. In `xfs_dir2_sf_verify()`, validate `(char *)sfep + sizeof(*sfep) < endp` and `sfep->namelen > 0` before `xfs_dir2_sf_nextentry()` and `endp < (char *)next_sfep`. [F65, F77, F126]
- In `xfs_dir2_node_replace()`, save `args->inumber` and `args->filetype` before `xfs_da3_node_lookup_int()` overwrites them. In `xfs_dir2_node_addname_int()` and `xfs_dir2_leafn_remove()`, if a data block's `bf[0].length` changes, update and log `freehdr.bests[findex]` (and `nvalid`/`nused`). [F66, F67]
- In `xfs_dialloc_ag_inobt()`, when `useleft && trec.ir_freecount`, set `pag->pagl_leftrec = trec.ir_startino` and `pag->pagl_rightrec = rec.ir_startino` before `rec = trec`. When `doneleft && doneright` with `searchdistance > 0`, reset `pagl_pagino`, `pagl_leftrec`, and `pagl_rightrec` to `NULLAGINO` and delete `tcur` and `cur` before `goto restart_pagno`. [F54, F55]
- In `xfs_ialloc_ag_alloc()`, call `xfs_inobt_insert_sprec()` before `xfs_finobt_insert_sprec()` so sparse `rec` is merged in `inobt` before updating `finobt`; also reset `args.minalignslop = 0` after `xfs_alloc_vextent_exact_bno()` before fallback `xfs_alloc_vextent_near_bno()` increases `args.alignment`. Across `xfs_ialloc.c`, bound AG block numbers with `xfs_ag_block_count(mp, pag_agno(pag))` rather than `mp->m_sb.sb_agblocks`, and keep `xfs_ialloc_log_agi()` `offsets[]` and `XFS_AGI_*_R1`/`R2` masks synced with `struct xfs_agi` (`XFS_AGI_IBLOCKS` logs both `agi_iblocks` and `agi_fblocks`). [F57, F58, F60, F73]
- In `xfs_exchmaps_finish_one()`, recheck `xmi_has_more_exchange_work(xmi)` after `xfs_exchmaps_find_mappings()` before calling `xfs_exchmaps_one_step()`, and return `-EAGAIN` if either `xmi_has_more_exchange_work(xmi)` or `xmi_has_postop_work(xmi)` is true. In `xfs_exchmaps_one_step()`, `xfs_exchmaps_update_size()` must advance `i_disk_size` using `irec2` for `xmi_ip1` and `irec1` for `xmi_ip2` after swapping `br_startoff`. In `xmi_delta_nextents_step()`, when `(state & CBOTH_CONTIG) == CBOTH_CONTIG` or `(state & NBOTH_CONTIG) == NBOTH_CONTIG`, clear `CRIGHT_CONTIG`/`NRIGHT_CONTIG` if `!xmi_can_merge_all()`. [F69, F90, F101]
- In `xfs_format.h`: bound non-NUL-terminated `sb_fname` and `rsb_fname` accesses to `XFSLABEL_MAX` (12); keep `sb_icount`, `sb_ifree`, `sb_fdblocks`, and `sb_frextents` contiguous in `xfs_sb`/`xfs_dsb` for `xfs_trans_apply_sb_deltas()`; and set `XFS_SB_VERSION_MOREBITSBIT` in `sbp->sb_versionnum` whenever setting a bit in V4 `sbp->sb_features2`. [F130, F131, F155]

## Synchronization

- `xfs_group_insert()` must initialize all `struct xfs_group` fields and set `xg_active_ref` to 1 before `xa_insert(&mp->m_groups[type].xa, ...)`. Hold `xg->xg_state_lock` when accessing `xg_checked` or `xg_sick`. [F25, F28]
- `xfs_ialloc_read_agi()` must set `pag->pagi_freecount` and `pag->pagi_count` before setting `XFS_AGSTATE_AGI_INIT`. After `xfs_dialloc_good_ag()` checks `pagi_freecount` locklessly, `xfs_dialloc_try_ag()` must lock the AGI via `xfs_ialloc_read_agi()` and recheck `pagi_freecount` before `xfs_dialloc_ag()`. [F29, F31]
- Callers of `xfs_exchange_mappings()` and `xfs_exchmaps_estimate()` must flush `req->ip1` and `req->ip2` and hold `XFS_ILOCK_EXCL` on both (and join them to `tp` for `xfs_exchange_mappings()`) so no `DELAYSTARTBLOCK` extents exist. Every in-core extent tree mutation (`xfs_iext_insert_raw()`, `xfs_iext_remove()`, `xfs_iext_update_extent()`) must call `xfs_iext_inc_seq(ifp)`. [F32, F33]

## Object Lifetimes

- `xfs_group_get()`/`hold()` increment passive `xg_ref` (dropped by `xfs_group_put()`), while `xfs_group_grab()`/`grab_next_mark()` use `atomic_inc_not_zero(&xg->xg_active_ref)` (dropped by `xfs_group_rele()`); hold `rcu_read_lock()` across the XArray lookup and ref increment. On `xa_insert()` failure, `xfs_group_insert()` cleans up internal fields without freeing `xg`; `xfs_group_free()` (sleepable context only) calls `xfs_group_rele(xg)` and `kfree_rcu_mightsleep(xg)`. [F1, F3, F26, F27, F136]
- In `xfs_dir2_node.c`: if `xfs_dir3_free_header_check()` fails in `__xfs_dir3_free_read()`, call `xfs_trans_brelse(tp, *bpp)` and set `*bpp = NULL`; in `xfs_dir2_node_find_freeblk()`, if `fblk && fblk->index < 0`, `brelse(tp, fbp)` and clear `fbp = fblk->bp = NULL`; in `xfs_dir2_node_trim_free()`, if `freehdr.nused > 0` or `xfs_dir2_shrink_inode()` fails, `brelse(tp, bp)`. When `xfs_dir2_shrink_inode()` succeeds, it invalidates the buffer: clear `dblk->bp = NULL` and `hdr = NULL` in `xfs_dir2_leafn_remove()`, clear `fbp = NULL` and `logfree = 0` in `xfs_dir3_data_block_free()`, and in `xfs_dir2_block_to_sf()` copy `bp->b_addr` into `sfp` before `xfs_dir2_shrink_inode()` and `kfree(sfp)` on all paths. [F4, F5, F6, F8, F12]
- Before `xfs_da_state_free(state)`, `xfs_dir2_node_lookup()` and `xfs_dir2_node_replace()` must `xfs_trans_brelse()` all `state->path.blk[i].bp` and unlogged `state->extrablk.bp` (when `extravalid`). In `xfs_dir2_leafn_lookup_for_entry()`, do not `brelse(tp, curbp)` when advancing or exiting if `curbp == state->extrablk.bp` from a prior case-insensitive match. [F7, F102]
- In `xfs_dir2_sf_addname_easy()`, save `byteoff = (char *)sfep - (char *)sfp` before `xfs_idata_realloc()` and recompute `sfep` from the new `sfp`. In `xfs_dir2_sf_addname_hard()`, `toino4()`, and `toino8()`, copy `if_data` to `kmalloc` `buf`, call `xfs_idata_realloc(dp, -oldsize, ...)` then `xfs_idata_realloc(dp, newsize, ...)`, and `kfree(buf)`. [F9, F10]
- `xfs_exchmaps_estimate()` must free `xmi` via `kmem_cache_free(xfs_exchmaps_intent_cache, xmi)` on all paths, whereas `xfs_exchange_mappings()` hands `xmi` to `xfs_exchmaps_defer_add(tp, xmi)`. In `xfs_exchmaps_link_to_sf()`, allocate `ip->i_disk_size + 1` bytes for `buf` (for NUL from `xfs_symlink_remote_read()`), call `xfs_symlink_remote_truncate()` then `xfs_idestroy_fork(ifp)` before `xfs_init_local_fork(..., ip->i_disk_size)`, and `kfree(buf)` on all paths. [F14, F15, F133]
- `xfs_inobt_init_cursor()` and `xfs_finobt_init_cursor()` hold `cur->bc_group` (freed by `xfs_btree_del_cursor()`), but borrow `agbp` in `cur->bc_ag.agbp`, which callers must `xfs_trans_brelse()`. In `xfs_dialloc_ag_finobt_near()`, if `rcur` wins over `lcur = *ocur`, delete `lcur` and set `*ocur = rcur`; else delete `rcur` and leave `*ocur` for the caller. In `xfs_dialloc_roll()`, `xfs_trans_bhold(tp, agibp)` and save/clear `tp->t_dqinfo` before `xfs_trans_roll(&tp)`, then restore `t_dqinfo`, `xfs_trans_bjoin(tp, agibp)` even on error, and set `*tpp = tp`. [F17, F19, F21]
- In `xfs_iext_realloc_root()` (`if_height == 1`), expand `new_size` to `NODE_SIZE` at `RECS_PER_LEAF`, `memset` the grown tail `[ifp->if_bytes, new_size)` to 0, and update both `ifp->if_data` and `cur->leaf` to `new`. `xfs_iext_free_last_leaf()` frees `if_data`, sets `if_data = NULL`, and decrements `if_height` when empty. In `xfs_iext_rebalance_leaf()`, redirect `cur->leaf` to the surviving sibling and adjust `cur->pos` before `xfs_iext_remove_node()` frees a merged leaf. `xfs_iext_destroy()` recursively frees subtrees at `level > 1` (up to `XFS_IEXT_KEY_INVALID`) and zeroes `if_bytes`, `if_height`, and `if_data`. [F22, F23, F24, F53, F122]

## API Contracts

- `xfs_group_next_range()` and `xfs_group_grab_next_mark()` consume `@xg`'s `xg_active_ref` via `xfs_group_rele(xg)`, so loops breaking early (including `for_each_perag_wrap_at()`) must release `@xg` themselves. Verify `XG_TYPE_AG` or `XG_TYPE_RTG` before calling `to_perag()` or `to_rtg()`. [F2, F120]
- `xfs_ialloc_read_agi()` returns locked `*agibpp` when non-NULL, or releases it via `xfs_trans_brelse()` when `agibpp == NULL`. `xfs_difree()` only sets `xic->first_ino` and `xic->alloc` when `xic->deleted` is `true`. `XFS_INOBT_REC_ADDR()`, `KEY_ADDR()`, and `PTR_ADDR()` take a 1-based `index`, and `xfs_finobt_calc_reserves()` adds to `*ask` and `*used` with `+=` (callers must initialize them). [F18, F44, F45, F49]
- `__xfs_dir3_free_read()` must call `xfs_dir3_free_header_check(*bpp, owner, fbno)` after `xfs_da_read_buf()`; callers of `xfs_dir2_free_try_read()` must check both `error` and `*bpp == NULL` (holes). In `xfs_dir2_sf.c`, set `sfp->i8count` before calling `xfs_dir2_sf_put_parent_ino()`, `firstentry()`, `nextentry()`, or `put_ino()`, and use `xfs_dir2_sf_hdr_size(i8count)` rather than `sizeof(struct xfs_dir2_sf_hdr)`. Check `size <= xfs_inode_data_fork_size(dp)` after `xfs_dir2_block_sfsize()` before using `sfhp` in `xfs_dir2_block_to_sf()`. [F50, F51, F78, F123]
- Zero-initialize output fields of `struct xfs_exchmaps_req` before `xfs_exchmaps_estimate()`. `xmi_isize1`/`xmi_isize2` use `-1` as a no-update sentinel (`xfs_exchmaps_update_size()` returns early if `new_isize < 0`). `xfs_exchmaps_find_mappings()` clamps `irec1->br_blockcount` and calls `xmi_advance()` over skipped/equal mappings, but callers must call `xmi_advance()` after handling a returned differing pair. [F40, F42, F89]
- `xfs_iext_remove()` leaves `cur` at the extent immediately following the removed extent (do not call `xfs_iext_next()` to reach it). When `cur->leaf == NULL`, `xfs_iext_prev()` resets `cur` to `xfs_iext_last(ifp, cur)` and `xfs_iext_next()` resets `cur` to `xfs_iext_first(ifp, cur)`. [F92, F93]
- `xfs_dquot_verify()` and `xfs_dqblk_verify()` treat `id == -1` as a wildcard, whereas `xfs_dqblk_repair()` requires `id != -1`. `xfs_dquot_buf_write_verify()` must only call `xfs_dquot_buf_verify()` without computing CRCs. Runtime corruption paths must call `xfs_*_mark_sick()`, reserving `xfs_*_mark_corrupt()`/`mark_healthy()` for fsck/scrub. [F39, F148, F157]

## Error Handling

- In `xfs_dir2_sf_replace()`, if `xfs_dir2_sf_toino8(args)` ran (`i8elevated = 1`) and the entry is not found, roll back via `xfs_dir2_sf_toino4(args)` before returning `-ENOENT`. In `xfs_dqinode_load()`, if validation fails after `ip` is loaded, call `xfs_irele(ip)` before returning an error. [F11, F13]
- Verifiers returning `xfs_failaddr_t` must return `NULL` on success and `__this_address` / `fa` on corruption. Post-read checks in `xfs_dir2_node.c` (outside `xfs_buf_ops`) must call `__xfs_buf_mark_corrupt()`/`xfs_buf_mark_corrupt()` rather than `xfs_verifier_error()`. In `xfs_inobt_init_cursor()` and `xfs_finobt_init_cursor()`, check `agbp != NULL` (staging cursors pass `NULL`) before reading `agbp->b_addr`. [F34, F43, F146]
- In `xfs_dialloc()`, reset `error = 0` when `xfs_dialloc_try_ag()` returns `-EAGAIN`, and clear `flags = 0` (setting `ok_alloc = true` if `low_space`) before `goto retry` after a trylock pass. Before returning, verify `ino != parent && xfs_verify_dir_ino(mp, ino)`, marking `XFS_SICK_AG_INOBT` and returning `-EFSCORRUPTED` on failure. [F95, F151]

## External Contracts

- In `xfs_fs.h`, preserve `XFS_IOC_GETXFLAGS`, `SETXFLAGS`, `GETVERSION`, `FSGETXATTR`, and `FSSETXATTR`, keep `xfs_attrlist` and `xfs_attrlist_ent` layout-compatible with `libattr`, and keep `xfs_bulkstat` timestamp seconds signed `int64_t` with `bs_pad2`/`bs_pad[6]` zeroed. [F75, F145, F159]

## Known Pitfalls

- Never use `sizeof(struct xfs_btree_block)` for on-disk header size; use `XFS_BTREE_SBLOCK_LEN`/`LBLOCK_LEN`/`CRC_LEN` (or `XFS_INOBT_BLOCK_LEN(mp)`), and only access v5 fields (`bb_blkno`, `bb_crc`, `bb_lsn`, `bb_owner`, `bb_uuid`) when `xfs_has_crc(mp)`. `finobt` helpers (`xfs_finobt_count_blocks()`, `dup_cursor()`, `insert_sprec()`, `xfs_dialloc_ag()`, `xfs_difree_finobt()`) must call `xfs_finobt_init_cursor()`, not `xfs_inobt_init_cursor()`. [F82, F88]
- On sparse inobt records (`xfs_inobt_issparse(irec->ir_holemask)`), mask `ir_free` with `xfs_inobt_irec_to_allocmask(irec)` to exclude holes (`1` in `ir_holemask` = hole, `1` in `ir_free` = free). Mask `~rec->ir_holemask` with `((1 << XFS_INOBT_HOLEMASK_BITS) - 1)` in `unsigned long` (`DECLARE_BITMAP` for `find_first_zero_bit()`) or `uint` (with word count for `xfs_next_bit()`), and make `inodespbit` `uint64_t` before shifting. [F83, F107, F132]
- Cast `xg->xg_gno` to `xfs_fsblock_t` before shifting/multiplying in `xfs_group_start_fsb()` and `xfs_gbno_to_daddr()`; return `0` if `!mp->m_groups[type].blklog` in `xfs_fsb_to_gno()`; and reject `glen == 0` before `check_add_overflow(gbno, glen - 1, &end)` in `xfs_verify_gbext()`. [F104, F105, F106]
- In `xfs_ialloc*.c` and `xfs_format.h`: check `inobt_mxr[0] != 0` and cast `agblocks` to `uint64_t` in `xfs_inobt_max_size()`; guard `n >= XFS_INODES_PER_CHUNK` in `xfs_inobt_maskn(i, n)`; use `1ULL`/`1LL` in `XFS_INO_MASK(k)` and `xfs_ialloc_setup_geometry()`; check `sb_imax_pct && ialloc_blks` and use `do_div()` on `icount` in `xfs_ialloc_setup_geometry()`; use `howmany(4 * sb_sectsize, sb_blocksize)` in `xfs_ialloc_calc_rootino()`; and use `(atomic_inc_return(&mp->m_agirotor) - 1) % mp->m_maxagi` in `xfs_dialloc_pick_ag()`. [F74, F108, F109, F110, F111, F112]
- In `xfs_dir2_sf_removename()`, `memmove()` trailing entries before shrinking with `xfs_idata_realloc()`. For `xfs_dir3_icleaf_hdr` and `xfs_dir3_icfree_hdr`, use `sizeof(ents[0])` and `sizeof(bests[0])` rather than `sizeof(hdr.ents)` or `sizeof(hdr.bests)`. [F125, F127]
- In `xfs_exchmaps.c`: use `isaligned_64()`, `roundup_64()`, and `rounddown_64()` with `sb_rextsize` in `xfs_exchmaps_can_skip_mapping()`; use `howmany_64(req->nr_exchanges, ...)` in `xfs_exchmaps_bmbt_blocks()`/`rmapbt_blocks()`; return `0` when `delta < 0` in `xmi_ensure_delta_nextents()` and pass `d_nexts1 + d_nexts2` when `ip1 == ip2`; and use ceiling `XFS_B_TO_FSB()` in `xmi_can_exchange_reflink_flags()`. [F113, F114, F115, F116]
- In `xfs_dquot_buf.c`: add `XFS_DQ_BIGTIME_SLACK` before `>> XFS_DQ_BIGTIME_SHIFT` in `xfs_dq_unix_to_bigtime()`, test 64-bit `timer != 0` (not truncated `t != 0`) in `xfs_dquot_to_disk_ts()`, and fall back to `xfs_calc_dquots_per_chunk(bp->b_length)` when `mp->m_quotainfo == NULL` in dquot buffer verifiers. [F117, F149]
