# SOUND — include/sound (part 1)

This component defines core ALSA headers, hardware abstractions, and device interfaces for sound cards, PCM streams, mixer controls, AC'97, HD-Audio (HDA), DMA memory allocation, and legacy ISA/PCI codecs.

## Architecture & Data Flow

- In `struct snd_kcontrol`, `vd[]` is `__counted_by(count)`: allocate via `struct_size(..., vd, count)`, set `kctl->count = count` before indexing `vd[]`, and copy `vd[]` with explicit `memcpy`. Once added to a card, rename only via `snd_ctl_rename()` or `snd_ctl_rename_id()` so `card->ctl_hash` and `card->ctl_numids` update in lockstep. In `struct snd_ctl_elem_id`, `numid` is 1-based (`0` is invalid) while `index` and `vd[]` offset `ioff` are 0-based; `snd_ctl_build_ioff()` adds a 0-based `offset` to both `id.index` and `id.numid`. [F44, F57, F97]
- Userspace control element allocations (`SNDRV_CTL_ELEM_ACCESS_USER`: data, enum `names_length`, TLV buffers) must check `max_user_ctl_alloc_size` and update `card->user_ctl_alloc_size` under `card->controls_rwsem` write lock on both allocation and replacement/free paths. [F147]
- Updating or clearing a substream DMA buffer must use `snd_pcm_set_runtime_buffer()` so `runtime->dma_buffer_p` and cached `dma_area`, `dma_addr`, and `dma_bytes` stay synchronized. In `snd_pcm_runtime`, `status->hw_ptr` and `control->appl_ptr` wrap modulo `runtime->boundary` (not `buffer_size`), so `snd_pcm_playback_avail()` and `snd_pcm_capture_avail()` must adjust `< 0` or `>= runtime->boundary` differences by `runtime->boundary`. [F46, F63]
- `snd_mask_leave(mask, val)` must sample `mask->bits[MASK_OFS(val)] & MASK_BIT(val)` before zeroing `mask` with `snd_mask_none()`, preserving whether `val` was previously set. [F52]
- In `struct hdac_bus`, `caddr_tbl` has `HDA_MAX_CODEC_ADDRESS + 1` (16) slots (`0..0x0f`), whereas `corb.cmds`/`res`, `rirb.cmds`/`res`, and `last_cmd` have only `HDA_MAX_CODECS` (8) slots (`HDA_CODEC_IDX_CONTROLLER` = 8 is a virtual controller index). Broken by: indexing `rirb` or `last_cmd` with `addr >= HDA_MAX_CODECS`. [F71]
- `struct nhlt_endpoint` and `struct nhlt_fmt_cfg` end with variable-length `struct nhlt_specific_cfg config` (`u32 size; u8 caps[];`): iterate `nhlt->desc` by `(u8 *)epnt + epnt->length` and `fmt->fmt_config` by `cfg->config.caps + cfg->config.size`, never pointer increment or indexing. [F67]
- When parsing ELD into `struct snd_parsed_hdmi_eld`, check `mnl <= ELD_MAX_MNL` (16), `ELD_FIXED_BYTES + mnl <= size`, and `ELD_FIXED_BYTES + mnl + 3 * (i + 1) <= size` for each SAD (`i < sad_count`, max `ELD_MAX_SAD` = 16), and read `port_id`, `manufacture_id`, and `product_id` via `get_unaligned_le*()`. [F68]
- In `include/sound/jack.h`, `enum snd_jack_types` switch bits (bits 0..6, `SND_JACK_SWITCH_TYPES` = 7) and button bits (`SND_JACK_BTN_0`..`SND_JACK_BTN_5`) must stay synchronized with `jack_switch_types[]` and `struct snd_jack.key[6]` in `sound/core/jack.c`. [F73]
- In `include/sound/emu10k1.h`, `SUB_REG()` / `SUB_REG_NC()` require a non-zero contiguous bitmask with shift and width each `<= 31`. Broken by: passing `0`, non-contiguous bits, or `0xffffffff` (width 32 overflows 5-bit `REG_SIZE`). [F74]

## Synchronization

- `snd_pcm_start()`, `snd_pcm_stop()`, `snd_pcm_drain_done()`, `__snd_pcm_set_state()` (which must update both `runtime->state` and mmap `runtime->status->state`), and `snd_pcm_period_elapsed_under_stream_lock()` require holding `snd_pcm_stream_lock*`, whereas `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` acquire `pcm_stream_lock_irqsave` internally and must be called unlocked. [F16, F18, F125]
- When `pcm->nonatomic` is false, `snd_pcm_ops` callbacks under `snd_pcm_stream_lock*` (`trigger`, `pointer`, `get_time_info`, `ack`) hold spinlock `substream->self_group.lock` with IRQs disabled and must not sleep; when `pcm->nonatomic` is true, `snd_pcm_stream_lock*` locks `self_group.mutex`, so `snd_pcm_period_elapsed()` and `snd_pcm_stop_xrun()` sleep and cannot run in atomic/IRQ context. [F122, F123]
- Locking a second `snd_pcm_substream` under another substream lock must use `snd_pcm_stream_lock_irqsave_nested()`. Because `snd_pcm_group` (`group->lock`/`mutex`) orders outside `substream->self_group`, locking `substream->group` while holding `self_group` must pin `group->refs` on trylock failure, drop the substream lock to lock `group` then relock `substream`, and recheck `substream->group == group`. [F17, F19]
- PCM user copy paths (`__snd_pcm_lib_xfer`) must not hold `runtime->buffer_mutex` (which nests inside `mm->mmap_lock` in OSS mmap), and instead guard the buffer via `runtime->buffer_accessing` while buffer-changing paths call `snd_pcm_buffer_access_lock()` before locking `buffer_mutex`. [F126]
- In the control core, call `snd_power_ref_and_wait(card)` before locking `card->controls_rwsem` (and `snd_power_unref(card)` after unlocking); `card->controls_rwlock` nests inside `controls_rwsem`, and `snd_ctl_file.read_lock` (guarding `ctl->events`) nests inside `controls_rwlock`. `snd_ctl_find_numid()`, `snd_ctl_find_id()`, and `snd_ctl_find_id_mixer()` return unreferenced pointers, so callers must hold `controls_rwsem` while dereferencing them. `snd_ctl_notify()` is IRQ-safe, whereas `snd_ctl_notify_one()` takes sleeping `snd_ctl_layer_rwsem` and requires process context. [F15, F128, F129, F130]
- `snd_hdac_stream_release_locked()` and `snd_hdac_ext_stream_decouple_locked()` require holding `bus->reg_lock`, while `snd_hdac_stream_assign()`, `snd_hdac_stream_release()`, and `snd_hdac_ext_stream_assign()`/`release()`/`decouple()` lock `bus->reg_lock` internally. `snd_hdac_bus_exec_verb_unlocked()` requires holding `bus->cmd_mutex` in process context, and `hdac_bus_eml_*_unlocked()` / `hdac_bus_eml_sdw_*_unlocked()` require holding `hdac_bus_eml_get_mutex(bus, alt, elid)`. [F26, F134, F135]
- `struct snd_i2c_bus` must use `snd_i2c_lock(bus)` / `snd_i2c_unlock(bus)` (never `bus->lock_mutex` directly) to route slave buses to `bus->master->lock_mutex`. `snd_gf1_select_voice()` must hold `gus->active_voice_lock`, and `snd_emu1010_fpga_write()`/`read()`/`link_dst_src_*()` require holding `emu->emu1010.lock` (`guard(snd_emu1010_fpga_lock)(emu)` or `snd_emu1010_fpga_write_lock()`). [F25, F49, F120]

## Object Lifetimes

- `snd_ctl_add()` and `snd_ctl_replace()` consume ownership of `kcontrol` and call `snd_ctl_free_one(kcontrol)` on failure; never free `kcontrol` afterwards. Both `snd_card_ref()` and `snd_lookup_minor_data()` (on non-NULL return with `card_ptr`) acquire `card->card_dev` and require `snd_card_unref(card)`. [F2, F4]
- After `snd_devm_card_new()`, if later devres allocations are used by `card->private_free` or `snd_device` `.dev_free`, any probe failure before `snd_card_register()` must call `snd_card_free()` or `snd_card_free_on_error()`. In `enum snd_device_type`, `SNDRV_DEV_CONTROL` must remain the last enumerator so it registers last, disconnects first, and frees in the second pass of `snd_device_free_all()`. [F106, F107]
- `snd_hda_power_up*` (`snd_hdac_power_up*`) increments the runtime PM count or `codec->core.in_pm` even on error; callers not using `CLASS(snd_hda_power*, pm)(codec)` must still call `snd_hda_power_down*` on failure, whereas `CLASS(...)` always powers down at scope exit and stores any error in `pm.err`. [F7, F37]
- `snd_hdac_device_init()` initializes `codec->dev`, adds `codec` to `bus->codec_list`, and calls `pm_runtime_get_noresume()`, so custom `codec->dev.release` callbacks must call `snd_hdac_device_exit()` and free via `put_device(&codec->dev)`. `snd_hdac_bus_alloc_stream_pages()` must be called after all `snd_hdac_stream_init()` calls, and `snd_hdac_bus_exit()` requires `bus->stream_list` and `bus->codec_list` to be empty. [F111, F113]
- `snd_ctl_file.pid` and `snd_pcm_substream.pid` hold refcounted `struct pid *` (`get_pid()` / `put_pid()`) and must be reported via `pid_vnr()`. `snd_es1688_create()` must manage `res_port`, `irq`, and `dma8` manually (`snd_es1688_free()`), never `devm_*`, because ISA probing reuses the same `struct device`. [F110, F148]

## API Contracts

- Multi-element (`count > 1`) control callbacks must compute 0-based element offsets via `snd_ctl_get_ioff*()` (`array_index_nospec()`). `snd_kcontrol_info_t` must leave `uinfo->access == 0`. `SNDRV_CTL_ELEM_ACCESS_TLV_CALLBACK` selects `tlv.c` (`snd_kcontrol_tlv_rw_t`) over `tlv.p` (kernel array with byte length in `tlv.p[1]`). [F56, F137, F139]
- Virtual master followers (`snd_ctl_add_follower*`) must share the same `type` (`INTEGER` or `BOOLEAN`), `min`/`max` bounds, and `count <= 2`. In `snd_ctl_apply_vmaster_followers` callbacks `func(vfollower, follower, arg)`, `vfollower` is the vmaster wrapper (call `vfollower->put()`; its `private_data` is internal) while `follower` has the driver's `snd_kcontrol_chip(follower)`. [F85, F140]
- `snd_pcm_hardware.formats` is a `SNDRV_PCM_FMTBIT_*` bitmask (not `SNDRV_PCM_FORMAT_*`), and `buffer_bytes_max`/`period_bytes_*`/`fifo_size` are bytes while `runtime->buffer_size`/`period_size` and `params_buffer_size()`/`params_period_size()` are frames (unlike `params_buffer_bytes()`/`params_period_bytes()`). Only call `bytes_to_samples()`, `bytes_to_frames()`, and `frame_aligned()` after `hw_params` sets `runtime->sample_bits`, `frame_bits`, and `byte_align`. [F36, F92, F145]
- Check `hw_is_mask(var)` before `hw_param_mask*()`/`constrs_mask()` and `hw_is_interval(var)` before `hw_param_interval*()`/`constrs_interval()`. `snd_pcm_hw_rule_add()` requires at most 4 non-negative dependency IDs terminated by `-1`. Use `snd_pcm_running(substream)` to include `SNDRV_PCM_STATE_DRAINING` playback streams, and in `snd_pcm_group_for_each_entry(s, substream)`, filter `s` to the same hardware instance and call `snd_pcm_trigger_done(s, substream)`. [F60, F61, F80, F81, F82]
- `snd_pcm_indirect_playback_pointer()` / `capture_pointer()` take `ptr` in bytes (not frames) and return `SNDRV_PCM_POS_XRUN` when `ops->ack()` returns `-EPIPE` or capture `hw_ready > qsize`. `snd_pcm_indirect_*_transfer()` treats `diff < -(snd_pcm_sframes_t)(runtime->boundary / 2)` as wrap-around and other `diff < 0` as `-EPIPE`, and its `copy` callback must not modify `rec->hw_data`, `sw_data`, `hw_ready`, or `sw_ready`. [F76, F95, F150]
- Non-contiguous/SG buffers (`SNDRV_DMA_TYPE_DEV_SG`, `DEV_WC_SG`, `NONCONTIG`, `VMALLOC`) must use `snd_sgbuf_get_addr()`, `snd_sgbuf_get_page()`, `snd_sgbuf_get_chunk_size()`, and `snd_sgbuf_aligned_pages(size)` instead of `dmab->addr + offset`. `snd_devm_alloc_dir_pages()` / `snd_devm_alloc_pages()` require a valid `dev` and reject `SNDRV_DMA_TYPE_CONTINUOUS` and `SNDRV_DMA_TYPE_VMALLOC`. [F93, F131, F133]
- HDA codec suspend/resume callbacks must bracket execution with `snd_hdac_enter_pm()` / `snd_hdac_leave_pm()` and use `snd_hdac_power_up_pm()` / `down_pm()` (or `CLASS(snd_hda_power_pm, ...)`) inside PM paths; set `codec->no_stream_clean_at_suspend = 1` if converter stream IDs must persist across suspend. Use `snd_hdac_reg_readb`/`w`/`writeb`/`w` (or `snd_hdac_chip_*` / `snd_hdac_stream_*_poll`) for 8/16-bit MMIO to honor `bus->aligned_mmio`. [F112, F114, F116]
- `snd_hda_codec_device_init()` formats `fmt` into 31 bytes via unbounded `vsprintf()`. `drv_to_hdac_driver()` wraps `container_of()`, so `const struct device_driver *` conversions and `hdac_driver.match` must use `const struct hdac_driver *`. Unregistering codecs in a loop requires `list_for_each_codec_safe(c, n, bus)`. [F79, F100, F104]
- `snd_pcm_set_ops()` requires non-NULL `open`, `close`, `prepare`, `trigger`, `pointer`, and (`ops->copy` or `runtime->dma_area`). `snd_ac97_controller_register()` requires non-NULL `reset`, `warm_reset`, and (if `slots_available`) `read`. `hdmi_codec_pdata` requires `i2s || spdif`, `ops->audio_shutdown`, and `ops->hw_params || ops->prepare`. [F142, F143, F144]
- In NHLT DMIC `config.caps`, verify `device_config.config_type == NHLT_CONFIG_TYPE_MIC_ARRAY` before reading `nhlt_dmic_array_config` (and `array_type == NHLT_MIC_ARRAY_VENDOR_DEFINED` before `nhlt_vendor_dmic_array_config`). In `snd_info_entry`, `entry->content` discriminates `c.text` (`SNDRV_INFO_CONTENT_TEXT`) vs `c.ops` (`SNDRV_INFO_CONTENT_DATA`), and `snd_card_proc_new()` leaves `*entryp` untouched when returning `-EINVAL` on `!CONFIG_SND_PROC_FS`. [F30, F32, F43]
- Terminate `snd_pci_quirk` (placing specific entries before `SND_PCI_QUIRK_VENDOR`), `ac97_quirk`, `hda_verb` (`nid == 0`), `snd_pcm_chmap_elem`, `snd_ac97_res_table`, and vmaster follower arrays with `{}` / `NULL`; terminate `snd_legacy_find_free_*()` tables with `-1`; and pass raw `(reg, data)` pairs (never `SUB_REG*`) ending with `REGLIST_END` to `snd_emu10k1_ptr_write_multiple()`, writing `pc + 0` before `pc + 1` on `MICROCODEBASE`/`A_MICROCODEBASE`. [F69, F70, F86, F88, F117, F121]

## Error Handling

- `snd_hdac_read_parm`, `snd_hdac_read_parm_uncached`, `snd_hdac_codec_read`, `snd_hda_codec_read`, and `snd_hda_param_read` return `(int)-1` on failure (not negative errno), whereas `_snd_hdac_read_parm` returns `0` or negative errno. `snd_hda_codec_device_init()` returns `ERR_PTR`, whereas `snd_hda_codec_pcm_new()`, `snd_ctl_new1()`, and `snd_devm_alloc_dir_pages()` return `NULL`. [F27, F28]
- `snd_pcm_format_signed`/`unsigned`/`*_endian` return `1`, `0`, or `-EINVAL` (tri-state, not boolean); `snd_pcm_format_width`, `snd_pcm_format_physical_width`, `params_width`, `params_physical_width`, and `snd_pcm_format_size` return `-EINVAL` on unknown/variable formats. `snd_BUG()` / `snd_BUG_ON(cond)` trigger `WARN*` when `CONFIG_SND_DEBUG` is set (`snd_BUG_ON` always evaluates `cond`) and must never check user input or hardware timeouts. [F33, F34, F149]

## External Contracts

- Never renumber `SNDRV_PCM_RATE_*` bits (`1U << n`, as `SNDRV_PCM_RATE_KNOT` is bit 31), and keep `rates[]` / `snd_pcm_known_rates` in bit-position order. Unless `codec->ctl_dev_id` is set, HDA mixer controls on `codec->core.addr > 0` must offset `kctl->id.index` by `10 * codec->core.addr` rather than setting `id.device`. [F58, F59, F89]
- In `snd_pcm_status64`/`32`, `snd_pcm_pack_audio_tstamp_report()` must preserve bits 0..15 of `audio_tstamp_data` (`*data &= 0xffff`) while packing bits 16..31, and `reserved`/`rsvd[4]` must be zeroed before copying to userspace. Kernel-internal `SNDRV_CTL_ELEM_ACCESS_SKIP_CHECK | SNDRV_CTL_ELEM_ACCESS_LED_MASK` must be masked out of `snd_ctl_elem_info.access` for userspace and rejected in `snd_ctl_elem_add()`. [F65, F66, F138]

## Known Pitfalls

- `snd_hdac_chip_updatel`/`w`/`b`, `snd_hdac_updatel`/`w`, and `snd_hdac_stream_updatel`/`w`/`b` evaluate `(read & ~(mask)) | (val)` without masking `val`, so callers must pre-mask `val`. [F77]
- In `snd_array_init(array, size, align)`, `size` is bytes per element while `align` is element count; `snd_array_new()` may `krealloc()` and invalidate element pointers; and after `snd_array_for_each(array, idx, ptr)` finishes without `break`, `ptr` is non-NULL past-the-end, so check `idx < array->used` rather than `if (ptr)`. [F78, F98]
- After narrowing `struct snd_interval` bounds directly, call `snd_interval_checkempty(i)` (and `snd_interval_none(i)`) rather than `snd_interval_empty(i)`; when `snd_interval_single(i)` holds, read `snd_interval_value(i)` rather than `i->min` / `snd_interval_min(i)`. [F83, F84]
- Use `snd_iprintf(buf, ...)` only in `c.text.read` callbacks (`buf->buffer` is `struct seq_file *`) and `snd_info_get_line()` / `char *` access only in `c.text.write`. Call `dev_to_snd_card(p)` only on `card->card_dev`, never on `card->dev`. [F101, F102]
