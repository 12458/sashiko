# BTRFS FILE SYSTEM — fs/btrfs (part 6)

Implements Btrfs VFS inode, directory, symlink, and `address_space` operations, including inode lifecycle, namespace ops, delalloc writeback, ordered extents, truncation, swapfiles, properties, and ioctls/encoded I/O.

## Architecture & Data Flow
- In `btrfs_inode`, `delalloc_bytes`, `new_delalloc_bytes`, and `csum_bytes` share unions with directory fields (`S_ISDIR`), and `defrag_bytes` shares a union with `reloc_block_group_start`; `new_delalloc_bytes` must be zeroed in `btrfs_alloc_inode()`; `inode->root` can be `NULL` in `btrfs_evict/destroy/drop_inode()`, and `file_extent_tree` is `NULL` on `NO_HOLES`/non-regular/free-space inodes (use `btrfs_inode_*_file_extent_range()`); atomic bit ops must only target `runtime_flags` (not 32-bit `flags`/`ro_flags`); `dir_index` is non-zero only when `i_nlink == 1` and must be cleared to 0 before inserting a new `btrfs_inode_ref` in `btrfs_link/rename*()`. [F529, F561, F562, F577, F631]
- New file extents/holes (`insert_inline_extent()`, `insert_reserved_file_extent()`, `btrfs_cont_expand()`) must call `btrfs_inode_set_file_extent_range()` before `btrfs_inode_safe_disk_i_size_write()`; an `extent_map` pinned by `btrfs_create_io_em()` must stay cached in `insert_reserved_file_extent()` (`drop_cache = false`) and be unpinned in `btrfs_finish_one_ordered()` (or dropped via `btrfs_drop_extent_map_range()` on error/truncation); non-truncated delalloc COW extents in `btrfs_finish_one_ordered()` must clear `EXTENT_DELALLOC_NEW | EXTENT_ADD_INODE_BYTES` before `btrfs_update_inode_fallback()`. [F571, F573, F576]
- `can_cow_file_range_inline()` requires `offset == 0`, `size <= sectorsize`, `data_len < sectorsize`, `data_len <= min(BTRFS_MAX_INLINE_DATA_SIZE, max_inline)`, and `size >= i_size_read()`; `btrfs_symlink()` requires `name_len < sectorsize` (no NUL), and `read_inline_extent()` / `uncompress_inline()` must clamp `ram_bytes` to `sectorsize` and zero `[max_size, sectorsize)`; `can_nocow_file_extent()` requires `extent_generation > btrfs_root_last_snapshot()`; `inode->defrag_compress` overrides mount options, `NOCOMPRESS`, and `prop_compress` in `inode_need_compress()` / `compress_file_range()`. [F588, F591, F603, F624, F628]
- Partial-folio `btrfs_invalidate_folio()` (`offset != 0 || length != folio_size`) must only call `btrfs_release_folio()` without clearing `ordered` or `folio_extent_mapped`; `btrfs_add_swap_extent()` must page-align extents inward, cap `nr_pages` to `sis->max - bsi->nr_pages`, and increment `first_ppage_reported` at `bsi->start == 0`. [F601, F651]
- In `btrfs_fileattr_set()`, `btrfs_mask_fsflags_for_type()` precedes `check_fsflags()`, `!fa->flags_valid` updates only `SYNC/IMMUTABLE/APPEND/NODUMP/NOATIME`, and otherwise `"btrfs.compression"` is updated before `inode->flags`, `btrfs_update_inode_mapping_flags()`, and `btrfs_sync_inode_flags_to_i_flags()`; in `btrfs_set_prop()` / `btrfs_inode_inherit_props()`, failed `handler->apply()` after `btrfs_setxattr()` must delete the xattr without setting `BTRFS_INODE_HAS_PROPS`, and `need_reserve` is set `true` only after a property is actually applied. [F731, F732, F770, F781, F819]
- `btrfs_ordered_sum::len` is in data bytes (not `sums[]` byte size); `rb_simple_*` nodes must start with `rb_node` + `u64 bytenr`; `btrfs_lockdep_keysets[]` must end with `{.id = 0}`. [F747, F795, F796]

## Synchronization
- `btrfs_set/clear/split/merge_delalloc_extent()` require `io_tree.lock` held (nesting `inode->lock` or `delalloc_lock` -> `delalloc_root_lock` inside), syncing `delalloc_bytes` via `btrfs_add/del_delalloc_inode()`; `new_delalloc_bytes` and `inode_add/sub_bytes()` updates require `inode->lock`; `file_extent_tree->lock` uses `file_extent_tree_class` (inside `inode->lock`). [F570, F572, F639, F640]
- `delayed_iput_lock` requires IRQs disabled and must be dropped before `iput()`; eviction (`evict_refill_and_join()`) must use `BTRFS_RESERVE_FLUSH_EVICT` and `btrfs_join_transaction()` (never `btrfs_start_transaction()` / `FLUSH_ALL`); `btrfs_del_inode_from_root()` must use `__xa_cmpxchg(..., inode, NULL, GFP_ATOMIC)` under `root->inodes` lock, and `btrfs_add_inode_to_root(inode, false)` requires a prior `xa_reserve()` (`xa_release()` on error). [F537, F538, F580, F646]
- Tree-log: `create_subvol()` calls `btrfs_record_new_subvolume()` before `btrfs_create_new_inode()`; `btrfs_rmdir()` calls `btrfs_record_snapshot_destroy()` before `btrfs_unlink_subvol/inode()` when `last_unlink_trans >= trans->transid`; non-root `btrfs_rename*()` pins log trans (`btrfs_pin_log_trans()`) on `root` and `dest` before unlinking until after `btrfs_log_new_name()`. [F539, F540, F679]
- DREW/snapshot/truncate: `btrfs_drew_try_write_lock()` and `btrfs_drew_read_lock()` require `smp_mb__after_atomic()` after counter increment; `btrfs_mksnapshot()` holds `btrfs_drew_read_lock(&snapshot_lock)` across delalloc flush, `snapshot_force_cow++`, `btrfs_wait_ordered_extents()`, and `btrfs_mksubvol()`; expanding `btrfs_setsize()` holds `btrfs_drew_write_lock(&snapshot_lock)` across `btrfs_cont_expand()` through `btrfs_update_inode()`; `btrfs_truncate()` ends `trans` before `btrfs_truncate_block()`; `__btrfs_prealloc_file_range()` calls `btrfs_dec_block_group_reservations()` after `insert_prealloc_file_extent()`. [F541, F587, F653, F680, F688]
- `btrfs_swap_activate()` acquires `i_mmap_lock`, `EXCLOP_SWAP_ACTIVATE`, `snapshot_lock`, and `nr_swapfiles` (under `root_item_lock` checking `!btrfs_root_dead()`) before `io_tree`, releases `path` before `btrfs_is_data_extent_shared()`, and cleans up via `out:` before `up_write(&i_mmap_lock)`. [F526, F542, F658]
- Encoded I/O: `btrfs_encoded_read()` and `btrfs_do_encoded_write()` recheck `btrfs_lookup_ordered_range()` (and pagecache on write) under `btrfs_lock_extent()`; `btrfs_encoded_read*()` drops `path`, `io_tree`, and `BTRFS_ILOCK_SHARED` before user copies; `btrfs_encoded_read()` keeps `io_tree` and `ILOCK_SHARED` iff returning `-EIOCBQUEUED` (requiring unlock on pre-queue error and `btrfs_lockdep_inode_release/acquire()` in `uring_encoded_read()`); `btrfs_encoded_read_endio()` uses `WRITE_ONCE(priv->status)` before `refcount_dec_and_test(&priv->pending_refs)`. [F527, F543, F545, F642, F829]
- Ordered extents: `btrfs_lock_and_flush_ordered_range()` unlocks `[start, end]` before `btrfs_start_ordered_extent()` and loops; `btrfs_remove_ordered_extent()` erases `rb_node`, clears matching `ordered_tree_last`, and sets `BTRFS_ORDERED_COMPLETE` under `ordered_tree_lock` before waking, and drops `trans_lock` after pinning `trans` before `pending_ordered--` / `btrfs_put_transaction()`; `!uptodate` COW extents set `BTRFS_INODE_COW_WRITE_ERROR` before queuing completion; free-space inodes use `endio_freespace_worker` and skip ordered lockdep; `cond_wake_up_nomb()` requires a prior full barrier (`cond_wake_up()` after `set_bit()`). [F695, F696, F699, F729, F808, F809]
- List splicing & ioctl locks: `start_delalloc_inodes()` / `btrfs_start_delalloc_roots()` hold `delalloc*_mutex`, pin via `igrab()` / `btrfs_grab_root()` under spinlock, and restore unvisited items; `ordered_root_lock` nests inside `ordered_extent_lock` (dropped before `btrfs_wait_ordered_extents()`), and `btrfs_wait_ordered_extents/roots()` relink each selected item before dropping the spinlock and splice `skipped`/`splice` back; `btrfs_*lock_root_node()` rechecks `eb == root->node` under lock; `QUOTA_CTL_DISABLE` locks `cleaner_mutex` before `subvol_sem`; clearing `RDONLY` in `subvol_setflags` holds `subvol_sem` (write) and `root_item_lock` (`send_in_progress == 0`); `fitrim`/`fs_info`/`dev_info` hold `rcu_read_lock()` across `devices` / `btrfs_dev_name()` (dropped before `copy_to_user()`); `copy_to_sk()` uses `*_nofault()` under leaf lock and `fault_in_subpage_writeable()` unlocked. [F544, F682, F683, F689, F771, F806, F817, F825]

## Object Lifetimes
- When `btrfs_iget_locked()` returns `I_NEW`, `btrfs_read_locked_inode()` calls `iget_failed()` on error (callers only call it if aborting earlier); `btrfs_create_new_inode()` preserves `args->inode` on error (`ihold()` before `discard_new_inode()`), so callers must `iput()` and null early-freed pointers; `btrfs_destroy_cachep()` calls `rcu_barrier()` before `kmem_cache_destroy()`. [F511, F521, F643]
- Subpage `__btrfs_release_folio()` / `btrfs_invalidate_folio()` call `wait_subpage_spinlock()` before `clear_folio_extent_mapped()`; `evict_inode_truncate_pages()` copies `start`/`end`/`state_flags` before dropping `io_tree->lock`; in `run_delalloc_compressed()`, `locked_folio` goes only to `async_chunk[0]`, `submit_compressed_extents(..., true)` releases `ihold()`, `css_get()`, and `num_chunks`, and `submit_one_async_extent()` resets `kthread_associate_blkcg(NULL)`. [F520, F533, F608, F657]
- In `create_subvol()`, failed `btrfs_insert_root()` must clear `leaf` dirty and call `btrfs_free_tree_block()` before `free_extent_buffer()`; `btrfs_balance()` takes ownership of `bctl` and `need_unlock`; `btrfs_lru_cache` is unlocked, embeds `btrfs_lru_cache_entry` at offset 0 of `kmalloc()` structs, takes ownership in `store()` only on 0, chains 64-bit `match_entry()` lists per `maple_tree` slot, and samples `entry->list.prev` before `list_del()` in `remove()` to `mtree_erase()`/`kfree()` empty slot heads. [F668, F670, F675, F700, F730, F782]

## API Contracts
- `can_nocow_file_extent()` may release `path` and frees it if `free_path`: `BTRFS_PATH_AUTO_FREE` callers must set `path = NULL`, and `!free_path` callers (`run_delalloc_nocow()`) must re-search if `!path->nodes[0]`; `btrfs_cleanup_ordered_extents()` and `btrfs_wait/lookup*_ordered_range()` take `(start, len)`, whereas `extent_clear_unlock_delalloc()` and `btrfs_*lock*_ordered_range()` take `(start, end)` (`btrfs_lock_and_flush_ordered_range()` decrements `cache->refs` when `cached_state == NULL`). [F519, F546, F578, F666, F715]
- `btrfs_create_io_em()` takes unshifted `BTRFS_ORDERED_*` (never `NOCOW`), while `btrfs_alloc_ordered_extent()` takes `1U << BTRFS_ORDERED_*`; `ENUM_BIT()` is `< 32` bits; `btrfs_inode_unlock()` flags must match `btrfs_inode_lock()` and never combine `BTRFS_ILOCK_TRY | BTRFS_ILOCK_MMAP`. [F549, F566, F604, F605, F793]
- `[__]cow_file_range_inline()` (after `can_cow_file_range_inline()`) returns `0` (done), `1` (fall back), or `< 0`; `btrfs_lookup_inode/file_extent()` and `btrfs_search_slot()` return `> 0` when missing; `exclop_start_or_cancel_reloc()` returns `> 0` when busy (check `if (ret)`); `btrfs_try_read_lock_root_node()` returns `ERR_PTR(-EAGAIN)`; `btrfs_item_ptr()` returns an `extent_buffer` offset (use `*_extent_buffer` helpers and zero new `inode_item` / stack `file_extent_item`); `btrfs_tree_unlock_rw()` BUGs on `rw == 0`; `btrfs_unlock_up_safe(path, level)` requires no parent updates `>= level`. [F550, F556, F560, F589, F630, F690, F701, F702, F718]
- `btrfs_create_new_inode()` calls `btrfs_set_inode_mapping_order()` for all inodes; `btrfs_tmpfile()` calls `set_nlink(inode, 1)` before `d_tmpfile()`; `btrfs_ignore_prop()` requires a validated name and `prop_handler` bounds `value` by `len`; `btrfs_update_ioctl_balance_args()` requires zeroed `*bargs`; `btrfs_root_name()` requires `BTRFS_ROOT_NAME_BUF_LEN` bytes; `nr == U64_MAX` in `btrfs_wait_ordered_extents/roots()` is not decremented. [F647, F654, F707, F722, F791, F800, F802]

## Error Handling
- Callers of `btrfs_cleanup_ordered_extents()` must not pass `EXTENT_DO_ACCOUNTING` or `EXTENT_CLEAR_META_RESV` to `extent_clear_unlock_delalloc()` on ordered subranges; `cow_file_range()` splits cleanup into `[orig_start, start - 1]` (ordered), `[start, start + cur_alloc_size - 1]` (`CLEAR_META_RESV`), and `[start + cur_alloc_size, end]` (`+ CLEAR_DATA_RESV`); `run_delalloc_nocow()` resets `cow_start = (u64)-1` after `fallback_to_cow()` and sets `cow_end`/`nocow_end` before `goto error`. [F517, F567, F611]
- In `btrfs_truncate_block()`, `only_release_metadata` requires `btrfs_delalloc_release_metadata()` and `btrfs_check_nocow_unlock()`; `insert_prealloc_file_extent()` jumps to `free_qgroup` on error after `btrfs_qgroup_release_data()`; `btrfs_delete_subvolume()` zeroes/frees `qgroup_reserved`, detaches `trans->block_rsv`, and clears `BTRFS_ROOT_SUBVOL_DEAD`; `IS_ERR(trans)` in `btrfs_finish_one_ordered()`, `btrfs_link()`, and `btrfs_truncate()` must set `trans = NULL`; `btrfs_end_transaction()` must not overwrite `ret` in `btrfs_rename*()` / `btrfs_truncate()`; failed shrinking `btrfs_truncate()` in `btrfs_setsize()` (`i_nlink > 0`) waits on ordered extents and restores `i_size = disk_i_size`; failed `btrfs_alloc_extent_map()` in `btrfs_cont_expand()` / `__btrfs_prealloc_file_range()` drops the range and sets `full_sync`. [F514, F522, F523, F555, F563, F574, F575]
- `btrfs_lookup_dentry()` / `btrfs_inode_by_name()` reject `len > BTRFS_NAME_LEN` (`-ENAMETOOLONG`) and bad `DIR_ITEM` key/type (`-EUCLEAN`); `btrfs_get_extent()` rejects `REG`/`PREALLOC` on `!S_ISREG` (`-EUCLEAN`) and checks `em` covers `start` (`-EIO`); `btrfs_wait_ordered_range()` never exits early on writeback/`ORDERED_IOERR` errors; `btrfs_ioctl_subvol_setflags()` restores `root_flags` on error; `btrfs_search_path_in_tree*()` bounds-checks `ptr` (`-ENAMETOOLONG`); 32-bit `subvol_sync` rejects `subvolid > U32_MAX` (`-EOVERFLOW`); relative `ioctl_resize` checks u64 underflow/overflow; `__btrfs_handle_fs_error()` ignores `-EROFS` when `sb_rdonly` and only forces read-only when `SB_BORN && !sb_rdonly` without canceling dev-replace. [F595, F596, F733, F756, F762, F772, F785, F832]

## External Contracts
- Encoded I/O: `encoded_write` validates `flags/reserved == 0`, valid `compression`/`encryption` (not both `NONE`), `unencoded_offset <= unencoded_len`, `len <= unencoded_len - unencoded_offset`, `!NODATASUM`, `0 < orig_count < unencoded_len <= MAX_UNCOMPRESSED`, `orig_count <= MAX_COMPRESSED`, `sectorsize` alignment, and LZO sector size; `encoded_read` locks `MAX_UNCOMPRESSED`, returns `-ENOBUFS` if compressed `> count`, caps uncompressed to `lockend + 1`, and copies in to `copy_end` / out from `copy_end_kernel` to `user + copy_end`; `uring_encoded_read/write()` reuses `bc->data` on `REISSUE` and keeps it on `-EAGAIN`/`-EIOCBQUEUED`. [F598, F599, F660, F738, F761, F828]
- Ioctls: `vol_args*` require `btrfs_check_ioctl_vol_args*()` (`-ENAMETOOLONG`); `__btrfs_ioctl_snap_create()` (`!subvol`) requires `ino == BTRFS_FIRST_FREE_OBJECTID` (`-EINVAL`), same sb (`-EXDEV`), and `inode_owner_or_capable()` (`-EPERM`); idmapped `snap_destroy` by ID requires `old_dir == dir` (`-EOPNOTSUPP`); `SET_RECEIVED_SUBVOL_32` is handled in `btrfs_ioctl()` under `CONFIG_64BIT`; `ino_to_path` converts `fspath->val[i]` to relative offsets; `copy_to_sk()` first-item overflow writes `sh.len = 0` and returns `-EOVERFLOW` (0 in v1, `-EOVERFLOW` in v2). [F755, F759, F798, F821, F822, F823]

## Known Pitfalls
- `btrfs_real_readdir()` / `btrfs_filldir()` use `get/put_unaligned()` on `filldir_buf`, release `path` before `btrfs_filldir()` when flushing (`>= PAGE_SIZE`) and restart from `ctx->pos`, and cap EOF `ctx->pos` to `INT_MAX` when `< INT_MAX`; `insert_reserved_file_extent()` at `file_pos == 0` accounts unaligned `drop_args.bytes_found` inline remainder separately from `sectorsize`. [F579, F592, F593, F662]
- Delalloc extent counts use `count_max_extents(fs_info, size)` (ceiling div), and merging/splitting `> max_extent_size` only adjusts `outstanding_extents` when the combined count differs from the sum of parts; in `btrfs_rename_exchange()`, `old_idx` comes from `new_dir` (for `old_inode` in `dest`) and `new_idx` from `old_dir` (for `new_inode` in `root`). [F617, F618, F619]
- `print_extent_item()` must `return` on unknown ref types; `iterate_object_props()` must `continue` after `btrfs_next_leaf()`; `copy_to_sk()` must carry across key fields without wrapping `U64_MAX`; `btrfs_wait_ordered_range()` clamps `orig_end` to `OFFSET_MAX` on overflow and stops at `end == 0 || end == start`; `BTRFS_32BIT_MAX_FILE_SIZE` casts `ULONG_MAX` to `u64` before `+ 1`; `btrfs_ioctl_fitrim()` must not clamp to `super->total_bytes`. [F753, F764, F769, F784, F789, F790]
