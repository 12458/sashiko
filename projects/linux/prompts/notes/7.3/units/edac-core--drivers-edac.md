# EDAC-CORE — drivers/edac

Provides the core EDAC subsystem for memory controllers, generic ECC devices, PCI parity checking, debugfs error injection, and RAS sysfs attributes (ECS, scrub, memory repair), plus hardware EDAC drivers.

## Architecture & Data Flow

- `add_mc_to_global_list()`, `add_edac_dev_to_global_list()`, and `add_edac_pci_to_global_list()` must keep `mc_devices`, `edac_device_list`, and `edac_pci_list` sorted by ascending `mc_idx`/`dev_idx`/`pci_idx` so stopping at the first `>=` entry catches duplicates. [F100]
- `edac_mc_alloc_dimms()` and `edac_get_dimm()` must use identical row-major order across `mci->layers[]` and keep `mci->dimms[idx]->idx == idx` (`edac_get_dimm()` checks `idx != index` and `mci_for_each_dimm()` steps via `(dimm)->idx + 1`); in `edac_device_alloc_ctl_info()`, `dev_ctl->blocks` is one contiguous `nr_instances * nr_blocks` array into which `dev_inst[i].blocks` points, so `__edac_device_free_ctl_info()` must only `kfree(ci->blocks)`, never `kfree(inst->blocks)`. [F61, F116]
- `struct attribute attr` must stay at offset 0 in `edac_dev_sysfs_attribute`, `edac_dev_sysfs_block_attribute`, and `edac_pci_dev_attribute` (handlers cast `struct attribute *` directly). [F78]
- In `edac_mc_handle_error()`, `row`/`chan` start at `-1`, become `dimm->csrow`/`cschannel` on the first matching populated DIMM, and stick at `-2` if another differs; in `edac_raw_mc_handle_error()`, clamp `e->grain` to `1` when zero before `fls_long(e->grain - 1)`; `edac_device_handle_ce_count()`/`ue_count()` must increment `block->counters` (if `nr_blocks > 0`), `instance->counters`, and `edac_dev->counters` together. [F63, F101, F107]
- In `edac_dev_register()`, the first-pass `attr_gcnt` sum across `ras_features[]` must match the second-pass `ras_attr_groups[]` slots written (`1` for scrub/mem_repair, `num_media_frus` for ECS), allocated as `attr_gcnt + 1`; keep `enum edac_mem_repair_attributes`, `mem_repair_dev_attr[]`, and `mem_repair_attr_visible()` aligned 1-to-1 (copied into per-instance `ctx->mem_repair_dev_attr[]` with `instance` in `mem_repair_create_desc()`), and keep `enum edac_ecs_attributes`, per-FRU `fru_ctx->dev_attr[]` (with `fru_id` in `ecs_create_desc()`), and `ecs_attr_visible()` synchronized. [F58, F59, F76]
- In `fsl_ddr_edac.c`, all register accesses must use `ddr_in32()`/`ddr_out32()` (handling `little_endian` and remapping `TYPE_IMX9` injection/`IMX9_MC_ERR_EN` to `inject_vbase` via `ddr_reg_addr()`); `fsl_ddr_mc_init()` must return `-EBUSY` if `ghes_get_devices()`; `fsl_mc_err_probe()` must save `FSL_MC_ERR_DISABLE` and (if `EDAC_OPSTATE_INT`) `FSL_MC_ERR_SBE`, and `fsl_mc_err_remove()` must zero `FSL_MC_ERR_INT_EN` and restore both before `edac_mc_del_mc()`. [F86, F132, F138]
- In `altera_edac.c`: `altr_check_ecc_deps()`, `altr_l2_check_deps()`, and `altr_sdram_probe()` must return `-ENODEV` if bootloader hasn't enabled ECC; `altr_sdram_probe()` must check `mem_size != 0` before `dimm->nr_pages = ((mem_size - 1) >> PAGE_SHIFT) + 1`, disable `ecc_irq_en_mask` and reset counters (`ecc_cnt_rst_mask`) before `edac_mc_add_mc()`/`devm_request_irq()`, and enable `ecc_irq_en_mask` only after both succeed. [F109, F130, F136]
- In `altera_edac.c` (A10/S10): the 64-IRQ domain maps SERR to hwirq `0..31` and DERR to `32..63` (`dberr * 32 + bit`) in `altr_edac_a10_irq_handler()`; `altr_init_a10_ecc_block()`/`altr_init_memory_port()` must mask `A10_SYSMGR_ECC_INTMASK_SET_OFST` and disable ECC with `wmb()`, poll `ALTR_A10_ECC_INITSTAT_OFST`, and clear `ALTR_A10_ECC_INTSTAT_OFST` before re-enabling ECC/IRQ; `s10_edac_dberr_handler()` must write DERR status to `S10_SYSMGR_UE_VAL_OFST` (`0x220`) and match `BIT(ed->db_irq)` in `edac->a10_ecc_devices` to log `readl(ed->base + ALTR_S10_DERR_ADDRA_OFST)` to `S10_SYSMGR_UE_ADDR_OFST` (`0x224`). [F88, F143, F145]

## Synchronization

- Hold `mem_ctls_mutex` for `__find_mci_by_dev()`/`add_mc_to_global_list()`, `device_ctls_mutex` for `find_edac_device_by_dev()`/`add_edac_dev_to_global_list()`, and `edac_pci_ctls_mutex` for `find_edac_pci_by_dev()`/`add_edac_pci_to_global_list()`; `del_mc_from_global_list()`, `del_edac_device_from_global_list()`, and `del_edac_pci_from_global_list()` must use `list_del_rcu()` then `synchronize_rcu()` before `INIT_LIST_HEAD()`. [F20, F154]
- In `edac_mc_add_mc_with_groups()`, `edac_device_add_device()`, and `edac_pci_add_device()`, init/queue polling work only when `edac_check != NULL`, after sysfs creation succeeds and `op_state = OP_RUNNING_POLL` under the subsystem mutex; `edac_mc_reset_delay_period()` must hold `mem_ctls_mutex` and check `mci->op_state == OP_RUNNING_POLL` before `edac_mod_work()`. [F25, F26]
- `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` must set `op_state = OP_OFFLINE` and remove the controller from its global list under the subsystem mutex (`mem_ctls_mutex`, `device_ctls_mutex`, `edac_pci_ctls_mutex`), then unlock before calling `edac_stop_work()` / `edac_device_workq_teardown()`. [F10]
- `edac_mc_handle_error()` mutates `mci->error_desc` and non-atomic counters unlocked; never call it concurrently on the same `mci` (e.g. from both `edac_check` polling and an IRQ). [F156]
- Gate `edac_pci_top_main_kobj` setup/teardown and its `THIS_MODULE` ref in `edac_pci_main_kobj_setup()`/`teardown()` with `atomic_inc_return(&edac_pci_sysfs_refcount) == 1` and `atomic_dec_return(...) == 0`; in `i5100_init_one()` (`bail_scrub`) and `i5100_remove_one()`, set `priv->scrub_enable = 0` before `cancel_delayed_work_sync(&priv->i5100_scrubbing)`, before disabling/putting PCI devs or freeing `mci`. [F27, F133]
- In `altera_edac.c`: regmaps used in `irq_chip` callbacks, hardirq/chained handlers, or panic notifiers (`s10_edac_dberr_handler`) must set `.fast_io = true`; debugfs triggers must finish `get_user()` and `alloc_mem()`/`dma_alloc_coherent()` before `local_irq_save()`/`disable()`; `l2_alloc_mem()` and `altr_sdr_mc_err_inject_write()` must flush caches (`wmb()` + `flush_cache_all()`, or `dma_alloc_coherent()` + `wmb()`/`rmb()`) so injected writes and `READ_ONCE()` reach hardware. [F158, F159, F161]

## Object Lifetimes

- `csrow_release()` and `dimm_release()` must remain no-ops, and `mci_for_each_dimm()` bodies must never `kfree(dimm)` (the loop step reads `dimm->idx`); `mci_release()` frees `mci->csrows` and `mci->dimms`. [F3, F91]
- Once `edac_device_register_sysfs_main_kobj()` succeeds in `edac_device_alloc_ctl_info()`, free `edac_device_ctl_info` only via `edac_device_free_ctl_info()`, never `__edac_device_free_ctl_info()` or `kfree()`. [F6]
- In `edac_mc_del_mc()` and `edac_device_del_device()`, drain polling work via `edac_stop_work()` / `edac_device_workq_teardown()` before removing sysfs (`edac_remove_sysfs_mci_device()`, `edac_device_remove_sysfs()`). [F23]
- Under `mem_ctls_mutex`, `edac_mc_add_mc_with_groups()` must set `edac_mc_owner = mci->mod_name` only after `add_mc_to_global_list()` and `edac_create_sysfs_mci_device()` succeed, and `edac_mc_del_mc()` must clear `edac_mc_owner = NULL` when `del_mc_from_global_list()` returns true. [F11]
- In `cpc925_remove()`, call `cpc925_del_edac_devices()` before `cpc925_mc_exit()`, `edac_mc_del_mc()`, and `edac_mc_free()` (child devices share `vbase`); in `altr_init_a10_ecc_device_type()`, `altr_edac_a10_device_add()`, and `socfpga_init_sdmmc_ecc()`, each child ECC node must pass `validate_parent_available()` (checking `"altr,ecc-parent"` and calling `of_node_put()`) before register access. [F15, F141]

## API Contracts

- Before `edac_mc_add_mc_with_groups()`, `edac_device_add_device()`, or `edac_pci_add_device()`, set `pdev`/`dev`, unique `mc_idx`/`dev_idx`/`pci_idx`, and for MC `dimm->nr_pages`, `mod_name`, `ctl_name`, and `dev_name`; set `edac_check` before registration and never change its nullness before removal. [F24, F44, F47]
- `edac_mc_add_mc_with_groups()` returns `0` or negative errno (never check `> 0`), whereas `edac_device_add_device()` and `edac_pci_add_device()` return `0` or positive `1` on failure (check non-zero, not `< 0`, and return a negative errno from probe). [F35, F36]
- `find_mci_by_dev()` and `edac_mc_find()` return borrowed pointers, whereas `edac_mc_del_mc()`, `edac_device_del_device()`, and `edac_pci_del_device()` return detached controllers that callers must free with `edac_mc_free()`, `edac_device_free_ctl_info()`, or `edac_pci_release_generic_ctl()`/`edac_pci_free_ctl_info()`. [F12]
- `edac_queue_work()`, `edac_mod_work()`, and `round_jiffies_relative()` take jiffies, while `edac_device_reset_delay_period()` and `edac_device_workq_setup()` take ms, must convert via `msecs_to_jiffies()`, and must update `edac_dev->poll_msec` and `delay` together; `edac_device_add_device()` must preserve non-zero `edac_dev->poll_msec` over `DEFAULT_POLL_INTERVAL`. [F49, F64]
- `csrow->first_page`..`last_page` is inclusive (`first_page + nr_pages - 1`), and `edac_mc_find_csrow_by_page()` returns `-1` on miss (check `row >= 0` before indexing `mci->csrows[row]`). [F39, F83]
- In `edac_mc_handle_error()`/`edac_raw_mc_handle_error()`, `page_frame_number` is a PFN, `offset_in_page` is bytes, and `grain` is non-zero bytes; direct `edac_raw_mc_handle_error(e)` callers must pass `&mci->error_desc` with non-NULL `e->msg` and `e->other_detail`; in `edac_ce_error()`/`edac_mc_scrub_block()`, translate PFN via `mci->ctl_page_to_phys()` if set, check `pfn_valid(page)`, use `kmap_atomic()`/`kunmap_atomic()`, and wrap `PageHighMem(pg)` in `local_irq_save()`/`restore()`. [F45, F155, F168]
- `edac_device_ctl_info::sysfs_attributes` is NULL-terminated (`attr.name == NULL`), whereas `edac_device_block::block_attributes` is bounded by `block->nr_attribs`; `off_val` in `edac_device_alloc_ctl_info()` only offsets sysfs names, so `edac_device_handle_ce`/`ue*()` callers must pass 0-based `inst_nr` and `block_nr`. [F77, F79]
- Call `edac_pci_do_parity_check()`, `edac_pci_handle_pe()`, and `edac_pci_handle_npe()` only from sleepable context with IRQs enabled (`for_each_pci_dev()` sleeps; disable IRQs only inside `edac_pci_dev_parity_test()`). [F157]
- For RAS features: `edac_dev_register()` requires non-NULL ops and 0-based sequential `instance` counts per type for `RAS_FEAT_SCRUB`/`MEM_REPAIR`, and non-NULL `ecs_ops` with `num_media_frus > 0` for `RAS_FEAT_ECS`; heap-allocated `struct attribute`s in `*_create_desc()` must call `sysfs_attr_init()`; and `ecs_attr_visible()`, `mem_repair_attr_visible()`, and `scrub_attr_visible()` must only expose read/write bits when the respective getter/setter is non-NULL. [F46, F163, F164]
- In `altera_edac.c`: call `dma_free_coherent()` in `altr_sdr_mc_err_inject_write()` only if `dma_alloc_coherent()` succeeded; in `altr_edac_device_trig()`, init `generic_ptr = edac_dci->dev`, pass `&generic_ptr` to `priv->alloc_mem()`, and pass `generic_ptr` by value to `priv->free_mem()`; bracket `altr_edac_a10_irq_handler()` status reads and `generic_handle_domain_irq()` with `chained_irq_enter()`/`exit()`. [F16, F123, F160]

## Error Handling

- When `device_add()` fails in `edac_create_dimm_object()` or `edac_create_csrow_object()`, call `put_device()`, whereas post-registration teardown in `edac_create_csrow_objects()`, `edac_delete_csrow_objects()`, and `edac_remove_sysfs_mci_device()` must call `device_unregister()`. [F2]
- When `device_register()` fails on `mci_pdev` (`edac_mc_sysfs_init()`) or `&ctx->dev` (`edac_dev_register()`), call `put_device()` and return without jumping to `kfree()` labels (`mc_attr_release()`/`edac_dev_release()` free them). Errors in `edac_dev_register()` *before* `device_register(&ctx->dev)` must jump to `data_mem_free` (`ctx->mem_repair`, `ctx->scrub`, `ras_attr_groups`, `ctx`), while `ecs_create_desc()`/`mem_repair_create_desc()` descriptors are devm-managed on `parent`. [F4, F5, F42]
- `edac_device_create_instance()`, `edac_device_create_block()`, and `edac_pci_create_instance_kobj()` must take `kobject_get()` on the parent main kobject before `kobject_init_and_add()` (child `.release` calls `kobject_put()`) and unwind created children on loop error. [F8]
- In `fsl_mc_err_probe()` and `altr_sdram_probe()`, errors after `edac_mc_add_mc*()` must jump to `err2` to call `edac_mc_del_mc()` first, and `devres_release_group()` must run before `edac_mc_free()`/`edac_device_free_ctl_info()` so `devm_request_irq()` with `mci`/`dci` is freed before `mci`/`dci` (closing/removing the group on success); platform probes must propagate negative errnos from `platform_get_irq()` instead of `-ENODEV`, and `cpc925_get_sdram_scrub_rate()` must check `si == 0` before dividing. [F13, F37, F43, F110]

## External Contracts

- `dimmdev_label_store()` and `channel_dimm_label_store()` must reject empty strings (after stripping a trailing `'\0'`/`'\n'`) or inputs `>= sizeof(dimm->label)` (32 bytes), and explicitly NUL-terminate `dimm->label`. [F81]

## Known Pitfalls

- `edac_mc_handle_error()` must `memset(&mci->error_desc, 0, ...)` and normalize NULL `msg`/`other_detail` to `""`; when `> EDAC_MAX_LABELS` DIMMs match, reset `p = e->label` and `*p = '\0'`; when `edac_get_dimm()` is NULL, increment `ue_noinfo_count` in `edac_inc_ue_error()` and `ce_noinfo_count` in `edac_inc_ce_error()`. [F66, F67, F94]
- Use `scnprintf()` (not `snprintf()`) when advancing `p` in `edac_dimm_info_location()`, `edac_mc_alloc_dimms()`, and `edac_mc_handle_error()`; pass literal `"%s"` to `dev_set_name()` and `kobject_init_and_add()` for runtime strings; `edac_mc_add_mc_with_groups()` compares `edac_mc_owner != mci->mod_name` by pointer, so multi-instance drivers must pass the same `mod_name` pointer; `list_for_each()` searches like `edac_mc_find()` must reset the entry pointer to `NULL` on miss; `edac_set_poll_msec()` must cast `kp->arg` to `unsigned int *` matching `param_get_uint`. [F92, F112, F114, F128, F166]
- PCI, RAS & debugfs: `edac_pci_alloc_ctl_info()` `edac_pci_name` must be `<= EDAC_DEVICE_NAME_LEN` (31) bytes; `EDAC_PCI_ATTR()` targets using `edac_pci_int_show`/`store` must be `int`; `get_pci_parity_status()` must ignore `status == 0xFFFF` if config dword 0 is `0xFFFFFFFF` and mask `status` to `PCI_STATUS_DETECTED_PARITY | PCI_STATUS_SIG_SYSTEM_ERROR | PCI_STATUS_PARITY` before writing back; in `ecs.c`/`mem_repair.c`, call `dev_get_drvdata(ras_feat_dev)` for `ctx`, but pass `ras_feat_dev->parent` and `ctx->ecs.private` or `ctx->mem_repair[inst].private` to `ops->cb()`, and RW RAS attrs require a non-NULL getter in `*_attr_visible()`; debugfs handlers using `to_mci(file->private_data)` need `&mci->dev`, while `altr_sdr_mc_err_inject_write` needs `mci`. [F68, F85, F97, F120, F126, F165]
- Intel, CPC925 & FSL pitfalls: `i3200`/`i82860`/`i82875p` must read `ERRSTS` before and after log registers (reporting `"UE overwrote CE"` on `(errsts ^ errsts2) & mask`) and test UE before CE; `i5100` must use 64-bit casts/shifts in `i5100_npages()`/`i5100_init_interleaving()` and write `0xaa` then `0xab` to `I5100_DINJ0`; CPC925 uses `CPC925_BIT(nr)` (`1UL << (31 - nr)`), `reg_end = reg + len/4` in `get_total_mem()`, and must not clear `ECC_MASK_ENABLE`/`CPU_MASK_ENABLE`/`MCCR_ECC_EN` on exit; `fsl_mc_check()` must guard `bad_data_bit >= 0` (`1ULL << bad_data_bit`) and `bad_ecc_bit >= 0`. [F53, F69, F71, F102, F106, F111, F122, F147]
- `altera_edac.c` pitfalls: test `ecc_cecnt_offset` in CE and `ecc_uecnt_offset` in UE in `altr_sdram_mc_err_handler()`; cast `p` to `unsigned long` in `ocram_free_mem()`; bound `altr_edac_device_trig()` by `trig_alloc_sz / sizeof(*ptemp)` (`>= ALTR_TRIGGER_READ_WRD_CNT`); pass `edac_device_ctl_info *` to `altr_edac_device_handler()` vs `altr_edac_device_dev *` to `prv->ecc_irq_handler`; wrap `a10_get_irq_mask()` in `BIT()`; keep `limit` a signed `int` (`limit < 0`) in `altr_init_memory_port()`; copy `u32 irq_status` to `unsigned long bits` before `for_each_set_bit()`; re-init PortB fields (`edac_dev_name`, `edac_idx`, `edac_dev`, `data`, `dci->dev`, `sb_irq`, `db_irq`) after `*altdev = *device` in `altr_portb_setup()`; use `writew()` on `INTTEST` in `altr_edac_a10_device_trig*()`, and `arm_smccc_smc()` in `altr_s10_sdram_check_ecc_deps()`. [F52, F70, F93, F104, F108, F113, F124, F125, F137, F142]
