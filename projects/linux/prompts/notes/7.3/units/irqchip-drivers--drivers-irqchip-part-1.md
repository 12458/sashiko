# IRQCHIP DRIVERS — drivers/irqchip (part 1)

This component implements core and SoC-specific interrupt and MSI controller drivers—including ARM GICv3/v4, GICv3 ITS, GICv3 MBI, GICv2m, GIC PM, RISC-V ACLINT SSWI, and platform controllers for Aspeed, ATH79, Atmel AIC/AIC5, Broadcom BCM2712/2835/2836, Exynos, TI Crossbar, and DaVinci.

## Architecture & Data Flow
- `irq_to_cpuid_lock()`/`unlock()` must check `d->chip == &its_vpe_irq_chip` before casting `d->chip_data` to `struct its_vpe *`, as non-vPE IRQs store `struct its_device *` in `d->chip_data` and resolve vPEs via `get_vlpi_map(d)`. [F42]
- In `its_vlpi_map()`/`unmap()`, `irqd_set_forwarded_to_vcpu(d)` must precede `lpi_write_config()` on map, and `irqd_clr_forwarded_to_vcpu(d)` must precede `lpi_update_config()` on unmap, because `get_vlpi_map()` tests `irqd_is_forwarded_to_vcpu(d)` to select `vprop_page` vs `prop_table_va`. In `lpi_update_config()`, `direct_lpi_inv(d)` is valid only when `gic_rdists->has_direct_lpi && (is_v4_1(its_dev->its) || !irqd_is_forwarded_to_vcpu(d))`; GICv4.0 vLPIs must use `its_send_vinv()`. [F61, F105]
- `struct event_lpi_map` arrays (`lpi_map`, `col_map`, `vlpi_maps`) are indexed by `its_get_event_id(d)` (`d->hwirq - lpi_base`), whereas LPI property tables (`prop_table_va`, `vprop_page` in `lpi_write_config()`) are indexed by `hwirq - 8192`. Domain `hwirq`s in `mip_middle_domain_free()`, `gicv2m_unalloc_msi()`, `mbi_free_msi()`, and `its_irq_domain_free()` include controller offsets (`mip->msi_offset`, `v2m->spi_start`, `mbi->spi_start`, `lpi_base`) that must be subtracted before freeing bitmap regions (and `mip` GIC SPI fwspecs add `mip->msi_base`). [F85, F94, F128, F133]
- Callers must update `event_map.col_map[event]` before `its_send_mapti()`, but only after `its_send_movi()` because `its_build_movi_cmd()` reads the old collection via `dev_event_to_col()` for `SYNC`. In `its_set_affinity()`, `its_dec_lpi_count(d, prev_cpu)` precedes CPU selection, and every exit path must call `its_inc_lpi_count(d, cpu)` or branch to `err` to restore `prev_cpu`. [F59, F60]
- In `its_create_device()`, `dev->nr_ites` must be `max(2, nvecs)` and `dev->itt_sz >= ITS_ITT_ALIGN` (256) so `its_build_mapd_cmd()` encodes a non-negative `ilog2(nr_ites) - 1` size and 256B-aligned ITT. `col_map` must be sized to `nr_lpis` when `alloc_lpis` is true (`its_lpi_alloc()` may halve `nr_irqs`) and `nr_ites` when false (`vpe_proxy.dev`). [F89, F124]
- `its_allocate_entry()` must zero `cmd->raw_cmd[0..3]`, and every command builder must call `its_fixup_cmd(cmd)`. In `its_send_vmovp()`, `struct its_cmd_desc desc = {}` must be zero-initialized for the `!its_list_map` fast path. [F47, F48]
- `its->cmd_base`/`cmd_write` are `struct its_cmd_block *` (32B stride): `its_cmd_ptr_to_offset()` scales by `sizeof(*ptr)` for `GITS_CWRITER`, while `its_queue_full()` divides `GITS_CREADR` by `sizeof(struct its_cmd_block)` and wraps at `ITS_CMD_QUEUE_NR_ENTRIES`. In `its_wait_for_range_completion()`, add `ITS_CMD_QUEUE_SZ` to `to_idx` when `to_idx < prev_idx` and to `delta = rd_idx - prev_idx` when `rd_idx < prev_idx`, updating `prev_idx = rd_idx`. In `its_restore_enable()`, writing `GITS_CBASER` resets `GITS_CREADR` to 0, requiring `its->cmd_write = its->cmd_base` and `gits_write_cwriter(0, ...)`. [F67, F106, F126]
- `its_alloc_collections()` must set `target_address = ~0ULL` because `valid_col()` rejects non-zero low 16 bits, and when `!GITS_TYPER_PTA`, `GICR_TYPER_CPU_NUMBER()` must be left-shifted by 16 in `target_address`. [F49, F92]
- All `GITS_BASER<n>` writes must use `its_write_baser()` to update `baser->val` via `its_read_baser()`. When programming `GITS_BASER<n>`, `GITS_CBASER`, `GICR_PROPBASER`, or `GICR_PENDBASER`, if read-back shareability is 0, cacheability must be set to non-cacheable (`*_nC`). 52-bit PAs in `GITS_BASER` require `psz == SZ_64K` and `GITS_BASER_PHYS_52_to_48()` / `GITS_BASER_ADDR_48_to_52()`. [F68, F71, F95]
- In `its_parse_indirect_baser()`, `esz` must be `u64` for `esz << ids`. In `its_alloc_table_entry()` and `allocate_vpe_l2_table()`, bounds-check `id` (flat) or `idx = id >> ilog2(psz / esz)` (L1) before indexing `table[idx]`, writing L1 entries as `cpu_to_le64(page_to_phys(page) | GITS_BASER_VALID)`. `allocate_vpe_l1_table()` must use `DIV_ROUND_UP(npg * psz, PAGE_SIZE)`. [F91, F114, F118]
- In `its_vpe_set_affinity()`, whenever `from != cpu`, call `its_send_vmovp()` and `its_vpe_db_proxy_move()` after updating `vpe->col_idx` even if `from` and `cpu` share a `vpe_table_mask`. Under `vpe_proxy.lock`, `its_vpe_db_proxy_map_locked()`/`unmap_locked()` must keep `vpe->vpe_proxy_event` (`-1` when unmapped) and `vpe_proxy.vpes[slot]` synced, evicting any existing occupant at `next_victim` via `its_vpe_db_proxy_unmap_locked()` first. [F58, F63]
- `merge_lpi_ranges(a, b)` must check `&a->entry == &lpi_range_list || &b->entry == &lpi_range_list` before dereferencing `a` or `b`, and fold `a` into `b` (`kfree(a)`) so `new` remains valid in `free_lpi_range()`. [F100]
- `inherit_vpe_l1_table_from_rd()` must clear `GICR_VPROPBASER_4_1_Z` before writing `GICR_VPROPBASER`. On GICv4.1 (`GICR_TYPER_RVPEID`) in `__gic_update_rdist_properties()` and `allocate_vpe_l1_table()`, if `GICR_VPENDBASER_Valid` is set, write `GICR_VPENDBASER_PendingLast` (clearing `Valid`) before clearing `GICR_VPROPBASER_4_1_VALID` or writing `GICR_VPROPBASER`. In `its_vpe_deschedule()`, `its_clear_vpend_valid()` must poll `GICR_VPENDBASER_Dirty` clear before and after clearing `Valid`, saving `IDAI` and `PendingLast` into `vpe`. [F70, F74, F151]
- `redist_disable_lpis()` must execute `dsb(sy)`, wait for `GICR_CTLR_RWP` clear, and verify `GICR_CTLR_ENABLE_LPIS == 0` before `its_cpu_init_lpis()` writes `GICR_PROPBASER`/`PENDBASER`. In `its_cpu_init_lpis()`, when `RDIST_FLAGS_RD_TABLES_PREALLOCATED` and `GICR_CTLR_ENABLE_LPIS` are set, jumping to `out` skips `PROPBASER`/`PENDBASER`/`GICR_CTLR` but must still run GICv4 `has_vlpis` and `allocate_vpe_l1_table()`. [F77, F141]
- `its_of_probe()` and `its_acpi_probe()` must run `its_reset_one()` on all ITS instances in a separate pass before calling `its_probe_one()` on any instance, aborting all if any reset fails. `its_enable_quirks(its)` must run at the start of `its_probe_one()` before `is_v4()`, `its_alloc_pages_node()`, or `its_alloc_tables()`, and `struct gic_quirk` arrays must end with a `.desc = NULL` sentinel. [F97, F139, F142]
- In `irq-gic-v3.c`, `gic_chip` (EOImode 0) and `gic_eoimode1_chip` (EOImode 1) must stay in sync for shared callbacks, flags, and EOI errata. EPPIs (`EPPI_BASE_INTID..+63`) map to rdist index `hwirq - EPPI_BASE_INTID + 32` (`__gic_get_rdist_index()`) and `ppi_descs` index `hwirq - EPPI_BASE_INTID + 16` (`__gic_get_ppi_index()`), while ESPIs map to `GICD_I*nE` at `hwirq - ESPI_BASE_INTID`. In `gic_iterate_rdists()`, stop when `fn` returns `0` or `single_redist` is true, and when `!redist_stride` advance `ptr` by an extra `SZ_64K * 2` if `typer & GICR_TYPER_VLPIS`. [F82, F96, F103]
- `gic_cpu_sys_reg_enable()` must precede `gic_prio_init()`, `gic_cpu_init()`, and `gic_cpu_sys_reg_init()` on boot, `gic_starting_cpu()`, and `gic_cpu_pm_notifier()`. In `gic_prio_init()`, when `FLAGS_WORKAROUND_INSECURE` is set and `!gic_dist_security_disabled()`, set `GICD_CTLR_DS` only if `cpus_have_group0` (else set `nmi_support_forbidden = true`). In `gic_dist_init()`, zero `GICD_CTLR` + `gic_dist_wait_for_rwp()` before configuring SPIs, and enable `GICD_CTLR_ARE_NS` + `gic_dist_wait_for_rwp()` before writing `GICD_IROUTER*`. [F135, F137, F146]
- Validate DT indices `< max` before indexing `cb->irq_map[entry]` in `crossbar_of_init()`; validate `[spi_start, spi_start + nr_spis)` via `is_msi_spi_valid()` (`32..1019`) before allocating `v2m->bm` in `gicv2m_init_one()`; allocate `smr_cache` with `DIV_ROUND_UP(nirqs, 32) * 32` entries in `sama5d2_aic5_of_init()`. [F83, F86, F119]

## Synchronization
- `its_irq_set_vcpu_affinity()` runs with IRQs disabled under `irq_desc` lock and must acquire `its_dev->event_map.vlpi_lock` via `raw_spinlock` (or `raw_spinlock_irqsave`, never `raw_spinlock_irq`) across all VLPI helpers (`its_vlpi_map/get/unmap/prop_update`), which must use `GFP_ATOMIC`. [F1, F18, F166]
- `its->dev_alloc_lock` (mutex) serializes device allocation/teardown in `its_msi_prepare()`/`teardown()`, while `its->lock` (`raw_spin_lock_irqsave`) nests inside it to protect `its_device_list` and command queue writes. `its_send_single_command()`/`vcommand()` must hold `its->lock` across allocation, encoding, `its_flush_cmd()`, reading `GITS_CREADR`, and `its_post_commands()`, dropping it before `its_wait_for_range_completion()`. [F24, F163]
- GICv4 ITSList operations (`its_map_vm()`, `its_unmap_vm()`, `its_vpe_set_affinity()`, `its_send_vmovp()`) must nest locks in order `vm->vmapp_lock` -> `vpe->vpe_lock` -> `vmovp_lock` -> `its->lock`, with `vmovp_lock` serializing `vmovp_seq_num` and `GITS_CMD_VMOVP` across ITS nodes. In `its_vpe_4_1_deschedule()`, when `info->req_db` is true, hold `vpe->vpe_lock` with IRQs disabled across `its_clear_vpend_valid()` and updating `vpe->pending_last`. [F29, F164]
- In `its_alloc_table_entry()` and `allocate_vpe_l2_table()`, flush the zeroed L2 page to PoC (if non-shareable) before writing `page_to_phys(page) | GITS_BASER_VALID` into `table[idx]`, then flush `table + idx` (if non-shareable) and execute `dsb(sy)`. [F27]
- Before sending IPIs, `gic_ipi_send_mask()` requires `dsb(ishst)` (and `isb()` after `ICC_SGI1R_EL1`) and `bcm2836_arm_irqchip_ipi_send_mask()` requires `smp_wmb()`. `gic_complete_ack()` requires `isb()` after `ICC_IAR1_EL1` (and `ICC_EOIR1_EL1`) before calling the domain handler. `__gic_handle_irq_from_irqsoff()` must mask regular IRQs via `gic_pmr_mask_irqs()` + `isb()` before `gic_read_iar()`, then restore `ICC_PMR_EL1`. In `gic_irq_set_irqchip_state()`, follow `gic_poke_irq(d, GICD_ISACTIVER)` with `gic_peek_irq(d, reg)`. [F33, F149, F169, F174]
- In `irq-atmel-aic5.c`, lock `&bgc->lock` on chip 0 (`irq_get_domain_generic_chip(domain, 0)`) while updating `gc->mask_cache` (`&= ~d->mask` or `|= d->mask`) on `gc = irq_data_get_irq_chip_data(d)`. `aic_irq_domain_xlate()` and `aic5_irq_domain_xlate()` must use `guard(raw_spinlock_irqsave)`. [F64, F108, F158]

## Object Lifetimes
- `its_alloc_pages_node()` and `its_free_pages()` pass `order` to `alloc_pages_node()`/`free_pages()` but `1 << order` to `set_memory_decrypted()`/`encrypted()`, and must leak pages if encryption state change fails. `its_create_device()` must save the exact `sz` passed to `itt_alloc_pool()` in `dev->itt_sz` for `itt_free_pool()`. [F3, F123, F125]
- `its_vlpi_map()` increments `nr_vlpis` and calls `its_map_vm()` only when `!irqd_is_forwarded_to_vcpu(d)`; `its_vlpi_unmap()` clears `its_dev->event_map.vm = NULL` and frees `vlpi_maps` when `!--nr_vlpis` hits 0. `its_msi_teardown()` must hold `its->dev_alloc_lock` and skip freeing LPIs, `its_send_mapd(its_dev, 0)`, and `its_free_device()` if `its_dev->shared` or `!bitmap_empty(lpi_map, ...)`. [F6, F7]
- In `its_cpu_memreserve_lpi()`, if `RD_LOCAL_PENDTABLE_PREALLOCATED` is set, free `gic_data_rdist()->pend_page` via `its_free_pending_table()` and set `pend_page = NULL`; else call `gic_reserve_range()`. [F9]
- `gicv2m_init_one()` takes ownership of `fwnode` only on success; on failure, callers must call `of_node_put(child)` (including on early loop break in `gicv2m_of_init()`) or `irq_domain_free_fwnode(fwnode)`. Never mark `gicv2m_get_fwnode()` or `gic_v3_get_gsi_domain_id()` `__init`. [F13, F99, F134]
- In `gic_runtime_resume()`, return `0` after enabling clocks if `chip_pm->chip_data` is `NULL` (since `gic_probe()` resumes before `gic_of_init_child()`), and unwind runtime PM and `irq_dispose_mapping(irq)` if `gic_probe()` fails. [F16]

## API Contracts
- `gic_retrigger()`, `its_irq_retrigger()`, and `its_vpe_retrigger()` must negate (`!`) the return of `*_set_irqchip_state()`. [F40]
- `its_irq_set_vcpu_affinity()` must check `!info` (signifying `its_vlpi_unmap()`) before dereferencing `info->cmd_type`, and `its_vlpi_get/unmap/prop_update()` must check `its_dev->event_map.vm && irqd_is_forwarded_to_vcpu(d)` before indexing `vlpi_maps`. [F44]
- Upper-layer ITS `msi_prepare` callbacks must set `info->scratchpad[0].ul` to the DeviceID and round `nvec` to a power of two before calling parent `msi_prepare()`. `gicv2m_irq_domain_alloc()`/`unalloc_msi()` also require power-of-two `nr_irqs`. [F52, F88, F121]
- `its_sgi_irq_domain_deactivate()` must call `its_configure_sgi()` twice (`false` to disable, `true` to clear pending). `its_build_vmapp_cmd()` must return `NULL` when `!desc->its_vmapp_cmd.valid && is_v4_1(its)` to avoid emitting `GITS_CMD_VSYNC`. In `its_vpe_set_affinity()`, when `!atomic_read(&vpe->vmapp_count)`, return `-EINVAL` only if `gic_requires_eager_mapping()`; else update effective affinity and return `IRQ_SET_MASK_OK_DONE`. [F56, F98, F140]
- `msi_parent_ops` using `msi_lib_init_dev_msi_info()` over fasteoi parents (`mip`, `gic_v3_its`, `gic_v5_its`, `gicv2m`, `gic_v3_mbi`) must set `MSI_CHIP_FLAG_SET_EOI` and omit `MSI_CHIP_FLAG_SET_ACK`. In `mbi_init_dev_msi_info()`, enable level MSI (`IRQCHIP_SUPPORTS_LEVEL_MSI`, `MSI_FLAG_LEVEL_CAPABLE`) only for `DOMAIN_BUS_DEVICE_MSI` with `mbi_compose_mbi_msg()`. [F175, F176, F180]
- GIC MSI `.alloc` callbacks must call `iommu_dma_prepare_msi(info->desc, msi_addr)` and `.irq_compose_msi_msg` must use `msi_msg_set_addr()`. Child domains of `gic_irq_domain_translate()` must pass a 3-cell `irq_fwspec` on OF (`param[1] = hwirq - 32` for SPIs; `GIC_IRQ_TYPE_LPI` for LPIs) and 2-cell (`param[0] = hwirq, param[1] = type`) when `is_fwnode_irqchip()`. [F179, F181]
- `gic_eoimode1_mask_irq()` must write `GICD_ICACTIVER` when `irqd_is_forwarded_to_vcpu(d)` is set. `gic_irq_domain_map()` must call `irqd_set_handle_enforce_irqctx(irqd)` on all mapped IRQs. [F182, F183]

## Error Handling
- In `its_vpe_irq_domain_alloc()`, verify `nr_ids >= nr_irqs` after `its_lpi_alloc()` (calling `its_lpi_free()` on shortfall), and once `vm->db_bitmap` and `vm->vprop_page` are set, delegate rollback solely to `its_vpe_irq_domain_free(domain, virq, i)`. [F2, F37]
- `crossbar_of_init()` must unwind `cb` allocations and reset `cb = NULL` on error. Callers of `aic_common_of_init()` must check `IS_ERR(domain)`. [F15, F39]
- `gic_cpu_pm_notifier()` must restore state on both `CPU_PM_EXIT` and `CPU_PM_ENTER_FAILED`. `gic_set_type()` must log `pr_warn()` and return `0` if `gic_configure_irq()` fails on a PPI/EPPI. Runtime GIC/ITS polling timeouts must use `pr_err_ratelimited()`. [F136, F188, F189]

## External Contracts
- Call `its_force_quiescent()` before writing `GITS_BASER<n>` or `GITS_CBASER`. `gic_mask_irq()` must wait for `RWP` after `GICD_ICENABLER`, and `gic_set_affinity()` must mask enabled IRQs while writing `GICD_IROUTER`. In `gic_enable_redist(false)`, verify `GICR_WAKER_ProcessorSleep` stuck before polling `ChildrenAsleep`. [F28, F34, F111]

## Known Pitfalls
- `gic_compute_target_list()` must decrement `cpu--` before setting `*base_cpu = cpu` on cluster mismatch. [F102]
- In `its_vpe_*mask_irq()`, pass `d->parent_data` to `lpi_write_config()`, but pass `d` and `d->parent_data->hwirq` to `its_vpe_send_inv()` / `__direct_lpi_inv()`. On GICv4.0, `its_vlpi_set_doorbell()` must use `its_send_vmovi()` (not `vmapti`) on mapped vLPIs. [F104, F186]
- Keep `fallthrough` across `case 8..4` in `gic_cpu_sys_reg_init()` (`ICC_AP0Rn_EL1` gated on `group0`). Test `numlpis > 2` in `its_lpi_init()`. Subtract `SZ_128K` when accessing `its->sgir_base + GITS_SGIR - SZ_128K`. [F109, F120, F127]
- Guard `GICD_TYPER2` reads with `!(gic_data.flags & FLAGS_WORKAROUND_CAVIUM_ERRATUM_38539)` after `gic_enable_quirks()`. Under `gic_nvidia_t241_erratum`, use `gic_dist_base_alias(d)` in `gic_peek_irq()`/`gic_set_type()` but `gic_data.dist_base` in `gic_poke_irq()`. Use `gic_poke_irq(d, GICD_ICACTIVER)` when `gic_arm64_erratum_2941627_needed(d)` is true in `gic_*eoi_irq()`. Skip `V2M_MSI_TYPER`/`IIDR` reads when `GICV2M_GRAVITON_ADDRESS_ONLY` is set. Reject `broken_rdists` in `gic_check_rdist()` (`CPUHP_BP_PREPARE_DYN`), not `gic_starting_cpu()`. [F145, F147, F148, F155, F173]
