# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 6)

Core PCI and Subfunction (SF) device lifecycle (`main.c`, `sf/`), firmware page allocation (`pagealloc.c`), MSI-X IRQ pools (`pci_irq.c`), SR-IOV VF lifecycle (`sriov.c`), hardware object wrappers (port, QoS, rate-limiting, RDMA), and Hardware Steering (HWS) action, STE pool, buddy allocator, and BWC matcher/rule engine (`steering/hws/`).

## Architecture & Data Flow
- Every `enum mlx5_cap_type` passed to `mlx5_core_get_caps()` / `mlx5_core_get_caps_mode()` must be in `types[]` in `main.c` so `mlx5_hca_caps_alloc()` pre-allocates `dev->caps.hca[cap_type]`. In `handle_hca_cap()`, enable `uar_4k` only when `MLX5_CAP_GEN_MAX(dev, uar_4k) && PAGE_SIZE > 4096`, with `log_uar_page_sz = PAGE_SHIFT - 12` and `cache_line_128byte = (cache_line_size() >= 128 ? 1 : 0)`. [F588, F697]
- For SFs (`mlx5_core_is_sf(dev)`), `dev->priv.irq_table` is `NULL`, so callers must use `mlx5_irq_table_get(dev)`. `sf_ctrl_pool` and `sf_comp_pool` stay `NULL` if `num_sf_ctrl + 1 > sf_vec_available`, so `mlx5_irq_table_get_comp_irq_pool()` and `ctrl_irq_pool_get()` must fall back to `pcif_pool`. When `!pci_msix_can_alloc_dyn(dev->pdev)`, `pcif_vec` and `total_vec` must be clamped to `pci_alloc_irq_vectors()`. [F565, F566, F674]
- MSI-X vector `0` in `pcif_pool` is statically allocated for the async IRQ: `mlx5_irq_alloc()` and `mlx5_system_free_irq()` must call `pci_msix_alloc_irq_at()` / `pci_msix_free_irq()` only when `i != 0 && pci_msix_can_alloc_dyn(dev->pdev)`. In `mlx5_irq_request_vector()`, add `MLX5_IRQ_VEC_COMP_BASE` (`1`) unless `!pool->xa_num_irqs.max` (single-IRQ mode, where `offset = 0` and `mlx5_irq_table_get_num_comp()` returns `1`). [F614, F675]
- `mlx5_irq_pool_is_sf_pool()` checks `!strncmp("mlx5_sf", pool->name, strlen("mlx5_sf"))`, and `pool->name` reserves `MLX5_MAX_IRQ_IDX_CHARS` bytes for `irq_sf_set_name()`. `MLX5_ADEV_NAME` must match `KBUILD_MODNAME`. `mlx5_sf_dev_table::sf_bar_length` must be `u64` so `sf_index * table->sf_bar_length` in `mlx5_sf_dev_add()` uses 64-bit math. SR-IOV `sriov->vfs_ctx[]` indices are 0-based, FW `function_id` is 1-based (`vf + 1`), and EC VF vports are `mlx5_core_ec_vf_vport_base(dev) + vf` (`+ func - 1` in `mlx5_core_func_to_vport()`). [F613, F642, F664, F679]
- In `pagealloc.c`, `fw_page->free_count`, `bitmask`, and `dev->priv.free_list` update in lockstep: `insert_page()` sets bits `[0, MLX5_NUM_4K_IN_PAGE)` to `1` (free) leaving upper bits `0` (so `fwp_fill_manage_pages_out()` must bound `for_each_clear_bit` to `MLX5_NUM_4K_IN_PAGE`), `alloc_4k()` unlinks `fp->list` at `free_count == 0`, `free_4k()` re-adds `fwp->list` on 0->1, and `free_fwp()` unlinks only when `in_free_list`. `page_root_xa` and `free_list` use the composite `get_function(func_id, ec_function)` key, which `alloc_4k()` must match. [F582, F584, F665]
- Jiffies deadlines in `wait_fw_init()`, `mlx5_reclaim_root_pages()`, `mlx5_wait_for_pages()`, `mlx5hws_bwc_queue_poll()`, and `hws_action_ste_pool_element_collect_stale()` must be `unsigned long` compared with `time_after()` / `time_before()`. `mlx5_reclaim_root_pages()` and `mlx5_wait_for_pages()` must reset `end = jiffies + ...` whenever progress (`nclaimed > 0` or `*pages < prev_pages`) is made. [F636, F653]
- In `buddy.c`, `max_order` must be `< 31`; `bitmap` and `num_free` have `max_order + 1` entries (`1 << (max_order - i)` bits), `mlx5hws_buddy_alloc_mem()` shifts `seg << order`, `mlx5hws_buddy_free_mem()` shifts `seg >> order`, and every `bitmap[order]` change must update `num_free[order]` in lockstep. [F599, F616, F647]
- For `MLX5HWS_TABLE_TYPE_FDB`, `mlx5hws_action_alloc_single_stc()` and `mlx5hws_action_free_single_stc()` must modify both `mlx5hws_pool_get_base_id()` and `mlx5hws_pool_get_base_mirror_id()`, resetting `obj_0_id` to `DROP` if mirror modify fails. `mlx5hws_action_template_process()` reserves `at->setters[0]` for jumbo STE jump-to-action and starts stages at `at->setters + 1`. In WQE setters, host-endian `arg_idx`, `stc.offset`, and `num_of_actions << 29` need `htonl()`, whereas `vlan_hdr` and `MLX5_ADDR_OF(set_action_in, single_action, data)` are already `__be32`. [F601, F624, F625]
- `hws_action_handle_tunnel_l3_to_l2()` allows only 14B (`HDR_LEN_L2`) or 18B (`HDR_LEN_L2_W_VLAN`) headers for `mlx5hws_action_prepare_decap_l3_data()`. `mlx5hws_action_create_dest_match_range()` requires `min, max <= 0xffff` and shifts `htonl(min << 16)` / `htonl(max << 16)`. In `hws_action_modify_write()`, `for (i = 0, j = 0; j < num_of_actions; i++, j++)` must test `BIT(i) & nop_locations` on source index `i` and increment `j` before copying. [F622, F623, F634]
- In HWS BWC, `mlx5hws_bwc_matcher::priority` must be `u32`. `mlx5hws_bwc_rule_create()` must check `mlx5hws_context_bwc_supported(ctx)` before `hws_bwc_gen_queue_idx(ctx)` (`% mlx5hws_bwc_queues(ctx)`). `mlx5hws_bwc_rule_action_update()` must walk to the last `bwc_rule->next_subrule` before `hws_bwc_rule_action_update()`. `hws_bwc_matcher_find_at()` starts at `i = 1` (skipping `at[0]`) and requires both `action_type_arr[j] == MLX5HWS_ACTION_TYP_LAST` and `rule_actions[j]` at end. `mlx5hws_bwc_queue_poll()` must clear `queue_full = false` and decrement `*pending_rules` on `ret > 0`, set `got_comp = !!ret`, and return `-ETIMEDOUT` when `!got_comp && time_after(jiffies, timeout)`. [F604, F633, F635, F640, F646]

## Synchronization
- `devl_lock(priv_to_devlink(dev))` must be acquired before `dev->intf_state_mutex` (`devl_assert_locked()` in `mlx5_load_one_devl_locked()` / `mlx5_unload_one_devl_locked()`). Removal/shutdown paths (`remove_one()`, `shutdown()`, `mlx5_sf_dev_remove()`, `mlx5_sf_dev_shutdown()`) must set `MLX5_BREAK_FW_WAIT` in `dev->intf_state` before draining `fw_reset` or `health` workqueues. [F539, F541]
- `dev->priv.page_root_xa` and `dev->priv.free_list` have no lock: runtime `PAGE_REQUEST` work must run on single-threaded `dev->priv.pg_wq`, and `mlx5_pagealloc_stop()` must unregister `pg_nb` and flush `pg_wq` before `mlx5_reclaim_startup_pages()`. [F544]
- `table->sf_state_lock` protects `sf->hw_state` and `table->function_ids`. In `mlx5_sf_dealloc()`, if `sf->hw_state != MLX5_VHCA_STATE_ALLOCATED`, call `mlx5_sf_hw_table_sf_deferred_free()` (`pending_delete = true`, `allocated = true` until `mlx5_sf_hw_vhca_event()` sees `ALLOCATED`), and erase/free `sf` under `sf_state_lock`. Both `mlx5_sf_dealloc()` and error paths after `mlx5_sf_alloc()` in `mlx5_sf_add()` must call `mlx5_sf_function_id_erase(table, sf)` before `mlx5_sf_free(table, sf)`. [F528, F552, F592]
- In `action_ste_pool.c`, `pool->lock` protects `elem->available` and `elem->full`: alloc/free must move `action_tbl` between `elem->full` (`mlx5hws_pool_empty()`) and `elem->available` and update `last_used = jiffies`. `hws_action_ste_pool_cleanup()` must collect stale tables under `p->lock` and destroy them via `hws_action_ste_table_cleanup_list()` after unlocking; `mlx5hws_action_ste_pool_uninit()` must call `cancel_delayed_work_sync(&ctx->action_ste_cleanup)` first. [F535, F554, F600]
- `ctx->bwc_send_queue_locks[idx]` protects `ctx->send_queue[mlx5hws_bwc_get_queue_id(ctx, idx)]` and `bwc_matcher->rules[idx]`. `hws_bwc_rule_list_add()` runs only after `hws_bwc_rule_create_sync()` succeeds under `queue_lock`; `mlx5hws_bwc_rule_destroy_simple()` and `hws_bwc_rule_action_update()` must lock `bwc_rule->bwc_queue_idx`, and `hws_bwc_rule_list_remove()` must run after `hws_bwc_rule_destroy_hws_sync()` and before `hws_bwc_rule_cnt_dec_with_shrink()` drops `queue_lock`. To extend `bwc_matcher->at` or resize/rehash `bwc_matcher->matcher`, unlock `queue_lock`, call `hws_bwc_lock_all_queues(ctx)`, revalidate (`hws_bwc_matcher_find_at()`, `rehash_required`, `num_of_rules`), and unlock via `hws_bwc_unlock_all_queues(ctx)`. [F556, F557, F558, F658]

## Object Lifetimes
- In `mlx5_init_one_devl_locked()`, when `mlx5_dev_is_lightweight(dev)` is true, skip both `mlx5_devlink_params_register()` and `mlx5_devlink_params_unregister()` in `err_load`. `mlx5_pci_close()` must call `mlx5_drain_health_wq(dev)` before `iounmap(dev->iseg)` and `release_bar(dev->pdev)`. Start health polling only after `mlx5_core_enable_hca()`, stop it before `mlx5_core_disable_hca()`, and in `mlx5_try_fast_unload()` restart it via `mlx5_start_health_poll(dev)` if both teardown commands fail. [F520, F521, F542, F668]
- `mlx5_irq_attach_nb()` must call `irq_get(irq)` before registering on `irq->nh`, and `mlx5_irq_detach_nb()` must unregister `nb` from `irq->nh` before `mlx5_irq_put(irq)`. [F546]
- In `rl.c`, `table->rl_lock` protects `table->refcount`, `table->rl_entry`, and entry fields; `find_rl_entry()` must skip `dedicated` entries. Rate add/remove must update `entry->refcount` and `table->refcount` (`mlx5_rl_table_get()` / `mlx5_rl_table_put()`) in lockstep under `table->rl_lock`, and `mlx5_rl_table_put()` must set `table->rl_entry = NULL` when freeing it at `refcount == 0`. [F526, F548, F593]
- Bulk HWS actions (`mlx5hws_action_create_reformat()`, `mlx5hws_action_create_modify_header()`, `hws_action_handle_tunnel_l3_to_l2()`) share one `arg_id` across an array of `mlx5hws_action`: rollback and `hws_action_destroy_hws()` must free per-element STCs/patterns across all initialized elements and destroy `arg_id` once. [F534]
- In `hws_bwc_matcher_move()`, once `mlx5hws_matcher_resize_set_target(old_matcher, new_matcher)` succeeds, it must set `bwc_matcher->matcher = new_matcher` and destroy `old_matcher` even if `hws_bwc_matcher_move_all()` fails; callers must re-read `bwc_matcher->matcher` after any call that may rehash or drop `queue_lock`. [F536, F597]

## API Contracts
- `mlx5_vf_get_core_dev()` returns a locked `mlx5_core_dev *` or `NULL` (never `ERR_PTR`). Callers of `mlx5_get_default_msix_vec_count()` must ensure `num_vfs > 0`. `mlx5_irq_get_locked()` and `irq_get()` return `1` on success and `0` on failure (`!ret`). `MLX5_FLEXIBLE_INLEN()` and `mlx5hws_buddy_alloc_mem()` return signed `int` (`< 0` on `-ENOMEM`), so callers must store the result in a signed `int` and check `< 0`. [F559, F561, F562, F563, F645]
- `mlx5_sf_coredev_to_adev(mdev)` requires `mlx5_core_is_sf(mdev)`, and `mlx5_sf_by_dl_port(dl_port)` requires an SF devlink port from `mlx5_sf_alloc()`. [F660, F662]
- `mlx5_query_port_fcs()` must initialize `*supported = false` and `*enabled = true` before any early return. `mlx5_set_dscp2prio()` (`MLX5_REG_QPDPM`) and `mlx5_set_port_fcs()` (`MLX5_REG_PCMR`) must query the register before modifying in place; `mlx5_set_port_stall_watermark()` must set `pptx_mask_n`, `pprx_mask_n`, and `ppan_mask_n` in `MLX5_REG_PFCC`. Query port buffer ownership via `mlx5_query_port_buffer_ownership()` rather than caching it. [F575, F586, F594]
- Hardware rate-limit indices in `rl.c` are 1-based, so `mlx5_rl_remove_rate_raw()` must index `table->rl_entry[index - 1]`. `mlx5_qos_create_leaf_node()` and `mlx5_qos_create_inner_node()` must check `mlx5_qos_element_type_supported()` and `mlx5_qos_tsar_type_supported()` before `mlx5_create_scheduling_element_cmd()`. [F577, F673]
- `mlx5hws_action_ste_chunk_alloc()` requires `chunk->ste.order` pre-initialized and `!(skip_rx && skip_tx)`. Action arrays for `mlx5hws_action_template_create()` / `mlx5hws_action_check_combo()` end with `MLX5HWS_ACTION_TYP_LAST`, and BWC `rule_actions[]` end with NULL `action` or `MLX5HWS_ACTION_TYP_LAST` within `MLX5HWS_BWC_MAX_ACTS`. `mlx5hws_pat_verify_actions()` and `mlx5hws_pat_get_pattern()` take byte sizes (`num_of_actions * MLX5HWS_MODIFY_ACTION_SIZE`), while `mlx5hws_pat_calc_nop()`, `mlx5hws_pat_require_reparse()`, and `mlx5hws_arg_create_modify_header_arg()` take action counts. `bwc_queue_idx` indexes `bwc_send_queue_locks[]` and `bwc_matcher->rules[]`, whereas `send_queue[]`, `rule_attr.queue_id`, and `mlx5hws_bwc_queue_poll()` require `mlx5hws_bwc_get_queue_id(ctx, bwc_queue_idx)`. [F579, F581, F619, F657]

## Error Handling
- `mlx5_access_reg()` calls `mlx5_cmd_check()` only when `verbose` is true. In `mlx5_rdma_enable_roce()`, zero-initialize `u8 mac[ETH_ALEN] = {}` in `mlx5_rdma_add_roce_addr()`, and unwind `mlx5_rdma_del_roce_addr()` and `mlx5_nic_vport_disable_roce()` on failure. In `hws_action_get_shared_stc_nic()`, errors after `kzalloc()` must jump to `free_shared_stc`, and `hws_action_put_shared_stc()` must set `ctx->common_res.shared_stc[stc_type] = NULL` at `refcount == 0`. [F527, F532, F572, F711]
- In `hws_bwc_matcher_extend_at()`, reject growth at `size_of_at_array >= MLX5HWS_MATCHER_MAX_AT`, halve `size_of_at_array` if `krealloc()` fails, and increment `num_of_at` only after `mlx5hws_action_template_create()` succeeds. In `mlx5hws_bwc_rule_create_simple()`, any error after `hws_bwc_rule_cnt_inc_with_rehash()` must call `hws_bwc_rule_cnt_dec(bwc_rule)`, and `-EBUSY`, `-ETIMEDOUT`, or `-EAGAIN` from `hws_bwc_rule_create_sync()` must return immediately without rehashing. In `hws_bwc_matcher_move_all_simple()`, on `mlx5hws_matcher_resize_rule_move()` error record `move_error` and `continue` without incrementing `pending_rules`, break on poll `-ETIMEDOUT`, and return the first of `move_error`, `poll_error`, or `drain_error`. [F538, F569, F571, F618, F627]

## External Contracts
- In `mlx5_sf_dev_probe()`, call `mlx5_core_peer_devlink_set()` before `mlx5_init_one_light()` / `mlx5_init_one()`. `mlx5_sf_activate()` may activate an inactive SF only when `sf->hw_state == MLX5_VHCA_STATE_ALLOCATED` (else `-EBUSY`). In `mlx5hws_action_create_dest_array()`, `MLX5HWS_ACTION_TYP_TBL` destinations must set `fte_attr.ignore_flow_level = 1`, and `is_wire_ft` must be placed at `dest_list[num_dest - 1]`. In `hws_action_fill_stc_attr()`, `remove_words.num_of_words` is in 2B words (`/ W_SIZE`), while `insert_header.header_size` and `insert_offset` are in bytes. [F576, F580, F700, F706]

## Known Pitfalls
- Zero `set_ctx` (`memset(set_ctx, 0, set_sz)`) before each `handle_hca_cap*()` call in `set_hca_cap()`. Use `dev->priv.numa_node` (not `dev_to_node()`) in `alloc_system_page()` and `mlx5_irq_table_init()`. On SFs, `mdev->pdev` is the parent PF's `pdev` and `auxiliary_set_drvdata()` is unused; get `mdev` via `container_of(adev, struct mlx5_sf_dev, adev)->mdev`. [F573, F585, F661]
- In `pagealloc.c`, clamp negative `npages` with `max_t(s32, npages, MAX_RECLAIM_NPAGES)` before negating, and define `MLX5_U64_4K_PAGE_MASK` as `((~(u64)0U) << PAGE_SHIFT)`. In `mlx5_port_ptys2info()`, widen `u32 eth_proto_oper` to `unsigned long` for `find_first_bit()` and check `i < max_size && table[i].speed != 0`. [F606, F611, F641, F667]
- `MLX5HWS_ACTION_TYP_REFORMAT_TNL_L3_TO_L2` uses `action->modify_header` (not `action->reformat`), and `hws_action_setter_insert_ptr()` / `hws_action_setter_tnl_l3_to_l2()` must index `rule_action->action + rule_action->reformat.hdr_idx`. In `mlx5hws_action_apply_setter()`, `setter->set_ctr` must run before `|= htonl(num_of_actions << 29)` on `stc_ix[MLX5HWS_ACTION_STC_IDX_CTRL]`. [F568, F602, F638]

## Other
- Read `&dev->iseg->initializing` (`wait_fw_init()`) and `health->health_counter` (`wait_vital()`) with `ioread32be()`, ignoring `0` and `0xffffffff` in `wait_vital()`. [F681]
