# ANALOG DEVICES INC IIO DRIVERS — drivers/iio (part 1)

This component contains Linux IIO accelerometer and ADC drivers for Analog Devices hardware (ADIS16201/16209, ADXL345/372, AD7124, AD7173/AD411x, AD7266, AD7280A, AD7291, AD7298, AD7405, AD7606, AD7766, AD7779, AD7791) across SPI, I2C, and parallel/IIO-backend buses.

## Architecture & Data Flow

- In `ad7124` and `ad7173`, runtime changes to `ad7124_channel_config` or `ad7173_channel_config` must update `cfg` and set `cfg->live = false` rather than writing directly to `AD7124_CONFIG`/`AD7124_FILTER` or `AD7173_REG_SETUP`/`AD7173_REG_FILTER`. Hardware setup fields must reside in `struct_group(config_props, ...)` and be mirrored in `static_assert` and field-by-field comparisons in `ad7124_find_similar_live_cfg()` and `ad7173_is_setup_equal()`. [F44, F106]
- Evicting a slot in `ad7124_pop_config()` or `ad7173_free_config_slot_lru()` must clear `st->channels[i].cfg.live = false` for all channels sharing `cfg_slot`. `ad7173_config_channel()` must call `ad7173_reset_usage_cnts()` when `st->config_usage_counter == U64_MAX`. In `ad7173`, `ad_sigma_delta_info.num_slots` must equal `info->num_channels` (4/8/16), while setup slot IDA allocation is bounded by `info->num_configs` (4/8). In `ad7173_write_raw()` and `ad7173_fw_parse_channel_config()`, update both `cfg->sinc5_odr_index` and `cfg->sinc3_odr_div` in lockstep, clamping `sinc3_odr_div` to `[1U, AD7173_FILTER_SINC3_MAP_DIV]`. [F45, F49, F97, F98, F123]
- In `ad7124_parse_channel_config()`, `num_channels <= AD7124_MAX_CHANNELS` (16), child `"reg" < num_channels`, and `"diff-channels"` pins must pass `ad7124_valid_input_select()`. In `ad7173_fw_parse_channel_config()`, validate current pins with `ad4111_validate_current_ain()` and voltage pins with `ad7173_validate_voltage_ain_inputs()`, which forbids mixing divided (`< num_voltage_in_div`) and undivided pins or `AD4111_VINCOM_INPUT` (`AD4111_IS_VINCOM_MISMATCH`). [F64, F65, F66, F124]
- In `__ad7124_calibrate_all()` and `ad7173_calibrate_all()`, skip channels with `type != IIO_VOLTAGE`; in `__ad7124_calibrate_all()`, full-scale calibration (`AD7124_ADC_CONTROL_MODE_INT_GAIN_CALIB`, when `pga_bits > 0`) must run and read back `AD7124_GAIN` before zero-scale calibration (`AD7124_ADC_CONTROL_MODE_INT_OFFSET_CALIB`). [F87]
- In `adxl345_core.c`, runtime reconfiguration (`adxl345_set_fifo()`, `adxl345_set_act_inact_en()`, `adxl345_write_raw()`, `adxl345_write_event_value()`, `adxl345_fifo_reset()`) must bracket register writes with `adxl345_set_measure_en(st, false)` and `adxl345_set_measure_en(st, true)`. In `adxl345_set_range()`, sample `range_old` from `ADXL345_REG_DATA_FORMAT` first, then rescale `ADXL345_REG_THRESH_ACT` and `st->inact_threshold` (via `adxl345_set_inact_threshold()`, writing `THRESH_INACT` and `THRESH_FF`) by `adxl345_range_factor_tbl` clamped to `[1, U8_MAX]`. In `adxl345_set_odr()`, follow `ADXL345_REG_BW_RATE` updates with `adxl345_set_inact_time(st, 0, 0)`. [F26, F54, F55, F104]
- In `adxl345_push_event()`, check each flag in `int_stat` with an independent `if` (not `else if`), defaulting `ret` to `-ENOENT` so unhandled interrupts trigger `adxl345_fifo_reset()`. [F88]
- In `ad7606_set_sampling_freq()`, sample `is_swinging` (`ad7606_pwm_is_swinging(st)`) and `is_high` (`duty_cycle == period`) before overwriting `cnvst_pwm_state.period`, updating `duty_cycle` to `period`, `period / 2`, or `0`. In `ad7606_get_chan_config()`, convert 1-based DT `"reg"` (`1..num_adc_channels`) to 0-based `reg - 1`. Scale lookups/updates index `st->chan_info[0]` when `!st->sw_mode_en` and `st->chan_info[chan->scan_index]` when `st->sw_mode_en`, passing `i + ci->reg_offset` to `st->write_scale()` while storing `i` in `ci->range`. In `ad7616_write_scale_sw()`, split interleaved channel `ch` into group `ch & 0x1` and `ch_index = ch >> 1` before `AD7616_RANGE_CH_ADDR/MSK/MODE`. [F56, F57, F69, F71]
- In `ad7606_par16_read_block()` and `ad7606_par8_read_block()`, when `st->gpio_frstdata` is set, read the first sample alone and verify `gpiod_get_value(st->gpio_frstdata)` is high before advancing `_buf` and decrementing `num`; if low, call `ad7606_reset(st)` and return `-EIO`. Callbacks using `to_spi_device(st->dev)` must only be wired into `ad7606_*_spi_bops` or `st->offload_en` paths, never `ad7606_par.c` paths. [F91, F113]
- In `ad7280a.c`, `ad7280_chain_setup()` must loop `n` from `0` through `AD7280A_MAX_CHAIN` inclusive (`slave_num = n - 1`). When `oversampling_ratio`, `acquisition_time`, or `slave_num` changes, call `ad7280_update_delay(st)` using `DIV_ROUND_UP(st->readback_delay_us, 1000)` before adding 5 us. SPI writes compute CRC-8 over `reg >> 11` into `GENMASK(10, 3)` before ORing `AD7280A_TRANS_WRITE_RES_PATTERN`; reads verify CRC-8 over `val >> 10` against `GENMASK(9, 2)` and use distinct `CONV_*` vs `REG_*` masks. [F59, F76, F93, F102]
- In `ad7779.c`, `ad7779_set_filter()` must call `ad7779_set_sampling_frequency(st, st->sampling_freq)` and update `st->filter_enabled`, and `ad7779_set_data_lines()` must update `ad7779_set_sampling_frequency()`, `iio_backend_num_lanes_set()`, and `AD7779_REG_DOUT_FORMAT` together. [F60]
- In `ad7291` and `ad7298`, voltage channel `x` (`0..7`) uses reversed bits `BIT(15 - x)` in `AD7291_COMMAND` and `AD7298_CH(x) = BIT(13 - x)`. In `ad7291.c`, `chip->command` must keep `AD7291_T_SENSE_MASK` set and set `chip->c_mask | AD7291_AUTOCYCLE` iff `chip->c_mask != 0`; `ad7291_read_raw()` must return `-EBUSY` when `AD7291_AUTOCYCLE` is set and must not persist single-channel bits into `chip->command`. [F62, F78]
- In `adxl345_state`, `ad7266_state`, `ad7280_state`, `ad7298_state`, `ad7606_state`, `ad7766`, and `ad7779_state`, `__aligned(IIO_DMA_MINALIGN)` buffers (`data`, `fifo_buf`, `tx`, `rx_buf`) must stay at the end of the struct after CPU-modified fields and hold all channel samples plus an `aligned_s64` timestamp. [F136, F156]

## Synchronization

- In `ad7124.c`, acquire `iio_device_claim_direct()` before `st->cfgs_lock` (never while holding `st->cfgs_lock`), since `ad7124_update_scan_mode()` takes `st->cfgs_lock` under IIO `mlock`. In `ad7173.c`, setup mutations and calibrations (`ad7173_write_raw()`, `ad7173_set_filter_type()`, `ad7173_write_syscalib()`) must hold `iio_device_claim_direct()`, and `ad7173_set_channel()` requires process context (`GFP_KERNEL` IDA allocation in `ad7173_load_config()`). [F16, F143]
- In `ad7606.c`, `ad7606_write_raw()` acquires `st->lock` before `iio_device_claim_direct()`, so callbacks under IIO `mlock` (`ad7606_update_scan_mode()`, `ad7606_buffer_ops`, `ad7606_backend_buffer_ops`) must never acquire `st->lock`. `ad7606_interrupt()` calls `iio_trigger_poll_nested(st->trig)` from a threaded IRQ, so `ad7606_trigger_handler()` must get timestamps via `iio_get_time_ns(indio_dev)` rather than `pf->timestamp`. [F17, F138]
- Direct-mode sysfs callbacks must wrap hardware transfers in `iio_device_claim_direct()`/`iio_device_release_direct()`: `ad7606_read_raw()` (`RAW`, `CALIBBIAS`, `CONVDELAY`), `ad7779_read_raw()`/`ad7779_write_raw()`, and `ad7266_read_raw()`/`ad7298_read_raw()`. In `ad7291.c`, hold `chip->state_lock` across checking `!(chip->command & AD7291_AUTOCYCLE)`, writing `AD7291_COMMAND`, and reading `AD7291_VOLTAGE` in `ad7291_read_raw()`, and across updating `chip->c_mask` and `chip->command` in `ad7291_write_event_config()`. [F18, F20, F24, F142]

## Object Lifetimes

- In `ad7606_probe()`, when `!st->gpio_convst || st->offload_en`, acquire `st->cnvst_pwm` via `devm_pwm_get()`, set it low via `ad7606_pwm_set_low()`, and register `ad7606_pwm_disable()` via `devm_add_action_or_reset()` before `st->bops->iio_backend_config()`. Keep `st->cnvst_pwm` enabled at `duty_cycle = 0` via `ad7606_pwm_set_low()` when conversions stop (never `pwm_disable()` at runtime), and in `ad7606_scan_direct()`, reset `st->gpio_convst` or `st->cnvst_pwm` low on all exit paths. In `ad7606_spi_offload_buffer_postenable()`, acquire `spi_optimize_message()`, `spi_offload_trigger_enable()`, and `ad7606_pwm_set_swing()` in order and release in reverse order on error and in `ad7606_spi_offload_buffer_predisable()`. [F1, F9, F10, F127]
- In `ad7766_preenable()`/`ad7766_postdisable()`, enable `ad7766->reg` before and disable after `ad7766->mclk`, asserting `ad7766->pd_gpio` high and sleeping 20 ms before `clk_disable_unprepare(ad7766->mclk)`. In `ad7766_probe()` and `ad7779_setup_without_backend()`, request `spi->irq` with `IRQF_NO_AUTOEN` and balance `enable_irq()`/`disable_irq()` in `ad7766_set_trigger_state()` and `ad7779_buffer_preenable()`/`ad7779_buffer_postdisable()`. Call `iio_trigger_get(st->trig)` when assigning `indio_dev->trig = st->trig` in `ad7606_probe()` and `ad7779_setup_without_backend()`. [F2, F11, F12]
- In `ad7173.c`, initialize every channel's `cfg.openwire_comp_chan = -1` in `ad7173_fw_parse_channel_config()`, and in `ad4111_openwire_event()`, reset `adchan->cfg.openwire_comp_chan = -1` and clear `AD4111_GPIO_GP_OW_EN` in `st->reg_gpiocon_regmap` on all exit paths. In `ad7280_chain_setup()`, write `AD7280A_CTRL_HB_PWRDN_SW` to `AD7280A_CTRL_HB_REG` on error after software reset, and register `ad7280_sw_power_down()` via `devm_add_action_or_reset()` in `ad7280_probe()`. [F4, F7, F34]
- In `ad7124_probe()` and `ad7173_probe()`, call `devm_ad_sd_setup_buffer_and_trigger()` before `ad7124_calibrate_all()` and `ad7173_setup()`. In `adxl345_core_probe()`, clear `ADXL345_REG_INT_ENABLE` and complete `devm_iio_kfifo_buffer_setup()` before `devm_request_threaded_irq()`. [F14, F25]

## API Contracts

- In `ad7173.c` and `ad7124.c`, pass the 0-based channel slot index (`chan->address` or loop index `i`)—never `chan->channel` or `ch->ain`—to `ad_sd_calibrate()` and `ad_sigma_delta_info` callbacks. In `ad7124_calibrate_all()`, lower `AD7124_ADC_CONTROL_POWER_MODE` in `st->adc_control` to `AD7124_MID_POWER` if `>= AD7124_FULL_POWER` before `__ad7124_calibrate_all()` and restore afterward. In `ad7173_update_scan_mode()`, if any enabled channel uses `AD7173_FILTER_SINC3`, all must share `AD7173_FILTER_SINC3` and `sinc3_odr_div`, and if two enabled channels with unequal setups (`!ad7173_is_setup_equal()`) share a `cfg_slot`, clear `st->channels[k].cfg.live = false` on all channels before returning `-EINVAL`. [F29, F118, F157]
- In `ad7606.c`, `ad7606_set_sampling_freq()` must reject `freq == 0` with `-EINVAL` and use `DIV_ROUND_UP_ULL(NSEC_PER_SEC, freq)`. Pass a `DECLARE_BITMAP(..., 3)` bitmap to `gpiod_multi_set_value_cansleep()` in `ad7606_write_os_hw()` and `ad7606b_sw_mode_setup()`. In `ad7606_spi_reg_read()`, set `.cs_change = 1` on `st->d16[0]`. In `ad7606_reg_access()`, when `readval` is non-NULL, store `*readval = ret` and return `0`. [F100, F107, F125, F153]
- In `ad7606_probe()`/`ad7606_probe_channels()`, when `st->bops->iio_backend_config` or `st->offload_en` is used, omit `IIO_CHAN_SOFT_TIMESTAMP`, and when `st->bops->iio_backend_config` is set, omit `INDIO_DIRECT_MODE` and `BIT(IIO_CHAN_INFO_RAW)`. When `ad7779` or `ad7173` uses an IIO backend or SPI offload (`ad7779_setup_channels()`, `ad7173_fw_parse_channel_config()`), copy static `iio_chan_spec` templates into per-device memory and set `scan_type.endianness = IIO_CPU`. [F149, F151]
- In `ad7280a.c`, pass a bit-reversed address via `ad7280a_devaddr()` (`chan->address >> 8`), never a sequential `0..slave_num` index, to `ad7280_write()`, `ad7280_read_reg()`, and `ad7280_read_channel()`. In `ad7779.c`, `ad7779_conf()` must enable `AD7779_SPI_CRC_EN_MSK` in `AD7779_REG_GEN_ERR_REG_1_EN` first, and `ad7779_spi_read()`/`ad7779_spi_write()` must omit the 3rd CRC8 byte iff `reg == AD7779_REG_GEN_ERR_REG_1_EN`. [F39, F133]
- When `.read_avail` (`adxl345`, `ad7124`, `ad7606`) returns `IIO_AVAIL_LIST` for a `[][2]` pair table, set `*length` to twice the pair count (`ARRAY_SIZE(...) * 2` or `ci->num_scales * 2`). In `iio_chan_spec_ext_info.write` callbacks, return `len` (`ret ?: len`) on success. Triggered buffer poll handlers (`ad7606`, `ad7779`, `ad7266`, `ad7298`, `ad7766`) must call `iio_trigger_notify_done()` on all exit paths (and `ad7606_trigger_handler()` must re-assert `st->gpio_convst` high). [F111, F152, F155]

## Error Handling

- In `ad7606.c`, check optional `ad7606_bus_ops` callbacks (`sw_mode_config`, `update_scan_mode`, `offload_config`, `iio_backend_config`) for NULL before calling, check boolean `st->offload_en` rather than `st->bus_data` or `bus_data->offload` (`ERR_PTR(-ENODEV)` when absent), and only use `st->cnvst_pwm` helpers or `IIO_CHAN_INFO_SAMP_FREQ` when `!st->gpio_convst || st->offload_en`. [F28, F31, F41]
- When a helper (`ad7266_read_single`, `ad7606_scan_direct`, `ad7298_scan_direct`, `iio_backend_oversampling_ratio_set`) runs under `iio_device_claim_direct()`, release direct mode and check `ret < 0` before using `*val` or mutating state. In `ad7124_write_raw()` (`IIO_CHAN_INFO_SAMP_FREQ`), reject negative values and `val == 0 && val2 == 0` before `ad7124_set_channel_odr()`. [F30, F94]
- When `devm_regulator_get_optional()` returns `ERR_PTR(-ENODEV)`, `ad7124_probe()` must keep `st->vref[i]` as `ERR_PTR(-ENODEV)` for `IS_ERR(st->vref[refsel])` in `ad7124_init_config_vref()`, whereas `ad7291_probe()` and `ad7298_probe()` must set `chip->reg` / `st->reg = NULL`. In `adxl345_core.c`, check the signed tri-state return of `adxl345_is_act_inact_ac()` and `adxl345_is_act_inact_en()` for `< 0` before boolean use, and compare `adxl345_get_int_line()` against `ADXL345_INT_NONE` (`0xff`) rather than `< 0` or `0` (`ADXL345_INT1`). [F32, F33, F36, F37]

## External Contracts

- In `ad7606_probe_channels()`, when `st->sw_mode_en` is true, place `BIT(IIO_CHAN_INFO_OVERSAMPLING_RATIO)` in `info_mask_shared_by_type` on slow buses and `info_mask_shared_by_all` on backend/offload buses. In `ad7173_temp_iio_channel_template` and `ad7124_parse_channel_config()`, do not set `.indexed = 1` on `IIO_TEMP`. In `adxl345_fifo_transfer()`, when `st->fifo_delay` is true (SPI `> 1.5 MHz`) and `samples > 1`, call `udelay(3)` after each 6-byte FIFO read. [F79, F144, F148]

## Known Pitfalls

- In `ad7606_spi_offload_buffer_postenable()`, compute `xfer->len` from `scan_type->realbits` (`(realbits > 16 ? 4 : 2) * num_adc_channels`), not `storagebits`. In `ad7606_scan_direct()`, read `st->data.buf32[ch]` when `realbits > 16` else `buf16[ch]`, and mask with `GENMASK(realbits - 1, 0)` before `sign_extend32()`; in `ad7606_spi_reg_write()`, mask `val & 0xFF`. In `ad7606_par8_read_block()`, `_buf` is `u16 *` while `insb()` takes byte counts (`insb(..., _buf, 2)`, `_buf++`, then `insb(..., _buf, num * 2)`). In `ad7606_par_probe()`, use `device_get_match_data(&pdev->dev)` when `dev_fwnode(&pdev->dev)` is present, and if `"io-backends"` is present, call `ad7606_probe()` with `&ad7606_bi_bops` before requesting IRQ/MMIO. [F72, F73, F109, F126, F128]
- In `ad7173_fw_parse_channel_config()`, reset `is_current_chan = false` and `*chan = ad7173_channel_template` each iteration, account for the temperature channel at index 0 (`chan_index = 1`) when `st->info->has_temp` is true, and start ODR indices at `st->info->odr_start_value` (also in `ad7173_write_raw()`). Clear shadow bitfields in `st->adc_mode` and `st->adc_control` with `& ~mask` before `|= FIELD_PREP(...)`. Widen 64-bit math in `ad7173_read_raw()` (`u64 temp << realbits` with `DIV_U64_ROUND_CLOSEST()`) and `ad7779_set_calibscale()` (`val * 5592405LL` with `DIV_ROUND_CLOSEST_ULL(..., MEGA)`). [F81, F82, F83, F96, F99, F122]
- In `adxl345_core_probe()`, run bus `setup()` before reading `ADXL345_REG_DEVID` and update `ADXL345_REG_DATA_FORMAT` via `regmap_update_bits()` with `data_format_mask`. In `adxl345_read_raw()` (`CALIBBIAS`), call `sign_extend32(regval, 7)` before `* 4`. In `adxl345_fifo_transfer()`/`adxl345_fifo_push()`, index `__le16 st->fifo_buf` by `i * ADXL345_DIRS` and pass `sizeof(st->fifo_buf[0]) * ADXL345_DIRS` to `regmap_bulk_read()`. In `ad7298_update_scan_mode()`, command transfers use `ring_xfer[0..1]`, samples use `ring_xfer[i + 2]` (`cs_change = 1`), and `ring_xfer[i + 1].cs_change = 0` clears `cs_change` on the final transfer after the loop. [F92, F103, F110, F116]
