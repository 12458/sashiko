# ETHERNET PHY LIBRARY — drivers/net

Provides MDIO bus controllers, MDIO bus multiplexers, OpenFirmware/ACPI/fwnode MDIO registration helpers, XPCS platform glue, and vendor Ethernet PHY drivers/libraries (including Aquantia, Broadcom, Airoha EN8811H, ADIN1100, and AX88796B). It bridges hardware MDIO/I2C/GPIO/MMIO interfaces and firmware descriptions to the kernel phylib, hwmon, LED, clock, and PTP timestamping subsystems.

## Architecture & Data Flow

- In `of_phy_register_fixed_link()`, `struct fixed_phy_status status` must be zero-initialized (`= {}`) at declaration because the `"in-band-status"` branch jumps directly to `register_phy:` without assigning any fields, relying on `status.link` and all other members being zero. [F47]
- In drivers/net/phy/air_en8811h.c, manual LED updates in air_hw_led_on_set() (when !on), air_led_blink_set(), and air_led_brightness_set() must clear priv->led[index].rules to 0, while air_led_hw_control_set() must clear AIR_PHY_LED_STATE_FORCE_ON and AIR_PHY_LED_STATE_FORCE_BLINK in priv->led[index].state. [F57]
- In drivers/net/mdio/mdio-mux-multiplexer.c, mdio_mux_multiplexer_switch_fn() and mdio_mux_multiplexer_remove() must only call mux_control_deselect(s->muxc) when s->do_deselect is true, and mdio_mux_multiplexer_switch_fn() must update s->do_deselect to true only when mux_control_select() succeeds and false when it fails. [F59]
- In drivers/net/phy/bcm-phy-ptp.c, any operation under priv->mutex that triggers a CPU framesync on NSE_CTRL must first clear NSE_FRAMESYNC_MASK | NSE_CAPTURE_EN via bcm_ptp_framesync_disable(), call bcm_ptp_framesync(), and restore priv->nse_ctrl via bcm_ptp_framesync_restore(). [F63]
- In drivers/net/phy/bcm-phy-ptp.c, bcm_ptp_settime_locked() must pass NSE_INIT to bcm_ptp_framesync() so SHADOW_LOAD (TIME_CODE_LOAD | NCO_TIME_LOAD) takes effect and auto-clears, whereas bcm_ptp_adjfine() triggers bcm_ptp_framesync() without NSE_INIT and must explicitly write 0 to SHADOW_LOAD after loading FREQ_LOAD. [F64]
- In drivers/net/phy/bcm-phy-ptp.c, reading captured timestamps in bcm_ptp_get_framesync_ts() and bcm_ptp_get_tstamp() must begin by writing HB_READ_START to HB_STAT_CTRL (or TS_READ_START to TS_READ_CTRL) and finish by writing HB_READ_END followed by 0 to HB_STAT_CTRL (or TS_READ_END followed by 0 to TS_READ_CTRL). [F65]
- In drivers/net/phy/aquantia/, aqr_phy_led_polarity_set() must record active-low and active-high LED indices in priv->leds_active_low and priv->leds_active_high, and aqr_gen1_config_init() must iterate over both bitmasks after reset to restore LED polarity via aqr_phy_led_active_low_set(). [F67]
- In drivers/net/phy/air_en8811h.c, en8811h_probe() initializes priv->mcu_needs_restart to false after en8811h_load_firmware(), and en8811h_config_init() must set priv->mcu_needs_restart to true on its first execution and call en8811h_restart_mcu(phydev) on subsequent executions before writing AIR_PHY_MCU_CMD_1..4. [F68]

## Synchronization

- In i2c_transfer_rollball(), i2c_lock_bus(i2c, I2C_LOCK_SEGMENT) must be held across reading SFP_PAGE, setting SFP_PAGE to SFP_PAGE_ROLLBALL_MDIO, executing __i2c_transfer_err(), and restoring the saved SFP_PAGE (including when __i2c_transfer_err() fails) so concurrent SFP accesses do not observe or overwrite the changed page. [F20]
- In _bcm_phy_cable_test_start() and _bcm_phy_cable_test_get_status(), when is_rdb is true, phy_lock_mdio_bus(phydev) must be held across __bcm_phy_enable_legacy_access(), the expansion register accesses, and __bcm_phy_enable_rdb_access() (even on error paths) so concurrent callers never observe the PHY left in legacy register access mode. [F24]
- In drivers/net/phy/bcm-phy-ptp.c, bcm_ptp_private::mutex must be held across all sequences that read or modify bcm_ptp_private::nse_ctrl, disable framesync via bcm_ptp_framesync_disable(), trigger bcm_ptp_framesync(), and restore NSE_CTRL via bcm_ptp_framesync_restore(), as well as across TS_READ_CTRL FIFO reads in bcm_ptp_get_tstamp(). [F25]
- In bcm-phy-ptp.c, bcm_ptp_perout_locked() and bcm_ptp_extts_locked() must call cancel_delayed_work_sync(&priv->pin_work) if priv->pin_active is true before calling INIT_DELAYED_WORK(), and bcm_ptp_perout_work() and bcm_ptp_extts_work() must abort without rescheduling if !priv->pin_active under priv->mutex. [F26]
- In drivers/net/phy/bcm-phy-ptp.c, bcm_ptp_stop() must synchronously stop both the PTP clock aux worker via ptp_cancel_worker_sync(priv->ptp_clock) and the pin delayed work via bcm_ptp_cancel_func(priv), and bcm_ptp_hwtstamp() must call ptp_cancel_worker_sync(priv->ptp_clock) when SLICE_TX_EN is cleared before purging priv->tx_queue. [F27]
- In bcm_ptp_match_tstamp(), walking priv->tx_queue with skb_queue_walk() and unlinking a matched SKB with __skb_unlink() must be protected by spin_lock_irqsave(&priv->tx_queue.lock, flags), and skb_complete_tx_timestamp() / kfree_skb() must be called after spin_unlock_irqrestore(&priv->tx_queue.lock, flags). [F28]
- In en8811h_probe(), priv->phydev must be initialized before calling en8811h_clk_provider_setup(&phydev->mdio.dev, &priv->hw), because devm_clk_hw_register() and devm_of_clk_add_hw_provider() publish en8811h_clk_ops callbacks that immediately dereference priv->phydev. [F30]

## Object Lifetimes

- When `phy_device_register()` or `mdio_device_register()` fails after `fwnode_handle_get()` and `device_set_node()` (or `dev.fwnode` assignment), the error path must clear `dev.fwnode` before calling `phy_device_free()` or `mdio_device_free()` because device release calls `fwnode_handle_put(dev->fwnode)`. [F1]
- In `fwnode_mdiobus_register_phy()`, `phy->psec` and `phy->mii_ts` must only be assigned after all fallible steps that can jump to `unregister_phy`, because `phy_device_remove(phy)` calls `unregister_mii_timestamper(phy->mii_ts)` and `pse_control_put(phy->psec)` while `clean_mii_ts` also calls `unregister_mii_timestamper(mii_ts)`. [F2]
- In `of_phy_get_and_connect()`, the `of_phy_is_fixed_link(np)` branch must increment `np`'s refcount with `of_node_get(np)` when assigning `phy_np` so that the shared `of_node_put(phy_np)` after `of_phy_connect()` stays balanced with the `of_parse_phandle()` branch. [F4]
- In `mdio_mux_init()`, when a caller-supplied `mux_bus` is used instead of `of_mdio_find_bus()`, `get_device(&parent_bus->dev)` must be called so that `put_device()` on the `err_pb_kz` rollback path and in `mdio_mux_uninit()` stays symmetric across both parent-bus acquisition modes. [F6]
- In `mdio_mux_init()`, a child `struct mdio_mux_child_bus` must only be linked onto `pb->children` after `of_mdiobus_register(cb->mii_bus, child_bus_node)` succeeds; if registration fails, `cb->mii_bus` must be freed immediately with `mdiobus_free()` because `mdio_mux_uninit_children()` calls `mdiobus_unregister()` on every entry in `pb->children`. [F7]
- In `aqr_firmware_load_nvmem()`, `cell` from `nvmem_cell_get()` and `buf` from `nvmem_cell_read()` must be released in reverse order (`kfree(buf)` then `nvmem_cell_put(cell)`) after `aqr_fw_boot()`, while a failure in `nvmem_cell_read()` must jump to `exit` to call `nvmem_cell_put(cell)` without `kfree(buf)`. [F17]
- In MDIO bus drivers that allocate `struct mii_bus` with non-devres `mdiobus_alloc()` or `mdiobus_alloc_size()` (`mdio-bcm-iproc.c`, `mdio-hisi-femac.c`, `mdio-moxart.c`, `mdio-sun4i.c`), `.remove` and probe error paths must call `mdiobus_unregister(bus)` before disabling clocks/regulators and calling `mdiobus_free(bus)`. [F18]

## API Contracts

- `of_mdio_find_device()` and `of_phy_find_device()` return a device with its embedded `struct device` reference count incremented by one; callers such as `of_phy_connect()` and `of_phy_deregister_fixed_link()` must drop that lookup reference via `put_device(&phy->mdio.dev)`. [F3]
- An `mii_bus` allocated with `alloc_mdio_bitbang(ctrl)` increments the module reference count of `ctrl->ops->owner` and must be released with `free_mdio_bitbang(bus)` (not plain `mdiobus_free(bus)`) on registration failure and after `mdiobus_unregister(bus)` on removal. [F10]
- In `aqr_phy_led_active_low_set()`, `__bcm_phy_modify_exp()`, `__bcm_phy_modify_rdb()`, and `air_buckpbus_reg_modify()`, the `set` argument is bitwise-ORed into `(old & ~mask) | set` (or passed to `phy_modify_mmd()`), so callers must pass a pre-shifted bitmask aligned with `mask` rather than a boolean or unshifted bit index. [F36]
- Callers of `bcm_phy_get_stats()` must provide a non-NULL `shadow` array of at least `bcm_phy_get_sset_count(phydev)` `u64` elements because `bcm_phy_get_stat()` unconditionally indexes `shadow[i] += val` whenever the register read is non-negative (and returns `U64_MAX` when `val < 0`). [F39]
- `bcm_ptp_probe()` returns `NULL` when the PHY model is unsupported or `CONFIG_BCM_NET_PHYPTP` is disabled and an `ERR_PTR` on allocation or `ptp_clock_register()` failure, so callers must check `IS_ERR()` during probe and check for non-NULL before calling `bcm_ptp_stop()` (which unconditionally dereferences `priv`). [F48]
- `bcm54xx_auxctl_write()` writes `regnum | val` directly to `MII_BCM54XX_AUX_CTL` without adding write-enable bits, whereas `bcm54xx_auxctl_read()` shifts `regnum` to `MII_BCM54XX_AUXCTL_SHDWSEL_READ_SHIFT` and sets `MII_BCM54XX_AUXCTL_SHDWSEL_MASK`; callers writing `MII_BCM54XX_AUXCTL_SHDWSEL_MISC` must set `MII_BCM54XX_AUXCTL_MISC_WREN` in `val`. [F50]
- `bcm_phy_write_exp()` and `bcm_phy_read_exp()` write `reg` verbatim to `MII_BCM54XX_EXP_SEL` (`0x17`) and require the expansion bank selector (e.g., `MII_BCM54XX_EXP_SEL_ER` or `MII_BCM54XX_EXP_SEL_TOP`) in `reg`, whereas `bcm_phy_write_exp_sel()` and `bcm_phy_read_exp_sel()` OR `MII_BCM54XX_EXP_SEL_ER` (`0x0f00`) into `reg`. [F51]

## Error Handling

- In `ipq4019_mdio_probe()`, when optional memory resource 1 (`res`) is present, `priv->eth_ldo_rdy` returned by `devm_ioremap_resource()` must be checked with `IS_ERR()` and propagated via `PTR_ERR()` because `ipq_mdio_reset()` only checks `if (priv->eth_ldo_rdy)` before dereferencing it with `readl()` and `writel()`. [F33]
- In `sun4i_mdio_probe()`, when `devm_regulator_get(&pdev->dev, "phy")` returns an error pointer other than `-EPROBE_DEFER`, `data->regulator` must be reset to `NULL` because both the `err_out_disable_regulator` cleanup path and `sun4i_mdio_remove()` test `if (data->regulator)` before calling `regulator_disable(data->regulator)`. [F34]
- In `aqr107_config_mdi()`, the return value of `of_property_read_u32(np, "marvell,mdi-cfg-order", &mdi_conf)` must be checked for `-EINVAL` and `-ENOSYS` to treat an absent property or disabled `CONFIG_OF` as a no-op (`return 0`), while propagating any other non-zero error. [F35]
- In `aqr_wait_reset_complete()`, `val` must be a signed `int` checked for `val < 0` after `read_poll_timeout(phy_read_mmd, val, val != 0, ...)` because a negative MDIO error satisfies `val != 0` and makes `read_poll_timeout()` return `0`, and `aqr_firmware_load()` relies on `0`, `-ETIMEDOUT`, and negative read errnos being distinct. [F37]
- `aqr107_get_stat()` returns `U64_MAX` when `phy_read_mmd()` returns a negative errno (`val < 0`), and `aqr107_get_stats()` must check `val == U64_MAX` before adding `val` to `priv->sgmii_stats[i]` so that failed register reads do not corrupt the cumulative software counter. [F38]
- In `_bcm_phy_cable_test_start()` and `_bcm_phy_cable_test_get_status()`, when `is_rdb` is true, the `out:` path must re-enable RDB access using `ret = __bcm_phy_enable_rdb_access(phydev) ? : ret;` before unlocking the MDIO bus so that a `0` return from `__bcm_phy_enable_rdb_access()` does not overwrite an earlier error in `ret`. [F40]
- In `_bcm_phy_cable_test_get_status()`, `*finished` must be initialized to `false` before any register access and only set to `true` after all pair results and fault lengths are reported, because the `BCM54XX_ECD_CTRL_IN_PROGRESS` branch returns `0` via `goto out;` expecting `*finished` to remain `false`. [F41]

## External Contracts

- In aqr_fw_boot() and aqr_fw_load_memory(), the trailing file CRC at size - sizeof(u16) and the per-word mailbox CRC in crc_data[] must be processed in big-endian byte order, whereas primary_offset, struct aqr_fw_header 24-bit fields, and payload words must be read as little-endian using unaligned accessors. [F76]
- In __air_write_buf(), each 4-byte firmware word in fw->data must be read as two unaligned little-endian 16-bit halves with the upper half (&fw->data[offset + 2]) written to AIR_BPBUS_WR_DATA_HIGH before the lower half (&fw->data[offset]) is written to AIR_BPBUS_WR_DATA_LOW. [F77]
- In aqr107_get_stat(), each SGMII counter defined in aqr107_hw_stats[] has a bit width stat->size up to 32 bits split across stat->reg (low min(stat->size, 16) bits) and, only when stat->size > 16, stat->reg + 1 (high stat->size - 16 bits). [F81]
- In bcm-phy-ptp.c, bcm_ptp_clock_info must declare the exact bitmasks of supported request flags in .supported_perout_flags (PTP_PEROUT_DUTY_CYCLE) and .supported_extts_flags (PTP_STRICT_FLAGS | PTP_RISING_EDGE), and bcm_ptp_perout_locked() must validate that req->period is 1s and the 8ns-scaled pulse is in [1, BCM_MAX_PULSE_8NS]. [F82]
- In bcm_ptp_rxtstamp(), the 8-byte timestamp inserted by the PHY immediately after struct ptp_header (at data = (u8 *)(header + 1)) must be read with get_unaligned_be32(data) and get_unaligned_be32(data + 4), and stripped via memmove() and __pskb_trim() only when off = data - skb->data + 8 < skb->len. [F83]
- In bcm_phy_set_wol() and bcm_phy_get_wol(), the 6-byte Ethernet address and mask arrays (da, ndev->dev_addr, mask) must be packed as big-endian 16-bit words (byte[i * 2] << 8 | byte[i * 2 + 1]) and mapped to BCM54XX_WOL_MPD_DATA1(2 - i), BCM54XX_WOL_MPD_DATA2(2 - i), and BCM54XX_WOL_MASK(2 - i) in reverse register order (2 - i for i = 0..2). [F86]
- of_phy_is_fixed_link() and of_phy_register_fixed_link() must support both the child-node 'fixed-link' binding (or non-"auto" 'managed' property) and the legacy 5-cell 'fixed-link' u32 array property where index 0 is ignored and indices 1..4 encode duplex, speed, pause, and asym_pause. [F90]

## Known Pitfalls

- In bcm_ptp_txtstamp(), BCM_SKB_CB(skb)->seq_id must be converted from the PTP header using be16_to_cpu(hdr->sequence_id) so that it matches the host-endian 16-bit sequence ID read from TS_INFO_0 into capts->seq_id by bcm_ptp_get_tstamp(). [F84]
- In `aqr_gen1_config_init`, `for_each_set_bit(led_idx, &priv->leds_active_low, AQR_MAX_LEDS)` and `for_each_set_bit(led_idx, &priv->leds_active_high, AQR_MAX_LEDS)` assign `led_idx` the 0-based LED index of each set bit, which must be passed as the `index` argument to `aqr_phy_led_active_low_set` with a constant boolean polarity. [F98]
- In `bcm_ptp_adjfine`, negative `scaled_ppm` must be negated into a positive magnitude (recording `neg_adj`) before computing `adj = scaled_ppm << 9` and calling `div_u64(adj, 15625)`, with `div_u64` used instead of `/` for 64-bit unsigned division on 32-bit targets. [F115]
- When writing the 48-bit NCO timestamp (in 16ns units) into `NCO_TIME_2_CTRL` in `bcm_ptp_settime_locked`, `ns >> 36` must be masked with `0xfff` so upper control bits such as `FREQ_MDIO_SEL` (`BIT(14)`) in `NCO_TIME_2_CTRL` are not inadvertently set. [F117]
- In `bcm_phy_downshift_set`, the range check `count - BCM54XX_SHD_SCR2_WSPD_RTRY_LMT_OFFSET > BCM54XX_SHD_SCR2_WSPD_RTRY_LMT_MASK` relies on `u8 count` promoting to signed `int` and both constants remaining signed `int` so `count` values `0` (`DOWNSHIFT_DEV_DISABLE`) and `1` evaluate to negative signed ints rather than wrapping unsigned. [F119]
- Jiffies-based deadlines stored as `jiffies + SKB_TS_TIMEOUT` in `BCM_SKB_CB(skb)->timeout` or `jiffies + MDIO_TIMEOUT` in `timeout_jiffies` must be compared using `time_after` (in `bcm_ptp_match_tstamp`) or `time_is_before_jiffies` (in `sun4i_mdio_read` and `sun4i_mdio_write`) rather than direct `<` or `>` operators. [F126]
- In aqr_fw_boot (drivers/net/phy/aquantia/aquantia_firmware.c), strings extracted from the firmware buffer must be bounds-validated with aqr_fw_validate_get and copied into a NUL-terminated buffer via strscpy before being formatted with %s. [F133]
