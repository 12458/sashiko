# EDAC-CORE — (top level)

Contains the public EDAC header (`include/linux/edac.h`), core polling workqueue (`wq.c`), memory scrubber sysfs (`scrub.c`), and EDAC drivers for Intel Skylake/10nm (`skx_base.c`, `skx_common.c`), Apollo Lake/Denverton (`pnd2_edac.c`), Freescale MPC85xx (`mpc85xx_edac.c`), SiFive RISC-V (`sifive_edac.c`), and Intel X38 (`x38_edac.c`).

## Architecture & Data Flow
- `skx_dev->imc[]` is indexed by logical IMC (`0` to `d->num_imc - 1`); drivers skipping absent IMCs must call `skx_set_mc_mapping(d, pmc, lmc)` (physical `pmc` 2nd, logical `lmc` 3rd), and `skx_adxl_decode()` must convert physical ADXL IMC IDs via `skx_get_mc_mapping(d, res->imc)` only after verifying `res->dev != NULL` (after `list_for_each_entry` on `dev_edac_list`) and `res->imc >= 0` (`~0x0ull` or missing `BIT_NM_MEMCTRL` yields `-1`). [F208, F226, F243, F252]
- Every enum constant before `INDEX_MAX` (`skx_common.h`) needs a matching string in `component_names[]` (`skx_common.c`), with mandatory ADXL components before `INDEX_NM_FIRST` and optional near-memory ones at/after `INDEX_NM_FIRST`; `skx_adxl_decode()` must check `BIT_NM_*` in `adxl_nm_bitmap` before indexing `adxl_values[]` with `component_indices[INDEX_NM_*]`, and when `skx_res_cfg->type == GNR` (set via `skx_set_res_cfg()`) and `err_src == ERR_SRC_2LM_FM`, switch `err_src` to `ERR_SRC_2LM_NM` if `adxl_values[component_indices[INDEX_MEMCTRL]] == -1`. [F215, F228, F265]
- In `struct skx_channel`, `rrl_ctl[2][NUM_RRL_SET]` is indexed by sub-channel/HBM pseudo-channel first and bounded by `NUM_RRL_SET` (matching `struct reg_rrl`) second; in `skx_base.c`, `skx_close_row[]`/`skx_open_row[]` in `skx_mad_decode()` must have `>= 18` entries (max `dimm->rowbits` from `numrow()`), and in `skx_tad_decode()`, when `res->chanways == 3` and `skt_interleave_bit > chn_interleave_bit`, `skx_do_interleave()` must de-interleave channel before socket passing `channel_addr` as `lowbits` (else socket before channel using `res->addr`). [F217, F227, F238]
- In `scrub.c`, `scrub_create_desc()` must zero-allocate `edac_scrub_context` (`devm_kzalloc`, storing borrowed `&scrub_ctx->group` in `attr_groups[0]` which callers must not `kfree()`) with `scrub_attrs[SCRUB_MAX_ATTRS + 1]`, copying `dev_attr[]` into `scrub_ctx->scrub_dev_attr[]` (`struct edac_scrub_dev_attr` with valid `instance` index for `TO_SCRUB_DEV_ATTR`) before taking `.dev_attr.attr` pointers; `dev_attr[]` and `scrub_attr_visible()` switch cases (gating r/w on non-NULL `ops` callbacks) must match `enum edac_scrub_attributes`. [F188, F219, F257, F258]
- In `pnd2_edac.c`, `get_registers()` on DNV must override `asym0.slice0_asym_channel_select`, `asym1.slice1_asym_channel_select`, and `chash.sym_slice{0,1}_channel_enabled` before calling `gen_sym_mask()`/`gen_asym_mask()` or computing `two_slices`/`two_channels`/`{sym,asym}_chan_mask`; `struct b_cr_asym_mem_region{0_mchbar,1_mchbar,_denverton}` must keep identical 32-bit layouts (bit 31 enable, matching base/limit) for `void *` casts in `{apl,dnv}_mk_region()`, and `chan_mask` must be `unsigned long` (unlike `u8` `{sym,asym}_chan_mask`) for `for_each_set_bit()`. [F220, F260, F264]
- In `pnd2_edac.c`, `sys2pmi()` must call `remove_addr_bit()` on `chan_intlv_bit_rm` before `slice_intlv_bit_rm` (returning early if `bitidx == -1`), `get_memory_error_data()` must right-shift `pmiidx` by `ops->pmiidx_shift` before `ops->pmi2mem()` (`dnv_ops` sizes `dmap[]`/`drp[]` to `DNV_NUM_CHANNELS`), and `dnv_pmi2mem()`/`dnv_get_dimm_config()` must check `dmap4[pmiidx].row14`..`row17 != 31` and `dmap1[pmiidx].ca11 != 0x3f` before `dnv_get_bit()`. [F230, F233, F250]
- In `mpc85xx_edac.c`, `mpc85xx_{pci,l2}_err_probe()` must add `0xe00` to `r.start` before `devm_request_mem_region()`/`devm_ioremap()` (`MPC85XX_{PCI,L2}_*` offsets are relative to `+0xe00`); in `x38_edac.c`, `mci->pvt_info` stores the `void __iomem *` window from `x38_map_mchbar()` (`sz_pvt = 0`). [F235, F261]

## Synchronization
- In `pnd2_edac.c`, all hardware registers must be cached into static structs during `get_registers()` in `pnd2_probe()`, and `RD_REG`/`RD_REGP`/`ops->rd_reg` (`apl_rd_reg`/`dnv_rd_reg`) must never be called from the MCE path (`pnd2_mce_check_error`, `pnd2_mce_output_error`, `sys2pmi`, `ops->pmi2mem`). [F193]
- In `x38_edac.c`, `x38_get_and_clear_error_info()` must read `X38_ERRSTS` into `info->errsts` before and `info->errsts2` after reading `eccerrlog[]`, re-reading `eccerrlog[]` before clearing `X38_ERRSTS` if `X38_ERRSTS_BITS` changed, and `x38_process_error_info()` must report the overwritten CE and set `info->errsts = info->errsts2`. [F224]
- Work queued via `edac_queue_work()`/`edac_mod_work()` runs on the `'edac-poller'` `WQ_MEM_RECLAIM` workqueue (no `GFP_KERNEL` allocations or flushing non-`WQ_MEM_RECLAIM` wqs), and `mpc85xx_{pci,pcie,l2}_check()` also run in hardirq (`mpc85xx_{pci,l2}_isr()`) so they must never sleep or take blocking locks. [F272, F273]

## Object Lifetimes
- `edac_stop_work()` must call `cancel_delayed_work_sync(work)` then `flush_workqueue(wq)` before freeing an EDAC ctl struct, and `edac_workqueue_teardown()` must reset `wq = NULL` after `destroy_workqueue(wq)`. [F189]
- In `skx_base.c`/`skx_common.c`, `mce_register_decode_chain(&skx_mce_dec)` and `skx_setup_debug()` must run after `skx_get_all_bus_mappings()`, `skx_register_mci()`, and `skx_adxl_get()`, and `skx_exit()` must call `mce_unregister_decode_chain()` and `skx_teardown_debug()` before `skx_adxl_put()` and `skx_remove()`; if `edac_debugfs_create_file()` fails in `skx_setup_debug()`, call `debugfs_remove(skx_test)` and set `skx_test = NULL`, and when freeing `adxl_values`/`adxl_msg` in `skx_adxl_get()` error paths or `skx_adxl_put()`, reset `adxl_component_count = 0`. [F172, F178, F266]
- If `skx_register_mci()` fails after `imc->mci = mci`, it must `kfree(mci->ctl_name)`, call `edac_mc_free(mci)`, and set `imc->mci = NULL`; `skx_unregister_mci()` must call `edac_mc_del_mc(mci->pdev)` before `kfree(mci->ctl_name)` and `edac_mc_free(mci)`. [F173, F174]
- In `get_all_munits()` and `skx_get_all_bus_mappings()`, any `pdev` from `pci_get_device(..., prev)` saved into `struct skx_dev` needs `pci_dev_get(pdev)` before advancing `prev = pdev`, and early loop exits must call `pci_dev_put(pdev)`. [F244]
- In `pnd2_edac.c`, `pnd2_init()` must finish `pnd2_probe()` before `mce_register_decode_chain(&pnd2_mce_dec)` and `setup_pnd2_debug()`, and `pnd2_exit()` must call `teardown_pnd2_debug()` and `mce_unregister_decode_chain(&pnd2_mce_dec)` before `pnd2_remove()`; `_apl_rd_reg()` must restore `P2SB_HIDE_OFF` to `hidden` via `goto out` on all exit paths after unhiding P2SB, and `get_mem_ctrl_hub_base_addr()`/`dnv_rd_reg()` must call `pci_dev_put(pdev)` and `iounmap(base)` before returning. [F179, F180, F181]
- In `sifive_edac.c`, `ecc_register()` must call `edac_device_add_device(p->dci)` before `register_sifive_ccache_error_notifier(&p->notifier)` (freeing `p->dci` on error), `ecc_unregister()` must unregister `p->notifier` before deleting/freeing `p->dci`, and `platform_device_unregister(sifive_pdev)` must run if `ecc_register()` fails in `sifive_edac_init()` and after `ecc_unregister()` in `sifive_edac_exit()`. [F182, F183]
- In `mpc85xx_{pci,l2}_err_probe()`, open a devres group via `devres_open_group()`, map `vbase` and register with EDAC before requesting IRQs/enabling error interrupts, and call `devres_remove_group()` on success or delete the EDAC device, call `irq_dispose_mapping()`, free ctl info, and call `devres_release_group()` on error; `mpc85xx_{pci,l2}_err_remove()` must restore `orig_pci_err_{cap_dr,en}`/`orig_l2_err_disable`, disable `MPC85XX_L2_ERRINTEN`, and call `irq_dispose_mapping(pdata->irq)` before deleting/freeing the EDAC device. [F184, F185, F199]
- In `x38_edac.c`, `x38_probe1()` must set `x38_channel_num`, `mci->pvt_info = window`, and `mci->edac_check = x38_check` before `edac_mc_add_mc(mci)`, and `x38_remove_one()` must call `edac_mc_del_mc(&pdev->dev)` before `iounmap(mci->pvt_info)` and `edac_mc_free(mci)`. [F197]

## API Contracts
- In `include/linux/edac.h`, `dimm_info` stores `nr_pages` in pages, `grain` in bytes, and raw enums in `dtype`/`mtype`/`edac_mode`, while `mem_ctl_info` capabilities (`mtype_cap`, `edac_ctl_cap`, `edac_cap`, `scrub_cap`) use `BIT()` masks (`*_FLAG_*`); `edac_get_dimm(mci, layer0, layer1, layer2)` returns `NULL` if any active layer coordinate is `< 0` or index `>= mci->tot_dimms`. [F213, F284]
- `skx_init()` and `pnd2_init()` must check `ghes_get_devices()` and `edac_get_owner()` (`-EBUSY`) and `cpu_feature_enabled(X86_FEATURE_HYPERVISOR)` (`-ENODEV`) before probing; `skx_mce_check_error()` and `pnd2_mce_check_error()` must return `NOTIFY_DONE` if `mce->kflags & MCE_HANDLED_CEC` and set `mce->kflags |= MCE_HANDLED_EDAC` after reporting an error. [F289, F291]
- Functions in `skx_common.c` (`skx_edac_common` module) called by `skx_edac`/`i10nm_edac` must use `EXPORT_SYMBOL_GPL()` and never `__init`/`__exit`; `skx_get_all_bus_mappings()` returns `<= 0` when no sockets/MCs are found (callers must fail on `<= 0`), `skx_get_hi_lo(did, off, tolm, tohm)` expects `off[]` as `{tolm, lower_tohm, upper_tohm}`, and `skx_get_{dimm,nvdimm}_info()` must return `1` when populated (`0` if NVDIMM size is `0`/`~0ull`) so `ndimms` gates `skx_check_ecc(mcmtr)`. [F202, F210, F287, F288]
- `GET_BITFIELD(v, lo, hi)` in `skx_common.h` and `pnd2_edac.c` takes `lo` before `hi` (`lo <= hi`, opposite of `GENMASK_ULL(hi, lo)`); in `pnd2_edac.c`, structs passed to `RD_REG()`/`RD_REGP()` must be 4 or 8 bytes (4 bytes when `r_opcode == 4`), and `msg` buffers passed to `get_memory_error_data()`, `sys2pmi()`, or `ops->pmi2mem()` must be `>= PND2_MSG_SIZE` (256) bytes. [F209, F259, F263]

## Error Handling
- `edac_{device,pci}_alloc_ctl_info()` and `edac_mc_alloc()` return `NULL` on failure, whereas `platform_device_register_simple()` in `sifive_edac_init()` returns `ERR_PTR` (`IS_ERR()`). [F200]
- In `skx_mce_check_error()`, zero-initialize `res` (`memset(&res, 0, sizeof(res))`), validate `res.addr` (`mce->addr & MCI_ADDR_PHYSADDR`) with `pfn_to_online_page(res.addr >> PAGE_SHIFT)` or `arch_is_platform_page(res.addr)` (logging `pr_err()` and returning `NOTIFY_DONE` without `WARN_ON()` if neither holds) before `driver_decode`/`skx_adxl_decode()`, and check `driver_decode` and `res.dev->imc[res.imc].mci` for `NULL`. [F207, F290]
- In `pnd2_edac.c`, `_apl_rd_reg()` returns negative errno on busy/timeout and positive `1..3` on P2SB status bits `[2:1]`, and `apl_rd_reg()` must initialize `ret = 0` before `ret |= _apl_rd_reg(...)`; callers of `_apl_rd_reg()`, `apl_rd_reg()`, and `RD_REG()` must check `!= 0`, not `< 0`. [F212]

## External Contracts
- In `edac_scrub_ops` and `EDAC_SCRUB_ATTR_SHOW`, `{get_min,get_max,get,set}_cycle{_duration}` use seconds (`"%u\n"`), whereas `{read,write}_{addr,size}` use 64-bit hex (`"0x%llx\n"`). [F283]

## Known Pitfalls
- In `skx_adxl_decode()` and `skx_show_retry_rd_err_log()`, check signed `MSG_SIZE - len <= 0` / `len - n > 0` after `snprintf()` before appending further to `adxl_msg`/`skx_msg`. [F236]
- In `skx_get_dimm_config()`, read `mcmtr` (`0x87c`) from `imc->chan[0].cdev` rather than `imc->chan[i].cdev`; in `get_all_munits()`, ignore `SAD` (`0x208e`) devices where config `0xB4` is `0` (unpopulated cores) while verifying non-zero values match `d->mcroute`; on UV systems (`is_uv_system()`), `skx_get_src_id()` must use `skx_get_pkg_id()` (checking `c->initialized && cpu_to_node(cpu) == node` before `topology_physical_package_id(cpu)`) instead of the 3-bit PCI config source ID. [F268, F269, F279]
- In `pnd2_edac.c`, widen `u32` bitfields to `u64` via `U64_LSHIFT()` before shifting by `>= 15` bits; in `mpc85xx_pci_check()`, mask out `PCI_EDE_MULTI_ERR` alongside `PCI_EDE_MST_ABRT` and `PCI_EDE_PERR_MASK` before `edac_pci_handle_npe()`; in `x38_map_mchbar()`, verify 64-bit `u.mchbar == (resource_size_t)u.mchbar` before `ioremap()`. [F241, F248, F253]
