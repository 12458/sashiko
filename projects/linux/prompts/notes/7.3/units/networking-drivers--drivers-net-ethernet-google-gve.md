# NETWORKING DRIVERS — drivers/net/ethernet/google/gve

The Google Virtual Ethernet (`gve`) driver supports Google Cloud's gVNIC PCIe device, implementing an AdminQ control plane and GQI and DQO datapath queue formats in QPL or RDA modes, alongside XDP, AF_XDP (XSK), PTP, RSS, and flow steering.

## Architecture & Data Flow
- `priv->rx` and `priv->tx` are NULL when closed; callbacks reachable while down (XSK setup/wakeup, stats, `netdev_queue_mgmt_ops`) must check `priv->rx`/`priv->tx`, `netif_running(dev)`, or `gve_get_napi_enabled(priv)` before indexing them, and control-plane paths (`gve_set_xdp()`, `gve_adjust_queues()`, `gve_adjust_ring_sizes()`, `gve_set_hsplit_config()`, `gve_set_features()`, `gve_reset()`, `gve_shutdown()`, `gve_suspend()`) must check `netif_running(dev)`, not `netif_carrier_ok(dev)`. [F39, F57]
- In DQO RX, `rx->dqo.page_pool` is allocated only in RDA mode (`cfg->raw_addressing`) and is NULL in QPL mode; all DQO RX teardown and buffer paths must check `rx->dqo.page_pool` before calling `page_pool` APIs and use it to discriminate `page_info.netmem` from `page_info.page`. [F37]
- In DQO TX, `tx->netdev_txq` is non-NULL only for stack TX queues (`idx < priv->tx_cfg.num_queues`) and NULL for XDP TX queues; shared paths (`gve_tx_stop_ring_dqo()`, `gve_clean_tx_done_dqo()`) must guard `netdev_tx_*` calls with `if (tx->netdev_txq)`, and `netdev_tx_completed_queue()` must count `pkt_compl_* + miss_compl_*` while excluding `reinject_compl_*`. [F45, F170]
- In `gve_tx_pending_packet_dqo`, `pending_packet->type` discriminates `skb`/`xdpf`, while `tx->dqo.qpl != NULL` discriminates `tx_qpl_buf_ids` from `dma`/`len`; `GVE_PACKET_STATE_UNALLOCATED` must remain 0 in `enum gve_packet_state` and be restored by `gve_free_pending_packet()` because `tx->dqo.pending_packets` is zero-allocated. [F46, F49]
- In DQO pools, `0` is a valid index, so empty `gve_index_list` and `s16` list heads/tails in `gve_rx_ring`/`gve_tx_ring` must be initialized to `-1`. In `gve_rx_buf_state_dqo`, `-1` marks end-of-list and allocated entries set `buf_state->next = buf_state - rx->dqo.buf_states` (`gve_buf_state_is_allocated()`), which `gve_rx_dqo()` must check with `buffer_id < rx->dqo.num_buf_states`; `gve_try_recycle_buf()` and `gve_get_recycled_buf_state()` must maintain `used_buf_states_cnt` and bound `used_buf_states` scans to 5 attempts. [F50, F68, F80, F108]
- In DQO TX completions, when `type == GVE_COMPL_TYPE_DQO_PKT`, `compl_tag` must have `GVE_ALT_MISS_COMPL_BIT` (`BIT(15)`) stripped and be bounds-checked against `tx->dqo.num_pending_packets`; in `gve_tx_alloc_ring_dqo()`, `num_pending_packets` must be reduced by `(complq_mask + 1) / GVE_TX_MIN_RE_INTERVAL`, halved for dual miss/reinjection completions, and clamped to `S16_MAX`. [F81, F118]
- In DQO TX, `gve_tx_pkt_desc_dqo.buf_size` is 14-bit (`GVE_TX_MAX_BUF_SIZE_DQO = 16383`), so `gve_tx_fill_pkt_desc_dqo()` must split larger buffers and `gve_num_descs_per_buf()` must reserve `DIV_ROUND_UP(size, GVE_TX_MAX_BUF_SIZE_DQO)` descriptors; `report_event` may only be set on the EOP descriptor (`(desc_idx - 1) & tx->mask`) when `((last_desc_idx - tx->dqo_tx.last_re_idx) & tx->mask) >= GVE_TX_MIN_RE_INTERVAL` (32). [F93, F95]
- Ring sizes (`tx_desc_cnt`, `rx_desc_cnt`) must be powers of two (`gve_validate_req_ring_size()`). GQI/QPL `u32` counters (`req`/`done`, `fill_cnt`/`cnt`, `alloc_tx_qpl_buf_cnt`/`free_tx_qpl_buf_cnt`) are unmasked (`producer - consumer`), whereas DQO `head`/`tail` are pre-masked in `[0, mask]` (used `(tail - head) & mask`, available `mask - num_used`). In GQI TX FIFO (`gve_tx_alloc_fifo()`), `fifo->head` is `L1_CACHE_ALIGN`-ed, so `gve_skb_fifo_bytes_required()` must include `pad_bytes` and `L1_CACHE_ALIGN(hlen) - hlen`. [F77, F115, F116, F152]
- In GQI RX (`gve_rx()`), `rx->desc.seqno` is 1-based `[1, 7]` (0 means empty) and wraps 7->1 via `gve_next_seqno()`; the first fragment includes 2-byte `GVE_RX_PAD` in `be16_to_cpu(desc->len)` and must check `frag_size > rx->packet_buffer_size` before subtracting `page_info->pad`. Any drop (`ctx->drop_pkt = true`) must `goto finish_frag` so `gve_rx_ctx_clear(ctx)` runs on `is_last_frag`; in `gve_clean_rx_done()`, the loop may exceed `budget` only while `ctx->frag_cnt != 0`, and on seqno failure when `ctx->frag_cnt != 0` it must call `napi_free_frags(napi)`, `gve_rx_ctx_clear(&rx->ctx)`, and `gve_schedule_reset()`. [F78, F98, F105, F160]
- In DQO completion rings, `cur_gen_bit` starts at 0, flips on wrap (`cur_gen_bit ^= (head == 0)`), and fields must be read only after `compl_desc->generation != cur_gen_bit` and `dma_rmb()`. In `gve_rx_poll_dqo()`, `complq->head`, `complq->num_free_slots`, `complq->cur_gen_bit`, `bufq->head`, and `rx->cnt` must advance on every descriptor before any `continue`, while `work_done` increments only on `compl_desc->end_of_packet`. [F79, F107]
- `priv->tx_cfg.num_xdp_queues` (and `tx_alloc_cfg.num_xdp_rings`) must equal `priv->rx_cfg.num_queues` when `priv->xdp_prog != NULL` and 0 otherwise (`gve_xdp_tx_queue_id()`). `gve_reg_xsk_pool()`/`gve_unreg_xsk_pool()` must update `rx->xsk_pool`, `tx[gve_xdp_tx_queue_id()]->xsk_pool`, and `priv->xsk_pools` in lockstep. Because `gve_xsk_tx_poll*()` runs in the `block->rx` branch of `gve_napi_poll*()`, `gve_xsk_wakeup()` must schedule the RX NAPI via `gve_rx_idx_to_ntfy(priv, queue_id)` for both RX and TX, bracketing `napi_schedule()` with `local_bh_disable()`/`local_bh_enable()`. [F54, F55, F60, F142, F156]
- Every stack `union gve_adminq_command` must be zeroed with `memset(&cmd, 0, sizeof(cmd))` so `cmd.status` is 0; every opcode in `gve_adminq_opcodes` and `gve_adminq_extended_cmd_opcodes` needs a case in `gve_adminq_issue_cmd()`; and `gve_gstrings_*_stats` must match `gve_get_ethtool_stats()`, `NUM_GVE_RX_CNTS`/`NUM_GVE_TX_CNTS`, and `enum xdp_action` up to `GVE_XDP_ACTIONS`. [F48, F73, F74]
- In `gve_adminq_describe_device()`, select `priv->queue_format` and `supported_features_mask` in priority order: `dev_op_dqo_rda`, `dev_op_dqo_qpl`, `dev_op_gqi_rda`, `GVE_GQI_RDA_FORMAT`, then `GVE_GQI_QPL_FORMAT`. During reset recovery and resume (`gve_init_priv(priv, true)`), `skip_describe_device` must be true to preserve user configs, and `gve_adminq_release()` must clear `GVE_PRIV_FLAGS_DEVICE_RINGS_OK`, `DEVICE_RESOURCES_OK`, and `ADMIN_QUEUE_OK`. [F70, F71, F99]
- In `gve_alloc_notify_blocks()`, if `pci_enable_msix_range()` returns fewer vectors, round `priv->num_ntfy_blks` down to even `(vecs_enabled - 1) & ~0x1`, set `priv->mgmt_msix_idx = priv->num_ntfy_blks`, and clamp `tx_cfg`/`rx_cfg` `max_queues` and `num_queues`. `priv->irq_db_indices` is an array of cacheline-aligned `struct gve_irq_db`, so `block->irq_db_index` (`&priv->irq_db_indices[i].index`) must not be indexed as a contiguous `__be32` array. [F65, F128]
- `priv->rss_key_size` is in bytes while `priv->rss_lut_size` is a `u32` count (multiply by 4 for allocs/copies/query checks, pass unscaled to `hash_lut_size`/`indir_size`); keep `priv->rss_config` synced when `priv->cache_rss_config` is true, and verify `be32_to_cpu(descriptor->total_length) == sizeof(*descriptor) + payload_len` in `gve_adminq_process_flow_rules_query()` and `gve_adminq_process_rss_query()`. In `gve_handle_report_stats()`, index `priv->tx[idx]`/`priv->rx[idx]` with `idx` while advancing a shared `stats_idx`, and in `gve_set_priv_flags()` only zero the driver-written prefix of `priv->stats_report->stats`. [F59, F90, F110, F126, F127]

## Synchronization
- Internal paths calling `gve_reset()`, `gve_close()`, or `gve_reset_recovery()` outside NDOs (`gve_handle_reset()`, `gve_shutdown()`, `gve_suspend()`, `gve_resume()`) must acquire `rtnl_lock()` then `netdev_lock(dev)`, and `gve_turnup()`, `gve_turndown()`, `gve_add_napi()`, and `gve_remove_napi()` must use `_locked` NAPI and XDP feature helpers. In `gve_probe()`, set `gve_set_probe_in_progress()` before requesting the mgmt IRQ and clear it only after `register_netdev()`, then queue `priv->service_task`. [F15, F24, F25]
- In `gve_turndown()`, disable NAPIs, call `netif_tx_disable()`, clear XDP redirect target, call `gve_clear_napi_enabled(priv)`, and run `synchronize_net()` before stopping rings. Execute `dma_wmb()` after `gve_rx_prefill_pages()` in `gve_rx_alloc_ring_gqi()`; execute `mb()` after unmasking IRQs before `napi_schedule()` in `gve_turnup()`; and execute `mb()` after writing `GVE_IRQ_ACK | GVE_IRQ_EVENT` before checking `gve_tx_clean_pending()` / `gve_rx_work_pending()` in `gve_napi_poll()`. [F16, F17, F20, F34]
- Callers of `gve_adminq_issue_cmd()` / `gve_adminq_kick_and_wait()` must hold `priv->adminq_lock` in process context (`msleep()`). Hold `tx->clean_lock` on GQI TX queues in `gve_maybe_stop_tx()` and `gve_tx_poll()`; in DQO TX, pair `mb()` after `netif_tx_stop_queue()` (before rechecking `gve_has_avail_slots_tx_dqo()`) with `mb()` after `gve_clean_tx_done_dqo()` (before `netif_tx_queue_stopped()`). All XDP/XSK TX submissions must hold `tx->xdp_lock` or `tx->dqo_tx.xdp_lock`. [F26, F27, F28, F33]
- In DQO TX, completions push to `dqo_compl.free_pending_packets` and `free_tx_qpl_buf_head` via `atomic_cmpxchg()`, and TX steals the list via `atomic_xchg(..., -1)` when its local `dqo_tx` list is `-1`. `gve_xsk_reorder_queue_push_dqo()` must write `xsk_reorder_queue[tail]` before `atomic_set_release(&tx->dqo_tx.xsk_reorder_queue_tail, tail)` (paired with `atomic_read_acquire()`), and `gve_handle_packet_completion()` must pass `!!napi` to `napi_consume_skb()`. [F32, F35, F143]

## Object Lifetimes
- In `gve_queue_mgmt_ops`, `gve_rx_queue_stop()` must reject `idx == 0` with `-ERANGE` on DQO, bracket single-queue AdminQ ops with `gve_turndown()` / `gve_turnup_and_check_status()`, and zero `priv->rx[idx]` when `gve_rx_queue_start()` aborts or `gve_rx_queue_stop()` copies `priv->rx[idx]` to `*per_q_mem`. `gve_queues_start()` takes ownership of `tx_alloc_cfg->tx` and `rx_alloc_cfg->rx` and frees them on error, so callers must never call `gve_queues_mem_free()` after it; `gve_set_xdp()` must only update `priv->xdp_prog` and `bpf_prog_put(old_prog)` after `gve_configure_rings_xdp()` succeeds. [F2, F11, F40, F165]
- In QPL mode, `rx->data.page_info[i].page` (GQI) and `gve_alloc_qpl_page_dqo()` (DQO) borrow from `qpl->pages`, so unfill/free paths must only subtract `pagecnt_bias - 1` without `put_page()` (and clear `buf_state->page_info.page = NULL` in DQO), whereas `rx->qpl_copy_pool[i].page` requires both `page_ref_sub()` and `put_page()`. `gve_register_qpl()` / `gve_unregister_qpl()` must maintain `priv->num_registered_pages <= priv->max_registered_pages`, reset to 0 in `gve_init_priv()`. [F3, F4, F13]
- In DQO RDA (`rx->dqo.page_pool != NULL`), `gve_reuse_buffer()` transfers `netmem` ownership to SKB or zero-copy `XDP_TX`/`XDP_REDIRECT` by clearing `netmem = 0`, while `gve_free_buffer()` (and `gve_xdp_done_dqo()` on error/drop) calls `gve_free_to_page_pool()` (`page_pool_put_full_netmem()`). On DQO RX teardown, call `page_pool_disable_direct_recycling()` before `gve_remove_napi()`, pass `allow_direct = false` to `gve_free_to_page_pool()` before `page_pool_destroy()`, check `gve_buf_state_is_allocated(rx, bs)` before `xsk_buff_free(bs->xsk_buff)`, and in `gve_rx_free_skb()` clear `napi->skb = NULL` if `rx->ctx.skb_head == napi->skb`. [F5, F6, F10, F12, F148, F149, F168]
- `gve_tx_stop_ring_gqi()` must drain all slots via `gve_clean_tx_done()` or `gve_clean_xdp_done()` before `gve_tx_fifo_release()`. In DQO TX, expired `miss_completions` in `remove_miss_completions()` must move to `timed_out_completions` (not `gve_free_pending_packet()`), and `GVE_TX_PENDING_PACKET_DQO_XSK` completions must set `state = GVE_PACKET_STATE_XSK_COMPLETE` so `gve_tx_process_xsk_completions()` frees them in order. [F7, F8, F103]
- `gve_queues_stop()` (when `DEVICE_RINGS_OK`) must run `gve_turndown()`, `gve_destroy_rings()`, and `gve_unregister_qpls()`—falling back to `gve_reset_and_teardown()` on error—before freeing ring/QPL DMA memory; `gve_teardown_device_resources()` (when `DEVICE_RESOURCES_OK`) must deconfigure flow rules, stats, and device resources via AdminQ—calling `gve_trigger_reset()` on error—before freeing DMA buffers. `gve_shutdown()` must call `netif_device_detach(netdev)` before teardown, and `gve_remove()` must finish `unregister_netdev()` and `gve_teardown_priv_resources()` before `destroy_workqueue(priv->gve_wq)`. [F18, F19, F471, F472]

## API Contracts
- `gve_rx_can_recycle_buffer()` returns `1` (reusable), `0` (busy), or `-1` (`page_count < pagecnt_bias`); callers must check `< 0` (and schedule reset) before treating it as boolean. In GQI TX, `gve_tx_add_skb_*()` returns `nsegs > 0` or `0` on drop (`gve_tx()` frees `skb`), whereas in DQO TX, `gve_try_tx_skb()` returns `0` on tx/drop (frees `skb` internally) and `-1` when full; both `gve_tx()` and `gve_tx_dqo()` must ring the doorbell before `NETDEV_TX_BUSY` or after a drop to flush `xmit_more` descriptors. [F43, F44, F169]
- Ring alloc/free functions (`gve_tx_alloc_rings_*`, `gve_tx_free_rings_*`, `gve_rx_alloc_ring*`, `gve_rx_free_ring*`) must read ring pointers, sizes, and queue counts from `cfg`, not `priv`. `dev->netmem_tx` is enabled only for DQO RDA; in `gve_tx_pending_packet_dqo`, index `0` uses `dma_map_single`/`dma_unmap_single` while indices `1..num_bufs - 1` use `skb_frag_dma_map` and `netmem_dma_unmap_page_attrs()`. [F112, F151, F164]
- `gve_set_netdev_xdp_features()` sets `dev->xdp_features` without `NETDEV_XDP_ACT_NDO_XMIT`, while `gve_turnup()`/`gve_turndown()` toggle it via `xdp_features_set/clear_redirect_target_locked()`. In `gve_napi_poll_dqo()`, when `reschedule` is true, return `budget` only if `gve_is_napi_on_home_cpu(priv, block->irq)`; otherwise clamp `work_done < budget` and call `napi_complete_done()`. [F155, F161]

## Error Handling
- In `gve_tx_add_skb_no_copy()`, set `info->skb` on the first descriptor, clear `info->skb = NULL` on fragments, and skip the unmapped metadata slot (`i == 1 && mtd_desc_nr == 1`) in `unmap_drop`. Check `gve_alloc_pending_packet(tx)` for `NULL`, check `IS_ERR(pool)` on `gve_rx_create_page_pool()` before assigning `rx->dqo.page_pool`, and in `gve_adminq_configure_flow_rule()` call `gve_reset(priv, true)` only on `-ETIME` and clear `rules_cache_synced` only when `!err`. [F9, F36, F38, F166]

## External Contracts
- `gve_adminq_alloc()` / `gve_adminq_release()` must branch on `priv->pdev->revision < 0x1`; commands > 56 bytes must use `gve_adminq_execute_extended_cmd()`; and `-EOPNOTSUPP` from `gve_adminq_verify_driver_compatibility()` must be treated as `0`. `gve_get_next_option()` must bounds-check `option_length` against `descriptor->total_length`; `gve_parse_device_option()` and `gve_enable_supported_features()` must accept unknown/longer options, check both `required_features_mask`/length and `GVE_SUP_*_MASK`, and set `priv->default_min_ring_size = true` on 8-byte `GVE_DEVICE_OPTION_NO_MIN_RING_SIZE`. [F87, F88, F89, F478, F479, F480]
- GQI TX `l4_csum_offset`, `l4_hdr_offset`, and `l3_offset` must be shifted `>> 1` (16-bit words); DQO `gve_extract_tx_metadata_dqo()` must bitwise-invert a zero 15-bit folded `skb->hash` before setting `metadata->path_hash`. [F53, F120]

## Known Pitfalls
- BAR0, AdminQ structs, and GQI descriptors/doorbells are big-endian (`__be*`, `iowrite32be`), whereas DQO descriptors and BAR2 doorbell values are little-endian (`__le*`, `iowrite32`) at a big-endian `db_index` (`be32_to_cpu`). Save `next_index = pending_packet->next` before mutating lists in `remove_miss_completions()` / `remove_timed_out_completions()` and check `timeout_jiffies` with `time_is_after_jiffies()`; in `gve_clean_xdp_done()` / `gve_clean_tx_done()`, loop `for (i = 0; i < to_do; i++)` incrementing `tx->done` inside the body; in `gve_rx_dqo()`, check `!netmem_is_net_iov(netmem)` before `netmem_to_page()` or `page_address`; and copy `gve_gstrings_adminq_stats` (`__nonstring_array`) with `ethtool_cpy()`. [F86, F104, F114, F123, F133, F150]
