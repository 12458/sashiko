# MAC80211 — net/mac80211 (part 1)

Implements `mac80211_config_ops` (`cfg.c`), channel context management (`chan.c`), driver-ops wrappers (`driver-ops.c`/`driver-ops.h`), EHT capability parsing (`eht.c`), ethtool hooks (`ethtool.c`), and debugfs interfaces for PHYs, netdevs, stations, and keys.

## Architecture & Data Flow

- `NL80211_IFTYPE_AP_VLAN` interfaces are never added to the driver (`drv_add_interface()` rejects them). Driver-ops wrappers that may receive an `AP_VLAN` (`drv_sta_*`, `drv_set_key`, `drv_ampdu_action`, `drv_flush*`, `drv_net_*`) must call `sdata = get_bss_sdata(sdata)` before `check_sdata_in_driver(sdata)` and `local->ops`. On `NL80211_IFTYPE_AP` links, `link->conf->chanreq` must be updated via `ieee80211_link_update_chanreq()` so `vlan_conf->chanreq` on all VLANs in `sdata->u.ap.vlans` stays synchronized for `link->link_id`. [F45, F55]
- Replacement channel contexts (`IEEE80211_CHANCTX_REPLACES_OTHER`) sit on `local->chanctx_list` before being added to the driver, so `ctx->driver_present` must stay synchronized across `drv_add_chanctx()`, `drv_remove_chanctx()`, and `drv_switch_vif_chanctx()`, and `ieee80211_iter_chan_contexts_*()`, `_ieee80211_recalc_chanctx_min_def()`, and `drv_change_chanctx()` must gate driver calls on `ctx->driver_present`. During `local->in_reconfig`, `_ieee80211_link_use_channel()` must skip releasing the channel, `ieee80211_assign_link_chanctx()` must skip unassigning `curr_ctx` and adding `assigned_chanctx_list`, and `drv_wake_tx_queue()` must set `IEEE80211_TXQ_DIRTY`. [F70, F73, F135]
- In `ieee80211_assign_beacon()`, when `mbssid` elements are present, `link_conf->bssid_indicator` comes from `new->mbssid_ies->elem[0].data[2]` (if `elem[0].len > 2`, else `0`) and is copied from `tx_bss_conf->bssid_indicator` to non-transmitted BSSes in `ieee80211_set_ap_mbssid_options()`. When `ieee80211_csa_finish` or `ieee80211_color_change_bss_config_notify` runs on a transmitting MBSSID link (`tx_bss_conf == link->conf`), propagate it to every link in `local` with `conf->tx_bss_conf == link->conf`. When populating `cfg80211_mbssid_elems` or `cfg80211_rnr_elems` (`ieee80211_copy_mbssid_beacon()`, `ieee80211_copy_rnr_beacon()`), set `dst->cnt` before accessing `__counted_by(cnt)` `dst->elem[]`. [F56, F57, F74]
- In multi-radio setups, `ieee80211_scan()`, `ieee80211_is_scan_ongoing()`, and `ieee80211_is_radar_required()` must map each link/ROC channel via `cfg80211_get_radio_idx_by_chan()` and check `ieee80211_is_radio_idx_in_scan_req()`. In `ieee80211_set_wiphy_params()`, only index `wiphy->radio_cfg[radio_idx]` when `radio_idx != -1 && radio_idx < wiphy->n_radio`. In `ieee80211_recalc_chanctx_chantype()`, filter `WLAN_STA_TDLS_WIDER_BW` peers on `local->sta_list` by `rcu_access_pointer(link->conf->chanctx_conf) == conf`. [F64, F66, F83]
- In `ieee80211_eht_cap_ie_to_sta_eht_cap()`, when `IEEE80211_EHT_PHY_CAP5_PPE_THRESHOLD_PRESENT` is set, check `eht_cap_len >= eht_total_size + sizeof(u16)` before reading `eht_ppe_hdr` and `eht_ppe_size <= sizeof(eht_cap->eht_ppe_thres)` before copying; `IEEE80211_EHT_MAC_CAP0_MAX_MPDU_LEN_MASK` must only update `max_amsdu_len` when `sband->band == NL80211_BAND_2GHZ`. In `link_sta_eht_capa_read()`, if no `IEEE80211_HE_PHY_CAP0_CHANNEL_WIDTH_SET_MASK_ALL` bit is set, format `nss->only_20mhz` as 4 bytes (`mcs_desc[0..3]`), else format `nss->bw._80`/`_160`/`_320` as 3 bytes (`mcs_desc[1..3]`). [F76, F89, F90]
- In `ethtool.c`, `ieee80211_get_stats` and `ieee80211_get_strings` reserve `STA_STATS_LEN` entries for mac80211 stats before passing `&data[STA_STATS_LEN]` / `&data[sz_sta_stats]` to `drv_get_et_stats` / `drv_get_et_strings` (`i == STA_STATS_LEN`), and the `drv_get_survey()` loop in `ieee80211_get_stats()` must reset `survey.filled = 0` before each call and on error before `break`. When falling back to `local->monitor_chanreq.oper` in `ieee80211_cfg_get_channel()` and `ieee80211_get_stats()`, check `local->open_count == local->virt_monitors` (not `local->monitors`). [F91, F106, F126]
- In `ieee80211_del_link_station()`, reject removing `params->link_id` with `-EINVAL` when `sta->sta.valid_links == BIT(params->link_id)` or `!(sta->sta.valid_links & BIT(params->link_id))`. In `__ieee80211_request_smps_mgd()`, do not return early on `old_req == smps_mode` when `smps_mode == IEEE80211_SMPS_AUTOMATIC`, and save `link->u.mgd.req_smps` before resolving `AUTOMATIC`. In `ieee80211_update_mesh_config()`, test 1-based `nl80211_meshconf_params` via `_chg_mesh_attr()` (`(mask >> (parm - 1)) & 0x1`). In debugfs write handlers (`aql_txq_limit_write()`, `sta_aql_write()`, `sta_agg_status_do_write()`), check `ac < IEEE80211_NUM_ACS` or `tid < IEEE80211_NUM_TIDS`. [F84, F87, F107, F108]

## Synchronization

- Exported driver notifications `ieee80211_csa_finish()`, `ieee80211_color_change_finish()`, and `ieee80211_obss_color_collision_notify()` must check `link_id < IEEE80211_MLD_MAX_NUM_LINKS` and hold `rcu_read_lock()` across `rcu_dereference(sdata->link[link_id])` and `for_each_sdata_link_rcu()` (never `for_each_sdata_link()` without `wiphy->mtx`) until `wiphy_work_queue` / `wiphy_delayed_work_queue` finishes. Work handlers `ieee80211_csa_finalize_work` and `ieee80211_color_change_finalize_work` must recheck `csa_active` / `color_change_active` and `ieee80211_sdata_running(sdata)` under the wiphy lock. [F31, F32, F80, F139]
- Updates to RCU-protected AP frame pointers on `link->u.ap` (`beacon`, `probe_resp`, `fils_discovery`, `unsol_bcast_probe_resp`, `s1g_short_beacon`) and `sdata->qos_map` must fully populate the new object before `rcu_assign_pointer` (or `RCU_INIT_POINTER`) and free the old object via `kfree_rcu`. [F26]
- `drv_start()` must set `local->started = true` and call `smp_mb()` before `local->ops->start()`; `drv_stop()` must call `local->ops->stop()`, `tasklet_disable()`/`tasklet_enable()` on `local->tasklet`, and `barrier()` before clearing `local->started = false`. In `ieee80211_del_tx_ts`, after setting `tx_tspec->up = -1`, run `synchronize_net()` and `ieee80211_flush_queues(local, sdata, false)` before `ieee80211_sta_handle_tspec_ac_params(sdata)` and zeroing `tx_tspec`. [F28, F127]
- Ethtool callbacks (`ieee80211_set_ringparam`, `ieee80211_get_ringparam`, `ieee80211_get_stats`) and `aql_txq_limit_write` must take `guard(wiphy)(local->hw.wiphy)` before iterating `local->sta_list`, updating `local->aql_txq_limit_low`/`high`, or calling `drv_set_ringparam`, `drv_get_ringparam`, or `drv_get_survey`. Netdev, link, and station aggregation debugfs handlers (`ieee80211_if_read/write_sdata`, `ieee80211_if_read/write_link`, `sta_agg_status_read/write`) must use `wiphy_locked_debugfs_read()` / `wiphy_locked_debugfs_write()`. [F36, F37, F154]
- AQM/airtime handlers (`ieee80211_get_txq_stats`, `aqm_read`, `ieee80211_if_fmt_aqm`, `sta_aqm_read`, `sta_airtime_read/write`, `sta_aql_read`) must hold `spin_lock_bh()` on `local->fq.lock` or `local->active_txq_lock[ac]` and keep `GFP_KERNEL` allocations and user copies outside the lock. `local->ack_status_lock` (`ieee80211_attach_ack_skb()`) and `local->queue_stop_reason_lock` (`queues_read()`) require `spin_lock_irqsave()`. `drv_link_sta_rc_update()` and `drv_get_key_seq()` run under `rcu_read_lock()` and must not call `might_sleep()` or block. [F143, F145, F155]

## Object Lifetimes

- `local->chanctx_list` is traversed under `rcu_read_lock()` by `ieee80211_iter_chan_contexts_atomic()`, so insertions require `list_add_rcu()` and removals (`ieee80211_free_chanctx()`, `ieee80211_link_unreserve_chanctx()`, `ieee80211_vif_use_reserved_switch()`) require `list_del_rcu()` and `kfree_rcu()`. Freeing either context of a replacement pair (`ieee80211_replace_chanctx()`) must reset its peer's `replace_ctx = NULL` and `replace_state = IEEE80211_CHANCTX_REPLACE_NONE`; if `ieee80211_link_unreserve_chanctx` drops `ieee80211_chanctx_refcount` to 0 on a `REPLACES_OTHER` context, free it via `list_del_rcu`/`kfree_rcu` without calling `ieee80211_free_chanctx`. [F3, F69, F147]
- If `drv_start_ap` fails in `ieee80211_start_ap` after `ieee80211_assign_beacon`, free `link->u.ap.beacon` via `kfree_rcu`, clear it with `RCU_INIT_POINTER`, clear `sdata->u.ap.active` if `ieee80211_num_beaconing_links(sdata) == 0`, and call `ieee80211_link_release_channel(link)`. In `ieee80211_stop_ap`, check `ieee80211_num_beaconing_links(sdata) <= 1` before clearing `link->u.ap.beacon`, subtract `skb_queue_len(&sdata->u.ap.ps.bc_buf)` from `local->total_ps_buffered` before `ieee80211_purge_tx_queue()`, and call `ieee80211_link_copy_chanctx_to_vlans(link, true)` before `ieee80211_link_release_channel(link)`. [F12, F18, F24, F102]
- In `__ieee80211_channel_switch`, if `link_conf->color_change_active` is true, call `ieee80211_color_change_abort(link_data)` before `ieee80211_set_csa_beacon()` overwrites `link_data->u.ap.next_beacon`. `ieee80211_nan_conf_copy` frees existing buffers in `dst` when `CFG80211_NAN_CONF_CHANGED_CONFIG` is set and calls `ieee80211_nan_conf_free(dst)` on error; never pass an uninitialized `dst` or copy into `sdata->u.nan.conf` before `drv_nan_change_conf` succeeds. In `ieee80211_del_intf_link`, do not clear `wdev->valid_links` before `ieee80211_vif_set_links()` completes. [F7, F14, F17]
- `sdata->deflink.debugfs_dir` and `sta->deflink.debugfs_dir` alias `sdata->vif.debugfs_dir` and `sta->debugfs_dir` in non-MLO mode, so `ieee80211_link_debugfs_remove` and `ieee80211_link_sta_debugfs_remove` must check for equality with the parent `debugfs_dir` and only clear the pointer without `debugfs_remove_recursive`. `drv_add_interface()` sets `IEEE80211_SDATA_IN_DRIVER` and adds driver debugfs after `add_interface()` succeeds; `drv_remove_interface()` clears `IEEE80211_SDATA_IN_DRIVER` and calls `ieee80211_debugfs_recreate_netdev()` before `remove_interface()`. `drv_change_vif_links` and `drv_change_sta_links` must remove link debugfs before the driver call and add them only after success when `!local->in_reconfig && !local->resuming`. [F15, F16, F131]

## API Contracts

- In `sta_apply_parameters()`, for TDLS peers or transitions to `NL80211_STA_FLAG_ASSOCIATED`, defer `sta_apply_auth_flags()` until after `sta_link_apply_parameters()`. `sta_apply_auth_flags()` must check upward transitions in order `AUTHENTICATED` -> `ASSOCIATED` -> `AUTHORIZED` and downward in reverse. Initialize rate control (`rate_control_rate_init_all_links(sta)` / `rate_control_rate_init(link_sta)`) before `IEEE80211_STA_ASSOC` or `ieee80211_sta_activate_link()`. In `ieee80211_add_link_station`, free a link from `ieee80211_sta_allocate_link` with `ieee80211_sta_free_link` if `sta_link_apply_parameters` fails; `ieee80211_sta_activate_link` consumes and frees it on failure. [F9, F62, F92, F136]
- `ieee80211_link_or_deflink()` returns `ERR_PTR(-EINVAL)` or `ERR_PTR(-ENOLINK)` (never `NULL`); callers must check `IS_ERR()`. When `link_id` can be `-1`, never index `sdata->link[]` or `sta->link[]` directly: use `ieee80211_link_or_deflink()` or clamp `link_id < 0` to `0` (`sta_link_apply_parameters()`, `drv_mgd_prepare_tx()`, `drv_mgd_complete_tx()`, `drv_mgd_protect_tdls_discover()`). In link-specific `cfg80211` ops (`__ieee80211_channel_switch`, `__ieee80211_csa_finalize`, `ieee80211_color_change`, `ieee80211_color_change_finalize`, `ieee80211_stop_ap`), pass the target `link_id` rather than `0` to `cfg80211` notifications. [F39, F51, F52, F81]
- `ieee80211_set_tx_power()` rejects `mbm < 0 || (mbm % 100)` with `-EOPNOTSUPP` and converts via `MBM_TO_DBM(mbm)` (or `INT_MIN` for `NL80211_TX_POWER_AUTOMATIC`), while `ieee80211_get_tx_power()` returns `-EINVAL` if `*dbm == INT_MIN`. When `!ieee80211_hw_check(&local->hw, NO_VIRTUAL_MONITOR)`, `ieee80211_set_tx_power()` must skip `NL80211_IFTYPE_MONITOR` in `local->interfaces`, and both `ieee80211_set_tx_power()` and `ieee80211_set_mon_options()` must check `WANT_MONITOR_VIF` before configuring `local->monitor_sdata`. [F53, F104, F128]
- `drv_flush_sta()` and `drv_get_expected_throughput()` must check `sta->uploaded` before calling `local->ops`. `ieee80211_add_chanctx()` must call `ieee80211_idle_off(local)` and `ieee80211_hw_config(local, -1, changed)` before `drv_add_chanctx()`, and `ieee80211_recalc_idle(local)` if it fails. In `sta_link_apply_parameters()`, validate `link->conf->chanreq.oper.width` is `NL80211_CHAN_WIDTH_20`..`320` before `__ieee80211_vht_handle_opmode()`. Before `ieee80211_assign_beacon()` or `ieee80211_set_probe_resp()`, check `n_counter_offsets_beacon` and `n_counter_offsets_presp <= IEEE80211_MAX_CNTDWN_COUNTERS_NUM`. Never pass `RX_QUEUED` (`___RX_QUEUED`) to `kfree_skb_reason()`. In `_link_id_dbg()`, pass `print` to `_sdata_dbg()` and gate `net_ratelimit()` behind `MAC80211_*_DEBUG`. [F44, F47, F75, F78, F134, F157]

## Error Handling

- In `chan.c`, `ieee80211_find_chanctx()`, `ieee80211_find_reservation_chanctx()`, and `ieee80211_alloc_chanctx()` return `NULL` on error, whereas `ieee80211_new_chanctx()` and `ieee80211_replace_chanctx()` return `ERR_PTR(-errno)` (`IS_ERR()`). `ieee80211_vif_use_reserved_switch()` returns `-EAGAIN` when deferred waiting for other links; `ieee80211_link_use_reserved_context()` must treat `-EAGAIN` as non-fatal and only propagate other errors when `new_ctx->replace_state == IEEE80211_CHANCTX_REPLACES_OTHER`. [F42, F43]
- `ieee80211_set_probe_resp()` returns `< 0` on error, `0` when installed, and `1` when absent; callers (`ieee80211_assign_beacon()`) must check `err < 0` for error and `err == 0` before setting `BSS_CHANGED_AP_PROBE_RESP`. In `ieee80211_add_key()`, convert `-EALREADY` from `ieee80211_key_link()` to `0`. User-facing callers of `ieee80211_set_active_links()` (`ieee80211_if_parse_active_links()`) must reject `active_links == 0` with `-EINVAL`. `check_sdata_in_driver()` must suppress `WARN_ONCE()` when `sdata->local->reconfig_failure` is set; `drv_conf_tx()` must gate its invalid `cw_min`/`cw_max` warning on `WARN_ONCE(local->ops->conf_tx, ...)`. [F40, F156, F159, F160, F174]

## External Contracts

- In `ieee80211_add_iface()`, never call `drv_prep_add_interface()` for `NL80211_IFTYPE_AP_VLAN`, and for `NL80211_IFTYPE_MONITOR` only when `WANT_MONITOR_VIF` and `params->flags & MONITOR_FLAG_ACTIVE` are set. When `fips_enabled` is true, `drv_set_key()` returns `-EOPNOTSUPP`, `drv_set_rekey_data()` is a no-op, and `ieee80211_add_key()` rejects WEP/TKIP with `-EINVAL`. `key_tx_spec_write()` must reject `pn >= (1ULL << 48)` with `-ERANGE`. `ieee80211_add_tx_ts()` must multiply `admitted_time` by 32 when storing `ifmgd->tx_tspec[ac].admitted_time`. [F85, F161, F162, F167]

## Known Pitfalls

- `cfg80211_beacon_dup()` allocates `mbssid_ies` and `rnr_ies` separately so `ieee80211_free_next_beacon()` must `kfree` both before freeing `link->u.ap.next_beacon`, whereas `struct beacon_data` in `ieee80211_assign_beacon()` embeds them in a single allocation. In `drv_assign_vif_chanctx()` and `drv_unassign_vif_chanctx()`, return early before `check_sdata_in_driver(sdata)` when `sdata->vif.type == NL80211_IFTYPE_MONITOR && local->emulate_chanctx && !ieee80211_hw_check(&local->hw, WANT_MONITOR_VIF)`. In `ieee80211_get_stats`, multiply `cfg80211_calculate_bitrate()` by `100000ULL` and cast `sinfo.signal_avg` and `survey.noise` (`s8`) to `u8` before storing into `u64 *data`. In `mpath_set_pinfo`, guard `jiffies_to_msecs(mpath->exp_time - jiffies)` with `time_before(jiffies, mpath->exp_time)`. [F59, F110, F111, F117, F129]
