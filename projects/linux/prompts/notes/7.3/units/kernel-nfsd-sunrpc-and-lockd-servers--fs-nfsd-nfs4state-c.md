# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd/nfs4state.c

`fs/nfsd/nfs4state.c` implements the NFSv4.0–4.2 state manager, handling lifecycles, lookups, and locking for clients (`nfs4_client`), sessions (`nfsd4_session`), stateowners, stateids (`nfs4_stid`), opened files (`nfs4_file`), POSIX locks, VFS leases (delegations), and the laundromat worker.

## Architecture & Data Flow
- Keep `struct nfs4_stid` (`dl_stid`, `st_stid`, `ls_stid`) at offset 0 of `nfs4_delegation`, `nfs4_ol_stateid`, and `nfs4_layout_stateid`, and `struct nfs4_stateowner` (`oo_owner`, `lo_owner`) at offset 0 of `nfs4_openowner` and `nfs4_lockowner` for direct slab alloc/free. Check `so->so_is_open_owner` before `openowner(so)`/`lockowner(so)` in `cl_ownerstr_hashtbl`, and `st->st_openstp == NULL` to distinguish open from lock stateids on `fp->fi_stateids`. [F224, F295, F296]
- Cast VFS `fl->c.flc_owner` to `struct nfs4_delegation *` only if `fl->fl_lmops == &nfsd_lease_mng_ops`, or to `struct nfs4_lockowner *` only if `fl->fl_lmops == &nfsd_posix_mng_ops` (`nfsd4_deleg_getattr_conflict`, `nfs4_set_lock_denied`). [F221]
- Each bit in `stp->st_access_bmap` holds one ref in `fp->fi_access[O_RDONLY]`/`fi_access[O_WRONLY]`; check `test_access()` before `__nfs4_file_get_access()` or `nfs4_file_put_access()`. `fp->fi_share_deny` caches the union of `bmap_to_share_mode(stp->st_deny_bmap)` across `fp->fi_stateids`; update under `fp->fi_lock` when adding bits and call `recalculate_deny_mode(fp)` (or `reset_union_bmap_deny()`) when clearing/unhashing. [F237, F238]
- `alloc_init_deleg` increments `num_delegations` on entry and must decrement via `out_dec` on error before `nfs4_alloc_stid` succeeds; thereafter `nfs4_free_deleg` decrements it. Setting `SC_STATUS_ADMIN_REVOKED` (`unhash_delegation_locked`, `nfsd4_revoke_states`) must pair with `atomic_inc(&clp->cl_admin_revoked)`, decremented in `nfs4_put_stid` or `put_ol_stateid_locked` on `cl_stateids` removal. [F196, F198]
- `put_ol_stateid_locked()` reuses `stp->st_locks` for `reaplist`, so child lock stateids must be drained via `unhash_open_stateid()` / `release_open_stateid_locks()` first. Delegation `reaplist` users (`nfs4_laundromat`, `__destroy_client`, `nfs4_state_shutdown_net`) reuse `dp->dl_recall_lru` after `unhash_delegation_locked()` and must unlink with `list_del_init(&dp->dl_recall_lru)` before `revoke_delegation()` or `destroy_unhashed_deleg()`. [F276, F277]
- Update `oo->oo_last_closed_stid` and `oo->oo_close_lru` (on `nn->close_lru`) together under `nn->client_lock` (`move_to_close_lru`, `release_last_closed_stateid`, `nfs4_laundromat`); `nfsd4_bump_seqid()` must call `release_last_closed_stateid()` before advancing an openowner's `so_seqid`. [F252]
- Under `nn->client_lock`, `NFSD4_CLIENT_CONFIRMED` in `clp->cl_flags` must match whether `clp->cl_namenode` is in `nn->conf_name_tree` or `nn->unconf_name_tree` for `unhash_client_locked()`. Call `nfsd4_dec_courtesy_client_count(nn, clp)` before setting `clp->cl_state = NFSD4_ACTIVE` (`get_client_locked`, `renew_client_locked`) or destroying `clp`. In `nfs4_get_client_reaplist()`, check `clp->cl_state == NFSD4_EXPIRABLE` before `if (!state_expired(lt, clp->cl_time)) break;`. [F243, F245, F280]
- `nfs4_open_delegation()` snapshots initial timestamps via `nfs4_delegation_stat()` into `dp->dl_atime`/`dl_mtime`/`dl_ctime`; `cb_getattr_update_times()` vets delegated timestamps against `dp->dl_*time` via `nfsd4_vet_deleg_time()`, not inode timestamps. [F241]
- `struct nfs4_clnt_odstate` pointers (`open->op_odstate`, `stp->st_clnt_odstate`, `dp->dl_clnt_odstate`) are allocated only when `nfsd4_has_session(cstate)` and `NFSEXP_PNFS` are set, and are `NULL` otherwise; all handlers must tolerate `NULL`. [F227]
- Compare `si_generation` via `nfsd4_stateid_generation_after(a, b)` (`(s32)(a->si_generation - b->si_generation) > 0`), never `>`. In `nfs4_inc_and_copy_stateid`, advance `si_generation` wraparound `0` to `1` (`0` is a session wildcard in `check_stateid_generation`). `nfs4_alloc_stid()` reserves ID 0 in `cl->cl_stateids` (`start = 1`), and `states_next()` must increment `id++` before `idr_get_next_ul()`. [F272, F292, F293]
- In `alloc_session`, clamp `new->se_cb_highest_slot` to `min(battrs->maxreqs - 1, NFSD_BC_SLOT_TABLE_SIZE - 1)` (reporting `maxreqs = se_cb_highest_slot + 1` in `nfsd4_create_session`). In `reduce_session_slots()`, if 16-bit `ses->se_slot_gen` wraps to `0`, set it to `1` and reset `slot->sl_generation = 0` across active slots under `nn->client_lock`. In `delegation_blocked()`, under `blocked_delegations_lock`, update `bd->entries`/`old_entries` and toggle `bd->new = 1 - bd->new` before zeroing `bd->set[bd->new]`. [F247, F262, F274]

## Synchronization
- Lock order: `state_lock` -> `clp->cl_lock` -> `fp->fi_lock`, and `nn->client_lock` -> `clp->cl_lock` -> `nfsd_session_list_lock`. `reduce_session_slots()` (under `nfsd_session_list_lock`) must use `spin_trylock(&nn->client_lock)`. In `nfsd4_del_conns()`, drop `clp->cl_lock` after unlinking each `nfsd4_conn` before `unregister_xpt_user()` (which syncs with `nfsd4_conn_lost()`, taking `clp->cl_lock`) and `free_conn()`. [F209, F308, F332]
- `stp->st_mutex` nests outside `clp->cl_lock` and `fp->fi_lock`: pin `stp->st_stid.sc_count`, drop spinlocks, and call `nfsd4_lock_ol_stateid(stp)` (`LOCK_STATEID_MUTEX` + `nfsd4_verify_open_stid`). In `init_open_stateid()` and `init_lock_stateid()`, lock candidate `stp->st_mutex` with `OPEN_STATEID_MUTEX` before `retry:`; if `retstp` is found, keep `stp->st_mutex` locked across `goto retry` on `nfsd4_lock_ol_stateid(retstp)` failure, or unlock `stp->st_mutex` before returning `retstp`. Under `cl_lock`, verify `!nfs4_openowner_unhashed(oo)` or `!nfs4_ol_stateid_unhashed(open_stp)` before linking into `so_stateids`, `fi_stateids`, or `st_locks`. [F211, F212, F287, F313]
- `nfs4_preprocess_seqid_op` and `nfs4_preprocess_confirmed_seqid_op` return `nfs_ok` with `*stpp` referenced and `stp->st_mutex` locked; on error, neither is held. `nfsd4_drop_revoked_stid` is entered with `cl->cl_lock` held and must unlock it on every path before returning or calling `free_ol_stateid_reaplist` / `nfs4_put_stid`. [F199, F201]
- `nfsd_break_one_deleg` runs under VFS `flc_lock`: if `nfsd4_run_cb(&dp->dl_recall)` fails, use `refcount_dec(&dp->dl_stid.sc_count)`, never `nfs4_put_stid`, and `nfs4_free_deleg` must not sleep. Callers unhashing a delegation for `revoke_delegation` (`nfs4_laundromat`, `nfsd4_revoke_states`) must increment `sc_count` before dropping `state_lock`. `revoke_delegation` and `nfsd4_free_stateid` sync `clp->cl_revoked` under `cl->cl_lock` via `SC_STATUS_FREEABLE`/`SC_STATUS_FREED`; `nfsd4_free_stateid` on a `SC_STATUS_REVOKED` delegation must set `SC_STATUS_CLOSED` under `s->sc_lock` and `SC_STATUS_FREED` under `cl->cl_lock` before dropping `cl->cl_lock` for `nfs4_put_stid(s)`. [F204, F206, F207]
- In `move_to_close_lru`, call `store_release_wake_up(&oo->oo_owner.so_replay.rp_locked, RP_UNHASHED)` before `wait_event(close_wq, refcount_read(&s->st_stid.sc_count) == 2)` so `nfsd4_cstate_assign_replay` waiters drop `sc_count`. In `force_expire_client`, after waiting on `expiry_wq` for `cl_rpc_users == 0`, recheck `list_empty(&clp->cl_lru)` under `nn->client_lock`; if already unhashed, wait on `expiry_wq` for `clp->cl_nfsd_dentry == NULL`. [F213, F214]
- `nfs4_file_rhltable` lookups (`nfsd4_file_hash_lookup`, `nfsd4_file_hash_insert`) require `rcu_read_lock()` and `refcount_inc_not_zero(&fi->fi_ref)`. `nfsd4_file_hash_insert` must hold `inode->i_lock` across lookup, `nfsd4_file_init`, `rhltable_insert`, and setting `fi_aliased = true` on both existing sibling `nfs4_file` entries and the new `nfs4_file`. [F215, F249]
- Place `smp_mb__after_atomic()` after `atomic_read(&ino->i_writecount)` before reading `fp->fi_fds[]` in `nfsd4_check_conflicting_opens`, and after `destroy_delegation(dp)` before `wake_up_var()` in `nfsd4_delegreturn` (waking `nfsd_wait_for_delegreturn`). [F216, F218]
- In `nfsd4_lock`, queue blocking locks (`FL_SLEEP`) onto `lock_sop->lo_blocked` and `nn->blocked_locks_lru` with `kref_get(&nbl->nbl_kref)` under `nn->blocked_locks_lock` before `vfs_lock_file`. Cleanup in `nfsd4_lock` must check `!list_empty(&nbl->nbl_list) && !list_empty(&nbl->nbl_lru)` under `nn->blocked_locks_lock` before unlinking and putting `nbl_kref` (`remove_blocked_locks`/`nfs4_laundromat` clear `nbl_list` while moving `nbl_lru`). Call `locks_delete_block` / `free_blocked_lock` only outside `nn->blocked_locks_lock`. [F217, F278, F316]
- `nfsd_client_shrinker` callbacks (`nfsd4_state_shrinker_count`, `nfsd4_state_shrinker_scan`) must not expire clients or recall delegations synchronously; offload to `nn->nfsd_shrinker_work` on `laundry_wq`. Pair `idr_preload(GFP_KERNEL)` outside `cl->cl_lock` / `nn->s2s_cp_lock` with `idr_alloc_cyclic(..., GFP_NOWAIT)` inside (`nfs4_alloc_stid`, `nfs4_init_cp_state`). [F309, F310]

## Object Lifetimes
- `nfsd4_sequence_check_conn` always consumes `new` (hashing or calling `free_conn(new)`), so `nfsd4_sequence` must set `conn = NULL`. When `nfsd4_process_open2` or `init_open_stateid` hashes `open->op_file`, `open->op_stp`, or `open->op_odstate`, clear that `open->op_*` pointer to `NULL` so `nfsd4_cleanup_open_state` only frees unconsumed allocations. [F185, F186]
- `move_to_close_lru` must set `s->st_stid.sc_file = NULL` after `put_nfs4_file()`. In `__nfs4_file_put_access` and `put_deleg_file`, when `fp->fi_access[oflag]` or `fp->fi_delegees` hits zero, clear `fp->fi_fds[]`, `fp->fi_deleg_file`, and `fp->fi_rdeleg_file` to `NULL` under `fp->fi_lock` before `nfsd_file_put` outside the lock. [F193, F195]
- In `nfsd4_create_session`, if `mark_client_expired_locked(old)` returns `nfserr_jukebox` after `cs_slot->sl_seqid++`, `out_expired_error` must revert `cs_slot->sl_seqid--`, skip `nfsd4_cache_create_session`, and drop `nn->client_lock` before `free_conn` and `__free_session`. Before freeing an `nfs4_ol_stateid` (`free_ol_stateid_reaplist` on v4.1+, or `nfs4_put_stid`), `nfs4_free_cpntf_statelist()` must drain `stid->sc_cp_list`. [F202, F256]

## API Contracts
- `nfs4_preprocess_stateid_op` sets `*cstid` only on `nfs_ok` for non-special stateids (dropping `s` via `nfs4_put_stid` on error or `cstid == NULL`, and leaving `*cstid` untouched on `ZERO_STATEID`/`ONE_STATEID`); callers must init `*cstid = NULL`, check `if (st)`, and put `st`. `nfsd4_deleg_getattr_conflict` sets `*pdp = dp` only on `nfs_ok` when `ncf_file_modified` is true; callers must init `*pdp = NULL` and call `nfs4_put_stid(&dp->dl_stid)` if non-NULL. [F188, F230, F234]
- Check that `get_client_locked(clp)` returns `nfs_ok` before using `clp` or calling `put_client_renew*()`, as it returns `nfserr_expired` without incrementing `cl_rpc_users` when `is_client_expired(clp)` is true. [F219]
- `st_access_bmap` and `st_deny_bmap` store `1 << mode` (bits 1..3), not wire `NFS4_SHARE_*` masks; convert via `bmap_to_share_mode()` before wire mask ops or `reset_union_bmap_deny(deny, stp)`. `fi_fds[3]` takes `O_RDONLY`/`O_WRONLY`/`O_RDWR` (`nfs4_access_to_omode()`), whereas `fi_access[2]` and `__nfs4_file_put_access(fp, oflag)` only accept `O_RDONLY` (0) or `O_WRONLY` (1). [F225, F226]
- Validate NFSv4 lock ranges with `check_lock_length()`, set `fl_end = last_byte_offset(offset, length)`, and call `nfs4_transform_lock_offset()`. In `nfsd4_process_open2`, delegation claims (`nfsd4_is_deleg_cur(open)`) must verify `dp->dl_stid.sc_file == fp` and return `nfserr_inval` on mismatch (or `nfserr_bad_stateid` if `fp` was newly inserted). [F236, F265]
- `cb_getattr_update_times()` must set `ATTR_ATIME_SET`/`ATTR_MTIME_SET`/`ATTR_CTIME_SET` and `ATTR_DELEG` in `ia_valid` before `notify_change()` under `inode_lock()`. `nfs4_unlock_deleg_lease()` must call `nfsd4_finalize_deleg_timestamps()` (clearing `FMODE_NOCMTIME`) before `kernel_setlease(..., F_UNLCK, ...)`. `nfsd_change_deleg_cb()` only allows `F_UNLCK` (`-EAGAIN` otherwise) and decrements `clp->cl_delegs_in_recall` if `dp->dl_recalled`. [F321, F322, F324]
- `nfs4_free_lock_stateid()` must release POSIX locks via `get_file(nf->nf_file)` and `filp_close(nf->nf_file, (fl_owner_t)lo)` before `nfsd_file_put(nf)`. Call `free_svc_cred()` before overwriting `clp->cl_cred` or `slot->sl_cred` via `copy_cred()` or freeing a slot/client. [F328, F336]

## Error Handling
- In `nfsd4_sequence()`, set `seq->maxslots`, `seq->target_maxslots`, and `seq->status_flags` after `out:` so `nfserr_replay_cache` jumps still initialize them. In `nfs4_get_vfs_file()`, sample `st_access_bmap`/`st_deny_bmap` before mutation and jump to `out_put_access` on failure to restore bitmaps, drop `fi_access`, and `reset_union_bmap_deny`. [F220, F239]

## External Contracts
- In `nfsd4_process_open2()`, `open_xor_delegation()` must release `stp` and zero `open->op_stateid` only when `new_stp` is true. In `create_client`, `client_files[]` must keep `"info"` at index 0 (`dentries[0]` -> `cl_nfsd_info_dentry`) and end with `{""}`. [F253, F266]
- `nfsd4_lookup_stateid()` must include `SC_STATUS_ADMIN_REVOKED | SC_STATUS_FREEABLE` in `statusmask` (plus `SC_STATUS_REVOKED` for `SC_TYPE_DELEG`) before `find_stateid_by_type()`. In `check_special_stateids()`, `ONE_STATEID(stateid) && (flags & RD_STATE)` returns `nfs_ok` before `opens_in_grace(net)`, whereas WRITE with `one_stateid` and READ/WRITE with `zero_stateid` check `opens_in_grace(net)` (`nfserr_grace`) first. [F267, F281]

## Known Pitfalls
- In `nfs4_open_delegation()` and `nfs4_delegation_stat()`, `currentfh` is the parent dir on `NFS4_OPEN_CLAIM_NULL`; query attributes from `file_dentry(nf->nf_file)` on `dp->dl_stid.sc_file` with `STATX_MODE`. In `nfsd4_lock()`, when `lock->lk_is_new` sets `cstate->replay_owner = &open_sop->oo_owner`, `out:` must also increment `lock_sop->lo_owner.so_seqid++` on `seqid_mutating_err(ntohl(status))`. [F268, F285]
- In `nfsd4_setclientid_confirm()`, reset `old = NULL` before `goto out` on any error after `old = find_confirmed_client_by_name(...)` prior to `mark_client_expired_locked(old)`. Cast `si.totalram` to `u64` before `* si.mem_unit` in `nfsd4_init_leases_net`. `xdr_netobj_dup` buffers (`cl_name`, `cl_nii_*`, `so_owner`, `ld_owner`) lack NUL terminators; bound reads by `.len` (`seq_quote_mem`, `same_owner_str`, `compare_blob`), never `%s`/`strcmp`/`strlen`. [F286, F288, F303]
