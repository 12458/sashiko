# DRM DRIVERS — (top level) (part 1)

This component comprises core DRM headers (`include/drm/*.h`), display protocol and bridge headers (`include/drm/display/*.h`, `include/drm/bridge/*.h`), AMD ASIC/ISP definitions, and GPU memory tracepoints (`drivers/gpu/trace/trace_gpu_mem.c`), defining state objects, refcounting, locking contracts, and driver callbacks for atomic KMS, DisplayPort (AUX, MST, DSC, tunneling), HDMI/HDCP/SCDC/MHL bridges, DRM device/driver lifecycles, and in-kernel DRM clients.

## Architecture & Data Flow

- `drm_atomic_state.connectors` is dynamically sized to `state->num_connector` with sparse `NULL` holes at unplugged indices: direct lookups by `drm_connector_index()` must check `index < state->num_connector`, and loops must guard on `state->connectors[i].ptr != NULL`. Because `drm_connector_mask()` computes `1 << connector->index` into a `u32` (`drm_crtc_state.connector_mask`), `drm_connector.index` must be in `[0, 31]`. [F79, F108]
- In `struct drm_plane_state`, `crtc` and `fb` must stay coupled: both non-NULL when enabled and both NULL when disabled (`WARN_ON` in `drm_atomic_plane_enabling()` / `drm_atomic_plane_disabling()`). [F67]
- `drm_connector.registration_state` is a tristate (`DRM_CONNECTOR_INITIALIZING`, `DRM_CONNECTOR_REGISTERED`, `DRM_CONNECTOR_UNREGISTERED`); `drm_connector_is_unregistered()` is true only for `DRM_CONNECTOR_UNREGISTERED`, allowing modesets during init while blocking them on removed connectors. Updates require `drm_connector.mutex`; unlocked readers must use `drm_connector_is_unregistered()` (`READ_ONCE()`). [F34, F126]
- In `struct drm_dp_mst_branch`, `port_parent` is `NULL` and `rad[8]` is all zeros (`lct == 1`) for the root primary branch `mgr->mst_primary`; `rad` nibbles are only valid for link counts `2 .. mstb->lct`. DPCD capability size macros spanning inclusive `[start, end]` (e.g., `DP_DSC_RECEIVER_CAP_SIZE`, `DP_PCON_DSC_ENCODER_CAP_SIZE`) must be `end - start + 1` so indexing `buf[end - start]` stays in bounds. [F52, F83]
- `drm_client_for_each_modeset()` advances `modeset++` until `modeset->crtc == NULL`, requiring `client->modesets` to have `num_crtc + 1` entries with a trailing zeroed sentinel (`crtc == NULL`). In `struct drm_crtc_crc`, `DRM_CRC_ENTRIES_NR` (`128`) must be a power of two, and `values_cnt` from `verify_crc_source` must be in `1..DRM_MAX_CRC_NR` (`10`). [F92, F93]
- Store DRM/HDA audio binding primitives (`master_bind_complete`, `dev`) per instance in `struct drm_audio_component`, never in static variables. Every `enum amd_asic_type` before `CHIP_LAST` in `include/drm/amd_asic_type.h` must match `amdgpu_asic_name[]`. `drm_arch_can_wc_memory()` must be `false` on ARM, arm64, LoongArch, Loongson64 MIPS, and cache-coherent PowerPC. [F62, F95, F137]

## Synchronization

- `drm_device.vbl_lock` wraps inner `drm_device.vblank_time_lock`. `drm_crtc_funcs.enable_vblank`, `disable_vblank`, `get_vblank_counter`, and `get_vblank_timestamp` run with both spinlocks held (IRQs disabled) and must never sleep. [F134]
- `drm_dev_is_unplugged()` drops its critical section immediately via `drm_dev_exit()` and races with `drm_dev_unplug()`; guard hotpluggable hardware access with paired `drm_dev_enter()` / `drm_dev_exit()`. [F35]
- When a `struct drm_private_obj` shares state across CRTCs, store a `struct drm_crtc_commit` reference in the private state during `atomic_commit_setup` and wait on it at the start of `atomic_commit_tail` to prevent out-of-order non-blocking commits from freeing it. [F29]
- In `struct drm_dp_mst_topology_mgr`: `payload_count` and `next_start_slot` are commit-only (never touch in `atomic_check`); `drm_dp_mst_atomic_payload.vc_start_slot` may only be read in commit after `drm_dp_mst_atomic_wait_for_dependencies()` (and after `drm_dp_add_payload_part1()` / `drm_dp_remove_payload_part2()` for updated slots), or under the MST modeset lock after `drm_crtc_commit_wait()` on `commit_deps`. [F24, F25]
- In `struct drm_dp_mst_topology_mgr`: `up_req_recv` and `down_rep_recv` are read unlocked, so topology removal must set `mgr->reset_rx_state = true` under `mgr->lock` rather than resetting them directly; `drm_dp_mst_port.mstb` and `drm_dp_mst_branch.ports` are modified only by `mgr->work` and `mgr->up_req_work` under both `mgr->probe_lock` and `mgr->lock` (external readers need `mgr->lock`); `qlock` protects `tx_msg_downq` and `drm_dp_sideband_msg_tx.state`, `delayed_destroy_lock` protects `destroy_port_list` and `destroy_branch_device_list`, and `up_req_lock` protects `up_req_list`. [F22, F27, F138]
- `drm_dp_aux.hw_mutex` only serializes a single `struct drm_dp_aux`; if multiple channels share hardware or `drm_dp_mst_topology_cbs.poll_hpd_irq` is used, drivers must lock against concurrent hardware access and HPD IRQs. [F143]
- In `struct drm_connector`, `drm_mode_config.connection_mutex` protects `state`; `drm_mode_config.mutex` protects `modes`, `status`, `probed_modes`, `display_info`, and `edid_blob_ptr`; `eld_mutex`, `edid_override_mutex`, `hdmi.infoframes.lock`, and `hdmi_audio.lock` protect `eld`, `edid_override`, `audio`, and `plugged_cb`. [F40]
- In `struct drm_master`, `drm_device.master_mutex` protects `unique`, `unique_len`, and `magic_map`; `drm_device.mode_config.idr_mutex` protects lease fields (`lessee_id`, `lessee_list`, `lessees`, `leases`, `lessee_idr`). `lessee_idr` and `lessees` are only used on the top-level owner (`lessor == NULL`, `lessee_id == 0`). [F37, F78]
- Initialize `struct drm_client_dev` with `drm_client_init()` and finish setup before `drm_client_register()` adds `client->list` under `drm_device.clientlist_mutex`. Hold `client->modeset_mutex` for `drm_client_for_each_modeset()`. Pair every successful `drm_client_buffer_vmap_local()` with `drm_client_buffer_vunmap_local()`. [F15, F31]

## Object Lifetimes

- Call `drm_plane_helper_funcs.end_fb_access` and finish reading `new_crtc_state` and `new_plane_state` before `drm_atomic_helper_commit_hw_done()`, which allows a subsequent commit to swap and free them. When `drm_atomic_helper_setup_commit()` takes a `drm_crtc_commit` reference for `new_crtc_state->event->base.completion`, it sets `commit->abort_completion = true` so `__drm_atomic_helper_crtc_destroy_state()` drops it if the commit aborts with `state->event` non-NULL. [F3, F5]
- Initialize `struct drm_private_obj` via `drm_atomic_private_obj_init()` before `drm_dev_register()` and clean up via `drm_atomic_private_obj_fini()` after `drm_dev_unregister()`. Modify `drm_connector_state.crtc` only via `drm_atomic_set_crtc_for_connector()` to keep connector refcounts and `crtc_state->connector_mask` symmetric. [F1, F20]
- A `struct drm_connector *` from `drm_connector_list_iter_next()` or `drm_for_each_connector_iter()` is valid only until the next step or `drm_connector_list_iter_end()`. Pair every `drm_connector_list_iter_begin()` with `drm_connector_list_iter_end()`; under `connector_list_lock`, final connector puts defer cleanup via `free_node` on `connector_free_list` and `connector_free_work`. Assigning `drm_connector.fwnode` transfers a `fwnode_handle` reference released by `drm_connector_cleanup()`. [F11, F12, F133]
- After `drm_client_register()`, never call `drm_client_release()` outside `drm_client_funcs.unregister`. Release `drm_file_get_master()` references on all paths with `drm_master_put(&master)` (which nulls `master`). Set `drm_device.dma_dev` via `drm_dev_set_dma_dev()` and read it via `drm_dev_dma_dev()`. [F14, F16, F123]
- Retain `struct drm_dp_mst_port *` by calling `drm_dp_mst_get_port_malloc()` in `drm_dp_mst_topology_cbs.add_connector` and releasing via `drm_dp_mst_put_port_malloc()` (never touch `topology_kref`). Release `drm_dp_tunnel_get()` / `drm_dp_tunnel_ref_get()` references with `drm_dp_tunnel_put()` (passing the same `ref_tracker **`) or `drm_dp_tunnel_ref_put()`. [F17, F18]

## API Contracts

- Atomic drivers (`drm_drv_uses_atomic_modeset()`) must set `atomic_duplicate_state` and `atomic_destroy_state` on `drm_crtc_funcs` and `drm_connector_funcs`, incrementing refcounts of all copied refcounted objects in `atomic_duplicate_state` and dropping them in `atomic_destroy_state`. `atomic_set_property` must only update `state` without mutating persistent state or doing cross-property validation (which belongs in `atomic_check`). [F7, F147, F151]
- `drm_atomic_state_alloc()` and `.atomic_duplicate_state()` return `NULL` on failure, whereas `devm_drm_dev_alloc()`, `drmm_crtc_alloc_with_planes()`, and `drm_client_framebuffer_create()` return `ERR_PTR()`. `funcs->destroy` must be `NULL` for managed `drmm_crtc_*` / `drmm_connector_*` init helpers and non-NULL for unmanaged `drm_crtc_init_with_planes()` / `drm_connector_init*()`. [F45, F53]
- Never modify `drm_atomic_state.allow_modeset`, never check it in commit paths (use `drm_atomic_crtc_needs_modeset()`), and check it before adding unrelated CRTCs via `drm_atomic_get_crtc_state()`. `drm_atomic_helper_duplicate_state()` sets `state->duplicated`, which check helpers/drivers must inspect to allow or fix up resume inconsistencies (e.g., unregistered connectors). [F65, F76]
- The core calls `drm_crtc_vblank_get()` before `drm_crtc_funcs.page_flip_target` and calls `drm_crtc_vblank_put()` on error; on `0`, the driver must call `drm_crtc_vblank_put()` on flip completion. Non-zero `drm_device.max_vblank_count` must be a `(1 << N) - 1` bitmask. [F8, F110]
- Per-device feature changes must modify `drm_device.driver_features`, never `drm_driver.driver_features`, and checks must use `drm_core_check_feature()` / `drm_core_check_all_features()`. Never combine `DRIVER_COMPUTE_ACCEL` with `DRIVER_RENDER` or `DRIVER_MODESET`. [F64, F124]
- Update `edid_blob_ptr`, `path_blob_ptr`, and `tile_blob_ptr` only via `drm_edid_connector_update()` / `drm_connector_update_edid_property()`, `drm_connector_set_path_property()`, and `drm_connector_set_tile_property()`. Never combine `DRM_CONNECTOR_POLL_HPD` with `DRM_CONNECTOR_POLL_CONNECT` / `DISCONNECT` in `connector->polled`, or call `drm_connector_attach_encoder()` when `connector->encoder` is already set. [F75, F162]
- `drm_connector_hdmi_audio_init()` requires non-NULL `prepare` and `shutdown` callbacks. For HDMI 4:4:4 deep color, check `edid_hdmi_rgb444_dc_modes` for RGB and `edid_hdmi_ycbcr444_dc_modes` for YCbCr. `drm_audio_component_ops.get_eld` returns the unclipped ELD length even when exceeding `@max_bytes`, so clamp positive returns to `@max_bytes`. [F90, F125, F154]
- `drm_dp_calc_pbn_mode()`, `drm_dp_bw_overhead()`, `drm_dp_link_symbol_cycles()`, and `drm_dsc_config.bits_per_pixel` take/store `.4` fixed-point bpp (`bpp << 4`, 1/16th bpp; use `>> 4` or `drm_dsc_get_bpp_int()` for integer bpp). [F55, F109]
- Call `drm_dp_aux_init()` before using AUX prior to registration (e.g., `of_dp_aux_populate_bus()`) and set `aux->drm_dev` before `drm_dp_aux_register()`. `drm_dp_aux.transfer()` returns bytes transferred or negative errno (`-EBUSY` retries) and must only mutate `msg->reply`. `wait_hpd_asserted` follows `readx_poll_timeout()` (`wait_us == 0` waits indefinitely, returns `0` or `-ETIMEDOUT` silently). [F43, F118, F130]
- `of_dp_aux_populate_bus()` / `devm_of_dp_aux_populate_bus()` return `-ENODEV` when `aux-bus` is absent (deprecated `*_ep_devices()` wrappers return `0`). `devm_drm_dp_hpd_bridge_alloc()` and `drm_dp_hpd_bridge_register()` return `ERR_PTR()` on error when `CONFIG_DRM_AUX_HPD_BRIDGE` is enabled, but `NULL` when disabled. `drm_dp_tunnel_get_allocated_bw()` and `drm_dp_tunnel_available_bw()` return `-1` when undetermined/disabled; `drm_dp_tunnel_update_state()` and `drm_dp_tunnel_handle_irq()` return `1` if changed, `0` if unchanged, or negative errno. [F46, F47, F48]
- Keep `#else` inline stubs in lockstep with signature changes in `include/drm/bridge/aux-bridge.h`, `include/drm/drm_debugfs.h`, `include/drm/drm_drv.h`, and `include/drm/display/drm_dp_tunnel.h`. [F60, F61, F77]
- Do not store per-device state in `drm_info_list.data` or `drm_debugfs_info.data` (use `seq_file->private`). Count LUT entries with `drm_color_lut_size()`, not byte `blob->length`. Terminate `dw_hdmi_plat_data` `mpll_cfg`, `cur_ctr`, and `phy_config` arrays with `mpixelclock == ~0UL`. Call `drm_memcpy_from_wc()` only in process context (`!in_interrupt()`). [F63, F94, F115, F136]

## External Contracts

- Atomic drivers must set `drm_connector_state.best_encoder` for `GETCONNECTOR`/`GETENCODER` and `drm_atomic_get_old/new_connector_for_encoder()`. In `struct drm_crtc_state`, `enable` governs shared resource reservation while `active` governs DPMS; never release shared resources when `active` is `false` while `enable` is `true`, and never fail `atomic_check` solely because `active` flips while `enable` is set. Virtualized drivers with hotspot-dependent cursor planes must set `DRIVER_CURSOR_HOTSPOT`. [F69, F70, F146]
- Endianness: `struct drm_dsc_picture_parameter_set` is a `__packed` 128-byte struct with `__be16` 16-bit fields; in `drm_hdcp.h`, 3-byte `seq_num_v` / `seq_num_m` and 24-bit SRM VRL lengths use `drm_hdcp_be24_to_cpu()` / `drm_hdcp_cpu_to_be24()`; in `mhl.h`, burst `id` / `burst_id[]` are `__be16`, while `mhl_burst_blk_rcv_buffer_info.size` is `__le16`. [F86, F87, F88]

## Known Pitfalls

- Despite `ssize_t` return types, `drm_scdc_read()`, `drm_scdc_write()`, `drm_dp_dual_mode_read()`, and `drm_dp_dual_mode_write()` return `0` on success and negative errno on failure, never byte counts. [F42]
- In `enum drm_dp_phy`, `DP_PHY_DPRX` is `0` and LTTPRs are 1-based (`DP_PHY_LTTPR1 = 1`..`8`); `DP_LTTPR_BASE(dp_phy)` and `DP_FEC_BASE(dp_phy)` require `dp_phy` in `DP_PHY_LTTPR1..DP_MAX_LTTPR_COUNT` (use `DP_PHY_LTTPR(i)` for 0-based `i`). Parenthesize `(val & MASK)` before `<<` or comparisons when decoding multi-field DPCD bytes (e.g., `DP_DSC_MAX_BITS_PER_PIXEL_HI`, `DP_DSC_BITS_PER_PIXEL_INC`). [F84, F98]
- In `drm_atomic.h`, sparse-array state iterators (`for_each_oldnew_*_in_state`, etc.) must assign cursors inside `for_each_if` only after checking `.ptr != NULL`. In `atomic_check` before state swap, walk CRTC planes via `drm_atomic_crtc_state_for_each_plane*()` on `crtc_state`, not `drm_atomic_crtc_for_each_plane()` (`crtc->state`). Check `drm_atomic_crtc_effectively_active(state)` rather than `state->active` alone when self-refresh may be active. [F96, F100, F103]
- `drm_connector_hdmi.vendor` (8) and `product` (16) are `__nonstring` padded arrays; never pass them to unbounded string functions. In `drm_color_lut_extract()`, `bit_precision > 16` requires `mul_u32_u32()` and `DIV_ROUND_CLOSEST_ULL()`, while `<= 16` uses 32-bit `DIV_ROUND_CLOSEST()`. Calling `drm_dev_unplug()` before `drm_atomic_helper_shutdown()` skips hardware disable callbacks guarded by `drm_dev_enter()`. [F91, F104, F120]
