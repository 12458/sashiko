# FIREWIRE SUBSYSTEM — (top level)

This unit comprises the kernel-wide and UAPI FireWire (IEEE 1394) headers (`include/linux/firewire.h`, `include/uapi/linux/firewire-cdev.h`), the SBP-2 SCSI-over-IEEE-1394 initiator driver (`drivers/firewire/sbp2.c`), PHY packet bitfield and Self-ID sequence helpers (`drivers/firewire/phy-packet-definitions.h`), KUnit test suites, and the userspace `nosy-dump` packet analyzer (`tools/firewire/`).

## Architecture & Data Flow

- `struct sbp2_orb base` must remain at offset 0 of `struct sbp2_management_orb`, `struct sbp2_command_orb`, and any new ORB subtype (`free_orb()` passes `container_of(kref, struct sbp2_orb, kref)` to `kfree()`), and every `struct sbp2_target` must reside at `shost->hostdata[0]` of a `struct Scsi_Host` from `scsi_host_alloc()` because `sbp2_conditionally_block()`, `sbp2_unblock()`, `sbp2_login()`, and `sbp2_remove()` downcast `tgt` via `container_of((void *)tgt, struct Scsi_Host, hostdata[0])`. [F278, F279]
- Each logical unit added in `sbp2_add_logical_unit()` increments `tgt->dont_block` by 1 (`lu->has_sdev = false`); `sbp2_probe()` must finish adding all units via `sbp2_scan_unit_dir()` before `sbp2_queue_work()` schedules `lu->work` on any unit, and `sbp2_allow_block(tgt)` decrements `tgt->dont_block` only once when initial `__scsi_add_device()` succeeds and sets `lu->has_sdev = true` (re-logins with `lu->has_sdev == true` must return early). [F198, F212]
- In `sbp2_status_write()`, inbound requests must satisfy `tcode == TCODE_WRITE_BLOCK_REQUEST` and `8 <= length <= sizeof(struct sbp2_status)` (32 bytes), `status.data` must be zeroed via `memset` before copying `length - 8` bytes, and the `list_for_each_entry` cursor `iter` over `lu->orb_list` must not be dereferenced after the loop (copy a match to `orb = NULL` before breaking and check `orb != NULL`). [F248, F261]
- When `sbp2_reconnect()` falls back to login by setting `lu->workfn = sbp2_login`, or when `sbp2_update()` schedules `lu->work` after a bus reset, `lu->retries` must be reset to `0` before `sbp2_queue_work()` so the worker gets a full 5-retry budget. [F264]
- In `sbp2_probe()`, `shost->max_cmd_len` must not exceed `SBP2_MAX_CDB_SIZE` (16), `scsi_driver_template.sg_tablesize` and `max_segment_size` must not exceed `SG_ALL` and `SBP2_MAX_SEG_SIZE` (`0xfffc`) to match `struct sbp2_command_orb`, and `sbp2_clamp_management_orb_timeout()` must clamp `tgt->mgt_orb_timeout` (bits 8..15 of `SBP2_CSR_UNIT_CHARACTERISTICS` in 500ms units) to `[5000, 40000]` ms before login work is queued. [F250, F251]
- In `sbp2_scsi_sdev_configure()`, `sdev->manage_system_start_stop`, `sdev->manage_runtime_start_stop`, and `sdev->manage_shutdown` may only be set when `sbp2_param_exclusive_login` is true, and `sbp2_send_management_orb()` must skip `SBP2_LOGOUT_REQUEST` when `fw_device_is_shutdown(device)` is true. [F301]
- `sbp2_init_workarounds()` must compute per-target `tgt->workarounds` in a local variable seeded from `sbp2_param_workarounds`, skipping `sbp2_workarounds_table` lookup when `SBP2_WORKAROUND_OVERRIDE` is set and never mutating `sbp2_param_workarounds` or `sbp2_workarounds_table`. [F244]
- `self_id_sequence_get_port_status()` and `self_id_sequence_set_port_status()` map 0-based `port_index` to `index = (port_index + 5) / 8` and `shift = 16 - ((port_index + 5) % 8) * 2` (capacity `quadlet_count * 8 - 5`), and `get_port_status` returns `PHY_PACKET_SELF_ID_PORT_STATUS_NONE` when `index >= min(quadlet_count, 4)` (`SELF_ID_SEQUENCE_MAXIMUM_QUADLET_COUNT`). [F253]
- In `tools/firewire/`, every `struct avc_opcode_info` entry in `opcode_info` (`decode-fcp.c`) must leave at least the final element of `fields[8]` with `.name == NULL` for `decode_avc()`, and any `packet_field` array in `nosy-dump.c` with a variable-length payload field (`width == 0`) must precede it with an unfiltered `PACKET_FIELD_DATA_LENGTH` field so `decode_link_packet()` sets `data_length` first. [F258, F269]

## Synchronization

- `sbp2_target.lock` (`tgt->lock`) must always be acquired with IRQ-disabling spinlock variants (`spin_lock_irqsave` or `spin_lock_irq`) because it protects `lu->orb_list`, `tgt->blocked`, `tgt->dont_block`, and `lu->blocked` across process/workqueue contexts and atomic callbacks (`sbp2_status_write()`, `complete_transaction()`). [F306]
- Under `tgt->lock`, `tgt->blocked` counts logical units with `lu->blocked == true`: `sbp2_conditionally_block()` must call `scsi_block_requests(shost)` while holding `tgt->lock` when `++tgt->blocked == 1`, whereas `sbp2_conditionally_unblock()` and `sbp2_unblock()` must call `scsi_unblock_requests(shost)` after releasing `tgt->lock`. [F199]
- Before `fw_send_request()`, `sbp2_send_orb()` must set `orb->lu`, append `orb->link` to `lu->orb_list` under `lu->tgt->lock`, and take two `kref_get(&orb->kref)` references (for `complete_transaction()` and the status/cancellation path) besides the caller's initial reference; `sbp2_status_write()` and `complete_transaction()` must hold `lu->tgt->lock` while checking/updating `orb->rcode` and unlinking `orb->link`, and release `lu->tgt->lock` before calling `orb->callback` (`complete_command_orb()` acquires `lu->tgt->lock`). [F207, F208]
- `sbp2_cancel_orbs()` must splice `lu->orb_list` into a local list under `lu->tgt->lock` and iterate it with `list_for_each_entry_safe`, because `fw_cancel_transaction()` synchronously invokes `complete_transaction()` (running `list_del(&orb->link)` and `kref_put`) and the fallback branch also drops `orb->kref` via `free_orb()`. [F262]
- `sbp2_login()` and `sbp2_reconnect()` must write `tgt->node_id` and `tgt->address_high` and issue `smp_wmb()` before storing `lu->generation`, pairing with `smp_rmb()` in `sbp2_scsi_queuecommand()` after reading `device->generation` and before reading `lu->tgt->address_high` (in `sbp2_map_scatterlist()`) and `lu->tgt->node_id`. [F214]
- In `sbp2_login()`, after `__scsi_add_device()` returns a valid `sdev`, the worker must execute `smp_rmb()` and verify `generation == device->card->generation` before setting `lu->has_sdev = true` and calling `sbp2_allow_block(tgt)`; if a bus reset intervened, it must remove `sdev`, log out, and reset `lu->workfn = sbp2_login`. [F215]

## Object Lifetimes

- The ORB callback reference on `orb->kref` belongs to `orb`'s membership in `lu->orb_list`: only the path that unlinks `orb` (`sbp2_status_write()` setting `RCODE_COMPLETE`, `complete_transaction()` when `orb->rcode != RCODE_COMPLETE`, or `sbp2_cancel_orbs()` only when `fw_cancel_transaction()` returns non-zero/`-ENOENT` because `0` synchronously ran `complete_transaction()`) may invoke `orb->callback` and drop that `kref` via `free_orb`. [F193, F221]
- In `sbp2_send_management_orb()`, after `wait_for_completion_timeout(&orb->done, ...)` returns, `sbp2_cancel_orbs(lu)` must be called before unmapping `orb->base.request_bus` and `orb->response_bus` and dropping `orb->base.kref` so no pending transaction or late `sbp2_status_write()` accesses unmapped DMA or freed memory. [F209]
- `sbp2_map_scatterlist()` only maps `orb->page_table_bus` and sets `COMMAND_ORB_PAGE_TABLE_PRESENT` in `orb->request.misc` when `scsi_dma_map(orb->cmd)` returns `n > 1`; `sbp2_unmap_scatterlist()` must check `COMMAND_ORB_PAGE_TABLE_PRESENT` before calling `dma_unmap_single()` on `orb->page_table_bus`. [F196]
- Both `__scsi_add_device()` in `sbp2_login()` and `scsi_device_lookup()` in `sbp2_remove()` return a `struct scsi_device` with an extra reference that must be released via `scsi_device_put(sdev)` on both normal and `scsi_remove_device(sdev)` rollback/teardown paths (when `!IS_ERR_OR_NULL(sdev)`). [F197]
- In `sbp2_probe()`, error paths before `scsi_add_host_with_dma()` succeeds must jump to `fail_shost_put` (`scsi_host_put(shost)`), whereas error paths after it succeeds must jump to `fail_remove` (`sbp2_remove(unit)`), where `sbp2_remove()` must call `sbp2_unblock(tgt)` first, then per `lu` run `cancel_delayed_work_sync(&lu->work)`, `scsi_remove_device()`/`scsi_device_put()`, `SBP2_LOGOUT_REQUEST` (if `lu->login_id != INVALID_LOGIN_ID`), `fw_core_remove_address_handler(&lu->address_handler)`, and `kfree(lu)`, before `scsi_remove_host()` and `scsi_host_put()`. [F200, F201]
- `fw_unit.directory` must not be accessed after `device_del(&fw_unit.device)`, and `fw_device.config_rom` and `fw_device.config_rom_length` may only be accessed either during the lifetime of an `fw_unit` before `device_del()` on the last `fw_unit` of the `fw_device` or while holding `fw_device_rwsem`. [F218]

## API Contracts

- Callers of `fw_send_request()` and `fw_send_request_with_tstamp()` must allow their `fw_transaction_callback_t` / `fw_transaction_callback_with_tstamp_t` callback to run synchronously in the caller's context and must not retain the `data` pointer after the callback returns. Broken by: holding a non-recursive lock across `fw_send_request()` that the callback also acquires. [F217]
- Every `sbp2_orb.callback` (`complete_management_orb()`, `complete_command_orb()`) must accept a nullable `struct sbp2_status *status` (non-NULL only from `sbp2_status_write()`), and any non-NULL `void *response` buffer passed to `sbp2_send_management_orb()` must be at least `sizeof(orb->response)` (16 bytes) because `sbp2_send_management_orb()` copies 16 bytes unconditionally. [F223, F280]
- Both `sbp2_probe()` and `sbp2_update()` must call `fw_device_enable_phys_dma()` on the parent `fw_device` so physical DMA from the remote SBP-2 target node is enabled on initial attach and re-enabled after every IEEE 1394 bus reset. [F297]
- `sbp2_scsi_sdev_init()` must reject any `struct scsi_device` with `!sdev->hostdata` by returning `-ENOSYS`, and in `sbp2_scsi_sdev_configure()`, `lim->max_hw_sectors` is in 512-byte sectors (`128 * 1024 / 512` for `SBP2_WORKAROUND_128K_MAX_TRANS`), whereas `scsi_driver_template.max_segment_size` (`SBP2_MAX_SEG_SIZE`) is in bytes (`0xfffc`). [F317, F318]
- In `include/linux/firewire.h` and `include/uapi/linux/firewire-cdev.h`, `fw_device.config_rom_length`, `fw_descriptor.length`, and `fw_cdev_add_descriptor.length` express 32-bit quadlet (`u32`) counts, whereas `fw_cdev_get_info.rom_length`, `fw_packet.payload_length`, and `fw_address_handler.length` express byte counts. [F285]
- In `drivers/firewire/phy-packet-definitions.h`, all `phy_packet_*_set_*()` and `self_id_sequence_set_port_status()` helpers perform read-modify-write bitfield updates requiring callers building a packet from scratch to zero-initialize target quadlets first, and `self_id_sequence_enumerator_next()` must return `ERR_PTR(-ENODATA)` if `cursor == NULL` or `quadlet_count == 0`, return `ERR_PTR(-EPROTO)` if a `more_packets` continuation hits `count >= enumerator->quadlet_count`, `count >= SELF_ID_SEQUENCE_MAXIMUM_QUADLET_COUNT`, `!extended`, or non-contiguous `sequence`, and validate all packets with local `cursor`/`count` before updating `enumerator->cursor` and `enumerator->quadlet_count` in lockstep. [F233, F245, F252]

## Error Handling

- `sbp2_cancel_orbs()` returns `0` when at least one pending ORB was still on `lu->orb_list` and had to be canceled, and `-ENOENT` when `lu->orb_list` was already empty because all ORBs completed. Broken by: treating `sbp2_cancel_orbs(lu) == 0` as normal ORB completion or `< 0` as a timeout error. [F220]
- `sbp2_add_logical_unit()` must initialize `lu->login_id = INVALID_LOGIN_ID` (`0x10000`) on the `kmalloc()`-allocated `struct sbp2_logical_unit` so `sbp2_remove()` only sends `SBP2_LOGOUT_REQUEST` if a 16-bit login ID was assigned, and in `sbp2_probe()`, `model` and `firmware_revision` must be initialized to `SBP2_ROM_VALUE_MISSING` and `tgt->directory_id` to the implicit directory offset before `sbp2_scan_unit_dir()`. [F226, F227]
- Because `sbp2_login()` sets `lu->workfn = sbp2_reconnect` before calling `__scsi_add_device()`, the `out_logout_login` error path (and any new error/retry path while `lu->has_sdev` is false) must reset `lu->workfn = sbp2_login` in addition to sending `SBP2_LOGOUT_REQUEST`. [F237]

## External Contracts

- In `include/uapi/linux/firewire-cdev.h`, `fw_cdev_event_request3` and `fw_cdev_event_response2` must retain explicit `__u32 padding` before `data[]` so their `sizeof` (56 and 32) matches across i386 and 64-bit ABIs, `fw_cdev_event_response` must keep `data` at offset 20 (`sizeof` 20 on `CONFIG_X86_32`, 24 elsewhere), and userspace clients receiving `fw_cdev_event_request{,2,3}` must issue `FW_CDEV_IOC_SEND_RESPONSE` with `handle` even for broadcast or FCP register writes. [F254, F326]
- `sbp2_sysfs_ieee1394_id_show()` must format the `/sys/bus/scsi/devices/.../ieee1394_id` attribute as `"%016llx:%06x:%04x\n"` (zero-padded 64-bit hex `guid`, 24-bit `directory_id`, and 16-bit `lun` separated by colons without `0x` prefixes). [F256]
- In `sbp2_map_scatterlist()`, `orb->request.data_descriptor.high` must be set to `cpu_to_be32(lu->tgt->address_high)` in both modes; when `n == 1`, it must encode a direct block descriptor without `COMMAND_ORB_PAGE_TABLE_PRESENT` and pass byte length `sg_dma_len(sg)` to `COMMAND_ORB_DATA_SIZE`, whereas when `n > 1`, `COMMAND_ORB_DATA_SIZE` takes the segment count `n` (with `COMMAND_ORB_PAGE_TABLE_PRESENT`) while DMA-mapping `sizeof(orb->page_table)` bytes to match `sbp2_unmap_scatterlist()`. [F281, F298]

## Known Pitfalls

- Because `RCODE_COMPLETE` is `0`, `sbp2_scsi_queuecommand()` must explicitly set `orb->base.rcode = -1` on a zero-allocated `struct sbp2_command_orb` before `sbp2_send_orb()` so `complete_transaction()` does not mistake an uninitialized `0` for a completed status write. [F222]
- Management ORB callers (`sbp2_login()`, `sbp2_reconnect()`, `sbp2_remove()`) must read `device->node_id` after `device->generation` and `smp_rmb()` rather than passing `tgt->node_id` to `sbp2_send_management_orb()` (`tgt->node_id` is only updated after login/reconnect succeeds), and `sbp2_login()` must mask `be32_to_cpu(response.command_block_agent.high)` with `0xffff` and cast to `u64` before `<< 32` when building `lu->command_block_agent_address`. [F266, F270]
- In `sbp2_workarounds_table`, entries with a specific `.model` must precede any entry sharing the same `.firmware_revision` that uses `.model = SBP2_ROM_VALUE_WILDCARD`, and `.firmware_revision` must have its low 8 bits zeroed, because `sbp2_init_workarounds()` masks `firmware_revision` with `0xffffff00` and breaks on the first match. [F260]
- In `tools/firewire/`, `list_for_each_entry` in `list.h` advances via `list_next(pos, member)` without a safe-next pointer so loops that unlink and free elements (`link_transaction_destroy()`, `clear_pending_transaction_list()`) must use `while (!list_empty(...))` with `list_head` and `list_remove`, and in `decode_link_packet()` (`nosy-dump.c`), when a field spans a 32-bit quadlet boundary, the `unsigned int` result of `get_bits(packet, offset, high_width)` must be stored in `unsigned long long bits` before `<< low_width`. [F268, F272]
