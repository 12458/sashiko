# SOUND - SOC LAYER / DYNAMIC AUDIO POWER MANAGEMENT (ASoC) — sound/soc (part 6)

Implements ALSA SoC audio drivers for Allwinner sunxi (`sun4i`/`sun6i`/`sun7i`/`sun8i`/`sun50i` codecs, I2S, SPDIF) and NVIDIA Tegra (`Tegra20` AC'97/DAS/I2S/SPDIF, `Tegra186` ASRC/DSPK, `Tegra210`/`Tegra264` ADMAIF/ADX), managing audio FIFOs, DMAengine integration, analog `ADDA_PR` regmap buses, headset jack detection, and AHUB client interfaces (CIF).

## Architecture & Data Flow

- In `tegra186_dspk_hw_params()`, `tegra_admaif_hw_params()`, and `tegra210_adx_set_audio_cif()`, `cif_conf.client_bits` must match `cif_conf.audio_bits` in every `params_format()` branch (`TEGRA_ACIF_BITS_16` for `S16_LE`), and 32-channel Tegra264 variants (`max_stream_ch == TEGRA264_ADMAIF_MAX_CHANNEL` or `adx->soc_data->max_ch == 32`) must call `tegra264_set_cif()` instead of `tegra_set_cif()`. [F181, F239]
- In `tegra_admaif_hw_params()`, `tegra_admaif_set_pack_mode()` must both set the active pack bit (`PACK8_EN` or `PACK16_EN`) and clear the other pack bit in `TEGRA_ADMAIF_CH_ACIF_TX_CTRL`/`RX_CTRL` (or clear both for `DATA_32BIT`) in lockstep with `valid_bit`. [F182]
- Because `TEGRA210_ADX_CFG_RAM_CTRL` and `TEGRA210_ADX_CFG_RAM_DATA` (and Tegra264 counterparts) are volatile in `tegra210_adx_volatile_reg()`/`tegra264_adx_volatile_reg()`, `tegra210_adx_runtime_resume()` must call `tegra210_adx_write_map_ram()` after `regcache_sync()` to program `adx->map` and `adx->byte_mask`. [F176]
- In `tegra210_adx.c`, `tegra210_adx_out_hw_params()` computes the TX CIF control register as `TEGRA210_ADX_TX1_CIF_CTRL + ((dai->id - 1) * TEGRA210_ADX_AUDIOCIF_CH_STRIDE)`, relying on `IN_DAI` at index 0 of `tegra210_adx_dais` so `OUT_DAI(1..4)` have `dai->id` 1..4; both `IN_DAI` and `OUT_DAI` must advertise `SNDRV_PCM_FMTBIT_S8`, `S16_LE`, `S24_LE`, and `S32_LE` in `playback.formats` and `capture.formats` without duplication. [F195, F201]
- In `tegra186_asrc_runtime_resume()`, `TEGRA186_ASRC_GLOBAL_SCRATCH_ADDR` and `TEGRA186_ASRC_GLOBAL_ENB` must be written before `regcache_sync()`, and volatile `TEGRA186_ASRC_RATIO_INT_PART`/`FRAC_PART` restored from `asrc->lane[]` afterward; whenever either ratio register is written for a `TEGRA186_ASRC_RATIO_SOURCE_SW` lane (in resume, `tegra186_asrc_out_hw_params()`, or `tegra186_asrc_put_ratio_int()`/`frac()`), `tegra186_asrc_lock_stream()` must follow. [F177, F178]
- In `tegra186_asrc.c`, `tegra186_asrc_out_hw_params()` indexes `asrc->lane[]` (`TEGRA186_ASRC_STREAM_MAX` = 6) via `id = dai->id - 7`, requiring the 6 `OUT_DAI` entries in `tegra186_asrc_dais` to immediately follow the 7 `IN_DAI` entries; in `tegra186_asrc_wr_reg()`, `rd_reg()`, and `volatile_reg()`, `reg %= TEGRA186_ASRC_STREAM_STRIDE` applies only when `reg < TEGRA186_ASRC_STREAM_LIMIT` (`0x2f0`) so global registers at `0x2f4+` do not alias. [F189, F210]
- In `tegra186_asrc.c`, `kcontrol->private_value` holds `struct soc_mreg_control *` (offset in `.regbase`) for `SOC_SINGLE_EXT_FRAC`, `struct soc_enum *` for `SOC_ENUM_EXT`, and `struct soc_mixer_control *` for `SOC_SINGLE_EXT`; each `get`/`put` callback must cast `private_value` to its matching struct. [F226]
- In `tegra186_dspk_hw_params()`, although `tegrat186_dspk_controls` ("FIFO Threshold") allows `dspk->rx_fifo_th` up to `TEGRA186_DSPK_RX_FIFO_DEPTH - 1`, `cif_conf.threshold` must clamp `dspk->rx_fifo_th` to `(TEGRA186_DSPK_RX_FIFO_DEPTH / cif_conf.audio_ch) - 1` because hardware threshold is in frames. [F196]
- In `tegra20_i2s_runtime_resume()` and `tegra20_spdif_runtime_resume()`, reset must be asserted, the module clock enabled followed by `usleep_range(10, 100)`, and reset deasserted before leaving cache-only mode and calling `regcache_sync()`; in `tegra20_i2s_filter_rates()` and `tegra20_spdif_filter_rates()`, if `valid_rates == 0`, set `valid_rates = BIT(ARRAY_SIZE(...)) - 1` before `snd_interval_list()`. [F220, F231]
- In `tegra20_ac97.c`, `tegra20_i2s.c`, and `tegra20_spdif.c`, all data FIFO registers (`TEGRA20_AC97_FIFO_TX1`/`RX1`, `TEGRA20_I2S_FIFO1`/`FIFO2`, `TEGRA20_SPDIF_DATA_OUT`/`DATA_IN`/`USR_STA_RX_A`/`USR_DAT_TX_A`) must be both `volatile_reg` and `precious_reg`; in `tegra20_spdif.c`, `TEGRA20_SPDIF_DATA_FIFO_CSR` TX attention level must be `>= spdif->playback_dma_data.maxburst`; in `tegra20_ac97.c`, reset/codec polling loops must use `time_after(jiffies, timeout)`. [F197, F221, F246]
- In `sun4i-i2s.c`, `sun4i_i2s_set_fmt()` must cache `i2s->format = fmt` after `variant->set_fmt()` succeeds because `sun8i_i2s_set_chan_cfg()` and `sun50i_h6_i2s_set_chan_cfg()` inspect `i2s->format` to set `lrck_period = slot_width` for `I2S`/`LEFT_J`/`RIGHT_J` vs `slot_width * slots` for `DSP_A`/`DSP_B`; in `sun8i_i2s_set_soc_fmt()` and `sun50i_h6_i2s_set_soc_fmt()`, `lrclk_pol` must start at `START_LOW` for `I2S` and `START_HIGH` for `DSP`/`LEFT_J`/`RIGHT_J` before XORing `LRCLK_POLARITY_MASK` on `IB_IF`/`NB_IF`. [F188, F200, F235]
- In `sun4i-i2s.c`, `sun4i_i2s_quirks::pcm_formats` must be a `u64` passed to `snd_pcm_hw_constraint_mask64()` in `sun4i_i2s_dai_startup()`; in `sun4i_i2s_set_clk_rate()`, `rate` must pass the `switch` and `oversample_rate = i2s->mclk_freq / rate` must pass `sun4i_i2s_oversample_is_valid()` before `sun4i_i2s_get_bclk_div()` and `sun4i_i2s_get_mclk_div()` divide by `rate` and `i2s->mclk_freq`. [F214, F219]
- In `sun8i_codec_hw_params()` and `sun8i_codec_hw_free()`, `clk_set_rate_exclusive()` and `scodec->sysclk_refcnt++` run only when `aif->open_streams == 0`, while `clk_rate_exclusive_put()`, `scodec->sysclk_refcnt--`, and zeroing `aif->lrck_div_order` and `aif->sample_rate` run only when `aif->open_streams == BIT(substream->stream)`; `sun8i_codec_update_sample_rate()` must be called whenever `aif->sample_rate` or `aif->active_streams` (in `sun8i_codec_aif_event()`) changes. [F184, F185]
- In `sun8i-codec.c`, `SUN8I_CODEC_AIF3` shares `AIF2` clocking: `sun8i_codec_set_fmt()` must reject slave mode (`value != 0`) and non-DSP formats (`format != 3`) on `AIF3` with `-EINVAL` and never write `MSTR_MOD`/`DATA_FMT_MASK` to `SUN8I_AIF_CLK_CTRL(AIF3)`, while `sun8i_codec_hw_params()` for `AIF2`/`AIF3` must verify any open partner stream (`(AIF2 + AIF3) - dai->id`) has matching `lrck_div_order` and `sample_rate` before writing dividers to `SUN8I_AIF_CLK_CTRL(AIF2)`. [F206, F237]
- In `sun8i_codec_set_fmt()`, `scodec->quirks->lrck_inversion` must only be XORed into `invert` when `format != 0x3`; in DSP mode (`format == 0x3`), `invert` bit 0 selects `DSP_A`/`DSP_B` (`dsp_format`) and caller LRCK inversion (`invert & BIT(0)`) must return `-EINVAL`. [F238]
- In `sun8i_codec_jack_irq()`, `SUN8I_HMIC_STS` IRQ bits are W1C (requiring `SUN8I_HMIC_STS` in `sun8i_codec_volatile_reg()`), `JACK_OUT_IRQ_ST` must be checked before `JACK_IN_IRQ_ST`, and `HMIC_DATA_IRQ_ST` must return early unless `scodec->jack_status == SUN8I_JACK_STATUS_CONNECTED` and only call `snd_soc_jack_report()` when `scodec->jack_last_sample >= 0` equals the current sample; in `sun8i_codec_jack_work()`, `ktime_ms_delta(scodec->jack_hbias_ready, ktime_get())` must be guarded by `!ktime_after(ktime_get(), scodec->jack_hbias_ready)` and add 10 ms before `msecs_to_jiffies()`. [F203, F222, F243]
- Because `sun50i_a64_codec_set_bias_level()` clears `SUN50I_ADDA_JACK_MIC_CTRL_MICADCEN` on `SND_SOC_BIAS_OFF`, entering `SND_SOC_BIAS_STANDBY` must query `snd_soc_dapm_get_pin_status(dapm, "HBIAS")` and restore `MICADCEN` alongside `JACKDETEN`; in `sun4i_spdif_hw_params()`, both `mclk` and `mclk_div` must be scaled by `host->quirks->mclk_multiplier`. [F187, F234]

## Synchronization

- In `sun8i-codec.c`, `sun8i_codec_enable_jack_detect()` must set `scodec->jack` and initialize `SUN8I_HMIC_CTRL1`/`CTRL2`/`STS` before `devm_request_threaded_irq()` registers `sun8i_codec_jack_irq()`; both `sun8i_codec_jack_irq()` and `sun8i_codec_jack_work()` must hold `scodec->jack_mutex` while accessing `last_hmic_irq`, `jack_status`, `jack_last_sample`, `jack_hbias_ready`, and `SUN8I_HMIC_STS`. [F156, F252]
- In `sun4i-spdif.c`, `sun4i_spdif_get_status()` and `sun4i_spdif_set_status()` must hold `host->lock` via `spin_lock_irqsave()` across multi-register IEC958 updates (`SUN4I_SPDIF_TXCHSTA0`, `TXCHSTA1`, `TXCFG`). [F158]
- In `sun8i-adda-pr-regmap.c`, `adda_reg_read()` and `adda_reg_write()` multiplex 5-bit analog registers through the single `ADDA_PR` MMIO register (deasserting `ADDA_PR_RESET`, setting `ADDA_PR_ADDR_SHIFT`, strobing `ADDA_PR_WRITE`), so `adda_pr_regmap_cfg` must keep `.fast_io = true` without `.disable_locking`; `sun8i_adda_pr_regmap_init()` passes raw `void __iomem *base` as the regmap context. [F227, F242]
- `tegra_admaif_stop()` (atomic trigger context) must poll channel disable and soft-reset with `regmap_read_poll_timeout_atomic()` (keeping `RX_STATUS`/`TX_STATUS` and `RX_SOFT_RESET`/`TX_SOFT_RESET` in `tegra_admaif_volatile_reg()`), whereas process-context `tegra210_adx_startup()` must use sleeping `regmap_read_poll_timeout()` on `TEGRA210_ADX_STATUS` and `TEGRA210_ADX_SOFT_RESET`. [F244, F250]

## Object Lifetimes

- In `sun4i_i2s_runtime_resume()` and `sun4i_i2s_runtime_suspend()`, `i2s->bus_clk` must be enabled before leaving cache-only mode, syncing regcache, or accessing `SUN4I_I2S_CTRL_REG` (and disabled on resume error), and in suspend `i2s->mod_clk` and `SUN4I_I2S_CTRL_REG` must be disabled and regcache set cache-only before disabling `i2s->bus_clk`. [F148]
- In `sun4i_i2s_probe()`, `sun4i_spdif_probe()`, and `sun8i_codec_probe()`, when `!pm_runtime_enabled(&pdev->dev)` triggers manual `runtime_resume` during probe, error paths and `.remove` (`sun4i_i2s_remove()`, `sun8i_codec_remove()`) must check `!pm_runtime_status_suspended(&pdev->dev)` and invoke `runtime_suspend`. [F149]
- In `tegra_admaif_probe()`, `admaif->soc_data` and `dev_set_drvdata(&pdev->dev, admaif)` must precede `devm_regmap_init_mmio()` and `tegra_isomgr_adma_register()`; `tegra_isomgr_adma_setbw(..., true/false)` in `tegra_admaif_prepare()`/`shutdown()` must stay paired with `tegra_isomgr_adma_register()` in probe and `tegra_isomgr_adma_unregister(&pdev->dev)` in `tegra_admaif_remove()`. [F150, F267]
- `tegra20_ac97_platform_probe()` and `tegra20_i2s_platform_probe()` call non-devm `snd_soc_register_component()` before `tegra_pcm_platform_register()`, so error paths and `.remove` (`tegra20_ac97_platform_remove()`, `tegra20_i2s_platform_remove()`) must call `tegra_pcm_platform_unregister()` before `snd_soc_unregister_component()`. [F152]
- In `sun8i_codec_disable_jack_detect()`, `devm_free_irq(component->dev, scodec->jack_irq, scodec)` must precede `cancel_delayed_work_sync(&scodec->jack_work)`, and both must finish before clearing `SUN8I_HMIC_CTRL1` IRQ bits and setting `scodec->jack = NULL`. [F154]

## API Contracts

- Custom `snd_kcontrol` `put` callbacks (`tegra186_dspk_put_*`, `tegra186_asrc_put_*`, `tegra210_admaif_*put_*`, `tegra210_adx_put_byte_map()`, `sun4i_spdif_set_status()`) must return `1` when state/registers change, `0` when unchanged, or negative errno on error. [F161]
- In `tegra210_admaif.c`, `CH_REG`, `CH_TX_REG`, `CH_RX_REG`, `NV_SOC_ENUM_EXT`, `admaif->mono_to_stereo[path]`, and `admaif->stereo_to_mono[path]` (indexed via `ec->reg` in `tegra210_admaif_pget_mono_to_stereo()`, `tegra210_admaif_pput_stereo_to_mono()`, etc.) take 0-based channel indices (`0..num_ch - 1`), whereas `ADMAIF_REG_DEFAULTS(id, chip)` and `TEGRA_ADMAIF_CIF_CTRL(reg)` take 1-based channel numbers (`1..num_ch`). [F167, F191]
- In `tegra20_das.c`, `tegra20_das_connect_dap_to_dac(das, dap, dac)` takes `(TEGRA20_DAS_DAP_ID_*, TEGRA20_DAS_DAP_SEL_*)` (`DAP_SEL_DAP*` = `16..20`), whereas `tegra20_das_connect_dac_to_dap(das, dac, dap)` takes `(TEGRA20_DAS_DAC_ID_*, TEGRA20_DAS_DAC_SEL_DAP*)`. [F169]
- DMAEngine DAI FIFO addresses (`snd_dmaengine_dai_dma_data.addr`) across `sun4i-*`, `tegra20_*`, and `tegra210_admaif` must use the physical `struct resource` start (`res->start`/`mem->start`) plus register offset, never the ioremapped `void __iomem *`; because ADMAIF `snd_soc_component_driver` structs omit `.trigger`, `tegra_admaif_trigger()` must call `snd_dmaengine_pcm_trigger(substream, cmd)` before starting/stopping hardware. [F254, F266]
- In `sun4i-codec.c`, `sun4i_codec_create_link()` returns `NULL` on failure, whereas every `sun4i_codec_quirks.create_card` callback must set `card->owner = THIS_MODULE` and return an `ERR_PTR` on failure because `sun4i_codec_probe()` checks `IS_ERR(card)`. [F170, F261]

## Error Handling

- In `sun4i-codec.c`, `sun4i_codec_get_mod_freq()` returns `0` on error whereas `sun4i_codec_get_hw_rate()` returns `0` as a valid rate code (48000/44100 Hz) and `-EINVAL` on error; in `sun4i-i2s.c` and `sun8i-codec.c`, divider/resolution helpers (`sun4i_i2s_get_bclk_div()`, `sun4i_i2s_get_mclk_div()`, `get_sr`/`sun4i_i2s_get_sr()`, `get_wss`/`sun4i_i2s_get_wss()`, `sun8i_i2s_get_sr_wss()`, `sun8i_codec_get_hw_rate()`, `sun8i_codec_get_lrck_div_order()`, `sun8i_codec_get_bclk_div()`) map values via `switch`/table lookups and return `>= 0` or `-EINVAL`, requiring signed `int` variables and `< 0` checks. [F171, F172, F236]

## External Contracts

- In `tegra_admaif_probe()`, Device Tree `"dma-names"` has capture (RX) at even index `i * 2` (`capture_dma_data[i].chan_name`) and playback (TX) at odd index `(i * 2) + 1` (`playback_dma_data[i].chan_name`) for each 0-based channel `i`. [F168]

## Known Pitfalls

- In `tegra186_dspk.c`, `dspk->ch_sel` stores the 0-based `enum tegra_dspk_ch_sel` (`LEFT` = 0, `RIGHT` = 1, `STEREO` = 2), so `tegra186_dspk_hw_params()` must write `(dspk->ch_sel + 1) << CH_SEL_SHIFT` to `TEGRA186_DSPK_CORE_CTRL`; in `tegra186_asrc.c`, `asrc->lane[id].input_thresh`/`output_thresh` pack upper watermark bits (`0x00201002`), so `tegra186_asrc_put_input_threshold()`/`output_threshold()` must preserve `~(0x3)`. [F164, F180]
- In `sun4i-codec.c`, `sun50i-codec-analog.c`, `sun8i-codec-analog.c`, and `sun8i-codec.c`, single-bit field macros (`SUN4I_CODEC_DAC_FIFOC_*`, `SUN50I_ADDA_*`, `SUN8I_ADDA_*`, `SUN8I_HMIC_CTRL1_*`) define unshifted bit indices and must be shifted or wrapped in `BIT()` for `regmap_*` and `snd_soc_component_update_bits()`. [F174]
- In `sun8i-codec.c`, `sun8i_codec_aif_event()` indexes `scodec->aifs[]` (`SUN8I_CODEC_NAIFS` = 3) via `w->sname[3] - '1'`, requiring widget `.sname` to have `'1'..'3'` at `sname[3]`; `sun8i_codec_get_lrck_div_order()` must use `order_base_2(div)` (ceiling log2) rather than `ilog2(div)`. [F198, F218]
- In `sun4i-spdif.c`, `sun4i_spdif_controls` are added to the DAI via `snd_soc_add_dai_controls()`, so `sun4i_spdif_get_status()`/`set_status()` must use `snd_kcontrol_chip(kcontrol)` (not `snd_soc_kcontrol_component()`), and `sun4i_spdif_set_status()` must cast `u8` `status[]` bytes to `u32` before shifting (`(u32)status[3] << 24`). [F215, F263]
- In `tegra210_admaif.c`, `tegra*_admaif_regmap_config.num_reg_defaults` is `TEGRA*_ADMAIF_CHANNEL_COUNT * 6 + 1` (1 global + 6 per `ADMAIF_REG_DEFAULTS()` / `REG_DEFAULTS()`); changing `tegra*_admaif_reg_defaults[]` requires updating `.num_reg_defaults`. [F225]
