# NETFILTER — (top level)

Provides the core Netfilter hook registration and packet traversal infrastructure (`net/netfilter/core.c`), IPv4 and IPv6 rerouting and bridge fragmentation helpers (`net/ipv4/netfilter.c`, `net/ipv6/netfilter.c`), RCU-protected cross-module hook pointers (`nf_ct_hook`, `nf_nat_hook`, `nf_ipv6_ops`, `nf_defrag_v4_hook`, `nf_defrag_v6_hook`), and the UAPI headers (`include/uapi/linux/netfilter*`) for netfilter, nf_tables, x_tables, ipset, conntrack, and nfnetlink.

## Architecture & Data Flow

- `allocate_hook_entries_size` must allocate `struct nf_hook_entries` via `kvzalloc` with `GFP_KERNEL_ACCOUNT` (for memcg accounting), sizing for the header, `num` `struct nf_hook_entry` elements, `num` `struct nf_hook_ops *` pointers, and a trailing `struct nf_hook_entries_rcu_head`, and set `e->num_hook_entries = num` so `nf_hook_entries_free` locates the RCU head at `&ops[num]`. [F343, F387]
- In `struct nf_hook_entries`, the `hooks` array and trailing `orig_ops` array (`nf_hook_entries_get_hook_ops()`) must stay index-aligned in `nf_hook_entries_grow()` and `__nf_hook_entries_try_shrink()`. In `nf_hook_entries_grow()`, the merge loop must skip `orig_ops[i] == &dummy_ops` (`priority == INT_MIN`) by advancing only `i` (`++i; continue;`), and when inserting `reg` before `orig_ops[i]` it must set `inserted = true` and increment `nhooks` without incrementing `i`. [F334, F354]
- `nf_hook_entries_grow()` must count only live entries (`orig_ops[i] != &dummy_ops`) plus one for the new hook and reject with `-E2BIG` when `alloc_entries > MAX_HOOK_COUNT` (1024) before calling `allocate_hook_entries_size` (which truncates `num` to `u16`). [F344]
- Hooks with `reg->pf == NFPROTO_INET` and `reg->hooknum == NF_INET_INGRESS` share `dev->nf_hooks_ingress` and `nf_hooks_needed[NFPROTO_NETDEV][NF_NETDEV_INGRESS]` with `NFPROTO_NETDEV` ingress hooks across `nf_hook_entry_head()`, `nf_ingress_hook()`, `nf_static_key_inc()`, and `nf_static_key_dec()`. [F337]
- For `reg->pf == NFPROTO_INET` with `reg->hooknum != NF_INET_INGRESS`, `nf_register_net_hook()` and `nf_unregister_net_hook()` must update both `NFPROTO_IPV4` and `NFPROTO_IPV6` hook tables, and `nf_register_net_hook()` must unregister `NFPROTO_IPV4` if `__nf_register_net_hook(net, NFPROTO_IPV6, reg)` fails. [F338]
- In `nf_hook_slow`, the `switch` on a hook's return value must mask with `NF_VERDICT_MASK` (`verdict & NF_VERDICT_MASK`), while passing the unmasked `verdict` to `NF_DROP_GETERR(verdict)` and `nf_queue(skb, state, s, verdict)` to preserve upper bits carrying errno (`NF_VERDICT_QMASK`) or `NF_VERDICT_FLAG_QUEUE_BYPASS`. [F352]
- In `ip_route_me_harder()` and `ip6_route_me_harder()`, `sk` must be converted via `sk_to_full_sk(sk)` before accessing full-socket fields (`inet_sk_flowi_flags(sk)`, `sk->sk_bound_dev_if`, `sock_net_uid()`), and `flowi4_l3mdev` / `flowi6_l3mdev` must be populated from `l3mdev_master_ifindex(skb_dst_dev(skb))` before route lookup. [F382]
- In `__nf_ip6_route`, the synthetic `fake_sk` passed to `ip6_route_output` when `strict` is true must be a `struct inet_sock` with `.pinet6` initialized to a valid `struct ipv6_pinfo` (`&fake_pinfo`), not a bare `struct sock` or `inet_sock` with NULL `.pinet6`. [F369]
- In `br_ip6_fragment()`, `skb_checksum_help(skb)` must be called when `skb->ip_summed == CHECKSUM_PARTIAL` before fragmenting, and the fastpath `skb_has_frag_list(skb)` walk must fall back to `slow_path` (`ip6_frag_init`/`ip6_frag_next`) if `skb_cloned(skb)`, any fragment has `skb_shared(frag2)`, or headroom is insufficient. [F384]

## Synchronization

- In `nf_remove_net_hook()`, the removed slot's `old->hooks[i].hook` and `orig_ops[i]` must be overwritten in-place with `accept_all` and `&dummy_ops` using `WRITE_ONCE` while leaving `old->hooks[i].priv` intact, and if `allocate_hook_entries_size()` fails in `__nf_hook_entries_try_shrink()`, it must return `NULL` while leaving `old` installed in `*pp` without freeing `old`, because concurrent RCU readers and unshrunk arrays continue reading `old`. [F318, F330]
- `__nf_register_net_hook` and `__nf_unregister_net_hook` must hold `nf_hook_mutex` while dereferencing `*pp` via `nf_entry_dereference`, mutating or shrinking `struct nf_hook_entries`, and publishing the replacement pointer with `rcu_assign_pointer`, and must only be called from sleepable process context. [F373]
- `nf_hook_entries_insert_raw` and `nf_hook_entries_delete_raw` do not acquire `nf_hook_mutex` and perform `GFP_KERNEL_ACCOUNT` allocations via `allocate_hook_entries_size`, so callers must serialize concurrent accesses to the target `struct nf_hook_entries __rcu **` pointer with their own sleepable lock in process context. [F374]

## Object Lifetimes

- `__nf_register_net_hook` increments `net_inc_ingress_queue()`, `net_inc_egress_queue()`, and `nf_static_key_inc(reg, pf)` only after `nf_hook_entries_grow` succeeds, and `__nf_unregister_net_hook` decrements them only when `nf_remove_net_hook(p, reg)` returns `true`. [F308]
- Any `struct nf_hook_entries` published via `rcu_assign_pointer` must be freed only via `nf_hook_entries_free` (after calling `nf_queue_nf_hook_drop(net)` outside `nf_hook_mutex` in `__nf_unregister_net_hook`). `nf_hook_entries_free` must store the base pointer `e` in `head->allocation` at `&ops[e->num_hook_entries]` before `call_rcu`, and `__nf_hook_entries_free` must `kvfree(head->allocation)` rather than using `container_of` on `struct rcu_head`. [F365, F376]
- In `ip_route_me_harder` and `ip6_route_me_harder`, before passing `dst` to `xfrm_lookup`, `skb`'s `dst` reference must be detached via `skb_dstref_steal(skb)` so `xfrm_lookup` owns the reference and `skb` does not double-release `dst` if `xfrm_lookup` fails. [F313]
- In `ip6_route_me_harder` and `__nf_ip6_route`, `ip6_route_output` always returns a non-NULL `dst_entry *` carrying a reference even when `dst->error != 0`, so when `dst->error != 0` callers must call `dst_release(dst)` before returning the error without attaching `dst` to `skb` or `*dst`. [F314]

## API Contracts

- Callers of `nf_hook_slow` and `nf_hook_slow_list` must hold `rcu_read_lock()` (not just `rcu_read_lock_bh()`) across the entire call so the `struct nf_hook_entries` blob `e` is not freed mid-traversal by `__nf_hook_entries_free` via `call_rcu`. [F320]
- In `nf_hook_entries_grow()`, a hook with `reg->hook_ops_type == NF_HOOK_OP_BPF` cannot share a priority (`reg->priority == orig_ops[i]->priority`) with any existing hook at attach time and fails with `-EBUSY`, whereas non-BPF hooks may attach at an existing BPF or non-BPF hook's priority. [F379]
- In `__nf_register_net_hook()` and `nf_hook_entry_head()`, hooks for `NFPROTO_NETDEV` (`NF_NETDEV_INGRESS` or `NF_NETDEV_EGRESS`) or `NFPROTO_INET` with `NF_INET_INGRESS` must specify a non-NULL `reg->dev` in the target netns (`dev_net(reg->dev) == net`), or fail with `-EINVAL`. [F380]
- After updating an skb's route or XFRM dst in `ip_route_me_harder` or `ip6_route_me_harder`, if `skb_headroom(skb) < hh_len` (`hh_len = skb_dst_dev(skb)->hard_header_len`), headroom must be expanded via `pskb_expand_head(skb, HH_DATA_ALIGN(hh_len - skb_headroom(skb)), 0, GFP_ATOMIC)`. [F347]
- `NF_DROP_ERR(x)` shifts `-x` left by 16 bits without parenthesizing `x`, and `nf_hook_slow` decodes it via `NF_DROP_GETERR(int verdict)` (`-(verdict >> 16)`), so callers must pass a negative errno in `[-0x7fff, -1]` as a single identifier or parenthesized expression. [F361]
- Callers of `SCTP_CHUNKMAP_RESET`, `SCTP_CHUNKMAP_SET_ALL`, `SCTP_CHUNKMAP_COPY`, `SCTP_CHUNKMAP_IS_CLEAR`, and `SCTP_CHUNKMAP_IS_ALL_SET` in `include/uapi/linux/netfilter/xt_sctp.h` must pass actual `__u32[64]` array objects (`sizeof(chunkmap)`), not decayed `__u32 *` pointers. [F366]

## Error Handling

- `nf_hook_entries_grow()` returns an `ERR_PTR` (`-EBUSY`, `-E2BIG`, or `-ENOMEM`) on failure rather than `NULL`, so callers (`nf_hook_entries_insert_raw()` and `__nf_register_net_hook()`) must check `IS_ERR(new_hooks)` before publishing `new_hooks` into `*pp` with `rcu_assign_pointer()`. [F329]
- `nf_register_net_hooks` registers `n` hooks sequentially and on failure at index `i > 0` must roll back only the registered prefix `reg[0 .. i-1]` via `nf_unregister_net_hooks(net, reg, i)`. [F310]
- `netfilter_init` initializes `register_pernet_subsys(&netfilter_net_ops)`, `netfilter_lwtunnel_init()`, and `netfilter_log_init()` in order, and on error must unwind previously succeeded steps in reverse order (`netfilter_lwtunnel_fini()` then `unregister_pernet_subsys(&netfilter_net_ops)`). [F311]
- Global RCU pointer `nf_ct_hook` in `net/netfilter/core.c` is NULL when `nf_conntrack` is not registered; `nf_ct_attach()`, `nf_conntrack_destroy()`, `nf_ct_set_closing()`, and `nf_ct_get_tuple_skb()` must check `rcu_dereference(nf_ct_hook)` for NULL under `rcu_read_lock()` before invoking callbacks. [F332]
- In `ip_route_me_harder()`, `ip_route_output_key()` returns an `ERR_PTR` on lookup failure, and even when it succeeds, `skb_dst(skb)->error` must be checked after `skb_dst_set(skb, &rt->dst)` before proceeding to XFRM lookup or headroom expansion. [F327]
- In `br_ip6_fragment()`, once `ip6_fraglist_init()` succeeds on the `skb_has_frag_list(skb)` path, `kfree(iter.tmp_hdr)` must be called after the output loop, and if `output()` returns a non-zero `err`, remaining fragments at `iter.frag` must be freed via `kfree_skb_list(iter.frag)` before returning `err`. [F333]

## External Contracts

- In `include/uapi/linux/netfilter/ipset/ip_set.h`, changing `ip_set_id_t` or `IPSET_INVALID_ID` requires updating `IPSET_ATTR_INDEX` in lockstep, and changing `IPSET_DIM_MAX` requires a new iptables set match/target revision. [F342]
- In `include/uapi/linux/netfilter/ipset/ip_set.h`, CADT attributes occupy `1..IPSET_ATTR_CADT_MAX` (16), while both create-only (`IPSET_ATTR_INITVAL`..`IPSET_ATTR_MEMSIZE`) and ADT-specific (`IPSET_ATTR_ETHER`..`IPSET_ATTR_PAD`) attributes start at `IPSET_ATTR_CADT_MAX + 1`; new CADT attributes must not be added past 16 without shifting or separating those spaces. [F350]
- In `include/uapi/linux/netfilter/nf_tables.h`, `enum nft_registers` is sparse: 16-byte registers `NFT_REG_VERDICT`..`NFT_REG_4` occupy `0..4` (`NFT_REG_MAX` = 4) and 4-byte registers `NFT_REG32_00`..`NFT_REG32_15` start at `8`, leaving `5..7` invalid. Broken by: treating `nft_registers` as dense `0..20` or bounding `NFT_REG32_*` with `NFT_REG_MAX`. [F349]
- In `include/uapi/linux/netfilter/nf_conntrack_common.h` and `nf_conntrack_tuple_common.h`, `enum ip_conntrack_info` values `< IP_CT_IS_REPLY` (3) denote original-direction states and values `>= IP_CT_IS_REPLY` denote reply-direction states at `orig_state + IP_CT_IS_REPLY`. [F351]
- In `include/uapi/linux/netfilter/nf_conntrack_common.h`, status bits in `IPS_UNCHANGEABLE_MASK` (`IPS_NAT_DONE_MASK`, `IPS_NAT_MASK`, `IPS_EXPECTED`, `IPS_CONFIRMED`, `IPS_DYING`, `IPS_SEQ_ADJUST`, `IPS_TEMPLATE`, `IPS_UNTRACKED`, `IPS_OFFLOAD`, `IPS_HW_OFFLOAD`) must never be directly modified by userspace, and any new internal-only status bit must be added to `IPS_UNCHANGEABLE_MASK`. [F386]
- In `include/uapi/linux/netfilter/xt_*.h` match/target structs (e.g., `struct idletimer_tg_info`, `struct xt_bpf_info`, `struct xt_cgroup_info_v1`), kernel-only pointer fields must be placed at the end of the struct and annotated with `__attribute__((aligned(8)))` to keep 32-bit userspace and 64-bit kernel `XT_ALIGN` layouts identical. [F378]

## Known Pitfalls

- In `nf_hook_slow_list`, packet iteration must use `list_for_each_entry_safe` and unlink each `skb` with `skb_list_del_init(skb)` before calling `nf_hook_slow(skb, state, e, 0)`, only re-queuing `skb` onto `sublist` when `nf_hook_slow` returns `1`. [F355]
- `SCTP_CHUNKMAP_SET`, `SCTP_CHUNKMAP_CLEAR`, and `SCTP_CHUNKMAP_IS_SET` in `include/uapi/linux/netfilter/xt_sctp.h` evaluate `type / bytes(__u32)` and `type % bytes(__u32)` without parenthesizing `type` (`bytes(__u32)` is `size_t` 32), so `type` must be a non-negative value `< 256` passed as a single token or parenthesized expression. [F362]
- `NF_CT_STATE_BIT(ctinfo)`, `XT_CONNTRACK_STATE_BIT(ctinfo)`, and `XT_STATE_BIT(ctinfo)` compute `(1 << ((ctinfo) % IP_CT_IS_REPLY + 1))`, which maps `IP_CT_UNTRACKED` (7) to `1 << 2` (aliasing `IP_CT_RELATED`), so callers must check `ct != NULL` (`ctinfo != IP_CT_UNTRACKED`) first and handle `IP_CT_UNTRACKED` separately. [F363]
- `xt_entry_foreach` and `xt_ematch_foreach` in `include/uapi/linux/netfilter/x_tables.h` must cast `ehead`, `entry`, and `pos` to `char *` before adding byte offsets `esize`, `next_offset`, `target_offset`, or `u.match_size`. [F367]
