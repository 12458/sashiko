# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 2)

Core device, buffer object (BO), execution queue, and diagnostic infrastructure for the Intel Xe DRM driver, implementing TTM buffer management, DMA-BUF, DRM client tracking, workload submission (`xe_exec` and execlist), forcewake, EU stall telemetry, devcoredump, and configfs/debugfs/sysfs.

## Architecture & Data Flow

- In `try_add_system()`, when `bo_flags` has both `XE_BO_FLAG_SYSTEM` and `XE_BO_FLAG_VRAM_MASK`, `XE_PL_TT` must set `TTM_PL_FLAG_FALLBACK`; thus `xe_bo_validate()` must return 0 if `xe_bo_is_pinned(bo)`, and `xe_dma_buf_pin()` must pass `in_place = true` to `xe_bo_pin_external()` after migrating to `XE_PL_TT`. In `xe_bo.h`, `XE_BO_FLAG_SYSTEM`, `XE_BO_FLAG_VRAM0`, and `XE_BO_FLAG_VRAM1` must stay contiguous in that order for placement bit-shifts in `xe_gem_create_ioctl()` and `XE_BO_FLAG_VRAM`. [F58, F59, F120]
- In `struct xe_ttm_tt`, `struct ttm_tt ttm` must be at offset 0 because `xe_ttm_tt_destroy()` passes `struct ttm_tt *` directly to `kfree()`. Because `xe_ttm_tt_create()` sets `TTM_TT_FLAG_EXTERNAL | TTM_TT_FLAG_EXTERNAL_MAPPABLE` on all non-`ttm_bo_type_sg` BOs, testing for imported DMA-BUFs in `xe_ttm_bo_is_imported()` and `xe_ttm_tt_[un]populate()` requires `TTM_TT_FLAG_EXTERNAL` set and `TTM_TT_FLAG_EXTERNAL_MAPPABLE` clear. [F103, F131]
- Shrinker counts in `xe->mem.shrinker` must be updated via `xe_ttm_tt_account_{add,subtract}()` whenever a mappable `ttm_tt` is populated, unpopulated, shrunken, pinned/unpinned while populated, or has `xe_tt->purgeable` toggled while populated. In `xe_ttm_tt_populate()`, restore a backed-up `ttm_tt` via `ttm_tt_restore()` only when `!xe_tt->purgeable`; if `xe_tt->purgeable`, call `ttm_tt_clear_backed_up(tt)` before allocating fresh pages, and reset `xe_tt->purgeable = false` on success. [F61, F68]
- Both `xe_bo_cpu_fault_fastpath()` and `xe_bo_cpu_fault()` must check `xe_ttm_bo_is_imported()`, run `xe_bo_fault_migrate()`, and check `DMA_RESV_USAGE_KERNEL` fences before `__xe_bo_cpu_fault()`, while `xe_bo_cpu_fault()` must return `VM_FAULT_RETRY` when `retry_after_wait` is true. `__xe_bo_cpu_fault()` links VRAM BOs via `bo->vram_userfault_link` into `xe->mem_access.vram_userfault.list` under `vram_userfault.lock`, which `xe_bo_move_notify()`, `xe_bo_runtime_pm_release_mmap_offset()`, and `xe_ttm_bo_destroy()` must unlink under that lock. [F62, F71]
- A user `xe_bo` with non-NULL `vm` shares `xe_vm_resv(vm)`, cannot be exported via `xe_gem_prime_export()` (`-EPERM`), and when `!xe_vm_in_fault_mode(vm)` joins `vm->lru_bulk_move`, which must be cleared via `ttm_bo_set_bulk_move(&bo->ttm, NULL)` (`__xe_bo_unset_bulk_move`) under the BO/VM lock on error cleanup or `xe_gem_object_close()`. [F72]
- In `xe_bo_evict_all()`, GPU-migrated BOs (user, `pinned.late.external`, `pinned.late.kernel_bo_present`) must be evicted and waited on via `xe_tile_migrate_wait()` before evicting `pinned.early.kernel_bo_present` via CPU memcpy, and restored in reverse (`xe_bo_restore_early()` before GT init, `xe_bo_restore_late()` after). In `xe_bo_evict_all_user()`, `!IS_DGFX(xe) && xe_device_has_flat_ccs(xe)` must not skip evicting `XE_PL_TT` so stolen-memory CCS metadata is saved across hibernation. [F153, F154]
- In `xe_device_probe()`, `xe_ttm_{sys,stolen}_mgr_init()` must run immediately before `xe_display_init_early()` so display performs the first TTM allocation. In `__xe_driver_flr()`, before setting `DRIVERFLR` in `GU_CNTL`, wait for `GU_CNTL & DRIVERFLR` to clear and write `DRIVERFLR_STATUS` to `GU_DEBUG`; after setting `DRIVERFLR`, wait for `GU_CNTL & DRIVERFLR` to clear, wait for `GU_DEBUG & DRIVERFLR_STATUS` to set, and write `DRIVERFLR_STATUS` to `GU_DEBUG` again. [F81, F149]
- In `xe_device_sysfs_init()` and `xe_debugfs_register()`, guard PF-only MMIO/PCODE attributes (`auto_link_downgrade_attr_group`, `late_bind_attr_group`, `debugfs_residencies`) with `!IS_SRIOV_VF(xe)`. In `xe_file_open()`, initialize `xef->vm.xa` and `xef->exec_queue.xa` with `XA_FLAGS_ALLOC1` so ID 0 stays reserved. [F102, F151]
- `struct xe_exec_queue` embeds `struct xe_lrc *lrc[] __counted_by(width)`, so `__xe_exec_queue_alloc()` must allocate `struct_size(q, lrc, width)` and set `q->width = width` before accessing `q->lrc`. In `xe_exec_queue_create_ioctl()` and `calc_validate_logical_mask()`, bound `len = args->width * args->num_placements` to `[1, XE_HW_ENGINE_MAX_INSTANCE]` before copying `eci`, indexed as `j * width + i` with `current_mask == prev_mask << 1` for `i > 0`. In `__xe_execlist_port_start()`, wrap `port->last_ctx_id` to 1 (never 0, reserved for idle in `__xe_execlist_port_idle()`) when exceeding `max_ctx`. [F91, F92, F99]
- `xe_devcoredump()` sets `coredump->captured = true` under `coredump->lock` until `xe_devcoredump_free()` cancels `snapshot.work`, frees `snapshot.read.buffer` and sub-objects, zeroes `coredump->snapshot`, and resets `captured = false`. `xe_devcoredump_read()` caps `ss->read.buffer` at `XE_DEVCOREDUMP_CHUNK_MAX` and must index by `chunk_offset` from `div_u64_rem(offset, XE_DEVCOREDUMP_CHUNK_MAX, &chunk_offset)` after repopulating whenever `offset` is outside `[chunk_position, chunk_position + XE_DEVCOREDUMP_CHUNK_MAX)`. [F75, F100]
- In `xe_eu_stall_stream_init()` and `xe_eu_stall_data_buf_alloc()`, size `stream->xecore_buf` and `stream->bo` by `xe_gt_topology_mask_last_dss(all_xecores) + 1` (not `num_xecores`). Mask `per_xecore_buf->{read,write}` with `(buf_size << 1) - 1` (preserving the overflow bit) and `xecore_buf->vaddr` offsets with `buf_size - 1`. In `xe_eu_stall_data_buf_read()`, `read_data_size == 0` must `goto exit_drop` so `clear_dropped_eviction_line_bit()` and `clear_bit(xecore, stream->data_drop.mask)` still run. [F87, F88, F116]
- In `xe_configfs.c`, keep `struct xe_config_device` (`dev->config` and `device_defaults`) zero-initialized across padding for `memcmp()` in `xe_configfs_check_device()`. `wa_bb_store()` allocates one buffer at `wa_bb[0].cs` and points `wa_bb[class].cs` into it (resetting `tmp_wa_bb[class].len = 0` between `parse_wa_bb_lines()` passes), so readers must test `wa_bb[class].len` (not `.cs`) and teardown must only `kfree(wa_bb[0].cs)`. [F55, F114, F140]

## Synchronization

- In `__xe_bo_create_locked()`, `xe_bo_create_user()`, and `xe_bo_create_pin_map_at_aligned()`, unlock on exit/error via `xe_bo_unlock_vm_held(bo)` (not `xe_bo_unlock(bo)`) to preserve the caller's VM lock. `xe_bo_addr()` requires holding `bo->ttm.base.resv` unless `READ_ONCE(bo->ttm.pin_count)` is non-zero. [F4, F32]
- `xe_bo_init_locked()` must wait for `DMA_RESV_USAGE_KERNEL` fences on `ttm_bo_type_kernel` BOs before returning, and `xe_bo_fault_migrate()` must wait for (or test in `no_wait_gpu` mode) `DMA_RESV_USAGE_KERNEL` fences via `xe_bo_wait_usage_kernel()` before `ttm_bo_populate()`. [F21, F22]
- `xe_bo_put()` may sleep and take reclaim-tainted locks (`client->bos_lock`, `ggtt->lock`, `dma_resv`), so atomic/spinlock/reclaim contexts must use `xe_bo_put_deferred()` + `xe_bo_put_commit()` or `xe_bo_put_async()`. In `show_meminfo()`, locking `bo` under `file->table_lock` or `client->bos_lock` must try `dma_resv_trylock()` first and on failure hold the `kref_get_unless_zero()` ref across dropping the spinlock before `xe_bo_lock(bo, false)`, releasing via `xe_bo_put_deferred()` / `xe_bo_put_commit()`. [F111, F166, F171]
- `xe_bo_apply_to_pinned()` must drop spinlock `xe->pinned.lock` after `xe_bo_get()` before calling sleeping `pinned_fn(bo)`; because `xe_bo_unpin()` may race, `xe_bo_notifier_prepare_pinned()` must recheck `xe_bo_is_pinned(bo)` after locking `bo`, and `xe_bo_apply_to_pinned()` must check `!list_empty(&bo->pinned_link)` after re-locking `xe->pinned.lock`. In `xe_bo_move()`, GPU migration/clear must check `xe_rpm_reclaim_safe(xe)` and use `xe_pm_runtime_get_noresume(xe)` when reclaim-unsafe. [F66, F176, F183]
- In `xe_exec_ioctl()`, if `xe_vm_userptr_check_repin(vm)` is true, take `vm->lock` in write mode, call `xe_vm_userptr_pin(vm)`, downgrade to read, and reverify `__xe_vm_userptr_needs_repin(vm)` under `xe_svm_notifier_lock_interruptible(vm)` across `xe_sched_job_arm(job)`, retrying on `-EAGAIN`. `xe_exec_queue_last_fence_{get,put,set,test_dep}()` require `vm->lock` for `EXEC_QUEUE_FLAG_VM` queues, or both `xe_vm_assert_held(vm)` and `q->hwe->hw_engine_group->mode_sem` otherwise. [F40, F173]
- In `xe_exec_queue_destroy_ioctl()` and `xe_exec_queue_fini()`, increment `xef->exec_queue.pending_removal` when erasing from `xef->exec_queue.xa` and decrement (with `wake_up_var()`) only after `xe_exec_queue_update_run_ticks()`. [F24]
- `xe_execlist_port.lock` is taken in hardirq by `xe_execlist_port_irq_handler()`, so non-IRQ callers (`xe_execlist_make_active()`, `xe_execlist_port_irq_fail_timer()`, `execlist_exec_queue_destroy_async()`) must use `spin_lock_irq[save]()`. `xe_execlist_port_destroy()` must delete `port->irq_fail` timer and clear `port->hwe->irq_handler` under `irq.lock` with IRQs disabled before `xe_lrc_put(port->lrc)`. [F28, F165]
- `__domain_wait()` runs under `spin_lock_irqsave(&fw->lock)` in `xe_force_wake_{get,put}()` and must pass `atomic = true` to `xe_mmio_wait32()`. In `xe_devcoredump_{read,free}()`, `flush_work(&ss->work)`, `cancel_work_sync(&coredump->snapshot.work)`, and `xe_pm_runtime_get()` must run outside `coredump->lock`. In `xe_eu_stall.c`, `gt->eu_stall->stream_lock` nests outside `stream->xecore_buf_lock` and wraps `cancel_delayed_work_sync(&stream->buf_poll_work)`, so `eu_stall_data_buf_poll_work_fn()` must never take `stream_lock`. [F164, F168, F177]

## Object Lifetimes

- TTM callbacks/shrinkers (`xe_evict_flags()`, `xe_bo_eviction_valuable()`, `xe_bo_shrink()`, `xe_ttm_bo_{release,delete_mem}_notify()`) must check `xe_bo_is_xe_bo(tbo)` before `ttm_to_xe_bo(tbo)`, and eviction/shrinker paths must also get a GEM ref via `xe_bo_get_unless_zero()` (paired with `xe_bo_put()`) before accessing `xe_bo` fields outside `ttm_buffer_object`. `__xe_bo_create_locked()` calls `xe_vm_get(vm)` and `xe_ttm_bo_destroy()` calls `xe_vm_put(bo->vm)` only when `bo->vm && xe_bo_is_user(bo)`. [F2, F5, F132]
- Unmapping a BO's sg in `xe_bo_dma_unmap_pinned()`, `xe_ttm_bo_delete_mem_notify()`, or `xe_tt_unmap_sg()` must clear both `ttm_bo->sg` and `xe_tt->sg` to `NULL`. In `xe_bo_evict_pinned_copy()` and `xe_bo_restore_pinned()`, always `xe_bo_vunmap(backup)` on exit, but only `xe_bo_vunmap(bo)` if `iosys_map_is_null(&bo->vmap)` was true on entry. [F12, F119]
- In `xe_device_remove()`, call `drm_dev_unplug(&xe->drm)` before `xe_bo_pci_dev_remove_all(xe)`. Managed kernel BO cleanup (`xe_bo_pinned_fini()`, `__xe_bo_unpin_map_no_vm()`) must use `devm_add_action_or_reset()` so they run before `xe_device_destroy()` (`drmm`), where `xe_bo_dev_fini(&xe->bo_device)` must flush `async_free` before `ttm_device_fini(&xe->ttm)`. [F29, F150, F161]
- `xe_dep_scheduler_fini()` must call `drm_sched_entity_fini()` before `drm_sched_fini()` and free via `kfree_rcu(dep_scheduler, rcu)`. In `xe_exec_queue_destroy()`, only iterate `&q->multi_gt_list` to put child queues when `!(q->flags & EXEC_QUEUE_FLAG_BIND_ENGINE_CHILD)`. [F13, F112]
- `xe_eu_stall_stream_open_locked()` sets `gt->eu_stall->stream = stream` and takes `drm_dev_get()`; error/close paths in `xe_eu_stall_stream_free()` must reset `gt->eu_stall->stream = NULL` and call `drm_dev_put()`. Callers of `find_xe_config_group_device()` must call `config_group_put(&dev->group)` when non-NULL. [F14, F201]

## API Contracts

- Translate `XE_FORCEWAKE_ALL` to `fw->initialized_domains` before `for_each_fw_domain_masked()` and never pass it to `xe_force_wake_ref()` or `xe_force_wake_assert_held()`. If `domain_wake_wait()` fails in `xe_force_wake_get()`, decrement `domain->ref` back to 0 and leave `BIT(domain->id)` unset in `fw->awake_domains` and `ref_incr`; callers of `xe_force_wake_get(fw, XE_FORCEWAKE_ALL)` must check `xe_force_wake_ref_has_domain(fw_ref, XE_FORCEWAKE_ALL)` and still call `xe_force_wake_put(fw, fw_ref)` on failure. [F43, F79, F98, F127]
- `xe_bo_ggtt_addr(bo)` requires `bo->tile != NULL`; use `__xe_bo_ggtt_addr(bo, tile_id)` when `bo->tile` may be NULL. Pass `offset = ~0ull` (not `0`, which forces `XE_BO_FLAG_FIXED_PLACEMENT` at 0) to `xe_bo_create_pin_map_at_{novm,aligned}()` for unconstrained placement. `xe_managed_bo_reinit_in_vram()` requires `!(*src)->vmap.is_iomem` and replaces `*src` at a new GGTT address, so callers must refresh cached pointers/addresses. `xe_bo_vmap()` requires `XE_BO_FLAG_NEEDS_CPU_ACCESS`, `force_contiguous(bo->flags)`, and `xe_bo_assert_held(bo)`. [F47, F50, F69, F141, F181]
- In `xe_bo_move()`, call `xe_bo_move_notify()` on `ttm_bo_type_sg` BOs only when `new_mem->mem_type == XE_PL_SYSTEM` (and `dma_buf_move_notify()` only when `dma_buf && !import_attach`), and call `ttm_bo_move_accel_cleanup()` only when `!move_lacks_source` (otherwise `dma_resv_add_fence(..., DMA_RESV_USAGE_KERNEL)` + `ttm_bo_move_null()`). `xe_ttm_access_memory()` returns positive `len` on success, while `xe_bo_read()` returns `0` on full read or `-EIO` on short read. [F49, F60, F188]
- `xe_sg_segment_size()` caps segment size to `round_down(min(UINT_MAX, dma_max_mapping_size(dev)) / 2, PAGE_SIZE)`. `xe_device_wmb()` must do `wmb()` plus a root-tile `VF_CAP_REG` MMIO write on `IS_DGFX(xe)`. In `xe_exec_ioctl()`, nonzero `args->num_batch_buffer` must equal `q->width`, and `args->address` is a user pointer when `q->width > 1` but a direct `u64` address when `q->width == 1`. [F90, F178, F180]
- `xe_configfs_get_ctx_restore_post_bb()` requires a non-NULL `cs` pointer (unlike `mid_bb`). `xe_eu_stall_get_sampling_rates()` writes `ARRAY_SIZE` to `*num_rates` but returns `sizeof(eu_stall_sampling_rates)`. `xe_print_blob_ascii85()` requires 4-byte-aligned `offset` and `size`. `devcoredump_snapshot()` must read `q->vm->xef->{process_name,pid}` instead of `current`. [F56, F138, F143, F204]

## Error Handling

- In `xe_device_probe_early()`, if `xe_pcode_probe_early()` fails, save `err` in `save_err` before `xe_survivability_mode_boot_enable()` and return `save_err` if survivability returns `0`. Inside `xe_validation_guard()` loops (e.g. `xe_bo_create_pin_range_novm()`), call `xe_bo_unlock(bo)` and `xe_bo_put(bo)` before `drm_exec_retry_on_contention()` or `xe_validation_retry_on_oom()`. Validate ioctl user args with `XE_IOCTL_DBG()`, never `WARN_ON()` or `xe_assert()`. [F53, F115, F197]

## External Contracts

- In `xe_gem_create_ioctl()`, require `args->handle == 0` and `args->size <= SIZE_MAX`. In `xe_gem_mmap_offset_ioctl()`, require `args->handle == 0` for `DRM_XE_MMAP_OFFSET_FLAG_PCI_BARRIER`; keep `XE_PCI_BARRIER_MMAP_OFFSET < DRM_FILE_PAGE_OFFSET_START << XE_PTE_SHIFT` for 4K write-only `xe_pci_barrier_mmap()`. In `exec_queue_set_priority()`, return `-EINVAL` above `XE_EXEC_QUEUE_PRIORITY_HIGH` and `-EPERM` above `xe_exec_queue_device_get_max_priority(xe)` (lacking `CAP_SYS_NICE`). [F57, F96, F121, F205]
- `xe_eu_stall_stream_read()` must `ALIGN_DOWN(count, stream->data_record_size)` and return `-EINVAL` if 0; `xe_eu_stall_stream_read_locked()` must set `reported_to_user = true` and return `-EIO` once when `stream->data_drop.mask` is non-zero, and return `total_size` whenever `total_size > 0` even if a later `xe_eu_stall_data_buf_read()` fails. `xe_config_make_device_group()` requires exact `"%04x:%02x:%02x.%d"` BDF names, and configfs store handlers must hold `dev->lock` and return `-EBUSY` if `is_bound(dev)`. [F54, F86, F89, F200, F207]

## Known Pitfalls

- `xe_bo_is_vram()` is true for `XE_PL_STOLEN` on DGFX, but `mem_type_is_vram()` must exclude `XE_PL_STOLEN` and `xe_ttm_io_mem_pfn()` / `vram_region_gpu_offset()` must branch on `XE_PL_STOLEN` before `res_to_mem_region()`. In `xe_bo_move()`, check `ttm_tt_is_populated(ttm) || ttm_tt_is_swapped(ttm)` (not `TTM_TT_FLAG_SWAPPED`) for `tt_has_data`. [F104, F109]
- Cast `unsigned long` page counts/offsets to `u64` before `<< PAGE_SHIFT` in `xe_tt_map_sg()` and `xe_ttm_io_mem_pfn()`, and use `DIV_ROUND_UP_ULL` / `DIV_ROUND_UP` in `xe_device_ccs_bytes()` and `xe_ttm_tt_create()`. In `lookup_engine_info()`, reject trailing chars (`*pattern != '\0'`) when `!mask`, and reject `bit = __ffs64(engine_info[i].mask) + instance` when `bit >= fls64(engine_info[i].mask)`. [F83, F84, F123, F125]
