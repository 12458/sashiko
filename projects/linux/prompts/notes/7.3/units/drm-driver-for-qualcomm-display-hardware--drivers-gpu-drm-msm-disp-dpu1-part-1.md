# DRM DRIVER for Qualcomm display hardware — drivers/gpu/drm/msm/disp/dpu1 (part 1)

This component contains the static SoC hardware catalog definitions (DPU 1.x–12.0), the core performance/bandwidth/clock management subsystem (`dpu_core_perf`), and the high-level DRM CRTC (`dpu_crtc`) and virtual encoder (`dpu_encoder`) implementations.

## Architecture & Data Flow

- In `dpu_crtc_atomic_check()`, when returning early because `!crtc_state->enable || !drm_atomic_crtc_effectively_active(crtc_state)`, `cstate->new_perf` must be zeroed so `dpu_crtc_duplicate_state()`'s `kmemdup()` does not retain stale clock/BW votes. When `crtc_state->mode_changed || crtc_state->connectors_changed`, `dpu_crtc_assign_resources()` must populate `cstate->mixers` and `cstate->num_mixers` before `_dpu_crtc_check_and_setup_lm_bounds()` computes `cstate->lm_bounds`. [F48, F57]
- Non-mode state changes that alter resource reservation in `dpu_crtc_get_topology()` or `dpu_encoder_update_topology()` (e.g. writeback YUV toggling `num_cdm` or clone mode toggling `cwb_enabled`) must be mirrored in `dpu_encoder_needs_modeset()` and `dpu_crtc_check_mode_changed()` to set `new_crtc_state->mode_changed = true`. [F58]
- In `dpu_crtc_assign_resources()` and `dpu_encoder_virt_atomic_mode_set()`, `num_ctl` for `DPU_HW_BLK_CTL` can be smaller than `num_lm` or `dpu_enc->num_phys_encs`, so `hw_ctl` indexing must clamp to `num_ctl - 1` or `hw_ctl[0]` rather than indexing `hw_ctl[i]` directly. [F71]
- In `dpu_crtc_atomic_begin()`, `dpu_encoder_trigger_kickoff_pending()` must run before `_dpu_crtc_blend_setup()` and `_dpu_crtc_setup_cp_blocks()` stage pending flush bits on CTLs. When clearing blend stages on a `dpu_hw_ctl` in `_dpu_crtc_blend_setup()` or `dpu_encoder_helper_reset_mixers()`, `set_active_fetch_pipes(ctl, NULL)` and `set_active_pipes(ctl, NULL)` (and `set_active_lms(ctl, NULL)` on mixer reset) must be called alongside `clear_all_blendstages`. [F54, F118]
- `dpu_encoder_helper_phys_cleanup()` must unbind/disable all optional features on shared blocks (`hw_wb`, `hw_intf`, `hw_pp` dither, `hw_cwb`, `merge_3d`, `hw_cdm`, `hw_dsc`) and clear `dpu_enc->dsc = NULL` before flushing/starting `ctl`. Any `dpu_encoder_virt` state cleared in `dpu_encoder_virt_atomic_disable()` or `dpu_encoder_helper_phys_cleanup()` (`connector`, `dsc`, `enabled`, `wide_bus_en`) must be re-initialized in `dpu_encoder_virt_atomic_enable()`, not `dpu_encoder_virt_atomic_mode_set()`. [F55, F56]
- In `dpu_encoder_prepare_for_kickoff()`, if any `phys->enable_state == DPU_ENC_ERR_NEEDS_HW_RESET` after `prepare_for_kickoff`, `dpu_encoder_helper_hw_reset()` must be called on all `dpu_enc->phys_encs[i]` in a second pass after `dpu_encoder_resource_control(drm_enc, DPU_ENC_RC_EVENT_KICKOFF)`. [F87]
- Each `struct dpu_encoder_phys` has either `hw_intf` or `hw_wb` populated, never both, and `struct dpu_crtc_mixer.hw_dspp` is `NULL` unless `crtc_state->ctm` reserved DSPPs; loops over `dpu_enc->phys_encs` or `cstate->mixers` (`_dpu_crtc_setup_cp_blocks()`, `dpu_crtc_atomic_print_state()`) must NULL-check `hw_intf`/`hw_wb`/`hw_dspp` before dereferencing. [F40, F41]
- In `dpu_crtc_mode_valid()`, `dpu_core_perf_adjusted_mode_clk()` (in kHz) must be stored in `u64 adjusted_mode_clk` and multiplied by `1000` before comparing with `max_core_clk_rate` (in Hz). `_dpu_encoder_calculate_linetime()` must check `pclk_rate` (`mode->clock`) != 0 before `DIV_ROUND_UP_ULL(1000000000ull, pclk_rate)`, `dpu_encoder_vsync_time()` must check `line_time != 0`, and `dpu_encoder_dsc_initial_line_calc()` must use `DIV_ROUND_UP(total_pixels, dsc->slice_width)`. [F90, F93, F95]
- In `catalog/dpu_*.h`: block `.name` strings (`DPU_HW_BLK_INFO`) must be <= 15 chars (`DPU_HW_BLK_NAME_LEN - 1`); unpopulated `intr_*` fields must be `0` (never `-1`, as `DPU_IRQ_IDX` is 1-based unsigned); `struct dpu_perf_cfg` must set non-zero `.max_bw_high` and `.min_prefill_lines`; and SmartDMA v2 SoCs must use `*_SDMA` SSPP masks (`VIG_SDM845_MASK_SDMA`, `VIG_SC7280_MASK_SDMA`, `DMA_SDM845_MASK_SDMA`, `DMA_CURSOR_SDM845_MASK_SDMA`) instead of `*_NO_SDMA`. [F66, F104, F108, F109]
- Versioned `catalog/dpu_*.h` rules: on DPU >= 5.0, `struct dpu_ctl_cfg` must not set `BIT(DPU_CTL_SPLIT_DISPLAY)` in `.features` (or `_dpu_rm_reserve_ctls()` skips them); on DPU < 5.0, `struct dpu_pingpong_cfg` must set `.intr_rdptr` (and `.sblk` on all versions); on DPU >= 7.0, `struct dpu_dsc_cfg` must set `.sblk`. [F107, F110, F111]

## Synchronization

- `dpu_enc->enc_spinlock` is taken in hardirq (`dpu_encoder_vblank_callback()`) and nests outside `crtc->dev->event_lock`. Always use `spin_lock_irqsave()`, never acquire it under `event_lock`, and drop it in `dpu_encoder_toggle_vblank_for_crtc()` before calling `phys->ops.control_vblank_irq()` (which takes sleeping `vblank_ctl_lock` and `irq_lock`). It protects `dpu_enc->crtc` in `dpu_encoder_assign_crtc()` (which requires `dpu_enc->crtc == NULL` before reassignment) and `dpu_encoder_vblank_callback()`. [F25, F130, F131]
- In `_dpu_encoder_kickoff_phys()`, `dpu_enc->enc_spinlock` (`spin_lock_irqsave()`) must cover setting `set_bit(i, dpu_enc->frame_busy_mask)` (only for `phys->split_role != ENC_ROLE_SLAVE`), `_dpu_encoder_trigger_flush()` (accumulating into `pending_flush` and flushing once on `cur_master` when `needs_single_flush(phys)` is true), and `_dpu_encoder_trigger_start(dpu_enc->cur_master)`. [F86, F124]
- In `dpu_crtc_commit_kickoff()` and `dpu_crtc_kickoff_clone_mode()`, `dpu_encoder_start_frame_done_timer()` must run after `dpu_encoder_kickoff()` sets `frame_busy_mask`. In `dpu_crtc_kickoff_clone_mode()`, `wb_encoder` must be kicked off before `rt_encoder`, and `dpu_encoder_start_frame_done_timer()` called on both only after both kickoffs complete. [F18, F81]
- `dpu_enc->enc_lock` protects `dpu_enc->enabled`, `dpu_enc->phys_encs[]`, and physical encoder enable/disable/restore sequences across `dpu_encoder_setup_display()`, `dpu_encoder_virt_atomic_enable()`, `dpu_encoder_virt_atomic_disable()`, `dpu_encoder_virt_runtime_resume()`, and `_dpu_encoder_status_show()`, nesting outside `dpu_enc->rc_lock`. [F28]
- In `dpu_encoder_resource_control()`, call `cancel_delayed_work_sync(&dpu_enc->delayed_off_work)` before acquiring `dpu_enc->rc_lock`. Process-context events (`KICKOFF`, `PRE_STOP`, `STOP`, `ENTER_IDLE`) must hold `rc_lock` across `rc_state` checks/mutations and IRQ/resource toggles, while irq-context `FRAME_DONE` must not acquire `rc_lock`. `ENTER_IDLE` must recheck `rc_state == DPU_ENC_RC_STATE_ON` and `frame_busy_mask[0] == 0` after locking `rc_lock`. [F29, F30, F127]
- Hardirq `dpu_encoder_frame_done_callback()` must zero `frame_done_timeout_ms` before non-blocking `timer_delete(&dpu_enc->frame_done_timer)` (while `dpu_encoder_virt_atomic_disable()` uses `timer_delete_sync()` under `enc_lock`). `dpu_encoder_frame_done_timeout()` must verify `frame_busy_mask[0]`, `dpu_enc->crtc`, and `atomic_xchg(&dpu_enc->frame_done_timeout_ms, 0) != 0` before reporting `DPU_ENCODER_FRAME_EVENT_ERROR`, without taking `enc_lock`. [F32, F134]
- Hardirq/softirq `dpu_crtc_frame_event_cb()` must ignore `DPU_ENCODER_FRAME_EVENT_IDLE` before dequeuing from `dpu_crtc->frame_event_list` under `spin_lock_irqsave(&dpu_crtc->spin_lock, ...)`, and defer `dpu_core_perf_crtc_release_bw()` to `dpu_crtc_frame_event_work()`, which must return `fevent` to `frame_event_list` under `dpu_crtc->spin_lock` on all paths. [F80, F129]
- `dpu_crtc_atomic_check()` increments `dpu_kms->bandwidth_ref` per active commit (released via `dpu_core_perf_crtc_release_bw()` when `frame_pending` hits 0 in `dpu_crtc_frame_event_work()` or on abort in `dpu_crtc_disable()`), while `dpu_crtc_enable()` and `dpu_crtc_disable()` hold an extra `bandwidth_ref` for `INTF_MODE_VIDEO`. [F33]
- When `dpu_encoder_helper_wait_for_irq()` times out on `wait_info->wq` but `dpu_core_irq_read()` shows a pending IRQ, it must wrap `func(phys_enc)` in `local_irq_save()`/`local_irq_restore()`. Callers of `dpu_crtc_get_intf_mode()` must hold `crtc->mutex` and never call it from `atomic_check`. [F133, F137]

## Object Lifetimes

- `dpu_crtc_init()` and `dpu_encoder_init()` allocate `dpu_crtc` and `dpu_encoder_virt` via `drmm_crtc_alloc_with_planes()` and `drmm_encoder_alloc()` (no manual `kfree()` `.destroy` hooks), whereas `struct dpu_crtc_state` is freed via `kfree()` in `dpu_crtc_destroy_state()`. [F125]
- When transferring `crtc->state->event` to `dpu_crtc->event` in `dpu_crtc_atomic_flush()` or sending vblank events in `_dpu_crtc_complete_flip()` and `dpu_crtc_disable()`, the source event pointer must be cleared to `NULL` under `dev->event_lock`. [F2]
- In `dpu_crtc_enable()`, call `dpu_encoder_assign_crtc(encoder, crtc)` before `drm_crtc_vblank_on(crtc)` when `!old_crtc_state->self_refresh_active` (skip assignment when `old_crtc_state->self_refresh_active` is set). In `dpu_crtc_disable()`, call `drm_crtc_vblank_off(crtc)` before `dpu_encoder_assign_crtc(encoder, NULL)` (keep `dpu_enc->crtc` when entering `crtc->state->self_refresh_active`, clear it when disabling from `old_crtc_state->self_refresh_active`). [F4, F17]
- In `dpu_crtc_disable()`, `_dpu_crtc_wait_for_frame_done(crtc)` must finish before setting `dpu_crtc->enabled = false`, releasing/zeroing `dpu_crtc->frame_pending`, dropping votes via `dpu_core_perf_crtc_update(crtc, 0)`, and calling `pm_runtime_put_sync(crtc->dev->dev)`. [F19]
- `_dpu_encoder_resource_enable()` calls `pm_runtime_get_sync()` before `_dpu_encoder_irq_enable()`, and `_dpu_encoder_resource_disable()` calls `_dpu_encoder_irq_disable()` before `pm_runtime_put_sync()`. In `dpu_encoder_resource_control()`, video mode keeps runtime PM active in `DPU_ENC_RC_STATE_IDLE` (`ENTER_IDLE` only disables IRQs), so `KICKOFF` and `PRE_STOP` from `IDLE` in video mode only call `_dpu_encoder_irq_enable()`, and `PRE_STOP` enters `PRE_OFF` so `STOP` calls `_dpu_encoder_resource_disable()`. [F8, F9]
- Under `dpu_enc->enc_lock`, `dpu_encoder_virt_atomic_disable()` must call `dpu_encoder_wait_for_tx_complete()`, send `DPU_ENC_RC_EVENT_PRE_STOP`, run `phys->ops.disable()`, drain `frame_done_timer` via `timer_delete_sync()` if `frame_done_timeout_ms` was non-zero, and send `DPU_ENC_RC_EVENT_STOP`. [F20]
- `dpu_crtc_assign_resources()` and `dpu_crtc_reassign_planes()` must call `dpu_rm_release(global_state, crtc)` and `dpu_rm_release_all_sspp(global_state, crtc)` before `if (!crtc_state->enable) return 0;`. `dpu_encoder_virt_atomic_mode_set()` must zero unused `dpu_enc->hw_pp[i]` (`i >= num_pp`) and set `dpu_enc->cur_master->hw_cdm = NULL` when no `DPU_HW_BLK_CDM` is assigned. `dpu_crtc_set_crc_source()` must balance `drm_crtc_vblank_get()`/`put()` and guard `crtc_state->crc_source` with `crtc->mutex` and `drm_dev->event_lock`. [F6, F13, F139]

## API Contracts

- In `dpu_core_perf_crtc_update()`, `_dpu_core_perf_crtc_update_bus()` must precede `dev_pm_opp_set_rate()`; for enabled CRTCs, votes only increase when `params_changed != 0` (`dpu_crtc_atomic_flush()`) and only decrease when `params_changed == 0` (`dpu_crtc_complete_commit()`). `bw_ctl` is in bytes/sec while `max_bw_high` and `icc_set_bw()` use kBps (1000-based), and `_dpu_core_perf_crtc_update_bus()` must check `if (!kms->num_paths)` before dividing `avg_bw` by `kms->num_paths`. [F34, F91, F140]
- Callers of `dpu_core_perf_aggregate()` (`dpu_core_perf_crtc_check()`, `_dpu_core_perf_crtc_update_bus()`) and `dpu_encoder_update_topology()` (`dpu_crtc_get_topology()`) must zero-initialize `struct dpu_core_perf_params perf = { 0 }` and `struct msm_display_topology topology = {0}` before calling them. [F44, F47]
- In `dpu_crtc_atomic_check()` and `dpu_crtc_assign_resources()`, resource reallocation is gated only by `crtc_state->mode_changed || crtc_state->connectors_changed` (ignore `active_changed`) and `dpu_rm_reserve()` runs whenever `crtc_state->enable` is true (ignore `crtc_state->active`). [F136]
- `dpu_rm_get_assigned_resources()` takes element count `blks_size` (`ARRAY_SIZE(...)` or `1`, never `sizeof(...)`), and callers must downcast returned `struct dpu_hw_blk *` with the `to_dpu_hw_*` macro matching `enum dpu_hw_blk_type`. Callers of `ctl->ops.set_active_fetch_pipes`, `set_active_pipes`, and `set_active_lms` must pass `NULL` or a zeroed `DECLARE_BITMAP(..., SSPP_MAX)` / `DECLARE_BITMAP(..., LM_MAX)`. [F96, F100, F105]
- In `dpu_encoder_setup_display()`, `disp_info->h_tile_instance[i]` is a 0-based controller index for `intf_type != INTF_WB`, but a 1-based `enum dpu_wb` ID for `INTF_WB`. Debugfs handlers must cast `s->private` / `file->private_data` to the exact type passed to `debugfs_create_file()` (`dpu_crtc *` in `_dpu_debugfs_status_show()`, `drm_crtc *` in `dpu_crtc_debugfs_state_show()`, `drm_encoder *` in `_dpu_encoder_status_show()`, `dpu_core_perf *` in `dpu_core_perf_mode_fops`). [F53, F101]

## Error Handling

- `dpu_encoder_helper_wait_for_irq()` and `dpu_encoder_wait_for_commit_done()` return `-EWOULDBLOCK` when `enable_state == DPU_ENC_DISABLED` and `-ETIMEDOUT` on hardware timeout; callers must check `ret == -ETIMEDOUT` before calling `dpu_encoder_helper_report_irq_timeout()` or `msm_disp_snapshot_state()`. In `dpu_encoder_underrun_callback()`, `dpu_encoder_frame_done_timeout()`, and `dpu_encoder_wait_for_commit_done()`, gate `msm_disp_snapshot_state()` to the first occurrence (`underrun_cnt == 1`, `frame_done_timeout_cnt == 1`, `!commit_done_timedout`), and use ratelimited logging in `dpu_crtc_frame_event_cb()` and `dpu_encoder_frame_done_timeout()`. [F36, F143, F144]
- `dpu_encoder_virt_add_phys_encs()` must check `dpu_enc->num_phys_encs + NUM_PHYS_ENCODER_TYPES < ARRAY_SIZE(dpu_enc->phys_encs)` before creating encoders, and check `IS_ERR(enc)` on `dpu_encoder_phys_*_init()` before storing `enc` in `phys_encs[]`, incrementing `num_phys_encs`, or setting `cur_master`/`cur_slave`. [F43, F75]
- `_dpu_crtc_check_and_setup_lm_bounds()` must reject `adj_mode->hdisplay` (when `!has_3d_merge`) and each `drm_rect_width(&cstate->lm_bounds[i])` exceeding `max_mixer_width` with `-E2BIG`. `enum dpu_crtc_crc_source` must stay signed so callers of `dpu_crtc_parse_crc_source()` can check `source < 0` (`DPU_CRTC_CRC_SOURCE_INVALID`), and `_dpu_core_perf_mode_write()` must reject `perf_mode >= DPU_PERF_MODE_MAX` with `-EINVAL`. [F37, F68, F73]

## Known Pitfalls

- In `dpu_crtc_disable()`, iterate `old_crtc_state->encoder_mask` (not `crtc->state->encoder_mask`), and in `dpu_crtc_vblank()`, iterate `crtc->dev->mode_config.encoder_list` because `crtc->state->encoder_mask` is cleared on disable. In `dpu_crtc_kickoff_clone_mode()`, initialize local `rt_encoder` and `wb_encoder` to `NULL` before `drm_for_each_encoder_mask()`. [F46, F82]
- `dpu_encoder_get_crc()` must index `crcs[pos + entries_added]` (not `pos + i`) because encoders without `collect_misr` are skipped, and `dpu_crtc_get_encoder_crc()` must check `rc < 0` because positive `rc` is `entries_added`. In `dpu_encoder_helper_wait_for_irq()`, test unsigned `irq_idx == 0` (not `irq_idx < 0`). [F67, F79]
- Cast the leading operand to `u64` in `_dpu_core_perf_calc_clk()` (`(u64)mode->vtotal * mode->hdisplay * drm_mode_vrefresh(mode)`), and guard `cur_line >= vtotal` before `vtotal - cur_line` in `dpu_encoder_vsync_time()`. Keep `enable_bw_release` and `dpu_perf_cfg` fields (`max_bw_low`, `max_bw_high`, `min_*_ib`) as `u32` (with `0400` debugfs mode on `perf_cfg`) for `debugfs_create_u32()`, keep `MAX_PHYS_ENCODERS_PER_VIRTUAL <= BITS_PER_LONG` for `frame_busy_mask[0]` checks, and format fourcc codes with `%p4cc` or `%4.4s`. [F89, F94, F102, F103, F106]
