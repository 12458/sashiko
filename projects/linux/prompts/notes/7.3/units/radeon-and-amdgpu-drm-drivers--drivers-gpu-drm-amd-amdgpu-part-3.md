# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 3)

Top-level PCI/DRM entry points (`amdgpu_drv.c`), GEM and DMA-BUF PRIME (`amdgpu_gem.c`, `amdgpu_dma_buf.c`), GART and doorbell managers (`amdgpu_gart.c`, `amdgpu_doorbell_mgr.c`), hardware/eviction fences (`amdgpu_fence.c`, `amdgpu_eviction_fence.c`), common GFX IP (`amdgpu_gfx.c`), legacy display helpers (`amdgpu_display.c`, `amdgpu_encoders.c`), and EEPROM/FRU utilities.

## Architecture & Data Flow

- In `amdgpu_dma_buf.c`, cast `dma_buf->priv` to `drm_gem_object`/`amdgpu_bo` only when `dma_buf->ops == &amdgpu_dmabuf_ops`, and `attach->importer_priv` only when `attach->importer_ops == &amdgpu_dma_buf_attach_ops` (`dma_buf_attach_adev`). `amdgpu_dma_buf_map` must reject `TTM_PL_VRAM` BOs when `amdgpu_dmabuf_is_xgmi_accessible(dma_buf_attach_adev(attach), bo)` rather than calling `amdgpu_vram_mgr_alloc_sgt`. [F419, F520]
- In `amdgpu_gem_object_close`, call `amdgpu_eviction_fence_detach(&fpriv->evf_mgr, bo)` only when `!amdgpu_vm_is_bo_always_valid(vm, bo)` since `AMDGPU_GEM_CREATE_VM_ALWAYS_VALID` BOs share `vm->root.bo->tbo.base.resv`. [F432]
- In `amdgpu_gfx_kiq_acquire` and `amdgpu_gfx_kiq_init_ring`, `amdgpu_queue_mask_bit_to_mec_queue` returns 0-based `mec` whereas `ring->me = mec + 1` is 1-based; assign each XCC's KIQ an unallocated bit from `adev->gfx.mec_bitmap[xcc_id].queue_bitmap` with `queue == 0` (skipping `mec == 1 && pipe > 1`), `ring->vm_hub = AMDGPU_GFXHUB(xcc_id)`, and doorbell offset `xcc_id * adev->doorbell_index.xcc_doorbell_range`. [F438, F464]
- In `amdgpu_gfx_enable_kgq` (non-MES) and `amdgpu_gfx_disable_kgq`, map/unmap `adev->gfx.gfx_ring[]` only when `amdgpu_gfx_is_master_xcc(adev, xcc_id)`, indexing at `i + xcc_id * adev->gfx.num_gfx_rings`. `amdgpu_gfx_is_master_xcc` must guard `num_xcc_per_xcp` with `adev->gfx.num_xcc_per_xcp ? adev->gfx.num_xcc_per_xcp : 1` before modulo `xcc_id % ...`. [F437, F488]
- In `amdgpu_gfx_set_enforce_isolation`, call `amdgpu_mes_update_enforce_isolation(adev)` after updating `adev->enforce_isolation[]` and unlocking `enforce_isolation_mutex`. In `amdgpu_gfx_enforce_isolation_handler` and `amdgpu_gfx_enforce_isolation_ring_begin_use`/`end_use`, remap `AMDGPU_XCP_NO_PARTITION` to `idx = 0` and verify `idx < MAX_XCP` before indexing per-XCP isolation arrays. [F429, F465]
- In `amdgpu_fence_driver_init_ring`, `ring->num_hw_submission` must be a power of 2, `fences` has `num_hw_submission * 2` entries, and `num_fences_mask` is `num_hw_submission * 2 - 1` (wrap via `seq & num_fences_mask`; full-table loops use `i <= num_fences_mask`). Fence sequences in `fence_drv.cpu_addr` and `trail_fence_cpu_addr` use `cpu_to_le32` on write and `le32_to_cpu` on read. [F456, F457]
- `amdgpu_gart_table_ram_alloc` sets `p[x].mapping = adev->mman.bdev.dev_mapping` across all `1UL << order` pages and `adev->gart.ptr = page_to_virt(p)`, so `amdgpu_gart_table_ram_free` must clear `p[x].mapping = NULL` on every page before `__free_pages(p, order)` and reset `adev->gart.ptr = NULL`. [F443]
- In `amdgpu_doorbell_create_kernel_doorbells`, after page-aligning `num_kernel_doorbells * sizeof(u32)`, setting `adev->mes.db_start_dw_offset = size / sizeof(u32)`, and adding `PAGE_SIZE` for MES, update `adev->doorbell.num_kernel_doorbells = size / sizeof(u32)`. [F444]
- Keep `amdgpu_kms_driver` and `amdgpu_partition_driver` (`amdgpu_drv.c`) in lockstep on callbacks, `amdgpu_ioctls_kms`, `amdgpu_driver_kms_fops`, PRIME import, and versions, while `amdgpu_partition_driver` omits `DRIVER_ATOMIC`/`DRIVER_MODESET`. Keep `xcp_desc[]`, `amdgpu_gfx_set_compute_partition`, and `amdgpu_gfx_compute_mode_desc` in lockstep when `enum amdgpu_gfx_partition` (`SPX`..`CPX`) changes. [F447, F448]
- In `amdgpu_gfx_cp_init_microcode`, read `gfx_firmware_header_v1_0`/`v2_0` fields with `le32_to_cpu()` and multiply `cp_hdr->jt_size` (dwords) by 4 for byte sizes. `amdgpu_gfx_csb_data_parser` iterates `rlc.cs_data` until `sect->section == NULL` and extents until `ext->extent == NULL`, and with `amdgpu_gfx_csb_preamble_start`/`end` must convert all written PM4 words via `cpu_to_le32()`. [F466, F467]
- In `amdgpu_eeprom_xfer` and `__amdgpu_eeprom_xfer`, adapter `max_read_len`/`max_write_len` quirks must exceed `EEPROM_OFFSET_SIZE` (2) and be reduced by `EEPROM_OFFSET_SIZE`; clamp writes to `EEPROM_PAGE_SIZE - (eeprom_addr & EEPROM_PAGE_MASK)` (256-byte page boundary) and reads to `U16_MAX`. [F458]
- In `extract_render_dcc_offset`, verify `amdgpu_bo_get_metadata` size `>= 40` and `metadata[0] == 1` before reading `metadata[7..9]`, and widen words to `u64` before shifting (`(u64)metadata[9] << 16u`, `(u64)metadata[9] << 8u`, `(u64)(metadata[7] & 0x1FE0000u) << 23`). [F462, F491]
- `amdgpu_pci_probe` must reject `CHIP_RAVEN` with `-ENOTSUPP` when `cc_platform_has(CC_ATTR_MEM_ENCRYPT)` is true. [F536]

## Synchronization

- In `amdgpu_gem_fault()`, `ttm_bo_vm_reserve(bo, vmf)` locks `bo->base.resv` on return `0`; unlock `bo->base.resv` on every exit path except when `ttm_bo_vm_fault_reserved()` or `ttm_bo_vm_dummy_page()` returns `VM_FAULT_RETRY` with `!(vmf->flags & FAULT_FLAG_RETRY_NOWAIT)`. [F385]
- `amdgpu_fence_driver_set_error` must hold `ring->fence_drv.lock` (`spin_lock_irqsave`) while iterating `drv->fences[]`, checking `!dma_fence_is_signaled_locked(fence)`, and calling `dma_fence_set_error(fence, error)`. [F397]
- `amdgpu_gfx_enforce_isolation_ring_begin_use`/`end_use` must unlock `adev->enforce_isolation_mutex` before calling `amdgpu_gfx_kfd_sch_ctrl` (whose work handler `amdgpu_gfx_enforce_isolation_handler` locks `enforce_isolation_mutex`). In `amdgpu_gfx_kfd_sch_ctrl`, when disabling (`!enable`) with `userq_sch_req_count[idx] == 0`, call `cancel_delayed_work_sync(&adev->gfx.enforce_isolation[idx].work)` before checking `userq_sch_inactive[idx]` or incrementing `userq_sch_req_count[idx]`. [F404, F532]
- In `amdgpu_gfx_do_off_ctrl`, disabling GFXOFF (`!enable`) when `gfx_off_req_count == 0` must cancel `gfx_off_delay_work`, and if `gfx_off_state` is true and SMU un-powergating succeeds, clear `gfx_off_state` and call `amdgpu_gfx_init_spm_golden` before incrementing `gfx_off_req_count` under `gfx_off_mutex`. Callers of `amdgpu_gfx_off_ctrl()` and `amdgpu_gfx_off_ctrl_immediate()` must pair every disable (`false`) with an enable (`true`) and never pass `true` when `gfx_off_req_count == 0`. [F390, F427]
- In `amdgpu_display_crtc_page_flip_target` and `amdgpu_display_flip_work_func`, `crtc->dev->event_lock` (`spin_lock_irqsave`) protects `amdgpu_crtc->pflip_status`, `pflip_works`, `crtc->primary->fb`, and the hardware `page_flip` call; initialize `work->shared`, `work->base`, and `work->target_vblank` before scheduling `flip_work`. [F407]
- In `amdgpu_debugfs_gem_info_show`, hold `rcu_read_lock()` while dereferencing `file->pid` via `rcu_dereference`, calling `pid_task(pid, PIDTYPE_TGID)`, and reading `task->comm` under `dev->filelist_mutex`. [F409]

## Object Lifetimes

- Ring fence teardown must run `amdgpu_fence_driver_hw_fini()` (waits/force-completes fences, puts ring IRQ ref, calls `timer_delete_sync(&ring->fence_drv.fallback_timer)`) before `amdgpu_fence_driver_sw_fini()` (stops scheduler, puts and frees `fence_drv.fences[]`). [F379]
- In `amdgpu_pci_remove`, `amdgpu_xcp_dev_unplug`, `amdgpu_gmc_prepare_nps_mode_change`, `drm_dev_unplug`, and `pm_runtime_get_sync` + `pm_runtime_forbid` must run before `amdgpu_driver_unload_kms`, which must complete before `pci_disable_device` and `pci_wait_for_pending_transaction`. [F503]
- In `amdgpu_gem_prime_import()`, if `dma_buf->ops == &amdgpu_dmabuf_ops` and `obj->dev == dev`, return `drm_gem_object_get(obj)` instead of creating a new SG BO or calling `get_dma_buf()`. In `amdgpu_dma_buf_vmap()`/`vunmap()`, pin the BO via `amdgpu_bo_pin()` before `drm_gem_dmabuf_vmap()` and unpin on vmap failure or after `drm_gem_dmabuf_vunmap()`. [F381, F537]
- In `amdgpu_gem_create_ioctl()`, when `AMDGPU_GEM_CREATE_VM_ALWAYS_VALID` is set, reserve `vm->root.bo` before `amdgpu_gem_object_create()`, set `abo->parent = amdgpu_bo_ref(vm->root.bo)` on success, and call `amdgpu_bo_unreserve(vm->root.bo)` on all exit paths. [F383]
- In `amdgpu_display_flip_handle_fence()`, when `fence` is non-NULL, clear `*f = NULL` and either transfer the ref to `amdgpu_display_flip_callback()` (which must call `dma_fence_put(f)`) or drop it via `dma_fence_put(fence)` if already signaled. [F388]
- Connector loops in `amdgpu_encoders.c`, `amdgpu_display.c`, and `amdgpu_runtime_idle_check_display()` must pair `drm_connector_list_iter_begin()` with `drm_connector_list_iter_end()` before returning. [F479]

## API Contracts

- `amdgpu_dma_buf_unmap()` branches on `sg_page(sgt->sgl)`: non-NULL (`TTM_PL_TT` from `drm_prime_pages_to_sg()`) uses `dma_unmap_sgtable()`, `sg_free_table()`, and `kfree()`; NULL (`TTM_PL_VRAM` from `amdgpu_vram_mgr_alloc_sgt()`) uses `amdgpu_vram_mgr_free_sgt()`. [F380]
- `amdgpu_fence_wait_polling` returns remaining positive usecs on success and `0` on timeout, so callers (`amdgpu_fence_emit_polling`, `amdgpu_kiq_rreg`, `amdgpu_kiq_wreg`) must check `r < 1`, and polling must compare sequences via signed `(int32_t)(wait_seq - amdgpu_fence_read(ring)) > 0`. [F414, F483]
- `amdgpu_eeprom_read`/`write` return bytes transferred or negative errno; callers like `amdgpu_fru_get_product_info` must check `len != expected_size` and return `len < 0 ? len : -EIO`. [F415]
- `amdgpu_file_to_fpriv` must check `filp && filp->f_op == &amdgpu_driver_kms_fops` (else `-EINVAL`) before casting `filp->private_data` to `struct drm_file *`. [F421]
- `amdgpu_gem_object_create` takes 1-based `xcp_id_plus1` (`0` sets `bo->xcp_id = -1`); callers with 0-based `xcp_id` (`amdgpu_gem_create_ioctl`, `amdgpu_gem_userptr_ioctl`, `amdgpu_mode_dumb_create`) must pass `xcp_id + 1`. [F423]
- `amdgpu_gem_timeout` takes an absolute `ktime_get()` deadline in ns, returning `MAX_SCHEDULE_TIMEOUT` if `(int64_t)timeout_ns < 0`, `0` if expired, and at most `MAX_SCHEDULE_TIMEOUT - 1` jiffies otherwise. [F426]
- `amdgpu_mm_rdoorbell`/`wdoorbell`/`rdoorbell64`/`wdoorbell64` must check `amdgpu_device_skip_hw_access(adev)` and `index < adev->doorbell.num_kernel_doorbells`. They and `amdgpu_doorbell_index_on_bar` index in 32-bit dwords, so 64-bit qword indices in `adev->doorbell_index` must be shifted left by 1 (`<< 1`, as in `amdgpu_gfx_kiq_init_ring`) or scaled by `DIV_ROUND_UP(db_size, 4)`. [F425, F518]
- In `amdgpu_gart_invalidate_tlb`, run `mb()` and `amdgpu_device_flush_hdp` (under `down_read_trylock(&adev->reset_domain->sem)`) after GART PTE updates and before `amdgpu_gmc_flush_gpu_tlb`. [F516]
- In `amdgpu_fence_driver_hw_fini` and `amdgpu_fence_driver_hw_init`, call `amdgpu_irq_put`/`get` only when `amdgpu_fence_need_ring_interrupt_restore(ring)` is true (false for GFX, compute, KIQ, MES, and SDMA 5.x+ when `adev->in_s0ix`). [F510]
- In `amdgpu_pci_shutdown`, `amdgpu_pmops_prepare`, and `amdgpu_pmops_poweroff`, return early when `adev->in_s4 && adev->in_suspend`. `amdgpu_pmops_prepare` must return `1` when `amdgpu_device_supports_boco(adev) && pm_runtime_suspended(dev)` or when neither S0ix nor S3 is active. [F417, F506]
- `amdgpu_pmops_resume` and `amdgpu_pmops_runtime_resume` must set `adev->no_hw_access = true` when `!pci_device_is_present(adev->pdev)` before `amdgpu_device_resume` or BACO exit. Manual PCI power transitions in `runtime_suspend`/`resume` must run only when `adev->pm.rpm_mode == AMDGPU_RUNPM_PX`. On BACO-capable Navi10+ dGPUs, `amdgpu_pci_probe` must call `amdgpu_get_secondary_funcs`. [F504, F507, F508]

## Error Handling

- In `amdgpu_gem_op_ioctl` and `amdgpu_gem_list_handles_ioctl`, translate non-zero `copy_to_user` returns to `-EFAULT`. [F413]
- In `amdgpu_gem_create_ioctl`, `amdgpu_gem_mmap_ioctl`, and `amdgpu_gem_wait_idle_ioctl`, read `args->in` first, then `memset(args, 0, sizeof(*args))` before populating `args->out`. [F422]
- On `-ERESTARTSYS` (in `amdgpu_gem_create_ioctl`, `amdgpu_gem_va_update_vm`, `extract_render_dcc_offset`, `amdgpu_display_get_fb_info`), do not log `DRM_ERROR()` or retry domains. In `amdgpu_gem_create_ioctl()`, when `amdgpu_gem_object_create()` fails with `r != -ERESTARTSYS`, the `retry:` fallback must clear `AMDGPU_GEM_CREATE_CPU_ACCESS_REQUIRED` before widening `AMDGPU_GEM_DOMAIN_VRAM` with `AMDGPU_GEM_DOMAIN_GTT`. [F470, F551]

## External Contracts

- `amdgpu_gem_prime_export()` must reject userptr BOs (`amdgpu_ttm_tt_get_usermm(bo->tbo.ttm)`) and `AMDGPU_GEM_CREATE_VM_ALWAYS_VALID` BOs with `ERR_PTR(-EPERM)`. `amdgpu_gem_object_mmap()` and `amdgpu_mode_dumb_mmap()` must reject userptr BOs and `AMDGPU_GEM_CREATE_NO_CPU_ACCESS` BOs with `-EPERM`. [F541, F543]
- In `amdgpu_gem_userptr_ioctl()`, apply `untagged_addr(args->addr)`, require page-aligned `addr` and `size`, and require `AMDGPU_GEM_USERPTR_REGISTER` (else `-EACCES`) when `!(args->flags & AMDGPU_GEM_USERPTR_READONLY)`. [F547]
- In `amdgpu_gem_metadata_ioctl` (`AMDGPU_GEM_METADATA_OP_SET_METADATA`), reject `args->data.data_size_bytes > sizeof(args->data.data)` with `-EINVAL`. [F452]
- In `amdgpu_gem_op_ioctl` (`AMDGPU_GEM_OP_GET_MAPPING_INFO`) and `amdgpu_gem_list_handles_ioctl`, overwrite `args->num_entries` with the total count and return `0` without copying if it exceeds the input capacity. [F454]
- In `amdgpu_gem_va_ioctl()`, reject `args->flags` only when both `(args->flags & ~valid_flags)` and `(args->flags & ~prt_flags)` are non-zero, and look up `args->handle` only when `args->operation != AMDGPU_VA_OP_CLEAR && !(args->flags & AMDGPU_VM_PAGE_PRT)`. [F469]

## Known Pitfalls

- Use `size_mul()` when computing byte lengths for `memdup_user()` from user `uint32_t` counts (e.g., `num_syncobj_handles` in `amdgpu_gem_add_input_fence()`). [F497]
- `amdgpu_display_flip_work_func` must compare vblank via signed `(int)(work->target_vblank - amdgpu_get_vblank_counter_kms(crtc)) > 0`. `amdgpu_gfx_enforce_isolation_wait_for_kfd` must check `time_after(cjiffies, adev->gfx.enforce_isolation_jiffies[idx])` and `jiffies_to_msecs(cjiffies) >= GFX_SLICE_PERIOD_MS` before subtracting to avoid underflow. [F484, F493]
- Use 64-bit shifts in `amdgpu_gfx_create_bitmask` (`(u32)((1ULL << bit_width) - 1)`) and `amdgpu_gfx_enable_kcq` (`1ull << amdgpu_queue_mask_bit_to_set_resource_bit(adev, i)`). [F486, F487]
- In `amdgpu_display_verify_plane`, fall back to `1` for `format->hsub`/`vsub`/`cpp[plane]` when `plane >= format->num_planes`, use `DIV_ROUND_UP(height, block_height)`, and cast `rfb->base.pitches[plane]` to `uint64_t` before multiplying. In `amdgpu_mode_dumb_create`, use `DIV_ROUND_UP(args->bpp, 8)` and `(u64)args->pitch * args->height`. [F489, F490, F492]
