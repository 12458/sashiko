# BLOCK LAYER — drivers/block

A collection of virtual, test, and platform-specific block device drivers: the highly configurable `null_blk` test/benchmarking driver (supporting memory-backed storage, writeback caching, zoned block device emulation, badblocks, bandwidth throttling, and fault injection), the Xen paravirtualized frontend block driver (`xen-blkfront.c`), the Sun LDOM Virtual Disk Client driver (`sunvdc.c`), the Sony PS3 storage disk driver (`ps3disk.c`), Apple Macintosh SWIM/SWIM3 floppy drivers (`swim.c`, `swim3.c`), the Nintendo 64 cartridge ROM block driver (`n64cart.c`), and the Amiga Zorro II/Chip RAM disk driver (`z2ram.c`).

## Architecture & Data Flow

- `rinfo->persistent_gnts_c` counts only `struct grant` entries on `rinfo->grants` with `gref != INVALID_GRANT_REF`: `get_free_grant()`, `purge_persistent_grants()`, and `blkif_free_ring()` decrement it when removing or revoking a valid `gref`, while `blkif_completion()` increments it only when `!gnttab_try_end_foreign_access()`. [F622]
- Whenever a sequential zone is reset or restored to `BLK_ZONE_COND_EMPTY` (in `null_reset_zone()` and `null_set_zone_cond()`), `zone->wp` must be reset to `zone->start` and, if `dev->memory_backed` is true, `null_handle_discard(dev, zone->start, zone->len)` must be called. [F674]
- When writing directly to `dev->data` with `is_fua` set in `copy_to_nullb()` or discarding sectors in `null_handle_discard()` while `null_cache_active(nullb)` is true, `null_free_sector(nullb, sector, true)` must be called to invalidate any cached copy of that sector in `dev->cache`. [F677]
- `blkif_ring_get_request()` must set `rinfo->shadow[id].request = req` and `rinfo->shadow[id].req.u.rw.id = id` after calling `get_id_from_freelist()`, because `add_id_to_freelist()` requires `rinfo->shadow[id].req.u.rw.id == id` and `rinfo->shadow[id].request != NULL` before chaining `id` back into `rinfo->shadow_free`. [F684]
- Both `vdc_end_one()` and `vdc_requeue_inflight()` must unmap `desc->cookies` via `ldc_unmap()`, set `desc->hdr.state = VIO_DESC_FREE`, advance `dr->cons = vio_dring_next(dr, idx)`, and clear `rqe->req = NULL` (or call `vdc_end_special()` when `rqe->req == NULL`). [F687]
- Because internal and external drives share `swd->base` MMIO registers in `swim.c`, operations on a `struct floppy_state` must select `fs->location` via `swim_drive(base, fs->location)` before issuing drive commands, and `swim_track()` must reset `fs->track = 0` after calling `swim_track00(base)` if `swim_seek()` fails. [F688]
- In `swim3.c`, every state transition out of a timed state in `swim3_interrupt()` must call `timer_delete(&fs->timeout)` and clear `fs->timeout_pending = 0`, and `floppy_open()` (when `fs->ref_count == 0`) and `floppy_revalidate()` must reset both `fs->cur_cyl = -1` and `fs->write_prot = -1`. [F689]
- In `z2_open()`, `current_device` must be checked under `z2ram_mutex` to reject opening a different minor device while active, and `z2ram_size` (which counts `Z2RAM_CHUNKSIZE` entries while populating `z2ram_map[]`) must be left-shifted by `Z2RAM_CHUNKSHIFT` into bytes before setting disk capacity. [F690]

## Synchronization

- `null_insert_page()` is entered with `nullb->lock` held (`__releases(&nullb->lock) __acquires(&nullb->lock)`), drops `nullb->lock` to call `null_alloc_page()` and `radix_tree_preload(GFP_NOIO)`, and must reacquire `spin_lock_irq(&nullb->lock)` on every exit path while pairing a successful `radix_tree_preload()` with `radix_tree_preload_end()`. [F617]
- In `null_blk`, `struct nullb_zone` uses a union of `spinlock` and `mutex` discriminated by `dev->memory_backed`: zone locking must use `null_init_zone_lock()`, `null_lock_zone()`, and `null_unlock_zone()` so memory-backed devices use `zone->mutex` (allowing page-allocation sleeps) while non-memory-backed devices use `zone->spinlock`. [F634]
- For `HCTX_TYPE_POLL` queues in `null_blk`, `nq->poll_lock` protects `nq->poll_list`; `null_poll()` must mark spliced requests complete via `blk_mq_set_request_complete()` before unlocking `nq->poll_lock`, and `null_timeout_rq()` must check `blk_mq_request_completed()` under `nq->poll_lock` before removing or completing `rq`. [F641]
- For non-poll queues in `null_blk`, `null_timeout_rq()` must only call `blk_mq_complete_request()` when `cmd->fake_timeout` is true, and `null_handle_cmd()` must only assign `cmd->error = sts` when `cmd->error == BLK_STS_OK` so real timeout errors (`BLK_STS_TIMEOUT`) are completed by the submission path without being overwritten. [F642]
- In `null_handle_throttled()`, after `atomic_long_sub_return()` drops `nullb->cur_bytes` below zero and `blk_mq_stop_hw_queues()` is called, `atomic_long_read(&nullb->cur_bytes) > 0` must be rechecked to restart queues if `nullb_bwtimer_fn()` refilled credits concurrently. [F643]
- In `xen-blkfront`, the lock acquisition hierarchy in `blkfront_delay_work()` and `purge_persistent_grants()` is `blkfront_mutex` -> `info->mutex` -> `rinfo->ring_lock`; code holding `rinfo->ring_lock` must never acquire `info->mutex` or `blkfront_mutex`. [F645]
- In `blkif_queue_discard_req()` and `blkif_queue_rw_req()`, all grant mappings and `rinfo->shadow[id]` fields must be populated under `rinfo->ring_lock` before copying `rinfo->shadow[id].req` into `*final_ring_req`, setting `rinfo->shadow[id].status = REQ_WAITING`, and publishing via `flush_requests()`. [F647]
- When `xlbd_reserve_minors()` allocates a larger `bitmap` with `GFP_KERNEL` outside `minor_lock` because `end > nr_minors`, it must re-check `end > nr_minors` after acquiring `minor_lock` before copying and replacing `minors` and `nr_minors`. [F648]

## Object Lifetimes

- `null_free_page()` always sets `NULLB_PAGE_FREE` in `t_page->bitmap`, but if `NULLB_PAGE_LOCK` is set (by `null_make_cache_space()` before `null_flush_cache_page()` drops `nullb->lock`), `null_free_page()` must return without freeing `t_page->page` or `t_page` so `null_flush_cache_page()` can free `c_page` after clearing `NULLB_PAGE_LOCK`. [F616]
- `null_free_zoned_dev()` must set `dev->zones = NULL` after `kvfree(dev->zones)`, and `null_add_dev()` error cleanup and `null_del_dev()` must set `dev->nullb = NULL` after `kfree(nullb)`, because `dev` outlives power cycles in configfs and both `null_free_dev()` and configfs store handlers test those pointers. [F619]
- In `blkif_queue_rw_req()`, whenever `new_persistent_gnts` is true (`gnttab_alloc_grant_references()` succeeded), `gnttab_free_grant_references(setup.gref_head)` must be called before returning to release any grant references from `max_grefs` not claimed by `get_grant()` or `get_indirect_grant()`. [F621]
- When `!info->bounce` and `info->max_indirect_segments` is non-zero, `get_indirect_grant()` pops a pre-allocated `struct page` from `rinfo->indirect_pages` into `gnt_list_entry->page`, and `blkif_completion()` must return `s->indirect_grants[i]->page` to `rinfo->indirect_pages` whenever `gnttab_try_end_foreign_access()` succeeds. [F624]
- In `blkif_free_ring()` and `blkfront_closing()`, `gnttab_cancel_free_callback(&rinfo->callback)` must be called before `flush_work(&rinfo->work)`, and `flush_work(&rinfo->work)` must be called with no locks held before tearing down the ring in `blkif_free_ring()`. [F626]
- In `vdc_port_mpgroup_check()`, a non-NULL `struct device *dev` returned by `device_find_child()` holds a reference acquired via `get_device()` and must be released with `put_device(dev)` before returning. [F627]
- In `generic_request()`, `port->vio.cmp` points to the stack-allocated `struct vio_completion comp`, so if `__vdc_tx_trigger(port)` returns an error (`err < 0`) and `generic_request()` does not wait on `comp.com`, it must clear `port->vio.cmp = NULL` before unlocking `port->vio.lock` and returning. [F628]
- `ps3disk_probe()` reserves a `devidx` bit in `ps3disk_mask` under `ps3disk_mask_mutex` before allocating `priv`, `dev->bounce_buf`, `ps3stor_setup()`, `priv->tag_set`, and `gendisk`, and both `ps3disk_probe()` error paths and `ps3disk_remove()` must unwind these in reverse order and clear the `devidx` bit under `ps3disk_mask_mutex`. [F631]

## API Contracts

- In `null_radix_tree_insert()`, if `radix_tree_insert()` fails because an entry already exists at `idx`, `null_radix_tree_insert()` consumes and frees the caller-supplied `t_page` via `null_free_page(t_page)` and returns the existing `struct nullb_page *` from `root` without incrementing `nullb->dev->curr_cache`. [F615]
- `null_zone_valid_read_len()` reads `zone->type` and `zone->wp` without taking the zone lock and may only be called when the target `struct nullb_zone` is already locked by the caller via `null_lock_zone()`. [F638]
- In `null_poll`, the third argument to `blk_mq_add_to_batch` must be a boolean expression indicating whether the request failed (`cmd->error != BLK_STS_OK`), and if `blk_mq_add_to_batch` returns `false`, `null_poll` must complete the request immediately via `blk_mq_end_request(req, cmd->error)`. [F655]
- In `n64cart.c`, `reg_base` is a `u32 __iomem *` indexed by word-offset enum constants (`PI_DRAM_REG` through `PI_STATUS_REG`), and `n64cart_do_bvec` must write `bv->bv_len - 1` (not `bv->bv_len`) to `PI_WRITE_REG` to transfer `bv->bv_len` bytes. [F670]
- In `generic_request()`, the LDC DMA buffer allocation and mapping length `op_len` must be rounded up to an 8-byte multiple (`(op_len + 7) & ~7`), while the caller's copy length `len` must be clamped to `<= op_len` before `memcpy()` into or out of `req_buf`. [F703]
- In `null_check_zone_resources`, `case BLK_ZONE_COND_EMPTY:` must check `null_check_active(dev)` and then fall through to `case BLK_ZONE_COND_CLOSED:` to check `null_check_open(dev)`, whereas `BLK_ZONE_COND_CLOSED` must only check `null_check_open(dev)` because a closed zone is already counted as active. [F710]
- In `null_set_zone_cond`, requesting `cond` (`BLK_ZONE_COND_READONLY` or `BLK_ZONE_COND_OFFLINE`) on a zone already in `zone->cond == cond` must toggle the zone back to `BLK_ZONE_COND_EMPTY` at `zone->wp = zone->start`, whereas transitioning from a normal state must call `null_finish_zone` first. [F713]

## Error Handling

- When `null_handle_badblocks` detects a bad block, it returns `BLK_STS_IOERR` while setting `*nr_sectors` to the partial I/O sector count (`0` unless `dev->badblocks_partial_io` is set), so `null_process_cmd` and `null_zone_write` must still transfer any non-zero `nr_sectors` before returning `badblocks_ret`. [F656]
- Because `blk_mq_update_nr_hw_queues` returns `void`, `nullb_update_nr_hw_queues` must detect failure by checking `set->nr_hw_queues == nr_hw_queues` afterward, and on mismatch must restore `dev->submit_queues` and `dev->poll_queues` from `dev->prev_submit_queues` and `dev->prev_poll_queues` and return `-ENOMEM`. [F660]
- In `xen-blkfront.c`, `blkif_completion` returns `0` when a split request (`s->associated_id != NO_ASSOCIATED_ID`) awaits its sibling response (`s2->status < REQ_DONE`), `1` when complete (updating `*id` if responses arrived out of order), and `-1` on a grant error; `blkif_interrupt` must `continue` on `0` and jump to `err` on `< 0`. [F664]
- In `xlvbd_alloc_gendisk` and `probe_disk`, the `struct gendisk *` returned by `blk_mq_alloc_disk` must be checked with `IS_ERR` in a local variable before being stored into `info->gd` or `port->disk`, because `blkfront_remove` and `vdc_blk_queue_start` test those fields for non-NULL rather than `IS_ERR_OR_NULL`. [F671]
- In `blkif_interrupt()`, before indexing `rinfo->shadow[id]` or completing a request, the handler must verify `!RING_RESPONSE_PROD_OVERFLOW(&rinfo->ring, rp)`, copy the response into local memory via `RING_COPY_RESPONSE()`, and check that `bret.id < BLK_RING_SIZE(info)`, `rinfo->shadow[id].status == REQ_WAITING`, and `bret.operation == op`. [F697]
- In `vdc_ack()`, incoming LDC `VIO_SUBTYPE_ACK` packets must be ignored unless `pkt->dring_ident == dr->ident`, `pkt->start_idx == pkt->end_idx`, and `pkt->start_idx < VDC_TX_RING_SIZE` before `vdc_end_one()` uses `pkt->start_idx` to index `port->rq_arr[]` and `vio_dring_entry()`. [F701]
- In `vdc_handle_attr()`, an attribute ACK with `pkt->vdisk_block_size > port->vdisk_block_size` must be rejected with `-ECONNRESET` and `port->max_xfer_size` must only be updated when `pkt->max_xfer_size < port->max_xfer_size`, preventing the peer from increasing transfer sizes beyond the `MAX_RING_COOKIES` limit. [F702]

## External Contracts

- In `write_per_ring_nodes()` and `talk_to_blkback()`, single-page rings (`nr_ring_pages == 1`) must write Xenbus key `"ring-ref"` whereas multi-page rings write `"ring-page-order"` and `"ring-ref%u"`, and single-queue devices (`nr_rings == 1`) must write ring keys directly under `dev->nodename` rather than `"%s/queue-%u"`. [F700]
- In `n64cart_do_bvec`, `n64cart_wait_dma()` must poll `PI_STATUS_REG` until both `PI_STATUS_DMA_BUSY` and `PI_STATUS_IO_BUSY` clear both before writing `PI_DRAM_REG`, `PI_CART_REG`, and `PI_WRITE_REG` (`bv->bv_len - 1`) and after writing `PI_WRITE_REG` before calling `dma_unmap_page`. [F755]
- In `swim3.c`, when stopping DBDMA on transfer timeout in `xfer_timeout`, after writing `out_le32(&dr->control, RUN << 16)`, the driver must poll `in_le32(&dr->status) & ACTIVE` (up to 1000 iterations of `udelay(1)`) before clearing `WRITE_SECTORS | DO_ACTION` in `sw->control_bic`. [F762]
- In `swim3_interrupt` (`do_transfer` case), when `(intr & ERROR_INTR) == 0 && cp->xfer_status == 0`, the handler must poll `cp->xfer_status` for up to 100 iterations of `udelay(1)` with `barrier()` before turning off DBDMA via `out_le32(&dr->control, (RUN | PAUSE) << 16)` and reading `cp->xfer_status` and `cp->res_count`. [F763]
- In `swim3.c`, all physical addresses programmed into DBDMA `cmdptr` or `struct dbdma_cmd.phy_addr` must be translated via `swim3_phys_to_bus` (`paddr + PCI_DRAM_OFFSET`) and stored little-endian (`out_le32` / `cpu_to_le32`), with `fs->dma_cmd` aligned via `DBDMA_ALIGN` and terminated by a `DBDMA_STOP` command. [F764]
- In both `swim.c` (`floppy_ioctl`) and `swim3.c` (`floppy_locked_ioctl`), any ioctl command with bit `0x80` set (`cmd & 0x80`) must check `capable(CAP_SYS_ADMIN)` and return `-EPERM` if the caller lacks the capability. [F796]

## Known Pitfalls

- In `memb_group_features_show()`, the loop over the `NULL`-terminated `nullb_device_attrs` array must check `ret >= left` after `snprintf(page + written, left, ...)` and return `-ENOBUFS` before subtracting `ret` from `left`. [F696]
- Because `struct blkfront_ring_info` ends with a flexible array `struct blk_shadow shadow[]` sized at runtime to `BLK_RING_SIZE(info)`, elements of `info->rinfo` are spaced by `info->rinfo_size` bytes and must be accessed via `get_rinfo()` or `for_each_rinfo()`, never via `info->rinfo[i]`. [F698]
- In `ps3disk_identify()`, `dev->bounce_buf` must be byte-swapped via `swap_buf_le16(id, ATA_ID_WORDS)` before `ata_id_n_sectors()` or `ata_id_c_string()`, and `ata_id_c_string()` must be passed an odd `len` (`len & 1`) so `len - 1` is an even byte count for `ata_id_string()`. [F706]
- In `drivers/block/swim3.c`, `act` runs an infinite `for (;;)` loop over `fs->state` in which branches that transition `fs->state` synchronously use `break` to re-evaluate immediately, whereas branches that initiate asynchronous hardware operations or timers (`scan_track`, `seek_track`, `settling`, `setup_transfer`) must `return`. [F724]
- When converting megabyte counts stored in `unsigned long` (`dev->size`, `dev->zone_size`, `dev->zone_capacity`) to 512-byte sectors in `mb_to_sects()` and `null_add_dev()`, the operand must be cast to 64-bit `sector_t` before multiplying by `SZ_1M` so sizes of 4096 MB or larger do not overflow 32-bit `unsigned long`. [F726]
- In `null_handle_badblocks()`, `sector < first_bad` must be checked after `first_bad` is rounded down with `ALIGN_DOWN(first_bad, block_sectors)` before computing `partial_io_sectors = first_bad - sector`. [F729]
- In `null_init_zoned_dev()`, `dev->zone_nr_conv` must be clamped to `dev->nr_zones - 1` before evaluating `dev->nr_zones - dev->zone_nr_conv` to bound `dev->zone_max_active` and `dev->zone_max_open`. [F732]
- In `swim3_queue_rq()`, `blk_rq_pos(req)` must be cast to `long` before dividing or taking modulo by `fs->secpercyl` so 32-bit PowerPC builds do not emit a 64-by-32-bit division. [F735]
