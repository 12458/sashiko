# BLOCK LAYER — block (part 2)

The multiqueue block layer (`blk-mq`) core and request management subsystem handles software (`blk_mq_ctx`) and hardware (`blk_mq_hw_ctx`) queue lifecycles, bitmap tag allocation, elevator scheduling dispatch, DMA/scatterlist mapping, queue limits validation and stacking, request QoS and writeback throttling (`blk-rq-qos.c`, `blk-wbt.c`), zoned write plugging, runtime power management, timeouts, and sysfs configuration.

## Architecture & Data Flow

- Unmapped `blk_mq_hw_ctx` has `nr_ctx == 0` and `tags == NULL`; check `blk_mq_hw_queue_mapped(hctx)` before accessing `hctx->tags`. Index `hctx->ctxs[]` and `hctx->ctx_map` by `ctx->index_hw[hctx->type]`, never `ctx->cpu`. `blk_mq_update_queue_map()` must zero `set->map[i]` via `blk_mq_clear_mq_map()` before `map_queues()`, and `blk_mq_map_swqueue()` must never free `set->tags[0]`. [F275, F291, F316]
- In `blk_mq_tags`, `rqs[]` and `static_rqs[]` map `[0, nr_reserved_tags)` to `breserved_tags` and `[nr_reserved_tags, nr_tags)` to `bitmap_tags` (offset `bitmap_tags` indices by `nr_reserved_tags`). Changing `tags->active_queues` under `tags->lock` in `__blk_mq_tag_busy()` / `__blk_mq_tag_idle()` requires `blk_mq_update_wake_batch()`. `blk_mq_alloc_tag_set()` caps `queue_depth` to `BLK_MQ_MAX_DEPTH` (`<= 1 << BLK_MQ_UNIQUE_TAG_BITS`). `blk_mq_alloc_rqs()` rounds request size to `cache_line_size()` and stores page order in `page->private`. [F293, F315, F358, F360]
- `queue_requests_store()` rejects `nr <= set->reserved_tags` (and `> MAX_SCHED_RQ` with elevator or `> set->queue_depth` without). In `blk_mq_update_nr_requests()`, growing non-shared `sched_tags` must update both every `hctx->sched_tags` and `q->elevator->et`, calling `ops.depth_updated(q)` only after `q->nr_requests = nr`. [F288, F314]
- Check `RQF_SPECIAL_PAYLOAD` (`rq->special_vec`) and `rq->bio != NULL` before dereferencing `rq->bio`. On partial completion (`req->bio != NULL`), `blk_update_request()` must update `__data_len`, `__sector` (unless passthrough), `REQ_FAILFAST_MASK` (if `RQF_MIXED_MERGE`), and `nr_phys_segments` (unless `RQF_SPECIAL_PAYLOAD`). `blk_rq_prep_clone()` copies `nr_phys_segments`, `nr_integrity_segments`, `__sector`, `__data_len`, and `RQF_SPECIAL_PAYLOAD`. `__blk_mq_requeue_request()` on started `rq` resets `state = MQ_RQ_IDLE`, clears `RQF_TIMED_OUT`, puts driver tag, and calls `rq_qos_requeue()`. `blk_mq_extract_queue_requests()` must update `rqs->tail = last`. [F277, F294, F295, F296, F333]
- `rq_qos_add()` sets `QUEUE_FLAG_QOS_ENABLED` while frozen; `rq_qos_del()` (when `q->rq_qos` is empty) and `rq_qos_exit()` clear it. `blk_set_queue_depth()` must call `rq_qos_queue_depth_changed(q)`. Outside WBT callbacks, use `wbt_rq_qos(q)` before `RQWB()`. `wbt_enable_default()` / `wbt_disable_default()` only change `WBT_STATE_*_DEFAULT` under `rqos_state_mutex`. Never dereference `rwb->sync_cookie`; clear it and `sync_issue` in `wbt_done()` / `wbt_requeue()`. [F220, F307, F308, F309, F365]
- Zone append emulation (`blk_zone_wplug_prepare_bio()`) sets `REQ_OP_WRITE | REQ_NOMERGE` and `BIO_EMULATES_ZONE_APPEND`, restored/cleared in `blk_zone_write_plug_bio_endio()`; on BIO error, call `disk_zone_wplug_abort()` and set `BLK_ZONE_WPLUG_NEED_WP_UPDATE` under `zwplug->lock` until `disk_zone_wplug_set_wp_offset()`. Balance the `q_usage_counter` ref from `disk_zone_wplug_add_bio()` via `blk_queue_exit(q)` on merge, abort, cached-rq reuse, or bio-based submit. [F299, F300, F301]
- `blkdev_zone_mgmt()` and `blkdev_truncate_zone_range()` check `sector + nr_sectors <= sector` and `> capacity`, allowing unaligned `nr_sectors` only at `capacity`. `disk_zone_is_full()` uses `last_zone_capacity` on the last zone and `zone_capacity` otherwise. `blk_zone_cond_str()` checks bounds and `!= NULL`. [F319, F320, F321]
- `blk_validate_limits()` recomputes derived limits and clears `BLK_FEAT_FUA` if `!BLK_FEAT_WRITE_CACHE`; `queue_limits_commit_update()` rejects integrity tags when `q->crypto_profile` is set. `blk_validate_atomic_write_limits()` zeroes derived `atomic_write_*` limits if disabled, `0`/`UINT_MAX`, or invalid (e.g. `> chunk_sectors`). Guard `sector_div()` with `!lim->max_discard_sectors` in `queue_limit_discard_alignment()` and `% t->discard_granularity` with `if (b->discard_granularity)` in `blk_stack_limits()`. `blk_apply_bdi_limits()` never reduces `bdi->ra_pages`. [F303, F305, F306, F353, F383]
- `QUEUE_FLAG_STATS` is updated under `q->stats->lock` and cleared only when `callbacks` is empty and `!accounting`. `blk_pm_mark_last_busy()` skips `RQF_PM` (`BLK_MQ_REQ_PM`) requests. [F310, F387]

## Synchronization

- Never call `blk_mq_freeze_queue()` (or `elevator_set_none()`) while quiesced via `blk_mq_quiesce_queue()`; freeze must precede quiesce. All dispatch paths must run inside `__blk_mq_run_dispatch_ops()` (`srcu_read_lock` if `BLK_MQ_F_BLOCKING`, else `rcu_read_lock()`), pairing with `blk_mq_wait_quiesce_done()`. [F250, F390]
- Queue state barriers/rechecks: `blk_mq_run_hw_queue()` rechecks `blk_mq_hw_queue_need_run(hctx)` under `q->queue_lock` when lockless check is false; `blk_mq_hctx_stopped()` runs `smp_mb()` and retests `BLK_MQ_S_STOPPED` (pairing with `smp_mb__after_atomic()` in `blk_mq_start_stopped_hw_queue()`); `blk_mq_dispatch_rq_list()` splices to `hctx->dispatch` under `hctx->lock` and runs `smp_mb()` before `blk_mq_sched_needs_restart(hctx)` (pairing with `__blk_mq_sched_restart()`). [F251, F263, F264]
- `blk_mq_mark_tag_wait()` locks `wq->lock` before `hctx->dispatch_wait_lock` and runs `smp_mb()` before `blk_mq_get_driver_tag()`. After `io_schedule()` in `blk_mq_get_tag()`, reload `ctx`/`hctx`/`tags`/`bt` (waking `bt_prev` if changed) and put the tag if `BLK_MQ_S_INACTIVE` is set. `blk_mq_find_and_get_req()` in `bt_iter()` verifies `rq != NULL`, `rq->tag == bitnr`, `req_ref_inc_not_zero(rq)`, and `rq->q == q`. [F258, F260, F262]
- `blk_mq_timeout_work()` uses `percpu_ref_tryget(&q->q_usage_counter)` (never `blk_queue_enter()`), and if `blk_mq_check_expired()` finds an expired `rq`, calls `blk_mq_wait_quiesce_done()` and resets `expired.next = 0` before `blk_mq_handle_expired()`. `blk_mq_remove_hw_queues_cpuhp()` splices `unused_hctx_list` under `unused_hctx_lock` rather than holding it under `blk_mq_cpuhp_lock`. `blk_mq_complete_send_ipi()` requires `!force_irqthreads()` and `cpu_online()`, and `blk_mq_raise_softirq()` requires `preempt_disable()`. [F254, F259, F338, F393]
- `queue_limits_start_update()` locks `q->limits_lock`; `queue_limits_commit_update()` / `_frozen()` require `limits_lock` (and a frozen queue on live queues, as in `queue_ra_store()`) and always unlock it, so call `queue_limits_cancel_update()` only when aborting before commit. [F225, F405]
- In `rq_qos_wait()`, if the first waiter gets a token after `prepare_to_wait_exclusive()`, call `finish_wait()` then `cleanup_cb()` if `data.got_token` is set; in `rq_qos_wake_function()`, `list_del_init_careful(&curr->entry)` must be last. `blk_throtl_activated()` checks both `q->td` and `blkcg_policy_enabled()`. `blk_stat_add()` uses `rcu_read_lock()` + `get_cpu()`, and `blk_stat_remove_callback()` uses `list_del_rcu()` under `stats->lock` and `timer_delete_sync()` before `call_rcu()`. [F221, F241, F366, F404]

## Object Lifetimes

- `blk_register_queue()` sets `QUEUE_FLAG_INIT_DONE` and switches `q_usage_counter` to percpu mode last. `blk_unregister_queue()` clears `QUEUE_FLAG_REGISTERED` under `sysfs_lock` and removes child sysfs before deleting `queue_kobj` and `elevator_set_none()`. `blk_mq_destroy_queue()` requires `!blk_queue_registered(q)`, drains/freezes `q`, cancels timers/works (`blk_sync_queue()`, `blk_mq_cancel_work_sync()`) before `blk_mq_exit_queue()`, and leaves `blk_put_queue()` to caller. In `blk_mq_exit_queue()`, `blk_mq_exit_hw_queues()` must precede `blk_mq_del_queue_tag_set()`. [F246, F372, F373, F376]
- `blk_mq_unregister_hctx()` checks `state_in_sysfs` before `kobject_del()`. `blk_mq_ctx_sysfs_release()` puts `ctxs->kobj` so `blk_mq_sysfs_release()` frees `ctxs` only after all `ctx->kobj` are put. `blk_mq_alloc_and_init_hctx()` reuses `unused_hctx_list` entries only if `blk_mq_hctx_is_reusable(hctx)`. [F217, F218, F227]
- Before freeing request pages (`blk_mq_free_rqs()`) or `hctx->fq` (`blk_mq_exit_hctx()`), run `exit_request()`, clear `static_rqs[i]`, and clear `drv_tags->rqs[]` via `blk_mq_clear_rq_mapping()` / `_flush_rq_mapping()` before `call_srcu(&set->tags_srcu, ...)`. `blk_mq_free_tag_set()` calls `srcu_barrier(&set->tags_srcu)` before `cleanup_srcu_struct()`. [F228, F397]
- Release crypto keyslots (`blk_crypto_rq_put_keyslot()`) before completing BIOs and save `bio->bi_next` before `bio_endio()`. Cloned requests (`blk_rq_prep_clone()`) must complete before `@rq_src`. Balance `blk_mq_get_dispatch_budget()` with `blk_mq_put_dispatch_budget()` (and `blk_mq_delay_run_hw_queues()` if `!rq`) or `blk_mq_release_budgets()`. `blk_pre_runtime_suspend()` sets `pm_only` and switches `q_usage_counter` to atomic mode before checking `percpu_ref_is_zero()`, clearing `pm_only` on `-EBUSY`, suspend error, or resume. [F232, F234, F239, F334, F340, F385, F418]

## API Contracts

- `__blk_mq_alloc_disk()`, `blk_mq_alloc_queue()`, `blk_mq_alloc_request()`, and `blk_mq_alloc_request_hctx()` (requires `BLK_MQ_REQ_NOWAIT | BLK_MQ_REQ_RESERVED`) return `ERR_PTR()`; `blk_mq_alloc_disk_for_queue()`, `__blk_mq_alloc_requests()`, `blk_mq_alloc_cached_request()`, and `blk_mq_get_new_requests()` return `NULL`. `blk_mq_get_tag()` returns `BLK_MQ_NO_TAG` (`-1U`) on failure; `blk_mq_get_tags()` returns `0`. [F267, F268, F269, F285]
- `blk_mq_alloc_tag_set()` requires `queue_rq`, paired `get_budget`/`put_budget`, and `map_queues` if `nr_maps > 1`. Never call `blk_mq_run_hw_queue(hctx, false)` in `in_interrupt()` or atomic context with `BLK_MQ_F_BLOCKING`. Dispatch loops must call `blk_mq_commit_rqs()` on leftover requests, `ret != BLK_STS_OK`, or `hctx` switch. CPU hotplug checks use `blk_mq_map_queue_type()`, not `hctx->cpumask`. [F331, F392, F407, F410]
- `__blk_rq_map_sg()` and `blk_rq_map_integrity_sg()` require `blk_rq_nr_phys_segments(rq)` / `nr_integrity_segments` entries and `*last_sg = NULL`. Passthrough and `REQ_OP_FLUSH` bypass `q->elevator` via `blk_mq_request_bypass_insert()`, and passthrough skips `rq_qos_done()` and `RQF_STATS`. `cb->bucket_fn(rq)` returns `< 0` or `< cb->buckets`. [F284, F318, F324, F327, F427]
- `blk_set_default_limits()` sets `max_user_discard_sectors` / `max_user_wzeroes_unmap_sectors` to `UINT_MAX`; `blk_set_stacking_limits()` sets `atomic_write_hw_max = UINT_MAX`. `blk_stack_limits()` and `bdev_alignment_offset()` return `-1` on misalignment. `blk_validate_limits()` checks page/segment/DMA bounds and rejects zoned limits without `BLK_FEAT_ZONED` / `CONFIG_BLK_DEV_ZONED`. `atomic_write_hw_*` / `_unit_*` are in bytes; `atomic_write_*_sectors` are in sectors. Sysfs `.store` returns count; `.store_limit` returns `0`. [F270, F272, F283, F287, F382, F412]

## Error Handling

- `blk_mq_init_tags()` initializes `tags->page_list`, and `blk_mq_alloc_rqs()` clears `static_rqs[i] = NULL` if `blk_mq_init_request()` fails. Error paths in `blk_mq_init_allocated_queue()` and `blk_mq_init_sched()` reset `q->mq_ops` and `q->elevator` (and teardown `sched_tags`) to `NULL`. [F278, F279]
- Call `blk_mq_bio_issue_init()` after splitting/integrity prep and before bio merge in `blk_mq_submit_bio()`. `blk_update_request()` skips error logging/tracing if passthrough, `RQF_QUIET`, or `GD_DEAD`. `blk_insert_cloned_request()` returns `BLK_STS_NOTSUPP` silently if `max_sectors == 0`. [F282, F425, F426]

## Known Pitfalls

- Initialize new `struct request` fields in both `blk_mq_rq_ctx_init()` (no `memset()`) and `blk_rq_init()`. Clear `RQF_USE_SCHED` after `ops.finish_request(rq)`. Pop `plug->cached_rqs` before `rq_qos_throttle()` in `blk_mq_use_cached_rq()` and zero `plug->rq_count` upfront in `blk_mq_flush_plug_list()`. [F261, F297, F362]
- In `blk_mq_dispatch_rq_list()`, `BLK_STS_RESOURCE` sets `needs_resource = true` before falling through to `BLK_STS_DEV_RESOURCE`. Test `REQ_POLLED` before `REQ_OP_READ` in `blk_mq_get_hctx_type()`. Skip `hctx` with `delayed_work_pending(&hctx->run_work)` in `blk_mq_delay_run_hw_queues()`. Check `!users` before dividing in `hctx_may_queue()`. [F328, F332, F341, F352]
- Avoid overflow/underflow: widen to `u64` in `blk_apply_bdi_limits()` and `QUEUE_SYSFS_LIMIT_SHOW_SECTORS_TO_BYTES`; use `check_shl_overflow()` in `blk_stack_atomic_writes_chunk_sectors()`; test `(bi_opf & (REQ_SYNC | REQ_IDLE)) == (REQ_SYNC | REQ_IDLE)` in `wbt_should_throttle()`; clamp `min(31, scale_step)` on `(depth - 1) >> scale_step` + 1 in `rq_depth_calc_max_depth()`; require `scale_step > 0` in `rwb_arm_timer()`; use ceiling division in `calc_wb_limits()`; and guard wrap/order in `blk_rq_stat_sum()`, `blk_stat_add()`, and `blk_add_timer()` (`time_before()`). [F330, F344, F345, F347, F349, F350, F351, F355, F356, F357]
