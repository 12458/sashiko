# BLOCK LAYER — block (part 1)

Core block layer foundation for block device (`bdev`) VFS lifecycle and claiming, `bio` allocation/cloning/splitting/chaining, request submission, plugging, bio/request merging, buffer mapping, inline encryption (`blk-crypto`), data integrity (`bio-integrity`), flush sequencing (`blk-flush`), badblocks, I/O contexts (`io_context`/`io_cq`), and blkcg.

## Architecture & Data Flow

- `__submit_bio_noacct()` moves `bio_list_on_stack[0]` to `[1]` before `__submit_bio(bio)`, partitions newly queued bios in `[0]` into `lower` (`q != bdev_get_queue(bio->bi_bdev)`) and `same`, and merges `lower`, `same`, `[1]`; in `submit_bio_noacct_nocheck()` with `current->bio_list` active and `split == true`, queue the remainder at the head of `[0]` via `bio_list_add_head()`; `punt_bios_to_rescuer(bs)` must only move bios with `bio->bi_pool == bs` to `bs->rescue_list`, restoring others to `current->bio_list`. [F83, F119, F197]
- `bio_reset()` must call `bio_uninit(bio)`, zero only `BIO_RESET_BYTES` (`offsetof(struct bio, bi_max_vecs)`), and set `__bi_remaining = 1` while preserving `bi_max_vecs`, `__bi_cnt`, `bi_io_vec`, and `bi_pool`; `bio_truncate()` must only reduce `bi_iter.bi_size` (zeroing tail on read) without altering `bi_io_vec` or `bi_vcnt`; `__bio_release_pages()` must compute `nr_pages` as `(fi.offset + fi.length - 1) / PAGE_SIZE - fi.offset / PAGE_SIZE + 1`. [F80, F98, F141]
- `__bio_advance()` must call `bio_integrity_advance()` and `bio_crypt_advance()` alongside `bio_advance_iter()`; shrinking `bi_iter.bi_size` in `bio_split()` / `bio_trim()` must call `bio_integrity_trim()` after updating `bi_size`; `bio_integrity_init()`, `bio_integrity_free()`, and `bio_integrity_finish()` must keep `REQ_INTEGRITY` in `bio->bi_opf` in sync with `bio->bi_integrity`; when `bio_integrity_copy_user()` bounce-copies a read bio, it allocates `nr_vecs + 1` bvecs with bounce at `bip_vec[0]` and pinned user bvecs at `&bip_vec[1]` for `bio_integrity_uncopy_user()`. [F69, F70, F71, F86]
- `blk-integrity` and `blk-crypto` are mutually exclusive: `blk_crypto_register()` rejects queues where `blk_integrity_queue_supports_integrity(q)` is true, and `bio_integrity_alloc()` returns `ERR_PTR(-EOPNOTSUPP)` if `bio_has_crypt_ctx(bio)`. [F210]
- `blk_attempt_plug_merge()` must check `plug->mq_list.tail` first before scanning `plug->mq_list` when `plug->multiple_queues` is set; `flush_plug_callbacks()` must drain `plug->cb_list` in a `while (!list_empty(&plug->cb_list))` loop using `list_splice_init()`. [F73, F126]
- Before merging requests with `RQF_MIXED_MERGE` or differing `REQ_FAILFAST_MASK`, `blk_rq_set_mixed_merge()` propagates `rq->cmd_flags & REQ_FAILFAST_MASK` to all bios on `rq` and sets `RQF_MIXED_MERGE`, and `blk_update_mixed_merge()` updates failfast bits on front-merge; `blk_cgroup_mergeable()` requires matching `bi_blkg` and `bio_issue_as_root_blkg()`. [F76, F213]
- `bio_crypt_ctx_mergeable(bc1, bc1_bytes, bc2)` checks DUN continuity in `@bc1` then `@bc2` order: `bio_attempt_front_merge()` passes `(bio->bi_crypt_context, bio->bi_iter.bi_size, req->crypt_ctx)` and updates `req->crypt_ctx->bc_dun` via `bio_crypt_do_front_merge()`, while back-merge and `blk_rq_append_bio()` call `bio_crypt_free_ctx(bio)`. [F60, F74]
- `bio_crypt_ctx.bc_dun` is little-endian limb-ordered `u64[BLK_CRYPTO_DUN_ARRAY_SIZE]`: `bio_crypt_dun_increment()` and `bio_crypt_dun_is_contiguous()` propagate 64-bit carry across all limbs (rejecting merge if final `carry != 0`), and `blk_crypto_dun_to_iv()` converts limbs via `cpu_to_le64()`; `blk_crypto_keyslot` transitions `0 -> 1` remove `slot->idle_slot_node` from `profile->idle_slots` and `1 -> 0` in `blk_crypto_put_keyslot()` re-adds it under `idle_slots_lock` and wakes `idle_slots_wait_queue`; `__blk_crypto_mode_attrs` is 1-based by `blk_crypto_mode_num` while `blk_crypto_mode_attrs` is filled at `[i - 1]`. [F92, F105, F107, F142]
- `blk_alloc_flush_queue()` must size `fq->flush_rq` to `round_up(sizeof(struct request) + cmd_size, cache_line_size())`; `blk_insert_flush()` requires `rq->bio == rq->biotail` so `blk_flush_restore_request()` can restore `rq->bio`, `rq->__sector`, and `rq->end_io` on `REQ_FSEQ_DONE`; `rq->flush.seq` only sets `REQ_FSEQ_ACTIONS` (bits 0..2), and `REQ_FSEQ_DATA | REQ_FSEQ_POSTFLUSH` in `blk_insert_flush()` must pre-set `REQ_FSEQ_PREFLUSH`. [F77, F122, F137, F160]
- In `blk_flush_queue`, `flush_pending_idx == flush_running_idx` when idle and toggles with `^= 1` under `fq->mq_flush_lock` while tracking `flush_data_in_flight`; `flush_end_io()` must toggle `flush_running_idx ^= 1` before iterating `running` with `list_for_each_entry_safe()` and `list_del_init(&rq->queuelist)` before `blk_flush_complete_seq()`. [F79, F121]
- Badblocks functions shifting by `bb->shift` (`badblocks_check()`, `_badblocks_set()`, `_badblocks_clear()`, `badblocks_show()`) must first check `bb->shift >= 0`; `BB_MAKE(a, l, ack)` requires `1 <= l <= BB_MAX_LEN` (512) and `bb->count <= MAX_BADBLOCKS`; `front_overwrite()` and `front_splitting_clear()` must save `BB_END(p[prev])` and `BB_ACK(p[prev])` before mutating `p[prev]`; `_badblocks_set()` must set `hint = ++prev` after `insert_at()` at `0` or `prev + 1` before `try_adjacent_combine(bb, prev)`. [F90, F108, F116, F136]

## Synchronization

- While a `request_queue` is frozen (`q->io_lockdep_map` / `q->q_lockdep_map`), never acquire `fs_reclaim` or `cpu_hotplug_lock` (e.g. `static_branch_inc()`/`dec()`); in `blk_queue_enter()` and `__bio_queue_enter()`, `smp_rmb()` must precede `wait_event(q->mq_freeze_wq, ...)` after `blk_try_enter_queue()` fails; `iocb_bio_iopoll()` must hold `rcu_read_lock()` while calling `bio_poll()`, which uses `READ_ONCE()` on `bi_cookie`/`bi_bdev` and `percpu_ref_tryget(&q->q_usage_counter)`. [F41, F42, F192]
- Direct-I/O reads mark folios dirty in process context via `bio_set_pages_dirty()`, and IRQ completion paths use `bio_check_pages_dirty()` to defer locking/dirtying to `bio_dirty_work`; `bio_integrity_unpin_bvec()` runs in IRQ context when `!BIP_COPY_USER` and must only call `unpin_user_page()`, never `set_page_dirty_lock()`. [F170, F171]
- `io_cq` teardown orders `q->queue_lock` before `ioc->lock`, so `put_io_context()` defers non-empty `icq_list` teardown to `ioc_release_fn()`; `set_task_ioprio()` checks `__task_cred(task)->uid` / `CAP_SYS_NICE` under `rcu_read_lock()` and `security_task_setioprio()`, and if `task_lock(task)` is dropped to allocate `io_context`, rechecks `PF_EXITING` and `task->io_context` after re-locking. [F15, F28, F214]
- `fq->mq_flush_lock` requires IRQ-disabling spinlocks (`q->requeue_lock` nests inside it), and `blk_kick_flush()` must set `flush_rq->end_io` before `smp_wmb()` and `req_ref_set(flush_rq, 1)`; `bb->lock` writers (`_badblocks_set()`, `_badblocks_clear()`, `ack_all_badblocks()`) must use `write_seqlock_irq*()` because `badblocks_check()` runs in IRQ context; `bdev_freeze()`, `bdev_thaw()`, and `bdev_mark_dead()` acquire `bdev->bd_holder_lock` and require the `bd_holder_ops` callback to release it. [F25, F34, F188, F190]
- `blk_crypto_hw_enter()` calls `pm_runtime_get_sync()` before `down_write(&profile->lock)`, whereas `blk_crypto_reprogram_all_keys()` takes `profile->lock` without runtime PM; `profile->idle_slots_lock` nests inside `profile->lock` and requires IRQ-saved locking; in `blk_crypto_get_keyslot()`, the slow path must re-call `blk_crypto_find_and_grab_keyslot()` and recheck `!list_empty(&profile->idle_slots)` after each `blk_crypto_hw_enter()` and call `blk_crypto_hw_exit()` before `wait_event()`. [F33, F162, F181]

## Object Lifetimes

- `bdev_file->private_data` holds `holder`, `ERR_PTR(ret)` on `bdev_open()` failure in `bdev_file_open_by_dev()` (after `ihold(BD_INODE(bdev))` so `fput()` only calls `blkdev_put_no_open()`), or `BDEV_I(bdev_file->f_mapping->host)` (never `NULL`) set under `disk->open_mutex` in `bdev_fput()`; readers must check `IS_ERR()` and `bdev_unclaimed()`; every successful `bd_prepare_to_claim()` must pair with `bd_finish_claiming()` or `bd_abort_claiming()`. [F3, F4, F5, F149]
- Caller-allocated bios (`bio_init()`, `bio_init_inline()`, `bio_kmalloc()`) and failed `__bio_clone()` targets must be cleaned up with `bio_uninit()` (or `bio_put()` if pooled); `bioset_exit()` must call `bio_alloc_cache_destroy(bs)` and `destroy_workqueue(bs->rescue_workqueue)` before `mempool_exit()` and `bio_put_slab()`; `blk_free_queue()` must defer `percpu_ref_exit(&q->q_usage_counter)` and `kmem_cache_free()` to `blk_free_queue_rcu()`. [F6, F14, F40, F51]
- `__submit_bio_noacct*()` must reset `current->bio_list = NULL` before returning; `blk_start_plug_nr_ios()` must not overwrite a non-NULL `current->plug`, and `blk_finish_plug(plug)` only flushes/clears `current->plug` when `plug == current->plug`; `attempt_merge()` transfers `next->bio`, calls `blk_crypto_rq_put_keyslot(next)`, clears `next->bio = NULL`, and returns `next` for the caller to free; `bio_alloc_map_data()` must deep-copy `iter_iov(data)` into `bmd->iov` when `iter_is_iovec(data)`. [F13, F18, F150, F161]
- `__blk_crypto_evict_key()` must unconditionally run `hlist_del(&slot->hash_node)` and `slot->key = NULL` even on error or non-zero `slot_refs`; profiles from `devm_blk_crypto_profile_init()` must not be passed to `blk_crypto_profile_destroy()`; `bb->dev` must not change between `__badblocks_init()` and `badblocks_exit()`; `disk_register/unregister_independent_access_ranges()` must `kobject_del()` each child `ia_range[i].kobj` before `iars->kobj` under `q->sysfs_lock`. [F22, F43, F164, F165]

## API Contracts

- With `bioset_init()` `front_pad > 0`, `struct bio` must be last in the outer struct because inline bvecs follow at `bio + 1`; `bio_kmalloc()` rejects `nr_vecs > BIO_MAX_INLINE_VECS`; `bio_check_pages_dirty()` consumes `@bio` (overwriting `bi_private` and calling `bio_put()`). [F10, F93, F144]
- `bio_split()` and `bio_trim()` take 512-byte sectors (`bio_trim()` checks `offset, size <= BIO_MAX_SECTORS` and `offset + size <= bio_sectors(bio)` before `<< 9`), while `bio_advance*()` and `bio_integrity_advance()` take bytes; `bio_split()` returns `ERR_PTR` without ending `@bio`, whereas `bio_submit_split*()` calls `bio_endio(bio)` and returns `NULL`; `bio_split_io_at()` returns `< 0` on error, `0` if unsplit, or `> 0` sectors (which `blk_rq_append_bio()` turns into `-EREMOTEIO` for bounce fallback). [F49, F50, F56, F132]
- `blk_rq_map_user()` and `blk_rq_integrity_map_user()` use `rq_data_dir(rq)` for `iov_iter` direction; `bio_integrity_map_iter()` validates `meta->iter.count >= integrity_bytes` and `!(meta->flags & ~IO_INTEGRITY_VALID_FLAGS)` and caps `it.count` to `integrity_bytes`; `blk_rq_unmap_user()` requires process context and the saved `rq->bio`, unmapping the whole `bi_next` chain while keeping the first error from `bio_uncopy_user()` (which checks `current->mm != NULL`); read bios using `bio_add_vmalloc*()` must call `invalidate_kernel_vmap_range()` on completion. [F62, F63, F102, F174, F175]
- `blk_queue_flag_set/clear(flag, q)` take a `QUEUE_FLAG_*` bit index, not a mask; `blk_set_pm_only(q)` and `blk_clear_pm_only(q)` must be balanced; `blk_sync_queue(q)` only cancels `q->timeout` and `q->timeout_work`; `blk_crypto_profile_init()` zeroes `*profile` so fields are set after it; `blk_crypto_update_capabilities()` must not shrink active capabilities; `blk_crypto_get_keyslot()` can return `BLK_STS_OK` with `*slot_ptr = NULL` when `num_slots == 0` (check `blk_crypto_rq_has_keyslot()`); `bio_crypt_set_ctx()` requires `__GFP_DIRECT_RECLAIM`. [F59, F67, F163, F166, F168, F169, F178]
- Badblocks APIs use `sector_t` (`badblocks_show()` casts `BB_OFFSET()` to `unsigned long long` before `<< bb->shift`), and `badblocks_check()` returns `0` (none), `1` (acked), or `-1` (unacked); `disk_set_independent_access_ranges()` requires `nr_ia_ranges > 0` partitioning `[0, get_capacity(disk))`; `blkcg_set_fc_appid()` rejects `app_id_len > FC_APPID_LEN`; blkcg policy private structs must embed `struct blkg_policy_data` at offset 0. [F66, F110, F113, F135, F155]

## Error Handling & External Contracts

- `bio_check_eod()` must still return `-EIO` when `nr_sectors != 0` and `maxsector == 0` (while skipping the log); `blk_rq_map_user_io()` with `vec && iov_count` must call `iov_iter_truncate(&iter, buf_len)`; `blk_crypto_ioctl()` handlers must check `memchr_inv(arg.reserved, 0, ...)` and bound key sizes (`-EINVAL` / `-EOVERFLOW`); `blk-integrity` `flag_store/show()` invert `BLK_INTEGRITY_NOVERIFY`/`NOGENERATE` polarity, and `blk_get_meta_cap()` maps `bi->csum_type` to `LBMD_PI_CSUM_*`; `badblocks_store()` requires `"%llu %d%c"` with `length > 0`; `queue_state_write()` returns `-ENOENT` if `blk_queue_dying(q)`. [F100, F104, F109, F128, F198, F199, F216]

## Known Pitfalls

- `I_BDEV()` and `BDEV_I()` only apply to `blockdev_superblock` inodes (`bdev_file->f_mapping->host`), never `/dev` VFS inodes (use `file_bdev()`); `bio_endio()` must loop on `bio_chain_endio` via `__bio_chain_endio()`; `__blkdev_sectors_to_bio_pages()` must use `DIV_ROUND_UP_SECTOR_T()`; `get_max_segment_size()` must compare `seg_boundary_mask - (seg_boundary_mask & paddr)` against `max_segment_size - 1` before `+ 1`; `blk_kick_flush()` and `update_io_ticks()` must use `time_before()`/`time_after()`. [F120, F134, F140, F143, F148]
- `blk_crypto_fallback_decrypt_endio()` must read `f_ctx->bi_private_orig` and `bi_end_io_orig` before writing `f_ctx->work` / `f_ctx->bio` (anonymous union); `blk_crypto_profile_init()` must clamp `slot_hashtable_size` to `>= 2` when `num_slots > 0`; `badblocks_check()` and `badblocks_show()` seqretry loops must reset all cursor/accumulator locals; in `_badblocks_set()`, `!can_front_overwrite(..., &extra)` (with `extra = 0`) jumps to `out` if `extra > 0` and skips `p[prev]` if `extra == 0`; `bb->page` shifts must use `memmove()` scaled by `8` before updating `bb->count`; `blk_mq_debugfs_write()` must check `attr == data` (no `.write` with `.seq_ops`). [F23, F106, F115, F117, F154, F159]
