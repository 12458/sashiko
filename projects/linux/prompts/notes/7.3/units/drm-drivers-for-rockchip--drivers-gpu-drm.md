# DRM DRIVERS FOR ROCKCHIP — drivers/gpu/drm

Implements the Rockchip DRM master driver, GEM/DMA/IOMMU memory management, framebuffer creation, the first-generation Video Output Processor (VOP) CRTC/plane controller, and display encoder/bridge subdrivers for DisplayPort (Analogix, Cadence, DesignWare), MIPI DSI (DesignWare v1/v2), and HDMI (DesignWare, DesignWare QP, Innosilicon, RK3066).

## Architecture & Data Flow

- `rockchip_drm_dma_init_device()` sets `private->iommu_dev = ERR_PTR(-ENODEV)` if any bound VOP lacks IOMMU. `rockchip_drm_init_iommu()` must check `IS_ERR_OR_NULL(private->iommu_dev)` and reset `private->domain = NULL` if `iommu_paging_domain_alloc()` returns `ERR_PTR`, as downstream checks only test `private->domain` for non-NULL. [F5, F38]
- Every framebuffer GEM object must be a `struct rockchip_gem_object` (`to_rockchip_obj()`), with `size` aligned via `round_up(size, PAGE_SIZE)` before `drm_gem_object_init()` (callers use `size >> PAGE_SHIFT`). PRIME imports are discriminated via `obj->import_attach` (and `private->domain`), whereas internal buffers use `rk_obj->pages != NULL` (IOMMU vs contiguous DMA). When `!private->domain`, `rockchip_gem_dma_map_sg()` must verify `drm_prime_get_contiguous_size(sg) >= attach->dmabuf->size` after `dma_map_sgtable()`. [F41, F110, F123, F160]
- For DMA-backed `rockchip_gem_object` buffers (`!rk_obj->pages`) with `!alloc_kmap`, `rk_obj->kvaddr` is a DMA cookie, so `rockchip_gem_prime_vmap()` must check `rk_obj->dma_attrs & DMA_ATTR_NO_KERNEL_MAPPING` before using `rk_obj->kvaddr`, and `rockchip_gem_prime_vunmap()` must only call `vunmap(map->vaddr)` when `rk_obj->pages && map->vaddr != rk_obj->kvaddr`. [F4, F40]
- `vop_plane_atomic_update()` and `vop_win_disable()` must update `vop->win_enabled` in lockstep with the hardware `enable` bit under `vop->reg_lock`. During Panel Self-Refresh (`self_refresh_active`), VOP must only call `rockchip_drm_set_win_enabled()`, leaving `vop->win_enabled`, clocks, and IOMMU intact. [F60, F178]
- After `vop_crtc_gamma_set()` sets `update_gamma_lut` to 1 and polls `vop_lut_buffer_index()`, it must write `VOP_REG_SET(vop, common, update_gamma_lut, 0)` under `vop->reg_lock` to clear the auto-cleared bit in `vop->regsbak`. `vop_crtc_atomic_enable()` must set `VOP_REG_SET(vop, intr, line_flag_num[0], vact_end)` alongside `vact_st_end`/`vpost_st_end`. [F59, F62]
- In `struct vop_reg`, any `write_mask = true` field must fit in bits `[15:0]`, and `reg->offset + _offset` must be 4-byte aligned and `< vop->len`. Any non-NULL `vop_data->win_yuv2yuv` must have `>= vop_data->win_size` elements, each with non-NULL `phy`. `VOP_WIN_TO_INDEX(vop_win)` uses pointer subtraction on `vop->win[]`, and `vop_plane_atomic_update()` must only enable per-pixel alpha (`alpha_en`, `src_alpha_ctl`) when `fb->format->has_alpha && VOP_WIN_TO_INDEX(vop_win) > 0`. [F85, F86, F90, F116]
- `vop_plane_atomic_check()` must reject YUV planes with odd `new_plane_state->src.x1 >> 16` or `DRM_MODE_REFLECT_Y`, and AFBC planes with non-zero `src.x1`/`src.y1` or rotation `!= DRM_MODE_ROTATE_0`. `vop_bind()` must require `vop_data->lut_size` to be `256` or `1024` before mapping `vop->lut_regs`, and `vop_crtc_atomic_check()` must verify `drm_color_lut_size(crtc_state->gamma_lut) == crtc->gamma_size`. [F87, F88, F111]
- In `has_rb_swapped()`, `DRM_FORMAT_RGB888` checks `VOP_MAJOR(version) == 3` and `DRM_FORMAT_BGR888` checks `VOP_MAJOR(version) != 3` (covering `version == 0`). In `vop_crtc_mode_fixup()`, if `clk_round_rate(vop->dclk, adjusted_mode->clock * 1000)` mismatches `adjusted_mode->clock` in kHz, retry with `+ 999` Hz and set `adjusted_mode->clock = DIV_ROUND_UP(rate, 1000)`. [F89, F108]
- Unsigned GRF offsets in `struct rockchip_dw_dsi_chip_data` use `0` as sentinel; `rockchip_hdmi_chip_data.lcdsel_grf_reg` is signed `int` using `-1` (`< 0`). In `analogix_dp-rockchip.c`, `0x0000` is a valid RK3588 GRF offset, so `rockchip_grf_reg_field` must use `GRF_REG_FIELD()` (`.valid = true`) and `rockchip_grf_field_write()` must check `field->valid`. `rockchip_dp_chip_data` and `rockchip_dw_dsi_chip_data` arrays must end with a `.reg == 0` sentinel, and `cdn_dp_data.max_phy` must be `<= MAX_PHY` (2). [F50, F51, F75, F78, F79]
- In `struct cdn_dp_device`, `dp->active_port` is `-1` when inactive; `cdn_dp_check_sink_connection()` must check `dp->active_port >= 0 && dp->active_port < dp->ports`. `cdn_dp_disable()` must reset `dp->active = false`, `dp->max_lanes = 0`, `dp->max_rate = 0` (and `cdn_dp_disable_phy()` resets `port->phy_enabled = false`, `port->lanes = 0`, `dp->active_port = -1`). Before `cdn_dp_train_link(dp)` on an active link in `cdn_dp_pd_event_work()`, sample `dp->max_rate` and `dp->max_lanes` and call `cdn_dp_config_video(dp)` if `dp->mode.clock` is set and either changed. [F54, F71, F72]
- In dual-DSI mode, if `dsi->dev->of_node` lacks `"clock-master"`, `dw_mipi_dsi_rockchip_bind()` must set `dsi->is_slave = true` and return `0`, and `dw_mipi_dsi_rockchip_unbind()` must return early when `dsi->is_slave`. When `dsi->slave`, the master must perform runtime PM, `dw_mipi_dsi_rockchip_config()`, and `dw_mipi_dsi_rockchip_set_lcdsel()` on both `dsi` and `dsi->slave`. [F68, F97]
- When external `dsi->phy` is present, `dw_mipi_dsi_rockchip_probe()` resets missing `dsi->pllref_clk` to `NULL`, and `dw_mipi_dsi_phy_init()` / `dw_mipi_dsi_get_lane_mbps()` must return early if `dsi->phy`. In `dw_mipi_dsi_get_lane_mbps()`, PLL pre-divider bounds must use `DIV_ROUND_UP(fin, 40 * USEC_PER_SEC)` for `min_prediv` and `fin / (5 * USEC_PER_SEC)` for `max_prediv`. [F56, F109]

## Synchronization

- `private->mm_lock` must protect `drm_mm_insert_node_generic()` and `drm_mm_remove_node()` in `rockchip_gem_iommu_map()`/`unmap()`, and `rockchip_gem_iommu_unmap()` must call `iommu_unmap()` before `drm_mm_remove_node(&rk_obj->mm)`. [F29]
- In `vop_enable()`, enable runtime PM and VOP clocks before `rockchip_drm_dma_attach_device()`, call `vop_win_disable()` on all windows unless exiting PSR, and set `vop->is_enabled = true` before `drm_crtc_vblank_on()`. In `vop_crtc_atomic_disable()`, call `reinit_completion(&vop->dsp_hold_completion)` and `vop_dsp_hold_valid_irq_enable(vop)` before setting `standby = 1`, wait on `dsp_hold_completion` before detaching IOMMU or disabling clocks, and call `vop_dsp_hold_valid_irq_disable(vop)` before `vop->is_enabled = false`. [F16, F17, F18]
- Hold `vop->reg_lock` when updating plane registers, `vop->win_enabled`, or calling `vop_cfg_done()`. Never acquire `vop->reg_lock` in `vop_isr()`/hardirq context (it uses `spin_lock()`), and release it before sleeping `readx_poll_timeout()` calls in `vop_crtc_gamma_set()`. [F19, F151, F157]
- Before setting `VOP_PENDING_FB_UNREF` in `vop->pending`, acquire `drm_framebuffer_get()` and `drm_crtc_vblank_get()` and call `drm_flip_work_queue(&vop->fb_unref_work, ...)`. In `vop_crtc_atomic_flush()`, call `vop_wait_for_irq_handler()` after releasing `vop->reg_lock` (post-`vop_cfg_done()`) and before taking `crtc->dev->event_lock` to arm `vop->event`. [F21, F153]
- `vop_isr()` runs on a shared hardirq line and must use `pm_runtime_get_if_in_use(vop->dev)` and `vop_core_clks_enable()`/`disable()` (`clk_enable()`/`disable()` on `hclk`, `aclk`, `dclk` left prepared by `vop_initial()` until `vop_unbind()`). `rockchip_drm_wait_vact_end()` must hold `vop->vop_lock` across checking/enabling/disabling `LINE_FLAG_INTR` and waiting on `vop->line_flag_completion`. [F22, F130, F154]
- In `cdn-dp-core.c`, all mailbox, power, link, audio, and `dp->suspended` operations must hold `dp->lock`. `cdn_dp_request_firmware()` requires `dp->lock` held on entry, drops it around `request_firmware()`, and must re-acquire it before returning. `cdn_dp_pd_event_work()` must unlock `dp->lock` before `drm_bridge_hpd_notify()`. [F11, F25, F145, F165]
- `dw_mipi_dsi_rockchip_host_attach()` and `dw_mipi_dsi_dphy_init()` must check `dsi->usage_mode == DW_DSI_USAGE_IDLE` and set `usage_mode` under `dsi->usage_mutex` before `component_add()`, and reset it to `IDLE` under `usage_mutex` after `component_del()` (never holding `usage_mutex` across `component_add()`/`del()`). `dw_mipi_dsi_rockchip_driver` requires `PROBE_FORCE_SYNCHRONOUS` and `SET_LATE_SYSTEM_SLEEP_PM_OPS`. [F31, F143]
- `inno_hdmi_i2c_xfer()` and `rk3066_hdmi_i2c_xfer()` must hold `i2c->lock` / `i2c->i2c_lock` across unmasking the EDID IRQ, calling `reinit_completion()` before writing `HDMI_EDID_SEGMENT_POINTER`, waiting on the completion, and re-masking the IRQ. Their hardirq handlers complete the DDC completion and return `IRQ_WAKE_THREAD` so `drm_helper_hpd_irq_event()` runs in thread context. [F35, F167]

## Object Lifetimes

- `rockchip_drm_init()` must register `rockchip_sub_drivers` before `rockchip_drm_platform_driver` (and unregister in reverse order). In `rockchip_drm_bind()`, `component_bind_all()` must precede `rockchip_drm_init_iommu()` and `drm_vblank_init()`, and `rockchip_drm_unbind()` must call `drm_atomic_helper_shutdown()` and `component_unbind_all()` before `rockchip_iommu_cleanup()`. [F13, F125]
- In `rockchip_drm_match_add()`, pass cursor `p` to `platform_find_device_by_driver(p, &drv->driver)`, call `put_device(p)`, and set `p = d`; remove stateless device links via `rockchip_drm_match_remove(dev)` on probe failure and in `rockchip_drm_platform_remove()`. In `rockchip_fb_create()`, free `afbc_fb` with `kfree()` if `drm_gem_fb_init_with_funcs()` fails, but use `drm_framebuffer_put(&afbc_fb->base)` if `drm_gem_fb_afbc_init()` fails afterwards. [F12, F100, F175]
- In `vop_bind()`, spinlocks, `vop_lock`, `vop_create_crtc()`, `pm_runtime_enable()`, and `vop_initial()` must precede `devm_request_irq()`. In `vop_destroy_crtc()`, call `drm_plane_cleanup()` on all planes before `drm_crtc_cleanup(crtc)` during `vop_unbind()`. [F23, F177]
- `vop_get_edp_connector()` must call `drm_connector_list_iter_end(&conn_iter)` before returning early from `drm_for_each_connector_iter()`. In `dw_mipi_dsi_rockchip_find_second()`, every non-returning `of_find_compatible_node()` iteration must `of_node_put(remote)`, and early returns must `of_node_put()` `remote`, `node`, and `local`. [F94, F96]

## API Contracts

- `rockchip_drm_endpoint_is_subdriver()` returns `1` (subdriver), `0` (external bridge), or `-ENODEV` (check `== 0` for bridges). `rockchip_rgb_init()` returns `ERR_PTR`, `NULL` (unused), or pointer (`vop_bind()` fails only on `IS_ERR(vop->rgb)`, `vop_unbind()` checks `if (vop->rgb)`). `dw_mipi_dsi_rockchip_find_second()` returns `NULL`, `ERR_PTR(-EPROBE_DEFER)`, or `struct device *` (check both `IS_ERR` and non-NULL). [F39, F47, F55]
- In `rockchip_drm_dma_attach_device()`, if `private->domain && IS_ENABLED(CONFIG_ARM_DMA_USE_IOMMU)`, detach and release `to_dma_iommu_mapping(dev)` before `iommu_attach_device()`. In `rockchip_gem_get_pages()`, set `sg_dma_address(s) = sg_phys(s)` after `drm_prime_pages_to_sg()` before `dma_sync_sgtable_for_device()`. `rockchip_gem_create_with_handle()` must pass `alloc_kmap = true` when `file_priv == drm->fb_helper->client.file`. [F149, F159, F172]
- `vop_crtc_reset()` and `vop_crtc_duplicate_state()` must allocate `struct rockchip_crtc_state` (`to_rockchip_crtc_state()`). `vop_create_crtc()` must init primary/cursor planes (`possible_crtcs = 0`) before `drm_crtc_init_with_planes()`, and overlay planes after with `drm_crtc_mask(crtc)`. `vop_crtc_atomic_begin()` must call `vop_crtc_gamma_set()` only when `color_mgmt_changed && !active_changed`. [F91, F121, F176]
- In `vop_reg_set()`, `reg->mask != 0` tests register presence and `_mask`/`v` must be unshifted. In `vop_plane_atomic_update()`, `new_state->src` is 16.16 fixed-point (`>> 16`), `act_info`/`dsp_info` encode `(height - 1) << 16 | ((width - 1) & 0xffff)`, and `yrgb_vir`/`uv_vir` take `DIV_ROUND_UP(fb->pitches[i], 4)`. [F48, F49]
- Pass `&dp->plat_data` embedded in `struct rockchip_dp_device` to `analogix_dp_probe()`. In `cdn_dp_firmware_init()`, add byte offsets (`hdr->header_size`, `hdr->iram_size`) to `const u8 *fw->data` before casting to `const u32 *`, and in `cdn_dp_load_firmware()` advance `const u32 *` pointers by 1 per `i += 4` byte step. [F117, F122]
- Every successful `cdn_dp_mailbox_validate_receive()` must be followed by `cdn_dp_mailbox_read_receive()` reading `req_size` bytes; on header mismatch `cdn_dp_mailbox_validate_receive()` must drain `mbox_size` bytes via `cdn_dp_mailbox_read()` before returning `-EINVAL`. All multi-byte Cadence DP mailbox fields are big-endian. [F76, F77, F99]
- Enable `grf_clk`/`grfclk` (`clk_prepare_enable()`/`disable_unprepare()`) around GRF `regmap_write()` calls. `dw_hdmi_rk3328_setup_hpd()` must end with `dw_hdmi_rk3328_read_hpd()`. `dw_hdmi_qp_rockchip_resume()` must call `hdmi->ctrl_ops->io_init(hdmi)` before `dw_hdmi_qp_resume()`. `inno_hdmi_i2c_xfer()` and `rk3066_hdmi_i2c_xfer()` only allow 1-byte writes to `DDC_ADDR`/`DDC_SEGMENT_ADDR` and must return `num` when helpers return `0`. [F58, F139, F140, F141, F180]

## Error Handling

- Store `iommu_map_sgtable()`'s return in `ssize_t` in `rockchip_gem_iommu_map()`; store `vop_convert_format()`'s return in signed `int` before `< 0`; store `cdn_dp_mailbox_read()`'s return in `int` and check `ret < 0` before `u8` truncation. Check `WARN_ON(!crtc->state)` / `WARN_ON(!connector->state)` in `vop_crtc_duplicate_state()` and `inno_hdmi_connector_duplicate_state()` before `kmemdup()`, check `devm_ioremap_resource(dev, res)` before `resource_size(res)` in `vop_bind()`, and log rejected configs in atomic check callbacks with `DRM_DEBUG_KMS()`. [F37, F42, F44, F46, F53, F171]

## Known Pitfalls

- Use `div_u64()`/`do_div()` for 64-bit divisions; widen `fout` and `_fbdiv` to `u64` before multiplying in `dw_mipi_dsi_get_lane_mbps()`; cast `tu_size_reg` to `u64` and keep `symbol` as `u64` in `cdn_dp_config_video()`; widen `aperture_start`/`end` to `u64` before `end - start + 1` in `rockchip_drm_init_iommu()`. [F104, F105, F106, F107]
- Index `uint32_t *vop->regsbak` with `offset >> 2` or `i / 4` (`vop->len` is bytes). Pass unscaled register indices to `inno_hdmi.c` `hdmi_readb()`/`writeb()` (which multiply by 4), unlike `rk3066_hdmi.c` (byte offsets). In `dw_hdmi_rockchip_bind()`, copy `.phy_data` to `hdmi->chip_data` and set `plat_data->phy_data = hdmi` and `priv_data = hdmi` on a `devm_kmemdup()` copy. [F115, F118, F119]
- In `dw_mipi_dsi_phy_init()`, write `PLL_INPUT_AND_LOOP_DIVIDER_RATIOS_CONTROL` after `LOW_PROGRAM_EN` and again after `HIGH_PROGRAM_EN`. In `dw_mipi_dsi_phy_get_timing()`, decrement `i` if `i == ARRAY_SIZE(hstt_table)`. Use `time_before(jiffies, timeout)` in `cdn_dp` polling loops. [F69, F95, F114]
