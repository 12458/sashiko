# WANGXUN ETHERNET DRIVER — drivers/net/ethernet/wangxun

Core shared library (`libwx`) and 1GbE PF/VF PCIe drivers (`ngbe`, `ngbevf`) for WangXun Ethernet controllers, implementing Tx/Rx rings, NAPI, page pool, interrupts, SR-IOV mailbox, PTP, MAC/VLAN filtering, ethtool, and phylink.

## Architecture & Data Flow

- Every `net_device` using `libwx` callbacks must have `sizeof(struct wx)` priv space with `struct wx` at offset 0 (driver state in `wx->priv`). Every `WX_STAT()` in `wx_gstrings_stats[]` must be `u64` or `u32` (and `wx_gstrings_fdir_stats[]` `u64`), as `wx_get_ethtool_stats()` reads `(char *)wx + stat_offset` as `*(u64 *)p` or `*(u32 *)p`. [F124, F125]
- Check nullable pointers: `wx->ptp_setup_sdp` is `NULL` on MACs without SDP (e.g. `wx_mac_sp`), so `wx_ptp_adjtime()`, `wx_ptp_settime64()`, `wx_ptp_feature_enable()`, `wx_ptp_reset()`, and `wx_ptp_suspend()` must check `if (wx->ptp_setup_sdp)`; `wx->b4_addr` is `NULL` on `ngbevf`, so `wx_reset_hw_vf()` must guard MSI-X backup/restore with `if (wx->b4_addr)`; `wx->msix_q_entries` and `wx->msix_entry` are `NULL` in MSI/INTx, so IRQ/channel helpers must check `pdev->msix_enabled` or `wx->msix_q_entries`. [F38, F39, F40]
- `wx_acquire_msix_vectors()` and `wx_configure_vectors()` map queues to `0..num_q_vectors - 1` and MISC to `num_q_vectors` (`.post_vectors = 1`), except on `wx_mac_em` with `num_vfs == 7` where `__wx_enable_sriov()` sets `WX_FLAG_IRQ_VECTOR_SHARED` (and `wx_sriov_clear_data()` clears it) so `ngbe_request_msix_irqs()`, `wx_acquire_msix_vectors()`, and `wx_set_ivar()` share vector 0 via `ngbe_misc_and_queue()`. [F77, F136]
- `wx_alloc_q_vector()` must use `struct_size(q_vector, ring, txr_count + rxr_count)` as Tx/Rx loops advance `ring++` across `q_vector->ring[]`. Ring counts (`tx_ring_count`, `rx_ring_count`, `ring->count`) must be clamped to `[128, 8192]` (`[WX_MIN_TXD, WX_MAX_TXD]`) and aligned to 128 (`WX_REQ_TX/RX_DESCRIPTOR_MULTIPLE`) before `wx_set_ring()`. [F76, F121]
- Circular rings (`struct wx_ring`) leave 1 slot unused (`wx_desc_unused()` subtracts 1); `wx_alloc_rx_buffers()` and `wx_clean_tx_irq()` subtract `ring->count` from `i` upfront, wrapping at 0 and adding `ring->count` back on exit. `wx_xmit_frame_ring()` must compute Tx descriptors for headlen and frags via `TXD_USE_COUNT(S)` (`DIV_ROUND_UP(S, WX_MAX_DATA_PER_TXD)`) plus 3 before `wx_maybe_stop_tx()`. [F81, F115]
- `wx_clean_rx_ring()` must zero `rx_ring->desc` and reset `next_to_alloc`, `next_to_clean`, and `next_to_use` to 0; `wx_alloc_rx_buffers()` must zero `wb.upper.status_error` and `length` on the new `next_to_use` descriptor before updating indices and `rx_ring->tail`. In `wx_clean_rx_irq()`, `wx_is_non_eop()` must run before any `continue` so `next_to_clean` always advances. [F51, F104]
- In `union wx_rx_desc`, status/error bits (`WX_RXD_STAT_*`, `WX_RXD_ERR_*`, `WX_RXD_STAT_IPV6EX`) are in `rx_desc->wb.upper.status_error` and must be tested via `wx_test_staterr()` (`cpu_to_le32()`), whereas ptype and RSS type are in `rx_desc->wb.lower.lo_dword`. [F85]
- In `wx_configure_tx()`, set `WX_TDM_CTL_TE` in `WX_TDM_CTL` before `wx_configure_tx_ring()`, and `WX_MAC_TX_CFG_TE` after. In `wx_configure_rx()`, call `wx_set_rx_buffer_len()` before `wx_configure_rx_ring()`, and bracket `wx_enable_rx()` with `wx_disable_sec_rx_path()` and `wx_enable_sec_rx_path()`. In `wx_stop_adapter()`, disable all Tx/Rx queues (`WX_PX_TR_CFG`, `WX_PX_RR_CFG`) and `WX_WRITE_FLUSH(wx)` before `wx_disable_pcie_master()`. [F127, F128, F148]
- In `wx_disable_rx()`, clearing `WX_RDB_PB_CTL_RXEN` must save `WX_PSR_CTL_SW_EN` in `wx->mac.set_lben` and clear `WX_PSR_CTL_SW_EN` so `wx_enable_rx()` can restore it; also only clear `WX_MAC_RX_CFG_RE` when `wx->subsystem_device_id` has neither `WX_NCSI_SUP` nor `WX_WOL_SUP`. [F55, F149]
- In `wx_set_rss_queues()`, when `WX_FLAG_FDIR_CAPABLE` is set, reset `ring_feature[RING_F_FDIR].indices = 1` before `if (f->indices > 1)`. `wx_setup_mrqc()` must call `wx_config_rss_field()`, `wx_enable_rss()`, and `wx_setup_reta()` even if `WX_FLAG_VMDQ_ENABLED` is set. When `WX_FLAG_SRIOV_ENABLED` and `WX_FLAG_MULTI_64_FUNC` are set, `wx_store_reta()`, `wx_store_rsskey()`, `wx_config_rss_field()`, and `wx_enable_rss()` must program per-pool registers at `wx->num_vfs` (`WX_RDB_VMRSSTBL`, `WX_RDB_VMRSSRK`, `WX_RDB_PL_CFG`), and PF loops over `rss_indir_tbl` must bound by `wx_rss_indir_tbl_entries(wx)` (64 with SR-IOV, 128 otherwise). [F49, F63, F82, F91]
- In `wx_configure_port()`, `wx->tpid[0..7]` must match `WX_CFG_TAG_TPID(0..3)` (`0`=`ETH_P_8021Q`, `1`=`ETH_P_8021AD`). `wx_fix_features()` must require CTAG and STAG bits in `NETIF_VLAN_STRIPPING/INSERTION/FILTERING_FEATURES` to match. VLVF index 0 is reserved for VLAN 0, so `wx_find_vlvf_slot()`, `wx_find_vlvf_entry()`, `wx_vlan_promisc_enable()`, and `wx_scrub_vfta()` only iterate `1..WX_PSR_VLAN_SWC_ENTRIES - 1`, and `wx_vlan_promisc_disable()` must call `wx_scrub_vfta()`. [F53, F68, F79, F137]
- `WX_PSR_MAC_SWC_AD_L/H` store MAC bytes reversed (`addr[2..5]` in `AD_L`, `addr[0..1]` in `AD_H` bits 15:0). `wx_mta_vector` masks to 12 bits (`0xFFF`), indexing 128-entry `mta_shadow`/`WX_PSR_MC_TBL` and `vft_shadow`/`WX_PSR_VLAN_TBL` via `WX_PSR_MC_TBL_REG` (`(v >> 5) & 0x7F`) and `WX_PSR_MC_TBL_BIT` (`v & 0x1F`). `wx_write_mc_addr_list()` must call `wx_restore_vf_multicasts()` when `WX_FLAG_SRIOV_ENABLED` is set. Per-VF 32-bit registers (`WX_RDM_VF_RE`, `WX_TDM_VF_TE`, `WX_TDM_*_AS`, `WX_PSR_VLAN_SWC_VM`) split indices via `WX_VF_REG_OFFSET` (bits 15:5) and `WX_VF_IND_SHIFT` (bits 4:0). [F54, F87, F112, F113]
- VF code must read `WX_VXMAILBOX` via `wx_read_v2p_mailbox()` to latch R2C bits (`WX_VXMAILBOX_R2C_BITS`) in `wx->mbx.mailbox` and clear via `wx_check_for_bit_vf()`. `wx_set_vf_multicasts()` must clamp hash count to `WX_MAX_VF_MC_ENTRIES` (30). `wx_get_queues_vf()` must clamp `max_tx/rx_queues` to `1..4` (`WX_VF_MAX_TX/RX_QUEUES`), `*num_tcs <= max_rx_queues`, and `*default_tc < max_tx_queues`. `wx_set_rx_mode_vf()` must test `IFF_PROMISC`, then `IFF_ALLMULTI`, then `IFF_BROADCAST | IFF_MULTICAST`. `wx_speed_lookup_vf[]` is indexed by `enum wx_mac_type`. [F64, F69, F73, F74, F95]
- Access `WX_TSC_1588_*` via `rd32ptp()`/`wr32ptp()` (which offset by `0xB500` on non-`wx_mac_em`). Reading `WX_PSR_1588_STMPH` or `WX_TSC_1588_STMPH` unlocks the timestamp latch, so `wx_ptp_rx_hwtstamp()` and `wx_ptp_tx_hwtstamp()` must read `STMPL` before `STMPH`. [F67, F145]
- In `wx_sw_init()`, if `subsystem_vendor != PCI_VENDOR_ID_WANGXUN` and `!pdev->is_virtfn`, read `wx->subsystem_device_id` from flash `0xfffdc` via `wx_flash_read_dword()` and `swab16()`. `ngbe_phylink_init()` must use `PHY_INTERFACE_MODE_RGMII_RXID`. With `wx->gpio_ctrl`, `NGBE_GPIO_DR_0` is active-low (`0` powers on SFP in `ngbe_sfp_modules_txrx_powerctl()`), and `WX_GPIO_POLARITY` in `ngbe_irq_enable()` is `0` (`0x3` when false). [F134, F135, F140]

## Synchronization

- In `wx_tx_map()`, execute `wmb()` after writing Tx descriptors and before `first->next_to_watch = tx_desc` and `tx_ring->tail`, paired with `smp_rmb()` in `wx_clean_tx_irq()` after reading non-NULL `next_to_watch` and before `eop_desc->wb.status`. In `wx_clean_rx_irq()`, execute `dma_rmb()` after `WX_RXD_STAT_DD`, and in `wx_alloc_rx_buffers()`, execute `wmb()` after clearing `status_error`/`length` and before writing `rx_ring->tail`. `wx_maybe_stop_tx()` must execute `smp_mb()` after `netif_stop_subqueue()` and recheck `wx_desc_unused(tx_ring) < size`, paired with `smp_mb()` in `wx_clean_tx_irq()` before `__netif_subqueue_stopped()`. [F26, F27, F28]
- `wx_napi_enable_all()` must `INIT_WORK` on `rx.dim.work` and `tx.dim.work` before `napi_enable()`, and `wx_napi_disable_all()` must call `napi_disable()` before `disable_work_sync()`. Bracket `ring->stats.packets`/`bytes` updates with `u64_stats_update_begin`/`end(&ring->syncp)` and reads (`wx_get_stats64()`, `wx_get_ethtool_stats()`) with `u64_stats_fetch_begin`/`retry(&ring->syncp)`. [F16, F29]
- All updates to `wx->hw_tc` and `wx->hw_cc` (including `timecounter_read(&wx->hw_tc)` in `wx_ptp_overflow_check()` and `wx_ptp_trigger_calc()`) must hold `write_seqlock_irqsave(&wx->hw_tc_lock, flags)`, while `wx_ptp_timecounter_cyc2time()` uses a `read_seqbegin`/`read_seqretry` loop. Call `wx->ptp_setup_sdp` only after releasing `hw_tc_lock` and never from hardirq `wx_ptp_check_pps_event()`. Pair `WRITE_ONCE(wx->base_incval, incval)` + `smp_mb()` in `wx_ptp_reset_cyclecounter()` with `smp_mb()` + `READ_ONCE(wx->base_incval)` in `wx_ptp_adjfine()`. [F20, F30, F151]
- `wx_acquire_sw_sync()` and `wx_release_sw_sync()` must hold `wx_sw_sync_lock` and modify only the caller's mask in `WX_MNG_SWFW_SYNC`. `wx_host_interface_command()` (and `wx_set_pps()`, `wx_read_ee_hostif*()`, `ngbe_eeprom_chksum_hostif()`) requires sleepable context. `wx_host_interface_command_s()` must release `WX_MNG_SWFW_SYNC_SW_MB` on all exits, and `_r()` must increment `swfw_index` and clear `WX_STATE_SWFW_BUSY` on all exits; both must use `cpu_to_le32()`, flush with `rd32a()`, poll `read_poll_timeout()` with `timeout * 1000` us, and unconditionally check `0x80` status. `wx_read_ee_hostif()` and `wx_read_ee_hostif_buffer()` must hold `WX_MNG_SWFW_SYNC_SW_FLASH` across both `wx_host_interface_command()` and reading `FW_NVM_DATA_OFFSET`. [F13, F31, F61, F142, F150]
- `wx_write/read_mbx_pf()` and `wx_write/read_mbx_vf()` must first acquire `wx_obtain_mbx_lock_pf(wx, vf)` or `wx_obtain_mbx_lock_vf(wx)`. VF mailbox callers must lock `wx->mbx.mbx_lock` with `spin_lock_bh()`, and VF polling (`wx_obtain_mbx_lock_vf`, `wx_poll_for_msg/ack`) must use `readx_poll_timeout_atomic()`. PF `wx_msg_task()` and its callees (`wx_rcv_msg_from_vf`, `wx_vf_reset_event/msg`) run in hardirq from `__ngbe_msix_misc()` and must not sleep or use `GFP_KERNEL`. [F24, F154, F155]

## Object Lifetimes

- `wx_free_resources()` only frees Tx/Rx rings; callers (`ngbe_open()` rollback, `ngbe_close()`) must call `wx_free_isb_resources(wx)` only after `wx_free_irq(wx)`. `wx_free_irq()` must skip `free_irq()` on `pdev->irq` and `wx->msix_entry->vector` when `wx->misc_irq_domain` is true, and skip `msix_q_entries[vector]` with neither `rx.ring` nor `tx.ring`. `wx_reset_interrupt_capability()` must check `pdev->msix_enabled` and free/null `msix_q_entries` and `msix_entry` before `pci_free_irq_vectors(wx->pdev)`. [F3, F4, F6]
- `wx_free_q_vector()` must null `wx->tx_ring`/`rx_ring` pointers and call `netif_napi_del()` before `kfree_rcu(q_vector, rcu)` (matching `rcu_read_lock()` + `READ_ONCE` in `wx_get_stats64()`). `wx_clean_rx_ring()` must call `dma_sync_single_range_for_cpu(..., WX_RX_BUFSZ, DMA_FROM_DEVICE)` before `page_pool_put_full_page(..., false)`. `wx_sriov_clear_data()` must set `wx->num_vfs = 0` before freeing/nulling `vfinfo` and `mv_list`. [F14, F17, F162]
- Call `wx_get_mac_addr()` only after `wx_check_flash_load()` and HW reset in `ngbe_probe()`/`ngbe_reset_hw()`. Signal firmware via `wx_control_hw(wx, true)` in `ngbe_open()` and `wx_control_hw(wx, false)` in `ngbe_close()`, `ngbe_dev_shutdown()`, and `ngbe_probe()` rollback. In `ngbe_remove()` and `wxvf_remove()`, call `unregister_netdev()` before freeing `rss_key`/`mac_table`/`vfinfo` or `wx_clear_interrupt_scheme()` (in `ngbe_remove()`, `wx_disable_sriov()` precedes `unregister_netdev()` and `phylink_destroy()` follows it); never manually free devres-managed `netdev`, `hw_addr`, or `mii_bus`. [F126, F131, F132, F133]

## API Contracts

- `wx_tso()` must check `skb_cow_head(skb, 0)` before mutating headers; it returns `< 0` on error, `1` on TSO, and `0` otherwise (`wx_xmit_frame_ring()` drops on `< 0` and calls `wx_tx_csum()` only on `0`). In `wx_encode_tx_desc_ptype()`, `wx_tso()`, and `wx_tx_csum()`, use `ipv6_skip_exthdr()` for IPv6 extension headers and handle both `IPPROTO_IPIP` and `IPPROTO_IPV6` as tunnels. In `wx_tx_csum()`, if `CHECKSUM_PARTIAL` and L4 is not TCP/SCTP/UDP, call `skb_checksum_help(skb)` and jump to `csum_failed` without `WX_TX_FLAGS_CSUM`. In `wx_rx_checksum()`, bypass L4 offload if `WX_RXD_STAT_IPV6EX` is set on non-SCTP, and call `__skb_incr_checksum_unnecessary(skb)` when `dptype.etype >= WX_DEC_PTYPE_ETYPE_IG`. In `wx_get_rx_buffer()`, skip `dma_sync_single_range_for_cpu` on the first non-EOP buffer (`!*skb`) and save `WX_CB(skb)->dma` in `wx_build_skb()` for `wx_dma_sync_frag()` at EOP. [F36, F161, F165, F166, F169, F173]
- `wx_add_mac_filter()` returns RAR slot `>= 0` or negative errno, so callers (`wx_set_vf_mac()`, `wx_set_vf_macvlan()`) must check `ret >= 0` or `ret < 0`. In `WX_VF_SET_MACVLAN` (`wx_write_uc_addr_list_vf()`, `wx_set_uc_addr_vf()`, `wx_set_vf_macvlan()`), index 0 clears all filters, index 1 clears then adds the first, and index > 1 appends. `wx_write_mbx_pf/vf()` reject `size > mbx->size` (15 dwords) with `-EINVAL`, while `wx_read_mbx_pf/vf()` clamp `size` to `mbx->size`. [F35, F72, F80]
- `wx_host_interface_command()` requires `length` in `1..256` (`WX_HI_MAX_BLOCK_BYTE_LENGTH`) and a multiple of 4, and `_s()`/`_r()` reject replies where `length < buf_len + hdr_size` with `-EFAULT`. Callers populating `struct wx_hic_read_shadow_ram` (`wx_read_ee_hostif_data/buffer()`) must convert `address` with `cpu_to_be32()` and `length` with `cpu_to_be16()`. `wx_read_ee_hostif*()` take `@offset` and `@words` in 16-bit words (`eeprom->sw_region_offset` is `WX_SW_REGION_PTR` `data >> 1`). [F45, F71, F86]

## Error Handling

- `wx_setup_rx_resources()` allocates `rx_buffer_info`, `desc`, and `page_pool` in order and must jump to `err_desc` to free `rx_ring->desc` before `rx_buffer_info` if `wx_alloc_page_pool()` fails, while `wx_free_rx_resources()` must call `wx_clean_rx_ring()` before freeing any of them. In `wx_ptp_init()`, `seqlock_init(&wx->hw_tc_lock)` must precede `wx_ptp_create_clock()`. When storing `ERR_PTR` into `rx_ring->page_pool` (`wx_alloc_page_pool()`) or `wx->ptp_clock` (`wx_ptp_create_clock()`), extract `PTR_ERR()` before resetting the field to `NULL`. `wx_alloc_mapped_page()` must return `false` on `NULL` from `page_pool_dev_alloc_pages()` before `page_pool_get_dma_addr()`. [F5, F11, F32, F33]
- In `wx_set_interrupt_capability()`, set `wx->num_q_vectors = 1` on MSI/INTx fallback before `wx_alloc_q_vectors()`. In `wx_set_vfta()`, verify `wx_set_vlvf()` returned `0` before writing `WX_PSR_VLAN_TBL` or `vft_shadow`. [F41, F47]

## External Contracts

- `wx_xmit_frame()` must pad skbs via `skb_put_padto(skb, 17)` and return `NETDEV_TX_OK` without freeing `skb` on error. Keep BQL balanced across `wx_tx_map()` (`netdev_tx_sent_queue()`), `wx_clean_tx_irq()` (`netdev_tx_completed_queue()`), and `wx_clean_tx_ring()` (`netdev_tx_reset_queue()`). In `wx_rcv_msg_from_vf()`, NACK commands other than `WX_VF_RESET` if `!vfinfo[vf].clear_to_send`, and in `wx_set_vf_mac_addr()`/`wx_set_vf_macvlan_msg()` check `is_valid_ether_addr()` and `pf_set_mac`. [F170, F174, F176]

## Known Pitfalls

- Widen `u32` upper registers to `u64` before `<< 32` in `rd64()`, `wx_ptp_readtime()`, and `wx_ptp_tx/rx_hwtstamp()`; `wx_ptp_readtime()` must bracket `WX_TSC_1588_SYSTIML` with two reads of `SYSTIMH` and re-read `SYSTIML` if they differ. Use `1ULL << pool` or `BIT_ULL(pool)` for `wx->mac_table[i].pools` (`u64`, `pool` up to 63). In `wx_ptp_trigger_calc()` and `wx_ptp_setup_sdp()`, cast nanoseconds to `u64` before `<< cc->shift` and use `div_u64`/`div_u64_rem`. In `wx_poll()`, guard `budget / q_vector->rx.count` with `rx.count > 1` and clamp with `max(..., 1)`. Use `DIV_ROUND_UP` in `wx_alloc_q_vectors()`. [F109, F110, F111, F114, F116, F118]
- Clear `WX_VT_MSGTYPE_CTS` from `msgbuf[0]` before comparing against `OPCODE | WX_VT_MSGTYPE_ACK/NACK` after `wx_mbx_write_and_read_reply()`. After `list_for_each()` in `wx_set_vf_macvlan()`, test `!entry || !entry->free`. In `wx_get_ethtool_stats()`, advance `i += 2` only after the `u64_stats_fetch_retry()` loop. Pass `WX_RSS_KEY_SIZE` (40), not `sizeof(wx->rss_key)`, when copying `wx->rss_key` (`u32 *`). Compare `jiffies` timestamps in `wx_ptp_overflow_check()` and `wx_ptp_rx/tx_hang()` with `time_is_before_jiffies()` and `time_after()`. [F66, F98, F102, F117, F119]
