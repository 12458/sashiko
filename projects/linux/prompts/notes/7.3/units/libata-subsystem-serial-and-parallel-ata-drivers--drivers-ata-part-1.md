# LIBATA SUBSYSTEM (Serial and Parallel ATA drivers) — drivers/ata (part 1)

This component contains the AHCI library (`libahci.c`, `ahci.h`), PCI and SoC platform AHCI drivers (`ahci.c`, `ahci_imx.c`, `ahci_tegra.c`, `ahci_xgene.c`, `ahci_brcm.c`, `ahci_dwc.c`, etc.), PCI SATA/PATA host drivers (`acard-ahci.c`, `ata_piix.c`, `ata_generic.c`), and the libata ACPI binding layer (`libata-acpi.c`).

## Architecture & Data Flow

- When enabling FIS-based switching (`pp->fbs_enabled`) in `ahci_enable_fbs()`, reset `pp->fbs_last_dev = -1`; when writing a new PMP index to `PORT_FBS` (`ahci_qc_issue`, `ahci_exec_polled_cmd`), clear `PORT_FBS_DEC` and update `pp->fbs_last_dev`. Allocate `AHCI_PORT_PRIV_FBS_DMA_SZ` (`AHCI_RX_FIS_SZ * 16` before `pp->cmd_tbl`, or `ACARD_AHCI_RX_FIS_SZ * 16` in `acard_ahci_port_start()`) whenever `pp->fbs_supported` is true. `pp->active_link` is only valid when `!pp->fbs_enabled && ap->qc_active`; when `pp->fbs_enabled`, `ahci_qc_complete()`, `ahci_qc_fill_rtf()`, `ahci_qc_ncq_fill_rtf()`, and `acard_ahci_qc_fill_rtf()` must not use `pp->active_link` and must offset `pp->rx_fis` by `qc->dev->link->pmp * AHCI_RX_FIS_SZ` (256, or `ACARD_AHCI_RX_FIS_SZ` (128) on `acard_ops`). [F61, F62, F93, F126, F127]
- In `ahci_qc_fill_rtf()`, PIO data-in completions (`ATA_PROT_PIO && DMA_FROM_DEVICE && !(qc->flags & ATA_QCFLAG_EH)`) and NCQ commands (`ata_is_ncq`) must return before reading `RX_FIS_D2H_REG`. In `ahci_qc_ncq_fill_rtf()`, both `while (done_mask)` loops must clear `done_mask &= ~(1ULL << tag)` unconditionally on every iteration even if `!qc` or `!ata_is_ncq`. [F108, F115, F119]
- In `ahci_handle_port_interrupt()`, mask `PORT_IRQ_BAD_PMP` (when `ATA_PFLAG_RESETTING`) and `PORT_IRQ_PHYRDY` (when `sata_lpm_ignore_phy_events(&ap->link)`) out of `status` before testing `status & PORT_IRQ_ERROR`. In `ahci_error_intr()`, read and write back `SCR_ERROR` (`ahci_scr_write`); check `(fbs >> PORT_FBS_DWE_OFFSET) < ap->nr_pmp_links` before indexing `ap->pmp_link`; set `if (!link) link = &ap->link;` before accessing `link`; record link-specific errors (`PORT_IRQ_TF_ERR` without `active_qc`, `PORT_IRQ_UNK_FIS`, `PORT_IRQ_BAD_PMP`, `PORT_IRQ_IF_ERR` with `fbs_need_dec`) on `active_ehi` (`&link->eh_info`) and port-wide/hotplug errors on `host_ehi` (`&ap->link.eh_info`). [F95, F106, F110, F117, F153]
- Before `sata_link_hardreset()` with `ahci_check_ready` (`ahci_do_hardreset`, `xgene_ahci_do_hardreset`, `ahci_qoriq_hardreset`, `ahci_avn_hardreset`), write `tf.status = ATA_BUSY` to `pp->rx_fis + RX_FIS_D2H_REG` via `ata_tf_to_fis()`, and only set `*class` when `online` is true; `ahci_do_hardreset()` must call `ahci_port_clear_pending_irq(ap)` after `hpriv->stop_engine(ap)`. Before `ahci_init_controller()` sets `HOST_IRQ_EN`, stop each non-dummy port via `ahci_deinit_port()` and clear pending IRQs via `ahci_port_clear_pending_irq()`. Update `pp->intr_mask` when changing port interrupts, and do not write `PORT_IRQ_MASK` in `ahci_pmp_attach()`/`detach()` when `ata_port_is_frozen(ap)`. [F52, F63, F136, F137]
- `ahci_save_initial_config()` must save `saved_cap`/`saved_cap2` before applying `AHCI_HFLAG_*` overrides so `ahci_restore_initial_config()` writes `saved_cap`/`saved_cap2` to `HOST_CAP`/`HOST_CAP2`. Size the host port array as `max(ahci_nr_ports(hpriv->cap), fls(hpriv->port_map))` in `ahci_init_one()` and `acard_ahci_init_one()`. Set `ATA_FLAG_NO_LPM` and `ATA_LPM_MAX_POWER` in `ahci_update_initial_lpm_policy()` if `ATA_PFLAG_EXTERNAL` or if `ATA_HOST_NO_PART`, `ATA_HOST_NO_SSC`, and `ATA_HOST_NO_DEVSLP` are all set; clamp `dito` to `0x3ff` in `ahci_set_aggressive_devslp()`. [F60, F96, F122, F144]
- `ahci_mvebu_stop_engine()` must save/restore `PORT_FBS` around clearing `PORT_CMD_START`; both `ahci_stop_engine()` and `ahci_mvebu_stop_engine()` must test `(tmp & (PORT_CMD_START | PORT_CMD_LIST_ON)) == 0` for idle early return. In `ahci_xgene.c`, `xgene_ahci_hardreset()` must save/restore `PORT_CMD`, `PORT_LST_ADDR`/`_HI`, and `PORT_FIS_ADDR`/`_HI`; `xgene_ahci_restart_engine()` must call `ahci_start_fis_rx()` and re-enable `PORT_FBS_EN` after `stop_engine()`; `xgene_ahci_softreset()` sets `ctx->class[ap->port_no]`, and `xgene_ahci_qc_issue()` writes `pmp` to `PORT_FBS` when `ATA_DEV_PMP` and updates `ctx->last_cmd[ap->port_no]`. [F78, F79, F80, F105]
- `ahci_qoriq_hardreset()` must save/restore `PORT_CMD` and `PORT_IRQ_STAT` on `AHCI_LS1021A`. `ahci_dwc_init_timer()`/`init_dmacr()` must cache `dpriv->timv` and `dpriv->dmacr[port]` for `ahci_dwc_reinit_host()`. In `ahci_imx.c`, `__sata_ahci_read_temperature()` must save/restore `SATA_PHY_CR_CLOCK_MPLL_TST`, `RTUNE_CTL`, and `DAC_CTL`, and floor `m2` (`if (!(m2 / 1000)) m2 = 1000;`); `read_adc_sum()` must increment `read_attempt` on every read and break when `> attempt_limit`. [F81, F82, F84, F116, F123]
- In `libata-acpi.c`, use `ata_dev_acpi_handle(dev)` (not `ACPI_HANDLE(&dev->tdev)`); pass `ACPI_COMPANION(ap->host->dev)` as `parent` in `ata_acpi_bind_dev()` when `ATA_FLAG_ACPI_SATA` else `ACPI_COMPANION(&ap->tdev)`; retrieve `ap->__acpi_init_gtm` only via `ata_acpi_init_gtm(ap)` and null-check it; call `swap_buf_le16(dev->id, ATA_ID_WORDS)` before and after `_SDD` in `ata_acpi_push_id()`, and `ata_dev_reread_id(dev, 0)` in `ata_acpi_on_devcfg()` when `nr_executed > 0`. [F47, F48, F76, F118]
- In `ata_piix.c`, `piix_init_one()` must save/restore `PIIX_IOCFG` (`hpriv->saved_iocfg`), copy `piix_port_info` to local `port_info[2]` before `piix_init_sata_map()` (which masks `map_value & map_db->mask` and pairs even/odd `IDE` entries via `i++`), and in `piix_init_sidpr()` call `ata_slave_link_init(ap)` if `ATA_FLAG_SLAVE_POSS` and use `&piix_sidpr_sht`. `piix_set_timings()` clears the UDMA bit in `0x48` and sets DTE (`control |= 8`) only if MWDMA exceeds `adev->pio_mode` (`set_dmamode` must follow `set_piomode`). On broken-suspend systems, set/clear `PIIX_HOST_BROKEN_SUSPEND` and call `pci_reenable_device()` on resume. Keep `{ 0, }` at the end of `ich_laptop[]` and `PCI_ANY_ID` class entries last in `ata_generic[]` and `ahci_pci_tbl[]`. [F72, F73, F74, F75, F99, F103, F151]

## Synchronization

- Hold `&host->lock` with IRQs disabled when calling `ahci_handle_port_intr()`. Clear `HOST_IRQ_STAT` with unmasked `irq_stat` under `&host->lock` after `ahci_handle_port_intr()` in `ahci_single_level_irq_intr()` and `ahci_thunderx_irq_handler()`, but before `xgene_ahci_handle_broken_edge_irq()` in `xgene_ahci_irq_intr()`. With `AHCI_HFLAG_MULTI_MSI`, `ahci_port_start()` must init `pp->lock` and set `ap->lock = &pp->lock`. [F23, F25, F26, F161]
- Stop DMA (`hpriv->stop_engine`) before `ahci_stop_fis_rx()` in `ahci_deinit_port()`, and call `ahci_start_fis_rx()` before `hpriv->start_engine` in `ahci_start_port()`. `xgene_ahci_restart_engine()` must poll `PORT_CMD_ISSUE` to `0` before `stop_engine()`. [F31, F34]
- Update `emp->led_state` under `ap->lock` in `ahci_transmit_led_message()` and `seattle_transmit_led_message()`, and sync `ATA_LFLAG_SW_ACTIVITY` with `emp->blink_policy` in `ahci_activity_store()`. In `ahci_sw_activity_blink()`, hold `ap->lock` across `emp->saved_activity` checks and `mod_timer()`, releasing it before `transmit_led_message()`. Retry `-EBUSY` LED transmission in `ahci_start_port()` with `msleep(1)` (not `ata_msleep`). [F28, F30, F67]
- Clear and flush `HOST_IRQ_EN` in `HOST_CTL` before PCI AHCI suspend or D3 (`ahci_pci_device_suspend`, `ahci_pci_device_runtime_suspend`, `acard_ahci_pci_device_suspend`). Platform AHCI drivers (`imx`, `dwc`, `qoriq`, `ceva`, `sunxi`) must call `ahci_platform_suspend_host()` before disabling clocks/PHYs and re-enable resources before `ahci_platform_resume_host()`. [F36, F41]
- In `brcm_ahci_read_id()` recovery, hold `&host->lock` (`spin_lock_irqsave`) to clear/flush `HOST_IRQ_EN`, drop it across `msleep`/`phy_init`/`phy_calibrate`, and re-acquire to set `HOST_IRQ_EN`. In `ata_acpi_handle_hotplug()`, hold `ap->lock` while updating `eh_info` and calling `ata_port_freeze()`/`ata_acpi_detach_device()`, and unlock before `ata_port_wait_eh()`. In `ata_piix.c`, hold `piix_lock` for PCI regs `0x40`-`0x54`, masking only target bits and keeping SITRE (`0x4000`) set in `0x40`/`0x42`. [F37, F39, F71]

## Object Lifetimes

- Call `pcim_pin_device(pdev)` if `pcim_request_all_regions()` returns `-EBUSY` in `ahci_init_one()`/`acard_ahci_init_one()`. Call `pci_free_irq_vectors(pdev)` in `ahci_init_irq()` if multi-MSI succeeds but `HOST_MRSM` is set. In `ahci_init_one()`/`ahci_remove_one()`, remove `dev_attr_remapped_nvme` on error and remove, call `pm_runtime_put_noidle()` only after `ahci_host_activate()`, and call `pm_runtime_get_noresume()` before `ata_pci_remove_one()`. [F2, F3, F4, F140]
- Balance `ahci_rpm_get_port(ap)` (`ahci_port_resume`/`start`) with `ahci_rpm_put_port(ap)` (`ahci_port_suspend`/`stop`), and bracket all sysfs/LED MMIO accesses (`ahci_show_port_cmd`, `ahci_read_em_buffer`, `ahci_store_em_buffer`, `ahci_show_em_supported`, `ahci_transmit_led_message`) with `ahci_rpm_get_port`/`put_port`. [F5, F158]
- `ahci_host_activate_multi_irqs()` must call `ata_host_start()` before `devm_request_irq()` and `disable_irq()` on dummy ports (`!pp`) before `ata_host_register()`. `ahci_init_sw_activity()` must init `emp` and `timer_setup(&emp->timer, ...)` before setting `ATA_LFLAG_SW_ACTIVITY`. `piix_disable_ahci()` must call `pci_iounmap()` after `pci_iomap()`. [F22, F24, F27]
- In `ahci_brcm.c`, enable clocks/regulators, then call `brcm_sata_init(priv)` (before any `hpriv->mmio` access) and `brcm_sata_phys_enable(priv)` before `ahci_platform_enable_phys(hpriv)` (and `ahci_platform_resume_host()`, not `ahci_platform_resume()`), unwinding via `brcm_sata_phys_disable()` and `ahci_platform_disable_*`; use `brcm_sata_readreg`/`writereg` for `priv->top_ctrl`. [F9, F83, F101, F159]
- Unwind resources in reverse order in `ceva_ahci_platform_enable_resources()`/`probe()`/`resume()`, `tegra_ahci_power_on()`/`off()`, and `ahci_dwc.c` (calling `dpriv->pdata->clear(hpriv)` before `ahci_platform_disable_resources(hpriv)`). In `ahci_imx.c`, call `imx_sata_disable(hpriv)` before disabling `sata_clk`; set `imxpriv->no_device = true` in `ahci_imx_error_handler()` only after `imx_sata_disable()` (which returns early if `no_device`); in `imx8_sata_enable()`, power off and exit `cali_phy1` then `cali_phy0` on error and right after `phy_power_on(sata_phy)`. [F8, F11, F12, F13, F14, F15]
- In `libata-acpi.c`, `kfree(output.pointer)` on all paths in `ata_acpi_gtm()`; `ata_dev_get_GTF()` returns `0` on `AE_NOT_FOUND` or `-EINVAL` on error, and `dev->gtf_cache` (outer `union acpi_object *`) must be freed via `ata_acpi_clear_gtf(dev)` on validation error, after `ata_acpi_exec_tfs()`, before re-caching in `ata_acpi_on_resume()`, and in `ata_acpi_on_disable()`. Init `context->data.ap`/`.dev` before `acpi_initialize_hp_context()`, and only read the matching union member in port vs device hotplug callbacks. [F18, F38, F44, F129, F132, F141]

## API Contracts

- Define `AHCI_SHT(drv_name)` per edge driver. With `AHCI_HFLAG_MULTI_MSI`, set `hpriv->get_irq_vector` (no custom `irq_handler`); per-port IRQs pass `struct ata_port *` to `ahci_multi_irqs_intr_hard()`, while single-IRQ passes `struct ata_host *` to `hpriv->irq_handler`. [F134, F176, F178]
- Call `ahci_enable_ahci()` before reading `HOST_CAP` in `ahci_save_initial_config()` and before/after `HOST_RESET` in `ahci_reset_controller()`. Stop and restart the port DMA engine around modifying `PORT_FBS_EN` in `PORT_FBS` or programming `PORT_DEVSLP`. Check `HOST_VERSION >= 1.2` before `HOST_CAP2` and `HOST_CAP_SNTF` before `PORT_SCR_NTF`; bounds-check `sc_reg` in `ahci_scr_offset()` and `reg` in `piix_sidpr_scr_read()`/`write()`; only mask `port_map` with `hpriv->mask_port_map` when non-zero. [F65, F97, F104, F135, F143]
- Zero 32-byte `AHCI_CMD_TBL_CDB` before copying `qc->cdb` in `ahci_qc_prep()`/`acard_ahci_qc_prep()`, and zero `pp->cmd_slot[tag].status` in `ahci_fill_cmd_slot()`. `.read_id` callbacks (`brcm`, `ceva`, `xgene`) return an `AC_ERR_*` mask (map `-errno` to `AC_ERR_OTHER`) and use `cpu_to_le16()` on `__le16 *id`. [F43, F55, F102]
- Check `pdev` bus/slot/devfn in DMI quirks (`ahci.c`, `ata_piix.c`); use `board_ahci` (not `board_ahci_pcs_quirk`) for new Intel IDs; keep `pdev->dma_mask < DMA_BIT_MASK(32)` intact in `ahci_configure_dma_masks()`; require `PCI_COMMAND_IO` before `pcim_enable_device()` in `ata_generic_init_one()`; pass `hwmon_dev` (not `&pdev->dev`) to `devm_thermal_of_zone_register()` in `ahci_imx.c`. [F133, F146, F147, F148, F149]

## Error Handling

- Set `ret = PTR_ERR(...)` before jumping to error labels in `imx_ahci_probe()`. In `ahci_stop_engine()`, wake the link via `ahci_set_lpm()` if `AHCI_HFLAG_WAKE_BEFORE_STOP` and `lpm_policy > ATA_LPM_MAX_POWER`, and return `-ENODEV` if `PORT_CMD == 0xffffffff`. Null-check `dmi->driver_data` before `strcmp()` in `ahci_broken_lpm()`/`ahci_sb600_enable_64bit()`. Ratelimit warnings in `ahci_handle_port_intr()`/`ahci_read_em_buffer()` (no `WARN_ON`). Return `0` on `AC_ERR_DEV`/filtered taskfiles in `ata_acpi_run_tf()`/`exec_tfs()`. [F42, F109, F145, F155, F185]

## External Contracts

- `ahci_fill_sg()` encodes `cpu_to_le32(sg_len - 1)` and `n_elem << 16` in `opts`; `acard_ahci_fill_sg()` encodes `cpu_to_le32(sg_len)` with bit 31 on the last SG and no `n_elem` in `opts`. `ahci_set_em_messages()` multiplies `HOST_EM_LOC` offset/size by 4 into `em_loc`/`em_buf_sz`; `ahci_read_em_buffer()` adds `em_buf_sz` when `!(em_ctl & EM_CTL_SMB)`; `ahci_store_em_buffer()` checks `size % 4 == 0 && size <= em_buf_sz`; bounds-check `pmp` against `EM_MAX_SLOTS` (with `array_index_nospec()` in `ahci_led_store()`). Validate `ACPI_TYPE_BUFFER` and length in `ata_acpi_gtm()` (`sizeof(struct ata_acpi_gtm)`) and `ata_dev_get_GTF()` (`% REGS_PER_GTF == 0`), and force `unit = 0` when `!(gtm->flags & 0x10)` in `ata_acpi_gtm_xfermask()`. [F56, F57, F68, F88, F89, F91, F130, F182]

## Known Pitfalls

- Add byte offsets to `void *` `pp->cmd_tbl`/`pp->rx_fis` before casting; use `const unsigned char *` in `ahci_store_em_buffer()`; shift `dma_addr_t` upper bits as `(addr >> 16) >> 16`; copy `u32` `port_map` into an `unsigned long` local before `for_each_set_bit()`. Keep `i` signed in `brcm_ahci_read_id()` and `ceva_ahci_platform_enable_resources()` for `while (--i >= 0)`; guard `deadline - now` with `time_after()` in `ahci_do_softreset()`; pre-divide `refclk_rate` by 10/100 in `ahci_da850`/`dm816`; override `.pmp_reset` with `.reset` on PMP ports. [F100, F120, F121, F124, F125, F128, F131, F180]
