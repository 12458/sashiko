# DRIVER CORE, KOBJECTS, DEBUGFS AND SYSFS — (top level) (part 1)

Implements core Linux device model subsystems (platform bus, NUMA node and CPU topology sysfs interfaces, SoC bus, syscore PM, pinctrl binding, MSI helpers, transport classes), sysfs and debugfs filesystems, and core headers for devices, buses, classes, drivers, devres, kobjects, and firmware properties.

## Architecture & Data Flow
- `struct bin_attribute` must keep `struct attribute attr` at offset 0 because `sysfs_add_bin_file_mode_ns()` passes `&battr->attr` as `priv` to `__kernfs_create_file()`, while `sysfs_kf_bin_*()` cast `of->kn->priv` directly to `const struct bin_attribute *`. [F118]
- In `sysfs_kf_read()`, `buf` must equal `of->prealloc_buf` before `ops->show(kobj, of->kn->priv, buf)`, and non-zero `pos` is shifted in place via `memmove(buf, buf + pos, len)`. [F67]
- In `internal_create_group()` and `sysfs_remove_group()`, call `kernfs_remove(kn)` only if `grp->name` is non-NULL (otherwise `kn` aliases `kobj->sd`). In `__first_visible()`, check both the array pointer and `[0]` of `grp->attrs` and `grp->bin_attrs` for non-NULL (groups like `initiators`/`targets` in `node.c` have `{ NULL }` arrays); when both `attrs` and `bin_attrs` are defined, group directory visibility uses `grp->is_visible(kobj, grp->attrs[0], 0)` exclusively, not `grp->is_bin_visible()`. [F51, F69, F98]
- In `sysfs_link_change_owner()` and `sysfs_rename_link_ns()`, look up `kn` under `kobj->sd` using `targ->sd->ns` (not `kobj->sd->ns`), and verify `kernfs_type(kn) == KERNFS_LINK` and `kn->symlink.target_kn->priv == targ` before modifying `kn`. [F109]
- In `__debugfs_create_file()`, if `real_fops` is NULL, set `inode->i_fop = &debugfs_noop_file_operations` (not `proxy_fops`), and `mode` must not set `S_IFMT` bits other than `S_IFREG`. Each `FULL_PROXY_FUNC` or `SHORT_PROXY_FUNC` in `debugfs_full_proxy_file_operations` and `debugfs_full_short_proxy_file_operations` checks `fsd->methods & bit`, so `__debugfs_file_get()` must set the matching `HAS_*` bit for every proxied callback. [F49, F65]
- In `debugfs_parse_param()`, evaluate `BIT(opt)` only after `fs_parse()` returns `>= 0` (fitting in `unsigned int` `debugfs_fs_info::opts`). In `_debugfs_apply_options()` with `remount == true`, update only root inode fields (`i_mode`, `i_uid`, `i_gid`) whose `BIT(Opt_*)` is set in `fsi->opts`, preserving `~S_IALLUGO` bits on `i_mode`. [F58, F113]
- In `devm_platform_get_irqs_affinity()`, set `ptr->count = nvec` before indexing `ptr->irq[]` (`__counted_by(count)`), after validating `maxvec >= minvec` and clamping `nvec` to `[minvec, maxvec]`. Reverse rollback loops over unsigned indices in `platform_device_add()`, `__platform_register_drivers()`, and `platform_unregister_drivers()` must use post-decrement `while (i--)` or `while (count--)` to avoid underflow. [F83, F85]
- In `drivers/base/node.c`: `node_state_attr[]` needs `NR_NODE_STATES` elements and `node_state_attrs[]` needs `NR_NODE_STATES + 1`; `node_set_perf_attrs()` and `node_update_perf_attrs()` must call `mempolicy_set_node_perf(nid, coord)` when updating `ACCESS_COORDINATE_CPU`; `register_memory_node_under_compute_node()` must link `"targets"` under `&initiator->dev.kobj` to `&targ_node->dev.kobj` and `"initiators"` under `&target->dev.kobj` to `&init_node->dev.kobj`. [F62, F88, F102]
- In `drivers/base/soc.c`, every attribute in `soc_attr[]` must be handled in both `soc_attribute_mode()` and `soc_info_show()`. [F64]
- In `struct property_entry`, `is_inline` selects `value` (`true`) vs `pointer` (`false`), and `length` is byte size (`_len_ * sizeof(element)`), not element count. [F56]

## Synchronization
- In `__debugfs_file_get()`, initialize all `struct debugfs_fsdata` fields (`active_users`, `active_users_drained`, `cancellations`, `cancellations_mtx`) before `cmpxchg(&dentry->d_fsdata, NULL, fsd)` (destroying `cancellations_mtx` before `kfree(fsd)` if `cmpxchg` loses); check `d_unlinked(dentry)` after `cmpxchg` and before `refcount_inc_not_zero(&fsd->active_users)`, pairing with `smp_mb()` before `READ_ONCE(dentry->d_fsdata)` in `__debugfs_file_removed()`. [F20, F21]
- In `__debugfs_file_removed()`, `refcount_dec_and_test(&fsd->active_users)` returns `true` when the initial reference was the last—return immediately on `true`, and enter the cancellation and `wait_for_completion(&fsd->active_users_drained)` loop only on `false`. [F90]
- `fsd->cancellations` is protected by `fsd->cancellations_mtx`: `__debugfs_file_removed()` must dequeue with `list_del_init(&c->list)` and call `c->cancel()` under `cancellations_mtx`; `debugfs_leave_cancellation()` checks `!list_empty(&cancellation->list)` under `cancellations_mtx`; and `debugfs_enter_cancellation()` must check `d_unlinked(dentry)` after unlocking `cancellations_mtx` and call `complete(&fsd->active_users_drained)` if true. [F22, F23]
- In `fs/sysfs/file.c`, `sysfs_file_kobj()` must read `rcu_dereference(kn->__parent)->priv` under RCU, and `sysfs_file_ops()` requires an active reference on `kn`. [F27]
- Sysfs binary read callbacks formatting live cpumasks (`cpumap_read()`, `cpulist_read()`, `define_siblings_read_func()`) must copy the cpumask into a local `cpumask_var_t` before calling `cpumap_print_bitmask_to_buf()` or `cpumap_print_list_to_buf()`. [F59]
- In `platform_dma_configure()`, load `READ_ONCE(dev->driver)` once and check non-NULL before `to_platform_driver(drv)->driver_managed_dma` (races with async driver binding). `device_lock_set_class()` and `device_lock_reset_class()` require `device_lock(dev)` held, and `device_lock_set_class()` requires `dev->mutex` to match `__lockdep_no_validate__`. [F29, F156]

## Object Lifetimes
- Once `platform_device_alloc()` or `platform_device_register()` initializes `pdev->dev`, never call `kfree(pdev)` on error—use `platform_device_put(pdev)`. `platform_device_add_resources()` and `platform_device_add_data()` must allocate the new `kmemdup*()` copy before calling `kfree()` on existing `pdev->resource` or `pdev->dev.platform_data` (freed in `platform_device_release()`). On `platform_device_add()` failure or `platform_device_del()`, if `pdev->id_auto` is set, call `ida_free(&platform_devid_ida, pdev->id)` and reset `pdev->id = PLATFORM_DEVID_AUTO`, and call `release_resource(r)` on claimed resources (`r->parent != NULL`). [F5, F6, F7]
- In `soc_device_register()`, once `soc_dev->dev.release = soc_release` is set, `device_register()` failure must clean up via `put_device(&soc_dev->dev)` without jumping to `out3`, while `soc_dev->attr` stays caller-owned until after `soc_device_unregister()`. [F9]
- In `unregister_node()`, unregister all children and attributes (`node_remove_accesses()`, `node_remove_caches()`—which unregisters `node->cache_attrs` before `node->cache_dev`—and hugetlb/compaction/reclaim) before `device_unregister(&node->dev)`, and clear `node_devices[nid] = NULL` in `unregister_one_node()`. `node_remove_accesses()` and `node_remove_caches()` must use `list_for_each_entry_safe()` because `device_unregister()` frees the current entry in `node_access_release()` / `node_cacheinfo_release()`. [F2, F101]
- `transport_remove_device()` only removes sysfs visibility and runs the transport remove callback; callers not using `transport_unregister_device()` must also call `transport_destroy_device()` to put `classdev` and `dev`. [F143]
- `devm_*` resources/actions are released during `device_del()` even if the device has no driver/bus or a devm action holds `get_device()`. `debugfs_create_devm_seqfile()` allocates `inode->i_private` via `devm_kzalloc(dev, ...)` without a dentry-removal callback, so its debugfs file/directory must be removed before `dev`'s devres release. [F130, F132]
- After `debugfs_start_creating()` succeeds, error paths must call `failed_creating(dentry)` (unlocking the parent inode, calling `dput()`, and releasing the `simple_pin_fs()` pin) and free caller allocations (e.g., `link` in `debugfs_create_symlink()`). [F15]
- Pair `debugfs_enter_cancellation()` with `debugfs_leave_cancellation()` before the stack `struct debugfs_cancellation` goes out of scope and before `debugfs_file_put()`. Callers must set `cancellation->cancel != NULL`, and `debugfs_enter_cancellation()` must run `INIT_LIST_HEAD(&cancellation->list)` before any `WARN_ON()` early return. [F13, F48]
- `full_proxy_release()` must call `real_fops->release(inode, file)` unconditionally without `debugfs_file_get()`, and `.release` handlers must not dereference `inode->i_private` assuming the file wasn't removed. For writable `debugfs_create_str()` (`mode & S_IWUGO`), `@value` (`char **`) must point to a `kmalloc`-allocated string because `debugfs_write_file_str()` `kfree()`s the old `*value`. [F24, F122]
- `sysfs_break_active_protection()` pins `kobj` and `kn` before `kernfs_break_active_protection(kn)`; `sysfs_unbreak_active_protection()` must read `kobj = sysfs_file_kobj(kn)` before `kernfs_unbreak_active_protection(kn)` and `kernfs_put(kn)`, and never access `kn` after. [F28]
- Early exits (`break`/`return`/`goto`) from `fwnode_for_each_child_node()`, `fwnode_for_each_available_child_node()`, or `device_for_each_child_node()` must call `fwnode_handle_put(child)` (or use `_scoped` variants). [F19]

## API Contracts
- `platform_get_irq*()` treat IRQ 0 as invalid (`-EINVAL` with warning) and return `> 0` on success or `< 0` on error. `platform_get_resource*()`, `platform_get_mem_or_io()`, and `platform_device_alloc()` return `NULL` on failure, whereas `devm_platform_*ioremap_resource*()`, `platform_device_register_full()`, and `__platform_create_bundle()` return `ERR_PTR()` and never `NULL`. In `platform_dma_configure()` / `platform_dma_cleanup()`, the platform bus claims the default IOMMU domain unless `to_platform_driver(drv)->driver_managed_dma` is `true`. [F34, F35, F36, F142]
- `__devm_add_action_or_reset()` / `devm_add_action_or_reset()` call `action(data)` immediately on failure, so callers must not call `action(data)` again. Devres array helpers (`devm_kmalloc_array`, `devm_krealloc_array`, `devm_kmemdup_array`) must guard against `size_t` multiplication overflow via `check_mul_overflow()` or `size_mul()`. [F18, F114]
- `debugfs_file_get()` uses `DBGFS_GET_ALREADY` (warning and returning `-EINVAL` if `d_fsdata` is unallocated); `.open` proxy handlers must call `__debugfs_file_get()` with `DBGFS_GET_REGULAR` or `DBGFS_GET_SHORT` and map `-EIO` to `-ENOENT`. For `debugfs_create_file()`, `real_fops->open` must not replace `filp->f_op`; for `debugfs_create_file_unsafe()`, `open_proxy_open()` replaces `filp->f_op` with `real_fops`, so non-open callbacks accessing removal-sensitive data must bracket accesses with `debugfs_file_get()` / `debugfs_file_put()`. [F44, F159, F161]
- In `debugfs_start_creating()`, `debugfs_lookup()`, and `debugfs_create_devm_seqfile()`, `parent == NULL` is valid (root), so reject only `IS_ERR(parent)`, never `IS_ERR_OR_NULL(parent)`. `debugfs_create_*()` return `ERR_PTR()` on failure or `CONFIG_DEBUG_FS=n` (never `NULL`), whereas `debugfs_lookup()` returns `NULL` on failure when `CONFIG_DEBUG_FS=y` and `ERR_PTR(-ENODEV)` when `CONFIG_DEBUG_FS=n`. Signed scalar attributes using `DEFINE_DEBUGFS_ATTRIBUTE_XSIGNED` (e.g., `fops_atomic_t`) must use `DEFINE_DEBUGFS_ATTRIBUTE_SIGNED` (`debugfs_attr_write_signed`). [F45, F46, F110]
- `sysfs_emit()` and `sysfs_emit_at()` require page-aligned `buf` (`!offset_in_page(buf)`), and `sysfs_emit_at()` requires `0 <= at < PAGE_SIZE` and returns bytes written at `buf + at` (use `len += sysfs_emit_at(buf, len, ...)`). Heap-allocated `struct attribute` / `struct bin_attribute` must call `sysfs_attr_init()` / `sysfs_bin_attr_init()` (unless `ignore_lockdep` is set). Attributes using `sysfs_bin_attr_simple_read()` (`BIN_ATTR_SIMPLE_RO()`, `BIN_ATTR_SIMPLE_ADMIN_RO()`) must set `.private` and non-zero `.size` (or `.bin_size`) so `sysfs_kf_bin_read()` bounds-checks `memcpy()`. [F50, F52, F75]
- `fwnode_property_read_string_array()` and `device_property_read_string_array()` return positive string count on success when `val != NULL` (or `< 0` on error), unlike `fwnode_property_read_u8/u16/u32/u64_array()` and `fwnode_property_read_string()` which return `0`. `device_is_big_endian()` and `fwnode_device_is_big_endian()` return `true` only with `"big-endian"` or `CONFIG_CPU_BIG_ENDIAN` + `"native-endian"`. `dev_fwnode()` must preserve `const` from `const struct device *` via `_Generic`. [F55, F125, F139]
- `soc_device_match()` requires `struct soc_device_attribute` match tables to terminate with an entry where `machine`, `family`, `revision`, and `soc_id` are all `NULL`. System sleep paths checking smart suspend must call `dev_pm_smart_suspend(dev)`, not `dev_pm_test_driver_flags(dev, DPM_FLAG_SMART_SUSPEND)`. [F108, F141]

## Error Handling
- In `devm_platform_get_irqs_affinity()`, `desc` from `irq_create_affinity_masks()` must be freed via `kfree(desc)` on both error and success paths, and `ptr` must be freed with `devres_free(ptr)` if failing before `devres_add()`. In `platform_device_add()`, `failed:` unwinds resources via `while (i--)`, requiring `i` to be the failing resource index from `insert_resource()` or `pdev->num_resources` from `device_add()`. [F8, F104]
- In `modalias_show()` and `platform_uevent()`, OF and ACPI modalias helpers fall back to the next source only on `-ENODEV`; any other negative error or non-negative result must return immediately. In `pinctrl_bind_pins()`, failure must free `dev->pins`, set `dev->pins = NULL`, and propagate only `-ENOMEM`, `-EPROBE_DEFER`, or `-EINVAL` (converting other errors like `-ENOENT`/`-ENODEV` to `0`). [F37, F41]
- When `transport_add_class_device()` fails at `sysfs_create_group()`, call `attribute_container_class_device_del(classdev)` before `tclass->remove(tcont, dev, classdev)`; if `attribute_container_add_class_device()` fails, still call `tclass->remove()`. [F11]
- In `sysfs_merge_group()` and `sysfs_create_files()`, the `for` loop checks `!error` / `!err` after incrementing `i` (and `attr`), so `while (--i >= 0)` pre-decrements; do not add an early `break` inside the loop without adjusting rollback indexing. Where duplicate symlinks are expected at runtime (e.g., `do_register_memory_block_under_node()`), use `sysfs_create_link_nowarn()` instead of `sysfs_create_link()` and ratelimit non-`-EEXIST` errors. [F99, F169]

## External Contracts
- `debugfs_parse_param()` must ignore unknown mount options (`-ENOPARAM` from `fs_parse()`) by returning `0`, and `debugfs_param_specs` must keep `fsparam_string("source", Opt_source)` to populate `fc->source`. `debugfs_write_file_str()` rejects non-zero `pos != strlen(old)` with `-EINVAL`, rejects `pos + count + 1 > PAGE_SIZE` with `-E2BIG`, and publishes the new string via `rcu_assign_pointer()` + `synchronize_rcu()` before freeing `old`. [F80, F163]
- In `drivers/base/physical_location.c` (`panel_show()`, `vertical_position_show()`, `horizontal_position_show()`), `switch` statements must handle every non-unknown enum variant before `default`. [F94]

## Known Pitfalls
- Do not tag pointers in `debugfs_inode_info` or `dentry->d_fsdata` with bit 1; distinguish regular `file_operations` and `debugfs_short_fops` via proxy fops and `enum dbgfs_get_mode`. Expose `unsigned long` in hex via `debugfs_create_xul()`, never by casting `unsigned long *` to `u64 *` for `debugfs_create_x64()`. [F78, F79]
- `platform_device_msi_init_and_alloc_irqs()` passes `nvec - 1` to `msi_domain_alloc_irqs_range()`, so `nvec` must be `>= 1` to avoid unsigned underflow. Topology and NUMA cpumask/cpulist sysfs attributes in `topology.c` and `node.c` must use `BIN_ATTR_RO()` sized with `CPUMAP_FILE_MAX_BYTES` or `CPULIST_FILE_MAX_BYTES`, not `PAGE_SIZE`-limited `DEVICE_ATTR`. [F84, F126]
