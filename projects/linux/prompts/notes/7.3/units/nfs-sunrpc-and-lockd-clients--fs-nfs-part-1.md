# NFS, SUNRPC, AND LOCKD CLIENTS — fs/nfs (part 1)

This unit implements core NFS client functionality: shared client/server lifecycle (`client.c`), file and directory VFS operations (`file.c`, `dir.c`), direct/swap I/O (`direct.c`), NFSv4 delegations (`delegation.c`), the NFSv4 callback server (`callback*.c`), the pNFS block/SCSI layout driver (`blocklayout/*`), sunrpc cache/DNS helpers (`cache_lib.c`, `dns_resolve.c`), and NFS re-export (`export.c`).

## Architecture & Data Flow
- In `nfs_server_insert/remove_lists()`, update `server->client_link` (`clp->cl_superblocks`), `server->master_link` (`nn->nfs_volume_list`), and `NFS_CS_STOP_RENEW` on `clp->cl_res_state` under `nn->nfs_client_lock`; `nfs_init_server_rpcclient()` must clone `clp->cl_rpcclient`, copy `timeo` into `server->client->cl_timeout_default`, and repoint `server->client->cl_timeout` to it. [F65, F73]
- Setting `NFS4CLNT_DELEGRETURN`, `NFS4CLNT_DELEGRETURN_DELAYED`, or `NFS4CLNT_DELEGATION_EXPIRED` on `clp->cl_state` requires setting the matching `NFS4SERV_*` bit on `server->delegation_flags`. `server->nr_active_delegations` is decremented only when `NFS_DELEGATION_REVOKED` is newly set in `nfs_mark_delegation_revoked()`, and incremented when attaching in `nfs_inode_set_delegation()` or clearing `NFS_DELEGATION_REVOKED` in `nfs_inode_reclaim_delegation()` and `nfs_update_inplace_delegation()`. [F59, F61]
- In `delegation.c`, stateid sequence comparisons must use `nfs4_stateid_is_newer()` or `nfs4_stateid_match_or_older()`, and in `nfs_mark_return_unused_delegation_types()`, `(delegation->type == (FMODE_READ|FMODE_WRITE)) && !(flags & FMODE_WRITE)` must precede `if (delegation->type & flags)`. [F110, F133]
- In `cb_layoutrecallargs`, `cbl_fh`/`cbl_range`/`cbl_stateid` are valid only for `RETURN_FILE` and `cbl_fsid` for `RETURN_FSID`, and `do_callback_layoutrecall()` returns host-endian `u32` converted to `__be32` in `nfs4_callback_layoutrecall()`. In `decode_lockowner()`, `cbnl_owner.s_dev`/`id` and `cbnl_valid = true` require wire `len == 20`. In `process_op()`, validate wire `op_nr` via `preprocess_nfs4*_op()` before indexing `callback_ops[op_nr]`, and in `validate_seqid()`, keep `slot->seq_nr` and `args->csa_sequenceid` 32-bit `u32`. [F50, F86, F87, F130]
- Every `nfs_access_entry` in `nfsi->access_cache` is paired in `nfsi->access_cache_entry_lru` under `inode->i_lock` and counted in `nfs_access_nr_entries`, while `NFS_INO_ACL_LRU_SET` tracks `nfsi->access_cache_inode_lru` in `nfs_access_lru_list` under `nfs_access_lru_lock`. `nfs_access_get_cached_rcu()` must check `lh == &nfsi->access_cache_entry_lru` before `access_cmp()`, `nfs_access_calc_mask()` requires all bits of `NFS_DIR_MAY_WRITE` or `NFS_FILE_MAY_WRITE`, and `nfs_do_access()` masks with `MAY_READ | MAY_WRITE | MAY_EXEC`. [F66, F115, F116]
- Iterating `NFS_I(dir)->open_files` as `nfs_open_dir_context` requires checking `S_ISDIR(dir->i_mode)`. In `nfs_llseek_dir()`, when `offset != filp->f_pos` under `filp->f_lock`, reset `page_index = 0`, `eof = false`, and set `dir_cookie` and `last_cookie` to `offset` (if `nfs_readdir_use_cookie(filp)`) or `0`. In `find_and_lock_cache_page()`, if filling the first folio (`last_cookie == 0`) changes `nfsi->cookieverf`, update it and call `invalidate_inode_pages2_range(mapping, 1, -1)`. In `nfs_readdir_folio_array_append()`, verify `nfs_readdir_array_can_expand()` and increment `array->size` before indexing `array->array[array->size - 1]`. [F74, F76, F135, F137]
- In `nfs_direct_read/write_schedule_iovec()`, `npages` must be `(result + pgbase + PAGE_SIZE - 1) / PAGE_SIZE`; when `nfs_pageio_add_request()` sets `defer = true`, reset `desc.pg_error = 0` and `pgbase = 0` after the first page. In `nfs_direct_join_group()`, when `req->wb_head != req`, `nfs_direct_add_page_head(&req->wb_list, req)` must insert after `&req->wb_list`, and when `req->wb_head == req`, unlink all other `subreq`s from `list` before `nfs_join_page_group()`. [F117, F119, F128]
- Non-redo O_DIRECT completions must call `nfs_update_delegated_atime(dreq->inode)` on read and `nfs_update_delegated_mtime_locked(dreq->inode)` under `inode->i_lock` on write. In `nfs_direct_write_completion()`, `NFS_IOHDR_UNSTABLE_WRITES` without `NFS_IOHDR_ERROR` must only set `dreq->flags = NFS_ODIRECT_DO_COMMIT` if `!dreq->flags`; `nfs_direct_write_schedule_work()` must sample and zero `dreq->flags` before calling `nfs_direct_commit_schedule()` or `nfs_direct_write_reschedule()`, which must call `nfs_clear_pnfs_ds_commit_verifiers(&dreq->ds_cinfo)`. [F64, F77, F118]
- In `bl_find_get_deviceid()`, if `bl_register_dev()` fails, call `nfs4_mark_deviceid_unavailable(node)`; nodes with `NFS_DEVICEID_UNAVAILABLE` must never be reused and are deleted via `nfs4_delete_deviceid()` after `PNFS_DEVICE_RETRY_TIMEOUT`. Because `be_node` and `be_list` share a union in `pnfs_block_extent`, `bl_alloc_lseg()` must `list_del(&be->be_list)` before `ext_tree_insert()`, and `__ext_tree_remove()` must `rb_erase(&be->be_node, root)` before `list_add_tail(&be->be_list, tmp)`. In `bl_read_pagelist()`, when `is_hole(&be)` is true, call `bl_submit_bio(bio)` and reset `map.start = NFS4_MAX_UINT64`. [F67, F72, F142]
- In `ext_tree_prepare/try_encode/encode_commit()`, encoding starts at `start_p + 1` (`*start_p` holds count) and size checks use `ext_tree_layoutupdate_size(bl, *count)`. `ext_tree_try_encode_commit()` must verify all `EXTENT_WRITTEN` extents fit before setting `EXTENT_COMMITTING` or zeroing `bl->bl_lwb` (`ext_tree_prepare_commit()` resets `count = 0` before `ext_tree_encode_commit()`), while `ext_tree_mark_committed()` sets `be_state = PNFS_BLOCK_READWRITE_DATA` and `be_tag = 0` on success or reverts `be_tag = EXTENT_WRITTEN` on error. [F68, F96, F104]

## Synchronization
- `nfs_mark_client_ready()` executes `smp_wmb()` before storing `clp->cl_cons_state`, paired with `smp_rmb()` in `nfs_found_client()` after `nfs_wait_client_init_complete()` confirms `NFS_CS_READY`. In `nfs_match_client()`, when `clp->cl_cons_state > NFS_CS_READY`, increment `clp->cl_count`, drop `nn->nfs_client_lock`, call `nfs_wait_client_init_complete(clp)`, put `clp`, re-acquire `nn->nfs_client_lock`, and `goto again`. In `nfs_get_client()`, schedule LOCALIO probing asynchronously via `nfs_local_probe_async(new)`. [F15, F122, F158]
- In `nfs_delegation_claim_opens()`, pin `ctx` with `get_nfs_open_context(ctx)` before dropping `rcu_read_lock()`, hold `sp->so_delegreturn_mutex` around `nfs4_open_delegation_recall()` and `nfs_delegation_claim_locks()`, release `ctx`, and restart the `nfsi->open_files` walk. `nfs_client/server_return_marked_delegations()` must not call `nfs_wb_all()` and must pass `issync = 0` to `nfs_end_delegation_return()`. [F24, F157]
- `nfs_force_lookup_revalidate(dir)` requires `dir->i_lock`. `nfs_lookup_revalidate()` and `nfs4_lookup_revalidate()` must call `__nfs_lookup_revalidate(dentry, flags)` first; `block_revalidate()` requires `dentry->d_lock` when setting `dentry->d_fsdata = NFS_FSDATA_BLOCKED`, and `unblock_revalidate()` must use `store_release_wake_up(&dentry->d_fsdata, NULL)`. In `nfs_rename()`, setting `cancelled = 1` on failed `rpc_wait_for_completion_task(task)` requires `smp_wmb()` before `rpc_put_task(task)`. [F25, F26, F28, F79]
- Acquire `nfs_access_lru_lock` before `inode->i_lock` (`nfs_access_get_cached_locked()` drops `inode->i_lock` before `nfs_access_zap_cache()`), and return `SHRINK_STOP` in `nfs_access_cache_scan()` if `(sc->gfp_mask & GFP_KERNEL) != GFP_KERNEL`. In `nfs_access_add_cache()`, initialize all `nfs_access_entry` fields before `smp_wmb()` and `nfs_access_add_rbtree()`, and free via `kfree_rcu()`. When `mask & MAY_NOT_BLOCK` is set in `nfs_permission()`, `nfs_do_access()`, `nfs_access_get_cached_locked()`, and `nfs_execute_ok()`, return `-ECHILD` without blocking. [F29, F146, F151, F162]
- `alloc/put_nfs_open_dir_context()` must use `list_add_tail_rcu()`/`list_del_rcu()` under `dir->i_lock` and `kfree_rcu()`. In `nfs_readdir_folio_array_append()`, call `nfs_readdir_copy_name()` before `kmap_local_folio(folio, 0)` and pair with `kunmap_local()`. In `nfs_vm_page_mkwrite()`, lock `folio` and verify `folio->mapping == inode->i_mapping` before `nfs_folio_length(folio)`, pair `sb_start/end_pagefault()`, and unlock `folio` unless returning `VM_FAULT_LOCKED`. [F163, F165, F167]
- Updates to `dreq->count`, `max_count`, `error`, and `flags` in direct I/O callbacks require `dreq->lock`, and `nfs_direct_write_complete()` must queue `dreq->work` onto `nfsiod_workqueue` rather than running commit/reschedule or `nfs_zap_mapping()` inline. In blocklayout, `bl_end_io_*` and `bl_end_par_io_*` must defer `ext_tree_mark_written()` and `pnfs_ld_read/write_done()` via `schedule_work(&hdr->task.u.tk_work)`; allocations under `bl->bl_ext_lock` must use `GFP_ATOMIC`, and `__ext_put_deviceids()` must be called after dropping `bl->bl_ext_lock`. [F32, F147, F148, F149]

## Object Lifetimes
- Once `nfs_get_client()` links `clp` onto `nn->nfs_client_list`, `init_client` must call `nfs_mark_client_ready(clp, error)` before `nfs_put_client(clp)` on failure. `nfs_free_server()` must call `nfs_server_remove_lists()` before `server->destroy()`, RPC client shutdown, or `call_rcu(..., delayed_free)`. [F1, F19]
- `nfs_detach_delegation_locked()` (and wrappers) returns the unlinked delegation without decrementing `refcount` (caller must call `nfs_put/free_delegation()`). In `nfs_delegation_find_inode_server()` and `nfs_layout_find_inode_by_*()`, call `nfs_sb_active(server->super)` and `igrab()` under `rcu_read_lock()`, drop `rcu_read_unlock()` before `nfs_sb_deactive()` if `igrab()` fails, and release returned inodes via `nfs_iput_and_deactive()`. [F3, F160]
- In `nfs4_callback_compound()`, call `nfs4_cb_free_slot(&cps)` before `nfs_put_client(cps.clp)`. `process_op()` reuses `rqstp->rq_argp` and `rq_resp` across ops without zeroing them, so sub-arrays allocated by `decode_args` (`args->devs`, `args->csa_rclists`) must be freed by the `process_op` handler. [F7, F144]
- Directory folio entry names are allocated by `nfs_readdir_copy_name()` via `kmemdup_nul()` + `kmemleak_not_leak()`, so reinitializing or freeing a readdir folio must call `nfs_readdir_clear_array()` first; in `nfs_readdir_folio_filler()`, call `nfs_readdir_folio_unlock_and_put(folio)` only when `folio != *arrays`. In `nfs_write_begin()`, `write_begin_get_folio()` returns a locked and referenced folio; if `nfs_flush_incompatible()` fails, call `folio_unlock()` and `folio_put()`, whereas `nfs_read_folio()` unlocks the folio so only `folio_put()` is called. [F12, F14, F112, F136]
- `nfs_direct_req_alloc()` sets `dreq->kref` to 2, so paths in `nfs_file_direct_read/write()` exiting before scheduling I/O or scheduling 0 bytes must call `nfs_direct_req_release(dreq)` twice (and pair `inode_dio_begin/end()`). Only set `dreq->iocb = iocb` when `!is_sync_kiocb(iocb)`, and hold `get_dreq(dreq)` across `nfs_direct_read/write_schedule_iovec()` and `nfs_direct_write_reschedule()` through `nfs_pageio_complete(&desc)` before `put_dreq(dreq)`. [F6, F33, F139]
- `ext_tree_prepare/free_commitdata()` use `arg->layoutupdate_pages != &arg->layoutupdate_page` to distinguish `__vmalloc` buffers from `arg->layoutupdate_page` and must free them on `-ENOMEM`. In extent rbtree loops, assign `be = ext_try_to_merge_left(root, be)` because merging `kfree`s `be`. `nfs_dns_ent_init()` must use `kmemdup_nul(key->hostname, key->namelen, GFP_KERNEL)` and `nfs_dns_ent_update()` must copy `key->addrlen` bytes of `key->addr`. [F11, F102, F143]

## API Contracts
- `clp->cl_cons_state` is `> 0` while initializing, `0` (`NFS_CS_READY`) when ready, and `< 0` on error; `nfs_client_init_status(clp)` requires `nfs_client_init_is_complete(clp)`. `nfs_alloc_server()` returns `NULL` on failure, while `nfs_alloc/get/init_client()` and `nfs_create/clone_server()` return `ERR_PTR`. `nfs_clone_server()` and `nfs_server_copy_userdata()` must not copy `server->caps` and must call `nfs_server_set_init_caps()` before `nfs_probe_server()`. [F46, F47, F62]
- Buffers passed to `decode_bitmap()` must have $\ge 3$ `uint32_t` elements. Before each `xdr_decode()`, `nfs_readdir_entry_decode()` must reset `entry->fattr->label->len = NFS4_MAXLABELLEN` when `label` is non-NULL, and `nfs_readdir_xdr_filler()` returns non-negative `pglen` or negative errno. `nfs_atomic_open()` only opens `S_ISREG` via `open_context` and falls back to `nfs_lookup()` + `finish_no_open()` otherwise. Cached access entries require `access_cmp(cred, cache)` and `(s64)(nfs_access_login_time(current, cred) - cache->timestamp) <= 0`. [F58, F84, F176, F177]
- In `nfs_invalidate_folio()`, partial invalidations (`offset != 0 || length < folio_size(folio)`) must call `nfs_wb_folio()` rather than `nfs_wb_folio_cancel()`. When `swap` is `true`, `nfs_file_direct_read/write()` must bypass `nfs_start/end_io_direct()`, `generic_write_checks()`, and `invalidate_inode_pages2_range()`, and use `FLUSH_STABLE`. [F166, F170]
- `ext_tree_insert(bl, new)` takes ownership of `new` and `new->be_device` on `0`, leaving them with the caller on negative error. In `bl_alloc_lseg()`, `-ENODEV` from `bl_find_get_deviceid()` sets `NFS_LSEG_UNAVAILABLE` on `lseg->pls_flags` and returns `lseg` (other errors free `lseg` and return `ERR_PTR`). `pnfs_block_extent` offsets/lengths are in sectors (`SECTOR_SHIFT`) while `pnfs_block_dev_map` and XDR wire offsets are in bytes (`be_v_offset` is valid only when `be_state != PNFS_BLOCK_NONE_DATA`, and `decode_sector_number()` rejects `(s & 0x1ff) != 0`). `block/scsilayout_type` set `PNFS_READ_WHOLE_PAGE`, and `is_aligned_req()` must reject unaligned direct I/O (`pgio->pg_dreq != NULL`) to MDS. [F10, F41, F43, F125, F180, F181]

## Error Handling
- `clp->cl_rpcclient`, `server->client`, and `server->client_acl` are initialized to `ERR_PTR(-EINVAL)` (not `NULL`), so checks must use `!IS_ERR()`. On error after `server->nfs_client = clp`, `nfs_init_server()` must reset `server->nfs_client = NULL` before `nfs_put_client(clp)`. In `nfs_lookup_revalidate_done()`, `-ESTALE` and `-ENOENT` set `error = 0` and fall through so `inode && IS_ROOT(dentry)` overrides `error` to `1`. [F44, F45, F114]
- `nfs4_callback_sequence()` must set `cps->clp = clp` and free `args->csa_rclists` on all exit paths, and store `htonl(NFS4ERR_RETRY_UNCACHED_REP)` in `cps->drc_status` while returning `0`. `decode/encode_op_hdr()` return `htonl(NFS4ERR_RESOURCE_HDR)`, which `nfs4_callback_compound()` translates to `htonl(NFS4ERR_RESOURCE)` while decrementing `nops`. `nfs_unlink()` and `nfs_rename()` must check `!(dentry->d_flags & DCACHE_NFSFS_RENAMED)` before `block_revalidate()` and call `unblock_revalidate()` on all exit paths. In `nfs_direct_wait/complete()`, positive `dreq->count` takes precedence over `dreq->error` (unless truncated to `0` by `nfs_direct_truncate_request()`). [F51, F52, F54, F57]

## External Contracts
- In `nfs4_callback_sequence()`, update `slot->seq_nr = args->csa_sequenceid` only after `nfs4_lookup_slot()`, `validate_seqid()`, `nfs4_try_to_lock_slot()`, `args->csa_cachethis == 0`, and `referring_call_exists()` succeed. `bl_pipe_downcall()` must verify `mlen == sizeof(struct bl_dev_msg)`, and `bl_resolve_deviceid()` must hold `nn->bl_mutex` and verify `b->simple.len <= PAGE_SIZE`. In `ext_tree_try_encode/encode_commit()`, `*lastbyte` is `bl->bl_lwb - 1` (`U64_MAX` if `0`) or `((be_prev->be_f_offset + be_prev->be_length) << SECTOR_SHIFT) - 1`. [F78, F91, F97, F183]

## Known Pitfalls
- `nfs_delegation_find_inode()` and `nfs_layout_find_inode()` never return `NULL` (check with `IS_ERR()`). `RCA4_TYPE_MASK_*` and `PNFS_FF_RCA4_TYPE_MASK_*` are bit indices requiring `BIT()` in `nfs4_callback_recallany()`, whereas `RCA4_TYPE_MASK_ALL` is a bitmask. `nfs_server_set_fsinfo()` must explicitly clear pre-set capability bits (like `NFS_CAP_XATTR`) when false, and `nfs_fh_to_dentry()` must cast `p[FILEID_HIGH_OFF]` to `u64` before `<< 32`. [F48, F49, F63, F123]
