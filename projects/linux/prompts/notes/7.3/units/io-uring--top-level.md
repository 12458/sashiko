# IO_URING — (top level)

Implements the core `io_uring` engine (`io_uring/io_uring.c`), `io-wq` worker pool (`io-wq.c`), shared types (`include/linux/io_uring_types.h`, `include/uapi/linux/io_uring.h`), memory mapping (`memmap.c`), provided buffers (`kbuf.c`), and auxiliary operations (`cancel.c`, `futex.c`, `fs.c`, `msg_ring.c`, `eventfd.c`, `napi.c`, `cmd_net.c`, `mock_file.c`).

## Architecture & Data Flow
- In `struct io_kiocb`, `req->kbuf` and `req->buf_node` share a union gated by `REQ_F_BUFFER_SELECTED` and `REQ_F_BUF_NODE`. Because `io_req_add_to_cache()` does not clear `req->creds` or `req->apoll` (poisoning them under `CONFIG_KASAN`) and `io_init_req()` does not reinitialize them, access them only when `REQ_F_CREDS` or `REQ_F_POLLED` is set. [F47, F50]
- `req->flags` (`io_req_flags_t`, `u64 __bitwise`) reserves bits 0..7 for UAPI `IOSQE_*` flags; internal `REQ_F_*_BIT` values must start at bit 8 (`REQ_F_FAIL_BIT`), stay `<= 63` (`__REQ_F_LAST_BIT <= 64`), and use `IO_REQ_FLAG()` (`BIT_ULL()`). Broken by: testing `req->flags & REQ_F_*_BIT` or using 32-bit `BIT()`. [F60, F121]
- In `struct io_buffer_list`, `buf_list` and `buf_ring` share a union gated by `bl->flags & IOBL_BUF_RING`. In `struct io_uring_buf_ring`, the 16B header (`tail` at offset 14) overlays `bufs[0]`, so `io_register_pbuf_ring()` must size it with `flex_array_size(br, bufs, reg.ring_entries)` (not `struct_size()`) and enforce `reg.ring_entries` is a power of 2 strictly `< 65536` (`MAX_BIDS_PER_BGID`). [F48, F92, F139]
- Before `__io_cqring_overflow_flush()` drops `completion_lock` and `uring_lock` while `ctx->cq_overflow_list` is non-empty, it must set `ctx->cqe_sentinel = ctx->cqe_cached` so CQE emitters enter `io_cqe_cache_refill()`. Empty/non-empty transitions of `ctx->cq_overflow_list` under `ctx->completion_lock` must update `IO_CHECK_CQ_OVERFLOW_BIT` in `ctx->check_cq` and `IORING_SQ_CQ_OVERFLOW` in `ctx->rings->sq_flags` together. [F64, F65]
- On `IORING_SETUP_CQE_MIXED` rings, 32B CQEs must set `IORING_CQE_F_32` (`ctx_cqe32_flags()`) and advance `ctx->cqe_cached` and `ctx->cached_cq_tail` by 2 slots (emitting an `IORING_CQE_F_SKIP` pad via `io_fill_nop_cqe()` on wrap), whereas `IORING_SETUP_CQE32` advances `cached_cq_tail` by 1. For 32B overflow CQEs, `io_alloc_ocqe()` must allocate `sizeof(struct io_overflow_cqe) + sizeof(struct io_uring_cqe)` (not `2 * sizeof(struct io_overflow_cqe)`), and `__io_cqring_overflow_flush()` must copy `2 * sizeof(struct io_uring_cqe)` bytes from `&ocqe->cqe`. [F66, F132]
- Because `ctx->sq_sqes` has element type `struct io_uring_sqe` (64B), indexing `ctx->sq_sqes` (`io_get_sqe()`, `__io_uring_show_fdinfo()`) must shift the index left by 1 when `IORING_SETUP_SQE128` is set, and byte copies must use `uring_sqe_size(ctx)`. [F135]
- Failing a request must use `req_set_fail(req)` (not `req->flags |= REQ_F_FAIL`) to convert `REQ_F_CQE_SKIP` into `REQ_F_SKIP_LINK_CQES`. In `io_submit_fail_init()`, a failed request with `IO_REQ_LINK_FLAGS` must be appended to `ctx->submit_state.link` and return `0`, deferring `io_queue_sqe_fallback()` until `!(req->flags & IO_REQ_LINK_FLAGS)` or `io_submit_state_end()`. [F78, F115]
- `io_fixed_file_set()` tags bits 0..1 (`FFS_NOWAIT | FFS_ISREG`) of `node->file_ptr` by shifting `io_file_get_flags(file)` by `REQ_F_SUPPORT_NOWAIT_BIT`, so `REQ_F_ISREG_BIT` must equal `REQ_F_SUPPORT_NOWAIT_BIT + 1` and `node->file_ptr` must be masked via `io_slot_file()`. `io_install_fixed_file()` must call `io_file_bitmap_set()` only when `io_reset_rsrc_node()` returns `false`, and `io_fixed_fd_remove()` must pair `io_reset_rsrc_node()` with `io_file_bitmap_clear()`. [F75, F141]
- In `io-wq.c`, `wq->hash_tail[hash]` tracks the last work item of a hash bucket in `acct->work_list` so same-hash items stay contiguous: `io_get_next_work()` must clear `wq->hash_tail[hash] = NULL` when cutting `[work, tail]`, and when a hash bit is already set in `wq->hash->map`, fast-forward `node` to `&tail->list` (`wq->hash_tail[hash]`); `io_wq_remove_pending()` must update `wq->hash_tail[hash]` to `prev_work` (if same hash) or `NULL`. [F76, F103]
- `io_init_req()` must check `req->opcode < IORING_OP_LAST` before `io_check_restriction()` calls `test_bit(req->opcode, ctx->restrictions.sqe_op)`. `ctx->personalities` must use `XA_FLAGS_ALLOC1` (1-based) because `sqe->personality == 0` means no override. In `io_cancel_req_match()`, `match_user_data` defaults to `true` when neither `IORING_ASYNC_CANCEL_FD` nor `IORING_ASYNC_CANCEL_OP` is set (unless `IORING_ASYNC_CANCEL_ANY`), whereas if `FD` or `OP` is set, `req->cqe.user_data` is compared only when `IORING_ASYNC_CANCEL_USERDATA` is set. [F97, F107, F142]

## Synchronization
- `io_ring_submit_lock()` acquires `ctx->uring_lock` only when `IO_URING_F_UNLOCKED` is set in `issue_flags`; pair it on all paths with `io_ring_submit_unlock()` using the same `IO_URING_F_UNLOCKED` bit, and pass core `io_uring`'s `issue_flags` (never hard-coded `0` or `IO_URING_F_UNLOCKED`) to `__io_uring_cmd_done()`, `io_uring_cmd_done()`, `io_uring_cmd_done32()`, and `io_uring_cmd_mark_cancelable()`. [F5, F61]
- `io_alloc_req()`, `__io_alloc_req_refill()`, `io_cache_alloc()`, `io_cache_free()`, and `io_uring_alloc_async_data()` require holding `ctx->uring_lock`. `io_uring_poll()` must never take `ctx->uring_lock`, and `io_uring_show_fdinfo()` must only use `mutex_trylock(&ctx->uring_lock)` to avoid lock-order inversion with epoll and procfs. [F152, F169]
- When `io_msg_ring` targets `target_ctx`, it must bounce CQEs or fixed-fd installs via `task_work` to `target_ctx->submitter_task` if `target_ctx->task_complete` is set, and otherwise use `io_lock_external_ctx()` (`mutex_trylock` unless `IO_URING_F_UNLOCKED`) before locking `target_ctx->uring_lock`. [F80]
- `io_acct_run_queue()` returns `true` with `acct->lock` held or `false` unlocked. In `io_worker_handle_work()`, set `worker->cur_work` under `worker->lock` before dropping `acct->lock` after `io_get_next_work()`, and hold `worker->lock` (inside `acct->workers_lock`) in `io_wq_worker_cancel()` while inspecting `worker->cur_work`. In `io_acct_cancel_pending_work()`, after unlinking `work` and dropping `acct->lock` for `io_run_cancel()`, return immediately and restart from the head in `io_wq_cancel_pending_work()`. [F24, F45, F102]
- Walking `io_for_each_link` when `REQ_F_LINK_TIMEOUT` is set (`io_match_task_safe()`, `io_prep_async_link()`) requires `raw_spin_lock_irq(&ctx->timeout_lock)`, and callers of `io_match_task_safe()` must not already hold `ctx->timeout_lock`. Regions and buffer lists looked up by `io_uring_mmap()` under `ctx->mmap_lock` must be fully initialized before publication via `io_create_region_mmap_safe()` or `io_buffer_add_list()` under `ctx->mmap_lock`. [F29, F74]
- Mutations to `ctx->napi_list` and `ctx->napi_ht` require `ctx->napi_lock` and RCU list/hash primitives with `kfree_rcu`; lockless traversals (`io_napi_hash_find()`, `__io_napi_do_busy_loop()`) require `scoped_guard(rcu)`. `io_eventfd_signal()` must dereference `ctx->io_ev_fd` under `guard(rcu)()`, pin `ev_fd->refs` via `refcount_inc_not_zero()`, and hold `ctx->completion_lock` around `ev_fd->last_cq_tail`; `io_eventfd_put()` must free `ev_fd` via `call_rcu`. [F39, F40]
- Because `io_get_sqe()` points into user-mapped shared memory, `io_init_req()` and `.prep` handlers must read `struct io_uring_sqe` fields via `READ_ONCE()`. Kernel reads of user-updated `rings->sq.tail` (`io_sqring_entries()`) and `br->tail` (`io_ring_buffer_select()`, `io_ring_buffers_peek()`) must use `smp_load_acquire()`, and kernel updates of `rings->cq.tail` (`io_commit_cqring()`) and `rings->sq.head` (`io_commit_sqring()`) must use `smp_store_release()`. [F84, F162]

## Object Lifetimes
- Assigning `req->async_data` must set `REQ_F_ASYNC_DATA`, and freeing/recycling it before `io_clean_op()` must clear both `req->async_data` and `REQ_F_ASYNC_DATA` via `io_req_async_data_free()` or `io_req_async_data_clear()`. [F1]
- `io_install_fixed_file()` must reject `io_is_uring_fops(file)` with `-EBADF`. Any request targeting an `io_uring` file (`io_file_get_normal()`) or relying on `current->mm` across async execution (`io_futex_prep()`, `io_futexv_prep()`) must call `io_req_track_inflight(req)`. [F2, F164]
- `io_file_get_normal()` takes an `fget()` ref dropped by `io_put_file()` only when `REQ_F_FIXED_FILE` is clear, whereas `io_file_get_fixed()` increments `req->file_node->refs` (dropped by `io_req_put_rsrc_nodes()`); assigning a fixed file to `req->file` must set `REQ_F_FIXED_FILE`. [F8]
- `__io_alloc_req_refill()` takes `percpu_ref_get_many(&ctx->refs, ret)` and increments `ctx->nr_req_allocated`: any `io_alloc_req()` request aborted before submission must be returned via `io_req_add_to_cache()` (never `kmem_cache_free()`), `io_queue_deferred()` must call `__io_req_caches_free(ctx)` before checking `ctx->nr_req_allocated != ctx->nr_drained`, and `ctx->defer_list` add/remove must adjust `ctx->nr_drained` by `io_linked_nr(req)`. [F10, F69]
- `io_submit_sqes()` pre-deducts `left` task refs via `io_get_task_refs(left)`, and if the loop stops early with `left > 0`, it must return them via `current->io_uring->cached_refs += left`. [F11]
- `io_wq_submit_work()` holds an extra `req` ref (`__io_req_set_refcount(req, 2)` or `req_ref_get(req)`) dropped by `io_wq_free_work()`, which `io_req_complete_post()` requires to call `req_ref_put(req)` without freeing `req`; call `io_req_complete_post()` only when `issue_flags & IO_URING_F_IOWQ`. In `io_wq_cancel_tw_create()`, `io_worker_cancel_cb(worker)` runs for both `create_worker_cb` and `create_worker_cont`, but `kfree(worker)` must only run when `cb->func == create_worker_cont`. [F17, F18]

## API Contracts
- `io_fixed_fd_install()` consumes `file` via `fput(file)` on failure, whereas `__io_fixed_fd_install()` takes ownership of `file` only on success (`ret >= 0`). [F6]
- `io_alloc_cache_init()` and `io_futex_cache_init()` return `false` on success and `true` on failure. `io_cache_alloc()` only zeroes the first `cache->init_clear` bytes on fresh allocations and KASAN unpoisoning, so callers must initialize all fields above `init_clear` and any fields modified before `io_cache_free()`. [F42, F57]
- `io_create_region()` must validate `reg->size != 0`, page alignment of `reg->user_addr` and `reg->size`, `reg->size >> PAGE_SHIFT <= INT_MAX`, and `!check_add_overflow(reg->user_addr, reg->size, &end)`; `io_region_validate_mmap()` must reject `mmap(2)` when `IO_REGION_F_USER_PROVIDED` is set. [F93]
- Paths resolving an arbitrary fd to a ring (`io_uring_enter()` without `IORING_ENTER_REGISTERED_RING`, `io_msg_ring()`, `io_uring_sync_msg_ring()`) must check `io_is_uring_fops(file)` before casting `file->private_data` to `struct io_ring_ctx *`. `io_uring_cmd_sock()` must check `prot && prot->ioctl`, and `io_uring_cmd_getsockopt()` (`level == SOL_SOCKET` only) and `io_uring_cmd_setsockopt()` must pass `!!(issue_flags & IO_URING_F_COMPAT)` (not `in_compat_syscall()`) to `do_sock_getsockopt()` / `do_sock_setsockopt()`. [F143, F171]
- In `io_submit_sqes()`, every exit path after `io_submit_state_start()` must call `io_submit_state_end()` to finish `state->plug`. `io_init_req()` must validate `sqe->personality` via `security_uring_override_creds(req->creds)`, and `io_prep_async_work()` must capture `get_current_cred()` when `REQ_F_CREDS` is unset so `__io_issue_sqe()` overrides creds during `def->issue()`. [F174, F180]
- `io_queue_worker_create()` must queue creation via `task_work_add` on `wq->task`, and `io_wq_cpu_affinity()` / `io_wq_max_workers()` must clamp `wq->cpu_mask` to `cpuset_cpus_allowed(tctx->io_wq->task, ...)` and `acct->max_workers` to `task_rlimit(current, RLIMIT_NPROC)`. `iou_mock_mgr_cmd()` requires `capable(CAP_SYS_ADMIN)`, and `io_create_mock_file()` must call `add_taint(TAINT_TEST, LOCKDEP_STILL_OK)`. [F183, F185]

## Error Handling
- On partial returns (`> 0` and `< nr_pages`) from `pin_user_pages_fast()` (`io_pin_pages()`) or `alloc_pages_bulk_node()` (`io_region_allocate_pages()`), unpin (`unpin_user_pages()`) or release (`release_pages()`) the pages before `kvfree(pages)`. In `io_uring_create()`, errors before `io_uring_get_file(ctx)` must call `io_ring_ctx_wait_and_kill(ctx)`, whereas errors after must jump to `err_fput` (`fput(file)`) so `io_uring_release()` kills `ctx` once. [F13, F14]
- Because `req->cmd.data` is not zeroed when `io_kiocb` is cached, any error in `io_init_req()` before `def->prep(req, sqe)` must return via `io_init_fail_req(req, err)` to zero `req->cmd.data` before `def->fail(req)`. When `io_alloc_ocqe()` fails, `io_cqring_add_overflow()` must increment `ctx->rings->cq_overflow` and set `IO_CHECK_CQ_DROPPED_BIT` in `ctx->check_cq` so `-EBADR` is returned before `io_uring_enter()` clears the bit. [F56, F184]
- `io_provide_buffers_prep()` must validate `p->len * p->nbufs` and `p->addr + size` with `check_mul_overflow()` / `check_add_overflow()` before `access_ok()`, and check `tmp + p->nbufs` against `MAX_BIDS_PER_BGID` in `u64`. In `io_ring_buffers_peek()`, when `arg->max_len` is non-zero, reject `len = READ_ONCE(buf->len) == 0` before dividing and use `needed = (arg->max_len + len - 1) / len`. [F124, F126]

## External Contracts
- `struct io_uring_sqe` must remain 64B using fixed-width UAPI types (`__u8`, `__u16`, `__u32`, `__s32`, `__u64`), with new members aliasing existing unions verified by `BUILD_BUG_SQE_ELEM`. Opcode `.prep` callbacks and setup/registration handlers must reject non-zero unused SQE fields, `resv`/`pad` fields, and unknown flags with `-EINVAL`. Bits 24..31 (`0xff000000`) of `sqe->uring_cmd_flags` are reserved for kernel-internal flags (`IORING_URING_CMD_CANCELABLE`, `IORING_URING_CMD_REISSUE`) and must not be in `IORING_URING_CMD_MASK`. [F83, F85, F95]
- Untrusted UAPI indices—`sqe->opcode` (`io_init_req()`), `ctx->sq_array[head]` (`io_get_sqe()`), registered ring `fd` (`io_uring_enter()`), `uarg` offset (`io_get_ext_arg_reg()`), and resource `index` (`io_rsrc_node_lookup()`)—must be clamped with `array_index_nospec()`. Under `CONFIG_MMU`, `io_uring_get_unmapped_area()` must reject non-zero `addr` with `-EINVAL`, and on `SHM_COLOUR` architectures both `io_uring_get_unmapped_area()` and `io_register_pbuf_ring()` (`!(reg.flags & IOU_PBUF_RING_MMAP)`) must enforce `SHM_COLOUR` alignment. [F175, F179]

## Known Pitfalls
- Zero `req->big_cqe` after copying it in `io_fill_cqe_req()` or `io_alloc_ocqe()` so recycled requests do not leak `extra1`/`extra2` on `IORING_SETUP_CQE32` rings. In `create_worker_cb()`, store `io_acct_activate_free_worker()` in `activated_free_worker` rather than reusing `do_create`, which must stay `false` unless `acct->nr_workers < acct->max_workers` under `acct->workers_lock`. [F67, F98]
- Save `node = req->comp_list.next` in `io_free_batch_list()` before `io_queue_iowq()`, `req_ref_put_and_test()`, or `io_req_add_to_cache()`, and read `next_hashed = wq_next_work(work)` in `io_worker_handle_work()` before `io_wq_submit_work()` and `io_wq_free_work()`. In `io_ring_exit_work()`, call `list_rotate_left(&ctx->tctx_list)` before `task_work_add()` so a failed `task_work_add()` advances to the next task. [F101, F104, F105]
- In `io_try_cancel()`, when `io_async_cancel_one()` returns `-EALREADY`, fall through to `io_poll_cancel()` (`if (!ret) return 0;`). In `io_sync_cancel()`, refresh `cd.seq = atomic_inc_return(&ctx->cancel_seq)` and re-lookup fixed files in `__io_sync_cancel()` on every retry after dropping `ctx->uring_lock`. [F106, F108]
- In `io_ring_buffers_peek()`, compute available entries in `__u16` arithmetic via `min_t(__u16, tail - head, UIO_MAXIOV)`. In `io_region_init_ptr()`, check `!PageHighMem(mr->pages[0])` alongside `ifd.nr_folios == 1` before calling `page_address()`, falling back to `vmap()` (`IO_REGION_F_VMAP`). [F130, F147]
