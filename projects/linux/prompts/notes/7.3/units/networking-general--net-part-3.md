# NETWORKING [GENERAL] — net (part 3)

Implements KCM sockets (`net/kcm/`), L2TPv2/v3 core, IP/IPv6 sockets, Ethernet pseudowires, and Netlink (`net/l2tp/`), L3 Master Device / VRF hooks (`net/l3mdev/`), and MPLS routing, GSO, and IP tunnels (`net/mpls/`).

## Architecture & Data Flow
- In `net/kcm/kcmsock.c`, an unreserved `kcm_psock` is on `mux->psocks_avail` iff `!psock->tx_stopped` (`kcm_abort_tx_psock()` unlinks when `!psock->tx_kcm`; `unreserve_psock()` skips `psock_now_avail()` when `tx_stopped`; `kcm_unattach()` unlinks only when `!tx_stopped`). Under `mux->rx_lock`, `psock->ready_rx_msg` and `mux->psocks_ready` update in lockstep: `reserve_rx_kcm()` sets `ready_rx_msg`, pauses `psock->strp`, and links `psock_ready_list`; `kcm_rcv_ready()` and `kcm_unattach()` unlink it, unpause `strp`, and clear `ready_rx_msg = NULL`. [F637, F639]
- In `kcm_sendmsg()`, an incomplete message (`!eor`) is saved via `kcm->seq_skb = head` and `kcm_tx_msg(head)->last_skb = skb`, clearing `kcm->seq_skb = NULL` once queued on `sk->sk_write_queue`; on `SOCK_SEQPACKET` error with `copied == 0`, free `head` only if `head != kcm->seq_skb`. In `kcm_write_msgs()`, if a reserved `kcm_psock` aborts (`psock->tx_stopped` on entry or non-`-EAGAIN` from `sock_sendmsg()`), reset `kcm_tx_msg(head)->started_tx = false` so retry restarts from `frag_offset = 0` and `sent = 0`. [F640, F641]
- `kcm_recvmsg()` and `kcm_splice_read()` must bound SKB reads to `stm->full_len` at `stm->offset` (`strp_msg(skb)`), and partial `SOCK_SEQPACKET` reads must update `stm->offset += copied` and `stm->full_len -= copied`. `init_kcm_sock()` and `kcm_attach()` keep `mux->kcm_socks` and `mux->psocks` sorted by ascending 0-based `index`. `struct kcm_proc_mux_state` must keep `struct seq_net_private p` first for `/proc/net/kcm` (`kcm_seq_ops`), whereas `/proc/net/kcm_stats` (`kcm_stats_seq_show()`) sets `seq->private` directly to `struct net *`. [F670, F672, F704]
- Whenever an L2TP session's `send_seq`, `cookie_len`, or `l2specific_type` is initialized or changed, call `l2tp_session_set_header_len()` so `session->hdr_len` matches `l2tp_build_l2tpv2_header()` / `l2tp_build_l2tpv3_header()`. L2TP `nr`/`ns` use version-dependent `session->nr_max` (`0xffff` v2, `0xffffff` v3) and `nr_window_size = nr_max / 2`, checking modular distance in `l2tp_seq_check_rx_window()` against `nr_max + 1`. In `l2tp_recv_common()`, when `!has_seq` and `!session->recv_seq`, the LAC check (`!session->lns_mode && session->send_seq`) that disables `send_seq` must precede `else if (session->send_seq)`. [F664, F665, F676]
- `L2TP_SKB_CB(skb)` places `struct l2tp_skb_cb` at `&skb->cb[sizeof(struct inet_skb_parm)]` so `IPCB(skb)` is preserved and both must fit in `sizeof(skb->cb)`. `l2tp_tunnel::name` (`L2TP_TUNNEL_NAME_MAX` = 20) and `l2tp_session::name` (`L2TP_SESSION_NAME_MAX` = 32) must stay NUL-terminated for fixed `memcpy` in `net/l2tp/trace.h`. [F705, F706]
- `struct l2tp_ip_sock` and `struct l2tp_ip6_sock` must keep `struct inet_sock inet` first, and `l2tp_ip6_prot.ipv6_pinfo_offset` must be `offsetof(struct l2tp_ip6_sock, inet6)`. Under `l2tp_ip_lock` / `l2tp_ip6_lock`, `l2tp_ip_bind()` and `l2tp_ip6_bind()` must link `sk_bind_node`, unlink `sk_node` via `sk_del_node_init(sk)`, and clear `SOCK_ZAPPED`; `l2tp_ip_close()` / `l2tp_ip6_close()` must unlink both. [F647, F701]
- In `l2tp_tunnel_get_next()`, `l2tp_v2_session_get_next()`, and `l2tp_v3_session_get_next()`, every `goto again` and continuing caller must increment `(*key)++` before `idr_get_next_ul()`. In `pn->l2tp_v2_session_idr` and `tunnel->session_list`, `session->session_id == 0` is reserved for `pppol2tp` dummy sessions and must be skipped in `l2tp_v2_session_get_next()` and `l2tp_dfs_seq_tunnel_show()`. [F667, F673]
- In `net/l3mdev/l3mdev.c`, `dev->l3mdev_ops` callbacks may only be dereferenced after verifying `netif_is_l3_master(dev)` (or resolving the master via `netdev_master_upper_dev_get_rcu()` if `netif_is_l3_slave(dev)`) and checking the callback is non-NULL. In `l3mdev_update_flow()`, if `fl->flowi_oif` resolves to an L3 master (`netif_is_l3_master(dev)`), reset `fl->flowi_oif = 0` after setting `fl->flowi_l3mdev`. [F630, F731]
- Every `struct mpls_nh` in `rt->rt_nh` has stride `rt->rt_nh_size` (`MPLS_NH_SIZE`) with via at `rt->rt_via_offset` (`MPLS_NH_VIA_OFF`), so access them only via `for_nexthops`/`change_nexthops`/`mpls_get_nexthop()` and `mpls_nh_via()`. In `mpls_multipath_hash()`, label walk is bounded by `MAX_MP_SELECT_LABELS` (4) and must `break` right after hashing an unreserved label following `MPLS_LABEL_ENTROPY` (`eli_seen`) or at `dec.bos`. [F656, F685]
- Validate user MPLS labels with `mpls_label_ok()` (`MPLS_LABEL_FIRST_UNRESERVED <= *index < net->mpls.platform_labels`, clamped with `array_index_nospec()`). In `resize_platform_label_table()`, scale element counts `limit` and `old_limit` by `sizeof(struct mpls_route *)` for allocation and `memcpy`. `mpls_dev_table` and `mpls_table` store struct-relative offsets (`MPLS_PERDEV_SYSCTL_OFFSET`, `MPLS_NS_SYSCTL_OFFSET`) in `.data` and must be `kmemdup()`ed and relocated per instance in `mpls_dev_sysctl_register()` and `mpls_net_init()`. Account for new netlink attributes in `mpls_dump_route()` / `mpls_netconf_fill_devconf()` within `lfib_nlmsg_size()` / `mpls_netconf_msgsize_devconf()`. [F651, F657, F698, F738]

## Synchronization
- In `kcm_unattach_ioctl()`, check and set `psock->unattaching = 1` under `spin_lock_bh(&mux->lock)` before calling `kcm_unattach(psock)`. When `kcm_unattach()` sees `psock->tx_kcm` under `mux->lock`, drop `mux->lock` for `kcm_abort_tx_psock()`, re-lock, recheck `psock->tx_kcm`, and if still set, set `psock->done = 1` with `smp_mb()` and queue `psock->tx_kcm->tx_work` so `unreserve_psock()` frees `psock` under the KCM socket lock. [F603, F606]
- Updates to `kcm->rx_wait` and `kcm->rx_psock` under `mux->rx_lock` require `WRITE_ONCE()`, and clearing `kcm->rx_psock` in `unreserve_rx_kcm()` requires `smp_mb()` before `sk_rmem_alloc_get(&kcm->sk)` to pair with `smp_mb__after_atomic()` and `READ_ONCE()` in `kcm_rfree()`. `kcm_sendmsg()` must acquire `kcm->tx_mutex` outside `lock_sock(sk)`. In `kcm_release()`, clear `kcm->tx_wait = false` and unlink from `mux->kcm_tx_waiters` under `spin_lock_bh(&mux->lock)` before `disable_work_sync(&kcm->tx_work)` and before unreserving `kcm->tx_psock` under `lock_sock(sk)`. [F605, F721, F722]
- In `l2tp_session_register()` and `l2tp_session_unhash()`, acquire `spin_lock_bh(&tunnel->list_lock)` before `spin_lock_bh(&pn->l2tp_session_idr_lock)` (which nests outside `clist->lock`), using `GFP_ATOMIC`. Because IDR slots are reserved with `NULL` and colliding sessions are hashed before `WRITE_ONCE(session->tunnel, tunnel)`, RCU-BH lookups (`l2tp_v3_session_get()`, `l2tp_tunnel_get()`) must null-check IDR entries and `READ_ONCE(session->tunnel)` and use `refcount_inc_not_zero()`. [F723, F724]
- In `l2tp_xmit_core()`, take `spin_lock_nested(&sk->sk_lock.slock, L2TP_DEPTH_NESTING)` across `l2tp_xmit_queue()`, and drop if `sock_owned_by_user(sk)` or `tunnel->fd >= 0 && sk->sk_state != TCP_ESTABLISHED`. In `l2tp_recv_dequeue()`, after dropping `session->reorder_q.lock` for `l2tp_recv_dequeue_skb()`, `goto start` to restart `skb_queue_walk_safe`. In `l2tp_nl_cmd_session_create()`, `genl_unlock()` before `request_module()`, then `genl_lock()` and re-check `l2tp_nl_cmd_ops[cfg.pw_type]`. [F675, F725, F729]
- `l3mdev_ifindex_lookup_by_table_id()` calls `hdlr->dev_lookup` under `spin_lock(&l3mdev_lock)`, so registered callbacks must not sleep or re-lock `l3mdev_lock`. In `net/mpls/af_mpls.c`, update live `rt->rt_nhn_alive` and `nh->nh_flags` under `rtnl_lock()` with `WRITE_ONCE()` and read under RCU with `READ_ONCE()` in `mpls_select_multipath()`. On `NETDEV_UNREGISTER` in `mpls_ifdown()`, if a multipath route has other nexthops, `kmemdup()` the route, clear `nh->nh_dev = NULL` on the clone, and replace via `mpls_route_update()`. Use `MPLS_INC_STATS` / `MPLS_INC_STATS_LEN` for `struct mpls_pcpu_stats` updates. [F615, F616, F694, F717]

## Object Lifetimes
- In `kcm_done()`, if `kcm->rx_psock` is non-NULL under `mux->rx_lock`, defer teardown by setting `kcm->rx_disabled = 1` and `kcm->done = 1` so `unreserve_rx_kcm()` schedules `kcm->done_work` (`kcm_done_work()`) to requeue `sk->sk_receive_queue`, call `release_mux()`, and `sock_put(&kcm->sk)`. [F585]
- `l2tp_tunnel_register()` reserves `tunnel->tunnel_id` with `NULL` in `pn->l2tp_tunnel_idr`, takes `sock_hold(sk)` while calling `sockfd_put(sock)` when `tunnel->fd >= 0`, and on error releases the socket and IDR entry without freeing `tunnel`. `l2tp_tunnel_delete()` bumps `tunnel->ref_count` when setting bit 0 of `tunnel->dead` and queuing `tunnel->del_work`; `l2tp_tunnel_del_work()` releases `sk->sk_socket` only when `tunnel->fd < 0` and calls `l2tp_tunnel_put()` twice. In `l2tp_pre_exit_net()`, call `__flush_workqueue(l2tp_wq)` twice after `l2tp_tunnel_delete()` so both tunnel and session delete works finish before `l2tp_exit_net()`. [F588, F589, F590]
- `l2tp_session_register()` increments `tunnel->ref_count` and sets `session->tunnel` only after `tunnel->acpt_newsess` and IDR allocation succeed, pairing with `l2tp_tunnel_put()` in `l2tp_session_free()`. `l2tp_dfs_seq_stop()` must put non-NULL `pd->session` and `pd->tunnel` and reset both to `NULL`. [F591, F595]
- `l2tp_eth_create()` must hold an extra `session->ref_count` and `rtnl_lock` across `l2tp_session_register()`, `register_netdevice()`, and `rcu_assign_pointer(spriv->dev, dev)`; on `register_netdevice()` failure, call `l2tp_session_delete()`, `l2tp_session_put()`, and `free_netdev(dev)`. Because `l2tp_eth_dev_setup()` sets `dev->needs_free_netdev = true`, never call `free_netdev(dev)` after `register_netdevice()` succeeds, and `l2tp_eth_dev_uninit()` must clear `RCU_INIT_POINTER(spriv->dev, NULL)`. [F593, F708, F710]
- `find_outdev()` drops the lookup's `dev_hold` via `dev_put(dev)` before returning `dev` because the caller holds `rtnl_lock` and `nh->nh_dev` is unreferenced. `mpls_dev_sysctl_register()` must set `mdev->sysctl = NULL` on failure; `mpls_dev_sysctl_unregister()` frees `mdev->sysctl->ctl_table_arg` after unregistering when non-NULL; on `NETDEV_UNREGISTER` in `mpls_dev_notify()`, run `mpls_ifdown()`, `mpls_dev_sysctl_unregister()`, and `RCU_INIT_POINTER(dev->mpls_ptr, NULL)` before `call_rcu(&mdev->rcu, mpls_dev_destroy_rcu)`. [F596, F597, F711]

## API Contracts
- `init_kcm_sock()` must set `kcm->sk.sk_state = TCP_ESTABLISHED`, and `.splice_read = kcm_splice_read` belongs only on `kcm_seqpacket_ops`. `kcm_splice_read()` must translate `SPLICE_F_*` `flags` to `MSG_DONTWAIT` (if `O_NONBLOCK` or `SPLICE_F_NONBLOCK`, which aliases `MSG_PEEK`) or `0` before `skb_recv_datagram()`. [F618, F750]
- `l2tp_tunnel_create()` returns `0`/errno and sets `*tunnelp`, whereas `l2tp_session_create()` returns `ERR_PTR(-ENOMEM)` on failure (never `NULL`). `l2tp_validate_socket()` checks `SOCK_DGRAM`, family, protocol, and (for UDP) `!sk->sk_user_data`; `l2tp_sk_to_tunnel()` looks up tunnels in `pn->l2tp_tunnel_idr` rather than `sk->sk_user_data`. Callers of `l2tp_session_get_next()` must reset `*key = 0` for each tunnel so `l2tp_v2_session_get_next()` seeds the upper-16-bit `tid`. [F622, F626, F702]
- Before `l2tp_recv_common()` on L2TPv3, callers must call `l2tp_v3_ensure_opt_in_linear(session, skb, &ptr, &optr)` to pull options and rebase `*ptr`/`*optr`. In `l2tp_eth_dev_recv()`, before `dev_forward_skb()`, check `pskb_may_pull(skb, ETH_HLEN)` and call `secpath_reset()`, `skb->ip_summed = CHECKSUM_NONE`, `skb_clear_hash()`, `skb_dst_drop()`, and `nf_reset_ct()`. [F663, F744]
- Validate `l3type` in `l3mdev_handlers` accessors via `l3mdev_check_type()` (rejecting `<= L3MDEV_TYPE_UNSPEC || > L3MDEV_TYPE_MAX`). `l3mdev_ifindex_lookup_by_table_id()` returns `-EINVAL` on error, whereas `l3mdev_master_ifindex_rcu()`, `l3mdev_master_upper_ifindex_by_index_rcu()`, `l3mdev_fib_table_rcu()`, and `l3mdev_fib_table_by_index()` return `0`. Callers of `l3mdev_link_scope_lookup()` must hold `rcu_read_lock()` across the call and use of the unreferenced `dst_entry *`. [F629, F669, F716]
- `nla_get_labels()` requires length multiple of 4 with `len / 4 <= max_labels` (`<= 255`), and when `label != NULL` decodes in reverse requiring `dec.bos` only on the last entry, `dec.ttl == 0`, `dec.tc == 0`, and `dec.label != MPLS_LABEL_IMPLNULL`. `mpls_build_state()` must call `nla_get_labels()` with `label = NULL` first to size `struct_size(tun_encap_info, label, n_labels)`. `mpls_forward()` must call `skb_share_check()`, `pskb_may_pull()`, `skb_warn_if_lro()`, `skb_forward_csum()`, and `skb_cow(skb, hh_len + new_header_size)` before mutating/xmitting. [F658, F697, F735]

## Error Handling
- In `kcm_sendmsg()`, if `kcm_write_msgs()` fails after `head` is queued on `sk->sk_write_queue` at EOR, record `report_csk_error(&kcm->sk, -err)` and return `copied`. In `l2tp_tunnel_sock_create()`, if `kernel_bind()` or `kernel_connect()` fails, call `kernel_sock_shutdown(sock, SHUT_RDWR)`, `sock_release(sock)`, and set `*sockp = NULL`. [F619, F623]

## External Contracts
- In L2TPv3 IP/IPv6 (`l2tp_ip_recv()`, `l2tp_ip6_recv()`, `l2tp_ip_sendmsg()`, `l2tp_ip6_push_pending_frames()`), the first 4 wire bytes are `session_id` (`0` = control frame with 4-byte zero prefix stripped on rx / prepended on tx). `l2tp_ip_getname()`, `l2tp_ip_recvmsg()`, `l2tp_ip6_getname()`, and `l2tp_ip6_recvmsg()` must zero unused fields/padding (`sin_zero`, `l2tp_unused`, `l2tp_flowinfo`, `l2tp_scope_id`, `l2tp_conn_id`). In `l2tp_nl_tunnel_send_addr4()` / `addr6()`, `L2TP_ENCAPTYPE_UDP` must fall through to `L2TP_ENCAPTYPE_IP`. All `l2tp_nl_ops` commands except `L2TP_CMD_NOOP` require `GENL_UNS_ADMIN_PERM`, and `l2tp_tunnel_notify()` / `l2tp_session_notify()` must map `-ESRCH` to `0`. [F666, F679, F746, F747]

## Known Pitfalls
- `requeue_rx_msgs()` must reset `skb->destructor = sock_rfree` before `skb_orphan(skb)` so `kcm_rfree()` does not re-lock `mux->rx_lock`. `release_mux()` requires `list_for_each_entry_safe` over `mux->psocks` when calling `kcm_unattach(psock)`. [F638, F682]
- In `l2tp_session_register()`, call `idr_replace()` on `pn->l2tp_v3_session_idr` only when `!other_session`. Cast `u16 tunnel_id` to `u32` before `<< 16` in `l2tp_v2_session_key()`. Use `time_after(jiffies, cb->expires)` in `l2tp_recv_dequeue()`. Check `len <= INT_MAX - transhdrlen` before `int ulen = len + transhdrlen` in `l2tp_ip6_sendmsg()`. [F677, F686, F688, F689]
- In `mpls_egress()`, decrement IPv4 `hdr4->ttl` and IPv6 `hdr6->hop_limit` only if non-zero, and call `csum_replace2()` with the old `hdr4->ttl` before assigning `hdr4->ttl = new_ttl`. In `mpls_gso_segment()`, save `skb->mac_header`, `skb->mac_len`, and `skb->protocol` before stripping `mpls_hlen` so `skb_gso_error_unwind()` and per-segment restoration use the outer values. [F654, F655]
