# SOUND — sound/usb (part 2)

Implements the ALSA USB audio mixer, PCM substream operations, UAC3 power domains, procfs diagnostics, and vendor mixer quirks.

## Architecture & Data Flow

- For multi-channel `usb_mixer_elem_info` controls (`cval->cmask != 0`), `BIT(c)` in `cmask` and `ch_readonly` maps to 1-based USB channel `c + 1` and `BIT(c + 1)` in `cval->cached`, while `cval->cache_val[idx]` is indexed by the dense 0-based count of set bits in `cmask`. In `restore_mixer_value()`, increment `idx` for every set bit in `cval->cmask` even when `!(cval->cached & BIT(c + 1))`. [F350, F366]
- `urb_ctx_queue_advance()` must receive only PCM DMA bytes consumed (excluding DSD DoP markers in `fill_playback_urb_dsd_dop()` or headers in `copy_to_urb_quirk()`) so `ctx->queued`, `subs->inflight_bytes`, and `subs->hwptr_done` advance in lockstep. When copying between linear `urb->transfer_buffer` and circular `runtime->dma_area` in `retire_capture_urb()` or `copy_to_urb()`, split transfers where `hwptr_done + bytes > subs->buffer_bytes` into two `memcpy` calls. [F345, F354]
- Validate raw UAC descriptors with `snd_usb_validate_audio_desc(p, protocol)` before accessing protocol-specific or variable-length fields. To prevent infinite recursion on cyclic descriptors, `check_input_term()` must clear `state->termbitmap` and `__check_input_term()` must `test_and_set_bit(id, state->termbitmap)`; `parse_audio_unit()` must check `test_and_set_bit(unitid, state->unitbitmap)` and `snd_usb_mixer_controls()` must mark `desc->bTerminalID` in `state.unitbitmap` before recursing. [F347, F362, F364]
- In `snd_usb_create_mixer()`, call `list_add(&mixer->list, &chip->mixer_list)` after `snd_usb_mixer_apply_create_quirk(mixer)` and `snd_device_new()`, because quirks like `snd_sc1810_init_mixer()` check `list_empty(&chip->mixer_list)` to run only on the first mixer interface. [F297]
- In `snd_usb_mixer_notify_id()` and `snd_usb_mixer_interrupt_v2()`, clear `info->cached` (or `BIT(channel)` for per-channel `UAC2_CS_CUR`) before `snd_ctl_notify()`. When `mixer_ctl_feature_info()` lazily initializes via `get_min_max_with_quirks()` and finds `cval->dBmin >= cval->dBmax`, clear `SNDRV_CTL_ELEM_ACCESS_TLV_READ | SNDRV_CTL_ELEM_ACCESS_TLV_CALLBACK` from `kcontrol->vd[0].access` and send `SNDRV_CTL_EVENT_MASK_INFO`. [F331, F334]
- `get_min_max_with_quirks()` and feature unit quirks must keep `cval->res` non-zero (default `1`), while `get_relative_value()`, `get_abs_value()`, and `get_max_exposed()` must guard against `cval->res == 0` (from `snd_create_std_mono_ctl_offset()`). In `get_ctl_value_v1()`/`_v2()`, pass `snd_usb_combine_bytes()` results through `convert_signed_value()`, and in `UAC2_CS_RANGE` replies skip the `sizeof(__u16)` subrange count header before reading `MIN`/`MAX`/`RES` at `val_size` strides. [F356, F371]
- In PCM hw_params rules (`hw_rule_rate`, `hw_rule_format`, `hw_rule_period_size_implicit_fb`, `hw_rule_periods_implicit_fb`), `get_endpoint_in_use()` must pass `subs->data_endpoint` or `subs->sync_endpoint` as `ref_ep` so an assigned endpoint only constrains parameters when `ep->opened > 1`. `snd_usb_pcm_delay()` must mask `(current_frame_number - subs->last_frame_number) & 0xff` to 8 bits. [F343, F375]
- In `snd_usb_pcm_prepare()`, gate early `start_endpoints(subs)` when `!subs->lowlatency_playback` on `substream->stream == SNDRV_PCM_STREAM_PLAYBACK`. In `snd_usb_substream_playback_trigger()`, `SNDRV_PCM_TRIGGER_START` must re-check `in_free_wheeling_mode(substream->runtime)` and clear `subs->lowlatency_playback = false` if true before `start_endpoints(subs)`. [F344, F359]
- In `mixer_us16x08.c`, `comp_msg` and `eqs_msq` overwrite all channel/band parameters at once, so `snd_us16x08_comp_put()`, `snd_us16x08_eq_put()`, and `snd_us16x08_eqswitch_put()` must populate all sibling parameters (and all `SND_US16X08_ID_EQ_BAND_COUNT` bands) from `comp_store`/`eq_store`. Index `eq_store->val` with `EQ_STORE_BAND_IDX(elem->head.id) - 1` and `comp_store->val` with `COMP_STORE_IDX(elem->head.id)`. [F340, F353]
- Static lookup tables (`usbmix_name_map`, `usbmix_selector_map`, `usbmix_connector_map`, `usbmix_ctl_map`, `procunit_info`, `procunit_value_info`, `std_mono_table`) must end with a zero sentinel. New `USB_MIXER_*` enum values in `mixer.h` need a matching entry in `val_types[]` (`snd_usb_mixer_dump_cval()`), and `restore_mixer_value()` must skip `USB_MIXER_BESPOKEN`. [F337, F355]
- In `mixer_quirks.c`, every `SND_DJM_*_IDX` macro needs a `[SND_DJM_*_IDX] = SND_DJM_DEVICE(...)` entry in `snd_djm_devices[]` and handling in `snd_djm_get_label_cap()`/`_caplevel()`. DJM models with distinct capture level options (DJM-A9, DJM-V10) must use dedicated arrays (`snd_djm_opts_a9_cap_level`, `snd_djm_opts_v10_cap_level`) rather than appending to `snd_djm_opts_cap_level`. [F338, F390]

## Synchronization

- Hold `subs->lock` when updating `subs->hwptr_done`, `subs->transfer_done`, `subs->inflight_bytes`, `subs->last_frame_number`, and `subs->period_elapsed_pending` in `retire_capture_urb()`/`retire_playback_urb()`, and continuously across reading `subs->hwptr_done` and `snd_usb_pcm_delay()` in `snd_usb_pcm_pointer()`, releasing `subs->lock` before `snd_pcm_period_elapsed()`. [F301, F302]
- In `prepare_playback_urb()`, release `subs->lock` before period notification and use `snd_pcm_period_elapsed_under_stream_lock()` when `in_stream_lock` is true; if a period elapses while `!subs->running && subs->lowlatency_playback`, set `subs->period_elapsed_pending = 1` so `retire_playback_urb()` notifies once `subs->running` is set. `snd_usb_pcm_playback_ack()` must pass `in_stream_lock = true` to `snd_usb_queue_pending_output_urbs()` and return its result directly so `-EPIPE` is handled by the PCM core. [F299, F300, F346]
- `chip->mutex` protects `subs->opened` (`snd_usb_pcm_open()`, `snd_usb_pcm_close()`) and `subs->cur_audiofmt` (`snd_usb_hw_params()`, `snd_usb_hw_free()`, `proc_dump_substream_status()`). Runtime PCM/mixer callbacks doing USB transfers or endpoint reconfigurations must guard access with `snd_usb_lock_shutdown(chip)` (`CLASS(snd_usb_lock, pm)(chip)`), and release `chip->mutex` before `snd_usb_lock_shutdown()`, `snd_usb_autoresume()`, or `snd_usb_autosuspend()`. [F305, F408]
- `start_endpoints()` and `stop_endpoints()` must track state with `test_and_set_bit()`/`test_and_clear_bit()` on `subs->flags`, and callers closing or restarting stopped endpoints (`snd_usb_hw_params()`, `snd_usb_hw_free()`, `snd_usb_pcm_prepare()`) must call `sync_pending_stops(subs)` first. On `SNDRV_PCM_TRIGGER_START` in `snd_usb_substream_playback_trigger()`, when `subs->lowlatency_playback` is set, call `snd_usb_endpoint_set_callback()` before `start_endpoints(subs)` and clear callbacks to `NULL` if `start_endpoints()` fails. [F303, F304]
- `snd_usb_mixer_suspend()` must call `snd_usb_mixer_inactivate()` (`usb_kill_urb()` on `mixer->urb` and `mixer->rc_urb`) before `mixer->private_suspend(mixer)`. URB submissions from interrupt context (`snd_usb_mixer_interrupt()`, `snd_usb_mixer_rc_memory_change()`) must use `GFP_ATOMIC` (and `snd_usb_mixer_interrupt()` must not resubmit on `-ENOENT`, `-ECONNRESET`, or `-ESHUTDOWN`), while PM resume in `snd_usb_mixer_activate()` must use `GFP_NOIO`. [F401, F402, F406]
- Initialize fields before publishing: in `snd_usb_mixer_add_list()`, set `list->kctl`, `list->is_std_info`, and `list->next_id_elem` before `mixer->id_elems[list->id] = list`; in `snd_us16x08_controls_create()`, set `meter_store->comp_store = comp_store` before registering `snd_us16x08_meter_ctl`; in `snd_usb_soundblaster_remote_init()`, call `init_waitqueue_head(&mixer->rc_waitq)` before `snd_hwdep_new()`, and consume `mixer->rc_code` via `xchg(&mixer->rc_code, 0)` in `snd_usb_sbrc_hwdep_read()`. [F308, F309, F312]
- In `snd_sc1810_init_mixer()`, initialize `private->data_mutex`, `private->usb_mutex`, `private->seqnum`, and `mixer->private_data` before `snd_s1810c_switch_init()`. Switch callbacks must lock `data_mutex` before `usb_mutex`, holding `usb_mutex` across `snd_sc1810c_get_status_field()`. [F311]

## Object Lifetimes

- In `snd_usb_mixer_disconnect()` and `snd_usb_mixer_free()`, call `usb_kill_urb()` on `mixer->urb` and `mixer->rc_urb` before `mixer->private_free(mixer)` or freeing `mixer->id_elems`, URB buffers, `mixer->rc_setup_packet`, or `mixer`. If `snd_usb_soundblaster_remote_init()` or `snd_usb_mixer_status_create()` frees `mixer->rc_urb` or `mixer->urb` on error, reset the pointer to `NULL` before returning. [F306, F320]
- `snd_usb_pcm_open()` must call `snd_usb_autosuspend(subs->stream->chip)` if `snd_media_stream_init()` fails, and reset `subs->opened = 0` under `chip->mutex` on any error after setting `subs->opened = 1`. [F288]
- In `usb_mixer_selector_elem_free()`, read `cval->max` (count of `namelist` strings in `kctl->private_value`) from `kctl->private_data` before freeing `kctl->private_data` and `kctl->private_value`. In `snd_dualsense_jack_create()`, call `snd_usb_mixer_add_control()` before `input_register_handler(&mei->ih)` (clearing `mei->ih.event = NULL` on error), and call `input_unregister_handler(&mei->ih)` before `snd_usb_mixer_elem_free(kctl)` in `snd_dualsense_mixer_elem_free()`. [F292, F310]
- When multiple kcontrols share `elem->private_data` (`comp_store` or `eq_store` in `snd_us16x08_controls_create()`), only one kcontrol may set `kctl->private_free = elem_private_free` (`do_private_free = true`); all others must use `snd_usb_mixer_elem_free`. [F386]

## API Contracts

- `snd_usb_mixer_add_list()` and `snd_usb_mixer_add_control()` transfer ownership of `kctl` and `kctl->private_data` to ALSA via `snd_ctl_add()` even on failure: set `kctl->private_free` beforehand and never free them on error. Pass `is_std_info = false` for bare `usb_mixer_elem_list` controls (`add_single_ctl_with_resume()`), never attach `usb_mixer_elem_info` callbacks (like `snd_usb_mixer_vol_tlv()`) to them, and check `list->is_std_info` before `mixer_elem_list_to_info(list)`. [F289, F351, F378]
- Buffers passed as `data` to `snd_usb_ctl_msg()` (or `snd_us16x08_send_urb()`) with `size > 0` must be writable (not `const` `.rodata`) even for `USB_DIR_OUT` because `snd_usb_ctl_msg()` unconditionally `memcpy`s back into `data`. Buffers/setup packets for `usb_fill_int_urb()`/`usb_fill_control_urb()` must be heap-allocated, while callers with stack buffers must use `snd_usb_ctl_msg()` rather than `usb_control_msg()`. [F376, F411]
- Both `snd_usb_hw_params()` and `snd_usb_pcm_prepare()` must set `UAC3_PD_STATE_D0` via `snd_usb_pcm_change_state()` before configuring/preparing endpoints (`snd_usb_pcm_close()`/`_resume()` use D1; `_suspend()` uses D2). When `subs->sync_endpoint` is present, configure, prepare, stop, and sync `subs->sync_endpoint` before `subs->data_endpoint`. In `snd_usb_hw_params()`, pass `is_sync_ep` as `fmt == sync_fmt` to `snd_usb_endpoint_open()` for `subs->sync_endpoint`. [F329, F397, F398]
- In `snd_usb_pcm_prepare()`, `snd_usb_endpoint_prepare(chip, subs->data_endpoint)` returns `> 0` when reconfigured (requiring `snd_usb_set_format_quirk()`), so reset `ret = 0` afterwards. `snd_usb_pcm_pointer()` must return `SNDRV_PCM_POS_XRUN` if `atomic_read(&subs->stream->chip->shutdown)` is set. `snd_usb_pcm_open()` must set `SNDRV_PCM_INFO_SYNC_APPLPTR` (not `SNDRV_PCM_INFO_EXPLICIT_SYNC`) when `as->chip->lowlatency` is enabled on playback. [F327, F413, F415]
- `snd_usb_pcm_has_fixed_rate()` and `find_format()` (`snd_usb_find_format()`) accept a nullable `subs` and must check `if (!subs)` before dereferencing `subs->stream` or `subs->direction`. In `snd_usb_audioformat_set_sync_ep()`, return early before generic sync parsing if `fmt->sync_ep` is set, `snd_usb_parse_implicit_fb_quirk() > 0`, or `fmt->ep_idx > 0`. [F315, F388]
- `get_max_exposed()` and the `val >= cval->max` branch of `get_relative_value()` must use `DIV_ROUND_UP(cval->max - cval->min, cval->res)`. `snd_usb_mixer_vol_tlv()` must convert UAC 1/256 dB values to ALSA 1/100 dB units, return `-ENOMEM` if `size < sizeof(scale)`, and set `SNDRV_CTL_TLVT_DB_MINMAX_MUTE` when `cval->min_mute` is set. [F372, F418]

## Error Handling

- If `snd_usb_hw_params()` fails after `snd_media_start_pipeline(subs)`, call `close_endpoints(chip, subs)` (if `snd_usb_lock_shutdown()` succeeded), `snd_usb_unlock_shutdown(chip)`, and `snd_media_stop_pipeline(subs)`. [F285]
- If `snd_usb_endpoint_start()` fails in `start_endpoints()`, clear the failed endpoint's `SUBSTREAM_FLAG_*_EP_STARTED` bit in `subs->flags` and call `stop_endpoints(subs, false)`. In `snd_usb_pcm_prepare()`, when `start_endpoints(subs)` returns `-EPIPE`, bound the `again:` retry with `!retry++` and call `sync_pending_stops(subs)` before `snd_usb_endpoint_prepare()`. [F286, F360]
- Because `filter_error(cval, err)` returns `0` when `ignore_ctl_error` is set, helpers/callbacks returning `filter_error()` (`get_connector_value()`, `mixer_ctl_feature_get()`, `mixer_ctl_procunit_get()`, `mixer_ctl_selector_get()`) must initialize output values on or before the error path. Callers of `snd_us16x08_recv_urb()` (like `snd_us16x08_meter_get()`) must zero-initialize their buffer because `snd_us16x08_recv_urb()` ignores errors and returns `0`. [F316, F319]
- `restore_mixer_value()` and `connector_mixer_resume()` must ignore USB control errors and return `0` so `snd_usb_mixer_resume()` reaches `snd_usb_mixer_activate()`. In `snd_usb_audioformat_set_sync_ep()`, when `is_playback && attr == USB_ENDPOINT_SYNC_NONE`, endpoint 1 validation failures must return `0` (not `-EINVAL`). In `retire_capture_urb()`, log ISO packet errors/misaligned lengths with `dev_*_ratelimited()` and truncate to `frames * stride`. [F328, F400, F422]

## External Contracts

- UAC control requests (`UAC_GET_*`, `UAC_SET_*`, `UAC2_CS_*`) via `snd_usb_ctl_msg()`, `get_ctl_value()`, or `snd_usb_mixer_set_ctl_value()` must pass `wValue` (`validx`) as `(control << 8) | channel`. In `get_ctl_value_v1()` and `snd_usb_mixer_set_ctl_value()`, abort retry loops immediately on `-ETIMEDOUT`. [F318, F394]
- `snd_usb_set_cur_mix_value()` must check `cval->master_readonly` (channel 0) or `cval->ch_readonly & BIT(channel - 1)` (1-based channels) and return `0` without writing if read-only. `snd_usb_audioformat_set_sync_ep()` must verify `bLength >= USB_DT_ENDPOINT_AUDIO_SIZE` before reading `bSynchAddress`. [F389, F393]

## Known Pitfalls

- `__check_input_term()` mutates `struct usb_audio_term *term` in place during recursion, so callers (`parse_term_uac2_iterm_unit()`, `parse_term_uac3_iterm_unit()`, `parse_term_selector_unit()`, `parse_term_proc_unit()`, `parse_term_effect_unit()`) must set `term->id` and `term->type` after it returns. [F335]
- In `parse_audio_mixer_unit()`, `num_ins` accumulates `iterm.channels` across pins and `ich` is initialized to `0` once before the outer `pin` loop. Mixer Unit `bmControls` bitmaps are unaligned MSB-first byte arrays (`0x80 >> (idx & 7)`): validate with `mixer_bitmap_overflow()` and read via `check_matrix_bitmap()`, never `unsigned long *` bitmap ops. [F368, F383]
- In `snd_usb_substream_playback_trigger()`, `SNDRV_PCM_TRIGGER_START` falls through to `SNDRV_PCM_TRIGGER_PAUSE_RELEASE`, which must check `cmd == SNDRV_PCM_TRIGGER_START` before calling `start_endpoints(subs)` when `subs->lowlatency_playback` is true. Because `runtime->dma_area` uses `SNDRV_DMA_TYPE_VMALLOC` or `SNDRV_DMA_TYPE_DEV_SG`, `copy_to_urb()` and `retire_capture_urb()` must `memcpy` via `urb->transfer_buffer`. [F361, F412]
- Cast `u8`/`unsigned char` values to `unsigned long` or `unsigned int` before `<< 24` (`SND_DJM_DEVICE_SHIFT`) when packing into `private_value` to avoid sign-extension. Declare fixed-endianness USB payload variables (`cpu_to_be32()`/`cpu_to_le32()`) as `__be32`/`__le32`. In `get_min_max_with_quirks()`, pass `cval->min`/`cval->max` through `convert_signed_value()` before computing `dBmin`/`dBmax`. In `snd_rme_current_freq_get()`, check `den != 0` and use `div64_u64(num, den)`. [F357, F370, F373, F374]
