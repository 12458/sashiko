# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel (part 8)

This unit implements the Intel I225/I226 2.5GbE (`igc`) driver (PCI lifecycle, Tx/Rx/XDP/AF_XDP datapaths, PHY/NVM, PTP/PTM, and TSN Qbv/CBS/FPE) alongside `ixgbe` devlink, main header, and 82598 hardware support.

## Architecture & Data Flow
- `igc_clean_tx_irq()` does not reset `tx_buffer->type`, and both `igc_clean_tx_irq()` and `igc_clean_tx_ring()` switch on `type` to free SKB, XDP, or XSK frames; every Tx submission path in `igc_main.c` must explicitly set `tx_buffer->type` on the packet's first `igc_tx_buffer`. [F710]
- `struct igc_rx_buffer` shares page-shared fields (`dma`, `page`, `page_offset`, `pagecnt_bias`) and `struct xdp_buff *xdp` in an anonymous union discriminated by `ring->xsk_pool`; Rx ring allocation, polling, and cleanup (`igc_clean_rx_ring_xsk_pool()` vs `igc_clean_rx_ring_page_shared()`) must branch on `ring->xsk_pool`. `struct igc_xdp_buff` must keep `struct xdp_buff` as its first member and fit within `xdp_buff_xsk->cb` (`XSK_CHECK_PRIV_TYPE`) for `xsk_buff_to_igc_ctx()`. [F712, F748]
- In `igc_xdp_xmit_zc()`, `while (budget >= 4 && xsk_tx_peek_desc(pool, &xdp_desc))` must evaluate `budget >= 4` before peeking so descriptors are not consumed without room for data, context, and 2 empty-frame descriptors; after `xsk_tx_metadata_request()`, local `ntu`, `bi`, and `budget` must be refreshed from `ring->next_to_use`, `meta_req.tx_buffer`, and `meta_req.used_desc`. [F722, F755]
- In `igc_clean_tx_irq()`, `igc_alloc_rx_buffers()`, and `igc_alloc_rx_buffers_zc()`, the ring cursor `i` is biased by `i -= ring->count` before the `do-while` loop and must be restored via `i += ring->count` before using `i` after the loop; Rx refill loops must also clear `wb.upper.length = 0` on the newly reached `next_to_use` descriptor before writing `ring->tail`. `ixgbe_desc_unused()` and `igc_desc_unused()` subtract 1, so checking for queued Tx work in `igc_watchdog_task()` must test `igc_desc_unused(tx_ring) + 1 < tx_ring->count`. [F749, F768, F779]
- When `IGC_RXDADV_STAT_TSIP` is set in `igc_clean_rx_irq()` or `igc_clean_rx_irq_zc()`, save the buffer start in `ctx.rx_ts`, advance `data` (and `data_meta` in ZC) by `IGC_TS_HDR_LEN` (16), and subtract `IGC_TS_HDR_LEN` from `size`. `struct igc_inline_rx_tstamps` places `timer1[2]` at DWORDs 0..1 and `timer0[2]` at DWORDs 2..3 (little-endian `[0]` nsecs, `[1]` secs, converted via `le32_to_cpu()` in `igc_ptp_rx_pktstamp()`). [F745, F746]
- `igc_rx_vlan()` must decode `rx_desc->wb.upper.vlan` with `be16_to_cpu()` instead of `le16_to_cpu()` when both `IGC_RXDEXT_STATERR_LB` and `IGC_RING_FLAG_RX_LB_VLAN_BSWAP` are set. `igc_fix_features()` must keep `NETIF_F_HW_VLAN_CTAG_TX` equal to `NETIF_F_HW_VLAN_CTAG_RX` (`IGC_CTRL_VME`). `igc_rss_type_table[]` and `igc_xdp_rss_type[]` must be sized to `IGC_RSS_TYPE_MAX_TABLE` (16) with entries 10..15 set to `NONE` because `igc_rss_type()` returns a 4-bit index. [F747, F752, F844]
- In `igc_rd32()`, an all-ones read (`!(~value)`) must only detach and zero `hw->hw_addr` if `!reg || !(~readl(hw_addr))`. Because `hw->hw_addr` is zeroed while `adapter->io_addr` retains the `ioremap` base, `igc_io_slot_reset()` must restore `hw->hw_addr = adapter->io_addr` before `igc_reset()`, and `iounmap()` must always use `adapter->io_addr`. [F735, F763]
- For I226 (`igc_is_device_id_i226(hw)`), `PCIE_LINK_STATE_L1_2` must be disabled in `igc_probe()` (after setting `hw->device_id`), `__igc_resume()`, and (via `pci_disable_link_state_locked()`) `igc_io_slot_reset()`. In `__igc_open()` and `__igc_close()`, skip `pm_runtime_*` calls when `resuming` or `suspending` is true. [F795, F796, F810]
- Before reset or suspend when `IGC_PTP_ENABLED` is set, `igc_ptp_suspend()` must call `igc_ptp_time_save()` so `igc_ptp_reset()` can restore elapsed PHC time via `igc_ptp_time_restore()` and re-apply `adapter->tstamp_config`. In `igc_phc_get_syncdevicetime()`, `rd32(IGC_PTM_CURR_T2_H)` must be byte-swapped with `swab32()` before shifting and combining with `IGC_PTM_CURR_T2_L`. [F734, F753]
- `adapter->cycle_time` must remain strictly positive (reset to `NSEC_PER_SEC` by `igc_qbv_clear_schedule()`) because `igc_tx_launchtime()` and `igc_tsn_enable_offload()` divide by it. When `netif_running(adapter->netdev)` is true and `igc_tsn_will_tx_mode_change()` is true, `igc_tsn_offload_apply()` must schedule `adapter->reset_task` rather than calling `igc_tsn_reset()` in place. [F728, F774]
- In `igc_tsn_enable_offload()` and `igc_tsn_disable_offload()`, update `IGC_RXPBS` via `igc_tsn_set_rxpbsize()` to preserve `IGC_RXPBS_CFG_TS_EN`. `igc_tsn_reset()` must sync the empty-address filter with `adapter->fpe.mmsv.pmac_enabled`, and `igc_tsn_enable_offload()` must update `IGC_TXQCTL_PREEMPTIBLE` and `IGC_TXDCTL_PRIORITY_HIGH` together per Tx queue. When disabling MQPRIO (`!mqprio->qopt.num_tc`) in `igc_tsn_enable_mqprio()`, clear `adapter->strict_priority_enable`, call `igc_fpe_clear_preempt_queue()` and `netdev_reset_tc()`, then call `igc_tsn_offload_apply()`. [F724, F729, F736]
- On I226 in `igc_tsn_enable_offload()`, when programming a future `base_time` with no GCL running (`!(rd32(IGC_BASET_H) || rd32(IGC_BASET_L))`), write `IGC_TQAVCTRL_FUTSCDDIS` to `IGC_TQAVCTRL` before `IGC_QBVCYCLET_S`, `IGC_QBVCYCLET`, and `IGC_BASET_H`, and write `0` to `IGC_BASET_L` before `baset_l`. [F730]
- `igc_del_mac_filter()` must never clear RAR index 0 via `igc_clear_mac_filter_hw()`; call `igc_set_mac_filter_hw(adapter, 0, type, addr, -1)` instead. `igc_add_nfc_rule()` must keep `adapter->nfc_rule_list` sorted by ascending `rule->location` for `igc_get_nfc_rule()`. `igc_write_flex_filter_ll()` must clear `IGC_WUFC_FLEX_HQ` before writing FHFT and re-enable it afterward (`igc_del_flex_filter()` must keep it set while `igc_flex_filter_in_use()`). `igc_deliver_wake_packet()` must check `1 <= wupl <= IGC_WUPM_BYTES` (128) and call `skb_put(skb, wupl)` before `roundup(wupl, 4)`. [F732, F733, F744, F762]
- In `ixgbe_reset_hw_82598()`, save `hw->mac.orig_autoc` once (`orig_link_settings_stored = true`) and restore it and powered-down Atlas loopback lanes (`IXGBE_ATLAS_PDN_TX_REG_EN`) on reset. In `ixgbe` devlink, multiply `hw->flash.sr_words` by `2u` for `shadow-ram` byte size, write `pci_get_dsn()` with `put_unaligned_be64()`, and sleep `mdelay(500)` before reading `IXGBE_FWSM(hw)` in `ixgbe_devlink_reload_empr_finish()`. [F739, F754, F769, F791]

## Synchronization
- Hardware PTM calls (`igc_ptp_getcrosststamp()`, `igc_ptm_stop()`, `igc_ptp_reset()`, `igc_ptm_trigger()`, `igc_ptm_reset()`) must hold `adapter->ptm_lock`. Process-context callers acquiring `adapter->tmreg_lock` must use `spin_lock_irqsave()`. When both are held in `igc_ptp_reset()`, acquire `ptm_lock` outer to `tmreg_lock` and poll with `readx_poll_timeout_atomic()`. [F692, F693, F819]
- Access `adapter->tx_tstamp[]` only under `spin_lock_irqsave(&adapter->ptp_tx_lock, ...)`. `igc_ptp_disable_tx_timestamp()` must clear `IGC_RING_FLAG_TX_HWTSTAMP` before `igc_ptp_clear_tx_tstamp()`, whereas `igc_ptp_enable_tx_timestamp()` must configure `IGC_TSYNCTXCTL` and flush `IGC_TXSTMPL`/`IGC_TXSTMPH` before setting `IGC_RING_FLAG_TX_HWTSTAMP`. [F694, F695]
- Callers of `igc_xdp_init_tx_descriptor()`, `igc_fpe_init_tx_descriptor()`, and `igc_flush_tx_descriptors()` must hold `__netif_tx_lock()`. `igc_insert_empty_frame()` (under `__netif_tx_lock`) and `igc_set_rx_mode()` / `igc_write_mc_addr_list()` (under `netif_addr_lock_bh`) must use `GFP_ATOMIC` and never sleep. [F696, F823, F824]
- `igc_tx_map()` must execute `wmb()` before setting `first->next_to_watch = tx_desc` and writing `tx_ring->tail`, paired with `smp_rmb()` in `igc_clean_tx_irq()` after reading `tx_buffer->next_to_watch` and before reading `eop_desc->wb.status`. `__igc_maybe_stop_tx()` and `igc_clean_tx_irq()` must execute `smp_mb()` between stopping/waking subqueues and checking `igc_desc_unused()` / `next_to_clean` (and `!test_bit(__IGC_DOWN, &adapter->state)`). Use `tx_syncp` for `packets`/`bytes`/`restart_queue` in NAPI and `tx_syncp2` for `restart_queue2` in Tx. [F700, F702, F828]
- Serialize `adapter->qbv_transition`, `tx_ring->admin_gate_closed`, and `tx_ring->oper_gate_closed` with `spin_lock_irqsave(&adapter->qbv_tx_lock, flags)`; for a future `base_time` in `igc_save_qbv_schedule()`, set `admin_gate_closed = true` rather than `oper_gate_closed = true` until `igc_qbv_scheduling_timer()` fires. In `igc_clean_rx_irq_zc()`, hold `rcu_read_lock()` across `READ_ONCE(adapter->xdp_prog)` and `__igc_xdp_run_prog()`. [F704, F705, F731]
- In `igc_read_phy_reg_gpy()` and `igc_write_phy_reg_gpy()`, wrap direct MDIC access (`dev_addr == 0`) with `hw->phy.ops.acquire(hw)` / `release(hw)`, but do not hold it around `igc_read_xmdio_reg()` / `igc_write_xmdio_reg()`. In `ixgbe_read_i2c_phy_82598()`, hold `acquire_swfw_sync(hw, gssr)` across MDIO SDA/SCL accesses and release on all paths. [F707, F835]
- Hold `devl_lock(adapter->devlink)` around `ixgbe_devlink_register_port()`, `ixgbe_devlink_init_regions()`, and `ixgbe_devlink_destroy_regions()`. In `ixgbe_devlink_nvm_snapshot()`, acquire/release `ixgbe_acquire_nvm()` per block and release on `ixgbe_read_flat_nvm()` failure (as in `ixgbe_devlink_nvm_read()`). [F708, F833]

## Object Lifetimes
- In `igc_probe()`, error paths after `igc_ptp_init()` and `igc_get_hw_control()` must call `igc_release_hw_control()` and `igc_ptp_stop()`. In `igc_down()` and `igc_remove()`, `set_bit(__IGC_DOWN, &adapter->state)` must precede `igc_irq_disable()`, NAPI disable, `timer_delete_sync()`, `cancel_work_sync()`, and `hrtimer_cancel()`. `__igc_resume()` must call `igc_init_interrupt_scheme(adapter, true)` before `igc_reset()` because `__igc_shutdown()` frees `q_vectors`; `igc_free_q_vector()` must use `kfree_rcu(q_vector, rcu)` and `igc_update_stats()` must hold `rcu_read_lock()`. [F675, F703, F809, F826]
- `igc_request_tx_tstamp()` calls `skb_get(skb)` which `igc_ptp_free_tx_buffer()` releases via `dev_kfree_skb_any(tstamp->skb)` and clears `tstamp->skb = NULL`. For `IGC_TX_BUFFER_TYPE_XSK`, `igc_xsk_request_timestamp()` sets `tx_buffer->xsk_pending_ts = true` to block `igc_clean_tx_irq()` reclamation until `igc_ptp_free_tx_buffer()` clears `xsk_pending_ts = false`, `tstamp->xsk_tx_buffer = NULL`, and `tstamp->buffer_type = 0`, and calls `igc_xsk_wakeup()`. [F682, F683]
- In `igc_clean_rx_irq_zc()`, free `bi->xdp` via `xsk_buff_free(bi->xdp)` on `IGC_XDP_PASS`/`IGC_XDP_CONSUMED` and clear `bi->xdp = NULL` before advancing `ntc`. In `igc_setup_rx_resources()` rollback and `igc_free_rx_resources()`, call `xdp_rxq_info_unreg(&rx_ring->xdp_rxq)` and clear `rx_ring->rx_buffer_info = NULL`. `ixgbe` devlink region `.snapshot` callbacks must allocate `*data` with a `kvfree()`-compatible allocator (`kvzalloc()`). [F685, F687, F792]

## API Contracts
- `igc_cleanup_headers()` frees `skb` when returning `true`, so callers must not free it again. `igc_xdp_init_tx_descriptor()` takes ownership of `xdpf` only when returning `0`. `igc_tso()` returns `< 0` on error, `0` when disabled (without writing `*hdr_len`), and `1` when emitted; callers must zero-init `hdr_len` and call `igc_tx_csum()` only on `0`. `igc_tso()` must call `skb_cow_head(skb, 0)`, and `igc_features_check()` must clear csum/TSO when header lengths exceed limits or on encapsulated packets without `NETIF_F_TSO_MANGLEID`. [F676, F678, F718, F841]
- In `igc_xsk_tx_metadata_ops`, `igc_xsk_request_timestamp()` and `igc_xsk_request_launch_time()` take `struct igc_metadata_request *` as `_priv`, whereas `igc_xsk_fill_timestamp()` takes `u64 *`. Rx pages mapped with `IGC_RX_DMA_ATTR` require explicit `dma_sync_single_range_for_cpu()` / `for_device()` in `igc_clean_rx_ring_page_shared()`, `igc_alloc_rx_buffers()`, and `igc_get_rx_buffer()`. [F789, F830]
- In `igc_poll()`, return `budget` without `napi_complete_done()` if `!clean_complete`; otherwise call `igc_ring_irq_enable()` only if `napi_complete_done(napi, work_done)` returns true, and return `min(work_done, budget - 1)`. In `igc_configure_msix()`, write `IGC_GPIE_MSIX_MODE` to `IGC_GPIE` before `IGC_IVAR_MISC` or `IGC_IVAR0`. [F802, F843]
- `igc_check_reset_block()` returns positive `IGC_ERR_BLK_PHY_RESET` (12) when blocked (treated as `0` by `igc_phy_hw_reset()`). `igc_read_phy_reg_gpy()` / `igc_write_phy_reg_gpy()` encode Clause 45 MMD in `GPY_MMD_MASK` (upper 16 bits) and use Clause 22 MDIC (max offset 31) when upper 16 bits are 0. `igc_set_mac_filter_hw()` and `igc_add_etype_filter()` enable queue steering when `int queue >= 0` and disable it when `queue < 0`. `igc_save_cbs_params()` requires queue 0 CBS enabled before enabling queue 1 and rejects disabling queue 0 while queue 1 is enabled. [F716, F719, F721, F767]
- `igc_ptm_trigger()` must follow `IGC_PTM_CTRL_TRIG` with `wrfl()`, and `igc_ptm_reset()` must clear `IGC_PTM_CTRL_TRIG` before writing `IGC_PTM_STAT_ALL` to `IGC_PTM_STAT`. `igc_ptp_set_timestamp_mode()` must set `config->rx_filter = HWTSTAMP_FILTER_ALL` for any non-`NONE` filter. Reading `IGC_GORCL`/`IGC_GOTCL` in `igc_update_stats()` must be followed by reading `IGC_GORCH`/`IGC_GOTCH`. [F799, F811, F848]

## Error Handling
- On DMA error in `igc_tx_map()`, unmap prior fragments, free `tx_buffer->skb` via `dev_kfree_skb_any()`, clear `tx_buffer->skb = NULL`, and rewind `next_to_use`. In `ixgbe_set_ctx_dev_caps()`, clear `nvm_update_pending_*` to `false` on inactive version query error. In `ixgbe_reset_hw_82598()`, keep `hw->phy.ops.init(hw)` in `phy_status` and propagate non-zero after MAC reset. In `ixgbe_devlink_init_regions()` (only on `ixgbe_mac_e610`), reset `IS_ERR()` region pointers to `NULL`. [F677, F714, F715, F814]

## External Contracts
- `ixgbe_devlink_register_port()` must set `attrs.no_phys_port_name = 1`. `igc_watchdog_task()` must preserve the exact `"NIC Link is Up %d Mbps %s Duplex, Flow Control: %s\n"` and `"NIC Link is Down\n"` messages. Guard PTM cross-timestamping in `igc_ptp.c` with `IS_ENABLED(CONFIG_X86_TSC)` and `!defined(CONFIG_UML)`. Pad Tx SKBs `< 17` bytes via `skb_padto()` in `igc_xmit_frame()`, and pad preemptible queue frames (`tx_ring->preemptible`) to `ETH_ZLEN` via `skb_padto()` + `skb_put()` in `igc_xmit_frame_ring()`. [F740, F794, F836, F842]

## Known Pitfalls
- In `igc_regs.h`, `rd32(reg)` / `wr32(reg, val)` take a byte offset (`u8 __iomem *hw_addr`), whereas `array_rd32(reg, offset)` / `array_wr32(reg, offset, value)` take a DWORD index (`offset << 2`). Reading `IGC_TXSTMPH_0` clears all TXTT ready bits in `IGC_TSYNCTXCTL`: save `IGC_TSYNCTXCTL` before reading `IGC_TXSTMPH_0` in `igc_ptp_tx_hwtstamp()`, and read `IGC_TXSTMPH_0` after timing out any slot in `igc_ptp_tx_hang()`. [F790, F801]
- In `igc_xmit_frame_ring()` and `igc_xsk_request_launch_time()`, resolve the packet's `igc_tx_buffer` from `tx_ring->next_to_use` after `igc_insert_empty_frame()` and before emitting the context descriptor (`igc_tso()`, `igc_tx_csum()`, `igc_tx_ctxtdesc()`). In `igc_tx_csum()`, `skb_checksum_help()` fallback must jump to `csum_failed:` / `no_csum:` so `igc_tx_ctxtdesc()` still runs for VLAN/launchtime. [F757, F766]
- Check the `s32` return value of `igc_phy_has_link()` before inspecting `*success`. Stage ITR updates in `q_vector->itr_val` with `q_vector->set_itr = 1` rather than calling `writel()` in NAPI, and guard `total_bytes / packets` with `packets != 0` in `igc_update_itr()` / `igc_update_ring_itr()`. Clamp `PTP_CLK_REQ_PEROUT` `rq->perout.start.sec` to `>= safe_start.tv_sec + 2` in `igc_ptp_feature_enable_i225()`. Do not reinitialize `i = 0` in the `PBA_STRATEGY_EQUAL` fallthrough loop of `ixgbe_set_rxpba_82598()`. [F717, F759, F775, F781, F803]
- Avoid 32-bit overflow/truncation: widen `scaled_ppm` to `u64` before `<< 14` and `div_u64(rate, 78125)` in `igc_ptp_adjfine_i225()`; use `61036ULL` and `DIV_ROUND_UP_ULL(..., 2500000)` for `cbs_value` in `igc_tsn_enable_offload()`; cast high 32-bit reads to 64-bit before `<< 32`; check 64-bit `offset + size > nvm_size` before `u32` cast in `ixgbe_devlink_nvm_read()` and `words > nvm->word_size - offset` in `igc_read_nvm_eerd()`; use `DIV_ROUND_UP()` in `ixgbe_devlink_nvm_snapshot()` and `igc_alloc_q_vectors()`. [F770, F771, F772, F773, F777]
