# USB NETWORKING DRIVERS — drivers/net/usb (part 1)

`usbnet` minidrivers (`aqc111`, ASIX `ax8817x`/`ax88772`/`ax88179`, `mcs7830`, `ch9200`, `cx82310_eth`, `gl620a`, `huawei_cdc_ncm`, `int51x1`, `kalmia`, `lg-vl600`, `net1080`) and standalone USB network drivers (`catc`, `cdc-phonet`, `ipheth`, `kaweth`, `pegasus`).

## Architecture & Data Flow

- Structs overlaid on `usbnet::data` (`unsigned long[5]`, 20B on 32-bit)—`asix_data`, `mcs7830_data`, `huawei_cdc_ncm_state`—must fit in `sizeof(dev->data)`; `huawei_cdc_ncm_state` must keep `struct cdc_ncm_ctx *ctx` at offset 0. [F83, F125]
- `aqc111_rx_fixup()` must check `skb->len >= sizeof(desc_hdr)` (8), `start_of_descs == desc_offset`, `pkt_count * 2 + desc_offset < skb_len`, `pkt_total_offset` (`(pkt_len + 7) & 0x7FFF8`) `<= desc_offset` (`==` on `pkt_count == 0`), and `pkt_len <= dev->hard_mtu + AQ_RX_HW_PAD`. `ax88179_rx_fixup()` must check `pkt_cnt * 4 + hdr_off <= skb->len` after trimming `rx_hdr`. Both must `skb_trim()` to `desc_offset`/`hdr_off` and set `pkt_desc_ptr`/`pkt_hdr` before `skb_pull()`. [F76, F77, F78, F129]
- `aqc111_rx_checksum()` and `ax88179_rx_checksum()` must check L3/L4 error bits before comparing the masked L4 protocol field for TCP/UDP to set `CHECKSUM_UNNECESSARY`. [F98]
- In `aqc111`: update `aqc111_data->rx_checksum` and `SFR_RXCOE_CTL` together in `aqc111_set_features()` and reprogram `SFR_RXCOE_CTL`/`SFR_TXCOE_CTL` in `aqc111_configure_csum_offload()`; keep `aqc111_data->rxctl` and `SFR_RX_CTL` in sync in `aqc111_set_rx_mode()`/`aqc111_link_reset()`, but use `temp_rx_ctrl` in `aqc111_suspend()` so `aqc111_resume()` restores `rxctl`; in `aqc111_set_phy_speed()`, `SPEED_5000`..`SPEED_100` cases must fall through when `autoneg == AUTONEG_ENABLE` and `break` otherwise. [F64, F65, F112]
- `ax88179_status()` must defer link-up/carrier-on to `ax88179_link_reset()` via `usbnet_link_change()`, which checks `GMII_PHY_PHYSR_LINK`, updates `AX_RX_BULKIN_QCTRL` and `dev->rx_urb_size` together, and calls `netif_carrier_on()`. Every `driver_info` in `ax88179_178a.c` needs `.reset = ax88179_net_reset` (since `ax88179_stop()` clears `AX_MEDIUM_RECEIVE_EN`), which reads hardware `GMII_PHY_PHYSR` (calling `ax88179_reset()` if 0, else setting `AX_MEDIUM_RECEIVE_EN`). [F59, F60, F140]
- Functions switching `GMII_PHY_PAGE_SELECT` (MII `0x1f`, e.g., `ax88179_disable_eee()`, `ax88179_enable_eee()`, `rtl8211cl_phy_init()`) must restore page 0 before returning. In `ax88772_init_phy()`, `priv->phydev_int` is `NULL` when `priv->embd_phy` is true. [F44, F62]
- `vl600_rx_fixup()` must check `frame->magic` (`0x53544448`/`0x44544d48`) before `skb_copy_expand()`, and `skb->len + s->current_rx_buf->len <= le32_to_cpup(&frame->len)` before `skb_put_data()`. `vl600_pkt_hdr` must stay packed to 14B with `h_proto` at offset 12. [F85, F86]
- `cx82310_rx_fixup()` must reject `len > CX82310_MTU` before saving partial packets into `dev->partial_data` (`CX82310_MTU + 2` bytes) and pull 2-byte aligned `(len + 1) & ~1` bytes when packets follow. [F114, F132]
- `ipheth_probe()` must call `ipheth_enable_ncm()` before `ipheth_alloc_urbs()` and update `rx_buf_len` and `rcvbulk_callback` together. `ipheth_rcvbulk_callback()` must jump to `rx_submit` on 0-byte or 4-byte `0x00, 0x01` URBs. `ipheth_rcvbulk_callback_ncm()` must check `actual_length >= IPHETH_NCM_HEADER_SIZE`, `wNdpIndex == cpu_to_le16(sizeof(struct usb_cdc_ncm_nth16))`, and bound `dpe16` loop to `IPHETH_NDP16_MAX_DPE` (22). [F69, F80, F104]
- In `catc`: `ctrl_queue` (`CTRL_QUEUE` = 16) masks `ctrl_head`/`ctrl_tail` with `CTRL_QUEUE - 1` and advances `ctrl_tail` under `ctrl_lock` on overflow; `catc_stats_timer()` queues `EthStats + 7..0` descending because `catc_stats_done()` combines pairs on even indices; for `is_f5u011`, `catc_irq_done()` increments `recq_sz` when `RX_RUNNING`, and `catc_rx_done()` decrements `recq_sz` and resubmits `rx_urb` before clearing `RX_RUNNING` at 0. [F71, F89, F107]
- In `pegasus`: `read_bulk_callback()` must check `count >= 4`, mask `buf[count - 2]` error bits with `0x1c` (ignoring `0x02` `Long_pkt` for VLANs), and check `pkt_len <= PEGASUS_MTU`; `pegasus_resume()` must zero `status`/`actual_length` on `rx_urb` and `intr_urb` before invoking their callbacks. [F73, F91, F97]
- `kaweth_download_firmware()` must check `fw->size <= KAWETH_FIRMWARE_BUF_SIZE` (4096); `kaweth_usb_receive()` must check `count > 2` and `pkt_len <= count - 2`. `net1080_reset()` must update `REG_TTL` via `MK_TTL(NC_READ_TTL_MS, TTL_OTHER(ttl))`. [F74, F92, F93]
- In `cdc-phonet`: `usbpn_probe()` allocates `net_device` with `struct_size(pnd, urbs, rxq_size)`; `usbpn_probe()`/`usbpn_disconnect()` set `pnd->disconnected = 1` before releasing peer `(pnd->intf == intf) ? pnd->data_intf : pnd->intf`; `rx_complete()` sets `req = NULL` before `goto resubmit` on `-ENOENT`/`-ECONNRESET`/`-ESHUTDOWN` so `put_page(page)` runs without `rx_submit()`. [F109, F113, F121]

## Synchronization

- `ax88772_bind()` holds `pm_runtime_get_noresume(&intf->dev)` until `ax88772_unbind()` to prevent `ndo_open()` under `rtnl_lock` from deadlocking with `ax88772_resume()`. USB callbacks/error paths calling `phylink_suspend()`, `phylink_resume()`, or `phylink_disconnect_phy()` must take `rtnl_lock()`. [F152, F153]
- `__asix_mdio_read()`/`__asix_mdio_write()` must hold `dev->phy_mutex`, poll `asix_check_host_enable()` (`-ETIMEDOUT` after `AX_HOST_EN_RETRIES`), and restore `asix_set_hw_mii()`. `mcs7830_read_phy()`/`mcs7830_write_phy()` must hold `dev->phy_mutex` across `HIF_REG_PHY_DATA`/`CMD1`, polling `HIF_REG_PHY_CMD2_READY_FLAG_BIT`, and reading `HIF_REG_PHY_DATA`. [F21, F137]
- `.ndo_set_rx_mode` (`aqc111_set_rx_mode`, `asix_set_multicast`, `ax88172_set_multicast`, `ax88179_set_multicast`, `mcs7830_set_multicast`, `int51x1_set_multicast`, `pegasus_set_multicast`) runs in BH context and must use `usbnet_write_cmd_async()` or `update_eth_regs_async()`. [F156, F167]
- `driver_info->status` (`aqc111`, `asix`, `ax88179`, `ch9200`, `mcs7830`) and `ipheth_sndbulk_callback()` run in URB completion context and must defer work via `usbnet_defer_kevent()`, `usbnet_link_change()`, or `schedule_delayed_work(&dev->carrier_work, 0)`. In BH `rx_fixup`, `cx82310_rx_fixup()` defers `cx82310_enable_ethernet()` via `schedule_work(&priv->reenable_work)` (cancelled in `cx82310_unbind()`), and `nc_ensure_sync()` uses `usbnet_write_cmd_async()`. [F158, F159, F168]
- In `catc.c`, `tx_lock` and `ctrl_lock` require `spin_lock_irqsave()`. `tx_idx`/`tx_ptr` require `tx_lock`, and `catc_tx_run()` toggles `tx_idx` and zeros `tx_ptr`. `ctrl_queue` callbacks under `ctrl_lock` must not sleep or call `catc_ctrl_async()`. `catc_stop()` must call `timer_delete_sync(&catc->timer)` before `usb_kill_urb(catc->ctrl_urb)`. [F70, F160, F161]
- `kaweth_close()`/`kaweth_suspend()` must set `KAWETH_STATUS_CLOSING`/`SUSPENDING` before `kaweth_kill_urbs()`, which kills `irq_urb`/`rx_urb` both before and after `cancel_delayed_work_sync(&kaweth->lowmem_work)`. `pegasus_close()` calls `tasklet_kill(&pegasus->rx_tl)` before `unlink_all_urbs()`; `pegasus_disconnect()` sets `PEGASUS_UNPLUG` before `cancel_delayed_work_sync()` and `unregister_netdev()`. [F28, F166]

## Object Lifetimes

- `ax88772_bind()` uses `devm_kzalloc()` and manually sets up `mdio`, `phylink`, PHY, and `pm_runtime_get_noresume()` in that order (never `devm_mdiobus_*` on `udev->dev`); `ax88772_unbind()` and error paths unwind in reverse order with `rtnl_lock()` around `phylink_disconnect_phy()`. `ax88178_bind()` uses `kzalloc()` and requires `ax88178_unbind`. [F1, F2, F46, F134]
- In `asix_rx_fixup_internal()`, clear `rx->ax_skb = NULL` on `usbnet_skb_return()`, call `reset_asix_rx_fixup_info(rx)` on error, call `asix_rx_fixup_common_free()` on unbind, and if `netdev_alloc_skb_ip_align()` fails, still set `rx->remaining = size` and guard `rx->ax_skb`. In `vl600_rx_fixup()`, clear `s->current_rx_buf = NULL` on `usbnet_skb_return()` or error free, and free it in `vl600_unbind()`. [F3, F4, F42, F101]
- `huawei_cdc_ncm_bind()` checks `IS_ERR(subdriver)` before setting `drvstate->subdriver` and clears `usbnet_dev->status = NULL`; `huawei_cdc_ncm_unbind()` calls `subdriver->disconnect()` and clears `subdriver = NULL` before `cdc_ncm_unbind()`. [F8, F45]
- On `usbpn_open()` failure, free unsubmitted `req` and call `usbpn_close(dev)` (which kills/frees `pnd->urbs[i]` and sets `NULL`). On `kaweth_open()` `irq_urb` failure, kill `rx_urb` and call `usb_autopm_put_interface()`. `pegasus_disconnect()` frees `pegasus->rx_skb` only after `unregister_netdev()` and `unlink_all_urbs()`. `ipheth_disconnect()` calls `unregister_netdev()` and `ipheth_kill_urbs()` before `ipheth_free_urbs()`, `kfree(ctrl_buf)`, and `free_netdev()`. [F7, F11, F12, F15]
- `catc_ctrl_async()` requires a persistent buffer `<= 64` bytes (never stack) and array lvalues for `f5u011_rxmode_async()`/`f5u011_mchash_async()`. [F127]

## API Contracts

- Direct `usb_control_msg()`/`usb_bulk_msg()` callers (`__aqc111_write_cmd`, `ch9200`, `cx82310_cmd`, `kalmia`, `catc_probe`) must use heap buffers. Coherent-buffer URBs refilled via `usb_fill_bulk_urb()`/`usb_fill_int_urb()` in `ipheth` and `kaweth` must re-set `URB_NO_TRANSFER_DMA_MAP` (and `transfer_dma`). [F163, F169]
- `usbnet` `rx_fixup` handlers must check `skb->len` against header/trailer sizes. `FLAG_MULTI_PACKET` drivers (`aqc111`, `asix_devices`, `ax88172a`) must pass all frames to `usbnet_skb_return()` and call `usbnet_set_skb_tx_stats()` in `tx_fixup`. `aqc111_rx_fixup()`/`ax88179_rx_fixup()` must copy sub-packets into `netdev_alloc_skb_ip_align()` SKBs (not `skb_clone()`). With `NETIF_F_SG`, `ax88179_tx_fixup()` and (when `!dev->can_dma_sg`) `aqc111_tx_fixup()` must call `skb_linearize()`. [F95, F170, F173, F175]
- Never divide/modulo by `dev->maxpacket` inside `driver_info->bind`. `ax88178_change_mtu()` must reject `((new_mtu + hard_header_len + 4) % dev->maxpacket) == 0` with `-EDOM`, unlink RX URBs via `ax88178_set_mfb()` when `rx_urb_size` grows, and call `usbnet_update_max_qlen()`. [F117, F186]
- Check `asix_read_phy_addr() < 0` in a signed `int` before storing, and set `priv->mdio->phy_mask = ~(BIT(priv->phy_addr & 0x1f) | BIT(AX_EMBD_PHY_ADDR))` in `ax88772_init_mdio()`. `ax88772_init_phy()` must set `mac_managed_pm = true` and `phy_suspend()` on `phydev` (and `phydev_int`), disconnecting `phylink` under `rtnl_lock()` on error. `asix_rx_fixup_common*()` requires `struct asix_common_private *` in `dev->driver_priv`. [F39, F116, F126, F136, F177]
- `ax88179_read_cmd()`/`write_cmd()`/`write_cmd_async()` cast `data` to `u16 *`/`u32 *` and byte-swap for `size == 2`/`4` (use `__ax88179_read_cmd()` for raw bytes). `ax88179_suspend()`/`resume()` must wrap commands in `ax88179_set_pm_mode(dev, true/false)`. `ax88179_get_mac_addr()` sets `addr_assign_type = NET_ADDR_PERM` when valid and non-local. [F123, F155, F179]
- `aqc111_bind()` calls `usb_driver_set_configuration(udev, 1)` and returns `-ENODEV` if `bConfigurationValue != 1`, and gates `SPEED_2500`/`5000` on `USB_SPEED_SUPER`. `mcs7830` gates `HIF_REG_PAUSE_THRESHOLD` and 32B reg length on `mcs7830_get_rev(dev) == 2`. `ch9200` uses 2-byte control transfers with MII `loc * 2`. `nc_vendor_read()`/`nc_register_read()` return `0` on success and byte-swap `*retval_ptr` in place. `pegasus` `mii_phy_probe()` returns `0xff` on error, and `pegasus_siocdevprivate()` requires `CAP_NET_ADMIN` for `SIOCDEVPRIVATE + 2` and masks `data[1] & 0x1f`. [F40, F41, F96, F149, F150, F151]

## Error Handling

- `aqc111_read_cmd*()` must treat `ret < size` as error (logging `ret` before returning `-ENODATA`). `mcs7830_get_reg()` and `ch9200:control_read()` convert `0 <= ret < size` to `-ENODATA`/`-EINVAL`, and callers must check `< 0` before reading `data`. `ax88179_read_cmd()` callers with `size != 2 && size != 4` must zero `data` or check errors. `usb_bulk_msg()` callers (`kalmia_send_init_packet`, `cx82310_cmd`) must check `ret == 0` before reading `act_len`/`actual_len`. `aqc111_suspend()` must `memset(&wol_cfg, 0, sizeof(wol_cfg))`. [F34, F36, F37, F38, F48, F49]
- `huawei_cdc_ncm_suspend()`/`resume()` must roll back the first layer (`usbnet_resume()` or `subdriver->suspend()`) if the second fails. `asix_suspend()`/`resume()` must NULL-check `priv` and `priv->suspend`/`resume`. `ax88179_disconnect()` sets `disconnecting = 1` before `usbnet_disconnect()` to silence `-ENODEV` warnings in `__ax88179_read/write_cmd()`. [F9, F43, F180]

## Known Pitfalls

- In `aqc111_rx_fixup()`, every `continue` must call `skb_pull(skb, pkt_len_with_padd)` and `pkt_desc_ptr++`. In `ax88179_rx_fixup()`, `continue` without pulling when `pkt_len == 0`, else `skb_pull(skb, pkt_len_plus_padd)`. In `vl600_rx_fixup()`, when `count == 0` uses `s->current_rx_buf`, call `usbnet_skb_return()`, clear `s->current_rx_buf = NULL`, and return `0`. [F99, F100, F108]
- In `asix`/`ax88179` `get_eeprom()`/`set_eeprom()`, use `first_word = offset >> 1`, `last_word = (offset + len - 1) >> 1`, size `last_word - first_word + 1`, index `eeprom_buff[i - first_word]`, and pre-read boundary words on odd `offset` or `offset + len`. [F84, F111, F118]
- Cast `AQ_TX_DESC_MSS_MASK`/`VLAN_MASK` values to `u64` before shifting in `aqc111_tx_fixup()`. Use `memmove()` and `skb_set_tail_pointer()` when shifting `skb->data` in `asix`, `genelink`, `int51x1`, `kalmia`, `vl600`, and `net1080` `tx_fixup`. [F115, F128]
- Keep `msleep(500)` and `msleep(200)` in `ax88179_reset()`, and use `unsigned long` with `time_after(jiffies, jtimeout)` in `ax88179`. In `kaweth_probe()`, only download firmware when `!(le16_to_cpu(udev->descriptor.bcdDevice) >> 8)`, then free resources and return `-EIO`. [F119, F139, F145]
