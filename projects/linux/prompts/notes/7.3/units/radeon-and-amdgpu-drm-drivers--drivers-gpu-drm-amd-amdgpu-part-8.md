# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 8)

Implements AMDGPU VM page table management (`amdgpu_vm_pt`, CPU/SDMA updaters, TLB fences), buddy VRAM allocation (`amdgpu_vram_mgr`), Accelerated Compute Partitioning (`amdgpu_xcp`, `aqua_vanjaram`), XGMI hive/RAS (`amdgpu_xgmi`), VPE (`amdgpu_vpe`), ATHUB clockgating, and legacy AtomBIOS interpreter/display helpers.

## Architecture & Data Flow

- In `amdgpu_vm_ptes_update`, when a parent update covers allocated child PTs (`cursor.entry->bo` in descendants with `cursor.pfn < frag_start`), set `params->needs_flush = true` and move children to `params->tlb_flush_waitlist` via `amdgpu_vm_pt_add_list`. When `params->unlocked` is true (`amdgpu_vm_ptes_update`, `amdgpu_vm_pt_free_list`), only modify leaf entries (descending until `amdgpu_vm_pt_descendant` is false, clearing one entry at a time if `cursor.level < AMDGPU_VM_PTB`) and never queue PTs to `tlb_flush_waitlist`. [F1279, F1280]
- `amdgpu_vm_pt_create` allocates `amdgpu_bo_vm::entries` with 0 elements at `AMDGPU_VM_PTB`; `amdgpu_vm_pt_descendant` and PT walkers must check `level < AMDGPU_VM_PTB` before indexing `to_amdgpu_bo_vm(bo)->entries`. In `amdgpu_vm_pte_update_noretry_flags`, replace `*flags` with `adev->gmc.noretry_flags` only when `(*flags & AMDGPU_VM_NORETRY_FLAGS) == AMDGPU_VM_NORETRY_FLAGS`. [F1300, F1322]
- In `amdgpu_vm_sdma_update`, 64-bit PTEs are staged backward from the end of `ib->ptr` by decrementing `p->num_dw_left` by `nptes * 2` dwords (after reserving `copy_pte_num_dw + 7` dwords); `amdgpu_vm_sdma_copy_ptes` scales `p->num_dw_left * 4` for the GPU byte address. [F1345]
- In `aqua_vanjaram_switch_partition_mode`, `adev->gfx.funcs->switch_partition_mode(xcp_mgr->adev, num_xcc_per_xcp)` must run before `amdgpu_xcp_init` so `num_xcc_per_xcp` is updated before `__aqua_vanjaram_get_xcp_ip_info`/`__aqua_vanjaram_get_xcp_mem_id` read it. `amdgpu_xcp_init` must clear `xcp[i].valid = false` across all `MAX_XCP` slots, set `num_xcp_per_mem_partition` before `get_xcp_mem_id`, and end with `amdgpu_xcp_update_partition_sched_list`. [F1288, F1290]
- In `__aqua_vanjaram_calc_xcp_mode`, `if (num_xcc_per_xcp == 1)` returning `AMDGPU_CPX_PARTITION_MODE` must precede `switch (mode)` (`num_xcc / num_xcc_per_xcp` is 1..4 when `num_xcc <= 4`). In `__aqua_vanjaram_get_auto_mode`, checks for `num_mem_partitions == 1` (`SPX`), `== num_xcc` (`CPX`), and `== num_xcc / 2` must precede `num_mem_partitions == 2 && !(adev->flags & AMD_IS_APU)` (`DPX`). [F1327, F1328]
- `amdgpu_get_next_xcp` must leave `*from` at the returned valid `amdgpu_xcp` index without incrementing it, as `for_each_xcp` increments `++i` in the loop step. [F1332]
- In `amdgpu_xgmi_add_device`, if `supports_extended_data` is true and `amdgpu_xgmi_initialize_hive_get_data_partition(hive, true)` is called, it must be reset with `(hive, false)` before returning. In `amdgpu_xgmi_remove_device`, `amdgpu_xgmi_sysfs_rem_dev_info` must precede `atomic_dec_return(&hive->number_devices)` because it uses `hive->number_devices` for the `node%d` link name. In `pcs_clear_status`, clear PCS status registers by writing `0xFFFFFFFF` then `0` via `WREG32_PCIE`. [F1291, F1292, F1363]
- In `vpe_hw_init`, ungate power (`AMD_PG_STATE_UNGATE`) before `vpe_load_microcode` and `vpe_ring_start`. In `vpe_hw_fini`/`vpe_suspend`, `cancel_delayed_work_sync(&adev->vpe.idle_work)` must precede `vpe_ring_stop` and `AMD_PG_STATE_GATE`. In `vpe_set_powergating_state`, `AMD_PG_STATE_GATE` must set `vpe->context_started = false` so `vpe_ring_begin_use` ungates power, toggles bit 0 of `vpe->regs.context_indicator`, and sets `context_started = true`. [F1294, F1351]
- When `vpe.collaborate_mode` is true, `vpe_ring_emit_pipeline_sync`, `vpe_ring_emit_wreg`, and `vpe_ring_emit_reg_wait` must emit `vpe_ring_emit_pred_exec(ring, 0, <exec_count>)` matching the exact dword length of the following packet. In `vpe_ring_emit_ib`/`vpe_ring_emit_fence`, IB addresses must be 32-byte aligned (`& 0xffffffe0`) and fence addresses 4-byte aligned (`!(addr & 0x3)`). `vpe_ring_preempt_ib` must deassert `queue0_preempt` (`0`) and call `amdgpu_ring_set_preempt_cond_exec(ring, true)` even if polling `trail_fence_cpu_addr` times out. [F1295, F1305, F1354]
- All `athub_v*_set_clockgating` functions must return early if `amdgpu_sriov_vf(adev)` is true and only write `ATHUB_MISC_CNTL` when `def != data`. [F1357]
- Top-level `amdgpu_atom_execute_table` under `ctx->mutex` resets `data_block`, `reg_block`, `fb_base`, `divmul[0..1]` to `0` and `io_mode` to `ATOM_IO_MM`, while nested `atom_op_calltable` calls `amdgpu_atom_execute_table_locked` directly to preserve them. Repeated jumps to `ctx->last_jump` exceeding `ATOM_CMD_TIMEOUT_SEC` in `atom_op_jump` or nested failures in `atom_op_calltable` must set `ctx->abort = true`. [F1296, F1330]
- In `atom.c`, handlers calling `atom_put_dst` must snapshot `int dptr = *ptr` before `atom_get_dst`/`atom_skip_dst` and pass `&dptr` and `saved` to `atom_put_dst`. `ATOM_ARG_PS` uses `get_unaligned_le32`/`cpu_to_le32`, so `amdgpu_atom_execute_table` callers must convert multi-byte fields with `cpu_to_le16`/`32` and `le16`/`32_to_cpu`. `ATOM_ARG_FB` accesses `gctx->scratch` as host-endian `uint32_t`, so byte streams in `atom_context->scratch` (e.g., `amdgpu_atombios_dp_process_aux_ch`) must use `amdgpu_atombios_copy_swap`, not `memcpy`. [F1297, F1313, F1314]
- `amdgpu_atombios_encoder_set_backlight_level` must update `dig->backlight_level` and `mmBIOS_SCRATCH_2` (`amdgpu_atombios_encoder_set_backlight_level_to_reg`) before `amdgpu_atombios_encoder_setup_dig_transmitter`. `amdgpu_atombios_encoder_init_backlight` must skip registration on Apple (`PCI_VENDOR_ID_APPLE`) device `0x6741`, and use `acpi_video_register_backlight()` when `ATOM_BIOS_INFO_BL_CONTROLLED_BY_GPU` is unset or `!acpi_video_backlight_use_native()`. [F1299, F1366]
- In `amdgpu_atombios_encoder_setup_dig`, `ATOM_ENABLE` must power on eDP (`ATOM_TRANSMITTER_ACTION_POWER_ON`) before transmitter enable/link training; `ATOM_DISABLE` must disable DP video, set sink D3, and disable the transmitter before panel power-off. `amdgpu_atombios_crtc_program_ss` must not run `EnableSpreadSpectrumOnPPLL` when enabling with `ss->percentage == 0` or `ss->type & ATOM_EXTERNAL_SS_MASK`, or when disabling if another enabled CRTC (`i != crtc_id`) shares `pll_id`. [F1367, F1368]

## Synchronization

- In `amdgpu_vm_pt_alloc`, call `amdgpu_vm_eviction_unlock(vm)` before `amdgpu_vm_pt_create` and re-acquire `amdgpu_vm_eviction_lock(vm)` immediately after, before checking return value `r`. [F1222]
- Before writing page table BOs, `amdgpu_vm_cpu_update` must wait on `vmbo->bo.tbo.base.resv` (`DMA_RESV_USAGE_KERNEL`) via `dma_resv_wait_timeout`, and `amdgpu_vm_sdma_update` must add all `DMA_RESV_USAGE_KERNEL` fences from `bo->tbo.base.resv` to `p->job` via `drm_sched_job_add_dependency`. [F1242]
- In `amdgpu_vm_sdma_commit`, when `p->unlocked` is true, store the job fence in `p->vm->last_unlocked` instead of `p->vm->root.bo->tbo.base.resv`. For delayed updates (`fence && !p->immediate`), set `DRM_SCHED_FENCE_DONT_PIPELINE` on `f->flags` and, when `!p->unlocked`, add the fence to `root.bo->tbo.base.resv` with `DMA_RESV_USAGE_BOOKKEEP`. [F1244, F1391]
- In `amdgpu_vram_mgr.c`, `mgr->allocated_vres_list` linkage and `vres->task` (`pid`/`comm`) in `amdgpu_vram_mgr_new()`, `amdgpu_vram_mgr_del()`, and `amdgpu_vram_mgr_query_address_block_info()` must be accessed under `mgr->lock`. [F1396]
- Callers of `amdgpu_xcp_query_partition_mode` holding `xcp_mgr->xcp_lock` must pass `AMDGPU_XCP_FL_LOCKED`. `__amdgpu_xcp_switch_partition_mode` must set `xcp_mgr->mode = AMDGPU_XCP_MODE_TRANS` under `xcp_lock` before `switch_partition_mode`, restore it on failure, and call `amdgpu_xcp_sysfs_entries_update` on success. [F1251, F1287]
- Hold `xgmi_mutex` when accessing `xgmi_hive_list` in `amdgpu_get_xgmi_hive` and `amdgpu_xgmi_remove_device`; `amdgpu_get_xgmi_hive` must initialize a new `amdgpu_hive_info` and call `kobject_get(&hive->kobj)` before dropping `xgmi_mutex`. [F1252]

## Object Lifetimes

- In `amdgpu_vm_tlb_fence_create`, `f->dependency` takes ownership of `*fence` without `dma_fence_get`, and `dma_fence_get(&f->base)` must precede `schedule_work(&f->work)` so `amdgpu_tlb_fence_work` owns a reference to drop while `*fence` gets `&f->base`. In `amdgpu_vm_sdma_commit`, `amdgpu_job_submit` returns `f` paired with `dma_fence_put(f)` at exit; updating `p->vm->last_unlocked` requires `dma_fence_get(f)` before `swap` and `dma_fence_put(tmp)`, while `*fence` uses `swap(*fence, f)` so the final `dma_fence_put(f)` drops the old `*fence`. [F1218, F1220]
- In `amdgpu_vm_pt_alloc`, child `pt_bo` must reference its parent via `pt_bo->parent = amdgpu_bo_ref(cursor->parent->bo)`. [F1223]
- In `amdgpu_xcp_dev_unplug`, for each secondary partition `i >= 1` with non-NULL `p_ddev`, restore saved `rdev`, `pdev`, `driver`, and `vma_offset_manager` onto `p_ddev` after `drm_dev_unplug(p_ddev)` and before `amdgpu_xcp_drm_dev_free(p_ddev)`. [F1228]
- `amdgpu_get_xgmi_hive` returns a kobject-referenced hive (holding both the `xgmi_hive_list` ref and a caller `kobject_get` ref) that callers must release via `amdgpu_put_xgmi_hive`. It sets `hive->reset_domain` only when `!amdgpu_sriov_vf(adev)`, reusing `adev->reset_domain` via `amdgpu_reset_get_reset_domain` if `type == XGMI_HIVE`. In `amdgpu_xgmi_remove_device`, clear `hive->hi_req_gpu = NULL` under `hive_lock` if it equals `adev`, drop the list ref when `number_devices` hits 0, and set `adev->hive = NULL` after `amdgpu_put_xgmi_hive`. [F1231, F1232, F1360]
- In `amdgpu_vpe_init_microcode` (on error) and `vpe_sw_fini`, `release_firmware(adev->vpe.fw)` must be followed by `adev->vpe.fw = NULL`. In `amdgpu_atombios_encoder_get_lcd_info`, `edid` from `drm_edid_alloc` is saved to `bios_hardcoded_edid` if `drm_edid_valid(edid)` is true, or freed immediately with `drm_edid_free(edid)` if false. [F1235, F1239]

## API Contracts

- In `amdgpu_vm_ptes_update`, `start`/`end` are 4KB PFNs (`cursor.pfn`), while `dst` is a byte address/offset advancing by `nptes * ((uint64_t)AMDGPU_GPU_PAGE_SIZE << shift)`. `vm->update_funcs->update` (`amdgpu_vm_cpu_update`/`amdgpu_vm_sdma_update`) takes byte offset `pe`, so callers (`amdgpu_vm_pde_update`, `amdgpu_vm_ptes_update`) must scale entry indices by `8`. Both `amdgpu_vm_cpu_commit` and `amdgpu_vm_sdma_commit` must atomically increment `p->vm->tlb_seq` when `p->needs_flush` is true. `amdgpu_vm_pt_create` sets `bp.xcp_id_plus1 = xcp_id + 1` (`0` means unset `-1`). [F1258, F1259, F1282, F1344]
- In `amdgpu_vram_mgr.c`, `fpfn`, `lpfn`, `page_alignment`, and `res->start` are PFNs, whereas `drm_buddy_alloc_blocks`, `amdgpu_vram_mgr_block_start`/`size`, and `visible_vram_size` are in bytes (convert via `PAGE_SHIFT`). `amdgpu_vram_mgr_query_page_status` returns `0` (`reserved_pages`), `-EBUSY` (`reservations_pending`), or `-ENOENT`; only call `amdgpu_vram_mgr_reserve_range` on `-ENOENT`. `amdgpu_vram_mgr_alloc_sgt` maps chunks `<= AMDGPU_MAX_SG_SEGMENT_SIZE` via `dma_map_resource` (`sg_page` is NULL), so `amdgpu_vram_mgr_free_sgt` must use `dma_unmap_resource`, not `dma_unmap_sg`. [F1263, F1380, F1387]
- `amdgpu_xcp_get_partition` takes a 0-based `instance` and returns a positive bitmask of partition IDs (`BIT(i)`), not an index. `amdgpu_set_xcp_id` takes `ring->xcc_id` for `AMDGPU_RING_TYPE_COMPUTE`/`KIQ` and `ring->me` for other rings. `xcp_metrics_show` must query size via `amdgpu_dpm_get_xcp_metrics(adev, xcp->id, NULL)` and reject `size > PAGE_SIZE` with `-ENOSPC` before populating `buf`. [F1265, F1266, F1307]
- `amdgpu_xgmi_get_bandwidth` requires non-NULL `min_bw`/`max_bw` (zeroed upfront) and rejects `peer_adev == NULL` with `-EINVAL` when `bw_mode == AMDGPU_XGMI_BW_MODE_PER_PEER`. [F1270]
- `vpe_ring_emit_wreg`/`reg_wait` shift dword `reg` by `<< 2`, and `vpe_ring_get_rptr`/`get_wptr`/`set_wptr` convert between dword indices and byte offsets via `<< 2`/`>> 2`. `amdgpu_vpe_configure_dpm` must verify `pratio_vmin`/`vmid`/`vnorm`/`vmax_freq` are non-zero before calling `vpe_internal_get_pratio`/`vpe_u1_8_from_fraction` (`div16_u16_rem` divisor). All `athub_v*_get_clockgating` functions OR (`|=`) `AMD_CG_SUPPORT_ATHUB_MGCG`/`LS` into `*flags`. [F1261, F1273, F1340]
- In `amdgpu_atombios_dp_aux_transfer`, `amdgpu_atombios_dp_process_aux_ch` returns `0` on write success, so replace non-negative write returns with `msg->size` and set `msg->reply = ack >> 4`. In `amdgpu_atombios_crtc_program_pll`, pass `clock / 10` (10 kHz) for `SetPixelClock` `crev` 1..6 and `clock * 10` (100 Hz) for `crev` 7. In `setup_dig_encoder` (v4) and `setup_dig_transmitter` (v5/v6), encode `hpd_id` as `0` if `AMDGPU_HPD_NONE` else `hpd_id + 1`, and `ucDigEncoderSel` as `1 << dig_encoder`. In `get_lcd_info`, `usModePatchTableOffset` is absolute if `(frev == 1) && (crev < 2)` else relative to `data_offset`; `ucFakeEDIDLength` is bytes if `128`, 128-byte blocks if `> 0`, or a 3-byte empty record if `0`. [F1275, F1276, F1277, F1278]

## Error Handling

- In `amdgpu_vm_sdma_prepare`, if `amdgpu_sync_push_to_job` fails after `amdgpu_vm_sdma_alloc_job`, zero `p->num_dw_left` and call `amdgpu_job_free(p->job)`. In `amdgpu_vm_sdma_update`, if `drm_sched_job_add_dependency` fails after `dma_fence_get(fence)`, call both `dma_fence_put(fence)` and `dma_resv_iter_end(&cursor)`. [F1219, F1221]
- In `amdgpu_vram_mgr_alloc_sgt`, zero `sg->length` after `sg_alloc_table` so `error_unmap` only calls `dma_unmap_resource` on entries with `sg->length != 0`. In `amdgpu_xcp_dev_alloc`, convert `-ENOSPC` from `amdgpu_xcp_drm_dev_alloc` to `ret = 0` and break to `out`, propagating other errors. In `amdgpu_atom_execute_table_locked`, always jump to `free:` to `kfree(ectx.ws)`. [F1227, F1237, F1267]

## External Contracts

- `amdgpu_xgmi_show_connected_port_num` must add 1 to 0-based `current_node` and `i` indices to match 1-based `node1..nodeN` sysfs names. In `aqua_vanjaram.c`, `aqua_vanjaram_read_*_state` must return `-EOVERFLOW` if `max_size < sizeof(*state_header) + amdgpu_reginst_size(...)`. In `amdgv_sriovmsg.h`, `amd_sriov_msg_pf2vf_info` and `amd_sriov_msg_vf2pf_info` must stay `AMD_SRIOV_MSG_SIZE_KB << 10` (1024B) by updating `*_INFO_FILLED_SIZE`. [F1310, F1393, F1394]

## Known Pitfalls

- When `for_each_amdgpu_vm_pt_dfs_safe` has a non-NULL `start`, `amdgpu_vm_pt_continue_dfs` stops before `start->entry`, so callers (`amdgpu_vm_pt_add_list`) must handle `start->entry` after the loop. In `amdgpu_vm_ptes_update`, do not call `amdgpu_vm_pt_next` when `frag < shift` so the outer loop descends to a child table, and widen `AMDGPU_GPU_PAGE_SIZE` and `mask + 1` to `uint64_t` before `<< shift`. In `amdgpu_vm_pte_fragment`, use `min_t(unsigned int, ffs(start) - 1, fls64(end - start) - 1)` so `ffs(start) == 0` wraps to `UINT_MAX`, and use `~((1ULL << max_frag) - 1)` when masking 64-bit `end`. [F1319, F1321, F1333, F1334, F1335]
- In `aqua_vanjaram.c`, `num_regs` sums in `pcie`/`xgmi`/`wafl`/`usr`/`usr1_reg_addrs` must match `NUM_*_SMN_REGS`, and `aqua_vanjaram_read_*_state` must advance instance pointers via `p = reg_data` after reading `smn_reg_values[]` rather than indexing the outer array. In `__aqua_vanjaram_get_xcp_ip_info`, compute `num_sdma_xcp`/`num_vcn_xcp` with `DIV_ROUND_UP(..., num_xcp)` and guard `num_xcp / num_vcn` with `if (num_vcn && num_xcp > num_vcn)`. In `amdgpu_xgmi_get_hops_count`, mask `psp_xgmi_node_info.num_hops` with `0x7` (bits `[7:6]` hold link type). [F1309, F1311, F1339, F1347]
- In `atom.c`, `atom_op_mul32` must cast operands to `uint64_t`, `atom_op_div32` must check `src != 0` and use `do_div(val64, src)` on `((uint64_t)divmul[1] << 32) | dst`, and `atom_put_dst` on `ATOM_IO_MM` `idx == 0` must shift `val << 2`. In `amdgpu_atombios_dp_process_aux_ch`, `base` is `(unsigned char *)(scratch + 1)` (byte offset 4) and `recv` is `base + 16` (byte offset 20), matching `lpAuxRequest = 4` and `lpDataOut = 20`. [F1341, F1349, F1369]
