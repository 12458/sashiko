# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 7)

This unit implements GPU page table management (`xe_pt`, `xe_pt_walk`), Shared Virtual Memory (`xe_svm` / `drm_gpusvm`), Protected Xe Path (`xe_pxp`), Register Table Processing (`xe_rtp`, `xe_reg_sr`), ringbuffer command emission (`xe_ring_ops`), memory shrinker, DRM query ioctls (`xe_query`), sync objects (`xe_sync`), range fences (`xe_range_fence`), suballocation (`xe_sa`), SR-IOV VF/PF support, scheduler jobs (`xe_sched_job`), and survivability mode.

## Architecture & Data Flow
- `xe_pt_destroy()` only recurses into child page tables (`pt->level > 0`) when `pt->num_live` is non-zero and walks `pt_dir->staging` via `xe_pt_entry_staging()`, so attaching a child to a non-preexisting parent in `xe_pt_insert_entry()` must set `parent->base.staging[offset]` and increment `parent->num_live`. Each `xe_vm_pgtable_update`'s `pt_entries` array is indexed relative to `entry->ofs` (`offset - entry->ofs`), whereas `pt_dir->children` and `pt_dir->staging` use the absolute index (`entry->ofs + j`). [F775, F895]
- In `xe_pt_abort_bind()`, `xe_pt_abort_unbind()`, and `xe_pt_update_ops_abort()`, staged updates must be unwound in reverse order using a signed `int` counter (`for (i = count - 1; i >= 0; --i)`), and `xe_pt_update_ops_abort()` must skip indices where `!pt_op->vma || i >= pt_update_ops->current_op`. [F868]
- `bind_op_prepare()` must set `BIT(tile->id)` in `vma->tile_staged`, `unbind_op_prepare()` must check `(vma->tile_present | vma->tile_staged) & BIT(tile->id)` before skipping an unbind, and `bind_op_commit()` must clear `BIT(tile->id)` from `vma->tile_staged` while setting it in `vma->tile_present`. [F837]
- On non-LR VMs, rebinding a VMA in `bind_op_prepare()` increments `vm->tlb_flush_seqno`, and `xe_sched_job_arm()` must compare `vm->tlb_flush_seqno` against `q->tlb_flush_seqno` (or check `vm->batch_invalidate_tlb`) to update `q->tlb_flush_seqno` and set `job->ring_ops_flush_tlb = true`. In `xe_ring_ops.c`, ring instructions that invalidate TLBs or AuxCCS tables (`emit_flush_imm_ggtt` with `MI_INVALIDATE_TLB`, `emit_pipe_invalidate`, `emit_flush_invalidate`, `emit_aux_table_inv`) must be bracketed by `preparser_disable(true)` and `preparser_disable(false)` before `emit_bb_start`. [F851, F937]
- In `xe_pt_offset()`, masking `addr` with `(1ull << walk->shifts[level + 1]) - 1` must be guarded by `level < walk->max_level` so `walk->shifts` is not indexed out of bounds. [F885]
- In `xe_res_cursor.h`, `xe_res_next()` must return immediately when `cur->remaining` reaches 0 after subtracting `size`, and `__xe_res_dma_next()` must guard coalescing with `cur->dma_seg_size - start < cur->remaining` so the cursor never dereferences past the end of `sgl`, `dma_addr`, or the VRAM buddy block list. [F869]
- In `apply_one_mmio()` (`xe_reg_sr.c`), masked registers (`reg.masked`) form the upper-16-bit write mask via `entry->clr_bits << 16` and OR in `entry->set_bits` without reading hardware (`entry->clr_bits` must be a superset of `entry->set_bits` in the lower 16 bits), while non-masked registers must use `xe_gt_mcr_unicast_read_any()`/`xe_gt_mcr_multicast_write()` when `reg.mcr` is set or `xe_mmio_read32()`/`xe_mmio_write32()` otherwise. [F891, F911]
- In `gsccs_send_message()`, `msg_in_size` and `msg_out_size_max` must not exceed `gsc_res->inout_size - sizeof(struct intel_gsc_mtl_header)`, `xe_device_wmb(xe)` must run after writing `gsc_res->batch`/`gsc_res->msg_in` and before `pxp_pkt_submit()`, and `reply_size` (`buffer_len + sizeof(struct pxp_cmd_header)`) must be clamped to `msg_out_size_max` before copying from `gsc_res->msg_out`. [F861, F923]
- An `xe_exec_queue` may only be added to `pxp->queues.list` in `__exec_queue_add()` while `pxp->status == XE_PXP_ACTIVE` under `pxp->mutex` with a runtime PM reference held, and `__pxp_exec_queue_remove()` must release that PM reference and reset `q->pxp.type` to `DRM_XE_PXP_TYPE_NONE` when unlinking `q->pxp.link`. [F844]
- `enum xe_sriov_mode` starts at `XE_SRIOV_MODE_NONE = 1` so `xe->sriov.__mode == 0` catches unprobed state in `xe_device_sriov_mode()`, requiring `xe_sriov_probe_early()` before any `IS_SRIOV*()` call; when PF mode is unsupported or disabled (`pf_continue_as_native` in `xe_sriov_pf_readiness()`), `pci_sriov_set_totalvfs(pdev, 0)` must be called. In PF mode, VF IDs are 1-based (`VFID(1)..VFID(totalvfs)`) with index 0 (`PFID`) for PF, so `xe->sriov.pf.vfs` has `1 + xe_sriov_pf_get_totalvfs(xe)` elements and valid `vfid` satisfies `vfid <= xe_sriov_pf_get_totalvfs(xe)`. [F819, F863, F908]
- Because `struct xe_sched_job_snapshot` marks `batch_addr[]` with `__counted_by(batch_addr_len)`, `xe_sched_job_snapshot_capture()` must set `snapshot->batch_addr_len = q->width` before indexing `snapshot->batch_addr[i]`. [F897]

## Synchronization
- In `xe_range_fence_insert()`, `rfence->tree` and `rfence->fence` must be initialized before `dma_fence_add_callback(fence, &rfence->cb, xe_range_fence_signal_notify)`. Both `xe_range_fence_signal_notify()` and `xe_range_fence_tree_remove_all()` must never remove nodes directly from `tree->root` (in IRQ context or during `xe_range_fence_tree_iter_first()`/`next()` walks); they must queue items via `llist_add()` onto `tree->list` and defer `xe_range_fence_tree_remove()`, `dma_fence_put()`, and `kfree()` to `__xe_range_fence_tree_cleanup()`. [F794, F881, F924]
- Waiters on `pxp->termination` or `pxp->activation` (`pxp_start()`, `pxp_terminate()`, `xe_pxp_pm_suspend()`) must never hold `pxp->mutex` during `wait_for_completion_timeout()`, as `complete_all()` is called under `pxp->mutex`. In `pxp_invalidate_queues()`, each queue on `pxp->queues.list` must be pinned with `xe_exec_queue_get_unless_zero()` and moved to a local list under `pxp->queues.lock` before dropping the spinlock to call `xe_exec_queue_kill()` and `__pxp_exec_queue_remove(pxp, q, false)`. [F797, F800]
- In `xe_svm_garbage_collector()`, `vm->svm.garbage_collector.lock` must be dropped after dequeuing each `xe_svm_range` and before calling `__xe_svm_garbage_collector()` (which takes `xe_vm_lock(vm, false)` and calls `drm_gpusvm_range_remove()`). [F805]
- `xe_pt_zap_ptes_range()` requires holding `vm->svm.gpusvm.notifier_lock` in write mode, or `notifier_lock` in read mode plus `vm->lock` in write mode; after zapping PTEs in `xe_svm_ranges_zap_ptes_in_range()`, setting `range->tile_invalidated` via `WRITE_ONCE` must not fail before TLB invalidation. [F933]
- In `xe_sriov_vf_ccs_fini()` and `xe_sriov_vf_ccs_detach_bo()`, instructions must be neutralized before releasing the queue or batchbuffer: set LRC ring tail to head via `xe_lrc_set_ring_tail(lrc, xe_lrc_ring_head(lrc))` on teardown, and overwrite `bb->cs` with `MI_NOOP` before `xe_bb_free()` on BO detach. [F810]
- In `user_fence_worker()` (`xe_sync.c`), `ufence->signalled` must be set to 1 and copied to `ufence->addr` before `wake_up_all(&ufence->xe->ufence_wq)`, and `xe_sync_entry_signal()` must null out `sync->chain_fence` after transferring it to `drm_syncobj_add_point()`. [F857]

## Object Lifetimes
- Before `xe_pt_commit_prepare_bind()`, `entries[i].pt_entries[j].pt` owns new child `xe_pt` subtrees and requires `xe_pt_cancel_bind()` on error, whereas `xe_pt_commit_prepare_bind()` moves new subtrees into `pt_dir->staging` and stores displaced subtrees in `entries[i].pt_entries[j].pt` for `xe_pt_commit()` or `xe_pt_abort_bind()`. [F772]
- `pxp_fini()` must call `destroy_workqueue(pxp->irq.wq)` before `xe_pxp_destroy_execution_resources(pxp)`, and `destroy_gsc_client_resources()` (if `gsc_res->q`) must tear down `gsc_res->q`, `gsc_res->bo`, and `gsc_res->vm` in reverse creation order. [F783]
- In `xe_drm_pagemap_populate_mm()`, `xe_bo_get(bo)` and `xe_pm_runtime_get_noresume(xe)` are acquired for `bo->devmem_allocation` before `drm_pagemap_migrate_to_devmem()`, so `xe_svm_devmem_release(&bo->devmem_allocation)` must be called if migration fails. [F784]
- In `xe_svm_unmap_address_range()`, the caller must hold `drm_gpusvm_range_get(range)` across `__xe_svm_garbage_collector(vm, to_xe_range(range))` while unlinking `garbage_collector_link` before `drm_gpusvm_range_put(range)`. In `__xe_svm_handle_pagefault()`, `xe_vm_set_validation_exec(vm, &exec)` must be cleared with `NULL` immediately after `xe_vm_range_rebind()` and before `drm_exec_retry_on_contention(&exec)` or exiting `xe_validation_guard`. [F785, F786]
- In `xe_shrinker_fini()`, `shrinker_free(shrinker->shrink)` must precede `flush_work(&shrinker->pm_worker)` and `kfree(shrinker)` so `xe_shrinker_scan()` cannot requeue `pm_worker` after flush. [F789]
- For `DRM_XE_SYNC_TYPE_USER_FENCE`, `user_fence_create()` pins `current->mm` via `mmgrab()` (`mmdrop()` in `user_fence_destroy()`), `user_fence_worker()` must use `mmget_not_zero()` and `kthread_use_mm()`/`kthread_unuse_mm()` around `copy_to_user()` before `mmput()`, and `xe_sync_entry_signal()` must take `dma_fence_get(fence)` and `user_fence_get(sync->ufence)` before `dma_fence_add_callback()`. [F792, F947]
- Because `xe_sched_job_create()` writes 2 elements of `job->ptrs[]` when `xe_sched_job_is_migration(q)` is true even if `q->width == 1` (requiring a 2-element `batch_addr` array), both `job_alloc()` and `job_free()` must select `xe_sched_job_parallel_slab` when `xe_exec_queue_is_parallel(q) || xe_sched_job_is_migration(q)`, and `xe_sched_job_arm()` must null out `job->ptrs[i].lrc_fence` and `job->ptrs[i - 1].chain_fence` as they are armed into `job->fence`. [F852, F896]

## API Contracts
- `xe_range_fence_insert()` consumes ownership of `@rfence` on every return path (inserting into `tree->root` or calling `ops->free(rfence)` immediately if already signaled or on callback error), so callers must never free or access `@rfence` afterwards. [F777]
- `xe_pt_create()` does not initialize the page-table BO, so if a new table is not completely covered by the bind range (`!covers` in `xe_pt_stage_bind_entry()`), the caller must call `xe_pt_populate_empty()` or `xe_pt_clear()`. [F827]
- `xe_pt_walk_range()` and `xe_pt_walk_shared()` take an exclusive upper address `end` (`last + 1`), whereas `xe_range_fence_insert()`, `xe_range_fence_tree_first()`/`next()`, and `xe_vm_pgtable_update_ops` (`start`, `last`) use an inclusive `last`. Callbacks in `xe_pt_walk_shared()` (`xe_pt_zap_ptes_entry`, `xe_pt_stage_unbind_entry`, `xe_pt_stage_unbind_post_descend`) receive the parent's `level` (or `root->level + 1` with `parent == *child` for root) and must operate on `*child` at `level - 1`, checking `parent != *child` before killing `*child`. [F864, F875]
- In `xe_rtp`, stepping rules (`XE_RTP_RULE_GRAPHICS_STEP`, `XE_RTP_RULE_MEDIA_STEP`) match half-open `[step_start, step_end)`, whereas IP version range rules (`XE_RTP_RULE_*_VERSION_RANGE`) match closed `[ver_start, ver_end]`. `xe_rtp_process_ctx_enable_active_tracking()` requires an initialized `unsigned long` bitmap of at least `BITS_TO_LONGS(n_entries)` words, as `rtp_mark_active()` only sets bits via `bitmap_set()`. [F831, F902]
- Callers of `xe_sriov_function_name()` must pass a buffer of `size >= 5` bytes for `"PF"` or `"VF%u"`. [F903]
- In `xe_shrinker.c`, `xe_shrinker_count()` and `xe_shrinker_scan()` may only count/scan non-purgeable `shrinkable_pages` for swap when `sc->gfp_mask & __GFP_FS` is set (`shrink_flags.writeback` also requires `!ctx.no_wait_gpu && (sc->gfp_mask & __GFP_IO)`), `xe_shrinker_count()` must return `SHRINK_EMPTY` when 0 pages are reclaimable, and `xe_shrinker_scan()` must update `sc->nr_scanned` and return `SHRINK_STOP` when `nr_scanned == 0`. [F950, F951]
- In `xe_svm_invalidate()`, even when `xe_vm_is_closed(vm)` skips GPU page tables, `xe_svm_range_notifier_event_end()` must still run for every matching `drm_gpusvm_range` to unmap DMA pages. [F955]

## Error Handling
- When `xe_sync_entry_parse()` fails for `DRM_XE_SYNC_TYPE_USER_FENCE`, `sync->ufence` holds an `ERR_PTR`, so callers must only call `xe_sync_entry_cleanup()` on entries where `xe_sync_entry_parse()` returned 0. [F823]
- When `xe_svm_range_set_default_attr()` returns `-EAGAIN` in `xe_svm_garbage_collector()`, it must record `ret = -EAGAIN` and continue draining `range_list`, and `xe_svm_handle_pagefault()` must re-lookup `vma` via `xe_vm_find_vma_by_addr()` on `-EAGAIN` before retrying. [F880]
- In `__xe_sa_bo_new()`, requests with `size > sa_manager->base.size` must be rejected upfront with `ERR_PTR(-ENOBUFS)` before `drm_suballoc_new()`. [F956]

## External Contracts
- Teardown callbacks such as `xe_survivability_mode_fini()` must only clean up kernel-created sysfs/driver state and never mutate user-controlled configfs attributes outside `.store()`. [F853]
- In `xe_query_ioctl()`, `query->extensions` and `query->reserved` must be 0, `query->query` must be bounds-checked and sanitized with `array_index_nospec()`, and every `xe_query_funcs` handler must write the expected size and return 0 when `query->size == 0` or reject `query->size != size` with `-EINVAL`. [F858, F940]
- Memory region bitmasks (`xe->info.mem_region_mask`, `near_mem_regions`, `far_mem_regions`) must use bit 0 for SYSMEM and `BIT(vram->id) << 1` for VRAM to match `mem_regions[].instance` in `query_mem_regions()`; `query_mem_regions()` must shift `XE_PL_TT`'s `man->size` by `PAGE_SHIFT` (VRAM `man->size` is already in bytes) and populate `used` and `cpu_visible_used` unconditionally without `perfmon_capable()`. [F855, F943, F944]
- In `xe_sync_entry_parse()`, `DRM_XE_SYNC_TYPE_SYNCOBJ` and `TIMELINE_SYNCOBJ` must reject non-zero `upper_32_bits(sync_in.addr)` with `-EINVAL`, and `USER_FENCE` must reject unaligned `sync_in.addr & 0x7` with `-EINVAL`. [F860]

## Known Pitfalls
- In `xe_pt_stage_bind_entry()`, when descending from level 1 to level 0, `walk->shifts` must be reset to `xe_normal_pt_shifts` (and `xe_walk->l0_end_addr` set to `next`) before checking if the L0 child can use `xe_compact_pt_shifts`. All page-table shift calculations using `walk->shifts[level]` or `xe_pt_shift(level)` must use 64-bit `1ull << shift` (shifts reach 39 and 48). [F835, F884]
- In `get_ccs_bb_pool_size()`, computing `ccs_mem_size` and `ptes` from 64-bit `sys_mem_size` must use `div64_u64()` and `DIV_ROUND_UP_ULL(..., XE_PAGE_SIZE)` before multiplying by `sizeof(u32)`. [F888]
- `xe_sched_job_started()` and `xe_sched_job_completed()` must compare 32-bit LRC seqnos via `!__dma_fence_is_later(dma_fence_chain_contained(job->fence), xe_sched_job_lrc_seqno(job), ...)` rather than `<=` or `>=`. [F889]
- In `query_oa_units()`, each `struct drm_xe_oa_unit` has a variable-length trailing `du->eci[du->num_engines]` array, so iteration must advance a byte pointer by `sizeof(*du) + j * sizeof(du->eci[0])` rather than indexing `qoa->oa_units[]`. [F899]
