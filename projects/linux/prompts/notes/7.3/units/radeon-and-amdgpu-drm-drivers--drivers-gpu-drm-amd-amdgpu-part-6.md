# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 6)

Core AMDGPU infrastructure covering TTM memory management, GPU command rings and software ring multiplexing, fence synchronization (`amdgpu_sync`, `amdgpu_seq64`), GPU reset domains, firmware parsing (`amdgpu_ucode`), RAS EEPROM/UMC retirement, RLC/SDMA helpers, and Secure Display debugfs.

## Architecture & Data Flow

- In `amdgpu_ring`, `ring_size` is a power-of-two byte count (`extra_bytes` is added only to `ring_obj` allocation size, never `ring_size` or `buf_mask`), while `wptr`, `rptr`, `max_dw`, `count_dw`, and `buf_mask` (`(ring_size / 4) - 1`) are DWords. DWord emitters (`amdgpu_ring_write`, `amdgpu_ring_write_multiple`, `amdgpu_ring_insert_nop`) must index `ring->ring[]` with `wptr & buf_mask` (using `ptr_mask` overflows when `support_64bit_ptrs` is true), mask `wptr` with `ptr_mask`, and decrement `count_dw`. [F1103, F1119, F1120]
- Writeback offsets from `amdgpu_device_wb_get` (`rptr_offs`, `wptr_offs`, `fence_offs`, `trail_fence_offs`, `cond_exe_offs`) are DWord indices: `amdgpu_ring_get_gpu_addr` multiplies `offset` by 4, while `amdgpu_ring_get_cpu_addr` indexes `uint32_t` `adev->wb.wb[offset]` directly. In `amdgpu_ring_to_mqd_prop()`, `prop->hqd_active` must be `true` only for `AMDGPU_RING_TYPE_KIQ`. [F1162, F1183]
- In `amdgpu_ring_mux_start_ib()`, `chunk` offsets (`cntl_offset`, `de_offset`, `ce_offset`) are initialized to `ring->buf_mask + 1`, so `amdgpu_mux_resubmit_chunks()` must check `<= e->ring->buf_mask` before calling `amdgpu_ring_patch_*`. Under `mux->lock`, `amdgpu_mux_resubmit_chunks` must set `mux->wptr_resubmit = chunk->end` per chunk, delete `mux->resubmit_timer`, and clear `mux->s_resubmit = false`; in `amdgpu_ring_mux_set_wptr`, low-priority rings (`hw_prio <= AMDGPU_RING_PRIO_DEFAULT`) must clamp `e->sw_cptr` up to `mux->wptr_resubmit` and skip copying when `mux->wptr_resubmit >= wptr`. [F1086, F1105, F1106]
- `struct ttm_tt ttm` must be the first member of `struct amdgpu_ttm_tt` at offset 0 for direct `(void *)` casts. In `amdgpu_ttm_backend_unbind`, userptr unpinning (`amdgpu_ttm_tt_unpin_userptr`) and imported DMA-buf unmapping (`dma_buf_unmap_attachment`, `ttm->sg = NULL`) must run before returning on `!gtt->bound` or `gtt->offset == AMDGPU_BO_INVALID_OFFSET`. [F1110, F1168]
- `amdgpu_res_cursor` stores byte-addressed `drm_buddy_block *` for `TTM_PL_VRAM` and page-addressed `drm_mm_node *` (`<< PAGE_SHIFT` in `amdgpu_res_first`/`next`) for `TTM_PL_TT`, `AMDGPU_PL_DOORBELL`, and `AMDGPU_PL_MMIO_REMAP`; never pass `AMDGPU_PL_PREEMPT` to `to_ttm_range_mgr_node` or `amdgpu_gtt_mgr_has_gart_addr`. [F1166]
- In `amdgpu_bo_move`, direct `TTM_PL_SYSTEM` <-> `TTM_PL_VRAM` moves when `buffer_funcs_enabled` is true must set `hop` to `TTM_PL_TT` and return `-EMULTIHOP` before `amdgpu_bo_move_notify` or `amdgpu_move_blit`. In `amdgpu_ttm_map_buffer`, IB size is `num_dw * 4 + num_bytes` (`num_dw = ALIGN(copy_num_dw, 8)`), with inline PTEs at `job->ibs[0].gpu_addr + num_dw * 4` and `&job->ibs[0].ptr[num_dw]` after `amdgpu_ring_pad_ib`. [F1142, F1169]
- In `amdgpu_ras_eeprom.c`, I2C buffers and offsets must step by `RAS_TABLE_RECORD_SIZE` (24) via `__encode_table_record_to_buf`/`__decode_table_record_from_buf`, never `sizeof(struct eeprom_table_record)`. Relative indices off `ras_fri` map via `RAS_RI_TO_AI` modulo `ras_max_record_count` (splitting multi-record I2C transfers at index 0), and `amdgpu_ras_eeprom_append_table` must compute `(b + ras_max_record_count - ras_fri) % ras_max_record_count` when updating `ras_num_recs`. [F1114, F1116, F1154]
- EEPROM record flags (`UMC_CHANNEL_IDX_V2`, `UMC_NPS_SHIFT`) must fit in bits 0..47 of `retired_page`/`offset`, and `amdgpu_ras_eeprom_append` must clear `~(nps << UMC_NPS_SHIFT)` from every `record[i].retired_page` before returning on all paths. [F1054, F1115]
- Updating `control->ras_num_recs` in `amdgpu_ras_eeprom_append` or `amdgpu_ras_eeprom_reset_table` requires updating `tbl_hdr` (`tbl_size`, `checksum`, `tbl_rai`) and `amdgpu_ras_debugfs_set_ret_size` under `ras_tbl_mutex`; `reset_table` must also zero `ras_num_recs`, `ras_num_bad_pages`, `ras_num_mca_recs`, `ras_num_pa_recs`, `ras_fri`, `bad_channel_bitmap`, and `con->update_channel_flag`, and notify SMU via `amdgpu_dpm_send_hbm_bad_pages_num` and `amdgpu_dpm_send_hbm_bad_channel_flag`. [F1099, F1100]
- In `amdgpu_ras_eeprom_append_table` and `amdgpu_ras_eeprom_read`, check `record[i].mem_channel < BITS_PER_TYPE(control->bad_channel_bitmap)` before `1 << record[i].mem_channel`; setting a new bit must set `con->update_channel_flag = true`, which `amdgpu_umc_handle_bad_pages` clears after calling `amdgpu_dpm_send_hbm_bad_channel_flag`. [F1101, F1150]
- `adev->umc.active_mask` is an `unsigned long` (`node_inst_num * umc_inst_num <= BITS_PER_LONG`): when `adev->aid_mask` is non-zero, it is a flat `node_inst_num * umc_inst_num` bitmap iterated with `amdgpu_umc_loop_all_aid` (div/mod `umc_inst_num`); when `aid_mask` is 0, it is a `node_inst_num` bitmap iterated with `LOOP_UMC_NODE_INST`. [F1128, F1170]
- In `amdgpu_sync_test_fence`, owner checks for `AMDGPU_FENCE_OWNER_UNDEFINED`, `KFD`, and `VM` must precede `switch (mode)`. In `amdgpu_seq64_alloc`, `bit_pos` from `adev->seq64.used` is scaled by `sizeof(u64)` for byte addresses (`va`, `gpu_addr`), but added unscaled to `u64 *` `cpu_base_addr`. [F1132, F1165]
- In `struct gfx_firmware_header_v1_0`, `jt_offset` and `jt_size` are DWords: byte calculations in `amdgpu_ucode_init_single_fw`, `amdgpu_ucode_patch_jt`, and `amdgpu_ucode_init_bo` must multiply by 4, while `__le32 *` indexing in `amdgpu_gfx_rlc_setup_cp_table` must not. `amdgpu_gfx_rlc_enter/exit_safe_mode()` must verify `rlc.funcs->is_rlc_enabled(adev)` and `AMD_CG_SUPPORT_GFX_{CGCG,MGCG,3D_CGCG}` in `adev->cg_flags` before calling `set/unset_safe_mode`. [F1126, F1190]
- `amdgpu_reset_xgmi_reset_on_init_suspend()` must suspend valid/hw IP blocks (except `AMD_IP_BLOCK_TYPE_DCE`) in reverse order from `num_ip_blocks - 1` down to 0, then call `amdgpu_vcn_save_vcpu_bo(adev)`. [F1176]

## Synchronization

- `amdgpu_device_lock_reset_domain` must set `in_gpu_reset = 1` before `down_write(&reset_domain->sem)`, and `unlock_reset_domain` must clear `in_gpu_reset = 0` before `up_write`. Callers of `amdgpu_reset_pending(domain)` must hold `domain->sem`. [F1061, F1062]
- `__amdgpu_ras_eeprom_write()`, `__amdgpu_ras_eeprom_read()`, `amdgpu_ras_eeprom_append_table()`, and `amdgpu_ras_eeprom_update_header()` require `control->ras_tbl_mutex` and take `down_read(&adev->reset_domain->sem)` inside it (lock order: `ras_tbl_mutex` -> `reset_domain->sem`). [F1194]
- `amdgpu_ring_mux_copy_pkt_from_sw_ring`, `amdgpu_mux_resubmit_chunks`, `amdgpu_ring_mux_set_wptr`, and `amdgpu_mcbp_trigger_preempt` must hold `mux->lock`. Because process context uses `spin_lock(&mux->lock)`, timer callback `amdgpu_mux_resubmit_fallback` must use `spin_trylock(&mux->lock)` and reschedule `resubmit_timer` via `amdgpu_ring_mux_schedule_resubmit` on contention. [F1068, F1069]
- In `amdgpu_bo_move`, moving from `TTM_PL_TT` or `AMDGPU_PL_PREEMPT` to `TTM_PL_SYSTEM` requires `ttm_bo_wait_ctx(bo, ctx)` to succeed before `amdgpu_ttm_backend_unbind` and `ttm_resource_free`. `amdgpu_ttm_bo_eviction_valuable()` must return `false` for `AMDGPU_PL_PREEMPT`. [F1072, F1202]
- `amdgpu_sync_resv()` requires the caller to hold the `dma_resv` lock (`dma_resv_for_each_fence()`); unlocked walks must use `dma_resv_for_each_fence_unlocked()` as in `amdgpu_sync_kfd()`. In `amdgpu_securedisplay_debugfs_write`, `psp_prep_securedisplay_cmd_buf`, `psp_securedisplay_invoke`, and reading `securedisplay_cmd` outputs must be held under `psp->securedisplay_context.mutex`. [F1078, F1197]

## Object Lifetimes

- `amdgpu_ttm_tt_unpopulate` must clear `ttm->pages[i]->mapping = NULL` before returning pages to the same pool (`adev->mman.ttm_pools[gtt->pool_id]` or `&adev->mman.bdev.pool`) used by `amdgpu_ttm_tt_populate`. `amdgpu_ttm_tt_set_userptr` stores refcounted `current->group_leader` in `gtt->usertask` (freed via `put_task_struct` in `amdgpu_ttm_backend_destroy`), and `amdgpu_ttm_tt_get_usermm` must read `gtt->usertask->mm`, not `current->mm`. [F1048, F1209]
- In `amdgpu_sync_resv`, when `amdgpu_sync_test_fence` matches `tmp` inside `dma_fence_chain_for_each(f, f)`, it must sync to chain node `f`, call `dma_fence_put(f)`, and `break`. In `amdgpu_seq64_map`, if `amdgpu_vm_bo_map` or `amdgpu_vm_bo_update` fails after `amdgpu_vm_bo_add`, call `amdgpu_vm_bo_del(adev, *bo_va)` before `drm_exec_fini(&exec)`. [F1053, F1133]
- Helpers using `amdgpu_bo_create_reserved` (`amdgpu_gfx_rlc_init_sr`, `amdgpu_gfx_rlc_init_cpt`) must call `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` before returning 0. In `amdgpu_gfx_rlc_init_microcode_v2_0`, `register_restore` is an interior pointer into `register_list_format` (`reg_list_format_size_bytes + reg_list_size_bytes`) and must never be passed to `kfree`. [F1056, F1163]
- `amdgpu_sdma_init_microcode` with `duplicate == true` shallow-copies `instance[0].fw` to `instance[1..num_instances-1]`, so `amdgpu_sdma_destroy_inst_ctx` must also pass `duplicate == true`. If `amdgpu_irq_get` fails after `amdgpu_ras_block_late_init` in `amdgpu_sdma_ras_late_init` or `amdgpu_umc_ras_late_init`, call `amdgpu_ras_block_late_fini`. [F1051, F1058]

## API Contracts

- `amdgpu_sync_peek_fence` returns a borrowed `dma_fence *`, whereas `amdgpu_sync_get_fence` returns a reference that callers must release with `dma_fence_put`. In `amdgpu_sync.c`, verify `to_drm_sched_fence(f)` or `to_amdgpu_amdkfd_fence(f)` before downcasting, and in `amdgpu_sync_add_later`, check `e->fence->context == f->context` before calling `amdgpu_sync_keep_later`. [F1043, F1156, F1171]
- Callers of `amdgpu_ring_alloc` must pair it with `amdgpu_ring_commit` or `amdgpu_ring_undo` (which restores `wptr_old` and calls `end_use`). `amdgpu_seq64_free()` expects the process `*va` from `amdgpu_seq64_alloc()`, not `*gpu_addr`. [F1090, F1102]
- `amdgpu_evict_flags` and `amdgpu_ttm_bo_eviction_valuable` must check `amdgpu_bo_is_amdgpu_bo(bo)` before `ttm_to_amdgpu_bo(bo)`. Before `ttm_bo_move_memcpy` in `amdgpu_bo_move`, both resources must satisfy `amdgpu_res_copyable` (requiring `TTM_PL_FLAG_CONTIGUOUS` and `amdgpu_res_cpu_visible` for VRAM). In `amdgpu_ttm_alloc_gart()`, call `amdgpu_gart_invalidate_tlb(adev)` after `amdgpu_ttm_gart_bind()`. [F1167, F1205, F1211]
- `amdgpu_ttm_tt_set_userptr` must call `amdgpu_ttm_tt_create(bo, 0)` before setting `TTM_TT_FLAG_EXTERNAL` on `page_flags` so `ttm->pages` is allocated. `amdgpu_ttm_tt_unpin_userptr()` must guard on `ttm->sg && ttm->sg->sgl` and derive `direction` from `AMDGPU_GEM_USERPTR_READONLY` matching `pin_userptr`. `amdgpu_ttm_access_memory()` returns positive bytes transferred on success, whereas `amdgpu_ttm_access_memory_sdma()` returns 0. [F1095, F1206, F1207]
- `__verify_ras_table_checksum()` returns 0 when valid, `1..255` on mismatch, and `-errno` on failure; do not check `res < 0` alone. `amdgpu_umc_fill_error_record()` right-shifts byte address `retired_page` by `AMDGPU_GPU_PAGE_SHIFT` into `err_rec->retired_page`, while storing `err_addr` unshifted. In `amdgpu_ucode.c`, `fw_attrs` `.show` callbacks must check `if (!buf)` first and return `amdgpu_ucode_is_valid(...)` for `amdgpu_ucode_sys_visible()`. [F1081, F1084, F1096]

## Error Handling

- `amdgpu_ucode_request()` remaps firmware request errors to `-ENODEV` and returns `-EINVAL` on `amdgpu_ucode_validate()` failure without calling `release_firmware(*fw)` because callers always call `amdgpu_ucode_release()`. [F1097]

## External Contracts

- In `amdgpu_ras_eeprom.c`, `tbl_hdr_fmt_size` and `rec_hdr_fmt_size` must match `tbl_hdr_fmt` and `rec_hdr_fmt` byte lengths, and `record.err_type` must be `< AMDGPU_RAS_EEPROM_ERR_COUNT` when indexing `record_err_type_str`. `amdgpu_debugfs_ring_read`, `amdgpu_debugfs_virt_ring_read`, and `amdgpu_ttm_vram_read/write` require 4-byte aligned `*pos` and `size`, with `ring_read` placing `rptr`, `wptr`, and driver `wptr` in the first 12 bytes. [F1117, F1125]

## Known Pitfalls

- Any `sync->fences` walk that removes entries via `amdgpu_sync_entry_free` or `hash_del` (`amdgpu_sync_peek_fence`, `clone`, `push_to_job`) must use `hash_for_each_safe`. Ring wrap-around calculations in `amdgpu_ring_patch_cond_exec`, `amdgpu_ring_mux_copy_pkt_from_sw_ring`, and `amdgpu_ring_mux_get_rptr` must add `ring->ring_size >> 2` (DWords), not `ring->ring_size` (bytes). [F1134, F1155]
- Cast `page_offset`, `ttm->num_pages`, and `ttm_resource.start` to `u64` before `<< PAGE_SHIFT` in `amdgpu_ttm_io_mem_pfn`, `pin_userptr`, `backend_bind`, and `alloc_gart`; widen `nps` to `uint64_t` before `<< UMC_NPS_SHIFT` (40) or `58` in `amdgpu_ras_eeprom_append` and `amdgpu_umc_pa2mca`; truncate `-csum` through `u8 csum` before assigning to `uint32_t` `checksum` in RAS EEPROM header helpers; reset intra-record offset `r = 0` after the first iteration in `amdgpu_ras_debugfs_table_read`. [F1137, F1144, F1147, F1149]
- `amdgpu_iomem_read/write()` must check `pfn_valid(pfn)` and `p->mapping == adev->mman.bdev.dev_mapping` before `kmap_local_page()`, and call `kunmap_local(ptr)` before returning on `copy_to/from_user()` failure. [F1201]

## Other

- In `amdgpu_ttm_vram_mm_access()`, `amdgpu_device_mm_access()` requires `ALIGN_DOWN(pos, 4)` and 4-byte widths, using read-modify-write for unaligned `pos`/`size`; `0xffffffff >> (bytes - size) * 8` is only safe under `while (size)` and `if (size < bytes)` (`1 <= bytes - size <= 3`). [F1157, F1185]
