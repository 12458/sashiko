# NETWORKING [MPTCP] — (top level)

Implements Multipath TCP (MPTCP v1, RFC 8684) for IPv4/IPv6, multiplexing a user-facing `struct mptcp_sock` across TCP subflow sockets via TCP ULP hooks, with option parsing/generation, SHA-256/HMAC handshakes, DSN mapping/retransmission, pluggable schedulers, and kernel/userspace Path Managers (PM).

## Architecture & Data Flow

- Closed initial subflow `msk->first` stays on `msk->conn_list`, while `__mptcp_close_ssk()` unlinks `subflow->node` when `msk->free_first || ssk != msk->first`. Gate one-shot accounting in `mptcp_close_ssk()` on `subflow->close_event_done`, skip `TCPF_FIN_WAIT1 | TCPF_FIN_WAIT2 | TCPF_CLOSING | TCPF_CLOSE` in `mptcp_pm_rm_addr_or_subflow()`, and use `mptcp_for_each_subflow_safe()` when calling `mptcp_close_ssk()` / `__mptcp_close_ssk()`. [F8, F98]
- `__mark_subflow_endp_available()` and `mptcp_pm_nl_rm_addr()` do not decrement `msk->pm.local_addr_used` or `add_addr_accepted` for ID 0, so kernel PM subflow creation must not increment `local_addr_used` when `local.addr.id == msk->mpc_endpoint_id` or `add_addr_accepted` when `remote.id == 0`. Run `__clear_bit(local.addr.id, msk->pm.id_avail_bitmap)` right after `select_local_address()` before any `continue`. [F9, F106]
- When `mptcp_pm_add_addr_c_flag_case(msk)` is true, `mptcp_pm_add_addr_received()` schedules `MPTCP_PM_ADD_ADDR_RECEIVED` for `addr->id > 0` even if `!READ_ONCE(pm->accept_addr)`, and `fill_local_addresses_vec()` pairs `MPTCP_PM_ADDR_FLAG_SUBFLOW` endpoints while clearing `id_avail_bitmap` and incrementing `local_addr_used`. In `check_fully_established()`, store `mp_opt->deny_join_id0` into `msk->pm.remote_deny_join_id0` after `set_fully_established:` so TFO (`subflow->is_mptfo && mp_opt->suboptions & OPTION_MPTCP_MPC_ACK`) records the peer's C-flag. [F92, F95]
- Size address ID bitmaps (`pm_nl_pernet::id_bitmap`, `mptcp_pm_data::id_avail_bitmap`, `unavail_id`, `id_bitmap` in `mptcp_userspace_pm_dump_addr()`) to `MPTCP_PM_MAX_ADDR_ID + 1` (256 bits), and convert `subflow->local_id` (`s16`, init `-1`) via `subflow_get_local_id()` before indexing. Mutating `pernet->endp_list` under `pernet->lock` must update `endp_{signal,subflow,laminar}_max`, `endpoints`, and `id_bitmap` in lockstep, while `__reset_counters()` on flush must preserve `limit_add_addr_accepted` and `limit_extra_subflows`. [F56, F82]
- `msk->first_pending` tracks the first unsent `mptcp_data_frag` in `msk->rtx_queue`. In `__mptcp_clean_una()`, if `dfrag == msk->first_pending` during `msk->recovery`, advance `msk->first_pending` before `dfrag_clear()`, and if `delta` (`snd_una - dfrag->data_seq`) exceeds `dfrag->already_sent`, clamp `dfrag->already_sent` up to `delta` (after `delta <= dfrag->data_len`) before subtracting `delta`. `__mptcp_retransmit_pending_data()` must reset `first_pending` and zero `already_sent`. [F62, F85]
- Zero newly attached `SKB_EXT_MPTCP` (`struct mptcp_ext`) via `memset(mpext, 0, sizeof(*mpext))` because `mptcp_ext_matches()` uses `memcmp()`. `mptcp_skb_ext_copy()` sets `from_ext->frozen = 1`; `mptcp_sendmsg_frag()` must check `mptcp_skb_can_collapse_to()` (`!mpext->frozen`), set `TCP_SKB_CB(skb)->eor = 1` when disallowing collapse, and clamp `ssk->sk_gso_max_size` to `MPTCP_MAX_GSO_SIZE` before `tcp_send_mss()` so `size_goal` fits in `u16 data_len`. [F122, F160, F163]
- `mptcp_data_queue_ofo()` must set `msk->ooo_last_skb = skb` when inserting into an empty `msk->out_of_order_queue` or when `skb_rb_next(skb)` is `NULL`. In `__mptcp_ofo_queue()`, advance `p = rb_next(p)` before `rb_erase(&skb->rbnode, &msk->out_of_order_queue)`. `__mptcp_try_coalesce()` must reject coalescing when `MPTCP_SKB_CB(to)->cant_coalesce` is set (required on TFO data SKBs in `mptcp_fastopen_subflow_synack_set_params()`), `MPTCP_SKB_CB(from)->offset != 0`, or `to->len + from->len > (READ_ONCE(sk->sk_rcvbuf) >> 3)`. [F61, F100, F158]
- Because `opts->addr` and `opts->ahmac` alias `opts->ext_copy` in `struct mptcp_out_options`, `mptcp_established_options_add_addr()` must stage into a local `struct mptcp_addr_info` and write `opts->addr` (zeroing `opts->ahmac` if `drop_other_suboptions`) only after confirming `OPTION_MPTCP_ADD_ADDR` fits. `MPTCPOPT_RM_ADDR` in `mptcp_parse_option()` and `mptcp_rm_addr_len()` requires `rm_list.nr` in `[1, MPTCP_RM_IDS_MAX]`. [F57, F77]
- Use `mptcp_set_state(sk, state)` (not `inet_sk_state_store()`) on locked MPTCP sockets to maintain `MPTCP_MIB_CURRESTAB`. Call `mptcp_shutdown_subflows(msk)` when `mptcp_check_data_fin_ack()` or `mptcp_check_data_fin()` enters `TCP_CLOSE`. In `mptcp_subflow_shutdown()`, `case TCP_LISTEN:` breaks if `!(how & RCV_SHUTDOWN)` and else falls through to `case TCP_SYN_SENT:` (`tcp_disconnect(ssk, O_NONBLOCK)`). [F54, F72, F97]
- `mptcp_disconnect()` zeroing `msk->flags` under `msk->fallback_lock` must restore `msk->allow_subflows = true` and `msk->allow_infinite_fallback = true`; when `mptcp_sendmsg_fastopen()` calls `mptcp_disconnect(sk, 0)` directly and gets 0, it must increment `sk->sk_disconnects` and set `sk->sk_socket->state = SS_UNCONNECTED`. [F53, F59]
- In `struct mptcp_subflow_context`, place transient per-connection fields inside `struct_group(reset, ...)` and persistent pointers/callbacks/list nodes outside it for `mptcp_subflow_ctx_reset()`. `mptcp_pm_data_reset()` sets `pm->work_pending = true` only when `pm->pm_type == MPTCP_PM_TYPE_KERNEL`, clearing `reset` and `rm_list_{tx,rx}.nr` while preserving `pm->lock`, `anno_list`, and `userspace_pm_local_addr_list`. [F65, F66]
- `mptcp_set_rwin()` must update `WRITE_ONCE(msk->old_wspace, tp->rcv_wnd)` on all exit paths. `mptcp_epollin_ready()` must return `false` when `mptcp_data_avail(mptcp_sk(sk)) == 0` before checking `sk_rcvlowat` or `tcp_under_memory_pressure(sk)`. Clear `subflow->mpc_drop = 0` in `mptcp_active_detect_blackhole()` if `!subflow->request_mptcp` on `TCP_SYN_SENT`; `mptcp_active_enable()` resets `pernet->active_disable_times = 0` only when `!(dev && (dev->flags & IFF_LOOPBACK))`. [F55, F58, F90, F91]
- `__mptcp_expand_seq()` adjusts `(1LL << 32)` when `before(old_seq32, cur_seq32)` or `after(old_seq32, cur_seq32)` disagrees with `u32` ordering. `icsk_mtup.probe_timestamp` stores non-zero `tcp_jiffies32` (`tout ? : 1` in `mptcp_set_close_tout()`), compared via `time_after32()` in `mptcp_close_tout_expired()` and rebased (`- tcp_jiffies32 + jiffies`) in `mptcp_reset_tout_timer()`. [F112, F121]
- Fallback child sockets in `mptcp_stream_accept()` where `!sk_is_mptcp(newsk)` are `struct tcp_sock` and require `newsock->sk->sk_socket->ops = mptcp_fallback_tcp_ops(newsock->sk)`. `struct mptcp6_sock` places `struct mptcp_sock msk` before `struct ipv6_pinfo np`, and `mptcp_sk_clone_init()` must set `inet_sk(nsk)->pinet6 = mptcp_inet6_sk(nsk)`. In `mptcp_diag_dump()`, decrement `diag_ctx->s_num` on `sk_diag_dump() < 0` before breaking. [F105, F128, F129]

## Synchronization

- PM helpers entered under `msk->pm.lock` (`mptcp_pm_send_ack()`, `mptcp_pm_rm_addr_or_subflow()`, `mptcp_pm_create_subflow_or_signal_addr()`, `mptcp_pm_nl_add_addr_received()`) must `spin_unlock_bh(&msk->pm.lock)` before locking/connecting/shutting down/closing `ssk` and re-lock before returning. Hold `lock_sock(sk)` on `msk` before calling `mptcp_pm_addr_send_ack()`, `mptcp_pm_remove_addr()`, `mptcp_pm_remove_anno_addr()`, `mptcp_pm_remove_addr_entry()`, or `mptcp_pm_rm_subflow()`. Hold `spin_lock_bh(&msk->pm.lock)` across any lookup-and-modify/unlink on `msk->pm.userspace_pm_local_addr_list`. [F17, F24, F25]
- Hold `spin_lock_bh(&msk->fallback_lock)` in `__mptcp_finish_join()`, `mptcp_finish_join()`, `__mptcp_retrans()`, `mptcp_pm_mp_fail_received()`, and `__mptcp_try_fallback()` across checking/updating `msk->allow_subflows`, `msk->allow_infinite_fallback`, and `MPTCP_FALLBACK_DONE`. In `check_fully_established()`, do not call `mptcp_pm_subflow_established()` or `mptcp_pm_fully_established()` while `list_empty(&subflow->node)`. [F21, F31]
- Atomic/BH rules: `mptcp_subflow_delegate()` requires softirq/BH-disabled context (`local_bh_disable()` in process context or direct `subflow->delegated_status` update when `sock_owned_by_user(sk)`). `__MPTCP_INC_STATS()` requires BHs disabled. `mptcp_try_fallback()` must override `ssk->sk_allocation = GFP_ATOMIC` around `tcp_shutdown(ssk, SEND_SHUTDOWN)` when `snd_data_fin_enable` is set. Callers of `mptcp_sendmsg_frag()` holding `mptcp_data_lock(sk)` or `msk->fallback_lock` must set `info.data_lock_held = true`. [F135, F136, F137, F139]
- RCU & fastopen: `mptcp_sched_find()` and `mptcp_pm_find()` require `rcu_read_lock()` (held across `mptcp_init_sched()` until `bpf_try_module_get()`). `mptcp_active_enable()` must use `rcu_read_lock()`, `__sk_dst_get(sk)`, and `dst_dev_rcu(dst)`. `subflow_get_info()` needs `lock_sock_fast(sk)` + `rcu_read_lock()` + `rcu_dereference(inet_csk(sk)->icsk_ulp_data)`, and `mptcp_diag_dump_listeners()` must pin `ctx->conn` with `refcount_inc_not_zero(&sk->sk_refcnt)` under `rcu_read_lock()` and `ilb->lock`. When `msk->fastopening` is set by `mptcp_sendmsg_fastopen()`, `mptcp_connect()` skips `lock_sock(ssk)` and `mptcp_disconnect()` returns `-EBUSY`. [F143, F145, F147, F148]
- Barriers: `mptcp_active_disable()` pairs `WRITE_ONCE(pernet->active_disable_stamp, ...)` + `smp_mb__before_atomic()` + `atomic_inc(&pernet->active_disable_times)` with `atomic_read()` + `smp_rmb()` + `READ_ONCE()` in `mptcp_active_should_disable()`. `__mptcp_subflow_error_report()` pairs `WRITE_ONCE(sk->sk_err, -err)` + `smp_wmb()` before `sk_error_report(sk)` with `smp_rmb()` before `READ_ONCE(sk->sk_err)` in `mptcp_poll()`. [F32, F33]

## Object Lifetimes

- Release `struct mptcp_sock *` from `mptcp_userspace_pm_get_sock()` and `mptcp_token_get_sock()` via `sock_put((struct sock *)msk)` on all exit paths. `mptcp_schedule_work(sk)` calls `sock_hold(sk)` when `schedule_work(&msk->work)` succeeds, balanced by `sock_put(sk)` in `mptcp_worker()` or `__sock_put(sk)` in `mptcp_cancel_work()` when `cancel_work_sync()` returns `true`. [F1, F11]
- Read needed `subflow` or `ssk` fields before calling `mptcp_close_ssk()` or `__mptcp_close_ssk()`, which may free `subflow` and `sock_put(ssk)`. Only `mptcp_napi_poll()` may dequeue `subflow` via `mptcp_subflow_delegated_next()`, clear `MPTCP_DELEGATE_SCHEDULED`, and drop the `sock_hold(ssk)` from `mptcp_subflow_delegate()`. [F6, F12]
- `mptcp_init_sched()` calls `bpf_try_module_get()` before setting `msk->sched` and calling `sched->init(msk)`; `mptcp_release_sched()` clears `msk->sched = NULL`, calls `sched->release(msk)` if defined, and calls `bpf_module_put()`. `dfrag_clear()` must unlink `dfrag->list`, `dfrag_uncharge()` `data_len + overhead`, and `put_page(dfrag->page)`. [F13, F14]
- `mptcp_skb_ext_move(to, from)` must `skb_ext_put(to)` if `to->active_extensions`, copy `extensions` and `active_extensions`, and zero `from->active_extensions = 0`. In `mptcp_incoming_options()`, zero-length packets (`seq == end_seq`) must process `DATA_FIN` and return before `skb_ext_add(skb, SKB_EXT_MPTCP)`. [F16, F162]
- Traverse `pernet->endp_list` with `list_for_each_entry_rcu()` under `rcu_read_lock()` or `pernet->lock`, and wait for `synchronize_rcu()` before `__mptcp_pm_release_addr_entry()` or `__flush_addrs()`. Atomic receive paths (`mptcp_pm_nl_get_local_id()`) must pass `replace = false` to `mptcp_pm_nl_append_new_local_addr()`, which frees `entry` internally on matching an implicit endpoint (`>= 0`) but leaves `entry` for the caller to free on `< 0`. Free `userspace_pm_local_addr_list` (`sock_kmemdup()`) entries with `sock_kfree_s()` or `kfree_rcu_mightsleep()` + `atomic_sub(..., &sk->sk_omem_alloc)`. Guard `kfree(table)` with `!net_eq(net, &init_net)` in `mptcp_pernet_new_table()` and call `unregister_net_sysctl_table()` before `kfree(table)` in `mptcp_pernet_del_table()`. [F20, F41, F131, F138, F146]

## API Contracts

- `mptcp_sk(sk)` requires an `IPPROTO_MPTCP` socket; `tcp_sk(sk)` and `mptcp_subflow_ctx(sk)` require an `IPPROTO_TCP` subflow socket (use `mptcp_sk(mptcp_subflow_ctx(sk)->conn)` for parent `msk`). Verify `sk_fullsock(sk)`, `sk->sk_protocol == IPPROTO_TCP`, and `sk_is_mptcp(sk)` (or `icsk_ulp_ops->name` `"mptcp"` on listeners) before downcasting arbitrary sockets. [F51, F126]
- `mptcp_pm_get_local_id()`, `mptcp_pm_nl_get_local_id()`, `mptcp_userspace_pm_get_local_id()`, `mptcp_pm_nl_append_new_local_addr()`, and `mptcp_userspace_pm_append_new_local_addr()` return `u8` ID (`>= 0`) or `< 0` error; store in signed `int`. `mptcp_subflow_delegate()` takes unshifted `MPTCP_DELEGATE_*`, while `mptcp_subflow_process_delegated()` takes `BIT(MPTCP_DELEGATE_*)`. `mptcp_napi_poll()` returns `budget` without `napi_complete_done()` when `++work_done == budget`, and calls `napi_complete_done(napi, 0)` when `work_done < budget`. [F40, F46, F108]
- `mptcp_crypto_hmac_sha()` requires a `SHA256_DIGEST_SIZE` (32B) output buffer. `mptcp_get_options()` only zeroes `mp_opt->status`, so `mptcp_parse_option()` must initialize all fields read for any set `suboptions` flag (`addr.port = 0`, `ahmac = 0`). [F47, F125]
- Sysctl handlers in `ctrl.c` must derive `struct mptcp_pernet` from `ctl->data` (matching hardcoded `table[0..11].data` indices in `mptcp_pernet_new_table()`, never `current->nsproxy->net_ns`), keep `pernet->path_manager` and `pernet->pm_type` in sync, and use `.mode = 0444` with unset `.data` for read-only entries. `struct mptcp_sched_ops` requires `.get_send`, while `.get_retrans`, `.init`, and `.release` are optional. [F130, F150, F151, F153, F154]

## Error Handling

- After `mptcp_alloc_tx_skb()` entails an `skb`, any early exit in `mptcp_sendmsg_frag()` before attaching payload bytes must call `tcp_remove_empty_skb(ssk)`. If subflow connect fails after `mptcp_token_new_connect(ssk)` in `mptcp_connect()`, call `mptcp_token_destroy(msk)` and `mptcp_set_state(sk, TCP_CLOSE)`. In `mptcp_incoming_options()`, return `false` if `skb_ext_add(skb, SKB_EXT_MPTCP)` returns `NULL` on a packet with payload. [F15, F19, F35]

## External Contracts

- `address_use_port()` is true only when `(entry->flags & (MPTCP_PM_ADDR_FLAG_SIGNAL | MPTCP_PM_ADDR_FLAG_SUBFLOW)) == MPTCP_PM_ADDR_FLAG_SIGNAL`, and `mptcp_pm_nl_append_new_local_addr()` zeroes `entry->addr.port` when false. `mptcp_pm_nl_add_addr_doit()` must reject `IMPLICIT`, `SIGNAL | FULLMESH`, and `addr.port` when `!address_use_port()`; `mptcp_pm_nl_set_flags()` must reject `FULLMESH` when `SIGNAL` or `IMPLICIT` is set. [F73, F74, F93]
- `MPTCP_PM_CMD_GET_ADDR` and `GET_LIMITS` omit `GENL_UNS_ADMIN_PERM`, mutating PM commands set it, and `MPTCP_PM_EV_GRP_NAME` sets `GENL_MCAST_CAP_NET_ADMIN` (regenerate `mptcp_pm.h` and `mptcp_pm_gen.{c,h}` from `mptcp_pm.yaml`). `subflow_get_info()` and `subflow_get_info_size()` gate sequence/offset attributes on `net_admin`. `mptcp_event_created()` sets `MPTCP_PM_EV_FLAG_DENY_JOIN_ID0` when `msk->pm.remote_deny_join_id0` is set. `__mptcp_make_csum()` always passes `cpu_to_be64(data_seq)` in `struct csum_pseudo_header`. [F60, F71, F113, F164, F165]

## Known Pitfalls

- `mptcp_addr_info::port` is `__be16`: convert `MPTCP_PM_ADDR_ATTR_PORT` (`NLA_U16`) with `htons()`/`ntohs()`, whereas `MPTCP_ATTR_SPORT`/`DPORT` use `nla_put_be16()`. In `mptcp_pm_nl_subflow_destroy_doit()`, when `addr_r.family == AF_INET && ipv6_addr_v4mapped(&addr_l.addr.addr6)`, pass `&addr_r.addr6` to `ipv6_addr_set_v4mapped()`. [F84, F109]
- In `mptcp_write_options()`, `__be32 *ptr` advances in 4-byte words (`+ 1` per 4B, `+ 2` per 8B, `+ 4` per IPv6, `+ 5` for `MPTCPOPT_HMAC_LEN`). In `mptcp_diag_dump_listeners()`, cursor `sk` is reassigned in-place from the listening TCP subflow to `sk = ctx->conn` before netns/family/refcount checks. Bound backoff shifts (`disable_times != 0` and `min(disable_times - 1, 6)`, clamp `icsk_retransmits` to `ilog2(TCP_RTO_MAX / TCP_RTO_MIN)`, `retrans_times < ADD_ADDR_RETRANS_MAX`) and break when `offs >= maxlen` after `snprintf()` in `mptcp_get_available_schedulers()` / `mptcp_pm_get_available()`. [F111, F117, F123, F133]
