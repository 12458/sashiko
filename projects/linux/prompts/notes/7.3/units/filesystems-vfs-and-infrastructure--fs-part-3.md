# FILESYSTEMS (VFS and infrastructure) — fs (part 3)

Provides VFS pathname resolution and directory operations (`fs/namei.c`), pseudo/in-memory filesystem helpers (`fs/libfs.c`), mount structures (`fs/mount.h`), multi-page BIO I/O (`fs/mpage.c`), and metadata block caching (`fs/mbcache.c`).

## Architecture & Data Flow

- `__set_nameidata()` copies `current->nameidata->total_link_count` to `p->total_link_count`; `restore_nameidata()` copies `now->total_link_count` back to `old->total_link_count`. In `link_path_walk()`, `nd->stack[...].name` and `!depth` at `OK:` must use local `depth`, not `nd->depth`. `terminate_walk()` drops `nd->root` and clears `ND_ROOT_GRABBED` while preserving `ND_ROOT_PRESET` across retries. [F82, F83, F120]
- In `acl_permission_check()`, `vfsuid_eq_kuid(vfsuid, current_fsuid())` precedes `IS_POSIXACL(inode)`, and `mask &= 7` follows `check_acl()`. In `generic_permission()`, `mask &= MAY_READ | MAY_WRITE | MAY_EXEC` precedes `mask == MAY_READ` (`CAP_DAC_READ_SEARCH`), and non-directory `CAP_DAC_OVERRIDE` requires `!(mask & MAY_EXEC) || (inode->i_mode & S_IXUGO)`. `alloc_anon_inode()` sets `i_mode = S_IRUSR | S_IWUSR` (no `S_IFMT`) and `S_ANON_INODE`. In `may_open()`, `S_IFBLK`/`S_IFCHR` fall through to `S_IFIFO`/`S_IFSOCK` to reject `MAY_EXEC` and clear `O_TRUNC` before `IS_APPEND(inode)`, and `default:` allows `IS_ANON_FILE(inode)`. [F116, F117, F121, F169]
- Under `CONFIG_DCACHE_WORD_ACCESS`, `full_name_hash()` mixes only full words with `HASH_MIX(x, y, a)` and XORs the final partial word via `x ^= a & bytemask_from_count(len)` before `fold_hash(x, y)` to match `hash_name()`. On `__BIG_ENDIAN`, `LAST_WORD_IS_DOT` and `LAST_WORD_IS_DOTDOT` are shifted to MSB (`0x2eul << (BITS_PER_LONG-8)` and `0x2e2eul << (BITS_PER_LONG-16)`). [F99, F100]
- In `dcache_dir_lseek()` and `dcache_readdir()`, offsets `0`/`1` are `.`/`..` and positive `d_children` start at `2`. `scan_positives()` skips `DCACHE_DENTRY_CURSOR` without decrementing `count`, and resets `count = 1` if `!--count == 0` on a dentry not `simple_positive(d)` under `d->d_lock`. When `dir_emit` returns false for `next`, `dcache_readdir()` uses `hlist_add_before(&cursor->d_sib, &next->d_sib)`, whereas `dcache_dir_lseek()` uses `hlist_add_behind(&cursor->d_sib, &to->d_sib)`. [F96, F107, F108]
- `simple_offset_add()` allocates in `[DIR_OFFSET_MIN, DIR_OFFSET_MAX]` (`3..S32_MAX-1`, `DIR_OFFSET_EOD = S32_MAX`), mapping `mtree_alloc_cyclic()`'s `-EBUSY` to `-ENOSPC` and returning `-EBUSY` only if `dentry2offset(dentry) != 0`. `offset_iterate_dir()` sets `ctx->pos = dentry2offset(dentry)` before `offset_dir_emit()`, and `DIR_OFFSET_EOD` only when lookup returns NULL. For `offset != DIR_OFFSET_FIRST`, `offset_dir_lookup()` searches downward via `mas_find_rev(&mas, DIR_OFFSET_MIN)`. [F45, F90, F109, F132]
- `simple_rename()` and `simple_rename_exchange()` must adjust parent `i_nlink` whenever a directory moves across parents without replacing another directory (including swapping a directory and non-directory across `old_dir != new_dir`). `generic_check_addressable()` checks `check_shl_overflow(num_blocks, blocksize_bits, &max_bytes)`, returns `0` if `num_blocks == 0`, and rejects `blocksize_bits < 9` before evaluating `(sector_t)(~0ULL) >> (blocksize_bits - 9)` or `last_fs_block` (`num_blocks - 1`). [F75, F127]
- `do_mpage_readpage()` and `mpage_write_folio()` require `i_blkbits >= 9`, `sector_t first_block` for `first_block << (blkbits - 9)`, contiguous mapped blocks from 0 with holes (`first_hole`/`first_unmapped`) only at the tail (else `goto confused`), and ceiling EOF block limit `(i_size + blocksize - 1) >> blkbits`. In `do_mpage_readpage()`, both block loops check extent end (`relative_block == last` or `nblocks`) before `page_block == blocks_per_folio` so `clear_buffer_mapped(map_bh)` runs when boundaries coincide. In `mpage_write_folio()`, `block_in_file >= (i_size + (1 << blkbits) - 1) >> blkbits` precedes `last_block = (i_size - 1) >> blkbits` to prevent `i_size == 0` underflow, and folios straddling `i_size` have their tail zeroed via `folio_zero_segment()`. [F80, F103, F114, F128, F129, F130, F178]
- In `mnt_notify_add()`, even when `m->to_notify` is skipped because neither `m->mnt_ns` nor `m->prev_ns` has `n_fsnotify_marks`, `m->prev_ns` must be updated to `m->mnt_ns`. `struct mount::mnt_pprev_for_sb` steals bit 0 for `WRITE_HOLD` (`1`), requires `__aligned(1)`, and must not be dereferenced while `WRITE_HOLD` is set. [F71, F138]

## Synchronization

- In `traverse_mounts()`, `__traverse_mounts()`, `lookup_one_positive_killable()`, `lookup_one_positive_unlocked()`, and `lookup_noperm_positive_unlocked()`, reading `d_flags` on a pinned dentry without parent `i_rwsem` or `d_lock` requires `smp_load_acquire(&dentry->d_flags)`. [F38]
- In `__follow_mount_rcu()` and `follow_dotdot_rcu()`, target `dentry->d_seq` must be sampled via `read_seqcount_begin()` before `read_seqretry(&mount_lock, nd->m_seq)` or `read_seqcount_retry(&old->d_seq, nd->seq)`. `path_init()` samples `nd->m_seq` and `nd->r_seq` before `smp_rmb()`, `handle_dots()` (`LAST_DOTDOT`) under `LOOKUP_IS_SCOPED` executes `smp_rmb()` and `__read_seqcount_retry` on both `mount_lock.seqcount` and `rename_lock.seqcount` after `step_into()` (returning `-EAGAIN` on retry), and `complete_walk()` keeps `nd->root.mnt` across `try_to_unlazy()` under `ND_ROOT_PRESET` or `LOOKUP_IS_SCOPED` and verifies `path_is_under(&nd->path, &nd->root)` under `LOOKUP_IS_SCOPED`. [F39, F40, F185]
- Under `LOOKUP_RCU`: `nd_alloc_stack()` uses `GFP_ATOMIC` (`GFP_KERNEL` otherwise) and `reserve_stack()` legitimizes `link` and calls `try_to_unlazy(nd)` before retrying on failure; `may_lookup()` passes `MAY_NOT_BLOCK` to `inode_permission()`, and `check_acl()` uses `get_cached_acl_rcu()` returning `-ECHILD` if `is_uncached_acl(acl)`; `pick_link()` passes `dentry = NULL` to `i_op->get_link`, and `__page_get_link()` uses `filemap_get_folio()` returning `ERR_PTR(-ECHILD)` if missing/non-uptodate when `dentry == NULL`. [F146, F147, F148]
- In `vfs_rename()`, with parents locked via `lock_rename()`, any directory `source` or `target` requiring locking must be locked before any non-directory `source` or `target`, and two non-directories must be locked via `lock_two_nondirectories(source, target)`. [F43]
- Before `scan_positives()` drops `dentry->d_lock` for `cond_resched()`, it moves `cursor->d_sib` behind `d->d_sib` and rebinds `p = &cursor->d_sib.next`, skipping `DCACHE_DENTRY_CURSOR`. In `offset_dir_lookup()` (`offset != DIR_OFFSET_FIRST`), `mas_find_rev()` and `find_positive_dentry(parent, child, false)` both run inside `rcu_read_lock()` / `rcu_read_unlock()`, with directory `i_rwsem` held by `offset_readdir()`. [F72, F163]
- `generic_ci_d_compare()` runs in RCU-walk context: it reads `dentry->d_parent` and `parent->d_inode` with `READ_ONCE()`, copies inline `d_shortname.string` to a stack buffer with `barrier()`, and never allocates with `GFP_KERNEL`. [F164]
- Bit 0 of `inode->i_version` is `I_VERSION_QUERIED`: `inode_maybe_inc_iversion()` clears it and adds `I_VERSION_INCREMENT` (`1ULL << I_VERSION_QUERIED_SHIFT`), and `inode_query_iversion()` right-shifts by `I_VERSION_QUERIED_SHIFT`. When `inode_maybe_inc_iversion()` fast-paths (`!force && !(cur & I_VERSION_QUERIED)`), it issues `smp_mb()` and re-reads `inode_peek_iversion_raw(inode)`, pairing with `smp_mb()` in `inode_query_iversion()`. [F133, F165]
- `stashed_dentry_get()` and `stash_dentry()` hold `guard(rcu)()` while dereferencing `*stashed` and calling `lockref_get_not_dead()`, and `stashed_dentry_prune()` clears `*stashed` via `cmpxchg(stashed, dentry, NULL)`. In `page_symlink()`, if `!mapping_gfp_constraint(mapping, __GFP_FS)`, `aops->write_begin()` is wrapped in `memalloc_nofs_save()` / `memalloc_nofs_restore()`. [F150, F166]
- In `__entry_find()` and `mb_cache_entry_get()`, under `hlist_bl_lock(head)`, `atomic_inc_not_zero(&entry->e_refcnt)` must be the final conjunct in `&&` after key, value, and `MBE_REUSABLE_B` checks. `__entry_find()` saves `entry` in `old_entry` before `while (node)` (resetting `entry = NULL` if the loop ends without `goto out`), and restarts from `hlist_bl_first(head)` if `hlist_bl_unhashed(&old_entry->e_hash_list)`. In `mb_cache_shrink()`, `test_bit(MBE_REFERENCED_B, &entry->e_flags)` precedes `atomic_cmpxchg(&entry->e_refcnt, 1, 0) != 1`, moving skipped entries via `list_move_tail(&entry->e_list, &cache->c_list)`. [F79, F111, F112, F113, F159]

## Object Lifetimes

- `__legitimize_path()` nulls `path->mnt` only when `__legitimize_mnt() > 0` and always nulls `path->dentry` on failure (`__legitimize_mnt() < 0` means the mount ref was acquired and must be dropped by `path_put()`). When `d_alloc_parallel()` returns `d_in_lookup(dentry)` in `__lookup_slow()`, `lookup_open()`, or `atomic_open()`, `d_lookup_done(dentry)` must be called after `i_op->lookup` or `i_op->atomic_open` and before `dput(dentry)` on error or replacement. [F5, F13]
- In `vfs_rename()`, `take_dentry_name_snapshot(&old_name, old_dentry)` precedes `i_op->rename()`, `d_move()`, or `d_exchange()`, passing `&old_name.name` to `fsnotify_move()` (and `&old_dentry->d_name` for the exchanged target's old name under `RENAME_EXCHANGE`). Every exit after snapshot, `dget(new_dentry)`, and child locking must jump to `out` to unlock the exact locked children, `dput(new_dentry)`, and `release_dentry_name_snapshot(&old_name)`. [F10, F87]
- `simple_pin_fs()` calls `mntget(*mount)` and increments `*count` under `pin_fs_lock`, then `mntput(mnt)` on any local `vfs_kern_mount()` result after unlocking; `simple_release_fs()` sets `*mount = NULL` under `pin_fs_lock` when `--*count == 0` before `mntput(mnt)`. In `path_from_stashed()` and `prepare_anon_dentry()`, `sops->put_data(data)` is called when reusing a dentry or when `new_inode_pseudo()` fails; once `sops->init_inode(inode, data)` runs, `@data` is owned by the inode and freed via `iput()`/`dput()`. [F17, F18]
- `mb_cache_entry_create()` initializes `e_list`, `e_key`, `e_value`, `e_flags = 0`, and `e_refcnt = 2` (no slab constructor/`__GFP_ZERO`) before hashing under `hlist_bl_lock(head)` (freeing `entry` on `-EBUSY` duplicate), dropping the setup ref via `mb_cache_entry_put()` only after adding `e_list` to `c_list` under `c_list_lock`. `mb_cache_entry_delete_or_get()` and `mb_cache_shrink()` zero `e_refcnt`, unlink `e_list` and decrement `c_entry_count` under `c_list_lock`, then call `__mb_cache_entry_free()`. `mb_cache_destroy()` requires no active users/refs and drains `c_list` unlocked after `shrinker_free()`. [F19, F26, F58, F78]
- In `mpage_write_folio()`, `bio_add_folio()` must succeed before `clean_buffers(folio, first_unmapped)` clears `BH_Dirty` on the first `first_unmapped` buffers (`try_to_free_buffers(folio)` only if `folio_test_uptodate(folio)`) and before `folio_start_writeback()` / `folio_unlock()`, so `confused` runs `block_write_full_folio()` with the folio locked and buffers dirty. [F21, F81]
- In `move_from_ns()` (`fs/mount.h`), before `rb_erase(&mnt->mnt_node, &ns->mounts)`, `ns->mnt_last_node` and `ns->mnt_first_node` are updated to `rb_prev`/`rb_next` if they point to `&mnt->mnt_node`, followed by `RB_CLEAR_NODE(&mnt->mnt_node)` so `mnt_ns_attached(mnt)` is false. [F22]

## API Contracts

- `nd_jump_link()` always consumes `@path` (`path_put(&nd->path)` and installs `*path` on success; `path_put(path)` on error). `scan_positives()` and `find_next_child()` always consume `@last`/`@prev` via `dput()` and return a new ref to the next positive child (or `NULL`). `mb_cache_entry_find_next()` always drops `@entry` via `mb_cache_entry_put()`, while `mb_cache_entry_delete_or_get()` returns `NULL` if absent/deleted or a referenced entry (caller must put) if `e_refcnt > 2`. [F6, F15, F20]
- `lock_rename()` and `lock_rename_child()` return `ERR_PTR(-EXDEV)` unlocked if no common ancestor, `NULL` locked if neither is an ancestor, or a non-error child `dentry *` trap locked if one is an ancestor. In `do_renameat2()`, `lock_rename(new_path.dentry, old_path.dentry)` passes `new_path.dentry` first, so `old_dentry == trap` is `-EINVAL` and `new_dentry == trap` is `-ENOTEMPTY` (`-EINVAL` under `RENAME_EXCHANGE`). [F47, F125]
- `d_op->d_revalidate()` and `d_weak_revalidate()` return `> 0` (valid), `0` (stale; invalidate or map to `-ESTALE`), or `< 0` (`-errno`, or `-ECHILD` in RCU). `try_lookup_noperm()` uses `d_lookup()` without `d_revalidate()`, whereas `lookup_noperm()` and `lookup_noperm_unlocked()` use `lookup_dcache()`. `lookup_one_qstr_excl()` requires a pre-hashed, validated single-component `qstr`. [F50, F101, F170]
- In `__traverse_mounts()` and `__follow_mount_rcu()`, `d_op->d_manage()` and `follow_automount()` return `-EISDIR` to stop traversal and use the current path without error (translate to `0`/`true`). Under `LOOKUP_NO_XDEV`, `follow_automount()` and `__traverse_mounts()` return `-EXDEV` before `d_automount()`/`d_manage()`, and `__follow_mount_rcu()` returns `false` on `DCACHE_MANAGED_DENTRY`. [F51, F168]
- `generic_set_sb_d_ops(sb)` runs after setting `sb->s_encoding` and `sb->s_cop`, and before creating `sb->s_root`. `struct tree_descr` arrays for `simple_fill_super()` must end with `{ "" }` (NULL `name` entries are skipped). Directory inodes using `simple_offset_dir_operations` must implement `i_op->get_offset_ctx` and reserve child `dentry->d_fsdata`. [F77, F92, F173]
- `page_symlink()` writes `len - 1` bytes (no NUL), so `page_get_link()` calls `nd_terminate_link(kaddr, inode->i_size, PAGE_SIZE - 1)` while `page_get_link_raw()` is not NUL-terminated. Symlink inodes using `page_get_link*()` must not set `__GFP_HIGHMEM` on `i_mapping`. Symlinks with non-NULL `inode->i_link` must still set `i_op->get_link` for `d_is_symlink()`. `set_delayed_call()` uses `kfree_link` and `page_put_link`, not cast `kfree`/`folio_put`. [F102, F143, F149, F171]
- Permission/ownership helpers in `fs/namei.c` (`inode_permission`, `generic_permission`, `acl_permission_check`, `may_linkat`, `may_create_in_sticky`, `__check_sticky`, `may_delete`, `may_create`) must map `i_uid`/`i_gid` via `struct mnt_idmap *idmap`. `kernel_tmpfile_open()` uses `alloc_empty_file_noaccount()` and must never be passed to `fd_install()`. In `vfs_rename()`, unless `FS_RENAME_DOES_D_MOVE` is set, VFS calls `d_move()` (or `d_exchange()` on `RENAME_EXCHANGE`) after `i_op->rename()` returns 0. [F180, F182, F187]

## Error Handling

- In `direct_write_fallback()`, if `buffered_written < 0` or `filemap_write_and_wait_range()` fails (rewinding `iocb->ki_pos` by `buffered_written`), return `direct_written` when `direct_written != 0`, and the negative error only when `direct_written == 0`. [F59]
- `generic_ci_d_compare()` returns `0` on match and `1` on mismatch; `generic_ci_match()` returns `1` on match and `0` on mismatch (logging via `pr_err_ratelimited()` and returning `0` if `utf8_strncasecmp*()` returns `< 0` under `sb_has_strict_encoding(sb)`). [F62, F184]

## External Contracts

- Under `LOOKUP_LINKAT_EMPTY`, `path_init()` must verify `fd_file(f)->f_cred == current_cred()` or `ns_capable(fd_file(f)->f_cred->user_ns, CAP_DAC_READ_SEARCH)`, returning `-ENOENT` otherwise. [F181]

## Known Pitfalls

- `simple_read_from_buffer(to, count, ppos, from, available)` and `simple_write_to_buffer(to, available, ppos, from, count)` swap `count` and `available` positions and return `-EFAULT` only if uncopied bytes equal `count`. Both and `memory_read_from_buffer()` must check `pos < 0` before `pos >= available`, and both before `available - pos`. [F69, F131]
- `generic_fh_to_dentry()` and `generic_fh_to_parent()` (like `generic_encode_ino32_fh()`) measure `fh_len` in 4-byte (`__u32`) words (`fh_len >= 2` for dentry, `> 2` for parent, `> 3` for `parent_gen`), despite kerneldoc saying bytes. [F94]
- In `vfs_rename()` when `max_links && new_dir != old_dir`, `is_dir && !new_is_dir` checks `new_dir->i_nlink >= max_links`, whereas `(flags & RENAME_EXCHANGE) && !is_dir && new_is_dir` checks `old_dir->i_nlink >= max_links`. In `do_unlinkat()` and `do_renameat2()`, `inode = NULL` (before `goto retry_deleg`/`retry`) and `should_retry = false` (before `goto retry`) must be reset on retry. [F124, F126]
