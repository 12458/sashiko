# WANGXUN ETHERNET DRIVER — drivers/net

10/25/40GbE PF (`txgbe`) and VF (`txgbevf`) PCI Ethernet drivers and DesignWare XPCS helper (`pcs-xpcs-wx.c`) for WangXun Sapphire (SP1000/WX1820) and Amber Lite (AML50xx/51xx) controllers. Built on `libwx`, `txgbe` adds Flow Director, UDP tunnel offload, misc IRQ domain management, software nodes for I2C/GPIO/SFP/phylink, and XPCS SERDES configuration.

## Architecture & Data Flow

- Helpers shared with `txgbevf` or called in `txgbe_probe()` before `wx->priv = txgbe` (`txgbe_sw_init`, `txgbe_reset_hw`, `txgbe_validate_eeprom_checksum`, `txgbe_init_service`, `txgbe_test_hostif`) must never dereference `wx->priv` (`NULL` until allocated in `txgbe_probe()`, always `NULL` in `txgbevf`). [F268]
- `txgbe_link_irq_handler()` runs on both `wx_mac_sp` and `wx_mac_aml`, but `txgbe->pcs` is `NULL` on `wx_mac_aml` and copper `wx_mac_sp`; it must check `if (txgbe->pcs)` to choose between `phylink_pcs_change(txgbe->pcs, up)` and `phylink_mac_change(wx->phylink, up)`. [F204]
- Whenever the MAC is reset/reconfigured while bringing link up (`txgbe_mac_link_up_aml()` after `txgbe_reconfig_mac()`, `txgbe_mac_finish()` after `txgbe_mac_prepare()`, and `txgbe_up_complete()` on `wx_mac_aml40`), `txgbe_enable_sec_tx_path(wx)` must be called to clear `WX_TSC_CTL_TX_DIS` and flush. `txgbe_reconfig_mac()` must also save and restore `WX_MAC_WDG_TIMEOUT` and `WX_MAC_RX_FLOW_CTRL` across `TXGBE_MIS_RST_MAC_RST(wx->bus.func)` and `wx_reset_mac(wx)`. [F226, F284]
- Both phylink MAC ops tables (`txgbe_mac_ops` and `txgbe_mac_ops_aml`) must update `wx->speed` (`speed` on link up, `SPEED_UNKNOWN` on link down), call `wx_ptp_reset_cyclecounter(wx)` when `WX_STATE_PTP_RUNNING` is set, and notify active VFs via `wx_ping_all_vfs_with_link_status()`. [F233]
- In `txgbe_disable_device()`, clearing `WX_MAC_TX_CFG_TE` in `WX_MAC_TX_CFG` must be skipped when `wx->subsystem_device_id` has `WX_NCSI_SUP` (`0x8000`) or `WX_WOL_SUP` (`0x4000`) set; in `txgbe_dev_shutdown()` and `txgbe_close()`, `wx_control_hw(wx, false)` must be called after stopping the device. [F288]
- Each `struct txgbe` instance must populate its own embedded `struct txgbe_nodes` (with `nodes.group` sized `SWNODE_MAX + 1` and `nodes->group[SWNODE_MAX]` left `NULL`) and qualify swnode names, `mii_bus->id`, GPIO labels, clkdev names, and `i2c_designware`/`sfp` platform device IDs with `pci_dev_id(pdev)`. [F231, F241]
- `txgbe_add_ethtool_fdir_entry()` must only update `txgbe->fdir_mask` and call `txgbe_fdir_set_input_mask()` when `txgbe->fdir_filter_list` is empty, and reject any new rule whose mask differs when non-empty. `txgbe->fdir_filter_list` must stay sorted in strictly ascending `rule->sw_idx` order via `txgbe_update_ethtool_fdir_entry()`, and both `txgbe_get_ethtool_fdir_entry()` and `txgbe_update_ethtool_fdir_entry()` must check `rule != NULL` after `hlist_for_each_entry_safe()` before dereferencing `rule->sw_idx`. [F219, F236, F248]
- `union txgbe_atr_input` instances passed to `txgbe_atr_compute_perfect_hash()` and `txgbe_fdir_write_perfect_filter()` must be zero-initialized before setting IPv4 fields (all 11 `dword_stream` words are hashed and `src_ip[0..2]` are written to `TXGBE_RDB_FDIR_IP6(0..2)`). In `txgbe_atr()`, `union txgbe_atr_hash_dword` variables `input` and `common` must be zero-initialized (`.dword = 0`) and `ring->q_vector` checked for `NULL` before use. [F210, F211]
- In `txgbe_atr_compute_sig_hash()` and `txgbe_atr_compute_perfect_hash()`, `lo_hash_dword ^= flow_vm_vlan ^ (flow_vm_vlan << 16)` must run after iteration 0 and before the `i = 1..15` loop so bit 0 of `flow_vm_vlan` is excluded during bit-0 processing; in `TXGBE_COMPUTE_SIG_HASH_ITERATION`, each `if / else if` chain must test `TXGBE_ATR_COMMON_HASH_KEY` before `TXGBE_ATR_BUCKET_HASH_KEY` and `TXGBE_ATR_SIGNATURE_HASH_KEY`. [F245, F260]
- In `txgbe_xpcs_switch_mode()`, `if (xpcs->interface == interface && !txgbe_xpcs_mode_quirk(xpcs))` must be evaluated before updating `xpcs->interface = interface` so `txgbe_xpcs_mode_quirk()` can detect when a LAN reset reverted `MDIO_CTRL2` to `MDIO_PCS_CTRL2_10GBR`. [F250]
- In `txgbe_set_ringparam()`, when `!netif_running(wx->netdev)`, updating `wx->tx_ring_count` and `wx->rx_ring_count` must also update `wx->tx_ring[i]->count` for all `wx->num_tx_queues` and `wx->rx_ring[i]->count` for all `wx->num_rx_queues`. [F229]
- `txgbe_init_thermal_sensor_thresh()` must zero `wx->mac.sensor` on all functions, but only program thermal sensor registers (`TXGBE_TS_CTL`, `WX_TS_INT_EN`, `WX_TS_EN`, `WX_TS_ALARM_THRE`, `WX_TS_DALARM_THRE`) when `wx->bus.func == 0`. [F232]
- `txgbe_enumerate_functions()` iterating `&pdev->bus->devices` must return `-EINVAL` if any device on the bus does not match both `pdev->vendor` and `pdev->device`, and `txgbe_probe()` must only call `txgbe_check_minimum_link(wx)` when `expected_gts > 0`. [F255]

## Synchronization

- `txgbe->fdir_perfect_lock` must be held across all accesses and updates to `txgbe->fdir_filter_list`, `txgbe->fdir_filter_count`, and `txgbe->fdir_mask` in `txgbe_add_ethtool_fdir_entry()`, `txgbe_del_ethtool_fdir_entry()`, `txgbe_update_ethtool_fdir_entry()`, `txgbe_fdir_filter_restore()`, and `txgbe_fdir_filter_exit()`. [F190]
- `txgbe_fdir_check_cmd_complete()` must poll with `read_poll_timeout_atomic` (not sleeping waits) because it runs in softirq Tx context via `txgbe_atr()` -> `txgbe_fdir_add_signature_filter()` and under `txgbe->fdir_perfect_lock`. `txgbe_fdir_write_perfect_filter()`, `txgbe_fdir_erase_perfect_filter()`, and `txgbe_fdir_enable()` must issue `WX_WRITE_FLUSH(wx)` after writing `TXGBE_RDB_FDIR_HASH` or `TXGBE_RDB_FDIR_CTL` and before writing `TXGBE_RDB_FDIR_CMD` or polling. [F289, F297]
- `wx->gpio_lock` must be initialized via `raw_spin_lock_init()` in `txgbe_gpio_init()` before `devm_gpiochip_add_data()`, and held via `raw_spin_lock_irqsave()` in `txgbe_gpio_direction_in()` and `txgbe_gpio_direction_out()` across `WX_GPIO_DR` and `WX_GPIO_DDR` updates. [F198]
- Child IRQs in `txgbe->misc.domain` (`txgbe->link_irq`, `txgbe->gpio_irq`) are mapped with `irq_set_nested_thread(irq, true)` in `txgbe_misc_irq_domain_map()` and must be requested with `request_threaded_irq(..., NULL, thread_fn, IRQF_ONESHOT, ...)` and dispatched via `handle_nested_irq()` from `txgbe_misc_irq_thread_fn()`, never from `txgbe_misc_irq_handle()`. [F293]

## Object Lifetimes

- `txgbe_sw_init()` (via `wx_sw_init()`) allocates `wx->rss_key` and `wx->mac_table` (freeing `rss_key` on failure), while `txgbevf_sw_init()` also allocates `wx->vfinfo` and frees all on internal failure; `txgbe_probe()` / `txgbevf_probe()` must jump to `err_pci_release_regions` when `*_sw_init()` fails, and unwind through `err_free_mac_table` / `err_free_sw_init` on later errors. [F177, F178]
- In `txgbe_probe()`, `txgbe_init_fdir()` and `txgbe_init_phy()` must complete before `register_netdev()`; in `txgbe_remove()`, `cancel_work_sync(&wx->service_task)`, `wx_disable_sriov(wx)`, and `unregister_netdev(netdev)` must complete before `txgbe_remove_phy(txgbe)` and `wx_free_isb_resources(wx)` (`wx->isb_mem` persists across `txgbe_close()`). [F182, F200]
- In `txgbe_open()` rollback and `txgbe_close()`, `wx_free_irq(wx)` must run before `txgbe_free_misc_irq(wx->priv)` (which clears `wx->misc_irq_domain = false`), and in `txgbe_setup_misc_irq()` rollback / `txgbe_free_misc_irq()`, `free_irq()` on `txgbe->gpio_irq`, `txgbe->link_irq`, and `txgbe->misc.irq` must precede `txgbe_del_irq_domain()`. [F179, F181]
- In `txgbe_init_phy()` error paths and `txgbe_remove_phy()`: for non-copper `wx_mac_sp`, release in strict reverse order (`txgbe->sfp_dev`, `txgbe->i2c_dev`, `txgbe->clock`/`txgbe->clk`, `wx->phylink`, `txgbe->pcs`, `txgbe->nodes.group`); for copper `wx_mac_sp`, call `phylink_disconnect_phy(txgbe->wx->phylink)` before `phylink_destroy(txgbe->wx->phylink)` (and destroy `phylink` if `phylink_connect_phy()` fails in `txgbe_phylink_init()`). [F183, F184]
- In `txgbe_add_ethtool_fdir_entry()`, `input` (`kzalloc()`) must be freed (after unlocking `txgbe->fdir_perfect_lock` if held) on every error path before `txgbe_update_ethtool_fdir_entry()` links it into `txgbe->fdir_filter_list`. Linked entries persist across `txgbe_down()`/`txgbe_up()` and are freed in `txgbe_close()` by `txgbe_fdir_filter_exit(wx)` (or individually by `txgbe_update_ethtool_fdir_entry()`), which must hold `fdir_perfect_lock`, `hlist_del()`, `kfree()`, and update `fdir_filter_count`. [F185, F186]
- In `txgbe_calc_eeprom_checksum()`, `eeprom_ptrs` (`kvmalloc_array()`) must be freed with `kvfree(eeprom_ptrs)` before both error and normal returns. [F187]

## API Contracts

- In `txgbe_phy.c`, MDIO (`mii_bus->priv`), GPIO (`gpiochip_get_data()`), and I2C regmap (`txgbe_i2c_read`/`txgbe_i2c_write` `context`) callbacks store and cast `struct wx *`, whereas in `txgbe_irq.c` the misc `irq_domain` `host_data` and `txgbe->misc.irq`, `txgbe->link_irq`, and `txgbe->gpio_irq` handlers store and cast `struct txgbe *`. [F269]
- In `txgbe_phylink_mac_select()`, `txgbe->pcs` must be returned whenever `wx->media_type != wx_media_copper` (`10GBASER`, `1000BASEX`, `SGMII`), and `NULL` when `wx->media_type == wx_media_copper`. [F278]
- `txgbe_xpcs_switch_mode()` may only be called from process context (`txgbe_pcs_poll_power_up()` and `txgbe_pma_init_done()` use sleeping `read_poll_timeout` loops). In `pcs-xpcs-wx.c`, `txgbe_write_pma()` and `txgbe_modify_pma()` automatically add `TXGBE_PMA_MMD` (`0x8020`), so callers must pass only the relative offset (`0x11`..`0x76`). [F216, F298]
- `txgbe_atr_compute_perfect_hash()` must be called with `input_mask->formatted.bkt_hash == 0` before `txgbe_match_ethtool_fdir_entry()` or `txgbe_fdir_write_perfect_filter()`, because it masks `input->dword_stream` in place and writes `input->formatted.bkt_hash`. `rule->action` stores raw `ring_cookie`, but `txgbe_fdir_write_perfect_filter()` requires `queue` mapped to the hardware register index (`wx->rx_ring[ring]->reg_idx` for PF, or `((vf - 1) * wx->num_rx_queues_per_pool) + ring` for VF). [F220, F302]
- In `txgbe_flowspec_to_flow_type()`, `fsp->flow_type` must be masked with `~FLOW_EXT` before switching, and under `IP_USER_FLOW` a `proto` of `0` is valid (`TXGBE_ATR_FLOW_TYPE_IPV4`) only when `fsp->m_u.usr_ip4_spec.proto == 0`, else `-EINVAL`. [F249]
- In `txgbe_udp_tunnel_sync()`, `ti.port` (`__be16` from `udp_tunnel_nic_get_port()`) must be converted with `ntohs(ti.port)` before writing `TXGBE_CFG_VXLAN`, `TXGBE_CFG_VXLAN_GPE`, or `TXGBE_CFG_GENEVE`. [F304]
- Callers of `TXGBE_MIS_PRB_CTL_LAN_UP(_i)` (`BIT(1 - (_i))`) must verify `_i < 2` first, and `txgbe_validate_eeprom_checksum()` must check `if (checksum_val)` before writing `*checksum_val`. [F209, F257]

## Error Handling

- In `txgbe_open()`, if `txgbe_request_queue_irqs()`, `netif_set_real_num_tx_queues()`, or `netif_set_real_num_rx_queues()` fails after `txgbe_setup_misc_irq()`, `err_free_misc_irq` must call `txgbe_free_misc_irq(wx->priv)` and `wx_reset_interrupt_capability(wx)` before `wx_free_resources(wx)`. [F180]
- In `txgbe_phy.c` and `txgbe_aml.c`, `xpcs_create_pcs_mdiodev()`, `phylink_create()`, `clk_register_fixed_rate()`, `devm_regmap_init()`, and `platform_device_register_full()` return `ERR_PTR` values that must be checked in a local variable with `IS_ERR()` before assigning to `txgbe->pcs`, `wx->phylink`, `txgbe->clk`, `txgbe->i2c_dev`, or `txgbe->sfp_dev`. [F206]
- In `txgbe_add_ethtool_fdir_entry()`, `err` starts as `-EINVAL` and is relied upon by the `txgbe_flowspec_to_flow_type()`, mask `memcmp()`, and `txgbe_match_ethtool_fdir_entry()` error jumps; no intermediate call may leave `err == 0` before those checks. [F207]

## External Contracts

- In `txgbe_ethtool.c`, `txgbe_fdir_write_perfect_filter()` and `txgbe_fdir_erase_perfect_filter()` must only be called when `netif_running(wx->netdev)` is true (filter memory is in the hardware Rx packet buffer). `txgbe_fdir_set_input_mask()` must bitwise-invert host-order port and IPv4 masks (`~fdirtcpm`, `ntohl(~input_mask->formatted.src_ip[0])`, `ntohl(~input_mask->formatted.dst_ip[0])`) before writing `TXGBE_RDB_FDIR_*_MSK`. [F239, F299]
- In `txgbe_atr()`, when `wx_decode_ptype(ptype).etype` is non-zero (tunneled packet), the signature hash must use `skb_inner_network_header(first->skb)` and `inner_tcp_hdr(first->skb)` with inverted ports (`common.port.src ^= th->dest`, `common.port.dst ^= th->source`). [F303]
- In `txgbe_clock_register()`, `clk_name` must be `"i2c_designware.%d"` with `pci_dev_id(pdev)` (matching `txgbe_i2c_register()` and `< 24` bytes for `MAX_DEV_ID`) and passed to `clkdev_create()` via `"%s"`. In `txgbe_gpio_init()`, `gc->label` (`"txgbe_gpio-%x"`) must identically match `nodes->gpio_name` (`swnodes[SWNODE_GPIO].name`) for `gpiolib-swnode` lookup. [F270, F271]
- In `txgbe_mdio_pcs_init()`, `mii_bus->phy_mask = ~0` with the PCS at address 0, and `txgbe_pcs_read()`/`txgbe_pcs_write()` must reject any non-zero `addr` (`if (addr) return -EOPNOTSUPP;`). [F309]

## Known Pitfalls

- In `txgbe_reset()`, `wx->mac_table[0].addr` must be copied into a temporary buffer before `wx_flush_sw_mac_table(wx)` (which zeroes in-use entries in place) and restored via `wx_mac_set_default_filter(wx, old_addr)`. [F224]
- In `union txgbe_atr_input`, `vlan_id`, `dst_ip`, `src_ip`, `src_port`, `dst_port`, and `flex_bytes` are big-endian and converted with `ntohl()`/`ntohs()` for FDIR registers (with 16-bit `ntohs(dst_port)` and `ntohs(flex_bytes)` widened to `u32` before `<< 16` shifts), whereas `formatted.bkt_hash` is stored in host byte order via `(__force __be16)` and read via `(__force u32)` without byte-swapping. [F238, F259]
- In `txgbe_calc_eeprom_checksum()`, callers must zero `*checksum` beforehand; words in `[TXGBE_EEPROM_I2C_SRART_PTR, TXGBE_EEPROM_I2C_END_PTR)` (`0x580..0x7ff`) must be replaced with `0xffff` on `wx_mac_aml`, `wx->eeprom.sw_region_offset + TXGBE_EEPROM_CHECKSUM` must be skipped, and `*checksum = TXGBE_EEPROM_SUM - *checksum` relies on wrapping `u16` arithmetic. [F244, F258]
- RMW updates to vendor PMA registers in `txgbe_pma_config_10gbaser()` and `txgbe_pma_config_1g()` must use `txgbe_modify_pma(xpcs, reg, mask, set)` so the value is written back to the same `TXGBE_PMA_MMD + reg` register. [F251]
