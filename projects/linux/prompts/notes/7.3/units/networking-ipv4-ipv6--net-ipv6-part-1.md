# NETWORKING [IPv4/IPv6] — net/ipv6 (part 1)

Implements the core IPv6 protocol family (`af_inet6.c`), interface autoconfiguration, SLAAC, and DAD (`addrconf.c`, `addrconf_core.c`), RFC 6724 source address labels (`addrlabel.c`), anycast (`anycast.c`), datagram socket/cmsg helpers (`datagram.c`), extension headers (`exthdrs.c`, `exthdrs_core.c`, `exthdrs_offload.c`), policy routing (`fib6_rules.c`, `fib6_notifier.c`), and IPv6 FOU/GUE (`fou6.c`).

## Architecture & Data Flow
- `idev->addr_list` insertions must use `ipv6_link_dev_addr()` to keep descending scope order (`__ipv6_dev_get_saddr()` stops at `score->scopedist > 0`; reverse walkers `__ipv6_get_lladdr()`, `ipv6_lonely_lladdr()`, `ipv6_inherit_eui64()` stop at `ifp->scope > IFA_LINK`). In `ipv6_get_saddr_eval()`, multi-valued rules (`IPV6_SADDR_RULE_SCOPE`, `IPV6_SADDR_RULE_PREFIX`) must cache scores in dedicated `ipv6_saddr_score` fields and return them in the `if (i <= score->rule)` switch. [F441, F485]
- `__ipv6_chk_addr_and_flags()` masks `IFA_F_TENTATIVE` from `ifp_flags` when `ifp->flags & IFA_F_OPTIMISTIC` is set before checking `!(ifp_flags & banned_flags)`; callers banning optimistic addresses must pass `IFA_F_OPTIMISTIC`. [F486]
- Deleting an `IFA_F_MANAGETEMPADDR` address in `inet6_addr_del()` or clearing that flag in `inet6_addr_modify()` must call `delete_tempaddrs(idev, ifp)`. When `addrconf_verify_rtnl()` regenerates an expiring `IFA_F_TEMPORARY` `ifp`, it must increment `ifp->regen_count` and reset `ifpub->regen_count = 0` before `ipv6_create_tempaddr(ifpub, true)`. [F444, F445]
- When `addrconf_ifdown()` retains a permanent address (`keep_addr_on_down`), it must set `ifa->state = INET6_IFADDR_STATE_PREDAD`, set `IFA_F_TENTATIVE` (unless `IFA_F_NODAD`), and detach/delete `ifa->rt` so `fixup_permanent_addr()` regenerates `ifa->rt` and restarts DAD on `NETDEV_UP`. `addrconf_disable_policy_idev()` must update `ifa->rt->dst_nopolicy` and `DST_NOPOLICY` on every per-CPU `rt6_info` in `ifa->rt->fib6_nh->rt6i_pcpu` via `addrconf_set_nopolicy()`. [F446, F448]
- L3 domain isolation: `ipv6_dev_get_saddr()` and `__ipv6_chk_addr_and_flags()` must match `l3mdev_master_ifindex_rcu` / `l3mdev_master_dev_rcu`; user `sin6_scope_id` in `__ip6_datagram_connect()` and `IPV6_PKTINFO` in `ip6_datagram_send_ctl()` must check `sk_dev_equal_l3scope(sk, ...)`; in `fib6_lookup()` / `fib6_rule_lookup()` with `fib6_has_custom_rules`, `l3mdev_update_flow()` must precede `fib_rules_lookup()`. When `r->src.plen != 0` and `!(flags & RT6_LOOKUP_F_HAS_SADDR)`, `fib6_rule_match()` must match if `FIB_RULE_FIND_SADDR` is set and defer prefix matching to `fib6_rule_saddr()`. [F497, F539, F548, F552]
- Because `inet6_acaddr_lst` (`anycast.c`) is global across netns, `ipv6_chk_acast_addr()` (`dev == NULL`) must check `net_eq(dev_net(fib6_info_nh_dev(aca->aca_rt)), net)`. In `__ip6addrlbl_add()`, `ip6addrlbl_table.head` must stay sorted by descending `prefixlen`, with `ifindex != 0` before `!p->ifindex` for equal `prefixlen`, as `__ipv6_addr_label()` returns the first match. [F461, F495]
- Netlink dumps: new attributes in `inet6_fill_ifla6_attrs()`, `inet6_fill_ifaddr()`, `inet6_fill_prefix()`, `inet6_netconf_fill_devconf()`, or `ip6addrlbl_fill()` must update their paired `*size()` helpers. `inet6_base_seq()` must substitute `0x80000000` if the 32-bit sequence wraps to `0`. `in6_dump_addrs()` must set `*s_ip_idx = err ? ip_idx : 0` on return so completed `idev` dumps reset `ctx->ip_idx`. [F462, F478, F489]
- Inbound `exthdrs.c` handlers modifying `CHECKSUM_COMPLETE` bytes (`ipv6_dest_hao`, `ipv6_srh_rcv`, `ipv6_rpl_srh_rcv`, `ipv6_rthdr_rcv`) must update `skb->csum` (`seg6_update_csum`, `skb_postpull_rcsum`/`skb_postpush_rcsum`) or set `CHECKSUM_NONE`. In `ipv6_rthdr_rcv()`, `addr` is `NULL` before `looped_back:` and set only when `segments_left > 0`, so `!addr` at `looped_back:` drops wire `segments_left == 0` Type 2 headers. `ipv6_hop_jumbo()` requires `nh[optoff + 1] == 4`, `(optoff & 3) == 2`, `pkt_len > IPV6_MAXPLEN`, `payload_len == 0`, and `pkt_len <= skb->len - sizeof(struct ipv6hdr)` before `pskb_trim_rcsum()`. [F468, F493, F541]
- In `ipv6_renew_options()` and `ipv6_dup_options()`, options after `opt2 + 1` are padded to `CMSG_ALIGN(ipv6_optlen(hdr))` in `tot_len` while `opt_nflen`/`opt_flen` sum unpadded lengths, and `ipv6_dup_options()` rebases pointers by `(char *)opt2 - (char *)opt`. [F470]
- Every `struct proto` in `inet6_register_protosw()` must embed `struct ipv6_pinfo` at `prot->ipv6_pinfo_offset` for `inet6_sk_generic()`. `inet6_net_init()` must set `icmpv6_ratemask_ptr = &icmpv6_ratemask` for `proc_do_large_bitmap()`. For `ETH_P_IPV6` error SKBs with `ipv6_datagram_support_addr(serr)`, `skb_network_header(skb) + serr->addr_offset` must point to `daddr` inside a complete `struct ipv6hdr` for `container_of` in `ipv6_recv_error()`. [F513, F515, F516]

## Synchronization
- In `addrconf.c`, `idev->lock` nests outside `ifp->lock`; both and `net->ipv6.addrconf_hash_lock` are used in softirq/timers (`addrconf_rs_timer`, `addrconf_prefix_rcv`, `addrconf_dad_failure`), requiring `_bh` locking in process context. `idev->token` accesses must hold `idev->lock`. [F414, F520, F521]
- RCU publication: `ipv6_add_dev()` must fully initialize `ndev` (locks, lists, timer, `nd_parms`, SNMP, `refcnt`, mcast, sysctl) before `rcu_assign_pointer(dev->ip6_ptr, ndev)`. `ipv6_add_addr()` must initialize `ifa->lock`, `dad_work`, `rt`, `idev`, and `refcnt = 1` before hashing into `inet6_addr_lst` (`addrconf_hash_lock`) and linking into `idev->addr_list` (`write_lock_bh(&idev->lock)`). [F401, F403]
- `ipv6_del_addr()` must atomically check and set `ifp->state = INET6_IFADDR_STATE_DEAD` under `spin_lock_bh(&ifp->lock)`; if already dead, it must only drop the caller's ref. Operations that cannot hold `idev->lock` (`addrconf_join_anycast`, `addrconf_leave_anycast`, `ip6_del_rt`) over `idev->addr_list` must stage entries via `ifa->if_list_aux` under `idev->lock` first. [F405, F406]
- In `addrconf_verify_rtnl()`, before dropping `ifp->lock` and `rcu_read_unlock_bh()` to call `ipv6_create_tempaddr()` or `ipv6_del_addr()`, pin `ifp`/`ifpub` with `in6_ifa_hold()`, and `goto restart` after re-acquiring `rcu_read_lock_bh()`. `addrconf_cleanup()` must drop `rtnl_net_unlock(&init_net)` before `destroy_workqueue(addrconf_wq)`, and `addrconf_exit_net()` must call `cancel_delayed_work_sync(&net->ipv6.addr_chk_work)` unlocked before freeing `inet6_addr_lst`. [F407, F412]
- RCU lookups in `ipv6_get_ifaddr()` and `addrconf_get_prefix_route()` must use `in6_ifa_hold_safe()` and `fib6_info_hold_safe()` under `rcu_read_lock()`. In `ipv6_sock_ac_join()`, hold `rcu_read_lock()` across `rt6_lookup()`, `dst_dev_rcu(&rt->dst)`, and `netdev_hold()`. [F526, F528]
- Socket concurrency (`af_inet6.c`, `datagram.c`): read `np->opt` under `rcu_read_lock()` and unlink via `xchg(&np->opt, NULL)` + `txopt_put()`. Update/clear `np->rxpmtu` and `np->pktoptions` with atomic `xchg()` and `kfree_skb()` the old SKB. Unlocked socket ops (`inet6_bind_sk`, `inet6_ioctl`, `inet6_sendmsg`, `inet6_recvmsg`) must use `READ_ONCE(sk->sk_prot)`, and `sk->sk_uid` readers must use `sk_uid(sk)`. [F421, F530, F531, F532]
- In `inet6_init()`, `rawv6_init()` and `sock_register(&inet6_family_ops)` must precede `icmpv6_init()`, `ndisc_init()`, and `igmp6_init()`, and `ipv6_stub`/`ipv6_bpf_stub` must be set last after `wmb()`. `inet6_register_protosw()` / `inet6_unregister_protosw()` must use `spin_lock_bh(&inetsw6_lock)` and RCU list ops, with `synchronize_net()` after unregistering. [F417, F533]

## Object Lifetimes
- `idev->dead = 1` must be set before `in6_dev_finish_destroy()` (or final `in6_dev_put()` in `addrconf_ifdown()`), and `addrconf_ifdown(dev, true)` must clear `dev->ip6_ptr = NULL` without `netdev_put(dev)` (`in6_dev_finish_destroy()` drops `idev->dev_tracker`). `ipv6_add_addr()` returns a caller ref that must be dropped with `in6_ifa_put()`, and `inet6_ifa_finish_destroy()` only frees `ifp` if `ifp->state == INET6_IFADDR_STATE_DEAD`. [F377, F379, F381, F411]
- Always use `addrconf_mod_dad_work()`/`addrconf_del_dad_work()` and `addrconf_mod_rs_timer()`/`addrconf_del_rs_timer()` to keep `ifp`/`idev` refcounts balanced. In `ipv6_create_tempaddr()`, `in6_ifa_hold(ifp)` transfers to `ift->ifpub` on success (and is put/cleared on `tempaddr_list` removal); any error/retry before `ift->ifpub = ifp` must call `in6_ifa_put(ifp)` and `in6_dev_put(idev)`. [F382, F383]
- Passing `ifp->rt` to `ip6_del_rt()` consumes the ref, so `ifp->rt` must be set to `NULL` (and `fixup_permanent_addr()` must `fib6_info_release()` any old `ifp->rt`). `aca_alloc()` takes an extra `fib6_info_hold(f6i)` because unlinking calls `ip6_del_rt()` while `aca_free_rcu()` calls `fib6_info_release(aca->aca_rt)`. [F385, F386]
- In `inet6_create()`, failures after `sock_init_data(sock, sk)` must jump to `out_sk_release` (`sk_common_release(sk)` and `sock->sk = NULL`). Detaching `np->opt` must subtract `opt->tot_len` from `sk->sk_omem_alloc` before `txopt_put(opt)`. In `ipv6_sock_ac_join()`, set `pac = NULL` once linked into `np->ipv6_ac_list` so `error:` does not `sock_kfree_s()` it. [F387, F388, F389]
- In `__inet6_bind()`, `get_port` or post-bind BPF failure must restore `sk->sk_ipv6only`, call `inet_reset_saddr(sk)`, and (on post-bind failure) `put_port(sk)`. In `__ip6_datagram_connect()`, `ip6_datagram_dst_update()` failure must restore `sk_v6_daddr`, `flow_label`, and `inet_dport`. [F390, F391]
- In `fib6_rule_lookup()`, `__fib6_rule_action()`, and `fib6_rule_suppress()`, release rejected routes via `ip6_rt_put_flags(rt, flags)` and call `dst_hold(&rt->dst)` on fallback/discard entries iff `!(flags & RT6_LOOKUP_F_DST_NOREF)`. [F394]
- `__addrconf_sysctl_unregister()` must save `p->sysctl_header->ctl_table_arg` before `unregister_net_sysctl_table()`, then `kfree()` it and clear `p->sysctl_header = NULL`. In `inet6_dump_addr()`/`inet6_rtm_getaddr()`, call `put_net(tgt_net)` iff `fillargs.netnsid >= 0`. In `inet6_addr_add()`, if `IFA_F_MCAUTOJOIN` succeeded and `ipv6_add_addr()` fails, roll back via `ipv6_mc_config(..., false, ...)`. [F396, F398, F399]

## API Contracts
- `ipv6_del_addr()` and `addrconf_dad_stop()` always consume one `ifp` ref via `in6_ifa_put(ifp)`; callers not transferring a ref must call `in6_ifa_hold(ifp)` first. [F380]
- `ipv6_add_addr()`, `ipv6_add_dev()`, `ipv6_find_idev()`, and `addrconf_add_dev()` return `ERR_PTR` on failure (never `NULL`). `ipv6_renew_options()` returns `NULL` as valid success when `tot_len == 0` and `ERR_PTR` on error, whereas `ipv6_dup_options()` returns `NULL` on error. `fib6_rule_lookup()` never returns `NULL`/`ERR_PTR`, falling back to `&net->ipv6.ip6_null_entry->dst`. [F424, F427, F435]
- `ipv6_dev_find()` and `fib6_lookup()` (`FIB_LOOKUP_NOREF`) return unreferenced pointers; callers must hold `rcu_read_lock()` (or RTNL for `ipv6_dev_find()`) across the call and all uses of the result. [F525, F535]
- Device config paths (`addrconf_dev_config()`, `addrconf_gre_config()`, `inet6_addr_add()`) must call `addrconf_add_dev()` rather than `ipv6_find_idev()` so `addrconf_add_mroute()` adds the `ff00::/8` route. `addrconf_prefix_route()` takes `expires` in `clock_t` (`jiffies_to_clock_t()`), whereas `cleanup_prefix_route()` and `fib6_set_expires()` take `jiffies`. [F437, F439]
- `ip6_datagram_send_ctl()` requires a non-NULL, zero-initialized `ipc6->opt`. When `opt->dst0opt && !opt->srcrt`, `ipv6_push_nfrag_opts()` ignores `dst0opt`, and `__ipv6_fixup_options()` shallow-copies `opt` into `opt_space` (`hopopt`/`dst1opt` still alias `opt`, so `opt_space` must not outlive `opt` or be passed to `ipv6_dup_options()`/`txopt_put()`). [F428, F498, F507]
- `exthdrs_core.c`: `ipv6_find_hdr()` requires `*offset` initialized to `0` or a valid header offset and returns `-EBADMSG`/`-ENOENT` on failure; `ipv6_skip_exthdr()` and `ipv6_find_tlv()` return `-1` on failure and require signed `int` storage; `ipv6_find_tlv()` requires `offset >= 0` in the linear SKB area. [F429, F430, F469]
- In `fib6_rule_action()`, `lookup_ptr == fib6_table_lookup` requires `lookup_data` to be `int *` (`oif`), else a `pol_lookup_t` with `const struct sk_buff *`. In `inet6_bind_sk()`, `BPF_CGROUP_RUN_PROG_INET_BIND_LOCK` must run after `addr_len >= SIN6_LEN_RFC2133` and before `__inet6_bind()`. `inet6_register_protosw()` must not shadow or override `INET_PROTOSW_PERMANENT` entries, and `inet6_unregister_protosw()` must refuse to remove them. [F510, F544, F546]

## Error Handling
- In `addrconf.c`, callers of `__dev_get_by_index()` or `__dev_get_by_name()` (`addrconf_add_ifaddr`, `inet6_rtm_newaddr`, `inet6_addr_del`) must check `dev != NULL` before `netdev_lock_ops()`, `ipv6_find_idev()`, or `__in6_dev_get_rtnl_net()`. [F423]
- Reset `ERR_PTR` before `out:` cleanup: in `ipv6_add_addr()`, set `f6i = NULL` if `addrconf_f6i_alloc()` fails before `out:` (`fib6_info_release(f6i)`). In `ip6_datagram_dst_update()`, return or clear `flowlabel` if `fl6_sock_lookup()` returns `IS_ERR` before `out:` (`fl6_sock_release(flowlabel)`). [F425, F426]
- Zero padding to avoid infoleaks: `__snmp6_fill_statsdev()` and `__snmp6_fill_stats64()` must `memset` trailing `pad` bytes in netlink attributes; `datagram.c` error/MTU cmsg builders (`ipv6_icmp_error`, `ipv6_local_error`, `ipv6_local_rxpmtu`, `ipv6_recv_error`, `ipv6_recv_rxpmtu`) must zero `ee_pad`, `ee_data`, `sin6_flowinfo`, `sin6_port`, `sin6_scope_id`, and `errhdr.offender`. [F432, F433]

## External Contracts
- Reject `plen > 128` in `inet6_addr_add()`, `inet6_addr_del()`, and `ip6addrlbl_newdel()`. Reject `IFA_F_MANAGETEMPADDR` with `-EINVAL` if `plen != 64` (or on `IFA_F_TEMPORARY` in `inet6_addr_modify()`), and reject `label == IPV6_ADDR_LABEL_DEFAULT` in `ip6addrlbl_newdel()`. [F480, F481, F503]
- In `__ip6_datagram_connect()` and `inet6_bind_sk()`/`__inet6_bind()`, only read `sin6_scope_id` if `addr_len >= sizeof(struct sockaddr_in6)` (28), not just `SIN6_LEN_RFC2133` (24). In `ip6_datagram_send_ctl()`, Hop-by-Hop/Destination options require `ns_capable(net->user_ns, CAP_NET_RAW)` and two-stage `cmsg_len` checks against `sizeof(struct ipv6_opt_hdr)` and `((hdr->hdrlen + 1) << 3)`. [F472, F547]
- `inet6_compat_routing_ioctl()` must copy `compat_in6_rtmsg` field-by-field (`rtmsg_info` size differs). `FRA_DSCP`/`FRA_DSCP_MASK` use unshifted 6-bit values (`<< 2` / `>> 2` with `inet_dsfield_to_dscp`/`inet_dscp_to_dsfield`) and are mutually exclusive with `frh->tos`. In `inet6_fill_ifla6_attrs()`, `RTEXT_FILTER_SKIP_STATS` must only skip `inet6_fill_ifla6_stats_attrs()`, still emitting `TOKEN`, `ADDR_GEN_MODE`, and `RA_MTU`. [F473, F475, F536]

## Known Pitfalls
- In `addrconf_gre_config()`, do not call `addrconf_addr_gen()` when `*(__be32 *)dev->dev_addr == 0` and `addr_gen_mode == IN6_ADDR_GEN_MODE_EUI64` (fall back to `add_v4_addrs()`). In `__ipv6_dev_get_saddr()`, swapping `hiscore` and `score` requires restoring `score->ifa = hiscore->ifa` for the `list_for_each_entry_rcu()` cursor. [F440, F442]
- `__addrconf_sysctl_register()` must rebase `table[i].data` by `(char *)p - (char *)&ipv6_devconf` and only set `extra1`/`extra2` when both are `NULL`. `__snmp6_fill_statsdev()`/`__snmp6_fill_stats64()` must use `put_unaligned()`/`memcpy()` for 4-byte-aligned netlink buffers and `snmp_get_cpu_field64()` for per-CPU stats. [F449, F527]
- In `addrconf.c`: `rfc3315_s14_backoff_init()`/`update()` must cast to `u64` before multiplying and use `do_div(tmp, 1000000)`; `ipv6_create_tempaddr()` must guard `idev->desync_factor %= max_desync_factor` with `if (max_desync_factor > 0)`; `check_cleanup_prefix_route()` and `addrconf_verify_rtnl()` must compare `jiffies` deadlines with `time_before()`. [F499, F501, F505]
- Inbound `exthdrs.c` handlers mutating headers (`ipv6_dest_hao`, `ipv6_srh_rcv`, `ipv6_rthdr_rcv`, `ipv6_hop_ioam`) must unshare SKBs (`pskb_expand_head`/`skb_ensure_writable`) and refresh cached header pointers. On `IFF_LOOPBACK` (`goto looped_back`), `ipv6_srh_rcv()` and `ipv6_rpl_srh_rcv()` must `skb_pull(skb, sizeof(struct ipv6hdr))` to undo `skb_push()`. [F455, F457]
