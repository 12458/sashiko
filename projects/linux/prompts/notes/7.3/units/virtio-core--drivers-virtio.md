# VIRTIO CORE — drivers/virtio

`drivers/virtio` provides the Virtio bus driver, virtqueue ring layouts (split, packed, in-order), transport drivers (PCI modern/legacy/admin, MMIO, vDPA), Virtio RTC, dma-buf helpers, and debugfs feature filtering.

## Architecture & Data Flow
- Update `struct virtqueue_ops` across all four tables (`split_ops`, `packed_ops`, `split_in_order_ops`, `packed_in_order_ops`); outside `VIRTQUEUE_CALL()` / `VOID_VIRTQUEUE_CALL()`, use `virtqueue_is_packed(vq)` or `virtqueue_is_in_order(vq)`. [F260, F295]
- Split rings require `is_power_of_2(num)` and mask indices with `& (vring.num - 1)`. Packed rings allow non-power-of-2 sizes (wrapping via `>= vring.num`) and initialize avail/used wrap counters to `1` (`avail_used_flags = 1 << VRING_PACKED_DESC_F_AVAIL`) with zeroed flags on init, reset, and `virtio_vdpa_setup_vq()`. [F277, F320]
- In `virtqueue_add_split()`, `n`, `sg_count`, and cursor `i` continue across the `out_sgs` and `in_sgs` loops without resetting; at `vq->num_added == (1 << 16) - 1`, call `virtqueue_kick(&vq->vq)`. `virtqueue_detach_unused_buf_split()` must decrement `avail_idx_shadow` and write `vring.avail->idx`. [F255, F300, F316]
- In `virtqueue_add_packed()`, `vring.desc` is indexed by `i` (from `next_avail_idx`) while `desc_extra` is indexed by `curr` (`desc_extra[curr].next` from `free_head`); `unmap_release` must reset and advance both in parallel. [F301]
- `desc_state[head].indir_desc` holds either the indirect table (`vq->indirect`) or caller `ctx` (`!vq->indirect`, `BUG_ON(ctx && vq->indirect)`). In `alloc_indirect_{split,packed}()`, `desc_extra[head/id].len` stores only `total_sg * sizeof(*desc)` so `len / sizeof(*desc)` locates the trailing `vring_desc_extra` array. [F246, F322]
- In `virtqueue_get_buf_ctx_{split,packed}_in_order()`, `vq->batch_last.id` caches the batch end ID and resets to `UINT_MAX` only when `last_used == vq->batch_last.id`, while earlier descriptors take `*len` from `desc_state[last_used].total_in_len`. `virtqueue_get_{desc,avail,used}_addr()` require `vq->we_own_ring`, computing split avail/used addresses via `(char *)avail/used - (char *)desc + queue_dma_addr`. [F257, F325]
- In `virtio_dev_probe()`, restore transport features `[VIRTIO_TRANSPORT_F_START, VIRTIO_TRANSPORT_F_END)` into `dev->features_array` after `virtio_debug_device_filter_features(dev)`, and re-run `finalize_features(dev)` if `drv->validate(dev)` alters `features_array`. [F262]
- `virtio_device_{freeze,reset_prepare}()` save `dev->failed = get_status(dev) & VIRTIO_CONFIG_S_FAILED` so `virtio_device_restore_priv()` re-applies it. `virtio_pci_freeze()` calls `pci_disable_device()` only on success; `virtio_pci_{restore,reset_done}()` call `pci_enable_device()` and `pci_set_master()` before `virtio_device_{restore,reset_done}()`. `virtio_mmio_restore()` writes `PAGE_SIZE` to `VIRTIO_MMIO_GUEST_PAGE_SIZE` on v1 before `virtio_device_restore()`. [F263, F357, F358]
- In `virtio_pci_modern`, `mdev->device` is optional: `vp_modern_probe()` uses `virtio_pci_config_nodev_ops` when `NULL`, `vp_modern_remove()` checks `mdev->device` before `pci_iounmap()`, and any `virtio_config_ops` change (except `.get`/`.set`) must update both `virtio_pci_config_ops` and `virtio_pci_config_nodev_ops`. `del_vq()` calls `pci_iounmap(vq->priv)` only when `!mdev->notify_base`. [F235, F236, F268]
- In `vp_find_vqs_{msix,intx}()`, `vm_find_vqs()`, and `virtio_vdpa_find_vqs()`, when `vqs_info[i].name` is `NULL`, set `vqs[i] = NULL` without incrementing `queue_idx`, and index `vp_dev->vqs` / `set_vq_affinity` by `queue_idx`. In `vp_find_one_vq_msix()`, check `!callback` before `vector_policy` (`VIRTIO_MSI_NO_VECTOR`, no `*allocated_vectors` increment). Exempt `vp_is_avq()` from `index >= vp_modern_get_num_queues(mdev)` in `setup_vq()` and use `vp_dev->admin_vq.info` in `vp_del_vqs()`. [F272, F294, F299]
- `vp_interrupt()` reads `vp_dev->isr` once (read-to-clear) and returns `IRQ_HANDLED` if non-zero. `vp_legacy_probe()` binds `0x1000..0x103f` (`revision == VIRTIO_PCI_ABI_VERSION`); `vp_modern_probe()` binds `0x1000..0x107f`. Legacy MMIO v1 and PCI legacy cap DMA masks at `32 + PAGE_SHIFT` / `32 + VIRTIO_PCI_QUEUE_ADDR_SHIFT`, reject `q_pfn >> 32` with `-E2BIG`, and legacy PCI `vp_finalize_features()` asserts `(u32)vdev->features == vdev->features`. [F310, F347, F348, F350]
- `vp_modern_admin_cmd_exec()` zero-allocates `va_status` as first in-sg, and `vp_modern_avq_done()` sets `cmd->result_sg_size = len - sizeof(*va_status)` (or `0`). `virtio_pci_admin_has_{dev_parts,legacy_io}()` require `(supported_cmds & BITMAP) == BITMAP`, and `virtio_pci_admin_legacy_io_notify_info()` bounds iteration by `VIRTIO_ADMIN_CMD_MAX_NOTIFY_INFO` and stops at `VIRTIO_ADMIN_CMD_NOTIFY_INFO_FLAGS_END`. [F288, F291, F329]
- `viortc_ptp_register()` copies `viortc_ptp_info_template` into `vio_ptp->ptp_info` before mutating it. `viortc_restore()` calls `del_vqs(dev)` before `viortc_init_vqs(viortc)` (which clamps `num_alarmq_bufs = min(num_elems, num_alarmq_bufs)` when `alarmq_bufs` is preallocated) and calls `__viortc_remove(viortc)` on error before `virtio_device_ready(dev)`. [F269, F270, F356]

## Synchronization
- If `VIRTIO_F_ORDER_PLATFORM` is set, `__vring_new_virtqueue_{split,packed}()` must set `vq->weak_barriers = false`. `virtqueue_add_split()` orders descriptors and `avail->ring[avail]` with `virtio_wmb(vq->weak_barriers)` before `avail->idx`; `virtqueue_add_packed*()` writes `desc[head].flags` last after `virtio_wmb(vq->weak_barriers)`. [F206, F207, F377]
- `virtqueue_kick_prepare_{split,packed}()` require `virtio_mb(vq->weak_barriers)` before reading event suppression fields. `virtqueue_enable_cb_{prepare,delayed}_packed()` (when `vq->event`) order `driver->off_wrap` before `driver->flags` with `virtio_wmb()`; `virtqueue_poll()` and `virtqueue_enable_cb_delayed_{split,packed}()` require `virtio_mb()` / `virtio_store_mb()` before polling used buffers. `virtqueue_get_buf_ctx_*()` require `virtio_rmb(vq->weak_barriers)` after polling `used->idx` or `desc[idx].flags` before reading `id`/`len`. [F209, F210, F211, F212]
- Hold `dev->vqs_list_lock` when mutating `dev->vqs` or iterating it in `virtio_break_device()` / `__virtio_unbreak_device()`, using `WRITE_ONCE`/`READ_ONCE` on `vq->broken`. `virtio_reset_device()` (with `CONFIG_VIRTIO_HARDEN_NOTIFICATION`) and `virtio_device_shutdown()` must call `virtio_break_device(dev)` and `virtio_synchronize_cbs(dev)` before `dev->config->reset(dev)`. [F214, F217]
- Serialize `config_core_enabled`, `config_driver_disabled`, `config_change_pending`, and `drv->config_changed(dev)` under `dev->config_lock` (IRQs disabled); `virtio_config_{driver,core}_enable()` must flush pending changes via `__virtio_config_changed(dev)` under the lock. Enable core config only after `probe`/`restore`/`reset_done` and `VIRTIO_CONFIG_S_DRIVER_OK`; disable before `remove`/`freeze`/`reset_prepare`. [F215, F216, F261]
- Protect `vp_dev->virtqueues` and `slow_virtqueues` with `vp_dev->lock` (`spin_lock_irqsave`): set `info->vq` before `list_add` in `vp_setup_vq()`; in `vp_modern_disable_vq_and_reset()`, reset in HW, `list_del` under `vp_dev->lock`, set `vq->reset = true`, `__virtqueue_break(vq)`, and `synchronize_irq()` (paired with `vp_modern_enable_vq_after_reset()`); in `vp_del_vq()`, `list_del` under `vp_dev->lock` only if `!vq->reset` before `vp_dev->del_vq(info)`. When `per_vq_vectors` is true, `vp_del_vqs()` must call `free_irq(irq, vq)` before `vp_del_vq(vq, info)`. [F218, F219, F220, F265]
- In `vp_reset()`, after writing `0` to status, poll `vp_modern_get_status(mdev)` until `0` before `vp_modern_avq_cleanup(vdev)` (which detaches unused buffers, sets `cmd->ret = -EIO`, and completes `cmd->completion`) and `vp_synchronize_vectors(vdev)`. Serialize admin VQ ops in `virtqueue_exec_admin_cmd()` and `vp_modern_avq_done()` under `spin_lock_irqsave(&admin_vq->lock, flags)`, calling `init_completion()` before `virtqueue_add_sgs()`; on `-ENOSPC`, drop `admin_vq->lock` and re-check `virtqueue_is_broken(vq)` before retrying. [F198, F221, F222, F303]
- In `viortc_probe()`, call `virtio_device_ready(vdev)` after `viortc_init_vqs()` and finish `viortc_clocks_init()` before `viortc_populate_vq(..., true)` (holding `alarm_viortc_vq->lock` around `virtqueue_kick_prepare()`) and `virtqueue_notify()`. `viortc_do_cb()` drops `viortc_vq->lock` before `handle_buf()`, and `viortc_alarmq_hdlr()` jumps to `feed_vq` on error to re-queue under lock. `viortc_class->stopped` is protected by `rtc_lock`, and runtime requests must pass `VIORTC_MSG_TIMEOUT` (not `0`) to `viortc_msg_xfer()`. [F225, F226, F304, F340, F365, F368]

## Object Lifetimes
- After `register_virtio_device()` calls `device_initialize(&dev->dev)`, release `dev` on error via `put_device(&dev->dev)`, never `kfree()`. In `unregister_virtio_device()`, all `dev` accesses precede `device_unregister(&dev->dev)`; callers touching the wrapper afterward must hold `get_device()`/`put_device()`. `virtio_device_of_init()` must `of_node_put(np)` if incompatible, or release `dev->dev.of_node` on `device_add()` failure and in `virtio_dev_remove()`. [F190, F191, F349]
- Transport `del_vqs` (`vp_del_vqs()`, `vm_del_vqs()`, `virtio_vdpa_del_vqs()`) must use `list_for_each_entry_safe()` on `&vdev->vqs`. `vp_del_vqs()` must reset `per_vq_vectors`, `intx_enabled`, `msix_enabled`, `msix_vectors`, and `msix_used_vectors` to `0`/`false` and `msix_names`, `msix_affinity_masks`, and `vqs` to `NULL`. `vm_del_vqs()` must call `disable_irq_wake(irq)` and clear `vm_dev->wake_irq_enabled` before `free_irq()`, and `vm_cmdline_parent` must be unregistered via `root_device_unregister()` after all children. [F194, F297, F343, F355]
- For `premapped` buffers, `extra[...].addr` is `DMA_MAPPING_ERROR` so `vring_need_unmap_buffer()` skips them, whereas indirect tables (`VRING_DESC_F_INDIRECT`) are unmapped whenever `vq->use_map_api` is true. Pass `vring_free_queue()` the exact byte size passed to `vring_alloc_queue()`. Data buffers (and `viortc_msg`, `req`, `resp` across waits in `viortc_msg_xfer()`) must be heap-allocated in non-vmalloc lowmem. [F200, F326, F331]
- In `virtio_pci_admin_obj_{create,destroy}()`, free IDs from `ida_alloc_range(&avq->dev_parts_ida, ...)` via `ida_free()` on create error, and in destroy only when `vp_modern_admin_cmd_exec()` succeeds (`!ret`). `viortc_msg_init()` sets `refcnt = 2`; if `virtqueue_add_sgs()` fails in `viortc_msg_xfer()`, call `viortc_msg_release(msg)` once. In `viortc_clocks_deinit()`, clear `clocks_to_unregister[i] = NULL` before `viortc_ptp_unregister()`, and run `viortc_clocks_deinit()` before `virtio_reset_device()` and `del_vqs()`. [F199, F204, F205]

## API Contracts
- Externally serialize all ops on a virtqueue except `virtqueue_notify`, `virtqueue_disable_cb`, `virtqueue_poll`, and `virtqueue_get_vring_size`. Externally serialize `virtio_pci_admin_*` calls per VF `pci_dev`. [F213, F227]
- `virtio_has_feature()` takes a bit index (`0..VIRTIO_FEATURES_BITS - 1`), calling `BUG()` if a device feature is missing from `feature_table*`. Register drivers via `register_virtio_driver()` with non-NULL `feature_table` when `feature_table_size > 0`. `drv->remove` must reset the device (`get_status(dev) == 0`), `virtio_dev_shutdown()` calls `drv->shutdown` instead of `virtio_device_shutdown(dev)` when set, and `vp_set_status()` / `vm_set_status()` call `BUG_ON(status == 0)`. [F230, F240, F337, F338, F379]
- `virtio_config_driver_{disable,enable}()` use `spin_lock_irq(&dev->config_lock)` (process context, IRQs enabled, no nesting). `virtio_add_status()`, `virtio_features_ok()`, and `config->reset` may sleep. [F360, F361]
- `vring_create_virtqueue*()` and `vring_new_virtqueue()` return `NULL` on error, while transport `setup_vq` helpers return `ERR_PTR(-errno)`. `virtio_pci_vf_get_pf_dev()` returns `NULL` on error. `viortc_ptp_register()` returns `ERR_PTR` on error or `NULL` if disabled, while `viortc_class_{init,from_dev}()` always return `ERR_PTR` on failure. `vp_{modern,legacy}_{config,queue}_vector()` return `VIRTIO_MSI_NO_VECTOR` (`0xffff`) on failure (convert to `-EBUSY`). [F232, F237, F238, F244]
- `vdev->map` (`struct virtio_map_ops`) must populate all nine callbacks, and `sync_single_for_{cpu,device}` take `addr + offset` pre-added as `map_handle`. Modern PCI `vp_{get,set}()` (`BUG_ON(offset + len > mdev->device_len)`) and MMIO v2+ `vm_{get,set}()` only allow `len` of 1, 2, 4, or 8. `virtio_dma_buf_export()` requires `ops->attach == &virtio_dma_buf_attach` and `get_uuid != NULL` (checked via `is_virtio_dma_buf()`), and `viortc_ptp_getcrosststamp()` must run `viortc_ptp_do_xtstamp()` before `get_device_system_crosststamp()`. [F243, F252, F284, F369, F381]

## Error Handling
- In `virtio_dev_probe()`, `register_virtio_device()`, and `virtio_device_restore_priv()`, set `VIRTIO_CONFIG_S_FAILED` via `virtio_add_status()` on failure after reset/status ack. In `virtio_device_{freeze,reset_prepare}()`, call `virtio_config_core_enable(dev)` if the driver callback fails. Validate feature bit `< VIRTIO_FEATURES_BITS` (`< 64` for legacy) before setting/clearing. [F192, F229, F289]
- In `vp_find_one_vq_msix()`, call `vp_del_vq(vq, *p_info)` if `request_irq()` fails after `vp_setup_vq()`. Call `vp_modern_set_queue_enable(..., true)` in `vp_modern_find_vqs()` only after `vp_find_vqs()` succeeds for all queues. [F193, F197]
- In `virtqueue_resize_{split,packed}()`, do not `vring_free()` the old vring until all new allocations succeed; on failure, call `virtqueue_reset_{split,packed}()`. On `unmap_release` in `virtqueue_add_packed*()`, restore `avail_used_flags`/`avail_wrap_counter` and stamp `unpub_flags` (opposite wrap `AVAIL | USED`) onto `desc[i].flags` for `i != head`. In `virtqueue_get_buf_ctx_{split,packed}()`, validate `id < vring.num` and `desc_state[id].data != NULL` (`BAD_RING()` otherwise). [F203, F248, F276]
- Validate BAR bounds/overflow/alignment in `vp_modern_map_capability()` and `vp_get_shm_region()`, `mdev->common_len >= offsetofend(...)` in `vp_check_common_size()`, 64-bit `(u64)off * notify_offset_multiplier + 2 <= notify_len` in `vp_modern_map_vq_notify()`, and `avq->max_dev_parts_objects != 0` before `ida_alloc_range()` in `virtio_pci_admin_obj_create()`. In `virtio_rtc`, validate response/notification lengths in `viortc_msg_xfer()` and `viortc_alarmq_hdlr()`, cap device `u64` ns timestamps at `KTIME_MAX`/`S64_MAX` in `virtio_rtc_ptp.c`, and check `alarm_time_sec >= 0` and `check_mul_overflow()` in `viortc_class_set_alarm()`. [F275, F280, F281, F282, F283, F286, F287, F311]

## External Contracts
- PCI admin capability commands use `VIRTIO_ADMIN_GROUP_TYPE_SELF`; SR-IOV member commands use `VIRTIO_ADMIN_GROUP_TYPE_SRIOV` with 1-based `group_member_id = cpu_to_le64(vf_id + 1)`. `vm_cmdline_set()` must return `-EINVAL` if `processed < 2`, `str[consumed] != '\0'`, or `irq == 0`. [F233, F290]

## Known Pitfalls
- `virtqueue_poll()` returns `true` when used buffers are pending (`false` if broken), whereas `virtqueue_enable_cb*()` returns `false` when used buffers are pending (`true` if empty or broken). [F250]
- Packed `vq->last_used_idx` includes the wrap bit at `VRING_PACKED_EVENT_F_WRAP_CTR`; strip it with `packed_last_used()` before indexing arrays. In `virtqueue_kick_prepare_packed()`, subtract `vring.num` from `event_idx` when `wrap_counter != avail_wrap_counter` before `vring_need_event()`. [F278, F319]
- Cast index differences to `u16` in `virtqueue_enable_cb_delayed_split()`. Access `used->ring[num]` (`avail_event_idx`) via `(__virtio16 *)`, never as `struct vring_used_elem`. Map scatterlists per-entry via `virtqueue_map_page_attrs()`, not `dma_map_sg()`. [F317, F324, F374]
- In `vp_finalize_features()`, save `vdev->features` before `vring_transport_features(vdev)` clears non-ring transport bits, then pass it to `vp_transport_features()`. Widen `vp_ioread32()` to `u64` before shifting by `32 * (i & 1)` in `vp_modern_get_*extended_features()`. Use `sizeof(*vp_dev->msix_names)` for the 256-byte name arrays, keep `avq->name` within `char name[10]` (`"avq.%u"`), and use `div_u64(..., NSEC_PER_SEC)` in `virtio_rtc_class.c`. [F296, F307, F315, F332]
