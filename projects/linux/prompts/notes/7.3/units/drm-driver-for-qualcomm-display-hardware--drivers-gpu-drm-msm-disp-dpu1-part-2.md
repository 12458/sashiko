# DRM DRIVER for Qualcomm display hardware — drivers/gpu/drm/msm/disp/dpu1 (part 2)

This unit implements physical encoder backends (`dpu_encoder_phys_{vid,cmd,wb}`), format descriptors (`dpu_formats`), hardware catalog tables (`dpu_hw_catalog`), interrupt controller (`dpu_hw_interrupts`), and low-level DPU hardware block drivers (`dpu_hw_*`).

## Architecture & Data Flow
- `struct dpu_hw_blk base` must stay at offset 0 of `struct dpu_hw_mixer` because `dpu_rm_init` checks only `IS_ERR(hw)` after `dpu_hw_lm_init` and assigns `&hw->base`, relying on `&hw->base == NULL` when `hw == NULL`. [F147]
- `dpu_encoder_phys_vid_init` allocates only `sizeof(struct dpu_encoder_phys)`, so `to_dpu_encoder_phys_cmd` and `to_dpu_encoder_phys_wb` require `intf_mode` to be `INTF_MODE_CMD` or `INTF_MODE_WB_LINE`. [F239]
- `dpu_encoder_phys_vid_enable` sets `enable_state = DPU_ENC_ENABLING` and defers `enable_timing(phys_enc->hw_intf, 1)` and `enable_state = DPU_ENC_ENABLED` until `dpu_encoder_phys_vid_handle_post_kickoff` after CTL flush. [F190]
- On kickoff timeout, `_dpu_encoder_phys_{cmd_handle_ppdone,wb_handle_wbdone}_timeout` must decrement `pending_kickoff_cnt`, set `enable_state = DPU_ENC_ERR_NEEDS_HW_RESET`, and increment the timeout counter (reset to `0` on a successful wait). [F189]
- `dpu_encoder_phys_cmd_enable_helper` calls `update_pending_flush_intf` unconditionally for master and slave; `dpu_encoder_phys_vid_enable` skips slave INTF flush only when `dpu_encoder_phys_vid_needs_single_flush(phys_enc)` is true. In video/WB encoders (`dpu_encoder_phys_vid_{setup_timing_engine,enable}`, `dpu_encoder_phys_wb_setup_ctl`, `_dpu_encoder_phys_wb_update_flush`), set `intf_cfg.merge_3d` and call `update_pending_flush_merge_3d` only when both `dpu_encoder_helper_get_3d_blend_mode(phys_enc)` and `phys_enc->hw_pp->merge_3d` are non-zero/non-NULL. [F249, F253]
- In `dpu_encoder_phys_vid_setup_timing_engine` and `drm_mode_to_intf_timing_params`: apply split, `DRM_FORMAT_YUV420`, DP widebus, and DSC adjustments to local copies without mutating `phys_enc->cached_mode`; query `timing->wide_bus_en` via `dpu_encoder_is_widebus_enabled(phys_enc->parent)` before `INTF_DP` adjustments and only shift porches / halve horizontal timings when `wide_bus_en` is true; and force `hsync_polarity = vsync_polarity = 0` when `type == INTF_DSI`. [F191, F250, F251]
- Tearcheck ops live on `dpu_hw_pingpong` (`core_major_ver < 5`) or `dpu_hw_intf` (`INTF_DSI` only, `core_major_ver >= 5`); `dpu_encoder_phys_cmd` must check `phys_enc->has_intf_te` before selecting TE ops or `INTR_IDX_RDPTR`. `dpu_hw_{intf,pp}_disable_autorefresh` must disconnect external TE, clear autorefresh enable, poll `wr_ptr_line_count` (`KICKOFF_TIMEOUT_MS`) until `0 < wr_ptr_line_count < vdisplay` is false, and reconnect TE. [F254, F255]
- Every `dpu_hw_ctl_update_pending_flush_*_v1` helper (and `dspp_sub_blocks`) must set both `ctx->pending_*_flush_mask` and its summary `BIT(*_IDX)` in `ctx->pending_flush_mask`. `dpu_hw_ctl_intf_cfg_v1` must update `CTL_{INTF,WB,CWB,DSC,MERGE_3D}_ACTIVE` via read-modify-write. `dpu_hw_ctl_reset_intf_cfg_v1` must invoke all implemented staging callbacks (`clear_all_blendstages`, `set_active_{lms,fetch_pipes,pipes}`) with `NULL` and mask off only the `CTL_*_ACTIVE` bits specified in `cfg`. [F183, F184, F185]
- In `dpu_hw_ctl`, `CTL_LAYER(lm)` maps `LM_5` to `0x024` (not `0x014`, which is `CTL_TOP`), and `dpu_hw_ctl_setup_blendstage` writes `mixercfg[4]` to `CTL_LAYER_EXT4(lm)` only when `core_major_ver >= 9`. Pipes with `cfg->idx == 0` in `ctl_blend_config` use 3-bit stage fields (`(i + 1) & 0x7`) in `CTL_LAYER` plus overflow `mixercfg[1] |= (i >= 7) << cfg->ext_shift` in `CTL_LAYER_EXT`, whereas `cfg->idx > 0` takes 4-bit `((i + 1) & 0xf) << cfg->shift` (skip when `cfg->idx == -1`). [F210, F225]
- In `struct dpu_lm_sub_blks`, `maxblendstages` excludes `DPU_STAGE_BASE` (`0`) and `blendstage_base[]` is 0-indexed from `DPU_STAGE_0` (`1`), so `_stage_offset` requires `DPU_STAGE_0 <= stage <= sblk->maxblendstages` and indexes `blendstage_base[stage - DPU_STAGE_0]`, whereas `dpu_hw_stage_cfg` arrays are indexed directly by `enum dpu_stage`. Also, `dpu_hw_lm_setup_out` and `dpu_hw_lm_setup_color3` (DPU < 12) share `LM_OP_MODE` (`BIT(31)` vs `BIT(31)|BIT(30)`) and must read-modify-write. [F195, F202]
- When `pipe->multirect_index != DPU_SSPP_RECT_SOLO`, `dpu_hw_sspp_setup_{multirect,sourceaddress}` must read-modify-write `SSPP_MULTIRECT_OPMODE` and `SSPP_SRC_YSTRIDE{0,1}` to preserve the sibling rect's bits. In `_dpu_hw_setup_scaler3_lut`, reset `lut_offset = 0` per `filter` (`QSEED3_FILTERS`), not inside the inner `QSEED3_LUT_REGIONS` loop (`lut_addr` is recomputed per region). [F192, F213]
- `irq_idx` in `dpu_hw_interrupts` is 1-based (`1`..`DPU_NUM_IRQS`, `0` invalid): `DPU_IRQ_IDX` adds 1, `DPU_IRQ_REG`/`DPU_IRQ_BIT` subtract 1, and `dpu_core_irq_get_entry` indexes `irq_tbl[irq_idx - 1]`. In `dpu_core_irq`, the `while ((bit = ffs(irq_status)) != 0)` loop must use `bit - 1` for both `DPU_IRQ_IDX(reg_idx, bit - 1)` and `irq_status &= ~BIT(bit - 1)` on every path. [F196, F211]
- In `enum dpu_hw_intr_reg`, `MDP_INTF0_INTR`..`MDP_INTF8_INTR` must stay contiguous and in sync with `dpu_intr_set_{legacy,7xxx}` and `MDP_INTR_MAX`. In `dpu_core_irq_{preinstall,uninstall}`, bracket `dpu_clear_irqs` and `dpu_disable_all_irqs` with `pm_runtime_{get,put}_sync(&dpu_kms->pdev->dev)`. Because `DPU_REG_{WRITE,READ}` use relaxed MMIO, IRQ register writes in `dpu_hw_interrupts.c`, `dpu_hw_setup_wd_timer`, and `dpu_hw_setup_misr` (between `MISR_CTRL_STATUS_CLEAR` and `MISR_CTRL_ENABLE`) require an explicit `wmb()`. [F187, F243, F245]
- In `_setup_mdp_ops`, `ops->setup_vsync_source` is `dpu_hw_setup_vsync_sel` (`core_major_ver < 5`), `dpu_hw_setup_wd_timer` (`5 <= core_major_ver < 8`), and `NULL` (`core_major_ver >= 8`). [F256]
- `_dpu_format_populate_plane_sizes_{ubwc,linear}` must `memset` `struct dpu_hw_fmt_layout` to 0 upfront (`total_size` sums all `DPU_MAX_PLANES` and `_dpu_format_populate_addrs_ubwc` reads `plane_size[2..3]` even when `!meta`). Linear non-interleaved formats must get non-zero `h_subsample`/`v_subsample` from `_dpu_get_v_h_subsample_rate` and reject `fb->width % h_subsample || fb->height % v_subsample` with `-EINVAL` before dividing. [F232, F235]
- In `struct dpu_hw_fmt_layout`, UBWC/tiled bitstream planes use indices `0` (Y/RGB) and `1` (CbCr) while metadata planes use `2` and `3`. `dpu_format_populate_addrs` stores 32-bit device IOVAs into `plane_addr[]` for `SSPP_SRC*_ADDR`/`WB_DST*_ADDR`, never CPU pointers. [F204, F267]
- In `struct dpu_qos_lut_tbl`, non-zero fill levels `fl` must be sorted ascending with any `fl == 0` default entry last (`entries[nentry - 1]`). In `dpu_hw_vbif`, `dpu_hw_set_qos_remap` locates `VBIF_XINL_QOS_LVL_REMAP_000` at `VBIF_XINL_QOS_RP_REMAP_000 + qos_rp_remap_size`, so catalog `qos_rp_remap_size` must equal `8 * npriority_lvl`. In `dpu_hw_catalog.c`, VIG SSPPs lacking CSC (`_VIG_SBLK_NOSCALE()` / `dpu_vig_sblk_noscale`) must use `plane_formats` (RGB only), not `plane_formats_yuv`. [F203, F207, F258]

## Synchronization
- Lock order is `phys_enc->vblank_ctl_lock` -> `dpu_kms->hw_intr->irq_lock` -> `phys_enc->enc_spinlock`. Because `dpu_core_irq` holds `irq_lock` across callbacks, never call `dpu_core_irq_*` under `enc_spinlock` or take `vblank_ctl_lock` in an IRQ callback. Process-context acquisitions of `irq_lock` and `enc_spinlock` must use `spin_lock_irqsave`, and `dpu_hw_intr_{enable,disable}_irq_locked` (plus `cache_irq_mask[]`/`irq_tbl[]` updates) require holding `intr->irq_lock`. [F158, F160, F265]
- `dpu_encoder_phys_vid_vblank_irq` must hold `enc_spinlock` while checking `!(get_flush_register(hw_ctl) & get_pending_flush(hw_ctl))` and decrementing `pending_kickoff_cnt`. In `dpu_encoder_phys_vid_disable`, after `enable_timing(phys_enc->hw_intf, 0)` under `enc_spinlock`, a master encoder must call `dpu_encoder_phys_inc_pending` and `dpu_encoder_phys_vid_wait_for_tx_complete` before `dpu_encoder_helper_phys_cleanup`. [F162, F163]
- `dpu_hw_ctl_{reset_control,wait_reset_status}` (`ctl->ops.{reset,wait_reset_status}`) sleep via `usleep_range` in `dpu_hw_ctl_poll_reset_status`; never call them in atomic context or under `enc_spinlock`. [F266]

## Object Lifetimes
- All `dpu_hw_*_init` and `dpu_encoder_phys_*_init` constructors allocate with `drmm_kzalloc`; never pass returned pointers to `kfree()`. [F145]
- Each 1-based `irq_idx` in `irq_tbl` holds at most one callback (`dpu_core_irq_register_callback` returns `-EBUSY` if `irq_entry->cb` is set); `dpu_core_irq_unregister_callback` must disable the IRQ and clear `cb` and `arg` to `NULL` under `irq_lock`. Toggle `INTR_IDX_{RDPTR,VSYNC}` only via `dpu_encoder_phys_{cmd,vid}_control_vblank_irq` under `vblank_ctl_lock` (skipping slaves and registering/unregistering on `0 <-> 1` transitions of `vblank_refcount`), and pair `dpu_encoder_phys_wb_irq_{enable,disable}` symmetrically around `wbirq_refcount` (`0 <-> 1`). [F148, F149, F150]
- `dpu_encoder_phys_wb_{prepare,cleanup}_wb_job` must pair `msm_framebuffer_prepare(job->fb, false)` with `msm_framebuffer_cleanup(job->fb, false)` when `job->fb` is non-NULL, and cleanup must clear `wb_enc->wb_job` and `wb_enc->wb_conn` to `NULL`. [F271]

## API Contracts
- `dpu_hw_{lm,intf}_init` return `NULL` for `PINGPONG_NONE`/`INTF_NONE` and `ERR_PTR(-ENOMEM)` on alloc failure (all other `dpu_hw_*_init` return only `ERR_PTR`); callers must check both `IS_ERR` and `NULL`. [F165]
- Callbacks for `dpu_core_irq_register_callback` and `dpu_encoder_helper_wait_for_irq` must have signature `void (*)(void *arg)` and cast `arg` inside the body. Once `dpu_encoder_phys_wb_prepare_for_kickoff` queues a job, both `dpu_encoder_phys_wb_done_irq` and `_dpu_encoder_phys_wb_handle_wbdone_timeout` must call `drm_writeback_signal_completion(wb_enc->wb_conn, 0)` if `wb_enc->wb_conn` is non-NULL. [F241, F270]
- `dpu_hw_clk_force_ctrl` returns `true` only if the bit was previously `0` (`!(reg_val & BIT(bit_off))`); callers (`_dpu_encoder_phys_wb_clk_force_ctrl`) must save `forced_on` and only disable clock force when `forced_on` is `true`. `dpu_hw_ctl_poll_reset_status` returns the raw `CTL_SW_RESET` bit (`0` = done, `1` = timeout), whereas `dpu_hw_ctl_{reset_control,wait_reset_status}` return `0` or `-EINVAL`. [F168, F169]
- NULL-check version-gated ops: `ctl->ops.{clear_all_blendstages,setup_blendstage}` (`core_major_ver < 12`), `ctl->ops.set_active_{pipes,lms}` and `lm->ops.{setup_blendstage,clear_all_blendstages}` (`core_major_ver >= 12`), and `ctl->ops.{reset_intf_cfg,update_pending_flush_{periph,merge_3d,cwb,dsc}}` (`core_major_ver >= 5`). `dpu_hw_pp_setup_dither`, `dpu_setup_dspp_pcc`, `dpu_hw_{ctl,lm}_setup_blendstage`, and `dpu_hw_ctl_set_active_{lms,pipes,fetch_pipes}` treat a `NULL` config pointer as the command to disable/unstage. [F171, F172, F174]
- Zero-init `struct dpu_hw_intf_cfg` (`= { 0 }`) before `{setup,reset}_intf_cfg`. In `dpu_hw_intf_cfg`, `intf`, `intf_master`, `wb`, and `merge_3d` take 1-based enum IDs, whereas `cwb` and `dsc` take bitmasks (`BIT(idx - *_0)`). Conversely, all `dpu_hw_ctl_update_pending_flush_*_v1` callbacks (`wb`, `cwb`, `intf`, `periph`, `merge_3d`, `dsc`, `cdm`) and `dpu_hw_{intf,wb,cdm,dsc}_bind_pingpong_blk{,_1_2}` (`PINGPONG_NONE` = `0` unbinds) take 1-based enum IDs, while `dpu_hw_ctl_set_active_{fetch_pipes,pipes,lms}` take bitmaps indexed by 1-based `enum dpu_sspp` / `enum dpu_lm`. [F177, F179, F180, F200, F201]
- Call `dpu_format_populate_plane_sizes` and check for `0` before `dpu_format_populate_addrs`. For 10-bit CSC (`DPU_SSPP_CSC_10BIT`), pass `csc_blk.base + 0x4` and `csc10 = true` to `dpu_hw_csc_setup`. In `dpu_hw_pp_setup_dither`, `cfg->c{0..3}_bitdepth` index `dither_depth_map[9]` directly (`0..8`). In `dpu_hw_dsc_config_1_2`, `dsc->slice_count` must be `>= 1` (`>= 2` with `DSC_MODE_MULTIPLEX`) for `_dsc_calc_output_buf_max_addr`, and `dsc->bits_per_pixel` must be doubled (`2 * bpp`) for `DSC_MAIN_CONF` when `native_422` or `native_420` is true. [F175, F181, F209, F231, F274]

## Error Handling
- Store `dpu_encoder_helper_wait_for_irq` return values in a signed `int` (`-ETIMEDOUT`, `-EWOULDBLOCK`, `-EINVAL`). `dpu_core_irq_callback_handler` must return early if `!irq_entry->cb` before incrementing `count` or calling `cb`. Always NULL-check optional `phys_enc->hw_cdm` and `phys_enc->hw_pp->merge_3d`. [F166, F167, F173]

## External Contracts
- Catalog format arrays (`plane_formats`, `plane_formats_yuv`, `wb2_formats_rgb_yuv`) must not contain duplicate `DRM_FORMAT_*` entries. [F268]

## Known Pitfalls
- Mask signed fields before shifting/ORing into registers: `dpu_hw_scaler3{,_de}_cfg`, `dpu_hw_pixel_ext` (`0xff`/`0xffff` in `dpu_hw_sspp_setup_pe_config`), and S15.16 `data->csc_mv[i] >> 7` (`& 0x1FFF` in `dpu_hw_csc_setup`); likewise convert/mask `drm_dsc_config` fields like `bits_per_component` (`== 10` or `& 0xf`) in `dpu_hw_dsc_config*`. In `dpu_hw_sspp_setup_pe_config`, `color == 2` is skipped, leaving `lr_pe[2]`, `tb_pe[2]`, and `tot_req_pixels[2]` uninitialized on the stack. [F176, F222, F223, F224, F257]
- In `dpu_hw_setup_scaler3`, when `!scaler3_cfg->enable`, `goto end;` instead of returning early so `QSEED3_OP_MODE` is written. In `_dpu_hw_setup_scaler3{,lite}_lut`, `{dir,cir,sep}_len` are byte sizes, `{cir,sep}_lut` `u32 *` offsets use element counts (`QSEED3{,LITE}_LUT_SIZE`), and `u32 lut_flag` must be copied to an `unsigned long` local before `test_bit()`. [F215, F236, F237]
- In `dpu_hw_ctl.c`, check 1-based block enums for non-zero before `BIT(id - *_0)`, and check `{fetch,lm}_tbl[i] != CTL_INVALID_BIT` (`0xffff`) before `BIT(tbl[i])`. In `dpu_hw_{cdm,wb}_bind_pingpong_blk`, check `pp >= PINGPONG_CWB_0` before `else if (pp)`. Keep QoS `creq_lut` in a `u64` across `_dpu_hw_{get,setup}_qos_lut`. [F212, F221, F230]
- `dsc->bits_per_pixel` is 6.4 fixed-point: use `drm_dsc_get_bpp_int(dsc)` when scaling `timing->width` in `drm_mode_to_intf_timing_params`, but write raw 6.4 `bits_per_pixel` in `dpu_hw_dsc_config*`. In `dpu_hw_intf_setup_timing_engine`, halve `data_width` (`p->width >> 1`) only when `p->wide_bus_en && !dp_intf`. [F227, F228]
- In `programmable_fetch_get_num_lines`, guard `start_of_frame_lines >= worst_case_needed_lines` before unsigned subtraction and clamp to `timing->v_front_porch`. In `dpu_hw_pp_get_line_count`, return `0xFFFF` if `height < init`, and when `line < init` add `0xFFFF - init` instead of subtracting `init`. [F233, F234]
