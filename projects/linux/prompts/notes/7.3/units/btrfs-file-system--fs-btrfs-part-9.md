# BTRFS FILE SYSTEM — fs/btrfs (part 9)

Implements the Btrfs send stream generator (`send.c`), space reservation and async reclaim (`space-info.c`), subpage sector bitmap tracking (`subpage.c`), and VFS superblock/mount handling, `/dev/btrfs-control`, and module init/exit (`super.c`).

## Architecture & Data Flow

- In `struct btrfs_folio_state`, `eb_refs` and `nr_locked` share a union discriminated by `BTRFS_SUBPAGE_METADATA` vs `BTRFS_SUBPAGE_DATA`; only use `btrfs_folio_inc/dec_eb_refs()` on metadata folios and `btrfs_folio_set/end_lock()` on data folios. `btrfs_subpage_set_uptodate/checked()` set the VFS folio flag only when `subpage_test_bitmap_all_set()` is true across all sectors, whereas `btrfs_subpage_clear_uptodate/checked()` clear the VFS flag when any sector bit is cleared. [F1034, F1045]
- Before `btrfs_ioctl_send()` walks commit roots in `send_subvol()`, it must call `flush_delalloc_roots(sctx)` then `ensure_commit_roots_uptodate(sctx)`. In `send.c`, `lookup_backref_cache()` must clear `sctx->backref_cache` when `fs_info->last_reloc_trans > sctx->backref_cache_last_reloc_trans`, and `store_backref_cache()` must record `last_reloc_trans` only when inserting the first entry (`size == 1`). [F1056, F1164]
- `sctx->dir_utimes_cache` must be initialized with `max_size = 0` so `btrfs_lru_cache_store()` never evicts during `cache_dir_utimes()`; pruning happens in `trim_dir_utimes_cache()` at the end of `finish_inode_if_needed()` and on teardown in `btrfs_ioctl_send()`. [F1097]
- In `wait_for_parent_move()`, when an ancestor `ino` is in `sctx->waiting_dir_moves` (`is_waiting_for_move(sctx, ino)`), renaming `sctx->cur_ino` must only be delayed if `sctx->cur_ino` is an ancestor of `ino` in `sctx->parent_root` (`is_ancestor()` returns 1). [F1101]
- In `clone_range()`, when cloning from the file being processed (`clone_root->root == sctx->send_root && clone_root->ino == sctx->cur_ino`), break as soon as `clone_root->offset >= sctx->cur_inode_next_write_offset` so the rest falls back to `send_extent_data()`. When a source clone range ends at `clone_src_i_size`, is unaligned to `SZ_64K`, and the destination ends before `sctx->cur_inode_size`, only clone the `SZ_64K`-aligned prefix and emit `send_extent_data()` for the tail. [F1076, F1103]
- `tree_advance()` must update `*key` from `path->nodes[*level]` even when `tree_move_next_or_upnext()` hits the end of the root node and returns `-1` (with `path->slots[root_level]` clamped to `nritems - 1`), so `restart_after_relocation()` can find the last key. [F1105]
- `struct name_cache_entry::name` is `__counted_by(name_len) __nonstring`; `__get_cur_name_and_parent()` must allocate `sizeof(*nce) + fs_path_len(dest)`, set `nce->name_len` before writing `nce->name`, and bound all reads by `nce->name_len`. [F1123]
- `do_async_reclaim_metadata_space()` increments `flush_state++` from `FLUSH_DELAYED_ITEMS_NR` to `final_state` (`RESET_ZONES` on zoned, `COMMIT_TRANS` otherwise); `enum btrfs_flush_state` order defines reclaim sequence and `RESET_ZONES` must stay after `COMMIT_TRANS`. `btrfs_space_info::clamp` must stay in `[1, 8]` because `need_preemptive_reclaim()` shifts `thresh >>= space_info->clamp`. [F1092, F1107]
- `DECLARE_SPACE_INFO_UPDATE()` guards `bytes_may_use`, `bytes_pinned`, and `bytes_zone_unusable` against unsigned underflow (`WARN_ON(1)` and clamp to 0); never subtract from these fields directly instead of calling `btrfs_space_info_update_*()` under `space_info->lock`. [F1080]
- Superblock RO transitions during remount or error handling must use `btrfs_set_sb_rdonly()` and `btrfs_clear_sb_rdonly()` to keep `SB_RDONLY` and `BTRFS_FS_STATE_RO` in lockstep. `btrfs_unfreeze()` must run `check_dev_super()` on all devices before clearing `BTRFS_FS_FROZEN`, and still return `0` after `btrfs_handle_fs_error()` so the VFS finishes unfreezing. [F1061, F1133]
- Any mount option added to `struct btrfs_fs_context` and `struct btrfs_fs_info` must be copied in both `btrfs_ctx_to_info()` and `btrfs_info_to_ctx()`. In `btrfs_parse_param()` and `btrfs_parse_compress()`, `nodatacow` must clear `COMPRESS`/`FORCE_COMPRESS` and set `NODATACOW`/`NODATASUM`, while `datasum` or any compression mode must clear both `NODATACOW` and `NODATASUM`. [F1062, F1066]

## Synchronization

- In `btrfs_compare_trees()`, release `fs_info->commit_root_sem` before calling `changed_cb()`, after replacing any level-0 leaf in `left_path->nodes[0]` or `right_path->nodes[0]` (and root nodes) under `commit_root_sem` with an unmapped clone via `btrfs_clone_extent_buffer()` or `replace_node_with_clone()`. After re-acquiring `commit_root_sem` in `btrfs_compare_trees()` or `full_send_tree()`, if `fs_info->last_reloc_trans > sctx->last_reloc_trans`, release paths and re-search/re-clone from commit roots via `restart_after_relocation()`. [F1008, F1057]
- In `btrfs_ioctl_send()`, hold `root->root_item_lock` on `send_root`, `sctx->parent_root`, and each `sctx->clone_roots[i].root` to verify `btrfs_root_readonly(root)`, `!btrfs_root_dead(root)`, and `!root->dedupe_in_progress`, and to increment `root->send_in_progress` (paired with `btrfs_root_dec_send_in_progress()` on cleanup). [F1024]
- In subpage mode, `btrfs_folio_inc/dec_eb_refs()` must hold `folio->mapping->i_private_lock` and increment `eb_refs` before radix tree insertion. All `btrfs_folio_state::bitmaps` accesses (and `nr_locked` bit-clearing in `btrfs_subpage_end_and_test_lock()` / `btrfs_folio_end_lock_bitmap()`) must use `spin_lock_irqsave(&bfs->lock)` because endio runs in irq context. [F1010, F1136]
- `btrfs_space_info_update_*()`, ticket list (`tickets`, `priority_tickets`) and `reclaim_size` updates, and `btrfs_try_granting_tickets()` require holding `btrfs_space_info::lock`. [F1013]
- In `btrfs_remount_ro()`, before `btrfs_commit_super()`, synchronously cancel async reclaim, cycle `uuid_tree_rescan_sem`, set `BTRFS_FS_STATE_RO`/`SB_RDONLY`, wait on `BTRFS_FS_CLEANER_RUNNING`, run delayed iputs, and pause/wait on dev-replace, scrub, balance, and qgroup rescan. [F1021]
- In `btrfs_get_tree_super()`, drop `uuid_mutex` before `sget_fc()` (pinning `fs_devices` via `btrfs_fs_devices_inc/dec_holding()`) to avoid `uuid_mutex` vs `sb->s_umount` ABBA deadlock. In `btrfs_sync_fs()`, when `btrfs_attach_transaction_barrier()` returns `-ENOENT` and `BTRFS_FS_NEED_TRANS_COMMIT` is set, probe `sb_start_write_trylock(sb)` (then `sb_end_write(sb)`) and return 0 without starting a transaction if frozen. [F1146, F1147]
- Accessing `fs_devices->latest_dev` and its `rcu_string` name in `btrfs_show_devname()`, or iterating `fs_devices->devices` without `device_list_mutex` in `btrfs_calc_avail_data_space()`, requires `rcu_read_lock()` (and `list_for_each_entry_rcu()`). [F1149]

## Object Lifetimes

- `struct fs_path` starts with `p->buf = p->inline_buf`; `fs_path_ensure_buf()` must `kmalloc()` + `memcpy()` when `p->buf == p->inline_buf` (never `krealloc(p->inline_buf)`), `memmove` reversed paths to the new buffer tail and recompute `p->start`/`p->end`, and `fs_path_free()`/`btrfs_ioctl_send()` must only `kfree(p->buf)` when `p->buf != p->inline_buf`. In `struct recorded_ref`, `ref->name` aliases `ref->full_path->start` (via `set_ref_path()`), so `refresh_ref_path()` must `kmemdup()` `ref->name` before `fs_path_reset()`, and `update_ref_path()` must populate a new `fs_path` before freeing `ref->full_path`. [F1006, F1053, F1120]
- `sctx->cur_inode` (opened in `send_extent_data()`) must be closed via `close_current_inode(sctx)` on inode transitions in `changed_inode()` and on teardown in `btrfs_ioctl_send()`, evicting pages, calling `iput()`, and setting `sctx->cur_inode = NULL`. Pagecache eviction via `truncate_inode_pages_range()` in `send_extent_data()` and `close_current_inode()` must use `PAGE_SIZE`-aligned ranges starting at `sctx->page_cache_clear_start`. [F1007, F1154]
- Multiple `pending_dir_move` entries with the same `parent_ino` chain via `pm->list` onto one rbtree node in `sctx->pending_dir_moves`; `tail_append_pending_moves()` and `btrfs_ioctl_send()` cleanup must detach/free all `pm->list` entries before erasing and freeing `pm`. [F1099]
- `btrfs_dup_fs_context()` increments `ctx->refs` and transfers `src_fc->source` to `fc->source` by setting `src_fc->source = NULL`, while `btrfs_get_tree_subvol()` sets `ctx->subvol_name = NULL` after `mount_subvol()` frees it. [F1065]
- `mod_init_seq` in `init_btrfs_fs()` / `btrfs_exit_btrfs_fs()` must register `/dev/btrfs-control` (`btrfs_interface_init`) and `btrfs_fs_type` (`register_btrfs`) last after all internal caches/sysfs/biosets, and tear down initialized steps in reverse order before `btrfs_cleanup_fs_uuids()`. [F1129]

## API Contracts

- `btrfs_subpage_*()` and non-clamping `btrfs_folio_*()` require `start` and `len` aligned to `fs_info->sectorsize` and within `[folio_pos(folio), folio_end(folio)]`; use `btrfs_folio_clamp_*()` for multi-folio ranges. `btrfs_subpage_clear_and_test_dirty()` does not clear the VFS folio dirty flag; callers must call `folio_clear_dirty_for_io(folio)` when it returns true. [F1035, F1036]
- `get_path_for_command()` returns `ERR_PTR` on error (never NULL), `&sctx->cur_inode_path` when `ino == sctx->cur_ino && gen == sctx->cur_inode_gen`, or a heap `struct fs_path *`; check `IS_ERR()` and release via `free_path_for_command(sctx, p)` rather than `fs_path_free()`. [F1039]
- `put_data_header()` sets `sctx->put_data = true`, and `tlv_put()` / `put_data_header()` fail with `-EINVAL` if `sctx->put_data` is already true; `BTRFS_SEND_A_DATA` must be the last attribute in a command before `send_cmd()` or `send_encoded_extent()` resets `sctx->send_size = 0` and `sctx->put_data = false`. [F1040]
- When `current->journal_info != NULL`, `__reserve_bytes()` and `btrfs_reserve_data_bytes()` must not use `BTRFS_RESERVE_FLUSH_ALL*`, `BTRFS_RESERVE_FLUSH_EVICT`, or `BTRFS_RESERVE_FLUSH_DATA`, `flush_space()` must not run `COMMIT_TRANS`, and `shrink_delalloc()` must not call `btrfs_wait_ordered_roots()`. [F1138, F1139]

## Error Handling

- In `btrfs_reconfigure()`, any failure after `btrfs_ctx_to_info(fs_info, ctx)` and `btrfs_remount_begin()` must jump to `restore:` to revert options from `old_ctx`, run `btrfs_remount_cleanup(fs_info, old_ctx.mount_opt)`, and clear `BTRFS_FS_STATE_REMOUNTING`. [F999]
- Callers of `btrfs_for_each_slot(..., iter_ret)` in `send.c` must check `if (iter_ret < 0)` after the loop and propagate `iter_ret`. [F1041]
- In `record_ref_in_tree()`, `set_ref_path(ref, path)` transfers `path` ownership to `ref->full_path` (freed by `recorded_ref_free(ref)`), so `out:` must only call `fs_path_free(path)` when `(!ref || !ref->full_path)`. In `btrfs_ioctl_send()`, `sctx->parent_root` is assigned from `btrfs_get_fs_root()` before `IS_ERR()` is checked, so `out:` must guard teardown with `!IS_ERR_OR_NULL(sctx->parent_root)`. [F1042, F1043]

## External Contracts

- In `send_cmd()` and `send_encoded_extent()`, zero `hdr->crc` before computing `crc32c(0, ...)` over the command and set `hdr->len` excluding `sizeof(struct btrfs_cmd_header)`. [F1072]
- `btrfs_parse_compress()` must accept `lzo:<level>` (`may_have_level = true`), but `btrfs_show_options()` must omit `:%d` for `BTRFS_COMPRESS_LZO` and must check `SSD_SPREAD` before the `else if` for `SSD`. `btrfs_show_options()` and `btrfs_show_devname()` must escape user paths with `seq_show_option(seq, "subvol", subvol_name)` and `seq_escape(m, ..., " \t\n\\")`. [F1081, F1082, F1088]
- In `btrfs_parse_param()`, `Opt_commit_interval` warns above `BTRFS_WARNING_COMMIT_INTERVAL` and maps `0` to `BTRFS_DEFAULT_COMMIT_INTERVAL`, `Opt_thread_pool` rejects `0` with `-EINVAL`, and `Opt_subvolid` maps `0` to `BTRFS_FS_TREE_OBJECTID`. [F1083]
- `btrfs_control_ioctl()` must check `capable(CAP_SYS_ADMIN)` and `btrfs_check_ioctl_vol_args_path(vol)` before dispatching commands, and convert `NULL` from `btrfs_scan_one_device(..., false)` with `PTR_ERR_OR_ZERO()`. [F1162]

## Known Pitfalls

- `btrfs_ioctl_send()` must reject `arg->clone_sources_count > SZ_8M / sizeof(struct clone_root)` before setting `sctx->clone_roots_cnt` (`int`) and allocating `arg->clone_sources_count + 1` elements. [F1114]
- In `iterate_dir_item()`, growing `buf` must check `is_vmalloc_addr(buf)` and `vfree(buf)` before `kvmalloc()` (never pass vmalloc to `krealloc()`), and `iterate_dir_item_t` callbacks must bound `name`/`data` by `name_len`/`data_len` (not NUL-terminated). `btrfs_get_subvol_name_from_objectid()` builds backwards from `name + PATH_MAX - 1`, must check `ptr < name` after `ptr -= len + 1`, and must use `memmove(name, ptr, name + PATH_MAX - ptr)`. [F1125, F1128]
- `calc_pct_ratio()` must check `check_mul_overflow(100, x, &x)` and clamp `y = 1` when `y >>= 10` becomes `0`. `calc_reclaim_items_nr()` and `btrfs_preempt_reclaim_metadata_space()` must clamp 0 division/shift results to 1 item because passing 0 to `flush_space()` or `btrfs_run_delayed_refs()` means an unbounded flush. Clamp `u64 temp` in `shrink_delalloc()` and `sc->nr_to_scan` in `btrfs_free_cached_objects()` to `LONG_MAX` before converting to signed `long`. [F1108, F1109, F1110]
- In `btrfs_parse_param()`, `Opt_compress_force*` set `FORCE_COMPRESS` and fall through to `btrfs_parse_compress()`, which must only clear `FORCE_COMPRESS` when `opt` is not `Opt_compress_force*` (or type is `"no"`/`"none"`). `Opt_acl` must only set `fc->sb_flags_mask |= SB_POSIXACL` when `fc->purpose != FS_CONTEXT_FOR_RECONFIGURE` (deferring to `btrfs_reconfigure()` on remount). `set_device_specific_options()` must not auto-enable `DISCARD_ASYNC` when `btrfs_is_zoned(fs_info)` or when `DISCARD_SYNC`, `DISCARD_ASYNC`, or `NODISCARD` is set. [F1089, F1132, F1157]
