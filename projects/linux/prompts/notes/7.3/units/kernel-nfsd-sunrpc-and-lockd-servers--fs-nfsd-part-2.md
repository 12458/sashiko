# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd (part 2)

This component provides the NFSD sunrpc service lifecycle (`nfssvc.c`), `/proc/fs/nfsd` and netlink control interfaces (`nfsctl.c`), filehandle verification and encoding (`nfsfh.c`, `nfsfh.h`), the duplicate reply cache (`nfscache.c`), NFSv2 handlers (`nfsproc.c`, `nfsxdr.c`), the NFSv4 XDR compound decoder and encoder (`nfs4xdr.c`, `nfs4xdr_gen.c`), central headers (`nfsd.h`, `state.h`, `pnfs.h`), and statistics (`stats.c`, `stats.h`).

## Architecture & Data Flow
- In `nfsd_dispatch()`, `xdr_stream_pos(&rqstp->rq_arg_stream)` and `xdr_stream_remaining(&rqstp->rq_arg_stream)` must be captured before `proc->pc_decode()` advances `rq_arg_stream` past the Call header checksummed by `nfsd_cache_lookup()`. In `nfsd_cacherep_alloc()`, `rp->c_key` must be zeroed via `memset()` before populating fields because `nfsd_cache_key_cmp()` uses `memcmp()` across the whole struct (including unused IPv4 `sockaddr_in6` bytes and padding). [F381, F404]
- In `nfsd_reply_cache_init()`, `hashsize` is rounded to a power of two via `nfsd_hashsize` (`<= 32768`) with `nn->maskbits = ilog2(hashsize)` (`hashsize == (1U << nn->maskbits)`). In `nfsd_prune_bucket_locked()`, DRC expiration against `rp->c_timestamp` must use `time_before(expiry, rp->c_timestamp)` where `expiry = jiffies - RC_EXPIRE`. [F455, F458]
- In `__fh_verify()`, even when `fhp->fh_dentry` is already populated, `check_pseudo_root()`, `nfsd_setuser_and_check_port()`, `nfsd_mode_check()`, security flavor checks, and `nfsd_permission()` must still run because access flags or export credentials may differ across operations. [F408]
- In `struct knfsd_fh`, `fh_auth_type` (`fh_raw[1]`) must be zeroed by `fh_compose()` and rejected with `nfserr_badhandle` if non-zero in `nfsd_set_fh_dentry()`, and `fh_fsid_type` must map to a non-zero byte length in `key_len()` with at least `1 + key_len(fh->fh_fsid_type) / 4` words in `fh->fh_size / 4`. Every `enum nfsd_fsid` variant must be handled in lockstep in `key_len()`, `mk_fsid()` (calls `BUG()`), `fsid_type_ok_for_exp()`, and `fsid_source()`. [F416, F426]
- In `set_version_and_fsid_type()`, `FSID_UUID16` and `FSID_UUID16_INUM` (16/24 bytes) require `fhp->fh_maxsize >= 64` (NFSv3/v4), and `FSID_DEV` requires `old_valid_dev(exp_sb(exp)->s_dev)` (otherwise `FSID_ENCODE_DEV`). [F427]
- In `nfsd4_decode_compound()`, `argp->opcnt` must be forced to `0` when `argp->minorversion > NFSD_SUPPORTED_MINOR_VERSION` because decoders/processors index `nfsd_suppattrs[minorversion]` (`NFSD_SUPPORTED_MINOR_VERSION + 1` rows). Every opcode accepted by `nfsd4_opnum_in_range()` must have non-NULL entries in both `nfsd4_dec_ops[]` and `nfsd4_enc_ops[]` (`BUG_ON(!nfsd4_enc_ops[op->opnum])`). [F415, F424]
- Every bit in `NFSD_WRITEABLE_ATTRS_WORD0..2` must have a decode branch in `nfsd4_decode_fattr4()` in ascending bit order (`attrlist4_count == xdr_stream_pos(argp->xdr) - starting_pos`). Every bit in `nfsd_suppattrs` (`NFSD4*_SUPPORTED_ATTRS_WORD*`) must have a non-NULL encoder in `nfsd4_enc_fattr4_encode_ops[]`. [F389, F414]
- `nfsd4_encode_fattr4()` must copy `const u32 *bmval` into a local `attrmask[3]` before masking bits so `nfsd4_encode_entry4_fattr()` can reuse `cd->rd_bmval`. When `nfsd4_deleg_getattr_conflict()` returns `dp`, `args.change_attr` must come from `dp->dl_cb_fattr.ncf_initial_cinfo` (after incrementing it and setting `args.stat.size = ncf_cur_fsize` if `ncf_file_modified`) rather than `nfsd4_change_attribute()`. [F398, F412]
- Raw `xdr_stream` opaque encoders (`nfsd4_encode_opaque_fixed()`, `nfsd4_encode_opaque()`, `nfsd4_encode_readv()`, `nfsd4_encode_readlink()`, `nfsd4_vbuf_to_stream()`) must zero trailing `xdr_pad_size(len)` bytes. In `nfsd4_decode_stateid4()` / `nfsd4_encode_stateid4()`, `si_generation` is byte-swapped (`be32_to_cpup` / `cpu_to_be32`), while `si_opaque` and `clientid_t` (`nfsd4_decode_clientid4()` / `nfsd4_encode_clientid4()`) are copied verbatim via `memcpy()`. [F395, F428]
- Each `nfsd()` kthread must call `unshare_fs_struct()` before setting `current->fs->umask = 0`. In `nfsd_set_nrthreads()`, each `nthreads[i]` must be clamped to `NFSD_MAXSERVS` before summing `tot`, and scaling must check `tot > 0` before dividing `nthreads[i] * NFSD_MAXSERVS / tot`. [F406, F457]
- In `nfsd_nl_listener_set_doit()`, removing any listener (non-empty `permsocks`) requires splicing `permsocks` back to `serv->sv_permsocks`, verifying `serv->sv_nrthreads == 0`, and calling `svc_xprt_destroy_all()` before recreating kept listeners. Toggling NFSv4 minor versions must go through `nfsd_minorversion()`, which sets `nn->nfsd_versions[4]` on `NFSD_SET` and calls `nfsd_adjust_nfsd_versions4()` on `NFSD_CLEAR`. [F399, F401]
- In `fs/nfsd/nfsctl.c`, static `nfsd` inode numbers must be below `NFSD_MaxReserved` in `enum NFSD_Root`, and `nfsd_files` plus any `struct tree_descr` array passed to `nfsd_client_mkdir()` (`nfsdfs_create_files()`) must end with an empty-name sentinel (`{""}` or `{NULL}`). [F435]

## Synchronization
- `nfsd_mutex` must be held across `nfsd_svc()`, `nfsd_create_serv()`, `nfsd_destroy_serv()`, and `nfsd_set_nrthreads()`, and when modifying `nn->nfsd_versions`, `nn->nfsd4_minorversions`, `nn->nfsd4_lease`, `nn->nfsd4_grace`, or `nfsd_max_blksize` after `nfsd_net_init()`. [F362]
- In `nfsd_reply_cache_init()`, `nn->drc_hashsize` must stay 0 until all buckets' `lru_head` and `cache_lock` in `nn->drc_hashtbl` are initialized, because `shrinker_register(nn->nfsd_reply_cache_shrinker)` runs first and `nfsd_reply_cache_scan()` iterates to `nn->drc_hashsize`. [F356]
- In `fs/nfsd/nfscache.c`, `b->rb_head`, `b->lru_head`, and `rp->c_state` (`RC_INPROG` / `RC_DONE`) require `b->cache_lock` (except in `nfsd_reply_cache_shutdown()` after `shrinker_free()`). `nfsd_cache_update()` must populate `rp->c_replvec` or `rp->c_replstat` while `c_state == RC_INPROG` before `lru_put_end()` and `RC_DONE`. `GFP_KERNEL` allocations (`nfsd_cacherep_alloc()`, `kmalloc()`) and `nfsd_cacherep_dispose()` must run outside `b->cache_lock`. [F364, F365, F473]
- In `clear_ncl()` and `get_nfsdfs_client()`, `inode->i_private` access requires `inode->i_lock`: `get_nfsdfs_client()` increments `nc->cl_ref` under `i_lock`, and `clear_ncl()` calls `kref_put(&ncl->cl_ref, ncl->cl_release)` after dropping `i_lock`. [F367]
- `nn->writeverf` updates require `write_seqlock(&nn->writeverf_lock)` via `nfsd_reset_write_verifier()`, and lockless readers must use `read_seqbegin()` / `read_seqretry()` via `nfsd_copy_write_verifier()`. `nfsd_net_try_get()` (using `percpu_ref_tryget_live(&nn->nfsd_net_ref)`) and `nfsd_net_put()` require RCU read lock (`__must_hold(rcu)`). `try_to_expire_client()` must use `cmpxchg(&clp->cl_state, NFSD4_COURTESY, NFSD4_EXPIRABLE)`. [F368, F371, F374]

## Object Lifetimes
- `fh_verify()` / `fh_verify_local()` callers must call `fh_put(fhp)` even on error because `nfsd_set_fh_dentry()` populates `fh_dentry`/`fh_export` before later `__fh_verify()` checks. In `nfsd_procedures2`, `.pc_release` callbacks (`nfssvc_release_attrstat`, `nfssvc_release_diropres`, `nfssvc_release_readres`) only release `resp->fh`, so handlers verifying `argp->fh`, `argp->ffh`, `argp->tfh`, or local `svc_fh` without `fh_copy()` into `resp->fh` must call `fh_put()`. [F337, F341]
- `fh_want_write()` acquires `mnt_want_write()` at most once per `svc_fh` (`fhp->fh_want_write`) and must be balanced by `fh_drop_write()` or `fh_put()`. `fh_put()` must call `fh_drop_write(fhp)` before `exp_put(fhp->fh_export)` and clear `fh_dentry`, `fh_export`, `fh_want_write`, `fh_pre_saved`, `fh_post_saved`, and `fh_no_wcc`. [F338, F490]
- In `fh_compose(fhp, exp, dentry, ref_fh)`, when `ref_fh == fhp`, `set_version_and_fsid_type()` and `ref_fh->fh_no_wcc` must be read and `fh_put(ref_fh)` called before assigning new `fh_dentry`/`fh_export` references; on `FILEID_INVALID`, `fh_compose()` drops its own references via `fh_put(fhp)`. [F340]
- In `nfsd_dispatch()`, once `nfsd_cache_lookup()` returns `RC_DOIT`, every exit path (including `RQ_DROPME` and `pc_encode` failure) must call `nfsd_cache_update()` (with `RC_NOCACHE, NULL` on drop/error). `rp->c_type = RC_REPLBUFF` is set iff `rp->c_replvec.iov_base` is allocated and accounted in `NFSD_STATS_DRC_MEM_USAGE`, and `rp->c_state != RC_UNUSED` iff linked in `b->rb_head` and counted in `nn->num_drc_entries`. [F342, F343]
- `nfsd_reply_cache_shutdown()` must call `shrinker_free(nn->nfsd_reply_cache_shrinker)` before freeing `nn->drc_hashtbl` entries and `kvfree(nn->drc_hashtbl)`, and must zero `nn->drc_hashtbl` and `nn->drc_hashsize`. [F344]
- `nfsd_destroy_serv()` requires `nfsd_mutex`, clears `nn->nfsd_serv = NULL` under `nfsd_notifier_lock`, balances `nfsd_notifier_refcount`, and unconditionally calls `svc_xprt_destroy_all()` and `svc_destroy(&serv)` even when `!nn->nfsd_net_up`. Callers of `nfsd_create_serv(net)` must call `nfsd_destroy_serv(net)` if `serv->sv_nrthreads == 0` when `nfsd_svc()` exits or if `!serv->sv_nrthreads && list_empty(&nn->nfsd_serv->sv_permsocks)` when configuring listeners. [F345, F346]
- In `nfs4svc_decode_compoundargs()`, decode buffers must use `svcxdr_tmpalloc()` (`argp->to_free`) and `argp->ops` (when `opcnt > ARRAY_SIZE(argp->iops)`) must use `vcalloc()` (resetting `argp->ops = argp->iops` on failure) for `nfsd4_release_compoundargs()`. `nfsd4_encode_getxattr()` and `nfsd4_encode_listxattrs()` must `kvfree()` `getxa_buf` and `lsxa_buf` on all paths once encoding finishes. [F351, F354]

## API Contracts
- `fh_copy(dst, src)` requires an unverified `src` (`src->fh_dentry == NULL`) because it shallow-copies without taking references. In `fs/nfsd/nfsfh.c`, `fh->fh_size`, `fhp->fh_maxsize`, and `key_len()` are in bytes, whereas `exportfs_decode_fh_raw()` (`data_left`), `exportfs_encode_fh()` (`maxsize`), and `fh_fsid()` pointer arithmetic use 4-byte words. [F339, F378]
- In `nfsd_set_fh_dentry()`, `NFSEXP_NOSUBTREECHECK` raises capabilities via `cap_raise_nfsd_set()` before `exportfs_decode_fh_raw()`, whereas without it `nfsd_setuser_and_check_port()` must run first so `nfsd_acceptable()` checks parent `MAY_EXEC` under client creds. In `__fh_verify()`, `check_xprtsec_policy(exp, rqstp)` must run before and independently of `NFSD_MAY_BYPASS_GSS*` (skipped only if `!rqstp` or `NFSD_MAY_NLM`). [F436, F488]
- `nfsd4_change_attribute()` requires `stat` from `vfs_getattr()` with `STATX_CHANGE_COOKIE` (plus `STATX_MODE | STATX_CTIME`) or `fh_getattr()` on an `NFS4_FHSIZE` handle (`fh_getattr()` omits `STATX_CHANGE_COOKIE` when `fh_maxsize != NFS4_FHSIZE`). [F379]
- `nfsd_svc()` returns `serv->sv_nrthreads >= 0` or negative errno; callers expecting `0` on success (e.g., `nfsd_nl_threads_set_doit()`) must clamp `if (ret > 0) ret = 0`. `write_threads()` and `__write_ports()` must pass `file->f_cred` (not `current_cred()`) to `nfsd_svc()`, `svc_addsock()`, and `svc_xprt_create()`. Code outside `nfsd()` kthreads must use `nfsd_current_rqst()` and check for `NULL`. [F385, F484, F494]
- `nfsd4_decode_bitmap4()` and `xdr_stream_decode_uint32_array()` take `bmlen` as `u32` count (`ARRAY_SIZE(bmval)`), never `sizeof(bmval)`. In `nfsd4_decode_sequence()` / `nfsd4_encode_sequence()`, wire `*_highest_slotid` fields are 0-based indices while `seq->maxslots` and `seq->target_maxslots` are 1-based counts (`+ 1` on decode, `- 1` on encode). `nfssvc_encode_entry()` and `nfsd4_encode_entry4()` return `0` or `-EINVAL`, storing the `__be32` `nfserr_*` status in `common.err`. [F393, F394, F462]

## Error Handling
- `__fh_verify()`, `nfsd_set_fh_dentry()`, and `nfsd_setuser_and_check_port()` must NULL-check `rqstp` because `fh_verify_local()` passes `rqstp == NULL` for LOCALIO. In `nfsd_set_fh_dentry()`, `exportfs_decode_fh_raw()` can return `NULL` or `ERR_PTR`, so it must be checked with `IS_ERR_OR_NULL()` before assigning `fhp->fh_dentry` and `fhp->fh_export`. [F376, F377]
- `nfsd4_decode_bitmap4()` must only return `nfserr_bad_xdr` on `-EBADMSG` from `xdr_stream_decode_uint32_array()`, treating `-EMSGSIZE` as `nfs_ok`. `nfsd4_decode_fattr4()` (`umask == NULL` from `nfsd4_decode_setattr()`) and `nfsd4_decode_share_access()` (`deleg_when == NULL` from `nfsd4_decode_open_downgrade()`) must NULL-check those pointers. `OP_NONTRIVIAL_ERROR_ENCODE` encoders (`nfsd4_encode_lock()`, `nfsd4_encode_lockt()`, `nfsd4_encode_setattr()`, `nfsd4_encode_setclientid()`) must return `nfserr` (not `nfs_ok`) after encoding an error payload. [F387, F390, F392]

## External Contracts
- `nfsd_print_version_support()` must suppress `+4.0` when v4.0 is enabled (`minor == 0 && supported`) while still printing `-4.0` when disabled. `nfsd_show()` (`/proc/net/rpc/nfsd`) must keep zero placeholders on `fh`, `th`, `ra`, and `proc4ops[0..2]`. `nfsd4_dec_ops[OP_PUTPUBFH]` must use `nfsd4_decode_noop()` across all minor versions per RFC 8881. [F431, F433, F440]

## Known Pitfalls
- `nfsd_mode_check()` can return internal `nfserr_symlink_not_dir` or v4.1 `nfserr_wrong_type`, so NFSv2 handlers must use `nfsd_map_status()` and NFSv4 encoders must use `nfsd4_map_status()`. `nfsd_minorversion()` returns `-1` when `minorversion > NFSD_SUPPORTED_MINOR_VERSION` and `change != NFSD_AVAIL`, so callers must bound `minorversion` or check `> 0` / `NFSD_AVAIL`. [F380, F384]
- In `set_version_and_fsid_type()`, `ref_fh = NULL` must precede the `version` switch and `fsid_type_ok_for_exp()` so `goto retry` does not loop infinitely. In `nfsd_acceptable()`, the parent walk must check `!IS_ROOT(tdentry)` because `dget_parent()` on a root dentry returns itself. `SVCFH_fmt()` uses a single static buffer, must reject `fh->fh_size > 64`, and must not be called twice in one `dprintk()`. [F445, F448, F467]
- In `nfsd_proc_setattr()`, the touch-time check must be `(iap->ia_valid & BOTH_TIME_SET) == BOTH_TIME_SET`. In `nfsd4_change_attribute()`, `stat->ctime.tv_sec` must be cast to `u64` before `<< 30`. [F438, F453]
- Strings from `nfsd4_decode_component4()`, `nfsd4_decode_opaque()`, `nfsd4_decode_nl4_server()`, and `svcxdr_decode_filename()` are not NUL-terminated; bound all accesses by decoded length. In `nfsd4_decode_fattr4()` (`FATTR4_WORD2_TIME_DELEG_ACCESS` / `MODIFY`), assign `tv_sec` from `.seconds` and `tv_nsec` from `.nseconds` (including `ia_ctime.tv_nsec = modify.nseconds`). [F450, F470]
- `nfsd4_encode_splice_read()` requires a single read in the compound, `xdr->buf->page_len == 0`, and `xdr->iov == xdr->buf->head` with `>= 1` word free, and must reset `buf->page_len = 0` on error before `xdr_truncate_encode()`. In `nfsd4_encode_listxattrs()`, `left -= XATTR_USER_PREFIX_LEN` and `sp += XATTR_USER_PREFIX_LEN` must precede `if (nuser++ < offset) goto contloop;`. In `nfs4svc_encode_compoundres()`, advance `p` past `resp->tag` by `XDR_QUADLEN(resp->taglen)`, not `resp->taglen / 4`. [F429, F447, F456]
