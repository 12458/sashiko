# DRM DRIVER FOR NVIDIA GEFORCE/QUADRO GPUS — drivers/gpu/drm/nouveau (part 2)

This unit implements the core DRM driver layer for NVIDIA GPUs (`nouveau`), bridging DRM/TTM/KMS/HMM with NVIF/NVKM to manage probing, PM/Optimus DSM, clients, channels, pushbuffers, TTM BO moves, fences, modesetting, VBIOS, DMEM, and ABI16/EXEC ioctls.

## Architecture & Data Flow

- In `struct nouveau_channel`, `dma.{cur,put,free,max}` are `u32` word indices matching `chan.push.{bgn,cur,end}`, while `chan->push.addr` and `user_get`/`user_put` are byte addresses (`<< 2`). `nouveau_channel_wait()` and `nouveau_channel_kick()` must add `push.cur - push.bgn` to `dma.cur` before `RING_SPACE()`/`FIRE_RING()`, and `nouveau_channel_wait()` must recompute `push.{bgn,cur,end}` from `push.mem.object.map.ptr + dma.cur` after `RING_SPACE()`. [F358, F417]
- `WRITE_PUT` must run `mb()` and `nouveau_bo_rd32(chan->push.buffer, 0)` before writing `chan->user_put`. On ring wrap in `nouveau_dma_wait()`, emit a jump to `chan->push.addr`, spin on `READ_GET()` until `get > NOUVEAU_DMA_SKIPS`, then call `WRITE_PUT(NOUVEAU_DMA_SKIPS)` and set `dma.{cur,put} = NOUVEAU_DMA_SKIPS`. `READ_GET` must reset `*timeout = 0` whenever `val != *prev_get` before checking the `100000` limit. [F327, F359, F395]
- `nouveau_fence_enable_signaling()` must increment `fctx->notify_ref` (allowing `fctx->event` at 1) and set `DMA_FENCE_FLAG_USER_BITS` only if `nouveau_fence_no_signaling()` returns true; else decrement `notify_ref` and call `nvif_event_block(&fctx->event)` at 0. `nouveau_fence_no_signaling()` requires `kref_read(&fence->base.refcount) > 1` because it unlinks and puts `fence->base` if signaled. [F300, F301]
- In `nouveau_fence_update()` and `nouveau_fence_is_signaled()`, cast `(seq - fence->base.seqno)` to `int` and compare against 0. `nouveau_fence_wait_legacy()` and `nouveau_fence_wait_busy()` must use `time_after_eq()`. Loops over `fctx->pending` calling `nouveau_fence_signal()` (`nouveau_fence_context_kill()`, `nouveau_fence_update()`) must use `list_for_each_entry_safe`. [F393, F404, F405]
- `nouveau_bo_pin_locked()` subtracts `bo->base.size` from `vram_available`/`gart_available` only when `pin_count` goes `0 -> 1`, and `nouveau_bo_unpin_locked()` adds it back only at `0`; if validation fails after forcing `nvbo->contig = true`, reset `contig = false`. Under `dmem->lock`, `nouveau_dmem_page_alloc_locked()`/`nouveau_dmem_chunk_alloc()` must increment `chunk->callocated`, and `nouveau_dmem_page_free()` must decrement it. [F354, F355]
- `nouveau_exec_ioctl_exec()` must bound `req->push_count` to `nouveau_exec_push_max_from_ib_max(chan->chan.gpfifo.max)` (returning `ib_max / 2 - 1` if `ib_max > 1`, else `0` to reserve one fence slot without underflow), and `nouveau_exec_job_init()` must reject `va_len > NV50_DMA_PUSH_MAX_LENGTH`. [F374, F410]
- In `nouveau_channels_init()`, `drm->runl` is sized to `fls64(runlists->data)` and indexed by bit position, so when `drm->chan_nr == 0` skip indices where `!(runlists->data & BIT(i))`. On pre-Fermi (`family < NV_DEVICE_INFO_V0_FERMI`), `nouveau_accel_gr_init()` must allocate `drm->notify` and `NvNotify0` (`drm->ntfy`) so `nv04_bo_move_init()`/`nv50_bo_move_init()` have `drm->ntfy.handle`. [F388, F436]
- `nouveau_dp_probe_dpcd()` must zero `outp->dp.lttpr.nr`, `rate_nr`, `link_nr`, and `link_bw` before probing, and zero `sink_count` if not `connector_status_connected`; `nouveau_dp_power_down()` must zero `outp->dp.lt.nr` under `hpd_irq_lock`. `nouveau_dp_train()` and `nv50_dp_mode_valid()` must round up DP symbol rates via `DIV_ROUND_UP(..., 8)`. [F361, F412]
- `nouveau_connector_set_edid()` must check `nv_connector->edid != edid` before updating the EDID property and freeing old `edid`; `nouveau_connector_detect()` must sync `drm_dp_cec_{set,unset}_edid()`; `nouveau_connector_get_modes()` must destroy/NULL `native_mode` before probing, and call `nouveau_connector_detect_depth()` before `nouveau_conn_native_mode()` for non-LVDS but after `native_mode` is set for LVDS. [F311, F362, F363]
- `parse_bit_structure()` must parse BIT `'i'` first to populate `feature_byte` and `is_mobile`. On resume, `nouveau_run_vbios_init()` must reset `crtchead = 0` and (when `bios->execute`) clear `last_script_invoc = 0` and `lvds_init_run = false`. `call_lvds_script()` and `run_tmds_table()` must save/restore `NV_PRAMDAC_SEL_CLK & 0x50000`; `call_lvds_script()` must set `lvds_init_run = true` before recursive `LVDS_INIT`, set `last_script_invoc = (script << 1 | head)`, and zero `NV_PBUS_POWERCTRL_2`; `enum LVDS_script` must stay 1..6. [F367, F370, F372, F380, F402]

## Synchronization

- `nouveau_abi16_get()` returns with `cli->mutex` held on success (unlocking only on allocation failure); every caller getting a non-NULL `abi16` must call `nouveau_abi16_put(abi16, ret)` on all paths. [F303]
- `fctx->lock` protects `fctx->pending`, `fctx->killed`, and `fctx->notify_ref`; `nouveau_fence_emit()` must check `fctx->killed` under `fctx->lock` before queuing `fence->head` (calling `dma_fence_put()` and returning `-ENODEV` if killed). `nouveau_fence_signal()` clears `fence->channel` via `rcu_assign_pointer()` under `fctx->lock`; unlocked readers (`nouveau_fence_sync()`, `nouveau_fence_is_signaled()`) need `rcu_read_lock()`. [F314, F316]
- `nouveau_exec_job_submit()` must hold `nouveau_uvmm_lock(uvmm)` across `drm_gpuvm_exec_lock(vme)`, unlock `uvmm` before `drm_gpuvm_exec_validate(vme)`, and call `drm_gpuvm_exec_unlock(vme)` either on validation error or in `nouveau_exec_job_armed_submit()` after `drm_gpuvm_exec_resv_add_fence()`. `nouveau_bo_init()` must only call `ttm_bo_unreserve(&nvbo->bo)` when caller-supplied `robj` is NULL. [F294, F325]
- `drm->ttm.io_reserve_mutex` protects `io_reserve_lru` and BAR1 mapping in `nouveau_ttm_io_mem_reserve()`/`nouveau_ttm_io_mem_free()`. On `-ENOSPC` eviction, `nouveau_ttm_io_mem_reserve()` must unlink from `io_reserve_lru`, call `drm_vma_node_unmap()` and `nouveau_ttm_io_mem_free_locked()`, and clear `nvbo->bo.resource->bus.{offset,addr}` under `io_reserve_mutex`. [F297, F328]
- `drm->clients_lock` protects `drm->clients` (never acquire under `cli->mutex`), and `nouveau_drm_open()` must finish `nouveau_cli_init()` before linking `cli->head`. `drm->client_mutex` serializes `nvif_client_ctor(&drm->_client, ...)` and `nvif_client_dtor(&cli->base)`. In `nouveau_cli_init()`, pass `NULL` (not `drm->sched_wq`) to `nouveau_sched_create(&cli->sched, drm, NULL, 1)` to avoid `free_job`/`run_job` deadlocks. [F319, F329, F330]
- `drm->hpd_lock` (with IRQs disabled) protects `drm->hpd_pending` and `nv_connector->hpd_pending`. `nv50_edp_{get,set}_brightness()` must lock `connection_mutex` and `crtc->mutex` via `drm_modeset_lock()` before accessing `connector->state->crtc` or calling `drm_edp_backlight_set_level()`. In `nouveau_display_acpi_ntfy()`, drop `pm_runtime_get()` (when `0` or `-EINPROGRESS`) via `pm_runtime_put_noidle()`. [F321, F326, F449]

## Object Lifetimes

- `nouveau_fence_context_del()` must cancel `uevent_work`, call `nouveau_fence_context_kill()`, destroy `fctx->event`, set `fctx->dead = 1`, and call `synchronize_rcu()` before `nouveau_channel_del()` frees `chan`. Unemitted fences from `nouveau_fence_create()` must be freed with `kfree()`, whereas fences emitted via `nouveau_fence_emit()` must use `nouveau_fence_unref()` and be nulled in `exec_job->fence`. [F298, F299]
- `nouveau_cli_fini()` must `flush_work(&cli->work)` before destroying `sched`, `uvmm`, `svm`, `vmm`, and `mmu`, and set `cli->device.object.map.ptr = NULL` before `nvif_device_dtor()`. `nouveau_drm_postclose()` must guard cleanup with `drm_dev_enter()`/`drm_dev_exit()` because `nouveau_drm_device_fini()` frees remaining clients after `drm_dev_unplug()`. [F306, F308]
- `nouveau_accel_init()` must precede `nouveau_dmem_init()` so `drm->ttm.{copy,chan}` are ready for `nouveau_dmem_migrate_init()`. `nouveau_dmem_fini()` must call `nouveau_dmem_evict_chunk(chunk)` before `nouveau_bo_unpin_del(&chunk->bo)` and `memunmap_pages()`. `nouveau_do_suspend()` must call `nouveau_dmem_suspend()` before `ttm_resource_manager_evict_all()` on VRAM, and `nouveau_do_resume()` must call `nouveau_dmem_resume()` after `nvif_client_resume()`. [F305, F428, F447]
- `nouveau_display_fini()` must call `nvif_event_block()` on `conn->irq` and `conn->hpd` for all non-MST connectors before `cancel_work_sync(&drm->hpd_work)` and `disp->fini(dev, runtime, suspend)`. [F322]

## API Contracts

- New DRM code must use NVIF rather than legacy `nvxx_*` macros, and `nouveau_bios_init()` must return early when `nvkm_gsp_rm(nvxx_device(drm)->gsp)` is true. `nouveau_display_fini(dev, suspend, runtime)` takes `(suspend, runtime)` while `disp->fini(dev, runtime, suspend)` takes `(runtime, suspend)`. [F349, F434]
- `nouveau_bo_{wr16,rd32,wr32}()` take an element index (`u16`/`u32`), not a byte offset; `nouveau_bo_{alloc,init,new}()` take `align` in bytes. On Tesla+, `nouveau_bo_move_prep()` attaches both source (`vma[0]`) and destination (`vma[1]`) VMAs to `nouveau_mem(old_reg)`. `nouveau_channel_new()`/`ctor()` take a non-zero runlist bitmask `runm` (converted via `__ffs64()`), and `struct nv_dma_v0.limit` must be inclusive (`start + size - 1`). [F350, F351, F352, F377, F396]
- `nvif_outp_dp_aux_xfer()` returns negative errno or non-negative AUX reply while updating `*psize`; `nouveau_connector_aux_xfer()` stores `ret >= 0` in `msg->reply` and returns `size`, whereas `nouveau_dp_probe_lttpr()` must treat any `ret != 0` as failure. [F333]
- `nouveau_conn_reset()` and `nouveau_conn_attach_properties()` are shared with MST (`struct nv50_mstc`), so only access `nv_connector->properties_state` when `!drm_drv_uses_atomic_modeset()` and use `nouveau_conn_atom(connector->state)` otherwise; `dither.{mode,depth}` enums must match hardware encodings, and modifier / `nouveau_drm_prop_enum_list` arrays must end with `DRM_FORMAT_MOD_INVALID` / `{}`. Backlight callbacks must use `bl_get_data(bd)` for `nouveau_encoder *` and `dev_get_drvdata(bd->dev.parent)` for `drm_connector *`. [F365, F384, F422, F423]
- `nouveau_framebuffer_new()` must validate all `info->num_planes` against `nvbo->bo.base.size` (via `nouveau_check_bl_size()`, which requires `nouveau_check_tile_mode()` before `nouveau_get_gobs_in_block()`), returning `-ERANGE` on overflow. `nouveau_abi16_ioctl()` subhandlers must check and subtract header size from `argc` before accessing payload; `nouveau_exec_ucopy()` must use `u_memcpya()`/`u_free()`; VBIOS accesses must use `ROM16()`, `ROM32()`, and `ROMPTR()`. [F373, F375, F379, F383, F406]
- In `nouveau_debugfs.c`, `drm_debugfs_create_files()` callbacks get `struct drm_info_node *` in `m->private`, while `debugfs_create_file()` callbacks get `struct drm_device *`. `nouveau_debugfs_pstate_set()` must reject `len >= sizeof(buf)` on zero-initialized `buf[32]`, and `nouveau_drm_debugfs_init()` must set `vbios.rom`'s `i_size = drm->vbios.length`. [F385, F386, F424]

## Error Handling

- Callers of `pm_runtime_get_sync()` must treat `>= 0` and `-EACCES` as success, and on `ret < 0 && ret != -EACCES` still call `pm_runtime_put_autosuspend()`; `nouveau_connector_detect()` must use `pm_runtime_get_noresume()` when `drm_kms_helper_is_poll_worker()` is true. [F312, F331]
- On failure in `nouveau_bo_move()` after `nouveau_bo_move_ntfy()` (except `-EMULTIHOP`), roll back via `nouveau_bo_move_ntfy(bo, bo->resource)`, `drm_gpuvm_bo_gem_evict(obj, !evict)`, and `nouveau_bo_vm_cleanup(bo, NULL, &new_tile)`. In `nouveau_ttm_io_mem_reserve()`, `nvif_object_map_handle()` returns `1` on valid I/O map (`0` -> `-EINVAL`, reset `1` -> `0`). `nouveau_ttm_fault_reserve_notify()` must return `VM_FAULT_NOPAGE` on `-EBUSY`/`-ERESTARTSYS`. [F296, F332, F469]
- `nouveau_fence_wait()` must map `dma_fence_wait_timeout()` `0` to `-EBUSY` and `> 0` to `0`. In `nouveau_do_suspend()`, `nouveau_fence(drm)->suspend(drm)` returns `bool`, so set `ret = -ENOMEM` on `false`. `nouveau_abi16_chan_fini()` must guard teardown with `chan->{sched,chan,ntfy}` and `heap.block_size`. `nouveau_dsm_detect()` must zero out-params before `nouveau_dsm_pci_probe()`. `nouveau_backlight_init()` must map `-ENODEV` to `0` before `fail_alloc`. [F334, F335, F343, F346, F348]

## External Contracts

- `nouveau_exec_ioctl_exec()` must verify `nouveau_cli_uvmm(cli)` and `chan->user.oclass >= NV50_CHANNEL_GPFIFO`, else return `-ENOSYS` via `nouveau_abi16_put()`. `nouveau_optimus_dsm()` must pack `arg` in little-endian and verify `obj->buffer.length == 4`; `nouveau_dsm_get_optimus_functions()` must use `nouveau_optimus_dsm()` (not `acpi_check_dsm()`). Disable D3cold if `!bridge_d3`, set `optimus_skip_dsm` if `pci_pr3_present()`, call `nouveau_switcheroo_optimus_dsm()` before `nouveau_do_suspend()` in runtime suspend, and return `1` from `nouveau_pmops_runtime_idle()`. [F387, F439, F440, F448, F472]
- `nouveau_dp_detect()` must call `drm_dp_dpcd_set_powered(&nv_connector->aux, false)` when returning `NOUVEAU_DP_NONE`. `parse_dcb20_entry()` must mask `DCB_OUTPUT_ANALOG` `conf` with `0xffff` (`< 0x30`) or `0xff` (`>= 0x30`). `quirk_broken_nv_runpm()`/`nouveau_drm_remove()` must save and restore `pdev->pm_cap` via `drm->old_pm_cap`. [F369, F381, F444]

## Known Pitfalls

- Before `to_nouveau_fence()`, verify `nouveau_local_fence()` and check under `rcu_read_lock()` that `rcu_dereference(f->channel)` is non-NULL and matches `chan->cli->drm`. In `nouveau_bo_move_ntfy()`, verify `bo->destroy == nouveau_bo_del_ttm` before accessing `nouveau_bo(bo)`. [F337, F338]
- In `nouveau_ttm_io_mem_reserve()`, `TTM_PL_TT` must fall through to `TTM_PL_VRAM` on NV50+ when `mem->kind` is set, and BAR1 mappings must use `ttm_uncached` on Tesla+ when `NVIF_MEM_UNCACHED` is set. Use `nouveau_for_each_non_mst_connector_iter` before `nouveau_connector(connector)`. [F391, F397, F437]
- In `nouveau_exec_ioctl_exec()`, check `if (!chan)` after `list_for_each_entry(chan16, ...)`. In `nouveau_abi16_ioctl_getparam()`, guard `pdev` against `NV_DEVICE_INFO_V0_SOC`. Use `roundup_64()` (only when `nvbo->mode != 0` for tiled alignment) in `nouveau_bo_fixup_align()`, `1ULL << vmm->page[i].shift` in `nouveau_bo_alloc()`, `(u64)pci_domain_nr(pdev->bus) << 32` in `nouveau_pci_name()`, and 1-based `++idx` / `map[i2c] - 1` in `dcb_fake_connectors()`. [F341, F382, F392, F407, F408, F413]
