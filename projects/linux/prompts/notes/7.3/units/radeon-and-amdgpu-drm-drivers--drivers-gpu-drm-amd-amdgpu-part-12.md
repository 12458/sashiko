# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 12)

This unit implements the Graphics and Compute (GC/GFX) IP block drivers for GFX v11 (`gfx_v11_0.c`, `gfx_v11_0_3.c`, RDNA3) and GFX v12 (`gfx_v12_0.c`, RDNA4), covering CP (PFP, ME, MEC) and RLC/IMU firmware loading, PM4 packet emission on GFX/compute/KIQ rings, MQD initialization, usermode queue MES callbacks, EOP and fault interrupts, GFXOFF/clockgating/powergating, cleaner shader execution, and per-queue/pipe reset.

## Architecture & Data Flow

- Because `ring->wptr` is a monotonically increasing 64-bit dword counter, `gfx_v11_0_ring_emit_init_cond_exec`, `gfx_v11_0_ring_emit_gfx_shadow`, and `gfx_v12_0_ring_emit_init_cond_exec` must mask `ring->wptr` with `ring->buf_mask` before indexing `ring->ring[]` or shifting by 2 to compute a byte offset into `ring->ring_obj`. [F968]
- In `gfx_v11_0_ring_emit_gfx_shadow`, `ring->set_q_mode_ptr` must be set to `&ring->ring[ring->set_q_mode_offs]` on the postfix call (`!shadow_va`) before `ring->set_q_mode_offs = offs` overwrites `set_q_mode_offs`, and `gfx_v11_0_ring_emit_vm_flush` must reset both `ring->set_q_mode_offs = 0` and `ring->set_q_mode_ptr = NULL`. [F991]
- Any change to PM4 dwords emitted by ring frame callbacks (`emit_vm_flush`, `emit_fence`, `emit_gfx_shadow`, `emit_cleaner_shader`, `emit_mem_sync`) or `emit_ib` must update `.emit_frame_size` or `.emit_ib_size` in `gfx_v11_0_ring_funcs_*` / `gfx_v12_0_ring_funcs_*`; similarly, `gfx11_kiq_*` and `gfx_v12_0_kiq_*` packet lengths must match `set_resources_size`, `map_queues_size`, `unmap_queues_size`, `query_status_size`, and `invalidate_tlbs_size` in `gfx_v11_0_kiq_pm4_funcs` and `gfx_v12_0_kiq_pm4_funcs`. [F946, F947]
- `gfx_v11_0_get_csb_size` must match the exact number of dwords written by both `gfx_v11_0_get_csb_buffer` and the clear-state preamble in `gfx_v11_0_cp_gfx_start`, and `gfx_v12_0_get_csb_size` must match `gfx_v12_0_get_csb_buffer`. Clear-state tables (`gfx11_cs_data`, `gfx12_cs_data`) parsed by these functions must terminate their `cs_section_def` array with `.section == NULL` and each nested `cs_extent_def` array with `.extent == NULL`. [F948, F970]
- In `gfx_v11_0_rlc_backdoor_autoload_copy_ucode` and `gfx_v12_0_rlc_backdoor_autoload_copy_ucode`, `id` must be verified strictly between `*_FIRMWARE_ID_INVALID` and `*_FIRMWARE_ID_MAX` before indexing `rlc_autoload_info[id]` or setting `*(uint64_t *)fw_autoload_mask` (which in v11 must use `1ULL << id` as `SOC21_FIRMWARE_ID_MAX == 37`), and `fw_size` must be clamped to `rlc_autoload_info[id].size` before `memcpy`. [F965, F992]
- In `gfx_v11_0_get_clockgating_state`, `gfx_v12_0_get_clockgating_state`, and the `gfx_v11_0_update_*` / `gfx_v12_0_update_*` helpers, `regRLC_CGTT_MGCG_OVERRIDE` bits are active-low override bits (`0` = clockgating enabled, `1` = overridden/disabled), whereas `CGCG_EN` and `CGLS_EN` in `regRLC_CGCG_CGLS_CTRL*` are active-high enable bits. [F977]
- `gfx_v11_0_init_gds_vmid` must only clear GDS/GWS/OA registers (`regGDS_VMID0_BASE`, `regGDS_VMID0_SIZE`, `regGDS_GWS_VMID0`, `regGDS_OA_VMID0`) for `vmid >= 1` and preserve `vmid = 0` for HWS firmware save/restore, and `gfx_v11_0_constants_init` / `gfx_v12_0_constants_init` must only program `regSH_MEM_BASES` for `i != 0`. [F952]
- In `gfx_v11_0_sw_init` and `gfx_v12_0_sw_init`, `adev->gfx.mec.num_mec` must be set to `1` across all GC 11.x and GC 12.x IP branches (and `adev->gfx.mec2_fw` set to `NULL` in `gfx_v11_0_init_microcode` and `gfx_v12_0_init_microcode`) because GFX11 and GFX12 hardware only implement a single MEC. [F1009]
- `gfx_v11_0_alloc_ip_dump`, `gfx_v11_ip_dump`, and `gfx_v11_ip_print` (and their `gfx_v12_*` counterparts) must use identical ME/MEC pipe/queue instance counts and `gc_cp_reg_list_*` / `gc_gfx_queue_reg_list_*` array sizes when sizing and indexing `ip_dump_compute_queues` and `ip_dump_gfx_queues`. Because `alloc_ip_dump` sets `ip_dump_core`, `ip_dump_compute_queues`, and `ip_dump_gfx_queues` to `NULL` on `kcalloc` failure without failing `sw_init`, the dump and print functions must null-check each buffer before indexing it. [F935, F957]

## Synchronization

- All `amdgpu_irq_src_funcs.set` callbacks in `gfx_v11_0.c` and `gfx_v12_0.c` (`gfx_v11_0_set_eop_interrupt_state`, `gfx_v11_0_set_priv_reg_fault_state`, `gfx_v11_0_set_bad_op_fault_state`, `gfx_v11_0_set_priv_inst_fault_state`, and `gfx_v12_0_*` equivalents) run under `adev->irq.lock` (`spin_lock_irqsave`) and must not sleep, call `amdgpu_gfx_off_ctrl`, or lock `adev->srbm_mutex`. [F1024]
- `gfx_v11_0_select_se_sh` and `gfx_v12_0_select_se_sh` write `regGRBM_GFX_INDEX` without locking; callers must hold `adev->grbm_idx_mutex` across per-SE/SH/instance register accesses and restore broadcast mode (`0xffffffff, 0xffffffff, 0xffffffff, 0`) before unlocking. [F921]
- `gfx_v11_0_select_me_pipe_q` and `gfx_v12_0_select_me_pipe_q` write `regGRBM_GFX_CNTL` via `soc21_grbm_select`/`soc24_grbm_select` without locking; runtime callers must hold `adev->srbm_mutex` across the ME/pipe/queue/VMID selection and banked register accesses and reset the selection to `(0, 0, 0, 0)` before unlocking. [F922]
- In `gfx_v11_0_soft_reset`, writing `regCP_VMID_RESET` must be protected by both `adev->gfx.reset_sem_mutex` and acquiring the hardware GFX index mutex via `gfx_v11_0_request_gfx_index_mutex(adev, true)`, followed by reading `regCP_VMID_RESET` three times before releasing `gfx_v11_0_request_gfx_index_mutex(adev, false)`. [F954]

## Object Lifetimes

- Whenever `gfx_v11_0` or `gfx_v12_0` allocates a kernel BO via `amdgpu_bo_create_reserved` for MEC HPD EOP (`hpd_eop_obj`) or CP PFP/ME/MEC firmware (`pfp_fw_obj`, `pfp_fw_data_obj`, `me_fw_obj`, `me_fw_data_obj`, `mec_fw_obj`, `mec_fw_data_obj`), it must call `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` once CPU population is done (including on error paths after creation). [F909]
- In `gfx_v11_0_get_gpu_clock_counter`, `gfx_v11_0_update_spm_vmid`, `gfx_v11_ip_dump`, and `gfx_v12_ip_dump`, `amdgpu_gfx_off_ctrl(adev, false)` must be called before acquiring `adev->gfx.gpu_clock_mutex` or `adev->srbm_mutex` and reading GC registers, and paired with `amdgpu_gfx_off_ctrl(adev, true)` after unlocking without early returns in between. [F917]
- In `gfx_v11_0_set_powergating_state` on GC 11.0.1, 11.0.4, and 11.5.x, `amdgpu_gfx_off_ctrl(adev, false)` must precede `gfx_v11_cntl_pg(adev, enable)` when un-gating (`!enable`), whereas `gfx_v11_cntl_pg(adev, enable)` must precede `amdgpu_gfx_off_ctrl(adev, true)` when gating (`enable`). [F918]
- In `gfx_v11_0_sw_init`, if `amdgpu_gfx_cleaner_shader_sw_init` fails, `adev->gfx.enable_cleaner_shader` must be reset to `false` so `amdgpu_gfx_cleaner_shader_init`, `amdgpu_gfx_cleaner_shader_sw_fini`, and ring isolation helpers do not access an uninitialized cleaner shader BO. [F910]
- In `gfx_v11_0_sw_fini` and `gfx_v12_0_sw_fini`, when `!adev->enable_mes_kiq`, the KIQ ring must be torn down in reverse initialization order by calling `amdgpu_gfx_kiq_free_ring(&adev->gfx.kiq[0].ring)` before `amdgpu_gfx_kiq_fini(adev, 0)` (reversing `amdgpu_gfx_kiq_init` then `amdgpu_gfx_kiq_init_ring`). [F911]
- All GFX v11 and v12 kernel BOs, rings, firmware objects, and `kcalloc`-allocated IP dump arrays (`ip_dump_core`, `ip_dump_compute_queues`, `ip_dump_gfx_queues`) are manually allocated without devres and must be explicitly freed in `gfx_v11_0_sw_fini` and `gfx_v12_0_sw_fini`. [F1022]
- In `gfx_v11_0_hw_init` and `gfx_v12_0_hw_init`, when `adev->firmware.load_type` is `AMDGPU_FW_LOAD_DIRECT` or `AMDGPU_FW_LOAD_RLC_BACKDOOR_AUTO` (with `amdgpu_dpm == 1`), `amdgpu_pm_load_smu_firmware` must be called before `gfx_v11_0_rlc_resume` or `gfx_v12_0_rlc_resume` because RLC firmware loading depends on SMU firmware being loaded first. [F1012]
- In `gfx_v11_0_hw_fini`, when `amdgpu_sriov_vf(adev)` is true, the function must return after unmapping KGQ, KCQ, and MES KIQ without calling `gfx_v11_0_cp_enable(adev, false)` or `adev->gfxhub.funcs->gart_disable(adev)` so CP can perform IDLE-SAVE during VF switch. [F913]

## API Contracts

- `gfx_v11_0_get_cpc_int_cntl`, `gfx_v11_0_set_compute_eop_interrupt_state`, `gfx_v12_0_get_cpc_int_cntl`, and `gfx_v12_0_set_compute_eop_interrupt_state` must only configure interrupts for `me == 1` (the first MEC), leaving all other MEC pipes' interrupts to `amdkfd`. `gfx_v11_0_get_cpg_int_cntl`, `gfx_v11_0_get_cpc_int_cntl`, `gfx_v12_0_get_cpg_int_cntl`, and `gfx_v12_0_get_cpc_int_cntl` return `0` when `(me, pipe)` is out of range or not controlled by amdgpu, and callers must verify the returned register offset is non-zero before calling `RREG32_SOC15_IP` or `WREG32_SOC15_IP`. [F931, F953]
- In `soc21_grbm_select`, `soc24_grbm_select`, `gfx_v11_0_get_cpc_int_cntl`, and `gfx_v12_0_get_cpc_int_cntl`, ME 0 is the GFX engine and compute MECs are 1-based (`me = mec + 1`), whereas `(0, 0, 0, 0)` resets the GRBM selection. Broken by: passing a 0-based MEC index directly as `me`. [F943]
- In `gfx_v11_0_gfx_mqd_init`, `gfx_v11_0_compute_mqd_init`, `gfx_v12_0_gfx_mqd_init`, and `gfx_v12_0_compute_mqd_init`, `prop->queue_size` is in bytes (encoded as `order_base_2(prop->queue_size / 4) - 1`), and `prop->hqd_base_gpu_addr` and `prop->eop_gpu_addr` are byte addresses that must be shifted right by 8 (`>> 8`). [F945]
- `gfx_v11_0_get_gfx_shadow_info` and `gfx_v12_0_get_gfx_shadow_info` only populate `shadow_info` and return `0` when `adev->gfx.cp_gfx_shadow` or `skip_check` is true; otherwise they zero `*shadow_info` and return a negative error (`-ENOTSUPP` on GFX11, `-EINVAL` on GFX12). Broken by: calling `amdgpu_gfx_get_gfx_shadow_info` (`skip_check = false`) when `cp_gfx_shadow` is false without checking the return value. [F932]
- RLC clockgating and powergating register updates (`regRLC_CGTT_MGCG_OVERRIDE`, `regRLC_CGCG_CGLS_CTRL`, `regRLC_PG_CNTL`) in `gfx_v11_0_update_gfx_clock_gating`, `gfx_v11_cntl_pg`, and `gfx_v12_0_update_gfx_clock_gating` must be bracketed by `amdgpu_gfx_rlc_enter_safe_mode(adev, 0)` and `amdgpu_gfx_rlc_exit_safe_mode(adev, 0)`. [F958]
- In `gfx_v11_0_cp_resume`, when `adev->gfx.disable_kq` is true, the temporary GFX ring must be tested with `amdgpu_ring_test_ring(ring)` instead of `amdgpu_ring_test_helper(ring)` so `ring->sched.ready` remains false, and then disabled via `amdgpu_gfx_disable_kgq(adev, 0)`. [F956]
- `gfx_v11_0_read_wave_data` and `gfx_v12_0_read_wave_data` append wave status dwords using `dst[(*no_fields)++]` without initializing `*no_fields`, and require `simd == 0` (`WARN_ON(simd != 0)`) because the SIMD ID is selected via the `instance` parameter of `select_se_sh` (also applies to `gfx_v11_0_read_wave_sgprs`). [F940]
- `gfx_v11_0_get_clockgating_state` and `gfx_v12_0_get_clockgating_state` only bitwise-OR (`*flags |= ...`) enabled `AMD_CG_SUPPORT_GFX_*` bits into `*flags` without clearing it, so callers must initialize `*flags` before querying clockgating state. [F941]

## Error Handling

- In `gfx_v11_0_ring_test_ib` and `gfx_v12_0_ring_test_ib`, the return value of `dma_fence_wait_timeout` must be stored in a signed `long` variable `r`, with `r == 0` converted to `-ETIMEDOUT` and `r < 0` propagated as an error before checking `*cpu_ptr`. [F930]
- `adev->gfx.ras` is only populated on `IP_VERSION(11, 0, 3)` in `gfx_v11_0_gpu_early_init` and is `NULL` on all other GC 11.x/12.x revisions, so GFX11 RAS paths like `gfx_v11_0_rlc_gc_fed_irq` must null-check `adev->gfx.ras` and its callback pointer. In `gfx_v11_0_3_rlc_gc_fed_irq`, `ras_if` (from `adev->sdma.ras_if` or `adev->gfx.ras_if`) must be null-checked before dereferencing, and `adev->virt.ops && adev->virt.ops->ras_poison_handler` must be checked before invoking the SR-IOV poison handler. [F933, F934]
- `gfx_v11_0_ring_emit_gfx_shadow` must check both `adev->gfx.cp_gfx_shadow` and `ring->ring_obj` before emitting `PACKET3_SET_Q_PREEMPTION_MODE` shadow packets or calling `amdgpu_bo_gpu_offset(ring->ring_obj)`. [F936]
- In `gfx_v11_0_init_microcode`, `gfx_v11_0_init_toc_microcode`, `gfx_v12_0_init_microcode`, and `gfx_v12_0_init_toc_microcode`, failure of `amdgpu_ucode_request` or `amdgpu_gfx_rlc_init_microcode` must jump to the `out:` cleanup path to call `amdgpu_ucode_release` on all requested firmware pointers (`pfp_fw`, `me_fw`, `rlc_fw`, `mec_fw`, `toc_fw`) while returning `err`. [F938]

## External Contracts

- On GFX11 and GFX12 rings, hardware RPTR writeback slots (`ring->rptr_cpu_addr`) are 32-bit (`*(uint32_t *)ring->rptr_cpu_addr` in `gfx_v11_0_ring_get_rptr_gfx`/`_compute` and `gfx_v12_0_ring_get_rptr_gfx`/`_compute`), while WPTR writeback slots (`ring->wptr_cpu_addr`) and doorbells are 64-bit (`atomic64_read`/`atomic64_set` and `WDOORBELL64` in `gfx_v11_0_ring_get_wptr_gfx`/`gfx_v11_0_ring_set_wptr_gfx` and v12 equivalents). [F975]

## Known Pitfalls

- In `gfx_v11_0_sw_init`, `gfx_v12_0_sw_init`, and `gfx_v11_0_soft_reset`, the 3-level queue loops iterate `j` over `num_queue_per_pipe` outside `k` over `num_pipe_per_me` / `num_pipe_per_mec`, so callees taking `(me, pipe, queue)` must receive `(i, k, j)` (not `(i, j, k)`), and `ring_id` must be reset to `0` before the compute ring loop. [F986]
- In `gfx_v12_0_cp_compute_load_microcode_rs64`, per-pipe MEC data copies into `u32 *fw_data_ptr` must scale the 64KB-aligned byte stride by `/ 4` (`fw_data_ptr + i * ALIGN(fw_data_size, 64 * 1024) / 4`), whereas `regCP_MEC_MDBASE_LO`/`_HI` takes the unscaled byte offset (`mec_fw_data_gpu_addr + i * ALIGN(fw_data_size, 64 * 1024)`). [F966]
- In `gfx_v11_0_rlc_backdoor_autoload_copy_toc_ucode` and `gfx_v12_0_rlc_backdoor_autoload_copy_toc_ucode`, `rlc_autoload_info[].size` is in bytes, so indexing `toc_ptr` near the end of `data` must divide `size` by `sizeof(*toc_ptr)` (`size / 8` for `uint64_t *` in v11, `size / 4` for `uint32_t *` in v12). [F1001]
- In `struct gfx_firmware_header_v1_0`, `header.ucode_array_offset_bytes` and `header.ucode_size_bytes` are in bytes while `jt_offset` and `jt_size` are in 32-bit dwords; code subtracting `jt_size` from `ucode_size_bytes` must multiply `jt_size` by 4, whereas indexing `const __le32 *fw_data` uses `fw_data + hdr->jt_offset + i` unscaled. [F1002]
- In `gfx_v11_0_ring_emit_de_meta`, `amdgpu_ring_write_multiple` takes its count in 32-bit dwords rather than bytes, so `sizeof(de_payload)` must be shifted right by 2 (`sizeof(de_payload) >> 2`) in both `PACKET3_WRITE_DATA` header sizing and the `amdgpu_ring_write_multiple` call. [F1007]
- `gfx_v11_ring_insert_nop` and `gfx_v12_ring_insert_nop` require `num_nop >= 1`, must return early after writing `ring->funcs->nop` when `num_nop == 1`, and for `num_nop >= 2` must emit `PACKET3(PACKET3_NOP, min(num_nop - 2, 0x3ffe))` followed by `amdgpu_ring_insert_nop(ring, num_nop - 1)` (not recursing into `gfx_v1*_ring_insert_nop`). [F989]
- In `gfx_v11_0` and `gfx_v12_0`, RS64 PFP microcode configuration must program `regCP_GFX_RS64_DC_BASE0_LO`/`HI` and `PFP_PIPE*_RESET`, whereas RS64 ME microcode configuration must program `regCP_GFX_RS64_DC_BASE1_LO`/`HI` and `ME_PIPE*_RESET`. [F990]
- In `gfx_v11_0_rlc_smu_handshake_cntl` and `gfx_v12_0_rlc_smu_handshake_cntl`, `RLC_PG_CNTL__SMU_HANDSHAKE_DISABLE_MASK` in `regRLC_PG_CNTL` has inverted polarity relative to `enable`: `!enable` sets the mask bit to disable RLC-SMU handshaking and GFXOFF, while `enable` clears it. [F978]
- In `gfx_v11_0_update_coarse_grain_clock_gating` and `gfx_v12_0_update_coarse_grain_clock_gating`, `regSDMA1_RLC_CGCG_CTRL` must only be read or written when `adev->sdma.num_instances > 1`, because some GC 11 and GC 12 ASICs only have one SDMA instance. [F1011]
