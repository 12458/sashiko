# MELLANOX ETHERNET DRIVER (mlx5e) — drivers/net/ethernet/mellanox/mlx5/core (part 2)

Implements E-Switch representors (`en_rep.c`), RX datapath (`en_rx.c`), NIC/FDB TC offload (`en_tc.c`), statistics (`en_stats.c`), and self-tests (`en_selftest.c`).

## Architecture & Data Flow

- `struct mlx5_flow_attr` ends with a union of `esw_attr` (`MLX5_FLOW_NAMESPACE_FDB`) and `nic_attr`. Allocate via `mlx5_alloc_flow_attr(ns)`, copy `ns_to_attr_sz(ns)` (`ESW_FLOW_ATTR_SZ`/`NIC_FLOW_ATTR_SZ`) bytes rather than `sizeof(*attr)`, and check `mlx5e_is_eswitch_flow(flow)` before accessing `esw_attr` or `nic_attr`. [F47, F128]
- Shared TC/rep helpers (`mlx5e_tc_action_miss_mapping_get/put`, `mlx5e_get_priv_obj_mapping`, `get_ct_priv`, `get_post_action`, `get_act_stats_handle`) must check `is_mdev_switchdev_mode(priv->mdev)` before accessing `esw->offloads` or `uplink_priv`; `mlx5e_is_uplink_rep`, `get_tc_ht`, and `is_flow_rule_duplicate_allowed` must verify representor mode or `rpriv != NULL` before dereferencing `priv->ppriv`. [F48, F139]
- In `parse_tc_actions`, splitting into a post-action `mlx5_flow_attr` at `i` must call `mlx5e_tc_act_post_parse` for `[i_split, i]`, clone `flow->attr`, set `i_split = i + 1`, reset `parse_state->if_count = 0`, and prepend via `list_add(&attr->list, &flow->attrs)`. Since original `flow->attr` stays last, post-act alloc/offload/unoffload/free loops must stop at `list_is_last(&attr->list, &flow->attrs)`. [F87, F109]
- In `post_process_attr` and `extra_split_attr_dests_needed`, call `mlx5e_tc_tun_encap_dests_set` only when `mlx5e_is_eswitch_flow(flow) && has_encap_dests(attr)`, and check static `MLX5_ESW_DEST_ENCAP` so `extra_split_attr`, mod-hdr handles, and counters are initialized even when `flow` is marked `SLOW`. [F35, F105]
- In `offload_pedit_fields`, `mask_field_get`, and `mask_field_clear`, `pedit_headers` masks/values are network byte order and require width-matched conversions (`be32_to_cpu`, `be16_to_cpu`, `u8`) based on `f->field_bsize`. Clear every matched SET/ADD mask via `mask_field_clear` (even no-ops) so `verify_offload_pedit_fields` passes; if `mod_hdr_acts.num_actions == 0`, `actions_prepare_mod_hdr_actions` must clear `MLX5_FLOW_CONTEXT_ACTION_MOD_HDR`, dealloc `mod_hdr_acts`, and reset `esw_attr->split_count = 0` when no VLAN pop/push exists. [F84, F85, F90]
- `mlx5e_tc_attr_to_reg_mappings` entries require `1 <= mlen <= 32` and `moffset + mlen <= 32`. `mlx5e_tc_match_to_reg_match` takes unshifted `val`/`mask` within `GENMASK(mlen - 1, 0)`, clears `max_mask << moffset` in `match_criteria`/`match_value`, ORs shifted `mask`/`val`, and sets `MLX5_MATCH_MISC_PARAMETERS_2`. [F82, F122]
- In `__parse_cls_flower`, when `parse_tunnel_attr` sets `match_inner = true`, switch `match_level`, `headers_c`, and `headers_v` to inner pointers before parsing L2/L3/L4 keys. In `enc_opts_is_dont_care_or_full_match`, once `*dont_care` is `false`, keep `if (!(*dont_care) || ...)` sticky across the `while (opts->len > off)` loop. Zero stack `tunnel_match_key` and `tunnel_match_enc_opts` with `memset` in `mlx5e_get_flow_tunnel_id()` before `mapping_add()`. [F59, F83, F113]
- `mlx5e_set_fwd_to_int_port_actions` must set `esw_attr->split_count = out_index` and `attr->dest_chain = 0`. `dec_jump_count` must decrement `jump_count` only when `(act->id, act->hw_index)` changes. `mlx5e_add_offloaded_nic_rule` must check `attr->dest_ft`, `nic_attr->hairpin_ft`, and `nic_attr->hairpin_tirn` before `attr->action & MLX5_FLOW_CONTEXT_ACTION_FWD_DEST`. [F88, F110, F111]
- Check `priv->channels.ptp != NULL` in `mlx5e_add_sqs_fwd_rules()` and `mlx5e_stats_ts_get()` even when `tx_ptp_opened` or `MLX5E_PFLAG_TX_PORT_TS` is set. In `mlx5e_add_sqs_fwd_rules()`, size `sqs_per_channel` with `+ 2` when `is_uplink_rep` is true and pass populated `num_sqs` to `mlx5e_sqs2vport_start()`. [F51, F133]
- In `mlx5e_post_rx_mpwqes`, drain `umr_completed` via `mlx5e_post_rx_mpwqe`, subtract from `umr_in_progress`, and zero it before computing `missing`. When building UMR WQEs (`mlx5e_alloc_rx_mpwqe`, `mlx5e_build_shampo_hd_umr`, `build_ksm_umr`), zero trailing `pad` MTTs and the header up to `inline_ksms`, set `sq->doorbell_cseg = &umr_wqe->hdr.ctrl`, and clear `sq->doorbell_cseg = NULL` after `mlx5e_notify_hw`. In `mlx5e_post_rx_wqes`, subtract `(head + wqe_bulk) & wqe_index_mask` from `wqe_bulk`. [F57, F66, F92, F158]
- Clear `rss_hash_type` and `rss_hash_result` in `mlx5e_decompress_cqe_no_hash`; in `mlx5e_decompress_enhanced_cqe`, return `budget_rem` without popping if `left > budget_rem`; in `mlx5e_cqes_update_owner`, invert `op_own` on ring wrap. Recompute `rx_headroom`, `metasize`, and `cqe_bcnt` after `mlx5e_xdp_handle` returns `false` in linear SKB builders, and verify IP headers via `is_last_ethertype_ip` (`pskb_may_pull`) before dereferencing in `mlx5e_handle_csum` and `mlx5e_enable_ecn`. [F71, F72, F93, F97, F117]
- Reset `rq->hw_gro_data->skb = NULL` whenever it is passed to `napi_gro_receive` or freed (`mlx5e_shampo_flush_skb`, `mlx5e_handle_rx_cqe_mpwrq_shampo`, `mlx5e_shampo_complete_rx_cqe`). In `mlx5e_poll_rx_cq()`, when `work_done > 0`, flush `hw_gro_data->skb` and call `mlx5e_xdp_rx_poll_complete(rq)` if `xdp_prog` is active. [F67, F177]
- New `mlx5e_sw_stats` fields must be aggregated in `mlx5e_stats_grp_sw_update_stats` and declared in `sw_stats_desc[]`. `mlx5e_stats_update*` iterates `stats_grps` in reverse while `mlx5e_stats_fill*` iterates forward, so dependent groups must precede dependencies. Copy VF rep stats from `priv->stats.rep_stats` via `mlx5e_stats_copy_rep_stats`. In `mlx5e_self_test*`, do not advance `count` when `st.cond_func(priv)` skips a test. [F74, F81, F115, F116]

## Synchronization

- In `mlx5e_hairpin_flow_add`, initialize `flows_lock`, `flows`, `dead_peer_wait_list`, `refcnt` (1), and `res_ready` before inserting `hpe` into `tc->hairpin_tbl` and unlocking `hairpin_tbl_lock`, and call `complete_all(&hpe->res_ready)` after setting `hpe->hp`. Wait on `res_ready` and check `!IS_ERR_OR_NULL(hpe->hp)` before dereferencing `hpe->hp`. [F23, F53]
- `mlx5e_hairpin_put` must use `refcount_dec_and_mutex_lock(&hpe->refcnt, &tc->hairpin_tbl_lock)` and unlink `hpe->hairpin_hlist` before unlocking and destroying `hpe->hp`. In `mlx5e_tc_hairpin_update_dead_peer` (registered on `NETDEV_UNREGISTER` via `tc->netdevice_nb`), pin entries with `refcount_inc_not_zero` under `hairpin_tbl_lock`, then wait on `res_ready`, call `mlx5_core_hairpin_clear_dead_peer`, and call `mlx5e_hairpin_put` after unlocking. [F16, F33, F148]
- `tc_ht` lookups (`mlx5e_configure_flower`, `mlx5e_delete_flower`, `mlx5e_stats_flower`) require `rcu_read_lock()` and `mlx5e_flow_get` before `rcu_read_unlock()`; `mlx5e_flow_put` uses `kfree_rcu`. Set lockdep classes `tc_ht_lock_key` and `tc_ht_wq_key` on `ht->mutex` and `ht->run_work.lockdep_map` in `mlx5e_tc_nic_init` and `mlx5e_tc_ht_init`. [F34, F165]
- Always call `complete_all(&flow->init_done)` after `mlx5e_tc_add_fdb_flow` in `__mlx5e_add_fdb_flow`, and `complete_all(&flow->del_hw_done)` after unoffloading in `mlx5e_tc_del_fdb_flow`. Hold `uplink_priv->unready_flows_lock` in `unready_flow_add/del` while updating `NOT_READY` and `flow->unready`. Hold `tc->t_lock` when creating/destroying `tc->t` in `mlx5e_add_offloaded_nic_rule` and `mlx5e_tc_del_nic_flow`. [F24, F31, F89]
- Use `mlx5_devcom_for_each_peer_entry_rcu` under `rcu_read_lock()` in `mlx5e_tc_query_route_vport`. Acquire `rtnl_lock()` before `netdev_lock(netdev)` in `mlx5e_uplink_rep_enable/disable`. In `en_stats.c` QoS stats readers, use `smp_load_acquire(&priv->htb_max_qos_sqs)` and `READ_ONCE` on `htb_qos_sq_stats` and `stats[i]`. Execute `dma_wmb()` before RQ doorbell record updates and `wmb()` after CQ doorbell record updates. [F39, F156, F160, F162]

## Object Lifetimes

- In `mlx5e_init_rep_tx`/`mlx5e_cleanup_rep_tx`, run `mlx5e_rep_neigh_init` before `mlx5e_init_uplink_rep_tx` and `mlx5e_tc_ht_init`, and `mlx5e_rep_neigh_cleanup` after `mlx5e_tc_ht_cleanup` and `mlx5e_cleanup_uplink_rep_tx`. In `mlx5e_cleanup_ul_rep_rx`, call `cancel_work_sync(&rpriv->uplink_priv.mpesw_work)` before `mlx5e_cleanup_rep_rx`. [F9, F27]
- Only destroy `rpriv->root_ft` in `mlx5e_destroy_rep_root_ft` when `rep->vport == MLX5_VPORT_UPLINK`. Clear `rpriv->vport_rx_rule = NULL` in `rep_vport_rx_rule_destroy`. Pair every `mlx5_chains_get_table` in `mlx5e_add_offloaded_nic_rule` with `mlx5_chains_put_table` on error and in `mlx5e_del_offloaded_nic_rule`. [F11, F12, F17]
- If `mlx5_flow_has_geneve_opt(spec)` is true after `mlx5e_tc_tun_parse`, call `mlx5_geneve_tlv_option_del(priv->mdev->geneve)` before freeing `spec`. In `mlx5e_configure_flower`, always release transient `mlx5_esw_hold` via `mlx5_esw_release`, and undo persistent `mlx5e_tc_block_ipsec_offload` and `mlx5_esw_get` on error/duplicate exits and in `mlx5e_delete_flower`. [F20, F21]
- Never cache pointers into `mod_hdr_acts->actions` across `mlx5e_mod_hdr_alloc()` calls, and increment `mod_hdr_acts->num_actions` after each call. Clear `MLX5E_RQ_FLAG_XDP_XMIT` and increment `frag_page->frags` when `mlx5e_xdp_handle()` consumes a frame; free XSK RX buffers with `xsk_buff_free()`. In `mlx5e_test_loopback`, `dev_queue_xmit` consumes `skb`; `mlx5e_test_loopback_validate` must call `skb_linearize`, check `skb_headlen`, compute UDP offset from `ip_hdr(skb)`, and call `kfree_skb(skb)`. [F14, F137, F176, F180, F181]

## API Contracts

- Verify `ndev->netdev_ops` is `&mlx5e_netdev_ops` or `&mlx5e_netdev_ops_rep` before treating `netdev_priv(ndev)` as `mlx5e_priv` (VF reps require `mlx5e_netdev_ops_rep`, uplink reps require `mlx5e_netdev_ops`). Callers of `mlx5e_tc_update_skb` must release `tc_priv->fwd_dev` via `dev_put` (even when `skb_done` is set). [F22, F140, F185]
- Check `IS_ERR()` on `mlx5e_tc_table_alloc()` and `mlx5e_flow_get()`, and `< 0` on `mlx5e_tc_match_to_reg_set_and_get_id()`. In `mlx5i_complete_rx_cqe()`, set `skb->dev = NULL` on drop so `mlx5i_handle_rx_cqe()` frees `skb`. Check `MLX5_CAP_GEN(..., hairpin)` on both local and peer mdevs in `mlx5e_hairpin_flow_add`, and pass `mlx5e_rqt_size(mdev, hp->num_channels)` as both `actual_sz` and `max_sz` in `mlx5e_hairpin_create_indirect_rqt()`. [F41, F42, F43, F46, F60, F154]
- In firmware `set_action_in` descriptors, `length == 0` encodes 32 bits. Pass `rep->vport - 1` to `mlx5_core_query_vport_counter(dev, 1, vf, ...)` and flip hardware TX/RX into `rep_stats->vport_rx_*/tx_*`, whereas `mlx5e_rep_query_aggr_q_counter()` takes `rep->vport` and requires `q_counter_other_vport` and `q_counter_aggregation` caps. [F62, F63, F151, F184]
- Allocate `ALIGN(headlen, sizeof(long))` linear SKB bytes before `mlx5e_copy_skb_header()`, and pass `rq->buff.map_dir` to all `dma_sync_single*_for_cpu` calls in `en_rx.c`. `fill_strings` and `fill_stats` in `mlx5e_stats_grp` must emit `get_num_stats(priv)` entries. `mlx5e_cond_loopback` must reject switchdev and `mlx5_get_sd(priv->mdev)` with `-EOPNOTSUPP`. [F131, F135, F149, F167]

## Error Handling

- Check `IS_ERR(post_act)` on `get_post_action()` and `IS_ERR_OR_NULL()` on `tc->t` and `flow->rule[0]`. Check `netdev != NULL` on `mlx5_uplink_netdev_get()` and `rpriv->netdev` before `netdev_priv()`. Assign negative errno to `err` before `goto` in `alloc_branch_attr` and `mlx5e_tc_action_miss_mapping_get`, and report user TC rule errors via `NL_SET_ERR_MSG_MOD(extack, ...)` without `WARN_ON`. On `mlx5e_alloc_rx_wqes` failure in `mlx5e_refill_rx_wqes`, free `total_alloc + refill_alloc` WQEs and set `BIT(MLX5E_WQE_FRAG_SKIP_RELEASE)` on `total_alloc + refill` WQEs. [F49, F50, F54, F55, F119, F193]

## External Contracts

- Set LRO `gso_size = DIV_ROUND_UP(cqe_bcnt - hdrlen, lro_num_seg)` and `gso_segs = lro_num_seg` in `mlx5e_build_rx_skb()`, and recompute `tcp->check` with `cqe->check_sum` and pseudo-header in `mlx5e_lro_update_hdr()`. Call `mlx5e_skb_csum_fixup()` in `mlx5e_handle_csum()` when `MLX5E_RQ_STATE_CSUM_FULL` is clear. Scope NIC TC netdev lookups and `tc->netdevice_nb` to `dev_net(priv->netdev)`. [F171, F172, F173, F191]

## Known Pitfalls

- Use `BIT_ULL()` on `dissector->used_keys` in `__parse_cls_flower`; use `do_div(rate, 1000000)` and `max_t(u32, rate, 1)` in `apply_police_params`; keep `sqcc` as `u16` compared with `!=`/`==` in `mlx5e_free_icosq_descs`/`mlx5e_poll_ico_cq`. Match `counter_desc` width/endianness with `MLX5E_READ_CTR*`; never pass `.soffset`-less types to `mlx5e_tc_match_to_reg_match()`; copy narrow bitmasks to an `unsigned long` local before `find_first_bit`/`for_each_set_bit`; check `count >= sizeof(drvinfo->fw_version)` in `mlx5e_rep_get_drvinfo()`. [F121, F124, F127, F134, F136, F141, F142]
