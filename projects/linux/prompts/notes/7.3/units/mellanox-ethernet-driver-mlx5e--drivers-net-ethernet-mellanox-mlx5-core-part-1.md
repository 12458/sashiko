# MELLANOX ETHERNET DRIVER (mlx5e) — drivers/net/ethernet/mellanox/mlx5/core (part 1)

This unit implements the core netdevice lifecycle, control plane, configuration, and flow-steering management for the Mellanox ConnectX-4+ Ethernet driver (`mlx5e`), managing channels (RQs, SQs, CQs, ICOSQs, XDP/XSK queues), shared hardware objects, flow tables (VLAN, L2, TTC, aRFS, ethtool RXNFC), and DIM.

## Architecture & Data Flow
- `fs->vlan` is only allocated when `MLX5E_PROFILE_FEATURE_FS_VLAN` is set; functions reachable on non-`FS_VLAN` profiles (`mlx5e_disable_cvlan_filter`, `mlx5e_fs_vlan_rx_add/kill_vid`, `mlx5e_fix_features`) must check `fs->vlan` for `NULL`. `mlx5e_attach/detach_netdev` must keep `fs->state_destroy` equal to `!test_bit(MLX5E_STATE_DESTROYING, &priv->state)` via `mlx5e_fs_set_state_destroy`, and `mlx5e_del_vlan_rules` must only run after `MLX5E_STATE_DESTROYING` is set and `set_rx_mode_work` is flushed on `priv->wq`. [F237, F266]
- `mlx5e_vlan_rx_add_cvid` must set `vid` in `fs->vlan->active_cvlans` before `mlx5e_add_vlan_rule` (clearing on error), and `mlx5e_fs_vlan_rx_kill_vid` must clear `vid` before `mlx5e_fs_del_vlan_rule` (both call `mlx5e_vport_context_update_vlans`). When `vlan->active_svlans` (`ETH_P_8021AD`) is non-empty, `mlx5e_fix_features` must clear `NETIF_F_HW_VLAN_CTAG_RX`, and `mlx5e_vlan_rx_add_svid` / `mlx5e_fs_vlan_rx_kill_vid` must call `netdev_update_features(netdev)` under `netdev_lock(netdev)`. [F265, F380]
- `mlx5e_apply_netdev_addr` must iterate `fs->l2.netdev_uc/mc` via `mlx5e_for_each_hash_node` (`hlist_for_each_entry_safe`), and `mlx5e_execute_l2_action` must reset `hn->action = MLX5E_ACTION_NONE` on `MLX5E_ACTION_ADD`. In `mlx5e_fill_addr_array`, because `ndev->dev_addr` is in `netdev_uc` and copied to `addr_array[0]` before the loop when `is_uc` is true, the loop must skip `ether_addr_equal(ndev->dev_addr, hn->ai.addr)`. [F296, F297]
- In `mlx5e_create_l2_table_groups` and `__mlx5e_create_vlan_table_groups`, the wildcard trap group (`MLX5E_L2/VLAN_GROUP_TRAP_SIZE`, zeroed `match_criteria_enable`) must be created last at the highest `start_flow_index` (`ix`). In `mlx5e_set_inner_ttc_params` and `mlx5e_set_ttc_params`, skip `mlx5_ttc_is_decrypted_esp_tt(tt)` and route `MLX5_TT_ANY` to `mlx5e_rx_res_get_tirn_direct(rx_res, 0)` instead of `mlx5e_rx_res_get_tirn_rss*`. [F298, F299]
- In `en_fs_ethtool.c`, strip `FLOW_EXT`, `FLOW_MAC_EXT`, and `FLOW_RSS` via `flow_type_mask()` before switching on `flow_type`. `validate_flow` returns a tuple count in `[1, ETHTOOL_NUM_L3_L4_FTS]` or `[1, ETHTOOL_NUM_L2_FTS]` so `prio = max_tuples - num_tuples` in `get_flow_table` stays in bounds, `0` when `ETHER_FLOW` has no masked fields, or negative errno; `mlx5e_ethtool_flow_replace` must reject `num_tuples <= 0`. [F235, F277, F292]
- When `priv->mqprio_rl` is created/replaced in `mlx5e_setup_tc_mqprio_channel` or `mlx5e_set_mqprio_rl`, update `params->mqprio.channel.hw_id` via `mlx5e_mqprio_rl_update_params`, and free old `priv->mqprio_rl` on transition to DCB or TX cleanup (after `mlx5e_safe_switch_params` succeeds). `mlx5e_set_trust_state` must recalculate `params.tx_min_inline_mode` via `mlx5e_params_calc_trust_tx_min_inline_mode` and reopen channels via `mlx5e_safe_switch_params` if it changes. [F269, F275]
- `mlx5e_dcbnl_build_netdev` requires `vport_group_manager` and `qos` caps; DSCP handlers in `en_dcbnl.c` require `MLX5_DSCP_SUPPORTED(mdev)`; and in `mlx5e_build_tc_tx_bw`, dividing/modding `MLX5E_MAX_BW_ALLOC` by `num_ets_zero_bw` must stay guarded by `if (num_ets_zero_bw)` and `if (last_ets_zero_bw_tc != -1)`. `mlx5e_modify_cq_moderation` and DIM require both `cq_moderation` and `cq_period_mode_modify`, plus `cq_period_start_from_cqe` for CQE mode. [F314, F344, F345]
- `netdev->num_tx_queues` (and `priv->txq2sq`, `txq2sq_stats`, `tx_rates`) must be sized by `mlx5e_get_max_num_txqs()` (`nch * profile->max_tc + ptp_txqs + qos_txqs`), and `mlx5e_calc_max_nch()` must subtract those reservations before dividing by `profile->max_tc`. `mlx5e_attach_netdev` must return `-EIO` if `mlx5e_get_max_sq_wqebbs(priv->mdev) < MLX5E_MAX_TX_WQEBBS`. Callbacks indexing `priv->channels.c[queue]` must hold `priv->state_lock` and verify `queue < priv->channels.num`. [F286, F291, F343]
- `mlx5e_init_wqe_alloc_info` must allocate `rq->wqe.frags` and `alloc_units` with `wq_sz << rq->wqe.info.log_num_frags` elements, and when a cyclic RQ in `mlx5e_alloc_rq` has `num_frags < (1 << log_num_frags)`, segment `f = num_frags` must be terminated with `byte_count = 0`, `lkey = params->terminate_lkey_be`, `addr = 0`. In `mlx5e_create_umr_mkey`, `klm_pas_mtt` writes must not exceed `mlx5e_mpwrq_umr_entry_size(umr_mode)`. [F288, F324, F325]
- In `mlx5e_build_nic_netdev`, do not advertise `NETIF_F_LRO` if `tunnel_lro_vxlan/gre` is set, and only advertise `NETIF_F_GRO_HW` when `mlx5e_hw_gro_supported` checks `shampo`, `shampo_header_split_data_merge`, `fixed_buffer_size`, `min_mkey_log_entity_size_fixed_buffer_valid`, and `min_mkey_log_entity_size_fixed_buffer <= MLX5E_SHAMPO_LOG_HEADER_ENTRY_SIZE`. `ETHTOOL_TCP_DATA_SPLIT_ENABLED` requires `NETIF_F_GRO_HW` (enforced in `mlx5e_ethtool_set_tcp_data_split` and `mlx5e_fix_features`). [F341, F342, F378]
- `NETIF_F_GRO_HW` and `NETIF_F_LRO` are mutually exclusive with XDP (`params->xdp_prog`), AF_XDP (`priv->xsk.refcnt`), and legacy cyclic RQ (`!MLX5E_PFLAG_RX_STRIDING_RQ`); `mlx5e_set_xdp_feature` must clear `netdev->xdp_features` when `packet_merge.type != MLX5E_PACKET_MERGE_NONE`. When `params->xdp_prog` is set, `mlx5e_open_rq` must set `MLX5E_RQ_STATE_NO_CSUM_COMPLETE` and `set_pflag_rx_no_csum_complete` must not clear it. [F374, F375]
- In `mlx5e_set_features`, initialize `oper_features = features` (reverting bits on failure in `mlx5e_handle_feature`), handling `NETIF_F_RXFCS` before `NETIF_F_LRO`/`NETIF_F_GRO_HW` when `features & (NETIF_F_GRO_HW | NETIF_F_LRO)` is non-zero, and after them otherwise. In `mlx5e_fix_features`, uplink representors (`mlx5e_is_uplink_rep(priv)`) must set `netdev->netns_immutable = true` (`false` otherwise) and clear `HW_TLS_RX/TX`, `NTUPLE`, `GRO_HW`, `HW_VLAN_CTAG_FILTER`, and `HW_MACSEC`. [F308, F381]

## Synchronization
- Lock order is `rtnl_lock()` -> `netdev_lock(netdev)` -> `mutex_lock(&priv->state_lock)`: unlock `priv->state_lock` before `netdev_update_features(netdev)`, and in `dcbnl_rtnl_ops` callbacks calling `mlx5e_safe_switch_params` (`mlx5e_set_trust_state`), acquire `netdev_lock(priv->netdev)` outside `priv->state_lock`. `async_event` runs in atomic EQ context and must queue `priv->update_carrier_work` on `priv->wq` rather than taking `priv->state_lock`. [F226, F354, F367]
- Deactivating/closing queues (`mlx5e_deactivate_rq/txqsq/icosq`, `mlx5e_close_xdpsq`) must clear `MLX5E_RQ/SQ_STATE_ENABLED` and call `synchronize_net()` before stopping TX queues or destroying hardware queues/descriptors. In `mlx5e_dim_rx/tx_change`, assign `rq/sq->dim` before setting `MLX5E_RQ/SQ_STATE_DIM`, and clear the bit and call `synchronize_net()` before `mlx5e_dim_disable`. [F216, F220]
- Recovery works (`mlx5e_tx_timeout_work`, `mlx5e_rq_timeout_work`, `mlx5e_tx_err_cqe_work`) must acquire `netdev_lock` via a `netdev_trylock` loop that aborts when `MLX5E_STATE_CHANNELS_ACTIVE` or `MLX5E_SQ_STATE_ENABLED` is cleared; clear that bit before `cancel_work_sync`, and in `mlx5e_cancel_tx_timeout_work` guard `cancel_work_sync(&priv->tx_timeout_work)` with `current_work() != &priv->tx_timeout_work`. [F219, F359]
- In `arfs_may_expire_flow` and `arfs_del_rules`, unlink `arfs_rule` entries from `rules_hash` via `mlx5e_for_each_arfs_rule` (`hlist_for_each_entry_safe`) onto a local `del_list` under `arfs->arfs_lock`, then iterate `del_list` with `hlist_for_each_entry_safe` after unlocking to call `mlx5_del_flow_rules` / `cancel_work_sync` and free them. [F294]

## Object Lifetimes
- In `en_fs_ethtool.c`, `mlx5e_ethtool_table` refcounts `eth_ft->ft` via `eth_ft->num_rules`. In `mlx5e_ethtool_flow_replace`, copy `eth_rule->flow_spec = *fs` before `add_ethtool_flow_rule` (`set_flow_attrs` masks `fs` in place), call `put_flow_table(eth_ft)` if `get_ethtool_rule` fails, and once `eth_rule->eth_ft = eth_ft` is set, clean up errors via `del_ethtool_rule` (which drops `eth_rule->rss`, `tot_num_rules`, and `eth_ft`, and unlinks `eth_rule->list`, requiring `list_for_each_entry_safe` in `mlx5e_ethtool_cleanup_steering`). [F194, F267, F293, F340]
- In `mlx5e_create_flow_steering`, `mlx5e_arfs_create_tables` runs before `mlx5e_create_ttc_table` (so `arfs_add_default_rule` must use `mlx5e_rx_res_get_tirn_rss(rx_res, tt)`); if it fails, clear `NETIF_F_NTUPLE` from `netdev->hw_features`. `mlx5e_arfs_destroy_tables` and `mlx5e_arfs_create_tables` error paths must call `mlx5e_fs_set_arfs(fs, NULL)` when freeing `arfs`, and `_mlx5e_cleanup_tables` must run `arfs_del_rules` before `destroy_workqueue(arfs->wq)` and `arfs_destroy_table`. [F197, F198, F199, F334]
- Open `c->rq` and `c->xskrq` hold their own `bpf_prog` ref on `rq->xdp_prog`; when `mlx5e_xdp_set` swaps programs with `reset == false` while opened, it must call `bpf_prog_add(prog, priv->channels.num)` and `bpf_prog_inc(prog)` for each active XSK RQ, releasing `old_prog` via `mlx5e_rq_replace_xdp_prog`. [F203]
- `mlx5e_set_tx_maxrate` shifts `rate << 10` (Mbit/s to Kbit/s) before `mlx5_rl_is_in_range`, `mlx5e_set_sq_maxrate`, and storing in `priv->tx_rates[index]`. `mlx5e_open_txqsq` reapplies `c->priv->tx_rates[sq->txq_ix]`; `mlx5e_set_sq_maxrate` must remove any existing `sq->rate_limit` via `mlx5_rl_remove_rate` and reset `sq->rate_limit = 0` before `mlx5_rl_add_rate` (and remove the new rate if `mlx5e_modify_sq` fails) so `mlx5e_close_txqsq` only removes active rates. [F204, F250, F268]
- In `mlx5e_create_mdev_resources`, `mlx5_alloc_bfreg` failures are non-fatal and set `res->num_bfregs = i`: free `res->bfregs` only up to `res->num_bfregs`, and in `mlx5e_channel_pick_doorbell` check `hw_objs->num_bfregs` for zero (falling back to `&c->mdev->priv.bfreg`) before `c->vec_ix % hw_objs->num_bfregs`. In `mlx5e_dcbnl_ieee_setapp`, revert trust to `MLX5_QPTS_TRUST_PCP` on `fw_err` if `dscp_app_cnt == 0`, and only increment `dscp_app_cnt` when `is_new`. [F214, F215, F282]
- In `mlx5e_close_rq/txqsq/queues`, cancel `dim->work`, `recover_work`, and `rx_timeout_work` via `cancel_work_sync` before destroying hardware queues and freeing memory. `mlx5e_rq_alloc_mpwqe_info`, `mlx5e_init_frags_partition`, and `mlx5e_init_xsk_buffs` must pre-set skip-release bits on all WQE slots, and `mlx5e_free_rx_descs` must free both queued WQEs and `missing` slots (`mlx5_wq_ll_missing(wq) + 1` or `mlx5_wq_cyc_missing(wq)`). [F221, F270]

## API Contracts
- `mlx5e_mqprio_rl_create` returns `NULL` when no TC has `max_rate != 0` (valid no-op), a valid pointer, or `ERR_PTR`; check `IS_ERR(rl)` for error and `if (rl)` before cleanup. `mlx5e_fs_init` and `mlx5e_create_netdev` return `NULL` on failure, whereas `mlx5e_tc_table_alloc`, `mlx5e_rx_res_create`, and `mlx5e_create_devlink` return `ERR_PTR`. [F233, F234]
- SR-IOV VF callbacks in `en_main.c` must pass `vf + 1` to `mlx5_eswitch_*_vport_*`, and `mlx5e_set_vf_rate` must pass `(esw, vf + 1, max_tx_rate, min_tx_rate)` to `mlx5_eswitch_set_vport_rate`. In `mlx5e_create_tises`, set `tisc.lag_tx_port_affinity = i + 1` and `tisc.prio = tc << 1`, and in `err_close_tises` start the inner loop at `for (tc--; tc >= 0; tc--)` and reset `tc = MLX5_MAX_NUM_TC` after each inner loop. [F248, F249, F253, F300]
- `mlx5e_modify_cq_moderation` requires `mlx5e_cq_period_mode(moder.cq_period_mode)` (unlike `mlx5e_modify_cq_period_mode`). `mlx5e_dim_enable` requires `struct mlx5e_rq *` with `mlx5e_rx_dim_work` and `struct mlx5e_txqsq *` with `mlx5e_tx_dim_work`. `set_pflag_tx_port_ts` and `mlx5e_mqprio_channel_validate` must enforce mutual exclusion between `MLX5E_PFLAG_TX_PORT_TS` and `TC_MQPRIO_MODE_CHANNEL`, and forbid modifying either while HTB (`mlx5e_selq_is_htb_enabled(&priv->selq)`) is active. [F251, F260, F327]
- In `en_fs_ethtool.c` and `en_arfs.c`, convert 16-bit network fields (ports, ethertype, `first_vid`) with `ntohs()` before `MLX5_SET`/`MLX5E_FTE_SET`, and copy IPv4/IPv6/MAC addresses in network byte order to `MLX5_ADDR_OF`/`MLX5E_FTE_ADDR_OF`. In `en_dcbnl.c`, `mlx5_max_tc(mdev)` is 0-based (loop `i <= max_tc`; caps use `max_tc + 1`), and `mlx5e_dcbnl_setdcbx/getcap/setall` return `0` on success and `1` on failure. [F278, F283, F387]
- `mlx5e_create_rq/sq/cq` must size `in` to `MLX5_ST_SZ_BYTES(create_*_in) + sizeof(u64) * wq_ctrl.buf.npages`. In `mlx5e_deactivate_txqsq`, check NOP WQE space via `mlx5e_wqc_has_room_for(wq, sq->cc, sq->pc, 1)` and `mlx5_wq_cyc_ctr2ix(wq, sq->pc)`. Wrap 1-arg `preactivate` functions for `mlx5e_safe_switch_params` with `MLX5E_DEFINE_PREACTIVATE_WRAPPER_CTX(fn)`. `mlx5e_activate_priv_channels` must run `mlx5e_build_txq_maps` before `netif_tx_start_all_queues`. [F320, F326, F329, F369]
- `mlx5e_features_check` must validate encapsulated CSUM/GSO packets via `mlx5e_tunnel_features_check`. In `mlx5e_setup_tc`, when `!netif_device_present(dev)`, return `-ENODEV` except for `TC_SETUP_BLOCK` with `FLOW_BLOCK_UNBIND`. `mlx5e_rx_flow_steer` runs in BH context: reject `skb->encapsulation` or non-IPv4/IPv6 with `-EPROTONOSUPPORT`, use `spin_lock_bh(&arfs->arfs_lock)`, `GFP_ATOMIC`, `filter_id = arfs->last_filter_id++ % RPS_NO_FILTER`, and queue to `arfs->wq`. [F379, F382, F388]

## Error Handling
- When an `ERR_PTR`-returning constructor (`mlx5_add_flow_rules`, `mlx5_create_flow_table/group`, `mlx5_crypto_dek_init`, `page_pool_create`, `mlx5e_rx_res_create`) is assigned to a struct field checked with `if (field)` on teardown, extract `PTR_ERR` and reset that field to `NULL`. [F241]
- In `mlx5e_netdev_change_profile` and `mlx5e_ethtool_set_channels`, store cleanup recovery return values in `rollback_err` / `err2` so `err` is preserved. In `set_feature_rx_vlan`, keep `priv->fs->vlan_strip_disable` and `params.vlan_strip_disable` in sync, reverting both to `enable` if `mlx5e_modify_channels_vsd` fails while `MLX5E_STATE_OPENED`. [F243, F264]

## External Contracts
- In `mlx5e_ethtool_get_drvinfo`, if `snprintf` into `drvinfo->fw_version` with `' (%.16s)'` `board_id` returns `count >= sizeof(drvinfo->fw_version)`, re-format `drvinfo->fw_version` with only `'%d.%d.%04d'`. [F285]

## Known Pitfalls
- In `mlx5e_vport_context_update_vlans` and `mlx5e_fill_addr_array`, stop fill loops at `i >= size` (clamped to `1 << log_max_*`). In `mlx5e_dcbnl_ieee_setapp/delapp`, verify `app->selector == IEEE_8021QAZ_APP_SEL_DSCP` and `app->protocol < MLX5E_MAX_DSCP` before indexing `dscp2prio[app->protocol]`. Skip `bitmap_empty` entries in `mlx5e_ethtool2ptys_*_adver_link`, and use bitwise `|=` (not `||`) in `mlx5e_reset_tx/rx_channels_moderation`. [F280, F284, F302, F311]
- In `mlx5e_alloc_rq`, compute striding RQ `dma_offset` via `mul_u32_u32(i, rq->mpwqe.mtts_per_wqe) << rq->mpwqe.page_shift`. In `mlx5e_build_umr_wqe`, compute `ds_cnt` with `DIV_ROUND_UP(..., MLX5_SEND_WQE_DS)` and only access `wqe->hdr` (never `inline_mtts/klms/ksms`). Access `rq->mpwqe.info` via `mlx5e_get_mpw_info(rq, i)` (never `info[i]`), and size `rq->wqe.alloc_units` with `sizeof(*aus->xsk_buffs)` or `sizeof(*aus->frag_pages)` (since `sizeof(union mlx5e_alloc_units) == 0`). [F312, F318, F321, F322, F323]
- In `blocking_event`, only dereference `trap_event_ctx` inside `case MLX5_DRIVER_EVENT_TYPE_TRAP:`. `mlx5e_wait_channels_min_rx_wqes` must skip `MLX5E_CHANNEL_STATE_XSK` channels, poll regular RQs via `mlx5e_wait_for_min_rx_wqes` (using `time_before(jiffies, exp_time)`) with `MLX5E_RQ_WQES_TIMEOUT` until first failure and `0` thereafter, and queue `rq->rx_timeout_work` if `mlx5e_rqwq_get_cur_sz(rq) < min_wqes`. [F319, F328, F347]
