# NVM EXPRESS DRIVER — drivers/nvme

`drivers/nvme` implements the NVMe host driver, Fabrics host library, ANA multipath, ioctl/`io_uring` passthrough, and DH-HMAC-CHAP/TLS authentication.

## Architecture & Data Flow
- `gendisk->private_data` is `nvme_ns_head *` when `nvme_disk_is_ns_head(disk)` (`&nvme_ns_head_ops`) and `nvme_ns *` when `&nvme_bdev_ops`; shared handlers must check `nvme_disk_is_ns_head()` before casting or calling `nvme_get_ns_from_dev()`. `req->q->queuedata` is `nvme_ns *` on I/O queues and `NULL` on admin/fabrics/connect queues; shared paths (`nvme_init_request`, `nvme_req_qid`, `nvme_map_user_request`, `nvme_submit_user_cmd`, `nvme_log_error`) must check for `NULL`. [F41, F42]
- `blk-mq` does not zero `nvme_request` (`status`, `retries`, `flags`); completing un-prepped requests (`!(rq->rq_flags & RQF_DONTPREP)`, e.g. `nvme_fail_nonready_command`) requires `nvme_clear_nvme_request()`. All completion side effects (error logging, `nvme_end_req_zoned()`, bio tracepoints, `nvme_mpath_end_request()`) must be in `__nvme_end_req()` for both `nvme_end_req()` and `nvme_complete_batch_req()`. [F47, F53]
- `nvme_decide_disposition()` must check `blk_noretry_request(req)`, `NVME_STATUS_DNR`, and `nvme_req(req)->retries >= nvme_max_retries` to return `COMPLETE` before `NVME_SC_AUTH_REQUIRED`, `REQ_NVME_MPATH`, or `RETRY`. `nvme_find_rq()` must mask 8-bit `nvme_req(rq)->genctr` with `nvme_genctr_mask` (`0xf`) before comparing with `nvme_genctr_from_cid()`. [F89, F115]
- `nvme_change_ctrl_state()` only transitions to `LIVE` from `CONNECTING`; `RESETTING` from `NEW`/`LIVE`; `CONNECTING` from `NEW`/`RESETTING`; `DELETING` from `LIVE`/`RESETTING`/`CONNECTING`; `DELETING_NOIO` from `DELETING`/`DEAD`; and `DEAD` from `DELETING`. `RESETTING`->`CONNECTING` starts `ctrl->failfast_work`, and `CONNECTING`->`LIVE` stops it, clears `NVME_CTRL_FAILFAST_EXPIRED`, and kicks requeue lists. `nvme_path_is_disabled()` accepts `LIVE`/`DELETING`, and `nvme_check_ready()` returns `queue_live` for Fabrics `DELETING`. [F51, F94, F95]
- Multipath paths (`nvme_scan_work`, `nvme_handle_aen_notice`, `nvme_failover_req`, `nvme_mpath_update`, `nvme_mpath_stop`, `nvme_mpath_add_disk`) must check `ctrl->ana_log_buf != NULL` (`nvme_ctrl_use_ana()`) before queueing `ana_work` or parsing `ana_log_buf`. In `nvme_mpath_init_identify()` when `ctrl->state != NVME_CTRL_LIVE`, `nvme_update_ns_ana_state()` must not call `nvme_mpath_set_live()`; `nvme_start_ctrl()` calls `nvme_mpath_update()` once live and unquiesced. [F60, F143]
- `nvme_parse_ana_log()` must check on every group that `offset` fits `sizeof(*desc)` and `flex_array_size(desc, nsids, nr_nsids)` in `ctrl->ana_log_size`, `desc->grpid` is `1..ctrl->anagrpmax`, and `desc->state` is `1..NVME_ANA_CHANGE`. Under `ctrl->ana_lock`, `nvme_read_ana_log()` counts `NVME_ANA_CHANGE` groups (`nr_change_groups`) and arms `anatt_timer` if `> 0` or calls `timer_delete_sync(&ctrl->anatt_timer)` if `0`. [F62, F74]
- `nvme_mpath_add_sysfs_link()` must check `GD_ADDED` on both `head->disk->state` and `ns->disk->state` before `test_and_set_bit(NVME_NS_SYSFS_ATTR_LINK, &ns->flags)`, clearing it on error. `nvme_update_ns_info()` must copy `logical_block_size`, `physical_block_size`, `io_min`, `io_opt`, `max_write_streams`, and `write_stream_granularity` directly from `ns->disk->queue->limits` to `head->disk->queue`, not just via `queue_limits_stack_bdev()`. [F54, F71]
- When `Set Features` passthrough updates `NVME_FEAT_KATO` (or a persistent discovery controller reconnects with `kato == 0` in `nvme_start_ctrl()`), call `nvme_stop_keep_alive()`, update `ctrl->kato` (`DIV_ROUND_UP(le32_to_cpu(cmd->common.cdw11), 1000)` in `nvme_update_keep_alive()`), and call `nvme_start_keep_alive()`. `nvme_queue_keep_alive_work()` must check `time_after(now, ka_next_check_tm)` before `ka_next_check_tm - now`. [F64, F112, F118]
- Discovery controllers (`NVME_DISC_SUBSYS_NAME`) must never share an existing `nvme_subsystem` in `__nvme_find_get_subsystem()`. `nvmf_host_add()` enforces a 1-to-1 bijection between `host->nqn` and `host->id` under `nvmf_hosts_mutex`, returning `ERR_PTR(-EINVAL)` on mismatch. [F66, F67]
- Passthrough (`nvme_submit_io`, `nvme_user_cmd`, `nvme_user_cmd64`, `nvme_uring_cmd_io`) must reject non-zero user `flags` with `-EINVAL`, and `nvme_init_request()` must clear `NVME_CMD_SGL_ALL`. `nvme_command_effects()` must clear `NVME_CMD_EFFECTS_CSE_MASK` for I/O commands (`ns != NULL`) and `NVME_CMD_EFFECTS_CSER_MASK` admin commands, and `nvme_init_known_nvm_effects()` clears it on `nvme_admin_security_recv`. [F73, F90]
- NVMe I/O `qid` is 1-based (`0` is admin): `nvme_req_qid()` is `queue_num + 1`, and `__nvme_submit_sync_cmd()` passes `qid - 1` to `blk_mq_alloc_request_hctx()`. 1-based fields (`crd` in `nvme_retry_req()`, `(status & NVME_STATUS_CRD) >> 11` `<= 3`; `bi_write_stream` in `nvme_setup_rw()`; `cur_fw_slot` in `nvme_get_fw_slot_info()`) treat `0` as inactive and subtract 1 to index `ctrl->crdt[]`, `head->plids[]`, and `log->frs[]`. [F78, F79, F110]
- `nvme_get_error_status_str()` and `nvme_get_[admin_|fabrics_]opcode_str()` must check `< ARRAY_SIZE(...)` and non-NULL entry on sparse arrays. `opt_tokens` must end with `{ NVMF_OPT_ERR, NULL }`, and `ARRAY_SIZE(opt_tokens)` loops (`__nvmf_concat_opt_tokens()`) must skip `NVMF_OPT_ERR`. [F83, F84]
- In `nvme_complete_async_event()`, `NVME_AER_ERROR_PERSIST_INT_ERR` calls `nvme_handle_aer_persistent_error()` and returns without queueing `async_event_work`. `nvme_queue_scan()` / `nvme_scan_work()` require `NVME_CTRL_LIVE` and `ctrl->tagset != NULL`. `nvme_id_cns_ok()` caps `cns` at `<= 1` (`vs < 1.1.0` or `NVME_QUIRK_IDENTIFY_CNS`) or `<= 3` (`vs < 1.2.0`), and `nvme_identify_ns_descs()` skips `NVME_ID_CNS_NS_DESC_LIST` when `(vs < 1.3.0 && !nvme_multi_css(ctrl))` or `NVME_QUIRK_NO_NS_DESC_LIST`. [F96, F134, F145]
- In `nvme_alloc_io_tag_set()`, `NVME_QUIRK_SHARED_TAGS` sets `reserved_tags = NVME_AQ_DEPTH`, and `NVME_F_FABRICS` sets `BLK_FEAT_SKIP_TAGSET_QUIESCE` on `connect_q`. In `nvme_disable_ctrl()`, `!shutdown && (ctrl->quirks & NVME_QUIRK_DELAY_BEFORE_CHK_RDY)` sleeps `NVME_QUIRK_DELAY_AMOUNT` ms before `nvme_wait_ready()`. [F147, F151, F192]

## Synchronization
- Workqueues drain in order: `ctrl->reset_work` (`nvme_reset_wq`) flushes `nvme_wq` (`nvme_stop_ctrl()`, `nvme_remove_namespaces()`), and `nvme_do_delete_ctrl()` (`nvme_delete_wq`) calls `flush_work(&ctrl->reset_work)`, `nvme_stop_ctrl()`, `nvme_remove_namespaces()`, `ops->delete_ctrl()`, and `nvme_uninit_ctrl()` in order. Never flush `reset_work` from `nvme_wq`. [F18, F131]
- Update `ctrl->state` only via `nvme_change_ctrl_state()` (under `ctrl->lock` with `WRITE_ONCE`); read via `nvme_ctrl_state()`. Before freeing `admin_q`, leave `NVME_CTRL_LIVE` and flush `async_event_work` (`nvme_stop_ctrl()`). [F20, F32]
- `nvme_remove_namespaces()` must call `nvme_mpath_clear_ctrl_paths()` and `nvme_unquiesce_io_queues()` before `flush_work(&ctrl->scan_work)`. In `nvme_scan_ns_list()`, each pass resets `atomic_set(&scan_info.next_nsid, 0)` before `nvme_scan_ns_async` and calls `async_synchronize_full_domain(&domain)` before reusing/freeing `ns_list`. [F21, F101]
- `ctrl->namespaces` updates require `ctrl->namespaces_lock`, aborting in `nvme_alloc_ns()` (`nvme_ns_add_to_ctrl_list()`) if `NVME_CTRL_FROZEN`, using RCU list ops + `synchronize_srcu(&ctrl->srcu)`. Readers under `srcu_read_lock(&ctrl->srcu)` use `list_for_each_entry_srcu()` and `nvme_get_ns()`. `nvme_remove_[invalid_]namespaces()` detaches under `namespaces_lock`, calls `synchronize_srcu(&ctrl->srcu)`, and iterates unlocked with `list_for_each_entry_safe()` to call `nvme_ns_remove()`. [F22, F98, F171]
- `subsys->lock` protects `subsys->nsheads`, `head->list`, and `head->delayed_removal_secs` / `NVME_NSHEAD_QUEUE_IF_NO_PATH` (updated together in `delayed_removal_secs_store()` + `synchronize_srcu(&head->srcu)`). Lockless `head->list` / `current_path[]` readers need `srcu_read_lock(&head->srcu)`. `nvme_ns_remove()` clears `NVME_NS_READY`, calls `synchronize_srcu(&ns->head->srcu)` before `nvme_mpath_clear_current_path()`, again if cleared, and again after `list_del_rcu(&ns->siblings)` under `subsys->lock`. [F25, F58, F173]
- `nvme_mpath_remove_disk()` and `nvme_remove_head_work()` must hold `head->subsys->lock` and recheck `list_empty(&head->list)` before unlinking `head->entry` and calling `nvme_remove_head()`. `head->requeue_lock` (`nvme_failover_req`, `nvme_ns_head_submit_bio`, `nvme_requeue_work`) always requires `spin_lock_irqsave` / `spin_lock_irq`. [F26, F160]
- Accessing `ctrl->ana_log_buf` requires `ctrl->ana_lock`. Before freeing/reallocating `ana_log_buf` in `nvme_mpath_uninit()` or `nvme_mpath_init_identify()` (which also sets `ctrl->nr_active = 0`), `nvme_mpath_stop()` must stop `anatt_timer` and `ana_work`. [F31, F61]
- `nvme_subsystems_lock` nests outside `subsys->lock` (`nvme_global_check_duplicate_ids()`) and protects `nvme_subsystems` and `subsys->ctrls`. Under it, `__nvme_find_get_subsystem()` uses `kref_get_unless_zero(&subsys->ref)`, and `nvme_subsys_iopolicy_update()` calls `nvme_mpath_clear_ctrl_paths()` across `subsys->ctrls`. [F35, F59, F164]
- `nvmf_create_ctrl()` holds `nvmf_transports_rwsem` across `nvmf_lookup_transport()` and `try_module_get(ops->module)` on static `nvmf_transport_ops`. Keep-alive and Fabrics reg/connect commands must use `BLK_MQ_REQ_RESERVED` / `NVME_SUBMIT_RESERVED` (plus `NOWAIT` for connect/keep-alive). [F34, F174]
- `nvme_setup_discard()` allocates `sizeof(*range) * NVME_DSM_MAX_RANGES` with `GFP_ATOMIC | __GFP_NOWARN`, falling back to `ctrl->discard_page` via `test_and_set_bit_lock(0, &ctrl->discard_page_busy)` (`BLK_STS_RESOURCE` if busy), released by `clear_bit_unlock()` in `nvme_cleanup_cmd()`. [F122, F158]

## Object Lifetimes
- When removing the last `nvme_ns` in `nvme_alloc_ns()` or in `nvme_remove_head()` / `nvme_mpath_remove_disk()`, call `nvme_put_ns_head()` if `head->disk != NULL` (even if `!NVME_NSHEAD_DISK_LIVE`). Queueing `head->remove_work` requires `try_module_get(THIS_MODULE)` balanced by `module_put()` in `nvme_remove_head_work()`. `nvme_mpath_put_disk()` must schedule/flush `requeue_work` and flush `partition_scan_work` before `put_disk()`. [F1, F15, F16]
- `nvme_init_ctrl()` takes 1 ref on `ctrl_device` and `nvme_add_ctrl()` takes a 2nd; errors after `nvme_add_ctrl()` require both `nvme_uninit_ctrl()` and `nvme_put_ctrl()`. After `device_initialize(&subsys->dev)` in `nvme_init_subsystem()`, free via `put_device()` / `nvme_put_subsystem()` (not `kfree()`), keeping `subsys->instance = -1` until registered. [F5, F139]
- `nvmf_parse_options()` must `kfree()`/`key_put()` prior repeatable option values before overwriting, and never leave `ERR_PTR` in `opts->host`, `opts->keyring`, or `opts->tls_key` on failure. If `nvme_alloc_[admin|io]_tag_set()` fails, destroy queues (`blk_mq_destroy_queue()` + `blk_put_queue()`), free tagset, and null `admin_q`/`fabrics_q`/`connect_q`. [F7, F13, F45]
- `nvme_uring_cmd_io()` saves `pdu->bio = req->bio` before submission so `nvme_uring_task_cb()` calls `blk_rq_unmap_user(pdu->bio)` before `io_uring_cmd_done32()`. `nvme_ns_head_submit_bio()` calls `bio_split_to_limits(bio)` before remapping `bi_bdev`. [F11, F187]
- Balance `dev_pm_qos_[expose|hide]_latency_tolerance()` with `ctrl->apst_enabled` in `nvme_init_identify()` and hide in `nvme_uninit_ctrl()`. In `nvme_configure_opal()`, call `opal_unlock_from_suspend()` when `NVME_CTRL_OACS_SEC_SUPP && ctrl->opal_dev && was_suspended`, or `free_opal_dev()` + `ctrl->opal_dev = NULL` if `!NVME_CTRL_OACS_SEC_SUPP`. [F154, F155]

## API Contracts
- If `->queue_rq` fails after `nvme_setup_cmd()`, call `nvme_cleanup_cmd(req)` and, if calling `nvme_host_path_error(req)`, unwind and return `BLK_STS_OK`. Transport PDU structs must put `struct nvme_request` at offset 0. [F8, F126]
- `__nvme_submit_sync_cmd()` only sets `*result` when `result && ret >= 0`. `nvme_map_user_request()` takes `NVME_IOCTL_*` bitmasks (`NVME_IOCTL_VEC`), not `bool`. `nvmf_create_ctrl()` checks `(opts->mask & required_opts) == required_opts` and clears `opts->mask &= ~NVMF_REQUIRED_OPTS` before transport checks. `nvme_dhchap_key` allocations must use `nvme_auth_key_struct_size(len)`. [F46, F48, F92, F121]
- `nvme_ctrl_from_file()` must check `file->f_op == &nvme_dev_fops`. `nvme_enable_ctrl()` writes `ctrl_config` (`NVME_CC_CRIME`/`NVME_CC_ENABLE` clear) to `NVME_REG_CC`, re-reads `NVME_REG_CAP` before computing timeout (`max(NVME_CAP_TIMEOUT(cap), NVME_CRTO_CRWMT(crto))` if `NVME_CAP_CRMS_CRWMS`), then sets `NVME_CC_ENABLE` and calls `nvme_wait_ready()`. [F128, F149, F150]

## Error Handling
- Sync helpers return `< 0` (errno) or `> 0` (NVMe status): guard `NVME_STATUS_DNR` with `ret > 0`; convert `ret > 0` via `blk_status_to_errno(nvme_error_status(ret))` before `ERR_PTR()`; and treat `status < 0 || status == NVME_SC_HOST_PATH_ERROR` as fatal (`nvme_set_queue_count()`). `nvme_error_status()` maps `NVME_SC_CMD_SIZE_LIM_EXCEEDED` (`0x183`) to `BLK_STS_IOERR` (not `BLK_STS_NOTSUPP`). [F36, F37, F38, F97]
- `nvme_check_ctrl_fabric_info()` warns and sets `ctrl->maxcmd = ctrl->sqsize + 1` if `maxcmd == 0`. `nvme_wait_ready()` returns `-ENODEV` on `csts == ~0` or timeout, and `-EINTR` on fatal signal. `IORING_URING_CMD_FIXED` uses `io_uring_cmd_import_fixed[_vec]()` + `blk_rq_map_user_iov()` without `WARN_ON_ONCE` on bad user flags. [F144, F152, F179]

## External Contracts
- In `nvme_configure_metadata()`, if `!(id->dps & NVME_NS_DPS_PI_FIRST)`, clear `head->pi_type = 0` when `disable_pi_offsets` is true; else `info->pi_offset = head->ms - head->pi_size`. `nvme_ns_ioctl()` handles `NVME_IOCTL_SUBMIT_IO32`, uses `nvme_to_user_ptr()`, and calls `force_successful_syscall_return()` for `NVME_IOCTL_ID`. `nvme_uring_cmd_checks()` requires `IO_URING_F_SQE128 | IO_URING_F_CQE32`. [F87, F175, F177, F182]

## Known Pitfalls
- Use `le32_to_cpu()`/`le64_to_cpu()` on `cdw10..cdw15` and `result` (`nvme_log_err_passthru()`), `le16_to_cpu(status) >> 1` in `nvme_try_complete_req()`, and map each `cdw10..cdw15`/`cdw2[0..1]` without typo duplication. `nvme_find_get_ns()` and `nvme_round_robin_path()` must not use the loop cursor `ns` after loop exit. `nvme_lookup_ana_group_desc()` copies only `*dst = *desc`, so `nvme_update_ns_ana_state()` / `nvme_mpath_add_disk()` must not read `desc->nsids[]`. [F85, F99, F105, F125]
- `nvme_process_ns_desc()` uses `(void *)cur + sizeof(*cur)`, and `nvme_identify_ns_descs()` breaks on `cur->nidl == 0` or `len < 0` before adding `sizeof(*cur)`. `nvme_query_fdp_info()` uses `sizeof(*head->plids)`. Avoid overflow/truncation: `check_shl_overflow` in `nvme_mps_to_sectors()`; bound `ctrl->dmrsl` by `nvme_sect_to_lba(ns->head, UINT_MAX)` in `nvme_config_discard()`; `do_div(transition_ms, 20)` + clamp `(1 << 24) - 1` in `nvme_configure_apst()`; `(timeout + 1) / 2` in `nvme_[en|dis]able_ctrl()`; reject `reconnect_delay <= 0` in `nvmf_parse_options()`; clamp `default_ps_max_latency_us` to `S32_MAX` in `nvme_add_ctrl()`. [F102, F108, F109, F111, F113, F114, F117, F119, F124]
