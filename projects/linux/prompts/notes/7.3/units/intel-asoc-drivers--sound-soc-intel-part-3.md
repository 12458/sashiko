# INTEL ASoC DRIVERS — sound/soc/intel (part 3)

This unit covers additional SOF machine drivers (`sof_sdw.c`, `sof_ssp_amp.c`, `sof_wm8804.c`), the Wildcat Point / Lynx Point AudioDSP platform driver (`catpt`) for DSP lifecycle, DesignWare DMA, firmware loading, IPC, and PCM streams, and common Intel ACPI machine match tables and topology/SDCA quirk helpers from Bay Trail through Panther Lake.

## Architecture & Data Flow

- Whenever DRAM or IRAM regions in `cdev->dram` or `cdev->iram` are requested or released after firmware boot, `catpt_dsp_update_srampge()` must be called to update PCI `VDRTCTL0` SRAM power-gating bits. `catpt_sram_init()` sets inclusive resource bounds `[start, start + size - 1]`, and `catpt_dsp_update_srampge()` computes inclusive block indices `l = (res->start - sram->start) / CATPT_MEMBLOCK_SIZE` and `h = (res->end - sram->start) / CATPT_MEMBLOCK_SIZE` to build `GENMASK(h, l)`. Since `VDRTCTL0` bits are active-low (`0` = powered on, `1` = power-gated), busy block masks must be inverted (`~(new << __ffs(mask)) & mask`) and newly enabled blocks iterated with `for_each_clear_bit_from()`. [F166, F194, F214]
- In `catpt_dev_init()`, `cdev->devfmt[i].iface` is initialized to `UINT_MAX` as the uninitialized sentinel (since `0` is `CATPT_SSP_IFACE_0`), and `catpt_dai_pcm_new()` must only copy `devfmt` into `cdev->devfmt[devfmt.iface]` after `catpt_ipc_set_device_format()` succeeds so `catpt_resume()` only replays valid SSP formats. [F155]
- In `catpt_dai_trigger()`, `SNDRV_PCM_TRIGGER_STOP` must set `stream->prepared = false` before falling through to `catpt_dsp_update_lpclock(cdev)`, while `SNDRV_PCM_TRIGGER_START` must call `catpt_dsp_update_lpclock(cdev)` before `catpt_ipc_resume_stream()`. [F204]
- In `catpt_dsp_do_send_msg()`, both `request.size` and `reply->size` (when `reply` is non-NULL) must be checked not to exceed `ipc->config.outbox_size` before writing the request to the outbox or setting `ipc->rx.size`. [F187]
- In `catpt/pcm.c`, `catpt_stream_volume()` and `catpt_mixer_volume()` must clamp `channel >= CATPT_CHANNELS_MAX` to 0 before indexing `volume_regaddr[]`, and `ctlvol_to_dspvol()` must clamp `value > DSP_VOLUME_STEP_MAX` (30) to 0 before computing `DSP_VOLUME_MAX >> (DSP_VOLUME_STEP_MAX - value)`. Conversely, `dspvol_to_ctlvol()` must check `volume > DSP_VOLUME_MAX` and `volume != 0` before calling `__fls(volume)`, because `__fls(0)` is undefined and bit 31 set would return 31 (`> DSP_VOLUME_STEP_MAX`). [F188, F219]
- In `catpt_coredump()`, parsing of the fixed-size `cdev->ipc.config.fw_info` buffer (`FW_INFO_SIZE_MAX` = 100 bytes) must bound token scanning via `strnchr(info, eof - info, ' ')` and hash copying via `min_t(u32, eof - info, CATPT_DUMP_HASH_SIZE)` so it never reads past `eof`. [F195]
- In `sof_sdw.c` and `sof_sdw_hdmi.c`, `snd_soc_card_get_drvdata(card)` always stores a `struct asoc_sdw_mc_private *`, while the Intel-specific `struct intel_mc_ctx *` is stored in and retrieved from `ctx->private`. [F229]
- In `mc_probe()` (`sof_sdw.c`), `codec_info_list[i].amp_num` must be reset to `0` for all `i < ctx->codec_info_list_count` before calling `sof_card_dai_links_create(card)` so per-codec `init` callbacks accumulate active amplifier counts from zero on each probe. [F162]
- In `sof_card_dai_links_create()`, the DMIC DAI link count `dmic_num` must not overwrite `mach_params->dmic_num`, which stores the mic channel count for `card->components` (`cfg-mics:%d`) and must be set to 0 when `ctx->ignore_internal_dmic` is true or `DMIC_DEFAULT_CHANNELS` when enabled via `SOC_SDW_PCH_DMIC`. [F174]
- In `sof_sdw.c`, each DAI link created in `create_sdw_dailink()` or via `asoc_sdw_init_simple_dai_link()` must use its own dynamically allocated `struct snd_soc_dai_link_component *platform` rather than a shared static array. In `create_dmic_dailinks()` and `create_hdmi_dailinks()`, `asoc_sdw_dmic_init` and `sof_sdw_hdmi_init` must be passed only on the first DAI link (`"dmic01"` and `i == 0`), with `NULL` passed for subsequent DMIC (`"dmic16k"`) and HDMI (`i > 0`) links. [F175, F215]
- In `sof_sdw_get_tplg_files()`, `tplg_mask` must test and set `BIT(tplg_dev)` to skip duplicate function types across `for_each_card_prelinks(card, i, dai_link)`, and `(*tplg_files)` must be indexed by `tplg_num++` rather than the DAI link cursor `i`. [F212]
- In `sof_wm8804_hw_params()`, `ctx->sample_rate` must be cleared to 0 before reconfiguring clock dividers, PLL, or SYSCLK and only set to `samplerate` after all clock and component updates succeed; when switching clock GPIOs (`ctx->gpio_44`, `ctx->gpio_48`), the GPIO driven LOW must be set before the GPIO driven HIGH. [F177]
- In `sound/soc/intel/common/soc-acpi-intel-ssp-common.c`, monolithic audio components that can serve as both headphone codec and speaker amplifier (such as `RT5650`) must be listed in both `codecs[]` and `amps[]`, and placed at the end of `amps[]` after all dedicated amplifier entries. [F178]
- Every `struct snd_soc_acpi_link_adr` array assigned to `snd_soc_acpi_mach.links` in Intel ACPI match tables must end with an empty `{}` sentinel element because `hda_sdw_machine_select()` and `asoc_sdw_parse_sdw_endpoints()` iterate until `!link->num_adr`. [F181]
- In `snd_soc_acpi_intel_*_sdw_machines` tables (e.g., ADL, ARL, MTL, PTL), entries with more active links in `.link_mask`, more devices in `.links`, or `.machine_check` must precede subset entries. In I2S `snd_soc_acpi_mach` tables (e.g., ADL, ARL, MTL, PTL, RPL), `.machine_quirk` entries must precede generic entries for the same codec, and amp-only boards (e.g., `CSC3541`, `INTC10B0`, `10EC1308`) must be placed at the end. [F198, F199]

## Synchronization

- In `catpt_dsp_do_send_msg()`, `catpt_ipc_msg_init()` and `catpt_dsp_send_tx()` must execute together under `spin_lock_irqsave(&ipc->lock, flags)` so `ipc->rx.size` and `done_completion`/`busy_completion` are reinitialized before writing `CATPT_SHIM_IPCC` can trigger an immediate reply interrupt in `catpt_dsp_irq_handler()`. [F141]
- In `catpt_boot_firmware()`, `reinit_completion(&cdev->fw_ready)` must be called before `catpt_dsp_stall(cdev, false)` un-stalls the DSP, and in `catpt_dsp_process_response()`, `catpt_ipc_arm()` must complete before `complete(&cdev->fw_ready)` wakes the booting thread. [F143]
- In `catpt_dsp_irq_handler()` and `catpt_dsp_irq_thread()`, `catpt_dsp_copy_rx()` and `catpt_dsp_process_response()` must finish copying mailbox data and signaling completions before clearing `CATPT_IPCC_DONE` or setting `CATPT_IPCD_DONE` and unmasking `CATPT_IMC_IPCCD` or `CATPT_IMC_IPCDB`. [F144]
- `catpt_dsp_send_msg_timeout()`, `catpt_dsp_send_msg()`, and all `catpt_ipc_*` wrappers acquire `cdev->ipc.mutex` and sleep on `wait_for_completion_timeout()`, so they may only be called from sleepable process or threaded-IRQ contexts. Delayed DSP replies and notifications (`CATPT_ISC_IPCDB`) must be masked in `catpt_dsp_irq_handler()` and processed in `catpt_dsp_irq_thread()`, because `catpt_dsp_process_response()` performs `GFP_KERNEL` allocations, `vzalloc()`/`dev_coredumpv()`, and sleeping IPC calls. [F254, F255]

## Object Lifetimes

- In `catpt_acpi_remove()`, `pm_runtime_disable(cdev->dev)` must be called before `catpt_dmac_remove(cdev)` so runtime PM get/put calls inside `dw_dma_remove()` on the shared device do not trigger postmortem runtime resume and suspend. [F127]
- Every SRAM child `struct resource` allocated via `catpt_request_region()` or `__request_region()` must be unlinked with `release_resource(res)` and then freed with `kfree(res)` in `catpt_dai_shutdown()` or `catpt_sram_free()`. When walking `sram->child` in `catpt_sram_free()`, `res->sibling` must be saved to a local pointer before calling `release_resource(res)` and `kfree(res)`. [F131, F207]
- In `catpt_load_block()`, SRAM regions (`__request_region`) must only be requested when `alloc` is true during initial firmware loading (`catpt_load_module`), and if `catpt_dma_memcpy_todsp()` fails it must roll back the reservation with `__release_region(sram, dst_addr, blk->size)`. [F134]
- In `sof_wm8804_probe()`, the `struct acpi_device` reference from `acpi_dev_get_first_match_dev()` must be released with `acpi_dev_put(adev)`, and when `SOF_WM8804_UP2_QUIRK` is set, `sof_wm8804_remove()` must call `gpiod_remove_lookup_table(&up2_gpios_table)` to balance `gpiod_add_lookup_table()`. [F139]

## API Contracts

- In `catpt_coredump()`, ownership of the `vzalloc()`-allocated dump buffer is transferred to `dev_coredumpv(cdev->dev, dump, dump_size, GFP_KERNEL)`; callers must not allocate it with `kmalloc()` or call `vfree(dump)` afterwards. [F135]
- In `sound/soc/intel/catpt/messages.c`, any IPC helper sending a header-only message without a payload must zero-initialize `struct catpt_ipc_msg request = { {0}}` because `catpt_dsp_do_send_msg()` checks `request.size > ipc->config.outbox_size` and `catpt_dsp_send_tx()` copies `request.size` bytes from `request.data`. [F151]
- Host DRAM offsets sent to the DSP in `catpt_ipc_alloc_stream()` must use `catpt_to_dsp_offset()`, whereas DSP offsets in `cdev->dx_ctx.meminfo[i].offset` must use `catpt_to_host_offset()` before checking `cdev->dram` bounds or adding to `cdev->lpe_base` and `cdev->dxbuf_paddr`. [F156]
- In `catpt_dsp_update_srampge()`, `catpt_dsp_power_down()`, and `catpt_dsp_power_up()`, core clock gating (`CATPT_VDRTCTL2_DCLCGE` in `VDRTCTL2`) must be disabled before modifying `VDRTCTL0`, `PMCS`, or SHIM/SSP power-cycle registers, and re-enabled once the sequence finishes. [F238]
- In `catpt/pcm.c`, because 24-bit audio is packed in 32-bit containers, `catpt_pcm_hardware` and 24-bit-capable FE entries in `dai_drivers[]` must advertise `SNDRV_PCM_FMTBIT_S32_LE` in `.formats` with `SNDRV_PCM_SUBFMTBIT_MSBITS_24 | SNDRV_PCM_SUBFMTBIT_MSBITS_MAX` in `.subformats` rather than `SNDRV_PCM_FMTBIT_S24_LE`. [F265]
- In `catpt/pcm.c`, `catpt_ipc_set_write_pos()` must only be called for `CATPT_STRM_TYPE_RENDER` streams in `catpt_dai_trigger()` and `catpt_stream_update_position()` with a byte offset from `frames_to_bytes()`, while `catpt_component_pointer()` must convert the MMIO byte position via `bytes_to_frames()`. [F268]
- Every SoundWire DAI link initialized in `create_sdw_dailink()` must set `nonatomic = true` because SoundWire stream and bank-switch operations in `sdw_ops` sleep on `wait_for_completion()`. [F149]
- In `create_sdw_dailinks()` and `create_sdw_dailink()`, `intel_ctx->sdw_pin_index[i]` must be initialized to `SOC_SDW_INTEL_BIDIR_PDI_BASE` before iterating `sof_dais`, and the 1-hot bitmask `sof_end->link_mask` must be converted to a 0-based link index via `ffs(sof_end->link_mask) - 1` when indexing `sdw_pin_index` or formatting DAI names. [F161]
- Unlike `.machine_quirk` callbacks in `soc-acpi-intel-*-match.c` which cast `void *arg` to `struct snd_soc_acpi_mach *` and return `struct snd_soc_acpi_mach *`, `.machine_check` callback `snd_soc_acpi_intel_sdca_is_device_rt712_vb(void *arg)` receives a nullable `struct sdw_intel_ctx *` and returns `bool`. [F164]
- In `sound/soc/intel/common/soc-intel-quirks.h`, the non-stub definition of `soc_intel_is_byt_cr()` calling `iosf_mbi_available()` and `iosf_mbi_read()` must be guarded by `#if IS_REACHABLE(CONFIG_IOSF_MBI)` rather than `#if IS_ENABLED(CONFIG_X86)` or `IS_ENABLED(CONFIG_IOSF_MBI)`. [F266]

## Error Handling

- Because `catpt_dsp_send_msg()` and `catpt_ipc_*` wrappers in `catpt/messages.c` return either a negative errno or a positive `enum catpt_reply_status` on DSP failure, callers returning kernel error codes must test `if (ret)` and translate non-zero values with `CATPT_IPC_ERROR(ret)`. [F150]
- In `catpt_dma_memcpy()`, the cookie returned by `dmaengine_submit(desc)` must be checked with `dma_submit_error()` before calling `dma_wait_for_async_tx(desc)`, and on submission failure execution must still clear the channel's `CATPT_HMDC_HDDA` bit in the `HMDC` shim register. [F153]
- `catpt_request_region()` returns `NULL` (not `ERR_PTR`) when no free SRAM region is available or `__request_region()` fails, and `cdev->scratch` remains `NULL` when `scratch_size` is 0, so `catpt_ipc_alloc_stream()` must guard `scratch` for `NULL` before dereferencing it. [F154]
- In `create_sdw_dailink()`, optional callbacks `sof_end->codec_info->add_sidecar` and `sof_end->dai_info->init` can be `NULL` even when `sof_end->include_sidecar` is true, so both must be checked for `NULL` before invocation. In `create_sdw_dailinks()`, `current_be_id` must be initialized to `0` before each `create_sdw_dailink()` call because it skips streams with `sof_dai->num_devs[stream] == 0` and can return `0` without writing `*be_id`. [F157, F158]
- In `sof_sdw.c` and `sof-function-topology-lib.c`, every `devm_kasprintf()` allocation for DAI link names, CPU DAI names, codec names, `card->components`, or topology filenames must be checked for `NULL` before use, returning `-ENOMEM` on failure. [F159]
- `sof_sdw_get_tplg_files()` must return a positive file count when all function topologies exist, `0` when a DAI link is unsupported or a sub-topology file is missing (falling back to the monolithic topology), and a negative errno (`-EINVAL` or `-ENOMEM`) only on fatal parsing or allocation errors. [F163]
- In `sof_wm8804_hw_params()`, `ctx->gpio_44` and `ctx->gpio_48` must be checked with `IS_ERR_OR_NULL()` before calling `gpiod_set_value_cansleep()`, as `sof_wm8804_probe()` leaves them `NULL` when `SOF_WM8804_UP2_QUIRK` is not set. [F165]

## External Contracts

- In `catpt_dsp_process_response()`, the 29-bit `msg.mailbox_address` field from `union catpt_notify_msg` must be shifted left by 3 (`msg.mailbox_address << 3`) to reconstruct the byte offset in `cdev->lpe_ba` for reading `struct catpt_fw_ready`. [F221]
- In `catpt_load_module()`, `type->entry_point` in `struct catpt_module_type` must be set to `mod->entry_point - 4` because the DSP expects the header's entry point address decremented by 4. [F223]
- In `catpt_dmac_probe()`, the device DMA and coherent masks must be restricted to 31 bits (`DMA_BIT_MASK(31)`) because `catpt_dma_memcpy_todsp()` and `catpt_dma_memcpy_fromdsp()` set bits 31:20 (`CATPT_DMA_DSP_ADDR_MASK`) to address DSP SRAM rather than host memory. [F259]
- In Intel SoundWire ACPI match tables, `struct snd_soc_acpi_adr_device` entries for CS35L56 amplifiers must use generic `"AMPn"` `.name_prefix` strings (e.g., `"AMP1"`..`"AMP8"`) rather than chip-specific prefix strings. [F184]
- Every `struct snd_soc_acpi_mach` `.drv_name` string in `soc-acpi-intel-*-match.c` and its corresponding `struct platform_device_id` `.name` in the machine driver must be at most `PLATFORM_NAME_SIZE - 1` (23) characters so the NUL terminator fits. [F233]

## Known Pitfalls

- `catpt_request_region()` unconditionally dereferences `root->child` and only searches gaps before existing child resources, relying on `catpt_first_boot_firmware()` having populated `cdev->dram.child` and reserved the tail region `[res->end + 1, cdev->dram.end]`. [F205]
- When `catpt_dsp_set_srampge()` updates `VDRTCTL0` to power-ungate SRAM blocks (clearing bits from 1 to 0), it must wait `udelay(60)` and then perform a 4-byte dummy `memcpy_fromio()` from the base of each newly enabled `CATPT_MEMBLOCK_SIZE` block before any other access to that block. [F237]
- Because Catpt AudioDSP hardware does not reset its SHIM and SSP registers across power cycles, both `catpt_dsp_power_down()` and `catpt_dsp_power_up()` must call `catpt_dsp_set_regs_defaults()` to restore default register values. [F239]
- In `create_ssp_dailinks()`, the set-bit index `i` from `for_each_set_bit(i, &ssp_mask, ...)` must be used for the SSP port number in `"SSP%d-Codec"` and `"SSP%d Pin"`, while the sequential counter `j++` must be used for the ACPI instance suffix in `"i2c-%s:0%d"`. [F211]
