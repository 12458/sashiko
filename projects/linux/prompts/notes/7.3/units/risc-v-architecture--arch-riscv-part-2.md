# RISC-V ARCHITECTURE — arch/riscv (part 2)

Provides core RISC-V architecture headers (MMU page tables, CSRs, SBI, atomics, uaccess, vector state, instruction encodings, and UAPI structures), vendor errata patching (Andes, MIPS, SiFive, T-Head), and RISC-V vector crypto glue drivers (AES, GHASH, SM3, SM4).

## Architecture & Data Flow

- `struct thread_info` must stay at offset 0 of `struct task_struct` (and changes synced with `asm-offsets.c`) so `tp` (`riscv_current_is_tp`) indexes both via `TASK_TI_*`; `asm_per_cpu` must load 32-bit `TASK_TI_CPU_NUM(tp)` with `lw`, not `REG_L`. Under `CONFIG_SHADOW_CALL_STACK`, `gp` holds `scs_sp` instead of `__global_pointer$`, so `load_global_pointer` must be a no-op and assembly entry/exit paths must preserve/switch `gp` via `scs_*` macros. [F52, F58, F128]
- Vector status helpers on `pt_regs->status` must use `__riscv_v_vstate_or` and `__riscv_v_vstate_check` so `SR_VS_THEAD` (bits 24:23) is used when `has_xtheadvector()` is true and `SR_VS` (bits 10:9) otherwise. In `__vstate_csr_save`/`__vstate_csr_restore`, when `has_xtheadvector()` is true, `SR_FS_DIRTY` must be set in `CSR_STATUS` before accessing `CSR_VXSAT`/`CSR_VXRM` and restored if `(status & SR_FS) != SR_FS_DIRTY`. [F36, F37]
- `riscv_v_vsize` is the total byte size of all 32 vector registers (`32 * vlenb`), so single-register `vlenb` is `riscv_v_vsize / 32` and `riscv_vector_vlen()` in bits is `riscv_v_vsize / 32 * 8`. `riscv64_aes_xts_supported()` must require `riscv_vector_vlen() < 2048` before registering `riscv64_zvkned_zvbb_zvkg_aes_skcipher_alg`. [F68, F102]
- `riscv_v_vstate_discard` must mark `regs->status` dirty (`__riscv_v_vstate_dirty`) after clobbering vector registers, while `riscv_v_vstate_save`/`restore` must mark `regs->status` clean (`__riscv_v_vstate_clean`). `riscv_v_vstate_set_restore` must set both `TIF_RISCV_V_DEFER_RESTORE` and `riscv_v_vstate_on(regs)` when `riscv_v_vstate_query(regs)` is true. [F38, F39]
- In `__switch_to_vector`, if `riscv_preempt_v_started(prev)` and `riscv_v_is_on()` hold, it must call `riscv_v_disable()` and set `RISCV_PREEMPT_V_IN_SCHEDULE`; when switching to `next` with `RISCV_PREEMPT_V_IN_SCHEDULE` set, it must clear that flag and call `riscv_v_enable()` instead of `riscv_preempt_v_set_restore(next)`. Updating `task->thread.envcfg` via `envcfg_update_bits` must immediately write `CSR_ENVCFG` when `task == current`, alongside `__switch_to_envcfg` on context switch. [F40, F41]
- In `pgd_alloc`, `sync_kernel_mappings(pgd)` must copy kernel PGD entries from `init_mm.pgd + USER_PTRS_PER_PGD` to `pgd + USER_PTRS_PER_PGD` (unscaled `pgd_t *` addition) with byte length `(PTRS_PER_PGD - USER_PTRS_PER_PGD) * sizeof(pgd_t)`. In `PGDIR_SHIFT`, `P4D_SHIFT`, and `VA_BITS`, `pgtable_l5_enabled` must be tested before `pgtable_l4_enabled` because `pgtable_l4_enabled` stays true under Sv57. [F45, F74, F103]
- Under `CONFIG_TRANSPARENT_HUGEPAGE`, `pmd_present(pmd)` must check `_PAGE_LEAF` alongside `_PAGE_PRESENT | _PAGE_PROT_NONE` so a PMD stays recognized by `pmd_trans_huge()` while `split_huge_page()` clears `_PAGE_PRESENT`. The sparse `vmemmap` pointer must be biased by `vmemmap_start_pfn` (not `ARCH_PFN_OFFSET`). On T-Head (`CONFIG_ERRATA_THEAD_MAE`), `pfn_pgd`, `pfn_pmd`, `pfn_pte`, and `pte_modify` must apply `ALT_THEAD_PMA` to protection bits. [F49, F59, F139]
- Under `CONFIG_RISCV_ISA_SUPM`, `init_new_context` must clear `MM_CONTEXT_LOCK_PMLEN` and `activate_mm` must reset `next->context.pmlen = 0`; `__untagged_addr_remote()` must sign-extend via `(long)(addr << pmlen) >> pmlen` on `CONFIG_MMU` (zero-extend otherwise), and `access_ok()` must untag via `untagged_addr()` before `__access_ok()`. [F48, F56]
- In `ALTERNATIVE_CFG` and `ALT_NEW_CONTENT`, old and replacement blocks must be wrapped in `.option push`, `.option norvc`, `.option norelax`, `.option pop` with equal byte lengths, and `__ALT_PTR(a, f)` must compute `(void *)&(a)->f + (a)->f`. `runtime_const_ptr()` and `runtime_const_shift_right_32()` must use `.option norvc` so `__runtime_fixup_ptr()`/`shift()` patch fixed 4-byte instructions at `where + 0/4/8/12`; `runtime_const_fixup()` must resolve self-relative `s32` entries as `*start + (void *)start`. In `__runtime_fixup_32()`, when `upper_immediate & 0xfffff000` is 0 (`lui_insn = RISCV_INSN_NOP4`), the `addi` branch must still run even if `lower_immediate & 0x00000fff` is 0 to emit `li rd, 0` (`addi_insn_mask &= 0x07fff`) instead of two `nop`s. [F69, F73, F95, F96, F127]
- In `struct riscv_isainfo`, indices 0..25 are single-letter extensions, multi-letter IDs must be in `[RISCV_ISA_EXT_BASE (26), RISCV_ISA_EXT_MAX)`, and pure bundles use `RISCV_ISA_EXT_INVALID`. Vendor extension IDs must be `< RISCV_ISA_VENDOR_EXT_MAX` (32) and offset by `RISCV_VENDOR_EXT_ALTERNATIVES_BASE` (`0x8000`) in alternatives; vendor errata IDs must be `< ERRATA_<VENDOR>_NUMBER` (`< 32` for `u32` bitmasks), and every `ERRATA_SIFIVE_*` up to `ERRATA_SIFIVE_NUMBER` needs a non-NULL `check_func` in `sifive/errata.c:errata_list`. [F54, F60, F61]
- Vendor non-coherent DMA probes (`errata_probe_cmo` in T-Head, `errata_probe_iocp` in Andes) must set a non-zero `riscv_cbom_block_size` alongside `riscv_noncoherent_supported()`. Andes `errata_probe_iocp()` must check both `ANDES_AX45MP_MARCHID`/`MIMPID` and `ax45mp_iocp_sw_workaround()`, while T-Head `errata_probe_mae()` must verify `arch_id == 0 && impid == 0` before reading `CSR_TH_SXSTATUS`. [F53, F105, F106]
- `riscv_insn_is_c_jr()` and `riscv_insn_is_c_jalr()` must check `(code & RVC_INSN_J_RS1_MASK) != 0` alongside `RVC_MATCH_C_JR`/`JALR` (`rs1 == 0` is `C.EBREAK` or reserved). `csr_seed_long()` must poll `CSR_SEED` with `csr_swap(CSR_SEED, 0)`, bound retries to `SEED_RETRY_LOOPS`, abort on `SEED_OPST_DEAD`, and only return `true` after `SEED_OPST_ES16` fills all `needed_seeds` (`sizeof(long) / sizeof(u16)`) 16-bit words. [F75, F79]

## Synchronization

- Callers of `untagged_addr_remote(mm, addr)` must hold `mm->mmap_lock`, enforced by `mmap_assert_locked(mm)`. `riscv_preempt_v_clear_dirty()` and `riscv_preempt_v_set_restore()` must issue `barrier()` before modifying `task->thread.riscv_v_flags`, and `riscv_v_flags()` must read `current->thread.riscv_v_flags` with `READ_ONCE()`. [F11, F14]
- Non-relaxed MMIO accessors (`readb`..`readq`, `writeb`..`writeq`) must order device accesses using `__io_ar` (`RISCV_FENCE(i, ir)`) after reads and `__io_bw` (`RISCV_FENCE(w, o)`) plus `__io_aw` (`mmiowb_set_pending()`) around writes, paired with `mmiowb()` (`RISCV_FENCE(o, w)`). `smp_mb__after_spinlock()` must use `RISCV_FENCE(iorw, iorw)` (including `o`). [F17, F123]
- Fully ordered `arch_xchg()` and `arch_cmpxchg()` must pair `sc.w.rl`/`sc.d.rl` with a trailing `RISCV_FULL_BARRIER` on the LR/SC path (before label `1:` in cmpxchg) or use `.aqrl` on `amoswap`/`amocas`. [F18]
- Text patching in `mips`/`sifive`/`thead_errata_patch_func()` and `__runtime_fixup_32()`/`shift()` must hold `text_mutex` around `patch_text_nosync()` / `patch_insn_write()`, while `RISCV_ALTERNATIVES_EARLY_BOOT` (before MMU) must use `memcpy()` and `local_flush_icache_all()`. In `__set_pte_at()`, when `pte_present(pteval) && pte_exec(pteval)` holds, `flush_icache_pte(mm, pteval)` must precede `set_pte(ptep, pteval)`. [F122, F130]

## Object Lifetimes

- In `riscv64_aes_cbc_cts_crypt` and `riscv64_aes_xts_crypt`, when an initial `skcipher_walk_virt(&walk, req, false)` does not cover the full request and execution switches to a subrequest, `skcipher_walk_abort(&walk)` must be called before starting the subrequest walk. [F1]
- In `arch/riscv/include/asm/pgalloc.h`, `pud_free` and `__pud_free_tlb` must only free/remove the page table descriptor when `pgtable_l4_enabled` is true, and `__p4d_free_tlb` only when `pgtable_l5_enabled` is true. [F3]

## API Contracts

- In `__riscv_v_vstate_save`, `__riscv_v_vstate_restore`, and `__riscv_v_vstate_discard`, vector register/CSR accesses must be bracketed by `riscv_v_enable()` and `riscv_v_disable()` with no early return leaving `SR_VS`/`SR_VS_THEAD` on. [F5]
- In `arch/riscv/crypto/*-riscv64-glue.c`, every vector crypto assembly call must be bracketed by `kernel_vector_begin()` and `kernel_vector_end()` with no early return or sleep in between. Synchronous `crypto_alg` callbacks (`riscv64_aes_encrypt`/`decrypt`, `riscv64_sm4_setkey`/`encrypt`/`decrypt`) and `shash_alg` helpers (`riscv64_ghash_blocks`, `sm3_block`) must check `crypto_simd_usable()` first and fall back to scalar C routines when false. [F8, F113]
- `riscv64_aes_setkey()` must expand keys via generic `aes_expandkey()` (not Zvkned instructions) so `key_dec` is populated for scalar `aes_decrypt()` and AES-192 is supported. `riscv64_zvkned_zvbb_zvkg_aes_skcipher_alg` must set `.base.cra_ctxsize = sizeof(struct riscv64_aes_xts_ctx)` and `.setkey = riscv64_aes_xts_setkey`. [F97, F132]
- `aes_ecb_*_zvkned()`, `aes_cbc_*_zvkned()`, and `ghash_zvkg()` require a non-zero length that is a multiple of 16. In `riscv64_aes_cbc_cts_crypt()` and `riscv64_aes_xts_crypt()`, `req->cryptlen < AES_BLOCK_SIZE` must return `-EINVAL`, and when a multi-segment walk splits a request requiring ciphertext stealing, at least the final full block plus partial tail block must be passed together in one assembly call. [F65, F66]
- Raw PMU event configs in `asm/sbi.h` must be masked by bits [63:62]: `RISCV_PMU_RAW_EVENT_MASK` (48-bit) or `RISCV_PMU_RAW_EVENT_V2_MASK` (56-bit on SBI v3.0) for hardware raw events (`00`), versus 62-bit `RISCV_PMU_PLAT_FW_EVENT_MASK` for platform firmware events (`11`). [F21]
- In `__get_user_nocheck()` and `__put_user_nocheck()`, when `!CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS` and `__gu_ptr` is not aligned to `sizeof(*__gu_ptr)`, the access must fall back to `__asm_copy_from/to_user_sum_enabled()`. [F57]
- `regs_get_register()` bounds-checks `@offset` against `MAX_REG_OFFSET` (`offsetof(struct pt_regs, orig_a0)`), so adding a readable trailing field to `struct pt_regs` requires updating `MAX_REG_OFFSET`. Syscall argument 0 is stored in `regs->orig_a0` while `regs->a0` holds the return value, so `syscall_get_arguments`, `syscall_set_arguments`, `SC_RISCV_REGS_TO_ARGS`, and `syscall_rollback()` must use `regs->orig_a0`. [F70, F145]
- T-Head `THEAD_CMO_OP()` must align `_start` down to `_cachesize`, iterate up to `_start + _size`, and execute `THEAD_SYNC_S` (`th.sync.s`) after the loop. Repeated string I/O helpers (`__io_reads_ins`, `__io_writes_outs`) must use host-endian `__raw_read*`/`__raw_write*` inside the loop and bracket the loop with `bfence`/`afence`. `cpu_do_idle()` must execute `mb()` before `wait_for_interrupt()`, and `ip_fast_csum(iph, ihl)` requires 4-byte aligned `iph` and `ihl >= 5`. [F108, F110, F111, F136]

## Error Handling

- Callers of `sbi_ecall()` / `__sbi_ecall()` must inspect `struct sbiret.error` against `SBI_SUCCESS` (0) or `SBI_ERR_*` and translate non-zero errors via `sbi_err_map_linux_errno()` rather than returning raw `ret.error`. [F20]
- `__get_user_error()`, `__get_user()`, and `get_user()` must zero destination `x` (including `__hi` in 32-bit `__get_user_8`) on `access_ok()` or load failure and return `-EFAULT`. `__asm_copy_to/from_user_sum_enabled()`, `raw_copy_to/from_user()`, and `clear_user()` return an `unsigned long` residual byte count (non-zero on fault), which uaccess callers must treat as a fault. [F23, F24]
- Inline assembly using `_ASM_EXTABLE_UACCESS_ERR` or `_ASM_EXTABLE_UACCESS_ERR_ZERO` without `asm_goto_output` (`__get_user_asm`, `__get_user_8`, `arch_futex_atomic_op_inuser`, `futex_atomic_cmpxchg_inatomic`) must initialize the error variable to `0` before `asm` and pass it with `"+r"`. In `ALT_SVPBMT(_val, prot)`, `_val` uses `"=r"`, so the default unpatched sequence must explicitly load `0` (`"li %0, 0\t\nnop"`). [F26, F32]

## External Contracts

- Adding a `RISCV_HWPROBE_KEY_*` in `uapi/asm/hwprobe.h` requires updating `RISCV_HWPROBE_MAX_KEY` in `asm/hwprobe.h` and adding bitmask keys to `hwprobe_key_is_bitmask()`. `uc_mcontext` must remain the final member of `struct ucontext`, `sc_extdesc` (`struct __riscv_extra_ext_header`) must keep its 129-`u32` `__padding` array and zeroed `reserved` word before `hdr`, and `struct user_regs_struct` must remain an exact layout prefix of `struct pt_regs` (`pc`/`epc`..`t6`). [F62, F64, F142]

## Known Pitfalls

- Vector crypto assembly `aes_encrypt_zvkned()`, `aes_decrypt_zvkned()`, and `sm4_crypt_zvksed_zvkb()` take `(key, src, dst)` (input before output), whereas scalar C fallbacks `aes_encrypt()`, `aes_decrypt()`, and `sm4_crypt_block()` take `(key, dst, src)` (output before input). [F29]
- In `riscv64_aes_xts_crypt()`, when `tail > 0 && walk.nbytes < walk.total`, `req` is reassigned to `&subreq` (`req->cryptlen - tail - AES_BLOCK_SIZE`), which post-loop `scatterwalk_ffwd()` calls rely on. In `riscv64_aes_ctr_crypt()`, the final chunk (`nbytes == walk.total`) must use `DIV_ROUND_UP(nbytes, AES_BLOCK_SIZE)` for `nblocks` so partial tail blocks advance `ctr32`. [F78, F87]
- In `__put_user(x, ptr)`, `x` must be evaluated into `__val` before `__enable_user_access()` sets `SR_SUM`, and `__disable_user_access()` must clear `SR_SUM` right after `__put_user_error()`. In `__put_user_nocheck()`, the unaligned-fallback temporary must be named `___val` (three underscores) so it does not shadow `val` or `__val` in outer macros. Switch-case helpers `__get_user_asm`/`8` and `__put_user_asm`/`8` must be wrapped in `do { ... } while (0)`, and 32-bit `__get_user_8()`/`__put_user_8()` must cast between `u64` and `__typeof__(x)` via `(__typeof__((x) - (x)))`. [F71, F92, F121, F146]
- On RV64, `lr.w` sign-extends 32-bit loads to 64 bits, so 32-bit cmpxchg operands in `futex_atomic_cmpxchg_inatomic()` (`oldval`) and the 4-byte case of `_arch_cmpxchg()` (`__old`) must be sign-extended via `(long)(int)` / `(long)(int)(long)` before `bne`. [F80, F81]
- Splitting a 32-bit value across U-type (`lui`/`auipc`) and I-type (`addi`/`jalr`) instructions in `riscv_insn_insert_utype_itype_imm()` and `__runtime_fixup_32()` must add `0x1000` to the upper 20-bit immediate when bit 11 of the lower 12-bit immediate is set. In fixed-width 32-bit inline assembly (`RISCV_RUNTIME_CONST_64_ZBA`, `RISCV_RUNTIME_CONST_64_ZBKB`), `.option norvc` must follow `.option arch` because `.option arch` resets `.option norvc` when `zca` is present. [F84, F116]
- In `ARCH_SWAB()`, Zbb `rev8` reverses bytes across `BITS_PER_LONG`, so the result must be right-shifted by `(BITS_PER_LONG - size)`. In `THEAD_CMO_OP()` and `ALT_CMO_OP()`, aligning `_start` must use `~((_cachesize) - 1UL)` so 32-bit `riscv_cbom_block_size` does not truncate 64-bit addresses. In `asm/csr.h`, `ENVCFG_*` and `SMSTATEEN0_*` masks at bits 32..63 must use 64-bit literals (`_AC(..., ULL)` or `_ULL(1)`). Under `CONFIG_RISCV_ISA_SVNAPOT`, `pte_pfn(pte)` must strip the lowest set PFN bit (`res & (res - 1UL)`) when `has_svnapot() && pte_napot(pte)` holds. [F85, F88, F91, F140]
- `syscall_get_arguments()` and `syscall_set_arguments()` must copy `regs->a1`..`regs->a5` via per-field assignments rather than `memcpy()`, which trips `CONFIG_FORTIFY_SOURCE` on `sizeof(regs->a1)`. In vDSO `ecall` wrappers (`getrandom_syscall`, `gettimeofday_fallback`, `clock_gettime_fallback`, `clock_getres_fallback`) where `ret` and arg0 share `asm("a0")`, `ret` must use `"=r"` (not `"+r"`) alongside `"r"` for arg0. `arch_kgdb_breakpoint()` must remain an out-of-line `noinline` function because its inline assembly defines global label `kgdb_compiled_break`. [F94, F115, F119]
