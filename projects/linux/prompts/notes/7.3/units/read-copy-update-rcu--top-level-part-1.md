# READ-COPY UPDATE (RCU) — (top level) (part 1)

This component implements the core Linux Read-Copy Update (RCU) subsystem—Tree, Tiny, Tasks/Rude/Trace RCU, segmented callback lists, and synchronization helpers—plus public APIs for read-side critical sections, pointer publication/dereferencing, grace-period waiting/polling, and RCU lists/refs.

## Architecture & Data Flow

- In `struct rcu_segcblist`, `tails[seg]` (`struct rcu_head **`) points to the `->next` pointer ending segment `seg` (or `&rsclp->head` when empty): `RCU_DONE_TAIL` (0) spans `[rsclp->head, *rsclp->tails[0])` and `seg > 0` spans `[*rsclp->tails[seg - 1], *rsclp->tails[seg])`. Segment emptiness tests pointer equality (`rcu_segcblist_segempty`), while trailing-list emptiness dereferences `*rsclp->tails[seg]` (`rcu_segcblist_restempty`). [F232, F276]
- `rcu_segcblist_extract_done_cbs()` must iterate `i` backwards from `RCU_CBLIST_NSEGS - 1` to `RCU_DONE_TAIL` when resetting `rsclp->tails[i] = &rsclp->head` so `tails[RCU_DONE_TAIL]` is updated last, whereas `rcu_segcblist_insert_done_cbs()` iterates forwards and breaks at the first non-empty segment. When `rcu_segcblist_advance()` moves `RCU_WAIT_TAIL` to `RCU_DONE_TAIL`, it must shift `RCU_NEXT_READY_TAIL` into `RCU_WAIT_TAIL` so `RCU_WAIT_TAIL` is never empty while `RCU_NEXT_READY_TAIL` is non-empty. [F208, F248]
- When `rcu_cblist_flush_enqueue()` flushes `srclp` into `drclp` and `rhp` is non-NULL, it must replace `srclp`'s head, tail, and `len` with `rhp` in place without calling `rcu_cblist_init(srclp)`, so `srclp` never transiently appears empty. [F210]
- Runtime traversal of `rcu_state.node[]` and `rcu_state.level[]` must bound by `rcu_num_nodes` and `rcu_num_lvls` (via `rcu_for_each_node_breadth_first()`, `rcu_for_each_leaf_node()`, `rcu_first_leaf_node()`) rather than `NUM_RCU_NODES` or `RCU_NUM_LVLS`, as `rcu_init_geometry()` can shrink them. `rcu_init_geometry()` must validate `2 <= rcu_fanout_leaf <= BITS_PER_LONG` and `rcu_capacity[RCU_NUM_LVLS - 1] >= nr_cpu_ids` (else fall back to `RCU_FANOUT_LEAF`), and use ceiling division for `NUM_RCU_LVL_*`, `num_rcu_lvl[i]`, and `levelspread[i]`. [F235, F236, F269]
- In `rcu_report_qs_rnp()`, the early-exit check `(!(rnp->qsmask & mask) && mask)` must keep `&& mask` because `rcu_gp_init()` passes `mask == 0` when `rnp->wait_blkd_tasks` is set on an all-offline leaf node. Unlike `rnp->qsmaskinitnext`, `rnp->expmaskinitnext` bits are never cleared on CPU offline, and `rcutree_report_cpu_starting()` increments `rcu_state.ncpus` only when `!(rnp->expmaskinitnext & mask)`. [F218, F259]
- Per-CPU `rdp->rcu_forced_tick` and `rdp->rcu_forced_tick_exp` are coupled under `rdp->mynode->lock` with `TICK_DEP_BIT_RCU` and `TICK_DEP_BIT_RCU_EXP`; clearing them in `rcu_disable_urgency_upon_qs()` or `rcu_report_exp_cpu_mult()` must also call `tick_dep_clear_cpu()`. [F212]
- `get_state_synchronize_rcu_full()` snapshots `rgosp->rgos_norm` from `rcu_state.gp_seq`, whereas `poll_state_synchronize_rcu_full()` tests it against root `rnp->gp_seq` via `rcu_seq_done_exact()` (subtracting `2 * RCU_SEQ_GP`). In `rcu_poll_gp_seq_end()`, if `*snap && *snap == rcu_state.gp_seq_polled`, zero both `gp_seq_polled_snap` and `gp_seq_polled_exp_snap` under the root `rcu_node` lock; if `*snap != rcu_state.gp_seq_polled`, zero `*snap` without calling `rcu_seq_end()`. [F204, F213]
- At GP completion, `rcu_future_gp_cleanup()` must advance `rnp->gp_seq_needed` to `rnp->gp_seq` when `!ULONG_CMP_LT(rnp->gp_seq, rnp->gp_seq_needed)`, and `rcu_exp_wait_wake()` must advance `rnp->exp_seq_rq` to `s` when `ULONG_CMP_LT(rnp->exp_seq_rq, s)`. Index `rnp->exp_wq[4]` by `rcu_seq_ctr(s) & 0x3`, never `s & 0x3`. [F237, F272]
- `rcu_state.srs_next` mixes `struct rcu_synchronize` requests with dummy wait-heads from `rcu_state.srs_wait_nodes[]`; any traversal must test `rcu_sr_is_wait_head(node)` before calling `rcu_sr_normal_complete()` or `rcu_sr_put_wait_head()`. Per-CPU `barrier_head.next` and `barrier_q_head.next` must initialize to self and reset to self in `rcu_barrier_callback()` / `rcu_barrier_tasks_generic_cb()` because `rcu_barrier_cb_is_done()` tests `rhp->next == rhp`. [F200, F239]
- In `struct rcu_tasks`, `rtp->rtpcp_array` is dense (`0 .. num_possible_cpus() - 1`) indexed by `rtpcp->index`, whereas `rtp->rtpcpu` is per-CPU indexed by sparse `rtpcp->cpu < rcu_task_cpu_ids` bounded by `rtp->percpu_dequeue_lim`. `cblist_init_generic()` clamps `lim` to `[1, rcu_task_cpu_ids]` and increments `shift = ilog2(rcu_task_cpu_ids / lim)` if `((rcu_task_cpu_ids - 1) >> shift) >= lim`. When shrinking queues in `rcu_tasks_need_gpcb()`, set `percpu_enqueue_lim = 1` and snapshot `percpu_dequeue_gpseq` first; lower `percpu_dequeue_lim` to 1 only after that GP completes and CPUs > 0 have zero callbacks. [F223, F238, F268]
- In `kernel/rcu/sync.c`, `rcu_sync_func()` must check `if (rsp->gp_count)` before `else if (rsp->gp_state == GP_REPLAY)`, and `rcu_sync_exit()` when `--rsp->gp_count == 0` in `GP_EXIT` must set `rsp->gp_state = GP_REPLAY` rather than calling `rcu_sync_call(rsp)` while `rsp->cb_head` is queued. [F249]
- `rcuref_t` biases counts by -1 (`rcuref_init()` sets `cnt - 1`; `rcuref_read()` returns `c >= RCUREF_RELEASED ? 0 : c + 1`) so `0x80000000U..0xFFFFFFFFU` represent zero, saturation, and dead zones for `atomic_add_negative_relaxed()` and `cnt < 0` in `__rcuref_put()`. In `rculist_nulls.h`, list-end checks must test `!is_a_nulls()` rather than non-NULL. [F246, F273]

## Synchronization

- Acquire/release `struct rcu_node` (and `struct rcu_tasks_percpu`) `->lock` only via `raw_spin_lock/unlock*_rcu_node()` with IRQs disabled. `rcu_report_qs_rnp()`, `rcu_report_unblock_qs_rnp()`, `__rcu_report_exp_rnp()`, and `rcu_report_exp_cpu_mult()` consume `rnp->lock` and restore IRQ flags on all paths. `rcu_start_this_gp()` requires and preserves `rnp_start->lock` held (unlocking ancestor locks), and callers of `rcu_start_this_gp()`, `rcu_gp_kthread_wake()`, and `rcu_report_qs_rsp()` must release all `rcu_node` locks before calling `rcu_gp_kthread_wake()`. [F145, F146, F296, F300]
- For CPU hotplug vs. GP init (`rcu_gp_init()`, `rcutree_report_cpu_starting()`, `rcutree_report_cpu_dead()`), acquire `rcu_state.ofl_lock` with IRQs disabled before `rcu_state.barrier_lock` or leaf `rnp->lock`. Under both locks, `rcutree_report_cpu_starting()` must set `rnp->qsmaskinitnext` before `rcu_report_qs_rnp()`, whereas `rcutree_report_cpu_dead()` must call `rcu_report_qs_rnp()` before clearing `rnp->qsmaskinitnext`. [F217, F298]
- `rcu_nocb_lock_irqsave()` must call `local_irq_save()` before testing `rcu_segcblist_is_offloaded(&rdp->cblist)` and locking `rdp->nocb_lock`. In `rcu_gp_cleanup()`, never call `rcu_accelerate_cbs(rnp, rdp)` when `rcu_rdp_is_offloaded(rdp)` is true. In `rcu_barrier_entrain()` and `rcutree_migrate_callbacks()`, lock order is `barrier_lock` -> `rdp->nocb_lock` -> leaf `rnp->lock`, and `wake_nocb_gp()` / `__call_rcu_nocb_wake()` must not be called while holding `rnp->lock` or `rdp->nocb_lock`. [F168, F173, F299]
- In `rcu_gp_init()`, `rcu_sr_normal_gp_init()` then `rcu_seq_start(&rcu_state.gp_seq)` must run under the root `rcu_node` lock before scanning leaf `rcu_node`s for `qsmaskinitnext`. In `rcu_sr_normal_gp_cleanup()`, increment `srs_cleanups_pending` before `queue_work(sync_wq, &rcu_state.srs_cleanup_work)` and decrement if `queue_work()` returns `false`; access `srs_done_tail` with release-acquire ordering and keep the `done` dummy node in place (`done->next = NULL`) in `rcu_sr_normal_gp_cleanup_work()`. [F152, F171, F175]
- In `rcu_exp_wait_wake()`, hold `rcu_state.exp_wake_mutex` across `rcu_exp_gp_seq_end()`, all `rnp->exp_seq_rq` updates, and `wake_up_all(&rnp->exp_wq[...])`. In `sync_rcu_exp_select_cpus()`, reset `rnp->exp_need_flush = false` on each leaf node and set it `true` only when `sync_rcu_exp_select_cpus_queue_work(rnp)` queues `rnp->rew.rew_work` onto `rnp->exp_kworker` (never `rcu_exp_gp_kworker`). [F176, F262]
- `rcu_barrier()` and `rcu_barrier_tasks_generic()` must initialize `barrier_cpu_count` / `barrier_q_count` to 2 before the per-CPU entrain loop and finish with `atomic_sub_and_test(2, ...)`. `rcu_barrier_callback()` must sample `rcu_state.barrier_sequence` before `atomic_dec_and_test(&rcu_state.barrier_cpu_count)`. `rcu_segcblist_add_len()` / `rcu_segcblist_inc_len()` updates must be bracketed by full memory barriers unless the CPU hotplug lock is held (`rcu_segcblist_merge()`). [F222, F260, F310]
- In `call_rcu_tasks_generic()`, never acquire `rtp->cbs_gbl_lock` while holding `rtpcp->lock`, and keep queue selection and enqueue inside `rcu_read_lock()` / `rcu_read_unlock()`. In `__list_splice_init_rcu()`, reinitialize `list` with `INIT_LIST_HEAD_RCU(list)` and call `sync()` before mutating `last->next` and publishing `first` via `rcu_assign_pointer(list_next_rcu(prev), first)`. [F178, F187]

## Object Lifetimes

- After `rcu_segcblist_extract_done_cbs()` in `rcu_do_batch()` and `rcu_tasks_invoke_cbs()`, callers must reinsert uninvoked callbacks via `rcu_segcblist_insert_done_cbs()` and subtract invoked count via `rcu_segcblist_add_len()`. `rcutree_migrate_callbacks()` must merge all callbacks via `rcu_segcblist_merge()` before calling `rcu_segcblist_disable()`. [F147, F154]
- Because `synchronize_rcu_normal()` and `synchronize_rcu_expedited()` allocate `struct rcu_synchronize rs` and `struct rcu_exp_work rew` on the stack, `rcu_sr_normal_complete()` (and callers) must read `rcu->next` and `rs->oldstate` before `complete(&rs->completion)`, and `wait_rcu_exp_gp()` must read `rewp->rew_s` before `rcu_exp_sel_wait_wake()`. [F282, F283]
- In Classic RCU Tasks, `rcu_tasks_pertask()` calls `get_task_struct(t)` and links `t->rcu_tasks_holdout_list`, so `rcu_tasks_postscan()` must check `list_empty(&t->rcu_tasks_holdout_list)` first, and `check_holdout_task()` must call `put_task_struct(t)` after `list_del_init()`. [F158]
- `rcu_spawn_gp_kthread()` must set `gp_activity` and `gp_req_activity` to `jiffies` before `smp_store_release(&rcu_state.gp_kthread, ...)`. `rcu_tasks_kthread()` must run `timer_setup(&rtpcp->lazy_timer, ...)` for all possible CPUs before `smp_store_release(&rtp->kthread_ptr, ...)`. `tasks_cblist_init_generic()` (`cblist_init_generic()`) must run during `rcu_init()` with IRQs disabled before any `call_rcu_tasks_generic()`. [F287, F288, F289]
- `rcu_sync_dtor()` must set `GP_REPLAY` to `GP_EXIT` under `rsp->rss_lock` and, if `rsp->gp_state != GP_IDLE`, call `rcu_barrier()` after unlocking. Every `prepare_to_rcuwait(w)` must pair with `finish_rcuwait(w)` on all exit paths, with external serialization for `w->task`. [F164, F182]
- Balance `rcu_async_hurry()` / `rcu_expedite_gp()` with `rcu_unexpedite_gp()` / `rcu_async_relax()` in `rcu_pm_notify()`, and balance `tick_dep_set(TICK_DEP_BIT_RCU)` in `rcutree_offline_cpu()` with `tick_dep_clear()` in `rcutree_dead_cpu()` and post-boot `rcutree_online_cpu()`. After `list_del_rcu()`, `list_bidir_del_rcu()`, `list_replace_rcu()`, or `hlist*_del/replace_rcu()`, wait for a GP before freeing the entry. [F291, F292, F306]

## API Contracts

- Never sleep, block, or call `synchronize_rcu*()` or `rcu_softirq_qs()` inside `rcu_read_lock*()` critical sections; RCU callbacks in `rcu_do_batch()`, `rcu_reclaim_tiny()`, and `rcu_tasks_invoke_cbs()` run with BH disabled under `rcu_callback_map` and must not sleep. Use `rcu_dereference_protected()` only while holding the update-side lock, never under `rcu_read_lock()` alone. [F184, F294, F315]
- `rcuref_get()` requires stable object memory (e.g., `rcu_read_lock()`) and checking its boolean return. `rcuref_put_rcusafe()` requires `rcu_read_lock()` or atomic context (else use `rcuref_put()`). Never free based on `rcuref_read(ref) == 0`; check `rcuref_put*()`'s return or `rcuref_is_dead()`. [F183, F192, F307]
- `exp_funnel_lock()` returns `true` with `exp_mutex` unlocked when GP `s` is already done, or `false` with `exp_mutex` held and `rcu_exp_gp_seq_start()` called. `force_qs_rnp()` callbacks (`rcu_watching_snap_save/recheck()`) return signed `int`: `> 0` on QS, `< 0` for `resched_cpu()`, `0` otherwise. [F189, F190]
- Initialize `struct rcu_cblist` via `rcu_cblist_init()` before `rcu_segcblist_extract_done/pend_cbs()`. Initialize `struct rcu_head` with `rcu_head_init()` before `rcu_head_after_call_rcu(rhp, f)` and do not test concurrently with or after callback execution. Align `rcu_head` to `sizeof(void *)` for `call_rcu*()`, and keep `LIST_BL_LOCKMASK` (bit 0) clear in `hlist_bl_set_first_rcu()`. [F198, F199, F241]
- Lists using `list_bidir_prev_rcu()` must remove entries with `list_bidir_del_rcu()`, never `list_del/replace_rcu()`. Cursors passed to `list_for_each_entry_continue/from_rcu()` must have remained in the list since entering the current `rcu_read_lock()` section (or be pinned in the list). [F203, F245]
- `rcu_sync_is_idle()` requires `rcu_read_lock_any_held()`; `rcu_sync_dtor()` requires sleepable context and `gp_count == 0`. `rcu_momentary_eqs()` and `rcu_virt_note_context_switch()` require IRQs disabled (and `CT_RCU_WATCHING` set for `rcu_momentary_eqs()`). `rcu_is_watching()`, `rcu_read_lock/unlock_sched_notrace()`, and `rcu_lockdep_current_cpu_online()` must use `preempt_disable/enable_notrace()`, and `rcu_irq_work_resched()` must stay `noinstr`. `struct rcu_tasks` using `rcu_tasks_wait_gp()` must set non-NULL `pregp_func`, `postscan_func`, `holdouts_func`, and `postgp_func`. [F309, F311, F316, F319]

## Error Handling

- In `rcu_barrier_entrain()`, if `rcu_segcblist_entrain()` returns `false` after `debug_rcu_head_queue(&rdp->barrier_head)`, call `debug_rcu_head_unqueue(&rdp->barrier_head)` without incrementing `barrier_cpu_count`. When `debug_rcu_head_queue(head)` fails in `__call_rcu_common()` or Tiny `call_rcu()`, cap logging with `atomic_inc_return(&doublefrees) < 4` and do not re-enqueue (set `head->func = rcu_leak_callback` in Tree RCU). [F148, F325]
- `rcu_spawn_exp_par_gp_kworker()` and `rcu_start_exp_gp_kworker()` must check `kthread_create/run_worker()` with `IS_ERR_OR_NULL()` and leave `rnp->exp_kworker` / `rcu_exp_gp_kworker` as `NULL` on error. `param_set_do_rcu_barrier()` must return `-EAGAIN` if `rcu_scheduler_active != RCU_SCHEDULER_RUNNING` and call `rcu_barrier_throttled()`. `synchronize_rcu_expedited_stall()` must suppress full dumps when `READ_ONCE(csd_lock_suppress_rcu_stall) && csd_lock_is_stuck()`. [F188, F322, F324]

## External Contracts

- `rcutree_report_cpu_starting()` and `rcutree_report_cpu_dead()` must run on the transitioning CPU with IRQs disabled, with no RCU read-side critical sections before `starting` or after `dead`. Keep `call_rcu_tasks_trace()` and `rcu_read_lock/unlock_trace()` defined as `BUG()` stubs when `!CONFIG_TASKS_TRACE_RCU` for the BPF JIT. [F312, F320]

## Known Pitfalls

- Use `rcu_segcblist_n_cbs()` rather than `rcu_segcblist_empty()` when in-flight extracted callbacks in `rcu_do_batch()` must be counted (`rcu_barrier()`, `rcu_segcblist_entrain()`). Use `list_first_or_null_rcu()` instead of `!list_empty()` followed by `list_first_entry()` / `list_entry_rcu()` in lockless readers. [F197, F244]
- `rcu_find_next_bit(rnp, cpu, mask)` takes a 0-based offset relative to `rnp->grplo` and returns a global CPU ID; `for_each_leaf_node_cpu_mask(rnp, cpu, mask)` and `leaf_node_cpu_bit(rnp, cpu)` index `mask` by `cpu - rnp->grplo` while `cpu` is in `[rnp->grplo, rnp->grphi]`. [F234, F251, F264]
- `rcu_tasks_postscan()` inserts a bare on-stack `struct list_head tmp` into `rtpcp->rtp_exit_list` before dropping `rtpcp->lock` for `cond_resched()` and refreshes `t1` from `tmp.next`; no other code may traverse `rtp_exit_list` and cast nodes to `struct task_struct`. In `rcu_print_task_exp_stall()` and `rcu_exp_print_detail_task_stall_rnp()`, initialize `t = list_entry(rnp->exp_tasks->prev, struct task_struct, rcu_node_entry)` without dereferencing `t` before `list_for_each_entry_continue()`. [F224, F261, F284]
- Mask `gp_seq` and `expedited_sequence` with `0xffffULL` / `0xffffffULL` before 40/16-bit left shifts in `rcutorture_gather_gp_seqs()`; read `rcu_divisor` once and clamp to `[0, sizeof(long) * 8 - 2]` before `pending >> div` in `rcu_do_batch()`; check `delay > 0` before modulo in `rcu_gp_slow()`. [F263, F265, F267]
