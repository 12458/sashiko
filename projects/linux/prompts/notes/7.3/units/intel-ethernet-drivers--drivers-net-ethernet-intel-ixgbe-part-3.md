# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 3)

This unit implements the PCI driver lifecycle, `net_device_ops`, NAPI Tx/Rx/XDP data paths, IRQ handling, service watchdog, PCIe AER recovery, PF/VF mailbox ops, and `tc` Flow Director tables (`ixgbe_model.h`) for the Intel 10GbE (`ixgbe`) driver.

## Architecture & Data Flow
- In `struct ixgbe_tx_buffer`, `skb` and `xdpf` share a union; non-XSK Tx cleanup must check `ring_is_xdp(tx_ring)` to free `xdpf` via `xdp_return_frame()` or `skb` via `dev_kfree_skb_any()` / `napi_consume_skb()`. `ixgbe_xmit_frame_ring()` must reserve `count + 3` descriptors via `ixgbe_maybe_stop_tx(tx_ring, count + 3)` summing `TXD_USE_COUNT()` over `skb_headlen(skb)` and all `nr_frags`, as `ixgbe_tx_map()` splits >16KB segments without rechecking. [F1520, F1561]
- `ixgbe_alloc_rx_buffers()` and `ixgbe_clean_tx_irq()` bias `i -= ring->count` before the loop (wrapping at `!i`) and must add `ring->count` back before storing `next_to_use` / `next_to_clean`. When `ixgbe_alloc_rx_buffers()` advances `next_to_use` to `i`, it must set `next_to_alloc = i`, zero `rx_desc->wb.upper.length` on the new `next_to_use` descriptor, run `wmb()`, and write `i` to `rx_ring->tail`. [F1535, F1559]
- In `ixgbe_can_reuse_rx_page()`, when `pagecnt_bias == 1`, `page_ref_add(page, USHRT_MAX - 1)` and `pagecnt_bias = USHRT_MAX` must update in lockstep. On `PAGE_SIZE < 8192`, `ixgbe_add_rx_frag()`, `ixgbe_construct_skb()`, `ixgbe_build_skb()`, and `ixgbe_rx_buffer_flip()` toggle `page_offset ^= truesize` (`truesize = ixgbe_rx_pg_size(rx_ring) / 2`); on `PAGE_SIZE >= 8192` they add `truesize` bounded by `IXGBE_LAST_OFFSET`. [F1537, F1572]
- `ixgbe_setup_tx/rx_resources()` 4K-align `ring->size` for DMA alloc/free, whereas `ixgbe_configure_tx/rx_ring()` program `IXGBE_TDLEN` / `IXGBE_RDLEN` with `ring->count * sizeof(desc)`. `ixgbe_clean_rx/tx_ring()` must reset `next_to_alloc`, `next_to_clean`, and `next_to_use` to 0 (and call `netdev_tx_reset_queue()` on non-XDP Tx rings). [F1541, F1602]
- `ixgbe_configure_rx()` must call `ixgbe_set_rx_buffer_len()` before `ixgbe_configure_rx_ring()`, which on `PAGE_SIZE < 8192` (non-82598/82599) sets `IXGBE_MAX_2K_FRAME_BUILD_SKB | IXGBE_RXDCTL_RLPML_EN` when `ring_uses_build_skb(ring)` and `!test_bit(__IXGBE_RX_3K_BUFFER, &ring->state)`. With RSC enabled, `ixgbe_configure_rscctl()` must set `IXGBE_RSCCTL_MAXDESC_16`; `ixgbe_update_rsc_stats()` must verify `IXGBE_CB(skb)->append_cnt != 0` before `ixgbe_set_rsc_gso_size()` and clear `append_cnt` only after `DIV_ROUND_UP()`. [F1565, F1566, F1593]
- On non-82598EB MACs, `ixgbe_configure_tx()` must set `IXGBE_DMATXCTL_TE` before `ixgbe_configure_tx_ring()`, and `ixgbe_disable_tx()` must clear it only after polling all active `IXGBE_TXDCTL_ENABLE` bits to clear. On `ixgbe_mac_82598EB`, `TXDCTL.ENABLE` / `RXDCTL.ENABLE` do not update when link is down (`!(IXGBE_READ_REG(hw, IXGBE_LINKS) & IXGBE_LINKS_UP)`), so `ixgbe_configure_tx_ring()`, `ixgbe_rx_desc_queue_enable()`, `ixgbe_disable_rx()`, and `ixgbe_disable_rxr_hw()` must skip polling when link is down. [F1579, F1606]
- In `ixgbe_configure()`, `ixgbe_configure_virtualization()` must precede `ixgbe_restore_vlan()` and `ixgbe_set_rx_mode()`; on 82599EB and X540, Flow Director init (`ixgbe_init_fdir_*_82599()` and `ixgbe_fdir_filter_restore()`) must be bracketed by `disable_rx_buff(hw)` and `enable_rx_buff(hw)`. [F1533, F1609]
- In `ixgbe_up_complete()`, before `ixgbe_irq_enable()`, clear `__IXGBE_DOWN`, call `ixgbe_napi_enable_all()`, and read `IXGBE_EICR`. In `ixgbe_down()`, before `ixgbe_clean_all_tx/rx_rings()`, stop netif Tx, call `ixgbe_disable_rx()` (plus `synchronize_rcu()` if `adapter->xdp_ring[0]` is set), `ixgbe_irq_disable()`, `ixgbe_napi_disable_all()`, delete `service_timer`, and call `ixgbe_disable_tx()` and `ixgbe_reset()`. [F1610, F1611]
- In `ixgbe_reset()`, after `hw->mac.ops.init_hw(hw)` clears RARs, call `ixgbe_flush_sw_mac_table()`, `__dev_uc_unsync(netdev, NULL)`, and `ixgbe_mac_set_default_filter()` (from `hw->mac.addr`). In `ixgbe_change_mtu()`, `WRITE_ONCE(netdev->mtu, new_mtu)` must precede `ixgbe_reinit_locked()`. [F1542, F1544]
- In `ixgbe_request_msix_irqs()`, `ixgbe_free_irq()`, `ixgbe_irq_disable()`, and `ixgbe_configure_msix()`, `vector`/`v_idx` after `0 .. adapter->num_q_vectors - 1` must equal `adapter->num_q_vectors` to index the `ixgbe_msix_other` entry. In `ixgbe_configure_msix()`, evaluate `BIT(adapter->num_vfs - 32) - 1` for `IXGBE_EITRSEL` only when `adapter->num_vfs > 32`. [F1576, F1594]
- `IXGBE_VLVF` slot 0 is reserved: `ixgbe_vlan_promisc_enable()`, `ixgbe_scrub_vfta()`, and `ixgbe_find_vlvf_entry()` must loop `for (i = IXGBE_VLVF_ENTRIES; --i;)` and map `(i, p)` to `IXGBE_VLVFB(i * 2 + p / 32)` bit `BIT(p % 32)`. In `ixgbe_mbx.c`, `IXGBE_MBVFICR` packs 16 VFs per register (`vf >> 4`, `vf % 16`, reqs in 0..15, ACKs in 16..31), while `IXGBE_VFLRE` / `IXGBE_VFLREC` pack 32 VFs (`vf >= 32`, `vf % 32`). [F1557, F1570]
- In `ixgbe_model.h`, `ixgbe_mat_field` tables end with `{.val = NULL}` and `ixgbe_nexthdr` tables with `{.jump = NULL}`. In `cls_u32` handlers (`ixgbe_configure_clsu32*`, `ixgbe_delete_clsu32`), non-root `uhtid` (`!= 0x800`) must be `< IXGBE_MAX_LINK_HANDLE`, indexing `jump_tables[uhtid]` and `tables` bit `uhtid - 1`. `filter->action` encodes 0-based `vf` as `(vf + 1) << ETHTOOL_RX_FLOW_SPEC_RING_VF_OFF` (`0` = PF), so `ixgbe_fdir_filter_restore()` must check `vf <= adapter->num_vfs` and use `vf - 1`. [F1522, F1567, F1569]
- `adapter->xdp_prog` is incompatible with SR-IOV/VMDq, DCB, LRO/RSC, macvlan offload (`ixgbe_fwd_add()`), and frames > `ixgbe_max_xdp_frame_size()`. In `ixgbe_cleanup_headers()`, skip `eth_skb_pad(skb)` when `ixgbe_rx_is_fcoe(rx_ring, rx_desc)` is true. [F1650, F1653]
- `ixgbe_pci_tbl` ends with `{0, }` and indexes `ixgbe_info_tbl[]`. In `ixgbe_probe()`, reject `pdev->is_virtfn` before `pci_enable_device_mem()`; copy `ixgbe_info` ops tables by value into `adapter->hw`; set `hw->eeprom.ops.read = &ixgbe_read_eeprom_bit_bang_generic` if `!(IXGBE_EEC(hw) & BIT(8))` before `ixgbe_sw_init()`; and copy PCI IDs into `hw` before `ii->get_invariants(hw)`. If `ixgbe_pcie_from_parent(&adapter->hw)` is true, read PCIe link info from `pdev->bus->parent->self`, and return early in `ixgbe_check_minimum_link()` if `hw->bus.type == ixgbe_bus_type_internal`. [F1549, F1616, F1617, F1619]
- Gate `pci_disable_device(pdev)` with `!test_and_set_bit(__IXGBE_DISABLED, &adapter->state)`, and on `pci_enable_device_mem(pdev)` in `ixgbe_resume()` / `ixgbe_io_slot_reset()` clear `__IXGBE_DISABLED` and restore `adapter->hw.hw_addr = adapter->io_addr`. Under `rtnl_lock()`, `__ixgbe_shutdown()` must detach `netdev`, call `ixgbe_close_suspend()` if running, and call `ixgbe_clear_interrupt_scheme()`, while `ixgbe_resume()` must call `ixgbe_init_interrupt_scheme()` before `ixgbe_open()`. Pair `ixgbe_get_hw_control()` (`IXGBE_CTRL_EXT_DRV_LOAD`) with `ixgbe_release_hw_control()` on close, shutdown, remove, and probe error. [F1627, F1628, F1629]

## Synchronization
- In `ixgbe_tx_map()` and `ixgbe_xmit_xdp_ring()`, execute `wmb()` / `smp_wmb()` after writing descriptors before setting `next_to_watch = tx_desc`, paired with `smp_rmb()` in `ixgbe_clean_tx_irq()` after reading non-NULL `next_to_watch` before reading `eop_desc->wb.status`. In `ixgbe_fwd_ring_up()`, setting `rx_ring[baseq + i]->netdev = vdev` must precede `ixgbe_add_mac_filter()` with `wmb()`. [F1496, F1507]
- XDP ring transmits and tail updates (`ixgbe_xmit_xdp_ring()`, `ixgbe_xdp_ring_update_tail*()`, `ixgbe_xdp_xmit()`) must hold `ring->tx_lock` when `static_branch_unlikely(&ixgbe_xdp_locking_key)` is enabled. When detaching XDP in `ixgbe_xdp_setup()` (`old_prog && !prog`), call `synchronize_rcu()` before `ixgbe_setup_tc()` and `xdp_features_clear_redirect_target(dev)` after. [F1500, F1654]
- Bracket `ring->stats.packets/bytes` updates in `ixgbe_update_tx/rx_ring_stats()` with `u64_stats_update_begin/end(&ring->syncp)`, and read them in `ixgbe_get_stats64()` / `ixgbe_get_ring_stats64()` with `u64_stats_fetch_begin/retry()` under `rcu_read_lock()` and `READ_ONCE(adapter->*_ring[i])`. [F1510]
- Initialize `service_timer` and `service_task` before setting `__IXGBE_SERVICE_INITED` in `ixgbe_probe()` / `ixgbe_recovery_probe()`. Every exit of `ixgbe_service_task()` and `ixgbe_recovery_service_task()` must call `ixgbe_service_event_complete(adapter)`. Never call `cancel_work_sync(&adapter->service_task)` inside `ixgbe_down()` or `ixgbe_reinit_locked()`. [F1495, F1511, F1634]
- Serialize SFP init and `IXGBE_FLAG2_SEARCH_FOR_SFP` / `IXGBE_FLAG2_SFP_NEEDS_RESET` / `IXGBE_FLAG_NEED_LINK_CONFIG` updates in `ixgbe_reset()`, `ixgbe_sfp_detection_subtask()`, and `ixgbe_sfp_link_config_subtask()` with `test_and_set_bit(__IXGBE_IN_SFP_INIT, &adapter->state)`. In `ixgbe_reset_subtask()`, after `rtnl_lock()`, recheck that `__IXGBE_DOWN`, `__IXGBE_REMOVING`, and `__IXGBE_RESETTING` are clear before `ixgbe_reinit_locked()`. Maintain lock order `devl_lock(adapter->devlink)` -> `rtnl_lock`. [F1504, F1506, F1638]

## Object Lifetimes
- `ixgbe_get_rx_buffer()` decrements `rx_buffer->pagecnt_bias`, so any path in `ixgbe_clean_rx_irq()` or `ixgbe_construct_skb()` not attaching/flipping `rx_buffer->page` must increment `pagecnt_bias` back before `ixgbe_put_rx_buffer()` or breaking out. `ixgbe_put_rx_buffer()` must clear `rx_buffer->page = NULL` and `rx_buffer->skb = NULL` after transferring or draining. [F1478, F1480]
- For non-EOP first Rx buffers (`IXGBE_CB(skb)->dma == rx_buffer->dma`), `ixgbe_put_rx_buffer()` must set `IXGBE_CB(skb)->page_released = true` to defer unmapping until EOP in `ixgbe_dma_sync_frag()` or teardown in `ixgbe_clean_rx_ring()`. Because Rx pages use `DMA_ATTR_SKIP_CPU_SYNC`, `ixgbe_clean_rx_ring()` must call `dma_sync_single_range_for_cpu()` before unmapping and freeing each queued `rx_buffer`. [F1479, F1641]
- In `ixgbe_setup_tx/rx_resources()`, restore `set_dev_node(dev, orig_node)` immediately after the first `dma_alloc_coherent()`. `ixgbe_free_tx/rx_resources()` must return early if `!ring->desc` and clear `tx/rx_buffer_info` and `ring->desc` to `NULL`. Pair `xdp_rxq_info_reg()` in `ixgbe_setup_rx_resources()` with `xdp_rxq_info_unreg(&rx_ring->xdp_rxq)` (after clearing `rx_ring->xdp_prog`) in `ixgbe_free_rx_resources()`. [F1485, F1486, F1661]
- In `ixgbe_xdp_setup()`, call `bpf_prog_put(old_prog)` only after `ixgbe_setup_tc()` (`need_reset`) or after updating all `rx_ring[i]->xdp_prog` via `WRITE_ONCE()`. In `ixgbe_free_irq()` under MSI-X, skip `q_vector`s where `!q_vector->rx.ring && !q_vector->tx.ring`. [F1487, F1491]
- In `ixgbe_fwd_del()`, call `ixgbe_del_mac_filter()` and `napi_synchronize(&qv->napi)` (if running) on each pool queue before clearing `ring->netdev = NULL` and freeing `accel`. In `ixgbe_configure_clsu32()`, when `!link_uhtid`, `ixgbe_update_ethtool_fdir_entry()` takes ownership of `input` while copying `mask`, so success must `kfree(mask)` only, whereas error paths free both. [F1490, F1499]
- In `ixgbe_io_error_detected()`, when breaking out of the `pci_get_device()` loop on a matching `vfdev`, call `pci_dev_put(vfdev)` after `pcie_flr(vfdev)` and increment `adapter->vferr_refcount` (paired with `ixgbe_io_resume()`). On teardown, set `__IXGBE_REMOVING` before `cancel_work_sync(&adapter->service_task)` and `unregister_netdev()`, and call both `free_netdev(netdev)` and `devlink_free(adapter->devlink)`. [F1492, F1497, F1613]

## API Contracts
- Use `ixgbe_from_netdev(netdev)` rather than casting `netdev_priv(netdev)`. Check `netif_is_ixgbe(ring->netdev)` in `ixgbe_process_skb_fields()` and `ixgbe_vlan_strip_enable/disable()` before treating `ring->netdev` as an ixgbe device or calling `macvlan_count_rx()`. In `netdev_walk_all_upper_dev_rcu()` callbacks (`ixgbe_macvlan_up()`, `ixgbe_reassign_macvlan_pool()`, `get_macvlan_queue()`), check `netif_is_macvlan(vdev)` before `macvlan_accel_priv(vdev)` and null-check `accel`. [F1599, F1601, F1651]
- `ixgbe_cleanup_headers()` frees `skb` when returning `true`, and `skb_put_padto(skb, 17)` in `__ixgbe_xmit_frame()` frees `skb` on error (return `NETDEV_TX_OK`); callers must not free or touch `skb` afterward. [F1481, F1649]
- Call `skb_cow_head(skb, 0)` before mutating headers in `ixgbe_tso()` or VLAN priority insertion in `ixgbe_xmit_frame_ring()`. `ixgbe_tso()` returns `< 0` on error (drop), `1` on TSO emitted, or `0` (call `ixgbe_tx_csum()` only on `0`). `ixgbe_features_check()` must clear csum/TSO if MAC hdr > 127 or network hdr > 511, and clear `NETIF_F_TSO` on non-IPsec encapsulated packets without `NETIF_F_TSO_MANGLEID`. [F1515, F1648, F1652]
- `ixgbe_xmit_xdp_ring()` returns `IXGBE_XDP_TX` (>0) or `IXGBE_XDP_CONSUMED` without freeing `xdpf`. After the `ixgbe_clean_rx_irq()` loop, call `xdp_do_flush()` and `ixgbe_xdp_ring_update_tail_locked()` if `xdp_xmit` has `IXGBE_XDP_REDIR` or `IXGBE_XDP_TX`. `ixgbe_xdp_xmit()` must reject `flags & ~XDP_XMIT_FLAGS_MASK` with `-EINVAL`, update tail only on `XDP_XMIT_FLUSH`, and return sent count without freeing unsent frames. [F1514, F1655, F1656]
- Pass hardware pool `VMDQ_P(pool)` (`VMDQ_P(0)` for PF, `VMDQ_P(accel->pool)` for macvlan) to `ixgbe_add/del_mac_filter()` and `ixgbe_available_rars()`. Store `ixgbe_add_mac_filter()` and `ixgbe_write_mc_addr_list()` returns in signed `int` (`< 0` on error). On MAC filter failure, `ixgbe_fwd_ring_up()` frees `accel` itself, so `ixgbe_fwd_add()` must not free it. Pass `ring->reg_idx` to `ixgbe_set_ivar()` for Rx/Tx queues, and `u32` word count (max `IXGBE_VFMAILBOX_SIZE = 16`) as `size` to `ixgbe_read/write_mbx()`. [F1489, F1512, F1513, F1529, F1531, F1532]

## Error Handling
- On DMA error, `ixgbe_tx_map()` unmaps fragments, frees and clears `first->skb = NULL`, and rewinds `next_to_use`, so `ixgbe_xmit_frame_ring()` must jump to `cleanup_tx_timestamp` (not `out_drop`). Any drop after setting `IXGBE_TX_FLAGS_TSTAMP` (`adapter->ptp_tx_skb = skb_get(skb)`) must free and NULL `ptp_tx_skb`, cancel `ptp_tx_work`, and clear `__IXGBE_PTP_TX_IN_PROGRESS`. In `ixgbe_setup_all_tx_resources()`, initialize `j = 0` before the `tx_ring` loop (`i`) for `err_setup_tx` unwind. [F1482, F1483, F1577]

## External Contracts
- In `enum ixgbe_pfvf_api_rev` (`ixgbe_mbx.h`), never reorder/renumber values, and append new revisions before `ixgbe_mbox_api_unknown`. In `ixgbe_poll()`, clamp `per_ring_budget = max(budget / q_vector->rx.count, 1)`, and after `napi_complete_done()` return `min(work_done, budget - 1)`. [F1553, F1587]

## Known Pitfalls
- In `ixgbe_clean_rx_irq()`, `xdp_res` is declared outside the poll loop and only assigned when `!skb`; any new `!skb` branch must set `xdp_res`. In `ixgbe_tx_csum()`, when `skb->ip_summed != CHECKSUM_PARTIAL` or after `skb_checksum_help(skb)`, still jump to `csum_failed` / `no_csum` so `ixgbe_tx_ctxtdesc()` is emitted if `IXGBE_TX_FLAGS_HW_VLAN | IXGBE_TX_FLAGS_CC` is set. In `ixgbe_atr()`, verify `skb_tail_pointer(skb)` bounds before reading network/TCP headers, and read IPv4 `ihl` as `(hdr.network[0] & 0x0F) << 2`. [F1564, F1575, F1583]
- In `ixgbe_msix_other()`, read `IXGBE_EICS` masked with `0xFFFF0000` before writing `IXGBE_EICR` to preserve queue IRQ bits. In legacy/MSI mode (`!(flags & IXGBE_FLAG_MSIX_ENABLED)`), `IXGBE_EIAM` has `IXGBE_EICS_RTX_QUEUE` set, so `ixgbe_check_hang_subtask()` must not write those bits to `IXGBE_EICS`. In `ixgbe_write_eitr()`, OR `itr_reg << 16` on `ixgbe_mac_82598EB` and `IXGBE_EITR_CNT_WDIS` on 82599EB+. [F1538, F1622, F1623]
- In `ixgbe_update_stats()`, read `_H` after `_L` on 82599EB+ split 64-bit counters (`QBTC`, `QBRC`, `GORC`, `GOTC`, `TOR`) to clear them (82598EB has only 32-bit `_H`), and accumulate VF stats (`UPDATE_VF_COUNTER_36bit/32bit`) only when `!test_bit(__IXGBE_RESETTING, &adapter->state)`. In `ixgbe_sw_init()`, `ixgbe_mac_x550em_a` and `ixgbe_mac_X550EM_x` fall through into `case ixgbe_mac_X550:`, so guard X550-only flags (`IXGBE_FLAG2_TEMP_SENSOR_CAPABLE`) with `if (hw->mac.type == ixgbe_mac_X550)`. Use `time_after()` for jiffies deadlines in `ixgbe_update_itr()`, `ixgbe_watchdog_update_link()`, and `ixgbe_sfp_detection_subtask()`. [F1585, F1597, F1598, F1625]
