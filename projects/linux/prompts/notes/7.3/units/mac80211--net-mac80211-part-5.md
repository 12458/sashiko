# MAC80211 — net/mac80211 (part 5)

Implements the mac80211 packet receive path (`rx.c`), station lifecycle and hash table management (`sta_info.c`/`sta_info.h`), hardware/software scanning (`scan.c`), spectrum management (`spectmgmt.c`), S1G/TWT handling (`s1g.c`), and Minstrel HT/VHT rate control (`rc80211_minstrel_ht.c`/`rc80211_minstrel_ht_debugfs.c`).

## Architecture & Data Flow

- `WLAN_STA_AUTH`, `WLAN_STA_ASSOC`, and `WLAN_STA_AUTHORIZED` must only be modified by `_sta_info_move_state()` (never `set_sta_flag()`/`clear_sta_flag()`) in lockstep with `sta->sta_state`, `ieee80211_vif_inc/dec_num_mcast()`, and fast-TX/RX caches. `struct ieee80211_sta sta` must remain the last member of `struct sta_info` (`sta.drv_priv[]` trails), and `__sta_info_alloc()` allocates all `IEEE80211_NUM_TIDS + 1` `txq_info` entries (strided by `sizeof(struct txq_info) + ALIGN(hw->txq_data_size, sizeof(void *))`) in one `kcalloc()` at `sta->sta.txq[0]`, freed via `kfree(to_txq_info(sta->sta.txq[0]))`. [F383, F415, F416]
- `link_sta_info->pcpu_rx_stats` is allocated only when `USES_RSS` is set (`fast_rx->uses_rss`). Accessors must guard `per_cpu_ptr()`/`this_cpu_ptr()` with `pcpu_rx_stats != NULL` (or `fast_rx->uses_rss`); when enabled, `ieee80211_rx_8023()` updates `this_cpu_ptr(link_sta->pcpu_rx_stats)` and not `rx_stats_avg.signal`/`chain_signal`, RX stats/forwarding in `ieee80211_rx_8023()` must match `ieee80211_rx_h_sta_process()`/`ieee80211_deliver_skb()`, and `sta_info.c` readers must sum `link_sta->rx_stats` and all `pcpu_rx_stats` CPUs. [F365, F374, F400]
- Every exit path in `ieee80211_check_fast_rx()` must reach `clear:` (`__acquire`/`__release(check_fast_rx)`) so `WLAN_STA_DECAP_OFFLOAD`, `drv_sta_set_decap_offload()`, and `sta->fast_rx` update together; `sta->fast_rx` is disabled when `AMPDU_AGGREGATION` lacks `SUPPORTS_REORDERING_BUFFER`, station PS uses `PS_NULLFUNC_STACK` or lacks `SUPPORTS_DYNAMIC_PS`, or on AP/AP_VLAN vifs without `AP_LINK_PS`. [F389, F477]
- For MLO stations (`sta->sta.valid_links && sta->sta.mlo`), `__ieee80211_sta_recalc_aggregates()` writes min `max_amsdu_len`, `max_rc_amsdu_len`, and `max_tid_amsdu_len` across active links into `sta->cur` (`sta->sta.cur = &sta->cur`) rather than mutating `deflink.agg`. `link_sta_info` tracks `capa_nss` and `op_mode_nss` separately from `link_sta->pub->rx_nss`. In `ieee80211_sta_set_max_amsdu_subframes()`, `ext_capab[7]` and `ext_capab[8]` require separate `ext_capab_len < 8` and `ext_capab_len >= 9` checks. [F385, F392, F418]
- `sta_stats_encode_rate()` and `sta_stats_decode_rate()` must encode/decode `enum sta_stats_type` and `STA_STATS_FIELD_*` in lockstep, relying on `ieee80211_rx_list()` validating `status->band < NUM_NL80211_BANDS` and bounds on `rate_idx`, `nss`, and `eht.gi`. In `sta_set_link_sinfo()`/`sta_set_sinfo()`, software `tx_bytes`/`rx_bytes` fallback must check that neither `NL80211_STA_INFO_{TX,RX}_BYTES64` nor `NL80211_STA_INFO_{TX,RX}_BYTES` is set in `filled`. `__bss_tim_set/clear/get()` must use byte-wise `tim[id / 8]` and `(1 << (id % 8))` rather than `unsigned long` bitops. [F401, F414, F417, F438]
- `rx->sta` and `rx->link_sta` can be NULL in RX handlers (including `ieee80211_rx_h_action()` for `PUBLIC`, `SELF_PROTECTED`, and `SPECTRUM_MGMT`), and `rx->link_sta` is non-NULL iff `rx->sta` is non-NULL. In `ieee80211_rx_for_interface()`, `link_sta_info_get_bss()` must precede `sta_info_get_bss()`. In `__ieee80211_rx_handle_packet()`, management frames must call `skb_linearize(skb)` after checking `skb->len >= ieee80211_hdrlen(fc)`, whereas non-management frames use `pskb_may_pull()`. [F375, F430, F504]
- Because `ieee80211_rx_handlers()` reuses one `ieee80211_rx_data`, `ieee80211_rx_h_decrypt()` must reset `rx->key = NULL` on entry, and its `mmie_keyidx >= 0 && ieee80211_is_beacon(fc)` branch must precede `mmie_keyidx >= 0`. `ieee80211_get_mmie_keyidx()` must check `skb->len >= 24 + sizeof(*mmie)` (or `sizeof(*mmie16)`). In `ieee80211_rx_h_defragment()`, when `entry->check_sequential_pn` is set, each fragment's big-endian `rx->ccm_gcm.pn` must equal `entry->last_pn + 1` (with carry) or drop with `RX_DROP_U_REPLAY`. [F411, F431, F432, F449]
- `tid_ampdu_rx` indexes `reorder_buf`/`reorder_time` by `sn % tid_agg_rx->buf_size` after `ieee80211_sta_manage_reorder_buf()` advances `head_seq_num`. `ieee80211_release_reorder_frame()` must always clear `BIT_ULL(index)` in `reorder_buf_filtered` and increment `head_seq_num` (including on `no_frame:`). In `rx.c`, 12-bit sequence numbers must use `ieee80211_sn_less()`/`ieee80211_sn_less_eq()` and modulo-4096 masks (`IEEE80211_SN_MASK`). [F409, F424, F448]
- In `ieee80211_deliver_skb()` and `ieee80211_rx_8023()`, intra-BSS forwarding must `skb_copy()` multicast frames into `xmit_skb` (keeping `skb` for local delivery), whereas unicast to an associated STA sets `xmit_skb = skb` and `skb = NULL`; bridging via `dev_queue_xmit(xmit_skb)` must add 256 to `xmit_skb->priority`. Slow-path mesh forwarding in `ieee80211_rx_mesh_data()` must call `ieee80211_set_qos_hdr(sdata, fwd_skb)` before `ieee80211_add_pending_skb()`. [F439, F498, F499]
- In `ieee80211_rx_check_bss_color_collision()`, check `baselen > rx->skb->len` before `rx->skb->len - baselen`, check `ie->datalen` against both `sizeof(struct ieee80211_he_operation)` and `ieee80211_he_oper_size(ie->data + 1)`, and pass `BIT_ULL(color)` to `ieee80211_obss_color_collision_notify()`. [F413, F442]
- In `__ieee80211_start_scan()`, `local->hw_scan_req` allocates `struct_size(local->hw_scan_req, req.channels, req->n_channels) + local->hw_scan_ies_bufsize` (scaling `hw_scan_ies_bufsize` by `n_bands` when `SINGLE_SCAN_ON_ALL_BANDS` is set), sets `req.n_channels` before accessing `req.channels[]`, and passes negative `req->tsf_report_link_id` through unchanged on MLD vifs. `ieee80211_scan_state_set_channel()` must increment `local->scan_channel_idx++` before `if (skip)`. `ieee80211_send_scan_probe_req()` must set `IEEE80211_TX_CTRL_DONT_USE_RATE_MASK`. In `ieee80211_scan_rx()`, S1G beacon `min_hdr_len` must add `ieee80211_s1g_optional_len(ext->frame_control)`. In `ieee80211_parse_ch_switch_ie()`, read `bwi->info.optional` via `get_unaligned_le16()` only when `IEEE80211_BW_IND_DIS_SUBCH_PRESENT` is set. [F394, F397, F404, F419, F420, F434]
- In Minstrel HT (`rc80211_minstrel_ht.c`), `minstrel_ht_refill_sample_rates()` must sync `cur_sample_rates` from `sample_rates`; `minstrel_ht_tx_status()` must keep `minstrel_ht_ri_txstat_valid/get_stats()` and `minstrel_ht_txstat_valid/get_stats()` in sync and reset `total_packets`/`sample_packets` to 0 when `mi->total_packets >= ~0 - info->status.ampdu_len`; `GROUP_IDX`/`VHT_GROUP_IDX` take 1-based `_streams`, `minstrel_ht_update_rates()` sets `rates->rate[i].idx = -1` when `i < IEEE80211_TX_RATE_TABLE_SIZE`, `mcs_group::duration[]` is widened to 32-bit and left-shifted by `group->shift` (`minstrel_get_duration()`), and `MINSTREL_FRAC(val, div)` requires `attempts > 0` or `ampdu_packets > 0`. [F390, F402, F421, F444, F445, F446]

## Synchronization

- In `sta_info_insert_finish()`, `WLAN_STA_BLOCK_BA` is set before hash/list insertion and cleared only after `sta_info_insert_drv_state()` succeeds and `WLAN_STA_INSERTED` is set. Moving from `IEEE80211_STA_AUTHORIZED` to `IEEE80211_STA_ASSOC` in `_sta_info_move_state()` with `local->ops->set_key` must clear `WLAN_STA_AUTHORIZED`, call `synchronize_net()`, and flush queues before key removal. [F353, F356]
- Callers of `sta_info_get()`, `sta_info_get_bss()`, and `link_sta_info_get_bss()` must hold `rcu_read_lock()` or `local->hw.wiphy->mtx`. Callers of `ieee80211_find_sta*()` must hold `rcu_read_lock()` across the lookup and all uses of the returned `ieee80211_sta *`. [F359, F488]
- In `sta_ps_end()` and `ieee80211_sta_block_awake()`, `WLAN_STA_PS_DELIVER` must be set before clearing `WLAN_STA_PS_STA`/`WLAN_STA_PS_DRIVER`, and cleared in `ieee80211_sta_ps_deliver_wakeup()` under `spin_lock_bh(&sta->ps_lock)` (nesting `spin_lock_irqsave()` on `tx_filtered[ac].lock` and `ps_tx_buf[ac].lock`) after splicing queues. While `WLAN_STA_PS_DRIVER` is set, PS wakeup/poll/uAPSD delivery is deferred to `sta->drv_deliver_wk` (`sta_deliver_ps_frames()`), which wraps delivery in `local_bh_disable()`/`local_bh_enable()`; `ieee80211_sta_ps_transition()` also requires BHs disabled. `__sta_info_recalc_tim()` holds `spin_lock_bh(&local->tim_lock)` around `ps->tim` and `drv_set_tim()`. [F361, F475, F491, F492, F493]
- `tid_agg_rx->reorder_lock` protects `reorder_buf`, `reorder_time`, `reorder_buf_filtered`, `head_seq_num`, and `stored_mpdu_num`, and must be dropped before `ieee80211_rx_handlers()`. `ieee80211_release_reorder_timeout()` requires `rcu_read_lock()`. [F362, F483]
- `ieee80211_invoke_fast_rx()` runs without `rx_path_lock` and rejects frames lacking `RX_FLAG_DUP_VALIDATED` (or `RX_FLAG_PN_VALIDATED | RX_FLAG_DECRYPTED` when `fast_rx->key` is set). `sta->fast_rx` updates require `spin_lock_bh(&sta->lock)` and `kfree_rcu(old, rcu_head)`. `ieee80211_rx_list()` drops frames when `quiescing`, `suspended`, `in_reconfig`, or `!started` is true, and `ieee80211_sched_scan_stopped()` ignores calls during `in_reconfig`. Minstrel HT callbacks under `sta->rate_ctrl_lock` must use `GFP_ATOMIC`. [F363, F476, F485, F497]

## Object Lifetimes

- `sta_info_insert()`/`sta_info_insert_rcu()` consume `sta` and free it on error; callers only call `sta_info_free()` if insertion was never called. `__sta_info_destroy_part1()` tears down BA, calls `drv_sync_rx_queues()`, unhashes/unlinks `sta`, and calls `drv_sta_pre_rcu_remove()`, and `synchronize_net()` must elapse before `__sta_info_destroy_part2()`. [F468, F470]
- Non-NULL returns from `ieee80211_bss_info_update()` must be released via `ieee80211_rx_bss_put(local, bss)`. With `use_origskb == true`, `ieee80211_make_monitor_skb()` zeroes `*origskb = NULL` and frees `skb` if `pskb_expand_head()` fails. [F344, F350]
- When `SCAN_HW_SCANNING` is set, `ieee80211_scan_cancel()` must not cancel `scan_work`, free `hw_scan_req`, or call `__ieee80211_scan_completed()`. On final completion in `__ieee80211_scan_completed()`, `hw_scan_req` is freed/nulled, `scan_req`/`scan_sdata` nulled, and `synchronize_rcu()` called before `cfg80211_scan_done()`. [F346, F347]

## API Contracts

- `sta_info_insert_rcu()` requires `wiphy->mtx` without `rcu_read_lock()`, and always returns with `rcu_read_lock()` held (`__acquires(RCU)`). `ieee80211_recalc_min_chandef()` and `ieee80211_recalc_p2p_go_ps_allowed()` must precede `sta_info_insert_drv_state()` in `sta_info_insert_finish()` when `sta_state >= IEEE80211_STA_ASSOC`. In `ieee80211_sta_activate_link()`, `ieee80211_recalc_min_chandef()` and `ieee80211_sta_recalc_aggregates()` precede `drv_change_sta_links()`, restoring `valid_links` and calling `sta_remove_link(sta, link_id, false)` on failure before `link_sta_info_hash_add()`. [F464, F473, F489]
- In `sta_info.c`, `link_id < 0` (`-1`) selects `&sta->deflink`, whereas `link_id >= 0` indexes `sta->link[link_id]`. On `NL80211_IFTYPE_STATION`, pre-populate `rx_beacon` from `count_beacon_signal` before `drv_sta_statistics()`/`drv_link_sta_statistics()`. [F378, F479]
- `ieee80211_sta_ps_deliver_response()` and `ieee80211_sta_ps_more_data()` take `ignored_acs` (`ieee80211_ac_to_qos_mask` bits): U-APSD passes `~sta->sta.uapsd_queues`, whereas PS-Poll and `__sta_info_recalc_tim()` pass `sta->sta.uapsd_queues` (resetting to `0` when `uapsd_queues == BIT(IEEE80211_NUM_ACS) - 1`). When `IEEE80211_HW_AP_LINK_PS` is set, RX handlers ignore PM bits and PS-Poll/uAPSD triggers, and `sta_ps_start()`/`ieee80211_sta_ps_deliver_wakeup()` skip `drv_sta_notify()`. [F379, F437, F474]
- In `ieee80211_rx_napi()`, `ieee80211_rx_list()` runs under `rcu_read_lock()` and unlinks each SKB via `skb_list_del_init(skb)` before `napi_gro_receive()`. `ieee80211_rx_handlers()` callbacks return `RX_QUEUED` if they consume/free `rx->skb`, and `RX_DROP`/drop-reason only when `rx->skb` remains for `ieee80211_rx_handlers_result()` to free; malformed action frames in `ieee80211_rx_h_action()` (`goto invalid`) set `IEEE80211_RX_MALFORMED_ACTION_FRM` and return `RX_CONTINUE`. [F371, F433, F505]
- `ieee80211_invoke_fast_rx()` calls `skb_postpull_rcsum()` before pulling 802.11+SNAP headers on non-mesh frames. `ieee80211_rx_mesh_fast_forward()` queries `mesh_fast_tx_get()` with `MESH_FAST_TX_TYPE_FORWARDED`. `ieee80211_request_ibss_scan()` copies `IEEE80211_MAX_SSID_LEN` bytes from `ssid`. In Minstrel HT, unused `mp->cck_rates[]`/`mp->ofdm_rates[][]` (`u8`) are `0xff`, and `minstrel_ht_get_expected_throughput()` scales `minstrel_ht_get_tp_avg()` to kbps (`tp_avg * 10 * AVG_PKT_SIZE * 8 / 1024`). [F381, F393, F455, F502, F506]

## Error Handling

- On `sta_info_insert_drv_state()` failure in `sta_info_insert_finish()`, unhash `sta->deflink` and `sta`, unlist `sta->list`, decrement `local->num_sta`, and call `synchronize_net()` before `cleanup_single_sta(sta)`; inside `sta_info_insert_drv_state()`, unwind non-IBSS `drv_sta_state()` failures back down to `IEEE80211_STA_NOTEXIST`. [F339, F340]
- If `pskb_expand_head()` fails on the final fragment in `ieee80211_rx_h_defragment()`, call `__skb_queue_purge(&entry->skb_list)` and return `RX_DROP_U_OOM` (leaving `rx->skb` for `ieee80211_rx_handlers_result()`). [F351]
- In `ieee80211_parse_ch_switch_ie()`, `validate_chandef_by_ht_vht_oper()` and `validate_chandef_by_6ghz_he_eht_oper()` set `chandef->chan = NULL` on failure, so `csa_ie->chanreq.ap` must be initialized from `csa_ie->chanreq.oper` first and updated only if `new_chandef.chan` is non-NULL. [F367]
- In `__ieee80211_start_scan()`, do not return early between `local->hw_scan_req` allocation and `if (rc)` cleanup; if `drv_hw_scan()` returns `1` (SW scan fallback), return `-EOPNOTSUPP` on `NL80211_IFTYPE_P2P_GO` or clear `hw_scan_req`, `scanning`, `scan_req`, and `scan_sdata` before `goto again`. [F370, F435]

## External Contracts

- `ieee80211_find_sta()` and `ieee80211_find_sta_by_ifaddr()` return `NULL` when `!sta->uploaded`, unlike `ieee80211_find_sta_by_link_addrs()`. `__ieee80211_rx_handle_packet()` requires 2-byte aligned `skb->data`. `ieee80211_rx_list()` zeroes `status->rx_flags`, and `ieee80211_deliver_skb_to_local_stack()` zeroes `skb->cb` and rewrites `ehdr->h_dest` to `sdata->vif.addr` on `control_port_protocol` frames. [F382, F396, F486, F500]

## Known Pitfalls

- Re-fetch `hdr` from `rx->skb->data` after decrypt in `ieee80211_rx_h_decrypt()`, `skb_linearize()` in `ieee80211_rx_h_defragment()`, and `skb_copy()` in `ieee80211_prepare_and_rx_handle()` (which must also copy `skb_hwtstamps(skb)->hwtstamp`). Stripping HT-Control in `ieee80211_clean_skb()` requires `pskb_may_pull(skb, hdrlen)` and `memmove()`. [F391, F456, F501]
- In `ieee80211_add_rx_radiotap_header()`, copy and `skb_pull()` HE/HE-MU/LSIG structs at `skb->data` before `skb_push()`/`memset()`, and derive `pos` via `&rthdr->it_optional[it_present + 1 - rthdr->it_optional]`. Use `DIV_ROUND_UP()` for 5/10 MHz legacy bitrates in `ieee80211_add_rx_radiotap_header()` and `sta_stats_decode_rate()`. [F399, F447, F457]
- In `__ieee80211_rx_handle_packet()`, multi-target loops must defer `consume = true` to `prev_sta`/`prev` after the loop and never dereference the loop cursor after termination. Use `BIT_ULL()` on `tid_ampdu_rx::reorder_buf_filtered` (`u64`) and `filtered`, and check `max_rx_aggregation_subframes <= 64` and `diff < tid_agg_rx->buf_size` before `filtered >> diff` in `ieee80211_mark_rx_ba_filtered_frames()`. [F429, F440, F441]
- `ewma_signal_add()`/`ewma_avg_signal_add()` store `-status->signal`, so `sta_set_sinfo()` and `sta_set_link_sinfo()` must negate `ewma_*_read()`. Initialize `sinfo->valid_links` from `sta->sta.valid_links` before `for_each_valid_link()` in `sta_set_sinfo()` and mask missing links with `&= ~BIT(link_id)` inside. Keep `ms->len + sizeof(*ms) <= 32768` in `minstrel_ht_stats_open()`/`minstrel_ht_stats_csv_open()`. [F380, F423, F460]
