# NETWORKING [GENERAL] — net/core (part 1)

Core protocol-independent networking subsystem implementing network device lifecycle and registration, TX/RX/NAPI datapaths, device adjacency graphs, XDP attachment (`net/core/dev.c`), datagram reception (`net/core/datagram.c`), and BPF socket storage (`net/core/bpf_sk_storage.c`).

## Architecture & Data Flow
- In `__netif_receive_skb_core()`, walk `ptype_all` before protocol handlers; flush deferred `pt_prev` via `deliver_skb()` and reset to `NULL` before `sch_handle_ingress()`, `nf_ingress()`, `vlan_do_receive()`, or `rx_handler(&skb)`; keep `*pskb` non-`NULL` whenever `*ppt_prev` is non-`NULL`; and when `skb_pfmemalloc(skb)` is true, skip `ptype_all` taps and drop (`SKB_DROP_REASON_PFMEMALLOC`) unless `skb_pfmemalloc_protocol(skb)` holds [F436, F483, F574].
- In `__netif_receive_skb_list_core()`, unlink each `skb` via `skb_list_del_init(skb)` before `__netif_receive_skb_core()`, and flush `sublist` via `__netif_receive_skb_list_ptype()` whenever `pt_curr != pt_prev || od_curr != orig_dev` [F485].
- `dev->xdp_state[mode]` keeps `.link` and `.prog` mutually exclusive (`dev_xdp_set_link()`/`dev_xdp_set_prog()`); query via `dev_xdp_prog(dev, mode)` rather than `.prog` directly. In `generic_xdp_install()`, `NULL`-to-non-`NULL` `dev->xdp_prog` transitions must increment `generic_xdp_needed_key` and call `netif_disable_lro(dev)` and `dev_disable_gro_hw(dev)`; non-`NULL`-to-`NULL` must decrement `generic_xdp_needed_key` [F437, F446].
- In `__netdev_update_features()`, when changing `NETIF_F_RX_UDP_TUNNEL_PORT`, `NETIF_F_HW_VLAN_CTAG_FILTER`, or `NETIF_F_HW_VLAN_STAG_FILTER`, assign `dev->features = features` before `*_get_rx_*_info(dev)` when enabling, but after `*_drop_rx_*_info(dev)` when disabling [F445].
- When `n->config != NULL`, `napi_disable_locked()` must call `napi_save_config()` and unhash `n`, and `napi_enable_locked()` must call `napi_restore_config()`. `netif_napi_add_config_locked()` requires 0-based `index < max(dev->num_tx_queues, dev->num_rx_queues)` (`dev->num_napi_configs`) [F442, F477].
- `skb->sender_cpu` (`1..NR_CPUS`, `cpu + 1`) and `skb->napi_id` (`>= MIN_NAPI_ID` in `napi_hash_add()`) share a union (`0` = unset); subtract 1 (`skb->sender_cpu - 1`) when indexing CPU arrays or `XPS_CPUS` maps [F464].
- Datapath queue selectors (`netdev_pick_tx()`, `netdev_core_pick_tx()`, `__get_xps_queue_idx()`, `netif_get_rxqueue()`, `get_rps_cpu()`) bound indices by `real_num_{tx,rx}_queues`, while teardown/reset iterates `num_{tx,rx}_queues`. In `__netif_set_xps_queue()`, `xps_copy_dev_maps()` requires both `num_tc` and `nr_ids` to match `dev_maps` [F465, F511].
- Removing SKBs from `sd->input_pkt_queue` or `sd->process_queue` outside `process_backlog()` (`flush_backlog()`, `dev_cpu_dead()`) must call `rps_input_queue_head_incr(sd)` per SKB [F448].
- `__netdev_upper_dev_link()` requires `dev->lower_level + upper_dev->upper_level <= MAX_NEST_DEV` (`-EMLINK`) and `!__netdev_has_upper_dev(upper_dev, dev)`. `__netdev_adjacent_dev_insert()` must insert master entries at head (`list_add_rcu()`) and non-master at tail (`list_add_tail_rcu()`), as `netdev_master_upper_dev_get*()` checks only the first entry [F476, F489].
- `pcpu_sw_netstats` and `pcpu_dstats` must share offsets for `{rx,tx}_{bytes,packets}`, and `rtnl_link_stats64` must start with `net_device_stats` fields in identical order (`u64` for `unsigned long`) for `netdev_stats_to_stats64()` [F462, F463].
- `alloc_netdev_mqs()` must set `dev->priv_len = sizeof_priv` (`__counted_by(priv_len)`). `netif_set_alias()` with `len > 0` must allocate `sizeof(*new_alias) + len + 1` and NUL-terminate `ifalias[len]`. `dev_index_reserve()` must reject `ifindex > INT_MAX` and use `xa_limit_31b`. `__dev_alloc_name()` must `strscpy(buf, name, IFNAMSIZ)` before `snprintf(res, ...)` (since `name` may alias `res`), verify a single `"%d"`, and bounds-check `0 <= i < max_netdevices` before `__set_bit(i, inuse)` [F458, F467, F504, F510, F512].
- In `sk_validate_xmit_skb()`, read `sk->sk_validate_xmit_skb` only if `sk_fullsock(sk)`, and `inet_twsk(sk)->tw_validate_xmit_skb` only if `sk_is_inet(sk) && sk->sk_state == TCP_TIME_WAIT` [F520].
- In `skb_set_peeked()`, if `skb_shared(skb)`, clone and splice the new SKB into the queue and consume the old one before setting `skb->peeked = 1`. In `zerocopy_fill_skb_from_iter()` and `zerocopy_fill_skb_from_devmem()`, check `nr_frags < MAX_SKB_FRAGS` (`-EMSGSIZE`) and cap `iov_iter_get_pages2()` to `MAX_SKB_FRAGS - frag` [F454, F470].
- `bpf_iter_attach_map()` must reject `prog->aux->max_rdwr_access > map->value_size` (`-EACCES`). `bpf_sk_storage_charge()` must check `size <= optmem_max` before `atomic_read(&sk->sk_omem_alloc) + size < optmem_max` [F473, F474].

## Synchronization
- Lockless lookups locking `dev->lock` (`__netdev_put_lock()`, `netdev_napi_by_id_lock()`, `netdev_get_by_index_lock()`, `netdev_xa_find_lock()`) must `dev_hold()` under RCU, drop RCU before `netdev_lock(dev)`, and verify `reg_state <= NETREG_REGISTERED`, `!moving_ns`, and `net_eq(dev_net(dev), net)`. `rtnl_net_dev_lock(dev)` must take `net_passive_inc(net)` under RCU before `rtnl_net_lock(net)` and re-verify `dev->nd_net.net` [F546, F549].
- `NETDEV_REGISTER`, `NETDEV_UP`, and `NETDEV_CHANGE` require `netdev_lock_ops(dev)` held; their callbacks must use unlocked `netif_*` helpers (`netif_xdp_propagate()`, `netif_set_promiscuity()`, `netif_state_change()`). Lower-device feature propagation (`netdev_sync_lower_features()`, `netif_disable_lro()`) must wrap each lower update in `netdev_lock_ops(lower)` [F408, F409].
- Unregistration and netns move (`unregister_netdevice_many_notify()`, `__dev_change_net_namespace()`) must call `unlist_netdevice()`, set `NETREG_UNREGISTERING`/`moving_ns` under `dev->lock`, and `synchronize_net()` before calling `dev_shutdown()` or XDP/TCX/MP uninstall under `netdev_lock_ops(dev)`. `netdev_run_todo()` must snapshot `net_todo_list` and `__rtnl_unlock()` before `rcu_barrier()`, setting `NETREG_UNREGISTERED` under `netdev_lock(dev)`, `linkwatch_sync_dev()`, and `netdev_wait_allrefs_any()`. `from_cleanup_net()` must use `READ_ONCE(cleanup_net_task)` [F406, F407, F415].
- `netdev_rx_handler_register()` must assign `rx_handler_data` before `rx_handler`; `netdev_rx_handler_unregister()` must clear `rx_handler` and `synchronize_net()` before clearing `rx_handler_data`. `netif_change_name()` must hold `write_seqlock_bh(&netdev_rename_lock)` when writing `dev->name` and call `synchronize_net()` between `netdev_name_node_del()` and `netdev_name_node_add()` [F401, F547].
- `napi_set_threaded()` must create `napi->thread` and issue `smp_mb__before_atomic()` before setting `NAPI_STATE_THREADED`. `netif_napi_add_weight_locked()` must gate `napi_kthread_create()` on `napi_get_threaded_config(dev, napi)`, not `dev->threaded` [F402, F524].
- `napi_schedule_prep()` and `napi_complete_done()` must update `n->state` via `try_cmpxchg()`, rescheduling if `NAPIF_STATE_MISSED` was set. `____napi_schedule()` requires hardirqs disabled, so `__napi_schedule_irqoff()` must call `__napi_schedule()` on `CONFIG_PREEMPT_RT`. In `__napi_busy_loop()`, call `busy_poll_stop()` if `napi_poll` is set before dropping RCU for `cond_resched()`, and reset `napi_poll = NULL` and re-lookup `napi_by_id()` at `restart:` [F414, F487, F555].
- `softnet_data` `output_queue` and `completion_queue` accesses (`__netif_reschedule()`, `dev_kfree_skb_irq_reason()`, `net_tx_action()`, `dev_cpu_dead()`) require hardirqs disabled (`local_irq_save()`/`disable()`), and detaching `sd->output_queue = NULL` must reset `sd->output_queue_tailp = &sd->output_queue`. Accessing `sd->process_queue` requires `local_lock_nested_bh(&softnet_data.process_queue_bh_lock)`, which `process_backlog()` must release before `__netif_receive_skb()` [F447, F544, F551].
- BPF/NAPI entry points (`tcx_run()`, `do_xdp_generic()`, `busy_poll_stop()`, `__napi_busy_loop()`, `napi_threaded_poll_loop()`, `net_rx_action()`) must bracket execution with `bpf_net_ctx_set()` and `bpf_net_ctx_clear()`. `__netif_receive_skb()`/`_list()` must bracket `sk_memalloc_socks() && skb_pfmemalloc(skb)` with `memalloc_noreclaim_save()`/`restore()` [F556, F558].
- XPS map writers (`__netif_set_xps_queue()`, `netif_reset_xps_queues()`) must hold `cpus_read_lock()` outside `xps_map_mutex`. `dev_fetch_dstats()` and `dev_fetch_sw_netstats()` must read counters into temporaries inside `u64_stats_fetch_retry()` and accumulate into `rtnl_link_stats64` only after the loop. `__dev_open()` waking `!netif_device_present(dev)` via `pm_runtime_resume(dev->dev.parent)` must re-check `netif_device_present(dev)` [F496, F535, F550].
- `__sk_queue_drop_skb()` and `skb_kill_datagram()` (do not use if queue lock is taken in hardirq) must take `spin_lock_bh(&sk_queue->lock)` and verify `skb->next != NULL` before unlinking a peeked SKB [F419].
- In `bpf_sk_storage_clone_elem()` and `diag_get()`, use `copy_map_value_locked()` if `btf_record_has_field(smap->map.record, BPF_SPIN_LOCK)`. `bpf_sk_storage_map_seq_find_next()` holds `rcu_read_lock()` only on non-`NULL` return (dropping RCU and resetting `skip_elems = 0` on bucket exhaustion), so `bpf_sk_storage_map_seq_stop()` must unlock RCU only when `v != NULL` [F418, F482].

## Object Lifetimes
- In `free_netdev()`, if `reg_state == NETREG_UNREGISTERING`, assert RTNL, set `needs_free_netdev = true`, and return early; otherwise call `mutex_destroy(&dev->lock)` only after `netif_free_rx_queues()`, `netdev_napi_exit()`, and all `dev->lock` users finish, and call `kvfree(dev)` only for `NETREG_UNINITIALIZED`/`NETREG_DUMMY` (`NETREG_UNREGISTERED` must set `NETREG_RELEASED` and call `put_device(&dev->dev)`). `unregister_netdevice_many_notify()` and `__dev_close()` must `list_del()` the caller's stack `list_head` before returning [F377, F521, F526, F527].
- In `netif_napi_set_irq_locked()` and `netif_napi_affinity_release()`, clear `rx_cpu_rmap->obj[napi_rmap_idx] = NULL` before `cpu_rmap_put()`. On `netif_alloc_rx_queues()` failure at index `i`, unregister only `while (i--) xdp_rxq_info_unreg(...)`, free `dev->_rx`, and set `dev->_rx = NULL` [F376, F387].
- `dev_xdp_install()` must call `bpf_prog_inc(prog)` before `bpf_op(dev, &xdp)` and `bpf_prog_put(prog)` on error. `bpf_xdp_link` holds no netdev ref (`bpf_xdp_link_attach()` drops it); `dev_xdp_uninstall()` and `bpf_xdp_link_release()` must set `link->dev = NULL` under `rtnl_lock()`. `__dev_remove_pack()` requires an RCU grace period (`synchronize_net()`) before freeing `packet_type` [F383, F384, F389].
- In `netdev_adjacent_change_{prepare,commit,abort}()`, when `new_dev == old_dev`, do not disable `old_dev` in prepare or unlink it in commit; on abort with `new_dev != NULL`, unlink `new_dev` and re-enable `old_dev` if `new_dev != old_dev` [F393].
- `zerocopy_fill_skb_from_iter()` must release coalesced page refs via `page_ref_sub(last_head, refs)`. `__zerocopy_sg_from_iter()` must charge `skb->truesize - orig_size` to socket wmem even on error return [F399, F400].

## API Contracts
- `__dev_get_by_{name,index}()`, `dev_get_by_{name,index}_rcu()`, and `dev_getbyhwaddr_rcu()` return borrowed pointers; `dev_get_by_{name,index}()`, `netdev_get_by_{name,index}()`, and `dev_getfirstbyhwtype()` increment refcount [F381].
- In `register_netdevice()`, `ndo_get_peer_dev` requires `pcpu_stat_type == NETDEV_PCPU_STAT_TSTATS`, and `NETIF_F_HW_VLAN_CTAG_FILTER` requires both `ndo_vlan_rx_{add,kill}_vid`. `__netdev_update_features()` returns `1` (changed), `-1` (`ndo_set_features` failed), or `0` (no notify); non-zero triggers `netdev_features_change()`. `dev_xdp_install()` and `netif_xdp_propagate()` must return `-EBUSY` if `dev_get_min_mp_channel_count(dev)` is non-zero or `hds_config == ETHTOOL_TCP_DATA_SPLIT_ENABLED` without `prog->aux->xdp_has_frags` [F438, F566, F571].
- `__netif_napi_del_locked()` requires `NAPI_STATE_SCHED` set (disabled) and `napi->dev` locked. In `__napi_poll()`, touch `n`'s state or repoll only when `work >= weight` (`work < weight` means driver poll already completed and released `n`) [F486, F528].
- `__skb_wait_for_more_packets()` returns `0` (retry), `< 0` (error in `*err`), or `1` with `*err = 0` on `RCV_SHUTDOWN` (EOF). In `__skb_try_recv_{from_queue,datagram}()`, `*off` with `MSG_PEEK` is in/out (input skip offset, output offset in returned `skb`). `__skb_datagram_iter()`, `zerocopy_fill_skb_from_iter()`, and `skb_checksum_help()` must check `skb_frags_readable(skb)`. `zerocopy_fill_skb_from_devmem()` only accepts `ITER_IOVEC` or `ITER_UBUF` (`-EFAULT`). `skb_copy_and_csum_datagram_msg()` requires `skb->len >= hlen` and must run `__skb_checksum_complete(skb)` before `skb_copy_datagram_msg()` when `msg_data_left(msg) < skb->len - hlen`. `bpf_fd_sk_storage_lookup_elem()` returns `ERR_PTR(err)` on bad FD, `NULL` on miss, and `sdata->data` on hit [F422, F425, F426, F468, F542, F577].

## Error Handling
- In `register_netdevice()`, normalize positive `ndo_init` return to `-EIO`; before `list_netdevice()`, unwind `NETDEV_PRE_UNINIT`, `dev_index_release()`, `netdev_do_free_pcpu_stats()`, `ndo_uninit()`, `priv_destructor()`, and `netdev_name_node_free()`; if `NETDEV_REGISTER` fails after `NETREG_REGISTERED`, set `needs_free_netdev = false` and call `unregister_netdevice_queue(dev, NULL)` [F379, F439].
- `netif_set_real_num_queues()` must apply RX/TX increases before decreases and roll back `rxq` to `old_rxq` if TX increase fails. `__netif_set_xps_queue()` error cleanup must only `kfree(new_map)` when `new_map != map`. Notifier registration rollback (`register_netdevice_notifier()`, `call_netdevice_register_net_notifiers()`) must use `for_each_{net,netdev}_continue_reverse()`. Adjacency insertion/link errors (`__netdev_adjacent_dev_insert()`, `__netdev_upper_dev_link()`) must unlink and drop `adj_dev` ref [F386, F390, F391, F392].
- `netif_change_name()` rollback must guard `if (err >= 0)` to preserve initial error and avoid infinite loops. `napi_kthread_create()` must reset `n->thread = NULL` on `IS_ERR()`. `dev_get_stats()` and `netdev_stats_to_stats64()` must zero `storage` and trailing extended fields. `__dev_set_promiscuity()` and `netif_set_allmulti()` must return `-EOVERFLOW` without modifying state if `inc > 0` wraps the counter to `0`. `__skb_datagram_iter()` must call `iov_iter_revert(to, offset - start_off)` before returning `-EFAULT` on short/unreadable copies [F427, F430, F431, F440, F501].

## External Contracts
- `bpf_sk_storage_diag_alloc()` requires `bpf_capable()`, `nla_len(nla) == sizeof(u32)`, and unique `BPF_MAP_TYPE_SK_STORAGE` maps; `diag_get()` and `nla_value_size()` must use `nla_reserve_64bit(..., SK_DIAG_BPF_STORAGE_PAD)` and `nla_total_size_64bit(value_size)` for `SK_DIAG_BPF_STORAGE_MAP_VALUE` [F472, F580].

## Known Pitfalls
- In `netif_receive_generic_xdp()`, `netif_skb_check_for_xdp(pskb, ...)` can reallocate `*pskb`; always dereference `*pskb` afterward. `netdev_lower_get_next{,_private}()` take `*iter` as current entry (`list_entry(*iter, ...)`), while `netdev_lower_get_next_private_rcu()` and `netdev_next_lower_dev()` take `*iter` as prior node (`(*iter)->next`). Cast `atomic_long_read()` to `unsigned long` before `u64` in `netdev_stats_to_stats64()`; cast `p` to `(void __percpu *)` before adding byte `offset` in `netdev_core_stats_inc()`; use `time_after()`/`time_after_eq()` for `jiffies` deadlines in `net_rx_action()` and `netdev_wait_allrefs_any()`; pass `&features` to `%pNF`; and use `size_t` `start` and `1UL << order` for compound page bounds in `zerocopy_fill_skb_from_iter()` [F451, F460, F495, F500, F506, F515, F523].
