# PERFORMANCE EVENTS SUBSYSTEM — (top level) (part 1)

Provides the kernel and UAPI headers (`include/linux/perf_event.h`, `include/uapi/linux/perf_event.h`), generic callchain buffer management (`kernel/events/callchain.c`), and architecture-specific CPU PMU drivers and callchain unwinders across Alpha, ARC, C-SKY, Hexagon, LoongArch, MIPS, PA-RISC, PowerPC, RISC-V, s390, SuperH, SPARC, x86, and Xtensa.

## Architecture & Data Flow
- `perf_callchain_entry__sizeof()` reserves `sysctl_perf_event_max_stack + sysctl_perf_event_max_contexts_per_stack` entries in `entry->ip[]`. `perf_callchain_store()` and `perf_callchain_store_context()` append to `entry->ip[entry->nr++]`, bounding frames via `ctx->nr < ctx->max_stack` and contexts via `ctx->contexts` (setting `ctx->contexts_maxed` when full to block `perf_callchain_store()`). In `fixup_uretprobe_trampoline_entries()`, `cur_ip` advances every iteration of `while (ri && cur_ip <= last_ip)`, whereas `ri = ri->next` advances only when `*cur_ip == tramp_addr`. [F65, F83, F84]
- Payload helpers on `struct perf_sample_data` (`perf_sample_save_callchain`, `perf_sample_save_raw_data`, `perf_sample_save_brstack`) must check the matching `PERF_SAMPLE_*` bit in `data->sample_flags` is unset, then set it and add the serialized byte size to `data->dyn_size` in lockstep. `perf_sample_save_brstack()` sizes the header as `sizeof(u64)` plus `sizeof(u64)` only when `branch_sample_hw_index(event)` is true—never `sizeof(struct perf_branch_stack)`. [F62, F105]
- On s390, `guest_is_user_mode(regs)` and `instruction_pointer_guest(regs)` dereference `sie_block(regs)` (`NULL` when `regs->gprs[15] == 0`) and require `is_in_guest(regs)` (`!user_mode(regs)` and `instruction_pointer(regs) == (unsigned long)&sie_exit`). `perf_misc_flags_sf()` reinterprets `&regs->int_parm_long` as `struct perf_sf_sde_regs *` and requires `regs->int_code == 0x1407`, `regs->int_parm == CPU_MF_INT_SF_PRA`, and `regs->gprs[15] == 0`. [F42, F110]
- On SPARC and Alpha, when constraint checking reassigns an active event (`cpuc->current_idx[i] != event->hw.idx`), enabling the PMU (`update_pcrs_for_enable()`, `maybe_change_configuration()`) must flush the old counter via `*_perf_event_update(..., cpuc->current_idx[i])` and reset `current_idx[i]` before reprogramming. In `sparc_pmu_del()` and `alpha_pmu_del()`, `cpuc->event[]`, `cpuc->events[]` (or `cpuc->evtype[]`), and `cpuc->current_idx[]` must shift down in lockstep, and `sparc_pmu_del()` must call `sparc_pmu_stop()` before shifting so `active_event_index()` finds the entry. [F53, F54]
- On SPARC, `hwc->event_base` packs `(encoding << 16) | pic_mask` with `PIC_UPPER` (`0x01`, `PIC_UPPER_INDEX = 0`) or `PIC_LOWER` (`0x02`, `PIC_LOWER_INDEX = 1`). When `sparc_pmu->num_pcrs == 1`, both counters share `cpuc->pcr[0]` and `pcr_ops->write_pic(0, ...)`: `sparc_default_write_pmc()` must read-modify-write only the target 32-bit half, `sparc_pmu->write_pmc(idx, val)` callers must mask `val & 0xffffffff`, and `sparc_pmu_disable_event()` must replace only `mask_for_index(idx)` with `nop_for_index(idx)` without clearing shared trace-enable bits. [F55, F79, F95]
- In `sparc_perf_event_update()`, `new_raw_count` and `prev_raw_count` must be shifted left by 32 before subtracting and arithmetic-right-shifting `s64 delta` by 32. In `perf_event_nmi_handler()`, when `sparc_pmu->irq_bit` is non-zero, `pcr_ops->write_pcr()` must clear PCR overflow bits before `sparc_perf_event_update()`, and if `val & (1ULL << 31)` is set, the 32-bit PIC has not wrapped and must be skipped with `continue`. [F88, F96, F125]
- On Alpha, counters share the IBOX `PCTR`: `alpha_write_pmc()` must mask `val` with `pmc_count_mask[idx]`, shift by `pmc_count_shift[idx]`, and OR in `(1<<idx)` before `wrperfmon(PERFMON_CMD_WRITE, val)`. `alpha_perf_event_set_period()` must clamp `left` to `[pmc_left[idx], pmc_max_period[idx]]` before writing `(unsigned long)(-left)`. `alpha_perf_event_update()` must mask `prev_raw_count` with `pmc_count_mask[idx]` before subtracting from `new_raw_count`, adding `pmc_max_period[idx] + 1` if `delta < 0`. `ev67_mapping[]` (0-based) must match `enum ev67_pmc_event_type` order (1-based, `[EV67_CYCLES, EV67_LAST_ET)`). [F72, F73, F97, F118]
- On LoongArch and MIPS, while counters are paused (`pause_local_counters()`), enabling/disabling an event must update `cpuc->saved_ctrl[idx]` because `resume_local_counters()` overwrites control registers from `cpuc->saved_ctrl[]`. `mipspmu_event_set_period()` and `loongarch_pmu_event_set_period()` must set `hwc->prev_count` and the counter to `overflow - left` (`overflow = 1ULL << (counter_bits - 1)`), with `max_period <= overflow - 1`. [F58, F93]
- On MIPS, `event_id == 0x00` is valid, so `mipspmu_map_general_event()` and `mipspmu_map_cache_event()` test `cntr_mask == 0` for unsupported entries. Valid `struct mips_perf_event` entries must set bits 8..23 (10..23 on `LOONGSON_PMU_TYPE2`) in `cntr_mask` via `CNTR_EVEN`/`CNTR_ODD`/`CNTR_ALL` because `mipspmu_perf_event_encode()` masks with `0xffff00` (`0xfffc00`) and `mipsxx_pmu_alloc_counter()` shifts `hwc->event_base` right by 8 (or 10). On `LOONGSON_PMU_TYPE2`, `mipspmu_event_set_period()` and `loongson3_reset_counters()` must select the event bank via `mipsxx_pmu_write_control()` before `mipspmu.write_counter()`. [F46, F77, F128]
- On ARC, `arc_pmu_stop()` must write `BIT(idx)` to `ARC_REG_PCT_INT_ACT` before clearing `BIT(idx)` in `ARC_REG_PCT_INT_CTRL`, and select `idx` in `ARC_REG_PCT_INDEX` to write `0` to `ARC_REG_PCT_CONFIG`. `arc_pmu_read_counter()` must select `idx` in `ARC_REG_PCT_INDEX`, set `ARC_REG_PCT_CONTROL_SN` in `ARC_REG_PCT_CONTROL`, and read `ARC_REG_PCT_SNAPH`/`SNAPL` rather than `COUNTL`/`COUNTH`. [F113, F114]
- On C-SKY, 64-bit counter reads (`csky_pmu_read_cc()`) must loop `do { tmp = hi; lo = ...; hi = ...; } while (hi != tmp)` via `cprgr`, and `csky_perf_event_update()` must call `sign_extend64(..., csky_pmu.count_width - 1)` before subtracting `prev_raw_count`. On SH4A, `PPC_PMCAT` writes (`sh4a_pmu_enable()`) must mask `~PMCAT_EMU_CLR_MASK`. On Xtensa, `XTENSA_PMU_PMSTAT(i)` is write-1-to-clear: `xtensa_pmu_setup()`, `xtensa_pmu_stop()`, and `xtensa_pmu_irq_handler()` must write back `get_er(XTENSA_PMU_PMSTAT(i))` via `set_er()`, never `0`. [F61, F94, F119, F130]

## Synchronization
- `callchain_mutex` serializes `nr_callchain_events` in `get_callchain_buffers()`/`put_callchain_buffers()`; `perf_event_max_stack_handler()` must hold `callchain_mutex` and return `-EBUSY` if `nr_callchain_events != 0`. `alloc_callchain_buffers()` must allocate `entries` and all per-CPU `entries->cpu_entries[cpu]` before `rcu_assign_pointer(callchain_cpus_entries, entries)`, and `release_callchain_buffers()` must clear `callchain_cpus_entries` and free via `call_rcu(&entries->rcu_head, release_callchain_buffers_rcu)`. `get_callchain_entry()`/`get_perf_callchain()` callers must stay in RCU read-side or non-preemptible/NMI context while dereferencing the entry. [F16, F17, F131]
- Modifying `perf_event::sibling_list`, `perf_event_context::event_list`, or `struct perf_event_pmu_context` lists requires both `ctx->mutex` and `ctx->lock`; reading/iterating them (`for_each_sibling_event()`) requires `ctx->mutex`, `ctx->lock`, or local IRQs disabled. `__perf_sw_event_sched()` writes `this_cpu_ptr(&__perf_regs[0])` without recursion tracking and requires preemption disabled with no recursive scheduling. `perf_cgroup_from_task(task, ctx)` requires the cgroup CSS pinned and `ctx->lock` held when `ctx != NULL`. [F19, F138, F139]
- In `alpha_pmu_add()`, `loongarch_pmu_add()`, `mipspmu_add()`, and `sh_pmu_add()`, `perf_pmu_disable(event->pmu)` on entry must pair with `perf_pmu_enable(event->pmu)` on all exit paths, including `-EAGAIN`. PMI/NMI-reentrant update routines (`mipspmu_event_update()`, `loongarch_pmu_event_update()`, `sparc_perf_event_update()`, `alpha_perf_event_update()`) must update `hw_perf_event::prev_count` via `local64_cmpxchg()` before adding to `event->count`. [F13, F20]
- `hw_perf_event_destroy()` (and SPARC `perf_event_release_pmc()`) must use `atomic_dec_and_mutex_lock(&active_events, ...)` with `pmu_reserve_mutex`/`pmc_grab_mutex` (paired with `atomic_inc_not_zero(&active_events)`) and never run with IRQs disabled. On SPARC, `perf_event_grab_pmc()`/`perf_event_release_pmc()` serialize `0 <-> 1` transitions under `pmc_grab_mutex` to call `perf_stop_nmi_watchdog()`, snapshot `pcr_ops->read_pcr(i)` into `cpuc->pcr[i]`, and restart `start_nmi_watchdog` on last release. [F27, F126]
- In MIPS/LoongArch `__hw_perf_event_init()`, `PERF_TYPE_RAW` requires holding `raw_event_mutex` across `map_raw_event()` and `*_perf_event_encode(pev)` (unlocking on `IS_ERR(pev)`). Under `CONFIG_MIPS_PERF_SHARED_TC_COUNTERS`, `pause_local_counters()` must precede locking `pmuint_rwlock` in `mipspmu_disable()` and `mipsxx_pmu_handle_shared_irq()`, and `resume_local_counters()` must follow unlocking `pmuint_rwlock` in `mipspmu_enable()` and `mipsxx_pmu_handle_shared_irq()`. [F25, F26]

## Object Lifetimes
- `get_callchain_buffers()` increments `nr_callchain_events` under `callchain_mutex` before validating `event_max_stack` or calling `alloc_callchain_buffers()`; error paths must decrement `nr_callchain_events` before unlocking. On per-CPU allocation failure, `alloc_callchain_buffers()` must `kfree()` all allocated `entries->cpu_entries[cpu]` across possible CPUs and `kfree(entries)` without setting `callchain_cpus_entries`. [F1, F2]
- Inherited child events (`event->parent != NULL`) share their parent's `addr_filters` and `fasync`; callers must use `perf_event_addr_filters(event)` and `perf_event_fasync(event)`. `sparc_pmu_event_init()` must finish all validations before calling `perf_event_grab_pmc()` and setting `event->destroy = hw_perf_event_destroy`. SuperH `__hw_perf_event_init()` sets `event->destroy = hw_perf_event_destroy` right after incrementing `num_events`, and `sh_pmu_event_init()` must call `event->destroy(event)` if `__hw_perf_event_init()` fails. [F8, F9, F11]
- `arc_pmu_del()`, `loongarch_pmu_del()`, and `mipspmu_del()` must stop the event with `PERF_EF_UPDATE`, clear `act_counter[idx]`/`cpuc->events[idx]`, and clear `idx` in `used_mask`. SPARC `perf_callchain_user()` must save and restore `current_thread_info()->fault_address` and `get_thread_fault_code()` across `pagefault_disable()`/`pagefault_enable()`. [F12, F14]

## API Contracts
- `struct pmu` callbacks `add()`, `del()`, `start()`, and `stop()` run with local IRQs and PMU disabled (`start()`/`stop()` may be NMI and must not sleep); `addr_filters_validate()` runs in `ioctl()` process context unserialized. `->del()` must call `->stop(event, PERF_EF_UPDATE)`, and `->stop()` must check `PERF_HES_STOPPED` and `PERF_HES_UPTODATE` independently so an already-stopped event still updates its count on `PERF_EF_UPDATE`. `->commit_txn()` clears `txn_flags` and re-enables the PMU only on success; on error, `->cancel_txn()` does so after `->del()` rollback. [F7, F21, F51]
- PMUs without overflow IRQs must set `PERF_PMU_CAP_NO_INTERRUPT` before `perf_pmu_register()`. `arc_pmu_device_probe()` must either request the per-CPU IRQ and run `arc_cpu_pmu_irq_init()` via `on_each_cpu()` (clearing `ARC_REG_PCT_INT_ACT`), or set `PERF_PMU_CAP_NO_INTERRUPT`. `for_each_sibling_event(sibling, event)` only iterates `event->sibling_list` when `event->group_leader == event` and skips the leader; group validators (`collect_events()`, `validate_group()`) must pass `event->group_leader` and handle the leader and unattached candidate event separately. [F85, F116, F150]
- `perf_sample_data_init()` only sets `data->sample_flags` (`PERF_SAMPLE_PERIOD`, plus `PERF_SAMPLE_ADDR` if `addr != 0`), `data->period`, and `data->dyn_size = 0`; reading optional fields requires checking `data->sample_flags`. In `struct perf_raw_frag` chains passed to `perf_sample_save_raw_data()`, non-terminal fragments need `frag->next >= sizeof(u64)` and the final fragment needs `frag->pad < sizeof(u64)` for `perf_raw_frag_last()`. [F39, F66]
- `perf_arch_fetch_caller_regs(regs, __ip)` must initialize mode fields (`psw.mask = 0` on s390, `cs = __KERNEL_CS` on x86, `result = 0` on PowerPC) so `user_mode(regs)` is false. On x86, `intel_fixed_bits_by_idx(_idx, _bits)` takes a 0-based fixed offset (`idx - INTEL_PMC_IDX_FIXED`), whereas `is_metric_idx(idx)`, `is_topdown_idx(idx)`, and `INTEL_PMC_OTHER_TOPDOWN_BITS(bit)` take the global PMC index (`idx >= INTEL_PMC_IDX_FIXED`). [F31, F33]

## Error Handling
- `struct pmu::event_init` must return `-ENOENT` when `event` does not target that PMU (e.g. unhandled `event->attr.type`), `0` on success, or another negative errno when invalid/unsupported; returning `-EINVAL`/`-EOPNOTSUPP` for an unhandled type aborts PMU iteration in `perf_init_event()`. In `get_callchain_entry(int *rctx)`, if `rcu_dereference(callchain_cpus_entries)` is `NULL` after `get_recursion_context()` succeeds (`*rctx != -1`), `put_recursion_context()` must be called before returning `NULL`; non-`NULL` callers must call `put_callchain_entry(rctx)`. In `csky_pmu_device_probe()`, `cpuhp_setup_state()` or `perf_pmu_register()` failure must call `csky_pmu_free_irq()` and `free_percpu(csky_pmu.hw_events)`. [F28, F35, F120]

## External Contracts
- In `struct perf_event_mmap_page`, reading `data_head`/`aux_head` requires `smp_rmb()` before reading data, and updating `data_tail`/`aux_tail` (`PROT_WRITE`) requires `smp_mb()` between reading data and storing the tail. `index` (from `pmu::event_idx`) is 1-based (`0` = inactive, `hwc->idx + 1` = active). UAPI 64-bit bitfield unions (`union perf_mem_data_src`, `union perf_sample_weight`) must provide reversed-order `#if defined(__LITTLE_ENDIAN_BITFIELD)` and `#elif defined(__BIG_ENDIAN_BITFIELD)` structs. [F23, F48, F69]

## Known Pitfalls
- In `get_callchain_entry()`, `entries->cpu_entries[cpu]` must be cast to `void *` before adding `*rctx * perf_callchain_entry__sizeof()`. On 64-bit SPARC, `perf_callchain_kernel()`, `perf_callchain_user_64()`, and the 64-bit path of `perf_callchain_user_32()` must add `STACK_BIAS` (2047) to every 64-bit FP (`UREG_I6`/`UREG_FP`, `sf.fp`) before validating/dereferencing `sparc_stackf`. On LoongArch, `perf_callchain_user()` and `user_backtrace()` must verify `fp` is non-zero and 16-byte aligned (`!(fp & 0xf)`), `access_ok()` on `fp - sizeof(struct stack_frame)`, and `(unsigned long)user_frame_tail < buftail.fp`. [F70, F80, F103]
- In Alpha `ev67_check_constraints()`, when assigning `EV67_INSTRUCTIONS` to PMC 0 (`idx0 = (evtype[0] == EV67_INSTRUCTIONS) ? 0 : 1`), the other event is at `evtype[idx0 ^ 1]`, whereas for PMC 1 events (`EV67_MBOXREPLAY`, `EV67_BCACHEMISS`) `idx0` already indexes `evtype[idx0]`. In `sparc_check_constraints()`, when event 0 is unconstrained (`PIC_UPPER | PIC_LOWER`) and event 1 is restricted, `idx0` must be `1` when `(msk1 & PIC_UPPER)` so event 0 takes `PIC_LOWER` (1) and event 1 gets `idx0 ^ 1` (`PIC_UPPER`, 0). [F89, F90]
- LoongArch `general_event_map` and `cache_event_map` tables must start with `PERF_MAP_ALL_UNSUPPORTED`/`PERF_CACHE_MAP_ALL_UNSUPPORTED` (`0xffffffff`) because `0x00` is `PERF_COUNT_HW_CPU_CYCLES`. Xtensa `xtensa_pmu_event_init()` and `xtensa_pmu_cache_event()` must bounds-check against `ARRAY_SIZE(xtensa_hw_ctl)`/`ARRAY_SIZE(xtensa_cache_ctl)` (not `PERF_COUNT_HW*_MAX`) and reject `0`. On SuperH and Xtensa, `event->hw.idx` must stay non-negative in `[0, MAX_HWEVENTS)`/`[0, XCHAL_NUM_PERF_COUNTERS)` across init and del because `*_pmu_add()` passes it directly to `__test_and_set_bit(idx, used_mask)`. [F71, F76, F109]
- On MIPS, `CNTR_BIT_MASK(n)` must handle `(n) == 64` (`~0ULL`); `mipsxx_pmu_read_counter()` must cast 32-bit CP0 reads (`read_c0_perfcntr0()`..`3()`) to `(u32)` before returning `u64`, while 64-bit accessors must mask with `CNTR_BIT_MASK(counter_bits)`. On ARC, `arc_pmu_raw_alloc()` must use `__GFP_ZERO` (sizing `attrs` to `n_events + 1`), and `arc_pmu_device_probe()` must convert `ARC_REG_CC_NAME0`/`1` via `le32_to_cpu()` and NUL-terminate `cc_name.str[ARCPMU_EVENT_NAME_LEN - 1]`. On C-SKY, LoongArch, and MIPS, PMU IRQ handlers call `irq_work_run()` directly, requiring local IRQs disabled and non-NMI IRQ delivery. [F74, F92, F107, F127, F143]
