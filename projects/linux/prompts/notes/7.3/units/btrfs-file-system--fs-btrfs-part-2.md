# BTRFS FILE SYSTEM — fs/btrfs (part 2)

Implements Btrfs copy-on-write B-tree operations, transparent compression/decompression workspace and bio management, file and B-tree defragmentation, delalloc space reservation, and delayed metadata updates (delayed inode items and delayed extent reference tracking).

## Architecture & Data Flow

- `btrfs_path` arrays `nodes`, `slots`, and `locks` are indexed by level `0 .. BTRFS_MAX_LEVEL - 1` (0 is leaf); guard `level + 1` parent access with `level < BTRFS_MAX_LEVEL - 1`. Whenever slot 0's key changes (`btrfs_set_item_key_safe()`, `btrfs_truncate_item()`, `setup_items_for_insert()`, `btrfs_del_ptr()`, `btrfs_del_items()`, `__push_leaf_left()`, `split_leaf()`), call `fixup_low_keys()` before `btrfs_unlock_up_safe()`. [F71, F92]
- Leaf item data grows downward from `BTRFS_LEAF_DATA_SIZE(fs_info)` toward item headers: for `start <= end`, item `start` is at a higher offset than `end`, and their contiguous data range starts at `btrfs_item_offset(leaf, end)` with length `btrfs_item_data_end(leaf, start) - btrfs_item_offset(leaf, end)`. [F84]
- Index `btrfs_delayed_ref_root::head_refs` and `dirty_extents` xarrays by `(bytenr >> fs_info->sectorsize_bits)`, never raw `bytenr`, to avoid 32-bit `unsigned long` truncation. [F81]
- `btrfs_delayed_ref_node`'s union is discriminated by `node->type` (`BTRFS_EXTENT_DATA_REF_KEY` / `BTRFS_SHARED_DATA_REF_KEY` for `data_ref`, else `tree_ref`), whereas `btrfs_ref` uses `ref->type` (`BTRFS_REF_DATA` vs `BTRFS_REF_METADATA`). Every node in `head->ref_tree` must be linked on `head->ref_add_list` via `add_list` iff `action == BTRFS_ADD_DELAYED_REF`, including when `insert_delayed_ref()` flips `exist->action` or `drop_delayed_ref()` removes it. [F53, F62]
- For data ref heads (`is_data`), adjust `delayed_refs->pending_csums` and csum leaf reservations (`trans->delayed_ref_csum_deletions` or `btrfs_delayed_refs_rsv_release()`) in lockstep whenever a head is inserted with `ref_mod < 0` or `update_existing_head_ref()` flips `total_ref_mod` across zero. `btrfs_update_delayed_refs_rsv()` must zero `trans->delayed_ref_updates` and `trans->delayed_ref_csum_deletions` after adding their size to `fs_info->delayed_refs_rsv`. [F63, F65]
- Delalloc and delayed-ref metadata calculations in `delalloc-space.c` and `delayed-ref.c` must use `count_max_extents()` and `btrfs_csum_bytes_to_leaves()` (`div_u64()` / `DIV_ROUND_UP_ULL()`), never truncating division. [F129]
- Delayed dir-index items track leaf reservations in `node->index_item_leaves` and `curr_index_batch_size` (`item->bytes_reserved == 0`); `btrfs_insert_delayed_item()` must not decrement `index_item_leaves` on partial batches when `continuous_keys_only` is set (`BTRFS_FS_LOG_RECOVERING`), and must check post-loop `next` (`NULL` iff all `ins_root` items were batched) to release `index_item_leaves` via `btrfs_delayed_item_release_leaves()` before `list_for_each_entry_safe()` reuses `next`. [F68, F115]
- `btrfs_insert_delayed_dir_index()` stores the `name_len`-byte name at `(char *)(dir_item + 1)` without a NUL terminator; bound all reads/formats by `name_len` (`%.*s` or `btrfs_stack_dir_name_len`). In-memory `root->root_item`, `delayed_node->inode_item`, and `delayed_item->data`'s `btrfs_dir_item` are little-endian and require `btrfs_stack_*` / `btrfs_root_*` or `cpu_to_le*` / `le*_to_cpu` accessors. [F100, F142]
- In `could_end_wait()`, check `val < seq || val >= seq + BTRFS_DELAYED_BATCH` on `delayed_root->items_seq` so signed 32-bit `atomic_t` wrap-around does not stall `btrfs_balance_delayed_items()`. [F130]
- In `struct compressed_bio`, `bbio` must be the final member, and the union holds `orig_bbio` only on compressed reads and `write_end_work` only on compressed writes. `enum btrfs_compression_type` changes must update `btrfs_compress_types[]`, `btrfs_compress_levels[]`, and all workspace/compression dispatchers in lockstep without disturbing slot 0's heuristic workspace manager. `heuristic_collect_sample()` must clamp `(end - start)` to `BTRFS_MAX_UNCOMPRESSED` and stop when `start > end - SAMPLING_READ_SIZE`. [F56, F80, F98]
- `radix_sort()` must align `bitlen` to `RADIX_BASE * 2`, require `array_buf` to hold `num` `bucket_item`s, and run two `RADIX_BASE` passes per iteration (`array` to `array_buf`, then back to `array`). [F110, F134]

## Synchronization

- Replacements of `root->node` (`btrfs_force_cow_block()`, `balance_level()`, `insert_new_root()`) must initialize `cow`, log the root mod, and increment `cow->refs` before `rcu_assign_pointer(root->node, cow)` and dropping `buf`'s ref; `btrfs_root_node()` must read `root->node` under `rcu_read_lock()`, call `refcount_inc_not_zero(&eb->refs)`, and `synchronize_rcu()` before retrying. `should_cow_block()` needs `smp_mb__before_atomic()` before testing `BTRFS_ROOT_FORCE_COW`. [F21, F22, F156]
- In `btrfs_search_slot()` and `setup_nodes_for_search()`, if `level` needs a write lock at `level` or `level + 1` and `write_lock_level` is lower, raise `write_lock_level`, call `btrfs_release_path(p)`, and restart from root. When `!p->skip_locking`, call `btrfs_maybe_reset_lockdep_class(root, eb)` before locking a child buffer; if `read_block_for_search()` reads from disk with `!p->skip_locking`, unlock above `parent_level`, read-lock `tmp`, call `btrfs_release_path(p)` before `btrfs_read_extent_buffer()`, and return `-EAGAIN`. [F23, F25, F147]
- When `path->need_commit_sem` is set (requiring `search_commit_root == 1` and `skip_locking == 1`), `btrfs_search_slot()` and `btrfs_next_old_leaf()` must call `finish_need_commit_sem_search(path)` before `up_read(&fs_info->commit_root_sem)`. `btrfs_next_old_leaf()` must clear `path->need_commit_sem` before `btrfs_search_slot()` while holding `commit_root_sem` and restore it to 1 before `finish_need_commit_sem_search(path)`. [F74, F155]
- Release any locked `btrfs_path` (`btrfs_release_path()` / `btrfs_free_path()`) before `btrfs_release_delayed_node()` or `btrfs_release_prepared_delayed_node()` because `delayed_node->mutex` ranks outside path locks. [F29]
- When `btrfs_readdir_get_delayed_items()` returns `true`, it upgraded `BTRFS_ILOCK_SHARED` to exclusive for `item->readdir_list`, and callers must call `btrfs_readdir_put_delayed_items()` to drop refs and `downgrade_write(&inode->vfs_inode.i_rwsem)`. `item->logged` and `item->log_list` require `node->mutex`, and `btrfs_log_get_delayed_items()` must check `!item->logged && list_empty(&item->log_list)` under `node->mutex`. [F13, F32]
- `add_delayed_ref()` must `xa_reserve()` in `head_refs` (and `dirty_extents` if qgroups are active) with `GFP_NOFS` before locking `delayed_refs->lock`, and hold `delayed_refs->lock` continuously across `add_delayed_ref_head()` and `insert_delayed_ref()`. [F36]
- Under `delayed_refs->lock`, `num_heads` counts `head_refs` with `tracked == true` and `num_heads_ready` counts those with `!processing`. `btrfs_select_ref_head()` sets `head->processing = true`, decrements `num_heads_ready`, and calls `btrfs_delayed_ref_lock()` (which, on trylock failure, pins `head->refs` before dropping `delayed_refs->lock` to lock `head->mutex`, then rechecks `head->tracked` after relocking `delayed_refs->lock` and unlocks `head->mutex` if `false`). Release `head` via `btrfs_unselect_ref_head()` or `btrfs_delete_ref_head()` (holding `delayed_refs->lock` and `head->lock`, decrementing `num_heads_ready` only if `!head->processing`); `btrfs_select_delayed_ref()` requires `head->mutex` and `head->lock`. [F17, F34, F35, F64]
- After `defrag_one_range()` locks/waits on folios and locks the `io_tree` extent, it must re-run `defrag_collect_targets()` with `locked = true` and skip `EXTENT_DELALLOC` ranges before `defrag_one_locked_target()`. [F39]
- In `btrfs_delalloc_reserve_metadata()`, use `BTRFS_RESERVE_NO_FLUSH` if `noflush` or `btrfs_is_free_space_inode(inode)`, and `BTRFS_RESERVE_FLUSH_LIMIT` if `current->journal_info` is set. In `btrfs_compr_pool_count()`, read `compr_pool.count` and `compr_pool.thresh` via `READ_ONCE()` into a signed local before returning `ret > 0 ? ret : 0`. [F152, F163]

## Object Lifetimes

- Call `btrfs_clear_buffer_dirty()` before freeing a dirtied tree block with `btrfs_free_tree_block()` (`insert_new_root()`, `balance_level()`, `btrfs_del_items()`). In `btrfs_del_leaf()`, after `btrfs_del_ptr()` and `btrfs_unlock_up_safe(path, 0)`, increment `leaf->refs` before `btrfs_free_tree_block()` and pair with `free_extent_buffer_stale(leaf)` so `path->nodes[0]` stays valid until `btrfs_release_path()`. [F1, F5]
- `btrfs_get_workspace()` increments `wsm->total_ws` before `alloc_workspace()` under `memalloc_nofs_save()` / `memalloc_nofs_restore()`, and on failure decrements `wsm->total_ws`, wakes `wsm->ws_wait`, logs a `__ratelimit()` warning if `atomic_read(total_ws) == 0`, and retries; `btrfs_put_workspace()` returns `ws` to `wsm->idle_ws` (incrementing `wsm->free_ws`) or frees it and decrements `wsm->total_ws`. [F8, F165]
- When `btrfs_get_delayed_node()` finds an uncached node in `root->delayed_nodes`, use `refcount_inc_not_zero(&node->refs)` under `xa_lock(&root->delayed_nodes)` and take two refs (cache + caller). Read-only helpers (`btrfs_readdir_get_delayed_items()`, `btrfs_log_get_delayed_items()`, `btrfs_log_put_delayed_items()`) must release `node` via `btrfs_delayed_node_ref_tracker_free()` and `refcount_dec(&node->refs)`, not `btrfs_release_delayed_node()`. [F12, F14]
- `add_delayed_ref_head()` frees `head_ref` if already in `head_refs` and frees `qrecord` only when `btrfs_qgroup_trace_extent_nolock() > 0` (leaving `qrecord` for `add_delayed_ref()` to `kfree()` on `< 0`), while `insert_delayed_ref()` returns `true` when merged so `add_delayed_ref()` frees `node` after tracing. [F16]
- Whenever `defrag_prepare_one_folio()` unlocks a folio for `btrfs_start_ordered_extent()` or `btrfs_read_folio()`, after re-locking it must verify `folio->mapping == mapping && folio->private`, or else unlock, `folio_put()`, and retry. [F18]

## API Contracts

- On success, `btrfs_force_cow_block()` (and `btrfs_cow_block()` when it COWs) consumes `buf` via `free_extent_buffer_stale(buf)`, unlocks `buf` if `*cow_ret == buf`, and returns the new write-locked buffer in `*cow_ret`; on error, `buf` stays locked and referenced by the caller. [F2]
- `btrfs_search_slot()` and `btrfs_search_old_slot()` require `p->nodes[0] == NULL`, and `btrfs_search_slot()` calls `btrfs_release_path(p)` on `< 0` error unless `p->skip_release_on_error` is set. In `btrfs_search_slot()`, `ins_len != 0` requires `cow != 0`; `p->search_commit_root` requires `p->skip_locking = 1`; `p->nowait` requires `!cow && !time_seq` and non-blocking trylocks/reads returning `-EAGAIN`. When `ins_len > 0`, include `sizeof(struct btrfs_item)` unless `p->search_for_extension` is set, whereas `btrfs_item_batch::total_data_size` must sum `data_sizes[0 .. nr - 1]` excluding `sizeof(struct btrfs_item)`. [F3, F45, F46, F138, F139, F154]
- `memmove_leaf_data()` and `copy_leaf_data()` take offsets relative to `btrfs_item_nr_offset(leaf, 0)` (`btrfs_item_offset`, `leaf_data_end`), whereas `read_extent_buffer()`, `write_extent_buffer()`, `memcpy_extent_buffer()`, and `memmove_extent_buffer()` take full extent-buffer offsets (`btrfs_item_ptr_offset`). `memmove_leaf_items()` and `copy_leaf_items()` take slot indices and item counts, whereas node pointer moves with `btrfs_node_key_ptr_offset` must scale by `sizeof(struct btrfs_key_ptr)`. [F135, F136]
- `btrfs_add_delayed_tree_ref()` and `btrfs_add_delayed_extent_op()` consume `extent_op` only on success; on `< 0` error, call `btrfs_free_delayed_extent_op(extent_op)`. Initialize `generic_ref->ref_root` before calling `btrfs_init_tree_ref()` or `btrfs_init_data_ref()`. [F15, F50]
- Delayed item/inode flushers (`__btrfs_run_delayed_items()`, `btrfs_commit_inode_delayed_items()`, `btrfs_commit_inode_delayed_inode()`, `btrfs_async_run_delayed_root()`) must temporarily switch `trans->block_rsv` to `&fs_info->delayed_block_rsv` and restore it on exit. [F69]
- In `btrfs_delalloc_release_metadata()`, `btrfs_delalloc_release_space()`, and `btrfs_delayed_inode_release_metadata()`, pass `qgroup_free = true` on error/cancellation rollback and `false` on normal completion. `btrfs_free_reserved_data_space_noquota()` requires `len` aligned to `fs_info->sectorsize`. [F58, F99]
- Pass the exact same `type` to `get_workspace()` / `btrfs_get_workspace()`, `compression_compress_pages()`, `compression_decompress()`, and `put_workspace()` / `btrfs_put_workspace()`. Validate `type < BTRFS_NR_COMPRESS_TYPES` before `btrfs_compress_level_valid()` or `btrfs_compress_set_level()`; `btrfs_decompress()` requires `dest_pgoff + destlen <= folio_size(dest_folio)` and `destlen <= fs_info->sectorsize`. [F95, F96, F132]

## Error Handling

- `btrfs_insert_empty_items()` and `btrfs_insert_empty_item()` return `-EEXIST` when `btrfs_search_slot()` returns `0` without releasing `path`, leaving `path` write-locked at the colliding key on `-EEXIST` while other `< 0` errors have already released `path`. [F47]
- `btrfs_select_ref_head()` returns a locked head, `NULL`, or `ERR_PTR(-EAGAIN)`; `defrag_get_extent()` returns an `extent_map *`, `NULL`, or `ERR_PTR` (whereas `defrag_lookup_extent()` converts `IS_ERR(em)` to `NULL`). Callers must check both `!ptr` and `IS_ERR(ptr)`. [F49, F59]
- `btrfs_check_data_free_space()` and `btrfs_delalloc_reserve_space()` normalize positive qgroup returns to `0`, and on error call `extent_changeset_free(*reserved)` and set `*reserved = NULL`. [F57]

## External Contracts

- `btrfs_defrag_file()` must reject `range->start >= isize`, compression types `>= BTRFS_NR_COMPRESS_TYPES`, and `!btrfs_compress_level_valid()` with `-EINVAL`, and check `range->start + range->len > range->start` before clamping `last_byte` to `isize`. Per cluster under `btrfs_inode_lock(inode, 0)`, recheck `IS_SWAPFILE(&inode->vfs_inode)` (`-ETXTBSY`) and `SB_ACTIVE`, reset `inode->defrag_compress = BTRFS_COMPRESS_NONE` before returning, update `cur = max(cluster_end + 1, last_scanned)` before breaking on `defrag_one_cluster() > 0`, set `range->start = cur` on exit, and return `sectors_defragged` whenever `sectors_defragged > 0`. [F60, F77, F112, F170, F171]

## Known Pitfalls

- In `btrfs_search_slot()`, reset `prev_cmp = -1` at `again:` because `search_for_key_slot()` forces `*slot = 0` when `prev_cmp == 0`. In `btrfs_prev_leaf()`, when `btrfs_search_slot() > 0`, if `path->slots[0] < nritems` and the key at `path->slots[0]` equals `orig_key`, decrement `path->slots[0]` (or return `1` if `0`), and return `0` for `ret <= 0` when comparing slot 0's `found_key` against `key`. [F102, F106]
- In `split_item()`, copy the original item into a buffer before adjusting offsets, as `orig_slot` moves to `orig_offset + item_size - split_offset` while `slot` is written at `orig_offset`. In `__push_leaf_right()`, the reverse loop over `u32 i` down to `nr` must check `if (i == 0) break;` because `nr == 0` when `empty` is true. [F72, F87]
- Cast `btrfs_item_ptr()` to `unsigned long` or `char *` before byte-offset arithmetic; when `btrfs_truncate_item()` truncates from the front (`!from_end`) of an inline `BTRFS_EXTENT_DATA_KEY` after adding `size_diff` to item offsets, shift the `BTRFS_FILE_EXTENT_INLINE_DATA_START` header forward before `memmove_leaf_data()`, advancing key offset by `size_diff`, and calling `fixup_low_keys()` if `slot == 0`. [F73, F137]
- In `btrfs_merge_delayed_refs()`, whenever `merge_ref()` erases the outer loop's `ref` from `head->ref_tree` (`swap(ref, next)` or `ref->ref_mod == 0`), it must return `true` so the outer loop restarts at `again:` instead of calling `rb_next(node)`. [F116]
- In `defrag_collect_targets()`, reset `last_is_target = false` per iteration and set `true` at `add:` so loop exit sets `*last_scanned_ret = max(start + len, *last_scanned_ret)` when `last_is_target` is true. In `btrfs_run_defrag_inodes()` and `btrfs_select_ref_head()`, if a lookup from a non-zero cursor finds nothing, reset the cursor to `0` and retry once. [F111, F118]
