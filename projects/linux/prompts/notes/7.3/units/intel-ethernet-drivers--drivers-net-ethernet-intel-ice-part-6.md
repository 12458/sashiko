# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ice (part 6)

This unit implements `ice_main.c` (PCI probe/remove, PM, service tasks, reset/rebuild, XDP/AF_XDP, `net_device_ops`), `ice_nvm.c` (NVM shadow RAM/flash access), and `ice_parser.c` (DDP packet parser simulation).

## Architecture & Data Flow
- Safe Mode: if `ice_init_ddp_config()` fails or leaves `ice_is_safe_mode(pf)` true, `ice_init_dev()` must call `ice_set_safe_mode_caps(hw)` before `ice_init_pf(pf)`, `ice_init_features()` and `ice_deinit_features()` must return immediately at entry, `ice_set_ops()` must bind `ice_netdev_safe_mode_ops` (with `ice_xdp_safe_mode` and no `udp_tunnel_nic_info`, `xdp_metadata_ops`, or `xdp_features`), `ice_set_netdev_features()` must restrict `features`/`hw_features` to `NETIF_F_SG | NETIF_F_HIGHDMA`, and `netif_is_ice()` must check both `&ice_netdev_ops` and `&ice_netdev_safe_mode_ops`. [F204, F217, F294, F326]
- Reset preparation and subtask: in `ice_reset_subtask()`, pending reset bits (`ICE_CORER_RECV`, `ICE_GLOBR_RECV`, `ICE_EMPR_RECV` and `ICE_PFR_REQ`, `ICE_CORER_REQ`, `ICE_GLOBR_REQ`) must be evaluated in ascending scope order via sequential `if` statements (not `else if`); in `ice_prepare_for_reset()`, if `ice_is_eswitch_mode_switchdev(pf)` is true, `ice_eswitch_br_fdb_flush()` must run under `rtnl_lock()` before `ice_clear_hw_tbls(hw)`, and if `ICE_FLAG_TC_MQPRIO` is set with `reset_type != ICE_RESET_PFR`, ADQ channels must be removed via `ice_remove_q_channels(vsi, true)` and `old_ena_tc`, `all_enatc`, `old_numtc`, `all_numtc`, `req_txq`, `req_rxq`, `ICE_FLAG_TC_MQPRIO`, and `mqprio_qopt` cleared. [F218, F219, F251]
- Rebuild and stats across reset: in `ice_rebuild()`, `pf->fw_emp_reset_disabled` must be cleared on `ICE_RESET_EMPR`, and if `ICE_FLAG_PTP_SUPPORTED` is set, `ice_ptp_rebuild()` must run before `ice_vsi_rebuild_by_type(pf, ICE_VSI_PF)` and `ice_ptp_restore_timestamp_mode(pf)` after; in `ice_req_irq_msix_misc()`, when `ice_is_reset_in_progress(pf->state)` is true, it must `goto skip_req_irq` (skipping `oicr_irq`/`ll_ts_irq` allocation) while still writing hardware OICR/ctrlq interrupt registers; and in `ice_update_pf_stats()`, `pf->stat_prev_loaded` must be cleared when `ice_is_reset_in_progress(pf->state)` is true, with `ice_update_vsi_ring_stats()` only adding `vsi_stats - stats_prev` deltas when `pf->stat_prev_loaded` is true. [F226, F228, F229, F230]
- ADQ channel cleanup: `ice_remove_q_channels()` must clear `ch` pointers on `vsi->tx_rings[ch->base_q + i]`, `vsi->rx_rings[ch->base_q + i]`, and their `q_vector`s before freeing `ch`, null out `vsi->tc_map_vsi[i]`, and zero `all_enatc`/`all_numtc`; when `ice_rem_all_chnl_fltrs()` removes a rule (`ice_rem_adv_rule_by_id` == 0) with `fltr->dest_vsi->type == ICE_VSI_CHNL`, it must decrement `dest_vsi->num_chnl_fltr` and (if `ICE_TC_FLWR_FIELD_DST_MAC` or `ICE_TC_FLWR_FIELD_ENC_DST_MAC` is set) `pf->num_dmac_chnl_fltrs`. [F220, F221]
- `ice_map_xdp_rings()` must compute `xdp_rings_per_v = DIV_ROUND_UP(xdp_rings_rem, vsi->num_q_vectors - v_idx)` (decrementing `xdp_rings_rem` each loop) and prepend XDP rings to `q_vector->tx.tx_ring` so `ice_unmap_xdp_rings()` can restore `q_vector->tx.tx_ring` to the first non-XDP ring (`!ring->tx_buf || !ice_ring_is_xdp(ring)`). [F225, F272]
- VLAN, MAC, and feature updates: `ice_set_vlan_filtering_features()` must only call `vlan_ops->ena_rx_filtering` when CTAG/STAG filtering is set and `!ice_is_eswitch_mode_switchdev(vsi->back)`; when `vsi->current_netdev_flags & IFF_ALLMULTI` is set, `ice_vlan_rx_add_vid()` must switch VLAN 0 from `ICE_MCAST_PROMISC_BITS` to `ICE_MCAST_VLAN_PROMISC_BITS` on the first non-zero VLAN (`ice_vsi_num_non_zero_vlans(vsi) == 1`) and `ice_vlan_rx_kill_vid()` must reverse this when `!ice_vsi_has_non_zero_vlans(vsi)`; `ice_add_mac_to_unsync_list()` must return 0 when `ether_addr_equal(addr, netdev->dev_addr)`; and `ice_set_features()` must test each flag in `changed` with independent `if` statements, not `else if`. [F216, F227, F250, F322]
- Sideband queue: `ice_clean_sbq_subtask()` must check `ice_is_generic_mac(&pf->hw)` and clear `ICE_SIDEBANDQ_EVENT_PENDING` without cleaning `ICE_CTL_Q_SB` on non-generic MACs, and `ice_ena_ctrlq_interrupts()` must not enable `PFINT_SB_CTL` when `hw->dev_caps.ts_dev_info.ts_ll_int_read` is true. [F297]
- NVM layout: `ice_read_sr_pointer()` must mask off `ICE_SR_NVM_PTR_4KB_UNITS` before multiplying by 4096 when set (or multiply by 2 when clear); `ice_get_nvm_css_hdr_len()` computes `(hdr_len_dword * 2) + ICE_NVM_AUTH_HEADER_LEN` words and `ice_read_nvm_sr_copy()` must `roundup(..., 32)` before adding to `offset`; and `ice_get_orom_civd_data()` must scan 512-byte-aligned `struct ice_orom_civd_info` blocks within `orom_size`, verifying both `"$CIV"` and a 0 byte-sum across `sizeof(struct ice_orom_civd_info)`. [F244, F266, F267]
- DDP parser logic and layouts: `ice_parser_dvm_set()` must update both `ICE_LBL_BST_TYPE_DVM` (`on`) and `ICE_LBL_BST_TYPE_SVM` (`!on`) in `bst_tcam_table`, setting both `key[ICE_BT_VM_OFF]` and `key_inv[ICE_BT_VM_OFF]`; `ice_ternary_match_byte()` must check don't-care (`bit_key != 0 && bit_key_inv != 0`) before mismatch; `ice_nearest_proto_id()` must skip `offset < rslt->po[i].offset` and reject `dist % 2 != 0`; `ice_bst_tcam_match()` pattern buffers (e.g. `bst_key`) must be `>= ICE_BST_TCAM_KEY_SIZE` (20) bytes; `ice_pg_cam_key::val` must match `ice_pg_nm_cam_key::val` with `next_proto` last and `__ice_pg_nm_cam_match()` must use `sizeof(item->key.val)`; `struct ice_lbl_item` software fields (`type`) must follow `idx`/`label` with `ice_parse_lbl_item()` copying only `idx`/`label`; and `struct ice_ptype_mk_tcam_item` must stay `__packed` and 24 bytes (`ICE_SID_RXPARSER_MARKER_TYPE_ENTRY_SIZE`). [F232, F249, F274, F275, F276, F277, F278]

## Synchronization
- `ice_load()` and `ice_unload()` require `devl_lock(priv_to_devlink(pf))`, and `ice_unload()` (plus `ice_load()`'s error path) must unwind in exact reverse order: RDMA, features, TC indirect block, netdev registration, devlink PF port, and netdev allocation. [F171]
- Service task and ctrlq: `ice_service_task_complete()` must run `smp_mb__before_atomic()` before `clear_bit(ICE_SERVICE_SCHED, pf->state)` on every exit of `ice_service_task()` and `ice_service_task_recovery_mode()`. In `ice_clean_adminq_subtask()`, `ice_clean_mailboxq_subtask()`, and `ice_clean_sbq_subtask()`, `ICE_*Q_EVENT_PENDING` must stay set when `__ice_clean_ctrlq()` returns non-zero, and when cleared, `ice_ctrlq_pending()` must be re-checked. [F183, F261]
- Filter sync: `ice_set_rx_mode()` runs in atomic context and must only set `ICE_VSI_UMAC_FLTR_CHANGED`, `ICE_VSI_MMAC_FLTR_CHANGED`, and `ICE_FLAG_FLTR_SYNC` and call `ice_service_task_schedule()`. `ice_vsi_sync_fltr()`, `ice_vlan_rx_add_vid()`, and `ice_vlan_rx_kill_vid()` must acquire `ICE_CFG_BUSY` in `vsi->state` via `test_and_set_bit()` and clear it on exit; in `ice_vsi_sync_fltr()`, `netif_addr_lock_bh(netdev)` must only wrap `__dev_uc_sync()`/`__dev_mc_sync()` and be dropped before `ice_fltr_remove_mac_list()` or `ice_fltr_add_mac_list()`. [F186, F187, F307]
- XDP locking: `ice_xdp()` must hold `vsi->xdp_state_lock` across `ice_xdp_setup_prog()` and `ice_xsk_pool_setup()`. `ice_vsi_assign_bpf_prog()` must `xchg(&vsi->xdp_prog, prog)`, `WRITE_ONCE(vsi->rx_rings[i]->xdp_prog, vsi->xdp_prog)`, and `bpf_prog_put()` any old prog, and in `ice_prepare_xdp_rings()` must only be called when `!ice_is_xdp_ena_vsi(vsi)`. If `ice_vsi_determine_xdp_res()` allocates `vsi->num_xdp_txq < num_possible_cpus()`, it must `static_branch_inc(&ice_xdp_locking_key)` (decremented in `ice_destroy_xdp_rings()`). [F188, F192, F223, F324]
- PTP, MQPRIO, AdminQ waiters, and NVM locks: `ice_ll_ts_intr()` must hold `pf->ptp.port.tx.lock` (`spin_lock_irqsave`) and verify `tx->init` before touching `tx->in_use` or calling timestamp helpers; `ice_setup_tc()` (`TC_SETUP_QDISC_MQPRIO`) when `cdev->adev` is non-NULL must lock `pf->adev_mutex`, `device_lock(&cdev->adev->dev)`, and `pf->tc_mutex` in that order; `pf->aq_wait_list` tasks must be registered via `ice_aq_prep_for_event()` before the AQ command and only unlinked (`hlist_del`) in `ice_aq_wait_for_event()` under `pf->aq_wait_lock` (while `ice_aq_check_events()` only copies `msg_buf` if `task_ev->msg_buf && task_ev->buf_len >= event->buf_len`); and when `!hw->flash.blank_nvm_mode`, `ice_read_flash_module()`, `ice_read_sr_word()`, `ice_discover_flash_size()`, and `ice_nvm_validate_checksum()` must bracket AQ commands with `ice_acquire_nvm()` / `ice_release_nvm()`. [F179, F200, F201, F211, F247, F256]

## Object Lifetimes
- Probe, remove, and devlink: in `ice_probe()`, under `is_kdump_kernel()`, save PCI state, run `pci_clear_master()` and `pcie_flr()`, and restore state before `pcim_enable_device()`; set `ICE_DOWN` and `ICE_SERVICE_DIS` in `pf->state` before HW/IRQ init; and if `ice_is_recovery_mode(&pf->hw)` is true, `ice_remove()` must stop the service task, call `ice_deinit_devlink(pf)`, and return early. `ice_init_devlink()` must call `ice_devlink_register()` before `ice_health_init()` (reversed in `ice_deinit_devlink()`), and `ice_init_supported_rxdids()` must run after `ice_load_pkg()` and always include `BIT(ICE_RXDID_LEGACY_1)`. [F172, F195, F286, F295, F299]
- Service task and IRQs: `ice_service_task_stop()` must set `ICE_SERVICE_DIS` before `timer_delete_sync(&pf->serv_tmr)` and `cancel_work_sync(&pf->serv_task)`, then clear `ICE_SERVICE_SCHED`. `ice_ena_misc_vector()` must zero `PFINT_OICR_ENA`, read `PFINT_OICR`, and set `GL_MDCK_TX_TDPU_RCU_ANTISPOOF_ITR_DIS_M` before enabling `PFINT_OICR_ENA`; `ice_free_irq_msix_misc()` must call `ice_dis_ctrlq_interrupts()`, zero `PFINT_OICR_ENA`, `ice_flush()`, `synchronize_irq()`, and `devm_free_irq()` before `ice_free_irq()`. [F184, F287, F288]
- VSI down and PM: callers of `ice_down()` must set `ICE_VSI_DOWN` first, and `ice_down()` must run `ice_vsi_dis_irq()` (disabling `QINT_RQCTL`, zeroing `GLINT_DYN_CTL`, and calling `ice_flush()` before `synchronize_irq()`, skipping `synchronize_irq()` for `ICE_VSI_VF`), stop HW rings, and call `ice_napi_disable_all()` before cleaning rings. `ice_suspend()` must call `disabled = ice_service_task_stop(pf)` (only calling `ice_service_task_restart(pf)` on early exit if `!disabled`), deinit RDMA, run `ice_prepare_for_shutdown()`, and free IRQs, `q_vectors`, and `ice_clear_interrupt_scheme()`, restored in `ice_resume()` via `ice_reinit_interrupt_scheme()`, `ice_init_rdma()`, and `ice_schedule_reset(pf, ICE_RESET_PFR)`. [F174, F198, F199, F300]
- XDP, channel VSI, and TC block lifetimes: `ice_destroy_xdp_rings()` must call `synchronize_rcu()` before `ice_free_tx_ring()` when `desc` is non-NULL, free `ring_stats` and `xdp_rings[i]` via `kfree_rcu()`, and when `cfg_type == ICE_XDP_CFG_PART`, skip `ice_unmap_xdp_rings()` and return before clearing `xdp_prog`/`num_xdp_txq` or updating the Tx scheduler. `ice_vsi_release_all()` must skip `ICE_VSI_CHNL` VSIs. In `ice_indr_setup_tc_block()` (`FLOW_BLOCK_BIND`), `indr_priv` is freed by `ice_rep_indr_tc_block_unbind()` on unbind, so `ice_indr_setup_tc_block()` must `list_del()` and `kfree(indr_priv)` only when `flow_indr_block_cb_alloc()` fails. [F168, F176, F177, F190]

## API Contracts
- `ice_hw_to_dev()` uses `container_of(hw, struct ice_pf, hw)` and dereferences `pf->pdev->dev`, requiring `hw` to be embedded in `struct ice_pf` after `pf->pdev = pdev`. In `ice_init_phy_user_cfg()`, `ice_init_phy_cfg_dflt_override()` must only run when `!ice_fw_supports_report_dflt_cfg(pi->hw)` and `ICE_LINK_OVERRIDE_EN` is set. [F284, F296]
- XDP, VLAN, and feature validation: `ice_xdp_setup_prog()` and `ice_change_mtu()` must reject `prog && !prog->aux->xdp_has_frags` when `mtu + ICE_ETH_PKT_HDR_PAD > ice_max_xdp_frame_size(vsi)`; `ice_vlan_rx_add_vid()` and `ice_vlan_rx_kill_vid()` must return 0 when `vid == 0`; `ice_fix_features()` must clear STAG Rx/Tx offloads if CTAG is set and keep CTAG/STAG filtering paired when `ice_is_dvm_ena()`; `ice_set_vlan_features()` and `ice_set_features()` must reject `NETIF_F_RXFCS` with `NETIF_VLAN_STRIPPING_FEATURES` (`-EIO`); and `ice_set_features()` must reject clearing `NETIF_F_HW_TC` when `ice_is_adq_active(pf)` (`-EACCES`) or enabling `NETIF_F_HW_CSUM` with `NETIF_F_ALL_TSO` when `ICE_F_GCS` is supported (`-EIO`). [F325, F327, F329, F330, F331]
- NVM contracts: `ice_get_flash_bank_offset()` returns `0` on error (check `!start` in `ice_read_flash_module()`); `ice_read_sr_word()`, `ice_read_sr_word_aq()`, `ice_read_nvm_module()`, `ice_read_nvm_sr_copy()`, and `ice_read_netlist_module()` take word offsets while `ice_read_flat_nvm()`, `ice_read_flash_module()`, `ice_aq_read_nvm()`, and `ice_aq_update_nvm()` take byte offsets/lengths; `ice_aq_read_nvm()` and `ice_aq_update_nvm()` must reject `offset > ICE_AQC_NVM_MAX_OFFSET` (`-EINVAL`); and `ice_nvm_pass_component_tbl()` must follow `ice_nvm_set_pkg_data()` before NVM update with `LIBIE_AQ_FLAG_RD` set on both. [F205, F207, F269, F306]
- Parser contracts: `ice_parser_create()`, `ice_parser_create_table()`, and `ice_xlt_kb_get()` return `ERR_PTR` (check `IS_ERR()`); `ice_parser_run()` must call `ice_parser_rt_reset()` and `ice_parser_rt_pktbuf_set()` before `ice_parser_rt_execute()`; `ice_bst_tcam_search()` sets `*start = i`, so callers looping over matches must increment `start`; `ice_parser_sect_item_get()` must keep `u32 __maybe_unused *offset`, check `index >= le16_to_cpu(hdr->count)`, and use `ICE_SEC_LBL_DATA_OFFSET` (2) for `ICE_SID_LBL_RXPARSER_TMEM` vs `ICE_SEC_DATA_OFFSET` (4) otherwise; and `ice_parser_create_table()` requires `no_offset = true` for Boost TCAM, Boost label, and Marker PType TCAM tables. [F208, F233, F237, F238, F257, F285]

## Error Handling
- In `ice_prepare_xdp_rings()`, if `ice_cfg_vsi_lan()` fails after `ice_map_xdp_rings()`, the error path must call `ice_unmap_xdp_rings(vsi)` before freeing rings, clear `pf->avail_txqs` and `vsi->txq_map` under `pf->avail_q_mutex`, and set `vsi->xdp_rings = NULL` after `devm_kfree()`. [F165]
- In `ice_init_tx_topology()`, only `-ENODEV` from `ice_cfg_tx_topo()` may be returned to abort `ice_init_ddp_config()`; all other errors must be converted to `0`. In `ice_vsi_sync_fltr()`, `-EEXIST` from `ice_fltr_add_mac_list()` or `ice_set_dflt_vsi()` must be cleared to `0`. [F169, F252]

## External Contracts
- `ice_pci_tbl` must be `const`, place `PCI_ANY_ID` entries after specific ones, and end with `{}`; `ice_probe()` must reject `pdev->is_virtfn` with `-EINVAL`. In `ice_fdb_add()`, `-EEXIST` from `dev_uc_add_excl()`/`dev_mc_add_excl()` must be cleared to `0` unless `flags & NLM_F_EXCL` is set. [F298, F328]

## Known Pitfalls
- Queue/VSI indexing and MQPRIO math: in `ice_chnl_cfg_res()` and `ice_remove_q_channels()`, index `tx_rings`/`rx_rings` on parent `vsi` (`ch->base_q + i`) but pass `ch->ch_vsi` to VSI-level helpers; in `ice_set_tx_maxrate()`, read `q_handle` and `tc` from main `vsi` before `vsi = ice_locate_vsi_using_queue(vsi, queue_index)`; and in `ice_validate_mqprio_qopt()`, `ice_create_q_channels()`, and `ice_setup_tc_mqprio_qdisc()`, divide 64-bit rates by `ICE_BW_KBPS_DIVISOR` with `div_u64()` and check `ICE_MIN_BW_LIMIT` with `iter_div_u64_rem()`. [F262, F263, F271]
- Packet headers, LLDP, WoL, and NVM bounds: in `ice_features_check()` with `skb->encapsulation`, only compute `skb_inner_network_header(skb) - skb_transport_header(skb)` when `gso` and `gso_type & (SKB_GSO_GRE | SKB_GSO_UDP_TUNNEL)` hold; in `ice_set_dflt_mib()`, advance `tlv` by `(char *)tlv + sizeof(tlv->typelen) + len`; in `ice_set_wake()`, write `U32_MAX` to `PFPM_WUS` before `PFPM_APM`/`PFPM_WUFC`; in `ice_get_pfa_module_tlv()`, compute `max_tlv` and `next_tlv` with `check_add_overflow()`; and in `ice_read_pba_string()`, verify `pba_tlv_len >= pba_size` and `pba_num_size >= (u32)pba_size * 2 + 1`. [F242, F243, F280, F301, F335]
