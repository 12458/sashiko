# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 2)

Implements ethtool operations, FCoE Direct Data Placement (DDP) offload, E610 PLDM firmware flash update, IPsec (XFRM) hardware offload, and ring/interrupt vector library helpers for the Intel ixgbe driver.

## Architecture & Data Flow
- In `ixgbe_ipsec_add_sa()`, `struct rx_sa rsa` must be zeroed with `memset` before populating `rsa.ipaddr`, as `AF_INET` writes only `&rsa.ipaddr[3]` while `ipsec->ip_tbl` `memcmp` and `ixgbe_ipsec_set_rx_ip()` read all 16 bytes. [F1365]
- In `ixgbe_ipsec_restore()`, the loop purging `IXGBE_RXTXMOD_VF` entries from `ipsec->rx_tbl`/`tx_tbl` via `ixgbe_ipsec_del_sa()` must run before reloading `ipsec->ip_tbl` via `ixgbe_ipsec_set_rx_ip()`. In `ixgbe_ipsec_clear_hw_tables()`, `ixgbe_ipsec_set_rx_ip()` runs only for `idx < IXGBE_IPSEC_MAX_RX_IP_COUNT` (128), while `ixgbe_ipsec_set_tx_sa()` and `ixgbe_ipsec_set_rx_sa()` continue to `IXGBE_IPSEC_MAX_SA_COUNT` (1024). [F1380, F1414]
- `ixgbe_fcoe_clear_ddp()` must set `ddp->err = 1` so `ixgbe_fcoe_ddp_put()` invalidates the HW DDP context unless `ixgbe_fcoe_ddp()` received an error-free `IXGBE_RXDADV_STAT_FCSTAT_FCPRSP` frame and cleared `ddp->err = 0` (while unmapping and NULLing `ddp->sgl`). [F1389]
- In `ixgbe_cache_ring_dcb_sriov()` and `ixgbe_cache_ring_sriov()`, `adapter->rx_ring[i]->netdev` must be `NULL` for `pool != 0` and `adapter->netdev` for pool 0 (and FCoE rings), as `ixgbe_process_skb_fields()` checks `netif_is_ixgbe(rx_ring->netdev)` to separate PF and macvlan pool traffic. [F1473]
- If `IXGBE_FLAG_FCOE_ENABLED` is set, `adapter->ring_feature[RING_F_FCOE].indices` must be non-zero; setting `fcoe->indices` to 0 (as in `ixgbe_set_dcb_sriov_queues()`) must clear `IXGBE_FLAG_FCOE_ENABLED`. In SR-IOV/DCB queue setup and ring-caching helpers, the VMDq mask (`vmdq_m` or `vmdq->mask`) must be assigned a non-zero pool mask before evaluating `__ALIGN_MASK(1, ~mask)`. [F1417, F1418]
- In `ixgbe_alloc_q_vectors()`, per-vector ring counts (`rqpv`, `tqpv`, `xqpv`) must use `DIV_ROUND_UP(remaining, q_vectors - v_idx)` and decrement remaining counts each iteration. [F1420]
- In `ixgbe_add_ethtool_fdir_entry()`, `union ixgbe_atr_input mask` must be zeroed with `memset` before setting fields because `memcmp(&adapter->fdir_mask, &mask, sizeof(mask))` compares the whole union. `ethtool_get_flow_spec_ring_vf(fsp->ring_cookie)` is 1-based: `vf == 0` maps `ring < adapter->num_rx_queues` to `adapter->rx_ring[ring]->reg_idx`; `vf != 0` requires `vf <= adapter->num_vfs` and `ring < adapter->num_rx_queues_per_pool` and maps to `(vf - 1) * adapter->num_rx_queues_per_pool + ring`. [F1374, F1400]
- In `ixgbe_set_coalesce()`, `tx_itr_prev` must be sampled from `adapter->rx_itr_setting` (when `q_vector[0]` has both `tx.count` and `rx.count`) or `adapter->tx_itr_setting` before mutating either field, so transitions across `IXGBE_100K_ITR` or `1` trigger `ixgbe_do_reset()`. [F1387]
- `ixgbe_flash_pldm_image()` seeds `priv.activate_flags` with the NVM preservation policy, so each `ixgbe_flash_component()` call must OR its `IXGBE_ACI_NVM_ACTIV_SEL_*` flag into `priv->activate_flags` for `ixgbe_finalize_update()` to pass to `ixgbe_switch_flash_banks()`. [F1390]
- `reg_test_82599` and `reg_test_82598` must be `const` and end with `{ .reg = 0 }`; `ixgbe_reg_test()` must set `IXGBE_RXDCTL_ENABLE` on `IXGBE_RXDCTL(0..3)` before testing `IXGBE_RDT(0..3)` and clear them to 0 after. [F1450]

## Synchronization
- `ixgbe_ipsec_vf_add_sa()` and `ixgbe_ipsec_vf_del_sa()` run from VF mailbox interrupt context (`ixgbe_msix_other` -> `ixgbe_msg_task`), so all allocations and helpers in them and in `ixgbe_ipsec_add_sa()` / `ixgbe_ipsec_del_sa()` must use `GFP_ATOMIC` and never sleep. [F1455]
- In `ixgbe_ipsec_add_sa()`, `ipsec->rx_tbl[sa_idx]` and HW Rx SA registers must be fully initialized before publishing `&ipsec->rx_tbl[sa_idx].hlist` to `ipsec->rx_sa_list` via `hash_add_rcu()`. Lookups in `ixgbe_ipsec_find_rx_state()` must hold `rcu_read_lock()`, skip `IXGBE_RXTXMOD_VF` entries, and call `xfrm_state_hold(rsa->xs)` before `rcu_read_unlock()`. [F1350, F1456]
- On non-X550 MACs (`hw->mac.type != ixgbe_mac_X550`), `ixgbe_fcoe_ddp_setup()` and `ixgbe_fcoe_ddp_put()` must hold `spin_lock_bh(&fcoe->lock)` across the entire indirect DDP and filter register sequence (`IXGBE_FCPTRL/H`, `IXGBE_FCBUFF`, `IXGBE_FCDMARW`, `IXGBE_FCPARAM`, `IXGBE_FCFLT`, `IXGBE_FCFLTRW`). [F1348]
- In `ixgbe_alloc_q_vector()`, each embedded `ixgbe_ring` must have its fields initialized and be linked into `q_vector->tx` or `rx` via `ixgbe_add_ring()` before publishing its pointer to `adapter->tx_ring`, `xdp_ring`, or `rx_ring` via `WRITE_ONCE()`. [F1346]
- `ixgbe_flash_pldm_image()` must call `ixgbe_cancel_pending_update()` before `ixgbe_acquire_nvm()`, and all `ixgbe_fwu_ops_e610` callbacks invoked by `pldmfw_flash_image()` must assume the NVM lock is already held without acquiring or releasing it. [F1337]
- `ixgbe_set_link_ksettings()` must bracket `hw->mac.ops.setup_link` with `test_and_set_bit`/`clear_bit(__IXGBE_IN_SFP_INIT, &adapter->state)`, and `ixgbe_get_module_eeprom()` must return `-EBUSY` when `__IXGBE_IN_SFP_INIT` is set. [F1355]

## Object Lifetimes
- `ixgbe_fcoe_ddp_setup()` must reject XIDs where `ddp->sgl != NULL` before `ixgbe_fcoe_clear_ddp(ddp)`, pair `get_cpu()` with `put_cpu()` on all paths, and unwind `dma_map_sg()` and `dma_pool_alloc()` via `out_noddp_free`, `out_noddp_unmap`, and `out_noddp`. `ixgbe_fcoe_ddp_put()` must set `ddp->pool = NULL` and call `ixgbe_fcoe_clear_ddp(ddp)` after freeing `ddp->udl` and unmapping `ddp->sgl`. `ixgbe_free_fcoe_ddp_resources()` must call `ixgbe_fcoe_ddp_put()` on all XIDs before `ixgbe_fcoe_dma_pool_free()`, and NULL out `ddp_pool->pool` and `fcoe->extra_ddp_buffer`. [F1333, F1334, F1336]
- In `ixgbe_ipsec_add_sa()` and `ixgbe_ipsec_del_sa()`, `ipsec->ip_tbl[ipi].ref_cnt` tracks inbound SAs sharing an IP; a slot and its HW register may only be cleared when `ref_cnt` reaches 0. `num_rx_sa`/`num_tx_sa` must be incremented only after all checks and table allocations succeed, and `ixgbe_ipsec_del_sa()` must call `ixgbe_ipsec_stop_engine()` and clear `IXGBE_FLAG2_IPSEC_ENABLED` when both reach 0. [F1338, F1339]
- `ixgbe_ipsec_vf_add_sa()` must free its synthetic `xs` and `xs->aead` with `kfree_sensitive()` if `ixgbe_ipsec_add_sa()` fails; `ixgbe_ipsec_vf_del_sa()` must free `xs` after `ixgbe_ipsec_del_sa()` (never inside `ixgbe_ipsec_del_sa()`, where PF states belong to the stack). [F1340]
- `ixgbe_free_q_vector()` must NULL out `adapter->xdp_ring[]`, `tx_ring[]`, and `rx_ring[]` with `WRITE_ONCE()`, clear `adapter->q_vector[v_idx]`, and call `__netif_napi_del()` before `kfree_rcu(q_vector, rcu)`. If `ixgbe_alloc_q_vectors()` fails in `ixgbe_init_interrupt_scheme()`, it must free allocated vectors `[0 .. v_idx-1]` and zero counts, and `ixgbe_init_interrupt_scheme()` must call `ixgbe_reset_interrupt_capability()`. [F1342, F1343]
- In `ixgbe_set_ringparam()`, new Tx, XDP, and Rx ring resources must be allocated in `temp_ring` (zeroing `temp_ring[i].xdp_rxq` before `ixgbe_setup_rx_resources()`) before freeing active rings; on failure, unwind `temp_ring[0 .. i-1]` before `ixgbe_up()`. [F1344]
- `ixgbe_update_ethtool_fdir_entry()` requires `adapter->fdir_perfect_lock` held and takes ownership of a non-NULL `input` filter into `adapter->fdir_filter_list` (freeing any displaced rule at `sw_idx` and adjusting `fdir_filter_count`); callers must `kfree(input)` only on error before calling it. [F1345]

## API Contracts
- `ixgbe_fcoe_ddp()` returns `< 0` on non-DDP/errored frames, `0` when DDP placed payload and the caller must free `skb`, or `> 0` byte count when DDP completes and `skb` goes to the ULD. `ixgbe_fcoe_ddp_setup()` (and `ddp_get`/`ddp_target`) returns `1` on success and `0` on failure, never `< 0`. [F1357, F1359]
- In `ixgbe_fso()`, when `skb_is_gso(skb)` is true, `gso_type` must be `SKB_GSO_FCOE`, `first->gso_segs` and `first->bytecount` must include `(first->gso_segs - 1) * *hdr_len` and trailers, and `IXGBE_ADVTXD_TUCMD_L4T_RSV` must be set in `type_tucmd`. [F1465]
- `ixgbe_init_ipsec_offload()` must not set `xfrmdev_ops` on `82598EB` or when `IXGBE_SECTXSTAT_SECTX_OFF_DIS` or `IXGBE_SECRXSTAT_SECRX_OFF_DIS` is set, and must call `ixgbe_ipsec_stop_engine()` and `ixgbe_ipsec_clear_hw_tables()` first. [F1438]
- In `ixgbe_ipsec_add_sa()`, `extack` can be `NULL` (from VF paths), so use `NL_SET_ERR_MSG_MOD()`; store `ixgbe_ipsec_find_empty_idx()` in a signed `int` and check `< 0` before casting to `u16 sa_idx`. `xs->xso.offload_handle` adds `IXGBE_IPSEC_BASE_RX_INDEX` (0) or `IXGBE_IPSEC_BASE_TX_INDEX` (1024), which all consumers must subtract before indexing `rx_tbl`/`tx_tbl`. [F1363, F1364, F1366]
- `ixgbe_ipsec_parse_proto_keys()` requires `alg_icv_len == IXGBE_IPSEC_AUTH_BITS` (128) and `alg_key_len` of `IXGBE_IPSEC_KEY_BITS` (160: 16B key + 4B salt at `((u32 *)key_data)[4]`) or 128 (salt = 0). Callers of `ixgbe_ipsec_tx()` must zero-initialize `struct ixgbe_ipsec_tx_data` before passing it. [F1367, F1396]
- `ixgbe_set_num_queues()` and `ixgbe_cache_ring_register()` must call helpers in order (`dcb_sriov`, `dcb`, `sriov`, `rss`) and stop at the first returning `true`. When `ixgbe_acquire_msix_vectors()` fails in `ixgbe_set_interrupt_capability()`, disable multi-TC DCB, SR-IOV, and RSS (`RING_F_RSS` limit = 1), call `ixgbe_set_num_queues()`, and set `adapter->num_q_vectors = 1`. [F1369, F1436]
- In `ixgbe_switch_flash_banks()`, check `emp_reset_available` for `NULL` before dereferencing. On E610, `ixgbe_flash_pldm_image()` and `ixgbe_check_component_response()` must allow updates when `!nvm_unified_update` or `IXGBE_ACI_NVM_PASS_COMP_PARTIAL_CHECK` if `hw->mac.ops.fw_recovery_mode(hw)` is true. [F1362, F1446]
- In `ixgbe_get_ethtool_stats()`, NULL-check `adapter->tx_ring[j]` and `rx_ring[j]`. In `ixgbe_get_coalesce()` and `ixgbe_set_coalesce()`, `rx_itr_setting` and `tx_itr_setting` store `0` and `1` unshifted and values `> 1` as `usecs << 2`, so shift by 2 only when `> 1`. In `ixgbe_get_eeprom()` and `ixgbe_set_eeprom()`, convert byte offsets/lengths to 16-bit words (`>> 1`) and byte-swap `u16` buffers with `le16_to_cpus()`/`cpu_to_le16s()`. [F1371, F1375, F1376]
- Offline `ixgbe_diag_test()` must abort if any VF has `clear_to_send`, run `ixgbe_link_test()` before `ixgbe_close()`/`ixgbe_reset()`, skip `ixgbe_loopback_test()` in SR-IOV/VMDq mode, and call `ixgbe_open()` or `disable_tx_laser()` after clearing `__IXGBE_TESTING`. `ixgbe_clean_test_rings()` must bracket `ixgbe_check_lbtest_frame()` page access with `dma_sync_single_for_cpu` and `dma_sync_single_for_device` (`DMA_FROM_DEVICE`). [F1451, F1461]

## Error Handling
- In `ixgbe_ipsec_vf_del_sa()`, if `!rsa->used` or `!tsa->used`, return `0` silently without logging an error (PF reset/VF down may have already cleared VF SAs). [F1470]

## External Contracts
- In `ixgbe_fcoe_ddp_setup()`, every buffer in `ddp->udl` after the first must start at a 4096B (`IXGBE_FCBUFF_MIN`) boundary, every buffer before the last must end at a 4096B boundary, and if the last buffer's `lastsize == 4096`, append `fcoe->extra_ddp_buffer_dma` with `lastsize = 1`. [F1360]
- `ixgbe_ipsec_vf_add_sa()` must verify `adapter->vfinfo[vf].trusted` and `IXGBE_FLAG2_VF_IPSEC_ENABLED`; `ixgbe_ipsec_vf_del_sa()` must verify `trusted`, `IXGBE_RXTXMOD_VF`, and `rsa->vf == vf` (or `tsa->vf == vf`). [F1468]
- `ixgbe_get_regs()` must stay within `IXGBE_REGS_LEN` (1145 `u32`s) and split 64-bit counters (`gorc`, `gotc`, `tor`) into low then high 32 bits at fixed indices. [F1402]

## Known Pitfalls
- `netdev->fcoe_ddp_xid` is `ddp_max - 1` (511, or 2047 on X550); `ixgbe_fcoe_ddp_setup()` and `ixgbe_fcoe_ddp_put()` reject `xid >= netdev->fcoe_ddp_xid`, whereas `ixgbe_fcoe_ddp()` and `ixgbe_free_fcoe_ddp_resources()` bound against `ddp_max`. In `ixgbe_fcoe_ddp()`, refresh or read `fh` (`skb->data`) before `skb_linearize(skb)`. Cast `ddp->udp` (`dma_addr_t`) to `u64` before `>> 32` in `ixgbe_fcoe_ddp_setup()`, and cast `prefix` and `mac->san_addr[i]` to `u64` before left-shifting in `ixgbe_fcoe_get_wwn()`. [F1393, F1415, F1416, F1434]
- In `ixgbe_ipsec_set_tx_sa()`, `ixgbe_ipsec_set_rx_sa()`, and `ixgbe_ipsec_set_rx_ip()`, swap `key[0..3]` and `salt` with `cpu_to_be32()` and write `key[3 - i]` in reverse order, but swap `spi` and `addr[0..3]` with `cpu_to_le32()`. In `ixgbe_ipsec_vf_add_sa()`, `sam` aliases `&msgbuf[1]`, so read all `sam` fields before writing `msgbuf[1]`. In `ixgbe_ipsec_stop_data()`, if TX/RX are not ready and `!adapter->link_up`, assert `IXGBE_MACC_FLU` and `IXGBE_HLREG0_LPBK` around the readiness poll and clear both after. [F1397, F1433, F1440]
- Check `if (tcs <= 1) return false;` before dividing by `tcs` in `ixgbe_set_dcb_sriov_queues()` and `ixgbe_set_dcb_queues()`. All `ixgbe_gstrings_stats` fields (`IXGBE_STAT`/`IXGBE_NETDEV_STAT`) must be 32-bit or 64-bit integers. [F1419, F1423]

## Other
- `ixgbe_ipsec_set_tx_sa()`, `ixgbe_ipsec_set_rx_sa()`, and `ixgbe_ipsec_set_rx_ip()` must write data registers, call `IXGBE_WRITE_FLUSH(hw)`, write `IXGBE_IPSTXIDX`/`IXGBE_IPSRXIDX` with `IXGBE_RXTXIDX_WRITE` while preserving `IXGBE_RXTXIDX_IPS_EN`, and call `IXGBE_WRITE_FLUSH(hw)`. [F1441]
