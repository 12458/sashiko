# QCOM AUDIO (ASoC) DRIVERS — sound/soc/codecs (part 1)

Qualcomm ASoC codec drivers and shared helper libraries for MSM8916/PM8916 analog/digital codecs, PM4125 SoundWire/SPMI codec, WCD9335 SLIMbus codec, Class-H (`wcd-clsh-v2`), and Multi-Button Headset Control (`wcd-mbhc-v2`).

## Architecture & Data Flow

- In `pm4125-sdw.c` and `pm4125.c`, `priv->regmap` is allocated only on the TX SoundWire slave (`priv->is_tx`) and is NULL on RX; it starts cache-only (`regcache_cache_only(priv->regmap, true)`) in `pm4125_probe` and only exits cache-only/syncs (`regcache_sync`) on `SDW_SLAVE_ATTACHED` in `pm4125_update_status` or `pm4125_sdw_runtime_resume`, so shared callbacks (`pm4125_update_status`, `pm4125_sdw_runtime_suspend`/`resume`) must check `if (priv->regmap)`. Also, `dev_get_drvdata(&slave->dev)` must stay `struct pm4125_sdw_priv *` while master platform/component drvdata is `struct pm4125_priv *`. [F32, F86, F96]
- In `pm4125_sdw_hw_params`, iterating `priv->port_config[0..PM4125_MAX_SWR_PORTS-1]` must skip zero `ch_mask` entries, compact active ports into `port_config[priv->active_ports++]` for `sdw_stream_add_slave`, and note `for_each_set_bit(j, &ch_mask, 4)` only counts bits 0..3 toward `priv->sconfig.ch_count`. Also, channel indices in `PM4125_SWRM_CH_MASK(ch_idx)` in `pm4125_probe()` must be 1..8 (`BIT(ch_idx - 1)`), as `pm4125_connect_port()` truncates `master_ch_mask` to `u8`. [F72, F81, F91]
- Since `MIC_BIAS_1..MIC_BIAS_4` are 1-based, `pm4125_micbias_control` and `wcd9335_micbias_control` must use `micb_index = micb_num - 1` (`0 <= micb_index < MAX_MICBIAS`) to index `micb_ref`/`pullup_ref`; `MICB_PULLUP_ENABLE` writes pullup bits only when `pullup_ref[micb_index] == 1 && micb_ref[micb_index] == 0`, `MICB_DISABLE` reaching `micb_ref == 0` switches to pullup mode if `pullup_ref > 0`, and `pm4125_codec_enable_micbias` must use `MICB_PULLUP_ENABLE`/`DISABLE` for `MIC_BIAS_3` (`enable_mask` is 0). [F57, F74, F109]
- In `wcd9335.c`, `wcd9335_slim_probe` sets `dev_set_drvdata(&slim->dev, wcd)` and `wcd9335_codec_probe` never calls `snd_soc_component_set_drvdata`, so both `dev_get_drvdata(comp->dev)` and `snd_soc_component_get_drvdata(comp)` must return the same `struct wcd9335_codec *`. Because `wcd->tx_chs[port_id].list` and `rx_chs[port_id].list` are shared across DAIs, `slim_tx_mixer_put` must guard `list_add_tail` with `tx_port_value[port_id] != dai_id` and `list_del_init` with `== dai_id` (setting `-1`), and `slim_rx_mux_put` must call `list_del_init` before re-adding. [F7, F87]
- In `wcd9335_codec`, `rx_chs` stores `ch->port` offset by `WCD9335_RX_START` (16..28) while `ch->shift` is 0..12, so `wcd9335_codec_enable_int_port` must subtract `WCD9335_RX_START` when `ch->port >= WCD9335_RX_START`; in `wcd9335_slimbus_irq`, `for_each_set_bit(j, &status, 32)` must use `port_id = (j >= 16 ? j - 16 : j)` for `WCD9335_SLIM_PGD_PORT_INT_EN0`/`TX_EN0` and raw `j` for `RX_SOURCE0`/`CLR_RX_0`, logging overflow/underflow via `dev_err_ratelimited` and clearing the port's `INT_EN0`/`TX_EN0` bit until `SND_SOC_DAPM_POST_PMU`. [F60, F77, F128]
- In `wcd9335.c`: `wcd9335_codec_hph_mode_gain_opt` must only write `WCD9335_HPH_L_EN`/`R_EN` and cache 5-bit `hph_l_gain`/`hph_r_gain` when the `WCD9335_ANA_HPH` PA bit is off and register != `l_val`/`r_val`; `wcd9335_config_compander` must return early if `!interp_n` (`INTERP_EAR`) and use `comp = interp_n - 1` for `comp_enabled`, `WCD9335_CDC_COMPANDER1_CTL`, and `WCD9335_CDC_RX1_RX_PATH_CFG`; `wcd9335_codec_find_amic_input` must reject `adc_mux_n == WCD9335_INVALID_ADC_MUX` (9), `< 0`, or `> 13`, using a 2-reg stride from `ADC_MUX0_CFG0` (`< 4`) vs 1-reg stride from `ADC_MUX4_CFG0` (`>= 4`). [F42, F61, F62]
- In `wcd-mbhc-v2.c`: `wcd_mbhc_report_plug_insertion` must skip `wcd_mbhc_compute_impedance` when `WCD_MBHC_HPH_PA_EN` is set and preserve `SND_JACK_LINEOUT` / `MBHC_PLUG_TYPE_HIGH_HPH` via `mbhc->force_linein` until `wcd_mbhc_report_plug_removal` clears it; in `wcd_mbhc_adc_hs_rem_irq`, checking `mbhc->current_plug == MBHC_PLUG_TYPE_HEADPHONE` to set `extn_cable_hph_rem = true` must precede `wcd_mbhc_elec_hs_report_unplug`; in `wcd_correct_swch_plug`, set `WCD_MBHC_DETECTION_DONE` to `1` only for `MBHC_PLUG_TYPE_HEADSET` (`0` otherwise) and re-enable `mbhc_hs_ins_intr` for `MBHC_PLUG_TYPE_HEADPHONE`. [F43, F71, F103]
- In `wcd-mbhc-v2.c`, jiffies timeouts in `wcd_correct_swch_plug()` and `wcd_mbhc_adc_hs_rem_irq()` must use `time_after(jiffies, timeout)`, and button debounce in `wcd_mbhc_btn_press_handler()` must use `jiffies_to_msecs(jiffies - mbhc->jiffies_atreport)`. [F82]
- In `msm8916-wcd-analog.c` and `msm8916-wcd-digital.c`: while `priv->detect_accessory_type` is true, `mbhc_btn_press_irq_handler` suppresses `SND_JACK_BTN_0` and `mbhc_btn_release_irq_handler` sets `priv->mbhc_btn0_released`, which `pm8916_mbhc_switch_irq_handler` consumes on insertion and resets on removal; in `pm8916_wcd_analog_enable_adc`, `PRE_PMU` sleeps 10ms before setting `CDC_A_TX_1_2_TEST_CTL_2` init, `POST_PMU` sleeps 12ms before clearing it, and `POST_PMD` `CDC_A_TX_2_EN` clears `MICB_1_CTL_CFILT_REF_SEL_MASK` and falls through to `CDC_A_TX_3_EN`; `msm8x16_wcd_get`/`put_iir_band_audio_mixer` require `bytes_ext.max <= WCD_IIR_FILTER_SIZE` (`sizeof(u32) * BAND_MAX`). [F47, F65, F83, F105]

## Synchronization

- In `wcd-mbhc-v2.c`, `wcd_mbhc_report_plug()`, `wcd_mbhc_adc_detect_plug_type()`, `wcd_schedule_hs_detect_plug()`, `wcd_cancel_hs_detect_plug()`, and `wcd_mbhc_cancel_pending_work()` require `mbhc->lock` held; `wcd_cancel_hs_detect_plug` sets `hs_detect_work_stop = true`, drops `mbhc->lock` across `cancel_work_sync`, and re-locks. In `mbhc_plug_detect_fn()`, set `mbhc->in_swch_irq_handler = true` before `wcd_mbhc_cancel_pending_work()` and read `mbhc->current_plug` only after it returns. [F2, F13, F16]
- In `wcd-mbhc-v2.c`, `wcd_btn_long_press_fn` (`mbhc_btn_dwork`) must never acquire `mbhc->lock` because `wcd_cancel_btn_work` calls `cancel_delayed_work_sync` while holding `mbhc->lock`; also, disabling `mbhc_hs_ins_intr` or `mbhc_hs_rem_intr` inside `wcd_mbhc_adc_hs_ins_irq`, `wcd_mbhc_elec_hs_report_unplug`, or `mbhc_plug_detect_fn` must use `disable_irq_nosync`, never `disable_irq`. [F113, F114]
- `pm4125_global_mbias_enable()` and `pm4125_global_mbias_disable()` must gate `PM4125_ANA_MBIAS_EN` updates via `atomic_inc_return(&pm4125->gloal_mbias_cnt) == 1` and `atomic_dec_and_test(&pm4125->gloal_mbias_cnt)`. [F23]

## Object Lifetimes

- `wcd_mbhc_init()` must allocate `struct wcd_mbhc` with non-devm `kzalloc`, initialize `mbhc->lock` and work structs (`mbhc_btn_dwork`, `correct_plug_swch`, `mbhc_plug_detect_work`) before requesting the 7 MBHC IRQs with non-devm `request_threaded_irq`, and `wcd_mbhc_deinit()` must `free_irq()` all 7 IRQs before cancelling work and `kfree(mbhc)`. [F17, F92]
- In `wcd9335.c`: `wcd9335_trigger` stop/suspend/pause must call `slim_stream_disable` before `slim_stream_unprepare`; `wcd9335_cdc_req_mclk_enable` must call `wcd9335_enable_master_bias` before `wcd9335_enable_mclk` on enable and `wcd9335_disable_mclk` before `wcd9335_disable_master_bias`, `clk_disable_unprepare(wcd->mclk)`, and `wcd9335_cdc_sido_ccl_enable(wcd, false)` on disable; `wcd9335_slim_set_hw_params` must `kfree` and clear `cfg->chs = NULL` on error and `kfree(dai->sconfig.chs)` on `SND_SOC_DAPM_POST_PMD` in `wcd9335_codec_enable_slim`. [F1, F6, F8]
- In `pm4125_add_slave_components`, `component_match_add_release` (`component_release_of`) takes ownership of `pm4125->rxnode` and `txnode`, so callers must not call `of_node_put` on them; in `wcd9335_parse_dt` and `pm4125_probe`, bulk regulators without manual `.remove` teardown must use `devm_regulator_bulk_get_enable`. [F11, F95]

## API Contracts

- `wcd_mbhc_init` and `wcd_mbhc_start` store borrowed pointers to `mbhc_cb`, `intr_ids`, `fields` (`>= WCD_MBHC_REG_FUNC_MAX` entries), `cfg`, and `jack` without copying, requiring them to outlive `wcd_mbhc_deinit`; `wcd_mbhc_init` requires non-NULL `intr_ids`, `fields`, `mbhc_cb`, `mbhc_cb->mbhc_bias`, and `mbhc_cb->set_btn_thr` (setting `impedance_detect` only if `compute_impedance` is set), while unsupported `fields[]` (`.reg == 0`) and other `mbhc_cb` callbacks may be NULL/0 (requiring `wcd_mbhc_read`/`write_field` and NULL checks); `wcd_mbhc_start` must set `mbhc->cfg` and `jack` before `wcd_mbhc_initialise()`. [F4, F18, F31, F84, F117]
- In `wcd-mbhc-v2`: if `cfg->hs_thr` or `hph_thr` is non-zero, `cfg->micb_mv` must be non-zero, and `get_micbias_val` must write `> 0` mV into `*mb` (callers divide by them unchecked); `set_btn_thr` (`pm4125_mbhc_program_btn_thr`) must check `num_btn <= WCD_MBHC_DEF_BUTTONS` (8); `wcd_measure_adc_once()` (`>= 0` mV or `-EINVAL`) and `wcd_check_cross_conn()` (`< 0` err/PA, `0` none, `1` cross-conn) must be stored in signed ints; `wcd_mbhc_get_impedance()` requires non-NULL `zl`/`zr` and returns `0` only if both `mbhc->zl` and `zr` are non-zero (`-EINVAL` otherwise). [F29, F30, F59, F78, F79]
- In `wcd-clsh-v2.c`: `wcd_clsh_ctrl_alloc` uses `kzalloc` and returns `ERR_PTR(-ENOMEM)`, requiring `IS_ERR()` checks and `wcd_clsh_ctrl_free` on error/`.remove`; `wcd_clsh_ctrl_set_state` and `wcd_clsh_set_hph_mode` sleep and mutate `wcd_clsh_ctrl` unsynchronized (call only under DAPM/card lock), branch on `ctrl->codec_version >= WCD937X` (`WCD_CLSH_STATE_LO` only for `< WCD937X`, `AUX` only for `>= WCD937X`), and `wcd_clsh_ctrl_set_state` rejects bitwise-OR states (`-EINVAL`), while `< WCD937X` rejects `CLS_H_NORMAL` and maps `CLS_H_LOHIFI` to `CLS_H_HIFI` on `HPHL`/`HPHR` and requires `CLS_AB` on `LO`. [F5, F37, F110, F116]
- In `pm4125_connect_port()`, `port_idx` is 1-based (`port_config[port_idx - 1]` and `m_port_map[port_num]` from index 1) while `ch_id` is 0-based (`ch_info[ch_id]`). In `pm4125_get_channel_map()` and `wcd9335_get_channel_map()`, unused direction pointers may be NULL (playback validates/writes only `rx_num`/`rx_slot`, capture only `tx_num`/`tx_slot`). In `wcd-mbhc-v2.h` and `pm4125.h`, `#if IS_ENABLED(...)` declarations and `#else` inline stubs must be updated in lockstep. [F36, F39, F54]
- In `wcd9335.c`, SLIMbus interface lookup, `slim_get_logical_addr`, `regmap_init_slimbus`, hardware bringup, and component registration must be deferred from `wcd9335_slim_probe` to `wcd9335_slim_status`; custom DAPM `.put` callbacks must call `snd_soc_dapm_mux_update_power` (`slim_rx_mux_put`), `snd_soc_dapm_mixer_update_power` (`slim_tx_mixer_put`), or `snd_soc_dapm_put_enum_double` (`wcd9335_put_dec_enum`, `wcd9335_int_dem_inp_mux_put`). [F121, F126]

## External Contracts

- `wcd_dt_parse_mbhc_data` and `pm4125_dt_parse_micbias_info` divide `"qcom,*-microvolt"` DT properties by 1000, so `hs_thr`, `hph_thr`, `btn_high`, `micb_mv`, and `micb1_mv..micb3_mv` are in millivolts. In `wcd_mbhc_report_plug_removal`, `wcd_cancel_btn_work` must be called first, and if it returns 0 while `mbhc->buttons_pressed` is non-zero, a button release (`0`) must be reported via `snd_soc_jack_report` before jack unplug. [F118, F127]

## Known Pitfalls

- Callers of `wcd_mbhc_write_field()` and `snd_soc_component_write_field()` must pass unshifted values (`snd_soc_component_write_field` shifts by `__ffs(mask)`). In `wcd_mbhc_initialise` and `wcd_correct_swch_plug`, which proceed on `-EACCES` and unconditionally call `pm_runtime_put_autosuspend` on exit, use `pm_runtime_get_sync` (with `pm_runtime_put_noidle` on `ret < 0 && ret != -EACCES`), never `pm_runtime_resume_and_get`. [F80, F94]
- Widget names in `wcd9335.c` and `msm8916-wcd-digital.c` have strict parser assumptions: `wcd9335_codec_enable_dec` copies 15 bytes, strips to the first space, and passes `strpbrk(..., "012345678")` to `kstrtouint` (`<= 15` chars, space before digit, no suffix); `wcd9335_codec_enable_dmic` and `msm8916_wcd_digital_enable_dmic` pass `strpbrk(w->name, ...)` to `kstrtouint` (no digits in prefix, no suffix); `__wcd9335_codec_enable_micbias` uses `strnstr(w->name, "MIC BIAS1", sizeof("MIC BIAS1"))` (no prefix before `"MIC BIAS1..4"`). [F88, F89, F90]
