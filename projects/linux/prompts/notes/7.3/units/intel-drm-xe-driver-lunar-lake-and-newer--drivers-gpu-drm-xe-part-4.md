# INTEL DRM XE DRIVER (Lunar Lake and newer) — drivers/gpu/drm/xe (part 4)

This component manages Graphics Technology (GT) state, topology, sysfs/throttle/stats reporting, SR-IOV Virtual Function (VF) GT operations, and the core Graphics Microcontroller (GuC) stack (`xe_guc`, `xe_guc_ct`, `xe_guc_ads`, `xe_guc_capture`, `xe_guc_pc`, doorbell/ID managers, engine activity, hwconfig, and logging).

## Architecture & Data Flow
- `gt->sriov` is a union of `pf` and `vf`: access `gt->sriov.vf` (`xe_gt_sriov_vf_*`) only when `IS_SRIOV_VF(xe)` and `gt->sriov.pf` only when `IS_SRIOV_PF(xe)`. On VFs, `xe_guc_init` and `xe_guc_init_post_hwconfig` skip `log`, `capture`, `ads`, `dbm`, `pc`, and `engine_activity`, leaving `guc->log.bo`, `guc->capture`, `guc->ads.bo`, and `guc->pc.bo` NULL; VF-reachable paths must check `!IS_SRIOV_VF(xe)` or pointer non-nullness. [F1106, F1107]
- When `xe->info.skip_guc_pc` is true, `xe_guc_pc_init` returns `0` without initializing `pc->freq_lock` or `pc->bo`; `xe_guc_pc_start`, `xe_guc_pc_stop`, `xe_guc_pc_gucrc_disable`, and `xe_guc_pc_restore_stashed_freq` must check `xe->info.skip_guc_pc` first. `xe_guc_hwconfig_init` only allocates `guc->hwconfig.bo` on `XE_GT0`, leaving it NULL on other GTs; callers must check `xe_guc_hwconfig_size(guc) != 0` before `xe_guc_hwconfig_copy`. [F1108, F1110]
- Under `submission_state.lock`, `idm_reserve_chunk_locked()` and `idm_release_chunk_locked()` must keep `idm->used` equal to the weight of `idm->bitmap`. Regular IDs (`retain == 0`) allocate from the low end via `bitmap_find_next_zero_area`; when `retain` or `spare` is non-zero (VF reservations on PF), `idm_reserve_chunk_locked()` and `dbm_reserve_chunk_locked()` must enforce PF quota (else `-EDQUOT`) and `idm_reserve_chunk_locked()` must allocate from the high end via `find_last_zero_area`. [F1077, F1161]
- Under `ct->fast_lock`, `__g2h_reserve_space`, `__g2h_release_space`, and `guc_ct_change_state` must synchronize `ct->ctbs.g2h.info.space`, `ct->g2h_outstanding`, and a runtime PM reference (`xe_pm_runtime_get_noresume` when `g2h_outstanding` becomes non-zero, `xe_pm_runtime_put` when it drops to zero). Every G2H event whose H2G sender reserved `g2h_len > 0` must release `len` dwords via `g2h_release_space()` in `parse_g2h_event()` (or `__g2h_release_space()` in `g2h_fast_path()`); unsolicited G2H events must not. [F1122, F1166]
- `struct guc_ctb_info` stores `size`, `resv_space`, `head`, `tail`, and `space` in `u32` dwords matching `struct guc_ct_buffer_desc`, whereas `iosys_map` accesses on `h2g->cmds`/`g2h->cmds` and KLV sizes (`GUC_KLV_SELF_CFG_*_CTB_SIZE_KEY`) must be scaled by `sizeof(u32)`. `next_ct_seqno` must mask `ct->fence_seqno++` with `CT_SEQNO_MASK` (`GENMASK(14, 0)`) and set `CT_SEQNO_UNTRACKED` (`BIT(15)`) only when `!is_g2h_fence`. [F1144, F1179]
- In `xe_guc_capture.c`: 64-bit registers in `struct __guc_mmio_reg_descr` tables must be consecutive `REG_64BIT_LOW_DW` (`regname = NULL`) then `REG_64BIT_HI_DW` (`regname` non-NULL) entries; every `struct __guc_mmio_reg_descr_group` array searched by `guc_capture_get_one_list` (including `guc->capture->extlists`) must end with a `.list == NULL` sentinel; loops unlinking from `outlist`/`cachelist` must use `list_for_each_entry_safe*`; and `guc_capture_extract_reglists()` skipping `datatype > GUC_STATE_CAPTURE_TYPE_ENGINE_INSTANCE` must drain all `numregs` entries via `guc_capture_log_get_register()` before `continue`. [F1135, F1150, F1168, F1170]
- `vf_lookup_reg` uses `bsearch` with `vf_runtime_reg_cmp` on `gt->sriov.vf.runtime.regs`, so `runtime->regs` must stay sorted by ascending GSI-adjusted `offset` and callers like `xe_gt_sriov_vf_read32` must pass `xe_mmio_adjusted_addr(&gt->mmio, reg.addr)`. In `xe_guc_engine_activity.c`, `allocate_engine_activity_group` sizes `eag` to `xe_sriov_pf_get_totalvfs(xe) + 1` on PF and `engine_activity_enable_function_stats` sets `num_functions = num_vfs + 1`, gated by `is_function_valid`. [F1157, F1158]
- `guc_bo_ggtt_addr` requires every GuC BO to be mapped in the target GuC's tile GGTT (`__xe_bo_ggtt_addr`) at `addr >= xe_wopcm_size(xe)` and `xe_bo_size(bo) <= GUC_GGTT_TOP - addr`. `GUC_LOG_*` in `guc_ctl_log_params_flags` and `XE_G2G_REGISTER_SIZE` in `guc_action_register_g2g_buffer` encode 0-based unit counts (`size / UNIT - 1`), whereas hardware `DOORBELLS_PER_SQIDI_MASK` in `guc_doorbell_init` requires `+ 1`. [F1159, F1160]
- In `__xe_guc_upload`, `guc_write_params` and `guc_prepare_xfer` must run before `guc_xfer_rsa` and `xe_uc_fw_upload`. `guc_enable_irq` must unmask `GUC_SG_INTR_MASK` via `xe_mmio_rmw32` (`ENGINE0_MASK` on media GTs, `ENGINE1_MASK` on primary GTs). In `pc_set_cur_freq`, `RP_CONTROL` must be set to `RPSWCTL_ENABLE` via `pc_set_manual_rp_ctrl(pc, true)` before writing `RPNSWREQ` and restored to `RPSWCTL_DISABLE` after waiting 100-300 us. [F1204, F1206, F1213]
- `xe_dss_mask_t`, `xe_eu_mask_t`, and `xe_l3_bank_mask_t` must be populated from 32-bit fuse registers via `bitmap_from_arr32` (or `bitmap_set_value8` on a zeroed mask) and sized with `XE_MAX_*_BITS` rather than `sizeof` on array parameters; pre-Xe_HP fuse registers (`GRAPHICS_VERx100(xe) < 1250` in `load_eu_mask`, non-DG2/PVC `< 1270` in `load_l3_bank_mask`) have inverted polarity and must be bitwise-negated first. `struct kobj_gt::base` must stay at offset 0 of `struct kobj_gt` because `xe_gt_sysfs_kobj_release` calls `kfree(kobj)`. [F1195, F1199, F1216]

## Synchronization
- In `h2g_write`, copying command words to `h2g->cmds` via `xe_map_memcpy_to` must be followed by `xe_device_wmb(xe)` before writing `h2g->info.tail` via `desc_write`. [F1084]
- `ct->fast_lock` protects `ct->ctbs.g2h.info.space`, `ct->ctbs.g2h.info.head`, and `ct->g2h_outstanding`; `__guc_ct_send_locked` must hold it continuously across `has_room`, `h2g_write`, and `__g2h_reserve_space` when `g2h_len > 0`. Because `xe_guc_ct_fast_path()` takes `ct->fast_lock` in hardirq context, process-context callers must use `spin_lock_irq(&ct->fast_lock)` (or `spin_lock_irqsave`). [F1085, F1223]
- `ct->lock` is primed under `fs_reclaim_acquire(GFP_KERNEL)` in `primelockdep()`, so holders of `ct->lock` must never use `GFP_KERNEL` allocations (use `GFP_ATOMIC`/`GFP_NOWAIT` or drop `ct->lock` before retrying as in `guc_ct_send_recv()`). `xe_guc_ct_disable` and `xe_guc_ct_stop` must transition `ct->state` via `guc_ct_change_state` and release `ct->lock`/`ct->fast_lock` before synchronously canceling `ct->safe_mode_worker` and `ct->g2h_worker`. [F1087, F1222]
- With workaround 22019338487, `xe_guc_pc_set_max_freq` must call `wait_for_flush_complete(pc)` before taking `pc->freq_lock`, and `xe_guc_pc_remove_flush_freq_limit` must clear `pc->flush_freq_limit` under `pc->freq_lock` and call `wake_up_var(&pc->flush_freq_limit)` after unlocking. `pc_action_query_task_state`, `enable_engine_activity_stats`, and `enable_function_engine_activity_stats` must use blocking `xe_guc_ct_send_block`. [F1093, F1094]
- `xe_guc_id_mgr` and `xe_guc_db_mgr` are protected by `guc->submission_state.lock` (`idm_mutex` / `dbm_mutex`); callers holding it must use `*_locked` helpers and callers not holding it must use non-`_locked` helpers. [F1232]

## Object Lifetimes
- Sub-allocations from `xe_guc_buf_reserve()` or `xe_guc_buf_from_data()` must be checked with `xe_guc_buf_is_valid()` before accessing `buf.sa` and freed with `xe_guc_buf_release()` (or `CLASS(xe_guc_buf*)`). In `guc_g2g_alloc()`, GT 0 creates a managed BO (`owned = true`) while non-zero GTs call `xe_bo_get()` (`owned = false`), so `guc_g2g_fini()` must call `xe_bo_put(guc->g2g.bo)` only when `!guc->g2g.owned` and set `guc->g2g.bo = NULL`. [F1068, F1074]
- Pre-allocated `struct __guc_capture_parsed_output` nodes in `devcoredump->snapshot.matched_node` must set `node->locked = 1` (preventing recycling from `outlist`) and be freed to `cachelist` via `guc_capture_free_outlist_node()` when replaced in `xe_engine_snapshot_capture_for_queue()` or released in `xe_guc_capture_put_matched_nodes()`. `guc_capture_init_node()` must save `node->reginfo[i].regs` before `memset(node, 0, sizeof(*node))`, zero the reg arrays, and restore the pointers and `node->link`. [F1076, F1097, F1112]
- When `vf_prepare_runtime_info()` frees an undersized `gt->sriov.vf.runtime.regs` via `drmm_kfree()`, it must clear `regs = NULL`, `num_regs = 0`, and `regs_size = 0` before `drmm_kcalloc()`, and `vf_query_runtime_info()` must call `vf_prepare_runtime_info(gt, 0)` on failure. [F1079]
- On DGFX, `xe_guc_realloc_post_hwconfig` and `xe_guc_ct_init_post_hwconfig` replace `guc->fw.bo`, `guc->log.bo`, `guc->ads.bo`, and `guc->ct.bo` via `xe_managed_bo_reinit_in_vram`, so `guc_init_params_post_hwconfig`, `xe_guc_ads_populate`, and `xe_guc_ct_enable` must refresh cached GGTT addresses and `iosys_map` views afterward. `xe_guc_comm_init_early` must run before any GuC MMIO communication so `guc->notify_reg` is initialized before `xe_guc_notify`. [F1193, F1200]

## API Contracts
- G2H handlers called from `process_g2h_msg` run under `ct->lock` inside `dequeue_one_g2h` and must send CT messages via `xe_guc_ct_send_g2h_handler` (`g2h_len = 0`, `g2h_fence = NULL`) rather than `xe_guc_ct_send*`. In `__guc_ct_send_locked`, `g2h_len` and `num_g2h` must both be `0` or both be non-zero, and both must be `0` when `g2h_fence` is non-NULL. [F1086, F1115]
- `xe_guc_ct_send_recv*` returns response length in dwords when `response_buffer` is non-NULL (which must hold up to `GUC_CTB_MAX_DWORDS`), `GUC_HXG_RESPONSE_MSG_0_DATA0` when NULL (`xe_guc_ct_send_block`), or negative errno. `xe_guc_mmio_send_recv` and `xe_guc_mmio_send` return negative errno or non-negative `DATA0` (callers expecting no payload must treat `ret > 0` as `-EPROTO`, and `guc_self_cfg` treats `ret == 0` as `-ENOKEY`), and non-NULL `response_buf` in `xe_guc_mmio_send_recv` must be sized to at least `VF_SW_FLAG_COUNT` (`GUC_MAX_MMIO_MSG_LEN`) dwords. [F1098, F1099, F1100]
- `xe_guc_buf_reserve` / `CLASS(xe_guc_buf, ...)` take size in `u32` dwords, whereas `xe_guc_buf_from_data` / `CLASS(xe_guc_buf_from_data, ...)` take size in bytes; callers writing indirect H2G data into a buffer must pass `xe_guc_buf_flush(buf)` rather than `xe_guc_buf_gpu_addr(buf)` to the H2G action. [F1103, F1236]
- `xe_guc_id_mgr_reserve*` and `xe_guc_db_mgr_reserve*` return a non-negative ID (`0` is valid) or negative errno; store in `int` and check `< 0`. Both `xe_guc_id_mgr_init` and `xe_guc_db_mgr_init` accept `~0U` for full capacity, but passing `0` to `xe_guc_id_mgr_init` returns `-EINVAL` whereas `xe_guc_db_mgr_init(dbm, 0)` succeeds with `dbm->count == 0` and `dbm->bitmap == NULL`. [F1104, F1105]
- In `xe_guc_pc.c`, `xe_guc_pc` APIs and SLPC unslice params use MHz, whereas `RPNSWREQ`, `MTL_*`, `GT_PERF_STATUS`, and `task_state_data.freq` use 16.66 MHz (`50/3 MHz`) units via `encode_freq`/`decode_freq`, and `xe_pcode_init_min_freq_table` uses 50 MHz units; `decode_freq`, `encode_freq`, and `pc_init_pcode_freq` must use `DIV_ROUND_CLOSEST` with `GT_FREQUENCY_MULTIPLIER` (50) and `GT_FREQUENCY_SCALER` (3). [F1116, F1181]
- `get_capture_list` in `xe_guc_ads.c` returns `false` on success and `true` when the caller must write `null_ggtt`, whereas `xe_guc_capture_getlistsize` and `xe_guc_capture_getlist` return `0` on success or negative errno. Callers of `gen_l3_mask_from_pattern` must zero-initialize stack `xe_l3_bank_mask_t` (`= {}`) and ensure `pattern` has no bits `>= patternbits` and `patternbits * (__fls(mask) + 1) <= XE_MAX_L3_BANK_MASK_BITS` (64). [F1114, F1120, F1183]
- `guc_debugfs_show` files must sit in a direct child directory of `gt#`, while subdirectories using `xe_gt_debugfs_simple_show` (like `vf`) must set `d_inode->i_private = gt`. In `xe_guc_debugfs_register`, guard `pf_only_debugfs_list` with `!IS_SRIOV_VF(xe)` and `slpc_debugfs_list` with `!IS_SRIOV_VF(xe) && !xe->info.skip_guc_pc`. [F1196, F1242]

## Error Handling
- `allocate_engine_activity_buffers()` must unpin `metadata_bo` via `xe_bo_unpin_map_no_vm()` if allocating `activity_bo` fails, and `engine_activity_enable_function_stats()` must call `free_engine_activity_buffers()` and reset `num_functions = 0` on failure. Because consumers NULL-check struct BO/suballocator pointers (`ct->bo`, `log->bo`, `ads->bo`, `pc->bo`, `guc->hwconfig.bo`, `cache->sam`, `buffer->metadata_bo`, `buffer->activity_bo`), init functions must check `IS_ERR` on a local variable before assigning to the struct field. [F1075, F1109]
- In `guc_ct_send_recv`, call `g2h_fence_init(&g2h_fence, response_buffer)` initially and on `goto retry` (when `g2h_fence.retry` is set) to reset `seqno` to `~0x0`, whereas `goto retry_same_fence` (after `-ENOMEM` `GFP_KERNEL` `xa_store` or `retry_failure`) must preserve `g2h_fence.seqno`. In `parse_g2h_response`, `CT_SEQNO_UNTRACKED` must trigger `CT_DEAD` and return `-EPROTO`, whereas a NULL `xa_erase(&ct->fence_lookup, fence)` on a tracked fence must release `GUC_CTB_HXG_MSG_MAX_LEN` via `g2h_release_space` and return `0`. [F1101, F1247, F1248]
- `xe_guc_ads_populate*` must first zero `ads->bo` with `xe_map_memset` and then set unused `system_info.mapping_table` slots to `GUC_MAX_INSTANCES_PER_CLASS` via `guc_mapping_table_init_invalid`. `guc_capture_extract_reglists` must clamp `numregs` to `guc->capture->max_mmio_per_node`. SLPC CT helpers in `xe_guc_pc.c` must suppress `xe_gt_err` when `xe_device_wedged(pc_to_xe(pc)) && ret == -ECANCELED`. [F1113, F1153, F1249]

## External Contracts
- `GUC_ACTION_HOST2GUC_SELF_CFG` (`guc_self_cfg`) and `XE_GUC_ACTION_CLIENT_SOFT_RESET` (`xe_guc_suspend`) must be sent over MMIO via `xe_guc_mmio_send` rather than over CT. `load_l3_bank_mask` and `xe_gt_topology_dump` must gate L3 bank mask population/reporting on `xe_gt_topology_report_l3(gt)` to exclude Xe3+ media GTs (`MEDIA_VER >= 30`). [F1209, F1244]

## Known Pitfalls
- `g2h_read` must compute signed `s32 avail = tail - g2h->info.head` (adding `g2h->info.size` if `< 0`), verify `len <= avail`, and split wrap-around copies when `(len - 1) + head > g2h->info.size`, scaling `&g2h->cmds` `iosys_map` offsets/lengths by `sizeof(u32)` while keeping `u32 *msg` pointer arithmetic in dwords. `guc_capture_log_remove_bytes` requires dword-aligned `bytes_needed` and must subtract `avail % sizeof(u32)` from `copy_size` before wrapping `buf->rd` to 0. [F1146, F1152, F1192]
- `xe_guc_klv_print` and `xe_guc_klv_count` must verify `num_dwords >= GUC_KLV_LEN_MIN` before reading `klvs[0]` and check `num_dwords >= len` (after subtracting `GUC_KLV_LEN_MIN`) before advancing `klvs`. In `vf_query_runtime_info`, validate `ret >= VF2PF_QUERY_RUNTIME_RESPONSE_MSG_MIN_LEN`, `(ret - VF2PF_QUERY_RUNTIME_RESPONSE_MSG_MIN_LEN) % 2 == 0`, `count == num`, and on continuation chunks (`start != 0`) `start + num <= gt->sriov.vf.runtime.num_regs`. [F1155, F1156]
- Cast high `u32` dwords to `u64` before `<< 32` (`make_u64*`) when reconstructing 64-bit KLV, GGTT, or captured register values, and pass `(int)(len * sizeof(u32))` as the `%*ph` width for `u32` arrays. In `xe_guc_engine_activity.c`, use `mul_u64_u32_div(ns, freq, NSEC_PER_SEC)` in `cpu_ns_to_guc_tsc_tick`, and in `get_engine_active_ticks` truncate `gpm_ts` with `lower_32_bits(gpm_ts)` before subtracting `cached_activity->last_update_tick`. [F1174, F1176, F1177, F1198]
- `CT_DEAD_*` enum constants in `xe_guc_ct.c` must remain sequential bit indices (`0..31`) rather than hex masks because callers shift `1 << reason_code`. In `xe_guc_mmio_send_recv`, read back `VF_SW_FLAG(LAST_INDEX)` / `MED_VF_SW_FLAG(LAST_INDEX)` via `xe_mmio_read32` after writing request dwords and before calling `xe_guc_notify(guc)`. [F1178, F1207]
