# TC subsystem — net/sched (part 3)

Generic packet scheduler core (`net/sched/sch_generic.c`) and 17 Qdiscs (`sch_htb`, `sch_hfsc`, `sch_qfq`, `sch_prio`, `sch_multiq`, `sch_mq`, `sch_mqprio`, `sch_ingress`, `sch_gred`, `sch_red`, `sch_pie`, `sch_hhf`, `sch_sfb`, `sch_sfq`, `sch_skbprio`, `sch_plug`), managing Qdisc lifecycle, grafting, enqueue/dequeue, bulk dequeuing, watchdogs, and QoS offloads.

## Architecture & Data Flow

- `noqueue_init()` must set `qdisc->enqueue = NULL` so `__dev_queue_xmit()` and `dev_deactivate_queue()` detect noqueue; mutations to `qdisc->state`, `refcnt`, or `dev_queue` (`transition_one_qdisc`, `qdisc_deactivate`) must check `!(qdisc->flags & TCQ_F_BUILTIN)` to protect `noop_qdisc`. [F239, F250]
- `dev_activate()` must return early if `!netif_carrier_ok(dev)` without transitioning `dev_queue->qdisc` to `qdisc_sleeping` or calling `netdev_watchdog_up()`. In `mq_change_real_num_tx()`, only per-queue `qdisc_sleeping` with `qdisc != &noop_qdisc && !qdisc->handle` may be added/removed in the Qdisc hash. [F327, F336]
- When `qdisc_create_dflt()` returns `NULL` for a default leaf (`htb_change_class`, `hfsc_change_class`, `qfq_change_class`, `prio_graft`), fall back to `&noop_qdisc` and skip `qdisc_hash_add()`. [F242]
- When `->change()` drops excess packets for a lowered `sch->limit`, dequeue via `qdisc_dequeue_internal()` and pass counts to `qdisc_tree_reduce_backlog()`. On `TCQ_F_CPUSTATS` Qdiscs (`pfifo_fast_reset`), `->reset()` must zero per-CPU `cpu_qstats` `backlog` and `qlen`. [F247, F248]
- In `dequeue_skb()`, SKBs from `q->gso_skb` set `*validate = false` unless `xfrm_offload(skb)`. Without `qdisc_may_bulk(q)`, `try_bulk_dequeue_skb_slow()` must stop chaining and stash any SKB with a mismatched `skb_get_queue_mapping()` into `q->skb_bad_txq` via `qdisc_enqueue_skb_bad_txq()`. [F356, F358]
- In `struct htb_class`, `cl->level` discriminates the `leaf` (`0`) vs `inner` (`> 0`) union; check `!cl->level` before accessing `cl->leaf`, and when changing between leaf and inner (`htb_change_class`, `htb_parent_to_leaf`), erase `cl->pq_node` from `q->hlevel[old_level].wait_pq` before updating `cl->level` and zeroing `inner`. [F240, F255]
- Child `dequeue()` (`netem`) can drop packets and invoke `qdisc_tree_reduce_backlog()` -> `htb_qlen_notify()` -> `htb_deactivate()`, so `htb_deactivate()` must return early if `!cl->prio_activity`, `htb_next_rb_node()` must check `if (*n)`, and `htb_lookup_leaf()`/`htb_dequeue_tree()` must handle `hprio->row.rb_node == NULL` mid-dequeue. [F207, F254]
- `htb_change_class_mode()` must call `htb_deactivate_prios()` before `cl->cmode = new_mode` and `htb_activate_prios()` after. `htb_remove_class_from_row()` must advance `hprio->ptr` via `htb_next_rb_node()` if equal to `cl->node + prio`, and `htb_deactivate_prios()` must save `cl->common.classid` in `last_ptr_id` and clear `ptr = NULL` before `htb_safe_rb_erase()`. [F252, F253]
- `htb_add_to_wait_tree()` must increment `cl->pq_key` if `cl->pq_key == q->now` so `htb_do_events()` terminates. `htb_init()` must clamp `q->rate2quantum >= 1`, and `htb_change_class()` must compute `cl->quantum` via `do_div()` and clamp to `INT_MAX`. [F286, F308]
- When HTB offload (`q->offload`) detaches a leaf (`htb_change_class`, `htb_destroy_class_offload`), add `old_q->bstats` into `parent->bstats_bias`. In `htb_destroy()` with `q->offload`, the `do { ... } while (changed)` loop must skip inner classes (`cl->level > 0`) and call `htb_parent_to_leaf(sch, cl, NULL)` when `last_child` is true. [F256, F288]
- In `hfsc_change_class()` and `hfsc_dequeue()`, re-check `cl->qdisc->q.qlen != 0` after `qdisc_peek_len(cl->qdisc)` before `init/update_ed()`, `update_d()`, or `init/update_vf()`. Any `cftree_insert/update/remove()` must call `update_cfmin(cl->cl_parent)`. [F258, F260]
- In `hfsc_change_class()`, upgrade any non-root `parent` lacking `HFSC_FSC` via `hfsc_upgrade_rt(parent)` under `sch_tree_lock(sch)`. In `hfsc_classify()` and `hfsc_bind_tcf()`, a filter on `head` may only resolve to `cl` with `cl->level < head->level` (`p->level > cl->level`). [F259, F289]
- In `sch_hfsc.c`, `m2sm()`, `m2ism()`, and `d2dx()` must widen `m`/`d` to `u64`, add `divisor - 1` before `do_div()`, and return `HT_INFINITY` in `m2ism()` when `m == 0`. `psched_ratecfg_precompute__()` must return `*mult = 1, *shift = 0` when `rate == 0`, and stop when `*mult & (1U << 31)` or `factor & (1ULL << 63)`. [F300, F302]
- In `sch_qfq.c`, `qfq_update_agg()` and `qfq_destroy_agg()` must update `q->nonfull_aggs`, `agg->budgetmax`, `agg->inv_w`, `q->wsum`, and `q->iwsum` in lockstep, advancing `q->in_serv_agg` via `qfq_choose_next_agg(q)` if equal. `qfq_change_class()` and `qfq_change_agg()` must check `lmax <= QFQ_MAX_LMAX` (and `>= QFQ_MIN_LMAX` in `qfq_change_class()`). [F261, F276]
- In `sch_qfq.c`, `qfq_slot_scan/rotate()` must shift `grp->full_slots` and advance `grp->front` modulo `QFQ_MAX_SLOTS` in lockstep, `qfq_slot_insert()` must cap `slot` at `QFQ_MAX_SLOTS - 2`, and virtual timestamp comparisons must use `qfq_gt(a, b)`. [F262, F304]
- In `sch_hhf.c`, `q->hhf_valid_bits[i]` (`HHF_ARRAYS_LEN` divisible by `BITS_PER_LONG`) shadows `q->hhf_arrays[i]`; `hhf_classify()` must check `test_bit()` and zero the counter if clear. `hhf_change()` must widen `new_quantum` to `u64` before `* new_hhf_non_hh_weight` (rejecting `0` or `> INT_MAX`), and timestamps must use `hhf_time_before(a, b)`. [F263, F309, F310, F324]
- In `sch_gred.c`, `gred_vqs_validate()` must verify `dp < table->DPs` and `dp == cdp || table->tab[dp] != NULL` before `gred_vqs_apply()`. Changing `grio` or VQ `prio` must call `gred_wred_mode_check(sch)`, and in `GRED_WRED_MODE`, `gred_enqueue()` must sync `q->vars` with `table->wred_set` via `gred_load/store_wred_set()`. [F266, F278]
- In `sch_mqprio.c`, `dev->num_tx_queues` must be `< TC_H_MIN_PRIORITY` (`0xFFE0`). In `mqprio_walk()`, if `ntx < TC_MAX_QUEUE` after the TC loop, pad `arg->count` and `ntx` to `TC_MAX_QUEUE` before `- TC_MAX_QUEUE`. `TCA_MQPRIO_TC_ENTRY_INDEX` policy max is `TC_QOPT_MAX_QUEUE - 1`, and `mqprio_parse_nlattr()` rate loops must check `nla_len(attr) == sizeof(u64)` and `i < qopt->num_tc`. [F268, F269, F271, F297]
- In `sch_sfq.c`, `sfq_change()` must reject `(int)ctl->quantum < 0`, `ctl->perturb_period < 0 || > INT_MAX / HZ`, and—after clamping `limit` to `maxdepth * maxflows`—reject `limit == 1`. `struct sfq_slot` must keep `skblist_next/prev` first; `sfq_index < SFQ_MAX_FLOWS` indexes `q->slots[]` while `>= SFQ_MAX_FLOWS` uses `sfq_dep_head()`, and 1-based handles from `sfq_classify/walk()` require `- 1` before indexing `q->ht[]`. [F273, F274, F275, F313, F318]
- `pie_process_dequeue()` and `pie_calculate_probability()` must check `dtime != 0` and `vars->avg_dq_rate > 0` before dividing. `skbprio_enqueue()` must clamp `skb->priority` to `SKBPRIO_MAX_PRIORITY - 1` and keep `q->lowest_prio`/`q->highest_prio` on non-empty buckets when `sch->q.qlen > 0` (`BUG_ON(!to_drop)`). [F281, F311]

## Synchronization

- In `sch_direct_xmit()`, release `qdisc_lock(q)` before `validate_xmit_skb_list()` and `HARD_TX_LOCK()`, and re-acquire it only after `HARD_TX_UNLOCK()` before `dev_requeue_skb()`. On `TCQ_F_NOLOCK` Qdiscs, `dequeue_skb()`, `dev_requeue_skb()`, and `*bad_txq()` must hold `qdisc_lock(q)` around `q->gso_skb` and `q->skb_bad_txq` (re-checking `skb_peek(&q->gso_skb)` after locking). [F210, F211]
- `qdisc_maybe_clear_missed()` must follow `clear_bit(__QDISC_STATE_MISSED, &q->state)` with `smp_mb__after_atomic()` before re-checking `netif_xmit_frozen_or_stopped(txq)`. In `pfifo_fast_dequeue()`, if bands appear empty while `READ_ONCE(qdisc->state) & QDISC_STATE_NON_EMPTY` and `need_retry`, set `need_retry = false`, clear `MISSED`/`DRAINING`, issue `smp_mb__after_atomic()`, and retry once. [F212, F213, F293]
- `dev_watchdog()` must check `netif_xmit_stopped(txq)`, then `smp_mb()`, before `READ_ONCE(txq->trans_start)`. `netif_tx_lock/unlock()` and `dev_watchdog()` must hold `dev->tx_global_lock` around `netif_freeze/unfreeze_queues()`, and `netif_freeze_queues()` must take `__netif_tx_lock(txq, cpu)` when setting `__QUEUE_STATE_FROZEN`. [F215, F343]
- `mini_qdisc_pair_swap()` (under `chain0->filter_chain_lock`) must wait on `miniq->rcu_state` before updating `miniq->filter_list` and `*miniqp->p_miniq`, then set `miniq_old->rcu_state = start_poll_synchronize_rcu()`. Datapath `htb/hfsc/qfq_classify()` and `qdisc_calculate_pkt_len()` must read `filter_list` and `sch->stab` via `rcu_dereference_bh()`. [F219, F353]
- `sch_tree_lock(sch)` disables BH: `GFP_KERNEL` allocations, `ndo_setup_tc`, and `qdisc_put()` / `*_destroy_class()` (`lockdep_unregister_key()` sleeps) must run outside it. When detaching/replacing a child Qdisc (`prio_tune`, `multiq_tune`, `__red_change`, `sfb_change`, `htb_delete`, `hfsc/qfq_delete_class`), call `qdisc_purge_queue()` (or `qdisc_replace()`) under `sch_tree_lock(sch)` before unlocking and calling `qdisc_put()`. [F221, F223, F338]
- Child Qdiscs (`netem`) can re-enter parent `enqueue()` during `qdisc_enqueue()`, so after `qdisc_enqueue()`, `hfsc_enqueue()` must check `!cl_in_el_or_vttree(cl)` and `qfq_enqueue()` must check `cl_is_active(cl)`. `qfq_change_agg()` runs in BH context and must use `GFP_ATOMIC`; all control/dump accesses to `cl->agg` (`qfq_change/delete/dump_class*`) must hold `sch_tree_lock(sch)`. [F206, F222, F340]
- `skbprio_change()` (`sch->limit`) and `hfsc_change_qdisc()` (`q->defcls`) run without `sch_tree_lock(sch)`, requiring `WRITE_ONCE()`/`READ_ONCE()`. `pfifo_fast_change_tx_queue_len()` must use `skb_array_resize_multiple_bh()` for `page_pool` safety. Timer callbacks (`pie_timer`, `red_adaptative_timer`, `sfq_perturbation`) must hold `rcu_read_lock()` around `qdisc_lock(qdisc_root_sleeping(sch))`, and callers under `sch_tree_lock(sch)` must use `timer_delete()`, not `timer_delete_sync()`. [F228, F341, F345]

## Object Lifetimes

- `htb_init()` and `hfsc_init_qdisc()` must call `qdisc_watchdog_init()` (and `INIT_WORK()` in HTB) before any fallible check. Qdisc `->destroy()` (`htb`, `pie`, `red`, `sfq`) must synchronously cancel work/timers (`cancel_work_sync()`, `qdisc_watchdog_cancel()`, `timer_delete_sync()` after zeroing `tupdate`/`perturb_period`) before freeing data or child Qdiscs. [F225, F346]
- In `htb_destroy()`, `hfsc_destroy_qdisc()`, and `qfq_destroy_qdisc()`, all `tcf_block_put()` calls must finish before freeing any class (`*_destroy_class`), as filter teardown invokes `.unbind_tcf`. In `sch_hfsc.c`, `q->root` is embedded in `struct hfsc_sched`, so `hfsc_destroy_class()` must guard `kfree(cl)` with `cl != &q->root` and `hfsc_delete_class()` must reject `cl == &q->root`. [F321, F372]
- With HTB offload (`q->offload`), both `cl->leaf.q` and `dev_queue->qdisc_sleeping` reference a leaf's child Qdisc, so `htb_graft()`, `htb_parent_to_leaf_offload()`, and `htb_change_class()` must call `qdisc_refcount_inc()` before `htb_graft_helper()`. `ingress/clsact_init/destroy()` must track `bpf_mprog_entry` users via `tcx_miniq_inc/dec()`, freeing only when `!tcx_entry_is_active(entry)`. `gred_change_vq()` must set `*prealloc = NULL` when consuming `prealloc`. [F196, F201, F205]

## API Contracts

- `qdisc_create_dflt()` and `__qdisc_destroy()` must use `bpf_try_module_get/put(ops, ops->owner)`. `qdisc_alloc()` returns `ERR_PTR` (requiring `ops->priv_size >= sizeof` `qdisc_priv(sch)`), `fifo_create_dflt()` returns `ERR_PTR`, and `qdisc_create_dflt()` returns `NULL` on error. [F191, F229, F316]
- `__skb_dequeue_bad_txq()` and `qdisc_dequeue_skb_bad_txq()` return `SKB_XOFF_MAGIC` (`1UL`) when the TXQ is stopped/frozen; `dequeue_skb()` must check `skb == SKB_XOFF_MAGIC` and return `NULL`. Helpers unlinking from `skb->next` (`try_bulk_dequeue_skb*`, `dequeue_head` in `sch_hhf.c`) must call `skb_mark_not_on_list()` on the tail SKB. [F230, F355]
- In `__qdisc_run()` and `dev_requeue_skb()`, `TCQ_F_NOLOCK` Qdiscs set `__QDISC_STATE_MISSED`, while locked Qdiscs call `__netif_schedule(q)`. Parent Qdiscs peeking a child (`prio/hfsc/agg_dequeue`) must dequeue via `qdisc_dequeue_peeked(child)`. Array-indexed classful Qdiscs (`prio`, `multiq`, `mq`, `mqprio`, `sfq`, `skbprio`) return 1-based cookies from `.find`/`.bind_tcf` and must subtract `1` before indexing arrays. Private `qdisc_skb_cb(skb)->data` structs (`sfb_skb_cb`) must call `qdisc_cb_private_validate()`. [F245, F359, F360, F362]
- Callers of `dev_graft_qdisc()` when `dev->flags & IFF_UP` must bracket it with `dev_deactivate/activate(dev)`. Offload helpers (`mq`, `htb`, `gred`, `red`, `prio`) must check both `tc_can_offload(dev)` and `ndo_setup_tc`. `__red_change()`, `gred_change_vq()`, and `sfq_change()` must call `red_check_params()` before `red_set_parms()`. [F312, F328, F335]
- `mqprio_init()` must query `qdisc_offload_query_caps()`, validate `qopt` via `mqprio_validate_qopt()` (checking queue counts when `!qopt->hw || caps->validate_queue_counts`) before `mqprio_parse_nlattr()` or `netdev_set_tc_queue()`, and reject `TC_FP_PREEMPTIBLE` unless `ethtool_dev_mm_supported(dev)`. With `qopt->hw`, `mqprio_enable_offload()` uses `ndo_setup_tc` instead of `netdev_set_num_tc/tc_queue()`, and `mqprio_destroy()` calls `mqprio_disable_offload()` if `priv->hw_offload` or `netdev_set_num_tc(dev, 0)` otherwise. [F270, F333, F334]

## Error Handling

- Because `qdisc_create()`/`__qdisc_destroy()` call `ops->reset/destroy()` on partial `ops->init()` failure, `gred_destroy()`, `pfifo_fast_reset/destroy()`, and `hhf_destroy()` must NULL-check `table->opt`, `q->ring.queue`, and `q->hh_flows`. In `htb_init()`, set `q->offload = true` only after `htb_offload()` (`TC_HTB_CREATE`) and all fallible steps succeed; if `htb_offload()` fails after `old = htb_graft_helper(dev_queue, NULL)` while `!destroying`, restore `htb_graft_helper(dev_queue, old)`. [F234, F241, F331]
- Classful schedulers (`htb_activate`, `htb_dequeue_tree`, `hfsc_dequeue`, `qfq_peek_skb`) must treat a child having `q.qlen == 0` after `qdisc_enqueue()` or returning `NULL` from `dequeue`/`peek` as recoverable (`qdisc_warn_nonwc()`), never `WARN_ON`. Hot-path warnings in `sch_direct_xmit()`, `gred_dequeue()`, and `htb_do_events()` must be rate-limited or once-only. [F364, F365]

## External Contracts

- Dump callbacks serializing stack UAPI structs (`htb_dump_class`, `gred_dump`, `sfq_dump`, `qfq_dump_class_stats`, `mqprio_dump`) must zero-initialize them; `gred_dump()` must append all `MAX_DPs` `tc_gred_qopt` entries in `TCA_GRED_PARMS` (`opt.DP = MAX_DPs + i` when `table->tab[i]` is NULL). `mqprio_parse_nlattr()` must offset trailing attributes by `NLA_ALIGN(sizeof(*qopt))` and reject them when `!qopt->hw`. Microsecond attributes in `sch_pie/hhf.c` and tick attributes (`buffer`/`cbuffer`, plus `HTB_VER >> 16` check) in `sch_htb.c` must convert units via `PSCHED_TICKS2NS/NS2TICKS` or `usecs_to_jiffies/jiffies_to_usecs`. [F279, F367, F368, F369, F370]

## Known Pitfalls

- In `htb_dequeue_tree()`, when deactivating an empty class (`htb_deactivate(q, cl)`) with `cl == start`, update `start = next` (`htb_lookup_leaf(hprio, prio)`) before `goto next` so `while (cl != start)` terminates. In `multiq_tune()`, size `removed` for `q->max_bands - qopt->bands` (not `q->max_bands - q->bands`). [F285, F315]
- In `sch_hfsc.c`, `seg_x2y()` and `seg_y2x()` must split `x`/`y` into upper (`>> SM_SHIFT`/`ISM_SHIFT`) and lower (`& SM_MASK`/`ISM_MASK`) parts before multiplying by `sm`/`ism`, and `seg_y2x()` must return `HT_INFINITY` if `ism == HT_INFINITY`. In `sch_qfq.c`, `qfq_make_eligible()` must check `last_flip_pos > 31` (`mask = ~0UL`) before `(1UL << last_flip_pos) - 1`, and 32-bit lengths/budgets must be cast to `u64` before multiplying by `inv_w` or `q->iwsum`. [F301, F305, F307]
