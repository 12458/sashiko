# NETFILTER — net/netfilter (part 3)

This unit implements Netfilter connection tracking L4 protocol trackers (TCP, UDP, SCTP, ICMP, ICMPv6, GRE, generic), application-layer helpers (SIP, PPTP, SANE, SNMP, TFTP), TCP sequence adjustment (`nf_conntrack_seqadj.c`), conntrack procfs/sysctl management (`nf_conntrack_standalone.c`), the flowtable fastpath with hardware/TC/XDP/BPF offload (`nf_flow_table_*.c`), and packet logging (`nf_log.c`, `nf_log_syslog.c`).

## Architecture & Data Flow
- `flow_offload_hash*` and `flow_offload_hash_cmp` hash/`memcmp` `struct flow_offload_tuple` up to `offsetof(..., __hash)`. Key fields must precede `__hash`, metadata must follow it, and every tuple passed to `flow_offload_lookup` or inserted into `rhashtable` must be zero-initialized. [F436, F462]
- `flow_offload_fill_route` copies `route->tuple[dir].in.encap[i]` in reverse (`i = num_encaps - 1` down to `0`) into `flow_tuple->encap[j]` and remaps `BIT(i)` of `ingress_vlans` to `BIT(j)` of `in_vlan_ingress` to match `nf_flow_tuple_encap` and `nf_flow_rule_match`. [F463]
- `nf_flow_table_iterate` must check `IS_ERR(tuplehash)` (continuing on `-EAGAIN`, breaking on other errors) and skip `tuplehash->tuple.dir != 0` before `container_of(..., tuplehash[0])`. [F489]
- In `nf_flow_exceeds_mtu()`, GSO packets with `skb->len > mtu` must be checked with `skb_gso_validate_network_len(skb, mtu)` against `tuple.mtu + ctx->offset`; when exceeded, `nf_flow_offload_*_forward()` must return `0` (`NF_ACCEPT`) without refreshing or tearing down the flow. [F545]
- Before `nf_flow_offload_ip*_hook()` calls `nf_flow_xmit_xfrm()`, it must zero `skb->cb` (`inet_skb_parm` / `inet6_skb_parm`), set `iif` to `skb->dev->ifindex`, and set `IPSKB_FORWARDED` / `IP6SKB_FORWARDED`. [F549]
- Flowtable expiration checks (`nf_flow_has_expired`, `flow_offload_fixup_ct`, `nf_flow_offload_stats`) must use `nf_flow_timeout_delta(timeout)` (`(__s32)(timeout - nf_flowtable_time_stamp)`). In `flow_offload_fixup_ct`, `timeout` must be a signed `s32` (clamped to `0` if `< 0`) before subtracting `offload_timeout` and comparing against `nf_flow_timeout_delta(READ_ONCE(ct->timeout))`. [F501, F502]
- Flowtable NAT helpers (`nf_flow_snat_*`, `nf_flow_dnat_*`) must sample the old port/IP before overwriting the header, and UDP checksum updates (`nf_flow_nat_*_udp`) must rewrite `0` to `CSUM_MANGLED_0`. [F460]
- In `nf_ct_seq_adjust()` and `nf_ct_sack_adjust()`, `skb_ensure_writable()` must cover `optend`, `tcph` (`skb->data + protoff`) must be re-derived afterwards, and `inet_proto_csum_replace4` must be called before overwriting `tcph->seq`, `tcph->ack_seq`, or SACK edges. [F461, F540]
- TCP seq/ACK/SACK orderings in `nf_conntrack_proto_tcp.c` and `nf_conntrack_seqadj.c` must use `before()` / `after()`, and peer ACK/SACK comparisons against `correction_pos` must subtract `offset_before` first. [F503]
- `tcp_options` must clamp `td_scale` to `TCP_MAX_WSCALE` (14). Resetting `ip_ct_tcp_state` in `nf_ct_tcp_state_reset` or `tcp_options` must zero `td_scale` and mask `flags &= IP_CT_TCP_FLAG_BE_LIBERAL`. In `tcp_init_sender` and `nlattr_to_tcp`, if either direction lacks `IP_CT_TCP_FLAG_WINDOW_SCALE`, both `td_scale` fields must be zeroed. [F446, F456, F499]
- In `tcp_options`, `tcp_sack`, and `nf_ct_sack_adjust`, option loops must verify `length >= 2` and `opsize >= 2 && opsize <= length` before reading or advancing, and `tcp_sack` must read SACK edges via `get_unaligned_be32`. [F468]
- In `get_conntrack_index`, `rst`, `syn`, and `fin` must be checked before `ack` so control segments with `ACK` do not map to `TCP_ACK_SET`. In `nf_conntrack_tcp_packet`, when `new_state == TCP_CONNTRACK_SYN_SENT` and `old_state >= TCP_CONNTRACK_TIME_WAIT` without `IP_CT_TCP_FLAG_CLOSE_INIT` or a prior same-dir `TCP_RST_SET`, the switch must fall through to `TCP_CONNTRACK_IGNORE`. [F483, F486]
- `nf_conntrack_l4proto_tcp.ctnl_timeout.obj_size` must use `TCP_CONNTRACK_TIMEOUT_MAX` (not `TCP_CONNTRACK_MAX`) to fit `RETRANS` and `UNACK`. In `sctp_new_state`, unmapped chunk types in `switch (chunk_type)` must hit `default` and return `cur_state` unchanged. [F488, F507]
- In `nf_conntrack_proto_icmp*.c`, `invmap` stores target types `+ 1` (`0` = unmapped), and ICMPv6 tables `invmap`/`valid_new` and `noct_valid_new` are indexed by `type - 128` and `icmp6_type - 130` with bounds checks. [F470]
- L4 error validators (`tcp_error`, `udp*_error`, `sctp_error`, `nf_conntrack_icmp*_error`) must only verify checksums when `state->hook == NF_INET_PRE_ROUTING` and `state->net->ct.sysctl_checksum` is enabled. [F550]
- In `conntrack_pptp_help`, `reqlen` must be checked against `pptp_msg_size[msg]` (`1 <= msg <= PPTP_MSG_MAX`) and clamped to `sizeof(*pptpReq)` before `skb_header_pointer`. In `nf_conntrack_sane.c`'s `help()`, check `dataoff < skb->len` and clamp `datalen` to `sizeof(struct sane_reply_net_start)` before `skb_header_pointer`. [F465, F467]
- In `nf_confirm()`, packets at `NF_INET_POST_ROUTING` on an L3 master/VRF output device (`in_vrf_postrouting(state)`) must return `NF_ACCEPT` immediately without running helpers, `nf_ct_seq_adjust()`, or `nf_conntrack_confirm()`. [F547]
- When `nf_ct_netns_do_get` first registers hooks for `nfproto` in a netns, it must run `nf_ct_tcp_fixup` to zero `seen[0..1].td_maxwin` on established TCP connections. [F442]
- `nf_conntrack_standalone_init_sysctl` must `kmemdup` `nf_ct_sysctl_table`, rebind per-netns `.data` pointers, and set `.mode = 0444` on `CT_MAX`, `CT_EXPECT_MAX`, and `CT_BUCKETS` when `!net_eq(&init_net, net)`. `nf_conntrack_hash_sysctl` must sync `nf_conntrack_htable_size_user` from `nf_conntrack_htable_size` before `proc_dointvec` and after `nf_conntrack_hash_resize`. [F443, F453]
- `nf_conntrack_standalone_init_proc()` must create `/proc/net/nf_conntrack` with mode `0440` owned by `net->user_ns` root. In `ct_seq_show`, GC via `nf_ct_kill(ct)` must decrement `st->skip_elems`. `ct_cpu_seq_show()` and `nf_flow_table_cpu_seq_show()` must check `v == SEQ_START_TOKEN` before dereferencing `st`. [F444, F514, F556]
- Packet loggers in `nf_log_syslog.c` must check `nf_log_allowed(net)` (`init_net || sysctl_nf_log_all_netns`) before logging, and `nf_log_all_netns` is registered only in `init_net`. [F557]

## Synchronization
- `flow_offload_teardown()` must gate `flow_offload_fixup_ct(flow)` behind `!test_and_set_bit(NF_FLOW_TEARDOWN, &flow->flags)`. `flow_offload_del` must remove both directional nodes from `rhashtable` before `flow_offload_free`, which must use `kfree_rcu(flow, rcu_head)`. [F412, F529]
- In `nf_flow_table_extend_ct_timeout()` and `ct_seq_show()`, lockless `refcount_inc_not_zero(&ct->ct_general.use)` must be followed by `smp_acquire__after_ctrl_dep()` before reading `ct->status`. [F413]
- Once `nf_ct_is_confirmed(ct)` is true, updates and multi-field reads of `ct->proto.tcp`, `ct->proto.sctp`, and `nf_conn_seqadj` (including in netlink and `flow_offload_fixup_tcp`) must hold `spin_lock_bh(&ct->lock)`. [F524]
- In `ct_get_next()`, after iterating `st->hash[i]` via `hlist_nulls_for_each_entry_rcu()`, it must walk to the nulls marker and verify `get_nulls_value(tmp) == i` before returning `h` (and `get_nulls_value(n) == i` at bucket end), restarting the bucket scan on mismatch. [F422]
- `getorigdst()` and `ipv6_getorigdst()` must copy socket fields under `lock_sock(sk)` / `release_sock(sk)` before `nf_conntrack_find_get()`, and call `nf_ct_put(ct)` before `copy_to_user()`. [F417]
- `nf_ct_proto_mutex` serializes `cnet->users*` and `nf_ct_bridge_info`; `nf_ct_netns_do_get()` must drop it before `request_module("nf_conntrack_bridge")`, reacquire to recheck `nf_ct_bridge_info`, and drop it before `nf_ct_iterate_cleanup_net()`. [F418]
- Updates to `loggers[pf][type]` and `net->nf.nf_loggers[pf]` require `nf_log_mutex` and RCU pointer primitives while `nf_log_packet()`/`nf_log_trace()` read under `rcu_read_lock()`, and `nf_log_unregister()` must call `synchronize_rcu()` after unlocking. [F419]
- `flow_offload_eth_dst()` must hold `read_lock_bh(&n->lock)` while reading `n->nud_state` and copying `n->ha` from `dst_neigh_lookup()` before `neigh_release(n)`. [F424]

## Object Lifetimes
- `nf_flow_table_free()` must unlink `flow_table->list`, cancel `gc_work`, and call `nf_flow_table_offload_flush()` before marking flows for teardown, running `nf_flow_table_gc_run()`, and calling `nf_flow_table_offload_flush_cleanup()` prior to `rhashtable_destroy()`. [F391]
- In `nf_flow_offload_init()` and `nf_flow_offload_tuple()`, `cls_flow->cookie` must point to `&flow->tuplehash[dir].tuple`. For `NF_FLOW_HW` flows, `nf_flow_offload_gc_step()` must not call `flow_offload_del()` until `nf_flow_offload_del()` sets `NF_FLOW_HW_DYING` and `flow_offload_work_del()` sets `NF_FLOW_HW_DEAD`. [F408, F515]
- Because `nf_flow_offload_rule_alloc()`'s `err_flow_match` rollback does not call `__nf_flow_offload_destroy()`, `nf_flow_rule_route_ipv4/ipv6()` must not fail after `flow_offload_redirect()` attaches a `dev_get_by_index()` reference to `entry->dev`. [F393]
- `nf_flow_table_block_setup()` modifies `flowtable->flow_block.cb_list` and frees `block_cb` under `down_write(&flowtable->flow_block_lock)`; `nf_flow_table_indr_cleanup()` must run `nf_flow_table_gc_cleanup()` before taking `flow_block_lock` to unlink and free `block_cb`. [F396]
- `nf_flowtable_by_dev_remove()` unlinks `flow_offload_xdp_ft` nodes with `list_del_rcu()`/`kfree_rcu()`, and when `list_empty(&elem->head)` unlinks `elem->hnode` under `nf_xdp_hashtable_lock` and frees `elem` after `synchronize_rcu()` outside the lock. [F397]
- In `ipv4_conntrack_local()`, when bypassing conntrack for a fragment carrying a template (`nf_ct_is_template(tmpl)`), clear `skb->_nfct = 0` and call `nf_ct_put(tmpl)` before returning `NF_ACCEPT`. In `ct_seq_show()`, every exit after `refcount_inc_not_zero()` must `goto release;` to call `nf_ct_put(ct)`. [F398, F405]
- `nf_ct_netns_get/put` for `NFPROTO_BRIDGE` and `nf_logger_find_get/put` for `NFPROTO_INET` must acquire/release both `NFPROTO_IPV4` and `NFPROTO_IPV6` (rolling back `IPV4` if `IPV6` fails). [F399, F402]
- `nf_ct_set_timeout()` must drop `h->timeout_find_get()` via `__nf_ct_timeout_put(timeout)` on failure, and `nf_ct_destroy_timeout()` must null `timeout_ext->timeout` after `h->timeout_put(t)`. `nf_ct_gre_keymap_destroy()` must set `ct_pptp_info->keymap[dir] = NULL` under `spin_lock_bh(&keymap_lock)` when unlinking and `kfree_rcu()`ing it. [F400, F401]
- `netfilter_log_sysctl_init/exit()` and `nf_lwtunnel_net_init/exit()` must `kfree(table)` only when `!net_eq(net, &init_net)` because `init_net` uses the static table directly. [F404]

## API Contracts
- `nf_ct_seq_offset` takes host-order `u32 seq`, whereas `nf_ct_seqadj_set` takes network-order `__be32 seq`; when adjusting ACK/SACK numbers in `tcp_in_window`, call `nf_ct_seq_offset` with `!dir` and `ack - 1`. [F439]
- `inet_proto_csum_replace2/4/16()` requires `pseudohdr = true` when mangling IPv4/IPv6 addresses and `pseudohdr = false` when mangling L4 ports or TCP seq/SACK numbers. [F544]
- In `nf_conntrack_proto_sctp.c`, `for_each_sctp_chunk` must only run after `do_basic_checks` verifies non-zero `sch->length`, and any `map` passed to `do_basic_checks()` must be zero-initialized and >= 256 bits. [F464, F521]
- In `ct_sip_get_header` and `ct_sip_next_header`, update `*matchoff = dptr - start` before returning `-1` on search/`match_len` failure. All non-void `nf_nat_sip_hooks` callbacks must return `NF_ACCEPT` (1) or `NF_DROP` (0), never negative errnos. [F427, F428]
- All `ctnl_timeout` callbacks (`*_timeout_nlattr_to_obj` / `*_timeout_obj_to_nlattr`) must convert `NLA_U32` attributes between big-endian seconds and jiffies via `ntohl(nla_get_be32(...)) * HZ` and `htonl(timeout / HZ)`. [F553]
- In `bpf_xdp_flow_lookup()`, `opts_len` must equal `NF_BPF_FLOWTABLE_OPTS_SZ` (`4`), and every `NULL` return path must set `opts->error` to a negative errno. [F554]

## Error Handling
- L4 protocol packet/error handlers (`nf_conntrack_*_packet`, `nf_conntrack_inet_error`) must return negated verdicts (`-NF_ACCEPT`, `-NF_REPEAT`) or `NF_DROP` (0), never negative errnos. Invalid packets must be logged via `nf_l4proto_log_invalid()` or `nf_ct_l4proto_log_invalid()`. [F425, F559]
- `nf_ct_seq_adjust` and `nf_ct_sack_adjust` return `1` on success and `0` on failure (unlike `skb_ensure_writable`). `nf_ct_seqadj_set` must check `nfct_seqadj(ct) != NULL` before setting `IPS_SEQ_ADJUST_BIT`. [F429, F434]
- In L4 `ctnl_timeout.nlattr_to_obj` callbacks (`gre`, `udp`, `tcp`, `sctp`), `data` can be `NULL` and must fall back to per-netns timeout storage. [F433]

## External Contracts
- `getorigdst` and `ipv6_getorigdst` must zero-initialize their stack `nf_conntrack_tuple` (and `sin.sin_zero` in `getorigdst`), and `tcp_to_nlattr()` must zero-initialize `struct nf_ct_tcp_flags tmp = {}` before `nla_put()`. [F437, F552]
- In `nf_hooks_lwtunnel_set()`, disabling `nf_hooks_lwtunnel_enabled` (`!enable`) once enabled must return `-EBUSY`. [F561]

## Known Pitfalls
- Recompute `iph`/`ip6h` from `skb_network_header(skb) + ctx->offset` after the second `pskb_may_pull` in `nf_flow_tuple_ip/ipv6`. In `sip_help_tcp`, `process_sip_msg` can reallocate the SKB and change `msglen`, so pass `&dptr` and `&msglen` by reference and update `diff = msglen - origlen`, `tdiff += diff`, and `datalen = datalen + diff - msglen`. [F448, F452]
- In `nf_flow_table_offload.c`, `tuplehash[dir].tuple` supplies `xmit_type`, encap `dst_cache`, and popped VLANs, whereas `tuplehash[!dir].tuple` (`other_tuple`) supplies `FLOW_OFFLOAD_XMIT_NEIGH` egress `iifidx`, neighbour `src_v4`, decap `dst_cache`, and pushed VLAN/PPPoE headers. [F496]
- Use `BIT_ULL()` (never `BIT()` or `1UL << ...`) for `match->dissector.used_keys` and `enc_keys` in `nf_flow_rule_*_match`. Use bit indices (`IPS_*_BIT`, `enum nf_flow_flags`) with `test_bit`/`set_bit`/`clear_bit`, and shifted masks (`IPS_*`, `NF_FLOWTABLE_*`) with bitwise `&`/`|`. [F498, F520]
- In `tcp_in_window`, the zero-ACK workaround for `RST|ACK` must test equality `((tcp_flag_word(tcph) & (TCP_FLAG_ACK|TCP_FLAG_RST)) == (TCP_FLAG_ACK|TCP_FLAG_RST)) && (ack == 0)`. [F484]
- In `nf_conntrack_icmpv6_redirect()`, do not dereference `rd_msg` after the second `skb_header_pointer(..., &tmp.nd_opt)` call because both share the `tmp` bounce union. In `gre_pkt_to_tuple`, request only 8 bytes in `skb_header_pointer` for `_pgrehdr` and only read up to `call_id`. [F466, F512]
- In `nf_conntrack_sip.c`, bound all payload scans by `limit - cp` or `limit - dptr` (never NUL-terminated string helpers or `-1` length to `in4_pton`/`in6_pton`), and in `ct_sip_get_sdp_header`, only dereference `thdr` when `term != SDP_HDR_UNSPEC`. [F471, F519]
- Use `div_s64(delta_time, NSEC_PER_SEC)` in `ct_show_delta_time`, and initialize `buf[0] = '\0'` before `proc_dostring()` on writes in `nf_log_proc_dostring()`. [F500, F518]
