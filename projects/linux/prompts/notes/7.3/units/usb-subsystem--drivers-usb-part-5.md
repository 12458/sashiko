# USB SUBSYSTEM — drivers/usb (part 5)

This unit covers `drivers/usb/mon/` (`usbmon` binary ring-buffer and debugfs text interfaces for snooping host controller URB traffic) and `drivers/usb/misc/` (23 miscellaneous USB host drivers, hub controllers, firmware loaders, and compliance/test drivers).

## Architecture & Data Flow

- In `mon_bin.c`, `rp->b_vec` pages (`CHUNK_SIZE` / `PAGE_SIZE`) are not virtually contiguous; translate offsets via `rp->b_vec[off / CHUNK_SIZE].ptr + off % CHUNK_SIZE`, chunk copies at `CHUNK_SIZE` (`mon_copy_to_buff()`, `copy_from_buf()`), and align allocations/frees to `PKT_ALIGN` (64, equal to `PKT_SIZE`) so `mon_bin_hdr` (64B) and `mon_bin_isodesc` (16B) never straddle boundaries. `mon_bin_hdr::len_cap` excludes `PKT_SIZE`, so payload always starts at `b_out + PKT_SIZE` even when API0 copies only `PKT_SZ_API0` (48) header bytes. [F236, F238, F283]
- In `mon_bin.c`, when `rp->mmap_active` is non-zero, `mon_bin_event()` must use `mon_buff_area_alloc_contiguous()`, which writes a `@` filler (`mon_buff_area_fill()`) at `rp->b_in`, wraps `rp->b_in` to `size`, and adds `size + fill_size` to `rp->b_cnt`. Multi-slot advances (`lendesc`, `rp->b_read - hdrbytes`, `size`) must wrap by subtracting `rp->b_size`, not resetting to `0`. [F224, F265]
- In `mon_text_get_data()` and `mon_bin_get_data()`, branch on `urb->num_sgs == 0`: use `urb->transfer_buffer` when `0`, else iterate `urb->sg` via `sg_virt(sg)` only when `!PageHighMem(sg_page(sg))` (and `!(urb->transfer_flags & URB_DMA_SG_COMBINED)` in `mon_bin_get_data()`). In `mon_text.c`, always advance `p->cnt` with `scnprintf(p->pbuf + p->cnt, p->limit - p->cnt, ...)` rather than `snprintf()`. [F209, F241]
- In `mon_main.c`, `ubus->monitored` must be `1` iff `mbus->nreaders` or `mon_bus0.nreaders` is non-zero (`mon_reader_add()`, `mon_reader_del()`, `mon_stop()`, `mon_bus_add()`). Because `mon_dissolve()` sets `mbus->u_bus = NULL` while open readers hold `mbus->ref`, `mon_stop()` and `mon_bin_open()` must check `mbus->u_bus != NULL` (for `mbus != &mon_bus0`). [F219, F220]
- In `usb3503.c`, `hub->dev` may be an `i2c_client` or `platform_device` (never downcast `hub->dev`), and `hub->regmap` is `NULL` on platform bindings so `usb3503_connect()` must check `if (hub->regmap)`. `usb3503_probe()` must parse `"refclk-frequency"` to set `hub->secondary_ref_clk` before requesting `"intn"` GPIO. `usb3503_switch_mode()` and `usb4604_switch_mode()` must not overwrite `hub->mode` when entering `*_MODE_STANDBY`, and entering `USB3503_MODE_HUB` must deassert `reset`/`bypass`, sleep 4–10ms, bracket `USB3503_PDS`/`USB3503_CFG1` updates with `USB3503_SP_ILOCK` set/clear, then assert `connect`. [F207, F231, F288, F306, F307]
- In `usbtest.c`, every `id_table` entry needs a valid `.driver_info` (`struct usbtest_info *`), `get_endpoints()` must reset endpoint pointers to `NULL` each `intf->num_altsetting` iteration, and `iso_alloc_urb()` must use `DIV_ROUND_UP(bytes, maxp)`. `simple_io()` must restore `urb->transfer_buffer_length` before returning, `usbtest_ioctl()` must reset `dev->info->alt` (`>= 0`) via `set_altsetting()` before `usbtest_do_ioctl()`, and `setup` must stay first in `struct subcase` (`urb->setup_packet = &reqp->setup`). [F234, F261, F272, F277, F289]
- In `iowarrior.c`, `iowarrior_probe()` overrides `dev->report_size` on interface 0 to 7 (`IOW56`/`IOW56AM`), 4 (`IOW28`/`IOW28L`), or 12 (`IOW100`) before buffer allocation; only those models use `dev->int_out_endpoint` URBs in `iowarrior_write()`, whereas `IOW24`/`IOW24SAG`/`IOWPV1`/`IOWPV2`/`IOW40` use `usb_set_report()` and support `IOW_WRITE`. `dev->read_queue` stride is `dev->report_size + 1`; `iowarrior_read()` accepts only `count == report_size` or `report_size + 1`, and `iowarrior_write()` accepts `0` or `report_size`. [F245, F292, F299]
- In `ldusb.c`, `dev->ring_buffer` slot stride is `sizeof(size_t) + dev->interrupt_in_endpoint_size` (`actual_length` at `actual_buffer[0]`, payload at `actual_buffer + 1`, checked `<= interrupt_in_endpoint_size` in `ld_usb_read()`). `dev->interrupt_out_endpoint` is optional: when absent, `interrupt_out_endpoint_size` falls back to `bMaxPacketSize0` and `ld_usb_write()` uses `usb_control_msg()` (`HID_REQ_SET_REPORT`). [F247, F300]
- In `uss720.c`, `get_1284_register()` must guard `reg < 9` before indexing `regindex[9]` and `priv->reg`. `change_mode()` must step through `ECR_PS2` when switching between modes both `> ECR_PS2`, and when leaving `ECR_PPF`/`ECR_ECP` for `<= ECR_PS2` with `!(priv->reg[1] & 0x20)`, poll register 6 until FIFO empty (`priv->reg[2] & 0x01`) or timeout (`-EBUSY`). [F249, F309]
- Hub ports are 1-based in `onboard_dev_create_pdevs()` (`1..parent_hub->maxchild`) and `lvs_rh_work()` (`1..descriptor->bNbrPorts`). `onboard_dev_create_pdevs()` must return early for non-primary root hubs (`!parent_hub->parent && !usb_hcd_is_primary_hcd(hcd)`) and skip child DT nodes with `peer-hub` if `!usb_hcd_is_primary_hcd(hcd)` or `of_find_device_by_node()` finds an existing pdev. `lvs_rh_probe()` must require `bDeviceProtocol == USB_HUB_PR_SS && !hdev->parent` and `ret >= USB_DT_HUB_NONVAR_SIZE + 2`. [F235, F251, F302]
- In `ehset.c`, `TEST_SINGLE_STEP_SET_FEATURE` requires `hub_udev == dev->bus->root_hub`, and before `TEST_SE0_NAK_PID`/`TEST_J_PID`/`TEST_K_PID`/`TEST_PACKET_PID`, `ehset_prepare_port_for_testing()` must clear `USB_PORT_FEAT_ENABLE` and sleep 100ms for hubs in `ehset_hub_list` or set `USB_PORT_FEAT_SUSPEND` otherwise. [F303]
- In `idmouse.c`, `dev->bulk_in_buffer` is allocated to `IMGSIZE + dev->bulk_in_size` bytes for `idmouse_create_image()` (which must run inside `idmouse_open()` bracketed by `usb_autopm_get_interface()`/`put_interface()`), while `idmouse_read()` exposes at most `IMGSIZE` bytes. In `usbsevseg.c`, `text_store()`/`decimals_store()` must use `my_memlen(buf, count)` (not `strlen()`), reject `end > MAXLEN` (8), and reverse indices (`len - 1 - i`). [F248, F254, F313]

## Synchronization

- In `mon_main.c`, `mon_bus_lookup()` and `mon_buses` accesses require `mon_lock`. `mon_reader_add()` and `mon_reader_del()` require `mon_lock`, must lock `mbus->lock` (`spin_lock_irqsave()`) when modifying `mbus->nreaders` and `mbus->r_list`, and update `mbus->ref` under `mon_lock` outside `mbus->lock`. [F185, F186]
- `struct mon_reader` callbacks (`rnf_submit`, `rnf_error`, `rnf_complete`) run under `spin_lock_irqsave(&mbus->lock, flags)`, so they must not sleep, must use `GFP_ATOMIC`, and must not lock `mbus->lock`. In `mon_text.c`, `mon_text_fetch()` must hold `mbus->lock` to access `rp->e_list` and `rp->nevents` (updated in lockstep on every add/remove), and `mon_text_release()` must call `mon_reader_del()` before draining `rp->e_list` unlocked. [F226, F316, F317]
- In `mon_bin.c`, `mon_bin_vma_fault()` must hold `rp->b_lock` across checking `rp->b_size`, indexing `rp->b_vec`, and `get_page()`, and `mon_bin_ioctl(MON_IOCT_RING_SIZE)` must hold `rp->b_lock` when checking `rp->mmap_active` and replacing `rp->b_vec`/`rp->b_size`. Calling `mon_buff_area_free()` in `mon_bin_get_event()`, `mon_bin_read()`, or `mon_bin_flush()` requires holding both `rp->fetch_lock` and `rp->b_lock` and resetting `rp->b_read = 0` under `rp->fetch_lock`. [F189, F223]
- Character device `.release` callbacks (`ld_usb_release()`, `adu_release()`, `iowarrior_release()`, `idmouse_release()`) must use uninterruptible `mutex_lock()`, never `mutex_lock_interruptible()`. [F169]
- In `adutux.c`, lock order is `adutux_mutex` -> `dev->mtx` -> `dev->buflock`. In `adu_read()`, swapping `read_buffer_primary` and `read_buffer_secondary` must set `secondary_head = 0`, `secondary_tail = read_buffer_length`, and `read_buffer_length = 0` under `dev->buflock`. [F190, F227]
- In `iowarrior_read()`, lock `dev->mutex` (`mutex_trylock()` if `O_NONBLOCK`, else `mutex_lock_interruptible()`) before accessing `present`, `report_size`, or `read_queue`, clear `dev->overflow_flag` before reading `read_idx`, and retry `copy_to_user()` while `atomic_read(&dev->overflow_flag)` is non-zero (set when `iowarrior_callback()` advances `read_idx` on overflow). [F191, F228]
- In `ldusb.c`, `ld_usb_read()` must hold `dev->rbsl` while checking `ring_head == ring_tail` in a `while` loop around `wait_event_interruptible()`, and re-acquire `dev->rbsl` after `copy_to_user()` to advance `ring_tail`, clear `buffer_overflow = 0`, and resubmit `dev->interrupt_in_urb` if `buffer_overflow` was set. [F193, F229]
- In `yurex.c`, `yurex_write()` must lock `dev->io_mutex` with `mutex_lock_interruptible()`, call `usb_kill_urb(dev->cntl_urb)` after `finish_wait()` and before `mutex_unlock(&dev->io_mutex)`, and unlock `dev->io_mutex` on every return path in `yurex_read()`/`yurex_write()`. [F166, F326, F327]
- In `usblcd.c`, `lcd_write()` must acquire `dev->limit_sem` before `down_read(&dev->io_rwsem)` and anchor the URB to `dev->submitted` before `usb_submit_urb()`, while `lcd_disconnect()` sets `dev->disconnected = 1` under `down_write(&dev->io_rwsem)` before `usb_kill_anchored_urbs(&dev->submitted)`. In `usbtest.c:ctrl_complete()`, drop `ctx->lock` with `spin_unlock(&ctx->lock)` (keeping IRQs disabled) around `usb_unlink_urb(u)`. [F196, F330]

## Object Lifetimes

- In `yurex.c`, `iowarrior.c`, and `adutux.c`, device structs outlive disconnect while open: `yurex_probe()` pins `udev` and `interface`, `yurex_disconnect()` poisons `urb`/`cntl_urb` and sets `disconnected = 1` without clearing `interface`, and `yurex_delete()` kills URBs and calls `usb_free_coherent()` before `usb_put_intf()`/`usb_put_dev()`. `iowarrior_probe()` pins `dev->interface` (`usb_put_intf()` in `iowarrior_delete()`), anchors write URBs to `dev->submitted`, and `iowarrior_disconnect()` holds `dev->mutex` across clearing `present` and checking `opened`. `adu_probe()` pins `dev->udev` (`usb_put_dev()` in `adu_delete()`). [F164, F165, F170, F171, F192]
- In `uss720.c`, `priv->usbdev` is owned by `parport_uss720_private` after `kref_init(&priv->ref_count)` and put in `destroy_priv()`. `submit_async_request()` must init `rq->ref_count`/`rq->compl`, `kref_get(&priv->ref_count)`, link `rq->asynclist` under `priv->asynclock`, and `kref_get(&rq->ref_count)` before `usb_submit_urb()`; callers must call `kref_put(&rq->ref_count, destroy_async)`. `uss720_disconnect()` must clear `priv->pp = NULL` (not `priv->usbdev`), remove/put the parport, call `kill_all_async_requests_priv(priv)`, and drop `priv->ref_count`. [F167, F168, F199, F298]
- In `usblcd.c`, `lcd_open()`/`lcd_release()` must balance `usb_autopm_get_interface()`/`put_interface()` (putting `dev->kref` if `autopm_get` fails), `lcd_suspend()` drains `dev->submitted` via `lcd_draw_down()`, and in `lcd_write()` any error after `down_interruptible(&dev->limit_sem)` before `usb_submit_urb()` succeeds must unanchor `urb`, free `buf`/`urb`, and call `up(&dev->limit_sem)`. [F174, F312]
- In `lvstest.c:lvs_rh_disconnect()`, call `usb_poison_urb(lvs->urb)` before `flush_work(&lvs->rh_work)`. In `appledisplay.c`, check `pdata->bd != NULL` before scheduling `pdata->work` in `appledisplay_complete()`, and call `usb_kill_urb(pdata->urb)` before `cancel_delayed_work_sync(&pdata->work)` on teardown. [F178, F294]
- In `usbsevseg.c`, `update_display_*()` must return early when `mydev->shadow_power != 1`, gate autopm on `mydev->has_interface_pm`, and use `GFP_NOIO` in `sevseg_resume()`/`sevseg_reset_resume()`. In `usbtest.c`, set `urbs[i] = NULL` after `simple_free_urb(urbs[i])` on submit failure in `test_queue()`, and free `buf - offset` in `ctrl_out()`. [F184, F280, F311]

## API Contracts

- In `mon_bin.c`, `mon_buff_area_alloc*()` returns an `unsigned int` offset (`0` is valid, `~0` on failure); `mon_bin_get_data()` returns the `unsigned int` uncopied residual byte count, which `mon_bin_event()` must subtract from `ep->len_cap` and pass (aligned) to `mon_buff_area_shrink()`. [F202, F203]
- Across `drivers/usb/misc/`, `usb_control_msg*()`/`usb_bulk_msg()` timeouts are in ms (not `HZ`), `bRequestType` direction must match the pipe, and `usb_control_msg()` buffers must be DMA-capable heap memory (`kmalloc`/`kzalloc`/`kmemdup`). [F215, F216, F290]
- Release `create_lvs_device()` devices via `destroy_lvs_device(udev)` (not `usb_put_dev()`). In `uss720.c`, atomic parport callbacks (`frob_control`, `restore_state`) must pass `GFP_ATOMIC` and `val = NULL` to `get_1284_register()`/`set_1284_register()`. In `usbtest.c`, `subcase->expected` is negative for mandatory faults and positive for optional faults. `emi26_probe()`/`emi62_probe()` must return `-EIO` after firmware load, and `iowarrior_open()`/`adu_open()`/`ld_usb_open()`/`idmouse_open()` must return `-EBUSY` when already open. [F179, F263, F325, F341, F343]

## Error Handling

- In `usbtest_ioctl()`, check `usbtest_do_ioctl()` with `if (retval < 0)` (not `if (retval)`), and in `ctrl_complete()` restore `status = ctx->status` after `usb_unlink_urb()`. Validate `param->sglen <= MAX_SGLEN`, `param->sglen > 0`, and `param->iterations <= UINT_MAX / param->sglen` before multiplying (`sglen >= 4` for case 24), and in `ch9_postconfig()` check `buf + sizeof(struct usb_dev_cap_header) <= dev->buf + total` and each capability's size before reading fields. [F200, F211, F243, F244]
- Check `ret < 0` on `ehset_prepare_port_for_testing()` in `ehset_probe()`, `IS_ERR(backlight)` before assigning `pdata->bd` in `appledisplay_probe()`, and `retval < 2` on 2-byte `usb_control_msg()` reads in `appledisplay_bl_get_brightness()` and `cypress_cy7c63.c:vendor_command()`. [F201, F204, F210]
- Zero `struct mon_bin_hdr` (`memset(ep, 0, PKT_SIZE)`) and `dp->_pad = 0` (`mon_bin_isodesc`) in `mon_bin.c`. Convert big-endian `rec->addr`/`rec->len` (`be32_to_cpu()`/`be16_to_cpu()`) and check `i + len < FW_LOAD_SIZE` in `emi26.c`/`emi62.c`/`ezusb.c`; check `ptr + 4` and `ptr + llen <= firmware->data + firmware->size` in `isight_firmware_load()`. [F212, F252, F253]
- Check `read_buffer_length < (4 * maxp) - urb->actual_length` in `adu_interrupt_in_callback()`, use `snprintf()` + `simple_read_from_buffer()` in `yurex_read()`, and treat `-ENOENT`/`-ECONNRESET`/`-ESHUTDOWN` in URB callbacks as normal unlink termination without logging or resubmitting. [F255, F257, F340]

## External Contracts

- In `mon_bin_mmap()`, reject `VM_WRITE` (`-EPERM`) and clear `VM_MAYWRITE` via `vm_flags_mod()`. Keep `mon_bin_compat_ioctl()` in sync with pointer-taking ioctls in `mon_bin_ioctl()`, use mode `0600` for `usbmon` debugfs files in `mon_text_add()`, and support both `USBTEST_REQUEST_32` and `USBTEST_REQUEST_64` in `usbtest_ioctl()`. [F332, F337, F338, F342]

## Known Pitfalls

- In `mon_text.c`, `mon_text_ctor()` poisons `mon_event_text` with `0xe5`: `mon_text_read_u()` must check `ep->type == 'E'` before `ep->xfertype`, `mon_text_read_*` must guard fields with `type`/`xfertype`/`setup_flag == 0`/`data_flag == 0` and clamp `numdesc <= ISODESC_MAX` (5) and `length <= DATA_MAX` (32), and `mon_get_timestamp()` must mask `now.tv_sec & 0xFFF`. In `mon_stop()`, `mbus` is overwritten by `list_for_each_entry()` when `mbus == &mon_bus0`. [F213, F240, F268, F270]
- In `usbtest.c`, URB buffer `offset` must be `< ARCH_KMALLOC_MINALIGN`. In `iowarrior_ioctl()` (`IOW_GETINFO`), swap `idVendor`/`bcdDevice` with `le16_to_cpu()`, but not `dev->product_id` or `udev->speed`. Keep `dev->bbu` (`__s64`) and `c` (`unsigned long long`) 64-bit in `yurex.c`, match `hub_udev` with `usb_device_match_id()` (not `to_usb_interface()`) in `ehset.c`, and keep the `usb_string(udev, 255, ...)` quirk for `LD_CASSY`/`LD_COM3LAB` (`bcdDevice <= 0x103`) in `ld_usb_probe()`. [F242, F246, F271, F276, F301]
