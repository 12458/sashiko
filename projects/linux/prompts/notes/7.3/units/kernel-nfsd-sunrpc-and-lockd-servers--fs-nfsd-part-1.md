# KERNEL NFSD, SUNRPC, AND LOCKD SERVERS — fs/nfsd (part 1)

This unit implements core NFSv3 and NFSv4 server procedure handlers, NFSv2/v3/v4 ACL translation, NFSv4 ID mapping, pNFS layout management, NFSv4 backchannel callbacks, client reboot recovery tracking, lockd file-open bindings, netlink server configuration, local-I/O (LOCALIO) support, and `struct nfsd_net`.

## Architecture & Data Flow
- In `struct nfsd4_callback`, `cb->cb_held_slot` uses `-1` for "no slot held" (`nfsd4_init_cb`, `nfsd41_cb_release_slot`) as `0` is `BIT(0)` in `ses->se_cb_slot_avail`; `grab_slot` and `highest_slotid` must subtract 1 from `ffs(ses->se_cb_slot_avail)` / `fls(~ses->se_cb_slot_avail)`, `grab_slot` must check `0 <= idx <= ses->se_cb_highest_slot` before `BIT(idx)`, and `nfsd41_cb_release_slot` must check `cb->cb_held_slot >= 0` before `BIT(cb->cb_held_slot)`. [F50, F85, F126]
- When `update_cb_slot_table()` grows `ses->se_cb_highest_slot` (`target > ses->se_cb_highest_slot`) under `ses->se_lock`, it must clamp `target` to `NFSD_BC_SLOT_TABLE_SIZE - 1` and reset `ses->se_cb_seq_nr[i] = 1` for `i` in `ses->se_cb_highest_slot + 1 .. target`. [F57]
- `max_cb_time` must bound `nn->nfsd4_lease` to `<= 3600` before casting to `u32` for `/ 10`, and clamp `((u32)nn->nfsd4_lease) / 10` to `>= 1u` before `* HZ`. `nfs_cb_errtbl` is scanned by `nfs_cb_stat_to_errno` until `stat == -1`, so `{ -1, -EIO }` must stay last. [F87, F122]
- `struct nfs4_cb_fattr` used with `NFSPROC4_CLNT_CB_GETATTR` must be embedded at `nfs4_delegation.dl_cb_fattr`, and `struct nfsd4_cb_offload` used with `nfsd4_cb_offload_ops` at `nfsd4_copy.cp_cb_offload`, for two-level `container_of` downcasts in `encode_cb_getattr4args` and `nfsd4_cb_offload_release`. [F133]
- Setting `ls->ls_recalled = true` in `nfsd4_recall_file_layout()` must be paired with `atomic_inc(&ls->ls_stid.sc_file->fi_lo_recalls)` under `ls->ls_lock`, and `nfsd4_free_layout_stateid()` must call `atomic_dec(&ls->ls_stid.sc_file->fi_lo_recalls)` iff `ls->ls_recalled` is true. [F64]
- In `nfsd4_return_file_layouts()`, if removing segments under `ls->ls_lock` empties `ls->ls_layouts`, set `ls->ls_stid.sc_status |= SC_STATUS_CLOSED` and `lrp->lrs_present = false`; else set `lrp->lrs_present = true` and (if `found > 0`) call `nfs4_inc_and_copy_stateid()` on `lrp->lr_sid`. [F66]
- `layout_end` must saturate `seg->offset + seg->length` to `NFS4_MAX_UINT64` on wraparound (`end < seg->offset`), and `layout_update_len` must keep `lo->length = NFS4_MAX_UINT64` when `end == NFS4_MAX_UINT64`. `nfsd4_layout_verify` must check `layout_type >= LAYOUT_TYPE_MAX` before `1 << layout_type` and `nfsd4_layout_ops[layout_type]`. [F120, F125]
- In `nfsd4_alloc_devid_map`, flexible array `map->fsid[]` is sized in bytes by `key_len(fh->fh_fsid_type)` for allocation (`sizeof(*map) + fsid_len`), `memcpy`, and `memcmp`. In `nfsd4_layoutcommit`, guard `lcp->lc_last_wr` with `if (lcp->lc_newoffset)` and `ls` lookup/put with `if (!lcp->lc_reclaim)`. [F37, F141]
- `nfsd4_savefh()` and `nfsd4_restorefh()` must copy `current_stateid` / `save_stateid` and `SAVED_STATE_ID_FLAG` / `CURRENT_STATE_ID_FLAG` with `save_fh` / `current_fh`; `nfsd4_ops[]` entries replacing `current_fh` without setting a stateid must set `OP_CLEAR_STATEID`. [F67]
- `nfsd4_decode_compound` sets out-of-range ops to `op->opnum = OP_ILLEGAL` (10044), so helpers indexing `nfsd4_ops[op->opnum]` (`OPDESC(op)`) or `nn->counter[NFSD_STATS_NFS4_OP(op->opnum)]` before checking `op->status` (`need_wrongsec_check`, `nfsd4_cache_this_op`, `nfsd4_max_reply`, `nfsd4_increment_op_stats`) must guard against `OP_ILLEGAL`. [F98]
- In `nfsd4_read()`, set `argp->splice_ok = false` when `!nfsd4_last_compound_op(rqstp)`. When `do_open_lookup()` or `nfsd4_create()` sets `current->fs->umask` from `op_umask`/`cr_umask`, it must reset `current->fs->umask = 0` on all exit paths. [F70, F71]
- For NFSv4.0 opens (`!nfsd4_has_session(cstate)`), `nfsd4_set_open_owner_reply_cache()` saves `resfh->fh_handle` into `oo_owner.so_replay.rp_openfh`, and on `nfserr_replay_me` from `nfsd4_process_open1()` in `nfsd4_open()`, `cstate->current_fh` must be restored from `rp->rp_openfh` via `fh_copy_shallow()` and `fh_verify()`. [F73]
- In `svcxdr_encode_nfs_fh3`, when `size > 0`, zero `p[XDR_QUADLEN(size) - 1]` before `memcpy`. `nfsd3_init_dirlist_pages` must clamp `count` to `>= (u32)(XDR_UNIT * 2)` before subtracting `XDR_UNIT * 2` for `buf->buflen` and advance `rqstp->rq_next_page` by `(buf->buflen + PAGE_SIZE - 1) >> PAGE_SHIFT`; `nfsd3_proc_readdir` and `nfsd3_proc_readdirplus` must reset `rqstp->rq_next_page = resp->xdr.page_ptr + 1` after `nfsd_readdir()`. [F48, F75, F127]
- `nfsd4_legacy_tracking_init()` and `nfsd4_umh_cltrack_init()` must reject `net != &init_net` with `-EINVAL`. In `idmap_lookup`, on `-ETIMEDOUT` from `cache_check`, jump to `retry` only if `lookup_fn(detail, key)` returns `*item != prev_item`; otherwise call `cache_put(&(*item)->h, detail)` and return `-ETIMEDOUT`. [F78, F116]
- In `low_mode_from_nfs4`, multi-bit masks (`NFS4_READ_MODE`, `write_mode`, `NFS4_EXECUTE_MODE`) require `(perm & mask) == mask`. In `_posix_to_nfsv4_one`, save `ACL_GROUP_OBJ` in `group_owner_entry` before emitting group allow ACEs, then reset `pa = group_owner_entry` for a second pass emitting group deny ACEs. [F104, F105]

## Synchronization
- In `fs/nfsd/nfs4layouts.c`, `ls->ls_lock` nests inside `fp->fi_lock` and `clp->cl_lock`, and `fp->fi_lock` nests inside `ls->ls_mutex`. In `nfsd4_insert_layout`, after dropping `ls->ls_lock` and `fp->fi_lock` for `GFP_KERNEL` allocation, reacquire both and re-run `nfsd4_recall_conflict` and `layouts_try_merge` before inserting into `ls->ls_layouts`. [F25, F146]
- In `nfsd4_close_layout`, extract and clear `ls->ls_file = NULL` under `ls->ls_stid.sc_file->fi_lock` before calling `kernel_setlease(..., F_UNLCK, ...)` and `nfsd_file_put` outside the lock. In `nfsd4_cb_layout_done`, acquire `ls->ls_file` via `nfsd_file_get` under `rcu_read_lock()` before `ops->fence_client` or `nfsd4_cb_layout_fail`, then `nfsd_file_put`. [F27, F149]
- `nfsd4_layout_lm_break` runs under atomic `flc_lock`, so it and `nfsd4_recall_file_layout` must not sleep, must defer RPCs via `nfsd4_run_cb`, and must set `fl->fl_break_time = 0` and return `false`; in `nfsd4_layout_setlease`, call `locks_free_lease(fl)` only if `kernel_setlease` fails. [F148, F175]
- `nfsd4_alloc_devid_map` must insert into `nfsd_devid_hash` under `nfsd_devid_lock` via `list_add_tail_rcu`, and `nfsd4_find_devid_map` must use `list_for_each_entry_rcu` under `rcu_read_lock()`. In `fs/nfsd/nfs4idmap.c`, `idtoname_lookup` and `nametoid_lookup` use `sunrpc_cache_lookup_rcu`, so `ent_put` must use `kfree_rcu(map, rcu_head)`. [F144, F154]
- Only `nfsd4_process_cb_update()` on `clp->cl_callback_wq` may clear `NFSD4_CLIENT_CB_UPDATE` in `clp->cl_flags`; while it is set, `nfsd4_mark_cb_down()` and `nfsd4_mark_cb_fault()` must not overwrite `clp->cl_cb_state`. Modifying `ses->se_cb_slot_avail` (`grab_slot`, `nfsd41_cb_release_slot`) requires `ses->se_lock`, while `session->se_cb_seq_nr[cb->cb_held_slot]` must be updated before `nfsd41_cb_release_slot`. [F61, F151]
- In `alloc_cld_upcall`, initialize `cu_done`, `cm_vers`, `cm_xid`, and `cu_net` before adding `cu_list` to `cn->cn_list` under `cn->cn_lock`, and if `cn->cn_xid` collides on `cn->cn_list`, increment `cn->cn_xid` and restart the scan from the head. In `cld_pipe_downcall`, perform all user-memory accesses (`copy_from_user`, `get_user`, `__cld_pipe_inprogress_downcall`) outside `cn->cn_lock`. [F32, F115, F159]
- In `nfsd4_umh_cltrack_create`, `nfsd4_umh_cltrack_remove`, and `nfsd4_umh_cltrack_check`, serialize `nfsd4_umh_cltrack_upcall` and `NFSD4_CLIENT_STABLE` updates with `nfsd4_cltrack_upcall_lock(clp)` / `nfsd4_cltrack_upcall_unlock(clp)`. [F160]

## Object Lifetimes
- `nfsd4_process_cb_update` gets `c->cn_xprt` via `svc_xprt_get` and passes it to `setup_callback_client` (`clp->cl_cb_conn.cb_xprt`), so it must call `svc_xprt_put(c->cn_xprt)` if `setup_callback_client` fails, and clear `clp->cl_cb_conn.cb_xprt` and `clp->cl_cb_client` to `NULL` on teardown. [F6]
- `nfsd4_run_cb` calls `nfsd41_cb_inflight_begin` before queuing `cb->cb_work` (calling `nfsd41_cb_inflight_end` if `nfsd4_queue_cb` returns `false`), every queued callback must end via `nfsd41_destroy_cb` or `nfsd4_cb_probe_release`, and `nfsd4_shutdown_callback` must run in process context before freeing `clp` to flush `clp->cl_callback_wq` and wait in `nfsd41_cb_inflight_wait_complete`. [F7, F153]
- `nfsd4_proc_compound` must clear `RQ_USEDEFERRAL` in `rqstp->rq_flags` before running ops and reach `out:` to restore it; jumping directly to `out:` (skipping `fh_put(current_fh)` and `fh_put(save_fh)`) is only safe before any op populates `current_fh`/`save_fh`. `nfsd3_proc_fsstat`, `nfsd3_proc_fsinfo`, and `nfsd3_proc_pathconf` lack `.pc_release` and must call `fh_put(&argp->fh)` before returning. [F16, F20, F69]
- In `nfsd_open_local_fh`, fast-path `*pnf` lookup must dereference `*pnf` and call `nfsd_file_get` under `rcu_read_lock()` after `nfsd_net_try_get(net)`; before `cmpxchg(pnf, NULL, localio)`, acquire a second `nfsd_net_try_get` and second `nfsd_file_get` reference (dropping both `localio` refs and the extra `net` ref if `cmpxchg` loses to a valid `new`), and call `put_group_info(rq_cred.cr_group_info)` if non-NULL after `svcauth_map_clnt_to_svc_cred_local`. [F142, F143, F163]

## API Contracts
- `nfsd4_process_cb_update` may pass `ses == NULL` to `setup_callback_client` when no backchannel is found or `clp->cl_minorversion == 0`, so `setup_callback_client` and `get_backchannel_cred` must only dereference `ses` when `clp->cl_minorversion != 0`. [F36]
- In `nfsd4_cb_done`, `cb->cb_ops->done(cb, task)` must return `0` (restart) or `1` (done); any other value hits `BUG()`. In `nfsd4_init_cb`, `ops == NULL` is valid only for `&clp->cl_cb_null`, as `nfsd4_cb_probe_done` / `nfsd4_cb_probe_release` use `container_of(calldata, struct nfs4_client, cl_cb_null)`. [F39, F132]
- In `nfsd4_preprocess_layout_stateid`, downcast `stid` to `struct nfs4_layout_stateid` only when `stid->sc_type == SC_TYPE_LAYOUT`; when `stid->sc_type != SC_TYPE_LAYOUT`, `nfs4_put_stid(stid)` drops the parent ref right after `nfsd4_alloc_layout_stateid` (so `!ls` must jump to `out`, not `out_put_stid`), and on `return 0`, `*lsp` has `ls->ls_stid` referenced and `ls->ls_mutex` locked (which callers and `out_unlock_stid` must unlock and put). [F51, F109, F131]
- `_nfsd4_verify` must check `!(verify->ve_attrlen & 3)`, read the encoded payload at `buf + 1 + ntohl(buf[0]) + 1` of length `ntohl(buf[1 + ntohl(buf[0])])`, and never return `nfs_ok`: it returns `nfserr_same` or `nfserr_not_same` (mapping `nfserr_resource` from `nfsd4_encode_fattr_to_buf` to `nfserr_not_same`) for `nfsd4_verify` / `nfsd4_nverify`. `set_change_info` requires `fhp->fh_pre_saved`, so `do_open_fhandle` must `memset` `open->op_cinfo` to zero instead. [F45, F54, F97]
- `nfsd_open_local_fh` must check `nfs_fh->size <= NFS4_FHSIZE` before `memcpy` into `fh.fh_handle.fh_raw`, and `nfsd_localio_ops` must provide `nfsd_file_dio_alignment`. `fs/nfsd/netlink.c` and `netlink.h` are generated from `Documentation/netlink/specs/nfsd.yaml`, and mutating ops in `nfsd_nl_ops` require `GENL_ADMIN_PERM`. [F89, F161, F165]
- In `svc_procedure` tables, `.pc_argzero` is in bytes while `.pc_xdrressize` is in 4-byte XDR words. Wire UID/GID conversions (`svcxdr_decode_sattr3`, `svcxdr_encode_fattr3`, `nfsd_map_name_to_uid`, `nfsd_map_name_to_gid`, `nfsd4_encode_user`, `nfsd4_encode_group`) must use `nfsd_user_namespace(rqstp)`. Legacy recdir ops (`nfsd4_create_clid_dir`, `nfsd4_remove_clid_dir`, `nfsd4_list_rec_dir`, `nfsd4_init_recdir`) must bracket VFS calls with `nfs4_save_creds` / `nfs4_reset_creds`, and `strscpy()` on fixed arrays (`work->nsui_ipaddr`, `user_recovery_dirname`) must pass `sizeof(dest)`. [F129, F166, F170, F181]

## Error Handling
- In `fs/nfsd/nfs4callback.c`, XDR reply decoders (`decode_cb_fattr4`, `decode_cb_op_status`, `decode_cb_compound4res`, `decode_cb_sequence4resok`, `nfs4_xdr_dec_cb_getattr`) must return `-EIO` on XDR stream failures, and callers of `decode_cb_sequence4res` and `decode_cb_op_status` must check both `status == 0` and `cb->cb_seq_status == 0` / `cb->cb_status == 0` before decoding further payload. [F34, F35]
- In `nfsd_open_local_fh`, `nfsd_file_acquire_local` returns `__be32` `beres` instead of setting `localio` to an `ERR_PTR`, so convert non-zero `beres` via `ERR_PTR(nfs_stat_to_errno(be32_to_cpu(beres)))` before `IS_ERR(localio)`. [F38]
- In `nfs4_acl_nfsv4_to_posix`, `posix_state_to_acl` returns `NULL` for empty default ACLs or `ERR_PTR` on error; on `IS_ERR(*pacl)` / `IS_ERR(*dpacl)`, reset the failed pointer to `NULL` (releasing `*pacl` if `*dpacl` failed), and on success call `sort_pacl` on both. In `nfsacld_proc_getacl` and `nfsd3_proc_getacl`, check `IS_ERR(acl)` before assigning `resp->acl_access` / `resp->acl_default`, and release and null both on `fail:`. [F41, F42, F174]
- In `nfsd4_verify_copy`, `out_put_dst` and `out_put_src` must call `nfsd_file_put` and reset `*dst = NULL` and `*src = NULL`. In `nfsd4_do_copy`, if `_nfsd_copy_file_range` returns `bytes < 0` when `copy->cp_res.wr_bytes_written > 0`, return `nfs_ok` so `encode_offload_info4` encodes the partial byte count. [F43, F46]
- In `nfs3svc_encode_entry3` and `nfs3svc_encode_entryplus3`, `out_toosmall` must reset `resp->cookie_offset = 0`, `resp->dirlist.len = starting_length`, `resp->common.err = nfserr_toosmall`, and return `-EINVAL`. In `idmap_name_to_id` and `idmap_id_to_name`, `idmap_lookup` returns `0` with referenced `item` (requiring `cache_put`) or negative errno (`-ENOENT` maps to `nfserr_badowner` / `encode_ascii_id`). In `nfsd3_proc_mknod` and `nfsd4_create`, reject `rdev = MKDEV(major, minor)` with `nfserr_inval` if `MAJOR(rdev) != major || MINOR(rdev) != minor`. [F49, F55, F124]

## External Contracts
- In `encode_cb_getattr4args()`, set `FATTR4_WORD0_CHANGE` in `bmap[0]` only when `!ncf->ncf_file_modified`; in `nfs4_xdr_dec_cb_getattr`, check `attrlen <= maxlen` before `decode_cb_fattr4`. [F56, F88]
- `nfsd4_create_file()` stores the exclusive-create verifier in `ia_mtime`/`ia_atime` and `do_open_lookup()` sets `FATTR4_WORD1_TIME_ACCESS | FATTR4_WORD1_TIME_MODIFY` in `open->op_bmval[1]`; on a positive-dentry verifier match, `NFS4_CREATE_EXCLUSIVE` must `break` to `out` whereas `NFS4_CREATE_EXCLUSIVE4_1` must `goto set_attr`. [F72, F110]
- `cld_pipe_downcall` must verify `mlen == nn->client_tracking_ops->msglen`, and when `hdr->cm_status == -EINPROGRESS`, leave `cup` on `cn->cn_list` without calling `complete(&cup->cu_done)`. In `idtoname_parse` and `nametoid_parse`, require `buf[buflen - 1] == '\n'` (overwritten with `'\0'`) and `len < IDMAP_NAMESZ`. [F52, F82, F90]
- Clamp `offset` and `count` to `(u64)OFFSET_MAX` in `nfsd3_proc_read` and `nfsd4_read`, but return `nfserr_fbig` if `offset > (u64)OFFSET_MAX` or `offset + len > (u64)OFFSET_MAX` in `nfsd3_proc_write` and `nfsd4_write`. In `nfsd4_layoutget`, check `> NFS4_MAX_UINT64 - lgp->lg_seg.offset` for `lg_seg.length` and `lg_minlength` when `!= NFS4_MAX_UINT64`, and reject `lg_seg.length == 0` or `< lg_minlength` with `nfserr_inval`. In `nfsd4_proc_compound`, check `nfsd4_check_resp_size(resp, plen)` with `COMPOUND_ERR_SLACK_SPACE` before `OP_MODIFIES_SOMETHING` ops. [F92, F95, F100]

## Known Pitfalls
- `struct cld_msg`, `struct cld_msg_v2`, and `struct cld_msg_hdr` are packed with `cm_xid` at offset 4; use `put_unaligned()` / `get_unaligned()` for `cm_xid`. In `nfsd4_cb_layout_done`, cast `nn->nfsd4_lease` to `u64` before `* (NSEC_PER_SEC * 2)`. In `idmap_name_to_id` and `numeric_name_to_id`, check `namelen + 1 > sizeof(buf)`, `memcpy`, and NUL-terminate `buf[namelen] = '\0'`. `nfs4_xdr_enc_cb_null` must call `xdr_reserve_space(xdr, 0)` for `krb5p`. [F83, F121, F137, F176]
