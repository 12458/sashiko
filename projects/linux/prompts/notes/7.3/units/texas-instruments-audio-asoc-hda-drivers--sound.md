# TEXAS INSTRUMENTS AUDIO (ASoC/HDA) DRIVERS — sound

This unit contains Texas Instruments audio codec and smart amplifier drivers across the HDA side-codec and ASoC frameworks (`pcm1681`, `pcm1789`, `pcm179x`, `pcm186x`, `pcm3008`, `pcm3060`, `pcm3168a`, `pcm5102a`, `pcm512x`, `tas2552`, `tas2562`, `tas2764`, `tas2770`, `tas2780`, `tas2781_hda_i2c`, and `tas2781-comlib`), managing I2C/SPI regmap access, DAI formats, clocks/PLLs, DAPM routing, ALSA kcontrols, UEFI calibration, and fault monitoring.

## Architecture & Data Flow
- `tasdevice_regmap` (`tas2781-comlib-i2c.c`) must use `.cache_type = REGCACHE_NONE` because one `regmap` is shared across multiple I2C addresses (`tasdev->dev_addr`) with `TASDEVICE_BOOKCTL_REG` outside `tasdevice_ranges`. In `tasdevice_change_chn_book()` and `tasdev_chn_switch()`, changing `client->addr` to `tasdev->dev_addr` requires writing `0` to `TASDEVICE_PAGE_SELECT`, and `tasdev->cur_book = book` must be set only after `regmap_write(map, TASDEVICE_BOOKCTL_REG, book)` succeeds. [F51, F52, F53]
- `tasdevice_init()` and `tas2781_system_resume()` must reset `tasdevice[i].cur_book`, `cur_prog`, and `cur_conf` to `-1` before reset/DSP load. Both `tasdevice_dspfw_init()` and `tas2781_system_resume()` must check `tas_priv->rcabin.init_profile_id >= 0` after `tasdevice_prmg_load()` and apply `TASDEVICE_BIN_BLK_PRE_POWER_UP` via `tasdevice_select_cfg_blk()`. [F39, F55]
- `tas2781_hda_i2c_probe()` stores `struct tas2781_hda *` as `clt->dev` drvdata while `tasdevice_i2c_probe()` stores `struct tasdevice_priv *`, so `tasdevice_kzalloc()` and `tasdevice_init()` must never call `dev_set_drvdata()`. `snd_ctl_new1()` and `tascodec_init()` pass `tas_priv` as kcontrol `private_data` (`snd_kcontrol_chip()`) and firmware `context`; `tas_priv->client` is `struct i2c_client *` and `tas_priv->codec` is `struct hda_codec *` in HDA paths. [F54, F111, F112]
- In `tas2764.c`, `tas2770.c`, and `tas2562.c`, `PWR_CTRL` encodes `dac_powered` and `unmuted`; power/mute updates must go through `tas2764_update_pwr_ctrl()`, `tas2770_update_pwr_ctrl()`, or `tas2562_update_pwr_ctrl()`. `tas2764_mute()` must step through `TAS2764_PWR_CTRL_MUTE` (`dac_powered = true`, `tas2764_update_pwr_ctrl()`, then `unmuted = !mute`; on mute: `unmuted = false`, `tas2764_update_pwr_ctrl()`, sleep 6–7 ms, `dac_powered = false`). [F60, F100]
- `tas2764_codec_suspend()` and `tas2770_codec_suspend()` must not clear `dac_powered` or `unmuted` when writing `SHUTDOWN` to `PWR_CTRL`, and resume must call `tas2764_update_pwr_ctrl()` / `tas2770_update_pwr_ctrl()` before `regcache_sync()`. In `tas2770.c`, `sense_event()` must set `TAS2770_PWR_CTRL_SHUTDOWN` on `SND_SOC_DAPM_PRE_REG` when toggling `ISENSE`/`VSENSE` and restore via `tas2770_update_pwr_ctrl()` on `SND_SOC_DAPM_POST_REG`. [F61, F62]
- In `tas2764_set_bitwidth()`, `tas2780_set_bitwidth()`, and `tas2562_set_bitwidth()`, TDM sense bits (`VSNS_ENABLE`/`VSNS_EN` in `TDM_CFG5`, `ISNS_ENABLE`/`ISNS_EN` in `TDM_CFG6`) must be set only when active-low `VSENSE_POWER_EN` or `ISENSE_POWER_EN` in `PWR_CTRL` is `0`. [F63]
- In `tas2764_codec_probe()`, `sn012776_bop_presets` and `tas2764_apply_init_quirks()` must run only for `DEVID_SN012776`, and `TAS2764_REG(0xf0, 0x0)..TAS2764_REG(0xff, 0x0)` must stay volatile in `tas2764_volatile_register()`. Sequences in `tas2764-quirks.h` accessing hidden page `0xfd` must bracket access with writes of `0xd` and `0x0` to `TAS2764_REG(0xfd, 0x0d)`. [F64, F125]
- In `tas2770_parse_dt()`, missing `ti,imon-slot-no`, `ti,vmon-slot-no`, or `ti,pdm-slot-no` must set `i_sense_slot`, `v_sense_slot`, or `pdm_slot` to `-1` (checked `!= -1` in `tas2770_codec_probe()`). In `tas2562`, `TAS2110` must skip `ti,imon-slot-no` / `ti,vmon-slot-no` in `tas2562_parse_dt()` and register `soc_component_dev_tas2110`. [F40, F128]
- `tas2552_sw_shutdown()` must check `if (!tas2552->component)` before `snd_soc_component_update_bits()` because `tas2552_runtime_suspend()` can run after `pm_runtime_put_sync_autosuspend()` in `tas2552_probe()` before `tas2552_component_probe()`. [F34]
- `tas2552_setup_pll()` must save `TAS2552_PLL_ENABLE` from `TAS2552_CFG_2` before clearing it to reprogram `TAS2552_CFG_1` and `TAS2552_PLL_CTRL_1..3`, then restore it. In `tas2552_set_dai_sysclk()`, out-of-range (`< 512000` or `> 24576000`) MCLK/IVCLKIN must set `clk_id = TAS2552_PLL_CLKIN_BCLK` and `freq = 0` before fallthrough. `tas2552_prepare()` must write `tdm_delay + 1` for `DSP_A`, `tdm_delay` for `DSP_B`, and `0` otherwise to `TAS2552_SER_CTRL_2`. [F72, F93, F99]
- In `pcm512x`, `pcm512x->sclk` can be an `ERR_PTR` at runtime (probe only aborts on `-EPROBE_DEFER`); all `clk_*` calls on `sclk` require `!IS_ERR(pcm512x->sclk)`, and `pcm512x_dai_startup_master()` must reject `IS_ERR(pcm512x->sclk)`. Each `supplies[i]` needs its own `supply_nb[i]` and `pcm512x_regulator_event_##i` calling `regcache_mark_dirty()` and `regcache_cache_only()` on `REGULATOR_EVENT_DISABLE`. `pcm512x_i2c_probe()` must copy `pcm512x_regmap` to a local struct before setting `read_flag_mask`/`write_flag_mask = 0x80`. [F32, F68, F69]
- `pcm512x_probe()` bounds non-zero DT `pll-in`/`pll-out` to `[1, 6]`, and `pcm512x_set_dividers()` / `pcm512x_hw_params()` must subtract `1` for 0-based GPIO offsets (`PCM512x_GREF_GPIO1`, `PCM512x_GPIO_OUTPUT_1`) and shifts (`PCM512x_G1OE`). `pcm512x_hw_rule_rate()` must use `DIV_ROUND_UP(16000000, frame_size)` for `ranges[1].min` on 48/64-bit frames. [F82, F103]
- `pcm3168a_probe()` must copy `pcm3168a_dais` into `pcm3168a->dai_drv` before `devm_snd_soc_register_component()`, and `pcm3168a_set_dai_fmt()` / `pcm3168a_set_tdm_slot()` must call `pcm3168a_update_fixup_pcm_stream(dai)`. `pcm3168a->sysclk` must stay non-zero (24576000 Hz fallback, ignoring `freq == 0`), using `DIV_ROUND_UP(3846 * 1000, pcm3168a->sysclk)` for reset delay. In `pcm3168a_hw_params()`, `pcm3168a_scki_ratios[]` is bounded to 6 entries for DAC and 4 for ADC, encoding matched `i` as `ms = i + 1`. [F66, F81, F105, F116]
- In `pcm1681.c`, `pcm1681_put_deemph()` and `pcm1681_hw_params()` must call `pcm1681_set_deemph(component)`, and DAC channels `1..8` map via `PCM1681_ATT_CONTROL(X)` (`0x01..0x06` for `1..6`, `X + 9` for `7..8`). In `pcm186x_hw_params()`, `if (priv->is_tdm_mode)` (`div_lrck = 256`) must precede `if (priv->is_provider_mode)`. [F71, F80, F94]

## Synchronization
- In `tas2781_hda_i2c.c`, all post-probe paths calling `tasdevice_*` register helpers must hold `tas_priv->codec_lock`. In `tascodec_init()`, `tas_priv->codec` must be set before `request_firmware_nowait()` because `tasdev_fw_ready()` reads it before locking `codec_lock`. In `tasdevice_dspfw_init()`, `tasdevice_dsp_prog_ctrl` and `tasdevice_dsp_conf_ctrl` must be added via `tasdev_add_kcontrols()` only after `tasdevice_dsp_parser()` succeeds. [F17, F19, F21]
- In `tas2764_codec_probe()`, `tas2764->component` assignment, `tas2764_reset()`, `regmap_reinit_cache()`, and `TAS2764_INT_MASK0..4` (`0` = unmask, `1` = mask) must complete before `devm_request_threaded_irq()` registers `tas2764_irq()` as `thread_fn` with `IRQF_ONESHOT`. [F26, F123, F143]
- `pcm1789_trigger()` is atomic and must defer `regmap_update_bits()` soft-reset to `pcm1789_work_queue()` via `schedule_work(&priv->work)`. `pcm1789_common_init()` must set `regmap`, `dev`, and `INIT_WORK(&pcm1789->work, ...)` before `devm_snd_soc_register_component()`, and `pcm1789_common_exit()` must call `flush_work(&priv->work)`. [F25, F142]

## Object Lifetimes
- In `tas2781_hda_i2c_probe()`, `tasdevice_init()` must run after `tas2781_read_acpi()` and before `pm_runtime_enable()` / `component_add()`; subsequent probe errors must jump to `err:` so `tas2781_hda_remove()` calls `tasdevice_remove()`, which must run only after `component_del()` and `pm_runtime_disable()`. [F7, F22]
- `tas2781_hda_unbind()` must clear `comp->playback_hook`, `comp->dev`, and `comp->name`, reset `fw_state = TASDEVICE_DSP_FW_PENDING`, and call `tas2781_hda_remove_controls()` before `tasdevice_config_info_remove()` and `tasdevice_dsp_remove(tas_hda->priv)`. `tasdevice_dsp_remove()` must also be called before reloading firmware in `tasdevice_dspfw_init()` and must set `tas_dev->fmw = NULL`. [F20, F58, F120, F151]
- `pcm3168a_probe()` and `pcm3168a_rt_resume()` must enable `scki` before `supplies`, and rollback (`err_regulator` -> `err_clk`) and `pcm3168a_disable()` must disable `supplies` before `scki`. `pcm512x_probe()` and `pcm512x_remove()` must unwind `regulator_bulk_enable()`, `clk_prepare_enable(sclk)`, and `pm_runtime_enable()` in reverse order (`err_pm`, `err_clk`, `err`). [F10, F130]

## API Contracts
- `tasdev_chn_switch()` must return `1` when changing `client->addr`, `0` when unchanged, or negative errno on `regmap_write()` failure; callers must validate `chn < tas_priv->ndev` beforehand because `tasdev_chn_switch()` does not check it. `tasdevice_dev_read/write/bulk_read/bulk_write/update_bits()` must validate `chn < tas_priv->ndev`, select `TASDEVICE_BOOK_ID(reg)` via `change_chn_book()`, and pass `TASDEVICE_PGRG(reg)` to `regmap`. [F27, F77, F78]
- `tas2781_get_i2c_res()` must skip `sb->slave_address == tas_priv->global_addr`, cap `tas_priv->ndev` at `TASDEVICE_MAX_CHANNELS`, and always return `1`. `tasdevice_dsp_remove()` and `tasdevice_*` firmware helpers cast `void *context` to `struct tasdevice_priv *`, so `tas2781_hda_i2c.c` must pass `tas_hda->priv` (never `tas_hda` or `tas_hda->hda_priv`). [F29, F76, F109, F110]
- `ACARD_SINGLE_RANGE_EXT_TLV` controls using `tas2781_amp_getvol`/`putvol` require `((1 << fls(xmax)) - 1) << xshift <= 0xff`. `pcm512x_find_sck()` and `pcm512x_pllin_dac_rate()` return `unsigned long` Hz (`0` on error), and `pcm512x_set_dividers()` must check for `0` before dividing. [F30, F45]
- TDM slot setters (`tas2764`, `tas2770`, `tas2780`, `tas2562`, `tas2552`, `pcm186x`) must check `tx_mask != 0` before calling `__ffs()`/`__fls()`. `tas2764`, `tas2770`, and `tas2780` must map a single set bit to both `left_slot` and `right_slot` (`channels_min = 1`, `channels_max = 2`), clear each consumed bit in `tx_mask`, and reject remaining `tx_mask != 0`, `rx_mask != 0`, or slot `>= slots`. `pcm186x_set_tdm_slot()` requires contiguous `tx_mask` bits and `__ffs(tx_mask) * slot_width <= 255`; `tas2552_set_dai_tdm_slot()` requires `(__ffs(tx_mask) + 1) == __fls(tx_mask)`; `tas2562`, `tas2770`, and `pcm3168a` must accept `slot_width == 0`. [F83, F86, F87, F91, F107, F146]
- `snd_soc_dai_ops` with direction-agnostic `.mute_stream` (`tas2764`, `tas2770`, `tas2780`, `tas2552`, `tas2562`, `pcm3168a`) must set `.no_capture_mute = 1`, and SmartAmp DAIs (`tas2552`, `tas2562`, `tas2764`, `tas2770`, `tas2780`) must define `.capture` and sense/feedback DAPM widgets/routes. [F145, F147]

## Error Handling
- In `tas2552_probe()`, failure after `pm_runtime_put_sync_autosuspend()` requires `pm_runtime_get_noresume()`. In `tas2764_parse_dt()` and `tas2770_parse_dt()`, non-`-EPROBE_DEFER` errors from `devm_gpiod_get_optional(dev, "shutdown", ...)` must set `sdz_gpio = NULL`. DAPM callbacks (`tas2562_dac_event`, `tas2770_dac_event`, `sense_event`) must return the status from power-control update helpers. [F14, F35, F38]
- In `tas2770_codec_suspend()`, if `!tas2770->sdz_gpio` and `snd_soc_component_update_bits()` fails, restore `regcache_cache_only(..., false)` and `regcache_sync()`, and on success set `ret = 0`. In `pcm186x_power_on()`, if `regcache_sync()` fails, restore `regcache_cache_only(..., true)` and call `regulator_bulk_disable()` without overwriting `ret`. [F36, F37]
- `tas2764_irq()` (`IRQF_SHARED`) must use `dev_crit_ratelimited()` / `dev_err_ratelimited()`, return `IRQ_NONE` when `latched[0] == 0`, and when `latched[0] != 0` set `TAS2764_INT_CLK_CFG_IRQZ_CLR` in `TAS2764_INT_CLK_CFG` (`TAS2764_INT_LTCH0..4` and `TAS2764_INT_CLK_CFG` must stay volatile). [F124, F155]

## External Contracts
- `tas2563_save_calibration()` must check `efi_rt_services_supported(EFI_RT_SUPPORTED_GET_VARIABLE)` (returning `-EINVAL` if false), keep `var8` and `efi_name` at `TAS2563_CAL_VAR_NAME_MAX` elements, `memset(efi_name, 0, sizeof(efi_name))` each inner loop before copying `k < sizeof(var8)` chars, query UEFI variables with 1-based `i + 1`, and pack `cd->data` as `p->ndev` records of 1-byte 0-based `i` plus `TASDEV_CALIB_N` `__be32` values. [F31, F41, F44, F114]
- `tasdevice_amp_putvol()` and `tasdevice_digital_putvol()` must clamp values via `tasdevice_clamp()`, update all `tas_priv->ndev` channels counting `err_cnt`, and return `(err_cnt == tas_priv->ndev) ? 0 : 1`. [F28, F150]
- In `pcm512x_set_dividers()` and `pcm186x_hw_params()`, `PCM512x_PLL_COEFF_0`/`4`, `PCM512x_*_CLKDIV*`, `PCM186X_BCK_DIV`, and `PCM186X_LRK_DIV` take `divider - 1`, while `PCM512x_PLL_COEFF_1..3` (J, D) and `PCM512x_IDAC_1`/`2` take unadjusted values. Hardware-mute `DECLARE_TLV_DB_SCALE` definitions (`tas2764_playback_volume`, `pcm3168a_dac/adc_tlv`, `pcm1789_dac_tlv`, `pcm179x_dac_tlv`, `pcm512x` `digital_tlv`) must set `mute = 1` and shift `min` down by one `step`. SPI codec drivers (`pcm179x`, `pcm186x`, `pcm3060`, `pcm3168a`, `pcm512x`) must keep `of_device_id` and `spi_device_id` tables synchronized. [F47, F136, F148]

## Known Pitfalls
- In `pcm512x_find_pll_coeff()`, after `for (R = 16; R; R--)` ends with `R == 0`, reset `R = 1` before `if (num > 0xffffffffUL / 10000) goto fallback;` (which guards `10000 * num`), and in `fallback:` compute `10000ULL * pll_rate * P` and `(u64)K * pllin_rate` using `DIV_ROUND_CLOSEST_ULL()` and `DIV_ROUND_DOWN_ULL()`. In `pcm3060_set_sysclk()`, `PCM3060_REG_CSEL` is inverted between DAC (`PCM3060_REG67`) and ADC (`PCM3060_REG72`), so set `PCM3060_REG_CSEL` for `CLK1` only on DAC and for `CLK2` only on ADC. [F95, F98, F101, F102]

## Other
- In `tas2764` and `tas2770`, deasserting `sdz_gpio`/`reset_gpio` or writing `TAS2764_RST`/`TAS2770_RST` requires `usleep_range(1000, 2000)` before register access, plus `regmap_reinit_cache()` after SW reset in codec probe. `tas2764_set_fmt()` and `tas2770_set_fmt()` must XOR base format polarity with `SND_SOC_DAIFMT_INV_MASK` for `FRAME_START`/`FPOL_MASK`. `pcm3168a_probe()` must request `gpio_rst` with `GPIOD_OUT_LOW | GPIOD_FLAGS_BIT_NONEXCLUSIVE`, sleep `DIV_ROUND_UP(3846 * 1000, sysclk)` ms, and assert `gpio_rst` (`1`) in `pcm3168a_remove()`. [F59, F122, F127, F134]
