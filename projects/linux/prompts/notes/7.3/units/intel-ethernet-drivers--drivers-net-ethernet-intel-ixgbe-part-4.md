# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ixgbe (part 4)

This component of `ixgbe` implements PHY and SFP+/QSFP+ transceiver management (`ixgbe_phy.c`), IEEE 1588 PTP clock and timestamping (`ixgbe_ptp.c`), SR-IOV VF provisioning and mailbox handling (`ixgbe_sriov.c`), hwmon thermal sensor sysfs (`ixgbe_sysfs.c`), X540 MAC/EEPROM/PHY operations (`ixgbe_x540.c`), and hardware register/descriptor definitions (`ixgbe_type.h`, `ixgbe_type_e610.h`).

## Architecture & Data Flow

- In `ixgbe_set_vf_multicasts()`, the untrusted entry count from `msgbuf[0]` (`IXGBE_VT_MSGINFO_MASK`) must be clamped to `IXGBE_MAX_VF_MC_ENTRIES` (30) before indexing `hash_list` (`&msgbuf[1]`) or `vfinfo->vf_mc_hashes`, and hashes/count must be stored in `vfinfo->vf_mc_hashes` and `vfinfo->num_vf_mc_hashes` so `ixgbe_restore_vf_multicasts()` can reprogram `IXGBE_MTA`, increment `hw->addr_ctrl.mta_in_use`, and update `IXGBE_VMOLR_ROMPE`. [F893, F910]
- In `ixgbe_set_vf_vlan()`, adding a VF VLAN set in `adapter->active_vlans` must first add `VMDQ_P(0)` via `set_vfta()`, and removing/failing to add a VF VLAN when `active_vlans` or `IXGBE_FLAG2_VLAN_PROMISC` is set must call `ixgbe_update_pf_promisc_vlvf()`. In `ixgbe_ndo_set_vf_vlan()`, setting non-zero `vlan`/`qos` when `vfinfo[vf].pf_vlan` is already non-zero must call `ixgbe_disable_port_vlan()` before `ixgbe_enable_port_vlan()`. In `ixgbe_clear_vf_vlans()`, clearing a VF bit in `IXGBE_VLVFB(word)` must preserve `IXGBE_VLVF(i)` and `IXGBE_VFTA` if any other VF pool bit remains set across the 64-bit `VLVFB` pair, and preserve `IXGBE_VFTA` if PF pool `VMDQ_P(0)` remains set. [F894, F895, F899]
- `ixgbe_set_vf_macvlan()` must keep `adapter->vf_mvs.l` and `adapter->mac_table` in lockstep by calling `ixgbe_del_mac_filter()` when freeing entries (`index <= 1`) and marking a `vf_macvlans` entry in-use (`free = false`, `vf = vf`) only after `ixgbe_add_mac_filter()` succeeds. Across VF resets in `ixgbe_vf_reset_event()` and `ixgbe_vf_reset_msg()`, transient VF state (VLANs, `num_vf_mc_hashes`, IPsec SAs, MACVLANs, `vf_api`, `PFMBMEM`, `PVFTDWBAHn/L`) must be cleared while preserving and re-applying PF-configured `vfinfo` fields (`pf_vlan`, `pf_qos`, `spoofchk_enabled`, `vf_mac_addresses`, `pf_set_mac`, `link_enable`). [F896, F897]
- VF Tx rate limiting requires a 10Gbps link stored in `adapter->vf_rate_link_speed` by `ixgbe_ndo_set_vf_bw()`; if `ixgbe_check_vf_rate_limit()` sees `ixgbe_link_mbps(adapter) != adapter->vf_rate_link_speed`, it must zero `vf_rate_link_speed` and all `vfinfo[i].tx_rate` and reprogram `IXGBE_RTTBCNRC`. In `ixgbe_pci_sriov_enable()`, `num_vfs` must not exceed `limit - num_rx_pools`, where `limit` is `IXGBE_MAX_VFS_8TC` (16, >4 TCs), `IXGBE_MAX_VFS_4TC` (32, 2..4 TCs), or `IXGBE_MAX_VFS_1TC` (64, <=1 TC) and `num_rx_pools` is the weight of `adapter->fwd_bitmask`. [F900, F912]
- On X550, X550EM_x, x550em_a, and E610, hardware time registers store 32-bit billions of cycles and 32-bit cycles; `ixgbe_ptp_read_X550()`, `ixgbe_ptp_convert_to_hwtstamp()`, and `ixgbe_ptp_gettimex()` must linearize them via `timespec64_to_ns()`, and `ixgbe_ptp_setup_sdp_X550()` must split `clock_edge` via `ns_to_timespec64()`. In `ixgbe_ptp_overflow_check()`, `ixgbe_ptp_rx_hang()`, `ixgbe_ptp_tx_hang()`, and `ixgbe_ptp_tx_hwtstamp_work()`, jiffies timestamps (`last_overflow_check`, `last_rx_ptp_check`, `rx_ring->last_rx_timestamp`, `ptp_tx_start`) must be compared via `time_is_before_jiffies()` and `time_after()`. [F937, F939]
- In `ixgbe_identify_sfp_module_generic()` and `ixgbe_identify_qsfp_module_generic()`, `hw->mac.ops.set_lan_id(hw)` must run before assigning core-specific `sfp_type` values, `sfp_setup_needed` must be set if `sfp_type` changes, and I2C read errors must reset `sfp_type` to `ixgbe_sfp_type_not_present`. In `ixgbe_get_sfp_init_sequence_offsets()` and `ixgbe_reset_phy_nl()`, EEPROM SFP init tables are traversed until `IXGBE_PHY_INIT_END_NL` (`0xFFFF`) in the ID list and `IXGBE_CONTROL_NL` with `edata == IXGBE_CONTROL_EOL_NL` (`0x0FFF`) in the data block, rejecting `0` or `0xFFFF` offsets. [F908, F917]
- On C3000 SoC (`x550em_a`), `ixgbe_mii_bus_init()` must only register an `mii_bus` on the lowest-numbered PCI function (`ixgbe_x550em_a_has_mii(hw)`), and all `x550em_a` MDIO callbacks (`ixgbe_x550em_a_mii_bus_read/write_c22/c45`) must acquire `IXGBE_GSSR_TOKEN_SM | IXGBE_GSSR_PHY0_SM` in addition to `hw->phy.phy_semaphore_mask`. `struct ixgbe_hw::back` and `struct mii_bus::priv` must always point to the owning `struct ixgbe_adapter`. [F909, F950]
- In `ixgbe_reset_hw_X540()`, `hw->mac.num_rar_entries` must be reset to `IXGBE_X540_MAX_TX_QUEUES` (128) before `hw->mac.ops.init_rx_addrs(hw)`, and when a valid `hw->mac.san_addr` is programmed into `san_mac_rar_index = num_rar_entries - 1`, `num_rar_entries` must be decremented. In `ixgbe_calc_eeprom_checksum_X540()`, EEPROM section pointers (`IXGBE_PCIE_ANALOG_PTR` .. `IXGBE_FW_PTR - 1`, excluding `IXGBE_PHY_PTR` and `IXGBE_OPTION_ROM_PTR`) and lengths must be skipped if `0`, `0xFFFF`, `pointer >= word_size`, or `pointer + length >= word_size`. [F906, F918]
- Binary firmware, OROM, and ACI/HIC structures in `ixgbe_type_e610.h` and `ixgbe_type.h` with unaligned multi-byte fields (`ixgbe_orom_civd_info`, `ixgbe_aci_cmd_get_link_status_data`, `ixgbe_aci_cmd_nvm_comp_tbl`, `ixgbe_hic_internal_phy_req`) must be marked `__packed`. [F919]

## Synchronization

- `ixgbe_get_swfw_sync_semaphore()` acquires `IXGBE_SWSM_SMBI` before `IXGBE_SWFW_REGSMP` and must call `ixgbe_release_swfw_sync_semaphore()` (which releases `IXGBE_SWFW_REGSMP` before `IXGBE_SWSM_SMBI`) if `REGSMP` times out. In `ixgbe_acquire_swfw_sync_X540()`, every acquired register semaphore must be released via `ixgbe_release_swfw_sync_semaphore(hw)` before sleeping or returning. Because X540 SWFW semaphore routines (`ixgbe_acquire/release_swfw_sync_X540`, `eeprom_ops_X540`, locked `phy_ops_X540`) sleep via `usleep_range()`, they require process context. [F859, F860, F980]
- Code holding `IXGBE_GSSR_EEP_SM` (`ixgbe_calc_eeprom_checksum_X540()` and locked sections of `ixgbe_validate/update_eeprom_checksum_X540()`) must call `ixgbe_read_eerd_generic()` / `ixgbe_write_eewr_generic()` rather than `hw->eeprom.ops.read/write`. [F861]
- In `ixgbe_read/write_i2c_combined_generic_int()` and `ixgbe_read/write_i2c_byte_generic_int()`, when `lock` is true, `ixgbe_i2c_bus_clear(hw)` must run before releasing `hw->phy.phy_semaphore_mask`. Unlike `ixgbe_read_i2c_byte_generic_int()` (which acquires/releases `swfw_mask` each retry), `ixgbe_write_i2c_byte_generic_int()` acquires `swfw_mask` once before the `do-while` loop and must not release it at the `fail:` label inside the loop. [F862, F933]
- In `ixgbe_ptp_init()`, `spin_lock_init(&adapter->tmreg_lock)` must precede `ixgbe_ptp_create_clock()`, and `INIT_WORK(&adapter->ptp_tx_work, ...)` plus `ixgbe_ptp_reset(adapter)` must complete before `set_bit(__IXGBE_PTP_RUNNING, &adapter->state)`. In `ixgbe_ptp_suspend()` and `ixgbe_ptp_tx_hang()`, `cancel_work_sync(&adapter->ptp_tx_work)` must precede `ixgbe_ptp_clear_tx_timestamp(adapter)`. [F863, F864, F865]
- `adapter->tmreg_lock` (`spin_lock_irqsave`) protects `adapter->hw_tc`, `adapter->hw_cc`, and `IXGBE_SYSTIM*` reads across all PTP clock/overflow/reset paths. `ixgbe_ptp_start_cyclecounter()` publishes `adapter->base_incval` via `WRITE_ONCE` + `smp_mb()`, pairing with `smp_mb()` + `READ_ONCE` in `ixgbe_ptp_adjfine_82599()`. [F869, F871]
- In `ixgbe_pci_sriov_enable()`, `__ixgbe_enable_sriov()`, `ixgbe_vf_configuration()`, and `ixgbe_sriov_reinit()` must complete before `pci_enable_sriov()`. `ixgbe_msg_task()` runs in hardirq (`ixgbe_msix_other`) holding `spin_lock_irqsave(&adapter->vfs_lock, flags)`, so VF reset/mailbox handlers (`ixgbe_vf_reset_event`, `ixgbe_rcv_msg/ack_from_vf`) must not sleep, and `ixgbe_disable_sriov()` must zero `adapter->num_vfs` under `vfs_lock` before dropping `vfdev` refs and freeing `vfinfo`/`mv_list`. [F872, F873, F973]
- In `ixgbe_rcv_msg_from_vf()` and `ixgbe_rcv_ack_from_vf()`, any non-`IXGBE_VF_RESET` message/ACK must be NACKed unless `vfinfo[vf].clear_to_send` is set (enabled at the end of `ixgbe_vf_reset_msg()` and cleared before pinging VFs in `ixgbe_set_vf_link_state()`, `ixgbe_ndo_set_vf_trust()`, and `ixgbe_check_mdd_event()`). [F874]

## Object Lifetimes

- In `ixgbe_ptp_create_clock()`, if `!IS_ERR_OR_NULL(adapter->ptp_clock)` reuse it without resetting `tstamp_config`; if `ptp_clock_register()` returns an `ERR_PTR`, reset `adapter->ptp_clock = NULL` because `ixgbe_ptp_stop()` and `ixgbe_ptp_check_pps_event()` only check for non-NULL. Only `ixgbe_ptp_stop()` (never `ixgbe_ptp_suspend()`) unregisters the clock, and it must call `ixgbe_ptp_suspend(adapter)` before `ptp_clock_unregister(adapter->ptp_clock)`. [F853, F866, F998]
- In `ixgbe_ptp_tx_hwtstamp()`, `adapter->ptp_tx_skb` must be set to `NULL` and `__IXGBE_PTP_TX_IN_PROGRESS` cleared via `clear_bit_unlock(&adapter->state)` before calling `skb_tstamp_tx()` and `dev_kfree_skb_any()` on the local `skb`. [F854]
- `ixgbe_get_first_secondary_devfn()` drops `rp_pdev` on all paths and returns an owned `pci_dev` from `pci_get_domain_bus_and_slot(0, bus, 0)` that callers (`ixgbe_x550em_a_has_mii()`) must `pci_dev_put()`. `ixgbe_mii_bus_init()` uses `devm_mdiobus_alloc()` with non-devm `mdiobus_register()`, so teardown must call `mdiobus_unregister()` without `mdiobus_free()`. `ixgbe_sysfs_init()` uses `devm_kzalloc()` and `devm_hwmon_device_register_with_groups()`, so `ixgbe_sysfs_exit()` must not manually free or unregister them. [F856, F857, F858]

## API Contracts

- `mac_ops_X540` leaves `init_thermal_sensor_thresh`, `disable_mdd`, `handle_mdd`, `restore_mdd_vf`, and `set_ethertype_anti_spoofing` `NULL`, and `adapter->ptp_setup_sdp` is `NULL` on `ixgbe_mac_82599EB`, so all callers must null-check them. Callers of `handle_mdd` (`ixgbe_check_mdd_event()`) must pass a zeroed `DECLARE_BITMAP(vf_bitmap, 64)`. [F881, F883, F951]
- `ixgbe_sysfs_init()` must return `0` without registering hwmon if `init_thermal_sensor_thresh` is `NULL` or returns non-zero, only add sensors with `location != 0`, call `sysfs_attr_init()` on each dynamic `dev_attr.attr` in `ixgbe_add_hwmon_attr()`, and keep max attributes (`IXGBE_MAX_SENSORS * 4`) in sync with `struct hwmon_buff::hwmon_list` and `attrs` (+1 for NULL). [F885, F947, F999]
- On X550 and E610, `ixgbe_ptp_read_X550()` and `ixgbe_ptp_gettimex()` must read `IXGBE_SYSTIMR` before `IXGBE_SYSTIML/H` to latch system time. Packet timestamp registers stay locked until `IXGBE_RXSTMPH`/`IXGBE_TXSTMPH` is read, so `ixgbe_ptp_rx_rgtstamp()` and `ixgbe_ptp_tx_hwtstamp()` must read low before high, and `ixgbe_ptp_clear_tx_timestamp()` must read `IXGBE_TXSTMPH` to unlatch. [F955, F956]
- `ixgbe_read/write_i2c_byte_generic()` (and `_unlocked`/`phy.ops` variants) take `(hw, byte_offset, dev_addr, data)` (offset before addr), whereas `ixgbe_read/write_i2c_combined_generic_int()` take `(hw, addr, reg, val, lock)`. `ixgbe_read/write_phy_reg_generic()` and `_mdi()` take `(hw, reg_addr, device_type, phy_data)` (reg before MMD), whereas `ixgbe_mii_bus_read_generic_c45()` takes `(bus, addr, devad, regnum)`. [F887, F888]
- `ixgbe_reset_phy_generic()`, `ixgbe_setup_phy_link_generic/tnx()`, `ixgbe_reset_phy_nl()`, and `ixgbe_set_copper_phy_power()` must abort if `ixgbe_check_reset_blocked(hw)` is true. `ixgbe_blink_led_start/stop_X540()` must reject `index > 3` before `IXGBE_LED_*` shifts. `eeprom.ops.read/write_buffer` (`ixgbe_read_eerd/write_eewr_buffer_X540()`) take 16-bit word offsets and word counts, not bytes; in `ixgbe_update_flash_X540()`, on `hw->revision_id == 0`, if `IXGBE_EEC_SEC1VAL` is set after the first `IXGBE_EEC_FLUP`, a second `FLUP` + poll must run. [F942, F946, F964, F965]
- `ixgbe_write_qde()` must call `IXGBE_WRITE_FLUSH(hw)` before each `IXGBE_QDE` write, and `ixgbe_rcv_msg_from_vf()` must call `IXGBE_WRITE_FLUSH(hw)` after `ixgbe_read_mbx()` before `ixgbe_write_mbx()`. `__ixgbe_enable_sriov()` must return `-EINVAL` if `adapter->xdp_prog` is loaded. [F972, F984]

## Error Handling

- `ixgbe_calc_eeprom_checksum_X540()` returns a 16-bit checksum or `-EIO`, and `ixgbe_set_vf_mac()` (`ixgbe_add_mac_filter()`) returns a non-negative RAR index or negative errno, so callers must store the result in a signed `int` and check `< 0`. `ixgbe_check_for_rst/msg/ack()` return `0` when an event is pending and `-EIO` otherwise, so callers must test `!ixgbe_check_for_*(hw, vf)`. [F877, F878, F879]
- `ixgbe_ptp_set_timestamp_mode()` must stage flag changes in local `aflags` and write `adapter->flags` (and `adapter->tstamp_config` in `ixgbe_ptp_hwtstamp_set()`) only after validation and register programming succeed. Unsupported VF API versions in `ixgbe_negotiate_vf_api()` must be logged with `e_dbg` before returning `-1`. [F886, F993]

## External Contracts

- `ixgbe_pci_sriov_enable()` must return positive `num_vfs` on success or negative errno on failure. When `vfinfo[vf].pf_set_mac && !vfinfo[vf].trusted`, `ixgbe_set_vf_mac_addr()` must reject `new_mac != vf_mac_addresses` and `ixgbe_set_vf_macvlan_msg()` must reject `index > 0`. `ixgbe_set_vf_vlan_msg()` must reject requests when `pf_vlan` or `hw_tcs` is non-zero and return `0` for `!vid && !add` without calling `ixgbe_set_vf_vlan()`. [F880, F988, F989]
- In `ixgbe_update_vf_xcast_mode()`, untrusted VFs must be clamped to `IXGBEVF_XCAST_MODE_MULTI`, and `PROMISC` must return `-EOPNOTSUPP` on `<= ixgbe_mac_82599EB` or `-EPERM` when `!(IXGBE_FCTRL & IXGBE_FCTRL_UPE)`. `ixgbe_set_vf_lpe()` must enforce `max_frame` in `[ETH_MIN_MTU, IXGBE_MAX_JUMBO_FRAME_SIZE]` and on `82599EB` with legacy VF APIs reject `> ETH_FRAME_LEN + ETH_FCS_LEN` and clear `IXGBE_VFRE`. `ixgbe_get_vf_reta()` and `ixgbe_ndo_set_vf_rss_query_en()` are restricted to 82599/X540 (packing 16 2-bit entries per `u32` into 8 dwords). [F911, F921, F990]
- In `ixgbe_ptp_rx_pktstamp()`, X550/E610 in-packet Rx timestamps (`__le64` at `skb->len - IXGBE_TS_HDR_LEN`) must be read as little-endian and trimmed via `__pskb_trim()`. SFF-8472 capability masks in `ixgbe_phy.h` (`IXGBE_SFF_BASEBX10_CAPABLE` = `0x40`) are powers of two and `IXGBE_SFF_BITRATE_NOMINAL` is in 100 MBd units (`0xD` = 1.25 Gb/s). In `ixgbe_sysfs.c`, temperature/threshold show callbacks must multiply by `1000` (millidegrees) and format `temp%u_*` with 1-based `offset + 1`. [F889, F890, F920]

## Known Pitfalls

- In `ixgbe_get_vfs()`, the `pci_get_device()` loop must `continue` (not `break`) when `vf >= adapter->num_vfs` and call `pci_dev_get(vfdev)` when storing `vfinfo[vf].vfdev` because `pci_get_device()` drops the previous ref. In `ixgbe_reset_phy_generic()`, `ixgbe_phy_x550em_ext_t` polls for `IXGBE_MDIO_TX_VENDOR_ALARMS_3_RST_MASK` to be set, whereas other PHYs poll for `MDIO_CTRL1_RESET` to clear. [F923, F931]
- In `ixgbe_ptp_setup_sdp_X540/X550()`, `NS_PER_HALF_SEC` and `(u64)rem` must be `u64` before `<< cc->shift` (up to 28) and `div_u64()`, and 32-bit `IXGBE_READ_REG()` results for `IXGBE_SYSTIMH`/`TXSTMPH`/`RXSTMPH` must be cast to `u64` before `<< 32`. Per-pool 64-bit register pairs (`IXGBE_VFRE`, `VFTE`, `VMECM`, `VLVFB`) must be indexed with `vf / 32` and bit `vf % 32`. `struct hwmon_attr::name` is 12 bytes, fitting `"temp%u_label"` only for single-digit `offset + 1` (`IXGBE_MAX_SENSORS` = 3). [F935, F936, F940, F948]
