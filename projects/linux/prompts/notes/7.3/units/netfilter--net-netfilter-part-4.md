# NETFILTER — net/netfilter (part 4)

Implements the Netfilter NAT core (`nf_nat_core.c`), L3/L4 header manipulation and checksum updates (`nf_nat_proto.c`), NAT modes (masquerade, redirect, OpenvSwitch, BPF), NAT application helpers (FTP, IRC, SIP, TFTP, Amanda), SYNPROXY TCP handshake offloader (`nf_synproxy_core.c`), userspace packet queueing (`nf_queue.c`), and socket option dispatch (`nf_sockopt.c`).

## Architecture & Data Flow
- In `nf_nat_packet`, `nf_nat_icmp_reply_translation`, and `nf_nat_icmpv6_reply_translation`, `statusbit` (from `NF_NAT_MANIP_SRC`/`DST` -> `IPS_SRC_NAT`/`IPS_DST_NAT`) must be inverted via `statusbit ^= IPS_NAT_MASK` when `dir == IP_CT_DIR_REPLY` before testing `ct->status`. In ICMP/ICMPv6 reply translation, translate the embedded inner packet first using `!manip` and `&ct->tuplehash[!dir].tuple`, recompute the ICMP/ICMPv6 checksum (unless `CHECKSUM_PARTIAL`), and finally translate the outer packet using `manip` and the `!dir` tuple. [F630, F646]
- In `nf_nat_inet_fn` and `nf_ct_nat_execute`, `case IP_CT_RELATED:` and `case IP_CT_RELATED_REPLY:` must fall through to `case IP_CT_NEW:` for non-ICMP/ICMPv6 packets so `!nf_nat_initialized(ct, maniptype)` initializes NAT state on the related conntrack. [F650]
- `nf_nat_inet_fn` must return `NF_ACCEPT` without initializing or applying NAT when `in_vrf_postrouting(state)` holds (`NF_INET_POST_ROUTING` and `netif_is_l3_master(state->out)`). If `nf_nat_oif_changed(state->hook, ctinfo, nat, state->out)` is true (`NF_INET_POST_ROUTING` in `IP_CT_DIR_ORIGINAL` with non-zero `nat->masq_index != state->out->ifindex`), it must call `nf_ct_kill_acct(ct, ctinfo, skb)` and return `NF_DROP`. [F698, F699]
- `__nf_nat_mangle_tcp_packet` and `nf_nat_mangle_udp_packet` must reject expansions via `enlarge_skb` when `skb->len + extra > 65535` before `pskb_expand_head` and `mangle_contents`. In `mangle_contents`, shift trailing payload (`data + match_offset + match_len` to `skb_tail_pointer(skb)`) to `data + match_offset + rep_len` with `memmove` before `memcpy` and before `skb_put`/`__skb_trim`; when `skb->len` changes, update `ip_hdr(skb)->tot_len` + `ip_send_check` or `ipv6_hdr(skb)->payload_len`, and in `nf_nat_mangle_udp_packet` set `udph->len = htons(skb->len - protoff)` before `nf_nat_csum_recalc`. [F621, F637, F669]
- `tcp_manip_pkt` and `sctp_manip_pkt` only require `hdrsize = 8` when `skb->len < hdroff + sizeof(*hdr)` and skip L4 checksum updates when `hdrsize < sizeof(*hdr)` (for truncated inner headers in ICMP errors). `gre_manip_pkt` must pass `hdroff + sizeof(*pgreh) - 8` (not `hdroff + sizeof(*pgreh)`) to `skb_ensure_writable` for PPTP GRE headers. [F636, F691]
- `nf_nat_l4proto_unique_tuple` treats `range->min_proto` and `range->max_proto` as inclusive big-endian bounds, swaps `min` and `max` if `max < min` for TCP/UDP/UDPLite/SCTP so `range_size = max - min + 1 >= 1`, and wraps ports via `htons(min + off % range_size)`. It caps `attempts` at `NF_NAT_MAX_ATTEMPTS`, and on `another_round` returns if `attempts >= range_size || attempts < 16`, otherwise halving `attempts /= 2` with a new random `off`. [F640, F654]
- `hash_by_src()` and `find_best_ips_proto()` scale 32-bit hashes into `[0, nf_nat_htable_size)` and `[0, dist)` using `reciprocal_scale()`, which widens the 32-bit unsigned operands to `u64` before multiplying and shifting right by 32 (`((u64)val * ep_ro) >> 32`). [F664]
- `nf_nat_register_fn` and `nf_nat_unregister_fn` must validate `pf < ARRAY_SIZE(nat_net->nat_proto_net)` and map the sparse `ops->hooknum` to the dense index `0 .. ops_count - 1` by matching `orig_nat_ops[i].hooknum` / `nat_ops[i].hooknum` before indexing `nat_ops`. [F641]
- In `nf_xfrm_me_harder`, cast `dst` (`struct dst_entry *`) to `struct xfrm_dst *` to access `->route` only after checking `dst->xfrm` is non-NULL; clear `sk` to `NULL` before `xfrm_lookup` if `!net_eq(net, sock_net(sk))`; and after replacing `skb_dst`, call `pskb_expand_head` if `skb_headroom(skb) < skb_dst(skb)->dev->hard_header_len`. [F678, F697]
- In `synproxy_parse_options`, compute signed `int length = (th->doff * 4) - sizeof(*th)` and reject `length < 0` before `skb_header_pointer`; for each non-NOP/EOL option verify `length >= 2`, `opsize >= 2`, and `opsize <= length`, read multi-byte fields with `get_unaligned_be16`/`get_unaligned_be32`, and clamp `opts->wscale` to `TCP_MAX_WSCALE` (`14`). [F631, F703]
- `synproxy_options_size` and `synproxy_build_options` must stay synchronized on exact 4-byte word counts, starting at `(__be32 *)(th + 1)` and writing the exact words reserved by `skb_put(nskb, sizeof(*nth) + synproxy_options_size(opts))`. Synthetic TCP packets in `nf_synproxy_core.c` must call `skb_reserve(nskb, MAX_TCP_HEADER)` before building headers and set `CHECKSUM_PARTIAL` (`csum_start`, `csum_offset`, and inverted pseudo-header checksum in `nth->check`) in `synproxy_send_tcp[_ipv6]`. [F673, F702]
- In `ipv4_synproxy_hook` and `ipv6_synproxy_hook`, when a `TCP_CONNTRACK_CLOSE` conntrack is reopened by an original-direction SYN (`th->syn && !th->ack && CTINFO2DIR(ctinfo) == IP_CT_DIR_ORIGINAL`), reset both `nf_ct_seqadj_init(ct, ctinfo, 0)` and `synproxy->tsoff = 0` before falling through to `TCP_CONNTRACK_SYN_SENT`. [F627]
- `__nf_queue` must allocate `sizeof(*entry) + route_key_size` bytes where `route_key_size` matches `state->pf` (`sizeof(struct ip_rt_info)` for `AF_INET`, `sizeof(struct ip6_rt_info)` for `AF_INET6`, `0` otherwise), and only call `nf_ip_saveroute` or `nf_ip6_saveroute` for that matching `pf`. [F643]

## Synchronization
- Insertions and deletions of `ct->nat_bysource` in `nf_nat_bysource[h]` (`nf_nat_setup_info`, `nf_nat_cleanup_conntrack`) must hold `spin_lock_bh(&nf_nat_locks[h % CONNTRACK_LOCKS])` where `h` is hashed from `ct->tuplehash[IP_CT_DIR_ORIGINAL].tuple` via `hash_by_src` (whose stack key `combined` must stay aligned to `SIPHASH_ALIGNMENT` and zero-filled via `memset` before `siphash`), while readers (`find_appropriate_src`) traverse under RCU. [F580, F642]
- `nf_ct_nat_ext_add` and `nf_nat_setup_info` must only mutate `ct->ext`, `ct->tuplehash[IP_CT_DIR_REPLY].tuple`, and `ct->status` (updated via non-atomic bitwise OR) when `!nf_ct_is_confirmed(ct)` holds. [F582]
- When `nf_nat_used_tuple_new` or `nf_nat_used_tuple_harder` inspects a colliding conntrack from `nf_conntrack_find_get`, it must recheck `thash->tuple.dst.dir`, read `ct->status` and `ct->proto.tcp.state` with `READ_ONCE`, and call `nf_ct_put(ct)` on all paths. [F584]
- In `nf_nat_sip_expected`, traversing `&help->expectations` on `ct->master` to find `pair_exp` must hold `spin_lock_bh(&nf_conntrack_expect_lock)`. In `nf_nat_redirect_ipv6`, iterating `&idev->addr_list` on `struct inet6_dev *idev` must hold `read_lock_bh(&idev->lock)`. [F589, F591]
- In `nf_nat_sip_fini`, `nf_nat_ftp_fini`, `nf_nat_irc_fini`, and `nf_nat_tftp_fini`, the RCU hook pointer (`nf_nat_sip_hooks`, `nf_nat_ftp_hook`, `nf_nat_irc_hook`, `nf_nat_tftp_hook`) must be cleared with `RCU_INIT_POINTER(..., NULL)` followed by `synchronize_rcu()` before unload. [F590]

## Object Lifetimes
- Before `__nf_queue` passes `entry` to `qh->outfn(entry, queuenum)`, it must convert any prefetched non-refcounted `skb->sk` to a refcounted `sock_edemux` socket, call `skb_dst_force(skb)`, and call `nf_queue_entry_get_refs(entry)`. `nf_queue_entry_get_refs` acquires `entry->state.sk` via `refcount_inc_not_zero` before calling `dev_hold` on `state->in`, `state->out`, `entry->physin`, and `entry->physout`: if `nf_queue_entry_get_refs` returns `false`, callers (`__nf_queue`, `nf_queue_entry_dup`) must call `kfree(entry)`, whereas if `qh->outfn` fails after refs are acquired, `__nf_queue` must call `nf_queue_entry_free(entry)`. [F563, F586]
- `nf_sockopt_find` acquires `ops->owner` via `try_module_get` under `nf_sockopt_mutex` (calling `module_put` if the option is out of range) and unlocks `nf_sockopt_mutex` before returning; `nf_setsockopt` and `nf_getsockopt` must call `module_put(ops->owner)` after `ops->set` or `ops->get`. [F566]
- `nf_nat_masquerade_inet_register_notifiers` registers `masq_dev_notifier`, `masq_inet_notifier`, and `masq_inet6_notifier` under `masq_mutex` when `masq_refcnt` transitions `0 -> 1`, and on error must unregister prior notifiers in reverse order and decrement `masq_refcnt` before unlocking `masq_mutex`. `nf_nat_inet_register_fn` registers `NFPROTO_IPV6` hooks before `NFPROTO_IPV4`, and if `NFPROTO_IPV4` fails it must roll back `NFPROTO_IPV6` via `nf_nat_unregister_fn`. [F568, F579]
- In `nf_nat_setup_info`, any fallible operation like `nfct_seqadj_ext_add(ct)` must succeed before linking `ct->nat_bysource` into `nf_nat_bysource` and setting `IPS_SRC_NAT_DONE` or `IPS_DST_NAT_DONE` in `ct->status`. During `nf_nat_cleanup`, `nf_nat_proto_clean` must atomically clear `IPS_SRC_NAT_DONE_BIT` via `test_and_clear_bit` and call `nf_nat_cleanup_conntrack(ct)` for null-bound conntracks, and `synchronize_net()` must run after clearing `nf_nat_hook` before `kvfree(nf_nat_bysource)`. [F569, F570]
- `nf_nat_ipv4_local_in` and `nf_nat_ipv6_local_in` must call `skb_orphan(skb)` when `nf_nat_ipv[46]_fn` returns `NF_ACCEPT`, `skb->sk` is non-NULL and not `inet_sk_transparent(sk)`, and SNAT changed the source address or `nf_nat_inet_port_was_mangled(skb, sk->sk_dport)` is true. In `nf_nat_ipv4_pre_routing` and `nf_nat_ipv6_in`, when DNAT modifies the destination IP and the verdict is not `NF_DROP` or `NF_STOLEN`, `skb_dst_drop(skb)` must be called. [F576, F577]
- `synproxy_send_tcp` and `synproxy_send_tcp_ipv6` take ownership of `nskb`, only attaching `nfct` and calling `nf_conntrack_get(nfct)` after routing (`ip_route_me_harder` or `nf_ip6_route` + `xfrm_lookup`) succeeds, and calling `kfree_skb(nskb)` on routing failure. In `ipv4_synproxy_hook` and `ipv6_synproxy_hook`, returning `NF_STOLEN` requires calling `consume_skb(skb)` first, whereas returning `NF_DROP` must not free `skb`. [F573, F574]
- `synproxy_net_init` allocates `snet->tmpl` via `nf_ct_tmpl_alloc`, freeing it with `nf_ct_tmpl_free(ct)` (along with `free_percpu(snet->stats)`) on init error, whereas `synproxy_net_exit` must release it with `nf_ct_put(snet->tmpl)`. [F578]

## API Contracts
- Callers of `nf_unregister_queue_handler` must flush all queued packets before unregistering `nf_queue_handler`, and every packet accepted by `qh->outfn` must eventually be reinjected or freed via `nf_queue_entry_free`. `nf_queue` passes `verdict >> NF_VERDICT_QBITS` as `queuenum` to `__nf_queue`, returns `1` without freeing `skb` only when `__nf_queue` returns `-ESRCH` and `verdict & NF_VERDICT_FLAG_QUEUE_BYPASS` is set, and otherwise frees `skb` on negative return and returns `0`. [F565, F610]
- Callers of `nf_ct_nat_ext_add` and `nfct_nat` (`nf_nat_masquerade_ipv4`, `nf_nat_masquerade_ipv6`, `nf_nat_oif_changed`, `device_cmp`) must NULL-check the returned `struct nf_conn_nat *` before dereferencing it. [F596]
- `nf_nat_alloc_null_binding`, `nf_nat_packet`, `nf_nat_icmp_reply_translation`, and `nf_nat_icmpv6_reply_translation` take an `NF_INET_*` `hooknum` (converted via `HOOK2MANIP(hooknum)`), whereas `nf_nat_setup_info` and `nf_nat_manip_pkt` take `enum nf_nat_manip_type` directly. [F599]
- `nf_ct_nat` must read the requested manipulation mask from `*action`, immediately reset `*action = 0` before any early return, and only set `BIT(maniptype)` in `*action` for each `nf_ct_nat_execute` call that returns `NF_ACCEPT`. [F600]
- `__nf_nat_mangle_tcp_packet` and `nf_nat_mangle_udp_packet` require `match_offset` to be relative to the start of the L4 payload (`protoff + tcph->doff * 4` or `protoff + sizeof(*udph)`), so callers like `mangle_packet` in `nf_nat_sip.c` whose `matchoff` is relative to `dataoff` must add `dataoff - baseoff`. [F605]
- `nf_sockopt_find` returns `ERR_PTR(-ENOPROTOOPT)` on failure (never `NULL`) and treats `[set_optmin, set_optmax)` and `[get_optmin, get_optmax)` as half-open intervals; callers (`nf_setsockopt`, `nf_getsockopt`) must check `IS_ERR(ops)`. [F612]

## Error Handling
- Callers of `nf_nat_setup_info` and `__nf_nat_alloc_null_binding` that return standard negative errnos (e.g. `nfnetlink_parse_nat_setup`) must map `NF_DROP` (`0`) to a negative errno like `-ENOMEM` and `NF_ACCEPT` (`1`) to `0`. Conversely, `nf_nat_icmp_reply_translation` and `nf_nat_icmpv6_reply_translation` return `1` on success and `0` on failure, which callers (`nf_nat_ipv[46]_fn`, `nf_ct_nat_execute`) must map to `NF_ACCEPT` and `NF_DROP`. [F593, F601]
- Callers of `ipv6_skip_exthdr` (`nf_nat_ipv6_manip_pkt`, `nf_nat_ipv6_fn`, `nf_ct_nat_execute`, `ipv6_synproxy_hook`) must store its return value in a signed `int` and check `< 0` before using it as an `unsigned int` offset. [F602]
- In `nf_xfrm_me_harder` and `synproxy_send_tcp_ipv6`, check `IS_ERR(dst)` on the return of `xfrm_lookup` before calling `skb_dst_set`, and in `nf_xfrm_me_harder` only call `skb_dst_drop(skb)` after `xfrm_lookup` succeeds. In `nf_nat_ipv4_out`, `nf_nat_ipv4_local_fn`, `nf_nat_ipv6_out`, and `nf_nat_ipv6_local_fn`, negative errnos from `ip_route_me_harder`, `nf_ip6_route_me_harder`, or `nf_xfrm_me_harder` must be wrapped with `NF_DROP_ERR(err)`. [F603, F604]
- In `ipv4_synproxy_hook` and `ipv6_synproxy_hook`, `nfct_synproxy(ct)` and `nf_ct_seqadj(ct)` are optional extensions from `snet->tmpl`; hooks must check `if (!synproxy) return NF_ACCEPT;` before accessing `synproxy` or calling `nf_ct_seqadj_init`. [F614]

## External Contracts
- `synproxy_cpu_seq_start` and `synproxy_cpu_seq_next` use `*pos == 0` for `SEQ_START_TOKEN` and 1-based `*pos = cpu + 1` for CPUs in `0 .. nr_cpu_ids - 1`, and `synproxy_cpu_seq_show` must format six tab-separated `%08x` columns with the first column (`entries`) fixed at `0`. [F644]
- `nf_nat_ftp` and `nf_nat_irc` must retain their no-op `ports` module parameter (`module_param_call(ports, warn_set, NULL, NULL, 0)`) returning `0`. [F645]

## Known Pitfalls
- In `nf_nat_ipv4_manip_pkt` and `nf_nat_ipv6_manip_pkt`, call `l4proto_manip_pkt` before overwriting `iph->saddr`/`daddr` or `ipv6h->saddr`/`daddr`, because `nf_csum_update` reads pre-NAT L3 addresses from the packet header. Furthermore, reload `iph`, `ipv6h`, and `inside` from `skb->data` after `l4proto_manip_pkt` or `nf_nat_ipv[46]_manip_pkt` (in `nf_nat_ipv[46]_manip_pkt` and `nf_nat_icmp[v6]_reply_translation`), and in `__nf_nat_mangle_tcp_packet` / `nf_nat_mangle_udp_packet` compute `tcph`/`udph` from `skb->data + protoff` only after `skb_ensure_writable` and `enlarge_skb`, because head reallocation invalidates pointers. [F618, F619, F620]
- In `ipv4_synproxy_hook` and `ipv6_synproxy_hook` (`TCP_CONNTRACK_SYN_RECV`), mask `opts.options` to clear `NF_SYNPROXY_OPT_MSS | NF_SYNPROXY_OPT_WSCALE | NF_SYNPROXY_OPT_SACK_PERM`, swap `opts.tsval`/`opts.tsecr` before `synproxy_send_server_ack[_ipv6]`, and swap them back before `synproxy_send_client_ack[_ipv6]`. [F628]
- In `nf_nat_icmp_reply_translation` and `nf_nat_icmpv6_reply_translation`, `ICMP_REDIRECT` and `NDISC_REDIRECT` require all bits of `IPS_NAT_DONE_MASK` set (`(ct->status & IPS_NAT_DONE_MASK) == IPS_NAT_DONE_MASK`) and all bits of `IPS_NAT_MASK` clear (`!(ct->status & IPS_NAT_MASK)`), or else return `0` to drop. [F647]
- In `nf_nat_proto.c`, `ipv6_addr_cmp` returns non-zero when addresses differ (`nf_nat_ipv6_local_in`, `nf_nat_ipv6_in`), whereas `nf_inet_addr_cmp` returns non-zero when addresses are equal (must be negated as `!nf_inet_addr_cmp(...)` in `nf_nat_ipv6_out` and `nf_nat_ipv6_local_fn`). When constructing an IPv4 `union nf_inet_addr` (e.g. `newrange.min_addr`/`max_addr` in `nf_nat_masquerade_ipv4` or `addr` in `masq_inet_event`), zero the entire 16-byte union before setting `.ip` because `nf_inet_addr_cmp` compares all 128 bits. [F648, F674]
- In `find_best_ips_proto`, pass `jhash2` the 32-bit word count `sizeof(tuple->src.u3) / sizeof(u32)` (not byte size), and compute `max` as `sizeof(var_ipp->ip) / sizeof(u32) - 1` or `sizeof(var_ipp->ip6) / sizeof(u32) - 1` when indexing `u32` array `all[]`. [F668]
