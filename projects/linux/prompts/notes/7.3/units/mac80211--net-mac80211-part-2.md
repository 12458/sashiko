# MAC80211 — net/mac80211 (part 2)

Core device, virtual interface (`iface.c`), MLO link (`link.c`), key (`key.c`, `fils_aead.c`), HT/HE (`ht.c`, `he.c`), IBSS (`ibss.c`), mesh (`mesh.c`), LED (`led.c`), and hardware lifecycle (`main.c`, `ieee80211_i.h`) management in mac80211.

## Architecture & Data Flow

- Trailing members `conf` (`ieee80211_key`, `ieee80211_chanctx`), `txq` (`txq_info`), and `vif` (`ieee80211_sub_if_data`) end with flexible/driver-private data and must remain last. In `ieee80211_if_add`, align the `txq_info` offset in `netdev_priv(ndev)` via `ALIGN(sizeof(*sdata) + local->hw.vif_data_size, sizeof(void *))`. [F598, F599]
- `ieee80211_setup_sdata` normalizes `P2P_GO`/`P2P_CLIENT` to `AP`/`STATION` (`vif.p2p = true`); use `ieee80211_vif_type_p2p(&sdata->vif)` for unnormalized types. Type changes (`ieee80211_if_change_type`, `ieee80211_runtime_change_iftype`) must call `ieee80211_teardown_sdata` then `ieee80211_setup_sdata` and reset `u.mgd.use_4addr = false` for `STATION`. [F550, F582]
- `sdata->bss` is NULL when an `AP` or `AP_VLAN` is stopped; check `sdata->bss != NULL` before `container_of(sdata->bss, ..., u.ap)`. In `ieee80211_set_vif_encap_ops` on `AP_VLAN`, read `vif.type` and `vif.offload_flags` from parent `bss`, but access `wdev.use_4addr` and `dev->netdev_ops` on `sdata`. [F551, F630]
- Changing `sdata->vif.offload_flags` in `ieee80211_set_sdata_offload_flags` requires `ieee80211_check_fast_rx_iface`, and `ieee80211_recalc_sdata_offload` must update `drv_update_vif_offload` and `ieee80211_set_vif_encap_ops` on `sdata` and child `AP_VLAN`s. Disable 802.3 TX encap offload when `local->virt_monitors != 0`, SW fragmentation is active, or 4-addr lacks `IEEE80211_OFFLOAD_ENCAP_4ADDR`. [F569, F695]
- Keep `AP` `crypto_tx_tailroom_needed_cnt` synced across `sdata->u.ap.vlans` via `update_vlan_tailroom_need_count`, inherited in `ieee80211_do_open`, and reset together in `ieee80211_reenable_keys`. [F568]
- Key slots: `sdata->keys`/`sta->ptk` have 4 (`0..3`); `link->gtk`/`link_sta->gtk` have 8: data (`0..3`), mgmt (`4..5`), beacon (`6..7`). `ieee80211_set_default_{key,mgmt_key,beacon_key}` expect `idx` in `0..3`, `4..5`, `6..7` (out-of-range clears to NULL). In `ieee80211_key_replace`, if `old` matches any `default_*_key` on `sdata`/`link`, clear or rebind it to `new`. In `_ieee80211_set_tx_key`, clear `WLAN_STA_BLOCK_BA` (if `force` or no `AMPDU_KEYBORDER_SUPPORT`) and call `ieee80211_check_fast_xmit(sta)`. [F565, F574, F575, F595]
- `u.{ccmp,gcmp}.rx_pn` have `IEEE80211_NUM_TIDS + 1` entries (`IEEE80211_NUM_TIDS` for `tid < 0`); `u.tkip.rx` has `IEEE80211_NUM_TIDS` (`0 <= tid < IEEE80211_NUM_TIDS`). `ieee80211_key_alloc` decodes little-endian `seq` via `get_unaligned_le16`/`le32` for TKIP, and byte-reverses `seq` into big-endian `rx_pn` (`seq[PN_LEN - j - 1]`) for CCMP/GCMP/CMAC/GMAC. [F596, F597]
- In `ieee80211_link_init` and `ieee80211_vif_update_links`, `link_id < 0` initializes `sdata->deflink` at slot 0; when `valid_links` transitions from 0 to non-zero, force bit 0 into `rem` but skip `&sdata->deflink` in `to_free`. In `ieee80211_set_vif_links_bitmaps`, non-zero `valid_links` requires `dormant_links` to be a strict subset, and `STATION` with `active_links == 0` allows at most one bit in `valid_links & ~dormant_links`. [F602, F611]
- Initialize unconfigured `txpower` and `*_power_level` to `INT_MIN` (`IEEE80211_UNSET_POWER_LEVEL`), not 0. When `ieee80211_register_hw` mutates `sband->vht_cap`, `kmemdup` `bands[band]` and set `BIT(band)` in `local->sband_allocated` so `ieee80211_free_hw` only frees cloned bands. [F559, F577]
- In `ieee80211_init_cipher_suites`, keep the 3 non-FIPS suites first and 4 MFP suites last to match `+ 3`/`- 4` slicing. Overridable fields in `ieee80211_apply_htcap_overrides` must be set in `mac80211_ht_capa_mod_mask`. [F578, F586]
- `ieee80211_mesh_build_beacon` must `skb_trim(skb, 0)` before building tail so `ifmsh->meshconf_offset` is relative to `bcn->tail`. `mesh_rmc_check` must use `hlist_for_each_entry_safe`, increment `entries` before testing expiry/`RMC_QUEUE_MAX_LEN`, and decrement `entries` on removal. [F579, F623]
- `ieee80211_mesh_update_bss_params` must verify `cap->datalen >= 1 + sizeof(*he_oper)` before `ieee80211_he_oper_size(cap->data + 1)`. `fils_decrypt_assoc_resp` must verify `*frame_len >= 30`, valid `WLAN_EID_EXT_FILS_SESSION` (`datalen == 9`), and `crypt_len >= AES_BLOCK_SIZE` before `aes_siv_decrypt`. [F588, F607]
- In `ieee80211_ibss_build_presp`, when `++rates_added == 8` in `WLAN_EID_SUPP_RATES`, increment `ri++` before breaking. In `ieee80211_get_mbssid_beacon_len`, `i == elems->cnt` is a sentinel returning total MBSSID/RNR length (keep `i > elems->cnt` check). [F593, F606]
- In `ieee80211_ifa_changed`, write `arp_addr_list[c]` only when `c < IEEE80211_BSS_ARP_ADDR_LIST_LEN`, but always increment `c` and `arp_addr_cnt`. In `tpt_trig_timer`, use signed `i` for reverse loop and treat `throughput < 0` as fallback sentinel. [F601, F603]
- `ieee80211_assign_perm_addr` requires contiguous `mask` (`__ffs64(mask) + hweight64(mask) == fls64(mask)`), stepping `val += 1ULL << __ffs64(mask)`. `ps_data.tim` must be `unsigned long`-aligned and `BITS_TO_LONGS`-sized, modified via `sta_info_{set,clear}_tim_bit`. When `local->open_count == 0` in `ieee80211_do_stop`, return immediately after `ieee80211_stop_device()`. [F627, F650, F653]

## Synchronization

- Mutating `local->interfaces` or `local->monitor_sdata` requires RTNL, wiphy lock, `local->iflist_mtx`, and RCU primitives; in `ieee80211_if_add`, finish `ieee80211_setup_sdata` and `cfg80211_register_netdevice` before `list_add_tail_rcu`. [F526, F668]
- `ieee80211_unregister_hw` must kill tasklets before `ieee80211_remove_interfaces`, and drop `wiphy_lock` and `rtnl_lock` before `cancel_work_sync(&local->restart_work)` and `destroy_workqueue`. `ieee80211_remove_interfaces` must call `cfg80211_shutdown_all_interfaces` before taking `wiphy_lock` and doing non-RCU list ops. [F669, F676]
- In `ieee80211_stop` on `AP`, call `dev_close(vlan->dev)` on `u.ap.vlans` before taking `wiphy` lock, and `ieee80211_stop_mbssid(sdata)` after. `ieee80211_do_stop` must clear `SDATA_STATE_RUNNING`, `synchronize_rcu()`, and call `ieee80211_free_keys(sdata, true)`; when purging `local->pending[i]`, unlink under `queue_stop_reason_lock` and call `ieee80211_free_txskb` after unlocking. [F670, F671, F672]
- When removing MLO links in `ieee80211_vif_update_links`, clear `sdata->link[id]` and `vif.link_conf[id]` with `RCU_INIT_POINTER` and `synchronize_rcu()` in `ieee80211_tear_down_links` before freeing keys or `link_container`s. [F536]
- Protect `local->mc_list` with `spin_lock_bh(&local->filter_lock)`, nest `filter_lock` inside `netif_addr_lock_bh(dev)`, and unlock `filter_lock` before `drv_configure_filter`. In `ieee80211_ba_session_work`, nest `fq->lock` inside `sta->lock`; if `!skb_queue_empty(&txqi->frags)`, unlock both before `synchronize_net()` and re-queuing. [F531, F538]
- `ieee80211_restart_hw` stops queues and sets `local->in_reconfig = true` before queuing `restart_work`, which flushes workqueues/wiphy works/ROC, cancels scans, and calls `synchronize_net()` before `ieee80211_reconfig`. Workers using `ieee80211_can_run_worker()` and `ieee80211_activate_links_work()` must abort when `in_reconfig` (or `quiescing`/`suspended`) is set. [F664, F665]
- Drain `ifibss->incomplete_stations` via `while (!list_empty(...))` under `incomplete_lock`, dropping the lock before `sta_info_free` / `ieee80211_ibss_finish_sta`. `ieee80211_ibss_add_sta` and `ieee80211_ibss_finish_sta` (`__acquires(RCU)`) must be called without RCU lock and always return with `rcu_read_lock()` held. [F622, F685]
- `ieee80211_ifa_changed` must check `wdev->registered` before `mutex_lock_nested(&local->hw.wiphy->mtx, 1)`. `ieee80211_stop_tpt_led_trig` must set `tpt_trig->running = false` before `timer_delete_sync`. [F674, F687]

## Object Lifetimes

- Free unlinked keys from `ieee80211_key_alloc` via `ieee80211_key_free_unused()` (frees crypto `tfm`). `ieee80211_free_keys_iface` and `ieee80211_remove_link_keys` must unlink keys via `ieee80211_key_replace(..., NULL)` onto a local list using `list_for_each_entry_safe` and wait for `synchronize_net()`/`synchronize_rcu()` before `__ieee80211_key_destroy`. In `ieee80211_key_enable_hw_accel`, never upload `KEY_FLAG_TAINTED` keys; if `KEY_FLAG_UPLOADED_TO_HARDWARE` was set, restore tailroom via `increment_tailroom_need_count` and clear the flag. [F511, F576, F621]
- On error in `ieee80211_vif_update_links()` (`new_links != 0`), restore `sdata->link` and `vif.link_conf`, zero `to_free`, free new links, and re-run `ieee80211_link_init(&sdata->deflink)` if `old_links == 0`. In `_ieee80211_set_active_links`, call `drv_change_vif_links` before updating chanctx/stations/keys when activating links, but after switching TDLS/chanctx/stations/keys when deactivating links. [F516, F657]
- Only `kfree(sdata)` when `!sdata->dev` (`P2P_DEVICE`, `NAN`, `monitor_sdata`); when `sdata->dev != NULL`, `sdata` and `txq_info` live in `netdev_priv`. Gate `local->open_count` and `drv_add/remove_interface` in `ieee80211_do_open`/`stop` on `coming_up`/`going_down`. [F522, F642]
- On `led_trigger_register` failure in `ieee80211_led_init`, `kfree` and NULL `.name` (or `tpt_led_trigger`). On `drv_join_ibss` failure in `__ieee80211_sta_join_ibss`, reset IBSS state, NULL and `kfree_rcu` `ifibss->presp`, and call `ieee80211_link_release_channel(&sdata->deflink)`. In `ieee80211_mesh_rebuild_beacon`, `kfree_rcu(old_bcn)` only after `ieee80211_mesh_build_beacon` succeeds; on failure in `ieee80211_mesh_csa_beacon`, NULL `ifmsh->csa` and `kfree_rcu(tmp_csa_settings)`. [F519, F523, F524]

## API Contracts

- `ieee80211_set_active_links` requires wiphy lock (else use `ieee80211_set_active_links_async`); when `old_active & active_links` is non-zero, call `_ieee80211_set_active_links(sdata, old_active & active_links)` before `_ieee80211_set_active_links(sdata, active_links)`. [F537, F573]
- `ieee80211_vif_cfg_change_notify` takes only `BSS_CHANGED_VIF_CFG_FLAGS`, `ieee80211_link_info_change_notify` rejects them, and `ieee80211_bss_info_change_notify` requires `!ieee80211_vif_is_mld(&sdata->vif)`. Never pass `IEEE80211_CONF_CHANGE_{CHANNEL,POWER,SMPS}` to `ieee80211_hw_config`. [F562, F563]
- `ieee80211_iter_keys` requires wiphy lock; `ieee80211_iter_keys_rcu` requires RCU lock and non-sleeping/non-removing callback; both pass `sta = NULL` for vif/link keys. In `ieee80211_key_replace` with `old == NULL` and `new->local->wowlan`, skip `ieee80211_key_enable_hw_accel` and set `KEY_FLAG_UPLOADED_TO_HARDWARE` on active links. [F554, F666, F679]
- `ieee80211_he_{cap_ie_to_sta_he_cap,op_ie_to_bss_conf,spr_ie_to_bss_conf}` must `memset` output structs to 0 before input checks; callers must pre-validate lengths with `ieee80211_he_capa_size_ok` and `ieee80211_he_spr_size`. [F558, F589, F590]
- `ieee80211_mesh_xmit_fast` returns `false` only if `skb` is unconsumed, and `true` once consumed/freed. `ieee80211_new_mesh_header` requires `addr4or5 != NULL` whenever `addr6 != NULL`. `ieee80211_request_smps` must use `rcu_read_lock()` to dereference `sdata->link[link_id]` and queue `request_smps_work`. Notifiers (`netdev_notify`, `ieee80211_ifa{,6}_changed`) must verify `dev->ieee80211_ptr` and `wiphy->privid == mac80211_wiphy_privid` before `IEEE80211_DEV_TO_SUB_IF`. [F547, F566, F647, F682]
- Hardware registration (`ieee80211_alloc_hw_nm`, `ieee80211_register_hw`): chanctx ops must be all-emulated (with NULL assign/unassign) or all-custom; `link_info_changed` and `vif_cfg_changed` must be paired and exclusive with `bss_info_changed`; `sta_state` is exclusive with `sta_add`/`remove`; `WIPHY_FLAG_SUPPORTS_MLO` requires `link_info_changed`, `HAS_RATE_CONTROL`, `AMPDU_AGGREGATION`, `MFP_CAPABLE`, `AP_LINK_PS` and forbids `emulate_chanctx` and legacy PS/beacon flags; `SW_CRYPTO_CONTROL` requires `cipher_suites`, `!fips_enabled`, and `drv_set_key() == 1` for SW fallback; `netdev_features` must be within `MAC80211_SUPPORTED_FEATURES`; HT/VHT/HE requires `hw.queues >= 4`, and EHT requires HE. [F660, F661, F662, F689, F690, F691]

## Error Handling

- `ieee80211_key_alloc` returns `ERR_PTR` (check `IS_ERR`); `ieee80211_key_link` frees `key` on all errors (never free `key` after `ieee80211_key_link` fails). In `ieee80211_runtime_change_iftype`, do not overwrite `ret` from `drv_change_interface` with `ieee80211_do_open`'s return value during rollback. Use ratelimited logging for IBSS station limit and peer DELBA frames. [F544, F556, F705]

## External Contracts

- `ieee80211_if_add` must call `dev_net_set(ndev, wiphy_net(local->hw.wiphy))` and set `needed_headroom`/`needed_tailroom` before `cfg80211_register_netdevice`. `ieee80211_mesh_xmit_fast` must resolve `CHECKSUM_PARTIAL` via `skb_checksum_help`, verify headroom, and call `skb_share_check` before `skb_push`. `ieee80211_handle_queued_frames` must reset `skb->pkt_type = 0` before `ieee80211_rx` or `ieee80211_tx_status_skb`. [F693, F696, F701]

## Known Pitfalls

- Check `link_id >= 0` before shifting `BIT(link_id)` on `key->conf.link_id` (`-1` for non-link keys). Copy `u16`/`u64` masks into `unsigned long` or `BITMAP_FROM_U64` before `for_each_set_bit`. [F635, F639, F651]
- `_ieee80211_set_active_links` must re-run `__ieee80211_sta_recalc_aggregates` after `drv_change_sta_links`. In `ieee80211_mesh_xmit_fast` (`MESH_FLAGS_AE_A5_A6`), save `skb->data + ETH_ALEN` before `skb_push`/`memcpy` overwrites the Ethernet header. `aes_siv_encrypt`/`decrypt` must copy input/IV before in-place output writes. [F572, F580, F581]
- In `ieee80211_do_stop`'s second switch, `NL80211_IFTYPE_MONITOR` breaks early for pure virtual monitors, otherwise releases `deflink` and falls through to `drv_remove_interface`. In `ieee80211_stop_mbssid` (`sdata != tx_sdata`), dereference `tx_link` from `tx_sdata->link[tx_bss_conf->link_id]`, clear `tx_link->conf->tx_bss_conf`, skip `sdata` and `tx_sdata` in the link loop, and stop `tx_sdata` last. [F616, F629]
