# EXT4 FILE SYSTEM — fs/ext4 (part 5)

Implements ext4 superblock/mount management (`super.c`), online resizing (`resize.c`), buffered readpage/readahead (`readpage.c`), fs-verity (`verity.c`), symlinks (`symlink.c`), extended attributes (`xattr*.c`), and sysfs/procfs (`sysfs.c`).

## Architecture & Data Flow
- In `ext4_load_super()`, when `blocksize != EXT4_MIN_BLOCK_SIZE`, `sbi->s_es` is at `bh->b_data + offset` (`do_div(logical_sb_block, blocksize)` from `sbi->s_sb_block * EXT4_MIN_BLOCK_SIZE`) and must be recomputed after `sb_set_blocksize()` reloads `bh`. Bound `s_log_block_size <= 6` and `s_log_cluster_size <= 20` before shifting; verify `clustersize >= sb->s_blocksize` in `ext4_handle_clustersize()` before setting `s_cluster_bits`; reset `s_log_groups_per_flex` to `0` if `< 1` or `> 31` in `ext4_fill_flex_info()`. [F322, F342, F343, F344]
- In `ext4_load_journal()`, save/restore `EXT4_S_ERR_START..EXT4_S_ERR_END` in `es` and `s_mount_state & EXT4_ERROR_FS` across `jbd2_journal_load()`, calling `ext4_commit_super()` only if changed and `!really_read_only`. In `__ext4_fill_super()`, clear `needs_recovery` after `ext4_load_and_init_journal()` if `bdev_read_only(sb->s_bdev)`. Reset `s_stripe` to 0 in `__ext4_fill_super()` and `__ext4_remount()` if `ext4_is_stripe_incompatible()`. [F287, F289, F290]
- Group descriptor `bg_*_hi` accessors require `EXT4_DESC_SIZE(sb) >= EXT4_MIN_DESC_SIZE_64BIT`. In `ext4_group_desc_csum()`, hash `sbi->s_desc_size - offset` bytes after `bg_checksum` only if `offset < sbi->s_desc_size`. In `ext4_flex_group_add()` and `descriptor_loc()`, GDT index `nr` uses `meta_bg` only when `ext4_has_feature_meta_bg(sb)` and `nr >= le32_to_cpu(es->s_first_meta_bg)`; in `descriptor_loc()`, increment `has_super` by 1 if `s_blocksize == 1024 && nr == 0 && le32_to_cpu(s_es->s_first_data_block) == 0`. [F319, F320, F327, F329]
- In `ext4_update_super()` (`resize.c`), update `s_freeclusters_counter`, `s_freeinodes_counter`, `fg->free_clusters`, `fg->free_inodes` (if `flex_bg`), `s_overhead`, `es->s_overhead_clusters`, and the superblock checksum under `lock_buffer(sbi->s_sbh)`. In `add_new_gdb()`, zero `dind->b_data[gdb_num % EXT4_ADDR_PER_BLOCK(sb)]`, decrement `inode->i_blocks` and `es->s_reserved_gdt_blocks`, and `rcu_assign_pointer()` `s_group_desc` before incrementing `s_gdb_count`. In `reserve_backup_gdb()`, wrap `data` to `(__le32 *)dind->b_data` when `++data >= end`. In `ext4_convert_meta_bg()`, clear `resize_inode`, set `meta_bg` and `es->s_first_meta_bg = num_desc_blocks(sb, sbi->s_groups_count)`, and free/zero `resize_inode`'s `EXT4_DIND_BLOCK` and `i_blocks`. [F282, F283, F284, F318]
- In `verify_group_input()`, `block_bitmap`, `inode_bitmap`, and `[inode_table, inode_table + s_itb_per_group)` must lie within `[start + overhead, start + input->blocks_count)` without overlapping, with `free_blocks_count >= 0`; keep `block_bitmap`, `inode_bitmap`, and `inode_table` contiguous `__u64` fields in `struct ext4_new_group_data`. In `ext4_resize_fs()` with `bigalloc`, mask `n_blocks_count` to a cluster multiple and drop final group `n_group` if it lacks `overhead + 2 + s_itb_per_group + s_cluster_ratio` blocks. [F316, F317, F365]
- In-inode xattr `e_value_offs` and `s.base` are offsets from `IFIRST(header)`; block xattrs from `BHDR(bh)`. `ext4_expand_extra_isize_ea()` must shift in-inode xattrs and adjust non-external `e_value_offs` by `old_extra_isize - new_extra_isize` via `ext4_xattr_shift_entries()`, then call `ext4_find_inline_data_nolock()` if inline data exists. `ext4_xattr_make_inode_space()` must never move `system.data`. [F293, F359, F404]
- `ext4_write_{trylock,lock}_xattr()` saves prior `EXT4_STATE_NO_EXPAND` into `*save` before setting it; `ext4_write_unlock_xattr()` clears it only if `*save == 0` (forced to 0 on deletion). Clear `MBE_REUSABLE_B` on `mb_cache_entry` when `h_refcount == EXT4_XATTR_REFCOUNT_MAX` in `ext4_xattr_block_set()`, and set it when `h_refcount == EXT4_XATTR_REFCOUNT_MAX - 1` in `ext4_xattr_release_block()` under `lock_buffer(bh)`. In `ext4_xattr_inode_dec_ref_all()`, zero `e_value_inum` and `e_value_size` in the same transaction that decrements `ea_inode` refcount, calling `ext4_xattr_restart_fn()` and `ext4_journal_get_write_access()` if `ext4_journal_ensure_credits_fn() > 0`. [F299, F301, F303]
- In `verity.c`, metadata starts at `ext4_verity_metadata_pos(inode)` (`round_up(inode->i_size, 65536)`), the descriptor starts at a block boundary after the Merkle tree, and `__le32 desc_size` is in the last 4 bytes of the last extent's final block. In `ext4_get_verity_descriptor_location()`, cast `end_lblk` to `u64` before `<< i_blkbits`, reject `desc_size > INT_MAX || desc_size > desc_size_pos`, and require `desc_pos = round_down(desc_size_pos - desc_size, i_blocksize(inode)) >= ext4_verity_metadata_pos(inode)`. [F310, F311, F353]
- In `ext4_statfs_project()`, clamp `f_blocks`, `f_bfree`, and `f_bavail` (and `f_files`, `f_ffree`) independently with `min()` against `limit` and `limit > cur ? limit - cur : 0`. In `ext4_get_link()`, call `nd_terminate_link(bh->b_data, inode->i_size, s_blocksize - 1)` for block symlinks; in `ext4_encrypted_get_link()`, bound `max_size` to `sizeof(i_data)` or `s_blocksize`. In `sysfs.c`, `attr_clusters_in_group` rejects `> s_clusters_per_group`, `reserved_clusters_store()` rejects `>= clusters` or `< 0`, and `s_{first,last}_error_func` must use `%.*s` with `a->attr_size` (32). [F313, F314, F324, F325]

## Synchronization
- `ext4_handle_error()` schedules `s_sb_upd_work` only when `continue_fs && journal && !ext4_test_mount_flag(sb, EXT4_MF_JOURNAL_DESTROY)` (calling `ext4_commit_super()` otherwise), paired with `ext4_journal_destroy()` setting `EXT4_MF_JOURNAL_DESTROY` before `ext4_force_commit()` and `flush_work(&sbi->s_sb_upd_work)`. [F240]
- In `__ext4_remount()`, serialize `ext4_apply_options()` and `restore_opts` rollback (`sb->s_flags`, `s_mount_opt{,2}`) under `ext4_writepages_down_write(sb)`. `sbi->s_qf_names[]` is RCU-protected: readers outside `s_umount` need `rcu_read_lock()` / `rcu_dereference()`, and writers under `s_umount` need `rcu_replace_pointer()` / `rcu_assign_pointer()` and `kfree_rcu_mightsleep()` / `synchronize_rcu()`. [F242, F243]
- In `ext4_quota_operations`, start the JBD2 handle before calling `dquot_*` helpers. In `ext4_release_dquot()`, call `sb_start_intwrite()` only when `!ext4_journal_current_handle()`, and still call `dquot_release(dquot)` if `ext4_journal_start()` fails. [F228, F400]
- `ext4_li_mtx` nests outside `eli->li_list_mtx`. In `ext4_lazyinit_thread()`, at `exit_thread` lock both and recheck `list_empty(&eli->li_request_list)` before freeing `ext4_li_info`; around `ext4_run_li_request(elr)`, drop `li_list_mtx` only while holding `down_read_trylock(&elr->lr_super->s_umount)` and `sb_start_write_trylock()`, and reload `n = pos->next` after relocking `li_list_mtx` before dropping `s_umount`. [F246, F247]
- Bracket online resize in `ext4_resize_begin()` (`EXT4_FLAGS_RESIZING`) and `ext4_resize_end()` (`clear_bit_unlock()` + `smp_mb__after_atomic()`). In `ext4_update_super()`, issue `smp_wmb()` before incrementing `sbi->s_groups_count` (pairing with `smp_rmb()` in `ext4_get_groups_count()`). Access `s_group_desc` and `s_flex_groups` under `rcu_read_lock()` / `sbi_array_rcu_deref()`, and free old arrays via `ext4_kvfree_array_rcu()`. [F248, F250, F375]
- In RCU-walk (`!dentry`), `ext4_encrypted_get_link()` and inline symlinks in `ext4_get_link()` return `ERR_PTR(-ECHILD)`, and block symlinks use `ext4_getblk(NULL, inode, 0, EXT4_GET_BLOCKS_CACHED_NOWAIT)` and return `ERR_PTR(-ECHILD)` if `!bh` or `!ext4_buffer_uptodate(bh)`. `ext4_truncate_failed_write()` must hold `filemap_invalidate_lock()` across `truncate_inode_pages()` and `ext4_truncate()`. [F254, F395]
- After `ext4_write_lock_xattr()`, `ext4_xattr_set_handle()` must re-read the xattr block via `ext4_xattr_get_block()` and recheck `jbd2_handle_buffer_credits(handle) >= credits` via `__ext4_xattr_set_credits()`. In `ext4_xattr_block_set()`, call `ext4_xattr_inode_lookup_create()` before `lock_buffer(bs->bh)`; `ext4_xattr_inode_iget()` must reject `parent->i_ino == ea_ino` and call `ext4_xattr_inode_set_class()`. [F256, F259]
- Before modifying an xattr block in place (`h_refcount == 1`) or freeing it, remove its `ea_block_cache` entry via `mb_cache_entry_delete_or_get()` under `lock_buffer(bh)` (cloning or waiting via `mb_cache_entry_wait_unused()` if busy). When decrementing `h_refcount > 1` in `ext4_xattr_release_block()`, call `ext4_handle_dirty_metadata()` before `unlock_buffer(bh)` if `ext4_handle_valid(handle)`, else after. [F258, F298]

## Object Lifetimes
- Set `j_commit_callback = ext4_journal_commit_callback` in `__ext4_fill_super()` only after `ext4_mb_init(sb)`. In `ext4_put_super()`, call `ext4_unregister_sysfs(sb)` before destroying `s_journal` or flushing `s_sb_upd_work`, and pair `kobject_put(&sbi->s_kobj)` with `wait_for_completion(&sbi->s_kobj_unregister)` after teardown (and on `kobject_init_and_add()` failure). [F221, F237]
- `ext4_apply_quota_options()` and `ext4_apply_test_dummy_encryption()` must NULL `ctx->s_qf_names[i]` and `ctx->dummy_enc_policy` after transferring them to `sbi`. In `ext4_register_li_request()`, set `elr = NULL` after `list_add()` before `ext4_run_lazyinit_thread()`. [F226, F227]
- `ext4_mark_iloc_dirty()` always consumes `iloc.bh`; callers with a shared `brelse(iloc.bh)` cleanup (`ext4_xattr_set_handle()`, `add_new_gdb()`) must set `iloc.bh = NULL`. In `ext4_resize_fs()`, release and NULL `resize_inode` (`iput`) and `flex_gd` (`free_flex_gd`) before jumping to `retry:`. [F230, F236]
- In `ext4_xattr_{inode,block}_cache_find()`, `mb_cache_entry_find_next()` consumes `ce`: call `mb_cache_entry_put()` on early loop exit (unless returned via `*pce = ce`) and never before `mb_cache_entry_find_next()`; `ext4_xattr_block_set()` must put and NULL `ce` and `new_bh` on retry or cleanup. [F231, F340]

## API Contracts
- `ext4_sb_bread{,_unmovable,_nofail}()` never return `NULL`, only `ERR_PTR(-errno)`. `__ext4_error{,_inode}()`, `save_error_info()`, `ext4_error_err()`, `EXT4_ERROR_INODE_ERR()`, and `ext4_abort()` take positive `errno` (`0` = `EFSCORRUPTED`); `ext4_decode_error()` and `ext4_std_error()` take negative `-errno`. [F262, F265]
- `ext4_journal_ensure_credits_fn()` and `ext4_resize_ensure_credits_batch()` return `< 0` on error, `0` if unchanged/extended, and `1` if restarted; check `err < 0` for errors and re-call `ext4_journal_get_write_access()` on `bh` when `err > 0`. `ext4_count_free()` takes bytes, whereas `ext4_mark_bitmap_end()` and `mb_set_bits()` take bit counts. `ext4_xattr_hash_entry{,_signed}()` take `name_len` in bytes and `value_count` in 32-bit words (`new_size >> 2` or `1`), with padding zeroed first. [F273, F362, F370]
- `ext4_begin_enable_verity()` must call `ext4_inode_attach_jinode()` and `dquot_initialize()` before `ext4_convert_inline_data()` and `ext4_truncate()`. In `ext4_end_enable_verity()`, `desc == NULL` must jump straight to `cleanup`. `ext4_get_verity_descriptor()` returns `desc_size` when `buf_size == 0`, or `-ERANGE` if `desc_size > buf_size`. `ext4_{read_merkle_tree_page,write_merkle_tree_block}()` must offset `index`/`pos` by `ext4_verity_metadata_pos(inode)`. [F270, F271, F272, F393]
- `ext4_mpage_readpages()` must submit any pending BIO and call `block_read_full_folio()` if a folio has `folio_buffers()`, a mapped block after a hole, or discontiguous blocks. `ext4_quota_write()` requires an active journal handle and single-block range; `ext4_quota_enable()` must set `S_NOQUOTA` before `dquot_load_quota_inode()`. `ext4_xattr_trusted_list()` and `trigger_test_error()` require `CAP_SYS_ADMIN`, `ext4_resize_begin()` requires `CAP_SYS_RESOURCE`, and `ext4_xattr_hurd_*()` requires `XATTR_USER`. [F391, F401, F405]

## Error Handling
- In `ext4_end_enable_verity()`, run `filemap_write_and_wait()` before clearing `EXT4_STATE_VERITY_IN_PROGRESS` and setting `EXT4_INODE_VERITY`; on error, call `truncate_inode_pages()`, `ext4_truncate()`, `ext4_orphan_del(NULL, inode)`, and clear `EXT4_STATE_VERITY_IN_PROGRESS`. [F219]
- In `__ext4_fill_super()`, after `d_make_root(root)`, error labels (`failed_mount4a`+) must call `dput(sb->s_root)` and never `iput(root)`; errors after `ext4_enable_quotas(sb)` must jump to `failed_mount9` (`ext4_quotas_off(sb, EXT4_MAXQUOTAS)` before `ext4_release_orphan_info(sb)`), and failure at `type` in `ext4_enable_quotas()` must call `ext4_quotas_off(sb, type)`. In `ext4_group_desc_init()`, set `sbi->s_gdb_count = i` on read failure at `i`. [F224, F277, F280]
- In `__ext4_remount()`, handle `test_opt2(sb, ABORT)` last; on `restore_opts`, call `dquot_resume(sb, -1)` for failed RW-to-RO transitions before restoring `sb->s_flags`. `ext4_handle_error()` sets `EXT4_FLAGS_EMERGENCY_RO` (not `SB_RDONLY`), skips `ERRORS_PANIC` when `system_going_down()`, and defers superblock updates to `s_sb_upd_work` when the journal is live. [F225, F398]
- In `symlink.c`, check both `IS_ERR(bh)` and `!bh` after `ext4_bread()` / `ext4_getblk()`. Where metadata read failure triggers `ext4_error*`, use `ext4_sb_bread_nofail()` or filter `-ENOMEM`. Reset `buffer_head *` or `inode *` variables to `NULL` after extracting errors before jumping to shared `brelse()` / `iput()` labels. Capture `ext4_journal_stop()` in `err2` and assign to `err` only if `!err`. [F261, F263, F264, F274, F388]
- In `ext4_xattr_set_handle()`, if `EXT4_STATE_NEW` is set after `ext4_reserve_inode_write()`, zero `raw_inode` (`s_inode_size` bytes) and clear `EXT4_STATE_NEW`. Zero trailing bytes in partial blocks (`ext4_xattr_inode_write()`, `update_backups()`) and pad `new_size - i->value_len` with zeros in `ext4_xattr_set_entry()` (or all `new_size` for `EXT4_ZERO_XATTR_VALUE`). Use `le32_to_cpup`/`le64_to_cpup`/`cpu_to_le32` in `sysfs.c` when `a->attr_ptr == ptr_ext4_super_block_offset`. [F266, F267, F269, F278]

## External Contracts
- In `_ext4_show_options()`, emit `emergency_ro` whenever `ext4_emergency_ro(sb)` is true; `MOPT_SET` requires `(mount_opt & m->mount_opt) == m->mount_opt` and `MOPT_CLEAR` requires `!(mount_opt & m->mount_opt)`. In `check_xattrs()`, check both `size > end - value` and `EXT4_XATTR_SIZE(size) > end - value`, plus `value >= (void *)e + sizeof(u32)` and `offs <= end - value_start`, before `buffer_verified(bh)`. [F328, F339, F402]

## Known Pitfalls
- In `ext4_xattr_make_inode_space()`, restart the scan from `IFIRST(header)` after `ext4_xattr_move_to_block()`. In `ext4_xattr_set_handle()`, the `-ENOSPC` fallback to `ext4_xattr_block_set()` when `!is.s.not_found` must call `ext4_xattr_block_find()` first if `i_file_acl && !bs.s.base`. When `ext4_xattr_block_set()` clones a shared block, copy `bs->s` to local `s_copy`, rebase `s->first`, `s->here`, and `s->end` into the `kmemdup`ed buffer, and zero `s->here->e_value_inum` and `e_value_size`. [F294, F297, F334]
- Copy non-NUL-terminated `e_name` (`e_name_len` bytes + `'\0'`) before passing as `ext4_xattr_info.name`. Cast `*name` to `unsigned char` in `ext4_xattr_hash_entry()`, and cast `inode_peek_iversion_raw(ea_inode)` to `u32` in `ext4_xattr_inode_get_ref()`. In `ext4_alloc_group_tables()`, initialize `bb_index`, `ib_index`, and `it_index` to 0 before `next_group:` (not in `for` headers), and convert block counts to clusters via `EXT4_NUM_B2C()`. [F332, F350, F356, F358, F364]
- Widen `ppb` to `loff_t` in `((loff_t)ppb) * ppb * ppb` and use `DIV_ROUND_UP_ULL()` in `ext4_max_bitmap_size()`; cast `*hi` to `time64_t` before `<< 32` in `__ext4_get_tstamp()` / `__print_tstamp()`; use `div64_u64()` by `ext4_blocks_count(es)` and `do_div()` by 100 in `ext4_update_super()`; cast `group`/`n_group` to `ext4_fsblk_t` before multiplying by `bpg` or `EXT4_BLOCKS_PER_GROUP(sb)`; use `time_before()` / `time_after_eq()` in `ext4_lazyinit_thread()`. In `sysfs.c`, `ext4_feat_attrs` must never dereference `sbi`, and `ext4_attr` `attr_id` width/endianness must match the target field. [F347, F348, F349, F351, F352, F366, F367]
