# RADEON and AMDGPU DRM DRIVERS — drivers/gpu/drm/amd/amdgpu (part 15)

Hardware IP block driver for GFX v9.0 (Vega10/12/20, Raven, Picasso, Renoir, Arcturus, Aldebaran), including RAS EDC error querying/injection and golden register/shader initialization for GFX v9.4 (Arcturus) and GFX v9.4.2 (Aldebaran).

## Architecture & Data Flow

- On compute-only GFX9 ASICs (`IP_VERSION(9, 4, 1)` Arcturus, `IP_VERSION(9, 4, 2)` Aldebaran), `adev->gfx.num_gfx_rings` is `0`; any path touching `adev->gfx.gfx_ring`, `adev->gfx.sw_gfx_ring`, `adev->gfx.muxer`, or 3D/CPG state must guard on `adev->gfx.num_gfx_rings`. [F1680]
- `adev->gfx.ras` is only populated on GC 9.4.0/9.4.1/9.4.2, and `enable_watchdog_timer` only on `gfx_v9_4_2_ras`; callers must check both `adev->gfx.ras` and `adev->gfx.ras->enable_watchdog_timer` before calling it. [F1681]
- `gfx_v9_0_alloc_ip_dump` sets `adev->gfx.ip_dump_core` or `adev->gfx.ip_dump_compute_queues` to `NULL` on `kcalloc` failure without failing `gfx_v9_0_sw_init`, so `gfx_v9_ip_dump` and `gfx_v9_ip_print` must NULL-check both pointers, iterate `(mec, pipe, queue)` in identical order with stride `ARRAY_SIZE(gc_cp_reg_list_9)`, and substitute `mmCP_MEC_ME2_HEADER_DUMP` when `mec > 0` and `reg_offset == mmCP_MEC_ME1_HEADER_DUMP`. [F1682, F1709]
- In `gfx_v9_0.c`, compute ring `ring->me` is 1-based (`mec + 1`, ME 0 is GFX): `soc15_grbm_select` and `gfx_v9_0_get_cpc_int_cntl` take `1 + i` for 0-based MEC index `i`, whereas `gfx_v9_0_kiq_map_queues` (`PACKET3_MAP_QUEUES_ME`) and `gfx_v9_0_compute_ring_init` EOP IRQ calculation pass `ring->me - 1`. [F1712]
- `gfx_v9_0_set_compute_eop_interrupt_state`, `gfx_v9_0_get_cpc_int_cntl`, `gfx_v9_0_set_cp_ecc_error_state`, and `gfx_v9_0_emit_wave_limit` must only touch MEC1 (`me == 1`, pipes 0–3) and never MEC2 registers; `gfx_v9_0_emit_wave_limit` must also skip `ring->pipe` (`if (i != ring->pipe)`) when throttling pipes for a high-priority compute ring. [F1697, F1698]
- In `gfx_v9_0_kiq_init_queue` and `gfx_v9_0_kcq_init_queue`, fresh MQD init must `memset` the full `sizeof(struct v9_mqd_allocation)` and set `dynamic_cu_mask` and `dynamic_rb_mask` to `0xFFFFFFFF` before `gfx_v9_0_mqd_init`; restoring from `mqd_backup` must reset `ring->wptr = 0`, call `amdgpu_ring_clear_ring(ring)`, and (for KCQ) zero `*ring->wptr_cpu_addr`. [F1688, F1700]
- `vgpr_init_regs`, `vgpr_init_regs_arcturus`, `sgpr1_init_regs`, and `sgpr2_init_regs` must all have 6 leading non-SE entries before `mmCOMPUTE_STATIC_THREAD_MGMT_SE0..SE7`, matching `gpr_reg_size = adev->gfx.config.max_shader_engines + 6` in `gfx_v9_0_do_edc_gpr_workarounds`. In `gfx_v9_0_do_edc_gpr_workarounds` and `gfx_v9_4_2_run_shader`, shader byte offsets (`vgpr_offset`, `sgpr_offset`, `shader_offset`) must be aligned via `ALIGN(..., 256)` and added as `u64` to `ib.gpu_addr` before `>> 8` for `mmCOMPUTE_PGM_LO`/`HI`. [F1704, F1736]
- In `gfx_v9_4_2_wait_for_waves_assigned`, `wave_cnt` and `offset` must reset to `0` at the start of each `do ... while (++loop < 2000 && wait)` pass, and `offset` must increment on every `(se, cu, simd, wave)` slot even when `(1 << wave) & mask` is false. [F1730]
- `gfx_v9_0_init_gds_vmid` must only clear GDS/GWS/OA registers for `vmid >= 1` (never VMID 0), whereas `gfx_v9_0_do_edc_gds_workarounds` must reset `mmGDS_VMID0_SIZE` to `0` after temporarily setting it to `adev->gds.gds_size`. [F1699]
- In `gfx_v9_0_update_gfx_clock_gating`, under RLC safe mode, MGCG/MGLS (`gfx_v9_0_update_medium_grain_clock_gating`) must be enabled before 3D and coarse-grain CGCG/CGLS when enabling clock gating, and disabled after them when disabling. [F1705]
- In `gfx_v9_0_query_utc_edc_status`, `gfx_v9_0_reset_ras_error_count`, `gfx_v9_4_query_utc_edc_status`, and `gfx_v9_4_reset_ras_error_count`, all UTC L2 `*ECC_INDEX`, `*EDC_INDEX`, and `*DSM_INDEX` registers must be reset to `255` after iterating over subblocks. [F1707]
- In `gfx_v9_1_parse_ind_reg_list` and `gfx_v9_1_init_rlc_save_restore_list`, the indirect section of `register_list_format` holds 3-dword tuples terminated by `0xFFFFFFFF`, advancing by 1 dword on `0xFFFFFFFF` and 3 dwords per indirect entry. In `gfx_v9_0_get_csb_size` and `gfx_v9_0_cp_gfx_start`, `gfx9_cs_data` and each `sect->section` array must remain terminated by `NULL` sentinels, and `amdgpu_gfxoff_quirk_list` must remain `static const` terminated by `{ 0, 0, 0, 0, 0 }` with `gfx_v9_0_should_disable_gfxoff` matching all 5 PCI fields. [F1718, F1734, F1761]
- `gfx_v9_ring_insert_nop` must return early when `num_nop == 1` before evaluating `num_nop - 2` in `PACKET3(PACKET3_NOP, min(num_nop - 2, 0x3ffe))`. [F1719]
- `gfx_v9_0_ring_emit_reg_write_reg_wait` may only emit a combined `gfx_v9_0_wait_reg_mem` (`opt = 1`) when `adev->gfx.me_fw_write_wait` (GFX) or `adev->gfx.mec_fw_write_wait` (other rings) is set, falling back to `amdgpu_ring_emit_reg_write_reg_wait_helper` otherwise. `gfx_v9_0_ring_emit_cleaner_shader` must emit `PACKET3_RUN_CLEANER_SHADER` on `IP_VERSION(9, 4, 2)` and `PACKET3_RUN_CLEANER_SHADER_9_0` on other GFX9 versions, with `adev->gfx.enable_cleaner_shader` gated on IP-specific `me_fw_version`/`pfp_fw_version`/`mec_fw_version` thresholds in `gfx_v9_0_sw_init`. [F1758, F1759]
- `gfx_v9_0_init_golden_registers` must skip `golden_settings_gc_9_x_common` on GC 9.3.0, 9.4.1, and 9.4.2, and on GC 9.4.2 `gfx_v9_4_2_init_golden_registers` must pick `golden_settings_gc_9_4_2_alde_die_0` or `_die_1` via `adev->smuio.funcs->get_die_id(adev)`. [F1760]

## Synchronization

- Every function in `gfx_v9_0.c`, `gfx_v9_4.c`, and `gfx_v9_4_2.c` that selects SE/SH/instance via `mmGRBM_GFX_INDEX` / `regGRBM_GFX_INDEX` under `adev->grbm_idx_mutex` must restore broadcast addressing (`0xffffffff, 0xffffffff, 0xffffffff` or `0xe0000000`) before unlocking `adev->grbm_idx_mutex` on every exit path (including timeouts in `gfx_v9_0_wait_for_rlc_serdes`). [F1664]
- Every function in `gfx_v9_0.c` and `gfx_v9_4_2.c` calling `soc15_grbm_select` for a non-zero ME/pipe/queue/VMID must hold `adev->srbm_mutex` and reset via `soc15_grbm_select(adev, 0, 0, 0, 0, 0)` before unlocking. When both RLC safe mode and `adev->srbm_mutex` are needed (`gfx_v9_0_kiq_reset_hw_queue`, `gfx_v9_0_reset_kcq`), `amdgpu_gfx_rlc_enter_safe_mode` must precede `mutex_lock(&adev->srbm_mutex)` and `amdgpu_gfx_rlc_exit_safe_mode` must follow `mutex_unlock`. [F1665, F1671]
- In `gfx_v9_0_eop_irq`, when `me_id == 0` and `adev->gfx.mcbp` is true, `amdgpu_mcbp_handle_trailing_fence_irq(&adev->gfx.muxer)` must run first, and `amdgpu_fence_process` must run on each `adev->gfx.sw_gfx_ring[i]` (never `gfx_ring[0]`) only when it returns false. [F1667]
- In `gfx_v9_0_ring_set_wptr_gfx` and `gfx_v9_0_ring_set_wptr_compute`, when `ring->use_doorbell` is true, `atomic64_set((atomic64_t *)ring->wptr_cpu_addr, ring->wptr)` must precede `WDOORBELL64(ring->doorbell_index, ring->wptr)`. In `gfx_v9_0_ring_emit_vm_flush` on `AMDGPU_RING_TYPE_GFX`, `PACKET3_PFP_SYNC_ME` must immediately follow `amdgpu_gmc_emit_flush_gpu_tlb`. [F1675, F1676]

## Object Lifetimes

- `gfx_v9_4_2_run_shader` frees `ib` via `amdgpu_ib_free` when `amdgpu_ib_schedule` fails and only transfers ownership of `ib` and `*fence_ptr` on return `0`; callers (`gfx_v9_4_2_do_sgprs_init`, `gfx_v9_4_2_do_vgprs_init`) must jump past that dispatch's `amdgpu_ib_free`/`dma_fence_put` label on error. In `gfx_v9_0_ring_test_ib` and `gfx_v9_0_do_edc_gpr_workarounds`, `struct dma_fence *f` must be initialized/reset to `NULL` before `amdgpu_ib_schedule` because `err2:` and `fail:` unconditionally call `dma_fence_put(f)`. [F1654, F1656]
- In `gfx_v9_0_mec_init`, BOs from `amdgpu_bo_create_reserved` (`hpd_eop_obj`, `mec_fw_obj`) must be unmapped/unreserved via `amdgpu_bo_kunmap` and `amdgpu_bo_unreserve` on success, and any error must call `gfx_v9_0_mec_fini(adev)`. In `gfx_v9_0_init_cp_compute_microcode`, failure to load optional `adev->gfx.mec2_fw` must reset `err = 0` and call `amdgpu_ucode_release(&adev->gfx.mec2_fw)`, whereas non-zero `err` at `out:` releases `adev->gfx.mec_fw`. [F1658, F1659]
- In `gfx_v9_0_sw_init`: if `amdgpu_gfx_cleaner_shader_sw_init` fails, reset `adev->gfx.enable_cleaner_shader = false`; run `gfx_v9_0_mec_init` before `gfx_v9_0_compute_ring_init` and `amdgpu_gfx_kiq_init` -> `amdgpu_gfx_kiq_init_ring` -> `amdgpu_gfx_mqd_sw_init`. `gfx_v9_0_sw_fini` must reverse these: call `amdgpu_ring_fini` on all `compute_ring`s before `gfx_v9_0_mec_fini`, and call `amdgpu_gfx_mqd_sw_fini(adev, 0)` and `amdgpu_gfx_kiq_free_ring(&adev->gfx.kiq[0].ring)` before `amdgpu_gfx_kiq_fini(adev, 0)`. [F1660, F1661, F1749]
- `gfx_v9_0_ring_begin_use_compute` and `gfx_v9_0_ring_end_use_compute` must bracket `gfx_v9_0_set_powergating_state` (`AMD_PG_STATE_UNGATE` / `AMD_PG_STATE_GATE` on `IP_VERSION(9, 1, 0)`) inside `amdgpu_gfx_enforce_isolation_ring_begin_use` and `amdgpu_gfx_enforce_isolation_ring_end_use` in reverse order. [F1663]
- In `gfx_v9_0_hw_fini`: (1) call `amdgpu_gfx_disable_kcq` before disabling CP or stopping RLC unless `amdgpu_ras_intr_triggered()`; (2) on `amdgpu_sriov_vf(adev)`, clear `CP_PQ_WPTR_POLL_CNTL.EN` to `0` after `gfx_v9_0_cp_gfx_enable(adev, false)`; (3) on unbind (`!amdgpu_in_reset(adev) && !adev->in_suspend`), call `gfx_v9_0_kiq_fini_register` under `adev->srbm_mutex` with KIQ's `me`/`pipe`/`queue` selected via `soc15_grbm_select`; (4) skip `adev->gfx.rlc.funcs->stop(adev)` when `adev->gmc.xgmi.connected_to_cpu && amdgpu_in_reset(adev)` or `GC_HWIP >= IP_VERSION(9, 4, 2)`. [F1668, F1752, F1753]

## API Contracts

- `gfx_v9_4_2_run_shader` takes `shader_size` in bytes and `regs_size` as element count (`ARRAY_SIZE`). In `gfx_v9_4_2_do_sgprs_init` and `gfx_v9_4_2_do_vgprs_init`, `wb_ib` must be allocated and zeroed for `(1 + wb_size) * sizeof(uint32_t)` bytes because `wb_ib.ptr[0]` is the stop-wave word at `wb_ib.gpu_addr` while `&wb_ib.ptr[1]` is passed as `wb_ptr` to `gfx_v9_4_2_wait_for_waves_assigned`. [F1692, F1742]
- `gfx_v9_0_query_ras_error_count`, `gfx_v9_4_query_ras_error_count`, and `gfx_v9_4_2_query_ras_error_count` must zero `err_data->ue_count` and `err_data->ce_count` before accumulating (`+=`) SEC/DED counts. `gfx_v9_4_2_query_sram_edc_count` and `gfx_v9_4_2_query_utc_edc_count` treat `NULL` `sec_count`/`ded_count` as reset-only mode and zero `*sec_count`/`*ded_count` at entry when non-NULL. [F1686, F1687]
- `gfx_v9_0_ras_fields`, `gfx_v9_4_ras_fields`, `gfx_v9_4_2_ras_fields`, and `gfx_v9_4_2_utc_blocks` store pre-shifted `SOC15_REG_FIELD` masks (`*_count_mask`) and shifts (`*_count_shift`), extracted via `(value & mask) >> shift`. `gfx_v9_0_ras_error_inject` must verify `info->head.sub_block_index < ARRAY_SIZE(ras_gfx_subblocks)`, non-NULL `name`, and matching `hw_supported_error_type`/`sw_supported_error_type` before `psp_ras_trigger_error`. [F1694, F1789]
- In `gfx_v9_0_ring_emit_ce_meta`, `gfx_v9_0_ring_emit_de_meta`, and `gfx_v9_0_ring_emit_ib_gfx`, `amdgpu_ring_ib_on_emit_ce`/`_de`/`_cntl` must be called immediately before writing the CE payload, DE payload, and IB `control` dword. Each KIQ PM4 callback in `gfx_v9_0_kiq_pm4_funcs` (`set_resources`, `map_queues`, `unmap_queues`, `query_status`, `invalidate_tlbs`) must emit the exact dword count in its `*_size` field (8, 7, 6, 7, 2). [F1701, F1787]

## Error Handling

- In `gfx_v9_4_2_do_sgprs_init`, if `gfx_v9_4_2_wait_for_waves_assigned` fails for `disp_ibs[0..2]`, `wb_ib.ptr[0]` must be set to `0xdeadbeaf` to stop spinning shader waves before jumping to `disp0_failed`/`disp1_failed`/`disp2_failed`. `gfx_v9_0_do_edc_gpr_workarounds`, `gfx_v9_4_2_do_sgprs_init`, and `gfx_v9_4_2_do_vgprs_init` must check `amdgpu_ras_is_supported(adev, AMDGPU_RAS_BLOCK__GFX)` and `sched.ready` on every target `compute_ring` (including `compute_ring[1]`), returning `0` if not ready. [F1655, F1683]

## External Contracts

- `gfx_v9_0_read_wave_data` must write format version `1` into `dst[(*no_fields)++]` followed by 15 wave status registers (16 dwords total, fitting in `amdgpu_debugfs_wave_read`'s `data[32]`). In `gfx_v9_0_mqd_init`, `mqd->cp_hqd_active` must only be set to `1` when `ring->funcs->type == AMDGPU_RING_TYPE_KIQ`. [F1723, F1792]

## Known Pitfalls

- In `gfx_v9_0_ring_patch_ce_meta` and `gfx_v9_0_ring_patch_de_meta`, `offset` and `ring->buf_mask + 1` are in dwords while `payload_size` is in bytes; when `offset + (payload_size >> 2) > ring->buf_mask + 1`, the copy must wrap around `&ring->ring[0]` after copying `(ring->buf_mask + 1 - offset) << 2` bytes. [F1713]
- In `gfx_v9_0_sw_init`, `j` iterates over `num_queue_per_pipe` (outer) and `k` over `num_pipe_per_mec` (inner), so `k` (pipe) must be passed before `j` (queue) to `amdgpu_gfx_is_mec_queue_enabled` and `gfx_v9_0_compute_ring_init`, and `ring_id` must increment only for enabled queues. [F1724]
- In `gfx_v9_0_get_cu_info`, `disable_masks` is indexed by `[i * adev->gfx.config.max_sh_per_se + j]`, but 4x4 arrays `cu_info->bitmap[0]` and `cu_info->ao_cu_bitmap` must be indexed as `[i % 4][j + i / 4]` so 8-SE/1-SH ASICs (Arcturus) map SE 4..7 into column 1 without overflow. [F1732]
- In `gfx_v9_0_ecc_late_init`, `gfx_v9_0_do_edc_gds_workarounds` must only run on cold boot (`!adev->in_suspend`) when `adev->gds.gds_size` is non-zero, and GPR/GDS ECC workarounds must run in `late_init` after the direct IB pool and compute rings are ready. [F1755]
- `gfx_v9_0_select_se_sh`, `gfx_v9_4_select_se_sh`, and `gfx_v9_4_2_select_se_sh` must write `GRBM_GFX_INDEX` via `WREG32_SOC15_RLC_SHADOW*`, and `wave_read_ind` / `wave_read_regs` must write `SQ_IND_INDEX` via `WREG32_SOC15_RLC*` per `rlcg_access_gc_9_0`. [F1764]
- In `gfx_v9_0_get_gpu_clock_counter`, `IP_VERSION(9, 3, 0)` must read `mmGOLDEN_TSC_COUNT_UPPER_Renoir`/`LOWER_Renoir` under `preempt_disable()` with `RREG32_SOC15_NO_KIQ` and rollover check (`hi_check != clock_hi`), whereas other GFX9 versions must bracket `mmRLC_GPU_CLOCK_COUNT_LSB`/`MSB` with `amdgpu_gfx_off_ctrl` and `adev->gfx.gpu_clock_mutex`. [F1766]
- In `gfx_v9_0_set_powergating_state` on GC 9.1.0, 9.2.2, and 9.3.0, `amdgpu_gfx_off_ctrl_immediate(adev, false)` must precede power-gating register writes when ungating (`!enable`), and `amdgpu_gfx_off_ctrl_immediate(adev, true)` must follow them when gating (`enable`). [F1771]
