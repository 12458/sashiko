# TTY LAYER AND SERIAL DRIVERS — drivers/tty (part 3)

This unit implements core TTY VFS operations (`tty_io.c`, `tty_buffer.c`, `tty_baudrate.c`, `tty_audit.c`, `tty.h`), Magic SysRq (`sysrq.c`), SyncLink GT (`synclink_gt.c`), and the Tegra TCU (`tegra-tcu.c`), Tegra UTC (`tegra-utc.c`), Intel Timberdale (`timbuart.c`), and Cadence/Xilinx Zynq (`xilinx_uartps.c`) UART drivers.

## Architecture & Data Flow
- `tty_buffer_alloc()` allocates `struct_size(p, data, 2 * size)` bytes, sets `p->size = size`, and adds `size` to `port->buf.mem_used` (even when reusing from `port->buf.free`); `tty_buffer_free()` and `tty_buffer_free_all()` subtract `p->size` before pushing to `buf->free` or freeing. A `tty_buffer` with `!flags` uses all `2 * size` bytes for chars, so `lookahead_bufs()` and `receive_buf()` must check `head->flags` before `flag_buf_ptr()`, and `__tty_buffer_request_room()` must allocate a new buffer when `!b->flags && flags`. [F397, F417, F484]
- In `tty_buffer_flush()` and `flush_to_ldisc()`, `buf->head` is freed and advanced only when `smp_load_acquire(&buf->head->next)` is non-NULL so `head`/`tail` are never NULL; on the remaining tail buffer, `tty_buffer_flush()` must set both `head->read` and `head->lookahead` to `head->commit` under `buf->lock`. [F418, F462]
- Under `tty_lock`, `tty->count` must equal open entries in `tty->tty_files` + 1 if `PTY_TYPE_SLAVE` has an open master (`tty->link->count`) + 1 if `tty_port_kopened(tty->port)`; `tty_add_file()` / `tty_del_file()` must stay in lockstep with `tty->count` and `tty_port_set_kopened()`. [F420]
- In `__tty_hangup()`, if any file on `tty->tty_files` has `write_iter == redirected_tty_write` (`cons_filp != NULL`), it must not set `cons_filp->f_op = &hung_up_tty_fops` and must call `tty->ops->close(tty, cons_filp)` `closecount` times instead of `tty->ops->hangup(tty)`. [F421]
- When `tty_init_termios()` restores `tty->driver->termios[idx]`, it must reset `tty->termios.c_line = tty->driver->init_termios.c_line` and recompute `c_ispeed`/`c_ospeed` via `tty_termios_input_baud_rate()` and `tty_termios_baud_rate()`. [F406]
- In `tegra-tcu.c`, `tegra_tcu_write_one()` and `tegra_tcu_receive()` pass the 32-bit word (`TCU_MBOX_BYTE` in `[23:0]`, `TCU_MBOX_NUM_BYTES(count)` in `[25:24]`) cast directly as `void *msg` (never `u32 *`), and `tegra_tcu_write()` must flush via `tegra_tcu_write_one()` whenever `written == 3` (including after `'\r'` during `\n` expansion). [F412, F446]
- In `tegra-utc.c`, TX/RX IRQ changes must update `tup->tx_irqmask` / `tup->rx_irqmask` in lockstep with `TEGRA_UTC_INTR_MASK` and `TEGRA_UTC_INTR_SET`, as `tegra_utc_isr()` masks `INTR_STATUS` and clears `INTR_CLEAR` with them. [F426]
- In `xilinx_uartps.c`: `cdns_uart->tx_timer` is shared between `cdns_rs485_tx_callback` and `cdns_rs485_rx_callback`, requiring `hrtimer_update_function()` before `hrtimer_start()`, and `cdns_rs485_tx_setup()` / `rx_setup()` must keep `rs485_tx_started` synced with RTS; `cdns_calc_after_tx_delay()` must cast `delay_rts_after_send` to `u64` before `* NSEC_PER_MSEC` and add `DIV_ROUND_UP(port->frame_time, 7)`; `cdns_uart_tx_empty()` must check `(status & (CDNS_UART_SR_TXEMPTY | CDNS_UART_SR_TACTIVE)) == CDNS_UART_SR_TXEMPTY`; `cdns_uart_probe()` must set `port->mapsize = resource_size(res)` and pass `port->mapsize` to `request_mem_region()`, `ioremap()`, and `release_mem_region()`; and `CDNS_UART_RXBS` / `CDNS_UART_IXR_BRK` use must be gated on `cdns_uart->quirks & CDNS_UART_RXBS_SUPPORT`. [F429, F455, F476, F477, F497, F501]
- `jiffies` timeouts in `cdns_uart_console_putchar()`, `cdns_uart_console_setup()`, and `wait_until_sent()` (`synclink_gt.c`) must use `time_after()` / `time_before()`. [F483]

## Synchronization
- In `__tty_buffer_request_room()`, `smp_store_release(&b->commit, b->used)` must precede `smp_store_release(&b->next, n)`, and consumers (`flush_to_ldisc()`, `lookahead_bufs()`, `tty_buffer_flush()`) must `smp_load_acquire(&head->next)` before `smp_load_acquire(&head->commit)`. `tty_buffer_lock_exclusive()` and `tty_buffer_flush()` must increment `port->buf.priority` before locking `port->buf.lock`, and `tty_buffer_unlock_exclusive()` must requeue `port->buf.work` if `head->commit != head->read`. [F372, F374]
- For PTY pairs, `tty->legacy_mutex` locks master-then-slave (`TTY_LOCK_NORMAL` before `tty_lock_slave()` with `TTY_LOCK_SLAVE`), whereas nested `port->buf.lock` locks slave-then-master (`TTY_LOCK_SLAVE` via `tty_buffer_set_lock_subclass()` before `TTY_LOCK_NORMAL`). [F519]
- `tty->write_buf` and `tty->write_cnt` require `tty->atomic_write_lock` (`tty_write_lock()`) across reallocation and `ld->ops->write()` in `iterate_tty_write()`. `tty_encode_baud_rate()` and `tty_get_baud_rate()` require `tty->termios_rwsem`. [F380, F381]
- `do_SAK()` and `tty_hangup()` may run in atomic/IRQ context and must schedule `tty->SAK_work` / `tty->hangup_work`, whereas `tty_vhangup()` and `tty_vhangup_session()` must call `__tty_hangup()` synchronously. In `show_cons_active()`, `console_list_lock()` must wrap `console_lock()` until after `console_unlock()`. [F523, F525, F541]
- While multithreaded, all `struct tty_audit_buf` field accesses and `tty_audit_buf_push(buf)` calls require `buf->mutex`. [F383]
- `__handle_sysrq()` runs `op_p->handler(key)` under `rcu_read_lock()` (often in IRQ context): handlers must not sleep (defer via `schedule_work()`), `__sysrq_swap_key_ops()` must call `synchronize_rcu()` after updating `sysrq_key_table` under `sysrq_key_table_lock`, and `sysrq_handle_crash()` must call `rcu_read_unlock()` before `panic()`. When `trigger_all_cpu_backtrace()` is false, `sysrq_handle_showallcpus()` must wrap local printing in `get_cpu()`/`put_cpu()` and defer `smp_call_function(showacpu, ...)` to `sysrq_showallcpus` work, where `showacpu()` uses `raw_spin_lock_irqsave(&show_lock, flags)`. [F384, F516, F518]
- UART RX ISRs holding `port->lock` must not call `uart_handle_sysrq_char()`; use `uart_prepare_sysrq_char()` + `uart_unlock_and_check_sysrq()` (`cdns_uart_handle_rx`/`cdns_uart_isr`) or drop `port->lock` (`tegra_utc_rx_chars`). [F386]
- In `tegra-utc.c`, `tegra_utc_console_write_atomic()` and `tegra_utc_console_write_thread()` must bracket all TX register accesses with `nbcon_enter_unsafe(wctxt)` / `nbcon_exit_unsafe(wctxt)` and abort if either returns false. [F528]
- In `timbuart.c`, `timbuart_handleinterrupt()` must save `TIMBUART_IER` to `uart->last_ier` and mask `TIMBUART_IER` before scheduling `uart->tasklet` (which re-enables `IER` under `port->lock`), `timbuart_start_tx()` must schedule `uart->tasklet`, and `timbuart_remove()` must call `tasklet_kill(&uart->tasklet)` before `uart_remove_one_port()`. [F530]
- In `xilinx_uartps.c`: `cdns_uart_shutdown()` must call `hrtimer_cancel(&cdns_uart->tx_timer)` before `uart_port_lock_irqsave()`; in `cdns_uart_clk_notifier_cb()`, `POST_RATE_CHANGE` sets `locked = 1` under `port->lock` and falls through to `ABORT_RATE_CHANGE` (which locks only if `!locked`); and `cdns_uart_console_write()` must use `uart_port_trylock_irqsave()` when `oops_in_progress` and unlock only if `locked`. [F459, F531, F532]

## Object Lifetimes
- In `tty_init_dev()`, any failure after `tty_driver_install_tty()` must unlock `tty` and call `release_tty(tty, idx)` (not `free_tty_struct(tty)`); if `tty->port` is still NULL, it must abort with `-EINVAL` via `err_release_lock`, and `release_tty()` must NULL-check `tty->port` and `tty->link`. [F354, F398]
- `tty_release_struct()` and `tty_kclose()` must call `tty_ldisc_release(tty)` and `tty_flush_works(tty)` before locking `tty_mutex` and calling `release_tty()`, because `tty_kref_put()` defers `release_one_tty()` via `queue_release_one_tty()` by reusing `tty->hangup_work`. [F358, F522]
- `__tty_hangup()` must call `tty_kref_put(tty)` for each ref returned by `tty_signal_session_leader()`, and under `tty->ctrl.lock` must set `tty->ctrl.session` and `tty->ctrl.pgrp` to `NULL` after `put_pid()`. [F359]
- `tty_buffer_free_all()` runs unlocked and warns if `atomic_xchg(&buf->mem_used, 0)` mismatches freed bytes, so `port->buf.work` and all producers/consumers must be stopped first; both `tty_buffer_free()` and `tty_buffer_free_all()` must check `b->size > 0` to avoid freeing `&port->buf.sentinel`. [F375, F487]
- `tty_audit_exit()` sets `current->signal->tty_audit_buf` to `ERR_PTR(-ESRCH)` and calls `tty_audit_buf_push(buf)` before `tty_audit_buf_free(buf)`; `tty_audit_buf_get()` uses `cmpxchg()` against `NULL` and frees its buffer on race. [F363]
- `tegra_tcu_probe()` must request the `"rx"` mbox channel only after `uart_add_one_port()`, and `tegra_tcu_remove()` must call `mbox_free_channel(tcu->rx)` before `uart_remove_one_port()` because `tegra_tcu_receive()` dereferences `tcu->port.state->port`. [F387]
- In `xilinx_uartps.c`, `cdns_uart_probe()` must reset `console_port = NULL` and `cdns_uart_console.index = -1` if `!console_is_registered(cdns_uart_uart_driver.cons)` after `uart_add_one_port()`, and `cdns_uart_remove()` must clear `console_port = NULL`. [F368]

## API Contracts
- `tty_init_dev()` and `tty_kopen_exclusive()` return `tty` with `tty_lock` held, while `tty_kopen_shared()` returns an unlocked `tty` with a kref. `tty_driver_lookup_tty()` returns `ERR_PTR`, `NULL`, or a kref'd `tty_struct *` (callers must check `IS_ERR()` and `tty_kref_put()`). `tty_open_current_tty()` returns `NULL` only when `device != MKDEV(TTYAUX_MAJOR, 0)` and `ERR_PTR` on `/dev/tty` open errors, which `tty_open()` must propagate without falling back to `tty_open_by_driver()`. [F355, F391, F392]
- `this_tty()` (for `iterate_fd()`) must verify `file->f_op->read_iter == tty_read` before `file_tty(file)` and return `fd + 1` on match (`__do_SAK()` logs `i - 1`). [F395, F488]
- `tty_termios_encode_baud_rate(termios, ibaud, obaud)` takes `ibaud` first, forces `ibaud = 0` if `obaud == 0`, samples `ibinput` and `BOTHER` in `c_cflag` before clearing `CBAUD` / `CBAUD << IBSHIFT`, and matches `obaud` (`ofound = i`) before `ibaud` in each loop iteration so `CBAUD << IBSHIFT` stays `B0` when `ibaud == obaud && !ibinput`. [F407, F415, F467]
- `tty_tiocmset()` must mask `set`/`clear` with `TIOCM_DTR | TIOCM_RTS | TIOCM_OUT1 | TIOCM_OUT2 | TIOCM_LOOP`. Bounded `ctl_table` entries in `tty_table` (`.extra1`/`.extra2`) must use `proc_dointvec_minmax`. `tty_buffer_set_limit()` requires `limit >= MIN_TTYB_SIZE` (256) before flip-buffer use. `tty_prepare_flip_string()`'s `*chars` pointer must never be used directly for DMA. [F409, F410, F515, F535]
- `cdns_uart_calc_baud_divs()` requires `baud != 0` and returns `0` if no divisors fit, which `cdns_uart_clk_notifier_cb()` must reject with `NOTIFY_BAD` on `PRE_RATE_CHANGE`. In `timbuart_set_termios()`, `old` must be NULL-checked before `tty_termios_copy_hw()`, and negative `bindex` from `get_bindex()` must be clamped before indexing `baudrates[bindex]`. [F396, F399, F447, F478]

## Error Handling
- In `tty_register_device_attr()`, `device_register(dev)` failure calls only `put_device(dev)`, whereas `tty_cdev_add()` failure calls `device_del(dev)` then `put_device(dev)`, and `cdev_add()` failure inside `tty_cdev_add()` must call `kobject_put(&driver->cdevs[index]->kobj)`. [F360]
- Once `tty_add_file()` is called in `tty_open()`, error cleanup must call `tty_release()` (not `tty_free_file()`) and reset `filp->f_op = &tty_fops` if `tty_hung_up_p(filp)` before `retry_open`. [F401]
- In `iterate_tty_read()`, if `copy_to_iter()` shorts with `cookie != NULL`, the loop must continue with `count = 0` and `retval = -EFAULT` without a negative `size` overwriting `retval`; `iterate_tty_read()` must call `memzero_explicit(kernel_buf, ...)` and `receive_buf()` must `memset(p, 0, n)` consumed flip-buffer bytes. [F402, F403]
- `tty_get_icount()`, `tty_tiocgserial()`, and `compat_tty_tiocgserial()` must zero output structs before driver callbacks; `compat_tty_tiocsserial()` must set `v.iomap_base = 0`; and both compat helpers must stop `memcpy` at `offsetof(struct serial_struct32, iomem_base)`. [F404, F442]
- `tty_buffer_alloc()` must use `GFP_ATOMIC | __GFP_NOWARN`, and `tty_set_serial()` / `tty_init_dev()` must use ratelimited logging. In `xilinx_uartps.c`, if enabling `uartclk` fails after `pclk`, `pclk` must be disabled. [F505, F550]

## External Contracts
- In `tty_ioctl()` / `tty_compat_ioctl()`, `tty_jobctrl_ioctl()` and driver ioctls return `-ENOIOCTLCMD` when unhandled to fall through to `ld->ops->ioctl()`, with final `-ENOIOCTLCMD` mapped to `-ENOTTY`; `TIOCCBRK` skips `tty_wait_until_sent()`; `TCFLSH` must `break` after `tty_buffer_flush()`; `TIOCGWINSZ`/`TIOCSWINSZ`/`TIOCGDEV` use `real_tty` (`tty_pair_get_tty(tty)`) while `TIOCCONS` rejects `real_tty != tty` with `-EINVAL`; and `tty_compat_ioctl()` / `slgt_compat_ioctl()` convert only pointer args via `compat_ptr(arg)`. [F394, F457, F458, F472, F545]
- `tiocsti()` must enforce `!tty_legacy_tiocsti && !capable(CAP_SYS_ADMIN)` (`-EIO`) and `(current->signal->tty != tty) && !capable(CAP_SYS_ADMIN)` (`-EPERM`), and call `tty_audit_tiocsti()` before locking `tty_buffer_lock_exclusive(tty->port)`. `tty_update_time()` updates timestamps only when `(sec ^ time.tv_sec) & ~7` is non-zero. [F538, F542]
- `tty_audit_add_data()` must skip `PTY_TYPE_MASTER` and `icanon && !L_ECHO(tty)` (unless `AUDIT_TTY_LOG_PASSWD`), clamp copies to `TTY_AUDIT_BUF_SIZE - buf->valid`, and call `tty_audit_buf_push(buf)` when `dev`/`icanon` changes or `buf->valid == TTY_AUDIT_BUF_SIZE`. `tty_audit_log()` must use `from_kuid(&init_user_ns, ...)` and `audit_log_untrustedstring()` for `comm`. `write_sysrq_trigger()` processes only the first byte unless it is `'_'`. [F440, F445, F546, F547]

## Known Pitfalls
- Callers of `__tty_buffer_request_room()` must read `port->buf.tail` only after it returns. `tty_buffer_space_avail()` must compute `mem_limit - atomic_read(&mem_used)` as signed `int` clamped with `max(space, 0)`. [F482, F486]
- `file_tty_write()` must use its `file` argument (not `iocb->ki_filp`) for `redirected_tty_write()`. `iterate_tty_write()` must call `iov_iter_revert(from, size - ret)` on partial `ld->ops->write()`. `tty_termios_baud_rate()` / `input_baud_rate()` must test `cbaud == BOTHER` before `cbaud & CBAUDEX` (`0x1000`). [F454, F469, F473]
- In `sysrq.c`: `sysrq_reinject_alt_sysrq()` must bracket `input_inject_event()` with `sysrq->reinjecting = true/false` and `mb()`; `sysrq_handle_keypress()` must clear `KEY_SYSRQ` in `dev->key` when `sysrq->active`; keypress/reset-seq handlers must ignore autorepeat (`value == 2`); and reset-seq helpers must reject keys `> KEY_MAX` and cast `kp->arg` as `unsigned short *`. [F425, F460, F494]
- In `xilinx_uartps.c`: `CDNS_UART_IER`/`IDR` are write-only (read `CDNS_UART_IMR` instead); never enable `CDNS_UART_IXR_PARITY` in `IER` or `CDNS_UART_RX_IRQS`; `cdns_uart_isr()` must check `!(readl(CR) & CDNS_UART_CR_RX_DIS)` before `cdns_uart_handle_rx()`; `cdns_uart_handle_rx()` must reset `isrstatus = 0` each loop iteration; and `cdns_uart_set_termios()` must preserve bit 0 (`cval |= mode_reg & 1`) in `CDNS_UART_MR`. [F428, F466, F498, F499, F500]
