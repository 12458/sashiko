# NETWORKING DRIVERS — include

This unit provides the core kernel headers, UAPI definitions, and Device Tree bindings for Linux network devices, link-layer protocols (Ethernet, 802.1Q VLAN, MACVLAN, HSR, PPPoX, TUN/TAP, FDDI, Fibre Channel, ARP), IPv4 device configuration, and ethtool/netdev netlink interfaces. Centered around `include/linux/netdevice.h`, it defines the lifecycle, queueing, NAPI polling, feature offload masks, statistics, and driver callback contracts (`struct net_device_ops`) used across all networking drivers and stack layers.

## Architecture & Data Flow
- `net_device::priv` has `__counted_by(priv_len)`, so allocations must set `dev->priv_len` before `netdev_priv(dev)`. `vlan_dev_priv()` and `macvlan_dev_real_dev()` / `macvlan_accel_priv()` unconditionally cast `netdev_priv(dev)`, so callers with an arbitrary `net_device *` must first check `is_vlan_dev(dev)` or `netif_is_macvlan(dev)`. `dev->ml_priv` is typed by `dev->ml_priv_type` and must be accessed via `netdev_get_ml_priv(dev, type)` (checking for `NULL`) and `netdev_set_ml_priv()`. [F1088, F1090, F1162]
- Never set `NETIF_F_HW_CSUM` together with `NETIF_F_IP_CSUM` or `NETIF_F_IPV6_CSUM`; multi-tagged VLAN packets must use `vlan_features_check()` (stripping all checksum offloads except `NETIF_F_HW_CSUM`) rather than `netdev_intersect_features()`. `can_checksum_protocol()` must check `protocol == htons(ETH_P_FCOE)` against `NETIF_F_FCOE_CRC` before testing `NETIF_F_HW_CSUM`. [F1140, F1222]
- New `NETIF_F_*_BIT` entries require matching `netdev_features_strings[]` entries in `net/ethtool/common.c`, and GSO bits in `NETIF_F_GSO_SHIFT..NETIF_F_GSO_LAST` must match `SKB_GSO_*` order in `net_gso_ok()`. `net_gso_ok()` maps `SKB_GSO_TCP_FIXEDID` and `SKB_GSO_TCP_FIXEDID_INNER` to `__SKB_GSO_TCP_FIXEDID`, shifts `gso_type` by `NETIF_F_GSO_SHIFT`, and checks `(features & feature) == feature`. `NETIF_F_ETHTOOL_BITS` must use `(__NETIF_F_BIT(NETDEV_FEATURE_COUNT - 1) | (__NETIF_F_BIT(NETDEV_FEATURE_COUNT - 1) - 1))` to avoid shifting by `NETDEV_FEATURE_COUNT`. [F1120, F1142, F1149]
- `__vlan_hwaccel_put_tag()` must set both `skb->vlan_proto` and `skb->vlan_tci`, and `__vlan_hwaccel_push_inside()` must clear `skb->vlan_all` via `__vlan_hwaccel_clear_tag()` after pushing the tag into the payload. [F1103]
- Because `is_multicast_ether_addr()` and `is_multicast_ether_addr_64bits()` return `true` for broadcast (`FF:FF:FF:FF:FF:FF`), `eth_skb_pkt_type()` must check `ether_addr_equal_64bits(eth->h_dest, dev->broadcast)` inside the multicast branch to classify `PACKET_BROADCAST` before `PACKET_MULTICAST`. [F1143]
- `struct sock sk` must stay first in `struct pppox_sock` (for `pppox_sk()`/`sk_pppox()`), `sizeof(struct sockaddr_pppox)` in UAPI must stay fixed, and `struct netdev_notifier_info info` must stay first in all `netdev_notifier_*_info` structs. [F1166, F1225]
- `XPS_MAP_SIZE(_num)` scales by `sizeof(u16)` for `xps_map::queues[]`, while `XPS_CPU_DEV_MAPS_SIZE(_tcs)` and `XPS_RXQ_DEV_MAPS_SIZE(_tcs, _rxqs)` scale by `sizeof(struct xps_map *)` for `xps_dev_maps::attr_map[]` and save `nr_ids` and `num_tc` (which must be used instead of `dev->num_tc` when indexing `attr_map[]`). [F1163]
- New `enum netdev_cmd` values require updating `netdev_cmd_to_name()` in `net/core/dev.c` (and `rtnetlink_event()` if applicable). `GRO_HASH_BUCKETS` must not exceed `sizeof(unsigned long) * 8` (`gro_node::bitmask` width). Only assign `dev->rx_cpu_rmap` if `ndo_rx_flow_steer` is implemented. [F1121, F1134, F1181]

## Synchronization
- `HARD_TX_LOCK(dev, txq, cpu)` and successful `HARD_TX_TRYLOCK(dev, txq)` acquire `txq->_xmit_lock` (`!dev->lltx`) or `__netif_tx_acquire(txq)` (`dev->lltx`) and must be paired on all paths with `HARD_TX_UNLOCK(dev, txq)`, not `__netif_tx_unlock(txq)`. `netif_tx_disable()` disables BH and takes `dev->tx_global_lock` before each `txq->_xmit_lock`, so `txq->_xmit_lock` nests inside `dev->tx_global_lock` with BH disabled. [F1053, F1065]
- `netif_tx_stop_queue()` must `WRITE_ONCE(dev_queue->trans_start, jiffies)` and `smp_mb__before_atomic()` before setting `__QUEUE_STATE_DRV_XOFF` (pairing with `dev_watchdog()`). In BQL, `netdev_tx_sent_queue()` must set `__QUEUE_STATE_STACK_XOFF` and `smp_mb__after_atomic()` before rechecking `dql_avail(&dev_queue->dql) >= 0`, pairing with `smp_mb()` in `netdev_tx_completed_queue()` between `dql_completed()` and `test_and_clear_bit(__QUEUE_STATE_STACK_XOFF, &dev_queue->state)`. [F1062, F1063]
- Per-CPU stats with `struct u64_stats_sync syncp` (`pcpu_sw_netstats`, `pcpu_dstats`, `pcpu_lstats`, `vlan_pcpu_stats`) must call `u64_stats_init(&stat->syncp)` on all possible CPUs at allocation (`__netdev_alloc_pcpu_stats()`) and wrap `u64_stats_t` updates in `u64_stats_update_begin()`/`u64_stats_update_end()` with preemption/BH disabled (`macvlan_count_rx()` uses `get_cpu_ptr()`/`put_cpu_ptr()`; `dev_sw_netstats_*()`, `dev_lstats_add()`, and `dev_dstats_*()` use `this_cpu_ptr()` and require non-preemptible callers). [F1071, F1195]
- In `struct napi_struct`, fields `thread` through `config` (`thread`, `gro_flush_timeout`, `irq_suspend_timeout`, `defer_hard_irqs`, `napi_id`, `dev_list`, `napi_hash_node`, `irq`, `notify`, `napi_rmap_idx`, `index`, `config`) are write-protected by `netdev_lock(napi->dev)`. [F1057]
- `net_device` hardware address list updates require `netif_addr_lock()` / `netif_addr_lock_bh()` (which nest via `dev->nested_level`), while lockless `for_each_dev_addr(dev, ha)` iteration requires `rcu_read_lock()`. [F1066]
- `in_dev_for_each_ifa_rcu()` requires `rcu_read_lock()`, `in_dev_for_each_ifa_rtnl()` requires `rtnl_lock`, and `in_dev_for_each_ifa_rtnl_net()` requires the per-netns RTNL lock. `vlan_get_rx_ctag_filter_info()`, `vlan_drop_rx_ctag_filter_info()`, `vlan_get_rx_stag_filter_info()`, and `vlan_drop_rx_stag_filter_info()` require `rtnl_lock` (`ASSERT_RTNL()`). [F1074, F1076]
- `____dev_forward_skb()` and `dev_hold()` run in atomic/RCU contexts and must pass `GFP_ATOMIC` to `skb_orphan_frags()` and `netdev_hold()`. Access `struct netdev_xmit` via `dev_recursion_level()`, `netdev_xmit_set_more()`, and `netdev_xmit_more()`, never `softnet_data.xmit` directly (`CONFIG_PREEMPT_RT` stores `net_xmit` on `current->net_xmit`). [F1188, F1196]

## Object Lifetimes
- `in_dev_get(dev)` increments `in_dev->refcnt` under `rcu_read_lock()` and requires `in_dev_put()`, whereas `__in_dev_get_rcu()`, `__in_dev_get_rtnl()`, and `__in_dev_get_rtnl_net()` do not increment `refcnt`. `ip_dev_find(net, addr)` calls `__ip_dev_find(net, addr, true)` and requires `dev_put()`, unlike `__ip_dev_find(net, addr, false)`. [F1042, F1043]
- `netdev_tracker_alloc()` upgrades an existing untracked reference (decrementing `no_tracker` without `__dev_hold()`), while `netdev_hold()` takes both a reference and a tracker; `netdev_ref_replace()` holds `@ndev` before putting `@odev`. [F1050]
- `netif_napi_add()` must initialize `napi_struct` before any other NAPI call, and if `dev->irq_affinity_auto` is set, `netif_napi_add_config()` must precede `netif_napi_set_irq()`. Unlike `netif_napi_del()` / `netif_napi_del_locked()`, `__netif_napi_del()` and `__netif_napi_del_locked()` do not call `synchronize_net()`, so callers must wait for an RCU grace period before freeing `@napi`. [F1045, F1046]
- `SET_NETDEV_DEVLINK_PORT(dev, port)` is only valid while `dev->reg_state == NETREG_UNINITIALIZED`, and `dev->devlink_port` must not change while registered. `napi_free_frags()` sets `napi->skb = NULL` after freeing, and `macvlan_release_l2fw_offload()` clears `macvlan->accel_priv = NULL` before `dev_uc_add()`. [F1047, F1049]

## API Contracts
- TX return codes `rc < NET_XMIT_MASK` (`dev_xmit_complete(rc)` is true: `NETDEV_TX_OK`, `-errno`, `NET_XMIT_*`) mean `@skb` was consumed; `rc >= NET_XMIT_MASK` (`NETDEV_TX_BUSY`) leaves `@skb` unconsumed. Broken by: `ndo_start_xmit` freeing `@skb` on `NETDEV_TX_BUSY`, returning `-errno` without freeing `@skb`, or `__dev_direct_xmit()` callers not freeing `@skb` when `!dev_xmit_complete(ret)`. [F1039]
- Never call `kfree_skb()` or `consume_skb()` when `in_hardirq() || irqs_disabled()`; use `dev_kfree_skb_irq()`, `dev_consume_skb_irq()`, `dev_kfree_skb_any()`, or `dev_consume_skb_any()`. [F1052]
- Only call `napi_complete_done()` when `work_done < budget`, and only rearm IRQs if it returns `true`. `napi_synchronize()` only waits for `NAPI_STATE_SCHED` to clear without blocking concurrent `napi_schedule()` calls; stop IRQ/timer sources first or use `napi_disable()` / `napi_disable_locked()`. [F1059, F1087]
- BQL `netdev_tx_completed_queue()` / `netdev_completed_queue()` `@bytes` must exactly match the `@bytes` passed to `netdev_tx_sent_queue()` / `__netdev_tx_sent_queue()` / `netdev_sent_queue()`. When `__netdev_tx_sent_queue()` or `__netdev_sent_queue()` returns `true`, the driver must ring the TX doorbell. `netdev_tx_reset_queue()` / `netdev_tx_reset_subqueue()` must both clear `__QUEUE_STATE_STACK_XOFF` and call `dql_reset(&q->dql)`. [F1097, F1116, F1182]
- Modify `dev->dev_addr` only via `dev_addr_mod()`, `dev_addr_set()`, `__dev_addr_set()`, or `eth_hw_addr_set()` to keep `dev_addr_shadow` and `dev_addrs` synced. `eth_hw_addr_random()` sets `NET_ADDR_RANDOM` and `eth_hw_addr_inherit()` copies `addr_assign_type`, whereas `eth_hw_addr_set()` and `eth_hw_addr_gen()` do not change `addr_assign_type`. `eth_addr_dec()`, `eth_addr_inc()`, `eth_addr_add()`, and `eth_hw_addr_gen()` must use `ether_addr_to_u64()` and `u64_to_ether_addr()`. [F1101, F1102, F1152]
- `is_link_local_ether_addr()`, `is_zero_ether_addr()`, `is_broadcast_ether_addr()`, `is_valid_ether_addr()`, `ether_addr_copy()`, `ether_addr_equal()`, and `compare_vlan_header()` require `u16` alignment (use `ether_addr_equal_unaligned()` if unaligned). `ether_addr_equal_64bits()`, `is_multicast_ether_addr_64bits()`, and `is_etherdev_addr()` read 8 bytes and require `u16` alignment plus 2 trailing pad bytes. `compare_ether_header()` requires `a + 2` and `b + 2` to be 4-byte aligned when `!CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`. [F1123, F1124, F1204]
- `net_device_ops::ndo_start_xmit` is mandatory. `ndo_fix_features` must only return the adjusted mask without side effects; `ndo_set_features` applies state and must return `> 0` or `-errno` if it mutates `dev->features` directly. Only virtual/userspace-controlled devices may implement `ndo_change_carrier`. Drivers not implementing `ndo_get_stats64` (which receives a zeroed `rtnl_link_stats64`) must update `dev->stats` atomically (`DEV_STATS_INC`/`DEV_STATS_ADD`). [F1179, F1207, F1212, F1213]
- `netif_carrier_on()` and `netif_carrier_off()` are hardirq-safe, but callers must serialize concurrent calls on the same device. Use `netif_oper_up()` (which accepts `IF_OPER_UP` and `IF_OPER_UNKNOWN`) instead of testing `dev->operstate == IF_OPER_UP`. [F1067, F1147]
- `__vlan_insert_inner_tag()`, `__vlan_insert_tag()`, `vlan_insert_inner_tag()`, `vlan_insert_tag()`, `vlan_insert_tag_set_proto()`, and `__vlan_hwaccel_put_tag()` take `@vlan_proto` as `__be16` and `@vlan_tci` in host byte order (`u16`). IPv4 config queries combined with `devconf_all` must use `IN_DEV_ANDCONF`, `IN_DEV_ORCONF`, `IN_DEV_MAXCONF`, `IN_DEV_RX_REDIRECTS`, or `IN_DEV_RPFILTER` rather than raw `IN_DEV_CONF_GET()`. [F1100, F1113]
- Clamp active TX queue indices to `dev->real_num_tx_queues` with `netdev_cap_txqueue()` before `netdev_get_tx_queue()`. Compare non-zero `txq->trans_start` / `dev_trans_start()` timestamps with `time_after()` / `time_before()`. [F1129, F1157]
- Non-RCU adjacency helpers (`netdev_lower_get_next()`, `netdev_lower_get_next_private()`) start `iter` at `dev->adj_list.lower.next`, whereas RCU helpers (`netdev_next_lower_dev_rcu()`, `netdev_lower_get_next_private_rcu()`, `netdev_upper_get_next_dev_rcu()`) start at `&dev->adj_list.{lower,upper}`. `for_each_netdev_dump()` requires pre-initializing `unsigned long ifindex` and never manually incrementing `ifindex` when breaking out on buffer full. [F1136, F1137]
- `netif_attrmask_next()` and `netif_attrmask_next_and()` must guard `cpu_max_bits_warn(n, nr_bits)` with `if (n != -1)`. `netif_msg_init()` must check `debug_value < 0 || debug_value >= 32` and `debug_value == 0` before shifting `1U << debug_value`. [F1145, F1153]

## Error Handling
- `ndo_uninit` is not called if `ndo_init` fails, so `ndo_init` must clean up all its allocations on error. `dev_queue_xmit()` callers must use `net_xmit_eval()` or `net_xmit_errno()` so `NET_XMIT_CN` is not treated as a drop. [F1044, F1079]
- `ndo_xdp_xmit` must free un-transmitted frames via `xdp_return_frame()` when returning `>= 0`, but must not free any frames when returning `< 0`. `ndo_bpf` (`XDP_SETUP_PROG` / `XDP_SETUP_PROG_HW`) must not `bpf_prog_put(bpf->prog)` on error, and must `bpf_prog_put()` the old program on success. [F1081, F1082]
- Check `__vlan_get_tag()` / `vlan_get_tag()` for `0` before reading `*vlan_tci` (they return `-ENODATA` without writing `*vlan_tci`). Check `tap_get_socket()`, `tap_get_ptr_ring()`, `tun_get_socket()`, and `tun_get_tx_ring()` with `IS_ERR()`, not `!ptr`. Check `__in_dev_get_rcu()`, `in_dev_get()`, and `__in_dev_get_rtnl*()` for `NULL` before passing to `IN_DEV_*` macros. [F1084, F1086, F1091]

## External Contracts
- Legacy `__be16` `TUNNEL_*` flags in `include/uapi/linux/if_tunnel.h` have no free bits; add new tunnel flags only to `IP_TUNNEL_*_BIT`. [F1133]

## Known Pitfalls
- Use shifted `NETIF_F_*` masks (not `NETIF_F_*_BIT` indices) on `dev->features`; pass bit indices `NAPI_STATE_*` / `__QUEUE_STATE_*` to `test_bit()`/`set_bit()` and shifted masks `NAPIF_STATE_*` / `QUEUE_STATE_*` to bitwise `&`/`|`. Use `BIT_ULL()` for bits 30..31 of `enum netdev_priv_flags`, and add new private flags as 1-bit bitfields on `struct net_device` rather than exceeding 32-bit `priv_flags`. [F1095, F1096, F1151]
- Reading `dev->up` under `netdev_lock(dev)` alone (without `rtnl_lock`) on a device without ops locking can see false negatives during concurrent `.ndo_open`/`.ndo_close`. Use `netdev_name(dev)` in logs because `dev->name` may contain unexpanded `%d` before registration. Call `pskb_may_pull(skb, VLAN_ETH_HLEN)` before `skb_vlan_eth_hdr(skb)` in `skb_vlan_tagged_multi()`. [F1061, F1110, F1169]
- `for_each_netdev_feature(mask_addr, bit)` requires `bit` to be a signed `int`. Wrap `if-else` bodies in braces inside `netdev_for_each_synced_uc_addr()`, `netdev_for_each_synced_mc_addr()`, and `for_each_netdev_in_bond_rcu()`. Guard `1U << (32 - logmask)` with `if (logmask)` in `inet_make_mask()` and `ffz(~hmask)` with `if (!hmask)` in `inet_mask_len()`. [F1138, F1139, F1154]
