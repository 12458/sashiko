# CRYPTO API — crypto (part 1)

This component implements the core Linux kernel cryptographic framework (lookup, larvals, templates, spawns, and transforms), the `acomp`, `aead`, `ahash`, and `akcipher` frontends, `AF_ALG` sockets, and software ciphers, hashes, and AEADs (including AEGIS-128, Adiantum, ARC4, Authenc, and Blowfish).

## Architecture & Data Flow

- Lookup & init: `crypto_alg_mod_lookup()` adds `CRYPTO_ALG_INTERNAL` to `mask` if unset in both `type` and `mask`. In `__crypto_alg_lookup()`, an exact `q->cra_driver_name` match breaks immediately after `crypto_mod_get(q)` and `crypto_mod_put(alg)` on any prior fuzzy match, while fuzzy `cra_name` matches keep scanning. When `frontend->init_tfm` or `alg->cra_init` returns `-EAGAIN` in `crypto_create_tfm_node()` or `__crypto_alloc_tfmgfp()`, call `crypto_shoot_alg(alg)` so `crypto_alloc_tfm_node()` / `crypto_alloc_base()` does not re-select `alg`. [F90, F91, F103]
- Spawns, params & queue: `crypto_remove_spawns()` must check `!spawn->registered`, `&inst->alg == nalg`, and `spawns->next == NULL` before walking `inst->alg.cra_users`, and `crypto_more_spawns()` must propagate `!spawn->dead` to the parent on `stack`. `struct cryptomgr_param` puts `CRYPTOA_TYPE` in `tb[0]`, 1-based `CRYPTOA_ALG` args in `tb[1..CRYPTO_MAX_ATTRS]`, and `NULL` in `tb[i + 1]` (`CRYPTO_MAX_ATTRS + 2` slots); `crypto_algapi_init()` must be `late_initcall`. `crypto_queue` keeps `queue->backlog` at `&queue->list` or the first backlogged entry, advancing in `crypto_dequeue_request()` and rewinding in `crypto_enqueue_request_head()` when `qlen >= max_qlen`. [F62, F83, F96, F134]
- `acomp` & `ahash` chains: `acomp_virt_to_sg()` must save `req->base.flags`, `req->svirt`, and `req->dvirt` into `req->chain` before `acomp_request_set_{src,dst}_sg()` overwrites the union and clears `VIRT` flags; `acomp_reqchain_finish()` restores them and `req->base.{complete,data}` only when `err != -EINPROGRESS`. In `crypto_ahash_setkey()`, when `!tfm->using_shash && crypto_ahash_need_fallback(tfm)`, set the key on both `tfm` and `crypto_ahash_fb(tfm)`. For `CRYPTO_AHASH_ALG_BLOCK_ONLY`, `ahash_prepare_alg()` adds `cra_blocksize + 1` to `cra_reqsize` and `halg.statesize` (tail length at `reqsize - 1`, buffer at `blenp - bs`), and `ahash_{update,finup}_finish()` must restore `req->src`, `req->nbytes`, and `req->base.{complete,data}`. [F35, F56, F58, F61, F118]
- `crypto_hash_walk_done()`: for SG walks (`!(walk->flags & CRYPTO_AHASH_REQ_VIRT)`), subtract `walk->offset` from `walk->data` before `kunmap_local(walk->data)`, and when `walk->entrylen` is non-zero, reset `walk->offset = 0` and increment `walk->pg` before `hash_walk_next(walk)`. [F102]
- `AF_ALG` SGLs & state: `af_alg_alloc_tsgl()` allocates `MAX_SGL_ENTS + 1` entries and `af_alg_sgl` embeds `sgl[ALG_MAX_PAGES + 1]` to reserve a trailing slot for `sg_chain()`, so `af_alg_sendmsg()` must cap additions to `MAX_SGL_ENTS - sgl->cur` and `af_alg_get_rsgl()` / `hash_sendmsg()` to `ALG_MAX_PAGES`. Clear `ctx->merge` when `MSG_SPLICE_PAGES` is used or `af_alg_pull_tsgl()` drains `ctx->used` to 0. `_skcipher_recvmsg()` must import, free, and NULL `ctx->state` (from `algif_skcipher_export()`) and set `CRYPTO_SKCIPHER_REQ_CONT`. `hash_sendmsg()` must call `hash_free_result(sk, ctx)` on a new message (`!ctx->more`) or error (and set `ctx->more = false`). `{hash,aead,skcipher}_check_key()` must `atomic_dec(&pask->nokey_refcnt)` and `atomic_set(&ask->nokey_refcnt, 0)` once keyed. [F65, F67, F68, F74, F75, F105]
- Request tails & ciphers: `crypto_akcipher_sync_prep()` must place `data->buf` at `(u8 *)(req + 1) + reqsize`; in `adiantum.c`, union `u` in `adiantum_request_ctx` and `req` in `adiantum_setkey()`'s `data` must stay last; in `authenc{,esn}.c`, `reqoff >= 2 * digestsize` and `crypto_aead_set_reqsize()` must add `sizeof(*areq_ctx) + reqoff` to the max sub-request size. `crypto_aegis128_decrypt_{generic,simd}()` must copy the tag from `req->src` before decrypting and wipe `req->dst` via `crypto_aegis128_wipe_chunk` on `-EBADMSG`. `crypto_aegis128_{encrypt,decrypt}_chunk_neon()` tail paths must bounce when `short_input` or restore `vst1q_u8(out - AEGIS_BLOCK_SIZE, msg)`, and `crypto_aegis128_have_simd()` requires `cpu_feature(AES)` on 32-bit ARM. `crypto_arc4_crypt()` must mutate `(struct arc4_ctx *)siv`, never `crypto_lskcipher_ctx(tfm)`. `le128_{add,sub}()` must snapshot `v1->b` and `v2->b` before writing `r->b`. [F70, F71, F107, F120, F121, F122, F128, F129]

## Synchronization

- Self-tests & larvals: `crypto_start_tests()` must call `set_crypto_boot_test_finished()` before taking `crypto_alg_sem`; both `crypto_start_tests()` and `crypto_start_test()` must take `down_write(&crypto_alg_sem)`, check/set `larval->test_started = true`, drop `crypto_alg_sem` before `crypto_schedule_test(larval)`, and restart the `crypto_alg_list` scan. `crypto_larval_lookup()` only calls `crypto_larval_add()` when `!(mask & CRYPTO_ALG_TESTED)` but always waits on existing larvals via `crypto_larval_wait()`, which on `!alg` or `-EEXIST` from `larval->adult` must re-run `crypto_alg_lookup()` and loop if still larval. [F17, F18, F19, F20, F98]
- Spawns & instances: `crypto_grab_spawn()` must take `down_write(&crypto_alg_sem)` and check `!crypto_is_moribund(alg)` before linking `spawn->list` into `alg->cra_users` (else `crypto_mod_put(alg)`). In `crypto_spawn_alg()`, if `crypto_mod_get(alg)` fails under `down_read(&crypto_alg_sem)`, pin `alg` with `crypto_alg_get(alg)` before `up_read()` and call `crypto_shoot_alg()` / `crypto_alg_put()` outside the lock. `crypto_destroy_instance_workfn()` must hold `down_write(&crypto_alg_sem)` and only free `tmpl->dead` entries with `refcount_read(&inst->alg.cra_refcnt) == -1`. `crypto_unregister_template()` must `up_write(&crypto_alg_sem)` before `crypto_free_instance()`, `crypto_remove_final()`, and `flush_work(&tmpl->free_work)`. [F22, F23, F24, F25]
- `AF_ALG` locking: lock child `sk` before `lock_sock_nested(psk, SINGLE_DEPTH_NESTING)` in `{aead,hash,skcipher}_check_key()`. Under `lock_sock(sk)`: `alg_bind()` rejects `atomic_read(&ask->refcnt) != 0` with `-EBUSY`; `alg_setsockopt()` rejects `atomic_read(&ask->refcnt) != atomic_read(&ask->nokey_refcnt)` with `-EBUSY`; `af_alg_sendmsg()` checks/sets `ctx->write = true` across `af_alg_wait_for_wmem()`; `af_alg_alloc_areq()` checks/sets `ctx->inflight = true` until `af_alg_free_resources()`; `algif_hash` accesses `ctx->more` and `ctx->result` only under `lock_sock(sk)`. `af_alg_{wmem,data}_wakeup()` must hold `rcu_read_lock()` across `rcu_dereference(sk->sk_wq)` and `sk_wake_async_rcu()`. [F28, F29, F30, F31, F33, F147]
- Atomic contexts: pass `atomic = true` to `acomp_walk_virt()` when holding `crypto_acomp_lock_stream_bh()` so `acomp_walk_done_{src,dst}()` do not `cond_resched()`. `ahash_op_done()` must clear `CRYPTO_TFM_REQ_MAY_SLEEP` from `areq->base.flags` before invoking its finish callback. `crypto_aegis128_{encrypt,decrypt}_simd()` must gate on `aegis128_do_simd()` and bracket each `*_neon` call with `kernel_neon_begin()`/`kernel_neon_end()`. [F135, F139, F151]

## Object Lifetimes

- Core & frontends: `crypto_mod_put()` must save `alg->cra_module` before `crypto_alg_put(alg)` can free `alg`. `*_register_instance()` takes ownership of `inst` only on success; on error the caller must invoke its free helper to `crypto_drop_spawn()` and free `inst`. In `crypto_create_tfm_node()`, `frontend->init_tfm(tfm)` failure skips `crypto_exit_ops(tfm)`, so `crypto_{acomp,ahash}_init_tfm()` must clean up `fb` and `alg->exit_tfm` on error. Async `acomp`/`ahash` ops reject `CRYPTO_TFM_REQ_ON_STACK` unless cloned via `crypto_request_clone()`, `ahash_request_free()` skips `kfree()` if on-stack, and `acomp_request_clone()` must rebase `nreq->{src,dst}` to `&nreq->chain.{ssg,dsg}` when pointing to `req->chain`. [F2, F5, F6, F116, F117]
- `AF_ALG` lifetimes: after `sock_init_data(newsock, sk2)` in `af_alg_accept()`, `newsock` owns `sk2` (`af_alg_release()` frees it), so never `sock_put(sk2)` on subsequent error paths. `alg_bind()` must swap `(ask->type, ask->private)` under `lock_sock(sk)` when `ask->refcnt == 0` and call `alg_do_release(type, private)` after `release_sock(sk)`. Set `sgl.need_unpin = iov_iter_extract_will_pin(&msg->msg_iter)` before `extract_iter_to_sg()`; initialize `rsgl->sgl.{need_unpin,sgt}` and `rsgl->sg_num_bytes = 0` on error whenever `rsgl` is on `areq->rsgl_list`; in `hash_sendmsg()`, jump to `unlock_free_result` (not `unlock_free`) before `ctx->sgl` is populated. Free `sock_kmalloc()` buffers with `sock_k{,z}free_s()` using exact sizes (`MAX_SGL_ENTS + 1` for `af_alg_tsgl`), and skip `sock_kfree_s()` when `rsgl == &areq->first_rsgl` and `kvfree()` when `sgl->sgt.sgl == sgl->sgl`. [F8, F11, F14, F16, F124, F125, F167]

## API Contracts

- Registration & types: `crypto_check_alg()` requires non-empty names, `cra_priority >= 0`, power-of-two `cra_alignmask + 1`, and `cra_alignmask`/`cra_blocksize` within `MAX_ALGAPI_*`/`MAX_CIPHER_*`. `CRYPTO_ALG_DUP_FIRST` requires non-NULL `alg->cra_type` and `alg` not embedded in a driver struct. Guard `.report` in `struct crypto_type` with `#if IS_ENABLED(CONFIG_CRYPTO_USER)`, keep `MODULE_SOFTDEP("pre: cryptomgr")` in `crypto/algapi.c`, and set `inst->free` before `{aead,ahash,akcipher}_register_instance()`. `crypto_attr_alg_name()` returns `ERR_PTR` on bad `rtattr`, which `crypto_grab_spawn()` accepts directly. [F44, F114, F153, F157, F158, F159]
- `ahash`, `aead` & `akcipher`: `ahash_prepare_alg()` requires non-zero `halg.statesize`, `cra_reqsize == 0 || cra_reqsize >= halg.statesize` (`<= MAX_SYNC_HASH_REQSIZE` if sync), and non-NULL `finup` when `CRYPTO_AHASH_ALG_BLOCK_ONLY` is set (whose `update` returns non-negative residual bytes or `< 0` errno). Store `crypto_hash_walk_{first,done}()` returns in signed `int` and pass errors to `crypto_hash_walk_done()` to unmap. `aead_prepare_alg()` requires `maxauthsize`, `ivsize`, and `chunksize` `<= PAGE_SIZE / 8`, and `crypto_aead_decrypt()` rejects `req->cryptlen < crypto_aead_authsize(aead)`. `crypto_register_akcipher()` defaults NULL `encrypt`, `decrypt`, and `set_priv_key` to `-ENOSYS` stubs, and `crypto_akcipher_sync_decrypt()` returns positive `data.dlen` on success. [F39, F40, F52, F80, F155, F160, F161]
- Cmsgs, keys & AEGIS: `af_alg_cmsg_send()` must validate `cmsg_len` before and after reading `con->iv->ivlen`, and `af_alg_sendmsg()` requires `con.iv->ivlen == ivsize`; `alg_proto` must not set `.memory_allocated` without `.sysctl_mem`. `crypto_authenc_extractkeys()` requires `RTA_OK(rta, keylen)`, exact `RTA_PAYLOAD(rta) == sizeof(*param)`, `be32_to_cpu(param->enckeylen)`, and `keylen - rta->rta_len >= keys->enckeylen`. `blowfish_setkey()` callers must guarantee `keylen != 0`. `crypto_aegis128_*_simd()` must take `struct aegis_state *state` from `crypto/aegis.h`, and `crypto_aegis128_module_init()` must register generic before SIMD, enable `have_simd` after, and unregister generic on SIMD failure. [F78, F79, F109, F127, F130, F156]

## Error Handling

- `crypto_drop_spawn()` must return if `!spawn->alg` and only call `crypto_mod_put(spawn->alg)` when `!spawn->registered`. `acomp_do_req_chain()` must call `acomp_save_req()` unconditionally before `acomp_do_one_req()`. `ahash_do_req_chain()` must check `statesize <= HASH_MAX_STATESIZE`, `crypto_ahash_need_fallback(tfm)`, and `!crypto_hash_no_export_core(tfm)` before using `crypto_ahash_fb(tfm)`, and restore `ahash_request_set_tfm(req, tfm)`. In `{aead,skcipher}_recvmsg()` loops, `err <= 0` from `_{aead,skcipher}_recvmsg()` must overwrite `ret` only when `!ret`, `err == -EIOCBQUEUED`, or `err == -EBADMSG`. [F34, F37, F45, F95]

## External Contracts

- In `af_alg_sendmsg()`, when `ctx->init && !ctx->more`, return `-EINVAL` only if `ctx->used` is non-zero (otherwise log with `pr_info_once()`). In `hash_sendmsg()`, when `!msg_data_left(msg)` on entry, return 0 if `!ctx->more`, or allocate `ctx->result` and call `crypto_ahash_final(&ctx->req)` if `ctx->more && !(msg->msg_flags & MSG_MORE)`. `alg_setkey_by_key_serial()` must use `lookup_user_key(serial, 0, KEY_NEED_SEARCH)` and read under `down_read(&key->sem)`, allowing only `"user"`, `"logon"`, `"encrypted"`, or `"trusted"` keys (`-ENOPROTOOPT` otherwise). In `algif_rng.c`, `_rng_recvmsg()` clamps `len` to `MAXSIZE` (128), while `rng_test_sendmsg()` and `rng_setentropy()` reject `len > MAXSIZE` (`-EMSGSIZE`), and `rng_setentropy()` requires `capable(CAP_SYS_ADMIN)`, `!pctx->entropy` (`-EINVAL`), and saves `pctx->entropy` for `kfree_sensitive()`. [F76, F88, F94, F168, F169, F173]

## Known Pitfalls

- Normalize `sg->offset` with `offset_in_page()` before `PAGE_SIZE - offset` in `hash_walk_new_entry()` and `shash_ahash_digest()`. `crypto_acomp_{compress,decompress}()` must `return` after `tfm->{compress,decompress}(req)` on the direct branch, and `ahash_def_finup_finish1()` must call `crypto_ahash_alg(tfm)->final(req)` directly. `crypto_akcipher_sync_prep()` must set `mlen = max(slen, dlen)` and check `sizeof(*req) + reqsize + mlen < mlen` for overflow. [F73, F85, F92, F93]
- `_aead_recvmsg()` must check `aead_sufficient_data()` and `used >= outlen - usedpages` before subtracting from `used`, and `hash_sendmsg()` must use `DIV_ROUND_UP(sk->sk_sndbuf, PAGE_SIZE)` for `max_pages`. `crypto_inc()` requires 4-byte alignment (or `CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS`) for its `__be32` loop and must fall through to `crypto_inc_byte()` on wrap. In AEGIS-128, widen `assoclen` and `cryptlen` to `u64` before `* 8` in `crypto_aegis128_final{,_neon}()`, and call `preload_sbox()` before `aegis128_update_neon()` inside the same NEON section in `aegis128-neon-inner.c`. [F81, F87, F108, F111, F152]
