# ARM/Rockchip SoC support — drivers/clk/rockchip

Core Rockchip SoC infrastructure covering Clock and Reset Units (CRU) for RK3528, RK3562, RK3568, RK3576, RK3588, RV1108, and RV1126, the Rockchip clocksource/clockevent timer, the DDR Frequency Interface (DFI) devfreq-event and perf PMU monitor, and the GPIO/IRQ bank controller.

## Architecture & Data Flow

- `rockchip_clk_init_base()` initializes all `ctx->clk_data.clks` slots to `ERR_PTR(-EPROBE_DEFER)` (via `rockchip_clk_init_early()`) or `ERR_PTR(-ENOENT)` (via `rockchip_clk_init()` and `rockchip_clk_finalize()`), so `rockchip_clk_get_lookup()` returns an `ERR_PTR` rather than `NULL` for unregistered clock IDs. Broken by: checking `rockchip_clk_get_lookup()` or `ctx->clk_data.clks[id]` for `NULL` instead of `IS_ERR()`. [F27]
- `rockchip_clk_register_branches()` must reset both `clk = NULL` and `flags = list->flags` at the start of each loop iteration so `CLK_SET_RATE_PARENT` from gate cases does not leak across iterations, and it unconditionally writes `ctx->clk_data.clks[list->id] = clk` via `rockchip_clk_set_lookup()` even when `list->id == 0`, so clock ID `0` is overwritten by every unexported clock and must never be used as a DT clock ID or `linked_clk_id`. [F59, F71]
- For any `branch_fraction_divider` clock with a `child` mux (`COMPOSITE_FRACMUX` or `COMPOSITE_FRACMUX_NOGATE`), `child->branch_type` must be `branch_mux` and `child->parent_names` must contain the exact `name` of the fractional divider clock so `match_string()` can wire up `rockchip_clk_frac_notifier_cb()`. [F53]
- Every `struct rockchip_pll_rate_table` array (`rk3568_pll_rates`, `rk3576_pll_rates`, `rk3588_pll_rates`, `rv1108_pll_rates`, `rv1126_pll_rates`) must be sorted in descending `.rate` order, terminated by a zeroed `{ /* sentinel */ }` entry with `.rate = 0`, and have divider fields (`_refdiv`, `_fbdiv`, `_postdiv1`, `_postdiv2`, or `_p`, `_m`, `_s`, `_k` in `RK3036_PLL_RATE`/`RK3588_PLL_RATE`) that arithmetically evaluate to `.rate` from the 24 MHz oscillator. [F55, F60]
- Because `rockchip_softrst_assert()` and `rockchip_softrst_deassert()` compute register byte offsets as `(id / 16) * 4` when `ROCKCHIP_SOFTRST_HIWORD_MASK` is set, LUT macros in `rst-rk3562.c`, `rst-rk3576.c`, and `rst-rk3588.c` must scale any 4-byte-aligned sub-CRU byte offset `B` by `4` (`B * 4 + reg * 16 + bit`) with `bit < 16`. [F63]
- In `drivers/clocksource/timer-rockchip.c`, `rk_timer_disable(timer)` must be called before `rk_timer_update_counter()` writes `TIMER_LOAD_COUNT0`/`TIMER_LOAD_COUNT1` when reconfiguring a running timer in `rk_timer_set_next_event()` or `rk_timer_set_periodic()`, followed by `rk_timer_enable()`. [F56]
- In `rk_timer_sched_read()`, the 32-bit down-counting `TIMER_CURRENT_VALUE0` register must be bitwise-negated as a 32-bit `u32` (`~readl_relaxed(...)`) before widening to `u64` so `sched_clock` receives a monotonically increasing 32-bit counter. [F90]
- In `struct rockchip_dfi`, `dfi->clk` must be either a valid `struct clk *` (as on RK3399) or `NULL` (as on RK3568/RK3588), never an `ERR_PTR`, because `rockchip_dfi_enable()` and `rockchip_dfi_disable()` pass it directly to `clk_prepare_enable()` and `clk_disable_unprepare()`. [F35]
- In `rk3568_dfi_init()` and `rk3588_dfi_init()`, the upper two bits of `dfi->ddr_type` from `PMUGRF_OS_REG3` (`DRAMTYPE_INFO_V3 << 3`) must only be ORed into `dfi->ddr_type` when `FIELD_GET(..._SYSREG_VERSION, reg3) >= 0x3`, and every `dfi->ddr_type` accepted by `rockchip_dfi_ddrtype_to_ctrl()` must also be handled in `rockchip_ddr_perf_init()`'s `switch (dfi->ddr_type)` to set a non-zero `dfi->burst_len`. [F78, F107]
- In `struct rockchip_dfi`, `dfi->max_channels` must not exceed `DMC_MAX_CHANNELS` (`4`), and per-channel MMIO loops must skip any channel `i` where `!(dfi->channel_mask & BIT(i))` because `dfi->channel_mask` can be sparse across `[0, dfi->max_channels)`. [F65]
- In `rockchip_ddr_perf_counters_add()` and `rockchip_dfi_get_event()`, the difference between two 64-bit `struct dmc_count_channel` fields (`now - last`) must be truncated to `u32` before widening back to 64-bit or comparing, because `rockchip_dfi_read_counters()` populates those `u64` fields from 32-bit wrapping MMIO counters. [F84]
- When `dfi->active_events` transitions from 0 to 1 in `rockchip_ddr_perf_event_add()`, `dfi->total_count` must be zeroed and `dfi->last_perf_count` sampled from hardware before starting `dfi->timer` and calling `rockchip_ddr_perf_event_start()`, and `dfi->timer` must be canceled when `dfi->active_events` reaches 0 in `rockchip_ddr_perf_event_del()`. [F48]
- `rockchip_ddr_perf_event_update()` rejects any perf event with `event->attr.config >= PERF_ACCESS_TYPE_MAX`, so every `PERF_EVENT_*` code handled in `rockchip_ddr_perf_event_get_count()` must be strictly less than `PERF_ACCESS_TYPE_MAX`. [F64]
- In `ddr_perf_offline_cpu()`, when migrating the PMU away from an offlining CPU (`cpu == dfi->cpu`), `dfi->cpu` must be updated to `target` in lockstep with `perf_pmu_migrate_context(&dfi->pmu, cpu, target)`. [F50]
- In `rockchip_interrupts_register()`, all 32 GPIO interrupt lines must be masked in `int_mask`, cleared in `port_eoi`, enabled in `int_en`, and reflected in `gc->mask_cache = 0xffffffff` before `irq_set_chained_handler_and_data()` installs `rockchip_irq_demux()`. [F100]
- In `rockchip_irq_set_type()`, changing an interrupt trigger type away from `IRQ_TYPE_EDGE_BOTH` must clear `BIT(d->hwirq)` in `bank->gpio_regs->int_bothedge` on `GPIO_TYPE_V2` and clear `BIT(d->hwirq)` in `bank->toggle_edge_mode` on `GPIO_TYPE_V1` before writing `int_type` and `int_polarity`; on `GPIO_TYPE_V1` with `bank->toggle_edge_mode` set, `rockchip_irq_set_type()` and `rockchip_irq_demux()` must keep `int_polarity` inverted relative to `ext_port`, with `rockchip_irq_demux()` re-reading `ext_port` in a loop until the pin level stops changing. [F42, F43]
- In `rockchip_gpio_set_debounce()`, when `bank->gpio_type == GPIO_TYPE_V2` and `!IS_ERR(bank->db_clk)`, `debounce` must be validated against `max_debounce = (GENMASK(23, 0) + 1) * 2 * 1000000 / freq` before computing `div_reg` so that `div_reg` fits within the 24-bit `dbclk_div_con` register. [F68]

## Synchronization

- In `rockchip_softrst_assert()` and `rockchip_softrst_deassert()`, when `ROCKCHIP_SOFTRST_HIWORD_MASK` is not set in `softrst->flags`, the 32-bit read-modify-write on `softrst->reg_base + (bank * 4)` must be serialized under `spin_lock_irqsave(&softrst->lock, flags)`. [F112]
- In `rk_timer_interrupt()`, when `clockevent_state_oneshot(ce)` is true, `rk_timer_disable(timer)` must be called before invoking `ce->event_handler(ce)`. [F123]
- In `drivers/devfreq/event/rockchip-dfi.c`, `dfi->total_count` and `dfi->last_perf_count` must be updated together under `write_seqlock(&dfi->count_seqlock)` in `rockchip_dfi_timer()` and read together inside a `read_seqbegin(&dfi->count_seqlock)` / `read_seqretry(&dfi->count_seqlock, seq)` loop in `rockchip_ddr_perf_event_get_count()`. [F47]
- In `drivers/gpio/gpio-rockchip.c`, `bank->slock` (`raw_spinlock_t`) protects GPIO register and `bank->toggle_edge_mode` updates across process context and hardirq/`irq_chip` callbacks, and must never be held across sleeping pinctrl or clock calls such as `pinctrl_gpio_direction_input()`/`output()` or `clk_prepare_enable()`/`clk_disable_unprepare()`. [F18]

## Object Lifetimes

- Every `GATE_LINK` clock's `linked_clk_id` must already be populated in `ctx->clk_data.clks` before `rockchip_clk_register_late_branches()` processes that entry (because `rk_clk_gate_link_probe()` immediately looks up `linked_clk_id` via `rockchip_clk_get_lookup()` and passes it to `pm_clk_add_clk()`), and late branch arrays (such as `rk3588_clk_branches`) and their `parent_names` must not be marked `__initdata` or `__initconst` (`PNAME()`) because `rockchip_clk_register_gate_link()` retains branch pointers in platform data. [F4, F110]
- In `rockchip_ddr_perf_init()`, `dfi->count_seqlock`, cpuhp state and instance registration, `rockchip_dfi_enable()`, and `hrtimer_setup(&dfi->timer, ...)` must be initialized and devres-tracked before `perf_pmu_register()` publishes `&dfi->pmu`, so devm teardown unregisters the PMU before removing cpuhp and disabling DFI. [F16]
- In `rockchip_interrupts_register()`, if `irq_alloc_domain_generic_chips()` fails after `irq_domain_create_linear()` creates `bank->domain`, the error path must call `irq_domain_remove(bank->domain)`. [F12]
- Every `struct device_node *` acquired via `of_get_parent()` in `rockchip_gpiolib_register()` and `rockchip_gpio_probe()`, or via `of_parse_phandle()` in `rockchip_dfi_probe()`, must be released with `of_node_put()` immediately after passing it to `of_pinctrl_get()` or `syscon_node_to_regmap()`. [F109]

## API Contracts

- When a clock controller is initialized via `rockchip_clk_init_early()`, its platform driver probe must call `rockchip_clk_finalize(ctx)` and then `of_clk_del_provider(np)` followed by `rockchip_clk_of_add_provider(np, ctx)` after registering late branches. [F51]
- In `rk_clk_gate_link_probe()`, runtime PM and the PM clock list must be initialized via `devm_pm_runtime_enable(dev)`, `devm_pm_clk_create(dev)`, and `pm_clk_add_clk(dev, linked_clk)` before `rk_clk_gate_link_register()` registers the gate clock with `dev`, and `pm_clk_remove_clk(dev, linked_clk)` must be called if registration fails. [F115]
- `rockchip_clk_find_max_clk_id()` must assign `list->child->id` (not `list->id`) to `max` when `list->child && list->child->id > max`, and because it returns the highest inclusive clock `id` while `rockchip_clk_set_lookup()` indexes `ctx->clk_data.clks[id]` without bounds checking, callers sizing `nr_clks` from `rockchip_clk_find_max_clk_id()` must add `1`. [F58, F70]
- In `rockchip_fractional_approximation()`, `to_clk_fd(hw)->flags` must have `CLK_FRAC_DIVIDER_POWER_OF_TWO_PS` set before calling `clk_fractional_divider_general_approximation()`, and `*parent_rate` is replaced with the grandparent clock rate when `rate * 20 > p_rate` and `p_rate % rate != 0`. [F125]
- In `rockchip_register_softrst_lut()`, when `lookup_table` is non-NULL, `num_regs` sets `softrst->rcdev.nr_resets` directly and must equal `ARRAY_SIZE(lookup_table)`, and every `lookup_table[id]` entry must be non-negative because `rockchip_softrst_assert()` and `rockchip_softrst_deassert()` assign it to `unsigned long id` before division. [F62]
- In `drivers/clocksource/timer-rockchip.c`, `rk_timer_sched_read()` must remain marked `notrace` and perform only lockless MMIO reads (`readl_relaxed()`), and `rk_clkevt` (allocated as `struct rk_clkevt` embedding `ce` and `timer`, unlike standalone `struct rk_timer *rk_clksrc`) must pass `&rk_clkevt->ce` as `dev_id` to `request_irq()` for `rk_timer_interrupt()` and `rk_timer()`. [F98, F122]
- In `rockchip_dfi_get_event()`, devfreq-event load reporting selects only the single active channel in `dfi->channel_mask` with the largest access delta since `dfi->last_event_count` and sets `edata->load_count = access * 4` and `edata->total_count = clock_cycles`. [F131]
- `rockchip_gpio_readl_bit()` shifts right by the bit index and masks with `0x1` to return `0` or `1`, and both `rockchip_gpio_readl_bit()` and `rockchip_gpio_writel_bit()` take a `0..31` pin index (`bit`) rather than `BIT(offset)`. [F38]
- In `drivers/gpio/gpio-rockchip.c`, `rockchip_interrupts_register()` sets `gc->private = bank` on generic IRQ chips, so every `irq_chip` callback on `bank->domain` must obtain `struct irq_chip_generic *` via `irq_data_get_irq_chip_data(d)` and read `gc->private` to get `struct rockchip_pin_bank *`. [F97]

## Error Handling

- In `rk_timer_probe()`, `irq_of_parse_and_map()` returns `0` on failure after `clk_prepare_enable(timer_clk)` has set `ret = 0`, so the `!irq` failure branch must explicitly set `ret = -EINVAL` before jumping to `out_irq`. [F33]
- `rockchip_dfi_probe()` must fail if the `"rockchip,pmu"` phandle or its syscon regmap is missing, must initialize `dfi->regmap_pmu` before calling `soc_init(dfi)` (which unconditionally reads `dfi->regmap_pmu`), and must register `dfi->edev` via `devm_devfreq_event_add_edev()` before calling `rockchip_ddr_perf_init(dfi)` or `rockchip_dfi_enable(dfi)` (which dereference `&dfi->edev->dev` for logging). [F34, F36]
- In `rockchip_ddr_perf_init()`, `cpuhp_setup_state_multi(CPUHP_AP_ONLINE_DYN, ...)` returns a positive dynamic state ID on success and a negative errno on failure, so its return value must be stored in a signed `int` and checked with `ret < 0` before assigning to `dfi->cpuhp_state`. [F37]
- Because `bank->db_clk` is `NULL` on `GPIO_TYPE_V1` banks (where `!IS_ERR(NULL)` is true) and `gpio_regs_v1` leaves `dbclk_div_en` and `dbclk_div_con` as `0` (aliasing `port_dr`), any code using `bank->db_clk` or dbclk divider registers must check `bank->gpio_type == GPIO_TYPE_V2` in addition to `!IS_ERR(bank->db_clk)`. [F39]

## External Contracts

- In `rockchip_ddr_perf_event_get_count()`, byte-counting perf events must return raw byte counts (`accesses * dfi->burst_len * dfi->buswidth[i]`) to match the `DFI_PMU_EVENT_ATTR` sysfs scale factor of `9.536743164e-07` (`2^-20`) and unit `"MB"`, while `PERF_EVENT_CYCLES` multiplies channel 0 `clock_cycles` by `dfi->count_multiplier`. [F133]

## Known Pitfalls

- In `struct rockchip_clk_branch`, `rockchip_clk_register_branch()` and `rockchip_clk_register_frac_branch()` treat `gate_offset < 0` (`-1`) as "no gate" (`0` is a valid offset), whereas `rockchip_clk_register_factor_branch()` treats `gate_offset == 0` as "no gate" and any non-zero value (including `-1`) as a gate offset. [F61]
- In `drivers/clk/rockchip/clk.h`, `HIWORD_UPDATE(val, mask, shift)` does not mask `val` with `mask` before shifting, so callers must ensure `0 <= val <= mask` (in particular, 1-based divider arguments to macros like `RK3576_BIGCORE_CLKSEL2` or `RK3588_CORE_L_SEL2` that pass `_div - 1` must be `>= 1`) and `shift + fls(mask) <= 16`. [F87]
- In `drivers/devfreq/event/rockchip-dfi.c`, platform and devfreq-event drvdata store `struct rockchip_dfi *`, whereas `perf_pmu_register()` sets the PMU sysfs device's drvdata to `struct pmu *`, so PMU sysfs attribute callbacks like `ddr_perf_cpumask_show()` must use `container_of(dev_get_drvdata(dev), struct rockchip_dfi, pmu)`. [F96]
- On `GPIO_TYPE_V2` banks, per-pin control registers (`gpio_regs_v2`) split pins `0..15` (`reg`) and `16..31` (`reg + 0x4`) with HIWORD write masks and require `rockchip_gpio_writel*()`/`rockchip_gpio_readl*()`, whereas `ext_port`, `int_status`, and `dbclk_div_con` are single 32-bit registers accessed via plain `readl()`/`writel()`. [F67]
- In `rockchip_irq_set_type()`, `type & IRQ_TYPE_EDGE_BOTH` selects `handle_edge_irq` for any edge trigger, whereas `type == IRQ_TYPE_EDGE_BOTH` must be checked with exact equality before the `else` branch's `switch (type)` handles single-edge (`IRQ_TYPE_EDGE_RISING`, `IRQ_TYPE_EDGE_FALLING`) and level triggers. [F79]
- In `rockchip_gpio_find_bank()`, the loop `for (i = 0; i < info->ctrl->nr_banks; i++, bank++)` advances `bank` one past `info->ctrl->pin_banks` when no match is found, so the return value must be gated on `found` (`return found ? bank : NULL;`). [F81]
- In `rockchip_gpio_set_debounce()`, dividing the 64-bit product `div = debounce * freq` must use `DIV_ROUND_CLOSEST_ULL(div, 2 * USEC_PER_SEC)` rather than `/` because `gpio-rockchip.c` builds on 32-bit ARM, and in `rockchip_irq_demux()`, the 32-bit interrupt status from `readl_relaxed()` must be stored in an `unsigned long pending` variable before passing `&pending` to `for_each_set_bit(irq, &pending, 32)`. [F89, F99]
