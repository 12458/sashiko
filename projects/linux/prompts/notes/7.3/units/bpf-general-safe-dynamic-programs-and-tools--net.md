# BPF [GENERAL] (Safe Dynamic Programs and Tools) — net

This unit implements the networking BPF subsystem, cBPF-to-eBPF conversion, networking helpers/kfuncs, XDP redirect/flush (`net/core/filter.c`), `BPF_PROG_TEST_RUN` (`net/bpf/test_run.c`), and dummy `bpf_struct_ops` tests (`net/bpf/bpf_dummy_struct_ops.c`).

## Architecture & Data Flow

- Every `is_valid_access` in `net/core/filter.c` must reject `off % size != 0`. Where default branches allow 32-bit/narrow reads (`bpf_skb`, `bpf_sock`, `sock_ops`), 64-bit fields must use `bpf_ctx_range*()` and struct padding ranges must explicitly return `false`. In `sock_addr`, `sk_msg`, `flow_dissector`, `sk_reuseport`, and `sk_lookup` validators, `switch (off)` must list every valid field with `default: return false`. Loads of 32-bit UAPI packet pointers (`data`, `data_end`, `data_meta`) must reject `info->is_ldsx`. [F278, F301, F302, F303, F315]
- When `sock_addr_convert_ctx_access()`, `sock_ops_convert_ctx_access()`, or `bpf_convert_data_end_access()` borrows a temp register, it must pick one distinct from `si->src_reg`/`si->dst_reg`, spill it to context scratch (`tmp_reg`/`temp`), and restore it on every branch. [F272]
- Every `sk_buff` helper for TC, LWT, or `CGROUP_SKB` that reallocates, linearizes, or shifts `skb->data`/`skb->len` (`bpf_try_make_writable`, `bpf_skb_adjust_room`, `bpf_skb_change_tail`, `bpf_skb_change_head`) must call `bpf_compute_data_pointers(skb)`. In `sk_skb_adjust_room()`, if `tls_sw_has_ctx_rx(skb->sk)`, `strp_msg(skb)->full_len` must be adjusted by `len_diff`. [F257, F271]
- In `bpf_skb_net_grow()`, when `encap` is true, `network_header`, `mac_header`, and `transport_header` must be sampled before `bpf_skb_net_hdr_push()` for `skb->inner_*_header`. On GSO packets (`skb_is_gso(skb)`), `bpf_skb_net_grow()`/`shrink()` must set `SKB_GSO_DODGY`, reset `gso_segs = 0`, and adjust `gso_size` unless `BPF_F_ADJ_ROOM_FIXED_GSO` is set (linearizing `skb` on grow if `frag_list` is present). [F264, F265]
- `bpf_lwt_seg6_store_bytes()` and `bpf_lwt_seg6_adjust_srh()` must set `srh_state->valid = false` when modifying SRH TLVs (and `adjust_srh` must update `srh_state->hdrlen += len` and `ipv6hdr->payload_len`). In `bpf_l4_csum_replace()`, when `(flags & BPF_F_HDR_FIELD_MASK) == 0`, `BPF_F_IPV6` must be accepted and passed as `is_ipv6` to `inet_proto_csum_replace_by_diff()`. [F263, F364]
- Every `sk_msg` sg-mutating helper (`bpf_msg_pull_data`, `bpf_msg_push_data`, `bpf_msg_pop_data`) must call `sk_msg_reset_curr(msg)` and recompute `msg->data`/`data_end`. When `msg->sg.size > 0`, `sk_msg_reset_curr()` sets `msg->sg.curr` to the element before `msg->sg.end` and `msg->sg.copybreak` to its `length` (not `0`). In `bpf_msg_push_data()`, `start == offset + l` is valid; if `i == msg->sg.end`, step `i` back via `sk_msg_iter_var_prev(i)`. [F258, F259, F280]
- `bpf_xdp_adjust_head()`/`meta()` must keep `xdp->data_meta >= xdp->data_hard_start + sizeof(struct xdp_frame)`, `xdp->data` in `[xdp_frame_end + metalen, xdp->data_end - ETH_HLEN]`, and `!xdp_metalen_invalid(metalen)`. `bpf_xdp_frags_shrink_tail()` must check `offset` against `(int)xdp_get_buff_len(xdp) - ETH_HLEN`, iterate backward with signed `int i`, and if `!sinfo->nr_frags`, subtract residual `offset` from `xdp->data_end` after clearing frags flags. For `MEM_TYPE_XSK_BUFF_POOL`, `bpf_xdp_frags_increase_tail()` and `bpf_xdp_shrink_data()` must also update the companion AF_XDP `xdp_buff` node (`xsk_buff_get_tail`/`head`). [F268, F289, F291]
- `bpf_redirect_info::map_id` uses `0` (no map), `[1, INT_MAX)` (IDR ID), or `INT_MAX` with `BPF_MAP_TYPE_UNSPEC` (`ifindex` XDP redirect). `BPF_F_REDIRECT_INTERNAL` (`BPF_F_NEIGH`, `BPF_F_PEER`, `BPF_F_NEXTHOP`) must not overlap `BPF_F_REDIRECT_FLAGS`, and `bpf_redirect()`/`bpf_clone_redirect()` must reject `flags & (~(BPF_F_INGRESS) | BPF_F_REDIRECT_INTERNAL)`. [F300, F305]
- In `bpf_sock_ops_get_syn()`, when `!bpf_sock->syn_skb`, `sk->sk_state == TCP_NEW_SYN_RECV` selects `inet_reqsk(sk)->saved_syn` vs `tcp_sk(sk)->saved_syn`. In `bpf_search_tcp_opt()`, `TCPOPT_EOL` terminates, `TCPOPT_NOP` advances by 1, and other kinds must reject `opend - op < 2 || opend - op < op[1] || op[1] < 2`. `bpf_sock_addr_set_sun_path()` must reject `sun_path__sz == 0 || sun_path__sz > UNIX_PATH_MAX`. [F242, F299, F311]
- `bpf_check_classic()` must verify opcodes, `BPF_DIV`/`BPF_MOD` `k != 0`, shifts `k < 32`, `BPF_MEM` `k < BPF_MEMWORDS` (`<= 16`), forward jumps `< flen`, and `filter[flen - 1]` is `BPF_RET` before `check_load_and_stores()`. In `check_load_and_stores()`, after `masks[pc + 1 + ...] &= memvalid`, reset `memvalid = ~0`. Because loads follow dominating stores, `bpf_convert_filter()` only updates `stack_depth` on `BPF_ST`/`STX`. [F285, F286, F307, F318, F320]
- In `bpf_convert_filter()`: prologue copies `ARG1` to `R6` (`CTX`) and, if `*seen_ld_abs`, caches `skb->data` in `R8` and `skb->len - skb->data_len` in `R9`; `BPF_DIV`/`MOD | BPF_X` zero-extends `R_X` and checks `!= 0`; 32-bit offsets must fit `s16` (`BPF_ADD` for loads or `-EINVAL` for jumps); `do_pass` retries must keep sizing/emission counts equal (`BUG_ON(*new_len != new_flen)`); and `memcpy()` into `new_insn` scales `insn - tmp_insns` by `sizeof(*insn)`. `bpf_skb_load_helper_16`/`32()` must convert negative offsets, use `get_unaligned_be16`/`32()`, and convert `skb_copy_bits()` with `be16`/`32_to_cpu()`. [F288, F308, F317, F319, F324, F357]
- With `BPF_F_TEST_XDP_LIVE_FRAMES`, `bpf_prog_test_run_xdp()` adds `sizeof(struct xdp_page_head)` to headroom and `xdp_test_run_init_page()` caps frame size at `PAGE_SIZE - sizeof(struct xdp_page_head)`. `bpf_test_run_xdp_live()` resets `xdp.frame_cnt = 0` per batch and passes it to `bpf_test_timer_continue()`. In `xdp_test_run_batch()`, if `ctx_was_changed(head)`, call `xdp_update_frame_from_buff(ctx, frm)` before redirect/`XDP_PASS`, and `reset_ctx()` must restore `head->frame->mem_type = head->orig_ctx.rxq->mem.type`. [F260, F261, F309, F325]

## Synchronization

- `tc_cls_act_btf_struct_access()` and `xdp_btf_struct_access()` must hold `nf_conn_btf_access_lock` across testing and calling `nfct_btf_struct_access`. `sock_ops` helpers mutating/reading socket state (`setsockopt`, `getsockopt`, `cb_flags_set`, `load_hdr_opt`) must return `-EOPNOTSUPP` when `!is_locked_tcp_sock_ops(bpf_sock)`. [F225, F227]
- `bpf_out_neigh_v4`/`v6()` must release `rcu_read_lock()` with matching `rcu_read_unlock()` on all paths and wrap `neigh_output()` in `local_bh_disable()`/`enable()` with `dev_xmit_recursion_inc()`/`dec()`. `bpf_lwt_seg6_*()` require per-CPU `srh_state->bh_lock`. [F342, F351]
- `bpf_test_run()` and `xdp_test_run_batch()` must wrap execution/redirects in `local_bh_disable()` and `bpf_net_ctx_set()`, clearing both before `bpf_test_timer_continue()`. `bpf_prog_test_run_raw_tp()` must hold `get_cpu()` across `cpu_online(cpu)` and IPI/execution, while `bpf_prog_test_run_syscall()` must use `rcu_read_lock_trace()`/`unlock_trace()`. [F344, F354]

## Object Lifetimes

- `__sk_attach_prog()`, `sk_detach_filter()`, and `sk_get_filter()` require the socket lock; `sk_filter_trim_cap()` uses `rcu_read_lock()`. `__sk_attach_prog()` charges `sk_omem_alloc` and `sysctl_optmem_max` via `__sk_filter_charge()` (uncharging old via `sk_filter_uncharge()`); `sk_reuseport_attach_bpf()` skips `sysctl_optmem_max`. `sk_filter_charge()` pins `fp` via `refcount_inc_not_zero(&fp->refcnt)` before charging and calls `sk_filter_release(fp)` on failure, which defers `__sk_filter_release()` via `call_rcu()`. [F221, F222, F347, F376]
- `__bpf_prog_release()` and `sk_reuseport_prog_free()` release eBPF programs (`SOCKET_FILTER`, `SK_REUSEPORT`) via `bpf_prog_put()` and cBPF programs (`UNSPEC`) via `bpf_release_orig_filter()` and `bpf_prog_free()`/`destroy()`. In `bpf_migrate_filter()`, if `bpf_prog_realloc(old_fp, ...)` returns NULL, reset `fp = old_fp` before `goto out_err_free`. [F206, F208]
- In `sk_lookup()`, `__bpf_sk_lookup()`, and `bpf_sk_lookup()`, any unreferenced returned socket must have `SOCK_RCU_FREE` set or return `NULL`. `bpf_sk_assign()` checks `!sk_unhashed(sk)` and, if `sk_is_refcounted(sk)`, pins via `refcount_inc_not_zero()` (`-ENOENT` on failure) before `skb_orphan()` and `skb->destructor = sock_pfree`. `bpf_sk_lookup_assign()` rejects `sk_is_refcounted(sk)` with `-ESOCKTNOSUPPORT`. `sk_select_reuseport()` error paths after `map_lookup_elem()` must call `sock_put(selected_sk)` if `sk_is_refcounted(selected_sk)`. [F217, F218, F230, F231]
- Call `skb_dst_drop(skb)` before `skb_dst_set()`. In `bpf_clone_redirect()`, after `skb_clone()`, call `bpf_try_make_head_writable(skb)` and `kfree_skb(clone)` on failure. `sol_tcp_sockopt_congestion()` rejects `tp->bpf_chg_cc_inprogress != 0` with `-EBUSY` and brackets `do_tcp_setsockopt()` with `1`/`0`. [F209, F210, F214]
- `bpf_msg_push`/`pop_data()` must pair sg splits/removals with `get_page()`/`put_page()` and update `msg->sg.size` and `sk_mem_charge`/`uncharge()`. Shrinking XDP frags (`bpf_xdp_frags_shrink_tail`, `bpf_xdp_pull_data`) must free consumed frags via `bpf_xdp_shrink_data()`, decrement `nr_frags`, and if 0, clear frags/pfmemalloc flags. `__xdp_do_redirect_frame()` and `xdp_do_generic_redirect()` must reset `ri->map_id`, `flags`, and `map_type` on entry, and clear `WRITE_ONCE(ri->map, NULL)` on broadcast. [F211, F212, F213]
- In `xdp_test_run_batch()`, failed frame update/redirect, `XDP_DROP`, or invalid action must call `xdp_return_buff(ctx)`, and `XDP_TX`/`REDIRECT` requires `xdp_do_flush()` before `bpf_net_ctx_clear()`. In `bpf_prog_test_run_xdp()`, after `xdp_convert_md_to_buff()`, all exit paths must call `xdp_convert_buff_to_md()` to `dev_put(xdp->rxq->dev)`. `bpf_prog_test_run_skb()` must guard `dev_put(dev)` with `if (dev && dev != net->loopback_dev)`. Pair `bpf_set_run_ctx()` with `bpf_reset_run_ctx()`. [F198, F199, F201, F340]

## API Contracts

- `bpf_prepare_filter()` and `bpf_migrate_filter()` free `fp` on error; callers must not free `fp` on `IS_ERR(fp)`. Read-modify-write helper args (`mtu_len` in `check_mtu`, `search_res` in `load_hdr_opt`) must use `MEM_WRITE` without `MEM_UNINIT`. Verifier capability checks (`cg_skb_is_valid_access`, `bpf_sk_base_func_proto`) must use `bpf_token_capable(prog->aux->token, ...)`. [F205, F250, F375]
- `bpf_xdp_pointer()` rejects `offset > 0xffff || len > 0xffff` (`-EFAULT`) and `offset + len > xdp_get_buff_len(xdp)` (`-EINVAL`), returning `NULL` across frag boundaries for `bpf_xdp_copy_buf()` fallback. `bpf_tcp_*gen_syncookie*()` require `th_len >= sizeof(*th)` and `th_len == th->doff * 4`, returning `cookie | ((u64)mss << 32)`. `__bpf_skc_lookup()` requires `len == sizeof(tuple->ipv4)` or `sizeof(tuple->ipv6)` and `(s32)netns_id < 0` or `netns_id <= S32_MAX`. [F255, F256, F290]
- Drivers using `xdp_do_redirect*()` must call `xdp_do_flush()` before `napi_complete_done()` and `local_bh_enable()`. In `xdp_master_redirect()`, when `slave != xdp->rxq->dev`, set `ri->tgt_index = slave->ifindex`, `ri->map_id = INT_MAX`, `ri->map_type = BPF_MAP_TYPE_UNSPEC`, and return `XDP_REDIRECT`. `lwt_seg6local_prog_ops` must not set `.test_run = bpf_prog_test_run_skb`. [F336, F337, F367]
- Callers of `bpf_ctx_init()` must check both `IS_ERR(ctx)` and `ctx != NULL`. `bpf_test_timer_continue()` uses `do_div(t->time_spent, t->i)`, clamps to `U32_MAX`, and requires `repeat >= 1`. BTF destructor kfuncs in `test_run.c` take `void *` with `CFI_NOSEAL()`. In `bpf_dummy_struct_ops.c`, `args->args[0] == 0` is `NULL` state, `check_test_run_args()` rejects `0` for non-nullable pointers, `bpf_struct_ops_test_run()` calls `arch_protect_bpf_trampoline()`, `dummy_ops_call_op()` adds `cfi_get_offset()`, and `bpf_dummy_ops_check_member()` rejects `prog->sleepable` except on `test_sleepable`. [F243, F244, F321, F330, F355, F356]

## Error Handling

- In `bpf_test_run()`, reset failed `item.cgroup_storage[stype]` `ERR_PTR` to `NULL` before `bpf_cgroup_storage_free()`. `bpf_test_finish()` and `bpf_ctx_finish()` must still copy clamped data and unclamped `size` to user space on `-ENOSPC`. In `xdp_test_run_batch()`, `out:` must run `xdp_do_flush()` and `xdp_recv_frames()` even after `-ENOMEM`, only overwriting `err` if `xdp_recv_frames()` fails. [F200, F239, F247]
- `bpf_search_tcp_opt()` returns `ERR_PTR(-ENOMSG)` when absent (setting `*eol = true` on `TCPOPT_EOL`, mapped to `-ENOSPC` by `store_hdr_opt`) and `ERR_PTR(-EFAULT)` on malformed options. Setting IPv4 addresses in `bpf_skb_get_tunnel_key()` or `bpf_skb_get_xfrm_state()` must zero trailing `&remote_ipv6[1]`/`&local_ipv6[1]` (3 `__u32`s). Transmit recursion in `__bpf_tx_skb()` and `bpf_out_neigh_v4`/`v6()` checks `dev_xmit_recursion()`, logs via `net_crit_ratelimited`, and returns `-ENETDOWN`; invalid XDP actions use `bpf_warn_invalid_xdp_action()`. [F240, F251, F377]

## External Contracts

- `sk_get_filter()` returns `0` (no filter), `-EACCES` (`!orig_prog`), `-EINVAL` (`len && len < fprog->len`), or `fprog->len` (block count). `copy_bpf_fprog_from_user()` handles `in_compat_syscall()` (`compat_sock_fprog`, `memset`, `compat_ptr()`). `bpf_ctx_init()` checks `bpf_check_uarg_tail_zero()`, and `convert___skb_to_skb()`, `verify_user_bpf_flow_keys()`, and `bpf_prog_test_run_sk_lookup()` check `range_is_zero()` on padding/unsupported fields. [F238, F293, F371]
- When `size != sizeof(struct bpf_tunnel_key)`, `bpf_skb_get`/`set_tunnel_key()` only accept legacy prefix `offsetof` sizes via a stack `compat` buffer. In `__sk_buff`, `bpf_sock_ops`, and `sk_msg_md` ctx access, `remote_port` loads 16-bit `skc_dport` and shifts left by 16 on `!__BIG_ENDIAN_BITFIELD`, while `local_port` loads `skc_num` unshifted. `sk_lookup` ctx access allows 1/2/4-byte reads at `remote_port` (2-byte load of `sport`) and 2-byte zero-padding reads at `offsetofend(..., remote_port)` (`MOV32_IMM 0`). [F294, F295, F296]

## Known Pitfalls

- `tc_cls_act_is_valid_access()` must intercept `tstamp_type`, set `prog->tstamp_type_access = 1`, and return `size == sizeof(__u8)` before `bpf_skb_is_valid_access()`. Packet-writing helpers (`bpf_skb_store_bytes`, `bpf_l3`/`l4_csum_replace`, `bpf_lwt_seg6_*`) must refresh pointers derived from `skb->data` (including `srh_state->srh`) after `bpf_try_make_writable()`, `skb_cow_head()`, or header push/pop. [F304, F328]
- `bpf_msg_pop_data()` must not advance `i` after `sk_msg_shift_left(msg, i)` when `pop >= sge->length`. `bpf_xdp_copy_buf()` must check `if (!len || next_frag == end_frag) break;` before dereferencing `next_frag`. In `bpf_convert_filter()`, `BPF_JMP | BPF_K` with `(int)fp->k < 0` must zero-extend `fp->k` into `BPF_REG_TMP` (`BPF_MOV32_IMM`) and compare with `BPF_X`. `sol_tcp_sockopt_congestion()` requires `*optlen >= 2`, NUL-terminates `getsockopt` (`optval[--(*optlen)] = '\0'`), and bounds `setsockopt` with `strncmp(..., optval, *optlen)`. [F306, F310, F316, F334]
