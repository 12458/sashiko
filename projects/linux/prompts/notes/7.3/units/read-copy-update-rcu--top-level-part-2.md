# READ-COPY UPDATE (RCU) — (top level) (part 2)

This unit implements Tree RCU extensions (`tree_nocb.h`, `tree_plugin.h`, `tree_stall.h`), generic RCU update primitives and lockdep/debugobjects integration (`update.c`), and the Rust RCU read-side lock guard (`rust/kernel/sync/rcu.rs`).

## Architecture & Data Flow
- Manipulate NOCB GP state (`nocb_gp_lock`, `nocb_defer_wakeup`, `nocb_timer`, `nocb_gp_sleep`, `nocb_gp_wq`, `nocb_head_rdp`, `nocb_toggling_rdp`) only on the group leader `rdp->nocb_gp_rdp`, never on a non-leader `rdp`. When canceling `rdp_gp->nocb_timer` via `timer_delete()` in `__wake_nocb_gp()` or `nocb_gp_wait()`, reset `rdp_gp->nocb_defer_wakeup = RCU_NOCB_WAKE_NOT` under `rdp_gp->nocb_gp_lock`. [F54, F55]
- `rdp->cblist.len` counts both `rdp->cblist` and `rdp->nocb_bypass`, while `rdp->lazy_len` counts only lazy callbacks in `rdp->nocb_bypass`. Enqueuing a new callback in `rcu_nocb_try_bypass()` or `rcu_nocb_do_flush_bypass()` must call `rcu_segcblist_inc_len(&rdp->cblist)`, whereas flushing bypass into `rdp->cblist` must not re-add their count. `rcu_nocb_do_flush_bypass()` must enqueue a new lazy `rhp` onto `rdp->nocb_bypass` and set `rhp = NULL` before calling `rcu_cblist_flush_enqueue()` and resetting `rdp->lazy_len = 0`. [F56, F57]
- In `nocb_gp_wait()`, after scanning `my_rdp->nocb_head_rdp`, schedule `RCU_NOCB_WAKE_LAZY` only when `lazy && !bypass`; if `bypass` is true, schedule `RCU_NOCB_WAKE_BYPASS`. Index `rnp->nocb_gp_wq` in `rcu_nocb_gp_get()` and `nocb_gp_wait()` via `rcu_seq_ctr(...) & 0x1`. [F82, F94]
- In `rcu_preempt_ctxt_queue()`, insert `t->rcu_node_entry` after `rnp->exp_tasks` only when `blkd_state` has `RCU_EXP_TASKS`, and after `rnp->gp_tasks` only when `RCU_GP_TASKS`; then set `rnp->gp_tasks` or `rnp->exp_tasks` to `&t->rcu_node_entry` if NULL when `RCU_GP_BLKD` or `RCU_EXP_BLKD` is set. Before advancing `rnp->gp_seq` for a new GP, call `rcu_preempt_check_blocked_tasks()` under `rnp->lock` to verify `!rnp->gp_tasks` and set `rnp->gp_tasks = rnp->blkd_tasks.next` whenever `rcu_preempt_has_tasks(rnp) && (rnp->qsmaskinit || rnp->wait_blkd_tasks)`. [F62, F86]
- To iterate over tasks blocking the current normal GP in `rcu_print_detail_task_stall_rnp()` and `rcu_print_task_stall()`, hold `rnp->lock`, check `rcu_preempt_blocked_readers_cgp(rnp)`, seed `t = list_entry(rnp->gp_tasks->prev, struct task_struct, rcu_node_entry)`, and use `list_for_each_entry_continue()`. [F88]
- `rcu_cpu_stall_reset()` must set `rcu_state.nr_fqs_jiffies_stall = 3` and `rcu_state.jiffies_stall = ULONG_MAX`, and `record_gp_stall_check_time()` must reset `nr_fqs_jiffies_stall = 0`. When `check_cpu_stall()` advances `rcu_state.jiffies_stall` via `cmpxchg()`, the offset added to `jiffies` must not exceed `ULONG_MAX / 2`. [F63, F99]
- `rcu_gp_is_normal()` must return false during `RCU_SCHEDULER_INIT`, and `rcu_nocb_try_bypass()` must reject bypass queuing whenever `rcu_scheduler_active != RCU_SCHEDULER_RUNNING`. `rcu_async_hurry_nesting` and `rcu_expedited_nesting` start at `1` until `rcu_end_inkernel_boot()` calls `rcu_unexpedite_gp()` and `rcu_async_relax()`, and every `rcu_async_hurry()` / `rcu_expedite_gp()` call must pair 1-to-1 with `rcu_async_relax()` / `rcu_unexpedite_gp()`. [F16, F91]
- Both `#ifdef` and `#else` variants of `rcu_print_task_stall()` (`CONFIG_PREEMPT_RCU`), `rcu_initiate_boost()` (`CONFIG_RCU_BOOST`), and `rcu_nocb_unlock_irqrestore()` (`CONFIG_RCU_NOCB_CPU`) must release `rnp->lock` and/or restore `flags` identically. [F66]
- `rcu_init_nohz()` must mask `rcu_nocb_mask` with `cpu_possible_mask` via `cpumask_and()` before indexing per-CPU `rcu_data`. `rcu_organize_nocb_kthreads()` must compute `nl = DIV_ROUND_UP(rdp->cpu + 1, ls) * ls`. `rcu_bootup_announce_oddness()` must clamp `nohz_full_patience_delay` to `[0, 5 * MSEC_PER_SEC]` before `msecs_to_jiffies()`. Keep `gp_state_names[]` in `tree_stall.h` synced with `RCU_GP_IDLE`..`RCU_GP_CLEANED`. [F68, F71, F72, F96]

## Synchronization
- Calling `rcu_rdp_is_offloaded(rdp)` (and `rcu_nocb_lock`/`rcu_nocb_unlock`) requires holding `barrier_mutex`, CPU hotplug lock, `rdp->nocb_lock`, or `nocb_mutex`, or running on `rdp`'s CPU with preemption disabled or in softirq, or running on `rdp->nocb_cb_kthread` or `rdp->nocb_gp_kthread`. `rdp->nocb_bypass_lock` nests inside `rdp->nocb_lock`: `rcu_nocb_do_flush_bypass()` requires both held with hard IRQs disabled and unlocks `rdp->nocb_bypass_lock`. [F23, F117]
- Toggling NOCB offload must keep `SEGCBLIST_OFFLOADED` on `rdp->cblist`, `rdp->nocb_entry_rdp` in `rdp_gp->nocb_head_rdp` (both under `raw_spin_lock_irqsave(&rdp->nocb_lock, flags)` in `nocb_gp_toggle_rdp()`, `rcu_nocb_rdp_deoffload_wait_cond()`, and `rcu_nocb_rdp_offload_wait_cond()`), and `rcu_nocb_mask` (under `rcu_state.nocb_mutex`) synchronized. When `rdp_gp->nocb_gp_kthread` is non-NULL, only `nocb_gp_wait()` via `nocb_gp_toggle_rdp()` may modify `rdp_gp->nocb_head_rdp` while offload/deoffload queue `rdp` in `rdp_gp->nocb_toggling_rdp` and wait on `rdp->nocb_state_wq`. [F25, F58, F84]
- `rcu_nocb_rdp_deoffload()` must call `rcu_barrier()` and `kthread_park(rdp->nocb_cb_kthread)` before clearing `SEGCBLIST_OFFLOADED`, while `rcu_nocb_rdp_offload()` must wait for `SEGCBLIST_OFFLOADED` before `kthread_unpark(rdp->nocb_cb_kthread)`. In `nocb_cb_wait()`, only call `kthread_parkme()` when `rdp->nocb_cb_sleep` is true (with `rcu_segcblist_n_cbs(&rdp->cblist) == 0` verified under `rcu_nocb_lock_irqsave`), and invoke `rcu_do_batch(rdp)` with BH disabled (`local_bh_disable()`/`enable()`) and hard IRQs enabled. [F7, F21, F114]
- In `lazy_rcu_shrink_count()` and `lazy_rcu_shrink_scan()`, acquire `rcu_state.nocb_mutex` via `mutex_trylock()` (never `mutex_lock()`) to protect `rcu_nocb_mask`, and recheck `READ_ONCE(rdp->lazy_len)` under `rcu_nocb_lock_irqsave(rdp, flags)` in `lazy_rcu_shrink_scan()`. [F30]
- `rcu_preempt_ctxt_queue()` consumes caller-held `rnp->lock` (with IRQs disabled) and unlocks it via `raw_spin_unlock_rcu_node(rnp)` leaving hard IRQs disabled. `rcu_initiate_boost()` consumes caller-held `rnp->lock` and `flags` and must call `raw_spin_unlock_irqrestore_rcu_node(rnp, flags)` on every return path. [F9, F12]
- In `__rcu_read_unlock()`, a compiler `barrier()` must precede `rcu_preempt_read_exit()`, and when it returns `0`, another `barrier()` must order the nesting decrement before `READ_ONCE(t->rcu_read_unlock_special.s)`. In `rcu_read_unlock_special()`, if `in_nmi()` is true on entry, return immediately. [F37, F109]
- In `rcu_preempt_deferred_qs_irqrestore()`, snapshot `rt_mutex_owner(&rnp->boost_mtx.rtmutex) == t` and `sync_rcu_exp_done(rnp)` under `rnp->lock` before unlocking to call `rcu_report_unblock_qs_rnp()` or `rt_mutex_futex_unlock()`. In `rcu_boost()`, recheck `rnp->exp_tasks` and `rnp->boost_tasks` and call `rt_mutex_init_proxy_locked(&rnp->boost_mtx.rtmutex, t)` under `rnp->lock`, then unlock with IRQs restored before `rt_mutex_lock(&rnp->boost_mtx)`. [F31, F60]
- In `rcu_print_task_stall()`, pin tasks on `rnp->blkd_tasks` with `get_task_struct(t)` under `rnp->lock`, then unlock via `raw_spin_unlock_irqrestore_rcu_node(rnp, flags)` before calling `task_call_func(t, check_slow_task, &rscr)` and `put_task_struct(t)`. In `rcu_check_gp_start_stall()`, lock leaf `rnp->lock` before `rnp_root->lock` (when `rnp_root != rnp`), and unlock in reverse order before `show_rcu_gp_kthreads()`. [F33, F34]
- In `record_gp_stall_check_time()`, order `WRITE_ONCE(rcu_state.gp_start, j)` before `WRITE_ONCE(rcu_state.jiffies_stall, j + j1)` with `smp_mb()`, pairing with `smp_rmb()`-separated reads of `gp_seq`, `jiffies_stall`, `gp_start`, and `gp_seq` in `check_cpu_stall()`. In `rcu_check_gp_kthread_expired_fqs_timer()`, load `rcu_state.gp_state` via `smp_load_acquire()` before `READ_ONCE(rcu_state.jiffies_force_qs)`. [F35, F36]
- `rcu_note_context_switch()`, `rcu_flavor_sched_clock_irq()`, `rcu_cpu_stall_reset()`, `check_cpu_stall()`, `print_cpu_stall()`, and `print_other_cpu_stall()` require hard IRQs disabled; `rcu_qs()` requires preemption disabled. [F121, F128]

## Object Lifetimes
- When removing `t` from `rnp->blkd_tasks` in `rcu_preempt_deferred_qs_irqrestore()` under `rnp->lock`, compute `np = rcu_next_node_entry(t, rnp)`, unlink `t->rcu_node_entry`, set `t->rcu_blocked_node = NULL`, and advance `rnp->gp_tasks`, `rnp->exp_tasks`, or `rnp->boost_tasks` matching `&t->rcu_node_entry` to `np`. [F10]
- Initialize `rdp->defer_qs_iw` only once at boot in `rcu_preempt_deferred_qs_init()` via `IRQ_WORK_INIT_HARD()`, never in `rcu_read_unlock_special()`. [F18]
- In `__wait_rcu_gp()`, both loops must apply identical `checktiny && crcu_array[i] == call_rcu` and deduplication checks so each active `rs_array[i]` runs `init_rcu_head_on_stack()` and `init_completion()` before `crcu_array[i](..., wakeme_after_rcu)`, and `destroy_rcu_head_on_stack()` only after `wait_for_completion_state()`. [F67, F131]
- In `rcu_dump_cpu_stacks()`, pair every `printk_deferred_enter()` with `printk_deferred_exit()`, including on early return. `kernel::sync::rcu::Guard` must remain `!Send`, call `rcu_read_lock()` only in `Guard::new()`, and call `rcu_read_unlock()` only in `Drop::drop()` (`Guard::unlock(self)` just drops `self`). [F17, F139]

## API Contracts
- When `rcu_nocb_try_bypass()` returns `false`, `rhp` is not enqueued and `rdp->nocb_lock` is held (if offloaded); when `true`, `rhp` is enqueued and `rdp->nocb_lock` is unlocked. `rcu_nocb_do_flush_bypass()` and `rcu_nocb_flush_bypass()` return `true` when `rhp_in`/`rhp` is `NULL`, and `false` only when `rhp_in` is non-NULL and `rdp->nocb_bypass` was empty (leaving the caller to enqueue `rhp` on `rdp->cblist`). [F3, F41]
- In `rcu_check_boost_fail()`, `cpup` is nullable (when non-NULL and returning `false`, set `*cpup` to the first holdout CPU or `-1`). `rcu_is_gp_kthread_starving()` and `rcu_is_rcuc_kthread_starving()` take a nullable `unsigned long *jp`, and `rcu_is_rcuc_kthread_starving()` writes `*jp` only when returning `true` (so `print_cpu_stall_info()` must not read `j` when `false`). In `print_cpu_stall_info()`, format `buf` with `snprintf(buf, sizeof(buf), ...)` and read `buf` only when `rcuc_starved` is true. [F49, F50, F100]
- `wakeme_after_rcu()` requires a `struct rcu_head *` embedded as `head` in an initialized `struct rcu_synchronize`. `debug_lockdep_rcu_enabled()` must be `noinstr` and `notrace` and return false when `rcu_scheduler_active == RCU_SCHEDULER_INACTIVE`, `!READ_ONCE(debug_locks)`, or `current->lockdep_recursion != 0`. `rcu_stall_chain_notifier_register()` requires `rcu_cpu_stall_notifiers` non-zero (else `-EEXIST`), and `rcu_stall_notifier_call_chain()` passes the jiffies stall duration cast to `void *`. [F103, F129, F143]

## Error Handling
- In `rcu_spawn_cpu_nocb_kthread()` and `rcu_spawn_one_boost_kthread()`, check `kthread_run()`/`kthread_create()` with `IS_ERR(t)` before assigning `rdp_gp->nocb_gp_kthread`, `rdp->nocb_cb_kthread`, or `rnp->boost_kthread_task`. On error in `rcu_spawn_cpu_nocb_kthread()`, lock `rcu_state.nocb_mutex` and, if `rcu_rdp_is_offloaded(rdp)`, call `rcu_nocb_rdp_deoffload(rdp)` and `cpumask_clear_cpu(cpu, rcu_nocb_mask)`. [F8, F39, F40]
- Check `rdp->nocb_gp_rdp` for `NULL` in `do_nocb_deferred_wakeup()` and `rcu_nocb_rdp_offload()` (which also checks `rdp->nocb_gp_kthread` and returns `-EINVAL`). In `rcu_nocb_rdp_deoffload()`, check `rdp->nocb_cb_kthread` and `rdp_gp->nocb_gp_kthread` for `NULL`, and if `rdp_gp->nocb_gp_kthread` is `NULL`, directly clear `SEGCBLIST_OFFLOADED` and `list_del(&rdp->nocb_entry_rdp)`. Check `rcu_state.gp_kthread` for `NULL` before inspecting or waking it in `__rcu_read_lock()`, `rcu_read_unlock_strict()`, and stall paths. [F44, F45, F52]
- In `lazy_rcu_shrink_count()` and `lazy_rcu_shrink_scan()`, early exits on `!cpumask_available(rcu_nocb_mask)` or `!mutex_trylock(&rcu_state.nocb_mutex)` return `0`, whereas a completed scan with `count == 0` returns `SHRINK_EMPTY` from `lazy_rcu_shrink_count()` and `SHRINK_STOP` from `lazy_rcu_shrink_scan()`. [F43]
- In `rcu_print_task_stall()`, read `rscr` only when `task_call_func(t, check_slow_task, &rscr) == 0`. In `check_cpu_stall()`, after winning `cmpxchg(&rcu_state.jiffies_stall, js, jn)`, check `kvm_check_and_clear_guest_paused()` before incrementing `rcu_stall_count`, calling `rcu_stall_notifier_call_chain()`, or printing stall warnings. [F48, F137]

## External Contracts
- `rcu_jiffies_till_stall_check()` clamps `rcu_cpu_stall_timeout` (seconds) to `[3, 300]`, writes it back, and returns `till_stall_check * HZ + RCU_STALL_DELAY_DELTA` jiffies. `rcu_exp_jiffies_till_stall_check()` treats `rcu_exp_cpu_stall_timeout` as ms (defaulting to `jiffies_to_msecs(rcu_jiffies_till_stall_check())` when `0`), clamps `msecs_to_jiffies()` to `[2UL, 300UL * HZ]`, writes back `jiffies_to_msecs()` if changed, and returns jiffies. [F135, F136]

## Known Pitfalls
- In `rcu_print_task_stall()`, iterate `ts[0..i-1]` via `while (i) { t = ts[--i]; ... }` so `ts[0]` is processed and `put_task_struct()` is called. `union rcu_special` subfields `b.{blocked,need_qs,exp_hint}` index 2-char literals in `rcu_print_task_stall()` and alias `u32 s`, so they must only hold `0` or `1` and clearing `.s = 0` clears all subfields. [F76, F78]
- In `wake_nocb_gp_defer()`, `RCU_NOCB_WAKE_LAZY` (2) only arms `rdp_gp->nocb_timer` when `nocb_defer_wakeup == RCU_NOCB_WAKE_NOT`, whereas `RCU_NOCB_WAKE_BYPASS` (1) overrides any pending deferral. In `rcu_nocb_try_bypass()`, check `ULONG_CMP_LT(rdp->nocb_nobypass_count, nocb_nobypass_lim_per_jiffy)` before comparing `c` against `nocb_nobypass_lim_per_jiffy`. [F81, F97]
- Check `cpumask_available(rcu_nocb_mask)` before accessing `rcu_nocb_mask` when `rcu_state.nocb_is_setup` may not be set. Guard all `pr_alert()`/`pr_cont()` calls in `rcu_organize_nocb_kthreads()` with `dump_tree`. Use `1UL << (cpu - rnp->grplo)` or `leaf_node_cpu_bit(rnp, cpu)` (never 32-bit `1 << ...`) for `rnp->qsmask` and `rnp->expmask`. [F85, F92, F106]
