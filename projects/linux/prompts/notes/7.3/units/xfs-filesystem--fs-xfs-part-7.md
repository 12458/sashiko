# XFS FILESYSTEM — fs/xfs (part 7)

This unit implements XFS VFS superblock and mount operations (`xfs_super.c`), copy-on-write and file range remapping (`xfs_reflink.c`), realtime extent allocation and growfs (`xfs_rtalloc.c`), symbolic links (`xfs_symlink.c`), refcount/rmap log intent items and recovery (`xfs_refcount_item.c`, `xfs_rmap_item.c`), and sysfs/sysctl/procfs stats/trace glue (`xfs_sysfs.c`, `xfs_sysctl.c`, `xfs_stats.c`, `xfs_trace.c`).

## Architecture & Data Flow

- `xfs_init_fs_context()` must set `mp->m_finobt_nores = true` so log recovery `ifree` transactions do not require per-AG finobt reservations, and must not copy `fc->sb_flags` (`SB_RDONLY`, `SB_DIRSYNC`, `SB_SYNCHRONOUS`) into `mp` (done in `xfs_fs_fill_super()` before `xfs_fs_validate_params(mp)`). [F189, F244]
- In `xfs_fs_parse_param()` and `xfs_fs_reconfigure()`, `fc->s_fs_info` (`parsing_mp` / `new_mp`) has `m_super == NULL`: never dereference `parsing_mp->m_super`, and pass `mp = XFS_M(fc->root->d_sb)` (not `new_mp`) to `xfs_finish_flags()`. Each `Opt_*` case in `xfs_fs_parse_param()` must not fall through; quota options must set `XFS_QFLAGS_MNTOPTS` in `m_qflags`, which `xfs_fs_fill_super()` and `xfs_fs_reconfigure()` must clear. Toggling `XFS_FEAT_SMALL_INUMS` in `xfs_fs_reconfigure()` requires calling `xfs_set_inode_alloc(mp, mp->m_sb.sb_agcount)`. [F223, F237, F247, F279]
- `xfs_remount_ro()` and `xfs_fs_freeze()` must drain reserve pools via `xfs_save_resvblks(mp)` before log quiesce/clean, and `xfs_remount_rw()` and `xfs_fs_unfreeze()` must restore them via `xfs_restore_resvblks(mp)`. In `xfs_setup_devices()`, `xfs_configure_buftarg()` must use `sb_dblocks` for `m_ddev_targp`, `sb_logblocks` for external `m_logdev_targp`, and `sb_rblocks` for external `m_rtdev_targp`. [F238, F264]
- `xfs_reinit_percpu_counters()` must only set `XC_FREE_RTEXTENTS` from `mp->m_sb.sb_frextents` when `!xfs_has_zoned(mp)`. `xfs_statfs_data()` and `xfs_statfs_inodes()` must clamp `st->f_bfree` and `st->f_ffree` at `0` using signed comparisons (`max(0LL, ...)` / `max_t(int64_t, 0, ...)`). [F236, F265]
- `rtg->rtg_rsum_cache` shares a union with `rtg_open_zone` and is only valid when `!xfs_has_zoned(mp)`. `xfs_alloc_rsum_cache()` must initialize it to `0xFF` (`memset(..., -1, rbmblocks)`), and `xfs_rtany_summary()` must clamp `high = min(high, rsum_cache[bbno] - 1)` and update `rsum_cache[bbno] = log + 1` only when `log + 1 < rsum_cache[bbno]`. [F213, F234]
- Before `xfs_rtallocate_range()` clears `[start, end]` via `xfs_rtmodify_range()`, it must find the enclosing free extent `[preblock, postblock]`, decrement its summary count via `xfs_rtmodify_summary()`, and increment summary counts for remaining `[preblock, start - 1]` and `[end + 1, postblock]` fragments. [F233]
- `xfs_rtallocate_clamp_len()` must first clamp `rtxlen` so `startrtx + rtxlen <= rtg->rtg_extents` before rounding down to `prod` via `xfs_rtalloc_align_len()`. When `xfs_bmap_rtalloc()` retries on `-ENOSPC` (`!noalign`), it must restore `ap->offset = orig_offset` and `ap->length = orig_length` and set `noalign = true`. [F246, F260]
- `xfs_growfs_rt()` must convert `in->extsize` via `XFS_FSB_TO_B(mp, in->extsize)` when checking `[XFS_MIN_RTEXTSIZE, XFS_MAX_RTEXTSIZE]`, and validate `in->newblocks` with `xfs_sb_validate_fsb_count()` and `xfs_rt_check_size(mp, in->newblocks - 1)`. `sb_rextslog` must be computed via `xfs_compute_rextslog()`. Growing RT in `xfs_growfs_rt_bmblock()` or `xfs_growfs_rt_zoned()` must set `XFS_FEAT_REALTIME` and update RT btree maxlevels (plus `m_rsumlevels`, `m_rsumblocks`, and `xfs_trans_resv_calc()` in `xfs_growfs_rt_bmblock()`). [F232, F261, F262]
- `xfs_reflink_end_cow_extent_locked()` must copy `got` to `del`, trim `del` to `[*offset_fsb, end_fsb)` with `xfs_trim_extent()` and `min(data.br_blockcount, del.br_blockcount)`, and pass untrimmed `got` to `xfs_bmap_del_extent_cow()`. `xfs_reflink_clear_inode_flag()` must check `xfs_can_free_cowblocks(ip)` before canceling CoW blocks or clearing `XFS_DIFLAG2_REFLINK`. [F256, F320]
- When `xfs_inactive_symlink_rmt()` sets `ip->i_disk_size = 0` before truncating blocks, it must change `VFS_I(ip)->i_mode` from `S_IFLNK` to `S_IFREG` and log `XFS_ILOG_CORE` in the same transaction. [F239]
- In `xlog_recover_{cui,rtcui,rui,rtrui}_commit_pass2()`, `item->ri_buf[0].iov_len` must be checked against the 0-extent size before reading `nextents`, and then verified to equal the `nextents` format size. `xfs_refcount_recover_work()` and `xfs_rmap_recover_work()` must validate every extent with `xfs_cui_validate_phys()` / `xfs_rui_validate_map()` before allocating a transaction. `xfs_cui_init()`/`xfs_cui_item_free()` and `xfs_rui_init()`/`xfs_rui_item_free()` must use `kzalloc()`/`kfree()` when `nextents > 16` and slab caches only when `nextents <= 16`. [F252, F253, F254]
- Changes to `uint32_t` fields in `struct __xfsstats` must keep `xstats[]` in `xfs_stats_format()`, `XFSSTAT_START_XQMSTAT` / `XFSSTAT_END_XQMSTAT`, and `struct xfsstats::a` in lockstep, with `uint64_t` fields at the end. `xfs_error_meta_init[]` must match `XFS_ERR_*` enum indices used by `xfs_error_get_cfg()`. [F250, F251]

## Synchronization

- `xfs_flush_inodes()` must not be called under `XFS_ILOCK` or folio locks, and must call `flush_work(&mp->m_flush_inodes_work)` before and after queueing `m_flush_inodes_work`. `xfs_fs_statfs()` must use non-blocking `xfs_inodegc_push(mp)`, not `xfs_inodegc_flush(mp)`. [F200, F201]
- In `xfs_remount_ro()`, after `sync_filesystem()`, call `xfs_blockgc_stop(mp)`, `xfs_blockgc_free_space(mp, &icw)` with `XFS_ICWALK_FLAG_SYNC`, `xfs_inodegc_stop(mp)`, and `xfs_zone_gc_stop(mp)` before `xfs_log_clean(mp)` and `xfs_set_readonly(mp)`. [F192]
- In `xfs_fs_freeze()`, `xfs_save_resvblks(mp)` and `xfs_log_quiesce(mp)` must run inside `memalloc_nofs_save()` / `memalloc_nofs_restore()`. `xfs_alloc_wq` and per-mount `m_buf_workqueue`, `m_unwritten_workqueue`, `m_reclaim_workqueue`, `m_blockgc_wq`, and `m_inodegc_wq` require `WQ_MEM_RECLAIM`. [F303, F304]
- In `xfs_rtallocate_rtg()` on `xfs_has_rtgroups(mp)`, `args.rtg` is locked with `XFS_RTGLOCK_BITMAP` without joining `tp` until `xfs_rtallocate_adjust_for_busy()` succeeds; earlier failures must jump to `out_unlock` (`*rtlocked = false`), whereas failures after `xfs_rtgroup_trans_join()` jump to `out_release`. [F186]
- `xfs_rtmount_rtg()` must call `xfs_rtmount_iread_extents()` under `XFS_ILOCK_EXCL` for every `rtg->rtg_inodes[i]` at mount time. `xfs_growfs_rt_bmblock()` must lock/join `rtg` with `XFS_RTGLOCK_BITMAP | XFS_RTGLOCK_RMAP` and update both `i_disk_size` and `i_size_write()` on `rbmip` and `rsumip`. `xfs_rtalloc_reinit_frextents()` must hold `XFS_RTGLOCK_BITMAP_SHARED` around `xfs_rtalloc_query_all()`, hold `mp->m_sb_lock` when writing `sb_frextents`, and call `xfs_set_freecounter(mp, XC_FREE_RTEXTENTS, mp->m_sb.sb_frextents)`. [F187, F197, F198, F235]
- `xfs_reflink_remap_prep()` must hold `xfs_ilock2_io_mmap(src, dest)` across prep, `xfs_reflink_set_inode_flag()`, and `xfs_flush_unmap_range()`, and only demote `src` after setting `XFS_IREMAPPING` when `inode_in != inode_out`. `xfs_reflink_fill_cow_hole()` and `xfs_reflink_fill_delalloc()` must re-run `xfs_find_trim_cow_extent()` after dropping/reacquiring `XFS_ILOCK_EXCL` around `xfs_trans_alloc_inode()`. [F206, F242]
- `xfs_refcount_defer_add()` and `xfs_rmap_defer_add()` must dispatch `ri->ri_realtime` intents to `xfs_rtrefcount_update_defer_type` / `xfs_rtrmap_update_defer_type` so RT and data AGF locks do not mix. `log_head_lsn_show()` must hold `log->l_icloglock`, while `log_tail_lsn_show()` must use `xlog_crack_atomic_lsn()`. [F199, F308]

## Object Lifetimes

- `xfs_cui_init()` and `xfs_rui_init()` set `refcount` to 2; `xfs_cui_release()` and `xfs_rui_release()` must remove from AIL and free only when `atomic_dec_and_test()` reaches 0. Each `xfs_refcount_intent` and `xfs_rmap_intent` holds `ri_group` dropped by `*_cancel_item()`; `*_finish_item()` must not cancel the item when returning `-EAGAIN`. [F163, F164]
- On error in `xfs_open_devices()`, reset any `ERR_PTR` in `mp->m_*_targp` to `NULL`, free allocated buftargs with `xfs_free_buftarg()`, and call `bdev_fput()` on unconsumed `rtdev_file` or `logdev_file`. `xfs_fs_parse_param()` must `kfree()` prior `m_logname`/`m_rtname` before assigning `kstrdup()`. In `xfs_fs_fill_super()`, errors after `xfs_mountfs(mp)` succeeds must jump to `out_unmount`. `xfs_destroy_caches()` must call `rcu_barrier()` before `kmem_cache_destroy()`. [F170, F174, F176, F316]
- `xfs_reflink_remap_extent()` must always reserve `XFS_EXTENTADD_SPACE_RES(mp, XFS_DATA_FORK)` blocks, and on `-EDQUOT`/`-ENOSPC` fallback (`!quota_reserved`), call `xfs_trans_reserve_quota_nblks()` for `dmap->br_blockcount` if `!smap_real && dmap_written`. [F182]

## API Contracts

- Callers of `xfs_reflink_cancel_cow_blocks()` and `xfs_reflink_clear_inode_flag()` must hold `XFS_ILOCK_EXCL` and join `ip` with `xfs_trans_ijoin(*tpp, ip, 0)` (not `XFS_ILOCK_EXCL`), using `*tpp` after the call. `xfs_reflink_cancel_cow_range()` takes byte `offset`/`count` and asserts `ip->i_cowfp != NULL`, while `xfs_reflink_cancel_cow_blocks()` takes fsblocks `[offset_fsb, end_fsb)` and checks `xfs_inode_has_cow_data(ip)`. Byte-to-fsb conversion in CoW range helpers must use `XFS_B_TO_FSBT()` for `offset_fsb` and `XFS_B_TO_FSB()` for `end_fsb`. [F179, F218, F287]
- Callers of `xfs_reflink_find_shared()` and `xfs_reflink_find_rtshared()` must check `shared_len != 0` before reading `shared_offset`. In `xfs_reflink_unshare()`, `filemap_write_and_wait_range()` takes inclusive end `offset + len - 1` (unlike `iomap_file_unshare()`/`dax_file_unshare()` which take `len`). `xfs_reflink_end_cow_extent_locked()` must always advance `*offset_fsb` (to `end_fsb` or `del.br_startoff + del.br_blockcount`). [F216, F217, F219]
- `xfs_reflink_remap_extent()` must clamp `dmap->br_blockcount = min(dmap->br_blockcount, smap.br_blockcount)` before any no-op early exit, and `xfs_reflink_remap_blocks()` must always set `*remapped` before returning (even on error). `xfs_reflink_remap_prep()` must reject cross-RT or mixed-DAX inodes with `-EINVAL`, and when `pos_out > XFS_ISIZE(dest)`, zero post-EOF and flush from `XFS_ISIZE(dest)` across `*len + (pos_out - XFS_ISIZE(dest))`. Never call `xfs_reflink_recover_cow()` when cached inodes may hold live CoW extents (e.g., `xfs_remount_rw()`). `xfs_reflink_max_atomic_cow()` must use `rounddown_pow_of_two()`. [F220, F241, F271, F331, F332]
- `xfs_rtallocate_rtgs()` and `xfs_rtallocate_rtg()` take `minlen`, `maxlen`, and `prod` in rtextents (`xfs_rtxlen_t`), while `bno_hint` (using `NULLFSBLOCK`, not `0`, when absent) and outputs `*bno`/`*blen` are in fsblocks (`xfs_rtx_to_rtb()`, `xfs_rtxlen_to_extlen()`). `xfs_rtallocate_extent_{exact,near,size}()` require `minlen` and `maxlen` to be multiples of `prod` (`xfs_rtalloc_align_minmax()`). `xfs_rtany_summary()` sets signed `int *maxlog = -1` when no free extents exist, so check `maxlog >= 0`. `xfs_rtmount_readsb()` must use `mp->m_sb.sb_blocksize >> BBSHIFT`, not `XFS_FSB_TO_BB(mp, 1)`. [F207, F208, F209, F212, F215]
- Bulk-copying extents into CUI/RUI items must set `cui_next_extent` / `rui_next_extent` to `nextents`, and `xlog_recover_{cud,rtcud,rud,rtrud}_commit_pass2()` must pass the intent type (`XFS_LI_CUI`, `XFS_LI_CUI_RT`, `XFS_LI_RUI`, `XFS_LI_RUI_RT`) to `xlog_recover_release_intent()`. [F228, F229]
- `xfs_symlink()` must set `args.idmap` and `args.pip = dp` and call `xfs_icreate_dqalloc()`, and reject `strlen(target_path) >= XFS_SYMLINK_MAXLEN`, while `xfs_readlink()` accepts `1..XFS_SYMLINK_MAXLEN` into a `XFS_SYMLINK_MAXLEN + 1` buffer. `xfs_fs_drop_inode()` must return `0` when `XFS_IRECOVERY` is set, and `xfs_fs_evict_inode()` must call `dax_break_layout_final(inode)` when `IS_DAX(inode)` before truncating pages. Attributes on `xfs_sysfs_ops` kobjects must be embedded in `struct xfs_sysfs_attr`. [F255, F299, F321, F327]

## Error Handling

- `xfs_refcount_finish_one_cleanup()` and `xfs_rmap_finish_one_cleanup()` must read `rcur->bc_ag.agbp` before `xfs_btree_del_cursor(rcur, error)` frees `rcur`, and call `xfs_trans_brelse(tp, agbp)` only when `error && agbp`. [F165]
- In `xfs_symlink()`, `dp` must not be joined via `xfs_trans_ijoin(tp, dp, 0)` until after `xfs_dialloc()` and `xfs_icreate()` succeed; on error after `xfs_icreate()`, call `xfs_trans_cancel(tp)` before unlocking `du.ip`, calling `xfs_finish_inode_setup(du.ip)` and `xfs_irele(du.ip)`, and unlocking `dp` if `unlock_dp_on_error`. [F167, F195]
- `xfs_fs_sync_fs()` stops `inodegc`, `blockgc`, and `zone_gc` at `SB_FREEZE_PAGEFAULT`; if `xfs_fs_freeze()` fails on a rw mount, it must restart all three. In `xfs_init_percpu_counters()`, unwinding 0-indexed `mp->m_free[i].count` must use `while (--i >= 0)`. [F172, F173]
- In `xfs_growfs_rt()`, if `xfs_growfs_rtg()` fails for `rgno >= old_rgcount`, grab `rtg`, call `xfs_rtunmount_rtg(rtg)` and `xfs_rtgroup_rele(rtg)`, then `xfs_rtgroup_free(mp, rgno)`; post-loop `xfs_update_secondary_sbs()` and `xfs_metafile_resv_init()` must use `error2` (ignoring `-ENOSPC` from `xfs_metafile_resv_init()`) to preserve `error`. In `xfs_rtallocate_rtg()`, when `xfs_rtallocate_extent_near()` returns `-ENOSPC`, call `xfs_rtbuf_cache_relse(&args)` and reset `error = 0` to fall back to `xfs_rtallocate_extent_size()`. [F185, F211, F214]

## External Contracts

- Slab cache names passed to `kmem_cache_create()` in `xfs_init_caches()` are exposed via `/proc/slabinfo` and `/sys/kernel/slab` and must not be renamed. [F266]

## Known Pitfalls

- In `xfs_reflink_cancel_cow_blocks()`, `xfs_bmap_del_extent_{delay,cow}()` reposition `icur`, whereas non-deleting branches must call `xfs_iext_prev(ifp, &icur)`. In `xfs_reflink_end_cow_extent_locked()` and `xfs_reflink_remap_extent()`, do not call `xfs_iext_count_extend()` until after all early-return checks. [F243, F249]
- In `xfs_growfs_rt_zoned()` and `xfs_growfs_rt_bmblock()`, pass `&M_RES(nmp)->tr_growrtfree` (from fake mount `nmp`, not `mp`) to `xfs_trans_alloc(mp, ...)`. In `xfs_rtallocate_rtgs()`, reset `bno_hint = NULLFSBLOCK` each iteration and initialize `rtlocked = false` inside the loop. Detect initial file-offset-0 user data allocation via `ap->datatype & XFS_ALLOC_INITIAL_USER_DATA` (not `ap->eof && ap->offset == 0`) for `xfs_rtpick_extent()`. [F274, F275, F277]
- Widen `mp->m_sb.sb_rgcount - 1` to 64-bit `xfs_rtxnum_t` before multiplying by `sb_rgextents` in `xfs_last_rtgroup_extents()`, and use `howmany_64()` when computing rtgroup counts in `xfs_growfs_rt_alloc_fake_mount()` and `xfs_growfs_rt_prep_groups()`. In `xfs_rtallocate_extent_near()`, use `(1ULL << (maxlog + 1)) - 1` with `min_t(xfs_rtblock_t, ...)` and guard `2 << (maxlog - mp->m_blkbit_log)` when `maxlog < mp->m_blkbit_log`; in `xfs_rtpick_extent()`, check `log2 != -1` before `1ULL << log2`. [F282, F283, F285, F286, F291]
- In `xfs_fs_fill_super()`, validate `MAX_LFS_FILESIZE` via `XFS_B_TO_FSBT(mp, MAX_LFS_FILESIZE)` and `xfs_verify_fileoff()`, not by converting `XFS_MAX_FILEOFF` to bytes. In `xfs_stats_format()`, do not reset `j = 0` in the inner loop. Never add attributes calling `err_to_mp()` (like `fail_at_unmount`) to `xfs_error_ktype.default_groups`. [F280, F288, F300]
