# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 7)

Implements the Software Steering (`mlx5dr` / SWS) direct rule engine across ConnectX STE hardware generations (v0–v3), hardware transport object management (`transobj.c`), UAR and BlueFlame register allocation (`uar.c`), NIC and HCA virtual port configuration (`vport.c`), Write-Combining (WC) probing (`wc.c`), and work queue primitives (`wq.c`, `wq.h`).

## Architecture & Data Flow

- New `struct mlx5dr_ste_ctx` callbacks must be initialized across `ste_ctx_v1`, `ste_ctx_v2`, and `ste_ctx_v3` (and `ste_ctx_v0` if supported on STEv0) unless callers in `dr_ste.c` check for NULL. In `dr_ste_v1_set_actions_tx`/`rx`, header bit-setting (`set_encap`, `set_push_vlan`, `set_pop_vlan`, `set_rx_decap`, `set_encap_l3`, `set_insert_hdr`, `set_remove_hdr`) must dispatch via `ste_ctx` callbacks rather than calling `dr_ste_v1_set_*` directly so `ste_ctx_v3` uses STEv3 layouts. [F755, F756]
- In `dr_ste_v1_set_actions_tx`/`rx`, `DR_ACTION_TYP_RANGE` must allocate a dedicated `DR_STE_V1_TYPE_MATCH_RANGES` STE via `dr_ste_v1_arr_init_next_match_range`, program its miss address via `dr_ste_v1_set_miss_addr`, and set `action_sz = 0` so no action fields are written onto it. When `DR_ACTION_TYP_POP_VLAN` is set and `!(actions_caps & DR_STE_CTX_ACTION_CAP_POP_MDFY)`, set `allow_modify_hdr = false` so a subsequent `DR_ACTION_TYP_MODIFY_HDR` allocates a new STE via `dr_ste_v1_arr_init_next_match`. [F758, F795]
- In `dr_ste_v0_set_actions_rx`, if `DR_ACTION_TYP_MODIFY_HDR` or `DR_ACTION_TYP_TAG` is processed when `dr_ste_v0_get_entry_type(last_ste) == DR_STE_TYPE_MODIFY_PKT`, call `dr_ste_v0_arr_init_next` first. In `dr_ste_v0_set_actions_tx`, apply `DR_ACTION_TYP_MODIFY_HDR` before encapsulation (`DR_ACTION_TYP_L2_TO_TNL_L2`/`L3`) in a `DR_STE_TYPE_MODIFY_PKT` STE, then call `dr_ste_v0_arr_init_next` for a new `DR_STE_TYPE_TX` STE for push-VLAN or encap. [F794, F860]
- In `dr_ste_v1_set_rewrite_actions`, test `rewrite_pattern != MLX5DR_INVALID_PATTERN_INDEX` (`0xffffffff`) rather than non-zero (`0` is valid); initialize unused `modify_pat_idx`/`decap_pat_idx` in `struct mlx5dr_ste_actions_attr` to `MLX5DR_INVALID_PATTERN_INDEX`. [F750]
- In `mlx5_cmd_dr_create_fte`, `actions`, `fs_dr_actions`, and `term_actions` have capacity `MLX5_FLOW_CONTEXT_ACTION_MAX` (34); every dynamic append must check the index against `MLX5_FLOW_CONTEXT_ACTION_MAX` (returning `-EOPNOTSUPP`). Order header transformations in `actions[]` as `decap -> pop vlan -> modify header` for RX and `modify header -> push vlan -> encap` for TX (deferring non-decap `pkt_reformat` via `delay_encap_set` until after `MOD_HDR` and `VLAN_PUSH`). Before checking `MLX5_FLOW_CONTEXT_ACTION_PACKET_REFORMAT`, if `MLX5_FLOW_CONTEXT_ACTION_FWD_DEST` is set and any child `mlx5_flow_rule` satisfies `contain_vport_reformat_action(dst)`, clear `MLX5_FLOW_CONTEXT_ACTION_PACKET_REFORMAT` from `fte->act_dests.action.action`. [F765, F790, F792]
- Before passing `dest_ft` to `mlx5dr_action_create_dest_table`, check `!mlx5dr_is_fw_table(dest_ft)` (`dest_ft->fs_dr_table.dr_table != NULL`); if `NULL`, use `mlx5dr_action_create_dest_flow_fw_table`. In `mlx5_cmd_dr_create_flow_table`, clear `MLX5_FLOW_TABLE_TUNNEL_EN_REFORMAT` and `MLX5_FLOW_TABLE_TUNNEL_EN_DECAP` from `flags` before `mlx5dr_table_create` when `!MLX5_CAP_FLOWTABLE(ns->dev, sw_owner_reformat_supported)`. [F749, F839]
- In `mlx5dr_ste_htbl_increase_threshold`, compute the threshold as `(num_of_entries + 1) / 2` so a 1-entry table (`DR_CHUNK_SIZE_1`) gets threshold 1 instead of 0. In `mlx5dr_supp_match_ranges`, test `MLX5_CAP_GEN_64(dev, match_definer_format_supported)` with `1ULL << MLX5_IFC_DEFINER_FORMAT_ID_SELECT`. [F809, F810]
- In `uar.c`, each `struct mlx5_uars_page` splits `bfregs` per UAR into regular (`reg_bitmap`/`reg_avail`) and fast-path (`fp_bitmap`/`fp_avail`) pools. Under the pool lock, `alloc_bfreg` and `mlx5_free_bfreg` must update the bitmap bit, `*avail`, `up->list` membership (removing at 0, re-adding at 1), and `up->ref_count` in lockstep. `bfreg->wc` records which pool (`wc_head` vs `reg_head`) owns `bfreg->up` after `-EAGAIN` fallback, and `mlx5_free_bfreg` must select `head`/`lock` from `bfreg->wc` and reconstruct `dbi` from `bfreg->map - up->map` via `addr_to_dbi_in_syspage` (classifying fast-path by `(dbi % MLX5_BFREGS_PER_UAR) >= MLX5_NON_FP_BFREGS_PER_UAR`); never modify `bfreg->map` or break the inverse relationship with `map_offset`. [F767, F768, F783]
- In `struct mlx5_wq_cyc`, `mlx5_wq_cyc_push`/`push_n` must increment `wq->wqe_ctr` and `wq->cur_sz` equally while `mlx5_wq_cyc_pop` decrements `wq->cur_sz`, and `mlx5_wq_cyc_reset` must zero both and call `mlx5_wq_cyc_update_db_record(wq)`. In `struct mlx5_wq_ll`, one slot is reserved for `wq->tail_next` (at `wq->fbc.sz_m1`), so usable capacity in `mlx5_wq_ll_is_full`/`missing` is `wq->fbc.sz_m1` (`mlx5_wq_ll_get_size(wq) - 1`). `mlx5_wq_ll_pop` must write the freed WQE index into `*wq->tail_next` before updating `wq->tail_next` and decrementing `wq->cur_sz`; `mlx5_wq_ll_reset` must zero `head`, `wqe_ctr`, and `cur_sz`, call `mlx5_wq_ll_init_list`, and call `mlx5_wq_ll_update_db_record`. [F769, F770, F780]
- In `mlx5_wc_post_nop`, set `MLX5_WQE_CTRL_CQ_UPDATE` on `ctrl->fm_ce_se` in the DMA WQE buffer only when `signaled` is true, but always set `MLX5_WQE_CTRL_CQ_UPDATE` on `mmio_wqe` written via `mlx5_iowrite64_copy`. [F803]
- In `mlx5_vport_get_other_func_cap` and `mlx5_vport_set_other_func_cap`, when `mlx5_vport_use_vhca_id_as_func_id(dev, vport, &vhca_id)` returns true, set `function_id_type = 1`, `function_id = vhca_id`, and `ec_vf_function = false`. In `mlx5_core_hairpin_create`, keep the `kzalloc` size (`sizeof(*hp) + params->num_channels * 2 * sizeof(u32)`) synchronized with `hp->rqn = (void *)hp + sizeof(*hp)` and `hp->sqn = hp->rqn + params->num_channels`. [F774, F817]

## Synchronization

- `mlx5dr_domain_lock` must acquire `&dmn->info.rx.mutex` before `&dmn->info.tx.mutex` and `mlx5dr_domain_unlock` must release in reverse order. Because `struct mlx5dr_ste::refcount` and `struct mlx5dr_ste_htbl::refcount` are non-atomic `u32` counters, all calls to `mlx5dr_ste_get`/`put` and `mlx5dr_htbl_get`/`put` must hold the owning `mlx5dr_domain_rx_tx` mutex. [F735, F736]
- In `mlx5dr_table_create`, complete `dr_table_init(tbl)`, `dr_table_create_sw_owned_tbl(tbl, uid)`, and `INIT_LIST_HEAD(&tbl->dbg_node)` before `mlx5dr_dbg_tbl_add(tbl)`. In `mlx5dr_table_destroy`, call `mlx5dr_dbg_tbl_del(tbl)` before `dr_table_destroy_sw_owned_tbl(tbl)` and `dr_table_uninit(tbl)`. [F737]
- Every `kref_put(&up->ref_count, up_rel_func)` on a `struct mlx5_uars_page` in `mlx5_put_uars_page` and `mlx5_free_bfreg` must be called under the owning `mlx5_bfreg_head` mutex (`reg_head.lock` or `wc_head.lock`). [F722]
- In `mlx5_wc_support_get`, when `mlx5_core_is_sf(mdev)` is true, acquire only `&parent->wc_state_lock` to serialize `mlx5_core_test_wc(parent)` and copy `parent->wc_state` to `mdev->wc_state`—never nest `&parent->wc_state_lock` inside `&mdev->wc_state_lock`. Always recheck `wc_state == MLX5_WC_STATE_UNINITIALIZED` after acquiring `wc_state_lock` (and inside `mlx5_core_test_wc` for `parent`). [F728, F729]
- In `mlx5_wc_post_nop`, place `dma_wmb()` between WQE writes and `sq->wq.db[MLX5_SND_DBR]` update, and `wmb()` before `mlx5_iowrite64_copy`. In `mlx5_wc_poll_cq`, increment `sq->cc` only after `mlx5_cqwq_pop(&cq->wq)`, `mlx5_cqwq_update_db_record(&cq->wq)`, and `wmb()`. In `mlx5_cqwq_get_cqe` and `mlx5_cqwq_get_cqe_enhanced_comp`, execute `dma_rmb()` after verifying `cqe->op_own & MLX5_CQE_OWNER_MASK` or `cqe->validity_iteration_count` before returning `cqe`. [F730, F731, F732]

## Object Lifetimes

- `mlx5dr_ste_htbl_alloc` initializes `htbl->refcount` to 0: `dr_table_init_nic` must call `mlx5dr_ste_htbl_free` (not `mlx5dr_htbl_put`, which underflows `refcount`) if setup fails before `mlx5dr_htbl_get(nic_tbl->s_anchor)`, and `dr_table_uninit_nic` must release `s_anchor` via `mlx5dr_htbl_put`. [F713]
- `mlx5dr_table_set_miss_action` must succeed in `dr_table_set_miss_action_nic` before touching `tbl->miss_action` or refcounts, and must decrement `tbl->miss_action->refcount` before incrementing `action->refcount` so self-assignment stays balanced. [F714]
- If `set_miss_action` fails in `mlx5_cmd_dr_create_flow_table`, call `mlx5dr_table_destroy(tbl)` and clear `ft->fs_dr_table.dr_table = NULL`. In `mlx5_cmd_dr_destroy_flow_table`, `mlx5dr_table_destroy(ft->fs_dr_table.dr_table)` must succeed before `mlx5dr_action_destroy(ft->fs_dr_table.miss_action)`. [F716, F717]
- In `mlx5_cmd_dr_create_fte`, record only locally allocated `mlx5dr_action` objects in `fs_dr_actions` (`fte->fs_dr_rule.dr_actions`), placing caller-owned `pkt_reformat` and `modify_hdr` only in `actions`/`term_actions`. Both `free_actions` in `mlx5_cmd_dr_create_fte` and `mlx5_cmd_dr_delete_fte` (after `mlx5dr_rule_destroy`) must destroy `fs_dr_actions` / `rule->dr_actions` in reverse order (`num_actions - 1` down to `0`). `mlx5_cmd_dr_update_fte` must save `fte->fs_dr_rule` in `fte_tmp`, zero `fte->fs_dr_rule`, and call `mlx5_cmd_dr_create_fte` before deleting `fte_tmp` via `mlx5_cmd_dr_delete_fte` (restoring `fte->fs_dr_rule` on error). [F718, F719, F720]
- `dr_ste_v1_alloc_modify_hdr_ptrn_arg` gets `action->rewrite->arg` via `mlx5dr_arg_get_obj` before `action->rewrite->ptrn` via `mlx5dr_ptrn_cache_get_pattern` (calling `mlx5dr_arg_put_obj` on pattern error), and `dr_ste_v1_free_modify_hdr_ptrn_arg` releases `ptrn` before `arg`. [F721]
- `mlx5_core_test_wc` allocates `sq->bfreg`, `sq->cq`, and `sq` in order and destroys in reverse (`mlx5_wc_destroy_sq`, `mlx5_wc_destroy_cq`, `mlx5_free_bfreg`), each calling `mlx5_core_destroy_sq`/`cq` before `mlx5_wq_destroy`. `mlx5_wq_cyc_create`, `mlx5_wq_qp_create`, `mlx5_cqwq_create`, and `mlx5_wq_ll_create` allocate `wq_ctrl->db` via `mlx5_db_alloc_node` before `wq_ctrl->buf` (calling `mlx5_db_free` on buffer failure) and set `wq_ctrl->mdev = mdev`. [F724, F725]
- Under `mlx5_roce_en_lock`, `mlx5_nic_vport_enable_roce` and `mlx5_nic_vport_disable_roce` must keep `mdev->roce.roce_en` balanced with firmware (restoring `mdev->roce.roce_en++` if `mlx5_nic_vport_update_roce_state` fails on disable), and `mlx5_nic_vport_affiliate_multiport` must call `mlx5_nic_vport_disable_roce(port_mdev)` on command error. `mlx5_core_hairpin_destroy` must call `mlx5_hairpin_unpair_queues` (`RDY` -> `RST`) before `mlx5_hairpin_destroy_queues`, and both must skip `hp->peer_mdev` SQ commands when `hp->peer_gone` is true. [F727, F835]

## API Contracts

- Every `mlx5_flow_cmds_dr` callback must check `mlx5_fs_cmd_is_fw_term_table(ft)` and delegate to `mlx5_fs_cmd_get_fw_cmds()` when true. All `mlx5dr_*_create*` and `mlx5dr_ste_htbl_alloc` functions return `NULL` on failure (never `ERR_PTR`), which `fs_dr.c` translates into negative errno. Every symbol under `#ifdef CONFIG_MLX5_SW_STEERING` in `fs_dr.h` must have a matching `static inline` stub in `#else`. [F748, F853, F868]
- `set_action_set`/`add` take bit `length` (1..32) and 0-based `shifter`: `dr_ste_v0_set_action_set`/`add` map `length == 32` to `0`, whereas `dr_ste_v1_set_action_set`/`add`/`copy` pass `length` directly and add `MLX5_MODIFY_HEADER_V1_QW_OFFSET` to `shifter`. In STE v1/v3 action builders (`set_encap`, `set_insert_hdr`, `set_remove_hdr`, `set_push_vlan`, `set_pop_vlan`, `set_encap_l3`), divide byte `size` and `offset` by 2 into 2-byte words and call `dr_ste_v1_set_reparse`. [F753, F857]
- `mlx5_get_uars_page` and `alloc_uars_page` return `ERR_PTR` on failure (never `NULL`); check with `IS_ERR`. `mlx5_wq_cyc_create`, `mlx5_wq_qp_create`, `mlx5_cqwq_create`, and `mlx5_wq_ll_create` do not zero `wq` counters or initialize CQE ownership bits; callers must zero-initialize `wq` and set each CQE's `op_own = 0xf1` after `mlx5_cqwq_create`. `create_wc_cq`/`sq` must add `sizeof(u64) * wq_ctrl.buf.npages` to `MLX5_ST_SZ_BYTES(create_cq_in)`/`(create_sq_in)` before `mlx5_fill_page_frag_array`. [F740, F746, F819]
- In `vport.c`, when `other_vport` is non-zero, `mlx5_core_query_vport_counter` and HCA vport query/modify functions must check `MLX5_CAP_GEN(dev, vport_group_manager)` or return `-EPERM`; `mlx5_core_query_vport_counter` takes a 0-based `vf` (setting `vport_number = vf + 1`), whereas `mlx5_query_hca_vport_gid`/`pkey`/`context` and `mlx5_core_modify_hca_vport_context` take a 1-based vport number directly. `mlx5_vport_get_other_func_cap` and `mlx5_vport_set_other_func_cap` take an unshifted capability index in `opmod` and shift `opmod << 1` internally. [F742, F743, F838]
- `mlx5_modify_nic_vport_mac_list` and `mlx5_modify_nic_vport_vlans` must reject `list_size` exceeding `1 << MLX5_CAP_GEN(dev, log_max_current_uc_list)`/`mc_list`/`vlan_list` with `-ENOSPC`, whereas `mlx5_query_nic_vport_mac_list` clamps `*list_size` to `max_list_size`. `mlx5_query_hca_vport_gid`/`pkey` must reject index `> tbsz` with `-EINVAL` unless index is `0xffff` (sizing `out_sz` for `tbsz` entries). `mlx5_nic_vport_update_local_lb` must check `disable_local_lb_mc`/`uc` capabilities before setting `field_select`. In `mlx5_query_min_inline`, `MLX5_CAP_INLINE_MODE_VPORT_CONTEXT` must fall through to `MLX5_CAP_INLINE_MODE_L2` if `mlx5_query_nic_vport_min_inline` fails. [F777, F778, F801, F837]

## Error Handling

- In `uar.c`, `alloc_uars_page` must return `ERR_PTR(-EAGAIN)` when `ioremap_wc` fails (`map_wc` is true) so `mlx5_alloc_bfreg` falls back to `map_wc = false`. In `mlx5_hairpin_create_queues` and `mlx5_hairpin_pair_queues`, `out_err_sq` / `err_modify_rq` must reset `i = hp->num_channels` after unwinding `0..i-1` before falling through to unwind the first loop. `mlx5_wq_cyc_wqe_dump` must gate `pr_info` and `print_hex_dump` behind `net_ratelimit()`. [F739, F800, F863]

## External Contracts

- In `mlx5_cqwq_get_wqe`, advance the `struct mlx5_cqe64` pointer by one 64-byte struct when CQE stride is 128 bytes (`cqe += wq->fbc.log_stride == 7`). In `mlx5_cqwq_update_db_record`, mask `wq->cc` with `0xffffff` before `cpu_to_be32`. `mlx5_wq_qp_create` must add 4 to `MLX5_GET(qpc, qpc, log_rq_stride)` and, when `rq_byte_size < PAGE_SIZE`, initialize `wq->sq.fbc` on the shared first page at stride offset `rq_byte_size / MLX5_SEND_WQE_BB`. [F781, F782, F813]
- `dr_ste_v1_set_action_decap_l3_list` and `dr_ste_v3_set_action_decap_l3_list` require `hw_action_sz >= DR_STE_DECAP_L3_ACTION_NUM` (8) double actions and `data_sz` of 14 or 18 bytes, prepending `data_sz % 4` (2) padding bytes before reverse 4-byte inline inserts and a 1-word remove. `dr_ste_v0_set_flex_parser` and `dr_ste_v1_set_flex_parser` must ignore `id >= DR_NUM_OF_FLEX_PARSERS` (8) or used IDs in `parser_is_used[id]`, mapping `0..3` (`<= DR_STE_MAX_FLEX_0_ID`) to `FLEX_PARSER_0` and `4..7` to `FLEX_PARSER_1`. In `dr_ste_v1_set_aso_flow_meter`, convert 1-based `dest_reg_id` via `(dest_reg_id - 1) / 2` and split `offset` by `MLX5DR_ASO_FLOW_METER_NUM_PER_OBJ` (2) into `object_id + (offset / 2)` and `line_id = offset % 2`. [F787, F788, F789]

## Known Pitfalls

- Because `dr_ste_v1_prepare_for_postsend` swaps the 16-byte `tag` and `mask` regions on every 64-byte STE, `dr_ste_v1_set_match_range_pkt_len` must write `min_value_2`/`max_value_2` into `min_value_0`/`max_value_0`. In `dr_ste_v0_set_actions_tx`, call `dr_ste_v0_set_go_back_bit` on the VLAN push STE when `encap` is true and on the encap STE when `MLX5_CAP_GEN(dmn->mdev, prio_tag_required)` is set. [F759, F842]
- Cast `miss_address_39_32` and `miss_address_31_6` to `u64` before `<< 26` and `<< 6` in `dr_ste_v0_get_miss_addr`/`dr_ste_v1_get_miss_addr`; store `uar2pfn` in `phys_addr_t` `pfn` before `pfn << PAGE_SHIFT` in `alloc_uars_page`; and widen `n_ethtype` (`u16`) to `u32` before `<< 16` in `create_action_push_vlan`. In `vport.c`, add `+ 2` to `MLX5_ADDR_OF(..., permanent_address)` and `current_uc_mac_address[i]` for `ether_addr_copy` to skip the 2-byte pad. [F806, F807, F808, F823]
