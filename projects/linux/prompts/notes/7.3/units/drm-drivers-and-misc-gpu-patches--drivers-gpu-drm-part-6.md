# DRM DRIVERS AND MISC GPU PATCHES — drivers/gpu/drm (part 6)

Core DRM infrastructure for `drm_mm`, `drm_pagemap`, PRIME/DMA-BUF, KMS objects/properties, modeset locking, display modes, planes, output probing/polling, DT/DMI/panel quirks, privacy screens, panic rendering, and debug printing.

## Architecture & Data Flow
- `drm_mode_object::free_cb` discriminates refcounted KMS objects from static ones: `__drm_mode_object_add()` initializes `refcount` only when `obj_free_cb` is non-NULL, `drm_mode_object_get()`/`put()` are no-ops when `free_cb` is NULL, and `drm_mode_object_find()` returns `NULL` (not `ERR_PTR`) on miss. `object_idr` IDs must be 1-based (`idr_init_base(..., 1)`, `start = 1`) as ID 0 is the unregistered sentinel. [F261, F303]
- `drm_mm_init()` sets `head_node.start = start + size` and `head_node.size = -size`, relying on u64 wraparound in `__drm_mm_hole_node_start()` (`start + size > start` must not overflow). In `drm_mm_reserve_node()`, `drm_mm_insert_node_in_range()`, and `drm_mm_remove_node()`, update `node->node_list` and call `rm_hole()` before `add_hole()` (which uses `list_next_entry(node, node_list)->start`). Because the interval tree uses inclusive `[START, start + size - 1]`, reserve/insert must reject `size == 0` or `start + size <= start` with `-ENOSPC`. [F280, F307, F308]
- `drm_prime_add_buf_handle()` and `drm_prime_remove_buf_handle()` must insert/erase each `struct drm_prime_member` in both `prime_fpriv->dmabufs` and `prime_fpriv->handles` in lockstep with one `dma_buf` ref per member. [F282]
- `__drm_universal_plane_init()` rejects `num_total_plane >= 32` and `format_count > 64` with `-EINVAL` (32-bit `plane->index` mask and `1ULL << j` in `u64 mod->formats`). `drm_mode_config_validate()` requires `DRIVER_MODESET` devices to have `num_primary == num_crtc`, unique `crtc->primary` matching `drm_crtc_mask(crtc)`, and no CRTC setting both `crtc->cursor` and legacy `cursor_set`/`cursor_set2`/`cursor_move`. In `drm_mode_cursor_universal()`, update `crtc->cursor_x/y` from `req->x/y` only after `__setplane_atomic()` or `__setplane_internal()` succeeds when `DRM_MODE_CURSOR_MOVE` is set. [F293, F342, F414]
- `drm_mode_validate_pipeline()` must continue across `drm_connector_for_each_possible_encoder()` and `drm_for_each_crtc()` when an encoder, bridge, or CRTC rejects `mode`, returning `0` once any combination sets `*status = MODE_OK`. In `drm_connector_list_update()`, when probed `pmode` matches `mode`, `drm_mode_copy(mode, pmode)` preserves `mode->head` while replacing timings if `mode->status == MODE_STALE` or `pmode` is `DRM_MODE_TYPE_PREFERRED` and `mode` is not, before unlinking/destroying `pmode`; use `drm_mode_copy()` for list-linked modes and `drm_mode_init()` for uninitialized stack modes. [F288, F330, F334]
- `drm_mode_parse_cmdline_options()` defaults to `DRM_MODE_ROTATE_0` if `!(rotation & DRM_MODE_ROTATE_MASK)` and validates `is_power_of_2(rotation & DRM_MODE_ROTATE_MASK)`. In `drm_of_component_probe()`, add all CRTC port phandles to `match` in a first loop before a second loop adds child endpoints' remote encoder nodes. [F327, F332]
- In `drm_privacy_screen_get()`, `best` starts at `-1` and `match` resets to `0` per entry, adding `2` for `dev_id` and `1` for `con_id` (skipping non-NULL mismatches) for `dev+con > dev-only > con-only > wildcard` precedence. In `drm_panel_orientation_quirks.c`, `orientation_data[]` must end with `{}` and non-NULL `bios_dates` arrays must end with `NULL`. [F314, F337]
- In `draw_panic_plane()`, pair `drm_panic_set_description()` with `drm_panic_clear_description()` before `drm_panic_unlock()`. `QR_BUFFER1_SIZE` and `QR_BUFFER2_SIZE` must both be `>= 4071` bytes as `qrbuf1`/`qrbuf2` swap between `data_size` (`>= 4071`) and `tmp_size` (`>= 3706`). [F296, F361]

## Synchronization
- Lock order in `drmm_mode_config_init()` is `crtc_ww_class` (`drm_modeset_lock`) -> `mmap_lock` -> `reservation_ww_class` (`dma_resv_lock`). On `-EDEADLK` with non-NULL `ctx`, `drm_modeset_lock()` sets `ctx->contended` and callers must call `drm_modeset_backoff(ctx)` before further lock/drop calls. In `modeset_lock()`, `-EALREADY` converts to `0` without `list_add(&lock->head, &ctx->locked)`. `drm_modeset_lock_all_ctx()` does not lock `dev->mode_config.mutex` (acquire it outside the `ww_mutex` loop). [F228, F229, F322, F384]
- In `drm_gem_prime_fd_to_handle()`, `drm_gem_handle_create_tail()` unlocks `dev->object_name_lock`; if `drm_prime_add_buf_handle()` fails, unlock `file_priv->prime.lock` before `drm_gem_handle_delete()`. In `drm_gem_prime_handle_to_dmabuf()`, checking `obj->handle_count == 0` in `export_and_register_object()` and calling `drm_prime_add_buf_handle()` must both happen under `dev->object_name_lock`. In `drm_gem_map_attach()`/`detach()`, `obj->funcs->pin`/`unpin` run under `dma_resv_lock(obj->resv, NULL)`. [F223, F247, F393]
- Hold `dev->mode_config.idr_mutex` in `__drm_mode_object_add()`, `drm_mode_object_register()`, `drm_mode_object_unregister()`, and `__drm_mode_object_find()` while accessing `object_idr`, `obj->id`, and `kref_get_unless_zero(&obj->refcount)`. Hold `dev->mode_config.mutex` for `drm_mode_probed_add()`, `drm_connector_list_update()`, `drm_helper_probe_single_connector_modes()`, and `check_connector_changed()`, plus `connection_mutex` across `detect_connector_status()`. Always take `connector_list_lock` with `spin_lock_irq`/`irqsave`. [F240, F254, F386]
- Call `drm_kms_helper_hotplug_event()` and `drm_kms_helper_connector_hotplug_event()` with no modeset locks held (otherwise set `delayed_event = true` and schedule `output_poll_work`). `output_poll_execute()` must use `mutex_trylock(&dev->mode_config.mutex)` and unlock before `drm_kms_helper_hotplug_event()`. In poll teardown/suspend, call `drm_kms_helper_disable_hpd(dev)` before `cancel_delayed_work_sync(&output_poll_work)` and only when `poll_enabled` is true; `.detect` callbacks must check `drm_kms_helper_is_poll_worker()` to avoid deadlocking with runtime suspend. [F252, F255, F380, F391]
- `drm_pagemap_migrate_to_devmem()` requires `mmap_assert_locked(mm)`, whereas `drm_pagemap_evict_to_ram()` uses `mmget_not_zero()` / `mmput_async()`. `drm_pagemap_devmem_init()` initializes `detached`, and `drm_pagemap_zdd_destroy()` (called from `drm_pagemap_page_free()` in potentially atomic `put_page()` context) must call `complete_all(&devmem->detached)` before `devmem->ops->devmem_release(devmem)`, which must not sleep. [F256, F257, F397]
- `drm_privacy_screen_unregister()` removes `priv->list` under `drm_privacy_screen_devs_lock` and clears `priv->ops` and `priv->drvdata` under `priv->lock` before `device_unregister()`; consumers must check `priv->ops != NULL` under `priv->lock`. Providers must unlock `priv->lock` after updating `sw_state`/`hw_state` before calling `drm_privacy_screen_call_notifier_chain(priv)`. [F250, F415]
- In `draw_panic_plane()`, `get_scanout_buffer`, `panic_flush`, and `set_pixel` run under `raw_spinlock_t` `panic_lock` with IRQs disabled and must not sleep. Allocations in `drm_mm_reserve_node()`, `drm_mm_insert_node_in_range()`, or `save_stack()` must use `GFP_NOWAIT`. [F381, F399]

## Object Lifetimes
- Foreign import in `drm_gem_prime_import_dev()` attaches, calls `get_dma_buf()`, and maps (LIFO rollback: unmap, detach, `dma_buf_put`), requiring `drm_prime_gem_destroy()` in `funcs->free`. Self-import (`drm_gem_is_prime_exported_dma_buf()`) increments `dma_buf->priv` refcount directly without `get_dma_buf()` or `dma_buf_attach()`. `drm_gem_dmabuf_export()` takes `drm_device` and `drm_gem_object` refs, requiring `drm_gem_dmabuf_release()`. [F221, F222, F404]
- In `drm_plane_force_disable()`, `__setplane_internal()`, and `drm_mode_page_flip_ioctl()`, reset `plane->old_fb = NULL` if the driver callback fails so cleanup does not put the still-bound `plane->fb`. `__drmm_universal_plane_alloc()` requires `funcs->destroy == NULL`, whereas `drm_universal_plane_init()` requires non-NULL `funcs->destroy` and must not use `devm_kzalloc()`. [F231, F371]
- `drm_modeset_register_all()` registers planes, CRTCs, encoders, then connectors; rollback and `drm_modeset_unregister_all()` must unregister in reverse order. Every `drm_for_each_connector_iter()` loop must call `drm_connector_list_iter_end()` on all exits. `drm_mode_config_cleanup()` must call `flush_work(&dev->mode_config.connector_free_work)` after `drm_connector_list_iter_end()` before destroying objects/IDRs, and must not hold `fb_lock` while freeing leaked framebuffers. [F237, F239, F325]
- `drm_of_component_match_add()` calls `of_node_get(node)`, so callers must still `of_node_put(node)`. Early returns/breaks in `for_each_endpoint_of_node()` or `for_each_child_of_node()` in `drm_of.c` must `of_node_put()` the cursor and `remote_port`. `drm_privacy_screen_lookup_add()` entries must stay in non-init memory until `drm_privacy_screen_lookup_remove()`; `drm_panic_setup_logo()` must `kmemdup()` both `struct linux_logo` and `->data` from `fb_find_logo()`. [F234, F235, F373, F374]

## API Contracts
- Zero-initialize `struct drm_mm_node` before `drm_mm_insert_node_in_range()` or `drm_mm_reserve_node()` (neither clears `node->flags`). `__drm_mm_interval_first(mm, start, last)` takes inclusive `last` and returns `&mm->head_node` (never `NULL`) on miss. Pass scanned nodes from `drm_mm_scan_add_block()` to `drm_mm_scan_remove_block()` in exact reverse order before `drm_mm_remove_node()` or `drm_mm_scan_init_with_range()`. [F259, F260, F281]
- Check `obj->type` before `obj_to_connector()`/`crtc()`/`plane()`, `drm_connector_set_obj_prop()`, or `drm_mode_crtc_set_obj_prop()`. Call `drm_object_attach_property()` only before registration. Atomic drivers may call `drm_object_property_set_value()` only on `DRM_MODE_PROP_IMMUTABLE` properties and must use `drm_object_property_get_default_value()` instead of `drm_object_property_get_value()`. [F262, F358, F369]
- Non-NULL `format_modifiers` in `drm_universal_plane_init()`/alloc wrappers must end with `DRM_FORMAT_MOD_INVALID`. `drm_plane_create_scaling_filter_property()` requires `BIT(DRM_SCALING_FILTER_*)` masks including `BIT(DRM_SCALING_FILTER_DEFAULT)`; `drm_plane_add_size_hints_property()` requires `DRM_PLANE_TYPE_CURSOR`. In `__setplane_check()`/`internal()`/`atomic()`, `crtc_x/y/w/h` are integer pixels (checked against `INT_MAX`) and `src_x/y/w/h` are 16.16 fixed-point. [F269, F302, F305]
- `drm_prime_sg_to_page_array()` and `drm_prime_sg_to_dma_addr_array()` return `-1` (`WARN_ON`) if pages exceed `max_entries`. `drm_gem_map_attach()` with `drm_gem_map_dma_buf()` requires `obj->funcs->get_sg_table != NULL` (else `-ENOSYS`) and maps with `DMA_ATTR_SKIP_CPU_SYNC`. [F272, F405]
- `drm_helper_probe_detect(connector, ctx, force)` returns positive `enum drm_connector_status` when `ctx == NULL`, or `-EDEADLK` / `< 0` when `ctx != NULL`. `drm_connector_mode_valid()` and `drm_mode_validate_pipeline()` put mode rejection in `*status` (`MODE_OK == 0`) and return non-zero `int` only on locking errors (`-EDEADLK`). `drm_display_mode::clock` is kHz while `drm_analog_tv_mode()`'s `pixel_clock_hz` and `videomode::pixelclock` are Hz; `drm_gtf_mode_complex()` takes `GTF_2C` and `GTF_2J` as `2 * C` and `2 * J`. [F274, F275, F277]
- `drm_privacy_screen_get()` and `drm_get_panel_backlight_quirk()` return `ERR_PTR` (never `NULL`) on failure, whereas `drm_get_panel_orientation_quirk()` returns `DRM_MODE_PANEL_ORIENTATION_UNKNOWN`; `drm_privacy_screen_put()`/`unregister()` accept `NULL` or `ERR_PTR`. Bound `struct drm_panic_line` access by `line->len` (not NUL) in `draw_txt_rectangle()`/`draw_line_with_wrap()`, and clamp `nbits` to `BITS_PER_TYPE(value)` in `drm_print_bits()`. [F273, F278, F315, F363]

## Error Handling
- In `drm_mode_page_flip_ioctl()`, `out:` must put and reset `fb = NULL` and `plane->old_fb = NULL` before `-EDEADLK` retry, failure must free `e` via `drm_event_cancel_free()`, and `drm_crtc_vblank_put(crtc)` runs only after the retry loop exits on error. `drm_mode_convert_umode()` must reject `in->clock > INT_MAX` or `in->vrefresh > INT_MAX` with `-ERANGE`. [F232, F349]

## External Contracts
- `__drm_mode_object_find()` checks `_drm_lease_held()` for CRTCs, connectors, and planes; legacy ioctls using `crtc->cursor` or `crtc->primary` must check `drm_lease_held()` explicitly. `drm_mode_getresources()`, `drm_mode_getplane_res()`, `drm_mode_getplane()`, and `drm_mode_object_get_properties()` must filter by client capabilities and leases on both passes, advancing `count` only for eligible entries, guarding `put_user()` with `count < user_capacity`, and counting past `user_capacity`. [F326, F408, F410]
- `drm_mode_convert_umode()` must mask `out->type` with `DRM_MODE_TYPE_ALL` and strip `DRM_MODE_FLAG_PIC_AR_MASK` from `out->flags` before `drm_mode_validate_driver()`, and both `drm_mode_convert_to_umode()` and `drm_mode_convert_umode()` must copy `name` via `strscpy_pad()`. [F311, F367]
- `drm_mode_page_flip_ioctl()` must reject `!(flags & DRM_MODE_PAGE_FLIP_TARGET)` when `sequence != 0` and `(flags & DRM_MODE_PAGE_FLIP_TARGET) == DRM_MODE_PAGE_FLIP_TARGET`. `FB_DAMAGE_CLIPS` (`drm_plane_get_damage_clips()`) uses integer framebuffer `drm_mode_rect`s with inclusive `(x1, y1)` and exclusive `(x2, y2)`. On non-Alpha, `drm_get_pci_domain()` returns `0` when `dev->if_version < 0x10004`. [F306, F316, F333]

## Known Pitfalls
- In `drm_mm_insert_node_in_range()`, extract and mask out `DRM_MM_INSERT_ONCE` from `mode` before `first_hole()`/`next_hole()` and step to `NULL` when `once` is true. In `drm_mm_scan_color_evict()`, check `&hole->hole_stack == &mm->hole_stack` after `list_for_each_entry()`. In `drm_mm_insert_node_in_range()` and `drm_mm_scan_add_block()`, normalize `alignment <= 1` to `0` and use `div64_u64_rem()` for non-power-of-two `u64` alignment. [F318, F319, F341]
- In `drm_mode_parse_cmdline_res_mode()`, `remaining = length - (end_ptr - str_start)` must be signed `int` checked for `< 0`. In `drm_mode_parse_command_line_for_connector()`, loop `while (bpp_ptr && !isdigit(bpp_ptr[1]))` to skip hyphens in named modes. Option parsers in `drm_mode_parse_cmdline_options()` must check `*delim == '='` before `delim + 1`. [F312, F331, F366]
- `drm_mode_vrefresh()` must check `htotal == 0 || vtotal == 0`, `check_mul_overflow()`, and use `DIV_ROUND_CLOSEST_ULL(mul_u32_u32(num, 1000), den)`. `fill_analog_mode()` and `drm_cvt_mode()` must widen `line_duration_ns * pixel_clock_hz` and `htotal * HV_FACTOR * 1000` to `u64` with `do_div()`, and `fill_analog_mode()` must use `DIV_ROUND_UP(..., pixel_duration_ns)` for `hslen`, `hfp_min`, and `hbp_min`. [F346, F347, F348]
- In `__drmm_universal_plane_alloc()` and `__drm_universal_plane_alloc()`, `plane` is `container + offset`: pass `container` to `kfree()` on error, but register `drmm_universal_plane_alloc_release()` with `plane`. `drm_mode_cursor_ioctl()` must copy only `sizeof(struct drm_mode_cursor)` into `struct drm_mode_cursor2 new_req` and zero `hot_x`/`hot_y`. `DRM_MODE_PAGE_FLIP_TARGET_ABSOLUTE` must check `(int)(target_vblank - current_vblank) > 1`. [F345, F356, F359]
- `drm_helper_move_panel_connectors_to_head()` must use `list_for_each_entry_safe()`, `list_move_tail()` onto a temp list, and `list_splice()`. In `drm_pagemap`, scale `void *buf` offsets by `sizeof(*src) * npages`, but add unscaled `npages` to typed `unsigned long *migrate.src`. In `drm_panic_get_qr_code_url()`, when `stream.total_out > max_qr_data_size` after `zlib_deflateEnd()`, advance `kmsg` past `'\n'` and recompute `kmsg_len` before `try_again`. Monochrome 1-bpp pitches in `drm_panic.c` require `DIV_ROUND_UP(width, 8)`, and `__drm_printfn_coredump()`'s `snprintf()` fast path requires `len < iterator->remain`. [F336, F338, F352, F357, F364]
