# NETFILTER — net/netfilter (part 7)

This unit implements `nf_tables` expressions and stateful objects (`nft_last` through `nft_xfrm`), the four `nf_tables` set backends (`nft_set_bitmap.c`, `nft_set_hash.c`, `nft_set_pipapo.c` with AVX2 in `nft_set_pipapo_avx2.c`, and `nft_set_rbtree.c`), and core Netfilter checksum and routing utilities (`utils.c`).

## Architecture & Data Flow

- Every set element struct (`nft_bitmap_elem`, `nft_rhash_elem`, `nft_hash_elem`, `nft_rbtree_elem`, `nft_pipapo_elem`) must put `struct nft_elem_priv priv` at offset 0 and `struct nft_set_ext ext` last, with `ops.elemsize = offsetof(..., ext)`. Under `CONFIG_MITIGATION_RETPOLINE`, `__nft_set_do_lookup()` dispatches every `nft_set_type.ops` directly before `WARN_ON_ONCE(1)`, so new backends must be added there. [F205, F264]
- `pipapo_realloc_scratch()` allocates per-CPU `struct nft_pipapo_scratch` with `struct_size(scratch, __map, bsize_max * 2) + NFT_PIPAPO_ALIGN_HEADROOM` and stores the unaligned pointer in `clone->scratch` for `pipapo_free_scratch()`, so `pipapo_get_slow()` and `pipapo_get_avx2()` must align `&scratch->__map[0]` via `NFT_PIPAPO_LT_ALIGN`. `nft_pipapo_insert()` must succeed in `pipapo_realloc_scratch(m, bsize_max)` before updating `m->bsize_max`, and `pipapo_resize()` must round `DIV_ROUND_UP(rules, BITS_PER_LONG)` up to `NFT_PIPAPO_ALIGN / sizeof(*new_lt)`. [F188, F245, F256]
- Before multi-field PIPAPO lookups, `pipapo_resmap_init()` sets `res_map[0 .. m->f->bsize - 1]` to `ULONG_MAX` and zeroes `res_map[m->f->bsize .. m->bsize_max - 1]` (which `pipapo_resmap_init_avx2()` also zeroes). In `pipapo_refill()`, when `!match_only`, every scanned `map[k]` must be cleared to `0` (even when returning `-1` on `i >= rules`) because `pipapo_get_slow()` swaps `res_map` and `fill_map`. [F164, F234]
- `union nft_pipapo_map_bucket` in `f->mt` holds `{ .to, .n }` ranges on intermediate fields and `struct nft_pipapo_elem *e` only on the last field (`i == m->field_count - 1`). `pipapo_drop()` must cut `rulemap[i].n` bits at `rulemap[i].to` from `f->lt` via `bitmap_cut()`, compact `f->mt` via `pipapo_unmap()` (subtracting `rulemap[i + 1].n` from `mt[].to` only on non-last fields), and decrement `f->rules`. `nft_pipapo_remove()` must verify `f->mt[rulemap[i].to].e == e` on the last field after `pipapo_match_field()` before calling `pipapo_drop()`. [F166, F187, F227]
- `nft_pipapo_lookup()` and `nft_pipapo_avx2_lookup()` on `priv->match` must pass `0` as `genmask` to `pipapo_get_slow()` / `pipapo_get_avx2()` because new-generation entries live only in `priv->clone` until `nft_pipapo_commit()`. Key pointer loops across concatenated fields in `pipapo_get_slow()`, `pipapo_get_avx2()`, `nft_pipapo_insert()`, and `nft_pipapo_remove()` must advance by `NFT_PIPAPO_GROUPS_PADDED_SIZE(f)` bytes. [F182, F260]
- `nft_bitmap_estimate()` rejects `desc->klen > 2`, `nft_bitmap_location()` shifts the key left by 1 (`k <<= 1`) for two generation bits per key, and `nft_bitmap_insert`, `nft_bitmap_remove`, `nft_bitmap_activate`, `nft_bitmap_deactivate`, and `nft_bitmap_flush` must update `(genmask << off)` in `priv->bitmap[idx]` in lockstep with `priv->list` and `be->ext`. [F193, F216]
- In `__nft_rbtree_insert()`, when visiting a key-equal start node (`d == 0` and `!nft_rbtree_interval_end(rbe)`) while `rbe_ge` already holds a key-equal node, `rbe_ge` must only be updated to `rbe` if `rbe_ge` and `new` share interval start/end polarity. [F230]
- `nft_rhash_walk_update()` must set `set->in_update_walk = true` during `walk_list` iteration (rejecting recursion with `-EMLINK`) and call `init_llist_node(&he->walk_node)` on every dequeued element even after `iter->err` is set. In `nft_rhash_expr_needs_gc_run()`, `expr->ops->gc()` must only trigger GC when `set->flags & NFT_SET_EVAL` is set. [F192, F225]
- Expressions copying `priv->len` bytes into 32-bit registers `dest` (`nft_payload_eval()`, `nft_payload_inner_eval()`) must zero `dest[priv->len / NFT_REG32_SIZE]` when `priv->len % NFT_REG32_SIZE != 0`; string writes (`nft_meta_get_eval_kind()`, `nft_meta_store_ifname()`, `nft_osf_eval()`) must use `strscpy_pad()` with `IFNAMSIZ` or `NFT_OSF_MAXGENRELEN`. [F175, F210]
- `nft_payload_set_eval()` must check `offset + priv->len <= skb->len` (or `NFT_BREAK`) before `skb_checksum()`. In `nft_payload_l4csum_offset()`, `IPPROTO_UDP` must check `nft_payload_udp_checksum()` and return `-1` if `uh->check == 0` before falling through to `IPPROTO_UDPLITE`. In `nft_payload_l4csum_update()`, when `skb->ip_summed == CHECKSUM_COMPLETE`, `nft_csum_replace(&sum, fsum, tsum)` must be paired with `skb->csum = ~csum_add(csum_sub(~(skb->csum), fsum), tsum)`. [F198, F208, F240]
- In `nft_payload_copy_vlan()`, when `offset < VLAN_ETH_HLEN`, `ethlen` must be clamped to `VLAN_ETH_HLEN - offset` before copying from `struct vlan_ethhdr veth` (copying any remainder from `skb` at `ETH_HLEN + mac_off`); when `offset >= VLAN_ETH_HLEN`, subtract `VLAN_HLEN` from `offset`. [F211]
- In `nf_ip6_check_hbh_len()`, the `while (len > 0)` loop must advance `off++` and `len--` on `IPV6_TLV_PAD1` and for other options verify `len >= 2` and `optlen = nh[off + 1] + 2 <= len`; for `IPV6_TLV_JUMBO`, it must verify `nh[off + 1] == 4`, `(off & 3) == 2`, `pkt_len > IPV6_MAXPLEN`, `!ipv6_hdr(skb)->payload_len`, and `pkt_len <= skb->len - sizeof(struct ipv6hdr)` before `*plen = pkt_len`. [F207, F236]
- In `nft_tunnel_obj_opts_init()`, `type` prevents mixing option kinds (`VXLAN`/`ERSPAN` require `type == 0`; `GENEVE` requires `0` or `IP_TUNNEL_GENEVE_OPT_BIT`). `nft_tunnel_opts_geneve_policy[NFTA_TUNNEL_KEY_GENEVE_DATA]` caps `.len` at 127, and `nft_tunnel_obj_geneve_init()` must check `data_len % 4 == 0` and cumulative `opts->len <= IP_TUNNEL_OPTS_MAX`. [F212, F237]
- In `nft_nat_init()`, `nft_masq_init()`, and `nft_redir_init()`, if `priv->sreg_*_min` is set without `*_MAX`, set `priv->sreg_*_max = priv->sreg_*_min`. In `nft_quota_do_dump()`, when `reset` is true, `atomic64_sub(consumed, &priv->consumed)` and `clear_bit(NFT_QUOTA_DEPLETED_BIT, &priv->flags)` must run after `nla_put_*` succeeds. [F178, F203]
- `nft_limit_init()` must reject `priv->rate == 0` (`-EINVAL`) before `div64_u64()`. `nft_xfrm_get_init()` rejects `spnum >= XFRM_MAX_DEPTH` (`-ERANGE`) and `nft_xfrm_get_eval_in()` checks `sp && sp->len > priv->spnum`. `nft_reject_init()` rejects `icmp_code > NFT_REJECT_ICMPX_MAX` (`-EINVAL`) for `NFT_REJECT_ICMPX_UNREACH`. `nft_socket_eval()`, `nft_meta_get_eval_skugid()`, and `nft_meta_get_eval_cgroup()` must ignore `skb->sk` if `!net_eq(nft_net(pkt), sock_net(sk))`. [F221, F222, F242, F299]

## Synchronization

- Callers of `pipapo_get_avx2()` (`nft_pipapo_avx2_lookup()`, `pipapo_get()`) must call `local_bh_disable()` and check `irq_fpu_usable()` first, and `pipapo_get_avx2()` must bracket AVX2 work with `kernel_fpu_begin_mask(0)` / `kernel_fpu_end()`. Every return path in `pipapo_get_slow()` and `pipapo_get_avx2()` after `__local_lock_nested_bh(&scratch->bh_lock)` must save `scratch->map_index = map_index` (inside the field loop), call `kernel_fpu_end()` (in AVX2), and unlock `scratch->bh_lock` (plus `local_bh_enable()` in `pipapo_get_slow()`). [F145, F153]
- In `nft_rhash_gc()`, `READ_ONCE(nft_net->gc_seq)` must be sampled before walking `priv->ht` and rechecked per element (aborting via `nft_trans_gc_destroy(gc)` if changed), `priv->wq_gc_seq` must be incremented to non-zero and stamped onto `he->wq_gc_seq` to skip duplicates across resize restarts, and `nft_trans_gc_catchall_async()` must precede `rhashtable_walk_stop(&hti)`. `nft_rhash_destroy()` must call `cancel_delayed_work_sync(&priv->gc_work)` before `rhashtable_free_and_destroy(&priv->ht, ...)`. [F157, F226, F278]
- `nft_rhash_walk_update()` must queue elements onto `walk_list` via `he->walk_node` under RCU and invoke `iter->fn` only after `rhashtable_walk_stop()` and `rhashtable_walk_exit()`. In `nft_bitmap_elem_find()`, `nft_bitmap_walk()`, and `nft_hash_walk()`, `lockdep_is_held(&nft_pernet(net)->commit_mutex)` must be passed to `list_for_each_entry_rcu()` / `hlist_for_each_entry_rcu()`. [F275, F276]
- `nft_set_do_lookup()` must sample `base_seq = nft_base_seq(net)` inside the `do { ... } while` loop before `__nft_set_do_lookup()`, retrying on `NULL` while `nft_lookup_should_retry(net, base_seq)`. `nft_limit_eval()` must use `spin_lock_bh(&priv->limit->lock)` around `priv->limit->tokens` and `priv->limit->last`. [F238, F286]

## Object Lifetimes

- In `nft_pipapo_destroy()`, when `priv->clone` is non-NULL, call `nft_set_pipapo_match_destroy()` only on `priv->clone` (never on `priv->match`, which shares `nft_pipapo_elem` pointers) and `pipapo_free_match()` on both. In `nft_pipapo_do_walk()` and `nft_set_pipapo_match_destroy()`, skip rules where `r < f->rules - 1 && f->mt[r + 1].e == f->mt[r].e`. [F183, F233]
- In `pipapo_resize()`, if `pipapo_realloc_mt()` fails, `kvfree(new_lt)` without modifying `f->lt` or `f->bsize`, and `kvfree(old_lt)` only after `pipapo_realloc_mt()` succeeds. In `nft_rhash_update()`, if `rhashtable_lookup_get_insert_key()` fails or returns `prev != NULL` after `nft_dynset_new()`, call both `nft_set_elem_destroy(set, &he->priv, true)` and `atomic_dec(&set->nelems)`. [F137, F143]
- In `nft_tunnel_obj_init()`, free `md` with `metadata_dst_free(md)` if `dst_cache_init()` fails; in `nft_tunnel_obj_eval()`, call `skb_dst_drop(skb)` and `dst_hold((struct dst_entry *)priv->md)` before `skb_dst_set()`. In `nft_synproxy_do_init()`, if `nf_synproxy_ipv6_init()` fails in `NFPROTO_INET`, call `nf_synproxy_ipv4_fini()` before `nf_ct_netns_put()`. [F135, F136]
- `nft_objref_deactivate()` must skip `nft_use_dec(&obj->use)` when `phase == NFT_TRANS_COMMIT`. In `nft_secmark_obj_init()`, `security_secmark_refcount_inc()` runs after `nft_secmark_compute_secid()`, so init error only calls `kfree(priv->ctx)`, whereas `nft_secmark_obj_destroy()` calls `security_secmark_refcount_dec()` and `kfree(priv->ctx)`. [F148, F149]

## API Contracts

- Across `nft_set_ops`: `->get()` returns `ERR_PTR(-ENOENT)` (never `NULL`) on a miss while `->lookup()` and `->deactivate()` return `NULL`; `->insert()` returning `-EEXIST` must assign `*elem_priv` to the existing element; `.walk` must call `iter->fn` without pre-filtering by `nft_set_elem_active()`, and `.activate` must call `nft_clear(net, &ext)`; and control-plane `.insert`, `.deactivate`, `pipapo_gc`, and `nft_rbtree_gc` must check expiration against `nft_net_tstamp(net)` via `__nft_set_elem_expired()`. [F171, F172, F194, F195]
- `nft_set_rbtree_type.ops` must implement `nft_rbtree_ksize`, `nft_rbtree_usize`, and `nft_rbtree_adjust_maxsize` for its two-nodes-per-interval layout. Control-plane allocations for user-created `nf_tables` state must use `GFP_KERNEL_ACCOUNT`. [F191, F304]
- In PIPAPO: callers of `pipapo_get_boundaries()` (`pipapo_match_field()`) must zero-initialize `left` and `right`; `pipapo_unmap()` must use `memmove()` (not `memcpy()`) when shifting `mt`; and `__bitmap_and()` / `bitmap_cut()` take bit counts (`f->bsize * BITS_PER_LONG`) while `pipapo_refill()` takes word counts (`f->bsize`). [F168, F259, F269]
- `nft_meta_inner_ops` and `nft_payload_inner_ops` leave `.eval = NULL` (using 4-arg `nft_meta_inner_eval()` / `nft_payload_inner_eval()`). `nft_payload_select_ops()` selects `&nft_payload_fast_ops` only when `len <= 4`, `is_power_of_2(len)`, `IS_ALIGNED(offset, len)`, and `base` is network/transport header. When `skb_vlan_tag_present(skb)` and `NFT_PAYLOAD_LL_HEADER` reads/writes past `offsetof(struct ethhdr, h_proto)`, `nft_payload_eval()` and `nft_payload_set_eval()` must use `nft_payload_copy_vlan()` / `nft_payload_set_vlan()` and adjust offsets by `VLAN_HLEN`. [F263, F294, F296]
- In `nft_payload_set_eval()`, `NFT_PAYLOAD_CSUM_INET` and `priv->csum_flags` must compute `fsum = skb_checksum(skb, offset, priv->len, 0)` before `skb_store_bits()`, whereas `NFT_PAYLOAD_CSUM_SCTP` calls `nft_payload_csum_sctp()` after `skb_store_bits()`. Callers of `nf_ip6_check_hbh_len(skb, &pkt_len)` must initialize `pkt_len` to `ntohs(ipv6_hdr(skb)->payload_len)` first. [F179, F297]
- `nft_objref_ops` and `nft_objref_map_ops` must validate object types in `nft_objref_validate_obj_type()` (restricting `NFT_OBJECT_SYNPROXY` to IPv4/IPv6/inet and `NF_INET_LOCAL_IN | NF_INET_FORWARD`), and family-agnostic `.validate` callbacks checking `NF_INET_*` hooks (`nft_nat_validate`, `nft_rt_validate`, `nft_socket_validate`, `nft_synproxy_validate`, `nft_tproxy_validate`, `nft_xfrm_validate`) must reject non-IP/inet `ctx->family` with `-EOPNOTSUPP`. `nft_socket_cgroup_subtree_level()` must only be called from process context (`nft_socket_init()`). [F284, F289, F290]

## Error Handling

- In PIPAPO, `m->scratch` is `struct nft_pipapo_scratch * __percpu *`, so dereference `*raw_cpu_ptr(m->scratch)` or `*get_cpu_ptr(m->scratch)` and check for `NULL`. On the final field (`last == true`) in `pipapo_get_slow()` and `pipapo_get_avx2()`, if `e = f->mt[ret].e` is expired or inactive for `genmask`, jump to `next_match` (`pipapo_refill()`) and return `NULL` if `ret < 0`. [F163, F165]
- PIPAPO `lt` allocations must use `lt_calculate_size()` (overflow-checked and capped at `INT_MAX`), and `pipapo_estimate_size()` must verify `if (size && div_u64(size, desc->size) != entry_size) return 0;` with callers rejecting `est->size == 0`. [F243, F254]
- `nft_payload_inner_init()` and `nft_meta_inner_init()` must check required `tb[]` attributes for `NULL` since `nft_expr_inner_parse()` skips `select_ops()`. In `nft_payload_l4csum_update()`, `nft_payload_l4csum_offset() < 0` must return `0`, whereas `skb_copy_bits()`, `skb_ensure_writable()`, or `skb_store_bits()` failures return `-1`. [F174, F180]
- `cgroup_get_from_path("/")` in `nft_socket_cgroup_subtree_level()` returns an `ERR_PTR` (check `IS_ERR()`), and callers must store `nft_socket_cgroup_subtree_level()` in a signed `int` and check `< 0`. `nft_log_init()` and `nft_log_destroy()` must check `priv->prefix != nft_log_null_prefix` before `kfree()` and skip `nf_logger_put()` for `NFT_LOGLEVEL_AUDIT`. [F176, F177]
- `nft_limit_init()` must use `check_mul_overflow()` / `check_add_overflow()` on `unit`, `rate`, and `burst` (returning `-EOVERFLOW`). `nft_queue_init()` must reject `priv->queues_total == 0` (`-EINVAL`) and `(u32)priv->queues_total - 1 + priv->queuenum > U16_MAX` (`-ERANGE`). [F241, F250]

## External Contracts

- `nft_tunnel_opts_dump()` must wrap each `struct geneve_opt` in its own `NFTA_TUNNEL_KEY_OPTS_GENEVE` nest inside the `while (opts->len > offset)` loop. `nft_overquota()` triggers only at `consumed > quota`, while depletion reporting and `nft_quota_do_dump()` capping `consumed_cap = quota` with `NFT_QUOTA_F_DEPLETED` trigger at `consumed >= quota`. `nft_socket_init()` saves `NFTA_SOCKET_LEVEL` in `priv->level_user` for `nft_socket_dump()` and adds `nft_socket_cgroup_subtree_level()` to `priv->level`. [F213, F214, F302]

## Known Pitfalls

- In `nf_ip6_check_hbh_len()`, refresh `nh = skb_network_header(skb)` and `ipv6_hdr(skb)` after `pskb_may_pull(skb, off + len)`. In `nft_tunnel_obj_geneve_init()` and `nft_tunnel_opts_dump()`, add byte offsets (`opts->len`, `offset`) to `u8 *` `opts->u.data` before casting to `struct geneve_opt *`. [F196, F255]
- In `pipapo_clone()`, `memcpy(dst, src, offsetof(struct nft_pipapo_field, lt))` requires all scalar fields in `struct nft_pipapo_field` to precede `lt`. In `nft_pipapo_avx2_fill()`, evaluate `~0UL >> (BITS_PER_LONG - len)` only when `1 <= len && len <= BITS_PER_LONG`. [F246, F258]
- `nft_hash_buckets()` must widen `size` to `u64` in `div_u64((u64)size * 4, 3)` and cap at `NFT_MAX_BUCKETS` before `roundup_pow_of_two()`, and `nft_hash_privsize()` / `nft_hash_estimate()` must multiply in `u64`. `nft_last_dump()` must check `time_before(jiffies, last_jiffies)` before `jiffies - last_jiffies`. [F247, F252]
