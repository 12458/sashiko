# FILESYSTEMS (VFS and infrastructure) — (top level)

Defines the primary kernel and UAPI VFS headers (`include/linux/fs.h`, `include/linux/fs_types.h`, `include/uapi/linux/fs.h`, `include/uapi/linux/openat2.h`), early boot root filesystem and initramfs/initrd mounting (`init/do_mounts*.c`, `init/initramfs*.c`), and safe Rust abstractions for VFS files, file descriptors, `kiocb`, `seq_file`, and `poll_table` (`rust/kernel/fs*.rs`, `rust/kernel/seq_file.rs`, `rust/kernel/sync/poll.rs`).

## Architecture & Data Flow

- `File`, `LocalFile`, and `SeqFile` must remain `#[repr(transparent)]` wrappers around `Opaque<bindings::file>` and `Opaque<bindings::seq_file>` because `File::from_raw_file`, `LocalFile::from_raw_file`, `LocalFile::assume_no_fdget_pos`, `AlwaysRefCounted::dec_ref`, and `SeqFile::from_raw` cast raw C pointers directly to and from wrapper pointers. Broken by: removing `#[repr(transparent)]` or adding a non-ZST field. [F457]
- `file_dentry(file)` requires `d_inode(file->f_path.dentry) == file_inode(file)`. For backing files on stackable filesystems (`f->f_mode & FMODE_BACKING`) whose `f_inode` belongs to the underlying filesystem, use `file_user_path(f)` and `file_user_inode(f)` for the user-visible path/inode. `backing_file_user_path(f)` uses `container_of()` to downcast to `struct backing_file`, so callers must verify `f->f_mode & FMODE_BACKING` first, and `FMODE_BACKING` must never be set on a normal `filp_cachep` file. [F413, F452]
- `FMODE_FSNOTIFY_HSM(exe_file->f_mode)` must remain constant across the lifetime of an open `exe_file` (do not mutate `FMODE_NONOTIFY` or `FMODE_NONOTIFY_PERM` after open), and `exe_file_deny_write_access()` must be paired with `exe_file_allow_write_access()` (not `allow_write_access()`) so `inode->i_writecount` is untouched when `FMODE_FSNOTIFY_HSM` is true. [F414]
- `super_block::s_uuid_len` must never exceed `sizeof(sb->s_uuid)` (16 bytes); filesystems with variable-length UUIDs must use `super_set_uuid()` so `FS_IOC_GETFSUUID` (`ioctl_getfsuuid()`) does not overflow `struct fsuuid2::uuid`. `super_set_sysfs_name_uuid(sb)` requires `sb->s_uuid_len == sizeof(sb->s_uuid)` (set via `super_set_uuid()`), and `sb->s_sysfs_name` must not be modified at runtime once registered. [F416, F423]
- In `struct file_handle`, `f_handle[]` is annotated with `__counted_by(handle_bytes)`, so code allocating or populating `struct file_handle` must set `handle_bytes` before indexing or copying into `f_handle[]`. [F456]
- In `init/initramfs.c`, `do_header()` must bound `name_len` to `1..=PATH_MAX` and `S_ISLNK(mode)` `body_len` to `<= PATH_MAX`, and must collect symlinks into `symlink_buf` (`state = Collect`) rather than `read_into(symlink_buf, ..., GotSymlink)`, because `do_symlink()` writes `collected[N_ALIGN(name_len) + body_len] = '\0'`. [F420]
- In `init/initramfs.c`, when `do_name()` opens a regular file (`S_ISREG(mode)`), it must omit `O_TRUNC` from `openflags` when `maybe_link()` returns `1` (existing hardlink linked) and only truncate when `body_len` is non-zero. [F405]
- In `init/initramfs.c`, `unpack_to_rootfs()` must save `this_header` and reset `this_header = 0` before calling `decompress()`, require `state == Reset` upon completion, and restore `this_header = saved_offset + my_inptr` before continuing the outer loop. [F406]
- During initramfs extraction, directory mtime updates must be deferred by recording directories with `dir_add()` into `dir_list` and applying `do_utime()` in `dir_utime()` via `list_for_each_entry_safe()` after the archive loop completes, rather than calling `do_utime()` in `do_name()`. [F437]
- In `init/do_mounts.c`, `wait_for_root` must guard `ktime_after(ktime_get_raw(), end)` with `root_wait > 0`, because `root_wait == -1` indicates an indefinite wait (`rootwait` without timeout or fallback from invalid `rootwait=`). [F440]

## Synchronization

- Because `struct file` uses a `SLAB_TYPESAFE_BY_RCU` cache (aliasing `f_freeptr` with `f_task_work`, `f_llist`, and `f_ra`), lockless RCU readers must acquire references via `get_file_rcu(&f)` or `get_file_active(&f)`, never `get_file(f)`. [F474]
- Callers of `i_size_write` must hold an exclusive per-inode lock serializing size updates (typically `inode->i_rwsem`); on 32-bit SMP `i_size_write` updates `inode->i_size_seqcount` without internal locking, so concurrent writers corrupt the seqcount and cause `i_size_read` to spin forever. [F468]
- Freeze protection started with `kiocb_start_write(iocb)` must be released with `kiocb_end_write(iocb)` (never `sb_end_write` or `file_end_write`), because `kiocb_start_write` calls `__sb_writers_release` and `kiocb_end_write` must call `__sb_writers_acquired` before `sb_end_write` to balance lockdep tracking across async I/O. [F470]
- `struct file.f_lock` is a non-IRQ-safe spinlock protecting `f_ep` and `f_flags` and must never be acquired from hardirq context. [F467]
- Callbacks running in non-blocking or RCU contexts must not sleep: `inode_operations.permission` when `mask & MAY_NOT_BLOCK` is set (return `-ECHILD` instead of blocking); `inode_operations.get_inode_acl` when its `bool` rcu argument is `true` (enabled when a filesystem sets `i_acl` or `i_default_acl` to `ACL_DONT_CACHE`); and `address_space_operations.migrate_folio` when `mode == MIGRATE_ASYNC`. [F463, F464, F466]
- In `populate_rootfs()`, `initramfs_cookie` must be assigned from `async_schedule_domain(do_populate_rootfs, NULL, &initramfs_domain)` before `usermodehelper_enable()` is called so `wait_for_initramfs()` cannot miss it. [F381]

## Object Lifetimes

- `FileDescriptorReservation::fd_install` transfers ownership of both `self.fd` and the `ARef<File>` refcount to `bindings::fd_install`, and must call `core::mem::forget` on both `self` and `file` so their destructors (`put_unused_fd` and `fput`) do not run. [F362]
- `<PollCondVar as PinnedDrop>::drop` must call `bindings::__wake_up_pollfree` on `self.inner.wait_queue_head` before `bindings::synchronize_rcu()`, ensuring all waiters registered via `PollTable::register_wait` are removed and an RCU grace period elapses before pinned `wait_queue_head` memory is freed. [F364]
- `unpack_to_rootfs` must call `dir_utime()`, `free_hash()`, and `kfree(bufs)` before returning regardless of whether `"TRAILER!!!"` was encountered or an error occurred, and `free_hash()` must clear `head[]` pointers and reset `hardlink_seen = false`. [F365]
- When `do_name` opens `wfile` with `filp_open` for a regular file (`S_ISREG(mode)`), it must unconditionally transition `state` to `CopyFile` (even when `body_len == 0`) so `do_copy` calls `do_utime_path(&wfile->f_path, mtime)` and `fput(wfile)`. [F366]
- `initrd_load` must unlink `"/initrd.image"` on every return path (whether `mount_initrd` is disabled, `rd_load_image` fails, `ROOT_DEV == Root_RAM0`, or `handle_initrd` runs), and `rd_load_image` must always unlink `"/dev/ram"` on exit. [F373]

## API Contracts

- `File::from_raw_file` and `LocalFile::from_raw_file` borrow `&'a File` / `&'a LocalFile` without incrementing `f_ref` (requiring a positive refcount for `'a`), whereas `LocalFile::fget` acquires a new refcount via `bindings::fget` owned by `ARef<LocalFile>`. Callers of `File::from_raw_file` and `LocalFile::assume_no_fdget_pos` must also guarantee no active `fdget_pos` call omitted `f_pos_lock` (and for `LocalFile::from_raw_file`, any unlocked `fdget_pos` is on the current thread), because `File` is `Send + Sync` and can be shared via `fd_install`. [F363, F458]
- `Kiocb<'a, T>::from_raw` requires `kiocb` to be non-null and valid for `'a`, with `(*kiocb).ki_filp->private_data` holding a foreign pointer created by `<T as ForeignOwnable>::into_foreign`, because `Kiocb::file` unconditionally calls `<T as ForeignOwnable>::borrow` on it. [F459]
- `PollTable` methods must tolerate a null `self.table` pointer because `PollTable::from_raw` permits null `bindings::poll_table` pointers (when polling readiness without registering a wait queue) and passes `self.table` directly to `bindings::poll_wait`. [F462]
- To check or bind to the credentials of the task that opened a file rather than the current worker or caller task, Rust code must use `LocalFile::cred()` (inherited by `File` via `Deref`), which reads `file->f_cred`. [F497]
- `replace_fops(f, fops)` drops the module reference on old `f->f_op` via `fops_put` without acquiring a new module reference on `fops` (and hits `BUG_ON` if `fops` is NULL), so it must only be called from `->open()` where `fops` is non-NULL and already pinned by module dependencies. [F368]
- A `struct file_operations` table must not define both `mmap` and `mmap_prepare`: `can_mmap_file()` treats them as mutually exclusive, triggers `WARN_ON_ONCE(has_mmap && has_mmap_prepare)`, and returns `false` if both are set. Conversely, when neither hook is set, `can_mmap_file()` must return `false` without `WARN_ON_ONCE()` because `mmap()` on an unmappable file is user-triggerable. [F388, F481]
- Callers not already holding a like-signed reference on `inode->i_writecount` or `mapping->i_mmap_writable` must acquire access via `get_write_access`/`deny_write_access` or `mapping_map_writable`/`mapping_deny_writable` and release via `put_write_access`/`allow_write_access` or `mapping_unmap_writable`/`mapping_allow_writable`, never modifying the counters directly without checking sign polarity. [F371]
- Filesystem `super_operations.alloc_inode` callbacks must allocate inodes via `alloc_inode_sb(sb, cache, gfp)` (`kmem_cache_alloc_lru`) rather than `kmem_cache_alloc` so the inode reclaim LRU context is bound to `sb->s_inode_lru`. [F372]
- Filesystems must not modify `inode->i_nlink` (`__i_nlink`) directly; they must use `inc_nlink()`, `drop_nlink()`, `clear_nlink()`, `set_nlink()`, `inode_inc_link_count()`, or `inode_dec_link_count()` to keep `super_block.s_remove_count` and dirty state consistent. [F484]
- Filesystems implementing `inode_operations.setattr` must test `(attr->ia_valid & ATTR_FILE)` rather than `attr->ia_file != NULL` to check whether the change comes from an open-file operation like `ftruncate()`. [F488]
- Filesystems setting `FS_ALLOW_IDMAP` in `file_system_type.fs_flags` must initialize and update `inode->i_uid` and `inode->i_gid` via `mnt_idmap`-aware helpers (`inode_fsuid_set()`, `inode_fsgid_set()`, `i_uid_update()`, `i_gid_update()`, `ia_vfsuid`, `ia_vfsgid`) rather than `current_fsuid()` or `attr->ia_uid`/`attr->ia_gid`. [F489]
- Anonymous inodes requiring LSM security enforcement must be allocated via `anon_inode_make_secure_inode()` rather than `alloc_anon_inode()` alone, which leaves `S_PRIVATE` set on `inode->i_flags` and bypasses LSM checks. [F490]
- Filesystems and block drivers supporting `IOCB_HAS_METADATA` must set `FMODE_HAS_METADATA` on `file->f_mode` at open time, and write paths handling `IOCB_ATOMIC` must validate per-I/O `IOCB_DIRECT` via `generic_atomic_write_valid(iocb, iter)` (not just `FMODE_CAN_ATOMIC_WRITE`) because `O_DIRECT` can be toggled after open via `fcntl()`. [F492]
- In `init/do_mounts.c`, `split_fs_names()` replaces commas with `'\0'` in-place and can yield empty strings, so callers iterating `num_fs` entries (`mount_root_generic`, `mount_nodev_root`) must advance by `strlen(p) + 1` and skip empty entries with `if (!*p) continue;`. [F399]
- In `init/initramfs.c`, `dir_add()` allocates `struct_size(de, name, nlen)` bytes for `struct dir_entry` and copies `name` with `strscpy(de->name, name, nlen)`, so callers must pass `nlen` including the trailing NUL byte (e.g. cpio `name_len`), not `strlen(name)`. [F444]

## Error Handling

- `ACL_NOT_CACHED` (`(void *)(-1)`), `ACL_DONT_CACHE` (`(void *)(-3)`), and `uncached_acl_sentinel(task)` (`(void *)task + 1`) all have bit 0 set (`is_uncached_acl(acl)`), and `ACL_NOT_CACHED`/`ACL_DONT_CACHE` also satisfy `IS_ERR()`. Consumers of `i_acl`, `i_default_acl`, or `get_inode_acl()` must check `is_uncached_acl(acl)` rather than only `if (acl)` or `!IS_ERR_OR_NULL(acl)`. [F390]
- `address_space_operations` callbacks (`read_folio`, `writepage`) can return positive status codes `AOP_WRITEPAGE_ACTIVATE` (`0x80000`, leaving the page locked) or `AOP_TRUNCATED_PAGE` (`0x80001`, having unlocked the page so callers must drop their reference and retry); callers must handle positive returns rather than checking only `< 0`. [F391]
- In `init/initramfs.c`, `xwrite()` returns the positive byte count already written (`return out ? out : rv`) if a subsequent `kernel_write()` fails (other than `-EINTR`/`-EAGAIN`) or returns `0`, so callers must check `xwrite(file, buf, len, &pos) != len` rather than `< 0`. [F395]
- In `init/do_mounts_rd.c`, `identify_ramdisk_image()` returns `< 0` on error/unrecognized image, `0` for a compressed image (where `*decompressor` may still be `NULL` if that algorithm is unconfigured), and `> 0` for image size in 1 KiB units. Callers must not treat `0` as an empty/invalid image or invoke `*decompressor` without a `NULL` check. [F400]
- In `init/do_mounts.c`, `rootwait_timeout_setup` must reject negative `sec` values and use `check_mul_overflow(sec, MSEC_PER_SEC, &root_wait)` before assigning `root_wait`, falling back to `root_wait = -1` (indefinite wait) on parse failure or overflow. [F439]

## Known Pitfalls

- Because `(file->f_mode & FMODE_FSNOTIFY_MASK) == (FMODE_NONOTIFY | FMODE_NONOTIFY_PERM)` suppresses only `FAN_ACCESS_PERM` rather than all events, checks for full fsnotify suppression must test `FMODE_FSNOTIFY_NONE(mode)` (`(mode & FMODE_FSNOTIFY_MASK) == FMODE_NONOTIFY`) rather than `mode & FMODE_NONOTIFY`, and fsnotify mode bits must be set via `file_set_fsnotify_mode()`. [F430]
- When `RWF_SYNC` is set in `kiocb_set_rw_flags()`, `IOCB_DSYNC` must also be set alongside `IOCB_SYNC` in `ki->ki_flags` because `generic_write_sync()` gates synchronisation on `iocb_is_dsync(iocb)` before checking `IOCB_SYNC` (`(iocb->ki_flags & IOCB_SYNC) ? 0 : 1`) to select full sync vs datasync in `vfs_fsync_range()`. [F432]
- `inode_state_wait_address(inode, bit)` computes `(char *)&(inode)->i_state + (bit)`, so `inode_state_wait_address()`, `inode_bit_waitqueue()`, and `inode_wake_up_bit()` must only be passed `enum inode_state_bits` indices (`0..3`, `< sizeof(inode->i_state)`), never shifted `I_*` (`enum inode_state_flags_t`) masks or bit numbers `>= 4`. [F449]
- `is_zero_ino` in `include/linux/fs.h` must check `(u32)ino == 0` rather than `ino == 0` because 32-bit userspace (`_FILE_OFFSET_BITS=32`) on a 64-bit kernel truncates `ino_t` to 32 bits and ignores entries with a zero inode number. [F438]
- In `do_name()` and `do_symlink()`, `collected` may point directly into an untrusted cpio buffer (`victim`) without NUL termination; `collected[name_len - 1] != '\0'` must be checked before passing `collected` to C-string APIs, and logging `collected` on that failure path must use `%.*s` with `(int)name_len` instead of `%s`. [F445]
- When `do_mount_root()` fails with `-EACCES` or `-EINVAL` in `mount_root_generic()`, `init_flush_fput()` must be called before continuing to the next filesystem type or retrying with `SB_RDONLY` so delayed block-device `fput` work finishes before the next mount attempt. [F435]
