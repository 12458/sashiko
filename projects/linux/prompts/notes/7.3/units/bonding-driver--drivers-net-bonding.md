# BONDING DRIVER — drivers/net/bonding

Aggregates slave `net_device`s into a virtual master (`bond%d`) across seven modes (balance-rr, active-backup, balance-xor, broadcast, 802.3ad, balance-tlb, balance-alb), handling enslavement, MII/ARP/NS link monitoring, offloads (VLAN, IPsec, TLS, XDP), and netlink/sysfs/procfs/debugfs config.

## Architecture & Data Flow
- `bond_update_slave_arr()` allocates `usable_slaves`/`all_slaves` (`struct bond_up_slave`) with `struct_size(..., arr, bond->slave_cnt)` under RTNL; in `BOND_MODE_8023AD`, if `bond_3ad_get_active_agg_info()` fails, `bond_reset_slave_arr()` must clear both to `NULL`. Hash readers (`bond_xmit_3ad_xor_slave_get`, `bond_xdp_xmit_3ad_xor_slave_get`) must check `slaves && READ_ONCE(slaves->count)` before `hash % count`. [F76, F107, F140]
- In `bond_alb.c`, `tx_hashtbl` is allocated only while open (`bond_open`..`bond_close`), so functions like `__tlb_clear_slave()` must check `tx_hashtbl != NULL`. Bucket `0` is valid in 256-entry `tx_hashtbl`/`rx_hashtbl`, so all index links must use `TLB_NULL_INDEX`/`RLB_NULL_INDEX` (`0xffffffff`). `rx_hashtbl[i].src_first` heads entries with `ip_src` hashing to `i`, independent of `ip_dst` at `i`: `rlb_delete_table_entry()` must only call `rlb_init_table_entry_dst()` and `rlb_src_unlink()` without resetting `src_first`. [F58, F99, F100]
- In `bond_alb.c`, save `next`/`src_next`/`used_next` before `tlb_init_table_entry()` or `rlb_delete_table_entry()` in `__tlb_clear_slave()`, `rlb_purge_src_ip()`, and `rlb_clear_vlan()`. `rlb_choose_channel()` hashes `arp->ip_dst` and matches `(ip_src, ip_dst)` on TX ARPs; `rlb_update_entry_from_arp()` hashes `arp->ip_src` and matches `client_info->ip_src == arp->ip_dst && client_info->ip_dst == arp->ip_src` on RX ARP replies. `rlb_arp_xmit()` requires `bond_slave_has_mac_rcu(bond, arp->mac_src)` and rejects bridge masters (`ip_dev_find` + `netif_is_any_bridge_master`). [F123, F130, F195]
- `bond_alb_deinit_slave()` must reset `bond->alb_info.rx_slave = NULL` before `rlb_clear_slave()`. `rlb_req_update_slave_clients()` and `rlb_rebalance()` must set `bond_info->rx_ntt = 1` only after the `rx_hashtbl_used_head` loop via a local `ntt` flag. In `BOND_MODE_TLB` (`!rlb_enabled`), `alb_set_mac_address()` and `bond_alb_handle_active_change()` must save `slave->dev->dev_addr` before `dev_set_mac_address()` and restore it with `dev_addr_set()`. [F87, F94, F125]
- In `bond_miimon_inspect()`, initialize `ignore_updelay = false`, set it via `!rcu_dereference(bond->curr_active_slave)` in active-backup or `usable_slaves && usable_slaves->count == 0` in other modes, and reset it to `false` once the first `BOND_LINK_BACK` slave reaches `BOND_LINK_UP`; `BOND_LINK_UP` must fall through to `BOND_LINK_FAIL` and `BOND_LINK_DOWN` to `BOND_LINK_BACK`. In `bond_miimon_commit()` and `bond_ab_arp_commit()`, defer `bond_select_active_slave()` via `do_failover = true` until `bond_for_each_slave` finishes (including when `slave->prio > active->prio`). [F67, F117, F118, F119]
- In wrap-around loops (`bond_ab_arp_probe()`, `__rlb_next_rx_slave()`), set `found = true` when `slave` matches `curr_arp_slave`/`rx_slave` only at loop end after recording `before`. In `bond_arp_rcv()` and `bond_na_rcv()`, when a backup slave validates a probe because `curr_active_slave` received traffic after `last_link_up`, pass `sip`/`tip` or `saddr`/`daddr` in reversed order to `bond_validate_arp()`/`bond_validate_na()`. Compare `last_rx`, `last_tx`, `last_link_up`, and `target_last_arp_rx[]` with `time_in_range()`, `time_after()`, or `time_before()`. [F114, F126, F138]
- `arp_targets` and `ns_targets` are dense zero-terminated arrays; `bond_option_arp_ip_target_rem()` must compact each slave's `target_last_arp_rx` before `arp_targets` (the slave loop tests `targets[i+1]`). In active-backup with `arp_validate`, solicited-node multicast MACs for `ns_targets` are programmed only on backup slaves (`!bond_is_active_slave(slave)`) via `slave_set_ns_maddrs()`: call `bond_slave_ns_maddrs_add()` before `bond_select_active_slave()` in `bond_enslave()`, and `bond_slave_ns_maddrs_del()` after `bond_change_active_slave(bond, NULL)` in `__bond_release_one()`. [F8, F78, F98]
- In `bond_3ad.c`, changes to `lacp_active`, `lacp_fast`, `ad_actor_sys_prio`, `ad_actor_system`, or slave `port_priority` must call `bond_3ad_update_lacp_active()`, `bond_3ad_update_lacp_rate()`, or `bond_3ad_update_ad_actor_settings()` under `spin_lock_bh(&bond->mode_lock)`. `ad_periodic_machine()` gates LACPDUs on `LACP_STATE_LACP_ACTIVITY` in `port->actor_oper_port_state` or `partner_oper.port_state` (not `params.lacp_active`), and `ad_rx_machine()` must not set `LACP_STATE_LACP_ACTIVITY` on `partner_oper.port_state` in `AD_RX_EXPIRED`. [F80, F81]
- In `bond_3ad.c`, `__update_selected()` and `__record_pdu()` compare/copy `lacpdu->actor_*` against `port->partner_oper`, while `__choose_matched()` and `__update_ntt()` compare `lacpdu->partner_*` against `port->actor_*`. In `ad_agg_selection_test()`, `BOND_AD_PRIO` falls through to `BOND_AD_COUNT` on ties, and `BOND_AD_COUNT` to `BOND_AD_STABLE`/`BOND_AD_BANDWIDTH`. `struct lacpdu` and `struct bond_marker` must stay the same 110-byte size for `bond_3ad_lacpdu_recv()` and `ad_marker_info_received()`. [F103, F120, F129]
- For stacked bonds, `bond_netdev_event()` must test `IFF_MASTER` and `IFF_SLAVE` with separate `if`s, `bond_enslave()` must reject `IFF_MASTER` devices where `!netif_is_bond_master(slave_dev)`, and slave release/unwind must clear `IFF_BONDING` only if `!netif_is_bond_master(slave_dev)`. `bond_neigh_setup()` must check `if (parms->dev == dev)` before setting `parms->neigh_setup = bond_neigh_init`. In `bond_enslave()`, randomizing a slave MAC under `BOND_FOM_FOLLOW` + `BOND_MODE_ACTIVEBACKUP` must be guarded by `bond_has_slaves(bond)`. [F116, F131, F149, F150]
- `bond_verify_device_path()` terminates `bond_vlan_tag` arrays with `vlan_proto = BOND_VLAN_PROTO_NONE` (non-VLAN uppers have `vlan_id = 0`); `bond_handle_vlan()` must increment `tags++` on the `!tags->vlan_id` `continue` branch as well as at loop end. Keep SKB and XDP slave selection in sync (`bond_xmit_roundrobin_slave_get` vs `bond_xdp_xmit_roundrobin_slave_get`, `bond_xmit_hash` vs `bond_xmit_hash_xdp`); only call `reciprocal_value()` when `packets_per_slave > 0` and `reciprocal_divide()` in `bond_rr_gen_slave_id()` when `packets_per_slave > 1`. [F96, F106, F127, F137]
- Cap `peer_notif_delay` at `300000` ms with `u32 send_peer_notif` and clamp with `max(1, bond->params.peer_notif_delay)` before modulo/multiplication in `bond_should_notify_peers()`, `bond_change_active_slave()`, and `ad_cond_set_peer_notif()`; check `miimon != 0` before `/` or `%` in `_bond_option_delay_set()` and `bond_check_params()`. In `bond_fold_stats()`, if `((nv | ov) >> 32) == 0`, compute `delta = (s64)(s32)((u32)nv - (u32)ov)` and add only if `delta > 0`. Buffers passed to `bond_slave_has_mac*`, `MAC_ADDRESS_EQUAL`, or `ether_addr_equal_64bits` need 2 bytes of trailing padding (`ETH_ALEN + 2`). [F132, F133, F134, F135, F147]

## Synchronization
- Call `bond_update_slave_arr()` under RTNL with `bond->mode_lock` NOT held; callers holding `mode_lock` without RTNL (`bond_3ad_state_machine_handler`) must defer via `bond_slave_arr_work_rearm()`. `bond->mode_lock` protects all 802.3ad port/aggregator state after `bond_3ad_bind_slave()` and all TLB/ALB `tx_hashtbl`/`rx_hashtbl` accesses (including `bond_debug_rlb_hash_show`). [F30, F37, F38]
- `bond_alb.c` functions calling `dev_set_mac_address()` or `dev_set_promiscuity()` (`alb_swap_mac_addr`, `alb_fasten_mac_swap`, `alb_change_hw_addr_on_detach`, `bond_alb_deinit_slave`, `rlb_teach_disabled_mac_on_primary`) require RTNL with `mode_lock` and RCU not held. In `bond_alb_handle_active_change()`, assign `curr_active_slave` and call `tlb_clear_slave()` on `swap_slave` and `new_slave` before swapping/setting MACs. [F39, F40]
- `bond_ipsec_add_sa_all()` and `bond_ipsec_del_sa_all()` must hold both `bond->ipsec_lock` and `spin_lock_bh(&ipsec->xs->lock)` while checking `xs->km.state != XFRM_STATE_DEAD`, updating `xs->xso.real_dev`, and calling `xdo_dev_state_delete`. Atomic-context `bond_ipsec_del_sa()` (called under `xs->lock`) must not take `bond->ipsec_lock` or touch `bond->ipsec_list`; defer list removal and `kfree(ipsec)` to `bond_ipsec_free_sa()`. [F26, F27]
- Use `rtnl_dereference()` / `bond_slave_get_rtnl()` in RTNL-only paths (`bond_miimon_commit`, `bond_ab_arp_commit`, `bond_change_active_slave`, `bond_select_active_slave`, `bond_slave_netdev_event`), and `rcu_dereference_rtnl()` in dual RCU/RTNL helpers (`bond_should_notify_peers`, `bond_option_active_slave_get_rcu`), never dereferencing after `rcu_read_unlock()`. Cache `READ_ONCE(bond->recv_probe)` in `bond_handle_frame()` (and call `consume_skb(skb)` if it returns `RX_HANDLER_CONSUMED`), and cache `rcu_dereference(tls_get_ctx(skb->sk)->netdev)` in `bond_tls_device_xmit()`. [F22, F46, F166, F167, F168]
- In `bond_get_stats()`, take `spin_lock_nested(&bond->stats_lock, bond_get_lowest_level_rcu(bond_dev))` inside `rcu_read_lock()`. Hold `netif_addr_lock_bh(bond->dev)` around `dev_uc_sync*`/`dev_mc_sync*` in `bond_hw_addr_swap()` and `bond_enslave()`. In `__bond_release_one()` with `unregister == true`, wrap `__netif_set_mtu()` in `netdev_lock_ops(slave_dev)`/`netdev_unlock_ops(slave_dev)`. Use `rtnl_trylock()` + `restart_syscall()` in `bond_opt_tryset_rtnl()`. [F41, F47, F179, F181]

## Object Lifetimes
- Ordering: `bond_create_debugfs()` before `register_pernet_subsys()`/`bond_netlink_init()`, and `bond_destroy_debugfs()` after `bond_netlink_fini()`/`unregister_pernet_subsys()`. In `bond_net_ops`, `bond_destroy_sysfs()` runs in `pre_exit`, bond unregistration in `exit_rtnl`, and `bond_destroy_proc_dir()` in `exit_batch`; `bond_remove_proc_entry()` must clear `bond->proc_entry = NULL` and `proc_file_name`. In `bond_newlink()`, call `register_netdevice()` and `bond_work_init_all()` before `bond_changelink()`, unwinding with `bond_work_cancel_all()` + `unregister_netdevice()` on error. In `bond_alb_initialize()`, call `tlb_deinitialize(bond)` if `rlb_initialize()` fails. [F1, F2, F3, F10, F25]
- In `bond_enslave()`, copy `new_slave->perm_hwaddr` before `bond_alb_init_slave()` (which must precede `bond_master_upper_dev_link()`), call `bond_set_dev_addr()` before `bond_3ad_initialize()`, and allocate `SLAVE_AD_INFO(new_slave)` + call `bond_3ad_bind_slave()` before `netdev_rx_handler_register()` and `bond_master_upper_dev_link()`. [F36, F72, F157]
- In `__bond_release_one()` and `bond_enslave()` unwind, `netdev_rx_handler_unregister()`, `bond_upper_dev_unlink()`, `bond_update_slave_arr()`, and clearing RCU slave pointers (`current_arp_slave`, `primary_slave`, `curr_active_slave`) must precede `synchronize_rcu()`, which must precede `slave_disable_netpoll()`, `dev_close()`, and `kobject_put(&slave->kobj)`. `slave_kobj_release()` must call `cancel_delayed_work_sync(&slave->notify_work)` before freeing. Bracket slave release and failover with balanced `block_netpoll_tx()`/`unblock_netpoll_tx()`. [F20, F43, F176, F177]
- Set `xs->xso.real_dev` only after `xdo_dev_state_add` succeeds and clear it to `NULL` before `xdo_dev_state_delete`/`free`. Pin `curr_active_slave->dev` with `netdev_hold`/`dev_hold` before `rcu_read_unlock()` in `bond_ipsec_add_sa()` and `bond_ethtool_get_ts_info()`. Pair `ip_dev_find()` with `dev_put()` in `rlb_arp_xmit()`, `ip_route_output()`/`ip6_route_output()` with `ip_rt_put()`/`dst_release()` in `bond_arp_send_all()`/`bond_ns_send_all()`, and check `!IS_ERR_OR_NULL(tags)` + `kfree(tags)` on `bond_verify_device_path()`. [F12, F13, F14, F15, F16]
- Roll back preceding slaves (`rollback_slave` up to `slave`) without clobbering the error code on per-slave failure in `bond_change_mtu()`, `bond_set_mac_address()`, `alb_set_mac_address()`, `bond_vlan_rx_add_vid()`, and `bond_xdp_set()`. Pair `dev_xdp_propagate()` with `bpf_prog_inc(prog)` per slave, and `bond_xdp_set()` clearing `old_prog` with `bpf_prog_put(old_prog)` and `static_branch_dec(&bpf_master_redirect_enabled_key)`. [F17, F18]

## API Contracts
- Always change/clear `bond->curr_active_slave` via `bond_change_active_slave()`. Check `bond_slave_get_rcu()`/`bond_slave_get_rtnl()` for `NULL`; on arbitrary devices (e.g., `bond_option_active_slave_set`), first verify `netif_is_bond_slave(slave_dev)` and `bond->dev == netdev_master_upper_dev_get(slave_dev)`. Convert `ns_targets` via `addrconf_addr_solict_mult()` before `ndisc_mc_map()`/`ndisc_send_skb()`. Do not free or TX `skb` when `bond_handle_vlan()` returns `false`. [F52, F59, F69, F73, F148]
- Reject mode changes in `bond_option_mode_set()` with `-EOPNOTSUPP` if `bond->xdp_prog && !bond_xdp_check()`. In `bond_xdp_set_features()`, clear features if `!bond_xdp_check()` or `!bond_has_slaves(bond)`, and mask out `NETDEV_XDP_ACT_XSK_ZEROCOPY` (XDP requires slave `ndo_bpf` and `ndo_xdp_xmit`). In `bond_xdp_xmit()`, stop on the first failed frame and return `nxmit` if `nxmit > 0`. Verify `real_dev->xfrmdev_ops`, callback, and `!netif_is_bond_master(real_dev)` in `bond_ipsec_*_sa*()`. Keep `NETIF_F_GSO_PARTIAL` in `BOND_ENC_FEATURES`/`bond_setup()` and aggregate `gso_partial_features` in `bond_compute_features()`. [F84, F161, F162, F185, F190]
- On first-slave type change in `bond_enslave()`, fire `NETDEV_PRE_TYPE_CHANGE`, flush UC/MC, call `bond_setup_by_slave()` (closing/reopening `bond_dev` if `IFF_UP`) or `bond_ether_setup()` (preserving `IFF_MASTER | (flags & (IFF_SLAVE | IFF_UP))` and clearing `IFF_TX_SKB_SHARING`), and fire `NETDEV_POST_TYPE_CHANGE`. Mask `bond_xmit_hash()` with `& 0xFF` for `tlb_choose_channel()`. Save/restore `qdisc_skb_cb(skb)->slave_dev_queue_mapping` across `bond_select_queue()` and `bond_dev_queue_xmit()`. [F92, F101, F163, F194, F200]
- `bond_option.unsuppmodes` must be `unsigned long` with `BIT(BOND_MODE_*)` masks; `bond_opt_value` tables need a `{ NULL, -1, 0 }` sentinel and names `<= 32` chars (`BOND_OPT_MAX_NAMELEN`); `BOND_OPTFLAG_RAWVAL` setters (`bond_option_arp_ip_targets_set`, `bond_option_slaves_set`) must check `strlen(newval->string) >= 1` before `+ 1`. [F71, F97, F105, F154]

## Error Handling
- In `bond_xdp_get_xmit_slave()`, ratelimit `netdev_err()` with `net_ratelimit()` and never `WARN_ON_ONCE()` on unsupported modes. [F189]

## External Contracts
- In `bond_changelink()`, check `nla_len(attr)` on nested `IFLA_BOND_ARP_IP_TARGET` (`>= 4`) and `IFLA_BOND_NS_IP6_TARGET` (`>= 16`). Match every new attribute in `bond_fill_info()`, `bond_fill_slave_info()`, or `bond_3ad_stats_fill()` in `bond_get_size()`, `bond_get_slave_size()`, or `bond_3ad_stats_size()`. Gate 802.3ad actor/partner keys, MACs, and LACPDU info in netlink/procfs with `capable(CAP_NET_ADMIN)`. [F111, F112, F198]

## Known Pitfalls
- Re-derive `data` and `eth_hdr`/`ip_hdr`/`ipv6_hdr` after every `pskb_may_pull()`, `pskb_network_may_pull()`, `bond_pull_data()`, or `alb_determine_nd()`. In `bond_handle_frame()`, assign `*pskb = skb_share_check(...)`, and call `skb_cow_head()` before writing `eth_hdr(skb)->h_dest` in ALB bridge mode. Use offset `0` for `skb_header_pointer()` on RX (`bond_na_rcv`, `rlb_arp_recv`, `bond_3ad_lacpdu_recv`) vs `skb_mac_header_len(skb)` on TX (`bond_should_broadcast_neighbor`); pass `mhoff = 0` in `bond_xmit_hash()` and call `skb_reset_mac_header(skb)` before `eth_hdr(skb)` in TLB/ALB TX. [F85, F86, F109, F144, F191]
- In `bond_arp_rcv()`, check `arp->ar_hln == bond->dev->addr_len` and `arp->ar_pln == 4` before `memcpy()`ing `sip`/`tip`. Zero-init `fl6` (without setting `flowi6_oif`) in `bond_ns_send_all()` and `parms` in `bond_neigh_init()`. Pass `&slave_dev` to `bond_opt_slave_initval()`; use `nla_get_u64` for `BOND_OPT_AD_ACTOR_SYSTEM`; pass writable strings to `bond_opt_initstr()` when `'\n'` or `':'` is present; size `command` buffers `IFNAMSIZ + 1` (`"%16s"`). Use `old_flags` in `__bond_release_one()` after notifiers, and clear `new_aggregator` if `!slave_iter` after `bond_for_each_slave()` in `bond_3ad_unbind_slave()`. [F65, F66, F70, F93, F108, F122, F142, F152, F153]
