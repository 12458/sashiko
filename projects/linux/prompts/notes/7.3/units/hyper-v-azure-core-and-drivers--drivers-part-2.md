# Hyper-V/Azure CORE AND DRIVERS — drivers (part 2)

Paravirtualized networking (`hv_netvsc`) and virtual PCIe root bus (`pci-hyperv`) drivers for Hyper-V guests. `hv_netvsc` implements NVSP/RNDIS, VRSS sub-channels, XDP, and SR-IOV VF bonding. `pci-hyperv` manages synthetic PCI root buses, MMIO config space, BAR probing, and MSI/MSI-X IRQ domains.

## Architecture & Data Flow
- In `netvsc_send_pkt()`, set `packet->dma_range = NULL` before checking `page_buf_cnt` (`skb->cb` is unzeroed). For `cp_partial`, `netvsc_copy_to_send_buf()` copies `pb[0]`, `netvsc_send()` decrements `page_buf_cnt`, and `netvsc_send_pkt()` increments `pb` before `netvsc_dma_map()`/`netvsc_build_mpb_array()`. `hv_page_buffer` entries need `offset < HV_HYP_PAGE_SIZE` (`offset_in_hvpage()`) and ceiling PFN counts (`HVPFN_UP(offset + len)`), never guest `PAGE_SIZE`. [F242, F303, F312]
- `netvsc_init_buf()` must verify `recv_section_size` and `send_section_size >= NETVSC_MTU_MIN` before `buf_size / send_section_size` (truncating) or `__netvsc_get_ringparam()`, and widen `u32` `recv_section_size * recv_section_cnt` to `u64`. `netvsc_receive()` checks `buflen <= recv_section_size` before `rndis_filter_receive()`. `nvchan->mrc.slots` (`netvsc_alloc_recv_comp_ring()`, `recv_comp_slot_avail()`) needs `recv_completion_cnt = recv_section_cnt + 1` entries (1 sentinel slot empty). [F277, F282, F311, F313]
- In `nvsc_rsc`, read `vlan`, `csum_info`, and `hash_info` only when their bit (`NVSC_RSC_*`) is set in `nvchan->rsc.ppi_flags`. Reset `nvchan->rsc.cnt = 0` on range/filter errors, non-RSC or `RNDIS_PKTINFO_1ST_FRAG` packets, or when `netvsc_recv_callback()` finishes an RSC packet (`!rsc_more`). `netvsc_poll()` persists `nvchan->desc` (`hv_pkt_iter_first()` only if `!nvchan->desc`); if `send_recv_completions()` fails with `work_done < budget`, reschedule NAPI without advancing `mrc->first`. [F244, F301, F304]
- In `netvsc_switch_datapath()`, clear `data_path_is_vf = false` before `NVSP_MSG4_TYPE_SWITCH_DATA_PATH` when `!vf`, and set `true` only after `vmbus_sendpacket()` and `wait_for_completion(&nv_dev->channel_init_wait)` succeed when `vf` is true. `netvsc_resume()` resets `data_path_is_vf = false` before `netvsc_attach()`, and `netvsc_unregister_vf()` calls `reinit_completion(&net_device_ctx->vf_add)`. [F251, F265]
- `netvsc_xmit()` and `netvsc_ndoxdp_xmit()` must check `vf_netdev && netif_running(vf_netdev) && netif_carrier_ok(vf_netdev) && !netpoll_tx_running(ndev) && ndev_ctx->data_path_is_vf` under RCU-bh before VF TX, and VF delegation (`netvsc_vf_xmit()`, `netvsc_select_queue()`, `netvsc_set_link_ksettings()`, `netvsc_ndoxdp_xmit()`) must pass `vf_netdev` (not `ndev`) to `vf_netdev` ops. [F272, F307]
- `netvsc_register_vf()` sets `ndev->needed_headroom >= vf_netdev->needed_headroom`, `vf_netdev->wanted_features = ndev->features`, and propagates XDP via `netvsc_vf_setxdp()`; `netvsc_unregister_vf()` resets `needed_headroom = RNDIS_AND_PPI_SIZE`. Both `netvsc_register_vf()` and `NETDEV_REGISTER` in `netvsc_netdev_event()` move `vf_netdev` into `dev_net(ndev)` before `netvsc_vf_join()`. Check `dev->netdev_ops == &device_ops` before `netdev_priv(dev)` in `netvsc_netdev_event()`/`get_netvsc_byref()`, and `dev_is_pci(parent)` in `get_netvsc_byslot()`. [F253, F331, F371]
- In `rndis_set_subchannel()`, verify `subchn_comp.num_subchannels <= nvdev->num_chn - 1` before `nvdev->num_chn = 1 + subchn_comp.num_subchannels`; on success, update `num_chn`, `tx_table`, and `netif_set_real_num_{tx,rx}_queues()`, and on failure reset `max_chn = 1` and `num_chn = 1`. `rndis_netdev_set_hwcaps()` resets `hw_features &= ~NETVSC_SUPPORTED_HW_FEATURES` and `tx_checksum_mask = 0`, checks `NDIS_TXCSUM_ALL_TCP4`/`TCP6`/`NDIS_LSOV2_CAP_IP6` for full equality (`(val & MASK) == MASK`), and updates `netvsc_gso_max_size` with `netif_set_tso_max_size()`. XDP and `NETIF_F_LRO` are mutually exclusive (`netvsc_xdp_set()`, `netvsc_fix_features()`). [F257, F258, F292, F314, F381]
- `hv_send_resources_{allocated,released}()` track the highest allocated slot in `hbus->wslot_res_allocated` (`-1` when none), and `hv_pci_enter_d0()` sets `wslot_res_allocated = 255` before `hv_pci_bus_exit(hdev, true)` on retry. `hv_pci_suspend()` passes `keep_devs = true` to `hv_pci_bus_exit()`, and `hv_pci_resume()` re-negotiates only `hbus->protocol_version` and calls `hv_pci_restore_msi_state(hbus)` after `prepopulate_bars(hbus)`. [F259, F266]
- Adding to `pci_protocol_versions` requires updating `hv_compose_msi_msg()`, `hv_send_resources_allocated()`, and `hv_irq_retarget_interrupt()`. In `hv_compose_msi_msg()` and `hv_compose_msi_req_v1`/`v2`/`v3`, `vector` is `u32` (`u8` for v1/v2) and `vector_count` is `u16`. Reuse `data->chip_data` (`tran_int_desc`) only when `multi_msi` is true (else `hv_int_desc_free()`); for `multi_msi`, pick vCPU via `hv_compose_multi_msi_req_get_cpu()` and leave `int_desc->vector_count = 0` on secondary IRQs so `hv_int_desc_free()` skips `PCI_DELETE_INTERRUPT_MESSAGE`. [F264, F273, F305, F308, F347]
- In `_hv_pcifront_{read,write}_config()`, simulated/read-only range checks must precede `where + size <= CFG_PAGE_SIZE` MMIO and use the next register's offset as `END` in `where + size <= END`. Keep `v_id`/`d_id` and `rev`/`prog_intf`/`subclass`/`base_class` contiguous in `hv_pcidev_description` for `memcpy()`. In `hv_pci_onchannelcallback()`, check `bytes_recvd >= struct_size(bus_rel, func, bus_rel->device_count)` and set `dr->device_count` before indexing `dr->func[]`; `pci_devices_present_work()` drains and `kfree`s superseded `hbus->dr_list` entries until only the last remains. [F274, F275, F287, F293, F297]

## Synchronization
- `netvsc_drv_init()` registers `netvsc_netdev_notifier` before `vmbus_driver_register(&netvsc_drv)`. In `netvsc_probe()`, hold `rtnl_lock()` from before `rndis_filter_device_add()` through scheduling `subchan_work`, `register_netdevice()`, adding to `netvsc_dev_list`, and the `for_each_netdev` VF scan (calling `rndis_filter_device_remove()` under RTNL on error). `netvsc_prepare_bonding()` sets `IFF_SLAVE | IFF_NO_ADDRCONF` in `NETDEV_POST_INIT` (or before `netvsc_register_vf()` in `netvsc_probe()`), and `get_netvsc_byslot()` matches `ndev->perm_addr` against both `vf_netdev->perm_addr` and `dev_addr`. [F216, F218, F341]
- `netvsc_vf_setxdp()` uses `netif_xdp_propagate()` (not `dev_xdp_propagate()`), and non-notifier callers of `netvsc_register_vf()` must hold `netdev_lock_ops(vf_netdev)`. On `NETDEV_REGISTER` for a `netvsc` dev in `netvsc_netdev_event()`, defer moving `vf_netdev` netns to `ndev_ctx->vfns_work` (`netvsc_vfns_work()`). RTNL workqueue handlers (`netvsc_subchan_work()`, `netvsc_vf_setup()`, `netvsc_vfns_work()`, `netvsc_link_change()`) must use `rtnl_trylock()`, reschedule on contention, and re-validate pointers after locking. [F217, F220, F361]
- In `netvsc_device_add()` and `netvsc_sc_open()`, set `nvchan->channel` and call `napi_enable()` / `netif_queue_set_napi()` before `vmbus_open()`, and publish `rcu_assign_pointer(net_device_ctx->nvdev, net_device)` only after `netvsc_connect_vsp()`. Callers of `netvsc_send()` must hold RCU-bh. In `rndis_filter_halt_device()`, order `nvdev->destroy = true` with `wmb()` before `wait_event(nvdev->wait_drain, netvsc_device_idle(nvdev))`, and in `rndis_filter_close_device()`, call `cancel_work_sync(&dev->mcast_work)` before clearing the packet filter. `netvsc_tx_{enable,disable}()` must issue `virt_wmb()` after updating `tx_disable` and before waking/disabling TX queues. [F219, F221, F223, F356]
- Hold `hbus->state_lock` across `hv_pci_enter_d0()`, resource/BAR setup, and `create_root_hv_pci_bus()` in `hv_pci_probe()`/`hv_pci_resume()`, and throughout `pci_devices_present_work()` and `hv_eject_device_work()`. In `hv_pci_remove()`/`hv_pci_suspend()`, call `tasklet_disable(&hdev->channel->callback_event)` while setting `hbus->state = hv_pcibus_removing`, then re-enable before flushing/destroying `hbus->wq` and closing VMBus. `hv_pci_query_relations()` publishes `comp` via `cmpxchg(&hbus->survey_event, NULL, &comp)` and calls `flush_workqueue(hbus->wq)` on every return path. [F226, F227, F228]
- `hv_compose_msi_msg()` runs with IRQ locks held: use `GFP_ATOMIC`, `tasklet_disable_in_atomic(&channel->callback_event)`, and poll `try_wait_for_completion()` while calling `hv_pci_onchannelcallback(hbus)` under `spin_lock_irqsave(&channel->sched_lock, flags)` when `channel->onchannel_callback != NULL`. In `_hv_pcifront_{read,write}_config()` and `hv_pcifront_get_vendor_id()`, hold `spin_lock_irqsave(&hbus->config_lock, flags)`, write `hpdev->desc.win_slot.slot` to the index page, and issue `mb()`/`wmb()` before `CFG_PAGE_OFFSET + where`. `hv_irq_retarget_interrupt()` and `hv_pci_{read,write}_mmio()` run with IRQs disabled using `*this_cpu_ptr(hyperv_pcpu_input_arg)` (`out` at `+ sizeof(*in)` in `hv_pci_read_mmio()`). [F263, F344, F365]

## Object Lifetimes
- In `netvsc_device_remove()`, call `napi_disable()` and `netif_queue_set_napi(..., NULL)` only for `i < ndev->real_num_rx_queues`, but `netif_napi_del()` for all `i < net_device->num_chn`. Unmap `packet->dma_range` via `netvsc_dma_unmap()` on `vmbus_sendpacket_mpb_desc()` failure in `netvsc_send_pkt()`, in `netvsc_send_tx_complete()` for SKBs, and in `rndis_filter_receive_response()` for control requests (`skb == NULL`). [F200, F202]
- `netvsc_xdp_set()` adds `nvdev->num_chn - 1` refs to `prog` and drops `nvdev->num_chn` refs from `old_prog`, so callers reusing `dev_info->bprog` (`netvsc_attach()`) must call `bpf_prog_inc(prog)` before and `bpf_prog_put(prog)` on error. `netvsc_run_xdp()` and `netvsc_alloc_recv_skb()` must free `xdp->data_hard_start` unless `act` is `XDP_PASS`, `XDP_TX`, or a successful `XDP_REDIRECT`, or if `build_skb()` fails. [F204, F379]
- `new_pcichild_device()` initializes `hpdev->desc` and takes two refs (`refcount_set(&hpdev->refs, 1)` + `get_pcichild()`) before adding to `hbus->children` under `device_list_lock`, and `get_pcichild_wslot()` calls `get_pcichild()` before unlocking. Removing a child from `hbus->children` requires two `put_pcichild()` calls (three in `hv_eject_device_work()`). On timeout/abort of a stack `pci_packet` in `hv_compose_msi_msg()` or `hv_pci_bus_exit()`, remove `trans_id` via `vmbus_request_addr_match()`, and call `comp_packet->completion_func()` under `lock_requestor()` in `hv_pci_onchannelcallback()`. `hv_pci_of_irq_domain_parent()` must call `of_node_put(parent)`. [F232, F350, F352, F366]

## API Contracts
- `netvsc_send()` consumes batched `msdp->skb` packets (or frees `msd_skb` and its send slot on error) but leaves the current `skb` unfreed when returning an error to `netvsc_xmit()`. Callers of `netvsc_xdp_xmit()` must call `skb_record_rx_queue(skb, q_idx)` first and pass `xdp_tx = true` to `netvsc_xmit()` to bypass `nvchan->msd`. `netvsc_drv_init()` computes `netvsc_ring_bytes` from `ring_size * 4096` (never `PAGE_SIZE`) with `VMBUS_RING_SIZE()`. `netvsc_poll()` calls `napi_complete_done()` only when `work_done < budget` and returns `min(work_done, budget)`. [F201, F234, F377, F382]
- `netvsc_vf_handle_frame()` calls `skb_share_check(skb, GFP_ATOMIC)` and updates `*pskb` before `skb->dev = ndev`. `netvsc_select_queue()` stores the raw VF queue in `qdisc_skb_cb(skb)->slave_dev_queue_mapping` before folding modulo `real_num_tx_queues`, and `netvsc_vf_xmit()` passes it to `skb_record_rx_queue()`. In `netvsc_alloc_recv_skb()`, when `NVSC_RSC_CSUM_INFO` has `ip_checksum_value_invalid` and `ip_checksum_succeeded` on `ETH_P_IP`, check `skb_headlen(skb) >= sizeof(struct iphdr)` and call `netvsc_comp_ipcsum(skb)`. `hv_pci_allocate_bridge_windows()` sets `IORESOURCE_WINDOW` and clears `IORESOURCE_BUSY` before `pci_add_resource()`, `hv_pci_free_bridge_windows()` restores `IORESOURCE_BUSY` before `vmbus_free_mmio()`, and `hv_allocate_config_window()` sets `IORESOURCE_BUSY` on `hbus->mem_config`. [F346, F375, F376, F383]

## Error Handling
- `rndis_filter_receive()`, `rndis_filter_receive_data()`, and `netvsc_recv_callback()` return `NVSP_STAT_SUCCESS` (1) or `NVSP_STAT_FAIL` (2), never `0` or `-errno`. `netvsc_device_add()` and `rndis_filter_device_add()` return `ERR_PTR(-errno)` (not `NULL`), whereas `net_device_ctx->nvdev` is a nullable RCU pointer set only in `netvsc_device_add()`. In `netvsc_send_tx_complete()`, check `cmd_rqst == VMBUS_RQST_ERROR` (`0` is a valid control packet completion that still decrements `queue_sends`). [F238, F239, F241]
- If updating the second device fails in `netvsc_change_mtu()`, `netvsc_set_mac_addr()`, or `netvsc_bpf()` (`XDP_SETUP_PROG`), roll back the first device's MTU, MAC, or XDP prog. On ARM64, if `hv_pci_vec_irq_gic_domain_alloc()` fails at index `i` in `hv_pci_vec_irq_domain_alloc()`, call `hv_pci_vec_irq_free(domain, virq, nr_irqs, i)` to free all `nr_irqs` bitmap bits and `i` parent IRQs. [F215, F254]
- `hv_pci_restore_msi_msg()` checks `pdev->msi_enabled || pdev->msix_enabled` before `msi_lock_descs()`. `hv_irq_retarget_interrupt()` and `hv_msi_free()` check `data->chip_data != NULL`, and `hv_compose_msi_msg()` zeroes `*msg` on error. In `hv_pci_assign_slots()`, format `hpdev->desc.ser` with `"%u"` (`SLOT_NAME_SIZE >= 11`) for `get_netvsc_byslot()`, and reset `hpdev->pci_slot = NULL` if `IS_ERR(hpdev->pci_slot)`. [F236, F237, F240, F333]

## External Contracts
- In `ndis_offload_params`, `0` means no change: zero-initialize before `rndis_filter_set_offload_params()`, use `*_DISABLED` to disable, and when `nvsp_version <= NVSP_PROTOCOL_VERSION_4`, truncate to `VERSION_4_OFFLOAD_SIZE` (22) and zero UDP checksum fields. `rndis_filter_set_rss_param()` sends `NDIS_RSS_PARAM_FLAG_DISABLE_RSS` before enabling (`flag = 0`), updating `rdev->rss_key` only on `RNDIS_STATUS_SUCCESS` when enabling. [F245, F268, F289]
- In `netvsc_linkstatus_callback()`, validate `status_buf_offset`/`status_buflen` against `data_buflen - RNDIS_HEADER_SIZE`. In `netvsc_send_table()`, when `nvsp_version <= NVSP_PROTOCOL_VERSION_6`, override `offset` to `sizeof(struct nvsp_message_header) + sizeof(union nvsp_6_message_uber)`. In `init_ppi_data()` and `rndis_get_ppi()`, `per_pkt_info_offset` and `data_offset` are relative to `(void *)&msg->msg.pkt` (`data + RNDIS_HEADER_SIZE`), `ppi_offset` is relative to `ppi`, and message sizes use `RNDIS_HEADER_SIZE` and `RNDIS_MESSAGE_SIZE(type)`. [F278, F279, F321, F322]
- When `hv_is_isolation_supported()`, require `nvsp_version >= NVSP_PROTOCOL_VERSION_61`, do not set `capability.sriov`, and ignore `NVSP_MSG4_TYPE_SEND_VF_ASSOCIATION`. In `hv_write_config_block()`, include `sizeof(pkt.reserved)` in `pkt_size`. `prepopulate_bars()` clears `PCI_COMMAND_MEMORY` before writing BARs and leaves it cleared. [F248, F267, F342]

## Known Pitfalls
- `netvsc_probe()` must `return 0` (not `ret`, which `check_dev_is_matching_vf()` overwrites). In `netvsc_xmit()`, complete `skb_linearize()`, `skb_cow_head()`, and `ETH_P_8021Q` `__skb_vlan_pop()` / `__vlan_hwaccel_put_tag()` / `VLAN_HLEN` length adjustments before computing `rndis_msg = (struct rndis_message *)skb->head` and `init_page_array()`. Copy host-shared `net_device->recv_buf` data into `nvchan->recv_buf` before validating/reading RNDIS headers, packets, or PPIs in `rndis_filter_receive*()` and `rndis_get_ppi()`. [F250, F261, F269, F384]
- `rndis_device::link_state` is `false` (0) when link is up (`!rdev->link_state`), and `netvsc_link_change()` uses `time_is_after_jiffies(next_reconfig)` and clamps `delay` to `LINKCHANGE_INT`. Use `sync_test_and_set_bit()` and `sync_change_bit()` on `send_section_map`, calling `netvsc_free_send_slot()` only once when `index != NETVSC_INVALID_INDEX`. In `survey_child_resources()` and `prepopulate_bars()`, 64-bit BARs (`PCI_BASE_ADDRESS_MEM_TYPE_64`) consume two slots (`i++` on every path including `continue`), require `(u64)probed_bar[i + 1] << 32`, and 32-bit BARs require `| 0xffffffff00000000ULL` before `get_bar_size()`; check `low_mmio_space`/`high_mmio_space` non-zero before `__builtin_clzll()` and shift `1ULL << (63 - __builtin_clzll(...))`. [F225, F291, F298, F309, F310, F316, F334]
