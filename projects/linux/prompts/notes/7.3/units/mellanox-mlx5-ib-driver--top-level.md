# MELLANOX MLX5 IB driver — (top level)

This component implements core QP, SRQ, UMR, WR posting, `restrack`, and uverbs ioctl operations for `mlx5_ib`, alongside `include/linux/mlx5/` core headers for capabilities, doorbells, completion/event queues, e-switch, and flow steering.

## Architecture & Data Flow
- `struct mlx5_core_rsc_common common` must be the first member of `struct mlx5_core_qp` and `struct mlx5_core_srq`. Every active `mlx5_ib_qp_base` (`trans_qp.base`, `raw_packet_qp.sq.base`, `raw_packet_qp.rq.base`) must set `container_mibqp = qp` for `to_mibqp()`, while `mlx5_ib_rwq::core_qp` uses `to_mibrwq()`. In `create_user_qp()` and `destroy_qp_common()`, use `&qp->raw_packet_qp.rq.base` (not `&qp->trans_qp.base`) when `qp->type == IB_QPT_RAW_PACKET` or `qp->flags & IB_QP_CREATE_SOURCE_QPN`. [F47, F131, F132]
- `qp_table.tree` keys for QPs, RQs, and SQs must be `rsn = qpn | (rsc_type << MLX5_USER_INDEX_LEN)` (`qpn` masked to 24 bits in `rsc_event_notifier()`), whereas DCTs live in `qp_table.dct_xa` indexed by 24-bit `dctn` alone. [F91]
- In `__mlx5_ib_qp_set_counter()`, `IB_QPT_RAW_PACKET` QPs bind counters on `qp->raw_packet_qp.rq` via `__mlx5_ib_qp_set_raw_qp_counter()` and `mlx5_core_modify_rq()`, not `RTS2RTS_QP` on `trans_qp.base`. If `mlx5_ib_qp_set_counter()` runs outside `RESET`/`RTS`, it sets `mqp->counter_pending = 1`, which `__mlx5_ib_modify_qp()` must apply and clear on transition to `IB_QPS_RTS`. [F46, F62]
- Transitioning a kernel non-`IB_QPT_XRC_TGT` QP to `IB_QPS_RESET` in `__mlx5_ib_modify_qp()` must clean `recv_cq`/`send_cq` via `mlx5_ib_cq_clean()`, zero `rq.head`, `rq.tail`, `sq.head`, `sq.tail`, `sq.cur_post`, `sq.last_poll`, and `db.db`, and reset `qp->sq.cur_edge = get_sq_edge(&qp->sq, 0)`. [F61]
- `set_qpc_atomic_flags()` derives `rre`/`rae`/`rwe` from `IB_QP_ACCESS_FLAGS` and `IB_QP_MAX_DEST_RD_ATOMIC` using cached `qp->trans_qp.atomic_rd_en` and `resp_depth` for omitted attributes; `__mlx5_ib_modify_qp()` must update those shadow fields only after `mlx5_core_qp_modify()` succeeds, and caches `attr->alt_port_num` in `trans_qp.alt_port` on `IB_QP_ALT_PATH` (copied to `qp->port` by `mlx5_ib_qp_event()` on `MLX5_EVENT_TYPE_PATH_MIG`). [F63, F65]
- In `mlx5_ib_modify_dct()`, `INIT`->`RTR` with `RDMA_AH_ATTR_TYPE_ROCE` must set `dctc` `eth_prio` to `attr->ah_attr.sl & 0x7`. When LAG is active, `dctc` `port` uses `get_tx_affinity_rr(dev, udata)` (which increments `ucontext->tx_port_affinity` for user QPs or `dev->port[port_num].roce.tx_port_affinity` for kernel callers) while `qp->port` stores `attr->port_num`; `mlx5_ib_dct_query_qp()` must return `mqp->port`, not `dctc` `port`. In `create_raw_packet_qp_tis()`, set `strict_lag_tx_port_affinity` when `!mlx5_ib_lag_should_assign_affinity(dev) && mlx5_lag_is_lacp_owner(dev->mdev)`. [F64, F81, F148, F149]
- Validate 1-based `port_num` against `1 <= port_num <= dev->num_ports` (never `MLX5_CAP_GEN(dev->mdev, num_ports)`) before indexing `dev->port[port_num - 1]`. In `validate_rd_atomic()`, check `max_rd_atomic`/`max_dest_rd_atomic` against `log_max_ra_res_dc`/`log_max_ra_req_dc` for `MLX5_IB_QPT_DCI`, and `log_max_ra_res_qp`/`log_max_ra_req_qp` otherwise. [F85, F86]
- In `mlx5_ib_create_srq()`, require `max_wr < (1 << MLX5_CAP_GEN(dev->mdev, log_max_srq_sz))` and `max_sge <= MLX5_CAP_GEN(dev->mdev, max_wqe_sz_rq) / sizeof(struct mlx5_wqe_data_seg)` before `roundup_pow_of_two(max_wr + 1)`. `get_pas_size()` must compute `DIV_ROUND_UP(rq_sz + (page_offset * po_quanta), page_size)`. Kernel SRQs use an in-buffer free list (`mlx5_wqe_srq_next_seg`): `mlx5_ib_post_srq_recv()` pops `srq->head` (`be16_to_cpu(next->next_wqe_index)`), stopping at `srq->tail`, and `mlx5_ib_free_srq_wqe()` links freed `wqe_index` at `srq->tail`. [F73, F84, F122]
- QPC/SRQC `log_rq_stride` and `mlx5_srq_attr.wqe_shift` store `wqe_shift - 4`, whereas WQC `log_wq_stride` in `set_wq()` and `create_raw_packet_qp_rq()` stores `in->wqe_shift + 4` (`log_rq_stride + 4`). For striding RQs, validate `single_wqe_log_num_of_strides` via `log_of_strides_valid()` before indexing `fw_map[rwq->log_num_strides - MLX5_EXT_MIN_SINGLE_WQE_LOG_NUM_STRIDES]`. In `bfregn_to_uar_index()` with `dyn_bfreg`, offset `index_of_sys_page` by `bfregi->num_static_sys_pages` and check `< bfregi->num_sys_pages`, `bfregn <= bfregi->num_dyn_bfregs`, and `sys_pages[index_of_sys_page] != MLX5_IB_INVALID_UAR_INDEX`. [F95, F101, F102]
- `mlx5r_wq_overflow()` must use unsigned `cur = wq->head - wq->tail` and test `cur + nreq >= wq->max_post`. Producer counters `qp->sq.cur_post` (`u16`), `srq->wqe_ctr` (`u16`), and `qp->rq.head & 0xffff` written to `ctrl->opmod_idx_opcode` and `db.db` wrap modulo `2^16` (never masked with `wqe_cnt - 1`). In `mlx5_ib_post_srq_recv()` and `mlx5_ib_post_recv()`, if `wr->num_sge` is below `max_avail_gather` / `qp->rq.max_gs`, set `scat[i]` to `byte_count = 0`, `addr = 0`, and cached `lkey = dev->mkeys.terminate_scatter_list_mkey` (already `__be32`; never query firmware in post loops). [F93, F114, F127, F128]
- `set_pi_umr_wr()` requires `sig_mr->sig->sig_status_checked` to be true and resets it to `false` after `set_sig_data_segment()`. UMR XLT DMA lengths (`sg.length`) and offsets must be multiples of `MLX5_UMR_FLEX_ALIGNMENT` (64B); `mlx5r_umr_get_xlt_octo()` must `ALIGN(..., 64)` before dividing by 16, `mlx5r_umr_update_offset()` must use `u64` octoword math, and `mlx5r_umr_update_xlt()` must add `idx & page_mask` to `npages` before aligning `idx` down. `umr_check_mkey_mask()` must verify HCA caps support UMR modification of `PAGE_SIZE`, `A`, or `RELAXED_ORDERING_WRITE`/`READ`; `get_umr_update_translation_mask()` must add `MLX5_MKEY_MASK_PAGE_SIZE_5` when `umr_log_entity_size_5` is set; `mlx5r_umr_set_access_flags()` sets `relaxed_ordering_read` only with `IB_ACCESS_RELAXED_ORDERING` and `MLX5_CAP_GEN(dev->mdev, relaxed_ordering_read)` or `pcie_relaxed_ordering_enabled(dev->mdev->pdev)`. [F71, F92, F123, F124, F145, F146, F151]
- `mlx5_ib_read_user_wqe_common()` must clamp copy length to `min(buflen, wq_end - offset, bcnt)`, and `mlx5_ib_read_user_wqe_sq()` must read wrapped SQ bytes from `wqe_index` 0. `dump_rsc()` must check `size + offset > MAX_DUMP_SIZE` (1024B) before copying. New `enum mlx5_cap_type` values must be `< MLX5_CAP_NUM` and added to `types[]` in `mlx5_hca_caps_alloc()`. [F89, F96, F97]

## Synchronization
- Lock hierarchy: `dev->reset_flow_resource_lock` -> `qp->sq.lock` / `qp->rq.lock` -> `cq->lock` -> `srq->lock`. Linking/unlinking QPs (`dev->qp_list`, `send_cq->list_send_qp`, `recv_cq->list_recv_qp`) requires `reset_flow_resource_lock` then `mlx5_ib_lock_cqs(send_cq, recv_cq)` (locking distinct CQs in ascending `mcq.cqn` order via `spin_lock_nested(..., SINGLE_DEPTH_NESTING)`). `mlx5r_wq_overflow()` runs under `sq.lock`/`rq.lock` with IRQs disabled and takes `cq->lock`. [F12, F29, F30, F164]
- Because `mlx5_get_rsc()`, `dct_event_notifier()`, and `srq_event_notifier()` run in atomic EQ IRQ context, process-context accesses to `qp_table.lock`, `qp_table.dct_xa`, and `srq_table.array` must disable IRQs (`spin_lock_irq*` / `xa_*_irq*`). `srq->lock` protects `head`, `tail`, `wqe_ctr`, and `next_wqe_index` (`mlx5_ib_free_srq_wqe()` requires IRQs disabled); `srq->mutex` serializes `mlx5_cmd_arm_srq()`. `qp->mutex` protects `qp->state`, `counter_pending`, `ibqp->counter`, and raw-packet SQ/RQ state across modify, query, and counter binding. [F27, F40, F160]
- `mlx5_core_destroy_rq_tracked()` must set `rq->common.invalid = true` via `modify_resource_common_state()` under `qp_table.lock` before `destroy_rq_tracked()`, revert to `false` on error, and call `destroy_resource_common()` only on success. `mlx5_core_destroy_dct()` must finish `mlx5_core_drain_dct()` and `wait_for_completion(&dct->drained)` (unless `MLX5_DEVICE_STATE_INTERNAL_ERROR`) while `dct` is still in `qp_table.dct_xa`, before `xa_cmpxchg_irq()` sets `XA_ZERO_ENTRY` and `_mlx5_core_destroy_dct()` runs. [F24, F25]
- In `mlx5r_ring_db()`, `mlx5_write64()` and `bf->offset ^= bf->buf_size` must run under `qp->sq.lock` after `wmb()` barriers separating WQE and `qp->db.db[MLX5_SND_DBR]` writes. In `mlx5_ib_post_recv()`, `mlx5_ib_post_srq_recv()`, and `mlx5_cq_arm()`, a `wmb()` must precede updating `*qp->db.db` / `*srq->db.db` (under `rq.lock` / `srq->lock`) or `mlx5_write64()` to `MLX5_CQ_DOORBELL`. [F32, F33, F162, F163]
- In `mlx5r_umr_post_send_wait()`, pair `down(&umrc->sem)` with `up(&umrc->sem)` on all paths and release `umrc->lock` before sleeping or calling `mlx5r_umr_recover()`. `mlx5r_umr_recover()` must set `MLX5_UMR_STATE_RECOVER` under `umrc->lock` and await a barrier WR completion before resetting `umrc->qp` to `RESET` and `RTS`. [F21, F76]
- In `handle_drain_completion()` during `MLX5_DEVICE_STATE_INTERNAL_ERROR` on a non-`IB_POLL_DIRECT` CQ, test-and-set `mcq->mcq.reset_notify_added` under `reset_flow_resource_lock`; if already set, drain `cq->iop` or `cq->work` after unlocking before calling `mcq->mcq.comp()`. Each `mlx5_core_dev` must use its per-device `dev->lock_key` for `intf_state_mutex`. [F39, F169]

## Object Lifetimes
- Initialize `qp_table`/`srq_table` locks, trees, and arrays before `mlx5_notifier_register()`, and call `mlx5_notifier_unregister()` first during cleanup. `mlx5_core_destroy_qp()` and `mlx5_core_destroy_sq_tracked()` must call `destroy_resource_common()` (removing from `qp_table.tree`, dropping initial ref via `mlx5_core_put_rsc()`, and waiting on `common.free`) before firmware `DESTROY_QP`/`DESTROY_SQ`. `destroy_qp_common()` must reset non-RSS QPs (`2RST_QP`), unlink from `dev->qp_list` and CQ lists under `reset_flow_resource_lock` and CQ locks, and destroy in firmware before `destroy_qp()` frees buffers/doorbells. [F23, F138, F143]
- Call `mlx5_ib_free_bfreg()` in `_create_user_qp()` and `destroy_qp()` only when `bfregn != MLX5_IB_INVALID_BFREG`. In `create_raw_packet_qp()` / `destroy_raw_packet_qp()`, create SQ resources TIS then SQ (teardown SQ then TIS) and RQ resources RQ then TIR (teardown TIR then RQ). In `modify_raw_packet_qp()`, `create_flow_rule_vport_sq()` returns `NULL`, `ERR_PTR`, or a handle; delete a non-NULL new rule with `mlx5_del_flow_rules()` if `modify_raw_packet_qp_sq()` fails, and destroy/replace `sq->flow_rule` only after it succeeds. [F11, F13, F15, F49]
- Set `MLX5_IB_WQ_FLAGS_DELAY_DROP` in `rwq->create_flags` only after `set_delay_drop()` succeeds, and call `destroy_user_rq()` only after `mlx5_core_destroy_rq_tracked()` succeeds. For `MLX5_IB_QPT_DCT`, `mlx5_ib_destroy_dct()` must call `mlx5_core_destroy_dct()` only when `mqp->state == IB_QPS_RTR` and free `mqp->dct.in` only after it succeeds. In `mlx5_ib_create_srq()`, free `in.pas` from `create_srq_kernel()` via `kvfree(in.pas)` immediately after `mlx5_cmd_create_srq()` (and on intervening errors). In `dump_rsc()`, always clean up with `mlx5_rsc_dump_cmd_destroy(cmd)` and `__free_page(page)`. [F14, F17, F18, F20]

## API Contracts
- `mlx5_core_res_hold()`, `mlx5_cmd_get_srq()`, and `rsc_event_notifier()` (for `qp->event()` on QP/RQ/SQ) transfer a `common.refcount` reference that the caller/callback must release via `mlx5_core_res_put()`; conversely, `srq->event()` (`mlx5_ib_srq_event()`) borrows the reference and must NOT call `mlx5_core_res_put()`. Pair `mlx5_ib_get_native_port_mdev()` with `mlx5_ib_put_native_port_mdev()` in `fill_multiport_info()`. [F5, F6, F19, F22]
- `_mlx5r_umr_zap_mkey()` returns signed `int` status and outputs count via `size_t *nblocks`. Store returns of `mlx5r_ib_rate()`, `get_*_ts_format()`, and `calc_sq_size()` in signed `int` and check `< 0`. Check `if (!page_size)` on `mlx5_umem_find_best_quantized_pgoff()` before `order_base_2()` or `ib_umem_num_dma_blocks()`. Subtract `MLX5_ADAPTER_PAGE_SHIFT` (12) from `log_page_size`/`log_wq_pg_sz` in `qpc`/`srqc`/`xrc_srqc`/`wq`, but write unshifted `page_shift` to UMR `mkc.log_page_size`. [F43, F44, F50, F51, F57, F120]
- In send WQE construction, `size` (`wqe_sz`) is in 16B DS units while `sq->cur_post` and `sq->wqe_cnt` are in 64B WQEBBs. Keep `*seg` 16B-aligned and call `handle_post_send_edge()` on every segment advance that can reach `*cur_edge`. `mlx5r_memcpy_send_wqe()` requires a 16B-aligned `*seg` and rounds the final chunk (`!n`) with `ALIGN(copysz, 16)`. `mlx5r_finish_wqe()` advances `qp->sq.cur_post` by `DIV_ROUND_UP(size * 16, MLX5_SEND_WQE_BB)`. [F59, F90, F113, F125, F126]
- Call `mlx5_eq_update_cc(eq, cc)` per EQE in EQ IRQ loops. In `mlx5_get_roce_state()`, check `MLX5_CAP_GEN(dev, roce)` if `roce_rw_supported`, else `mlx5_is_roce_on(dev)`. [F79, F147]

## Error Handling
- In `mlx5_ib_post_send()`, `mlx5_ib_post_recv()`, and `mlx5_ib_post_srq_recv()`, every error path must set `*bad_wr = wr` and, if `nreq > 0`, jump to `out:` / `break` to ring the doorbell and advance `sq.head`, `rq.head`, or `srq->wqe_ctr`. `mlx5r_begin_wqe()` must zero `*(uint32_t *)(*seg + 8) = 0`. [F54, F55, F112]
- Guard `mlx5r_umr_cleanup()` with `dev->umrc.pd != NULL` and `mlx5r_umr_resource_cleanup()` with `dev->umrc.state != MLX5_UMR_STATE_UNINIT`. Call `nla_nest_cancel(msg, table_attr)` on error after `nla_nest_start()` in `fill_stat_mr_entry()` / `fill_res_mr_entry()`. Ignore `ib_modify_qp()` failure in `mlx5_ib_drain_sq()` / `mlx5_ib_drain_rq()` when `mdev->state == MLX5_DEVICE_STATE_INTERNAL_ERROR`. [F45, F171, F184]

## External Contracts
- For non-RSS QPs, accept `udata->inlen >= offsetof(struct mlx5_ib_create_qp, ece_options)` and check zeroed bytes from `offsetof(..., reserved)` via `ib_is_udata_cleared()`. Bound `resp.response_length` by `udata->outlen` in `mlx5_ib_modify_dct()` and `mlx5_ib_modify_qp()`. In `process_vendor_flags()` / `process_create_flags()`, clear each handled bit via `process_vendor_flag()` / `process_create_flag()` (`SCATTER_CQE` and `ALLOW_SCATTER_CQE` must be cleared without error even when `sctr_data_cqe` is false), and match mutually exclusive flag pairs (`TYPE_DCT | TYPE_DCI`, `UAR_PAGE_INDEX | BFREG_INDEX`) in a `switch`. [F88, F103, F104, F106, F107]
- In `mlx5_ib_query_qp()`, `memset` `qp_init_attr` and `qp_attr` first, and for user QPs (`ibqp->uobject != NULL`) report `max_send_wr = 0`, `max_send_sge = 0`, and omit `qp_context`. Require `capable(CAP_SYS_RAWIO)` for `IB_WQ_FLAGS_DELAY_DROP` (`-EPERM`) and `dev->port_caps[qp->port - 1].has_smi` for `IB_QPT_SMI` sends (`-EPERM`). On `IB_QP_CREATE_IPOIB_UD_LSO` QPs, insert a zeroed `mlx5_wqe_eth_pad` before `mlx5_wqe_eth_seg` and set both `L3_CSUM | L4_CSUM` on `IB_SEND_IP_CSUM`. In `create_rss_raw_qp_tir()`, reject `MLX5_RX_HASH_INNER` without `TUNNEL_OFFLOADS`, mixed IPv4/IPv6 fields, or multiple L4 protocols. [F178, F179, F180, F181, F182]

## Known Pitfalls
- Restore `sg.length = orig_sg_length` before `mlx5r_umr_unmap_free_xlt()`. On intermediate flushes in `_mlx5r_umr_update_mr_pas()`, advance `offset += sg.length`, call `mlx5r_umr_update_offset()`, and reset `cur_ksm`/`cur_mtt` to `entry`. UMR XLT buffers (`xlt_emergency_page`, `mlx5r_umr_create_xlt()`) must be dynamically allocated pages synced via `dma_sync_single_for_cpu()` / `dma_sync_single_for_device()` when reused. Convert `wqe->ctrl_seg.mkey_mask` (`__be64`) with `cpu_to_be64()` / `be64_to_cpu()`, and keep `struct mlx5r_umr_context` and `struct mlx5_ib_umr_context` layouts identical. [F9, F87, F111, F134, F155]
- In `mlx5_ib_post_send()`, `IB_WR_REG_MR_INTEGRITY` in `handle_qpt_rc()` must jump to `skip_psv` (unlike `LOCAL_INV`/`REG_MR` which zero `*num_sge`). In `mlx5_ib_modify_qp()`, check `qp->type == IB_QPT_GSI` before mapping `MLX5_IB_QPT_HW_GSI` to `qp_type = IB_QPT_GSI`, and compute `log_sra_max`/`log_rra_max` via `fls(val - 1)` when `val > 0`. [F108, F115, F116]
- `MLX5_SET*`/`MLX5_GET*` require aligned pointers and 32-bit `MLX5_SET`/`MLX5_GET` cannot cross dword boundaries; `__mlx5_mask*` must shift `1ull`. Use `MLX5_ST_SZ_BYTES` for byte sizes (adding `count * sizeof(u64)` or `sizeof(u32)` for trailing PAS/RQT arrays) and `MLX5_ST_SZ_DW` for `u32 *` offsets. Cast `icm_address_39_32`/`63_40` to `u64` before shifting >= 32, and use `1UL << page_shift` for page sizes. [F98, F99, F117, F118, F119, F129, F137]
