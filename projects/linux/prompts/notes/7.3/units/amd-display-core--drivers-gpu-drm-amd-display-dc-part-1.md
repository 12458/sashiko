# AMD DISPLAY CORE — drivers/gpu/drm/amd/display/dc (part 1)

Display Core VBIOS/ATOMFirmware parser (`dc/bios`) and Display Clock Manager base and DCE implementations (`dc/clk_mgr`). `dc/bios` parses legacy ATOMBIOS (`bios_parser.c`, `command_table.c`) and modern ATOMFirmware (`bios_parser2.c`, `command_table2.c`) data tables and executes VBIOS command tables via the interpreter or DMUB. `dc/clk_mgr` dispatches clock manager construction across ASIC families and manages display/pixel/DP reference clocks, DENTIST dividers, and PSR/Replay power state transitions.

## Architecture & Data Flow
- Because `bios_parser_types_internal.h` and `bios_parser_types_internal2.h` define incompatible `struct bios_parser` layouts, `BP_FROM_DCB` must only be used inside callbacks belonging to the matching parser's `vbios_funcs` table, never in shared helpers such as `bios_parser_helper.c`. [F431]
- In `command_table2.c`, command table initializers supporting DMUB (`init_dig_encoder_control`, `init_transmitter_control`, `init_set_pixel_clock`, `init_enable_disp_power_gating`) must wire unrecognized table revisions to their `*_fallback` handlers rather than `NULL` so DMUB execution works when VBIOS omits those tables. [F394]
- Any ASIC family or revision added to `dc_clk_mgr_create()` whose constructor allocates internal resources (e.g., `dcn3_clk_mgr_construct`, `dcn31_clk_mgr_construct`, `dcn35_clk_mgr_construct`, `dcn401_clk_mgr_construct`) must have a matching case in `dc_destroy_clk_mgr()` calling `*_clk_mgr_destroy()` before `kfree(clk_mgr)`. [F388]
- In `dce_set_clock()`, `pxl_clk_params.pll_id` must be `CLOCK_SOURCE_ID_PLL0` when `clk_mgr_base->ctx->dce_version` is `DCE_VERSION_6_0` or `DCE_VERSION_6_4`, and `CLOCK_SOURCE_ID_DFS` on newer DCE versions. When `clk_mgr_dce->dfs_bypass_active` is true, `pxl_clk_params.flags.SET_DISPCLK_DFS_BYPASS` must be set before `program_display_engine_pll()`, and both `clk_mgr_dce->dfs_bypass_disp_clk` and `actual_clock` must be updated from `pxl_clk_params.dfs_bypass_display_clock`. [F384, F439]
-When adding a new encoder type to `enum encoder_id` mapped from VBIOS object IDs, `encoder_id_from_bios_object_id()` in `bios_parser_common.c` and its inverse mappings `dal_cmd_table_helper_encoder_id_to_atom()` (`command_table_helper.c`) and `dal_cmd_table_helper_encoder_id_to_atom2()` (`command_table_helper2.c`) must be updated in lockstep. [F393]
- In `dal_graphics_object_id_is_valid()`, `id.id == 0` is valid when `id.type` is `OBJECT_TYPE_GPU` or `OBJECT_TYPE_ENGINE` (requiring only `id.enum_id != ENUM_ID_UNKNOWN`), whereas all other object types require both `id.id != 0` and `id.enum_id != ENUM_ID_UNKNOWN`. [F377]
- In `dce110` and `dce112` (both legacy and ATOMFirmware) command table helpers, `dig_encoder_sel_to_atom()` must always return `0` (no FE), whereas DCE 60 and DCE 80 helpers translate `ENGINE_ID_DIGA..G` to `ATOM_TRANMSITTER_V5__DIGA..G_SEL`. [F444]
- `dentist_get_divider_from_did` clamps `did` to `[DENTIST_BASE_DID_1, DENTIST_MAX_DID]` (`[0x08, 0x7f]`) before interpolating across the 4 DENTIST divider ranges, guaranteeing a return value `>= DENTIST_DIVIDER_RANGE_1_START` (`8`) that callers like `dce_get_dp_ref_freq_khz` can divide by without zero-check. [F402]
- In `clk_mgr_helper_get_active_display_cnt`, streams where `dc_state_get_stream_subvp_type(context, stream) == SUBVP_PHANTOM` must be skipped via `continue` before counting active displays. [F416]
- In `dce_get_max_pixel_clock_for_all_paths`, `pipe_ctx` entries with `pipe_ctx->stream == NULL` or `pipe_ctx->top_pipe != NULL` must be skipped so unallocated and underlay/split secondary pipes are excluded from the maximum pixel clock calculation. [F417]

## Synchronization
- Every DMUB VBIOS command helper in `command_table2.c` (`encoder_control_dmcub`, `transmitter_control_dmcub`, `transmitter_control_dmcub_v1_7`, `set_pixel_clock_dmcub`, `enable_disp_power_gating_dmcub`, `enable_lvtma_control_dmcub`) must invoke `dc_wake_and_execute_dmub_cmd` with `DM_DMUB_WAIT_TYPE_WAIT` so command execution completes synchronously. [F360]

## Object Lifetimes
- `bios_get_image` (and `GET_IMAGE`) returns a borrowed pointer (`bp->bios + offset`) into the caller-owned VBIOS image `init->bios` stored in `bp->base.bios`; VBIOS table pointers stored in `struct bios_parser` (`master_data_tbl`, `object_info_tbl`) must never be passed to `kfree` and require `init->bios` to outlive `struct dc_bios`. [F355]
- `dc_destroy_clk_mgr` frees the outer clock manager allocation via `kfree(TO_CLK_MGR_INTERNAL(clk_mgr_base))`, so every ASIC-specific clock manager struct allocated in `dc_clk_mgr_create` must embed `struct clk_mgr_internal base` as its first member (at offset 0), and no per-ASIC `*_clk_mgr_destroy` helper may `kfree` the `clk_mgr` struct itself. [F357]
- `dc_clk_mgr_create` must be called after `ctx->dc_bios` is initialized (and constructors must set `clk_mgr->base.ctx = ctx`), and `dc_destroy_clk_mgr` must be called before `ctx` is freed because `dce_clk_mgr_construct` reads `ctx->dc_bios` and `dc_destroy_clk_mgr` dereferences `clk_mgr_base->ctx`. [F358]
- `clk_mgr_exit_optimized_pwr_state` and `clk_mgr_optimize_pwr_state` must be called in matched pairs without back-to-back exit calls, preserving LIFO order (`hwss.exit_optimized_pwr_state` before disabling eDP PSR/Replay, and restoring PSR/Replay from `clk_mgr->psr_allow_active_cache` before `hwss.optimize_pwr_state`). [F359]

## API Contracts
- `dal_bios_parser_destroy` dispatches through `(*dcb)->funcs->bios_parser_destroy(dcb)` (`bios_parser_destroy` or `firmware_parser_destroy`), which requires a non-NULL `dcb` and `*dcb` and zeroes `*dcb = NULL` after freeing the `struct bios_parser` instance. [F356]
- When mapping a flexible-array VBIOS table in `bios_parser.c` (such as `ATOM_OBJECT_TABLE`, `ATOM_ASIC_INTERNAL_SS_INFO_V2`, `ATOM_ASIC_INTERNAL_SS_INFO_V3`, or `ATOM_GPIO_PIN_LUT`), callers must call `bios_get_image` with `struct_size(..., 1)` rather than `GET_IMAGE`, which only checks `sizeof(header)`. [F395]
- `EXEC_BIOS_CMD_TABLE(command, params)` in `command_table.c` and `command_table2.c` compares `amdgpu_atom_execute_table(...) == 0` and evaluates to `true` on success and `false` on error, so callers must treat a truthy return as `BP_RESULT_OK` and a falsy return as `BP_RESULT_FAILURE`. [F372]
- `set_pixel_clock_v3()`, `set_pixel_clock_v5()`, `set_pixel_clock_v6()`, `program_clock_v5()`, and `program_clock_v6()` must divide `bp_params->target_pixel_clock_100hz` by 100 to convert to 10kHz VBIOS units, whereas `set_pixel_clock_v7()` in `command_table.c` and `command_table2.c` passes `target_pixel_clock_100hz` unscaled in 100Hz units. In `set_pixel_clock_v3()`, `bp_params->fractional_feedback_divider` (scaled by 1,000,000) must be divided by 100,000 before casting to `uint8_t` for `allocation.sPCLKInput.ucFracFbDiv`, whereas `set_pixel_clock_v5()` and `set_pixel_clock_v6()` pass it unscaled to `ulFbDivDecFrac`. [F363, F365]
- `set_crtc_using_dtd_timing_v3()` in `command_table.c` and `command_table2.c` must subtract `h_addressable` from `h_total` and `h_sync_start` and subtract `v_addressable` from `v_total` and `v_sync_start`, adding 1 to `usV_SyncOffset`/`v_syncoffset` when `bp_params->flags.INTERLACE` is set. [F367]
- `clock_source_id_to_atom_phy_clk_src_id()` and `hpd_sel_to_atom()` in `dce60`/`dce80`/`dce110` must right-shift `ATOM_TRANSMITTER_CONFIG_V5_*` masks (`>> 2` and `>> 4`) to return unshifted bitfield values, whereas `dce112` `hpd_sel_to_atom()` returns `ATOM_TRANSMITTER_V6_HPD*_SEL` unshifted. [F374]
- In `transmitter_control_v2()`, `transmitter_control_v3()`, and `transmitter_control_v4()`, when `cntl->lanes_number > LANE_COUNT_FOUR` (dual-link), `cntl->pixel_clock` (in kHz) must be divided by 20 instead of 10 when setting `params.usPixelClock`. [F375]
- In `external_encoder_control_v3()`, `encoder.enum_id` is 1-based (`ENUM_ID_1 = 1`, `ENUM_ID_2 = 2`) and must be decremented by 1 before shifting into `cntl_params->ucConfig` bits [6:4] (`(encoder.enum_id - 1) << 4`). [F376]
- In `command_table_helper` vtables, `assign_control_parameter`, `clock_source_id_to_ref_clk_src`, and `transmitter_bp_to_atom` are `NULL` on DCE110 and DCE112, while `dc_clock_type_to_atom` and `transmitter_color_depth_to_atom` are only populated on DCE112; callers must not invoke those callbacks on DCE versions where they are `NULL`. [F454]
- In `dc_clk_mgr_create()`, `dc_destroy_clk_mgr()`, `command_table_helper.c`, and `command_table_helper2.c`, all DCN ASIC family cases (`FAMILY_RV` through `AMDGPU_FAMILY_GC_12_0_0`) must be guarded by `CONFIG_DRM_AMD_DC_FP`, and all `FAMILY_SI` / `DCE_VERSION_6_*` references (`dce60_clk_mgr_construct`, `dal_cmd_tbl_helper_dce60_get_table`) must be guarded by `CONFIG_DRM_AMD_DC_SI`. [F448, F450]

## Error Handling
- Function pointers in `bp->cmd_tbl` are set to `NULL` by `dal_bios_parser_init_cmd_tbl()` and `dal_firmware_parser_init_cmd_tbl()` when a VBIOS command table revision is absent or unsupported, so every caller must check the `bp->cmd_tbl` member for `NULL` before invoking it. [F371]
- `get_atom_data_table_revision()` in `bios_parser.c` and `bios_parser2.c` must initialize `tbl_revision->major = 0` and `tbl_revision->minor = 0` before returning when `atom_data_tbl` is `NULL`, because callers pass the unchecked result of `GET_IMAGE()` and switch on `major` and `minor`. [F378]
- In `bios_parser_get_gpio_pin_info` and `get_gpio_i2c_info` across `bios_parser.c` and `bios_parser2.c`, `usStructureSize` / `structuresize` must be checked to be at least the table header size plus one entry size before subtracting the header size to compute the unsigned entry `count`. [F396]
- In `bios_parser_get_vram_info()`, the local status variable `enum bp_result result` must be a non-static automatic variable initialized to `BP_RESULT_BADBIOSTABLE` so that each call re-initializes its status and falls back from `umc_info` to `vram_info` when `umc_info` is absent or unsupported. [F364]
- In `bios_parser_get_connector_id()` (`bios_parser.c` and `bios_parser2.c`), an index `i` beyond `tbl->ucNumberOfObjects` or `number_of_path`, or a path entry with `encoderobjid == 0` or `display_objid == 0`, represents an absent sparse connector slot and must return an `OBJECT_TYPE_UNKNOWN` object ID silently without `dm_error()` or `ASSERT()`. [F449]
- `dce_adjust_dp_ref_freq_for_ss` must check that `clk_mgr_dce->dprefclk_ss_divider != 0` before passing `dprefclk_ss_divider` as the denominator to `dc_fixpt_from_fraction`. [F424]

## External Contracts
- When executing `SetPixelClock` v5 or v6 (`set_pixel_clock_v5`, `set_pixel_clock_v6`, `program_clock_v5`, `program_clock_v6`) or `ExternalEncoderControl` v3 (`external_encoder_control_v3`), the full `*_PS_ALLOCATION_*` wrapper struct must be passed to `EXEC_BIOS_CMD_TABLE` rather than the inner parameter struct. [F405]
- In `set_dce_clock_v2_1()` (`command_table.c` and `command_table2.c`), `bp_params->target_clock_frequency` is in kHz and must be divided by 10 into 10kHz units (`ulDCEClkFreq` / `dceclk_10khz`) only when `bp_params->clock_type != DCECLOCK_TYPE_DPREFCLK`, then multiplied by 10 back to kHz after `SetDCEClock` executes. [F452]
- In `transmitter_control_v1_7()`, when executing via DMUB on a link with a non-zero `phy_transition_bitmask`, `dm_acpi_process_phy_transition_interlock()` must be called before `transmitter_control_dmcub_v1_7()` for `TRANSMITTER_CONTROL_ENABLE` and after it for `TRANSMITTER_CONTROL_DISABLE`. [F440]

## Known Pitfalls
- Callers of `EXEC_BIOS_CMD_TABLE` in `command_table.c` and `command_table2.c` must pass the parameter structure lvalue directly rather than a pointer to it, because the macro takes `&params` (cast to `uint32_t *`) and `sizeof(params)`. [F429]
- In `bios_parser_construct`, the `bp->object_info_tbl.revision.minor >= 3` branch must precede the `bp->object_info_tbl.revision.minor >= 1` branch so that v1.3+ object headers are bounds-checked as `ATOM_OBJECT_HEADER_V3` via `GET_IMAGE`. [F413]
- In `transmitter_control_v1_6` (`command_table.c` and `command_table2.c`) and `transmitter_control_v1_7` (`command_table2.c`), `dplaneset` (`ucDPLaneSet`) and `digmode` (`ucDigMode`) share a union and must be assigned in mutually exclusive `if (cntl->action == TRANSMITTER_CONTROL_SET_VOLTAGE_AND_PREEMPASIS) ... else ...` branches. [F420]
- In `enable_spread_spectrum_on_ppll_v2` and `enable_spread_spectrum_on_ppll_v3`, `bp_params->ds.feedback_amount` and `bp_params->ds.nfrac_amount` must be left-shifted by their `ATOM_PPLL_SS_AMOUNT_*_SHIFT` constants before masking with `ATOM_PPLL_SS_AMOUNT_*_MASK`, because the masks are pre-shifted and masking before shifting yields zero. [F422]
- In `adjust_display_pll_v2` and `adjust_display_pll_v3`, `bp_params->pixel_clock` and the VBIOS-returned 10 kHz output frequency must be widened to `uint64_t` before multiplication and divided using `div_u64` only after verifying the 10 kHz input clock is non-zero. [F423]
- In `dce11_pplib_apply_display_requirements`, dividing the 64-bit `dc->bw_vbios->high_yclk.value` by `memory_type_multiplier` and `10000` must use `div64_s64` rather than the `/` operator. [F427]
- In `dce_clock_read_ss_info`, `get_spread_spectrum_info` for `AS_SIGNAL_TYPE_GPU_PLL` must check both `result == BP_RESULT_OK` and `info.spread_spectrum_percentage != 0` before enabling `ss_on_dprefclk` and returning early, and must only set `dprefclk_ss_percentage` when `info.type.CENTER_MODE == 0`. [F419]
- In `get_firmware_info_v2_1` and `get_firmware_info_v2_2`, when `CENTER_MODE` is set on internal spread spectrum entries, `memory_clk_ss_percentage` and `engine_clk_ss_percentage` must be incremented by 1 before dividing by 2 to round up the halved percentage. [F426]
