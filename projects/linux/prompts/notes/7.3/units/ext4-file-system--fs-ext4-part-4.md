# EXT4 FILE SYSTEM — fs/ext4 (part 4)

Implements ext4's multi-block allocator (mballoc), directory/namespace operations (HTree and casefolding), online extent migration/defragmentation, Multi-Mount Protection (MMP), orphan tracking, and writeback bio I/O.

## Architecture & Data Flow
- `mb_update_avg_fragment_size()` and `mb_set_largest_free_order()` require `GFP_ATOMIC` (no `__GFP_NOFAIL`) for `xa_insert()` under `ext4_lock_group` and unconditional `xa_erase()` of `old >= 0`: if `bb_fragments == 0`, set `new = -1` and `bb_avg_fragment_size_order = -1` without early return; gate only `s_mb_largest_free_orders[new]` insert on `MB_OPTIMIZE_SCAN`. [F72, F73, F179]
- `mb_free_blocks()` updates `bb_free`, `bb_first_free`, and `bb_fragments` only if `mb_test_and_clear_bits() == -1`. `ext4_free_data_in_buddy()` and `ext4_mb_clear_bb()` must unconditionally call `EXT4_MB_GRP_CLEAR_TRIMMED()`. Clear `EXT4_FREE_BLOCKS_VALIDATED` if `ext4_free_blocks()` trims clusters or `ext4_mb_clear_bb()` loops (`overflow`). [F74, F75, F127]
- `ext4_mb_mark_context()` updates `gdp` `ext4_free_group_clusters`, `ext4_block_bitmap_csum_set()`, and `ext4_group_desc_csum_set()` under `ext4_lock_group()`, adds `changed` to `fg->free_clusters` if `s_log_groups_per_flex`, and sets `*ret_changed = changed`; callers skip in-core updates only if `err && changed == 0`. [F55, F76]
- `ext4_mb_scan_groups_goal_fast()` sets `CR_BEST_AVAIL_LEN` only if `EXT4_MB_HINT_DATA`, else `CR_GOAL_LEN_SLOW`; `ext4_mb_scan_groups_best_avail()` falling back to `CR_GOAL_LEN_SLOW` restores `ac_g_ex.fe_len = ac_orig_goal_len`. If `ext4_mb_try_best_found()` loses `ac_b_ex`, zero `ac_b_ex` and set `AC_STATUS_CONTINUE`, `EXT4_MB_HINT_FIRST`, and `CR_ANY_FREE`. [F78, F79, F117]
- In `ext4_mb_find_by_goal()`, stripe check (`ac_g_ex.fe_len == EXT4_NUM_B2C(sbi, sbi->s_stripe)`) precedes `max >= ac_g_ex.fe_len` so stripe extents require `do_div(start, sbi->s_stripe) == 0`. Every `ext4_mb_complex_scan_group()` iteration (including `!ext4_mb_cr_expensive()`) must advance `i` and decrement `free`. [F121, F122]
- `s_mb_largest_free_orders`, `s_mb_avg_fragment_size`, `s_mb_offsets`, `s_mb_maxs`, and `bb_counters[]` have `MB_NUM_ORDERS(sb)` (`s_blocksize_bits + 2`) elements: clamp orders below `MB_NUM_ORDERS(sb)` and bound `bb_counters` copy/zero by `s_blocksize_bits + 2`. `ext4_mb_normalize_request()` clamps `start + size <= EXT_MAX_BLOCKS` and calls `ext4_mb_pa_adjust_overlap()`. [F100, F101, F160]
- Use `ext4_inode_orphan_tracked(inode)`, not `list_empty(&ei->i_orphan)`, to include `EXT4_STATE_ORPHAN_FILE` orphans. Error paths dropping `i_nlink` before `ext4_orphan_add()` (`ext4_add_nondir()`, `ext4_symlink()`, `ext4_rename()`) must call `ext4_mark_inode_dirty()` since `ext4_orphan_file_add()` only journals the orphan file block. [F83, F85]
- `ext4_end_bio()`, `ext4_put_io_end_defer()`, and `ext4_put_io_end()` must all use `ext4_io_end_defer_completion()`. `ext4_bio_write_folio()` calls `set_buffer_async_write(bh)` on submitted buffers and `__folio_start_writeback()` before `io_submit_add_bh()`, reverting with `clear_buffer_async_write()`/`set_buffer_dirty()` on encryption error. [F94, F95]
- Indirect inodes use 32-bit block numbers, so `ext4_mb_use_preallocated()` and `ext4_ind_migrate()` reject blocks `> EXT4_MAX_BLOCK_FILE_PHYS`. `ext4_ind_migrate()` flushes `DELALLOC` via `ext4_alloc_da_blocks()` before locking `s_writepages_rwsem`/`i_data_sem`, requiring `eh_depth == 0`, `eh_entries <= 1`, and `end < EXT4_NDIR_BLOCKS`. [F113, F146, F210]
- `ext4_dx_csum_verify()`/`ext4_dx_csum_set()` check `count_offset + limit * sizeof(struct dx_entry) <= blocksize - sizeof(struct dx_tail)` and cast `struct dx_countlimit *c` to `struct dx_entry *` before `+ limit` for `struct dx_tail *`. `make_indexed_dir()` calls `ext4_check_dx_root()`; `ext4_search_dir()` checks `de->name + de->name_len <= dlimit` before `ext4_match()` and `de_len > 0`. [F107, F108, F109, F166]
- On `IS_CASEFOLDED(dir)` when `!sb_no_casefold_compat_fallback(sb)`, `__ext4_find_entry()` linearly scans on `ext4_dx_find_entry()` miss, and `ext4_match()` ignores `EXT4_DIRENT_HASH` mismatch. `ext4_rename_dir_finish()` passes `ent->inode` (not `ent->dir`) when dirtying `ent->dir_bh` while setting `parent_de->inode` to the new parent's `i_ino`. [F132, F137]

## Synchronization
- `ext4_multi_mount_protect()` sets `s_mmp_bh` before `kthread_run(kmmpd, ...)` (`kmmpd()` dereferences `s_mmp_bh` on entry), and `ext4_stop_mmpd()` finishes `kthread_stop(sbi->s_mmp_tsk)` before `brelse(sbi->s_mmp_bh)`. `kmmpd()` uses `write_mmp_block()` (`sb_start_write`/`sb_end_write`); mount/remount under `s_umount` uses `write_mmp_block_thawed()`. [F26, F27, F205]
- In `ext4_end_bio()`, if `ext4_io_end_defer_completion(io_end)`, link `bio` via `xchg(&io_end->bio, bio)` before `ext4_put_io_end_defer()` (repurposing `bio->bi_private` as a `struct bio *` list for `ext4_release_io_end()`); else call `ext4_put_io_end_defer()` before `ext4_finish_bio()`. `i_rsv_conversion_list` requires `spin_lock_irqsave(&ei->i_completed_io_lock, flags)`, checking `list_empty()` and queueing work under lock. [F30, F31, F173]
- `ext4_double_down_write_data_sem()` and `mext_folio_double_lock()` lock in ascending `struct inode *` order (`first < second`). `ext4_ext_migrate()` and `ext4_ind_migrate()` hold `ext4_writepages_down_write()`/`ext4_writepages_up_write()` outside `ext4_journal_start()`/`ext4_journal_stop()`; `ext4_ext_migrate()` sets `EXT4_STATE_EXT_MIGRATE` under `i_data_sem`, reverified under `i_data_sem` in `ext4_ext_swap_inode_data()`. [F32, F34, F187]
- `ext4_orphan_file_add()` reserves a slot via `atomic_dec_if_positive(&oi->of_binfo[i].ob_free_entries) >= 0` and claims `bdata[j]` via `cmpxchg() == 0`, calling `atomic_inc()` on error or `looped > 3`. `ext4_mb_alloc_groupinfo()` copies old `group_info` pointers into `new_groupinfo` before `rcu_assign_pointer()`, freeing `old_groupinfo` via `ext4_kvfree_array_rcu()`. [F35, F47]
- `ei->i_prealloc_lock` and `lg->lg_prealloc_lock` nest inside `ext4_lock_group()` (drop before `ext4_mb_load_buddy_gfp()`/`ext4_lock_group()`). Unlinking/reading `grp->bb_prealloc_list` requires `ext4_lock_group()`. `ext4_mb_use_group_pa()` must not advance `MB_GROUP_PA` `pa_pstart`/`pa_lstart`/`pa_free`/`pa_len`; `ext4_mb_release_context()` updates them under `pa_lock` after `ext4_mb_mark_diskspace_used()` and unlocks `ac->ac_lg->lg_mutex`. [F40, F42, F181, F183]
- Under `i_prealloc_lock`, `ext4_mb_use_preallocated()` and `ext4_mb_pa_adjust_overlap()` descend `ei->i_prealloc_node` by `pa_lstart` ignoring `pa_deleted`, then walk `rb_prev()`/`rb_next()` past `pa_deleted != 0`; once `ext4_mb_use_preallocated()` finds `pa_deleted == 0`, hold `pa_lock` across range checks, `atomic_inc(&tmp_pa->pa_count)`, and `ext4_mb_use_inode_pa()`. If `pa_count != 0` or `pa_deleted != 0` in `ext4_discard_preallocations()`, drop locks, sleep (`HZ`), and restart at `rb_first()`. [F41, F123, F124, F125]

## Object Lifetimes
- `make_indexed_dir()` always consumes `bh` (`brelse(bh)` on error or `dx_release(frames)` via `frames[0].bh`), so callers (`ext4_add_entry()`) must set `bh = NULL`. `dx_release()` copies `info->indirect_levels` to a local before `brelse(frames[i].bh)` since `info` aliases `frames[0].bh->b_data`. [F2, F133]
- When `ext4_orphan_cleanup()` clears `SB_RDONLY` and enables quotas (`quota_update = 1`), it must call `dquot_quota_off()` and restore `sb->s_flags = s_flags` on exit. When `kmmpd()` aborts before unmount (`goto wait_to_exit`), it must `put_bh(bh_check)` and sleep in `while (!kthread_should_stop())`. [F12, F14]
- Inserting into an empty `db->bb_free_root` (`!*n`) in `ext4_mb_free_metadata()` pins `bd_buddy_folio` and `bd_bitmap_folio` via `folio_get()`, balanced by `folio_put()` in `ext4_free_data_in_buddy()` when `rb_erase()` empties `bb_free_root`. `ext4_mb_use_best_found()` also pins both folios in `ac` until `ext4_mb_release_context()`. [F20, F38]
- In `ext4_prealloc_space`, `pa_node`/`pa_node_lock` depend on `pa_type` and `u.pa_tmp_list` aliases `u.pa_rcu`: `MB_INODE_PA` is erased under `write_lock(inode_lock)` and freed via `ext4_mb_pa_free()`, while `MB_GROUP_PA` is unlinked via `list_del_rcu()` under `lg_lock` and—after `list_del(&pa->u.pa_tmp_list)`—freed via `call_rcu(&pa->u.pa_rcu, ext4_mb_pa_callback)`. `ext4_mb_release()` flushes `s_discard_work` before freeing `s_group_info`/`s_buddy_cache`; `ext4_exit_mballoc()` calls `rcu_barrier()` before `kmem_cache_destroy()`. [F24, F45, F170]

## API Contracts
- `ext4_add_nondir()` consumes `*inodep` via `d_instantiate_new()` and sets `*inodep = NULL` on success; on failure it drops `i_nlink`, calls `ext4_orphan_add()`, unlocks the inode, and leaves `*inodep` non-NULL for `iput(*inodep)` after `ext4_journal_stop()`. `do_split()` may swap `*bh` with `bh2`, and on error calls `brelse(*bh)`/`brelse(bh2)` and sets `*bh = NULL`. [F1, F3]
- `read_mmp_block()` reuses `*bh` or calls `sb_getblk()`, and on error calls `brelse(*bh)` and sets `*bh = NULL`. `ext4_multi_mount_protect()` stores `bh` in `s_mmp_bh`, and if `kthread_run()` fails, resets `s_mmp_tsk = NULL` and releases `s_mmp_bh` at `failed:` because `ext4_stop_mmpd()` checks `if (sbi->s_mmp_tsk)`. [F13, F64]
- `ext4_mb_new_blocks()` and `ext4_mb_new_blocks_simple()` return `ext4_fsblk_t` (0 on failure), set `ar->len` to allocated clusters (0 on failure), and assign `*errp` on every path. In `ext4_free_extent` and `ext4_prealloc_space`, `fe_logical`/`pa_lstart`/`pa_pstart` are blocks, while `fe_start`/`fe_len`/`pa_len`/`pa_free` are clusters (`EXT4_C2B()`/`EXT4_NUM_B2C()`). [F50, F56]
- `__ext4_read_dirblock()` returns `ERR_PTR` on errors or unexpected holes (`INDEX`, `DIRENT_HTREE`, or `block == 0`), but returns `NULL` for holes at `block > 0` with `EITHER`/`DIRENT`, so check both `IS_ERR(bh)` and `!bh`. `ext4_orphan_del()` and `ext4_orphan_file_del()` accept `handle == NULL`, unlinking `s_orphan` and clearing `EXT4_STATE_ORPHAN_FILE` without journal updates. [F57, F69]
- Because `ext4_dir_entry_2::name` is 255 bytes while on-disk dirents are variable-length, advance/copy/zero dirents via `ext4_rec_len_from_disk()`/`ext4_dir_rec_len()`, never `sizeof(struct ext4_dir_entry_2)` or `de++`; pass `dir = NULL` to `ext4_dir_rec_len()` for `.` and `..` (and `dx_root_limit()`) so `ext4_dir_entry_hash` is omitted. [F162, F163]
- Dropping an `ext4_io_end_t` from `ext4_end_bio()` or while holding a JBD2 `handle_t` must use `ext4_put_io_end_defer()`, not synchronous `ext4_put_io_end()`. In `ext4_tmpfile()` and `ext4_whiteout_for_rename()`, where `dquot_initialize()` already ran on the parent dir, pass `EXT4_MAXQUOTAS_TRANS_BLOCKS()` (not `EXT4_MAXQUOTAS_INIT_BLOCKS()`) to `ext4_new_inode_start_handle()`. [F176, F194]

## Error Handling
- In `ext4_dx_add_entry()`, once `bh2` is allocated via `ext4_append()`, any error jumping to `journal_error` before `brelse(bh2)` must call `brelse(bh2)` (`cleanup` only frees `bh`/`frames`). `dx_probe()`, `ext4_dx_find_entry()`, and `ext4_dx_add_entry()` return `ERR_BAD_DX_DIR` on HTree corruption; callers must fall back to linear scan or return `-EFSCORRUPTED`. [F4, F58]
- Callers of `ext4_new_inode_start_handle()` must stop `ext4_journal_current_handle()` if non-NULL even when `IS_ERR(inode)`. If `ext4_rename()` fails after `ext4_whiteout_for_rename()`, `end_rename` must `ext4_resetent()` `old`, drop `whiteout` nlink, mark dirty, `ext4_orphan_add()`, unlock, stop `handle`, and `iput(whiteout)`. In `ext4_orphan_add()`/`ext4_orphan_del()`, paths skipping `ext4_mark_iloc_dirty()` must `brelse(iloc.bh)` (and unlink `i_orphan` on add error). [F6, F11, F61]
- In `ext4_mb_new_blocks()`, `ac->ac_pa` links to `bb_prealloc_list` only on `AC_STATUS_FOUND` with `ac_o_ex.fe_len < ac_b_ex.fe_len`, else call `ext4_mb_pa_put_free(ac)`. On error, run `ext4_discard_allocated_blocks(ac)` before `errout` sets `ac_b_ex.fe_len = 0` (skipping `MB_GROUP_PA` in `ext4_mb_release_context()`), and at `out:` (if `!EXT4_MB_DELALLOC_RESERVED`) refund `inquota - ar->len` via `dquot_free_block()` and subtract `reserv_clstrs` from `s_dirtyclusters_counter` if `!ar->len`. [F21, F22, F23]
- `ext4_get_group_info()` can return `NULL`, so callers (`ext4_mb_good_group()`, `ext4_mb_good_group_nolock()`, `ext4_mb_clear_bb()`) must check `if (!grp)` before `EXT4_MB_GRP_BBITMAP_CORRUPT(grp)`. `ext4_mb_good_group_nolock()` returns `1`, `0`, or `< 0`; `ext4_mb_scan_group()` skips on `ret <= 0` while recording the first error in `ac->ac_first_err`. [F51, F52]

## External Contracts
- With `CONFIG_UNICODE` and `IS_CASEFOLDED(dir)`, `ext4_lookup()` returns `NULL` without `d_splice_alias()` when `!inode`, and `ext4_rmdir()`/`ext4_unlink()` call `d_invalidate(dentry)` on success so negative dentries are not cached. `ext4_lookup()` must validate `ext4_valid_inum(dir->i_sb, ino)` and `ino != dir->i_ino`, converting `ERR_PTR(-ESTALE)` from `ext4_iget()` to `ERR_PTR(-EFSCORRUPTED)`. [F196, F198]
- In `ext4_bio_write_folio()`, if any skipped buffer has `buffer_dirty(bh)` or `buffer_jbd(bh) && buffer_jbddirty(bh)`, call `folio_redirty_for_writepage()` and pass `keep_towrite = true` to `__folio_start_writeback()`. In `read_mmp_block()`, if `*bh` is non-NULL, call `clear_buffer_uptodate(*bh)` before locking `*bh` and calling `ext4_read_bh()`, and verify `EXT4_MMP_MAGIC` and `ext4_mmp_csum_verify()`. [F201, F206]

## Known Pitfalls
- In `ext4_dx_add_entry()`, splitting a higher HTree node (`frame > frames`) or adding a root level (`add_level == 1`) sets `restart = 1` and must release `bh`/`frames` and `goto again` (`dx_probe()`); when splitting an immediate parent (`!add_level`) with `at - entries >= icount1`, rebase `frame->at`/`frame->entries` into `entries2` and swap `frame->bh` with `bh2` before `do_split()`. [F87, F88]
- In `ext4_rename()`, adding/updating the destination entry can split/index/convert `old.dir`, invalidating `old.de`/`old.bh`, so `ext4_rename_delete()` and `ext4_resetent()` must verify or re-lookup `old.de`. When deleting/moving a dirent without merging into a previous entry (`dx_move_dirents()`, `ext4_generic_delete_entry()`), zero from `&de->name_len` (with `de->inode = 0`) rather than `memset(de, 0, rec_len)` to preserve `de->rec_len`; `dx_pack_dirents()` must compute `ext4_next_entry()` before modifying `to->rec_len` and use `memmove()`. [F164, F165, F167]
- Widen exclusive logical end blocks of `ext4_free_extent` or `ext4_prealloc_space` to `loff_t` via `extent_logical_end()`/`pa_logical_end()` so `0x100000000` does not wrap 32-bit `ext4_lblk_t`/`int`. Widen `orig_page_offset` (`pgoff_t`) to `loff_t` before `<< PAGE_SHIFT` in `move_extent_per_page()` and `trimmed` to `uint64_t` before `<< sb->s_blocksize_bits` in `ext4_trim_fs()`. [F141, F143]
