# Hyper-V/Azure CORE AND DRIVERS — (top level) (part 2)

This unit comprises the Hyper-V SCSI/FC storage driver (`storvsc_drv.c`), UIO VMBus driver (`uio_hv_generic.c`), AF_VSOCK transport (`hyperv_transport.c`), Hyper-V headers (`include/linux/hyperv.h`, `include/hyperv/*`, `include/uapi/linux/hyperv.h`), and userspace daemons (`tools/hv/*`).

## Architecture & Data Flow

- On `struct vmbus_channel`, `primary_channel` is NULL on primary channels and non-NULL on subchannels (where `device_obj` is NULL); callbacks on both (`hv_uio_channel_cb`, `storvsc_on_channel_callback`) must resolve `hv_device` via `chan->primary_channel ? chan->primary_channel->device_obj : chan->device_obj`, while primary-only callbacks (`hv_uio_rescind`) use `chan->device_obj`. [F429]
- In `storvsc_drv.c`, `stor_device->stor_chns` has `nr_cpu_ids` entries: index `stor_chns[]` and `alloced_cpus` only by Linux CPU (`< nr_cpu_ids`, never `target_vp`). In `storvsc_change_target_cpu()`, after updating `alloced_cpus` for `old`, iterate `for_each_possible_cpu(cpu)` and clear `stor_chns[cpu]` for every CPU not in `alloced_cpus` before setting `stor_chns[new]` and `alloced_cpus` for `new`. [F487, F526]
- In `storvsc_on_io_completion()` and `storvsc_command_completion()`, clamp `sense_info_length` to `STORVSC_SENSE_BUFFER_SIZE` before copying `sense_data`, and zero `data_transfer_length` on non-overrun errors and clamp it to `cmd_request->payload->range.len` before `scsi_set_resid()`. [F466]
- In `storvsc_probe()`, clamp `max_xfer_bytes` to `STORVSC_FC_MAX_XFER_SIZE` when `is_fc` is true before deriving `host->max_sectors` and `host->sg_tablesize`. In `storvsc_on_receive()`, `VSTOR_OPERATION_FCHBA_DATA` must update `stor_device->node_name`/`port_name` via `cache_wwn()` in lockstep with `fc_host_node_name(stor_device->host)` and `fc_host_port_name(stor_device->host)`. [F448, F532]
- `hvs_channel_writable_bytes()` must return 0 when `hv_get_bytes_to_write(&chan->outbound) <= HVS_PKT_LEN(1) + HVS_PKT_LEN(0)` and subtract both lengths so the ring never hits 100% full and reserves space for `hvs_shutdown_lock_held()`'s 0-byte FIN packet. In `hvs_stream_dequeue()` and `hvs_stream_has_data()`, call `hv_pkt_iter_first(hvs->chan)` only when `hvs->recv_desc` is NULL, and advance via `hv_pkt_iter_next()` only when `hvs->recv_data_len` reaches 0 (else `hvs->recv_data_off += to_read`). [F471, F490]
- In `set_channel_pending_send_size()` under `c->outbound.ring_lock`, a non-zero `size` in `c->outbound.ring_buffer->pending_send_sz` must increment `c->out_full_total` and (if `!c->out_full_flag`) increment `c->out_full_first` and set `c->out_full_flag = true`; a zero `size` must clear `c->out_full_flag = false`. [F454]
- `__cpumask_to_vpset()` must translate each CPU via `hv_cpu_number_to_vp_number()` (returning -1 on `VP_INVAL`), verify `hv_max_vp_index / HV_VCPUS_PER_SPARSE_BANK < HV_MAX_SPARSE_VCPU_BANKS`, and zero `vpset->bank_contents[0 .. max_vcpu_bank]` inclusive before setting bits on reused `hv_tlb_flush_ex` buffers. [F478]
- In `tools/hv/vmbus_bufring.c`, every ring packet has an 8-byte trailer (`sizeof(uint64_t)`): `vmbus_txbr_write()` must reserve `total + sizeof(save_windex)` with `avail > total`, `vmbus_rxbr_peek()`/`vmbus_rxbr_read()` must require `dlen + skip + sizeof(uint64_t)` bytes, and `rte_vmbus_chan_recv_raw()` must verify `pkt.hlen >= VMBUS_CHANPKT_HLEN_MIN`, `pkt.hlen <= pkt.tlen`, and `(pkt.tlen << VMBUS_CHANPKT_SIZE_SHIFT) <= *len` before copying. [F473, F474]
- In `hv_fcopy_start()`, convert `__u16` `smsg_in->file_name` and `path_name` via `wcstoutf8()` bounded to `W_MAX_PATH - 1` chars, and in `hv_fcopy_create_file()` reject paths where `snprintf()` into `target_fname` returns `>= sizeof(target_fname)`. In `vss_operate()`, skip `/` in the `getmntent(mounts)` loop (`root_seen = 1`), freeze/thaw `/` only after `endmntent(mounts)`, and in `err:` thaw via `vss_operate(VSS_OP_THAW)` before `syslog()`. [F475, F498]

## Synchronization

- Before `vmbus_open()` in `storvsc_connect_to_vsp()` or `handle_sc_creation()`, set `channel->max_pkt_size` and `channel->next_request_id_callback`; in `handle_sc_creation()`, publish `new_sc` to `stor_device->stor_chns` and `alloced_cpus` only after `vmbus_open()` succeeds. [F408]
- For synchronous `VMBUS_RQST_INIT`/`VMBUS_RQST_RESET` packets in `handle_multichannel_storage()`, `storvsc_execute_vstor_op()`, and `storvsc_host_reset_handler()`, call `init_completion(&request->wait_event)` before `vmbus_sendpacket()`; in `storvsc_host_reset_handler()`, also call `storvsc_wait_to_drain(stor_device)` after `wait_for_completion_timeout()` before returning `SUCCESS`. [F409, F412]
- In `storvsc_dev_remove()`, order `stor_device->destroy = true` with `wmb()` before `storvsc_wait_to_drain(stor_device)`, and do not call `hv_set_drvdata(device, NULL)` or `vmbus_close(device->channel)` until `storvsc_wait_to_drain()` returns. In `storvsc_host_scan()`, hold `host->scan_mutex` across `shost_for_each_device(sdev, host)` and release it before `scsi_scan_host(host)`. [F410, F415]
- Serialize runtime updates to `stor_device->stor_chns[]` and `alloced_cpus` in `storvsc_change_target_cpu()` and `get_og_chn()` under `spin_lock_irqsave(&stor_device->lock, flags)`, using `READ_ONCE()`/`WRITE_ONCE()` for lockless reads in `storvsc_do_io()`; if `READ_ONCE(stor_device->stor_chns[q_num])` is NULL, `storvsc_do_io()` must acquire `stor_device->lock` and recheck `stor_chns[q_num]` before calling `get_og_chn()`. [F413, F414]
- In `hv_uio_remove()`, call `hv_remove_ring_sysfs(dev->channel)` and `uio_unregister_device(&pdata->info)` before `hv_uio_cleanup()` and `vmbus_free_ring()`. Because `hv_uio_probe()` and `hv_uio_new_channel()` set `HV_CALL_ISR`, `hv_uio_channel_cb()` runs in hardirq context under `rcu_read_lock()` and `channel->sched_lock` and must not sleep. [F419, F543]
- In `hvs_open_connection()`, after `vsock_find_bound_socket(&addr)` returns `sk`, hold `lock_sock(sk)` while checking `sk->sk_state`, opening `chan`, and queuing sockets, and call `sock_put(sk)` before `release_sock(sk)` on exit. [F420]
- In `hvs_close_lock_held()`, set `sock_hold(sk)` and `vsk->close_work_scheduled = true` under the socket lock before `schedule_delayed_work(&vsk->close_work, ...)`. `hvs_close_timeout()` must call `sock_hold(sk)`, `lock_sock(sk)`, and recheck `!sock_flag(sk, SOCK_DONE)` before `hvs_do_close_lock_held(vsk, false)`, while `hvs_do_close_lock_held()` (under `lock_sock(sk)`) must use `cancel_delayed_work(&vsk->close_work)`, never `cancel_delayed_work_sync()`. [F422, F549]
- Read `rbi->ring_buffer->write_index` in `hv_get_bytes_to_read()` and `read_index` in `hv_get_bytes_to_write()` with `READ_ONCE()`. `hv_begin_read()` and `hv_end_read()` must issue `virt_mb()` right after writing `rbi->ring_buffer->interrupt_mask`, and `hv_end_read()` must re-check `hv_get_bytes_to_read(rbi)` after the barrier. [F423, F424]
- In `hv_read_tsc_page_tsc()`, read `tsc_pg->tsc_sequence` with `READ_ONCE()` (returning `false` if 0), order with `smp_rmb()` before reading `tsc_scale`, `tsc_offset`, and `hv_get_raw_timer()`, and order with a second `smp_rmb()` before verifying `READ_ONCE(tsc_pg->tsc_sequence) == sequence`. [F426]
- In `tools/hv/vmbus_bufring.c`, `vmbus_txbr_write()` must atomically advance shadow `tbr->windex` via `rte_atomic32_cmpset()` (initialized to `br->vbr->windex` in `vmbus_br_setup()`), copy the packet and `save_windex` trailer, and only then spin-update shared `vbr->windex` from `old_windex` to `next_windex`. [F459]

## Object Lifetimes

- In `storvsc_queuecommand()`, once `scsi_dma_map(scmnd)` succeeds, unmap via `storvsc_on_channel_callback()` on completion or `scsi_dma_unmap(scmnd)` whenever `storvsc_do_io()` returns non-zero. In `storvsc_command_completion()`, copy `cmd_request->payload` and `payload_sz` into locals before `scsi_done(scmnd)`, and call `kfree(payload)` only when `payload_sz > sizeof(struct vmbus_channel_packet_multipage_buffer)`. [F392, F393]
- In `storvsc_probe()`, error paths after `storvsc_connect_to_vsp()` succeeds (`err_out2`..`err_out4`) must call `storvsc_dev_remove(device)` and jump to `err_out0` (`scsi_host_put(host)`), bypassing `err_out1`. `storvsc_suspend()` must drain via `storvsc_wait_to_drain()`, drain `host_dev->handle_error_wq`, close `hv_dev->channel`, free/null `stor_device->stor_chns`, and clear `alloced_cpus` before `storvsc_resume()`. [F395, F533]
- In `hv_uio_open()`/`hv_uio_release()`, call `vmbus_connect_ring()` only when `atomic_inc_return(&pdata->refcnt) == 1` (decrementing on failure) and `vmbus_disconnect_ring()` only when `atomic_dec_and_test(&pdata->refcnt)` is true. In `hv_uio_probe()` and `hv_uio_cleanup()`, call `vfree()` on `pdata->recv_buf` or `send_buf` only when `!pdata->recv_gpadl.decrypted` or `!pdata->send_gpadl.decrypted`. [F418, F557]
- In `hvs_open_connection()`, if `vmbus_open()` fails, reset `hvs_new->chan` or `hvs->chan` to NULL (and `sock_put(new)` if `conn_from_host`) before jumping to `out`. When `vmbus_open()` succeeds, complete `set_per_channel_state(chan, conn_from_host ? new : sk)` and `sock_hold(conn_from_host ? new : sk)` before `vmbus_set_chn_rescind_callback(chan, hvs_close_connection)`. [F401, F421]

## API Contracts

- In `storvsc_drv.c`, VMBus request ID `0` is reserved: `storvsc_next_request_id()` returns `blk_mq_unique_tag() + 1`, and `storvsc_on_channel_callback()` passes `rqst_id - 1` to `scsi_host_find_tag()` and rejects `VSTOR_OPERATION_COMPLETE_IO` and `VSTOR_OPERATION_FCHBA_DATA` when `rqst_id == 0`. [F436]
- In `handle_multichannel_storage()`, call `vmbus_set_sc_create_callback(device->channel, handle_sc_creation)` before sending `VSTOR_OPERATION_CREATE_SUB_CHANNELS`. `storvsc_eh_timed_out()` must always return `SCSI_EH_RESET_TIMER` (never `fc_eh_timed_out()`). Set `scsi_driver.virt_boundary_mask` and `dma_set_min_align_mask()` to `HV_HYP_PAGE_SIZE - 1`, and `host->sg_tablesize` to `(max_xfer_bytes >> HV_HYP_PAGE_SHIFT) + 1`. [F531, F577, F579]
- In `uio_hv_generic.c`, modify `channel->inbound.ring_buffer->interrupt_mask` only in `set_event()` via `hv_uio_irqcontrol()`: write `interrupt_mask = !irq_state` and `virt_mb()` before `vmbus_set_event(channel)`, and apply `set_event()` to both `dev->channel` and `&primary->sc_list` under `vmbus_connection.channel_mutex`. [F449, F493, F538]
- In `hv_uio_probe()`, set `INT_PAGE_MAP` and `MON_PAGE_MAP` sizes to `HV_HYP_PAGE_SIZE`, and `TXRX_RING_MAP` / `hv_uio_ring_mmap()` to `channel->ringbuffer_pagecount << PAGE_SHIFT`. `hv_uio_rescind()` must set `pdata->info.irq = 0`, call `uio_event_notify(&pdata->info)`, and call `vmbus_device_unregister(channel->device_obj)`. [F578, F584]
- In `hvs_open_connection()`, check `hvs_check_transport(vnew)` after `vsock_assign_transport(vnew, vsock_sk(sk))` before using `vnew->trans`. Keep `hvs_suspend`/`hvs_resume` on `hvs_drv`, and always return `0` from `hvs_probe()`. [F587, F589]
- `virt_to_hvpfn()` must resolve `is_vmalloc_addr(addr)` via `page_to_phys(vmalloc_to_page(addr)) + offset_in_page(addr)` before `>> HV_HYP_PAGE_SHIFT`. `vmbus_channel_packet_page_buffer`, `vmbus_channel_packet_multipage_buffer`, and `vmbus_packet_mpb_array` must match the packed layout of `struct vmdata_gpa_direct`. In `hv_vss_msg` and `hv_kvp_msg`, extract `operation` and `pool` from `vss_hdr`/`kvp_hdr` before assigning union-aliased `error`. [F442, F515, F559]

## Error Handling

- In `storvsc_handle_error()`, switch on `SRB_STATUS(vm_srb->srb_status)` (low 6 bits) and test `SRB_STATUS_AUTOSENSE_VALID`/`SRB_STATUS_QUEUE_FROZEN` as bit flags. In `storvsc_channel_init()`, probe `protocol_version[]` with `storvsc_execute_vstor_op(device, request, false)`. In `storvsc_on_io_completion()`, log with `storvsc_log_ratelimited()` using `STORVSC_LOGGING_WARN` for `TEST_UNIT_READY`. [F483, F486, F583]
- In `hvs_stream_enqueue()`, if a later chunk fails when `bytes_written > 0`, jump to `out` so `ret = bytes_written`. In `vss_do_freeze()`, treat `EBUSY` on `FIFREEZE` and `EINVAL` on `FITHAW` as success (`return 0`). [F441, F592]

## External Contracts

- Vsock service GUIDs must match `srv_id_template` in `b[4..15]` via `is_valid_srv_id()`, with `svm_port` in `b[0..3]` (`union hvs_service_id`). UIO ring consumers (`hv_fcopy_uio_daemon`) must divide sysfs ring `st_size` by 2 for `ring_size`, mmap `2 * ring_size` via `vmbus_uio_map()`, and set `rxbr` at `(char *)ring + ring_size`. [F472, F477]
- Pad `struct hv_ring_buffer` and `struct vmbus_bufring` headers to page size before `buffer[]`/`data[]` with no trailing fields. Never change UAPI/on-disk `HV_KVP_EXCHANGE_MAX_VALUE_SIZE` (2048) or `HV_KVP_EXCHANGE_MAX_KEY_SIZE` (512), and validate `key_size`/`value_size` against them in `kvp_key_add_or_modify()` and `kvp_get_value()`. [F480, F516]

## Known Pitfalls

- In `storvsc_queuecommand()`, zero `cmd_request->vstor_packet`, `payload->range.len`, and `payload_sz` before checking `scsi_sg_count(scmnd)`, compute `hvpg_count`/`hvpfns_to_add` with `HVPFN_UP()` on the end address and `HVPFN_DOWN()` on the start, and initialize `i = 0` once before `for_each_sg()` so `payload->range.pfn_array[i++]` packs contiguously. [F445, F488, F508]
- In `storvsc_drv.c`, `get_og_chn()` must return `stor_device->device->channel` when `num_channels == 0` before the `hash_qnum -= num_channels` loop; `storvsc_get_chs()` must use `sector_div(cylinders, heads * sectors_pt)`; and `storvsc_on_channel_callback()` must use `time_after(jiffies, time_limit)`. [F504, F507, F513]
- In `hvs_open_connection()`, when `conn_from_host` is true, pass child socket `new` to `vmbus_open()`, `set_per_channel_state()`, and `sock_hold()`, while `out:` always drops parent `sk`. In `hv_pkt_data()`, `hv_pkt_datalen()`, `hv_pkt_len()`, `fcopy_pkt_process()`, and `rte_vmbus_chan_recv_raw()`, shift 8-byte descriptor lengths (`offset8`/`hlen`, `len8`/`tlen`) left by 3, and keep `hvs->recv_desc` typed as `struct vmpacket_descriptor *` for `hvs->recv_desc + 1`. [F489, F518, F519]
- Cast to 64-bit before shifting: `(u64)` on `varhead_size`, `rep_count`, and `rep_comp` in `hv_do_rep_hypercall()`, `(u64)HV_LINUX_VENDOR_ID << 48` in `hv_generate_guest_id()`, `((uint64_t)old_windex) << 32` in `vmbus_txbr_write()`, and use `mul_u64_u64_shr(*cur_tsc, scale, 64)` in `hv_read_tsc_page_tsc()`. [F500, F501, F502, F506]
- In `hv_kvp_daemon.c`, recompute interior pointers (`readp`) and update `kvp_file_info[pool].records`, `num_blocks`, and `num_records` together after `realloc()`; bound `__u16` IP buffers in `hv_kvp_ipaddr_value` by `MAX_IP_ADDR_SIZE * 2` (`sizeof(...)`); and in `kvp_set_ip_info()` keep `process_ip_string_nm()` returning `> 0` on matches (`0` on none) and `process_dns_gateway_nm()` filtering by `ip_ver`. In `hv_fcopy_create_file()`, when `q == p` in `strchr(p, '/')`, advance `p++` and `continue`, else restore `*q = '/'` and set `p = q + 1`. [F461, F497, F499, F524]
