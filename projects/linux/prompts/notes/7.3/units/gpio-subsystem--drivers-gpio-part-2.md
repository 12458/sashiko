# GPIO SUBSYSTEM — drivers/gpio (part 2)

This unit implements `struct gpio_chip` and `struct irq_chip` backends for SoC MMIO GPIO blocks (i.MX/MXC, R-Car, MPC8xxx, PL061, Realtek Otto, RTD, SiFive, BlueField), I2C/SPI/PMIC expanders (PCA953x, PCF857x, MAX732x, PISOSR, Spreadtrum EIC), USB MPSSE bridges (`gpio-mpsse.c`), firmware mailbox expanders (`gpio-raspberrypi-exp.c`), and generic MMIO (`gpio-mmio.c`) and single-register (`gpio-reg.c`) libraries.

## Architecture & Data Flow

- In `gpio-mmio.c`, `bgpio_line2mask()`, `chip->sdata`, and `chip->sdir` must use `unsigned long` and `BIT()` (never `u32` or `1 << line`) for 64-bit registers (`chip->bits == 64`). `chip->sdir` is `1` for output and `0` for input; `bgpio_dir_in/out()` and `gpio_generic_chip_init()` must write `chip->sdir` to `reg_dir_out` and `~chip->sdir` to `reg_dir_in`. `bgpio_setup_io()` must always set `gc->set` (`bgpio_set_none` for `GPIO_GENERIC_NO_OUTPUT`), updating `bgpio_simple_dir_out()`, `bgpio_dir_out_dir/val_first()`, and `gpio_generic_chip_set()` in lockstep. [F49, F51, F100]
- In `gpio-pca953x.c`, `ngpio` must not exceed `MAX_LINE` (`MAX_BANK * BANK_SZ`, 40). `NBANK(chip)` must use `DIV_ROUND_UP(chip->gpio_chip.ngpio, BANK_SZ)`. `pca953x_bank_shift()` must compute `fls((chip->gpio_chip.ngpio - 1) / BANK_SZ)` only after `pca953x_setup_gpio()` sets `ngpio > 0`. `pca953x_irq_setup()` seeds `chip->irq_stat` from `regs->input & regs->direction`, and `pca953x_irq_pending()` must compare `regs->input & reg_direction` against `chip->irq_stat` under `chip->i2c_lock`. In `pca953x_gpio_set_pull_up_down()`, `PIN_CONFIG_BIAS_PULL_PIN_DEFAULT` and `PIN_CONFIG_BIAS_DISABLE` leave `PCAL953X_PULL_SEL` unchanged (`ret = 0`), and only `PIN_CONFIG_BIAS_DISABLE` clears `PCAL953X_PULL_EN`. [F89, F103, F104, F109, F124]
- In `gpio-rcar.c`, `gpio_rcar_config_interrupt_input_mode()` must program `POSNEG`, `EDGLEVEL`, and (`has_both_edge_trigger`) `BOTHEDGE` under `p->lock` before setting `IOINTSEL`, and write `BIT(hwirq)` to `INTCLR` afterward when `!level_trigger`. `gpio_rcar_config_general_input_output_mode()` must clear `POSNEG` and `IOINTSEL` under `p->lock` alongside `INOUTSEL` (and `OUTDTSEL` if `has_outdtsel && output`). When `!p->info.has_always_in`, `gpio_rcar_get()` and `gpio_rcar_get_multiple()` must read `OUTDT` for output lines (`INOUTSEL` set) and `INDT` only for inputs. [F62, F131, F132]
- In `gpio-mxc.c`, `GPIO_EDGE_SEL` is `-EINVAL` on SoCs without an edge-select register, so `gpio_set_irq_type()` must check `GPIO_EDGE_SEL >= 0`, and store only validated `IRQ_TYPE_*` constants (`<= IRQ_TYPE_LEVEL_LOW`, 8) into `port->pad_type[gpio_idx]` (indexed into 9-element `pad_type_map[]`). Because `mx3_gpio_irq_handler()` returns while `port->is_pad_wakeup` is true, `mxc_gpio_noirq_resume()` must call `mxc_gpio_set_pad_wakeup(port, false)` and clear `port->is_pad_wakeup = false`. `mxc_gpio_runtime_suspend/resume()` must detach/reattach chained IRQ handlers via `mxc_update_irq_chained_handler()` around `port->clk` disable/enable (detaching on clk error). [F45, F61, F81, F129]
- In `gpio-realtek-otto.c`, `realtek_gpio_probe()` must enforce `ngpios <= REALTEK_GPIO_MAX` (32) and cap `nr_cpus` to `min(resource_size(res) / REALTEK_GPIO_PORTS_PER_BANK, num_present_cpus())` for `ctrl->cpu_irq_maskable`. `realtek_gpio_irq_set_type/mask/unmask()` must update `ctrl->intr_type[line]` and `ctrl->intr_mask[line]` under `ctrl->lock` and call `realtek_gpio_update_line_imr()` to write their bitwise AND at word offset `4 * (line_shift / 32)` and shift `line_shift % 32` (`line_shift = ctrl->line_imr_pos(line)`). [F63, F79, F105]
- In `gpio-mpc8xxx.c`, lines map big-endian via `mpc_pin2mask(offset)` (`BIT(31 - offset)`) and `31 - i` in `mpc8xxx_gpio_irq_cascade()`. `mpc5121/5125_gpio_dir_out()` must reject input-only lines `28..31` and `0..3` (`-EINVAL`). `mpc8572_gpio_get()` reads outputs from `chip.sdata & out_mask` and inputs from `GPIO_DAT & ~out_mask`. On QorIQ/LS1028A/LS1088A/ACPI, `mpc8xxx_probe()` must write `0xffffffff` to `GPIO_IBE` and set `chip.sdata = GPIO_DAT & GPIO_DIR`. [F83, F143, F144]
- In `gpio-max732x.c`, `max732x_setup_gpio()` uses loop index `i` (`0..15`, `i < 8` Group A) for feature slots while `port` (`mask = 1 << port`) increments only after skipping `PORT_NONE`. In `max732x_gpio_direction_input()`, pins in both `dir_input` and `dir_output` (`PORT_OPENDRAIN`) require `max732x_gpio_set_value(gc, off, 1)`. [F60, F92]
- In `gpio-pl061.c`, `pl061_direction_output()` must write `!!value << offset` to `base + BIT(offset + 2)` both before and after setting `BIT(offset)` in `GPIODIR` under `pl061->lock`, and `pl061_suspend()` must zero `csave_regs.gpio_data` before ORing in output values. In `gpio-reg.c`, `gpio_reg_init()` sets `gc.to_irq = gpio_reg_to_irq` only when `irqs != NULL`, and `gpio_reg_get()` returns `r->out` for outputs and reads `r->reg` twice for inputs. [F47, F65, F134, F145]
- In `gpio-mpsse.c`, `gpio_mpsse_probe()` must issue `SET_BITMODE_REQUEST` with `MODE_RESET` (`0`) to `priv->intf_id + 1` before `MODE_MPSSE` (`2 << 8`), and `mpsse_read()` must read into `priv->bulk_in_buf` clamped to `min_t(size_t, len + 2, usb_endpoint_maxp(priv->bulk_in))`, check `desc.len_actual >= desc.len`, and copy `desc.len_actual - 2` bytes from `desc.data + 2`. [F117, F138]
- Keep `struct gpio_chip` at offset 0 of `struct mpsse_priv`, `struct pcf857x`, and `struct max732x_chip` (`irq_chip` callbacks cast `irq_data_get_irq_chip_data()` directly). In `gpio-mlxbf3.c`, `mlxbf3_gpio_irq_disable()` must clear `BIT(offset)` in `MLXBF_GPIO_CAUSE_OR_CLRCAUSE` after `EVTEN0`, and `mlxbf3_gpio_shutdown()` must zero `EVTEN0` and write `MLXBF_GPIO_CLR_ALL_INTS` to `CLRCAUSE`. [F112, F125]
- In `gpio-rtd.c`, `rtd_gpio_info` tables must size `dir/dato/dati/ie/dp_offset` `>= DIV_ROUND_UP(num_gpios, 32)`, `gpa/gpda_offset` `>= DIV_ROUND_UP(num_gpios, 31)`, and `deb_offset` `>= DIV_ROUND_UP(num_gpios, 8)`. In `pisosr_gpio_probe()`, `buffer_size = DIV_ROUND_UP(ngpio, 8)`. In `gpio-sch311x.c`, `sch311x_gpio_request/free()` must reject `config_regs[offset] == 0`. In `pcf857x_probe()`, with `reset_gpio`, hold high `fsleep(4)`, deassert `fsleep(100)`, and keep `n_latch = 0` (`gpio->out = ~0`). [F82, F107, F116, F140]

## Synchronization

- In `gpio-mmio.c`, hold `chip->lock` (`raw_spin_lock_irqsave()`) across every `chip->sdata` or `chip->sdir` update and `chip->write_reg()`. In `gpio-pl061.c`, `pl061->lock` is used in hardirq context, so `gpio_chip`/PM callbacks must use `raw_spin_lock_irqsave()`. In `gpio-sifive.c`, post-probe `chip->regs` accesses must hold `gpio_generic_lock_irqsave(&chip->gen_gc)`, which `sifive_gpio_irq_enable()` must drop before `gc->direction_input()` or `sifive_gpio_set_ie()`. [F16, F159, F162]
- In `gpio-pca953x.c`, `pca953x_probe()` must call `lockdep_set_subclass(&chip->i2c_lock, i2c_adapter_depth(client->adapter))` and initialize `clientdata`, `driver_data`, `ngpio`, and `check_reg` before `devm_regmap_init_i2c()`. All post-probe `chip->regmap` accesses require `chip->i2c_lock`. `chip->irq_lock` nests outside `chip->i2c_lock`, `pca953x_irq_handler()` must drop `i2c_lock` before `handle_nested_irq()`, `pca953x_irq_mask/unmask/set_type/shutdown()` only touch bitmaps (deferring I2C to `pca953x_irq_bus_sync_unlock()`), and `pca953x_save/restore_context()` must toggle `disable/enable_irq()` and `regcache_cache_only()` together under `i2c_lock`. [F18, F19, F21, F54, F149, F151]
- In `gpio-mpsse.c`, `priv->irq_mutex` nests outside `priv->io_mutex`, `gpio_mpsse_direction_output()` must drop `io_mutex` (`scoped_guard`) before `gpio_mpsse_gpio_set()`, and `mpsse_read()` callers must hold `io_mutex`. In `gpio-pcf857x.c`, `gpio->lock` protects `out/status/irq_enabled` and must be dropped before `handle_nested_irq()` in `pcf857x_irq()`. In `gpio-pmic-eic-sprd.c`, `sprd_pmic_eic_irq_mask/unmask/set_type()` only update `pmic_eic->reg[]` under `buslock`, deferring regmap I/O to `bus_sync_unlock()`. [F23, F29, F155, F161]
- In `gpio-mlxbf2.c`, bracket `YU_GPIO_MODE0_SET/CLEAR` and `MODE1_CLEAR` writes with `mlxbf2_gpio_lock_acquire/release()` (`yu_arm_gpio_lock_param.lock` mutex then `&gs->chip.lock` raw spinlock); do not sleep between them or release on acquire error. In `gpio-realtek-otto.c`, `realtek_gpio_irq_cpu_mask()` loops must iterate only over `ctrl->cpu_irq_maskable` (under `raw_spin_lock_irqsave(&ctrl->lock)` in `set_affinity`). In `gpio-mpc5200.c`, hold `gpio_lock` (`spin_lock_irqsave`) across `shadow_dvo/ddr/gpioe` and register writes. In `gpio-rdc321x.c`, hold `gpch->lock` across `data_reg` and PCI config R/W. In `gpio-sch311x.c`, bracket `SIO_CONFIG_KEY_ENTER/EXIT` (`0x55`/`0xaa`) with `request_muxed_region`/`release_region(sio_config_port, 2)`. [F30, F67, F142, F156, F163, F164]

## Object Lifetimes

- In `gpio-rcar.c`, `gpio_rcar_parse_dt()` must call `of_node_put(args.np)` when `of_parse_phandle_with_fixed_args() == 0`. `gpio_rcar_request()` must call `pm_runtime_put(p->dev)` on `pm_runtime_get_sync()` or `pinctrl_gpio_request()` failure; `gpio_rcar_free()` must call `gpio_rcar_config_general_input_output_mode(..., false)` before `pm_runtime_put()`. `gpio_rcar_probe/remove()` must call `gpiochip_remove()` before `pm_runtime_disable()`. In `rpi_exp_gpio_probe()` and `mxs_gpio_probe()`, release `of_get_parent(np)` via `of_node_put()`. [F1, F2, F3, F15, F133]
- In `mpc8xxx_probe/remove()`, call `irq_domain_remove(mpc8xxx_gc->irq)` on `devm_request_irq()` failure or unbind. In `mb86s70_gpio_remove()`, call `acpi_gpiochip_free_interrupts()` before `gpiochip_remove()`. In `men_z127_probe()`, register `mcb_request_mem()` immediately with `devm_add_action_or_reset(..., men_z127_release_mem, ...)`. In `sch311x_gpio_pdev_add()`, call `platform_device_put()` on failure after `platform_device_alloc()`. [F11, F12, F13, F14]
- When `girq->num_parents > 0`, `girq->parents` must point to heap/device-struct memory, never stack. In `gpio_reg_init()`, `names` and `irqs` are stored by pointer and must outlive the `gpio_chip` with `>= num` elements. In `gpio-sch311x.c`, `sch311x_gpio_blocks` must not be `__initdata`/`__initconst`. [F118, F119, F120]

## API Contracts

- In `bgpio_get_set_multiple()`, `bgpio_get_multiple[_be]()`, and `pcf857x_get_multiple()`, execute `*bits &= ~*mask` before ORing in read values. In `gpio-mmio.c`, recover `struct gpio_generic_chip *` via `to_gpio_generic_chip(gc)` (never `gpiochip_get_data(gc)`), pass `cfg->sz` in bytes (power of 2, `cfg->sz * 8 <= BITS_PER_LONG`, no `GPIO_GENERIC_BIG_ENDIAN_BYTE_ORDER` with `sz == 8`), and keep `gc.ngpio <= chip->bits`. [F50, F114, F115, F173]
- `gpio_chip.set_config` callbacks must return `-ENOTSUPP` for unsupported parameters and convert `PIN_CONFIG_INPUT_DEBOUNCE` arguments from microseconds. For `IRQF_SHARED` parent IRQs (`mlxbf2/mlxbf3/mediatek/rcar`), leave `girq->parent_handler/parents = NULL`, `num_parents = 0`, and use `devm_request_irq()`. In `gpio-rtd.c`, `parent_handler_data = data`, so `irq_desc_get_handler_data(desc)` returns `struct rtd_gpio *`. Non-nested `handle_edge_irq` chips (`mlxbf3/mpc8xxx/pl061/realtek/sa1100`) must define `.irq_ack`. [F121, F171, F172, F177, F178]

## Error Handling & External Contracts

- Pass negative error codes (never `client->irq`) to `dev_err_probe()`. Check `devm_mutex_init()` in `gpio_mpsse_probe()` and `pisosr_gpio_probe()`. In `rpi_exp_gpio_probe()`, `!fw` from `devm_rpi_firmware_get()` must return `-EPROBE_DEFER` after `of_node_put(fw_node)`. In `gpio-rdc321x.c`, convert PCI config status via `pcibios_err_to_errno()`. Use `platform_get_irq_optional()` in `mlxbf2/mlxbf3/realtek/sifive` probes. [F37, F38, F42, F44, F165]
- In `gpio-raspberrypi-exp.c`, every `rpi_firmware_property()` call must set `.gpio = off + RPI_EXP_GPIO_BASE` and verify `ret == 0 && .gpio == 0` on return; `rpi_exp_gpio_dir_in/out()` must preserve `rpi_exp_gpio_get_polarity()` in `RPI_FIRMWARE_SET_GPIO_CONFIG`. [F66, F76]

## Known Pitfalls

- In `gpio-pca953x.c`, `chip->check_reg` is `NULL` for `TCA6418_TYPE` (dispatch `TCA6418_TYPE` before `chip->check_reg()`), single-line ops on `TCA6418_TYPE` must use `pca953x_get_bit_mask()` (`BIT(7 - (offset % 8))` only for `offset <= 7`), `pcal6534_check_register()` must test `reg >= 0x54` before `reg >= 0x30`, and bitmap ops on `pca953x_read_regs()` output must use `gc->ngpio`, not `MAX_LINE`. [F52, F78, F86, F110]
- In `gpio-realtek-otto.c`, when `!GPIO_PORTS_REVERSED`, 1-bit bank regs use `ioread32be/write32be` while 2-bit IMR regs use `ioread32/write32` with `realtek_gpio_line_imr_pos_swapped()` (`port ^ 1`). In `gpio-rtd.c`, `gpa/gpda_offset` pack 31 GPIOs in bits 31:1 with bit 0 as `write_en` (`BIT(hwirq % 31) << 1`). [F80, F106]
- Test `(trigger & IRQ_TYPE_EDGE_BOTH) == IRQ_TYPE_EDGE_BOTH` before single-edge flags in `pl061_irq_type()`. Set `state = post_state` before `goto retry` in `sprd_pmic_eic_toggle_trigger()`. Clear the current bit on every path in `mxc/mxs/max732x` bit-scan loops. In `gpio-mxc/mxs.c`, `irq_data_get_irq_chip_data(d)` is `struct irq_chip_generic *` (`gc->private`), not `struct gpio_chip *`. In `gpio-rc5t583.c`, pass `rc5t583_gpio->rc5t583->dev` (not `gc->parent`) to MFD helpers. In `gpio-max732x.c`, widen `INT_CAPS(x)` to `uint64_t` before `<< 32`. [F84, F94, F96, F98, F99, F102]
