# DRM DRIVERS FOR ROCKCHIP — (top level)

Implements the second-generation Video Output Processor (VOP2) CRTC, plane, overlay, and register description drivers for newer Rockchip SoCs (RK3566, RK3568, RK3576, RK3588), along with legacy VOP1 register tables and the LVDS and parallel RGB display output drivers.

## Architecture & Data Flow

- In `vop2`, `sys_grf`, `vop_grf`, `vo1_grf`, and `sys_pmu` are only looked up when their `VOP2_FEATURE_HAS_*` flag is set in `vop2->data->feature`, and `vop2->lut_regs` is `NULL` when the optional `"gamma-lut"` resource is absent. Broken by: dereferencing these fields without checking the corresponding feature flag or non-NULL pointer. [F207]
- On `vop2->version <= VOP_VERSION_RK3588`, `vop2_enable()` must initialize `vop2->old_layer_sel` and `vop2->old_port_sel` from `RK3568_OVL_LAYER_SEL` and `RK3568_OVL_PORT_SEL`; when `rk3568_vop2_setup_layer_mixer()` binds `win` to `layer_id`, it must also move `old_win` (previously bound to `layer_id`) into `old_layer_id` so no window is selected by multiple layers at once. [F219, F220]
- Video port and window registers in `vop2_nonvolatile_range` are cached in `vop2->map` (`REGCACHE_MAPLE`) until `vop2_cfg_done()` latches them; `vop2_disable()` and `__vop2_regs_dump()` must call `regcache_drop_region(vop2->map, 0, vop2_regmap_config.max_register)` when powering down or dumping live hardware registers. Broken by: dropping `regcache_drop_region()` or adding non-latched status registers to `vop2_nonvolatile_range`. [F221]
- For cluster windows (`vop2_cluster_window(win)`), `vop2_plane_atomic_update()` and `vop2_win_disable()` must update `VOP2_WIN_CLUSTER_ENABLE` alongside `VOP2_WIN_ENABLE`, and `vop2_plane_atomic_update()` must clear `VOP2_WIN_AFBC_ENABLE` and `VOP2_WIN_TRANSFORM_OFFSET` to `0` when `!afbc_en`. [F225]
- In `rk3568_vop2_setup_overlay()` and `rk3576_vop2_setup_overlay()`, `vp->win_mask` and each attached plane's `win->delay` must be updated before calling `vop2_setup_alpha()` (which calls `vop2_find_start_mixer_id_for_vp()` over `vp->win_mask`) and `rk3568_vop2_setup_dly_for_windows()`. [F226]
- In `vop2_setup_alpha()`, the mixer configuration loop over `drm_atomic_crtc_for_each_plane()` must skip `zpos == 0` with `continue` and compute the register offset as `(mixer_id + zpos - 1) * 0x10`, applying any non-cluster bottom-layer global alpha (`bottom_layer_alpha_en`) at `zpos == 1`. [F254]
- On `VOP_VERSION_RK3568` (`!vop2_supports_seamless_gamma_lut_update(vop2)`), `vop2_crtc_atomic_check_gamma()` must reject enabling gamma LUT on a second CRTC via `vop2_gamma_lut_in_use()`, and `vop2_crtc_atomic_set_gamma_rk356x()` must disable `DSP_LUT_EN`, call `vop2_cfg_done()`, and poll `vop2_vp_dsp_lut_poll_disabled()` before writing `lut_regs`. [F284]
- VOP2 interrupt registers (`RK3568_VP_INT_EN`, `RK3568_VP_INT_CLR`, `RK3568_SYS0_INT_EN`, `RK3568_SYS0_INT_CLR`, `RK3568_SYS1_INT_EN`, `RK3568_SYS1_INT_CLR`) and per-VP bits in `RK3568_REG_CFG_DONE` require upper-16-bit write masks (`mask << 16 | val`) in `vop2_crtc_enable_irq()`, `vop2_crtc_disable_irq()`, `vop2_cfg_done()`, and ISRs. [F289]
- In `vop2_create_crtcs()`, `possible_crtcs` bit positions must use the sequential index `nvp` of connected video ports (`vp->crtc.port != NULL`) rather than `vp->id`, `vp->nlayers` must only be set on connected ports, and mirror windows (`vop2_is_mirror_win()`) must be skipped. Because RK3566 and RK3568 share `VOP_VERSION_RK3568` and `rk3568_vop_win_data`, RK3566 quirks (`RK3568_OTP_WIN_EN` in `vop2_enable()` and `vop2_is_mirror_win()`) must check `vop2->data->soc_id == 3566`, not `vop2->version`. [F231, F278]
- On VOP2 SoCs with `vop2->version > VOP_VERSION_RK3568`, each window on an AXI bus in `struct vop2_win_data` must have unique non-zero `axi_yrgb_r_id` and `axi_uv_r_id` (cluster IDs `< 0xf`), and `vop2_plane_atomic_update()` must program `VOP2_WIN_AXI_BUS_ID`, `VOP2_WIN_AXI_YRGB_R_ID`, and `VOP2_WIN_AXI_UV_R_ID` (which must not be written on `VOP_VERSION_RK3568`). [F280]
- Every `struct vop2_video_port_data` entry used with `rk3576_set_intf_mux()` (`rk3576_vop_video_ports`) must initialize `pixel_rate` to a non-zero value, because `rk3576_set_intf_mux()` divides `adjusted_mode->crtc_clock` by `vp->data->pixel_rate` whenever `DRM_MODE_FLAG_DBLCLK` is not set. [F261]
- `vop2_scale_factor()` must guard against `dst < 2` and `src < 2` before decrementing `src` and `dst`, use `DIV_ROUND_UP(src << shift, dst) - 1`, and clamp `fac` to `U16_MAX` to prevent division by zero, unsigned underflow, and 16-bit truncation. [F258]
- In `struct vop2`, the flexible array `struct vop2_win win[]` must remain the last member (allocated via `struct_size(vop2, win, vop2_data->win_size)` in `vop2_bind()`). In `struct vop2_data` and `struct vop_data`, `win_size` and `regs_dump_size` must be element counts (`ARRAY_SIZE`), not `sizeof`. [F240, F265]
- Each `struct vop2_regs_dump` entry's `size` field must be a multiple of 16 bytes (`0x10`), because `vop2_regs_print()` steps by 4 32-bit registers per iteration (`i += 4` while `i < dump->size >> 2`) and unconditionally reads up to `dump->base + 4 * (i + 3)`. [F242]
- Every `uint64_t` modifier array assigned to `vop2_win_data.format_modifiers` or `vop_win_phy.format_modifiers` must end with `DRM_FORMAT_MOD_INVALID`, which `drm_universal_plane_init()` scans for as a sentinel. [F268]
- In `rk3399_vop_win_data`, `rk3399_win0_data` and `rk3399_win1_data` must remain separate `struct vop_win_phy` instances despite sharing register offsets so `format_modifiers_win_full_afbc` is advertised only on `win0` and not on `win1`. [F233]
- In VOP1 `rockchip_vop_reg.c`, every `struct vop_data` using the internal parallel RGB encoder (`px30_vop_big`, `px30_vop_lit`, `rk3066_vop`, `rk3188_vop`) must include `VOP_FEATURE_INTERNAL_RGB` in `.feature`, SoCs with a hardware DMA stop bit (`rk3066_common`) must define `.dma_stop` in `struct vop_common`, and `struct vop_intr.intrs` arrays must pad unused hardware interrupt bit positions (`1 << i`) with `0`. [F243, F282]
- In `rk3288_writel()`, when `lvds->output != DISPLAY_OUTPUT_LVDS` (`DISPLAY_OUTPUT_RGB` or `DISPLAY_OUTPUT_DUAL_LVDS`), every write to channel 0 at `lvds->regs + offset` must also be mirrored to channel 1 at `lvds->regs + offset + RK3288_LVDS_CH1_OFFSET`. [F232]

## Synchronization

- `vop2_lock(vop2)` (`vop2->vop2_lock`) must be held across `vop2_crtc_atomic_enable()` and `vop2_crtc_atomic_disable()` to serialize `vop2->enable_count` transitions (gating `vop2_enable()`/`vop2_disable()` between 0 and 1) and shared Gamma LUT programming via `vop2_crtc_atomic_try_set_gamma()`, released via `vop2_unlock(vop2)` on every return path in `vop2_crtc_atomic_enable()` (including `clk_prepare_enable(vp->dclk)` or `setup_intf_mux()` failure), and `vop2_crtc_atomic_disable()` must restore `vp->dclk` to `vp->dclk_src` if reparented to `pll_hdmiphy0`/`pll_hdmiphy1`. [F184, F195, F227]
- In `vop2_crtc_atomic_disable()`, while holding `vop2->vop2_lock`, the driver must write `RK3568_VP_DSP_CTRL__STANDBY` and wait for `vp->dsp_hold_completion` (signaled by `VP_INT_DSP_HOLD_VALID` in `vop2_isr()`/`rk3576_vp_isr()`) before decrementing `vop2->enable_count` and calling `vop2_disable()` to disable `vop2->aclk`. [F295]
- `vop2_crtc_atomic_flush()` must call `vop2_cfg_done(vp)` before moving `crtc->state->event` to `vp->event` under `crtc->dev->event_lock`, and `vop2_isr()` / `rk3576_vp_isr()` must only deliver and clear `vp->event` (and call `drm_crtc_vblank_put()`) when `BIT(vp->id)` in `RK3568_REG_CFG_DONE` has cleared. [F228]
- In the `IRQF_SHARED` hardirq handlers `vop2_isr()` and `rk3576_vp_isr()`, the handler must check `pm_runtime_get_if_in_use(vop2->dev)` and return `IRQ_NONE` before any `vop2_readl()`/`vop2_writel()` access, and must release the reference with the non-sleeping `pm_runtime_put(vop2->dev)` before returning. [F294]
- Debugfs dump callbacks (`vop2_summary_show()` and `__vop2_regs_dump()`) must hold `drm_modeset_lock_all(drm_dev)` while traversing `crtc->state` and `plane->state` or while calling `regcache_drop_region(vop2->map, ...)` and reading `vop2->enable_count` and hardware registers. [F298]

## Object Lifetimes

- In `vop2_bind()`, the per-video-port `irq_name` passed to `devm_request_irq()` must be allocated with device lifetime via `devm_kasprintf()` rather than a stack buffer, because `devm_request_irq()` stores the `irq_name` pointer directly without copying. [F271]
- In `vop2_destroy_crtcs()`, all planes in `drm->mode_config.plane_list` must be cleaned up with `drm_plane_cleanup()` before iterating `drm->mode_config.crtc_list` to call `of_node_put(crtc->port)` and `drm_crtc_cleanup()`, because plane teardown references the CRTC. [F274]
- In `rockchip_lvds_bind()` and `rockchip_rgb_init()`, breaking out of `for_each_child_of_node(port, endpoint)` when `drm_of_find_panel_or_bridge()` succeeds requires an explicit `of_node_put(endpoint)`, and `of_node_put(port)` must be called on every exit path. [F194]
- In `rk3288_lvds_probe()`, if `devm_pinctrl_get()` or `pinctrl_lookup_state()` returns an `IS_ERR()` pointer, `lvds->pins` must be freed and reset to `NULL` so `rk3288_lvds_grf_config()` does not pass an error pointer `lvds->pins->p` to `pinctrl_select_state()`. [F192]
- Because `rk3288_lvds_probe()` acquires `lvds->pclk` with `devm_clk_get_prepared()`, `rk3288_lvds_poweron()` and `rk3288_lvds_poweroff()` must use `clk_enable()` and `clk_disable()` (not `clk_prepare_enable()`/`clk_disable_unprepare()`), and `rk3288_lvds_poweron()` must call `clk_disable(lvds->pclk)` if `pm_runtime_resume_and_get()` fails. [F291]

## API Contracts

- `vop2_vp_write()` and `vop2_vp_read()` add `vp->data->offset` to their `offset` argument and require VP-relative offsets (e.g. `RK3568_VP_DSP_CTRL`), whereas `vop2_writel()`/`vop2_readl()` take absolute VOP2 register offsets and `vop2_win_write()` takes an `enum vop2_win_regs` index. Broken by: passing absolute offsets like `RK3568_VP_INT_EN(vp->id)` or `RK3576_OVL_BG_MIX_CTRL(vp->id)` to `vop2_vp_write()`, or byte offsets to `vop2_win_write()`. [F216]
- Both arguments to `rk3588_calc_dclk(child_clk, max_dclk)` and the return value of `vop2_ops->setup_intf_mux()` must be in Hz (`0` on failure), whereas `drm_display_mode.crtc_clock` is in kHz and must be multiplied by `1000` before conversion. [F213]
- `vop2_parse_alpha()` must zero-initialize `src_color_ctrl.val`, `dst_color_ctrl.val`, `src_alpha_ctrl.val`, and `dst_alpha_ctrl.val` in `struct vop2_alpha` before populating `.bits`, because callers pass an uninitialized stack `struct vop2_alpha` and write `.val` to registers. [F211]
- Show callbacks in `vop2_debugfs_list` registered via `drm_debugfs_create_files()` receive a `struct drm_info_node *` in `s->private` and must retrieve `struct vop2 *` from `node->info_ent->data` (set by `vop2_debugfs_init()`), not by casting `s->private` directly. [F273]
- `rockchip_rgb_init()` returns `NULL` when no non-subdriver RGB endpoint exists, an `ERR_PTR` on failure, or a valid pointer; `vop2_bind()` must abort and call `vop2_destroy_crtcs()` on `-EPROBE_DEFER`, clear `vop2->rgb = NULL` on other `IS_ERR` returns, and call `rockchip_rgb_fini(vop2->rgb)` in `vop2_unbind()` only when `vop2->rgb` is non-NULL. [F277]

## Error Handling

- Because `enum vop2_data_format` has only non-negative enumerators (`0` to `0x16`), callers of `vop2_convert_format()` checking for `-EINVAL` must store the return value in a signed `int` before testing `< 0`. Broken by: testing `vop2_convert_format(fmt) < 0` directly or storing it in `enum vop2_data_format` or `u32`. [F204]
- In `vop2_create_crtcs()`, after scanning `vop2->win` to assign a primary plane to an active `vop2_video_port`, `vp->primary_plane` must be checked for `NULL` before `drm_crtc_init_with_planes()` dereferences `&vp->primary_plane->base`. [F205]
- `vop2_crtc_duplicate_state()` must check `!crtc->state` (with `WARN_ON(!crtc->state)`) and return `NULL` before calling `to_rockchip_crtc_state(crtc->state)` and `kmemdup()`. [F206]
- In `rockchip_lvds_bind()`, when `drm_of_find_panel_or_bridge()` returns a non-zero error `ret`, the error path must return that exact `ret` rather than overwriting it with a hardcoded error code. [F208]
- In the hardirq handlers `vop2_isr()` and `rk3576_vp_isr()`, hardware scanout underrun (`VP_INT_POST_BUF_EMPTY`) and AXI bus error (`VOP2_INT_BUS_ERRPR`) interrupts must be logged with `drm_err_ratelimited()` rather than unratelimited logging or `WARN*()`. [F300]

## Known Pitfalls

- In `rk3568_vop_cluster_regs`, `rk3568_vop_smart_regs`, `rk3576_vop_cluster_regs`, and `rk3576_vop_smart_regs`, any `enum vop2_win_regs` entry not supported by that window type that may be written via `vop2_win_write()` must be initialized to `{ .reg = 0xffffffff }` so `vop2_regmap_init()` does not add `win->offset` to default register `0`. [F222]
- Because `enum vop2_layer_phy_id` values for cluster windows (`ROCKCHIP_VOP2_CLUSTER0..ROCKCHIP_VOP2_CLUSTER3`) are non-contiguous (`0, 1, 6, 7`), `vop2_setup_cluster_alpha()` and other hardware-indexed logic must map `win->data->phys_id` via an explicit `switch` rather than multiplying `phys_id` by a stride. [F235]
- In `struct vop2_video_port_data`, `pre_scan_max_dly[4]` has two indexing conventions depending on `setup_bg_dly`: `rk3568_vop2_setup_bg_dly()` reads `pre_scan_max_dly[3]` directly, whereas `rk3576_vop2_setup_bg_dly()` sums indices `VOP2_DLY_WIN` (0), `VOP2_DLY_LAYER_MIX` (1), and `VOP2_DLY_HDR_MIX` (2). [F241]
- In `rk3568_set_intf_mux()`, every endpoint case in `switch (id)` must update both its interface enable/mux bits in `die` (`RK3568_DSP_IF_EN`) and its pin polarity bitfield in `dip` (`RK3568_DSP_IF_POL`) with `polflags`; in `rk3588_set_intf_mux()`, each endpoint case must clear and set its own matching `RK3588_SYS_DSP_INFACE_EN_*` bitfields in `die`; and in `rk3568_vop2_setup_layer_mixer()`, each video port (`vp0..vp2`) must write its layer boundary into its own matching `RK3568_OVL_PORT_SET__PORT*_MUX` field in `port_sel`. [F246, F247, F249]
- In `rk3588_calc_cru_cfg()`, per-interface branches must assign raw power-of-two divider factors (`1`, `2`, or `4`) to `*if_pixclk_div`, `*if_dclk_div`, and `*dclk_out_div` rather than shift exponents, because the function converts all four divider outputs in-place via `ilog2()` at the end. [F262]
- In `vop2_setup_scale()`, vertical prescale checks must test `>= (4 * dst_h)` before `else if (... >= (2 * dst_h))`, and `gt4` and `gt2` must be reset to `0` before computing `cbcr_src_h` prescaling in the `info->is_yuv` branch. [F253]
- In `vop2_afbc_transform_offset()` and `vop2_plane_atomic_update()`, bits-per-pixel must be obtained via `vop2_get_bpp(fb->format)` rather than `drm_format_info_bpp()`, because `DRM_FORMAT_YUV420_8BIT` and `DRM_FORMAT_YUV420_10BIT` have zero `cpp` in DRM core and would divide by zero in `(fb->pitches[0] << 3) / bpp`. [F257]
- In `vop2_plane_atomic_update()`, when `afbc_en` is true, `VOP2_WIN_AFBC_HDR_PTR` (and on `VOP_VERSION_RK3576`+, `VOP2_WIN_AFBC_PLD_OFFSET` with `VOP2_WIN_AFBC_PLD_OFFSET_EN`) must use the zero-offset framebuffer base (`rk_obj->dma_addr + fb->offsets[0]`) while crop offsets go to `VOP2_WIN_TRANSFORM_OFFSET` and `VOP2_WIN_AFBC_PIC_OFFSET`; additionally, `VOP2_WIN_AFBC_AUTO_GATING_EN` has inverted polarity (`0` on `VOP_VERSION_RK3568`, `1` on `vop2->version != VOP_VERSION_RK3568`). [F287, F288]
- In `vop2_create_crtcs()`, `char dclk_name[9]` has no spare capacity beyond `"dclk_vp"` (7 bytes), a single-digit `vp->id` (1 byte), and NUL (1 byte); lengthening the format string or supporting `vp->id >= 10` requires enlarging `dclk_name`. [F272]
