# FUNCTION HOOKS (FTRACE) — (top level)

Provides the public header interface (`include/linux/ftrace.h`) and per-architecture backends (`arch/*/kernel/ftrace.c`, `arch/*/include/asm/ftrace.h`) for function tracing, dynamic callsite patching, function graph return hooking, and kprobes-on-ftrace.

## Architecture & Data Flow

- Under `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, every path in `ftrace_init_nop()`, `ftrace_make_nop()`, and `ftrace_replace_code()` that initializes or converts a callsite to NOP must call `ftrace_rec_set_nop_ops(rec)` (`&ftrace_nop_ops`). On arm64 and riscv, `ftrace_rec_set_ops()` must compute the pre-function literal slot as `ALIGN_DOWN(rec->ip - 12, 8)` so a 4-byte `BTI` shifting `rec->ip` from `+12` to `+16` still resolves to the 8-byte-aligned base; on riscv, pass `&ops` and `sizeof(ops)` (not `ops`/`sizeof(*ops)`) to `patch_text_nosync()`. [F43, F65, F98]
- In `ftrace_partial_regs()` and `arch_ftrace_fill_perf_regs()`, set the kernel-mode state field in `struct pt_regs` (`pstate = PSR_MODE_EL1h` on arm64, `cs = __KERNEL_CS` on x86, `psw.mask = 0` on s390, `msr` on powerpc) so `user_mode(regs)` is false. On arm64 and riscv, bound `ftrace_partial_regs()` `memcpy()` by the source array (`sizeof(afregs->regs)` on arm64, `sizeof(afregs->args)` on riscv), not `pt_regs`. On arm64, `sizeof(struct __arch_ftrace_regs)` must be a 16-byte multiple (via `__unused` when `!CONFIG_DYNAMIC_FTRACE_WITH_DIRECT_CALLS`); on RISC-V (`CONFIG_DYNAMIC_FTRACE_WITH_ARGS`), include `t2`–`t6` under `CONFIG_CC_IS_CLANG`. [F33, F96, F99, F127]
- On x86_64, `create_trampoline()` and `set_ftrace_ops_ro()` must size dynamic trampolines as `(end_offset - start_offset) + RET_SIZE + sizeof(void *)` (return at `+ size`, `ftrace_ops *` at `+ size + RET_SIZE`), computing `npages` via `DIV_ROUND_UP(..., PAGE_SIZE)`. In `create_trampoline()`, cloning `ftrace_regs_caller` (`FTRACE_OPS_FL_SAVE_REGS`) must check `ftrace_regs_caller_jmp` starts with `0x75`, overwrite it with a 2-byte NOP, and retarget the RIP-relative `movq` at `op_offset`; if `cpu_wants_rethunk_at(ip)` at `trampoline + size`, emit a `JMP32_INSN_OPCODE` to `x86_return_thunk` via `__text_gen_insn()` instead of `RET_INSN_OPCODE`. [F48, F73, F94, F106]
- In x86 `ftrace_replace_code()`, all records must pass `ftrace_verify_code()` via `ftrace_test_record()` before any callsite is queued with `smp_text_poke_batch_add()` or mutated with `ftrace_update_record()`, and any pointer assigned to `ftrace_expected` must point to static storage or be cleared (`ftrace_expected = NULL`) after `ftrace_bug()`. On architectures with separate default and reg-saving trampolines without `CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS` (x86, powerpc, arm, csky), `ftrace_update_ftrace_func()` must patch both `ftrace_call` and `ftrace_regs_call`. [F46, F49, F103]
- In `ftrace_find_callable_addr()` (arm64, LoongArch) and `ftrace_get_call_inst()` (powerpc), replace an unreachable custom trampoline address with `FTRACE_ADDR` or `FTRACE_REGS_ADDR` before testing reachability or resolving a module PLT/stub. On arm64, `get_ftrace_plt()` must check `within_module_mem_type(addr, mod, MOD_INIT_TEXT)` for `mod->arch.init_ftrace_trampolines` and `MOD_TEXT` for `mod->arch.ftrace_trampolines` using callsite `pc`. [F85, F123]
- `FTRACE_MCOUNT_MAX_OFFSET` must cover the max byte offset from symbol entry to `rec->ip` (`16` on 64-bit powerpc, `8` on `CONFIG_PPC32`, `ENDBR_INSN_SIZE` on x86 `CONFIG_HAVE_FENTRY`). On x86, `arch_ftrace_get_symaddr(fentry_ip)` must subtract `ENDBR_INSN_SIZE` if `is_endbr((void *)(fentry_ip - ENDBR_INSN_SIZE))`. On arm64 (`CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`), `ftrace_call_adjust()` must verify 8-byte alignment of `addr`, skip two literal NOPs, skip `BTI` if `CONFIG_ARM64_BTI_KERNEL` and `aarch64_insn_is_bti()`, and skip `MOV X9, LR`. [F68, F124, F125]
- On powerpc (`CONFIG_PPC_FTRACE_OUT_OF_LINE`), `ftrace_get_ool_stub(rec)` (`rec->arch.ool_stub`) stores `&ool_stub->insn[0]` (`ftrace_op` at `- sizeof(unsigned long)`, `bl ftrace_caller` at `+ MCOUNT_INSN_SIZE`). `ftrace_make_call()` / `ftrace_replace_code()` must patch both `ftrace_get_ool_stub(rec) + MCOUNT_INSN_SIZE` and `rec->ip`. `ftrace_init_ool_stub()` must check `*ool_stub_index > ool_stub_count` and verify both `&ool_stub->insn[0]` and `&ool_stub->insn[3]` satisfy `is_offset_in_branch_range()`. On 64-bit PowerPC (`!CONFIG_MPROFILE_KERNEL`), `__ftrace_make_nop()` must verify `ip + 4` is `PPC_INST_LD_TOC` and patch to `PPC_RAW_BRANCH(8)` rather than `PPC_RAW_NOP()`. [F50, F69, F100, F129]
- On s390, `ftrace_make_call()`, `ftrace_make_nop()`, and `ftrace_modify_call()` must check `cpu_has_seq_insn()`, calling `ftrace_patch_branch_insn()` (which must verify `IS_ALIGNED(ip, 8)`) only when supported, and otherwise patching `trampoline->interceptor` and `ftrace_patch_branch_mask()`. `ftrace_insn::disp` is in halfwords (`(target - ip) / 2`) and must be widened to `s64` (`(s64)insn.disp * 2`) in `ftrace_get_trampoline()`. `ftrace_init_nop()` must check `*next_trampoline >= trampolines_end` (`-ENOMEM`), and `struct ftrace_hotpatch_trampoline` must stay `__packed` and equal `SIZEOF_FTRACE_HOTPATCH_TRAMPOLINE` (24). [F71, F72, F105]
- On RISC-V, `to_auipc_t0(offset)` must add `AUIPC_PAD` (`0x1000`) when `offset & JALR_SIGN_MASK` (`0x800`) is set, and `ftrace_make_call()` must fall back to `FTRACE_ADDR` when distance from `ftrace_caller` exceeds `JALR_RANGE` (`0x7ff`). On 32-bit ARM, `ftrace_call_adjust()` must clear bit 0 (`addr & ~1`), and `ftrace_modify_code()` must convert `old` via `__opcode_to_mem_thumb32(old)` or `__opcode_to_mem_arm(old)`. On 64-bit PARISC, `ftrace_make_call()` must select `ftrace_trampoline_unaligned` when `rec->ip & 0x4` and patch at `rec->ip + 4 - size`. [F66, F74, F77]
- In LoongArch `ftrace_get_parent_ra_addr()`, bound backward scanning (`insn--`) by `limit = 32` (`-EINVAL`). On 64-bit MIPS, `arch_syscall_addr(nr)` must check `[__NR_<ABI>_Linux, __NR_<ABI>_Linux + __NR_<ABI>_Linux_syscalls)` before indexing `sys*_call_table`, returning `(unsigned long)&sys_ni_syscall` otherwise. `ftrace_regs_get_kernel_stack_nth()` must verify `(stackp + nth)` and `stackp` share the same `~(THREAD_SIZE - 1)` base. `FTRACE_FL_*` flags in `struct dyn_ftrace.flags` must use `1UL` shifts `>= FTRACE_REF_MAX_SHIFT` (19). [F57, F75, F76, F89]

## Synchronization

- Callers of `function_graph_enter_regs()` and `function_graph_enter()` (`ftrace_graph_func()`, `prepare_ftrace_return()`) must not call `ftrace_test_recursion_trylock()`, which is acquired internally. Conversely, `kprobe_ftrace_handler()` must acquire `ftrace_test_recursion_trylock(ip, parent_ip)` before calling `get_kprobe()` or touching per-CPU kprobe state (`current_kprobe`, `get_kprobe_ctlblk()`), reset `current_kprobe = NULL`, and call `ftrace_test_recursion_unlock(bit)` on all exit paths. [F5, F29]
- A static `struct ftrace_ops` on `ftrace_ops_list` must never be freed or have `ops->next` modified after `register_ftrace_function()`, even after `unregister_ftrace_function()`, because lockless readers traverse `ftrace_ops_list` without a grace period; `do_for_each_ftrace_op()` / `while_for_each_ftrace_op()` must stop at `&ftrace_list_end` (as well as `NULL`). [F16, F59]
- `ops_func` callbacks are invoked with `direct_mutex` and `ftrace_lock` held for `FTRACE_OPS_CMD_ENABLE_SHARE_IPMODIFY_SELF`, and `direct_mutex` only for `FTRACE_OPS_CMD_ENABLE_SHARE_IPMODIFY_PEER` / `DISABLE_SHARE_IPMODIFY_PEER`. `stack_tracer_disable()` / `stack_tracer_enable()` require preemption or IRQs disabled across both calls on the same CPU. `__ftrace_enabled_save()` / `__ftrace_enabled_restore()` require caller synchronization across the pair. [F17, F18, F19]
- On x86, `ftrace_arch_code_modify_prepare()` locks `text_mutex` and sets `ftrace_poke_late = 1`; `ftrace_arch_code_modify_post_process()` must run `smp_text_poke_batch_finish()` and reset `ftrace_poke_late = 0` before unlocking `text_mutex`. On x86_64, `create_trampoline()` and `arch_ftrace_update_trampoline()` must hold `text_mutex` while generating and poking the callback `CALL`, and `create_trampoline()` must call `set_memory_rox()` only after all code and the `ops` pointer are written. [F3, F21, F119]
- On RISC-V, `ftrace_init_nop()` runs outside `ftrace_arch_code_modify_prepare()`/`post_process()` and must acquire `text_mutex` itself before `ftrace_rec_set_nop_ops()` and `patch_insn_write()`. `arch_ftrace_update_code()` must call `flush_icache_all()` after `ftrace_modify_all_code()`, and when `!CONFIG_DYNAMIC_FTRACE_WITH_CALL_OPS`, `ftrace_update_ftrace_func()` must run `smp_wmb()` and `smp_call_function(ftrace_sync_ipi, NULL, 1)` with IRQs enabled after `WRITE_ONCE(ftrace_call_dest, func)`. [F22, F120]
- On s390 (`!cpu_has_seq_insn()`), `ftrace_init_nop()` must write `ftrace_hotpatch_trampoline` before patching `insn->disp` at `rec->ip`, and `ftrace_make_trampoline_call()` must write `trampoline->interceptor` before enabling the branch mask; `ftrace_arch_code_modify_post_process()` must call `text_poke_sync_lock()`. On SuperH, `do_ftrace_mod_code()` must use the `mod_code_ip`/`mod_code_newcode`, `smp_mb()`, `wait_for_nmi_and_set_mod_flag()`, `clear_mod_flag()`, and `wait_for_nmi()` handshake. On C-SKY (`!CONFIG_CPU_HAS_ICACHE_INS`), only CPU 1 (`atomic_inc_return(&param->cpu_count) == 1`) runs `ftrace_modify_all_code()` and increments `cpu_count` again while other CPUs spin until `cpu_count > num_online_cpus()` before `local_icache_inv_all()`. [F26, F27, F28, F121]

## Object Lifetimes

- When `private` data is attached to a core-kernel (non-`FTRACE_OPS_FL_DYNAMIC`) `struct ftrace_ops`, the caller must execute `schedule_on_each_cpu()` after `unregister_ftrace_function()` before freeing `ops->private`. [F15]
- On x86_64, `arch_ftrace_update_trampoline()`, `set_ftrace_ops_ro()`, `arch_ftrace_trampoline_func()`, and `arch_ftrace_trampoline_free()` must require `ops->flags & FTRACE_OPS_FL_ALLOC_TRAMP`. `arch_ftrace_trampoline_free()` must clear `ops->trampoline = 0` after `tramp_free()`, and `create_trampoline()` must call `tramp_free(trampoline)` without setting `FTRACE_OPS_FL_ALLOC_TRAMP` on error. [F2, F47]
- On PowerPC (`ftrace.c`, `ftrace_64_pg.c`), `ftrace_free_init_tramp()` must zero the `ftrace_tramps[]` slot holding `(unsigned long)ftrace_tramp_init` when `.init.text` is freed, and `find_ftrace_tramp()` must `continue` past zero `ftrace_tramps[i]` slots rather than stopping on `!ftrace_tramps[i]`. `ftrace_enable_ftrace_graph_caller()` and `ftrace_disable_ftrace_graph_caller()` must symmetrically enable/disable the graph caller branch or static key. [F8, F10, F83]

## API Contracts

- Attribute flags in `struct ftrace_ops->flags` (`FTRACE_OPS_FL_SAVE_REGS`, `FTRACE_OPS_FL_SAVE_REGS_IF_SUPPORTED`, `FTRACE_OPS_FL_RECURSION`, `FTRACE_OPS_FL_STUB`, `FTRACE_OPS_FL_IPMODIFY`) must be set before registration and never modified while registered. [F14]
- The `struct module *mod` parameter to `ftrace_make_nop()` is non-NULL only during module load and `NULL` at runtime. When `mod` is `NULL`, `ftrace_find_callable_addr()` (arm64, LoongArch), `ftrace_lookup_module_stub()` (PowerPC), and `ftrace_lookup_module()` (PPC64) must call `__module_text_address()` under `guard(rcu)()` while relying on caller-held `ftrace_lock`; on 32-bit ARM (`CONFIG_ARM_MODULE_PLTS`), `ftrace_make_nop()` must cache `mod` in `rec->arch.mod` on load and fall back to `rec->arch.mod` when `mod` is `NULL`. [F11, F38, F53]
- With `CONFIG_HAVE_DYNAMIC_FTRACE_WITH_ARGS`, `arch_ftrace_get_regs()` / `ftrace_get_regs()` must return `NULL` unless a full `struct pt_regs` was saved (`regs.cs` on x86, `PIF_FTRACE_FULL_REGS` on s390, `regs.msr` on powerpc, or always `NULL` on arm64/riscv). On arm64 and riscv, `ftrace_regs_get_argument()` must enforce `n < 8` and return `0` for `n >= 8`. [F32, F62]
- `ftrace_regs_set_instruction_pointer(fregs, ip)` must write `ip` to the saved PC field of `fregs` (`instruction_pointer_set()` on LoongArch, `pc` on arm64, `epc` on riscv, `psw.addr` on s390, `regs_set_return_ip()` on powerpc), not the return-value register. With `CONFIG_DYNAMIC_FTRACE_WITH_DIRECT_CALLS`, `arch_ftrace_set_direct_caller(fregs, addr)` must write `addr` to the register slot checked by `ftrace_caller` exit (`direct_tramp` on arm64, `t1` on RISC-V, `regs[13]` on LoongArch, `orig_ax` on x86, `orig_gpr2` on s390, `orig_gpr3` on PowerPC). [F34, F130]
- In `ftrace_graph_func()` and `prepare_ftrace_return()`, the `retp` argument to `function_graph_enter_regs()` / `function_graph_enter()` must match the stack/frame pointer passed by the unwinder to `ftrace_graph_ret_addr()` (`(unsigned long *)sp` on s390/powerpc, `(void *)frame_pointer` on arm64), not a saved register address inside `ftrace_regs`. [F35]
- Architectures with prefixed syscall wrapper symbols (`__riscv_`, `__arm64_`, `__x64_sys`, `__s390x_`, `ppc_`, `__sys_`) must define `ARCH_HAS_SYSCALL_MATCH_SYM_NAME` and `arch_syscall_match_sym_name(sym, name)`. 64-bit architectures with separate 32-bit compat syscall tables must define `ARCH_TRACE_IGNORE_COMPAT_SYSCALLS` and `arch_trace_is_compat_syscall(regs)`. [F134, F135]

## Error Handling

- `ftrace_make_nop()`, `ftrace_init_nop()`, `ftrace_make_call()`, and `ftrace_modify_call()` must return `0` on success, `-EFAULT` on read fault, `-EINVAL` on unexpected instruction bytes, or `-EPERM` on write fault. On s390, `ftrace_get_trampoline()` returns `ERR_PTR(-EFAULT)` or `ERR_PTR(-EINVAL)` (not `NULL`) on failure, so callers must check `IS_ERR(trampoline)` and propagate `PTR_ERR(trampoline)`. [F30, F41]
- `function_graph_enter()` and `function_graph_enter_regs()` return `0` on success and negative (`-EBUSY`) on failure; `prepare_ftrace_return()` and `ftrace_graph_func()` must only redirect the return address when `0` is returned, and on architectures that overwrite `*parent = return_hooker` beforehand (ARM, MIPS, SuperH, MicroBlaze), must restore `*parent = old` on non-zero return. [F9, F36]

## External Contracts

- When `ARCH_SUPPORTS_FTRACE_OPS` is 0, `arch_ftrace_ops_list_func()` must be declared and defined with two parameters (`unsigned long ip, unsigned long parent_ip`), while `ftrace_ops_list_func` is linker-aliased to it with the 4-parameter `ftrace_func_t` signature. [F104]

## Known Pitfalls

- Despite the inverted kernel-doc comment in `include/linux/ftrace.h`, `ftrace_need_init_nop()` must return nonzero (`true`) when `ftrace_init_nop()` is needed for each callsite and `0` (`false`) when compiler NOPs need no initialization. In `ftrace_replace_code()`, `ftrace_get_addr_curr(rec)` must be called before `ftrace_update_record(rec, enable)`, which mutates the `FTRACE_FL_*_EN` flags that `ftrace_get_addr_curr()` reads. [F31, F45]
- Signedness and macro pitfalls: in `reachable_by_bl()` (arm64, LoongArch), compute `long offset = (long)addr - (long)pc` before comparing against `-SZ_128M` and `SZ_128M`; on PowerPC, `find_bl_target()` must sign-extend the 26-bit `PPC_LI()` offset from bit 25 (`if (offset & 0x02000000) offset |= 0xfe000000`) and cast to `long` before adding to `ip`, and `ftrace_dyn_arch_init()` must cast `SZ_8G`/`SZ_2G` to signed (`(long)`/`(long long)`) before unary negation; on RISC-V, parenthesize `make_call_t0` macro arguments `caller` and `callee` before casts and `-`. [F78, F91, F93, F95]
- In arm64 `arch_ftrace_get_symaddr()`, reading `fentry_ip - AARCH64_INSN_SIZE * 2` under `CONFIG_ARM64_BTI_KERNEL` must use `get_kernel_nofault()` when `(fentry_ip & ~PAGE_MASK) < AARCH64_INSN_SIZE * 2` and pass `le32_to_cpu((__le32)insn)` to `aarch64_insn_is_bti()`. [F64]
- `get_lock_parent_ip()` (`include/linux/ftrace.h`) and s390's `return_address(n)` must be `__always_inline` (and s390's `return_address(n)` must check `if (!n)` before `do { ... } while (--n);`). On x86, `prepare_ftrace_return()` and `ftrace_graph_func()` must call `skip_ftrace_return()` (checking `(long)__builtin_frame_address(0) >= 0` and `current->tracing_graph_pause`). On 32-bit ARM (`CONFIG_UNWINDER_FRAME_POINTER`), `prepare_ftrace_return()` must read `frame_pointer - 8` via inline `__get_kernel_nofault()` rather than any traceable helper. [F88, F108, F118, F128]
