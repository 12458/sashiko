# CAN NETWORK DRIVERS — drivers

USB CAN/CAN-FD adapter drivers (`kvaser_usb`, `peak_usb`, `ucan`, `usb_8dev`), virtual CAN network interfaces (`vcan`, `vxcan`), and the generic CAN transceiver PHY driver (`drivers/phy/phy-can-transceiver.c`).

## Architecture & Data Flow

- `vcan` and `vxcan` allocate `net_device` via `rtnl_link_ops` without `struct can_priv` at `netdev_priv(dev)`: `vxcan_link_ops.priv_size` reserves `ALIGN(sizeof(struct vxcan_priv), NETDEV_ALIGN) + sizeof(struct can_ml_priv)` with `can_ml_priv` placed at that offset in `vxcan_setup()`, and callbacks must never call `can_dev_dropped_skb()`, `can_change_mtu()`, or helpers casting `netdev_priv(dev)` to `struct can_priv *`. [F428, F450]
- In `vxcan`, `vxcan_open()` calls `netif_carrier_on()` on both `dev` and `peer` only when `peer->flags & IFF_UP`, whereas `vxcan_close()` calls `netif_carrier_off()` on `dev` and `peer` (if non-NULL). [F401]
- In `kvaser_usb_probe()`, `dev_init_card()`, `dev_get_software_info()`, `dev_get_software_details()`, `dev_get_card_info()`, and `dev_get_capabilities()` must finish before `kvaser_usb_init_one()` or `kvaser_usb_setup_rx_urbs()`; `kvaser_usb_init_one()` calls `alloc_candev()` with `struct_size(priv, tx_contexts, dev->max_tx_urbs)` after `max_tx_urbs` is finalized, and optional `kvaser_usb_dev_ops` callbacks (`dev_reset_chip`, `dev_init_channel`, `dev_remove_channel`, `dev_get_software_details`, `dev_get_capabilities`) must be null-checked. [F391, F453, F476]
- In `kvaser_usb`, free `priv->tx_contexts[]` slots have `echo_index = dev->max_tx_urbs`; acquiring/releasing slots in `kvaser_usb_start_xmit()`, `kvaser_usb_hydra_tx_acknowledge()`, or `kvaser_usb_leaf_tx_acknowledge()` must update `echo_index` and `active_tx_contexts` under `priv->tx_contexts_lock`, and `kvaser_usb_leaf_set_mode(CAN_MODE_START)` and `kvaser_usb_close()` must call `kvaser_usb_unlink_tx_urbs(priv)` to kill `tx_submitted` URBs and reset `active_tx_contexts = 0` and `echo_index = dev->max_tx_urbs`. [F359, F407]
- In `kvaser_usb`, `dev->nchannels` must be capped to `KVASER_USB_MAX_NET_DEVICES` (`MAX_USBCAN_NET_DEVICES` for `KVASER_USBCAN`) in `get_card_info`, and RX handlers must verify `channel < dev->nchannels` before indexing `dev->nets[channel]`. [F420]
- In `kvaser_usb_hydra`, `struct kvaser_cmd *` may be downcast to `struct kvaser_cmd_ext *` only when `cmd->header.cmd_no == CMD_EXTENDED`, and `kvaser_usb_hydra_frame_to_cmd()` may use `kvaser_cmd_ext` only when `KVASER_USB_HYDRA_CAP_EXT_CMD` is set; `kvaser_usb_hydra_read_bulk_callback()` must check `<= KVASER_USB_HYDRA_MAX_CMD_LEN` before `memcpy()` into `card_data->usb_rx_leftover`; and `kvaser_usb_hydra_set_cmd_dest_he()` / `kvaser_usb_hydra_set_cmd_transid()` must mask inputs with `KVASER_USB_HYDRA_HE_ADDR_DEST_MASK` and `KVASER_USB_HYDRA_TRANSID_MASK`. [F393, F417, F419]
- `kvaser_usb_hydra_stop_chip()` must set `priv->can.state = CAN_STATE_STOPPED` before sending `CMD_STOP_CHIP_REQ` (and `kvaser_usb_hydra_update_state()` must ignore `old_state == CAN_STATE_STOPPED && new_state == CAN_STATE_BUS_OFF`); `kvaser_usb_hydra_get_busparams()` must set `hydra->pending_get_busparams_type` before `CMD_GET_BUSPARAMS_REQ` so `kvaser_usb_hydra_get_busparams_reply()` populates `busparams_nominal`/`busparams_data` and resets `pending_get_busparams_type = -1` before completing `get_busparams_comp`. [F405, F409]
- In `kvaser_usb_leaf`, `struct kvaser_cmd` overlays incompatible `u.leaf` and `u.usbcan` unions: every command in `kvaser_usb_leaf_wait_cmd()` or `kvaser_usb_leaf_handle_command()` must have its minimum size in `kvaser_usb_leaf_cmd_sizes_leaf` / `kvaser_usb_leaf_cmd_sizes_usbcan` (or `CMD_SIZE_ANY`), pass `kvaser_usb_leaf_verify_size()`, and branch on `dev->driver_info->family` before reading `u.leaf` or `u.usbcan`. [F395, F415]
- In `kvaser_usb_leaf_rx_error()`, ignore events when `!netif_running(priv->netdev)`, schedule `leaf->chip_state_req_work` when `new_state < CAN_STATE_BUS_OFF` and `es->rxerr || es->txerr || new_state == CAN_STATE_ERROR_PASSIVE || leaf->joining_bus`, and cancel `chip_state_req_work` in `kvaser_usb_leaf_stop_chip()` and `kvaser_usb_leaf_remove_channel()`; bus-off auto-restart checks in `kvaser_usb_leaf` must test `state == CAN_STATE_BUS_OFF` (not `>= CAN_STATE_BUS_OFF`). [F403, F404, F430]
- In `kvaser_usb_hydra_rx_msg_ext()` and `pcan_usb_fd_decode_canmsg()`, Classical CAN frames allocated into `struct canfd_frame *` via `alloc_can_skb()` must set `cf->len` via `can_frame_set_cc_len()` (not `can_fd_dlc2len()`). [F463]
- In `pcan_usb_pro` and `pcan_usb_fd`, `usb_if->dev_opened_count` is incremented in `start()` after enabling timestamp/calibration messages when `dev_opened_count == 0`, and decremented in `stop()` after disabling them when `dev_opened_count == 1`. [F363]
- In `pcan_usb_fd_init()`, extended endpoints in `pcan_ufd_fw_info` are valid only when `le16_to_cpu(fw_info->type) >= PCAN_USBFD_TYPE_EXT`; `CAN_CTRLMODE_FD_NON_ISO` is in `ctrlmode_supported` only when `fw_info->fw_version[0] >= 2`, and `pcan_usb_fd_build_restart_cmd()` emits `PUCAN_OPTION_CANDFDISO` only when `ctrlmode_supported & CAN_CTRLMODE_FD_NON_ISO`, keeping total restart commands in `buf` `<= PCAN_USB_MAX_CMD_LEN` (32 bytes). [F398, F460, F474]
- In `pcan_usb.c`, `pcan_usb_init()` sets `CAN_CTRLMODE_ONE_SHOT | CAN_CTRLMODE_LOOPBACK` only when `device_rev >= 41`, `pcan_usb_start()` calls `pcan_usb_set_silent()` only when `device_rev > 3`, `pcan_usb_set_can_channel_id()` rejects `can_ch_id > U8_MAX` or `IFF_UP`, and `pcan_usb_decode_status()`/`pcan_usb_decode_data()` must pass `!mc->rec_ts_idx` to `pcan_usb_decode_ts()` and increment `mc->rec_ts_idx`. [F413, F481]
- In `ucan.c`, every TX URB `urb->context` must be an element of `up->context_array` (since `echo_skb` index is `context - up->context_array`) acquired via `ucan_alloc_context()` and released via `ucan_release_context()` under `up->context_lock`; `ucan_tx_complete_msg()` must verify `len >= UCAN_IN_HDR_SIZE` and even, iterate `(len - UCAN_IN_HDR_SIZE) / 2` times, and only call `can_get_echo_skb()`/`can_free_echo_skb()` when `ucan_release_context()` returns `true`; and `ucan_handle_error_frame()` must keep sequential `if` checks on `data[1]` ordered `ACTIVE` -> `WARNING` -> `PASSIVE`. [F365, F440, F455, F457]

## Synchronization

- In `vxcan`, `priv->peer` is published via `rcu_assign_pointer()` in `vxcan_newlink()` and cleared via `RCU_INIT_POINTER()` in `vxcan_dellink()`, so `vxcan_xmit()` and `vxcan_get_iflink()` must hold `rcu_read_lock()` across all uses of `rcu_dereference(priv->peer)` (including `netif_rx()` and `peer->stats`) and handle `NULL`. [F373]
- In `kvaser_usb`, synchronous `kvaser_usb_recv_cmd` (`kvaser_usb_hydra_wait_cmd`, `kvaser_usb_leaf_wait_cmd`) is restricted to probe before `kvaser_usb_setup_rx_urbs()`; once `dev->rxinitdone` is set, replies must use per-channel completions (`start_comp`, `stop_comp`, `flush_comp`, `get_busparams_comp`) initialized once with `init_completion()` in `kvaser_usb_init_one()` and reset with `reinit_completion()` before sending; and paths holding `priv->tx_contexts_lock` or `card_data->transid_lock` must never acquire `card_data->usb_rx_leftover_lock`. [F368, F370, F489]
- In `ucan`, `up->context_lock` protects `context_array[i].allocated`, `available_tx_urbs`, and coupled `netif_stop_queue()`/`netif_wake_queue()` calls, while `up->echo_skb_lock` protects all `can_put_echo_skb()`, `can_get_echo_skb()`, and `can_free_echo_skb()` calls; in `usb_8dev`, `priv->usb_8dev_cmd_lock` must be held across both `usb_8dev_send_cmd_msg()` and `usb_8dev_wait_cmd_msg()`. [F375, F376, F378]
- In `peak_usb`, `PCAN_USB_STATE_STARTED` is set in `peak_usb_start()` after `dev_start()` succeeds, cleared at the start of `peak_usb_ndo_stop()`, and checked in `peak_usb_read_bulk_callback()` before `dev_decode_buf()`; `peak_usb_restart()` and `dev_restart_async` must use `GFP_ATOMIC` and async `usb_submit_urb()`, with `pcan_usb_restart_async()` returning `-EBUSY` if `timer_pending(&pdev->restart_timer)`. [F380, F381]

## Object Lifetimes

- In `vxcan_newlink()`, call `free_netdev(peer)` if `register_netdevice(peer)` fails, or `unregister_netdevice(peer)` without `free_netdev(peer)` if a later step fails (`dev->needs_free_netdev = true`); in `vxcan_xmit()`, after `can_dropped_invalid_skb()` returns false, `oskb` must be freed via `consume_skb(oskb)` or `kfree_skb(oskb)` and exit via `rcu_read_unlock()`. [F353, F355]
- `kvaser_usb_unlink_tx_urbs()` must never be called from atomic URB completion context; `kvaser_usb_remove_interfaces()` must first `unregister_candev()` all channels, then call `kvaser_usb_unlink_all_urbs(dev)` (which, like `usb_8dev.c:unlink_all_urbs`, must `usb_kill_anchored_urbs(&...->rx_submitted)` before `usb_free_coherent()` on `rxbuf`), and only then run `ops->dev_remove_channel(priv)`, `kvaser_usb_devlink_port_unregister(priv)`, and `free_candev()`. [F358, F372, F493]
- In `peak_usb_write_bulk_callback()`, when `netif_device_present(netdev)` is true, always call `can_get_echo_skb()` and reset `context->echo_index = PCAN_USB_MAX_TX_URBS` even if `urb->status != 0` (waking the queue only when `!urb->status`); in `peak_usb_unlink_all_urbs()`, free unsubmitted `tx_contexts[i].urb` (`echo_index == PCAN_USB_MAX_TX_URBS`) before `usb_kill_anchored_urbs(&dev->tx_submitted)`; and in `peak_usb_disconnect()`, set `dev->next_siblings = NULL` before `dev_free()` so shared `usb_if` is freed only when `!prev_siblings && !next_siblings`. [F360, F362, F379]
- In `ucan_submit_rx_urbs()`, each submitted `urbs[i]` must be freed with `usb_free_urb()` and set to `NULL` so on error `ucan_cleanup_rx_urbs()` frees only unsubmitted URBs while `usb_kill_anchored_urbs(&up->rx_urbs)` makes `ucan_read_bulk_callback()` call `usb_free_coherent()` (which it must do whenever exiting without resubmitting); in `ucan_close()`, kill both `tx_urbs` and `rx_urbs` before `ucan_release_context_array(up)`. [F364, F377, F492]

## API Contracts

- Every `cmd` passed to `kvaser_usb_send_cmd()` or `kvaser_usb_send_cmd_async()` must be heap-allocated (`kmalloc`/`kzalloc`), and `kvaser_usb_send_cmd_async()` takes ownership of `cmd` only when returning `0` (callers must `kfree(cmd)` on error); in `kvaser_usb_init_one()`, set `netdev->dev_id = channel` and `netdev->dev_port = channel`, registering `devlink_port` before `register_candev()` and unregistering after `unregister_candev()`. [F356, F465, F504]
- `struct kvaser_cmd` passed to `kvaser_usb_hydra_wait_cmd()` (which is only for non-`CMD_EXTENDED` 32-byte commands) or `kvaser_usb_hydra_set_cmd_dest_he()` must be zero-initialized; `kvaser_usb_*_get_single_capability()` results in `cmd->cap_res` are valid only when `*status == KVASER_USB_*_CAP_STAT_OK`; `kvaser_usb_hydra_map_channel()` `name` must be `<= 15` chars; and `kvaser_usb_ticks_to_ktime()` must use `div_u64()` with non-zero `cfg->timestamp_freq`. [F392, F394, F446, F462, F467]
- In `peak_usb`, `dev_restart_async` takes ownership of `urb` and `buf` only on returning `0` and its callback must call `peak_usb_async_complete(urb)` and `peak_usb_restart_complete(dev)`; PEAK bittiming callbacks must subtract 1 from 1-based `can_bittiming` fields (`sjw - 1`, `phase_seg2 - 1`, `prop_seg + phase_seg1 - 1`, `brp - 1`); `pcan_usb_send_cmd()`/`pcan_usb_wait_rsp()` non-NULL `p` arguments must be `>= PCAN_USB_CMD_ARGS_LEN` (14) bytes; `pcan_msg_add_rec()` arguments must match `va_arg()` types; and `pcan_usb_fd_send_cmd(dev, cmd_tail)` expects a pointer one past the last command. [F399, F458, F461, F468, F495]
- `pcan_usb_pro_send_req()` must `memset(req_addr, '\0', req_size)` on `USB_DIR_IN` requests and clamp `usb_control_msg() >= 0` to `0`, and `ucan_ctrl_command_out()` callers like `ucan_set_bittiming()` must also clamp non-negative byte counts to `0`; `ucan_open()` must zero-initialize `ctrlmode` before setting `up->ctl_msg_buffer->cmd_start.mode`; and `ucan_prepare_and_anchor_rx_urbs()`/`ucan_cleanup_rx_urbs()` must clear `urbs` with `sizeof(*urbs) * UCAN_MAX_RX_URBS`. [F386, F389, F396, F456]
- `vcan_change_mtu()` and `vxcan_change_mtu()` must reject changes when `IFF_UP` (`-EBUSY`) or when `new_mtu` is not `CAN_MTU`, `CANFD_MTU`, or `can_is_canxl_dev_mtu(new_mtu)` (`-EINVAL`); `vxcan_newlink()` must use `rtnl_newlink_peer_net(params)` and `rtnl_nla_parse_ifinfomsg()` with `.peer_type = VXCAN_INFO_PEER`. [F429, F500]

## Error Handling

- In `kvaser_usb_init_one()`, errors after `dev->nets[channel] = priv` must unregister `devlink_port`, `free_candev(netdev)`, and set `dev->nets[channel] = NULL`; in `kvaser_usb_set_bittiming()`, convert `-EOPNOTSUPP` from `ops->dev_get_busparams(priv)` to `0` before comparing `busparams_nominal`, and check both `dev_set_data_bittiming` and `dev_get_data_busparams` in `kvaser_usb_set_data_bittiming()`. [F357, F390]
- In `peak_usb_create_dev()`, `dev_init` failures skip `dev_free`, so `pcan_usb_pro_init()`/`pcan_usb_fd_init()` must free their own allocations on error; in `pcan_usb_fd_decode_status()` and `pcan_usb_decode_error()`, `CAN_STATE_BUS_OFF` must run `can_change_state()` and `can_bus_off(netdev)` even if `alloc_can_err_skb()` fails. [F397, F506]
- In `ucan_open()`, `err_stop`/`err_reset` must store cleanup results in `ret_cleanup` (not `ret`), and `ucan_get_fw_str()` must pass `size - 1` to `usb_control_msg()` and NUL-terminate `fw_str[ret] = '\0'` (or `strscpy(fw_str, "unknown", size)` when `ret <= 0`); in `usb_8dev_start_xmit()`, `nofreecontext` must free `buf` and `urb` without freeing `skb` before returning `NETDEV_TX_BUSY` (whereas `NETDEV_TX_OK` error paths must also free `skb`), and `usb_8dev_send_cmd()` must verify `begin == USB_8DEV_CMD_START`, `end == USB_8DEV_CMD_END`, `num_bytes_read == 16`, and `opt1 == 0`. [F366, F387, F388, F400]

## External Contracts

- `pcan_usb_fd_send_cmd()` must append an 8-byte `0xff` end-of-collection record when `cmd_tail - cmd_head <= PCAN_UFD_CMD_BUFFER_SIZE - sizeof(u64)` and split transfers into `<= PCAN_UFD_LOSPD_PKT_SIZE` (64) byte chunks when `speed != USB_SPEED_HIGH`; `pcan_usb_fd_encode_msg()` must 4-byte align `tx_msg_size` and write a zero-size terminator at `(struct pucan_tx_msg *)(obuf + tx_msg_size)` (paired with `!rx_msg->size` termination in `pcan_usb_fd_decode_buf()`); `peak_usb_get_eeprom()`/`peak_usb_set_eeprom()` must use `__le32 ch_id_le` (with 1-byte `get_eeprom_len` on `pcan_usb`); and `ucan` must access `msg.can_msg.dlc` only when `CAN_RTR_FLAG` is set. [F421, F422, F424, F426, F459]

## Known Pitfalls

- In `kvaser_usb_leaf`, set `leaf->joining_bus = true` before `CMD_START_CHIP` in `start_chip`/`set_mode`; do not gate `es->txerr`/`es->rxerr` state thresholds on `M16C_STATE_BUS_ERROR` in `kvaser_usb_leaf_rx_error_update_can_state()`; check `KVASER_LEAF && cmd->id == CMD_LEAF_LOG_MESSAGE` before the general `MSG_FLAG_ERROR_FRAME` branch in `kvaser_usb_leaf_rx_can_msg()`; and combine USBCanII 16-bit timestamps with `usbcan_timestamp_msb` and `KVASER_USB_USBCAN_TIMESTAMP_FACTOR`. [F402, F431, F433, F449]
- Cast `le16_to_cpu(timestamp[1..2])` to `u64` before shifting in `kvaser_usb_timestamp48_to_ktime()`, and use `1ULL`/`BIT_ULL` when shifting by `ts_used_bits` and handle wrap-around in `peak_usb_update_ts_now()`/`peak_usb_get_ts_time()`; keep strings formatted into 16-byte `buf` `<= 15` chars in `kvaser_usb_devlink_info_get()`; reset `new_state = CAN_STATE_ERROR_ACTIVE` in `default:` of `pcan_usb_pro_handle_error()`; and gate peer `tbp[IFLA_IFNAME]` on `ifmp` in `vxcan_newlink()`. [F439, F443, F444, F445, F447, F466]
