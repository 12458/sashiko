# BPF [GENERAL] (Safe Dynamic Programs and Tools) — (top level) (part 2)

This component provides core BPF infrastructure, specialized maps, iterators, tracing backends (`kernel/trace/bpf_trace.c`), and low-level primitives: the NMI-safe per-CPU allocator (`memalloc.c`), resilient queued spinlocks (`rqspinlock.c`), per-CPU freelists, arena range trees, hardware offload (`offload.c`), netns links (`net_namespace.c`), BPF tokens (`token.c`), program streams (`stream.c`), and ELF build-ID parsing (`lib/buildid.c`).

## Architecture & Data Flow
- In `memalloc.c`, non-percpu allocations include an 8-byte `LLIST_NODE_SZ` header inside `unit_size` storing `struct bpf_mem_cache *`, while percpu allocations (`percpu_size != 0`) omit `LLIST_NODE_SZ` from `size`/`unit_size` and allocate a two-pointer header (`obj[0]` cache/`llist_node`, `obj[1]` `__alloc_percpu_gfp()` ptr freed by `free_one()`); callers receive `ptr + LLIST_NODE_SZ` and free paths use `ptr - LLIST_NODE_SZ`. `bpf_mem_cache_idx()` must reject `!size` and `size > BPF_MEM_ALLOC_SIZE_MAX`; `init_refill_work()` must divide by `c->unit_size` only after it is set; and adding to an empty `c->free_by_rcu` (`__llist_add()` true) must set `c->free_by_rcu_tail` (copied to `c->waiting_for_gp_tail` on grace-period handoff). [F63, F80, F129, F133, F134]
- In `offload.c`, `ondev->offdev` is `NULL` for `BPF_F_XDP_DEV_BOUND_ONLY` programs, so `offload->offdev->ops` may only be accessed when `bpf_prog_is_offloaded(prog->aux)`. In `__bpf_offload_dev_netdev_unregister()`, migrating `ondev->progs` and `ondev->maps` to `altdev` must update every `offload->netdev` and `offmap->netdev` to `altdev->netdev` and use `list_splice_init()`, or use `list_for_each_entry_safe()` to destroy them when `!altdev`. [F48, F67, F111]
- In `queue_stack_maps.c`, `qs->size` must be `attr->max_entries + 1` (in 64-bit math) with `head`, `tail`, and stack top `qs->head - 1` wrapping modulo `qs->size`; when `queue_stack_map_push_elem()` overwrites a full map (`BPF_EXIST`), it must advance `qs->tail` before `qs->head`. [F81, F86]
- In `bpf_trace.c`, `bpf_kprobe_multi_link_attach()` and `bpf_uprobe_multi_link_attach()` must reject `sizeof(u64) != sizeof(void *)`, and `bpf_kprobe_multi_link_attach()` must co-sort `cookies[]` with `us.syms[]` (`symbols_swap_r`) and `link->addrs[]` (`bpf_kprobe_multi_cookie_swap`). Helpers/kfuncs downcasting `current->bpf_ctx` to `bpf_kprobe_multi_run_ctx`, `bpf_uprobe_multi_run_ctx`, or `bpf_session_run_ctx` must only be exposed to matching `expected_attach_type` programs; `kprobe_prog_is_valid_access()` must check `off + size <= sizeof(struct pt_regs)`, and `pe_prog_is_valid_access()` must allow 8-byte accesses with `off % 8 == 4` on 32-bit architectures. [F72, F92, F128, F142]
- In `rqspinlock.c`, `rqspinlock_held::cnt` can exceed `RES_NR_HELD` and `locks[cnt - 1]` is the lock being acquired, so `check_deadlock_AA()` and `check_deadlock_ABBA()` must clamp `cnt` to `RES_NR_HELD` and scan only up to `cnt - 1` (skipping CPUs with `real_cnt < 2 || real_cnt > RES_NR_HELD` in ABBA). `RES_INIT_TIMEOUT()` must set `u16 ts.spin = 0` so `!(ts).spin++` in `RES_CHECK_TIMEOUT()` arms `ts.timeout_end` immediately. [F88, F132]
- In `range_tree.c`, `range_node::rn_last` is inclusive (`last = start + len - 1`), splitting neighbours at `start - 1` and `last + 1`. In `pcpu_freelist_populate()`, `m = nr_elems % num_possible_cpus()` extra elements must be given to the first `m` CPUs. In `task_iter.c`, `bpf_iter_seq_task_{info,file_info,vma_info}` must keep `common` at offset 0 for `init_seq_pidns()`/`fini_seq_pidns()`. In `bpf_stream_get()`, 1-based `stream_id` (`BPF_STDOUT == 1`, `BPF_STDERR == 2`) must be validated before indexing `aux->stream[stream_id - 1]`. [F87, F89, F94, F131]

## Synchronization
- In `memalloc.c`, `bpf_mem_{alloc,free,free_rcu}` and `bpf_mem_cache_{alloc,free,free_rcu,alloc_flags}` require `migrate_disable()`. In `unit_alloc()`, `unit_free()`, and `unit_free_rcu()`, non-atomic `__llist_del_first()`/`__llist_add()` on `free_llist`/`free_by_rcu` require IRQs disabled and `local_inc_return(&c->active) == 1` (otherwise using atomic `llist_add()` on `free_llist_extra*`), and `local_irq_restore(flags)` must follow `irq_work_raise(c)`. On `CONFIG_PREEMPT_RT`, `inc_active()`/`dec_active()` must also disable/restore IRQs. [F153, F154, F155, F156]
- In `resilient_queued_spin_lock_slowpath()`, on contention (`val & ~_Q_LOCKED_MASK`) after `queued_fetch_set_pending_acquire()`, call `clear_pending(lock)` only if `!(val & _Q_PENDING_MASK)`; place `barrier()` between `rqnodes[0].mcs.count++` and zeroing `node->locked`/`node->next`, and `smp_wmb()` before `xchg_tail()`. On timeout, pending waiters must call `clear_pending(lock)` and MCS waiters at `waitq_timeout` must either reset tail via `try_cmpxchg_tail(lock, tail, 0)` or wait for `node->next` and set `WRITE_ONCE(next->locked, RES_TIMEOUT_VAL)` before decrementing `count`. [F35, F36, F101]
- `__pcpu_freelist_push()`/`__pcpu_freelist_pop()` require local IRQs disabled, and `___pcpu_freelist_pop()` must recheck `head->first != NULL` after `raw_res_spin_lock(&head->lock)`. [F29]
- In `net_namespace.c`, `bpf_netns_link::net` is unreferenced and protected by `netns_bpf_mutex`: link callbacks must verify `net_link->net != NULL` (and `check_net(net)`) under `netns_bpf_mutex`, where `net->bpf.progs[type]` and `net->bpf.links[type]` are mutually exclusive; in `bpf_netns_link_release()`, `link_index()` must precede `list_del(&net_link->node)`, while `link_count()` and `fill_prog_array()` must follow it. [F30, F113, F190]
- In `reuseport_array.c`, always acquire `spin_lock_bh(&reuseport_lock)` before `write_lock_bh(&sk->sk_callback_lock)`. `bpf_fd_reuseport_array_update_elem()` must re-run `reuseport_array_update_check()` under both locks and unlock `nsk->sk_callback_lock` before locking `free_osk->sk_callback_lock`; `bpf_sk_reuseport_detach()` must clear both `sk->sk_user_data` and `*socks` inside `write_lock_bh(&sk->sk_callback_lock)`. [F32, F164, F165]
- When `task_vma_seq_get_next()` or `task_vma_seq_stop()` drops `mmap_lock`, it must save `prev_vm_start`/`prev_vm_end` (`prev_vm_start = ~0UL` in `stop` when `v != NULL`) and re-lookup via `find_vma(curr_mm, info->prev_vm_end - 1)` after relocking instead of dereferencing `info->vma`. [F28]
- In `bpf_trace.c`, `event->prog` and `event->tp_event->prog_array` accesses require `bpf_event_mutex`; in `perf_event_detach_bpf_prog()`, handle `!old_array` by skipping copy, fall back to `bpf_prog_array_delete_safe()` on copy failure, and always clear `event->prog = NULL` and call `synchronize_rcu_tasks_trace()` after unlocking before `bpf_prog_put(prog)`. [F7, F40, F50]
- In `bpf_trace.c`, `bpf_send_signal_common()` and `bpf_probe_write_user()` must reject `PF_KTHREAD | PF_EXITING` and `!nmi_uaccess_okay()` (plus `!is_global_init(task)` for signals and `in_interrupt()` / `copy_to_user_nofault()` for writes); when `preempt_count() != 0 || irqs_disabled()`, signals must defer to `send_signal_work` (`-EBUSY` if `irq_work_is_busy()`) with `get_task_struct(task)` released by `do_bpf_send_signal()`. [F39, F170, F171]
- In `bpf_trace.c`, raw_tp helpers must use `get_bpf_raw_tp_regs()`/`put_bpf_raw_tp_regs()` (decrementing `bpf_raw_tp_nest_level` and returning `ERR_PTR(-EBUSY)` without `WARN_ON_ONCE` on overflow); non-sleepable `bpf_probe_read_user*_dynptr` kfuncs must use `copy_user_*_nofault` callbacks; `uprobe_prog_run()` must bracket `bpf_prog_run()` with `migrate_disable()` and `rcu_read_lock_trace()` (if `prog->sleepable`) or `rcu_read_lock()`; and `bpf_uprobe_multi_link_attach()` must call `get_pid_task(find_vpid(pid), PIDTYPE_TGID)` under `rcu_read_lock()`. [F74, F173, F174, F176, F188]

## Object Lifetimes
- `task_vma_seq_get_next()` must hold `info->task`, `info->mm`, and `mmap_read_lock(info->mm)` when returning a VMA, and release all three and clear `info->{task,mm,vma}` to `NULL` when returning `NULL`. In `load_skel()` (`bpf_preload_kern.c`), `skel->links.dump_bpf_{map,prog}_fd` must be closed via `close_fd()` and zeroed after `bpf_link_get_from_fd()`. [F17, F21]
- `bpf_{kprobe,uprobe}_multi_link_lops` must use `.dealloc_deferred`. In `bpf_uprobe_multi_link_attach()`, initialize `link->{task,link}` and `uprobes[i].{link,consumer}` before `uprobe_register()`, set `link->cnt = i` on registration error at `i`, and in `bpf_uprobe_unregister()` call `uprobe_unregister_nosync()` on all entries then `uprobe_unregister_sync()` before freeing resources. In `bpf_kprobe_multi_link_attach()`, after `bpf_link_prime()` and setting `link->{addrs,cookies}`, errors must use `bpf_link_cleanup(&link_primer)`; sort `addrs`/`cookies` and call `get_modules_for_addrs()` before `register_fprobe_ips()`, and call `unregister_fprobe()` before `kprobe_multi_put_modules()` on release. [F41, F42, F58, F59, F175]
- In `offload.c`, post-init accesses to `prog->aux->offload` and `struct bpf_offloaded_map` must hold `bpf_devs_lock` and verify `prog->aux->offload != NULL` or `offmap->netdev != NULL`. `__bpf_prog_offload_destroy()` must call `ops->destroy(prog)` only if `offload->dev_state` is set, and bound-only `ondev` (`!ondev->offdev`) must be unregistered when its last prog is destroyed or its netdev unregisters. [F148, F149, F150, F151]

## API Contracts
- `netns_bpf_prog_attach()` takes `prog` ownership only on return `0` (putting old `attached`) and must not put `prog` on error. `bpf_mem_cache_raw_free(ptr)` requires a prior `rcu_tasks_trace` grace period, and `alloc_bulk()`/`bpf_mem_cache_alloc_flags()` must bracket `__GFP_ACCOUNT` `__alloc()` calls with `get_memcg(c)`/`set_active_memcg()` and `mem_cgroup_put()`. [F4, F11, F181]
- `task_iter.c` must pass `PIDTYPE_PID` to `get_pid_task()` for `BPF_TASK_ITER_TID` and `common->pid_visiting`, and `PIDTYPE_TGID` only on initial `!*tid` lookup in `task_group_seq_get_next()`. `parse_build_id()` must overflow-check 4-byte-aligned `name_sz`/`desc_sz` offsets against `note_end`, require `0 < desc_sz <= BUILD_ID_SIZE_MAX`, zero-pad `build_id` up to `BUILD_ID_SIZE_MAX`, and guard `*size = desc_sz` if `size != NULL`. [F51, F54, F84]
- Callers of `range_tree_find()` must test its `s64` return for `< 0` before truncating to `u32`. `bpf_res_spin_{lock_irqsave,unlock_irqrestore}` must access `flags__irq_flag` as `u64 *` while passing `unsigned long` to `local_irq_{save,restore}`. `__bpf_dynptr_copy_str()` callbacks must NUL-terminate `dst` and return byte count including NUL. [F57, F123, F141]
- `uprobe_multi_link_handler()` must return `0` for non-session uprobes and only `UPROBE_HANDLER_IGNORE` or `0` for session uprobes. `__bpf_perf_event_output()` must verify `PERF_TYPE_SOFTWARE`, `PERF_COUNT_SW_BPF_OUTPUT`, and `event->oncpu == smp_processor_id()`, and call `perf_sample_save_raw_data()`. `reuseport_array_update_check()` requires TCP/UDP `AF_INET`/`AF_INET6`, `SOCK_RCU_FREE`, `sk_hashed(nsk)`, `nsk_reuse`, and `!nsk->sk_user_data`, and `bpf_fd_reuseport_array_update_elem()` must check `fd64 <= S32_MAX`. [F126, F183, F187, F192]

## Error Handling
- Open-coded iterator `_new` kfuncs (`bpf_iter_{task_vma,css_task,task}_new`) must zero their internal pointer (`kit->{data,css_it,pos} = NULL`) on all error paths. `net_device` pointers looked up by ifindex must pass `bpf_dev_offload_check(netdev)` before `netdev_lock_ops()`/`ndo_bpf`, and `bpf_prog_offload_{replace_insn,remove_insns}` must update sticky `offload->opt_failed |= ret` and skip callbacks once set. [F46, F47, F49]
- Read helpers taking `ARG_PTR_TO_UNINIT_MEM` (`bpf_probe_read_{user,user_str,kernel_str}_common`, `bpf_perf_{event,prog}_read_value`) and empty `__queue_map_get()`/`__stack_map_get()` must `memset(dst, 0, size)` on error. In `bpf_stream_read()`, `copy_to_user()` failure must restore `elem->consumed_len = cons_len` and return `-EFAULT`. [F55, F56, F61]

## External Contracts
- `bpf_{kprobe,uprobe}_multi_link_attach()` and `netns_bpf_link_create()` must reject non-zero `attr->link_create.flags`. `bpf_uprobe_multi_link_attach()` must reject `pid < 0`, resolve `pid` with `PIDTYPE_TGID`, and filter via `uprobe->link->task->mm == mm` and `same_thread_group(current, link->task)`. In `bpf_{kprobe,uprobe}_multi_link_fill_link_info()`, return `-EINVAL` on mismatched buffer/count, copy `ucount` items and set `info->...count = link->cnt` before returning `-ENOSPC` when `ucount < link->cnt`, zero `uaddrs` when `!kallsyms_show_value(current_cred())`, and still set `path_size` via `d_path()` when `!upath && !upath_size`. [F95, F96, F182, F184, F185]
- `btf_sysfs_vmlinux_mmap()` must reject `vm_pgoff`, `pfn + pages < pfn`, or `(vm_size >> PAGE_SHIFT) > pages` (`-EINVAL`), reject `VM_WRITE | VM_EXEC | VM_MAYSHARE` (`-EACCES`), clear `VM_MAYEXEC | VM_MAYWRITE` (`vm_flags_mod`), and use `__pa_symbol(__start_BTF)`. `bpf_token_create()` requires a bpffs root dentry (`sb->s_op == &bpf_super_ops`) in a non-init userns matching `current_user_ns()`; `bpf_token_allow_*` must check `< __MAX_BPF_*` before `BIT_ULL()`, and `bpf_token_show_fdinfo()` must test `(field & mask) == mask`. `bpf_prog_dev_bound_init()` allows only `SCHED_CLS`/`XDP`, rejects `BPF_F_XDP_DEV_BOUND_ONLY` on `SCHED_CLS`, and for offloaded progs requires `ondev->offdev` and rejects `BPF_F_XDP_HAS_FRAGS` and XDP metadata kfuncs. [F62, F97, F114, F152, F163, F179, F180, F193]

## Known Pitfalls
- In `lib/buildid.c`, copy ELF/note fields with `READ_ONCE()` before any subsequent `freader_fetch()` call, which invalidates prior pointers. In `task_iter.c`, `goto retry` in `task_seq_get_next()` must increment `++*tid` and set `task = NULL` after `put_task_struct()`, while `task_{file,vma}_seq_get_next()` must stop on `BPF_TASK_ITER_TID` or increment `info->tid` and clear `info->task = NULL` before `goto again`. [F83, F103, F105]
- In `memalloc.c`, allocator hotpath functions must be `notrace` and detached `llist_node` traversals must use `llist_for_each_safe()`. In `bpf_stream_backlog_fill()`, `tail = llist_del_all(&stream->log)` becomes the tail after `head = llist_reverse_order(tail)`. `bpf_d_path()` must use `memmove(buf, p, len)`. In `get_modules_for_addrs()`, `break` inside `scoped_guard(rcu)` only exits the guard block, so set `skip_add`/`err` and check them outside. [F108, F109, F116, F140, F158]
