# NETWORKING DRIVERS — drivers/net (part 3)

This unit covers virtual networking drivers (`tun`, `veth`, `pfcp`, `nlmon`), RapidIO Ethernet (`rionet`), Sun GEM and generic MII PHY libraries (`sungem_phy`, `mii`), parallel port IP (`plip`), SLIP and VJ compression (`slip`, `slhc`), and PPP BSD compression and PPTP (`bsd_comp`, `pptp`).

## Architecture & Data Flow
- `struct sock sk` must be first in `struct tun_file` (`tun_chr_open` casts `sk_alloc()`). `tun->tfiles[0..numqueues-1]` is dense (`numqueues + numdisabled <= MAX_TAP_QUEUES`); `__tun_detach()` swaps `tfiles[numqueues - 1]` into `index` and updates `queue_index` and `xdp_rxq.queue_index`. Iterating `tun->disabled` for `tun_enable_queue()` requires `list_for_each_entry_safe()`. `tun_ebpf_select_queue()` and `tun_xdp_xmit()` must check `READ_ONCE(tun->numqueues) != 0` before `% numqueues`. [F764, F781, F792, F810]
- `tun_get_user()` and `tun_xdp_one()` TAP injection must reject payloads `< ETH_HLEN` (and non-zero `virtio_net_hdr` `hdr_len < ETH_HLEN`) before `eth_type_trans()`. `tun_napi_alloc_frags()` must reject `it->nr_segs > MAX_SKB_FRAGS + 1`, `len > ETH_MAX_MTU - NET_SKB_PAD - NET_IP_ALIGN`, or segment `i >= 1` with `iov_len == 0` or `> PAGE_SIZE`. [F758, F763]
- `set_offload()` must check each `TUN_F_*` flag only inside its prerequisite block (`TUN_F_CSUM` for all; `features & PLAIN_GSO` for `TUN_F_UDP_TUNNEL_GSO*`) and clear it from `arg` so `if (arg) return -EINVAL;` catches invalid flags. `tun_flow_cleanup()` must compare `this_timer = e->updated + delay` against `jiffies` and `next_timer` via `time_before_eq()` and `time_before()`. [F787, F800]
- `veth` (`rq->xdp_ring`) and `tun` (`tfile->tx_ring`) tag `xdp_frame *` entries with bit 0 (`veth_xdp_to_ptr()` / `tun_xdp_to_ptr()`); consumers must test `veth_is_xdp_frame()` / `tun_is_xdp_frame()` and clear bit 0. `veth_xdp_xmit()` and `veth_xmit()` must check `rcu_access_pointer(rq->napi)` before producing to `rq->xdp_ring`. `veth_xdp_rcv_one()` sets `vxbuf.skb = NULL`, so `veth_xdp_metadata_ops` callbacks must return `-ENODATA` if `!_ctx->skb`. [F727, F729, F773]
- `veth_set_rx_headroom()` sets both `dev` and `peer` `needed_headroom` to `max(priv->requested_headroom, peer_priv->requested_headroom)`. `veth_set_channels()` must reject zero `rx_count` or `tx_count` with `-EINVAL`. `veth_get_strings`, `veth_get_sset_count`, and `veth_get_ethtool_stats` must iterate `real_num_{rx,tx}_queues`. [F749, F793, F813]
- `sl_realloc_bufs()` under `sl->lock` must copy remaining TX bytes (`sl->xleft <= len`) from `sl->xhead` to the new `sl->xbuff` and reset `sl->xhead = sl->xbuff` before `kfree(xbuff)`. [F750]
- `slhc_compress()` and `slhc_remember()` must validate `isize >= sizeof(struct iphdr)`, `ip->ihl >= 5`, `isize >= ip->ihl * 4 + sizeof(struct tcphdr)`, `th->doff >= 5`, and `isize >= ip->ihl * 4 + th->doff * 4` before reading TCP fields or options. `slhc_remember()` must sample the slot index from `iph->protocol` and restore `IPPROTO_TCP` before `ip_fast_csum(icp, ihl)` and copying to `cs->cs_ip`. `slhc_uncompress()` requires `0 <= x <= comp->rslot_limit` and `rstate[x].initialized` on `NEW_C`, and rejects implicit-index packets when `SLF_TOSS` is set. [F751, F765, F766]
- `bsd_alloc()` restricts `BSD_NBITS(options[2])` to `9..15` (`bsd_dict::cptr` is 16-bit) and allocates `db->lens` with `maxmaxcode + 1` elements when `decomp != 0`. `bsd_compress()` and `bsd_decompress()` must update `in_count` and `bytes_out` (plus dribble byte when `bitno < 32`) identically before `bsd_check(db)`, which ages counts by `count >> 2` at `RATIO_MAX` and checks `bytes_out != 0` before dividing. `bsd_decompress()` must reject non-`CLEAR` `incode > max_ent + 2`, `> db->maxmaxcode`, or `> max_ent && oldcode == CLEAR`, and check `explen += codelen + extra <= osize` before writing `obuf`. [F753, F770, F771, F794, F804]
- `pptp_create()` sets `seq_recv = ack_sent = 0xffffffff`. In `pptp_rcv_core()`, `headersize` subtracts `sizeof(header->ack)` when `!GRE_IS_ACK()`, `pskb_may_pull(skb, headersize + payload_len)` must precede reading `payload`, and seq/ack checks must pair `<`/`>` with `WRAPPED(curseq, lastseq)`. [F769, F798, F799]
- In `plip.c`, `enum plip_connection_state` directly indexes `connection_state_table[]`. In `plip_send_packet()` and `plip_receive_packet()`, states `PLIP_PK_TRIGGER` through `PLIP_PK_CHECKSUM` must advance `state` and `fallthrough`, and `plip_receive_packet()` must check `8 <= rcv->length.h <= dev->mtu + dev->hard_header_len` before allocating `rcv->skb`. [F757, F776, F779]
- `generic_mii_ioctl()` `SIOCSMIIREG` only updates cached `mii_if` state when `mii_data->phy_id == mii_if->phy_id`. `rionet_add_dev()` must check `is_rionet_capable()` before `rionet_setup_netdev()`, and `rionet_{add,remove}_dev()` must check `dev_rionet_capable(rdev)`. [F756, F826]

## Synchronization
- `tfile->tun` and `tun->tfiles[]` require `rcu_read_lock()` or `rtnl_lock()`; blocking callers must use `tun_get()` / `tun_put()`. `tun_attach()` must publish `tfile->tun` and `tun->tfiles[numqueues]` via `rcu_assign_pointer()` only after initializing `tx_ring`, `queue_index`, `xdp_rxq`, and `napi`, and in `tun_set_iff()` only after `register_netdevice()` succeeds. [F704, F832]
- When `tfile->napi_enabled` (`!frags`), `tun_get_user()` and `tun_xdp_one()` must check `tfile->detached` under `tfile->sk.sk_write_queue.lock` before queueing and scheduling NAPI. When `tun_napi_frags_enabled(tfile)`, `tun_get_user()` must hold `tfile->napi_mutex` across `tun_napi_alloc_frags()`, copy, `do_xdp_generic()`, and `napi_gro_frags()`, clearing `tfile->napi.skb` or calling `napi_free_frags()` on error before unlocking. [F707, F708]
- Process-context XDP in `tun_build_skb()`, `tun_get_user()`, and `tun_sendmsg()` requires `local_bh_disable()` and `rcu_read_lock()`, and native XDP must wrap `bpf_prog_run_xdp()` and `xdp_do_flush()` with `bpf_net_ctx_set()` / `clear()`. Process-context `dev_sw_netstats_{rx,tx}_add()` in `tun.c` requires `preempt_disable()`/`enable()`. [F835, F837]
- Non-timer `tun->lock` callers must use `spin_lock_bh(&tun->lock)` (`tun_flow_cleanup()` runs in timer context), and `tun_flow_uninit()` must call `timer_delete_sync(&tun->flow_gc_timer)` before `tun_flow_flush()`. `update_filter()` must set `filter->count = 0` and `wmb()` before mutating `addr`/`mask`, then `wmb()` before storing `filter->count`. `tun_chr_poll()` must recheck `tun_sock_writeable()` after `test_and_set_bit(SOCKWQ_ASYNC_NOSPACE, ...)`. [F710, F711, F838]
- `__veth_xdp_flush()` needs `smp_mb()` after producing to `rq->xdp_ring` and before reading `rq->rx_notify_masked`, pairing with `smp_store_mb(rq->rx_notify_masked, false)` in `veth_poll()`. `rq->stats.vs` accesses must use `u64_stats_update_begin(&rq->stats.syncp)`/`end()` and `u64_stats_fetch_begin()`/`retry()`. [F712, F844]
- In `pptp.c`, `add_chan()`/`del_chan()` hold `chan_lock`, `lookup_chan()` checks `s_addr` and calls `sock_hold()` under `rcu_read_lock()`, and `pptp_release()` calls `del_chan()` and `synchronize_rcu()` before `pppox_unbind_sock()`. [F715]
- In `slip.c`, process/workqueue callers (`slip_transmit()`, `sl_realloc_bufs()`, `slip_close()`, `slip_ioctl()`) must use `spin_lock_bh(&sl->lock)` (`sl_xmit()`/`sl_tx_timeout()` run in softirq/timer). `sl_encaps()` must `set_bit(TTY_DO_WRITE_WAKEUP, &sl->tty->flags)` before `tty->ops->write()`. [F716, F845]
- `plip_send_packet()` must recheck `nl->connection == PLIP_CN_RECEIVE` after `DISABLE(dev->irq)` and `synchronize_irq(dev->irq)` (calling `ENABLE(dev->irq)` on collision), and `plip_bh_timeout_error()` only calls `DISABLE(dev->irq)` when `error == HS_TIMEOUT`. When `dev->irq == -1`, `plip_close()` must set `nl->kill_timer = 1` and wait on `nl->killed_timer_cmp` before releasing `nl->pardev` and freeing SKBs. [F718, F820]
- In `rionet.c`, non-IRQ callers (`rionet_start_xmit()`, `rionet_open()`) must use `spin_lock_irqsave()` on `rnet->tx_lock` and `nets[netid].lock`, and `rionet_outb_msg_event()` must free TX SKBs with `dev_kfree_skb_irq()`. [F849]

## Object Lifetimes
- In `tun_recvmsg()` and `tun_do_read()`, a non-NULL `msg_control`/`ptr` owns a `tx_ring` entry and must free it (`tun_ptr_free()`, `xdp_return_frame()`, `kfree_skb()`, or `consume_skb()`) on all paths. In `tun_build_skb()`, `XDP_REDIRECT`/`XDP_TX` calls `get_page(alloc_frag->page)` before `tun_xdp_act()`, so negative `tun_xdp_act()` errors must call `put_page(alloc_frag->page)`. [F684, F692]
- `tun_file` takes one `sk` ref in `tun_chr_open()` (dropped in `tun_chr_close()`) and a second via `sock_hold(&tfile->sk)` on initial attach in `tun_attach()`, kept while disabled and dropped only on clean detach in `__tun_detach()` or `tun_detach_all()`. `TUNSETPERSIST` calls `__module_get(THIS_MODULE)` only on 0-to-1 transition, and `module_put(THIS_MODULE)` when cleared or in `tun_detach_all()`. [F688, F689]
- `veth_napi_del_range()` must clear `rq->napi = NULL` and call `napi_disable(&rq->xdp_napi)` / `__netif_napi_del(&rq->xdp_napi)` before `synchronize_net()`, and only then run `ptr_ring_cleanup(&rq->xdp_ring, veth_ptr_free)` and `page_pool_destroy(rq->page_pool)`. [F840]
- `sl_alloc_bufs()`, `sl_realloc_bufs()`, and `sl_free_bufs()` must swap `rbuff`, `xbuff`, `cbuff`, and `slcomp` via `xchg()` and free them (`kfree()` / `slhc_free()`) outside `spin_lock_bh(&sl->lock)`. [F703]
- `plip_wakeup()` must not claim `nl->pardev` if `!(dev->flags & IFF_UP)`. When `nl->connection != PLIP_CN_NONE`, `plip_preempt()` sets `nl->should_relinquish = 1` and returns `1`, deferring `parport_release()` to `plip_connection_close()`. `bcm5421_init()` must `of_node_put(np)` after `of_get_parent()`. `rionet_remove_dev()` must only send `RIONET_DOORBELL_LEAVE` if `rdev->state` is not `GONE`/`INITIALIZING`, and call `rio_release_outb_dbell(rdev, peer->res)` after unlocking before `kfree(peer)`. [F818, F819, F825, F827]

## API Contracts
- `tun_build_skb()` returns `ERR_PTR(err)` on error, `NULL` on XDP drop/consume, and `sk_buff *` on pass, so `tun_get_user()` must check `PTR_ERR_OR_ZERO(skb)` before `!skb`. `tun_get_socket()` and `tun_get_tx_ring()` must check `file->f_op == &tun_fops`. `veth_newlink()` must use `rtnl_newlink_peer_net(params)`. `veth_xdp_rcv()` must check `skb_shared(skb) || skb_unclone(skb, GFP_ATOMIC)` and fall back to `netif_receive_skb(skb)` instead of `napi_gro_receive()`. [F719, F732, F862, F868]
- Under `CONFIG_INET`, `slhc_init(rslots, tslots)` requires `0..255` slots and returns `ERR_PTR` on failure (`!CONFIG_INET` returns `NULL`), so `CONFIG_INET` callers must check `IS_ERR()`. `bsd_compress()` accepts `obuf == NULL` (`osize == 0`) and returns `0` when `wptr == NULL`; `bsd_decompress()` returns `DECOMP_ERROR` (`-1`) on seq mismatch and `DECOMP_FATALERROR` (`-2`) on mid-packet `CLEAR` (`ilen > 0`), invalid code, or MRU overflow. `pptp_xmit()` must call `pskb_may_pull(skb, 3)` after `skb_realloc_headroom()` before reading `skb->data[0..2]`. [F733, F738, F851]
- Callers of `mii_ethtool_gset()` and `mii_ethtool_get_link_ksettings()` must zero-init the output struct, and `generic_mii_ioctl()` must init `*duplex_chg_out = 0` when non-NULL. `MII_CTRL1000`/`MII_STAT1000` require `mii->supports_gmii`, and `mii_check_gmii_support()` checks `BMSR_ESTATEN` before reading `MII_ESTATUS`. [F736, F821]

## Error Handling
- If `sk_attach_filter()` fails at queue `i` in `tun_attach_filter()`, `tun_detach_filter(tun, i)` must unwind `0..i-1`. `tun_get_user()` must `memset(&hdr, 0, sizeof(hdr))`, and `__tun_vnet_hdr_put()` must zero trailing bytes beyond `tun_vnet_parse_size(features)` via `iov_iter_zero()`. `veth_xdp_set()` error paths must jump to `err` to restore `priv->_xdp_prog = old_prog` without `bpf_prog_put(old_prog)`. [F690, F696, F724]
- In `pptp_xmit()`, errors before `pptp_route_output()` or when `IS_ERR(rt)` jump to `tx_drop` (`kfree_skb`), while errors after valid `rt` and before `skb_dst_set()` jump to `tx_error` (`ip_rt_put` then `kfree_skb`). In `pfcp_newlink()`, if `register_netdevice(dev)` fails after `pfcp_add_sock(pfcp)`, it must call `pfcp_del_sock(pfcp)` and clear `pfcp->net = NULL`. [F698, F700]

## External Contracts
- `__tun_chr_ioctl()` must copy `struct ifreq` using `ifreq_len`, zero-init `ifr` when not copied from userspace, and set `ifr.ifr_name[IFNAMSIZ - 1] = '\0'` on `TUNSETIFF`. `TUNSETLINK` must return `-EBUSY` if `IFF_UP`, and wrap `type` / `addr_len = tun_get_addr_len(type)` updates with `NETDEV_PRE_TYPE_CHANGE` / `NETDEV_POST_TYPE_CHANGE`. 16-bit `virtio_net_hdr` fields must use `tun_vnet16_to_cpu()` / `cpu_to_tun_vnet16()`. `tun_not_capable()` denies attachment only when (`uid_valid(owner) && !uid_eq(euid, owner)`) or (`gid_valid(group) && !in_egroup_p(group)`), and `!ns_capable(user_ns, CAP_NET_ADMIN)`. [F723, F761, F814, F852, F863]
- `generic_mii_ioctl()` must mask `phy_id` and `reg_num` with `phy_id_mask` and `reg_num_mask`. `sl_siocdevprivate()` and `plip_siocdevprivate()` must return `-EOPNOTSUPP` when `in_compat_syscall()`. [F775, F777]

## Known Pitfalls
- In `tun_xdp_one()`, `metasize = xdp->data - xdp->data_meta` must be signed `int` and checked with `metasize > 0`. When `hdr->gso_type != 0` in `tun_get_user()` or `tun_xdp_one()`, skip `bpf_prog_run_xdp()` and run `do_xdp_generic()` after `tun_vnet_hdr_tnl_to_skb()`. In `tun_napi_alloc_frags()`, loop `i = 1..nr_segs - 1` must index `iter_iov(it) + i` and pass fragment `i - 1` to `skb_fill_page_desc()`. [F725, F778, F858]
- `veth_enable_xdp_range()` saves `rq->xdp_rxq.mem` in `rq->xdp_mem`, and `veth_xdp_rcv_skb()` (on `XDP_TX`/`REDIRECT`) and `veth_disable_xdp_range()` (before `xdp_rxq_info_unreg()`) must restore `rq->xdp_rxq.mem = rq->xdp_mem`. In `__veth_napi_enable_range()`, `err_xdp_ring:` must reset `i = end` before `err_page_pool:`. In `veth_newlink()`, peer attributes in `data[VETH_INFO_PEER]` must use `tbp` (`peer_tb`), not `tb`. [F784, F786, F866]
- `slhc_uncompress()` expands headers in place via `memmove()` after checking `len = isize - (cp - icp) >= 0`, requiring `count + 80 <= sl->buffsize` in `sl_bump()`. `sl_bump()` must test `c & SL_TYPE_COMPRESSED_TCP` (`0x80`) before `c >= SL_TYPE_UNCOMPRESSED_TCP` (`0x70`). `slhc_compress()` must compute `deltaA`/`deltaS` as 32-bit unsigned differences before checking `> 0x0000ffff`. `mii_link_ok()` and `genmii_poll_link()` must dummy-read `MII_BMSR` before reading `BMSR_LSTATUS`. [F767, F790, F797, F822]

## Other
- `bcm5221_init()` and `bcm5241_init()` must set `MII_BCM5221_TEST_ENABLE_SHADOWS` in `MII_BCM5221_TEST` before accessing shadow registers `MII_BCM5221_SHDOW_AUX_STAT2` / `MODE4`, and clear it before returning. [F824]
