# AMD DISPLAY CORE — drivers/gpu/drm/amd/display/amdgpu_dm (part 2)

AMDGPU Display Manager modules for color management, CRTC vblank/VRR/PSR/CRC, DP MST/DSC fairness, HDCP workqueues, two-tier IRQ dispatch, DC OS helpers, and debugfs.

## Architecture & Data Flow

- In `struct amdgpu_dm_connector`, `struct drm_connector base` must stay at offset 0 because `connector_debugfs_init` passes `struct amdgpu_dm_connector *` as private data while debugfs callbacks cast `m->private`/`i_private` to either `struct amdgpu_dm_connector *` or `struct drm_connector *`. [F296]
- `amdgpu_dm_update_plane_color_mgmt()` must reset `dc_plane_state->in_transfer_func` to `TF_TYPE_BYPASS` before checking degamma, and reject (`-EINVAL`) setting both plane degamma (`__set_dm_plane_degamma() != -EINVAL`) and CRTC degamma (`cm_has_degamma || cm_is_degamma_srgb`). [F237]
- `amdgpu_dm_crtc_init()` must only enable CRTC degamma (`MAX_COLOR_LUT_ENTRIES`) when `dc->caps.color.dpp.dcn_arch` is true and `dce_version != DCN_VERSION_4_01`; `dm_crtc_additional_color_mgmt()` must only attach `regamma_tf_property` when `dc->caps.color.mpc.ogam_ram` is true. [F309]
- `amdgpu_dm_verify_lut3d_size()` must check both `dc->caps.color.dpp.hw_3d_lut` and `dc->caps.color.mpc.preblend`, and verify `lut3d_size == MAX_COLOR_3DLUT_SIZE^3` (4913) before `__drm_3dlut_to_dc_3dlut()` stripes `lut` across `lut0..lut3` in steps of 4 up to `lut3d_size - 4` (avoiding underflow or overflowing `tetrahedral_17x17x17`). [F252, F308]
- In `compute_mst_dsc_configs_for_state()` and `pre_compute_mst_dsc_configs_for_state()`, after `compute_mst_dsc_configs_for_link()` succeeds, all streams sharing `stream->link` must be marked `true` in `computed_streams[]`; in `compute_mst_dsc_configs_for_link()` and `set_dsc_configs_from_fairness_vars()`, `params` is indexed `0..count-1` while shared `vars` must be indexed at `vars[i + k]` (`k = *link_vars_start_index`, advanced by `count` per link). [F261, F279]
- In `increase_dsc_bpp()` and `try_disable_dsc()`, if `drm_dp_mst_atomic_check(state)` fails after updating `vars[next_index].pbn` and `drm_dp_atomic_find_time_slots()`, `vars[next_index].pbn` must be restored and `drm_dp_atomic_find_time_slots()` called again to roll back the time-slot reservation. [F239]
- In `dm_dp_mst_is_port_support_mode()`, when `passthrough_aux` and `immediate_upstream_port` are NULL (LCT=1), `virtual_channel_bw_in_kbps` must fall back to `root_link_bw_in_kbps` and still be checked against `bw_range.min_kbps`. [F267]
- In `dm_helpers_dp_write_dsc_enable()` for non-Synaptics DP MST streams with `port->passthrough_aux`, enabling DSC must write `DP_DSC_ENABLE` to `port->passthrough_aux` before `aconnector->dsc_aux`, and disabling must write `aconnector->dsc_aux` before `port->passthrough_aux`. [F305]
- In `dm_handle_mst_sideband_msg_ready_event()`, the ESI DPCD read/ack loop must hold `aconnector->handle_mst_msg_ready`, bound iterations to `max_process_count` (30), and retry each `dpcd_addr + 1` ACK write up to 3 times. [F315]
- DSC debugfs write handlers (`dp_dsc_clock_en_write`, `dp_dsc_slice_width_write`, `dp_dsc_slice_height_write`, `dp_dsc_bits_per_pixel_write`) must set `dm_crtc_state->dsc_force_changed = true` on `crtc->state`, while `amdgpu_dm_crtc_duplicate_state()` must leave `dsc_force_changed` zeroed. [F238]
- `update_phy_id_mapping()` must cap collected connectors at `AMDGPU_DM_MAX_CRTC`, and both `update_phy_id_mapping()` and `get_phy_id()` must unpack MST `rad` hops (`lct > 1`, `0 <= k < lct - 1`) as `(rad[k / 2] >> ((k % 2) ? 0 : 4)) & 0xf`. [F262]
- `dm_need_crc_dither()` must return `true` for `AMDGPU_DM_PIPE_CRC_SOURCE_NONE` as well as `*_DITHER` sources so `amdgpu_dm_crtc_configure_crc_source()` restores default dithering on stop; in `dm_helpers_dp_handle_test_pattern_request()`, pipe search must require `!pipes[i].top_pipe && !pipes[i].prev_odm_pipe` and return `false` if `pipe_ctx` is NULL. [F275, F278]
- Before calling `psp_hdcp_invoke()`, `psp_dtm_invoke()`, or `psp_securedisplay_invoke()` (in `psp_get_srm`, `psp_set_srm`, `enable_assr`, `amdgpu_dm_crtc_notify_ta_to_read`), callers must verify `psp->*_context.context.initialized` before accessing `shared_buf`. [F311]

## Synchronization

- `amdgpu_dm_irq_register_interrupt()` allocates with `GFP_KERNEL` (non-atomic context only) and must initialize `handler`, `handler_arg`, `dm`, `irq_source`, and `INIT_WORK(&handler_data->work, dm_irq_work_func)` before `list_add_tail(&handler_data->list, hnd_list)`. [F197, F322]
- `INTERRUPT_HIGH_IRQ_CONTEXT` handlers in `irq_handler_list_high_tab` (`amdgpu_dm_crtc_handle_vblank`, `amdgpu_dm_crtc_handle_crc_irq`) run from `amdgpu_dm_irq_immediate_work()` under `spin_lock_irqsave(&adev->dm.irq_handler_list_table_lock)` and must not sleep or re-acquire `irq_handler_list_table_lock`. [F321]
- `amdgpu_dm_crtc_set_vblank()` (`amdgpu_dm_crtc_enable_vblank` / `disable_vblank`) runs under DRM vblank/event spinlocks, so it must allocate `vblank_control_work` with `GFP_ATOMIC` and defer `dm->dc_lock` operations (`amdgpu_dm_crtc_set_panel_sr_feature()`) to `amdgpu_dm_crtc_vblank_control_worker`. [F325]
- `drm_device.event_lock` protects `acrtc->dm_irq_params` and `crtc_ctx->roi`/`crc_info.crc` across hardirq and process/workqueue contexts and must always be acquired with IRQs disabled. [F327]
- In `amdgpu_dm_crtc_handle_crc_window_irq()` (`LEGACY_MODE`), DMUB ROI forwarding and PSP TA notification must be deferred to `forward_roi_work` and `notify_ta_work`; `amdgpu_dm_crtc_notify_ta_to_read()` and `amdgpu_dm_forward_crc_window()` must copy `crc`/`roi` under `event_lock` and drop it before taking `psp->securedisplay_context.mutex` or `dm->dc_lock`, and hold `ddev->mode_config.mutex` when calling `get_phy_id()` or `update_phy_id_mapping()`. [F200, F203, F329]
- In `amdgpu_dm_idle_worker()`, after dropping `dc_lock` across `fsleep()`, `dc_lock` must be re-acquired and `!amdgpu_dm_is_headless(adev) && !amdgpu_dm_psr_is_active_allowed(dm)` plus `idle_work->enable` rechecked before calling `dc_post_update_surfaces_to_stream()` and `dc_allow_idle_optimizations(dc, true)`. [F207]
- Per-link `hdcp_w->mutex` must protect all `mod_hdcp_*` calls, `process_output()`, and `hdcp_w->aconnector[conn_index]` updates; `event_property_update()` must acquire `dev->mode_config.connection_mutex` before `hdcp_work->mutex` and await `conn_state->commit->hw_done` before calling `drm_hdcp_update_content_protection()`. [F191, F192]
- In `amdgpu_dm_debugfs.c`, `trigger_hotplug`, `dp_is_mst_connector_show`, and `dp_mst_progress_status_show` must take `aconnector->hpd_lock` outer-most before `dc_lock`, `mgr->base.lock`, or `drm_modeset_lock_all(dev)`; DSC debugfs write handlers must lock `mode_config.mutex`, `connection_mutex`, then `crtc->mutex` and unlock in reverse order before freeing `wr_buf`. [F187, F212]

## Object Lifetimes

- `amdgpu_dm_set_crc_window_default` must clear `acrtc->dm_irq_params.crc_window_activated` under `drm_dev->event_lock` before flushing `notify_ta_work` and `forward_roi_work` and forwarding a `NULL` window to DMUB. [F177]
- `dm_dp_add_mst_connector()` must call `drm_connector_dynamic_init()`, `amdgpu_dm_connector_funcs_reset()`, and `drm_dp_mst_get_port_malloc(port)` (paired with `drm_dp_mst_put_port_malloc(aconnector->mst_output_port)` in `dm_dp_mst_connector_destroy()`). [F349]
- Releasing `aconnector->dc_sink` in `dm_dp_mst_detect` or `amdgpu_dm_mst_connector_early_unregister` must remove the remote sink from `dc_link` (if `sink_count != 0`), call `dc_sink_release`, set `aconnector->dc_sink = NULL`, and call `amdgpu_dm_mst_reset_mst_connector_setting(aconnector)`; `amdgpu_dm_mst_connector_early_unregister()` must hold `root->mst_mgr.base.lock` across this teardown after `drm_dp_mst_connector_early_unregister()`. [F181, F209]
- In `pre_validate_dsc`, `local_dc_state` is shallow-copied from `dm_state->context`, so `clean_exit` must only call `dc_stream_release(local_dc_state->streams[i])` when `local_dc_state->streams[i] != dm_state->context->streams[i]` before `vfree(local_dc_state)`. [F182]
- Updating `hdcp_w->aconnector[conn_index]` in `hdcp_update_display()` or `update_config()` must pair `drm_connector_get()` and `drm_connector_put()`, and `hdcp_remove_display()` / `hdcp_reset_display()` must call `drm_connector_put()` before setting the slot to `NULL`. [F307]
- `hdcp_destroy()` must call `cancel_delayed_work_sync()` on `callback_dwork`, `watchdog_timer_dwork`, and `property_validate_dwork` for all `0..max_link - 1` links without holding `hdcp_work[i].mutex`, and remove `hdcp_work[0].attr` from sysfs before freeing `srm`, `srm_temp`, and `hdcp_work`. [F189, F333]
- `crtc_debugfs_init` must call `dput(dir)` on the dentry from `debugfs_lookup("crc", ...)`; `dtn_log_read` must `kfree(log_ctx.buf)` on all paths after `log_hw_state()`; `hdmi_cec_state_write` and `trigger_hotplug` must set `aconnector->notifier = NULL` and `link->local_sink = NULL` after unregistering/releasing them. [F185, F186, F188]

## API Contracts

- `amdgpu_dm_crtc_helper_atomic_check()` must return `-EINVAL` when `crtc_state->async_flip` is set and `dm_crtc_state->update_type != UPDATE_TYPE_FAST`. [F344]
- In `amdgpu_dm_crtc_handle_vblank()`, after `drm_crtc_handle_vblank()`, if `acrtc->event` is set and `acrtc->pflip_status != AMDGPU_FLIP_SUBMITTED`, it must under `dev->event_lock` call `drm_crtc_send_vblank_event()`, call `drm_crtc_vblank_put(crtc)`, and set `acrtc->event = NULL`. [F346]
- In `amdgpu_dm_crtc_handle_crc_window_irq()`, `window_param[i]` holds end coordinates (`x_end`, `y_end`), so `crtc_ctx->roi[i].rect` must be computed as `width = windowa_x_end - windowa_x_start` and `height = windowa_y_end - windowa_y_start`. [F226]
- Whole-bpp limits in `display_info.max_dsc_bpp` and `struct dc_dsc_policy` (`min_target_bpp`, `max_target_bpp`) must be multiplied by `16` when passed to `max_target_bpp_limit_override_x16` or `dc_dsc_compute_bandwidth_range()`. [F229]
- `dm_dp_aux_transfer` downcasts `struct drm_dp_aux *` via `TO_DM_AUX(aux)` and must only be used for `aconnector->dm_dp_aux.aux`, never for `drm_dp_mst_port.aux` or `dsc_aux`. [F297]
- When removing an MST payload in `dm_helpers_dp_mst_write_payload_allocation_table()` (`!enable`) or `dm_helpers_dp_mst_update_mst_mgr_for_deallocation()`, `dm_helpers_construct_old_payload()` must reconstruct `old_payload` from `mst_state->payloads` before updating DC or calling `drm_dp_remove_payload_part2()`. [F350]

## Error Handling

- `validate_irq_registration_params()` and `validate_irq_unregistration_params()` must check `DAL_VALID_IRQ_SRC_NUM(irq_source)` and `int_context < INTERRUPT_CONTEXT_NUMBER` before indexing `irq_handler_list_high_tab` or `irq_handler_list_low_tab`. [F257]
- In `dm_helpers_parse_edid_caps()`, `drm_edid_to_sad()` and `drm_edid_to_speaker_allocation()` return negative errno or `0` when absent, so counts must be signed, returning early if `sad_count <= 0` and clamping negative `sadb_count` to `0`. [F227]
- In `validate_dsc_caps_on_connector()`, `dsc_branch_dec_caps` passed to `dc_dsc_parse_dsc_dpcd()` must remain `NULL` unless the 3-byte `drm_dp_dpcd_read()` of `DP_DSC_BRANCH_OVERALL_THROUGHPUT_0` returns `3`. [F228]
- In `compute_mst_dsc_configs_for_link()`, if the uncompressed `drm_dp_mst_atomic_check(state)` returns `-ENOSPC`, it must fall through to the max-compression pass, whereas any other non-zero error must be returned immediately. [F230]
- `psp_set_srm()` must return `-EINVAL` if `srm_version == PSP_SRM_VERSION_MAX` (`0xFFFF`) even when `hdcp_status == TA_HDCP_STATUS__SUCCESS` and `valid_signature == 1`; in `update_config()` (`amdgpu_dm_hdcp.c`), `sink` must fall back from `dc_sink` to `dc_em_sink` and be checked for non-NULL before dereferencing `sink->sink_signal`. [F220, F221]
- `dmub_tracebuffer_show()` must check `adev->dm.dmub_srv != NULL` before taking `&adev->dm.dmub_srv->meta_info` (falling back to `DMUB_TRACE_BUFFER_SIZE`), locate `entries` after `sizeof(struct dmub_debugfs_trace_header)`, wrap `first_entry = num_entries % max_entries`, and clamp `num_entries = min(num_entries, max_entries)`. [F214, F264]
- In `amdgpu_dm_debugfs.c`, `parse_write_buffer_into_params()` must clamp `*param_nums` to `max_param_num` and parse hex (`kstrtol(..., 16, ...)`); `dp_dsc_slice_width_write` / `height_write` must check `param[0] > 0` before `DIV_ROUND_UP`; `edp_ilr_show()` must step `entry` by 2, and `edp_ilr_write()` must check `param[1] < edp_supported_link_rates_count`. [F263, F266, F286]

## External Contracts

- Because `PSP_HDCP_SRM_FIRST_GEN_MAX_SIZE` (5120) exceeds `PAGE_SIZE`, `srm_data_write()` must stage chunks at `work->srm_temp + pos`, call `psp_set_srm()` with length `pos + count`, and return `count` even if `psp_set_srm()` fails on an incomplete prefix chunk. [F254]
- `dp_link_settings_read()` and `dp_phy_settings_read()` require 4-byte aligned `*pos` and `size` (`*pos & 3 || size & 3` returns `-EINVAL`), and `dp_max_bpc_write()` requires `param[0]` in `[6, 16]`. [F265]

## Known Pitfalls

- Because `__drm_lut_to_dc_gamma()` loops up to `MAX_COLOR_LEGACY_LUT_ENTRIES` or `MAX_COLOR_LUT_ENTRIES` and `__is_lut_linear()` divides by `size - 1`, callers (`amdgpu_dm_check_crtc_color_mgmt`, `__set_output_tf`, `__set_input_tf`, `__set_legacy_tf`) must validate LUT sizes via `amdgpu_dm_verify_lut_sizes()` or `amdgpu_dm_verify_lut3d_size()` first. [F251, F282]
- CRTC CTM blobs (`crtc->base.ctm->data`, `struct drm_color_ctm`, 9 elements) must use `__drm_ctm_to_dc_matrix`, whereas plane CTM blobs (`dm_plane_state->ctm->data`, `struct drm_color_ctm_3x4`, 12 elements) must use `__drm_ctm_3x4_to_dc_matrix`. [F294]
- In `dm_mst_get_pbn_divider`, `kbps_to_peak_pbn`, `bpp_x16_from_pbn`, and `kbps_from_pbn`, 32-bit `kbps`/`pbn` values must be widened to 64-bit unsigned before multiplying, using `div64_u64`/`div_u64`/`DIV64_U64_ROUND_UP` and `dfixed_const(pbn_div_x100) / 100`; `kbps_to_peak_pbn` and `increase_dsc_bpp` (`DIV_ROUND_UP(..., dfixed_trunc(mst_state->pbn_div))`) must use ceiling division. [F287, F288, F289]
- In `dm_helpers_read_local_edid` and `dm_dp_mst_get_modes`, `edid->extensions` excludes the base block, so raw EDID size is `(edid->extensions + 1) * EDID_LENGTH` after checking `edid->extensions < sizeof(sink->dc_edid.raw_edid) / EDID_LENGTH`. [F300]
- In `dmub_trace_mask_show` and `dmub_trace_mask_set`, `response` and `mask` must be held in `u64` variables before shifting by `shift` or `16` across the 4-iteration loop (shifts reach 32 and 48 bits). [F285]
