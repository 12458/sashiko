# OPEN FIRMWARE AND FLATTENED DEVICE TREE — drivers/of

`drivers/of` parses early-boot FDT blobs and PROM trees into refcounted `struct device_node` and `struct property` objects under `/sys/firmware/devicetree` and `/proc/device-tree`, providing APIs for node/property queries, phandle/graph traversal, address/DMA/IRQ translation, reserved memory, device creation, and changesets/overlays.

## Architecture & Data Flow
- `of_node_release()` requires `OF_DETACHED` before refcount hits zero (never format `!OF_DETACHED` `node` with `%pOF`), and only frees `node` and `properties`/`deadprops` when `OF_DETACHED` and `OF_DYNAMIC` are set and—if `OF_OVERLAY`—`OF_OVERLAY_FREE_CSET` was set by `__of_changeset_entry_destroy()` at refcount `1`. [F11, F33]
- `__of_detach_node()` must set `OF_DETACHED` and call `__of_phandle_cache_inv_entry(np->phandle)` under `devtree_lock` before `__of_detach_node_sysfs()` so `of_find_node_by_phandle()` cannot return or re-cache `np`. [F56]
- Changeset property builders (`of_changeset_add_prop_string()`, etc.) must pass stack `struct property` structs to `of_changeset_add_prop_helper()` / `of_changeset_update_prop_helper()` for `__of_prop_dup()`. On `OF_RECONFIG_UPDATE_PROPERTY`, `__of_changeset_entry_apply()` saves the displaced property in `ce->old_prop` via `__of_update_property()`, and `__of_changeset_entry_invert()` swaps `ce->prop` and `ce->old_prop` (or sets `OF_RECONFIG_REMOVE_PROPERTY` if `!ce->old_prop`). [F60, F130]
- `of_overlay_remove()` returns `-EBUSY` if `overlay_removal_is_ok()` finds overlapping nodes in a newer overlay on `ovcs_list`, and only zeroes `*ovcs_id` and calls `free_overlay_changeset(ovcs)` after `OF_OVERLAY_PRE_REMOVE` and `__of_changeset_revert_entries()` succeed; `of_overlay_remove_all()` and `of_changeset_destroy()` must use `list_for_each_entry_safe_reverse()`. Failed rollbacks in `of_overlay_apply()` / `of_overlay_remove()` permanently set `DTSF_APPLY_FAIL` / `DTSF_REVERT_FAIL` in `devicetree_state_flags` so `devicetree_corrupt()` rejects future overlay ops with `-EBUSY`. [F19, F61, F104]
- `init_overlay_changeset()` must put a `"__symbols__"` child at `ovcs->fragments[ovcs->count - 1]` with `ovcs->symbols_fragment = true` for `build_changeset()`. In `add_changeset_property()` and `add_changeset_node()`, `/__symbols__` properties fail with `-EINVAL` if existing and else use `dup_and_fixup_symbol_prop()`; targeting `target->in_livetree` rejects differing `#address-cells`/`#size-cells` (`-EINVAL`, or `0` if equal) and non-zero phandles on both `node` and `tchild` (`-EINVAL`). [F69, F70, F87]
- `of_platform_device_create_pdata()` and `of_amba_device_create()` gate creation with `of_node_test_and_set_flag(np, OF_POPULATED)` (clearing on error); `of_platform_device_destroy()` and `of_platform_depopulate()` clear `OF_POPULATED` / `OF_POPULATED_BUS` and check `dev->bus == &platform_bus_type` or `&amba_bustype` before downcasting `dev`. [F62, F129]
- In `of_translate_one()`, a missing `rprop` on `parent` fails unless `rprop` is `"dma-ranges"` or `of_empty_ranges_quirk(parent)`; for 1:1 translation, read `offset = of_read_number(addr, na)` before mutating `addr` and zero only `addr + pbus->flag_cells` (`(pna - pbus->flag_cells) * 4` bytes). [F65, F141]
- `__of_address_resource_bounds()` checks `overflows_type(start, r->start)` and sets `r->end` via `check_add_overflow(r->start, size - 1, &r->end)` if `size > 0`, or `wrapping_sub(typeof(r->end), r->start, 1)` if `size == 0`. `"nonposted-mmio"` sets `IORESOURCE_MEM_NONPOSTED`, which `of_iomap()` / `of_io_request_and_map()` must map via `ioremap_np()`. [F75, F147]
- In `of_irq_parse_raw()`, `"interrupt-map"` on an `"interrupt-controller"` node takes precedence unless absent or in `of_irq_imap_abusers`. In `of_parse_phandle_with_args_map()`, each nexus step must update both `initial_match_array[i]` and `out_args->args[i]` with the `<list>-map-pass-thru`-merged specifier before `cur = new`. [F64, F140]
- `struct property.value` is big-endian: `of_property_read_*` must use `be*_to_cpup()` / `of_read_number()`, and `of_changeset_add_prop_u32_array()` must use `cpu_to_be32()`. `__reserved_mem_alloc_in_range()` only calls `memblock_set_bottom_up(bottom_up)` when `bottom_up != top_down` and restores `prev_bottom_up`. `__of_match_node()` requires a zeroed sentinel and scans the full table for the highest score. [F67, F92, F143]
- Updating `OF_RECONFIG_*` or `enum of_overlay_notify_action` requires updating `action_names[]` and `of_overlay_action_name[]`; changing `drivers/of/` APIs requires updating `!CONFIG_OF*` stubs in `include/linux/of.h` and `drivers/of/of_private.h`. [F73, F74]

## Synchronization
- Hold `devtree_lock` (`raw_spin_lock_irqsave()`) when accessing live `parent`/`child`/`sibling`, `properties`/`deadprops`, or `phandle_cache`, calling `of_node_get()` before unlocking. Internal `__of_*` helpers (`__of_find_property`, `__of_get_property`, `__of_find_all_nodes`, `__of_get_next_child`, `__of_find_node_by_path`, `__of_find_node_by_full_path`, `__of_device_is_available`) do not lock `devtree_lock` and require `devtree_lock` held or `OF_DETACHED`. [F23, F24]
- Hold `of_mutex` across live DT mutations, sysfs updates, and post-boot `aliases_lookup` walks (`of_alias_get_id()`). Drop `devtree_lock` before `__of_*_sysfs()`, and unlock `of_mutex` in `__of_changeset_apply_notify()` / `__of_changeset_revert_notify()` around `__of_changeset_entry_notify()`. [F14, F27, F29]
- `of_overlay_fdt_apply()` locks `of_overlay_phandle_mutex` (`of_overlay_mutex_lock()`) outside `of_mutex`, serializing `of_resolve_phandles()` (requires `OF_DETACHED` and `of_overlay_phandle_mutex`) and `of_overlay_apply()`; `adjust_overlay_phandles()` updates both `overlay->phandle` and `phandle`/`linux,phandle` properties by `live_tree_max_phandle() + 1` before `__local_fixups__`. [F16, F68]
- `of_reserved_mem_device_release()` unlinks `struct rmem_assigned_device` entries under `of_rmem_assigned_device_mutex` onto a local list and unlocks before `rd->rmem->ops->device_release()`. [F158]

## Object Lifetimes
- Iterative lookup helpers (`of_find_all_nodes`, `of_find_node_by_*`, `of_find_compatible_node`, `of_find_matching_node_and_match`, `of_get_next_*`, `of_graph_get_next_*`) put `prev`/`from` and get the returned node, and `of_phandle_iterator_next()` puts the prior `it->node` on each step/error; early exits from non-scoped `for_each_*` loops or `of_for_each_phandle()` must call `of_node_put()`. [F1, F3]
- `__of_remove_property()` and `__of_update_property()` move replaced/removed `struct property` objects to `np->deadprops` under `devtree_lock` until `of_node_release()`. `__of_changeset_entry_destroy()` does not free `ce->prop`, so `of_changeset_add_prop_helper()` must call `__of_prop_free(new_pp)` and return if `of_changeset_add_property()` fails, or link `new_pp` to `np->deadprops` on success. [F9, F10]
- `of_changeset_destroy()` must call `device_link_wait_removal()` before destroying entries. When `of_kset` is initialized, `__of_attach_node_sysfs()` calls `of_node_get(np)` after `kobject_add()` and `kfree(name)` on `safe_name()`, and `__of_detach_node_sysfs()` removes property `bin_file`s and `np->kobj` before `of_node_put(np)`. [F12, F15]
- `of_resolve_phandles()` must bind `local_fixups` and `tree_symbols` with `__free(device_node)` and call `of_node_put(refnode)` on each `of_find_node_by_path(refpath)` in the `__fixups__` loop. [F22]
- In `of_irq_init()`, each `struct of_intc_desc` on `intc_desc_list` owns refs to `desc->dev` and `desc->interrupt_parent` (self-parenting dropped/NULLed). It initializes parent-first from `desc->interrupt_parent == NULL`, sets `OF_POPULATED` before `desc->irq_init_cb()` (clearing on error), breaks if `intc_parent_list` is empty, and puts both `desc->interrupt_parent` and `desc->dev` before `kfree(desc)` on error. [F6, F109, F134]

## API Contracts
- `__of_find_node_by_path()` increments the returned node's refcount, and `__of_find_node_by_full_path()` consumes the caller's ref on `node` while returning an owned ref without `devtree_lock`. [F2]
- `of_irq_parse_raw()` gets the resolved parent in `out_irq->np` without putting the initial `out_irq->np` (`of_irq_parse_one()` must put initial `p` and callers must put `out_irq->np`); on a self-referencing `interrupt-map` (`ipar == newpar`), `of_irq_parse_raw()` must put `ipar` before returning `0` because `of_irq_parse_imap_parent()` got a second ref. [F4, F5]
- `__of_translate_address()` uses `__free(device_node)` on `dev`/`parent`, except non-`LOGIC_PIO_CPU_MMIO` indirect-IO ranges transfer `dev` via `*host = no_free_ptr(dev)` for the caller to put. `of_translate_address()`, `of_translate_dma_address()`, `__of_translate_address()`, and `of_translate_ioport()` return `OF_BAD_ADDR` (`(u64)-1`) on failure; `of_dma_get_range()` skips `OF_BAD_ADDR` and returns `-EINVAL` if `!num_ranges`. [F8, F40]
- `of_find_property()`, `of_get_property()`, `__of_find_property()`, and `__of_get_property()` leave `*lenp` untouched on `NULL`. Variable-array readers (`of_property_read_variable_u32_array()`, etc.) scale `sz_min`/`sz_max` by `sizeof(*out_values)` for `of_find_property_value_of_size()` and divide returned `sz` by `sizeof(*out_values)` when `sz_max != 0`. [F38, F122]
- `irq_of_parse_and_map()` returns `unsigned int` `0` on failure, whereas `of_irq_get()`, `of_irq_get_byname()`, and `of_irq_to_resource()` return signed `int` (`< 0` error, `0` mapping failure, `> 0` IRQ). [F42]
- `of_phandle_iterator_init()` zeroes `*it` and requires `cells_name || cell_count >= 0`. `of_phandle_iterator_next()` sets `it->cur = it->phandle_end`, falls back to `it->cell_count >= 0` when `it->cells_name` is absent, checks `it->cur + count <= it->list_end` when `it->phandle` is non-zero, and sets `it->phandle_end = it->cur + count`. `of_fwnode_get_reference_args()` puts `of_args.np` if `!args`, or zero-fills `args->args[i]` up to `NR_FWNODE_REFERENCE_ARGS`. [F51, F84, F108, F169]
- In `of_supplier_bindings[]`, `.parse_prop` and `.get_con_dev` return refcounted `device_node *` pointers (put by `of_link_property()`), with `.parse_prop` returning first supplier at `index == 0` and `NULL` when exhausted. Subnode bindings (`parse_remote_endpoint()`) must set `.get_con_dev` (`of_graph_get_port_parent`) so `of_link_property()` passes `con_dev_np` to `of_link_to_phandle()`; never add standalone `"interrupt-parent"` to `of_supplier_bindings[]`. [F99, F111, F144, F145, F170]
- `of_reserved_mem_device_init_by_idx()` returns `0` when `target` is disabled, whereas `of_reserved_mem_region_to_resource()` returns `-ENODEV` when `!target || !of_device_is_available(target)`. `early_init_dt_alloc_reserved_memory_arch()` calls `kmemleak_ignore_phys(base)` on all `!err` allocations, and `early_init_dt_reserve_memory()` returns `-EBUSY` without `memblock_mark_nomap()` if a `nomap` region overlaps `memblock.memory` and is already reserved. String arrays for `of_device_compatible_match()`, `of_machine_compatible_match()`, `of_flat_dt_match()`, and `__of_device_is_status()` must be `NULL`-terminated. [F53, F90, F166, F168]

## Error Handling
- `__of_changeset_apply_entries()` rolls back via `list_for_each_entry_continue_reverse()` and `__of_changeset_revert_entries()` via `list_for_each_entry_continue()`, keeping primary error in `ret` and rollback error in zero-initialized `*ret_revert` / `*ret_apply`. [F13, F48]
- `of_overlay_fdt_apply()` must set `ovcs->notify_state = OF_OVERLAY_INIT` and `of_changeset_init(&ovcs->cset)` on `ovcs_list` insertion, check `overlay_fdt_size >= sizeof(struct fdt_header)`, `!fdt_check_header()`, and `overlay_fdt_size >= fdt_totalsize()`, save raw `kmalloc(size + FDT_ALIGN_SIZE)` in `ovcs->new_fdt` while unflattening `PTR_ALIGN(new_fdt, FDT_ALIGN_SIZE)`, and on `of_overlay_apply()` failure export `*ret_ovcs_id = ovcs->id` for `of_overlay_remove()` instead of `free_overlay_changeset()`. [F37, F47, F80, F124]
- Check `of_match_bus()` for `NULL`, and check `of_property_present(np, "#address-cells")` before `of_bus_n_addr_cells(np)`. Check `OF_CHECK_COUNTS()` on `na`, `ns`, `pna`, `pns` before copying into `addr[OF_MAX_ADDR_CELLS]` in `__of_translate_address()` and `fdt_translate_address()`. [F43, F82]
- In `of_parse_phandle_with_args_map()`, `of_property_read_u32()` sets `ret = 0`, so every `goto put` in the loop must set a negative `ret`; advancing past a phandle cell in `of_parse_phandle_with_args_map()` or `of_irq_parse_imap_parent()` must decrement `map_len`/`len` before checking remaining cells and `MAX_PHANDLE_ARGS`. [F44, F76]
- `update_usages_of_a_phandle_reference()` and `adjust_local_phandle_references()` must verify `offset + 4 <= prop->length` and `prop_fix->length % 4 == 0`. String readers (`of_property_read_string*()`, `of_property_match_string()`, `dup_and_fixup_symbol_prop()`) must check NUL-termination within `prop->length` via `strnlen()`. [F81, F83]
- In `of_dma_configure_id()`, call `of_dma_get_range()` on `__of_get_dma_parent(np)` if `np == dev->of_node` else `of_node_get(np)`; only reset `dev->dma_range_map = NULL` on `-EPROBE_DEFER` if `set_map`, and ensure non-zero `end` (`dev->coherent_dma_mask` or `(1ULL << 32) - 1` fallback) before `DMA_BIT_MASK(ilog2(end) + 1)`. [F54, F110, F115]

## External Contracts
- `__of_add_property_sysfs()` gives `"security-"` properties mode `0400` and `size = 0`. `early_init_dt_scan_chosen()` scrubs `/chosen/rng-seed` via `fdt_nop_property()` and updates `of_fdt_crc32` for `of_fdt_raw_init()`. [F164, F165]
- `/chosen/linux,usable-memory-range` orders `crashk_res` before `crashk_low_res` (`MAX_USABLE_RANGES`); `of_kexec_alloc_and_setup_fdt()` deletes existing `"kaslr-seed"` and `"linux,ima-kexec-buffer"` (`remove_ima_buffer()`) and only writes fresh seeds if `rng_is_initialized()`. `of_platform_default_populate_init()` names the primary PowerPC boot display `"of-display"` and others `"of-display.%d"` (bounds-checked). [F79, F93, F172]

## Known Pitfalls
- Never use `%pOF` under `devtree_lock` (deadlocks in `of_get_parent()`), and never place an alphanumeric literal directly after `%pOF*` (use `%c`). [F25, F127]
- `of_read_number()` / `of_read_ulong()` take `size` in 4-byte cells: divide byte lengths from `of_get_property()` / `fdt_getprop()` (including `"linux,initrd-*"`) by 4 for `of_read_number()`, `__be32 *` math, or cell comparisons, but scale `const void *` offsets (`do_get_kexec_buffer()`) by `4 * addr_cells`. [F50, F78, F120, F121]
- `of_modalias()` rejects `(len > 0 && !str) || len < 0` (`-EINVAL`) and clamps `csize` when `csize >= len`; callers sizing with `of_modalias(np, NULL, 0)` (`of_request_module()`) must add 1 to `size` for allocation and the second call, and `of_device_uevent_modalias()` must check `sl >= sizeof(env->buf) - env->buflen`. [F91, F126]
- `of_find_node_opts_by_path()` and `__of_find_node_by_path()` bound alias/component lengths with `'/'` and `':'` (`strcspn(path, "/:")`). `of_graph_get_next_endpoint()` resets `prev = NULL` when advancing `port`. [F77, F107]
- `early_init_dt_add_memory_arch()` must check `size` before page-aligning `base` or subtracting `phys_offset - base`, and clamp against `MAX_MEMBLOCK_ADDR` before `memblock_add()`. Use `initial_boot_params_pa`, never `__pa(initial_boot_params)`. [F116, F117, F159]
