# GENERIC PHY FRAMEWORK — (top level)

Core Generic PHY headers/bindings (`include/linux/phy/*`, `include/dt-bindings/phy/*`) and PHY drivers for Socionext UniPhier, Sophgo CV1800, ST (SPEAr, STM32 USBPHYC), Tegra194 P2U, and TI (AM654, J721E WIZ, OMAP USB2/Control, PIPE3, GMII-SEL, DA8xx, DM816x, TUSB1210, TWL4030).

## Architecture & Data Flow

- In `phy-ti-pipe3.c` and `phy-omap-usb2.c`, absent optional/mode-unused clocks (`refclk`, `wkupclk`, `div_clk`, `optclk`) hold `ERR_PTR` and must be checked with `!IS_ERR()`, not non-NULL. `struct pipe3_dpll_map` arrays (`dpll_map_usb`, `dpll_map_sata`) must end with a `{ }` sentinel (`.rate == 0`). [F183, F213]
- In `phy-omap-control.c`, `struct omap_control_phy` maps `otghs_control` only for `OMAP_CTRL_TYPE_OTGHS`, `power` when `type != OMAP_CTRL_TYPE_OTGHS`, `pcie_pcs` for `OMAP_CTRL_TYPE_PCIE`, and `sys_clk` for `PIPE3`/`PCIE`. `omap_control_phy_id_table` `.data` must point to a `const enum omap_control_phy_type` object (not an integer cast to `void *`) because `omap_control_phy_probe()` dereferences it. [F186, F243]
- In `twl4030`, `omap_usb`, and `dm816x_usb_phy` `set_peripheral()`/`set_host()`, clearing `otg->gadget` or `otg->host` to NULL must set `otg->state = OTG_STATE_UNDEFINED`. In `twl4030_usb_linkstat()`, if `STS_HW_CONDITIONS` `BIT(7)` is set, `twl4030_is_driving_vbus()` must clear self-driven VBUS first, and `BIT(2)` (`MUSB_ID_GROUND`) must be checked before `BIT(7)` (`MUSB_VBUS_VALID`). [F204, F229]
- In `phy-tusb1210.c`, cache ULPI writes to `ULPI_OTG_CTRL` and `TUSB1210_VENDOR_SPECIFIC2` in `tusb->otg_ctrl` and `tusb->vendor_specific2` for restore in `tusb1210_power_on()` and `TUSB1210_CHG_DET_FINISH_DET`. Once `TUSB1210_CHG_DET_CONNECTING` gets runtime PM on `tusb->dev->parent`, all paths (including `tusb1210_chg_det_handle_ulpi_error()` retries) must reach `TUSB1210_CHG_DET_FINISH_DET` to call `pm_runtime_put(tusb->dev->parent)`. [F201, F234]
- In `phy-stm32-usbphyc.c` and `phy-gmii-sel.c`, `dev_get_drvdata(dev)` holds the controller struct (`struct stm32_usbphyc *` or `struct phy_gmii_sel_priv *`), while `phy_get_drvdata(phy)` holds the per-port struct (`struct stm32_usbphyc_phy *` or `struct phy_gmii_sel_phy_priv *`). [F247]
- In `phy-stm32-usbphyc.c`: `stm32_usbphyc_pll_init()` must verify `clk_rate` is in `[PLL_INFF_MIN_RATE_HZ, PLL_INFF_MAX_RATE_HZ]` before `stm32_usbphyc_get_pll_params()`; `stm32_usbphyc_phy_tuning()` must OR factory `OTPCOMP` from `STM32_USBPHYC_TUNE(index)` into `usbphyc_phy->tune` so tuning and `stm32_usbphyc_resume()` preserve it; `usbphyc->switch_setup` (initially `-EINVAL`) must be updated with `SWITHOST` in `STM32_USBPHYC_MISC` via `stm32_usbphyc_switch_setup()` to reject conflicting port 1 requests with `-EBUSY` and restore on resume. [F194, F196, F238]
- In `phy-gmii-sel.c`, `phy_gmii_init_phy()` must advance `*fields++` at every enum slot (`PORT_MODE`, `RGMII_ID_MODE`, `RMII_IO_CLK_EN`) even when its `soc_data->features` bit is unset, and copy `soc_data->regfields[port - 1]` to a local `struct reg_field` to add `priv->reg_offset` before `devm_regmap_field_alloc()`. When `soc_data->use_of_data` is true, `priv->num_ports = size / sizeof(u32)` requires `soc_data->regfields` to have `>= priv->num_ports` rows. [F199, F233, F248]
- In `phy_gmii_sel_mode()`, update `if_phy->phy_if_mode` only after validating `mode`/`submode` so `phy_gmii_sel_resume_noirq()` replays only valid submodes. `RGMII_RXID` groups with `RGMII` (`rgmii_id = 0`), while `RGMII_ID`/`RGMII_TXID` set `rgmii_id = 1`. SoCs with `BIT(PHY_GMII_SEL_FIXED_TX_DELAY)` must reject `rgmii_id != 0` with `-EINVAL` while keeping `BIT(PHY_GMII_SEL_RGMII_ID_MODE)` and its `regfields` entry so `rgmii_id = 0` is written. [F200, F226, F255]
- In `phy-am654-serdes.c`, `serdes_am654_xlate()` and `serdes_am654_release()` must keep `am654_phy->busy`, `am654_phy->type`, and `mux_control` in lockstep. In `serdes_am654_clk_register()`, convert the `of_get_address()` pointer via `be32_to_cpu(*addr)` and keep `clock_num` (`mux->clk_id`) in `0 .. SERDES_NUM_CLOCKS - 1`. [F197, F223]
- In `phy-j721e-wiz.c`: `wiz->num_lanes` and child `reg + num_lanes` in `wiz_get_lane_phy_types()` must be `<= WIZ_MAX_LANES` (4); `clk_div_table` arrays must end with `{ /* sentinel */ }` (`.div == 0`); any `wiz_data` with `WIZ_CORE_REFCLK1` in `clk_mux_sel` `.parents` must set `.pma_cmn_refclk1_int_mode`; when `wiz->scm_regmap` is present, allocate `mux_sel_field[]` and `pma_cmn_refclk1_int_mode` on `scm_regmap` and write 1 to `wiz->sup_legacy_clk_override` in `wiz_probe()` and `wiz_resume_noirq()`; `switch (wiz->type)` in `wiz_clock_probe()` and `wiz_clock_cleanup()` must list the exact same `wiz_type` variants (`AM64_WIZ_10G`, `J7200_WIZ_10G`, `J784S4_WIZ_10G`, `J721S2_WIZ_10G`); in `wiz_mode_select()`, `PHY_TYPE_USXGMII` sets `p0_mac_src_sel[i] = 0x3`, `p0_rxfclk_sel[i] = 0x3`, `p0_refclk_sel[i] = 0x2`, and `p_standard_mode[i] = LANE_MODE_GEN2`. [F208, F212, F219, F220, F230, F261]
- In UniPhier PHYs: `uniphier_u2phy_probe()` scans `uniphier_u2phy_soc_data` until `config0.offset == 0` (requiring non-zero valid offsets and a zero sentinel); `.nparams` must be `<= MAX_PHY_PARAMS` (4 in `usb3hs`, 7 in `usb3ss`); `uniphier_u3hsphy_update_config()` calls `trim_func()` only if `uniphier_u3hsphy_get_nvparams()` succeeds and `trim_param_is_valid(&trim)` holds, else sets `HSPHY_CFG0_HSDISC_MASK` in `*pconfig` to 3. [F193, F222, F245]

## Synchronization

- `struct phy` (`include/linux/phy/phy.h`) serializes `phy_ops` with `phy->mutex` using a per-instance `lockdep_key` (allowing nested upstream `phy_ops` calls); `phy_ops` run in sleeping context and must not be called from atomic context. Set `phy_set_drvdata()` and `dev_set_drvdata()` / `platform_set_drvdata()` before `of_phy_provider_register()` or `devm_of_phy_provider_register()`. [F158, F159, F274]
- In `phy-twl4030-usb.c`: `twl4030_usb_remove()` must finish `usb_remove_phy()` and `cancel_delayed_work_sync(&twl->id_workaround_work)` before disabling runtime PM and `POWER_CTRL_OTG_ENAB`; `twl4030_usb_suspend()` must call `disable_irq(twl->irq)` before checking `twl->runtime_suspended` and calling `twl4030_usb_runtime_suspend()`, and `twl4030_usb_resume()` must call `twl4030_usb_runtime_resume()` when `twl->needs_resume` is set before `twl4030_usb_irq(0, twl)`; `twl4030_usb_irq()` must reschedule `id_workaround_work` only when `status == MUSB_ID_GROUND` and `pm_runtime_active(twl->dev)`. [F164, F277, F278]
- In `phy-stm32-usbphyc.c`, control the shared PLL and `vdda1v1`/`vdda1v8` via `stm32_usbphyc_pll_enable()`/`disable()` (`usbphyc->n_pll_cons`). `usbphyc_phy->active` must be true iff that port holds a count in `n_pll_cons`, and `stm32_usbphyc_remove()` must call `stm32_usbphyc_phy_exit()` on active ports and `stm32_usbphyc_clk48_unregister()` before `clk_disable_unprepare(usbphyc->clk)`. [F165, F195, F271]

## Object Lifetimes

- `omap_usb2_probe()` and `ti_pipe3_get_sysctrl()` must tie `put_device(&control_pdev->dev)` for `of_find_device_by_node()` to the consumer via `devm_add_action_or_reset()`. `tusb1210_get_online()` must hold `power_supply_get_by_name()` only during the property read and call `power_supply_put()` before returning, never caching it in `struct tusb1210`. [F144, F145]
- In `phy-j721e-wiz.c`, for `J721E_WIZ_16G`/`10G`, `wiz_clock_cleanup()` must call `of_clk_del_provider()` and `of_node_put()` for all children in `clk_mux_sel` and `clk_div_sel`. `wiz_probe()` must `of_node_put(child_node)` for `"serdes"` on all exit paths, and `wiz_remove()` must call `of_platform_device_destroy(&serdes_pdev->dev, NULL)` before `wiz_clock_cleanup()` and `pm_runtime_disable()`. [F150, F151]
- In `ulpi_phy.h`, `ulpi_phy_create()` must call `phy_destroy(phy)` if `phy_create_lookup()` fails, and `ulpi_phy_destroy()` must call `phy_remove_lookup(phy, "usb2-phy", dev_name(ulpi->dev.parent))` before `phy_destroy(phy)`. In `twl4030_usb_irq()`, gate runtime PM get/put on `twl->dev` with `atomic_add_unless(&twl->connected, 1, 1)` on connect and `atomic_add_unless(&twl->connected, -1, 0)` on disconnect, and balance in `twl4030_usb_remove()` if `cable_present(twl->linkstat)`. [F154, F155]

## API Contracts

- In `phy.h` and `omap_control_phy.h`, keep `#if IS_ENABLED(...)` prototypes and `#else` stubs in lockstep. `devm_phy_optional_get()` and `devm_of_phy_optional_get()` return NULL when absent/disabled (non-optional getters return `ERR_PTR`), and `!IS_ENABLED(CONFIG_GENERIC_PHY)` op stubs (`phy_init`, `phy_power_on`, `phy_configure`, `phy_validate`, etc.) must return 0 if `!phy` before `-ENOSYS`/`-ENODEV`. In `struct phy_ops`, `.validate()` may adjust `opts` but must not mutate hardware or `struct phy` state; `.configure()` requires `phy_init()` first. [F169, F170, F171, F211]
- In `struct phy_configure_opts_dp` (`phy-dp.h`), `link_rate` is in Mb/s; `.configure()` must gate updates on `set_rate`, `set_lanes`, and `set_voltages`, applying `voltage[]`/`pre[]` only to lanes `0 .. lanes - 1`. In `struct phy_configure_opts_mipi_dphy` (`phy-mipi-dphy.h`), `hs_clk_rate`/`lp_clk_rate` are in Hz, `clk_pre` in UI, `init`/`wakeup` in us, and other timings (`clk_prepare`, `hs_prepare`, `hs_exit`, `lpx`, etc.) in ps. [F172, F173, F284]
- In `phy-gmii-sel.c`, port IDs (`if_phy->id`, `args->args[0]` in `phy_gmii_sel_of_xlate()`, `main_ports` in `phy_gmii_sel_probe()`) are 1-based: bound to `[1, soc_data->num_ports]` and convert to `id - 1` before indexing `priv->if_phys`, `soc_data->regfields`, or `PHY_GMII_PORT()`/`BIT(id - 1)` in `qsgmii_main_ports`. [F179, F239]
- In `phy-j721e-wiz.c`, `wiz_phy_reset_assert()`/`deassert()` use reset ID 0 for whole-SERDES reset (`wiz->phy_reset_n`, sleeping in `deassert` when `wiz->gpio_typec_dir` is set) and IDs `1..num_lanes` for lane `id - 1` (`nr_resets = num_lanes + 1`). `wiz_phy_en_refclk_ops` (`.enable`/`.disable`/`.is_enabled`) runs in atomic CCF context on `wiz->phy_en_refclk`, so `wiz_regmap_config` must stay non-sleeping spinlock-backed. In `phy-stm32-usbphyc.c`, `usbphyc_clk48_ops` must wire `stm32_usbphyc_pll_enable()`/`disable()` to `.prepare`/`.unprepare` (not `.enable`/`.disable`) because they sleep. [F181, F280, F281, F282]

## Error Handling

- In `tusb1210_probe()`, errors after `tusb1210_probe_charger_detect()` must call `tusb1210_remove_charger_detect()` (unregistering `psy_nb` and canceling `chg_det_work` before `power_supply_unregister(tusb->psy)`). In `tusb1210_power_on()`, `tusb1210_ulpi_write(tusb, TUSB1210_VENDOR_SPECIFIC2, tusb->vendor_specific2)` must not fail `tusb1210_power_on()` on error. [F146, F253]
- In `stm32_usbphyc_pll_enable()`, errors after `atomic_inc_return(&usbphyc->n_pll_cons)` must jump to `reg_disable` or `dec_n_pll_cons` to `atomic_dec(&usbphyc->n_pll_cons)`. In `stm32_usbphyc_phy_init()`, the `pll_disable` error path must ignore `stm32_usbphyc_pll_disable()`'s return value and return `ret`. [F148, F175]
- In `serdes_am654_probe()`, errors after `of_clk_add_provider()` and `pm_runtime_enable()` must jump to `clk_err` (`of_clk_del_provider()` and `pm_runtime_disable()`). In `stm32_usbphyc_probe()` and `uniphier_u2phy_probe()`, early error exits from `for_each_child_of_node()` must jump to `put_child`/`out_put_child` (`of_node_put(child)`). [F152, F156]
- Clear `vbus = NULL` when `devm_regulator_get_optional()` in `stm32_usbphyc_probe()` or `uniphier_u2phy`/`u3hsphy`/`u3ssphy_probe()` returns `IS_ERR()` other than `-EPROBE_DEFER`. Likewise, clear optional syscon regmap fields (`phy_power_syscon`, `pcs_syscon`, `dpll_reset_syscon`, `syscon_phy_power` in `ti_pipe3_get_sysctrl()`/`omap_usb2_probe()`, and `wiz->scm_regmap` on non-`J7200_WIZ_10G` in `wiz_probe()`) to NULL when `syscon_regmap_lookup_by_phandle()` returns `IS_ERR()`. [F177, F182, F184]
- In `phy_gmii_sel_init_ports()` and `serdes_am654_clk_register()`, check `of_get_address()` for non-NULL before `be32_to_cpu()` or using `size`. In `wiz_probe()`, `devm_ioremap()` and `of_platform_device_create()` return NULL (not `ERR_PTR`) on failure, and jumping to `err_addr_to_resource` or `err_wiz_init` on NULL or bounds checks requires setting `ret` to a negative errno. [F178, F180]
- In `omap_usb_set_vbus()` and `omap_usb_start_srp()`, verify both `phy->comparator` and `set_vbus`/`start_srp` are non-NULL or return `-ENODEV`. In `omap_usb2_enable_clocks()` and `ti_pipe3_enable_clocks()`, unwind failed `clk_prepare_enable()` calls with `clk_disable_unprepare()` (not `clk_disable()`). In `phy-twl4030-usb.c`, store `twl4030_readb()`/`twl4030_usb_read()` results in a signed `int` and check `>= 0`. [F185, F187, F265]

## External Contracts

- In `phy-j721e-wiz.c`, `wiz->output_clks[]` and `output_clk_names[]` are indexed by sparse `TI_WIZ_*` DT constants (`TI_WIZ_PHY_EN_REFCLK` is 16), so `WIZ_MAX_OUTPUT_CLOCKS` and `wiz->clk_data.clk_num` must exceed the highest `TI_WIZ_*` constant. In `stm32_usbphyc_of_xlate()`, port 0 (`index == 0`) requires `args->args_count == 0` and port 1 (`index == 1`) requires `args->args_count == 1` before reading `args->args[0]`. [F218, F224]

## Known Pitfalls

- In `phy-twl4030-usb.c`: in `twl4030_usb_probe()`, `err` must be 0 before `if (pdata) err = phy_create_lookup(...)`; in `twl4030_usb_runtime_resume()`, write 0 to `VUSB_DEDICATED2` after enabling `twl->usb3v1` (to clear `VUSB3V1_SLEEP`), and wrap `twl4030_usb_set_mode()` with `twl4030_i2c_access(twl, 1)` and (for `T2_USB_MODE_ULPI`) `twl4030_i2c_access(twl, 0)`; modify registers lacking `_clr`/`_set` aliases (`VBUS_DEBOUNCE`, `ID_DEBOUNCE`, `VBAT_TIMER`, `PHY_PWR_CTRL`, `PHY_CLK_CTRL`, `PHY_CLK_CTRL_STS`) via `twl4030_usb_read()`/`write()`/`write_verify()`, never `set_bits()`/`clear_bits()`. [F190, F202, F203, F267]
- In `uniphier_u3ssphy_set_param()` and `uniphier_pciephy_set_param()`, read-modify-write indirect registers by reading the current byte (`SSPHY_TESTO` masked with `TESTO_DAT_MASK`, or `uniphier_pciephy_testio_read(priv, id)` shifting by `TESTIO_PHY_SHIFT` when `id != 0`), clearing the mask, and ORing the field before `FIELD_PREP(TESTI_DAT_MASK, ...)`; follow every `writel` in `uniphier_pciephy`/`u3ssphy_testio_write()` with two dummy `readl`s from `PCL_PHY_TEST_O`/`SSPHY_TESTO`. [F191, F192, F273]
- In `phy-ti-pipe3.c`, `phy-omap-control.c`, and `phy-omap-usb2.c`: with `phy_power_syscon`, `ti_pipe3_power_on()` enables `TX_POWERON` then `TX_POWERON | RX_POWERON` in two writes for `SATA`/`USBSS`, but TX+RX together then `ti_pipe3_calibrate()` for `PCIE`; for SATA Errata i783, keep `refclk` enabled in `probe()`, skip DPLL reprogramming if `PLL_LOCK` is set in `init()`, and in `exit()` skip idling if `!dpll_reset_syscon` or pulse `SATA_PLL_SOFT_RESET` after idling; divide `clk_get_rate()` by `1000000` (to MHz) before shifting by `OMAP_CTRL_PIPE3_PHY_PWRCTL_CLK_FREQ_SHIFT` (22); use `time_after()`/`time_before()` in jiffies loops (`ti_pipe3_dpll_wait_lock()`, `ti_pipe3_exit()`, `twl4030_i2c_access()`); in `omap_usb2_probe()`, copy `phy->flags = phy_data->flags` before `omap_usb2_init_errata(phy)` sets `OMAP_USB2_DISABLE_CHRG_DET`. [F205, F240, F241, F263, F266]
- In `phy_gmii_sel_probe()` and `phy_gmii_sel_init_ports()`, set `priv->no_offset = true` when `priv->regmap` uses `regmap_init_mmio()`, and set `priv->reg_offset = __be32_to_cpu(*offset)` only when `!priv->no_offset`. In `serdes_am654_clk_mux_set_parent()`, decode all current parents from `serdes_am654_mux_table[val]`, replace `parents[mux->clk_id]`, and look up the new table row for `AM654_SERDES_CTRL_CLKSEL_MASK`. [F198, F216, F254]
- In `phy-j721e-wiz.c`: in `wiz_probe()`, skip `wiz_init(wiz)` if any lane has `P_ENABLE` or `P_ENABLE_FORCE` set in `wiz->p_enable[i]`; in `wiz_mode_select()`, place all `wiz->lane_phy_type[i]` branches before `else continue;` so configured lanes reach `regmap_field_write(wiz->p_standard_mode[i], mode)`; in `wiz_phy_en_refclk_register()`, size `clk_name` as `strlen(dev_name(dev)) + strlen(output_clk_names[TI_WIZ_PHY_EN_REFCLK]) + 2` for `"%s_%s"`. In `stm32_usbphyc_get_pll_params()`, cast `PLL_FVCO_MHZ` to `unsigned long long` before multiplying by `HZ_PER_MHZ` and `(1 << 16)`, and divide 64-bit `ndiv` and `frac` by `(clk_rate * 2)` using `do_div()`. [F225, F236, F237, F246, F260]
