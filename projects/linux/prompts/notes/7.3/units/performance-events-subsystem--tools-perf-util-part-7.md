# PERFORMANCE EVENTS SUBSYSTEM — tools/perf/util (part 7)

Provides core `perf` utilities (`tools/perf/util/`): machine modeling (`machine.c`), memory maps (`maps.c`, `map.c`), event/metric parsing (`parse-events.c`, `metricgroup.c`, `parse-branch-options.c`), mmap (`mmap.c`), ordered events (`ordered-events.c`), LLVM disassembly (`llvm.c`), lock contention (`lock-contention.c`), memory/NUMA (`mem-events.c`, `mem2node.c`), namespaces (`namespaces.c`), LZMA (`lzma.c`), and mutexes (`mutex.c`).

## Architecture & Data Flow
- Trailing `struct kmap` at `&RC_CHK_ACCESS(map)[1]` is allocated only by `map__new2()` and `map__clone()` when `dso__kernel(dso)` is true (`map__new()` allocates `sizeof(*map)`), so `__map__kmap()`/`map__kmap()` must check `dso && dso__kernel(dso)`. Every `maps.c` insertion into `maps_by_address` (`__maps__insert()`, `__maps__insert_sorted()`, `__maps__fixup_overlap_and_insert()`, `maps__copy_from()`) must call `map__set_kmap_maps()`. [F369, F378]
- When `__maps__insert()` sees `map__end(new) < map__start(new)` (setting `ends_broken = true`), `maps__fixup_end()` must run after all kernel/module/extra maps are added in `machine__create_kernel_maps()` or `machine__load_kallsyms()`. In `maps__remove_maps()` and `__maps__fixup_overlap_and_insert()`, do not increment loop index `i` on the `__maps__remove()` path because `memmove()` shifts subsequent entries down. [F383, F414]
- In `maps__set_module_path()`, when `m->comp && is_kmod_dso(dso)`, increment `dso__symtab_type(dso)` by 1 alongside `dso__set_comp(dso, m->comp)` to switch `DSO_BINARY_TYPE__SYSTEM_PATH_KMODULE` / `GUEST_KMODULE` to `*_COMP`. In `thread__resolve_callchain_sample()`, reject `branch->nr > PERF_MAX_BRANCH_DEPTH` (127) before calling `remove_loops()`, whose `unsigned char chash[CHASHSZ]` uses `NO_ENTRY` (`0xff`). [F385, F403]
- `ordered_events__queue()` rejects timestamps `0` and `~0ULL` (`-ETIME`). `__ordered_events__flush()` computes `OE_FLUSH__HALF` as `first->timestamp + (last->timestamp - first->timestamp) / 2` and reserves `ULLONG_MAX` for `FINAL`/`TOP`. In `do_flush()`, sample `oe->last->timestamp` into `last_ts` before `ordered_events__delete()`, then set `oe->last` to `NULL` if `oe->events` is empty or `list_entry(head->prev, struct ordered_event, list)` if `last_ts <= limit`. [F387, F432]
- In `parse-events.c`, `term->val` in `struct parse_events_term` is discriminated by `term->type_val` (`NUM` vs `STR`); check `term->type_val` before reading/freeing `term->val.str`. In `parse_events_add_pmu()`, deep-copy `const_parsed_terms` via `parse_events_terms__copy()` before `fix_raw(&parsed_terms, pmu)` (which must run before `config_attr()` and check `perf_pmu__have_event()` before hex-parsing `TERM_TYPE_RAW`), `config_attr()`, and `perf_pmu__check_alias()`. [F368, F391, F453]
- In `metricgroup.c`, terminate `metric_expr->metric_events` and `metric_refs` with a `NULL` sentinel for `metricgroup__copy_metric_events()`. `setup_metric_events()` must skip hybrid `evsel`s with `ev->pmu->name != pmu` when `!all_pmus`, putting only the first `evsel` per `metric_id` into `metric_events` and setting `ev->metric_leader = metric_events[i]` on duplicates. [F405, F456]
- In `resolve_metric()`, collect sub-metrics into `pending` during `hashmap__for_each_entry(root_metric->pctx->ids, ...)` and call `expr__del_id()` / `add_metric()` only after iteration. In `metricgroup__build_event_string()`, skip tool PMU events (`tool_pmu__str_to_event(id) != TOOL_PMU__EVENT_NONE`) during the `ctx->ids` loop and emit them after the closing `}:W` brace. [F394, F417]
- In `mem-events.c`, store global recording selection in `perf_mem_record[PERF_MEM_EVENTS__MAX]` (not per-PMU `struct perf_mem_event`) because `perf_pmu__mem_events_parse()` runs only on the first memory PMU while `perf_mem_events__record_args()` iterates all. Keep `PERF_MEM_LVLNUM_*`, `enum mem_stat_*`, `mem_lvlnum[]`, `mem_stat_index()`, and `mem_stat_name()` in sync. In `c2c_decode_stats()`, `mrem` is `data_src->mem_remote && !data_src->mem_hops`. [F389, F390, F422]
- In `mem2node__init()`, call `phys_entry__insert(&entries[i], &map->root)` only after `realloc(entries, sizeof(*entries) * j)` shrinks `entries`, so `realloc()` cannot relocate linked `rb_node`s. [F436]

## Synchronization
- When a `struct maps` reader (`maps__for_each_map`, `maps__find`, `maps__find_by_name`, `maps__find_next_entry`, `maps__merge_in`) sees `maps_by_address_sorted` or `maps_by_name_sorted` false under `down_read`, it must drop the read lock before sorting under `down_write` and re-check the flag after re-locking. `maps__find_next_entry()` must ensure `maps_by_address_sorted` before `maps__by_address_index(maps, map)` and pre-increment `++i < maps__nr_maps(maps)`. [F350, F397]
- In `maps__merge_in`, after upgrading from `down_read` to `down_write(maps__lock(kmaps))`, re-verify `maps__maps_by_address_sorted(kmaps)` and recompute `first_after_`, `kmaps_maps_by_address`, and `kmaps__nr_maps`. In `maps__find_by_name`, load `RC_CHK_ACCESS(maps)->last_search_by_name_idx` once into local `unsigned int i` under `down_read` and verify `i < maps__nr_maps(maps) && maps__maps_by_name(maps)` before indexing. [F351, F353]
- `maps__copy_from(dest, parent)` locks `dest` for write then `parent` for read; callers must ensure `!maps__equal(dest, parent)` and never reverse lock order. In `__machine__findnew_thread`, call `thread__init_maps(th, machine)` only after `threads__findnew` releases `table->lock`, and on failure call `threads__remove(&machine->threads, th)` before `thread__put`. [F349, F355]
- In `perf_mmap__aio_mmap`, initialize every `map->aio.cblocks[i].aio_fildes = -1` before publishing `map`, as `record__aio_sync` treats `aio_fildes != -1` as an active `aio_write`. [F358]

## Object Lifetimes
- `map_symbol__copy` and `addr_map_symbol__copy` call `maps__get`/`map__get` without releasing `dst`'s existing refs; call `map_symbol__exit` or `addr_map_symbol__exit` before overwriting an initialized `dst`. When `memcpy`ing `struct callchain_cursor_node` in `has_stitched_lbr` and `save_lbr_cursor_node`, get `ms.maps`/`ms.map` refs and call `map_symbol__exit` before overwriting `prev_lbr_cursor[idx]` or splicing `lbr_stitch->lists` to `free_lists`. [F330, F331]
- In `struct maps`, non-NULL `maps_by_name` holds an independent `struct map` ref per entry alongside `maps_by_address`; balance `map__get`/`map__put` on both arrays. `map__new`, `map__new2`, and `map__clone` take a `dso__get(dso)` ref (released in `map__exit` via `dso__zput`), whereas `map__set_kmap_maps` stores an un-refcounted `kmap->kmaps` backpointer. [F332, F335]
- In `machine__destroy_kernel_maps`, call `maps__remove(machine__kernel_maps(machine), map)` before freeing `kmap->ref_reloc_sym` and calling `map__zput(machine->vmlinux_map)`. [F360]
- In `ordered_events`, when `oe->copy_on_queue` is true, `alloc_event` `memdup`s `event` and adds `event->header.size` to `oe->cur_alloc_size`; every removal (`ordered_events__delete`), failure, and `ordered_events__free` must call `free_dup_event`/`__free_dup_event` and clear `event->event = NULL`. `ordered_events__free()` must unlink non-NULL `oe->buffer` from `oe->to_free` and free it with `max = oe->buffer_idx` before freeing full `oe->to_free` buffers with `MAX_SAMPLE_BUFFER`. [F341, F388]
- `metricgroup__lookup()` passes a stack `struct metric_event` to `rblist__add_node()`, so `metric_event_new()` must heap-allocate a copy and call `INIT_LIST_HEAD(&me->head)` after `memcpy()`. [F440]

## API Contracts
- `dso__set_nsinfo` takes ownership of `nsi` (putting old `dso->nsinfo` without `nsinfo__get(nsi)`). In `map__new`, lock `dso__lock(dso)` around `dso__set_nsinfo(dso, nsi)`, call `nsinfo__put(nsi)` only on `out_delete`, and for `is_vdso_map(filename)` pass an `nsinfo__copy` with `nsinfo__clear_need_setns`. `DECLARE_RC_STRUCT(nsinfo)` accessors (`nsinfo__in_pidns`, `nsinfo__need_setns`, `nsinfo__pid`, `nsinfo__tgid`, `nsinfo__nstgid`) must match member types (`bool` vs `pid_t`). [F336, F448, F464]
- `machine__findnew_thread`, `machine__find_thread`, `machine__idle_thread`, `machine__findnew_guest_code`, and `machines__findnew_guest_code` return a refcounted `struct thread *` that callers must release with `thread__put`. `machine__set_current_tid()` must pass `&init_val` (`const pid_t init_val = -1`) as `v` to `realloc_array_as_needed(machine->current_tid, ...)`. [F339, F447]
- `parse_events_error__handle` takes ownership of heap strings `str` and `help`; `parse_events__set_default_name` consumes heap string `name` (assigning, `strdup`ing, or `free`ing it). `config_term_common()` must reject `PARSE_EVENTS__TERM_TYPE_AUX_SAMPLE_SIZE` with `term->val.num > UINT_MAX` before copying into 32-bit `aux_sample_size`. [F344, F346, F429]
- `map__load(map)` must return `>= 0` before calling `map__map_ip()` for symbol lookup (`maps__find_symbol()`), `map__for_each_symbol()`, or `dso__data_write_cache_addr()` in `machine__process_text_poke()`. `map__new()` takes byte length `len` (passing `start + len` to `map__init()`), whereas `map__init()` and `map__set_end()` take exclusive `end`. In `__map__fprintf_dsoname()`, size `buf` at least `symbol_conf.pad_output_len_dso + 1` bytes for `scnprintf_pad()`. [F370, F371, F441, F477]
- `perf_mmap__push()` masks monotonic `md->core.start` and `end` with `md->core.mask`; when `(start & mask) + size != (end & mask)`, split the read at `mask + 1 - (start & mask)` bytes. `MMAP_CPU_MASK_BYTES(m)` must be `BITS_TO_LONGS(nbits) * sizeof(unsigned long)` for `bitmap_zalloc()` / `sched_setaffinity()`. [F400, F443]
- `mem_bswap_32()` and `mem_bswap_64()` take signed `int byte_size` (in bytes, padded to 4/8 bytes) and loop `while (byte_size > 0)`. `parse_filter()` and `exclude_perf()` cast `opt->value` to `struct evlist **`, whereas `parse_branch_stack()` casts `opt->value` to `__u64 *`. [F444, F446]

## Error Handling
- `lzma_is_compressed()` returns `bool` and must return `false` (never negative `rc`) when `open()` or `read()` fails. In `machine.c`, `add_callchain_ip()` and `resolve_lbr_callchain_sample()` return `1` on non-error conditions, so `resolve_lbr_callchain_sample()` and `thread__resolve_callchain_sample()` must clamp `(err < 0) ? err : 0`. [F361, F364]
- `nsinfo__mountns_enter()` must set `nc->oldns = -1` and `nc->newns = -1` before early returns and set `oldcwd`/`oldns`/`newns` only after `setns()` succeeds. `nsinfo__new()` returns `NULL` for `pid == 0`, but if `nsinfo__init(nsi)` fails (`-1`), it must call `nsinfo__clear_need_setns(nsi)` and return `nsi`. [F372, F373]
- `perf_mmap__push()` maps `-EAGAIN` from `perf_mmap__read_init()` to `1`, returning `0` when data was pushed and `-1` on other errors. `tracepoint_error()` accepts negative `PTR_ERR` and positive `errno`, so it must normalize `err = abs(err)`. `llvm__addr2line()` returns frame count `> 0` on success (`<= 0` on failure), whereas `symbol__disassemble_llvm()` returns `0` on success and `-1` or positive `errno` on failure. [F375, F376, F377]

## External Contracts
- `machine__process_text_poke()` reads replacement bytes from `event->text_poke.bytes + event->text_poke.old_len` (`new_len` bytes). When `machine__set_kernel_mmap()` gets `start == 0 && end == 0`, it must set `map__set_end(machine->vmlinux_map, ~0ULL)`. `machine__resolve_kernel_addr()` must keep signature `char *(void *vmachine, unsigned long long *addrp, char **modp)` for `tep_set_function_resolver()`. [F406, F407, F449]
- `namespaces__new()` must size and `memcpy` `namespaces->link_info` using `event->nr_namespaces` when `event` is non-NULL (`NR_NAMESPACES` only when NULL). `__perf_pmu__mem_events_init()` must skip entries with `e->tag == NULL` and check `perf_pmu__mem_events_supported()` in sysfs before setting `e->supported`. [F409, F459]
- `metric__group_events()` must return `false` for `MetricNoGroupEventsNmi` (and `MetricNoGroupEventsThresholdAndNmi` when `!metric_no_threshold`) if `sysctl__nmi_watchdog_enabled()`, and for `MetricNoGroupEventsSmt` if `smt_on()`. [F458]
- In `parse_events__sort_events_and_fix_groups` and `evsel__compute_group_pmu_name`, split groups with differing `group_pmu_name`, except software events and groups led by an AUX event (`evsel__is_aux_event(leader)`) adopt the group's non-software/AUX `group_pmu_name`. In `parse_events__modifier_list`, evaluate `!exclude_GH && exclude_GH_default` only after `user`/`kernel`/`hypervisor`/`guest`/`host` modifiers, reject `attr.precise_ip > 3` (`-EINVAL`), and set `pinned`/`exclusive` only on `evsel__is_group_leader(evsel)`. [F410, F473, F474]

## Known Pitfalls
- `maps__for_each_map` must reload `maps__nr_maps(maps)` and `maps__maps_by_address(maps)` every iteration because a callback may insert and `realloc` `maps_by_address` when `perf_singlethreaded`. `map__start_cmp()` and `map__addr_cmp()` must use relational operators returning `-1`/`0`/`1` on 64-bit addresses and `intptr_t`, never truncated `int` subtraction. [F354, F427]
- In `machine__get_running_kernel_start()`, look up `_edata` and `_etext` with `kallsyms__get_symbol_start()`, not `kallsyms__get_function_start()`. In `parse_events__decode_legacy_cache()`, `config_term_pmu()`, and `__parse_events_add_numeric()`, cast the 32-bit PMU type to `u64`/`__u64` before `<< PERF_PMU_TYPE_SHIFT` (32). [F412, F424]
- For `DECLARE_RC_STRUCT` types (`map`, `maps`, `nsinfo`, `mem_info`), allocate/copy using `sizeof(RC_STRUCT(<type>))` and `RC_CHK_ACCESS()`, not `sizeof(struct <type>)`. In `mmap_cpu_mask__scnprintf()`, allocate `MASK_SIZE + 1` bytes and set `buf[len] = '\0'` after `bitmap_scnprintf()`. [F434, F442]
