# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64) — arch/arm64

Host-side headers, UAPI definitions, and core host kernel implementation for KVM on arm64 (`arch/arm64/include/asm/kvm_*.h`, `arch/arm64/include/uapi/asm/kvm.h`, `arch/arm64/kvm/{arm,arch_timer,at,config,debug}.c`), managing VM/vCPU lifecycle, ioctls, guest sysregs/features, timer virtualization, nested Stage-1 `AT` emulation, and debug/trace state switching.

## Architecture & Data Flow
- In `vcpu->arch.iflags`, `INCREMENT_PC` (`BIT(1)`) overlaps `EXCEPT_MASK` (`GENMASK(3, 1)`), making `kvm_incr_pc()` and `kvm_pend_exception()` mutually exclusive; `kvm_arch_vcpu_ioctl_run()` must commit pending `PENDING_EXCEPTION` or `INCREMENT_PC` via `kvm_call_hyp(__kvm_adjust_pc, vcpu)` before `vcpu_put()`. [F69]
- In `enum vcpu_sysreg`, index `kvm_sysreg_masks::mask` by `r - __SANITISED_REG_START__` and `kvm_cpu_context::vncr_array` by `r - __VNCR_START__`. Declare every VNCR register after `MARKER(__VNCR_START__)` with `VNCR(r)` to bound `NR_SYS_REGS`, and keep `APIAKEYLO_EL1`..`APGAKEYHI_EL1` contiguous and ordered for `ptrauth_save_state`/`ptrauth_restore_state` (`PTRAUTH_REG_OFFSET`). [F77, F78, F121]
- `IDREG_IDX(id)` (`((sys_reg_CRm(id) - 1) << 3) | sys_reg_Op2(id)`) only indexes `kvm->arch.id_regs` (`KVM_ARM_ID_REG_NUM` = 56) for `1 <= crm < 8`; use `__vm_id_reg()` for `CRm == 0` (`MIDR_EL1`, `REVIDR_EL1`, `AIDR_EL1`) or `CTR_EL0`. Check guest VM helpers (`kvm_has_tcr2`, `kvm_has_s1pie`, `kvm_has_s1poe`, `kvm_has_fpmr`, `kvm_has_sctlr2`) before accessing optional Stage-1 registers (`SYS_TCR2`, `SYS_PIR`, `SYS_PIRE0`, `SYS_POR`, `SYS_POR_EL0`) or setting `HCRX_EL2` bits in `vcpu_set_hcrx()`. In `kvm_has_pauth()`/`kvm_has_full_ptr_auth()`, Pointer Auth requires `(pa + pi + pa3) == 1`. [F81, F108, F137]
- In `arch_timer.c`, `timer_restore_state()`/`timer_save_state()` require an `isb()` between writing `SYS_CNTV_CVAL`/`SYS_CNTP_CVAL` and enabling `CTL`, and between disabling `CTL` and zeroing `cntvoff`/`cntpoff`. For `TIMER_PTIMER`/`TIMER_HPTIMER` (and `CNTV_CVAL` when `has_broken_cntvoff()` is set for `ARM64_WORKAROUND_QCOM_ORYON_CNTVOFF`), `timer_restore_state()` zeros hardware `cntvoff` (when broken) or calls `set_cntpoff(offset)` and adds `timer_get_offset(ctx)` to `CVAL`, while `timer_save_state()` subtracts `timer_get_offset(ctx)` from `CVAL` and calls `set_cntpoff(0)`. [F61, F139, F140]
- `TIMER_REG_TVAL` is a 32-bit signed offset of `CVAL`: `kvm_arm_timer_read()` truncates deltas with `lower_32_bits()`, and `kvm_arm_timer_write()` sign-extends with `(s32)val`. Bound active timer loops (`kvm_timer_earliest_exp()`, `kvm_timer_vcpu_reset()`, `timer_irqs_are_valid()`, `kvm_arch_timer_get_input_level()`) by `nr_timers(vcpu)`, not `NR_KVM_TIMERS`. In `kvm_timer_sync_nested()` when `!cpus_have_final_cap(ARM64_HAS_ECV)`, resolve timers via `get_timer_map()` and cancel/re-emulate only `map.emul_vtimer` and `map.emul_ptimer`, never overwriting hardware EL1 timer registers with VNCR state. [F60, F89, F90]
- In Stage-1 `AT` walks: `setup_s1_walk()` restricts `wi->pgshift` to `{12, 14, 16}` and validates `wi->txsz` in `[12, 48]` before `GENMASK(ia_bits - 1, 0)` and `GENMASK(63, ia_bits)`; `check_output_size()` guards `GENMASK_ULL(51, wi->max_oa_bits)` with `wi->max_oa_bits < 52` (`wi->pa52bit`) and `GENMASK_ULL(47, wi->max_oa_bits)` with `wi->max_oa_bits < 48`; `walk_s1()` adds `contiguous_bit_shift(desc, wi, level)` to `va_bottom` when `PTE_CONT` is set. [F113, F114, F164]
- In `compute_s1_permissions()`, apply `pan` to `wr->pw` and `wr->pr` only after base, `compute_s1_hierarchical_permissions()`, `compute_s1_overlay_permissions()`, and WXN finalize `wr->ur`, `wr->uw`, and `wr->ux`. In `compute_par_s12()` when `HCR_EL2.FWB` is set and `s2_memattr` is Device memory (`MemAttr[2] == 0`), set `final_attr = min(s2_memattr_to_attr(s2_memattr), s1_parattr)`. [F95, F100]
- When `KVM_GUESTDBG_SINGLESTEP` is enabled, `kvm_vcpu_load_debug()` saves the guest's inverted `DBG_SPSR_SS` in `GUEST_SS_ACTIVE_PENDING` before setting `*vcpu_cpsr(vcpu)` from `HOST_SS_ACTIVE_PENDING`, and `kvm_vcpu_put_debug()` saves host step state and restores guest `DBG_SPSR_SS`. When `kvm_debug_handle_oslar()` updates `OSLSR_EL1_OSLK`, it must cycle `kvm_arch_vcpu_put()` and `kvm_arch_vcpu_load()` under `preempt_disable()`. [F64, F65]
- In `kvm_arch_vcpu_ioctl_vcpu_init()`, clear `BIT(KVM_ARM_VCPU_POWER_OFF)` from `init->features[0]` before `kvm_vcpu_set_target()`, and if `vcpu_has_run_once(vcpu)`, unmap Stage-2 or invalidate I-cache while `vcpu_reset_hcr()` preserves existing `vcpu->arch.hcr_el2` bits. In `kvm_arch_vcpu_ioctl()`, `KVM_{SET,GET}_ONE_REG` must flush pending `KVM_REQ_VCPU_RESET` via `kvm_reset_vcpu()` before `kvm_arm_{set,get}_reg()`. In `kvm_vcpu_wfi()`, set `IN_WFI` and call `kvm_vgic_put()` under `preempt_disable()` before `kvm_vcpu_halt()`, then clear `IN_WFIT`/`IN_WFI` and call `kvm_vgic_load()` under `preempt_disable()`. [F71, F72, F143]
- `push_hyp_memcache()`/`pop_hyp_memcache()` must keep `mc->nr_pages` synced with `mc->head`; `pop_hyp_memcache()` must check `!mc->nr_pages` first and mask `mc->head` with `PAGE_MASK` before `to_va()`. `__hyp_pgtable_max_pages()` and `hyp_ffa_proxy_pages()` must use `DIV_ROUND_UP`. [F15, F76, F116]
- Flush EL1-initialized nVHE data read by EL2 with MMU off (`kvm_init_params` in `cpu_prepare_hyp_mode()`, `.hyp.bss` in `kvm_hyp_init_symbols()`) via `kvm_flush_dcache_to_poc()`. In protected nVHE mode, save the hyp stack PA in `params->stack_pa` during `init_hyp_mode()` rather than using `__hyp_pa()`. EL2 extable entries (`_kvm_extable`, `__KVM_EXTABLE`, e.g., `__kvm_at`) require `x18` to hold the hyp SCS value and fixups to restore `SPSR_EL2` and `ELR_EL2`; `save_callee_saved_regs`/`restore_callee_saved_regs` must include `x18`, and `ctxt` passed to `restore_callee_saved_regs` must not be in `x18`–`x28`. [F160, F163, F165, F166]

## Synchronization
- Lock order is `kvm->lock` -> `vcpu->mutex` -> `kvm->arch.config_lock` (`kvm_arch_init_vm()`, `kvm_arch_vcpu_create()`). Hold `config_lock` in `__kvm_vcpu_set_target()` (for `KVM_ARCH_FLAG_VCPU_FEATURES_CONFIGURED`, `vcpu_features`, `kvm_setup_vcpu()`, `VCPU_INITIALIZED`) and when updating `kvm->arch.mpidr_data` via `rcu_assign_pointer()` (with `synchronize_rcu()` before freeing in `kvm_destroy_mpidr_data()`); `kvm_mpidr_to_vcpu()` reads `mpidr_data` under `rcu_read_lock()`/`rcu_dereference()`. [F21, F32, F154]
- In `kvm_arch_vcpu_ioctl_run()`, set `vcpu->mode = IN_GUEST_MODE` via `smp_store_mb()` after `local_irq_disable()` and before `kvm_vcpu_exit_request()`. Keep `kvm_arm_vcpu_enter_exit()` `noinstr` (`guest_state_{enter,exit}_irqoff()` enter an RCU extended quiescent state around `__kvm_vcpu_run`). On exit with IRQs disabled, run `kvm_pmu_sync_hwstate()`, then `kvm_vgic_sync_hwstate()`, then `kvm_timer_sync_user()` and `kvm_timer_sync_nested()`, before `local_irq_enable()`. [F19, F146, F156]
- `vcpu->arch.mp_state` writes require `vcpu->arch.mp_state_lock` and `WRITE_ONCE()`; lockless readers (`kvm_arm_vcpu_stopped()`, `kvm_arm_vcpu_suspended()`, `kvm_arch_vcpu_ioctl_get_mpstate()`) use `READ_ONCE()`. In `kvm_vcpu_sleep()`, run `smp_rmb()` after `rcuwait_wait_event()` sees `!kvm_arm_vcpu_stopped(vcpu)` to pair with `smp_wmb()` in `kvm_psci_vcpu_on()` before `check_vcpu_requests()`. [F22, F23]
- `vcpu->arch.{cflags,iflags,sflags}` use non-atomic RMW with preemption disabled (`__vcpu_set_flag`/`__vcpu_clear_flag`) and must only be mutated by the owning vCPU. In `vcpu_interrupt_line()`, modify `HCR_VI`/`HCR_VF` in `*vcpu_hcr(vcpu)` with `test_and_set_bit`/`test_and_clear_bit`, then `kvm_make_request(KVM_REQ_IRQ_PENDING, vcpu)` and `kvm_vcpu_kick(vcpu)`. [F24, F25]
- `timer_save_state()`/`timer_restore_state()` must use `local_irq_save()` across `ctx->loaded` and EL0 timer register accesses. In `kvm_arch_timer_handler()`, check `if (!vcpu)` and return `IRQ_HANDLED` before dereferencing `*dev_id`. [F27, F149]
- In `__kvm_at_s1e01_fast()` and `__kvm_at_s1e2()`, hardware `AT` must hold `write_lock_irqsave(&vcpu->kvm->mmu_lock)`, restore `HCR_HOST_VHE_FLAGS` into `HCR_EL2` before `__mmu_config_restore()`, and save/restore `SYS_PSTATE_PAN` in `at_s1e1p_fast()`. Software walks in `walk_s1()` (`handle_at_slow()`, `__kvm_translate_va()`, `__kvm_find_s1_desc_level()`) call `kvm_read_guest()` and require sleepable context under `srcu_read_lock(&vcpu->kvm->srcu)`. [F33, F70, F159]
- Pair every `kvm_pgtable_walk_begin(walker)` with `kvm_pgtable_walk_end(walker)`; never set `KVM_PGTABLE_WALK_SHARED` in hyp context (`__KVM_{NVHE,VHE}_HYPERVISOR__`, where RCU is unavailable and `kvm_pgtable_walk_begin()` returns `-EPERM`). When `is_protected_kvm_enabled()`, `kvm_fault_lock()`/`kvm_fault_unlock()` must take `kvm->mmu_lock` in exclusive write mode. [F14, F38, F158]
- Call `kvm_sys_regs_create_debugfs()` and `kvm_s2_ptdump_create_debugfs()` only from preemptible `kvm_arch_create_vm_debugfs()`, never `kvm_reset_vcpu()`. `kvm_arch_update_irqfd_routing()` runs under a spinlock and must only call `kvm_vgic_v4_unset_forwarding()`, never `kvm_vgic_v4_set_forwarding()` (which takes sleeping `its_lock`). [F147, F148]

## Object Lifetimes
- In `kvm_arch_vcpu_load()`: (1) when `!is_protected_kvm_enabled()` and `vcpu_has_nv(vcpu)`, call `kvm_vcpu_load_hw_mmu()` before reading `vcpu->arch.hw_mmu` (and in `kvm_arch_vcpu_put()`, call `kvm_vcpu_put_hw_mmu()` after `kvm_vcpu_put_vhe()`); (2) call `kvm_arm_vmid_update(&mmu->vmid)` before programming `VTTBR_EL2` (`kvm_vcpu_load_vhe()`), then in non-pKVM mode if `*this_cpu_ptr(mmu->last_vcpu_ran) != vcpu->vcpu_idx`, call `kvm_call_hyp(__kvm_flush_cpu_context, mmu)` and update `*last_ran`; (3) call `kvm_vcpu_load_debug()` before `kvm_vcpu_load_vhe()` (sets `SYSREGS_ON_CPU`); (4) call `kvm_timer_vcpu_load()` before `kvm_vgic_load()` (`kvm_timer_vcpu_load_nested_switch()`). [F7, F8, F16, F74, F155]
- In `kvm_timer_vcpu_put()`, save direct timers (`timer_save_state()`), cancel emulated hrtimers (`soft_timer_cancel()`), and if `kvm_vcpu_is_blocking(vcpu)`, arm `timer->bg_timer` via `kvm_timer_blocking()` (canceled in `kvm_timer_vcpu_load()` and `kvm_timer_vcpu_terminate()`). [F144]
- When `is_protected_kvm_enabled()`, `cpu_hyp_uninit()` must not call `cpu_hyp_reset()` or clear `kvm_hyp_initialized`, and `teardown_hyp_mode()` must not free `kvm_arm_hyp_stack_base`, `sve_state`, or `kvm_arm_hyp_percpu_base` when `per_cpu(kvm_hyp_initialized, cpu)` is set. In `hyp_init_cpu_pm_notifier()`, `CPU_PM_ENTER` calls `cpu_hyp_reset()` without clearing `kvm_hyp_initialized` so `CPU_PM_ENTER_FAILED`/`CPU_PM_EXIT` can call `cpu_hyp_reinit()`. Call `finalize_init_hyp_mode()` in `kvm_arm_init()` only after all fallible steps (`kvm_init()`) succeed, as it overwrites `sve_state` in-place with `kern_hyp_va(sve_state)`. [F1, F41, F75]

## API Contracts
- `__vcpu_sys_reg()`, `__vcpu_assign_sys_reg()`, `__vcpu_rmw_sys_reg()`, and `ctxt_sys_reg()` only access memory (`sys_regs`/`vncr_array`); use `vcpu_{read,write}_sys_reg()` whenever a register may be live on the CPU (`SYSREGS_ON_CPU`). Pass only `0..31` (`31` = `XZR`) to `vcpu_{get,set}_reg()`. In `kvm_arm_timer_{read,write}_sysreg()`, bracket direct timer accesses with `timer_save_state()`/`timer_restore_state()` under `preempt_disable()`, and wrap emulated timer writes with `soft_timer_cancel()`/`timer_emulate()`. [F62, F66, F83]
- `kvm_vcpu_exit_request(vcpu, &ret)` leaves `*ret` unmodified when exiting to kernel context to handle work and re-enter, so initialize `ret > 0` first. Before `__kvm_translate_va(vcpu, wi, wr, va)`, set `wi->{regime,as_el0,pan}` and zero the rest of `*wi` and `*wr`; check `!wr->failed` (and `wr->level != S1_MMU_DISABLED`) before reading `wr->{desc,pa,level}` from `s1_walk_result`. [F44, F46, F47]
- `kvm_vcpu_get_fault_ipa()` returns `INVALID_GPA` when `HPFAR_EL2_NS` is clear, and `FIELD_GET(HPFAR_EL2_FIPA, hpfar) << 12` (without the sub-4KB offset) otherwise. For Stage-2 write fault classification (`kvm_is_write_fault()`), check `kvm_vcpu_abt_iss1tw(vcpu)` before `kvm_vcpu_trap_is_iabt()` and `kvm_vcpu_dabt_iswrite()`, and for `S1PTW` faults only treat permission faults (`kvm_vcpu_trap_is_permission_fault()`) as writes. [F55, F98]
- In `kvm_arch_alloc_vm()`, use `kzalloc()` rather than `__vmalloc()` when `!has_vhe()` so `kvm_share_hyp(kvm, kvm + 1)` gets physically contiguous linear memory. `kvm_init_mpidr_data()` must cap `struct_size(data, cmpidr_to_idx, nr_entries) <= PAGE_SIZE`; `kvm_mpidr_index()` must copy `u64` `mpidr_mask` and `mpidr & MPIDR_HWID_BITMASK` to local `unsigned long`s for `bitmap_gather()`, and `kvm_mpidr_to_vcpu()` must verify `mpidr == kvm_vcpu_get_mpidr_aff(vcpu)`. [F86, F129, F170]
- Call `kvm_{enable,disable}_trbe()` and `kvm_tracing_set_el1_configuration()` with preemption disabled and guard `kvm_host_data` with `skip_trbe_access()`. `kvm_pgtable_stage2_wrprotect()` and `kvm_pgtable_stage2_test_clear_young()` do not invalidate TLBs; callers must invalidate Stage-2 TLBs afterwards. [F186, F187]

## Error Handling
- In `kvm_arch_vcpu_create()`, call `kvm_vgic_vcpu_destroy()` (and `kvm_unshare_hyp()`) if steps after `kvm_vgic_vcpu_init()` fail. In `kvm_timer_hyp_init()`, free `host_ptimer_irq` and `host_vtimer_irq` via `free_percpu_irq(..., kvm_get_running_vcpus())` on later errors. [F6, F134]
- In `kvm_arch_irq_bypass_{add,del}_producer()` and `kvm_arch_update_irqfd_routing()`, check `irq_entry->type == KVM_IRQ_ROUTING_MSI` before reading `irq_entry->msi` or calling `kvm_vgic_v4_{set,unset}_forwarding()`. Null-check `map.{direct_ptimer,emul_vtimer,emul_ptimer}` from `get_timer_map()` when `!vcpu_has_nv(vcpu)` is possible. On `vcpu_mode_is_bad_32bit(vcpu)`, `kvm_arch_vcpu_ioctl_run()` must clear `VCPU_INITIALIZED` and return `ARM_EXCEPTION_IL` without host `WARN_ON`/`BUG_ON`. [F42, F43, F176]

## External Contracts
- `KVM_REG_ARM_TIMER_CVAL` and `KVM_REG_ARM_TIMER_CNT` have swapped `(CRm, Op2)` encodings in UAPI, so match them explicitly rather than decoding `SYS_CNTV_CVAL_EL0`/`SYS_CNTVCT_EL0`. `KVM_ARM_FEATURE_ID_RANGE_IDX` maps `Op1` `{0, 1, 3}` to `{0, 1, 2}` via `__op1 -= (__op1 == 3)` to fit `KVM_ARM_FEATURE_ID_RANGE_SIZE` (192). [F49, F82]
- `kvm_vcpu_init_check_features()` returns `-ENOENT` for bits outside `KVM_VCPU_VALID_FEATURES` or non-zero `init->features[1..6]`, and `-EINVAL` if unsupported by `system_supported_vcpu_features()`. `kvm_arch_vcpu_ioctl()` (`KVM_{SET,GET}_ONE_REG`, `KVM_GET_REG_LIST`, `KVM_ARM_VCPU_FINALIZE`) and `kvm_arch_vcpu_run_pid_change()` return `-ENOEXEC` if `!kvm_vcpu_initialized(vcpu)`, and `KVM_GET_REG_LIST`/`kvm_arch_vcpu_run_pid_change()` return `-EPERM` if `!kvm_arm_vcpu_is_finalized(vcpu)`. [F87, F180]
- `kvm_arm_vcpu_get_events()` must zero `struct kvm_vcpu_events`, and `kvm_arm_vcpu_set_events()` must reject non-zero `reserved` or `exception.pad` (`-EINVAL`). `kvm_vm_ioctl_set_counter_offset()` must reject non-zero `offset->reserved` (`-EINVAL`), hold `kvm->lock`, and use `kvm_trylock_all_vcpus(kvm)` (`-EBUSY`). [F179, F184]

## Known Pitfalls
- In `idreg_feat_match()` and `kvm_cmp_feat()`, sign-extend signed ID fields (`sign_extend64()`) so `0b1111` (-1) < 0, and keep the comparison inside `kvm_cmp_feat_{signed,unsigned}()` to avoid ternary unsigned promotion. In `timer_set_traps()`, pass `(set, clr)` to `assign_clear_set_bit()` for negative-polarity enable bits (`CNTHCTL_EL1PCEN << 10`, `CNTHCTL_EL1PCTEN << 10`) and `(clr, set)` for positive-polarity trap bits. [F93, F103, F109]
- Cast 32-bit masks (`TCR_EL2_PS_MASK`, `(1 << size) - 1`) to `u64` before shifting into bits `>= 32` (`tcr_el2_ps_to_tcr_el1_ips()`, `VTTBR_VMID_MASK()`). In `cpu_prepare_hyp_mode()`, apply `TCR_EL2_MASK`, `TCR_EL2_RES1`, `TCR_EL2_PS_MASK`, and `TCR_EL2_DS` only when `!cpus_have_final_cap(ARM64_KVM_HVHE)`. [F111, F136]
- `per_cpu_ptr_nvhe_sym(sym, cpu)` must cast `&CHOOSE_NVHE_SYM(sym)` and `&CHOOSE_NVHE_SYM(__per_cpu_start)` to `unsigned long` before subtracting and adding `kvm_arm_hyp_percpu_base[cpu]`. Use `kvm_s2_mmu_to_kvm(mmu)` (`container_of` on `mmu->arch`), never `container_of(mmu, struct kvm, arch.mmu)`. Copy `init->features[0]` (`__u32[7]`) to a local `unsigned long` before passing its address to bitmap/bitops helpers. [F122, F126, F127]
