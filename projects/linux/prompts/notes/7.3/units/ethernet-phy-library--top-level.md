# ETHERNET PHY LIBRARY — (top level)

This unit contains the SFP cage state machine and bus infrastructure (`sfp.c`, `sfp-bus.c`, `sfp.h`), Realtek, SMSC, Vitesse, STE10Xp, Teranetics, uPD60620, and Xilinx GMII2RGMII PHY drivers, software PHY emulation (`swphy.c`), OpenFirmware network helpers (`net/core/of_net.c`), and core phylib/MDIO/MII headers.

## Architecture & Data Flow
- In `sfp-bus.c`, socket-to-upstream helpers must fetch `upstream_ops` via `sfp_get_upstream_ops(bus)` and null-check callbacks; `sfp_upstream_start()`, `sfp_upstream_stop()`, and `sfp_upstream_set_signal_rate()` must check `bus->registered` before dereferencing `bus->socket_ops`, but `start`/`stop` must always update `bus->started` so `sfp_register_bus()` / `sfp_unregister_bus()` can invoke `socket_ops->start()` or `stop()`. [F544, F572]
- In `__sfp_sm_event()`, call `sfp_sm_device()`, `sfp_sm_module()`, then `sfp_sm_main()` in order. Adding any `SFP_MOD_*`, `SFP_DEV_*`, `SFP_E_*`, or `SFP_S_*` enum requires updating `mod_state_strings[]`, `dev_state_strings[]`, `event_strings[]`, or `sm_state_strings[]`. In `sfp_sm_mod_probe()` and `sfp_sm_module()`, reset per-module fields (`i2c_block_size`, `module_t_start_up`, `module_t_wait`, `phy_t_retry`, `state_ignore_mask`, `state_hw_mask`) before `sfp->quirk->fixup(sfp)` and schedule `sfp->poll` after updating `state_hw_mask`. [F570, F578, F597]
- In `sfp_check_state()`, OR `sfp->state & SFP_F_OUTPUTS` (`SFP_F_TX_DISABLE | SFP_F_RS0 | SFP_F_RS1`) into `sfp_get_state(sfp)` before assigning `sfp->state`. In `sfp_gpio_set_state()`, output GPIOs (`GPIO_TX_DISABLE`, `GPIO_RS0`, `GPIO_RS1`, requested with `GPIOD_ASIS`) use `gpiod_direction_output()` only when `state & SFP_F_PRESENT` and their `sfp->state_hw_drive` bit are set; otherwise use `gpiod_direction_input()`. [F569, F642]
- `sfp_i2c_read()` must split transfers into chunks <= `sfp->i2c_block_size` (<= `SFP_EEPROM_BLOCK_SIZE`). `sfp_hwmon_probe()` must not register hwmon when `sfp->i2c_block_size < 2` (16-bit registers in `sfp_diag` and page `0x51` require atomic 2-byte reads). In `sfp_sm_link_check_los()`, `sfp_los_event_active()`, and `sfp_los_event_inactive()`, mask `sfp->id.ext.options` with `los_inverted | los_normal` and compare for equality against a single flag (not bitwise AND). [F582, F583, F593]
- Generic MDIO lookups (`fwnode_mdio_find_device()`, `mdiobus_find_device()`) must check `mdiodev->flags & MDIO_DEVICE_FLAG_PHY` before `to_phy_device()`. In `struct phy_device_node`, check `upstream_type` before reading the `upstream` union. In `include/linux/phy.h`, new `PHY_INTERFACE_MODE_*` enums need `phy_modes()` entries; new negative IRQ sentinels (`PHY_POLL`, `PHY_MAC_INTERRUPT`) need `phy_interrupt_is_valid()` updates; in `struct mdio_bus_stats`, all counters must be `u64_stats_t` above `struct u64_stats_sync syncp` (last). [F547, F575, F576, F618, F624]
- In `smsc.c`, `smsc_phy_config_init()`, `lan87xx_read_status()`, `smsc_phy_get_edpd()`, and `smsc_phy_set_edpd()` must null-check `phydev->priv`. When `phydev->irq != PHY_POLL`, EDPD defaults to disabled and `smsc_phy_set_edpd()` rejects values other than `ETHTOOL_PHY_EDPD_DISABLE` / `ETHTOOL_PHY_EDPD_NO_TX` (`-EOPNOTSUPP`). `smsc_phy_set_edpd()` must validate non-special values in `[PHY_STATE_MACH_MS, PHY_STATE_MACH_MS + 1000]` before subtracting `PHY_STATE_MACH_MS` and set `priv->edpd_mode_set_by_user = true` so `smsc_phy_config_init()` preserves user EDPD state. [F549, F564, F614, F630]
- In `lan87xx_phy_config_init()` and `lan87xx_config_aneg()`, always set `SPECIAL_CTRL_STS_OVRRD_AMDIX_`. Pair enabling Auto-MDIX in `lan87xx_phy_config_init()` with `phydev->mdix_ctrl = ETH_TP_MDI_AUTO`. When `phydev->autoneg == AUTONEG_DISABLE` and `phydev->mdix_ctrl == ETH_TP_MDI_AUTO`, `lan87xx_config_aneg()` must force `ETH_TP_MDI` in hardware and `phydev->mdix` without overwriting `phydev->mdix_ctrl`. `lan874x_set_wol()` must reject `WAKE_ARP | WAKE_MCAST` and update `priv->wol_arp` for `lan874x_get_wol()`. [F562, F563, F565, F629]
- In `realtek/`, `rtl8211f_probe()` may only set wakeup capable / wake IRQ when both `"wakeup-source"` and `phy_interrupt_is_valid(phydev)` hold. `rtl8211f_config_intr()` must cache the mask in `priv->iner` so `rtl8211f_resume()` restores `RTL821x_INER` after `rtl8211f_suspend()` writes `RTL8211F_INER_PME`. `rtl8211f_led_hw_control_set()` and `rtl8211e_led_hw_control_set()` must use paged RMW (`phy_modify_paged()` / `rtl821x_modify_ext_page()`) and preserve `RTL8211F_LEDCR_MODE`. `rtl822x_hwmon_get_temp()` must mask `raw` to 10 bits and sign-extend (`if (raw >= 512) raw -= 1024;`) before scaling. [F566, F567, F592, F633]
- In `xgmiitorgmii_probe()`, save `priv->phy_dev->drv` in `priv->phy_drv`, copy it to `priv->conv_phy_drv` to override `.read_status`/`.set_loopback`, point `priv->phy_dev->drv` at `&priv->conv_phy_drv`, store `priv` on `&priv->phy_dev->mdio` (not `mdiodev`), and delegate via `priv->phy_drv`. In `swphy.c`, every `speed[]` entry must set both duplex bits and every `duplex[]` entry must set all speed bits. [F568, F574, F602]

## Synchronization
- In `sfp.c`, lock order is `rtnl_lock` -> `sfp->sm_mutex` -> `sfp->st_mutex`. `sfp_sm_event()` / `__sfp_sm_event()` require `rtnl_lock` and `sfp->sm_mutex`. `sfp_get_state()`, `sfp_set_state()`, and post-probe updates to `state_hw_drive`, `state_hw_mask`, `state_soft_mask`, and `sfp->state` output bits require `sfp->st_mutex`. Never call `cancel_delayed_work_sync()` on `sfp->timeout` or `sfp->poll` under `rtnl_lock` or `sfp->sm_mutex`; `sfp_sm_set_timer()` must use `cancel_delayed_work()`. [F527, F650, F651]
- In `sfp-bus.c`, `sfp_bus_add_upstream()`, `sfp_bus_del_upstream()`, `sfp_register_socket()`, and `sfp_unregister_socket()` must modify bus pointers and `registered` under `rtnl_lock()`. `sfp_get_name()` requires `rtnl_lock` and returns a pointer valid only until `rtnl_unlock()`. [F514, F532]
- Unlocked helpers (`__phy_read()`, `__phy_write()`, `__phy_modify()`, `__mdiobus_c45_read()`, `__mdiobus_c45_write()`) and `.read_page`/`.write_page`/`.read_mmd`/`.write_mmd` require `phydev->mdio.bus->mdio_lock` and must not call locking `phy_read()`/`phy_write()`. In `phylib_stubs.h`, stub wrappers require `rtnl_lock` (`ASSERT_RTNL()`) and must update `#if IS_ENABLED(CONFIG_PHYLIB)` and `#else` blocks together. [F533, F577, F656]

## Object Lifetimes
- In `sfp_bus_find_fwnode()`, put `ref.fwnode` via `fwnode_handle_put()` on both the unavailable return and after `sfp_bus_get()`; callers release the returned `sfp_bus` via `sfp_bus_put()`. If `sfp_register_bus()` fails in `sfp_bus_add_upstream()` or `sfp_register_socket()`, call `sfp_upstream_clear()` / `sfp_socket_clear()` under `rtnl_lock()` and `sfp_bus_put()` after `rtnl_unlock()`. `sfp_unregister_bus()` tears down in reverse order: `upstream_ops->detach`, `socket_ops->stop` (if `started`), `socket_ops->detach`, `ops->disconnect_phy`, and clearing `registered`. [F511, F512, F513]
- `sfp_sm_probe_phy()` rolls back `sfp_add_phy()` failure with `phy_device_remove()` then `phy_device_free()`. Exiting an active state in `sfp_sm_main()` must call `sfp_sm_phy_detach()` (`sfp_remove_phy()`, `phy_device_remove()`, `phy_device_free()`, `sfp->mod_phy = NULL`) before `sfp_i2c_mdiobus_destroy()` (`sfp->i2c_mii = NULL`). [F515, F516]
- In `sfp_sm_module()`, `SFP_E_REMOVE` must unconditionally call `sfp_sm_mod_remove()` so `sfp_hwmon_remove()` always runs, while `sfp_sm_mod_remove()` calls `sfp_module_remove()` only when `sm_mod_state > SFP_MOD_WAITDEV` (and `SFP_MOD_HPOWER` calls `sfp_module_remove()` before `SFP_MOD_ERROR`). `sfp_hwmon_remove()` must call `cancel_delayed_work_sync(&sfp->hwmon_probe)` before checking `!IS_ERR_OR_NULL(sfp->hwmon_dev)`, unregistering it, clearing `sfp->hwmon_dev = NULL`, and freeing `sfp->hwmon_name`. [F517, F518]
- In `sfp_probe()`, register `devm_add_action_or_reset(sfp->dev, sfp_cleanup, sfp)` before `devm_request_threaded_irq()`, and sanitize teardown-inspected fields on failure: set `sfp->gpio_irq[i] = 0` on IRQ failure, check `!IS_ERR_OR_NULL(sfp->hwmon_dev)` in `sfp_hwmon_remove()`, and on `sfp_i2c_configure()` failure set `sfp->i2c = NULL` while calling `i2c_put_adapter(i2c)` and `fwnode_handle_put(h)` in `sfp_i2c_get()`. [F519, F551, F640]
- In `of_get_mac_address_nvmem()`, release `pdev` (`put_device()`), `cell` (`nvmem_cell_put()`), and `mac` (`kfree()`). In `xgmiitorgmii_probe()`, call `of_node_put(phy_node)` after `of_phy_find_device()`, and `put_device(&priv->phy_dev->mdio.dev)` if `!priv->phy_dev->drv` or probe fails. In `rtl821x_suspend()` / `rtl821x_resume()`, disable `priv->clk` only when `!phydev->wol_enabled` and `genphy_suspend()` succeeds, and re-enable in resume only when `!phydev->wol_enabled`. [F520, F521, F523]

## API Contracts
- `sfp_bus_find_fwnode()` returns `struct sfp_bus *`, `NULL` when optional/unavailable (`-ENOENT`), or `ERR_PTR`. `sfp_register_socket()` returns `NULL` on failure; `sfp_alloc()` returns `ERR_PTR`. `sfp_register_bus()` / `sfp_unregister_bus()` require non-NULL `attach`/`detach` (and socket `start`/`stop`). `sfp_get_module_info()`, `sfp_get_module_eeprom()`, and `sfp_get_module_eeprom_by_page()` require a registered socket and buffer >= `ee->len`. `sfp_upstream_set_signal_rate()` takes `rate_kbd` in kBd. `sfp_select_interface()` orders predicates from highest to lowest speed with `1000baseT` (`SGMII`) before `1000baseX`. [F537, F538, F595, F657, F658, F660]
- `phy_read*()` and `mdiobus_read*()` return `0..0xffff` as `int` or `< 0` on error (check `< 0` before narrowing to `u16`). `*phy_modify*_changed()` return `< 0` on error, `0` if unchanged, and `1` if changed (check `ret < 0`, never `if (ret)`). `swphy_read_reg()` returns `-1` for `reg > MII_REGS_NUM`, `MII_MMD_CTRL`, or `MII_MMD_DATA`, `0xffff` for unimplemented MII registers, and `0` with `WARN_ON` if `state->speed` is invalid (even when `state->link == 0`). [F540, F541, F542, F667]
- In `struct phy_driver`, do not set both `features` and `get_features` (only set `phydev->supported`), do not mutate `phydev` in `link_change_notify`, and in `led_blink_set` use ms delays (defaulting when both 0 and writing back actual timings). `phy_disable_eee_mode()` requires `phydev->state < PHY_UP`. `get_phy_stats`/`get_link_stats` only overwrite supported fields (pre-filled with `ETHTOOL_STAT_NOT_SET`); `get_stats` (`smsc_get_stat()`) stores `U64_MAX` on error. [F555, F662, F663, F664]
- In `struct phy_plca_cfg`, `-1` is the unset sentinel. `mii_c73_mod_linkmode()` requires `lpa` to have >= 3 `u16` elements. Downcast macros (`to_mdio_device`, `to_phy_device`, etc.) must use `container_of_const()`. Call `free_mdio_bitbang()` only after `mdiobus_unregister()`. `!CONFIG_OF_MDIO` / `!CONFIG_ACPI_MDIO` stubs for `of_mdiobus_register()`, `devm_of_mdiobus_register()`, and `acpi_mdiobus_register()` must fall back to `mdiobus_register()`. `of_get_phy_mode()` sets `*interface = PHY_INTERFACE_MODE_NA` on error; `of_get_mac_addr()` / `of_get_mac_address_nvmem()` check `length == ETH_ALEN` and `is_valid_ether_addr()`, and `of_get_ethdev_address()` only updates `dev` on `0`. [F536, F553, F556, F580, F617, F625, F675]
- In `realtek_main.c`, `RTL822X_VND2_C22_REG(reg)` is for C45 PHYs (`phydev->is_c45`), while `rtlgen_read_vend2()`/`rtlgen_write_vend2()` hardcode PHY address `0`. `rtl8211x_led_hw_is_supported()` and RTL8211E/F LED callbacks reject `index >= RTL8211x_LED_COUNT` (3) (`-EINVAL`) and require `TRIGGER_NETDEV_RX` and `TRIGGER_NETDEV_TX` to be both set or both clear (`-EOPNOTSUPP`). `vsc73xx_get_downshift()` adds `2` to `MII_VSC73XX_PHY_CTRL_EXT3_DOWNSHIFT_CNT`, and `vsc73xx_set_downshift()` rejects `cnt == 1` (`-EINVAL`) and `cnt > 5` (`-E2BIG`) before subtracting `2`. `xgene_enet_set_field_value()`/`xgene_enet_get_field_value()` require `1ULL << len` with `len` in `[1, 63]` and `pos + len <= 64`. [F560, F561, F615, F672]

## Error Handling
- Pair every `phy_save_page()` or `phy_select_page()` with `phy_restore_page(phydev, oldpage, ret)` even when `oldpage < 0`. In `read_poll_timeout()` loops on `phy_read*()` (`phy_read_poll_timeout()`, `lan87xx_read_status()`), include `val < 0` in the break condition and check `val < 0` afterward. [F550, F608]
- In `sfp_sm_mod_probe()`, a base checksum mismatch (`cc_base`) on non-Cotsworks modules aborts with `-EINVAL`, whereas an extended mismatch (`cc_ext`) zeroes `id.ext` and continues; `sfp_init_module()` must zero `bus->caps` before parsing. `sfp_check()` on `id.base` or `id.ext` must use `sizeof(...) - 1`, and `sfp_cotsworks_fixup_check()` must recompute and write `SFP_CC_BASE` after modifying `id->base`. [F554, F573, F620]

## External Contracts
- In `sfp.c`, 16-bit fields in `sfp->id.ext.options` and `struct sfp_diag` are `__be16`. In `sfp_hwmon_calibrate_temp()`, sign-extend `if (*value >= 0x8000) *value -= 0x10000;` after `sfp_hwmon_calibrate()` and before `DIV_ROUND_CLOSEST(*value * 1000, 256)` with a signed divisor. [F584, F610]
- `sfp_module_eeprom()` and `sfp_module_eeprom_by_page()` return `-ENODEV` when `!(sfp->state & SFP_F_PRESENT)`. `sfp_module_eeprom()` maps `[0, ETH_MODULE_SFF_8079_LEN)` to `0x50` (`a2 = false`) and `[ETH_MODULE_SFF_8079_LEN, ETH_MODULE_SFF_8472_LEN)` to `0x51` (`a2 = true`), subtracting `ETH_MODULE_SFF_8079_LEN` from the second region's offset. `sfp_module_eeprom_by_page()` rejects non-zero `bank`/`page` or `i2c_address` not in `{0x50, 0x51}` (`-EOPNOTSUPP`). [F585, F670]
- In `sfp_module_parse_support()`, when `id->base.br_nominal == 255` and `id->ext.br_max` is non-zero, decode nominal bitrate as `250 * id->ext.br_max` and scale tolerances using `id->ext.br_min` (`br_nom * id->ext.br_min / 100`). `mdio_phy_id_is_c45()` must check both `(phy_id & MDIO_PHY_ID_C45)` and `!(phy_id & ~MDIO_PHY_ID_C45_MASK)` (`0x83ff`). [F590, F612]

## Known Pitfalls
- `linkmode_*_bit()`, `phy_disable_eee_mode()`, and `phy_remove_link_mode()` take a bit index (`ETHTOOL_LINK_MODE_*_BIT`), whereas `phy_set_bits()`, `phy_clear_bits()`, `phy_modify()`, and `ethtool_adv_to_*()` take shifted masks. `DECLARE_PHY_INTERFACE_MASK` bitmaps must only use `phy_interface_*` helpers, never `linkmode_*` or `phylink_set()`. `mdiobb_read_c45()` and `mdiobb_write_c45()` take `(bus, int phy, int devad, int reg, ...)` despite swapped parameter names in `mdio-bitbang.h`. [F557, F558, F621]
- In `sfp.c`, bound non-NUL-terminated `struct sfp_eeprom_id` ASCII strings with `sfp_strlen(..., ARRAY_SIZE(...))` or `%.*s`. In `sfp_module_parse_rate_select()`, convert `rate_id == 3` to `SFF_RID_8431` before checking `rate_id & SFF_RID_8079`. In `sfp_module_parse_support()` / `sfp_init_module()`, run `if (linkmode_empty(modes) && br_nom)` before setting `Autoneg`/`Pause`/`FIBRE`/`TP`. In `sfp_sm_main()`, set `sfp->sm_phy_retries = R_PHY_RETRY` before jumping to `phy_probe`, and in `SFP_S_WAIT` check `timeout > sfp->module_t_wait` before subtracting `module_t_wait` (clamping to `1`). [F581, F594, F596, F599, F609]
- In `lan874x_chk_wol_pattern()`, the inner loop must `break` on `if (!len)` to avoid `u8` underflow. In `vsc82xx_config_intr()`, read `MII_VSC8244_ISTAT` to ACK interrupts before writing `0` to `MII_VSC8244_IMASK`. On Realtek internal PHYs, C22 MMD reads return 0, so `rtl8226_match_phy_device()`, `rtl8221b_match_phy_device()`, and `rtl_internal_nbaset_match_phy_device()` must check `rtlgen_supports_mmd()`, and `rtlgen_read_mmd()`/`rtl822x_read_mmd()` must redirect to `__mdiobus_c45_read` at address 0. [F607, F628, F635]
