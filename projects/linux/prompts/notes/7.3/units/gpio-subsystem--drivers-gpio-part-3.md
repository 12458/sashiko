# GPIO SUBSYSTEM — drivers/gpio (part 3)

This unit covers GPIO controller drivers from `gpio-sim.c` to `gpio-xgs-iproc.c`, including `gpio-sim.c`, `gpio-virtuser.c`, NVIDIA Tegra (`gpio-tegra.c`, `gpio-tegra186.c`), Super I/O (`gpio-winbond.c`), USB bridges (`gpio-viperboard.c`), and PMIC/MFD expanders (TPS65xxx, TWL4030/6040, WM8xxx, STMPE, TC3589x).

## Architecture & Data Flow
- In `gpio-sim.c`, `gpio_sim_free()` must restore `chip->value_map` from `chip->pull_map` when clearing `chip->request_map` under `chip->lock`. In `gpio_sim_apply_pull()`, `chip->value_map` is updated at `set_value:` only if unrequested or input (`!test_bit(offset, chip->request_map) || test_bit(offset, chip->direction_map)`), while `chip->pull_map` is always updated at `set_pull:` (including on `irq_set_irqchip_state()` error). [F234, F270]
- In `gpio-sim.c`, `gpio_sim_bank_config_make_line_group()` accepts any unsigned `line<offset>`, so `gpio_sim_get_line_names_size()`, `gpio_sim_set_line_names()`, and `gpio_sim_add_hogs()` must skip `line->offset >= bank->num_lines`. When `!gpio_sim_bank_has_label(bank)`, `gpio_sim_add_hogs()` and `gpio_sim_add_bank()` must format fallback labels identically as `"gpio-sim.%u:%pfwP"` (`"%s:%pfwP"` with `dev_name(dev)`, `swnode`). [F235, F254]
- In `gpio_sim_make_bank_swnode()`, `properties` has `GPIO_SIM_PROP_MAX` (5) zeroed entries (max `GPIO_SIM_PROP_MAX - 1` properties to keep the sentinel), and `"gpio-reserved-ranges"` in `gpio_sim_get_reserved_ranges_size()` needs `size += 2` per invalid `gpio_sim_line` to match `(line->offset, 1)` pairs in `gpio_sim_set_reserved_ranges()`. [F256, F290]
- In `gpio-sim.c`, `gpio_sim_setup_sysfs()` must zero-allocate `chip->attr_groups` (`num_lines + 1`) and per-line `attrs` (`GPIO_SIM_NUM_ATTRS` = 3) for NULL termination. `gpio_sim_add_bank()` must allocate `request_map`, `direction_map`, `value_map`, and `pull_map` via `devm_bitmap_alloc()`/`devm_bitmap_zalloc()` for `num_lines` bits so `bitmap_replace()` in `gpio_sim_get_multiple()`/`gpio_sim_set_multiple()` has full `unsigned long` words. [F289, F298]
- In `gpio-virtuser.c`, `gpio_virtuser_make_lookup_group()` must reject `strlen(name) > GPIO_VIRTUSER_NAME_BUF_LEN - 1` so `lookup->con_id` fits in `gpio_virtuser_line_data::consumer`. `gpio_virtuser_lookup_entry_config_drive_store()` and `gpio_virtuser_lookup_entry_config_pull_store()` must clear mutually exclusive flags in the same group (`GPIO_OPEN_DRAIN | GPIO_OPEN_SOURCE` or `GPIO_PULL_UP | GPIO_PULL_DOWN | GPIO_PULL_DISABLE`) before setting `entry->flags`. [F252, F271]
- In `gpio_virtuser_value_array_do_read()`, the buffer for `gpio_virtuser_dbgfs_emit_value_array()` needs at least `descs->ndescs + 1` bytes (`bufsize = descs->ndescs + 2`) for `descs->ndescs` bits plus `'\n'`. In `gpio_virtuser_get_ids()`, `devm_kmemdup()` copying the prefix before `"-gpios"` (`diff = dash - prop->name`) must allocate `diff + 1` bytes and set `tmp[diff] = '\0'`. [F296, F297]
- In `gpio-tegra186.c`, DT specifiers, `tegra186_pin_range::offset`, and parent IRQ offsets use stride 8 (`port * 8 + pin`), while `gpio_chip` and child `irq_domain` hwirqs pack pins densely by summing `gpio->soc->ports[i].pins`. In `tegra186_gpio_irq()`, `offset` must advance by `port->pins` at `skip:` on every iteration, even when a port is skipped. MMIO offsets in `gpio->base` and `gpio->secure` must use `port->bank` and `port->port` (strides `0x200`/`0x20` and `TEGRA186_GPIO_SCR_PORT_SIZE`/`TEGRA186_GPIO_SCR_PIN_SIZE`), never the `soc->ports` index. [F257, F258, F272]
- In `tegra186_gpio_is_accessible()`, after `TEGRA186_GPIO_VM_RW_MASK`, `TEGRA186_GPIO_SCR` read (`!SEC_REN || SEC_G1R`) and write (`!SEC_WEN || SEC_G1W`) access must be checked as independent clauses. `tegra186_gpio_init_route_mapping()` must write `TEGRA186_GPIO_INT_ROUTE_MAPPING(p, 0)` only when `TEGRA186_GPIO_CTL_SCR` has both `SEC_REN` and `SEC_WEN` cleared. [F265, F309]
- In `tegra_gpio_irq_handler()`, `unmasked` tracks if `chained_irq_exit(chip, desc)` ran early before `generic_handle_domain_irq()` for an edge pin (`lvl & (0x100 << pin)`), and post-loop `chained_irq_exit()` must run only if `!unmasked`. `tegra_gpio_suspend()` must save `GPIO_MSK_DBC_EN` as `(dbc_enb << 8) | dbc_enb` and replace `GPIO_INT_ENB` with `bank->wake_enb[p]` before `tegra_gpio_resume()`. In `tegra_gpio_irq_handler()` and `spacemit_gpio_irq_handler()`, 32-bit status registers scanned by `for_each_set_bit()` must be stored in an `unsigned long`, never a cast `u32 *`. [F273, F300, F321]
- In `gpio-stmpe.c` and `gpio-tc3589x.c`, atomic IRQ callbacks (`*_irq_set_type`, `*_irq_mask`, `*_irq_unmask`) must only modify cached `regs[][]`, while `*_irq_sync_unlock()` writes changed bytes to hardware and updates `oldregs[i][j] = new` under `irq_lock`. [F241]
- In `gpio-stmpe.c`, skip `REG_RE`/`REG_FE` on `STMPE801`/`STMPE1600`; read `STMPE_IDX_GPMR_LSB`/`STMPE_IDX_GPMR_CSB` in `stmpe_gpio_irq_sync_unlock()` on `STMPE1600`; and do not write status/`GPEDR` in `stmpe_gpio_irq()` on `STMPE801`/`STMPE1600`/`STMPE1801`. In `stmpe_gpio_irq()`, `STMPE1600` uses `STMPE_IDX_ISGPIOR_LSB` (`bank = i`), whereas other variants order status MSB-to-LSB using `STMPE_IDX_ISGPIOR_MSB` (`bank = num_banks - i - 1`). [F275, F310]
- In `gpio-tc3589x.c`, `tc3589x_gpio_irq_mask()`/`tc3589x_gpio_irq_unmask()` must toggle `regs[REG_IE][regoffset]` and `regs[REG_DIRECT][regoffset]` in opposite directions. `tc3589x_gpio_irq_set_type()` must check `type == IRQ_TYPE_EDGE_BOTH` and return early after setting `REG_IBE` before `REG_IS`/`REG_IEV`. `tc3589x_gpio_probe()` must write `TC3589x_DKBDMSK_ELINT | TC3589x_DKBDMSK_EINT` to `TC3589x_DKBDMSK` after clearing `TC3589x_RSTCTRL_GPIRST` and before `devm_request_threaded_irq()`. [F242, F277, F304]
- In `gpio-syscon.c`, `priv->dreg_offset` and `priv->dir_reg_offset` are in bits (shifted by 3 in `syscon_gpio_probe()`), so callbacks must compute byte offsets as `(offs / SYSCON_REG_BITS) * SYSCON_REG_SIZE` and bits as `offs % SYSCON_REG_BITS`. In `gpio-xgene-sb.c`, hwirqs (`0 .. priv->nirq - 1`) are offset from `gpio_chip` pins by `priv->irq_start` (`HWIRQ_TO_GPIO`/`GPIO_TO_HWIRQ`); `MPA_GPIO_SEL_LO` (`gpio * 2`) and `gpiochip_lock_as_irq()` use `gpio`, while `MPA_GPIO_INT_LVL` uses `d->hwirq`. [F262, F263]
- In `gpio-vx855.c` (`vx855gpio_direction_input()`, `vx855gpio_get()`, `vx855gpio_set()`, `vx855gpio_set_config()`), `nr` is partitioned in order as `< NR_VX855_GPI`, `< NR_VX855_GPInO`, and `>= NR_VX855_GPInO`, subtracting `NR_VX855_GPI` for `gpo_o_bit()` and `NR_VX855_GPInO` for `gpio_i_bit()`/`gpio_o_bit()`. [F278]
- In `ts4900_gpio_direction_output()`, switching from input (`!(reg & TS4900_GPIO_OE)`) to output must write `TS4900_GPIO_OUT` before setting `TS4900_GPIO_OE`, and `ts4900_gpio_direction_input()` must clear only `TS4900_GPIO_OE` via `regmap_update_bits()`. In `wm831x_gpio_direction_out()` and `wm8350_gpio_direction_out()`, the direction register (`WM831X_GPIO1_CONTROL` / `WM8350_GPIO_CONFIGURATION_I_O`) must be set to output before `wm831x_gpio_set()` / `wm8350_gpio_set()`. [F317, F318]

## Synchronization
- In `gpio-sim.c`, `chip->lock` must be held across all reads and non-atomic bit modifications (`__set_bit`, `__clear_bit`, `__assign_bit`, `bitmap_replace`) of `request_map`, `direction_map`, `value_map`, and `pull_map`. [F200]
- In `gpio-virtuser.c`, `consumer_lock` must be initialized before `gpio_virtuser_create_debugfs_attrs()` and held when accessing `data->consumer` in `gpio_virtuser_consumer_read()`/`gpio_virtuser_consumer_write()`. `IRQ_WORK_INIT_HARD` callbacks (`gpio_virtuser_*_atomic`) run in hardirq context, so `GFP_KERNEL` allocations, user copies, and `_cansleep` calls must stay in the process-context caller. [F207, F323]
- In `gpio-twl4030.c`, `priv->mutex` protects `usage_count`, `direction`, `out_state`, and `cached_leden`, and `twl_direction_out()` must unlock `priv->mutex` before calling `twl_set()`. In `gpio-timberdale.c`, `TGPIO_IER` updates in `timbgpio_irq_enable()`/`timbgpio_irq_disable()` must update `tgpio->last_ier` under `tgpio->lock` because `timbgpio_irq()` zeroes and restores `TGPIO_IER` from `last_ier`. [F214, F216]
- In `gpio-winbond.c`, every Super I/O access sequence must pair `winbond_sio_enter(base)` (`request_muxed_region()` + `WB_SIO_EXT_ENTER_KEY` twice) with `winbond_sio_leave(base)` (`WB_SIO_EXT_EXIT_KEY` + `release_region()`) with no early return in between. [F315]
- Shared port register RMW sequences (`sprd_gpio_update()`, `xgene_gpio_dir_out()`, `gpio-vf610.c`) require an IRQ-saving spinlock; `__xgene_gpio_set()` in `gpio-xgene.c` requires `spin_lock_irqsave(&chip->lock, ...)`. In `gpio-tegra.c`, `tegra_gpio_irq_set_type()` must use raw spinlock `bank->lvl_lock[port]` (`raw_spin_lock_irqsave`) for `GPIO_INT_LVL`, while `tegra_gpio_set_debounce()` uses `spin_lock_irqsave(&bank->dbc_lock[port], flags)` for `bank->dbc_cnt[port]` and `GPIO_DBC_CNT`. [F319, F325, F331]
- In `gpio-viperboard.c`, all accesses to the shared heap DMA buffer `vb->buf` (`gamsg`/`gbmsg`) and `usb_control_msg()` calls across `gpioa`/`gpiob` must hold `vb->lock`. Every `struct vprbrd_gpioa_msg` transfer must initialize all 11 fields of `gamsg` (including `gamsg->__fill = 0x00`), and `vprbrd_gpiob_direction_output()` must unlock `vb->lock` after `vprbrd_gpiob_setdir()` before calling `vprbrd_gpiob_set()`. [F224, F327]

## Object Lifetimes
- In `gpio_sim_add_bank()`, register `devm_add_action_or_reset(dev, gpio_sim_dispose_mappings, chip)` after `devm_irq_domain_create_sim_full()` and before `devm_gpiochip_add_data()`; register `devm_add_action_or_reset(dev, gpio_sim_put_device, chip->dev)` for the `device_find_child()` reference and call `dev_set_drvdata(chip->dev, chip)` before `gpio_sim_setup_sysfs(chip)`. [F184, F185, F201]
- In `gpio-sim.c`, `gpio_sim_device_lockup_configfs()` must pass the leaf `config_item` (`&line->hog->item` if `line->hog`, else `&line->group.cg_item`) to `configfs_depend_item_unlocked()`/`configfs_undepend_item_unlocked()`, and `gpio_sim_device_config_live_store()` must undepend when `live == !!ret`. Configfs `.release` callbacks (`gpio_sim_hog_config_item_release()`, `gpio_sim_line_config_group_release()`, `gpio_sim_bank_config_group_release()`) must use their `parent` field (never `item->ci_parent`) and unlink under `&dev->lock` before freeing. [F188, F189]
- In `gpio-xgene-sb.c`, `xgene_gpio_sb_remove()` must call `acpi_gpiochip_free_interrupts(&priv->chip.gc)` before `irq_domain_remove(priv->irq_domain)`, and `xgene_gpio_sb_probe()` must call `irq_domain_remove(priv->irq_domain)` if `devm_gpiochip_add_data()` fails. In `gpio-virtuser.c`, callers of `gpio_virtuser_irq_work_queue_sync()` with stack `gpio_virtuser_irq_work_context` must wait in `wait_for_completion(&ctx->work_completion)`, and the callback must not touch `ctx` after `complete(&ctx->work_completion)`. [F199, F293]
- In `tegra_gpio_probe()`, `tegra186_gpio_add_pin_ranges()`, and `tegra186_gpio_probe()`, every `device_node *` from `of_find_matching_node()`/`of_find_compatible_node()` must be released via `of_node_put(np)` on all paths (including `-EPROBE_DEFER`). In `vf610_gpio_probe()`, `clk_port` and `clk_gpio` are optional on `devm_clk_get()` errors other than `-EPROBE_DEFER`, and each enabled clock must register `devm_add_action_or_reset(dev, vf610_gpio_disable_clk, ...)` before register access. [F314, F320]

## API Contracts
- In `gpio-tegra186.c`, `tegra186_gpio_get_port()` mutates `*pin` in-place to a port-relative index and returns `NULL` if out-of-range, so `tegra186_gpio_get_base()` callers must check for `NULL`. In `gpio-tegra.c` and `gpio-tegra186.c`, `PIN_CONFIG_INPUT_DEBOUNCE` arguments (in us) must be converted via `DIV_ROUND_UP(..., 1000)` and bounded to 255 ms. [F225, F226]
- In `gpio-winbond.c`, `gpio_chip` offsets pack only enabled `params.gpios` ports (8 pins/port; 5 for GPIO6 at `BIT(5)`). Callers of `winbond_sio_reg_bset()`, `winbond_sio_reg_bclear()`, and `winbond_sio_reg_btest()` must first call `winbond_gpio_get_info(&offset, &info)` to translate `*offset` to a bit index `< 8` and check its boolean return (mutating callbacks `winbond_gpio_direction_in()`, `winbond_gpio_direction_out()`, `winbond_gpio_set()` must return `-EACCES` on `false`). `winbond_gpio_imatch()` must return `winbond_gpio_check_chip(...) == 0`, and `winbond_gpio_chip` and `wcd_gpio_data::chip` (`gpio-wcd934x.c`) must set `can_sleep = true`. [F227, F228, F260, F284, F328]
- In `gpio-twl4030.c`, offsets `>= TWL4030_GPIO_MAX` are output-only LEDs in `TWL4030_MODULE_LED`: guard `TWL4030_MODULE_GPIO` helpers with `offset < TWL4030_GPIO_MAX` and subtract `TWL4030_GPIO_MAX` for `twl4030_led_set_value()`. In `gpio-tps68470.c`, offsets `>= TPS68470_N_REGULAR_GPIO` are output-only SGPOs in `TPS68470_REG_SGPO`: guard `TPS68470_GPIO_CTL_REG_A` and subtract `TPS68470_N_REGULAR_GPIO` for `TPS68470_REG_SGPO`. [F229, F230]
- In `gpio-xgene-sb.c` (`struct gpio_generic_chip`), use `gpio_generic_read_reg()`/`gpio_generic_write_reg()` on `&priv->chip`, never `gc->read_reg`/`gc->write_reg` directly. In `gpio-xgs-iproc.c`, `iproc_gpio_irq_handler()` and `iproc_gpio_irq_chip` callbacks downcast `struct gpio_chip *` via `to_iproc_gpio()`, so `devm_request_irq()` must pass `&chip->gen_gc.gc` as `dev_id`. [F245, F299]

## Error Handling
- In `stmpe_gpio_irq_sync_unlock()`, store every `stmpe_reg_read()` result in a signed `int` and jump to `err:` if `< 0` so hardware writes are aborted while `stmpe_gpio->irq_lock` is still unlocked. [F217]
- In `tegra_gpio_irq_set_wake()`, if `irq_chip_set_wake_parent(d, enable)` fails after `irq_set_irq_wake(tgi->irqs[bank->bank], enable)`, roll back with `irq_set_irq_wake(tgi->irqs[bank->bank], !enable)` before returning. In `tegra186_gpio_probe()`, query `"security"` and `"gpio"` resources with `platform_get_resource_byname()` and fall back to indexed `platform_get_resource()` before `devm_ioremap_resource()`. [F322, F334]

## External Contracts
- In `gpio-virtuser.c`, `gpio_virtuser_debounce_set()` must reject `val > UINT_MAX` with `-E2BIG` and translate `-ENOTSUPP` from `gpiod_set_debounce()` to `-EOPNOTSUPP`. `gpio_virtuser_lookup_entry_config_offset_store()` must reject `offset > (U16_MAX - 1)` because negative `entry->offset` maps to `U16_MAX` in `gpio_virtuser_make_lookup_table()`. `gpio_virtuser_value_array_do_write()` must verify `count - 1 == descs->ndescs` before `bitmap_zalloc(descs->ndescs, ...)` and parsing `count - 1` chars in `gpio_virtuser_dbgfs_parse_value_array()`. [F218, F251, F282, F283]
- In `gpio-sim.c`, check `num_lines > GPIO_SIM_NGPIO_MAX` in `gpio_sim_add_bank()` during probe rather than in `gpio_sim_bank_config_num_lines_store()`, and keep `gpio_sim_sysfs_val_store` returning `-EPERM` on the `value` sysfs attribute. In `gpio-viperboard.c`, `struct vprbrd_gpiob_msg` fields `val` and `mask` must use `cpu_to_be16()` on OUT and `be16_to_cpu()` on IN transfers. [F253, F259, F339]

## Known Pitfalls
- In `stmpe_gpio_irq_sync_unlock()` and `stmpe_gpio_irq()`, compute `num_banks` as `DIV_ROUND_UP(stmpe->num_gpios, 8)`, not `stmpe->num_gpios / 8`. In `gpio-virtuser.c`, `struct gpio_virtuser_attr_data ad` must stay at offset 0 of `gpio_virtuser_line_array_data` and `gpio_virtuser_line_data` (`gpio_virtuser_value_array_do_read()`/`gpio_virtuser_value_array_do_write()` must only access `data->ad`), and `strscpy()` must be used when copying runtime strings into `data->consumer`. [F285, F292, F294]
