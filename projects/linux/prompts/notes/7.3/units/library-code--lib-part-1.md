# LIBRARY CODE — lib (part 1)

Core kernel utilities, data structures, allocators, parsers, and encoding/decompression routines in `lib/` (`argv_split.c` through `hweight.c`), including `assoc_array`, `genalloc`, `btree`, BCH, ASN.1, decompressors, `devres.c`, `cpu_rmap.c`, and `dynamic_queue_limits.c`.

## Architecture & Data Flow

- In `lib/assoc_array.c`, `assoc_array_apply_edit()` adds `edit->adjust_count_by` to `nr_leaves_on_branch` on `edit->adjust_count_on` and its ancestors via `back_pointer` (plus `array->nr_leaves_on_tree`). In `assoc_array_delete()`, removing the last leaf (`nr_leaves_on_tree == 1`) must set `edit->set[1]` to clear `array->root = NULL`, `edit->excised_subtree = array->root`, and `edit->adjust_count_on = NULL`; when collapsing a subtree, `edit->ops_for_excised_subtree` must stay `NULL` so surviving leaves copied into `new_n0` are not freed by `assoc_array_rcu_cleanup()`, which must also clear `edit->excised_subtree`'s root `back_pointer = NULL` before `assoc_array_destroy_subtree()`. [F7, F52, F53, F54]
- In `assoc_array_gc()`, if any child could not fold into `new_n` (`retained == true`) yet `new_n->nr_leaves_on_branch <= ASSOC_ARRAY_FAN_OUT`, it must `goto retry_compress`; folding a child at `new_n->slots[slot]` must clear `new_n->slots[slot] = NULL` and set `next_slot = slot` if `slot < next_slot`. In `assoc_array_insert_into_terminal_node()`, `all_leaves_cluster_together` must recompute `edit->segment_cache[0..ASSOC_ARRAY_FAN_OUT]` at the new shortcut's `skip_to_level` before `goto do_split_node`. [F86, F87, F88]
- In `lib/genalloc.c`, `gen_pool_chunk::end_addr` is inclusive (`virt + size - 1`), so `chunk_size()` is `end_addr - start_addr + 1` and range checks (`gen_pool_virt_to_phys()`, `gen_pool_free_owner()`, `gen_pool_has_addr()`) must use `<= chunk->end_addr`. `gen_pool_add_owner()` must size `chunk->bits` as `BITS_TO_LONGS(nbits) * sizeof(long)` for `unsigned long` `try_cmpxchg()`. Chunk capacity `nbits` rounds down (`size >> order`), whereas alloc/free request `nbits` rounds up (`(size + (1UL << order) - 1) >> order`), and `chunk->avail` must be adjusted by `(nbits << pool->min_alloc_order)`, not raw `size`. [F47, F77, F106, F115]
- In `lib/btree.c`, each `NODESIZE` node packs `geo->no_pairs` keys (`0..geo->no_longs - 1`) and values (`node[geo->no_longs + n]`) in descending key order with `NULL` values marking unused trailing slots. In `merge()`, `right`'s entries copy into `left`, child pointers at `lpos` and `lpos + 1` in `parent` must be swapped, and `btree_remove_level(head, geo, bkey(geo, parent, lpos), level + 1)` must run before freeing `right`. [F57, F80]
- In `dynamic_queue_limits`, wrapping `unsigned int` counters (`num_queued`, `num_completed`, `prev_num_queued`, `adj_limit`) must be compared via signed differences (`POSDIFF`, `AFTER_EQ`, `dql_avail()`), so `dql_queued()` must reject `count > DQL_MAX_OBJECT` and `dql_completed()` must clamp `limit` to `dql->max_limit <= DQL_MAX_LIMIT`. When clamped `limit != dql->limit` in `dql_completed()`, `ovlimit` must be reset to `0` before storing `prev_ovlimit = ovlimit` and `adj_limit = limit + completed`. `dql_reset()` must zero counters and `history`, set `limit = min_limit` and `lowest_slack = UINT_MAX`, and set `slack_start_time`, `last_reap`, and `history_head` to `jiffies` while preserving `min_limit`, `max_limit`, `slack_hold_time`, and `stall_thrs`. [F50, F51, F81, F107]
- In `lib/cpu_rmap.c`, `alloc_cpu_rmap()` must reject `size > 0xffff` (and callers must not pass `size == 0`) and align `rmap->obj` via `ALIGN(offsetof(struct cpu_rmap, near[nr_cpu_ids]), sizeof(void *))`. In `cpu_rmap_update()`, before setting `rmap->near[cpu].dist = 0` for the new `affinity`, every online CPU with `rmap->near[cpu].index == index` must have `dist` reset to `CPU_RMAP_DIST_INF` and be added to `update_mask`. [F58, F78]
- In `lib/bch.c`, `bch->elp` must be allocated with `(t + 1) * sizeof(struct gf_poly_deg1)` bytes (not `GF_POLY_SZ(2 * t)`) because `factor_polynomial()` indexes `((struct gf_poly_deg1 *)f)[gcd->deg].poly`. `mod_s(bch, v)` requires `v < 2 * GF_N(bch)`; `modulo(bch, v)` must be used when `v >= 2 * GF_N(bch)` (`a_pow()`, `find_poly_deg2_roots()`). [F105, F113]
- `asn1_ber_decoder()` rejects `datalen > 65535` (`-EMSGSIZE`) and definite length fields `n > 2` (`cons_dp_stack`/`cons_datalen_stack` are `unsigned short[NR_CONS_STACK]`). When `ASN1_OP_END_*` with `ASN1_OP_END__OF` loops to `pc = machine[pc + 1]`, it must restore `csp++` (and `dp--` for indefinite or `datalen = len` for definite length) after popping `cons_*_stack[--csp]`. [F67, F90]
- In `lib/devres.c` and `lib/genalloc.c`, `devres_alloc*()` stores a pointer payload, so release/match callbacks must dereference `*(void __iomem **)res` or `*(struct gen_pool **)res`. Under `ARCH_HAS_RELATIVE_EXTABLE` (`lib/extable.c`) and `CONFIG_GENERIC_BUG_RELATIVE_POINTERS` (`lib/bug.c`), relative displacements (`x->insn`, `x->fixup`, `bug_addr_disp`, `file_disp`) are relative to the field's own address, and `swap_ex()` must adjust `insn` and `fixup` by `b - a`. [F121, F122]
- In `digsig_verify_rsa()` and `pkcs_1_v1_5_decode_emsa()`, MPI result `p` (length `l`) must be right-aligned in zeroed `out1` of modulus length `mlen` (`memcpy(out1 + mlen - l, p, l)`), and `pkcs_1_v1_5_decode_emsa()` must check `modulus_len >= 11` and `msg[0] == 0x00 && msg[1] == 0x01`. `argv_split()` allocates `argc + 2` pointers, storing `argv_str` at `argv[-1]` and `NULL` at `argv_ret[argc]` for `argv_free()`. [F66, F71]
- In `lib/errname.c`, `names_0` errnos must be `<= 300` and `names_512` in `[512, 550]`, with aliased errnos omitted or `#if`-guarded and MIPS `EDQUOT` outside `names_0`. `compressed_formats[]` (`lib/decompress.c`) must end with a zeroed sentinel. In `get_next_block()` (`lib/decompress_bunzip2.c`), `hufGroup->base` and `limit` use 1-based pointers (`base - 1`, `limit - 1`) and `limit[maxLen + 1] = INT_MAX` in `int limit[MAX_HUFCODE_BITS + 1]`. [F61, F73, F74]

## Synchronization

- In `lib/assoc_array.c`, `assoc_array_iterate()` and `assoc_array_find()` require `rcu_read_lock()` or an exclusive lock, and tree walks must use `READ_ONCE()` on `root`, `slots`, `next_node`, and `back_pointer`. `assoc_array_subtree_iterate()` must visit all leaf slots before descending into metadata slots in a second pass. `assoc_array_destroy()` has no RCU deferral and requires all concurrent accesses (including RCU readers) to be prevented. [F15, F16, F85]
- In `gen_pool_add_owner()`, all `gen_pool_chunk` fields must be initialized before acquiring `pool->lock` and calling `list_add_rcu(&chunk->next_chunk, &pool->chunks)`, and chunks must only be added in sleepable process context (`vzalloc_node()`). [F18, F140]
- Between `dql_queue_stall()` and `dql_check_stall()`, clearing reused `dql->history` slots must precede `WRITE_ONCE(dql->history_head, now_hi)` via `smp_wmb()`, and `dql_check_stall()` must issue `smp_rmb()` after `READ_ONCE(dql->history_head)` and retry if `READ_ONCE(dql->history_head)` changed after scanning `history`. [F20]
- In `lib/flex_proportions.c`, callers must externally serialize `fprop_new_period()`, which must wrap `p->events` and `p->period` updates in `preempt_disable_nested()` and `write_seqcount_begin`/`end(&p->sequence)`. In `fprop_reflect_period_percpu()`, after `raw_spin_lock_irqsave(&pl->lock, flags)`, `pl->period >= period` must be rechecked under `pl->lock`. [F21, F22]
- `ei_mutex` must protect all accesses to `error_injection_list` in `lib/error-inject.c`. In `digsig_verify_rsa()`, `down_read(&key->sem)` must be held before `user_key_payload_locked(key)` until all `ukp->data` reads finish, checking `!ukp` after locking. [F25, F26]
- `dump_stack_lvl()` must skip `printk_cpu_sync_get_irqsave()` / `put_irqrestore()` when `panic_on_this_cpu()` is true. `report_bug()` must wrap `__report_bug()` in `warn_rcu_enter()` / `exit()`, and `module_bug_list` must use RCU (`list_for_each_entry_rcu()`, `list_add_rcu()`, `list_del_rcu()`), not a spinlock. `lib/atomic64.c` must use `local_irq_save()` and `arch_spin_lock()` on `atomic64_lock`. `dhry_benchmark()` must pin the CPU with `get_cpu()` / `put_cpu()` around `dhry()`. [F28, F131, F132, F144]

## Object Lifetimes

- In `lib/cpu_rmap.c`, `irq_cpu_rmap_release()` and `irq_cpu_rmap_add()`'s `err_set` path must clear `rmap->obj[glue->index] = NULL` before `cpu_rmap_put(glue->rmap)`. `free_irq_cpu_rmap()` must run in process context before `free_irq()` because `irq_set_affinity_notifier(..., NULL)` sleeps and needs valid IRQ descriptors. [F1, F124]
- `of_gen_pool_get()` returns a borrowed `struct gen_pool *` and must drop `of_node_put(parent)`, `put_device(&pdev->dev)`, and `of_node_put(np_pool)` before returning. All `gen_pool` allocations (including `devm_gen_pool_create()`) must be freed before `gen_pool_destroy()` / `devm_gen_pool_release()` (`BUG_ON(bit < end_bit)`). [F2, F128]
- `btree_destroy()` only frees `head->node` and `head->mempool`; non-empty trees must first be emptied with `btree_grim_visitor()` or `btree_remove()`. In `btree_merge()`, when `target->node` is `NULL`, `victim->node` and `height` move to `target` and `victim` must be reset via `__btree_init(victim)`. [F8, F9]

## API Contracts

- `assoc_array_cancel_edit()` frees `edit->new_meta[]` and `edit` but never frees `edit->leaf` (nor does `assoc_array_insert_set_object()`). In `assoc_array_gc()`, `iterator` must increment a retained leaf's refcount before returning `true`, because both `assoc_array_rcu_cleanup()` and the `enomem` rollback (`assoc_array_destroy_subtree()`) call `ops->free_object()` on all leaves in their subtrees. [F5, F6]
- In `lib/genalloc.c`, `devm_gen_pool_create()` keys pools on `dev` by `pool->name` (`NULL` matches only unnamed pools in `devm_gen_pool_match()`) and returns `ERR_PTR(-EINVAL)` on duplicate name or `ERR_PTR(-ENOMEM)` on failure, whereas `gen_pool_create()`, `gen_pool_get()`, and `of_gen_pool_get()` return `NULL`. `gen_pool_virt_to_phys()` returns `(phys_addr_t)-1` on failure, whereas `gen_pool_alloc_algo_owner()` returns `0`. `min_alloc_order` is a log2 byte order, and `gen_pool_fixed_alloc()` requires `offset` aligned to `1UL << pool->min_alloc_order` (`WARN_ON`). `genpool_algo_t` callbacks must return `>= size` (`end_bit`) on failure (0 is valid) and, like `gen_pool_for_each_chunk()` callbacks, run under `rcu_read_lock()` and must not sleep. `gen_pool_alloc*()` / `free*()` require `CONFIG_ARCH_HAVE_NMI_SAFE_CMPXCHG` in NMI. [F31, F32, F34, F49, F139, F141, F155]
- In `lib/devres.c`, `devm_ioremap_resource*()` and `devm_of_iomap()` return `IOMEM_ERR_PTR()`, whereas `devm_ioremap*()` and `devm_ioport_map()` return `NULL`. `devm_iounmap()` and `devm_ioport_unmap()` must only receive pointers from `devm_ioremap*()` / `devm_ioport_map()` (`WARN_ON`). [F30, F125]
- In `lib/bch.c`, `bch_init()` requires `m` in `5..15`, `t` in `1..64`, `m * t < (1 << m) - 1`, and under `CONFIG_BCH_CONST_PARAMS` rejects `(m, t) != (CONFIG_BCH_CONST_M, CONFIG_BCH_CONST_T)` with `NULL`. `bch_encode()` loads existing `ecc` when non-NULL, so callers starting fresh must zero `ecc`. `bch_decode()` returns error count `>= 0`, `-EINVAL` (including `8 * len > bch->n - bch->ecc_bits`), or `-EBADMSG`, and `errloc[i] >= 8 * len` lies in ECC, not `data`. [F39, F40, F83, F161]
- In `lib/asn1_encoder.c`, `asn1_encode_integer()` requires `integer >= 0` and `asn1_encode_tag()` requires `tag <= 30`. In-place recoding (`string == NULL` or `seq == NULL`) requires `len <= 127` and `data` set to the pointer returned by the initial `len = -1` call (`data -= 2`). [F69, F159]
- `hex_to_bin()` returns signed `0..15` or `-1`. In `hex2bin()` and `bin2hex()`, `@count` is binary bytes (`u8`), and `bin2hex()` does not NUL-terminate `@dst`. `get_options()` always writes the count to `ints[0]` (even if `nints == 0`), so `@ints` must be non-NULL; when `get_option()` returns `3` (`M-N`), `get_range()` fills `[M, N-1]` and advances `i` by `range_nums - 1`, leaving `str` at `N`. [F46, F95, F117, F118]
- `ip_fast_csum(iph, ihl)` takes `ihl` in 4-byte words, whereas `ip_compute_csum()` and `csum_partial()` take bytes; chained `csum_partial()` calls require even `len` on all non-final fragments. `btree_insert()` requires `val != NULL` and a new key (`BUG_ON`; use `btree_update()` for existing keys). `dql_completed(dql, count)` requires `count <= READ_ONCE(dql->num_queued) - dql->num_completed` (`BUG_ON`). `__clzdi2()` and `__ctzdi2()` must take `u64` and use `fls64()` / `__ffs64()`. [F84, F97, F152, F153, F158]

## Error Handling

- In `gen_pool_alloc_algo_owner()`, a partial `bitmap_set_ll()` failure (`remain != 0`) must roll back `nbits - remain` bits via `bitmap_clear_ll()` before `goto retry`. In `__devm_ioremap_resource()`, if `__devm_ioremap()` fails, `devm_release_mem_region(dev, res->start, size)` must be called immediately. [F4, F11]
- `get_injectable_error_type()` must initialize its return value to `-EINVAL`. Every exported `asn1_encode_*()` must check `if (IS_ERR(data)) return data;` first. `bch_alloc()` only sets `*err = 1` on failure, so callers must initialize `err = 0` and check `err` before dereferencing. In `digsig_verify_rsa()`, `ERR_PTR()` values from `mpi_read_from_buffer()` must not be passed to `mpi_free()` (`while (--i >= 0) mpi_free(pkey[i])`). [F29, F37, F41, F43]

## External Contracts

- In `asn1_encode_integer()`, if the top non-zero byte has `byte & 0x80`, a leading `0x00` must be prepended and `data_len` decremented (checking `data_len == 0` afterward). Under `#ifdef PREBOOT`, `__decompress()` in `decompress_unlz4.c`, `decompress_bunzip2.c`, and `decompress_unlzma.c` must pass `in_len - 4` (`len - 4`) to exclude the 4-byte size trailer. In `of_gen_pool_get()`, a child DT node without its own `platform_device` looks up the pool on the parent device by `"label"` or `of_node_full_name(np_pool)`. [F70, F75, F130]

## Known Pitfalls

- In `btree_insert_level()`, after splitting a full node and inserting `new` at `level + 1`, it must `goto retry` to re-run `find_level()`, `getpos()`, and `getfill()`. In `btree_get_prev()`, `retry_key` must be cleared to `NULL` before `goto retry` from `miss`. [F55, F91]
- In `asn1_find_indefinite_length()` and `asn1_ber_decoder()`, length checks must use `len > datalen - dp` and `pc + asn1_op_lengths[op] > machlen` to avoid overflow; on `ASN1_OP_MATCH__SKIP` after a tag mismatch, `asn1_ber_decoder()` must decrement `dp--`. [F68, F89]
- `find_cpio_data()` must check both bounds and pointer wrap (`nptr > p + len || dptr < p || nptr < dptr`). `parse_header()` and `unlzo()` (`lib/decompress_unlzo.c`) must check `end - parse < l + 4`, `dst_len > LZO_BLOCK_SIZE`, and `src_len <= 0 || src_len > dst_len`. In `get_next_block()` (`lib/decompress_bunzip2.c`), `temp[MAX_HUFCODE_BITS + 1]` must be wider than 8 bits (`unsigned short`) for `MAX_SYMBOLS` (258). [F72, F76, F99]
- `hex_to_bin()` must cast `((ch - '9' - 1) & ('0' - 1 - ch))` to `unsigned` before `>> 8`; `hex2bin()` must check `hex_to_bin(*src++) >= 0` on the high nibble before advancing `src` for the low nibble; `hex_dump_to_buffer()` must use `get_unaligned()` for 2/4/8-byte groups. In `get_option()`, when `*cur == '-'`, `cur` must advance before `simple_strtoull(++cur, str, 0)` so `cur == *str` catches a bare hyphen. [F62, F63, F64, F108]
- `__fprop_add_percpu_max()` must widen `numerator` and `denominator` to `u64` before `* max_frac` or `<< FPROP_FRAC_SHIFT` and use `div_u64()`. `fprop_new_period()` and `fprop_reflect_period_percpu()` must guard right-shifts by `periods < 64` (`< BITS_PER_LONG`). `compute_syndromes()` and `build_mod8_tables()` (`lib/bch.c`) must guard `1u << (32 - m)` and `g[j] << (d + 1)` with `m != 0` and `d < 31`. [F101, F102, F104]
- `__cmpdi2()`, `__ashldi3()`, and `__ashrdi3()` must cast `DWstruct.low` (and `high` for carries) to `unsigned int`. `cmp_ex_sort()` and `cmp_ex_search()` (`lib/extable.c`) must compare `unsigned long` addresses with `>` / `<`, not `int` subtraction. `devmem_is_allowed()` must use `PFN_PHYS(pfn)`. Unlike `of_iomap()`, `devm_of_iomap()` calls `devm_ioremap_resource()`, failing with `ERR_PTR(-EBUSY)` on shared regions. [F98, F100, F109, F127]
