# MAC80211 — net/mac80211 (part 4)

This unit implements the client Station MLME state machine (`mlme.c`), OCB mode (`ocb.c`), off-channel/ROC (`offchannel.c`), 802.11 IE parsing (`parse.c`), power management (`pm.c`), and rate control (`rate.c`/`rate.h`).

## Architecture & Data Flow
- In `struct ieee80211_elems_parse`, `elems` must sit at offset 0 and `scratch[]` is `3 * params->len`; `ieee802_11_parse_elems_full()` must call `ieee80211_clear_tpe()` on `elems->tpe` and `elems->csa_tpe` (`0x7f`). In `_ieee802_11_parse_elems_full()` and `care_about_ies`, `params->filter` is 64-bit: check `id < 64` and use `1ULL << id`; per element, reset `elem_parse_failed = 0`, set `__set_bit(id, seen_elems)` only if `!elem_parse_failed`, and on duplicate single-instance elements (`test_bit(id, seen_elems)`) record `IEEE80211_PARSE_ERR_DUP_ELEM` and `continue` before CRC/pointer updates. [F222, F252, F264, F279]
- In `struct ieee80211_mle_per_sta_profile`, `sta_info_len` includes its 1-byte length field while `prof->variable` starts after it; `ieee80211_prep_mle_link_parse()` must check `elems->sta_prof_len >= sizeof(*prof) + prof->sta_info_len - 1 + 4` before skipping the 4-byte assoc-response fixed fields (`capab_info`, `status`). In `ieee80211_rearrange_tpe_psd()`, stage full-channel order into `tmp` before overwriting `psd->power`. In `ieee80211_determine_chan_mode()`, refresh `parse_params.mode` from `conn->mode` after `again:`, `kfree(elems)` before every `goto again;`, and strictly decrease `conn->mode`. [F245, F251, F271]
- In `ieee80211_mgd_assoc()` and `ieee80211_mgd_assoc_ml_reconf()`, call `ieee80211_mgd_get_ap_ht_vht_capa()` for every link before `ieee80211_add_link_elems()`; both must check `sband->vht_cap.vht_supported` alongside `conn.mode >= IEEE80211_CONN_MODE_VHT` and `band != NL80211_BAND_6GHZ`. In `ieee80211_add_link_elems()`, `present_elems` (`PRESENT_ELEMS_MAX` = 8) reserves its last slot for `0` and must record standard IDs (`< PRESENT_ELEM_EXT_OFFS`) before extension IDs. [F224, F257, F295]
- In `ieee80211_assoc_config_link()`, set `wmm_last_param_set` and `mu_edca_last_param_set` to `-1` before `ieee80211_sta_wmm_params()`. In `ieee80211_do_assoc()`, reset `assoc_data->comeback = false` on each attempt, and in `ieee80211_sta_work()`, do not update `assoc_data->timeout` on TX status (`ifmgd->status_received`) while `assoc_data->comeback` is set. [F211, F225, F234]
- In `ieee80211_set_disassoc()`, sending deauth/disassoc (`tx == true`) requires at least one active link with `!link->u.mgd.csa.blocked_tx`; clear `IEEE80211_CONF_PS` via `ieee80211_hw_config()` before sending, and zero `sdata->deflink.u.mgd.bssid` and `sdata->vif.cfg.ap_addr` only after `ieee80211_send_deauth_disassoc()`. In `ieee80211_sta_process_chanswitch()`, check `ieee80211_hw_check(&local->hw, CHANCTX_STA_CSA)` before `drv_pre_channel_switch()` or `ieee80211_link_reserve_chanctx()`. [F231, F307, F309]
- Do not arm `bcn_mon_timer`, `conn_mon_timer`, or `monitor_work` when `CONNECTION_MONITOR` is set on `local->hw`. In `ieee80211_mgd_probe_ap()`, check `already = !!(ifmgd->flags & IEEE80211_STA_CONNECTION_POLL)` before setting the flag, and if `already`, return without resetting `probe_send_count` or calling `ieee80211_mgd_probe_ap_send()`. In `run_again()`, if `sdata->u.mgd.timer` is pending, call `mod_timer()` only if `time_before(timeout, sdata->u.mgd.timer.expires)`. [F275, F284, F303]
- In `ieee80211_enable_ps()` and `ieee80211_dynamic_ps_enable_work()`, if `PS_NULLFUNC_STACK` and `REPORTS_TX_ACK_STATUS` are set, wait for `IEEE80211_STA_NULLFUNC_ACKED` before setting `IEEE80211_CONF_PS` or calling `ieee80211_hw_config()`. In `ieee80211_dynamic_ps_enable_work()`, when `dynamic_ps_timeout > 0`, re-arm `dynamic_ps_timer` and return if `drv_tx_frames_pending(local)` or any `local->queue_stop_reasons[q]` is non-zero (under `spin_lock_irqsave(&local->queue_stop_reason_lock, flags)`). [F304, F305, F320]
- In `ieee80211_offchannel_stop_vifs()`, stop queues (`IEEE80211_QUEUE_STOP_REASON_OFFCHANNEL`) and call `ieee80211_flush_queues(local, NULL, false)` before setting `SDATA_STATE_OFFCHANNEL`, disabling beacons, and calling `ieee80211_offchannel_ps_enable()`; save `bss_conf.enable_beacon` in `SDATA_STATE_OFFCHANNEL_BEACON_STOPPED` before clearing it so `ieee80211_offchannel_return()` only re-enables previously active beacons. Started `ieee80211_roc_work` items on `local->roc_list` must form a contiguous head prefix (use `list_for_each_entry_safe()` with `ieee80211_roc_notify_destroy()`), as callers `break` at `!roc->started`. In `ieee80211_mgmt_tx()`, set `IEEE80211_TX_CTRL_DONT_USE_RATE_MASK` in `control.flags`, and if `params->dont_wait_for_ack`, set `*cookie = 0xffffffff` before `ieee80211_start_roc_work()`. [F243, F247, F267, F300, F333]
- `ieee80211_tx_rate` arrays terminate at `idx = -1` (`idx < 0`); `rate_fixup_ratelist()` sets all slots after `idx < 0` (and legacy slots with `idx >= sband->n_bitrates`) to `-1`. In `rate_control_send_low()`, positive `mcast_rate[sband->band]` (`0` = unconfigured) maps to `rates[0].idx = mcast_rate - 1`. In `rate_idx_match_mcs_mask()` and `rate_idx_match_vht_mcs_mask()`, HT `rate_idx` is `ridx = *rate_idx / 8` (`< IEEE80211_HT_MCS_MASK_LEN`), `rbit = *rate_idx % 8`; VHT `rate_idx` is `ridx = *rate_idx >> 4` (`< NL80211_VHT_NSS_MAX`), `rbit = *rate_idx & 0xf`; `rbit` starts at the selected rate's bit on `i == ridx` and resets to `7`/`15` (down) or `0` (up) after each outer iteration. [F260, F261, F262, F269]

## Synchronization
- In `rate_control_rate_init()`, set `WLAN_STA_RATE_CONTROL` only after `ref->ops->rate_init()` finishes under `sta->rate_ctrl_lock`. All per-STA `rate_control_ops` callbacks run under `spin_lock_bh(&sta->rate_ctrl_lock)`, with `rcu_read_lock()` outside `sta->rate_ctrl_lock` in `rate_control_rate_init()` and `rate_control_rate_update()`. `ieee80211_rate_control_ops_get()` takes `kernel_param_lock(THIS_MODULE)` outside `rate_ctrl_mutex` (taken in `ieee80211_try_rate_control_ops_get()`); never invert this order. [F194, F197, F315]
- In `ieee80211_cancel_roc()`, flush `local->hw_roc_start` via `wiphy_work_flush()` before inspecting `local->roc_list`, and for started HW ROCs cancel `local->hw_roc_done` via `wiphy_work_cancel()` after `drv_cancel_remain_on_channel()` before `ieee80211_start_next_roc()`. In `ieee80211_reconfig_roc()`, flush both `hw_roc_start` and `hw_roc_done` before iterating `local->roc_list`. [F203, F204]
- Whenever `timer_delete_sync(&local->dynamic_ps_timer)` is called, also cancel `local->dynamic_ps_enable_work` via `wiphy_work_cancel()`. In `ieee80211_set_disassoc()`, after `netif_carrier_off()` and disabling PS, run `synchronize_net()` and `ieee80211_flush_queues(local, sdata, true)` before TXing deauth/disassoc and tearing down STA state. In `ieee80211_mgd_stop()`, hold `spin_lock_bh(&ifmgd->teardown_lock)` while freeing/clearing `teardown_skb` and `orig_teardown_skb`. [F206, F208, F209]
- In `__ieee80211_suspend()`, `local->suspending = true` + `mb()` precedes scan/ROC/BA cancellations and queue flushing; `local->quiescing = true` + `mb()` precedes `flush_workqueue()` and timer/work cancellations; and `local->suspended = true` + `barrier()` precedes clearing `quiescing` and `suspending`. [F296]
- In `ieee80211_ocb_leave()`, set `ifocb->joined = false` before flushing STAs and `timer_delete_sync(&sdata->u.ocb.housekeeping_timer)` so `ieee80211_ocb_work()` sees `ifocb->joined != true`. `ifocb->incomplete_lock` is taken with `spin_lock()` in softirq (`ieee80211_ocb_rx_no_sta`), so process-context callers (`ieee80211_ocb_work`, `ieee80211_ocb_leave`) must use `spin_lock_bh(&ifocb->incomplete_lock)` and drop it before `ieee80211_ocb_finish_sta()` or `sta_info_free()`. `ieee80211_sta_bcn_mon_timer()` and `ieee80211_sta_conn_mon_timer()` run in softirq without `wiphy->mtx`, so `ieee80211_is_csa_in_progress()` and `ieee80211_latest_active_link_conn_timeout()` must use `guard(rcu)()` and RCU accessors (`for_each_link_data_rcu()`, `sta_info_get()`, `rcu_dereference()`). [F311, F312, F322]

## Object Lifetimes
- `ieee802_11_parse_elems_full()` returns heap-allocated `&elems_parse->elems`, which callers must `kfree()` on every exit or re-parse path. In `ieee80211_assoc_config_link()`, when missing Assoc Resp element pointers are copied from `bss_elems` into `elems`, `bss_ies` must outlive `elems`, and pointers into `bss_elems`'s `scratch[]` must never outlive `kfree(bss_elems)`. [F176, F294]
- In `ieee80211_mgd_auth()`, `cfg80211_ref_bss()` is acquired for `auth_data->bss` only after `ieee80211_prep_connection()` and `ieee80211_auth()` succeed; `err_clear:` must `kfree(auth_data)` and set `ifmgd->auth_data = NULL` without calling `ieee80211_destroy_auth_data()`. `ifmgd->assoc_req_ies` outlives `ieee80211_destroy_assoc_data()` for `cfg80211_rx_assoc_resp()`; `ieee80211_send_assoc()` must `kfree(ifmgd->assoc_req_ies)` before reassigning it, and `ieee80211_mgd_stop()` must free and NULL it. [F180, F183]
- In `ieee80211_mgd_assoc_ml_reconf()`, call `ieee80211_build_ml_reconf_req()` before `ieee80211_vif_set_links()` and `ieee80211_sta_remove_link()` tear down `req->rem_links`, and finish link removal before `ieee80211_tx_skb()`. `add_links_data->link[link_id].elems` aliases `req->add_links[link_id].elems` and must not be read after `ieee80211_mgd_assoc_ml_reconf()` returns. When ML reconf with `add_links_data` ends (`ieee80211_process_ml_reconf_resp()` or `ieee80211_ml_reconf_reset()`), call `cfg80211_mlo_reconf_add_done()` once and free/NULL `reconf.add_links_data`. [F187, F188, F289]
- In `ieee80211_set_disassoc()`, if `IEEE80211_VIF_REMOVE_AP_AFTER_DISASSOC` is set, move `ap_sta` to `IEEE80211_STA_NONE` via `sta_info_move_state()` before notifying `BSS_CHANGED_ASSOC`, and call `sta_info_flush(sdata, -1)` only after that notification. During non-WoWLAN suspend in `__ieee80211_suspend()`, each running non-`AP_VLAN`, non-`MONITOR` vif must run `ieee80211_mgd_quiesce()` (if station), flush `sdata->dec_tailroom_needed_wk`, and call `drv_remove_interface()` before `ieee80211_stop_device(local, true)`. [F299, F306]
- After `ieee80211_attach_ack_skb()` in `ieee80211_mgmt_tx()`, free any untransmitted `skb` with `ieee80211_free_txskb()` (not `kfree_skb()`), and set `roc->frame = NULL` on TX in `ieee80211_handle_roc_started()`. `rate_control_set_rates()` publishes `rates` via `rcu_assign_pointer(pubsta->rates, rates)` and must free any replaced `old` table with `kfree_rcu(old, rcu_head)`. [F190, F193]

## API Contracts
- `ieee802_11_parse_elems_full()` returns `NULL` on failure (`!elems`) and rejects `params->link_id >= 0 && params->bss` (`WARN_ON`; set `params->link_id = -1` when `params->bss` is set), whereas `ieee80211_determine_chan_mode()` returns `ERR_PTR()` on failure and never `NULL` (`IS_ERR(elems)`). `ieee80211_latest_active_link_conn_timeout()` initializes `latest_timeout = jiffies`, so callers must check `time_is_after_jiffies(latest_timeout)`. When a non-assoc MLD link's per-STA profile has a non-zero status code, `ieee80211_assoc_config_link()` stores it in `assoc_data->link[link_id].status` and returns `true`; callers must check `status`. [F212, F214, F215, F226]
- `ieee80211_prep_channel()` accepts nullable `link` (return `0` before chanctx assignment when `!link`), and `ieee80211_sta_process_chanswitch()` accepts nullable `csa_elems` (treat `!csa_elems` as `res = 1`). In `ieee80211_prep_connection()`, when allocating `new_sta`, populate `link->conf` (BSSID, basic rates via `ieee80211_mgd_setup_link_sta()`, beacon timing) before `ieee80211_prep_channel()`, and call `ieee80211_link_info_change_notify()` after it. [F216, F217, F308]
- In `rate_control_tx_status()`, `st->skb` may be `NULL`; check `ref->ops->tx_status_ext` first and verify `st->skb` before `ref->ops->tx_status`. `ieee80211_get_tx_rates()` accepts nullable `vif` and `sta`; check `if (!vif) return;` after `rate_control_fill_sta_table()` before `vif_to_sdata(vif)` and guard `rate_fixup_ratelist()` with `if (sta)`. `ieee80211_ocb_finish_sta()` enters RCU via `sta_info_insert_rcu()` (`__acquires(RCU)`) on both success and failure; callers must pair it with `rcu_read_unlock()`. [F218, F219, F313]

## Error Handling
- In `__ieee80211_suspend()`, `drv_suspend()` returns `< 0` on error, `0` on WoWLAN success, or `1` to request disconnect (`WARN_ON(err != 1)` for other `> 0`); on any non-zero return, wake `IEEE80211_QUEUE_STOP_REASON_SUSPEND` queues via `ieee80211_wake_queues_by_reason()`, and on `err < 0` clear `WLAN_STA_BLOCK_BA`, `local->quiescing`, and `local->wowlan`. In `ieee80211_prep_connection()`, errors after allocating `new_sta` but before `sta_info_insert(new_sta)` must call `sta_info_free(local, new_sta)` and jump to `out_err`; `sta_info_insert(new_sta)` consumes `new_sta` on both success and failure (`new_sta = NULL`) and failure must jump to `out_release_chan`. [F192, F221, F329]

## Known Pitfalls
- In `__ieee80211_roc_work()`, save `roc->on_channel` before `ieee80211_recalc_sw_work()`, which frees finished `roc` items via `ieee80211_end_finished_rocs()`. In `ieee80211_end_finished_rocs()`, store `remaining = roc->start_time + msecs_to_jiffies(roc->duration) - now` in a signed `long` so `remaining <= 0` handles `jiffies` wrap-around. [F205, F285]
- In `ieee80211_rx_mgmt_beacon()`, `ieee80211_mgd_check_cross_link_csa()` defragments per-STA profiles in place inside `elems->ml_basic`; never re-parse `elems->ml_basic` afterwards. For S1G beacons (`ieee80211_is_s1g_beacon()`), offset `variable` by `ieee80211_s1g_optional_len(ext->frame_control)` before checking `baselen > len`, and call `ieee80211_is_s1g_short_beacon()` only when `ext` is non-NULL using `parse_params.start` and `parse_params.len`. [F236, F253]
- In `ieee80211_parse_extension_element()`, `data` and `len` exclude the 1-byte extension ID while `ieee80211_he_oper_size(data)` and `ieee80211_he_spr_size(data)` include it: check `len >= sizeof(...)` first, then `len >= ieee80211_he_*_size(data) - 1`. In `ieee80211_parse_tpe()`, call `ieee80211_valid_tpe_element()` first and return on `!count` before `N = 1 << (count - 1)`. For `LOCAL_EIRP` and `REG_CLIENT_EIRP`, `count` is 0-based (`count + 1` octets), so when `count == 3` and `len > sizeof(*env) + count + 1`, read 320 MHz EIRP from `env->variable[4]`. [F249, F250, F280]
- Use `get_unaligned_le16()` for 16-bit fields at variable offsets in IEs and action frames (`ieee80211_ml_reconfiguration()`, `ieee80211_parse_adv_t2l()`, `ieee80211_get_ttlm()`, `ieee80211_process_ml_reconf_resp()`, `ieee80211_process_epcs_ena_resp()`). When comparing `ssize_t len = cfg80211_defragment_element(...)` against `sizeof()`, cast `sizeof()` to `ssize_t` or check `len < 0` first. In `ieee80211_ml_reconfiguration()`, check `link_removal_timeout[link_id] < 1` (`link_delay = 0`) before `link_conf->beacon_int * (link_removal_timeout[link_id] - 1)`. [F254, F256, F278]
- In `ieee802_11_find_bssid_profile()`, matching `ether_addr_equal(new_bssid, bss->bssid)` in the inner loop must immediately `return profile_len`, and return `0` after the outer loop. Gate `conn.mode >= IEEE80211_CONN_MODE_VHT` checks requiring VHT IEs on `NL80211_BAND_5GHZ` (`is_5ghz`) in `ieee80211_assoc_config_link()` and `ieee80211_determine_ap_chan()`. In `ieee80211_mgd_ssid_mismatch()`, negate `memcmp` for zeroed hidden SSIDs (`if (!memcmp(elems->ssid, zero_ssid, elems->ssid_len)) return false;`), while `return memcmp(elems->ssid, cfg->ssid, cfg->ssid_len);` returns `true` on mismatch. [F263, F272, F273]
- During WoWLAN suspend in `__ieee80211_suspend()`, after `ieee80211_mgd_quiesce(sdata)`, if `associated && powersave` and `!(local->hw.conf.flags & IEEE80211_CONF_PS)`, set `IEEE80211_CONF_PS` via `ieee80211_hw_config()` before `drv_suspend()`. In `ieee80211_offchannel_ps_enable()`, after clearing `IEEE80211_CONF_PS`, call `ieee80211_send_nullfunc(local, sdata, true)` when `!offchannel_ps_enabled` or `!ieee80211_hw_check(&local->hw, PS_NULLFUNC_STACK)`. [F297, F301]
