# KERNEL VIRTUAL MACHINE FOR ARM64 (KVM/arm64) — arch/arm64/kvm (part 2)

This unit implements the EL2 hypervisor execution engine and page-table library (`pgtable.c`, `vgic-v3-sr.c`, `exception.c`, `aarch32.c`, `include/hyp/`, `vhe/`, and `nvhe/`). It drives host/guest world switches, saves/restores CPU, sysreg, FPSIMD/SVE, debug, VGIC, and timer state, handles EL2 traps and TLB invalidations, and implements pKVM memory ownership, host Stage-2 isolation, PSCI relay, and FF-A proxying.

## Architecture & Data Flow
- `ctxt_to_vcpu(ctxt)` falls back to `container_of(ctxt, struct kvm_vcpu, arch.ctxt)` when `ctxt->__hyp_running_vcpu == NULL`. `__hyp_running_vcpu` is non-NULL only on `host_ctxt` (`NULL` on guest `vcpu->arch.ctxt`), must be set to `vcpu` before loading guest sysregs/traps or passing `host_ctxt` to `sysreg-sr.h` helpers in `__kvm_vcpu_run()` or `kvm_vcpu_load_vhe()`, and cleared to `NULL` after restoring host state in `__kvm_vcpu_run()` or `kvm_vcpu_put_vhe()`. [F207, F297, F315]
- In `__compute_hcr()`, when `vcpu_has_nv(vcpu)` and `is_hyp_ctxt(vcpu)`, only config-driven RES1 bits from `kvm_vcpu_apply_reg_masks(vcpu, HCR_EL2, 0) & ~NV_HCR_GUEST_EXCLUDE` may be merged into `hcr_el2` (never raw `__vcpu_sys_reg(vcpu, HCR_EL2)`). Because `to_hw_pstate()` maps virtual `PSR_MODE_EL2t`/`EL2h` to `PSR_MODE_EL1t`/`EL1h` in `SPSR_EL2`, `__compute_hcr()` must set `VCPU_IN_HYP_CONTEXT` and `fixup_guest_exit()` must restore `PSR_MODE_EL2*` in `*vcpu_cpsr(vcpu)` before exit handlers run. When `HCR_VSE` is set, `___activate_traps()`/`___deactivate_traps()` must use `vserror_state_is_nested(vcpu)` to choose between `vcpu->arch.hcr_el2`/`vsesr_el2` and `__ctxt_sys_reg(&vcpu->arch.ctxt, HCR_EL2)`/`VSESR_EL2`, syncing `read_sysreg(hcr_el2) & HCR_VSE` back on exit. [F252, F253, F254]
- `__activate_cptr_traps()` must dynamically compute and write `cptr_el2`/`cpacr_el1` (and `fpexc32_el2` via `__activate_traps_fpsimd32()`) on every trap activation and after `kvm_hyp_handle_fpsimd()` sets `*host_data_ptr(fp_owner) = FP_STATE_GUEST_OWNED` or `kvm_hyp_handle_cpacr_el1()` writes `CPTR_EL2`. After `__deactivate_traps()` in `__kvm_vcpu_run_vhe()` or `__deactivate_cptr_traps()` in `fpsimd_sve_sync()`/`kvm_hyp_handle_fpsimd()`, an `isb()` must precede any FPSIMD, SVE (`ZCR_EL1`/`ZCR_EL2`), `FPMR`, or `FPEXC32_EL2` access. [F251, F346]
- `__sysreg32_restore_state(vcpu)` must precede 64-bit guest sysreg restore in nVHE `__kvm_vcpu_run()` and VHE `__vcpu_load_switch_sysregs()`, and in nVHE all VM sysregs must be restored before `__load_stage2()`. On nVHE with `ARM64_WORKAROUND_SPECULATIVE_AT`, `__sysreg_restore_el1_state()` and `__deactivate_traps()` must set `TCR_EPD1_MASK | TCR_EPD0_MASK` with `isb()` and force `SCTLR_ELx_M` on before switching Stage-2, restoring `SCTLR_EL1`, `isb()`, and `TCR_EL1` only after Stage-2 is configured. [F323, F324]
- Saving/restoring optional registers (`TCR2_EL1`, `PIR_EL1`, `PIRE0_EL1`, `POR_EL1`, `SCTLR2_EL1`, and `_EL2` counterparts) must be gated by `ctxt_has_*()` helpers checking both CPU capability and per-VM `kvm_has_*()`. `SYS_POR_EL0` must be saved/restored on every world switch in `__sysreg_{save,restore}_common_state()` when `ctxt_has_s1poe(ctxt)` holds, never deferred to `__sysreg_{save,restore}_user_state()`. [F320, F347]
- In `__vgic_v3_activate_traps()`, `!(cpu_if->vgic_hcr & ICH_HCR_EL2_En)` must precede `else if (!cpu_if->vgic_sre)` so a disabled vGIC sets `ICC_SRE_EL1 = ICC_SRE_EL1_SRE` and traps at EL2. When `!cpu_if->vgic_sre`, `__vgic_v3_activate_traps()` must write `0` to `ICC_SRE_EL1` and `isb()` before writing `ICH_VMCR_EL2` and before `__vgic_v3_restore_state()`. [F289, F326]
- Fast EL2 exit dispatch tables (`hyp_exit_handlers` in `vhe/switch.c`, `hyp_exit_handlers` and `pvm_exit_handlers` in `nvhe/switch.c`) must be updated in lockstep. In `kvm_handle_pvm_sys64()`, `kvm_hyp_handle_sysreg()` must precede `kvm_handle_pvm_sysreg()`. In `nvhe/sys_regs.c`, `pvm_sys_reg_descs[]` must be strictly ascending in `(Op0, Op1, CRn, CRm, Op2)` with no duplicates (`kvm_check_pvm_sysreg_table()`). [F264, F273, F288]
- In pKVM: `pkvm_hyp_vcpu_to_hyp_vm()` uses `container_of(hyp_vcpu->vcpu.kvm, struct pkvm_hyp_vm, kvm)`, so `hyp_vcpu->vcpu.kvm` must point to `&hyp_vm->kvm` (never `host_kvm`), and mapping/unmapping `pkvm_hyp_vm` in `__pkvm_init_vm()`/`__pkvm_teardown_vm()` must use `pkvm_get_hyp_vm_size(nr_vcpus)`. `pkvm_init_features_from_host()` must copy `host_kvm->arch.midr_el1` to `hyp_vm->kvm.arch.midr_el1` when `KVM_ARCH_FLAG_WRITABLE_IMP_ID_REGS` is set, and `flush_hyp_vcpu()`/`sync_hyp_vcpu()` must call `flush_debug_state()`/`sync_debug_state()`. [F248, F249, F310, F317]
- `host_stage2_force_pte_cb()` must force PTE mappings in `host_mmu.pgt` whenever `prot` is not `PKVM_HOST_MEM_PROT` or `PKVM_HOST_MMIO_PROT`, and `stage2_set_prot_attr()` must reject `KVM_PGTABLE_PROT_DEVICE | KVM_PGTABLE_PROT_NORMAL_NC` with `-EINVAL`. `__pkvm_host_share_guest()`/`__pkvm_host_unshare_guest()` must update `page->host_share_guest_count`, `set_host_state()`, and guest Stage-2 PTE (`PKVM_PAGE_SHARED_BORROWED`) in lockstep under `host_mmu.lock` and `vm->lock`, resetting to `PKVM_PAGE_OWNED` only when `host_share_guest_count == 0` and rejecting `PKVM_PAGE_SHARED_OWNED` pages with `host_share_guest_count == 0` (`-EPERM`) in `__pkvm_host_share_guest()`. [F256, F257, F291, F292]

## Synchronization
- Lock ordering in pKVM (`mem_protect.c`, `pkvm.c`): `vm_table_lock` ranks outside `host_lock_component()` (`host_mmu.lock`), which must always precede `hyp_lock_component()` (`pkvm_pgd_lock`) or `guest_lock_component(vm)` (`vm->lock`). Never acquire `vm_table_lock` (`get_pkvm_hyp_vm()`/`put_pkvm_hyp_vm()`) while holding `host_mmu.lock` or `pkvm_pgd_lock`, nor `host_lock_component()` while holding `hyp_lock_component()` or `guest_lock_component(vm)`. [F215, F218]
- In `struct hyp_page`, `__host_state` and `host_share_guest_count` require `host_mmu.lock`, `__hyp_state_comp` requires `pkvm_pgd_lock`, and guest Stage-2 PTEs require `vm->lock`, held continuously across checks and updates; `guest_lock_component(vm)` must also bracket any `vm->pgt` walk invoking `vm->mm_ops` (`guest_s2_*` dereference per-CPU `current_vm->pool`). `vm_table_lock` protects `vm_table` (`get_vm_by_handle()`), `hyp_virt_to_page(hyp_vm)->refcount` (`get_pkvm_hyp_vm()`, `put_pkvm_hyp_vm()`, `pkvm_load_hyp_vcpu()`, `pkvm_put_hyp_vcpu()`), `hyp_vcpu->loaded_hyp_vcpu`, `hyp_vm->vcpus[]`, and `kvm_init_pvm_id_regs()`. [F198, F214, F217]
- When installing a valid leaf or table PTE in `hyp_map_walker_try_leaf()`, `hyp_map_walker()`, or `stage2_make_pte()`, child table initialization, `mm_ops->get_page(ctx->ptep)`, and (in `stage2_map_walker_try_leaf()` after `stage2_try_break_pte()`) `mm_ops->dcache_clean_inval_poc` and `mm_ops->icache_inval_pou` must complete before `smp_store_release(ctx->ptep, new)`. [F211, F349]
- In `nvhe/ffa.c`, `host_buffers.lock` protects `host_buffers`, `hyp_buffers`, and `ffa_desc_buf`; in `__do_ffa_mem_xfer()` and `do_ffa_mem_frag_tx()`, it must be held continuously while copying `host_buffers.tx` into `hyp_buffers.tx` via `memcpy()` before parsing descriptors or calling `ffa_host_share_ranges()`, and across the SMC to EL3. [F219, F258]
- In `psci_cpu_on()`, `try_acquire_boot_args(boot_args)` (`atomic_cmpxchg_acquire`) must precede writing `boot_args->pc`/`r0` and `wmb()` before `psci_call()`. Ownership of `cpu_on_args.lock` transfers to `__kvm_host_psci_cpu_entry(true)` (which must read `r0`/`pc` before `release_boot_args()`) iff `psci_call()` returns `PSCI_RET_SUCCESS`; otherwise `psci_cpu_on()` must call `release_boot_args(boot_args)`. [F205, F210]
- In `vhe/switch.c`, `__vcpu_load_activate_traps()` and `__vcpu_put_deactivate_traps()` must wrap `__activate_traps_common()` and `__deactivate_traps_common()` in `local_irq_save`/`local_irq_restore`. In `nvhe/mem_protect.c` and `nvhe/mm.c`, `__apply_guest_page()` must map guest pages via `hyp_fixmap_map`/`unmap` or locked `hyp_fixblock_map`/`unmap`, and `fixmap_clear_slot()` must issue inner-shareable `vale2is` TLBI. [F345, F348]

## Object Lifetimes
- `stage2_pte_is_counted()` counts both valid and non-zero invalid PTEs, so `stage2_try_break_pte()`, `stage2_make_pte()`, and `stage2_map_walker_try_leaf()` must balance `get_page()`/`put_page()` on `ctx->ptep`, and `stage2_map_walk_leaf()` must call `mm_ops->put_page(childp)` if `stage2_try_break_pte()` fails. [F191]
- `hyp_pin_shared_mem(from, to)` and `hyp_unpin_shared_mem(from, to)` operate on `[ALIGN_DOWN(from, PAGE_SIZE), PAGE_ALIGN(to))`, mapping into `pkvm_pgtable` on `p->refcount` 0->1 and unmapping at `refcount == 1` before decrementing; `__pkvm_host_unshare_hyp()` returns `-EBUSY` while `hyp_page_count((void *)virt)` is non-zero. Callers with a `void *` multi-page buffer (`sve_state`) must pass `from + byte_size`, not `buf + 1`. [F196, F311]
- In `nvhe/page_alloc.c`, all `struct hyp_page` refcount changes and buddy-tree updates for a `hyp_pool` require the same `pool->lock` critical section; high-order `hyp_alloc_pages()` allocations must be split with `hyp_split_page()` before freeing order-0 pages with `hyp_put_page()`. Only the head `struct hyp_page` of a coalesced buddy page may have a valid `p->order` (tail pages must have `HYP_NO_ORDER`), and shifts by `order` (`PAGE_SIZE << p->order`, `1 << order`) must only be evaluated on head pages before `p->order = HYP_NO_ORDER`. [F199, F265, F306]

## API Contracts
- `kvm_pgtable_stage2_free_unlinked()` drops the final reference on the root `pgtable` page via `mm_ops->put_page(pgtable)` after freeing child subtrees, so callers (`kvm_pgtable_stage2_create_unlinked()`, `stage2_split_walker()`) must not call `mm_ops->put_page(pgtable)` again. `kvm_pgtable_stage2_split()` requires `mc` to be `&mmu->split_page_cache` of the target `struct kvm_s2_mmu`. [F190, F316]
- `_kvm_pgtable_walk()` must reject `data->addr > BIT(pgt->ia_bits)` or `data->end > BIT(pgt->ia_bits)` with `-ERANGE` before `kvm_pgd_page_idx()`, `__kvm_pgtable_walk()` must reject levels outside `[KVM_PGTABLE_FIRST_LEVEL, KVM_PGTABLE_LAST_LEVEL]`, and page-table level variables/parameters (`kvm_granule_shift()`, `kvm_pgd_page_idx()`, `__kvm_pgtable_walk()`, `kvm_pgtable_hyp_init()`) must use signed types (`s8` or `int`). `kvm_pgtable_hyp_unmap()` requires `pgt->mm_ops->page_count != NULL` (else returning `0`) and returns `u64` unmapped bytes, so callers must check `!= size` for failure. [F225, F282, F303, F356]
- TLB invalidation contracts: when leaf level is unknown (range flushes in `__kvm_tlb_flush_vmid_range()` or zapping table PTEs `kvm_pte_table(ctx->old, ctx->level)` in `hyp_unmap_walker()` and `stage2_unmap_put_pte()`), pass `TLBI_TTL_UNKNOWN` (never `0` or `ctx->level`). `__tlbi_level(ipas2e1*, ipa, level)` requires `ipa >>= 12`, whereas `__flush_s2_tlb_range_op()` takes an unshifted byte `start` aligned to `stride` and `pages` as a page count. In `vhe/tlb.c`, `__kvm_tlbi_s1e2()` takes a nullable `mmu` and must guard `enter_vmid_context()`/`exit_vmid_context()` with `if (mmu)`. [F234, F245, F246]
- In `nvhe/mem_protect.c`: range operations (`host_stage2_set_owner_locked()`, `__host_check_page_state_range()`) must validate that `[addr, addr + size)` lies within a single `memblock_region` via `range_is_memory()` or `check_range_allowed_memory()` (not `addr_is_memory()`). `__guest_check_transition_size()` restricts guest Stage-2 transitions (`share`, `unshare`, `wrprotect`, `test_clear_young`) to `nr_pages == 1` or a PMD-aligned block. Callers of `assert_host_shared_guest(vm, ipa, size)` that may hit block or page mappings (`__pkvm_host_relax_perms_guest()`, `__pkvm_host_mkyoung_guest()`) must pass `size = 0`. [F242, F266, F281]
- In `nvhe/page_alloc.c`, unlinking from `pool->free_area` must use `page_remove_from_list(p)` (zeroing the embedded `list_head`), never `list_del()`. Callers of `hyp_pfn_to_phys(pfn)` must pass a 64-bit integer operand (`(pfn) << PAGE_SHIFT` is evaluated before casting). `__get_fault_info()` sets `HPFAR_EL2_NS` only when a valid fault IPA is resolved, so callers must check `fault.hpfar_el2 & HPFAR_EL2_NS` before reading `HPFAR_EL2_FIPA`. [F240, F294, F301]

## Error Handling
- In `nvhe/ffa.c`, `do_ffa_rxtx_map()` (under `host_buffers.lock`) acquires `ffa_map_hyp_buffers()`, `__pkvm_host_share_hyp()`, and `hyp_pin_shared_mem()` in order and unwinds in reverse; `do_ffa_rxtx_unmap()` must unpin, unshare, and `NULL` `host_buffers.tx`/`rx` before `ffa_unmap_hyp_buffers()`. `__ffa_host_share_ranges()`/`__ffa_host_unshare_ranges()` return the `u32` count of processed ranges, which `ffa_host_share_ranges()`/`ffa_host_unshare_ranges()` must roll back when `< nranges` (`FFA_RET_DENIED`). `__do_ffa_mem_xfer()` and `do_ffa_mem_frag_tx()` must call `ffa_host_unshare_ranges()` on SMC failure, `do_ffa_mem_frag_tx()` must call `ffa_mem_reclaim()` if `ffa_host_share_ranges()` fails, and `do_ffa_mem_frag_tx()`, `__do_ffa_mem_xfer()`, and `do_ffa_mem_reclaim()` must keep `ret == 0` on SMC failure and call `ffa_to_smccc_res(res, ret)` only when `ret != 0`. [F202, F203, F230, F235]
- `__vgic_v2_perform_cpuif_access()` and `__vgic_v3_perform_cpuif_access()` return `1` (handled), `0` (unhandled), and `-1` (v2: promote to `ARM_EXCEPTION_EL1_SERROR`); callers must compare against `1` and `-1` rather than testing as a boolean. `allocate_vm_table_entry()`, `find_free_vm_table_entry()`, and `__pkvm_reserve_vm()` return negative errno on failure and must be checked in a signed `int` (`< 0`) before `idx_to_vm_handle()`. [F226, F229]

## External Contracts
- Host-initiated guest Stage-2 MMU hypercalls (`handle___pkvm_host_*_guest`, `handle___pkvm_tlb_flush_vmid`) must reject protected VMs via `!pkvm_hyp_vcpu_is_protected(hyp_vcpu)` or `get_np_pkvm_hyp_vm()`. `handle___pkvm_create_private_mapping()` must encode failure as `(unsigned long)ERR_PTR(err)` in `cpu_reg(host_ctxt, 1)`, `kvm_host_psci_handler()` must zero `cpu_reg(host_ctxt, 1..3)` after writing `cpu_reg(host_ctxt, 0) = ret`, and `__vgic_v2_perform_cpuif_access()` must reject accesses where `kvm_vcpu_dabt_get_as(vcpu) != sizeof(u32)` or `fault_ipa & 3` and byte-swap with `__kvm_swab32()` when `__is_be(vcpu)`. [F228, F241, F278, F363]

## Known Pitfalls
- In `__kvm_pgtable_visit()`, after `kvm_pgtable_visitor_cb()` for `KVM_PGTABLE_WALK_TABLE_PRE` or `KVM_PGTABLE_WALK_LEAF`, `ctx.old` must be reloaded via `READ_ONCE(*ptep)` and `table = kvm_pte_table(ctx.old, level)` recomputed before advancing `data->addr` or descending into `childp`. In `stage2_try_break_pte()`, when flushing TLBs for a broken table PTE, `ctx->addr` must be aligned down to `kvm_granule_size(ctx->level)` before `kvm_tlb_flush_vmid_range()`. [F259, F342]
- In `nvhe/sys_regs.c`, every `pvm_ftr_bits` array passed to `get_restricted_features()` must end with `FEAT_END` (`{ .width = 0 }`), values (`min_signed`, `sys_val`, `pvm_max`) must be widened to 64-bit unsigned types before shifting by `shift`, and when `restrictions[i].sign` is true and either `sys_val` or `pvm_max` has its sign bit set (`>= 1UL << (width - 1)`), `max(sys_val, pvm_max)` must be used instead of `min()`. [F274, F290, F302]
- In `__activate_cptr_traps_vhe()`, nested guest FP/SVE trap state in `cptr` is tested via bit 0 of `FPEN` and `ZEN` (`!(SYS_FIELD_GET(CPACR_EL1, FPEN, cptr) & BIT(0))`), clearing the entire `CPACR_EL1_FPEN` or `CPACR_EL1_ZEN` field in `val` when bit 0 is clear. [F286]
