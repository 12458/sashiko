# SCHEDULER — kernel/sched (part 4)

Core internal scheduler header (`sched.h`), RT (`rt.c`) and Stop (`stop_task.c`) classes, PELT (`pelt.c`, `pelt.h`) and global load-average (`loadavg.c`), scheduler syscalls (`syscalls.c`), SMP/NUMA topology (`topology.c`), `/proc/schedstat` (`stats.c`, `stats.h`), and standard (`wait.c`), bit/var (`wait_bit.c`), and simple (`swait.c`) waitqueues.

## Architecture & Data Flow
- `struct sched_class` instances must use `DEFINE_SCHED_CLASS(name)` between `__sched_class_highest` and `__sched_class_lowest` (`sched_class_above(a, b)` is `a < b`). In `next_active_class()`, skipping `fair_sched_class` (`scx_switched_all()`) must precede the separate `if` skipping `ext_sched_class` (`!scx_enabled()`). In `put_prev_set_next_task()`, `__put_prev_set_next_dl_server(rq, prev, next)` must run even when `next == prev`. [F445, F467, F484]
- `rq->nr_uninterruptible` is modified under `rq->__lock`; per-CPU counts can be negative across migrations and only the cross-CPU sum is valid. `struct rq::nr_pinned` (`RQ_nr_pinned`) must be `unsigned int` for `this_rq_pinned()`. On 64-bit, `scale_load_down(w)` clamps non-zero `w >> SCHED_FIXEDPOINT_SHIFT` to `>= 2UL` (`MIN_SHARES`). `uclamp_bucket_id()` must clamp `clamp_value / UCLAMP_BUCKET_DELTA` to `UCLAMP_BUCKETS - 1`. [F379, F494, F495, F529]
- In `rt.c`, `sched_rt_entity *rt_se` may be a group (`rt_se->my_q != NULL`); check `rt_entity_is_task(rt_se)` or `!group_rt_rq(rt_se)` before `rt_task_of(rt_se)`. `dequeue_rt_stack()` must dequeue top-down from root to `rt_se` before `dequeue_top_rt_rq()` because parent `rt_se_prio()` reads child `rt_rq->highest_prio.curr`. [F409, F423]
- `rt_prio_array::bitmap` has `MAX_RT_PRIO + 1` bits (sentinel bit `MAX_RT_PRIO` always set), while `array->queue` has `MAX_RT_PRIO` entries; check `idx < MAX_RT_PRIO` before indexing `queue`. `inc_rt_prio_smp()` / `dec_rt_prio_smp()` call `cpupri_set()` only when `rt_rq == &rq->rt && rq->online`. `enqueue_pushable_task()` / `dequeue_pushable_task()` must update `highest_prio.next`, `overloaded`, `rto_mask`, and `rto_count` in lockstep; `set_next_task_rt()` must call `dequeue_pushable_task()`. When `do_sched_rt_period_timer()` unthrottles a runnable `rt_rq` on an idle CPU, it must call `rq_clock_cancel_skipupdate(rq)`. [F424, F425, F427, F454]
- In `__sched_setscheduler()`, if `pi && rt_effective_prio(p, newprio) == oldprio`, clear `DEQUEUE_MOVE` from `queue_flags`; `move_entity()` skips relisting only when `(flags & (DEQUEUE_SAVE | DEQUEUE_MOVE)) == DEQUEUE_SAVE`. Enforce `attr->sched_priority <= MAX_RT_PRIO - 1` and `rt_policy(policy) == (attr->sched_priority != 0)` before `__setscheduler_params()`. Entering RT/DL sets `p->timer_slack_ns = 0`; leaving restores `p->default_timer_slack_ns` if `timer_slack_ns == 0`. Preserve `p->uclamp_req[clamp_id]` with `uc_se->user_defined` unless `SCHED_FLAG_UTIL_CLAMP_{MIN,MAX}` is set (`-1` clears `user_defined`). [F432, F433, F434, F451, F474]
- Allocations of `sched_domain`, `sched_group`, `sched_group_capacity`, and `asym_cap_data` must add `cpumask_size()` to `sizeof(...)`. `sched_domain_topology_level` arrays must end with `{ .mask = NULL }`. `sd->groups` is circular (built via `for_each_cpu_wrap(i, span, cpu)`), terminating at `sg == sd->groups`. In `build_sched_domains()`, the `claim_allocations()` / `init_sched_groups_capacity()` loop must iterate CPUs descending (`nr_cpumask_bits - 1` down to `0`). [F462, F465, F486, F498]
- In `cpu_attach_domain()`, advance `tmp = tmp->parent` only in the `else` branch when `!sd_parent_degenerate(tmp, parent)`, and call `update_top_cache_domain(cpu)` (`sd_llc_id` set before `sd_share_id`). `highest_flag_domain()` may break early on `!(sd->flags & flag)` only if `flag & SD_SHARED_CHILD_MASK`. `partition_sched_domains_locked()` must call `dl_rebuild_rd_accounting()`, and `rq_attach_root()` must call `__dl_server_attach_root(&rq->fair_server, rq)` when `rq->fair_server.dl_server` is set. [F435, F436, F437, F481, F483]
- `decay_load(val, n)` returns `0` if `n > LOAD_AVG_PERIOD * 63`, shifts `val >>= local_n / LOAD_AVG_PERIOD`, and reduces `local_n %= LOAD_AVG_PERIOD` before indexing `runnable_avg_yN_inv`. `___update_load_avg()` divides `*_sum` by `get_pelt_divider(sa)`, and `__update_load_avg_se()` calls `cfs_se_util_change(&se->avg)`. On migration (`task_on_rq_migrating(p)`), `__update_stats_wait_end()` stores pre-migration `delta` in `stats->wait_start` for `__update_stats_wait_start()` to subtract. [F440, F441, F458]
- `bit_waitqueue()` and `__var_waitqueue()` share `bit_wait_table`; `wake_bit_function()` and `var_wake_function()` must match both `key->flags` and `key->bit_nr` (`-1` for var waiters; `!test_bit()` for bit waiters), and `var_wake_function()` must never call `test_bit()`. [F443, F509]

## Synchronization
- `rq_clock*()` requires `rq->__lock` and `update_rq_clock(rq)` since `rq_pin_lock()` (unless `RQCF_ACT_SKIP`). Temporary lock drops must pair `rq_unpin_lock(rq, rf)` with `rq_repin_lock(rq, rf)` (never `rq_pin_lock()`) to preserve `RQCF_UPDATED` and call `scx_rq_clock_invalidate(rq)`; `double_lock_balance()` / `double_rq_lock()` must call `double_rq_clock_clear_update()`. On `!CONFIG_64BIT`, `clock_idle`, `clock_pelt_idle`, and `throttled_pelt_idle` require `u64_u32_load()` / `u64_u32_store()`, and `_update_idle_rq_clock_pelt()` orders `clock_idle` before `clock_pelt_idle` with `smp_wmb()`. [F375, F387, F388, F446]
- `calc_global_nohz()` orders `WRITE_ONCE(calc_load_update)` before `calc_load_idx` increment with `smp_wmb()`, pairing with `smp_rmb()` in `calc_load_write_idx()`. `rt_set_overload()` sets `rto_mask` and executes `smp_wmb()` before `atomic_inc(&rd->rto_count)`, pairing with `smp_rmb()` in `pull_rt_task()` and `atomic_read_acquire(&rd->rto_loop_next)` in `rto_next_cpu()`. [F378, F394]
- `rt_rq->rt_runtime_lock` and `rt_b->rt_runtime_lock` nest inside `rq->__lock`, and `rt_b->rt_runtime_lock` must be acquired before `rt_rq->rt_runtime_lock`. Before `stop_one_cpu_nowait(..., push_cpu_stop, ...)` in `push_rt_task()` / `pull_rt_task()`, call `get_push_task()` under `rq->__lock` and bracket `raw_spin_rq_unlock()` and `stop_one_cpu_nowait()` with `preempt_disable()` / `preempt_enable()`. [F396, F517, F520]
- In `__sched_setscheduler()`, `uclamp_validate()` and `cpuset_lock()` (when `dl_policy`) must precede `task_rq_lock(p, &rf)`, with `cpuset_unlock()` after `task_rq_unlock()` on all exit, error, and `recheck` paths (retrying if `oldpolicy != -1 && oldpolicy != p->policy`). At exit, disable preemption before `splice_balance_callbacks(rq)` and `task_rq_unlock()`, then run `rt_mutex_adjust_pi(p)` and `balance_callbacks(rq, head)` before `preempt_enable()`. In `yield_to()`, recheck `task_rq(p) == p_rq` after `double_rq_lock(rq, p_rq)`. [F368, F399, F400, F401]
- In `sched_getparam()`, `sched_getattr()`, and `sched_rr_get_interval()`, `scoped_guard(rcu)` and `task_rq_lock` must exit before user copies. `walk_tg_tree()`, `for_each_rt_rq()`, `next_task_group()`, and `idle_get_state(rq)` require RCU read lock. `sched_init_numa()` zeroes `sched_domains_numa_levels` before allocation and sets `nr_levels` after RCU publication; `sched_reset_numa()` zeroes it and clears RCU pointers before `synchronize_rcu()` and `kfree()`. [F402, F525, F527, F528]
- In `prepare_to_wait*()`, `set_current_state(state)` must follow waitqueue insertion; on pending signal in `prepare_to_wait_event()` / `prepare_to_swait_event()`, remove the entry via `list_del_init()` under the queue lock before returning `-ERESTARTSYS`. `do_wait_intr*()` is entered/exited with `wq->lock` held and returns `-ERESTARTSYS` on signal with `wait` still queued and `TASK_INTERRUPTIBLE`, leaving cleanup to the caller. [F373, F381, F382]
- In `wait_woken()` and `woken_wake_function()`, `set_current_state(mode)` precedes testing `WQ_FLAG_WOKEN`, and `smp_store_mb()` clearing `WQ_FLAG_WOKEN` pairs with `smp_mb()` before setting it. `swake_up_all()` splices `q->task_list` to a local list and unlinks entries before `raw_spin_unlock_irq(&q->lock)`; IRQ-disabled/hardirq callers must use `swake_up_all_locked()` under `q->lock`. [F380, F384, F471]

## Object Lifetimes
- `__block_task(rq, p)` ends with `smp_store_release(&p->on_rq, 0)`; never dereference `p` afterwards without `p->pi_lock` or a refcount. `push_rt_task()` must pin `next_task` with `get_task_struct()` before `find_lock_lowest_rq()` (which rechecks `!is_migration_disabled(task)`, `cpus_mask`, and `task == pick_next_pushable_task(rq)` if `double_lock_balance()` dropped `rq->__lock`), and call `put_task_struct(next_task)` before `goto retry`. [F366, F391, F395]
- `rq_attach_root()` decrements `old_rd->refcount` before incrementing `rd->refcount` and frees via `call_rcu(&old_rd->rcu, free_rootdomain)` after unlocking `rq`, so never pass `rd == rq->rd` when `refcount == 1`. `rd->rto_loop` and `rd->rto_cpu` require `rd->rto_lock` (resetting `rto_cpu = -1` at `>= nr_cpu_ids` and repeating only if `atomic_read_acquire(&rd->rto_loop_next) != rd->rto_loop`), pairing `sched_get_rd()` in `tell_cpu_to_push()` with `sched_put_rd()` in `rto_push_irq_work_func()`. [F364, F397, F478]
- `partition_sched_domains_locked()` takes ownership of `doms_new` and `dattr_new` (freeing old `doms_cur != &fallback_doms` and `dattr_cur`). Before `claim_allocations()`, freeing NUMA overlap groups in `build_overlap_sched_groups()` or `__sdt_free()` must pass `free_sgc = 0` to `free_sched_groups()`. `sched_setaffinity()` must call `kfree(ac.user_mask)` after `__sched_setaffinity(p, &ac)`. [F360, F363, F370]
- `finish_wait()` and `finish_swait()` use lockless `!list_empty_careful()` paired with `list_del_init_careful()` in `autoremove_wake_function()`. In `__wait_on_bit_lock()`, when `action` returns non-zero, `finish_wait()` must precede `test_and_set_bit()`. [F374, F383]

## API Contracts
- `task_tick_rt()` and `task_tick_stop()` must use `@rq` and `@p`/`@curr`, never `this_rq()`, `smp_processor_id()`, or `current`. `cpufreq_update_util(rq, flags)` requires `cpu_of(rq)`, RCU-sched lock, `rq->__lock`, and updated `rq` clock. `__sched_setscheduler*()` must not be called in interrupt context when `pi` is true; `sys_sched_setscheduler()` and `sys_sched_setattr()` must reject `(int)attr.sched_policy < 0` with `-EINVAL` before `SETPARAM_POLICY`. [F415, F515, F522, F526]
- `__normal_prio()` maps `rt_prio` to `MAX_RT_PRIO - 1 - rt_prio` and `nice` via `NICE_TO_PRIO(nice)`; `task_prio(p)` subtracts `MAX_RT_PRIO`. `sched_move_task(tsk, for_autogroup)` requires `true` for autogroup and `false` for cgroup moves. On `check_same_owner(p)` failure, `sched_setaffinity()` checks `ns_capable(__task_cred(p)->user_ns, CAP_SYS_NICE)`, while `user_check_sched_setscheduler()` checks global `capable(CAP_SYS_NICE)` after `task_rlimit(p, ...)` checks fail. Under `rt_group_sched_enabled()`, `__sched_setscheduler()` (`user == true`) and `sched_rt_can_attach()` reject RT tasks on non-autogroup groups with `rt_bandwidth_enabled()` and `rt_runtime == 0`. [F416, F418, F540, F541]
- `alloc_rt_sched_group()` and `sched_rt_can_attach()` return `1` on success / `0` on failure; `tg_set_rt_bandwidth()` and `sched_group_set_rt_{runtime,period}()` return `0` or `-errno` (checking `U64_MAX / NSEC_PER_USEC` overflow and mapping `< 0` to `RUNTIME_INF`). `find_lowest_rq()` returns `-1` on failure; check `cpu != -1` before `cpu_rq(cpu)`. `sched_numa_hop_mask()` requires RCU read lock (pointer invalid after unlock) and returns `ERR_PTR()` or `NULL` (check `IS_ERR_OR_NULL()`). `tl->sd_flags()` may only return `TOPOLOGY_SD_FLAGS`, and `set_sched_topology()` must precede `sched_smp_initialized`. [F404, F405, F410, F411, F524, F535]
- Callers of `wake_up_bit()`, `__wake_up_bit()`, and `wake_up_var()` must issue `smp_mb__after_atomic()` or `smp_mb()` before waking. `__wake_up_common()` returns residual `nr_exclusive`, while `__wake_up_common_lock()` / `__wake_up()` return `nr_exclusive - remaining`; `wait_queue_func_t` returns `< 0` to abort, `0` if not woken, `> 0` if woken; `wait_bit_action_f` returns `0` to continue or non-zero errno to abort. [F385, F406, F407]

## Error Handling & External Contracts
- `build_sched_domains()` must pass `alloc_state` from `__visit_domain_allocation_hell()` to `__free_domain_allocs(&d, alloc_state, cpu_map)` on all exit paths. Check `if (tl->sd_flags)` before calling it. In `sched_numa_find_nth_cpu()`, check `rcu_dereference(sched_domains_numa_masks)` and `bsearch()` result `hop_masks` for `NULL`, returning `nr_cpu_ids`. Zero-initialize stack `kattr` and `lp` in `sys_sched_getattr()` / `sys_sched_getparam()`. [F403, F413, F419, F421]
- `sched_copy_attr()` must zero `*attr`, map `size == 0` to `SCHED_ATTR_SIZE_VER0`, require `size >= SCHED_ATTR_SIZE_VER1` for `SCHED_FLAG_UTIL_CLAMP`, and on size errors write `sizeof(*attr)` to `uattr->size` and return `-E2BIG`. Reject `SCHED_FLAG_SUGOV` when `user` is true and mask `kattr.sched_flags &= SCHED_FLAG_ALL` in `sys_sched_getattr()`. `get_user_cpu_mask()` clears `new_mask` when `len < cpumask_size()` and clamps `len`; `sys_sched_getaffinity()` rejects `len * BITS_PER_BYTE < nr_cpu_ids` or unaligned `len`, uses `zalloc_cpumask_var()`, and returns `min(len, cpumask_size())`. Changing `show_schedstat()` requires bumping `SCHEDSTAT_VERSION`, and `schedstat_start()` iterates `cpu_online_mask`. [F414, F449, F450, F452, F539, F543]

## Known Pitfalls
- `__wake_up_common()` must snapshot `curr->flags` before `curr->func` and use `list_for_each_entry_safe_from()`. `bit_wait_timeout()` must snapshot `now = READ_ONCE(jiffies)` once for both `time_after_eq(now, word->timeout)` and `word->timeout - now`. `___update_load_sum()` must check `(s64)delta < 0` before `delta >>= 10` and advance `last_update_time` by `delta << 10`. Use `div_u64()` / `do_div()` for 64-bit divisions in `rt.c` and `DIV_ROUND_UP()` in `watchdog()`. `sched_numa_find_nth_cpu()` must map `node = numa_nearest_node(node, N_CPU)`, `sched_numa_find_closest()` must check `!masks[i][j]`, and `hop_cmp()` must check `b == k->masks` before `*((struct cpumask ***)b - 1)`. [F464, F469, F489, F493, F496, F502]
