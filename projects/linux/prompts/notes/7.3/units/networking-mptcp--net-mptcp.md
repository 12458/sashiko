# NETWORKING [MPTCP] — net/mptcp

Manages MPTCP subflow lifecycle and TCP ULP integration (`subflow.c`), socket options and diagnostics synchronization (`sockopt.c`), connection token hashing (`token.c`), and SYN-cookie state for `MP_JOIN` (`syncookies.c`).

## Architecture & Data Flow
- `mptcp_token_accept()` moves `req->token_node` from `bucket->req_chain` to `msk` in `bucket->msk_chain` without changing `bucket->chain_len`, making `mptcp_token_destroy_request(req)` a no-op and leaving `chain_len` decrement to `mptcp_token_destroy(msk)`. Unlinking in all three functions must use `hlist_nulls_del_init_rcu()` or `__sk_nulls_del_node_init_rcu()` so unhashed checks see a cleared `pprev`. Hashing `msk` into `msk_chain` (`mptcp_token_new_connect()`, `mptcp_token_accept()`) must pair with `sock_prot_inuse_add(..., 1)`, and `mptcp_token_destroy()` must call `sock_prot_inuse_add(..., -1)` and reset `msk->token = 0`. [F172, F221, F257]
- Before overwriting `icsk->icsk_af_ops` in `subflow_ulp_init()` or `mptcpv6_handle_mapped()` (which must first check `icsk->icsk_af_ops == target`), save the old pointer to `subflow->icsk_af_ops` (and propagate it in `subflow_ulp_clone()`). On fallback (`subflow_ulp_fallback()`, `mptcp_subflow_tcp_fallback()`, `mptcp_subflow_ops_undo_override()`), restore `sk_data_ready`, `sk_state_change`, `sk_write_space`, `sk_error_report`, `icsk_af_ops`, and `sk_prot`, while clearing `icsk_ulp_ops`, `icsk_ulp_data`, and `tcp_sk(sk)->is_mptcp`. [F228, F229]
- In `subflow_syn_recv_sock()` and `subflow_ulp_clone()`, check `tcp_rsk(req)->is_mptcp` before dereferencing `mptcp_subflow_rsk(req)` (an unchecked cast). Both IPv4 and IPv6 subflow request-sock slabs in `subflow_ops_init()` allocate `sizeof(struct mptcp_subflow_request_sock)` starting with `struct tcp_request_sock`, requiring `sizeof(struct tcp_request_sock) == sizeof(struct tcp6_request_sock)`. [F276, F280]
- In `mptcp_subflow_create_socket()`, because workqueues can create subflows, `sf->sk` must inherit the parent `msk` socket's cgroup (`mptcp_attach_cgroup()`), upgraded netns refcount (`sk_net_refcnt_upgrade()`), socket options (`mptcp_sockopt_sync_locked()`), and `SOCK_INODE` `i_ino`, `i_uid`, and `i_gid`. [F234]
- In `get_mapping_status()`: expand `mpext->data_seq` via `mptcp_expand_seq(READ_ONCE(msk->ack_seq), mpext->data_seq, mpext->dsn64)` before comparing/assigning `subflow->map_seq`; mask 32-bit (`!mpext->dsn64`) `data_fin_seq = mpext->data_seq + data_len - 1` with `GENMASK_ULL(31, 0)` before `mptcp_update_rcv_data_fin()`; and when setting `subflow->map_valid = 1`, reset `subflow->map_csum_len = 0` and `subflow->map_data_csum = csum_unfold(mpext->csum)` before `validate_data_csum()`. When `mpext->data_fin == 1` and `data_len > 1`, `subflow->map_data_len` stores `data_len - 1`, so `__mptcp_make_csum()` in `get_mapping_status()` and `validate_data_csum()` must receive `subflow->map_data_len + subflow->map_data_fin`. [F230, F244, F245, F269]
- In `get_mapping_status()`, delete accepted/merged extensions via `skb_ext_del(skb, SKB_EXT_MPTCP)`. If a pure `DATA_FIN` (`mpext->data_fin == 1 && data_len == 1`) arrives while `subflow->map_valid` is set, delete the extension and return `MAPPING_OK` (not `MAPPING_DATA_FIN`). If a 0-length skb without a mapping (`!mpext || !mpext->use_map`) arrives while `!subflow->map_valid`, consume it with `sk_eat_skb(ssk, skb)` and return `MAPPING_EMPTY`. [F231, F256, F263]
- When subflow consumption advances `mptcp_subflow_get_map_offset(subflow) >= subflow->map_data_len` in `mptcp_subflow_data_available()` or `mptcp_subflow_discard_data()`, reset `subflow->map_valid = 0` (and `subflow->data_avail = false` in `mptcp_subflow_data_available()`). `mptcp_subflow_discard_data()` must include the `TCPHDR_FIN` byte (`avail_len + fin`) when advancing `tcp_sk(ssk)->copied_seq` across the end of an skb. [F232, F262]
- In `mptcp_subflow_fail()`, if `fail_tout = jiffies + TCP_RTO_MAX` wraps to `0`, set it to `1` before storing `subflow->fail_tout` (`0` means no fail timeout). [F273]
- `sockopt_seq_inc()` must preserve `(u32)sk->sk_state << 24u` in `msk->setsockopt_seq` via `sockopt_seq_reset()` while incrementing the low 24-bit counter. In `mptcp_sol_socket_sync_intval()` and `sync_socket_options()`, updating `ssk->sk_sndbuf` when `SOCK_SNDBUF_LOCK` is set must also update `mptcp_subflow_ctx(ssk)->cached_sndbuf`, and updating `ssk->sk_mark` must call `sk_dst_reset(ssk)` if changed. [F222, F223, F224]
- `mptcp_sockopt_sync_locked()` must keep `ssk->sk_rcvlowat = 0` and `tcp_sk(ssk)->notsent_lowat = UINT_MAX` on subflows, and `subflow_data_ready()` must compare `mptcp_data_avail(msk)` against `parent->sk_rcvlowat`. `mptcp_setsockopt_sol_tcp_congestion()` checks `ns_capable(sock_net(sk)->user_ns, CAP_NET_ADMIN)`, whereas `sync_socket_options()` propagates `msk->ca_name` via `tcp_set_congestion_control(ssk, msk->ca_name, false, true)` without re-checking `current`. [F265, F313]

## Synchronization
- Serialize all `token_bucket` (`req_chain`, `msk_chain`, `chain_len`) mutations under `spin_lock_bh(&bucket->lock)`. Before `__sk_nulls_add_node_rcu()` in `mptcp_token_new_connect()` or `mptcp_token_accept()`, initialize `msk->token` with `WRITE_ONCE()`. [F186, F187]
- In RCU token scans (`mptcp_token_exists()`, `mptcp_token_get_sock()`), check `get_nulls_value(pos) != (token & token_mask)` after `sk_nulls_for_each_rcu()` and retry on mismatch. In `mptcp_token_get_sock()` and `mptcp_token_iter_next()`, take a ref with `refcount_inc_not_zero(&sk->sk_refcnt)` inside `rcu_read_lock()`, revalidate `sock_net(sk)` (and `READ_ONCE(msk->token)` in `mptcp_token_get_sock()`), and `sock_put(sk)` + retry on mismatch. [F188, F189]
- `subflow_init_req_cookie_join_save()` and `mptcp_token_join_cookie_init_state()` must hold `spin_lock_bh(&join_entry_locks[i])` across the entire check, `e->valid` transition, `mptcp_token_get_sock()` lookup, and field copy of `join_entries[i]`. [F190]
- `mptcp_subflow_queue_clean()` must splice out `queue->rskq_accept_head/tail` under `queue->rskq_lock` and call `release_sock(listener_ssk)` before locking each unaccepted child's `mptcp_sock` (`sk = subflow->conn`) and calling `mptcp_cancel_work(sk)`, then re-lock `listener_ssk` and restore `rskq_accept_head/tail`. [F184]
- In `__subflow_state_change()`, dereference `rcu_dereference(sk->sk_wq)` inside `rcu_read_lock()` covering both `skwq_has_sleeper(wq)` and `wake_up_interruptible_all(&wq->wait)`. [F293]
- `mptcp_diag_fill_info()` must call `unlock_sock_fast(sk, slow)` before acquiring `mptcp_data_lock(sk)` (`spin_lock_bh(&sk->sk_lock.slock)`). In `sockopt.c`, setsockopt helpers delegating to `sock_setsockopt(sk->sk_socket, ...)` or `ip_setsockopt(sk, ...)` on `sk` must do so before `lock_sock(sk)`. In `mptcp_getsockopt_tcpinfo()`, `mptcp_getsockopt_subflow_addrs()`, and `mptcp_getsockopt_full_info()`, iterate `mptcp_for_each_subflow()` under `lock_sock(sk)` and call `release_sock(sk)` before returning `-EFAULT` on `copy_to_user()` failure. [F199, F296, F298]

## Object Lifetimes
- When `subflow_syn_recv_sock()` attaches a passive `MP_JOIN` child to `msk`, transfer `subflow_req->msk` to `ctx->conn` and set `subflow_req->msk = NULL` to prevent double-put in `subflow_req_destructor()` or `dispose_child`'s `mptcp_subflow_drop_ctx()`. [F173]
- `mptcp_subflow_reset()` must hold `sock_hold(sk)` on `sk = subflow->conn` across `tcp_done(ssk)` and `mptcp_schedule_work(sk)`, because `tcp_done(ssk)` calls `subflow_ulp_release(ssk)`, dropping `ctx->conn`'s ref. Once a kernel subflow socket `sf` is in `msk->conn_list` and grafted via `mptcp_sock_graft(ssk, sk->sk_socket)`, discard `sf` via `iput(SOCK_INODE(sf))` rather than `sock_release(sf)`. [F178, F180]
- Publish `icsk->icsk_ulp_data` (`struct mptcp_subflow_context`) with `rcu_assign_pointer()`, clear it with `rcu_assign_pointer(icsk->icsk_ulp_data, NULL)` in `subflow_ulp_fallback()`, and free via `kfree_rcu(ctx, rcu)`. In `subflow_ulp_release()`, if `ctx->conn` is non-NULL, call `kfree_rcu(ctx, rcu)` only when `ctx->disposable || list_empty(&ctx->node)`; otherwise schedule `MPTCP_WORK_CLOSE_SUBFLOW` on `ctx->conn` for `__mptcp_close_ssk()`. [F181, F292]

## API Contracts
- On `dispose_child` in `subflow_syn_recv_sock()`, set `tcp_rsk(req)->drop_req = true`, call `inet_csk_prepare_for_destroy_sock(child)` and `tcp_done(child)`, and return the non-NULL `child` so the TCP caller drops the final ref. [F174]
- `subflow_ulp_init()` must return `-EOPNOTSUPP` if `!sk->sk_kern_sock`. `subflow_ulp_clone()` must pass its `gfp_t priority` argument to `subflow_create_ctx(newsk, priority)` (not `GFP_KERNEL`). `mptcp_propagate_state()` must guard `msk->snd_una`, `msk->wnd_end`, and `subflow_set_remote_key()` updates with `if (mp_opt)`. [F211, F294, F299]
- `subflow_generate_hmac(key1, key2, nonce1, nonce2, hmac)` takes sender `(key1, nonce1)` and receiver `(key2, nonce2)` (local first when generating, remote first when validating), and a `SHA256_DIGEST_SIZE` (32-byte) `hmac` buffer (not the 20-byte `subflow->hmac`). On a SYN-cookie third ACK (`!th->syn`), `mptcp_join_entry_hash()` and `mptcp_subflow_init_cookie_req()` must use `TCP_SKB_CB(skb)->seq - 1`. [F215, F217]
- Callers of `__mptcp_nmpc_sk(msk)` must hold `lock_sock((struct sock *)msk)`, check `IS_ERR(ssk)`, and not call `sock_put(ssk)`. In `mptcp_setsockopt()`, non-`SOL_SOCKET` options must pass `mptcp_supported_sockopt(level, optname)` before checking `__mptcp_tcp_fallback(msk)` or dispatching. `mptcp_get_subflow_data()` and `mptcp_get_full_info()` return negative errno or non-negative residual byte count; store in signed `int` and test `< 0`. [F185, F201, F254]
- `token_hash` has `token_mask + 1` buckets (`0..token_mask`) with `hlist_nulls` heads initialized to the bucket index; `mptcp_token_iter_next()` iterates `slot <= token_mask` and counts 1-based `num` in `msk_chain` (skipping `num <= *s_num`). Guard KUnit-only token exports with `#if IS_MODULE(CONFIG_MPTCP_KUNIT_TEST)`, and in `token_test.c` (`build_msk()`), initialize mock `sk->sk_protocol = IPPROTO_MPTCP` and `sk->sk_prot`. [F249, F282, F304]

## Error Handling
- `subflow_token_join_request()` must `sock_put((struct sock *)msk)` if `mptcp_pm_get_local_id()` returns `< 0`. `subflow_v4_route_req()` and `subflow_v6_route_req()` must call `dst_release(dst)` before returning `NULL` if `subflow_check_req()` fails. Always call `subflow_init_req()` on new or cookie-reconstructed `mptcp_subflow_request_sock` (allocated from `SLAB_TYPESAFE_BY_RCU` without `__GFP_ZERO`) to clear `mp_capable`, `mp_join`, `msk`, and `token_node.pprev`. [F175, F177, F213]
- Check `sk_is_mptcp(ssk)`, `ctx`, and `ctx->conn` for NULL in `mptcp_subflow_queue_clean()`, `mptcp_subflow_drop_ctx()`, and `subflow_ulp_release()` (since `subflow_ulp_fallback()` clears ULP state). Check `sk->sk_socket` for NULL in `mptcp_subflow_create_socket()` and `subflow_error_report()` (unaccepted server `sk` has `sk_socket == NULL`). [F207, F209]
- Check `mpext = mptcp_get_ext(skb)` for NULL and `mpext->use_map` in `get_mapping_status()`, and check `skb_ext_add()` for NULL and `memset(mpext, 0, sizeof(*mpext))` in `subflow_add_reset_reason()`. In `mptcp_setsockopt_sol_tcp_congestion()`, require `optlen >= 1`, bound `strncpy_from_sockptr()` to `min_t(long, TCP_CA_NAME_MAX - 1, optlen)`, and set `name[ret] = 0`. Record wire-protocol errors via `MPTCP_INC_STATS` / `SUBFLOW_REQ_INC_STATS` and `pr_debug`, never `WARN_ON*` or unratelimited `pr_warn`/`pr_err`. [F210, F243, F315]

## External Contracts
- `memset()` output structs (`mptcp_info`, `mptcp_subflow_addrs`, `mptcp_subflow_info`) to zero before any early return or conditional assignment in `mptcp_diag_fill_info()`, `mptcp_get_sub_addrs()`, and `mptcp_getsockopt_full_info()`. [F214]
- `mptcp_get_subflow_data()` and `mptcp_get_full_info()` must reject user `u32` size fields `> INT_MAX` and non-zero kernel-output fields (`num_subflows`, `size_kernel`, `size_tcpinfo_kernel`, `size_sfinfo_kernel`) with `-EINVAL`. `mptcp_get_full_info()` requires `*optlen >= MIN_FULL_INFO_OPTLEN_SIZE` (40) and copies only 40 bytes from userspace. [F239, F310]
- `mptcp_getsockopt_tcpinfo()` and `mptcp_getsockopt_subflow_addrs()` write subflow entries at `optval + sfd.size_subflow_data`, and `mptcp_put_subflow_data()` sets `*optlen` to `sfd->size_subflow_data + copied` (`copied > 0`) or `min(sfd->size_subflow_data, sizeof(*sfd))` (`copied == 0`). `mptcp_getsockopt_full_info()` must increment `sfcount` for all subflows in `msk->conn_list` while copying/advancing `sfinfoptr` and `tcpinfoptr` by clamped `mfi.size_sfinfo_user` and `mfi.size_tcpinfo_user` only when pre-incremented `sfcount < mfi.size_arrays_user`. [F238, F240]
- `mptcp_getsockopt_info()` must return `0` immediately when `*optlen == 0`. `mptcp_put_int_option()` writes a single `unsigned char` with `*optlen = 1` when `0 < *optlen < sizeof(int)` and `0 <= val <= 255`. `mptcp_getsockopt_sol_tcp()` must divide fallback `sysctl_tcp_keepalive_time` and `sysctl_tcp_keepalive_intvl` by `HZ`. [F219, F241, F242]

## Known Pitfalls
- In `skb_is_fully_mapped()` and `mptcp_subflow_discard_data()`, verify `tp->copied_seq - TCP_SKB_CB(skb)->seq <= skb->len` before subtracting from `skb->len`. Compare 32-bit sequence numbers with `before()` in `validate_mapping()` and `mptcp_subflow_discard_data()`, and 64-bit DSNs with `before64()` in `subflow_check_data_avail()` and `mptcp_subflow_discard_data()`, clamping `u64` `old_ack - ack_seq` to `u32 avail_len` before narrowing to `u32 incr`. In `validate_data_csum()`, check `skb_queue_is_last(&ssk->sk_receive_queue, skb)` before `skb = skb->next`. [F246, F258, F271, F272]
- In `mptcp_setsockopt_sol_tcp()`, handle non-`int` options (`TCP_CONGESTION`, `TCP_FASTOPEN_KEY`) and `mptcp_setsockopt_first_sf_only()` callers in the first `switch` before `mptcp_get_int_option()` and `lock_sock(sk)`. Apply pre-connect options to `ssk` first and mirror to `sk` in `mptcp_setsockopt_sol_socket()` and `mptcp_setsockopt_v6()`, but apply to `sk` via `ip_setsockopt()` first and mirror to `ssk` in `mptcp_setsockopt_sol_ip_set()`. In `mptcp_set_rcvlowat()`, reject `sk->sk_protocol == IPPROTO_TCP` before calling `mptcp_sk(sk)` helpers (BPF can pass a grafted subflow `tcp_sock`). [F255, F264, F275]
