# QCOM AUDIO (ASoC) DRIVERS — sound/soc/codecs (part 2)

Qualcomm ASoC codec drivers for WCD9340/WCD9341 (SLIMbus/MFD), WCD9370/WCD9375 (SoundWire), and the SoundWire slave transport layer for WCD9380/WCD9385, implementing DAI operations, clock gate providers, SoundWire port/stream management, interrupt domains, MBHC impedance measurement, and DAPM audio routing.

## Architecture & Data Flow
- In `wcd934x_codec_probe`, static const templates `wcd934x_rx_chs` and `wcd934x_tx_chs` must be `memcpy`'d into per-instance `wcd->rx_chs` and `wcd->tx_chs`, and `wcd934x_set_channel_map` must call `INIT_LIST_HEAD` on their `.list` nodes before SLIMbus routing controls use them. [F170]
- In `slim_rx_mux_put` and `slim_tx_mixer_put`, removing a channel node from `wcd->dai[...].slim_ch_list` must use `list_del_init()` (never `list_del()`), and adding a node must check `list_empty()` and no-op when the control value is unchanged. [F136]
- In `wcd934x_rx_chs`, SLIMbus RX channels store `.port = p + WCD934X_RX_START` (16..28) and `.shift = p` (0..12); code indexing RX arrays (`wcd->rx_chs`, `wcd->rx_port_value`) or RX interrupt registers (`WCD934X_SLIM_PGD_PORT_INT_EN0`) must subtract `WCD934X_RX_START` from `ch->port`. [F187]
- In `wcd9370_probe` and `wcd9380_probe`, only the TX SoundWire slave (`wcd->is_tx`) initializes `wcd->regmap` via `devm_regmap_init_sdw` and must immediately call `regcache_cache_only(wcd->regmap, true)` until `wcd_update_status` syncs the cache upon `SDW_SLAVE_ATTACHED`. [F210]
- In `wcd9370_probe` and `wcd9380_probe`, the highest bit in `pdev->prop.source_ports` and `pdev->prop.sink_ports` must not exceed `WCD937X_MAX_SWR_PORTS - 1` or `WCD938X_MAX_SWR_PORTS - 1`, because `GENMASK` is inclusive and the masks index 0-based `wcd937x_dpn_prop` and `wcd938x_dpn_prop`. [F184]
- `wcd937x_connect_port` must update both `wcd->port_config[port_idx - 1].ch_mask` and `wcd->master_channel_map[sdev->m_port_map[port_num]]` in lockstep, and `wcd937x_set_compander` must call `wcd937x_connect_port` whenever `comp1_enable` or `comp2_enable` changes. [F167]
- `wcd937x_sdw_hw_params` and `wcd938x_sdw_hw_params` must reset `wcd->sconfig.ch_count` to 1 and `wcd->active_ports` to 0 before compacting non-zero `wcd->port_config` entries into the contiguous local `port_config` array passed to `sdw_stream_add_slave`. [F168]
- In `wcd934x_micbias_control` and `wcd937x_micbias_control`, the shared 2-bit enable field (`0xc0`) of each `ANA_MICBn` register must only be set to pull-up mode (`BIT(7)`) when `micb_ref[micb_index] == 0` and `pullup_ref[micb_index] > 0`, and cleared to 0 only when both counters reach 0 under `micb_lock`. [F174]
- `wcd934x_wcd_mbhc_calc_impedance` and `wcd937x_wcd_mbhc_calc_impedance` must save `ANA_MBHC_BTN5..BTN7`, `MBHC_CTL_CLK`, `MBHC_NEW_ZDET_ANA_CTL`, and `ANA_MBHC_ELECT` `FSM_EN` before running zdet ramps, and every exit path must jump to `zdet_complete` to restore them along with `ANA_MBHC_MECH`. If the left-channel measurement yields floating impedance (`ZDET_FLOATING_IMPEDANCE` or `> ZDET_VAL_100K`), `zdet_param_ptr` and `d1` must be reset to `&zdet_param[1]` and `d1_a[1]` before the right-channel ramp. [F176, F196]
- In `wcd934x_mbhc_get_result_params` and `wcd937x_mbhc_get_result_params`, `denom = (x1 * d1) - (1 << (14 - noff))` must be evaluated as a signed 32-bit integer and checked for `denom > 0` before dividing `WCD934X_MBHC_ZDET_CONST * 1000` or `WCD937X_MBHC_ZDET_CONST * 1000` by `denom`. [F200]
- In `wcd937x_mbhc_moisture_config` and `wcd937x_mbhc_get_moisture_status`, if `!wcd937x->mbhc_cfg.hphl_swh` (normally-closed jack) or `wcd937x->mbhc_cfg.moist_rref == R_OFF`, `WCD937X_M_RTH_CTL_MASK` in `WCD937X_MBHC_NEW_CTL_2` must be set to `R_OFF` and moisture detection must not be enabled. [F180]
- `wcd934x_int_dem_inp_mux_put` must update `WCD934X_RX_DLY_ZN_EN_MASK` in `WCD934X_CDC_RX{0,1,2}_RX_PATH_CFG0` in lockstep with `WCD934X_CDC_RX{0,1,2}_RX_PATH_SEC0`, and `wcd934x_codec_hphl_dac_event` / `wcd934x_codec_hphr_dac_event` require that `SEC0` DEM input (`& 0x03`) to be `0x01` when `hph_mode` is Class-H. [F178]
- In `wcd934x_set_prim_interpolator_rate` and `wcd934x_set_mix_interpolator_rate`, loops over `0..WCD934X_NUM_INTERPOLATORS - 1` must skip `INTERP_LO3_NA` and `INTERP_LO4_NA` before accessing interpolator registers. [F194]
- `wcd934x_put_iir_band_audio_mixer` and `wcd934x_get_iir_band_audio_mixer` `memcpy` `ctl->bytes_ext.max` bytes between `ucontrol->value.bytes.data` and stack buffer `u32 coeff[BAND_MAX]`, so `bytes_ext.max` in `WCD_IIR_FILTER_CTL` must not exceed `sizeof(u32) * BAND_MAX` (`WCD_IIR_FILTER_SIZE`). [F205]
- In `wcd937x_soc_codec_probe`, PDM watchdog IRQs (`hphr_pdm_wd_int`, `hphl_pdm_wd_int`, `aux_pdm_wd_int`) must be disabled with `disable_irq_nosync` immediately after `devm_request_threaded_irq` so `enable_irq` in `SND_SOC_DAPM_POST_PMU` and `disable_irq_nosync` in `SND_SOC_DAPM_PRE_PMD` of HPHR, HPHL, AUX, and EAR PA widgets stay balanced. [F217]
- In `wcd937x_codec_enable_ear_pa`, `wcd937x->ear_rx_path` must be latched from `WCD937X_DIGITAL_CDC_EAR_PATH_CTL` during `SND_SOC_DAPM_PRE_PMU` and reused across `POST_PMU`, `PRE_PMD`, and `POST_PMD` to select between `aux_pdm_wd_int`/`WCD937X_DIGITAL_PDM_WD_CTL2` and `hphl_pdm_wd_int`/`WCD937X_DIGITAL_PDM_WD_CTL0`. Broken by: re-reading `WCD937X_DIGITAL_CDC_EAR_PATH_CTL` in `PRE_PMD` or `POST_PMD`. [F197]

## Synchronization
- In `wcd934x.c`, `__wcd934x_cdc_mclk_enable(wcd, false)` must not disable `sysclk` or `wcd->extclk` while `WCD934X_CDC_SWR_CLK_EN_MASK` is set in `WCD934X_CDC_CLK_RST_CTRL_SWR_CONTROL`, and `wcd934x_swrm_clock(wcd, false)` must clear `WCD934X_CDC_SWR_CLK_EN_MASK` before calling `__wcd934x_cdc_mclk_enable(wcd, false)`. [F148]
- In `wcd934x.c`, `swclk_gate_enable` and `swclk_gate_disable` must be wired to `.prepare` and `.unprepare` in `swclk_gate_ops` (never `.enable` or `.disable`), because `wcd934x_swrm_clock` takes `wcd->sysclk_mutex`, sleeps via `usleep_range`, and calls `clk_prepare_enable` and SLIMbus `regmap` I/O. [F227]
- In `wcd934x.c`, `wcd->sysclk_mutex` must only be held for the `wcd->sysclk_users` counter update inside `wcd934x_enable_ana_bias_and_sysclk` and `wcd934x_disable_ana_bias_and_syclk` and must never be nested with `wcd->micb_lock` (e.g., `wcd934x_mbhc_request_micbias` calls `__wcd934x_cdc_mclk_enable` outside `wcd934x_micbias_control`). [F231]
- In `wcd937x_bind()`, `wcd937x->regmap`, `wcd937x->virq` (via `wcd937x_irq_init()`), and `slave_irq` on both `sdw_priv[AIF1_PB]` and `sdw_priv[AIF1_CAP]` must be initialized before calling `snd_soc_register_component()`. [F149]

## Object Lifetimes
- In `wcd934x_trigger()`, stopping, suspending, or pausing (`SNDRV_PCM_TRIGGER_STOP`, `SUSPEND`, `PAUSE_PUSH`) must call `slim_stream_disable(dai_data->sruntime)` before `slim_stream_unprepare(dai_data->sruntime)`. [F132]
- In `wcd937x_probe`, regulator supplies in `wcd937x_supplies` are managed via `devm_regulator_bulk_get_enable`, so error paths and `wcd937x_remove` must not call `regulator_bulk_disable` or `regulator_bulk_free`. [F219]

## API Contracts
- In `wcd934x.c`, the codec platform device (`pdev->dev` / `component->dev`) stores `struct wcd934x_codec *` in drvdata, whereas its parent MFD device (`dev->parent` / `component->dev->parent`) stores `struct wcd934x_ddata *`. [F207]
- In `wcd937x.c` and `wcd937x-sdw.c`, the master codec platform device (`component->dev` / `dai->dev`) stores `struct wcd937x_priv *` in drvdata, whereas SoundWire slave devices (`wcd937x->rxdev`, `wcd937x->txdev`, `&slave->dev`) store `struct wcd937x_sdw_priv *` (accessed from DAI callbacks via `wcd937x->sdw_priv[dai->id]`). [F208]
- In `wcd937x_get_channel_map()` and `wcd934x_get_channel_map()`, playback DAIs (`AIF1_PB..AIF4_PB`) must only validate and write `rx_slot` and `rx_num`, while capture DAIs (`AIF1_CAP..AIF3_CAP`) must only validate and write `tx_slot` and `tx_num`, because callers may pass NULL for the unused direction. [F160]
- `wcd934x_set_channel_map` must reject `tx_num > WCD934X_TX_MAX` or `rx_num > WCD934X_RX_MAX` (and NULL `tx_slot` or `rx_slot`) before copying slot numbers into `wcd->tx_chs` and `wcd->rx_chs`. [F189]
- In `wcd9370_probe` and `wcd9380_probe`, DT properties `qcom,tx-port-mapping` and `qcom,rx-port-mapping` must be read into `&pdev->m_port_map[1]` (1-based), and `wcd937x_connect_port` must index `wcd->port_config[port_idx - 1]` while indexing `sdev->m_port_map[port_num]`. [F236]
- In `wcd9370_probe`, 1-based channel indices from `qcom,tx-channel-mapping` and `qcom,rx-channel-mapping` must be converted via `WCD937X_SWRM_CH_MASK(master_ch_mask[i])` (`BIT(ch_idx - 1)`) before storing into `wcd->ch_info[i].master_ch_mask`. [F237]
- Every `SOC_SINGLE_EXT` control using `wcd937x_set_compander`, `wcd937x_get_swr_port`, or `wcd937x_set_swr_port` must set `xreg` (`mc->reg`) to a `wcd937x_rx_sdw_channels` or `wcd937x_tx_sdw_channels` enum (never `SND_SOC_NOPM`), as `mc->reg` indexes `wcd->ch_info[]` and its 1-based `port_num` indexes `wcd->port_config[port_idx - 1]`. [F183]
- Any DAPM widget using `wcd934x_codec_enable_dmic()` must have a name whose first digit in `"012345"` starts a valid decimal DMIC index (`0..5`), and any widget using `wcd934x_codec_enable_dec()` must have a space-separated name (at most 15 chars) whose second token's first digit in `"012345678"` starts a valid decimal decimator index (`0..8`). [F165]
- `wcd937x_mbhc_zdet_ramp()` and `wcd934x_mbhc_zdet_ramp()` accept nullable `zl` and `zr` out-parameters (skipping HPH_L when `!zl` and HPH_R when `!zr`) and must initialize local `zdet` to 0 before calling `wcd937x_mbhc_get_result_params()` or `wcd934x_mbhc_get_result_params()`, which leave `*zdet` unmodified on ramp errors (`!c1 || !x1`). [F158]
- Callers of `wcd934x_wcd_mbhc_qfuse_cal` and `wcd937x_wcd_mbhc_qfuse_cal` must convert ramp impedance from milliohms to ohms by dividing by 1000 before passing `z_val`, because `qfuse_cal` compares `*z_val` against `ZDET_VAL_400 / 1000` and multiplies `*z_val` by 10000 in signed 32-bit arithmetic. [F201]
- In `wcd937x_sdw_runtime_suspend/resume` and `wcd938x_sdw_runtime_suspend/resume`, when `wcd->regmap` is non-NULL, suspend must enable cache-only mode and call `regcache_mark_dirty(wcd->regmap)`, and resume must disable cache-only mode and call `regcache_sync(wcd->regmap)`. [F211]
- In `wcd937x_soc_codec_probe`, `wcd9375_dapm_widgets` (AMIC4, ADC3, DMIC1-DMIC6) and `wcd9375_audio_map` must only be registered when `WCD937X_DIGITAL_EFUSE_REG_0` is `CHIPID_WCD9375`, and any failure in `snd_soc_dapm_new_controls` or `snd_soc_dapm_add_routes` must call `wcd_clsh_ctrl_free(wcd937x->clsh_info)`. [F216]
- `wcd_irq_chip_map` in `wcd937x.c` must call `irq_set_nested_thread(virq, 1)` on `wcd->virq` (`wcd->slave_irq`) so `wcd9370_interrupt_callback` and `wcd9380_interrupt_callback` can synchronously invoke the `regmap_irq` thread via `handle_nested_irq` from the SoundWire IRQ thread. [F228]
- Cross-module SoundWire helpers in `wcd937x-sdw.c` (`wcd937x_sdw_hw_params`) and `wcd938x-sdw.c` (`wcd938x_sdw_hw_params`, `wcd938x_sdw_free`, `wcd938x_sdw_set_sdw_stream`) must use `EXPORT_SYMBOL_GPL` and provide `#if IS_ENABLED(CONFIG_SND_SOC_WCD937X_SDW)` / `CONFIG_SND_SOC_WCD938X_SDW` fallback stubs returning `-EOPNOTSUPP`. [F240]

## Error Handling
- In `wcd934x_mbhc_init()`, if `wcd_mbhc_init()` returns an error pointer, `wcd->mbhc` must be reset to NULL before returning because `wcd934x_comp_probe()` ignores `wcd934x_mbhc_init()` failures and downstream callers (`wcd934x_codec_set_jack`, `wcd934x_mbhc_deinit`, `wcd_mbhc_event_notify`) only check for NULL. [F153]
- If `wcd934x_slim_set_hw_params()` fails after allocating `cfg->chs`, it must both `kfree(cfg->chs)` and set `cfg->chs = NULL` so a subsequent `wcd934x_hw_free()` does not `kfree()` a dangling pointer. [F157]
- `wcd934x_get_dmic_clk_val` must check that `dmic_clk_rate` is non-zero before computing `mclk_rate / dmic_clk_rate`, falling back to `WCD934X_DMIC_CLK_DIV_2` (for 9.6 MHz MCLK) or `WCD934X_DMIC_CLK_DIV_3`. [F202]

## Known Pitfalls
- In `wcd937x.h` and `wcd937x.c`, unshifted field constants (`WCD937X_MICB_ENABLE` = 1, `WCD937X_MICB_PULL_UP` = 2, `zdet_param->ldo_ctl`) must be written with `snd_soc_component_write_field()`, whereas pre-shifted register values (`BIT(6)`, `BIT(7)`, `zdet_param->btn5/btn6/btn7`) must be written with `snd_soc_component_update_bits()`. [F163]
- In `wcd934x_get_dmic_sample_rate`, any `continue` branch inside the `while (!dec_found && adc_mux_index < WCD934X_MAX_VALID_ADC_MUX)` loop must increment `adc_mux_index` before continuing. [F193]
- In `wcd937x_reset`, asserting `wcd937x->reset_gpio` (`gpiod_set_value(wcd937x->reset_gpio, 1)`) must be followed after the 20–30 us delay by de-asserting it (`gpiod_set_value(wcd937x->reset_gpio, 0)`) and another 20–30 us delay before registering the component master. [F218]
- In `wcd934x_comp_init`, `wcd934x_enable_efuse_sensing` must run before `wcd934x_get_version`, and must enable MCLK via `__wcd934x_cdc_mclk_enable(wcd, true)`, set `WCD934X_EFUSE_SENSE_EN_MASK`, sleep 5 ms (`usleep_range(5000, 5500)`), check bit 0 of `WCD934X_CHIP_TIER_CTRL_EFUSE_STATUS`, and disable MCLK. [F223]
- In `wcd937x_mbhc_get_result_params`, both the ramp-completion poll on `WCD937X_ANA_MBHC_RESULT_2` (bit `0x80`) and the ramp-down poll on `WCD937X_ANA_MBHC_RESULT_1`/`RESULT_2` (`while (x1 != 0)`) must be bounded by `WCD937X_ZDET_NUM_MEASUREMENTS` (900) iterations, and `WCD937X_ANA_MBHC_ZDET` bit `0x20` must be cleared after reading the result. [F226]
