# USB SUBSYSTEM — drivers/usb/gadget/udc (part 2)

UDC peripheral drivers for NXP LPC32xx (`lpc32xx_udc`), Renesas M66592 (`m66592-udc`), Maxim MAX3420E (`max3420_udc`), PLX NET2280/USB338x (`net2280`), and TI OMAP1 (`omap_udc`).

## Architecture & Data Flow
- In `net2280`, `queue_dma()` swaps `ep->dummy`/`ep->td_dma` with `req->td`/`req->td_dma` without zeroing the new dummy's `dmacount`: `net2280_free_request()` must free current `req->td`, `net2280_remove()` must free `dev->ep[1..4].dummy` before `dma_pool_destroy()`, and paths completing aborted DMA requests (`net2280_dequeue`, `handle_ep_small`) must set `req->td->dmacount = 0` before `dma_done()`. [F6, F62]
- In `net2280`, single-transfer DMA in `start_dma()` sets `req->td->dmadesc = 0` and stores residual `req->req.length - tmp` in `req->td->dmacount` for `scan_dma_completions()`. For IN DMA, `DMA_FIFO_VALIDATE` is cached in `ep->in_fifo_validate`; if a request's ZLP/short-packet need differs, `net2280_queue()` must pass `valid = 0` to `queue_dma()` so DMA stops and `restart_dma()` reprograms `dmactl`. [F48, F63]
- In `net2280_dequeue()`, under `ep->dev->lock`, DMA endpoints (`ep->dma`) must set `ep->stopped = 1`, call `stop_dma(ep->dma)`, and run `scan_dma_completions(ep)` before searching `ep->queue`. When unlinking the head (`ep->queue.next == &req->queue`), reset `req = NULL` after completion so `if (req) done(...)` is skipped and `start_dma()` runs on the new head. In `handle_ep_small()`, reset `stuck = 0` when `num_completed != 0` or `stuck_req != req`, and break with `req = NULL` if `stuck++ > 5`. [F23, F89, F90]
- On USB338x (`PLX_PCIE`), `dev->usb_ext`, `dev->llregs`, and `dev->plregs` are only mapped when `dev->quirks & PLX_PCIE` is set. In `enhanced_mode`, IN endpoints offset `ep->regs` by `0xC0` from `ep->cfg` while sharing `ep->cfg` (`&dev->epregs[ne[i]]`) with same-number OUT endpoints; access `ep_cfg` via `ep->cfg->ep_cfg` and preserve sibling-direction bits in `net2280_enable()`, `ep_reset_338x()`, and `set_fifo_bytecount()`. [F65, F76, F132]
- In `net2280`, keep the 9-element USB338x endpoint order in lockstep across `ep_info_adv`, `ep_bit`, `ep_key`, `ne`, `ep_reg_addr`, `ep_pl`, and `ep_enhanced`. In `net2280_match_ep()`, test `USB_ENDPOINT_XFER_INT` before `!= USB_ENDPOINT_XFER_BULK`. [F66, F88]
- In `lpc32xx_udc`, `lpc32xx_ep_enable()` must reject `usb_endpoint_maxp(desc) == 0` before setting `ep->ep.maxpacket`. `lpc32xx_ep_enable()`/`lpc32xx_ep_disable()` must keep `ep->hwep_num`, `udc->udca_v_base[ep->hwep_num]`, and `udc->enabled_ep_cnt` synchronized, waking `udc->ep_disable_wait_queue` on disable. `iso_status` in `struct lpc32xx_usbd_dd_gad` must stay at offset 24 (`dd->this_dma + 24` in `lpc32xx_ep_queue()`), and `lpc32xx_udc_probe()` must bind `udc->ep[i].udc = udc`, `udc->gadget.ep0 = &udc->ep[0].ep`, and call `udc_reinit(udc)` after `devm_kmemdup()`. [F55, F56, F70, F105]
- In `m66592-udc`, guard `clk_disable()`/`clk_put()` on `m66592->pdata->on_chip`. `free_pipe_config()` must call `pipe_buffer_release()` before `m66592_ep_release()` clears `ep->pipenum = 0`. `enable_pipe_irq()` and `disable_pipe_irq()` must save `M66592_INTENB0`, clear `M66592_BEMPE | M66592_NRDYE | M66592_BRDYE` before modifying `M66592_BRDYENB`/`BEMPENB`/`NRDYENB`, and restore `M66592_INTENB0`. [F39, F58, F59]
- In `omap_udc`, `udc->ep[32]` is indexed by `addr & 0xf` (EP0/OUT) and `16 + (addr & 0xf)` (IN); `ep->dma_channel` is 1-based (`1..3`, `0` unassigned). Callers of `dma_channel_release()` (`omap_ep_dequeue`, `omap_ep_set_halt`, `nuke`) must check `ep->dma_channel != 0` (not `ep->has_dma`), and `dma_channel_release()` must leave `ep->has_dma` set until `nuke()` finishes `done()` (so `usb_gadget_unmap_request()` runs). [F3, F79, F100]
- In `omap_udc`, `ep0_irq()` writes `UDC_DEV_CFG` to `UDC_SYSCON2` and sets `udc->ep0_set_config = 1` before `setup()`; write `UDC_CLR_CFG` if `setup()` fails or `ep0` stalls, or enable `UDC_EPN_RX_IE | UDC_EPN_TX_IE` in `omap_ep_queue()` on success. In `read_fifo()`, break before `done()` when `!ep->bEndpointAddress` so `ep0_irq()` deselects EP0 first. [F68, F97]
- In `omap_udc`, `omap_udc_setup()` must program `UDC_EP_RX`/`UDC_EP_TX` before setting `UDC_CFG_LOCK` in `UDC_SYSCON1` (8-byte aligned, `<= 2048` bytes total). `machine_without_vbus_sense()` must include `omap_osk`, `omap_palmte`, and `sx1`. On OMAP16xx, `omap_udc_enable_clock()` runs under `udc->lock` and must only call `clk_enable()` + `udelay(100)` and `clk_disable()`. [F135, F136, F138]
- In `max3420_udc`, `spi_max3420_enable()` and `spi_max3420_stall()` must return early when `ep->id == 0`. In `max3420_thread()`, reset `loop_again = 0` after the sleep block and set `loop_again = 1` whenever any work helper returns true. [F75, F91]
- In `lpc32xx_ep_dequeue()`, `max3420_ep_dequeue()`, `net2280_dequeue()`, and `omap_ep_dequeue()`, save a `list_for_each_entry` match into a separate `NULL`-initialized pointer before `break` rather than testing the loop cursor after the loop. In bounded register polling loops in `m66592-udc.c` and `lpc32xx_udc.c`, combine the state check and positive timeout (`timeout-- > 0` / `to > 0`) with `&&` (not `||`). [F84, F86]

## Synchronization
- When draining `ep->queue` in `nuke()`, `handle_stat0_irqs()`, or `m66592_disable()`, use `while (!list_empty(&ep->queue))` and re-fetch `ep->queue.next` on each pass because completion drops the spinlock. In `net2280` and `omap_udc`, `done()` must save `ep->stopped`, set `ep->stopped = 1` before unlocking for giveback, and restore it after relocking. In `m66592-udc`, `m66592_queue()` and `transfer_complete()` (after relocking and re-reading `ep->queue.next`) must check `ep->ep.desc != NULL` before `start_packet()`. [F13, F40, F87, F147]
- In `lpc32xx_udc`, `done()`, `stop_activity()`, and `udc_handle_ep0_setup()` must be called with `udc->lock` held and drop it around `usb_gadget_giveback_request()`, `driver->disconnect()`, and `driver->setup()`. `lpc32xx_stop()` and `lpc32xx_vbus_session()` (`!udc->driver`) must drop `udc->lock` to wait on `ep_disable_wait_queue` for `enabled_ep_cnt == 0` before relocking for `udc_clk_set(udc, 0)`. Pass `block = 0` to `isp1301_pullup_enable()` when holding `udc->lock` (`stop_activity()`, `pullup()`), and keep `lpc32xx_usb_vbus_irq()` threaded (`IRQF_ONESHOT`) because `vbus_work()` sleeps. [F8, F27, F139, F142]
- In `max3420_udc`, all `spi_*()` helpers call blocking `spi_sync()` and must only run in `max3420_thread()` under `udc->spi_bus_mutex`; never hold `udc->lock` or `ep->lock` across `spi_*()` or `max3420_req_done()`. `max3420_irq_handler()` must only call `disable_irq_nosync(spi->irq)` when `(udc->todo & ENABLE_IRQ) == 0` and set `ENABLE_IRQ` under `udc->lock`, paired with `max3420_thread()` clearing `ENABLE_IRQ` and calling `enable_irq(spi->irq)` under `udc->lock`. [F16, F29, F144]
- In `net2280`, `fill_dma_desc()` must execute `wmb()` before writing `td->dmacount` with `BIT(VALID_BIT)`, paired with `rmb()` in `scan_dma_completions()` before reading `req->td->dmacount`. After `ep0_start()`, callers of `get_idx_reg()`, `set_idx_reg()`, and `set_max_speed()` must hold `dev->lock`. [F22, F24]
- In `omap_udc`, runtime `use_ep()` (`UDC_EP_NUM`) accesses must hold `udc->lock`, and any path setting `UDC_EP_SEL` must call `deselect_ep()` before unlocking. `ep0_irq()` must bracket unlocked `udc->driver->setup()` with `udc->ep0_setup = 1` and `0` so synchronous EP0 OUT `omap_ep_queue()` calls jump to `irq_wait`. [F21, F32]

## Object Lifetimes
- In `lpc32xx_udc`, `net2280`, and `omap_udc`, use `list_del_init(&req->queue)` when removing requests from `ep->queue`. Map DMA requests with `usb_gadget_map_request()` in `.queue` before locking and unmap with `usb_gadget_unmap_request()` in `done()` before unlocking; in `lpc32xx_udc`, non-EP0 (`ep->lep != 0`) requests also allocate `req->dd_desc_ptr` via `udc_dd_alloc()` (`GFP_ATOMIC | GFP_DMA`) in `.queue` and free it via `udc_dd_free()` in `done()`. [F9, F17, F143, F152]
- In `m66592_probe()`, set `m66592->ep0_req = NULL` after `m66592_free_request()` at `err_add_udc` before falling through to `clean_up:`. In `m66592_remove()`, call `usb_del_gadget_udc()` and `timer_shutdown_sync(&m66592->timer)` before `iounmap()`/`kfree()`. In `get_status()`, point `m66592->ep0_req->buf` to `m66592->ep0_data` (not stack). [F1, F31, F112]
- In `max3420_probe()`, errors after `usb_add_gadget_udc()` must jump to `del_gadget` (`usb_del_gadget_udc()`). In `lpc32xx_udc_probe()`, call `of_node_put()` on the `"transceiver"` node right after `isp1301_get_client()`. In `omap_udc_remove()`, set `udc->done` to a stack `completion` before `usb_del_gadget_udc()` and `wait_for_completion()` before `release_mem_region()`. [F2, F5, F115]

## API Contracts
- Across all five drivers, `.udc_start` must not modify `driver->driver.bus`. In `max3420_udc`, `spi_rd_buf()`/`spi_wr_buf()` callers must bound `len <= MAX3420_EP_MAX_PACKET` (64). [F74, F156]
- In `lpc32xx_udc`, `udc_ep0_in_req()`/`udc_ep0_out_req()` return `1` on completion, so `lpc32xx_ep_queue()` must return `(status < 0) ? status : 0`. `uda_*_devint()` take pre-shifted masks, whereas `uda_*_hwepint()` and `udc_ep_dma_*()` take unshifted `hwep` (`0..31`). [F37, F38]
- In `m66592-udc`, `m66592_mdfy(m66592, val, pat, offset)` takes set-bits `val` before clear-mask `pat`. `setup_packet()` returns `1` to delegate to `driver->setup` and `0` if handled internally. [F42, F43]
- In `net2280`, reject `_req->length > DMA_BYTE_COUNT_MASK` in `net2280_queue()`, use `get_unaligned()`/`put_unaligned()` with `cpu_to_le32s()` in `write_fifo()`/`read_fifo()` calling `set_fifo_bytecount()` only on the final word, and bound sysfs `registers_show()`/`queues_show()` with `scnprintf()` (aborting `queues_show` to `done:` if `t <= 0 || t > size`). [F78, F162]
- In `omap_udc`, `write_fifo()`/`read_fifo()` return `1` when complete (already calling `done()` for non-EP0), so `omap_ep_queue()` must set `req = NULL` on `1`. Endpoint names in `omap_ep_setup()` (with suffix) must be `<= 13` chars (`char[14]`). [F50, F113]

## Error Handling
- In `lpc32xx_ep_*` callbacks, do not dereference `ep->udc` (or call `ep_dbg()`) before checking `!_ep`/`!ep`. In `net2280` ep callbacks, the initial `!_ep` check must return via `pr_err()` rather than `goto print_err` (`ep->dev->pdev->dev`). [F35, F46]
- In `max3420_probe()`, `of_irq_get_byname(..., "vbus") <= 0` configures self-powered mode rather than failing probe. In `omap_udc`, `udc->transceiver` may hold an `ERR_PTR` from `usb_get_phy()`, so check `!IS_ERR_OR_NULL(udc->transceiver)`. [F45, F51]

## Known Pitfalls
- In `m66592-udc`, index `pipenum2ep` by `ep->pipenum` and `epaddr2ep` by `w_index & USB_ENDPOINT_NUMBER_MASK`; `get_pipectr_addr(pipenum)` is 1-based, so `control_reg_*()` must use `M66592_DCPCTR` for `pipenum == 0`. Call `control_end(m66592, 1)` for internal control transfers without a queued request (`clear_feature`, `set_feature`). [F57, F72, F92]
- In `m66592-udc`, use ceiling division (`(len + 3) / 4` or `(len + 1) / 2`) in `m66592_read_fifo()` and `(req->req.length + ep->ep.maxpacket - 1) / ep->ep.maxpacket` for `ep->fifotrn` in `start_packet_read()`, but truncating division (`len / 4` or `len / 2`) in `m66592_write_fifo()` with `iowrite8()` for tail bytes (at `fifoaddr + (3 - i)` if `M66592_CFBCFG` else `fifoaddr + i`, toggling `M66592_MBW_16` if `wr0_shorted_to_wr1`). Wait `ndelay(450)` after writing `M66592_CURPIPE` in `pipe_change()`/`pipe_initialize()`. In `m66592_irq()`, save/restore `M66592_CFIFOSEL`, and if `on_chip` with `intsts0 == 0 && intenb0 == 0`, call `m66592_start_xclock()` and re-read. [F73, F102, F103, F104, F122, F125]
- In `lpc32xx_udc`, index `udc->ep[]` by `ep->lep` (`0..NUM_ENDPOINTS - 1`) but use `ep->hwep_num` (`0..31`) for `udca_v_base[]`, protocol commands, and `1 << ep->hwep_num` masks. Shift by `i * 8` (not `n * 8`) in unaligned inner loops of `udc_pop_fifo()`/`udc_stuff_fifo()`. `udc_protocol_cmd_w()` must read `USBD_DEVINTST` before clearing `USBD_CCEMPTY`, writing `USBD_CMDCODE`, and polling `USBD_CCEMPTY`. When `udc->atx == STOTG04`, omit `MC2_SPD_SUSP_CTRL` and `MC2_GLOBAL_PWR_DN`. [F83, F94, F119, F120]
- In `net2280`, in `handle_stat0_irqs()` (`USB_RECIP_ENDPOINT`), target `e = get_ep_by_addr(dev, w_index)` for halt/DMA helpers (`clear_halt`, `set_halt`, `restart_dma`, `abort_dma`) and `ep` (`&dev->ep[0]`) for `allow_status(ep)`/`set_fifo_bytecount(ep, ...)`. `set_fifo_bytecount()` must use `writeb()` to `(u8 *)&ep->regs->ep_cfg + 2` for vendor `0x17cc` and 32-bit RMW of `&ep->cfg->ep_cfg` otherwise. On `PLX_PCIE`, `net2280_irq()` must clear and restore bit 31 of `dev->regs->pciirqenb1`. [F98, F129, F130]
- In `omap_udc`, RMW of `UDC_TXDMA_CFG`/`UDC_RXDMA_CFG` must OR `UDC_DMA_REQ` back in; in `write_packet()`/`read_packet()`, set `buf = (u8 *)wp` after the 16-bit loop. In `max3420_udc`, clear `ENABLE_EP`/`STALL_EP` before setting `ep->todo` and test with `==` (not `&`) because `DISABLE`/`UNSTALL` (`3 << N`) contain `ENABLE`/`STALL` (`1 << N`). [F67, F85, F110]
