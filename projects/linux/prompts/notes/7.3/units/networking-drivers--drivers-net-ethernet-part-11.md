# NETWORKING DRIVERS — drivers/net/ethernet (part 11)

This unit comprises five Ethernet drivers: SMSC EPIC/100 PCI Fast Ethernet (`epic100`), SMC 9194 ISA/platform (`smc9194`), SMC 91c92 PCMCIA (`smc91c92_cs`), SpacemiT K1 SoC EMAC (`k1_emac`), and Sun Cassini PCI Gigabit (`cassini`).

## Architecture & Data Flow

- In `epic100.c`, `ep->cur_tx`, `ep->dirty_tx`, `ep->cur_rx`, and `ep->dirty_rx` are monotonically increasing counters (never wrapped in place with `%=`); index ring slots with `% TX_RING_SIZE` or `% RX_RING_SIZE` and compute occupancy via `cur - dirty`. In `epic_restart()`, after soft-resetting (`ew32(GENCTL, 0x4001)`), program `PRxCDAR` and `PTxCDAR` with the DMA addresses of `ep->cur_rx % RX_RING_SIZE` and `ep->dirty_tx % RX_RING_SIZE`, not base `ep->rx_ring_dma`/`ep->tx_ring_dma`. [F382, F385]
- In `epic_init_ring()` and `epic_rx()`, set `ep->dirty_rx = (unsigned int)(i - RX_RING_SIZE)` after allocating `i` buffers; in `epic_rx()`, if `netdev_alloc_skb()` fails, break before setting `DescOwn` or advancing `ep->dirty_rx`. When `!netif_running(dev)`, `ethtool_begin()` and `ethtool_complete()` track `ep->ethtool_ops_nesting` to wake the chip/MII (`GENCTL = 0x0200`, `NVCTL |= 0x4800`) on `0 -> 1` and return it to sleep (`GENCTL = 0x0008`, `NVCTL & ~0x483c`) on `1 -> 0`. [F383, F413]
- In `k1_emac.c`, `emac_tx_mem_map()` and `emac_tx_map_frag()` pack up to two SKB fragments per TX descriptor via `frag_idx % 2`: even fragments advance `tx_ring->head` and fill `buf[0]`/`buffer_addr_1`, while odd fragments reuse that descriptor for `buf[1]`/`buffer_addr_2`. [F391]
- In `k1_emac.c`, `emac_rx_frame_good()` must reject descriptors with `len <= ETH_FCS_LEN || len > priv->dma_buf_sz` before `emac_rx_clean_desc()` subtracts `ETH_FCS_LEN` from `u32` length and calls `skb_put()`. Every `emac_rx_clean_desc()` iteration consuming a descriptor (valid or error) must set `rx_buf->skb = NULL` and advance `rx_ring->tail`, since `emac_alloc_rx_desc_buffers()` refills from `rx_ring->head` only while `!rx_buf->skb`. [F390, F406]
- In `cassini.c`, `cas_xmit_tx_ringN()` appending a target-abort workaround descriptor via `tx_tiny_map()` must set `cp->tx_tiny_use[ring][entry].used = 1` on the tiny-buffer slot and increment `cp->tx_tiny_use[ring][tentry].nbufs` on the SKB's initial slot `tentry`. In `cas_tx_ringN()`, before freeing `skbs[entry]`, subtract `skb_shinfo(skb)->nr_frags + cp->tx_tiny_use[ring][entry].nbufs + 1` from `count` (breaking if `count < 0`), and when unmapping each fragment advance `entry` past any following `tx_tiny_use[ring][entry].used` slot without unmapping it. [F374, F407]
- In `cassini.c`, post `cp->init_rxds[ring]` descriptors to `REG_RX_KICK` (`REG_PLUS_RX_KICK1`) only on multiples of 4, and advance completion indices in `cas_rx_ringN()` by `(1 + CAS_VAL(RX_COMP1_SKIP, words[0])) & RX_COMP_ENTRY`. In `cas_rx_process_pkt()`, clamp first-page length with `hlen = min(cp->page_size - off, dlen)` and abort if `hlen < 0` before DMA sync, copying, or attaching fragments. [F398, F401]
- In `cassini.c`, `cp->net_stats` and `cp->stat_lock` are sized `N_TX_RINGS + 1` (`N_TX_RINGS >= N_RX_DESC_RINGS` and `N_RX_COMP_RINGS`), where `0..N_TX_RINGS - 1` are per-ring scratch slots and `N_TX_RINGS` is cumulative. After `cas_get_stats()` folds MAC error registers and `cp->net_stats[0..N_TX_RINGS - 1]` into `cp->net_stats[N_TX_RINGS]`, it must call `cas_clear_mac_err(cp)` and `memset()` each `cp->net_stats[i]` to zero under `cp->stat_lock`. Update `ethtool_cassini_statnames` and `data[i++]` in `cas_get_ethtool_stats()` in lockstep (`BUG_ON(i != CAS_NUM_STAT_KEYS)`). [F372, F377, F430]
- In `cassini.c`, `cas_set_link_modes()` must update `MAC_RX_CFG_STRIP_FCS`, `cp->crc_size` (`0` full-duplex, `4` half-duplex), and `cp->min_frame_size` in lockstep. `REG_MAC_ADDRN(0..44)` uses 3-register groups: `0..2` station MAC, `3..41` (`1 <= i <= CAS_MC_EXACT_MATCH_SIZE`) exact-match multicast in `cas_process_mc_list()`, and `42..44` pause control. `cas_saturn_firmware_init()` must check `fw->size >= 2` before reading `fw->data[0..1]` and subtracting 2. In `cas_txmac_interrupt()`, return early for `MAC_TX_DEFER_TIMER` only if `!(txmac_stat & ~MAC_TX_DEFER_TIMER)`. [F371, F399, F402, F411]

## Synchronization

- In `epic100.c`, hold `ep->napi_lock` across `napi_schedule_prep()` and masking NAPI IRQs in `epic_interrupt()`, and across clearing `EpicNapiEvent` in `INTSTAT` and unmasking NAPI IRQs after `napi_complete_done()` in `epic_poll()`. In `epic_start_xmit()`, `epic_init_ring()`, and `epic_rx()`, populate `bufaddr`/`buflength` and `ep->tx_skbuff[entry]`/`ep->rx_skbuff[entry]` before setting `DescOwn`. [F331, F332]
- In `k1_emac.c`, `emac_alloc_rx_desc_buffers()` must write `rx_desc`, execute `dma_wmb()`, and set `RX_DESC_0_OWN` via `WRITE_ONCE()`, paired in `emac_rx_clean_desc()` with `READ_ONCE(rx_desc->desc0)` and `dma_rmb()`. In `emac_tx_mem_map()`, withhold `TX_DESC_0_OWN` from the first descriptor (`old_head`) until all subsequent fragment descriptors are written, then run `dma_wmb()` and `WRITE_ONCE()` before `emac_dma_start_transmit()`. `emac_tx_clean_desc()` must hold `netif_tx_lock(ndev)` while advancing `tx_ring->tail`, freeing TX buffers, and waking the queue. [F339, F458, F460]
- In `k1_emac.c`, all accesses to `tx_stats`, `rx_stats`, `tx_stats_off`, `rx_stats_off`, and calls to `emac_stats_update()` must hold `priv->stats_lock` (using `spin_lock_bh()` in process context since `emac_stats_timer()` runs in softirq), and `emac_read_stat_cnt()` must use atomic `readl_poll_timeout_atomic()`. [F340, F456]
- In `cassini.c`, lock order is `cp->pm_mutex` outermost, then `cp->lock` (`spin_lock_irqsave()`), then `cp->tx_lock[0..N_TX_RINGS - 1]` ascending via `spin_lock_nested(&cp->tx_lock[i], i)`. Hold `cp->pm_mutex` across `cas_open()`, `cas_close()`, `cas_ioctl()`, `cas_suspend()`, `cas_resume()`, and `cas_shutdown()` to serialize `cp->hw_running` and `cp->opened`. In `cas_close()`, call `napi_disable(&cp->napi)` before taking `cp->pm_mutex` and `cas_lock_all_save()` because `cas_poll()` takes `cp->lock`. [F343, F461, F462]
- In `cassini.c`, scheduling `cp->reset_task` increments `cp->reset_task_pending` and `cp->reset_task_pending_{all,spare,mtu}`, and `cas_reset_task()` must decrement `cp->reset_task_pending` on every exit path. `cas_shutdown()` must clear `cp->hw_running = 0`, call `timer_delete_sync(&cp->link_timer)`, and wait for `atomic_read(&cp->reset_task_pending) == 0` before taking `cas_lock_all_save()`. [F328, F348]
- In `cassini.c`, `cp->rx_inuse_list` requires `cp->rx_inuse_lock` and `cp->rx_spare_list` (`cp->rx_spares_needed`) requires `cp->rx_spare_lock`. `cas_page_dequeue()` must drop `cp->rx_spare_lock` before calling `cas_spare_recover()` and recheck `list_empty(&cp->rx_spare_list)` after relocking. `cas_spare_recover()` must move `cp->rx_inuse_list` via `list_splice_init()` under `cp->rx_inuse_lock`, iterate with `list_for_each_safe()`, and splice entries still having `page_count(page->buffer) > 1` back under `cp->rx_inuse_lock`. [F346, F409]
- In `cassini.c`, `cas_get_stats()` must take `cp->stat_lock[N_TX_RINGS]` with `spin_lock_irqsave()` before taking `cp->stat_lock[0..N_TX_RINGS - 1]` or calling `cas_clear_mac_err(cp)`, as IRQ/NAPI handlers use `spin_lock(&cp->stat_lock[i])`. `cas_rxc_init()` must zero `word1..word3` and set `RX_COMP4_ZERO` in `word4`, and `cas_rx_ringN()` must check both `CAS_VAL(RX_COMP1_TYPE, words[0]) != 0` and `(words[3] & RX_COMP4_ZERO) == 0`. [F350, F463]

## Object Lifetimes

- In `epic_rx()`, when passing `ep->rx_skbuff[entry]` directly to `netif_receive_skb()`, unmap `ep->rx_ring[entry].bufaddr` and set `ep->rx_skbuff[entry] = NULL` so the refill loop allocates a replacement before restoring `DescOwn`. [F316]
- In `k1_emac.c`, `emac_tx_map_frag()` must set `tx_buf->buf[buf_idx].dma_addr` and `map_as_page` only after `!dma_mapping_error(dev, addr)`, and `emac_tx_mem_map()` sets `tx_buf->skb` only on the final fragment (`f == frag_num`), so `emac_free_tx_buf()` unmaps valid slots with the matching API and frees `skb` once. `emac_mdio_init()` and `emac_phy_connect()` must call `of_node_put()` on all exit paths. [F321, F324, F355]
- In `k1_emac.c`, `emac_down()` must stop `free_irq()`, `napi_disable()`, `timer_delete_sync(&priv->txtimer)`, `cancel_work_sync(&priv->tx_timeout_task)`, and `timer_delete_sync(&priv->stats_timer)`, and under `priv->stats_lock` call `emac_stats_update()` and snapshot `tx_stats`/`rx_stats` into `tx_stats_off`/`rx_stats_off` before `pm_runtime_put_sync()` or freeing rings in `emac_stop()`. [F341, F366]
- In `cassini.c`, when an RX page has `page_count(page->buffer) > 1` during reposting in `cas_page_spare()` or `cas_post_rxds_ringN()`, queue it to `cp->rx_inuse_list` under `cp->rx_inuse_lock` and replace it via `cas_page_dequeue()`. When `cas_init_one()` modifies `PCI_CACHE_LINE_SIZE`, save `orig_cacheline_size` and restore it on probe failure and in `cas_remove_one()`. [F326, F330]

## API Contracts

- In `epic_start_xmit()`, `smc_wait_to_send_packet()`, and `cas_start_xmit()`, return `NETDEV_TX_OK` if `skb_padto()` fails (`skb_padto()` already freed the SKB). [F486]
- In `k1_emac.c`, `platform_set_drvdata()` stores `struct emac_priv *` (use `priv->ndev` for `net_device`). `emac_config_dt()` bounds `priv->tx_delay`/`rx_delay` by `EMAC_MAX_DELAY_PS` (`delay_unit_to_ps(EMAC_MAX_DELAY_UNIT - 1)`) and converts them in-place via `delay_ps_to_unit()`, so `emac_update_delay_line()` writes them directly without re-converting. Accesses to `priv->regmap_apmu` must add `priv->regmap_apmu_offset` and use `regmap_update_bits()`/`regmap_set_bits()`, never `regmap_write()`. [F352, F369, F419, F427]
- In `k1_emac.c`, `emac_start_xmit()` must require `emac_tx_avail(priv) >= nfrags + 1` before `emac_tx_mem_map()` and stop the queue if `emac_tx_avail(priv) <= MAX_SKB_FRAGS + 2`. With `NETDEV_PCPU_STAT_DSTATS`, `emac_get_stat_tx_drops()` must aggregate `dev_dstats_tx_dropped()` across CPUs using `u64_stats_fetch_begin()`/`retry`. [F488, F491]
- In `cassini.c`, `CAS_TABORT(cp)` is `2` when `CAS_FLAG_TARGET_ABORT` is set and `1` otherwise (never `0`); test `CAS_TABORT(cp) == 1` for disabled, and multiply `MAX_SKB_FRAGS + 1` by `CAS_TABORT(cp)` in `TX_BUFFS_AVAIL()`. `cas_reset(cp, blkflag)` and `cas_init_hw(cp, restart_link)` have opposite boolean senses (`blkflag` preserves link when `!(pending_all > 0)`; `restart_link` restarts when `pending_all > 0`). [F362, F364]
- In `cassini.c`, `ethtool_register_table` uses negative `offsets` for MII registers (`cas_phy_read(cp, -offsets)`) and non-negative for MMIO, and `cas_read_regs(cp, ptr, len)` takes a `u32` count (`regs->len / sizeof(u32)`), not bytes. `cas_set_multicast()` on a running chip must clear and poll `MAC_RX_CFG_EN`, then clear `MAC_RX_CFG_PROMISC_EN | MAC_RX_CFG_HASH_FILTER_EN` and poll `MAC_RX_CFG_HASH_FILTER_EN` before `cas_setup_multicast()`. [F365, F376, F431]
- In `cassini.c`, `SIOCGMIIPHY` in `cas_ioctl()` sets `data->phy_id = cp->phy_addr` and falls through to `SIOCGMIIREG`, bracketing `cas_phy_read()`/`cas_phy_write()` with `cas_mif_poll(cp, 0)` and `cas_mif_poll(cp, 1)`. Every `cas_hp_inst_t` table passed to `cas_load_firmware()` needs non-NULL `note` on active entries and a `{ NULL }` sentinel. [F412, F432]
- In `cassini.c`, `cas_rx_process_pkt()` must copy at least `RX_COPY_MIN` (64) bytes (or `hlen`) into `skb->data` before attaching page fragments with `__skb_frag_ref()`. When `cp->crc_size != 0`, fold trailing FCS out of `RX_COMP4_TCP_CSUM` via `csum_partial()` and set `CHECKSUM_COMPLETE` only for `htons(ETH_P_IP)`. [F494, F495]

## Error Handling

- In `epic100.c`, `mdio_read()` returns `0xffff` (not negative errno) on timeout; callers (`epic_init_one()`, `epic_open()`, `check_media()`) must check `0xffff`. In `epic_rx_err()`, check `status == EpicRemoved` (`0xffffffff`) before bitmask checks (`RxOverflow`, `RxFull`). In `k1_emac.c`, `emac_rx_frame_good()` uses `WARN_ON_ONCE()` only when `RX_DESC_0_LAST_DESCRIPTOR` is clear, and `dev_dbg_ratelimited()` for wire errors. [F356, F414, F490]

## External Contracts

- In `epic100.c`, 16-bit `LAN0` and `MC0` registers are 4-byte spaced (`LAN0 + i * 4`, `MC0 + i * 4`) while the memory array is indexed by `i`. In `k1_emac.c`, descriptor `total_cnt - 1` must set `RX_DESC_1_END_RING` / `TX_DESC_1_END_RING`, and `emac_set_rx_mode()` packs the 64-bit multicast hash into `u32 mc_filter[4]` at 16 bits per element (`hash / 16`, `hash % 16`) for 16-bit `MAC_MULTICAST_HASH_TABLE1..4`. In `cassini.h`, do not reorder `struct cas_init_block` fields (`rxcs`, `rxds`, `txds`, `tx_compwb`) or break their 8KB/2KB/8B alignment. [F392, F396, F428, F435]

## Known Pitfalls

- In `epic100.c`, descriptors use host byte order because `GENCTL` (`0x0432` vs `0x0412`) enables hardware byteswap under `#ifdef __BIG_ENDIAN`. After waking or soft-resetting via `GENCTL` in `epic_init_one()`, `epic_open()`, or `epic_restart()`, write `0x0008` to `TEST1` 16 times before MII access. In `smc9194.c`, `interfaces[]` is indexed by `dev->if_port - 1` (`1..2`), whereas `if_names[]` in `smc91c92_cs.c` is indexed by 0-based `dev->if_port` (`0..2`). [F384, F387, F443]
- In `k1_emac.c`, `MREGBIT_SOFTWARE_RESET` in `DMA_CONFIGURATION` is not self-clearing: `emac_init_hw()` must write it, sleep 9000–10000 us, write `0x0`, and sleep 9000–10000 us. In `emac_update_counter()`, keep `upper_32_bits(*counter)` in a `u64` before `<< 32` and increment on `old_low > new_low`. `emac_ethtool_stats.offset` stores a `u64` index (`offsetof(...) / sizeof(u64)`), not a byte offset. [F417, F426, F442]
- In `cassini.c`, `cas_init_rx_dma()`/`cas_init_tx_dma()` must add the ring byte offset to `u64 desc_dma = cp->block_dvma` before splitting `>> 32` and `& 0xffffffff`, and `cas_init_tx_dma()` must not write `0` to `REG_TX_KICKN(i)`. In `cas_pcs_link_check()`, re-read `REG_PCS_MII_STATUS` if `PCS_MII_STATUS_LINK_STATUS` is 0, and require `PCS_MII_STATUS_AUTONEG_COMP` before honoring `PCS_MII_STATUS_REMOTE_FAULT`. [F410, F420, F449]
- In `cassini.c`, `cas_hard_reset()` resets PCI via `BIM_LOCAL_DEV_SOFT_0`, so call `pci_save_state()` in `cas_init_one()` beforehand and `pci_restore_state()` in `cas_hard_reset()`. `cas_get_vpd_info()` must set `BIM_LOCAL_DEV_PROM | BIM_LOCAL_DEV_PAD` in `REG_BIM_LOCAL_DEV_EN` before reading ROM and clear it to `0` on exit. `cas_phy_init()` must clear `REG_PCS_CFG` to `0` before writing `REG_PCS_MII_ADVERT` and restore `PCS_CFG_EN`. Revisions below `CAS_ID_REV2` set `CAS_FLAG_NO_HW_CSUM` and must not set `NETIF_F_HW_CSUM | NETIF_F_SG`. [F448, F451, F452, F453]
