# BTRFS FILE SYSTEM — fs/btrfs (part 12)

Manages Btrfs multi-device volumes, chunk allocation, and block mapping (`volumes.c`), extended attributes (`xattr.c`), zlib/zstd compression (`zlib.c`, `zstd.c`), and zoned block device (HMZBD/ZNS) management (`zoned.c`).

## Architecture & Data Flow

- `btrfs_add_chunk_map()` sets `CHUNK_ALLOCATED` and clears `CHUNK_TRIMMED` in each stripe device's `alloc_state` under `mapping_tree_lock`; `btrfs_remove_chunk_map()` / `btrfs_mapping_tree_free()` clear `CHUNK_ALLOCATED` and call `RB_CLEAR_NODE(&map->rb_node)`. `btrfs_find_chunk_map_nolock()` must clamp `u64 end = logical + length` to `U64_MAX` if `end < logical`. [F1222, F1249]
- Mutating `btrfs_device::bytes_used` or `disk_total_bytes` (`create_chunk`, `btrfs_remove_chunk`, `btrfs_grow_device`, `btrfs_shrink_device`) must link `device->post_commit_list` onto `trans->transaction->dev_update_list` under `chunk_mutex` if `list_empty()`. [F1221]
- Adding/removing a `BTRFS_BLOCK_GROUP_SYSTEM` chunk item in `chunk_root` (`btrfs_chunk_alloc_add_chunk_item`, `btrfs_remove_chunk`) must update `super_copy->sys_chunk_array` via `btrfs_add_system_chunk()` or `btrfs_del_sys_chunk()` under `chunk_mutex`. `btrfs_del_sys_chunk()` shifts trailing bytes with `memmove(ptr, ptr + len, array_size - (cur + len))` and decrements `array_size` without advancing `ptr` or `cur`. [F1223, F1294]
- Before detaching an active `btrfs_device` from `fs_devices->devices` (`btrfs_rm_device`, `btrfs_destroy_dev_replace_tgtdev`) or sprouting (`btrfs_init_new_device`), call `btrfs_assign_next_active_device()` under `device_list_mutex` to repoint `sb->s_bdev` and `fs_devices->latest_dev`. [F1224]
- `struct btrfs_chunk` embeds the first `struct btrfs_stripe` inline, so chunk item size for `num_stripes >= 1` is `sizeof(struct btrfs_chunk) + sizeof(struct btrfs_stripe) * (num_stripes - 1)` via `btrfs_chunk_item_size()`. [F1243]
- In `btrfs_map_block()`, when `dev_replace_is_ongoing && dev_replace->tgtdev && op != BTRFS_MAP_READ`, allocate `io_geom.num_stripes + 2` stripes in `alloc_btrfs_io_context()` (for DUP target stripes). When `bioc->full_stripe_logical != (u64)-1` (RAID56 write/rebuild), `bioc->stripes[0..data_stripes-1]` must be rotated by `(i + stripe_nr) % num_stripes`, followed by P, Q, and replace stripes. [F1244, F1246]
- `btrfs_bg_flags_to_raid_index()` must check `(flags & BTRFS_BLOCK_GROUP_PROFILE_MASK) == 0` (`BTRFS_RAID_SINGLE`) before `BTRFS_BG_FLAG_TO_INDEX()` (which calls `ilog2()`). `fs_devices->rr_min_contig_read` must be `>= fs_info->sectorsize` so `>> sectorsize_bits` in `btrfs_read_rr()` is non-zero. [F1284, F1286]
- On 32-bit, `read_one_chunk()` must reject `BTRFS_BLOCK_GROUP_METADATA` chunks with `logical + length >= MAX_LFS_FILESIZE` via `check_32bit_meta_chunk()`. `btrfs_read_disk_super()` must verify `bytenr + BTRFS_SUPER_INFO_SIZE < bdev_nr_bytes(bdev)` and NUL-terminate `super->label[BTRFS_LABEL_SIZE - 1]` when non-empty. [F1253, F1256]
- Check `sp->is_block_group` on `struct btrfs_swapfile_pin` before casting `sp->ptr` to `btrfs_block_group *` or reading `sp->bg_extent_count`. Setting `XATTR_NAME_CAPS` (`btrfs_xattr_handler_set_security()`, `btrfs_initxattrs()`) must clear `BTRFS_INODE_NO_CAP_XATTR` on `BTRFS_I(inode)->runtime_flags`. [F1230, F1299]
- On zoned FS, missing devices (`!device->bdev`) have `!device->zone_info`, so check `device->bdev` first. Always null-check `zinfo->zone_cache` (freed by `btrfs_free_zone_cache()` and set to `NULL` alongside fresh `seq_zones`, `empty_zones`, and `active_zones` bitmap copies in `btrfs_clone_dev_zone_info()`). [F1207, F1208, F1231]
- When `zone_info->max_active_zones > 0`, update `active_zones` and `active_zones_left` together via `btrfs_dev_set_active_zone()` / `btrfs_dev_clear_active_zone()`; `btrfs_reset_device_zone()` must call both `btrfs_dev_set_zone_empty()` and `btrfs_dev_clear_active_zone()`. [F1232]
- In `btrfs_zone_activate()`, `btrfs_zoned_bg_is_full()` only rejects `BTRFS_BLOCK_GROUP_DATA` (non-data requires `meta_write_pointer == start`). Activating meta/sys BGs decrements `zinfo->reserved_active_zones` and links `bg->active_bg_list` into `fs_info->zone_active_bgs`; `do_zone_finish()` and `call_zone_finish()` must increment `reserved_active_zones` and unlink `active_bg_list`. [F1233, F1263]
- `btrfs_get_dev_zone_info()` bounds `zone_size` to `[BTRFS_MIN_ZONE_SIZE, BTRFS_MAX_ZONE_SIZE]` (`SZ_4M..SZ_8G`) and increments `nr_zones = nr_sectors >> ilog2(zone_sectors)` if `!IS_ALIGNED(nr_sectors, zone_sectors)`. `zinfo->sb_zones` stores 2 zones per mirror `i` at `BTRFS_NR_SB_LOG_ZONES * i` (`sb_zone` and `sb_zone + 1`), requiring `sb_zone + 1 < nr_zones`. [F1260, F1285, F1289]

## Synchronization

- Lock order: `sb->s_umount` -> `uuid_mutex` -> `device_list_mutex` -> `chunk_mutex` (or `uuid_mutex` -> `balance_mutex`). In `btrfs_init_new_device()`, call `btrfs_init_sprout()` (`GFP_KERNEL`) before taking `device_list_mutex`. [F1186, F1332]
- Extent buffer locks nest outside `chunk_mutex`: `btrfs_remove_chunk()` must call `btrfs_free_dev_extent()` before locking `chunk_mutex`, and `calculate_alloc_pointer()` (`zoned.c`) must return immediately when `new` is true (`chunk_mutex` held). [F1198, F1304]
- `fs_info->mapping_tree` lookups require `mapping_tree_lock` (read) and incrementing `map->refs` before unlock; updates (`btrfs_add_chunk_map`, `btrfs_remove_chunk_map`) require `mapping_tree_lock` (write). [F1319]
- In `btrfs_map_block()`, read-lock `dev_replace->rwsem` only when `dev_replace->replace_task != current`, unlock immediately if `!dev_replace_is_ongoing`, else hold until `out:`. Callers of `btrfs_relocate_chunk()` must hold `fs_info->reclaim_bgs_lock` across both the chunk/dev tree search and `btrfs_relocate_chunk()`. [F1170, F1189]
- Mutating `fs_devices->devices` or calling `btrfs_set_super_num_devices()` on a mounted FS requires `device_list_mutex`. Replacing `device->name` on a live device requires `device_list_mutex` (and `uuid_mutex`), `rcu_assign_pointer()`, and `kfree_rcu_mightsleep()`. [F1191, F1194]
- Live `btrfs_device::{total_bytes,disk_total_bytes,bytes_used}` updates and unlocked reads must use `btrfs_device_set_*` / `btrfs_device_get_*`. Updates to `dev->dev_stat_values` must precede `atomic_inc(&dev->dev_stats_ccnt)` with `smp_mb__before_atomic()`, pairing with `smp_rmb()` in `btrfs_run_dev_stats()`. [F1192, F1318]
- Process-context access to `struct zstd_workspace_manager` (`zstd_find_workspace`, `zstd_put_workspace`, `zstd_free_workspace_manager`) must use `spin_lock_bh(&zwsm->lock)` / `spin_unlock_bh(&zwsm->lock)` because `zstd_reclaim_timer_fn()` runs in softirq timer context. [F1196]
- Zoned BG lock order: `chunk_mutex` -> `zone_active_bgs_lock` -> `block_group->lock`. `btrfs_reset_unused_block_groups()` must use `spin_trylock(&bg->lock)` under `unused_bgs_lock` and check `found` after the loop. [F1279, F1310]
- In `do_zone_finish()`, after dropping `block_group->lock` to set RO and wait for writes, re-lock `block_group->lock` and recheck `BLOCK_GROUP_FLAG_ZONE_IS_ACTIVE`, `!block_group->reserved`, and `!BLOCK_GROUP_FLAG_ZONED_DATA_RELOC`. In `check_bg_is_active()`, `zoned_meta_io_lock` protects `active_meta_bg` / `active_system_bg`, and `*active_bg == tgt` must be rechecked under it after waiting before `btrfs_put_block_group(tgt)`. [F1200, F1201]

## Object Lifetimes

- `btrfs_add_chunk_map()` consumes the initial ref from `btrfs_alloc_chunk_map()`; call `btrfs_free_chunk_map()` if failing before/during `btrfs_add_chunk_map()`, and `btrfs_remove_chunk_map()` if rolling back after it succeeds. [F1165]
- Removing a `btrfs_device` from a mounted `fs_devices->devices` (`btrfs_rm_device`, `btrfs_rm_dev_replace_free_srcdev`, `btrfs_destroy_dev_replace_tgtdev`) requires `list_del_rcu(&device->dev_list)` and `synchronize_rcu()` before `btrfs_free_device()`. `btrfs_rm_device()` must return `device->bdev_file` via `*bdev_file` instead of closing it under the SB write lock. [F1172, F1177]
- `btrfs_read_disk_super()` returns a pagecache pointer released via `btrfs_release_disk_super()`; `btrfs_get_bdev_and_sb()` must close `*bdev_file` and NULL out `*disk_super` and `*bdev_file` on failure. [F1175]
- In `zstd_find_workspace()`, a higher-level workspace borrowed for a lower level (`clip_level(level) != workspace->level`) stays on `zwsm->lru_list` with `req_level != 0`; `zstd_reclaim_timer_fn()` must skip `victim->req_level != 0`, and `zstd_put_workspace()` resets `req_level = 0`. `zstd_free_workspace_manager()` must unlock `zwsm->lock` before `timer_delete_sync(&zwsm->timer)` and finish it before `kfree(zwsm)`. [F1179, F1180]
- `btrfs_schedule_zone_finish_bg()` takes refs on `bg` (`btrfs_get_block_group`) and `eb` (`bg->last_eb`) before queueing `bg->zone_finish_work`; `btrfs_zone_finish_endio_workfn()` must release both via `free_extent_buffer(bg->last_eb)` and `btrfs_put_block_group(bg)`. [F1182]

## API Contracts

- `btrfs_map_block()` sets `*bioc_ret = NULL` when using `smap` or on failure after `alloc_btrfs_io_context()` (after `btrfs_put_bioc(bioc)`), or returns a refcounted `btrfs_io_context` for `btrfs_put_bioc()`. `mirror_num` in `btrfs_map_block()` / `btrfs_map_repair_block()` is 1-based (`0` = any live mirror), so index stripes with `mirror_num - 1`. [F1169, F1247]
- `btrfs_find_chunk_map()` / `btrfs_find_chunk_map_nolock()` return `NULL` on miss and may return `map->start > logical` if `[logical, logical + length)` overlaps; `btrfs_get_chunk_map()` returns `ERR_PTR(-EINVAL)` (never `NULL`) on miss. [F1203]
- `btrfs_balance()` requires `balance_mutex` held on entry/exit and consumes `bctl` and the exclop: unless paused, every exit path frees `bctl` and calls `btrfs_exclop_finish()`. `chunk_*_filter()` helpers return `true` to skip a chunk and `false` to balance it. [F1174, F1266]
- `btrfs_scan_one_device()` opens with `BLK_OPEN_READ`, `holder = NULL`, and no `set_blocksize()` (`btrfs_get_bdev_and_sb()` calls `set_blocksize()` only when `holder != NULL`); when `mount_arg_dev == false`, it returns `NULL` when skipped by `btrfs_skip_registration()` and `ERR_PTR()` on error, requiring `IS_ERR_OR_NULL()`. [F1202, F1333]
- `find_free_dev_extent()` always writes `*start` and non-NULL `*len` (largest hole), even on `-ENOSPC`. Init `struct btrfs_dev_lookup_args` with `BTRFS_DEV_LOOKUP_ARGS_INIT` (`.devid = (u64)-1`), and call `btrfs_put_dev_args_from_path()` only after `btrfs_get_dev_args_from_path()`. [F1204, F1206]
- `btrfs_rm_device()` and `btrfs_check_raid_min_devices()` can return positive `BTRFS_ERROR_DEV_*` or negative `-errno`, so check `ret != 0`. Every `BTRFS_BLOCK_GROUP_*` profile and `enum btrfs_raid_types` entry must be in `btrfs_raid_array` with `BTRFS_RAID1_MAX_MIRRORS` matching max RAID1 `ncopies`. Pre-initialize buffers passed to `btrfs_describe_block_groups()` and `describe_balance_args()` in case `flags == 0`. [F1220, F1238, F1300]
- `btrfs_setxattr_trans()` must reuse non-NULL `current->journal_info` as `trans` without starting/ending a transaction, allowing only `XATTR_SECURITY_PREFIX` xattrs. [F1336]
- In `zlib_decompress()` and `zstd_decompress()`, errors or short output (`to_copy < destlen`) must zero the tail via `folio_zero_range(dest_folio, dest_pgoff + to_copy, destlen - to_copy)` and return `-EIO`. In `zstd.c`, convert signed `level` (`-15..15`) via `clip_level(level)` before indexing `zstd_ws_mem_sizes[]`, `zwsm->idle_ws[]`, or `zwsm->active_map`, keeping signed `level` in `workspace->req_level`. [F1212, F1213]
- Wrap allocations and `blkdev_zone_mgmt` in transaction, writeback, or I/O paths (`btrfs_initxattrs`, `zstd_get_workspace`, `sb_log_location`, `btrfs_advance_sb_log`, `btrfs_reset_device_zone`, `call_zone_finish`, `btrfs_reset_unused_block_groups`) in `memalloc_nofs_save()` / `memalloc_nofs_restore()`. Shift byte offsets/lengths by `>> SECTOR_SHIFT` for `blkdev_zone_mgmt()`, `blkdev_report_zones()`, `bdev_zone_capacity()`, and `blkdev_issue_zeroout()`. [F1321, F1327]
- `btrfs_zone_finish_one_bg()` returns `1` if finished, `0` if none eligible, `< 0` on error. `#else` stubs in `zoned.h` must preserve output contracts (`*bytenr_ret = btrfs_sb_offset(mirror)` in `btrfs_sb_log_location_bdev()`, `*bytes = 0` in `btrfs_reset_device_zone()`). [F1216, F1239]

## Error Handling

- In `btrfs_rm_device()`, after unlinking `device->dev_alloc_list` and decrementing `rw_devices` under `chunk_mutex`, any failure in `btrfs_shrink_device()` or `btrfs_start_transaction()` must jump to `error_undo`. `btrfs_dev_stat_inc_and_print()` and `find_live_mirror()` must use `btrfs_err_rl` / `btrfs_warn_rl`, suppressing stat prints until `dev->dev_stats_valid`. [F1173, F1341]
- In `btrfs_setxattr()`, if `btrfs_insert_xattr_item()` returns `-EOVERFLOW` or `-EEXIST`, reset `ret = 0` and call `btrfs_match_dir_item_name()` for in-place replacement (or `-ENOSPC` if `!di && !(flags & XATTR_REPLACE)`). [F1217]
- In `zlib_compress_folios()` and `zstd_compress_folios()`, advancing input folios must `kunmap_local()`, NULL out `data_in` / `workspace->in_buf.src`, and `folio_put(in_folio)` before `btrfs_compress_filemap_get_folio()`, and every exit path must set `*out_folios = nr_folios`. [F1181]
- `sb_write_pointer()` sets `*wp_ret = zones[0].start << SECTOR_SHIFT` and returns `-ENOENT` when both SB log zones are empty; `btrfs_get_dev_zone_info()` and `sb_log_location()` must treat `-ENOENT` as valid empty log (without subtracting `BTRFS_SUPER_INFO_SIZE` on `READ`). [F1210]

## External Contracts

- `btrfs_device_init_dev_stats()` may read stat `i` only if `item_size >= (1 + i) * sizeof(__le64)`, and `btrfs_get_dev_stats()` may write `stats->values[i]` only when `stats->nr_items > i`. `btrfs_check_zoned_mode()` must call `blk_stack_limits()` only when `bdev_is_zoned(device->bdev)`. [F1254, F1326]

## Known Pitfalls

- After `memcpy()` in `btrfs_init_sprout()`, re-init `seed_devices->{devices,alloc_list,device_list_mutex}`, and in `btrfs_setup_sprout()` repoint `device->fs_devices = seed_devices` and zero `fs_devices` counters. In `btrfs_rm_device()`, decrement `num_devices`, `missing_devices`, and `open_devices` on `cur_devices = device->fs_devices`, and decrement `total_devices` on both `cur_devices` and `fs_info->fs_devices`. [F1226, F1274]
- In `should_balance_chunk()`, keep `BTRFS_BALANCE_ARGS_LIMIT` / `LIMIT_RANGE` last because it decrements `bctl->{data,meta,sys}.limit` / `limit_max`; `__btrfs_balance()` must save those limits before `counting = true` and restore `limit` at `again:` when `counting = false`. [F1227, F1251]
- In `btrfs_shrink_device()`, restore `device->total_bytes`, `fs_devices->total_rw_bytes`, and `fs_info->free_chunk_space` under `chunk_mutex` at `done:` on failure. Backward B-tree loops in `__btrfs_balance()`, `btrfs_relocate_sys_chunks()`, and `btrfs_shrink_device()` must guard against `offset == 0` underflow. [F1228, F1250]
- `btrfs_read_sys_array()` passes extent_buffer offset `(struct btrfs_chunk *)sb_array_offset` to `btrfs_chunk_*` and `read_one_chunk()`, whereas `btrfs_del_sys_chunk()` uses `btrfs_stack_chunk_*` on host `super_copy->sys_chunk_array`. [F1252]
- Widen 32-bit stripe counts via `btrfs_stripe_nr_to_offset()` before `<< BTRFS_STRIPE_LEN_SHIFT`, and cast 32-bit `zone_number` and queue limits to `u64` / `sector_t` before shifting in `zoned.c`. Use `rounddown()` (not `round_down()`) for `devs_increment` and `nr_data_stripes(map)`, `div_u64()` / `div_u64_rem()` / `div64_u64()` for 64-bit divisions, and `time_after()` in `zstd_reclaim_timer_fn()`. [F1280, F1281, F1287, F1288, F1291]
