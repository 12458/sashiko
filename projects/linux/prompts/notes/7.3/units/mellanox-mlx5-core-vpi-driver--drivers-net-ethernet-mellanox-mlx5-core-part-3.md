# MELLANOX MLX5 core VPI driver — drivers/net/ethernet/mellanox/mlx5/core (part 3)

This unit implements the mlx5 E-Switch subsystem (`eswitch.c` and `esw/`), managing SR-IOV, Subfunctions (SFs), and Switchdev hardware offloads across virtual ports, ACLs (`esw/acl/`), legacy L2/VEPA (`esw/legacy.c`), indirect tables (`esw/indir_table.c`), bridge/multicast offloads (`esw/bridge*.c`), QoS (`esw/qos.c`), IPsec (`esw/ipsec*.c`), and devlink ports (`esw/devlink_port.c`).

## Architecture & Data Flow

- `esw->fdb_table` is a union of `legacy` and `offloads` discriminated by `esw->mode` (`MLX5_ESWITCH_LEGACY` vs `MLX5_ESWITCH_OFFLOADS`), valid only when `mlx5_esw_is_fdb_created(esw)` is true. `esw_create_legacy_fdb_table` partitions `esw->fdb_table.legacy.fdb` (`table_size = fdb->max_fte`) into `0 .. table_size - 3` (`addr_grp`), `table_size - 2` (`allmulti_grp`), and `table_size - 1` (`promisc_grp`). [F1304, F1343]
- `struct mlx5_vport_key` must remain `__packed` without padding and `flow_attr_to_vport_key` must initialize every field, as `mlx5_esw_vporttbl_get`/`put` pass un-zeroed stack keys to `jhash` and `memcmp`. [F1312]
- `vport->uc_list` and `vport->mc_list` only hold `struct vport_addr`, whereas `esw->mc_table` only holds `struct esw_mc_addr`; `container_of` and `l2addr_hash_find` must match. `esw->nb` (`eswitch_vport_event`, via `mlx5_nb_cof(nb, struct mlx5_eswitch, nb)`) and `esw->esw_funcs.nb` (`mlx5_esw_funcs_changed_handler`) are distinct `struct mlx5_nb` instances. [F1374, F1377]
- Skip manager vports (`mlx5_esw_is_manager_vport`) in `esw_legacy_vport_acl_setup`/`cleanup`, `mlx5_esw_vport_caps_get`, `mlx5_esw_vport_vhca_id_map`/`unmap`, and vport admin-state changes in `esw_vport_setup`/`cleanup`. Call `modify_esw_vport_cvlan` in `esw_vport_setup` and `__mlx5_eswitch_set_vport_vlan` only when `esw->mode == MLX5_ESWITCH_OFFLOADS || !esw_vst_mode_is_steering(esw)`. [F1389, F1391]
- `acl_ingress_ofld_setup` and `esw_acl_egress_ofld_setup` must increment `num_ftes`/`table_size` under the exact conditions that `esw_acl_ingress_ofld_groups_create` and `esw_acl_egress_ofld_groups_create` create 1-FTE groups. `esw_acl_ingress_ofld_rules_create` must call `esw_acl_ingress_mod_metadata_create` before `esw_acl_ingress_prio_tag_create` (and destroy `allow_rule` before `modify_metadata`), and `mlx5_esw_acl_ingress_vport_metadata_update` must restore `vport->metadata = vport->default_metadata` on error. [F1329, F1342]
- `mlx5_esw_bridge_fdb_entry_init`/`cleanup` must link/unlink `bridge->fdb_ht`, `bridge->fdb_list`, and `vlan->fdb_list` in lockstep with flow handles and `ingress_counter`. `mlx5_esw_bridge_mdb_port_insert`/`remove` must keep `entry->num_ports` synced with `entry->ports`, and `mlx5_esw_bridge_port_mdb_entry_detach` must destroy `entry` when `entry->num_ports == 0` or refresh `entry->egress_handle`. [F1321, F1322]
- Changing `MLX5_ESW_BRIDGE_VLAN_FILTERING_FLAG` (`mlx5_esw_bridge_vlan_filtering_set`) or `bridge->vlan_proto` (`mlx5_esw_bridge_vlan_proto_set`) requires calling both `mlx5_esw_bridge_fdb_flush` and `mlx5_esw_bridge_mdb_flush`; `mlx5_esw_bridge_vlan_proto_set` must also call `mlx5_esw_bridge_vlans_recreate`. [F1323]
- Bridge ports and FDB/MDB lookups in `br_offloads` must key on both `vport_num` and `esw_owner_vhca_id` (`mlx5_esw_bridge_port_key_from_data` / `mlx5_esw_bridge_port_key`), and `MLX5_ESW_BRIDGE_FLAG_PEER` FDB entries must be excluded from local switchdev notifications and aging. In `bridge_priv.h`, `[IDX_FROM, IDX_TO]` flow group ranges must form contiguous partitions summing to `MLX5_ESW_BRIDGE_{INGRESS,EGRESS,MCAST}_TABLE_SIZE`. [F1325, F1341]
- In `struct mlx5_esw_sched_node`, `node->vport` is `NULL` on node-level TSARs (`SCHED_NODE_TYPE_VPORTS_TSAR`, `SCHED_NODE_TYPE_VPORTS_TC_TSAR`); keep `sched_node_type_str` and `esw_qos_sched_elem_warn` synced with `enum sched_node_type`. Because `SCHED_NODE_TYPE_RATE_LIMITER` vport nodes are unlinked from `parent->children`, `esw_qos_nodes_set_parent` must update `child->vport->qos.sched_node->parent` via `SCHED_NODE_TYPE_VPORT_TC` grandchildren, and `mlx5_esw_qos_set_vport_min_rate` must propagate `min_rate` to `vport->qos.sched_nodes[i]`. [F1305, F1333, F1335]
- `vport->qos.sched_nodes` has `esw_qos_num_tcs(dev)` entries: validate `tc_bw` via `esw_qos_validate_unsupported_tc_bw`, never index `>= esw_qos_num_tcs(dev)`, and check `esw_qos_tc_bw_disabled(tc_bw)` before `esw_qos_set_tc_arbiter_bw_shares` so `esw_qos_calculate_tc_bw_divider` never sees a zero sum. [F1344, F1364]
- `mlx5_esw_ipsec_rx_setup_modify_header` allocates `sa_entry->rx_mapped_id` in `XA_LIMIT(1, ESW_IPSEC_RX_MAPPED_ID_MASK)` so `0` is the unmapped sentinel for `mlx5_esw_ipsec_rx_id_mapping_remove` and the ID fits at `ESW_ZONE_ID_BITS` of `METADATA_REG_C_1`. [F1349]
- Signature/contract changes in `eswitch.h` or `esw/acl/ofld.h` must update both `#ifdef CONFIG_MLX5_ESWITCH` declarations and `#else` stubs. [F1336]

## Synchronization

- Call `mlx5_esw_release` iff `mlx5_esw_hold` returned `true` (which it also does when `!mlx5_esw_allowed(esw)` without locking `esw->mode_lock`). `mlx5_esw_try_lock` and `mlx5_esw_lock` unlock `esw->mode_lock` on negative error, so call `mlx5_esw_unlock` only when `mlx5_esw_try_lock` returns `>= 0` or `mlx5_esw_lock` returns `0`. [F1259, F1260]
- Hold `devl_lock(priv_to_devlink(esw->dev))` for `mlx5_eswitch_enable_locked`, `mlx5_eswitch_enable`, `mlx5_eswitch_disable_sriov`, and `mlx5_eswitch_disable`. Hold `rtnl_lock` for `mlx5_esw_acl_ingress_vport_metadata_update`. [F1288, F1295]
- In `mlx5_esw_vport_alloc`, initialize `vport->dev`, `vport->vport`, `vport->index`, `vport->vhca_id`, and `INIT_WORK(&vport->vport_change_handler, ...)` before `xa_insert(&esw->vports, ...)`. [F1278]
- `eswitch_vport_event` runs in atomic notifier context and must defer work to `esw->work_queue` via `vport->vport_change_handler` (`esw_vport_change_handler`), which acquires `esw->state_lock`; never hold `esw->state_lock` when calling `mlx5_eswitch_event_handler_unregister` or `flush_workqueue(esw->work_queue)`. [F1280, F1392]
- `esw->state_lock` nests outside `esw_qos_lock(esw)` (`esw->qos.domain->lock`) and is required by `mlx5_esw_qos_vport_disable`. In `mlx5_eswitch_unload_vport`, `mlx5_esw_offloads_unload_rep` (which calls `mlx5_esw_qos_vport_update_parent(vport, NULL, NULL)` and unregisters the devlink port) must precede `mlx5_esw_vport_disable`. [F1283, F1284]
- Hold `esw->fdb_table.offloads.vports.lock` across `esw_vport_tbl_lookup` and all `vports.table` / `e->num_rules` updates in `mlx5_esw_vporttbl_get`/`put`. Hold `esw->fdb_table.offloads.indir->lock` across lookup, creation, `e->fwd_ref`, `mlx5_esw_indir_table_rule_get`/`put`, and removal in `mlx5_esw_indir_table_get`/`put`. [F1289, F1290]
- All bridge offload state (`br_offloads->bridges`, `ports`, `fdb_list`/`ht`, `mdb_list`/`ht`, `port->vlans`) requires `rtnl_lock`; `mlx5_esw_bridge_debugfs_start` must acquire `rtnl_lock()` on all returns and `mlx5_esw_bridge_debugfs_stop` releases it. In `mlx5_esw_bridge_ingress_flow_peer_create` and `mlx5_esw_bridge_mcast_filter_flow_peer_create`, hold `mlx5_devcom_for_each_peer_begin(devcom)` across both peer lookup and `peer_esw` flow creation. [F1276, F1291, F1294]
- Async FDB work in `mlx5_esw_bridge_fdb_create` and `mlx5_esw_bridge_port_vlan_lookup` must re-verify that `mlx5_esw_bridge_port` and `mlx5_esw_bridge_vlan` still exist. `mlx5_esw_bridge_update` must skip FDB entries with `MLX5_ESW_BRIDGE_FLAG_DELETED` (set by `mlx5_esw_bridge_fdb_mark_deleted`) or `ADDED_BY_USER`, and compare timestamps with `time_after` and `time_is_before_jiffies`. [F1292, F1293, F1366]
- `mlx5_esw_ipsec_restore_dest_uplink` must check `atomic_read(&rep->rep_data[REP_ETH].state) == REP_LOADED` before walking `rpriv->tc_ht` and skip `IS_ERR(flow)`. Use `xa_alloc_bh`/`xa_erase_bh` on `ipsec->ipsec_obj_id_map` because `mlx5_esw_ipsec_rx_ipsec_obj_id_search` runs in NAPI RX softirq. [F1297, F1401]

## Object Lifetimes

- A `struct vport_addr` with `mc_promisc == true` holds no reference on `esw_mc->refcnt` in `esw_add_mc_addr`, `esw_del_mc_addr`, and `esw_update_vport_addr_list` unless promoted by incrementing `esw_mc->refcnt` and clearing `addr->mc_promisc`. [F1261]
- `mlx5_esw_vport_disable` must set `vport->enabled = false` before `esw_vport_change_handle_locked(vport)`, and `esw_vport_cleanup` must not clear `vport->info`. [F1262]
- On error in `esw_acl_ingress_src_port_drop_create`, call `esw_acl_ingress_ofld_cleanup` only if `created == true`. ACL teardown helpers (`esw_acl_ingress_table_destroy`, `esw_acl_ingress_allow_rule_destroy`, `esw_acl_ingress_mod_metadata_destroy`, `esw_acl_egress_ofld_fwd2vport_destroy`) only check non-NULL, so creation paths must reset `vport->ingress.acl`, `allow_rule`, `modify_metadata_rule`, and `fwd_rule` to `NULL` on `IS_ERR`. [F1264, F1265]
- `mlx5_esw_offloads_pf_vf_devlink_port_init`/`cleanup` allocates and frees `vport->dl_port`, whereas `mlx5_esw_offloads_sf_devlink_port_init`/`cleanup` borrows `dl_port` and must only set `vport->dl_port = NULL`. [F1270]
- `mlx5_esw_indir_table_rule_get` must call `mlx5e_mod_hdr_dealloc(&mod_acts)` on both success and error paths, while holding `mlx5_chains_get_table(chains, 0, 1, 0)` until `mlx5_esw_indir_table_rule_put` drops `rule->refcnt` to 0 and clears `e->recirc_rule = NULL`; `mlx5_esw_indir_table_put` destroys the entry only when `e->fwd_ref == 0 && !e->recirc_rule`. [F1271, F1272]
- `mlx5_esw_bridge_lookup` (on `mlx5_esw_bridge_create` failure) and `mlx5_esw_bridge_put` (when `bridge->refcnt == 0`) must call `mlx5_esw_bridge_ingress_table_cleanup` if `br_offloads->bridges` is empty. Clear `MLX5_ESW_BRIDGE_MCAST_FLAG` on `bridge->flags` before calling `mlx5_esw_brige_mcast_global_disable`. In `mlx5_esw_bridge_port_mdb_attach`, if `mlx5_esw_bridge_mdb_port_insert` fails, call `mlx5_esw_bridge_port_mdb_entry_cleanup` iff `!entry->num_ports`. [F1273, F1274, F1275]

## API Contracts

- `mlx5_devlink_eswitch_get` returns `ERR_PTR` (`IS_ERR()`), whereas `mlx5_devlink_eswitch_nocheck_get` returns a raw pointer that can be `NULL`. `mlx5_esw_vport_vhca_id` returns `bool` (`true` on success, `false` without modifying `*vhca_id` on failure). [F1299, F1301]
- `mlx5_esw_bridge_ingress_mld_fg_create` returns `NULL` when `MLX5_FLEX_PROTO_ICMPV6` is unsupported, or `ERR_PTR` on error; fail only on `IS_ERR` and guard MLD rules on `br_offloads->ingress_mld_fg != NULL`. `__esw_fdb_set_vport_rule` and its wrappers convert `IS_ERR` from `mlx5_add_flow_rules` to `NULL`. [F1302, F1303]
- Passing `MLX5_ESWITCH_IGNORE_NUM_VFS` (`< 0`) to `mlx5_eswitch_enable_locked` / `mlx5_eswitch_update_num_of_vfs` preserves `num_vfs` and `num_ec_vfs`. In `mlx5_eswitch_set_vport_state`, translate `MLX5_VPORT_UPLINK` to `opmod = MLX5_VPORT_STATE_OP_MOD_UPLINK`, `other_vport = 0`, `vport = 0`. [F1316, F1319]
- `set_action_in.data` in `mlx5_modify_header_alloc` takes unshifted values aligned to bit 0, whereas `fte_match_param` takes values shifted by `ESW_SOURCE_PORT_METADATA_OFFSET` or `ESW_ZONE_ID_BITS`. [F1318]
- Host VF `vport_num` is 1-based: `mlx5_eswitch_get_vport_config` and `mlx5_esw_offloads_pf_vf_devlink_port_attrs_set` must use `vport_num - 1` (`vport->adj_info.function_id` for adjacent VFs, `vport_num - base_vport` for EC VFs). `mlx5_esw_for_each_vf_vport` takes inclusive `last` (`num_vfs` for local VFs, `U16_MAX` with `vport->adjacent` check for adjacent VFs). Guard `mlx5_esw_for_each_ec_vf_vport` with `mlx5_core_ec_sriov_enabled(esw->dev)`. [F1320, F1338, F1339]
- Size `QUERY_DELEGATED_VHCA` `outlen` in `mlx5_esw_adjacent_vhcas_setup` as `MLX5_ST_SZ_BYTES(query_delegated_vhca_out) + delegated_vhca_max * MLX5_ST_SZ_BYTES(delegated_function_vhca_rid_info)`. [F1368]
- Ports using `mlx5_esw_pf_vf_dl_port_ops`, `mlx5_esw_dl_sf_port_ops`, or `mlx5_devlink_port_vport_get` must be embedded in `struct mlx5_devlink_port` initialized via `mlx5_devlink_port_init`. Devlink rate leaf `priv` is `struct mlx5_vport *`; rate node `priv`/`parent_priv` is `struct mlx5_esw_sched_node *`. [F1371, F1373]
- Keep `TRACE_INCLUDE_PATH`, `TRACE_INCLUDE_FILE`, and `#include <trace/define_trace.h>` outside the header guard in `bridge_tracepoint.h` and `qos_tracepoint.h`. [F1417]

## Error Handling

- In `mlx5_esw_bridge_egress_table_init`, non-fatal miss flow failures must reset the failed `miss_fg`, `miss_pkt_reformat`, or `miss_handle` pointer to `NULL` and free earlier miss resources before `skip_miss_flow`. [F1308]
- On failure in `esw_qos_tc_arbiter_scheduling_setup` or `esw_qos_node_enable_tc_arbitration`, destroy the new scheduling element and restore `node->ix` (and `node->type`). [F1310]

## External Contracts

- `__mlx5_eswitch_set_vport_vlan` rejects `vlan > 4095 || qos > 7` with `-EINVAL`; `mlx5_eswitch_set_vport_vlan` must return `0` (not `-EOPNOTSUPP`) when `esw->mode != MLX5_ESWITCH_LEGACY && vlan == 0`. [F1348]
- `mlx5_esw_bridge_fdb_create` and `mlx5_esw_bridge_fdb_del_notify` emit `SWITCHDEV_FDB_{ADD,DEL}_TO_BRIDGE` only when neither `ADDED_BY_USER` nor `PEER` is set, and `SWITCHDEV_FDB_OFFLOADED` for user-added entries. Convert `ageing_time` with `clock_t_to_jiffies` in `mlx5_esw_bridge_create` and `mlx5_esw_bridge_ageing_time_set`. [F1410, F1412]

## Known Pitfalls

- Zero reused `flow_group_in` with `memset(flow_group_in, 0, inlen)` between `mlx5_create_flow_group` calls in `esw_acl_ingress_{ofld,lgcy}_groups_create`. `MLX5_SET_TO_ONES` on `outer_headers` MACs must set both `*_47_16` and `*_15_0`. [F1313, F1347]
- Use `list_for_each_entry_safe` when reparenting/converting child nodes in `esw_qos_nodes_set_parent`, `esw_qos_switch_vport_tcs_to_vport`, and `esw_qos_switch_vports_node_to_tc_arbiter`. Never use `sizeof(tc_bw)` on decayed `u32 *tc_bw` parameters; use `sizeof(tc_arbiter_node->tc_bw)` or `DEVLINK_RATE_TCS_MAX * sizeof(u32)`. [F1352, F1370]
- Check `v == SEQ_START_TOKEN` before `list_entry` in `mlx5_esw_bridge_debugfs_next`/`show`. Set `other_vport` / `MLX5_FLOW_TABLE_OTHER_VPORT` when `vport_num != 0 || mlx5_core_is_ecpf(dev)` in `arm_vport_context_events_cmd` and `esw_acl_table_create`. [F1375, F1388]
