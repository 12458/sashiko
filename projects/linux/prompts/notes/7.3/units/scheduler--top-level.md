# SCHEDULER — (top level)

This component defines the core Linux scheduler headers (`include/linux/sched.h`, `include/linux/preempt.h`, `include/linux/wait.h`, `include/uapi/linux/sched.h`), unity-build units (`kernel/sched/build_policy.c`, `kernel/sched/build_utility.c`), and foundational utilities (`kernel/sched/autogroup.c`, `kernel/sched/clock.c`, `kernel/sched/completion.c`) for `struct task_struct`, preemption/migration control, waitqueues, completions, autogroups, and CPU scheduling clocks.

## Architecture & Data Flow

- In `struct task_struct`, `thread_info` must remain the first field under `CONFIG_THREAD_INFO_IN_TASK`, only scheduling-critical fields may precede `randomized_struct_fields_start`, and the scheduler-lock-serialized bitfields (`sched_reset_on_fork`..`sched_task_hot`) must be separated from `sched_remote_wakeup` and subsequent unserialized bitfields by `unsigned :0;`. [F620, F621]
- The MSB (`0x80000000`, `UTIL_AVG_UNCHANGED`) of `struct sched_avg::util_est` is a synchronization flag bit (relying on `util_est <= SCHED_CAPACITY_SCALE`); never store unmasked values reaching bit 31 or read arithmetic values without clearing `UTIL_AVG_UNCHANGED`. [F643]
- `__task_state_index()` and `task_index_to_char()` rely on `TASK_REPORT` occupying contiguous low bits (`0x01`..`0x40`) so `TASK_REPORT_IDLE` (`TASK_REPORT + 1`) is a power of two and `fls(state)` yields a `0..8` index into `state_char[]`; because `TASK_IDLE` is `TASK_UNINTERRUPTIBLE | TASK_NOLOAD` (`TASK_NOLOAD` outside `TASK_REPORT`), `__task_state_index()` must check `(tsk_state & TASK_IDLE) == TASK_IDLE` after masking with `TASK_REPORT`. [F622, F628]
- In `___wait_event()`, `if (condition) break;` must precede `if (___wait_is_interruptible(state) && __int)` so woken waiters consume the condition before failing with `-ERESTARTSYS`; only the `__int` signal path may `goto __out` past `finish_wait()`, while `cmd` exits (as in `__wait_event_hrtimeout()`) must `break`. [F631]
- `autogroup_task_group(p, tg)` must gate `p->signal->autogroup->tg` access on `task_wants_autogroup(p, tg)` (false when `tg != &root_task_group` or `p->flags & PF_EXITING`, which is set before `sched_autogroup_exit_task()` detaches the task). [F592]
- Under `CONFIG_HAVE_UNSTABLE_SCHED_CLOCK`, `__set_sched_clock_stable()` must compute `__sched_clock_offset` (`scd->tick_gtod + __gtod_offset - scd->tick_raw`) with IRQs disabled before enabling `__sched_clock_stable` and calling `tick_dep_clear(TICK_DEP_BIT_CLOCK_UNSTABLE)`; `__clear_sched_clock_stable()` must call `tick_dep_set(TICK_DEP_BIT_CLOCK_UNSTABLE)` before scheduling `sched_clock_work`, where `__sched_clock_work()` stamps and clones per-CPU `sched_clock_data` across all possible CPUs before disabling `__sched_clock_stable`. [F611, F660]
- In `sched_clock_local()` and `sched_clock_remote()`, 64-bit timestamp comparisons and clamping must use signed differences (`(s64)(x - y) < 0` via `wrap_min()`/`wrap_max()`), and in default `sched_clock()`, `(jiffies - INITIAL_JIFFIES)` must be cast to `unsigned long long` before multiplying by `(NSEC_PER_SEC / HZ)`. [F638, F639]
- In `include/linux/preempt.h`, `in_serving_softirq()`, `in_task()`, and `interrupt_context_level()` must test `SOFTIRQ_OFFSET` rather than `SOFTIRQ_MASK` (so `SOFTIRQ_DISABLE_OFFSET` is not misclassified as active softirq), and `interrupt_context_level()` must accumulate higher-priority masks (`NMI_MASK`, `NMI_MASK | HARDIRQ_MASK`, `NMI_MASK | HARDIRQ_MASK | SOFTIRQ_OFFSET`) at each step. [F626, F627]
- On `!CONFIG_PREEMPT_COUNT` kernels, `preempt_disable()`/`preempt_enable()` (and `_notrace`/`_no_resched` variants) must still expand to compiler `barrier()`s so faulting calls like `get_user()`/`put_user()` are not reordered. [F667]

## Synchronization

- Updates to `task_struct::uclamp_req` and `task_struct::uclamp` require `task_rq_lock()`; `current_save_and_set_rtlock_wait_state()` and `current_restore_rtlock_saved_state()` require IRQs disabled and `current->pi_lock` held while saving `current->__state` to `current->saved_state`, setting `TASK_RTLOCK_WAIT`, or restoring `__state` and resetting `saved_state` to `TASK_RUNNING`. [F570, F573]
- `__migrate_disable()` increments `this_rq_pinned()` only on the outer `0 -> 1` transition under disabled preemption, `__migrate_enable()` on `1 -> 0` must disable preemption, restore `current->cpus_ptr` via `___migrate_enable()`, and issue `barrier()` before clearing `migration_disabled = 0` and decrementing `this_rq_pinned()`, and both must cast `unsigned short migration_disabled` to `s16` for `<= 0` / `< 0` overflow/underflow checks. [F566, F605, F642]
- Code inside a spinlock, rwlock, softirq, or regular interrupt handler needing CPU-local preemption serialization without a dedicated lock must pair `preempt_disable_nested()` and `preempt_enable_nested()` (those contexts remain preemptible on `CONFIG_PREEMPT_RT`). [F665]
- Wait loops not serialized with wakeups under a common lock must use `set_current_state()` (`smp_store_mb()`) before testing the condition rather than `__set_current_state()`, and lockless wakeup checks using `waitqueue_active()` or `wq_has_single_sleeper()` require a prior `smp_mb()` (as in `wq_has_sleeper()`) after storing the wake condition. [F578, F579]
- `__wait_event_interruptible_locked()` requires `wq.lock` held on entry matching `fn` (`spin_lock()` for `do_wait_intr`, `spin_lock_irq()` for `do_wait_intr_irq`) and unlinks `__wait` via `__remove_wait_queue()` and resets `TASK_RUNNING` under `wq.lock` on all exits; `__wait_event_*lock_irq*()` require `lock` held on entry, drop it via `spin_unlock_irq(&lock)` only around `cmd` and `schedule*()`, and reacquire it before retesting `condition` or exiting (`cmd` must not return, break, or relock). [F555, F556]
- `try_wait_for_completion()` and `do_wait_for_common()` must recheck `x->done` under `x->wait.lock` before decrementing `x->done` (when `x->done != UINT_MAX`), even after an earlier `READ_ONCE(x->done)` or after reacquiring `x->wait.lock` from `action(timeout)`. [F577]
- `sched_autogroup_create_attach()` must never be called under any spinlock (`autogroup_create()` uses `GFP_KERNEL` and `autogroup_move_group()` takes `sighand->siglock`), and `sched_autogroup_detach()` must never be called under `sighand->siglock`. [F575]
- Because `autogroup_default` wraps `root_task_group` without setting `root_task_group.autogroup`, `proc_sched_autogroup_show_task()` and `autogroup_path()` must check `task_group_is_autogroup()`; in `proc_sched_autogroup_set_nice(p, nice)` and `proc_sched_autogroup_show_task(p, ...)`, callers must check `security_task_setnice()`/`can_nice()` against `current`, pin `p` via `autogroup_task_get(p)`, hold `ag->lock` (`down_write` to update, `down_read` to read), sanitize `array_index_nospec(nice + 20, 40)` for `sched_prio_to_weight[]`, update `ag->nice` only if `sched_group_set_shares()` succeeds, and call `autogroup_kref_put(ag)`. [F568, F610, F617, F636]
- Reading/stamping `scd->tick_gtod` and `scd->tick_raw` (in `__set_sched_clock_stable()`, `sched_clock_tick_stable()`, and `sched_clock_init()` via `__sched_clock_gtod_offset()`) requires local IRQs disabled; `sched_clock_init()` must finish `__sched_clock_gtod_offset()` before `static_branch_inc(&sched_clock_running)`, and `sched_clock_idle_wakeup_event()` must return early if `timekeeping_suspended` is set before calling `sched_clock_tick()`. [F562, F574, F659]
- `sched_clock_init_late()` must run as a `late_initcall()` and issue `smp_mb()` between incrementing `sched_clock_running` and reading `__sched_clock_stable_early`, paired with `smp_mb()` in `clear_sched_clock_stable()` between clearing `__sched_clock_stable_early` and checking `sched_clock_running`. [F661]
- `sched_clock_local()` and `sched_clock_remote()` must update `scd->clock` via `raw_try_cmpxchg64()`/`try_cmpxchg64()` loops (on 32-bit, `sched_clock_remote()` must read remote `scd->clock` via `cmpxchg64(&scd->clock, 0, 0)` and call `sched_clock_local(my_scd)` inside the loop), and `local_clock_noinstr()` must be called with preemption disabled and only invoke `noinstr`-safe helpers. [F581, F681]

## Object Lifetimes

- In `autogroup_destroy()`, `ag->tg->rt_se` and `ag->tg->rt_rq` must be reset to `NULL` (under `CONFIG_RT_GROUP_SCHED`) before `sched_destroy_group(ag->tg)` because `autogroup_create()` aliased them to `root_task_group`; never `kfree(ag)` in `autogroup_destroy()`, as `sched_destroy_group()` defers freeing across RCU to `autogroup_free()`. [F546, F547]
- After observing `READ_ONCE(x->done)` non-zero, `completion_done()` must still lock and unlock `x->wait.lock` before returning `true` so callers freeing `x` cannot race with `complete()`; in `do_wait_for_common()`, on-stack `DECLARE_SWAITQUEUE(wait)` must be unlinked and `TASK_RUNNING` restored via `__finish_swait(&x->wait, &wait)` under `x->wait.lock` on every exit path. [F550, F551]
- Before freeing a polled `struct wait_queue_head` whose lifetime is shorter than the polled `struct file`, the owner must call `wake_up_pollfree(wq_head)` and RCU-delay freeing the `wait_queue_head`. [F552]
- `__wait_event_hrtimeout()` must pair `hrtimer_setup_sleeper_on_stack(&__t, ...)` with both `hrtimer_cancel(&__t.timer)` and `destroy_hrtimer_on_stack(&__t.timer)` after `___wait_event()` on all exit paths, even when `timeout == KTIME_MAX`. [F554]

## API Contracts

- `set_current_state()`/`__set_current_state()` only accept normal wait states (`!is_special_task_state(state_value)`), whereas `__TASK_STOPPED`, `__TASK_TRACED`, `TASK_PARKED`, `TASK_DEAD`, and `TASK_FROZEN` require `set_special_state()` (under `current->pi_lock`); `task_index_to_char()` takes an index (`0..8`) from `[__]task_state_index()`, never a raw `TASK_*` bitmask. [F601, F602]
- `alloc_tag_save(tag)` swaps `current->alloc_tag` with `tag` and returns `old`; callers must pass both to `alloc_tag_restore(tag, old)` on all exit paths. [F560]
- `preempt_ops::sched_out` runs with `rq->lock` held and IRQs disabled, whereas `sched_in` runs without `rq->lock` and with IRQs enabled; `cond_resched_lock()` and `cond_resched_rwlock_*()` must never be called inside `rcu_read_lock()`; `*preempt_enable_no_resched*` and `preempt_check_resched` are undefined under `#ifdef MODULE`; and drivers must never use `in_atomic()` to test whether sleeping is permitted (`PREEMPT_DISABLE_OFFSET == 0` when `!CONFIG_PREEMPT_COUNT`, `PREEMPT_LOCK_OFFSET == 0` on `PREEMPT_RT`). [F576, F662, F675, F697]
- `wait_event_{interruptible,killable,freezable}_timeout()`, `wait_event_interruptible_lock_irq_timeout()`, and `wait_for_completion_{interruptible,killable}_timeout()` return signed `long` (`-ERESTARTSYS` on signal, `0` on timeout, `>= 1` on success), so callers must store the result in a signed `long` and check `< 0`. [F583, F585]
- `complete_all()` must not be called from hardirq/NMI context on `CONFIG_PREEMPT_RT` (`lockdep_assert_RT_in_threaded_ctx()`), and because it sets `x->done = UINT_MAX`, `completion_done()` and `try_wait_for_completion()` always return `true` until `reinit_completion()` and cannot test whether waiters have finished. [F586, F684]

## Error Handling

- On allocation failure in `autogroup_create()`, it must free any partial `struct autogroup`, log a `printk_ratelimit()`-guarded `KERN_WARNING`, and return `autogroup_kref_get(&autogroup_default)` rather than `NULL` or `ERR_PTR`. [F694]

## External Contracts

- `CLONE_NEWTIME` (`0x00000080`) overlaps `CSIGNAL` (`0x000000ff`) and is valid only in `unshare()` and `clone3()`; `struct clone_args` forbids `CSIGNAL`/`CLONE_DETACHED` in `flags`, takes lowest stack address in `stack` with byte size in `stack_size`, takes element count (not bytes) in `set_tid_size`, and requires new fields appended at the end as `__aligned_u64`; any new `SCHED_FLAG_*` constant must be added to `SCHED_FLAG_ALL`. [F603, F645, F687, F689]

## Known Pitfalls

- `task_struct::flags` uses pre-shifted `PF_*` masks (`&`, `|`) while `atomic_flags` uses `PFA_*` bit indices (`0..7` via `TASK_PFA_*` / `test_bit()`); `*_tsk_thread_flag()` take `TIF_*` bit indices while `atomic_long_*` on `task_thread_info(tsk)->flags` take shifted `_TIF_*` masks; and `tsk_used_math(p)`/`used_math()` return `0` or `PF_USED_MATH` (`0x2000`), never `1`. [F587, F599, F600]
- `wait_queue_entry` passed to `prepare_to_wait*()`/`finish_wait()` must be initialized with `DEFINE_WAIT*()`/`init_wait*()` (never `DECLARE_WAITQUEUE()`/`init_waitqueue_entry()`), on-stack `wait_queue_head` must use `DECLARE_WAIT_QUEUE_HEAD_ONSTACK()`, `__add_wait_queue()` must insert at tracked `head` (not loop cursor `wq`) after `WQ_FLAG_PRIORITY` entries, and macros calling `___wait_cond_timeout()` must declare `long __ret = timeout`. [F595, F596, F630, F632]
