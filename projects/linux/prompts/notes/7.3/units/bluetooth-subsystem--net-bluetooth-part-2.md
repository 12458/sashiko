# BLUETOOTH SUBSYSTEM — net/bluetooth (part 2)

This unit implements Bluetooth HCI event processing (`hci_event.c`) and the `PF_BLUETOOTH`/`BTPROTO_HCI` socket layer (`hci_sock.c`), parsing controller events and command completions to update `hci_dev`/`hci_conn` state and exposing raw, user, monitor, control (management), and logging HCI socket channels.

## Architecture & Data Flow
- `hci_ev_table` and `hci_le_ev_table` entries require designated `[op]` `HCI_EV*`/`HCI_LE_EV*` initializers; `struct hci_ev` unions `func` and `func_req` discriminated by `ev->req` (`HCI_EV_REQ`/`HCI_EV_REQ_VL`), so `hci_event_func()` must check `!ev->func` and branch on `ev->req`. Fixed-length `hci_cc_table` entries returning fields beyond `status` must use `HCI_CC(..., sizeof(struct hci_rp_...))` instead of `HCI_CC_STATUS`, and `hci_cmd_complete_evt()` must set `*status = skb->data[0]` before `hci_req_cmd_complete()` when `ev->opcode` is not in `hci_cc_table`. [F46, F64, F67, F94]
- When matching `hci_skb_event(hdev->req_skb)`, `hci_event_packet()` must require `hci_opcode_ogf(hci_skb_opcode(hdev->req_skb)) != 0x08`, whereas `hci_le_meta_evt()` must require OGF `0x08` (or `HCI_OP_NOP`). [F87]
- In `hci_cc_read_buffer_size()` and `hci_cc_le_read_buffer_size{_v2}()`, setting `*_pkts` (`acl`, `sco`, `le`, `iso`) must also initialize `*_cnt`; reject `!hdev->acl_mtu || !hdev->acl_pkts` and non-zero `hdev->le_mtu < HCI_MIN_LE_MTU` with `HCI_ERROR_INVALID_PARAMETERS`. In `hci_num_comp_pkts_evt()` and `hci_cc_delete_stored_link_key()`, clamp `conn->sent` and `hdev->stored_num_keys` to 0 before subtraction and clamp `hdev->*_cnt` to `hdev->*_pkts` after addition. [F54, F70, F103]
- Before accessing `conn->iso_qos.ucast` (unioned with `bcast` in `struct bt_iso_qos`), handlers (`hci_unbound_cis_failed()`, `hci_le_cis_established_evt()`) must verify `conn->type == CIS_LINK` rather than inferring unicast ISO from `conn->dst`. In `hci_le_big_sync_established_evt()` (`ev->status == 0`), each BIS `hci_conn` must set `bis->state = BT_CONNECTED`, set `HCI_CONN_BIG_SYNC` in `bis->flags`, and call `hci_debugfs_create_conn(bis)` and `hci_conn_add_sysfs(bis)` before `hci_iso_setup_path(bis)`. In `hci_le_big_info_adv_report_evt()`, copy `ev->encryption` to `pa_sync->iso_qos.bcast.encryption` before `hci_connect_cfm(pa_sync, 0)`. [F42, F47, F52]
- In `le_set_scan_enable_complete()`, `LE_SCAN_ENABLE` must only call `clear_pending_adv_report(hdev)` and `hci_discovery_set_state(hdev, DISCOVERY_FINDING)` when `hdev->le_scan_type == LE_SCAN_ACTIVE`, and `LE_SCAN_DISABLE` must cancel `hdev->le_scan_disable` and flush any pending report via `mgmt_device_found()`. In `hci_resolve_next_name()`, check `discov->name_resolve_timeout` with `time_after(jiffies, ...)`. [F53, F104]
- In `hci_cc_le_set_adv_set_random_addr()`, only update `adv->random_addr` when `cp->handle != 0`. When disabling or terminating a single extended advertising set (`hci_cc_le_set_ext_adv_enable()` with `cp->num_of_sets != 0` or `hci_le_ext_adv_term_evt()`), do not clear `HCI_LE_ADV` on `hdev` if any `adv_info` in `hdev->adv_instances` still has `adv->enabled` set. [F58, F59]
- In `hci_cc_read_local_ext_features()` and `hci_remote_ext_features_evt()`, verify wire `page < HCI_MAX_PAGES` before indexing `features[page]`, and do not update `hdev->max_page` when `HCI_QUIRK_BROKEN_LOCAL_EXT_FEATURES_PAGE_2` is set. In `hci_le_ext_adv_report_evt()`, mask `info->primary_phy` and `info->secondary_phy` with `0x1f` under `HCI_QUIRK_FIXUP_LE_EXT_ADV_REPORT_PHY`. In `hci_encrypt_change_evt()`, skip `HCI_OP_WRITE_AUTH_PAYLOAD_TO` under `HCI_QUIRK_BROKEN_WRITE_AUTH_PAYLOAD_TIMEOUT`, and otherwise send it only when `HCI_CONN_ENCRYPT` and `HCI_CONN_AES_CCM` are set and Ping is supported (`lmp_ping_capable(hdev)` or `HCI_LE_PING`). [F71, F113, F114, F116]
- `check_pending_le_conn()` must not initiate a connection while `hdev->suspended` is true, or while `hdev->conn_hash.le_num_peripheral > 0` if `HCI_QUIRK_BROKEN_LE_STATES` is set or `!(hdev->le_states[3] & 0x10)`. Loops over `hdev->conn_hash.list` or `hdev->adv_instances` that delete entries (`hci_unbound_cis_failed()`, `hci_cc_le_clear_adv_sets()`) must use `list_for_each_entry_safe` under `hdev->lock`. [F93, F115]
- In `hci_mgmt_cmd()` and `hci_logging_frame()`, verify `skb->len >= sizeof(*hdr)` (or `+ 3`) before computing unsigned `skb->len - sizeof(*hdr)`. `hci_mgmt_cmd()` must verify `__le16_to_cpu(hdr->len) == skb->len - sizeof(*hdr)`, `opcode < chan->handler_count`, and `len` against `handler->data_len` (`>=` if `HCI_MGMT_VAR_LEN`, else `==`). `hci_logging_frame()` must verify `__le16_to_cpu(hdr->len) == skb->len - sizeof(*hdr)`, `__le16_to_cpu(hdr->opcode) == 0x0000`, `priority <= 7`, `ident_len <= skb->len - sizeof(*hdr) - 3`, and NUL bytes at `skb->data[sizeof(*hdr) + ident_len + 1]` and `skb->data[skb->len - 1]`. [F76, F77, F102]
- `hci_pi(sk)` casts `struct sock *` to `struct hci_pinfo *`, requiring `struct bt_sock bt` to remain the first member of `struct hci_pinfo` and every `sk` in `hci_sk_list` or passed to `hci_sock_*` helpers to be allocated with `hci_sk_proto`. [F109]

## Synchronization
- Callbacks in `hci_ev_table`, `hci_le_ev_table`, `hci_cc_table`, and `hci_cs_table` are entered without `hdev->lock` and must unlock any `hci_dev_lock(hdev)` they acquire before returning, whereas helpers `check_pending_le_conn()`, `process_adv_report()`, and `hci_unbound_cis_failed()` require the caller to hold `hci_dev_lock(hdev)`. [F12, F23]
- Because `hci_conn_hash_lookup_*()` drops `rcu_read_unlock()` before returning an unreferenced `struct hci_conn *`, event handlers (like `hci_num_comp_pkts_evt()`) must hold `hci_dev_lock(hdev)` across the lookup and operations like `hci_conn_tx_dequeue()`. When iterating BIS connections in `hci_le_create_big_complete_evt()` or `hci_le_big_sync_lost_evt()` to call sleeping or list-mutating helpers (`hci_debugfs_create_conn()`, `hci_conn_del()`), hold `hci_dev_lock(hdev)` and loop on `hci_conn_hash_lookup_big_state()` instead of `list_for_each_entry_rcu`. [F22, F121]
- In `hci_conn_complete_evt()` and `le_conn_complete_evt()`, an existing `hdev->conn_hash` entry with `conn->role == HCI_ROLE_MASTER` must have `conn->state == BT_CONNECT` before being used as the active outgoing connection. [F17]
- Before sending `HCI_OP_READ_ENC_KEY_SIZE` in `hci_read_enc_key_size()`, pre-populate `conn->enc_key_size` from `hci_conn_key_enc_size(conn)` or `hdev->min_enc_key_size`; in `hci_cc_read_enc_key_size()`, if `conn->enc_key_size` is smaller than `hdev->min_enc_key_size` or `*key_enc_size`, clear both `HCI_CONN_ENCRYPT` and `HCI_CONN_AES_CCM` on `conn->flags` and set `status = HCI_ERROR_AUTH_FAILURE`. [F16, F55]
- In `handle_cmd_cnt_and_timer()`, checking `!test_bit(HCI_RESET, &hdev->flags)` and `!hci_dev_test_flag(hdev, HCI_CMD_DRAIN_WORKQUEUE)` and queuing `hdev->ncmd_timer` must occur inside `rcu_read_lock()`. In `hci_cc_inquiry_cancel()` and `hci_inquiry_complete_evt()`, order `clear_bit(HCI_INQUIRY, &hdev->flags)` with `smp_mb__after_atomic()` before `wake_up_bit(&hdev->flags, HCI_INQUIRY)`. [F28, F29]
- Because `hci_sock_create()` links `sk` into `hci_sk_list` in state `BT_OPEN`, `hci_sock_bind()` must initialize `channel`, `hdev`, flags, and `mtu` on `hci_pi(sk)` under `lock_sock(sk)` before setting `sk->sk_state = BT_BOUND`. [F15]
- `lock_sock(sk)` nests outside `mgmt_chan_list_lock`, `hdev->lock`, `hci_dev_list_lock`, and `hci_sk_list.lock`; `hci_sock_ioctl()` must drop `lock_sock(sk)` before calling unbound device ioctls (`hci_dev_open()`, `hci_dev_close()`, `hci_dev_reset()`, `hci_dev_cmd()`, `hci_inquiry()`). All `mgmt_chan_list` accesses and `hci_mgmt_cmd()` execution must hold `mgmt_chan_list_lock`. All `sk_buff` allocations/clones under `read_lock(&hci_sk_list.lock)` or `read_lock(&hci_dev_list_lock)` in `hci_sock.c` must use `GFP_ATOMIC`. [F126, F127, F128]

## Object Lifetimes
- When `check_pending_le_conn()` starts an implicit auto-connection (`!params->explicit_connect`), it stores an extra `hci_conn_get(conn)` reference in `params->conn` that `le_conn_complete_evt()` must release via `hci_conn_drop()`, `hci_conn_put()`, and `params->conn = NULL`. Unlinking a debug `struct link_key` in `hci_link_key_notify_evt()` or a single-use `SMP_STK` `struct smp_ltk` in `hci_le_ltk_request_evt()` under `hci_dev_lock(hdev)` requires `list_del_rcu()` and `kfree_rcu(..., rcu)`. [F2, F25]
- `hci_sock_dev_event(hdev, HCI_DEV_UNREG)` only sets `sk->sk_err = EPIPE` under `read_lock(&hci_sk_list.lock)`; `hci_pi(sk)->hdev` is only cleared and put under `lock_sock(sk)` in `hci_sock_bind()` or `hci_sock_release()`. When re-binding a socket whose `hdev` has `HCI_UNREGISTER` set, `hci_sock_bind()` must clear `hci_pi(sk)->hdev = NULL`, reset `sk->sk_state = BT_OPEN`, and call `hci_dev_put(hdev)` before checking `sk->sk_state == BT_BOUND`. [F5, F20]
- On `HCI_CHANNEL_USER` bind failure in `hci_dev_open(hdev->id)` (other than `-EALREADY`), `hci_sock_bind()` must clear `HCI_USER_CHANNEL`, call `mgmt_index_added(hdev)`, and call `hci_dev_put(hdev)` without incrementing `hdev->promisc` or setting `hci_pi(sk)->hdev`. In `hci_sock_release()` for `HCI_CHANNEL_USER`, call `hci_dev_do_close(hdev)`, `hci_dev_clear_flag(hdev, HCI_USER_CHANNEL)`, and `mgmt_index_added(hdev)` only if `!hci_dev_test_flag(hdev, HCI_UNREGISTER)`, but always run `atomic_dec(&hdev->promisc)` and `hci_dev_put(hdev)`. [F4, F119]
- A socket's monitor cookie (`hci_pi(sk)->cookie`) is allocated once via `hci_sock_gen_cookie()` (for `RAW`, `USER`, and `CONTROL` channels): if `hci_sock_gen_cookie(sk)` returns false in `hci_sock_bind()`, send `create_monitor_ctrl_close(sk)` before updating `hci_pi(sk)->hdev` and sending `create_monitor_ctrl_open(sk)`; in `hci_sock_release()`, call `hci_sock_free_cookie(sk)` after `create_monitor_ctrl_close(sk)`. [F9, F62]
- `hci_event_packet()` frees `skb` at `done:`, so `hci_event.c` callbacks must never call `kfree_skb(skb)`. In `hci_sock_sendmsg()`, `hci_logging_frame()` and `hci_mgmt_cmd()` borrow `skb` and must jump to `drop:`, whereas `HCI_CHANNEL_RAW` and `HCI_CHANNEL_USER` queue `skb` to `raw_q`/`cmd_q`. Every `sock_queue_rcv_skb(sk, skb)` call in `hci_sock.c` must call `kfree_skb(skb)` on non-zero return, and `hci_send_to_sock()`/`hci_send_to_monitor()` must unshare and reserve headroom via `__pskb_copy_fclone()` before `skb_push()`. [F6, F14, F135, F137]

## API Contracts
- `hci_hdev_from_sock(sk)` returns a borrowed `hci_pi(sk)->hdev` pointer, `ERR_PTR(-EBADFD)` when `NULL`, or `ERR_PTR(-EPIPE)` when `HCI_UNREGISTER` is set (never `NULL`); callers must hold `lock_sock(sk)`, check `IS_ERR(hdev)`, and never call `hci_dev_put(hdev)`. In `hci_mgmt_cmd()`, `hdev` from `hci_dev_get(index)` can be `NULL` (`HCI_MGMT_NO_HDEV`/`HCI_MGMT_HDEV_OPTIONAL`), is owned by `hci_mgmt_cmd()`, requires `if (hdev && chan->hdev_init)` before `chan->hdev_init(sk, hdev)`, and must be released at `done:` via `if (hdev) hci_dev_put(hdev)`. [F7, F8, F30, F33]
- Because `hci_event_func()`, `hci_le_meta_evt()`, and `hci_cc_func()` already pull `min_len` (`sizeof(*ev)`) bytes from `skb`, handlers with trailing flexible arrays or variable-length payloads must pull only `flex_array_size(ev, <member>, ev-><count>)` (never `struct_size()`) via `hci_ev_skb_pull()`, `hci_le_ev_skb_pull()`, or `hci_cc_skb_pull()`, and check the returned pointer for `NULL` before dereferencing. [F37, F66, F105]
- `hci_cc_func()` and `hci_cc_table` callbacks return an unsigned `u8` HCI status (`0x00` or `HCI_ERROR_*`, never a negative errno). `hci_sent_cmd_data(hdev, opcode)` returns `NULL` on missing/mismatched `hdev->sent_cmd` and must be NULL-checked by all `hci_cc_*`/`hci_cs_*` callers. [F38, F39]
- `hci_conn_add()`, `hci_conn_add_unset()`, and `hci_connect_le()` return `ERR_PTR` on failure (never `NULL`), whereas `hci_conn_hash_lookup_*()` returns `NULL`. Connection-complete handlers (`hci_conn_complete_evt()`, `hci_sync_conn_complete_evt()`, `le_conn_complete_evt()`) must abort `hci_debugfs_create_conn()` and `hci_conn_add_sysfs()` if `!HCI_CONN_HANDLE_UNSET(conn->handle)` or `hci_conn_set_handle()` returns non-zero. [F40, F43]
- `hci_mgmt_cmd()` must reject handlers lacking `HCI_MGMT_UNTRUSTED` with `MGMT_STATUS_PERMISSION_DENIED` unless `hci_sock_test_flag(sk, HCI_SOCK_TRUSTED)` is set. In `hci_sock_ioctl()`, setting `HCI_SOCK_TRUSTED` on an unbound `HCI_CHANNEL_RAW` socket must check `sk_capable(sk, CAP_NET_ADMIN)` rather than `capable(CAP_NET_ADMIN)`. [F142, F143]

## Error Handling
- `hci_sock_setsockopt()` and `hci_sock_setsockopt_old()` must use `copy_safe_from_sockptr()` rather than `copy_from_sockptr()`. In `check_pending_le_conn()`, check `!IS_ERR(conn)` on `hci_connect_le()` before setting `params->conn` and return `NULL` on error for `process_adv_report()`. In `hci_event_func()`, `hci_le_meta_evt()`, and `hci_cc_func()`, reject `skb->len < min_len` with `bt_dev_err` without calling the handler, whereas `skb->len > max_len` only warns and still calls the handler. [F31, F41, F144]

## External Contracts
- `hci_sock_compat_ioctl()` must pass integer device-ID `arg` values (`HCIDEVUP`, `HCIDEVDOWN`, `HCIDEVRESET`, `HCIDEVRESTAT`) unchanged to `hci_sock_ioctl()` and convert pointer ioctls via `(unsigned long)compat_ptr(arg)`. In `hci_sock_cmsg()`, 32-bit compat `HCI_CMSG_TSTAMP` (`!COMPAT_USE_64BIT_TIME && (msg->msg_flags & MSG_CMSG_COMPAT)`) must emit `struct old_timeval32`. [F36, F139]
- `hci_sec_filter` and `struct hci_filter` event/OCF masks must be tested via 32-bit `hci_test_bit()` and copied as two `u32` words in `HCI_FILTER` sockopts rather than `unsigned long` `test_bit()`. `hci_sock_setsockopt()` must reject `BT_SNDMTU`/`BT_RCVMTU` with `-ENOPROTOOPT` on `HCI_CHANNEL_RAW` and `HCI_CHANNEL_USER`. `hci_inquiry_result_with_rssi_evt()` must dispatch between `struct inquiry_info_rssi_pscan` and `struct inquiry_info_rssi` by matching `skb->len` against `array_size(ev->num, ...)`. [F74, F129, F140]

## Known Pitfalls
- In `hci_le_adv_report_evt()` and `hci_le_ext_adv_report_evt()`, each `ev->num` loop iteration must pull `sizeof(*info)` first and then pull `info->length + 1` (legacy `rssi` byte) or `info->length` bytes via `hci_le_ev_skb_pull()`. In `ext_evt_type_to_legacy()`, mask out `LE_EXT_ADV_DATA_STATUS_MASK` before testing `!evt_type`, and test `LE_EXT_ADV_DIRECT_IND` before returning `LE_ADV_IND` under `LE_EXT_ADV_CONN_IND`. [F82, F106]
- In `process_adv_report()`, only validate `direct_addr` RPA/IRK when `!hci_dev_test_flag(hdev, HCI_MESH) && direct_addr && hci_dev_test_flag(hdev, HCI_PRIVACY)`, and keep `!ext_adv` on the inner `store_pending_adv_report()` check (`!ext_adv && (type == LE_ADV_IND || type == LE_ADV_SCAN_IND)`) rather than the outer `!has_pending_adv_report(hdev)` branch. [F83, F84]
- Zero trailing `sizeof(cp.ltk) - ltk->enc_size` bytes of `cp.ltk` in `hci_le_ltk_request_evt()`, bound `ev->name` with `strnlen(ev->name, HCI_MAX_NAME_LENGTH)` in `hci_remote_name_evt()`, and use `get_unaligned_le16()` when reading 16-bit fields at raw offsets from `hci_sent_cmd_data()`. In `hci_user_confirm_request_evt()`, jump to `confirm` with `confirm_hint = 1` if `(!test_bit(HCI_CONN_AUTH_PEND, &conn->flags) && conn->io_capability != HCI_IO_NO_INPUT_OUTPUT)` or `hci_find_link_key(hdev, &ev->bdaddr)` holds. [F45, F73, F85, F111]
- In `hci_num_comp_pkts_evt()`, `switch (conn->type)` must cover `SCO_LINK`/`ESCO_LINK` for `sco_cnt`, `CIS_LINK`/`BIS_LINK`/`PA_LINK` for `iso_cnt`, and fall back to `acl_cnt` for `LE_LINK` when `!hdev->le_pkts`. When `hci_conn_complete_evt()` or `hci_sync_conn_complete_evt()` gets `SCO_LINK` with no matching `SCO_LINK` conn, fall back to `hci_conn_hash_lookup_ba(hdev, ESCO_LINK, &ev->bdaddr)` and set `conn->type = SCO_LINK`. [F88, F92]
- In `hci_disconn_complete_evt()`, guard `hci_conn_params_lookup()` and `hci_update_passive_scan(hdev)` with `if (conn->type == LE_LINK)`, and only fall through on `HCI_AUTO_CONN_LINK_LOSS` when `ev->reason == HCI_ERROR_CONNECTION_TIMEOUT`. In `hci_sock_copy_creds()`, if `!sk->sk_peer_pid` and `bt_sk(sk)->parent && bt_sk(sk)->parent->sk_peer_pid`, reassign `sk = bt_sk(sk)->parent` before reading `sk_peer_pid` and `sk_peer_cred`. [F90, F99]
