# MEMORY MANAGEMENT - CORE — (top level) (part 2)

This unit implements core memory management and architecture-independent page table operations (`mm/memory.c`, `mm/mmu_notifier.c`, `mm/highmem.c`, `mm/maccess.c`, `mm/debug.c`, `mm/folio-compat.c`, `mm/mmzone.c`, `mm/init-mm.c`, `mm/internal.h`, and `include/linux/pgtable.h`), covering page fault handling, page table allocation/zapping/remapping, cross-process VM access, highmem `kmap`/`kmap_local` mappings, nofault memory copies, and MMU notifier invalidations.

## Architecture & Data Flow
- In `free_pgd_range()`, `free_p4d_range()`, `free_pud_range()`, and `free_pmd_range()`, upper-bound checks on `end` and `ceiling` must compare `end - 1 > ceiling - 1` and `addr > end - 1`, and masking a non-zero `ceiling` down to `0` must return early. [F273]
- In `do_page_mkwrite()`, `vmf->flags` must be saved into `old_flags` before setting `vmf->flags = FAULT_FLAG_WRITE | FAULT_FLAG_MKWRITE` for `vmf->vma->vm_ops->page_mkwrite(vmf)`, and restored immediately after. In `gup_must_unshare()`, `(flags & (FOLL_WRITE | FOLL_PIN)) != FOLL_PIN` must require `FOLL_PIN` set and `FOLL_WRITE` clear before proceeding. [F254, F294]
- In `__access_remote_vm()` and `__copy_remote_vm_str()`, `addr` must be untagged with `untagged_addr_remote(mm, addr)` under `mmap_read_lock_killable(mm)` before `vma_lookup()` or `get_user_page_vma_remote()`. In `__copy_remote_vm_str()`, when `strscpy(buf, maddr + offset, bytes)` returns `-E2BIG` and `bytes != len`, `maddr + (PAGE_SIZE - 1)` must be re-copied into `buf + bytes - 1` because `strscpy()` overwrote it with NUL. [F276, F277]
- In `mm/mmu_notifier.c`, `interval_sub->interval_tree` stores inclusive `[start, start + length - 1]`: `__mmu_interval_notifier_insert()` must reject `length == 0` or `start + (length - 1)` overflow with `-EOVERFLOW`, and `mn_itree_inv_start_range()` / `mn_itree_inv_next()` must query `[range->start, range->end - 1]`. `subscriptions->invalidate_seq` must be even when idle and odd (`seq |= 1`) while invalidating; `interval_sub->invalidate_seq` must always be set to an odd value (`cur_seq` or `subscriptions->invalidate_seq - 1`). [F275, F304]
- In `mm/highmem.c`, under `kmap_lock`, `kunmap_high()` must only decrement `pkmap_count[nr]` down to `1`; only `flush_all_zero_pkmaps()` may transition `1` to `0` while clearing `pkmap_page_table[i]`, calling `set_page_address(page, NULL)`, and calling `flush_tlb_kernel_range()`. `kmap_local` fixmap addresses grow downward from `FIX_KMAP_BEGIN`: bounds checks must test `addr >= __fix_to_virt(FIX_KMAP_END) && addr <= __fix_to_virt(FIX_KMAP_BEGIN)` and `kmap_get_pte()` must index `&__kmap_pte[-idx]`. Under `CONFIG_DEBUG_KMAP_LOCAL`, `kmap_local_idx_push()` increments `idx` by `KM_INCR` (2) and returns `idx - 1`, leaving even slots (`!(i & 0x01)`) in `kmap_ctrl.pteval[]` zeroed as guard pages that `__kmap_local_sched_out()`/`in()` must skip. [F262, F278, F279]
- In `mm/maccess.c`, `copy_from_kernel_nofault()` and `strncpy_from_kernel_nofault()` must validate with `copy_from_kernel_nofault_allowed()` (returning `-ERANGE` on failure), while `copy_from_user_nofault()` must check `__access_ok()` and `nmi_uaccess_okay()`. When `!IS_ENABLED(CONFIG_HAVE_EFFICIENT_UNALIGNED_ACCESS)`, `u64`/`u32`/`u16` loops in `copy_from_kernel_nofault()` and `copy_to_kernel_nofault()` must gate on `align = (unsigned long)dst | (unsigned long)src` having low bits clear (`!(align & 7)`, `!(align & 3)`, `!(align & 1)`). [F281, F282]
- When initializing `struct xa_state` to populate/update XArray nodes where `!dax_mapping(mapping) && !shmem_mapping(mapping)`, callers must invoke `mapping_set_update(xas, mapping)` to set both `workingset_update_node` and `&shadow_nodes`. In `lruvec_init()`, `lruvec->lists[LRU_UNEVICTABLE]` must be poisoned via `list_del()` after `INIT_LIST_HEAD` because unevictable folios reuse `lru` for `mlock_count`. [F246, F267]
- In `include/linux/vmstat.h`, `zone_page_state_add()`, `node_page_state_add()`, and `zone_numa_event_add()` must update per-zone/node and global atomic arrays in lockstep, preserving `vmstat_text` layout indexed by `*_stat_name` and `vm_event_name`. In `mm/debug.c`, `pageflag_names[]` (`ARRAY_SIZE == __NR_PAGEFLAGS + 1`), `gfpflag_names[]`, and `vmaflag_names[]` must end with `{0, NULL}`, and `page_type_name()` must subtract `0xf0` from `page_type >> 24` and bounds-check `ARRAY_SIZE(page_type_names)`. [F266, F283]

## Synchronization
- Before publishing a new page table page into an upper entry (`pgd_populate`, `p4d_populate`, `pud_populate`, `pmd_populate`, `pmd_populate_kernel`), `smp_wmb()` must execute after initializing the page and its lock. On `CONFIG_GUP_GET_PXX_LOW_HIGH`, `ptep_get_lockless()` and `pmdp_get_lockless()` require interrupts disabled while looping over low/high words separated by `smp_rmb()`. [F211, F328]
- Every successful `follow_pfnmap_start(args)` returns with `args->lock` held and `args->ptep` mapped, and must be paired with `follow_pfnmap_end(args)` under `mmap_lock` (or `i_mmap_rwsem`). In `generic_access_phys()`, because `follow_pfnmap_end(&args)` drops the lock before `ioremap_prot()`, `follow_pfnmap_start(&args)` must be called again after `ioremap_prot()` to reverify `args.pgprot`, `args.pfn`, and `args.writable` across `memcpy_toio()`/`memcpy_fromio()`. [F203, F224]
- In `__wp_can_reuse_large_anon_folio()`, after optimistic lockless checks, `folio_lock_large_mapcount(folio)` must be acquired and both `test_bit(FOLIO_MM_IDS_SHARED_BITNUM, &folio->_mm_ids)` and `folio_large_mapcount(folio) != folio_ref_count(folio)` reverified under that lock before asserting mapcount invariants or reusing the folio. [F218]
- In `copy_pte_range()`, destination `dst_ptl` must be acquired first via `pte_alloc_map_lock()` and source `src_ptl` second via `spin_lock_nested(src_ptl, SINGLE_DEPTH_NESTING)`. A PTE protection transaction started with `ptep_modify_prot_start()` (or `modify_prot_start_ptes()`) must be committed with `ptep_modify_prot_commit()` (or `modify_prot_commit_ptes()`) before releasing the PTE lock. [F329, F336]
- `__apply_to_page_range()` must track modifications across all levels in `pgtbl_mod_mask mask` (`p4d_alloc_track()`, `pud_alloc_track()`, `pmd_alloc_track()`, `pte_alloc_kernel_track()`) and call `arch_sync_kernel_mappings(start, start + size)` whenever `mask & ARCH_PAGE_TABLE_SYNC_MASK` is non-zero. [F337]
- Under `FAULT_FLAG_VMA_LOCK`, `__vmf_anon_prepare()` must acquire `mmap_read_trylock(vma->vm_mm)` before `__anon_vma_prepare(vma)`, and if trylock fails, `vmf_anon_prepare()` must call `vma_end_read(vmf->vma)` and return `VM_FAULT_RETRY`. In `remove_device_exclusive_entry()`, because the PTE lock is not held during swap-entry lookup, the caller must pin `folio` with `folio_try_get(folio)` before `folio_lock_or_retry()` and `pte_same()`. [F338, F340]
- In `__might_fault()`, when `!pagefault_disabled()` and `current->mm` is non-NULL, `might_lock_read(&current->mm->mmap_lock)` must be called without gating on `CONFIG_DEBUG_ATOMIC_SLEEP`. `folio_evictable()` must hold `rcu_read_lock()` across `folio_mapping(folio)` and `mapping_unevictable()`. [F334, F345]
- In `__mmu_notifier_register()`, `struct mmu_notifier_subscriptions` must be allocated/initialized before `mm_take_all_locks(mm)` and published to `mm->notifier_subscriptions` via `smp_store_release()`, pairing with `smp_load_acquire()` in unlocked readers like `mmu_interval_notifier_insert()`. Callers of `mmu_interval_notifier_remove()` and `mmu_interval_read_begin()` must not hold any lock acquired inside an `invalidate` or `invalidate_range_start` callback because both sleep on `subscriptions->wq` waiting for `__mmu_notifier_invalidate_range_end()`. [F213, F216]

## Object Lifetimes
- In `handle_mm_fault()`, `vma` must not be dereferenced after `hugetlb_fault()` or `__handle_mm_fault()` because they may drop `mmap_lock` or the VMA lock and free `vma`; cache needed fields (`mm = vma->vm_mm`, `is_droppable`) beforehand. In `fault_dirty_shared_page()`, sample `folio_raw_mapping(folio)` while `folio` is locked before `folio_unlock(folio)`. [F222, F255]
- Consuming `vmf->prealloc_pte` via `pmd_install()` or `deposit_prealloc_pte()` must clear `vmf->prealloc_pte = NULL` so `do_fault()` can `pte_free()` any leftover. In `copy_present_page()`, set `*prealloc = NULL` only after `copy_mc_user_highpage()` succeeds; in `copy_pte_range()`, any unconsumed `prealloc` folio must be freed with `folio_put()` and reset to `NULL` after each PTE step and at exit. [F199, F200]
- In `wp_page_copy()`, under `vmf->ptl`, `ptep_clear_flush()` and `set_pte_at()` must complete before `folio_remove_rmap_pte(old_folio, vmf->page, vma)`, and `old_folio`'s page-table ref is transferred to `new_folio` to be dropped after `mmu_notifier_invalidate_range_end()`. [F204]
- `__kmap_local_pfn_prot()` pushes onto `current->kmap_ctrl` and calls `migrate_disable()`, and must be unmapped in strict LIFO order via `kunmap_local_indexed()`, which verifies the top slot address, clears the fixmap PTE and `kmap_ctrl.pteval`, pops `kmap_ctrl.idx`, and calls `migrate_enable()`. [F206]
- `__mmu_notifier_register()` takes `mmgrab(mm)` for a non-NULL `subscription`. `mn_hlist_release()` and `mmu_notifier_unregister()` must unlink `subscription->hlist` with `hlist_del_init_rcu()` under `subscriptions->lock` and call `synchronize_srcu(&srcu)` before returning / `mmdrop(mm)`. `mmu_notifier_put()` unlinks when `users == 0` and defers `ops->free_notifier()` and `mmdrop(mm)` via `call_srcu(&srcu, ...)` in `mmu_notifier_free_rcu()`; modules using `mmu_notifier_put()` must call `mmu_notifier_synchronize()` in `__exit`. [F208, F214, F349]
- While `mn_itree_is_invalidating(subscriptions)` is true, `__mmu_interval_notifier_insert()` and `mmu_interval_notifier_remove()` must defer `itree` mutations to `mn_itree_inv_end()` via `deferred_list`, and `mmu_interval_notifier_remove()` must wait on `subscriptions->wq` before `mmdrop(mm)`. `mn_itree_inv_end()` must drain `deferred_list` with `hlist_for_each_entry_safe()` under `subscriptions->lock`, checking `RB_EMPTY_NODE(&interval_sub->interval_tree.rb)` to select `interval_tree_insert()` vs `interval_tree_remove()` before `hlist_del(&interval_sub->deferred_item)`. [F210, F300]

## API Contracts
- `finish_fault()` expects the folio (`vmf->cow_page` or `vmf->page`) locked and referenced, and consumes that reference iff it returns `0`; on any non-zero `VM_FAULT_*`, the caller must unlock and `folio_put()` the folio. [F201]
- Callers of `folio_pte_batch_flags()`, `folio_pte_batch()`, and `swap_pte_batch()` must pass `max_nr >= 1` bounded to the current VMA and single PMD range. `folio_pte_batch_flags()` must clamp `max_nr` up front to `folio_pfn(folio) + folio_nr_pages(folio) - pte_pfn(pte)` and clamp its return with `min(nr, max_nr)` (as `pte_batch_hint()` can exceed `max_nr`), and callers must pass a local PTE copy in `@ptentp` rather than a page-table pointer (`!(virt_addr_valid(ptentp) && PageTable(virt_to_page(ptentp)))`) because `FPB_MERGE_*` mutates `*ptentp`. [F248, F268, F269]
- `modify_prot_start_ptes()` and `get_and_clear_full_ptes()` must merge `pte_dirty` and `pte_young` from every PTE in the batch into the returned PTE, and `modify_prot_commit_ptes()` must advance both `old_pte` and `pte` PFNs via `pte_next_pfn()` on each step. [F265]
- In `insert_pages()`, `pages_to_write_in_pmd` must be capped at `PTRS_PER_PTE - pte_index(addr)`. `curr_page_idx` must advance monotonically across batches/PMDs without resetting at `more:`, and `remaining_pages_total` must be decremented by `batch_size` after each batch or by `pte_idx` on mid-batch `insert_page_in_batch_locked()` error before setting `*num = remaining_pages_total` at `out:`. Every non-zero page inserted via `vm_insert_page()`, `vm_insert_pages()`, or `vmf_insert_page_mkwrite()` must belong to a referenced folio that is neither anonymous (`folio_test_anon`) nor typed (`page_has_type`) (`validate_page_before_insert()`). [F272, F299, F358]
- In `handle_mm_fault()`, `mem_cgroup_enter_user_fault()` / `mem_cgroup_exit_user_fault()` must be called only when `FAULT_FLAG_USER` is set, and if the fault finishes without `VM_FAULT_OOM` while `task_in_memcg_oom(current)` is true, `mem_cgroup_oom_synchronize(false)` must be called. [F363]
- `__mmu_notifier_register()` and `mmu_notifier_register()` accept `subscription == NULL` to initialize `itree` mode, so dereferences of `subscription` in `__mmu_notifier_register()` must be NULL-checked. A non-NULL `subscription` must not set both `ops->arch_invalidate_secondary_tlbs` and `ops->invalidate_range_start`/`end` (`-EINVAL`). [F236, F351]
- `kmap_high()` may sleep on `pkmap_map_wait` in `map_new_virtual()` and cannot be called from atomic/interrupt contexts (use `kmap_local_page()` or `kmap_high_get()`). `init_rss_vec()` and `add_mm_rss_vec()` require an `int` array of at least `NR_MM_COUNTERS` elements. Hardware-poisoned folios must be unmapped via `unmap_poisoned_folio(folio, pfn, must_kill)` rather than direct `try_to_unmap()`. `pagecache_get_page()` must return `folio_file_page(folio, index)` rather than `&folio->page`. [F315, F331, F359, F360]

## Error Handling
- `alloc_anon_folio()` returns a `struct folio *`, `NULL` on OOM, or `ERR_PTR(-EAGAIN)` when `pte_offset_map()` fails; `do_anonymous_page()` must check `IS_ERR(folio)` (returning `0` to retry) before `!folio` (`VM_FAULT_OOM`). In `do_swap_page()`, `ksm_might_need_to_copy()` returns a folio, `NULL` on OOM, or `ERR_PTR(-EHWPOISON)`; on failure, restore `folio = swapcache` before jumping to `out_page`. [F231, F232]
- `copy_from_user_nofault()` and `copy_to_user_nofault()` return `0` on full copy and `-EFAULT` on any non-zero residual from `__copy_*_user_inatomic()`, whereas `copy_folio_from_user()` returns the positive residual byte count (`0` on success). [F244]

## External Contracts
- Unlike `access_process_vm()` (which returns non-negative bytes transferred, `0` on failure), `copy_remote_vm_str()` and `__copy_remote_vm_str()` return `-EFAULT` on any error and must write `*(char *)buf = '\0'` whenever `len > 0` across all failure paths. [F238]
- `strncpy_from_kernel_nofault()` and `strncpy_from_user_nofault()` must always NUL-terminate `dst` when `count > 0` (`dst[count - 1] = '\0'` on truncation) and return the length including trailing NUL (up to `count`). Internal kernel-write probing helpers in `mm/maccess.c` such as `copy_to_kernel_nofault()` must not be exported via `EXPORT_SYMBOL*`. [F322, F350]

## Known Pitfalls
- In `finish_fault()`, if `nr_pages > 1` and `!pte_range_none(vmf->pte, nr_pages)` under the PTE lock, it must set `needs_fallback = true`, call `pte_unmap_unlock(vmf->pte, vmf->ptl)`, and jump to `fallback` (`nr_pages = 1`, `addr = vmf->address`) rather than returning `VM_FAULT_NOPAGE`. [F288]
- Functions iterating a `pte_t *` cursor (`copy_pte_range()`, `zap_pte_range()`, `insert_pages()`, `remap_pte_range()`, `apply_to_pte_range()`) must pass the initial mapped `pte_t *` to `pte_unmap_unlock()`, not the incremented cursor. In `apply_to_pte_range()`, `pte` must be incremented in `while (pte++, addr += PAGE_SIZE, addr != end)` rather than inside `if (create || !pte_none(ptep_get(pte)))`. [F289, F318]
- In `zap_pmd_range()`, if `zap_pte_range()` returns `addr != next` (transient `pte_offset_map_lock()` failure), `pmd--` must execute before `while (pmd++, cond_resched(), addr != end)` so the same PMD is re-processed. Under `CONFIG_HIGHPTE`, `__pte_map()` must cast `kmap_local_page()`'s `void *` to `pte_t *` before adding `pte_index(address)`. [F296, F317]
- On `CONFIG_SMP`, `global_zone_page_state()`, `global_node_page_state_pages()`, `zone_page_state()`, and `zone_page_state_snapshot()` must read `atomic_long_t` into a signed `long` and clamp negative values (`if (x < 0) x = 0`) before returning `unsigned long`. [F312]
