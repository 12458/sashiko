# ARM/QUALCOMM MAILING LIST — (top level) (part 1)

This component comprises core Qualcomm platform infrastructure and bus/peripheral drivers, including the Secure Channel Manager (`qcom_scm`), 32-bit ARM SMP bringup (`platsmp.c`), hardware CPU frequency scaling (`qcom-cpufreq-hw`), Application Data Mover DMA (`qcom_adm`), GENI/QUP I2C controllers, EBI2/SSC buses, timers, SPM cpuidle, PRNG crypto, SPMI extcon, SMD Bluetooth HCI, and hwspinlocks.

## Architecture & Data Flow
- In `__scm_smc_do_quirk()`, `quirk.state.a6` must be initialized to 0 before the retry loop and preserved across `QCOM_SCM_INTERRUPTED` iterations while `a0` is replaced with `res->a0`; `fill_wq_resume_args()` must zero all 8 `resume->args` entries before populating `args[0..2]` for `QCOM_SCM_WAITQ_SLEEP` resumption. [F50]
- In `qcom_cpufreq_hw_read_lut()`, allocate `LUT_MAX_ENTRIES + 1` entries for `policy->freq_table` (for the `CPUFREQ_TABLE_END` sentinel), and clamp `reg_perf_state` to `LUT_MAX_ENTRIES - 1` in `qcom_cpufreq_get_freq()`. When `dev_pm_opp_of_add_table()` succeeds, set `icc_scaling_enabled = true` and disable all DT OPPs via `for (rate = 0; ; rate++)` (incrementing `rate` after `dev_pm_opp_find_freq_ceil(cpu_dev, &rate)` and breaking on `IS_ERR(opp)`) before re-enabling LUT-matched OPPs via `qcom_cpufreq_update_opp()`. [F64, F92, F108]
- In `qcom_cpufreq_hw_target_index()` and `qcom_cpufreq_hw_fast_switch()`, when `data->per_core_dcvs` is true, writing `index` to `soc_data->reg_perf_state` must be followed by writing `index` to `soc_data->reg_perf_state + i * 4` for every sibling core `1 .. cpumask_weight(policy->related_cpus) - 1`. [F63]
- `spm_cpuidle_register()` must copy the static `qcom_spm_idle_driver` template into per-CPU `data->cpuidle_driver` before setting `cpumask = (struct cpumask *)cpumask_of(cpu)` and calling `dt_init_idle_driver()`. In `qcom_cpu_spc()`, restore `PM_SLEEP_MODE_STBY` via `spm_set_low_power_mode()` after `cpu_suspend(0, qcom_pm_collapse)`. `qcom_boot_secondary()` must check `!per_cpu(cold_boot_done, cpu)` before calling `func(cpu)` and only set `cold_boot_done = true` when `func(cpu) == 0`. [F67, F83, F174]
- In `adm_prep_slave_sg()`, snapshot `achan->mux`, `achan->crci`, and `blk_size` into `async_desc` so `adm_start_dma()` programs `ADM_CRCI_CTL` from `async_desc`; compute `box_count`/`single_count` with `DIV_ROUND_UP` (incrementing `single_count` if `sg_dma_len(sg) % burst != 0`) and include `sizeof(*cple) + 2 * ADM_DESC_ALIGN` in `async_desc->dma_len`. `cple` and `desc` must be 8-byte aligned (`PTR_ALIGN(..., ADM_DESC_ALIGN)`) with DMA addresses shifted `>> 3`, `adm_start_dma()` needs `wmb()` before writing `ADM_CH_CMD_PTR`, and `adm_dma_free_desc()` must free `async_desc->cpl` (not `cple`). [F77, F118, F131, F154]
- `adm_process_fc_descriptors()` and `adm_process_non_fc_descriptors()` must advance `desc` by `sizeof(*box_desc)` or `sizeof(*single_desc)` per descriptor and return it. In `adm_process_fc_descriptors()`, on `sg_is_last(sg)`, set `ADM_CMD_LC` on `single_desc->cmd` when `remainder != 0`, or on `box_desc->cmd` (if `box_desc` is non-NULL) when `remainder == 0`. In `adm_dma_xlate()`, save a match from `list_for_each_entry(chan, ...)` into `candidate` before breaking rather than checking `chan` after the loop. [F113, F114, F132]
- In `qup_i2c_probe()`, check `clk_freq` is in `1..I2C_MAX_FAST_MODE_PLUS_FREQ` before dividing by `clk_freq`. In `qup_i2c_disable_clocks()`, transition to `QUP_RESET_STATE` and set `QUP_CLOCK_AUTO_GATE` in `QUP_CONFIG` before `clk_disable_unprepare(qup->pclk)`, and call `qup_i2c_vote_bw(qup, 0)` to zero both the interconnect vote and `qup->cur_bw_clk_freq`. [F72, F121, F158]
- `qup_i2c_poll_state_mask()` requires `QUP_STATE_VALID` and `(state & req_mask) == req_state`; `qup_i2c_change_state()` must call `qup_i2c_poll_state_valid()` before writing `QUP_STATE` and `qup_i2c_poll_state()` after. In `qup_i2c_bus_active()`, poll `I2C_STATUS_BUS_ACTIVE` using `time_after(jiffies, timeout)` and on timeout set `ret = -ETIMEDOUT` and `break`. [F101, F103, F124, F152]
- In `qup_i2c_determine_mode_v2()`, keep `qup->use_dma = false` if any `msgs[idx].buf` satisfies `is_vmalloc_addr()`. When `qup->use_dma` is true in `qup_i2c_xfer_v2()`, `qup_i2c_interrupt()` must not write `QUP_RESET_STATE` on error (leaving recovery to `qup_i2c_bam_schedule_desc()`), and `qup_i2c_xfer_v2()` must reset `qup->use_dma = false` after `qup_i2c_bam_xfer()`. [F74, F180]
- In `qup_i2c_bam_xfer()`, `qup_i2c_bam_clear_tag_buffers()` must zero `btx.sg_cnt`, `brx.sg_cnt`, and `tag_buf_pos` before the message loop and after each `qup_i2c_bam_schedule_desc()` call; flush and clear whenever `sg_cnt > qup->max_xfer_sg_len` so messages and EOT/FLUSH tags do not overrun `(MX_DMA_BLOCKS << 1) + 1` SG entries. [F99, F104]
- `qup_i2c_set_blk_data()` must compute `qup->blk.count = DIV_ROUND_UP(msg->len, qup->blk_xfer_limit)`. In `qup_i2c_read_rx_fifo_v2()`, `qup_i2c_recv_tags()` shifts the first `QUP_IN_FIFO_BASE` word in `blk->rx_fifo_data` by `blk->rx_tag_len * 8`, sets `blk->rx_fifo_data_pos = blk->rx_tag_len`, and decrements `blk->fifo_available` by `blk->rx_tag_len` before `qup_i2c_recv_data()` starts at `j = blk->rx_fifo_data_pos`. [F75, F122]
- In `geni_i2c_irq()`, check `!cur || m_stat & (M_CMD_FAILURE_EN | M_CMD_ABORT_EN) || dm_rx_st & DM_I2C_CB_ERR` before FIFO RX/TX branches and, when `!dma`, write 0 to `SE_GENI_TX_WATERMARK_REG`. [F106]
- In `msm_timer_set_next_event()`, after clearing `TIMER_ENABLE_EN`, writing `TIMER_CLEAR`, and setting `TIMER_MATCH_VAL`, spin until `TIMER_STS_GPT0_CLR_PEND` clears in `sts_base` (if non-NULL) before re-enabling `TIMER_ENABLE_EN`. In `qcom_ebi2_setup_chipselect()`, clamp non-boolean DT `val` to `xp->max` before shifting by `xp->shift`. [F125, F151]

## Synchronization
- In `__scm_smc_do()`, lock and unlock `qcom_scm_lock` around each `__scm_smc_do_quirk_handle_waitq()` inside the `QCOM_SCM_V2_EBUSY` retry loop so the lock is not held across error returns or `msleep()`. Because `__scm_smc_do()` holds `qcom_scm_lock` while waiting on `__scm->waitq_comp`, `qcom_scm_irq_handler()` and `scm_get_wq_ctx()` must call `__scm_smc_do_quirk()` without `qcom_scm_lock`, and `scm_get_wq_ctx()` must use `ARM_SMCCC_FAST_CALL`. `__qcom_scm_qseecom_call()` requires `qcom_scm_qseecom_call_lock` held outside `qcom_scm_lock`. [F9, F28, F160, F167]
- In `qcom_cpufreq_hw_lmh_init()`, request `data->throttle_irq` with `IRQF_NO_AUTOEN` after initializing `throttle_lock` and `throttle_work`, enabling it only in `qcom_cpufreq_ready()`. In `qcom_cpufreq_hw_cpu_offline()`, set `data->cancel_throttle = true` under `throttle_lock` and unlock before `cancel_delayed_work_sync(&data->throttle_work)`, while `qcom_lmh_dcvs_notify()` checks `cancel_throttle` under `throttle_lock` before re-arming. Set `policy->fast_switch_possible = true` only when `!icc_scaling_enabled` because `qcom_cpufreq_set_bw()` sleeps in `dev_pm_opp_set_opp()`. [F32, F33, F171]
- In `qup_i2c_probe()`, reset the core (`QUP_SW_RESET`) and poll `qup_i2c_poll_state_valid()` before requesting `qup->irq` with `IRQF_NO_AUTOEN`; transfer helpers (`qup_i2c_bam_xfer`, `qup_i2c_conf_xfer_v1`, `qup_i2c_conf_xfer_v2`) must pair `enable_irq(qup->irq)` with `disable_irq(qup->irq)` on all paths before clearing `qup->msg = NULL`. [F24, F39]
- In `i2c-qcom-geni.c`, `geni_i2c_abort_xfer()` must hold `spin_lock_irqsave(&gi2c->lock, flags)` while updating `gi2c->cur`/`gi2c->abort_done` and calling `geni_se_abort_m_cmd()`, releasing it before `wait_for_completion_timeout(&gi2c->done, ...)`. [F178]
- In `qcom_adm.c`, non-IRQ callers must acquire `achan->vc.lock` with `spin_lock_irqsave()`. Under `achan->vc.lock`, `adm_start_dma()` sets `achan->curr_txd` and clears `achan->error = 0`, `adm_issue_pending()` calls `adm_start_dma()` only when `!achan->curr_txd`, and `adm_dma_irq()` clears `achan->curr_txd = NULL` before starting the next descriptor. [F78, F176]
- `btqcomsmd_recv()` runs from RPMSG interrupt callbacks (`btqcomsmd_acl_callback`, `btqcomsmd_cmd_callback`) and must allocate SKBs with `GFP_ATOMIC`. [F175]

## Object Lifetimes
- In `qcom_scm.c` ICE key functions (`qcom_scm_ice_set_key`, `qcom_scm_derive_sw_secret`, `qcom_scm_generate_ice_key`, `qcom_scm_prepare_ice_key`, `qcom_scm_import_ice_key`), wipe every TZMem key/secret buffer with `memzero_explicit()` on all paths before `__free(qcom_tzmem)` runs. [F7]
- In `cortex_a7_release_secondary()`, `kpssv1_release_secondary()`, `kpssv2_release_secondary()`, and `msm_dt_timer_init()`, unmap all `of_iomap()`/`ioremap()` mappings with `iounmap()` and drop `of_get_cpu_node()`/`of_parse_phandle()` nodes with `of_node_put()` on all paths. In `spm_cpuidle_register()` and early exits from `for_each_available_child_of_node()`/`for_each_of_cpu_node()`, drop OF nodes via `of_node_put()` and `pdev` from `of_find_device_by_node()` via `put_device(&pdev->dev)`. [F10, F11, F14, F115]
- In `qcom_ssc_block_bus_probe()` and `qcom_ssc_block_bus_remove()`, do not `iounmap()` `devm_ioremap_resource()` mappings, but manually detach power domains via `qcom_ssc_block_bus_pds_detach()` on remove or probe failure; `qcom_ssc_block_bus_pds_attach()` and `qcom_ssc_block_bus_pds_enable()` must use signed `int i` and unwind `for (i--; i >= 0; i--)`. [F13, F116, F141]
- In `qcom-cpufreq-hw.c` (`qcom_cpufreq_set_bw`, `qcom_cpufreq_hw_read_lut`, `qcom_lmh_dcvs_notify`), release every non-error `opp` from `dev_pm_opp_find_freq_*()` with `dev_pm_opp_put(opp)`. [F16]
- In `i2c-qcom-geni.c` (`setup_gpi_dma`) and `i2c-qup.c` (`qup_i2c_req_dma`), release `dma_request_chan()` channels via `dma_release_channel()` on probe failure and remove. In `qup_i2c_bam_schedule_desc()`, if RX `dmaengine_prep_slave_sg()` fails after `dma_async_issue_pending(qup->btx.dma)`, call `dmaengine_terminate_sync(qup->btx.dma)` before `dma_unmap_sg()`. In `adm_dma_remove()`, mask channel IRQs in `ADM_CH_RSLT_CONF`, kill `vc.task`, and call `adm_terminate_all()` before `devm_free_irq()` and disabling clocks. [F23, F36, F143]

## API Contracts
- `qcom_scm_call()` sleeps (`might_sleep()`, `qcom_scm_lock`, `waitq_comp`, `QCOM_SCM_V2_EBUSY`); atomic/idle callers (`qcom_scm_cpu_power_down`) must use `qcom_scm_call_atomic()`, where `scm_legacy_call_atomic()` allows at most `SCM_LEGACY_ATOMIC_N_REG_ARGS` (5) args. `qcom_scm_shm_bridge_enable()` must use its `scm_dev` argument and never dereference `__scm`. `qcom_scm_qseecom_app_send()` requires `req` and `rsp` allocated from `qcom_tzmem`. [F48, F138, F161, F164]
- In `qcom_scm_iommu_secure_ptbl_size()`, `res.result[0]` is size and `res.result[1]` is status; in `qcom_scm_shm_bridge_create()`, `res.result[0]` is status and `res.result[1]` is handle (if `handle` is non-NULL). In `qcom_scm_ice_set_key()`, `key_size` is bytes and `data_unit_size` is 512-byte sectors; in `qcom_scm_iommu_set_cp_pool_size(spare, size)`, `args[0] = size` and `args[1] = spare`. [F46, F49]
- In `qcom_scm_assign_mem()`, `*srcvm` is a `BIT(vmid)` bitmask updated to `next_vm` only when `__qcom_scm_assign_mem()` returns 0, whereas `src[i++] = cpu_to_le32(b)` (`i` reset to 0) and `newvm[].vmid` take bit indices `0..63`. In `qcom_scm-legacy.c`, use `scm_legacy_command_to_response()`, `scm_legacy_get_command_buffer()`, and `scm_legacy_get_response_buffer()` rather than pointer arithmetic. [F47, F84, F112]
- In `qcom-cpufreq-hw.c`, convert kHz (`policy->freq_table`, `qcom_cpufreq_get_freq`, `__qcom_cpufreq_hw_get`) and Hz (`dev_pm_opp_*`, `qcom_cpufreq_hw_recalc_rate`, `qcom_lmh_get_throttle_freq`) using `HZ_PER_KHZ` (1000). `qcom_cpufreq_hw_clk_ops` must provide `.determine_rate` (`qcom_cpufreq_hw_determine_rate`). `qcom_get_related_cpus()` and `spm_cpuidle_drv_probe()` must iterate `for_each_present_cpu()`, not `for_each_possible_cpu()`. [F126, F173, F185]
- `adm_slave_config()` must verify `cfg->peripheral_size == sizeof(struct qcom_adm_peripheral_config)` before reading `cfg->peripheral_config`. In `btqcomsmd_setup()`, use `hci_set_quirk(hdev, ...)` and free the `__hci_cmd_sync()` response `skb` with `kfree_skb()`. [F96, F184]
- In `qup_i2c_xfer_v2_msg()` SMBus block reads (`qup_i2c_check_msg_len(msg)`), check `msg->buf[0] <= I2C_SMBUS_BLOCK_MAX` (else `-EPROTO`), set `msg->len = msg->buf[0]` and `qup->is_smbus_read = true` for the recursive read (`blk->cur_data += 1`), and afterward clear `qup->is_smbus_read = false` and restore `msg->len += 1`. [F76, F192]

## Error Handling
- Guard `__scm` against NULL (e.g., via `qcom_scm_is_available()`) in any SCM helper or param callback reachable before `qcom_scm_probe()` finishes (`qcom_scm_get_tzmem_pool`, `qcom_scm_set_boot_addr`, `qcom_scm_cpu_power_down`, `set_download_mode`). In `qcom_scm_shm_bridge_enable()`, translate `res.result[0] == SHMBRIDGE_RESULT_NOTSUPP` to `-EOPNOTSUPP`. Unlike `__scm_smc_call()` and `scm_legacy_call()`, `scm_legacy_call_atomic()` does not pass `smc_res.a0` through `qcom_scm_remap_error()`. [F42, F44, F45]
- In `qcom-cpufreq-hw.c`, check `reg_current_vote` and `reg_intr_clr` are non-zero before accessing `base + offset` in `qcom_lmh_get_throttle_freq()` and `qcom_lmh_dcvs_handle_irq()`. Keep `data->throttle_irq` signed (`-ENXIO` when absent): guard `qcom_lmh_get_throttle_freq()` in `__qcom_cpufreq_hw_get()` with `data->throttle_irq >= 0`, and guard `qcom_cpufreq_hw_cpu_online()`, `qcom_cpufreq_hw_cpu_offline()`, and `qcom_cpufreq_hw_lmh_exit()` with `data->throttle_irq > 0`. [F54, F56, F144]
- `qcom_hwspinlock_trylock()` must return `1` when acquired (`lock_owner == QCOM_MUTEX_APPS_PROC_ID`), `0` when contended, and negative errno on regmap failure. `qcom_ssc_block_bus_pds_attach()` must check `IS_ERR_OR_NULL(pds[i])` and return `PTR_ERR(pds[i]) ?: -ENODATA`. In `qup_i2c_req_dma()`, reset `btx.dma`/`brx.dma` to `NULL` on `dma_request_chan()` error. In `btqcomsmd_send()`, call `kfree_skb(skb)` only when `ret == 0`. [F51, F53, F60, F62]

## External Contracts
- Probe `SMC_CONVENTION_ARM_64` in `__get_convention()` only under `IS_ENABLED(CONFIG_ARM64)`. In `__scm_smc_call()`, when `arglen > SCM_SMC_N_REG_ARGS` (4), write `desc->args[3..9]` (`SCM_SMC_FIRST_EXT_IDX = 3`) to the TZMem buffer as `__le32` (`ARM_SMCCC_SMC_32`) or `__le64` (`ARM_SMCCC_SMC_64`), with its physical address in `smc.args[5]`. In `qcom_scm_assign_mem()`, pad `ptr_sz` and offsets of `mem_to_map`/`destvm` with `ALIGN(..., SZ_64)`, but pass unaligned `mem_to_map_sz`, `src_sz`, and `dest_sz` to `__qcom_scm_assign_mem()`. In `scm_legacy_call()`, call `dma_sync_single_for_cpu(..., DMA_FROM_DEVICE)` on `rsp` until `rsp->is_complete` and on the response buffer before reading `res_buf`. [F86, F129, F163, F165]
- In `i2c-qup.c`, `qup_i2c_set_tags()` and `qup_i2c_write_rx_tags_v1()` must encode length `QUP_READ_LIMIT` (256) as `0` in the u8 tag byte, and `qup_i2c_xfer_v2_msg()` must cap v2 PIO RX `qup->blk_xfer_limit` to `RECV_MAX_DATA_LEN` (254). Mark `msm_read_timer_count()` and `msm_sched_clock_read()` as `notrace`. [F97, F182]

## Known Pitfalls
- Callers of `qcom_scm_hdcp_req()` must pass a `req` array of at least `QCOM_SCM_HDCP_MAX_REQ_CNT` (5) elements regardless of `req_cnt`, as `req[0..4]` are read unconditionally. In `qup_i2c_interrupt()`, for writes, require `opflags & QUP_MX_OUTPUT_DONE` only when `blk->is_tx_blk_mode` is true. In `geni_i2c_irq()`, widen `cur->buf[gi2c->cur_wr++]` to `u32` before shifting by `(p * 8)`. [F88, F102, F120]
