# PERFORMANCE EVENTS SUBSYSTEM — kernel/events/core.c

Core Linux Performance Events subsystem (`perf_event_open`, `perf_fops`, event grouping, per-CPU/task contexts, PMU lifecycle, HW/SW/TP/BPF dispatching, ring/AUX buffers, inheritance, and IPIs).

## Architecture & Data Flow
- `__pmu_detach_event()` sets `state <= PERF_EVENT_STATE_REVOKED` and nulls `pmu`, `pmu_ctx`, and `destroy`; callers (`_perf_ioctl()`, `perf_mmap()`) must check `state > PERF_EVENT_STATE_REVOKED` before touching `pmu`/`pmu_ctx`. `event->prog` is `BPF_PROG_TYPE_PERF_EVENT` or tracing (`KPROBE`/`TRACEPOINT`); `__perf_event_overflow()` checks `prog->type == BPF_PROG_TYPE_PERF_EVENT` before `bpf_overflow_handler()`, and `perf_event_free_bpf_prog()` branches on `perf_event_is_tracing(event)`. [F194, F195]
- `event_sched_in()`/`event_sched_out()` update `oncpu`, `state`, `cpc->active_oncpu`, `ctx->nr_freq`, `epc->nr_freq`, and `cpc->exclusive` in lockstep; if `pmu->add()` fails in `event_sched_in()`, revert `state = INACTIVE` and `oncpu = -1`. In `group_sched_in()`, if any sibling or `pmu->commit_txn()` fails, roll back `group_event` and scheduled siblings via `event_sched_out()` before `pmu->cancel_txn()`. [F212, F213]
- `list_add_event()`/`list_del_event()` update `PERF_ATTACH_CONTEXT`, `ctx->nr_events`, `pmu_ctx->nr_events`, `ctx->nr_user`, `ctx->nr_stat`, `ctx->nr_no_switch_fast`, the group rb-tree, and `ctx->generation` in lockstep. For top-level events (`!event->parent`), `account_event()`/`unaccount_event()` symmetrically update global `nr_*_events`, `perf_sched_count`, and per-CPU `pmu_sb_events`. [F211, F228]
- `__perf_effective_state()` treats siblings as `OFF` when `leader->state <= PERF_EVENT_STATE_OFF`; `perf_event_set_state()` calls `perf_event_update_time()` and, if `(event->state < 0) ^ (state < 0)`, `perf_event_update_sibling_time()` before writing `state`. `_perf_event_enable()` keeps detached `PERF_EV_CAP_SIBLING` singletons (`group_leader == event`) in `ERROR`, and sets recoverable `ERROR` events to `OFF` under `ctx->lock` before `event_function_call()`. [F208, F255]
- `perf_remove_from_context()` sets `state = PERF_EVENT_STATE_OFF`, so `move_group` and `__perf_pmu_install_event()` must reinitialize `state` before `perf_install_in_context()`. In `inherit_event()`, `child_event->state` derives from `parent_state` (`INACTIVE` if `>= INACTIVE`, else `OFF`), and `attr.freq` events copy `parent_event->hw.sample_period`. [F224, F225]
- When `event_limit` hits 0 in `__perf_event_overflow()`, call `pmu->stop(event, 0)` immediately alongside `pending_kill = POLL_HUP` and `perf_event_disable_inatomic()`. Both `event_sched_out()` and `__perf_pending_disable()` clear `pending_disable = 0` when setting `PERF_EVENT_STATE_OFF`. [F215, F216]
- `perf_event_throttle()`/`unthrottle()` return early if `state != PERF_EVENT_STATE_ACTIVE` before `pmu->stop()`/`start()` (inactive siblings have `hw.idx == -1`). `__perf_event_period()` restarting an `ACTIVE` event via `pmu->start(event, PERF_EF_RELOAD)` calls `perf_event_unthrottle_group(event, true)` if `hw.interrupts == MAX_INTERRUPTS`. `__perf_event_account_interrupt()` sets `hwc->interrupts = 1` on a new tick, so test `hwc->interrupts >= max_samples_per_tick` on every interrupt. [F217, F232, F268]
- Every `PERF_SAMPLE_*` field in `perf_output_sample()` must be sized in `__perf_event_header_size()`, `perf_event__id_header_size()`, or `data->dyn_size` in `perf_prepare_sample()`. Ring-buffer records require 8-byte aligned `header.size` with zero-padded variable tails. `PERF_SAMPLE_STACK_USER` requires 8-byte aligned `sample_stack_user < USHRT_MAX` and clamps `stack_size` to `USHRT_MAX - header_size - sizeof(u64)` on u16 wrap; `PERF_SAMPLE_AUX` clamps to `U16_MAX - (perf_sample_data_size(data, event) + sizeof(u64))` rounded down to 8 bytes. [F229, F235, F236, F240]
- `perf_group_attach()`/`detach()` update `nr_siblings`, `group_generation`, and `perf_event__header_size()` for all members. `perf_event_validate_size()` checks `__perf_event_read_size()` with `nr_siblings + 1 <= 16*1024` across the group; formatted `u64` counts in `perf_read_one()`, `__perf_read_group_add()`, `perf_output_read_one()`, and `perf_output_read_group()` must match `__perf_event_read_size()` and fit `values[5]`/`values[6]`. [F209, F273, F280]
- Fast context switch in `perf_event_context_sched_out()` (`context_equiv()` with zero `nr_no_switch_fast`) swaps `ctx->task`/`next_ctx->task`, swaps `task->perf_event_ctxp`/`next->perf_event_ctxp`, and calls `perf_event_sync_stat()`. `perf_cgroup_ensure_storage()` sizes `cpuctx->heap` to `>= 1 +` max cgroup depth (`__heap_add()` is unchecked); `visit_groups_merge()` advances `*evt = perf_event_groups_next(*evt, pmu)` and sifts down or pops. `container_of(ctx, struct perf_cpu_context, ctx)` requires `!ctx->task` or `is_cgroup_event(event)`. [F218, F243, F264, F284]
- `perf_mmap_rb()` subtracts 1 user page from `nr_pages` before requiring 0 or power-of-two data pages; `perf_mmap_aux()` requires power-of-two `nr_pages` and `vma->vm_pgoff << PAGE_SHIFT == rb->user_page->aux_offset >= perf_data_size(rb) + PAGE_SIZE`. `perf_event_index()` returns 0 unless active and unstopped, and `perf_event_update_userpage()` subtracts `hw.prev_count` from `userpg->offset` only when `userpg->index != 0`. [F231, F244]
- `perf_pmu_register()` allocates dynamic IDs in `pmu_idr` at `>= PERF_TYPE_MAX` when `type < 0`; `perf_init_event()` saves `event->orig_type = event->attr.type` (for `perf_sigtrap()`) before `perf_try_init_event()` and decodes extended types from `attr.config >> PERF_PMU_TYPE_SHIFT` for `PERF_TYPE_HARDWARE`/`HW_CACHE`. `perf_event_pid_type()` and `primary_event_id()` resolve `if (event->parent) event = event->parent` before reading `ns` or `id`. `perf_event_modify_attr()` calls `perf_event_modify_copy_attr()` on `event` and each `child` before `func`. [F226, F227, F245, F321]

## Synchronization
- `pmus_lock` nests inside `pmus_srcu`: `perf_pmu_unregister()` drops `pmus_lock` before `synchronize_srcu(&pmus_srcu)`, and `perf_event_alloc()` callers hold `pmus_srcu` across allocation and installation. Iterating `pmus` under `pmus_lock` without `pmus_srcu`/RCU (`perf_event_clear_cpumask()`) uses `list_for_each_entry()`. `perf_iterate_ctx()` callers hold RCU read lock. [F308, F310, F311]
- `event->child_mutex` nests inside `ctx->mutex`; `perf_event_release_kernel()` pins `child->ctx` (`get_ctx()`), drops `child_mutex`, locks `ctx->mutex` then `child_mutex`, and reverifies `list_first_entry_or_null(&event->child_list, ...) == child`. Detaching from `task->perf_event_list` (`perf_event_exit_task()`, `perf_remove_from_owner()`) requires `list_del_init(&event->owner_entry)` then `smp_store_release(&event->owner, NULL)` under `perf_event_mutex`; `perf_remove_from_owner()` rechecks `event->owner` after locking `owner->perf_event_mutex`. [F181, F182]
- `rb->aux_mutex` nests inside `event->mmap_mutex` (`perf_mmap_aux()`, `perf_mmap_close()`). When `perf_mmap_close()` detaches `rb->event_list`, it pins `event->refcount` under `rcu_read_lock()`, drops RCU, locks `event->mmap_mutex`, rechecks `event->rb == rb`, and restarts the walk. `__pmu_detach_event()` cycles `event->mmap_mutex` after setting `PERF_EVENT_STATE_REVOKED`, pairing with `perf_mmap()` checking `state <= PERF_EVENT_STATE_REVOKED` under `mmap_mutex`. [F185, F186, F187]
- `perf_lock_task_context()` calls `local_irq_save()` before `rcu_read_lock()`, and under `ctx->lock` reverifies `ctx == rcu_dereference(task->perf_event_ctxp)`, `ctx->task != TASK_TOMBSTONE`, and `refcount_inc_not_zero(&ctx->refcount)`. In `event_function_call()`, the fallback path calls `local_irq_disable()` before `this_cpu_ptr(&perf_cpu_context)` and `perf_ctx_lock()`, re-enabling IRQs on all exits/retries. [F176, F296]
- `perf_cgroup_switch()` rechecks `READ_ONCE(cpuctx->cgrp) == NULL` under `perf_ctx_lock(cpuctx, cpuctx->task_ctx)`. In `perf_event_read()`, if the `INACTIVE` branch locks `ctx->lock` and sees `event->state != PERF_EVENT_STATE_INACTIVE`, it unlocks and jumps to `again` without re-reading `event->state` at `again:`. [F171, F261]
- Barriers: `put_ctx()` issues `smp_mb__after_atomic()` when `refcount_dec_and_test()` is false before testing `ctx->task == TASK_TOMBSTONE`. `event_sched_in()` writes `event->oncpu` and `smp_wmb()` before `PERF_EVENT_STATE_ACTIVE`, pairing with `smp_rmb()` in `perf_event_read()`, `perf_event_stop()`, and `__perf_event_stop()`. `perf_install_in_context()` publishes `event->ctx` via `smp_store_release()` (pairing with `smp_load_acquire()` in `perf_iterate_sb_cpu()`), and before `task_function_call()` issues `smp_mb()` and rechecks `task_curr(task)` under `ctx->lock` on IPI miss. [F172, F177, F178, F179]
- `perf_event_throttle()` sets `hw.interrupts = MAX_INTERRUPTS` before `pmu->stop(event, 0)`, and `perf_swevent_cancel_hrtimer()` skips `hrtimer_cancel()` when `hwc->interrupts == MAX_INTERRUPTS`. `perf_pmu_snapshot_aux()` disables IRQs and sets `rb->aux_in_sampling = 1` around `pmu->snapshot_aux()`, while `perf_prepare_sample_aux()` aborts if `rb->aux_in_sampling` is set. [F300, F306]
- In `__perf_event_overflow()`, `task_work_add()` for `pending_task` passes `TWA_NMI_CURRENT` if `in_nmi()` else `TWA_RESUME`, and only on `0` sets `pending_work` and increments `ctx->nr_no_switch_fast` and `event->refcount`. Per-task `perf_event_open()` holds `task->signal->exec_update_lock` across `perf_check_permission()` and `perf_install_in_context()`; `attr->sigtrap` requires `CAP_KILL` in target's `user_ns` (with `perfmon_capable()`) or `PTRACE_MODE_ATTACH_REALCREDS`. [F163, F315, F320]

## Object Lifetimes
- In `inherit_event()`, exits after setting `child_event->parent` before `atomic_long_inc_not_zero(&parent_event->refcount)` must call `free_event(child_event)` (not `put_event()`). `perf_child_detach()` only clears `PERF_ATTACH_CHILD` and `child_list` without clearing `event->parent` or dropping its refcount until `put_event()` finishes `_free_event()`. [F155, F156]
- `_free_event()` calls `irq_work_sync()` on `pending_irq` and `pending_disable_irq`, and never waits on `pending_task` (which holds `event->refcount` until `perf_pending_task()`). In `__free_event()`, `event->destroy(event)` precedes `put_task_struct(event->hw.target)`, and `put_pmu_ctx(event->pmu_ctx)` precedes `put_ctx(event->ctx)`. [F180, F302]
- `__do_sys_perf_event_open()` computes `perf_event__header_size()` and `perf_event__id_header_size()` under `ctx->mutex` before `perf_install_in_context()`, and `move_group` installs siblings before `group_leader`. `__perf_pmu_install_event()` completes `get_ctx(ctx)` and `perf_install_in_context()` before `put_ctx(old_ctx)`. [F168, F190]
- `perf_event_exit_task_context()` sets `WRITE_ONCE(ctx->task, TASK_TOMBSTONE)` under `ctx->lock` when dropping `task`, and `put_ctx()` checks `ctx->task != TASK_TOMBSTONE` before `put_task_struct(ctx->task)`. In `ring_buffer_attach()`, replacing `old_rb` requires `cond_synchronize_rcu(event->rcu_batches)` before `list_add_rcu()`, and if `has_aux(event)`, `perf_event_stop(event, 0)` before `rcu_assign_pointer(event->rb, rb)`. [F169, F305]
- `perf_pmu_register()` reserves `pmu_idr` with `NULL` and publishes via `idr_cmpxchg()` and `list_add_rcu()` only after `cpu_pmu_context`, callbacks, and `pmu->events` are initialized. `perf_pmu_free()` releases `epc.embedded` per-CPU contexts via `put_pmu_ctx(&cpc->epc)` and only calls `kfree(cpc)` when `!cpc->epc.embedded`. `perf_event_exit_cpu_context()` calls `perf_event_clear_cpumask(cpu)` under `pmus_lock` before `__perf_event_exit_context`. `perf_cgroup_ensure_storage()` must not `kfree()` `cpuctx->heap_default`. [F282, F286, F290, F294]

## API Contracts
- `unclone_ctx()` (under `ctx->lock`) returns `ctx->parent_ctx` (`__must_check`) with ref held; unlock `ctx->lock` before `put_ctx()`. `inherit_event()` returns `ERR_PTR()`, `NULL` (revoked/orphaned), or valid pointer; callers (`inherit_group()`) check `IS_ERR()` first and treat `NULL` as non-error. `perf_callchain()` returns `&__empty_callchain` (never `NULL`) on failure. `perf_swevent_get_recursion_context()` returns `< 0` or an `rctx` released via `perf_swevent_put_recursion_context(rctx)` on all paths. [F164, F191, F192, F193]
- `perf_event_open()` and `_perf_event_period()` reject `sample_freq > sysctl_perf_event_sample_rate` when `attr.freq`, and when `!attr.freq` reject `value & (1ULL << 63)` and call `perf_event_check_period()`. `perf_event_alloc()` rejects `(unsigned)cpu >= nr_cpu_ids` unless `task && cpu == -1`; `PERF_FLAG_PID_CGROUP` rejects `pid == -1` or `cpu == -1`. [F204, F238, F250]
- `perf_event_set_filter()` uses `strndup_user(arg, PAGE_SIZE)`; `perf_event_parse_addr_filter()` rejects `ACTION_FILTER` with `size == 0` or trailing state `!= IF_STATE_ACTION` (`-EINVAL`), and for `!kernel` filters rejects CPU-wide events (`-EOPNOTSUPP`), verifies `S_ISREG` via `kern_path()`, and releases `filter->path` in `free_filters_list()`. [F249, F326]
- `perf_pmu_free()` checks `pmu->dev && pmu->dev != PMU_NULL_DEV`. If `pmu->event_unmapped` is set, `perf_pmu_unregister()` rolls back `pmu_idr`/`pmus` removal under `pmus_lock` and returns `-EBUSY` when `!pmu_empty(pmu)`. `perf_event_set_clock()` rejects `CLOCK_REALTIME`/`BOOTTIME`/`TAI` unless `PERF_PMU_CAP_NO_NMI`. `perf_mmap_vmops.may_split` is `perf_mmap_may_split` (`-EINVAL`). [F292, F313, F316, F325]

## Error Handling
- Pre-install errors (`event->ctx == NULL`) after `find_get_pmu_context()` must call `put_pmu_ctx(event->pmu_ctx)` and null `event->pmu_ctx` before `put_event()`. In `perf_event_alloc()`, `attach_perf_ctx_data()` must immediately follow `perf_init_event()` when `PERF_ATTACH_TASK_DATA` is set. In `perf_try_init_event()`, failures after `pmu->event_init()` returns 0 must jump to `err_destroy`. `perf_tp_event()` and `__perf_tp_event_target_task()` call `perf_sample_data_init()` inside the event loop. `__perf_event_header__init_id()` zeroes `data->cpu_entry.reserved` when `PERF_SAMPLE_CPU` is set. [F158, F160, F201, F203, F293]

## External Contracts
- `perf_copy_attr()` maps `size == 0` to `PERF_ATTR_SIZE_VER0`, checks `[PERF_ATTR_SIZE_VER0, PAGE_SIZE]` via `copy_struct_from_user()` (writing `sizeof(*attr)` to `uattr->size` on `-E2BIG`), and rejects non-zero `__reserved_1`/`2`/`3` or unknown bits in `sample_type`, `read_format`, or `branch_sample_type` (`-EINVAL`). `__perf_read()` returns `0` on `PERF_EVENT_STATE_ERROR` and `-ENOSPC` if `count < event->read_size`. `perf_compat_ioctl()` rewrites `_IOC_SIZE` for pointer-sized ioctls. `perf_uprobe_event_init()` requires `capable(CAP_SYS_ADMIN)`. [F233, F234, F239, F247, F319]

## Known Pitfalls
- Sampling in `do_exit()` can see `current->mm == NULL`; `perf_sample_ustack_size()` and `perf_callchain()` check `current->mm != NULL`, and `perf_get_page_size()` falls back to `&init_mm`. `perf_event_setup_cpumask()` checks `cpumask_empty(perf_online_mask)` and `!cpumask_empty(cpumask)`. `perf_event_bpf_emit_ksymbols()` emits `prog->aux->ksym.name` and starts `prog->aux->func[i]` at `i = 1`. `perf_output_sample_regs()` uses `bitmap_from_u64(_mask, mask)` before `for_each_set_bit()`. `perf_event_set_bpf_handler()` rejects `prog->call_get_stack` when `attr.precise_ip != 0` (`-EPROTO`) unless full kernel+user `PERF_SAMPLE_CALLCHAIN` is enabled. [F196, F197, F202, F285, F314]
- In `perf_prepare_sample()`, check `(sample_type & ~data->sample_flags) & PERF_SAMPLE_REGS_USER` (not `filtered_sample_type`) when adding `REGS_USER` to `data->dyn_size`, and account all dynamic fields before `PERF_SAMPLE_STACK_USER` and `PERF_SAMPLE_AUX`. Never call `for_each_sibling_event()` when `event->ctx == NULL`. [F252, F256, F279]
