# ARM64 PORT (AARCH64 ARCHITECTURE) — (top level)

Implements the AArch64 memory management subsystem (`arch/arm64/mm/`), architecture library routines (`arch/arm64/lib/`), and confidential computing guest drivers (`drivers/virt/coco/`), covering page tables, fault handling, ASID management, contiguous PTEs (`contpte`), HugeTLB, Guarded Control Stack (GCS), MTE swap tags, fixmap/transitional tables, instruction encoding, and Arm CCA/pKVM guest hypercalls.

## Architecture & Data Flow
- In `arch/arm64/mm/context.c`, `mm->context.id`, `active_asids`, and `reserved_asids` store 64-bit context IDs (generation in `ASID_MASK`), so indexing `asid_map` or `pinned_asid_map` must strip the generation via `ctxid2asid(asid)`. `new_context()` must start `find_next_zero_bit()` on `asid_map` at index `>= 1` (ASID `#0` is reserved), and `asids_update_limit()` must cap `max_pinned_asids` at `num_available_asids - num_possible_cpus() - 2`. When `arm64_kernel_unmapped_at_el0()` is active, `set_kpti_asid_bits()` fills `asid_map` and `pinned_asid_map` with `0xaa` (even kernel ASIDs only), and `arm64_mm_context_get()` must set `asid |= 1` on non-zero ASIDs. [F239, F240, F285]
- In `new_context()`, `check_update_reserved_asid(asid, newasid)` must run before checking `refcount_read(&mm->context.pinned)` and scan every CPU in `for_each_possible_cpu()` without early exit so all matching `per_cpu(reserved_asids, cpu)` update to `newasid`. In `flush_context()`, if `atomic64_xchg_relaxed(&per_cpu(active_asids, i), 0)` returns `0`, preserve `per_cpu(reserved_asids, i)` and set its bit in `asid_map` rather than overwriting with `0`. [F174, F209]
- `__contpte_try_fold()`, `__contpte_try_unfold()`, and `contpte_set_ptes()` must guard contiguous PTE manipulation with `mm_is_user(mm)` (excluding `init_mm` and `mm_is_efi(mm)`), and `__contpte_try_fold()` must verify a single non-special `struct folio` spans the entire `CONT_PTE_SIZE` block. Before clearing, write-protecting, or changing `pte_write()` (`contpte_clear_full_ptes()`, `contpte_get_and_clear_full_ptes()`, `contpte_wrprotect_ptes()`, `contpte_ptep_set_access_flags()`), any partially covered `CONT_PTES` block must be unfolded via `contpte_try_unfold_partial()` or `__contpte_try_unfold()`. [F214, F320]
- In `contpte_convert()`, `contpte_ptep_get()`, and `contpte_ptep_get_lockless()`, dirty and young (`PTE_AF`) bits must be ORed across all `CONT_PTES` entries in the aligned block. In `contpte_ptep_get()` and `contpte_ptep_get_lockless()`, the `pte_dirty(pte)` branch must start its inner `pte_young` scan at current index `i` without advancing `i` or `ptep`, whereas the `pte_young(pte)` branch advances `i`, `ptep`, and `pfn` before its inner `pte_dirty` scan. [F212, F255]
- In `arch/arm64/mm/contpte.c` and `arch/arm64/mm/mmu.c`, aligning a `pte_t *` or `pmd_t *` via `PTR_ALIGN_DOWN()` must scale `CONT_PTES` or `CONT_PMDS` by `sizeof(*ptep)` or `sizeof(*pmdp)`, whereas virtual addresses use `CONT_PTE_SIZE` and PFNs use `CONT_PTES`. [F277]
- In `do_page_fault()`, if `faulthandler_disabled() || !mm`, jump to `no_context` (`__do_kernel_fault()`) before taking VMA or `mmap_lock` locks. Check `is_gcs_fault(esr)` before `is_write_abort(esr)` and read-fault branches so every GCS fault (including reads) sets `VM_WRITE` and `FAULT_FLAG_WRITE`. When `handle_mm_fault()` under `FAULT_FLAG_VMA_LOCK` returns `VM_FAULT_RETRY` with `VM_FAULT_MAJOR`, set `FAULT_FLAG_TRIED` in `mm_flags` before retrying under `mmap_lock`. [F221, F252, F299]
- In `fault_from_pkey()`, Permission Overlay fault detection must validate `POR_EL0` against `vma_pkey(vma)` via `arch_vma_access_permitted()` rather than trusting `ESR_ELx_Overlay`. `esr_to_fault_info()` indexes `fault_info[]` with `esr & ESR_ELx_FSC` (`0x00..0x3f`) without a bounds check, so `fault_info` must keep all 64 entries with `do_bad` in unallocated slots. [F241, F303]
- For `EX_TYPE_UACCESS_CPY` entries, both `insn_may_access_user()` and `ex_handler_uaccess_cpy()` must call `cpy_faulted_on_uaccess(ex, esr)` to verify `esr & ESR_ELx_WNR` matches `FIELD_GET(EX_DATA_UACCESS_WRITE, ex->data)`. `ex_handler_load_unaligned_zeropad()` must align `addr &= ~0x7UL` before loading `*(unsigned long *)addr` and shift by `8 * (addr & 0x7UL)` right on little-endian (`>>=`) or left on big-endian (`<<=`). [F247, F263]
- In `arch/arm64/mm/mmu.c`, `__pgd_pgtable_alloc()` strips `__GFP_ZERO`, so every `alloc_init_*` allocating via `pgtable_alloc()` must call `init_clear_pgtable()` before `__p*d_populate()`. `mark_rodata_ro()` must set `WRITE_ONCE(rodata_is_rw, false)` before `update_mapping_prot()` on `__start_rodata..__init_begin` so `set_swapper_pgd()` switches to `pgd_set_fixmap()` under `swapper_pgdir_lock` before `swapper_pg_dir` becomes read-only. [F204, F225]
- In `vmemmap_populate()`, sub-section ranges (`end - start < PAGES_PER_SECTION * sizeof(struct page)`) must use `vmemmap_populate_basepages()` rather than `vmemmap_populate_hugepages()`, even on `CONFIG_ARM64_4K_PAGES`. In `trans_pgd_idmap_page()`, break when `level_msb == max_msb` so `level_lsb` does not pass `max_msb` in `GENMASK_ULL(level_msb, level_lsb)`. [F243, F274]
- In `huge_pte_alloc()`, allocate the `p4d` level via `p4d_alloc(mm, pgdp, addr)` and check for NULL rather than calling `p4d_offset(pgdp, addr)`. In `huge_pte_offset()`, `if (sz != PUD_SIZE && pud_none(pud)) return NULL;` must precede `if (pud_leaf(pud) || !pud_present(pud))`, and `if (!(sz == PMD_SIZE || sz == CONT_PMD_SIZE) && pmd_none(pmd)) return NULL;` must precede `if (pmd_leaf(pmd) || !pmd_present(pmd))`. [F257, F315]
- `__set_fixmap()` requires `idx` strictly within `(FIX_HOLE, __end_of_fixed_addresses)` because `fixmap_pte()` indexes `bm_pte` by subtracting `(FIXADDR_TOT_START >> PMD_SHIFT)` from `(addr >> PMD_SHIFT)`. [F236]
- Functions accessing `SYS_POR_EL0` (`arch_set_user_pkey_access()`) or GCS registers `SYS_GCSPR_EL0` / `SYS_GCSCRE0_EL1` (`gcs_alloc_thread_stack()`, `arch_set_shadow_stack_status()`) must first verify `system_supports_poe()` or `system_supports_gcs()`. `arch_set_user_pkey_access()` must read `SYS_POR_EL0`, clear only `~(POE_MASK << POR_ELx_PERM_SHIFT(pkey))`, and OR in `POR_ELx_PERM_PREP(pkey, new_por)`. [F226, F293]
- In `gcs_alloc_thread_stack()`, allocate a new shadow stack VMA via `alloc_gcs()` only when `(args->flags & (CLONE_VFORK | CLONE_VM)) == CLONE_VM`; otherwise copy `tsk->thread.gcspr_el0` from `SYS_GCSPR_EL0`. In `SYSCALL_DEFINE3(map_shadow_stack, ...)`, execute `gcsb_dsync()` after `put_user_gcs()` before returning to user space. [F262, F313]
- `__sync_icache_dcache()`, `flush_dcache_folio()`, and `flush_dcache_page()` must test, set, and clear `PG_dcache_clean` on `folio->flags.f` rather than individual subpages, and `__sync_icache_dcache()` must call `sync_icache_aliases()` across `folio_size(folio)` when `PG_dcache_clean` is clear. In `arch_wb_cache_pmem()`, execute `dmb(osh)` before `dcache_clean_pop()`. [F316, F319]
- In `aarch64_encode_immediate()`, compute `n = esz == 64` after the `for (tmp = esz / 2; tmp >= 2; tmp /= 2)` replication-stride loop reduces `esz`, rather than from `variant == AARCH64_INSN_VARIANT_64BIT`. In `pkvm_init_hyp_services()`, verify `HYP_MEMINFO`, `MEM_SHARE`, and `MEM_UNSHARE` via `kvm_arm_hyp_service_available()` and `pkvm_granule <= PAGE_SIZE` before registering `pkvm_crypt_ops` or `mmio_guard_ioremap_hook`. [F266, F287]

## Synchronization
- In `do_page_fault()`, after `lock_vma_under_rcu(mm, addr)` or `lock_mm_and_find_vma()`, when `fault_from_pkey(vma, mm_flags)` is true, sample `vma_pkey(vma)` into `pkey` before unlocking. Pre-fault rejections must call `vma_end_read(vma)` or `mmap_read_unlock(mm)` before `goto bad_area`. Post-`handle_mm_fault()` code must call `vma_end_read(vma)` only when `!(fault & (VM_FAULT_RETRY | VM_FAULT_COMPLETED))`, and `mmap_read_unlock(mm)` only when `!fault_signal_pending(fault, regs) && !(fault & (VM_FAULT_COMPLETED | VM_FAULT_RETRY))`. [F164, F165, F222]
- In `check_and_switch_context()`, the lockless fastpath may install `asid` into `this_cpu_ptr(&active_asids)` via `atomic64_cmpxchg_relaxed()` only when `old_active_asid` is non-zero and `asid_gen_match(asid)` holds; if `old_active_asid` is `0` or `cmpxchg` fails against `flush_context()`, acquire `cpu_asid_lock`, reload `mm->context.id`, and recheck `asid_gen_match()` before calling `new_context(mm)`. [F172, F296]
- `set_swapper_pgd()` must remain `noinstr` and, when `!rodata_is_rw`, hold the non-sleeping `swapper_pgdir_lock` spinlock across `pgd_set_fixmap(__pa_symbol(pgdp))`, `WRITE_ONCE(*fixmap_pgdp, pgd)`, and `pgd_clear_fixmap()`, whereas `__create_pgd_mapping()` serializes `FIX_P4D`/`FIX_PUD`/`FIX_PMD`/`FIX_PTE` usage under the sleeping `fixmap_lock` mutex. [F179, F306]
- In `split_pmd()`, `split_pud()`, and `init_clear_pgtable()`, execute `dsb(ishst)` after writing/zeroing child entries and before `__pmd_populate()` or `__pud_populate()`. In `is_spurious_el1_translation_fault()`, execute `at s1e1r` and `read_sysreg_par()` with local IRQs disabled (`local_irq_save()`/`local_irq_restore()`) separated by `isb()`. [F180, F302]
- In `mte_restore_tags()`, `copy_highpage()`, and `tag_clear_highpage()`, acquire the MTE lock via `try_page_mte_tagging()` (or `folio_try_hugetlb_mte_tagging()`) before writing tags and call `set_page_mte_tagged()` (or `folio_set_hugetlb_mte_tagged()`) afterwards. [F182]
- In `contpte_ptep_get_lockless()`, any `contpte_is_consistent()` failure in the outer or inner dirty/young loops must jump to `retry` to re-read `*orig_ptep` and reset `orig_prot`, `ptep`, `pfn`, and `i`, discarding accumulated dirty/young bits in `orig_pte`. [F256]

## Object Lifetimes
- In `mte_save_tags()`, after `xa_store(&mte_pages, page_swap_entry(page).val, tag_storage, GFP_KERNEL)`, call `mte_free_tag_storage(tag_storage)` if `xa_is_err(ret)`, or `mte_free_tag_storage(ret)` if `ret` is non-NULL. `mte_restore_tags()` must only call `xa_load(&mte_pages, entry.val)` without erasing/freeing; tags are erased and freed only in `mte_invalidate_tags()` or `mte_invalidate_tags_area()`. [F158, F160]
- Under `cpu_asid_lock`, `arm64_mm_context_get()` increments `nr_pinned_asids` and sets `pinned_asid_map` only when `mm->context.pinned` transitions 0->1, and `arm64_mm_context_put()` clears `pinned_asid_map` and decrements `nr_pinned_asids` only when `refcount_dec_and_test(&mm->context.pinned)` is true. [F161]
- `pgd_alloc()` and `pgd_free()` must use matching allocators gated by `pgdir_is_page_size()`: `__pgd_alloc(mm, 0)` / `__pgd_free(mm, pgd)` when true, and `kmem_cache_alloc(pgd_cache, gfp)` / `kmem_cache_free(pgd_cache, pgd)` otherwise. [F169]

## API Contracts
- In `arch/arm64/mm/hugetlbpage.c`, `set_huge_pte_at()`, `huge_pte_clear()`, and `huge_ptep_get_and_clear()` must derive `ncontig` and `pgsize` from `sz` via `num_contig_ptes(sz, &pgsize)` rather than `pte_cont()` or PFN extraction. In `arch/arm64/mm/contpte.c`, callers of `__contpte_try_fold()` must verify `pte_valid(pte)` and `!pte_special(pte)` beforehand, and `contpte_set_ptes()` must only be called with `nr > 1` on initially non-present ranges. [F195, F197, F198]
- In `arch/arm64/mm/fixmap.c`, `__set_fixmap()` runs in hardirq context and must not sleep, take mutexes, or use IPI TLB shootdowns. `early_fixmap_init_pud()`/`pmd()`/`pte()` must populate `bm_pud`/`bm_pmd`/`bm_pte` via `__p4d_populate()`, `__pud_populate()`, and `__pmd_populate()` with `__pa_symbol()`. `fixmap_remap_fdt()` must verify `dt_phys` is non-zero and `MIN_FDT_ALIGN`-aligned before mapping `PAGE_SIZE` at `FIX_FDT`, and verify `fdt_magic(dt_virt) == FDT_MAGIC` and `*size <= MAX_FDT_SIZE` before mapping `offset + *size`. [F202, F235, F307]
- `__phys_addr_symbol()` (`__pa_symbol()`) only accepts `[KERNEL_START, KERNEL_END]`, whereas `__virt_to_phys()` (`virt_to_phys()`) only accepts linear-map addresses satisfying `__is_lm_address(__tag_reset(x))`. `trans_alloc_page` in `struct trans_pgd_info` must return a `PAGE_SIZE`-aligned, zeroed page. [F203, F279]
- In `arch/arm64/lib/insn.c`, `aarch64_insn_gen_movewide()` requires `shift` to be a multiple of 16 (`0`, `16`, `32`, `48`) rather than a `0..3` `hw` index. Callers of `range_of_ones(u64 val)` (`aarch64_encode_immediate()`) must reject `0` and `~0ULL` beforehand (and set `imm |= ~mask` before `range_of_ones(~imm)`). [F208, F273]
- Every `ptdump_pg_state` passed to `arm64_ptdump_walk_pgd()` must terminate `ptdump.range` with `{0, 0}` and `marker` with `{-1, NULL}`. Assembly routines in `arch/arm64/mm/proc.S` called via `__pa_symbol()` pointers in `mmu.c` (`idmap_cpu_replace_ttbr1`, `idmap_kpti_install_ng_mappings`, `wait_linear_map_split_to_ptes`) must use `SYM_TYPED_FUNC_START` matching the C `typedef`. `arm_cca_guest_init()` must check `is_realm_world()` (returning `-ENODEV` if false) before `tsm_report_register(&arm_cca_tsm_ops, NULL)`. [F246, F282, F288]

## Error Handling
- In `arch_prepare_to_swap()`, if `mte_save_tags(folio_page(folio, i))` fails, unwind with `while (i--) __mte_invalidate_tags(folio_page(folio, i));`. In `mte_invalidate_tags_area()`, pass `last_entry.val - 1` (where `last_entry = swp_entry(type + 1, 0)`) as the upper bound to `xas_for_each()`. [F159, F245]
- Callers of `put_user_gcs()` such as `SYSCALL_DEFINE3(map_shadow_stack, ...)` must initialize `int ret = 0` before `put_user_gcs(cap_val, cap_ptr, &ret)`; if `ret != 0`, call `vm_munmap(addr, size)` before returning `-EFAULT`. [F162, F200]
- `aarch64_insn_encode_immediate()` and `aarch64_insn_encode_register()` must return `AARCH64_BREAK_FAULT` immediately if `insn == AARCH64_BREAK_FAULT`. `mmio_guard_ioremap_hook()` must only invoke `ARM_SMCCC_VENDOR_HYP_KVM_MMIO_GUARD_FUNC_ID` for `PROT_DEVICE_nGnRE` or `PROT_DEVICE_nGnRnE`, and must return `0` (logging via `WARN_ON_ONCE()`). [F192, F323]

## External Contracts
- In `SYSCALL_DEFINE3(map_shadow_stack, ...)`, require page-aligned `addr`, 8-byte-aligned `size != 8`, and `PAGE_ALIGN(size) >= size` before calling `alloc_gcs()` and writing the token at `addr + size - (cap_offset * sizeof(unsigned long))`. `arch_set_shadow_stack_status()` must reject `arg & ~PR_SHADOW_STACK_SUPPORTED_STATUS_MASK`, whereas `arch_lock_shadow_stack_status()` must OR all bits of `arg` into `task->thread.gcs_el0_locked`. [F233, F234]
- `set_thread_esr()` must sanitize faults on `!is_ttbr0_addr()` to `ESR_ELx_FSC_FAULT` with RES0/ISS instruction bits masked out. `do_mem_abort()` and `do_sea()` must pass `untagged_addr(far)` to `arm64_notify_die()`, and `do_sea()` must pass `siaddr = 0` when `esr & ESR_ELx_FnV` is set. [F207, F242]

## Known Pitfalls
- In `do_csum()` (`__no_sanitize_address`), guard `len <= 0` to return `0` before `kasan_check_read(buff, len)` or `len = len + offset - 8`, and keep strict loop bounds `len > 64` and `len > 8` so final `len` is in `[-7, 0]`. In `csum_ipv6_magic()`, cast `(u32)proto << 24` on little-endian to avoid sign-extension into `u64 sum`. [F231, F232, F267, F330]
- `is_write_abort()` must require `(esr & ESR_ELx_WNR) && !(esr & ESR_ELx_CM)`. In `pfn_is_map_memory()`, check `PHYS_PFN(PFN_PHYS(pfn)) == pfn` before `memblock_is_map_memory()`. For `asid_map` and `pinned_asid_map`, pass `BITS_TO_LONGS(NUM_USER_ASIDS) * sizeof(unsigned long)` to `memset()` and `NUM_USER_ASIDS` to `bitmap_*()` / `find_next_zero_bit()`. [F253, F271, F286]
