# ARM64 PORT (AARCH64 ARCHITECTURE) — arch/arm64 (part 2)

Provides core AArch64 architecture headers, UAPI definitions, and low-level ACPI boot and NUMA initialization routines. It defines page table layouts and manipulation primitives, TLB invalidation helpers, user-space memory access (PAN/TTBR0/MTE), system register encodings, instruction encoding/decoding headers, stack unwinding helpers, Realm Services Interface (RSI) SMC definitions, and VDSO helpers.

## Architecture & Data Flow
- `pte_present_invalid()`, `pte_valid_not_user()`, and `pte_access_permitted_no_overlay()` must test multi-bit masks against exact expected bit combinations (`(val & mask) == expected`), because `PTE_PRESENT_INVALID` aliases `PTE_NG` and execute-only user mappings clear `PTE_USER`. `pte_protnone()` must check `pte_present_invalid(pte) && !pte_user(pte) && !pte_user_exec(pte)`, and `pmd_trans_huge()` must OR `PTE_VALID` into `pmd` before calling `!pmd_table()`, as PMDs marked invalid via `pmd_mkinvalid()` are not necessarily `PROT_NONE` or non-huge. [F84, F85]
- Before `pte_wrprotect()` or `pte_modify()` alters `PTE_WRITE` or `PTE_RDONLY`, it must check `pte_hw_dirty(pte)` (`pte_write(pte) && !pte_rdonly(pte)`) and set `PTE_DIRTY`, and `pte_modify()` must then call `pte_mkdirty(pte)` if `pte_sw_dirty(pte)` is set. In `__get_and_clear_full_ptes()`, the loop over `nr` PTEs must OR any `pte_dirty(tmp_pte)` and `pte_young(tmp_pte)` from subsequent entries into the returned `pte`. `PTE_SWBITS_MASK` must cover all software PTE bits modifiable on a live valid PTE so `pgattr_change_is_safe()` in `__check_safe_pte_update()` permits live updates without break-before-make. [F86, F91, F138]
- Under `CONFIG_ARM64_LPA2`, `PHYS_MASK_SHIFT` (and `MAX_PHYSMEM_BITS`) must check `lpa2_is_enabled()` and fall back to 48 bits when `TCR_DS` is clear rather than unconditionally expanding to `CONFIG_ARM64_PA_BITS` (52). `ARM64_HW_PGTABLE_LEVELS(va_bits)` must compute ceiling division `((va_bits) - PTDESC_ORDER - 1) / PTDESC_TABLE_SHIFT` (`DIV_ROUND_UP((va_bits) - PAGE_SHIFT, PTDESC_TABLE_SHIFT)`) so partial top-level VA ranges allocate a translation level. [F100, F118]
- `VMEMMAP_SIZE` must be sized for `_PAGE_END(VA_BITS_MIN) - PAGE_OFFSET` multiplied by `sizeof(struct page)` per page, and when `VA_BITS > VA_BITS_MIN`, `VMALLOC_END` reclaims unused lower vmemmap space by adding `VMEMMAP_UNUSED_NPAGES * sizeof(struct page)` to `VMEMMAP_START`. In `asm/memory.h`, `MT_NORMAL` must remain index 0 because `vm_get_page_prot()` ORs `MT_NORMAL_TAGGED` into `protection_map[]` assuming `MT_NORMAL` is 0, and `PCI_IO_SIZE` must remain a power of two so `IO_SPACE_LIMIT` (`PCI_IO_SIZE - 1`) forms a contiguous low-bit mask. [F79, F105, F116]
- In `asm/memory.h`, `untagged_addr(addr)` must bitwise-AND `__addr` with `__untagged_addr(__addr)` (`sign_extend64((__force u64)(addr), 55)`) rather than unconditionally sign-extending bit 55, so user addresses (bit 55 == 0) clear tag bits [63:56] while kernel addresses (bit 55 == 1) preserve them. [F99]
- In `arm64_mops_reset_regs()`, `regs->regs[srcreg]` must only be indexed when `ESR_ELx_MOPS_ISS_MEM_INST` is clear (CPY* instructions), because SET* instructions can encode XZR (31) in `srcreg`, which is out of bounds for the 31-element `user_pt_regs::regs[]` array. [F65]
- In `asm/processor.h`, `start_thread_common()` must only reset `regs->user_regs`, `regs->orig_x0`, and `regs->pmr` while preserving `regs->syscallno` and keeping `regs->stackframe` intact (`fp == 0`, `lr == 0`, `type == FRAME_META_TYPE_FINAL`). In `struct thread_struct`, the hardened-usercopy whitelist sub-struct `uw` must contain no implicit padding between `tp_value`, `tp2_value`, `fpmr`, `pad`, and `fpsimd_state`, as enforced by `arch_thread_struct_whitelist()`. [F112, F129]
- In `unwind_consume_stack()`, `*info` must be overwritten with `stackinfo_get_unknown()` before restoring `state->stack = tmp` and setting `state->stack.low = sp + size`, preventing stack re-entry after a transition and ensuring monotonic stack advance. [F88]
- In `asm/syscall.h`, for compat tasks (`is_compat_thread()`), `syscall_get_return_value()` must sign-extend `regs->regs[0]` from bit 31 via `sign_extend64(val, 31)`, and `syscall_set_return_value()` must mask `val` with `lower_32_bits(val)`. In `uapi/asm/bitsperlong.h`, `__BITS_PER_LONG` must be `32` when `defined(__KERNEL__) && !defined(__aarch64__)` so 32-bit compat vDSO builds do not shift 32-bit `unsigned long` operands out of bounds. [F92, F98]
- In `asm/pkeys.h`, `mm_pkey_is_allocated()` must reject `pkey < 0 || pkey >= arch_max_pkey()` before `1U << pkey`, and `mm_pkey_alloc()` must check `mm_pkey_allocation_map(mm) == all_pkeys_mask` before calling `ffz()` and `mm_set_pkey_allocated()` so the shift stays within the 8-bit `pkey_allocation_map`. [F97]
- In `arch/arm64/kernel/acpi_numa.c`, `acpi_early_node_map` must initialize all `NR_CPUS` elements to `NUMA_NO_NODE` via `[0 ... NR_CPUS - 1] = NUMA_NO_NODE` so unmapped CPUs queried by `acpi_numa_get_nid()` do not default to node 0. `acpi_numa_gicc_affinity_init()` must reject SRAT GICC subtables with `header.length < sizeof(struct acpi_srat_gicc_affinity)`, and `acpi_parse_gicc_pxm()` must translate `pa->acpi_processor_uid` via `get_cpu_for_acpi_id()` and skip negative results before indexing `acpi_early_node_map[cpu]` or `cpu_logical_map(cpu)`. [F33, F71]
- `arch_parse_debug_rodata()` must assign both `rodata_enabled` and `rodata_full` for every accepted `"rodata="` argument (`"on"`, `"off"`, `"noalias"`). `struct mod_arch_specific` in `asm/module.h` and `SECTIONS` in `asm/module.lds.h` must provide paired PLT and dynamic ftrace trampoline state for both core (`.plt`, `.text.ftrace_trampoline`) and init (`.init.plt`, `.init.text.ftrace_trampoline`) sections. `enum arm64_bp_harden_el1_vectors` (`asm/vectors.h`) and `enum arm64_hyp_spectre_vector` (`asm/spectre.h`, `HYP_VECTOR_DIRECT == 0`) must match the `SZ_2K` slot layout of `tramp_vecs`/`__bp_harden_el1_vectors` and `__bp_harden_hyp_vecs`. [F59, F60, F64]

## Synchronization
- TLB invalidation routines (`flush_tlb_mm`, `__flush_tlb_page_nosync`, `__flush_tlb_range_nosync`) must execute `dsb(ishst)` after clearing a PTE and before reading `ASID(mm)` via `atomic64_read(&mm->context.id)` so a concurrent ASID rollover on another CPU cannot walk page tables before the invalid PTE store is visible. [F13]
- In-place permission or access/dirty flag updates on live valid PTEs (`__ptep_test_and_clear_young()`, `___ptep_set_wrprotect()`, `__clear_young_dirty_pte()`) must use a `cmpxchg_relaxed()` loop (transferring `pte_hw_dirty(pte)` to `PTE_DIRTY` before clearing `PTE_WRITE`) to avoid racing with concurrent hardware AF/DBM updates. [F23]
- Under `CONFIG_ARM64_CONTPTE`, all public PTE accessors and mutators in `asm/pgtable.h` except `ptep_get_lockless()` require the page table lock (PTL). Because `ptep_get()` can return `PTE_CONT` set, public PTE setters (`set_pte`, `set_ptes`, `ptep_set_access_flags`) must clear `PTE_CONT` via `pte_mknoncont()`, while `PTE_CONT`-aware callers (hugetlb, kernel mappers) must call `__`-prefixed helpers (`__set_ptes`, `__ptep_get`, etc.). With runtime folding (`CONFIG_PGTABLE_LEVELS <= 4`), `p4d_offset_lockless_folded()` must pass `pgdp` (via `p4d_offset(pgdp, addr)`) rather than stack `&pgd`, because `p4d_to_folded_pud()` aligns the pointer down to `PAGE_SIZE`. [F24, F25, F45]
- `set_page_mte_tagged()` and `folio_set_hugetlb_mte_tagged()` must issue `smp_wmb()` before `set_bit(PG_mte_tagged, ...)`, and `page_mte_tagged()` and `folio_test_hugetlb_mte_tagged()` must issue `smp_rmb()` when `test_bit(PG_mte_tagged, ...)` returns true. `mte_check_tfsr_exit()` must execute `dsb(nsh); isb()` before `mte_check_tfsr_el1()` because asynchronous MTE tag check faults are not automatically synchronized into `TFSR_EL1` on kernel exit. [F17, F19]
- `preempt_count_set()`, `__preempt_count_add()`, `__preempt_count_sub()`, and `__preempt_count_dec_and_test()` must modify only the 32-bit `current_thread_info()->preempt.count` to preserve `preempt.need_resched` in the 64-bit `preempt_count` union. In `__preempt_count_dec_and_test()`, when `pc` is non-zero, it must reload 64-bit `ti->preempt_count` via `READ_ONCE()` after `WRITE_ONCE(ti->preempt.count, --pc)` in case an interrupt arrived between the read and write and cleared `need_resched`. [F27, F63]
- `__pmr_local_irq_enable()` and `__pmr_local_irq_restore()` must call `pmr_sync()` after writing `SYS_ICC_PMR_EL1` (within compiler `barrier()`s), and `__pmr_local_irq_save()` must only call `__pmr_local_irq_disable()` when `!__pmr_irqs_disabled_flags(flags)` to preserve non-`GIC_PRIO_IRQON` mask states. [F28]
- `update_cpu_boot_status()` must write `secondary_data.status` with `WRITE_ONCE()` followed by `dsb(ishst)` before parking in `cpu_park_loop()`. In compat vDSO (`asm/vdso/compat_gettimeofday.h`), `__arch_get_hw_counter()` must bracket the `mrrc` read with `isb()` before and after. `__io_ar(v)` (`asm/io.h`) must execute `dma_rmb()` followed by `eor` + `cbnz` (with `"memory"` clobber) consuming `v` to order subsequent `udelay()` `ISB`s after the MMIO read. `arm64_is_ras_serror()` and `arm64_ras_serror_get_severity()` (`asm/traps.h`) require `!preemptible()` because `this_cpu_has_cap(ARM64_HAS_RAS_EXTN)` reads per-CPU state. [F30, F31, F114, F127]

## Object Lifetimes
- In `arch/arm64/kernel/acpi.c`, every ACPI table pointer obtained via `acpi_get_table()` (e.g., in `acpi_fadt_sanity_check()` and `acpi_boot_table_init()`) must be released with `acpi_put_table()` on all return paths; in `acpi_boot_table_init()`, local `facs` must be initialized to `NULL` and checked for non-NULL before dereferencing and calling `acpi_put_table(facs)`. [F1, F36]
- When `CONFIG_PGTABLE_LEVELS > 3`, `pud_free()` must return without calling `__pud_free()` when `!pgtable_l4_enabled()` because the PUD level is folded at runtime. `init_new_context()` must pre-reserve protection key 0 (`BIT(0)`) in `mm->context.pkey_allocation_map`, and `arch_dup_pkeys()` must copy `oldmm->context.pkey_allocation_map` on fork. [F4, F6]

## API Contracts
- `__TLBI_VADDR(addr, asid)` takes an unshifted VA (shifting right by 12 internally) and `__tlbi_level()` accepts `level` in `0..3`, whereas `__TLBI_VADDR_RANGE(baddr, asid, scale, num, ttl)` requires a pre-shifted base address (`addr >> 16` when LPA2 is enabled, else `addr >> PAGE_SHIFT`) and encodes `ttl` in `1..3`. `pte_offset_kimg()`, `pmd_offset_kimg()`, `pud_offset_kimg()`, and `p4d_offset_kimg()` use `__phys_to_kimg()` (`+ kimage_voffset`) and must only be called on static kernel-image tables, never on linear-mapped or dynamically allocated tables. [F40, F43]
- `set_page_mte_tagged()`, `page_mte_tagged()`, and `try_page_mte_tagging()` require a non-hugetlb page (`!folio_test_hugetlb(page_folio(page))`), whereas hugetlb folios must use `folio_set_hugetlb_mte_tagged()`, `folio_test_hugetlb_mte_tagged()`, and `folio_try_hugetlb_mte_tagging()`. [F48]
- `arch_calc_vm_flag_bits()` must return `VM_MTE_ALLOWED` when `system_supports_mte()` is true and either `flags & (MAP_ANONYMOUS | MAP_HUGETLB)` or `shmem_file(file) || is_file_hugepages(file)` holds (as hugetlbfs `mmap()` may omit `MAP_HUGETLB`). `arch_validate_flags()` must reject `VM_SHADOW_STACK | VM_EXEC` and warn (`VM_WARN_ON`) on `VM_SHARED` when `system_supports_gcs()` is true. `arch_vma_access_permitted()` must return `true` without reading `SYS_POR_EL0` when `foreign || vma_is_foreign(vma)` is true, checking `por_el0_allows_pkey()` only for current's own VMAs. [F82, F142, F153]
- In `asm/io.h`, `count` in `__iowrite32_copy()` (`__const_memcpy_toio_aligned32()`) and `__iowrite64_copy()` (`__const_memcpy_toio_aligned64()`) is the `u32` or `u64` word count (not bytes), and for compile-time constant `count` in `{1, 2, 4, 8}`, they must emit contiguous `str` instructions followed by `dgh()`. In `asm/insn.h`, `aarch64_insn_is_mops()` (mask `0x3B200C00`, value `0x19000400`) must match FEAT_MOPS instructions so kprobes/uprobes reject them. [F106, F115, F137]

## Error Handling
- `__get_user_error(x, ptr, err)` and `__put_user_error(x, ptr, err)` set `err = -EFAULT` on failure (with `__get_user_error` zeroing `x`) and leave `err` unmodified on success, so callers must initialize `err = 0`. In `arch/arm64/kernel/acpi_numa.c`, `acpi_parse_gicc_pxm()` must return `0` (not a negative error) when an SRAT GICC entry is disabled (`!(pa->flags & ACPI_SRAT_GICC_ENABLED)`) or `get_cpu_for_acpi_id() < 0`, so `acpi_table_parse_entries()` continues parsing remaining entries. [F47, F122]

## External Contracts
- In `asm/uaccess.h`, `access_ok()` must untag user pointers via `untagged_addr()` when `CONFIG_ARM64_TAGGED_ADDR_ABI` is enabled and `current` has `PF_KTHREAD` or `TIF_TAGGED_ADDR` set, and uaccess helpers (`__get_user_error`, `__put_user_error`, `raw_copy_from_user`, `raw_copy_to_user`, `unsafe_get_user`, `unsafe_put_user`, `__clear_user`) must mask pointers with `uaccess_mask_ptr()` / `__uaccess_mask_ptr()` before dereferencing. `arch_untagged_si_addr()` must preserve top-byte tags when `sig == SIGTRAP && si_code == TRAP_BRKPT` and call `untagged_addr(addr)` otherwise. [F69, F149, F154]
- For RSI calls (`asm/rsi_smc.h`, `asm/rsi_cmds.h`, `asm/rsi.h`): `struct realm_config` must be 4KB-aligned (`__aligned(0x1000)`) and 4KB-sized; `rsi_attestation_token_init()` must require `32 <= size <= 64` before `memcpy(&regs.a1, challenge, size)`; `rsi_set_addr_range_state()` returns `-EPERM` when `res.a2 != RSI_ACCEPT` and otherwise unsigned `res.a0` as `long`; and `rsi_set_memory_range()` must verify `ret == 0` (not just `ret < 0`) and `start <= top && top <= end` before `start = top`. [F38, F74]
- In `uapi/asm/sigcontext.h` and `sve_context.h`, extension records in `sigcontext.__reserved[]` and `extra_context` must be 16-byte aligned and terminated by a zero `_aarch64_ctx` (`magic == 0`, `size == 0`), with `fpsimd_context`, `esr_context`, and at most one `extra_context` placed in `sigcontext.__reserved[]`; macro parameters (`vq`, `n`, `vl`) in `ZA_SIG_*`, `ZT_SIG_*`, and `__SVE_*`/`__sve_*` must be parenthesized around `*`, `/`, `%`, and comparisons. In `asm/kgdb.h`, `NUMREGBYTES` must size `pstate`, `fpsr`, and `fpcr` at 4 bytes each (`_EXTRA_REGS * 4`) to match GDB's 32-bit SPSR/PSTATE protocol. [F75, F78, F83]

## Known Pitfalls
- Use `pte_advance_pfn()` when advancing a PTE across physical pages (as in `__set_ptes_anysz()`) rather than adding offsets to `pte_val(pte)`, because 52-bit PAs split high OA bits into `PTE_ADDR_HIGH` below `PTE_ADDR_LOW`. In `pte_cont_addr_end(addr, end)` and `pmd_cont_addr_end(addr, end)`, keep `__boundary - 1 < (end) - 1` so boundaries wrapping to `0` at the top of the address space do not compare less than `end`. [F68, F101]
- In `__raw_get_user()`, `__raw_put_user()`, `__get_kernel_nofault()`, and `__put_kernel_nofault()`, evaluate macro arguments (`ptr`, `x`, `dst`, `src`) into local variables outside the `uaccess_ttbr0_enable()` or `__mte_enable_tco_async()` region, and disable TTBR0/TCO on both normal and fault-label paths. [F90]
- Avoid 32-bit truncation/sign-extension in macros: cast `clear` to `u64` before negation (`~(u64)(clear)`) in `sysreg_clear_set*()` (`asm/sysreg.h`); cast `pfn` to `phys_addr_t` before `<< PAGE_SHIFT` in `pfn_pte()`, `pfn_pmd()`, and `pfn_pud()`; and cast `asid` and `(num) + 1` to `unsigned long` before left-shifting in `__TLBI_VADDR()` and `__TLBI_RANGE_PAGES()`. [F93, F94, F95]
- In `runtime_const_fixup()`, cast `start` to `void *` before adding the relative byte offset `*start` (`*start + (void *)start`) while `start++` advances by one `s32`. In `asm/vdso/gettimeofday.h`, under `CONFIG_CC_IS_GCC && CONFIG_PAGE_SIZE_64KB`, `__arch_get_vdso_u_time_data()` must apply `OPTIMIZER_HIDE_VAR()` to `&vdso_u_time_data`. [F108, F130]
