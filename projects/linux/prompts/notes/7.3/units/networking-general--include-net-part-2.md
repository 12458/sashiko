# NETWORKING [GENERAL] — include/net (part 2)

Core networking headers for network namespaces (`struct net`), Netlink (`netlink.h`), Qdisc scheduling and RED (`sch_generic.h`, `red.h`), neighbour resolution (`neighbour.h`, `ndisc.h`), netdev locking/queues/netmem (`netdev_lock.h`, `netdev_queues.h`, `netmem.h`), PSP offload, and MANA/GDMA hardware.

## Architecture & Data Flow
- `reqsk_queue_added()` increments `queue->young` and `queue->qlen`, while `reqsk_queue_removed()` decrements `queue->young` only if `req->num_timeout == 0`; transitioning `req->num_timeout` from 0 to non-zero on a queued `request_sock` must decrement `queue->young`, and `num_timeout` must not be reset to 0 before removal. [F190]
- Qdisc `skb->cb` data must live inside `struct qdisc_skb_cb::data` (`<= QDISC_CB_PRIV_LEN` = 20 bytes) and be checked with `qdisc_cb_private_validate()`. Likewise, `struct strp_msg strp` must remain the first field of `struct _strp_msg` because `strp_msg(skb)` casts `(void *)skb->cb + offsetof(struct sk_skb_cb, strp)` directly. [F279, F315]
- For Qdiscs with `TCQ_F_CPUSTATS` (`qdisc_is_percpu_stats()`), `qdisc->q.qlen` is unused; check emptiness via `qdisc_is_empty()` (`QDISC_STATE_NON_EMPTY`) and packet count via `qdisc_qlen_sum()`. Software-path execution on `struct tcf_block` is tracked via `tp->usesw` (with `tp->counted` under `tp->lock`) and summed in `block->useswcnt`, which must be updated when non-`skip_sw` filters are added or `tcf_proto` instances destroyed. [F249, F288]
- In RED (`red_parms` / `red_vars`), `red_set_parms()` and `red_adaptative_algo()` must clamp `p->qth_delta` and `max_p_delta` to `>= 1` before dividing or calling `reciprocal_value()`. Updating `red_parms::max_P` must recompute `max_P_reciprocal`, and calling `red_set_parms()` requires resetting `red_vars` via `red_set_vars()`. [F252, F294]
- A non-zero `neigh_table::entry_size` for `neighbour_priv()` must be `>= offsetof(struct neighbour, primary_key) + tbl->key_len` and wrapped in `NEIGH_ENTRY_SIZE()`. `neigh_confirm()` and `neigh_event_send_probe()` must compare `n->confirmed` or `neigh->used` against `now` with `!=` before writing `now`. [F303, F313]
- `psp_is_allowed_nondata()` must test for a 1-byte pure FIN using modular subtraction (`end_seq - seq == 1`). [F302]
- In `struct mana_cq`, check `cq->type` (`MANA_CQ_TYPE_RX` vs `MANA_CQ_TYPE_TX`) before dereferencing `cq->rxq` or `cq->txq`. For `GDMA_SQ` and `GDMA_RQ`, `gdma_queue` tracks `head`/`tail` in 32-byte `GDMA_WQE_BU_SIZE` units, while `union gdma_doorbell_entry` requires `tail_ptr` in bytes (`head * GDMA_WQE_BU_SIZE`) and `rq.wqe_cnt = 0`. [F234, F326]
- MANA/GDMA `/* HW DATA */` structs in `gdma.h`, `mana.h`, and `hw_channel.h` lack `__packed` and must keep natural alignment with explicit padding. Trailing flexible arrays `rx_oobs[]` (`mana_rxq`), `indir_tab[]` (`mana_cfg_rx_steer_req_v2`), and `reqs[]` (`hwc_dma_buf`) are `__counted_by()` `num_rx_buf`, `num_indir_entries`, and `num_reqs`, which must be set before access. [F271, F272]

## Synchronization
- Because `netdev_lock_ops()`, `netdev_unlock_ops()`, `netdev_lock_ops_to_full()`, `netdev_unlock_full_to_ops()`, and `netdev_lock_ops_compat()`/`netdev_unlock_ops_compat()` branch on `netdev_need_ops_lock(dev)`, `dev->request_ops_lock`, `dev->queue_mgmt_ops`, and `dev->netdev_ops->net_shaper_ops` must not change between lock and unlock. Calling code that asserts `dev->lock` from an ops-locked section requires `netdev_lock_ops_to_full()` / `netdev_unlock_full_to_ops()`. [F195, F205]
- Locking `dev->lock` on multiple `net_device` instances requires `rtnl_lock` (`netdev_lock_cmp_fn()`). RCU pointers serialized by `dev->lock` must use `netdev_lock_dereference(p, dev)` when holding `dev->lock` outside RCU read sections, not `rtnl_dereference()` or bare `rcu_dereference()`. [F333, F335]
- `netif_txq_try_stop()` and `netif_txq_maybe_stop()` must only be called from `ndo_start_xmit` (which must still check for a full ring at entry). Before calling them or `__netif_txq_completed_wake()`, update all ring indexes and pass a `@get_desc` expression that re-reads free descriptors on each evaluation rather than a local variable. [F208, F322]
- Lockless reads of `neighbour::ha` must use the `n->ha_lock` seqlock (`neigh_ha_snapshot()`), and lockless reads of `hh_cache` (`hh_len`/`hh_data`) must use the `hh->hh_lock` seqlock (`neigh_hh_output()` / `neigh_hh_bridge()`). [F215]
- `pernet_operations` callbacks (`init`, `pre_exit`, `exit`, `exit_batch`) run without exclusive locks (only `exit_rtnl` holds `rtnl_lock`), so shared state requires explicit locking. Acquiring a `struct net` reference without an existing live reference (e.g., in `for_each_net_rcu`) must use `maybe_get_net()` and NULL-check, not `get_net()`. [F217, F338]
- `sch_tree_lock(q)` uses `spin_lock_bh()` and, unless `TCQ_F_MQROOT` is set, asserts `ASSERT_RTNL()` via `qdisc_root_sleeping_lock(q)`. Classifiers with `TCF_PROTO_OPS_DOIT_UNLOCKED` must implement `.delete_empty()` and serialize `tcf_proto` state with `tp->lock` (`tcf_proto_dereference()`). [F345, F347]
- `strp_pause()` requires holding `strp->sk`'s socket lock (`strp_unpause()` does not). Underscore-prefixed `__SNMP_*` stats macros require BHs disabled; use `SNMP_*` in process context. [F221, F350]
- Precede `writeq()` of `union gdma_doorbell_entry` with `wmb()`, and precede `gdma_cqe`/`gdma_eqe` payload reads with `rmb()` after checking `owner_bits`. In `mana_rdma_remove()`, set `gd->rdma_teardown = true` and flush `gc->service_wq` before removing `gd->adev` and deregistering `gd`. [F327, F328]

## Object Lifetimes
- `__netns_tracker_alloc()` and `__netns_tracker_free()` must be called with matching `refcounted` flags, and `put_net_track()` must free the tracker before `put_net()`. Register netdev pernet ops with `register_pernet_device()` and subsystem/protocol ops with `register_pernet_subsys()`. `net_generic()` users must let `pernet_operations::size` manage their object and never cache `struct net_generic` or mutate `net->gen->ptr[id]`. [F185, F186, F187]
- A `neigh_table::constructor` replacing `neigh->parms` must call `__neigh_parms_put(neigh->parms)` on the old pointer and `neigh_parms_clone()` on the new one. [F193]
- Inside `Qdisc::enqueue(skb, sch, to_free)`, drop packets via `qdisc_drop()`, `qdisc_drop_all()`, `qdisc_drop_reason()`, or `__qdisc_drop()` onto `*to_free`, never `kfree_skb()`. [F201]
- Once `gdma_mem_info.dma_region_handle` is bound to a hardware EQ or MANA WQ/CQ (`mana_create_wq_obj()`), reset `dma_region_handle = GDMA_INVALID_DMA_REGION` (0). Pair every successful `mana_cfg_vport()` with `mana_uncfg_vport()`, and release non-NULL `mana_get_primary_netdev()` returns with `netdev_put(ndev, tracker)`. [F323, F324, F329]

## API Contracts
- `skb_steal_sock()` requires calling `sock_put()` on the returned `sk` iff `*refcounted` is true. `inet_reqsk(sk)` is only valid when `sk->sk_state == TCP_NEW_SYN_RECV`. [F188, F306]
- `__neigh_lookup_noref()` / `___neigh_lookup_noref()` return RCU-protected pointers without a ref, whereas `neigh_lookup()`, `neigh_create()`, `__neigh_lookup()`, and `__neigh_lookup_errno()` return refcounted pointers requiring `neigh_release()`. `neigh_hh_output()` and `neigh_output()` always consume `skb`, and require `skb_headroom(skb) >= HH_DATA_MOD` (or `HH_DATA_ALIGN(hh->hh_len)`). [F191, F194, F373]
- Use `NEIGH_VAR_INIT()` in `ndo_neigh_setup`, and `NEIGH_VAR_SET()` / `neigh_var_set()` for post-init per-device `neigh_parms` updates so `p->data_state` is updated. Initialize `*notify` (e.g., to 0) before calling `neigh_update_is_router()`. [F239, F250]
- In `ndisc_ops`, `fill_addr_option` must write the exact byte length reported by `opt_addr_space`, and both must check `icmp6_type == NDISC_REDIRECT` before dereferencing `neigh`, `ha_buf`, or `ha`. Always NULL-check the return of `ndisc_opt_addr_data()` / `__ndisc_opt_addr_data()`. [F258, F273, F274]
- Call `qdisc_put()` on the old `Qdisc *` returned by `qdisc_replace()` and `dev_graft_qdisc()`. Pass `__u64` for both `bytes` and `packets` to `_bstats_update()`. Validate RED parameters with `red_check_params()` before calling `red_set_parms()`. [F200, F292, F296]
- `nlmsg_unicast()`, `nlmsg_multicast()`, and `nlmsg_multicast_filtered()` always consume `skb`. Never set `cb->seq = 0` when using `nl_dump_check_consistent()`. `nla_put_msecs()`, `nla_get_msecs()`, and `nla_get_msecs_default()` all take/return jiffies. [F202, F244, F253]
- Size `nla_policy[]` and `tb[]` arrays to `maxtype + 1` (index 0 holds `strict_start_type`). Use `NLA_POLICY_MIN_LEN()` rather than implicit `NLA_UNSPEC` with `.len` under strict validation, and set `.len = ARRAY_SIZE(nested_policy) - 1` (via `NLA_POLICY_NESTED()`) on `NLA_NESTED` / `NLA_NESTED_ARRAY` entries. In `rtnl_link_ops::newlink`, use `rtnl_newlink_link_net(params)` and `rtnl_newlink_peer_net(params)` rather than raw `params->link_net` / `peer_net`. [F262, F287, F309, F360]
- `netdev_stat_ops` callbacks receive `stats` pre-filled with `0xff`: only assign collected fields (never zero the struct or `+=` uninitialized fields), and initialize any per-queue field in `get_base_stats` as well. Initialize `rx_sum` and `tx_sum` before `netdev_stat_queue_sum()`. [F236, F237, F320]
- `ndo_queue_mem_alloc` and `ndo_queue_mem_free` may run while `!netif_running(dev)` (unlike `ndo_queue_start`/`stop`). Only call `__netmem_to_page()`, `__netmem_to_nmdesc()`, `__netmem_get_pp()`, and `__netmem_address()` when `netmem_ref` is known not to have `NET_IOV` set. [F230, F318]
- `psp_sk_get_assoc_rcu()` requires `sk_is_inet(sk)` and `sk_state != TCP_NEW_SYN_RECV`, using `inet_twsk(sk)->psp_assoc` for `TCP_TIME_WAIT`. Pass explicit `sk` (not `skb->sk`) to `psp_reply_set_decrypted(sk, skb)` after `skb_set_owner_edemux()`. `psp_dev_create()` requires non-zero `psd_caps->versions`, all five `psp_dev_ops` callbacks non-NULL, and persistent `psd_ops`/`psd_caps` pointers. [F232, F233, F330]
- Zero-initialize GDMA request structs before `mana_gd_init_req_hdr()`. Do not combine `REGULATORY_WIPHY_SELF_MANAGED` with `REGULATORY_CUSTOM_REG`, `REGULATORY_STRICT_REG`, `REGULATORY_COUNTRY_IE_FOLLOW_POWER`, or `REGULATORY_COUNTRY_IE_IGNORE`. [F240, F332]

## Error Handling
- When `scm_send()` / `__scm_send()` returns 0, the caller must call `scm_destroy(&scm)` (including on later error paths); on `< 0`, `__scm_send()` already destroyed it. [F198]
- `Qdisc_ops::destroy` runs even if `Qdisc_ops::init` fails, so any resource freed on an `init` error path must have its pointer in `qdisc_priv(sch)` set to `NULL`. [F199]
- Check `IS_ERR()` on: `neigh_create()`, `__neigh_create()`, `__neigh_lookup_errno()`, `ip_neigh_gw6()`, `copy_net_ns()`, `get_net_ns()`, `get_net_ns_by_fd()`, `get_net_ns_by_pid()`, `rtnl_link_ops::alloc`, `rtnl_create_link()`, `rtnl_get_net_ns_capable()`, and `rtnl_link_get_net()`. Check `NULL` on: `neigh_lookup()`, `__neigh_lookup()`, `maybe_get_net()`, `get_net_ns_by_id()`, `ndo_queue_get_dma_dev()`, and `netdev_queue_get_dma_dev()`. [F224, F226, F227]
- `netif_txq_maybe_stop()` and `__netif_txq_completed_wake()` return `0` (state changed), `1` (left enabled), or `-1` (race/unchanged), not a boolean. Store `nla_strscpy()`'s return in a signed `ssize_t` and check `< 0` (`-E2BIG`). [F228, F229]

## External Contracts
- Build nested attributes for `nla_parse_nested()` with `nla_nest_start()` (`NLA_F_NESTED`), not `nla_nest_start_noflag()`. Read `NLA_UINT` / `NLA_SINT` attributes with `nla_get_uint()` / `nla_get_sint()`, not `nla_get_u64()` / `nla_get_s64()`. [F301, F365]
- `nshhdr::ver_flags_ttl_len` encodes length in 4-byte words (use `nsh_hdr_len()` / `nsh_set_flags_ttl_len()`): 24 bytes for `NSH_M_TYPE1` and a 4-byte multiple `>= 8` for `NSH_M_TYPE2`. Because `psched_ratecfg_getrate()` clamps 64-bit rates to `~0U` in 32-bit `tc_ratespec::rate`, Qdiscs supporting 64-bit rates must dump a separate 64-bit rate attribute. [F278, F280]
- `gdma_list_devices_resp.devs` may contain zero-filled holes (`GDMA_DRV_CAP_FLAG_1_DEV_LIST_HOLES_SUP`); scan up to `GDMA_DEV_LIST_SIZE` while counting non-zero entries up to `resp.num_of_devs`. [F282]

## Known Pitfalls
- Never attach page frags (`skb_shinfo(skb)->frags`) to an `sk_buff` from `nlmsg_new_large()`, as `netlink_skb_destructor()` zeroes `skb->head` and leaks frags. [F203]
- `NLA_POLICY_RANGE()`, `NLA_POLICY_MIN()`, and `NLA_POLICY_MAX()` store bounds in `s16` (`[-32768, 32767]`); use `NLA_POLICY_FULL_RANGE()` / `NLA_POLICY_FULL_RANGE_SIGNED()` outside that range. Check `NLA_VALIDATE_FUNCTION` and `NLA_VALIDATE_MASK` before calling `nla_get_range_unsigned()` / `nla_get_range_signed()` on `nla_policy`. [F263, F281]
- Verify `nlh->nlmsg_len >= nlmsg_msg_size(hdrlen)` before `nlmsg_data()`, `nlmsg_len()`, `nlmsg_attrdata()`, or `nlmsg_attrlen()` when not using `__nlmsg_parse()`. In `nla_for_each_*` / `nlmsg_for_each_msg`, `rem` must be a signed `int`, and attribute types must be read via `nla_type(nla)` (masking `NLA_TYPE_MASK`). [F265, F266, F286]
- Emit 64-bit netlink attributes with `nla_put_64bit()` / `nla_put_u64_64bit()` / `nla_put_s64()` (sizing with `nla_total_size_64bit()`) and read them with `nla_get_u64()` / `nla_get_s64()` / `nla_get_be64()` rather than dereferencing `nla_data(nla)`. `NLA_STRING` is not guaranteed NUL-terminated; use `NLA_NUL_STRING` or `nla_strscpy()` / `nla_strdup()` / `nla_strcmp()`. [F267, F310, F312]
- Set `skb->prev = NULL` before passing a non-GSO-list `skb` (e.g., from `qdisc_skb_head`) to `qdisc_drop_all()` / `__qdisc_drop_all()`. [F284]
- Guard `Plog < 32` in `red_maxp()`, cast `us_idle` to `u64` before `v->qavg * us_idle` in `red_calc_qavg_from_idle_time()`, widen `len`/`pkt_num` to `u64` before multiplying by `r->mult` in `psched_l2t_ns()` / `psched_pkt2t_ns()`, and use `DIV_ROUND_UP(len, 48) * 53` for `TC_LINKLAYER_ATM`. [F293, F295, F297]
