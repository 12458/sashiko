# INTEL ETHERNET DRIVERS — drivers/net/ethernet/intel/ice (part 1)

Core headers, devlink device/port/region/health/rate management (PF, VF, and Subfunction dynamic ports), AdminQ command layouts, base VSI queue and interrupt vector setup, multi-PF shared `ice_adapter` tracking, and Accelerated RFS (aRFS) flow steering for the Intel E800 series (`ice`) driver.

## Architecture & Data Flow
- When configuring or stopping an ADQ channel Tx ring (`ring->ch != NULL`) in `ice_base.c`, hardware VSI and queue indices must come from `ring->ch` (`vsi_num`, `ch_vsi->idx`, `base_q`, and `tc = 0`), not the parent `vsi`. [F1102]
- In `ice_traverse_tx_tree`, VF/SF leaf nodes (`devl_rate_leaf_create`) must not set `node->rate_node`, and `ice_devlink_rate_clear_tx_topology` must clear `node->rate_node` across the scheduler tree when `devl_rate_nodes_destroy` tears down the rate tree on eswitch detach. [F1010]
- `vsi->arfs_fltr_cntrs` is incremented via `ice_arfs_update_active_fltr_cntrs` only when `ice_fdir_write_fltr` succeeds in `ice_arfs_add_flow_rules`, and decremented when `ice_fdir_write_fltr` succeeds in `ice_arfs_del_flow_rules` or when `ice_rx_flow_steer` resets an `ICE_ARFS_ACTIVE` entry to `ICE_ARFS_INACTIVE`. [F1015]
- All non-static functions in `ice_arfs.h` under `#ifdef CONFIG_RFS_ACCEL` (`ice_rx_flow_steer`, `ice_clear_arfs`, `ice_init_arfs`, `ice_sync_arfs_fltrs`, `ice_set_cpu_rx_rmap`, `ice_remove_arfs`, `ice_rebuild_arfs`, `ice_is_arfs_using_perfect_flow`) must have matching `static inline` stubs in `#else`. [F1077]
- In `enum ice_pf_state`, any non-nominal state bit (checked by `ice_pf_state_is_nominal`) must precede `ICE_STATE_NOMINAL_CHECK_BITS`, and `ICE_STATE_NBITS` must stay last. [F1080]
- In `ice_adapter_index()`, non-E825C devices must mask out `ICE_ADAPTER_FIXED_INDEX` (`BIT_ULL(63)`) from `pci_get_dsn(pdev)` to avoid colliding with `ICE_ADAPTER_INDEX_E825C`, and 32-bit builds must verify `adapter->index == ice_adapter_index(pdev)` after `xa_load()` to catch `ice_adapter_xa_index` XOR folding collisions. [F1089]
- In `ice_devlink_port_split()`, the option search loop (`ICE_AQC_PORT_OPT_MAX`) must iterate `i` from `1` to `option_count` inclusive using `j = (active_idx + i) % option_count` so alternate options with the same split count match before `active_idx`. [F1098]
- `ice_health_status_lookup` must remain sorted by ascending `enum ice_aqc_health_status` `.code` for `ice_health_status_lookup_compare`/`ice_get_health_status`; in `ice_process_health_status_event()`, verify `count <= event->buf_len / sizeof(*health_info)` before indexing `event->msg_buf`, and never `continue` before the loop body's trailing `health_info++`. [F1097, F1169]

## Synchronization
- Callers acquiring the NVM lock via `ice_acquire_nvm` (`ice_devlink_nvm_snapshot`, `ice_devlink_nvm_read`, `ice_get_tx_topo_user_sel`, `ice_update_tx_topo_user_sel`, `ice_devlink_aq_set_port_option`) must call `ice_release_nvm(&pf->hw)` on every exit path. [F1007]
- PF devlink setup/teardown and SF allocation helpers (`ice_devlink_register`, `ice_devlink_unregister`, `ice_devlink_register_params`, `ice_devlink_unregister_params`, `ice_devlink_init_regions`, `ice_devlink_destroy_regions`, `ice_health_init`, `ice_health_deinit`, `ice_allocate_sf`) require `devl_lock(priv_to_devlink(pf))` held; `ice_tear_down_devlink_rate_tree()` must lock `devl_lock` before `pf->vfs.table_lock`, and Tx scheduler tree operations in devlink rate handlers (`ice_devlink_rate_init_tx_topology`, `ice_devlink_rate_clear_tx_topology`, `ice_devlink_rate_node_del`, `ice_devlink_set_parent`, `ice_set_object_tx_*`) must hold `pi->sched_lock` inside `devl_lock`. [F1027, F1028, F1153]
- All `vsi->arfs_fltr_list` and filter state accesses must use `spin_lock_bh(&vsi->arfs_lock)` / `spin_unlock_bh()` (shared between softirq `ice_rx_flow_steer` and process-context `ice_sync_arfs_fltrs`/`ice_clear_arfs`); `ice_is_arfs_using_perfect_flow()` must call `smp_mb__before_atomic()` before `atomic_read()` on `vsi->arfs_fltr_cntrs->active_*_cnt`. [F1040, F1146]
- `ice_is_xdp_ena_vsi()` must read `vsi->xdp_prog` with `READ_ONCE()`; `ice_rx_xsk_pool()` and `ice_tx_xsk_pool()` must write `ring->xsk_pool` with `WRITE_ONCE()`, and `ice_qp_ena()` must call `synchronize_net()` after enabling NAPI/IRQs and before `netif_tx_start_queue()`. [F1034, F1039]
- `ice_qp_dis()` must call `synchronize_net()`, `netif_carrier_off()`, `netif_tx_stop_queue()`, `ice_qvec_dis_irq()`, and `ice_qvec_toggle_napi(vsi, q_vector, false)` before stopping hardware rings and calling `ice_qp_clean_rings()`; `ice_vsi_stop_tx_ring()` must clear `QINT_TQCTL_CAUSE_ENA_M`, `ndelay(100)`, and call `ice_trigger_sw_intr()` (if VF not disabled) before `ice_dis_vsi_txq()`. [F1035, F1036]
- `ice_clear_rdma_cap()` must clear `ICE_FLAG_PLUG_AUX_DEV` in `pf->flags` before setting `ICE_FLAG_UNPLUG_AUX_DEV`; `ice_cfg_xps_tx_ring()` must atomically `test_and_set_bit(ICE_TX_XPS_INIT_DONE, ring->xps_state)` before `netif_set_xps_queue()`; callers of `__ice_vsi_get_qs()` must be in sleepable process context and not hold `qs_cfg->qs_mutex` (`pf->avail_q_mutex`). [F1030, F1041, F1158]

## Object Lifetimes
- `ice_adapter_get()` and `ice_adapter_put()` require sleepable process context, serialize `ice_adapters` xarray and `adapter->refcount` under `ice_adapters_mutex`, return `ERR_PTR` on failure (`ice_adapter_new` `NULL` -> `ERR_PTR(-ENOMEM)` after `xa_release`, so callers must check `IS_ERR`), and require all `adapter->ports.ports` entries removed before the last `ice_adapter_put()` runs `ice_adapter_free()` outside `ice_adapters_mutex`. [F1002, F1025, F1046, F1156]
- `ice_allocate_pf()` registers `ice_devlink_free` via `devm_add_action_or_reset` (with `devlink_priv()` holding `struct ice_pf *` for `ice_devlink_ops`), whereas `ice_allocate_sf()` returns an unmanaged `struct ice_sf_priv` (for `ice_sf_devlink_ops`) whose devlink must be explicitly freed with `devlink_free()` (e.g. in `ice_sf_dev_remove`). [F1003, F1115]
- `ice_arfs_add_flow_rules()` only unlinks and `devm_kfree`s the wrapper `struct ice_arfs_entry_ptr` (`ep`) and never `ep->arfs_entry`, whereas `ice_arfs_del_flow_rules()` unlinks and `devm_kfree`s `struct ice_arfs_entry` (`e`) after `ice_arfs_update_flow_rules` removed it from `vsi->arfs_fltr_list` via `hlist_del()`. [F1014]
- `ice_init_arfs()` must assign `vsi->arfs_fltr_list` (checked by `ice_is_arfs_active`) only after `ice_init_arfs_cntrs()` and `spin_lock_init(&vsi->arfs_lock)` succeed, and `ice_clear_arfs()` (and `ice_init_arfs_cntrs()` on error) must set `arfs_fltr_list`, `arfs_last_fltr_id`, and `arfs_fltr_cntrs` to `NULL` after freeing. [F1016]
- `ice_vsi_alloc_q_vector()` initializes `q_vector->irq.index = -ENOENT` and treats `< 0` from `ice_alloc_irq` as failure; VF control VSIs (`ICE_VSI_CTRL && vsi->vf`) share one IRQ via `ice_get_vf_ctrl_vsi(pf, vsi)`, so `ice_free_q_vector()` must skip `ice_free_irq()` when `irq.index < 0` or `ice_get_vf_ctrl_vsi(pf, vsi)` is non-NULL; both must guard `netif_napi_add_config` and `netif_napi_del` on `if (vsi->netdev)`. [F1018, F1051, F1174]
- `ice_devlink_nvm_snapshot()` and `ice_devlink_devcaps_snapshot()` must allocate `*data` with `vzalloc()` (and `vfree()` on error) because `ice_nvm_region_ops`, `ice_sram_region_ops`, and `ice_devcaps_region_ops` use `.destructor = vfree`; `ice_devlink_rate_node_new()` must allocate `struct ice_sched_node` with `devm_kzalloc(ice_hw_to_dev(pi->hw), ...)` to match `devm_kfree()` in `ice_free_sched_node()`. [F1006, F1009]
- `ice_devlink_register_params()` and `ice_devlink_unregister_params()` must both gate `ice_dvl_sched_params` on `tx_sched_topo_comp_mode_en`, and `ice_devlink_register_params()` must unwind `ice_dvl_msix_params` and `ice_dvl_rdma_params` on error. [F1008]
- `ice_mdd_reporter_dump()` and `ice_tx_hang_reporter_dump()` must not retain `priv_ctx` after returning because `ice_report_mdd_event()` and `ice_report_tx_hang()` pass stack pointers to `ice_devlink_health_report()`; atomic contexts like `.ndo_tx_timeout` must stage data via `ice_prep_tx_hang_report()` into `pf->health_reporters.tx_hang_buf` rather than calling sleepable `ice_report_tx_hang()`. [F1117, F1148]

## API Contracts
- Never call `ice_netdev_to_pf()` on VF/SF port representor netdevs (`np->repr != NULL`, `np->vsi == NULL`); check `ice_is_port_repr_netdev()` or use `ice_get_netdev_priv_vsi()`; only call `ice_devlink_port_to_dyn(port)` on `ice_devlink_port_sf_ops` (`DEVLINK_PORT_FLAVOUR_PCI_SF`) ports; always NULL-check `ice_get_ctrl_vsi(pf)` (returns `NULL` if `!pf->vsi` or `pf->ctrl_vsi_idx == ICE_NO_VSI`). [F1056, F1116, F1119]
- If `ice_vsi_alloc_q_vector()` fails at `v_idx > 0` in `ice_vsi_alloc_q_vectors()`, it shrinks `vsi->num_q_vectors = v_idx` and returns `0`, returning an error only if `v_idx == 0` (or `-EEXIST` if `vsi->q_vectors[0]` is non-NULL). [F1050]
- `ice_set_txq_ctx_vmvf()` only sets `*vmvf_num` for `ICE_VSI_VF` (`vf_base_id + vf->vf_id`), relying on `ice_vsi_cfg_txq()` and `ice_cfg_tstamp()` to zero-initialize `tlan_ctx`/`txtime_ctx` for other VSI types; `ice_set_object_tx_share()` and `ice_set_object_tx_max()` must convert bytes/sec `bw` to Kbps via `div_u64(bw, 125)` before `ice_sched_set_node_bw_lmt()`. [F1058, F1059]
- `ice_rx_flow_steer()` must reject encapsulated, non-IPv4/IPv6, fragmented IPv4, or non-TCP/UDP packets with `-EPROTONOSUPPORT`, reject flows without an active 4-tuple FDIR profile (`ice_arfs_is_perfect_flow_set`) with `-EOPNOTSUPP`, and return `fltr_info->fltr_id` on success; `ice_arfs_cmp()` requires prior validation that `n_proto` is IPv4/IPv6 and `ip_proto` is TCP/UDP. [F1090, F1170]
- `ice_sram_region_ops` byte size is `hw->flash.sr_words * 2u`, and `ice_devlink_nvm_read()` must return `-ERANGE` when `offset + size >= nvm_size`; `ice_devlink_versions` getters must leave `ctx->buf[0] == '\0'` when a version is absent, and `ice_info_cgu_fw_build()`/`ice_info_cgu_id()` must check `ice_is_feature_supported(pf, ICE_F_CGU)` before `ice_aq_get_cgu_info()`. [F1057, F1087, F1138]
- Gate `pf->health_reporters.{fw,port}` and `ice_config_health_events()` in `ice_health_init()`/`ice_health_deinit()` on `ice_is_fw_health_report_supported(&pf->hw)`; call `ice_devlink_set_port_split_options()` only when `pf->hw.pf_id == 0`; set `BIT(DEVLINK_RELOAD_ACTION_DRIVER_REINIT)` or `BIT(DEVLINK_RELOAD_ACTION_FW_ACTIVATE)` in `*actions_performed` in `ice_devlink_reload_up()`; call `ice_vsi_wait_one_rx_ring()` and `ice_vsi_ctrl_one_rx_ring(..., true)` only in sleepable context (`ice_pf_rxq_wait()` uses `usleep_range`). [F1141, F1142, F1157, F1162]

## Error Handling
- `ice_devlink_init_regions()` and `ice_init_devlink_rep()` must convert `IS_ERR` returns from `devl_region_create()` and `devl_health_reporter_create()` to `NULL` so `ice_devlink_destroy_regions()`, `ice_deinit_devl_reporter()`, and `ice_health_assign_healthy_state()` can safely test pointers for non-NULL. [F1004, F1005]
- On partial allocation failure in `__ice_vsi_get_qs_sc()`, clear all `i` bits already set in `qs_cfg->pf_map` and zero `qs_cfg->vsi_map` before unlocking `qs_cfg->qs_mutex`; in `ice_vsi_cfg_txq()`, if `ice_alloc_setup_tstamp_ring()` or `ice_cfg_tstamp()` fails after `ice_ena_vsi_txq()`, call `ice_free_tx_tstamp_ring(ring)` (if allocated) and `ice_dis_vsi_txq()`. [F1017, F1020]
- `ice_vsi_stop_tx_ring()` treats `-EBUSY` and `-ENOENT` from `ice_dis_vsi_txq()` as `0`; `ice_qp_dis()` and `ice_qp_ena()` run all steps even after an earlier error, recording the first error via `if (!fail) fail = err`. [F1052, F1053]

## External Contracts
- In `struct ice_aqc_dis_txq_item` (`0x0C31`), when `num_qs` is even, add 2 bytes of padding after `q_id[]` to 4-byte align the next `parent_teid`; `struct ice_aqc_add_txqs_perq` must use 22-byte `ice_txq_ctx_buf_t` (`ICE_TXQ_CTX_SZ`), not 40-byte `ice_txq_ctx_buf_full_t` (`ICE_TXQ_CTX_FULL_SZ`). [F1061, F1086]
- `ice_vsi_ctrl_one_rx_ring()` must call `ice_flush(hw)` after writing `QRX_CTRL` before `ice_pf_rxq_wait()`; `ice_cfg_txq_interrupt()` and `ice_cfg_rxq_interrupt()` must call `ice_flush(hw)` after writing `QINT_TQCTL`/`QINT_RQCTL`, and when `ice_is_xdp_ena_vsi(vsi)` is true, `ice_cfg_txq_interrupt()` must also write `QINT_TQCTL(vsi->txq_map[txq + vsi->num_xdp_txq])`. [F1123, F1127]
- `ice_irq_dynamic_ena()` must return without writing `GLINT_DYN_CTL` if `vsi && test_bit(ICE_VSI_DOWN, vsi->state)`, and must set both `GLINT_DYN_CTL_INTENA_M` and `GLINT_DYN_CTL_CLEARPBA_M`; `ice_devlink_port_fn_hw_addr_set()` must reject changes with `-EBUSY` if `dyn_port->attached` and `-EADDRNOTAVAIL` if `hw_addr_len != ETH_ALEN || !is_valid_ether_addr(hw_addr)`. [F1129, F1168]

## Known Pitfalls
- In `ice_pf_rxq_wait()` and `ice_vsi_ctrl_one_rx_ring()`, normalize `QRX_CTRL_QENA_STAT_M` with `!!` (`ena == !!(reg & QRX_CTRL_QENA_STAT_M)`); in `ice_vsi_map_rings_to_vectors()`, reset `q_vector->tx.tx_ring = NULL` and `q_vector->rx.rx_ring = NULL` on each vector iteration; in `ice_arfs_is_flow_expired()`, test UDP expiration using `time_in_range64(arfs_entry->time_activated + ICE_ARFS_TIME_DELTA_EXPIRATION, arfs_entry->time_activated, get_jiffies_64())`. [F1101, F1103, F1111]
