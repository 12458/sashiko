# NFC SUBSYSTEM — (top level)

This component covers core NFC device management (`net/nfc/core.c`), sockets (`net/nfc/af_nfc.c`), the Digital stack (`net/nfc/digital_core.c`), NFC/NCI/HCI/Digital headers, and four driver families (`s3fwrn5`, `st-nci`, `st21nfca`, `st95hf`) across I2C, SPI, and UART.

## Architecture & Data Flow

- Apply `to_nfc_dev(d)` only to `nfc_class` devices, never bus parents (`dev->parent`). `dev->targets_generation` and `nfc_devlist_generation` start at `1` for Netlink `cb->seq`, with `nfc_devlist_generation` incremented under `nfc_devlist_mutex` alongside `device_add` / `device_del`. [F71, F97, F130]
- `digital_target_found` must validate `protocol` in `switch (protocol)` (1..7, else `-EINVAL`) before `1 << protocol`, update `curr_rf_tech`, set `skb_add_crc` / `skb_check_crc` to non-NULL wrappers (`digital_skb_*_crc_none` if `DIGITAL_DRV_CAPS_IN_CRC(ddev)`), and zero `poll_tech_count` before `nfc_targets_found`, restoring it on error. [F72, F115, F126]
- Size `pipes[]` in `nci_hci_dev` / `nfc_hci_dev` to `*_MAX_PIPES` (128; never index with sentinels `0x80`/`0x81`) and `gate2pipe[]` to `*_MAX_GATES` (256). `hdev->quirks` shares generic quirks (`0`) and `st21nfca` flags (`ST21NFCA_FACTORY_MODE = 2`), requiring distinct bit indices `< BITS_PER_LONG`. [F87, F135]
- In `st_nci_hci_network_init` and `st21nfca_hci_probe`, verify `dev_num < *_NUM_DEVICES` (256) after `find_first_zero_bit` before `set_bit` or formatting NUL-terminated `init_data.session_id` (`char[9]`); set `init_data.gate_count = ARRAY_SIZE(...)` (`<= 50`) while `memcpy` into `init_data.gates` uses `sizeof(...)`. `*_hci_load_session` must mutate only `init_data.gates` (not static `*_gates`), check `*_DM_IS_PIPE_OPEN` (`(p & 0x0f) == 0x06`) and `j < ARRAY_SIZE(..._gates)`, and update `init_data.gates[j].pipe`, `gate2pipe[gate]`, and `pipes[pipe]` together. [F73, F100, F123, F131, F134]
- In `st21nfca` / `st-nci` `*_control_se`, arm `count_pipes`, `expected_pipes`, `req_completion`, `se_active_timer`, and `se_active = true` together, and in `EVT_HOT_PLUG` / `ANY_OPEN_PIPE` call `timer_delete_sync(&info->se_info.se_active_timer)` and set `se_active = false` before `complete(&info->se_info.req_completion)`. In `*_se_get_bwi`, advance `i` past `TA` (`*_ATR_TA_PRESENT`) before reading `TB` (`*_ATR_TB_PRESENT`), and pass only a 4-bit nibble (`atr[i] >> 4`) to `*_BWI_TO_TIMEOUT(x)` (`(1 << x) * 200`). [F80, F109, F116]
- `ndlc_open` / `ndlc_close` must call `ndlc->ops->enable` before setting/clearing `ndlc->powered` because `st_nci_*_enable` only calls `enable_irq` when `powered == 0 && irq_active == 0`. In `llt_ndlc`, set `t1_active` / `t2_active` on `mod_timer` and clear on expiry or `timer_delete_sync`; `llt_ndlc_requeue_data_pending` must `skb_dequeue_tail`, set the retransmit bit in `skb->data[0]`, and `skb_queue_head`. [F74, F75, F76]
- `st21nfca_hci_i2c_write` must byte-stuff only `skb->data[1 .. skb->len - 2]`, and `st21nfca_hci_i2c_repack` must trim `skb` to `i - j` before `check_crc`. In `st21nfca_hci_i2c_read` and `st21nfca_hci_irq_thread_fn`, reset `phy->current_read_len = 0` on `ST21NFCA_SOF_EOF`, read error, `-EBADMSG` retry, or mid-frame `IS_START_OF_FRAME(buf)` (also calling `skb_trim(skb, 0)`). In `st21nfca_im_recv_dep_res_cb`, mask `curr_nfc_dep_pni` increments with `ST21NFCA_NFC_DEP_PFB_PNI()` (`& 0x03`). [F79, F107, F108, F118]
- Keep `struct phy_common common` at offset 0 of `s3fwrn5_i2c_phy` and `s3fwrn82_uart_phy` for `s3fwrn5_phy_*` casts. `s3fwrn5_fw_init` resets `parity = 0x00` and `s3fwrn5_fw_prep_msg` ORs `parity` into `hdr.type` and toggles `parity ^= 0x80`; `s3fwrn5_fw_request_firmware` must `memcpy(fw->date, ..., 12)` and set `fw->date[12] = '\0'`. [F81, F129, F132]
- In `st95hf`, `dev_set_drvdata(&nfc_spi_dev->dev, ...)` stores `&st95context->spicontext` while `nfc_digital_set_drvdata` and IRQ `dev_id` store `st95context` (use `container_of` in `st95hf_remove`). For `106A`, `st95hf_in_configure_hw` stores framing in `sendrcv_trflag` so TX appends it and RX checks/strips the 2-byte CRC only when `sendrcv_trflag == TRFLAG_NFCA_STD_FRAME_CRC`. In `st95hf_spi_recv_response`, combine `receivebuff[0] & 0x60` with `receivebuff[1]` for the 10-bit length, and allocate `MAX_RESPONSE_BUFFER_SIZE` (280) for async `skb_resp`. [F85, F95, F128]

## Synchronization

- In `net/nfc/core.c`, `device_lock(&dev->dev)` serializes `shutting_down`, `rfkill`, and `active_target`: `nfc_unregister_device` sets `shutting_down = true` under the lock, and all core entry points and `mod_timer(&dev->check_pres_timer, ...)` calls must hold `device_lock` and check `!dev->shutting_down`. Call `timer_delete_sync(&dev->check_pres_timer)` before `nfc_deactivate_target` or `im_transceive`, and set `dev->rfkill = NULL` under `device_lock` when destroying `rfkill`. In `nfc_check_pres_work`, copy `active_target->idx` and call `device_unlock(&dev->dev)` before `nfc_target_lost`. [F2, F23, F25, F69, F70, F151]
- In `net/nfc/af_nfc.c`, `nfc_proto_register` must call sleeping `proto_register` before `write_lock(&proto_tab_lock)` (calling `proto_unregister` after unlocking if `proto_tab[id]` is busy), `nfc_proto_unregister` must clear `proto_tab[id]` under `write_lock` before `proto_unregister`, and `nfc_sock_create` calls `nfc_protocol.create` under `read_lock(&proto_tab_lock)` (no sleeping or `GFP_KERNEL`). [F4, F29, F148, F149]
- In `net/nfc/digital_core.c`, `ddev->cmd_lock` protects `cmd_queue` and `cmd->pending`: `digital_wq_cmd` keeps the active `cmd` at the head (`pending = 1`) until `digital_wq_cmd_complete` (or sync error) unlinks it and calls `schedule_work(&ddev->cmd_work)`, dropping `cmd_lock` before `ddev->ops` or `cmd->cmd_cb`. Check `poll_tech_count != 0` under `ddev->poll_lock` in `digital_poll_next_tech`, and zero `poll_tech_count` under `poll_lock` then unlock before `cancel_delayed_work_sync(&ddev->poll_work)`. [F30, F32, F110, F114]
- In `st-nci`, `st_nci_open` sets `ST_NCI_RUNNING` via `test_and_set_bit` before `ndlc_open` (clearing on error), `st_nci_send` checks `test_bit(ST_NCI_RUNNING, &info->flags)` before `ndlc_send`, and `st_nci_close` clears it after `ndlc_close`; `ndlc_t1_timeout` / `ndlc_t2_timeout` must only schedule `ndlc->sm_work`. [F35, F155]
- In `st21nfca`, hold `info->info_lock` across `info->state` and `phy_ops->enable` / `disable` in `st21nfca_hci_open` / `close`, and `phy->phy_lock` across I2C retries in `st21nfca_hci_i2c_write` / `read`. `st21nfca_se_wt_timeout` must defer work to `se_info.timeout_work`, and both `st21nfca_apdu_reader_event_received` and `st21nfca_se_deinit` must call `timer_delete_sync(&info->se_info.bwi_timer)` before `cancel_work_sync(&info->se_info.timeout_work)`. [F37, F38, F39, F154]
- In `s3fwrn5`, lock order is `info->mutex` -> `phy->common.mutex`: `s3fwrn5_nci_send` holds `info->mutex` across checking `S3FWRN5_MODE_NCI` and calling `s3fwrn5_write`. Under `phy->common.mutex`, `s3fwrn5_i2c_set_mode` sets `phy->irq_skip = true` on mode change, and `s3fwrn5_i2c_write` clears `irq_skip = false` before sending. [F40, F82]
- In `st95hf`, lock order is `rm_lock` -> `spicontext.spi_lock`: `rm_lock` serializes `st95hf_remove` (`nfcdev_free = true`, freeing `ddev`) against `st95hf_irq_thread_handler`, while `spi_lock` serializes SPI transfers and for SYNC requests in `st95hf_spi_send` must be held across `req_issync = true`, `reinit_completion(&spicontext->done)`, `spi_sync`, and `wait_for_completion_timeout`. Hardirq `st95hf_irq_handler` must only call `complete(&spicontext->done)` if `req_issync` or return `IRQ_WAKE_THREAD`. [F43, F45, F156, F158]
- `st95hf_in_send_cmd` sets `complete_cb_arg` and calls `down_killable(&stcontext->exchange_lock)` before ASYNC send: on `st95hf_spi_send` error it calls `up(&exchange_lock)` and `kfree_skb(skb_resp)` without freeing `skb`, and on success it calls `kfree_skb(skb)` and leaves `exchange_lock` for `st95hf_irq_thread_handler`. On `WTX_REQ_FROM_TAG`, if `st95hf_handle_wtx(stcontext, true, ...)` succeeds, `st95hf_irq_thread_handler` sets `wtx = true`, unlocks `rm_lock`, and returns `IRQ_HANDLED` without `up(&exchange_lock)`, freeing `skb_resp`, or calling `complete_cb`; on the next response/error it calls `st95hf_handle_wtx(stcontext, false, 0)`, clears `wtx = false` (and `cb_arg->rats = false` on error), and `up(&exchange_lock)`. [F19, F44, F84, F111]

## Object Lifetimes

- Always free `nfc_allocate_device` devices with `nfc_free_device(dev)` (never `kfree(dev)`). `nfc_deactivate_target`, `nfc_dep_link_down`, and `nfc_target_lost` must set `dev->active_target = NULL` under `device_lock(&dev->dev)` (`nfc_target_lost` returns `-EINVAL` if `i == dev->n_targets`, or decrements `n_targets` and compacts/frees `dev->targets`). `nfc_digital_unregister_device` unregisters `nfc_dev`, zeros `poll_tech_count` under `poll_lock`, cancels `poll_work`, `cmd_work`, and `cmd_complete_work`, and drains `cmd_queue` via `cmd->cmd_cb(..., ERR_PTR(-ENODEV))` before freeing `mdaa_params` and `cmd`. [F3, F9, F105, F136]
- `ndlc_remove` must call `timer_delete_sync` on `t1_timer` / `t2_timer` and `cancel_work_sync(&ndlc->sm_work)` before `st_nci_remove` and queue purging. `st21nfca_hci_remove` must call `st21nfca_dep_deinit` and `st21nfca_se_deinit` before unregistering/freeing `hdev` and `info`, and `st21nfca_hci_i2c_probe` errors and `st21nfca_hci_i2c_remove` must `kfree_skb(phy->pending_skb)`. [F34, F36, F139]
- In `s3fwrn5_firmware_update`, return directly if `s3fwrn5_fw_setup` fails (it releases `fw.fw`), and `goto out:` (`s3fwrn5_fw_cleanup`) after it succeeds. In `s3fwrn5_fw_send_msg`, call `reinit_completion(&fw_info->completion)` before `s3fwrn5_write`, callers always `kfree_skb(msg)`, and on success `fw_info->rsp` moves to `*rsp` (`fw_info->rsp = NULL`) for the caller to `kfree_skb(rsp)`. `s3fwrn82_uart_probe` errors and `s3fwrn82_uart_remove` tear down in LIFO order: `s3fwrn5_remove`, `serdev_device_close`, `kfree_skb(phy->recv_skb)`. In `st95hf_probe` / `st95hf_remove`, check `if (st95context->st95hf_supply)` before `regulator_disable`. [F12, F13, F14, F42, F60, F141]

## API Contracts

- `nfc_allocate_device` requires `start_poll`, `stop_poll`, `activate_target`, `deactivate_target`, `im_transceive`, and non-zero `supported_protocols`, and only initializes `check_pres_*` if `ops->check_presence` is set (guard optional ops, and set both `enable_se` and `disable_se` if SE is used). `nfc_digital_allocate_device` requires `in_configure_hw`, `in_send_cmd`, `tg_listen`, `tg_configure_hw`, `tg_send_cmd`, `abort_cmd`, and `switch_rf` (plus `tg_get_rf_tech` if `tg_listen_md` is set); `digital_start_poll` checks `tg_listen_mdaa` then `tg_listen_md` before `nfca`/`nfcf`, and `in_configure_hw` / `tg_configure_hw` must enable RF because `digital_poll_next_tech` turns RF off between polls. [F58, F59, F67, F102, F161, F162]
- `digital_target_found`, `nfc_activate_target`, and `curr_protocol` take unshifted `NFC_PROTO_*` numbers, whereas `nfc_allocate_device`, `nfc_digital_allocate_device`, `nfc_start_poll`, `nfc_tm_activated`, and `supported_protocols` take `NFC_PROTO_*_MASK` bitmasks. `nfc_targets_found`, `nfc_target_lost`, and `nfc_driver_failure` take `device_lock(&dev->dev)` (process context only, never inside `nfc_ops`), and `nfc_targets_found` must guard `kmemdup` with `if (targets)`. [F61, F150, F164]
- `nfc_data_exchange` and `nfc_tm_data_received` always consume `skb` (even on error). Allocate RX `sk_buff`s for `data_exchange_cb_t` or reassembly via `nfc_alloc_recv_skb` (`NFC_HEADER_SIZE` headroom), and never exceed declared `tx_headroom` / `tx_tailroom` on TX `sk_buff`s. Physical `write` callbacks and `nfc_hci_ops.xmit` must return `0` on full write or `-errno` (never byte count) and leave `skb` unaltered and unconsumed (`s3fwrn5_nci_send` calls `kfree_skb` on error, `consume_skb` on success). [F5, F11, F49, F168, F169, F173]
- If an async `nfc_digital_ops` callback fails synchronously, do not free `skb` or call `nfc_digital_cmd_complete_t` (`digital_wq_cmd` frees `cmd->req`). Once it returns `0`, the driver must call `nfc_digital_cmd_complete_t`: on error/timeout free any response `skb` and pass `ERR_PTR(-errno)` (never `NULL`), and on `!IS_ERR(resp)` the callback frees `resp` (`digital_in_send_complete` converts `IS_ERR(resp)` to `rc = PTR_ERR(resp), resp = NULL` for `data_exchange_cb_t`). [F10, F50, F165, F166]
- Call `nfc_vendor_cmd_alloc_reply_skb` and `nfc_vendor_cmd_reply` only synchronously in `nfc_vendor_cmd.doit` without touching `skb->cb`, and either pass `msg` to `nfc_vendor_cmd_reply` or `kfree_skb(msg)`. `nfc_fw_download_done` takes `0` or positive errno (`u32`), and `s3fwrn5_fw_init` requires NUL-terminated `fw_name` `<= NFC_FIRMWARE_NAME_MAXSIZE` (32). [F18, F65, F66, F133]
- `se_io` handlers (`st_nci_se_io`, `st21nfca_hci_se_io`) must `kfree(cb_context)` on sync error before arming `bwi_timer`. `*_control_se` returns positive `se_idx` or `< 0` (check `r < 0`). `st21nfca` / `st-nci` gate event `default:` branches must return `1` without freeing `skb`. For `nci_core_conn_create` with `params->length > 0`, `params->value` needs `sizeof(struct dest_spec_params)` bytes and `params_len = sizeof(*params) + params->length`. In `st95hf`, `st95hf_echo_command` passes `recv_res = false` (`st95hf_spi_recv_echo_res`) while other `SYNC` commands pass `recv_res = true` (`st95hf_spi_recv_response`, where callers must check `< 0` and `receivebuff[0]`). [F6, F54, F55, F56, F103, F122]

## Error Handling

- Check `devm_gpiod_get`, `devm_clk_get_optional_enabled`, and `devm_regulator_get` with `IS_ERR()`, and reject `skb->len <= 2` in `digital_skb_check_crc` before `skb->len - 2`. [F48, F93]
- In `st21nfca` / `st_nci` `*_connectivity_event_received`, `*_EVT_TRANSACTION` checks must use `||` (`-EPROTO`) to validate `skb->len` against `2`, `aid_len + 4` (`aid_len <= sizeof(transaction->aid)`), and `aid_len + 4 + params_len` before reading `skb->data` and allocating `sizeof(*transaction) + params_len`. In `st_nci_i2c_read` / `st_nci_spi_read`, check 16-bit BE `len` at `buf + 2` against `<= 250` before reading into `buf`. `st95hf_send_recv_cmd` must check `cmd_len <= MAX_CMD_LEN` (7), `no_cmd_params >= no_modif`, and `param_offset < no_cmd_params`, copying `cmd_params` into local `spi_cmd_buffer` before writing `spi_cmd_buffer[3 + param_offset]`. [F83, F86, F88, F96, F99]

## External Contracts

- `include/uapi/linux/nfc.h` structs must use `__kernel_sa_family_t`, `__kernel_size_t`, `__u32`, and `__u8`, and `nfc_sock_create` must reject `net != &init_net` with `-EAFNOSUPPORT`. [F174, F175]

## Known Pitfalls

- Use `nfc_find_target` instead of `dev->targets[target_idx]`. Pass `ARRAY_SIZE(cmds)` (never `sizeof(cmds)`) to `*_set_vendor_cmds`. Mask NDLC `pcb` with `PCB_TYPE_MASK` / `PCB_SYNC_MASK` before comparing. In `s3fwrn5_nci_rf_configure`, use `*((u32 *)(fw->data + i))` (`i += 4`), never `((u32 *)fw->data)[i]`. [F91, F101, F125, F177]
