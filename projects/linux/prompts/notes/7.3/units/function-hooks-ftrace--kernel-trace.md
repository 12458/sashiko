# FUNCTION HOOKS (FTRACE) — kernel/trace

`kernel/trace/ftrace.c` and `kernel/trace/fgraph.c` manage callsite records, `ftrace_ops` and `fgraph_ops` lifecycles, filter hashes, direct calls, profiling, tracefs filters, and per-task shadow return stacks (`ret_stack`).

## Architecture & Data Flow
- `dyn_ftrace->flags` packs refcount in bits `0..18` (`FTRACE_REF_MAX`) and flags in `19..31`: `__ftrace_hash_rec_update()` must bound `ftrace_rec_count(rec)` against `FTRACE_REF_MAX` and `0`. When disabling (`!flag` with `update`), `ftrace_check_record()` must keep `FTRACE_NOCLEAR_FLAGS` (`FTRACE_FL_DISABLED | FTRACE_FL_TOUCHED | FTRACE_FL_MODIFIED`), clearing all other flags if count is 0 or only `*_EN` flags if `> 0`. `ftrace_get_addr_new()` and `ftrace_get_addr_curr()` must check `FTRACE_FL_DIRECT`/`_EN` before `FTRACE_FL_TRAMP`/`_EN`, and `TRAMP` before `FTRACE_FL_REGS`/`_EN`. [F216, F240, F255]
- Around `ftrace_run_update_code()`, `ftrace_run_modify_code()` and `ftrace_shutdown()` must populate `ops->old_hash` while `FTRACE_OPS_FL_MODIFYING` or `FTRACE_OPS_FL_REMOVING` (`removed_ops = ops`) is set, and clear them after. `ftrace_find_tramp_ops_curr()` must check `removed_ops->old_hash` first, skip `FTRACE_OPS_FL_ADDING` ops, test `&op->old_hash` if `FTRACE_OPS_FL_MODIFYING`, and test `op->func_hash` otherwise. [F221, F247]
- `ftrace_startup_subops()` must canonicalize `NULL` `filter_hash`/`notrace_hash` to `EMPTY_HASH` before `add_next_hash()`. In `add_first_hash()` and `add_next_hash()`, a manager ops must keep `notrace_hash = EMPTY_HASH` whenever its aggregated `filter_hash` is non-empty (subtracting subop `notrace_hash` via `remove_hash()`), only populating `notrace_hash` via `intersect_hash()` when `filter_hash == EMPTY_HASH`. [F190, F214]
- `ftrace_hash_move_and_update_ops()` must route `FTRACE_OPS_FL_SUBOP` ops (or unenabled ops sharing `func_hash` with an enabled subop on `op->subop_list`) through `ftrace_hash_move_and_update_subops()`. When `ftrace_hash_rec_update_modify()` or `ftrace_ops_update_code()` modifies an ops with `func_hash == &global_ops.local_hash`, it must walk `ftrace_ops_list` to update all enabled ops sharing `&global_ops.local_hash`. [F206, F208]
- `__register_ftrace_function()` and `register_ftrace_graph()` must save `ops->saved_func` / `gops->saved_func` before PID wrapping, and `__unregister_ftrace_function()` must restore `ops->func = ops->saved_func`. Toggling `op->func` in `ftrace_update_pid_func()` / `__register_ftrace_function()` requires `ftrace_update_trampoline()` and `update_ftrace_function()`; toggling `gops->entryfunc` in `fgraph_update_pid_func()` requires `static_call_update(fgraph_func, gops->entryfunc)` when `ftrace_graph_active == 1`. [F203, F204, F300]
- `register_ftrace_graph()` must create `fgraph_stack_cachep` before `fgraph_cpu_init` or `start_graph_tracing()`, and keep `fgraph_array`, `fgraph_array_bitmask`, `ftrace_graph_active`, `fgraph_direct_gops`, `fgraph_func`, `fgraph_retfunc`, and `fgraph_do_direct` synchronized via `ftrace_graph_enable_direct()` / `ftrace_graph_disable_direct()` as `ftrace_graph_active` crosses 1. Only `fgraph_ops::ops` may set `FTRACE_OPS_FL_GRAPH` or join `graph_ops.subop_list`; `subop_list` walkers (`print_subops()`) must check `FTRACE_OPS_FL_GRAPH` before `container_of`. [F205, F268, F276]
- Before setting `t->ret_stack` in `alloc_retstack_tasklist()` or `graph_init_task()`, `ret_stack_init_task_vars()` must zero `SHADOW_STACK_TASK_VARS`, and set `t->curr_ret_stack = 0` and `t->curr_ret_depth = -1` before `smp_wmb()`. `start_graph_tracing()` sizes `ret_stack_list` for `FTRACE_RETSTACK_ALLOC_SIZE` pointers (`sizeof(*ret_stack_list)`), allocating stacks from `fgraph_stack_cachep`. [F199, F261]
- `ftrace_push_return_trace()` and `fgraph_reserve_data()` must reject offsets `>= SHADOW_STACK_MAX_OFFSET` (reserving `SHADOW_STACK_TASK_VARS`). `get_ret_stack()` must check `offset > 0` before reading `t->ret_stack[offset - 1]` and `offs > 0 && offs <= offset` before subtracting `offs`. `FGRAPH_ARRAY_SIZE` must not exceed `1 << FGRAPH_DATA_INDEX_BITS` (16) or `FGRAPH_INDEX_BITS` (16). [F225, F226, F228]
- `ftrace_page::records` has size `1 << pg->order` pages: capacity checks and `ftrace_free_pages()` / `ftrace_release_mod()` must scale by `pg->order`, and adding/freeing pages or records must update `ftrace_number_of_pages`, `ftrace_number_of_groups`, and `ftrace_update_tot_cnt`. `ftrace_process_locs()` must filter zero and (when `!mod`) non-`is_kernel_text`/`is_kernel_inittext` addresses before `ftrace_call_adjust()`. `lookup_rec()` must check `pg->index == 0` before `pg->records[pg->index - 1].ip`. Hash insertions (`__ftrace_match_addr()`, `enter_record()`, `append_hash()`, `ftrace_graph_set_hash()`) must check `*ftrace_lookup_ip()` before `add_hash_entry()`. [F209, F213, F223, F224, F265]
- `ftrace_profile_page` must be a single page-aligned page (for `PAGE_MASK` in `function_stat_next()`) with `pg->index <= PROFILES_PER_PAGE`. `ftrace_profile_reset()` must reset `stat->pages = stat->start`, zero `stat->hash`, and zero `pg->index` and `PROFILE_RECORDS_SIZE` bytes (never `PAGE_SIZE`) of `pg->records` across `pg->next`. [F217, F263, F264]
- `ftrace_graph_probe_sched_switch()` must check `next->ftrace_timestamp != 0` before adding sleep time. `profile_graph_return()` must subtract `current->ftrace_sleeptime - profile_data->sleeptime` when `!fgraph_sleep_time`, and when `!fgraph_graph_time`, add `calltime` to `parent_data->subtime` before subtracting `profile_data->subtime` (clamping `calltime` to 0 if `profile_data->subtime >= calltime`). `function_stat_show()` must check `stddev_denom = rec->counter * (rec->counter - 1) * 1000` for non-zero before `div64_ul()`. [F250, F252, F259, F260]
- In `ftrace_regex_open()` and `__ftrace_graph_open()`, `file->private_data` is `struct seq_file *` only when `FMODE_READ` is set, and `ftrace_iterator *` or `ftrace_graph_data *` when write-only. `MULTI_FLAGS` must check `#ifdef CONFIG_HAVE_DYNAMIC_FTRACE_WITH_REGS` (with `CONFIG_`). [F195, F298]

## Synchronization
- Lock order: `direct_mutex` -> `ftrace_lock`, and `trace_types_lock` -> `ops->func_hash->regex_lock` -> `ftrace_lock`. Drop `ftrace_lock` before `cleanup_direct_functions_after_ipmodify()`, `clear_mod_from_hashes()`, `clear_func_from_hashes()`, and `match_records()`. `ftrace_rec_iter_*()` uses a static iterator and requires `ftrace_lock`. [F171, F173, F183]
- `register_ftrace_graph()` must not set `fgraph_array[i] = gops` until `ftrace_startup_subops()` succeeds. Lockless readers in `function_graph_enter_regs()` and `__ftrace_return_to_handler()` must use `READ_ONCE(fgraph_array[i])`, check `!= &fgraph_stub`, and bracket `entryfunc`/`retfunc` with `ftrace_test_recursion_trylock()` / `unlock()`. [F164, F165, F279]
- `ftrace_push_return_trace()` and `fgraph_reserve_data()` must write descriptor `val` to the new stack top, `barrier()`, advance `current->curr_ret_stack`, `barrier()`, and write `val` again. `__ftrace_return_to_handler()` must not decrement `curr_ret_stack` until after all `retfunc` calls and a `barrier()`. [F167, F168]
- In `ftrace_modify_all_code()` (`FTRACE_UPDATE_TRACE_FUNC`), call `update_ftrace_func(ftrace_ops_list_func)` before `ftrace_replace_code()`, and publish `function_trace_op` with `smp_wmb()` (and `ftrace_sync_ipi` if IRQs enabled) before `update_ftrace_func(ftrace_trace_function)`. `ftrace_replace_code()` may only call `cond_resched()` when `FTRACE_MODIFY_MAY_SLEEP_FL` is set; process-context `do_for_each_ftrace_rec()` loops doing kallsyms/patching must call `cond_resched()`. In `ftrace_process_locs()`, `ftrace_update_code()` requires `local_irq_save()` when `!mod`, whereas `mod != NULL` runs with IRQs enabled and `FTRACE_FL_DISABLED` set. [F182, F239, F294, F295]
- `ftrace_find_profiled_func()` and `__ftrace_lookup_ip()` must use `hlist_for_each_entry_rcu_notrace()` under `preempt_disable_notrace()`. `function_profile_call()` and `profile_graph_return()` require `guard(preempt_notrace)()`, and `ftrace_profile_alloc()` must serialize against NMI via `atomic_inc_return(&stat->disabled) != 1` and re-check `ftrace_find_profiled_func()`. `ftrace_mod_address_lookup()` and `ftrace_mod_get_kallsym()` must `preempt_disable()` across `list_for_each_entry_rcu()`. [F277, F280, F291]
- `pid_write()` and `clear_ftrace_pids()` must hold `ftrace_lock`, use `rcu_assign_pointer()`, and `synchronize_rcu()` before `trace_pid_list_free()`. `t_start()`, `g_start()`, `fpid_start()`, and `fnpid_start()` unconditionally acquire their locks before any return, so only `t_stop()`, `g_stop()`, and `fpid_stop()` may release them. Idle task shadow stacks must be initialized for online CPUs in `start_graph_tracing()` and via hotplug `fgraph_cpu_init()`. [F159, F292, F296]

## Object Lifetimes
- `register_ftrace_graph()` must call `fgraph_lru_release_index()` and set `gops->saved_func = NULL` on error; `unregister_ftrace_graph()` must set `fgraph_array[gops->idx] = &fgraph_stub` (never `NULL`). `ftrace_graph_init_task()` must set `t->ret_stack = NULL` before conditional allocation; `ftrace_graph_exit_task()` must set `t->ret_stack = NULL` and `barrier()` before `kmem_cache_free()`; `idle_ret_stack` is never freed. In `alloc_retstack_tasklist()`, `free:` must free `ret_stack_list[start..end)`, and `start_graph_tracing()` must retry on `-EAGAIN`. [F146, F148, F249]
- Free `ftrace_hash` only via `free_ftrace_hash()` or `free_ftrace_hash_rcu()` (preserving `EMPTY_HASH`), and reset freed pointers in `ftrace_free_filter()` to `EMPTY_HASH`. In `ftrace_startup_subops()`, `rebuild_hashes()`, `ftrace_shutdown_subops()`, and `ftrace_hash_move_and_update_subops()`, free intermediate/replaced hashes and roll back `subops->list` on error. [F150, F152]
- On `ftrace_hash_ipmodify_enable()` failure, `ftrace_startup()` must roll back `__unregister_ftrace_function()`, `ftrace_start_up--`, `FTRACE_OPS_FL_ENABLED`, and `ftrace_trampoline_free()`. `ftrace_shutdown()` on `FTRACE_OPS_FL_DYNAMIC` ops must call both `synchronize_rcu_tasks_rude()` and `synchronize_rcu_tasks()` before `ftrace_trampoline_free()`. `ftrace_trampoline_free()` (`FTRACE_OPS_FL_ALLOC_TRAMP`) must emit unregister perf events and call `ftrace_remove_trampoline_from_kallsyms()` before `arch_ftrace_trampoline_free()`. [F153, F154]
- `ftrace_regex_open()` must copy `filter_hash`/`notrace_hash` into `iter->hash` under `regex_lock` and clean up `iter->hash`, `iter->parser`, `iter`, and `trace_array_put(tr)` on error. `__ftrace_graph_open()` must clear `fgd->hash = NULL` before unlocking `graph_lock` so `g_start()` re-fetches it and resets `fgd->idx = 0` and `fgd->entry = NULL`. `ftrace_regex_release()` and `ftrace_graph_release()` must read `m->private` before `seq_release()` when `FMODE_READ` is set, and `ftrace_graph_release()` must call `synchronize_rcu_tasks_rude()` before freeing `old_hash` and free `fgd->new_hash`. [F157, F158, F175, F212]
- `register_ftrace_function_probe()` and `unregister_ftrace_function_probe_func()` must pair `acquire_probe_locked()` with `release_probe()` across dropping `ftrace_lock`, and roll back `probe_ops->init()` via `probe_ops->free()` on error. Unlinked `ftrace_page` structs in `ftrace_process_locs()`, `ftrace_release_mod()`, and `ftrace_free_mem()` must be freed only after unlocking `ftrace_lock` and calling `synchronize_rcu()`. `ftrace_release_mod()` must unlink `mod_map` and call `call_rcu(&mod_map->rcu, ftrace_free_mod_map)` before checking `ftrace_disabled`. [F160, F162, F163]

## API Contracts
- `ftrace_func_mapper` has `ftrace_hash` first and `ftrace_func_map` has `ftrace_func_entry` first; `@free_func` in `free_ftrace_func_mapper()` must only free `map->data` and never `kfree(map)`. In `append_hash()`, `*hash == NULL` allocates a new hash whereas non-NULL `ftrace_hash_empty(*hash)` (`EMPTY_HASH`) returns 0 immediately. `alloc_ftrace_hash(size_bits)` takes a shift exponent, so callers must apply `fls()` before clamping to `FTRACE_HASH_MAX_BITS`. [F161, F184, F191, F270]
- Filter/command helpers (`ftrace_mod_callback()`, `ftrace_set_regex()`, `ftrace_regex_open()`/`release()`) must check `if (!tr)` because standalone filters have `ops->private == NULL`. `match_records()` / `ftrace_match_records()` return `1` (matched), `0` (no match), or `< 0` (`-ENOMEM`). `ftrace_location_range()` and `ftrace_text_reserved()` take an inclusive `end` (`ip + size - 1`). [F192, F194, F201]
- `fgraph_reserve_data()` rounds `size_bytes` up to `sizeof(long)` words, `make_data_type_val()` / `__get_data_size()` encode `size - 1`, and `fgraph_retrieve*_data()` returns the word-rounded byte size. `ftrace_graph_ret_addr()` must pass `task` (not `current`) to `get_ret_stack()`, start at `*idx ? : task->curr_ret_stack`, and update `*idx = i`. `ftrace_suspend_notifier_call()` must pair `pause_graph_tracing()` (`PM_HIBERNATION_PREPARE`) with `unpause_graph_tracing()` (`PM_POST_HIBERNATION`). [F231, F243, F256, F274]
- `__ftrace_ops_list_func()` and `ftrace_ops_assist_func()` must check `!(op->flags & FTRACE_OPS_FL_RCU) || rcu_is_watching()`, and `ftrace_ops_get_func()` must route `FTRACE_OPS_FL_RCU` or `FTRACE_OPS_FL_RECURSION` ops to `ftrace_ops_assist_func`. `ftrace_ops_test()` must return `0` when `regs == NULL && (ops->flags & FTRACE_OPS_FL_SAVE_REGS)`. [F278, F297]

## Error Handling
- `function_graph_enter_regs()` must save/restore `current->curr_ret_stack` around each `entryfunc` returning 0, and roll back `FGRAPH_FRAME_OFFSET + 1` and `curr_ret_depth` if `bitmap == 0`. Stack exhaustion in `ftrace_push_return_trace()` only increments `current->trace_overrun` and returns `-EBUSY` (never `ftrace_graph_stop()` or `WARN`). [F147, F310]
- Local `filter_hash`/`notrace_hash` pointers passed to `add_first_hash()`, `add_next_hash()`, or `rebuild_hashes()` must be initialized to `EMPTY_HASH`, and out-parameter NULL checks must dereference the pointer (`!*filter_hash`, `!*notrace_hash`, `!*orig_subhash`). [F188, F189]
- `FTRACE_WARN_ON*()` calls `ftrace_kill()` and must never be used for recoverable user/registration errors. If `ftrace_disabled` is set during `ftrace_startup()`, only call `__unregister_ftrace_function(ops)` and return `-ENODEV` without freeing trampolines or rolling back record flags. [F308, F309]

## External Contracts
- `add_rec_by_index()` must decrement 1-based user indices and check `< 0`. In `t_next()`, save `l = *pos` before `(*pos)++` and pass `&l` to `t_mod_start()`. `ftrace_avail*_open()`, `__ftrace_graph_open()`, and `tracing_check_open_get_tr()` must check `security_locked_down(LOCKDOWN_TRACEFS)` (omitted for `enabled_functions`/`touched_functions`). `ftrace_regex_release()` and `ftrace_graph_release()` must flush `trace_parser_loaded(parser)` before moving the staged hash. When `is_permanent_ops_registered()` is true, `ftrace_enable_sysctl()` must refuse disabling with `-EBUSY`, and `__register_ftrace_function()` must reject `FTRACE_OPS_FL_PERMANENT` when `!ftrace_enabled`. [F235, F237, F304, F305, F307]

## Known Pitfalls
- `ftrace_ops_set_global_filter(ops)` is a no-op if `FTRACE_OPS_FL_INITIALIZED` is set, so call it before `ftrace_ops_init()` or registration. `break` inside `do_for_each_ftrace_rec()` only exits the inner page loop; use `goto` or `return`. `ftrace_hash_key()` must return `0` when `hash->size_bits == 0` before `hash_long()`. In `ftrace_free_mem()`, `memmove()` and `goto again` after a `bsearch()` hit on a non-empty page, or rewind `pg = container_of(last_pg, struct ftrace_page, next)` when unlinking an empty page; in `ftrace_release_mod()`, guard `ftrace_pages = next_to_ftrace_page(last_pg)` with `pg != ftrace_pages_start`. [F193, F238, F246, F253, F267]
