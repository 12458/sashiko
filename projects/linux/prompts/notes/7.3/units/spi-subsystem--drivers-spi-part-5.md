# SPI SUBSYSTEM — drivers/spi (part 5)

SPI, QSPI, and OSPI host drivers for STM32, Tegra114/20, TI QSPI, Allwinner sun4i/sun6i, Spreadtrum SPI/ADI, Socionext F-OSPI, Topcliff PCH, UniPhier, ST SSC4, Xilinx, NetLogic XLP, and XCOMM, plus `spi-tle62x0.c` and `spi-test.h`.

## Architecture & Data Flow
- In `spi-stm32-ospi.c` and `spi-stm32-qspi.c`: `stm32_ospi_setup()`/`stm32_qspi_setup()` must cache `OSPI_CR`/`QSPI_CR` and `OSPI_DCR1`/`QSPI_DCR` in `cr_reg`/`dcr_reg` for resume; `dirmap_read` must select `CR_FMODE_MM`/`CCR_FMODE_MM` only when `op.addr.val + op.data.nbytes + 1 < mm_size && op.addr.buswidth`; in `stm32_ospi_send()`/`stm32_qspi_send()`, MM reads must jump to `abort` after `stm32_ospi_xfer()`/`stm32_qspi_tx()` even when `err == 0`, skipping `wait_cmd`; `stm32_qspi_setup()` must group `mode = spi->mode & (SPI_TX_OCTAL | SPI_RX_OCTAL)` with `gpiod_count(qspi->dev, "cs") == -ENOENT` and set `CR_DFM` when `mode != 0`; and `stm32_qspi_get_mode()` must clamp `buswidth >= 4` to `CCR_BUSWIDTH_4`. [F229, F247, F258, F262, F308]
- In `spi-tegra114.c` and `spi-tegra20-slink.c`: `tegra_spi_setup()`, `tegra_spi_set_hw_cs_timing()`, and `tegra_slink_setup()` must modify only the target CS's bits in `def_command1_reg`, `spi_cs_timing1`, `spi_cs_timing2`, and `def_command_reg`; resetting `SPI_COMMAND2` to `def_command2_reg` in `tegra_spi_resume()` or asserting `tspi->rst` on timeout in `tegra_spi_transfer_one_message()` must set `tspi->last_used_cs = host->num_chipselect + 1`; `SPI_INTR_MASK` in `tegra_spi_setup()` requires `tspi->soc_data->has_intr_mask_reg`; `SPI_FIFO_EMPTY`/`SLINK_FIFO_EMPTY` must be tested with `(status & MASK) != MASK`; and `tegra_spi`/`slink`/`sflash_runtime_suspend()` must perform a dummy register read to flush PPSB writes before `clk_disable_unprepare()`. [F227, F228, F260, F303, F312]
- In `spi-tegra114.c` and `spi-tegra20-slink.c`: packed mode (`tspi->is_packed`) in `tegra_spi`/`slink_fill_tx_fifo_from_client_txbuf()` and `tegra_spi`/`slink_start_dma_based_transfer()` must round byte counts up to 32-bit words via `DIV_ROUND_UP(..., 4)`; unpacked mode (`!tspi->is_packed`) uses 4 bytes/word in `tx_dma_buf`/`rx_dma_buf`, so `curr_dma_words` must be capped at `max_buf_size / 4` and DMA length set to `curr_dma_words * 4`; in `spi-tegra114.c`, unpacked helpers must clamp byte counts to `t->len - tspi->cur_pos` before copying and advancing `cur_tx_pos`/`cur_rx_pos`, and `handle_cpu_based_xfer()`/`handle_dma_based_xfer()` must update `tspi->cur_pos` only after RX readout (`tegra_spi_read_rx_fifo_to_client_rxbuf()`/`tegra_spi_copy_spi_rxbuf_to_client_rxbuf()`). [F252, F268, F282, F290]
- In `spi-ti-qspi.c`: `ti_qspi_setup_clk()` must update `qspi->ctx_reg.clkctrl` with `QSPI_SPI_CLOCK_CNTRL_REG` for `ti_qspi_restore_ctx()`; in `qspi_read_msg()` when `wlen == 1` and `count < QSPI_WLEN_MAX_BYTES`, `rxlen` must be capped at `min(count, 4)` so `rx_wlen = rxlen << 3` keeps shifts `rx >> (rx_wlen - 8/16/24)` in `0..24`; and jiffies loops in `qspi_is_busy()`, `ti_qspi_poll_wc()`, and `tegra_spi_flush_fifos()` must use `time_after()`. [F226, F279, F287]
- In `spi-sn-f-ospi.c`: `f_ospi_adjust_op_size()` must clamp `op->data.nbytes` to `OSPI_DAT_SIZE_MAX` (2048); when `f_ospi_config_indir_protocol()` writes `0` (without `OSPI_DAT_SIZE_EN`) to `OSPI_DAT_SIZE_INDIR`, `f_ospi_indir_read()`/`write()` must call `f_ospi_indir_stop_xfer()` and `f_ospi_indir_read()` must reset `OSPI_SWRST_INDIR_READ_FIFO`; and writing `OSPI_CLK_CTL`, `OSPI_PROT_CTL_INDIR`, or `OSPI_ACC_MODE` in `f_ospi_init()`/`f_ospi_indir_prepare_op()` must be bracketed by `f_ospi_prepare_config()` (polling `OSPI_STAT` for `(val & (stat0 | stat1)) == stat1`) and `f_ospi_unprepare_config()`. [F238, F251, F259, F311]
- In `spi-sprd.c` and `spi-sprd-adi.c`: `sprd_spi_set_speed()`/`sprd_spi_init_hw()` must update `ss->hw_speed_hz` and `ss->word_delay` with `SPRD_SPI_CLKD`/`SPRD_SPI_CTL5` (clamping `word_delay` to `14..130` before `DIV_ROUND_UP(word_delay - 10, 4)`); for `SPRD_SPI_RX_MODE`, `sprd_spi_setup_transfer()` must set `ss->write_bufs = sprd_spi_write_only_receive`; when `t->len > ss->dma.fragmens_len` in `sprd_spi_dma_txrx_bufs()`, `ss->dma.rx_len` must be rounded down to a multiple of `fragmens_len` with the remainder read in `sprd_spi_handle_irq()`; `sprd_adi_read()`/`write()` must validate `reg` via `sprd_adi_check_addr(sadi, reg)` before accessing `REG_ADI_RD_CMD` or `slave_vbase + reg`; and `sprd_adi_hw_init()` must skip `chn_id < 2` before `REG_ADI_CHN_ADDR(chn_id)` and bound `chn_id < ADI_HW_CHNS` (50). [F231, F232, F244, F245, F255, F284]
- In `spi-sun4i.c` and `spi-sun6i.c`: `sun4i`/`sun6i_spi_transfer_one()` must set `SUN4I_CTL_DHB`/`SUN6I_TFR_CTL_DHB` iff `sspi->rx_buf == NULL`; `sun4i_spi_transfer_one()` must reject TX `tfr->len >= SUN4I_MAX_XFER_SIZE` (and RX `> SUN4I_MAX_XFER_SIZE`) and pre-fill at most `SUN4I_FIFO_DEPTH - 1` bytes; `sun4i_spi_set_cs()` must set `SUN4I_CTL_CS_ACTIVE_LOW` when `!(spi->mode & SPI_CS_HIGH)`; and `sun6i_spi_transfer_one()` may write `SUN6I_CLK_CTL_REG` only when `sspi->cfg->has_clk_ctl` is true, else setting `sspi->mclk` rate and `SUN6I_TFR_CTL_SDM`/`SDC`. [F256, F304, F306, F310]
- In `spi-st-ssc4.c`, `spi_st_transfer_one()` must save/restore `SSC_CTL` (`ctl`) around 16-bit (`ctl | 0xf`) transfers, and `spi_st_pm` must use `pm_ptr(&spi_st_pm)`. In `spi-xilinx.c`, `xilinx_spi_probe()` must probe endianness via `XSPI_CR_LOOP` at `XSPI_CR_OFFSET` before resetting `XIPIF_V123B_RESETR_OFFSET`, and `xilinx_spi_setup_transfer()`/`chipselect()` must only toggle `BIT(cs)` against `xspi->cs_inactive` in `XSPI_SSR_OFFSET`. [F235, F236, F298, F316]
- In `spi-xlp.c`, `xlp_spi_transfer_one()` must set `xspi->cs = spi_get_chipselect(spi, 0)`, and `xlp_spi_txrx_bufs()` must split into `<= XLP_SPI_XFER_SIZE` (28) byte chunks (`cmd_cont = 1` on intermediate chunks) with `xlp_spi_fill_txfifo()`/`read_rxfifo()` packing `nbytes = min(len, 4)` in reverse order (`nbytes - 1`..`0`). In `spi-xcomm.c`, `spi_xcomm_setup_transfer()` must reject `t->len > 62` (`u8 buf[63]`). In `spi-tle62x0.c`, buffers and `gpio_attrs[16]` require `st->nr_gpio <= 16`. In `spi-test.h`, `iterate_len` must end with `-1` within `SPI_TEST_MAX_ITERATE`. [F237, F239, F254, F294, F297]

## Synchronization
- In `spi-stm32-ospi.c` and `spi-stm32-qspi.c`, entry points must call `pm_runtime_resume_and_get()` before locking `ospi->lock`/`qspi->lock` and `pm_runtime_put_autosuspend()` after unlocking; `lock` must be held across setting `fmode` (`status_timeout`, `PSMKR`, `PSMAR`) and calling `stm32_ospi_send()`/`stm32_qspi_send()`, and across CS GPIO assertion/deassertion in `stm32_ospi`/`qspi_transfer_one_message()`, where any loop error must `goto end_of_transfer`. [F173, F185, F186, F320]
- In `spi-ti-qspi.c`, `qspi->list_lock` must be held across checking/updating `mmap_enabled` and `current_cs`, configuring clocks/MMIO registers, and running transfers in `ti_qspi_exec_mem_op()` and `ti_qspi_start_transfer_one()`. In `spi-sn-f-ospi.c`, `ospi->mlock` must be held across the entire indirect read/write sequence in `f_ospi_indir_read()`/`write()`. [F190, F192]
- In `spi-tegra114.c` and `spi-tegra20-slink.c`, `handle_dma_based_xfer()` must await `tx_dma_complete`/`rx_dma_complete` and call `dmaengine_terminate_all()` before `spin_lock_irqsave(&tspi->lock, flags)`. In `spi-uniphier.c`, `uniphier_spi_transfer_one_dma()` must set `SSI_DMA_RX_BUSY`/`TX_BUSY` in `priv->dma_busy` before submitting DMA, and `uniphier_spi_dma_rxcb()`/`txcb()` must use `atomic_fetch_andnot()` to call `spi_finalize_current_transfer()` only when the other bit is clear. [F196, F318]
- In `spi-sun4i.c` and `spi-sun6i.c`, `sun4i`/`sun6i_spi_handler()` must check `SUN4I`/`SUN6I_INT_CTL_TC` before FIFO threshold bits and clear `RF_F34`/`RF_RDY` or `TF_E34`/`TF_ERQ` in `INT_STA_REG` only after draining/refilling the FIFO; in `sun6i_spi_transfer_one()`, RX DMA (`rx_len > 0`) must wait on `sspi->dma_rx_done` after `sspi->done`, calling `dmaengine_terminate_sync()` on `dma_rx` and `dma_tx` on timeout. In `spi-sprd.c`, `sprd_spi_handle_irq()` on `SPRD_SPI_MASK_TX_END` must complete `xfer_completion` only when `!(ss->trans_mode & SPRD_SPI_RX_MODE)`. In `spi-sprd-adi.c`, `sprd_adi_read()`/`write()` must bracket register/`slave_vbase` accesses with `hwspin_lock_timeout_irqsave()`/`unlock_irqrestore()` when `sadi->hwlock` is non-NULL. In `spi_st_irq()` (`spi-st-ssc4.c`), when `words_remaining == 0`, clear `SSC_IEN` and flush via `readl(spi_st->base + SSC_IEN)` before `complete(&spi_st->done)`. [F205, F264, F272, F319, F327]

## Object Lifetimes
- In `stm32_ospi_tx_dma()` and `stm32_qspi_tx_dma()`, once `spi_controller_dma_map_mem_op_data()` succeeds, all exit paths must call `spi_controller_dma_unmap_mem_op_data()`, calling `dmaengine_terminate_all()` first on timeout after `dma_async_issue_pending()`. In `ti_qspi_dma_xfer()`, a timeout on `qspi->transfer_complete` must call `dmaengine_terminate_sync(chan)` before returning. [F172, F191]
- In `stm32_ospi_remove()` and `stm32_qspi_remove()`, `spi_unregister_controller()` must run while runtime-resumed and before disabling `OSPI_CR`/`QSPI_CR`, releasing DMA channels, and `mutex_destroy(&lock)`. In `spi-stm32-ospi.c`, `ospi->rstc` must be obtained via `devm_reset_control_array_get_exclusive_released()` and bracketed with `reset_control_acquire()` in probe/resume and `reset_control_release()` in remove/suspend. [F189, F300]
- In `tle62x0_probe()`, if `device_create_file()` fails for `gpio_attrs[ptr]`, `err_gpios` must remove `gpio_attrs[0..ptr-1]`, remove `dev_attr_status_show`, and `kfree(st)`; `tle62x0_remove()` must remove all `gpio_attrs[0..st->nr_gpio-1]` and `dev_attr_status_show` before `kfree(st)`. In `tegra_spi_setup()`, errors after `tegra_spi_parse_cdata_dt()` must call `tegra_spi_cleanup(spi)`. [F174, F179, F195]
- In `spi-topcliff-pch.c`, `pch_spi_request_dma()`/`release_dma()` must balance `pci_get_slot()` with `pci_dev_put()`, and if RX DMA request fails, release/NULL `dma->chan_tx` and set `data->use_dma = 0`; in `pch_spi_pd_remove()`, set `data->status = STATUS_EXITING` and call `pch_spi_free_resources()` (`flush_work(&data->work)`) before disabling IRQs, `free_irq()`, and unmapping `io_remap_addr`. In `sprd_spi_dma_request()`/`runtime_resume()`, a `SPRD_SPI_TX` failure must release `SPRD_SPI_RX`, and a DMA request failure in resume must call `clk_disable_unprepare(ss->clk)`. In `sun6i_spi_runtime_resume()`/`suspend()`, manage `hclk`, `mclk`, and `rstc` in strict LIFO order (`err2` then `err` on failure). [F175, F181, F184, F201]

## API Contracts
- In `tegra_spi_set_hw_cs_timing()`, check `delay->value != 0` before requiring `delay->unit == SPI_DELAY_UNIT_SCK`; callers of `tegra_spi`/`slink_calculate_curr_xfer_param()` must ensure `t->len > tspi->cur_pos` (skipping `xfer->len == 0` in `tegra_spi_transfer_one_message()`); and CPU accesses to `tx_dma_buf`/`rx_dma_buf` must be bracketed by `dma_sync_single_for_cpu()` and `dma_sync_single_for_device()`. [F208, F281, F325]
- In `spi-ti-qspi.c`, `ti_qspi_adjust_op_size()` must clamp `op->data.nbytes` to `qspi->mmap_size - op->addr.val` below `mmap_size` (and `QSPI_FRAME - (1 + op->addr.nbytes + op->dummy.nbytes)` above); `ti_qspi_exec_mem_op()` must return `-EOPNOTSUPP` if the op is not a non-empty `SPI_MEM_DATA_IN` read with 1..4-byte address or if `from + op->data.nbytes > qspi->mmap_size`; and `qspi->rx_chan` may use `spi_controller_dma_map_mem_op_data()` only if `virt_addr_valid(op->data.buf.in)`, else `ti_qspi_dma_bounce_buffer()`. [F249, F329, F331]
- In `spi-stm32-ospi.c` and `spi-stm32-qspi.c`, when `stm32_ospi`/`qspi_tx_dma()` fails, `stm32_ospi_xfer()`/`stm32_qspi_tx()` must fall back to `stm32_ospi_poll()`/`stm32_qspi_tx_poll()`; in `stm32_ospi`/`qspi_transfer_one_message()`, a `dummy_data` transfer is merged into the next transfer's `op.dummy` and must set `ret = -EINVAL` and `goto end_of_transfer` if last in `msg->transfers`. In `spi-sprd.c`, `ss->write_bufs`/`read_bufs` take `len` in words, advance `tx_buf`/`rx_buf` by `len * bytes_per_word`, and return bytes transferred. In `sprd_adi_transfer_one()`, reads pass a relative offset (`< slave_addr_size`) in `*(u32 *)t->rx_buf` and writes pass `u32` `{reg, val}` in `t->tx_buf`. In `f_ospi_supports_op()`, return `spi_mem_default_supports_op(mem, op)`. In `xilinx_spi_probe()`, setting `bitbang.txrx_bufs` requires setting `bitbang.setup_transfer = xilinx_spi_setup_transfer`. [F210, F221, F291, F328, F332, F334, F335]

## Error Handling
- In `pch_spi_probe()` and `tle62x0_probe()`, loop counter `i`/`ptr` must be a signed `int` for `while (--i >= 0)` / `while (--ptr >= 0)`; in `pch_spi_probe()`, if `platform_device_add_data()`/`add()` fails, call `platform_device_put(pd_dev)` before `err_platform_device` unregisters `pd_save[0..i-1]`. In `tegra_spi`/`slink_start_dma_based_transfer()`, if RX DMA fails when `cur_direction & DATA_DIR_TX`, call `dmaengine_terminate_all(tspi->tx_dma_chan)`. In `sun6i_spi_prepare_dma()` and `uniphier_spi_transfer_one_dma()`, initialize `rxdesc = NULL`, and if TX `dmaengine_prep_slave_sg()` fails when `rxdesc` is non-NULL, call `dmaengine_terminate_sync(host->dma_rx)`. [F176, F178, F218, F223]
- Check `devm_ioremap_resource()`/`devm_platform_get_and_ioremap_resource()` with `IS_ERR()` in `stm32_ospi_get_resources()`, `stm32_qspi_probe()`, and `ti_qspi_probe()`. In `xilinx_spi_probe()`, `platform_get_irq()` returning `-ENXIO` is non-fatal (polling mode), so signed `int xspi->irq` must be checked for `>= 0` in `xilinx_spi_txrx_bufs()`. `uniphier_spi_setup_transfer()` must reset `priv->error = 0`, and `spi_xcomm_transfer_one()` must reset `status = 0` after each transfer. [F206, F211, F215, F217]

## External Contracts
- In `spi-tle62x0.c`, sysfs `dev_attr_gpio1`..`16` use 1-based names while `to_gpio_num()` returns their 0-based index (`0..15`) in `gpio_attrs[]` to shift `st->gpio_state`. [F242]

## Known Pitfalls
- In `stm32_ospi_send()`, `stm32_qspi_send()`, and `f_ospi_get_dummy_cycle()`, evaluate `op->dummy.nbytes * 8 / op->dummy.buswidth` only when `nbytes` (and `buswidth`) is non-zero; `OSPI_DLR`/`QSPI_DLR` and `CCR_ADSIZE_MASK` encode `nbytes - 1`, requiring non-zero checks on `op->data.nbytes` and `op->addr.nbytes`; in `spi-stm32-ospi.c`, index `spi->chip_select[]` and `cs_gpiod[]` by `ffs(spi->cs_index_mask) - 1` (`cs < STM32_OSPI_MAX_NORCHIP`); and in `spi-stm32-ospi.c`, `spi-stm32-qspi.c`, `spi-ti-qspi.c`, and `spi-sn-f-ospi.c`, `platform_set_drvdata()` stores the private struct (`stm32_ospi`, `stm32_qspi`, `ti_qspi`, `f_ospi`) rather than `struct spi_controller *`. [F214, F246, F248, F289]
- In `spi-topcliff-pch.c`, `pch_spi_process_messages()` must save/restore `cur_trans->len` (`save_total_len`) and `cur_trans->rx_buf` (`save_rx_buf`) around DMA; `do { ... } while (data->cur_trans != NULL)` relies on `pch_spi_nomore_transfer()` setting `data->cur_trans = NULL` at the end of `current_msg->transfers`; and `pch_spi_set_tx()` must allocate `pkt_tx_buff`/`pkt_rx_buff` (`u16 *`) with `cur_trans->len * sizeof(*data->pkt_tx_buff)`. In `spi-tegra114.c`, non-empty transfers with `bits_per_word == 32` must set `tspi->is_packed = true` to avoid `((u32)1 << 32)` in unpacked RX helpers. In `spi_st_setup()`, compute `spi_st->baud = spi_st_clk / (2 * sscbrg)` after validating `sscbrg` in `0x07..BIT(16)` and before wrapping `BIT(16)` to `0x0`. In `xlp_spi_txrx_bufs()`, advance `tx_buf`/`rx_buf` by `sz` only when non-NULL. [F234, F266, F276, F278, F292, F295]

## Other
- In `spi-ti-qspi.c`, 128-bit (`QSPI_WLEN_MAX_BYTES`) bursts during `wlen == 1` transfers in `qspi_write_msg()`/`qspi_read_msg()` must byte-swap 32-bit words (`cpu_to_be32()`/`be32_to_cpu()`) and access `QSPI_SPI_DATA_REG_3` down to `QSPI_SPI_DATA_REG`. In `spi-uniphier.c`, `uniphier_spi_send()`/`recv()` must clamp per-word bytes to `min(bytes_per_word(priv->bits_per_word), priv->tx_bytes)` (or `rx_bytes`) and use `get`/`put_unaligned_le16()`/`le32()`. In `spi_xcomm_sync_config()`, write 16-bit BE fields at `&buf[1]` and `&buf[3]` via `put_unaligned_be16()`. [F241, F250, F253]
