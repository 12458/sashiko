# BTRFS FILE SYSTEM — fs/btrfs (part 3)

Handles Btrfs disk I/O and mount/unmount lifecycle (`open_ctree`/`close_ctree`, superblock and tree-block I/O/validation, `btree_aops`), online device replacement (`dev-replace`), dir-item/xattr B-tree helpers, direct I/O via iomap, async discard/TRIM, NFS export ops, and `extent_io_tree` range state tracking.

## Architecture & Data Flow

- In `struct extent_io_tree`, the union holds `tree->inode` only when `tree->owner == IO_TREE_INODE_IO` and `tree->fs_info` for all other `IO_TREE_*` owners; check `tree->owner` or use `btrfs_extent_io_tree_to_fs_info()` / `btrfs_extent_io_tree_to_inode()`. [F220]
- `struct extent_state` nodes with `EXTENT_LOCK_BITS | EXTENT_BOUNDARY` must never be merged in `merge_state()` or `insert_state()`, nor passed to `btrfs_convert_extent_bit()`. `ENUM_BIT(EXTENT_NOWAIT)` must remain the last extent state bit enum entry because `set_gfp_mask_from_bits()` clears it via `*bits &= EXTENT_NOWAIT - 1`. [F208, F221]
- In `set_state_bits()` and `clear_state_bit()`, pass `EXTENT_CTLBITS` in `bits` to `btrfs_set_delalloc_extent()` / `btrfs_clear_delalloc_extent()` but mask them out (`bits & ~EXTENT_CTLBITS`) before updating `state->state` or `changeset`. `btrfs_clear_extent_bit_changeset()` must also OR `EXTENT_NORESERVE` into `bits` whenever clearing `EXTENT_DELALLOC`. [F242, F243]
- In `struct btrfs_dio_private`, `struct btrfs_bio bbio` must remain the final member because `btrfs_init_dio()` initializes `btrfs_dio_bioset` with `front_pad = offsetof(struct btrfs_dio_private, bbio.bio)` and `BIOSET_NEED_BVECS`. [F229]
- Because `insert_with_overflow()` packs colliding dir/xattr entries into one B-tree item, `btrfs_delete_one_dir_name()` must check `sub_item_len == item_len` and, when `sub_item_len < item_len`, shift trailing entries with `memmove_extent_buffer()` and call `btrfs_truncate_item()` rather than `btrfs_del_item()`. [F258]
- `btrfs_init_dev_replace()` must verify `btrfs_item_size(eb, slot) == sizeof(struct btrfs_dev_replace_item)` before reading fields, and `btrfs_run_dev_replace()` must delete and recreate any existing item smaller than `sizeof(struct btrfs_dev_replace_item)` before writing. `validate_sys_chunk_array()` must verify `sys_array_size <= BTRFS_SYSTEM_CHUNK_ARRAY_SIZE`, `cur + sizeof(*disk_key) <= sys_array_size` before reading `disk_key` and `btrfs_stack_chunk_num_stripes(chunk)`, and `cur + btrfs_chunk_item_size(num_stripes) <= sys_array_size` before `btrfs_check_chunk_valid()`. [F264, F273]

## Synchronization

- In `btrfs_dio_iomap_begin()`, direct-write `btrfs_check_data_free_space()` must run before `lock_extent_direct()`. `lock_extent_direct()` must lock `EXTENT_DIO_LOCKED` before `EXTENT_LOCKED` on `BTRFS_I(inode)->io_tree`, unlock `EXTENT_LOCKED` (`btrfs_unlock_extent()`) before waiting on an ordered extent or retrying on conflict, and unlock `EXTENT_DIO_LOCKED` (`btrfs_unlock_dio_extent()`) on error. `btrfs_dio_iomap_begin()` always clears `EXTENT_LOCKED` before returning `0`, and clears `EXTENT_DIO_LOCKED` on `[lockstart, lockend]` for writes; for reads, `EXTENT_DIO_LOCKED` on `[start, start + len - 1]` transfers to `btrfs_dio_end_io()` / `btrfs_dio_iomap_end()`, while any tail `[start + len, lockend]` must be unlocked in `btrfs_dio_iomap_begin()`. [F176, F179, F197]
- When `btrfs_direct_write()` takes `btrfs_inode_lock()` with `BTRFS_ILOCK_SHARED`, recheck under lock that `IS_NOSEC(inode)` and (after `generic_write_checks()`) `pos + iov_iter_count(from) <= i_size_read(inode)`, relocking exclusively if either fails. In `btrfs_direct_write()` and `btrfs_direct_read()`, disable `iov_iter` page faults (`from->nofault = true`; `pagefault_disable()` and `to->nofault = true` for reads) during `btrfs_dio_write()` / `btrfs_dio_read()`, faulting pages in outside the iomap call before retrying. [F199, F200]
- When `set_extent_bit()` fails with `-EEXIST` on `EXTENT_LOCK_BITS` at `failed_start > start`, `btrfs_try_lock_extent_bits()` and `btrfs_lock_extent_bits()` must clear `[start, failed_start - 1]` via `btrfs_clear_extent_bit()` before returning `0` or sleeping in `wait_extent_bit()`. [F191]
- In `fs/btrfs/dev-replace.c`, lock order is `dev_replace->lock_finishing_cancel_unmount` -> `fs_devices->device_list_mutex` -> `fs_info->chunk_mutex` -> `dev_replace->rwsem`. After committing transactions until `src_device->post_commit_list` is empty, `btrfs_dev_replace_finishing()` must hold `device_list_mutex` then `chunk_mutex`, copy `CHUNK_ALLOCATED` ranges from `src_device->alloc_state` to `tgt_device->alloc_state` (`btrfs_set_target_alloc_state()`), and call `btrfs_dev_replace_update_device_in_mapping_tree()`, which must re-lookup `node` from `next_start` via `btrfs_find_chunk_map_nolock()` whenever `cond_resched_rwlock_write(&fs_info->mapping_tree_lock)` drops the lock. [F203, F250, F251, F313]
- In `btrfs_discard_cleanup()`, `btrfs_discard_stop()` (clearing `BTRFS_FS_DISCARD_RUNNING`) and `cancel_delayed_work_sync(&fs_info->discard_ctl.work)` must precede `btrfs_discard_purge_list(&fs_info->discard_ctl)`. `btrfs_discard_purge_list()` must drop `discard_ctl->lock` before calling `btrfs_mark_bg_unused()` on purged block groups with `block_group->used == 0` (and `btrfs_discard_resume()` must punt `fs_info->unused_bgs` via `btrfs_discard_punt_unused_bgs_list()`). `btrfs_discard_update_discardable()` requires `block_group->free_space_ctl->tree_lock`. [F206, F207, F249]
- In `open_ctree()`, do not set `BTRFS_FS_OPEN` until `btrfs_start_pre_rw_mount()`, `btrfs_discard_resume()`, and any `btrfs_check_uuid_tree()` succeed, keeping `cleaner_kthread` asleep. In `cleaner_kthread()`, unlock `fs_info->cleaner_mutex` before `btrfs_delete_unused_bgs(fs_info)`. In `btrfs_destroy_pinned_extent()`, hold `fs_info->unused_bg_unpin_mutex` across `btrfs_find_first_extent_bit()`, `btrfs_clear_extent_dirty()`, and `btrfs_error_unpin_extent_range()`. [F210, F211, F215]
- `btrfs_mark_buffer_dirty()` requires `btrfs_assert_tree_write_locked(buf)` and `trans->transid == fs_info->generation`. `btrfs_init_fs_info()` must init `fs_info->buffer_tree` with `XA_FLAGS_LOCK_IRQ` and `buffer_xa_class`. `__btrfs_btree_balance_dirty()` must return immediately if `current->flags & PF_MEMALLOC`. [F216, F318, F326]

## Object Lifetimes

- In `btrfs_get_blocks_direct_write()`, if metadata reservation fails in `can_nocow` or when entering `!can_nocow` COW, call `btrfs_free_extent_map(*map)` and set `*map = NULL` because `btrfs_dio_iomap_begin()` does not free `em` on error. When `btrfs_check_data_free_space()` reserves `data_alloc_len` in `btrfs_dio_iomap_begin()`, error exits must call `btrfs_free_reserved_data_space()` and `extent_changeset_free(dio_data->data_reserved)`; on success, free all `data_alloc_len` if `dio_data->nocow_done` or `data_alloc_len - len` if `len < data_alloc_len` (and `btrfs_get_blocks_direct_write()` must release `prev_len - len` of metadata), deferring `extent_changeset_free(dio_data->data_reserved)` to `btrfs_dio_iomap_end()`. [F175, F177, F254]
- In `btrfs_get_root_ref()` (and `btrfs_get_new_fs_root()`), if `btrfs_lookup_fs_root()` finds a cached root, free any non-zero `*anon_dev` via `free_anon_bdev()` and zero it; if a newly read root fails after `btrfs_init_fs_root()` attaches `*anon_dev`, reset `root->anon_dev = 0` before `btrfs_put_root(root)`. [F182]
- `btrfs_insert_fs_root()` calls `btrfs_grab_root()` and sets `BTRFS_ROOT_IN_RADIX` under `fs_info->fs_roots_radix_lock`. Lookups in `fs_info->fs_roots_radix` (`btrfs_lookup_fs_root()`, `btrfs_cleanup_fs_roots()`, `btrfs_drop_all_logs()`) must call `btrfs_grab_root()` under `fs_roots_radix_lock`, and `btrfs_drop_and_free_fs_root()` must only call `btrfs_put_root(root)` when `test_and_clear_bit(BTRFS_ROOT_IN_RADIX, &root->state)` succeeds under `fs_roots_radix_lock`. [F183, F320]
- In `close_ctree()`, `free_root_pointers()` and `btrfs_free_fs_roots()` must precede `btrfs_free_block_groups()` so leftover tree-log extent buffers from I/O errors are freed before block group accounting teardown. [F186]
- A `btrfs_block_group` holds one ref while on `discard_ctl->discard_list`, plus a working ref from `peek_discard_list()` in `discard_ctl->block_group` that `btrfs_discard_workfn()` must drop and clear to `NULL` under `discard_ctl->lock` on every exit. `remove_from_discard_list()` must clear `discard_ctl->block_group = NULL` when `block_group == discard_ctl->block_group` and return `true` so `btrfs_discard_cancel_work()` cancels `discard_ctl->work` synchronously. `btrfs_discard_punt_unused_bgs_list()` must still call `btrfs_put_block_group(block_group)` for the `unused_bgs` ref after `btrfs_discard_queue_work()`. [F187, F188, F248]
- In `btrfs_clear_extent_bit_changeset()`, `set_extent_bit()`, and `btrfs_convert_extent_bit()`, set `prealloc = NULL` when consumed by `split_state()` or `insert_state_fast()`, or when `insert_state()` returns `inserted_state == prealloc`, so `out:` frees `prealloc` only when unused. [F190]
- In `btrfs_dev_replace_finishing()`, clear `dev_replace->tgtdev` and `dev_replace->srcdev` to `NULL` under `dev_replace->rwsem` before `btrfs_rm_dev_replace_blocked(fs_info)`, and run `btrfs_destroy_dev_replace_tgtdev()` or `btrfs_rm_dev_replace_remove_srcdev()` before `btrfs_rm_dev_replace_unblocked()`. [F192]
- `btrfs_get_dentry()` must call `btrfs_put_root(root)` right after `btrfs_iget(objectid, root)`, and if non-zero `generation != inode->vfs_inode.i_generation`, call `iput(&inode->vfs_inode)` before returning `ERR_PTR(-ESTALE)`. `write_dev_supers()` gets each superblock folio with `FGP_LOCK | FGP_ACCESSED | FGP_CREAT` and transfers lock and ref to the bio, whose `btrfs_end_super_write()` callback must call `folio_unlock()`, `folio_put()`, and `bio_put()`. [F193, F194]

## API Contracts

- `btrfs_global_root()`, `btrfs_extent_root()`, and `btrfs_csum_root()` return borrowed `struct btrfs_root *` (or `NULL`); `btrfs_get_global_root()` and `btrfs_lookup_fs_root()` return refcounted roots (or `NULL`); and `btrfs_get_fs_root()`, `btrfs_get_new_fs_root()`, `btrfs_get_fs_root_commit_root()`, `btrfs_read_tree_root()`, and `btrfs_create_tree()` return refcounted roots or `ERR_PTR`. Release refcounted roots with `btrfs_put_root()`. [F184, F230]
- `btrfs_lookup_dir_item()`, `btrfs_lookup_dir_index_item()`, and `btrfs_lookup_xattr()` return `NULL` when not found and `ERR_PTR` on error, whereas `btrfs_search_dir_index_item()` returns `ERR_PTR(-ENOENT)` when not found. In the three `btrfs_lookup_*` helpers, `@mod` is `0` for read-only (`@trans` may be `NULL`), `1` for modification (`ins_len = 0, cow = 1`), and `-1` for deletion (`ins_len = -1, cow = 1`). `btrfs_insert_xattr_item()` rejects `name_len + data_len > BTRFS_MAX_XATTR_SIZE(root->fs_info)` with `-ENOSPC`, and `btrfs_check_dir_item_collision()` rejects collisions exceeding `BTRFS_LEAF_DATA_SIZE(root->fs_info)` with `-EOVERFLOW`. [F222, F223, F266]
- On buffered fallback in `btrfs_dio_iomap_begin()`, return `-EAGAIN` if `flags & IOMAP_NOWAIT` and `-ENOTBLK` otherwise. In `btrfs_direct_write()`, if `IOCB_NOWAIT` reaches `buffered:`, return `-EAGAIN`; on buffered fallback (including `!BTRFS_INODE_NODATASUM` or `fs_info->sectorsize > PAGE_SIZE` in `check_direct_IO()`), flush, wait, and invalidate mapping pages over `[pos, endbyte]`. In `btrfs_direct_read()`, if `fsverity_active(inode)` or `check_direct_read() < 0`, return `0` for buffered fallback. `btrfs_dio_end_io()` must restore `bbio->bio.bi_private = bbio->private` (saved by `btrfs_dio_submit_io()`) before `iomap_dio_bio_end_io(bio)`. [F227, F309, F327, F329, F334]
- `extent_io_tree` range ops take inclusive `[start, end]`, whereas `btrfs_lookup_ordered_range()` and `btrfs_finish_ordered_extent()` take `(start, len)`. Callers of `btrfs_set_extent_bit()` or `btrfs_clear_extent_bit_changeset()` under a non-sleeping lock must pass `EXTENT_NOWAIT` so `set_gfp_mask_from_bits()` selects `GFP_NOWAIT` and skips `cond_resched()`. `btrfs_get_range_bits()` requires `cached_state && *cached_state == NULL`. `btrfs_find_first_extent_bit()` matches `state->state & bits`, whereas `btrfs_count_range_bits()` requires `(state->state & bits) == bits`. `btrfs_find_first_clear_extent_bit()` can return `*end_ret = U64_MAX` and `*start_ret < start`, so callers must clamp both. [F235, F236, F287, F293, F311]
- `btrfs_dev_replace_by_ioctl()` stores `btrfs_dev_replace_start()`'s return in `args->result` and translates `BTRFS_IOCTL_DEV_REPLACE_RESULT_SCRUB_INPROGRESS` and `BTRFS_IOCTL_DEV_REPLACE_RESULT_NO_ERROR` into `0`. [F234]

## Error Handling

- In `load_global_roots_objectid()`, if `read_tree_root_path()` returns `IS_ERR(root)`, set `ret = PTR_ERR(root)` unconditionally before breaking, even with `BTRFS_MOUNT_IGNOREBADROOTS`. When a fallible call assigned to `root->node` (`read_tree_block()` in `read_tree_root_path()`, `load_super_root()`, `btrfs_replay_log()`) or `fs_info->fs_root` (in `open_ctree()`) returns `IS_ERR()`, reset the field to `NULL` before cleanup. [F217, F219]
- In `btrfs_dio_iomap_begin()`, `memset(dio_data, 0, sizeof(*dio_data))` must precede any jump to `err:` or `unlock_err:`. In `btrfs_cleanup_fs_roots()`, once `btrfs_grab_root()` acquires refs on `gang[0..found-1]`, iterate across all `found` entries to call `btrfs_put_root(gang[i])`, calling `btrfs_orphan_cleanup(gang[i])` only while `!ret`. [F226, F232]

## External Contracts

- In `btrfs_get_name()`, set `name[name_len] = '\0'` after `read_extent_buffer()`. In `btrfs_dev_replace_by_ioctl()`, `btrfs_check_replace_dev_names()` must verify NUL-termination of `args->start.tgtdev_name` (and `srcdev_name` when `srcdevid == 0`) via `memchr()`, or set `args->start.srcdev_name[0] = 0` when `srcdevid != 0`. [F300, F337]

## Known Pitfalls

- In `btrfs_direct_write()` and `btrfs_direct_read()`, `iomap_dio_complete()` and `btrfs_dio_read()` return a cumulative byte count including `done_before`, so assign `written = ret` / `read = ret` rather than `+=`. On `-EFAULT` or partial-transfer retries, stop if `left = iov_iter_count()` equals `prev_left`. [F228, F283]
- In `btrfs_clear_extent_bit_changeset()`, `set_extent_bit()`, and `btrfs_convert_extent_bit()`, save `last_end = state->end` at `hit_next` before `clear_state_bit()` or `merge_state()`, and check `last_end >= end` / advance `start = last_end + 1` instead of reading `state->end`. [F279]
- When searching with `key.offset = (u64)-1` in `btrfs_get_parent()` and `btrfs_init_root_free_objectid()`, reject `ret == 0` with `-EUCLEAN` and check `path->slots[0] > 0` before decrementing `path->slots[0]`. [F262]
- In `btrfs_sb_offset()`, widen `SZ_16K` to `u64` before shifting by `BTRFS_SUPER_MIRROR_SHIFT * mirror`, and guard `mirror >= 0`. In `__btrfs_discard_schedule_work()`, widen `u32 kbps_limit` to `u64` before `* SZ_1K`, use `div64_u64()` for `bps_delay` only when `kbps_limit != 0`, and guard `now < block_group->discard_eligible_time` and `delay > elapsed` before `nsecs_to_jiffies()`. In `btrfs_insert_xattr_item()`, `btrfs_insert_dir_item()`, `btrfs_match_dir_item_name()`, and `btrfs_get_name()`, cast to `(char *)` before adding byte lengths (`name_len`, `this_len`). [F290, F291, F292, F298]
