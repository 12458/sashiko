# ARM/QUALCOMM MAILING LIST — (top level) (part 2)

This unit contains Qualcomm peripheral drivers—UART/console serial (`msm_serial`, `qcom_geni_serial`), UFS host (`ufs-qcom`), DWC3 USB glue (`dwc3-qcom`), PMIC WLED backlight (`qcom-wled`), and APCS/KPSS watchdog (`qcom-wdt`)—plus DT clock binding headers (`include/dt-bindings/clock/qcom,*`).

## Architecture & Data Flow

- In `ufs_qcom_get_bw_table()`, clamp 1-based gear/lane indices from `host->dev_req_params` to `QCOM_UFS_MAX_GEAR` (5) and `QCOM_UFS_MAX_LANE` (2) (`MODE_MIN`/`MODE_MAX` use `[0][0]`); new max bandwidths in `ufs_qcom_bw_table` must update `[MODE_MAX][0][0]`. In `ufs_qcom_pwr_change_notify()` (`POST_CHANGE`), copy `dev_req_params` to `host->dev_req_params` before `ufs_qcom_icc_update_bw(host)`. [F370, F374, F387]
- In `ufs-qcom.c`, keep `host->phy_gear` synced with `host->host_params.hs_tx_gear` in `ufs_qcom_parse_gear_limits()`, and in `ufs_qcom_pwr_change_notify()` (`PRE_CHANGE`, `UFSHCD_STATE_RESET`) either clear `UFSHCD_QUIRK_REINIT_AFTER_MAX_GEAR_SWITCH` if matching `dev_req_params->gear_tx` or update `host->phy_gear`. In `ufs_qcom_power_up_sequence()`, if `hw_ver.major == 0x5` and `phy_gear == UFS_HS_G5`, set `host_params.hs_rate = PA_HS_MODE_A` before computing PHY `mode`. [F372, F373]
- In `ufs-qcom.c`, new `TSTBUS_*` enums before `TSTBUS_MAX` need a `testbus_info[]` entry (`nminor <= 256` for `ufs_qcom_dump_testbus()`, which passes `nminor * sizeof(u32)` to `print_hex_dump()`) and a `case` in `ufs_qcom_testbus_config()`. In `ufs_qcom_set_core_clk_ctrl()`, check `cycles_in_1us` with `FIELD_FIT(CLK_1US_CYCLES_MASK_V4, ...)` (`hw_ver.major >= 4`) or `CLK_1US_CYCLES_MASK` (`< 4`), returning `-ERANGE` before `FIELD_PREP`. In `ufs_qcom_cfg_timers()`, clamp `clk_freq` to `>= DEFAULT_CLK_RATE_HZ` (`1000000`) before dividing by `USEC_PER_SEC`. [F375, F389, F415, F429]
- In `ufs_qcom_op_runtime_config()`, compute `opr->base = hba->mcq_base + (opr->offset - UFS_QCOM_MCQ_CONFIG_OFFSET)`. In `ufs_qcom_check_hibern8()`, re-read `ufshcd_dme_get()` once on timeout before checking `tx_fsm_val != TX_FSM_HIBERN8`. In `ufs_qcom_init()`, if `drvdata && drvdata->no_phy_retention` (`sm8550`/`sm8650`), set `hba->spm_lvl = UFS_PM_LVL_5`. [F406, F426, F440]
- In `dwc3-qcom.c`, `qcom->ports[]` and `pwr_evnt_irq_stat_reg[]` use 0-based `port_index`, while `usb_hub_find_child()` in `dwc3_qcom_read_usb2_speed()` and multiport DT IRQ names use `port_index + 1`. `dwc3_qcom_suspend()` saves `port->usb2_speed` before enabling IRQs, and `dwc3_qcom_disable_port_interrupts()` on resume must branch on saved `port->usb2_speed` identically to `dwc3_qcom_enable_port_interrupts()`. [F376, F392]
- In `qcom_geni_serial.c`, `port->tx_fifo_depth`, `TX_FIFO_WC`, and `RX_FIFO_WC_MSK` are in 4-byte words (`BYTES_PER_FIFO_WORD`) while `SE_UART_TX_TRANS_LEN`, `tx_remaining`, `tx_queued`, and `kfifo_len` are in bytes. In `qcom_geni_serial_handle_tx_fifo()`, clear `M_TX_FIFO_WATERMARK_EN` in `SE_GENI_M_IRQ_CLEAR` after writing a chunk and disable it in `SE_GENI_M_IRQ_EN` when `tx_remaining == 0`. Before console TX in `__qcom_geni_serial_console_write()` or UARTDM `__msm_console_write()`, add the number of `'\n'` bytes in `s[0..count-1]` to the hardware TX length (`SE_UART_TX_TRANS_LEN` / `msm_reset_dm_count()`). [F369, F385, F424]
- In `qcom_geni_serial.c`, earlycon helpers (`qcom_geni_serial_poll_bitfield()`, `get_char()`, `wr_char()`, `__qcom_geni_serial_console_write()`) must only call `to_dev_port(uport)` when `((struct qcom_geni_private_data *)uport->private_data)->drv` is non-NULL. When `drop` is true in `handle_rx_console()` and `qcom_geni_serial_handle_rx_dma()`, still drain `SE_GENI_RX_FIFOn` or unprep/re-prep RX DMA. [F404, F421]
- In `get_port_from_line()`, pass `nr_ports - 1` as max to `ida_alloc_range(&port_ida, ...)`. `qcom_geni_serial_probe()` must return `-ENODEV` if `uport->private_data` is non-NULL. In `qcom_geni_serial_port_setup()`, call `geni_load_se_firmware(&port->se, GENI_SE_UART)` if proto is `GENI_SE_INVALID_PROTO`, or return `-ENXIO` if not `GENI_SE_UART`. [F382, F442, F444]
- In `msm_serial.c`, `struct uart_port uart` must be first in `struct msm_port` (`msm_serial_suspend()`/`resume()` cast `dev_get_drvdata()` to `struct msm_port *`). `msm_serial_set_mnd_regs()` must skip `MSM_UART_MREG`/`NREG`/`DREG`/`MNDREG` when `msm_port->is_uartdm` is set. In `msm_find_best_baud()`, when `clk_round_rate(msm_port->clk, old + 1)` returns `target == old`, break before `entry = table; continue;`. [F400, F422, F441]
- In `msm_handle_tx()`, TX DMA `dma_count` must be 4-byte aligned (`UARTDM_TX_AIGN`) and `>= UARTDM_BURST_SIZE` (16) on `is_uartdm > UARTDM_1P3`, and `<= UARTDM_TX_MAX` (256) on `<= UARTDM_1P3`, else use `msm_handle_tx_pio()`. In `msm_handle_rx_dm()`, `msm_port->old_snap_state` accumulates bytes read on non-stale `MSM_UART_IMR_RXLEV` and is subtracted from `UARTDM_RX_TOTAL_SNAP` and zeroed on `MSM_UART_IMR_RXSTALE` before re-arming `UARTDM_DMRX`. [F364, F386]
- In `qcom-wled.c`, `wled_cabc_config`, `wled_ovp_delay`, and `wled_auto_detection_required` are `NULL` on WLED3 (`version == 3`). On WLED5 (`version == 5`), clamp `max_brightness` to `WLED5_SINK_REG_BRIGHT_MAX_12B` when `cfg.cabc_sel` is set before `wled5_setup()`, and in `wled_update_status()` call `wled5_mod_sync_toggle()` on WLED5 vs `wled->wled_sync_toggle()` on `< 5`. In `wled_configure()`, bound `qcom,enabled-strings` length `string_len` and elements by `wled->max_string_count`, and `qcom,num-strings <= string_len`. [F354, F378, F380, F395]
- In `qcom-wled.c`, call `wled_module_enable()` only when `!!brightness != !!wled->brightness` (or in `wled_short_irq_handler()`). In `wled_auto_string_detection()`, read `WLED4_SINK_REG_CURR_SINK` before disabling sinks, and restore CABC, `WLED3_CTRL_REG_FEEDBACK_CONTROL`, `wled->brightness`, and `WLED3_CTRL_REG_MOD_EN` (or set `disabled_by_short = true` if `!sink_valid`). In `qcom-wdt.c`, both `qcom_wdt_set_timeout()` and `qcom_wdt_set_pretimeout()` must call `qcom_wdt_start()` to update `WDT_BARK_TIME` (`(timeout - pretimeout) * rate`), `WDT_BITE_TIME` (`timeout * rate`), and `WDT_RST`. [F377, F379, F381]

## Synchronization

- In `qcom_geni_serial_probe()`, mark `uport->irq` `IRQ_NOAUTOEN`. `qcom_geni_serial_startup()` must call `qcom_geni_serial_start_rx()` under `uart_port_lock_irq(uport)` after `port_setup()` and before `enable_irq(uport->irq)`. In `qcom_geni_serial_shutdown()`, call `disable_irq(uport->irq)` before `uart_port_lock_irq(uport)`, and run `stop_tx()`, `stop_rx()`, and `cancel_tx_cmd()` under `uport->lock`. [F328, F329, F330]
- In `__msm_console_write()` and `qcom_geni_serial_console_write()`, use `uart_port_trylock_irqsave()` when `oops_in_progress` is set and only unlock if `locked`. In `qcom_geni_serial_console_write()`, when `qcom_geni_serial_main_active(uport)` and (`!locked` or `port->tx_remaining == 0`), call `qcom_geni_serial_poll_tx_done()` instead of `drain_fifo()`. In `qcom_geni_serial_set_termios()`, update `port->poll_timeout_us` via `WRITE_ONCE()`. [F331, F332, F456]
- In `qcom_geni_serial_isr()`, `msm_uart_irq()`, and `msm_complete_rx_dma()`, call `uart_prepare_sysrq_char()` under `uport->lock` and unlock with `uart_unlock_and_check_sysrq()` (`_irqrestore`). In `qcom-wled.c`, hold `wled->lock` across `wled_update_status()`, `wled_short_irq_handler()`, `wled_ovp_irq_handler()`, and `wled_auto_detection_at_init()`. [F336, F473]
- In `msm_serial.c`, runtime updates to `msm_port->imr` and `MSM_UART_IMR` must hold `port->lock`. `msm_set_baud_rate()` (`__must_hold(&port->lock)`) must unlock before `msm_find_best_baud()` and `dev_pm_opp_set_rate()`, then relock and update `*saved_flags` before touching `port->uartclk`, `msm_port->imr`, or registers. `msm_stop_dma()` must clear `dma->rx.count` and `sg_init_table(&dma->tx_sg, 1)`, and `msm_complete_rx_dma()`/`tx_dma()` must recheck `!dma->rx.count` / `!sg_dma_len(&dma->tx_sg)` after locking `port->lock`. [F333, F334, F335]
- In `dwc3-qcom.c`, request wakeup IRQs with `IRQF_NO_AUTOEN`, enable them only after core suspend, and disable before core resume; only call `dwc3_qcom_is_host(qcom)` or dereference `qcom->dwc.xhci` where role switching cannot race. In `ufs_qcom_host_reset()`, call `ufshcd_disable_irq(hba)` before `reset_control_assert(host->core_reset)`, and `ufshcd_enable_irq(hba)` after deassert only if `hba->is_irq_enabled` was true. [F339, F342, F462]

## Object Lifetimes

- In `ufs_qcom_opp_freq_to_clk_freq()`, verify `found` before `dev_pm_opp_get_freq_indexed(opp, idx)` and call `dev_pm_opp_put(opp)` on both `!found` and normal paths. In `ufs-qcom.c`, free platform MSIs via `platform_device_msi_free_irqs_all(hba->dev)` on `ufs_qcom_config_esi()` errors and in `ufs_qcom_remove()` when `host->esi_enabled`. In `ufs_qcom_hce_enable_notify()` (`PRE_CHANGE`), run `ufs_qcom_power_up_sequence(hba)` before `ufs_qcom_enable_lane_clks(host)`; if `phy_set_mode_ext()`, `phy_power_on()`, or `phy_calibrate()` fails after `phy_init(phy)`, call `phy_exit(phy)`, and in `ufs_qcom_exit()` disable lane clocks and call `phy_power_off()` before `phy_exit()`. [F312, F314, F407, F432, F435]
- In `dwc3-qcom.c`, never call `reset_control_assert(qcom->resets)` after `reset_control_deassert()`. After `clk_bulk_prepare_enable()`, probe failures must disable/unprepare `qcom->clks` (calling `dwc3_core_remove(&qcom->dwc)` first if `dwc3_core_probe()` succeeded). `dwc3_qcom_interconnect_init()` uses non-devm `of_icc_get()`, so its failures, later probe failures, and `dwc3_qcom_remove()` must `icc_put()` both `icc_path_ddr` and `icc_path_apps`. [F317, F319, F449]
- In `msm_serial.c`, `msm_request_tx_dma()`, `msm_request_rx_dma()`, and `msm_release_dma()` must zero `struct msm_dma` on failure/release (`dma->chan = NULL`). `msm_request_port()` must `release_mem_region()` if `ioremap()` fails, and `msm_release_port()` must release the region, `iounmap()`, and set `port->membase = NULL`. In `msm_serial_early_console_setup_dm()`, clear `UARTDM_DMEN` to 0 and reset/enable TX via `MSM_UART_CR` before setting `device->con->write`. [F320, F322, F431]
- In `qcom-wled.c`, when `wled_module_enable(wled, 0)` runs with `wled->ovp_irq > 0`, call `disable_irq(wled->ovp_irq)` only if `cancel_delayed_work_sync(&wled->ovp_work)` is `false`; `wled_configure_ovp_irq()` must reset `wled->ovp_irq = 0` if `devm_request_threaded_irq()` fails. [F327]

## API Contracts

- In `ufs-qcom.c`, when `hba->use_pm_opp` and `freq != ULONG_MAX`, `ufs_qcom_cfg_timers()`, `ufs_qcom_set_core_clk_ctrl()`, and `ufs_qcom_freq_to_gear_speed()` must map `freq` via `ufs_qcom_opp_freq_to_clk_freq()`. `ufs_qcom_freq_to_gear_speed()` must clamp gear to `hba->max_pwr_info.info.gear_rx` and return `UFS_HS_DONT_CHANGE` if `!hba->use_pm_opp` or unsupported. `ufs_qcom_set_clk_40ns_cycles()` takes `cycles_in_1us` in MHz via `ceil(clk_freq, HZ_PER_MHZ)` and must use its `switch` table (403 MHz needs 16, not 17). [F346, F347, F371, F414]
- In `ufs_qcom_ice_init()`, scale `REG_UFS_CRYPTOCAP` index `i` by `sizeof(__le32)`, pass `caps.config_count + 1` to `devm_blk_crypto_profile_init()`, and multiply `cap.sdus_mask` by `512`. `ufs_qcom_ice_keyslot_program()`/`evict()` must bracket ICE calls with `ufshcd_hold(hba)`/`ufshcd_release(hba)`. In `ufs_qcom_config_esi()`, allocate `hba->nr_hw_queues - hba->nr_queues[HCTX_TYPE_POLL]` MSIs. In `ufs_qcom_dump_dbg_regs()`, guard `ufs_qcom_dump_mcq_hci_regs()`, `cond_resched()`, and `ufs_qcom_dump_testbus()` with `if (in_task())`, and use `GFP_ATOMIC` in `ufs_qcom_dump_regs()`. [F427, F460, F468, F470]
- In `dwc3-qcom.c`, `drvdata` is owned by `dwc3_core_probe()` (`&qcom->dwc`); never call `platform_set_drvdata()` in `dwc3_qcom_probe()` and always use `to_dwc3_qcom(dev_get_drvdata())`. Pass `probe_data.ignore_clocks_and_resets = true` and cap `probe_data.res->end` at `res.start + SDM845_QSCRATCH_BASE_OFFSET` to `dwc3_core_probe()`. [F423, F475]
- In `qcom_geni_serial.c`, `qcom_geni_serial_poll_init()`, `startup()`, and `console_setup()` must check `if (!port->setup)` before `qcom_geni_serial_port_setup()`, and `poll_init()` must only issue `UART_START_READ` when `!qcom_geni_serial_secondary_active(uport)`. In `wled3/4/5_set_brightness()`, pass a `__le16` (`cpu_to_le16`) with `val_count = sizeof(v)` (`2`) to `regmap_bulk_write()`. [F368, F428]
- In `qcom-wdt.c`, `qcom_wdt_probe()` must reject `wdt->rate == 0` or `> data->max_tick_count`, and if `qcom_wdt_is_running()`, call `qcom_wdt_start()` and set `WDOG_HW_RUNNING` before registration. `qcom_wdt_restart()` runs in atomic context and must call `wmb()` after enabling `WDT_EN` and use `mdelay()`. [F466, F476]

## Error Handling

- In `ufs_qcom_setup_clocks()`, check `ufshcd_get_variant(hba)` for `NULL` before dereferencing `host`. After `ufshcd_set_variant(hba, host)` in `ufs_qcom_init()`, failures must `goto out_variant_clear` to reset variant to `NULL`. In `ufs_qcom_clk_scale_notify()`, any error after `ufshcd_uic_hibern8_enter(hba)` in `PRE_CHANGE` must call `ufshcd_uic_hibern8_exit(hba)`. In `ufs_qcom_ice_init()`, treat `devm_of_qcom_ice_get()` returning `ERR_PTR(-EOPNOTSUPP)` or `NULL` as non-fatal (`return 0` without `UFSHCD_CAP_CRYPTO`). [F316, F343, F344, F345]
- In `dwc3-qcom.c`, `dwc3_qcom_interconnect_enable()`/`disable()` must roll back `icc_path_ddr` if `icc_path_apps` fails. In `dwc3_qcom_probe()`, check `platform_get_resource()`/`devm_ioremap()` for `NULL` and set negative `ret` before `goto clk_disable`. In `dwc3_qcom_setup_port_irq()`, leave `qcom->ports[port_index].*_phy_irq` as `0` unless `irq > 0` and `dwc3_qcom_request_irq()` succeeds. Check `devm_kasprintf()` for `NULL` (`-ENOMEM`) in `wled_configure()`, `dwc3_qcom_setup_port_irq()`, and `qcom_geni_serial_probe()`. In `msm_serial_probe()` and `geni_serial_resource_init()`, ignore `-ENODEV` from `devm_pm_opp_of_add_table()` and propagate other errors. [F318, F350, F351, F352, F360]

## External Contracts

- `include/dt-bindings/clock/qcom,dispcc-sm8150.h` and `qcom,dispcc-sm8350.h` symlink to `qcom,dispcc-sm8250.h`; never renumber or remove existing IDs in `qcom,dispcc-sm8250.h`. In `ufs-qcom.c`, `ufs_qcom_init()` and `ufs_qcom_init_lane_clks()` must skip `devm_phy_get()` and `devm_clk_bulk_get_all()` when `has_acpi_companion(dev)` is true. [F398, F443]

## Known Pitfalls

- For 32-bit UART FIFOs (`UARTDM_RF`/`TF`, `MSM_UART_TF`, `SE_GENI_RX`/`TX_FIFOn`), `ioread32_rep()`/`iowrite32_rep()` require a `>= 4`-byte buffer and `count = 1` (words, not bytes), and partial `< 4`-byte TX stack buffers `buf[4]` must be zero-initialized (`msm_handle_tx_pio()`, `__msm_console_write()`, `qcom_geni_serial_send_chunk_fifo()`). [F358, F425]
- In `qcom_geni_serial_poll_bitfield()`, round `timeout_us` via `DIV_ROUND_UP(timeout_us, 10) * 10` before the `timeout_us -= 10` loop and use `udelay()` (not `readl_poll_atomic()`, for earlycon). In `qcom_geni_serial_get_char()`/`handle_rx_fifo()`, check `word_cnt` non-zero before `word_cnt - 1`, and treat `RX_LAST_BYTE_VALID == 0` on `RX_LAST` as `BYTES_PER_FIFO_WORD` (4). [F402, F419]
- In `__msm_console_write()`, keep `bool replaced = false` outside `while (i < count)` and only advance `s++` when `j < num_chars` after `'\r'` insertion. In `msm_start_rx_dma()` fallback and `msm_complete_tx_dma()` on `UARTDM > 1p3`, reset and re-enable RX/TX via `MSM_UART_CR` after clearing `UARTDM_DMEN`. [F399, F447]
- In `qcom-wled.c`, index per-string registers and sink bits by `j = wled->cfg.enabled_strings[i]`, not loop counter `i`; in `wled_auto_string_detection()`, shift `j` for `WLED4_SINK_REG_CURR_SINK` but write `j + 1` to `WLED3_CTRL_REG_FEEDBACK_CONTROL`. Keep `if (c == val) break;` inside `for (j = 0; c != val; j++)` in `wled_configure()`. In `wled4_setup()`, write `WLED4_CTRL_REG_SEC_UNLOCK` (`0xa5`) to `WLED4_CTRL_REG_SEC_ACCESS` before writing `WLED4_CTRL_REG_TEST1`. [F396, F410, F411, F448]
- In `ufs-qcom.c`, flush writes to `REG_UFS_CFG1`, `REG_UFS_CFG2`, `REG_UFS_SYS1CLK_1US`, and `dev_ref_clk_ctrl_mmio` with a readback before delaying. In `dwc3_qcom_disable_wakeup_irq()`, use `disable_irq_nosync(irq)` rather than `disable_irq(irq)`. [F445, F463]
