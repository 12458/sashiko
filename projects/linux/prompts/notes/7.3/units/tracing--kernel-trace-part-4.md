# TRACING — kernel/trace (part 4)

Advanced ftrace trace event mechanisms: triggers (`trace_events_trigger.c`), histograms/actions (`trace_events_hist.c`), synthetic events (`trace_events_synth.c`), user events (`trace_events_user.c`), event injection (`trace_events_inject.c`), and format exports (`trace_export.c`).

## Architecture & Data Flow

- In `event_hist_trigger_parse()`, `create_actions(hist_data)` must precede `tracing_map_init()` (so `hist_trigger_elt_data_alloc()` allocates `n_field_var_str + n_save_var_str + n_var_str` slots in `elt_data->field_var_str`) and `save_hist_vars(hist_data)` (called whenever `has_hist_vars(hist_data) || hist_data->n_var_refs` is true). `elt_data->comm` is allocated only when a field has `HIST_FIELD_FL_EXECNAME`, so callers must check `elt_data->comm != NULL`. [F62, F69, F74]
- In `event_hist_trigger()`, `resolve_var_refs()` must run with `self = false` before `hist_trigger_elt_update()` (`var_data != hist_data`) and `self = true` after (`var_data == hist_data`). `create_var_ref()` must enforce `hist_data->n_var_refs < TRACING_MAP_VARS_MAX`, and `parse_action_params()`/`trace_action_create()` must bound `data->n_params` to `SYNTH_FIELDS_MAX`. [F100, F117]
- In `struct action_data`, `data->handler` discriminates the union: `match_data` for `HANDLER_ONMATCH` (`onmatch_destroy()`) vs `track_data` for `HANDLER_ONMAX`/`HANDLER_ONCHANGE` (`track_data_destroy()`). For `ACTION_TRACE`, `data->synth_event_name` is set only when `data->use_trace_keyword` is true (else `data->action_name`). [F58, F59]
- `create_key_field()` aligns keys to `sizeof(u64)` up to `HIST_KEY_SIZE_MAX`. `event_hist_trigger()` must `memset()` per-CPU `hist_pad->compound_key` (`hist_data->key_size`) and `hist_pad->entries` (`HIST_STACKTRACE_SIZE`), and `add_to_key()` clamps strings to `key_field->size - 1`. Stacktrace vars store frame count at `((unsigned long *)str)[0]` and frames from index 1; `trace_event_raw_event_synth()`, `print_synth_event()`, and `event_hist_trigger()` must reserve/skip index 0. [F64, F95, F103]
- `create_tracing_map_fields()` registers `HIST_FIELD_FL_VAR` as map variables, so `create_sort_keys()` must skip them when incrementing `sort_key->field_idx`, and `event_hist_trigger_print()` must add `hist_data->n_vars` when `idx >= hist_data->n_vals - hist_data->n_vars`. [F110]
- `parse_unary()` and `parse_expr()` must copy `size`, `is_signed`, `type`, and `HIST_FIELD_FL_TIMESTAMP | HIST_FIELD_FL_TIMESTAMP_USECS` from `operand1` to `expr`, and `contains_operator()` must scan `+`/`-` before `/`/`*` via `strrchr()` (`plus_op > minus_op`, `mult_op > div_op`). For `FIELD_OP_DIV` with a `HIST_FIELD_FL_CONST` divisor, `parse_expr()` must reject 0 and copy `var2->constant` to `operand2->constant` before `hist_field_get_div_fn()`; `HIST_FIELD_FN_DIV_MULT_SHIFT` requires divisor and dividend `< (1 << HIST_DIV_SHIFT)`. [F72, F108, F122, F123]
- `find_named_trigger()` must skip entries with `data->named_data != NULL`. Loops on `file->triggers` must check `cmd_ops->trigger_type` before casting `private_data`. Iterators on `dyn_event_list` (`find_synth_event()`, `synth_events_seq_show()`) must check `is_synth_event(pos)` before `to_synth_event(pos)`. [F60, F120, F141]
- In `trace_events_synth.c`, `synth_field.offset` and `synth_event.n_u64` count 8-byte `union trace_synth_field` slots (`STR_VAR_LEN_MAX / sizeof(u64)` for static strings, 1 otherwise), whereas `trace_define_field()` and `trace_dynamic_info.offset` use byte offsets. [F128]
- `trace_alloc_entry()` (`trace_events_inject.c`) allocates `entry_size + 1` zeroed bytes and points `FILTER_DYN_STRING`, `FILTER_RDYN_STRING`, and `FILTER_PTR_STRING` fields to the trailing NUL or `""`. Dynamic locators at `*(u32 *)(entry + field->offset)` encode `(str_len << 16) | str_loc`, with `str_loc` relative to `entry` for `__data_loc` (`FILTER_DYN_STRING`) and to `field->offset + sizeof(u32)` for `__rel_loc` (`FILTER_RDYN_STRING` / `VALIDATOR_REL`). [F65, F67, F99]
- In `trace_events_user.c`, field/validator offsets include `sizeof(struct trace_entry)` while `user->min_size` excludes it; `user_event_ftrace()`/`user_event_perf()` copy into `entry + 1` but pass `entry` to `user_event_validate()`. `user_events_write_core()` must verify `idx >= 0 && idx < refs->count` and `i->count >= user->min_size`. [F88, F137]
- `user_event_set_tp_name()` allocates a separate `EVENT_TP_NAME(user)` only when `EVENT_MULTI_FORMAT(user->reg_flags)` is set; `find_user_event()` must match `EVENT_MULTI_FORMAT`, and teardown must free `EVENT_TP_NAME(user)` when `EVENT_NAME(user) != EVENT_TP_NAME(user)`. [F85]
- `user_event_enabler.values` must be `unsigned long` for `ENABLE_BITOPS()`. `user_event_enabler_dup()` must skip `ENABLE_VAL_FREEING_BIT` enablers and mask `values` with `ENABLE_VAL_DUP_MASK`. Fault retry loops in `user_event_enabler_create()`, `user_event_mm_clear_bit()`, and `user_event_enabler_fault_fixup()` must init `attempt` before `retry:`, increment in `user_event_enabler_write()`, and bound to `attempt <= 10` in `user_event_mm_fault_in()`. [F82, F116, F138]
- `ERRORS` X-macros in `trace_events_hist.c` and `trace_events_synth.c` must keep enums and `err_text[]` 1-to-1 for `hist_err()`/`synth_err()`. [F176]

## Synchronization

- In `trace_events_user.c`, lock order is `group->reg_mutex` -> `event_mutex` -> `mm->mmap_lock`. `user_event_parse()` holds `group->reg_mutex` for `user_event_set_tp_name()` and `event_mutex` for `current_user_events`/`max_user_events`, registration, and `group->register_table`. `user_event_put(user, locked)` and `user_event_enabler_destroy(enabler, locked)` require `locked == true` iff `event_mutex` is held. [F32, F154]
- `user_event_enabler_write()` holds `event_mutex` and `mmap_read_lock(mm->mm)`, pins with `pin_user_pages_remote(..., FOLL_WRITE | FOLL_NOFAULT, ...)`, maps with `kmap_local_page()`/`kunmap_local()`, and unpins with `unpin_user_pages_dirty_lock(&page, 1, true)`. On pin failure, `user_event_enabler_create()` and `user_event_mm_clear_bit()` must drop both `mmap_read_lock` and `event_mutex` before `user_event_mm_fault_in()`, while `fixup_fault` defers via `user_event_enabler_queue_fault()` (`GFP_NOWAIT`). [F27, F151, F169]
- `user_event_enabler_update()` must not hold `rcu_read_lock()` across `mmap_read_lock()` or `user_event_enabler_write()`; under `event_mutex`, it collects `mm->next` via `user_event_mm_get_all()`, drops RCU, then locks each `mm->mm` and calls `user_event_mm_put()`. In `user_event_mm_remove()`, when `mm->tasks` hits 0 under `user_event_mms_lock`, it removes `mm->mms_link`, cycles `mmap_write_lock(mm->mm)`, and defers `user_event_mm_put()` via `queue_rcu_work()`, while writers/faults check `refcount_read(&mm->tasks) == 0` under `mmap_read_lock`. [F30, F150]
- `user_events_ref_add()` updates `info->refs` under `group->reg_mutex` via `rcu_assign_pointer()` and `kfree_rcu(refs, rcu)`. `user_events_write_core()` calls `fault_in_iov_iter_readable()` before `rcu_read_lock_sched()`, reads `info->refs` via `rcu_dereference_sched()`, and probes copy via `copy_nofault()`. [F149, F158]
- In `trace_events_trigger.c`, `event_mutex` nests outside `trigger_cmd_mutex`. All `file->triggers` RCU list mutations and `update_cond_flag()` calls require `event_mutex`. Because triggers and `trace_synth()` run under `rcu_read_lock_sched()`, `trigger_data_free()` and `set_trigger_filter()` must call `tracepoint_synchronize_unregister()` before freeing; `event_hist_trigger_free()` must call `trigger_data_free(data)` before tearing down vars/hists/pads, and `hist_clear()` must pause all same-named triggers via `pause_named_trigger()` and synchronize tracepoints before `tracing_map_clear()`. [F35, F38, F77, F155, F156]
- `event_hist_trigger()` runs in any context (including NMI) and must bracket per-CPU `hist_pads` access (`MAX_HIST_CNT`) with `get_hist_pad()` and `put_hist_pad()`. [F145]
- In `trace_events_synth.c`, `lastcmd_mutex` protects `last_cmd` in `errpos()`, `last_cmd_set()`, and `synth_err()`. In `trace_event_raw_event_synth()` and `trace_string()`, strings must be read only via `fetch_store_strlen()`, `fetch_store_string()`, or `strncpy_from_{user,kernel}_nofault()`. [F24, F147]
- `event_inject_write()` holds `event_mutex` across `event_file_file()`, `parse_entry()`, and `trace_inject_entry()`, which holds `rcu_read_lock_sched()` across buffer reserve/commit. [F43]

## Object Lifetimes

- `parse_entry()` leaves `*pentry` allocated on non-`-ENOMEM` errors, so `event_inject_write()` must always `kfree(entry)`. In `event_trigger_parse()`, `trigger_data_alloc()` is bracketed across registration by `event_trigger_init()`/`event_trigger_free()` and freed on error/removal via `trigger_data_free()`, not `kfree()`. [F1, F3]
- `register_snapshot_trigger()` calls `tracing_arm_snapshot(file->tr)` and must call `tracing_disarm_snapshot(file->tr)` if `register_trigger()` fails; `unregister_snapshot_trigger()` disarms only if `try_unregister_trigger()` returns `true`. [F5]
- `synth_event_reg()` pairs `try_module_get(event->mod)` on register with `module_put(event->mod)` on unregister. `synth_event_delete()` on a module event (`se->mod != NULL`) must call `tracing_reset_all_online_cpus()` after dropping `event_mutex`. `destroy_synth_event()` and `synth_event_release()` require `se->ref == 0` (tracked under `event_mutex` by `trace_action_create()`, `action_data_destroy()`, `event_hist_trigger_parse()`, and `hist_unreg_all()`). [F7, F10, F174]
- `alloc_synth_event()` sets `event->n_fields = n_fields` only after all allocations succeed, so `__create_synth_event()` frees `fields[i]` on `alloc_synth_event()` failure. Similarly, `create_hist_data()` clears `hist_data->attrs = NULL` on error before `destroy_hist_data()`, so `event_hist_trigger_parse()` must call `destroy_hist_trigger_attrs(attrs)` when `create_hist_data()` returns `ERR_PTR`. [F8, F15]
- `event_hist_trigger_init()` calls `alloc_hist_pad()` before `++data->ref`, and `event_hist_trigger_free()` must call `free_hist_pad()` unconditionally on every call. `destroy_hist_field()` ignores `HIST_FIELD_FL_VAR_REF` fields, which are freed once via `__destroy_hist_field()` on `hist_data->var_refs[]` in `destroy_hist_fields()`. [F13, F16]
- On last ref of a non-persistent `user_event`, `user_event_put()` holds `event_mutex`, resets `user->refcnt` to 1 while in `group->register_table`, and queues `delayed_destroy_user_event()` on `user->put_work`. If `copy_nofault()` or `user_event_validate()` fails after reservation, `user_event_ftrace()` must call `__trace_event_discard_commit()` and `user_event_perf()` must call `perf_swevent_put_recursion_context()`. [F18, F23]

## API Contracts

- Synthetic event tracing must bracket reserve/commit with `ring_buffer_nest_start()`/`ring_buffer_nest_end()`; once `[__]synth_event_trace_start()` succeeds, `[__]synth_event_trace_end()` must be called even on error. `__synth_event_add_val()` must check `trace_state->disabled` before dereferencing `event`/`entry` and reject mixing `add_name` and `add_next` (`-EINVAL`). [F9, F121, F148]
- `create_synth_event()` and `user_event_create()` must return `-ECANCELED` on prefix mismatch. `synth_events_open()` and `event_trigger_regex_open()` must check `security_locked_down(LOCKDOWN_TRACEFS)` before `O_TRUNC` cleanup. `user_event_capable()` requires `perfmon_capable()` when `USER_EVENT_REG_PERSIST` is set. [F45, F166, F171]
- `parse_field()` returns `ERR_PTR` on error, or `NULL` on success for common/synthetic tokens while setting `HIST_FIELD_FL_*`. `find_match_var()`, `find_synthetic_field_var()`, and `create_target_field_var()` return `NULL`, a valid pointer, or `ERR_PTR`, so callers must check both and clear `ERR_PTR` before cleanup. [F51, F52]
- `synth_field_size()` returns `0` for both valid dynamic (`char[]`, `long[]`) and unknown types, requiring a secondary check. `trace_string()` returns `fetch_store_strlen()` when `is_dynamic` is true (else `0`), advancing `*n_u64` by `1` (dynamic) or `STR_VAR_LEN_MAX / sizeof(u64)` (static). [F54, F55]
- `__set_synth_event_print_fmt()` returns length excluding NUL (allocate `len + 1`), whereas `user_*_set_*()` helpers include NUL; `user_dyn_field_set_string()` updates `*iout = i` only when `len != 0`. `__fill_bar_str(buf, size, ...)` writes `buf[size] = '\0'` (buffer needs `size + 1` bytes). [F112, F133, F142]

## Error Handling

- `set_trigger_filter()` sets `data->filter` even on error, so callers of `event_trigger_set_filter()` must call `event_trigger_reset_filter()` on failure. Tracefs `.read`/`.write`/`seq_operations.start` callbacks must call `event_file_file(filp)` (checking `EVENT_FILE_FL_FREED`, returning `-ENODEV` if `NULL`) under `event_mutex`, not `event_file_data(filp)`. [F4, F44]
- `register_trace_event()` returns `0` on failure (translate to `-ENODEV`). `ERR_PTR` values stored in `event->tp` or `hist_data->map` must be cleared to `NULL` before teardown, whereas `create_hist_field()` returns `NULL` on failure. [F46, F47, F53]
- `event_hist_trigger()` must check `if (unlikely(!rbe))` before dereferencing `rbe`/`rec`. `hist_field_div()` must return `-1` on `!val2` before shifting/dividing. `synth_event_trace*()` wrappers must translate `-ENOENT` from `__synth_event_trace_init()` to `0`. [F61, F124, F177]

## External Contracts

- `user_reg_get()` and `user_unreg_get()` must check `size` in `[offsetofend(...), PAGE_SIZE]`, use `copy_struct_from_user()`, and reject unknown flags or non-zero reserved fields; `user_reg_get()` also requires `enable_size` of 4 (or 8 on 64-bit), aligned `access_ok()` `enable_addr`, and `enable_bit < enable_size * BITS_PER_BYTE`. `user_event_validate()` must verify `__data_loc`/`__rel_loc` bounds and NUL termination (`VALIDATOR_ENSURE_NULL`) in the kernel buffer after copy. [F86, F163, F165]
- `user_event_parse()` must use `user_event_argv_split()` (`insert_space_after_semis()`), and `user_field_set_string()`/`user_event_show()` must append `" %d"` (`field->size`) for `"struct "` types. `__create_synth_event()` allows multiple fields per `;` segment only when `cmd_version == 1`. `__array` in `trace_export.c` must set `.len = _len`. [F91, F92, F97, F98]

## Known Pitfalls

- `create_tracing_map_fields()` must check `hist_field->flags` before `field->size` because legacy `cpu`/`stacktrace`/`comm` fields have `field->size == 0`. In `check_expr_operands()` and `parse_expr()`, `HIST_FIELD_FL_VAR_REF`/`HIST_FIELD_FL_ALIAS` operands must be resolved via `find_var_field(operand->var.hist_data, ...)`. [F70, F118]
- In `parse_entry()`, `krealloc()` requires refreshing `entry = *pentry` and freeing `entry` on failure. In `user_events_write_core()`, pass a copy `copy = *i` of the `iov_iter` to each probe. In `user_event_parse_field()`, check `"__data_loc unsigned "`/`"__rel_loc unsigned "` before non-unsigned prefixes. [F79, F84, F109]
- `align_addr_bit()` must align `uaddr` to `sizeof(long)` and add 32 to `bit` for `ENABLE_VAL_32_ON_64_BIT` (on aligned BE or unaligned LE), and `user_events_ioctl_unreg()` must keep `ENABLE_VAL_COMPAT_MASK`. [F90]
- Two-pass `snprintf()` helpers must use `LEN_OR_ZERO` (`len ? len - pos : 0`). `__synth_event_show()` advances by `sizeof("__data_loc")` (11), and `synth_field_fmt()` returns `"%s"` for strings. `entry->fields[n_u64]` must be accessed via width-matched `union trace_synth_field` members, and `is_string`/`is_stack`/scalar loops must use `if`/`else if`/`else`. [F93, F94, F106, F132, F134]
- In `event_enable_*()`, `trace_event_trigger_enable_disable()` and `update_cond_flag()` target `file`, while soft-mode `trace_event_enable_disable(..., 1)` and `trace_event_try_get_ref()` target `enable_data->file`. `__get_percentage()` must re-check `!total` after `div64_u64(total, 10000)`, and `hist_field_bucket()` must use `div64_ul()` when `val >= LONG_MAX`. [F119, F125, F126]
